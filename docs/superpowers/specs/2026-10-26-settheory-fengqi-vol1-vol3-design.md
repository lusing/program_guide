## 5. 正文写作规范

每章采用“问题—定义—直觉—引理—主定理—证明—例子—机器实验—边界—小结”的教学顺序，可按内容合并，但不得只罗列代码。

硬性要求：

1. 每章不少于 200 行，文字多于代码；难章不设上限。
2. 代码前说明为什么需要它，代码后解释输出和数学意义；正文不出现的示例辅助代码不得在理解主线上留下缺口。
3. 原书编号只作溯源，如“冯琦第三卷定理 1.2”，不得写成“证明见原书”。
4. 主定理至少讲清：假设各自为何需要、证明分几步、每步消费哪个前引理、结论改变了什么。
5. 对极长证明采用完整路线图加逐引理证明，不用“类似可证”掩盖关键的新技巧；真正重复的机械步骤可明确指出重复对象与归纳参数。
6. 区分 ZFC 定理、相对一致性结论和额外大基数假设。所有断言必须带清前提，不把 `Con(ZFC+大基数)` 写成无条件存在。
7. 统一符号：初等嵌入 `j`、临界点 `crit(j)`、泛型滤子 `G`、非荟萃理想 `NS_κ`、投影点类 `Σ^1_n/Π^1_n/Δ^1_n`；首次出现给文字定义。
8. 章末采用 Zig 式上一章/下一章导航；新章与既有 Jech、Viale 路线只作概念对照，不制造阅读依赖。

## 6. 七通道设计

| 通道 | 主要承担 | 禁止的假绿 |
|---|---|---|
| Lean 4 + mathlib4 | 序数/基数/滤子/拓扑/测度/博弈等官方锚点；有限超滤、有限商与树的可证片段 | 以 `sorry`、未审计公理或 `native_decide` 假称完整大基数形式化 |
| Isabelle/ZF | ZF 对象逻辑、Constructible、序数/基数、传递模型与有限浅嵌入 | 用超时、失败日志或不可复现缓存宣称通过 |
| Coq | 可判定有限结构、关系/树/博弈、显式公理记账与计算证明 | 用未声明公理或计算超时留下无结论文件 |
| Agda | 构造性有限模型、归纳树、策略与良基递归 | 以 `postulate` 隐去本次要证的命题 |
| Julia | 高性能有限枚举、超幂表、条件搜索、博弈与数值实验 | 只打印“PASS”而无独立断言；缺章号/END 标记 |
| Python/scipy | 与 Julia 独立实现的组合对拍、测度/拓扑实验、穷举反例 | 复制同一错误算法而不做交叉约束；非 ASCII 输出受 GBK 影响 |
| Prolog | 有限关系搜索、泛型链、树分支、策略与约束枚举 | 搜索超时、栈溢出或 `forall` 绑定泄漏造成空成功 |

每个有限实验在正文中明确“它验证了哪个有限命题、它不能证明哪个无穷命题”。大基数本体、完整力迫定理、覆盖引理、Martin–Steel 等以数学正文为主，不宣称当前数学库已经完整形式化。
