## 新章设计（编号=示例号）

### 35 FOL 语义表列（C/L）

- 对书：3e §7.5-7.6。桥接：07（命题表列）→ 本章 γ/δ → 16（FOL ND）。
- 教学要点：α/β 抄命题层；γ 用新鲜变元、δ 用新闭项（Ben-Ari 的
  a_{f,i} 编号常量——「按需求造名字」与 23 章 Henkin 常量同源）；
  fuel 化搜索；开饱和分支读出 Herbrand 项模型。
- 机器件：深嵌入表列规则 + 可靠性（开分支→模型）+ 单向完备
  （饱和开分支的存在性传递）；复用 14 章 fterm/folform。

### 36 LTL 语义表列（C/L）

- 对书：3e §13.5（2e §11.4 佐证）。桥接：27（LTL 语义）→ 本章判定法
  → 38（表列状态图当 Büchi 的前身）。
- 教学要点：闭包集（有限性是算法成立的根基）；节点 = (当前公式集,
  下一公式集) 对；X-步展开；开放分支→预备状态图→环上 fulfillment
  检查（每个 F/U 最终兑现）——有限图+环 = 无穷路径的有限证书。
- 机器件：closure 计算 + 具体公式现场（如 ◇□p 可满足读出模型、
  □(p→◇q) 类）。

### 37 时态演绎系统 L（C/L）

- 对书：3e ch14（公理系统 L）+ §13.6\*（过去算子 U/S+分离定理，文档级）。
- 桥接：31（模态 K）——G/X 是线性时序上的模态；17（Gen 侧条件）。
- 教学要点：公理 = 重言实例 + □ 分配（K）+ ◇↔¬□¬ + **归纳公理**
  （时态归纳=不变式规则的理论形态，直通 25/30/39）；MP + Gen(□)。
- 机器件：深嵌入公理系统 + 若干定理（分配/对偶/归纳实例）。

### 38 自动机与 LTL 模型检查（C/L/P）——本轮最大件

- 对书：3e §16.4-16.8（程序=自动机、¬φ→Büchi、乘积+空性检查）。
- 桥接：28（显式 MC 实验）→ 本章反例路径的**算法化搜索**；36（表列
  状态图是 Büchi 的前身）；34（符号路线的显式对偶）。
- 教学要点：模型 K × ¬φ 的 Büchi 乘积；空性 ⟺ 无反例；非空见证 =
  「到达接受态且成环」的有限路径段——无穷反例的有限证书（与 36
  fulfillment 同一机制）；嵌套 DFS/Tarjan 找环的算法思想。
- 机器件：C/L 显式 Büchi + product + 找环 + 正确性小定理（环→无穷
  反例路径读出）；P（SWI-Prolog）同一算法可运行版，真跑小协议找反例。

### 39 并发程序演绎验证（C/L）

- 对书：3e §16.1-16.3。桥接：28（同一互斥案例的 MC 面）→ 演绎面；
  25/30（霍尔规则）→ 并发版；37（时态归纳=不变式）。
- 教学要点：交错语义；原子区/await 的霍尔规则；全局不变式 I 对
  **每条原子步**保持 ⟹ AG I——演绎验证与模型检查在此合流。
- 机器件：小并发例（简化互斥）「不变式对每个原子步保持」逐步机器化。

### 40 SLD 与逻辑编程语义（C/L/P）

- 对书：3e ch11（SLD/计算规则/Prolog）+ 2e §8.3（cut/NAF/CWA 细节）
  + 2e §8.5（CLP 小节）。
- 桥接：20（T_P 不动点）→ SLD 搜索树 → Prolog 工程化（cut/NAF 偏离
  纯逻辑的点在账本上写清）。
- 教学要点：计算规则独立性（fair 计算规则不影响可解集）；搜索规则
  决定解的次序与完备性；green/red cut；NAF 与经典否定的差异+CWA；
  CLP(H)：约束传播代替标签生成。
- 机器件：C/L 计算规则独立性（对归结树归纳）；P 实测现场
  （cut 语义对照/NAF 非 CWA 例/CLP 简例）。

### 41 归结完备性与 SAT 难例（C/L）

- 对书：3e §4.4-4.5（归结 S&C+鸽笼难例）+ §6.2（Davis-Putnam 变量
  消元）+ §6.4（扩展例）+ §6.5-6.7（启发式/随机/复杂度，文档级）。
- 桥接：19（归结可靠性）→ 完备性补口；09（DPLL）→ DP 消元的对照面；
  07（表列判定）与归结判定的两条路。
- 教学要点：归结反驳完备；鸽笼 PHP 归结证明长度指数爆炸（SAT 求解
  器的天然难例——复杂度注记）；DP 三规则（纯文字/单子句/变量消元）
  是 DPLL 的「消元先行」亲戚。
- 机器件：PHP(3,2) 显式归结反驳件 + DP 变量消元器（C/L）。

### 42 程序合成与形式语义（C/L）

- 对书：3e §15.4（合成）+ §15.5（形式语义）+ §15.6（相对完备性注记）。
- 桥接：25/30（霍尔规则正向用）→ 反向用（规约反推程序）；12（证明=
  程序）的工程化身；39 的步语义单进程版。
- 教学要点：除法程序合成走查（不变式发现的艺术——逆向构造）；
  while 小步操作语义；指称=不动点（与 20/34 的 Knaster–Tarski 第四次
  会师）；Cook 相对完备性（不完备性的又一现身——枚举不可表达）。
- 机器件：step 语义 + 「霍尔三元组对步语义可靠」联接件
  （若 {P}c{Q} 且执行 s→*s' 则 P s → Q s'）。

## Prolog 通道协议（第七通道）

- 入口：`build.ps1` 新增分支——发现 `examples/NN_*/exNN_*.pl` 时执行
  `swipl -q -f <file> -g main -t halt`（工作目录=文件所在目录）；
- 判定：exit 0 + stdout 出现「==== exNN 开始/结束 ====` 标记区间
  （单引擎简化协议；prolog 教程的六条判定/双引擎逐字节比对不搬——
  本教程 .pl 只有两件且非主角）；
- 编码纪律：.pl 一律 UTF-8 无 BOM + LF（Write 后 python
  `open(p,'w',newline='\n')` 规范化）；swipl 10 源码默认 UTF-8，
  批次一以中注释实测，必要时加 `:- encoding(utf8).`；
- 跨引擎抽查（可选手动）：WSL gprolog 1.5.0 跑同一文件比对输出；
- 布局：`examples/38_buechi/ex38_buechi.pl`、
  `examples/40_sldprolog/ex40_prolog.pl`。
