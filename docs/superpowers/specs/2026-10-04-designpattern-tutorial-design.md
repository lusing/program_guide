# 设计模式教程（C++23）设计文档

日期：2026-10-04
状态：已获用户批准（聊天设计阶段）

## 1. 目标与范围

编写一套符合 C++23 的设计模式教程，工程位于 `G:\code\guide\designpattern\`，体例沿用本仓库已有教程（以 `datastruct/`、`cpp20/` 为模板）。

参考三本书：

1. 《设计模式之禅（第 2 版）》（秦小波）——epub，165 个 xhtml **全文本**，直接抽取无需 OCR。主叙事线：意图→场景→逐步演化的写法最贴近教程要求。
2. 刘伟主编《设计模式（第 2 版）》（清华大学出版社）——452 页扫描 PDF，**无文本层**，需 OCR。补充标准定义、角色表、适用性、优缺点。
3. GoF《设计模式：可复用面向对象软件的基础》（2000 中译本）——13 个扫描 PDF，需 OCR。提供权威出处、经典实现与"特定语言的变化和问题"章节。

规模定位：**40 章、五篇** = 23 个 GoF 模式（含简单工厂前置章）+ 原则三讲 + 现代专题 + 实战混编 + 收官。

## 2. 关键决策（用户已拍板）

- **规模**：40 章以上。
- **现代 C++ 线**：**每章都对比**。经典 OO 写法讲透之后，给 C++23 现代写法（concepts / `std::variant`+`overload` / `std::function` / CRTP / ranges / `std::generator` / magic static / designated initializers 等），并明确"何时用哪种"。
- **验证通道**：MSVC（`/std:c++latest`）+ clang 双通道，编译+运行+输出断言全绿才过。
- **正文形态**：教程而非代码罗列。所有要讲解的代码在正文中内嵌引用，读者只读 docs 不看 examples 也能学会；每段代码前后必有文字；每章 ≥200 行、文字多于代码；"对应示例"指路放正文末尾。
- **OCR 范围**：按批次选择性 OCR——每批只 OCR 当前写作章节涉及的页码区间（两书合计约 700 页上限，实际按需），OCR 文本存 `materials/` 复用。
- **cudnn 路径**：OCR 时须设 `PATH="/g/cudnn/9.24/bin/12.9/x64:$PATH"`（rapidocr-onnxruntime 1.2.3，onnxruntime-gpu 1.20）。

## 3. 章节结构（40 章）

### 第 1 篇 准备与原则（1–4）

1. **开篇**：为什么 C++ 程序员要重学设计模式；三书导读与互补关系；C++23 工具链与本教程编码约定。
2. **单一职责与开闭原则**（SRP+OCP）。
3. **里氏替换与依赖倒置**（LSP+DIP）。
4. **接口隔离、迪米特与合成复用**（ISP+LoD+CRP）。

### 第 2 篇 创建型（5–10）

5. **简单工厂**（非 GoF，之禅前置章）：静态工厂、`std::expected` 错误处理。
6. **工厂方法**：虚构造器；模板方法版工厂；`std::movable_function`/注册表写法。
7. **抽象工厂**：产品族；`concepts` 约束产品族一致性。
8. **单例**：magic static 与 C++11 保证；`std::call_once`；Meyers 单例；单例的现代反思（依赖注入、可测试性）。
9. **原型**：`clone`、协变返回；`std::unique_ptr`+polymorphic clone。
10. **建造者**：流式 API；designated initializers；builder 模式 vs 聚合初始化。

### 第 3 篇 结构型（11–17）

11. **适配器**：对象适配器 vs 类适配器（多继承）；模板适配器。
12. **桥**：pImpl 惯用法即桥；所有权与析构语义。
13. **组合**：递归树形结构；`std::variant` 树 vs 继承树。
14. **装饰**：层层包装；模板链式装饰（policy chain）。
15. **外观**：薄封装；`constexpr` 外观。
16. **享元**：对象共享与 `flyweight` 表；`std::unordered_map`+`shared_ptr`；`std::flyweight`（boost 对照）。
17. **代理**：延迟初始化、写时复制、`std::optional`+pImpl。

### 第 4 篇 行为型（18–28）

18. **职责链**：链式处理；`std::optional` 传播、coroutine 视角。
19. **命令**：命令对象、undo/redo；`std::function`+`std::any_state`。
20. **解释器**：文法树；`std::variant` 解释器；编译期表达式模板对照。
21. **迭代器**：经典迭代器接口；C++20 ranges、C++23 `std::generator`。
22. **中介者**：集中通信；信号槽对照。
23. **备忘录**：状态快照；`std::variant`+序列化。
24. **观察者**：订阅通知；`std::function` 列表、signal-slot；线程安全问题。
25. **状态**：状态机；`std::variant`+overload 的现代状态机。
26. **策略**：可插拔算法；`std::function`/lambda/concepts 策略。
27. **模板方法**：钩子与 CRTP 静态多态对照。
28. **访问者**：双重分派；`std::variant`+`overload` 替代经典 Visitor 的完整对比。

### 第 5 篇 现代专题与实战（29–40）

29. **多态三副面孔**：虚函数 vs concepts vs `std::variant`——选择总览与性能实测。
30. **类型擦除**：`std::function` 之外的手工 type erasure、`function_ref`。
31. **实战：可扩展日志系统**（策略+装饰+工厂+单例的现代替代）。
32. **实战：事件总线**（观察者+中介者+线程安全）。
33. **实战：编译期状态机**（状态+命令+variant+constexpr）。
34. **实战：对象池与资源管理**（享元+单例+RAII）。
35. **实战：插件式框架**（工厂方法+原型+动态注册）。
36. **实战：表达式求值器**（解释器+组合+访问者+备忘录）。
37. **实战：文档导出框架**（抽象工厂+桥+外观）。
38. **实战：权限校验管道**（职责链+策略+代理）。
39. **模式的误用与陷阱**：过度设计、anti-pattern、何时不用模式；之禅混编篇反思。
40. **收官**：CHEATSheet；23 模式 × 三书章节对照表；模式关系图谱。

## 4. 每章固定结构

1. 意图与动机场景（真实痛点）。
2. 朴素写法及其坏处。
3. 经典模式逐段讲解——结构图（文字/ASCII）、角色表、代码全部内嵌引用并逐段讲解。
4. C++23 现代写法对比——同场景用现代惯用法重写。
5. 两版取舍——何时经典、何时现代。
6. 陷阱清单。
7. 与三书的对应章节索引（正文末尾）。

## 5. 工程形态

- `docs/NN-name.md`：40 章正文。
- `examples/NN_name/`：每章一个示例工程，含确定性输出的 main。
- `materials/`：epub 抽取文本、OCR 产出（md/txt）与页码索引。
- `build.ps1`：MSVC + clang 双通道编译、运行、输出断言（同 `datastruct/build.ps1` 模式）。
- `run-all.sh` / `tools/`：批量验证。
- `README.md`：三书导读 + 分章导航；`CHEATSheet.md` 于收官章完成。
