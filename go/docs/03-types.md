# 03 · 类型与变量

> 对应示例：`examples/03_types/`

## 3.1 零值：没有"未初始化"

C++ 的局部变量初值是"栈上残留垃圾"，Go 从根上消灭了这类未定义行为——**声明即有确定值**：

| 类型 | 零值 |
|---|---|
| 数值（int/float…） | `0` |
| 布尔 | `false` |
| 字符串 | `""`（不是 nil） |
| 指针 / 切片 / map / 接口 / 函数 | `nil` |
| 结构体 | 各字段各自零值 |

好处是双重的：读未赋值的变量不炸；**"零值可用"成为 API 设计目标**（如 `var wg sync.WaitGroup` 不用构造直接用）。

## 3.2 声明三件套

```go
var name string = "显式"  // 完整形态：包级常客；局部啰嗦
var age = 18              // 类型省略：右值推断
city := "北京"            // 短声明：只能进函数，主力写法
const pi = 3.14159        // 常量：编译期定死
```

`:=` 的限制：**左侧至少一个新变量**，纯重复赋值要换 `=`。同一作用域里 `x := 1; x := 2` 是编译错；但内外两层作用域的 `:=` 构成**遮蔽**（shadowing）——这是 code review 的常客。

## 3.3 无类型常量：任意精度

```go
const big = 1 << 62       // 超过 int64 也能表示
const pi = 3.141592653589793238462643383279 // 想多精就多精
```

常量在编译期是数学意义上的数，**用时才落进具体类型**。`const huge = 1 << 40` 配 `int32` 变量会在转换处报错，而不是像变量那样悄悄截断。

## 3.4 基本类型全景

| 类别 | 类型 |
|---|---|
| 整数 | `int` `int8/16/32/64`；`uint` 系；`byte`(=uint8)；`rune`(=int32) |
| 浮点 | `float32` `float64`（无 long double） |
| 复数 | `complex64` `complex128`（科学计算用，教程不展开） |
| 布尔 | `bool`（没有整数当 bool 用的隐式转换） |
| 字符串 | `string`（不可变 UTF-8 字节序列） |

`int` 是 64 位平台上的 64 位——**默认就写 `int`**，只有接口对齐（协议、文件格式）才动定宽类型。

## 3.5 显式转换：Go 不做隐式

```go
var f float64 = 3.99
i := int(f)               // 3：向零截断，不是四舍五入
i = int(math.Round(f))    // 4：要四舍五入自己说

type Celsius float64      // 命名类型：即使底层相同也不互通
type Fahrenheit float64
var c Celsius = 36.5
var f2 Fahrenheit = c     // 编译错：不同类型
f2 = Fahrenheit(c)        // 显式转换才放行
```

`int16` ↔ `int`、`int` ↔ `float64` 全都要手写转换。啰嗦？是。但"单位错了编不过"救过无数命——温度、金额、像素坐标各起一名，混用当场爆炸而不是上线后爆炸。

**转换不检查溢出**：`int32(1 << 40)` 静默截断成 0（示例 03 有实测），要防溢出自己判或用 `math.Checked` 类的手法。

## 3.6 iota：Go 的枚举

```go
type Weekday int

const (
	Sunday Weekday = iota // 0，后续自动递增
	Monday                // 1
	Tuesday               // 2
)

func (d Weekday) String() string { // 实现 fmt.Stringer，%v 打名字
	return [...]string{"周日", "周一", "周二"}[d]
}
```

没有 enum 关键字，`const + iota` 就是枚举。进阶玩法（位标志 `Flag1 = 1 << iota`）在标准库一抓一把。**给枚举实现 `String()`** 是基本礼仪，否则日志里全是数字。

## 3.7 min/max/clear：1.21 内建

```go
min(3, 1, 2)              // 1：任意同类型参数
max(3.14, 2.72)           // 3.14
clamped := min(max(v, lo), hi)  // 夹逼一行搞定
clear(slice)              // 切片/映射元素清零/清空
```

注意它们是**编译器内建**不是函数——不能当函数值传（`f := min` 编译不过）。

## 3.8 坑位清单

1. **`int` 和 `int64` 是不同类型**：内置函数返回 int，API 用 int64，混用处处 `int64(x)`。
2. **截断 vs 四舍五入**：`int(3.99) == 3`；金融场景先 `math.Round`。
3. **字符串零值是 `""` 不是 nil**：判断空串用 `s == ""`。
4. **`:=` 遮蔽**：`if err := f(); err != nil` 里新 err 遮蔽外层 err——vet 的 shadow 检查器专抓这个（默认不开）。
5. **无类型常量传参**：`f(1)` 里 1 会自动适配参数类型（包括自定义命名类型），变量就没有这待遇——常量与变量的规则不对称，面试常考。
