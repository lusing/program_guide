# 06 · 数组、切片与字符串

> 对应示例：`examples/06_slices/`

## 6.1 数组 `[N]T`：长度是类型的一部分

```zig
const arr = [_]i32{ 10, 20, 30, 40, 50 };  // [_] 推断长度，等价 [5]i32
var copy = arr;      // 数组是值：赋值 = 整块拷贝
copy[0] = -1;        // arr[0] 还是 10
```

`[5]i32` 和 `[6]i32` 是**不同类型**。数组是纯值类型——传参、赋值都拷贝（想避免拷贝传切片或 `*const [5]i32`）。这在 C 里是不可想象的（数组名退化指针），在 Zig 里数组是"一个东西"，指针才是另一回事。

## 6.2 切片 `[]T`：胖指针

```zig
const full: []const i32 = &arr;    // 数组"退化"为切片（取视图）
const mid: []const i32 = arr[1..3]; // 子切片左闭右开：{20, 30}
// mid[9] —— 越界访问 Debug/ReleaseSafe 下 panic（边界检查兜底）
```

切片 = **指针 + 长度**的胖指针，是 Zig 最常用的"序列类型"——函数参数几乎都收 `[]T`/`[]const T` 而不是数组（长度解耦）。它是对底层数组的**借用视图**：不拥有内存、生命周期挂在底层上（坑位 2）。`slice.ptr` 拿裸指针，`slice.len` 拿长度。

边界检查在 Debug/ReleaseSafe 全程开着——C 里 `arr[i]` 越界写穿内存的静默灾难，Zig 里当场崩给你看。

## 6.3 字符串：没有 string 类型

```zig
const msg = "你好，Zig";           // 类型 *const [12:0]u8：UTF-8 字节 + 末尾 0
const s: []const u8 = msg;          // 退化为切片
s.len                               // 12：字节数！不是字符数
```

Zig 的字符串就是**字节切片**。字面量的真身是"定长哨兵数组指针"（6.4 节），用到哪都自动退化成 `[]const u8`。**没有内建 UTF-8 解码**——`s.len` 是字节数（中文每字 3 字节），要按字符处理用 `std.unicode` 手动解码。打印用 `{s}`（原始字节直出）。

## 6.4 哨兵 `[:0]`：保证 0 结尾

```zig
const cz: [:0]const u8 = msg;
cz[cz.len]      // == 0：哨兵切片允许读 len 处的那个 0
```

`[N:0]u8` / `[:0]u8` 在类型里写明"末尾有个 0"——这就是与 C 字符串互操作的地基（17 章）：`cz.ptr` 可以直接丢给要 `const char*` 的 C 函数。普通切片**没有**这个保证，转 C 前要么拷贝加 0，要么确认来源是字面量/哨兵切片。

## 6.5 指针三兄弟

```zig
var x: u32 = 42;
const p: *u32 = &x;              // 单项指针：解引用 p.*，类型带"指向谁"
const many: [*]const i32 = &arr; // 多项指针：只有起点，没有长度信息
// [*:0]const u8                  // 哨兵多项指针：靠 0 找尾（C 字符串视角）
```

| 形态 | 类型 | 长度 | 用途 |
|---|---|---|---|
| 单项 | `*T` | 天然 1 个 | 普通指针、方法 self、可选优化 `?*T` 同宽 |
| 多项 | `[*]T` | **无**（危险） | 与 C 交互、底层缓冲 |
| 切片 | `[]T` | 有（胖指针） | 日常序列操作 |

**默认写切片，多项指针只在 C 边界出现**——它没有长度，越界全靠你自己保证。`&arr`（数组取址）会退化成多项指针，这常是意外来源（坑位 3）。

## 6.6 const 与可变切片

```zig
var buf = [_]u8{ 'a', 'b', 'c', 'd' };
const mut: []u8 = buf[0..];   // 可变切片：能写元素
mut[0] = 'A';
// const ro: []const u8 = mut;  // 随时可要只读视图
```

可变性分两层：`[]u8`（可写元素）和 `[]const u8`（只读）。函数参数尽量收 `[]const T`——把"我不改你的数据"写进签名。注意 `const mut` 里 const 修饰的是切片变量本身（不能重绑），元素可不可变看里面有没有 `const`。

## 6.7 坑位清单

1. **`s.len` 是字节数**：UTF-8 字符串按"字符数"循环 `s[0..n]` 会切碎多字节字符——要么按字节处理，要么 `std.unicode.Utf8View`。
2. **切片指向栈数组逃逸后悬空**：函数返回 `buf[0..]`（buf 是局部数组）= 返回悬空指针——返回切片必须返回堆内存或调用者传入的缓冲。
3. **`&arr` 是多项指针不是切片**：`[*]i32` 没有 len；要切片写 `arr[0..]` 或 `&arr` 配切片目标类型（`const s: []const i32 = &arr;` 会自动退化，两个语境别混）。
4. **修改字符串字面量编译错**：`*const [N:0]u8` 天生只读；要可变字符串先 `alloc.dupe(u8, "literal")` 拷到堆。
5. **编译期边界的子切片是数组指针**：`s[0..3]`（3 是字面量）得到 `*const [3]u8` 而不是切片——打印它要 `{any}`，传参给 `[]const u8` 倒是自动退化无碍。
6. **`for (arr) |v|` 是值拷贝**：改元素用 `|*v|`（捕获指针）或下标循环（见 04 章坑位）。
