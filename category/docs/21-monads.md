# 21 单子

> 对书：贺伟 3.5/3.6 / Simmons 5.5。代码：`examples/21_monads/`。

单子 (T, η, μ)：**代数理论的范畴化身**。机器内容（Coq）：SetMonad record
（T + Tmap + ret + join，定律按元素给）+ List 单子完整验证（零公理）。
元素级定律 = 范畴级定律的 funext 打包（贺伟 3.5 模结构的点式内联）。

文档层：**伴随生成单子**（F ⊣ G ⟹ T := G∘F）——17 章的自由范畴伴随生成「路径单子」；
Kleisli/Eilenberg–Moore 范畴；**Beck 单子性定理**（贺伟 3.6）的精细条件需要极限完整机器化——边界记录。

## 21.1 T-代数与 Eilenberg–Moore 范畴（贺伟 3.5）

单子 T = (T, η, μ) 上的**T-代数**是一个对象 A 配一条「乘法」
h : T(A) → A，满足两条结合/单位律：

```text
h∘T(h) = h∘μ_A          （乘法结合——两次折叠 = 先并再折叠）
h∘η_A  = 1_A            （单位——单元素不折叠）
```

T-代数与保结构的 (f : (A,h) → (B,k)，f∘h = k∘T(f)) 组成
**Eilenberg–Moore 范畴 A^T**。三个直觉样本把「代数」二字
落实：

- **List 单子**：代数 = 幺半群（h = 折叠——17 章自由幺半群的
  泛性质换个方向读：不是「X 造出 List X」，而是「List X 上的
  代数结构」）；
- **幂集单子 P**（贺伟练习 3.5.1 的完整展开）：代数 = **完备
  格**！h : P(X) → X 把任意子集并成一个元素；定义
  `x ≤ y ⟺ h({x,y}) = y`，则 (X,≤) 是偏序且 `∨A = h(A)`——
  **完备并运算恰好是 P-代数**。24 章的完备格线在这里得到
  单子论解释；
- **伴随生成的单子**：F ⊣ G ⟹ T := GF、η 是单位、
  μ := GεF——每个 G(B) 天生是 T-代数（h := G(ε_B)），
  这给了比较函子的原型（下一段）。

## 21.2 比较函子与可模性（贺伟 3.5.6/3.5.7）

给定伴随 (F ⊣ G)：**比较函子** K : B → A^T 把 B 的对象送到
它的「免费 T-代数」`(G(B), G(ε_B))`。K 唯一满足
`G^T∘K = G`、`K∘F = F^T`（F^T : A → A^T 是自由代数函子）
——唯一性证明是「两个候选满足同一组方程」的老招式（贺伟
3.5.6 走了一遍，包括用 K(ε_B) 的代数态射性逼出 h = G(ε_B)）。

**可模**(monadic)：K 是**同构**时称 G 可模——「B 整个就是
T-代数范畴」。贺伟的三个判例（3.5.7/3.5.8/3.5.9）一正一反
一面镜子：

| 函子 | 可模？ | 原因 |
|---|---|---|
| SmGp → Set（半群遗忘） | ✓ | 比较函子把半群 S 送到 (S, 乘积映射)；反向把代数 h : T(X)→X 的 X 变成半群（h 就是乘法）——**逐点互逆** |
| 反射子范畴的包含 D ↪ C | ✓ | （3.6.5 会用 Beck 定理重证） |
| Top → Set（拓扑遗忘） | ✗ | 伴随的离散化 D 的模是 T = (1, 1, 1)（平凡），A^T ≅ Set，K : Top → Set 不是同构 |

「可模」的口号：**遗忘函子忘掉的东西恰好被代数律补齐**——
半群的乘法可从 List 结构恢复，拓扑却恢复不出来（同一条
集合数据配多种拓扑）。

## 21.3 Beck 单子性定理（贺伟 3.6）

什么时候 G 可模？Beck 定理把答案压缩到**余等化子**上。两个
铺垫概念：

- **绝对余等化子**：被**任何函子**保持的余等化子——h : B → C
  是 f,g 的绝对余等化子 ⟺ 存在 s, t 使 `hs = 1_C`、
  `ft = 1_B`、`gt = sh`（分裂三件套）；
- **G 创造/保持并反射余等化子**：G 把 G-像中的等值对送回
  唯一的余等化子。

**定理 3.6.4**（粗版 Beck）：G 可模 ⟺ B 有且 G 保持那些
「G-像分裂的」平行对的余等化子。**证明的三段剧**（贺伟给的
完整版）：

1. **(1)⟹(2)**：A^T 里每个代数 h 的平行对 T(h), μ_A 有分裂
   三件套（t := η_A 等）——绝对余等化子白送，G 保持它因为
   绝对；
2. **(2)⟹(3)**：分裂 ⟹ 绝对（单向包含）；
3. **(3)⟹(1)**：核心构造——把每个 T-代数 (A, h) 实现为 B 中
   某对象 L(A,h) 上的**自由代数 + 取余等化子**，比较函子的
   逆 L 用「h 是平行对的分裂余等化子」造出，`LK = 1`、
   `KL = 1` 分别用泛性质与 3.1.7 的单位万有性。

**旗舰应用**（贺伟例 3.6.6）：**HComp → Set 可模**！伴随的
左伴随是 Stone-Čech 紧化 β；验证 Beck 条件的叙事是纯点集
拓扑：紧空间上的商 = 闭等价关系 = 紧 Hausdorff 商——**拓扑
定理保证范畴条件**。练习 3.6.3 的对偶小品：幂集函子 P(f)
可模 ⟺ f 满射——「满射 = 商信息的完整传递」又一证。

机器化迈出第一步（ex21 新增，零公理）：**分裂余等值子的泛性质
是方程游戏**——分裂数据四条（s;h = 1_C、t;f = 1_B、t;g = h;s、
外加 f;h = g;h；最后一条不由三件套推出：A 比 B 大时 g 在 t 的
像外可自由取值，须按定义给出），则任何 k 满足 f;k = g;k 时
中介 m := s;k **存在且唯一**：

```coq
Lemma split_coeq_mediate : forall (C : Category) (a b c d : Obj C)
  (f g : Hom C a b) (h : Hom C b c) (s : Hom C c b) (t : Hom C b a),
  comp C s h = idn C c -> comp C t f = idn C b ->
  comp C t g = comp C h s -> comp C f h = comp C g h ->
  forall (k : Hom C b d), comp C f k = comp C g k ->
  { m : Hom C c d | k = comp C h m /      forall m', k = comp C h m' -> m' = m }.
```

存在性的七步连环 `k = 1;k = (t;f);k = t;(f;k) = t;(g;k) =
(t;g);k = (h;s);k = h;(s;k)` 只用四条方程与三条定律——**任何
函子作用上去仍然是证明**，这就是「绝对」的机器版。注意证明
里 `symmetry` 后只在左侧重写：直接 `rewrite <- (idL C k)` 会把
右侧的 k 一并替换、连环雪崩（ex21 坑位有记录）。

「绝对性」的机器版：证明只用到三条方程与范畴定律——任何
函子作用上去仍然是证明（函子保复合与恒等）。Beck 定理的
完整机器化（代数范畴的组装）与 06 章 record 相等的边界同源。

## 坑位速记
1. 「对象层单子」写不下 η·Tη（T 要作用在态射上）——Set 级单子显式携带 Tmap 最省基础设施。
2. concat 的 A 是显式参数：map concat 里要 `concat (A:=A)` 钉实例——joinAssoc 的辅助引理先立再用。
3. join (ret x) = x 的单元素情形要 app_nil_r 收尾（++ nil 不定义折叠）。
4. （新增）split_coeq_mediate 的存在性分支：先 symmetry 翻转
   目标、只在左侧重写——rewrite 对 k 这种变量会全局替换，
   右侧副本跟着连环变形后 reflexivity 永远对不上。
5. （新增）分裂三件套推不出 h 等值化 f,g——A 比 t 的像大时
   g 在像外自由，机器里必须把 f;h = g;h 列为假设（贺伟 3.6.1
   的定义本就包含它；漏写会「证明」出假命题）。
