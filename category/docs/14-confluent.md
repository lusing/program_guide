# 14 合流余极限：把结构搬上块

> 对书：Simmons 4.7（Confluent colimits in Set）+ 4.5.1 的
> 二进有理数尾声 /《高级范畴论》3.5 的余极限练习 / 贺伟 2.3。
> 代码：`examples/14_confluent/`（ex14_confluent.v，Coq）。

## 14.1 合流模板：为什么「有公共后继」是甜点区

13 章的极限有万能公式（等值化子 ∩ 乘积），余极限没有——
商掉什么、怎么商，形状说了算。但有一类形状好得惊人：模板
I 是**合流**（confluent）的定向预序——任何两个节点 i、j 都
有公共后继 k（i ≤ k 且 j ≤ k）。链条 0 ≤ 1 ≤ 2 ≤ …、菱形
格、以及 11.4 的 ℤ 塔都合流。

合流模板上，**对象的定向并**有显式描述：

```text
∐ A 的元素写成 [x, i]（x ∈ A(i)，i 记来历）
[x, i] = [y, j]  ⟺  某个公共后继 k 上  x|k = y|j
```

其中 `x|k` 是 x 沿模板边的连接函数走到 A(k) 的像。11.4 的
二进有理数正是这个描述的 ℤ-塔版：`2⁻ᵐx = 2⁻ⁿy` 就是「在
公共的更精细层上相等」，（★）就是合流性给的良定义性。

**为什么合流关键**：非合流模板（比如平行对 f, g : A ⇉ B）的
余极限是余等化子——要把 f(x) 与 g(x) **强制等同**，等同的
传递闭包会雪崩（Church-Rosser 问题）。合流模板只做「被动
认同」（后来在公共后继处本来就该相等的才认同），商关系自动
等价、无需闭包。**推导方向的箭头都朝一处走，冲突无处发生**。

## 14.2 第一道搬运：R-集的余极限（Simmons 4.7.1）

给定合流模板上的 R-集图（连接函数都是 R-态射），块集 L =
∐A/∼ 上要长出 R-作用。**唯一合理的定义**是按来历分量作用：

```text
[x, i] · r  :=  [x·r, i]
```

**良定义性**是全部工作：设 [x, i] = [y, j]，即公共后继 k 上
`x|k = y|j`。要证 [x·r, i] = [y·r, j]，即 `(x·r)|k = (y·r)|j`。
但连接函数是 R-态射：`(x|k)·r = (x·r)|k`，于是

```text
(x·r)|k = (x|k)·r = (y|j)·r = (y·r)|j
```

三步都是「先限制后作用 = 先作用后限制」——**交换方块追一追**。
作用公理 `[x·r]·s = [x·(rs)`、`[x·1] = [x]` 逐块验证；每个
连接函数 `x ↦ [x, i]` 自动是 R-态射（定义即如此）。

**万有性**：任何余锥 (M, β(i)) 掉到 Set 里有唯一中介
`μ([x,i]) = β(i)(x)`；要证的只有 μ 保作用——
`μ([x,i]·r) = μ([x·r,i]) = β(i)(x·r) = β(i)(x)·r`——第三步
恰是「β(i) 是 R-态射」。**掉到 Set 算、再把结构抬回去**，
13 章配方表的对偶版本。

## 14.3 第二道搬运：幺半群（Simmons 4.7.2）

块集 L 上要定义乘法，麻烦在于 [x, i] 与 [y, j] 来自**不同**
节点——乘积该在哪个节点算？合流性给答案：取公共后继 k，
**先都送到 k 再乘**：

```text
[x, i] · [y, j]  :=  [ (x|k · y|k), k ]
```

良定义性的证明是个小迷宫（书里 4.7.2 走了整整两页）：换
代表元 (x₁,i₁) ~ (x₂,i₂)、换后继 k₁ → k₂ 都要核对，落点是
「取 l ≥ i,j,k₁,k₂ 的公共后继，两边都坍到 (x|l · y|l)」。
结合律同理——三个块取公共后继的两种次序坍到同一处。恒等元
不存在（除非模板有最小元）——所以一般得到的是**半群**；
有最小元的模板（比如塔）得到幺半群。连接函数是幺半群同态
`[xy, i] = [x,i]·[y,i]`——同节点时取 k := i 直接成立。

## 14.4 机器版：两源一格的最小合流模板

三节点的 V 形模板 `0 → 2 ← 1`（两条边都指向公共后继 2）是
最小的非平凡合流模板。机器化（Coq）取 bool 上的具体图：
`h₀, h₁ : bool → bool`，块的商关系 `x ~ y ⟺ h₀ x = h₁ y`。
用「范式编码」绕开商集基建：每个块有到 A(2) 的典范代表
`x ↦ h₀ x`，于是**块集 = A(2) 的像**，作用从 A(2) 继承——
前提是像对作用封闭（`h₀ x · r = h₀ (x·r)` 落回像内，恰是
h₀ 保作用的复读）。代码骨架：

```coq
(* 块 = A2 的像：[x,0] ↦ h0 x，[y,1] ↦ h1 y *)
Definition Block (z : bool) : Prop := h0 z = z \/ h1 z = z.

(* 作用搬上块：像封闭 = h0/h1 保作用的直接推论 *)
Lemma block_act_closed : forall x r, h0 x = z -> h0 (act x r) = act z.
```

全套在 bool 上穷尽验证（destruct 全枚举）——**良定义性在
具体图上是可判定的**，这正是合流余极限适合入门机器化的原因：
非合流模板的传递闭包在 bool 上也会爆（f ≠ g 时余等化子把
两点粘成一点，商关系不再「逐点可检」）。

## 14.5 这套技术去哪了

- **滤余极限**（filtered colimits）：合流模板的无穷推广，
  是「有限信息拼无穷对象」的标准工具——代数闭包、局部化、
  形式幂级数环、stalk（茎）全是滤余极限；
- **预层与层**：28 章的层化 = 「先做预层（自由装修）再沿覆盖
  商掉」——商关系正是合流式的「在更细覆盖上相等」；
- **幺半群情形**的「先送到公共后继再乘」是**滤余极限与有限
  极限交换**（filtered colimits commute with finite limits in
  Set）的最小体现——同调代数里正合性判据的支柱之一。

## 坑位速记

1. 良定义性的证明骨架永远是「限制与作用交换」——把它写成
   引理复用，别在每处重推。
2. 范式编码（块 ↦ 公共后继处的像）绕开商集基建，但**前提
   是像对结构封闭**——这一步省不得，否则后续引理全部悬空。
3. bool 上穷尽验证是「具体图上的判定性」红利；换无穷载体
   （ℕ、ℤ）时穷尽失效，回到抽象良定义性证明。
4. 幺半群乘法的 k 选取**不唯一**——良定义性证明必须覆盖
   「换后继」的相容性（书的 4.7.2 两页就在干这个）；机器化
   时选 l ≥ 一切相关节点的公共后继一步到位。
