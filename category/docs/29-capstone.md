# 29 压轴：把书串起来

> 复习章：一条线走完全书。

**泛性质是主角**：积（10）→ 拉回（11）→ 极限（12）→ 覆盖的
极限形状（27）是同一件事的四次登场；
**唯一性当武器**：10 的积同构、11 的拉回保 mono、12 的 hom
配对唯一、16 的自由折叠唯一——「取样两次喂同一唯一性」
贯穿全书；
**Yoneda 是引擎**：08 的往返 ⟹ 14 的可表函子连续 ⟹ 17 的
RAPL（文档）⟹ 27 的层化保极限；
**对偶是免费午餐**：02 的 opposite 造出余积（10）、推出（11）、
余极限（12）、合流块的对称收益（13）；
**伴随是纲领**：15 三面孔 → 16 自由-遗忘 → 18-20 CS 线 →
23 保 sup ⟺ 有右伴随 → 24 ∃ ⊣ I ⊣ ∀ → 25 Σ ⊣ U ⊣ Π →
26 反变伴随 → 27 层化 ⊣ 嵌入——Eilenberg–Mac Lane 的
「范畴为定义函子、函子为定义自然变换、自然变换为定义伴随」
在 29 章合龙；**Simmons 补的最后一环**：伴随的「序论化身」
（23-25）让抽象的三面孔有了查表可算的模型，反变伴随（26）
把两侧世界缝起来。

**量的飞越**：24 章之前「伴随」是 record 与追图；24 章之后
多了第三副面孔——**格上查表**。16 格伴随定律、64 格量词
伴随、bool 穷尽的 Σ/Π 往返：抽象定理的「可计算切片」
是本教程 Simmons 线的独特收成。

**压轴一图**（文字版）：

```text
   Set ──Σ──▶ Set-R ──Π──▶ Set        （25：三明治）
    │  ◀──U──┘  ◀──U──┘
    ▼ （26 反变）
   Pos ⇄ Top；OS ≅ ΞS（特征函子）
    │ （24：截面上）
   LS/US：∃ ⊣ I ⊣ ∀（量词即伴随）
    │ （23：瘦范畴里）
   保 sup ⟺ 有右伴随（Galois 连接 = 伴随的序论化身）
    ▼ （27：OS 上不打架的预层）
   Sh(S) ⊣↪ [OS^op, Set]（层化反射）—— topos 的大门
```

三文化的分水岭汇总（07/09 章）：依赖字段的 record 相等——
Coq（分量级止步）、Agda（setoid）、Lean（结构 η + 内核 PI）
——这是任何 2-范畴形式化都要面对的第一道门；Simmons 线
新增的分水岭是**可判定性**：有限格/有限预序上的伴随、
量词、作用全部查表（24-26 章），无限现场回到文档层——
「机器查表 + 文档讲理」的双轨制是全书方法论的最终形态。
