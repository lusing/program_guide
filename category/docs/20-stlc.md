# 20 函数式语言、演绎系统与 λ 演算的范畴

> 对书：《高级范畴论》第 6 章（计算机科学中的范畴）6.1–6.3。
> 本章为文档章（机器线：19 章 ex19_ccc + typetheory 教程 13 章）。

## 20.1 函数式语言范畴 FL（6.1）：范畴公理 = 程序等价

《高级范畴论》第 6 章的开场白值得引用：**计算机科学家对
范畴论的浓厚兴趣，多半是由于函数式程序设计语言的程序
设计很像是一个范畴**。6.1 把这句话落成构造。取纯函数式
语言（无变量、无赋值），做三步「无害修改」：

1. **常量归约为运算**：添一个单位类型 I，把常量 c : A 改写
   成 c : I → A——从此「数据」与「程序」同层；
2. **空程序**：每类型 A 有恒等运算 1_A : A → A；
3. **串行执行**：f : A → B、g : B → C 有合成 f;g : A → C
   （程序的顺序连接）。

于是 **FL 范畴**：

```text
对象 = 类型          态射 = 运算（类型间的函数）
复合 = 「；」串行    恒等 = 空运算
```

三条范畴律逐条变成**程序等价的公理**：

```text
1_A; f = f = f; 1_B        （空程序不做事——idL/idR）
(f;g);h = f;(g;h)          （顺序结合无所谓怎么括——assoc）
```

反过来读更有味：**范畴论就是「程序代数」的公理化**——
把任何函数式语言交给这个构造，得到的范畴的万有性质
（积、指数、终对象……）逐条检查，就是给语言做「类型系统
体检」。19 章的 CCC 是体检表；FL 是被检者。

## 20.2 演绎系统范畴 FDS（6.2）：证明的组合代数

形式演绎系统（FDS）= 公式 + 推演规则。6.2 的构造与 FL 平行：

```text
对象 = 公式                 态射 = 证明（从单公式出发的推导 f : A → B）
复合 = 并置（f;g = 先证 f 再接 g）    恒等 = 平凡证明 1_A : A → A
```

范畴律的证明论读法：**idL/idR = 平凡证明不增加内容、
assoc = 推导的分段方式无关紧要**。这恰是**切割消除**
(cut elimination) 的范畴影子——Gentzen 的主定理说每个
带切割的证明都能改写成无切割的；范畴语言说：复合虽然
是「新造」的态射，但它的范数（证明长度/正则性）可控。

FDS 范畴的意义：**逻辑不是「关于范畴的」，逻辑本身就是
范畴**——公式与证明遵守与类型与程序完全相同的组合法则。
这就是 Curry–Howard 对应（命题 = 类型、证明 = 程序）的
范畴论地基，而 λ 演算是这条线上的「通用语」。

## 20.3 带类型 λ 演算：把两侧缝起来（6.3）

19 章 19.2-19.3 已把 ΛT 的规则（R1-R18）与语法范畴
(ΛT) 完整展开。这里补三块拼图——**三方对应的完整表**：

| 函数式语言 FL | 演绎系统 FDS | 带类型 λ 演算 ΛT | 范畴 (ΛT) |
|---|---|---|---|
| 类型 | 公式 | 类型 | 对象 |
| 运算 f : A → B | 证明 f : A ⊢ B | 项 ⟨x,φ⟩ | 态射 |
| 串行 ； | 并置 ； | 代换 | 复合 |
| 空程序 | 平凡证明 | 变元 x | 恒等 |
| 积类型 | 合取 ∧ | A×B 与 ⟨,⟩、π | 积 |
| 函数类型 | 蕴含 ⇒ | B^A 与 λ、ε | 指数 |
| 单位类型 I | 真命题 ⊤ | 基类型 Π | 终对象 |
| β 规约 | 切割消除 | R16 | eval 律 |
| η 外延 | 外延等价 | R17 | curry 唯一性 |

**一行总结**：程序、证明、λ 项是**同一件事（态射）的三种
记法**；FL/FDS/ΛT 三个范畴构造是同一台机器的三个进料口。
《高级范畴论》把 CS 三个领域用范畴论焊成一体——这正是
19 章「三位一体」的操作层。

## 20.4 语义指派：从语法范畴到语义范畴

有了语法范畴 (ΛT)，语义 = **函子** ⟦−⟧ : (ΛT) → C（C 是
某个 CCC，典型地 Set 或其化身）：类型/项按解释表逐条送走，
等式规则 R14-R18 恰好保证 ⟦−⟧ 良定义（商掉的等式在语义里
也相等）。这条路线的全机器化（STLC 的语法、代入引理、
可靠性/完备性）在 typetheory 教程 13 章走通；本书记录
骨架——**语义 = 保结构的翻译**，而「保结构」的检查表
就是 CCC 公理逐条。

## 20.5 去向

- **程序逻辑**：FDS 范畴 + 21 章单子 = 计算效应的模型
  （state、exception、IO 单子——函数式语言的「不纯」成分
  全部经单子装回纯范畴）；
- **类型论**：依赖类型（ΛT 加「类型依赖项」）→ locally
  cartesian closed 范畴——typetheory 教程的主线；
- **拓扑斯**：28 章——CCC + 子对象分类器；直觉主义高阶
  逻辑 = 拓扑斯内部语言。λ 演算这条线最终通向「逻辑的
  几何化身」。

## 坑位速记

1. FL 的「无害修改」第 1 步（添 I 类型）不可省——常量
   不归约成运算，空对象上的态射就没有着落，范畴凑不齐。
2. FDS 的态射是**从单公式出发**的证明——多前提推导要先
   用积打包成单前提（这正是「上下文 = 积」的来源）。
3. 三方对应表里「恒等」一行最容易被忽略：空程序/平凡证明/
   变元是同一概念，漏掉它 idL 无从解释。
4. 语义指派 ⟦−⟧ 必须落在 **CCC** 里——只保证积不保证指数
   的范畴装不下 λ 抽象（curry 无处可去）。
