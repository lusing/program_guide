## 23.1 准加法范畴：Hom 上的算术

Abel 群范畴 AbGp 有个别的范畴没有的天赋：**两个同态可以相加**
`(f+g)(x) = f(x) + g(x)`，而且复合对加法**双线性**。把这个
天赋公理化：

**定义（准加法范畴，贺伟 4.1.1）**：每个 Hom 集 C(A,B) 自带
Abel 群结构（加法 + 零态射 0），复合满足**四项双线性律**：

```text
(g + g′)(f + f′) = gf + gf′ + g′f + g′f′
```

（展开 = 左分配 + 右分配 + 零吸收三条合一。）样本：AbGp、
Mod_R；**单对象准加法范畴 = 环**（Hom = 环元素、复合 = 乘法、
加法 = 环加法——双线性恰是环的分配律）。反过来，任何环 R 给出
单对象准加法范畴——**环论被收编为范畴论的一隅**。

零态射由加法白送，且「任意对象间有唯一的零态射」与恒等兼容
（0f = f0 = 0——双线性的推论）。注意贺伟的记号约定：全书把
不同对象间的零态射都写 0，靠定义域/值域区分。

## 23.2 核与余核：等值子的算术化

预加法范畴里，等值子塌缩成**一半**：

**定义（4.1.3）**：f : A → B 的**核** ker(f) := 等值子(f, 0)；
**余核** coker(f) := 余等值子(f, 0)。

显式判据：k : K → A 是核 ⟺ fk = 0 且任何 fk′ = 0 的 k′ 唯一
穿过 k。「f 零化谁」成了一个万有性质。

**引理（4.1.4）**：h 是某个态射的核 ⟺ h 是某平行对的等值子。
方向 (⟸)：h 等值化 f, g ⟹ h 等值化 (f−g, 0) = ker(f−g)——
**减法让等值子只剩一条腿**。于是在准加法范畴里谈极限只需
核、谈余极限只需余核（11 章的两件工具合并成一件）。这正是
Abel 范畴「一切算术化」的第一次兑现。

**引理（4.1.5，零对象四等价）**：A 始对象 ⟺ A 终对象 ⟺
`1_A = 0 : A → A` ⟺ Hom(A,A) 平凡群。证明两行：始 ⟹ Hom(A,A)
单点 ⟹ 1 = 0；1 = 0 ⟹ 任何 f = 1f = 0f = 0（Hom(A,B) 只含
零）⟹ A 始。准加法范畴的零对象**始=终**（03 章的一般零对象
在这里获得算术身份）。

## 23.3 双积：积与余积的合体（引理 4.1.6）

Abel 世界的奇观：**积和余积是同一个对象**。

**引理（4.1.6）**：设 p1 : C → A、p2 : C → B、q1 : A → C、
q2 : B → C 满足**四条分块等式 + 一条合成等式**：

```text
p1q1 = 1A    p2q2 = 1B    p1q2 = 0    p2q1 = 0    q1p1 + q2p2 = 1C
```

则 (C, p1, p2) 是 A 与 B 的**积**（中介 h = q1f + q2g），
对偶地 (C, q1, q2) 是**余积**。这样的 C 叫 **双积** A ⊕ B。

机器版（ex23_abelian 的旗舰，零公理）——中介公式的两条投影
方程逐行是双线性的操演：

```coq
Lemma biproduct_is_product : forall (P : Preadd) (a b c : Obj P)
  (p1 : Hom P c a) (p2 : Hom P c b) (q1 : Hom P a c) (q2 : Hom P b c),
  (* 四条分块 + 一条合成，略 *)
  forall (x : Obj P) (f : Hom P x a) (g : Hom P x b),
  { h : Hom P x c | comp P h p1 = f /\ comp P h p2 = g /\
      forall h', comp P h' p1 = f -> comp P h' p2 = g -> h' = h }.
```

唯一性也是算术：`h′ = 1h′ = (q1p1 + q2p2)h′ = q1f + q2g = h`。
**对角/余对角公式（4.1.8）**：f + f′ 有纯粹的积表达
`f + f′ = c∘(f ⊕ f′)∘d`（d 对角、c 余对角）——**加法本身由
双积重建**，「Hom 的算术」与「对象的直和」互相翻译。

## 23.4 矩阵演算：双积之间的态射 = 矩阵（贺伟 4.1 的华彩）

双积的工业级红利：态射 f : ⊕ᵢAᵢ → ⊕ⱼBⱼ 由**分量矩阵**
`fᵢⱼ = pⱼ f qᵢ` 完全确定，且**复合就是矩阵乘法**：

```text
(gf)ᵢₖ = Σⱼ gⱼₖ fᵢⱼ        （求和 = 加法、乘法 = 复合）
```

验证只需把 1 = Σ qᵢpᵢ 塞进复合中间拆开（贺伟 4.1 的原话：
「双积之间的态射的复合就是通常的矩阵乘积」）。线性代数里
「矩阵 = 线性映射」的范畴论解释：**线性代数 = 双积上的加法
范畴论**。单对象情形退化成环的乘法——23.1 的机器件
（nat 半环版）验证了这一层。

## 23.5 加法范畴、加法函子与 Abel 范畴

**加法范畴**（4.1.7）：准加法 + 有限双积 + 零对象。清点：
AbGp、Mod_R、双积逐点的函子范畴 [C, D]（例 4.2.3——预层
世界的加法结构逐对象装配）。

**加法函子**（4.1.9）：T(f+g) = T(f) + T(g)。注意 T(0) = 0
自动成立（T(0) = T(0+0) = T(0)+T(0)，两边消去）。**命题
4.1.10**：T 加法 ⟺ T 保持双积——证明是把 4.1.6 的五条等式
逐条搬过去：**「保结构」的检验在双积语言里是有限的**。
态射函子 C(A,−)、C(−,B) 都加法（练习 4.1.3——逐点加法定义）。

**Abel 范畴**（4.2.1）：加法范畴 + 有限完备/余完备 + **每个
单态射是某个态射的核、每个满态射是某个态射的余核**。最后
两条是「像分解」的保证：f = im(f)∘coim(f) 且 coim 单、im 满、
二者典范同构（Abel 性把一般范畴里可能失败的「商 = 子对象」
焊死）。样本：AbGp、Mod_R、[C, D]（D Abel）、层范畴
Sh(X, Ab)（28 章——层论的代数化靠这一步）。

## 23.6 正合序列与左/右正合函子（4.3）

**正合**：序列 …→Aₙ₊₁→Aₙ→Aₙ₋₁→… 在 Aₙ 处正合 ⟺
`im(fₙ₊₁) = ker(fₙ)`。只保证 fₙfₙ₊₁ = 0 的叫**连通序列**
（正合 ⟹ 连通，反之不然——AbGp 里随手可造）。两个短型：

```text
0 → A → B → C      正合 ⟺ f = ker(g)      （左短型 (*)）
A → B → C → 0      正合 ⟺ g = coker(f)    （右短型 (**))
```

**正合函子**（4.3.2）：加法函子 T 保持正合序列。分档：

- **左正合**：保持 (*) 型 ⟺ T 保核 ⟺ T 保有限极限；
- **右正合**：保持 (**) 型 ⟺ T 保余核 ⟺ T 保有限余极限；
- **命题 4.3.3**：T 正合 ⟺ 保 0→A→B→C→0 型 ⟺ 保核与余核 ⟺
  保有限极限与余极限 ⟺ 既左正合又右正合——五条等价把
  「正合」钉在极限论的坐标系上（15 章 RAPL 的算术版）。

经典判例：Hom(A,−) **左**正合（保核不保余核）、−⊗A **右**
正合——**两者恰是伴随对**（张量 ⊣ Hom，17 章）。「伴随的
一端正合、另一端欠一点」是同调代数全部麻烦的来源——**导出
函子**就是给欠的一端「补左/右导数」：Ext = R¹Hom、Tor = L₁⊗。
范畴论在此接上同调代数的主干道。

## 23.7 伪元素与蛇形引理（4.3.5–4.3.7）

Abel 范畴里可以做「元素式」推理而不真用元素——**伪元素**
(pseudo-element)：态射等价类（f ~ g 若有 epi 使…），f 的伪
元素运算满足「相等可代换」的弱形式。**命题 4.3.5**：单态射
m : A → B 的拉回是单态射 + 满态射的拉回性 ⟹ 伪元素语言里
「b ∈ B 通过 m 分解」良定义——**图表证明可以写成元素追迹**。

**蛇形引理（4.3.7）**：交换 3×3 图（行、列都正合）中存在
**连接态射** s : A₃ → D₁ 使

```text
0 → A₁ → A₂ → A₃ → D₁ → D₂ → D₃ → 0   正合
```

证明的「蛇行」：A₃ 的元素先拉回到 B₂/B₃（引理 4.3.4 的拉回
方块 P），再沿正合性滑到 C₁，压到 D₁——**追元素的每一步都
对应一个泛性质的使用**（拉回→像→核→余核）。蛇形引理是
长正合序列、导出函子的存在性、同调代数一切图表引理的母定理
——机器化需要 Abel 范畴的完整基建（核/余核/像的组装），
本书记录为边界；伪元素一节的元素式演算可在有限 Abel 范畴
（AbGp 的有限群子范畴）上查表验证。

## 坑位速记

1. 准加法的「Abel 群」在机器里先用交换幺半群近似（nat 版）：
   逆元在 Hom 层拖入 ℤ 与抽象代数基建——文档里注明升级路线。
2. 双积唯一性的消去方向：h′ = 1h′ 先展开 1 = q1p1 + q2p2，
   再分别吸掉 p1h′ = f、p2h′ = g——顺序反了会卡在 0 的
   吸收上。
3. 矩阵分量的指标序 fᵢⱼ = pⱼfqᵢ（先 q 后 p）：j 在前——
   与线性代数习惯的 aᵢⱼ 相反，抄书时注意。
4. 左/右正合的「左右」指保持**左短型/右短型**（0 在左/右端），
   不是「保左极限」——术语第一次见极易记反。
