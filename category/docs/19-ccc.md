## 19.1 定义：把「函数当对象」公理化

Set 里有三件宝：单点集 1、笛卡尔积 ×、函数集 A→B。把它们
抽象成范畴公理：

**Cartesian 闭范畴**(CCC) = 终对象 + 二元积 + **指数**。指数
b^a 是「函数对象」——由泛性质刻画：

```text
eval : b^a × a → b            （应用）
curry : Hom(c × a, b) ≅ Hom(c, b^a)    （双元变单元——自然双射）
```

机器版（Coq，TyCat 的化身）：指数 = 函数类型、curry/uncurry
是逐点互逆：

```coq
Definition curry {A B C : Set} (f : A * B -> C) : A -> (B -> C) :=
  fun a b => f (a, b).

Lemma curry_uncurry_round : forall (A B C : Set)
  (f : A * B -> C), uncurry (curry f) = f.
Proof.
  intros. apply funext. intros [a b]. reflexivity.   (* Σ-η 一步 *)
Qed.
```

往返二（`curry_uncurry_round`）要两层 funext（先函数、再点）
——「函数相等」在 CCC 里是**外延**的，这是 Set 化身的红利，
也是抽象 CCC 里必须作为公理背的东西。样本清点：Set、
Poset（Heyting 代数！a ⇒ b = 蕴含）、**ΛT**（下两节的语法
化身）、Cat 自己（函子范畴）——CCC 是「自己的函数空间」。

## 19.2 带类型 λ-演算 ΛT：语法的完整清单（高级范畴论 6.3）

《高级范畴论》6.3 把 ΛT 的公理写得极工整，值得整表收录。
**类型规则**：

```text
R1  基类型 Π 存在                    R2  A、B 是类型 ⟹ A×B、B^A 是类型
R3  * : Π（基项）                   R4  每个类型 A 有可数无穷个变元
R5  a:A, b:B ⟹ ⟨a,b⟩ : A×B         R6  c:A×B ⟹ π(c):A、π′(c):B
R7  a:A, f:B^A ⟹ ε(f,a) : B        R8  x:A, φ(x):B ⟹ λx∈A.φ(x) : B^A
```

**等式规则**（变元集 X 包含所有自由变元；a =ₓ b 读「在任何
解释下指称相同」）：

```text
R9   =ₓ 是等价关系，且对 X 加宽/函数作用稳定
R10  a:Π ⟹ a = *                       （基类型单点）
R14  π⟨a,b⟩ = a、π′⟨a,b⟩ = b           （积的投射律）
R15  ⟨πc, π′c⟩ = c                     （配对是满射——唯一性）
R16  (λx.φ)(a) = φ(a)                  （β：应用即代入）
R17  x 不自由于 f ⟹ λx.fx = f          （η：外延性）
R18  y 可代入 ⟹ λx.φ = λy.φ(y)         （α：换名）
```

三条 R14/R15 是积的万有性质；R16/R17 是指数的两条律
（β 对应 eval 方程、η 对应 curry 的唯一性）；R10 让基类型
成为终对象——**λ 演算的全部计算规则逐条对应 CCC 公理**，
这就是 Lambek 对应的语法侧。

## 19.3 ΛT 范畴：把「项」造成态射（语法范畴的绝招）

由 ΛT 造范畴 (ΛT) 的定义有个精巧处理——**态射是「变元-项」
对**：

```text
对象 = 类型
态射 A → B = ⟨x∈A, φ(x)⟩，其中 φ 除 x 外无自由变元
恒等 = ⟨x∈A, x⟩
复合 ⟨y,ψ⟩∘⟨x,φ⟩ = ⟨x, ψ(φ(x)/y)⟩     （代入即复合！）
```

两个细节决定成败：

1. **模等价商**：⟨x,φ⟩ = ⟨y,ψ⟩ 当且仅当换名后 φ =ₓ ψ——
   R18（α）保证换名不改变态射，「同型变元对应同一态射」
   靠商实现；
2. **代入引理**：复合的结合律 = 代换的结合律
   χ(ψ(φ)) = (ψ(φ))(χ)——这是 λ 演算里「代入服从代入」的
   逐字翻译（机器化的真正工作量全在这一步，见坑位）。

于是 (ΛT) 是范畴，而且**天然是 CCC**：

| CCC 结构 | ΛT 证据 |
|---|---|
| 终对象 1 | 基类型 Π（R10：一切项 = *） |
| 积 A×B | 类型构造子 ×（R5/R6/R14/R15） |
| 指数 B^A | 类型构造子 ^A（R7/R8） |
| eval 律 | R16（β） |
| curry 唯一性 | R17（η） |

**λ 演算 = CCC 的内部语言**（Lambek 定理的对偶半边）：
任何 CCC 里都可以「说」λ 演算的话——项 = 态射、βη = 定律。
19.1 的 Set 模型只是可能世界之一；ΛT 范畴是「语法的范畴」，
初始 CCC 的雏形。

## 19.4 三家化身的对照

| | Set | Poset(Heyting) | (ΛT) |
|---|---|---|---|
| 1 | 单点 | 顶 | 基类型 Π |
| A×B | 笛卡尔积 | 下确界 A∧B | 积类型 |
| B^A | 函数集 | 蕴含 A⇒B | 指数类型 |
| curry | 逐点闭包 | A∧c ≤ b ⟺ c ≤ A⇒b | λ 抽象 |
| eval | 函数应用 | modus ponens | β 规约 |

**同一套公理，三个世界**：集合论的世界、逻辑的世界、计算的
世界——Curry–Howard–Lambek 三位一体的范畴论表述。24 章的
Heyting 结构（∀ 是右伴随）在这里得到第三重身份：**直觉主义
逻辑的蕴含 = 指数**。

## 坑位速记

1. uncurry_round 要两层 funext（c 再 a）——一层留给函数相等
   一层留给参数。
2. curry 的类型要 @ 钉住（Set Implicit Arguments 隐化）。
3. ΛT 范畴的态射「变元-项对」必须模 α 商——不商的话
   λx.x 与 λy.y 是两个恒等，idL 直接失败。
4. 复合 = 代入的方向：⟨x,φ⟩ 然后 ⟨y,ψ⟩ 是 ⟨x, ψ(φ(x))⟩
   ——先代入内层再代入外层，方向反了会造出非结合的「复合」。
5. R17（η）不是计算规则而是**外延性公理**——语义侧它白送
   （函数相等外延），语法侧它必须列为公理。
