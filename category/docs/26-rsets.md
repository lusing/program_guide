# 26 幺半集：Σ ⊣ U ⊣ Π

> 对书：Simmons 6.7–6.11（R-sets 与两个伴随）/《高级范畴论》
> 5.4（自由与余自由）/ 贺伟 3.3（伴随实例）。
> 代码：`examples/26_rsets/`（ex26_rsets.v / .lean）。

## 26.1 R-集：作用即结构

固定幺半群 R。**R-集**是带右作用的集合 `(A, ·)`：每个
`r ∈ R` 给自映射 `a ↦ a·r`，满足 `(a·r)·s = a·(rs)`、
`a·1 = a`（Simmons 1.2.8 的 Set-R；协变版 R-Set 的箭头方向
相反）。**态射** f 保作用：`f(a·r) = f(a)·r`。三个直接样本
（6.7.1）：R = {±1} 给「带对合的集合」；R = {1,0}（乘法）
给「带部分指定元素的集合」；R = {±1,±i} 给「带两个可交换
对合的集合」——**幺半群的选择 = 结构种类的选择**，这是
「结构集配方」（01 章）的参数化终极版。

R-集的极限逐点算（13 章配方表：`(a·r)(i) = a(i)·r`）；
余极限走 14 章的块法。本章的主角是另一件事：**Set ↔ Set-R
之间的一对伴随**——自由 Σ 与余自由 Π。

## 26.2 自由 R-集：ΣX = X × R（Simmons 6.8–6.9）

任何集合 X 造 R-集：

```text
ΣX := X × R        (x, r)·s := (x, rs)
```

（6.8.1 的结合律是 R 自身结合律的复读。）单位
`η(x) := (x, 1)`。**万有性**（6.8.4）：任何函数
`g : X → A`（A 是 R-集）沿 η 唯一扩张成态射：

```text
g♯(x, r) := g(x)·r          （6.8.4：先吃 x 再作用 r）
```

唯一性一行看穿：`(x, r) = (x, 1)·r = η(x)·r`，故
`f(x,r) = f(η(x)·r) = f(η(x))·r`——**任何态射被它在 η 上的
值完全决定**（6.8.3）。存在性：g♯ 保作用
`(g♯((x,r))·s) = g♯(x, rs) = g(x)·rs = (g(x)·r)·s` ✓。
17 章「自由 = 折叠即求值」的伴随版。

**上伴随**（6.9）：Σ ⊣ U（U 是遗忘函子）。三角恒等式
（6.9.1）两侧算一遍：
`ε_ΣX(Σ(η)(x,r)) = ε(η x, r) = (η x)·r = (x,1)·r = (x,r)` ✓
`U(ε_A)(η_A(a)) = ε_A(a,1) = a·1 = a` ✓
——单位余单位严丝合缝，全程只用了「作用律 + 定义」。

## 26.3 余自由 R-集：ΠX = R → X（Simmons 6.10–6.11）

对偶端更妙：**函数集** R → X 配「预复合作用」：

```text
ΠX := (R → X)        (h·r)(s) := h(rs)
```

（6.10.1：`((h·r)·s)(t) = h(rs·t)?? = h(r(st))`——结合律
的又一次复读，注意方向：h·r 把 h 的输入预乘 r。）余单位
`ε(h) := h(1)`（「取 1 处的值」）。**余万有性**（6.10.5/
6.10.8）：任何态射 `f : A → ΠX` 唯一分解 `f = Π(g)∘η`，
其中 `g := ε∘f`：

```text
g(a) := f(a)(1)      （g♭ 的取值）
η(a)(r) := a·r 的常值化…… 准确说 η_A(a)(r) := a·r
```

组合的往返：`Π(g♭)(a)(r) = g♭(a·r) = f(a·r)(1) =
(f(a)·r)(1) = f(a)(r·1) = f(a)(r)` ✓——三步分别是 g♭ 定义、
f 保作用、作用律。**Π 是「把 X 装进所有可能的历史里」**：
R-集同态 A → ΠX 等价于「A 的每个元素配一条 R-索引的 X 值
轨迹，且轨迹与作用相容」——指数对象（19 章 CCC）在作用
世界的化身。

**下伴随**（6.11）：U ⊣ Π。R-集范畴**笛卡尔闭**了吗？
Σ ⊣ U ⊣ Π 的存在说明 Set-R 有足够的左/右伴随资源；实际上
Set-R 就是 Set 上的「R-作用层」——拓扑斯的/proto-指数结构
一应俱全（28 章回望）。

## 26.4 机器版：R = (bool, ∧) 上的往返双程

取 R := bool 配合取（∧，单位 true）——最小的非平凡幺半群。
机器化（Coq/Lean）验证书里全部往返公式：

```coq
(* ΣX = X × bool；(x,r)·s = (x, r ∧ s) *)
(* g♯(x,r) := g x ∧ r   ——任何函数的扩张 *)
(* g♯♭ = g :  g♯♭(x) = g♯(x, true) = g x ∧ true = g x *)
(* f♭♯ = f :  f♭♯(x,r) = f♭(x) ∧ r = f(x,true) ∧ r
                            = f((x,true)·r)   （f 保作用）
                            = f(x, true ∧ r) = f(x,r) *)
```

两条往返的证明分别用了「true 是 ∧ 的单位」（定义性）与
「f 保作用」（一次同态律）——**右往返比左往返多一条假设**，
这正是 16 章换位演算的实例级预演。三角恒等式两条（25.2 的
算式）也全部 bool 穷尽。零公理。

## 26.5 幺半群换装与去向（Simmons 3.3.14/3.3.15）

幺半群态射 `φ : S → R` 把任何 R-集「拉回」成 S-集
（`a ⋆ s := a·φ(s)`）——`Mon` 到「范畴族」的作用（05 章
5.6 的换装函子）。极限/余极限、Σ/Π 全部沿 φ 换装——
**表示的灵活性是结构集范式的红利**。

去向：Set-R 是「一个对象上的预层」——把单点范畴换成
任意小范畴 C，`Set^{C^op}` = 预层范畴（01 章 1.9 的 Ŝ、
28 章的正式舞台）。Σ/Π 在那里变成 **Kan 扩张**的特例；
「自由-遗忘-余自由」三明治是所有「结构层化」问题的通用
骨架（层的伴随三明治：层化 ⊣ 嵌入 ⊣ 忘却，28 章）。

## 坑位速记

1. Π 的作用是**预复合**方向：`(h·r)(s) = h(rs)`——写成
   `h(sr)` 会导致 25.3 的三步往返全部断裂（6.10.1 的老坑）。
2. Σ 的往返 `g♯♭ = g` 是定义性的（true 单位），`f♭♯ = f`
   要用一次保作用——**两个方向的代价不对称**，别抄成对称。
3. ε(h) = h(1) 的「1」是幺元——R = (bool,∧) 时是 true；
   换 R 时别惯性写 0（加法幺元的串台）。
4. bool 穷尽验证时注意 ∧ 的短路与 Coq implb 的方向——
   定义即查表的风格下，方向错误 = 全红，幸运的可判定错误。
