# 28 层与拓扑斯：从范畴到层的终点站

> 对书：贺伟第 5 章 / Simmons 1.4（预层一瞥）+ 3.3.2 + 5.6
> （Ξ/Υ 反变伴随——27 章已展开）/《高级范畴论》第 6 章。
> 本章为文档章（机器化边界见 27.6）。

## 28.1 预层：把「逐点装配」正式化

02 章 1.9 节埋的线到这里收网：**预层**是反变函子
`F : C^op → Set`。三个化身已经在手：

- **结构族**：预序 S 上的预层 = 相容的集合族 `A(i)` + 连接
  函数（Simmons 1.4 的 Ŝ）——链复形是「m+2 ≤ n 时为零」的
  特款（ℤ 当索引）；
- **图与交换图**：C := Pth(∇)（13 章模板的路径范畴），预层
  = 反变的 ∇-图——《高级范畴论》的图自然变换正是预层态射；
- **R-集**：C := 单点范畴配 R 的_deluxe 版本——26 章 Σ⊣U⊣Π
  是「单点预层」的自由/余自由对。

**预层范畴 [C^op, Set]** 逐点继承 Set 的一切极限（13 章配方），
并且**笛卡尔闭**（指数逐点 NF(X)(c) := [yc, X]，其中 y 是
Yoneda 嵌入的记号滥用——准确说是 F(c)-簇的相容族）。
**问题**：预层允许「局部打架」——不同节点上的选取互相矛盾。
层就是**不许打架**的预层。

## 28.2 层条件：分离 + 粘合

取定「场地」——最直观的版本：拓扑空间 S，预层 F : OS^op → Set
（27 章：OS ≅ ΞS，开集包含为序——**OS 是完备格**，25 章的
截面演算整个适用）。F 是**层**当且仅当对每个开覆盖
`U = ⋃ Uᵢ`：

1. **分离性（separated）**：s, t ∈ F(U) 在每个 F(Uᵢ) 上相等
   ⟹ s = t——「局部相等则整体相等」；
2. **粘合性（glueing）**：每族相容的 `sᵢ ∈ F(Uᵢ)`（在交上
   一致：`sᵢ|_{Uᵢ∩Uⱼ} = sⱼ|_{Uᵢ∩Uⱼ}`）粘成唯一的
   `s ∈ F(U)`——「局部解拼成整体解」。

两个标准样本：**连续函数层** C(−)（粘连续函数 = 粘合引理，
 undergrad 拓扑的 patching）；**有界函数预层**（分离但不粘合：
   |x| < 1 局部可解、整体无解）——反例的存在正是层条件的
   存在理由。

**范畴论的统一表述**：把覆盖做成图表（Uᵢ 与 Uᵢ∩Uⱼ 摆成
一个形状），F 是层 ⟺ 对每个覆盖，F 把该形状的极限送去
**等值化对**的核：

```text
F(U) → ∏ᵢ F(Uᵢ) ⇉ ∏ᵢⱼ F(Uᵢ∩Uⱼ)        （层的等化子正合列）
```

**层 = 把覆盖的极限变成等值的预层**——13 章的极限语言 +
12 章的等化子在此合流。

## 28.3 étale 空间：层的几何身体

每个层 F 配一个空间——**étale 空间** Et(F)：底是 S，纤维
`F_x = colim_{x ∈ U} F(U)`（沿 x 的开邻域滤方向的**茎/stalk**，
14 章合流余极限的正式应用！），拓扑由「截面的图像」生成。
定理（贺伟 5.2）：**层 ↔ étale 空间**（局部同胚 π : E → S）
是范畴**等价**（08 章的定义在真正的数学里第一次满血）。

- 层 → étale：取茎、贴截面拓扑；
- étale → 层：取截面 Γ(U) = {连续 s : U → E | π∘s = id}；
- 往返： stalk 级别逐点还原、整体级别典范同构。

**层化**（sheafification）：任何预层 F 有「最好的层近似」
F⁺ = étale 空间的截面层——**层化 ⊣ 嵌入**（层是预层范畴的
反射子范畴，18 章的回收！）。三明治成型：

```text
层化 ⊣ 嵌入 : Sh(S) ↪ [OS^op, Set]
```

与 26 章的 Σ ⊣ U ⊣ Π 同框：**「加结构-忘结构」的左伴随 +
「取最优近似」的反射**——伴随论的两板斧在层论首次合击。

## 28.4 Grothendieck 拓扑：覆盖的公理化

把「开覆盖」从拓扑里抽出来：小范畴 C 上的 **Grothendieck
拓扑** J 给每个对象 c 指定一族**覆盖筛**(covering sieve)
J(c) ⊆ P(hom(−, c))，满足三条公理（恒等筛覆盖、筛的加细
稳定、覆盖传递）。**(C, J) = site**。层 = 对每个覆盖筛满足
等值条件的预层——**拓扑空间层论是 site 的特例**
（C := OS，覆盖筛 = 包含某个开覆盖的筛）。

为什么要抽象？三个回报：

1. **概形论**：Zariski/étale/fppf 拓扑全是 site——代数几何的
   「正确开集」不是点的邻域而是映射族；
2. **逻辑**：**拓扑斯** = 层范畴 Sh(C, J)——笛卡尔闭 + 子对象
   分类器 Ω（27 章的 Sierpiński 2 推广成「真值对象」）。拓扑斯
   内部演算是直觉主义高阶逻辑——25 章的 Heyting 结构
   （∀ 右伴随）在此升格为完整逻辑；
3. **25 章的升维**：覆盖筛的「局部相等」就是截面格上的
   ∃/∀ 演算加一条相容律——序论→层论的每一步都有 25 章
   的影子。

**层的上同调**：Ab-群层（23 章 Abel 范畴 + 层）的导出函子
——全局截面 Γ 通常只左正合，右导出给 Hⁱ——「拓扑学的
代数不变量」全部经由这条管线（同调代数不在本书范围，
但管线本身是范畴论的最大工业应用）。

## 28.5 回望全书：从范畴到层的走廊

| 章 | 出发的行李 | 到站的用途 |
|---|---|---|
| 01–04 | 范畴、结构集、预层一瞥、图 | 预层 = 反变函子；交换图 = 自然性 |
| 05–08 | 幂集三函子、NT、Yoneda | Ξ/Π 特征函子；可表性 = 「开集即映射」 |
| 09–13 | 切片、极限、等化子、合流 | 覆盖的极限形状；茎 = 合流余极限 |
| 14–17 | 连续函子、伴随、自由/余自由 | RAPL（层化保极限）；反射子范畴 |
| 23–26 | 完备格、∃⊣I⊣∀、Σ⊣U⊣Π、反变伴随 | OS 格上做截面演算；伴随三明治 |

「从范畴到层」不是章节顺序的巧合，而是**依赖图**：
每章都在为层条件的一块拼图供货。Simmons 那句「把零件藏
起来，图景反而清楚」在全书的尺度上兑现——层的定义只用
「函子 + 极限」两个词，但每个词后面站着七章的基建。

## 28.6 机器化边界（诚实清单）

- 预层范畴的 record 级组装：07 章三文化的老墙（Lean 可行、
  Coq/Agda 边界已记录）；
- 层条件本身可判定的最小现场：**Sierpiński 空间**（2 点、
  3 开集）上的层 = 对唯一非平凡覆盖 {1} 的等值条件——
  26.5 的「玩具舞台」：预层 = 两个集合 + 一条限制函数，
  粘合 = 乘积上的一元等式。全部可枚举——适合作为未来
  批次的第一个完整机器层；
- stalk 的合流余极限：14 章的 V-模板推广到「邻域滤方向」
  需要无限合流——文档级。

## 坑位速记

1. 层条件的两个方向别混：分离是**单射性**（等值 ⟹ 相等）、
   粘合是**满射性**（相容族有原像）——合成「F(U) ≅ 相容族」。
2. OS^op 的箭头方向：限制映射沿包含**反向**走——预层的
   反变性写错，粘合等式的形状全崩。
3. 茎的方向：colim over 邻域——**越小的邻域越「后」**，
   与直觉的「细化」方向相反。
4. 层化两步走（先分离化再粘合化）与「一步 Et(F)」等价——
   文档里两种说法混用时注意区分构造与性质。
