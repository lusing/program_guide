# 11 极限的一般理论

> 对书：贺伟 2.1 / Simmons 第 4 章 /《高级范畴论》3.5。代码：`examples/11_limits/`。

一般理论：**图 = 函子 D : I → C，锥 = NT(Δc, D)，极限 = 终锥**。
锥的顶点带着「腿族」与图态射交换；极限是终锥——所有锥唯一地穿过它。

本章机器化最透明的一片：常值函子 constFun（定律 = idL 的最小用例）+ 二元形状的展开版 Cone2/IsLimit2，双向引理「二元离散图的极限 = 积」零公理。

文档层要点：Set 的极限公式（Simmons 4.6.1）：lim D ⊆ ∏ D(i) 的等化子；完备范畴（贺伟 2.5）有全部小极限 ⟺ 有乘积+等化子；余极限 = 反范畴的极限。

## 坑位速记
1. 形状范畴的 Hom「离散」定义在类型层会卡 if 归约——按「两条腿」直接展开成记录更清楚。
2. IsLimit2 与 IsProduct 只差一层包装——两个方向都是「拆包装 + 复用」。
