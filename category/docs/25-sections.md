# 25 截面与三个超幂函子：∃ ⊣ I ⊣ ∀

> 对书：Simmons 6.3–6.6（Sections / 两个完备化 / 三个自函子 /
> 长伴随串）/《高级范畴论》1.7（幂集函子）。
> 代码：`examples/25_sections/`（ex25_sections.v / .lean）。

## 25.1 截面格：LS 与 US

预序 S 的**下截面**(lower section / downset) X 满足
`a ≤ x ∈ X ⟹ a ∈ X`；**上截面**(upper section / upset) 对偶。
全体下截面记 LS、上截面记 US。三条闭包性质（Simmons 6.3.1）：

```text
任意族 {Xᵢ} ⊆ LS：⋃Xᵢ 与 ⋂Xᵢ 都在 LS；∅ 与 S 在 LS
每个 X ∈ LS 都有分解 X = ⋃ {↓x | x ∈ X}     （主截面并分解）
```

于是 **LS 自身是完备格**（并交逐点做），US 同理。两个主截面
映射方向相反（6.3.2）：

```text
η∃(a) = ↓a   随 a 单调
η∀(a) = (↑a)′   随 a 单调（a ↦ ↑a 反单调，再取补回正）
```

**两个完备化**（6.4）：`S ↪ LS`（a ↦ ↓a，保一切并）与
`S ↪ US`（a ↦ (↑a)′，保一切交——因为取了补）。S 稠密地住进
两个完备格里；Dedekind 截割构造实数正是 ↓ 完备化的历史原型
（「实数 = ℚ 的下截面」），理想完备化（环论）、downset 代数
（域理论）同源。

## 25.2 单调映射的三种推进（Simmons 6.5 / 1.3.9）

给定单调 `f : T → S`，把 06 章的幂集三函子搬到截面世界——
每个都在 LS（或 US）上取值，因为截面性质保证封闭：

| 函子 | 定义 | 语义 |
|---|---|---|
| `∃(f) : LS(T) → LS(S)` | `∃(f)(X) := ⋃{↓f(x) | x ∈ X}` | 直接像的下闭包：「存在见证」 |
| `I(f) : LS(S) → LS(T)` | `I(f)(Y) := f⁻¹(Y)` | 逆像：「逐点检验」 |
| `∀(f) : LS(S) → LS(T)` | `∀(f)(Y) := (⋃{↑f(x) | x ∉ Y})′` | 对偶像：「所有纤维」 |

三者都是函子（复合律各一步格运算）；离散预序上它们退化成
06 章的幂集三兄弟——**截面版是量词的「真身」，幂集版只是
影子**：序结构让「存在/所有」有了层级（witness 可以更弱、
检验可以更强）。

**伴随串**（6.5.2，本章旗舰）：

```text
∃(f) ⊣ I(f) ⊣ ∀(f)

∃(f)(X) ⊆ Y  ⟺  X ⊆ I(f)(Y)          （左伴随）
I(f)(Y) ⊆ X  ⟺  Y ⊆ ∀(f)(X)          （右伴随）
```

证明是四行集合论：`∃(f)(X) ⊆ Y ⟺ ∀x∈X, f(x) ∈ Y ⟺
X ⊆ f⁻¹(Y)`；第二条对偶。**量词的左/右伴随身份**就此落定：
存在量词是逆像的左伴随（爱并）、全称量词是右伴随（爱交）——
逻辑的「∃ 粗、∀ 细」有了范畴结构。24 章的定理（保 sup ⟺ 有
右伴随）在这里一眼可见：∃(f) 保并（左伴随）、∀(f) 保交。

**复合的函子性**沿 f 复合反序（I 反变、两端正变）——与
06 章幂集版完全平行。

## 25.3 长伴随串（Simmons 6.6）

把完备化迭代下去：S ↪ LS ↪ LS(LS) ↪ …，每层的主截面
映射 δ（↓ 嵌入）与它的右伴随 σ（并的直接像：X ↦ ⋃X，把
截面族拍扁）给出**每层一对伴随** `δ ⊣ σ`（6.6：σn+1 是
δn+1 的右伴随）。串起来：

```text
... δ₁ ⊣ σ₀ ; δ₂ ⊣ σ₁ ; δ₃ ⊣ σ₂ ...
∃(δ) ⊣ I(δ) ⊣ ∀(δ)     ——每个嵌入再配三条推进
```

**交替应用 δ 与 σ 就是「闭包/内部」演算**：σ∘δ = id（嵌入
满），δ∘σ ⊒ id（一个闭包算子）——拓扑的闭包/内部、模态逻辑
的 □◇、粗糙集的上下近似，全是这串的实例。6.6.1 的小反例
（两点链上 ∃(f)(∅) ≠ ∀(f)(∅)）提醒：三兄弟**互不相同**，
除非 f 特殊。

## 25.4 机器版：三点链上的 ∃ ⊣ I ⊣ ∀

三元素链 0 ≤ 1 ≤ 2、单调 `φ : x ↦ min(x+1, 2)`。截面 =
升链闭包的布尔谓词（8 个 LS 元素）。机器化（Coq/Lean）：

```lean
def existsF (X : Chain3 → Bool) : Chain3 → Bool :=
  fun s => (X 0 && le3 0 (φ 0) s...) -- 直接像 + 下闭包，查表定义

theorem exists_left_adjoint (X Y : LS) :
    incl (existsF φ X) Y = incl X (inverseF φ Y) := by
  cases 全枚举           -- 64 组 (X,Y)，各组 3 点查表
```

- `∃(φ) ⊣ I(φ)`：64 组谓词对穷尽（每组是 3 点布尔包含检查）；
- `I(φ) ⊣ ∀(φ)` 对偶穷尽；
- 三推进的复合律抽查（I 反变、∃/∀ 正变）。

全部可判定、零公理——有限预序上量词演算是**纯查表**，
这是本章机器件便宜的原因；无限预序（ℤ、ℝ 的截面）回到
文档级，良定义性靠 6.5.2 的四行集合论。

## 25.5 去向：从序到逻辑到层

- **直觉主义逻辑**：完备格 Heyting 代数上，I ⊣ ∀ 的右伴随
  性质即蕴含词 `Y ⊃ X := ⋁{z | Y ∧ z ≤ X}` 的定义——
  「∀ 是右伴随」直接给出「⇒ 的存在性」；
- **模态/时序**：24.3 的闭包串是 □/◇ 的代数原型；
- **层论**：28 章的开集格 OS 上，∃/I/∀ 沿开集包含序上演——
  sheaf 条件「局部粘合」= 某个 ∀-型条件对覆盖成立；
  Heyting 结构正是拓扑斯的逻辑骨架。

## 坑位速记

1. 截面谓词的「闭包性」在机器里要显式检查（或用范式编码：
   只存规范代表）——否则 8 元素的「全集」混入非法截面。
2. `∀(f)(Y) = (↑f[Y′])′` 的补号方向极容易写反——语义检验：
   ∀ 应该「越小越保守」，查 f 为常值映射的极端情形。
3. 伴随的两个包含等式方向（∃ 的 X 在左、∀ 的 X 在右）——
   背反了 64 格穷尽会全红，属「幸运的可判定错误」。
4. 复合律的「反序」只属于 I：∃(g∘f) = ∃(g)∘∃(f) 而
   I(g∘f) = I(f)∘I(g)——与 06 章幂集版逐字相同，可对照记。
