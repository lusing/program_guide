# 13 伴随的三副面孔

> 对书：贺伟 3.1 /《高级范畴论》5.2–5.4 / Simmons 5.1。代码：`examples/13_adjunctions/`。

伴随 F ⊣ G 的三副面孔：**hom-双射** / **泛映射** / **单位-余单位**。机器内容：Adjunction record（η/ε 分量族 + 自然性 + 三角恒等式，分量内联免 NT record 的依赖字段问题）+ hom-双射两个方向 φ/ψ + 往返等式 ψ(φ f) = f（零公理，五步追图：Fcomp 并 → assoc 拆 → ε 自然性 → assoc 并 → 三角恒等式 → idL）。

往返 2（φ(ψ g) = g）对称地用 η 自然性 + tri2。三面孔的完整等价证明需要 NT 基础设施 + 选择公理——文档层记录（贺伟 3.1 的三条路线对照表）。
