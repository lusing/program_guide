## 9.1 从一个问题出发：把「带箭头的对象」打包

到 09 章为止，我们见过的范畴构件都是「现成范畴 + 现成函子」。
但很多数学对象天生带着一条箭头：

- **切片**（slice）`(C↓S)`：范畴 C 里「趴在对象 S 上」的全体
  对象——对象是 `α : X → S`，箭头是让三角交换的 `u : X → Y`；
- **余切片** `(S↓C)`：箭头反过来 `α : S → X`；
- **箭头范畴** `C↓`：对象是 C 里的箭头 `f : A → B` 本身；
- **函子图**：函子 F 在每个对象上的「图像」。

Simmons 3.3.4 的观察：这四样东西是**同一个构造**的特例。
给定一对**平行**函子（同靶）：

```text
        U              L
    C ------→ A ←------ B
```

**逗号范畴** `(U ↓ L)` 的数据是：

- **对象**：三元组 `(c, b, α)`，其中 `c : C`、`b : B`，
  `α : U c → L b` 是 A 里的箭头；
- **箭头** `(c, b, α) → (c′, b′, α′)`：一对箭头
  `u : c → c′`、`v : b → b′`，使得 A 里的方块交换：

```text
   U c  ──α──→  L b
   │            │
 U u│            │L v        （方块交换：α′ ∘ U u = L v ∘ α）
   ↓            ↓
   U c′ ──α′─→  L b′
```

- 复合按分量进行，恒等按分量取——交换方块的「外圈仍是
  交换方块」正是 05 章追逐技术的最小应用（Simmons 3.3.10 把
  这一步详细写了出来：两个交换方块拼起来的外圈交换，靠
  assoc 一次重组即得）。

名字里的「逗号」来自 Lawvere 最初的记号 `(U ↓ L)`——画出来
就是上面那个 A 处「拐弯」的形状。

## 9.2 三个化身（Simmons 3.3.11）

逗号范畴的威力在于**一次定义、多处收账**：

| 取 U、L | 得到 | 对象是 |
|---|---|---|
| `U = L = Id_C` | 箭头范畴 `C↓` | C 的箭头 `f : A → B` |
| `U = Id_C`，`L = K_S`（常值在 S） | 切片 `(C↓S)` | `α : X → S` |
| `U = K_S`，`L = Id_C` | 余切片 `(S↓C)` | `α : S → X` |

验证切片一栏：`L = K_S` 把任何 `b` 都送到 S，于是对象三元组
里的 `L b` 恒为 S，箭头 `α : X → S`——**b 是个哑元**，扔掉它
就得到通常的切片定义。同理箭头里的 `v : b → b′` 也失去作用，
只剩让三角交换的 `u`。机器版最能看清这件事——对象类型**定义地
化简**：

```coq
(* (Id ↓ K_s) 的对象：c、哑元 b、箭头 Le c s *)
Record CommaObj : Type := mkCommaObj {
  cobj : nat;
  cbob : bool;                      (* 哑元：K_s 把它抹平 *)
  carr : Le cobj 1                  (* 箭头 x → s = 1 *)
}.
```

对预序范畴（03 章的 leCat），箭头 `Le c s` 至多一条，于是
`(leCat ↓ s)` 的对象恰是**主下截面** ↓s = {x | x ≤ s} 的元素
——03 章 2.5 节的截面在这里获得了范畴身份：**切片范畴在
预序上的化身就是截面**。凸截面 `(s↓S↓t)` 则是两个切片的
交（对象同时带 `s ≤ x` 与 `x ≤ t`）。

## 9.3 机器版：对象对应是定义性的

三份代码做同一件事：在 leCat 上取 `K = K₁`（常值在 1），
构造 `(Id ↓ K)`，然后观察对象类型**自动就是**截面：

```lean
/-- (Id ↓ K₁) 的对象 = (x, 哑元, Le x 1) —— 投影即截面成员关系 -/
def SectionOf : Type := Σ' x : Nat, Le x 1

def toSection : CommaObj → SectionOf
  | ⟨x, _, α⟩ => ⟨x, α⟩

def fromSection : SectionOf → CommaObj
  | ⟨x, α⟩ => ⟨x, false, α⟩    -- 哑元随便填

example : ∀ o, toSection (fromSection o) = o := by
  intro ⟨x, α⟩; rfl
```

`toSection ∘ fromSection` 是 `rfl` 级恒等（哑元被扔掉）；
反方向差一个哑元——**严格相等不成立、典范同构成立**，这正是
03 章「op 的 op 不是 C」的老裂缝在新场景的重演。教程的诚实
清单：机器里能拿到的是分量级对应，不是 record 级相等。

箭头复合的封闭性（Simmons 3.3.10 的交换方块拼接）在 Coq 版
里完整机器化：两个箭头 `(u, v)`、`(u′, v′)` 可复合时，外圈
方块的交换性由 assoc 直接给出——

```coq
(* 外圈交换：α″ ∘ (U u;U u′) = (L v;L v′) ∘ α *)
comma_comp_law : comp carr3 (comp (Umap u) (Umap u')) =
                 comp (comp (Lmap v) (Lmap v')) carr
```

## 9.4 为什么逗号范畴重要：万有箭头的家

逗号范畴不只是「打包技巧」。17 章的主角——**自由/余自由构造**
——的泛性质恰好住在逗号范畴里：

- 函子 `U : A → X`、对象 `X` 的**万有箭头**
  `η : X → U(FX)` 是逗号范畴 `(X ↓ U)`（X 视为一个对象的
  范畴、K = 常值）的**初始对象**；
- 对偶地，`U` 的余万有箭头是 `(U ↓ X)` 的终对象；
- Simmons 5.5 的「F-free / F-cofree 数据」正是这两句话的
  展开——到 17 章我们回来收这笔账。

另一个方向的收获：**函子图**。`(Id ↓ F)` 与 `(F ↓ Id)` 把
「F 的图像」做成范畴，等价于切片/余切片的相对化——极限论里
的「图像分解」技术与 Grothendieck 构造都以它为起点（28 章
预层栈的线索）。

最后是术语学：为什么叫「逗号」？Lawvere 1963 年的原始记号
是 `(S ↓ U)`，读作「S comma U」。中文文献也译作「逗号范畴」
或「俯范畴/仰范畴」（专指切片/余切片两个特例）。

## 9.5 三家写法对照

| | Coq | Agda | Lean |
|---|---|---|---|
| 三元组对象 | Record + 参数哑元 | record + Σ | structure |
| 对象→截面 | 定义性投影 | 定义性投影 | 定义性投影 |
| 往返恒等 | 分量级 rfl | refl | rfl |
| 交换方块拼接 | assoc 重写 | trans/cong 链 | rw + assoc |

与前几章同一个教训：**依赖 record 的「定义性化简」在三家都
免费，但「record 级相等」三家三价**——这里只需要前者，所以
三家难得地写得一样短。

## 坑位速记

1. 逗号范畴的箭头是**一对**箭头 `(u, v)`——外圈交换性不是
   额外公理，是 assoc 的直接推论；别把它当独立字段重新证明。
2. 切片化简里哑元 `b` 扔不得太早：定义里保留它，投影时扔——
   「保留冗余定义、使用时化简」比「提前修剪」更经得起机器
   检查（record 相等的裂缝会更少）。
3. 预序范畴的逗号对象：`Le c s` 是 Set 值归纳族——构造对象
   时要给出具体构造子（`le_refl`/`le_step` 链），不能凭
   类型检查通过就完事。
