## 12.1 子对象：谈「包含态射」而非「包含关系」

具体数学里到处是「子对象」——子集、子群、子空间。范畴论的
处理方式有个漂亮的转弯（贺伟 1.5 开篇）：**与其讨论对象之间
的包含关系，不如讨论包含态射的性质**。而且不同的具体范畴对
「包含」的要求不同，所以干脆把它参数化：

**定义（M-子对象）**：取范畴 C 中一族单态射 M。若
`f : A → B` 在 M 中，则称 (A, f) 为 B 的一个 **M-子对象**。
M 取全体单态射时就是通常的**子对象**。

哪个范畴的子对象对应直觉的「子结构」？逐家清点（贺伟例
1.5.2/1.5.3——第二条是 surprises 所在）：

| 范畴 | 子对象 = ? |
|---|---|
| Set / Gp / AbGp / Rng / Mod_R / **HComp** | 子集 / 子群 / … / 紧 Hausdorff 子空间 ✓ |
| **Top / Rel / Poset** | **不是**子空间 / 子关系 / 子偏序！ |

Top 出问题的原因：单态射只要求集合单射 + 连续，子对象的
「子拓扑」可以比子空间拓扑粗——范畴只认 mono，不认「该有的
拓扑」。「良幂」(well-powered)——每个对象只有「集合大小」的
子对象族——Set/Top/Gp 都满足；贺伟例 1.5.7 用「所有序数加
顶」造出非良幂的范畴。良幂性是后续（子对象分类子、拓扑斯）
的库存管理假设。

**Sub(B) 的序**：(A,f) ≤ (A′,f′) ⟺ 存在（唯一——f 单）g
使 f = f′g。**引理 1.5.4**：≤ 两个方向都成立 ⟹ 同构——
`f(hg) = f = f·1A ⟹ hg = 1A`（f 单消去），对称得 gh = 1。
于是**模同构后 Sub(B) 是偏序集**。「唯一性当武器」的最小
现场又一次出现。

## 12.2 商对象与「等价关系的化身」

对偶定义：一族满态射 E 里的 `f : B → A` 给出 B 的 **E-商
对象**。Set 里商对象 ↔ **商集**，而商集 ↔ 等价关系（例
1.5.15）：满射 e : B → A 造等价关系 `x ~ y ⟺ e(x) = e(y)`
（e 的**核对**，11 章）；反过来等价关系 ~ 造商映射
`B → B/~`。这个一一对应是「商 = 粘合」的全部内容：
**商对象记的不是结果集，而是「谁和谁被认同」**。HComp 的
商对象 ↔ 紧商空间（同款对应）；一般的 Top 又是反例重灾区
（商拓扑在范畴里对应的是**余等化子**，11.5 的闭包雪崩问题）。

## 12.3 终点与起点的三件赠品（贺伟 1.5.8–1.5.13）

终对象/始对象的定义在 03 章已进机器。贺伟在这里补三条
「便宜但常被忽视」的性质：

1. **唯一到同构**（命题 1.5.9）：两个终对象互为唯一箭头，
   唯一性直接给互逆——泛性质免费午餐的元祖版本；
2. **预序里的化身**（例 1.5.12）：偏序集当范畴，终对象 =
   最大元、始对象 = 最小元——24 章完备格的 ⊤/⊥；
3. **终对象出发的箭头都是 mono**（命题 1.5.13）：f : T → A，
   T 终 ⟹ f 单（平行对 g,h : X → T 只有一个人，自动相等）。
   于是**每个从终点出发的箭头都是 A 的子对象**——「泛元素」
   (generic element) 的雏形：可表函子的 Yoneda 对应（08 章）
   正是这条路走到底。

机器版三行（零公理）：

```coq
Lemma terminal_arrow_mono : forall (C : Category) (t : Obj C),
  Terminal C t -> forall a (f : Hom C t a), Mono C t a f.
Proof.
  intros C t Ht a f c g hfg _. (* g = h：终点唯一箭头 *)
  apply (proj2_sig (Ht c)).   (* Hom(c,t) 恰一：g 和 h 都是它 *)
Qed.
```

## 12.4 射影对象：把「提升」公理化（贺伟 1.7.1–1.7.7）

线性代数与模论里「射影模」的范畴化。取一族满态射 E（对
同构复合封闭）：

**定义（E-射影对象）**：P 是 E-射影 ⟺ 对 E 中每个
`e : A → B`、每个 `f : P → B`，f 能**沿 e 提升**——存在
`g : P → A` 使 `f = e∘g`。直觉：**P 上的问题能搬到「楼上」
解决**。

四个样板：

- **Set**：任何集合都射影——满射逐点选原像。**这就是选择
  公理**（例 1.7.2 明说了 AC 的角色，03 章诚实清单的呼应）；
- **Top**：射影对象 = **离散空间**（例 1.7.3：把离散 P 恒等
  到平庸 P 的满射可提升，逼出 P 的拓扑必须离散）；
- **Gp/AbGp**：**ℤ 是射影的**（例 1.7.4：自由生成元选一个
  原像，g(z) := za——「自由 = 射影」的最小实例，17 章
  自由范畴、21 章自由幺半群同款论证）；
- **函子表述**（命题 1.7.5）：P 射影 ⟺ `C(P,−)` 保满态射
  ——「射影 = 表现在 epi 上的忠实性」，RAPL（18 章）的
  零阶近似。

两条封闭引理（机器版零公理）：

```text
命题 1.7.6   始对象是射影对象（唯一箭头自动完成提升）
命题 1.7.7   射影对象的收缩仍是射影对象
```

**收缩**(retract)：B 是 A 的收缩 ⟺ 存在 i : B → A、
r : A → B 使 `r∘i = 1_B`（03 章分裂单的「子对象版」）。
1.7.7 的证明图值得整个机器化——它把「提升」与「往返」缝
在一行等式里：

```text
给 f : R → B、e : A → B 满。f∘r : P → B 经 P 的射影性
提升为 g : P → A（f r = e g）。于是
f = f∘1R = f∘(r i) = (f r) i = (e g) i = e (g i)
——h := g∘i 就是所要的提升。收缩 i 把 P 的提升拉回 R。
```

## 12.5 单射对象：对偶的宇宙

**定义（M-单射对象）**：I 单射 ⟺ 每个单射 m : A → B、每个
f : A → I 都能**沿 m 扩张**成 g : B → I。对偶样本同样精彩
（贺伟例 1.7.9/1.7.10 与练习 1.7）：

- **Set**：任何**非空**集合单射（选一个点常值扩张）；空集
  对空 ↔ 非空的提升——对偶世界里「非空」成了主角；
- **HComp**：单态射 = 闭嵌入；**Tietze–Urysohn 扩张定理**
  说 [0,1] 的任何幂 [0,1]^I 是单射对象——而且 HComp 的全部
  单射对象恰好是它们（幂 + 收缩）！**拓扑定理的范畴翻译**
  第一次完整亮相；
- **练习 1.7.3（贺伟点名的彩蛋）**：Top₀ 中**严格单射**
  (extremal mono) 的单射对象恰是 **Sierpiński 空间 S 的幂**
  的收缩——26 章的两面对象在这里客串逻辑真值对象，27 章
  子对象分类子的前哨。

练习 1.7.1/1.7.2（终对象单射、收缩封闭）是 1.7.6/1.7.7 的
镜像——本教程机器版把它们一并交给读者（ex12 的对偶扩展题）。

## 12.6 机器版

三份代码（三语言同构）装四个定理：

| 引理 | 内容 | 证明要点 |
|---|---|---|
| `terminal_arrow_mono` | 命题 1.5.13 | 唯一箭头两次使用 |
| `initial_projective` | 命题 1.7.6 | Hom(P,−) 单点 ⟹ 提升唯一存在 |
| `retract_projective` | 命题 1.7.7 | 「提升 → 收缩拉回」两行等式 |
| `kerPair_equiv` | 例 1.5.15 的核 | e = fst 在 4 点集上：refl/sym/trans 全计算 |

`retract_projective` 的 Coq 版（零公理，命题与提升都是
Σ-数据）：

```coq
Definition Projective (C : Category) (p : Obj C) : Type :=
  forall a b (e : Hom C a b), Epi C a b e ->
  forall f : Hom C p b, { g : Hom C p a | f = comp C g e }.

Definition RetractOf (C : Category) (r p : Obj C) : Type :=
  { i : Hom C r p | { rr : Hom C p r | comp C i rr = idn C r } }.

Lemma retract_projective : forall C (p r : Obj C),
  Projective C p -> RetractOf C r p -> Projective C r.
Proof.
  intros C p r Hp [i [rr Hrr]] a b e He f.
  destruct (Hp a b e He (comp C f rr)) as [g Hg].  (* 提升 f∘rr *)
  exists (comp C g i).                              (* 拉回 *)
  rewrite assoc, Hg, <- assoc, Hrr, idL. exact f.   (* 四步缝合 *)
Qed.
```

注意方向账：`Hrr : i;rr = 1_R` 与 `Hg : (f;rr) = g;e`（图序）
的组合顺序——assoc 展开的方向弄反会 rewrite 失败（本文件
坑位 1 有实测记录）。`kerPair_equiv` 在 `bool × bool` 上取
`e := fst`，等价三律全部 `destruct` 穷尽——「商的信息住在
等价关系里」的可计算版。

## 12.7 去向：射影/单射对象的大戏台

- **足够射影/足够单射**(enough projectives/injectives)：
  每个对象都是某个射影的商 / 单射的子对象——模论与上同调
  的开机条件（23 章 Abel 范畴、导出函子的「用射影消解」）；
- **射影 = 平坦的影子**：模的射影性 ⟺ 张量积正合性——
  伴随（17 章）与正合性（23 章 4.3）的交汇；
- ** injective envelope / projective cover**：极小单射扩张
  存在与否是范畴的「刚性指标」；
- **逻辑侧**：Boole 代数的 Stone 对偶里，射影对象 ↔ 极不
  胜连通空间（贺伟 1.7 练习 4 的方向）——26 章反变伴随的
  又一个化身。

## 坑位速记

1. `retract_projective` 的缝合顺序：先 assoc 暴露 `(f;rr);i`
   的左半，再用提升等式 Hg 换 `(f;rr)`，右半用 Hrr 收缩回
   1_R——顺序错一步 rewrite 找不到模式。
2. Projective 定义里「提升」是**数据**（Σ）不是性质——
   收缩封闭引理要把它构造出来，Prop 版定义会让 exists 卡住。
3. E-相对射影中 E 要对同构复合封闭——绝对版本（全体满态射）
   在机器里省掉这个条件，文档里别混用两版定义的引理。
4. Set 的「全射影 = 选择公理」：机器验证只对**具体满射**有效
   （有限集逐点选），一般陈述在构造性内核里不可证——03 章
   诚实清单的延续。
