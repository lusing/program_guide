## 24.1 完备预序： supremum 一个人干活

预序 (S, ≤) 当范畴看（03 章的瘦范畴：`Hom a b ⟺ a ≤ b`），
** supremum ⋁ 就是余极限、infimum ⋀ 就是极限**——13 章的一般
理论在瘦范畴里塌缩成两行算术：

```text
⋁X = X 的余极限：X 的每个元素 ≤ ⋁X（余锥），且 ≤ 任何别的上界（泛性）
⋀X = X 的极限：对偶
```

预序 **完备**（complete）= 每个子集 X ⊆ S 都有 ⋁X。空集的
sup 是**底** ⊥、全集的 sup 是 **顶** ⊤；单点集的 sup 是自己；
二元 sup 就是 join `a∨b`。

**第一个定理**（Simmons 6.2.3）：**有全部 sup ⟹ 有全部 inf**。
证明是瘦范畴式的一行诗：

```text
⋀X := ⋁ { y | ∀x∈X, y ≤ x }      （下界集的 sup）
```

X 的每个 x 是下界集的上界，故 ⋁(下界集) ≤ 每个 x——它自己是
下界且 ≥ 一切下界。**极限 = 一切余极限的余极限**——对偶原理
在完备性上的兑现（反向同样成立：inf 齐 ⟹ sup 齐）。

书里 6.2.4 的反例值得记：实轴区间 [0,1]∪(2,3] 对通常序**完备**
（上半段的 inf 是 2——尽管 2 不在集合里，上半段的 inf 按定义
取在 [0,1]∪(2,3] 里是... 等等，2 ∉ S，inf{2<x≤3} 的下界集含
1，故 inf = 1）——**完备性允许「缺口外借」**，inf/sup 不必是
「聚点」，只是序论角色；同一区间嵌入 [0,3] 后 inf 变 2——
**包含映射保 ⋁ 不保 ⋀**：完备范畴的子范畴未必完备，强保
结构要挑箭头（这就是 6.2 区分 ⋁-morphism / ⋀-morphism 的
原因，也是 22 章 Pos 两条完备化路线的分叉点）。

## 24.2 旗舰定理：保 sup ⟺ 有右伴随（Simmons 6.1.1）

单调映射 `f : S → T`。以下等价：

1. **f 有右伴随**：存在单调 g : T → S 使 `f(a) ≤ b ⟺ a ≤ g(b)`；
2. **f 保全部 sup**：`f(⋁X) = ⋁f[X]`。

**(1)⟹(2)** 的证明是 adjunction 的字典游戏：

```text
f(⋁X) ≤ b ⟺ ⋁X ≤ g(b) ⟺ (∀x∈X) x ≤ g(b) ⟺ (∀x∈X) f(x) ≤ b ⟺ ⋁f[X] ≤ b
```

两端对一切 b 同序 ⟹ 相等——**瘦范畴里「同 ≡ 泛性质」**，judgment
只剩一行。对偶（(1) 用左伴随版本）：f 有左伴随 ⟺ f 保全部 inf。

**(2)⟹(1) 是构造**：右伴随被迫是

```text
g(b) := ⋁ { a | f(a) ≤ b }        （「f⁻¹(↓b) 的 sup」）
```

两个方向的验证：f(a) ≤ b ⟹ a ∈ 该集合 ⟹ a ≤ g(b)；反向用
保 sup：a ≤ g(b) ⟹ f(a) ≤ f(⋁...) = ⋁f[该集合] ≤ b（集合里
每个 a′ 都 f(a′) ≤ b，故 sup 的像 ≤ b）。**g 是唯一可能的**
——伴随在瘦范畴里唯一（Hom 至多一条）。

这条定理的名字：**剩余映射**(residuated map) 与剩余补
(residual)；f ⊣ g 这对在序论里叫 **Galois 连接**（单调版本；
「Galois 对应」反变版见 27 章）。三个经典样本：

- **取整**（Simmons 1.3.8）：ℤ 嵌入 ℝ，`⌊·⌋ ⊣ ι ⊣ ⌈·⌉`——
  下整/上整是包含映射的左/右伴随；
- **幂集**：直接像 ∃(f) ⊣ 逆像 I(f)——25 章主角；
- **格论**：x ↦ x∧c 与 x ↦ x∨c 互为伴随（分配格上三条
  分配律全剩）。

**投影对**（projection pair，1.3.6）：f ⊣ g ⟺ 两个不等式
`a ≤ g(f(a))`、`f(g(b)) ≤ b`——比等式弱、比定义好用；复合
封闭（1.3.7）。工程读法：**g 是 f 的「最优下近似」**——
g(b) 是「f 之后不超过 b」的最大输入。编译器的抽象解释、
程序分析的 Galois 连接（抽象域 ⊣ 具体域）全是这条定理的
应用现场。

## 24.3 机器版：菱形上的剩余映射

四元素菱形（⊥, 左 a, 右 b, ⊤；a、b 不可比）是最小的非链
完备格。机器化（三语言）：序表 + 16 个子集的 sup 表全部
穷尽可算。旗舰验证：`f(x) := x ∨ a`（与 a 取 join）——

```coq
Inductive Diam : Set := dBot | dL | dR | dTop.   (* a := dL *)

Definition fJoin (x : Diam) : Diam := (* x ∨ dL *) ...

(* 伴随定律：f(x) ≤ y  ⟺  x ≤ g(y)，16 格穷尽 *)
Lemma adjunction_law : forall x y, leD (fJoin x) y = leD x (gAdj y).
Proof. intros x y. destruct x, y; reflexivity. Qed.
```

`gAdj(y) := ⋁{x | f x ≤ y}` 按 23.2 的公式**算出来**——
机器先「查表构造」再「穷尽验证」，正是定理 (2)⟹(1) 的
可计算版。加一条**单调性**与**保 sup 抽查**（单点/双点
子集），全套零公理。

## 24.4 两个完备化预演

完备预序的范畴（⋁-morphism 为箭头）自身又是一个大舞台：
S 可以嵌入 LS（全体下截面的完备格）与 US——25 章的两个
完备化；而 ⋁-morphism 的范畴与 ⋀-morphism 的范畴**不同**
（保 sup 不保 inf，6.2.4 的反例），这两条路线将分道扬镳
成 25 章的 ∃/I/∀ 三函子。序与范畴的字典（预序 = 瘦范畴、
伴随 = Galois 连接、完备 = 有全部余极限）从此章起全面
双向通行。

## 坑位速记

1. 瘦范畴里「相等」退化为「同序」——证明两对象相等只需
   `∀b, (x ≤ b ⟺ y ≤ b)`；机器版即 16 格查表。
2. g 的构造式定义要先证「集合非空性可用性」——{a | f a ≤ b}
   永远含 ⊥（f(⊥) ≤ b 自动？不——要 f 保 ⊥！查表确认），
   有限格机器版无此顾虑（sup 表全算）。
3. 「保 sup」必须**全部**子集——只保二元 join 不够（无限
   格的反例在文档级；有限格上二元 join + 底即够，机器版
   因此便宜）。
4. Lean/Agda 的枚举构造子（dBot/dL/dR/dTop）各自写 sup 表
   ——Coq 用 function 定义 + destruct 全枚举最省。
