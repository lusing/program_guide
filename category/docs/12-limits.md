# 12 极限的一般理论

> 对书：贺伟 2.1（泛极映）/ Simmons 第 4 章（模板、解、泛解、
> 怎么算极限）/《高级范畴论》3.5。
> 代码：`examples/12_limits/`（ex12_limits.v / .lean，双语）。

## 12.1 把「形状」参数化：模板与图

10、11 章的积、等化子、拉回各是一个**形状**：二元离散图、平行
对、方块。Simmons 4.1 的做法是把形状本身当成研究对象。一个
**模板** ∇ 是个小图：一堆**节点** i、一堆**边** e（每条边有源汇）。
一个 ∇-**图**就是把 ∇ 摆进范畴 C 里：每个节点 i 贴一个对象
A(i)、每条边 e : i → j 贴一条箭头 A(e) : A(i) → A(j)——用 04 章
的语言，这就是图态射 `∇ → U(C)`。

要谈「交换的三角」就得有复合，于是把模板升格成它的**路径范畴**
Pth(∇)（04 章的 freeCat！）：节点不动、边升格为生成箭头。4.3.1
的关键观察：**∇-图与 Pth(∇)-图携带同样的信息**——每条路径 π
对应的箭头 A(π) 由各段复合唯一确定，「路径三角交换」自动成立。
用范畴论行话说：图表 = **函子** `Pth(∇) → C`；「图 = 函子」
从此成为正式语法（贺伟本直接从这里开题）。

## 12.2 解与泛解：锥的正式定义

∇-图 A 的一个**左解**（left solution，即**锥** cone）是：

- 一个顶点对象 X；
- 每个节点 i 一条**腿** `ξ(i) : X → A(i)`；
- 对每条边 e : i → j，三角交换：`ξ(j) = A(e) ∘ ξ(i)`。

**右解**（余锥 cocone）把箭头全部反悔：腿 `α(i) : A(i) → X`、
`α(j) = α(i) ∘ A(e)`。**泛左解**（极限）是这样的左解：任何
别的左解都经它**唯一分解**——存在唯一 `h : X → L` 使每个
`ξ(i) = λ(i) ∘ h`。泛右解（余极限）对偶。

回忆 09 章：解们自己构成范畴（箭头 = 保腿的顶点间箭头），极限
= 该范畴的**终对象**、余极限 = **始对象**——「泛性质 = 切片
范畴的端点」，与 03 章终始对象的定义一脉相承。由此**极限唯一
到同构**（10 章旗舰的同款论证，一个字不用改）。

机器版（双语）把这个定义落在二元离散形状上：

```lean
/-- 二元形状的锥与极限：两条腿 + 唯一分解 -/
structure Cone2 (D : Diag2 C) where
  apex : C.Obj
  leg1 : C.Hom apex D.a
  leg2 : C.Hom apex D.b

structure IsLimit2 (D : Diag2 C) extends Cone2 D where
  mediate : ∀ (k : Cone2 D), C.Hom k.apex apex
  uniq : ∀ (k : Cone2 D) (h h' : C.Hom k.apex apex), ...
```

**双向引理**（零公理）：二元离散图的极限就是积——
`limit2_is_product`（把 Cone2 拆开正好是 IsProduct 的两条腿）
与 `product_is_limit2`（积的数据正是那个泛锥）。11 章的
「等化子 = 沿对角线的拉回」、12.4 的 Set 公式，都是同一根
逻辑藤上的瓜。

## 12.3 Set 里极限怎么算：线程法（Simmons 4.6）

一般理论说「极限 = 终锥」，但**具体算出来**是另一回事。4.6 给
的算法分三步，适用于一切结构集范畴：

**第一步：Set 的公式**。∇-图的极限落在乘积里：

```text
lim A = { a ∈ ∏ᵢ A(i) | 对每条边 e : i → j，A(e)(a(i)) = a(j) }
```

∏ 的元素是**线程**(thread)——每个节点选一个值；极限 = 满足
相容性的线程集，投影是取分量。相容性恰好是「等化掉所有边」，
所以 **lim = 等值化子 ⊆ 乘积**（11 章的两件工具拼出一切）。

**第二步：结构集范畴——逐点装修**（4.6.1）。Set^D（带特异
子集 R 的集合）的极限：先在 Set 里算出线程集 A，再**逐点**
装上结构 `a ∈ R ⟺ ∀i, a(i) ∈ R(i)`。验证只有一件事：中介
映射保结构——因为 `x ∈ W ⟹ μ(x)(i) = ξ(i)(x) ∈ R(i)`，
逐点一推就过。

同一配方横扫一族范畴（4.6.2/4.6.3）：

| 范畴 | 结构 | 逐点装修 |
|---|---|---|
| Eqv（预序集） | 等价关系 | `a ∼ b ⟺ ∀i, a(i) ∼ᵢ b(i)` |
| Set-R（R-集） | 右作用 | `(a·r)(i) = a(i)·r` |
| Mon/CMon/Grp | 运算 | 分量式运算（见第三步） |
| Top | 拓扑 | 初始拓扑（子基 = 各分量的开集原像） |

**第三步：满子范畴的免费午餐**（4.6.4）。CMon 是 Mon 的**满**
子范畴（同态自动保交换律）；Grp 同理是 Mon 的满子范畴。于是
在 Mon 里算出的线程极限**自动**落在 CMon/Grp 里：交换律
`(a⋆b)(i) = a(i)b(i) = b(i)a(i) = (b⋆a)(i)` 逐点成立；逆元
逐点取。**满子范畴对极限封闭**——这是「极限在 Set 里造、结构
免费继承」的最强形态，17 章（反射子范畴）的前奏。

## 12.4 旗舰例子：一条塔的极限与余极限（Simmons 4.5.1）

把 ℤ 当索引（预序），节点 m 摆 ℤ，边 m → m+1 摆加倍映射
`d(n) = 2n`：

```text
... ← A(m) ← A(m+1) ← ...      其中每个 A(m) = ℤ，连接箭头 n ↦ 2n
```

**极限是什么？** 设 (X, ξ(m)) 是锥。锥条件给出
`ξ(m+1)(a) = 2·ξ(m)(a)`，归纳得 `ξ(m+r)(a) = 2ʳ·ξ(m)(a)`。
但 ξ(m+r)(a) 是整数——被 2 的任意次幂整除的整数只有 0！
于是**每条腿都是常零函数**，锥退化成「X 加一族常映射」。
单点集 L = {*} 配常零腿是其中之一，且任何锥经它唯一分解
（X → L 只有一个函数）——**极限 = 单点**。整条无穷塔被
2 的幂「压扁」成一点。

**余极限是什么？** 余锥条件 `f(m)(z) = f(m+1)(2z)`。候选：
**二进有理数** D = {2⁻ᵐx}，第 m 个分量给
`ρ(m)(x) = 2⁻ᵐx`。这里冒出全书最典型的坑：**表示不唯一**
（2⁻¹·1 = 2⁻²·2）。定义函数 h : D → A 前必须先证（★）：

```text
2⁻ᵐx = 2⁻ⁿy  ⟹  f(m)(x) = f(n)(y)
```

证明：不妨 m ≤ n，y = 2^(n−m)·x，则
`f(n)(y) = f(m + r)(2ʳx) = f(m)(x)`——恰好是余锥条件的
r 步归纳。有了（★），`h(2⁻ᵐx) := f(m)(x)` **良定义**且是
唯一可能的中介。**余极限 = D**。

同一条塔，极限 1、余极限 D——**极限讨债（约束压扁一切），
余极限放贷（把所有相容性兑现成新元素）**。这个对比是理解
极限论的钥匙：Baire 纲、p-adic、局部化、形式幂级数，全是
这条塔的变奏。（4.5.2 的预序版把 A(i) 换成两点链，极限与
余极限同时坍缩成单点——约束吃掉一切的最简现场。）

## 12.5 完备范畴：两件工具走天下

范畴**完备**（complete）= 每个小图都有极限。定理（贺伟 2.5、
Simmons 4.6 收尾）：**有任意乘积 + 有等化子 ⟺ 完备**。理由
就是 12.3 的公式：lim = 等值化子 ∩ 乘积——两件工具足以拼出
一切形状。对偶：**余积 + 余等化子 ⟺ 余完备**。

清点家底：Set/Pos/Mon/Grp/Top 全部完备且余完备（12.3 的
配方表就是证明纲要）；有限范畴里 FinCat 有有限极限无任意
乘积（基数不够）；每章的主角——函子范畴 [C, Set]——逐点
完备（27 章预层范畴的立足点）。

## 12.6 机器与文档的分工

本章双语机器化的内容：常值函子 `constFun`（定律 = idL 的
最小用例）、`limit2_is_product` / `product_is_limit2` 双向
引理（零公理）。Set 公式、线程法、（★）良定义性是文档级
内容——机器化需要函子范畴的 record 级相等（06 章三文化
的老边界）与商集基建，在 13 章的合流余极限处迈出第一步。

## 坑位速记

1. 形状范畴的 Hom「离散」定义在类型层会卡 if 归约——按
   「两条腿」直接展开成记录更清楚。
2. IsLimit2 与 IsProduct 只差一层包装——两个方向都是
   「拆包装 + 复用」。
3. 「表示不唯一就先证良定义」（★）是余极限计算的通用坑——
   13 章的块 [x,i] 同款。
4. 「满子范畴对极限封闭」免掉整个第三步验证——判断范畴是否
   满子范畴比算极限便宜得多。
5. 中介映射保结构的验证永远是「逐点取分量」一次推理——
   4.6 三例（Set^D/Eqv/Set-R）的证明逐行同构，背下骨架即可。
