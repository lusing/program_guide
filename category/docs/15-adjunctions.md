# 15 伴随的三副面孔

> 对书：贺伟 3.1 /《高级范畴论》5.2–5.4 / Simmons 5.1。代码：`examples/15_adjunctions/`。

伴随 F ⊣ G 的三副面孔：**hom-双射** / **泛映射** / **单位-余单位**。机器内容：Adjunction record（η/ε 分量族 + 自然性 + 三角恒等式，分量内联免 NT record 的依赖字段问题）+ hom-双射两个方向 φ/ψ + 往返等式 ψ(φ f) = f（零公理，五步追图：Fcomp 并 → assoc 拆 → ε 自然性 → assoc 并 → 三角恒等式 → idL）。

往返 2（φ(ψ g) = g）对称地用 η 自然性 + tri2。三面孔的完整等价证明需要 NT 基础设施 + 选择公理——文档层记录（贺伟 3.1 的三条路线对照表）。

## 15.1 换位演算：Table 5.1 的四条自然性（Simmons 5.1）

hom-双射 φ/ψ 不是孤立的集合等式——它在**两个变量上各自
自然**。把 φ 的输入沿 C 的箭头 k、输出沿 D 的箭头 l 挪动，
得到四种组合（书 Table 5.1 的 (♯↑)/(♯↓)/(♭↑)/(♭↓)）：

```text
g : FA → B  ──(l ∘ g)──→  l∘g : FA → B′   ⟹ φ(l∘g) = G(l) ∘ φ(g)
g : FA → B  ──(g ∘ Fk)──→  g∘Fk : FA′ → B  ⟹ φ(g∘Fk) = φ(g) ∘ k
```

（ψ 的两条反向同形。）口诀：**φ 把 D 侧的复合搬进 G、把
F 侧的复合搬出去**。这不是新公理——由 φ 的定义
`φ(g) = ε_B ∘ F(g)` 加两个自然性直接算出；但在实用中，
Table 5.1 是伴随代数的「乘法表」：验证任何伴随等式先查表、
再用三角恒等式收尾。15 章机器版的 `adj_round1` 五步追图，
本质就是这张表的一列。

**换位是双向的记号纪律**：f♭ 的输入必须是「F 打头」的箭头
（`FA → B` 型），g♯ 的输入必须是「G 打尾」的箭头——类型系统
免费执行了「什么能换、什么不能换」。这也是 26 章（反变伴随
curry-and-chips）的预告：那里的「双向」跨的是两个变量簇。

## 15.2 三个样板间（Simmons 5.2）

书里给的三组实例覆盖三种典型口味：

- **代数味**（5.2.1）：`Set[X, UA] ≅ Inv[ΣX, A]`——X × Σ 上
  的「逆系统」（Inv）与 A 上的代数结构互相翻译。左边的 f
  是裸函数、右边 ψ 是保结构映射；♯ = 沿分量配对、♭ = 取第
  零分量。25 章 Σ ⊣ U 的雏形；
- **集合味**（5.2.2）：幂集对 `(∃ ⊣ I)` 的雏形——24 章把它
  推广到截面格；
- **拓扑味**（5.2.3）：Stone 型对偶的雏形——26 章 ⇑/⇓/Ξ/Π
  的正式舞台。

三个样板的共同点：**伴随两边是「同一份数据的两种读法」**——
代数/组合、存在/全称、几何/代数。读法的切换保复合，这就是
自然性。

## 15.3 从解耦数据重建伴随（Simmons 5.3–5.4）

**解耦**（uncoupled）视角：别假设 G 已知。给定 F 与一族
「F-free 解」（每个 B 配 `η_B : B → U(FB)` 泛箭头），那么：

1. **G 在对象上被迫**：G(B) := 那个自由对象的载体；
2. **G 在箭头上被迫**：`G(l) := (l ∘ η_B)♯`——唯一分解；
3. η/ε、hom-双射、自然性**全部被唯一性挤出**——每个等式
   的证明都是「两个候选都满足同一组方程，故相等」。

5.4 的单位-余单位版本同构地换掉 η/ε 的角色：从 (η, ε) 满足
三角恒等式出发重建双射。**伴随没有「额外」的自由度**——
数据 = 泛解族，其余全是必然。这正是 16 章机器件的组织方式：
先造自由对象、再让泛性质自动长出右伴随。
