# 27 反变伴随：Sierpiński 的两副面孔

> 对书：Simmons 3.3.2（Spaces, presets, and posets）+ 5.6
> （Contravariant adjunctions）/《高级范畴论》1.8（对偶伴随）。
> 本章为文档章（机器化边界见 26.5）。

## 27.1 两个翻译器：⇑ 与 ⇓

预序（preset/poset）与拓扑空间（space）可以互相翻译，两个
方向各有一个函子（Simmons 3.3.3/3.3.4）：

```text
⇑ : Pre → Top     预序 A 配「上截面当开集」的拓扑（Alexandrov 拓扑）
⇓ : Top → Pre     空间 S 配「特殊化预序」：x ≤ y ⟺ x 的每个开邻域含 y
```

验证各一行：单调映射把上截面拉回上截面（⇑ 是函子）；连续映射
对特殊化预序单调（⇓ 是函子——因为开集原像保开）。**这两个
翻译器互不对逆**：⇑⇓ 把预序原样送回（A 的开集 = 上截面，
特殊化序还原 A ✓ 3.3.5 的 (a)），⇓⇑ 则把空间「Alexandrov 化」
——丢掉非 Alexandrov 的开集。**一对伴随式的近亲，不是等价**。

3.3.5 的定理一锤定音：两个 hom-集**逐函数相同**：

```text
Pre[A, ⇓S] = Top[⇑A, S]        （同一个函数集的两种读法）
```

⇑ 既左伴随又右伴随于 ⇓（对预序这种「瘦」场合，双侧伴随
退化成同一个函数集）。

## 27.2 Sierpiński 对象 2 与两个特征函子

单点升级：**Sierpiński空间** 2 = {0,1}，开集 {∅, {1}, {0,1}}
——「1 比 0 更开」。它住在两个世界里：

- 当拓扑空间：连续映射 `S → 2` 恰是**开集的特征函数**
  （p 连续 ⟺ p⁻¹{1} 开）——全体连续特征记 ΞS；
- 当预序：0 < 1，单调映射 `A → 2` 恰是**上截面的特征函数**。

于是两个「开集载体」都有了函子化读法（3.3.5/5.6.1(f)）：

```text
O S ≅ ΞS = Top[S, 2]        开集格 = 到 2 的连续映射（配点态序）
ΥA ≅ ΠA = Pos[A, 2]         上截面格 = 到 2 的单调映射（配点态序）
```

**一个对象 2，两副面孔，同时孕育两个反变函子**——Simmons
称之为 **schizophrenic object**（精神分裂对象；对偶对象的
标准造法）。O ≅ Ξ 与 Υ ≅ Π 都是**格同构**（3.3.7 给了完整
证明：χS 单调双射，序保持逐点核对）。

## 27.3 反变伴随：Pos[A, OS] ≅ Top[S, ΥA]（Simmons 5.6.1）

两个反变函子配成**反变伴随**：不是 hom-双射而是
**两个方向的 hom-集合互换**：

```text
Pos[A, O S] ≅ Top[S, Υ A]
   f  ↦  fσ        fσ(s) = {a | s ∈ f(a)}     （a 进「s 的解释」）
   φα  ↦  f        φα(a) = {s | a ∈ φ(s)}     （s 进「a 的解释」）
```

**两份 curry**：把 f : A → OS（curry 后是 A×S → 2）与
φ : S → ΥA（S×A → 2）配对——**交换两个输入的次序**就互相
翻译（5.6.2 的名句：*curry and chips*）。往返验证（5.6.1(d)）
是经典的「取补再取补」：

```text
fσα(a) = {s | a ∈ fσ(s)} = {s | s ∈ f(a)} = f(a)
φασ(s) = {a | s ∈ φα(a)} = {a | s ∈ φ(s)} = φ(s)
```

fσ 连续性：`fσ⁻¹⟨a⟩ = f(a₁) ∩ ... ∩ f(aₘ)`（基元素的原像是
有限交）；φα 单调性同款。**单位与余单位**（5.6.1(e)）：

```text
η_A(a) = ⟨{a}⟩      （主上截面的特征）       A → ΥΠA = Pos[A,2] 特征的特征
η_S(s) = s 的开邻域集                       S → OΞS
```

η_S 连续 = 「有限交开」；η_A 单调 = 「↑ 反单调取补回正」——
25 章两个完备化的单位在这里**合体成同一个伴随的两条单位律**。

## 27.4 这个伴随吃什么：六个定理的收成

反变伴随把 16 章的整套机器反着运转（RAPL 的反变版）：

| 定理 | 收成 |
|---|---|
| O 保极限（反变 = 保余极限） | 开集对**任意并**、有限交封闭——拓扑公理是伴随的免费午餐 |
| Υ 同款 | 上截面格完备 |
| Ξ/Π 同构 | 「开集」与「连续特征」可互换——层论的标准做法 |
| 单位是单射 | S 嵌入 OΞS（ sober 化的起点）、A 嵌入 ΥΠA（25 章完备化） |
| 特殊化序可逆 | T₁ 空间 ⇔ 特殊化序离散（「点不分高低」）|
| Alexandrov 子范畴 | ⇑⇓ ≅ Id 的固定点 = Alexandrov 空间 = 预序的化身 |

最后两行连接 28 章：**层论 = 在 OS 格上做 25 章的截面演算**；
拓扑斯的逻辑（Heyting 代数）从 O 的格结构里长出来。

## 27.5 机器化边界（诚实清单）

本章停在设计文档层的三个原因：

1. Top 的机器化要「开集族」为数据（拓扑不必可数），hom-集
   的连续性判定不可判定化——需要限定到**有限拓扑**才有穷尽
   验证（一个 3 点空间有 29 种拓扑——枚举本身已是练习）；
2. 反变伴随的 NT 基建撞 06 章的老墙（record 相等三文化）；
3. fσ/φα 的往返在集合层是纯粹的像/原像交换——05 章幂集三
   函子的机器件已覆盖其内核。

延伸路线（给未来的批次）：限定 S 为 2 点空间、A 为 2 点链，
Ξ/Υ 退化为 4 元布尔格——**可判定的反变伴随玩具**，全部
查表。这是 28 章层的粘合条件在同一个小舞台上的预演。

## 坑位速记

1. 特殊化序方向：x ≤ y 定义为「x 的开邻域 ⊇ y 所在开集」
   ——T₀ 反对称、T₁ 离散；写反了 ⇓ 的单调性就崩。
2. Υ 的元素是**上**截面、O 的元素是开集——反变伴随两侧的
   「格方向」相反（一侧并、一侧交），RAPL 反变版的收获
   全靠这处对齐。
3. fσ 的连续性核对要走**基**（有限交），不是逐开集——
   Alexandrov 化后才能逐点。
4. schizophrenic 对象是「一个对象、两个范畴的成员资格」——
   别把它当成两个对象的简写：正是「同一性」给出自然双射。
