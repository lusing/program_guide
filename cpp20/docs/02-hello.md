# 02 · 第一个程序：从源码到 exe

> 对应示例：`examples/02_hello/`

## 2.1 最小的程序：main 与返回值

```cpp
int main() {
    // ═══ 2.1 最小的程序：main 与返回值 ═══
    std::println("你好，C++23！");  // println 自动换行
    // ……
    // ═══ 2.4 退出码：0 表示成功 ═══
    return 0;  // 脚本/CI 按退出码判断成败
}
```

四件事钉死：`main` 是程序入口，签名就是 `int main()`；返回 `int`，**0 表示成功、非零表示失败**——CI 脚本、build.ps1 都靠这个判断；`return 0;` 可以省略（main 特例，编译器自动补），但教程里显式写出来；花括号换行风格随团队，本教程用 K&R（`{` 不换行）。

示例源码里的 `// ═══ N.M 小节名 ═══` 分节注释是本教程的**导航系统**：N.M 与本章小节号一一对应，代码和文档互相对照着看。

## 2.2 std::print / std::println：占位符格式化

C++23 之前，输出是 C++ 最尴尬的角落：`printf` 类型不安全、`cout` 冗长。**`<print>` 一锤定音**：

```cpp
std::print("姓名：{}，年龄：{}\n", "阿 C", 25);
std::print("编号 {:03}，PI ≈ {:.2f}\n", 7, 3.14159);
std::print("{:*^24}\n", "居中标题");  // 填充对齐
```

`{}` 是占位符，参数按顺序填入。花括号里可以带**格式说明**（冒号后）：

| 写法 | 效果 | 说明 |
|---|---|---|
| `{}` | 默认 | 类型自己决定怎么显示 |
| `{:03}` | `007` | 宽度 3，前补零 |
| `{:.2f}` | `3.14` | 定点小数 2 位 |
| `{:*^24}` | `*******居中标题*******` | 填充 `*`、居中、宽 24 |
| `{:>10}` / `{:<10}` | 右/左对齐宽度 10 | 报表对齐 |

`std::println` = `std::print` + 自动换行，**优先用它**，忘 `\n` 的经典 bug 从此消失。第 22 章有完整格式说明书。

## 2.3 老朋友 iostream：认得即可

```cpp
std::cout << "iostream 也能输出："
          << "int " << 42 << "，double " << 3.14 << "\n";
```

二十年存量代码里 `std::cout` 遍地都是：`<<` 把数据"推"进流，可以链式。新代码用 `print`（更短、类型安全、格式化能力强），但**读旧代码**必须认识 cout。混用注意：两者的缓冲独立，交错输出可能乱序，调试期用 `std::endl`（带刷新）或干脆别混。

## 2.4 亲手编译一次

build.ps1 一键搞定，但第一次必须手工走一遍，理解它替你做了什么：

```bash
cd /g/code/guide/cpp20/examples/02_hello
# 进入 VS 编译环境（设置 PATH/INCLUDE/LIB），然后编译
cat > /tmp/cc.bat << 'EOF'
@echo off
call "G:\Program Files\Microsoft Visual Studio\18\Community\VC\Auxiliary\Build\vcvars64.bat" >nul
cl /nologo /std:c++latest /EHsc /utf-8 /permissive- /Zc:__cplusplus /W4 /Fe:demo.exe main.cpp
EOF
cmd //c "$(cygpath -w /tmp/cc.bat)" && ./demo.exe
```

三步：`vcvars64.bat` 把编译器请进命令行（否则 `cl` 找不到）；`cl … main.cpp` 编译+链接出 `demo.exe`；运行。**C++ 的"运行"永远比解释型语言多一步构建**——改代码后要重新编译才能看到效果，这是节奏上的最大不适应。

参数含义见[第 01 章](01-overview.md)工具链一节。中文正常显示的前提：源文件存成 UTF-8（`/utf-8` 参数配合），控制台 `chcp 65001`（build.ps1 已代设）。

## 2.5 注释与源码组织

```cpp
// 单行注释到行尾
/* 块注释，可以
   跨行 */
```

单文件能写到几千行，但真实项目按**翻译单元**拆分：一个 .cpp 一个单元，声明进头文件（第 18 章展开，C++20 还有新玩具"模块"）。教程的示例都刻意单文件（模块章除外），让你聚焦语言本身。

## 2.6 坑位清单

1. **忘分号**：`std::println("hi")` 少写 `;`，报错指向**下一行**——C++ 编译器读到别处才发现断了。报错行号是"发现处"不是"肇事处"。
2. **全角符号混入**：中文输入法的 `；`、`"`、`（）` 看着一样，编译器当垃圾字符。报" strange character"类错误先检查这个。
3. **`std::` 前缀丢了**：`print(...)` 报"找不到标识符"。教程不使用 `using namespace std;`（污染命名空间，大项目雷区），所有标准库名字带全前缀——多打五个字符，换全局清晰。
4. **双击 exe 闪退**：控制台程序跑完即关。在终端里运行它，而不是资源管理器双击。
5. **print 里 `{` 字面量**：想打印花括号本身要 `{{` / `}}` 转义。
