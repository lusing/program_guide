# 03 · 类型与变量：把数据放进盒子里

> 对应示例：`examples/03_types/`

## 3.1 基本类型与固定宽度整数

C++ 的基本类型贴着硬件：**类型 = 宽度 + 解释方式**。示例输出直接回答"多宽"：

```cpp
std::print("int {} 字节，double {} 字节，char {} 字节\n",
           sizeof(int), sizeof(double), sizeof(char));
// 本机输出：int 4 字节，double 8 字节，char 1 字节
```

| 类型 | 典型宽度 | 字面量 | 备注 |
|---|---|---|---|
| `int` | 4 字节 | `42` | 默认整数选择；本机范围约 ±21 亿 |
| `double` | 8 字节 | `3.14` | 默认浮点选择（`float` 只在省内存/传 C 接口时用） |
| `char` | 1 字节 | `'A'` | 单引号是字符，双引号是字符串（第 06 章） |
| `bool` | 1 字节 | `true` | print 输出 `true`/`false`（不是 1/0） |
| `std::int64_t` | 固定 8 字节 | `9000000000LL` | **固定宽度**：`<cstdint>` 还有 int8/16/32_t 及无符号版 |

`int` 的"至少 16 位"是标准给的底线，实际宽度随平台。跨平台、要精确宽度时用 `<cstdint>` 的 `int32_t`/`int64_t`——**别猜，写死**：

```cpp
std::int32_t exact = 1'000'000;      // 固定宽度：不猜平台
std::int64_t big = 9'000'000'000LL;  // LL 后缀：字面量也得是 64 位
```

`9'000'000'000` 超出 int 范围，**不加 `LL` 后缀会怎样**？字面量会被编译器按能装下它的最小类型处理，但混入 int 参与的表达式时仍可能先按 int 截断。规则：大字面量配大后缀，让类型从字面量这层就正确。

整数没有"任意精度"版本——溢出就是 UB（见本章坑位）。真需要大数运算时用专门的库，或换语言。

## 3.2 整数字面量：进制与分隔符

```cpp
auto bin = 0b1010;  // 二进制 10
auto hex = 0xFF;    // 十六进制 255
auto grouped = 1'234'567;
// 输出：bin=10 hex=255 grouped=1234567
```

`0b`/`0x` 前缀换进制；**数字分隔符 `'`**（C++14）纯为可读性，位掩码和大数是它的主场：`0b1010'0001` 一眼看出两组，`1'234'567'890` 不用数零。浮点后缀 `f`（`3.0f` → float）、`L`（long double）；**无后缀小数字面量一律 double**——想当然写 `auto x = 0.5;` 以为省内存的 float，其实拿了 double。

## 3.3 auto：让编译器推导

```cpp
auto count = 42;    // int
auto ratio = 0.5;   // double（不是 float！）
auto letter = 'Z';  // char
// 输出：42 0.5 Z
```

`auto` 是**编译期类型推断**（同 C# 的 var 思路），运行期零开销、类型一经推断钉死。判型口诀：整数字面量→int，带小数点→double，单引号→char，双引号→`const char*`（C 风格字符串——见了 `auto s = "hi";` 要警觉，字符串请用 std::string，第 06 章）。

使用准则：右侧类型一目了然就用 auto（少噪音）；右侧看不出类型（复杂表达式、模板返回值）写显式类型，替读者省一次心智解析。auto **不是**动态类型——`auto x = 42; x = "hi";` 编译错误，它只是"替你写类型名"。

## 3.4 初始化三种写法与 narrowing

C++ 有三种初始化，这不是历史包袱大赛，认清主力即可：

```cpp
int a = 10;    // 拷贝初始化
int b(10);     // 直接初始化
int c{10};     // 列表初始化：不允许窄化
double d = 3;  // 隐式转换：可以，但 {} 会拦
// int bad{3.14};  // 编译错误：double → int 是 narrowing——{} 帮你把关
```

**本教程约定：新代码一律 `{}`**。理由就是那行被注释掉的 `bad{3.14}`：`=` 会静默截断（3.14 变 3），`{}` 直接编译报错——把"精度悄悄丢失"这类 bug 拦在构建期。现代 C++ 的重要口味：**能在编译期炸的错误，绝不留到运行期**。三种写法在简单类型上等价，差异在自定义类型上才展开（第 08 章构造函数）。

## 3.5 constexpr：编译期就定下来的值

```cpp
constexpr double tau = 2.0 * std::numbers::pi;  // <numbers> (C++20)
constexpr int months = 12;
int weekly[months]{};  // C 数组长度须是编译期常量（数组详见第 06 章）
weekly[0] = 1;
static_assert(months == 12);  // 编译期断言：免费的单测
```

`constexpr` 变量 = "我保证这个值编译期就能算出来"，编译器于是把它当常量折叠进指令。三大用处：C 数组长度（如上）、模板参数（第 13 章）、`static_assert`——**编译期断言**，条件不满足直接构建失败，比运行时 assert 更早一步、且零运行成本。违反保证（拿运行期值初始化 constexpr）会得到干脆的编译错误。

`std::numbers::pi`（C++20 `<numbers>`）是标准库数学常数家族（还有 e、sqrt2 等），别再手写 3.14159。`int weekly[months]{}` 末尾的 `{}` 是"全部零初始化"——不留未初始化内存。

变量默认在栈上、离开作用域自动销毁——这是 C++ 内存故事的开头，完整的心智模型在第 08 章 RAII 建立。

## 3.6 类型转换：只写 static_cast

```cpp
double pi = 3.14;
int approx = static_cast<int>(pi);  // 显式转换：意图清楚，3
int bad = (int)pi;                  // C 风格：能编译，但什么都转，禁用
int also_bad = pi;                  // 隐式截断：/W4 警告伺候
```

规则一句话：**转换必写 `static_cast<T>`，一眼可见、一处一查**。C 风格 `(int)` 什么危险转换都敢做（连"把指针 reinterpret 成别的类型"都放行），`static_cast` 在编译期就限定在"合理的转换"范围内。隐式加宽（`double d = 3;`）安全放行；隐式窄化（`int i = 3.14;`）被 /W4 点名。

## 3.7 坑位清单

1. **整数溢出是 UB（未定义行为）**：`INT_MAX + 1` 不抛异常、不回绕，编译器可以直接假设它不发生并据此优化出诡异结果。会溢出的运算用 `int64_t` 接住，或运算前检查。
2. **`5 / 2 == 2`**：整数除法截断。要小数，先让一侧变浮点：`5.0 / 2`。
3. **有符号/无符号比较**：`vector.size()` 返回无符号数，`for (int i = 0; i < v.size(); ++i)` 在 /W4 下告警（C4018）；倒序无符号循环 `for (size_t i = v.size()-1; i >= 0; --i)` 是**死循环**（无符号永远 ≥0）。倒序遍历用迭代器或 ranges 的 reverse 视图（第 12 章）。
4. **读未初始化变量是 UB**：`int x; std::println("{}", x);` 输出随机值还算走运。声明时就初始化——`int x{};` 给零值兜底。
5. **`char` 有无符号看平台**：直接存 UTF-8 字节（≥0x80）时，`char` 在 MSVC 是有符号的、比较会出负数。处理原始字节用 `unsigned char` / `std::byte`——第 22 章编码节会再遇到它。
6. **`0.1 + 0.2 != 0.3`**：二进制浮点表示误差，判相等用容差（`std::abs(a-b) < 1e-9`）；钱不能用 double 精确表示，C++ 没有 decimal 内建类型，金融场景用整数"分"+定标或专门库。
