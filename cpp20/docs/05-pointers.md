# 05 · 指针与引用：地址、解引用与 new/delete

> 对应示例：`examples/05_pointers/`

## 5.1 指针 = 存地址的变量

```cpp
int count{42};
int* pcount{&count};   // “pointer to int”：只能存 int 的地址
*pcount = 7;           // 解引用：改的就是 count 本尊
int* pnull{nullptr};   // “什么都不指”的固定写法
```

`&` 是**取地址**，`*` 是**解引用**（间接访问）。指针是"类型化的地址"：`int*` 只能存 int 的地址——知道地址还不够，还得知道那块内存**按什么类型解释**，所以指针带类型。三条纪律从第一天起立好：

1. **定义指针必初始化**（暂时没目标就 `nullptr`）——未初始化指针比未初始化变量危险一个量级；
2. **解引用前必保证非空**（`if (p != nullptr)` 或确保约定非空）；
3. 所有指针一样宽（存的是地址而非数据）：`sizeof(double*) == sizeof(char*)`，与指向类型无关——示例里 8 / 8。

`std::print` 家族不接受任意指针参数，要看地址得 `static_cast<void*>(p)`（教学调试用；真实输出地址会让程序输出不可复现，本教程示例从不打印地址）。

## 5.2 const 组合拳：右到左读

```cpp
const int* ptr_to_const{&value};   // 指向常量的指针：数据只读，指针可换目标
int* const const_ptr{&value};      // 常量指针：指针只读，数据可改
// const int* const 两者都只读
```

三种组合一张表（读法：**从右往左**，见到 `*` 念"pointer to"）：

| 声明 | 数据可改吗 | 指针可换目标吗 | 像 |
|---|---|---|---|
| `const int* p` | ❌ | ✅ | string_view 的味道 |
| `int* const p` | ✅ | ❌ | **引用的本质** |
| `const int* const p` | ❌ | ❌ | const 引用 |

const 只能**加强**不能削弱：`const int` 的地址可以交给 `const int*`，但不能交给 `int*`——否则常量就能被绕道改掉。

## 5.3 指针与数组：退化与指针算术

```cpp
int data[5]{2, 4, 6, 8, 10};
int* p{data};                        // 数组名退化为首元素地址（&data[0]）
std::println("{}", p[2]);            // 10 —— p[2] 就是 *(p + 2)
++p;                                 // 前进“一个元素”（4 字节），不是 1 字节
std::println("{}", p1 - p2);         // 指针相减 = 元素个数（类型 std::ptrdiff_t）
```

数组名在表达式里**退化成指针**，于是下标与指针算术等价：`p[i]` ≡ `*(p + i)`。指针算术按**元素宽度**跳（`int*` + 1 前进 sizeof(int)），这正是"指针带类型"的第二个理由。两个高频坑：

- `*p + 1` 是"取值再加 1"，`*(p + 1)` 才是"移一格再取值"——优先级使然，混用时永远加括号；
- 指针可以走出数组边界（语言不拦你，解引用即 UB）——遍历用 range-for 或带 size 的容器，别玩裸指针走钢丝。

## 5.4 对象指针：`->` 是 `. `的指针版

```cpp
Session s{"登录"};
Session* ps{&s};
std::println("{}", ps->name);        // 等价 (*ps).name——括号必须写，. 优先级更高
std::vector<int>* pv{&v};
pv->push_back(4);                    // 指针调成员函数同样用 ->
```

`->`（箭头/间接成员选择）是"先解引用再取成员"的合写。智能指针（第 13 章）也用 `->`——你现在就知道为什么了：它们是"包着裸指针的对象"。`auto*` 顺手记：`auto* p = &x;` 声明"这一定是个指针"，用别的类型初始化直接编译错。

## 5.5 堆与 new/delete：对象活得比作用域久

```cpp
double* pd{new double{3.14}};        // 自由存储上造对象，返回地址
delete pd;                           // 用完必须还
pd = nullptr;                        // 还完置空——防悬垂的基本纪律

int* arr{new int[4]{1, 2, 3, 4}};    // 动态数组：长度可以运行期才定
delete[] arr;                        // new[] 必配 delete[]
```

栈对象的生死跟着作用域走，但有些对象必须活得久（容器要能长大、返回值要活得比函数久）。C++ 的答案是**自由存储**（free store，俗称堆）：`new` 申请、`delete` 归还。四条配对铁律：**每个 `new` 恰好一次 `delete`，每个 `new[]` 恰好一次 `delete[]`**——混配、双删、漏删全是未定义行为。

裸指针管理堆的四大经典事故，每一个都在真实项目里烧过钱：

| 事故 | 代码长相 | 后果 |
|---|---|---|
| **泄漏** | `new` 了忘 `delete` | 内存缓慢流失，跑一周 OOM |
| **悬垂** | `delete` 后继续用 | UB：读垃圾/崩溃 |
| **双删** | 两处 `delete` 同一指针 | 堆结构破坏，随机崩 |
| **混配** | `new[]` 配 `delete` | UB（多数实现直接损坏堆） |

`delete p` 之后 p 还存着旧地址（dangling pointer）——**delete 完立刻置 nullptr**，且 `delete nullptr` 无害，不用 if 包。C++20 的 `std::make_unique_for_overwrite` 这类"不置零"变体属于性能特化，用到再查。

## 5.6 引用：必然绑定、永不换绑的别名

```cpp
int n{5};
int& ref{n};      // 出生起就是 n 的别名
ref = 8;          // 给 n 赋 8
int m{20};
ref = m;          // 仍是给 n 赋值（n 变 20）——引用不能换绑！
```

引用与指针的差异，一张表钉死：

| | 指针 `T*` | 引用 `T&` |
|---|---|---|
| 可以为空 | ✅ `nullptr` | ❌ 必然绑定 |
| 可以换目标 | ✅ `p = &other` | ❌ 终身别名 |
| 需要解引用语法 | `*p` / `p->` | 不用，当普通变量用 |
| 可以重设/做算术 | ✅ | ❌ |
| 心智模型 | 可空的地址 | **永不换绑的 const 指针的语法糖** |

`ref = m` 不换绑而是赋值——这是从 C 过来的程序员最容易栽的一跤。函数参数选型回扣第 06 章：要"可能没有"用指针（或 optional），要"必然有且要改"用引用，要"只读不拷"用 const 引用。值类别与 `T&&`（右值引用）是第 22 章移动语义的主角，本章按下。

## 5.7 黄金法则：不写裸 new/delete

书里最值钱的一条建议直接抄给你：**日常代码永远不直接使用 `new`/`new[]`/`delete`/`delete[]`**。替代品只有两个——

- 动态数组 → `std::vector`（第 14 章）；
- 单个对象 → 智能指针 `make_unique` / `make_shared`（第 13 章）。

学 new/delete 不是为了用，是为了**读得懂存量代码、修得了它们的 bug**（修法往往就是重写成 vector/智能指针）。本教程只在 13 章的"为什么还要 new/delete"一节再回望一次。

## 5.8 坑位清单

1. **未初始化指针**：`int* p;` 里是随机地址，解引用即 UB——声明即 `nullptr`。
2. **delete 后不置空**：悬垂指针继续被用是 UB；`delete p; p = nullptr;` 连写。
3. **new[] 配 delete**（无 `[]`）：编译器不报错，运行期堆损坏——配对纪律背下来。
4. **返回局部变量的地址/引用**：函数返回即销毁，指针悬垂——按值返回（有 RVO，第 22 章）。
5. **`long* p, number;` 声明两个"指针"**：星号只跟第一个变量——一行只声明一个变量。
6. **指针走出数组边界**：`p + n` 本身合法，解引用越界是 UB——边界自己管。
7. **用 `==` 比较指针指向的内容**：`p1 == p2` 比的是**地址**不是值；比内容用 `*p1 == *p2`。
