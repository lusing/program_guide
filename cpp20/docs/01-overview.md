# 01 · C++ 全景：一门不断进化的语言

> 本章无独立示例，代码引用 `examples/02_hello/`。

## 1.1 C++ 是什么

C++ 是一门**编译型、静态类型、多范式**的系统级语言：既能贴着硬件写（内存布局、位运算、无 GC 暂停），又能搭出高层的抽象（类、模板、概念）。它被用来造操作系统、游戏引擎、数据库、浏览器——以及如今的大模型推理框架。

代价是**语言复杂、坑多**。本教程的态度：教"现代子集"——C++20/23 的惯用写法（`std::print`、智能指针、ranges、concepts），老式写法（裸 new、printf、char* 手工管理）只在"认得旧代码"的最低限度内出现。你已经会编程，所以重点不是"什么是循环"，而是**C++ 与你熟悉的语言在思维上的差异**。

## 1.2 编译模型：先懂这个，再写代码

用 Python/JS 的经验直接套 C++ 会处处别扭，根子在执行模型：

| | 解释型（Python） | 编译型（C++） |
|---|---|---|
| 运行前 | 直接跑源码 | 源码 → **编译** → 目标文件 → **链接** → exe |
| 类型检查 | 运行时 | **编译期**（错误在构建阶段暴露） |
| 依赖 | import 时找模块 | 编译期看声明（头文件/模块），链接期找实现 |
| 部署 | 带解释器 | 一个 exe（基本自包含） |

C++ 的一个**翻译单元**（translation unit，基本等于一个 .cpp 文件）单独编译成目标文件（.obj），链接器再把多个 .obj 缝成可执行文件。"声明与定义分离"、"头文件"、"模板要看得见实现"这些 C++ 特色规则，全部源于这个模型——第 18 章会正面展开，现在先有这张图。

## 1.3 标准演进：98 → 23

C++ 每三年发一版标准，**C++11 是现代 C++ 的分水岭**（auto、智能指针、lambda、移动语义都从这来），C++20 是第二次大跃进：

| 标准 | 关键词 | 一句话 |
|---|---|---|
| C++98/03 | STL、类 | 最初的面向对象 + 泛型 |
| **C++11** | auto、unique_ptr、lambda、range-for、move | "现代 C++"开始 |
| C++14/17 | 结构化绑定、if 初始化、optional/string_view | 打磨补齐 |
| **C++20** | **concepts、ranges、协程、模块、spaceship** | 四大件 + 格式化库 |
| **C++23** | **print、expected、generator、flat_map、mdspan** | 库层面的现代化 |
| C++26 | 反射（草案） | 展望，本教程一句话带过 |

本教程以 **C++23 为运行基线**（编译开关 `/std:c++latest`），凡是 C++20/23 的新特性都会标注版本；没标注的就是"很久以前就有"。

## 1.4 编译器与工具链

三大主流编译器：

| 编译器 | 厂商 | Windows 入口 | 备注 |
|---|---|---|---|
| **MSVC** (`cl`) | Microsoft | VS 开发者命令行 | 本教程主线，C++23 库支持最全之一 |
| GCC (`g++`) | GNU | MinGW/WSL | Linux 默认，`-std=c++23` |
| Clang (`clang++`) | LLVM | LLVM 官方包 | 错误信息最友好 |

各家对最新标准的**库特性**支持有先后差（比如某个 C++23 特性 MSVC 有了、GCC 还没有）。具体矩阵不背——查 [cppreference 编译器支持页](https://en.cppreference.com/w/cpp/compiler_support)，以本机实测为准。第 23 章会集中讲跨编译器差异与 CMake。

本教程工具链（`build.ps1` 已内置）：

```
cl /nologo /std:c++latest /EHsc /utf-8 /permissive- /Zc:__cplusplus /W4 文件.cpp
```

参数速记：`/std:c++latest` 最新语言标准；`/EHsc` C++ 异常；`/utf-8` 源码按 UTF-8（中文必需）；`/permissive-` 严格一致性（拒绝老式歧义代码）；`/W4` 高级别警告——**本教程要求零告警**，警告就是没写干净的代码。

## 1.5 本教程的工作流

每章的学法固定三步：**读讲解 → 跑示例 → 改代码再跑**。

```bash
cd /g/code/guide/cpp20
"/g/Program Files/PowerShell/7/pwsh" -NoProfile -ExecutionPolicy Bypass -File build.ps1 -All       # 全部 23 个示例
"/g/Program Files/PowerShell/7/pwsh" -NoProfile -ExecutionPolicy Bypass -File build.ps1 -Example 12_ranges   # 单个示例
```

build.ps1 做三层验证：**编译（/W4 零告警）→ 运行（退出码 0）→ 示例内置 assert 自检**。示例不满足这三层就进不了仓库——你在文档里看到的每段代码都是真编译真跑过的。

直接双击/命令行运行 exe 时中文会乱码（控制台默认 GBK）：先 `chcp 65001`。经 build.ps1 运行无此问题（脚本已设 UTF-8）。

## 1.7 学习心态

- **C++ 是工具箱不是宗教**：过程式、面向对象、泛型、函数式都有。教程教你选现代惯用的那把。
- **遇到"为什么这么怪"，答案通常是历史兼容或性能**。接受它，用现代写法绕开它。
- **先学安全子集**：`std::string`/`vector`/智能指针/ranges 覆盖 90% 日常；指针运算、裸内存这些"著名 C++"内容，本教程刻意延后并少讲——需要时你会认出来的。
- 编译器报错是**队友不是敌人**：C++ 的错误信息长，是因为它在编译期替你挡掉了运行时炸雷。读报错的技巧会随章节推进穿插讲解。

## 1.8 坑位清单

1. **拿 C++98 时代的资料入门**：教程/博客里的 `new`/`delete`、`char*`、裸数组优先写法都是历史。识别标志：没有智能指针、没有 `auto`。本教程即 antidote。
2. **标准与编译器对不上**：代码用了 C++23 特性却用默认标准编译——报一堆"不认识"的错。先确认 `/std:c++latest`，再查 cppreference 支持矩阵。
3. **忽略警告**：/W4 的每条警告都是潜在 bug（未初始化、窄化、未用返回值）。教程铁律：零告警。
4. **中文乱码就怀疑代码**：先 `chcp 65001`，八成是控制台编码不是程序问题。
5. **跳章学并发/模板**：19–21 章押着前面所有章节的积累（RAII、移动、类型推导），跳过去只能抄不能懂。
