# 00 · 开始之前：Emacs 是什么、怎么启动

这一章把三件事讲清楚：Emacs 到底是个什么东西、怎么把它打开、以及怎么体面地退出。读完你就能开一个干净的 Emacs 跟着后面每一章敲。

## 0.1 Emacs 的四个特点

Emacs 官方给自己的定位是「先进的、自助文档的、可定制的、可扩展的」编辑器。这四个词不是营销话术，每一个都对应你日后会真实用到的能力，值得先建立直觉：

**先进（advanced）**——它远不止「插入和删除文本」。Emacs 的编辑命令是按**字符、单词、行、句子、段落、页面**这些文本单位来操作的，还能操作各种编程语言里的**表达式和注释**。除此之外它能控制子进程、自动给程序缩进、同屏显示多个文件、像编辑本地文件一样编辑远程文件。你会在后面的章节里逐一见到这些能力。

**自助文档（self-documenting）**——这是 Emacs 最该先学会利用的一点：任何时候你都能用「帮助命令」查出**当前有哪些选择**、**某个命令到底做什么**、**跟某个主题相关的所有命令**。也就是说，你不需要背下所有快捷键——忘了就当场问 Emacs。第 4 章专门讲这套帮助系统；这里先记住一个：`C-h t`（命令 `help-with-tutorial`）会打开 Emacs 自带的交互式入门教程。

**可定制（customizable）**——你可以用简单的方式改变 Emacs 命令的行为。举个例子：如果你用的编程语言注释以 `<**` 开头、以 `**>` 结尾，你可以告诉 Emacs 的注释命令改用这两个串；你也可以把上下左右的光标移动命令重新绑定到你觉得顺手的任意键上。第 20 章讲定制。

**可扩展（extensible）**——比定制更进一步：你可以用 Lisp 语言写出**全新的命令**，由 Emacs 内置的 Lisp 解释器运行。已有命令甚至能在一次编辑会话进行到一半时被重新定义，不必重启 Emacs。Emacs 里绝大多数编辑命令本身就是用 Lisp 写的。写扩展属于编程——这套仓库里另有一份 [Emacs 扩展开发指南](../extending-emacs/README.md) 专门讲它。本教程只讲**怎么用**，不要求你会写 Lisp。

## 0.2 本教程对应的版本

正文里所有按键、命令名、默认值都以 **GNU Emacs 31.1** 为准。Emacs 的默认绑定偶尔会随版本变化，遇到这类地方正文会当场点明。一个典型例子：切换缓冲区只读的键 `C-x C-q`，在较老的 Emacs 里绑的是 `toggle-read-only`，在 31.1 里绑的是 `read-only-mode`——功能一样，名字换了。你可以用 `M-x emacs-version RET` 查自己手上的版本。

## 0.3 启动 Emacs

在命令行里，最常用的启动方式就是敲：

```bash
emacs
```

如果你在一个跑着 Unix shell 的终端窗口里，想让 Emacs 在后台运行、把终端窗口留着干别的，就加个 `&`：

```bash
emacs &
```

启动后，第一个 frame（窗口框架）会显示一个名叫 `*GNU Emacs*` 的特殊 buffer，也就是「启动画面」。上面有关于 Emacs 的信息，还有一批给新手用的**链接**——比如激活「Emacs Tutorial」链接会打开入门教程，效果等同于命令 `C-h t`（`help-with-tutorial`）。激活链接有两种办法：把光标（point）移到链接上按 `RET`，或者用鼠标左键（`mouse-1`）点它。

你也可以在启动时就让 Emacs 访问某个文件：

```bash
emacs foo.txt
```

这会启动 Emacs 并让一个 buffer 显示 `foo.txt` 的内容。这个用法主要是为了跟其他「从 shell 里启动、做短编辑」的编辑器兼容。如果你这样调用，初始 frame 会被分成两个 window——一个显示你指定的文件，另一个显示启动画面。（frame 和 window 的区别见第 1 章和第 10 章。）

**不推荐每次编辑都重启 Emacs。** 推荐的做法是登录后只启动一次，然后整个会话里所有编辑都在这一个 Emacs 中进行。这样 Emacs 会积累起有价值的上下文——kill ring（剪切历史）、寄存器、撤销历史、mark ring——这些都让编辑更顺手。要在 Emacs 已经开着时从别的程序打开文件，可以用 `emacsclient` 这个辅助程序把文件送进现有的 Emacs 会话（第 22 章会讲 Emacs Server）。

### 练习用的「干净」Emacs

想在不影响自己已有配置的前提下练手，用 `-Q` 启动：

```bash
emacs -Q
```

`-Q` 表示**不加载任何个人配置文件、不加载任何第三方包**，得到的是一个「出厂设置」的 Emacs。本教程里说的默认键位，指的就是这种干净状态下的绑定——所以跟着练时用 `emacs -Q` 最能对得上。

## 0.4 退出与挂起

**退出 Emacs** 用 `C-x C-c`（命令 `save-buffers-kill-terminal`）。它不是简单地把窗口关掉：如果有 buffer 被改过、还没保存，Emacs 会先逐个问你要不要保存，都处理完了才真正退出。这个「先兜住你的改动再走」的行为，正是它跟直接关窗口的区别——所以你几乎不会因为手滑关掉 Emacs 而丢数据。

如果你并不想保存某个被改动的 buffer，可以在它提问时回答 `n`（不保存）；提问的细节见第 5 章的「yes-or-no 提示」。

**挂起 Emacs**（让它暂时让出终端、之后再回到原样）用 `C-z`（命令 `suspend-frame`）。这在纯文本终端下特别有用：挂起后你回到 shell，用 shell 的 `fg` 命令再回到 Emacs。在图形界面下，`C-z` 通常是把这个 frame 最小化/隐藏，而不是退回 shell。

## 0.5 一个随时能救命的键：`C-g`

在正式学各种命令之前，先记住这一个：`C-g`（命令 `keyboard-quit`）。

Emacs 是多步交互的——有时它会问你要参数、有时你在一个增量搜索里、有时你不小心按了个前缀键正等着后续输入。**任何时候你想取消当前正在进行的这件事、回到「什么都没在干」的稳定状态，就按 `C-g`。** 按一次不行就再按一次。它是你在 Emacs 里最可靠的「刹车」，后面每一章遇到需要中止的场景都会用到它。

## 0.6 先认识按键记法

后面的章节会大量出现 `C-x C-f`、`M-x`、`RET` 这类写法。这里先给一个够用的最小解释，第 2 章会展开：

- `C-x`：按住 **Control** 键，再按 `x`。
- `M-x`：按住 **Meta** 键再按 `x`。多数现代键盘上 Meta 就是 **Alt**；如果键盘没有 Meta，就先按 `ESC`、松开，再按 `x`（写作 `ESC x`，等价于 `M-x`）。
- `RET`：回车键（Return / Enter）。
- `SPC`：空格键。`DEL`：退格键。
- 多键序列如 `C-x C-f`：**连着按**——先按 `C-x`（按住 Control 敲 x），然后松开，再按 `C-f`。中间的 `C-x` 叫「前缀键」，Emacs 会等你接着按下一个键。
- `M-x find-file RET`：这表示按 `M-x`，然后在屏幕底部弹出的输入区里**输入** `find-file` 这几个字符，再按 `RET` 确认。这是「按名字调用命令」的通用写法，第 2 章详述。

## 0.7 小结

- Emacs 是先进、自助文档、可定制、可扩展的编辑器；忘了快捷键就当场问它（`C-h` 系列）。
- 用 `emacs` 启动，`emacs -Q` 启动一个不加载配置的干净实例来练手，`emacsclient` 往已开的会话里送文件。
- `C-x C-c` 退出（会先兜住未保存的改动），`C-z` 挂起。
- 卡住了、想取消当前操作：`C-g`。
