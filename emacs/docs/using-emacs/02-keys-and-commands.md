# 02 · 按键与命令

这一章讲 Emacs 怎么理解你敲的键。搞清楚「输入事件→键序列→命令」这条链路之后，你就不再是死记快捷键，而是理解为什么某个键做某件事、怎么找到没绑键的命令、怎么给命令传参数。

## 2.1 输入事件：Emacs 看到的最小单位

你按下的每一个键、每一次鼠标点击，在 Emacs 内部都是一个**输入事件**（input event）。普通字符（`a`、`B`、`3`）、控制字符（`RET`、`TAB`、`DEL`、`ESC`）、功能键（`<f1>`、`<Home>`、`<LEFT>`）、鼠标点击——这些都是输入事件。

Emacs 还能识别**修饰键**（modifier keys）组合：

- **Control**（键盘上通常标 `Ctrl`）：按住 Control 再按另一个键，写作 `C-字母`。例如 `C-a` 就是按住 Ctrl 敲 `a`。
- **Meta**（键盘上通常是 `Alt`）：按住 Meta 再按另一个键，写作 `M-字母`。例如 `M-a` 就是按住 Alt 敲 `a`。

修饰键也可以用在非字母键上：`C-<f1>`、`M-<LEFT>` 都是合法的。

Emacs 还支持另外三个修饰键（Super、Hyper、Alt 的额外用法），但日常编辑很少用到。

### 用 ESC 代替 Meta

如果你的键盘没有 Meta 键，或者在某些文本终端上 Meta 不好使，可以用两键序列代替：先按 `ESC` 松开，再按下一个字符。`ESC` 然后 `a` 等价于 `M-a`。`ESC` 然后 `C-a` 等价于 `C-M-a`。

注意：`ESC` 不是按住不放，而是**按一下松开**再按下一个键。这与按住 Meta 不放再按另一个键的效果相同。

### 图形界面的注意事项

在图形界面下，窗口管理器可能会拦截某些组合键，比如 `M-<TAB>`、`M-<SPC>`、`C-M-d`、`C-M-l`。遇到这种情况，要么修改窗口管理器的快捷键设置，要么在 Emacs 里重新绑定受影响的命令。

## 2.2 键序列：从输入事件到命令

一个或多个输入事件组成一个**键序列**（key sequence，简称「键」）。键序列分两种：

**完整键**（complete key）——能直接调用一个命令的键序列。例如 `C-f`（向前移一个字符）、`C-x C-f`（打开文件）、`C-x 4 C-f`（在另一个 window 打开文件）。

**前缀键**（prefix key）——还不够长、不能直接调用命令的键序列。它等着后面的输入来拼成更长的序列。例如 `C-x` 是前缀键：单独按 `C-x` 不会做任何事，Emacs 会等你按下一个键。`C-x` 加上 `C-f` 组成完整键 `C-x C-f`；`C-x` 加上 `4` 组成另一个前缀键 `C-x 4`。

**每个键序列非完整即前缀**——没有第三种情况。

前缀键可以叠加。例如 `C-x` 是前缀键，`C-x 4` 也是前缀键，`C-x 4 C-f` 才是完整键。实际使用中键序列很少超过三四个事件。

你不能在一个完整键后面继续追加事件。`C-f` 是完整键，所以 `C-f C-k` 是两个键序列，不是一个。

### 默认的前缀键

Emacs 31.1 默认的前缀键有：`C-c`、`C-h`（等价于 `<f1>`）、`C-x`、`C-x RET`、`C-x @`、`C-x a`、`C-x n`、`C-x r`、`C-x t`、`C-x v`、`C-x 4`、`C-x 5`、`C-x 6`（等价于 `<f2>`）、`ESC`、`M-g`。

**小技巧**：在任何前缀键后面按 `C-h` 或 `?`，Emacs 会列出该前缀键下所有可用的后续键和对应命令。唯一的例外是 `ESC`：`ESC C-h` 实际上等于 `C-M-h`（`mark-defun`），不是查帮助。对 `ESC` 前缀要用 `<f1>` 来查：`ESC <f1>`。

## 2.3 命令与键绑定

Emacs 并不直接给键赋予意义。Emacs 给**命令**（command）赋予意义，然后通过**键绑定**（key binding）把键映射到命令。

每个命令有一个名字，由程序员用英文单词加连字符命名，比如 `next-line`、`forward-word`、`find-file`。命令本质上是一种特殊的 Lisp 函数。

当你看到「`C-n` 向下移动一行」这种说法时，严格来讲：命令 `next-line` 做向下移动的事，`C-n` 只是碰巧绑定到了 `next-line`。如果你把 `C-n` 重新绑定到 `forward-word`，那 `C-n` 就会变成向前移一个单词。

键绑定记录在**键映射**（keymap）里。不同的模式有自己的键映射，多层映射叠加在一起决定了你按某个键时实际执行什么命令。

## 2.4 M-x：按名字调用命令

很多命令没有绑定到快捷键上——Emacs 有几千个命令，键不够用。但没有键绑定不代表不能用：**任何命令都可以按名字调用**。

方法是：`M-x`，输入命令名，`RET` 确认。

```
M-x forward-char RET
```

效果与 `C-f` 完全相同。`M-x` 会在 minibuffer 里显示 `M-x` 作为提示符，你输入命令名时可以用 **Tab 补全**——比如输入 `forw` 按 `TAB`，Emacs 会帮你补全成 `forward-`，再输入 `char RET` 即可。

`M-x` 本身绑定的命令叫 `execute-extended-command`。

### M-x 的几个细节

**补全时忽略过时命令**：在以前版本里标记为 obsolete 的命令不会出现在补全列表里（除非你输入它们的全名）。当前版本标记为 obsolete 的命令仍然会列出。

**过滤不相关命令**：你可以设置变量 `read-extended-command-predicate`，让补全自动排除与当前 buffer 的主模式和次模式无关的命令。默认不过滤。

**提示快捷键**：当你用 `M-x` 调用了一个有键绑定的命令时，Emacs 会在 echo area 告诉你「这个命令也可以用 `M-f` 来调用」。这个提示默认显示 2 秒。变量 `suggest-key-bindings` 控制这个行为：设为 `nil` 关闭，设为数字改变显示秒数。

**M-S-x**：与 `M-x` 类似，但只列出与当前主模式和启用的次模式相关的命令。

**取消**：按了 `M-x` 又不想执行了？`C-g` 取消。

## 2.5 数字参数（Prefix Argument）

你可以给任何命令一个**数字参数**（也叫前缀参数）。有些命令把数字参数当作重复次数：

- `C-f` 不带参数：向前移 1 个字符。
- `C-f` 带参数 10：向前移 10 个字符。

没有参数等价于参数 1。负数参数让命令反向操作。

### 方法一：M-数字

按住 Meta 敲数字键。`M-5 C-n` 向下移 5 行。`M--`（Meta 减号）表示负数。

多位数不需要一直按住 Meta：`M-5 0 C-n` 向下移 50 行——`M-5` 开始数字参数，后面的 `0` 自动被当作参数的一部分。

**注意**：`M-5 0 C-n` 不是在缓冲区里插入 5 个 `0` 然后向下移 1 行。`0` 被吸收进了前缀参数。如果你真的想插入 5 个 `0` 再执行命令，用 `M-5 C-u 0`——`C-u` 在这里的作用是「终止前缀参数，让后面的按键恢复正常」。

### 方法二：C-u（universal-argument）

`C-u`（`universal-argument`）后面跟数字或负号。`C-u 4 2 C-f` 向前移 42 个字符。`C-u - 3 C-n` 向上移 3 行。

**`C-u` 单独使用的特殊含义**：「乘以 4」。

- `C-u C-n`：向下移 4 行。
- `C-u C-u C-n`：向下移 16 行（4 × 4）。
- `C-u C-u C-f`：向前移 16 个字符。

这个「乘以 4」的用法在需要「比较大地」重复一个命令时很方便：`C-u C-n` 向下移一大截，`C-u C-k` 杀掉 4 行，`C-u C-u C-o` 插入 16 个空行。

### 方法三：C-数字（图形界面）

在图形界面下，`C-0`、`C-1` 等与 `M-0`、`M-1` 等效果相同，都可以用来输入数字参数。

### 参数对自插入字符的影响

数字参数也可以用在插入字符上：`C-u 6 4 a` 插入 64 个 `a`。但对于数字字符有个陷阱：`C-u 6 4 1` 会被解释为参数 641，而不是「参数 64 然后插入 `1`」。解决办法是用另一个 `C-u` 隔开：`C-u 6 4 C-u 1` 插入 64 个 `1`。

### 有些命令关心参数但不关心值

比如 `M-q`（`fill-paragraph`）排版段落；带参数时除了排版还会做两端对齐。这种情况下给一个 `C-u` 就够了。

### 有些命令在有无参数时行为不同

比如 `C-k`（`kill-line`）：带参数 N 杀掉 N 行（含换行符）；不带参数时行为特殊——杀掉从 point 到行尾的内容，如果 point 已经在行尾则杀掉换行符本身。

## 2.6 重复命令

### 用数字参数重复

很多简单命令可以把数字参数当重复次数用：`M-5 C-n` 向下移 5 行，`C-u 8 C-d` 删除 8 个字符。

但如果命令需要自己的输入（比如 `M-x` 后面的命令名），或者数字参数有别的含义，这种方法就不管用了。

### C-x z（repeat）

`C-x z`（`repeat`）重复上一个命令，使用与上次相同的参数。按一次 `C-x z` 重复一次；继续按 `z` 每次都再重复一次。按任何其他键结束重复。

例如：

```
C-u 2 0 C-d        ← 删除 20 个字符
C-x z z z          ← 再重复 3 次，共删除 80 个字符
```

`C-x z` 绑定的命令是 `repeat`。

### repeat-mode

`repeat-mode` 是一个全局次模式，开启后，某些多键命令在执行后进入一个短暂的重复状态：你只需按命令的最后一个键就能重复。

例如开启 `repeat-mode` 后：

- `C-x u`（撤销）之后，连续按 `u` 就能反复撤销，不用每次都按 `C-x`。
- `C-x o`（切换 window）之后，连续按 `o` 就能连续切换。

这些单键快捷方式会在 echo area 显示出来。按任何其他不在重复定义里的键就退出重复状态。

用 `M-x describe-repeat-maps RET` 可以查看哪些命令支持 `repeat-mode` 的重复。

变量 `repeat-exit-key` 可以设一个专门退出重复状态的键（比如设为 `RET`），按这个键只退出重复状态、不执行该键本身的功能。变量 `repeat-exit-timeout` 可以设一个空闲超时，若干秒不按键就自动退出重复状态。

## 2.7 其他输入方式

### 鼠标

Emacs 支持鼠标点击、拖拽、滚轮等输入。鼠标点击可以移动 point、选菜单、激活链接等。本教程不深入讲鼠标操作，但你应该知道鼠标也是输入事件的一种。

### 触摸屏与虚拟键盘

Emacs 也支持触摸屏和屏幕键盘的输入，但本教程不涉及这些场景。

## 2.8 键位记法速查

把前面散落的记法汇总一下，方便你随时查阅：

| 记法 | 含义 |
|------|------|
| `C-x` | 按住 Control 敲 `x` |
| `M-x` | 按住 Meta（Alt）敲 `x`；或先按 `ESC` 松开再按 `x` |
| `C-M-x` | 同时按住 Control 和 Meta 敲 `x`；或 `ESC` 然后 `C-x` |
| `RET` | 回车键（Return / Enter） |
| `SPC` | 空格键 |
| `DEL` | 退格键（Backspace） |
| `<f1>` | 功能键 F1 |
| `C-x C-f` | 先按 `C-x`（前缀键），再按 `C-f` |
| `M-x find-file RET` | 按 `M-x`，在 minibuffer 输入 `find-file`，按 `RET` 确认 |

## 2.9 小结

- 输入事件是 Emacs 看到的最小单位：字符、控制键、鼠标点击。
- 键序列是完整键（调用命令）或前缀键（等待后续输入）。
- 命令通过键绑定与键关联；同一命令可以绑到不同键上。
- `M-x 命令名 RET` 可以调用任何命令，不管有没有键绑定。
- 数字参数用 `M-数字`、`C-u 数字`、或 `C-u`（乘以 4）来指定。
- `C-x z` 重复上一个命令；`repeat-mode` 让某些命令支持单键重复。
