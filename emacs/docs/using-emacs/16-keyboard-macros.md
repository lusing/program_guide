# 16 · 键盘宏

键盘宏（Keyboard Macro）是 Emacs 里最被低估的功能之一。它的思想很简单：**把你按的键录下来，然后一键回放**。当你发现自己在重复同一组操作时——比如给每一行加前缀、在每张表格行里做同样的格式化——键盘宏就是最快的解决方案。

与 Lisp 扩展相比，键盘宏不需要写代码，录制过程就是你正常编辑的过程。缺点是它不够强大，不能写条件分支和循环。但在"重复做同一件事"这个场景里，它比任何方案都快。

## 16.1 录制与回放

Emacs 有两套键绑定来操作键盘宏：一套用功能键 `<F3>` / `<F4>`（推荐），一套用传统的 `C-x (` / `C-x )` 序列。两者操作的是同一个宏——只是键不同。

### 16.1.1 用功能键

| 键 | 命令 | 作用 |
|---|---|---|
| `<f3>` | `kmacro-start-macro-or-insert-counter` | 开始录制宏 |
| `<f4>` | `kmacro-end-or-call-macro` | 结束录制，或回放已录好的宏 |

录制过程：

1. 按 `<f3>`。mode line 上出现 `Def`，表示正在录制。
2. 执行你想重复的操作。你按的每个键都被记录下来，同时**也被执行**——所以你能实时看到效果。
3. 按 `<f4>` 结束录制。宏定义完毕，并且**立即回放一次**（因为录制时已经执行了一遍，所以效果是做了两次——这是正常的，下一节解释怎么避免）。

之后每次按 `<f4>` 都回放一次这个宏。给 `<f4>` 加数值参数可以回放多次：`C-u 10 <f4>` 回放 10 次。参数为 0 表示无限循环回放，直到出错或你按 `C-g`。

### 16.1.2 用传统键

| 键 | 命令 | 作用 |
|---|---|---|
| `C-x (` | `kmacro-start-macro` | 开始录制（旧式） |
| `C-x )` | `kmacro-end-macro` | 结束录制（旧式） |
| `C-x e` | `kmacro-end-and-call-macro` | 结束并立即回放 |

`C-x (` 开始录制，`C-x )` 结束录制。`C-x e` 结束并回放——如果你在录制中按 `C-x e`，它会先结束再回放。回放完按 `e` 可以再回放一次（不需要重新按 `C-x e`）。

`C-x )` 可以带数值参数——`C-u 4 C-x )` 在录制结束后立即回放 3 次（录制本身算第 1 次）。

### 16.1.3 一个具体例子

假设你有一个文件，每行都是一个名字，你想在每个名字后面加 `, OK`：

```
Alice
Bob
Charlie
```

录制宏：

```
<f3> C-e , SPC O K <f4>
```

这个宏做了：`C-e`（到行尾），然后输入 `, OK`。录制结束后光标在第二行。按 `<f4>` 回放，第二行也加上了 `, OK`。按 `C-u 5 <f4>` 对后面 5 行都做同样操作。

结果：

```
Alice, OK
Bob, OK
Charlie, OK
```

**要点**：如果你的操作需要先移动到正确位置再执行，把移动命令也录进宏里。宏回放时从当前光标位置开始，所以包含移动命令可以让宏在每一行都从正确的位置开始。

### 16.1.4 追加到已有宏

| 键 | 作用 |
|---|---|
| `C-u <f3>` | 回放已有宏，然后继续录制追加 |
| `C-u C-u <f3>` | 不回放，直接追加录制 |

`C-u <f3>` 等价于先按 `<f3>` 再重打一遍已有定义——所以它会先回放一次。如果你只想在末尾加几个键而不回放，用 `C-u C-u <f3>`。

变量 `kmacro-execute-before-append` 控制 `C-u <f3>` 的行为：默认 `t`（回放再追加），设为 `nil` 则只追加不回放。

## 16.2 对 region 各行执行宏

| 键 | 命令 | 作用 |
|---|---|---|
| `C-x C-k r` | `apply-macro-to-region-lines` | 对 region 内每一行回放宏 |

这是批量操作的利器。选好 region（包含若干行），按 `C-x C-k r`，Emacs 会逐行移动光标到行首，然后回放宏。

例如，给 region 内的每一行加上行号：

```
<f3> C-a <f3> . SPC <f4>     ← 录制：到行首，插入计数器值加 ". "
C-x C-k r                     ← 对 region 每行执行
```

关于 `<f3>` 在宏定义中插入计数器，下一节详述。

## 16.3 宏计数器

每个键盘宏都有一个关联的**计数器**，初始值为 0。计数器让你在宏里插入递增的数字——做编号列表、批量命名时特别有用。

| 键 | 命令 | 作用 |
|---|---|---|
| `<f3>`（录制中） | `kmacro-start-macro-or-insert-counter` | 插入计数器值并递增 |
| `C-x C-k C-i` | `kmacro-insert-counter` | 插入计数器值并递增（录制外也可用） |
| `C-x C-k C-c` | `kmacro-set-counter` | 设置计数器值 |
| `C-x C-k C-a` | `kmacro-add-counter` | 给计数器加一个值 |
| `C-x C-k C-f` | `kmacro-set-format` | 设置计数器格式 |

在录制宏时按 `<f3>`，如果当前正在录制（mode line 显示 `Def`），它不会开始新宏，而是**插入当前计数器值**并把计数器加 1。

### 16.3.1 用计数器做编号列表

录制这样一个宏：

```
<f3> C-a <f3> . SPC <f4>
```

宏定义：到行首 → 插入计数器值（初始 0）→ 输入 `. `。

第一次回放（录制时自动执行）：在行首插入 `0. `。
第二次回放：插入 `1. `。
第三次：`2. `。依此类推。

给 `<f3>`（插入计数器）加数值参数可以改变递增步长。`C-u 5 <f3>` 在插入后把计数器加 5 而不是 1。`C-u <f3>`（只给 `C-u` 不加数字）插入**上一次**的计数器值而不递增。

### 16.3.2 设置计数器

`C-x C-k C-c` 设置计数器的值。在宏里使用可以重置计数器。例如，如果你想在每 10 行后重新从 1 开始编号，可以在宏里加一个 `C-x C-k C-c` 的条件判断——但键盘宏本身不支持条件，所以这通常需要在宏的录制中手动安排。

`C-x C-k C-a` 给计数器加上参数值。`C-u` 参数重置计数器为上次插入的值。

### 16.3.3 计数器格式

`C-x C-k C-f` 设置计数器插入时的格式。默认 `%d`（十进制无填充）。你可以输入任何 `format` 函数接受的格式串：

- `%03d`：三位数，前补零（001, 002, 003...）
- `%05d`：五位数，前补零
- `item-%02d`：直接带前缀（item-01, item-02...）

格式串不需要加引号，直接在 minibuffer 里输入。清空 minibuffer 回车恢复默认 `%d`。

## 16.4 宏环（Macro Ring）

Emacs 维护一个**键盘宏环**——每次你定义一个新宏，它就被推到环的头部。你可以旋转这个环来访问之前定义的宏。

| 键 | 命令 | 作用 |
|---|---|---|
| `C-x C-k C-k` | `kmacro-end-or-call-macro-repeat` | 回放环首的宏 |
| `C-x C-k C-n` | `kmacro-cycle-ring-next` | 环旋转到下一个（更早的）宏 |
| `C-x C-k C-p` | `kmacro-cycle-ring-previous` | 环旋转到上一个（更晚的）宏 |

`C-x C-k C-k` 回放当前环首的宏。回放完后可以直接按 `C-k` 再回放一次（不需要重新按 `C-x C-k` 前缀），或按 `C-n` / `C-p` 旋转环。

`C-x C-k C-p` 把环往前转—— bringing 你刚刚定义的**上一个**宏到环首。`C-x C-k C-n` 反向转。每次旋转后 Emacs 在 echo area 显示新环首宏的定义。

环的大小由变量 `kmacro-ring-max` 控制。

**注意**：`<f4>` 和 `C-x e` 总是操作环首的宏——也就是最近定义的宏。旋转环后，`<f4>` 就会回放旋转后的环首宏。

## 16.5 命名与保存宏

录好的宏默认只存在于当前会话。你可以给它一个名字，或者保存到文件里。

| 键 | 命令 | 作用 |
|---|---|---|
| `C-x C-k n` | `kmacro-name-last-macro` | 给最近的宏起一个命令名 |
| `C-x C-k b` | `kmacro-bind-to-key` | 把宏绑到一个键 |
| `M-x insert-kbd-macro` | — | 把宏定义以 Lisp 代码插入 buffer |

### 16.5.1 命名宏

`C-x C-k n` 读入一个名字（如 `add-ok-suffix`），然后这个宏就可以用 `M-x add-ok-suffix` 调用了。名字在当前 Emacs 会话内有效。

如果名字已经被其他命令占用，会报错。

### 16.5.2 绑定到键

`C-x C-k b` 后按你想绑的键序列，宏就被绑到了那个键上。如果该键已绑定其他命令，会询问是否覆盖。

为了避免冲突，`C-x C-k 0` 到 `C-x C-k 9` 和 `C-x C-k A` 到 `C-x C-k Z` 预留给用户自定义宏绑定。用这些键时只需按数字或字母：`C-x C-k b 4` 把宏绑到 `C-x C-k 4`。

### 16.5.3 保存到文件

`M-x insert-kbd-macro RET 宏名 RET` 把宏的 Lisp 定义插入当前 buffer。保存这个 buffer（通常是 `~/.emacs` 或 `~/.emacs.d/init.el`），以后每次启动 Emacs 都会自动定义这个宏。

带前缀参数调用 `insert-kbd-macro`（`C-u M-x insert-kbd-macro`）会额外生成代码记录你绑定的键。

## 16.6 编辑宏

录好的宏可以事后编辑——不用重新录制。

| 键 | 命令 | 作用 |
|---|---|---|
| `C-x C-k C-e` | `kmacro-edit-macro` | 编辑最近的宏 |
| `C-x C-k e` | `edit-kbd-macro` | 编辑指定名字的宏 |
| `C-x C-k l` | `kmacro-edit-lossage` | 把最近 300 次按键作为宏编辑 |

`C-x C-k C-e` 打开一个 `edmacro-mode` buffer，里面是宏的文本表示——每个按键占一行或用一个助记符表示。你可以用普通的文本编辑命令修改它。编辑完后 `C-c C-c` 保存修改并关闭 buffer。

在 edmacro buffer 里：

- `C-c C-q`（`edmacro-insert-key`）插入下一个你按的键的正确格式表示。
- `C-c C-r` 用 region 的文本替换宏的内容。

`C-x C-k e` 后输入调用宏的方式（`C-x e`、`M-x 宏名`、或其他绑定的键），然后编辑那个宏。

`C-x C-k l` 把你最近按过的 300 个键作为宏打开编辑——这在"你刚做了一串操作想保存下来"时特别有用。不需要提前录制，事后把操作历史抓回来编辑即可。

## 16.7 逐步编辑宏

| 键 | 命令 | 作用 |
|---|---|---|
| `C-x C-k SPC` | `kmacro-step-edit-macro` | 逐步回放并编辑宏 |

这是一种交互式的宏编辑方式。Emacs 逐个显示宏里的命令，让你决定：

- `SPC` / `y`：执行当前命令，继续下一个
- `n` / `d` / `DEL`：跳过并删除当前命令
- `f`：这次执行时跳过，但不删除
- `TAB`：执行当前命令及后面所有类似命令（如连续的几个字符插入）
- `c`：不再逐步编辑，执行完剩余命令
- `i` 键序列 `C-j`：在当前命令前插入新命令
- `r` 键序列 `C-j`：用新命令替换当前命令
- `q` / `C-g`：取消编辑

逐步编辑结束后（除非取消），修改后的宏替换原来的宏。

这在宏"大体对但有个别步骤需要调整"时特别有用——比打开 edmacro buffer 看文本表示更直观。

## 16.8 宏中的查询（Query）

| 键 | 命令 | 作用 |
|---|---|---|
| `C-x q` | `kbd-macro-query` | 在宏中插入一个查询点 |

在录制宏时按 `C-x q`，宏回放时会在这一点暂停并等待你输入：

- `RET`：继续执行宏
- `C-g`：停止执行宏
- 数字 + `RET`：执行指定次数后停止
- `C-r`：进入递归编辑，完成后 `C-M-c` 继续宏

这在"大部分时候按固定流程走，偶尔需要人工判断"时很有用。

## 16.9 小结

- `<f3>` 开始录制，`<f4>` 结束/回放。`C-x (` / `C-x )` / `C-x e` 是旧式等价键。
- `<f4>` 带数值参数回放多次，0 表示无限循环。
- `C-u <f3>` 追加录制（先回放再追加），`C-u C-u <f3>` 直接追加。
- 宏计数器：录制中按 `<f3>` 插入递增数字，`C-x C-k C-c` 设值，`C-x C-k C-f` 设格式。
- 宏环：`C-x C-k C-k` 回放环首宏，`C-x C-k C-n` / `C-x C-k C-p` 旋转环。
- `C-x C-k n` 命名宏，`C-x C-k b` 绑键，`M-x insert-kbd-macro` 保存到文件。
- `C-x C-k C-e` 编辑宏文本，`C-x C-k SPC` 逐步编辑，`C-x C-k l` 从最近 300 次按键创建宏。
- `C-x C-k r` 对 region 各行执行宏。
- `C-x q` 在宏中插入查询点。

键盘宏是"发现自己在重复操作"时的第一反应。录下来，回放，必要时编辑——比写 Lisp 快得多，比手动重复更可靠。
