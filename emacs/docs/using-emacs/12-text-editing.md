# 12 · 文本编辑

前面几章讲了光标怎么移动、文本怎么复制删除。这一章换一个角度：按**文本单位**来操作。Emacs 把文本分成字符、词、句子、段落、页面五级，每一级都有对应的"移动 / 删除 / 标记"命令。掌握这套体系后，你不再需要逐字符地挪光标——一句话、一段话都可以一键跳过或一键删除。

章末还会讲填充（Filling）、大小写转换和缩进，这些都是写文档时的高频操作。

## 12.1 词（Words）

Emacs 里"词"的定义由当前 major mode 的语法表决定。在英文和大多数文本模式里，一段连续的字母数字字符就是一个词；中文模式下词边界由分词逻辑决定。下面这组键与字符级的 `C-f`、`C-b`、`C-d`、`DEL`、`C-t` 一一对应，只不过单位从字符换成了词：

| 键 | 命令 | 作用 |
|---|---|---|
| `M-f` | `forward-word` | 光标向前移过一个词 |
| `M-b` | `backward-word` | 光标向后移过一个词 |
| `M-d` | `kill-word` | 杀死（剪切）从光标到词尾的内容 |
| `M-DEL` | `backward-kill-word` | 杀死从光标到词头的内容 |
| `M-t` | `transpose-words` | 交换光标前后的两个词 |
| `M-@` | `mark-word` | 把 mark 设在下一个个词末尾，激活 region |

**为什么是 Meta 键？** Emacs 的键位设计有一条规律：`C-` 前缀操作字符，`M-` 前缀操作词，更高层的文本单位用更"重"的键序列。记住这条规律，后面的句子、段落命令就不用死记了。

`M-f` 和 `M-b` 可以带数值参数——`C-u 3 M-f` 向前跳三个词。负参数反方向走。`M-d` 杀的是"从光标到 `M-f` 会到的位置"之间的全部文本，包括中间的标点。如果你只想杀词不杀标点，先 `M-f` 跳到词尾再 `M-DEL` 反向杀回来。

`M-t` 交换词时，两个词之间的分隔符（空格、逗号等）原地不动：`FOO, BAR` 变成 `BAR, FOO`，而不是 `BAR FOO,`。

## 12.2 句子（Sentences）

| 键 | 命令 | 作用 |
|---|---|---|
| `M-a` | `backward-sentence` | 移到当前句子开头 |
| `M-e` | `forward-sentence` | 移到当前句子结尾 |
| `M-k` | `kill-sentence` | 杀死从光标到句尾的内容 |
| `C-x DEL` | `backward-kill-sentence` | 杀死从光标到句头的内容 |

键位选择的思路仍然是类比：`C-a` / `C-e` 到行首行尾，`M-a` / `M-e` 到句首句尾。

**句子的判定规则**：Emacs 默认采用美式打字习惯——句子以 `.`, `?`, `!` 加上**两个空格**或换行结束，中间允许夹着 `)` `]` `'` `"` 等闭合符号。这条规则的意义在于区分句号结束句子和缩写里的点号（如 `e.g.`）。如果你习惯句尾只打一个空格，可以把变量 `sentence-end-double-space` 设为 `nil`，但代价是缩写点号会被误判为句末。

`M-k` 可以带正参数 N 杀后面 N 个句子，负参数杀回到前面第 N 个句子开头。

## 12.3 段落（Paragraphs）

| 键 | 命令 | 作用 |
|---|---|---|
| `M-{` | `backward-paragraph` | 移到当前/上一段的开头 |
| `M-}` | `forward-paragraph` | 移到当前/下一段的结尾 |
| `M-h` | `mark-paragraph` | 把整个段落选入 region |

段落之间以**空行**分隔（在 Text mode 和大多数编程模式下）。注意：缩进的行**不是**段落分隔符——这是 Text mode 的行为。如果你需要缩进行作为段落边界，用 Paragraph-Indent Text mode。

`M-h` 是一个很实用的命令：它把 point 放在段落开头、mark 放在段落结尾，于是整个段落被选中。接着 `C-w` 就能剪切整段，`M-q` 能重排整段。如果光标恰好在两段之间的空行上，`M-h` 选中后面那段。如果 region 已经激活，再按一次 `M-h` 会把 mark 再往后推一个段落——可以连续按来选中多段。

## 12.4 页面（Pages）

有些纯文本文件用 **formfeed 字符**（ASCII 12，即 `C-l`，显示为 `^L`）来分页。传统上打印时 formfeed 会强制换页。

| 键 | 命令 | 作用 |
|---|---|---|
| `C-x [` | `backward-page` | 移到上一个页面边界 |
| `C-x ]` | `forward-page` | 移到下一个页面边界 |
| `C-x C-p` | `mark-page` | 选中当前页 |

插入 formfeed 字符用 `C-q C-l`（`C-q` 是 quoted-insert，把下一个键原样插入）。`C-x C-p C-w` 可以剪切一整页然后粘贴到别处——因为 `mark-page` 把页面结束处的 formfeed 也包含在 region 里，所以粘贴后分页符依然完整。

`M-x what-page` 显示光标在第几页、页内第几行。`C-x l`（`count-lines-page`）显示当前页有多少行，适合决定在哪里把一页拆成两页。

## 12.5 填充（Filling）

"填充"是指把一段文本的各行重新断开，使每行宽度不超过某个上限（`fill-column`）。这在写散文、邮件、注释时很常用。

### 12.5.1 Auto Fill 模式

Auto Fill 是一个 buffer-local 的 minor mode。开启后，每次你打空格或回车，Emacs 都会检查当前行是否超过了 `fill-column`，超过了就在合适的位置自动断行。

用 `M-x auto-fill-mode` 开关。开启后 mode line 上出现 `Fill` 字样。

想插入空格或换行但不触发自动断行，用 `C-q SPC` 或 `C-q C-j`。

Auto Fill 只**断行**不**合行**——如果你在段落中间删了几个字导致行变短，它不会自动把下面的行拉上来。要整体重排需要用 `M-q`。

### 12.5.2 手动填充命令

| 键 | 命令 | 作用 |
|---|---|---|
| `M-q` | `fill-paragraph` | 重排当前段落 |
| `C-x f` | `set-fill-column` | 设置 fill-column |

`M-q` 是最常用的：它把光标所在段落的所有行重新断开，使每行不超过 `fill-column`，同时删除多余的空格和 tab。如果 region 处于激活状态，`M-q` 重排 region 内的所有段落。

带数值参数调用 `M-q` 会额外做**两端对齐**（justification）——在词间插入额外空格使右端严格对齐到 `fill-column`。再去掉这些多余空格，只需不带参数再按一次 `M-q`。

`fill-column` 的默认值是 **70**。`C-x f` 后面跟一个数字就把它设成那个值；直接 `C-u C-x f` 则把 `fill-column` 设成光标当前所在的列。

`M-x unfill-paragraph` 是 `M-q` 的反操作——把段落里的所有换行删掉，合成一整行。

## 12.6 大小写转换

| 键 | 命令 | 作用 |
|---|---|---|
| `M-l` | `downcase-word` | 把后面的词变成小写 |
| `M-u` | `upcase-word` | 把后面的词变成大写 |
| `M-c` | `capitalize-word` | 把后面的词变成首字母大写 |
| `C-x C-l` | `downcase-region` | 把 region 全部变成小写 |
| `C-x C-u` | `upcase-region` | 把 region 全部变成大写 |

`M-l`、`M-u`、`M-c` 执行完后光标移过被转换的词，所以连续按可以逐词转换。带负参数（如 `M-- M-u`）则转换光标**前面**的词且光标不动——刚打完一个大写词想改小写，直接 `M-- M-l` 即可。如果在词的中间调用，只转换光标之后的部分。

`C-x C-l` 和 `C-x C-u` 默认是**禁用**命令（disabled command）——第一次调用时 Emacs 会问你是否确认并选择以后是否不再询问。这是防止误操作的设计。

## 12.7 缩进

### 12.7.1 TAB 键

`TAB`（命令 `indent-for-tab-command`）是最基本的缩进键，但它在不同 major mode 下行为不同：

- **Text mode**：把光标推到下一个 tab stop（通常是 8 列一个），或者与前一行第一个非空白字符对齐。
- **编程模式**（C mode、Lisp mode 等）：根据语言的缩进规则重新缩进当前行。
- **region 激活时**：缩进 region 内的所有行。

如果只想插入一个原始的 tab 字符而不触发缩进，用 `C-q TAB`。

### 12.7.2 更多缩进命令

| 键 | 命令 | 作用 |
|---|---|---|
| `C-M-\` | `indent-region` | 缩进 region 内的每一行 |
| `C-x TAB` | `indent-rigidly` | 把 region 整体左移/右移 |
| `M-^` | `delete-indentation` | 合并当前行与上一行 |
| `M-m` | `back-to-indentation` | 移到当前行第一个非空白字符 |

`C-M-\` 在 region 未激活时也能工作——它对"从上一个 `mark-ring` 位置到光标"之间的区域操作。更常见的用法是先 `C-SPC` 设 mark、移动光标、再 `C-M-\`。带数值参数 N 调用时，把 region 内每行都缩进到第 N 列。

`C-x TAB`（`indent-rigidly`）不带参数时会进入一个**临时交互模式**：左右方向键每次移动一列，`S-<LEFT>` / `S-<RIGHT>` 跳到上一个/下一个 tab stop。按任何其他键退出临时模式。带数值参数 N 则直接整体右移 N 列（负值左移）。

`M-^`（`delete-indentation`）把当前行与上一行合并：删掉行首空白和换行符，替换为一个空格。在 Lisp 代码里，如果连接处恰好是 `)(`，则不插入空格。带参数时合并当前行与**下一行**。如果 region 激活，则合并 region 内的所有行。

## 12.8 小结

- 词：`M-f` / `M-b` / `M-d` / `M-DEL`，与字符级命令一一对应。
- 句：`M-a` / `M-e` / `M-k`，默认按两句空格约定识别句末。
- 段：`M-{` / `M-}` / `M-h`，`M-h` 一键选中整段。
- 页：`C-x [` / `C-x ]` / `C-x C-p`，按 formfeed 字符分页。
- 填充：`M-q` 重排段落，`C-x f` 设宽度，`auto-fill-mode` 自动断行。
- 大小写：`M-l` / `M-u` / `M-c` 逐词，`C-x C-l` / `C-x C-u` 对 region。
- 缩进：`TAB` 按模式缩进当前行，`C-M-\` 缩进 region，`M-^` 合并行。

掌握了按文本单位操作的方法，你就不再是一个字符一个字符地"爬"文本了。下一章讲 major mode 与 minor mode——不同文件类型下 Emacs 的行为为什么不同，以及你怎么控制它。
