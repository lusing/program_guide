# 48 · ZF：集合论对象逻辑

## 48.1 一句话概括

HOL 里"集合"是谓词的语法糖；ZF 把**集合**当一等公民，
在 FOL 之上公理化（logics-ZF 手册 + 库索引 ZF 部分）。
没有类型，一切靠分离公理刻画；证明的重心从"归纳"移到
"属于关系的推理"。对 HOL 用户：重新认识"类型 vs 集合"。

## 48.2 公理的定理形态

```isabelle
thm extension          (* 外延：集合由元素决定 *)
lemma sep_demo: "{x ∈ A. x ∈ B} ⊆ B" by blast
lemma pair_union: "{0} ∪ {1} = {0, 1}" by blast
```

分离公理的语法形态就是 `{x ∈ A. φ(x)}`。

## 48.3 序数与超穷归纳

```isabelle
thm trans_induct       (* 对全体序数的超穷归纳 *)
lemma Ord_zero_is_least: "Ord(i) ⟹ 0 ≤ i"
  by (rule Ord_0_le)
```

`Ord` 是传递且由 < 良序的集合；0 是最小序数（官方
`Ord_0_le` 一行，别重证）。**ZF 继承 FOL 的函数式写法**
（`Ord(i)` 而非 `Ord i`——实测空格应用解析失败，第 47 章同款雷）。

## 48.4 AC 等价形态（文档节）

`CardinalArith`/`Zorn` 等理论里躺着经典等价：AC ⟺ 佐恩引理 ⟺
良序定理。本教程不展开证明（每个都是几页），记住拿取路径。

## 48.5 与 HOL 的对照

| 概念 | HOL | ZF |
|---|---|---|
| 集合 | 'a set（谓词语法糖）| 一等对象，仅 ∈ |
| 函数 | 普通类型 'a ⇒ 'b | 有序对的集合 |
| 类型检查 | 静态、编译期 | 无类型，全靠分离 |
| 归纳 | 结构/规则归纳 | 超穷归纳 trans_induct |
| 库 | HOL-Library 等 | ZF-Constructable 等 |

## 48.6 坑位清单（实测）

1. **没有类型**：`::` 标注不可用——HOL 肌肉记忆全废。
2. `Ord(i)` 函数式写法（FOL 家族语法）。
3. 自然数是冯诺依曼序数（0 = ∅，1 = {0}……），`2` 既是数又是集合，
   化简行为和 HOL numeral 完全不同。
4. `value` 不可用（代码生成器没配 ZF）。
5. `simp` 可用但规则集是 ZF 的；`auto` 部分可用（配 blast）。
6. `blast` 在 ZF 里好用——公理多带 ⟷/集合等式时先试它。
