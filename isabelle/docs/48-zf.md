# 48 · ZF：公理集合论的形式化

对应示例：`../examples/zf/T48_zf.thy`（IsaTutZF 会话，父堆 ZF）

> 参考：[Isabelle/ZF 库索引](https://dist.isabelle.cit.tum.de/dist/library/FOL/ZF/index.html)

## 48.1 一句话概括

Isabelle 是**逻辑框架**——HOL 只是它最常用的一种对象逻辑（第 47 章讲了一阶逻辑 FOL）。本章进入更深处：**ZF（Zermelo--Fraenkel）公理集合论**。

HOL 里"集合"是谓词的语法糖——`'a set` 本质上就是 `'a ⇒ bool`，类型系统保证你不会把整数当函数用。ZF 完全不同：**没有类型系统**，一切对象都是集合，唯一的原始关系是属于关系 `∈`。数字 0 是空集 `∅`，数字 1 是 `{∅}`，数字 2 是 `{∅, {∅}}`——每个自然数都是一个集合。函数也是集合——它是有序对的集合。

这种设计的代价是失去了编译期类型检查（HOL 里 `::` 标注在 ZF 里完全不可用），但收获是**数学上的纯粹性**：整个数学大厦只需要一个概念——集合，和一条关系——属于。

Isabelle/ZF 的库覆盖了公理集合论的完整生态：

- **公理底座**（`ZF_Base`）：外延、并、幂、无穷、基础、替换——六条公理以定理形态呈现
- **集合运算**（`upair`/`equalities`）：无序对、交、差、`cons`、`succ`
- **有序对与函数**（`pair`/`func`）：`Pair`、`Pi`、`Lambda`、`apply`
- **良基与递归**（`WF`）：`wf`、`wfrec`
- **序数**（`Ordinal`）：`Transset`、`Ord`、超穷归纳 `trans_induct`
- **自然数**（`Nat`）：`nat` 作为最小不动点、`nat_induct`、`nat_rec`
- **有限集**（`Finite`）：`Fin` 算子、`FiniteFun`
- **基数**（`Cardinal`）：等势 `≈`、Schroeder-Bernstein 定理
- **整数**（`Int`）：自然数对的等价类构造
- **列表**（`List`）：`list(A)` 数据类型
- **选择公理**（`AC`/`Zorn`）：AC 公理、Zorn 引理

本章逐一走过这些理论，每一段代码都在正文中解释。

## 48.2 公理的定理形态

ZF_Base 把 ZF 的公理写成 Isabelle 定理。这意味着你可以像使用任何其他定理一样使用它们——`thm` 命令可以查看它们的形态。

**外延律**：两个集合相等当且仅当互相包含。

```isabelle
thm extension
```

输出：`A = B ⟷ A ⊆ B ∧ B ⊆ A`

这是集合论的第一条公理：集合完全由它的元素决定。如果两个集合包含相同的元素，它们就相等。

**并集公理**：

```isabelle
thm Union_iff
```

输出：`A ∈ ⋃(C) ⟷ (∃B∈C. A ∈ B)`

`⋃(C)` 是集合族 `C` 的并——它收集所有属于 `C` 中某个集合的元素。

**幂集公理**：

```isabelle
thm Pow_iff
```

输出：`A ∈ Pow(B) ⟷ A ⊆ B`

`Pow(B)` 是 `B` 的所有子集的集合。

**无穷公理**：

```isabelle
thm infinity
```

输出：`0 ∈ Inf ∧ (∀y∈Inf. succ(y) ∈ Inf)`

存在一个集合 `Inf`，包含空集且对后继运算 `succ` 封闭。这保证了无穷集合的存在。

**基础公理**（正则公理）：

```isabelle
thm foundation
```

输出：`A = 0 ∨ (∃x∈A. ∀y∈x. y ∉ A)`

每个非空集合都有一个 `∈`-极小元。这条公理排除了 `x ∈ x` 这样的病态集合，也排除了无穷下降链 `… ∈ x₂ ∈ x₁ ∈ x₀`。

**替换公理模式**：

```isabelle
thm replacement
```

输出：`(∀x∈A. ∀y z. P(x,y) ∧ P(x,z) ⟶ y = z) ⟹ b ∈ PrimReplace(A,P) ⟷ (∃x∈A. P(x,b))`

如果 `P` 在 `A` 上是函数的（每个 `x` 最多对应一个 `y`），则 `PrimReplace(A,P)` 收集所有像 `P(x,·)`。这是 ZF 最强大的公理——从已有集合出发构造新集合。

**分离公理**从替换推出。`Collect(A,P)` 即 `{x ∈ A. P(x)}`，其核心等价由化简器直接展开：

```isabelle
lemma separation_demo: "a ∈ {x ∈ A. P(x)} ⟷ a ∈ A ∧ P(a)"
  by simp
```

`by simp` 就能证明——因为 `separation` 是化简器的内置规则。`{x ∈ A. P(x)}` 的展开就是 `a ∈ A ∧ P(a)`。

## 48.3 有界量词

ZF 大量使用**有界量词** `∀x∈A. P(x)` 和 `∃x∈A. P(x)`（内部名称 `Ball` 和 `Bex`）。与 HOL 的全称量词 `∀x. P(x)` 不同，有界量词限制搜索范围到一个集合 `A`——这在无类型环境里是必要的，否则量词的范围就是"全体集合"，那会导致悖论。

**引入规则**：

```isabelle
lemma ball_demo:
  assumes "⋀x. x ∈ A ⟹ P(x)"
  shows "∀x∈A. P(x)"
  using assms by (rule ballI)
```

`ballI` 是 `Ball` 的引入规则：如果对 `A` 中每个元素 `P` 都成立，则 `∀x∈A. P(x)` 成立。注意 `⋀` 是 Isabelle 的元量词——它说"对任意 `x`，如果 `x ∈ A`，则 `P(x)`"。

```isabelle
lemma bex_demo:
  assumes "P(a)" and "a ∈ A"
  shows "∃x∈A. P(x)"
  using assms by (rule bexI)
```

`bexI` 是 `Bex` 的引入规则：找到一个见证 `a`，它满足 `P` 且属于 `A`。注意 `bexI` 的两个前提顺序：先是 `P(x)`，后是 `x ∈ A`。

**消去规则**：

```isabelle
lemma bspec_demo:
  assumes "∀x∈A. P(x)" and "x ∈ A"
  shows "P(x)"
  using assms by (rule bspec)
```

`bspec`（bounded specification）：从 `∀x∈A. P(x)` 和 `x ∈ A` 得到 `P(x)`。这对应 HOL 里的 `spec`（全称消去），但多了集合成员条件。

## 48.4 无序对、二元运算与 cons

`Upair(a,b)` 是无序对 `{a,b}`。二元并、交、差都从它定义：

```isabelle
lemma Upair_iff: "c ∈ Upair(a,b) ⟷ c = a ∨ c = b"
  by simp

lemma Un_iff: "c ∈ A ∪ B ⟷ c ∈ A ∨ c ∈ B"
  by simp

lemma Int_iff: "c ∈ A ∩ B ⟷ c ∈ A ∧ c ∈ B"
  by simp

lemma Diff_iff: "c ∈ A - B ⟷ c ∈ A ∧ c ∉ B"
  by simp
```

这些全是 `by simp`——化简器已经知道 `Upair`、`Un`、`Int`、`Diff` 的定义展开。

`cons(a,A)` 把元素 `a` 加入集合 `A`：`cons(a,A) = Upair(a,a) ∪ A`。

```isabelle
lemma cons_iff: "a ∈ cons(b,A) ⟷ a = b ∨ a ∈ A"
  by simp
```

`succ(i)` 是序数后继：`succ(i) = cons(i,i)`。

```isabelle
lemma succ_iff: "i ∈ succ(j) ⟷ i = j ∨ i ∈ j"
  by (simp add: succ_iff)
```

这里 `succ_iff` 本身就是化简规则，所以 `by (simp add: succ_iff)` 直接展开。

**集合枚举语法** `{a,b,c}` 是 `cons(a,cons(b,cons(c,0)))` 的语法糖。单元素集 `{a}` 就是 `cons(a,0)`：

```isabelle
lemma singleton_iff: "a ∈ {b} ⟷ a = b"
  by simp
```

一个具体例子：

```isabelle
lemma pair_union: "{0} ∪ {1} = {0, 1}"
  by blast
```

`blast` 在这里一步完成——它知道 `{0}` 就是 `cons(0,0)`，`{1}` 就是 `cons(1,0)`，`{0,1}` 就是 `cons(0,cons(1,0))`，然后验证两边包含相同元素。

## 48.5 基础公理的推论

基础公理直接推出 `∈` 的反自反性和反对称性。

**反自反性**：任何集合不能属于自己。

```isabelle
lemma no_self_mem: "a ∉ a"
  by (rule mem_not_refl)
```

`mem_not_refl` 是库中已有的定理，从基础公理推出。证明思路：假设 `a ∈ a`，对集合 `{a}` 应用基础公理——`{a}` 非空，所以存在极小元 `x ∈ {a}` 使得 `∀y∈x. y ∉ {a}`。唯一的 `x` 就是 `a`，所以 `∀y∈a. y ∉ {a}`。但 `a ∈ a`，所以 `a ∈ {a}`，矛盾。

**反对称性**：若 `a ∈ b` 则 `b ∉ a`。

```isabelle
lemma mem_asym_demo:
  assumes "a ∈ b"
  shows "b ∉ a"
  using assms by (blast elim: mem_asym)
```

`mem_asym` 是库中的消除规则。`blast` 配合 `elim: mem_asym` 自动完成推理。

`succ` 的单射性和 `succ(n) ≠ 0` 也都从基础公理推出：

```isabelle
thm succ_inject_iff
```

输出：`succ(m) = succ(n) ⟷ m = n`

```isabelle
thm succ_not_0
```

输出：`succ(n) ≠ 0`

## 48.6 有序对、积与函数空间

`Pair(a,b)`（记号 `⟨a,b⟩`）是有序对。Isabelle/ZF 用**对称定义** `{{a,a},{a,b}}`——这比 Kuratowski 原始定义 `{{a},{a,b}}` 在化简器里表现更好（对称性让某些等式证明更简单）。

```isabelle
lemma Pair_inject: "⟨a,b⟩ = ⟨c,d⟩ ⟹ a = c ∧ b = d"
  by simp
```

`fst` 和 `snd` 用 `THE`（确定描述算子）提取分量：`fst(p) = THE a. ∃b. p = Pair(a,b)`。

**依赖积** `Sigma(A,B)`（记号 `∑x∈A. B(x)`）是所有有序对 `⟨x,y⟩` 的集合，其中 `x ∈ A` 且 `y ∈ B(x)`。非依赖版本 `A × B` 是笛卡尔积。

**依赖函数空间** `Pi(A,B)`（记号 `∏x∈A. B(x)`）是所有函数的集合——函数在这里就是满足特定条件的有序对集合。非依赖版本 `A → B` 是普通函数空间。

`Lambda(A,f)`（记号 `λx∈A. f(x)`）构造函数——它是有序对 `⟨x,f(x)⟩` 的集合：

```isabelle
lemma lam_type_demo:
  assumes "⋀x. x ∈ A ⟹ f(x) ∈ B(x)"
  shows "(λx∈A. f(x)) ∈ Pi(A,B)"
  using assms by (rule lam_type)
```

`lam_type` 是库中的类型检查规则：如果 `f` 把 `A` 中每个元素映射到对应的 `B(x)`，则 `λx∈A. f(x)` 属于 `Pi(A,B)`。注意这里用 `by (rule lam_type)` 而不是 `by simp`——因为 `lam_type` 不是化简规则。

**函数应用**用反引号 `f`a`（不是 HOL 的空格应用 `f a`）：

```isabelle
lemma beta_demo:
  assumes "a ∈ A"
  shows "(λx∈A. f(x)) ` a = f(a)"
  using assms by (rule beta)
```

`beta` 是 β-归约规则：对定义域内的 `a`，`(λx∈A. f(x))`a` 等于 `f(a)`。

**应用不在定义域的元素**得到 `0`（空集）：

```isabelle
thm apply_0
```

输出：`a ∉ domain(f) ⟹ f`a = 0`

这是 ZF 的特殊设计——HOL 里应用未定义的值是未指定的（由类型决定），ZF 里统一返回空集。

**函数外延**：两个函数如果在所有输入上相等则相等。

```isabelle
thm fun_extension
```

输出：`⟦f ∈ Pi(A,B); g ∈ Pi(A,B); ⋀x. x ∈ A ⟹ f`x = g`x⟧ ⟹ f = g`

## 48.7 关系运算

ZF 里关系就是有序对的集合。

`converse(r)` 是逆关系——把所有有序对翻转。`domain(r)` 是定义域（所有有序对的第一个分量的集合），`range(r)` 是值域，`field(r) = domain(r) ∪ range(r)` 是域。

`r `` A` 是像——`A` 中所有元素在 `r` 下的像的集合。`restrict(r,A)` 是限制——只保留定义域在 `A` 中的有序对。

```isabelle
lemma domain_lambda:
  shows "domain(λx∈A. f(x)) = A"
  by (rule domain_lam)
```

`domain_lam` 是库中定理：`λ`-表达式的定义域就是 `A`。

```isabelle
lemma image_lambda:
  assumes "C ⊆ A"
  shows "(λx∈A. f(x)) `` C = {f(x). x ∈ C}"
  using assms by (rule image_lam)
```

`image_lam`：`λ`-表达式在子集 `C` 上的像等于 `{f(x). x ∈ C}`（`RepFun` 语法）。前提 `C ⊆ A` 保证 `C` 中元素都在定义域内。

`Image` 的中缀记号是 ` `` `（两个反引号）：

```isabelle
thm image_def
```

输出：`r `` A = {y ∈ range(r). ∃x∈A. ⟨x,y⟩ ∈ r}`

## 48.8 描述与条件

`THE x. P(x)` 是**确定描述**（Hilbert 的 ι 算子）。若恰好有一个 `x` 满足 `P`，则 `THE x. P(x)` 等于那个 `x`：

```isabelle
lemma the_equality_demo:
  assumes "P(a)" and "⋀x. P(x) ⟹ x = a"
  shows "(THE x. P(x)) = a"
  using assms by (rule the_equality)
```

`the_equality` 是核心规则：`P(a)` 成立且 `a` 是唯一的满足者，则 `THE x. P(x) = a`。

若不存在唯一的 `x`，`THE` 返回 `0`：

```isabelle
thm the_0
```

输出：`¬ (∃!x. P(x)) ⟹ (THE x. P(x)) = 0`

`if P then a else b` 是条件表达式：

```isabelle
lemma if_true_demo: "(if True then a else b) = a"
  by simp

lemma if_false_demo: "(if False then a else b) = b"
  by simp
```

两个都是 `by simp`——`if_true` 和 `if_false` 是化简器的内置规则。

## 48.9 子集与集合等式

`A ⊆ B` 定义为 `∀x∈A. x ∈ B`。

**子集引入规则**：

```isabelle
lemma subsetI_demo:
  assumes "⋀x. x ∈ A ⟹ x ∈ B"
  shows "A ⊆ B"
  using assms by (rule subsetI)
```

`subsetI`：如果对每个 `x`，`x ∈ A` 蕴含 `x ∈ B`，则 `A ⊆ B`。

**集合等式**的标准证法是双向子集：

```isabelle
lemma equality_demo:
  assumes "A ⊆ B" and "B ⊆ A"
  shows "A = B"
  using assms by (rule equalityI)
```

`equalityI` 从 `A ⊆ B` 和 `B ⊆ A` 推出 `A = B`——这直接来自外延公理。

**Cantor 定理**：没有从 `A` 到 `Pow(A)` 的满射。

```isabelle
thm cantor
```

输出：`∃S ∈ Pow(A). ∀x∈A. b(x) ≠ S`

对任意函数 `b`，都存在 `Pow(A)` 中的集合 `S` 不在 `b` 的值域里。这是集合论的经典结果——幂集的"大小"严格大于原集合。

## 48.10 良基关系与良基递归

`wf(r)` 表示关系 `r` 是**良基的**：每个非空集合都有 `r`-极小元。定义直接对应：

`wf(r) ≡ ∀Z. Z = 0 ∨ (∃x∈Z. ∀y. ⟨y,x⟩ ∈ r ⟶ y ∉ Z)`

即：对每个非空集合 `Z`，存在 `x ∈ Z` 使得没有 `y ∈ Z` 满足 `⟨y,x⟩ ∈ r`——`x` 就是 `Z` 的 `r`-极小元。

**良基归纳**：

```isabelle
thm wf_induct
```

输出：`⟦wf(r); ⋀x. (⋀y. ⟨y,x⟩ ∈ r ⟹ P(y)) ⟹ P(x)⟧ ⟹ P(a)`

若 `r` 良基，且 `P` 对所有 `r`-前驱成立则 `P(x)` 成立，则 `P` 对所有 `a` 成立。这是数学归纳法的推广——自然数归纳、结构归纳、超穷归纳都是它的特例。

**良基递归定理** `wfrec`：

```isabelle
thm wfrec
```

在良基关系上定义函数——`f(x) = H(x, f restricted to r-predecessors of x)`。

`Memrel(A)` 是集合 `A` 上的属于关系（作为有序对集合）：

```isabelle
thm wf_Memrel
```

输出：`wf(Memrel(A))`

基础公理保证属于关系总是良基的——这是良基递归在集合论里可行的根本原因。

## 48.11 传递集与序数

`Transset(i)`：`i` 是**传递集**——每个元素也是子集。

```isabelle
thm Transset_def
```

输出：`Transset(i) ≡ ∀x∈i. x ⊆ i`

三种等价刻画：

```isabelle
lemma Transset_iff_Pow_demo: "Transset(A) ⟷ A ⊆ Pow(A)"
  by (rule Transset_iff_Pow)

lemma Transset_iff_Union_demo: "Transset(A) ⟷ ⋃(A) ⊆ A"
  by (rule Transset_iff_Union_subset)
```

传递集意味着 `A ⊆ Pow(A)`（每个元素也是子集），也意味着 `⋃(A) ⊆ A`（所有元素的并包含在 `A` 中）。

`Ord(i)`：`i` 是**序数**——传递且每个元素传递。

```isabelle
thm Ord_def
```

输出：`Ord(i) ≡ Transset(i) ∧ (∀x∈i. Transset(x))`

冯诺依曼序数：`0 = ∅`，`1 = {0} = {∅}`，`2 = {0,1} = {∅, {∅}}`，`ω = nat`。每个序数都是它所有前驱的集合。

```isabelle
lemma Ord_0_demo: "Ord(0)"
  by simp

lemma Ord_succ_demo: "Ord(i) ⟹ Ord(succ(i))"
  by (rule Ord_succ)
```

`0` 是序数（空集平凡传递），序数的后继也是序数。

`i < j` 定义为 `i ∈ j ∧ Ord(j)`。`i ≤ j` 定义为 `i < succ(j)`：

```isabelle
thm lt_def
```

输出：`i < j ≡ i ∈ j ∧ Ord(j)`

**序数的三歧性**（线性序）：

```isabelle
thm Ord_linear
```

输出：`Ord(i) ⟹ Ord(j) ⟹ i ∈ j ∨ i = j ∨ j ∈ i`

任意两个序数可比——这是序数的核心性质。证明用超穷归纳（对两个参数都做）。

**超穷归纳**——对全体序数归纳：

```isabelle
thm trans_induct
```

输出：`Ord(i) ⟹ (⋀x. Ord(x) ⟹ (⋀y. y ∈ x ⟹ P(y)) ⟹ P(x)) ⟹ P(i)`

要证明 `P(i)` 对所有序数成立，只需证明：对任意序数 `x`，若 `P(y)` 对所有 `y ∈ x` 成立，则 `P(x)` 成立。这覆盖了三种情况：零（`x = 0`，前提空虚成立）、后继（`x = succ(y)`，归纳假设在 `y` 上）、极限（`x` 是极限序数，归纳假设在所有前驱上）。

**序数情形分解**：

```isabelle
thm Ord_cases
```

每个序数要么是 `0`，要么是后继序数，要么是极限序数——三者互斥。

**Burali-Forti 悖论**：不存在所有序数的集合。

```isabelle
thm ON_class
```

输出：`¬ (∀i. i ∈ X ⟷ Ord(i))`

如果存在这样的集合 `X`，则 `X` 本身是序数（可以验证），从而 `X ∈ X`，违反反自反性。

`Limit(i)`：`i` 是极限序数——非零且对后继封闭。

```isabelle
thm Limit_def
```

输出：`Limit(i) ≡ Ord(i) ∧ 0 < i ∧ (∀y. y < i ⟶ succ(y) < i)`

## 48.12 自然数

`nat` 定义为**最小不动点**：

```isabelle
thm nat_unfold
```

输出：`nat = {0} ∪ {succ(x). x ∈ nat}`

即 `nat ≡ lfp(Inf, λX. {0} ∪ {succ(i). i ∈ X})`——`nat` 是包含 `0` 且对 `succ` 封闭的最小集合。`Inf`（无穷公理提供的集合）保证这个不动点存在。

**类型检查**：

```isabelle
lemma nat_0_demo: "0 ∈ nat"
  by simp

lemma nat_succ_demo: "n ∈ nat ⟹ succ(n) ∈ nat"
  by simp
```

`0` 是自然数，自然数的后继也是自然数——`by simp` 就能证明，因为 `nat_unfold` 是化简规则。

**数学归纳法**：

```isabelle
thm nat_induct
```

输出：`⟦n ∈ nat; P(0); ⋀x. ⟦x ∈ nat; P(x)⟧ ⟹ P(succ(x))⟧ ⟹ P(n)`

标准的自然数归纳：基础步骤 `P(0)`，归纳步骤 `P(x) ⟹ P(succ(x))`。

**情形分解**：

```isabelle
thm natE
```

每个自然数要么是 `0`，要么是某个自然数的后继。

`nat_rec` 是自然数上的**原始递归算子**，用 `wfrec(Memrel(nat),...)` 定义：

```isabelle
thm nat_rec_0
thm nat_rec_succ
```

`nat_rec(0, a, b) = a`，`nat_rec(succ(k), a, b) = b(k, nat_rec(k, a, b))`——这是原始递归的标准模式。

**每个自然数都是序数**：

```isabelle
thm nat_into_Ord
```

输出：`n ∈ nat ⟹ Ord(n)`

`nat` 本身是极限序数（即 `ω`）：

```isabelle
thm Limit_nat
```

## 48.13 有限集

`Fin(A)` 是 `A` 的**有限子集算子**，用归纳定义：

```isabelle
thm Fin.intros
```

两条引入规则：`0 ∈ Fin(A)`（空集有限），`⟦a ∈ A; b ∈ Fin(A)⟧ ⟹ cons(a,b) ∈ Fin(A)`（有限集加一个元素仍有限）。

**有限集归纳**：

```isabelle
thm Fin_induct
```

要证明 `P(b)` 对所有 `b ∈ Fin(A)` 成立：基础 `P(0)`，归纳步骤 `⟦x ∈ A; y ∈ Fin(A); x ∉ y; P(y)⟧ ⟹ P(cons(x,y))`。注意额外条件 `x ∉ y`——这避免重复计数。

**两个有限集的并仍有限**：

```isabelle
thm Fin_UnI
```

输出：`⟦b ∈ Fin(A); c ∈ Fin(A)⟧ ⟹ b ∪ c ∈ Fin(A)`

`Finite(A)` 定义为与某个自然数等势：

```isabelle
thm Finite_def
```

输出：`Finite(A) ≡ ∃n∈nat. A ≈ n`

## 48.14 基数与等势

`A ≈ B`（**等势**）：存在 `A` 到 `B` 的双射。

```isabelle
thm eqpoll_def
```

输出：`A ≈ B ≡ ∃f. f ∈ bij(A,B)`

`A ≲ B`（**弱支配**）：存在 `A` 到 `B` 的单射。

```isabelle
thm lepoll_def
```

输出：`A ≲ B ≡ ∃f. f ∈ inj(A,B)`

`|A|`（**基数**）是等势于 `A` 的最小序数：

```isabelle
thm cardinal_def
```

输出：`|A| ≡ (μ i. i ≈ A)`

`μ` 是最小序数算子（`Least`）。

**Schroeder-Bernstein 定理**：若 `A ≲ B` 且 `B ≲ A` 则 `A ≈ B`。

```isabelle
thm schroeder_bernstein
```

输出：`⟦f ∈ inj(X,Y); g ∈ inj(Y,X)⟧ ⟹ ∃h. h ∈ bij(X,Y)`

证明核心是 **Banach 分解定理**——用 `lfp`（最小不动点）构造一个分解，把 `X` 和 `Y` 分别分成两部分，使得双射可以在每部分上分别构造。这是集合论的经典结果，Isabelle/ZF 给出了完整的机器验证证明。

**等势是等价关系**：

```isabelle
thm eqpoll_refl
thm eqpoll_sym
thm eqpoll_trans
```

自反性（恒等映射是双射）、对称性（双射的逆是双射）、传递性（双射的复合是双射）。

## 48.15 整数

ZF 的整数 `int` 构造为**自然数对的等价类**：`⟨x,y⟩` 代表 `x - y`。

等价关系 `intrel`：

```isabelle
thm intrel_def
```

输出：`intrel ≡ {p ∈ (nat×nat)×(nat×nat). ∃x1 y1 x2 y2. p = ⟨⟨x1,y1⟩,⟨x2,y2⟩⟩ ∧ x1 #+ y2 = x2 #+ y1}`

`⟨x1,y1⟩` 和 `⟨x2,y2⟩` 等价当且仅当 `x1 + y2 = x2 + y1`——即 `x1 - y1 = x2 - y2`（虽然减法还没定义，但交叉乘法避免了减法）。

```isabelle
thm int_def
```

输出：`int ≡ (nat×nat) // intrel`

整数就是自然数对关于 `intrel` 的等价类的集合。

自然数到整数的嵌入 `$# m`：

```isabelle
thm int_of_def
```

输出：`$# m ≡ intrel `` {⟨natify(m), 0⟩}`

自然数 `m` 映射到等价类 `⟨m, 0⟩`——代表 `m - 0 = m`。

加法 `$+`、乘法 `$*`、取负 `$-` 满足交换律、分配律等：

```isabelle
thm zadd_commute
thm zmult_commute
thm zadd_zmult_distrib
```

整数上的线性序：

```isabelle
thm zless_linear
```

整数的情形分解：

```isabelle
thm int_cases
```

每个整数要么是 `$# n`（非负），要么是 `$- $# succ(n)`（负）。

## 48.16 列表

`list(A)` 是 ZF 的**列表数据类型**，通过 `Datatype` 包的 `datatype` 命令定义：

```
datatype list(A) = Nil | Cons(a ∈ A, l ∈ list(A))
```

注意 ZF 的 `datatype` 语法与 HOL 不同——类型约束写在构造子参数里（`a ∈ A`），不是用 `::`。

基本操作 `map`、`app`（中缀 `@`）、`rev` 满足以下定理：

```isabelle
thm map_ident
```

输出：`l ∈ list(A) ⟹ map(λu. u, l) = l`

```isabelle
thm app_assoc
```

输出：`xs ∈ list(A) ⟹ (xs @ ys) @ zs = xs @ (ys @ zs)`

```isabelle
thm rev_rev_ident
```

输出：`l ∈ list(A) ⟹ rev(rev(l)) = l`

列表归纳有两种形式——普通归纳 `list.induct`（对 `Nil`/`Cons` 结构归纳）和 `list_append_induct`（对 `@` 的右参数归纳，证明 `app` 相关性质更方便）：

```isabelle
thm list.induct
thm list_append_induct
```

## 48.17 选择公理与 Zorn 引理

`AC` 公理在**独立的 `AC` 理论中**（不在 `ZF` 主入口内）。其形式（Halmos 1960）：若 `A` 非空且每个 `B(x)` 非空，则 `Pi(A,B)` 非空——依赖选择函数存在。

`Zorn` 理论用 `TFin`（Tukey 函数的归纳定义）推出 **Zorn 引理**：每个链都有上界的偏序集有极大元。证明基于 Abrial & Laffitte 的未发表文章。

`AC` 与 Zorn 引理、良序定理（每个集合可良序）在 ZF 里等价——但每个等价证明都是几页长，本教程不展开。

`ZFC = ZF + InfDatatype`，即 ZF 加上无穷分支数据类型支持。`ZFC` 理论本身只有一行 `imports ZF InfDatatype`。

## 48.18 迭代与超穷递归

`ZF` 理论（主入口）定义了**函数迭代** `F^n(x)` 和**超穷递归** `transrec3`。

```isabelle
lemma iterates_zero: "F^0 (x) = x"
  by simp

lemma iterates_succ: "F^(succ(n)) (x) = F(F^n (x))"
  by simp
```

`F^0(x) = x`，`F^(succ(n))(x) = F(F^n(x))`——标准的函数迭代定义。

`ω` 次迭代：

```isabelle
thm iterates_omega_def
```

输出：`F^ω(x) ≡ ⋃n∈nat. F^n(x)`

`transrec3` 按零/后继/极限三种情况做超穷递归：

```isabelle
thm transrec3_0
thm transrec3_succ
thm transrec3_Limit
```

`transrec3(0, a, b, c) = a`，`transrec3(succ(i), a, b, c) = b(i, transrec3(i, a, b, c))`，`transrec3(Limit(i), a, b, c) = c(i, λy∈i. transrec3(y, a, b, c))`。

## 48.19 与 HOL 的对照

| 概念 | HOL | ZF |
|---|---|---|
| 集合 | `'a set`（谓词语法糖）| 一等对象，仅 `∈` 关系 |
| 函数 | 普通类型 `'a ⇒ 'b` | 有序对的集合（`Pi`）|
| 应用 | `f x`（空格）| `f`x`（反引号）|
| 类型检查 | 静态、编译期 | 无类型，全靠分离公理 |
| 归纳 | 结构/规则归纳 | 超穷归纳 `trans_induct` |
| 自动化 | `auto` / `metis` | `blast` / `auto`（部分）|
| 代码生成 | `export_code` | 不可用（`value` 也不可用）|
| 库 | HOL-Library 等 | ZF-Constructible / ZF-IMP 等 |

## 48.20 坑位清单（实测）

1. ZF **没有类型**：`x ∈ A` 里没有类型变量；`::` 类型标注不可用——HOL 肌肉记忆全废。
2. 谓词用函数式写法 `Ord(i)`、`P(x)`——`P x` 空格应用在量词体里直接解析失败（实测 Inner syntax error，第 47 章同款雷）。
3. 函数应用 `f`a` 用反引号，不是空格。
4. 自然数是冯诺依曼序数（`0 = ∅`，`1 = {0}`……），`2` 既是数又是集合，化简行为和 HOL numeral 完全不同。
5. `value` 不可用（代码生成器没配 ZF）。
6. `simp` 可用但规则集是 ZF 的；`auto` 部分可用（配 `blast`）。
7. `blast` 在 ZF 里好用——公理多带 `⟷` / 集合等式时先试它。
8. `metis` 在 ZF 里不可用（那是 HOL 的）。
9. 定理名带撇号家族（`succ`、`Ord_succ`），与 HOL 的引理重名时靠会话前缀消歧。
10. `datatype` 在 ZF 里可用（通过 Datatype 理论），但语法与 HOL 略有不同（类型约束写在构造子参数里）。
