## 1. 一个新手最常见的困惑

打开 .NET 的官网，你会撞见一堆名词：C#、.NET、.NET 10、CLR、BCL、MSBuild、NuGet……它们不是同一种东西。一张图理清层级：

```text
┌──────────────────────────────────────────────────┐
│ 你的代码（C# 源文件 .cs / 工程文件 .csproj）        │  ← 你写的
├──────────────────────────────────────────────────┤
│ C# 语言 + 编译器（Roslyn）                          │  ← 语言：语法规则
│     把源码编译成 IL（中间语言）                      │
├──────────────────────────────────────────────────┤
│ CLR（公共语言运行时）                                │  ← 运行时：加载/JIT/GC/线程
│     JIT 把 IL 翻译成机器码；垃圾回收也在这           │
├──────────────────────────────────────────────────┤
│ BCL（基础类库）                                     │  ← 类库：Console/List/File/…
│     几万个现成类型，你天天 using 的东西              │
└──────────────────────────────────────────────────┘
```

各自一句话：

| 名词 | 是什么 | 类比 |
|---|---|---|
| **C#** | 一门编程语言（语法规则） | 汉语的语法 |
| **.NET** | 平台总称：运行时 + 类库 + 工具链 | "汉语世界"（语法+词典+出版社） |
| **CLR** | .NET 的执行引擎（JIT、GC 所在） | 出版社的印刷厂 |
| **BCL** | 基础类库（`Console`、`List<T>`、`File`…） | 一本大词典 |
| **IL** | 编译产物（中间语言），装进 dll/exe | 出版前的排版稿 |

说"C# 程序跑在 .NET 上"：你写 C# → 编译成 IL 装进程序集 → CLR 加载 → JIT 逐方法翻译成机器码 → CPU 执行。运行 `examples/01_overview` 能亲眼看到这条链上的运行时版本、程序集路径等信息。

## 2. C# 的版本演化线（2026 视角）

C# 从 2002 年的 1.0 到今天，每年 11 月随 .NET 新版发布一次，当前是 **C# 14**（搭配 .NET 10）。不必背版本号，但要知道几个改天换地的节点：

| 版本 | 年份 | 里程碑 | 本教程章节 |
|---|---|---|---|
| 2.0 | 2005 | 泛型 | 第 12 章 |
| 3.0 | 2007 | LINQ、lambda、var、扩展方法 | 第 15-17、20 章 |
| 5.0 | 2012 | async/await | 第 28 章 |
| 6~8 | 2015-19 | 表达式成员、可空引用类型、switch 表达式 | 第 19、21 章 |
| 9~11 | 2020-22 | record、顶层语句、模式匹配大扩充、原始字符串 | 第 11、03、19、06 章 |
| 12~14 | 2023-25 | 主构造函数、集合表达式、扩展成员 | 第 08、20 章 |

**学习策略**：按特性学、不按版本学——现代 C# 代码里三代特性混用是常态，本教程全部用当代写法。

## 3. C# 的性格：强类型 + 多范式

- **强类型**：变量类型编译期定死，`"abc" + 123` 编译器要么报错要么明确转换——错误在上线前抓住，而不是半夜炸在生产环境
- **多范式**：面向对象（类/继承/接口，第 8-10 章）、函数式（lambda/LINQ，第 15-17 章）、如今还有低层能力（Span/unsafe，第 26-27 章）
- **托管运行**：内存由 GC 管（第 25 章），你很少直接碰指针；但需要性能时也能开 unsafe 下探

这门语言的哲学可以概括为一句话：**让常见事情简单，让罕见事情可能**。

## 4. C# 能干什么

- **桌面应用**：WPF/WinForms/WinUI 3（本仓库的 win32/mfc/wpf/WinUI3 教程是它们的家谱）
- **Web**：ASP.NET Core（网站、API、微服务——业界最大用量的方向）
- **游戏**：Unity 的脚本语言就是 C#
- **移动**：MAUI（一套代码 iOS/Android）
- **云原生/CLI 工具/AI 工程**（Semantic Kernel 等）

本教程专注**语言本身**：36 章讲透 C# 的类型系统、语法与运行机制。平台应用见 `dotnet` 教程（Web/EF/测试）与 WPF 教程（桌面 GUI），三者的关系：**csharp 深挖语言 → dotnet 用语言建平台应用 → wpf 用语言建桌面界面**。

## 常见坑

**C# 和 .NET 混用**：".NET 是语言" "C# 是框架"——都反了。C# 是语言，.NET 是平台。

**以为 .NET 只能在 Windows**：2016 年 .NET Core 起 Linux/macOS 一等公民；只有 WPF/WinForms 这类桌面框架限 Windows。

**追新版本焦虑**：新版特性是"可选进化"，旧代码不用重写。先学通第 3~19 章的核心，新特性是锦上添花。

## 自测

1. **C#、.NET、CLR、BCL 四者关系？** —— C# 是语言（编译成 IL）；.NET 是平台总称；CLR 是运行时（JIT/GC）；BCL 是基础类库。
2. **一段 C# 代码怎么变成屏幕上的输出？** —— 编译成 IL 装进程序集 → CLR 加载 → JIT 译成机器码 → CPU 执行。
3. **C# 3.0 和 5.0 各带来了什么划时代特性？** —— LINQ/lambda 家族；async/await。
