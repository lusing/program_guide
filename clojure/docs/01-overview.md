# 01 · 认识 Clojure ⭐

> 对应示例：无（本章是全景与心智模型；第一个可运行示例在 03 章）

> Clojure 是一门**运行在 JVM 上的 Lisp**，2007 年由 Rich Hickey 发布。
> 它把 Lisp 的"代码即数据"与 Java 生态的"二十年底蕴"焊接在一起，
> 用**不可变数据 + 少数几种受控的可变引用**重新回答了"状态怎么办"。

## 1.1 三根支柱

1. **不可变的持久化数据结构**：`[1 2 3]`、`{:a 1}`、`#{:x}` 永远不可改。"修改"返回新值，老值毫发无损——底层靠结构共享（05 章），`conj` 一百万次也不复制一百万份。
2. **函数式转换管线**：日常代码是 `map` / `filter` / `reduce` / 线程宏（09 章），状态被隔离进 `atom` / `ref` / `agent`（14 章）。
3. **Lisp 元编程**：代码就是嵌套列表，宏在编译期生成代码（11 章）——`when`、`->`、`or` 这些"语法"全都是普通宏，你写的一样好。

## 1.2 S-表达式：前缀记法

```clojure
(+ 1 2)              ; => 3        括号在前面，运算符也在前面
(* 3 (+ 1 2))        ; => 9        嵌套就是组合，没有优先级表要背
(println "Hi")       ; 打印 Hi，返回 nil（副作用函数返回 nil 是惯例）
```

前缀记法的直接红利：**没有运算符优先级**（`*` 和 `+` 谁先算？括号说了算）、**天然支持 n 元**（`(+ 1 2 3 4)`）、**宏看到的代码和写的一模一样**（homoiconicity，11 章）。

Clojure 在传统 Lisp 之上加了几种**集合字面量**——这是它对老 Lisp 最显眼的改良：

| 字面量 | 类型 | 老 Lisp 的写法 |
|---|---|---|
| `'(1 2 3)` | list | `(list 1 2 3)` |
| `[1 2 3]` | vector | `(vector 1 2 3)` |
| `{:a 1, :b 2}` | map | `(gethash ...)` |
| `#{1 2 3}` | set | 无对应物 |
| `:keyword` | keyword | `:keyword`（Common Lisp 也有） |

## 1.3 值、标识与时间

Rich Hickey 的核心洞察（演讲 "Are We There Yet"）：多数语言的"变量"把**值**（value）、**标识**（identity）、**时间**（time）搅在一起。Clojure 把它们拆开：

- **值**：不可变。`42`、`"hi"`、`{:name "Alice" :age 30}` 是值，31 岁的 Alice 和 30 岁的 Alice 是两个不同的值。
- **标识**：`atom`/`ref` 是"随时间指向不同值的稳定名字"。`(def age (atom 30))` 之后 `@age` 今天是 30、明天是 31——变的是引用指向，不是值本身。
- **时间**：`swap!`/`dosync` 保证"观察-计算-替换"的过程原子。

对照主流语言：`x = x + 1` 在命令式语言里是**原地覆写**（值被摧毁）；在 Clojure 里你会写成"基于旧值算出新值，原子地装回引用"。差别看似微小，却是并发正确性的全部来源（14 章）。

## 1.4 放在 Lisp 家族里看

| | Clojure | Common Lisp (SBCL) | Scheme (R7RS) |
|---|---|---|---|
| 宿主 | JVM（另有 CLR/JS 移植） | 原生编译 | 多实现 |
| 命名空间 | Lisp-1（函数变量同域） | **Lisp-2**（函数变量分域） | Lisp-1 |
| 数据结构 | 持久化不可变 | 可变 | 可变 |
| 并发 | STM/atom/agent | 锁 | 并发模块 |
| 集合字面量 | `[]` `{}` `#{}` | 无 | 无 |
| 宏 | syntax-quote + gensym | defmacro + gensym | 卫生宏 |

两个常见误解要澄清：**Clojure 是 Lisp-1**——函数和变量共用一个命名空间，函数是一等值，传函数不需要 `#'f` 取"函数对象"（那只是取 Var 本身）。**Clojure 不是纯函数式**——它允许副作用，但用引用类型把副作用圈进明确定义的位置，而不是撒满全局。

## 1.5 为什么值得学

- **务实**：直接用 Java 的全部生态（15 章）——数据库驱动、加密库、HTTP 客户端，一个都能不少。
- **数据优先**：JSON/EDN 天然映射到 map/vector，写"数据处理"类程序异常顺手（22 章）。
- **并发模型**：STM 与 atom 把"多线程改共享状态"从雷区变成日常（14 章）。
- **REPL 文化**：程序跑着，你逐个表达式求值、改函数、立即生效——反馈回路比"编译-重启-打断点"短一个量级。
- 生产案例：Nubank（数亿用户银行核心）、Walmart、CircleCI 后端早期、大量数据处理系统。
