3. 能走完 3-CNF-SAT → CLIQUE → VERTEX-COVER 的构造与正确性论证；
4. 理解「归约的方向」：证明 X 是 NPC，要把**已知的 NPC 问题归约到
   X**（不是反过来）；
5. 知道面对 NPC 问题时的五条出路（精确指数/近似/参数化/启发式/

6. 会写排列树并说清「swap 必须换回来」「下标必须 1-based」两条纪律；

7. 能推导并实现状压 DP 求精确色数 `f[S] = 1 + min{f[S\I]}`，

8. 能用**三重求和夹逼**证出三角 N-后的上界 `⌊(2N+1)/3⌋`，

9. 会用归约矩阵构造 TSP 下界，实现包含/排除二叉分支限界并与暴力

10. 会解哈密尔顿回路（判定 + 构造）：回溯固定起点剪旋转对称，与
    Held-Karp 状压 DP O(n²2ⁿ) 互校；知道 Dirac/度数条件只是充分
    不必要。

## 多项式归约：问题之间的「若则」桥

X ≤p Y（X 多项式归约到 Y）＝ 存在多项式可计算的变换 f，使
x 是 X 的 yes 实例 ⟺ f(x) 是 Y 的 yes 实例。三个直接推论：

- **传递**：X ≤p Y 且 Y ≤p Z ⟹ X ≤p Z；
- **下界传染**：X ≤p Y 且 Y ∈ P ⟹ X ∈ P（「Y 容易则 X 容易」）；
- **硬度传染**：X 是 NPC 且 X ≤p Y 且 Y ∈ NP ⟹ Y 是 NPC——**归约链
  就是 hardness 的传播链**，本章证明全部长这个样。

**方向学**（最易犯的错）：要证 Y 难，必须拿一个已知的难 X 归约到
Y——「我把 Y 归约到 X」什么也没证明（把难题变到难题是白说，难题变
到容易的 X 只说明 Y 可能容易）。

## 三个复杂度类

- **P**：多项式时间**可解**（判定问题）；第 2–33 章的全部成果都在 P。
- **NP**：多项式时间**可验证**——存在多项式长的「证书」，验证器多
  项式时间核验（满足赋值之于 SAT、哈密顿圈之于 HAM-CYCLE、完美
  匹配之于二分图——注意后者其实也在 P，类成员与难度无关）；
- **NPC**（NP 完全）：NP 里最难的一族——任何 NP 问题都 ≤p 到它。
  Cook-Levin 定理给出第一块基石：CIRCUIT-SAT 是 NPC（计算本身的
  布尔电路化），随后 SAT（§34.?）→ 3-CNF-SAT 逐级归约。

P ⊆ NP 是平凡包含；**P = NP?** 未知。主流猜想是不等——那时 NPC 问题
没有多项式算法，本教程的第 36 章才有存在理由。

## 可执行的归约链（示例 35）

**实例**：φ = (x₁∨¬x₂∨x₃)∧(¬x₁∨x₂∨x₄)∧(¬x₂∨¬x₃∨x₄)∧(x₁∨x₂∨¬x₄)。
暴力枚举 16 个赋值：**8 个满足**（裁判的真值表）。

**归约 1：3-CNF-SAT → CLIQUE**（定理 34.11）。构造：每个子句的每个
文字一个顶点（4×3 = 12 顶点）；两个顶点有边 ⟺ 不同子句 ∧ 文字不
矛盾。**断言：φ 可满足 ⟺ 图有大小 k=4 的团**：

- (⇐) 团内每两顶点有边 ⟹ 互不矛盾（一文字一子句取值可以一致）且
  恰好每子句一个（不同子句才连边）→ 读出一个满足赋值；
- (⇒) 满足赋值每子句选一个真文字 → 4 个顶点两两不矛盾 → 团。

实测（示例 35.2）：12 顶点 45 条边；从赋值 (0,0,0,0) 导出团
{1, 3, 6, 11}（分别取 ¬x₂, ¬x₁, ¬x₂, ¬x₄），程序逐对验证团内全边。

**归约 2：CLIQUE → VERTEX-COVER**（定理 34.14? 34.5-?）。补图变换：
G 有 k 团 ⟺ Ḡ 有 n−k 顶点覆盖（团的补集在补图中恰好覆盖所有补边）。
实测（示例 35.3）：补图 21 条边；取非团的 8 顶点，覆盖检验通过。

```
归约 1（3-SAT→CLIQUE）：12 顶点、45 条边、目标团大小 k = 4
    从满足赋值 x=(0,0,0,0) 导出 4 团：顶点 { 1 3 6 11  }（两两有边）
归约 2（CLIQUE→VC）：补图 21 条边；取非团的 8 顶点，覆盖检验 = 1
三方对账：满足赋值 → 4 团 → 补图 8 覆盖，全部成立
```

**三方对账**的意义：归约的构造性证明（两个方向的蕴含）在具体实例上
走通——「证明的抽样验证」，与第 2 章循环不变式的 assert 抽样同一
哲学。

## 面对 NPC 问题的五条出路

1. **精确指数但可剪枝**：SAT 求解器（DPLL/CDCL）的工业神话——百万
   变量的真实实例照啃（最坏仍指数，实际输入友好）；回溯 + 剪枝清单
   见 35.5；
2. **近似算法**（第 36 章）：顶点覆盖 2 近似、TSP（度量版）2 近似；
3. **参数化**：固定参数可解（FPT）——顶点覆盖按 k（解大小）指数、
   按 n 多项式；
4. **启发式/随机化**：模拟退火、遗传算法——无保证但常管用；
5. **记忆化 + 位掩码状态压缩**（本节新增，也是最容易被忽略的一条）：
   当**状态本身能用一个小整数描述**时，指数可以压到状态数而不是解空间
   大小。两种典型：

   - **记忆化**（哈希表 / 置换表）：同一个失败局面只算一次。适用面比
     想象广——凡是「后继只依赖当前局面、与到达路径无关」的问题都能用。
     井字博弈、博弈树搜索（4×4 只需算 3^16 = 4.3×10⁷ 个状态的上界，
     实际可达状态远少于此）是标准例子。
   - **位掩码状态压缩**：`f[S]` 的 `S` 是一个顶点集合时，用 `uint32_t`
     的第 `i` 位表示「顶点 i 在集合里」，于是集合运算变成位运算
     （`S \ I` 是 `S & ~I`、邻接判定是 `pre[v] & S`），且状态能直接
     当数组下标。**指数从 mⁿ 降到 2ⁿ**（35.6 的色数 DP）或 `3ⁿ`
     （枚举独立集族）。

   **什么时候这条最有效**：n 小（≤ 20）但**判定结构能编码进一个整数**
   时。它不改变问题的 NP 性质，只是把「指数的底数」压到状态数。
   反之，若状态无法压进一个机器字（n 上百、或状态是任意子集之外的
   结构），这条路就断了——此时只剩前面四条。

   **注意它常与前四条组合**：FPT 是「按参数 k 记忆化」（第 3 条），
   位压缩是「按 n 的小规模记忆化」（第 5 条），而剪枝是第 1 条——
   工业求解器三样都有。

## 回溯三框架与剪枝清单

NPC 问题在**小规模**上仍然可解——工具就是回溯。但回溯的可用性完全由
**解空间规模 S** 决定：任何「枚举解空间」的算法至少是 Ω(S)。所以第一个
问题永远是「S 多大」，第二个才是「怎么剪」。

### 三个框架的精确规模

设解向量 `x = ⟨x₁,…,xₙ⟩`，第 k 层取值域 `Ω_k`（`|Ω_k| = m_k`）：

| 框架 | 做法 | 规模 | 主导项 |
|---|---|---|---|
| 一般回溯 | 每层遍历 `Ω_k` | **Θ(mⁿ)** | 叶层 `∏m_j = mⁿ` |
| 排列树 | 固定后缀、逐位交换 | **Θ(n!)** | 叶数恰 = n! |
| 子集树 | `x_k ∈ {0,1}` | **Θ(2ⁿ)** | 叶数 = 2ⁿ |

排列树的写法（`x` 是 1-based）：

```cpp
for (int i = k; i <= n; ++i) {
    std::swap(x[k], x[i]);
    if (IS_PARTIAL(x, k + 1)) { PERMUTATION_TREE(x, k + 1); }
    std::swap(x[k], x[i]);      // ← 必须换回来，否则漏解
}
```

「固定后缀 + 逐位交换」保证每个排列**恰好生成一次**——实测 n = 5/8/10 的
叶数分别是 120/40320/3628800，**精确等于 n!**，不多不少（节点总数略大，
因为内部结点也计数：n = 10 时 9864101 个）。

**必须换回来**：漏掉 `swap` 还原是最隐蔽的一类 bug。实测 n = 4 时，
漏还原版的**叶数仍是 24**（搜索树的形状没变！），但最大值从 4321 变成
3421——**少报了一个解**。这类 bug 不改叶数、不改递归次数、不改耗时，
只改答案，测试往往只查「跑通了没」而查不出「答案全不全」。
**所以断言必须打在值上，不能只打在计数上。**

**下标必须 1-based**（配套的另一个坑）：0-based 时循环写成 `i < n`，
基例 `k > n` **永不触发**，递归会在 `k = n` 时空转返回——**一个解都不
记录**。写排列树时这两点要一起检查。

**增量维护**。为每个正在探索的部分解维护 `current_value`（进递归时加、
出递归时减），为最优解维护 `best_value` 与 `best_x`（最大化初值 −∞、
最小化 +∞）。到达完整合法解时比较并更新。不增量维护就要在每个节点
重算 `O(n)`，白扔一个因子。

### 剪枝清单

剪枝是回溯能否实用的**唯一关键**。五类，每条都以「S 从多少降到多少」
量化：

1. **可行性剪枝**：部分解已违反约束立即回溯（`IS_PARTIAL`）。例：N-后
   的「行列差值不能重复」检查。本章 35.7 的三角 N-后若只查行列，Θ(2ᴺ)
   在 N > 10 时就跑不动。
2. **上下界剪枝**：用**乐观估计** `g(x)`（当前部分解能达到的最优值的
   上界）剪——`g(x)` 已不优于 `best_value` 就回溯。实测 8 元子集和：
   解空间 2⁸ = 256，带剪枝只访问 **1 个叶**、剪掉 8 次。关键是 `g` 要
   **乐观**（宁可多剪不了，不可剪错）：「剩下全选」是子集和问题的合法上界。
3. **对称性消除**：解在某个变换下等价 ⟹ 只枚举代表元。环状排列固定
   首元：`n! → (n−1)!`（n = 8 时 40320 → 5040，省 8 倍）；N-后利用左右
   镜像对称，首行只枚举一半：`n! → n!/2`。
4. **只枚举未定位置**（常量消除）：输入里已固定的分量不再参与排列。
   8 元问题里 5 个位置已定 ⟹ 只对 3 个未定位置做排列树：`8! = 40320 →
   3! = 6`，**省 6720 倍**。这常常比任何剪枝都管用。
5. **失败子问题记忆化**：状态空间小的博弈/搜索问题（AND-OR 树、博弈树）
   必须改用记忆化，否则阶乘级爆炸——同一个局面算一次就够了。

### 「S + 剪枝」比精确 Θ 更实用

精确的 Θ 只告诉你**最坏**有多坏；工程上真正要回答的是「这台机器上
跑不跑得动」，那要看 **S 规模 + 剪枝率**。一个 Θ(2ⁿ) 的算法在
n = 30、剪掉 99.9% 时可能秒出，反之一个 Θ(n²) 但无剪枝的算法在
n = 10⁵ 时照样超时。**报复杂度时把 S 与实际剪枝效果一起报，才是可用的
复杂度。**

## 状压 DP：精确求图色数

**问题**：给 n 个顶点（n ≤ 10）与邻接关系，每个顶点染一种颜色，相邻者
颜色不同，求**最少**颜色数 χ(G)。这等价于「地图国家染色」——每个国家
染一色，共享正长度边界的两国不同色。

**为什么不能靠回溯**。让 m 从 1 递增、反复调用 m-染色回溯，单次
Θ(mⁿ)、共试 m = 2..χ 次，总 **Θ(χ^(n+1))**。n = 10、χ = 5 时约 5×10⁷
勉强；χ = 8 时 10⁹ 不可行。**指数底数从 m 变成 χ 是关键**——它比单次
回溯还多一个指数因子。状压 DP 把底数压回 3。

### 状态与转移

设 `f[S]` = 诱导子图 `G[S]` 的色数，`f[∅] = 0`。取 `S` 中**编号最小**的
顶点 `v`，则

```
f[S] = 1 + min { f[S \ I] : I ⊆ S 为独立集，v ∈ I }
```

计算顺序按 `|S|` 递增（`S \ I` 严格更小，依赖已就绪）。

**独立集判定 O(1)**：预处理 `pre[v]` = `v` 的邻居位掩码，则 `I` 是
独立集 ⟺ 对每个 `v ∈ I` 有 `pre[v] & I == 0`。逐个顶点判 O(|I|)，
用「最小位 + 递推」摊到 O(1)：`indep[S] = indep[S \ {v}] && ((pre[v] & (S \ {v})) == 0)`。

### 正确性（两个方向都要证）

**（⇒ 下界）** 任取 S 的一个合法染色。`v` 所在的**颜色类**在 S 上恰是
一个含 `v` 的独立集 `I`（同色 ⟹ 无相邻 ⟹ 独立集），其余顶点用
`S \ I` 上诱导子图的合法染色，需要 ≤ `f[S \ I]` 种颜色。总颜色数
= 1 + (S∖I 用的色数) ≥ `1 + f[S \ I] ≥ 1 + min f[S \ I]`。故
`f[S] ≥ 1 + min{...}`。

**（⇐ 上界）** 任取一个含 `v` 的独立集 `I ⊆ S`。把 `I` 里所有顶点染成
**同一种新颜色**（合法，因为 `I` 独立，内部无相邻）；`S \ I` 用
`f[S \ I]` 种颜色（对更小的子问题递归，这是良基的）。`I` 用新色、`S \ I`
用旧色，两部分之间**不可能有同色相邻**（新色只出现在 I 内）⟹ 合法染色，
用色数恰为 `1 + f[S \ I]`。故 `f[S] ≤ 1 + min{...}`。

两个方向合起来即等式。∎

### 为什么是 O(3ⁿ)

枚举 `S` 的独立集族时，每个元素恰有**三种归属**：
**在 `S \ I` 里** / **在 `I \ {v}` 里**（`I` 除去 v 后与 v 无邻）/ **就是 v**。
三种选择的组合数是 `3^|S|`，故总时间 **O(3ⁿ)**，空间 **O(2ⁿ)**。
n = 10 时 3¹⁰ = 59049，**瞬间完成**。

（更快的版本：转移时只枚举**极大独立集**——含 v 的极大独立集一定存在
且数量远少于全部独立集，可降到 `O(2ⁿ·n)`。但 n ≤ 10 时没必要。）

**实测对账**：K₄ → 4、K₅ → 5、C₅（奇圈）→ 3、K₃,₃ → 2、空图 → 1；
另外 48 个随机图（n = 1..8）上 DP 的 χ 与「m 从 1 递增 + m-染色回溯」的
最小可行 m **逐一相等**。

**四色定理不适用**。定理要求每个国家是**连通**区域；而「同一国家可以有
多个不相连区域」使缩点后的国家邻接图**不一定是平面图**——上例的 K₅ 就是
反证（χ = 5 > 4）。所以本题不能直接答 4。

## 三角 N-后：先证上界，再给构造

**问题**：边长 N 的三角棋盘（格点 `(i,j)`，`1 ≤ j ≤ i ≤ N`，斜边为主对角线
方向），放尽可能多的互不攻击的皇后。两个皇后 `(i₁,j₁)`、`(i₂,j₂)` 互不攻击
⟺ `i₁ ≠ i₂` 且 `j₁ ≠ j₂` 且 `i₁ − j₁ ≠ i₂ − j₂`（竖直、水平、平行斜边
三个方向）。

### 上界 `⌊(2N+1)/3⌋`：三重求和夹逼

设放了 `k` 个皇后，位置 `(i₁,j₁), …, (i_k,j_k)`。**三个方向各不重复**
给出三个不等式：

- **行号** `i₁,…,i_k` 是 `[1,N]` 中 k 个互不相同的整数 ⟹ 取最大的 k 个
  时和最大：`Σi ≤ N + (N−1) + ⋯ + (N−k+1) = k(2N−k+1)/2`；
- **列号** `j₁,…,j_k` 是 k 个互不相同的正整数 ⟹ 取最小的 k 个时和最小：
  `Σj ≥ 1 + 2 + ⋯ + k = k(k+1)/2`；
- **差值** `d_t = i_t − j_t ≥ 0`（因为 `j ≤ i`）且两两不同 ⟹ 是 k 个互不
  相同的非负整数 ⟹ `Σd ≥ 0 + 1 + ⋯ + (k−1) = k(k−1)/2`。

关键的一步是**把这三式串起来**，因为 `Σd = Σi − Σj` 是同一个量：

```
k(k−1)/2  ≤  Σd  =  Σi − Σj  ≤  k(2N−k+1)/2 − k(k+1)/2  =  k(N−k)
```

（右侧化简：`k(2N−k+1−k−1)/2 = k(2N−2k)/2 = k(N−k)`。）两边同除 `k`：

```
(k−1)/2 ≤ N − k   ⟹   k − 1 ≤ 2N − 2k   ⟹   3k ≤ 2N + 1   ⟹   k ≤ ⌊(2N+1)/3⌋
```

∎ 这个证明漂亮的地方在于**它不依赖任何搜索**——回溯逐行决定放不放是
Θ(2ᴺ)，`N > 10` 就跑不动，**上界只能靠代数证**。实测三例（N = 10/20/30）
把夹逼的每一项都算出来对照。

### 构造：奇偶两段，Θ(N)

设 `q = ⌊N/3⌋`，把 `k = ⌊(2N+1)/3⌋` 个皇后摆成**两段**：

```
段 A：行 q+1 … 2q+1（连续 q+1 行），列 q+1, q, …, 1（递减）
      ⟹ 差值 i−j = 0, 2, 4, …（**偶数段**，共 q+1 个）
段 B：行 2q+2 …（连续段），列 2q+1, 2q, …（递减）
      ⟹ 差值 i−j = 1, 3, 5, …（**奇数段**，共 q 或 q−1 个）
```

三条合法性逐一验证（不靠「看起来对」）：

- **行号两两不同**：段 A 占 `[q+1, 2q+1]`，段 B 占 `[2q+2, …]`，两段
  行区间**不交**；段内行号连续故互异。✓
- **列号两两不同**：段 A 占 `[1, q+1]`，段 B 从 `2q+1` 往下且长度 ≤ q
  ⟹ 段 B 的列 ≥ `2q+1 − q + 1 = q + 2 > q + 1`，两段**不交**。✓
- **差值两两不同**：偶数段与奇数段**天然不交**（奇偶性）——**这是选
  「奇偶两段」而不是「奇偶列」的关键**。✓
- **棋盘形状**：`j ≤ i` 逐点成立（`|i − j| = 差值 ≥ 0` 即 `i ≥ j`）。✓

段长取 `sizeA = q+1`、`sizeB = q`（`N mod 3 ≠ 0`）或 `q−1`（`N mod 3 = 0`），
使总数恰为 `⌊(2N+1)/3⌋`——**达到上界，故最优**。实测：`N = 7` 得
`(3,3)(4,2)(5,1)(6,5)(7,4)`（5 个 = ⌊15/3⌋）；`N = 10` 得 7 个；
`N = 1000` 得 667 个。**穷举校验 N = 1..2000 全部通过，失败 0 个。**

### 「先证上界、再给构造」是标准套路

这是组合优化里最有用的三步曲：

1. **先证上界**——不搜就知道天花板在哪，而且是**代数夹逼**出来的，
   不是「搜出来只有这么多」（后者只是上界的一个**下界**估计，搜索没跑完
   就不能断言）。
2. **再给达到上界的构造**——最优性变成**证明**出来的，不依赖搜索的运气、
   不依赖「我跑到了就应该是最优」。
3. **构造本身是 Θ(N) 闭式**——比任何搜索都快几个量级，且没有「最坏情形」。

对照本章 35.6 的状压 DP（`O(3ⁿ)`，n ≤ 10 可接受）：**同样是 NP 问题，
「判定规模」决定用搜索（DP/回溯）还是用构造**。n = 10 用 DP，n = 10⁶
只能靠「证上界 + 构造」——因为 `2ⁿ` 连表示都做不到。

## TSP 分支限界：归约矩阵下界（35.8）

TSP 没有多项式精确解，但**分支限界**（branch and bound）能让 n 几十的
实例瞬时求到**可证明的最优**——不是启发式：它把解空间组织成搜索树，
每个节点带一个「本支最优值的下界」，下界 ≥ 现行最好解（incumbent）的
分支整支剪掉。关键全在下界的质量：下界越紧，剪掉的越多。

### 把旅游看成指派

一条从 0 出发的有向旅游，每个顶点恰有一条出边（**每行选一格**）、恰有
一条入边（**每列选一格**），且 n 条边构成**单环**。先放宽「单环」要求：
任何「每行每列各一格」的选取（指派）的代价，都是 TSP 最优值的下界——
旅游是合法指派之一，最优指派 ≤ 最优旅游。

### 归约矩阵：常数和就是下界

对权矩阵（对角置 ∞）做**行归约**：每个存活行减去行内最小值；再**列
归约**：每列减去列内最小值。两个事实：

1. 归约不产生负元素（减的是本行/列最小值）；
2. 任何「每行每列各一格」的指派，恰从每行取一格、每列取一格——
   每行的减项恰好贡献一次，列同理。所以**每个指派的代价都减少同一个
   常数** R（所有减去值之和），指派之间的优劣完全不变。

常数 R 因此是原矩阵任何指派（因而任何旅游）都**至少**要付的代价：
下界 = R。归约后矩阵每行每列至少一个 0——若能选 n 个互不共行列的
0 格组成指派，该指派就达到下界、立刻是最优。

### 包含/排除二叉分支

下界不等于答案时，取当前路径末端所在行的一个 0 格 (i,j)，把解空间
**二歧地**切开：

- **包含支**（旅游用边 i→j）：删行 i、删列 j（出/入边名额已用），
  并**禁掉 j 直接回起点 0 的边**——前缀还没走遍全部顶点时闭合必形成
  短环（其余存活行只能自相成环）。对剩余矩阵重新归约，新增归约常数
  r₁ 把下界抬高到 R+r₁，路径追加 j。
- **排除支**（旅游不用 i→j）：把 (i,j) 置 ∞，重新归约，下界抬高到
  R+r₂，路径不动。

叶子：路径含全部 n 个顶点，用**原矩阵**算路径边 + 闭合边的真实代价，
更新现行解。每个节点进门先查 `下界 ≥ 现行解 ⇒ 剪枝`；最坏仍是指数
（35 章的判决不会失效），但实测节点数极小。

### 对账与规模

固定 5 顶点例：B&B 给出代价 18、路径 0→3→2→1→4→0，与 (n−1)!=24
条旅游的暴力枚举一致，只访问 17 个节点。300 个随机 n=4..8 矩阵上
0 例不一致，平均约 30 个节点。n=24 的植入环大例（环边权 1、其余
100，最优 24）只访问 47 个节点——暴力要枚举 23! ≈ 2.585×10²² 条。

## 哈密尔顿回路：回溯与 Held-Karp（35.9)

经过每个顶点**恰一次**并回到起点的环。判定版是 NP 完全（CLRS 练习
34.2-?：由 3-SAT 归约，哈密尔顿回路是 NPC 名录里的元老）——它与
TSP 的关系：给无权图每条边权 1、非边权 ∞，哈密尔顿回路存在 ⟺ TSP
最优 = n。小实例的两条精确解法：

### 回溯：固定起点剪掉旋转对称

环的旋转对称让起点可以**固定为顶点 0**（n 个等价起点缩成 1 个），
排列树从 (n−1)! 枝减为必要时再谈。逐位试**未访问的邻点**（邻接剪枝
比裸排列强得多），放满 n 个点后检查最后一点与 0 有边闭合。找到即
返回整条回路——判定与构造一体。

### Held-Karp：状压 DP

> dp[S][v] = 1 ⟺ 存在从 0 出发、恰经过 S（含 0 与 v）、止于 v 的路径

转移：dp[S∪{w}][w] |= dp[S][v] ∧ adj[v][w]（w ∉ S）。答案 = 存在
v 使 dp[全集][v] ∧ adj[v][0]。**O(n²·2ⁿ) 时间、O(n·2ⁿ) 空间**——
它正是 35.6 色数 DP 与 27 章 TSP 分支限界的共同祖先（Held-Karp 1962），
比暴力 (n−1)! 在 n=20 时已是 10⁶ 倍差距。判定版只需布尔表；求最优
TSP 时换成 min 就行（35.8 的下界正是它的松弛）。

```
=== 35.9 哈密尔顿回路：回溯 vs Held-Karp 状压 DP ===
  固定例（5 点 7 边）：回溯给出回路 1→2→3→5→4→1（闭合）；Held-Karp 判存在 = 1
  挂一个孤立点：两口径同判「无回路」= 1
  随机 300 例（n≤9）：两口径不一致 0 例（有回路的 56 例）
  大例（18 顶点、边概率 45%）：Held-Karp 判存在 = 1
```

固定例（5 点 7 边：12/14/23/24/34/35/45）回路 1→2→3→5→4→1 手数
可核；挂一个孤立顶点后两口径同判不存在（度 ≤ 1 的点必不在任何
哈密尔顿回路里——必要条件）。300 个随机图（n ≤ 9）上回溯与 DP
0 例不一致；18 顶点大例只跑 Held-Karp（2¹⁸·18² ≈ 8500 万步，瞬时）。

**充分 vs 必要的分寸**：Dirac 定理（每个顶点度 ≥ n/2 ⟹ 哈密尔顿
回路存在）等充分条件只需 O(n) 检查，但**不必要**——固定例里顶点 1
的度只有 2 < 5/2，回路照样存在。充分条件用来「白捡 yes」，判定与
构造还得靠指数算法。

## C++23 语言点

- 邻接矩阵 `vector<vector<char>>`（12 顶点小图——稠密判定方便）；
- 文字编码 int（+k/−k 表示 xₖ/¬xₖ）——**变元 × 极性**的紧凑表示；
- `char` 直接进 format 打成控制字符（0/1 的 ASCII）——布尔值打印
  必须 `static_cast<int>`（本例实测翻车，六条判定的控制字符闸门
  当场拦截）。
- 35.6 的状态用 `std::uint32_t` 位掩码：集合运算全部变位运算
  （`S \ I` 是 `S & ~I`、邻接判定是 `pre[v] & S`），且掩码**直接当
  `vector` 下标**——`f[S & ~I]` 不需要查表。找最低位用
  `std::countr_zero`（`<bit>`）。
- 35.6 的 `f[S]` 公式进 `format` 串时 `{` 要转义（`min {{ f[S \ I] }}`），
  或者像示例那样改用 `∖`（U+2216 集合减）与 `∅` 等非 ASCII 数学符号——
  后者更可读，且不会忘记转义。

## 坑位清单

1. **归约方向做反**
   （现象：拿未知问题归约到 3-SAT 然后宣称「证明了它 NPC」；原因：
   方向反了——那只证明它「不比 3-SAT 难」；对策：背口诀「要证难，
   难者来」——已知的难问题归到新问题上。）
2. **构造变换不满足「iff」只做了「只若」**
   （现象：归约的两个方向只证了一个（通常只证了 可满足→团）；
   后果：只保证单向，问题可能在 Y 侧轻易求解；对策：两个方向的
   蕴含都要写——示例的三方对账就是把两个方向都跑通。）
3. **char 布尔值进 format**
   （现象：stdout 出现控制字符、判定第 4 条炸、gcc 与 msvc 显示
   不一致；原因：`std::format` 把 char 按字符打印——0/1 是控制字符；
   对策：static_cast<int>（本例实测翻车）。）
4. **把 NP 当「非多项式」**
   （现象：口头说「NP 就是指数」；原因：NP 是「多项式可验证」——
   它可能全在 P 里（P=NP 若真）；对策：类定义逐字背，特别注意
   二分图完美匹配在 P 也在 NP（类成员≠难）。）
5. **实例太弱（满足赋值唯一/不存在）**
   （现象：归约演示碰巧跑通但没有检验力；原因：实例选择没让构造
   的边角（多解、矛盾对、跨子句约束）出现；对策：选 8/16 满足的
   实例（本例），证书侧（团/覆盖）单独暴力验证。）
6. **排列树漏掉 `swap` 还原**
   （现象：答案少了一个解（本例 n = 4 最大值 4321 变成 3421）；原因：
   交换后没换回来，数组被污染，后续交换在错误的排列上做；后果：**最隐蔽
   的一类 bug**——叶数不变（仍是 4! = 24）、递归次数不变、耗时不变，
   只改答案，「跑通了」的测试查不出来；对策：`swap` 严格配对，且**断言
   要打在值上**（`assert(best == 4321)`）而不是只打在计数上。）
7. **排列树用 0-based 下标**
   （现象：一个解都不记录，`best` 恒为初值；原因：循环写成 `i < n` 时
   基例 `k > n` **永不触发**，递归在 `k = n` 空转返回；后果：静默返回
   错误答案（连「空结果」都不是，是「未初始化」）；对策：排列树统一
   1-based（`x[1..n]`、循环 `i = k..n`、基例 `k > n`），三者配套。）
8. **色数 DP 的邻接掩码写错一位**
   （现象：K₄ 算出 χ = 2（真值 4），C₅ 算出 2（真值 3）；原因：邻接
   掩码的第 `u` 位含义搞反或写错位（K₄ 顶点 1 应是 `0b1101` 而非
   `0b1011`）；后果：**少染色**——DP 内部自洽但答案偏低，不崩溃只出错；
   对策：掩码是图的性质，**先单独手算核对一张小图的邻接掩码**（列出每个
   顶点的邻居列表），再喂给 DP。）
9. **错误直觉：地图染色直接答 4（四色定理）**
   （现象：国家邻接图含 K₅ 时输出 4；原因：四色定理要求每个国家是**连通**
   区域，而「同一国家允许多个不相连区域」使缩点图不必是平面图；后果：
   系统性偏小的答案；对策：缩点后判断图是否平面，非平面就得自己算 χ
   （状压 DP，n ≤ 10 瞬间完成）。）
10. **错误直觉：三角 N-后的上界是「搜出来只有这么多」**
    （现象：把回溯在 N = 8 找到的 5 个当成最大值；原因：搜索只给出一个
    **下界**（找到了这么多 ⟹ 至少能放这么多），没证明不能更多；后果：
    把「搜到的解」当「最优解」上报，n 稍大就错；对策：上界必须靠
    **三重求和夹逼**代数证出（`3k ≤ 2N+1`），再给达到上界的构造。）
11. **增量子集和不还原 `current_value`**
    （现象：剪枝判断全错，剪掉本该搜的分支；原因：进递归加了 `w[k]`
    但出递归没减（或减错对象）；后果：剪枝率异常高、`best` 偏小，
    且**不崩溃只偏小**；对策：加减严格配对，剪枝率与最优值同时断言。）
12. **包含支漏设「禁止短环」**
    （现象：B&B 给出比暴力更小的「最优」；原因：删行删列只保证指派
    结构，指派可能含多个互不相连的环——j 提前回 0 的边不堵，剩余顶点
    就会自相成环，拼出低于真实 TSP 的假方案；后果：假最优（最危险的
    一类错——程序自洽）；对策：前缀未满时禁 j→0，且全部结果与 (n−1)!
    暴力对账（本例 300 随机例的检验正为此）。）
13. **叶子用归约矩阵算代价**
    （现象：最优值系统性偏小；原因：归约矩阵的权已被逐层扣减，它给出的
    是「相对值」，真实旅游代价必须查原矩阵；对策：归约矩阵只服务下界，
    叶子路径定案后用 w 重算（本例写法）。）
14. **剪枝条件写成严格不等或方向相反**
    （现象：下界恰等于现行解时仍展开，节点数膨胀；或把最优支剪掉答案
    偏大；原因：`lb > best` 与 `lb ≥ best` 差一个等号——相等时该支至多
    追平现行解，不包含新答案，安全剪掉；对策：进门先剪，`>=` 且
    叶子先于剪枝更新 incumbent（叶子的 lb 必 ≤ 其真实代价）。）
15. **哈密尔顿回溯不固定起点**
    （现象：同一环被当作 n 个不同解反复搜、首解随机漂移；原因：环有
    n 个旋转起点 + 2 个方向，全等价；对策：固定起点 0（必要时再固定
    第二点访问序最小的邻居以砍镜像），回溯从 dfs(0,1) 起步。）
16. **Held-Karp 的 dp 初值/闭包边忘记含 0**
    （现象：n=2 的图恒判不存在、或漏判经过全部点的环；原因：dp[1][0]=1
    的初态要求 S **含 0**（循环里 `S&1` 跳过无 0 的集合）；收尾判
    dp[full][v] ∧ adj[v][0] 缺一不可——只查 dp 会把「路径」当「环」；
    对策：三角形（有环）与路径图（无环）两个最小锚点先行断言。）
17. **把 Dirac 条件当必要条件用**
    （现象：某点度 < n/2 就断言无回路；原因：Dirac（每点度 ≥ n/2）
    是**充分**条件，保证存在但不刻画全部存在情形——固定例中顶点 1
    度仅 2 却有回路；对策：充分条件只能输出 yes；no 与构造必须走
    精确算法（回溯 / Held-Karp）。）

=== 35.6 状压 DP：精确求图色数 χ(G) ===
  状态 f[S] = 诱导子图 G[S] 的色数；转移取 v = S 中编号最小者：
    f[S] = 1 + min { f[S \ I] : I ⊆ S 为独立集，v ∈ I }
  正确性（两个方向都要证）：
    (⇒ 下界) 任何 S 的合法染色里，v 所在的颜色类在 S 上是含 v 的独立集 I，
           其余 S\I 用 ≤ f[S\I] 色 ⟹ f[S] ≥ 1 + min f[S\I]
    (⇐ 上界) 对任意含 v 的独立集 I，用一色染 I、其余用 f[S\I] 色即得合法染色
  为什么 O(3ⁿ)：枚举 S 的独立集族时每个元素有三种归属 —— 在 S∖I / 在 I∖v / 是 v
  独立集判定 O(1)：I 独立 ⟺ 对每个 v ∈ I 有 pre[v] & I == 0
    空图（无边）（n = 4）：χ = 1（独立集 DP 精确值，期望 1）
       K₄ 完全图（n = 4）：χ = 4（独立集 DP 精确值，期望 4）
         C₅ 奇圈（n = 5）：χ = 3（独立集 DP 精确值，期望 3）
       K₅ 完全图（n = 5）：χ = 5（独立集 DP 精确值，期望 5）
     二分图 K₃,₃（n = 6）：χ = 2（独立集 DP 精确值，期望 2）
  K₅ 的 χ = 5 > 4 ⟹ **四色定理在这里不适用**：该定理要求每个国家是连通区域，
  而「同一国家有多个不相连区域」使缩点后的邻接图可以是 K₅ 这类非平面图。

  对账：随机图上 DP 的 χ 与「m-染色回溯」的最小可行 m 必须一致
    48 个随机图（n = 1..8）上 DP 与回溯逐一相等 —— 状压 DP 无误
  复杂度：时间 O(3ⁿ)（n = 10 时 3¹⁰ = 59049，瞬间完成），空间 O(2ⁿ)

=== 35.7 三角 N-后：先证上界，再给构造 ===
  棋盘：边长 N，格点 (i,j) 满足 1 ≤ j ≤ i ≤ N。互不攻击 ⟺
        i₁ ≠ i₂ 且 j₁ ≠ j₂ 且 i₁−j₁ ≠ i₂−j₂（三个方向各判一次）

  【上界】设放了 k 个皇后。三方向各不重复给出三个不等式：
    行号两两不同 ⟹ Σi ≤ N+(N−1)+⋯+(N−k+1) = k(2N−k+1)/2  （取最大的 k 个）
    列号两两不同 ⟹ Σj ≥ 1+2+⋯+k = k(k+1)/2              （取最小的 k 个）
    差值两两不同且 d = i−j ≥ 0 ⟹ Σd ≥ 0+1+⋯+(k−1) = k(k−1)/2
  又 Σd = Σi − Σj，于是夹逼：
    k(k−1)/2 ≤ Σd = Σi − Σj ≤ k(2N−k+1)/2 − k(k+1)/2 = k(N−k)
  两边除 k：(k−1)/2 ≤ N−k ⟹ k−1 ≤ 2N−2k ⟹ **3k ≤ 2N+1** ⟹ k ≤ ⌊(2N+1)/3⌋
    N = 10：k = 7 ⇔ 3k = 21 ≤ 2N+1 = 21；代入夹逼 Σd ≥ 21、Σd ≤ k(N−k) = 21
    N = 20：k = 13 ⇔ 3k = 39 ≤ 2N+1 = 41；代入夹逼 Σd ≥ 78、Σd ≤ k(N−k) = 91
    N = 30：k = 20 ⇔ 3k = 60 ≤ 2N+1 = 61；代入夹逼 Σd ≥ 190、Σd ≤ k(N−k) = 200
  注意上界的**来源**：不是「搜出来只有这么多」，而是被三重求和夹住的。
  回溯逐行决定放不放，Θ(2ᴺ) —— N > 10 就跑不动，**证上界必须用代数**。

  【构造】q = ⌊N/3⌋，把 k 个皇后摆成两段（Θ(N)，无搜索）：
    段 A：行 q+1..2q+1，列 q+1, q, …, 1     ⟹ 差值 i−j = 0, 2, 4, …（偶数段）
    段 B：行 2q+2..，   列 2q+1, 2q, …      ⟹ 差值 i−j = 1, 3, 5, …（奇数段）
  三条合法性逐一验证：
    行号：段 A 与段 B 的行区间**不交** ⟹ 两两不同
    列号：段 A 占 1..q+1，段 B 从 2q+1 往下且长度 ≤ q ⟹ 两段不交
    差值：偶数段与奇数段**天然不交** ⟹ 两两不同（这是选「奇偶两段」的关键）
  段长(sizeA = q+1, sizeB = q 或 q−1)使总数恰为 ⌊(2N+1)/3⌋，达到上界。

     N ⌊(2N+1)/3⌋   实放  位置 (行,列)
     1      1      1  (1,1) 
     4      3      3  (2,2) (3,1) (4,3) 
     7      5      5  (3,3) (4,2) (5,1) (6,5) (7,4) 
    10      7      7  (4,4) (5,3) (6,2) (7,1) (8,7) (9,6) (10,5) 
    13      9      9  (5,5) (6,4) (7,3) (8,2) (9,1) (10,9) (11,8) (12,7) (13,6) 
    20     13     13  前 4 个 = (7,7) (8,6) (9,5) (10,4) … 共 13 个
   100     67     67  前 4 个 = (34,34) (35,33) (36,32) (37,31) … 共 67 个
  1000    667    667  前 4 个 = (334,334) (335,333) (336,332) (337,331) … 共 667 个

  穷举校验 N = 1..2000：构造与上界一致且三方向无冲突，失败 0 个

  方法论：「**先证上界、再给构造**」是组合优化的标准套路：
    ① 不搜就知道答案的天花板在哪（代数夹逼，不是「搜出来只有这么多」）；
    ② 构造达到上界 ⟹ 最优性是**证明**出来的，不依赖搜索的运气；
    ③ 构造是 O(N) 的闭式，比任何搜索都快几个量级。
  对照本章 35.6：那里用状压 DP 精确求 χ（2ⁿ/3ⁿ 可接受），
  这里连 2ⁿ 都不能搜 —— **同样是 NP 问题，判定规模决定用搜索还是用构造**。
