## 叉积：方向的原语（§33.1）

(p₂−p₁) × (p₃−p₁) = (x₂−x₁)(y₃−y₁) − (y₂−y₁)(x₃−x₁)：

- **> 0**：p₃ 在 p₁→p₂ 的左侧（逆时针转）；
- **< 0**：右侧（顺时针）；**= 0**：三点共线。

实测（示例 34.1）：cross(o, (4,4), (8,0)) = **−32**（右转）、交换两参数
变 **+32**（左转——叉积反对称）、(4,4) 与 (2,2) 共线得 0。**整数坐标
下叉积无误差**——这是本章全部判定可以放心用 `<= 0` / `> 0` 硬判的
根基（浮点版要 epsilon，见坑位 1）。

## 线段相交（§33.2）

两段相交 ⟺ **互相跨越**（每段的两端点严格分居另一段两侧）或某个端
点恰在另一段上。四个叉积符号 + 共线时的「在线检查」：

```cpp
if (((d1 > 0 && d2 < 0) || (d1 < 0 && d2 > 0)) &&
    ((d3 > 0 && d4 < 0) || (d3 < 0 && d4 > 0))) return true;  // 规范相交
/* 四个 d==0 的边界：端点在线段上（共线前提下查包围盒） */
```

实测四种情形（示例 34.2）：规范相交 ✓、共线不相接 ✗、共线重叠 ✓
（端点在线上）、平行 ✗——CLRS 图 33.3/33.4 的全覆盖。

## Graham 扫描凸包（§33.3）

平面点集的凸包 = 包住所有点的最小凸多边形。三步：

1. 选**最下最左**点做锚点（必在凸包上）；
2. 其余点按**极角排序**（叉积比较，共线近的先）；
3. **栈扫描**：每进一点，检查栈顶两点是否左转；右转（或共线）就弹出。

实测（7 点 = 矩形 4 角 + 3 内点，示例 34.3）：

```
Graham 凸包（7 点 = 4 角 + 3 内点）：顶点序 (0,0) (4,0) (4,3) (0,3)
  内点 (2,1)(1,2)(3,2) 都在凸包内（左转检验）= 1，角点数 = 4
```

验证双保险：① 输出顶点序对每相邻三元组**严格左转**（逆时针凸性）；
② 内点用「对所有边左转」检验在包内。复杂度 O(n lg n)（排序主导）。
（Andrew 的单调链变体——按 x 排序扫上下壳——更常用于工程，练习 3。）

## 最近点对（§33.4）

分治：按 x 中线切两半递归；取两侧最优 δ = min(δ_L, δ_R)；**中线带宽
检查**——与中线距离 < δ 的点按 y 序排成竖条，条内每个点只需向后比
**至多 7 个**邻居（δ×2δ 矩形里装不下更多点）。T(n) = 2T(n/2) + O(n)
= **O(n lg n)**。实测（10 点，示例 34.4）：

```
最近点对（10 点）：暴力 = 分治 = 距离² 2（点对 (2,3)-(3,4))
```

分治与暴力逐比特对账（整数距离平方无浮点）；已知最近对 (2,3)-(3,4)
距离² = 2 ✓。

## 点在简单多边形内：射线奇偶法

给定一个**简单多边形**（顶点按顺序首尾相连、边不自交的闭合折线）和一点
p，判定 p 在多边形内、在边界上、还是外部。

### 核心事实：穿边一次，里外翻转

从 p 向任意方向（这里取水平向右）引一条射线。射线每穿过一次多边形的边，
所在点的「里外」状态翻转一次；无穷远处在外（偶数次），故

```
穿过边数为奇数 ⟺ p 在多边形内
```

直接按这个定义实现还有三个边界要处理干净。

### 三个边界细节

1. **边界优先判。** 先对每条边查叉积：`cross(a,b,p)==0` 且 p 在边的包围
   盒内（`on_segment`），立即判定为边界——边界点再去数奇偶没有意义。
2. **顶点只能被数一次：半开跨越规则。** 射线恰好过一个顶点时，相接的两
   条边可能把该顶点各数一遍（合计 2，相当于没翻转），也可能都不数。把边
   的端点按 y 规范化成 a（低）、b（高），只在

   ```
   a.y ≤ p.y < b.y
   ```

   时认为该边跨过射线——于是一个顶点恰好属于「从它向上走的那一条边」，
   每个顶点数且只数一次。
3. **不用除法算交点。** 边与射线交点的横坐标是
   x = a.x + (p.y−a.y)(b.x−a.x)/(b.y−a.y)。整数口径下避免除法与浮点：
   交点在 p 右侧 ⟺

   ```
   (a.x − p.x)(b.y − a.y) + (p.y − a.y)(b.x − a.x) > 0
   ```

   这正是把比较式通分后的交叉相乘，正负号严格可判。

### 独立对账：竖直射线与栅格泛洪

示例安排两层独立核对：① 把所有点的 x、y 交换后改用**竖直向上**射线复用
同一判据——方向不同，一处符号错就会暴露；② 对沿整数格线走的多边形
（自避游走生成、闭合边为单位段），沿多边形的边砌墙，从四周边界格灌水做
**栅格 BFS 泛洪**，水到不了的格子即内部——与射线法零共享代码。200 个
随机格线多边形上逐格中心（半整数点放大 2 倍）核对，不一致格数为 0。

> 适用范围：射线奇偶法针对简单多边形。自交多边形要用**绕数法**（winding
> number，按叉积符号统计边绕 p 的总圈数，练习 7）；含洞多边形分别给外环、
> 内环计数。

## 天空轮廓：事件扫描

n 栋矩形建筑（左边界 l、右边界 r、高 h）叠在同一条地平线上，求叠加后的
轮廓：一列关键点 (x, h)，相邻关键点之间高度恒定。

### 高度函数与事件

按左闭右开定义高度函数

```
H(x) = max{ h_i | l_i ≤ x < r_i }（无楼覆盖时为 0）
```

高度只可能在某栋楼的左/右边界处变化。为每栋楼造两个事件：在 l 处**插入**
h、在 r 处**删除** h；用一个多重集维护当前覆盖区间上的活跃高度，其最大
值就是 H(x)。两个关键点决定正确性：

1. **同一 x 的事件必须成组处理完**，再比较最大值——否则同位置的插入与
   删除会产生中间假关键点；
2. **删除只删一个副本**：`active.erase(active.find(h))`——同高度多栋楼
   并存时 `erase(h)` 会一次删光。

最大值变化才输出关键点。2n 个事件各 O(lg n)，总计 O(n lg n)。

### 独立对账与实测

示例另写 O(n²) 真值：收集全部不同 x，在每个坐标按定义直接扫所有楼取最大
值。固定例（含遮挡与间隙）关键点为

```
(2,10) (3,15) (7,12) (12,0) (15,10) (20,8) (24,0)
```

间隙（无楼覆盖区间）处高度回落为 0。300 个随机例上两口径 0 例不一致；
大例取 2 万栋完全重合、高度递增的楼——相互遮挡后只剩两个关键点
(0,20000)、(20000,0)，用结构性质直接核对（O(n²) 口径在此规模不可行）。

## 平面被直线分割：区域数的增量构造（34.7）

平面上画 n 条**无限延伸**的直线，最多把平面分成多少个区域？

### 关键一步：新线被切成几段，就新增几个区域

逐条加入直线。设第 k 条线与已画的 k−1 条线有 **t 个互不重合的交点**，
这些点把新线切成 **t+1 段**（含两端射线）；每一段都把它穿过的一个旧
区域一分为二，故第 k 条线新增 **t+1** 个区域。

要让区域最多，就要让 t 最大 = k−1——每个旧交点都存在且互不重合。这
恰好要求直线族处于**一般位置**：

1. **没有两条平行**（否则该对不相交，t 少 1）；
2. **没有三线共点**（否则三个交点并成一个，t 再少）。

一般位置下 t = k−1，新增 k 个区域：从 R(0)=1 累加，

```
R(n) = 1 + 1 + 2 + … + n = 1 + n(n+1)/2
```

前几项：R(0..6) = 1, 2, 4, 7, 11, 16, 22。注意闭式给的是**最大值**；
平行线、共点线都会让真实区域更少——退化不是例外，必须单独计数。

### 一个可精确认证的构造

取直线 i：**y = i·x + i²**（i=0,1,…,n−1）。斜率两两不同（无平行）；
直线 i 与 j 的交点为 (−i−j, i·j)——由 (i+j, ij) 可唯一反解无序对
{i,j}，故全部 C(n,2) 个交点互不相同（无三线共点）。

代码不依赖肉眼看图，而用两套整数检验：

- **平行**：直接比较斜率；
- **三线共点**：行列式 mᵢ(cⱼ−cₖ)+mⱼ(cₖ−cᵢ)+mₖ(cᵢ−cⱼ) == 0
  （对本构造它等于 −(i−j)(j−k)(k−i)，三元互异时恒非零）。

n≤12 时逐三元全检验证一般位置；随机 50 组（斜率 −20..20、随机截距，
拒绝不满足一般位置的候选）计数与闭式 0 例不一致。

### 大例的完整认证

n=1000：R = **500501**。一般位置用「全部 C(n,2) 个交点的
(i+j, i·j) 无重复」做 O(n²) 认证（499500 个点全部互异）——不用浮点、
不抽样，构造性质被程序逐对核实。

## 最小包围圆：Welzl 随机增量（34.8）

给定平面点集，求半径最小的圆包含所有点——基站选址、碰撞包围体的经典
问题。两条结构事实先立住：

1. 最优圆的边界上至少有 2 个点：**两点**确定时以该点对为直径；
   **三点**确定时为其外接圆（三角形非钝角时三个点都在边界上）；
2. 不需要 4 个支撑点：任何 ≥4 点的边界集中总能找到一个 2/3 点子圆同样
   覆盖全体。

### 随机增量递推

记 D(P, R) 为覆盖点集 P、且要求 R 中的点都在边界上的最小圆：

```
D(P, R):
  若 P 为空或 |R| = 3：返回过 R 的圆（trivial）
  随机取一点 p；D = D(P\{p}, R)
  若 p 在 D 内：返回 D
  否则 p 必在边界：返回 D(P\{p}, R∪{p})
```

点的顺序随机后，第 i 个点恰为边界点的概率 ≤ 3/i（边界支撑 ≤3），
求和得**期望 O(n)** 时间。

### 三处实现要点（本教程实测）

- **trivial 圆**：|R|=0 为空圆（用 r<0 哨兵）；|R|=1 半径为 0；
  |R|=2 取中点、半径为距离之半；|R|=3 用加倍行列式求外接圆圆心
  （全程 `double`，六个坐标显式转换避免窄化告警）。三点共线时外接圆
  退化——改取三对点对圆中覆盖三点的最小者；
- **成员判定带 ε**：边界点在浮点误差下可能被判在圆外，`in_circle` 用
  距离平方与 r² + ε 比较；
- **递归深度**：教科书递推写法每处理一个点就无条件递归 `D(P\{p},R)`，
  n=20000 时调用栈直接溢出。改写为外层**迭代**循环顺序扫描，只有点落
  在圆外才递归（把该点钉到支撑集、重算前缀），此时递归深度 ≤ |R|+1
  ≤ **4**。

```
=== 34.8 最小包围圆：Welzl 随机增量（期望 O(n)）===
  结构例：单点 r=0；两点 (0,0)(4,3) 直径 r=2.5；共线 4 点 r=2.5
  正方形 4 顶点：圆心 (1.5,1.5)，r=2.121320
  随机 200 组（n≤9）：Welzl 与暴力半径不一致 0 例
  大例（2 万点，坐标 ±10 万）：圆心 (-723.00,-254.50)，r=140622.3573（最远点 140622.35725605654，越界 0 个）
```

暴力真值独立枚举所有 1/2/3 点候选圆（三点外接圆 + 两点直径圆 + 单点
r=0），保留覆盖全体且半径最小者。200 组随机小点（n=2..9）上与 Welzl
半径 0 例不一致；2 万点大例逐点回代，越界 0 个且半径不超出坐标对角线
上界。

## 冗余传感器：并集面积与有向邻居（34.9）

传感器 C 监测以自身为中心、边长 2h 的正方形区域。若该区域能被**其他**
传感器的监测区域完全覆盖，C 就是冗余的（故障/拆除它不产生监测盲区）。
判定式：

> 冗余 ⟺ C 的正方形 S_C（面积 **4h²**）被其余相关传感器正方形之并
> 完全覆盖，即 union(neighbor squares clipped to S_C) = 4h²。

### 有向邻居关系与裁剪

传感器 k 能分担 C 的覆盖，前提是 C 的中心落在 k 的正方形内：
**|x_C − x_k| ≤ h 且 |y_C − y_k| ≤ h**。注意这是**有向**关系（监测能力
以 k 为中心度量，不能默认对称）；随后把 k 的正方形**裁剪**到 C 的
2h×2h 方格内（只有落在 S_C 内的部分对覆盖有贡献），得到半开矩形
[x₀,x₁)×[y₀,y₁)。

### 并集面积：x 切条 + y 区间合并

1. 收集所有矩形的 x 边并排序去重，得到竖向窄条；
2. 每个条 [x_i, x_{i+1}) 上，找出横跨该条的矩形，取其 y 区间排序、
   重叠合并，被覆盖长度 = Σ(y₁−y₀)；
3. 面积 = Σ 条宽 × 覆盖长度。

坐标与 h 全为整数，面积精确为整数；半开口径让相邻条/相邻区间在边界
上不重不漏。独立对账改数**单位格子**：枚举每个被任一矩形覆盖的整数
单位格 (x,y) 放进集合，格子数即面积。

### 固定例与大阵列

```
=== 34.9 冗余传感器：C 正方形 ⊆ 邻居正方形之并 ===
  植入例（4 邻居铺满）：切条并面积 64＝4h²，格子口径 64，冗余
  植入例（缺 1 邻居）：覆盖 48/64 格，不冗余
  随机 200 个小场：切条 vs 格子口径不一致 0 例；冗余传感器共 55 个
  大例（30×30 阵列，间距 h）：冗余 896 个（四角均不冗余），期望恰为 L²−4 = 896
```

30×30、间距恰为 h 的阵列上有个值得想清楚的结论：边上（非角）传感器
的方格被轴向两个邻居铺满（邻格正方形向外多伸出 h，正好盖住它朝外的
半条），而四角传感器的朝外对角象限无人覆盖。因此冗余数是
**L²−4 = 896**，四个角传感器是仅有的非冗余点。

## 隐藏节点：圆盘图上的 V 形三元组（34.10）

自组织网络里每台设备既是终端又是路由器，通信半径 R：设备 i、j 可
直接通信 ⟺ (xᵢ−xⱼ)² + (yᵢ−yⱼ)² ≤ R²（无向）。**隐藏节点问题**：
a、b 不能直接通信，却同时通过同一个 c 收发——共享介质时 a、b 都
以为信道空闲，冲突发生在 c 处。计数：

> 隐藏节点集合 = 三元组 {a,b,c}：a、b 间**无边**，a–c、b–c **有边**
> （三点上的诱导子图恰是两条共点边，形如 V）。

注意口径是「恰两条边」：a、b 有边的三元组（三角形或路径 a–c–b 的
补形）都不算——后者 b、c 间无边而 a、c 有边，不对称不构成隐藏对。

### 暴力与位行两个口径

- **暴力 O(n³)**：先建邻接矩阵（整数距离平方，精确无浮点）；枚举
  **有序对** (i,j)（i<j）跳过有边者，对每个第三点 k 检查
  adj[i][k] + adj[j][k] == 2。注意 k 要遍历**全部**下标——V 的中心
  可能在 i、j 之间编号（本教程实测翻车：k 从 j+1 起数漏掉中心编号
  较小的组，单位正方形例 4 组只剩 0 组）；
- **位行 O(n³/64)**：把每行的邻接压成 64 位字（`bits[i]` 的第 j 位
  ＝ adj[i][j]），对每个非边对 (i,j)，公共邻居数 =
  `popcount(bits[i] & bits[j])`——一次 AND+popcount 并行 64 个
  第三点，与 Warshall 传递闭包的位并行同源（26 章）。

### 固定例与结构下界

```
=== 34.10 隐藏节点：圆盘图「V 形三元组」（暴力 O(n³) vs 位行 O(n³/64)）===
  固定例（单位正方形 4 点，R=1）：隐藏集合 4 组（两口径一致 = 1）
  随机 300 个小场（n≤12）：暴力三元组 vs 位行公共邻不一致 0 例
  大例（60×50 网格 3000 点，R=1）：隐藏集合 17344 组（≥ 4×格子数 11564）
```

单位正方形 4 点、R=1：四条边都在（距离 ≤1），两条对角线都不在
（距离 √2 > 1）——每个三元组恰缺自己那条对角线，共 4 组隐藏集合，
手数即可核对。大例 60×50 网格（间距 1、R=1）：每个单位格的四个
角构成一个 V（两对角不通信、横竖边都在），4×59×49 = 11564 组是
**结构下界**，实际 17344 组——网格边缘的点还与更远的点组成额外的
V。300 个随机小场（n ≤ 12）两口径 0 例不一致。

## C++23 语言点

- `struct Pt { long long x, y; }` + 聚合初始化——几何点的极简表示；
- `std::ranges::sort(px, {}, &Pt::x)`——按成员投影排序；
- **整数化纪律**：坐标全部 long long，叉积/距离平方都精确——本教程
  能用整数就绝不碰浮点几何（对账与正确性双赢）；
- **`std::multiset` + 排序事件分组**：扫描线类问题（轮廓、区间覆盖）的
  通用骨架——事件排序、同坐标成组处理、有序结构查极值；删除等价元素务必
  经迭代器只删一个副本；
- 共点检验是一句 **long long 行列式 == 0**：能用整数代数判定就不先算
  交点坐标——几何里「精确判定优先于坐标计算」与叉积纪律同源。

## 与 STL 对照

无标准几何库（CGAL 是 heavyweight 正统；Boost.Geometry 轻量）。
工程几何的日常：`std::ranges::min_element` 找锚点、投影排序做预处理；
扫描线问题则直接用 `std::multiset` / 优先堆——本章工具箱与 STL 完美互补。

## 坑位清单

1. **浮点坐标下的 `cross == 0` 判共线**
   （现象：偶尔判错方向、凸包顶点抖动；原因：浮点误差让「共线」的
   叉积是 1e-16 而不是 0；对策：本教程纪律——坐标整数化；必须浮点时
   用 epsilon（|c| < ε 视为 0），并把 ε 与坐标量级挂钩。）
2. **Graham 的极角排序用 atan2**
   （现象：性能差且共线组顺序错（凸包多算共线点）；原因：atan2 有
   精度与速度问题，共线时排序不稳定；对策：叉积比较器（本例写法），
   共线时按距离排序并配合 `<= 0` 弹出。）
3. **线段相交漏掉「端点在线上」的边界**
   （现象：T 形/端点相接的段判为不相交；原因：只写了互跨检查；
   对策：四个 d==0 分支的在线检查（包围盒判定）——本例四种情形的
   测试集就是为这些边界准备的。）
4. **最近点对的条内检查忘了按 y 排序**
   （现象：条内 O(k²) 暴力、复杂度退化；原因：「至多 7 邻」的证明
   依赖 y 序；对策：条按 y 序（从 py 直接过滤，别重新 sort——顺序
   已经有了），向后最多比 7 个（本例写法）。）
5. **射线过顶点时两端都开或都闭**
   （现象：射线恰好过顶点时答案翻转——把某些内点判外、外点判内，且只在
   整点数据上出错；原因：相接两边若都数该顶点（合计 2，等于没翻）或都不
   数，奇偶都错；对策：半开规则 a.y ≤ p.y < b.y——顶点只属于向上的那一条
   边；用「射线水平穿过锯齿顶点」的专用用例回归，再靠栅格泛洪随机对账。）
6. **交点横坐标用除法算出再比较**
   （现象：整数坐标下本可精确的判定出现舍入误差，或分母为负时不等号翻向；
   原因：x 交点公式含除法，浮点化后边界点（交点横坐标恰为 p.x）由舍入决定；
   对策：交叉相乘——
   `(a.x−p.x)(b.y−a.y) + (p.y−a.y)(b.x−a.x) > 0`，全程 long long；
   边已规范化 a.y<b.y，分母恒正，符号无需再翻。）
7. **先翻奇偶后查边界**
   （现象：边上的点有时报内、有时报外；原因：边界点（cross==0 且在包围盒
   内）不参与奇偶游戏——它既不是内也不是外；若先计数再判边界，计数结果
   依赖边的方向顺序，不稳定；对策：每条边先做边界判定，全部边都不命中再
   做射线计数，两类检查的输出分开处理。）
8. **天空轮廓同 x 事件分次输出**
   （现象：同位置出现成对的假关键点（高度先升后降或反之）；原因：一栋楼的
   右边界与另一栋楼的左边界恰在同一 x 时，若处理一个事件就比较一次最大值，
   中间态被当成轮廓变化；对策：事件按 x 排序、分组循环，同 x 全部插入/删除
   完成后再比较一次。）
9. **多重集删除写成 `erase(h)` 而非 `erase(find(h))`**
   （现象：同高度多栋楼并存时，一栋先结束，最大高度意外提前下降；原因：
   `multiset::erase(value)` 删除**全部**等价元素，`erase(iterator)` 只删
   一个；后果：只在含同高楼的输入上 WA——随机对账必须允许同高；对策：
   删除走 `find` 取迭代器，并断言该高度确实存在。）
10. **左右边界的覆盖口径不一致（[l,r) 与 [l,r] 混用）**
    （现象：扫描线与逐点真值在边界坐标上对不上；原因：高度函数按左闭右开
    定义——右边界处楼不再覆盖，若真值口径把右端点也算覆盖，两口径在每个
    r 处系统性分歧；对策：两口径统一 `l ≤ x && x < r`；先在单楼输入上核对
    两个端点（l 处有高度、r 处为 0）。）
11. **把闭式当成任意直线族的答案**
    （现象：三条平行线只分出 4 个区域，却断言 R(3)=7；原因：
    1+n(n+1)/2 是**最大**区域数，前提是一般位置——平行线 t<k−1、
    三线共点合并交点都让真实值偏小；对策：先跑一般位置检验（平行 +
    行列式），退化情形按「逐条数互不重合交点」的增量计数。）
12. **共点检验用浮点 / 交点坐标去重**
    （现象：大 n 下「理应共点」的三条线被判不共点；原因：先算交点坐标
    再比较引入舍入误差，n=1000 的坐标积已达 10⁶ 量级；对策：直接用
    整数行列式 mᵢ(cⱼ−cₖ)+… == 0 判定，全程不出现除法。）
13. **构造一般位置时只验证「无平行」**
    （现象：拒绝采样的随机直线族里仍有三线共点，计数对不上闭式；原因：
    一般位置有两个独立条件，漏掉共点检验等于没做；对策：本例随机例
    用 O(n³) 完整检验后才接受，n≤10 成本可忽略。）
14. **MEC 成员判定不带 ε、外接圆不防共线**
    （现象：边界点偶发被判在圆外、支撑集被撑大到循环重复；或三点共线
    时行列式为 0、圆心除出垃圾值；原因：浮点比较与退化几何都是必处理
    的分支；对策：`in_circle` 比较距离平方与 r²+ε；三点圆先查共线，
    退化时退回三对点对圆取最小。）
15. **照搬 Welzl 无条件递归，n=20000 爆栈**
    （现象：0xC00000FD 栈溢出；原因：`D(P\{p},R)` 每点递归一次、
    深度 n；对策：外层迭代扫描，仅当点在圆外才递归并重算前缀——该点
    进入支撑集后递归层数至多 |R|+1 ≤ 4。）
16. **暴力真值漏掉候选或只看半径不验覆盖**
    （现象：暴力「最优」比 Welzl 还小，对账无意义；原因：候选必须含
    全部单点/点对/三点圆，且每个候选都要先覆盖全体点才比半径；对策：
    真值函数两类候选统一收集、统一覆盖检查，n≤9 的小例才枚举三点。）
17. **传感器邻居关系默认对称、裁剪被省略**
    （现象：并集面积超过 4h²、或把本不相关的传感器算作邻居；原因：
    「C 中心在 k 方格内」是以 k 为中心的有向判据，且只有 k 方格与
    S_C 的交集参与覆盖；对策：先按 |Δx|,|Δy|≤h 定向筛邻居，再把每个
    邻方逐一裁剪到 C 的 2h×2h 方格。）
18. **切条/区间的边界差一位**
    （现象：并集面积与单位格计数系统性偏大；原因：矩形与区间必须同一
    半开口径 [x₀,x₁)，条宽 x_{i+1}−x_i、合并时相邻区间 y₁==y₀′ 不
    重叠；对策：整数坐标下两种口径互验（面积＝格子数），单矩形例先
    核对面积恰为 4h²。）
19. **格点阵列期望写成 (L−2)²**
    （现象：30×30 大例断言 784 失败、实测 896；原因：边缘非角传感器
    被轴向两邻居覆盖，只有四角的朝外象限无人覆盖——冗余数是 L²−4；
    对策：分别分析角、边、内点三类，断言四角非冗余后再核对总数。）
20. **隐藏节点第三点只从 j+1 起枚举（本例实测翻车）**
    （现象：单位正方形例数出 0 组，固定例第一步就 assert；原因：V 的
    中心 c 编号可以落在 i、j 之间甚至小于两者——「有序对 + k>j」把
    中心编号小的组全漏掉；对策：k 遍历全表并跳过 k==i、k==j，或改用
    位行口径（AND 天然全表）；固定例先手数 4 组钉死。）
21. **把「恰两条边」放宽成「a、c 与 b、c 有边」**
    （现象：三角形三元组也被计入、计数偏大；原因：三点全连通时
    a、b 互相听得见，不构成隐藏冲突——判据需要 adj[a][b]==0 的
    前置排除；对策：枚举非边对起步（有边对直接 continue），检查
    两条共点边即可，三角形天然不进循环。）
