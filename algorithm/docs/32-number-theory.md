# 32 · 数论算法

> 对应 CLRS 第 31 章 *Number-Theoretic Algorithms*（英文 3rd ed. pp.949–
> 980）。欧几里得辗转相除是史上最古老算法（公元前 300 年）；它的现代
> 后裔——模幂、Miller-Rabin、RSA——撑起了整座公钥密码学。本章整数
> 运算全程 64 位、精确无浮点（三通道对账天然友好）。

## 学习目标

1. 会写欧几里得与扩展 gcd（Bézout 系数），知道逆元从它来；
2. 会写平方-相乘的模幂（Θ(lg b) 次乘法）；
3. 能解释 Fermat 测试为何被 Carmichael 数骗、Miller-Rabin 如何拆穿；
4. 能走完 RSA 的完整流程（选 p q / 求 φ / 配 e d / 加解密）。

## 欧几里得与扩展 gcd（§31.2）

gcd(a,b) = gcd(b, a mod b)——辗转序列每步严格递减，对数步收敛
（Lamé 定理：步数 ≤ 5·位数，与斐波那契最坏例挂钩——第 5 章的老朋友
再登场）。**扩展版**顺带产出 Bézout 系数：

```
欧几里得 gcd(99, 78)：
  辗转序列: 99 → 78 → 21 → 15 → 6 → 3
  gcd = 3（辗转 5 步）
  扩展 gcd：99·(-11) + 78·(14) = 3（Bézout 恒等式 = gcd）
```

Bézout 的直接应用：gcd(a,n) = 1 时 a 的**模逆元** a⁻¹ (mod n) 就是
扩展 gcd 的 x 系数（取正模）。

## 模运算：快速幂（§31.6）

a^b mod n 用**平方-相乘**：按 b 的二进制位，每步平方、逢 1 再乘 a——
Θ(lg b) 次模乘。实测 7⁵⁶⁰ mod 561 只花 13 次乘法（朴素要 560 次）；
中途值永远 < n²（64 位装得下）——**不取模先算幂会溢出宇宙**。

```
模幂 7^560 mod 561 = 1（平方-相乘 13 次乘法 vs 朴素 560 次）
乘法逆元：17⁻¹ mod 3120 = 2753（检查 17·2753 mod 3120 = 1，gcd = 1）
```

## 素性测试：Fermat 的坑与 Miller-Rabin（§31.8）

**Fermat 小定理**：p 素 ⟹ a^{p−1} ≡ 1 (mod p)。拿它当测试（a^{n−1}
≠ 1 则 n 必合）单向有效；**反向不成立**——Carmichael 数（561 是最小
者）对所有互素 a 都满足 a^{n−1} ≡ 1，Fermat 测试集体被骗。实测：
7⁵⁶⁰ mod 561 = 1，假象完美。

**Miller-Rabin** 加一步「平方根检查」：n−1 = 2^s·d，算 a^d 后连续
平方——途中若得到 ±1 之外的「1 的平方根」（x ≠ ±1 但 x² ≡ 1），
n 必合（mod 素数只有 ±1 两个平方根）。实测（基 = {2,3,5,7}）：

```
素性测试（基 = {2,3,5,7}）：
  561 = 3·11·17（Carmichael 数）：Fermat 测试 7^560≡1 被骗，Miller-Rabin 判为素 = 0（基 2 即为 witness，拆穿 = 1）
  7919 判素 = 1（第 1000 个素数），104729 判素 = 1（第 10000 个），3233 判素 = 0（= 61·53，正确识破）
```

Miller-Rabin 是**随机化**测试：k 个随机基把错误率压到 4⁻ᵏ（无 Carmichael
式漏洞——「强伪素」对固定基存在但对随机基稀少）。确定性变体：对
64 位整数，固定 12 个基即是决定性的（工程事实）。

## RSA 全流程（§31.7）

```
RSA（p=61, q=53）：n = 3233, φ(n) = 3120, e = 17, d = e⁻¹ = 2753
  加密：c = 65^17 mod 3233 = 2790
  解密：m = 2790^2753 mod 3233 = 65（= 原文 65，RSA 闭环）
  正确性：ed = 17·2753 = 46801 = 15·φ + 1（费马小定理 + CRT ⇒ m^{ed} ≡ m）
```

- 公钥 (e, n)、私钥 d：ed ≡ 1 (mod φ(n))（d 用扩展 gcd 求）；
- 加密 c = mᵉ mod n、解密 m = c^d mod n——都是快速幂；
- 正确性：m^{ed} = m^{15φ+1} ≡ m（费马小定理在 mod p、mod q 各来一次，
  CRT 合并）——**欧拉定理是引擎，中国剩余定理是变速箱**；
- 安全性依赖「分解 n = pq 不可行」——与算法复杂度的边界（第 35 章
  NP 理论）一线相牵。真实 RSA 的 n 是 2048 位（617 位十进制），大数
  运算库（GMP）就位后同一套代码。

## C++23 语言点

- 全程 `long long`（64 位）：模乘 a·b < n² ≤ 63 位才安全——n > 3×10⁹
  时要 `__int128`（GCC/clang 有、MSVC 无——三通道纪律下用「乘法拆分」
  或限制 n 范围，本例 n=3233 远离边界）；
- 递归版 ext_gcd 的引用多返回值（x/y 出参）——与第 4 章 struct 返回
  两种风格任选；
- `std::format` 的字面花括号要转义（`m^{ed}` 写成 `m^{{ed}}`——本例
  实测翻车的编译错）。

## 与 STL 对照

`std::gcd`/`std::lcm`（`<numeric>`，C++17）覆盖欧几里得；无模幂/
Miller-Rabin（密码学不走标准库——OpenSSL/libsodium 的领地）。
`std::mt19937` 在密码场景**禁用**（可预测）——需要 CSPRNG。

## 坑位清单

1. **φ(n) 算错（本例实测翻车）**
   （现象：逆元断言挂——17⁻¹ mod 3220 ≠ 2753；原因：φ(3233) =
   φ(61·53) = 60·52 = **3120**，手滑写成 3220（像 p+q 的和）；对策：
   φ 由 (p−1)(q−1) 现场计算，别手抄常数（本例修正版）。）
2. **试除捷径吃掉见证检验（本例实测翻车）**
   （现象：对 561 的「witness 拆穿」断言不触发；原因：基列表含 3，
   而 3 | 561，试除提前返回「合数」（结论对）但没走 Miller-Rabin 的
   平方根检查（演示失效）；对策：试除只留 2，基列表专用于见证。）
3. **模乘溢出**
   （现象：大 n 下结果随机错；原因：a·b 在 long long 里溢出（n > 3×10⁹
   时 n² > 2⁶³）；对策：__int128 / 乘法拆分（俄罗斯农民式）/ 限制
   n < 3×10⁹，并把「安全范围」写成注释与断言。）
4. **Fermat 测试当确定性用**
   （现象：561 被判素；原因：Carmichael 数对全部互素基撒谎；对策：
   Miller-Rabin（平方根检查）+ 随机基，或对小 n 用试除打表。）
5. **格式串里的 `^{...}`**
   （现象：编译错误指向 consteval；原因：`{ed}` 被当占位符；对策：
   转义为 `{{ed}}`——数学文案进 format 的通例（本例实测翻车）。）
