# 36 · 近似算法

> 对应 CLRS 第 35 章 *Approximation Algorithms*（英文 3rd ed. pp.1106–
> 1143）。第 35 章宣判：NPC 问题大概率没有多项式精确解。近似算法的
> 契约是：**多项式时间 + 解的质量有保证**（ρ-近似：解 ≤ ρ·OPT）。
> 这是工程世界观对理论极限的回应——「要不到最优，要一个可证不差于
> 2 倍的」。

## 学习目标

1. 能定义 ρ-近似算法（对最小化问题：解 ≤ ρ·OPT）；
2. 能证明顶点覆盖贪心的 2-近似（极大匹配论证）；
3. 能证明度量 TSP 的 MST 先序 2-近似（并知道**非度量 TSP 无常数比**）；
4. 能陈述集合覆盖贪心的 ln 近似（贪心每步的最优子结构较弱但够用）；
5. 会算装箱的 FF/FFD/Best-Fit，能陈述 FFD 的 11/9 渐近保证并对照精确解；
6. 会实现 k-中心的最远点贪心（最远优先遍历）并能证明其 2-近似；知道
   在度量距离下比值 2 不可再降（除非 P = NP）。

## 顶点覆盖的 2-近似（§35.1）

贪心：反复任取一条未覆盖边，**两端都放进覆盖**（得到一个极大匹配
的端点集）。正确性与比值的证明：

```
顶点覆盖 2-近似（8 边 7 点图）：贪心覆盖 6 点（合法性 = 1），暴力最优 = 3，
比值 = 2.00（≤ 2 保证）
```

- **合法性**：每条边要么自己被选，要么相邻边选中时它的端点进了覆盖
 （程序对 8 条边逐条验证）；
- **≤ 2·OPT**：选中的边两两无公共端点（极大匹配）——任何顶点覆盖
  必须给**每条匹配边至少一个端点**，而匹配边互不相交 ⟹ OPT ≥ 匹配
  数；贪心选 = 2 × 匹配数 ⟹ 解 ≤ 2·OPT。本例恰取等（6 = 2×3）——
  **紧例**，说明比值 2 不能再压（这个图上贪心就是比最优差一倍）。

## 度量 TSP 的 2-近似（§35.2）

**度量 TSP**（距离满足三角不等式）的 MST 先序法：建 MST → 从根先序
走一圈 → 相邻跳过重复点（捷径）。证明链：先序全程 = MST 每边走两遍
（≤ 2·MST）；捷径不增（三角不等式！）；MST ≤ OPT（去掉最优环一条边
就是生成树）⟹ 近似 ≤ 2·OPT。

```
度量 TSP 2-近似（5 点平面图，曼哈顿距离口径）：
  近似先序: 0 1 4 3 2
  近似长 30 vs 暴力最优 24，比值 = 1.25（≤ 2 保证）
```

**距离口径的纪律**（本例实测选型）：曼哈顿（L1）满足三角不等式且
整数——**平方欧氏不是度量**（(a+b)² ≠ a²+b² 破坏捷径论证），用它
断言 ≤ 2 会真的翻车。非度量 TSP 更惨：**不存在多项式常数比近似**
（除非 P = NP——由哈密顿圈归约可证）。

## 集合覆盖的 ln 近似（§35.3）

贪心：每轮选**覆盖新元素最多**的集合。比值界 H(d)（d = 最大集合
大小）≈ ln d——证明用「计费论证」：每个元素被首次覆盖时记账
1/增益，总额 = 集合数；OPT 至少……（对数势能的又一化身）。实测：

```
集合覆盖贪心（全域 12 元素，6 集合）：贪心选 5 个，暴力最优 = 5，H_6 ≈ 2.45 为理论界
```

本例贪心恰好命中最优（5 = 5）——ln 界是**最坏保证**，日常输入常更
好。集合覆盖的 ln 界是紧的（构造实例逼出 (1−o(1)) ln n）——除非
P = NP，不可能 (1−ε) ln n 近似（Feige）。

## 装箱：FF / FFD / Best-Fit（§36.4）

**装箱问题**：n 件物品各有尺寸 sᵢ（1..C），容量 C 的箱子用几只才能
装下全部？它是 NP 难的（划分问题的归约），但结构比 TSP 「仁慈」——
离线简单排序就能逼近最优，还存在 PTAS（任意 1+ε，时间指数于 1/ε）。

三个贪心，一个比一个精：

- **First-Fit（FF，原序）**：每件物品线性扫描已有箱子，**第一个**放得
  下的箱子就放，都放不下开新箱。在线算法（不必预知后续物品）。
- **First-Fit Decreasing（FFD）**：先把物品**降序排序**再 First-Fit。
  大件先占位，小件填缝隙——离线换来的红利。
- **Best-Fit**：每件放进「剩余容量最小、但仍放得下」的箱子。用有序
  结构对剩余容量做 `lower_bound(sᵢ)`，每次 O(log 箱数)，整体
  O(n log n)。

固定例物品 40/50/60/30/20（C=100）：FF 用 3 箱——40+50 先挤一箱
（余 10），60 开第二箱，30 两处都放不下开第三箱；Best-Fit 同样 3 箱
（它也认为 40+50 的余 10 最该保留）；**FFD 只要 2 箱**：排序后
60+40、50+30+20，精确最优也是 2。

**精确解**：箱子数从总量下界 k₀=⌈Σsᵢ/C⌉ 起逐个试，DFS 把物品分进
k 个箱子，两条对称破缺一不可——相同剩余容量的箱子只试一次（交换
箱号不产生新摆法）；一件物品试过空箱后不再试更后面的空箱。n≤12
足够快，正好给贪心当裁判。

**FFD 的保证**（Johnson–Garey 等的经典定理）：

9·FFD ≤ 11·OPT + 6，即 FFD ≤ (11/9)OPT + 2/3，
**渐近** 11/9 比；n→∞ 时 OPT→∞，常数 6 被摊薄。实测 1500 个随机例
（n≤12）FFD 超出最优 1 箱以上的 **0 例**、定理违反 **0 例**。

大例 10 万件 1..100 的随机物品：Best-Fit 用 50644 箱，总量下界
50381，**比值 1.01**——碎片被规模摊薄。注意断言纪律：箱数 ≥ 下界
是硬保证，但「只多两三箱」在随机尺寸下并不成立（每箱平均留一点
碎片），示例只断言经验比值 ≤ 1.20——这是**实测陈述**，不冒充定理。

## k-中心：最远点贪心（36.5）

**问题**：平面上 n 个点，选 **k 个中心**（必须从输入点里选），最小化
所有点到最近中心的距离（覆盖半径）。建基站、选配送仓的经典模型；
它也是 NP 难的（k=1 就是最小包围圆的多点版之外的一般化判定）。

### 最远优先遍历（farthest-first traversal）

1. 任取一点当第一个中心；
2. 维护每个点到已选中心集的最短距离 dist[i]；
3. 每轮把 **dist 最大的点**（离现有中心最远者）加进中心集，更新
   dist——直到凑满 k 个。

直觉：每一步都去「最痛的地方」设点。复杂度 O(nk)。

### 2-近似的鸽笼证明

设贪心最终半径 r_g（全体点到中心 ≤ r_g），最优半径 r*。若 r_g > 2r*：
贪心过程中第 k+1 轮的最远点 p 距 k 个已选中心都 > 2r*（否则轮次早就
结束）——这 k 个中心与 p 共 **k+1 个点、两两距离 > 2r***（p 与每个
中心 > 2r*，而中心两两距离 ≥ 各自到 p 的距离之和的一半 > 2r*，由
三角不等式）。最优解只有 k 个中心，鸽笼原理必有**一个 OPT 中心同时
覆盖其中两点**，而该中心到其覆盖点的距离 ≤ r*，三角不等式给出这两点
相距 ≤ 2r*——矛盾。所以 r_g ≤ 2r*。

注意证明只在**度量距离**（三角不等式）下成立——与 TSP 2-近似同一
纪律。且该比值是紧的：除非 P = NP，度量 k-中心不存在 (2−ε)-近似。

### 实测

```
=== 36.5 k-中心：最远点贪心 2-近似（曼哈顿口径）===
  正方形 4 点：k=1 最优半径 4；k=2 贪心 2 vs 最优 2（对角两点即最优）
  数线例（0,1,2,3,10，k=2）：贪心半径 3（中心 0 与 10），最优 2，比值 1.50（≤ 2 保证）
  随机 300 例（n≤9，k≤3）：贪心命中最优 113 例；比值 > 2 的 0 例
  大例（2000 点，k=25）：贪心半径 234（独立全量复算一致 = 1）
```

- 数线例演示贪心**不总是最优**：起点 0 与最远点 10 先占两端，k=2 用
  完，中间的 3 距两端都 3——最优解（1 与 10）半径只要 2，比值 1.5；
- 独立真值：C(n,k) 枚举全部中心子集（n ≤ 9 瞬时），300 随机例上
  贪心 113 例命中最优、0 例超出 2 倍；
- 大例 2000 点、k=25：半径用独立的 O(nk) 全量复算核对。

## 近似算法的版图

| 问题 | 近似比 | 下界/备注 |
|---|---|---|
| 顶点覆盖 | 2 | 紧（贪心）；LP 松弛也是 2 |
| 度量 TSP | 2（MST 法）/ 1.5（Christofides） | 1.5 需最小完美匹配 |
| 一般 TSP | 无多项式常数比 | 除非 P = NP |
| 集合覆盖 | ln n（紧） | Feige 的不可能性 |
| 装箱 | 1.22?（AFAS）/ 渐近 1 + ε | PTAS 存在 |
| k-中心 | 2（最远点贪心，紧） | 度量下 (2−ε) 不可近似 |
| knapsack | 1 + ε（FPTAS） | 「好到任意精度」的可能 |

**近似谱系**：PTAS（1+ε，ε 任意小，可能指数于 1/ε）→ FPTAS（对 1/ε
也多项式）→ 常数比 → 对数比 → 无保证启发式。背包有 FPTAS 而 TSP 没有
PTAS（除非 P=NP）——「问题的可近似性」是 NPC 内部的第二层结构。

## C++23 语言点

- 暴力最优用**位掩码枚举**（顶点覆盖的 2⁷、集合覆盖的 2⁶）——小实例
  的真值裁判标准姿势；
- `std::popcount`（`<bit>`，C++20）——`__builtin_popcount` 不可移植
 （MSVC 无，本例实测换掉）；
- 比值打印 `{:.2f}`——保证比值是「整数比整数」的双精度除法（确定）。

## 与 STL 对照

无标准库。近似算法的世界观反而接近日常工程：「先跑一个有保证的快
解，有空再精确」——数据库查询计划、地图路线的分层规划都是这个
模式（HL 路线 = 预计算近似 + 局部精化）。

## 坑位清单

1. **用非度量距离跑 TSP 2-近似的断言**
   （现象：assert(approx ≤ 2·opt) 偶尔炸；原因：平方欧氏不满足三角
   不等式，捷径不增的论证失效；对策：距离函数必须先过三角不等式
   （曼哈顿/欧氏/图最短路都行——第 25 章的产物当距离矩阵！本例的
   选型过程就是这条坑的实测）。）
2. **验证覆盖合法性只查了贪心自选的边**
   （现象：漏掉与选中端点无关的边；对策：全量边逐条检查（本例
   isCover 的写法），覆盖合法性断言优先于比值断言。）
3. **紧例当 bug 报**
   （现象：比值恰 2.00 以为实现错了；原因：贪心 2-近似是紧的——
   存在实例逼出等号；对策：与暴力最优对账（比值 ≤ 2 即可），别指望
   贪心总是接近最优。）
4. **忘了近似保证是「对最优」不是「对输入规模」**
   （现象：宣称「O(n) 的 2-近似」混淆时间与质量；对策：两个维度分开
   说——时间多项式 + 解 ≤ ρ·OPT。）
5. **对称破缺漏一条，精确解指数爆炸**
   （现象：n=12 已经搜不完；原因：相同剩余容量的箱子逐个试 = 枚举箱号
   排列，且每件都能开任意空箱——同构摆法重复 k! 量级；对策：同余量
   跳过 + 空箱只试第一个，n≤12 瞬时完成（本例实测写法）。）
6. **把 Best-Fit 的直觉「一定最优」当事实**
   （现象：本例 Best-Fit 用 3 箱而最优 2 箱，以为代码错了；原因：40+50
   局部最满却堵死 30 的去处——局部最优不是全局最优；对策：与精确解
   对账，贪心只信定理界（Best-Fit 同样有渐近 11/9 型保证）。）
7. **大例断言「箱数 ≤ 下界 + 常数」**
   （现象：10 万件随机尺寸断言 used ≤ lb+2 真的翻车；原因：随机碎片
   每箱摊一点，总量随 n 线性；对策：区分硬下界（used ≥ lb）与渐近
   陈述（比值随规模趋 1），经验界用比值断言且标注非定理。）
8. **k-中心贪心的「最远」拿全量距离当口径**
   （现象：每轮 O(n²) 重算点到中心集距离，大例变慢；原因：新中心
   加入后每个点的 dist 只可能变小——dist[i] = min(dist[i],
   d(i, 新中心)) 一次 O(n) 增量更新即可；对策：dist 数组跨轮维护，
   与 Dijkstra 的松弛同款骨架，总体 O(nk)。）
9. **中心子集枚举的 next_permutation 掩码初始值全 0**
   （现象：k 个 1 放在掩码前段，第一轮就漏掉「前 k 个点」这个子集、
   或循环提前结束；原因：next_permutation 按字典序推进，1 必须先
   放**尾部**才能不重不漏地走完全部组合；对策：mask 尾 k 位置 1
   起（C(n,k) 恰好被完整枚举），与 23.19 颜色串枚举的口径对齐。）
