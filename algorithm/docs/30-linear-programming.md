# 30 · 线性规划与单纯形法

> 对应 CLRS 第 29 章 *Linear Programming*（英文 3rd ed. pp.856–915）。
> 线性规划 = 线性目标 + 线性约束下的极值——它是「最大流、最短路、
> 匹配、对局论」的共同超类，也是「多项式时间内可解但实践靠指数最坏
> 算法」的经典范例（单纯形最坏指数、实践飞快；椭球/内点法多项式）。

## 学习目标

1. 能写出标准形与松弛形的互转；
2. 会实现表式单纯形（进基/离基/旋转）并追踪每步目标值；
3. 理解基本可行解 = 顶点、单纯形 = 沿多面体边爬山；
4. 能读出对偶变量（影子价格）并验证强对偶定理；
5. 知道退化与循环（Bland 规则的用武之地）；
6. 会用顶点枚举 O(m²) 解两个变量的 LP；对「全是 y ≥ ax+b」的简化形，
   会按斜率排序、用上包络栈 O(n log n) 求解并判定无界。

## 形式与几何

**标准形**：max cᵀx s.t. Ax ≤ b, x ≥ 0。**松弛形**：加松弛变量把
不等式变成等式（x₃ = 4 − x₁ − x₂ …）。几何图像：可行域是**多面体**
（半空间交），最优值在**顶点**取得（若有限）——顶点 = 「n 个约束
取等」的交点 = 松弛形的**基本解**（非基变量全零）。单纯形法 =
**从一个顶点沿边爬到更优顶点**，直到无改进方向。

## 单纯形法（§29.? SIMPLEX）

表（tableau）上两步循环：

1. **进基**：目标行还有正（本例规范化下为负）系数的变量——增大它能
   提升目标；选最负者（Dantzig 规则）；
2. **离基**：最小比值检验（bᵢ/aᵢⱼ 最小的行）——保证右端非负（可行性
   不破）；
3. **旋转（PIVOT）**：高斯消元把该列变成单位向量——新基变量就位。

实测（示例 30，整数顶点例题——计划注记的数值纪律）：

```
单纯形法（例题：max 3x+2y, s.t. x+y≤4, x+3y≤6, x≤3, x,y≥0）：
  迭代追踪（表旋转）：
  pivot #1：x1 进基、行 3 离基，z = 9.000000
  pivot #2：x2 进基、行 1 离基，z = 11.000000
  最优目标值 z = 11.000000（手算顶点枚举答案 11）
  最优解 x = 3.000000, y = 1.000000（顶点 (3,1)）
  顶点枚举对账：暴力最优 = 11.000000（= 单纯形）
```

两次旋转：x 先爬到 3（z=9，撞上 x≤3 的边），y 再进基到 1（z=11，
撞上 x+y≤4 的顶点）——**沿边爬山的完整可视化**。对账三重：顶点
枚举（小例的暴力真值）、解回代、目标值。

## 对偶与强对偶（§29.4）

每个原始 LP 都有对偶影子：max cᵀx (Ax≤b) 的对偶是 min bᵀy
(Aᵀy≥c, y≥0)。**强对偶定理（29.10）**：一方有有限最优 ⟹ 双方最优值
相等。对偶变量 y*（影子价格）从最优表的目标行**松弛列**直接读出：

```
  对偶变量（影子价格 = 最优目标行的松弛列）：u1=2.000000, u2=0.000000, u3=1.000000
  对偶目标 4u1+6u2+3u3 = 11.000000（强对偶 = 原始最优 11）
```

u₁=2：第一约束（x+y≤4）松一格，最优值涨 2——「资源价格」的算法含义
（u₂=0：该约束不起作用，白给多余量）。最大流最小割（第 27 章）正是
LP 对偶在图上的特例——两章在此握手。

## 两个变量的 LP：顶点枚举与上包络（30.5）

两个变量时可行域能画在平面上：每条约束 a·x + b·y ≤ c 是一个半平面，
可行域是半平面的交（凸多边形，可能无界）。这让我们可以绕开单纯形，
用最直接的几何办法求解。

### 顶点枚举 O(m²)

最优值必在可行域顶点取得，而每个顶点是**某两条边界直线的交点**。于是：

1. 枚举 m 条约束的所有 C(m,2) 个直线对，求交点（行列式 det=0 的平行对
   跳过）；
2. 对每个交点用**全部 m 条**约束过滤（不满足任一条就不是可行点）；
3. 在幸存顶点里取目标 p·x+q·y 的极值。

时间 O(m³)？交点 O(m²) 个、每个过 m 条约束 ⟹ O(m³)；本章代码规模
小（m≤10），无所谓。注意它**不需要**初始可行基，也没有旋转——退化
（多线共点）只会产生重复候选，不影响正确性。

**半平面的符号纪律**：x ≥ 0 写成半平面是 `{-1, 0, 0}`（−x ≤ 0），
写成 `{1,0,0}` 就变成 x ≤ 0——本例实测在这里翻过车。

**农夫例题**。设 x 头猪、y 只羊；两条约束：资金 6300x+10600y ≤ 200000，
收益门槛 22000x+35000y ≥ 200000（半平面记为 −22000x−35000y ≤ −200000），
x,y ≥ 0。目标 **min x+y**（最少养几头能跨过收益门槛）：

- 连续最优：每头羊收益 35000 最高，顶点 (0, 200000/35000) = (0, 40/7)，
  x+y = **40/7 ≈ 5.714**；
- 整数最优：x+y=5 时最大可能收益 5·35000=175000 < 200000，不可行；
  x+y=6 取 6 只羊可行 ⟹ **6 头**。

整数答案恰好等于连续最优的上取整，但这只是本例的幸运——**整数 LP 不
能靠对连续解取整求得**（一般情况下取整点可能破坏约束，整数最优也可以
显著大于连续最优）。代码在有限 x 范围内逐点用整数算术枚举可行 y。

### 简化形：上包络 O(n log n)

一类更简单的 LP：约束全是 **y ≥ a·x + b**，目标 min y。对给定 x，最小
可行 y = maxᵢ(aᵢx+bᵢ)——即直线族的**上包络**。包络是凸分段线性函数，
最小值只可能落在断点（两直线交点）或水平段上。

按**斜率排序**后用一个栈构造包络：加入新直线时，若它与栈顶直线的断点
落在栈顶与次栈顶断点的左边（顺序反了），栈顶直线永不在包络上，弹出；
同斜率只留截距最高的一条。构造 O(n log n)，再遍历 O(n) 个断点求值。

**无界判定**：包络在 x→±∞ 的走向由两端斜率决定——栈首斜率 > 0（左端
无上界）或栈尾斜率 < 0（右端 y 随 x→∞ 趋向 −∞）⟹ min y 无下界。只有
两端斜率把 0「夹住」时答案有限。

实测：直线 y≥0、y≥x−10、y≥−2x+20、y≥4x−80 的最小 y = **0**
（在 x=10 的断点）。随机 300 例（3..10 条直线）用「包络栈 / O(n²)
断点对举 / 通用顶点枚举」三个独立口径对账，0 例不一致。大例
10 万条随机直线，O(n log n) 给出最小 y ≈ 95.36，并在最优点逐条直线
复核包络值。

## 复杂度与退化

- **最坏指数**：Klee-Minty 立方体让 Dantzig 规则走 2ⁿ 个顶点；
- **实践飞快**：现实 LP 的旋转次数 ≈ O(m + n)——「指数最坏、线性平均」
  的著名案例；
- **退化**：最小比值平局时基变量取 0——转一圈目标值不动（循环）；
  **Bland 规则**（最小下标进基/离基）保证终止，代价是慢一点；
- **多项式替代**：椭球法（理论意义）与 Karmarkar 内点法（实践竞争者）
  ——「多项式」与「实用」并不总是一致，单纯形是活教材。

## C++23 语言点

- 表式实现的 `vector<vector<double>>`（行=约束+目标行）；
- `std::fabs(f) < 1e-15` 的零判据（浮点表的「= 0」必须带容差）；
- 例题的整数顶点设计让所有断言可用 1e-9 容差对整数真值（数值纪律）。

## 与 STL 对照

无标准 LP。工业界：Gurobi/CPLEX（商业）与 HiGHS/Clp（开源）——单纯形
+ 内点混合、稀疏矩阵、精确算术可选。把 LP 当「求解器调用」的工程视角：
约束建模比算法本身更值钱。

## 坑位清单

1. **进基判据的符号约定弄反**
   （现象：目标越旋越小、几步后「最优」在次优点；原因：目标行存
   z − Σcᵢxᵢ 时**负系数**才是改进方向——正负号取决于规范化方式；
   后果：静默次优；对策：先手推一遍两旋转的表（本例的追踪输出），
   z 必须每步单调升（本例实测翻车后修正）。）
2. **最小比值用负系数行**
   （现象：旋转后右端变负，可行域丢了；原因：比值检验只对 aᵢⱼ > 0
   的行做；对策：循环里 `if (a > 1e-9)` 的门槛（本例写法）。）
3. **退化循环没防**
   （现象：罕见输入下死循环（目标值不动但基一直在换）；原因：平局
   比值 + Dantzig 规则的已知循环构造；对策：Bland 规则开关（练习 5），
   或随机平局打破。）
4. **无界返回值当最优**
   （现象：目标行有进基列但比值检验全空（无 aᵢⱼ>0），返回 1e18 被
   当成数值；原因：该方向可行域无界（LP 无有限最优）；对策：哨兵值
   显式区分（本例 return 1e18 + 调用方断言 z < 1e17）。）
5. **对偶变量读错符号/列**
   （现象：对偶目标对不上原始最优；原因：影子价格在目标行的**松弛
   列**（不是决策列），符号看规范化；对策：强对偶断言（本例
   4u₁+6u₂+3u₃ == 11 的验证就是这个防线）。）
6. **非负约束的半平面符号写反**
   （现象：顶点枚举返回无解或最优值 0；原因：x ≥ 0 是 `{-1,0,0}`
   （−x ≤ 0）——写成 `{1,0,0}` 成了 x ≤ 0，可行域被翻到错误一侧；
   对策：每条非负约束单独检查边界方向，本例实测翻车后修正。）
7. **多口径对账却用了不同的定义域**
   （现象：包络法在整个 ℝ 上给出断点 x=−5，而带 x≥0 的顶点枚举给
   边界 x=0 的值，三方法「不一致」；原因：对照实验必须同域——本例
   随机 300 例改为全部在 ℝ 上比较才通过；对策：对账前列出每个口径
   的域，域不同时单独加边界直线（如 x=0）再比。）
8. **上包络栈对同斜率/断点失序处理不全**
   （现象：栈中混入永不上包络的直线，断点处求值偏大；原因：同斜率
   须只留截距最高者，新断点压到旧断点左边时必须循环弹出；对策：
   用 O(n²) 断点对举做独立口径全程对账（本例写法）。）
9. **整数 LP 直接对连续最优向上取整**
   （现象：农夫例恰好能取整，就以为 ILP 可以这么解；原因：连续最优
   附近的整数点未必满足约束，整数最优一般 > ⌈连续最优⌉；对策：在
   有限范围内逐整数点用整数算术枚举（本例），一般 ILP 是第 35 章的
   NP 难问题。）

4. （CLRS 思考题 29-2/29-3? 29-?）Klee-Minty 例的构造（指数路径）；

   观察旋转次数变化。
6. （本教程）二维顶点枚举是 O(m²) 个交点 × m 条过滤；三维 LP 的可行
   域顶点是三个约束平面的交点——写出三维枚举的算法与 O(m⁴) 量级，
   并解释为什么高维枚举在实践上不可行（顶点数本身可指数）。
7. （本教程）构造一个 min y 无下界的直线族（如全部负斜率），验证
   包络栈的无界判定；再说明此时 O(n²) 断点对举仍返回一个有限值，
   为什么那个值**不是**最优（它只是最优点的伪装）。
8. （本教程）给农夫问题再加一条「每头猪另需占地 2 单位、每只羊 1
   单位，总占地 ≤ 9」的约束，逐整数点枚举新最优；验证连续最优是否
   改变、整数答案是否还等于连续值上取整。
