# 26 · 所有顶点对最短路径

> 对应 CLRS 第 25 章 *All-Pairs Shortest Paths*（英文 3rd ed. pp.704–726）。
> 要 V 个源的最短路——最直接是「每个源跑一遍 Dijkstra」（O(VE + V² lg V)）；
> 本章给两条更深的路：**Floyd-Warshall**（DP 于中转点，Θ(V³)，容忍
> 负权）与 **Johnson**（重赋权化归 Dijkstra，稀疏图王座）。

## 学习目标

1. 能写出 Floyd-Warshall 的 DP 递推与 D^(k) 的语义；
2. 会用前驱矩阵（next 表）重构具体路径；
3. 会写传递闭包（FW 的按位版）；
4. 理解 Johnson 的重赋权思想（potentials 让所有边非负）与它对
   稀疏图的复杂度优势；
5. 能对同一非负图三角对账（FW vs 逐源 Dijkstra）；
6. 会用全源距离定义**离心距、半径与中心**：在连通图上用 FW/BFS 求
   e(v)=max d(v,u) 并收集半径最小者；在树上会用整轮剥叶法求中心
   （1 或 2 个）并知道半径 = ⌈直径/2⌉。

## Floyd-Warshall（§25.2）

**DP 状态**：d^(k)[i][j] = 只允许**中转点 ⊆ {1..k}** 的 i→j 最短路。

```
d^(0)[i][j] = w[i][j]（直达边）
d^(k)[i][j] = min(d^(k-1)[i][j],               // 不经 k
                  d^(k-1)[i][k] + d^(k-1)[k][j])  // 经 k 恰一次
```

关键观察：**k 在右侧只出现在端点**（d^(k-1)[i][k] 里 k 不会是中转），
所以可以原地滚动（k,i,j 三重循环顺序不能乱）。Θ(V³) 时间、Θ(V²) 空间。

图 25.1 的经典实测（示例 26.1，含负权 −4/−5）：

```
D^(0)（权重矩阵 W）:
  0  3  8  ∞ -4        D^(5)（最终全源距离矩阵）:
  ∞  0  ∞  1  7          0  1 -3  2 -4
  ∞  4  0  ∞  ∞          3  0 -4  1 -1
  2  ∞ -5  0  ∞    →     7  4  0  5  3
  ∞  ∞  ∞  6  0          2 -1 -5  0 -2
                           8  5  1  6  0
```

与 CLRS 图 25.4 的 D^(5) 逐格一致（assert 全量核对）。看点：负权如何
传播——D^(1) 里 4 行的 5 与 −2（4→1→2、4→1→5 借道顶点 1）；最终表
里 2 行的 3（2→3? 不，2→4→1→5→? 的链）——负权把「绕远路」变成捷径。

**路径重构**：next[i][j] = 「i→j 第一步」，FW 更新时同步改写；
查路径时沿 next 链走。示例：1→5 的最短路是直达边（−4）——不是所有
负权图都得绕路。

**INF 卫哨（本例实测翻车）**：`INF + (−4) = 999996 < INF`——不加卫哨
时「无穷大的边」被负权伪松弛，D^(1) 出现 999996 这类怪值。正确写法：
松前判 `d[i][k] < INF && d[k][j] < INF`。

## 传递闭包（§25.2 的姊妹）

把 min/+ 换成 **and/or**：t^(k)[i][j] = t[i][k] && t[k][j]——可达性矩阵。
Θ(V³) 且可用位运算一次并行 64 个顶点（位集优化到 Θ(V³/64)，Warshall
的原始动机）。示例 26.3 的 4 顶点例：0 可达全部、1/2/3 互达但**到不了
0**（入向无边）——闭包矩阵不是全 1。

## Johnson：重赋权 + Dijkstra（§25.4）

**问题**：稀疏图（E ≪ V²）上跑 V 次 Dijkstra 最快，但图有负权时
Dijkstra 非法。**Johnson 的魔法**：给每个顶点一个势 h(v)，新权

w′(u,v) = w(u,v) + h(u) − h(v)

任何路径的总权平移 h(s) − h(t)（**路径结构不变、最短路不变**）；取
h(v) = δ(超级源, v)（Bellman-Ford 一次），则 w′ ≥ 0（三角不等式的
逆向读法）——负权图化归成非负图！之后 V 次 Dijkstra，总复杂度
O(V·E lg V)。无负环是前提（h 的存在性 ⟺ 无负环）。

Johnson 是「**变换问题使其适配快速算法**」的典范——与第 5 章随机化、
第 11 章全域散列同一谱系：不硬打，换个表示再打。

## 三角对账（示例 26.4）

同一张非负图：FW 一次 vs 逐源 Dijkstra 五次——**5×5 距离矩阵逐格
一致**（25 个断言）。这是「两个独立实现互相锁死」的验证学：FW 是 DP、
Dijkstra 是贪心，两条完全不同的推理链到达同一矩阵，出错时几乎不可能
错得一样。

## 复杂度对比

| 方法 | 时间 | 空间 | 适用 |
|---|---|---|---|
| V × Dijkstra（二叉堆） | O(VE lg V) | O(V²) | 稀疏、非负 |
| V × Dijkstra（斐波那契堆） | O(V² lg V + VE) | O(V²) | 稀疏、非负 |
| Johnson | 同上 + BF 的 O(VE) | O(V²) | 稀疏、有负权 |
| Floyd-Warshall | Θ(V³) | O(V²) | 稠密、有负权 |
| 矩阵乘法（重复平方） | Θ(V³ lg V) | O(V²) | 理论漂亮、实践少见 |

V ≈ 1000、E ≈ 5000 时 Johnson 完胜 FW（V³ = 10⁹ vs VE lg V ≈ 5×10⁷）；
稠密到 E ≈ V² 时两者同阶、FW 的实现常数更小。

## 图的中心：离心距、半径与树的剥叶法

拿到全源距离矩阵后，一个直接应用是找「图的中心」——在道路网里建急救
站、在分布式系统里放主节点，都希望该点到最远节点的距离尽量小。

**定义**（限连通图）：

- **离心距** e(v) = max_{u∈V} d(v,u)：v 到最远点的距离；
- **半径** r = min_v e(v)：所有「最坏情况距离」里最小的一个；
- **中心** = { v ｜ e(v) = r }：达到半径的顶点（注意是集合，一般图上
  可能有很多个）。

固定例（7 顶点连通图）各点离心距与中心：

```
=== 26.5 图的中心：e(v)=max d(v,u)，半径与中心点 ===
  各点离心距: A:4 B:3 C:3 D:2 E:3 F:4 G:4
  中心点: D ；半径 2
  随机 200 个连通图：BFS vs Floyd 距离/中心不一致 0 例
  随机树 100 棵：剥叶中心/半径与 Floyd 口径不一致 0 例
  大例（n=400 随机连通图）：半径 5，中心 252 个（中心到每点 ≤半径已逐点核）
```

### 树上：剥叶法与直径

在**树**上中心只有两种可能：一个点或一条边的两个端点，它们恰是任一
**直径**（最长路径）的中点。因此不必求全源距离，两轮观察即可定位：

1. 取所有当前叶子（度 ≤ 1），**整轮同时删去**，新产生的叶子下一轮再删；
2. 重复到存活点 ≤ 2 个——存活点就是全部中心。

直觉：直径的两个端点必在每轮的叶子集合里，每剥一轮直径从两端各缩一；
剥 ⌊diam/2⌋ 轮后只剩中点。奇数直径留一个中心点、半径 = (diam+1)/2；
偶数直径留两个、半径 = diam/2——统一写作 **半径 = ⌈diam/2⌉**。

### 对账与口径

- 200 个随机连通图（随机生成树保连通 + 补随机边）上，逐源 BFS 与
  Floyd 的距离、离心距、半径、中心集合全部一致；
- 100 棵随机树上，剥叶中心与 Floyd 中心集合一致，剥叶半径与 BFS 实测
  直径满足 ⌈diam/2⌉；
- 大例 n=400 上逐个中心核对「到任意点距离 ≤ 半径」；
- 不连通图离心距含 ∞、半径与中心无定义，示例单独检查连通性标志。

## 坑位清单

1. **INF + 负权 = 溢出伪松弛（本例实测翻车）**
   （现象：D^(1) 出现 999996，「不可达」被写成接近 INF 的小数字；
   原因：INT_MAX 或 1e6 当 INF 直接参与加法，负权把它拉到 INF 之下；
   后果：不可达对的最短路变成假值，后续重构路径走向不存在的链；
   对策：松前卫哨（d[i][k] ≥ INF 则 continue），或 INF 取小值且全图
   任何路径权和 < INF/2 的约定写进注释。）
2. **k 循环不在最外层**
   （现象：结果部分错（D^(k) 的语义要求 k 是「逐步开放的中转点」）；
   原因：i/j/k 的循环序错了，DP 的阶段维必须最外；对策：背下
   `for k for i for j`——FW 的签名节奏（本例写法）。）
3. **next 表更新成 j 而不是 next[i][k]**
   （现象：重构路径一步跳错、循环成环；原因：改写应为「走 k 的第一
   步」= next[i][k]，直赋 j 只对直达边成立；对策：路径重构断言——
   沿 next 链走的累计权 == d[i][j]（练习 6 的内容）。）
4. **对负权图跑 V 次 Dijkstra**
   （现象：部分源的结果错；原因：Dijkstra 的非负前提被无视；对策：
   入口扫描边权，有负 → Johnson（先 BF 求势再重赋权）。）
5. **传递闭包断言「全可达」**
   （现象：非强连通图被误判失败；原因：闭包矩阵本来就不是全 1——
   可达性是偏序不是全序；对策：断言对照**手工推的**闭包矩阵（本例
   实测翻车后的写法）。）
6. **不连通图上硬算半径与中心**
   （现象：INF 被当成普通大数字参与 max/min，某点仅因自己所在连通块
   小而「离心距最小」被错选成中心；原因：只要有一个不可达对，离心距
   就是 ∞，半径与中心无定义；对策：先跑连通性检查（FW 矩阵扫 INF，
   或并查集/BFS 数连通块），不连通直接报无中心。）
7. **剥叶不按「整轮同时」进行**
   （现象：偶数直径的两个中心被剥成一个，或奇数直径中心错位到邻点；
   原因：先剥的叶子会立刻改变邻点的度，顺序处理等于多剥了半轮；对策：
   每轮先把当前叶子收集成快照，统一删除并统一更新度数，再进入下一轮；
   循环终止条件是存活点 ≤ 2 个。）
8. **以为中心唯一、无权大图却跑 Floyd**
   （现象：漏掉同样达到半径的中心点，或 n=400 的图上 Θ(V³) 慢得不
   必要；原因：一般图的中心集合可以很大（实测大例有 252 个），只有树
   保证中心 ≤ 2 个；无权图的全源距离用逐源 BFS 只需 O(V(V+E))；对策：
   中心按集合收集、按集合对账，无权图优先 BFS、稠密带权图才上 FW。）

   离心距并验证「D 到任一点距离 ≤ 2、其余每点都能找到距它 ≥ 3
   的点」——由此说明半径恰为 2 且中心唯一。
8. （本教程）证明树上「剥叶 ⌊diam/2⌋ 轮后存活点即中心」：先证每轮
   被剥集合恰含直径端点，再证剥叶不改变「剩余树的直径＝原直径−2」；
   由此推出半径 = ⌈diam/2⌉。
9. （本教程）给加权树（边权不全为 1）设计中心算法：剥叶法中每点带
   一个「距最近已剥叶子的距离」累加器，在 O(V) 内求出加权半径与
   中心（可能为一条边的内分点）；在随机加权树上与 Floyd 中心对账。
