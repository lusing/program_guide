# 31 · 多项式与快速傅里叶变换

> 对应 CLRS 第 30 章 *Polynomials and the FFT*（英文 3rd ed. pp.922–
> 946）。多项式有两种表示：**系数**（除法难）与**点值**（乘法 = 点值
> 逐点乘，O(n)）。FFT 就是两种表示之间的 Θ(n lg n) 传送门——卷积
> （多项式乘、大数乘、信号滤波、卷积网络）从此进入对数世界。

## 学习目标

1. 能写 DFT 的定义（单位根求值）与逆变换（插值）；
2. 会实现递归 FFT（奇偶分裂 + 蝴蝶合并），理解 lg n 层的结构；
3. 能用卷积定理做多项式乘法并与朴素卷积对账；
4. 会用「数位当系数」把大整数乘法化归多项式乘法；
5. 掌握浮点章的数值纪律：定点打印、容差断言、llround 进位。

## 两种表示与单位根（§30.1/30.2）

n 次多项式由 **n 个点值**唯一确定（不同横坐标）。选**n 次单位根**
ω⁰, ω¹, …, ωⁿ⁻¹（ω = e^{2πi/n}）做横坐标——这套特殊点的求值/插值
都有 Θ(n lg n) 的递归算法（FFT/IFFT）。CLRS 约定 ω = e^{+2πi/n}
（**符号约定要钉死**——本例首版把正逆变换的符号弄反，DFT 出来的是
共轭值，手算对账一抓一个准）。

**消去/折半/求和引理**：ω²ₙ = ωₙ²（平方折半）、(ω^{k+n/2})² = ω²ₖ
（奇偶下标在平方后合并）——FFT 递归的全部根据。

## 递归 FFT（§30.? RECURSIVE-FFT）

```cpp
static void fft(std::vector<CD>& a, double sign) {
    const std::size_t n = a.size();
    if (n == 1) { return; }
    std::vector<CD> even(n / 2), odd(n / 2);
    for (std::size_t i = 0; i < n / 2; ++i) { even[i] = a[2*i]; odd[i] = a[2*i+1]; }
    fft(even, sign);
    fft(odd, sign);
    // 蝴蝶：a[k] 与 a[k+n/2] 用 w^k 一次复乘合并
    for (std::size_t k = 0; k < n / 2; ++k) {
        a[k]       = even[k] + w * odd[k];
        a[k + n/2] = even[k] - w * odd[k];
        w *= wn;
    }
}
```

T(n) = 2T(n/2) + Θ(n) = Θ(n lg n)。每层 n/2 次**复数乘法**（蝴蝶的
w 因子）——与朴素 DFT 的 n² 次复乘对比就是全部收益。逆变换 = 同一
算法换 ω̄（sign 取反）再除 n——**正逆共用一份代码**。

实测（示例 31.1，A(x) = 1+2x+3x² 的 4 点 DFT，手算精确对账）：

```
DFT（A(x)=1+2x+3x² 的 4 点值表示）：
  A(w^0) = +6.00+0.00i
  A(w^1) = -2.00+2.00i
  A(w^2) = +2.00+0.00i
  A(w^3) = -2.00-2.00i
  往返一致性 FFT→IFFT 复原系数（容差 1e-9）= 1
```

（A(i) = 1+2i+3i² = 1+2i−3 = −2+2i ✓——四个值全部与手算逐位吻合；
往返一致性（FFT 再 IFFT 复原原系数）是实现的第二道防线。）

## 卷积定理：多项式乘法（§30.?）

**C = A·B 的系数 = IFFT( FFT(A)·FFT(B) )**——点值表示下乘法是逐点
O(n)，整个流水线 Θ(n lg n)。实测（示例 31.3）：

```
卷积定理（(1+2x+3x²)(4+5x)）：FFT 版系数: 4.00 13.00 22.00 15.00
  与朴素卷积逐系数一致（= 4,13,22,15）；FFT 复数乘 4 次 vs 朴素标量乘 6 次
```

小例上 FFT 的乘法计数还更多（递归开销主导）——渐近优势要到 n 千级
才显现（n=1024 时 5120·lg 级复乘 vs 10⁶ 标量乘）。工程版：迭代
FFT（位逆序置换 + 自底向上蝶形，练习 30.3-?）省递归分配、缓存 w 表。

## 大整数乘法（§30.?）

十进制数的数位就是多项式系数（123 = 1·10²+2·10+3）——**大数乘 =
多项式卷积 + 进位归一化**。实测（示例 31.4）：

```
大整数乘法：123456789 × 987654321 = 121932631112635269（校验 121932631112635269）
```

double 精度撑得住 9 位×9 位（卷积系数 ≤ 81·9 ≈ 729，远低于 2⁵³）；
竞赛的大数板子用 long double 或 NTT（数论变换，模素数域的 FFT——
第 32 章数论知识回收）破精度墙。

## 数值纪律的三连击（本例实测翻车清单）

1. **符号约定**：正变换用 +（CLRS 约定）还是 −（工程惯例）必须钉死，
   首版弄反 → DFT 全共轭；
2. **llround 进位**：FFT 结果带 ±1e-9 噪声，`(long long)prod[i]` 的
   截断会把 9.9999996 吃成 9——必须 `llround`；
3. **进位扩展**：最高位 ≥ 10 时（本例 3449 → 进位链把首两位变成 12）
   要把向量扩一位——循环写死 `i+1 < size` 会丢最高进位；
4. **char 当系数**：`vector<double>(str.rbegin(), str.rend())` 把字符
   码 '9'=57 当数字——必须减 '0'（本例最离谱的一坑）。

## 与 STL 对照

无标准 FFT（`std::fftw` 不存在；FFTW 是 C 事实标准）。C++23 的关联
新物：`std::complex` 的运算全 IEEE 确定（固定运算序 → 三通道对账可行
——本例逐字节一致的基础）；`std::numbers::pi`（C++20）精确常量。

## 坑位清单

1. **正逆变换的符号弄反（本例实测翻车）**
   （现象：DFT 值全为手算的共轭；原因：sign 约定两头不一致；对策：
   CLRS 约定 ω = e^{+2πi/n} 写进注释，DFT 用小例手算对账（1+2x+3x²
   的四点值是完美的验钞机）。）
2. **进位用截断不用取整（本例实测翻车）**
   （现象：个位数系统性差 1（9.9999996 → 9）；对策：llround 后再做
   模运算（本例修正版）。）
3. **最高进位丢失（本例实测翻车）**
   （现象：结果少一位或首位是两位数（'<' 之类的怪字符）；原因：进位
   循环只归一化到 size−2，尾部 ≥10 要扩容；对策：整数向量上的完整
   归一化循环（本例修正版），输出前断言每位 ∈ [0,9]。）
4. **字符串直接构造系数向量（本例实测翻车）**
   （现象：卷积值大得离谱（57² 量级）；原因：char 迭代器构造 double
   向量存的是字符码；对策：`*it - '0'`（本例修正版）——「字符 ≠ 数字」
   是 C++ 老坑，在数值代码里加倍致命。）
5. **FFT 长度不是 2 的幂**
   （现象：递归分裂奇数长度、蝴蝶错位；原因：递归 FFT 要求 n = 2^k；
   对策：调用前 `while (n < need) n *= 2` 补零（本例 poly_mul_fft 的
   写法）；或用任意长度的 Bluestein 算法。）
