# 16 · 动态规划（下）：LCS、最优 BST 与编辑距离

> 对应 CLRS §15.4–15.5（英文 3rd ed. pp.390–405）。上一章给了方法论，这一
> 章两个「状态不是一维下标」的例子：LCS 的状态是**二维对角**（两个序列
> 的前缀对），最优 BST 的状态是**区间**。最后加一个实战延伸——编辑距离
> （LCS 的变体，diff/拼写检查/生物序列比对的共同祖先）。

## 学习目标

1. 能写出 LCS 的二维递推与重构（b 表回溯）；
2. 能推最优 BST 的 e/w/root 三表递推（CLRS 例 2.75）；
3. 会把「新问题」映射到已有 DP 骨架（编辑距离 = LCS 的插/删/改版）；
4. 理解二维 DP 表的填表顺序与空间压缩（滚动数组）的可能性。

## 最长公共子序列（§15.4）

**问题**：X = ⟨x₁..xₘ⟩、Y = ⟨y₁..yₙ⟩，找最长的公共子序列（可断续、
保序）。X = ABCBDAB、Y = BDCABA 时 LCS 长度 4（如 BCBA）。

**递推**（状态 = 两串的前缀对 (i, j)）：

```
c[i,j] = 0                          若 i=0 或 j=0
       = c[i-1,j-1] + 1             若 x_i = y_j      （对角）
       = max(c[i-1,j], c[i,j-1])    否则              （上/左取大）
```

**最优子结构**：两末字符相等时它必在**某个** LCS 里（去掉它，剩下的
是两个更短前缀的 LCS）；不等时至少一端的末字符不在 LCS 中——两种
「退一格」的子问题必有一个保住最优。Θ(mn) 时间与空间。

**重构**：b 表记录每格的来向（↖/↑/←），从右下角回溯到边界即得 LCS
本身（示例 16.1 从 "ABCBDAB"/"BDCABA" 重构出 `BCBA`，并用
`is_subsequence` 双向验证——重构结果必须同时是两串的子序列）。

```
LCS（图 15.8 数据 X=ABCBDAB, Y=BDCABA）：
  长度 = 4，重构出的 LCS = "BCBA"
  c 表右下角（D A B 行 × 末 3 列）: 2 3 3 / 3 3 4 / 3 4 4
```

## 最优 BST（§15.5）

**问题**：n 个键 k₁<…<kₙ（查找概率 pᵢ）与 n+1 个伪键 d₀..dₙ（ miss
概率 qⱼ，落在键间隙）。造 BST 使**期望搜索代价** Σpᵢ·(depth(kᵢ)+1) +
Σqⱼ·(depth(dⱼ)+1) 最小。平衡 BST 只是最优的特例——概率偏斜时最优树
**故意不平衡**（把高频键放浅处）。

**递推**（状态 = 区间 [i,j] + 根的选择）：

```
e[i,j] = q_{i-1}                                  若 j = i−1（空树，只剩伪键）
       = min_{i≤r≤j} { e[i,r−1] + e[r+1,j] + w[i,j] }
w[i,j] = w[i,j−1] + p_j + q_j                     （区间总概率，增量维护）
```

**关键洞见**：选定根 k_r 后，深度全体 +1 的代价恰是 w[i,j]（子树全体
概率和）——于是 e 由「两半子问题 + 区间概率和」构成。Θ(n³) 时间。

CLRS 图 15.10 的 5 键例（p=⟨.15,.10,.05,.10,.20⟩，
q=⟨.05,.10,.05,.05,.05,.10⟩）实测：

```
最优 BST（图 15.10 数据，5 键）：期望搜索代价 = 2.750000（CLRS 答案 2.75）
  根 = k2（root[1][5]），子树根 root[2][5] = k4
```

最优树把 p=0.20 的 k₅ 放在深度 2、高频 k₁/k₂ 在顶部——与「均匀键就
平衡」的直觉对照鲜明。

## 编辑距离：LCS 骨架的变奏（实战延伸）

d[i,j] = x 前 i 与 y 前 j 的最少编辑数（插/删/改），递推与 LCS 同构、
只是格子值换语义：

```cpp
d[i][j] = min({ d[i-1][j] + 1,          // 删 x_i
                d[i][j-1] + 1,          // 插 y_j
                d[i-1][j-1] + cost });  // cost = 0（相同）或 subCost（改）
```

**恒等式做交叉验证**：替换代价取 2（替换不划算 ⇒ 事实上的只插删）时，
d = m + n − 2·LCS——两个独立实现的 DP 互相锁死（示例 16.4）：

```
编辑距离（Levenshtein，替换代价 1）：kitten→sitting = 3（经典 3 步：改 k→s、改 e→i、插 g）
  ABCBDAB vs BDCABA：Levenshtein = 5，插删距离 = 5（= 7+6−2×LCS4 = 5，恒等式验证）
```

应用谱系：`diff`（插删 + 块移动）、拼写检查（Levenshtein ≤ k 的词典
扫描）、DNA 序列比对（改错罚分不对称的加权版）、`git` 的 Myers diff
（O(ND) 的 D=编辑距离算法——工程版再优化一层）。

## C++23 语言点

- 二维表的 `vector<vector<int>>` 直白版；竞赛/工程版用一维平铺 +
  手工下标（缓存友好），空间可滚动压缩到两行（c[i] 只依赖第 i−1 行）；
- 递归重构用 `std::function`（闭包递归最简写法；第 10/15 章的显式对象
  形参 lambda 是零开销替代）；
- `std::min({...})` 的 initializer_list 版一次取三数最小。

## 与 STL 对照

无直接对应。留意两个「近亲」：`std::mismatch`/`std::ranges::mismatch`
（找两序列首个不同点——编辑对齐的基本件）与 `std::string::starts_with`
（C++20 起，前缀判定的标准件）。

## 坑位清单

1. **重构 LCS 时 b 表方向写反**
   （现象：重构出的串是 LCS 的「反序」或空串；原因：回溯时先把字符
   拼接在后面/前面弄错——`lcs(i-1,j-1) + x[i-1]` 才是正序；后果：长度
   对但串错；对策：重构后必须做 `is_subsequence` 双向断言（示例的
   做法——只查长度查不出这种错）。）
2. **最优 BST 的 w 表增量式算错**
   （现象：e 表全盘偏小量；原因：w[i,j] = w[i,j−1] + p_j + q_j 的增量
   里两项都要加——漏 q_j 是常见笔误；后果：整棵树的期望代价系统性
   偏低；对策：小例手算 w 表逐格对（n=5 只有 15 格）；或用
   Σp+Σq 全量重算对账。）
3. **区间 DP 的循环边界差一**
   （现象：e[i][i−1] 越界或空树格漏初始化；原因：区间 DP 的「空区间」
   是合法状态（j = i−1），必须显式初始化；后果：未定义行为或漏最优；
   对策：先写边界态（空树 = 只含伪键），再写 l = 1..n 的主循环。）
4. **把「允许替换的编辑距离」与「插删距离」混为一谈**
   （现象：断言 Levenshtein == m+n−2·LCS 失败；原因：恒等式只对替换
   代价 ≥ 2（或禁止替换）成立；替换代价 1 时距离只能更小或相等；
   后果：错误断言把正确的实现判了死刑；对策：替换代价参数化（示例
   edit_distance(x, y, subCost)），恒等式用 subCost=2 验证——本例
   首版实测翻车。）

## 练习

1. （CLRS 练习 15.4-1）求 ⟨1,0,0,1,0,1,1⟩ 与 ⟨0,1,1,0,1,1,0⟩ 的 LCS。
2. （CLRS 练习 15.4-2）由 c 表（没有 b 表）重构 LCS——回溯时比较
   c 值推断方向。
3. （CLRS 练习 15.4-4）LCS 的空间优化：两行滚动 O(min(m,n))；以及
   只需长度时 Hirschberg 的线性空间分治。
4. （CLRS 练习 15.4-5）最长单调递增子序列 O(n²) DP（排序+LCS 的转化），
   再挑战 O(n lg n)（耐心排序/二分——第 9 章 nth_element 的亲戚）。
5. （CLRS 练习 15.5-1/15.5-2）构造最优 BST 的结构（打印树）；对
   p=⟨0.05,0.4,0.08,0.04,0.1,0.1,0.23⟩ 算最优代价（答案 2.18）。
6. （CLRS 练习 15.5-4）Knuth 的优化：root[i,j−1] ≤ root[i,j] ≤
   root[i+1,j] 把 Θ(n³) 压到 Θ(n²)。
7. （本教程）给编辑距离加「操作轨迹重构」（d 表回溯输出「改 k→s」的
   编辑脚本），对 kitten→sitting 打印三步操作。
