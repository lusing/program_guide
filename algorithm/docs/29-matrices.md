# 29 · 矩阵运算：LUP 分解与求解

> 对应 CLRS 第 28 章 *Matrix Operations*（英文 3rd ed. pp.826–852）。
> Strassen 已在第 04 章讲过；本章主菜是 **LUP 分解**——把 Ax=b 的求解
> 变成「分解 Θ(n³) 一次 + 每个右端项 Θ(n²) 求解」的流水线，顺产
> 行列式与逆矩阵。数值线性代数（LAPACK/Eigen 的地基）从这里开始。

## 学习目标

1. 会实现部分主元的 LU 分解并解释主元选择的数值意义；
2. 会用 L·U 前代/回代解线性方程组；
3. 能从 LU 读出行列式（符号 × 对角积）与逆矩阵（逐列求解）；
4. 记住 LUP 的头号实现坑：行交换时 L 的已算部分必须跟着换。

## LUP 分解（§28.2? LUP-DECOMPOSITION）

把 A 写成 **P·A = L·U**：L 单位下三角（消元乘数）、U 上三角（消元
结果）、P 置换（记录行交换）。**部分主元**：每步选当前列绝对值最大
的行做主元——「除以大头」把舍入误差压住（不选主元的 LU 在某些良态
矩阵上都能爆掉，练习 28.2-? 的经典反例）。

分解后的世界很便宜：

- **解 Ax=b**：PAx = Pb ⟹ Ly = Pb（前代，O(n²)）⟹ Ux = y（回代，
  O(n²)）——换右端项 b 只花平方级；
- **行列式**：det(A) = sign(P)·Π U[i][i]——分解的免费赠品；
- **逆矩阵**：A⁻¹ 的每一列 = 解 A·x = eᵢ——n 次平方级求解，总 Θ(n³)
  （但常数是 LU 的 ~3 倍；「要求逆吗」在数值上几乎总是「不」——直接
  解 Ax=b 更准更快）。

实测（示例 29，经典 3×3 例 A = [[2,1,−1],[−3,−1,2],[−2,1,2]]，
b = A·[1,2,3]ᵀ = [1,1,6]ᵀ）：

```
LUP 分解（部分主元）：P·A = L·U
  置换 perm = [1,2,0]（行 1 换到首位），行列式符号 = 1
  L·U 与 P·A 重积一致（容差 1e-9）= 1
  解 Ax=b：x = [1.000000, 2.000000, 3.000000]（真值 [1,2,3]，|误差|<1e-9 = 1）
  det(A) = sign·∏U[i][i] = -1.000000（真值 −1）
  逆矩阵 A⁻¹ 求得（A·A⁻¹ = I 容差验证 = 1），A⁻¹[0][0] = 4.000000
```

四件套（重积对账 / 求解 / 行列式 / 逆）全部与手算真值吻合。

## 行交换的 L 陷阱（本例实测翻车）

第 k 步交换行 pivot ↔ k 时，**L 的前 k 列（已算出的乘数）必须跟着
换**——乘数属于「行」而不是「位置」。漏掉这一步，L·U 重积对不上
P·A（本例首版实测，重积断言当场抓出）。教科书不显式讲它（CLRS 的
原地版把乘数存在矩阵下三角里、行交换自然带着走），分离存储的实现
必须自己补上。

## 数值纪律（浮点章的输出规矩）

本章起进入浮点域，本教程的三条纪律（docs/01）全程生效：

1. **定点打印**（{:.6f}）——不打印裸浮点；
2. **容差断言**（|x − 真值| < 1e-9）——整数例题让真值精确可验；
3. **例题选整数**（计划注记）——A、b、x、det 全整数，double 的舍入
   误差远小于 1e-9，三通道逐字节一致。

## 复杂度与其他算法

| 操作 | 复杂度 | 备注 |
|---|---|---|
| 矩阵乘（朴素/Strassen） | Θ(n³) / Θ(n^2.81) | 第 04 章 |
| LUP 分解 | Θ(n³) | 一次投资 |
| 每右端项求解 | Θ(n²) | 前代+回代 |
| 行列式 / 逆 | Θ(n³) | 分解的副产品 / 逐列 |

（对称正定矩阵的 Cholesky（A = LLᵀ）省一半——练习 28-?；三对角
系统的 Θ(n) 追赶法——思考题 28-1。）

## 与 STL 对照

无标准线性代数（C++26 的 `std::linalg` 在路上——本教程特性禁用清单
上的「等三通道」一员）。Eigen 是 C++ 事实标准（LUP = `PartialPivLU`）；
生产数值库全部选主元 + 分块 + SIMD——「同一个数学，快三个数量级」
的工程学。

## 坑位清单

1. **行交换时 L 不跟着换（本例实测翻车）**
   （现象：L·U ≠ P·A，重积断言炸；原因：分离存储的 L 里已算出的
   乘数属于原行，换 u 行时 l 的前 k 列要成对 swap；对策：swap 循环
   写在同一个 if 里（本例修正版），重积断言兜底。）
2. **不选主元直接消元**
   （现象：主元为 0 崩溃、或接近 0 时误差爆炸；原因：无主元的 LU
   数值不稳定；对策：部分主元（列最大）是底线，全主元更稳但更贵。）
3. **前代/回代的循环边界差一**
   （现象：解差一个下标分量；原因：y[i] = (Pb[i] − Σ_{j<i} L[i][j]y[j])
   的求和区间与 x 的逆序区间容易抄错；对策：小例手算对照（本例的
   [1,2,3] 真值设计就是干这个的）。）
4. **求逆当默认操作**
   （现象：x = A⁻¹·b 比 Ax=b 慢且更不准；原因：逆把 n 次求解的误差
   固化进矩阵，且 Θ(n³) 常数更大；对策：永远直接解，逆只在做
   「反复乘不同向量且不能缓存分解」的罕见场景才值得。）
