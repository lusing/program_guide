# 24 · 最小生成树

> 对应 CLRS 第 23 章 *Minimum Spanning Trees*（英文 3rd ed. pp.624–642）。
> 无向连通带权图里挑 n−1 条边连通所有顶点、总权最小。两条经典贪心路线
> ——Kruskal（按边贪心 + 并查集）与 Prim（按点贪心 + 堆）——都是
> **_cut 性质**（安全边定理）的化身；第 22 章的并查集在这里正式上岗。

## 学习目标

1. 能陈述并证明 cut 性质（跨越任何割的最小边是安全边）；
2. 会实现 Kruskal（排序 + 并查集）与 Prim（键值 + 堆/数组），复杂度
   O(E lg E) 与 O(E lg V)；
3. 理解两算法的差异：边视角 vs 点视角、稀疏图 vs 稠密图；
4. 能对同一图跑两法并对账（总权一致、边集可不同）；
5. 会把「阈值可行性」翻译成 MST 边权序列上的定位（物以类聚），并用
   逐阈值 DSU 枚举验证。

## cut 性质：一切 MST 贪心的根据

**定理 23.1**：把顶点集分成 (S, V−S)，设 e 是跨越该割的**最小权边**，
则存在某棵 MST 含 e。（证明：交换论证——任取 MST，若不含 e，沿 e 加入
形成环，环上必有另一条跨割边 e′，|e′| ≥ |e|，换入 e 总权不增。）

**贪心模板**：维护「已确定的安全边集 A」（始终是某 MST 的子集），每轮
找一个割，使 A 的边都不跨割，然后取该割的最小边入 A——**归纳地长成
MST**。Kruskal 与 Prim 只是选割的方式不同：

- **Kruskal**：按权升序考虑每条边；A 所在的连通分量自动定义割（边的
  两端是否已连通）——并查集 O(α) 判定，成环则弃；
- **Prim**：割 = （树, 非树）；每轮取「跨割最小边」= 键值最小的非树点；
  堆维护键值。

## Kruskal 实测（图 23.1）

排序后逐边入并查集，成环弃边（示例 24.2）：

```
Kruskal 边集: gh ci fg ab cf cd ah de
总权 = 37，弃边 6 条（成环检测）
```

1+2+2+4+4+7+8+9 = 37，与 CLRS 图 23.4 的 MST 一致；14 条边弃 6 条
（连成 9 个点恰用 8 条）。复杂度 O(E lg E)——排序主导；并查集的
O(E·α(V)) 只是配角。

## Prim 实测（图 23.1，源 a）

键值数组版：key[v] = 「v 到树的最小边权」，每轮 O(V) 扫描取最小（教学
版；工程版换二叉堆到 O(E lg V)）：

```
Prim(a) 边集: ab bc ci cf fg gh cd de
总权 = 37
```

**对账的看点**：两法总权同为 37、都是 8 条边的连通生成树（示例用并查集
独立验证连通性），但**边集不同**——Kruskal 选了 ah(8)，Prim 选了 bc(8)。
这不是 bug：两者权相等时 MST **不唯一**，cut 性质只保证「某棵 MST 含
安全边」。判「合法 MST」的标准是总权与生成树性，不是逐边相同。

## 复杂度与选型

| 算法 | 时间 | 适合 |
|---|---|---|
| Kruskal | O(E lg E) | 稀疏图（E ≈ V）：排序便宜、并查集飞快 |
| Prim + 二叉堆 | O(E lg V) | 稠密图（E ≈ V²）：每个邻接只看一次 |
| Prim + 斐波那契堆 | O(E + V lg V) | 理论优化（第 20 章的摊还收益落地） |
| Borůvka | O(E lg V) | 并行/分布式（欧陆经典，思考题 23-3? 23-? 的原型） |

工程现实：网络布线、聚类（层次聚类的单链版本 = 逐步合并的 MST）、
图像分割（Felzenszwalb 的最小生成树分割）——MST 是「最便宜的连通性」
的代名词。

## 物以类聚：MST 边权序列上的分组阈值

**问题**：N 个对象各有两个整数属性 (a, b)，两对象的相似度（距离）为
曼哈顿距离 `|aᵢ−aⱼ| + |bᵢ−bⱼ|`。要把 N 个对象分成 K 组，使得组内每
个非唯一成员至少有一个伙伴与它的距离不超过 X。求满足条件的最小 X。

### 阈值视角：先想怎么「判定」，再想怎么「求最小」

给定阈值 X，只保留距离 ≤ X 的边。在这张图上：

- 任何大小 ≥ 2 的连通分量，其成员都有资格同组——沿路径每人都有一条
  ≤X 的邻接边（端点有路径上的邻居，内部点亦然）；
- 孤立点也没关系：它**自成一组**，题目对「组内唯一对象」无要求，条件
  真空成立。

所以「X 可行」⟺ 边 ≤X 的图至多有 K 个连通分量（把若干分量合并，组数
还能进一步减少，直到 K）。随着 X 增大，分量数只减不增——可行性单调，
求最小 X 就是找分量数首次 ≤K 的时刻。

### 归约到 MST：Kruskal 边序自带答案

对完全图跑 Kruskal：合并严格按边权升序发生。初始 N 个分量，每接受一条
边分量数减 1；使分量数**首次降到 K** 的那次合并，其边权就是最小阈值。

```cpp
for (const Edge& e : edges) {
    if (dsu.unite(e.u, e.v)) {
        if (--components == K) { return e.w; }
    }
}
```

等价地，把 MST 的 N−1 条边权排成升序，答案在 0 基下标 **N−K−1** 处：
要分成 K 组，需要从 MST 上「拆掉」K−1 条边（去掉最大的 K−1 条），组内
保留下来的最大边就是阈值。样例的 MST 边权为 1 1 2 2 2，N−K−1 = 3，
答案 2。

> 注意别把位置记成「第 K 条」：要降到 K 个分量需要 N−K 次合并，答案
> 是第 N−K 次合并（1 基）的边权，与 K 没有直接的下标关系。

### 对账：逐阈值 DSU 枚举

不做 MST 归约，也可以直接枚举所有不同边权 X，每次从空并查集重建边
≤X 的图、数分量，取第一个可行 X。它比 MST 法慢（O(E²)），但只依赖
「阈值 ⟹ 分量数」的原始定义，思路完全独立。示例对 1500 个随机案例
（N≤12）两法 0 例不一致。

### 与层次聚类的关系

这一节的算法就是**单链层次聚类**（single-linkage clustering）：两类之间
的距离定义为最近点对距离，聚类过程恰好是 Kruskal 合并过程；在第
N−K 次合并处切开树状图（dendrogram），得到 K 个单链簇。MST 是聚类
算法的隐藏骨架，不是巧合。

## C++23 语言点

- `std::ranges::sort(edges, {}, &Edge::w)`——投影排序按权升序，一行；
- 并查集内联复刻（第 22 章的 20 行模板随手带上）；
- 生成树合法性断言：n−1 条边 + 并查集全连通（示例 `is_spanning_tree`）。

## 与 STL 对照

无标准 MST 算法。Boost.Graph 的 `kruskal_minimum_spanning_tree` 与
`prim_minimum_spanning_tree` 是工业实现；对拍时注意其「平局打破」
规则与手写版不同（边序依赖）——对账用总权与生成树性，别比边集。

## 坑位清单

1. **转写边表抄错权重**
   （现象：MST 总权 35 而非 37，两算法「一致地错」；原因：c–d 与 c–f
   的 7/4 抄反——两算法共用同一张错表，互相对账发现不了；对策：总权
   与书上已知答案对（37），或第三条路（Borůvka）三角对账——本例实测
   翻车后修正。）
2. **断言两算法边集相同**
   （现象：MST 不唯一时 assert 挂——Prim 选 bc、Kruskal 选 ah；
   原因：平局时不同贪心走不同路；对策：对账「总权 + 生成树性」，
   边集只打印不比较（示例的写法）。）
3. **Kruskal 忘排序或排错键**
   （现象：弃边数暴涨或结果非最优；对策：sort 写进函数第一步，投影
   &Edge::w 明示。）
4. **Prim 的 key 初始化**
   （现象：多源点或源选错；原因：key[src]=0 其余 ∞，出队 n 次恰用
   n−1 条边——多初始化一个 0 就多长一条边；对策：出队循环 n 次 +
   树边数断言 = n−1（示例写法）。）
5. **图不连通还硬求 MST**
   （现象：Prim 扫描不到点 assert 失败 / Kruskal 树边 < n−1；对策：
   入口先 BFS 判连通，或对结果断言边数（Kruskal 天然兼容森林——
   「最小生成森林」）。）
6. **聚类阈值位置记成「MST 的第 K 条边」**
   （现象：K 较大时答案算成最小边，偏小；原因：降到 K 个分量需要
   N−K 次合并，答案是 0 基下标 N−K−1 处的边权（拆 K−1 条最大边），
   不是第 K 条；对策：代码直接以「--components == K」为停机条件，避免
   手算下标，并用逐阈值 DSU 重建对账。）
7. **阈值判定时漏掉孤立点也能成组**
   （现象：把「每人都要有 ≤X 伙伴」误读成硬性条件，X 偏大；原因：
   题目只对**非唯一成员**提要求，孤立分量自成一组条件真空成立——可行性
   判据是分量数 ≤K 而非「无孤立分量」；对策：判定函数只数 DSU 分量，
   不单独检查孤立点。）

## 练习

1. （CLRS 练习 23.1-1/23.1-3）cut 性质的交换论证补全；反例：割的
   **非最小**边不安全。
2. （CLRS 练习 23.2-1/23.2-2/23.2-3）Kruskal 在图 23.1 上的逐步运行
   （对账本例输出）；不同边序对 Kruskal 结果的影响（同一 MST 权）；
   稠密图下 Prim 数组版 O(V²) 的适用性。
3. （CLRS 练习 23.2-4）边权 ∈ [1, |V|] 整数域时 Kruskal 能到 O(E·α(V))
   （计数排序替代比较排序——第 8 章回收）。
4. （CLRS 练习 23.2-8）MST 唯一的充分条件（每条割边严格最小）。
5. （CLRS 思考题 23-1/23-2）次优 MST； bottleneck 生成树（最小化最大
   边权）比 MST 更容易——二分 + 连通性。
6. （本教程）给示例加 Borůvka 版（每分量同时选最小出边），三法总权
   对账；再构造一个 MST 不唯一的图（权相等的两条边互换）观察边集漂移。
7. （本教程）物以类聚：把相似度换成欧氏距离平方（注意整数范围），
   MST 法与逐阈值枚举仍应一致；再实现「全链聚类」（两类距离取最远点
   对）并说明它为什么不能像单链那样复用 Kruskal。
