# 37 · 数学背景速览与全书收束

> 对应 CLRS 附录 A–D（求和/集合等/计数与概率/矩阵，英文 3rd ed.
> pp.1165–1249）+ 全书总账。附录的数学在正文中已按需出场（求和在
> 第 3 章、鸽笼在第 11 章、期望在第 5 章、矩阵在第 29 章），本章把它们
> 系统化成一张速查网，并给全书一个「地图级」的收束。

## 学习目标

1. 熟记四大求和（算术/几何/调和/平方和）与积分界；
2. 会用鸽笼与计数做「存在性」论证；
3. 会验证概率恒等式与频率收敛（固定种子模拟）；
4. 能对照全书复杂度总表回顾 37 章的技术主线。

## 附录 A：求和（§37.1）

机器验证四大求和（示例 37.1，n=1000/10000）：

```
求和公式（n=1000，机器验证）：
  Σk = 500500 = n(n+1)/2 = 500500
  Σk² = 333833500 = n(n+1)(2n+1)/6 = 333833500
  Σ2^k (k=0..10) = 2047 = 2^11−1 = 2047
  H_10000 = 9.787606（ln 10000 + γ = 9.2103 + 0.5772 = 9.7875）
```

它们的正文足迹：Σk 是插入排序最坏情形（第 02 章）；几何级数是
「BFS 按层」与 vEB 的收敛（第 23/21 章）；调和级数是快排期望与并查集
摊还的常客（第 07/22 章）；平方和在方差计算里（第 05 章的 Var）。
积分界（Σf ≤ ∫f + 修正）是「换精确和为界」的标准工具。

## 附录 B/C：集合、计数与概率（§37.2–37.3）

**鸽笼原理**：n+1 个物品放进 n 个盒子必有一盒双份——散列表的碰撞
不可避免（第 11 章）、生日悖论 23 人（第 05 章）、决策树下界 ⌈lg n!⌉
（第 08 章）全是它。**计数**：排列 P(n,k)、组合 C(n,k)——「有多少个
输入形态」的度量（示例验证 C(10,3) = 120）。

**概率三公理 → 期望线性性 → 方差**（第 05 章已展开）。示例 37.3 的
频率验证：双骰和为 7 的概率 6/36 = 0.166667，固定种子 12 万次模拟
得 0.168167（±0.5% 内）——「理论值 ↔ 模拟值」的双轨对账是概率章的
标准动作。

## 附录 D：矩阵（§37.4）

## 收束：三条贯穿全书的暗线

1. **「分而治之」的形态学**：递归式 T(n) = aT(n/b) + f(n) 统摄归并
   （a=b=2）、快排（随机 a=1）、Strassen（a=7）、BFPRT（1/5+7/10）、
   FFT（a=2 但维度是「位」）——主定理是形态学的语法；
2. **「摊还」的世界观**：贵操作被历史存款买单——计数器的势能、vector
   的倍增、并查集的 α、斐波那契堆的懒整理——「平均地看」而不是
   「最坏地看」每个操作；
3. **「随机化」的三件用途**：打破输入最坏（快排/选择）、构造存在性
   （全域散列/Miller-Rabin）、近似计数——第 5 章的工具箱一路用到了
   第 36 章。

而工程侧的暗线只有一条：**证明给结构以信任，验证给实现以生命**——
37 章、111 个验证单元（37 示例 × 3 通道）、68 条实测坑位，全部由
机器对账背书。这既是本教程的方法论，也是它对 CLRS 的一点回馈。

## C++23 语言点

- 求和验证的整型溢出意识（Σk² 在 n=1000 时 3.3×10⁸——64 位安心；
  `1 << 11` 赋 long long 要写 `1LL <<`，本例实测翻车的 MSVC C4334）；
- `std::abs` 用于双精度（`<cstdlib>` 版是整数！——本例用的 `<cmath>`
  版）；
- 静态表格打印——收束章的「地图」用纯文本对齐（宽度列）。

## 与 STL 对照

`std::accumulate`/`std::reduce`（求和）、`std::midpoint`/`std::lerp`
（数值插值）——附录 A/D 的冰山一角在库里的样子。

## 坑位清单

1. **`1 << k` 赋给 64 位类型（本例实测翻车）**
   （现象：MSVC C4334 告警「32 位移位隐式转 64 位」；原因：字面量 1
   是 int，1 << 31 以上是 UB；对策：`1LL <<`——移位的第一纪律。）
2. **调和级数用 int 累加 1/k**
   （现象：全是 0（整数除法）；对策：1.0 / k；除法的两个操作数至少
   一个是浮点。）
3. **概率断言窗口小于随机波动**
   （现象：模拟断言偶发失败；原因：σ = √(p(1−p)/N)，窗口应 ≥ 3σ；
   对策：像示例一样 12 万次 ±0.5%（≈ 3.4σ）——第 05 章坑位的老朋友。）

4. （本教程）把复杂度总表按「输入形态」（比较/整数/图/多项式/几何）
   重排成自己的速查卡；挑 5 个「曾经不懂、现在懂了」的章写三句话
   总结。
