## C. 跨通道差异判据

- **`<print>` 链接（g++ 通道）**：scoop MinGW libstdc++ 15.2 缺
  `std::__open_terminal` 符号，一链接 `<print>` 必挂（designpattern 2026-09-28
  实测）；build.ps1 两级探针自动降级 `-DALGO_NO_PRINT`，示例顶部 8 行 IO 垫片兜底
  （`std::format` + `std::printf` 产出与 `std::println` 逐字节相同的 UTF-8）。
- **`uniform_int_distribution` 不可移植**：分布算法实现未规定，MSVC 与 libstdc++
  给出不同序列——跨通道逐字节对账必挂；一律自写 `rand_below(rng, n)`。
- **unordered 容器遍历序跨实现不同**：对账高压线；排序后再打印或改用 `std::map`。

## D. 高频算法速查（跨章通用）

**二分查找的三个语义**（04 章）：`lower_bound` = 第一个 ≥ x；`upper_bound`
= 第一个 > x；两者之差 = x 的出现次数。旋转数组找最小值（04 章）以**右端点**
为基准才能保证每轮严格收缩——以左端点或 mid 判定会在未旋转的数组上死循环。

**快速幂的三层**（15/32 章）：朴素连乘 n 次 → 快速幂 2⌈lg n⌉−1 次 →
矩阵快速幂 Θ(lg n) 次 3 算。注意**快速幂不改变溢出点**：`3^40` 用哪种算法
都装不下 long long，两种算法甚至给出**同一个**错误值（补码）。

**位运算核心恒等式**（32 章）：

| 恒等式 | 用途 | 边界坑 |
|---|---|---|
| `x & (x-1)` | 清最低的 1 | `x==0` 时结果为 0，不是「清掉了什么」 |
| `(x & (x-1)) == 0` | 判 2 的幂 | **对 x=0 也成立**，须加 `x > 0` 或用 `std::has_single_bit` |
| `x ^ (x >> 1)` | 格雷码（相邻差 1 位） | 无 |
| `n ^ (n-1)` | 循环变量 `i--` 的等价写法 | 无 |

**DP 三形态取舍**（15 章）：自底向上是首选（无调用开销、无栈溢出、缓存友好）；
记忆化的价值在**状态空间非线性或只有部分可达**时（省的是整个量级而非常数）。

**溢出探测的三种写法**（32 章，按可移植性排序）：

1. 除法预判 `|r| > mag / |base|`（不依赖 UB，也不依赖任何编译器扩展）；
2. 宽类型 `__int128` ——GCC/Clang 专属，**MSVC 没有**（C4235），三通道
   纪律下禁用；确需 128 位按编译器分档（`_mul128`/`_umul128` vs `__int128`）；
3. ~~先乘再看符号~~ ——**有符号溢出是 UB，编译器有权删掉检查分支**；
   ~~无符号回绕 `next < cur`~~ ——仅适用于单调递增量（如斐波那契）。

**交叉乘积超 int64 时的分数比较**（4 章）：除后比
`k ≤ ⌊1000·B/P⌋ = (B/P)*1000 + (B%P)*1000/P`——通用兜底；乘积恰在
(9.22e18, 1.84e19) 缝隙里时 unsigned 复核可用，但那是侥幸不是通解。

**int64 的负向多一位**：`[-2^63, 2^63−1]`，所以 `|INT64_MIN| = INT64_MAX+1`，
`abs(INT64_MIN)` 本身就是 UB。做边界判定时 API 要收「最大绝对值 mag」
而不是「整数上限」。

**倒序循环的统一写法**：`for (std::size_t i = n; i-- > 0;)`——起点写 `n`。
写成 `n-1` 会漏掉最后一个元素（后置递减在比较**之后**才执行，
循环体看到的第一个下标是 `n-2`）。全教程统一此写法（第 8 章稳定排序起）。

**按谓词分区**（07 章）：把 PARTITION 抽象成 `partition_by(span<T>, Pred)`，
快排 / `std::stable_partition` / 分类问题共用同一段循环骨架。它是**不稳定**
的——交换会把远处元素换到前面，要稳定须多开 Θ(n) 辅助数组。

**copy-and-swap**（01 章）：`operator=(T other) noexcept { swap }`。
按值收参 ⇒ 自赋值天然正确 + 整个函数 `noexcept`（vector 扩容能走搬移）。
代价是多一次拷贝（实测 `a = b` 恰好 1 次拷贝构造）。**不要再加
`operator=(const T&) = delete`**，会与按值版本构成歧义。

**防御性编程三形态**（01 章）——判断标准是「这个条件不成立时谁能修」：

- 程序员能修 → `assert`（契约，NDEBUG 下消失）；
- 调用方能修 → 异常或 `std::expected`（外部输入）；
- 不是错 → 返回值 / `optional`（二分「没找到」是**正常分支**，不是异常）。

## E. 本轮补充的坑位（剑指Offer 内容整合时实测）

69. `rebuild_naive`/`rebuild_fast` 的坐标系混用：递归里 `in` 已被切片，
    `pos` 却是**全局**中序下标，`p - lo` 混了两套坐标系 → 段错误。修法是
    把「窗口相对下标」与「全局下标」显式分成两个参数（12 章）。
70. `RebuildTree::make` 里 `push_back` 触发 vector 扩容 → 用 `.root` 下标
    在扩容后访问是 UB。修法：先取局部下标再 link，绝不在 `make` 之后用旧
    下标写容器（12 章）。
71. 子树判定的语义是「在 A 的**整棵树范围内**找 B」，需要一个从每个节点
    尝试的驱动函数；只写「从 x 出发递归比形状」的函数无法表达这个语义
    （12 章，实测三个断言连挂后重写）。
72. 链表原地归并：`merge_by_value` 收尾时误取 `b.head` 而非剩余指针 `y`，
    把已消费的节点又接了一遍 → 环。修法：只收指针，不收池（12→10 章）。
73. `NodePool::append` 从不设置 `head`，新表头恒为 NIL——「append 后链表
    长度为 0」的诡异现象源于此（10 章）。
74. 两栈队列的倒栈计数口径：统计的是**元素搬运次数**（n=4 时 4）而非
    倒栈轮次（2）。断言写 `== 2` 就挂——先把口径写进变量名（10 章）。
75. 旋转数组二分：`lo = mid` 在 `mid == lo` 时**不缩小区间** → 死循环。
    必须用右端点基准的严格收缩版本（04 章）。
76. `std::span<T>` 不能从 `vector<T>` **隐式**构造（范围构造是 explicit）；
    `partition_by(std::span<int>{nums}, ...)` 显式构造才通（07 章）。
77. format 串里的字面花括号：`{20,15,7}` 被当占位符 → 编译错。写
    `[20, 15, 7]` 或转义 `{{}}`（07/12 章实测）。
78. 树形注释行尾的 `\` 触发 gcc `-Wcomment`（"multi-line comment"）。
    heredoc/bash 里写反斜杠还会被吃掉——**统一用 Unicode 树形字符**
    （`└` `├` `─`），一劳永逸（12 章）。
79. `pow_checked` 的**平方步骤本身**会溢出：即使最终结果装得下，
    `a=-2, n=63` 时 base 会一路平方到 2^64。修法：预判 `base²` 超界就换成
    「绝对值大于 mag」的哨兵（32 章）。
80. `for (std::size_t i = d_.size() - 1; i-- > 0;)` 漏掉最高位 → `999+1`
    打成 `000`。后置递减的比较在自减之前，循环体看到的首个下标是 `size-2`
    （32 章实测）。
81. 局部 `constexpr` 在 lambda 里**仍需显式捕获**（只有 `static constexpr`
    / 枚举 / 字面量免捕获），而捕获常量会触发 `-Wunused-lambda-capture`
    ——谓词里直接写字面量最干净（07 章）。
82. 模板噪声里的签名不匹配被误判为缺头文件：rebuild 传的是
    `const vector&` 而函数要 `span<const>`；`int` 与 `size_t` 混比触发
    sign-compare（04/07 章）。
83. **小 n 验证通过的计数公式不代表对**：冒泡趟数 count(T=1) 的
    「Σi 组合」公式在 n=3 全对、n=4 就漏（真值 7，公式给 6）。正解
    T = max_i(i − f(i))，count(T=1) = 2^(n−1)−1；其余 T 无闭式，用穷举表
    （08 章）。
84. **最小交换代价的「借全局最小」分支漏记 +t**：方法二代价是
    s + t + (k+1)·a 不是 s + (k+1)·a——a 换进、归位各带一次轮换侧接触。
    t = a 的算例暴露不出；用「排列为节点、交换为带权边」的 Dijkstra
    暴力对账可揪出（08 章）。
85. **构造式数学法的方案族不完备**：找牛妞的六方案只允许从 2 的幂附近
    起飞，连自带样例 N=3, K=21 都答错（真值 5 = 走两步到 5 再连飞）。
    状态转移明确的问题先写 BFS 拿精确解，数学法拿 BFS 当裁判（23 章）。
86. **握手定理的奇偶只是必要条件**：度数和为偶的序列 {2,2,0,0} 仍可能
    不可图；要判定就上 Havel–Hakimi，输出措辞保持「Maybe」的语义
    （23 章）。
87. **x=0 的十进制位数是 1**：「以 0 结尾」⟺ mod 10 == 0，模数必须取 10；
    「m 乘十直到 m > x」的通用写法让 x=0 时 m 停在 1，答案变成「区间长度」。
    且对账的枚举版与公式版要**共享**同一个 modulus 函数，否则两版
    一起错、对账查不出（03 章）。
88. **模数 10¹⁹ 装不进 int64**：x 可达 10¹⁸（19 位）时 m = 10¹⁹ >
    INT64_MAX——升 unsigned long long（上限 1.84×10¹⁹）恰好装下；
    升档前先算清目标值域（03 章）。
89. **「尾段收尾」的两处边界**：骑士金币的尾段是「剩 n−days 天每天 k 枚」
    （k 已指向下一加段，别再 +1）；公交调度的兜底等待是 T − R（扫描前先设
    初值，找到更小再覆盖），到站即上车用 `prefix >= R` 不是 `>`（02 章）。
90. **「转换不前进」要直接比较，不要枚举参数族**：`(A−V)K ≤ A` 一个比较
    统一兜住 K=0、K=1（V=0 持平）、K≥2 但能量太低放大后仍亏（9,7,3 → 6<9）；
    只判 K=1 必漏（02 章）。
91. **「这一步达标」先预判再乘法**：(A−V)K ≥ N ⟺ A−V ≥ ⌈N/K⌉；命中直接
    返回，不命中时乘积 < N——全程无值超过 N，溢出从结构消失，不靠宽类型
    （02 章）。
92. **等差数列的 0 基起点是 L−1**：「坑 i 被占」写 `(i−1) mod I == L` 整体
    错位一格、一株种不上；统一写 `(i−L) mod I == 0` 避开基转换，并写两个
    独立实现对账（10 章）。
93. **`vector<bool>` 是代理容器不是 bool 数组**：元素是代理对象、取引用失败；
    位图优先 `vector<char>`，省内存时手写位图（10/11 章）。
94. **归并逆序记账记「左段剩余」mid−i**：右段元素先出列时只与左段**尚未
    出列**者成逆序；相等取左（相等不是逆序），全相等输入验收计数 0
    （04 章）。
95. **字母计数版先记账后自增**：计数器计的是「之前」的个数，顺序反了每个
    非首字符多算 1；T 只更新不累加（04 章）。
96. **Fenwick 下标必须 1 基，且上下行方向别反**：更新 `i += i&−i`、前缀
    `i -= i&−i`；0 基时 lowbit(0)=0 立刻死循环（14 章）。
97. **多维盒求和的 2ᵈ 个前缀要齐全**：三维八顶点，符号按「左端−1」个数
    奇偶；先验收整盒（只有一项为正）与贴边盒，再随机对账（14 章）。
98. **容量乘法全程 size_t**：s³ 用 int 连乘先溢出再转宽类型，数组分配过小；
    写 `std::size_t{s}*s*s`（14 章）。
99. **开机即处的 mode_0 不计重启**：x=0∨y=0 的任务开机先做完、不进边集；
    把首轮 mode_0 计数会系统性多 1（27 章，样例最优 2 非 3）。
100. **最大度贪婪点覆盖无最优性**：3×3 即有反例（最优 2、贪婪 3）；二部图
     最小点覆盖走 König——最大匹配即答案，Kuhn/Dinic（27 章）。
101. **Kuhn 访问数组用时间戳**：`seen[v]==token`，每轮搜索换 token，免反复
     清空；O(VE)（27 章）。
102. **取消资格的 −1 记在首个项目账上**：第二项目从未为他加过；学生记录存
     first_project，跨项目首现即撤回并标记（11 章）。
103. **题面升降序自相矛盾时以样例为准**：文字写升序、样例是人数降序+名字
     升序（11 章）。
104. **输入行分类只看首字符大小写**：项目名大写开头、学生 id 小写开头；
     含空格/数字等内容特征都不可靠（11 章）。
105. **`[qx]` 的 q 多位要循环累加**：`q=q·10+digit` 吃到非数字；只取一位则
     把后续数字/字母当普通内容（33 章）。
106. **q 个 x 用 append(q,x)**：`push_back(char(q))` 只追加一个乱码字符；
     dry-run 算总长 reserve（33 章）。
107. **逆向命中反转模式、不反转程序**：v 命中 text 逆向 ⟺ reverse(v) 命中
     text；只查本体会漏掉 FEEE→EEEF 尾部这类命中（33 章）。
108. **数字三角形滚动数组必须逆序更新**：j 从 i 往下扫——正序时 dp[j−1]
     已是本轮新值（同一行递推），等于允许同行横走（15 章）。
109. **数字三角形两端前驱缺失按 −∞**：j=0 只能来自正上、j=i 只能来自左上；
     漏判边界会读到 0 或旧值，负数权重样例必错（15 章）。
110. **三角形路径重构：choice 表与回溯方向一致**：记录「左上」者回溯时
     col−−；用暴力 2^(n−1) 条路径与备忘版三方对账（15 章）。
111. **渡河每轮两种送慢人策略取小**：最快者摆渡 2·a₀+a_{n−2}+a_{n−1}；慢人
     结伴 a₀+2·a₁+a_{n−1}。只用前者则 {1,2,5,10} 得 19 非 17；循环 n≥4，
     收尾：1 人 a₀、2 人 a₁、3 人 a₀+a₁+a₂（17 章）。
112. **树堆：根由优先级选、左右由标签划分**，两个不变式各管一维；递归划分
     O(n²)、栈深可达 n（n=50000 溢出），大数据用笛卡尔树单调栈 O(n)
     （13 章）。
113. **RPN 弹栈先 op2 后 op1**：`x N %` 必须算成 op1%op2；测周期用
     k − first[x]（环长），尾巴长度不计入，并以 Floyd 快慢指针 O(1) 空间
     对账（10 章）。
114. **取模前中间积不受 N 约束**：唯一 % 在末尾，N≤1.1·10⁶ 时三因子连乘
     约 1.3·10¹⁸ 装得下 unsigned long long，因子更多必须换大整数（10 章）。
115. **聚类阈值在 Kruskal 合并序上定位**：--components==K 的接受边权即答案
     （MST 边 0 基下标 N−K−1，不是「第 K 条」）；孤立点自成一组、条件真空
     成立——判据是分量数 ≤K，不查孤立点；逐阈值 DSU 重建对账（24 章）。
116. **二部图最大独立集只有 α=n−ν 是正解**：「二染色后分量取大」给出的
     只是可行独立集，较小侧满足 Hall 条件时才最优；连通反例（左 4 右 3、
     ν=2）取大 4 而 α=5。随机 2000 例取大法 26 例偏小（27 章）。
117. **无向图邻接表必须两个方向都入表**：只存单向弧时 BFS 把两端染成
     同色，按颜色分左右部产生越界下标，Kuhn 在 seen[v] 处 0xC0000005；
     建表两行成对写（27 章）。
118. **对称排序先写下标模式再写码**：输出原下标 0,2,4,…,…,5,3,1；「放
     首部」不是 push_front（后对要排在先对后面）；奇数下标段起点用有符号
     int（n 奇 n−2、n=1 得 −1），size_t 回绕死循环（02 章）。
119. **反转数相加是三个动作**：各自反转、相加、和**再反转**（漏末步
     24/1 得 43 非 34）；长位数走数字串右端对齐列加法，反转串开头的 0
     是已丢弃的尾零、不作有效列（否则 10+60 得 70）（10 章）。
120. **浏览器前后翻页 = 两栈 + 当前页**：当前页不属于任何栈；BACK/
     FORWARD 先推当前页入目标栈、再从来源栈弹新页；VISIT 必须清空
     forward（历史分叉）；来源栈空时命令**整体无副作用**、输出
     Ignored（10 章）。
121. **「三方独占」走节点拆点流**：s→食物(1)→牛妞_in→牛妞_out(1)→
     饮料(1)→t；食物↔饮料直接匹配会把同一牛妞计两次（1 牛妞 2 食物
     2 饮料：匹配 2、正解 1）；顶点容量 gadget 通用：v_in→v_out 容量
     = c(v)（27 章）。
122. **树上覆盖目标点：答案 = 2W − 最远目标距离**：W 是连接 k 与全部
     目标的最小子树边权和；以 k 根树、逆序传播 needed、needed 的父边
     才计入；终点必为目标；「每次去最近目标」非最优（样例 9 对 8）
     （23 章）。
123. **枚举全体拓扑序判据是「pre[v] ⊆ used」**：位掩码回溯、候选升序
     ⟹ 字典序；「直接计数位置区间 + 只查重复」会吐 acbd 违反 b<c；
     即使算全传递闭包，区间仍允许 adbc 违反 b<d——区间只能当剪枝
     （23 章）。
124. **任意进制转换以数字串中转**：B1→十进制走 Horner（v=v·B1+digit），
     十进制→B2 走反复长除、首个余数是**低位**（必须反序）；0 显式
     返回"0"；输入剥前导零、商串首位 0 不输出；40 位数绝不可塞进
     内置整数（32 章）。
125. **石子合并区间 DP**：`mn[i][j]=min_k(mn[i][k]+mn[k+1][j])+w(i,j)`，
     最后合龙必加区间总和（n=2 漏加得 0）；圆环把数组拼到 2n−1、扫
     n 个长 n 窗口（整段取答案会重用同一堆）；最大端点性质
     `mx=max(mx[i][j−1],mx[i+1][j])+w` 只对最大成立，最小别用；
     「最小相邻先合」贪心有反例（16 章）。
126. **两机流水车间 Johnson 规则**：N1={a<b} 按 a 升序在前、N2={a≥b}
     按 b **降序**在后（N2 升序必错）；仿真 `f1+=aᵢ; f2=max(f1,f2)+bᵢ`
     （漏 max 系统性偏小）；相邻判据 min(aᵢ,bⱼ)≤min(aⱼ,bᵢ)，单一
     排序键表达不了；三机车间不可套用；下界 max(Σa,Σb)（17 章）。
127. **网格布线 = 格为点、四邻权 1 的 BFS**：−2 封锁/−1 未访/≥0 距离；
     (m+2)×(n+2) 围墙全标 −2 消灭边界判断，真实格带 (+1,+1) 偏移；
     逆向重建只认「恰小 1」邻居（"更小"会踩 −1/−2）；不可达返回空；
     DFS 首达路径不最短；对账走 Floyd-Warshall（23 章）。
128. **最小费用最大流逐次最短路**：加边成对 cost/−cost（反向边退钱，
     写成 0/+cost 无法改道）；残量有负边 ⟹ SPFA 或势函数 Dijkstra；
     每轮增广瓶颈 d，`cost += d·dist[t]`；原图含负费边要先消负环；
     改道例：第 2 单位走反向边、单位费用 103（27 章）。
129. **方格取数 = 二部图最大权独立集**：(x+y) 染色，s→黑/白→t 容量
     =权值，黑→相邻白 ∞=total+1（∞ 不够大割会切冲突边）；答案
     total−maxflow；还原：黑**可达**入选、白**不可达**入选（白向反了
     选出相邻格）；无权才退化成 n−匹配；一般图不成立（27 章）。
130. **汉诺塔递归与非递归**：T(n)=2T(n−1)+1 ⟹ 2ⁿ−1（long long 计数）；
     非递归第 i 步搬 `ctz(i)+1` 号盘（i=2ᵏ·奇数搬 k+1），盘 d 沿固定
     循环移动——n+d 偶：0→2→1→0，奇：0→1→2→0；n 奇偶翻转所有方向；
     递归版逐步对账 n=1..16（04 章）。
131. **二维极点分治**：严格支配（x、y 都严格），同点/同 x 互不支配；
