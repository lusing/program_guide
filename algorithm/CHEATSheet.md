## B. C++23 语言/库坑位

（逐批登记，四段式详见各章「坑位清单」，此处是速查摘要。）

01–04 章批次（8 条）：

1. `std::ranges::sort` 报「不是 std::ranges 的成员」——算法在 `<algorithm>`，
   `<ranges>` 只有视图（01 章，三通道齐红实测）。
2. libstdc++ 特性宏拆散在各头文件，`<algorithm>` 只带自己的宏；探测前必须
   `#include <version>`（01 章，msvc=1/gcc=0 假象）。
3. MinGW libstdc++ 15.2 链接 `<print>` 必挂（缺 `std::__open_terminal`）——
   两级探针 + `-DALGO_NO_PRINT` + IO 垫片（01 章；垫片用 `std::format`+
   `printf`，字节流与 `std::print` 一致）。
4. 特性宏「数值」跨库不同（`__cpp_lib_ranges_zip` 202207 vs 202110）——
   探测表只打 0/1 布尔（01 章）。
5. 无符号 `assert(n > 0)` 触发 gcc `-Wextra`（-Wtype-limits）——写 `n != 0`
   （01 章）。
6. `std::size_t` 下标回绕：边界检查必须前置（`i > 0 && a[i-1] > key`），
   且比较计数放 `&&` 右侧防短路漏计（02 章）。
7. `std::log/pow` 尾数跨标准库可异——分析实验全整数运算，⌊lg n⌋ 用
   `bit_width(n)-1`（03 章）。
8. Strassen 公式手抄错号（C22 的 −P7 写进括号变成 +P7）——与朴素乘法
   `assert(mat_eq(...))` 对账，第一次运行就抓住（04 章，真实翻车实录）。

05–07 章批次（5 条）：

9. `vector` 没有 `.first()`——span 系切片要 `std::span{a}.first(n)`（07 章，
   gcc 先报、msvc 后报，断言语义错误连带暴露）。
10. 断言「分区后左段有序」——PARTITION 只保证 max(左段) ≤ 主元 ≤ min(右段)，
    左段 [2,1,3] 无序是设计内（07 章，真实翻车实录）。
11. 洗牌方向写反（`RANDOM(1,n)` 全范围）造成 4:5 两档偏倚——n=3 时 27 条
    等概率路径不均匀映射到 6 排列（05 章，270000 次实测）。
12. 「期望对数」≠「至少一次概率」：生日悖论用 C(k,2)/365≥1 推出 28 人，
    精确乘积才是 23（05 章）。
13. 重复元素场景两路分区退化：全相等数组 n(n−1)/2、三值域数组劣化 500 倍，
    三路分区一次切平（07 章）。

08–10 章批次（6 条）：

14. 副作用表达式别进 println 实参——`println("{}", s.pop(), s.pop())` 在
    MSVC/clang 从右往左求值，输出反序且三通道一致（对账抓不住）（10 章，
    实测翻车）。
15. `//` 注释行尾反斜杠触发 gcc `-Wcomment`（续行吞掉下一行）——ASCII 树
    注释的 `/  \` 行尾踩雷（10 章，实测翻车）。
16. 成对 min-max 公式奇偶有别：n 偶 3n/2−2、n 奇 3(n−1)/2，统一界才是
    3⌊n/2⌋（09 章，断言实测抓出）。
17. 计数排序正序落位会静默丢稳定性——必须倒序（08 章）；基数排序每趟
    必须稳定，LSD 的归纳前提。
18. ⌈lg m⌉ = bit_width(m−1)（08 章下界表用它精确取整）。
19. BFPRT 组大小 5 的由来：1/5 + 7/10 < 1 才收敛，组取 3 恰卡死在 1
    （09 章）。

11–13 章批次（5 条）：

20. 二次探查要全覆盖需 m ≡ 3 (mod 4)——m=101 装到 α>0.5 就「假满」，
    换 103（11 章，推演时抓住）。
21. 红黑树删除漏写 CLRS 的 `x.p = y`（哨兵之父）——手造用例全绿、
    随机压力数千步后黑高断裂；连「看似多余的行」一起抄（13 章，
    实测翻车，经典中的经典）。
22. 开地址删除直接置空会截断探查序列——要 DELETED 哨兵或改链址
    （11 章）。
23. BST 删除双子节点用「键值覆盖」会让外部句柄悬空——用 TRANSPLANT
    节点顶替（12 章）。
24. 有序输入实测：n=255 时 BST 高 255（链）vs 红黑树高 14（界 16）
    （13 章）。

14–15 章批次（4 条）：

25. 表驱动数据的规模要随表断言——CLRS 价格表只到 10，demo 用 n=15
    越界（15 章，实测翻车后压回 {8,10}）。
26. 区间树的中序键是 lo、hi 只进 max——按 hi 组织则左优先论证失效
    （14 章）。
27. 扩张字段的维护必须局部化（只依赖直接孩子），否则底座代价被破坏
    （14 章，定理 14.1 检核）。
28. 填表顺序 = 子问题图的拓扑序——矩阵链必须按链长递增；「值表+决策表」
    双表才能重构最优解（15 章）。

## C. 跨通道差异判据

- **`<print>` 链接（g++ 通道）**：scoop MinGW libstdc++ 15.2 缺
  `std::__open_terminal` 符号，一链接 `<print>` 必挂（designpattern 2026-09-28
  实测）；build.ps1 两级探针自动降级 `-DALGO_NO_PRINT`，示例顶部 8 行 IO 垫片兜底
  （`std::format` + `std::printf` 产出与 `std::println` 逐字节相同的 UTF-8）。
- **`uniform_int_distribution` 不可移植**：分布算法实现未规定，MSVC 与 libstdc++
  给出不同序列——跨通道逐字节对账必挂；一律自写 `rand_below(rng, n)`。
- **unordered 容器遍历序跨实现不同**：对账高压线；排序后再打印或改用 `std::map`。

16–17 章批次（3 条）：

29. 「替换代价 1 的编辑距离 = m+n−2·LCS」不成立——恒等式只在替换
    代价 ≥ 2（等价只插删）时成立，subCost 参数化后用 2 验证（16 章，
    首版断言实测翻车）。
30. ranges::sort 投影默认升序——降序必须显式 `std::ranges::greater{}`
    （17 章，拟阵贪心选反实测）。
31. 贪心正确性是定理不是直觉：活动选择只有「最早结束」对（最早开始/
    最短时长/最少冲突均有反例）；小规模 DP 对账是最便宜的验证（17 章）。

18–20 章批次（5 条）：

32. 存值不存指针：extract 后要读「刚删节点」的 id 就把 id 先取出来——
    `lastDeleted = z; delete z;` 再读 ->id 是 use-after-free（20 章，
    三通道齐崩 0xC0000005 实测）。
33. 动态表收缩阈值 1/2 抖动 vs 1/4：同负载 25600 vs 64 次拷贝，400 倍
    （18 章实测）。
34. 二进制计数器势能法 Φ=1 的个数：每次自增摊还恰为 2，与翻转位数无关
    （18 章，16 次全验）。
35. 斐波那契堆降键负载要「大幅降」才触发 cut——小步递减几乎不违反
    堆序，级联剪切不发生（20 章实测）；decrease-key 必须 assert 新≤旧。
36. consolidate 度数数组按 1.44·lg n 开（φ 系数），按 lg n 开恰好越界
    （20 章）。

21–23 章批次（6 条）：

37. `__builtin_ctz` 不可移植（MSVC 无）——用 `std::countr_zero`/`bit_width`
    （21 章，实测翻车）。
38. vEB 的「min 不入簇」不变式——双表示会让 successor 漂移；空簇置位
    时别忘 summary.insert(c)（21 章）。
39. 并查集对抗负载要构造链式合并序列（(i,0) 级联）——纯随机 union
    测不出朴素 vs 按秩的差距（22 章，实测翻车后重设负载）。
40. 摊还账本要算总账：路径压缩的第二趟遍历也必须计数（22 章）。
41. 转写图的边集用握手定理断言 Σdeg=2|E| + 距离场逐点 assert——漏边
    会让后续全歪（23 章，漏 s–v 实测翻车）。
42. 无向 DFS 边分类的两个坑：树边反向弧（回父）跳过、后向边另一侧的
    黑色相遇去重——否则后向边数翻倍、环检测误报（23 章）。

24–26 章批次（5 条）：

43. 边表转写抄错权重（c–d/c–f 的 7/4 互换）——两算法共用同一错表
    互相发现不了，对账要引第三真值（书上答案 37）（24 章实测翻车）。
44. MST 不唯一时别断言两算法边集相同——对账「总权 + 生成树性」，
    Kruskal 选 ah(8) vs Prim 选 bc(8) 合法并存（24 章）。
45. INF + 负权的溢出伪松弛：INT_MAX 当 INF 直接加 −4 回绕下穿 INF，
    松前必须卫哨 d==INF / d[i][k]≥INF（25/26 章，FW 的 D^(1)=999996
    实测翻车）。
46. Dijkstra 的 lazy 删除过期判断用严格大于（du > d[u]）——du == d[u]
    是有效条目；出队序应严格非降（25 章）。
47. BF 三段式：V−1 轮松弛 + 单独一轮检测；松弛轮多跑一轮会把检测
    混进松弛、无负环也误报（25 章）。

27–28 章批次（5 条）：

48. 教材图数据在 PDF 里是图像不是文本——照记忆抄容量矩阵必错；改用
    手算可验的自造网络并在文档注明（27 章实测翻车）。
49. 流的反对称要成对维护：f[u][v] += d 必须伴随 f[v][u] −= d——反悔
    额度（残量反向边）建在这上面（27 章）。
50. 最小割的 S 集要在残量网络（含反向边）上算，用原容量图算出的割
    容量会大于最大流（27 章）。
51. `<span>` 忘显式包含：gcc 传递包含侥幸过、MSVC/clang 红线——三通道
    一致性才能暴露（28 章实测翻车）。
52. 并行输出纪律：按完成序打印 = 对账必炸；结果按索引回收、汇合后
    主线程统一打印；共享计数用 atomic 或按线程分槽（28 章）。

29–31 章批次（6 条）：

53. LUP 行交换时 L 的已算乘数必须跟着换行——分离存储实现必踩（29 章，
    重积断言实测抓出）。
54. 单纯形进基判据看符号约定：目标行存 z−Σcx 时**负系数**才是改进方向
    （30 章实测翻车）；最小比值只对 a>0 的行做。
55. FFT 正逆变换的 sign 约定钉死（CLRS 用 e^{+2πi/n}）——弄反则 DFT 全
    共轭，小例手算对账一抓一个准（31 章实测翻车）。
56. FFT 卷积结果带 ±1e-9 噪声：进位必须 llround（截断会把 9.9999996
    吃成 9），最高位 ≥10 要扩容（31 章实测翻车）。
57. `vector<double>(str.rbegin(), str.rend())` 存的是字符码 '9'=57——
    必须减 '0'（31 章实测翻车）。
58. 递归 FFT 要求长度为 2 的幂：调用前补零到 2^k（31 章）。

32–33 章批次（6 条）：

59. φ(n) = (p−1)(q−1) 现场计算别手抄——3120 抄成 3220 逆元断言必挂
    （32 章实测翻车）。
60. Miller-Rabin 的试除捷径会吃掉见证检验——基列表若含 n 的因子，
    提前返回「合数」但演示路径没走平方根检查（32 章实测翻车）。
61. 模乘安全域：n² < 2⁶³ 才能直接 long long——n > 3×10⁹ 需 __int128
    （MSVC 无）或乘法拆分（32 章）。
62. format 字面花括号要 {{}}——数学文案 m^{ed} 编译即炸（32 章实测）。
63. Carmichael 数 561 骗过全部 Fermat 测试（7^560≡1 mod 561 实测）——
    Miller-Rabin 的平方根检查才拆穿（32 章）。
64. KMP 的「π 含哨兵」与「next 数组」两种约定差一位——混用必死循环；
    先手推 ababac 的全表再上机；RK 滚动更新先 +q 防负（33 章）。

34–35 章批次（4 条）：

65. 几何全程整数坐标——叉积/距离平方精确无误差；浮点几何的 cross==0
    要 epsilon，且 ε 随坐标量级调整（34 章）。
66. char 布尔值直接进 format 打成控制字符（0/1 是 ASCII 控制符）——

67. Graham 极角排序用叉积比较器而非 atan2——共线组按距离排序并配

68. 归约方向学：证 Y 难须「难者来」——已知 NPC 问题归约到 Y；把 Y
    归约到 X 什么也没证明（35 章）。
