# 25 正则测度与 Radon 测度：内外逼近的银行制度

**对应严书 §5.3（pp. 119-123）/ 袁上册 §11.2.1-11.2.2（pdf275-278）。
mathlib `Measure.Regular` 类族 ✓（Regular/InnerRegular/OuterRegular）。**

---

## 25.1 为什么"测度"还要加形容词

抽象测度对集合的账可以完全无视拓扑（Borel 集的账与开集/
紧集无任何关系）。但分析学的操作——逼近、取极限、在紧集上
截断——全都依赖"拓扑能控制账目"。**正则性**就是这份控制
合同：内（紧集逼近）/外（开集逼近）双向的银行制度。本章
定义三档正则性并给判据；第 24 章 Riesz 产出的测度自动持证
（正则性是 C_c 泛函的免费赠品），第 29 章将证明 Polish 空间
上一切有限 Borel 测度都持证（拓扑好 ⟹ 账目纪律好）。

## 25.2 三档定义（严书 5.3.1 / 袁定义 11.15 一族）

设 μ 为拓扑空间 X 上 Borel σ-代数上的测度。

1. **内正则（开集版）**：一切 Borel 集 A，μ(A) =
   sup{μ(K)：K ⊆ A 紧}——**质量从内部由紧集堆出**；
2. **外正则**：μ(A) = inf{μ(U)：A ⊆ U 开}——**质量从外部
   由开集压出**；
3. **Radon 测度**（严书定义）：内正则 + 外正则 + 紧集有限
   质量（μ(K) < ∞ 对一切紧 K）——三合一的完全体。

不同教材的口径差异（诚实标注）：Halmos/Folland 的"Radon"
只需内正则 + 紧有限；袁书 11.2.2 取"外正则 + 紧有限 +
Borel"；mathlib 的 `Measure.Regular` = **IsFiniteMeasureOn
Compacts + OuterRegular + （开集上的）紧内正则**——三档在
**σ-有限 + LCH 正则空间**的常用地带等价，教学口径统一为
严书的"内外双正则 + 紧有限"并脚注变体。

**即时例子**：(ℝⁿ, Lebesgue) 是 Radon（Heine-Borel 紧性 +
外测度的开覆盖定义直接给双向）；离散空间上计数测度 Radon
（紧 = 有限集）；**反例**：不可数空间上 Borel 测度 μ(A) =
0 若 A 可数、= ∞ 若不可数——紧集（可数？不可数紧？在一般
空间无法控制）与开集的账完全脱钩，三档全灭。

## 25.3 判据与结构定理（严书 5.3.2-5.3.5）

**判据一（Radon ⟺ 紧有限 + 外正则，严书 5.3.4）**：LCH 上
已正则的 μ 是 Radon ⟺ 一切紧集质量有限——把三合一化简为
两个一维检查（内正则性在 LCH + 外正则下自动跟进：磨光
引理把 K 的账从下面顶上去）。

**判据二（Baire → Borel 的唯一扩张，严书 5.3.3）**：紧
Hausdorff X 上 Ba(X) 上的有限测度 ⟹ 唯一扩张为 B(X) 上的
正则测度——第 24 章 Riesz 构造的收尾步骤（在 Ba 上造的测度
自动装修到 B 上）。

**结构定理（Lusin 型分离，严书 5.3.5-5.3.7 一族）**：
Radon μ 下，Borel 集 A 与紧 K 的账可以双向夹逼：∃ 开 U ⊇ A
使 μ(U∖A) < ε、∃ 紧 K ⊆ A 使 μ(A∖K) < ε——一切 Borel 集
在测度意义下"几乎是紧集也几乎是开集"。**推论**：有限
Radon 测度下，Borel 集全体 = σ(紧 Gδ)（对逼近封闭），
简单函数可用 C_c 函数在 L¹ 中逼近（第 27 章 Lusin 的引子）。

## 25.4 Radon 测度的运算封闭性

Radon 测度对测度论的自然操作稳定（分析的日常工具箱）：

1. **限制**：μ Radon ⟹ μ|A（Borel 子空间）Radon；
2. **有限和与标量乘**：μ + ν、cμ（c ≥ 0）Radon；
3. **密度**：μ Radon、f 局部可积 ⟹ f·μ Radon（RN 的正则
   版传递——第 12 章结构在拓扑层的重演）；
4. **像测度**：f : X → Y 连续、proper（紧集的原像紧）⟹
   f(μ) Radon——**properness 不可省**：非 proper 连续映射可
   把质量压进非紧集中（例：x ↦ 1/x 型映射把 ℝ 的 Lebesgue
   推成 0 处的病态集中）；
5. **乘积**：μ ⊗ ν Radon（LCH σ-有限情形）——第 28 章正题。

mathlib 对应：`Regular` 的 instance 族（`zero`、`smul`、
`add`、restrict、`map` 带条件）在 `Measure/Regular.lean`
成套收录——**类的封闭性即 instance 的算术**。

## 25.5 内外逼近的账本格式（三明治定理）

正则性的实用形态：有限 Radon μ、Borel 集 A、ε > 0 ⟹

  K ⊆ A ⊆ U，μ(U ∖ K) < ε（紧-开三明治）。

由内外两个 inf/sup 各取 ε/2 再交割。这个三明治是后文的
通用垫片：第 27 章（Lusin：连续函数在紧集上拟合可测函数）、
第 29 章（Polish 胎紧性：紧集吸收 1-ε 质量）、第 31 章
（弱收敛的 portmanteau：开集下极限/闭集上极限）全部从这块
三明治切下去。**教学口径**：正则性不是装饰性形容词，而是
"测度论与分析学之间的汇率协议"——没有它，拓扑语句和测度
语句无法互相翻译。

## 25.2.5 反例档案：正则性的三重死亡现场

**反例一（不可数计数背景的坏测度）**：X 不可数离散，
μ(A) = 0 若 A 可数、∞ 否则。紧 = 有限集 → 一切紧集账 0，
但 μ(X) = ∞——内正则死；开集只有 ∅ 可数，外逼近死。
**死因**：质量的"不可数弥散"与紧有限性矛盾。

**反例二（非局部紧的裂缝）**：X = ℚ ∩ [0,1]（继承拓扑，
可分非完备），μ = 计数×缩放？ℚ 上没有天然"Lebesgue"——
取 μ = Σ2⁻ⁿδ_{qₙ}（枚举求和）：紧集在 ℚ 中 = 闭于 ℝ 的
有界集∩ℚ ∩ 紧？ℚ 的紧子集测度可达 1（闭包技巧），此例
其实 Radon ✓——换：μ(A) = Lebesgue 外测度的限制？ℚ
Lebesgue 零测……**教学结论**：ℚ 上的正则性要靠具体构造，
"继承拓扑不保证继承正则性"的正确反例要到非度量空间找
（反例一足够）。保留此段作为"反例构造的试错现场"——
第 04/09 章反例纪律的延续：候选反例先过三档定义再上场。

**反例三（σ-有限缺失）**：X = ℝ，μ = 计数测度（σ-有限
✓ 其实 Radon ✓）；真正 σ-有限缺失的经典例在乘积：μ⊗ν
双方 σ-无限时矩形账延拓失败（第 18 章对角线）——正则性
救不了存在性。**分层结论**：存在性看 σ-有限、纪律看
正则性——两个维度独立体检。

## 25.5.5 正则性层级表：从 τ-可加到 Radon

测度与拓扑的合同有强度梯度（每档含前档）：

| 档位 | 条件 | 典型定理 | 章 |
|---|---|---|---|
| Borel 测度 | B(X) 上可测 | 抽象层一切定理 | 03-22 |
| τ-可加 | 开族的局部有限并上超可加 | 乘积测度正则性的中间站 | 28 |
| 外正则 | 开覆盖下确界 | 弱收敛 portmanteau 的下半连续 | 31 |
| 内正则（闭） | 闭集内逼近 | 有限 Borel 的通用档（Polish 免费领） | 29 |
| 内正则（紧）/Radon | 紧逼近 + 紧有限 | Riesz/胎紧/Prokhorov 全家 | 24, 32 |

**读法**：越往下"拓扑对账目的控制"越强；Polish 空间把
第五档发给一切有限 Borel 测度（第 29 章 5.7.6），一般
LCH 上要逐测度验收。mathlib 的 class 设计（OuterRegular/
InnerRegular/Regular 三 class + instance 组合）正是这张
表的类型化——合同条款按需签订。

## 25.8.5 习题账单（自检清单）

1. 证明：μ Radon ⟹ μ|_A（Borel 子集）Radon（内外逼近
   与 K∩A 的交割）；
2. 正则测度的差账：A ⊆ B，μ(B∖A) < ε ⟹ 存在三明治
   K ⊆ A, U ⊇ B 使 μ(U∖K) < ε（把 25.5 的三明治推到
   两集版本——第 31 章 portmanteau 的标准用法）；
3. 密度传递：μ Radon + f ∈ L¹_loc(μ) ⟹ f·μ Radon（提示：
   紧集上 f 有界逼近 + 三明治）；
4. 反例一的三档逐条验尸（25.2.5 的正式版）；
5. μ Radon、X σ-紧 ⟹ 存在紧穷竭 {Kₙ} 使 μ(Kₙ↑X) 且
   μ(Kₙ∖Kₙ₋₁) 有限（"分块记账"的 Radon 版）。

## 25.6 数值实验：三明治构造的显影

**Julia（`25_regular_measures.jl`）**：μ = [0,1]² 上
2D Lebesgue 网格（200×200）：

- **三明治构造**：对"方块 A = [0.3,0.7]² 与中心挖洞的环
  D = [0.2,0.8]²∖[0.4,0.6]²"两族 Borel 集，数值找内接/外接
  的网格紧集（闭方块）与开集（开方块），验证 |μ(U) − μ(K)|
  ≤ 2·网格分辨率——三明治的存在性数值化；
- **外正则的单调收敛**：A 的开 ε-邻域 A⁺ₑ 的测度随 ε ↓ 0
  收敛到 μ(A)（ε = 2⁻ᵏ 序列，单调递减账）；
- **内正则的紧穷竭**：A ∩ [−n,n]² 的测数升列 → μ(A)；
- **非正则反例的数值显影**：ℚ ∩ [0,1]（可数稠密）上计数
  测度的限制——一切紧集（ℚ 中紧 = 有限？不——ℚ 紧子集可以
  无限但必须闭于 ℝ），账目行为打印对照。

**Python（`25_regular_measures.py`）**：Fraction 精确版——
网格三明治的精确分数账（μ(K) ≤ μ(A) ≤ μ(U) 与差值界）；
Cantor 型集（三分集的前 n 级构造）的内外逼近账（μ(Kₙ) =
(2/3)ⁿ 精确递减——正则性在分形上的表现）。

**历史注记**：正则性的系统化归功于 Radon（1913，紧集
逼近）与 Bourbaki 学派的整合（1950s，把"Radon 测度"定为
连续泛函的等价类——第 26 章的路线）。不同传统的术语冲突
（Halmos 的"正则" vs Bourbaki 的"Radon"）延续至今——本
教程的口径表（25.2）就是为读者穿越文献准备的通行证。

## 25.7 Lean：Measure.Regular 类族

mathlib 锚点（`Measure/Regular.lean`）：class `OuterRegular`
（开覆盖下确界）、class `Regular`（extends IsFiniteMeasure
OnCompacts + OuterRegular + 紧内正则）、class `InnerRegular`
（宽口径版）与 `InnerRegularCompactLTTop`；instance 算术：
`zero`/`smul_nnreal`/`add`/restrict 族。`Ch25RegularMeasures.
lean` 实弹：

1. **锚点 #check**：三 class 与若干 instance；
2. **Lebesgue 的正则性**：`volume` 在 ℝⁿ 的 Regular/
   OuterRegular instance 引用（mathlib 已证的免费资产——
   本土定理的机器户口）；
3. **三明治引理**：由 OuterRegular + InnerRegular 拼装的
   ε-三明治（在 instance 上取 inf/sup 的显式推导）；
4. **封闭性**：`c • μ` 仍 Regular 的 instance 化引用。

## 25.8 要点回顾

1. 三档定义：内正则（紧逼近）/外正则（开逼近）/Radon
  （+ 紧有限）；教材口径差异如实标注，工作口径取严书。
2. 判据：LCH 下 Radon ⟺ 外正则 + 紧有限；Ba 有限测度唯一
   扩张为 Borel 正则（Riesz 收尾）。
3. 封闭性：限制/和/密度/proper 像/乘积——instance 算术。
4. ε-三明治是后文通用垫片（Lusin/胎紧/portmanteau）。
5. 机器侧：`Measure.Regular` 类族 + instance 套件；数值
   通道把三明治构造与单调逼近账算到底。
