# 第 54 章 普遍极限定理（袁 ch23）

50-52 章的三部曲（WLLN/SLLN/CLT）各自回答一个具体问题。本章问
**元问题**：行态独立的三角阵列 {X_{n,k}}，部分和 Sₙ = ΣₖX_{n,k}
经仿射正规化 (Sₙ−aₙ)/bₙ 之后，一切可能的非退化极限是什么？
答案就是本章的标题——**普遍极限定理**（Khinchin-Feller-
Gnedenko-Kolmogorov 学派的纲领性成果）：极限族恰是 53 章的
无穷可分分布全体 D。52 章的正态、23 章的 Poisson 只是 D 中
两个成员的收编条款。

## 54.1 阵列语言：为什么必须是三角阵列

**定义 54.A（袁 23.1）**。{X_{n,k}：1 ≤ k ≤ kₙ, n ≥ 1}，
kₙ → ∞：每行内部独立、EX_{n,k}² < ∞。部分和 Sₙ = Σ_{k≤kₙ}
X_{n,k}。**普遍极限问题**：求一切可能的极限
(Sₙ−aₙ)/bₙ →ᵈ Y（Y 非退化，bₙ > 0）。

iid 部分和是其特例（X_{n,k} = X_k 不随 n 变）——但 CLT 的
实际应用（加权和、核估计、随机游动嵌入）几乎全是真三角阵列
（第 k 项的分布随 n 缩放）。**阵列是独立和理论的正确坐标：
正规化吸收进阵列**（X_{n,k} = X_k/bₙ），从此"选 aₙ, bₙ"
变成"选阵列"——一个对象，不再两个。

## 54.2 无穷小条件：单项贡献的一致消失（袁 23.3.1）

**定义 54.B**。阵列**无穷小**（infinitesimal）：
∀ε>0，limₙ max_{k≤kₙ} P{|X_{n,k}| > ε} = 0——任一单项
都渐近地小于任何固定尺度。

这是"许多小原因"的数学化。**没有它，极限理论退化为平凡**：
例如 kₙ = 1（单行单元素），Sₙ/bₙ 可以收敛到任何东西（极限
分布本来就是任意的）。习题 23.5 给出最常用的充分条件：
EX_{n,k}² ≤ c 且 kₙ·max_k EX_{n,k}² → 0 ⟹ 无穷小
（C_r 不等式 + Markov：max P > ε ≤ max EX²/ε²，但需要
总量控制——习题的真账是 Σ EX² → 0 的情形）。

## 54.3 退化收敛准则：极限为常数的完全刻画（袁 23.3.2）

最简单的极限是退化 δ_c。别小看它——**退化准则是整个理论的
地基**（主定理的证明第一步就是分离退化部分）。

**定理 54.C（袁 23.4，退化收敛准则）**。无穷小阵列，
c ∈ ℝ：Sₙ − aₙ →ᵈ c ⟺ 三条同时成立：
  (i) ∀ε>0：Σₖ P{|X_{n,k}| > ε} → 0（尾部稀少）；
  (ii) Σₖ E[X_{n,k}·I{|X_{n,k}|≤1}] − aₙ → c（截尾期望和）；
  (iii) Σₖ Var[X_{n,k}·I{|X_{n,k}|≤1}] → 0（截尾方差和）。

**逐条读法**：(i) 说"没有哪一项能跳出去"（比无穷小更强——
它管的是**和**的稀少性，Borel-Cantelli 型）；(ii) 说"期望
全部兑现为常数"；(iii) 说"涨落全部消失"。三级数定理
（51.3）的 a.s. 版本在此变成依概率版——同一套截尾技术，
两种收敛模式的两次收割。

退化的另一面：iid 场景的引理 23.2/23.3（Fₙ(bₙx) → 1 与 →0
的单点质量逃逸账）说明 bₙ 的选取本身承载极限信息——**正规
化的自由度正是阵列理论的隐藏维度**（54.5 主定理中 bₙ 要
"正规化"：单调且 bₙ/bₘ 有界性）。

## 54.4 正态与 Poisson 的收编：两个成员的条款（袁 23.4.1）

**例 54.D（正态收编，袁 23.8）**。无穷小阵列，Sₙ →ᵈ N(0,1)
⟺ **Lindeberg 条件**（52.3 的 (21.1)）。52 章的 L-F 定理
在阵列语言下重述为普遍极限定理的正态条款——加上 Feller
条件（max σₖ²/Bₙ² → 0，恰好是无穷小的方差版）就是完全体。

**例 54.E（Poisson 收编，袁 23.9 前的例）**。计数型阵列
（X_{n,k} = 1 的概率 p_{n,k}，0 否则）：Σₖp_{n,k} → λ 且
max p_{n,k} → 0 ⟹ Sₙ →ᵈ Po(λ)。**小概率事件之和的律**：
罕见事件计数在"总强度收敛、单项强度消失"下收敛到 Poisson
——Poisson 极限定理（例 13.25/13.26 的阵列版完全体）。

**定理 54.F（独立三和定理，袁 23.9）**。给出极限 Y 的
Lévy-Khinchin 表示 (α, M, N, σ²)（53 章 Lévy 表示的四件套），
无穷小阵列收敛到 Y 的充要条件是三组量和（每组和随 n 收敛
到表示中的对应量）。**53 章的表示理论在此兑现为收敛判据**：
谱函数 Mₙ、Nₙ 与正态分量 σₙ² 的"总和"逐一到位。

## 54.5 主定理：极限族 = 无穷可分全体（袁 23.10）

**定理 54.G（Khinchin 1937/Feller/Gnedenko，袁 23.10）**。
  (A) 若 (Sₙ−aₙ)/bₙ →ᵈ Y（Y 非退化），则 Y 无穷可分；
  (B) 反之，任一无穷可分 Y 都实现为某无穷小阵列的极限
     （正规化 bₙ 单调）。

**(A) 的证明骨架**（数组 → i.d. 的手术）：固定 m，把第 n 行
的 kₙ 项**均分为 m 组**（每组 kₙ/m 项，行内独立 ⟹ 组间
独立），组内和 T_{n,j}；Sₙ 的正规化极限存在 ⟹ {T_{n,j}}
的联合分布胎紧（习题 12.33：和有界 ⟹ 各分量随机有界）⟹
子列收敛 ⟹ φ_Y = (φ_{T})^m ⟹ Y i.d.（53.3 构造定理的
"分组 + 胎紧"完全同款——两章在此会师）。无穷小性保证分组
合法（每组仍是"许多小项"）。

**(B) 的构造**：取 Y 的 LK 表示 (α, G)，构造跳跃阵列
X_{n,k}（第 n 行把 G 离散成 n 份 Poisson 型 + 正态分量
σ²/n·Z + 漂移 α/n）——**i.d. 的 Poisson 型极限构造
（53.3 定理 22.9）反方向运行**。四常青例在此全部重演：
δ、正态、Poisson、Γ 各自的阵列实现就是教科书里那些经典
收敛（二项→Poisson、几何和→Γ……）。

## 54.6 iid 情形：四情形决议表（袁 23.4.2）

iid 部分和 (Sₙ−aₙ)/bₙ →ᵈ Y 非退化的完全分类（六步法，
定理 23.11-23.13 的骨架）：

| 情形 | 尾部条件 | bₙ 的阶 | 极限 Y |
|---|---|---|---|
| 退化 | —（aₙ 吸收） | 任意 | δ_c |
| 正态 | EX² < ∞（Var > 0） | √n | N(0,σ²) |
| Poisson 型 | 稀有事件 | n | Po(λ) |
| 稳定 (0<α<2) | P{±X>x} ~ c±x^{−α} | n^{1/α} | 稳定律 S(α) |

**例 54.H（袁 23.11/23.12/23.13）**。① 正态 ⟺ EX² < ∞
（Lindeberg-Lévy 的逆：极限正态则方差必有限——习题 23.6）；
② Poisson：P{X=1}=λ/n 型稀有效应；③ Cauchy：对称尾
P{|X|>x} ~ c/x ⟹ Sₙ/n →ᵈ Cauchy（α=1 稳定——**除以 n
而不是 √n**，重尾世界的另一种"平均"）。四情形表把 50-52 章
+ 55 章装进一个框架：**矩条件决定你去哪个极限**。

特征函数（1 + λ(e^{it}−1)/n)ⁿ 逐点收敛到 exp(λ(e^{it}−1))

## 54.7.5 实验断言清单（数值通道验收单）

1. **二项→Poisson 的速率**：Bin(n,2/n) vs Po(2) 的 TV 距离
   = 0.0522 → 0.00457 → 0.00045（n = 10/100/1000——1/n 律）；
2. **Cauchy 不变性**：Sₙ/n 的分位数误差 n=5 与 n=80 同量级
   （0.072/0.085——分布不变是 α=1 的指纹）；
3. **涨落尺度**：正态源 max|Sₖ| ≈ 1.1·√n（n=400 实测 21.7，
   LIL 渐近界 √(2nLLn) = 34.9 在有限 n 未达——如实）vs Cauchy
   源 ≈ 1.3·n（518——大跳主导），两世界 24 倍分离；
4. **无穷小判决**：均匀 1/n 阵列的 max P = 0.01 → 0；带
   离群首项 = 1/2 ↛ 0（Python/Prolog 的精确分数双证）。

## 54.9 历史注记与要点回顾

Khinchin（1937）给出 iid 情形的稳定收敛分类；Feller（1935
的 L-F 对偶）与 Gnedenko（1939）完成独立阵列的一般理论
（Gnedenko-Kolmogorov 1949 专著《独立随机变量和的极限分布》
是学派的圣经）。退化收敛准则属于 Bernstein（1926）的早期
工作谱系。"普遍极限"纲领的意义：**概率论的极限定理不是
一串孤立奇迹，而是一棵以 i.d. 为根的树**——每个古典定理
是树上一枝。

要点回顾：
1. 阵列语言统一正规化：X_{n,k} = X_k/bₙ 把 aₙ,bₙ 吸收进
   阵列，"选正规化"变"选阵列"。
2. 无穷小条件 = 单项贡献一致消失——没有它理论平凡。
3. 退化准则：尾部稀少 + 期望兑现 + 方差消失（三级数的
   依概率版）。
4. 主定理：非退化极限 ⟺ 无穷可分；证明 = 分组 + 胎紧
   （53 章构造定理反向运行）。
5. iid 四情形表：矩条件（EX²、尾指数 α）决定极限户口
   （δ/正态/Poisson/稳定）与 bₙ 阶（—/√n/n/n^{1/α}）。
6. 机器侧：二项→Poisson ch.f. 全程机器证（复合利息极限
   收官）；数值通道四情形的收敛谱与尾账。
