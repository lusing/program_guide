# 02 单调类定理（集合形式）

**对应严书 §1.2（pp. 5-11）。**

---

## 2.1 一个奇怪的分工：两个定理干一件事

上一章定义了 σ-代数，但"验证某集类是 σ-代数"往往很烦：可数并封闭
要检查无穷多种情况。单调类定理说：**很多情况下只需检查两种简单得多的
封闭性**。它有两个平行的版本：

- **版本 A（单调类定理）**：设 C 是一个**代数**，m(C) 是包含 C 的最小
  单调类，则 m(C) = σ(C)。
- **版本 B（Dynkin π-λ 定理）**：设 C 是一个 **π-系**，λ(C) 是包含 C 的
  最小 λ 类（Dynkin 类），则 λ(C) = σ(C)。

两个定理结论相同（生成物就是 σ-代数），前提不同（代数 vs π-系 +
不同的闭包算子）。为什么需要两个？因为应用时你手里握着的封闭性往往
只有一种：验证函数性质时容易得到单调列封闭（版本 A 的主场，第 08 章
函数形式的姊妹篇），验证测度相等时容易得到 λ 类封闭（版本 B 的主场，
第 06 章的唯一性定理）。

## 2.2 定义与陈述

**定义（单调类）** M 是单调类，若对单调递增列 {Aₙ} 有 ⋃Aₙ ∈ M，且对
单调递减列有 ⋂Aₙ ∈ M。

**定义（λ 类 / Dynkin 类）** D 是 λ 类，若：Ω ∈ D；A, B ∈ D 且
B ⊆ A 时 A \ B ∈ D（真差封闭）；{Aₙ} 两两不交时 ⋃Aₙ ∈ D（**不交**
可数并封闭）。

注意 λ 类的三处"抠门"：补封闭只对真差成立、并封闭只对不交并成立。
它比 σ-代数弱得多——但配合 π-系就够翻身。

**定理（Dynkin π-λ）** 若 C 是 π-系，则 λ(C) ∩ {对交封闭} 蕴含
λ(C) = σ(C)。证明的引擎是"好集技术"（good sets argument）：固定
B ∈ C，考察 G_B := {A : A ∩ B ∈ λ(C)}，证明 G_B 是含 C 的 λ 类
（这里用到 C 的 π-系性质处理不交并的交），于是 λ(C) ⊆ G_B，即
λ(C) 对"与 C 成员的交"封闭；再固定 A ∈ λ(C) 考察 G_A，二次运用得
λ(C) 对交封闭——一个既是 λ 类又对交封闭的类就是 σ-类（我们马上
在 Lean 里证明这条"读出方向"）。

## 2.3 读出方向的形式化：λ 类 ∩ π-系 ⟹ σ-类

定理的完整证明（λ(C) 的极小性论证）在正文完成；机器通道证明它的
技术核心——**一个对交封闭的 λ 类已是 σ-类**。Lean 证明
（`Ch02MonotoneClass.lean`）分三步：

第一步，由交封闭导出补封闭与一般差封闭：

```lean
have hcomp : ∀ A ∈ C, Aᶜ ∈ C := by
  intro A hA
  rw [Set.compl_eq_univ_sdiff]        -- Aᶜ = univ \ A（真差）
  exact hdiff _ huniv _ hA (Set.subset_univ _)
have hdiff2 : ∀ A ∈ C, ∀ B ∈ C, A \ B ∈ C := by
  intro A hA B hB
  rw [Set.sdiff_eq]                    -- A \ B = A ∩ Bᶜ
  exact hPi A hA _ (hcomp B hB)
```

两个 rewrite 各干一件事：把补化为全集的真差（λ 类的强项），把一般差
化为与补的交（π-系的强项）。**两个"弱"封闭性在这里拼出了一个"强"的。**

第二步，De Morgan 给出二元并封闭：

```lean
have h2 : A ∪ B = (Aᶜ ∩ Bᶜ)ᶜ := Set.union_eq_compl_compl_inter_compl A B
```

注意这里我们**不需要**不交化——交封闭 + 补封闭已经免费给出并封闭。
（教材的传统证法用不交化，是因为它只假设 λ + π；我们的 hPi 本来就是
对一切交封闭，路更短。）

第三步，任意可列并不交化为 Dₙ = fₙ \ ⋃_{k<n} fₖ，用强归纳取"最早
出现指标"证明覆盖：

```lean
have key : ∀ n, x ∈ f n → ∃ m, x ∈ D m := by
  intro n
  induction n using Nat.strong_induction_on with
  | h n ih =>
    intro hx
    by_cases h : x ∈ ⋃ k < n, f k
    · obtain ⟨k, hk, hxk⟩ := Set.mem_iUnion₂.mp h
      exact ih k hk hxk          -- x 更早出现，向前归约
    · exact ⟨n, by rw [hDdef]; exact ⟨hx, h⟩⟩   -- n 就是最早指标
```

这一段是全证明的灵魂：x ∈ ⋃fₙ ⟹ x 在某个 Dₙ 中，靠的是自然数的
强归纳（找最早出现处）。Dₙ 两两不交是集合恒等式的直接推论。

同文件还证明了版本 A 的读出方向（代数 + 单调类 ⟹ σ-类）：任意可列并
化为部分和列 Bₙ = f₀ ∪ … ∪ fₙ 的单调极限——代数给有限并，单调类
接管极限。两个引擎殊途同归。

## 2.4 有限宇宙上的解剖实验

数值通道把这三种闭包的强弱关系摆在了台面上。Julia 实验
（`02_monotone_class.jl`）的核心输出：

```
π-系 {∅,单点×4}：σ = 16，λ = 16，单调 = 5
非 π-系 {{1,2},{2,3}}：σ = 16，λ = 6
代数 {∅,{1,2},{3,4},Ω}：σ = 4，单调 = 4
嵌套链（π-系）：σ = 16，λ = 16
```

三行读数各讲一个道理：

1. **第一行**：单点族加 ∅ 是 π-系，λ-闭包追平 σ-闭包（16 = 幂集）
   ——π-λ 定理的有限影子。但**单调闭包原地不动**（5 个成员）！
   原因：有限宇宙上单调列的极限就是列中的某一项，"对单调极限封闭"
   退化成空话。这**不是**定理失效，而是提醒：单调类定理的威力来自
   **无穷**单调列，它的有限影子是平凡的；λ 类（带不交并封闭）在
   有限宇宙上仍然有力——这正是 Dynkin 设计 λ 类的用意。
2. **第二行**：{1,2} 与 {2,3} 的交是 {2}，不在族里——π 条件被破坏，
   λ-闭包卡在 6 个成员，追不上 σ-闭包。π 条件不可去。
3. **第三行**：从代数出发，σ-闭包就是自身（有限代数即 σ-代数），
   单调闭包同样守恒——版本 A 的影子（平凡但一致）。

Prolog 通道（`02_monotone_class.pl`）把闭包算子写成了纯逻辑：一个
通用的 `closure_/3` 以"步进谓词"为参数，`sigma_step`、`mono_step`、
`lambda_step` 三种步进即得三种闭包：

```prolog
closure_(Step, C, S) :-
    findall(D, call(Step, C, D), New),
    (   any_new(New, C)
    ->  append_new(New, C, C2), closure_(Step, C2, S)
    ;   S = C ).
```

调这里时踩的坑值得入账：判断"是否还有新集合"的 `any_new/2` 最初
写了空列表子句（`any_new([], _).`），语义成了"没有新的也算有新的"，
不动点处恒真、闭包永不停止。**空基情形必须失败**——不动点检测的
语义就藏在"失败即终止"里。这与第 01 章 Prolog 的 cut 教训同源：
逻辑程序的"否定即失败"语义需要精确设计，多一个子句少一个子句，
行为天差地别。

## 2.5 极小性论证全文：好集技术的两步走

把 π-λ 定理的"生成方向"补成完整证明（读这一段时请拿纸笔画两个椭圆）。

**目标**：λ(C) 对交封闭。分两步，每步的形状完全相同。

**第一步**：固定 B ∈ C，令 G := {A ∈ λ(C) : A ∩ B ∈ λ(C)}。
(a) G ⊇ C：A ∈ C 时 A ∩ B ∈ C ⊆ λ(C)（π-系！）。
(b) G 是含 Ω 的 λ 类——逐一核对三条款：Ω ∩ B = B ∈ C ✓；真差
    (A₁ \ A₂) ∩ B = (A₁∩B) \ (A₂∩B)，两块都在 λ(C) 中且后者含于
    前者，真差封闭给出结果 ✓；不交列的交：Aₙ ∩ B 两两不交，可数
    不交并封闭两次使用 ✓。
由 λ(C) 的极小性，λ(C) ⊆ G。结论：**C 中每个 B 与 λ(C) 中每个 A 的
交都在 λ(C) 中**。

**第二步**：现在固定 A ∈ λ(C)，令 H := {B : A ∩ B ∈ λ(C)}。
(a) 由第一步，H ⊇ C。(b) H 是 λ 类——核对方式与第一步逐字相同
（对称性！）。极小性给出 λ(C) ⊆ H，即 λ(C) 对自身的交封闭。∎

两步的差别只有一处：第一步的 (a) 用 π-系性质，第二步的 (a) 用第一步
的结论。这就是"好集技术"的全部秘密——**把要证的性质装进一个类，证它
是 λ 类，然后让极小性替你冲击**。第 06 章的唯一性、第 18 章 Fubini 的
截面可测性，都是这段论证的换装重演。

代数版本（m(C) = σ(C)）的证明骨架：m(C) 本身是代数（用"对每个固定
A，{B : A∪B, A\B 均在 m(C)}是好集"的同类技术证并封闭），而**既是代数
又是单调类的类是 σ-代数**（可数并 = 部分和列的单调极限，正是 Lean
通道 Engine1 的内容）。

## 2.6 使用范式与一次预演

范式（先立牌子）：
> 要证性质 P 对 σ(C) 全体成立：证 {A : P(A)} ⊇ C 且是单调类（C 为
> 代数），或 ⊇ C 且是 λ 类（C 为 π-系）。

一次预演（结论第 06 章正式使用）：设 μ, ν 是有限测度且在 π-系 C 上
相等，则 μ = ν 在 σ(C) 上成立。论证：D := {A : μ(A) = ν(A)} 含 C；
Ω ∈ D；真差封闭：B ⊆ A 时 μ(A\B) = μ(A) − μ(B) = ν(A) − ν(B) =
ν(A\B)（**有限性在此登场**——否则 ∞−∞ 无定义）；不交可数并封闭：
部分和列的极限。故 D 是 λ 类，π-λ 定理收工。注意这个论证**不能**把
"真差"换成"补"（补封闭需要 μ(Ω) = ν(Ω)，它恰好由覆盖列的极限给
出）——条件之间咬合得严丝合缝，没有一处多余。

以后全书会反复出现这样的论证模式（先在这里立个牌子）：

> 要证某性质 P 对 σ(C) 中所有集合成立，只需：(1) {A : P(A)} 包含 C；
> (2) {A : P(A)} 是单调类（或 λ 类）；(3) C 是代数（或 π-系）。

第 06 章的测度唯一性、第 08 章的函数单调类定理、第 18 章 Fubini
定理中"截面可测"的证明，全是这个范式的实例。把第 02 章吃透，
后面每一次"由生成系过渡到 σ-代数"都是免费重放。

## 2.7 要点回顾

1. 单调类定理（代数版）与 Dynkin π-λ 定理（π-系版）是同一目标的
   两条路线：从弱封闭性出发把生成物逼成 σ-代数。
2. 读出方向的核心技巧：λ + 交封闭 ⟹ σ（De Morgan 与不交化）；
   代数 + 单调 ⟹ σ（部分和列的单调极限）。
3. 好集技术（G_B := {A : A ∩ B ∈ λ(C)}）是极小性论证的标准姿势。
4. 有限宇宙上：λ-闭包与 σ-闭包的差距精确刻画 π 条件的作用；单调
   闭包退化——无穷性才是单调类定理的舞台。
