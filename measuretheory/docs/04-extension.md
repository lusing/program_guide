# 04 外测度与测度的扩张

**对应严书 §1.4（pp. 15-22）。**

---

## 4.1 本章在全书的地位

如果说前三章是"词汇表"，本章就是测度论的**存在性定理**：除了硬凑的
例子，我们至今没有任何办法造出一个定义在完整 σ-代数上的测度。外测度
+ Carathéodory 扩张定理解决了这件事，它是一条流水线：

```
半环上的预测度（区间长度）
    │  对可数覆盖取下确界
    ▼
外测度 μ* : 2^Ω → [0,∞]   （只满足单调 + 次可加）
    │  Carathéodory 限制
    ▼
σ(可测集) 上的完备测度 μ
```

Lebesgue 测度、Lebesgue-Stieltjes 测度（第 05 章）、乘积测度
（第 18 章）、Hausdorff 测度全部产自这条流水线。

## 4.2 外测度

**定义（外测度）** μ* : 2^Ω → [0, ∞] 是外测度，若 μ*(∅) = 0、单调、
且**可数次可加**：μ*(⋃Aₙ) ≤ Σμ*(Aₙ)。

注意：外测度定义在**全体**子集上，代价是放弃可加性——只有"很好的"
集合之间才能精确相加。从预测度造外测度的标准方法是**覆盖下确界**：

  μ*(A) = inf { Σ μ₀(Iₙ) : A ⊆ ⋃ Iₙ, Iₙ ∈ 半环 }

（严书 1.4 的 μ*-构造。）区间长度经此方法给出 Lebesgue 外测度；直径的
s 次幂给出 Hausdorff 外测度。

## 4.3 Carathéodory 判据与扩张定理

**定义（可测）** 集 A 称为 μ*-可测，若对**任意**试验集 T：

  μ*(T) = μ*(T ∩ A) + μ*(T \ A)

这个定义的妙处：它不要求 A 自身有任何拓扑或结构，只要求 A 能把一切
集合"干净地切成两片"。直觉上，A 的边界不能太毛糙——切口的模糊带
会破坏等式。

**定理（Carathéodory）** 可测集全体 M 是 σ-代数，μ* 限制在 M 上是
完备测度（零测子集全可测）。若 μ* 由半环 C 上的预测度生成，则
M ⊇ σ(C) 且 μ* 在 C 上与预测度一致；当预测度 σ-有限时扩张唯一
（唯一性第 06 章正式收官）。

**证明的关键结构**（正文全文展开，机器通道验证其核心引理）：M 对补
封闭是平凡的（T ∩ A 与 T \ A 交换位置）；M 对**二元并**封闭需要
四分分解——u 被 s 切成两片后，u \ s 再被 t 切，三片拼出 u ∩ (s ∪ t)
与 u \ (s ∪ t)。这段论证不能靠"显然"蒙混，Lean 通道把它逐行钉死：

```lean
theorem caratheodory_union {s t : Set α} (hs : IsCaratheodoryFor m s)
    (ht : IsCaratheodoryFor m t) : IsCaratheodoryFor m (s ∪ t) := by
  intro u
  have key1 : m (u ∩ (s ∪ t)) = m (u ∩ s) + m (u \ s ∩ t) := by
    have h := hs (u ∩ (s ∪ t))
    -- (u ∩ (s∪t)) ∩ s = u ∩ s；(u ∩ (s∪t)) \ s = u\s ∩ t
    rw [h, e1, e2]
  have key2 : m u = m (u ∩ s) + m (u \ s ∩ t) + m ((u \ s) \ t) := by
    rw [hs u, ht (u \ s)]     -- 两次切割的复合
  have key3 : u \ (s ∪ t) = (u \ s) \ t := by
    ext x; simp only [...]; tauto
  rw [key1, key3, key2]
```

读法：key1 用 s 的可测性切 u ∩ (s∪t)（切口恰好分出 u∩s 与
u\s∩t）；key2 是 s 切 u、t 再切 u\s 的链式复合；key3 是集合恒等式
"挖掉并 = 连挖两次"。三者拼起来，可加等式两边逐项相等。

mathlib 侧的官方对应物：`OuterMeasure.caratheodory`（可测集全体，
直接是一个 `MeasurableSpace`）、`OuterMeasure.toMeasure`（限制成
测度）、`Measure.completion`（完备化）。mathlib 的 Lebesgue 测度
`volume` 本身就是这条流水线的产物。

## 4.4 半环上的两道质检工序（严书 1.4.4 / 1.4.5）

扩张定理的原料是"半环上的预测度"，但第 03 章只给了**有限**可加性。
可数可加怎么验？逐条验证可数分解不可能，严书给了两道省力工序。

**工序一（命题 1.4.4）**：半环 C 上的非负集函数 μ（μ(∅)=0）是
σ-可加的，当且仅当它**有限可加**且**半 σ-可加**（A ⊆ ⋃Aₙ ⟹
μ(A) ≤ Σμ(Aₙ)）。必要性平凡；充分性的证明是一行漂亮的减法：要证
μ(A) = Σμ(Aₙ)（设 A = ⋃Aₙ 已不交化），先由有限可加性得
μ(A) ≥ Σₖ≤ₙ μ(Aₖ) 对一切 n 成立（截断族 A₁..Aₙ ⊕ 余集 Cᵈ ∈ C_σ，
有限可加沿分解展开），令 n → ∞ 得 μ(A) ≥ Σμ(Aₙ)；反向正是半
σ-可加。**"可数"性质被压成"有限 + 极限"**——第 05 章验证 LS 预测度
时走的就是这条捷径。

**工序二（引理 1.4.5）**：要验证 A 是 μ*-可测的，**不必**对全体
试验集 T 检查切割等式，只需对生成半环 C 中的每个 C 检查

  μ(C) ≥ μ*(C ∩ A) + μ*(C ∩ Aᶜ)。

直觉：C 的外测度值是"原料价"，最紧的预算约束；若 A 能把每种原料
干净切开，它就能切开一切由原料覆盖出来的集合（对任意 T 的覆盖
{Iₙ} 逐项套用 C-版本不等式，按 ε/2ⁿ 摊派后求和取极限）。这与第
02 章"在 π-系上检查即可"是同一个范式在集合层与测度层的两次成像：
**生成系承载全部信息**。Lebesgue 测度的区间可测性（4.5 节第 4 步）
由此只需对区间试验集验证。

## 4.5 完备化

扩张得到的测度可能不完备：σ(C) 里可能有零测集，其子集不在 σ(C) 里。
**完备化**把所有零测子集（连同与可测集差一个零测集的集合）补进去，
得到最小完备扩张 μ̄。mathlib 对应 `Measure.completion`；Lebesgue
测度 = Borel 测度的完备化，这是"Lebesgue ⊋ Borel"的机构性解释。
Cantor 集是检验完备化的经典标尺（Borel 且零测，其子集不全 Borel，
但全 Lebesgue-可测）。

## 4.6 Lebesgue 测度构造的逐步核对

把流水线落到实处（这里是核对单，证明见严书 §1.4 与本章正文）：

1. **原料**：C = {(a, b]}（含 ∅ 与无限区间），预测度 μ₀((a,b]) =
   b − a（约定 a ≥ b 时为 0）。C 是半环（第 01 章表），μ₀ 有限可加
   且半 σ-可加（不交区间的长度相加，公共加细论证见第 03 章 3.6 节），
   工序一（1.4.4）随即给 σ-可加。
2. **外测度**：λ*(A) = inf {Σ(bₙ − aₙ) : A ⊆ ⋃(aₙ, bₙ]}。Heine-Borel
   保证紧集的覆盖有有限子覆盖——这是 λ* 在紧集上"可达下确界"的来源，
   也是 5.7 节正则性的种子。
3. **核对区间**：λ*((a,b]) = b − a。≤ 显然（自己覆盖自己）；≥ 用紧性
   + ε/2ⁿ 膨胀技巧（每个覆盖区间向左伸 ε/2ⁿ，紧覆盖抽有限子覆盖，
   剩下的是有限不等式）。
4. **可测性**：工序二（1.4.5）把"对任意 T"压缩成"对区间 C"：(a,b]
   对区间试验集的切割等式由覆盖的逐项切割给出，于是 (a,b] ∈ M，
   ℬ(ℝ) ⊆ M。
5. **平移不变**：覆盖平移还是覆盖，λ*(A + t) = λ*(A)——Vitali 反例
   的弹药。
6. **完备化**：Lebesgue σ-代数 = M 本身（这条流水线的产品天然完备），
   它严格大于 ℬ(ℝ)（Cantor 集的不可测……不，Cantor 子集全可测——
   严格大于的见证：Cantor 集的子集有 2^c 个，Borel 集只有 c 个，
   基数论证）。

第 5、6 两步值得咀嚼：**基数论证**证明 Lebesgue σ-代数严格更大，但
**构造不出**具体的"非 Borel 的 Lebesgue 可测集"（能造的都是选择公理
式的存在性）；而"Lebesgue 可测但含于零测 Borel 集"的集合比比皆是
（Cantor 子集）。两种"多余"的来源不同，前者是基数，后者是完备化。

## 4.7 数值与逻辑实验：可测性的"分辨率"

**Julia（`04_extension.jl`）**在 [0,1) 的 2⁸ 网格上实现了覆盖式外测度，
验证单调性、次可加性（各 500 次随机实验），并用 Cantor 集深度 3 的
块做覆盖对照：

```
Cantor 集深度 3：格点外测度 = 0.3633，真值 (2/3)^3 = 0.2963
Carathéodory 判据：二进区间对 300 个随机试验集全部精确可加
有限影子：网格外测度限制是完备测度（Vitali 反例本质上是不可数现象）
```

第三行的结论值得咀嚼：有限离散网格上，逐点计数式的外测度让**所有**
子集可测——Vitali 式不可测集在有限宇宙里**不存在**。不可测性是
不可数现象（准确说：依赖选择公理下的不可数结构），数值实验只能逼近
而不能重现它。实验还顺带暴露了一个实现细节：按"游程覆盖"取下确界
的算法，在整数网格上的最优值恰好等于 1 的个数（popcount）——外测度
退化成计数测度。这不是 bug，而是"区间长度 = 格点数"权重的必然，
也再次说明**外测度的形状由覆盖权重的结构决定**。

**Python（`04_extension.py`）**用 `Fraction` 把 Julia 的浮点实验
重做成**精确**版本：单调性与次可加性各 300 次随机实验零舍入误差；
Cantor 深度 3 的格点外测度断言写成

```python
assert abs(m_star - true_m) <= Fraction(1, N) * 8, "覆盖误差 ≤ 每块一个网格"
```

——不等式右边是"每个 Cantor 块至多多盖一个网格列"的**推论式容差**，
而不是拍脑袋的 ε；Carathéodory 判据同样在 200 组随机 (A, T) 上逐组
精确成立。两个通道一浮点一分数互为对拍，是本工程数值纪律的标准配置。

**Prolog（`04_extension.pl`）**给出了一个真正非平凡的有限模型：
块覆盖外测度。取块代数 {{1,2}, {3,4}}，定义

  m*(A) = 覆盖 A 所需块的长度和 = 2 × (A 触及的块数)

它单调、次可加（全体 16×16 子集对穷举验证），但只有 **4 个**
Carathéodory 可测集——恰好是块代数 {∅, {1,2}, {3,4}, Ω} 本身：

```
monotonicity over all comparable pairs: OK
subadditivity over all subset pairs: OK
witness A={1}, T={1,2}: m*(T)=2 vs m*(TA)+m*(TcA)=2+2=4
caratheodory measurable sets: 4 of 16
measurable class = block algebra {empty,{1,2},{3,4},Omega}: OK
```

见证行是全部趣味所在：A = {1} 切 T = {1,2} 时，两片各触及一个块，
各付 2 的"块价"，总共 4 > 2——A 分辨不出块内部，故不可测。
**外测度的分辨率决定了可测结构**：Julia 的逐点模型分辨率最高
（全体可测），Prolog 的块模型分辨率是块（4 个可测集），连续情形的
Lebesgue 外测度分辨率是"区间精度"（Borel + 零测完备化）。三个模型
一件道理，这是本章最想留下的直觉。

## 4.8 Vitali 集：不可测性的存在性

最后补上存在性论证的骨架（正文详述）：在 [0,1) 上按"差为有理数"
分类，每类取一点得 V。若 V 可测且平移不变，则 [0,1) 的可数个互不
重叠的平移覆盖住一个固定区间又含于另一固定区间，可数可加性迫使
μ(V) 同时为 0 与为正——矛盾。结论：**V 不 Lebesgue 可测**。测度论
注定不能测量一切；这条边界线本身就是学科的疆界。

## 4.9 要点回顾

1. 外测度 = 全子集上的单调 + 次可加；由覆盖下确界从预测度构造。
2. Carathéodory 判据（切一切加得齐）选出 σ-代数；限制成完备测度。
3. 两道质检工序：σ-可加 ⟺ 有限可加 + 半 σ-可加（1.4.4）；可测性
   只需对生成半环验收（1.4.5）——"生成系承载全部信息"的测度层成像。
4. 二元并封闭的四分分解是证明的技术心脏；σ-有限给唯一性。
5. 有限模型的三种分辨率（逐点 / 块 / 区间）演示可测结构的来源；
   不可测性是不可数现象。
