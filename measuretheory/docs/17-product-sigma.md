# 17 乘积可测空间：联合观测的舞台

**对应严书 §4.1（pp. 83-87）/ 袁上册 §10.1（pdf247-252）。**

---

## 17.1 为什么需要乘积

到此为止的测度论都住在"一个"可测空间里。但概率论的第一个动作就
是同时看两个随机变量（联合分布）、分析学的第一个动作就是二重积分
（f(x,y)）、随机过程的第一个动作就是样本序列（X₁, X₂, …）。这些
对象全部住在某个**乘积空间** Ω₁ × Ω₂（或 ∏ᵢ Ωᵢ）上。本章回答
两个问题：

1. 乘积空间上的 σ-代数怎么定？（答案：**可测矩形生成**）
2. 这样定出来的结构，与"逐坐标看"的操作（截口、投影）相容吗？
  （答案：投影可测、截口可测——Good 集方法的标准演练场）

第 04 章已经预演过有限版本（ℝⁿ 的盒半环）；本章把它推广到任意
指标族，并把生成系的几种形态理清——袁书定理 10.5/10.6 给出的
"可测矩形全体是半代数、可测柱集全体是代数"两件套，是无穷乘积
测度（第 20 章）的地基。

## 17.2 有限乘积：矩形与最小性

设 (X, A)、(Y, B) 为可测空间。**可测矩形**是形如 A × B
（A ∈ A, B ∈ B）的集合。定义**乘积 σ-代数**

  A ⊗ B := σ({A × B : A ∈ A, B ∈ B})。

三个即时观察：

1. **最小性**：A ⊗ B 是使两个投影 π₁ : X×Y → X、π₂ : X×Y → Y
   都可测的最小 σ-代数（π₁⁻¹(A) = A × Y 是可测矩形）。
2. **半代数结构**（袁定理 10.5(i)）：可测矩形全体对有限交封闭
  （(A×B) ∩ (A'×B') = (A∩A') × (B∩B')），其补集可写成有限个不交
   矩形之并（(A×B)ᶜ = (Aᶜ×Y) ∪ (A×Bᶜ)）——衔接第 04 章 ℝⁿ 盒
   半环的验收工序，乘积测度的构造（第 18 章）正是在这个半代数上
   起步的。
3. **与拓扑对齐**：ℝᵐ × ℝⁿ 上 B(ℝᵐⁿ) = B(ℝᵐ) ⊗ B(ℝⁿ)。两行
   证明：⊇ 方向——投影连续故可测，B(ℝᵐ)⊗B(ℝⁿ) 由连续投影的
   逆像生成 ⊆ B(乘积拓扑)；⊆ 方向——乘积拓扑的开集是盒
   U₁×U₂（Uᵢ 开）的任意并，而每个盒 ∈ B(ℝᵐ)⊗B(ℝⁿ)，开集
   全体落进 σ-代数即得。**这条对齐让"拓扑直觉"与"测度记账"
   在 ℝⁿ 上完全互通**——但分寸见 17.4：不可数乘积上它仍是
   真定理（袁定理 10.6），只是两边的"开集/可测集"都变得相当
   瘦。

**"到乘积的映射"判据**：f : Z → X×Y 可测 ⟺ 两个分量
π₁∘f 与 π₂∘f 都可测。这是"最小性"的函数版：A ⊗ B 由投影生成，
生成系的逆像可测就够（第 07 章 comap 机器的直接应用）。机器侧
mathlib 的 `Measurable.prodMk`（配对可测）就是这条判据的一半，
另一半由 `Measurable.fst`/`Measurable.snd`（投影可测）免费给出。

## 17.3 截口：逐坐标切片

对 E ⊆ X×Y 与 x ∈ X、y ∈ Y，**截口**

  E_x := {y : (x,y) ∈ E}，  E^y := {x : (x,y) ∈ E}。

**截口定理（严书 4.1 章内引理 / 袁定义 10.7 邻域）**：E ∈ A ⊗ B
⟹ 对**一切** x，E_x ∈ B；对一切 y，E^y ∈ A。证明是 Good 集方法
的教科书范例：

1. **G := {E : 一切截口可测}** 包含全体可测矩形（(A×B)_x 要么
   是 B 要么是 ∅，看 x ∈ A 与否）；
2. G 对补与可数并不封闭性逐一验证：Eᶜ 的截口 = (E_x)ᶜ；∪Eₙ 的
   截口 = ∪(Eₙ)_x——两行集合恒等式；
3. 故 G ⊇ σ(矩形) = A ⊗ B。∎

同样的骨架立即给出函数版：f : X×Y → ℝ 为 A ⊗ B 可测 ⟹ 每个
截口函数 f(x, ·) 可测（f(x,·)⁻¹(B) = (f⁻¹(B))_x，集版直接套）。
**注意方向**：截口对**每个固定坐标**都可测，但"对所有 x 同时"
的信息（联合可测性）严格强于"每个截口可测"——第 09 章 separable
过程的可测性修补（可分修改）正是这条缝隙的受害者与修复现场。
第 18 章 Fubini 定理的全部技术难度，都藏在"从逐点截口回到整体
积分"这一步。

## 17.4 任意族：柱集接管

设 (Ωᵢ, Fᵢ)_{i∈I} 为任意族（I 可以不可数）。**坐标投影**
πᵢ : ∏Ωⱼ → Ωᵢ。定义

  ⊗ᵢ∈I Fᵢ := σ(⋃ᵢ πᵢ⁻¹(Fᵢ))。

**可测柱集**：形如 π_S⁻¹(∏_{i∈S} Aᵢ) 的集合，其中 S ⊆ I
**有限**、Aᵢ ∈ Fᵢ——"只在有限多个坐标上设置条件，其余全自由"。
**可测矩形**（有限支集版本）：S 有限时 ∏_{i∈S} Aᵢ × ∏_{i∉S} Ωᵢ。

**定理（严书 4.1.4 / 袁定理 10.5）——三级台阶**：

1. **可测矩形全体是半代数**（S 取遍 I 的非空有限子集）：交封闭
   显然；补可写成有限不交矩形之并。但**不是代数**：两个盒之并
   一般不是盒（[0,1]×[0,1] ∪ [1,2]×[1,2] 无法压成一个矩形）——
   半代数正是第 04 章盒半环的抽象复用；
2. **可测柱集全体是代数**（柱集 = π_S⁻¹(E)，S 有限、
   E ∈ ⊗_{i∈S}Fᵢ 为有限乘积中的**任意**可测集，不限于盒）：
   补封闭（同支集取 Eᶜ）；有限并封闭（支集 S, T 先提升到 S∪T：
   π_S⁻¹(E) = π_{S∪T}⁻¹(E × ∏_{i∈T∖S}Ωᵢ)，再在 S∪T 内取并）。
   注意这一步**不需要 I 可数**——有限支集的运算永远停留在
   有限支集；
3. **可数支集柱集全体是 σ-代数，且恰等于 ⊗ᵢ∈I Fᵢ**：可数并的
   支集 = 支集的可数并（仍可数），提升论证照抄第 2 级；它包含
   一切单坐标生成元 πᵢ⁻¹(Aᵢ)，故 ⊗ᵢ Fᵢ ⊆ 它；反向包含由
   π_S 可测给出。∎

第 3 级就是**不可数乘积的"可数本质"**：每个 E ∈ ⊗ᵢ Fᵢ 都只
依赖可数多个坐标——存在可数 S 与 A ∈ ⊗_{i∈S}Fᵢ 使
E = π_S⁻¹(A)。ℝ^ℝ 上乘积 σ-代数的事件只看得到可数多条坐标轴。
推论（袁定理 10.6）：对任意（包括不可数）T，乘积拓扑空间 ℝ^T
上 **B(ℝ^T) = ⊗_{t∈T}B(ℝ)**——箱拓扑基 ⊆ 右边、右边由连续
投影生成 ⊆ 左边。**但注意分寸**：单点集 {ω} 在 ⊗ 中（可数支集
∩ 闭点），而"逐点收敛点集"{lim πₙ = 存在} 需要可数坐标与极限
运算——仍在 ⊗ 内；真正逃出 ⊗ 的是涉及**不可数** sup/inf 的
集合（如 {ω 有界} 对不可数 T）——那已是第 43 章随机过程
可分性的裂缝，第 40 章解析集的入口。

**子投影可测（严书 4.1.3）**：对任意 S ⊆ I，π_S :
(∏Ωᵢ, ⊗ᵢFᵢ) → (∏_{i∈S}Ωᵢ, ⊗_{i∈S}Fᵢ) 可测。证明一行：
π_S 的每个生成元 πᵢ⁻¹(Aᵢ) (i∈S) 在大空间里也可测，用
命题 2.1.3（生成系判据）收尾。

## 17.5 两套生成系的对照表

| 生成系 | 形态 | 代数层级 | 用途 |
|---|---|---|---|
| 可测矩形（盒形边） | ∏_{i∈S}Aᵢ，S 有限 | **半代数**（并不封闭） | 乘积测度起步（第 18/20 章的外测度进料） |
| 可测柱集（有限支集） | π_S⁻¹(E)，E ∈ ⊗_{i∈S}Fᵢ | **代数**（任意 I） | 无穷乘积的存在性战场（柱集代数上先造可加集函数再延拓） |
| 可数支集柱集 | π_S⁻¹(A)，S 可数 | **σ-代数 = ⊗ᵢFᵢ** | "可数本质"定理本体 |
| 坐标逆像 ⋃πᵢ⁻¹(Fᵢ) | 单坐标事件 | σ-系的子基 | 定义本身（最小性最直观） |
| 箱（拓扑版） | ∏开集 | 拓扑基（非 σ-代数） | 乘积拓扑 ↔ 乘积 σ-代数的桥（袁定理 10.6：B(ℝ^T) = ⊗B(ℝ)，第 28 章） |

袁书 10.1.3（"与 K 有关的几个乘积 σ-代数"）再补两行：固定
J ⊆ I，⊗_{i∈J}Fᵢ 与 ⊗_{i∈I}Fᵢ 经 π_J 相互翻译；I = J ⊔ Jᶜ
时 ⊗ᵢFᵢ = (⊗_J Fᵢ) ⊗ (⊗_{Jᶜ} Fᵢ)——**有限剖分指标集等于
有限乘积的迭代**，这是 Kolmogorov 相容性（第 21 章）里"边缘
一致"的代数原形。

## 17.6 Lean：MeasurableSpace.prod 一族

mathlib 的乘积 σ-代数是 `MeasurableSpace.prod`（Constructions/
Pi.lean，二元记号 `m₁ ⊗ m₂`?——正名以 #check 为准），配套
`Measurable.fst`/`Measurable.snd`（投影可测）与 `Measurable.prodMk`
（配对判据的一半）。`Ch17ProductSigma.lean` 的实弹：

1. **锚点正名**：`#check @MeasurableSpace.prod` 等，看清 prod 的
   定义位置与记号；
2. **配对判据**：`fun p : ℝ × ℝ => (p.1 * p.2, p.2 - p.1)` 可测
  ——`Measurable.prodMk` 把目标劈成两个一元目标，`fun_prop`
   （fst/snd/四则的自动可测性）收割；
3. **复合到 Borel**：`fun p : ℝ × ℝ => sin p.1 + cos p.2` 可测
  ——第 07 章 Borel 机器与本章投影的组合；
4. **矩形的可测性与预像**：`MeasurableSet.prod`（Icc 0 1 ×ˢ
   Icc 0 1 可测）与对角线式预像 `x ↦ (x, -x)` 的复合——
   `(x,-x) ∈ [0,1]×[0,1]` 强迫 x = 0，机器把这条"几何直觉"
   落成 `Set.preimage` 的显式等式。

## 17.7 数值实验：小空间上的完整枚举

有限空间上，"生成"是可以**算完**的：从矩形出发反复做补与
有限并，直到封闭——这就是 σ-代数的闭包算法（有限空间里
σ-代数 = 代数，有限步收敛）。

**Julia（`17_product_sigma.jl`）**：X = Y = {0,1}（幂集 σ-代数）：

- 4 个原子 (a,b)，矩形全体 = 16 个（4×4）；闭包算法跑出乘积
  σ-代数 = 幂集（16 个集合）——**矩形已经生成一切**；
- **截口全查**：对 16 个集合 × 2 个 x 值 × 2 个 y 值 = 64 个
  截口逐一验证可测（平凡真，但流水线就是定理 17.3 的可运行版）；
- **瘦 σ-代数版本**：A = σ({{0}}) = {∅,{0},{1},X}（4 元），
  B 同构——A ⊗ B 闭包跑出 16 元幂集；再取 A = {∅,X}（平凡），
  A ⊗ B = B 的搬運（4 元）——**乘积 σ-代数对输入的依赖性**
  数值可见。

**Python（`17_product_sigma.py`）**：Fraction/整数精确版 + **不
可数支集的教学演示**：I = 1..6（模拟"不可数"用有限指标集 +
显式支集记账），枚举柱集时显式记录每个集合的**支集**
（哪些坐标被约束），验证：柱集族对交封闭且支集取并；有限并
支集仍是有限并——袁定理 10.5 的逐条数值对拍。

**Prolog（`17_product_sigma.pl`）**：符号版——可测矩形
`rect(A,B)`、补 `comp/2`、并 `cup/2` 在有限格上的闭包谓词
`in_prod_sigma/1`（表驱动），以及截口谓词 `section/3` 的
穷举验证。集合法则用位串表示（第 01 章的工具箱复用）。

## 17.8 要点回顾

1. A ⊗ B = σ(矩形) = 使投影可测的最小 σ-代数；"到乘积的映射
   可测 ⟺ 分量可测"是最小性的函数版。
2. 截口定理：乘积可测 ⟹ 一切截口可测；Good 集方法三步
  （矩形起步 / 补并不封闭 / 收 σ）。反向不成立——联合可测
   严格强于逐截口可测（第 09 章可分性的裂缝）。
3. 任意族三级台阶：矩形=半代数、有限支集柱集=代数（任意 I）、
   可数支集柱集=σ-代数=⊗ᵢFᵢ——不可数乘积的"可数本质"。
   B(ℝ^T) = ⊗B(ℝ) 对一切 T 成立（袁定理 10.6）。
4. 有限剖分指标集 ⟹ 乘积 σ-代数迭代分配——Kolmogorov 相容性
   的代数原形。
5. 机器侧：mathlib `MeasurableSpace.prod`/`prodMk`/`fst`/`snd`；
   数值通道在小空间上把"生成"算到底。
