## 50.1 问题：平均为什么收敛

样本平均 X̄ₙ = (X₁+…+Xₙ)/n 收敛到期望 μ 吗？**三种收敛
档位**（依概率/完全 a.s./Lᵖ）与**四种独立度**（iid/
独立/两两/阵列）的矩阵给出一整章的谱系。核心权衡：
**矩条件 vs 独立性强度**——矩越强，独立性可以越弱。

## 50.2 依概率收敛的谱系（袁 19.1）

**Markov LLN（袁 19.1.2）**：{Xₖ} 独立（或两两不相关），
Var Xₖ ≤ C（一致有界）且（关键）

  (1/n²)·ΣVar Xₖ → 0（**Markov 条件**）

⟹ X̄ₙ − E X̄ₙ →p 0。证明一行：Chebyshev + 条件代入。
一致有界的特例给 Bernstein-Khinchin（袁 19.1.3：
独立 + 有界 ⟹ X̄ₙ →p EX̄ₙ）。

**Khinchin LLN（袁 19.1.4）**：iid + **仅一阶矩** EX < ∞
（无方差！但独立性最强）⟹ X̄ₙ →p EX。证明用截尾术
（48 章工具）：X 截成 X^c 与残尾，截断部分用 Markov
LLN、残尾概率 → 0（一阶矩的存在性给尾部质量的消失）。
**矩与独立性的兑换**：Khinchin 用满 iid 换最低矩。

**Marcinkiewicz-Zygmund LLN（袁 19.1.5）**：iid +
E|X|^p < ∞（0 < p < 2）⟹ n^{−1/p}(Sₙ − n·b) → 0（a.s.
其中 p ≥ 1 时 b = EX；p < 1 时 b 任意）——**速率的精确
指数**（p = 1 退化为 Khinchin；p = 2 是 √n-速率——51 章
LIL 的对照）。

## 50.3 阵列版与经典退化收敛（袁 19.2-19.3）

**行独立三角阵列 {X_{n,k}}**（第 n 行内部独立）：
X̄ₙ = ΣₖX_{n,k} 的收敛理论——CLT 的同伴（52 章同框架）。
**经典退化收敛准则（袁 19.3.2）**：三角阵列 max 项的
影响消失（max P + max 尾 → 0）+ 归一化和的方差 → σ²
⟹ X̄ₙ − EX̄ₙ →p 0（无穷小条件的雏形——53 章普遍极限
理论的入口）。

**圣彼得堡悖论（袁 19.3.3）**：E|X| = ∞ 的经典现场——
游戏 E X = ∞ 但 median 收敛：**截尾平均值收敛**于
log₂(n) 型增长（如果截断水平固定）或发散（不截断）。
数值通道模拟这个悖论的实际感受（100 万局游戏的平均
依然不稳定）。

**Kolmogorov-Feller LLN（袁 19.3.4）**：iid + E|X| = ∞
时截尾平均 n·P(|X| > n) → 0 的**充要条件**——无穷期望
世界的细粒度收敛（重尾理论的经典起点）。

## 50.3.5 Khinchin 截尾证明的完整账（一阶矩的最小消费）

Khinchin 定理（iid + E|X| < ∞ ⟹ X̄ₙ →p EX）的截尾证明
逐步解剖（"矩-独立兑换"的现场）：

1. **截断选择**：取 cₙ = n（随 n 增长的截断水平——保证
   截断后的 Bernoulli 部分有界）。定义 Yₖ = Xₖ·1_{|Xₖ|
   ≤ n}、Zₖ = Xₖ − Yₖ（残尾）；
2. **截断部分**（Chebyshev 路线）：Var(Yₖ) ≤ E[Yₖ²] ≤
   n·E[|X|·1_{|X|≤n}]（关键缩放 |X|² ≤ n|X| 于截断域）；
   P(|Σ(Yₖ−EYₖ)| > nε) ≤ n·E|X|/(n²ε²) = E|X|/(nε²) → 0；
3. **残尾部分**（一阶矩的收费）：P(∃Zₖ ≠ 0) ≤ n·P(|X|
   > n) ≤ E[|X|·1_{|X|>n}] → 0（**一阶矩存在 ⟹ 截尾期望
   收敛**——单调收敛的尾部余项）；
4. **期望对齐**：|EYₖ − EX| ≤ E|Zₖ| → 0。合龙三段。∎

**兑换账**：iid（满独立）买到"只有一阶矩"的低门槛——
若无独立性，Markov 条件需要二阶矩的一致控制（48 章）。
**截断水平 cₙ = n 的选取**是"截断部分方差 → 0 且残尾
概率 → 0"的平衡点——50.6 数值通道的 Pareto 实验正是
这个平衡点的 α = 1 分界现场。

## 50.3.6 习题账单（自检清单）

1. Markov LLN 的 Chebyshev 一行证明与 Markov 条件的
   必要性讨论（一致有界方差 vs 条件本身）；
2. Khinchin 截尾证明的四步完整核算（特别是步骤 3 的
   单调收敛账）；
3. MZ LLN 的 p < 1 情形（b 任意的直觉——重尾时中心
   化无意义）；
4. 圣彼得堡悖论的截尾平均计算（截断到 2^k 的平均 →
   k − 常数——精确的 log 账）；
5. K-F 充要条件的两个方向（n·P(|X|>n) → 0 的截尾收敛
   vs 反例的构造）；
6. 分位数相合性的证明（F⁻¹ 的单调 + Fₙ 的逐点收敛 +
   连续性假设的必要性）。

## 50.4 分布函数与分位数的相合性（袁 19.2）

**Glivenko-Cantelli 的弱版预演（袁 19.2.1-19.2.2）**：
经验 cdf Fₙ(x) → F(x) 逐点（每点用 BC + Khinchin）——
完全一致版本（sup_x |Fₙ − F| → 0 a.s.）在 51 章（强大
数定律的收获）。**样本分位数 → 总体分位数（袁 19.2.3）**：
F⁻¹ 的连续性 + Fₙ 的逐点收敛——统计估计量的渐近理论
第一课（52 章 Delta 方法的入口）。

## 50.4.5 实验断言清单（数值通道验收单）

1. **轨道带**：Bernoulli(p=1/3) 的 |X̄ₙ − p| 轨道在
   ±2/√n 带内（200 轨道 × 10⁴ 步的覆盖率 ≥ 95%）；
2. **Pareto 分界**：α = 2 的均值收敛 vs α = 1 的发散
  （100 万样本的平均轨迹对照——截尾平衡点的现场）；
3. **圣彼得堡**：截尾版（上限 2²⁰）的平均 ~ log₂ n 增长
   vs 不截尾的爆跳；
4. **MZ 速率**：p = 1.5 的 n^{−1/1.5} 归一化和 → 0
  （轨道验证 + 100 次重复的分布）；
5. **分位数**：N(0,1) 的样本中位数 → 0（|med| ~
   √(π/2n) 的速率账）。

## 50.4.6 历史注记

Bernoulli（1713，《推测术》第四部分）证明二项频率的
收敛（史上第一个大数定律——20 年的计算劳动）；Chebyshev
（1867）的概率不等式方法开启了现代路线；Markov（1907）
的链条件（Markov 条件以他命名——不独立情形的第一步）；
Khinchin（1929）的 iid 一阶矩完全体；Kolmogorov（1930）
的强大数定律（51 章）；MZ（1937）的精确速率。**本章的
每个定理都对应一个名字**——概率论的英雄世纪（1713-
1937）在 LLN 一条线上写完。Glivenko-Cantelli（1933）的
完全一致版本启动了现代统计学习理论（VC 维的先声）。

## 50.4.7 三大收敛定理的关系图（本章的坐标系）

本章定理在"独立性 × 矩"平面上的位置（52 章 CLT 与 51 章
SLLN 的邻居图）：

```
矩强度 ↑
  4 阶  |              Berry-Esseen 速率（52）
  2 阶  |  Markov LLN      CLT（52：√n 速率）
  1 阶  |  Khinchin LLN    （CLT 需 2 阶——最小矩）
 <1 阶  |  MZ p<1          （中心化失效）
  ∞阶   |  K-F 充要条件     （无穷期望的细粒度）
        +——————————————————————→ 独立性强度
          iid    独立    两两    Markov条件
```

**读法**：LLN 沿"降矩"轴推进（Khinchin 是极限——iid 的
最低矩）；CLT 卡在 2 阶矩（再低无标准正态极限——重尾
吸引到稳定律，55 章）；SLLN（51 章）在 a.s. 档位上
平行推进。**三条定理线共享本章的截尾/不等式工具**——
48 章的四代引擎在此全部上场。

## 50.5 数值实验

**Julia（`50_lln.jl`）**：① Bernoulli 频率收敛（|X̄ₙ−p|
的轨道带 ~ n^{−1/2}——Chebyshev 界的视觉化）；② Khinchin
的截尾证明现场（E|X| < ∞ 的 Pareto 尾 α = 2 的均值收敛
vs α = 1 的发散）；③ 圣彼得堡模拟（截尾 vs 不截尾的
平均轨迹对照）；④ MZ 速率（p = 1.5 的 |Sₙ − nb|/n^{1/p}
→ 0 的轨道验证）；⑤ 分位数收敛（样本中位数 → 真中位
数的速率）。**Python**：Fraction 精确的 Bernoulli 频率
收敛率（P(|X̄ₙ−p|>ε) ≤ 1/(4nε²) 的精确上界 vs 二项
精确概率）；截尾账的精确分数；MZ 的精确幂。
**Prolog（`50_lln.pl`）**：全程精确有理数（`is` 的分数算术
不落浮点）的弱大数律小账——① n = 20、ε = 1/5 的 Chebyshev
界 `1/(4nε²) = 5/16` **恒等验证**（`Bound =:= 5/16`）压住
二项精确尾概率；② 界的 1/n 衰减做成逐级对半的精确恒等
（B(10) = 2·B(20) = 4·B(40)，`=: =` 判决而非浮点近似）；
③ **圣彼得堡截尾账**：E[X; X ≤ 2^k] = Σ_{j≤k} 2^j·2^{−j−1}
= (k+1)/2 的逐点分数和（每档恰贡献 ½——50.5.5 截尾视角的
机器原文）；④ 同带宽尾概率的单调收缩（n=20 的精确值 <
n=10 的精确值——WLLN 方向性的判决性小样本）。`binom/3`
递归 + `pow2/2` 让这四本账全部在 ℚ 里结清。

## 50.5.5 圣彼得堡悖论的深账（教学价值完全体）

Bernoulli（1738，Daniel）的原始问题：游戏回报 2^k（概率
2^{-k}）——EX = ∞ 但"公平入场费"直觉是有限的。测度论的
三个视角：

1. **截尾视角**（K-F 路线）：截断到 2^m 的游戏期望 =
   m/2 + O(1)——入场费随截断增长；现代金融的风险管理
  （VaR 型尾部截断）同款逻辑；
2. **中位数视角**：median(X̄ₙ) ~ log₂(n)（远小于均值）——
   "平均被极端事件绑架"的定量版本（与 42 章乘积鞅的
   双轨分叉同族：期望 vs 典型轨道的分道）；
3. **效用视角**（原始解）：对数效用下的期望有限——
   效用凹性抵消回报凸性（现代决策论的起点）。

数值实验同时跑三视角（截断平均 / 中位数轨迹 / 对数
效用平均），**一个悖论三个定理**——教学浓缩度极高。
