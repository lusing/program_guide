## 41.1 公平游戏的公理化

赌徒的资本过程 {Xₙ}：每次下注后的累计盈亏。**鞅**（martingale）
= "平均而言不赚不赔"的公理化：

- **鞅**：Xₙ 可积、适应 filtration 𝓕ₙ（信息流），且
  E[X_{n+1}|𝓕ₙ] = Xₙ——已知全部历史，下一步的期望资本
  = 当前资本（公平游戏）；
- **下鞅**（submartingale）：E[X_{n+1}|𝓕ₙ] ≥ Xₙ（有利游戏：
  趋势向上）；**上鞅**（supermartingale）：≤（不利游戏）。

符号约定注意：严书与 mathlib 一致——"sub"指"下界方向"
（E[X|𝓕] ≥ X）。**等价刻画**：鞅 ⟺ 对一切 m < n，
E[Xₙ|𝓕ₘ] = Xₘ（塔性质迭代）；⟺ 差分 Dₙ = Xₙ − X_{n−1}
满足 E[Dₙ|𝓕_{n−1}] = 0（**鞅差列**——新息的语言，36.4.6
投影几何的直接应用）。

**即时例子库**：① 独立零均值部分和 Sₙ = Σξᵢ（E[ξ_{n+1}|
𝓕ₙ] = E[ξ_{n+1}] = 0——新息独立退化）；② 产品鞅
Mₙ = ∏(1+ξᵢ)（对数鞅的指数化——金融数学的标准件）；
③ **Doob-Levy 鞅**：Xₙ = E[X_∞|𝓕ₙ]（任意可积 X_∞ 造出
的一切鞅——L¹ 的投影族，UI 的免费来源（38.4 应用二的
具体化））；④ 凸函数变换：f 凸时 f(鞅) 为下鞅（Jensen 条
件版——251 页的 OCR 现场）；⑤ 非负上鞅的收敛预备。

**凸变换表（严书 8.1 定理）**：f 连续凸 ⟹ f(Xₙ) 下鞅
（X 鞅）；f 连续凸非降 ⟹ f(Xₙ) 下鞅（X 下鞅）——
|X|ᵖ（p≥1）、X⁺、(X−a)⁺ 全是下鞅化工厂。

## 41.2 Doob 分解：趋势与新息的分离

**Doob 分解定理（严书 8.1 / mathlib Centering.lean 的
predictablePart + martingalePart）**：可积适应过程 Xₙ =
**可料部分 Aₙ + 鞅部分 Mₙ**，其中 Aₙ 可料（Aₙ ∈ 𝓕_{n−1}——
"事前可知"）且 A₀ = 0、Mₙ 为鞅。分解唯一。

**构造（数学一行账）**：Aₙ = Σₖ₌₁ⁿ E[Xₖ − X_{k−1}|𝓕_{k−1}]
（条件期望的逐步累积——趋势的条件化提取）；Mₙ = Xₙ − Aₙ
（新息鞅）。**读法**：一切适应过程 = 决定论趋势 + 公平
游戏噪声——计量经济学（趋势分离）、赌徒问题（何时有利
可图）的概念底座。**下鞅 ⟺ 可料部分递增**（趋势单调向上
——Doob-Meyer 分解（连续时间）的离散原型，随机积分论的
起点）。

## 41.3 Doob 极大不等式族

**极大函数**：X*ₙ = max_{k≤n} Xₖ（运行最大值）。**Doob L¹
极大不等式（严书 8.1.9 一带）**：下鞅 X 满足

  λ·P(X*ₙ ≥ λ) ≤ E[Xₙ · 1_{X*ₙ ≥ λ}] ≤ E[Xₙ⁺]

——运行最大超过 λ 的概率被终端值的正部控制（尾概率的
鞅版 Chebyshev 强化）。**证明骨架（严书经典三行）**：
停时 τ = min{k : Xₖ ≥ λ}（首穿时）；{X*ₙ ≥ λ} = {τ ≤ n}；
下鞅的可选停止（X_τ ≤ E[Xₙ|𝓕_τ] 的停时版）给
λ·P ≤ E[X_τ] ≤ E[Xₙ1_{τ≤n}]。∎

**Lᵖ 版（Doob maximal L^p）**：p > 1 时 ‖X*ₙ‖ₚ ≤
q·‖Xₙ‖ₚ（q = p/(p−1)——Hölder 对偶指数）：**鞅的运行
最大值的范数被终端值控制**——Hardy-Littlewood 极大函数
的鞅版（调和分析在概率论的孪生）。证明是分布恒等式
E[(X*)ᵖ] = p∫λᵖ⁻¹P(X*≥λ)dλ + L¹ 版代入 + Hölder 收口。

**上穿不等式（Doob upcrossing，严书 8.1 后段）**：区间
[a,b] 的上穿次数 Uₙ[a,b]（从下于 a 上穿到大于 b 的次数）：

  E[Uₙ[a,b]] ≤ E[(Xₙ − a)⁺]/(b − a)

下鞅"来回穿越"的次数被终端超出量控制——**收敛定理的
发动机**（42 章主角）。mathlib 的 `upcrossingStrat`（上穿
策略——在 [a,b] 区间低买高卖的交易策略）与
`upcrossingsBefore` 把上穿次数类型化；**上穿策略的收益 =
(b−a)·上穿次数**（赌博策略的收益账），下鞅性限制策略
收益 ⟹ 次数控制——证明的全部直觉。

## 41.4 停时与可选停止

**停时**（stopping time）：τ : Ω → ℕ∪{∞} 使 {τ ≤ n} ∈ 𝓕ₙ
（"何时停"只依赖已知信息——不能偷看未来）。停时过程
X_τ、σ-代数 𝓕_τ = {A : A∩{τ≤n} ∈ 𝓕ₙ ∀n}（停时前信息）。

**可选停止定理（optional stopping，严书 8.1 一族）**：τ₁ ≤ τ₂
有界停时、X 鞅（或下鞅）⟹ E[X_{τ₂}|𝓕_{τ₁}] = X_{τ₁}
（≥）——**公平游戏加公平停止规则仍是公平游戏**。有界性
不可省：τ = 首次 Xₙ ≥ 2（简单随机游走），E[X_τ] = 2 ≠
0 = X₀——**无界停时的"等待好运"策略破坏公平性**
（赌徒谬误的数学内核：有限资金的赌徒必败定理的机制）。

**应用**：首穿时分布（反射原理的期望版）、 Wald 恒等式
（E[X_τ] = μE[τ] 的两条件版）、最优停止问题的框架
（Snell 包络 = 最小上控鞅——39 章 ess inf 的下游）。

## 41.4.4b 实验断言清单（数值通道验收单）

1. **鞅轨道**：E[Xₙ] = 0（500 轨道均值 < 0.1·√n 噪声带）
   vs 单轨道极差 ~ √n；
2. **凸工厂**：E|Xₙ| ≈ √(2n/π)（精确公式对拍）；
3. **Doob L¹**：λP(X*ₙ ≥ λ) ≤ E[Xₙ⁺] 逐 λ（λ = 2,5,10
   的采样账全部 ≤）；
4. **L² 版**：‖X*‖₂ ≤ 2‖Xₙ‖₂（采样范数比 < 2）；
5. **上穿**：Uₙ 均值 ≤ E[(Xₙ−a)⁺]/(b−a)；
6. **可选停止双面**：有界停时公平 vs 无界首穿的
   E[X_τ] = 2、E[τ] = ∞ 双账。

## 41.4.5 上穿策略的账本（证明的赌博直觉）

Doob 上穿不等式的经典证明是一个**交易策略的收益账**：
在 X < a 时买入一股、X > b 时卖出（[a,b] 区间的低买高卖）。
策略可料（仓位只依赖历史——41 章可料性），其收益 =
(b−a)×上穿次数 − 持仓期的期末浮亏。两个关键账目：

1. **下鞅限制策略期望**：可料策略作用于下鞅的收益期望
   ≥ 0（43 章变换引理的逆用）——下鞅的"上涨趋势"使
   低买高卖期望不亏；
2. **收益分解**：(b−a)·Uₙ[a,b] − (Xₙ − 买点的末段账)
   ≤ 策略总收益 ≤ E[(Xₙ − a)⁺]（末段浮亏被正部控制）。

合龙即 E[Uₙ] ≤ E[(Xₙ−a)⁺]/(b−a)。∎——**"一切鞅式不等式
都是某个交易策略的盈亏封顶"**（Doob 原话的精神）：概率
不等式的证明文化在这里与金融直觉合流。mathlib 的
`upcrossingStrat` 正是把这个策略显式定义（346 行起）——
形式化直接继承了赌博论证的骨架。

**历史注记**：Doob（1940s，Illinois）系统化了离散鞅论
（"stochastic processes"一书 1953）；"martingale"一词源自
赌博术语（法国 provincial 的马具/赌博双关——Hausdorff
时代的数学幽默）。上穿不等式是 Doob 对 Ville（1939）工作的
关键改进——收敛定理的完整钥匙。

## 41.6 数值实验：公平游戏的账本

**Julia（`41_martingale_inequalities.jl`）**：

- **鞅的轨道**：简单随机游走 200 步 × 500 条轨道——
  E[Xₙ] = 0 恒定（期望平的）vs 单条轨道的剧烈波动
  （"平均公平 ≠ 个体安稳"）；
- **凸变换工厂**：|Xₙ| 的均值单调上升（|鞅| 是下鞅的
  轨道级证据：E|Xₙ| = √(2n/π) 增长）；
- **Doob L¹ 版**：P(X*ₙ ≥ λ)·λ vs E[Xₙ⁺] 的逐 λ 验证
  （λ = 2, 5, 10：不等式逐档成立）；
- **Lᵖ 版**：‖X*ₙ‖₂ ≤ 2‖Xₙ‖₂（q=2 的具体账：max 范数
  ≤ 2 倍终端范数——随机游走的精确值 √n 对拍）；
- **上穿计数**：随机游走在 [−1, 1] 的上穿次数 Uₙ vs
  E[(Xₙ−a)⁺]/(b−a) 上界（n = 1000 的模拟均值对照）；
- **可选停止的双面**：有界停时 τ = min(n₀, 首穿 2) 的
  E[X_τ] ≈ 0（公平保持）；无界 τ = 首穿 2 的 E[X_τ] = 2
  （公平破产——但 E[τ] = ∞ 的账面同时打印）。

**Python（`41_martingale_inequalities.py`）**：Fraction 精确
版——有限二叉树鞅（½ 上 ½ 下）的全树期望账、Doob 分解
的精确拆解（可料 + 鞅分量的逐步账）、上穿不等式的精确
分数验证。

## 41.7 要点回顾

1. 鞅 = 条件公平（E[X_{n+1}|𝓕ₙ] = Xₙ）；凸变换工厂
  （f(鞅) 下鞅）；Doob-Levy 鞅 = 投影族的完全体。
2. Doob 分解：X = 可料趋势 + 新息鞅（唯一）；下鞅 ⟺
   趋势递增——Doob-Meyer 的离散原型。
3. Doob 极大不等式：L¹ 版（停时三行证明）与 Lᵖ 版
  （q 倍控制）；上穿不等式 = 收敛定理的发动机。
4. 可选停止：有界停时保公平；无界停时的赌徒谬误现场
  （首穿时 E[X_τ] ≠ X₀ 但 E[τ] = ∞）。
5. 机器侧：mathlib Submartingale/Doob 分解/上穿策略族；
   数值通道公平游戏账本与破坏现场。
