## 19.1 从乘积测度到"逐点换配方"

第 18 章的 μ×ν 是**一张固定的配方**：第二坐标的测度 ν 不随
第一坐标走。但现实世界的模型几乎全是"看菜下饭"：马氏链的
下一步分布依赖当前位置（转移概率）、条件分布 Y|X=x 随 x 变、
信号处理的观测核 P(观测|状态)。数学对象是**转移核**：

  K : X × B → [0,∞]（或 [0,1] 为概率核）

满足两条：**(1) 固定 x**，K(x, ·) 是 (Y,B) 上的测度（概率核则
是概率）；**(2) 固定 B**，x ↦ K(x,B) 可测。第二条是"参数依赖
的可测性"——它保证后面一切积分良定义，也是核与"任意二元
集函数"的分界线。

**极端情形校准**：常值核 K(x,B) = ν(B)（不看 x）退化成乘积
测度的配方；dirac 核 K(x,B) = I_B(f(x)) 是确定性映射 f 的
"噪声版零份"。核 = 介于"完全独立"与"完全确定"之间的整个
谱系，乘积测度只是谱系的一端。

## 19.2 由核造测度：μK 与核版 Fubini

给定 (X,A) 上测度 μ 与核 K，定义

  μK(B) := ∫ K(x,B) μ(dx)——B 的账 = 逐 x 报价再平均。

可测性条款 (2) 使被积函数合法；μ σ-有限（或 K σ-有限核）时
μK 是测度（σ-可加性 = 被积函数的逐点 σ-可加性 + MCT）。
K = 常值 ν 时 μK = μ×ν 限制在"第二因子"上的像——μK 就是
μ×ν 的直接推广。

**核版 Fubini（严书习题 4.3.1）**：f 为 X×Y 可测、关于 μK
可积（或非负）⟹

  ∫ f d(μK) = ∫[∫ f(x,y) K(x,dy)] μ(dx)

且内层对 μ-a.e. x 良定义。证明与第 18 章同骨架：指示函数 =
定义，线性 → 简单，MCT/控制收敛收满。**注意方向不对称**：
核版 Fubini 只有一个方向的累次积分（先 y 后 x）——先 x 后 y
的"对称版"需要逆向核，一般不存在（这就是条件结构的箭头性：
第 37 章正则条件分布的定向伏笔）。

**集函数版截口**：E ∈ A ⊗ B 时 x ↦ K(x,E_x) 可测且
(μK)(E) = ∫K(x,E_x)μ(dx)——第 18 章截口定理的核化，Good 集
证明照抄，矩形一步换成 K(x, (A×B)_x) = I_A(x)K(x,B)。

## 19.3 核的复合：两步走

两个核 K₁（X→Y）、K₂（Y→Z）的**复合**

  (K₁ ⊗ K₂)(x, C) := ∫ K₂(y, C) K₁(x, dy)

——"先按 K₁ 走到 y，再从 y 按 K₂ 走"的两步转移。恒等核
I(x,B) = δ_x(B)（dirac）是复合的单位元：I ⊗ K = K ⊗ I = K。
结合律 ((K₁⊗K₂)⊗K₃ = K₁⊗(K₂⊗K₃)) 是 Fubini 对三因子的
应用——"先走完前两步再走第三步"与"先走后两步再补第一步"
总账相同。

**与测度的相互作用**：μ(K₁⊗K₂) = (μK₁)K₂——先复合核再
平均，与先平均再走，结果一致（核版 Fubini 的直接推论）。
这就是 **Chapman-Kolmogorov 方程**的测度语言：马氏链 n+m 步
转移核 = n 步核 ⊗ m 步核，"两段旅程拼接"不依赖中间站的
停留细节。

## 19.3.5 可测性条款为何不可省

条款 (2)（x ↦ K(x,B) 可测）看起来是技术装饰，实际是 μK
存在的**承重墙**：若允许不可测依赖，取 B 上的符号"核"
K(x,B) = I_B(0)·g(x)，其中 g 不可测——则 μK(B) = ∫g dμ
直接无定义；更隐蔽的事故是**可加性漂移**：K(x,·) 逐点可加
但 μK(B) = ∫K(x,B)dμ 的被积函数族 {K(·,B)}_B 不同时可测
时，"逐点 σ-可加 ⟹ 积分后 σ-可加"的 MCT 搬运一步都迈不出。
数值通道造不出不可测性（有限模型里一切可测），这是本章
docs 侧必须讲透、机器侧只能"正面用"的一处不对称——形式化
通道里 `Kernel` 类型的定义**内置**可测性字段，负面案例由
类型系统挡在门外（mathlib 的 `Kernel α β := ∀ x, Measure β`
+ `IsMarkovKernel`/可测性 packed 的一族 def——正名见 19.6）。

**有限世界的诚实说明**：Julia/Python 的"核"只是矩阵
K[x, B]——有限指标集上一切函数可测，条款 (2) 自动真。数值
实验验证的是**账目恒等式**（Fubini/CK/复合），不是可测性
本身；这一点在对照形式化通道结论时须分清。

## 19.3.6 n 步递归与平稳分布的细账

马氏链的 n 步核满足递归 K^{(n+1)} = K^{(n)} ⊗ K（Chapman-
Kolmogorov 的算子版）。两态例子（P = [[0.7,0.3],[0.4,0.6]]）
的显式对角化把递归解成闭式：

- 特征值 λ₁ = 1（平稳方向）、λ₂ = 0.3；
- Pⁿ = π·1ᵀ + λ₂ⁿ·(修正幂)，其中 π = (4/7, 3/7) 为平稳行
  向量；
- 于是 |μₙ(i) − π(i)| ≤ C·0.3ⁿ——**收敛速率完全由次特征值
  决定**，初始分布只进常数 C。

这笔账是第 50/51 章大数定律的"有限态预演"：大数定律讲
时间平均 → 期望，马氏链收敛讲分布 → 平稳；两者在高斯/
独立情形汇合（ergodic 定理的离散影子）。数值通道用 0.3ⁿ
的指数拟合验证次特征值预言——**定理（线性代数）与实验
（迭代）在同一张账上签字**。

## 19.4 独立、条件与核的谱系表

| 场景 | 核 | 产出的测度 | 章节 |
|---|---|---|---|
| 独立乘积 | K(x,B) = ν(B) | μK = μ×ν | 第 18 章 |
| 确定映射 | K(x,B) = I_B(f(x)) | μK = 像测度 f(μ) | 第 07 章 |
| 马氏链一步 | 转移矩阵 P(x,dy) | 初始 ⊗ n 次复合 = n 步分布 | 本章 |
| 条件分布 | K(x,dy) = P(Y∈dy \| X=x) | μK = 联合分布 | 第 37 章 |
| Tulcea 构造 | 逐坐标核列 | 无穷乘积概率 | 第 21 章 |

表的读法：第 18 章乘积测度与第 07 章像测度都是核的两个端点，
本章把它们连成一条线，第 21 章把这条线拉到无穷维——**核是
"逐坐标装配测度"的通用零件**。严书 §4.5 Tulcea 定理的证明
本质就是"无穷次核复合"的相容性验收。

**配对与乘积核**：两个核 K（X→Y）、L（X→Z）还可**并排**
装配：(K ⊗̃ L)(x, dydz) := K(x,dy)·L(x,dz)——"同一起点、
两个独立分身"。mathlib 的 `Kernel.prod` 与复合 `Kernel.comp`
是两种不同的二元运算（并排 vs 串联），记号分别为 `κ ⊗ₖ ν`
与 `κ ⊗∘ ν` 类（正名以 #check 为准）——**串联制造马氏依赖，
并排制造条件独立**，第 37 章正则条件分布与第 41 章鞅的合成
滤波都要在两者间来回切换。

## 19.5 马氏链：核复合的数值显影

两状态马氏链 P = [[0.7,0.3],[0.4,0.6]]，初始 μ₀ = (1,0)：

- 一步分布 μ₁ = μ₀P：核 Fubini 的矩阵乘法原文；
- 两步分布 μ₂ = μ₁P = μ₀(P⊗P)：**核复合 = 矩阵乘方**，
  Chapman-Kolmogorov 的有限态全文；
- n → ∞：μₙ → 平稳分布 π = (4/7, 3/7)（解 πP = π）——
  收敛速率由 |λ₂| = 0.3（次特征值）控制。数值通道对拍
  μₙ 与 π 的差随 n 指数衰减。

这个例子把抽象的 (K₁⊗K₂) 落成可手算的矩阵乘法——教学上
是"核 = 泛化的转移矩阵"的最短路径。

## 19.6 Lean：Kernel 一族（B4 实测定名）

mathlib 的核是 `Kernel α β`（`α → Measure β` + 内置可测性，
Probability/Kernel/ 文件族）。复合 `Kernel.comp`（**记号 `∘ₖ`**，
Composition/Comp.lean）；**单位元是 `Kernel.id`**（不是 dirac！
单位律 `id_comp`/`comp_id`）；dirac 型核叫 **`Kernel.deterministic
f hf`**（Basic.lean:59，逐点账 `deterministic_apply`——参数序
可测性证明在前、点在后）。金子引理：**`deterministic_comp_
deterministic`（CompMap.lean:50）：确定性核的复合 = 映射的
复合**——核复合在"完全确定"端退化为函数复合。`Ch19Kernels.
lean` 实弹：

1. **锚点 #check**：`comp`/`id`/单位律两件/`comp_apply`/
   `deterministic`/`deterministic_comp_deterministic`/`prod`；
2. **单位律**：`id ∘ₖ κ = κ` 与 `κ ∘ₖ id = κ`；
3. **两步转移**：布尔翻转核 κnot = deterministic not，两次复合
   = 恒等——`deterministic_comp_deterministic` + `not_not` +
   逐集账（`ext` + `deterministic_apply`/`id_apply`）三行收口，
   "矩阵乘方"的两态原文。

## 19.7 数值实验

**Julia（`19_kernels.jl`）**：两态马氏链全流程（一步/两步/n 步
分布、Chapman-Kolmogorov 数值恒等式 (P²)ᵢⱼ = ΣₖPᵢₖPₖⱼ 逐
项、平稳分布收敛速率 |μₙ-π| ≈ C·0.3ⁿ 拟合）；核版 Fubini 的
连续版：μ = [0,1] 均匀、K(x,·) = N(x, 0.1) 高斯核，
∫f d(μK) 的"逐 x 报价再平均"与直接卷积积分对拍（数值积分
误差 < 1e-8）。

**Python（`19_kernels.py`）**：Fraction 精确版马氏链（P 用
有理数 7/10 等）——两步分布精确账、平稳分布 π = (4/7,3/7)
的精确解与迭代逼近误差的整数账；核版 Fubini 在离散 μ、K 上
的精确双重和。

**Prolog（`19_kernels.pl`）**：符号复合——核表示为
`k(Name, X, Y, P)` 事实表，复合谓词 `kcomp/4`（枚举中间态
求和）、`markov/3`（n 步分布的递归计算）、Chapman 恒等式
的穷举验证（两态全查）。

## 19.7.5 实验断言清单（数值通道的验收单）

三通道各出一张可判定的断言单，全部 `@assert` 化：

1. **一步账**：μ₀ = (1,0) 时 μ₁ = (0.7, 0.3)（一行矩阵乘）；
2. **两步账**：μ₂ = (0.61, 0.39)（0.7·0.7+0.3·0.4 = 0.61——
   Julia/Python 双通道同账，Fraction 精确 61/100）；
3. **Chapman 恒等式**：(P⊗P)ᵢⱼ = ΣₖPᵢₖPₖⱼ 四个分量逐一核对
  （0.61 = 0.49+0.12、0.39 = 0.21+0.18、0.58 = 0.28+0.24…
   精确分数账）；
4. **平稳分布**：πP = π 的解 π = (4/7,3/7)（Python 解线性
   方程组精确；Julia 数值解 1e-15 内）；
5. **收敛速率**：|μₙ(1) − 4/7| / 0.3ⁿ 有界（n 到 40，比值
   序列有界性验证次特征值预言）；
6. **核版 Fubini（连续）**：μK 的"逐 x 报价"与卷积闭式
   ∫φ(y−x)w(x)dx 双算法对拍 < 1e-8。

## 19.8 要点回顾

1. 核 = 逐 x 可测的测度族；可测性条款是参数依赖的入场券。
2. μK 造测度 + 核版 Fubini（单向累次！）；集函数版截口
   x ↦ K(x,E_x) 可测。
3. 复合 K₁⊗K₂ = 两步转移，dirac 是单位元，结合律 = 三因子
   Fubini；μ(K₁⊗K₂) = (μK₁)K₂ 即 Chapman-Kolmogorov。
4. 谱系表：乘积测度/像测度/条件分布/无穷乘积都是核的站位；
   第 21 章 Tulcea 是无穷次复合的验收。
5. 机器侧：`Kernel.comp`/`prod`/`dirac`/核 Fubini 族；
   数值通道把复合落成矩阵乘方。
