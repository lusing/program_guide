## 49.1 为什么特征函数是概率论的第一工具

第 44 章已立起 Bochner 框架（正定性 + 连续性 ⟺ 特征
函数）。本章按袁书 17-18 的路线补全**应用层**：

1. **计算库**：常见分布的 φ 速查（Gauss/Cauchy/Poisson/
   二项/均匀/指数——逐个手算，数值对拍）；
2. **三大定理**：唯一性（44 章 ext_of_charFun 机器版）、
   **Lévy 连续性定理**（φₙ → φ 连续于 0 ⟹ μₙ ⇒ μ——弱
   收敛的调和判据）、矩-导数词典（φ 的 k 阶导 = i^k E X^k）；
3. **判别**：非负定性（Bochner/Pólya）、增量不等式、
   截尾不等式（袁 17.2-17.4）；
4. **应用初步（袁 18）**：Lévy 等价定理、正态逼近（De
   Moivre-Laplace）、Pearson χ² 渐近、非中心 χ²（统计
   理论的调和地基）。

**设计哲学**：分布的卷积在 φ 侧变成**乘法**（35 章卷积
↔ 独立性的调和翻译）、收敛在 φ 侧变成**逐点收敛**——
**一切难算的测度论操作被 φ 侧的初等运算替代**。这就是
概率论的"取对数"（乘法 → 加法的经典技巧的分布版）。

## 49.2 计算库（袁 17.1 的速查表 + 补充）

| 分布 | φ(t) | 备注 |
|---|---|---|
| δ_a | e^{ita} | 点质量 |
| Bernoulli(p) | q + pe^{it} | 两点 |
| Bin(n,p) | (q+pe^{it})ⁿ | 卷积幂 |
| Poisson(λ) | e^{λ(e^{it}−1)} | 跳过程 |
| U[a,b] | (e^{itb}−e^{ita})/it(b−a) | 均匀 |
| Exp(λ) | λ/(λ−it) | 指数 |
| N(μ,σ²) | e^{itμ−σ²t²/2} | **主角** |
| Cauchy | e^{−\|t\|} | 重尾无矩 |
| Gamma(α,λ) | (λ/(λ−it))ᵅ | Exp 的幂 |

**三条即时组合律**：独立和 = 乘积；n 倍 = 幂（X₁+…+Xₙ
iid ⟹ φⁿ）；位置缩放 φ_{aX+b}(t) = e^{itb}φ_X(at)。

## 49.3 Lévy 连续性定理（袁 17.3.2）

**定理**：{μₙ} 概率测度列、φₙ 其特征函数。若 φₙ(t) →
φ(t) 逐点且 **φ 在 0 处连续**，则 φ 是某概率测度 μ 的
特征函数且 μₙ ⇒ μ（弱收敛）。

**证明骨架（袁 17.3 的三步）**：

1. **胎紧性**：φₙ 在 0 的连续性（一致）给质量紧吸收
  （|1 − φₙ(t)| 小 ⟹ 分布质量集中于有限区间——截尾
   积分账）——32 章 Prokhorov 的一维入口；
2. **任意子列的极限识别**：Helly 子列（30 章）的极限
   μ* 的 φ* = φ（被积函数的收敛传递——控制收敛）；
3. **极限唯一 ⟹ 全列收敛**（32 章三步模板的最后一击：
   子列极限的唯一性 ⟹ 整列收敛）。∎

**核心地位**：这是 CLT（52 章）证明的**唯一**收敛引擎
——"特征函数逐点收敛 + 0 处连续"的检查比直接验证弱
收敛容易百倍。

**逆定理**：μₙ ⇒ μ ⟹ φₙ → φ 逐点（有界连续检验的
特例）——**等价成立**（袁 18.1 的 Lévy 等价定理）。

## 49.4 矩与导数（袁 17.5）

**词典**：E|X|^k < ∞ ⟹ φ 的 k 阶导数存在且 φ^{(k)}(0) =
i^k E[X^k]。反向：φ 在 0 处 2k 阶可导 ⟹ E|X|^{2k} < ∞
（偶数阶的双向——奇数阶只有单向）。**注意**：φ 可微
与矩存在**不等价**（奇数阶的反例——袁书 17.5 的细节
讨论）。

**Taylor 展开的操作**：φ(t) = 1 + itEX − t²EX²/2 + o(t²)
（二阶矩存在时）——**52 章 CLT 证明的核心公式**（φ 的
对数展开到二阶）。数值通道在网格上验证展开精度。

## 49.4.5 Lévy 连续性证明的细节账（三步的完整解剖）

第一步（胎紧）的核心计算（袁 17.3 的截尾积分账）：

  |1 − φₙ(t)| 小 ⟹ ∫(1 − cos(tx))dμₙ(x) 小（Re 部）
  ⟹ 对适当的 T：μₙ(|x| > 2/T) 有界（1 − cos ≥ c 于
  |tx| ≥ 2 的区域——振荡平均下的正下界）。

**一致性问题**：φₙ 在 0 处的连续性必须**关于 n 一致**
（否则某些 μₙ 的质量可以逃逸）——逐点收敛 φₙ(t) → φ(t)
在**每个固定 t** 处给了一致性（|φₙ(t)−φ(t)| ≤ ε 对 n ≥
N(t)）——固定一个 t 即可（单点截账）。**技巧的关键**：
不需要全局一致，只需一个 t 的窗口。

第二步（Helly + 传递）：30 章的子列 μ_{nₖ} → μ*（淡收敛
可能亏质量）；φ_{nₖ} → φ 的逐点 + Lebesgue 控制收敛给
φ* = φ（被积函数 |e^{itx}| = 1 一致有界——DCT 全额
适用）；**亏质量排除**：φ 在 0 连续 ⟹ μ* 是概率（亏
额会使 φ*(0) < 1 但 φ(0) = 1）。

第三步（唯一 ⟹ 全列）：一切收敛子列的极限有同一 φ =
φ_μ ⟹ 同一 μ（唯一性）——若全列不收敛则存在 ε-分离
子列，其 Helly 子子列收敛到同一 μ，矛盾。∎

## 49.4.6 习题账单（自检清单）

1. 计算库九行的每一行手算（指数/均匀/Cauchy 的积分
   是练习的重点——对称性的使用）；
2. 证明三条组合律（独立和/幂/位置缩放）；
3. Lévy 连续性三步的每步独立验证（特别是第一步的
   截尾积分账的常数选取）；
4. De Moivre-Laplace 的 φ 侧证明（(q+pe^{it/√{npq}})ⁿ →
   e^{−t²/2} 的对数展开到二阶——52 章的完整版预演）；
5. 矩-导数词典的反例构造（奇数阶单向性——E|X| = ∞
   但 φ' 存在的对称分布）；
6. Gamma(α,λ) 的 φ 计算与 χ² 的特例核对。

## 49.5 应用初步（袁 18）

**Lévy 等价定理（袁 18.1.1）**：μₙ ⇒ μ ⟺ φₙ → φ（弱
收敛的完全调和刻画）。推论：连续映射 + Cramér-Wold 的
φ 版（多维经一维线性组合的 φ 检查）。

**De Moivre-Laplace（袁 18.1.2）**：Bin(n,p) 标准化 →
N(0,1)——**CLT 的第一个特例**（φ 侧三行：(q+pe^{it/√})ⁿ
→ e^{−t²/2}——52 章的预演）。

**正态抽样分布（袁 18.1.3-18.2）**：样本均值/样本方差
的 φ 计算；χ² 分布的 φ = (1−2it)^{−n/2}（Gamma 的
特例）；非中心 χ² 的 φ——统计推断的三大分布在 φ 侧
的统一账。

## 49.5.5 实验断言清单（数值通道验收单）

1. **闭式对拍**：Gauss/Poisson/Exp/Cauchy 的 φ 数值积分
   （Simpson，误差 < 1e-5）vs 闭式（逐 t 网格）；
2. **乘积律**：Exp(1)+Exp(1) 的 φ（数值卷积或直和）=
   Gamma(2,1) 的 φ = (1−it)^{−2}；
3. **Lévy 显影**：Bin(n, 1/3) 标准化的 φ_n(t) 逐 t →
   e^{−t²/2}（n = 10..1000 的收敛表）；
4. **Taylor 二阶**：N(0,1) 的 φ − (1 − t²/2) = O(t³) 的
   实测余项（|t|³/6 界）；
5. **词典**：Exp(1) 的 φ'(0)/i = 1 = EX（数值微分 vs
   解析）。

## 49.6 数值实验

**Julia（`49_characteristic_functions.jl`）**：① 计算库
的 φ 数值积分 vs 闭式（Gauss/Poisson/Exp/Cauchy 四个）；
② 独立和乘积律（Exp+Exp 的 φ 乘积 vs Gamma(2) 的 φ）；
③ Lévy 连续性的数值显影（Bin(n, 1/3) 标准化的 φ →
Gauss 的 φ——逐 t 的收敛账）；④ Taylor 展开的精度
（N(0,1) 的 φ 二阶展开误差 ~ t³）；⑤ 矩-导数词典
（数值微分 φ'(0)/i vs EX）。**Python**：Fraction/精确的
两点-Poisson-Bin 的 φ 代数；De Moivre-Laplace 的极限
账（(cos(t/√n))ⁿ → e^{−t²/2} 的精确对拍）。
**Prolog（`49_characteristic_functions.pl`）**：把复值 φ 拆成
实/虚两柱的符号小账——① **Euler 账**：两点 ±1 各 ½ 的
φ(t) = (e^{it}+e^{−it})/2，虚部 sin 奇性对消、实部落回
cos t（计算库第一行的 Prolog 原文）；② Bin(2,½) 的
Re/Im 闭式（1/4 + ½cos t + ¼cos 2t；½sin t + ¼sin 2t）
与归一 φ(0) = 1（实部分数和恰等于 1，Prolog `=:=` 判决）；
③ **矩-导数词典**的差分实现：φ'(0) = i·EX（虚部一差 →
EX = 1）、−φ''(0) = EX²（实部对称二差 → EX² = 3/2，
即 Var + (EX)² = ½ + 1 的账）；④ **独立和 = 乘积**：X+Y 直算
（支撑 {2,0,−2} 概率 {¼,½,¼}）vs cos²t 恒等——49.3
卷积→乘法字典律的最小机器证。

## 49.5.6 Isabelle 侧的锚点（MT49）

Isabelle `Probability/Characteristic_Functions.thy`：
`char_distribution`（分布的特征函数）与 `char_integral`
（积分表示）。`MT49/T49_CharFunctions.thy` 实弹：有限
计数空间上特征函数的显式计算（两点分布的 cos 型闭式 +
归一账 φ(0) = 1）——与 Lean 侧 charFun 的有限维对照。

**数值通道的读图钥匙**：一切 φ 实验的合法性锚是 Bochner
（44 章）——数值积分算出的 φ 自动满足正定性（Gram 矩阵
半正定检查的隐性验证）；闭式对拍的误差带是 Simpson 积分
的 O(h⁴) 项。这两条让"φ 侧的一切计算"成为最可靠的数值
实验族之一。

## 49.6.5 历史注记

Lévy（1925，博士论文）引入特征函数方法；Kolmogorov
（1933）的公理化书将其确立为概率论标准工具。Lévy 连续
性定理（原版 1937 教材）的"0 处连续"条件由 Gnedenko
推广到一般距离空间。Cramér（1946）的《统计数学方法》
把 φ 方法带进统计推断（Chapter 10 的 φ 侧三大分布）。
现代发展：φ 的数值反演（金融期权的 Carr-Madan 方法）与
特征函数的随机化（Levy 过程的完全理论）延续着这条线。
mathlib 的 `charFun` 形式化是 2020s 的产物——本章四锚
（charFun/ext/conv/gaussianReal）是三百年调和传统的
类型化终点。

## 49.7 要点回顾

1. φ = 分布的调和护照：卷积→乘法、收敛→逐点、矩→导数。
2. 计算库九行 + 三组合律——一切常用分布的 φ 手到擒来。
3. Lévy 连续性（胎紧+Helly+唯一）= CLT 的唯一引擎；
   Lévy 等价 = 弱收敛的完全调和刻画。
4. 矩-导数词典（偶数阶双向）；Taylor 到二阶 = 52 章
   的核心公式。
5. 机器侧：mathlib charFun 全家（44 章复用）；数值
   通道的闭式对拍与收敛账。
