## 48.1 为什么需要整整一章的不等式

第 35-47 章的机器（独立性/条件期望/鞅/收敛）在极限定理中
扮演"发动机"，但一切定量的**尾概率控制**都靠不等式家族。
袁书第 14 章按历史与逻辑的四代分档：

| 代 | 不等式 | 控制对象 | 章 |
|---|---|---|---|
| 一代 | Chebyshev/Markov | 单变量二阶矩 | 10 |
| 二代 | Lévy/Ottaviani/Kolmogorov max | **部分和的最大值** | 本 |
| 三代 | MZ/Rosenthal | 高阶矩的幂结构 | 本 |
| 四代 | Hájek-Rényi/Etemadi/HJ | **下鞅型时变控制** | 本 |

每一代解决上一代的瓶颈：一代给 Sₙ 的偏差但看不见 max Sₖ；
二代看 max 但要独立性；三代放宽到高阶矩；四代到鞅与次对角
结构。**现代概率论的定量层就是这四代的组合技**。

## 48.2 截尾术与 Chebyshev 精确化（袁 14.1-14.2）

**截尾术（Yuan 14.1.2）**：X 的 c-截断 X^c = X·1_{|X|≤c}
（或中心化版本）——把重尾砍成轻尾 + 剩尾概率的记账。
Chebyshev 的截尾版：

  P(|Sₙ − ESₙ| ≥ x) ≤ Var(Sₙ^c)/x² + n·P(|X| > c)
——两项的取舍（截断水平的调参）是一切"截尾-中心化"证明
的标准动作（第 50 章 Markov LLN 的引擎、51 章 K-F 定理）。

**Chebyshev 最优性（袁 14.1 例）**：两点分布 ±x 达到等号
——界不可改进。**c_r 不等式（Yuan 14.1.3）**：
E|X+Y|^r ≤ c_r(E|X|^r + E|Y|^r)（c_r = 1 或 2^{r−1}）——
和的矩控制（凸性 + 对称化）。mathlib 侧 Chebyshev 的手作
先例在第 10 章（Markov 两行内核）；本章补截尾版账。

## 48.3 最大值不等式：二代三连（袁 14.2/14.4）

**Lévy 不等式（1937，袁 14.2.2）**：Xᵢ 对称 iid、Sₖ 部分和：

  P(max_{k≤n}(Sₙ − Sₖ) ≥ x) ≤ 2·P(Sₙ ≥ x)——**尾部和的
  最大值被终端的 2 倍控制**。对称性的几何（反射原理的
  期望版）。证明思想：对称过程的"最后一次越界"事件的
  配对反射。

**Ottaviani 不等式（袁 14.4.2）**：无对称性要求，用分离
参数 h：

  P(max|Sₖ| ≥ x+y) ≤ P(|Sₙ| ≥ x) / (1 − maxP(|Sₙ−Sₖ| > y))——
  分母的"一致性"来自独立增量（第 41 章 Doob 极大不等式
  的概率版表亲）。

**Kolmogorov 最大值不等式（袁 14.4.3）**：独立零均值：

  P(max_{k≤n}|Sₖ| ≥ x) ≤ E[Sₙ²]/x² = Σσᵢ²/x²——
  **部分和的最大值的二阶矩控制**（单变量 Chebyshev 的
  max 升级——运行最大值不消耗更多预算）。证明：停时
  分解（首穿集上 Sₙ² ≥ x² 的条件期望）——Doob L¹ 极大
  不等式（41 章）的独立和特例。

## 48.4 高阶矩与下鞅型（袁 14.3-14.4 后段）

**Marcinkiewicz-Zygmund 不等式（袁 14.3.1）**：独立零均值
（或鞅差）、p ≥ 1：

  E|Sₙ|^p ≤ C_p·E(Σξₖ²)^{p/2}——**和的 Lᵖ 范数被平方
  和的 L^{p/2} 控制**（Khinchin 型不等式的独立版；常数
  C_p 只依赖 p）。证明的骨架是 Burkholder 的好 λ 不等式
  （分布式递归）——现代鞅论的基础件。

**Rosenthal 不等式（袁 14.3.2）**：独立（不必零均值）：

  E|Sₙ|^p ≤ C_p·max(ΣE|ξₖ|^p, (ΣEξₖ²)^{p/2})——
  **"重尾主导"与"轻尾组合"两 regime 的取大**（MZ 的
  加项补齐：非中心化的个体矩）。应用：高阶矩的 UI 判据
 （38 章 p > 1 一致矩的推广形式）。

**Hájek-Rényi 不等式（袁 14.4.4）**：独立 + 非增正序列
{cₖ}：

  P(max_{k≤n} cₖ|Sₖ| ≥ x) ≤ Σcₖ²σₖ²/x²——**时变加权的
  最大值控制**（Kolmogorov max 的加权版；cₖ = n/k 给出
  强大数定律的收敛速率——51 章的主引擎）。

**Etemadi 不等式（袁 14.4.1）**：两两独立：

  P(max|Sₖ| ≥ 3x) ≤ 3·maxP(|Sₖ| ≥ x)——**两两独立够用**
  （SLLN 的独立性强放松）；**Hoffmann-Jørgensen（袁
  14.4.5）**：tail 的迭代收敛结构（高矩的递归降阶）。

## 48.4.5 Kolmogorov 最大不等式的三行证明（心脏解剖）

运行最大值"不消耗预算"的精确机制（独立情形的三行账）：

  定义停时 τ = min{k : |Sₖ| ≥ x}（首穿时——41 章工具）。
  分解：{max ≤ n} = ⊔_{k=1}^n {τ = k}（可测分划）。则

  E[Sₙ²] ≥ Σₖ E[Sₙ²·1_{τ=k}] = Σₖ E[Sₖ²·1_{τ=k}] + 交叉项

  交叉项 = ΣₖE[2Sₖ(Sₙ−Sₖ)1_{τ=k}] = 0（**独立性 + 零均值**：
  Sₙ−Sₖ 独立于 σ(S₁,…,Sₖ) ⊇ {τ=k}——E[(Sₙ−Sₖ)|前 k 步] =
  0）。所以 E[Sₙ²] ≥ ΣₖE[Sₖ²1_{τ=k}] ≥ x²·P(max ≥ x)。∎

**与 Doob 的关系**：这个三行账在 41 章以"下鞅的停时单边
性"的形式重演——独立性 + 零均值恰是"Sₖ 是鞅"的两个充分
条件。**一切极大不等式的证明母型**。

## 48.4.6 习题账单（自检清单）

1. Chebyshev 取等的两点分布验证（袁 14.1 例的完整计算）；
2. c_r 不等式的凸性证明（r ≥ 1 与 r < 1 的两段）；
3. Lévy 不等式的反射配对证明（对称性在哪里用——非对称
   情形给反例）；
4. Ottaviani 分母的一致性估计（独立增量 + 三角不等式）；
5. Kolmogorov max 的三行证明细节（交叉项为零的条件
   逐一检查）；
6. MZ 的 p = 2 情形手算（就是恒等式——Khinchin 的原型）；
7. Rosenthal 两 regime 的"取大"结构（轻尾 regime 的
   (Σσ²)^{p/2} 与重尾 regime 的 ΣE|ξ|^p 何时主导——给
   出两 regime 的分界参数）；
8. Hájek-Rényi 的 cₖ = n/k 情形与 SLLN 速率的关系。

## 48.5.5 实验断言清单（数值通道验收单）

1. **取等现场**：两点 ±x 的 P(|X|≥x) = Var/x² 精确相等
  （Fraction 零误差）；
2. **Kolmogorov max**：P(max_{k≤n}|Sₖ| ≥ x) 的 10⁵ 模拟
   vs Σσ²/x² 上界（逐 x = 1..5 的带图对拍）；
3. **Lévy 2 倍常数**：对称情形 P(max(Sₙ−Sₖ) ≥ x) ≤ 2P(Sₙ
   ≥ x) 的模拟账；
4. **Rosenthal 两 regime**：重尾（t 分布 3 自由）vs 轻尾
  （均匀）的 E|Sₙ|^p / max(...) 的比值谱；
5. **Hájek-Rényi**：cₖ = 1/k 的加权 max 的收敛轨迹。

## 48.6 数值实验

**Julia（`48_prob_inequalities.jl`）**：① Chebyshev 两点
分布取等现场；② Kolmogorov max 的模拟验证（P(max|Sₖ| ≥ x)
vs Σσ²/x² 的逐 x 对拍）；③ Lévy 对称情形的 2 倍常数；
④ Rosenthal 两 regime 的演示（重尾 vs 轻尾的 max 主导）；
⑤ Hájek-Rényi 的加权 max（cₖ = 1/k 的收敛账）。
**Python**：Fraction 精确的两点取等账、截尾 Chebyshev 的
显式分数、有限和的最大值恒等式（全路径枚举）。
**Prolog（`48_prob_inequalities.pl`）**：全精确有理数
（`is` 保持分数不落地浮点）的四本小账——① Chebyshev 取等
（±1 两点：`Var =:= Bound` 恒等）；② Markov 的严格富余
（`P < Bound`，两点分布取不到等号时差在哪）；③ **Kolmogorov
极大的取等现场**：两步 ±1 游动穷举四条路径，运行最大值
`max|Sₖ|` 落在 [2,1,1,2]，P(max≥2) = 2/4 = 1/2 恰等于
Σσ²/λ² = 2/4——48.5.5 断言 2 的 n=2 零误差特例；④ 二项
系数 `binom/3` 递归驱动的均值 Chebyshev 账（n=4：精确 1/8
对界 1/4）。Prolog 通道的传统角色在此依旧：**给浮点模拟
一个可以 `=:=` 的判决性小数**。

## 48.5.6 与 41 章 Doob 不等式的同构表

| 本章（独立和） | 41 章（鞅/下鞅） | 共同母型 |
|---|---|---|
| Kolmogorov max | Doob L¹ 极大 | 停时分解 + 零交叉项 |
| MZ（p ≥ 1） | Doob Lᵖ/Burkholder | 凸函数的运行最大控制 |
| Hájek-Rényi | 加权 Doob（下鞅） | 时变权值的单调控制 |
| Etemadi | 两两独立版鞅 | 部分独立性够用 |

**读法**：独立零均值和 = 鞅的最简实例（41.1 例①）——
本章四件在鞅论的对应物全部存在且证明更一般（交叉项为零
只需鞅性不需独立）。**但本章的常数显式性**（2 倍、
3 倍、C_p 的具体值）在鞅版中常丢失——经典不等式的工程
价值正在于常数的可用性（统计检验的功效计算）。

## 48.6.5 历史注记

Lévy（1937）的《随机变量求和理论》奠基了二代不等式
（Lévy/Ottaviani 几乎同期）；Kolmogorov（1928）的最大
不等式是 SLLN（1929）的直接引擎——"先有工具再有定理"
的经典次序。MZ（1937-38）与 Rosenthal（1970）的矩不等式
在 Banach 空间概率论（Burkholder 的好 λ 方法）中完成
完全体；Hájek-Rényi（1955）的时变版本服务序贯统计；
Etemadi（1981）的两两独立版是 SLLN 独立性需求的最终
定论。**四代引擎的编年史就是极限定理的编年史**。

## 48.7 要点回顾

1. 四代引擎：单变量 → max → 高阶矩 → 时变/鞅型。
2. 截尾术是重尾问题的标准动作（截断水平调参）。
3. Kolmogorov max = 运行最大不消耗预算（停时分解）；
   MZ/Rosenthal 的两 regime 结构。
4. Hájek-Rényi 给收敛速率；Etemadi 放松到两两独立。
5. 机器侧：Chebyshev 手作先例（10 章）+ docs 全家；
   数值通道的取等与两 regime 现场。
