## 22.1 投影极限：Kolmogorov 定理的坐标系换装

第 21 章把无穷维测度造在乘积空间 ∏Ωᵢ 上。但很多自然的无穷维
对象**不是乘积**：p-进整数（ℤ/2ⁿℤ 的粘合）、布朗轨道空间
（C[0,∞) ⊂ ℝ^ℕ 的闭子空间）、流线丛上的柱面结构。统一的语言
是**投影极限（逆极限）**：

  给定逆系统：集合塔 E₁ ← E₂ ← E₃ ← …（粘合映射
  π_{n,m} : E_m → E_n, m ≥ n，相容 π_{n,m}∘π_{m,k} = π_{n,k}），

  投影极限 E_∞ := {(x_n) ∈ ∏E_n : π_{n,m}(x_m) = x_n}——
  "在每一层都取好位置，且层与层互相咬合"的相容序列全体。

E_∞ 带投影 π_n : E_∞ → E_n。**测度的翻译**：E_∞ 上的测度 μ
⟺ 相容族 μ_n = μ∘π_n^{-1}（每层一个分布 + 层间粘合）——
Kolmogorov 定理的话术原样成立：**相容有限维分布 ⟺ 投影极限
测度**。严书 4.6.2 引理验证：乘积空间情形（粘合 = 坐标删除）
的投影极限语言与第 21 章逐字对齐；非乘积系统则把"存在性验收"
转嫁给各层紧性（E_n 紧 ⟹ E_∞ 紧 ⟹ 相容概率族有极限测度——
**这只需要 Tychonoff 定理 + Riesz 表现**，是拓扑版的
Kolmogorov，第 24 章的接口）。

**两个标杆例子**：

- **Cantor 集**：{0,1}ⁿ 塔（粘合 = 截断前 n-1 位）的投影极限
  = {0,1}^ℕ（同胚于 Cantor 集）——乘积系统的正装出演；
- **C[0,1]（轨道空间）**：ℝⁿ 塔（粘合 = 删一个坐标）的极限是
  ℝ^ℕ；连续轨道子空间 C[0,1] ⊆ ℝ^ℕ **不是**柱集 σ-代数成员
  （它依赖不可数多个坐标的一致条件）——布朗运动的构造必须
  "Kolmogorov 造在 ℝ^ℕ + 连续修改定理搬进 C[0,1]"（第 43 章
  的正题）。**投影极限视角把这步搬演说透**：测度从 ℝ^ℕ 限制
  到闭子空间 C[0,1] 时，外测度装修（第 04 章完备化机器）与
  轨道空间的上同胚结构都要到位。

## 22.2 随机 Daniell 积分：泛函账本的随机化

第 15 章的 Daniell 机器把"确定积分泛函"翻译回测度。严书 §4.7
（严加安的研究方向之一）问一个更锋利的问题：**积分值本身是
随机的**——条件期望（第 36 章）、随机测度（经验过程）、
Gibbs 场的规范——能否从"随机泛函的公理"重建"随机测度"？

**定义（严书 4.7.1 的骨架）**：(Ω, 𝓕, P) 概率空间，H 为
"随机被积函数"组成的向量格（x ↦ f(x,ω)：可测空间 (E,ε)
× Ω 上的函数族，对每个 ω 是 x 的向量格元素），**随机 Daniell
积分** I : H → L¹(P)（取值随机变量！）满足：

1. **线性与正性**：I(af+bg) = aI(f)+bI(g)（在 a.s. 意义下），
   f ≥ 0 ⟹ I(f) ≥ 0 a.s.；
2. **Daniell 连续性的随机版**：fₙ ↓ 0（逐 x、对 a.e. ω）
   ⟹ I(fₙ) → 0 **依概率**（严书取依概率收敛——比 a.s. 弱，
   比 L¹ 也弱，恰是随机环境里"免费"的那一档，第 09 章四收敛
   矩阵的选型现场）。

**核表示定理（严书 4.7.9 的主定理）**：满足公理的 I 可表示为

  I(f)(ω) = ∫ f(x, ω) μ(ω, dx)

其中 μ 为**随机测度**（Ω × ε → [0,∞] 的核，第 19 章的 σ-有限
核；概率情形即转移核）——**随机 Daniell 积分 ⟺ 核积分**，
正如确定 Daniell ⟺ 测度积分。证明的战略与第 15 章平行：
H⁺ 单调上扩 → 指示函数落账 → 集函数族验证可加性 →
Carathéodory 延拓；战术上的新困难是**一切等式只 a.s. 成立**，
可数个例外零集的合并（"a.s. 手术后缝合约"）贯穿全程——
依概率收敛的子列兑换（第 09 章的 Riesz 子列机器）负责把
逐点性质从子列回收。

## 22.2.5 两个可手查的实例：条件期望与经验测度

随机 Daniell 公理不是空中楼阁，两个日常对象立刻对号入座：

**实例一（条件期望）**：E 上有界可测函数全体 H（x ↦ f(x)），
随机泛函取 I(f)(ω) := E[f(X) | 𝓖](ω)——X 为取值 E 的随机
元、𝓖 ⊆ 𝓕 为子 σ-代数。线性/正性免费；fₙ ↓ 0 ⟹ 条件
期望单调列 I(fₙ) = E[fₙ(X)|𝓖] ↓ 0 a.s.（条件单调收敛，
第 36 章三定理的条件版——袁下册 15.2.1 的正主）。核表示
定理断言：存在正则条件分布 μ(ω,dx) = P(X ∈ dx | 𝓖)(ω)
使 I(f)(ω) = ∫f(x)μ(ω,dx)——**第 37 章存在性定理（Polish
值随机元的正则条件分布）在本章公理框架下的重述**。两章
互为对证：公理路线（本章）给抽象保证，构造路线（第 37 章）
给 Polish 情形的显式装配。

**实例二（经验测度）**：H = 有界函数全体，I(f)(ω) :=
(1/n)Σᵢf(Xᵢ(ω))——样本均值泛函。此时核是**纯随机的 dirac
和** μ(ω,dx) = (1/n)Σᵢδ_{Xᵢ(ω)}(dx)，核表示显式成立
（无需定理）。公理的"依概率连续"条款在此退化为平凡——
但 Glivenko-Cantelli（第 51 章）把它强化为一致收敛时，
经验测度作为随机测度**取值于测度空间**的轨道理论随即开场
（第 31 章弱收敛的随机版接口）。

**a.s. 缝合约（战术难点详解）**：随机 Daniell 证明中每条
等式自带例外零集 N₁, N₂, …；可数合并 N = ∪Nₖ 仍零测，在
Ω ∖ N 上一切等式**同时**成立——这就是"缝合"。危险在
**不可数族**：逐 x 的积分等式有不可数多个 x，不能直接合并；
出路是把 x 离散化（简单函数逼近，可数多个分层）或用
依概率收敛 + 子列兑换（第 09 章 Riesz 子列：依测度收敛列
有 a.s. 收敛子列）把"逐点"需求压回可数。第 16 章 Bochner
构造的同款战术（DCT 搬运 + 完备性收尾）在此复用——三步
构造的谱系从数值积分一路贯到随机泛函。

## 22.3 三台"从局部造整体"机器的总表

| 机器 | 进料 | 出品 | 验收引擎 | 章 |
|---|---|---|---|---|
| Daniell（确定） | 正线性泛函 + 下单调连续 | 测度 μ，I = ∫·dμ | 单调上扩 + Carathéodory | 15 |
| Kolmogorov/Tulcea | 相容有限维 / 核列 | 无穷维概率 P | 紧类套 / 逐层剥核 | 21 |
| 随机 Daniell | 随机正线性 + 依概率连续 | 随机测度（核）μ(ω,dx) | a.s. 缝合 + 子列兑换 | 22 |

三台机器共享一条设计哲学：**积分/分布/泛函的"局部账本"
只要满足最小连续性公理，就必然来自某个测度论对象**——账本
先于货币，公理先于构造。第 15 章的三层楼（测度/积分/泛函
公理）在第 21-22 章加盖到无穷维与随机层：**四楼是随机泛函
公理，住户是核**。应用侧的对应：条件期望 = 关于随机测度
（正则条件分布，第 37 章）的积分；Gibbs 规范 = 随机 Daniell
的 DLR 方程形态——第 43 章（过程装修）与第 47 章（高斯测度）
都会回引本表。

## 22.1.5 第三个标杆：p-进整数的逆极限展开

**ℤ₂（2-进整数）**：塔 E_n = ℤ/2ⁿℤ（粘合 π_{n,n+1} = 模
2ⁿ 约减）。投影极限 ℤ₂ = {(x_n)：x_{n+1} ≡ x_n mod 2ⁿ}——
"每一位都定好、且高位永远兼容低位"的位串。三笔账：

1. **集合层**：ℤ₂ ↔ {0,1}^ℕ（二进制位串）双射——逆极限与
   乘积空间可以同胚，**结构不同**（ℤ₂ 带加法群结构，粘合
   映射是群同态）；
2. **测度层**：Haar 测度 μ(2ⁿℤ₂) = 2⁻ⁿ——均匀分布的相容
   族 μ_n = ℤ/2ⁿℤ 上的均匀分布，经 Kolmogorov 装配得到
   ℤ₂ 上的 Haar 概率。**p-进世界的一切"均匀"都是本章
   相容性机器的出品**；
3. **随机层**：ℤ₂ 上独立位串 = 均匀 Haar 随机元——数值通道
   的位串采样（第 20 章）在 ℤ₂ 语境下就是"均匀 2-进随机
   整数"的采样，两章的随机模型互为译文。

这个例子教学价值在于：**逆系统的粘合映射不必是"删坐标"**
——模约减、商映射、投影到子空间都是合法粘合；测度论只
关心"相容族 ⟺ 极限测度"的词典，群结构（第 47 章特征理论
的 p-进侧）是测度之上的附加层。

## 22.4 Lean：IsProjectiveLimit 谓词族（本章主角的机器版）

mathlib `Constructions/Projective.lean` 把 22.1 的词典直接形式化：

- `IsProjectiveMeasureFamily P`：族 P : ∀ J : Finset ι,
  Measure (∀ j : J, α j) 相容（粘合下边缘一致）——**"层间咬合"
  的谓词化**；
- `IsProjectiveLimit μ P`：∀ I, (μ.map I.restrict) = P I——
  "μ 的一切有限投影账 = 层内账"；
- `IsProjectiveLimit.measure_cylinder`：柱集账 μ(cylinder I s)
  = P I s（投影极限的账本定理）；
- `IsProjectiveLimit.unique`：有限测度情形 μ = ν（唯一性——
  `ext_of_generate_finite` + 柱集 π-系收口，第 06 章的机器）。

`Ch22ProjectiveLimits.lean` 实弹：Cantor 塔语境（Bool 因子、
bern2 = ½·(δtrue+δfalse)）——`infinitePi_map_restrict` 的有限维
边际账（每个有限窗口 J 的像 = 有限 pi）、`eq_infinitePi`（唯一性
判据）与 `infinitePi_eq_pi`（有限指标封顶：Fin 3 上两套坐标
完全重合）——第 22.1 节"词典"的三行机器对账。

## 22.5 数值实验：有限塔的极限显影

**Julia（`22_projective_limits.jl`）**：

- **Cantor 塔**：{0,1}ⁿ 塔的"极限元素"= 无穷位串——采样
  N = 10⁵ 条均匀位串，对每 n 验证第 n 层分布 = 均匀 2⁻ⁿ
  （相容族的极限显影）；
- **高斯塔**：布朗式协方差 K(s,t) = min(s,t) 的 n 维截段
  采样（Cholesky），n = 2 vs n = 3 的共享坐标边缘对拍
  （Kolmogorov 相容性的蒙特卡罗版；同一次采样里前 2 个坐标
  在两种塔中同分布——**同一条样本轨道，两层塔的账一致**）；
- **连续修改预演**：离散网格轨道的极大增量 max|B_{t+Δ}-
  B_t| 随网格加密 Δ → 0 的衰减 ~ √(Δ log(1/Δ))（Lévy 模量
  的数值影子——为第 43 章的连续修改定理垫场）。

**Python（`22_projective_limits.py`）**：Fraction 精确版
Cantor 塔（2⁻ⁿ 精确账、截断映射 π_{n,m} 的显式矩阵）；
高斯塔用精确 2×2/3×3 协方差子块核对（min(s,t) 的子块结构 =
相容性的代数原文）。

## 22.5.5 习题账单（自检清单）

1. 验证 {0,1}ⁿ 塔的投影极限与 {0,1}^ℕ 的典范双射（相容
   序列 ⟺ 完整位串）；
2. 证明 ℤ₂ 上 Haar 测度的有限维截口 = ℤ/2ⁿℤ 均匀分布
  （相容族的显式装配）；
3. 设 I(f) = E[f(X)|𝓖]：逐条验证随机 Daniell 公理（线性/
   正性/依概率连续），指出核表示中 μ 的身份（第 37 章
   正则条件分布）；
4. 解释"图像零测账"（18.4.6）与"C[0,1] 不在柱集 σ-代数"
   的张力：可测函数的图像进乘积 σ-代数，而连续轨道子空间
   为何不进（提示：一致条件的不可数性）；
5. 把三台机器总表扩成四行：加入 **Riesz 表现**（第 24 章：
   C_c 泛函 → Radon 测度）并填好每一列——四台机器的
   "验收引擎"列各不相同，这是测度论拓扑层的入口作业。

## 22.6 要点回顾

1. 投影极限 = 逆系统上的相容序列；测度 ↔ 相容有限维分布的
   词典与 Kolmogorov 定理逐字对齐；紧塔的存在性走 Tychonoff
   + Riesz（第 24 章接口）。
2. C[0,1] 不是柱集成员——轨道空间的测度必须"造在 ℝ^ℕ 再
   搬家"（连续修改），第 43 章的主战场预告。
3. 随机 Daniell：随机正线性泛函 + 依概率连续 ⟹ 核表示
  （μ(ω,dx)）——a.s. 缝合与子列兑换是战术难点。
4. 三台机器总表：Daniell/Kolmogorov-Tulcea/随机 Daniell =
   三层楼的加盖；条件期望与 DLR 方程是四楼住户。
5. 机器侧：Lean `IsProjectiveLimit` 谓词族（柱集账+唯一性）；
   Isabelle `Projective_Limit` 塔上实弹；数值通道把相容性与
   高斯塔算到底；随机 Daniell 公理化由 docs 承载。
