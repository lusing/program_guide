# 第 56 章 重对数律（袁 ch25）

大数定律说 Sₙ/n → 0；CLT 说 Sₙ ~ √n·N(0,1)。**几乎必然地**，
Sₙ 到底能走多远？答案精确到常数：
limsup Sₙ/√(2n log log n) = σ a.s.——分母里第二个 log 的
出现是概率论最优美的时刻之一。本章路线：a.s. 稳定性（三常数
定理的独立阵列版）→ Hartman-Wintner LIL（iid 完全体）→
习题账（Cramér 条件、单边 LIL、几何速度）。

## 56.1 a.s. 稳定性：三级数的重述（袁 25.1.1）

**定理 56.A（袁 25.1/25.2，a.s. 稳定性）**。独立阵列（行内）：
截尾和 ΣX_{n,k}I{|X_{n,k}|≤c} 的 a.s. 收敛性 ⟺ 三条件
（ΣP{|X_{n,k}|>c}<∞、ΣE[截尾]收敛、ΣVar[截尾]<∞）——
51 章三级数定理在阵列语言下的重述。**工具完全复用**：本章
的新意在"上极限的精确刻度"，不在收敛性本身。

## 56.2 三常数定理：limsup 的完全刻画（袁 25.1.2）

**定理 56.B（袁 25.3，Kolmogorov 三常数定理）**。独立阵列
{X_{n,k}}，bₙ ↑ ∞：limsupₙ (Sₙ−aₙ(ε))/bₙ = c(ε) a.s.
（某有限常数，ε 为截尾水平）——且 c 与截尾无关（定理 25.5
推广到独立不同分布）。**五步证明**的骨架：
1. 截尾分离（|X_{n,k}| ≤ εbₙ 的主部 + 稀少大项）；
2. 尾概率的指数估计（LIL 的引擎，见 56.3 的 (25.16)）；
3. Borel-Cantelli 双向（上界用第一引理，下界用独立性）；
4. 对数阈值：ε ↔ exp 步长使 ΣP 恰在 1/∞ 之间——
   **log log 的出现是 B-C 收敛账的精确结算**；
5. 常数的唯一性（两个截尾水平给出相同 limsup）。

**读法**：LIL 是三常数定理在"最优 bₙ"处的特例——bₙ 取
√(2n log log n)·σ 时 c = 1。定理的威力在**任意独立阵列**
（不必 iid）：刻度 bₙ 由方差和 Bₙ² = ΣVar 决定，
bₙ ~ √(2Bₙ² log log Bₙ²)。

## 56.3 Hartman-Wintner：iid 完全体（袁 25.2）

**定理 56.C（Hartman-Wintner 1941，袁 25.7）**。iid，
EX = 0，0 < σ² = EX² < ∞：
  limsupₙ Sₙ/√(2n log log n) = σ a.s.（且对称地
  liminf = −σ——轨道在 ±包络间无限次触界）。

**上界 (25.16) 的四步解剖**（教材正文给完全证明）：

  P{max_{k≤n} Sₖ ≥ (1+ε)√(2n log log n)} →（沿几何子列
  n = qᵐ 求和收敛）：

1. **几何子列**：n_m = q^m（q>1），Σ_m P{sup_{n_m≤n<n_{m+1}}
   |Sₙ| > (1+ε)√(2n_m LL n_m)} 的收敛性由下界控制——
   子列的稀疏化把"无限多 n"压缩成"可数多个块"，B-C 的
   入场费（ΣP<∞）由此缴清；
2. **分段估计**（习题 25.3）：块内 max 由 Kolmogorov 最大
   不等式（48 章）压住；
3. **对称化下界**：Sₙˢ = Sₙ − Sₙ′ 的尾概率 ≥ (1/2)P{|Sₙ|>t}
   （习题 25.2 的对称化账）——把一般情形化到对称；
4. **对数阈值的精确结算**（习题 25.4/25.5）：正态尾
   P{N(0,σ²)>t} ≈ exp(−t²/2σ²) 的阶梯积分与
   t² = 2σ²LLn 的联立 → P{块越界} ≈ (log n)^{−(1+ε)²}·
   修正——**恰在 ε=0 处发散、ε>0 处收敛**（1/m 的对数
   积分墙）。下界（limsup ≥ σ）用独立性 + 第二 B-C 的
   事件独立性（习题 25.8/25.9 的独立子列技巧）。

**log log 的必然性**：√(n log n) 太小（B-C 发散——轨道
必穿越）、√(n (log log n)^{1+ε}) 太大（收敛——轨道不至），
**√(n log log n) 是穿越与不穿越的分界**。Kolmogorov 早期
(1929) 证明需三阶矩有限，Hartman-Wintner (1941) 降到二阶
（最优——习题 25.2 的 Cramér 条件账）。

## 56.4 习题账单（袁 25.3 精选）

- **25.1（积分收敛准则）**：∫₁^∞ x^{−1}(log x)^{−c}dx 的
  敛散在 c=1 处分界——log log 尺度的积分学根源；
- **25.2（对称化 + Cramér 条件）**：EX²<∞ 的 Cramér 条件
  （∀t>0: ΣE[e^{−t|X|}]…型）是 LIL 尾估计的母体假设；
- **25.4（正态尾阶梯）**：∫_x^∞ e^{−t²/2}dt ≤ (1/x)e^{−x²/2}
  ——几何子列求和的逐块进场券；
- **25.5（指数界）**：P{N(0,1) > t} ≤ e^{−t²/2} 与下界
  (1−1/t²)e^{−t²/2}——**上下界夹出 log log 的精确指数**；
- **25.6（单边 LIL）**：limsup 用 max_{k≤n}Sₖ 代替 Sₙ 仍是
  σ（首次穿越的反射原理型账）；
- **25.7（几何速度）**：对 c>1，P{Sₙ 越界 i.o.（在
  c·包络下）} 的 0/1 由 c 与 1 的比较决定——**包络系数的
  临界性**；
- **25.8/25.9（独立子列）**：{S_{n_m}} 沿稀疏子列的独立性
  （间隔足够大时近似独立）——下界证明的核心技巧。

### 56.3.5 (25.16) 上界的细账（四步的公式层）

第 1 步（几何子列）：取 n_m = ⌈q^m⌉，块 (n_m, n_{m+1}] 的
越界事件 A_m = {sup_{n_m<n≤n_{m+1}} |Sₙ| > (1+ε)√(2n_m LL n_m)}
——块长的选取 q 使 ΣP(A_m) 的收敛性可判（每块独立近似）。

第 2 步（分段最大）：sup 的 Kolmogorov 型控制
P{max_{k≤n}|Sₖ|>t} ≤ 2P{|Sₙ|>t−√(2n)}（Lévy 反射不等式的
雏形——运行最大转化为端点，48 章停时分解的亲戚）。

第 3 步（对称化下界）：P{|Sₙˢ|>t} ≥ (1/2)P{|Sₙ|>t}——
对称版的尾概率不小于一般版的一半（习题 25.2 的账），把
母体化到对称后用第 4 步的正态尾。

第 4 步（对数阈值）：P{|Sₙˢ| > (1+ε)√(2nLLn)} ≈ exp(−(1+ε)²
LLn) = (log n)^{−(1+ε)²}——在 n_m = q^m 上 = m^{−(1+ε)²}，
**恰在 ε=0 处 Σ1/m 发散、ε>0 处收敛**（p 级数的墙）。
log log 的位置由"尾概率的 exp(−t²/2n) 与 √n 的联立"唯一
确定——它是 B-C 收敛账的精确结算，不是设计选择。

## 56.2.5 三常数定理的"三常数"是谁

定理名里的三常数 = **aₙ（平移）、bₙ（刻度）、c（上极限
值）**：给定独立阵列，三者由阵列的方差和与截尾账唯一确定
（在等价意义下）。LIL 是 c = σ 的特例；c = ∞ 对应"轨道
无界地超过刻度"（重尾情形——实验断言 4 的 Cauchy 破产）；
c = 0 对应"刻度取得过大"。**定理把"limsup 等于什么"从
存在陈述变成了可计算账**——这是它比"LIL 存在"更深的
地方：给任意独立阵列（不必 iid、不必同方差），三常数算得出。

三常数定理的**证明五步**中第 4 步（对数阈值）与 LIL 四步
中的同名步骤是同一招——B-C 收敛账的精确结算。区别只在
LIL 需要正态尾的精确指数（t² = 2σ²LLn 联立），而三常数
定理只要求尾概率的单边估计（ε 步长即可）。

## 56.5.5 实验断言清单（数值通道验收单）

1. **包络轨道**（有限 n 诚实账）：40 条 n=4e4 正态游走中
   39 条触 0.9·包络；2 倍包络穿越 7 条；中位比 1.46
   （渐近 1——log log(4e4) = 2.36 的二阶修正 ~1/√LLn）；
2. **几何子列 0/1**：q=1.5 的 27 检查点上，c=1.6 越界 2 次
   （收敛侧）vs c=0.8 越界 7 次（发散侧）；
3. **单边 LIL**：max Sₖ/包络 的中位 0.77（渐近同 1，单边
   只用一半触界机会）；
4. **重尾破产**：Cauchy 步长的 |S|/包络 达 310（正态 <1.6）
   ——EX²=∞ 则包络被碾压；
5. **积分墙**（Python）：∫dx/(x(log x)^c) 的离散部分和
   c=0.5 时 6.11（发散侧）vs c=1.5 时 2.4（收敛侧）；
6. **正态尾阶梯**：∫_x^∞e^{−t²/2}dt ≤ (1/x)e^{−x²/2} 的
   逐 x 覆盖比（0.66/0.84/0.88 at x=1/2/3——渐近紧）；
7. **包络锚点**：n = e^e 处 LLn = 1，包络 = √(2n) 精确
   （log log 尺度的标定点）。

## 56.6 历史注记与要点回顾

Khintchine（1924）证明 Bernoulli 情形；Kolmogorov（1929）
三阶矩版；Hartman-Wintner（1941）二阶矩完全体（最优）。
Strassen（1964）的泛函 LIL（轨道在 Brown 桥紧集里稠密）
与 Chung（1948）的下包络（min max |S| ~ √(n/LLn)）是两大
后续。Kolmogorov 三常数定理（1929）是阵列版的一般框架。

要点回顾：
1. 三常数定理：独立阵列的 limsup 刻度完全刻画（方差和
   Bₙ² 驱动 bₙ）。
2. Hartman-Wintner：limsup Sₙ/√(2nLLn) = σ a.s.——
   EX²<∞ 最优。
3. 四步证明：几何子列 + 分段最大 + 对称化 + 对数阈值
   （log log 是 B-C 收敛账的精确结算）。
4. 包络的临界性：系数 >1 收敛、<1 发散、=1 触界
   （习题 25.7 的 0/1）。
5. LIL 是 SLLN 的精修：收敛（→0）的"速度上限"精确到
   常数——与 CLT 的 √n 尺度互补（CLT 管分布形状，
   LIL 管轨道包络）。
6. 机器侧：B-C 第一引理手作 + 正态尾件复用（Lean 分工）；
   包络轨道与几何子列 0/1 转换（数值）。
