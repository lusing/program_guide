## 23.1 为什么测度论要搬进拓扑

前四章的测度论住在抽象可测空间里——但现实中的测度几乎全部
长在拓扑空间上：Lebesgue 测度靠开区间、概率分布靠分布函数
（右连续 = 拓扑信息）、随机过程的轨道空间自带紧开拓扑。拓扑
给测度论三件装备：**(1) 免费的可测结构**（Borel σ-代数——连续
函数自动可测）；**(2) 逼近机制**（开集/紧集做内外逼近——正则性
的原料）；**(3) 收敛语言**（网、滤子、连续映射——弱收敛的土壤）。
本章是"拓扑词汇速成班"：只收测度论后文要用的子集，每个概念
都配"它在哪一章上场"的路标。

## 23.2 收敛词汇：从序列到网

拓扑空间里序列不足以刻画一切（不可度量的空间里"闭"≠"序列
闭"）。**网（net）**是序列的推广：定义域从 ℕ 换成任意有向集
D（预序 + 上界）。x_α → x ⟺ 对 x 的每个邻域 U， eventual 地
x_α ∈ U。三条常用事实（严书 5.1.1-5.1.4）：

1. f 连续 ⟺ 对一切网 x_α → x 有 f(x_α) → f(x)；
2. A 闭 ⟺ A 中网的极限都在 A；
3. 聚点 x ∈ closure A ⟺ A 中有网收敛到 x。

**教学口径**：数学侧网是"带方向的族"；机器侧 Lean 用**滤子**
（Filter）表达同一内容（`Filter.Tendsto`——第 09 章已用），网
与滤子互相翻译（mathlib 的 `net_theory`/`Filter` 双轨）。袁书
§2.2.7 只讲序列收敛并注明"一般拓扑空间中不充分"——本教程
统一滤子口径，与 mathlib 对齐。

## 23.3 分离与计数：Hausdorff、可数基、可分

**分离公理**（只取需要的两档）：T₂/Hausdorff（两点可用不交
开集分离——极限唯一性的最低保证）；**正则**（点与闭集可分离）
+ T₁ ⟹ T₃。局部紧 Hausdorff（每点有紧邻域基的 Hausdorff
空间，LCH）是本章主角舞台——§5.2 Riesz 定理的家。

**可数性**（两档）：**第一可数**（每点有可数邻域基——序列
够用的空间）；**第二可数**（全空间有可数基）。**可分**（有
可数稠密集）。关系链（袁书 §2.4）：第二可数 ⟹ 第一可数 +
可分；度量空间上三者几乎合流（度量可分 ⟺ 第二可数）。 ℝⁿ
可分；不可数离散空间可分失败（每点孤立，稠密 = 全空间）。

**度量化的意义**：度量空间自带序列语言（d(xₙ,x) → 0）、
完备性、全有界——三者合成的 **Polish**（可分完备度量）是
第 29 章的主角。Urysohn 度量化定理（第二可数 + T₃ ⟹ 可度量化
为 [0,1]^ℕ 子空间）把"拓扑好"折算成"距离好"。

## 23.4 Borel σ-代数：生成与对齐

**定义**：B(X) := σ(开集全体)。立即的生成系清单（对 ℝ 验证
过的一切在此复演）：σ(闭集) = σ(紧集)（LCH）= σ(开区间)
（ℝ）= σ({f > a}，f 取遍 C(X))。最后这个生成系是**函数侧
入口**：B(X) 是使**一切连续函数可测**的最小 σ-代数（严书
5.1.5）。机器对应：mathlib `borel` 定义于 `BorelSpace`（拓扑
→ σ-代数的 canonical 装配），`Continuous.measurable` 即"连续
⟹ Borel 可测"——第 07 章的 Borel 机器在此一般化。

**乘积对齐**（严书 5.1.14 / 第 17 章 B(ℝᵐⁿ) = B(ℝᵐ)⊗B(ℝⁿ)
的一般版）：B(X × Y) ⊇ B(X) ⊗ B(Y)，且 X, Y 第二可数时取等
（box 基可数 → 开集可数并落进乘积 σ-代数）。mathlib：
`prod_le_borel_prod` + 第二可数下的 `BorelSpace (α × β)`
instance；任意族的版本：countable 指标 + 第二可数 ⟹
B(∏Xᵢ) = ⊗B(Xᵢ)（mathlib `Pi.borelSpace` instance）。**第二
可数不可省**：不可数乘积上两边的"开集"结构都太瘦，等式
依旧成立但两边都只含可数支集柱集——第 17 章袁定理 10.6 的
拓扑版。

**逆像与商**：f : X → Y 连续 ⟹ f⁻¹(B(Y)) ⊆ B(X)（即 f 可
测）；嵌入/投影都是 Borel 态射。Borel 态射对复合封闭——
"Borel 范畴"是拓扑范畴到可测范畴的保结构函子（第 40 章解析
集理论的入口）。

## 23.5 Baire σ-代数：连续函数的眼光

**定义**：Ba(X) := σ({f⁻¹(0)：f ∈ C(X)})——由连续函数的
零集（等价地 {f ≥ a}、{f > a} 闭型零集）生成。包含关系
Ba(X) ⊆ B(X)，且：

- **度量空间（或任何完美正规空间）上取等**：开集 G =
  {d(·, Gᶜ) > 0} 的零集补——Ba = B；
- **一般 LCH 上可严格小**：紧 Hausdorff 不可度量化时，
  Ba(X) 恰是"紧 Gδ 集的 σ-代数"，B(X) 更大（Alexander
  双紧立方是经典反例土壤）。

**Baire 的用途**：Riesz 定理的原始形式（严书 §5.2 的 Daniell
路线）先在 Ba(X) 上造测度（C_c 泛函天然只看见 Baire 集），
再用正则性扩到 B(X)（严书 5.3.3 习题：Baire 有限测度 ⟹
唯一 Borel 正则扩张）。**概率论的实用口径**：可分度量空间上
两者相同，"Borel 测度"一词无需犹豫；一般拓扑上的随机过程
（如 C[0,1] 上的柱面讨论）要留意区分。

**分工注记**：mathlib 无 Baire σ-代数基础设施（拓扑层的
`BaireSpace` 是"完备度量空间非空开集"的 Baire 纲定理概念，
同名不同物）；Isabelle 亦无。本章 Baire 内容由 docs 讲清，
数值通道在有限拓扑上模拟"零集生成 vs 开集生成"的差距。

## 23.3.5 网与滤子的翻译表

机器侧（Lean/mathlib）用滤子做收敛的通用语言，数学侧（严书）
用网——对照表：

| 数学（网） | 机器（滤子） |
|---|---|
| 网 x : D → X | 函数 + Filter（邻域滤子 𝓝 x） |
| x_α → x | `Filter.Tendsto x D (𝓝 x)`（D 为方向滤子） |
| 子网 | 滤子的 map/反推（`Filter.map`） |
| 聚点 | `ClusterPt x F` |
| eventual 性质 | `∀ᶠ α in F, P α` |

网的构造性优势（数学直觉：'沿方向取极限'）与滤子的代数
优势（组合子完备、mathlib 全套 API）各有战场；本教程在
docs 用网的语言叙述定理（贴严书），在机器层用滤子（贴
mathlib）——第 09 章已实操过 `Tendsto`，本章起是常态。

## 23.4.5 度量化：把拓扑折算成距离

**Urysohn 度量化定理**：正则 + 第二可数 ⟹ 可嵌入 [0,1]^ℕ
（Hilbert 方块）⟹ 可度量化。骨架：可数基 {Uₙ} 中配对
(x ∈ Ūₙ ⊆ Uₘ) 的 Urysohn 函数 fₙₘ 分离点，映射
x ↦ (fₙₘ(x)) 嵌入。**教学价值**：概率论的"具体空间"几乎
全是可度量的——度量化定理保证"讨论距离与讨论拓扑等价"
在标准舞台合法。反方向不成立：可度量 ⟹ 正则 ✓ 但不必
第二可数（不可数离散空间可度量、不可分）。**度量的等价
改造**（第 29 章工具箱预告）：d ↦ d/(1+d)、d ↦ min(d,1)
保拓扑、保完备性——距离不是拓扑的"本体"而是"坐标"。

## 23.4.6 Borel 结构的层级图

Borel σ-代数内部按生成层级（ℝ 上的经典分层，第 40 章
解析集的起点）：

- Σ⁰₁ = 开集，Π⁰₁ = 闭集；
- Σ⁰₂ = F_σ（闭可数并），Π⁰₂ = G_δ；
- Σ⁰ₙ = (Π⁰ₙ₋₁) 的可数并……归纳推进；
- B(X) = ∪ₙΣ⁰ₙ（可数序数全并——严格大于一切有限层）。

例：ℚ 是 Σ⁰₂ 不是 Π⁰₂；可微函数集（C[0,1] 中）是 Π⁰₃
复杂的经典示例。**层级敏感度**是描述集合论的入口：第
40 章（解析集 = 连续像）与第 29 章（Gδ = Polish 子空间）
都在这张图上作业。

## 23.8.5 习题账单（自检清单）

1. 在 Sierpiński 空间 Σ = {0,1}（开集 {∅,{1},Σ}）上：
   枚举全部连续函数 Σ → ℝ；验证 Ba(Σ) = B(Σ)；
2. 证明 σ(紧集) = σ(闭集)（LCH：闭集 = 紧集的可数并——
   σ-紧穷竭；一般空间给反例）；
3. 网 1_A 型反例：构造"序列闭但非闭"的集合（第一不可数
   序数空间 ω₁ 中的例子——超出度量的世界）；
4. 证明：第二可数 ⟹ Lindelöf（开覆盖有可数子覆盖）——
   乘积对齐定理（B(X×Y) = B⊗B）证明里用到的隐藏件；
5. 把 23.4 的五组生成系逐条证成等价（开集/闭集/紧集/
   {f>a}/box）。

## 23.6 数值实验：有限拓扑上的 Borel 账

**Julia（`23_topology_borel.jl`）**：Ω = {1,2,3,4} 带拓扑
τ = {∅, {1}, {1,2}, Ω}（Sierpiński 型四点空间）：

- **Borel 闭包**：从 τ 出发补/并可数闭包（有限即终止）——
  得 8 元 σ-代数（含 {1}, {2,3,4}, {1,2}, {3,4}…全账枚举）；
- **连续函数判定**：枚举全部 4^4 = 256 个函数 f : Ω → ℝ
 （取值 0/1/2/3），按"f⁻¹(开集) ∈ τ"筛出连续函数全体——
  恰好是"沿特殊化序单调"的函数（拓扑序 1 ≺ 2 ≺ 3 ≍ 4）；
- **Ba vs B（意外收获）**：连续函数只有 4 个常值（拓扑太粗，
  纤维必须开）——零集只有 ∅/Ω，Ba = 平凡 σ-代数 {∅,Ω}（2 元）
  **⊊ B（8 元）**。**有限 ≠ 完美正规**：非 T₁ 有限拓扑上 Ba
  可真小于 B（离散有限才取等）——数值通道抓出的真反例，
  修正了"有限空间自动 Ba = B"的想当然；
- **乘积对齐**：τ × τ 乘积拓扑的 Borel vs B(τ)⊗B(τ)——
  有限空间第二可数平凡成立，账目 8×8 收敛到一致。

**Python（`23_topology_borel.py`）**：整数精确版同账 +
**第二可数性检查器**（基可数性在有限空间平凡真，但实现
"拓扑基"概念本身：τ 的每个开集 = 基元素之并——对基候选
{ {1}, {1,2}, Ω } 验证覆盖性）。

**Prolog（`23_topology_borel.pl`）**：符号版——`open/1`
事实表、`closed/1`（补）、闭包谓词 `in_borel/1`（补/有限并
饱和）、连续函数筛选 `cont/1`（预像检验穷举）。

## 23.7 Lean：borel 与连续可测

mathlib 锚点：`borel`（TopologicalSpace → MeasurableSpace
的 canonical 装配）、`Continuous.measurable`（连续 ⟹ Borel
可测）、`prod_le_borel_prod`（乘积 σ-代数 ≤ Borel 乘积）与
第二可数下的取等 instance、`SeparableSpace`/`
SecondCountableTopology`。`Ch23TopologyBorel.lean` 实弹：

1. **锚点 #check**：`borel`/`Continuous.measurable` 等；
2. **连续可测**：ℝ 上 `fun x => sin x + |x|` 型组合的 Borel
   可测性（连续性 → fun_prop/连续引理 → 可测）；
3. **乘积对齐**：`BorelSpace (ℝ × ℝ)` instance 的引用与
   `prod_le_borel_prod` 的方向确认（≤ 与 ≥ 两侧谁免费谁要
   第二可数）；
4. **可分性**：`SeparableSpace ℝ` 的 instance 引用（第 29 章
   Polish 的入场券）。

## 23.8 要点回顾

1. 拓扑给测度论三件装备：免费可测结构（Borel）、逼近机制
  （开/紧）、收敛语言（网/滤子——机器统一滤子口径）。
2. B(X) = σ(开集) = σ({f > a})（连续函数入口）；乘积对齐
   B(X×Y) = B(X)⊗B(Y) 需第二可数；连续映射 = Borel 态射。
3. Baire σ-代数 Ba(X) = σ(零集)：度量空间上与 Borel 相等；
   一般 LCH 上可严格小——Riesz 构造的天然落点（§5.2 伏笔）。
4. 可数性三档（第一可数/第二可数/可分）与度量化（Urysohn）
   ——Polish 空间的入场准备。
5. 机器侧：mathlib `borel`/`Continuous.measurable`/`prod_le_
   borel_prod`；Baire σ-代数无基础设施（分工如实标注）；
   数值通道在有限拓扑上把 Borel 闭包算到底。
