## 43.1 为什么要放松"全局可积"

鞅的定义要求每个 Xₙ 可积——但过程论的天然对象（随机
积分、连续时间金融模型）常只有**局部**可积性。策略：
用**局部化停时列** τₖ ↑ ∞ 把过程"截断成鞅"：

**局部鞅（local martingale，严书 8.3.1-8.3.2）**：适应
过程 M 称局部鞅，若存在停时列 τₖ ↑ ∞ a.s. 使每个
**停止过程** M^{τₖ}ₙ := M_{n∧τₖ} 是（真）鞅。

**直觉**："在每一段有限时间内公平"（τₖ 内的游戏规则
公平），但全局期望可以不存在——公平性的局部版本。
τₖ 的典型选取：τₖ = inf{n : |Mₙ| ≥ k}（按幅度截断）——
有界停止过程自动可积。

## 43.2 基本定理与危险地带

**恢复定理（严书 8.3.4 系）**：局部鞅 M 若每个 Mₙ 可积
⟹ M 是真鞅（局部 + 可积 = 全局公平）。特别地：**非负
局部鞅 + M₀ 可积 ⟹ 鞅**（非负性的可积福利——下极限
控制）。

**危险地带（反例档案）**：局部的弱化让经典鞅定理逐一
失效——

1. **非负局部鞅可以不是 UI**：乘积鞅的局部化变体
  （Mₙ → 0 a.s. 但 E Mₙ = 1：42 章反例本身已是局部鞅
   情形的展示）——**局部公平 + 期望恒定 + a.s. 衰减**
   三者共存的微妙现场；
2. **可选停止需要局部化版**：无界停时的 E[M_τ] 可以
   严格偏离 M₀（41 章首穿现场的局部鞅读法）；
3. **凸变换不再自动封闭**：f(局部鞅) 的下鞅性需要
   f(M^{τₖ}) 的逐段验证（可积性逐段缴费）。

**判定清单（工程手册）**：局部鞅 + 下列任一 ⟹ 真鞅：
① 一致可积；② Lᵖ 有界（p > 1——Doob Lᵖ 的局部版）；
③ 非负 + M₀ 可积；④ 有界变差（|ΔM| 累积有界的补偿版）。

## 43.3 停时变换与可料变换

严书 8.3 后段（8.3.5-8.3.6）处理**过程的变换代数**：

- **可料变换**（discrete stochastic integral）：Hₙ 可料
  （Hₙ ∈ 𝓕ₙ₋₁——基于昨日信息的今日仓位），变换过程
  (H·X)ₙ = Σₖ Hₖ·Dₖ（D = X 的差分）。**可料变换保持
  鞅性**（E[HₖDₖ|𝓕ₖ₋₁] = HₖE[Dₖ|𝓕ₖ₋₁] = 0——可料
  系数自由出入条件号，36 章取出性质）——**离散随机
  积分**的原型（H = 仓位策略，X = 价格，H·X = 策略
  盈亏——公平市场无免费午餐的数学形式：一切可料策略
  的盈亏过程仍是鞅）；
- **局部化下的变换**：H 有界 ⟹ 变换保持局部鞅（逐段
  截断验证）；H 无界时需 H·M 的局部化序列——**随机
  积分论的严格性税**。

**赌博解读（41 章的深化）**：可料策略 = "公平赌场里
用任何资金管理策略都无法获利"——鞅的强形式公平；
而**非可料策略**（偷看未来）当然可以获利——停时的
可料性约束是"不偷看"的公理化。

## 43.4 连续时间的影子（前瞻导览）

本教程止步于离散时间，但局部鞅的全部意义在连续时间
绽放：① Itô 积分 ∫H dM 天然只是局部鞅（可积性要
H、M 的平方变差缴费）；② **半鞅** = 局部鞅 + 有限变差
（Doob 分解的连续极限）——随机分析的基本对象类；③
资产定价基本定理（无套利 ⟺ 存在等价局部鞅测度）把
"公平"从哲学变成可检验的数学条件。**离散局部鞅是
连续理论的脚手架**：一切技术难点（局部化序列的选取、
停止的收敛）在离散已全部显影。

## 43.4.5 局部化的选取学（工程细节）

局部鞅定义中的停时列 τₖ 不是唯一的——**选取的技艺**
决定后续验证的难度：

| 选取 | τₖ = inf{n : |Mₙ| ≥ k} | τₖ = inf{n : Σ|ΔM| ≥ k} | 变差型 |
|---|---|---|---|
| 截断效果 | 幅度有界 | 二次变差有界 | 路径变差有界 |
| 适用 | 通用 | 平方可积情形 | 有界变差邻域 |
| 恢复 | 可积 ⟹ 真鞅 | L² 界 ⟹ L² 鞅 | BV 分解 |

**经验法则**：先猜需要的全局界（L¹/L²/BV），再选能提供
该界的停时列——"从结论反推局部化"。连续时间里这成为
精确的技术（Itô 的局部化序列），离散版本是其实习场。

## 43.4.6 习题账单（自检清单）

1. 证明恢复定理（局部 + 逐点可积 ⟹ 鞅）：提示——
   E[M_{n+1}1_A] 对 A ∈ 𝓕ₙ 的验证中交换 lim 与期望
   （DCT 经截断停时）；
2. 非负局部鞅 + M₀ 可积 ⟹ 鞅（下极限控制法）；
3. 可料变换保持鞅性的完整证明（取出性质逐项）+ 反例：
   非可料 H（偷看一步）的获利过程显式计算；
4. 构造：UI 失败的局部鞅（乘积鞅重尾化）并验证其
   局部化序列的逐段鞅性；
5. 离散 Itô 等距的预告：E[(H·M)ₙ²] = E[ΣHₖ²(Dₖ)²]
   （L² 鞅 + 可料 H——正交性的加权版，43.4 的伏笔）。

## 43.4.7b 无套利的离散影子（43.4 的具体化）

可料策略盈亏是鞅 ⟺ **无套利**（no free lunch）：任何
不偷看的策略都不能把正概率获利与零概率亏损兼得。离散
版本的证明一行（鞅性 + 初始资本 0 ⟹ E[盈亏] = 0 ⟹
无套利）；连续时间（Delbaen-Schachermayer 1994 的"无
免费午餐与维其尔风险"）需要局部鞅测度的深水装备——
43.4 的完全体。数值通道的"偷看策略获利"实验正是套利
的微缩现场：非可料性 = 信息优势 = 套利。

## 43.4.7 历史注记

局部鞅由 Itô-Watanabe（1965）引入连续时间随机分析；
离散版本（严书 §8.3 的处理）是教学抽象——为连续理论
预演局部化技术。"Local"一词在法语传统（maringale
locale，Meyer 学派）下强调"逐段成立"。Doob 分解
（1940s）→ 局部化（1960s）→ 半鞅与随机积分百科（Dellacherie-
Meyer 十卷）——离散到连续的技术升级路线图。

## 43.4.8 实验断言清单（数值通道验收单）

1. **截断稳定**：M^{τₖ} 的期望恒 1（k = 2, 5 两档截断
   后 500 轨道均值 = 1 ± 噪声）vs 重尾版全局 E 的发散；
2. **可料策略**：(H·X) 期望 ≈ 0（跟随策略的鞅性保持）；
3. **偷看策略**：期望单调增（每步 +|μ| 的显式速率）；
4. **恢复定理**：截断版非负过程的收敛 + 可积对照；
5. **L² 等距预告**：可料 H 的变换方差 = ΣHₖ²Var(Dₖ)
  （逐项精确 vs 采样）。

## 43.4.9 习题补充

6. 局部化序列的构造练习：对 Mₙ = ∏(1+ξₖ)（ε = 0.8
   重尾版）验证 τₖ = inf{|M| ≥ k} 的停止过程鞅性；
7. 半鞅分解的手算：Xₙ = n + Sₙ（趋势 + 噪声）的 Doob
   分解与局部化读法。

## 43.6 数值实验：截断与策略

**Julia（`43_local_martingales.jl`）**：

- **局部化截断**：乘积鞅 Mₙ（±0.4 步长）在 τₖ =
  inf{|M| ≥ k} 截断后的 M^{τₖ} 期望恒 1（每段是鞅的
  数值验证，k = 2, 5）vs 全局 E[Mₙ] 的恒 1（本例 UI
  恰好成立——对照**重尾化变体**（±0.8 步长）的 E 爆炸
  截断后的稳定性）；
- **可料策略**：信号策略 Hₙ = ±1（按昨日涨跌跟进）
  于随机游走——(H·X)ₙ 的期望恒 0（鞅性保持的模拟）；
  对照**偷看策略** Hₙ = 今日实际方向（非可料）——期望
  单调增长（"未来信息获利"的数值显影）；
- **非负局部鞅恢复**：Rₙ = |Mₙ| 的规范化变体（非负
  下鞅）的收敛与可积性对照。

**Python（`43_local_martingales.py`）**：Fraction 精确版
——有限二叉树的截断过程全树账（M^{τₖ} 的期望逐层精确
= 1）、可料变换的精确期望恒等（逐节点条件账）、非可料
策略的精确获利账（期望增长率的显式分数）。

## 43.7 要点回顾

1. 局部鞅 = 停时列截断下的逐段鞅；局部 + 可积 ⟹ 真
   鞅（非负 + M₀ 可积的福利版）。
2. 危险地带：UI 失效、可选停止的偏离、凸变换的逐段
   缴税——判定清单四条是工程手册。
3. 可料变换保持鞅性（离散随机积分——取出性质的应用）；
   "公平市场无免费午餐"的数学形式。
4. 连续前瞻：Itô 积分/半鞅/无套利定价——局部化技术
   的终极舞台。
5. 机器分工如实：mathlib 无局部鞅基础设施；零件 +
   数值通道的截断/策略账承载。
