## 39.1 从 sup 到 ess sup：零测模糊的纠正

sup 对一切点负责——一个异常点就能推高 sup。测度论的
"几乎处处"世界观要的是**忽略零测集后的最大值**：

**定义（ess sup）**：ess sup X = inf{a : X ≤ a a.s.}——
一切 a.s. 上界的下确界。对偶：ess inf X = sup{a : X ≥ a
a.s.}。约定：零测空间上 ess sup = −∞（一切 a 都是 a.s.
上界）；X⁺ 无界时 ess sup = +∞。

**基本账**：

1. **存在 witnesses**：ess sup X = a* 时，X ≤ a* a.s.
  （a.s. 上界的可数交仍 a.s.——inf 的逼近列取极限）；
2. **sup ≥ ess sup** 恒成立；等号当 X "本性连续"（如
   连续函数 + 全支撑测度）；**严格不等的现场**：X =
   1_ℚ∩[0,1] 于 Lebesgue：sup = 1 = ess sup；X =
   2·1_{ Cantor 集 } + 1：ess sup = 1（Cantor 零测）而
   sup = 2——零测尖刺被无视；
3. **函数化 ess sup（族版本）**：{Xᵢ} 族的 ess sup =
   逐点 sup 的本性化——**可数族的 ess sup 良定义且是
   本性上界**（不可数族的逐点 sup 可能不可测——可分性
   修补的技术根源，第 43 章随机过程的可测修饰伏笔）；
4. **子 σ-代数上的 ess sup/inf（严书 7.5.1 的主定理）**：
   H ⊆ L⁺ 的**本性下确界** ess inf H 存在（在 a.s. 等
   价意义下）：存在 𝓖-可测（或指定子 σ-代数内）的
   X* ∈ H 的下确界，使一切 H 成员 ≥ X* a.s. 且 X* 是
   此类中最大者——**L⁰ 的完备格性质**（Dedekind 完备
   的 a.s. 版）。

## 39.2 主定理：ess inf 的存在（严书 7.5.1-7.5.5）

**定理（下确界定理）**：H 为非空族（L⁺ 或一致可积族等
合适类）。则存在（a.s. 唯一的）X* = ess inf H。

**证明骨架（严书 p.239-241 的四步——一个精彩的手工
格论）**：

1. **有理指标下降列**：对每个 q ∈ ℚ₊，取 H_q ⊆ H 使
   E[H_q 截断] → inf{E[截断 h] : h ∈ H}（期望层的 inf
   逼近）；令 Sₙ = 逐点 min(H_{q₁},…,H_{qₙ})（前 n 个
   有理的下降网）——单调下降的网列；
2. **极限的候选**：X* = lim Sₙ（下降列的逐点极限，
   值 [0,∞]）——一切 H 成员 ≥ 某 Sₙ ≥ X*（每个 h 终将
   被网罩住）；
3. **X* 是本性下界**：h ≥ X* a.s. 逐 h 验证；
4. **最大性（反证）**：若 Y > X* 以正概率（Y 是另一本
   性下界），取 A = [Y > X* + ε]（P(A) > 0），构造
   h' = min(h, Y + ε·1_A) 型的 H 改进元压过 X*——与
   X* 的构造（期望层的下确界逼近）矛盾。∎

**教学价值**：这是"实数完备性"（Dedekind cut）在随机
变量世界的完整重放——期望层逼近 + 下降网 + 反证压榨。
L⁰（a.s. 等价类）是**完备格**（一切有界族有 sup/inf），
而 L⁰ 的不可度量化（收敛拓扑的复杂度）被格性质部分
救济——第 09 章依测度收敛世界的秩序基石。

## 39.3 ess sup 的运算清单

1. **数乘与平移**：ess sup(cX) = c·ess sup X（c ≥ 0）、
   ess sup(X+c) = ess sup X + c；
2. **子可加**：ess sup(X+Y) ≤ ess sup X + ess sup Y
  （a.s. 上界相加）——**无等式**（X = 1_A、Y = 1_{Aᶜ}
   型的互补例：左 1、右 2）；
3. **乘法**：ess sup(XY) ≤ ess sup X · ess sup Y（非负）；
4. **与积分**：ess sup X ≤ a ⟹ E[X] ≤ a·P(Ω)——Markov
   的逆弱化；|X| ≤ Y a.s. ⟹ Y 是支配（L∞ 范数的本体：
   ‖X‖∞ := ess sup|X|——**L∞ = 本性有界函数空间**，第
   13/14 章 ba 空间舞台的函数版）；
5. **与条件期望**：ess sup E[X|𝓖] ≤ E[ess sup X|𝓖]
  （Jensen 的格版——条件期望的投影保序但不保 sup 的
   等式）。

## 39.4 L∞ 与三层应用的地图

**L∞ 的户口**：‖X‖_∞ = ess sup|X|；L∞ 是 Banach 格、
Lᵖ（p<∞）的对偶终点站（第 13-14 章谱系表的 ∞ 端）、
乘法理想（L∞·Lᵖ ⊆ Lᵖ）——**ess sup 是"逐点控制"的
可测世界正版**。三个后文站点：① 鞅的极值控制（Doob
的 L∞ 型不等式，第 41 章）；② 随机过程的本性极值
（ess sup_t |X_t| 的可测性——可分修改的出场费，第 43
章）；③ 条件 ess sup（ess sup 关于子 σ-代数的条件
化——数值通道的"分块 ess sup"模型）。

## 39.4.5 ess inf 存在定理的读法与使用指南

严书 7.5.1 的主定理在实际使用中的三个常见形态：

1. **停止问题形态**：H = {某类可接受策略的报酬}，
   ess inf H = 最优下界（最优停止理论的"价值过程"是
   H 的最小上控——Snell 包络，第 42 章鞅论的直接下游）；
2. **条件化形态**：指定子 σ-代数 𝓖 上的 ess inf（一切
   成员与结果都 𝓖-可测）——适应性信息的格运算；
3. **局部化形态**：H 的元素只在 A ∈ 𝓕 上定义——ess inf
   的粘贴（零测集上的值不影响全局——a.s. 语义的自洽）。

**使用纪律**：ess inf/sup 的等式必须在 a.s. 意义下陈述
（两侧都只是等价类）；数值验证用"逐块账"（有限模型的
分块 ess sup）——与第 36 章条件期望的离散锚同款。

## 39.4.6 习题账单（自检清单）

1. 计算：ess sup(1_ℚ)（= 0）、ess sup(1_Cantor)（= 0，
   Lebesgue）、ess sup(1_Cantor)（= 1，Cantor 测度）
   ——同一函数不同测度的三账；
2. 证明子可加性并给互补反例的精确账（1_A + 1_{Aᶜ}：
   左 1 右 2，P(A) ∈ (0,1)）；
3. 有限划分模型的 ess sup 分块公式与数值对拍；
4. 构造不可数族的逐点 sup 不可测的例子（[0,1] 上
   {1_{x}：x} 的 sup ≡ 1 可测——改 {1_{V_x}} 的
   Vitali 型选择）；说明可数族的良定义性；
5. ‖X‖_∞ = 0 ⟺ X = 0 a.s.；L∞ 与 C[0,1] 的关系（连续
   代表定理：L∞ 函数何时有连续版本——Lebesgue 点论）。

## 39.5.4b 补充：可测性修饰的三行预告

不可数族 {X_t} 的 ess sup 可测性问题（39.1 第 3 条）的
标准解法是**可分修饰**（Doob）：若过程可分（存在可数
稠密指标集 D 使轨道由 D 上值决定本性极值），则
ess sup_t X_t = ess sup_{t∈D} X_t——可数化后一切良定。
第 43 章正式开工；本章只立"ess sup 的可数化门票"的
招牌。

## 39.5.5 历史注记与 L⁰ 的地位

ess sup 的系统使用始于 Koopman-Neumann（算子代数的
Borchers 一族）与概率论的条件期望时代；L⁰（a.s. 等价类
的全体）作为**完备格但非局部凸**的拓扑向量空间是泛函
分析的著名异类——它的拓扑（依测度收敛）不可度量化于
非原子空间、对偶可能平凡——**格结构（ess sup/inf）是
L⁰ 上仅存的良行为**。第 09 章四收敛矩阵中"依测度"列的
种种温和弱，正是这个异类空间的拓扑面貌；本章的格定理
（ess inf 存在）则是它在代数面的完全体。**教学定位**：
L⁰ 的格 = "随机变量的 Booleans 代数 + 完备性"——第 40
章解析集的容度论证（可容度性的 sup-逼近）在 L⁰ 格上
运转。

## 39.5.6 数值实验的读法补充

有限模型上"ess sup = sup 除以零测位"的直接实现（权表
中 μ = 0 的位置被无视）是认知锚；连续情形的数值化只能
走"尖刺测度参数化"（尖刺测度 ε → 0 时 ess sup 跳变到
低台）——**跳变时刻 = 尖刺测度离开 0 的瞬间**，这正是
"a.s. 语义对零测的不连续性"的数值显影（与第 09 章
Egorov 的 ε-带、第 27 章运走集的 δ-带同族的"模糊度
参数"）。

## 39.6 数值实验：尖刺的无视与格运算

**Julia（`39_esssup.jl`）**：

- **尖刺无视**：X = 1 + 1_{单点}（Lebesgue 离散格模型：
  μ({尖刺}) = 0）——sup = 2、ess sup = 1 的分账；尖刺
  换到正测块（μ = 1/2）后 ess sup = 2（回弹现场）；
- **ess sup vs sup 谱系**：随机函数在 1000 点格上，
  零测集（1 点）正测集（1%）不同比例的尖刺——sup 恒
  高、ess sup 随尖刺测度跳变（阶跃账）；
- **族版本**：5 个函数的逐点 max vs ess sup（数值差 =
  零测尖刺贡献）；子可加不等式的验证与互补反例；
- **条件 ess sup**：分块模型上 ess sup(X|块) 的逐块
   账（分块 ess sup 的有限版）。

**Python（`39_esssup.py`）**：Fraction 精确版——尖刺账
的精确分数（μ(尖刺) = 0 vs 1/n 的 ess sup 跳变表）、
格运算四条的精确验证、L∞ 范数的有限模型计算。

**Prolog（`39_esssup.pl`）**：符号版——`ess_sup/3`（位串
+ 权表上忽略零测位的最大值）、尖刺反例谓词、族 sup 的
穷举。
