# 第 53 章 无穷可分分布（袁 ch22）

寻找行态独立随机变量阵列部分和的极限分布族，是普遍极限问题
（54 章）的范畴；**无穷可分分布**（infinitely divisible，
i.d.）是关键的入口族——Finetti 1929 年引进概念，Lévy 与
Khinchin 1937 年给出完全刻画。特征函数方法在此被运用到极致：
三态等价定义、无处为零性、构造定理、Lévy-Khinchin/Lévy/
Kolmogorov 三大表示，构成 20 世纪古典极限定理的主干。

## 53.1 定义三形态与四个例子（袁 22.1.1）

**定义 53.A（袁 22.1）。** 三个等价视角：
  (i) d.f. 版：对每个 n ≥ 1，存在 d.f. Fₙ 使 F = Fₙ*⋯*Fₙ
      （n 重卷积）；
  (ii) ch.f. 版：φ(t) = [φₙ(t)]ⁿ（n 次根仍是 ch.f.）；
  (iii) r.v. 版：X =ᵈ Xₙ₁+⋯+Xₙₙ（n 个 iid 拷贝之和）。
用 D 记无穷可分分布族（同时记其 ch.f. 族）。

**四个常青例**（全部是 ch.f. 的指数形式，n 均分指数即分解）：
- 退化 δₐ：φ(t) = e^{iat} = [e^{iat/n}]ⁿ；
- 正态 N(μ,σ²)：φ = exp(iμt−σ²t²/2) = [exp(iμt/n−σ²t²/2n)]ⁿ；
- Poisson Po(λ)：φ = exp[λ(e^{it}−1)] = [exp((λ/n)(e^{it}−1))]ⁿ；
- Γ(α,λ)：φ = (1−it/λ)^{−α} = [(1−it/λ)^{−α/n}]ⁿ。

**两个反问题**：指数形式的 ch.f. 都 i.d. 吗？是（53.4 的
Poisson 型构造给出）；i.d. 的 ch.f. 都有指数形式吗？**否**
——指数形式要求 φ 无处为零（53.2），而 53.3 的反例族
（有界支撑、均匀分布）给出大量无处为零之外的非 i.d. 分布。
这精确划分了表示理论的疆界。

## 53.2 基本性质：无处为零与 Log 手术（袁 22.1.2）

**命题 53.B（袁 22.2）。** φ∈D ⟹ |φ|∈D。证明：φ(−t) = φ̄(t)
∈D（习题 22.1：D 对乘积封闭 ⟹ |φ|² = φ·φ̄ ∈D ⟹ |φ|² =
[φₙ]^{2n} ⟹ |φ| = [φₙ]ⁿ）。注意：**φ 是 ch.f. 但 |φ| 未必是**
——i.d. 族的模封闭性是 D 的专属福利。

**命题 53.C（袁 22.3，全章的技术枢纽）。** φ∈D ⟹ φ 无处为零。
证明是漂亮的**极限 ch.f. 手术**：|φₙ|² = ⁿ√(|φ|²) 逐点趋于
φ̃(t) = 1 若 |φ(t)|>0、0 若 |φ(t)|=0。φ(0) = 1 + 连续性给出
0 的邻域内 |φ| > 0 ⟹ φ̃ 在 0 连续 ⟹ 连续性定理（17 章）使
φ̃ 是 ch.f. ⟹ φ̃ ≡ 1（ch.f. 在 0 邻域恒 1 则恒 1）⟹ φ 无处
为零。**无处为零性把 φ^{1/n} 的歧义彻底杀死**——这是下一步
Log 手术的前提。

**注记 53.D（袁 22.4，连续对数）。** θ 连续、无处为零、θ(0)=1
⟹ 唯一写成 θ = |θ|e^{iω}，ω 连续、ω(0)=0；定义
Log θ(t) = log|θ(t)| + iω(t)（**连续分支对数**，不是主值
对数——辐角沿轨道连续展开）。于是 φ∈D 的 n 次根唯一确定：
φₙ = exp((1/n)Log φ)，且 φₙ → 1 ⟹ Xₙ₁ →ᵈ 0（分解越细，
单份越小）。

**命题 53.E（袁 22.5）。** lim n(φₙ−1) = Log φ（由
lim n(z^{1/n}−1) = Log z，习题 22.5）。**D 的"指数母函数"
ψ = Log φ 就此显形**——三大表示表示的都是 ψ。

**定理 53.F（袁 22.6，弱封闭）。** i.d.ch.f. 列 φₙ → φ
（ch.f.）⟹ φ∈D。证明：φₙ = φₙₘᵐ，φₙₘ → φ^{1/m}（0 处连续
+ 连续性定理），φ = (φ^{1/m})ᵐ。D 是弱闭集——极限分布的
候选族在弱收敛下封闭，普遍极限问题的法律框架成立。

## 53.3 构造定理与 Poisson 型（袁 22.1.3）

**定理 53.G（袁 22.7，构造定理）。** X i.d. ⟺ 存在行态独立
同分布三角阵列 {Xₙₖ} 使 Sₙ = ΣXₙₖ →ᵈ X。"⇒" 平凡（取
Xₙₖ = Xₙₖ 分解）。"⇐" 是**分组 + 胎紧**手术：任意 k，
S_{nk} = Yₙ,₁+⋯+Yₙ,ₖ（每组 k 项之和）；S_{nk} →ᵈ X 使
{Yₙ,₁} 随机有界（习题 12.33）⟹ 胎紧 ⟹ 子列 Y_{nₗ,1} →ᵈ Y
⟹ φ_X = [φ_Y]^k ⟹ X 是 i.d.。**i.d. 恰是"阵列行和的极限
族"——定义与极限问题完全对齐。**

**定义 53.H（Poisson 型，袁 22.8）。** φ(t) = exp[iαt +
λ(e^{iβt}−1)]（λ≥0）——βX+α 其中 X~Po(λ) 的 ch.f.，显然
i.d.（λ 均分即可）。

**定理 53.I（袁 22.9，Poisson 型构造）。** φ∈D ⟺ φ 在 0
连续且是有限个 Poisson 型 ch.f. 之积的极限。"⇐" 由 53.F。
"⇒"：Log φ = lim n(φ^{1/n}−1) = lim n∫(e^{itx}−1)dFₙ（Fₙ
为 φₙ 的 d.f.）；R-S 积分的分割定义把 ∫ 展开为
Σλₙᵥ(e^{iβₙᵥt}−1)（λₙᵥ = n[Fₙ(xᵥ)−Fₙ(xᵥ₋₁)]，βₙᵥ = xᵥ），
指数化即 Poisson 型积的极限。**一切 i.d. 分布都是"复合
Poisson 的极限"**——跳跃过程观点的第一次显形。

**例 53.J（袁 22.10，几何分布的 Poisson 积解剖）。**
φ(t) = (p−1)/(p−e^{it})（p>1）：Log φ = log(1−1/p) −
log(1−e^{it}/p) = Σₖ (1/kpᵏ)(e^{itk}−1)，逐项是 Poisson 型
（λₖ = 1/(kpᵏ)，βₖ = k）⟹ φ = Πₖexp[λₖ(e^{ikᵗ}−1)]∈D。
**几何分布 = 无穷多复合 Poisson 的叠加**（步长 k 的 Poisson
脉冲强度 1/(kpᵏ)）——离散 LK 表示的第一次手算。本例的
Prolog/Python 通道实弹（53.7）给出有限截断的精确对拍。

## 53.4 反例账：谁不是 i.d.（袁习题 22.1-22.9）

- **有界支撑非退化 ⟹ 非 i.d.**（习题 22.3）：X =ᵈ ΣXₙₖ 且
  |X|≤M a.s. ⟹ |Xₙₖ| ≤ M/n a.s.（独立和的支集是支集和），
  Var Xₙₖ = σ²/n，CLT 迫使极限正态——矛盾（有界支撑正态不
  存在）;
- **均匀分布非 i.d.**（习题 22.4，上条的推论）；
- **P{X=±1}=1/4 各、P{X=0}=1/2 非 i.d.**：φ(t) = 1/2 +
  (1/2)cos t 在 t=π 处为零 ⟹ 违反无处为零性（经典三点反例）。
  **警示：无处为零是必要非充分**（53.A 的反问题其二）；而
  P{±1}=1/8/P{0}=3/4 的 φ = 3/4+(1/4)cos t **恒 ≥ 1/2 永不
  为零**——零点路线对它失效（非 i.d. 须另证：53.7 的卷积根
  穷举）。
- **复合 Poisson 机器**（习题 22.8）：φ ch.f. ⟹ e^{λ(φ−1)}
  是 i.d.ch.f.（n 均分 λ/n）；22.9：φ∈D ⟹ e^{cLogφ}∈D
  （c≥0 任意幂——**i.d. 族的"连续时间化"**，Lévy 过程的
  种子）。

## 53.5 Lévy-Khinchin 表示（袁 22.2.1）

**记号**。ψ(t) = iαt + ∫(e^{itx}−1−itx/(1+x²))·(1+x²)/x²
dG(x)，α∈ℝ，G 是 q.d.f.（单调不减、右连续、G(−∞)=0、
G(∞)<∞）。被积函数 g(t,x) = (e^{itx}−1−itx/(1+x²))·
(1+x²)/x² 在 x=0 约定 g(t,0) = −t²/2（lim 计算）——
**0 处的奇异被"补偿项" itx/(1+x²) 精确吸收**，这是全表示
理论的调参核心。

**定理 53.K（袁 22.11，充分性）。** e^{ψ}∈D。证明：ε 区间
I_ε 的 R-S 分割把积分写成有限 Poisson 型对数和的极限
（λₙᵥ = (1+x²)/x²·[G(xᵥ)−G(xᵥ₋₁)] ≥ 0，βₙᵥ = xᵥ，
αₙᵥ = −λₙᵥx²/(1+x²)），53.I 收割；ε→0 时 I₊、I₋ 各自收敛
（习题 22.11 的 0 连续性），0 点跳 [G(0)−G(0−)] 贡献正态项
−t²/2·jump——**LK 表示 = 漂移 iαt + 正态跳 + Poisson 型
积分的极限**。

**引理 53.L（袁 22.12，唯一性）。** ψ 与 (α,G) 相互唯一决定。
手术是**双射链** ψ → λ → Λ → G → α：λ(t) = ψ(t) −
∫₀¹[ψ(t+h)+ψ(t−h)]/2 dh（对 t 方向做二阶对称差分的积分版），
Fubini 结算出 λ(t) = ∫e^{itx}dΛ(x)，其中 Λ(x) =
∫ˣ(1−sin y/y)(1+y²)/y² dG(y)（∫₀¹(1−cos hx)dh = 1−sin x/x！
——一次内积即完成"核的脱补偿"）；被积函数 A(y) =
(1−sin y/y)(1+y²)/y² 在 0 取值 1/3! 且全局 0 < c₁ ≤ A ≤ c₂
< ∞ ⟹ Λ 是 q.d.f. 且 λ/Λ(∞) 是 Λ/Λ(∞) 的 ch.f. ⟹ 唯一性
定理（49 章）⟹ Λ 唯一 ⟹ G 唯一（G = ∫ˣA⁻¹(1+y²)/y²… 反解）
⟹ α 唯一。**唯一性的全部成本是一次 Fubini 换序**。

**引理 53.M（袁 22.13，封闭连续）。** ψₙ = (αₙ,Gₙ)：
(i) αₙ→α, Gₙ→ʷG ⟹ ψₙ→ψ；(ii) ψₙ→ψ 且 ψ 在 0 连续 ⟹
∃α, G 使 αₙ→α, Gₙ→ʷG（λₙ → λ 一致（推论 17.26 的一致
连续）⟹ Λₙ(∞) 有界 ⟹ Helly 弱紧（32 章）⟹ Λ 极限 ⟹
Gₙ→G（习题 12.15 的 A⁻¹ 有界账）⟹ αₙ 收敛）。

**定理 53.N（Lévy-Khinchin 1937，袁 22.14）。** φ∈D ⟺ φ
具有 LK 表示 (22.7)。必要性：ψ = lim n(φ^{1/n}−1)，令
αₙ = n∫x/(1+x²)dFₙ、Gₙ(x) = n∫₋∞ˣ y²/(1+y²)dFₙ(y) ⟹
ψ = lim ψₙ（53.E 的展开重排），引理 53.M (ii) 给极限 (α,G)。
**谱函数 G 的读法**：G 在 x 处的质量密度 ∝ n·Fₙ 的"单位
跳跃贡献"——n 份分解的极限浓缩。

**例 53.O（袁 22.15，三例的 (α,G) 账）**：
- δₐ：α = a，G ≡ 0；
- N(μ,σ²)：α = μ，G = σ²·I_{[0,∞)}（0 处跳 σ²——正态 =
  纯 Brown 分量）；
- Po(λ)：Log φ = λ(e^{it}−1) = i(λ/2)t + λ(e^{it}−1−it/2)，
  故 α = λ/2，G = (λ/2)·I_{[1,∞)}（1 处跳 λ/2——
  **补偿项把"纯跳跃"伪装成"带漂移"**，α 不是直觉的 0）。

## 53.6 Lévy 表示与 Kolmogorov 表示（袁 22.2.2-3）

**Lévy 表示（1934，袁 22.18）** 把 G 拆成三件套：σ² =
G(0)−G(0−)（正态分量）、M(x) = ∫_{−∞}ˣ(1+y²)/y² dG(y)
（x<0，负半轴谱）、N(x) = −∫_x^∞(1+y²)/y² dG(y)（x>0）。
φ∈D ⟺ φ = exp[iβt − σ²t²/2 + ∫_{(−∞,0)}(e^{itx}−1−
itx/(1+x²))dM(x) + ∫_{(0,∞)}(…)dN(x)]，且 (M,N) 满足：
M 在 (−∞,0) 单调不减右连续 M(−∞)=0，N 在 (0,∞) 同且
N(∞)=0，∫_{−δ<x<0}x²dM + ∫_{0<x<δ}x²dN < ∞（**原点邻域的
平方可积——小跳必须足够温和**）。推论 22.19 的 Lévy 测度
μ（μ{0}=0 的有限测度化版本）是 Lévy 过程理论的直接入口。

**Kolmogorov 表示（1932，袁 22.20-22.21，方差有限特化）**。
ψ(t) = iγt + ∫(e^{itx}−1−itx)/x² dK(x)（核在 0 约定 −t²/2，
|g| ≤ t²/2 使积分无条件收敛——**有限方差替换了补偿项的
必要性**）。唯一性（引理 22.20）：ψ''(t) = −∫e^{itx}dK(x)
⟹ −ψ''/K(∞) 是 K/K(∞) 的 ch.f. ⟹ K 唯一。**定理 22.21**：
φ∈D 且方差有限 ⟺ Kolmogorov 表示。必要性手术：方差有限 ⟹
ψ 两阶可导（17 章矩-导数词典）⟹ −ψ''(0) = lim∫(sin²hx/h²)
(1+x²)/x² dG < ∞ ⟹ 连续参数 Fatou（习题 7.32）⟹
∫(1+x²)dG < ∞ ⟹ ∫|x|dG < ∞ ⟹ K(x) = ∫ˣ(1+y²)dG(y)、
γ = α + ∫ydG(y) 良定义。命题 22.22 结清参数语义：**期望 γ、
方差 K(∞)**（ψ'(0)=iγ, ψ''(0)=−K(∞) ⟹ φ'(0)=iγ,
φ''(0)=−K(∞)−γ²）——**K 的总质量就是方差**。

**收敛条件**（袁 22.3）：LK 版（定理 22.23）φₙ→φ ⟺
Gₙ→ʷG 且 αₙ→α；Lévy 版（定理 22.24）三条件 (A) 谱函数逐点、
(B) 漂移 βₙ(τ)→β(τ)、(C) 原点能量 lim_ε lim_n[∫x²dMₙ+
σₙ²+∫x²dNₙ] = σ²——脚注警告 **σₙ² ↛ σ²**（正态原子可以
被小跳序列"走私"掉，能量账只在 (C) 的双极限里守恒）；
Kolmogorov 版（定理 22.25）φₙ→φ 且 Kₙ(∞)→K(∞) ⟺
Kₙ→ʷK, γₙ→γ（证明：t→∞ 挤 γ；Helly + C₀(ℝ) 被积函数 +
唯一性）。**表示的收敛理论 = 弱收敛法律在参数空间的直译**。

## 53.8 历史注记与要点回顾

Finetti（1929）引入概念；Kolmogorov（1932）给出有限方差版
表示；Lévy（1934）给出 (M,N) 谱表示；Lévy-Khinchin（1937）
的 G 表示是完全刻画——**四年三代表示，一年比一年一般**。
Raikov-Ottaviani 定理（习题 22.13 脚注：X₁+X₂~Po(λ) 独立 ⟹
各 Poisson，去掉 i.d. 也成立）是分解理论的逆向明珠；Cramér
定理（正态版：和正态 ⟹ 各正态）同族。Lévy 测度观点在
1960s 由 Itô 等人的 Lévy 过程理论完全接管——无穷可分分布
是"带跳随机过程"的分布侧身份证。

要点回顾：
1. i.d. 三形态等价：n 重卷积 / ch.f. n 次根 / iid 和分解；
   阵列行和极限 ⟺ i.d.（构造定理）。
2. 无处为零性 ⟹ 连续 Log 手术 ⟹ ψ = Log φ 良定义 ⟹
   lim n(φ^{1/n}−1) = ψ——一切表示表示的都是 ψ。
3. LK 表示：ψ = iαt + ∫(e^{itx}−1−itx/(1+x²))(1+x²)/x² dG；
   补偿项吸收 0 点奇异；唯一性 = 一次 Fubini（1−sin x/x 核）。
4. 三例账：δₐ=(a,0)、N=(μ,σ² 阶跃)、Po=(λ/2, λ/2 阶跃于 1)；
   Lévy 版拆 0 点跳（正态）与两半轴谱；Kolmogorov 版
   （方差有限）期望 γ、方差 K(∞)。
5. 收敛条件：LK 版 Gₙ→ʷG+αₙ→α；Lévy 版 (A)(B)(C) 三件套
   （σₙ²↛σ²——原点能量的双极限守恒）；Kolmogorov 版加
   Kₙ(∞)→K(∞)。
6. 反例账：有界支撑/均匀/三点（φ(π)=0）皆非 i.d.；
   无处为零必要非充分；复合 Poisson 机器 e^{λ(φ−1)} 是
   i.d. 的免费工厂。
7. 机器分工：mathlib 无 i.d. 基础设施——Lean 以卷积幂承载
   Poisson/Gauss 的 n 重分解定理；数值通道对拍 Poisson 积重建
   （Panjer 1e−17）、Bochner 破产（1−√2）与分解搜索。
