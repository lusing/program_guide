## 57.2 测度论核心定理卡

**扩张链条**：半环上的 σ 可加集函数 → 外测度（Carathéodory）
→ 唯一扩张到 σ(半环)（σ 有限时）。**π-λ 定理**是唯一性的
引擎：两测度在 π 系上相等 + σ 有限 ⟹ 在 σ(π) 上相等。

**单调类三件套**： monotone class（集合版，02 章）/ π-λ
（Dynkin）/ 泛函单调类（08 章）——三者都是"小类生成大类"
的同一原理三次出场。

**Radon-Nikodym**（12 章）：μ ≪ ν + σ 有限 ⟹ dμ = f dν。
**Lebesgue 分解**：μ = f·ν + μ⊥。**Jordan-Hahn**（12 章）：
符号测度 = 正部 − 负部（唯一）。

**Fubini-Tonelli**（18 章）：σ 有限 × 可测 ⟹ 逐项积分 =
重积分；非负情形 Tonelli 无条件换序。

**三个反例常备**：非可测集（Vitali）；Fatow 不等号（严格的
正测度侧）；乘积 σ 代数真包含于 Borel 乘积（非第二可数）。

## 57.3 收敛模式谱系（09 章 + 30-34 章）

```
a.s. 收敛 ──┐
            ├─→ 依概率 ─→ 依分布（弱收敛）
Lᵖ 收敛 ────┘        ↑
                     └── 子列原理：依概率 ⟹ a.s. 子列
```

- **依测度/概率**：∀ε，μ{|fₙ−f|>ε} → 0；
- **几乎一致（Egorov）**：有限测度上 a.s. ⟹ 挖 ε 后一致；
- **弱收敛刻画**（31 章）：一切有界连续函数的积分收敛；
- **Portmanteau**（31 章）：开集下界/闭集上界/连续集边界零；
- **Skorokhod 表示**（32 章）：弱收敛 ⟹ a.s. 表示（CDF 逆）；
- **Prohorov**（32 章）：胎紧 ⟺ 相对紧（Polish 空间）；
- **vague**（34 章）：C₀/C_c 检验函数（丢失质量到无穷）。

## 57.4 条件期望与鞅（36-43 章）

**条件期望定义**：E[X|G] 是 G 可测的"最优投影"（L² 投影 /
Radon-Nikodym 导数两幅面孔）。**塔性质**：F₁⊂F₂ ⟹
E[E[X|F₂]|F₁] = E[X|F₁]。**Jensen**：凸 φ ⟹ φ(E[X|G]) ≤
E[φ(X)|G]。

**鞅三定律**（41-42 章）：
- **Doob 分解**：适应列 = 可料 + 鞅（唯一）；
- **Doob 不等式**：E[max Xₖᵖ] ≤ (p/(p−1))ᵖ E[Xₙᵖ]；
- **上穿不等式** → **收敛定理**：sup E[Xₙ⁺] < ∞ ⟹ a.s.
  收敛；UI ⟺ L¹ 收敛 ⟺ Doob-Levy 表示（Vitali 合龙）。

## 57.5 特征函数计算库（49 章）

| 分布 | φ(t) | 备注 |
|---|---|---|
| δₐ | e^{iat} | n 根存在 |
| N(μ,σ²) | e^{iμt−σ²t²/2} | i.d.（σ²/n 均分） |
| Po(λ) | exp[λ(e^{it}−1)] | i.d.（λ/n 均分） |
| Γ(α,λ) | (1−it/λ)^{−α} | i.d. |
| 均匀 | sin(t/2)/(t/2)·e^{it/2} | 有零点 → 非 i.d. |
| Cauchy | e^{−\|t\|} | 稳定 α=1 |
| 两点 ±1 | cos t | Bin 的母函数 |

**三大定理**：唯一性（φ 定分布）；卷积→乘法
（φ_{X+Y} = φ_X·φ_Y）；**Lévy 连续性**（φₙ→φ(0 处连续)
⟹ 弱收敛 + φ 是 ch.f.）。

**矩-导数词典**：E[Xⁿ] = i^{−n}φ⁽ⁿ⁾(0)（矩存在时双向）。

## 57.6 极限定理全景（48-56 章）

**不等式四代**（48 章）：Markov/Chebyshev（单变量）→
Kolmogorov max/上穿（运行最大）→ MZ/Rosenthal（高阶矩）→
Hájek-Rényi/Etemadi（时变/两两独立）。

**大数律谱系**（50-51 章）：

| 定理 | 条件 | 结论 | 归一化 |
|---|---|---|---|
| Markov LLN | n⁻²ΣVar → 0 | Sₙ/n →ᵖ EX | n |
| Khinchin WLLN | iid E\|X\|<∞ | Sₙ/n →ᵖ EX | n |
| MZ WLLN | iid E\|X\|ᵖ<∞ (p<2) | n^{−1/p}Sₙ →ᵖ 0 | n^{1/p} |
| Kolmogorov SLLN | iid E\|X\|<∞ | Sₙ/n → EX a.s. | n |
| 三级数 | 独立（无矩） | ΣXₙ a.s. 收敛 ⟺ 三级数 | — |

**CLT 家族**（52 章）：Lindeberg-Feller 充要（无单主导项）；
Lyapunov 充分（δ 阶矩）；Berry-Esseen 速率 36γ³/(√nσ³)；
Cramér-Wold 多维降维；Delta 方法（渐近链式法则）。

**普遍极限与稳定**（54-55 章）：独立阵列的非退化极限族 =
无穷可分全体 D；iid 四情形（δ/正态 √n/Poisson n/稳定
n^{1/α}）；尾平衡 n·P{±X>aₙ}→c± ⟺ 稳定极限；α ≤ 2 的
国境线（α>2 ⟹ EX²<∞ ⟹ CLT 拆台）。

**LIL**（56 章）：limsup Sₙ/√(2n log log n) = σ a.s.
（EX²<∞ 最优）——SLLN 的精修，包络的精确刻度。

## 57.7 无穷维测度（44-47 章）

**Bochner**（44 章）：φ 正定连续 φ(0)=1 ⟺ φ 是某测度的

## 57.9 证明技术十式（全书复用率最高的招）

1. **截尾**：重尾问题先砍到 |X|≤c（三级数/CLT/SLLN 全用）；
2. **对称化**：X−X′ 化非对称为对称（52/53 章）；
3. **子序列法**：k² 子列先证再夹（51 章）；
4. **Borel-Cantelli 双向**：ΣP 收敛/发散定 0/1（35/56 章）；
5. **π-λ/单调类**：小类验证大类等式（02/08 章）；
6. **停时/首穿**：运行最大 ≤ 停时分解（41/48 章）；
7. **特征函数三步**：Taylor 展开 → 取实部 → 连续性收割
   （52/53 章）；
8. **分组+胎紧**：和的收敛 ⟹ 分量随机有界（54 章）；
9. **三明治夹逼**：单调性 + 逐点 ⟹ 一致（GC 定理，51 章）；

## 57.11 快速公式卡

**积分极限三定理**：单调收敛（0≤fₙ↑f）；Fatou
（∫liminf ≤ liminf∫）；控制收敛（|fₙ|≤g 可积）。

**Lᵖ 对偶**：(Lᵖ)* = L^q（1<p<∞，σ 有限）；L¹ 的对偶 =
L∞（σ 有限）；L∞ 的对偶 = ba（有限可加荷，14 章）。

**条件期望的取出**：G 可测的 Y：E[XY|G] = Y·E[X|G]。

**方差分解**：Var(X) = E[Var(X|G)] + Var(E[X|G])。

**Doob 上穿数**：E[ν([a,b])] ≤ E[(Xₙ−a)⁻]/(b−a)。

**Chapman-Kolmogorov**：κ₁∘κ₂ 复合核的转移账（19 章）。

**尾平衡**：n·P{X>aₙ} → c ⟹ aₙ ~ (n/c)^{1/α}·L(n)。

**LIL 包络**：±σ√(2n log log n)——触界无穷次、不穿越
（乘 1+ε）。

## 57.13 五通道验证哲学（收官方法论）

全书 210 个验证单元背后的**纪律**，值得单独一页：

1. **精确优先**：恒等式用 Fraction/SWI 有理数判 `=:=`，
   浮点只做量级断言——"标记 ≠ 算对"的教训写进了每个
   `build.ps1` 的头尾标记对账（`==== NN` / `END ====`）；
2. **有限 n 诚实账**：渐近定理的数值验证只断言理论量级与
   方向（LIL 的 log log 慢修正、1/log 尺度的 WLLN、有限
   格点的 CDF 中心差）——不冒领渐近常数；
3. **分工如实**：mathlib 没有的基础设施（i.d./稳定/LIL/
   普遍极限）不硬凑——docs 承载理论 + 已有零件的实弹
   （B-C 引理、卷积幂、复合利息极限）；有的基础设施
   （strong_law_ae、CLT、AnalyticSet）就完整收割；
4. **机器抓数学错**：三点反例的 1/8-3/4 版（永不零）、
   CMS 公式的手写版（高斯行为）、能量账的方差项——全部
   由数值通道首先暴露，再回改 docs 与代码；
5. **每章自包含**：docs 不让读者翻原书——定理陈述、证明
   解剖、实验断言三件套齐备；代码全部在正文引用讲解。
