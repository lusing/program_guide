## 26.1 从 C_c 到 C₀：把"紧支撑"放松成"消逝"

C_c(X) 上第 24 章的 Riesz 定理已经很好，但泛函分析更爱的
舞台是 **C₀(X)**：在无穷远处消逝的连续函数全体——

  C₀(X) = {f ∈ C(X)：∀ε > 0, ∃紧 K，|f| < ε 于 X ∖ K}，
  配一致范数 ‖f‖∞。

C_c(X) 在 C₀(X) 中稠密（截断 + 磨光的例行公事）；当 X 紧
时 C₀ = C（一切函数自动"消逝"）。**C₀ 是 Banach 空间**——
完备性使对偶理论（Hahn-Banach、范数达到）全面可用，这是
C_c（一般只有局部凸拓扑）给不了的。经典的例子们：C₀(ℕ) =
c₀（收敛到 0 的序列）；C₀(ℝ) = 连续且 lim_{|x|→∞} f = 0；
单点紧化 X⁺ = X ⊔ {∞} 上 C(X⁺) 中"在 ∞ 处取 0"的闭子空间
恰是 C₀(X)——**C₀ = 单点紧化的约束函数空间**，这个视角把
非紧空间的问题翻译成紧空间的问题（第 29 章 Polish 讨论的
常用渡口）。

## 26.2 对偶定理（严书 5.4.1-5.4.2）

**定理（C₀(X)\* = 符号 Radon 测度）**：X 为 LCH。对每个
连续线性泛函 Λ ∈ C₀(X)\*，存在**唯一的符号 Radon 测度**
ν（有限总变差 |ν|(X) < ∞、正负部 ν⁺/ν⁻ 都是 Radon，见
第 12 章）使

  Λ(f) = ∫ f dν（一切 f ∈ C₀(X)），且 ‖Λ‖ = |ν|(X)（保范）。

反向显然：每个符号 Radon ν 定义上述泛函。于是**线性代数
等式**：C₀(X)\* ≅ M_Radon,signed(X)（符号 Radon 测度空间，
配总变差范数）。

**证明骨架（Jordan 分解 + 正情形 RMK，严书 5.4.1 的思路）**：

1. **正部分离**：对 Λ 作 Jordan 式分解（C₀ 版）：定义
   Λ⁺(f) = sup{Λ(g)：0 ≤ g ≤ f}（f ≥ 0），则 Λ⁺、Λ⁻ =
   Λ⁺ − Λ 都是**正**线性泛函且 Λ = Λ⁺ − Λ⁻——符号泛函的
   Hahn 分解（第 12 章测度版的手工移植，或走
   "Λ = Λ₁ − Λ₂ + iΛ₂′ 的四分解"复情形）；
2. **正情形引用**：Λ⁺ 延拓到 C_c（C₀ 稠密 + 正泛函连续
   自动延拓）→ 第 24 章 RMK 给 Radon 测度 μ⁺；同理 μ⁻；
3. **装配**：ν = μ⁺ − μ⁻，∫f dν = Λ⁺(f) − Λ⁻(f) = Λ(f)；
4. **范数账**：|Λ(f)| ≤ ∫|f|d|ν| ≤ ‖f‖∞·|ν|(X) 给 ≤；
   取 f ≈ dν/d|ν| 的 C₀ 逼近（第 12 章 RN 导数 ‖·‖∞ ≈ 1）
   给 ≥ ——合龙 ‖Λ‖ = |ν|(X)。∎

**唯一性**：两符号 Radon 在 C₀ 同账 ⟹ 正部同账（Jordan 分解
的唯一性）⟹ RMK 唯一性。

## 26.3 对偶词典：泛函 ↔ 测度的完整对照

| 泛函侧（C₀(X)\*） | 测度侧（符号 Radon） | 章 |
|---|---|---|
| 正泛函 0 ≤ Λ | 正 Radon 测度 | 24 |
| ‖Λ‖ | 总变差 \|ν\|(X) | 12 |
| Λ 的 Jordan 分解 | ν⁺ − ν⁻ | 12 |
| 点评价 δ_x(f) = f(x) | Dirac 测度 δ_x | 07 |
| Λ(f) = ∫f g dμ（g ∈ L¹）| 密度测度 g·μ | 12 |
| 复泛函 Λ = Λ₁ + iΛ₂ | 复测度 ν₁ + iν₂ | — |

词典的使用方向：**泛函分析问题翻译成测度论问题**（或反
向）。两个经典翻译：(a) C₀(X)\* 的弱\*拓扑 = 测度的淡收敛
（第 34 章，vague = weak\*——本章的直接后果）；(b) 正泛函
锥的极点 = Dirac 测度（Choquet 理论入口，第 40 章容度的
邻居）。

## 26.4 三个具体空间的实弹对照

**X = ℕ（离散）**：C₀(ℕ) = c₀。对偶 c₀\* = ℓ¹（序列版）——
符号 Radon 测度 = 可求和符号序列（每点质量可正可负，
Σ|νₖ| < ∞）。**泛函-序列词典**：Λ(x) = Σνₖxₖ——第 13 章
Lp 对偶表的序列版首行，在此获得测度论户口。

**X = ℝ**：C₀(ℝ)\* = 符号 Radon 测度。例：Λ(f) = f(0) −
f(1) 对应 ν = δ₀ − δ₁（‖Λ‖ = 2 = |ν|）；Λ(f) = ∫f g dλ
（g ∈ L¹）对应 g·λ。**密度测度与原子测度在同一空间混居**——
对偶空间的丰富性的测度论原文。

**X 紧（C(X)\*）**：Riesz 原始定理的舞台（1909）：紧空间上
连续函数对偶 = 符号 Radon 测度——本节的一切在 X 紧时回归
历史原版。C(X) 与 C₀(X) 的关系经单点紧化互通：C(X⁺)\* 的
"在常函数上的账"分出总质量，其余部分对应 C₀(X)\*。

## 26.4.5 单点紧化的函数账（C₀ 视角的技术细节）

X⁺ = X ⊔ {∞}（开集 = X 的开集 ∪ {∞}∪(X∖K)，K 紧）。三
条函数账：

1. **C(X⁺) ≅ C₀(X) ⊕ ℝ**：f ↦ (f − f(∞), f(∞))——约束
   子空间 + 常数；对偶层面 M(X⁺) = M_c(X) ⊕ ℝ（"带总质量
   分量的测度"）；
2. **泛函延拓的桥梁**：C₀(X)\* 的 Λ ↪ C(X⁺)\*（Λ⁺(g) =
   Λ(g − g(∞))，在常函数上账 0）——**弱\*拓扑的对应**：
   C₀ 的弱\* = M(X⁺) 弱\*中"总质量 0 超平面"的限制（淡
   收敛的定义动机，第 34 章正题）；
3. **X 紧时的一切退化**：∞ 孤立点，C₀ = C，本章 = 第 24
   章的符号版——对偶定理的谱系在同一框架内。

**教学对位**：第 17-22 章的"柱集 vs 乘积"两套坐标、本章的
"C₀ vs C(X⁺)⊕ℝ"——数学结构的多视角对账是本书反复出现
的操作系统。

## 26.3.5 弱\*拓扑预告（第 34 章的种子发芽）

C₀(X)\* ≅ M_radon(X)（本章）直接定义**淡收敛（vague）**：
νₙ → ν vague ⟺ ∫f dνₙ → ∫f dν 对一切 f ∈ C₀(X)——即
弱\*收敛的测度版。三条即刻观察：(a) 总质量**不守恒**
（C₀ 看不见逃逸质量：δₙ → 0 vague 于 ℝ——第 34 章逃逸
例的机制）；(b) 若改成 C_c 检验族，收敛更弱（紧支撑看不
见更远的逃逸）；(c) 若 X 紧，C₀ = C，淡收敛 = 弱收敛
（第 31 章）——**收敛强度的谱系由检验函数族决定**，本章
的函数空间分层就是第 30-34 章收敛谱系的分档器。

## 26.7.5 习题账单（自检清单）

1. X = ℕ：验证 c₀\* = ℓ¹ 的保范同构（Λ(x) = Σνₖxₖ，
   ‖Λ‖ = Σ|νₖ|；达范向量 xₖ = sign(νₖ)）；
2. Λ(f) = f(0) − f(1) + ∫f dλ 于 C₀(ℝ)：写出 Jordan 分解
   与总变差（ν = δ₀ − δ₁ + λ，|ν| = δ₀ + δ₁ + λ，
   ‖Λ‖ = 2 + ∞？——局部紧非 σ-有限时 L¹ 密度不有限！
   此题改为 [0,1] 上版本收尾）；
3. 证明泛函 Jordan 分解的唯一性（Λ⁺ 的极小性刻画）；
4. 复泛函的四分解 Λ = Λ₁ − Λ₂ + iΛ₃ − iΛ₄ 与复测度的
   对应（正部/虚部各自的 Jordan）；
5. 用单点紧化证明：正泛函 Λ ∈ C₀(X)\* ⟺ 其 C(X⁺) 延拓
   在常函数 1 上非负（正性的紧化判据）。

## 26.4.6 c₀ 与 ℓ¹ 的对偶细账（离散实弹的完全体）

X = ℕ 的完整词典（有限情形的数值实验之理论原型）：

- **空间**：c₀ = {x : xₙ → 0}，‖x‖ = sup|xₙ|（Banach，
  C₀(ℕ) 的化身）；c₀ 的对偶 ℓ¹；ℓ¹ 的对偶 ℓ^∞——经典
  三级火箭 c₀ ⊂ ℓ^∞、(c₀)* = ℓ¹、(ℓ¹)* = ℓ^∞；
- **测度户口**：符号 Radon 于 ℕ = 符号序列 ν = (νₖ)，
  Σ|νₖ| < ∞；正测度 = 非负可和序列；总变差 |ν|(ℕ) =
  Σ|νₖ| = ‖Λ‖（26.2 保范的序列原文）；
- **达范向量**：xₖ = sign(νₖ) ∈ c₀（有限支撑截断逼近
  达范——c₀ 中 sign 向量若 ν 不有限支撑则只在极限处
  达范，逼近账 ‖Λ‖ 的 sup 定义）；
- **对照第 13 章**：这是 Lp 对偶表在 p = ∞ 列的"测度论
  侧写"——(ℓ^∞)\* 严格大于 ℓ¹（ba 空间，第 14 章）而
  (c₀)\* = ℓ¹ 恰好——**"消逝"条件砍掉了越轨泛函的生存
  空间**（有限可加荷在 c₀ 上仍有限可加但被 ℓ¹ 收编？
  不——第 14 章的自然密度荷在 c₀ 上 = 0 泛函：密度荷对
  消逝序列的账为 0——**越轨者在 c₀ 上集体隐身**，对偶
  因此干净）。

## 26.5 数值实验：Jordan 拼装与保范账

**Julia（`26_c0_dual.jl`）**：X = {1,2,3,4,5}（离散，C₀ =
c₀ 有限版）：

- **符号泛函的 Jordan 分解**：给 Λ 由权 (2, −3, 0, 1.5, −0.5)
  定义——数值计算 Λ⁺ = (2,0,0,1.5,0)、Λ⁻ = (0,3,0,0,0.5)
 （逐点正负部），验证 Λ = Λ⁺ − Λ⁻ 与 |ν| 权 = 逐点 |·| ；
- **保范账**：‖Λ‖ = Σ|νᵢ| = 7；构造近极向量 f\* = sign(ν)
  （C₀ 的单位球内，有限维达范）验证 |Λ(f\*)| = 7 —— 保范
  等式的达范现场；
- **密度情形**：X = [0,1] 连续版，g = x − 1/2（符号），
  Λ(f) = ∫f g dλ：数值积分 vs 闭式 ∫f(x)(x−1/2)dx 对三个
  测试函数对拍；‖Λ‖ = ∫|g| = 1/4 显式核对。

**Python（`26_c0_dual.py`）**：Fraction 精确版 Jordan 分解
与保范账（有限空间全精确）；g 的 ∫|g| 精确 = 1/4（多项式
积分的精确分数）。

## 26.6 Lean：正侧主定理 + docs 层拼装（分工如实）

mathlib 实况：**符号/复版 RMK 未打包**（`RealRMK` 处理正
线性泛函；Jordan 分解在 `SignedMeasure` 层有、但"符号 RMK"
的桥梁定理缺）。`Ch26C0Dual.lean` 的诚实方案：

1. **锚点 #check**：`RealRMK.integral_rieszMeasure`（正情形
   的完全体）+ `BoundedContinuousFunction`/`C_c` 类型正名
  （C₀ 的机器对应：紧空间上 BoundedContinuousFunction =
   C(X)；一般 LCH 的 C₀ 无专门类型，Bounded +
   ZeroAtInfty 谓词组合）；
2. **点评价泛函的测度户口**：δ₀(f) = f(0) 的正线性 + 其
   Riesz 测度 = dirac 的账目核对（`integral_dirac` 收割）；
3. **Jordan 侧的引用**：`SignedMeasure` 与 Jordan 分解锚点
   （第 12 章件）过目——拼装路线的零件清单。

## 26.7 要点回顾

1. C₀(X)（消逝连续函数，Banach）取代 C_c 获得完备性；
   单点紧化视角：C₀ = C(X⁺) 的约束子空间。
2. C₀(X)\* = 符号 Radon 测度（保范同构）：证明 = 泛函 Jordan
   分解 + 正情形 RMK + 范数三明治。
3. 对偶词典六行：评价/密度/分解的全部翻译条目；弱\*拓扑
   = 淡收敛（第 34 章的种子）。
4. 实弹：c₀\* = ℓ¹（序列户口）、δ₀−δ₁、g·λ——原子与密度
   混居的对偶空间。
5. 机器侧分工如实：正泛函侧 `RealRMK` 主定理机器化；符号
   版由 docs 拼装 + 数值通道保范账。
