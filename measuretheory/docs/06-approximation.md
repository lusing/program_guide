# 06 测度的逼近

**对应严书 §1.6（pp. 24-26）。**

---

## 6.1 唯一性：测度论的"解析延拓"

第 04 章造出了测度，第 05 章给了原料；本章关门上锁：**在生成系上相等
的 σ-有限测度只有一个**。它的意义怎么强调都不过分——我们从来不需要
在完整的 σ-代数上验证两个测度相等，只需在小小的生成 π-系上核对：

> **定理（唯一性 / 逼近）** 设 C 是 π-系，σ(C) = 𝓕，且存在 C 中序列
> Bₙ ↑ Ω 使 μ(Bₙ) = ν(Bₙ) < ∞。若 μ, ν 在 C 上相等，则 μ = ν。

结构（第 02 章 Dynkin π-λ 定理的直接重放）：{A : μ(A) = ν(A)} 包含
π-系 C；在 μ(Bₙ) < ∞ 的条件下它是 λ 类（真差封闭要用减法——这正是
有限性条件的用武之地；不交并封闭由测度连续性给出）；π-λ 定理把它
撑到 σ(C)。

"逼近"是同一枚硬币的另一面（6.2 节展开严书 1.6 全部机器）：对
σ-有限测度，任意可测集的测度可以用生成类中集合的可数并从内侧
（有限时再从外侧）逼近。实践里这就是"用简单集合算复杂集合"的
许可证——数值实验里"二进区间逼近 Lebesgue 测度"的合法性全由它背书。

## 6.2 逼近定理：H-类引理与单调类收官（严书 1.6）

唯一性是"相等"的一面，逼近是"计算"的一面。严书 §1.6 的主定理回答：
**F 中任一集合的测度，何时能用小子类 C 里的集合算到？** 先记
C_σ = {⋃ₙ Cₙ : Cₙ ∈ C}（C 的可数并族）。

**引理（H-类，严书 1.6.1）** 设 C ⊆ F 任意，令

  H = {A ∈ F : μ(A) = sup{μ(B) : B ⊆ A, B ∈ C_σ}}，

则 C_σ ⊆ H（每个 B 用自己逼近自己），且 H 满足：

1. Aₙ ∈ H, Aₙ ↑ A ⟹ A ∈ H；
2. Aₙ ∈ H 且 μ(Aₙ) < ∞ ⟹ ⋂ₙ Aₙ ∈ H。

特别地，**μ 有限时 H 是单调类**且对可列交封闭。

证明的两次出手值得背下来。升列：对每个 Aₙ 取 εₙ-最优内侧逼近
Bₙ ∈ C_σ（μ(Bₙ) ≥ μ(Aₙ) − εₙ），则 ⋃Bₙ ∈ C_σ、⊆ A，且
μ(⋃Bₙ) = lim μ(⋃ₖ≤ₙ Bₖ) ≥ limsup μ(Bₙ) ≥ lim μ(Aₙ) − εₙ——
**下方连续性把逐项逼近抬成整体逼近**。降列：μ(A₁) < ∞ 时上方连续
给 μ(⋂Aₙ) = lim μ(Aₙ)，同样的 ε-逼近取交集即可（这就是为什么需要
有限性——第 03 章的计数测度反例在这里收费）。

**定理（逼近，严书 1.6.3）** 设 μ σ-有限，C ⊆ F 满足：∅ ∈ C、
对有限交封闭（π-系）、C_σ 对有限并封闭（从而 C_σ ⊇ 代数壳）、
σ(C) = F。则对一切 A ∈ F：

  μ(A) = sup{μ(B) : B ⊆ A, B ∈ C_σ}。   (1.6.1)

**证明三步**（严书路线）：

1. **有限情形，单调类收官**：μ 有限时 H 是包含代数 C_σ 的单调类，
   第 02 章单调类定理（严书 1.2.5：代数生成的单调类 = 生成的
   σ-代数）给 H ⊇ m(C_σ) = σ(C_σ) = σ(C) = F。
2. **截断技巧**：一般的 σ-有限 μ、μ(A) < ∞ 的 A——令
   ν(E) = μ(E ∩ A)，这是**有限**测度，第一步的结论对 ν 成立；在
   E = A 处读出 sup{μ(B) : B ⊆ A, B ∈ C_σ} = ν(A) = μ(A)。截断
   是把"局部有限"折成"整体有限"的标准折纸。
3. **μ(A) = ∞**：取 Aₙ ∈ F，μ(Aₙ) < ∞，Aₙ ↑ A（σ-有限性），
   则 sup{μ(B) : B ⊆ A} ≥ μ(Aₙ) → ∞，等式平凡成立。

**推论（双侧逼近，严书 1.6.4）** μ 有限时还有**外侧**版本：

  μ(A) = inf{μ(C) : A ⊆ C, C ∈ D_σ}，D = {Cᶜ : C ∈ C}，

——把内侧逼近用到 Aᶜ 再取补即可。内外双逼近是"用简单集合夹住
复杂集合"的完整许可证。

**为什么逼近类是 C_σ 而不是 C？** 直接用 C 不够：A 可能与任何
单个 C-成员都"形状不合"（如 A 是两个不交区间之并，而 C 只含区间
——第 01 章的半环老朋友）。但把 C 升级到可数并 C_σ **不损失可
计算性**：B = ⋃Bₙ ∈ C_σ 的测度由下方连续性 = lim 部分和，仍是
"对 C 逐项取值再取极限"。换句话说，C_σ 是"既比 C 大得多、又与 C
同样可算"的最小升级——定理在这个 sweet spot 上工作。同理，双侧
逼近的外侧类 D_σ 是"可数交的补"，有限测度下由上方连续保持可算。
回头看第 04 章：外测度定义为对**可数覆盖**取 inf，正是同一枚硬币
——覆盖与内侧逼近在 σ-有限处会师，这就是扩张定理与逼近定理的
内在一致性。

**习题 1.6.1（前瞻）**：X 距离空间、μ 在 (X, B(X)) 上 σ-有限时，
闭集从内、开集从外逼近 μ(B)。拓扑入场后 C 换成闭集族/开集族——
这正是第 25 章**正则测度**的种子：本章的纯测度论机器，加上紧性，
就长成 Radon 测度理论。

## 6.3 两个前提各管什么：反例集

唯一性与逼近各有两个前提——生成性（σ(C) = F）与 σ-有限性。反例
把它们的分工钉死。

**σ-有限缺失**（唯一性失效）：取 Ω = ℕ，𝓕 = σ({A})，A = 偶数集
（𝓕 = {∅, A, Aᶜ, Ω}）；μ = 计数测度，ν = "按 2 计数"。两者都在
生成系 {A} 上取值 ∞——"相等"，但 μ({1}) = 1 ≠ 2 = ν({1})。
**生成系上的无限值相等毫无约束力**：1 = 1 是信息，∞ = ∞ 不是。

**生成性缺失**（逼近失效）：同一张权重表在**非生成**子族上相等
不保证全等——第 6.5 节 Prolog 对照实验的正面演出：权重表
[1,2,3,4] 与 [1,2,4,3] 在 {Iic 1, Iic 2} 上取值相同（1 与 3），
在 Iic 3 上分道扬镳。顺带一个朴素的事实（实验最初的设计错误）：
有限宇宙上，**任何**两张不同权重表都不可能在全部 Iic 上相等——
Iic 值经差分唯一决定权重。唯一性定理在有限世界是平凡的，它的
全部内容都在无穷处。

## 6.4 Lean：唯一性机器的实弹射击

mathlib 的 `Measure.ext_of_generateFrom_of_iUnion` 正是定理本体
（`Ch06Approximation.lean` 演示完整调用）。我们在 ℕ 上选 π-系
C = {Iic n}（初始段），先用"单点集 = Iic(k+1) ∩ (Iic k)ᶜ"证明
σ(C) = 全幂集：

```lean
private theorem iic_gen :
    (MeasurableSpace.generateFrom {s : Set ℕ | ∃ n, s = Set.Iic n}) = ⊤ := by
  ...
  have hsg : ∀ k : ℕ, MeasurableSet[MeasurableSpace.generateFrom C] {k} := by
    intro k
    rcases k with _ | k'
    · -- {0} = Iic 0
      exact MeasurableSpace.measurableSet_generateFrom ⟨0, hE⟩
    · -- {k'+1} = Iic (k'+1) ∩ (Iic k')ᶜ
      rw [hE]
      exact h1.inter h2.compl
  -- 任意子集 = 可数个单点集之并
```

然后一步调用唯一性：

```lean
exact Measure.ext_of_generateFrom_of_iUnion C (fun i => Set.Iic i)
  hA hpi h1B (fun i => ⟨i, rfl⟩) hμB (by rintro s ⟨n, rfl⟩; exact h n)
```

六个参数各就各位：生成性 hA（环境实例 = σ(C)）、π-系 hpi、覆盖列
h1B（⋃Iic = Ω）、覆盖列在 C 中、有限性 hμB（μ(Ω) < ∞ 传递）、
生成系上的相等。调它时踩的坑：hA 的左端是"环境 MeasurableSpace 实例"，
Lean 对 `‹MeasurableSpace ℕ›` 的匿名实例与 `(inferInstance : …)` 的
合成路径可能不同构，用 `rw [hgen]; exact htop.symm` 绕开了实例项的
直接匹配——**实例相等不总是 rfl**，遇到时改写目标而不是硬配类型。

## 6.5 数值实验：逼近的收敛与唯一性的统计影子

Julia（`06_approximation.jl`）把逼近定理拆成三个实验：

**二进代数逼近**：目标集 A = [0, 0.3) ∪ [0.5, 0.7)（真测度 0.5），
深度 d 的二进网格中点采样估计：

```
深度 12 逼近误差 0.0 < 1e-3：逼近定理的数值影子
```

边界 0.3 不落在二进点上时误差是 O(2⁻ᵈ) 的锯齿收敛；对比 Python 侧
边界对齐集合（A = [0,1/4)∪[1/2,3/4)，边界全是二进点），深度 2 起
**精确**命中——边界对齐时逼近一步到位，这正是"生成代数够不够细"
的直观。

**唯一性的统计影子**：50 万均匀样本的经验测度 vs Lebesgue 在 64 个
二进区间上的最大偏差 2.4×10⁻⁴——两个"在生成系上（近似）相等"的
测度处处（近似）相等。

**剖分一致性**：同一集合的两种二进剖分（粗 / 细）算出的测度值逐位
相等——在生成系上的取值决定一切，与剖分选择无关。

Prolog（`06_approximation.pl`）在 Ω={1..4} 上做了唯一性的**对照
实验**（这个设计有故事：最初想让两张不同的原子权重表在全部 Iic 上
相等——在有限宇宙上根本不可能，Iic 值经差分唯一决定权重！机器不说谎，
实验目标本身错了）。修正后的对照：

```
on non-generating class agreement does NOT extend: OK
no two distinct tables agree on full C (uniqueness on generator): OK
sigma(C) = power set (16 subsets): OK
singleton {2} = Iic2 minus Iic1: OK
```

第一行是反例方向：两张表 [1,2,3,4] 与 [1,2,4,3]（后两个原子互换）
在**非生成**子族 {Iic 1, Iic 2} 上相等（都是 1, 3），但在 Iic 3 上
分道扬镳——**生成性**是唯一性的另一半前提，与 σ-有限缺一不可。
第二行是正例方向：在完整生成族上，不存在两张不同权重表取值相同
（穷举验证）。一正一反，把定理的两个条件各自的作用钉在台面上。

## 6.6 要点回顾

1. 唯一性定理：π-系上相等 + σ-有限 ⟹ 全等；证明 = 第 02 章 π-λ
   引擎的重放，有限性条件在"真差封闭"一步登场。
2. 逼近定理（1.6.3）三步：H-类引理（单调类）→ 单调类定理收官
   （有限情形）→ 截断 ν(E) = μ(E∩A) 折局部有限 + 穷竭列处理 ∞。
3. 有限测度有双侧逼近（1.6.4）；距离空间上闭内开外（习题 1.6.1）
   是第 25 章正则性的种子。
4. 反例分工：生成系上的 ∞ = ∞ 无约束力（σ-有限的收费）；非生成
   系上的相等不传播（生成性的收费）。
5. 数值影子：边界对齐的逼近一步精确；非生成系上的相等不传播。
