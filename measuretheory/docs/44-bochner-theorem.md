## 44.0 预备：特征函数的三重身份

在进入 Bochner 定理前，先立稳 φ_μ(t) = E e^{i⟨X,t⟩} 的
三重身份（本章到第 49 章的读图钥匙）：

1. **调和侧**：μ 的 Fourier 变换（积分在单位圆上进行——
   一切 Fourier 分析定理的测度版可用）；
2. **概率侧**：一切线性泛函 ⟨X, t⟩ 的一维特征函数的打包
  （φ(t) 恰是 ⟨·,t⟩ 的特征函数——一族一维对象的族表）；
3. **代数侧**：卷积半群到逐点乘法半群的同态（独立和的
   特征函数 = 逐点积——第 35 章的调和翻译）。

Bochner 定理回答"哪些函数是某个 μ 的 φ"——**代数（正定）
+ 分析（连续）完全刻画概率内容**。这是全书"公理化提纯"
主题在调和世界的最后一幕。

## 44.1 从 ℝⁿ 到无穷维的正定性

特征函数 φ_μ(t) = ∫e^{i⟨x,t⟩}dμ（第 49 章的实值主角在此
先以抽象形式登场）。一切特征函数共享三条代数性质：

1. **正定性（positive definite）**：对任意 t₁,…,tₙ 与复数
   c₁,…,cₙ：Σc_j c̄_k φ(t_j − t_k) ≥ 0——矩阵 [φ(t_j−t_k)]
   半正定（证明一行：E|Σc_j e^{i⟨X,t_j⟩}|² ≥ 0）；
2. **φ(0) = μ 全质量**、|φ(t)| ≤ φ(0)；
3. **连续性**（控制收敛）。

**Bochner 定理（ℝⁿ 版，严书 9.1 / 袁下册 17.4.2）**：反之，
**正定 + 连续 + φ(0) = 1 的函数必是某概率测度的特征函数**——
代数条件完全刻画特征函数。证明路线（ℝⁿ）：φ 正定 ⟹ 平移
不变核 K(s,t) = φ(s−t) 非负定 ⟹ **泛函分析的表示定理**
（Herglotz/Riesz 型：非负定核 ⟺ 谱测度的 Fourier 变换）。

## 44.1.5 一维完全体的手算（Bochner 的证明引擎）

一维 Bochner 的构造性证明（Feller 的路线，机器可承载）：

1. **测度候选**：f(t) 正定连续，定义 σ_N(t) = f(t)·
   (1 − |t|/N)_+（Pólya 截断——正定性保持：正定 ×
   三角核正定）；
2. **反演**：σ_N 的 Fourier 反变换给非负密度 g_N
  （正定函数的 Fourier 变换是正测度——一维的核论证）；
3. **归一化与极限**：∫g_N = σ_N(0) = 1（近似恒等）；N → ∞
   得概率测度列；**胎紧性**来自 f 的连续性（|f(t)−1| 小
   ⟹ 质量集中于 |x| 小处——32 章机器）；Helly 子列收敛
   到 μ，f_μ = f 由截断的逼近性收口。∎

这个证明把 32 章（胎紧+Helly）、35 章（卷积恒等）与本章
（正定）织成一张网——**Bochner 定理是测度收敛机器的
调和侧总装**。

## 44.2 Hilbert 空间版：Minlos-Sazonov 的前奏

严书 §9.2 把 Bochner 推到可分 Hilbert 空间 H。**φ : H → ℂ
正定连续**（对范数拓扑）时，结论**部分保持**：φ 是 H 上
**有限 Borel 测度**的特征函数 ⟺ φ(0) < ∞ + 正定 + **在 0
处关于某个"好"范数连续**。这里"好"范数 = 比原范数**粗**的
迹型范数 ‖x‖_* （形如 ‖Ax‖，A 为 Hilbert-Schmidt 型算子）。

**核心现象（9.2.3 的 Δ-引理）**：若正定 φ 在 H 的 Borel
σ-代数上诱导可数可加测度，则 φ 必在 0 处关于**迹范数**
连续——原范数的连续性**不够支付** σ-可加性（柱面账本只在
迹拓扑下闭合）。这正是第 45 章 Sazonov 定理的入口。

## 44.2.5 Δ-引理的读法（严书 9.2.2 的非正式版）

Hilbert 空间上柱测度的 σ-可加性有一个显式的**定量缺口**
（Δ-引理的核心不等式）：若柱测度 μ 在 B(H) 上 σ-可加，
则对 ε > 0 存在**有限秩投影 P₀** 使一切 P ≥ P₀ 有

  μ({x : \|Px\|² > r}) < ε（对适当的 r——质量的有限
  维集中性）。

**反方向的崩塌**：白噪声柱测度（λₙ ≡ 1）对每个固定 P
的 μ_P 是 P(H) 的标准 Gauss——μ_P({\|·\|² > n}) 不
随 P 的秩一致小（每个 n 维标准正态的能量期望 = n）——
**有限维集中性失效**，σ-可加性无法收费。这就是 45 章
主角定理的"病灶诊断书"。

## 44.3 唯一性与反演

**唯一性定理（mathlib `Measure.ext_of_charFun` 已形式化）**：
两个有限测度在二阶可分 Hilbert 上 charFun 逐点相等 ⟹ 测度
相等——特征函数是测度的**完全指纹**。证明用测试函数族的
稠密性（指数函数的张成在 C_b 中稠密——Stone-Weierstrass
的复值版）。

**反演的实操**：密度与特征函数经 Fourier 变换互推（第 49 章
实值完全体）；本章以**乘积结构**预演：charFun_conv
（mathlib ✓）——卷积的特征函数 = 特征函数的逐点乘积
（第 35 章卷积 ↔ 独立性的调和侧翻译，机器化件）。

## 44.3.5 反演公式的实操版（第 49 章的预装）

特征函数 → 分布的三条实用通道（本章预告，49 章实弹）：

1. **连续点反演**：μ 的密度 f 在 Lebesgue 点 x 处
   f(x) = lim_{T→∞}(2T)^{−1}∫_{−T}^T e^{−itx}φ(t)dt
  （当 φ 可积时更强：f 连续且反演一致）；
2. **Lévy 反演公式**（分布函数版）：F(b)−F(a) 的
   φ-积分表示（在连续点上）——第 49 章唯一性定理的
   证明引擎；
3. **矩-导数词典**：φ 的 k 阶导数 = i^k E[X^k]（矩存在
   时；φ 在 0 处 2k 阶可微 ⟺ 2k 阶矩有限——袁下册
   17.5 的正反两版）。

mathlib 侧 `Measure.ext_of_charFun` 是唯一性的类型化；
反演公式的机器件分布在 `CharacteristicFunction/` 与
`LevyConvergence` 文件族。

## 44.4 正定性的判例库

| 函数 | 正定? | 来源测度 |
|---|---|---|
| e^{−σ²t²/2} | ✓ | N(0,σ²) |
| e^{−λ\|t\|} | ✓ | Cauchy 型 |
| cos(at) | ✓ | (δ_a+δ_{−a})/2 |
| 1 − \|t\|（\|t\| ≤ 1 处） | ✓（三角） | 三角密度 |
| e^{−\|t\|²}（非 t²） | ✗（高维） | ——（Gauss 是 t² 型） |
| 1_{t=0} | ✓（退化） | 无穷维白噪声柱测度 |

Pólya 定理（袁 17.4.3）：凸、偶、趋于 0 的函数正定——
构造新特征函数的快餐通道。

## 44.4.5 正定性的代数细账（三个即时推论）

正定性 φ(t_j − t_k) 半正定的三个免费推论（证明全部 ≤ 两行）：

1. **Hermite 对称**：φ(−t) = \overline{φ(t)}（c = (1, i) 的
   2×2 主子式）——特征函数的实部偶、虚部奇；
2. **|φ(t)| ≤ φ(0)**（c = (1, −φ(t)/|φ(t)|) 的 2×2 主子式）；
3. **φ 在 0 连续 ⟹ 处处一致连续**（|φ(t+h) − φ(t)|² ≤
   2φ(0)(φ(0) − Re φ(h))——正定函数的"一致连续免费升级"）。

**判例的深读**：e^{−\|t\|²}（非 t²）在高维不正定——正定性
与维数耦合（Gauss e^{−t²} 只在一维/可分乘积结构下正定）；
1_{t=0} 的"退化正定"对应**无穷维白噪声柱测度**（45 章主角
的柱面身份证）——正定函数类从"温和"（可积测度）到"狂野"
（仅柱面可加）的整个谱系由连续性强度分档。

## 44.4.7 历史一览

Bochner（1932，"Monotone Funktionen"与调和分析专论）建立
了 ℝⁿ 版本；Herglotz（1911）的一维圆周版是前身。正定
函数的技术随后统治调和分析（Kolmogorov 谱表示、Krein
延拓理论）。概率侧的丰收：Lévy（1937）以此建立特征函数
方法（第 49 章主角的历史起点）。mathlib 的 charFun
形式化（2020s）沿 ProbabilityTheory 主线——本章锚点的
直接来源。
