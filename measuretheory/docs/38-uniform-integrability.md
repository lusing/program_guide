# 38 一致可积：L¹ 收敛的通行证制度

**对应严书 §7.4（pp. 155-159）/ 袁上册 §9.3（pdf241-246）。
mathlib `Function/UniformIntegrable.lean` ✓。**

## 38.1 问题：L¹ 收敛的缺口

依概率收敛 + E|Xₙ| → E|X| 不保证 L¹ 收敛（质量可以在
尾巴上逃逸——E|Xₙ| 的账面把逃逸抹平）。缺的正是**尾部
质量的一致控制**：

**定义（一致可积，UI）**：族 {Xᵢ} 满足

  lim_{K→∞} supᵢ E[|Xᵢ|·1_{|Xᵢ|>K}] = 0——一切成员的
  尾部积分**一致**小。

**读法**：每单个可积函数 UI（积分的绝对连续性——第 10
章单调收敛的推论）；**族的一致性**是新的 quantitative
要求。即时反例：{n·1_{[0,1/n]}}（逃逸尖峰）——每个成员
积分为 1，但 sup E[|Xₙ|1_{|Xₙ|>K}] = 1 对一切 K（第 n 个
尖峰在 K < n 时全贡献）——不 UI。对照 {1_{[0,1/n]}}（无
尖峰化）UI ✓。

## 38.2 判据族

**de la Vallée-Poussin 判据（UI 的凸函数刻画，严书 7.4.1
/ 袁 9.3.2）**：{Xᵢ} UI ⟺ 存在**超线性凸函数** G（G(t)/t
→ ∞）使 supᵢ E[G(|Xᵢ|)] < ∞。

证明两向：(⟸) 尾部积分 ≤ E[G(|X|)]·sup_{t>K} t/G(t)
（超线性使比值 → 0——Chebyshev 的凸强化）；(⟹) 构造
G：取 Kₙ 使尾积分 ≤ 2⁻ⁿ 于 Kₙ，分段线性拼接超线性凸
函数——**UI 的余量恰够付一个凸函数的门票**。∎

**速查表**：|Xᵢ| ≤ Y（单一可积控制）⟹ UI（DCT 型族）；
sup E|Xᵢ|^p < ∞（p > 1 一致矩）⟹ UI（G = t^p 的直接
缴费）；可数个 UI 族的并 UI（ε/2 摊派）；UI 族的线性
组合、条件期望像（|E[Xᵢ|𝓖]| ≤ E[|Xᵢ||𝓖] + Jensen——
**条件期望保 UI**，第 36 章的回礼）。

**UI ⟺ L¹ 有界 + 一致绝对连续**（ε-δ 双条件版，袁 9.3
的等价形态）：sup E|Xᵢ| < ∞ 且 ∀ε ∃δ：P(A) < δ ⟹
supᵢ ∫_A |Xᵢ| < ε——Vitali 定理的零件形态。

## 38.3 Vitali 收敛定理（L¹ 的完全体）

**定理（Vitali，严书 7.4.2 一族）**：{Xₙ} UI 且 Xₙ →p X
⟹ X 可积、Xₙ → X **于 L¹**、且 E|Xₙ| → E|X|。

**证明骨架（三段）**：

1. **极限的可积性**：Fatou 的依概率版（子列 a.s. 化——
   第 09 章 Riesz 子列）+ UI 传递：E|X| ≤ liminf E|Xₙₖ|
   ≤ sup < ∞；
2. **截断双分**：|Xₙ−X| ≤ |Xₙ−Xₙ^K| + |Xₙ^K−X^K| +
   |X^K−X|（K-截断记号）——第二段由依概率收敛 + 有界
   ⟹ L¹（有界收敛的依概率版）；第一、三段由 UI（Xₙ 与
   极限 X 的 UI——第 1 步的传递）的 K-一致小控制；
3. **合龙**：limsup E|Xₙ−X| ≤ 2ε + ε ⟹ L¹ 收敛；期望
   收敛由 |E Xₙ − E X| ≤ E|Xₙ−X|。∎

**与 DCT 的关系**：DCT 是 Vitali 的特例（单一控制 Y ⟹
UI 族）；Vitali 把"控制函数"弱化为"一致尾部小"——**从
单一房东收租改为整栋楼统一物业费**。三箭头总结：

  L¹ 收敛 ⟹ 依概率 + E|Xₙ|→E|X|（平凡方向）
  依概率 + UI ⟹ L¹ 收敛（Vitali）

**反向箭头的独立反例**：{n·1_{[0,1/n]}} 依测度 → 0 且
E = 1 恒定，但 L¹ 差恒 1——**UI 缺席的现场**（数值通道
的主实验，第 09 章逃逸尖峰的回归）。

## 38.4 UI 的三大应用

**应用一（鞅收敛的前置，第 42 章伏笔）**：鞅 {Xₙ} 的
L¹ 收敛 ⟺ {Xₙ} UI（Doob 收敛定理的右半箭头）——上穿
不等式给 a.s. 收敛，UI 把 a.s. 升级为 L¹。**应用二
（条件期望族的紧性）**：{E[X|𝓖]：𝓖 子 σ-代数} 是 UI 族
（Jensen + 单一控制 E|X|）——**一切条件期望共享 L¹ 紧性**
（Dunford-Pettis 定理的影子：UI ⟺ L¹ 的相对弱紧，泛函
分析的深水区在第 13 章对偶表的 L¹ 行补上"紧性"列）。
**应用三（换极限的执照）**：UI + 依分布收敛 ⟹ E 收敛
（Skorohod 表示 + Vitali 的组合——第 31 章表示定理的
回礼；矩问题的"什么时候能对弱极限换期望"的标准答案）。

## 38.4.5 UI 与 Lp 有界谱系（判据的强度阶梯）

从强到弱的缴费阶梯（每档 ⟹ 下档）：

| 档 | 条件 | 缴费函数 | 获得物 |
|---|---|---|---|
| 单一控制 | \|Xᵢ\| ≤ Y ∈ L¹ | —— | DCT 直接可用 |
| 一致 p-矩（p>1） | sup E\|Xᵢ\|^p < ∞ | G = t^p | UI + L¹ 紧 |
| 一致凸界 | sup E[G(\|Xᵢ\|)] < ∞（G 超线性） | G 本身 | UI |
| UI | 尾积一致小 | （构造出的 G） | Vitali |
| L¹ 有界 | sup E\|Xᵢ\| < ∞ | —— | 仅 Markov 型 |

**阶梯的教学读法**：从上往下每级放松一个量级，Vitali
恰好卡在"实用判据（矩/控制）"与"抽象判据（UI 本身）"
的分界——**统计与过程论的日常在上三档，鞅论的一般
定理在第四档**（Doob 的 L¹ 收敛定理以 UI 为充要，不再
依赖任何具体矩）。反例的阶梯同样清晰：逃逸尖峰（不
UI 但 L¹ 有界）卡在底两档之间；{√n·1_{[0,1/n]}}（UI
但无一致二阶矩）卡在第三档下方——**每个反例标定一个
档位差**。

**历史注记**：de la Vallée-Poussin（1915，凸函数判据的
原型）；Vitali 定理的现代概率表述归于 Le Cam 与
Dubins（1950-60s）；UI 成为概率论标准装备经
Meyer《概率与位势》（1966）与 Dellacherie-Meyer 系统化。
"Uniform integrability"一词是英语世界的转写（法语
uniformément intégrable）。

## 38.4.6 Dunford-Pettis 的影子（深水区导览）

**定理（Dunford-Pottis，泛函分析）**：L¹ 中族 UI ⟺
相对弱紧（弱拓扑 σ(L¹, L∞) 下闭包紧）。本书不证（需要
对偶理论的深水装备），但给两个读法：① Vitali 的收敛
对象（L¹ 范数）强于弱收敛——UI 族内依概率收敛的极限
自动弱收敛（第 13 章 L¹ 对偶的 β 泛函检验版）；② 条件
期望族 {E[X|𝓖]} 的 UI（38.4 应用二）说明"一切条件期望
共享弱紧性"——**鞅的弱收敛理论（第 42 章严书 7.4.8 的
引理正是此路）从 UI 门前出发**。泛函分析与概率论在
L¹ 弱拓扑处的这条暗河，是 UI 概念的最终户口。

## 38.5.5 实验断言清单（数值通道验收单）

1. **正例尾账**：N(0,1) 族的 E|X|·1_{|X|>K}（K = 3,4,5）
   数值积分，一致 ~ 10⁻³ → 10⁻⁶ 递减（Erfc 精确公式
   对照）；
2. **尖峰判尸**：Xₙ = n·1_{[0,1/n]} 的 sup_n 尾积分
   （K = 10, 100）恒 = 1 的整数账；
3. **Vitali 升舱**：E|Xₙ−X| → 0（好族）vs 恒 1（尖峰
   族）的双轨打印；
4. **矩缴费**：sup E|Xₙ|² ≤ C 的族尾积分 ≤ C/K 的
   Chebyshev-凸版账（二项族精确分数）；
5. **条件期望保 UI**：分块平均族 {E[X|𝓖]} 的尾积分
   ≤ E[|X|1_{|X|>K}]（Jensen 截断版）的数值验证。

## 38.5.6 习题账单（自检清单）

1. 证明：单一控制族 UI；一致 p-矩族 UI；UI 族的有限
   并与线性组合 UI；
2. 反例三连：逃逸尖峰（L¹ 有界不 UI）、√n 尖峰（UI
   无一致二阶矩）、滑动均匀 {U[n,2n]}（依测度 → 0 但
   E = 1）各卡哪个档位；
3. Vitali 三段证明的截断双分细节补全（第一、三段的
   UI-ε 分配）；
4. 条件期望保 UI 的证明（Jensen + 尾部的条件化）；
5. 用 UI + 依分布收敛 ⟹ 期望收敛（Skorohod 表示 +
   Vitali 的两行组合）重做：二项 → 正态的矩收敛（第
   52 章 CLT 的矩版预告）。

## 38.6 数值实验：尾部账与升舱失败

**Julia（`38_uniform_integrability.jl`）**：

- **UI 正例**：Xₙ ~ N(0, 1)（固定分布族）的尾积分
  E|X|1_{|X|>K} 随 K → ∞ 一致小（K = 5 时 ~ 10⁻⁶）；
  有界族 |Xₙ| ≤ 1 的尾账恒 0（K ≥ 1）；
- **逃逸尖峰**：Xₙ = n·1_{[0,1/n]} 的尾账 sup_n
  E[|Xₙ|1_{|Xₙ|>K}] = 1 对一切 K（尖峰高度 n 超过 K 后
  全贡献）——L¹ 收敛失败的账面解剖；
- **Vitali 升舱**：Xₙ = X + 1/n·noise（UI 化的收敛列）
  的 E|Xₙ−X| → 0（vs 逃逸尖峰的恒 1 对照）；
- **de la Vallée-Poussin**：sup E|Xₙ|² 有界 ⟹ UI 的
  数值验证（G = t² 缴费账：E[Xₙ²] ≤ C ⟹ 尾部 ≤ C/K）。

**Python（`38_uniform_integrability.py`）**：Fraction 精确
版——尖峰族的精确账（E[|Xₙ|1_{|Xₙ|>K}] = 1_{n>K} 的整数
账）、二项族的矩判据精确分数（sup E|Xₙ|² = p(1−p) 的
精确控制）、截断双分的精确拆账。

## 38.7 要点回顾

1. UI = 尾部积分一致小；单函数免费、族要缴费；判据 de
   la Vallée-Poussin（超线性凸函数的存在性 ⟺ UI）。
2. Vitali：UI + 依概率 ⟹ L¹（截断双分三段证明）——DCT
   的物业费化；反向箭头的尖峰反例。
3. 应用：鞅 L¹ 收敛的右箭头（42 章）；条件期望族的 L¹
   紧性（Dunford-Pettis 影子）；弱极限换期望的执照。
4. 机器侧：mathlib UniformIntegrable 全家（含 condexp
   保持）；数值通道尖峰判尸与升舱对照。
