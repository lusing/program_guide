# 18 乘积测度与 Fubini 定理：重积分的换序执照

**对应严书 §4.2（pp. 88-93）/ 袁上册 §10.2-10.3（pdf252-264，
定理 10.10-10.15）。**

---

## 18.1 矩形上的账本

给定两个 σ-有限测度空间 (X,A,μ)、(Y,B,ν)，在第 17 章的乘积
σ-代数 A ⊗ B 上造一个"配得上"的测度：最自然的订单是**矩形按
乘积记账**

  (μ×ν)(A×B) = μ(A)·ν(B)。

两件事要验：**(a) 这笔账在矩形半代数上 σ-可加**——第 04 章
半环验收工序的回归，但这次验收工具不是 Heine-Borel 紧性而是
**π-λ / 单调类**：设 ⊔ₙ(Aₙ×Bₙ) = A×B（不交），固定 y ∈ B，
则 ⊔ₙAₙ·I_{Bₙ}(y) = A，逐 y 用 μ 的 σ-可加性得
Σₙμ(Aₙ)I_{Bₙ}(y) = μ(A)I_B(y)，两侧对 dν 积分（被积项非负，
MCT 合法交换 Σ 与 ∫）得 Σμ(Aₙ)ν(Bₙ) = μ(A)ν(B)。∎——
**μ、ν 各出一次 σ-可加性，MCT 出一次交换权**，验收完成；
**(b) σ-有限时延拓唯一**（第 06 章唯一性定理直接套：矩形是
π-系，σ-有限穷竭列 A_n×B_n ↑ 造出乘积空间的穷竭）。袁书
定理 10.10 把 (a)(b) 打包：**σ-有限乘积测度存在且唯一**。

**σ-有限不是摆设**：μ = ν = 计数测度于 [0,1]（不可数空间）时
矩形账 (μ×ν)({x}×{y}) = 1，对角线 Δ = ⊔ₓ {(x,x)} 不可数并，
"逐点记账"给出 +∞ 而对角线作为集合的截口账 ∫ν(Δ_x)dμ =
∫1 dμ = +∞ 与 ∫μ(Δ^y)dν = +∞ 撞车不出矛盾，但**换序定理
全面失效**（下节反例）；更根本地，计数测度在不可数空间上不
σ-有限，唯一的乘积延拓不存在。

**验收的另一种走法（外测度路线）**：也可以先造外测度
μ*(E) = inf{Σμ(Aₙ)ν(Bₙ) : E ⊆ ⊔(Aₙ×Bₙ)}，再验矩形都
Carathéodory 可测——袁书 §4.2（上册）的外测度章与 §10.2 在
此处接驳。两条路线产出同一测度（π-系上相等 + 唯一性）；
严书走单调类（快），袁书走外测度（与第 04 章机器复用更彻底）
——本教程按严书主线、脚注指回袁书。

## 18.2 截口定理：乘积测度的逐片记账

**定理（严书 4.2 系 / 袁引理 10.11-10.13 一族）**：E ∈ A ⊗ B
可测 ⟹

1. 每个 E_x ∈ B、每个 E^y ∈ A（第 17 章截口定理）；
2. x ↦ ν(E_x) 是 A-可测函数、y ↦ μ(E^y) 是 B-可测函数；
3. **(μ×ν)(E) = ∫ν(E_x)dμ = ∫μ(E^y)dν**。

证明照旧 Good 集：满足三条的 E 全体包含矩形（ν((A×B)_x) =
ν(B)·I_A(x)，账目 ∫ν(B)dμ(A·) = μ(A)ν(B) ✓），对单调极限
封闭（截口逐点单调 + MCT 两次），由单调类定理收满 A ⊗ B。
**这条定理就是"乘积测度"的身份证**：它说明 μ×ν 的值可以完全
由"逐片测量再积分"复原——Fubini/Tonelli 的全部内容都是它
的函数版包装。

## 18.3 Tonelli 与 Fubini：两张执照

**Tonelli（非负执照，严书 4.2 系/袁定理 10.13）**：f ≥ 0 可测
（值 [0,∞]）⟹ 每个 f(·,x) 与 f(x,·) 可测、x ↦ ∫f(x,y)dν(y)
与 y ↦ ∫f(x,y)dμ(x) 可测，且

  ∫f d(μ×ν) = ∫[∫f dν]dμ = ∫[∫f dμ]dν

——三值同为 +∞ 也算"相等"。证明：指示函数=截口定理，线性
→ 简单函数，MCT → 一般非负（第 10 章三步构造的原样复用）。
**非负性免费送你换序**，这是 [0,∞] 值域"无符号烦恼"的红利。

**Fubini（可积执照，严书 4.2.7/袁定理 10.15）**：f 关于 μ×ν
**可积**（|f| 的 Tonelli 积分有限）⟹ 对 μ-a.e. x，f(x,·)
ν-可积；截口积分函数可积，且换序等式成立。严书 4.2.7 还给
"积分存在"（∫f⁺ 与 ∫f⁻ 至一有限）版本的完整陈述——工具
链：Tonelli 用于 |f| 判可积，Fubini 用于 f 本身。

**执业口诀**：先用 Tonelli 算 ∫|f|（此时不怕 +∞），账面有限
再领 Fubini 换序执照。跳过第一步直接换序是经典事故源——
下节的 a_{mn} 就是事故报告。

## 18.4 反例档案：两张罚单

**罚单一（换序事故，级数版）**：a_{mn} = 1 (m=n)、−1 (m=n+1)、
0 其余。按行求和：第 1 行和 = 1，第 m ≥ 2 行和 = 0，总和 = 1；
按列求和：每列和 = 0，总和 = 0。双重级数**绝对发散**
（Σ|a_{mn}| = ∞），Fubini 执照吊销，两个累次积分合法地不相等。
数值通道把它原样对拍（Julia 双通道截断、Python Fraction 精确
账）。测度版：ℕ 上计数测度自乘，f(m,n) = a_{mn}。

**罚单二（σ-有限缺失）**：X = Y = [0,1]，μ = Lebesgue，ν =
计数测度（不 σ-有限）。E = 对角线 Δ：ν(Δ_x) = 1 故
∫ν(Δ_x)dμ = 1；μ(Δ^y) = 0 故 ∫μ(Δ^y)dν = 0。若 Fubini 适用
则 1 = 0——荒谬的根源是 μ×ν 根本不存在（矩形账在半环上就不
σ-可加）。**对角线是测度论的"照妖镜"**：它在乘积空间的测度
同时检验 σ-有限性（本题）、图的可测性（第 09 章）与绝对连续性
（第 12 章 L¹ 值测度反例）。

**注记（完备化陷阱）**：Lebesgue ⊗ Lebesgue **不是** Lebesgue
（在 ℝ²）：后者是前者的完备化。Borel × Borel 的框架里 Fubini
处处成立，但"零测集的子集"逐条处理时要先完备化再截口——
严书 4.2 末的习题与袁书 §4.3（上册，完备化章）在此接口。
实操口径：**形式化通道一律用 Borel/未完备化框架**（mathlib、
Isabelle 均如此），分析上的 Lebesgue 完备化需要时用
`Measure.completion`（第 04 章锚点）。

## 18.4.5 应用选讲：卷积与三类经典账

Fubini 的日常使用中，三类账出现频率最高，值得各记一笔：

**账一（卷积）**：∫ f(y−x)g(x)dx = ∫f(z)g(x)dxdz 换元后
= (f*g)(y)——卷积的存在与范数账 ‖f*g‖ᵣ ≤ ‖f‖_p‖g‖_q
（Young 不等式）全部由 Tonelli 起步（先对 |f|·|g| 用非负执照
验账面有限）。卷积是第 49 章特征函数（φ_{X+Y} = φ_X·φ_Y 的
测度论根基）与第 35 章独立和分布的引擎——概率论的"乘法"
在测度层面就是卷积，而卷积的合法性一概由本节执照签发。

**账二（化重积分为累次）**：∫∫ e^{−x²y}dxdy 于 [0,∞)×[0,1]
——对 x 先积无初等原函数，对 y 先积得 ∫(1−e^{−x²})/x² dx
= 2√π。**顺序敏感**是 Fubini 的日常：先验 |f| 可积（此处
Tonelli 直接给有限），再选便宜的一侧积——执照在手，路线
自由。

**账三（体积的截口账）**：区域 D = {(x,y) : 0 ≤ y ≤ f(x)}
的面积 = ∫f dx——"面积 = 逐 x 量高度再积分"就是截口定理
在 Lebesgue×Lebesgue 上的原文。第 05 章 L-S 测度的分布函数
账 F(b) − F(a) = μ((a,b]) 与这里同一台记账机。

**历史注记**：Fubini（1907）给出可积情形的换序定理；Tonelli
（1909）补上非负情形（允许 +∞）——两人的名字共享一条定理
是分析学里罕见的平分秋色。Lebesgue 本人对"逐片记账"的原始
处理依赖其测度的定义；现代陈述（截口定理 + 单调类）归功于
后世的公理化重整（主要是 Hahn 与 Kolmogorov 的教材传统）。
袁书 §10.3 把 Tonelli 排在 Fubini 之前（定理 10.13 → 10.15）
正是"非负执照先行"的执业顺序——本教程同序。

## 18.4.6 图像的测度账：对角线的定量版

可测函数 f : X → Y 的**图像** G_f = {(x, f(x))} 的乘积测度
有闭式账：截口 (G_f)_x = {f(x)}，故

  (μ×ν)(G_f) = ∫ ν({f(x)}) μ(dx)。

三条即时推论：**ν 无原子**（一切单点 ν-零测）⟹ 图像零测
——ℝ² 中可测曲线的面积为零是本文的特例；**ν = 计数测度**
⟹ (μ×ν)(G_f) = μ(X)——18.4 的对角线（f = id、μ = ν =
Lebesgue + 计数的混合）正是这笔账的爆点；**图像可测性**
（G_f ∈ A ⊗ B：x ↦ (x, f(x)) 可测 + 对角线在 B⊗B 中——
ℝ 情形对角线是闭集）是记账的前提，第 09 章（可测图像）
与第 31 章（弱收敛中的图像连续性）都将回引这笔账。

## 18.5 Lean：Measure.prod 与 lintegral_prod

mathlib 主锚（PLAN §1 已核）：`Measure.prod`（乘积测度构造，
Constructions/…）、矩形账 `μ.prod ν (s ×ˢ t) = μ s * ν t`
（`Measure.prod_prod` 一族）、Tonelli = `lintegral_prod` 与
`lintegral_prod_sym`（Marginal.lean，正名以 #check 为准），
Fubini = `integral_prod`。`Ch18Fubini.lean` 实弹：

1. **锚点 #check**：四件套过目；
2. **矩形账**：dirac × dirac 下 {(a,b)} 的乘积测度 = 1·1——
   `Measure.prod_prod` 一行；
3. **Tonelli 数值内核**：[0,1]×[0,1] 上常值 1 的 lintegral
   两侧交换（`lintegral_prod_sym`）等值；
4. **绝对可和级数的换序**（Fubini 执照正面案例）：ℕ×ℕ 计数
   测度上 a_{mn} 的**绝对收敛**变体（如 a_{mn} = 2^{-m-n}），
   两个累次和相等——与罚单一形成"有执照/无执照"的对照。

## 18.7 数值实验：两张罚单的现场记录

**Julia（`18_fubini.jl`）**：

- **罚单一对拍**：a_{mn} 截断到 N×N（N = 100, 1000, 10000），
  行先和 vs 列先和——收敛到 1 与 0，**截断对称但极限不同**
  （边界行的账随 N 增长不消失，这是"事故在边界"的数值显影）；
- **绝对收敛对照**：a_{mn} = 2^{-(m+n)} 同样截断，两序差
  ≤ 4·2^{-N}（显式界），指数收敛——执照有效的定量面貌；
- **矩形账与截口定理**：有限网格 {0,1,2}×{0,1,2} 上 μ、ν 取
  点权，逐集合验证 (μ×ν)(E) = Σₓ ν(E_x)·w_μ(x)——截口定理
  的全枚举版。

**Python（`18_fubini.py`）**：Fraction 精确版——罚单一是纯
整数账（上和 1、下和 0，零舍入）；网格乘积测度与截口账全
精确；2^{-(m+n)} 的对照和精确为 1（Σ2^{-m}Σ2^{-n} = 1·1）。

## 18.8 要点回顾

1. 乘积测度 = 矩形账 μ(A)ν(B) 的唯一 σ-可加延拓（σ-有限时）；
   验收靠 π-λ/单调类，不是紧性。
2. 截口定理是身份证：μ×ν 的账可逐片复原；Good 集三步证明。
3. Tonelli（非负，允许 +∞）与 Fubini（可积）是两张执照；
   执业口诀：先 Tonelli 验 |f|，账面有限再换序。
4. 罚单档案：a_{mn}（绝对发散，累次和 1 vs 0）；对角线 ×
   计数测度（σ-有限缺失，乘积测度不存在）。
5. 完备化口径：Borel 框架形式化，Lebesgue 完备化按需补——
   `Measure.completion` 的接口位。
6. 机器侧：`Measure.prod`/`prod_prod`/`lintegral_prod(_sym)`/
   `integral_prod`；Isabelle `emeasure_pair_measure`/Fubini 族；
   数值通道两张罚单全对拍。
