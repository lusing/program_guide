# 07 可测映射

**对应严书 §2.1（pp. 27-31）。**

## 7.1 定义：把结构搬回家的函数

**定义（可测映射）** 设 (Ω, 𝓕)、(E, ε) 为可测空间。映射 f : Ω → E
称为 **𝓕/ε-可测**，若对每个 A ∈ ε 有 f⁻¹(A) ∈ 𝓕。实值（含 ±∞）情形
称**可测函数**。

与连续性的对照是理解本章的钥匙：连续 f : X → Y 要求**开集的原像
开**——结构顺着 f "拉回来"保持；可测要求**可测集的原像可测**——
σ-代数顺着 f 拉回来保持。两者的共同姿态是"原像方向"：σ-代数对
补与可数并封闭，而原像运算与这些操作**完美交换**（第 01 章的
de Morgan 律），所以理论全部长在原像侧。像方向则不然：f[A ∩ B]
与 f[A] ∩ f[B] 可以不同，f[⋃Aₙ] 也未必等于 ⋃f[Aₙ] 的可测化——
像测度一章（第 07/18 章习题与第 40 章解析集）将为此付出真金白银
的技术代价。

为什么概率论关心可测而非连续：随机变量 X 是"样本来到的实数"，
我们无法要求样本空间有拓扑，只能要求 {X ≤ a}（"观察事件"）可测。
可测性是**观察的代数**：能被 f 区分的样本，才构成可谈论的事件。

## 7.2 实值情形：五张等价检查表

**定理（严书 2.1.4）** f : Ω → ℝ̄ 可测 ⟺ 以下任一条：

1. ∀a ∈ ℝ, [f < a] := {ω : f(ω) < a} ∈ 𝓕；
2. ∀a ∈ ℝ, [f ≤ a] ∈ 𝓕；
3. ∀a ∈ ℝ, [f > a] ∈ 𝓕；
4. ∀a ∈ ℝ, [f ≥ a] ∈ 𝓕。

证明的枢纽是**生成族缩减**：区间族 {[−∞, a) : a ∈ ℝ} 生成 ℬ(ℝ̄)，
而"可测性只需对生成族检查"（下节命题 2.1.3）一步收割全部等价。
注意每个版本只盯**一种**不等号——严格与非严格不可混用（[f < a] 与
[f ≤ a] 互相通过可数交/并转换：[f ≤ a] = ⋂ₙ [f < a + 1/n]，
[f < a] = ⋃ₙ [f ≤ a − 1/n]，故两组任取其一即够）。数值与 Prolog
实验将把这两组转换做成了机器检查。

这一组等价条件是"算测度"的接口：P(X ≤ a)、P(X < a) 这些概率论
的基本对象，其良定义性全部锚定在此。

## 7.3 运算封闭性：逐条搬运

可测函数全体对下述运算封闭（严书 2.1.5 及习题）：

- **线性**：af + bg 可测。关键技巧是**有理数细分**：
  [f + g < a] = ⋃_{r∈ℚ} ([f < r] ∩ [g < a − r])——把二维条件
  (f, g) 落入半平面拆成可数个矩形，可数并保持可测。ℚ 的稠密与
  可数性缺一不可，这个技巧在第 09 章讨论向量值收敛时反复返场。
- **格运算**：f ∧ g、f ∨ g、f⁺ = f ∨ 0、f⁻ = (−f) ∨ 0、|f| 可测
  （如 [f ∧ g > a] = [f > a] ∩ [g > a]）。
- **乘法与除法**：fg 可测（先做平方：[f² > a] 对 a ≥ 0 拆成
  [f > √a] ∪ [f < −√a]）；f/g 在 g ≠ 0 处可测。
- **极限**：fₙ 可测 ⟹ liminf fₙ、limsup fₙ（可数交并的复合）、
  逐点极限 f 可测；[fₙ = g]、[fₙ ≤ g] 也是可测集
  （[fₙ − g = 0] = ⋂ₖ [|fₙ − g| < 1/k]）。
- **复合**（习题 2.1.2）：f : Ω → E 可测、h : E → G 可测 ⟹
  h ∘ f 可测——原像的原像是原像，(h∘f)⁻¹ = f⁻¹ ∘ h⁻¹。

**命题（在生成系上检查，严书 2.1.3）** 若 ε = σ(C)，则 f 可测 ⟺
对每个 A ∈ C 有 f⁻¹(A) ∈ 𝓕。这是第 02 章"检查生成系即可"的函数版：
可测性的验证成本从"全体可测集"降到"一个小生成族"。典型应用：
Borel 可测 ⟺ 半直线原像可测（上一节）；连续 ⟹ Borel 可测
（开集原像开，开集可测）。

## 7.4 σ(f)：一个函数知道多少

**定义（诱导 σ-代数）** f : Ω → E 诱导 σ(f) := f⁻¹(ε) :=
{f⁻¹(A) : A ∈ ε}，即**使 f 可测的最小** 𝓕-子 σ-代数。它是"仅凭
观察 f 所能谈论的全部事件"。

三条基本事实（习题 2.1.1 等）：

1. f⁻¹(ε) 本身就是 σ-代数（原像与补/并交换），且 σ(f) =
   σ({f⁻¹(A) : A ∈ C}) 对任意生成系 C 成立——**生成系的原像生成
   原像的 σ-代数**。
2. **族版**：𝓗 一族映射诱导的 σ-代数 = σ(⋃_{f∈𝓗} f⁻¹(ε))；且若
   g 为 σ(𝓗)-可测，则存在**可数子族** 𝓗₀ 使 g 已是 σ(𝓗₀)-可测
   ——每个可测函数只用到可数多条信息（生成 σ-代数的"可数依赖"
   现象，第 01 章习题 1.2.3 的函数版）。
3. **因子定理**：g 是 σ(f)-可测 ⟺ 存在可测 h : E → ℝ̄ 使
   g = h ∘ f（g 是 f 的函数）。有限模型里这是精确的等式：
   g 在 f 的每个纤维（fiber，原像点集）上必为常数。

第 36 章条件期望 σ(X) 的"信息解释"、第 21 章乘积族的柱 σ-代数，
都从这三条起步。

## 7.5 简单函数：可测世界的砖块

**定义（严书 2.1.7）** A ⊆ Ω 的**示性函数** I_A(ω) = 1 (ω ∈ A)、
0 否则；只取有限多个值的函数称**简单函数**。标准表示
f = Σᵢ aᵢ I_{Aᵢ}，Aᵢ = f⁻¹({aᵢ}) 两两不交；f 可测 ⟺ 每个 Aᵢ
可测。

**定理（逼近，严书 2.1.8）** (1) 任何可测 f 存在简单可测 fₙ 使
|fₙ| ≤ |f| 且 fₙ → f 逐点；(2) f ≥ 0 时可取 fₙ ↑ f。

非负情形的构造是**二进网格**：fₙ = Σ_{k=0}^{n2ⁿ−1} (k/2ⁿ)
I_{[k/2ⁿ ≤ f < (k+1)/2ⁿ]} + n I_{[f ≥ n]}。每一层把值域切成
宽 2⁻ⁿ 的格点、顶端截断在 n。这张网格在第 03 篇积分构造
（第 10 章）原样重现——简单函数是积分的 Riemann 和对应物。
有界情形可加强为**一致逼近**（习题 2.1.3），一致速度由 f 的振幅
与网格层数直接控制。

## 7.6 Borel 映射、向量值与像测度

- **习题 2.1.5**：距离空间上 ℬ(Ω) = σ(C_b(Ω))——**有界连续函数
  生成 Borel σ-代数**（f ∈ C_b 的 [f < a] 是开集，反之开集的
  距离函数 d(·, A) 连续）。这条习题是第 31 章弱收敛"用有界连续
  函数检验"的合法性来源，也是第 08 章函数单调类的标准入口。
- **习题 2.1.6**：f₁,…,fₘ Borel 可测 ⟹ 向量 (f₁,…,fₘ) :
  Ω → ℝᵐ 可测（对 ℝᵐ 的盒生成系检查，逐坐标还原）。
- **像测度**：可测 f : Ω → E 与 Ω 上测度 μ 造出 E 上的测度
  μ.f⁻¹ := μ ∘ f⁻¹（(μ.f⁻¹)(A) = μ(f⁻¹(A))）——**分布**。
  可数可加性由原像与并可交换直接继承，无需任何新机器。概率论
  "随机变量的分布"就是这一行定义；反过来，第 05 章的 LS 测度
  讲的正是"每个分布长在哪条 f 上"。

## 7.7 Lean：comap 一族与生成系检查

mathlib 把 σ(f) 打包为 `MeasurableSpace.comap`（`MeasurableSpace/
Basic.lean`），本章三个定理各配一个机器件（`Ch07MeasurableMaps.lean`）：

```lean
-- σ(f) 的显式公式：由可测集原像生成（comap_eq_generateFrom）
example (f : α → β) (m : MeasurableSpace β) :
    m.comap f = MeasurableSpace.generateFrom
      {t | ∃ s, MeasurableSet[m] s ∧ f ⁻¹' s = t} :=
  MeasurableSpace.comap_eq_generateFrom m f

-- 习题 2.1.1 的机器版：生成系的原像生成原像的 σ-代数
example (f : α → β) (s : Set (Set β)) :
    (MeasurableSpace.generateFrom s).comap f
      = MeasurableSpace.generateFrom (f ⁻¹' '' s) :=
  MeasurableSpace.comap_generateFrom

-- 命题 2.1.3 的机器版：在生成系上检查可测性
example {s : Set (Set β)} {f : α → β}
    (h : ∀ t ∈ s, MeasurableSet (f ⁻¹' t)) :
    Measurable[MeasurableSpace.generateFrom s] f :=
  measurable_generateFrom h
```

复合可测一行（`Measurable.comp`，注意可测性假设写在两侧空间上）：

```lean
example (hf : Measurable f) (hg : Measurable g) : Measurable (g ∘ f) :=
  hg.comp hf
```

像测度是 `Measure.map f μ`（`Measure/Map.lean`，irreducible 定义
——它的全部性质按 API 调用；示例里狄拉克质量经奇偶映射搬到 {1}，
一行 `map_apply` + `dirac_apply_of_mem` 收割）。写文件时踩到的坑
有二：其一，生成族 `⋃ a : ℚ, {Iic ↑a}` 的成员关系必须先用
`simp only [Set.mem_iUnion, Set.mem_singleton_iff]` 剥开再解构，
`rintro ⟨r, rfl⟩` 直接上会在 Membership 外壳上翻车；其二，
`measurable_generateFrom` 造的是**陪域** σ-代数，而方括号实例语法
`Measurable[m]` 只能改值域侧——须用 `@Measurable γ β _ (…generateFrom s)`
显式形式，且 `generateFrom` 与 ℝ 环境实例不定义相等，要经
`BorelSpace.measurable_eq` 两步换算后才能 `exact`。

## 7.8 数值与逻辑实验：σ(f) 到底有多大

**Julia（`07_measurable_maps.jl`）**在 Ω = {1,…,8} 上取
f = [1,1,2,2,3,3,3,3]（三个纤维，大小 2/2/4），机器枚举
σ(f)：恰好是"纤维的并集族"，共 2³ = 8 个集合——**|σ(f)| = 2^纤维数**
的一般规律在有限情形精确成立。第二个实验验证因子定理：枚举 Ω 上
全部 3⁸ = 6561 个 {0,1,2}-值函数 g，`g 为 σ(f)-可测 ⟺ g 在每个
纤维上常数` 的双方向全部吻合（3³ = 27 个可测、其余不可测）。第三个
实验：g = h ∘ f 的分解中 h 在纤维标记集上被 g 的纤维值唯一确定。

**Python（`07_measurable_maps.py`）**做同样实验的精确版本，并追加
"生成系的原像生成 σ(f)"检查：取 E 侧生成系 C = {{a},{b}}，机器
验证 σ(f⁻¹(C)) = σ(f)（集合族相等，逐元素核对），把习题 2.1.1
变成运行结果。

**Prolog（`07_measurable_maps.pl`）**同题：σ(f) 枚举、纤维常数
判定、五等价条件的 [f < a]/[f ≤ a] 互转（有限值域上穷举阈值 a）。

三个通道一件结论：**σ(f) 是 f 的知识边界——它恰好包含"问 f 的
可测问题"能得到的事件，一个不多（因子定理），一个不少（定义）**。

## 7.9 要点回顾

1. 可测 = 可测集的原像可测；一切运算封闭性来自"原像与 σ-代数
   运算交换"。加法的技术内核是有理数细分。
2. 实值可测的五种检查（<, ≤, >, ≥ 任一 suffices）；生成系检查
   把验证成本降到小族。
3. σ(f) = 原像 σ-代数 = 最小使 f 可测 = f 的知识边界；g 为
   σ(f)-可测 ⟺ g = h∘f；可测函数只依赖可数多条信息。
4. 简单函数按二进网格逼近任何可测函数（|fₙ| ≤ |f|，非负时单调），
   二进网格是第 10 章积分构造的脚手架。
5. ℬ = σ(C_b)（连续函数生成 Borel）——弱收敛与函数单调类的接口。
