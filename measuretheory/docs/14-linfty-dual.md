**对应严书 §3.5（pp. 72-74）。通道分工章：mathlib 与 Isabelle 均无
ba（有限可加荷）基础设施，本章由 Julia / Python / Prolog 数值通道

---

## 14.1 对偶故事的另一半

第 13 章给了 (Lᵖ)* = L^q（1 ≤ p < ∞，σ-有限）。链条的最后一块：
**L∞ 的对偶是什么？**直觉的候选是 L¹（照 p/q 对偶表的延长），
但直觉在这里**错得很有教益**：L∞ 的对偶严格大于 L¹。原因藏在
"可数可加"这四个字里——L¹ 密度 g·μ 造出的泛函是**可数可加**的
荷，而 L∞ 上的连续线性泛函只被迫对**有限**结构连续，足以容纳
**只有限可加**的带符号集函数。这批"越轨者"组成 ba 空间。

## 14.2 ba：有限可加荷的银行

**定义** ba(Ω, 𝓕) = 𝓕 上全体**有限可加**符号集函数 μ（μ(∅)=0、
不交有限并可加），配**全变差范数**

  ‖μ‖_var = sup { Σᵢ |μ(Aᵢ)| : {A₁,…,Aₙ} 为 Ω 的 𝓕-可测有限划分 }。

ba 按此范数完备（Banach）。可数可加的成员子空间记 ca(Ω, 𝓕)
——正是第 12 章的有限符号测度全体，且那里的变差定义与这里的
有限划分版本一致。**包含链：L¹-密度荷 ⊂ ca ⊂ ba**，两步都严格。

ba 元素的表现（严书 3.5 前置）：对 μ ∈ ba 与 f = ΣαᵢI_{Aᵢ}
简单函数，定义 μ(f) = Σαᵢμ(Aᵢ)；|μ(f)| ≤ ‖f‖∞·‖μ‖var 使
定义按 L∞ 范数连续地延拓到整个 L∞（简单函数在 L∞ 稠密）——
**每个 ba 荷都是 L∞ 上的连续泛函**。

## 14.3 对偶定理：(L∞)* = ba（严书 3.5.1-3.5.2）

**定理** T_μ(f) = μ(f) 给出 ba(Ω,𝓕) 到 L∞(Ω,𝓕)* 的**保范线性
同构**。进而对基测度 m，ba(Ω,𝓕,m) := {μ ∈ ba : m(A)=0 ⟹
μ(A)=0}（ba 意义的绝对连续）同构于 L∞(Ω,𝓕,m)*。

证明的两个方向一升一降：T_μ ∈ (L∞)* 且 ‖T_μ‖ ≤ ‖μ‖var 由
上一节的不等式；反过来，给定 ℓ ∈ (L∞)*，令 μ(A) = ℓ(I_A)——
**有限**可加性只需 ℓ 的线性（I_{A⊔B} = I_A + I_B），‖μ‖var ≤ ‖ℓ‖
由对偶范数定义取测试函数 Σ±I_{Aᵢ}。两个方向合龙给出 ‖T_μ‖ =
‖μ‖var。**关键观察：从泛函只能"免费"提取有限可加性**——可数
可加需要 ℓ 对单调极限的连续性，而 L∞ 范数太粗，装不下这种
控制（第 11 章 DCT 的控制函数在 ‖·‖∞ 下一般不存在）。

## 14.4 越轨者档案：纯有限可加荷的三个标本

**标本一（自然密度荷）**：Ω = ℕ，对"有自然密度"的集合 A
（|A ∩ [1,n]|/n → δ(A)）赋值 δ(A)。有限可加性成立（不交并的
密度 = 密度之和，当三者都存在）；**单点密度为 0，但 δ(ℕ) = 1**
——可数可加性当场死亡（Σₖ δ({k}) = 0 ≠ 1）。它是 L∞(ℕ, 计数)
上"在无穷远处取样"的泛函的集合版。数值通道把它做成可运行
的账本：偶数集 1/2、3 的倍数 1/3、平方数 0——有限可加在
结构集上逐例成立。

**标本二（Banach 极限）**：ℓ(x) = "广义极限"（对有界数列），
平移不变、介于 liminf 与 limsup 之间——Hahn-Banach 从 ca 中
"擦边"造出的 ba 元素，泛函版标本一。

**标本三（超滤荷）**：自由超滤 𝒰 上 μ(A) = 1_{A∈𝒰}——
{0,1} 值的有限可加荷，可数可加性破产方式与标本一相同。选择
公理的身影（自由超滤的存在性）提示：**越轨者的存在性是不可
构造的**——这与第 04 章 Vitali 集的处境同源。

**为什么 L¹ 接不住它们**：若 δ 由 g ∈ L¹ 表现（δ(f)=∫fg），
则 δ 在可数可加性下复活，与标本一的死亡现场矛盾。**ba \ ca
的成员正是"住在 L∞ 对偶里的选择公理幽灵"**——第 38 章一致
可积讨论中"逃逸到无穷"的量，在这里找到了代数住址。

## 14.5 数值实验：越轨者的有限账本与退化定理

**Julia（`14_linfty_dual.jl`）**：

- **自然密度荷**：对结构族（偶数、3 的倍数、平方数、2 的幂、
  模 6 余 1）数值计算 |A∩[1,n]|/n 的收敛轨迹（n 到 10⁶），与
  解析极限（1/2, 1/3, 0, 0, 1/6）对照到 1e-3；
- **有限可加性的数值检查**：不交结构并（偶 ∪ 3 的倍数 ∖ 6 的
  倍数）的密度 = 分密度之和，逐 n 验证恒等式（截断误差 < 1e-6）；
- **可数可加的死亡现场**：单点密度（任意 n 处 1/n → 0）vs
  δ(ℕ) = 1——一行账，胜千言；
- **ba vs ca 的有限退化**：有限 Ω 上有限可加 ⟺ 可数可加
  （无"新集合可数并"的燃料），数值确认 ba = ca（维数一致）。

**Python（`14_linfty_dual.py`）**：Fraction 精确版——结构族的
密度序列 |A∩[1,n]|/n 是有理数列，其闭式极限（1/2 等）与
**精确不等式**（前 n 项密度与极限的偏差 ≤ C/n 型显式界）配对；
死亡现场的整数账（0·∞ ≠ 1 的语义账）。

**Prolog（`14_linfty_dual.pl`）**：有限退化定理的穷举版——
Ω = {1,2,3} 上把"荷"表示为 2³ = 8 个基本块的赋值，验证：
全体有限可加荷（8 维空间）= 全体可数可加荷（同一空间）；
并把"单点质量"与"总质量"的账在有限世界与无限世界（自然密度）
间做对照表——**越轨是无穷现象**的又一证词（与第 04/09 章
反例的"不可数性"同族）。

## 14.5.5 ba 的完备性证明骨架

ba 是 Banach 空间的验证（通常被略过的一课）：设 {μₙ} 为
‖·‖var-Cauchy 列。**逐点极限存在**：对每个 A ∈ 𝓕，|μₙ(A) −
μₘ(A)| ≤ ‖μₙ − μₘ‖var（单集划分），故 μ(A) = lim μₙ(A) 良定义。
**μ ∈ ba**：有限可加性逐点取极限保持。**范数收敛**：对任意
有限划分 {A₁,…,Aₖ}，Σᵢ|μₙ(Aᵢ) − μ(Aᵢ)| = limₘ Σᵢ|μₙ(Aᵢ) −
μₘ(Aᵢ)| ≤ limsupₘ ‖μₙ − μₘ‖var——对划分取上确界后令 n 大。
**逐点 + 范数双收敛**是"以点态信息恢复范数信息"的又一实例
（对照第 13 章对偶范数的对偶方向取等）。

值得注意的对称性：ca 的完备性（有限符号测度全体）是 ba 的
**闭子空间**——可数可加性是"对递增序列的连续性"，而连续性
在范数极限下保持（一致性来自变差范数的控制）。于是有正合列

  0 → ca(Ω,𝓕) → ba(Ω,𝓕) → ba/ca → 0，

商空间 ba/ca 度量"纯有限可加的越轨程度"——第 14.4 的三个标本
都是它的非零代表（自然密度荷的等价类）。

## 14.5.6 ba(Ω,𝓕,m) 的内部结构

对基测度 m，ba(Ω,𝓕,m) := {μ ∈ ba : μ ≪ m}（m-零测集上
荷也为零——注意这是**集函数级**的绝对连续，比第 12 章的
ε-δ 语言弱：有限可加荷没有 ε-δ 自动传递）。结构定理：

  ba(Ω,𝓕,m) ≅ L¹(m) ⊕ (纯有限可加但 ≪ m 的部分)。

前一块是通常的密度荷；后一块在 m **σ-有限时仍然非零**
（与 ca 的情形不同！）：例如 m = Lebesgue 于 [0,1]，取
"趋零密度荷"δ(A) = lim_{ε→0} m(A∩[0,ε])/ε（对有密度的 A）——
它 ≪ m（Lebesgue 零测集上恒 0），但纯有限可加。**σ-有限只
拯救 ca 层的对偶（第 13 章），救不了 ba 层**——这就是
(L¹)* = L∞ 需要 σ-有限、而 (L∞)* = ba(·,m) 无论 σ 与否都
"超员"的原因。数值通道的覆盖账（μ*(A) 由块权下确界）是
这条分解的有限影子：有限世界里第二块恒为零（退化定理），
无限世界里它由极限过程（ε→0、n→∞）显影。

**对偶谱系总表**（合并第 13-14 章的完整地图）：

| 空间 | 对偶 | 条件 | 机器对应 |
|---|---|---|---|
| Lᵖ, 1<p<∞ | L^q | 无 | 局部 RN + 凸性 |
| L¹ | L∞ | μ σ-有限 | RN + 相容拼接 |
| L∞ | ba(·,m) | 无 | I_A → ℓ(I_A) |
| L² | L² | 无 | Hilbert 内积 |

表的读法：**p 从 ∞ 往 1 走，对偶的"可测表示"越来越足**；
p = 2 是自对偶的平衡点。概率论实际工作中 1 < p < ∞ 是"舒适区"，
边界 p = 1, ∞ 各有一个反例陷阱（σ-有限缺失 / ba 越轨）——
本章与第 13 章各葬送一个想当然。

## 14.6 通道分工说明

mathlib 与 Isabelle 均未收录 ba 空间（mathlib 的 `Measure` 类型
按定义可数可加，有限可加荷需要 `AddContent`/向量测度层的额外
结构，且对偶定理本身缺失）——本章按工程纪律不硬造形式化，
数值通道承担全部机器验证。这与 funanalysis 教程处理 von
Neumann 代数等无基础设施主题的先例一致：**docs 如实标注分工，
不虚构"已形式化"**。

## 14.6.5 延伸与习题账单

**加权密度族的封闭练习**：对任意权列 wₖ > 0、Σwₖ = ∞（发散！）
，δ_w(A) = lim_n Σ_{k≤n, k∈A} wₖ / Σ_{k≤n} wₖ（当极限存在）
仍是有限可加荷——发散性保证单点密度为 0（同阶无穷小的竞争），
收敛权（Σwₖ < ∞）则给出货真价实的可数可加测度。**发散与
收敛的分界线就是 ba/ca 的分界线**：数值实验里取 wₖ = 1/k
（调和发散）与 wₖ = 2⁻ᵏ（收敛）各跑一遍覆盖账，两个世界的
行为差异（单点质量 0 vs 2⁻ᵏ）一目了然。

**泛函分析视角的收束**：ba(Ω,𝓕) 就是空间 ℓ∞(𝓕)（有界集函数）
中满足有限可加性的闭子空间，而 (L∞)* = ba 可改写为
"ℓ∞ 的对偶超越 ℓ¹"——这正是序列空间里的经典事实
((ℓ∞)* = ba(ℕ) ⊋ ℓ¹) 的测度论原文。Banach 极限的平移不变性
在 ba 里翻译为：荷对"平移等价类"取常值——选择公理给出它
的存在，但**任何显式定义都造不出它**（可构造宇宙 ZF + AD 里
Banach 极限不存在）——形式化基础设施（mathlib/Isabelle）对
ba 的缺席与此不无关系：**不可构造对象的形式化需要显式选择
原理的全程陪护**，工程代价远超收益。

**习题速览**（自检清单）：
1. 验证自然密度荷在"密度存在的集合全体"上有限可加，且该
   集族是代数但非 σ-代数（哪一步断链？）；
2. 证明 ba/ca 中自然密度荷的等价类非零；
3. 构造 ba(Ω,𝓕,m) 中 ≪ m 但纯有限可加的元素（提示：
   [0,1] 上趋零密度）；
4. 用对偶谱系表解释：为何 L∞ 自反性失败是 ba ≠ L¹ 的直接
   推论（自反 ⟺ 对偶两次还原，ba 的对偶回不到 L∞）。

## 14.7 要点回顾

1. (L∞)* = ba：对偶从"密度泛函"扩容到"有限可加荷"；保范同构
   的双向构造一升一降（μ → T_μ；ℓ → μ(A) = ℓ(I_A)）。
2. 有限可加是线性的免费赠品，可数可加需要对极限的控制——
   L∞ 范数给不起。
3. 越轨者标本：自然密度荷（单点 0 vs 全空间 1）、Banach 极限、
   超滤荷——全部依赖选择公理式的存在性。
4. ba(·,m) 版本给出 L∞(m)* 的刻画；与第 13 章 p < ∞ 的对偶表
   合并成完整的对偶谱系。
5. 有限世界的退化定理：ba = ca——越轨是无穷现象。
