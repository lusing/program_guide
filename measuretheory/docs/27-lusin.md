## 27.1 问题：可测函数有多"连续"

Borel 可测函数可以极不连续（Dirichlet 函数 1_ℚ 是 Borel
的）。Lusin 定理（1912）的惊人结论：**只要扔掉一个小测度
集，任何可测函数在一个大测度的紧集上都连续**——可测性
几乎就是"逐片连续"。三个层次的说法（由弱到强，互相等价
或接近）：

1. **C_c 稠密版（严书 5.5.1）**：Radon 测度 μ 下，C_c(X)
   在 L^p(μ)（1 ≤ p < ∞）中稠密——连续函数穷尽一切可测
   函数的 L^p 等价类；
2. **紧限制版（经典 Lusin）**：f 可测、μ 有限 Radon ⟹
   ∀ε > 0，∃紧 K，μ(X∖K) < ε 且 f|_K 连续；
3. **连续延拓版（强 Lusin）**：f|_K 可进一步延拓为全空间
   的连续函数（Tietze 型，X 正则时成立）。

三版的共同灵魂：**可测函数的病态可以被一个小集合打包
运走**。这与 Egorov（第 09 章：收敛的病态同理可运走）是
双生定理——两个"几乎处处"的拓扑化。

## 27.2 证明骨架（C_c 稠密 ⟹ 紧限制的路线）

**第一步（简单函数的连续拟合）**：指示函数 1_A（A Borel）
由正则性取紧-开三明治 K ⊆ A ⊆ U（μ(U∖K) < ε），磨光引理
（第 24 章零件库）给 φ ∈ C_c：K 上 = 1、U 外 = 0——则
‖1_A − φ‖_p^p ≤ μ(U∖K) < ε。简单函数（有限线性组合）
同理。**第二步（一般 f）**：简单函数在 L^p 稠密（第 09 章
件）→ 双 ε 传递。第 1 版完成。**第三步（升级到紧限制）**：
对 f 取 L^p 逼近列 fₙ ∈ C_c（‖f − fₙ‖_p < 2⁻ⁿ）+ 连续
函数级数的快速收敛集（Egorov 的紧版：挖掉小测集后一致
收敛）+ 一致收敛保持连续——限制在余集 K 上 f 连续。∎

**细节警示（严书 5.5.1 证明的关口）**：Lᵖ 稠密对 **p < ∞**
成立；p = ∞ 失败（1_ℚ 与任何连续函数的 ‖·‖∞ 距离 = 1——
本性上确界对零测集失明但拓扑不）。这呼应第 09 章"L∞ 的
世界没有 Egorov"——**逼近定理的 p < ∞ 边界**。

## 27.3 Lusin 的推论家族

1. **可测函数的层级图像**：f 可测 ⟺ 存在连续函数列 fₙ 与
   满集 E = ∪Kₙ（紧穷竭），fₙ → f 在每个 Kₙ 上一致——
   "可测 = 紧片上的连续极限"（严书 5.5.1 的逆读）；
2. **积分的连续函数定义**：∫f dμ 可由 C_c 函数的积分逼近
   （L¹ 版）——Riemann 世界与 Lebesgue 世界的又一通道
  （第 24 章应用一的深化）；
3. **加法方程的正则化（严书 5.5.2 习题，经典）**：f :
   ℝ → ℝ 可测且满足 f(a+b) = f(a) + f(b)（Cauchy 方程）
   ⟹ f 连续（从而线性 f(x) = cx）。证明用 Lusin：在某正
   测集上 f 近似连续，加法结构把这份连续性传染到全空间
  ——**代数等式 + 可测性 = 正则性**的范式定理（同样套路
   处理 f(xy) = f(x)f(y) 等函数方程；机器侧第 08 章的
   λ-系是集合版同款思路）；
4. **与 Egorov 的合成**：可测函数列 a.e. 收敛 ⟹ 存在紧
   集 K（μ(X∖K) < ε）上**一致**收敛且每项连续——两个
   "几乎"叠成完全体（第 31 章弱收敛证明的标准零件）。

## 27.2.5 三版等价的细账（从稠密版到延拓版）

**（1 ⟹ 2）稠密版升级到紧限制**：取 fₙ ∈ C_c 使
‖f − fₙ‖_p < 2⁻ⁿ（p = 1 即可）；由 Egorov 紧版（有限
Radon 上挖小集后一致收敛——第 09 章 Egorov + 第 25 章
紧穷竭的合成）存在 K（μ(X∖K) < ε/2）使 fₙ 在 K 上一致
收敛；一致极限保持连续 → f|_K 连续。**（2 ⟹ 3）紧限制
升级到延拓**：f|_K 连续、K 闭 ⊆ 正则空间 X → Tietze 延拓
定理给 F ∈ C(X)（值域 [0,1] 型限制）延拓 f|_K。**（2 ⟸ 3
等）反向平凡**（延拓函数的限制即自身）。三版同一件事的
三种包装——选择按用途：积分逼近用 1、轨道性质用 2、
泛函构造用 3。

**病态打包的极限**：运走集的测度可以任意小但**不必为
零**——1_ℚ 需要运走全部无理点的邻域？不：运走一个包含
ℚ 的测度 ε 开集即可（剩余闭集上 f = 0？错——闭集
F = [0,1]∖U（U ⊇ ℚ，μ(U) < ε），F 上 1_ℚ 的限制 = 1_F
的…… F 无理点处 f = 0，ℚ 点被 U 运走——f|_F ≡ 0 ✓
连续！）。**打包机制**：病态点集收进 ε-开袋，剩余部分
函数自动变乖——这正是"正则性 + 可测性"的乘法效应。

## 27.3.5 Cauchy 方程正则化的完整骨架（经典习题的完全体）

**定理（严书 5.5.2）**：f : ℝ → ℝ 可测，f(x+y) = f(x)+f(y)
⟹ f(x) = cx。

1. **正测集上的近似连续**：Lusin 给闭集 F（μ(F) > 0）上
   f 连续；Steinhaus 定理（第 35 章前置件）：F−F 含 0 的
   邻域 → f 在 0 的邻域上被控制；
2. **局部有界 → 局部连续**：加法性把 F 上的连续传染：
   |f(h) − f(h₀)| = |f(h−h₀) + f(h₀) − f(h₀)|，h−h₀ ∈
   F−F 小邻域 → f 在原点连续（f(0) = 0、f(−x) = −f(x)）；
3. **线性收割**：f(q) = qf(1)（q ∈ ℚ 归纳）；连续 + ℚ
   稠密 → f(x) = x·f(1) ∀x。∎

**范式总结**：可测性（Lusin 化）+ 代数等式（传染性）=
正则性。同款：Lebesgue 可测的特征函数方程、乘法版、
群上的同态正则化——**第 35 章 Steinhaus 与第 40 章解析
集都会重演这个"局部→整体"的传染逻辑**。

## 27.5.5 习题账单（自检清单）

1. 1_ℚ 与一切连续函数的 ‖·‖∞ 距离 = 1；但 ‖·‖₁ 距离
   = 0（a.e. 相等）——两种距离的哲学差异一句话总结；
2. 写出 C_c 在 Lᵖ 稠密证明中"p = ∞ 失败"的完整反例；
3. Steinhaus 定理陈述（正测集的差集含邻域）并说明它在
   27.3.5 的第 1 步如何使用；
4. 强 Lusin（延拓版）在 X = ℝ、f = 1_{[0,1]} 上的显式
   构造：K = [0,δ]∪[1−δ,1]∪… 的选取与 Tietze 延拓的
   显式分段线性；
5. 证明：若 μ 有限 Radon，则对一切可测 f 存在连续函数
   列 gₙ 与满测开集 U 使 gₙ → f 在 U 的每个紧子集上一致
  ——三版定理的"序列包装"。

## 27.3.6 Lusin 与 Egorov：双胞胎定理的对照表

两个"几乎"定理共享同一套证明零件，对照阅读最能看清结构：

| | Egorov（第 09 章） | Lusin（本章） |
|---|---|---|
| 对象 | 收敛列 fₙ → f | 单个可测 f |
| 病态 | 不收敛快的点集 | 不连续的点集 |
| 运走 | 小测集后**一致收敛** | 小测集后**限制连续** |
| 零件 | 逐点收敛的层级集 ∪ₙ∩ₘ∪_{k≥m}[|fₖ−f|<2⁻ⁿ] | 三明治 + 磨光 |
| 测度前提 | 有限测度（σ-有限失败例） | Radon（正则性承重） |
| p = ∞ 界 | 一致收敛即 L∞ 收敛 ✓ | C_c 不稠密于 L∞ ✗ |
| 下游 | Riesz 子列、Vitali | 积分的 C_c 定义、条件分布 |

**共同格式**：∀ε ∃好集（补集测度 < ε）使得"逐点性质
升级为一致性质"。数学的"几乎处处"从来不是终点——终点
是"在大多数地方完全规矩"。两个定理是这条哲学的收敛列
版与单函数版。

## 27.4 数值实验：拟合与运走

**Julia（`27_lusin.jl`）**：

- **指示函数的连续拟合**：A = [0.3, 0.7] ∪ Cantor 集（前
  6 级），f = 1_A 在 [0,1] 上；构造分段线性拟合 φ_ε
 （斜坡宽 ε）——数值积分 ‖f − φ_ε‖₁ ≤ 2ε·μ(边界带) 收敛
  账（ε = 2⁻ᵏ 序列）；
- **紧限制的显影**：Dirichlet 型函数 f = 1_ℚ∩[0,1] 在
  网格上的"连续化"：挖掉测度 δ 的带（把 ℚ 点扰动进 δ-带），
  剩余集合上 f 恒 0——连续！μ(挖掉) = δ 任取——**Lusin 的
  运走集构造可视化**；
- **Cauchy 方程的传染演示**：f(x) = cx（c = 0.7）与病态
  Hamel 解（取 Hamel 基的可测性破坏版——数值只能演示
  "若可测则连续"的正向：cx 的连续性 + 加法等式核对）；
- **p = ∞ 边界**：1_ℚ 与最佳连续近似的 ‖·‖∞ 距离恒 = 1
  的数值证词（第 27.2 警示的机器账）。

**Python（`27_lusin.py`）**：Fraction/精确账——分段线性拟合
的 L¹ 差精确分数（斜坡的面积公式）、Cantor 拟合的 3⁻ⁿ 级
精确递推、1_ℚ 的无穷情形账。

## 27.4.5 实验断言清单（数值通道验收单）

1. **拟合账**：A = [0.3,0.7] 的 φ_ε（斜坡 ε）的 L¹ 差 ≤
   2ε（精确面积公式）；Cantor 前 6 级的拟合差 3⁻ⁿ 级；
2. **运走账**：1_ℚ 挖 δ-开带后剩余集上恒 0——连续化达成，
   μ(带) = δ 任给（0.01, 0.001 序列验证）；
3. **p = ∞ 证词**：1_ℚ 与最优连续近似的 sup 差恒 ≥ 1
  （网格搜索的数值下界）；
4. **Cauchy 传染**：f(x) = 0.7x 的加法等式逐对核对（随机
   1000 对 (a,b) 的 f(a+b) = f(a)+f(b) 浮点账）+ 连续性
  （|f(x+h)−f(x)| = 0.7|h| 显式）；
5. **级数拟合**：Σφₙ 型 C_c 级数对 L¹ 目标 f 的逼近误差
   谱（Egorov 合成件的数值影子）。

## 27.6 要点回顾

1. Lusin 三版：C_c 在 Lᵖ（p<∞）稠密 / 紧限制连续 /
   连续延拓——"病态打包运走"的三个包装。
2. 证明 = 三明治 + 磨光（指示函数起步）+ 简单函数稠密 +
   Egorov 紧版（升级）；p = ∞ 边界（1_ℚ 反例）。
3. 推论：可测 = 紧片连续极限；积分的 C_c 定义；Cauchy
   方程正则化（代数 + 可测 = 连续）；与 Egorov 的合成件
  （第 31 章零件）。
