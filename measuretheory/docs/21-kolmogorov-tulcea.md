## 21.1 问题：先有有限维，后有整体

第 20 章的独立乘积把"每个坐标的配方"装配成整体测度。但随机
过程的标准处境更一般：**先给定有限维分布族**——对每个有限
指标集 S，(Ω_S, ⊗_{i∈S}F_i) 上有概率 P_S（"在窗口 S 里看，
分布已知"），**何时存在 ∏Ωᵢ 上的 P 使每个窗口的像测度恰为
P_S？**必要条件自动成立——**相容性**：

  S ⊆ T ⟹ P_T ∘ π_{S,T}^{-1} = P_S（大窗口的边缘 = 小窗口）。

Kolmogorov（1933）的回答：Ωᵢ = ℝ（或任何 Polish）时**相容性
也充分**。这条定理是随机过程论的"创世执照"：布朗运动（有限
维高斯相容）、马氏链（转移核迭代）、无穷粒子系（Gibbs 规范）
全都持此证上岗。本章按严书 §4.5 的路线——**紧类抽象**——
给出推广形式，它同时涵盖 Kolmogorov（拓扑紧）与 Tulcea
（核构造）两个经典引擎。

## 21.2 紧类：紧性的纯集合论提纯

**定义（严书 4.5.1）**：集类 𝓒 称**紧类**，若对任何
{Cₙ} ⊆ 𝓒（不必递减！），∩ₙCₙ = ∅ ⟹ 存在 m 使
∩_{n≤m}Cₙ = ∅。——把"紧集套非空"提炼成不含拓扑的交性质。

**原型**：Hausdorff 空间中的紧集全体是紧类（紧集套原理：递减
紧集族的有限交非空 ⟹ 全交非空；非递减序列取有限段交改造成递减
即可）。**反例**：开集类不是紧类（(0, 1/n) 递减交空但有限交
非空）；单点类 {{x} : x ∈ ℝ} 不是（xₙ → x*，xₙ ≠ x*：交空、
有限交非空）。

**封闭性（严书引理 4.5.2 的要点）**：紧类对"可数并的有限
包装"稳定——𝓒_uf := {有限个 𝓒 元素之并的有限交} 仍是紧类
（证明是组合式的：把新类的空交反推回旧族的空交，抽有限子族）。
这一步为下节的"近似集中"提供材质。

## 21.3 紧测度与推广的 Kolmogorov 定理

**定义（严书 4.5.4）**：(E, ε, μ) 上 μ 称**紧测度**，若存在
紧类 𝓒 ⊆ ε 使 μ(A) = sup{μ(C) : C ⊆ A, C ∈ 𝓒}——测度从
内部被紧类逼近（内正则性的紧类版）。Borel 概率测度在
Polish 空间上都是紧测度（胎紧性：紧集吸收 1-ε 的质量，第
29/32 章的正则性定理正是这件事实的完全体）。

**定理（严书 4.5.5，推广的 Kolmogorov 相容性定理）**：
(Ωᵢ,Fᵢ)_{i∈I}，𝓢 为有限支集柱集代数。相容族 {P_S} 若满足
**每个 P_S 的半代数限制是紧测度**（存在公共紧类做内部逼近），
则在 𝓢 上定义的集函数 P（P(柱) := P_S(柱)）可唯一延拓为
⊗ᵢFᵢ 上的概率测度。

**证明骨架四步**（严书 pp. 103-105）：

1. **柱集账良定义**：相容性保证（同柱两种写法走更大的 S 统一
   收账）；
2. **有限可加**：柱集代数上标准的有限剖分论证；
3. **σ-可加（灵魂步骤）**：Cₙ ∈ 𝓢 递减、P(Cₙ) ≥ ε > 0，往证
   ∩Cₙ ≠ ∅。对每个 Cₙ 用紧逼近取**紧见证** Kₙ ⊆ Cₙ 使
   P(Cₙ ∖ Kₙ) ≤ ε·2^{-(n+1)}；令 D_n := ∩_{k≤n}K_k（紧类成员，
   测度 ≥ ε/2 > 0 故非空！）。**紧类性质**接管：若 ∩D_n = ∅
   则某有限段交 = ∅，与 D_n 非空矛盾；故 ∩ₙD_n ≠ ∅，其任一
   点落在 ∩Cₙ 内。∎——第 20 章验收论证的抽象重放：紧见证 +
   ε/2ⁿ 摊派 + 紧类套原理；
4. **延拓与唯一性**：第 04 章 Carathéodory 机器 + 第 06 章
   π-系唯一性。

## 21.3.5 反例与检验清单：相容性如何死亡

**反例一（边缘失配）**：二维族 P_{1,2} = 均匀于 {(0,0),(1,1)}
（完美相关），P_{2,3} = 均匀于 {(0,0),(1,1)}，P_{1,3} =
独立均匀。检验：P_{1,2} 的第二边缘 = 均匀{0,1}；P_{2,3} 的
第一边缘 = 均匀{0,1} ✓；但三维装配必然要求 X₁ = X₂、X₂ = X₃
（两两完全相关），于是 X₁ = X₃ 完全相关——与 P_{1,3} 独立
矛盾。**相容性死在传递性上**：两两相容 ≠ 整体相容（与
"两两独立 ≠ 独立"，第 35 章，同一族陷阱）。

**反例二（缺紧测度性）**：Ω = ℚ（有理数带 Borel 限制），
Pₙ = 标准差 1/n 的"高斯型"分布序列的相容族——ℚ 上概率测度
**不是紧测度**（ℚ 无非空紧集有正测度：紧集 = 有界闭紧
子集，在 ℚ 中测度可被挖空）。此类族可能没有无穷维装配
（质量在"无穷远处"渗漏）——Polish 前提（或紧类前提）在
非完备空间上的真实代价。经典例：取 Ω = ℚ，P 作用于柱集
"前 n 坐标落在 x* = √2 的 1/n 邻域"，有限维相容、整体无
极限点。

**检验清单**（数值通道检查器的规格）：对族 {P_S}，
(1) 每个 P_S 是概率（归一）；(2) S ⊆ T ⟹ marginal(P_T, S)
= P_S（**枚举所有窗口对**）；(3)（核装配路线）验证
marginal(P_{S∪{j}}, S) 递归一致。第 21.7 节的 Prolog/Python
检查器就是这份清单的可运行版。

## 21.4 经典形式的收割

**Kolmogorov 相容性定理（Ωᵢ = ℝ）**：ℝ 上每个概率测度是紧
测度（紧区间的内逼近：[-M,M] 吸收 1-ε；紧区间全体是紧类），
且**公共紧类可取**（乘积紧盒 {∏[-M,M] 截段}）。故 ℝ^I 上
任何相容有限维分布族都装配出唯一的乘积概率。三个即时执照：

- **独立序列**：P_S = ⊗_{i∈S}P_i（第 20 章的重新发证）；
- **马氏链**：P_n = ν ⊗ P ⊗ … ⊗ P（转移核 n 次复合的有限维
   分布，第 19 章 Chapman-Kolmogorov 保证相容）；
- **高斯过程**：均值 m(t) + 相容协方差 K(s,t)（半正定）给出
  有限维高斯族，相容性 = 协方差的子块结构——布朗运动
  K(s,t) = min(s,t) 在此持证上岗（第 47 章完全体）。

**唯一性的代价**：⊗ᵢFᵢ 上唯一，但**完备化后不唯一延伸**；
且 ⊗ᵢB(ℝ) 的事件只依赖可数坐标（第 17 章）——"整体轨道性质"
（连续性、有界性）需要**可分修改**或外测度装修才能落进测度论
（第 43 章正题）。

## 21.5 Tulcea 定理：核动力的存在性

**Tulcea（1949）**：Ω_n、转移概率核 Q_n : Ω_{<n} → Ω_n
（第 n 步依赖前 n-1 步），定义有限维

  P_n := ν₁ ⊗ Q₂ ⊗ … ⊗ Q_n（核复合的测度版，第 19 章）。

相容性免费（核复合的结合律）。**结论**：无穷维 P 存在——
**不需要任何紧性/拓扑**，核的可测性条款顶替一切。证明是
"指示函数的递归收割"：对柱集指示 I_C（C 支集 ≤ n）有
∫I_C dP_n = ∫…∫（逐层核积分）；要证 P 在柱集代数上 σ-可加，
把递减柱集列的指示压进条件期望塔（第 36 章的预告），递归地
"剥最后一层坐标"——严书 pp. 104-105 的证明（OCR p129 可见
h₂、Q₂(ω(1),dw(2))、A₁(ω(1)) 的记号现场）用**正则条件版**
论证：若 P(Cₙ) ≥ ε，逐层取出"条件正概率见证"
ω(1) ∈ B₁、ω(2) ∈ B₂(ω(1))…，拼出 ∩Cₙ 的点。

**两台发动机的对照**：

| | Kolmogorov（紧类版） | Tulcea（核版） |
|---|---|---|
| 进料 | 相容有限维族 + 紧测度性 | 初始分布 + 核列 |
| 引擎 | 紧见证 + 紧类套原理 | 逐层剥核 + 条件见证 |
| 拓扑要求 | 要（紧类从拓扑来） | 不要 |
| 分布自由度 | 任意相容（含长程依赖） | 马氏式逐坐标装配 |
| 严书 4.5 的地位 | 4.5.5 定理 | 4.5.7 推广（核+紧类混合版统一两者） |

**混合版才是严书的正货**：4.5.5 的证明允许"部分坐标用核、
部分坐标用紧测度"——随机过程的现代构造（如 Gibbs 场的
DLR 方程）常用此混合形态。

## 21.7 数值实验：相容性的双向账

**Julia（`21_kolmogorov.jl`）**：

- **相容族正例**：二维高斯族 P_{s,t}（协方差 min(s,t)）——
  固定窗口 {1,2} 的边缘 vs 直接指定：数值积分对拍边缘密度；
  三维窗口 {1,2,3} 的二维边缘 = 二维窗口分布（离散网格 +
  Simpson 积分，误差 < 1e-6）——**相容性的数值原文**；
- **不相容反例**：故意取 P_{1,2} 与 P_{2,3} 边缘不匹配的族，
  检查器报出断言失败（P_{1,2} 的第二边际 ≠ P_{2,3} 的第一
  边际）；
- **核装配**：马氏链两步（第 19 章的核）作为 Tulcea 有限维
  的实例——P₃ 的 {2}-边缘 = P₂ 的 {2}-边缘（核复合恒等式
  的数值版）。

**Python（`21_kolmogorov.py`）**：Fraction 精确版相容性检查器
——有限格点分布族 {P_S} 的边缘投影（`marginal(P_S, keep)`）、
相容性谓词 `consistent(family)` 全窗两两核对；马氏链 3 步
装配的精确账。

**Prolog（`21_kolmogorov.pl`）**：符号检查器——分布表
`dist(S, Assign, P)`、边缘谓词 `marg/4`（对被丢坐标求和）、
`consistent/1`（枚举窗口对核对共享边缘）、反例族与正例族
（独立乘积、核装配）各跑一遍。

## 21.7.5 历史注记

Kolmogorov（1933，《概率论基础》第四章）以相容性定理为
公理化概率论的"存在性兜底"：公理本身不保证无穷维模型存在，
相容性定理补上这块地基。Tulcea（1949）的核版去掉了拓扑
前提，成为马氏过程构造（Doob、Neveu 的教材传统）的标准件。
**紧类抽象**的谱系：从 Parthasarathy（1967）的"compact
class"到严书 §4.5 的混合推广（核 + 紧类两台发动机合一），
这条线在随机过程的现代教材（如 He-Wang-Yan）中定型。袁书
10.4.2 只收经典版（Polish 前提），严书的推广版覆盖"部分
坐标拓扑、部分坐标核"的混合构造——**Gibbs 场的 DLR 方程
（有限体积规范 + 边界条件）正是这种混合形态的实战现场**，
本章 docs 的总表（21.5）为此留了接口。

## 21.8 要点回顾

1. 相容性是无穷维存在的必要条件；紧测度性（Polish 情形免费）
   使之充分——Kolmogorov 相容性定理 = 随机过程的创世执照。
2. 紧类把"紧集套原理"提纯成交性质，对有限交/可数并的包装
   稳定；证明灵魂 = 紧见证 + ε/2ⁿ 摊派 + 紧类套。
3. Tulcea 用核可测性顶替拓扑：逐层剥核的构造性存在，马氏式
   装配不要紧性；严书 4.5.5 的混合版统一两台发动机。
4. 唯一性限于 ⊗ᵢFᵢ（可数坐标本质）；轨道性质的装修留给
   第 43 章。
5. 机器侧（两台发动机各配一台）：Lean = `IonescuTulcea.traj`/
   `trajMeasure`（Tulcea 全形式化）+ `IsProjectiveLimit` 谓词
   族与唯一性；Isabelle = `Projective_Limit`（Kolmogorov 存在
   性）；数值通道做相容性检查器（正例/反例/核装配三向账）。
