## 15.1 掉头行驶的测度论

第 04 章的 Carathéodory 路线是"从集函数（预测度）到积分"：
先有长度，再有测度，最后有积分。Daniell 路线（1918）**完全
掉头**：从"已经会积分"的函数类出发（黎曼积分、阶梯函数积分、
期望值公理），**把测度造出来**。动机是公理化概率论的前置问题：
Kolmogorov 公理把概率定义为测度，但随机变量的"期望"在直觉上
先于事件的概率——Daniell 给出"从期望造概率"的严格机器，也是
第 45 章 Minlos-Sazonov 定理在核空间上的标准前置件。

## 15.2 向量格与 Daniell 积分（严书 3.6.1-3.6.3）

**向量格** H：Ω 上的实值函数组成的线性空间，且 f, g ∈ H ⟹
f ∧ g, f ∨ g ∈ H（等价地 |f| = f ∨ (−f) ∈ H）。格运算与线性
组合生成大量封闭性（f ∧ a、f⁺、f⁻ 都在 H 内），够格当"积分的
试验田"。

**Daniell 积分** I : H → ℝ：

1. **正线性**：I(af + bg) = aI(f) + bI(g)，f ≥ 0 ⟹ I(f) ≥ 0；
2. **下单调连续**（严书 3.6.4）：fₙ ∈ H, fₙ ↓ 0 ⟹ I(fₙ) ↓ 0。

等价形态（3.6.5）：fₙ ↑ f ∈ H ⟹ I(fₙ) ↑ I(f)——条件 2 正是
MCT 的公理化。**不要求 H 对极限封闭**：I 只需在"极限落在 H
内"时连续。两个即时例子（3.6.4-3.6.5）：代数 A 上的简单函数
全体（I = 简单积分），以及整个 L¹(μ)（I = μ-积分）——Daniell
公理是对这两个实例的公理化提纯。

## 15.3 构造五步：H 到 μ*（严书 3.6.6-3.6.9）

Daniell 扩张的流水线与 Carathéodory 惊人地平行——逐条对照表
放在 15.5。

1. **上扩 H***：H⁺ = H ∩ [0,∞)；H* = {f : ∃fₙ ∈ H⁺, fₙ ↑ f}
   （单调升包，允许 ∞ 值）。I 上扩为 I*(f) = sup I(fₙ)
   （良定义：格运算保证不同逼近列的 sup 一致）。
2. **造集族 C**：C = {C ⊆ Ω : I_C ∈ H*}——"指示函数能被
   H⁺ 单调逼近"的集合。H 的格封闭性（引理 3.6.7）保证
   C 对**可数并**与**有限交**封闭、且 [f > a] ∈ C（f ∈ H⁺）——
   C 已经是 λ-系的近亲。
3. **造外测度**：μ*(C) = I*(I_C)（C ∈ C 上先赋值），一般
   A ⊆ Ω 用覆盖下确界 μ*(A) = inf{μ*(C) : C ∈ C, A ⊆ C}。
   次可加性：ε/2ⁿ 摊派 + C 的可数并封闭——**与第 04 章
   Lebesgue 外测度的证明逐字同构**。
4. **Carathéodory 限制**：M* = 全体 μ*-可测集 ⊇ σ(C)（引理
   1.4.5 复用——半环验收工序的回归），μ = μ*|M* 是测度。
5. **表示定理（Daniell-Stone）**：H ⊆ L¹(μ) 且 I(f) = ∫f dμ
   对一切 f ∈ H 成立；μ 在 σ(C) 上由 I 唯一确定。

## 15.4 Stone 条件与唯一性

表示的**唯一性**需要额外一点：**Stone 条件** f ∈ H ⟹ f ∧ 1 ∈ H
（"截断"留在 H 内）。无此条件时 I 可能在不同测度上有相同
表现（H 太瘦，分不清测度在某块上的质量）。带 Stone 条件的
Daniell-Stone 定理给出一一对应：

  { Daniell 积分 (H, I) } ↔ { 测度 μ : H 的简单积分闭包 = μ 的积分 }。

阶梯函数（f ∧ 1 仍是阶梯）天然满足 Stone 条件；"无界线性函数
全体"（f ∧ 1 跑出去）是标准反例。

## 15.5 两台发动机的对照表

| Carathéodory（第 04 章） | Daniell（本章） |
|---|---|
| 原料：半环上的预测度 μ₀ | 原料：向量格上的正线性泛函 I |
| 区间长度 μ₀((a,b]) | 阶梯积分 I(ΣαᵢI_Aᵢ) |
| 覆盖下确界造外测度 μ* | H* 上扩 + I*，μ*(A) = inf I*(I_C) |
| Heine-Borel 紧性（验收 σ-可加） | 下单调连续（验收 3.6.4） |
| Carathéodory 判据选 M | 同一判据（引理 1.4.5 原样复用） |
| 完备化收尾 | Stone 条件收尾（唯一性） |

**两条路线殊途同归到 (σ-代数, 测度, 积分) 三件套**——这不是
巧合：外测度机器与单调升包机器在格论层面是同一台设备（上确界
保序延拓）的两种外壳。第 24 章 Riesz 表现定理（正线性泛函 →
Radon 测度）是 Daniell 路线在拓扑世界的现代化版本。

## 15.6 数值实验：有限 Daniell 的完整流水线

**Julia（`15_daniell.jl`）**在 Ω = {1,…,8} 上复刻五步流水线：

- **进料**：H = 三块划分 {{1,2},{3,4},{5,6,7,8}} 上的阶梯函数
  （6 维向量格），I 由块权 (1/2, 1/3, 1/6) 给出（I(αI_A+βI_B+γI_C)
  = α/2 + β/3 + γ/6）；
- **步骤 1-2**：数值枚举 H*（有限格上 = 非负阶梯全体）与 C
  （= 三块代数：8 个并集）；
- **步骤 3**：μ*(A) = inf 覆盖账——有限世界精确等于"命中块的
  权和"（未被细分的块整块计价）；
- **步骤 4**：Carathéodory 可测集 = 三块代数本身（μ* 的原子
  即三块）；μ = μ*|代数，总质量 1 核对；
- **步骤 5（表示）**：随机生成 500 个 H 中函数，I(f) 与
  ∫f dμ 逐个精确相等——**Daniell-Stone 表示定理的有限版全文**；
- **对照**：换块权 (0.2, 0.5, 0.3) 重跑，μ 随之改变而结构不变
  ——I 的信息全部进入 μ（唯一性方向）。

**Python（`15_daniell.py`）**：Fraction 精确版——μ* 覆盖账、
表示积分、总质量全部零舍入；并加**非 Stone 反例的演示**：
把 H 换成"不含 f ∧ 1 封闭"的瘦格（只含两块常数函数），演示
同一 I 允许不同 μ（在第三块上挪质量不影响 I）——唯一性失败
的有限版。

**Prolog（`15_daniell.pl`）**：符号版流水线——向量格运算
（∧ ∨ + 线性）在 6 元组上定义、Daniell 公理逐条检查（含
fₙ ↓ 0 ⟹ I ↓ 0 的有限链版本）、μ* 的覆盖账与表示定理的
穷举核对。

## 15.6.5 I* 的性质清单与两个即时应用

上扩后的 I* 继承 I 的全部代数性质并新增连续性（证明全部是
"逼近列的取 sup"的直接搬运）：

1. 正齐次与次可加：I*(f + g) ≤ I*(f) + I*(g)（两列逼近的
   逐项相加给一列逼近，sup 不增）——**注意是次可加**，等号
   需要 f、g 的逼近列相容；
2. 单调：f ≤ g ⟹ I*(f) ≤ I*(g)；
3. 下连续：fₙ ∈ H*, fₙ ↑ f ⟹ I*(fₙ) ↑ I*(f)（对角线再取
   一层 sup）；
4. 集函数侧：μ*(C∪D) ≤ μ*(C) + μ*(D)，且 C ⊆ D ⟹
   μ*(C) ≤ μ*(D)。

**即时应用一（测度的再发现）**：从 H = [a,b] 上连续函数全体、
I = Riemann 积分出发，五步流水线产出 **Lebesgue 测度**——
Riemann 积分以为自己只是求和工具，被 Daniell 透视出体内
的测度。这正是 Daniell 1918 年原论文的动机：不依赖长度
直觉（区间长度公理）而仅用积分的代数与连续性重建分析学。

**即时应用二（概率的正向公理化）**：H = 某类"赌注"（随机变量的
简单组合）、I = 期望价格的公理（正线性 + 连续性），五步产出
概率测度 P 与 E(X) = ∫XdP——**期望在公理上先于概率**。
这与 Kolmogorov 1933 的"概率优先"形成对偶的两条公理化道路，
在第 21 章 Kolmogorov 相容性定理（概率优先路线的高塔）与
第 45 章 Minlos-Sazonov（期望优先路线在无穷维的巅峰）处
将再次相遇。

**H* 构造的一个技术细节**（初学最易卡壳处）：为什么上扩到 H*
而不是直接对 H 用 sup？因为 H 对 sup 不封闭（单调列的极限
可能跑出 H），而 I 的延拓恰恰需要"追着极限跑"的场地；H* 里的
元素可以取 ∞ 值（如 fₙ = n 单调升到恒 ∞），I*(f) = ∞ 合法——
**∞ 是场地的一部分而非事故**。C 的定义（I_C ∈ H*）则把 ∞
挡在集函数门外：I*(I_C) = ∞ 的集合根本不进 C，μ* 从 C 起步
时已自带有限性预算。这与第 04 章外测度允许 μ*(A) = ∞ 的姿态
完全一致——两台发动机在同一处放松、同一处收紧。

## 15.7.5 与 Riesz 表现定理的接口

第 24 章的主角（Riesz-Markov-Kakutani：局部紧空间上 C_c 的
正线性泛函 = Radon 测度）在结构上是 Daniell 定理的**拓扑增强
版**——对照阅读最能看清各零件的分工：

- **公共骨架**：正线性 + 单调连续（Daniell 公理 = Riesz 泛函
  的连续性）→ 外测度 → Carathéodory 限制 → 表示；
- **Riesz 多付的**：紧集的有限性预算（‖·‖_K 上界换内正则性）、
  Urysohn 引理（开集的连续逼近——把 C 族的封闭性从"格运算"
  升级为"拓扑分离"）、Riesz 表示空间取 **Radon 测度**（内紧
  外开正则——第 25 章的正则性已预装）；
- **Daniell 多付的**：对 Ω 无任何拓扑要求（一般测度空间通吃），
  Stone 条件的代数表述。**两条路在 C_c(Ω) 上重合**：H = 紧支撑
  连续函数既满足 Daniell 公理又带拓扑——第 24 章的 mathlib
  锚点 `RieszMarkovKakutani` 文件族正是从这一族函数出发的
  形式化。

**测度论公理的三层楼**：底层——长度/测度公理（Kolmogorov、
Carathéodory：集合的账本）；中层——积分公理（Daniell：函数
的账本）；顶层——泛函公理（Riesz：拓扑的账本）。三层楼互相
翻译，每一层都有自己的"原生定理"（底层的 RN 定理、中层的
Stone 唯一性、顶层的正则性），翻译保真度由各自的附加条件
（σ-有限 / Stone / 局部紧）保证。本教程的章节布局正是沿
这三层楼爬升：第 01-12 章住底层，第 13-15 章住中层，第 23-29
章登顶层。

## 15.8 要点回顾

1. Daniell = 测度论的掉头行驶：从期望公理造概率测度；正向
   （简单积分/L¹）两例是公理的来源。
2. 五步流水线：H* 上扩 → C 集族 → μ* 外测度 → Carathéodory
   限制 → 表示定理；与第 04 章对照表逐行平行。
3. Stone 条件（f∧1 ∈ H）买唯一性；无它的瘦格反例在数值通道
   复刻。
4. 定位：Kolmogorov 公理化的事后补票；第 24 章 Riesz 表现的
   前身；第 45 章 Minlos-Sazonov 的标准前置件。
5. 三层楼视角（测度/积分/泛函公理）是全书结构的一把总钥匙。
