## 32.1 问题：谁有收敛子列？

数列有界 ⟹ 有收敛子列（Bolzano-Weierstrass）。测度列的
对应问题是：**什么条件保证 {μₙ} 有弱收敛子列？** 一维的
Helly（30 章）给了半个答案（子列存在但极限可能亏损）；
本章的**Prokhorov 定理**补上另一半：**胎紧性**（质量不
集体逃逸）⟺ 弱相对紧（一切序列有弱收敛于族内的子列）。
这是第 31 章弱收敛的"存在性发动机"——一切"先抽子列"式
证明（中心极限定理的常规证法、第 52 章）的动力室。

## 32.2 胎紧性：定义与即时判据

**定义（严书 6.3.3 / 袁 12.7.2）**：Λ ⊆ P(X)（概率测度族）
**胎紧**：∀ε > 0，∃紧 K ⊆ X 使 inf_{μ∈Λ} μ(K) ≥ 1 − ε
——一个紧集**统一**吸收全族的质量。

**Ulam 定理（单测度版，29 章的收割）**：Polish 空间上
**单个**概率测度恒胎紧——紧套逐 ε 构造（铺砖 + 完备化）。
但**族的一致性**要额外付款：

- ℝᵈ 上有界（分布）族：若 {μₙ} 一致小尾（∃M：μₙ([−M,M]ᶜ)
  ≤ ε 一致 n）⟹ 胎紧；
- **一致有界矩族**：sup ∫|x|² dμₙ < ∞ ⟹ 胎紧（Chebyshev
  一致版：μₙ(|x| > M) ≤ C/M²）；
- **反例（非胎紧）**：{δₙ} 于 ℝ——每个紧集吃不到跑远的质量；
  {δ_{n mod k}} 循环族同理；
- **非 Polish 陷阱**：ℚ（继承拓扑）上 {δ_{qₙ}：qₙ 遍历
  ℚ}——ℚ 的紧集（闭于 ℝ 的有界集∩ℚ 中紧者）在可数稠密
  下无法统一吸收（单点测度胎紧 ✓ 但族不胎紧且 Prokhorov
  失效——Polish 前提不可省的见证）。

## 32.3 Prohorov 定理：两个方向的不对称

**定理（严书 6.3.4-6.3.5 / 袁 12.7.3）**：度量空间 X：

1. **(胎紧 ⟹ 相对紧)**：Λ 胎紧 ⟹ Λ 的每个序列有弱收敛
   子列（**极限在 P(X) 内**——质量不亏损）；
2. **(相对紧 ⟹ 胎紧)**：X Polish（或可分完备）时反向成立。

**方向 1 的证明骨架（三步，对角线的完全体）**：

1. **可数检验集**：可分空间取可数稠密 {xₖ}；球族
   B(xₖ, r) 的示值 {μₙ(B(xₖ,r))} 有界 → 对角线子列使
   一切 (k, r ∈ ℚ⁺) 同时收敛——**柱面账本**的逐点极限 μ*
   （在球生成的代数上良定义）；
2. **胎紧 ⟹ μ* 可数可加**：紧套 Kₑ 吸收质量 ⟹ 递减空交
   的列在 μ* 下账 → 0（ε-紧控制——**Carathéodory 验收的
   紧性版**，第 20 章 σ-可加验收的拓扑重演）；
3. **延拓 + Portmanteau 收口**：μ* 延拓成测度 μ（π-λ 机器），
   球账的逐点收敛 + 磨光不等式给闭集上 limsup 纪律 ⟹
   μ_{nₖ} ⇒ μ。∎

**方向 2 的证明思路（反证 + Polish 分离）**：非胎紧族若
相对紧，取违反胎紧的 ε-证据序列 + 弱收敛子列的极限 μ；
μ 自身胎紧（Ulam）给紧集 K，但构造的开集 G ⊇ K 与证据
序列矛盾（portmanteau 单边条款的对抗使用）。

## 32.4 Prohorov 的应用流水线

**标准三步（CLT 型证明的模板，第 52 章实弹）**：

1. 证 {μₙ} 胎紧（通常：一致矩条件）；
2. 识别一切子列极限（特征函数/矩/典型检验唯一确定 μ）；
3. 收口：相对紧 + 极限唯一 ⟹ 全列收敛（反证：否则违反
   极限唯一）。

**其他常客**：① C[0,1] 上的测度紧性判据（Arzelà-Ascoli 的
测度版：**模连续性一致控制** + 胎紧——第 43 章过程存在性
的核心工具）；② 经验过程（Donsker 定理，第 52 章邻居）；
③ Gibbs 测度的热力学极限（第 22 章混合引擎的下游）。

## 32.3.5 验收步骤的细账（Carathéodory 的紧性版）

方向 1 第 2 步的 σ-可加验收展开（与第 20 章 20.2.5 的
平行对照——读者应并排阅读）：

1. **递减空交的账**：柱面族上的 μ* 已有限可加；设 Bₖ ↓ ∅
   要证 μ*(Bₖ) → 0。反证 μ*(Bₖ) ≥ ε 对一切 k；
2. **紧控制**：胎紧给紧 K（族内每个 μ(K) ≥ 1−ε/4），
   Bₖ ∩ K ↓ ∅ 于紧 K——**有限交性质**：某 B_{k₀} ∩ K = ∅
  （K 紧：闭子集递减空交 ⟹ 有限步空）；
3. **余量收口**：μ*(B_{k₀}) ≤ μ*(Kᶜ) 的控制 = 每个测度
   的 K 外质量 + 极限传递 ≤ ε/4 + 柱面逼近差 < ε——矛盾。∎

**与第 20/21 章的同构**：柱面代数 ↔ 柱集代数、μ* 的有限
可加 ↔ 账本良定义、紧验收 ↔ 紧类验收——**Prokhorov 是
Kolmogorov 延拓定理的"收敛版转置"**：那边造一个测度，
这边收敛到某测度，发动机同一台。

## 32.4.5 C[0,1] 紧性判据的账单（过程论的钥匙预览）

Arzelà-Ascoli 的测度版（第 43 章主用）：P(C[0,1]) 中族 Λ
相对紧 ⟺ ① 起点一致紧（{X(0)} 胎紧于 ℝ）+ ② **模连续性
一致小**：lim_{δ→0} sup_{μ∈Λ} μ(w_X(δ) > ε) = 0，其中
w_X(δ) = sup_{|s−t|≤δ}|X(s)−X(t)|。证明：①+② ⟹ 轨道
以大概率落入等度连续的紧函数类（Ascoli）⟹ 胎紧 ⟹
Prokhorov。**这是 32 章机器在无穷维的第一次实战**——布朗
运动的存在性（Lévy 构造的连续修改路线）全部依赖此判据。
数值通道在 43 章将做 w_X(δ) ~ √(δ log(1/δ)) 的模量实验
（22 章已预演）。

## 32.5.5 实验断言清单（数值通道验收单）

1. **一致矩 ⟹ 胎紧**：σₙ ≤ 2 的正态族于 M = 8 的吸收
   下界 1 − 4/64（Chebyshev 精确分数账）逐 n 验证；
2. **δₙ 非胎紧**：μₙ([−M,M]) = 1_{n≤M}——一致下界 0 的
   整数账；M = 10⁶ 时前 10⁶ 项通过、第 10⁶+1 项破产
  （一致性破产的"迟到的反例"）；
3. **对角线**：5 列混合漂移在 100 球上的同时收敛子列；
4. **矩逃逸**：N(0,n) 的二阶矩账 = n → ∞；
5. **半额逃逸**：μₙ = δₙ/2 + δ_{−n}/2 的 Helly-淡极限
   （30.3.5 案例 3 的数值对拍）。

## 32.5.6 Prokhorov 距离与胎紧的接口账

d_P（33 章）把本章主定理度量化的两个即时收成：

1. **紧集刻画**：Λ ⊆ P(S) 是 d_P-紧 ⟺ Λ 胎紧（32 章
   的度量化陈述）——Heine-Borel 的测度版；数值上"d_P-紧"
   的验收转化为"紧套吸收"的显式构造（实验断言 1 的
   Chebyshev 账即其雏形）；
2. **完备化的免费午餐**：S Polish ⟹ (P(S), d_P) 完备
  （33.3.5 的三步证明）——一切 Cauchy 列自动收敛，"先证
   Cauchy 再补验收"的证题模板（特征函数法的标准姿势，
   49 章实弹）由此合法化。

## 32.6.6 历史注记

Prokhorov（1956）在一般度量空间的系统化沿用 Umam（1941，
紧空间）与 Lévy（1937，一维 cdf）的先驱工作；"胎紧"
术语来自 Le Cam 的法语 tends（收紧）。Prokhorov 本人同期
定义了 33 章的距离——两件套（距离 + 紧性刻画）把弱收敛
从"逐函数检验的手艺"升级为"度量拓扑的工程"。此后
Billingsley（1968《Convergence of Probability Measures》）
把这套机器推广到 C[0,1] 与 D[0,1]（跳过程 Skorohod 空间）
——现代数理统计与过程论的标准装备。

## 32.7 要点回顾

1. 胎紧 = 紧集统一吸收全族质量；Ulam 给单测度免费（Polish），
   族要一致付款（一致矩/一致小尾）。
2. Prohorov：胎紧 ⟹ 相对紧（对角线 + 紧控制验收 + π-λ）；
   Polish 下反向。非 Polish 反例（ℚ 上 δ-族）。
3. 应用三步模板：胎紧 + 极限唯一 ⟹ 全列收敛——CLT 的
   标准流水线；C[0,1] 版（模连续性）是过程论的钥匙。
4. 机器侧：mathlib `IsTightMeasureSet`/Prokhorov 文件族；
   数值通道把一致下界与对角线算到底。
