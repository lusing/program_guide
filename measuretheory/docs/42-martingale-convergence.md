## 42.1 问题：Xₙ 有极限吗

鞅的期望恒定，但轨道可以漂移（随机游走）也可以收敛
（Doob-Levy 型）。**判别收剑的核心是上穿不等式**（41.3）：
轨道在区间 [a,b] 来回穿越的次数有界 ⟹ 轨道最终"选定
一侧"——一切有理区间上穿越有限 ⟹ liminf = limsup ⟹
极限存在。

## 42.2 a.s. 收敛定理（Doob）

**定理（下鞅收敛，严书 8.2.1-8.2.5 一带）**：{Xₙ} 下鞅
满足 **supₙ E[Xₙ⁺] < ∞**（正部一致有界）⟹ X_∞ = lim Xₙ
**a.s. 存在**（值域可积性待定——极限可能不可积）。

**证明骨架（上穿论证，三步）**：

1. **上穿期望控制**：E[U_∞[a,b]] ≤ supₙE[(Xₙ−a)⁺]/(b−a)
   < ∞（41.3 + 单调极限）⟹ U_∞[a,b] < ∞ a.s.（非负整数
   值随机变量期望有限 ⟹ a.s. 有限）；
2. **有理区间扫射**：对一切 a < b ∈ ℚ，U_∞[a,b] < ∞
  a.s.（可数交仍 a.s.）——轨道最终不再穿越任何有理区间
   ⟹ liminf = limsup（若 liminf < limsup，取夹在中间的
   有理 a < b 得无穷穿越——矛盾）；
3. **收口**：X_∞ := lim Xₙ 存在（值 ±∞ 可能——推 sup 条
   件升级排除）。∎

**条件的最小性**：sup E[Xₙ⁺] < ∞ 不可弱化为 sup E|Xₙ| <
∞ 之外的形式；随机游走（鞅但 E[Xₙ⁺] = E|Xₙ|/2 ~ √n →
∞）不收敛——**漂移的动力 = 正部期望的膨胀**。

## 42.3 L¹ 收敛与 UI（38 章的收割）

**定理（鞅的 L¹ 完全体，严书 8.2.5-8.2.9）**：{Xₙ} 鞅。
以下等价：

1. {Xₙ} **UI**（一致可积）；
2. Xₙ → X_∞ **于 L¹**（且 a.s.）；
3. 存在可积 X_∞ 使 Xₙ = E[X_∞|𝓕ₙ]（**Doob-Levy 表示**）。

此时收敛是双重的（a.s. + L¹）且极限回填表示：鞅的
"闭合"（closed martingale）。**证明的枢纽**是 38 章
Vitali 定理：a.s. 收敛（42.2）+ UI ⟹ L¹（38.3 的直接
套用——两章在此合龙）；(3)⟹(1) 是条件期望族的 UI
（38.4 应用二）。∎

**非闭合鞅的反例**：E[Xₙ⁺] 有界但非 UI 的下鞅（极限
存在但不可积）；**UI 失败的经典**：乘积鞅 Mₙ = ∏(1+ξᵢ)
（非负鞅 → 0 a.s. 但 E[Mₙ] = 1 恒定——**a.s. 极限与期望
极限的双轨分叉**（lim E ≠ E lim 的活标本，38 章尖峰的
鞅版）。

## 42.4 应用精选

**应用一（Pólya 罐模型）**：红黑球按"抽出放回双倍"规则
的罐中红球比例 Rₙ——非负鞅（E[R_{n+1}|𝓕ₙ] = Rₙ）⟹
Rₙ → R_∞ a.s.；R_∞ 的分布是 **Beta(初红, 初黑)**（UI
验证：有界 [0,1] ⟹ 自动 UI ⟹ L¹ 收敛 + 极限分布的矩
匹配）——贝叶斯统计（共轭先验）的概率论根基。

**应用二（分枝过程灭绝）**：Galton-Watson 过程的规范化
Zₙ/μⁿ（μ = 均值）是鞅 → 极限 W；灭绝概率 = 最小不动点
s = Σpₖsᵏ（生成函数不动点方程——数值通道模拟验证）。

**应用三（随机 Bolzano-Weierstrass / 强大数定律的鞅证）**：
Sₙ/n → 0（iid 零均值）可经鞅方法证明（对换群/下标随机
化技巧）——第 09 章 9.7 预告的兑现点之一；完整 SLLN
在第 51 章袁书线展开。

**应用四（L² 鞅与正交级数）**：平方可积鞅差的正交性
（E[DₘDₙ] = 0, m ≠ n——新息正交）使 ‖Xₙ‖² = Σ‖Dₖ‖²
（勾股定理的随机版）——**鞅 = 函数空间正交化的概率
对应**（Karhunen-Loève 展开的离散影子，第 47 章伏笔）。

## 42.4.5 Pólya 罐的完全账（教学级演算）

Pólya 罐是鞅收敛的"手算完全体"，全账如下：初 r 红 b 黑；
每步抽出一球放回并**追加同色一球**。红球比例 Rₙ 满足：

1. **鞅性**：E[R_{n+1}|𝓕ₙ] = Rₙ·(Rₙ(t+r+1)/(t+r+1)) +
   (1−Rₙ)·(Rₙ(t+r)/(t+r+1)) = Rₙ（t = 当前总数——两条
   转移的加权平均恰好回到原值，两行代数）；
2. **有界性**：Rₙ ∈ [0,1] ⟹ 自动 UI ⟹ L¹ + a.s. 双收敛
   （42.3 完全体直接套用）；
3. **极限分布**：R_∞ ~ Beta(r, b)——矩匹配法（混合矩
   E[Rₙᵏ(1−Rₙ)ˡ] 的递推在 n → ∞ 收敛到 Beta 矩）或
   Doob 的原始论证（条件分布的交换极限）；
4. **奇迹**：初 (1,1) 时 R_∞ ~ Uniform[0,1]——**同一个
   极限分布覆盖一切可能值**（Laplace 问题的鞅解——
   "从完全无知到均匀信念"的动力学）。

数值通道的 200 轨道直方图对拍 Beta 密度是本章主实验
——理论四步每一步都在模拟中可见。

## 42.4.6 乘积鞅的双轨分叉解剖（42.3 反例的机理）

Mₙ = ∏ₖ₌₁ⁿ(1 + ξₖ)，ξₖ iid ±ε（各 ½）。三层账：

1. **鞅性**：E[M_{n+1}|𝓕ₙ] = Mₙ·E[1+ξ] = Mₙ（独立乘数
   的条件期望 1）；
2. **期望轨道**：E[Mₙ] = 1 恒定（乘法期望）；
3. **a.s. 轨道**：log Mₙ = Σlog(1+ξₖ) 是零均值随机游走
   （E log(1+ξ) = ½log(1−ε²) < 0——**几何平均亏于算术
   平均**）⟹ log Mₙ → −∞ a.s. ⟹ Mₙ → 0 a.s.。

**双轨分叉的根源**：E[log] < log E（Jensen 间隙）——
期望被稀有繁荣轨道（M 巨大的小概率事件）撑住，而
典型轨道衰减。UI 失败的显影：{Mₙ > λ} 的概率 → 0 对
固定 λ，但 E[Mₙ1_{Mₙ>λ}] = 1 − F_n(λ) 的极限 > 0——
**尾部质量不肯交枪**。金融解读：杠杆策略的"期望不亏
但几乎必然归零"——鞅论给赌徒谬误的精确解剖。

**历史注记**：Doob 收敛定理（1940）+ L¹ 完全体（Meyer
1960s 的 UI 理论补全）是离散鞅论的双柱。Pólya 罐（1931）
早于鞅论但事后被认出是教科书级鞅——"先有例子后有理论"
的又一例。乘积鞅的双轨分叉在金融数学（杠杆 ETF 的波动
损耗）中有精确的工业对应。

## 42.4.7 习题账单（自检清单）

1. 上穿论证的细节：U_∞ < ∞ a.s. ⟹ liminf = limsup
   的反证构造（有理区间夹逼的选取）；
2. sup E[Xₙ⁺] < ∞ 的最小性：随机游走的 E[Xₙ⁺] ~ √n
   计算（正态半期望公式）；
3. UI ⟺ L¹ ⟺ Doob-Levy 三等价中每个箭头的独立证明；
4. Pólya 罐 Beta 极限的矩匹配法（E[Rᵏ(1−R)ˡ] 的双参
   递推收敛）；
5. G-W 过程：Zₙ/μⁿ 鞅性验证 + 灭绝概率不动点方程的
   母函数推导（g(s) = s 的最小非负解）。

## 42.4.7.5 与第 38 章的合龙点（章际接口复述）

42.3 的三等价把 38 章的 UI 从"技术条件"升格为"鞅论的
中心概念"：UI 的鞅论身份 = **闭合性**（Xₙ = E[X_∞|𝓕ₙ]
的表示存在）。反向读：非 UI 的鞅是"没有终点的公平游戏"
——信息流永不完成。这为第 51 章（SLLN 的鞅证路线）与
第 47 章（L² 理论的正交展开）预装了语义。

## 42.4.8 实验断言清单（数值通道验收单）

1. **Pólya**：200 轨道全部收敛（末段波动 < ε）；极限
   直方图 vs Beta(1,1) 均匀密度（KS 型偏差 < 阈）；
2. **乘积鞅**：轨道 → 0（中位数 ~ (1−ε²)^{n/2} 衰减）；
   200 轨道均值 ≈ 1（双轨分叉）；
3. **G-W**：次临界（μ = 0.8）灭绝频率 ≈ 1；超临界
  （μ = 1.5，p₀ = 0.25）存活频率 ≈ 1 − s（s = 不动点）；
4. **勾股账**：协方差矩阵 DₘDₙ（m ≠ n）的采样值 ~ 0
  （对角 = 方差列）。

## 42.6 数值实验：命运的四种走向

**Julia（`42_martingale_convergence.jl`）**：

- **Pólya 罐**：1000 步的 Rₙ 轨道 × 200 条——每条收敛
  （a.s.）；极限直方图 vs Beta(a, b) 密度（初 (1,1) 的
  Beta(1,1) = 均匀——经典"任意极限都可能出现"的完全体）；
- **乘积鞅**：Mₙ = ∏(1±0.1) 的轨道 → 0（a.s. 快速衰减）
  vs E[Mₙ] = 1（200 条轨道的均值恒 1——双轨分叉显影）；
- **分枝过程**：灭绝概率模拟（μ < 1 的次临界：全部灭绝
  比例 vs 不动点 s；μ > 1：存活比例 vs 1−s）；
- **上穿计数**：随机游走 [−1,1] 上穿总数 vs 上界（41 章
  实验的 n→∞ 版）；
- **L² 勾股账**：鞅差正交性的模拟验证（E[DₘDₙ] ≈ 0 for
  m≠n 的采样协方差矩阵近对角）。

**Python（`42_martingale_convergence.py`）**：Fraction 精确
版——有限二叉树 Pólya 罐的全树账（Rₙ 的分布精确递推 +
极限分布的有限逼近）、乘积鞅的精确期望恒等、G-W 灭绝
方程的精确不动点（二项后代分布 s = fs 迭代）。

## 42.7 要点回顾

1. a.s. 收敛：sup E[Xₙ⁺] < ∞ ⟹ 极限存在（上穿不等式
   → 有理区间扫射 → liminf = limsup 三步）。
2. L¹ 完全体：UI ⟺ L¹ 收敛 ⟺ Doob-Levy 表示（38 章
   Vitali 的合龙）；乘积鞅的非闭合反例（双轨分叉）。
3. 应用四件：Pólya 罐（Beta 极限）、G-W 灭绝（不动点）、
   鞅证 SLLN、L² 正交级数（K-L 展开的影子）。
4. 机器侧：mathlib exists_ae_tendsto_of_bdd + 上穿族；
