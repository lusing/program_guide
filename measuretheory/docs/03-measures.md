# 03 测度与非负集函数

**对应严书 §1.3（pp. 11-15）。**

---

## 3.1 定义：可数可加是唯一的主角

**定义（测度）** 设 𝓕 是 σ-代数。函数 μ : 𝓕 → [0, ∞] 称为测度，若：

1. μ(∅) = 0；
2. **可数可加**：{Aₙ} 两两不交时，μ(⋃Aₙ) = Σ μ(Aₙ)。

三条可测空间 + 测度合称测度空间 (Ω, 𝓕, μ)。取值允许 ∞ 是深思熟虑的：
Lebesgue 测度给 ℝ 本身赋 ∞，硬塞有限值反而毁掉平移不变性。

可数可加性的"可数"二字是全部威力的来源，也是全部技术困难的来源：
它把级数论的全部现象（正项级数可重排、部分和逼近、上下极限）直接
注入集合论。基本推论一览（证明都是"不交化 + 级数性质"的例行公事）：

- **单调性**：A ⊆ B ⟹ μ(A) ≤ μ(B)（严书 1.3.3）。
- **次可加性**：μ(⋃Aₙ) ≤ Σμ(Aₙ)（不必不交，等号可能失效）。
- **下方连续**：Aₙ ↑ A ⟹ μ(Aₙ) ↑ μ(A)。
- **上方连续**：Aₙ ↓ A 且 **μ(A₁) < ∞** ⟹ μ(Aₙ) ↓ μ(A)。
- **Borel-Cantelli 引理的雏形**：Σμ(Aₙ) < ∞ ⟹ μ(lim sup Aₙ) = 0
  （第 35 章正式展开）。

上方连续的有限性条件不是装饰：反例是计数测度下 Aₙ = {n, n+1, …}，
每个测度 ∞，交为 ∅ 测度 0——∞ − ∞ 在测度论里没有定义，这就是
**σ-有限**条件反复出场的第一个预告。

## 3.2 从半环到环：预测度的第一次搬家

严书 1.3 的后半处理一个工程问题：我们通常只能在**半环**上自然地定义
"长度"（区间）、"质量"（矩形）——怎么把它搬进 σ-代数？第一步是搬到
**环**上（1.3.5 引理）：半环 C 上的集函数 μ 若满足有限可加（在 C 内
可表出的不交并上），则延拓到环 R(C)（C 中有限不交并）上仍是良定义的
测度——**良定义**二字是关键：同一集合的两种不交分解必须给出同一个值，
这由半环结构保证（分解的公共加细仍是 C 中不交并）。

第二步（半环 → σ-代数）需要外测度机器，那是第 04 章的主场。

## 3.3 σ-有限：一个值钱的形容词

**定义** μ 是 σ-有限的，若 Ω = ⋃Ωₙ 且 μ(Ωₙ) < ∞。

与之配套的两个弱化概念：μ 是**半有限**的，若每个正测度集都含有正有限
测度子集（排除"0-∞ 测度"式的懒惰）；μ 在 A 上**有限**，若 μ(A) < ∞。
三者的关系：有限 ⟹ σ-有限 ⟹ 半有限，反方向都不成立：计数测度在 ℕ
上 σ-有限但不有限；计数测度其实处处半有限（单点测 1），真正的半有限
反例是 0-∞ 测度（μ(A) ∈ {0, ∞}，非空集无有限正测度子集）。这一族
形容词的精确差价，在 L∞ 的对偶（第 14 章）与 Radon-Nikodym
（第 12 章）里会逐一兑现。

σ-有限测度享有大量"有限测度的美德"：唯一性定理（第 06 章）、Fubini
（第 18 章）、L¹ 对偶是 L∞（第 13 章）都需要它。反例同样珍贵：
计数测度在不可数集上**不** σ-有限；[0,1] 上限制在可数-余可数 σ-代数
的测度 μ(A) = 0 或 ∞（按 A 可数与否）不 σ-有限——它有大量的"病态
表亲"，以后每次定理的 σ-有限假设被用到时，都值得回想这两个反例。

## 3.4 完备性：零测集的"引力范围"

**定义（零测集与完备性）** μ(A) = 0 的可测集 A 称为 **μ-零测集**；
若每个零测集的**每个子集**都可测，称 (Ω, 𝓕, μ) 为**完备测度空间**。

这个定义看似技术性，实则划定了测度的"引力范围"：一个零测集的子集
理应也是零测的（质量为零的整体，部分岂能有质量？），但 σ-代数可能
不够大，装不下这些子集。Borel σ-代数对 Lebesgue 测度就**不完备**
——Cantor 集是 Borel 零测集，它有不可数个子集不在 ℬ(ℝ) 里；而
Lebesgue σ-代数完备。第 04 章的完备化定理（严书 1.4.8）将证明：
任何测度都可以最小代价补齐——这是流水线的最后一道工序。

完备性在应用中的收费方式：几乎处处（a.e.）性质的运算。在不完备空间
里，"a.e. 相等"的函数改一个零测集上的值可能跑出可测函数的范围；
第 09-11 章的极限定理与第 16 章的 Bochner 积分都默认在完备化后的
空间工作，账单都追溯到本节。

## 3.5 有限测度的概率化改造（严书 1.3.5）

严书 1.3.5 引理是一条常被低估的工程引理：**有限测度的问题可以归结
为概率测度的问题**。设 μ 是 (Ω, 𝓕) 上有限测度，μ(Ω) > 0，取 Ω 的
可数划分 {Aₙ} 使 0 < μ(Aₙ) < ∞，定义

  ν(A) = Σₙ 2⁻ⁿ · μ(A ∩ Aₙ) / μ(Aₙ)

则 ν 是概率测度，且 **ν(A) = 0 ⟺ μ(A) = 0**（零测集完全一致），
更有一份"还原公式"

  μ(A) = Σₙ 2ⁿ · ν(A ∩ Aₙ) · μ(Aₙ)。

读法：把每个块 Aₙ 上的 μ 条件化成概率（除以 μ(Aₙ)），再按权重
2⁻ⁿ 加权混合——只要权重和为 1，ν 自动可数可加（非负级数逐项求和）。
还原公式的验证是基变换的例行计算（在 ν(A ∩ Aₘ) 的定义里令 A :=
A ∩ Aₘ，两侧同乘 2ᵐμ(Aₘ) 后对 m 求和）。

用途在第 31-32 章兑现：弱收敛与胎紧性的多数定理先对概率测度证明，
再经此引理平移到有限测度。它也是"σ-有限 ⟹ 局部有限测度的可数
拼接"这一主题的最简样板——第 18 章 Fubini、第 20 章无穷乘积的
证明骨架里都有它的影子。

## 3.6 半环到环：良定义性的公共加细论证

把 3.2 的引理展开。设 μ₀ 是半环 C 上的（有限可加）预测度。环
R(C) = {C 中成员的有限不交并}。定义 μ(A) = Σ μ₀(Iₖ)（任选一个不交
分解 A = ⊎ Iₖ，Iₖ ∈ C）。**要害是良定义**：设另有一个分解
A = ⊎ Jₗ。考虑"公共加细"Kₗₖ = Jₗ ∩ Iₖ ∈ C（半环对交封闭），则

  A = ⊎ₗ ⊎ₖ Kₗₖ = ⊎ₖ ⊎ₗ Kₗₖ

两个重排都是 C 中不交并。对每个 Iₖ：Iₖ = ⊎ₗ (Iₖ ∩ Jₗ) 是 C 内可表出
的不交并，有限可加性给 μ₀(Iₖ) = Σₗ μ₀(Iₖ ∩ Jₗ)；同理 μ₀(Jₗ) =
Σₖ μ₀(Kₗₖ)。于是

  Σₖ μ₀(Iₖ) = Σₖ Σₗ μ₀(Kₗₖ) = Σₗ Σₖ μ₀(Kₗₖ) = Σₗ μ₀(Jₗ)

（非负项级数可自由重排——**非负性在这里第一次付息**）。μ 在 R(C)
上的可数可加性随之而来：R(C) 中可数不交并的每个成员再拆回 C，得到
C 上的二重不交族，预测度的有限可加 + 上穿 σ 的部分和极限完成收敛。
这条"先搬到环"的路线在 Lebesgue-Stieltjes（第 05 章）与乘积测度
（第 18 章）里逐字重演。

顺带把 Borel-Cantelli 雏形证了：lim sup Aₙ = ⋂ₙ ⋃_{k≥n} Aₖ，而
μ(⋃_{k≥n} Aₖ) ≤ Σ_{k≥n} μ(Aₖ) → 0（级数尾项趋于零），故
μ(lim sup Aₙ) = lim_n ↓ μ(⋃_{k≥n} Aₖ) = 0——单调性、次可加性、
上方连续（首项有限：被 Σμ(Aₙ) ≤ 有限控制）三箭齐发。

## 3.7 Lean：基本律逐条对齐

mathlib 的 `MeasureTheory.Measure` 就是本章的测度（[0, ∞] 值、可数
可加），基本律全部现成（`Ch03Measures.lean`）：

```lean
example (μ : Measure ℕ) : μ ∅ = 0 := measure_empty

example (μ : Measure ℕ) (s t : Set ℕ) (h : s ⊆ t) : μ s ≤ μ t :=
  measure_mono h

example (μ : Measure ℕ) (s : ℕ → Set ℕ)
    (hd : Pairwise (fun i j => Disjoint (s i) (s j)))
    (hm : ∀ i, MeasurableSet (s i)) : μ (⋃ i, s i) = ∑' i, μ (s i) :=
  measure_iUnion hd hm
```

`∑'` 是 mathlib 的可数求和记号。注意 `measure_iUnion` 在这个版本里
要求可测性假设——mathlib 另有 `measure_iUnion₀` 系列处理不可测情形，
选错版本会得到出乎意味的失败信息。下方连续的 sup 形式一行拿下：

```lean
example (μ : Measure ℕ) (f : ℕ → Set ℕ) (hmono : Monotone f)
    : μ (⋃ i, f i) = ⨆ i, μ (f i) := hmono.measure_iUnion
```

（单调族的并可数并封闭自动可测化处理，故无需可测性假设——这个细节
在第 04 章外测度语境里有对照意义。）

上方连续的具象版（volume (0, 1/n) ↓ 0）走的是"极限穿过积分号"的
路线：`(0, 1/n)` 的测度 = ofReal(1/n − 0)，由 `Real.tendsto_inv_atTop_zero`
与 ofReal 的连续性复合而成。写它时踩的坑：`(n : ℝ)` 的类型推导
在 Tendsto 目标里把 n 当成了 ℝ（cast 歧义），显式写
`fun (n : ℕ) => …` 才对——**目标类型含糊时，绑定器注解是第一止损点**。

## 3.8 数值实验：一个测度的全身检查

Julia（`03_measures.jl`）与 Python（`03_measures.py`）对原子测度
μ({k}) = 2⁻ᵏ 做了全面体检。Julia 侧（浮点）：

```
μ(Ω) 截断到 60 项 = 1.0，与 1 的差 < 1e-12
单调性 + 次可加性：1000 次随机实验全过
下方连续：μ({1..n}) ↑ μ(Ω) = 1，第 60 项误差 0.0
上方连续：μ({n,n+1,...}) = 2^{-(n-1)} → 0：解析值与数值全部吻合
不交分解：μ(偶) = 0.333333，μ(奇) = 0.666667，和恰为 1
```

其中"上方连续"一栏需要小心口径：数值上只能对**截断**尾部求和
（k 从 n 加到 10n），断言必须对照**同口径的解析值**
2^{-(n-1)} − 2^{-10n}——用未截断的 2^{-(n-1)} 对照会差出一个
2^{-10n}（n=1 时是 1e-3 量级），这是数值测度论的第一个纪律：
**断言的两边必须同口径截断**。

Python 侧用 `Fraction` 精确有理数把同一实验跑成了**零舍入误差**版本，
包括精确的截断恒等式：

```python
even = sum(mu_atom(k) for k in range(2, 61, 2))
assert even == Fraction(1, 3) - Fraction(1, 3 * 2 ** 60)  # 精确截断值
```

这里藏着一个"心算过关再断言"的教训：偶数和的截断修正项是
−1/(3·2⁶⁰)，奇数和的是 −1/(3·2⁵⁹)（分母差一个 2！），初稿把奇数
修正项的符号与分母都写错，Fraction 立刻翻脸。**精确算术的断言没有
容错空间，每一个修正项都要推出来**——这正是对拍通道的价值：Julia
的浮点版本只验到 1e-6，Python 的分数版本逼着把修正项算到个位数位。

Prolog 通道（`03_measures.pl`）自制了有理数 q(N, D)（gcd 约简），
把总质量、有限可加、次可加、尾部公式全部验成整数等式：

```prolog
check_tail :-
    forall(member(N, [1, 3, 8]),
           ( numlist(N, 20, L), mu_set(L, q(A, B)),
             E is 2 ** (N - 1), F is 2 ** 20,
             A * F =:= (F // E) * B - B,   % A/B = 1/E - 1/2^20
             ... ))
```

交叉等式 `A·2²⁰ = 2²⁰/E·B − B` 避开了除法舍入——整数算术里，
**把分数等式交叉相乘**是标准姿势。

## 3.9 全书造测度的三条流水线（预告）

到目前为止，获得测度的途径只有"定义后直接验证"一条。接下来的三章将
装配三条流水线，全书的大多数测度都产自于此：

1. **外测度流水线**（第 04 章）：预测度 → 覆盖下确界 → Carathéodory
   限制。产品：Lebesgue 测度、LS 测度、Hausdorff 测度。
2. **密度流水线**（第 12 章）：已有测度 μ + 非负可测 f ⟹ f·μ
   （可测集 A ↦ ∫_A f dμ）。产品：绝对连续概率分布。
3. **像测度与乘积流水线**（第 07、18 章）：可测映射的 pushforward、
   二元测度的乘积。产品：随机向量、随机过程的有限维分布。

三条流水线的"质检工序"全部是本章的基本律：可数可加一旦破坏，后续
的一切定理（极限定理、分解定理、收敛定理）都将失去地基。

## 3.10 要点回顾

1. 测度 = 空集为零 + 可数可加（值域 [0,∞]）；一切基本律皆其推论。
2. 上方连续需要有限首项；σ-有限是全书反复出场的健康证；完备性划定
   零测集的引力范围（Borel 不完备，Lebesgue 完备）。
3. 有限测度可概率化（1.3.5），零测集不变、质量可还原——第 31-32
   章"先证概率情形再平移"的机构。
4. 半环上的有限可加集函数可唯一搬到环上；再往上走需要外测度（下章）。
5. 数值纪律三条：同口径截断、精确算术无容错、分数等式交叉相乘。
