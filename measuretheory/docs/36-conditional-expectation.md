## 36.1 问题：知道了一部分信息后的最佳估计

已知今天上午的股价，下午价格的期望是多少？"**条件**期望"
= 把无条件期望按信息层重算。数学设置：概率空间 (Ω,𝓕,P)、
**子 σ-代数** 𝓖 ⊆ 𝓕（"已知信息"——𝓖 越大信息越多）、
可积随机变量 X。求 𝓖-可测的 Y 使 Y 在 𝓖 的每个"原子"
上与 X 同平均。

**定义（严书 7.2 定义 = RN 路线，第 12 章的收割）**：X ≥ 0
时定义 Q(A) = ∫_A X dP（A ∈ 𝓖）——𝓖 上绝对连续（≪ P|𝓖）
的测度；RN 导数给出 𝓖-可测的 Y = dQ/d(P|𝓖)；一般 X 分
正负部。刻画：

  Y = E[X|𝓖] ⟺ Y 𝓖-可测 且 ∫_A Y dP = ∫_A X dP（∀A ∈ 𝓖）。

唯一性 a.s.（RN 唯一性）。**投影读法**：E[X|𝓖] = X 在
L²(𝓖) 子空间上的**正交投影**（有限方差时）——"最佳均方
估计"的几何身份；条件期望是 Hilbert 空间理论在概率中的
第一件大工具。

## 36.2 基本性质清单（严书 7.2.1 / 袁 15.1.3）

1. **线性与正性**：E[aX+bY|𝓖] = aE[X|𝓖]+bE[Y|𝓖]；X ≥ 0
   ⟹ E[X|𝓖] ≥ 0（积分刻化的直接推论）；
2. **塔性质（tower）**：𝓗 ⊆ 𝓖 ⟹ E[E[X|𝓖]|𝓗] = E[X|𝓗]
  ——小信息层上的估计可以经大信息层中转（投影的幂等
   复合：P_𝓗 P_𝓖 = P_𝓗——几何语言的直接翻译）；
3. **取出性质**：Z 𝓖-可测且有界 ⟹ E[ZX|𝓖] = Z·E[X|𝓖]
  ——已知信息可以自由出入条件号（"已知量当常数"）；
4. **期望的收回**：E[E[X|𝓖]] = E[X]（A = Ω 的特例）；
5. **独立性退化为无条件**：X 与 𝓖 独立 ⟹ E[X|𝓖] = E[X]
  （信息无增益）；𝓖 = σ(Z) 且 X 与 Z 独立同此；
6. **Jensen 不等式**：φ 凸、φ(X) 可积 ⟹ φ(E[X|𝓖]) ≤
   E[φ(X)|𝓖]（证明与无条件版同骨架——条件版的 Fatou/
   单调收敛三件套支撑，见 36.3）；
7. **单调收敛/控制收敛的条件版**：Xₙ ↑ X ⟹ E[Xₙ|𝓖] ↑
   E[X|𝓖]（a.s.）；|Xₙ| ≤ Y 可积 ⟹ E[Xₙ|𝓖] → E[X|𝓖]
  ——**一切积分极限定理都有条件版**（袁 15.2.1 的系统
   陈述）。

**性质的证明文化**：一切"等式"类性质经积分刻画（对 A ∈ 𝓖
验证两侧积分相等——π-λ 或单调类收口）；一切"不等式"类
（Jensen）经凸函数的支撑线族 + 条件单调收敛。**条件期望的
证明纪律：永远在积分层面工作，绝不在逐点层面纠缠**（a.s.
等价的模糊性由积分层自动吸收）。

## 36.3 条件版三大定理与凸性（袁 15.2）

**条件单调收敛**：Xₙ ≥ 0、Xₙ ↑ X ⟹ E[Xₙ|𝓖] ↑ E[X|𝓖]。
证明骨架：右侧单调（条件期望保序）⟹ 极限 Y 存在（𝓖-可测）；
对 A ∈ 𝓖，∫_A Y = lim∫_A E[Xₙ|𝓖] = lim∫_A Xₙ = ∫_A X
（无条件 MCT 搬运）⟹ Y 满足刻画。∎

**条件 Fatou 与控制收敛**：同法平移（Fatou 的 liminf 不等
式在积分层经逐项 Fatou；DCT 的控制函数照常工作）。

**条件 Jensen**：φ 凸 ⟹ φ 有可数支撑线族（φ(x) = supₖ
(aₖx+bₖ)）⟹ aₖE[X|𝓖]+bₖ ≤ E[φ(X)|𝓖]（线性 + 单调）⟹
sup 落在 𝓖-可测的左侧 ⟹ Jensen 收口。∎

**凸性应用三连**：|E[X|𝓖]|^p ≤ E[|X|^p|𝓖]（φ = |·|^p）；
E[|E[X|𝓖]|^p] ≤ E[|X|^p]（再取期望——Lᵖ 有界性传递，
投影的范数压缩）；**条件矩的链式账**：E[φ(X)] =
E[E[φ(X)|𝓖]]（全期望公式的凸版——后文鞅与 UI 的日常）。

## 36.4 初等条件期望与离散模型（袁 15.4）

**有限划分模型**：𝓖 = σ(A₁,…,A_m)（划分），则

  E[X|𝓖] = Σᵢ E[X|Aᵢ]·1_{Aᵢ}，其中 E[X|Aᵢ] =
  ∫_{Aᵢ} X dP / P(Aᵢ)（P(Aᵢ) > 0 时；零测原子约定 0）。

一切性质的离散验证场（数值通道的主战场）：塔性质 = 分组
平均的再平均；取出性质 = 加权平均中已知权重；Jensen =
逐原子套无条件 Jensen。

**初等概率的条件概率 vs 测度论的条件期望**：P(A|B) =
P(A∩B)/P(B) 是"固定证据 B"的数字；测度论版 E[1_A|𝓖]
是"证据族 {B} 上逐块报数"的函数——**初等版是 𝓖 =
{∅,B,Bᶜ,Ω} 的特例**。袁书 15.4 的历史顺序（先初等后
一般）与严书（直接 RN 定义）互为镜像；本教程从一般到
特例（测度论优先），特例做直觉锚。

**条件概率的陷阱预告**：P(·|𝓖) 作为**函数族** A ↦
E[1_A|𝓖] 每个版本 a.s. 定义，但"逐 A 选版本"的选择无法
拼成一个真正的核（可数个例外集合并掉之后仍有不可数个
A）——**正则条件概率**（第 37 章）就是补丁：一次性选好
全部版本使 (ω,A) ↦ P(A|𝓖)(ω) 成为真核。

## 36.4.5 三个经典条件的显式库（初等锚点集）

条件期望的"可以手算"清单（数值与直觉的锚点）：

1. **独立退化**：X ⊥ 𝓖 ⟹ E[X|𝓖] = E[X]（常值）——
   无信息则报均值；
2. **已知退化**：X 𝓖-可测 ⟹ E[X|𝓖] = X（自身）——满
   信息则原样返回；两退化的夹层：E[X|σ(X)] = X；
3. **二元离散**：(X,Y) 取值 {(i,j)} 联合概率 p_ij：
   E[Y|X=i] = Σⱼ j·p_ij/Σⱼ p_ij——加权平均（列归一化）；
4. **密度连续版**：f(x,y) 联合密度：E[g(Y)|X=x] =
   ∫g(y)f(x,y)dy / ∫f(x,y')dy'——权重归一化的积分版；
5. **二元正态**：E[Y|X=x] = μ_y + ρ(σ_y/σ_x)(x−μ_x)——
   **线性回归方程的原型**（条件期望 = 最小二乘直线，
   正态时两概念重合；一般分布时回归曲线 E[Y|X=x] 是
   非线性最优预测）。

第 5 条是统计学的"高斯世界舒适区"根源：正态性把条件
期望（无穷维对象）压缩成两个参数（斜率与截距）——第
47 章高斯论的预缴学费。

## 36.4.6 条件期望作为平均算子的谱（几何深化）

分块平均 E[·|𝓖] 是 L² 上的**正交投影 P**，其算子性质
谱系：‖P‖ = 1（范数压缩——Jensen 的 L² 版）；P 自伴
（⟨PX, Y⟩ = ⟨X, PY⟩ 对 𝓖-可测 Y——取出性质的内积形）；
P 幂等（塔性质）；P 的不动点集 = L²(𝓖)（已知退化）；
P 的核 = L²(𝓖)⊥（与一切 𝓖-可测函数正交的"纯新息"）。
**新息分解**：X = E[X|𝓖] + (X − E[X|𝓖])——信号 + 噪声
的正交分解（Hilbert 空间的直接和），第 41 章鞅论的
几何底座（鞅差列 = 逐层新息的堆叠）。

4. 条件 Jensen 的支撑线证明细节（凸函数的可数支撑线
   族从哪里来——可分性的又一次缴费）；

  （否——L¹ 无内积，最佳逼近可能不唯一；L² 才有唯一
   投影——范数选择决定几何）。

## 36.7 数值实验：分块平均的全家福

**Julia（`36_conditional_expectation.jl`）**：

- **有限划分**：Ω = {1..12}、𝓖 = {{1..4},{5..8},{9..12}}
  三块划分，X 随机数——E[X|𝓖] 逐块平均计算 + 三大性质
  数值验证（塔：两层划分 E[E[X|𝓖₁]|𝓖₀] = E[X|𝓖₀] 到
  机器精度；取出：E[Z·X|𝓖] = Z·E[X|𝓖] 对块常数 Z）；
- **Jensen**：φ = x²、|x|、exp 的三组（E[φ(X)|𝓖] 与
  φ(E[X|𝓖]) 的分块差恒 ≥ 0）；
- **投影几何**：L² 中 X 到分块常数空间的投影——Gram
  矩阵求解 vs 条件期望直接计算（两条路同一答案）；残差
  与 𝓖-可测函数正交（内积 = 0 的数值验证）；
- **条件版 MCT**：Xₙ = min(X, n) 的截断列的条件期望
  单调上升账。

**Python（`36_conditional_expectation.py`）**：Fraction 精确
版——分块平均的精确分数、塔/取出/Jensen 的精确核对
（不等式方向的精确判定）、两层划分的分组再分组账。
