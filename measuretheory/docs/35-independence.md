## 35.1 从乘法开始的对称性

测度论给了乘积测度（第 18/20 章），概率论问反过来：**什么时候
联合分布就是边缘的乘积？**独立性把这个直觉公理化：

- **事件独立**：P(A∩B) = P(A)P(B)——联合账 = 边缘账的乘法；
- **事件类独立**：σ-代数族 {𝓕ᵢ} 独立 ⟺ 一切"每族取一个事件"
  的有限交都满足乘法账；
- **随机变量独立**：σ(Xᵢ) 族独立 ⟺ 联合分布 = 边缘乘积
 （Fubini 通道：∫f(X₁,…,Xₙ)dP = ∫…∫f(x₁,…,xₙ)∏dPᵢ——第
   18 章乘积测度的概率原文）。

**定义的分寸**（严书 7.1.1-7.1.2）：独立性必须对**一切有限子族**
验证——两两独立（仅对二元组）严格弱于族独立。经典反例：两次
掷骰的 (A = 第一颗偶, B = 第二颗偶, C = 总和偶) 两两独立但
三者不独立（P(ABC) = 1/8 ≠ 1/4·1/4·…账目显影见 35.6 数值
通道）。另一个方向：独立族的**子族**自动独立、独立族经可测
映射（fᵢ 作用于 Xᵢ）保持、**两族独立则各自生成的 σ-代数
独立**（π-λ 提升的关键一步）。

## 35.2 独立性的判据族

**生成系判据**：若 {𝓒ᵢ} 是各 𝓕ᵢ 的 π-系生成族且 𝓒ᵢ 间独立
（一切有限交乘法账），则 σ(𝓒ᵢ) 独立——π-λ 定理的又一次
收割（第 06/08 章机器的概率应用）。

**分布判据**：(X,Y) 独立 ⟺ 联合 cdf F(x,y) = F_X(x)F_Y(y)
（矩形上乘法 → π-系 → 全局）；密度情形 f(x,y) = f_X(x)f_Y(y)
（a.e.）；特征函数 φ(t,s) = φ_X(t)φ_Y(s)（第 49 章主力判据）。

**矩判据**：X, Y 独立 ⟹ E[XY] = E[X]E[Y]（可积时）；**反向
不成立**（不相关 ≠ 独立——反例 (X, Y=X²) 型，见 35.6）；但
**联合正态时**不相关 ⟹ 独立（第 47 章完全体）。

**Borel-Cantelli 引理（两版，严书 7.1.3-7.1.4 / 袁 13.3.1）**：

1. **第一版（无独立性）**：ΣP(Aₙ) < ∞ ⟹ P(Aₙ i.o.) = 0
  ——Markov 不等式的级数版：P(Aₙ i.o.) = P(Σ1_{Aₙ} = ∞) ≤
   E[Σ1_{Aₙ}] 的级数收敛控制；
2. **第二版（需独立）**：{Aₙ} 独立且 ΣP(Aₙ) = ∞ ⟹
   P(Aₙ i.o.) = 1——乘法账的爆发：∏(1−P(Aₙ)) = 0 ⟹
   lim P(∪_{n≥k}Aₙ) = 1。

两版合读：**独立时 ΣP(Aₙ) 的收敛性完全决定 i.o. 的概率**——
0-1 现象。数值通道的双实验（收敛级数 vs 发散级数）是 35.6
的主菜。

## 35.3 尾部 σ-代数与 0-1 律

**尾部 σ-代数**：𝓣 = ∩ₙ σ(Xₖ : k ≥ n)——"无穷远处的事件"
（频率极限、级数收敛性、limsup 都是尾部事件）。

**Kolmogorov 0-1 律（严书 7.1.6 / 袁 13.3.3）**：{Xₙ} 独立
⟹ 𝓣 中事件概率 ∈ {0,1}。

证明（独立性提升 + 逼近）：尾部事件 A ∈ 𝓣 与一切有限窗
σ(X₁,…,Xₙ) 独立（A ∈ σ(Xₖ: k > n) 且两族独立）；令
𝓖 = ∪ₙσ(X₁,…,Xₙ)（π-系），A 与 𝓖 独立 ⟹ A 与 σ(𝓖) =
σ(X₁,X₂,…) 独立——而 A 自己在这个 σ-代数里！P(A) =
P(A∩A) = P(A)² ⟹ P(A) ∈ {0,1}。∎——**"与自己独立"的
自反性爆破**是全部 0-1 律的机制原型。

**Borel 0-1 律（袁 13.3.2）**：独立 {Aₙ} 的 limsup 事件
（i.o.）概率由 ΣP(Aₙ) 完全二值化（35.2 的重述）。

**Hewitt-Savage 0-1 律（袁 13.3.4，严书略）**：{Xₙ} iid ⟹
**交换不变**事件（对有限置换不变的集合）概率 ∈ {0,1}。证明
用有限交换群逼近 + 独立性传递。应用：随机游走常返/瞬移的
判定（事件"无穷多次回原点"是交换不变的）——0-1 律把定性
问题二值化，剩下的计算交给具体轨道分析（第 51 章 SLLN 的
邻居工具）。

## 35.4 独立随机变量的构造与卷积

**构造（第 20 章收割）**：给定边缘分布 {Pᵢ}，乘积测度
∏Pᵢ 使坐标独立——**独立性的存在性由无穷乘积测度背书**
（"任何一族分布都可以找到使它们独立的联合模型"）。

**卷积（袁 13.4）**：独立 X, Y 的和的分布

  P_{X+Y} = P_X * P_Y，(μ*ν)(A) = ∫μ(A−y)dν(y)
  = ∫ν(A−x)dμ(x)（Fubini 的对称双通道）。

卷积的性质清单：交换/结合（独立性重组）、单位元 δ₀、
μ₁*…*μₙ = n 步卷积（Chapman-Kolmogorov 的分布版——第
19 章核机器的 iid 特例）、**支撑相加**（supp(μ*ν) =
supp μ + supp ν 的闭包）。分析中的化身：L¹ 函数卷积
（Young 不等式，第 18.4.5）、分布函数卷积（袁 13.4.2：
F_{X+Y}(z) = ∫F_X(z−y)dF_Y(y)——R-S 积分的概率应用）、
特征函数乘法（第 49 章 φ_{X+Y} = φ_X·φ_Y——独立性经
傅里叶侧变成逐点乘法，卷积方程的解耦器）。

## 35.4.5 卷积的分析侧账（跨章总表）

卷积把独立性送到三个数学世界，账户汇总：

| 世界 | 对象 | 独立性的化身 | 章 |
|---|---|---|---|
| 测度 | μ*ν | Fubini 对称双通道 | 18, 19 |
| 分析 | f*g（L¹ 函数） | Young 不等式 ‖f*g‖ᵣ ≤ ‖f‖ₚ‖g‖_q | 13 |
| 调和 | φ_X·φ_Y | 特征函数逐点乘法 | 49 |
| 代数 | 母函数 M_X·M_Y | 矩母函数乘法 | 49 |
| 算法 | 随机化归约 | 独立采样可并行 | 51 |

**独立性 = 乘法结构在一切变换下的保持**——从测度的乘积
（乘法账）到调和的逐点乘（解耦），一个概念的五次显影。
教学读法：当"和的分布"难以直接算时，卷积方程 X+Y 的
求解路线是：边缘 → 特征函数乘法 → 反演（第 49 章的
标准流水线，本章先立方程）。

## 35.4.6 习题账单（自检清单）

1. 双骰模型：写出 (A,B,C) 的全部 8 个交事件的概率账，
   验证两两独立但 P(ABC) = 1/8 ≠ 1/2·1/2·1/2 的爆雷；
2. 证明：独立族的子族独立；独立族经可测映射保持；
   σ(X) 与 σ(Y) 独立 ⟺ 一切 {X∈B}{Y∈C} 乘法账；
3. 构造三个事件使 P(ABC) = P(A)P(B)P(C) 但两两不独立
  （"三元账对但二元账错"的反向反例）；
4. Borel-Cantelli 第二版证明：∏(1−P(Aₙ)) = 0 ⟹
   lim_{k} P(∪_{n≥k}Aₙ) = 1 的级数-乘积对偶细节；
5. Hewitt-Savage 的应用：随机游走 Sₙ（iid 步长）的
   {lim Sₙ = +∞}、{Sₙ 回原点无穷多次} 都是交换不
   变事件——概率二值化后由强大数定律判别其取值。

## 35.5.5 实验断言清单（数值通道验收单）

1. **双骰**：P(A)=P(B)=P(C)=1/2、P(AB)=P(AC)=P(BC)=1/4
   （两两 ✓）、P(ABC)=1/8 ≠ 1/8？——精确验证 P(ABC) 的
   真值（总和偶与前两个偶的交：第一二颗决定后第三颗被
   完全决定，P = 1/4·1 = 1/4？数值 36 格全枚举给真账，
   与 1/2³ = 1/8 对照爆雷倍数）；
2. **BC 一**：Σ1/n² 收敛——i.o. 频率（200 轨道 × 10⁶
   步）→ 0（Borel 数 ~ π²/6 的尾端行为）；
3. **BC 二**：Σ1/n 发散——i.o. 频率 → 1；发生次数 ~
   log n 拟合（乘积爆炸的对数侧写）；
4. **卷积**：U*U = 三角分布的分箱直方图 vs 解析密度
   （KL 型误差 < 阈）；
5. **尾部事件**：iid Bernoulli 频率极限事件的 0-1 显影
  （200 轨道全部落入 1 侧的 ε-带）。

## 35.6 数值实验：乘法账与 0-1 现象

**Julia（`35_independence.jl`）**：

- **两两 ≠ 族独立**：双骰子模型 (A,B,C) 的 8 个交事件账
  全枚举——两两乘法 ✓（4 对各验证）但 ABC 账 1/8 ≠ 1/4
  （总和偶的联合账爆雷现场）；
- **Borel-Cantelli 第一版**：P(Aₙ) = 1/n² 的级数收敛——
  i.o. 频率（10⁶ 步轨道 × 200 条）平均 → 0；
- **第二版**：P(Aₙ) = 1/n 的发散——i.o. 频率 → 1（无数
  次发生的现场：轨道上 Aₙ 发生的次数 ~ log n 增长）；
- **卷积**：两个 Uniform[0,1] 的和 = 三角分布（直方图
  对拍 + 密度 f(z) = z ∧ (2−z) 的解析核对）；Bernoulli
  卷积 n 次的二项收敛；
- **0-1 律**：iid 序列的频率极限事件 {|lim Sₙ/n − 1/2|
  < 0.01} 在 200 条轨道上频率 → 1（事件的"1 侧"显影——
  理论由第 51 章 SLLN 背书，本章只见其 0-1 性）。

**Python（`35_independence.py`）**：Fraction 精确版——双骰
模型的 36 格联合分布表（两两/三元账全精确）、卷积的精确
分数账（离散分布的卷积表逐格）、i.o. 事件的级数判据精确
化（Σ1/n² = π²/6 vs Σ1/n 发散的对照）。

**Prolog（`35_independence.pl`）**：有限模型的独立性检查
器——`indep_events/2`（乘法账逐对）、`pairwise_not_mutual/0`
（两两独立但三元爆雷的见证）、卷积表谓词 `conv/3`。

## 35.7 要点回顾

1. 独立性三级定义（事件/类/变量）；两两 ≠ 族独立（双骰
   反例）；π-λ 提升与可测映射保持。
2. Borel-Cantelli 两版：收敛 ⟹ i.o. 概率 0；独立 + 发散
   ⟹ i.o. 概率 1——ΣP(Aₙ) 完全二值化。
3. 0-1 律：尾部 σ-代数（Kolmogorov："与自己独立"的自反
   爆破）、交换事件（Hewitt-Savage）——概率 ∈ {0,1}。
4. 卷积 = 独立和的分布机器：Fubini 对称双通道、特征函数
   逐点乘法（49 章接口）、Young 不等式（18 章接口）。
5. 机器侧：mathlib Indep 族 + ZeroOne；数值通道双骰/BC/
   卷积/三角分布四大现场。
