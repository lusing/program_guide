# 16 Bochner 积分：向量值的积分

**对应严书 §3.7（pp. 80-82）。**

---

## 16.1 为什么实值积分不够用

随机过程（样本轨道是函数）、发展方程（解在无穷维空间游走）、
条件期望（本身是随机变量）——这些对象的"积分"值在 Banach 空间
E 里，不在 ℝ 里。把 f(ω) ∈ E 逐分量积分是最朴素的念头，但
分量依赖基的选取，且无穷维没有现成的基。Bochner 积分（1933）
的回答干脆利落：**照抄 Lebesgue 三步构造，把"非负"换成"范数"**。
Pettis 积分（1938）走弱路线：先用泛函检验再找回向量。本章给出
两台机器及其分工。

## 16.2 强可测与 Pettis 可测（严书 3.7.1-3.7.3）

**强可测** X : Ω → E（E 为 Banach）：存在**简单可测函数列**
Xₙ = Σᵢ αᵢI_{Aᵢ}（Aᵢ ∈ 𝓕）使 Xₙ(ω) **强收敛**（按范数）到
X(ω)。关键结构定理（3.7.3）：

1. 逼近可取"加倍控制"：‖Xₙ(ω)‖ ≤ 2‖X(ω)‖（先截断 ‖X‖ 再
   网格化）；
2. 强可测 ⟹ Borel 可测（强极限的 Borel 传递）；
3. 强可测全体是向量空间，对范数极限封闭。

**Pettis 可测**：ω ↦ f(X(ω)) 对一切 f ∈ E* 可测（弱可测）。
两者由 **Pettis 可测定理**打通：E 可分时，弱可测 + 范数可测
（ω ↦ ‖X(ω)‖ 可测）⟹ 强可测。证明的引擎是对角线引理（3.7.2）：
可分 E 的对偶单位球上，逐点收敛可以由**序列**穷尽——E* 的
"紧性"在逐点拓扑下由可数网实现（这是泛函分析里 Alaoglu 定理
的可数版影子）。**可分性是收费点**：不可分空间的弱可测可以
永久弱于强可测（取恒等映射到 ℓ² 的不可测替身）。

## 16.3 Bochner 积分的构造（严书 3.7.4）

三步照抄：

1. **简单函数**：X = ΣαᵢI_{Aᵢ}、‖X‖ 可积（⟺ 各 μ(Aᵢ) < ∞），
   定义 ∫X dμ = Σᵢ μ(Aᵢ)·αᵢ ∈ E（表示无关性由标准分解）；
2. **一般强可测**：取加倍控制的逼近列 Xₙ；‖X‖ μ-可积时，
   ‖Xₙ − Xₘ‖ ≤ 4‖X‖ 可积，且 ‖Xₙ − Xₘ‖ → 0 逐点 ⟹
   **实值 DCT** 给 ∫‖Xₙ − Xₘ‖dμ → 0 ⟹ {∫Xₙ} 是 E 中
   基本列 ⟹ 强收敛（E 完备！）到 ∫X dμ；
3. **良定义与泛函穿透**：换逼近列不影响极限；对一切 f ∈ E*：

   f(∫X dμ) = ∫ f(X) dμ ——**用泛函检验积分**的唯一性来源
   （E* 分离 E 的点）。

**可积判据**：X Bochner 可积 ⟺ X 强可测且 ‖X‖ μ-可积——
一切信息在实值函数 ‖X‖ 里（习题 3.7.1 的刻画）。**Bochner-DCT**
（习题 3.7.2）：Xₙ → X 强 a.e.、‖Xₙ‖ ≤ g 可积 ⟹ ∫Xₙ → ∫X
（提示 ‖Xₙ − X‖ ≤ 2g，实值 DCT 穿透）——实值机器全程代工。

## 16.4 Pettis 积分与反例档案

**Pettis 积分**：弱可测的 X 若存在 α_A ∈ E 使 f(α_A) =
∫_A f(X)dμ 对一切 f ∈ E*、A ∈ 𝓕，则称 X Pettis 可积，
α_A = ∫_A Xdμ（Pettis 不定积分）。包含关系：**Bochner ⟹
Pettis**（泛函穿透），且两种积分一致。反向不成立，且向量值
世界还有一个更深的陷阱：

**反例（习题 3.7.3，向量值 Radon-Nikodym 失效）**：取
μ = [0,1] 上 Lebesgue，E = L¹[0,1]，V(A) = I_A（指示函数作为
E 的元素）。V 是 ≪ μ 的 **E 值可数可加测度**（‖V‖(A) = μ(A)
有限），但**不存在 Bochner 可积的 X 使 V(A) = ∫_A Xdμ**。
理由（骨架）：若存在，则对单点 a，"V({a}) = 0 = ∫_{a} X"迫使
X(ω)(ω) = 0 a.e.；而对分划的一致可加性迫使 X(ω) = I_ω 型的
"对角线函数"——它作为 L¹ 值函数不可测（对角线 |X(ω)‖ ≡ 1 但
泛函 ω ↦ X(ω)(t) 在固定 t 处要求可测性，与 Fubini 冲突）。
**这就是第 37 章正则条件分布必须引入额外结构的原因**：向量值
RN 定理需要**值空间有 Radon-Nikodym 性质**（有界变差向量测度
都有密度 ⟺ E 是 ASP 空间；L¹ 没有）。

= `tendsto_integral_of_dominated_convergence`（第 11 章的实弹

以 `#check` 正名，实弹：向量值常值函数的积分（dirac 上逐分量

## 16.7 数值实验：向量值三步曲

**Julia（`16_bochner_integral.jl`）**在 ℝ² 值函数上复刻：

- **分量独立 ≠ 凑合**：f(x) = (x, x²) 在 [0,1] 上的 Bochner
  积分按分量 = (1/2, 1/3)——中点法数值验证到 1e-5；
- **简单函数逼近**：f(x) = (sin x, cos x) 的 8 段阶梯逼近
  Xₙ（加倍控制版），‖Xₙ − f‖∞ ≤ 网格宽，积分误差随之收缩；
- **Bochner-DCT 数值**：Xₙ(x) = (xⁿ, 0)，‖Xₙ‖ ≤ (1,1) 可积，
  逐点 → (0,0)，积分列 → (0,0)——向量版控制收敛；
- **范数判据**：X Bochner 可积 ⟺ ‖X‖ 可积——数值对拍
  ∫‖f‖dμ 与 ‖∫f dμ‖（后者 ≤ 前者，三角不等式的积分版）。

**Python（`16_bochner_integral.py`）**：精确分数版——(1/2, 1/3)
的闭式核对、阶梯逼近误差的显式界、DCT 序列 (1/(n+1), 0) → (0,0)
的精确账。

## 16.7.5 反例深挖：对角线论证的完整骨架

习题 3.7.3 的 V(A) = I_A（E = L¹[0,1] 值测度）为何无 Bochner
密度——把骨架拆到可手查的六步：

1. **V 是向量值测度**：不交并的可数可加性来自 I_{⊔Aₙ} =
   ΣI_{Aₙ} 在 L¹ 中收敛（‖差‖₁ ≤ Σ 后段 μ(Aₙ) → 0）；
   ‖V‖(A) = μ(A)（指示函数的 L¹ 范数恰为测度）⟹ V ≪ μ 且
   全变差有限——**一切表面条件全达标**；
2. **假设有密度 X**：V(A) = ∫_A Xdμ，X : [0,1] → L¹[0,1]
   Bochner 可积；
3. **对角线矛盾的上半场**：对 a.e. 固定的 ω，考虑泛函
   φ_ω(g) = g(ω)？——g ↦ g(ω) 不是 L¹ 上的有界泛函！改用
   **Fubini 穿透**：∫₀¹ X(ω)(t)dt = μ-积分的范数侧信息，
   推出 ‖X(ω)‖₁ 的可积性（‖X‖ 可积 ✓ 本来就有）；
4. **对角线矛盾的下半场**：V(A) = ∫_A Xdμ 两边对 A 微分
   （RN 的向量版直觉）：X(ω) 应当"是" I_ω——但对 ω ↦ I_ω
   逐范数不可分（‖I_s − I_t‖₁ = 2 对 s ≠ t，不可数 2-分离
   集 ⟹ 值域不可分 ⟹ X 非强可测，违反第 16.2 的可分性要求）；
5. **可分性卡死**：强可测函数的值域本质可分（简单函数逼近
   的值落在可数生成的闭包里），而 {I_ω} 的像不可分——**密度
   在入口处就被强可测性拒绝**；
6. **结论的抽象化**：向量值 RN 定理需要值空间 E 使一切
   ≪ μ 且有界变差的向量测度都有 Bochner 密度——这样的 E
   称 **Radon-Nikodym 空间**（= ASP/有界变差凸闭包性质）。
   L¹ 不行，自反空间（L^p, 1<p<∞）、Hilbert 都行——第 37 章
   条件分布核的存在性正是靠 Polish/标准 Borel 的可分性 +
   这些空间性质凑齐的。

**教学注记**：这个反例是"逐点直觉在无穷维集体失效"的典型——
每个 ω 处 I_ω 都无害，但 ω ↦ I_ω 作为整体不可测。数值通道
无法复刻它（需要不可数分离族），但第 16.7 的分量实验正是
"逐点无害"的那一半——反例的另一半（整体失效）由 docs 讲清。

## 16.7.6 Pettis 积分的深析与分工表

Pettis 积分的**弱定义**（每个 f ∈ E* 侧积分后还原出向量）看似
更弱，实则是另一种工作哲学：**不要求值域可分，代价是积分的
存在性成了真条件**（Bochner 的存在性由 ‖X‖ 可积自动给出，
Pettis 需要逐一验证泛函积分的相容性）。三档强度排布：

| | 强可测要求 | 可积判据 | 积分性质 |
|---|---|---|---|
| Bochner | 强可测（可分值） | ‖X‖ ∈ L¹（充分必要） | 范数连续、DCT 齐备 |
| Pettis | 弱可测 + 范数可测 | 泛函相容性（条件性强） | 弱连续、唯一性靠 E* 分离 |
| Dunford | 仅弱可测 | f(X) ∈ L¹ ∀f | 积分落在 E**（可能出格） |

Dunford 积分（第三档）是"彻底躺平"的版本：只保证泛函侧
可积，还 原 出 的 元素在**二次对偶** E** 里——它回到 E 当且仅当
X 是 Pettis 可积。**三档的差就是可分性的三次讨价还价**：
Bochner 用值域可分买下全部强拓扑；Pettis 用相容性条件换得
值域自由；Dunford 干脆搬进更大的旅馆。

**应用侧的分工**：随机过程理论（第 47 章高斯测度）用 Bochner
（可分 Banach 上的样条/柱面逼近都保强可测）；条件期望的
向量值推广（第 37 章）优先 Pettis（子 σ-代数上的投影天然
弱定义）；算子值积分（谱定理的函数演算）常见 Dunford。
**选型口诀：能强不弱、能弱不逃（到二次对偶）**——每降一档，
唯一性与范数控制都在流失。

**与第 12 章 RN 的最终对位**：向量值测度 V 的三种分解
（Bochner 密度 / Pettis 密度 / 无密度）正对应值空间的
Radon-Nikodym 性质的三个等级——第 16.7.5 的反例（L¹ 值
V(A) = I_A）是第二档向第三档的坠落现场：它甚至没有 Pettis
密度（更强的反例：V 连 Dunford 密度都没有的构造存在）。
把"密度存在性"当作值空间的**试纸**，是无穷维测度论
（第 44-47 章）反复使用的诊断手法。

## 16.8 要点回顾

1. 强可测 = 简单函数的强极限（加倍控制）；Pettis 可测 = 泛函
   检验；可分时由对角线引理打通（Pettis 可测定理）。
2. Bochner 构造照抄三步：简单 → 基本列（实值 DCT 代工 + E 完备）
   → 泛函穿透定唯一。可积 ⟺ 强可测 + ‖X‖ 可积。
3. Bochner ⟹ Pettis；反向与向量值 RN 都会破产——L¹ 值测度
   V(A) = I_A 无 Bochner 密度（对角线反例），ASP 空间是值空间
   的正确抽象——第 37 章正则条件分布的技术伏笔。
4. 机器侧：mathlib 的 integral 即 Bochner（实值实验全是向量版
   的特例）；Isabelle 的 has_bochner_integral；数值通道按分量
   精确复刻。
5. Bochner/Pettis/Dunford 三档积分 = 可分性的三次讨价还价。
