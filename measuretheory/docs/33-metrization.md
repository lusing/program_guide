## 33.1 为什么需要距离

弱收敛定义为"对一切有界连续函数检验"——量词 ∀f 让收敛
概念难以量化。**度量化**：在 P(S)（概率测度全体）上造距离
d_P 使 d_P(μₙ, μ) → 0 ⟺ μₙ ⇒ μ——弱收敛变成序列语言，
一切度量空间定理（完备性、紧性、Baire 纲）即刻可用。可分
度量空间上这件事总是可能的（本章主角），但距离不唯一
（姊妹版：有界 Lipschitz 距离，33.4）。

## 33.2 Lévy-Prokhorov 距离的定义与账本

**定义**：对 A ⊆ S，记 Aᵉ = {x : d(x, A) < ε}（ε-膨胀）。

  d_P(μ, ν) := inf{ε > 0：μ(A) ≤ ν(Aᵉ) + ε 与 ν(A) ≤ μ(Aᵉ)
  + ε 对一切 Borel A}。

直观：**两个测度在一切集合上互不落后 ε-膨胀 + ε-余量**。
立即性质：d_P(μₙ, μ) → 0 ⟺ μₙ ⇒ μ（Portmanteau 的距离化
——闭集的 ε-膨胀是开集，单边条款 ⇄ 距离不等式的逐条翻译）；
d_P ≤ 1；离散空间上 d_P(δₓ, δᵧ) = min(d(x,y), 1)（退化检查）。

**与 Prohorov 定理的接口**：(P(S), d_P) 的紧性 = 弱相对紧 =
胎紧（32 章）——Prokhorov 定理的度量化陈述："P(S) 上
d_P-紧集 = 胎紧集"。**Polish 的封闭性收割**：S 可分完备
⟹ (P(S), d_P) 可分完备（Polish 的 lifting——概率测度空间
继承 Polish，第 29 章家谱的"乘法封闭"另一例：S ↦ P(S)
保 Polish）。

## 33.3 有界 Lipschitz 距离：姊妹版与等价

  d_BL(μ, ν) := sup{∫f d(μ−ν)：‖f‖∞ ≤ 1, Lip(f) ≤ 1}。

**等价性（常数损益）**：d_P ≤ 2·d_BL^{1/2}? 精确常数随
文献——**两距离诱导同一收敛**（弱收敛）的证明是磨光引理
的双向使用。d_BL 的优势：**线性结构**（积分差的双线性使
凸组合、卷积的 Lipschitz 估计直接可用——第 49 章特征
函数方法的土壤）；d_P 的优势：**集合语言**（与 Portmanteau
的直译）。工程与文献两者混用，收敛等价保证翻译无损。

## 33.2.5 距离公理的验证细账

d_P 是距离的验证（度量公理第三条非平凡）：

1. **对称**：定义中 μ/ν 双向不等式对称 ✓；
2. **恒等**：d_P(μ,ν) = 0 ⟹ μ(A) ≤ ν(A⁰) = ν(closure A)
   ≤ ν(A)？——0-膨胀取闭包，μ ≤ ν 于闭包；对 A 开有
   μ(A) ≤ ν(A) 且对称 ⟹ μ = ν（π-系收口）；
3. **三角不等式**：d_P(μ,λ) ≤ d_P(μ,ν) + d_P(ν,λ) 的
   证明是膨胀的复合账：A ⊆ (A^δ)^ε ⊆ A^{δ+ε}（三角
   不等式的距离版），账目逐项合并 ε + δ。∎

**度量的有界化**：d_P ≤ 1 天然有界（ε-余量条款）——大
距离被截断，**收敛速率在"小距离区"才有意义**（数值实验
的读法提示）。

## 33.3.5 完备性的证明骨架（Polish lifting 的核心）

S 可分完备 ⟹ (P(S), d_P) 完备的证明三步：

1. **Cauchy 列的候选极限**：对可数稠密 {xₖ}，柱面账
   μₙ(B(xₖ,r)) 一切 Cauchy（ℝ 完备）⟹ 逐点极限 μ* 存在
  （对角线免了——Cauchy 直接给）；
2. **σ-可加验收**：Cauchy 性给"ε-等度绝对连续"式控制
  （Prokhorov 半径小的两项互为近似 ⟹ 一致紧吸收即胎紧
  ——**Cauchy + 单点胎紧 ⟹ 族胎紧**），32.3.5 的紧验收
   机器照跑；
3. **d_P 收敛**：验收通过的 μ 使柱面账极限 = μ 账 ⟹
   距离条款逐项满足。∎

这就是"S ↦ P(S) 保 Polish"的机器内部——概率测度空间的
完备性不是天上掉的，是底空间完备性经 Prokhorov 机器的
转写。**随机元空间的迭代**（P(P(S))……）因此安全——
贝叶斯非参数统计（Dirichlet 过程）的严格地基。

## 33.3.6 一维专属：Lévy 竖直距离的账

一维上还有 Lévy 的原始距离 d_L(F,G) = inf{ε > 0：
G(x−ε)−ε ≤ F(x) ≤ G(x+ε)+ε ∀x}（cdf 的"平移+竖直"
混合膨胀）。三条账：

1. **与弱收敛等价**（一维）：跳点的处理由平移条款吸收
  ——δ_{1/n} 例中 d_L(δ_{1/n}, δ₀) ≤ 1/n（平移吞掉跳点
   差）——30 章跳点失败的又一距离化消解；
2. **与 d_P 的互控**：一维上 d_L 与 d_P 互相 Lipschitz
   控制（常数损益）——同收敛；
3. **数值友好**：cdf 的逐点比较（无需集合枚举）——一维
   实验的标准实现（本通道 30/33 章共用的账本格式）。

**教学定位**：d_L 是"字典一维舒适区"（30 章）的距离版
——高维无 cdf 便利，d_P/d_BL 接棒。四个距离在 ℝ 上
d_L ~ d_P ~ d_BL 同收敛，TV 独立成档——数值通道 33.4
的对照实验把这条谱系走一遍。

## 33.4.5 实验断言清单（数值通道验收单）

1. **离散穷举**：S = {0,1,2}，μ = (1/2,1/4,1/4) 与
   ν = (1/4,1/2,1/4)：8 个子集 × 双向膨胀账 —— d_P 精确
   = 1/4（Fraction 账）；
2. **δ 族**：d_P(δ_a, δ_b) = min(|a−b|, 1) 的采样账
  （a,b ∈ {0, 0.5, 1, 3} 的 6 对距离表）；
3. **δ_{1/n}**：d_P → 0（速率 1/n）vs Fₙ(0) 不收敛——
   30 章"跳点失败"的距离化消解；
4. **二项-正态**：B(n,1/2) vs N(1/2,1/4) 的 d_P 上界
  （网格膨胀检验）~ c·n^{-1/2}；
5. **三角不等式**：小模型上 (μ,ν,λ) 三元组全查的整数账。

## 33.4.7 实验补充：全变差的独立档（老大哥现场）

TV(μ,ν) = sup_A |μ(A)−ν(A)|（一切可测集）比 d_P 强得多：
TV 看得见跳点——δ_{1/n} 与 δ₀ 的 TV = 1（{0} 集合的账差
恒 1）**不收敛**！数值实验：① δ_{1/n}：d_P → 0 但 TV = 1
（永久）——强弱分档的活标本；② B(n,1/2) vs N(1/2,1/4)：
TV 也 → 0（格点 vs 连续的 TV = 1？——离散与连续测度
TV 恒 = 1！sup 取 {单点 k}：μ({k}) > 0 = ν({k})，累计
TV = 1）——**TV 对"格点 → 连续"的收敛全面失明**，弱
收敛/d_P 才是正确语言。实验把两个反例的 d_P/TV 双账并排
打印——收敛档位的选择从此有据可查。

## 33.4.6 历史注记与姊妹距离族

Lévy 在 1937 年一维版本已用 cdf 的"竖直距离"（sup|F−G|
于连续点——一维专属，跳点敏感）；Prokhorov（1956）推广
到一般度量空间的集合膨胀版（本章主角）。姊妹族谱：
**Fortet-Mourier 距离**（有界 Lipschitz 的加权版，耦合
优化的对偶）、**Wasserstein/Kantorovich-Rubinstein 距离**
W_p（∫d(x,y)^p 的最优传输下确界——最优传输理论的入口，
W₁ = d_BL 的对偶就是 KR 对偶定理）、**全变差**（最强：
一切可测集检验，= 最粗糙耦合的 sup——弱收敛的老大哥，
第 35 章独立性场景出场）。**选型口诀**：形状用 d_P、
线性用 d_BL、传输用 W_p、集合精确用 TV——同一收敛（弱）
的不同量化，按下游计算选工具。
