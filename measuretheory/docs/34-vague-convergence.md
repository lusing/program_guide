## 34.1 三档检验函数族：收敛强度的分档器

第 26 章的对偶定理把检验函数族与测度空间挂钩，本章收割
三档收敛：

| 收敛 | 检验族 | 保留什么 | 丢掉什么 |
|---|---|---|---|
| 弱收敛（31 章） | C_b（有界连续） | 总质量 + 形状 | —— |
| **淡收敛（vague）** | **C₀（消逝连续）** | 形状（紧观察窗内） | **总质量**（逃逸质量不可见） |
| 紧淡收敛 | C_c（紧支撑） | 紧窗内形状 | 总质量 + 窗外一切 |

νₙ → ν vague：∫f dνₙ → ∫f dν 对一切 f ∈ C₀。**淡弱于弱**
（C₀ ⊂ C_b）：δₙ → 0 淡收敛（f(n) → 0 对消逝 f ✓）但
不弱收敛（∫1 dδₙ = 1 ↛ 0）——**逃逸质量在 C₀ 检验下隐身**。
第 26 章 26.3.5 的预告在此兑现：C₀(X)\* 的弱\*拓扑 = 测度
的淡收敛——对偶理论的直接收获。

## 34.2 完全正则判定：淡收敛 + 质量收敛 = 弱收敛

**判定链（严书 6.5.x 的要点）**：νₙ → ν 淡收敛且
νₙ(X) → ν(X)（总质量收敛）⟹ νₙ → ν 弱收敛。

证明骨架：C_b 的 f 用"截断函数 × 消逝函数"分解——
f = f·χ_R + f·(1−χ_R)，χ_R ∈ C_c 紧截断；前者是 C_c ⊂ C₀
检验（淡收敛覆盖），后者的范数在余集上被 {1−χ_R 的支撑
外} 控制——**质量的尾端控制**来自总质量 + 紧窗的 C₀ 账。
∎（细节是 ε-三明治的又一次摊派。）

**教学口径**：弱收敛 = 淡收敛 + 质量不逃逸。"质量逃逸"
是淡收敛世界的合法行为——点过程理论（强度趋于无穷的
Poisson 过程）、位势论（质量流向边界）以淡收敛为**正确**
的收敛：它精确记录"局部形状极限"而不纠缠总量。

## 34.3 Helly 与淡收敛的对账

一维情形，Helly 选择（30 章）的子列极限恰是**淡极限**
（F_{nₖ}(x) → F(x) 于连续点 ⟺ δ 型积分账收敛 ⟺ 淡收敛
于 F 对应的次概率测度）：30 章的"端点亏损"正是淡收敛的
规范化——亏损质量在淡拓扑里就是"去了 ∞"。**Prokhorov
胎紧（32 章）在淡世界的对应物**：质量一致有界 + 一致
紧吸收 ⟹ 淡相对紧（每个序列有淡收敛子列）——"紧淡
Prokhorov"，严书 6.5 的组合定理把三档收敛与两档紧性
（弱相对紧/淡相对紧）织成一张对照表，本章 docs 以
表格收录（严书 6.5.8 一带）。

**反例档案（三档分化现场）**：ℝ 上 ① δₙ：淡 → 0，非弱
（质量逃逸）；② (1−1/n)δ₀ + (1/n)δₙ：弱 → δ₀（污染
逃逸但总质量保住——弱收敛的鲁棒性）且淡 → δ₀ ✓；
③ N(0, n)：淡 → 0（方差吹散质量），非弱。三例的数值
对拍见 34.4。

## 34.2.5 判定链的证明细账（截断分解的完整版）

νₙ → ν 淡 + νₙ(X) → ν(X) ⟹ 弱收敛的证明，ε-账逐行：

1. **截断函数**：取 χ_m ∈ C_c，0 ≤ χ_m ≤ 1，χ_m ↗ 1
  （LCH 的穷竭列，m → ∞）；
2. **分解**：∫f dνₙ = ∫fχ_m dνₙ + ∫f(1−χ_m) dνₙ——
   第一项 χ_m·f ∈ C_c ⊆ C₀（淡收敛覆盖：→ ∫fχ_m dν），
   第二项 |…| ≤ ‖f‖∞·νₙ({χ_m < 1})；
3. **尾端控制**：ν({χ_m < 1}) → 0（m → ∞，单调收敛）；
   固定 m 大使 ν({χ_m<1}) ≤ ε；νₙ(X) → ν(X) 与淡账在
   紧支撑检验下推出 νₙ({χ_m<1}) → ν({χ_m<1})??——
   **{χ_m<1} 是开集不是闭集**！处理：取闭子集 K_m ⊆
   {χ_m = 1} 使 ν(K_mᶜ) ≤ ε，χ_{K_m} 型磨光 φ_m ≼ 1_{K_mᶜᶜ}
   的开-闭夹逼——尾端 ≤ ‖f‖∞(νₙ−ν 账差) + 2ε；
4. **合龙**：limsup |∫f dνₙ − ∫f dν| ≤ (C_c 项差 → 0)
   + ‖f‖∞·2ε + ε ⟹ ε → 0 收口。∎

技术要点：**开集的 νₙ-账在淡收敛下只有下极限控制**
（portmanteau 的淡版单边纪律）——闭集夹逼是必需的，这
也是"淡 + 质量收敛"缺一不可的原因（只淡不质量时尾端
失控——δₙ 反例的机制解剖）。

## 34.3.5 严书 6.5 的对照总表（三档收敛 × 两档紧性）

| | 弱收敛 | 淡收敛 |
|---|---|---|
| 检验族 | C_b | C₀ |
| 质量守恒 | ✓（∫1 检验在列） | ✗（逃逸不可见） |
| Portmanteau 单边 | 闭 limsup / 开 liminf | 紧集内同款 + 端点条款 |
| 相对紧（胎紧版） | 胎紧 ⟺ 弱相对紧 | 质量有界 + 一致紧吸收 ⟺ 淡相对紧 |
| 子列极限空间 | P(X)（满额概率） | 次概率（Meas ≤ 1） |
| Helly 对接 | 胎紧补亏损 | **Helly 极限的原生档** |
| 应用户口 | 统计极限/CLT | 点过程/位势论/边界理论 |

**读法**：淡收敛把第 30 章 Helly 的"端点亏损"合法化为
拓扑——次概率测度空间 Meas(X)（总质量 ≤ 1）配淡拓扑
是 C₀(X)* 的正锥弱\*化——**泛函分析的 Banach-Alaoglu
紧性在此接手**（C₀ 对偶单位球的弱\*紧 = 淡相对紧的
抽象来源——有界线性泛函的免费午餐）。数学的三层楼
（26 章对偶 → 30 章 Helly → 34 章淡拓扑）在最后一张表
合龙。

## 34.4.4 离散模型的三档分离实验（ℕ 上的完全账）

ℕ（离散、局部紧、σ-紧）上检验族全部退化成级数：

- **C_b** = ℓ^∞（有界数列）；**C₀** = c₀；**C_c** = 有限
  支撑列；
- **测度** = ℓ¹-型权向量 w（Σwₖ ≤ 1 次概率）；
- **三档收敛**：Σfₖwₖⁿ 的收敛对 f ∈ ℓ^∞ / c₀ / 有限
  支撑——**c₀ 检验 = "逃逸质量隐身"**（wⁿ = eₙ（第 n 位
  单位权）：Σfₖ(eₙ)ₖ = fₙ → 0 对 f ∈ c₀ ✓，对 f ≡ 1
  ∈ ℓ^∞ ✗）；
- **判定链**：wⁿ = (1−1/n)e₁ + eₙ/n 的总质量 1 → 1 且
  c₀ 账 → f₁ ⟹ ℓ^∞ 账收敛（弱档达标）——数值实验的
  完整三档对照表。

这个离散模型是 34 章全部概念的**最小完全实现**——数值
通道（Python Fraction）以它为主战场，连续情形（δₙ、N(0,n)）
由 Julia 补充。

## 34.4.5 实验断言清单（数值通道验收单）

1. **δₙ**：e^{−n} 型消逝检验账 → 0（精确分数 (1/e)ⁿ 的
   Julia 浮点 / Python Decimal）；∫1 = 1 ↛ 0 的整数账；
2. **N(0,n)**：e^{−x²/2n} 检验的 ∫ = √(2πn)·(缩放) → 0
  （数值积分）；
3. **污染**：(1−1/n)f(0) + f(n)/n → f(0) 的三函数对拍；
4. **判定链打钩**：②例的 νₙ(ℝ) = 1 → 1 与淡账 → 弱
   收敛的合并验证；
5. **次概率画像**：μₙ = δₙ/2 + δ_{−n}/2 的淡极限 = 0
   （30.3.5 案例 3 的淡档收据）。

## 34.4 数值实验：逃逸的三种方式

**Julia（`34_vague_convergence.jl`）**：

- **δₙ**：C₀ 检验 f(x) = e^{−|x|}（消逝）的 ∫f dδₙ = e^{−n}
  → 0 ✓ 淡收敛；总质量恒 1 ↛ 0 ✗ 弱收敛——两档判定链的
  现场账；
- **N(0, n)**：f ∈ C₀ 的 ∫f dN(0,n) → 0（方差吹散——
  数值积分验证）；总质量 1 恒定——淡极限 0、弱极限无；
- **污染逃逸**：μₙ = (1−1/n)δ₀ + (1/n)δₙ——一切 C_b 检验
  ∫f dμₙ = (1−1/n)f(0) + f(n)/n → f(0) ✓ 弱收敛（对拍
  31 章 Slutsky 的邻居）；
- **判定链的数值收口**：② 例同时验证 νₙ(ℝ) = 1 → 1
  （质量收敛）——"淡 + 质量 ⟹ 弱"的三个前提逐条打钩。

**Python（`34_vague_convergence.py`）**：Fraction 精确版
——离散逃逸族的 C₀ 检验账（可和权序列 w ∈ ℓ¹ 充当"消逝
检验"于 ℕ：Σwₙδₙ 型账本）、总质量账、判定链的精确核对；
紧淡 vs 淡的分离（有限支撑检验只看前 K 项的截断差）。

## 34.5.6 历史注记与术语口径

"Vague convergence"出自法国学派（Lévy 学生的口语"收敛
 vague"），Dellacherie-Meyer 与 Bourbaki 传统的"étroitement
（窄）"与之抗衡；英文文献另有 **weak\* convergence**（泛函
分析口径，26 章）与 **narrow convergence**（Bourbini 口径，
= 本教程的"弱收敛"！）——**三个名字两张映射**，穿越文献
时的对照卡：

| 本教程 | Bourbaki/法国 | 泛函分析 | 概率工程 |
|---|---|---|---|
| 弱收敛（C_b） | narrow (étroit) | —— | weak convergence |
| 淡收敛（C₀） | vague | weak\*（对偶球上） | vague convergence |

Kallenberg（Foundations of Modern Probability）以 vague 为
默认并加"total mass"条款升档到 weak——本教程同款（34.2
判定链）。**口径纪律**：读文献先查检验函数族——族定档
位，名字只是包装。

## 34.6 要点回顾

1. 三档检验族 C_b ⊃ C₀ ⊃ C_c 对应弱/淡/紧淡三档收敛；
   淡收敛 = C₀ 检验 = C₀(X)\* 的弱\*（26 章对偶的直接收获）。
2. 判定链：淡 + 总质量收敛 ⟹ 弱（截断分解证明）。
3. 逃逸合法：δₙ、N(0,n) 淡 → 0；污染逃逸保弱（(1−1/n)δ₀
   型）；Helly 极限的规范化 = 淡收敛。
4. 应用户口：点过程/位势论以淡收敛为正确语言。
5. 机器分工如实：mathlib 无打包；零件 + 数值逃逸账承载。
