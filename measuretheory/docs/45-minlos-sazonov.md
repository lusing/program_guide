## 45.0 预备：柱测度的三本账

在陈述 Sazonov 定理前，把柱测度（第 19 章核机器的无穷维
化）的三本账记清：

1. **柱集账**：C = π_P⁻¹(B)（B 是 P(H) 的 Borel 集，
   P 有限秩投影）——柱集代数 ⊂ B(H)；
2. **柱面账本**：μ_P(B) := Bochner(φ∘Pⁱ)(B)——P(H) ≅ ℝⁿ
   上的真测度；相容性（P' ≤ P 时 μ_{P'} = μ_P 的投影）由
   φ 的正定性保证（Kolmogorov 相容性，第 21 章的调和版）；
3. **延拓问题**：柱面账本在柱集代数上有限可加（自动），
   **σ-可加性是额外收费**——Sazonov 定理的收银台。

**相容性免费、σ-可加性收费**的分工与第 21 章完全平行
（那边紧类付费、这边迹型连续性付费）——两条收费通道
殊途同归到"质量不逃逸"。

## 45.1 问题的坐标化

在 ℝⁿ 上，正定连续 φ = e^{i⟨·,t⟩} 的积分给出测度是免费的
（Bochner）。在无穷维 Hilbert H 上，**柱面账本** φ 经
有限维投影 P：μ_P(B) = "P 的 Bochner 测度"——柱测度的
装配（第 19 章核机器的无穷维化）。**核心问题**：柱测度何時
延拓为 H 上的真 σ-可加 Borel 测度？

**收费原理（严书 9.2.2 Δ-引理的非正式读法）**：σ-可加性
要求"质量不通过坐标逃逸"。对**原范数**拓扑，紧集太瘦
（无穷维单位球非紧）——账本合不上。**Sazonov 洞察**：改用
**迹型范数 ‖x‖_* = ‖Ax‖**（A 紧/迹类算子）——加粗拓扑使
紧集变胖，σ-可加性可收账。

## 45.1.5 Sazonov 拓扑的直觉（为什么加粗能省钱）

把范数从 \|·\| 换成更粗的 \|·\|_*（单位球更大）为什么
能买到 σ-可加性？两条直觉账：

1. **紧集变胖**：\|·\|_*-单位球包含 \|·\|-单位球的"厚
   邻域"——原范数下非紧的集合在粗拓扑下可以紧（Gauss
   型测度的能量集中 \|x\|_*² ~ Σλₙ⁻¹xₙ² 有限在粗范数
   下的控制）；
2. **连续性门槛降低**：φ 只需在 0 处 \|·\|_*-连续（更弱
   的要求——更多正定函数合格），但换来的测度住在 B(H)
   上（更强的结论）——**以拓扑的粗化换测度的存在**。

一句话：**Sazonov 定理 = 用"更难连续"换"更可加"**。
数学的守恒定律在无穷维的一次优雅显影。

## 45.2 定理陈述（等价三胞胎）

**Sazonov 定理（严书 9.2.4）**：正定 φ : H → ℂ（φ(0)=1）。
以下等价：

1. φ 是 H 上某概率测度的特征函数；
2. φ 在 0 处关于**某个 Hilbert-Schmidt 型范数** ‖·‖_* 连续；
3. （Minlos 变体）φ 在 0 处关于**迹型范数**连续。

**Minlos 定理（核空间版，严书 §9.3 的目标）**：核空间
（Schwartz 型：投影极限 + 迹型嵌入）上正定连续泛函 =
可数可加测度的 Fourier 变换——**广义函数论的测度论地基**
（Schwartz 分布的随机版）。第 46 章主角。

**证明骨架（(2)⟹(1) 的三步，严书 9.2.4 的核心）**：

1. **柱测度的一致紧性**：‖·‖_* 连续给 ε-δ 控制；对每个
   有限维投影 P，在 P(H) 中找紧球 K_P（按 * 范数）吸收
   柱面质量的 1−ε——**胎紧性（32 章 Prokhorov 的柱面版）**；
2. **σ-可加性验收**：递减柱集列 Bₙ ↓ ∅ 的账 → 0（紧控制
   ——第 20 章验收论证的拓扑重演）；
3. **Carathéodory 延拓**：柱 σ-代数 → B(H) 的唯一延拓。∎

## 45.2.5 证明三步的逐步细账（(2)⟹(1)）

Sazonov 定理核心方向的完整账目（每步的"付费项目"与
"交付物"）：

**第 1 步（柱面胎紧）**：‖·‖_* 连续给 δ 使 ‖x‖_* < δ ⟹
1 − Re φ(x) < ε。取秩 N 的投影 P_N（截断到前 N 个谱坐标），
则对剩余部分 x − P_N x 有 ‖·‖_*-控制——**关键不等式**：
μ({‖x − P_N x‖ > r}) ≤ (something/r²)·Σ_{n>N} λₙ
（Chebyshev 型 + 迹尾收敛 Σ_{n>N}λₙ → 0）。交付：一族
一致的紧集 K_N（= P_N 截段的‖·‖_*-紧球）吸收柱面质量
的 1 − ε。

**第 2 步（σ-可加验收）**：柱集列 Bₖ ↓ ∅ 要证柱账 → 0。
反证 + 胎紧：K_N 内的下降闭集有限步触空（紧性）；K_N 外
的质量 ≤ ε 由第 1 步控制——**逃逸被截尾和堵死**（与第 20
章验收、32 章 Prokhorov 论证同一母型——三处的紧控制都是
"质量不通过无穷远逃逸"的付费形式）。

**第 3 步（延拓）**：验收通过的柱面账本经 Carathéodory
延拓（第 04 章机器）到 B(H)；唯一性由柱集 π-系（第 06
章）收口。∎

**交付物清单**：概率测度 μ（B(H) 上）+ φ = φ_μ 的验证
（柱集上账目一致 + 单调类）。整个过程消费的预付资产：
迹收敛 Σλₙ < ∞（第 1 步）、Chebyshev（第 10 章）、
Carathéodory（第 04 章）、π-λ 唯一性（第 06 章）——
**Sazonov 定理是前半册机器的无穷维联销**。

## 45.3 正反例档案

**正例**：① 无穷乘积 Gauss（Σλₙ < ∞ 的特征值）——协方差
算子迹类 ⟹ ‖x‖_*² = Σxₙ²/λₙ 型范数的连续性 ✓（第 47 章
主角的入场券）；② 柱 Wiener 测度（Cameron-Martin 空间上）。

**反例（白噪声）**：λₙ = 1（全 1 特征值）——φ(w) =
e^{−‖w‖²/2} 是**柱正定**的（每个有限维投影是标准 Gauss），
但 Σλₙ = ∞：对 H 的 Borel σ-代数**没有** σ-可加延拓
（否则单位球的平移不变 + σ-紧矛盾——"无穷维无 Lebesgue
测度"的 Bochner-Sazonov 版证明，47 章复演）。**白噪声
只能住在更大的分布空间 S' 里**（Minlos 的核空间版解围——
第 46 章）。

## 45.4.5 Hilbert-Schmidt 与迹的对照（收费等级表）

Sazonov 定理的"迹型范数"有两档常用（严书的 ‖·‖_* 与
Hilbert-Schmidt ‖·‖_{HS}）——收费清单：

| 概念 | 定义 | 等价刻画 | 收费对象 |
|---|---|---|---|
| 迹类 S₁ | Tr A < ∞ | A = Σλₙ·eₙ⊗eₙ，Σλₙ < ∞ | 协方差算子 |
| Hilbert-Schmidt S₂ | \|A\|_{HS}² = Tr A*A < ∞ | 像的单位球 ∈ ℓ² | Gauss 的‖·‖_* |
| 紧算子 | 像的单位球预紧 | 谱 → 0（无重数条件） | CM 嵌入 |

关系链：S₁ ⊆ S₂ ⊆ 紧算子 ⊆ 有界（严格包含）。**Gauss
测度的协方差 A ∈ S₁（强制）；特征泛函的 ‖·‖_* 连续只需
S₂ 型**——两档之间的缝隙正是 Sazonov (2)/(3) 两个版本的
内容差异。数值通道的 λₙ 部分和对照正是 S₁ 的收费单。

## 45.4.6 习题账单

1. 证明 Δ-引理：柱面 σ-可加 ⟹ φ 在 0 处迹型连续（提示：
   反证 + 紧集缺失构造逃逸柱列）；
2. Sazonov (2)⟹(1) 三步的每一步独立验证；
3. 白噪声柱正定的验证（每个有限维投影是标准正态）+ 无
   B(H) 延拓的紧性论证细节；
4. 计算例：λₙ = n^{−α} 的 Gauss 何时迹类（α > 1）——
   α = 1 的临界失败账；
5. 从 Prokhorov（32 章）的胎紧论证到柱面胎紧的改写
  （"紧集"换成"‖·‖_*-紧集"）。

## 45.5 数值实验

**Julia**：迹类条件的数值验证（λₙ = 1/n² 的部分和收敛 vs
λₙ = 1 发散——两条特征值曲线的对比账）；柱面 Gauss 的
有限维投影收敛（n 维边际 → 迹极限）；白噪声的"每个有限
维是标准正态、整体无 σ-可加"的分箱演示。**Python**：
Fraction 精确的 Σ1/n² = π²/6 < ∞ vs Σ1 = ∞ 对照；柱面
一致性（不同投影方向的边缘相同）。

## 45.5.5 实验断言清单

1. **特征值账**：λₙ = 1/n² 的部分和 → π²/6 < ∞（精确
   Fraction + 数值双账）vs λₙ ≡ 1 的发散；
2. **柱面一致**：不同投影基下的白噪声柱面（i.i.d. 正态）
   同分布（正交基变换的采样对拍）；
3. **截断收敛**：迹类 Gauss 的 n 维边际的范数收敛
   Σλₙzₙ² → 稳定值；
4. **临界例**：λₙ = 1/n 的部分和 ~ log n 发散（Harmonic
   型——不迹类但 HS？1/n 的平方和 π²/6 收敛 ⟹ HS ✓
   S₁ ✗——两档的活标本）。

**历史注记**：Sazonov（1958，莫斯科）与 Minlos（1959，
独立）在相近时间建立了 Hilbert/核空间版本的定理；Gel'fand
学派的广义函数计划是共同背景。Dunford-Schwartz 的"Linear
Operators"第三卷收录了国际视角的整理。白噪声的严格化
（Gel'fand-Vilenkin 1964 的"广义随机函数"专论）与量子
场论的构造性计划（Nelson、Symanzik）把 Minlos 定理推上
数学物理的前台。
