## 30.1 从随机变量到分布函数：一维的完全字典

ℝ 上概率测度 μ ↔ 分布函数 F(x) = μ((−∞, x])（右连续、递增、
端点行为 F(−∞)=0、F(+∞)=1）——第 05 章的 L-S 机器。本章把
这张字典扩展到**收敛**：μₙ → μ 的各种意义下，Fₙ 与 F 如何
互动。一维的便利在于**分布函数是 ℝ 上的实值函数**——收敛
概念（逐点/一致/在连续点）全套分析学工具可用；高维（第 31
章）则换 Borel 检验函数的通用语言。

**关键定义**：x 称为 F 的**连续点**，若 F(x) = F(x−)（左极限
相等，即 μ({x}) = 0）。连续点集在 ℝ 中稠密（跳跃点至多可数
——每跳 ≥ 1/n 的点有限）——"几乎所有点都连续"是逐点收敛
只在连续点成立的舞台。

## 30.2 弱收敛与逐点收敛的等价（一维完全体）

**定理（一维特征化）**：ℝ 上概率测度列 μₙ 弱收敛于 μ
（∫f dμₙ → ∫f dμ 对一切有界连续 f——第 31 章的一般定义在
此预演）⟺ **Fₙ(x) → F(x) 在 F 的一切连续点**。

证明两向：

1. **(⟹)** 固定连续点 x：f = 连续磨光 1_{(−∞,x]} 的上下
   逼近（在 x±δ 处斜坡），弱收敛给 limsup Fₙ(x) ≤ F(x+δ)、
   liminf ≥ F(x−δ)，δ → 0 用连续性夹逼；
2. **(⟸)** 有界连续 f 被阶梯函数一致逼近（在 F 的连续点处
   切割）；阶梯函数的积分是 F 值的有限和——逐点收敛 + 控制
   收敛（尾项 ε-控制）传递。∎

**连续点条件的必要性（反例）**：μₙ = δ_{1/n}，μ = δ₀：
Fₙ(x) → F(x) 除 x = 0（Fₙ(0) = 0 ↛ F(0) = 1）——但 μₙ 弱
收敛于 δ₀ ✓（1/n 处的质量滑动到 0）。**逐点收敛在跳点上
失败但弱收敛仍成立**——连续点就是"质量落点不被追问"的
安全检查位。

## 30.3 Helly 选择定理：紧性的序论来源

**Helly 选择定理（严书 6.1 / 袁 12.3.2）**：{Fₙ} 为分布函数
列（一致有界变差），则存在子列 F_{nₖ} 与右连续递增 F 使
F_{nₖ}(x) → F(x) 于 F 的连续点（F 未必是分布函数——端点
可以亏损）。

证明是**对角线法**的教科书现场：ℚ 可数稠密，{Fₙ(q)}：q ∈ ℚ
逐点有界 → 依次取子列让 F(q₁) 收敛、再取子列让 F(q₂) 收敛…
对角线子列使一切有理点同时收敛；F := ℚ 上的极限 + 右连续
延拓；一般连续点由稠密性 + 单调夹逼。∎

**质量逃逸的显影**：Fₙ = δₙ 的分布函数——任何子列逐点收敛
到 F ≡ 0（端点亏损 1）："紧性"保住了子列存在，但**极限可以
不是概率测度**——亏损的质量去了无穷远。这份亏损由**胎紧性**
（第 32 章）堵住：胎紧族的一切 Helly 子列极限自动满额。
两章的分工：Helly 给"子列存在"，Prohorov 给"极限合格"。

**应用：一维 Prokhorov 预演**。ℝ 上胎紧概率族 = 弱相对紧
（每个开覆盖吸收质量的紧集堵住 Helly 亏损）——第 32 章
一般 Polish 定理的一维先行版。

## 30.2.5 磨光不等式的细账（等价证明的发动机）

(⟹) 方向的核心计算一行摊开：闭集 F 与 ε > 0，取连续函数
f_ε = 1 − min(d(x,F)/ε, 1)（F 上 = 1，距离 ≥ ε 处 = 0）：

  limsupₙ μₙ(F) ≤ limsupₙ ∫f_ε dμₙ = ∫f_ε dμ ≤ μ(Fᵉ)，
  令 ε → 0（F 闭 ⟹ ∩Fᵉ = F）得 limsup ≤ μ(F)。∎

**教学价值**：这五行是 Portmanteau（31 章）、Prokhorov（32
章）、Skorokhod（31 章）一切单边不等式的母版——"指示函数
的连续替身 + 极限交换 + 膨胀收紧"三连。读者应把它当作
**磨光三连**背诵——本书第 24 章（Urysohn 磨光）、第 27 章
（Lusin 拟合）与本章是该技术的三次规模化应用。

## 30.3.5 Helly 极限的次概率解读

Helly 子列的极限 F 可能端点亏损：lim Fₙ(x) 于 x → ±∞ 可以
< 1（右端）或 > 0（左端）。规范化解读：F 对应**次概率测度**
（sub-probability，总质量 ≤ 1），亏损量 = 逃逸质量的分布
函数画像。三条账：

1. **δₙ**：Fₙ(x) → 0 对一切固定 x——极限 F ≡ 0，总质量 0
  （全额逃逸）；
2. **(1−1/n)δ₀ + (1/n)δₙ**：Fₙ(x) → 1_{x≥0}——极限 F 无
   亏损（污染逃逸但质量记账在 δ₀ 处保住——弱收敛的鲁棒）；
3. **δₙ 与 δ_{−n} 各半**：极限 F ≡ 1/2·1_{[0,∞)}——半额
   逃逸的次概率画像。

第 34 章淡收敛把这份画像理论化：Helly 极限 = 淡极限。

## 30.2.6 一个综合例：泊松逼近的二项路线

B(n, λ/n) ⇒ Poi(λ)（"稀有事件定律"）是一维字典的全流程
演练：① cdf 都是阶梯函数，跳点分别为 k 与 k（λ 的整点处
双方都有跳——**跳点即连续点失效区**？不：极限 Poi(λ) 的
跳点集 {0,1,2,…}，B(n,λ/n) 在 k 处也有跳——但弱收敛只
要求**μ-连续点**收敛：μ = Poi(λ) 于非整点 x 处连续，
Fₙ(x) → F(x) 于非整点 ✓；② 阶梯逼近的有限和账：
Σₖ P(B=k)·1_{k≤x} → Σₖ P(Poi=k)·1_{k≤x}（逐项泊松极限
P(B(n,λ/n)=k) → e^{-λ}λ^k/k!——组合恒等式的 Stirling 收
尾）；③ 数值对拍：n = 100、λ = 3 的 sup 差（非整点）≈
0.02（Le Cam 界 λ²/n 的影子——第 52 章的 Poisson 收敛
准则在低维的预演）。

## 30.4.5 实验断言清单（数值通道验收单）

1. **跳点失败**：δ_{1/n} 的 Fₙ(0) = 0 ↛ F(0) = 1（精确
   整数账）；x = 0.3 处 Fₙ(0.3) = 1_{1/n≤0.3} → 1 ✓；
2. **Helly 对角线**：20 条混合正态漂移列在 200 点上的
   对角线子列——一切点账同时收敛（残差 < 容差）；
3. **逃逸**：δₙ 的 Fₙ(固定 x) = 1_{n≤x} → 0（对拍 30.3.5
   案例 1）；
4. **污染**：μₙ = (1−1/n)N(0,1)+(1/n)N(n,10) 的
   ∫sin dμₙ → ∫sin dN(0,1)（数值积分差 < 1e-6）；
5. **B(n,1/2)**：Fₙ 于连续点的收敛 + sup 差 ~ n^{-1/2}
  （Berry-Esseen 影子，52 章伏笔）。

## 30.5.5 习题账单（自检清单）

1. 证明跳跃点集可数（每跳 ≥ 1/k 的点 ≤ k 个——整数账）；
2. Fₙ → F 逐点于连续点，但 Fₙ(x₀) 在跳点 x₀ 的极限可以
   是什么？（区间 [F(x₀−), F(x₀)] 内任意聚点——构造三种
   不同行为的 μₙ）；
3. Helly 对角线第 k 步取子列后，前 k−1 个有理点的收敛性
   为何不损失？（子列的子列保收敛）；
4. δₙ 无弱收敛子列，但 {δₙ} 的 Helly 极限存在（30.3.5）——
   "相对紧"两种含义（弱 vs 淡）在此分化（34 章伏笔）；
5. 用磨光三连直接证明 limsup μₙ(F) ≤ μ(F) ⟹ liminf
   μₙ(G) ≥ μ(G)（补集翻译）。

## 30.4 数值实验：分布函数赛马

**Julia（`30_euclidean_convergence.jl`）**：

- **δ_{1/n} 滑动**：Fₙ(x) 在 x = 0 处的值恒 0 vs F(0) = 1
  （跳点失败现场）；x = 0.1 处 Fₙ(0.1) → 1 = F(0.1)（连续点
   成功）——连续点条件的双向对拍；
- **Helly 对角线**：随机 20 条分布函数列（混合正态的参数
  漂移），在 200 个网格点上执行对角线取子列——一切有理点
  收敛的数值显影；
- **质量逃逸**：δₙ 的 Fₙ 在固定 x 处 → 0（亏损现场）+
  Fₙ(n) = 1（质量在跑）——端点行为账；
- **磨光逼近的积分对拍**：∫f dμₙ vs ∫f dμ（f = sin 光滑
   函数）对 μₙ = (1−1/n)N(0,1) + (1/n)N(n, 10)—— contaminant
  质量滑走时弱收敛仍成立（积分差 → 0）。

**Python（`30_euclidean_convergence.py`）**：Fraction 精确版
——阶梯逼近的有限和账（F 值的显式求和）、跳跃点可数性
（每跳 ≥ 1/k 的点数 ≤ k 的整数账）、二项分布 B(n, p) 的
Fₙ 在连续点的精确收敛率（Berry-Esseen 的 n^{-1/2} 影子，
第 52 章伏笔）。

## 30.5.6 三维与高维的预览（cdf 字典的边界）

ℝᵈ 上分布函数 F(x) = μ((−∞, x₁]×…×(−∞, x_d]) 的"连续点"
= 各坐标超平面不承载质量的点。字典的高维版：μₙ ⇒ μ ⟺
Fₙ → F 于 μ-连续点（超平面零测点）——但**高维 Helly 的
对角线更费周章**（每条坐标轴的跳跃集可数，d 维的超平面族
仍零测——稠密连续点集的论证照搬）。工程上高维几乎不用
cdf 而用特征函数（第 49 章）或 Cramér-Wold（31 章）——
cdf 字典是一维的舒适区，高维让位于更对称的工具。

**历史注记**：Helly（1912，选择定理）先于 Kolmogorov 公
理化（1933）二十年——分布函数的序性质（单调有界）承载
了测度论之前的概率极限论证。Lévy（1925）以 cdf 收敛定义
"收敛律"，Skorokhod（1956）补齐表示定理——本章的三件
套横跨四十年。

## 30.7 要点回顾

1. 一维完全字典：μₙ → μ 弱 ⟺ Fₙ → F 于连续点；连续点集
   稠密（跳点至多可数）。
2. Helly 对角线：分布函数列的逐点子列极限存在（可能亏损）；
   胎紧（32 章）堵住亏损。
3. 反例档案：δ_{1/n}（跳点失败但弱收敛 ✓）、δₙ（质量逃逸、
   极限非概率）。
4. 机器侧：mathlib `cdf` API；Isabelle `helly_selection`；
   数值通道把对角线与逃逸账算到底。
