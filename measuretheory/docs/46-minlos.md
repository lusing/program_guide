## 46.1 核空间：投影极限的完全体

**核空间（nuclear space，严书 9.3.1 定义）**：局部凸拓扑
向量空间 X，拓扑由半范数族 {|·|_p} 生成，且对每个 p 存在
q > p 使**恒等映射 (X, |·|_q) → (X, |·|_p) 是迹类算子**
（S₁ 型）——"每一层比下一层厚得多"的无穷塔。

**原型**：Schwartz 空间 S(ℝ)（速降光滑函数）——半范数
|f|_{k,m} = sup|x^k f^{(m)}(x)| 的塔；其**对偶 S'(ℝ)** =
缓增分布（广义函数）。**核空间的三件宝**：① 一切连续
线性泛函可达（对偶"够大"）；② 有限维投影的迹型一致
（Sazonov 收费的批量豁免）；③ 可分 + 桶型（泛函分析便利）。

## 46.1.5 半范数塔的手感（S(ℝ) 的具体账）

把核空间的原型 S(ℝ)（速降光滑函数）的塔算出实感：半范数

  |f|_{k,m} = sup_{x∈ℝ} |x^k f^{(m)}(x)|

塔的层级（k, m ∈ ℕ）。**核性验证的账**：从 |·|_{k,m+2} 到
|·|_{k,m} 的恒等算子是迹类的——因为 x^m f^{(m)} 的求导
"丢失的两阶导数"换来可积权的平方衰减，Sobolev 嵌入
H^{s+1} ⊂ H^s 是 Hilbert-Schmidt（s 维数 < ∞ 时紧）的
无穷维版本。**对偶塔**：S'(ℝ)（缓增分布）= 归纳极限
（半范数的对偶塔）——δ 函数、导数 δ'、多项式乘 δ 都
住在 S' 里但不在 L² 里——**分布空间的"更大旅馆"**正是
Minlos 测度的住宅区。

## 46.1.6 习题账单

1. 验证 S(ℝ) 是核空间（两层级间的迹型嵌入——Sobolev
   嵌入的显式账）；
2. 证明柱测度的相容性由特征泛函的正定性自动给出
  （有限维 Bochner + 投影一致性——第 21 章相容性的
   调和版）；
3. 白噪声特征泛函 e^{−⟨f,f⟩/2} 在 S 上连续（对每个
   半范数的 Cauchy-Schwarz 账）但不在 L²(ℝ) 的 Hilbert
   范数上连续（反例序列）——核拓扑的必要性现场；
4. 计算：δ_a 的特征泛函（φ(f) = e^{if(a)}——点评估
   泛函作为 S' 的元素）；
5. Poisson 噪声 φ(f) = exp(∫(e^{if}−1)dλ) 的正定性与
   连续性验证（Lévy-Khinchin 的核空间版——53 章伏笔）。

## 46.2 Minlos 定理

**定理（严书 9.3.x）**：X 核空间、φ : X → ℂ 正定连续
（对核拓扑）。则存在 X 的**对偶 X'** 上唯一 Radon 概率
测度 μ 使

  φ(x) = ∫_{X'} e^{i⟨T, x⟩} dμ(T)。

**读法**：核空间上的正定泛函自动在对偶空间落户——**测度
住进广义函数**。白噪声（45 章反例）的解围：S 上 φ(f) =
e^{−‖f‖²_{L²}/2}（柱正定）经 Minlos 给出 **S' 上的白噪声
测度**——δ-相关广义场的严格化。证明：核性给一致的迹型
范数控制（Sazonov 的 (2) 每层满足）+ 投影极限的 Kolmogorov
延拓（第 21 章机器在局部凸层运转）。

## 46.2.5 证明骨架（投影极限的逐层装配）

Minlos 定理的证明 = Sazonov 定理 + 投影极限的组装线：

1. **逐层收费**：核空间 X 的每个"商空间"X/p（半范数 p 的
   完备化）是 Hilbert 空间；φ 诱导 X/p 上的正定连续函数
  ——**Sazonov 定理逐层适用**（每层收一次迹型费——核性
   保证相邻层的迹型嵌入使费用"越付越少"）；
2. **相容族**：层与层之间的投影使各层的 Sazonov 测度
   相容（Kolmogorov 相容性，第 21 章机器在局部凸索引
   集上的运转）；
3. **极限装配**：相容族在对偶空间 X'（配投影极限拓扑的
   对偶——归纳极限）上装配 Radon 测度（Prokhorov 的
   局部凸版——胎紧性由逐层的紧球族供给）。∎

**核性的角色**：它是"逐层 Sazonov 费用"的**批量折扣券**
——没有核性，每层各自付费但总账可能发散（白噪声住在
非核 Hilbert 空间 L² 上的失败 = 总账发散的具体现场）；
核性把无穷层的费用压缩为有限（塔的迹型一致性）。

## 46.3 柱测度与特征泛函的词典

**柱集**：C = {T ∈ X' : (⟨T,x₁⟩,…,⟨T,xₙ⟩) ∈ B}（对偶侧
的有限坐标约束——第 17 章柱集的对偶版）。**柱测度**：
柱集代数上的有限可加集函数（有限维投影 Bochner 的装配）。
**特征泛函**：μ 的 Fourier 变换 φ_μ(x) = ∫e^{i⟨T,x⟩}dμ(T)
——X 上的正定连续函数。**Minlos 词典**：

  X' 上 Radon 测度 ⟷ X 上正定连续泛函（φ ↔ μ 一一对应）。

随机广义函数论（Gel'fand-Vilenkin）的语言底座：随机场 =
对偶空间上的测度 = 核空间上的特征泛函——三种身份自由
换装。

## 46.3.5 白噪声解围的完整账（45 章反例的终局）

白噪声 φ(f) = e^{−‖f‖²_{L²}/2} 的**三步落户**：

1. **L²(ℝ) 上失败**（45 章）：特征值 λₙ ≡ 1，Σλₙ = ∞
  ——Sazonov 收费无着落，无 B(L²) 延拓；
2. **S(ℝ) 上正定连续 ✓**：|φ(f) − φ(g)| ≤ ‖f−g‖_{L²}·
   (‖f‖+‖g‖)/2 型的 Lipschitz 账 + S ⊂ L² 连续嵌入——
   但关键在于**S 的核拓扑**比 L²-范数细（更多半范数），
   连续性要求**更强**，看似更难满足？**非也**——φ 在
   S 的每个半范数球上的控制反而由速降性供给（速降
   ⟹ L² 范数有限）——连续性 ✓；
3. **Minlos 发证**：S 核 ⟹ φ 给出 S' 上 Radon 概率
   μ_white——一切"坐标"⟨T, f⟩ ~ N(0, ‖f‖²) 且协方差
   E⟨T,f⟩⟨T,g⟩ = ⟨f,g⟩（白噪声的协方差 = 恒等算子——
   在 S' 的住宅里恒等协方差合法）。

**Brown 运动的实现**：B_t := ⟨T, 1_{[0,t]}⟩（白噪声对
示性函数的作用）——增量独立性（示性函数正交 ⟹ Gauss
不相关 ⟹ 独立）+ 增量分布 N(0,t)——**布朗运动 = 白噪声
的随机积分**，第 43 章轨道装修预告在此兑现。

## 46.4 应用：广义随机场

① **白噪声场**：S' 上的 Gauss 测度（特征泛函
e^{−⟨f,f⟩/2}）——Brown 运动 = 白噪声的积分（分布意义
下的导数关系）；② **Poisson 噪声**：φ(f) = exp(∫(e^{if}−1)
dλ)——跳过程的完全随机测度化；③ **量子场论**：Euclidean
场的构造性定义（Nelson 对称性 / Osterwalder-Schrader 公理
的测度入口）——物理的严格化管道。Minlos 定理是这一切的
"存在性发证机关"。

## 46.4.5 实验断言清单

1. **柱面一致**：白噪声的 n 维截断（i.i.d. 正态）在换
   正交基后同分布（采样对拍 + 精确矩）；
2. **正则性恶化**：截断维数增加时路径的正则性（对 t 的
   连续模）退化——"广义"的必要性数值显影；
3. **δ 泛函账**：点评估的柱面分布 = δ_a（示性测试函数
   的精确账）；
4. **Brown 实现**：白噪声采样 → 累积和 → 轨道的增量
   正态性与独立性（KS 检验型对拍）；
5. **Poisson 噪声**：φ(f) = exp(∫(e^{if(x)−1)dx) 的柱面
   模拟（复合 Poisson 采样）。

## 46.5 数值实验

**Julia（`46_minlos.jl`）**：

- **白噪声柱面**：n = 100 维截断（i.i.d. N(0,1) 坐标）——
  随机正交基变换后的坐标分布仍 i.i.d.（不变性的采样
  对拍：变换后样本的协方差 ≈ 单位阵）；
- **Brown 实现**：白噪声采样 z ~ N(0, Iₙ) → 累积和
  B_{k} = Σ√Δ·z——增量独立（相邻段协方差 ≈ 0）+ 方差
  正比于 t（|B_t|²/t → 1 的频率验证）——白噪声积分的
  轨道显影；
- **正则性恶化**：截断维数 10/50/200 的"广义场"路径的
  连续模（max|x_{k+1} − x_k| 随维数增长 ~ √(Δ·2log n)）
  ——分布身份无法住进连续函数空间的数值证词；
- **Poisson 噪声**：φ(f) = exp(λ∫(e^{if}−1)dx) 的复合
  Poisson 采样（跳位置均匀 × 跳数 Poisson(λ)）——特征
  泛函的采样平均 vs 解析闭式。

**Python（`46_minlos.py`）**：Fraction 精确版——柱面一致
性的精确矩账（i.i.d. 的二阶矩恒等）；δ 泛函的指示测试
（⟨T, 1_{[a,b]}⟩ 的分布核对）；Brown 增量的精确方差比。

## 46.5.5 历史注记与分工口径

**历史**：核空间概念来自 Grothendieck（1950s，张量积
拓扑研究）；Schwartz（1950-51，分布论）确立了 S/S' 的
原型地位；Minlos（1959）的定理把 Gel'fand 学派的"广义
随机函数"计划严格化。Gel'fand-Vilenkin 四卷本（1964）
是该传统的百科。物理侧：Osterwalder-Schrader（1973）
公理把 Euclidean 场测度的存在性（Minlos 发证）与
Minkowski 量子场联系起来——构造性场论的测度论骨架。

**分工口径**：mathlib/Isabelle 均无核空间与 Minlos 基础
设施（拓扑向量空间层尚在建设中）——本章 Lean 侧以
零件（gaussianReal/白噪声有限维截断）承载，docs 承担
定理本体——第 14/15/43 章分工先例的延续。

## 46.6 要点回顾

1. 核空间 = 迹型嵌入的投影极限塔；S(ℝ) 与 S'(ℝ) 是原型。
2. Minlos：核上的正定连续泛函 = 对偶上的 Radon 测度——
   测度住进广义函数。
3. 词典：Radon 测度 ⟷ 特征泛函；白噪声/Poisson 噪声/
   QFT 场的应用三连。
