# 13 Lᵖ 空间：完备性、不等式与对偶

**对应严书 §3.4（pp. 62-71）。**

---

## 13.1 从积分到距离

第 10 章的积分把"函数的大小"折成数；Lᵖ 把"函数的远近"折成数。
对 p ≥ 1 与可测 f，定义

  ‖f‖ₚ = (μ(|f|ᵖ))^{1/p}（1 ≤ p < ∞），

Lᵖ = {可测 f : ‖f‖ₚ < ∞}（a.e. 等价类意义）。p = ∞ 的本性上
确界范数在第 14 章展开。Lᵖ 是"按积分大小分层的函数仓库"：
p 越大越在乎尖峰、越不在乎铺开——第 47 章 Cameron-Martin 空间
的嵌入讨论将反复使用这条直觉。

## 13.2 三条奠基不等式（严书 3.4.1）

对 r > 0、1 < p, q < ∞、1/p + 1/q = 1、s ≥ 1：

1. **Cᵣ 不等式**：μ(|f+g|ʳ) ≤ Cᵣ·(μ(|f|ʳ)+μ(|g|ʳ))，
   Cᵣ = max(1, 2^{r−1})——逐点不等式 |a+b|ʳ ≤ Cᵣ(|a|ʳ+|b|ʳ)
   直接积分，凸性的婴儿版；
2. **Hölder**：μ(|fg|) ≤ ‖f‖ₚ‖g‖_{L^q}——Young 不等式
   ab ≤ aᵖ/p + b^q/q（凸函数在切线下的经典形态）对"归一化对"
   f/‖f‖ₚ、g/‖g‖_q 积分；p = q = 2 时即 **Schwarz 不等式**
   |⟨f,g⟩| ≤ ‖f‖₂‖g‖₂——L² 是内积空间；
3. **Minkowski**：‖f+g‖ₛ ≤ ‖f‖ₛ + ‖g‖ₛ——对 |f+g|ˢ =
   |f+g|^{s−1}|f+g| 用两次 Hölder 拆开。

范数三公理（正定/齐次/三角）由此落地：正定来自第 10 章
"μ(|f|ᵖ)=0 ⟹ f=0 a.e."（等价类商掉零测差异）。**Hölder 的
对偶指标 1/p+1/q=1 是"Lᵖ 与 L^q 互相配对"的账本**——第 13.4
节说明这不仅是巧合。

**Young 不等式的两张脸**：ab ≤ aᵖ/p + b^q/q 对 a, b ≥ 0——
证明一（凸性）：x ↦ eˣ 是凸的，Young = 加权 AM-GM 的连续版
（取对数 a = eˢ, b = eᵗ，右边 = (p·s + q·t 的加权平均的指数)）；
证明二（切线）：对固定 b，函数 a ↦ aᵖ/p + b^q/q − ab 在
a = b^{q−1} 处取最小 0——凸函数在切线之上。两张脸在第 13.4
对偶与第 44 章特征函数的正定性判据里各返场一次。离散特例：
ℓᵖ（计数测度）的 Hölder 就是熟知的 Σ|aᵢbᵢ| ≤ ‖a‖ₚ‖b‖_q，
p = q = 2 即 Cauchy——Lagrange 恒等式给出精确取等条件
（aᵢbⱼ − aⱼbᵢ 全为零，即两向量线性相关），数值通道把它做成了
"平方账整数不等式"。

## 13.3 完备性：Riesz-Fischer 定理（严书 3.4.4-3.4.5）

**定理** （Lᵖ, ‖·‖ₚ）是 Banach 空间。

证明的骨架是三步兑换（严书 3.4.4 引理）：**Lᵖ 收敛 ⟺ Lᵖ 基本
列**。⟹ 方向由 Cᵣ 不等式（范数差的 r 次幂被两个距离控制）；
⟸ 方向：基本列 ⟹ 依测度基本列（Chebyshev/Markov：μ([|fₙ−fₘ|
≥ ε]) ≤ ‖fₙ−fₘ‖ᵖʳ/εʳ）⟹ 由第 09 章依测度 Cauchy 判据存在
极限 f ⟹ Fatou 对 ‖fₙ−fₘ‖ 取 n→∞ 把 f 拉回 Lᵖ。**三件前作
（Markov、依测度完备化、Fatou）在这里合龙**——本章没有新机器，
全是旧零件的总装。附产：Lᵖ 收敛 ⟹ 依测度收敛 + 存在子列 a.e.
收敛（Riesz）。

**范数收敛的刻画（3.4.6）**：‖fₙ−f‖ₚ → 0 ⟺ fₙ → f 依测度且
‖fₙ‖ₚ → ‖f‖ₚ。加条件的单调情形（fₙ ↑ f、‖fₙ‖ₚ → ‖f‖ₚ ⟹
Lᵖ 收敛）是 MCT 的 Lᵖ 版。这两条把"Lᵖ 拓扑"接到第 09 章的
收敛方式矩阵上。

**L² 的 Hilbert 结构**：⟨f, g⟩ = ∫fg dμ 是内积（Schwarz 保证
良定义与 Cauchy-Schwarz 不等式），‖f‖₂ = √⟨f,f⟩。完备内积
空间（Hilbert）的全部机器立即可用：正交投影（第 36 章条件期望
= L² 正交投影——全书最重要的单个应用）、正交基、Parseval、
Riesz 表现（对偶 = 自身）。第 13.4 的对偶定理在 p = 2 处取最简
形态：T ⟺ g 的对应由内积一挥而就，无需 RN——**p = 2 是对偶
定理的"免费区"，p ≠ 2 才付 RN 的构造费**。有限维原型：ℝⁿ 的
对偶是 ℝⁿ，L² 是它的无穷维直译。

**完备性证明的分步账单**（把 13.3 开头的骨架拆成可查账的六步，
数值通道逐步对应）：

1. 基本列 ⟹ 依测度基本列：Markov（Chebyshev），费用 ε^{-r}；
2. 依测度基本列 ⟹ 存在极限 f：第 09 章判据（Riesz 提子列 +
   对角线）；
3. f ∈ Lᵖ：Fatou 对 ‖fₙ−fₘ‖ᵖ 取 n → ∞（固定 m 后放缩）；
4. ‖fₙ−f‖ₚ → 0：同一 Fatou 的直接读数；
5. 唯一性：Lᵖ 距离的分离性（a.e. 等价类）；
6. 子列 a.e. 收敛：Riesz 子列定理的附产。
   数值实验的"截断 Cauchy 列差范数单调归零"是这六步在第 3-4
   步上的离散影子。

## 13.4 对偶定理：(Lᵖ)* = L^q（严书 3.4.13-3.4.15）

**定理** 设 1 ≤ p < ∞、1/p+1/q = 1、μ σ-有限。则每个连续线性
泛函 T ∈ (Lᵖ)* 都唯一地表现为

  T(f) = ∫ f·g dμ，g ∈ L^q，且 ‖T‖ = ‖g‖_q。

**证明的装配线**（严书路线，两段构造）：

1. **局部化**：对测度有限块 A，ν_A(B) = T(I_B) 定义出 ≪ μ|A
   的符号测度，**RN 定理**给出 g_A = dν_A/dμ；Fatou（对截断
   g_A·I_{[|g_A|≤n]} 的范数列）证明 g_A ∈ L^q 且 ‖g_A‖_q ≤ ‖T‖；
2. **拼接**：相容族 {g_A}（A ⊆ B 时 g_B|_A = g_A a.e.）沿
   σ-有限穷竭列 Aₙ ↑ Ω 单调拼出 g；T 的表现与范数等式经
   单调极限传递。

**p = 1 的 σ-有限条件不可省**（3.4.15 反例）：取 Ω = ℝ、
𝓕 = 可数-余可数 σ-代数、μ = 计数测度（非 σ-有限！），则
F(f) = Σ_{a>0} f(a) 是 L¹ 上范数为 1 的连续泛函，但唯一满足
表现的"密度"g = I_{(0,∞)} **不可测**——(L¹)* ⊋ L^∞。这个
反例的构造逻辑值得慢读：L¹ 的元素只在可数集外为零，所以
"沿正半轴求和"合法且连续；但 I_{(0,∞)} 相对可数-余可数
σ-代数不可测（(0,∞) 与其补都不可数）——**泛函合法而密度
不合法，账本在错误的 σ-代数上记账**。p > 1 时 σ-有限可去掉
（凸性给出一致有界的穷竭）。L² 的对偶是自身（Riesz 表现的
Hilbert 版）——第 26 章 C₀ 对偶的先声。

**范数等式 ‖T‖ = ‖g‖_q 的双向账**：≤ 方向就是 Hölder（表现
泛函被 g 的范数控制）；≥ 方向取"对偶方向"函数 f* =
sign(g)·|g|^{q−1}（归一化后）使 Hölder 取等——数值通道的
"对偶方向取到范数"实验正是这一步的离散版。取等函数的存在把
上确界变成最大值：**L^q 的单位球在 Lᵖ 配对下达到对偶范数**——
一致凸性（第 38 章）将把这条线推向唯一性。

**可分性附账（3.4.9-3.4.11）**：μ σ-有限时 L¹ 可分 ⟺ σ-代数
"μ-可分"（可数集族在有限测度集上按对称差稠密）；反例仍是
计数测度。可分性是第 31 章弱收敛可度量化讨论的门票。

## 13.5 Lean：Lp 与 Hölder

mathlib 的 Lᵖ 在 `Function/LpSpace/Basic.lean:89`（结构
`MeasureTheory.Lp E p μ`，元素是 a.e.-等价类），范数实例
`instNormedAddCommGroup`（带 `Fact (1 ≤ p)`）与成员谓词
`MemLp`（LpSeminorm/Defs:118）；Hölder 在 `Function/Holder.lean:81`
——注意它挂在 **ContinuousLinearMap** 命名空间（双线性配对的
界），不在 MeasureTheory 下；完备性在 `LpSpace/Complete.lean`。
`Ch13LpSpaces.lean` 以 `#check` 正名四件，实弹三发：

```lean
/-- 离散 Schwarz 的数值账：f=[1,2,3,4]、g=[4,3,2,1]，
⟨f,g⟩=20，右端 ‖f‖₂‖g‖₂ = √30·√30 = 30 —— 平方后整数比较。 -/
example : (1*4 + 2*3 + 3*2 + 4*1 : ℚ)^2 ≤
    ((1^2 + 2^2 + 3^2 + 4^2 : ℚ) * (4^2 + 3^2 + 2^2 + 1^2)) := by
  norm_num

/-- Cauchy 不等式的代数内核（Schwarz 的骨架）：(Σaᵢbᵢ)² ≤
(Σaᵢ²)(Σbᵢ²)——经典证明是 Lagrange 恒等式（差平方和 ≥ 0），
nlinarith 拿着六个平方非负项直接收。 -/
example (a b c d e f g h : ℚ) :
    (a*e + b*f + c*g + d*h)^2
      ≤ (a^2 + b^2 + c^2 + d^2) * (e^2 + f^2 + g^2 + h^2) := by
  -- 六个交叉差平方各非负（positivity），nlinarith 合龙
  nlinarith [h1, h2, h3, h4, h5, h6]

/-- 常值函数在有限测度上属于一切 Lᵖ（memLp_const）。 -/
example (μ : Measure Bool) [IsFiniteMeasure μ] (p : ℝ≥0∞)
    (c : ℝ) : MemLp (fun _ : Bool => c) p μ := memLp_const c
```

值得记录：**nlinarith 能从"六个平方非负"自动合成 Lagrange
恒等式路线**——把教科书里"展开移项"的证明压成一行提示列表；
但有理数上的数值账（第一例）反而要自己先心算平方化。

## 13.6 数值实验：离散 Lᵖ 的全家福

**Julia（`13_lp_spaces.jl`）**在 6 点原子测度（权 2⁻ᵏ）上：

- **三角不等式全族**：随机 1000 对函数，对 p ∈ {1, 2, 3, ∞(截断
  而非本性)}验证 ‖f+g‖ₚ ≤ ‖f‖ₚ+‖g‖ₚ；
- **Hölder 紧性**：p=q=2 时随机对的 Schwarz 比值分布——最紧
  的一对逼近 1（g = c·f 时取等）；
- **完备性演示**：L² 中构造 Cauchy 列 fₙ = f·I_{前 n 原子}
  → f，逐项验证 ‖fₙ−f‖₂ 单调降到 0；再演示非 Cauchy 列
  （范数振荡）不收敛；
- **对偶表现**：随机 g ∈ L^q，验证 T(f) = ∫fg 的算子范数
  ‖T‖ = ‖g‖_q（在有限维原子测度上是精确等式：穷举基向量
  逼近）。

**Python（`13_lp_spaces.py`）**：Fraction 精确版——Hölder 与
Minkowski 的**精确**不等式（有理数 p-范数用 `Fraction ** p` 的
整数幂根：权与函数值取 2 的幂使范数精确），Schwarz 取等的
构造性例子（g = 2f 比值恰 1），L² Cauchy 列的差范数精确归零账。

**数值实测的账目纪律（13 章特有）**：p-范数含 1/p 次根，超出
有理数域——精确账只能记"p 次幂和"（平方账）：Minkowski 的 p=1
情形幂和即范数（精确），p=2,4 取根后浮点比较（1e-12 容差）；
Schwarz 与对偶全部平方化后是**整数不等式**，Fraction 分毫不差。
"哪个量在哪个域里可精确"要在设计实验时先想清楚——这是 p-范数
与第 10-12 章纯加性账目的本质差异。

## 13.7 要点回顾

1. Lᵖ 距离把第 10 章积分折成范数；三条不等式（Cᵣ/Hölder/
   Minkowski）是凸性的三个刻度；L² 配内积成 Hilbert。
2. 完备性 = Markov + 依测度完备化 + Fatou 的总装；收敛刻画
   （依测度 + 范数收敛）接通第 09 章矩阵。
3. 对偶 (Lᵖ)* = L^q：局部 RN + 相容拼接；p=1 需 σ-有限
   （可数-余可数计数反例——密度不可测！）；p>1 无此忧。
4. 可分性：σ-有限 ⟺ L¹ 可分（μ-可分 σ-代数）；计数测度again。
5. 机器侧：mathlib 的 Lp 结构 + Holder.lean + Complete.lean；
   离散世界的 Hölder 是加权和不等式，精确可验。
