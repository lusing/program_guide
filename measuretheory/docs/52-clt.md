# 第 52 章 中心极限定理（袁 ch21）

51 章问"平均收敛到哪"，本章问"偏差的涨落长什么样"。答案从
Dé Moivre 1733 年研究抛硬币正面次数的分布逼近开始，经 Laplace
（1812）推广到一般 p，Lyapunov（1901）首次用特征函数方法证明
一般形式，Lindeberg（1922）给出最一般的充分条件，Feller
（1935）补必要性——**二阶矩存在的独立和的渐近正态性**至此
完全刻画。Pólya 1920 年命名"中心极限定理"（central limit
theorem）：它是概率论的中心，也是统计推断（区间估计的枢轴量、
假设检验的检验统计量）的理论源泉。

## 52.1 两档定义与历史坐标（袁 21.1.1）

**定义 52.A（袁 21.1）。** {Xₙ} 为 r.v. 序列，Sₙ = ΣXₖ：
  (i) **古典 CLT**：Var Sₙ < ∞ 且 (Sₙ−ESₙ)/√Var Sₙ →ᵈ N(0,1)；
  (ii) **现代 CLT**：存在中心化 {aₙ} 与正则化 {bₙ}（0<bₙ→∞）
      使 (Sₙ−aₙ)/bₙ →ᵈ N(0,1)，此时称 (Sₙ−aₙ)/bₙ 渐近标准
      正态。

本章只涉方差有界情形；方差无界（重尾）属普遍极限问题范畴，
是 53-55 章的题材（稳定分布接管正态的位置）。

## 52.2 两座桥头堡：Dé Moivre-Laplace 与 Lindeberg-Lévy

**定理 52.B（Dé Moivre-Laplace，袁 21.2）。** Bernoulli(p)
iid：(Sₙ−np)/√(np(1−p)) →ᵈ N(0,1)。Dé Moivre 1733 只做了
p = 1/2，Laplace 1812 扩到一般 p——概率论历史上第一个 CLT。

**定理 52.C（Lindeberg-Lévy，袁 21.3）。** iid，EX = μ，
Var X = σ² < ∞：(Sₙ−nμ)/(√nσ) →ᵈ N(0,1)。脚注警告：这里的
"独立"不能减弱为"两两独立"（与 51 章 SLLN 的 Etemadi 版恰成
对照——弱律降级够用，CLT 不行）。

**例 52.D（袁 21.4，χ² 的双极限）。** Xₙ ~ χ²(n)：写成
Xₙ = ΣUₖ²（Uₖ iid N(0,1)），E(Uₖ²−1) = 0，Var(Uₖ²−1) = 2，
L-L 给 Yₙ = (Xₙ−n)/√n →ᵈ N(0,2)；而 Khinchin 大数律给
Xₙ/n →ᵖ 1，Slutsky（30 章）完成 Zₙ = √Xₙ−√n =
Yₙ/(1+√(Xₙ/n)) →ᵈ N(0,1/2)。**同一对象两种正则化两种极限**
——CLT + WLLN + Slutsky 的三件套合奏。

## 52.3 Lindeberg-Feller：充要条件的完全解剖（袁 21.1.4）

**定理 52.E（袁 21.5，古典极限问题的最高成就）。** 独立
（不必同分布），σₙ² = Var Xₙ < ∞，μₙ = EXₙ，Bₙ² = Σσₖ²：
  (i) **Feller 条件** limₙ max_{k≤n} σₖ²/Bₙ² = 0 与
  (ii) (Sₙ−ESₙ)/Bₙ →ᵈ N(0,1)
同时成立的充要条件是 **Lindeberg 条件**（21.1）：∀ε>0，
  limₙ Bₙ⁻² Σₖ E(Xₖ−μₖ)²I{|Xₖ−μₖ| ≥ εBₙ} = 0。

读法：**正态性 = 没有哪一项的方差能成气候**。Feller 条件说
"单项贡献一致渐近可忽略"（即 53 章的无穷小条件）；Lindeberg
说"大偏差对二阶矩的贡献消失"。

**证明解剖（特征函数手术，49 章工具的总决战）。** 归一化
Xₙₖ = (Xₖ−μₖ)/Bₙ（EXₙₖ = 0，ΣEXₙₖ² = 1）。

(i) 一行账：σₖ²/Bₙ² = EXₙₖ²I{|Xₙₖ|<ε} + EXₙₖ²I{|Xₙₖ|≥ε}
≤ ε² + Lindeberg 项 ⟹ max σₖ²/Bₙ² → 0。

(ii) 记 φₙₖ 为 Xₙₖ 的 ch.f.，φₙ = Πφₙₖ 为 ΣXₙₖ 的 ch.f.。
三断言收割：
- **断言 1（(21.3)）**：limₙ max_k|φₙₖ(t)−1| = 0。由
  φₙₖ−1 = E(e^{itXₙₖ}−1−itXₙₖ) 与 Taylor 余项
  |e^{ix}−1−ix| ≤ x²/2（49 章引理 17.40）：
  |φₙₖ−1| ≤ t²σₖ²/(2Bₙ²) ≤ (t²/2)max σₖ²/Bₙ² → 0（用 (i)）。
- **断言 2（(21.5)）**：limₙ{Log φₙ(t) − Σ[φₙₖ(t)−1]} = 0。
  大 n 时 |φₙₖ−1| < 1/2（断言 1），幂级数展开
  Log(1+z) = Σ(−1)^{j−1}z^j/j 合法；余项
  |Rₙ(t)| ≤ max_k|φₙₖ−1|·Σ|φₙₖ−1| ≤ (t²/2)·max|φₙₖ−1| → 0
  （Σ|φₙₖ−1| ≤ t²/2 由 (21.4) 与 Σσₖ²/Bₙ² = 1）。
- **主账**：ρₙ(t) = t²/2 + Σ[φₙₖ(t)−1] =
  ΣE[e^{itXₙₖ}−1−itXₙₖ+(tXₙₖ)²/2]。按 {|Xₙₖ|<ε} 与
  {|Xₙₖ|≥ε} 两段：小段用三阶 Taylor（|余项| ≤ |t|³ε/6·
  ΣEXₙₖ²I{<ε}），大段用二阶（t²ΣEXₙₖ²I{≥ε} = Lindeberg
  项）⟹ |ρₙ(t)| ≤ |t|³ε/6 + t²(1−|t|ε/6)·Lindeberg 项 →
  |t|³ε/6（先 n→∞）→ 0（再 ε→0）。故 Σ[φₙₖ−1] → −t²/2，
  Log φₙ(t) → −t²/2，φₙ(t) → e^{−t²/2}——**Lévy 连续性定理
  （49 章）收割 (ii)**。

"⇒" 方向（Feller 的必要性）：(i) ⟹ 断言 1、2 照旧；(ii) +
连续性定理 ⟹ φₙ → e^{−t²/2} ⟹ Σ[φₙₖ−1] → −t²/2。**取实部**：
t²/2 − ΣE(1−cos tXₙₖ) → 0。按 ε 分两段：小段用
1−cos x = 2sin²(x/2) ≤ x²/2 给出
ΣE(1−cos tXₙₖ)I{<ε} ≤ (t²/2)[1−ΣEXₙₖ²I{≥ε}]；大段用
1−cos x ≤ 2 给出 ΣE(1−cos tXₙₖ)I{≥ε} ≤ 2ΣP{|Xₙₖ|≥ε} ≤
(2/ε²)Lindeberg 项。合并：0 ≤ ΣEXₙₖ²I{≥ε} ≤ (2/t²)[2/ε² +
o(1)]——先 n→∞ 再 |t|→∞ 得 Lindeberg 条件。**取实部一步是
神来之笔**：复值的 φ 账在实部变成非负的 1−cos 账，两段不等式
全部可用。

**注记 52.F（袁 21.8，一致收敛升级）。** Φ 处处连续 ⟹ 弱收敛
加强为一致：sup_x|P{(Sₙ−ESₙ)/Bₙ ≤ x} − Φ(x)| → 0——ESₙ 与
Bₙ² 因此称 Sₙ 的**渐近均值/渐近方差**（分布函数版的全局逼近）。

## 52.4 Lyapunov 条件：最易验的充分条件（袁 21.1.5）

**定理 52.G（Lyapunov，袁 21.9）。** 独立，∃δ>0 使
limₙ Bₙ^{−(2+δ)} Σₖ E|Xₖ−EXₖ|^{2+δ} = 0，则 CLT 成立。

证明一行：Lindeberg 项 ≤ ε⁻δ Bₙ^{−(2+δ)}ΣE|Xₖ−μₖ|^{2+δ}
I{|Xₖ−μₖ|≥εBₙ} ≤ ε⁻δ·(Lyapunov 项) → 0。**δ 阶矩条件比
Lindeberg 好验得多**——工程实践中的首选通行证（1901 年
Lyapunov 的工作正是特征函数方法的封神之作）。

## 52.5 阵列版与统计应用（袁 21.2）

归一化 Xₙₖ = (Xₖ−EXₖ)/Bₙ 提示：真正自然的对象是**三角阵列**
{Xₙₖ, 1≤k≤kₙ, n≥1}。**定义 52.H（条件 (C)，袁 21.10）**：
kₙ→∞、行态独立、零均值、Bₙ² = Σσₙₖ² = 1。

**定理 52.I（经典正态收敛准则，袁 21.11）。** 条件 (C) 下：
(i) lim max σₙₖ² = 0 与 (ii) Sₙ →ᵈ N(0,1) 同时成立 ⟺
lim ΣEXₙₖ²I{|Xₙₖ|≥ε} = 0（阵列 Lindeberg）。

**定理 52.J（Hájek-Sidak，袁 21.12）。** iid + 常数向量 cₙ
满足 max cₙₖ²/Σcₙₖ² → 0 ⟹ 加权和 Σcₙₖ(Xₖ−μ)/(σ√Σcₙₖ²)
→ᵈ N(0,1)。证明：Yₙₖ = cₙₖ(Xₖ−μ)/(σ√Σc²) 满足 (C)，
Lindeberg 项 ≤ σ⁻²E(X−μ)²I{(X−μ)² ≥ ε²σ²Σc²/max c²} → 0
（(21.12) 使阈值 →∞，DCT 收割）。应用：线性回归最小二乘
估计的 CLT（习题 21.16）。

**定理 52.K（阵列 Lyapunov，袁 21.13）。** 条件 (C) +
ΣE|Xₙₖ|^{2+δ} → 0 ⟹ Sₙ →ᵈ N(0,1)。**应用（定理 21.14）**：
核估计的渐近正态——(f̂ₙ(x)−Ef̂ₙ(x))/√Var f̂ₙ(x) →ᵈ N(0,1)
（f、K 有界，x∈C(f)）：Xₙⱼ 取为核项的标准化，三阶矩账
ΣE|Xₙⱼ|³ → 0 由习题 20.33 的 Bochner 极限（J₁ₙ→f(x)∫K³，
J₂ₙ→f(x)∫K²）结清——**51 章核估计的大样本合法性在此闭环**。

**定理 52.L（样本分位数渐近正态，袁 21.16）。** 0<p<1，F 在
F^←(p) 连续，右导数 F'₊(F^←(p)) > 0 ⟹ √n[X_{(⌈np⌉)}−F^←(p)]
→ᵈ N(0, p(1−p)/[F'₊(F^←(p))]²)。证明的**事件等价手术**值得
记住：对 I{Xₖ≤F^←(p)} ~ Bernoulli(p) 用 L-L 得
Wₙ = √n[p−F̂ₙ(F^←(p))] →ᵈ N(0,p(1−p))；分位数事件等价链
（√n[X_{(⌈np⌉)}−F^←(p)] ≤ t ⟺ F̂ₙ^←(p) ≤ F^←(p)+t/√n ⟺
Zₙ,t ≤ √n[F(F^←(p)+t/√n)−p] → tF'₊）把次序统计量翻译成
经验分布语言，再由 Zₙ,t − Wₙ →ᵖ 0（习题 21.17）+ Slutsky
收拢。**"分位数的涨落 = 经验分布的涨落 / 局部密度"**——
密度越大分位数越稳，方差 p(1−p)/f² 直观落地。

## 52.6 多维化与 Delta 方法（袁 21.3）

**定理 52.M（Cramér-Wold，袁 21.17）。** ℝᵏ 值 R.V.：
Xₙ →ᵈ X ⟺ ∀θ∈ℝᵏ，θᵀXₙ →ᵈ θᵀX。"⟸" 用两次连续性定理：
t = 1 代入 θᵀ 的 ch.f. 收敛得 φ_{Xₙ} → φ_X。**一切多维
收敛问题降维成一维**——这是 k 维 CLT 的全部秘密。

**定理 52.N（多维 Lindeberg-Lévy，袁 21.18）。** iid k 维，
EX₁ = μ，Cov X₁ = Σ：(ΣXⱼ−nμ)/√n →ᵈ Nₖ(0,Σ)。证明一行：
Yₙ = θᵀ(Xₙ−μ) 一维 L-L + Cramér-Wold。例 21.19：ℝᵏ 简单
对称随机徘徊 →ᵈ Nₖ(0, k⁻¹Iₖ)（协方差账：EX₁ⱼX₁ₗ = 0
因不同时取非零，VarX₁₁ = 1/k）。

**定理 52.O（Delta 方法，袁 21.20）。** √n(Tₙ−θ) →ᵈ T，
ġ 在 θ 邻域连续 ⟹ √n(g(Tₙ)−g(θ)) →ᵈ ġ(θ)T；特别地
T ~ Nₖ(0,Σ) 时极限是 Nₘ(0, ġΣġᵀ)。证明只有一步**积分型
Taylor**：g(x) = g(θ) + ∫₀¹ġ(θ+v(x−θ))dv·(x−θ)，由
Tₙ →ᵖ θ（习题 12.19）得积分因子 →ᵖ ġ(θ)，Slutsky 收拢。
**"渐近分布的链式法则"**：统计量经光滑变换后的渐近方差 =
梯度左乘右乘。

例 21.21 两则：(1) g = x²：μ≠0 时 √n(X̄ₙ²−μ²) →ᵈ
N(0,4μ²σ²)；μ = 0 时退化，改走 nX̄ₙ²/σ² →ᵈ χ²(1)（定理
12.38）——**梯度为零处 Delta 失效，升一阶 Taylor 接手**；
(2) g = log x：√n(log X̄ₙ−log μ) →ᵈ N(0,σ²/μ²)。

**例 52.P（袁 21.22，样本相关系数的完全账）。** 二维样本，
四阶联合矩存在：Tₙ = (X,Y,X²,Y²,XY)ᵀ 的 5 维 CLT + Delta
（g(x) = (x₅−x₁x₂)/√((x₃−x₁²)(x₄−x₂²))）⟹
√n(rₙ−ρ) →ᵈ N(0,(1−ρ²)²)。方差账全手算：尺度平移不变性
归一到 N₂(0,(1 ρ;ρ 1))；∂g/∂x₁|θ = ∂g/∂x₂|θ = 0，
∂g/∂x₃|θ = ∂g/∂x₄|θ = −ρ/2，∂g/∂x₅|θ = 1；Gauss 四阶矩
（Wick 型：VarXY = 1+ρ²，Cov(X²,Y²) = 2ρ²，Cov(X²,XY) =
2ρ）拼出 Σ，v² = ∇g·Σ·∇gᵀ = (1−ρ²)²。**51 章给强相合，
本章给涨落形状**——同一对象的两章接力。

## 52.7 收敛速度：Esseen 与 Berry-Esseen（袁 21.4）

CLT 只说极限是 Φ；多快？**Esseen（1945）平滑不等式**是全部
速度估计的引擎：

**定理 52.Q（Esseen，袁 21.23）。** sup F'ᵥ ≤ A < ∞ ⟹ ∀T>0，
  sup_x|Fᵤ(x)−Fᵥ(x)| ≤ (1/π)∫_{−T}^{T}|(φᵤ(t)−φᵥ(t))/t|
  (1−|t|/T)dt + 24A/(πT)。

证明的**磨光手术**：Pólya 分布 W_T = W/T（φ_{W_T}(t) =
(1−|t/T|)⁺——三角 ch.f.，密度 (1−cos Tx)/(πTx²)）与 U、V
独立卷积 ⟹ 卷积后的 ch.f. 绝对可积 ⟹ 反演公式 (17.10) 可用：
Δ_T(x) = −(2π)⁻¹∫_{−T}^{T}(φᵤ−φᵥ)(t)/(it)·φ_{W_T}(t)dt，
故 Δ*_T ≤ (2π)⁻¹∫|(φᵤ−φᵥ)/t|dt。再反向：Δ* ≤ 2Δ*_T +
3Δ*P{|W_T| > Δ*/2A}（几何：Δ(x₀+s) ≥ Δ*−As 由 F'ᵥ ≤ A，
在 |y|≤Δ*/2A 的邻域积分），尾部 P{|W_T|>a} ≤ 8A/(πΔ*T)
（(21.26) 的 1−cos ≤ min 账）⟹ Δ* ≤ 2Δ*_T + 24A/(πT)。
**两个误差源：ch.f. 近 → 主项；磨光滑失 → 24A/(πT) 项。**

**引理 52.R（袁 21.24，ch.f. 的精度账）。** 零均值独立，
γₖ³ = E|Xₖ|³ < ∞，βₙ³ = Σγₖ³：|t| ≤ Bₙ³/(4βₙ³) 时
  |φ_{Sₙ/Bₙ}(t) − e^{−t²/2}| ≤ 16(βₙ³/Bₙ³)|t|³e^{−t²/3}。
三区间解剖：(a) 中段 |t| ≤ Bₙ/(2βₙ) 用**对称化**
|φ_{Xₖ}|² = φ_{Xₖˢ}（Xˢ = X−X′，EXˢ³ 账 8γ³）+ 三阶 Taylor
⟹ |φₙ(t)|² ≤ exp(−t²+t²/3) = e^{−2t²/3}；(b) 过渡段用
1 ≤ (8βₙ³|t|³)/Bₙ³ 把 e^{−t²/3} 换出来；(c) 小区间
（σₖ|t|/Bₙ < 1/2）用 Log 展开 + |Log(1−z)+z| ≤ |z|²
（习题 21.24）⟹ Log φₙ = −t²/2 + rₙ，|rₙ| ≤
(61/144)(βₙ³/Bₙ³)|t|³ < 1/18，再 |e^z−1| ≤ |z|e^{|z|}
收割。**对称化 + Log 展开 + 三阶 Taylor——52 章与 53 章
共享的技术栈在此全部亮相。**

**定理 52.S（Esseen 不等式，袁 21.25）。** 引理条件下：
sup_x|F_{Sₙ/Bₙ}(x)−Φ(x)| ≤ 36βₙ³/Bₙ³。（T = Bₙ³/(4βₙ³)，
∫t²e^{−t²/3}dt = 3√(3π)/2，常数账 (24√3/√π +
96/(π√(2π))) ≤ 36。）

**定理 52.T（Berry-Esseen，1941/1942，袁 21.26）。** iid
零均值，γ³ = E|X|³ < ∞：sup_x|F_{Sₙ/(√nσ)}(x)−Φ(x)| ≤
36γ³/(√nσ³)。**CLT 的速率是 1/√n，代价是三阶矩**——
统计推断中" n 多大才够"的定量回答。

习题 21.14/21.15 埋下 55 章的种子：对称 P{|X|>x} = 1/x²
（x≥1，方差不存在！）时 Sₙ/√(n log n) →ᵈ N(0,1)——**截尾
方差 ~log n 接管归一化**；P{|X|>x} = x^{−α}（α∈(0,2)）时
Sₙ/n^{1/α} →ᵈ 非退化 Y——**归一化不再是 √n，极限不再是
正态：稳定分布的预告**。

**Python（`52_clt.py`）**：Fraction 精确账——Dé Moivre-Laplace

## 52.9 历史注记与要点回顾

Dé Moivre（1733）→ Laplace（1812）→ Lyapunov（1901，特征
函数封神）→ Lindeberg（1922，充分性破天荒）→ Feller（1935，
必要性）——二百年浓缩为一条充要条件。Cramér-Wold（1936）
把多维问题降维；Esseen（1945）把"收敛"升级为"速率"。
Berry-Esseen 的最优常数至今仍在改进（36 → 0.47 附近的历史
长坡），但量级 √n 不可改进（格子点分布已达界）。

要点回顾：
1. Lindeberg ⟺ Feller + CLT：正态性 = 单项贡献消失；
   Lyapunov δ 阶矩是最易验的充分通行证。
2. 证明技术栈：Taylor 余项（17.40）+ Log 幂级数 +
   取实部 1−cos 两段账 + Lévy 连续性收割——全部来自 49 章。
3. 阵列版是统计应用的真身：Hájek-Sidak（加权和）、核估计
   渐近正态、分位数 CLT（事件等价手术）。
4. 多维 = Cramér-Wold 降维 + Delta 链式法则；梯度零处
   Delta 失效（χ² 接手）。
5. 速度：Esseen 平滑（Pólya 磨光）→ 36β³/B³ →
   Berry-Esseen 36γ³/(√nσ³)；量级 1/√n 最优。
6. 边界：方差不存在的对称重尾仍可有 CLT 型极限
   （√(n log n) 归一化）或稳定极限（n^{1/α}）——53-55 章
   的入口。
