# 第 55 章 稳定分布（袁 ch24）

54 章的四情形表里最神秘的一行是 0 < α < 2 的稳定极限：
正规化不是 √n 而是 n^{1/α}，极限不是正态而是**稳定分布**。
本章解剖这个族：四特征等价定义、参数化（α,β,γ,δ）、存在性
（α ≤ 2 的第一性证明）、广义 CLT（尾平衡双充要）。

## 55.1 四特征：一个概念的四面（袁 24.1.1）

**定义 55.A（袁 24.1，吸引律四特征）**。分布 μ（或 r.v. X）：
  (a1) **吸引域存在**：iid {Xₖ} ~ μ′，∃aₙ∈ℝ, bₙ>0 使
      (Sₙ−aₙ)/bₙ →ᵈ μ（μ′ 落入 μ 的吸引域）；
  (a2) **卷积封闭**：∀c₁,c₂>0，∃c₃>0, c₄：c₁X₁+c₂X₂ ≡
      c₃X+c₄（线性组合仍是自身的仿射像）；
  (a3) **弱极限封闭**：稳定序列的弱极限仍稳定；
  (a4) **S(a) 型**：μ 非退化，其一切正仿射像的弱极限封闭。
**定理 55.B（袁 24.2）**：四条等价——这就是"稳定"的定义。

**读法**：(a2) 是**代数面**（自相似：两个拷贝的加权和重排
后回到自己——正态的 σ²=σ₁²+σ₂² 是其特例）；(a1) 是**分析
面**（作为极限出现）；(a3) 是**拓扑面**（族闭）；(a4) 是
**结构面**。一个概念四面体，物理里管这叫**标度不变性**——
重整化群的不动点。

**参数化（S(α) 的刻画）**。μ ∈ S(α)（0<α≤2）⟺ ∀n：
X₁+⋯+Xₙ ≡ n^{1/α}X + dₙ（某常数）。指数 α 叫**特征指数**：
- α = 2：正态（唯一有二阶矩的稳定律，例 24.4）；
- α = 1：Cauchy（n 个 Cauchy 的和 ≡ n·Cauchy——除以 n
  而非 √n！）；1−β⟹"零偏"：X ≡ −X；再"严格稳定"：dₙ = 0
  （对称稳定都严格，α≠1 时零偏⟺严格）。
**对称稳定**的 ch.f. 有闭式（定理 24.5）：
φ(t) = exp(−γ|t|^α)（γ>0）——γ 是尺度、|t|^α 是指纹。
α=2 给 e^{−γt²}（正态）、α=1 给 e^{−γ|t|}（Cauchy）。

**下三角群作用**。正仿射 (a,b)：X ↦ (X−a)/b 在分布上的
作用构成群；S(α) 是此群的不动点族——**稳定 = 仿射群的
不动点**（54 章主定理的正规化自由度在此被"模掉"）。

## 55.2 存在性与 α ≤ 2：第一性证明（袁 24.2）

**定理 55.C（袁 24.7/24.8）**。0<α≤2：形如
  φ(t) = exp{−∫(1−cos tx)·(1+x²)/x² σ(dx)}
的 ch.f.（σ 型积分）**存在 ⟺ α ≤ 2**（对称情形）。

证明的**核心一行**（α 上界的第一性来源）：
1 − cos u ≥ u²/2 − u⁴/24 ⟹ 被积下界 ~ t²(1+x²)·I{|tx|≤1}
——∫(1+x²)σ(dx) 在 |x|≤1/|t| 上的部分必须 ~ |t|^{−α+α−2}…
精确地：取 σ(dx) = c x^{−1−α}dx（|x|>1），则
∫(1−cos tx)x^{−1−α}dx ~ |t|^α 当且仅当 **α < 2**；
α = 2 时 x² 项的积分为无穷（∫_1^∞ x^{1−α}dx 发散当
α≥2）⟹ 只有正态分量能救场（e^{−σ²t²/2}）。**为什么
没有 α>2 的稳定律**：假想 α>2 的尾 P{|X|>x} ~ x^{−α}，
则 EX² < ∞ ⟹ CLT 说 √n 正态——与 n^{1/α} 正规化矛盾
（习题 24.2 的反向账：α>2 ⟹ EXᵖ<∞ ∀p<α 与 CLT 相互
拆台）。**α=2 是重尾与轻尾的国境线**。

**稳定 ch.f. 的标准形式（定理 24.6）**：
Log φ(t) = iδt − γ|t|^α(1 + iβ·sgn(t)·tan(πα/2))（α≠1；
α=1 时换成 (2/π)β·sgn(t)·log|t| 的修正形式——α=1 的
对数扭曲是 Cauchy 族与一般稳定的分水岭）。四参数
（α∈(0,2]，β∈[−1,1]，γ>0，δ∈ℝ）= 指数/偏度/尺度/位置。

## 55.3 广义 CLT：尾平衡的双充要（袁 24.3）

**定理 55.D（袁 24.9，Gnedenko-Kolmogorov）**。iid X，
0<α<2，Y 稳定 S(α)（谱 (M,N) 或参数 (c₊,c₋)）：存在
aₙ 使 Sₙ/aₙ − aₙ →ᵈ Y ⟺ **尾平衡**：
  n·P{X > aₙ} → c₊，n·P{X < −aₙ} → c₋（c₊+c₋ > 0），
且 Y 的谱由 M(x) = c₊/α·|x|^α（x<0 侧）与 N(x) =
−c₋/α·x^α（x>0 侧）给出；aₙ 的选取由**变易方程**
aₙ/a_{⌊nt⌋} → t^{1/α} 刻画（正规化自洽——α 由它反解）。

**读法**：n·P{X>aₙ} = P{前 n 项有一项 > aₙ} 的期望个数
——尾平衡说"超过当前正规化尺度的项数收敛到有限的强度"。
这是 52 章 Lindeberg 的重尾版：Lindeberg 管截尾二阶矩的
消失，尾平衡管**截尾一阶尾的兑现**。对称情形
P{±X>x} ~ c/x^α ⟹ Sₙ/n^{1/α} →ᵈ 对称稳定
exp(−c'|t|^α)（例 24.10 六步法的骨架：截尾三和定理 54.F
逐项对账）。

**矩账（定理 24.10 后注）**。极限稳定 α ⟺ 母体满足：
E|X|ᵖ < ∞ ∀p < α；E|X|ᵖ = ∞ ∀p > α（习题 24.2 的反向：
α<2 ⟹ EX² = ∞；习题 24.3：正态 α=2 是唯一 EX²<∞ 的
稳定律）。**α 是尾指数也是矩边界**——与 51 章 MZ 定理的
E|X|ᵖ ⟺ n^{−1/p} 收敛（p<2）严格咬合：**同一个 α，
一个管和的极限（本章），一个管平均的速率（51 章）**。

## 55.4 偏态与例（袁 24.4）

**例 55.E（Cauchy 的 c± 账，例 24.11）**。P{X>x} =
c₊/x、P{X<−x} = c₋/x（x>1，中间任意）：尾平衡成立
（aₙ ~ (c₊+c₋)n），极限是**偏态 Cauchy**
φ(t) = exp{−(c₊+c₋)|t|·(1 + i(c₊−c₋)/(c₊+c₋)·(2/π)
sgn(t)log|t|)}——α=1 的对数扭曲显形。对称输入 c₊=c₋
给标准 Cauchy。

**例 55.F（正态的对偶身份）**。α=2 的稳定 = 正态：它
同时是 (i) CLT 的极限（52 章，轻尾），(ii) 稳定族的边界
成员（本章，α 上确界），(iii) LK 表示中 σ² 分量的纯形态
（53 章）。三重身份同一分布——**正态是三个理论的公共
不动点**。

## 55.5 机器通道

**Lean（`Ch55StableLaws.lean`）**：**分工如实**——mathlib
无稳定分布基础设施（无 StableDistribution、稳定 ch.f.），
但**有 Cauchy 与 Pareto 的测度实现**
（`Probability/Distributions/Cauchy.lean` 的 `cauchyMeasure`
与 `Pareto.lean` 的 `paretoMeasure`）。本章机器侧：两锚点
正名 + 实弹两件——① **Cauchy 密度的归一积分**
（`integral_cauchyPDFReal_eq_one`：∫ 1/(π(1+x²))dx = 1，
1/π 密度的机器原文——Cauchy 是无期望分布（EX 不绝对收敛）
却完美归一的第一公民）；② **Pareto 的 cdf 公式**
（`cdf_paretoMeasure_eq_lintegral`：F(x) = 1−(t/x)^r，
x≥t——广义 CLT 尾平衡的母体实现：r = α 的 Pareto 正是
P{X>x} = (t/x)^α ~ c x^{−α} 的标准重尾）。稳定 ch.f. 的
标准形式与广义 CLT 由 docs 承载。

**Julia（`55_stable_laws.jl`）**：① **Cauchy 稳定性的直接
模拟**：iid Cauchy（tan(π(U−1/2)) 采样）的 Sₙ/n 的 IQR 在
n = 5 与 n = 80 间不动（1.95→1.98，理论 2——α=1 的判决性
显影）；② **α=1.5 对称稳定的 LePage 级数采样**
（X = Σ±Γₖ^{−1/α}，Γₖ 泊松时序——数学上严格的构造；实测
坑：CMS 公式的手写回忆版产出高斯行为（P{|X|>100}=0 且 √n
稳定），弃用改道）：n^{1/α} 归一化下 IQR 稳定（3.45→3.57）
而 √n 归一化下**膨胀**（4.55→7.38——α<2 ⟹ n^{1/α} > √n，
√n 是不足归一化使分布发散）；③ **广义 CLT 的刻度显影**：
Pareto(1,1.5) 母体的和在 n^{2/3} 刻度下 IQR 饱和
（2.72→3.18→3.45）；④ **矩边界的精确账**：Cauchy 的截尾
二阶矩 = (2/π)(m−arctan m) 的线性增长（m=50: 31.0 vs 理论
30.8；m=200: 130.5 vs 126.3）vs 正态的恒 1。
**Python（`55_stable_laws.py`）**：① 对称稳定密度的数值
反演（LK 积分 → pdf，α = 0.5/1/1.5 与 α=2 正态的对照表）；
② 尾平衡常数的精确账（Pareto(1,α) 的 P{X>aₙ} 分数）；
③ 矩边界账：E|X|ᵖ 分数积分在 p≶α 两侧的敛散判决。
**Prolog（`55_stable_laws.pl`）**：① 四特征等价的有限
模型对照（两点/三点分布逐条检验四特征的哪条破产）；② aₙ
变易方程 aₙ = C·n^{1/α} 的数值核对（α=1/1.5/2 三档）；
③ 对称稳定 ch.f. 的 |t|^α 指纹判决（α 由 t 网格上的
−log|φ|/log|t| 反解）。

## 55.2.5 稳定 ch.f. 标准形式的读法

四参数的**分工**要记牢：α（指数）管尾与归一化（n^{1/α}）；
β（偏度 ∈ [−1,1]）管两尾的不平衡（c₊−c₋）；γ（尺度）是
竖向拉伸；δ（位置）是平移。**α=1 的特殊性**在于 tan(πα/2)
发散——标准形式必须换成对数扭曲 (2/π)β sgn(t) log|t|：偏态
在 α=1 处不再是一个有限的 β 旋转，而是对数漂移——这是
Cauchy 族与一般稳定族的真正分水岭（例 55.E 的偏态 Cauchy
显形了这个对数项）。

**与 LK 表示的对账**（53 章）：稳定律是 i.d. 的特例——其
Lévy 测度 μ(dx) = (c₊ x^{−α−1} 1_{x>0} + c₋ |x|^{−α−1}
1_{x<0})dx（幂律谱！）+ σ² 分量（仅 α=2 非零）。**稳定 =
幂律谱的 i.d.**：一切稳定的复杂性浓缩在谱的幂指数与两尾
配比两个数里。

## 55.5.5 实验断言清单（数值通道验收单）

1. **Cauchy 不变性（α=1）**：iid Cauchy 的 Sₙ/n 的 IQR 在
   n = 5/80 间不动（1.95→1.98，理论 2）；
2. **LePage 表示的稳定性（α=1.5）**：n^{1/α} 归一化下 IQR
   稳定（3.45→3.57）；√n 归一化下膨胀（4.55→7.38）——
   错误刻度使分布发散（实测坑：CMS 公式的手写回忆版产出
   高斯行为，弃用）；
3. **广义 CLT 刻度**：Pareto(1,1.5) 的和在 n^{2/3} 下 IQR
   饱和（2.72→3.18→3.45——从下逼近稳定 IQR）；
4. **矩边界**：Cauchy 截尾二阶矩 = (2/π)(m−arctan m) 线性
   增长（m=50: 31.0 vs 30.8；m=200: 130.5 vs 126.3）；
   正态的恒 1——α=1 与 α=2 的矩账分离；
5. **密度反演**（Python）：exp(−|t|^α) 的 LK 反演在
   α = 1/1.5/1.9 归一（含截断尾损），α=1 的 f(0) = 1/π 精确。

## 55.5.8 习题账单（袁 24.4 精选）

- **24.1（S(α) 的等价刻画）**：参数化的自洽（仿射群作用
  下 (α,β,γ,δ) 的变换律——位置/尺度吸收、α/β 不变）；
- **24.2（矩账的正反两向）**：α<2 ⟹ EX² = ∞（反向：EXᵖ<∞
  ⟺ p<α）——与 51 章 MZ 定理的 p 域严格咬合；
- **24.3（正态的孤立性）**：EX²<∞ 的稳定律只有正态
  （α=2 行的完全刻画）；
- **24.4（Cauchy 的 c± 对账）**：偏态 Cauchy 的对数扭曲
  项 (2/π)β sgn(t) log|t|——α=1 的特殊性；
- **24.5（严格稳定与中心化）**：零偏 ⟺ 严格（α≠1）的
  常数 dₙ 何时可吸收。

## 55.6 历史注记与要点回顾

Lévy（1925，博士论文）在 Cauchy 与正态之间发现连续谱系
（Lévy 分布 α=1/2 出现在 Brown 首中时）；Khinchin-Levy
（1936）给出稳定 ch.f. 的四参数形式；Gnedenko（1939）与
Kolmogorov 完成广义 CLT 的尾平衡刻画。稳定分布的现代生命
在金融（Mandelbrot 1963：棉价收益是 α≈1.7 稳定——重尾
革命）与物理（Lévy 飞行、 anomalous diffusion）。

要点回顾：
1. 稳定 = 仿射群不动点（四特征等价）：自相似 + 吸引域 +
   闭性 + S(a) 型。
2. 对称稳定 ch.f. = exp(−γ|t|^α)；α≤2 的第一性证明是
   x² 积分的发散墙（α>2 ⟹ EX²<∞ ⟹ CLT 拆台）。
3. 广义 CLT：尾平衡 n·P{±X>aₙ}→c± ⟺ 稳定极限；谱
   (M,N) 由 (c₊,c₋) 显式给出；aₙ 变易方程定 α。
4. 矩账：E|X|ᵖ<∞ ⟺ p<α——α 同时是尾指数与矩边界，
   与 MZ 定理的 p<2 严格咬合。
5. 正态的三重身份（CLT 极限/稳定边界/LK 纯分量）。
6. 机器侧：Cauchy 归一与 Pareto cdf 的 mathlib 实弹；
   CMS 采样与 LK 反演的数值通道。
