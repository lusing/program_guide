# 08 函数形式的单调类定理

**对应严书 §2.2（pp. 31-37）。**

---

## 8.1 动机：从"集合的定理"到"函数的定理"

第 02 章解决了：两个测度在 π-系上相等 ⟹ 处处相等。但应用里更常
见的句式是**函数版**：*已知某类函数满足性质 P（如积分交换极限、
可在乘积测度下用 Fubini），要证所有可测函数满足 P*。集合版的
"λ-类"搬到函数世界就是**λ-族**，π-π 对应变成"示性函数当桥"。
本章把第 02 章的引擎在函数层面重装一遍，并给出三条可替换使用的
定理形态（严书 2.2.4 乘积版、2.2.7 单调族版、2.2.3 注记的检查单版）。

## 8.2 λ-族：函数世界的 λ-类

**定义（λ-族，严书 2.2.1）** Ω 上的非负实值函数族 H 称为 λ-族，若：

1. 1 ∈ H；
2. f ∈ H, α ∈ ℝ₊ ⟹ αf ∈ H；f, g ∈ H, f ≥ g ⟹ f − g ∈ H；
3. fₙ ∈ H, 0 ≤ fₙ ↑ f 且 f **有界**（另一形态：有限）⟹ f ∈ H。

与集合 λ-类的逐条对照：1 ↔ Ω ∈ λ；差 ↔ 真差（g ⊆ f 时 f−g ↔
f∖g）；单调极限 ↔ 升列并。**注（严书 2.2.3）**：λ-族自动对**加法**
封闭——技巧是常量垫底：f + g ≤ C 时
f + g = C − [(C − f) − g]，第 1、2 条两次出手（C − f ≥ g ≥ 0）。
这一行"垫高再减"在第 14 章处理 L∞ 荷时还会出场。

记 Λ(C) = 含 C 的最小 λ-族，C^t = 有界 σ(C)-可测非负函数全体。
目标是给"C 小小地封闭一点 ⟹ Λ(C) = C^t"的判据。

## 8.3 乘积形式（严书 2.2.4）

**定理** 对非负有界函数族 C：Λ(C) = C^t ⟺ f, g ∈ C ⟹ fg ∈ Λ(C)。

**证明的两阶段自举**（每个阶段都是"证明 G 是 λ-族 ⟹ G 撑满"）：

- **阶段一**：G₁ = {f ∈ Λ(C) : ∀g ∈ C, fg ∈ Λ(C)}。验证 G₁ 是
  λ-族（乘积与 λ-运算的相容性逐条核对），且 G₁ ⊇ C（定理假设），
  故 G₁ = Λ(C)：**Λ(C) 的每个成员乘 C 的成员仍在 Λ(C)**。
- **阶段二**：G₂ = {f ∈ Λ(C) : ∀g ∈ Λ(C), fg ∈ Λ(C)}。同法
  G₂ = Λ(C)：**Λ(C) 对乘法封闭**。

集合部分：F := {A ⊆ Ω : I_A ∈ Λ(C)}。由阶段二，F 对交封闭
（I_A I_B = I_{A∩B}），又直接是 λ-类——**F 既 λ 又 π，故是 σ-代数**
（第 02 章的 π-λ 定理原样回放！）。于是 F ⊇ σ({A : I_A ∈ Λ(C)})，
而后者恰是 σ(C)（示性函数在 C 中 ⟹ [f > a] ∈ σ(C) 型论证）。

下确界 f∧g 落入 Λ(C) 用的是**平方根迭代**：先归一化 |f−g| ≤ 1，
令 P₀ = 0、Pₙ₊₁(t) = Pₙ(t) + (t − Pₙ(t)²)/2——多项式序列
Pₙ(t) ↑ √t（t ∈ [0,1]，不动点方程 x = x + (t − x²)/2 即 x² = t，
从 0 出发的 Newton 式迭代单调上升）。把 t 换成已落入 Λ(C) 的
(f−g)²：Pₙ((f−g)²) 逐个是 Λ(C) 中元的线性与乘积组合，单调升到
|(f−g)|，λ-条件的第 3 条收口，f∧g = (f+g−|f−g|)/2 到手。
**"闭包里造根号"是函数单调类技术的招牌动作**——格运算不直接
可用时，用多项式迭代逼近连续函数。

## 8.4 单调族形式（严书 2.2.6-2.2.7）

**定义** 有界函数族 H 为**单调族**，若它对一致有界单调序列的极限
封闭。M(C) := 含 C 的最小单调族；L_b(C) := 有界 σ(C)-可测函数全体。

**定理（严书 2.2.7）** M(C) = L_b(C) ⟺ M(C) 满足：1 ∈ M(C)；
f ∈ C, α ∈ ℝ ⟹ αf ∈ M(C)；f, g ∈ C ⟹ f + g, f ∧ g ∈ M(C)。

证明的自举结构与 8.3 同型（H₁、H₂ 两步撑满，得 M(C) 是线性格），
集合落点换成 F = {A : I_A ∈ M(C)} 是**代数**；"C 中元 F-可测"用
截断函数 fₙ = n(f − a)⁺ ∧ 1 ∈ M(C) 单调升到 I_{[f>a]}，得
[f > a] ∈ F。最后一击仍是二进网格：F-可测有界函数被简单函数
（M(C) 中示性的线性组合）一致逼近，M(C) 的单调封闭收口。

三种形态的关系：λ-族版（非负、差封闭）与单调族版（有界、格封闭）
互为对方的开胃菜；乘积版在两边都能证。**选用法则**：要证的性质
对乘法自然封闭（如"积分 = 二重积分"）用 2.2.4；对格与极限自然
封闭（如" Fatou 不等式成立"）用 2.2.7。

## 8.5 检查单版：日常应用的形态

实际使用时最顺手的是严书 2.2.3 注记（定理 2.2.1 的另一形式）：

> 设 C 为 π-类（对交封闭），H 为非负函数族，满足：
> (1) 1 ∈ H；(2) αf ∈ H、f ≥ g ∈ H ⟹ f − g ∈ H；
> (3) 0 ≤ fₙ ↑ f 有界 ⟹ f ∈ H；(4) ∀A ∈ C, I_A ∈ H。
> 则 H ⊇ 一切非负 σ(C)-可测函数。

使用范式（全书至少五次返场）：**要证"一切可测函数有性质 P"，
令 H := {f ≥ 0 : P(f)}，验四条**——前三条通常是 P 的代数性质
（线性、单调极限），第 4 条是"最简单情形"（示性函数，往往手算）。
第 11 章单调收敛定理的推广、第 18 章 Fubini、第 36 章条件期望的
唯一性，走的全是这条流水线。对照第 02 章："验集合的相等 ⟹ 换成
验函数的属于"，两章是同一台引擎的两个排气管。

为什么 C 必须是 π-类：阶段一的乘法封闭在集合侧恰是 I_A·I_B =
I_{A∩B}——**函数乘法 ↔ 集合相交**。C 不封闭于交，则示性函数们
的乘积飞出 H 的保证范围，链条断在第一环。Prolog 实验将给出
"非 π-类上定理失效"的有限反例。

**集合版与函数版的逐行对照**（第 02 章 ↔ 本章，一台引擎两张皮）：

| 集合版（第 02 章） | 函数版（本章） |
|---|---|
| π-系（对交封闭） | π-类 C + 示性函数 I_A 当桥 |
| λ-类（Ω ∈；真差；升列并） | λ-族（1 ∈；锥 + 差；有界升列极限） |
| λ(C) = 最小 λ-类 | Λ(C) = 最小 λ-族 / M(C) = 最小单调族 |
| λ(C) = σ(C) 判据：C 是 π-系 | Λ(C) = C^t 判据：C 中乘积落入 Λ(C) |
| 引擎：既 λ 又 π ⟹ σ-代数 | 引擎：两阶段自举 G₁ → G₂ |
| 应用：测度相等、独立性（35 章） | 应用：积分定理、Fubini、条件期望 |

对照表最后一列预告了全书五次大返场：第 11 章推广单调收敛、第 18
章 Fubini 的"先简单后极限"、第 36 章条件期望唯一性、第 35 章独立性
判据、第 31 章 Portmanteau 的检验函数族——每一次都是"验四条检查单"
的机械重复。**学透本章，等于给全书一半的证明预付了模板费。**

## 8.6 Lean：π-λ 引擎的机器本体与有限函数模型

侦察结论（PLAN 锚点表修正）：mathlib **有**集合版的机器本体
`MeasurableSpace.induction_on_inter`（`MeasureTheory/PiSystem.lean:692`，
用 `DynkinSystem.GenerateHas` 归纳原理实现）：

```lean
/-- 若 π-系 s 生成 m，且谓词 C 在 ∅、s 的成员、可测补、可数不交并下
封闭，则 C 对一切 m-可测集成立。 -/
theorem MeasurableSpace.induction_on_inter {m : MeasurableSpace α}
    {C : ∀ s : Set α, MeasurableSet s → Prop} {s : Set (Set α)}
    (h_eq : m = generateFrom s) (h_inter : IsPiSystem s)
    (empty : C ∅ .empty) (basic : ∀ t (ht : t ∈ s), C t _)
    (compl : ∀ t (htm : MeasurableSet t), C t htm → C tᶜ htm.compl)
    (iUnion : ∀ (f : ℕ → Set α), Pairwise (Disjoint on f) → ...) :
    ∀ t (ht : MeasurableSet t), C t ht
```

这正是"谓词 C 版 π-λ 定理"——本章函数定理的集合引擎。mathlib
**没有**函数形式单调类定理的直接打包（`Measurable` 的格封闭在新版
交给 `fun_prop`，逼近走 `SimpleFunc` 系列），所以
`Ch08FunctionalMonotoneClass.lean` 的方案是三件套：

1. 用 `induction_on_inter` 现场重放经典应用——ℝ 上两个**有限**
   测度在有理射线 π-系上相等 ⟹ 相等（谓词 C t := μ t = ν t），
   作为引擎点火演示；
2. 严书 2.2.3 注"垫高技巧"的机器版：含常值 1、锥封闭、差封闭的
   函数族自动对加法封闭（f + g = C − [(C − f) − g]，三次差封闭，
   序关系全部 `linarith` 可解）；
3. f ∨ g = (f + g + |f − g|)/2 的格公式件：换写公式后一行
   `fun_prop`——函数格封闭的代数内核一目了然。

重放（1）时机器抓出一个**真数学细节**：补集一步需要
μ tᶜ = μ Ω − μ t，两测度在 π-系上相等并不自动给 μ Ω = ν Ω！
必须先证总质量相等（⋃ₙ Iic ↑n = ℝ，下方连续取极限，
`iSup_congr` 收口）——这正是第 06 章唯一性定理里"σ-有限穷竭
列"承担的工作，机器不收含糊账。

## 8.7 数值与逻辑实验：闭包迭代的收敛

**Julia（`08_functional_monotone_class.jl`）**在 Ω = {1,2,3,4} 上
做函数格闭包的浮点/整数版：取 π-类 C = {∅, {1,2}, Ω}（对交封闭），
从示性函数 {0, I_{12}, 1} 出发迭代"线性组合 + f∧g + 单调序列极限
（有限空间上 = 简单封箱）"，第一步就稳定在 8 个函数
{a·I_{12} + b·I_{34} : a, b ∈ 标尺} 的格上——恰好是有界
σ(C)-可测全体（σ(C) = {∅,{12},{34},Ω}，可测函数 = 按块常数）。
对照实验：取**非 π** 类 C = {{1,2},{2,3}}，同样迭代得到的封闭族
严格大于"按块常数"函数——但 σ(C) 变成全幂集（{2} = {12}∩{23}
可生成），L_b(C) 也变大，最终仍追平——这正是定理的微妙之处：
**π-性保证的是 Λ(C) = C^t 的"省力判据"，不是相等本身**。实验
按"最小 λ-族按元素计数"两条路径（从 C 直接做 λ-闭包 vs 从
L_b(C) 回收）对拍，展示判据的边界。

**Python（`08_functional_monotone_class.py`）**把同一实验做成**精确
有理数**版：函数值取自 {0, 1/2, 1} 标尺，闭包迭代无浮点误差；
并对"两阶段自举"做了独立复刻——先算 {f : ∀g∈C, fg ∈ Λ} 再算
乘法封闭族，验证两步后乘法封闭恰追平 L_b(C)（有限空间上以元素
集合相等断言）。平方根迭代也顺带数值演示：Pₙ 从 0 逼近 √α 的
逐层误差，见证"闭包里造根号"的收敛速度。

**Prolog（`08_functional_monotone_class.pl`）**做同一实验的符号版：
函数表示为值向量，闭包算子在表上定义，π-类与非 π-类两种进料，
输出闭包规模与 L_b(C) 规模的对比表。

## 8.8 要点回顾

1. 函数单调类定理 = 集合 π-λ 定理的函数层重装；示性函数是两层
   之间的电梯（I_A I_B = I_{A∩B}）。
2. 三种形态：λ-族乘积版（2.2.4，两阶段自举 + 平方根迭代
   Pₙ₊₁ = Pₙ + (t − Pₙ²)/2 → √t）、单调族格版（2.2.7，截断 +
   二进网格收口）、检查单版（2.2.3 注，日常应用形态：验四条——
   1 ∈ H、锥+差、有界单调极限、π-类指示函数）。
3. 自举结构"证明 G 是 λ-族 ⟹ G 撑满"是三版共用的证明引擎；
   集合落点"既 λ 又 π ⟹ σ-代数"回放第 02 章。垫高技巧
   （f + g = C − [(C − f) − g]）是 λ-族内部的加法发电机。
4. C 的 π-性是判据的钥匙而非结论的边界；机器通道在有限模型上
   把这条边界摸了一遍（π：闭包 9 == L_b 9；非 π：9 ≪ 81，
   乘积指示 I₂ 缺席）。
5. mathlib 锚点：`MeasurableSpace.induction_on_inter`（PiSystem.lean）
   是集合版机器本体；函数版以垫高件与格公式件自造；重放时机器
   抓出"补集一步需要总质量相等"的隐含工序（第 06 章穷竭列的伏笔）。
6. 下一站：第 09 章的收敛方式矩阵里，"依测度收敛序列可提取 a.e.
   骨架"的证明正是本章自举思想与 Borel-Cantelli 的合奏。
