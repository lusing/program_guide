# 01 集合运算与集类

**对应严书 §1.1（pp. 1-6）。**

---

## 1.1 为什么第一章不谈"测度"却谈"集合的家族"

测度论要回答的问题是：给一族集合指定"大小"。但指定大小之前，先得问：
**这些集合生活在一个什么样的家族里？** 家族对集合运算的封闭性，决定了
"大小"能被怎样地计算——有限次运算够不够、要不要取极限、能不能求补。

举个预览性的例子：长度之所以能算，是因为区间的差不交分解后仍是区间
的有限并（区间族是**半环**）；概率之所以能加，是因为事件族对补与可数并
封闭（**σ-代数**）。本章的任务就是把"家族的封闭性等级"整理成一张地图：
半环 ⊂ 环 ⊂ 代数 ⊂ σ-代数，以及两条旁路：π-系与 λ-系（下一章的主角）。

## 1.2 集合运算的语言

设 Ω 为全集（测度论里常写作基本空间）。对集列 {Aₙ}，回忆：

- **上极限**：lim sup Aₙ = ⋂ₙ ⋃_{k≥n} Aₖ = {ω : ω 属于无穷多个 Aₙ}；
- **下极限**：lim inf Aₙ = ⋃ₙ ⋂_{k≥n} Aₖ = {ω : ω 至多不属于有限多个 Aₙ}；
- 单调列的极限：Aₙ ↑ A 时记 A = ⋃Aₙ；Aₙ ↓ A 时记 A = ⋂Aₙ。

一个处处用到的技巧（严书 1.1.5）：**把可列并改写成可列不交并**。令
B₁ = A₁，Bₙ = Aₙ \ (A₁ ∪ … ∪ Aₙ₋₁)（n ≥ 2），则 Bₙ 两两不交且
⋃Bₙ = ⋃Aₙ。第 02 章证明 λ 类封闭性与第 03 章证明测度可加性时，这个
"不交化"技巧都会反复出场。

严书还引入了一组紧凑记号（值得熟悉，读文献常见）：

- C_δ：对可列交封闭所得的类；C_σ：对可列并封闭；C_nf / C_uf：对有限交 /
  有限并封闭；C_σf：对可列不交并封闭。于是 "G_δ 集" = 开集类取 C_δ，
  "F_σ 集" = 闭集类取 C_σ——拓扑与测度的第一处握手。

## 1.3 集类家族：从半环到 σ-代数

以下定义全部针对集类 C ⊆ 2^Ω（约定非空）。

**定义 1（半环）** C 是半环，若：∅ ∈ C；A, B ∈ C ⟹ A ∩ B ∈ C；
且 A \ B 可写成 C 中**有限个两两不交**成员之并。

**定义 2（环）** C 是环，若 ∅ ∈ C 且对差与有限并封闭。（等价地：对差不
交化后的有限不交并封闭。）环里的集合"大小"可以有限次加减。

**定义 3（代数）** C 是代数，若 Ω ∈ C 且对补与有限并封闭。代数 = 含 Ω
的环。注意：代数对**可数**并未必封闭——有限 Ω 上无区别，无限 Ω 上有
天壤之别。

**定义 4（σ-代数 / σ-环）** 对补（含 Ω）与**可数**并封闭。σ-代数是测度
的天然居所：可数可加性要求运算域对可数并封闭，缺一点都不行。

**定义 5（π-系）** 对**二元交**封闭（有的教材还要求非空）。π-系是"最小
限度"的封闭性——下一章将看到，配合 λ-系它有惊人的威力。

**最重要的例子与反例**（这张表值得反复回看）：

| 集类 | 是半环？ | 是环？ | 是 σ-代数？ |
|---|---|---|---|
| ℝ 上形如 (a, b] 的区间 + ∅ | ✓ | ✗（两区间之并可能断开） | ✗ |
| ℝ 上有限个不交区间之并 | ✓ | ✓（环！） | ✗（可数并可能出开集） |
| ℚ 的有限子集全体 | ✓ | ✓ | ✗ |
| ℚ 的子集全体 | ✓ | ✓ | ✓ |
| {∅, A, Aᶜ, Ω}（A 固定） | ✓ | ✓ | ✓ |
| 可数-余可数集类 | ✗ | ✗ | ✓ |

最后两行提醒我们：等级之间没有简单的线性包含，σ-代数可以很"瘦"
（4 个成员）也可以很"胖"（整个幂集）。

**为什么半环重要？** 因为它是"能承载预测度"的最经济结构：在半环上，
只要给每个成员一个非负数并验证有限可加（在半环内可表出的那些不交并
上），第 04 章的 Carathéodory 机器就能把它扩张成 σ(半环) 上的完整测度。
Lebesgue 测度的旅程就是：给区间赋长度 →（半环上的预测度）→ 外测度 →
限制到可测集 → 完备化。

## 1.4 生成：σ(C) 与最小性

对任意集类 C，存在包含 C 的最小 σ-代数 σ(C)——所有包含 C 的 σ-代数
之交。这个定义看似平淡，实则是全书的发动机：**Borel σ-代数 ℬ(ℝⁿ) :=
σ(开集)**，随机变量的可测性 σ(X) := σ({X⁻¹(B)})，都由它定义。

Lean 里这就是 `MeasurableSpace.generateFrom`，其最小性表述为
`generateFrom_le`：若 C 中每个成员都在某可测空间 m 中可测，则
σ(C) ≤ m。我们在 Lean 通道验证了这条最小性，以及"区间族 {(a,b]} 是
π-系"：

```lean
example : IsPiSystem {s : Set ℝ | ∃ a b : ℝ, s = Set.Ioc a b} := by
  intro s hs t ht _
  obtain ⟨a, b, rfl⟩ := hs
  obtain ⟨c, d, rfl⟩ := ht
  show ∃ a' b' : ℝ, Set.Ioc a b ∩ Set.Ioc c d = Set.Ioc a' b'
  exact ⟨max a c, min b d, Set.Ioc_inter_Ioc⟩
```

这段证明在做的事：两个左开右闭区间的交还是左开右闭区间——交的左端点
取 max、右端点取 min（`Set.Ioc_inter_Ioc`）。注意 2026 版 mathlib 的
`IsPiSystem` 采用了一个**较弱**的约定：只要求**非空**交封闭（第三个
前提 `_` 我们直接丢弃）；标准教材（含严书）的 π-系要求所有交封闭。
用库时看清约定，是形式化的日常。

## 1.5 机器视角：闭包的枚举实验

集类的封闭性在有限宇宙上可以**穷举验证**。Julia 通道
（`examples/julia/01_setclasses.jl`）在 Ω = {1,…,6} 上把区间半环
的全部性质跑了一遍，核心是闭包迭代：

```julia
function closure_disjoint_union(C)
    S = Set(C)
    changed = true
    steps = 0
    while changed
        changed = false
        steps += 1
        for u in collect(S), v in collect(S)
            if (u & v) == 0 && !((u | v) ∈ S)
                push!(S, u | v)
                changed = true
            end
        end
    end
    S, steps
end
```

这段代码反复把"两两不交成员的并"加进类里，直到不动点。输出告诉我们：

```
区间族对交封闭（π-系）: OK，共 22 个成员
半环条件（差≤2 片不交区间）: OK
反例：{1,2} ∪ {4,5} ∉ C —— 区间半环不是环
C_uf 闭包：22 → 64 个成员，2 轮迭代到不动点
∪ 闭包同样 64 个成员（两闭包一致: OK）
```

读数：22 个区间（含 ∅），两轮不交并封闭化后变成全部 64 = 2⁶ 个子集
——在有限宇宙上，区间半环"差一点"就是幂集；而不交并闭包与普通并闭包
**给出同一个结果**（因为差可以由交与补表出，两者在不动点处汇合）。
Python 通道（`01_setclasses.py`）用 `frozenset` 与字典去重独立实现
了同一实验，结论逐条一致——双引擎对拍的意义就在于此：一个引擎的
实现 bug（比如我们第一版 Julia 里 `UInt8(1) << k` 的类型提升错误）
会被另一个引擎暴露。

Prolog 通道（`01_setclasses.pl`）则把"差分解"变成了搜索问题：
区间 (1,4] \ (2,3] = {2,4} 是否能写成**两片不交区间**之并——
Prolog 的回溯恰好是"找出所有两片组合并检查覆盖"的天然语义：

```prolog
union_two_pieces(C, D) :-
    member(U, C), member(V, C), disjoint(U, V),
    union_(U, V, W), seteq(W, D).
```

调试这章的 Prolog 时踩了一个值得记录的坑：最初自写的 `mem/2` 谓词
第一子句放了 cut（`mem(X,[X|_]) :- !.`），结果搜索把成员关系的第一
个解钉死、后续解被剪掉，闭包计算"失明"。**可回溯枚举必须用标准
`member/2`**——这是 cut 语义的经典陷阱。

## 1.6 三个练手例子（自包含演算）

**例 1（可数-余可数 σ-代数）** Ω 任意，C := {A ⊆ Ω : A 可数或 Aᶜ 可数}。
验证它是 σ-代数：设 Aₙ ∈ C。若全部 Aₙ 可数，则 ⋃Aₙ 可数 ∈ C；若某
Aₙ₀ 的余集可数，则 (⋃Aₙ)ᶜ = ⋂Aₙᶜ ⊆ Aₙ₀ᶜ 可数，故 ⋃Aₙ ∈ C。补封闭
由定义自反。这个 σ-代数在不可数 Ω 上严格介于 {∅, Ω} 与幂集之间，
是"最小有意思"的 σ-代数样板。

**例 2（生成 σ-代数的逐级生长）** 取 Ω = ℝ，C = {(a, ∞) : a ∈ ℝ}。
则 σ(C) 包含：交 (a,∞) ∩ (b,∞) = (max, ∞)；补 (−∞, a]；于是开区间
(a, b) = (a, ∞) ∩ (−∞, b)；于是一切开集（开集 = 可数个开区间并）；
于是 σ(C) = ℬ(ℝ)。反过来用闭集、用 [a, b)、用有理端点区间做生成系，
得到的都是同一个 ℬ(ℝ)——**Borel σ-代数的"多面性"**是第 23 章（拓扑
预备）的入场测试。

**例 3（不交化的手工演算）** 取 A₁ = {1,2}, A₂ = {2,3}, A₃ = {3,4}。
按 B₁ = A₁, B₂ = A₂ \ A₁, B₃ = A₃ \ (A₁ ∪ A₂)：
B₁ = {1,2}，B₂ = {3}，B₃ = {4}——两两不交，并 = {1,2,3,4} = ⋃Aₙ。
注意 2 被并进了 B₁，3 归 B₂：**每个元素归入它首次出现的片**。这个
"首次出现"原则在 Prolog 通道的强归纳证明（第 02 章）与测度的
可加性证明里都会正式化。

## 1.7 严书习题选讲的两条线索

习题 1.1 的两个方向值得记住：

- **De Morgan 的对偶训练**：把"对交封闭"的类取余，得"对并封闭"的类
  （作用于余类）。第 02 章证明 λ 类补封闭、第 04 章 Carathéodory 补
  封闭，全靠这个对偶。
- **极限运算的交换**：lim sup 与 lim inf 对集合运算的分配律（交并的
  de Morgan 配合量词移动），例如 A ∩ lim sup Bₙ = lim sup (A ∩ Bₙ)。
  Egorov 定理（第 09 章）的证明将一次性动用六七条这类恒等式——在
  本章把它们当消遣练熟，届时才不会在符号堆里迷路。



1. 封闭性等级：半环（差不交分解）→ 环（差 + 有限并）→ 代数（+Ω 与补）
   → σ-代数（+可数并）。旁路：π-系（交）、λ-系（Dynkin，下一章）。
2. σ(C) 由最小性定义；Borel σ-代数 = σ(开集)。
3. 区间族是半环不是环；"不交化技巧"（可列并 → 可列不交并）贯穿全书。
4. 有限宇宙的枚举实验是集类概念的"可计算影子"：22 → 64 的闭包增长、
   半环反例、两闭包汇合，都能逐位验证。
