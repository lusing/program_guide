## 28.1 两个世界的乘积对账

第 18 章在抽象 σ-有限测度上造了乘积测度；本章在**拓扑世界**
重新对账：X, Y 为 LCH、μ, ν 为 Radon 测度，则

1. **σ-代数层**：B(X) ⊗ B(Y) = B(X × Y)（第 23 章对齐，
   第二可数免费、一般 LCH 也要成立——box 拓扑基的紧穷竭
   论证）；
2. **测度层**：μ ⊗ ν（第 18 章造的）是 Radon 测度——正则性
   在乘积中传递；
3. **积分层**：Fubini/Tonelli 对 Radon 乘积照常营业
  （μ ⊗ ν σ-有限性由紧穷竭传递）。

**唯一性口径升级**：抽象层（第 18 章）π-系唯一性给
"σ-有限延拓唯一"；拓扑层多出**Radon 唯一性**——两个 Radon
测度若在 C_c(X×Y) 上同账，则相等（RMK 唯一性的乘积版）。
两条唯一性在此合流。

## 28.2 Radon 传递的证明骨架（严书 5.6.2-5.6.4）

**紧有限性**：K ⊆ X×Y 紧 ⟹ 投影紧 ⟹ K ⊆ K₁×K₂（紧乘积）
⟹ (μ⊗ν)(K) ≤ μ(K₁)ν(K₂) < ∞（紧有限由双方紧有限传递——
矩形账的单调性一步）。

**外正则**：乘积开集 W 是 box 之并；σ-有限穷竭 + 第 18 章
外测度账（μ⊗ν)(W) = inf Σμ(Aₙ)ν(Bₙ)）逐步夹逼——把开集
的账压到 box 账的下确界，每个 box 的开逼近由 μ、ν 的外正则
接力。

**内正则（关键步骤，用截口一致连续引理）**：严书 5.6.5
引理：**T 紧、f ∈ C(S×T) ⟹ 对每个 s₀ 及 ε，存在 s₀ 的开
邻域 U 使 |f(s,t) − f(s₀,t)| < ε 对一切 s ∈ U, t ∈ T**——
连续性在紧因子上"一致地"传递到另一因子的邻域。用它把
K 的内接"乘积紧集"的账顶上去：对 W ⊇ K（W 开），构造
紧 K₁×K₂ ⊆ W 吸收 (μ⊗ν)(W) − ε 的质量（磨光 + 截口引理
的双因子迭代）。∎

**这条截口引理是本章的技术心脏**——它就是"紧性 = 一致
连续性的拓扑供应商"（Heine-Cantor 的高维版），第 47 章
（柱面逼近）与第 43 章（轨道空间装修）都会再来借这台
机器。

## 28.3 拓扑版 Fubini 的完全体（袁 11.4.2）

袁书 §11.4 的表述把三件事打包成"Radon 乘积测度"的完全体：
μ, ν Radon（σ-有限）⟹ 存在唯一 Radon 测度 μ×̂ν 使

  (μ×̂ν)(A×B) = μ(A)ν(B)（一切 Borel 矩形），

且 f ∈ L¹(μ×̂ν) 时 Fubini 换序成立、f ≥ 0 时 Tonelli 成立、
**f ∈ C_c(X×Y) 时 ∫f d(μ×̂ν) 的累次积分两条路都通**（连续
函数的截口连续 → 截口积分连续 → 累次积分 = 重积分的
"连续函数专属快速通道"——第 24 章 Riesz 泛函的乘积版：
I(f) = ∫∫f dμdν 是 C_c(X×Y) 上的正线性泛函，其 Riesz 测度
恰是 μ×̂ν——**RMK 视角的乘积构造**，与第 18 章的
Carathéodory 构造再度汇流）。

## 28.4 迭代与 n 因子

固定 y 的截口定理（第 17 章抽象版）在拓扑层升级：f 连续 ⟹
截口 f(·, y) 连续（直接）；f 可测 + Radon ⟹ 几乎处处截口
可测（抽象版照用）。n 因子乘积归纳推进：B(X₁×…×Xₙ) =
⊗B(Xᵢ)（有限族免第二可数）；Radon 性 n 元迭代传递（紧
穷竭的笛卡尔积仍是紧穷竭）。**与第 20 章无穷乘积的接口**：
无穷乘积测度（柱集装配）在 LCH σ-紧 Polish 因子下自动
Radon（第 29 章工具收割）——"无穷维 Radon"不是梦，
Cantor 空间与 ℝ^ℕ 是正例；但**非紧因子的无穷乘积要过
σ-有限+胎紧的关卡**（第 32 章伏笔）。

## 28.2.5 截口一致连续引理的证明骨架（本章心脏的解剖）

**引理（严书 5.6.5）**：S 拓扑空间、T 紧、f ∈ C(S×T) ⟹
∀s₀ ∀ε ∃s₀ 邻域 U：sup_{s∈U, t∈T}|f(s,t) − f(s₀,t)| < ε。

**证明**（Heine-Cantor 的参数版）：

1. **逐点开覆盖**：固定 t ∈ T，f 在 (s₀,t) 连续 ⟹ 存在
   邻域 U_t × V_t 使 |f(s,u) − f(s₀,t)| < ε/2 于其上；
2. **紧性收网**：{V_t} 覆盖 T ⟹ 有限子覆盖 V_{t₁},…,V_{tₙ}；
   取 U = ∩U_{tᵢ}（有限交，仍邻域）；
3. **三角拼账**：s ∈ U, t ∈ T ⟹ t ∈ V_{tᵢ} 某 i ⟹
   |f(s,t) − f(s₀,t)| ≤ |f(s,t) − f(s₀,tᵢ)| + |f(s₀,tᵢ)
   − f(s₀,t)| < ε/2 + ε/2。∎

**为何这就是"一致连续性的供应商"**：当 S = T（同一度量
紧空间），取邻域 U = 球 → 结论读作 d(s,s₀) < δ ⟹
sup_t |f(s,t)−f(s₀,t)| < ε——两个变量的一致连续（乘积
紧性的标准推论）。**测度论的用法**（28.2 内正则步骤）：
把"K ⊆ W（开）"的逼近误差沿 T-因子一致化，使一次性
磨光在所有 t 上同时工作——一致性与可积性交换的许可
证（第 11 章DCT 的拓扑版亲戚）。

## 28.4.5 无穷乘积的 Radon 关卡

n 因子 Radon 迭代完毕后，自然的追问：**可数乘积呢**？
三条关卡：

1. **σ-代数层畅通**：B(∏Xᵢ) = ⊗B(Xᵢ)（可数指标 + 各因子
   第二可数——第 17/23 章件）；
2. **测度层看因子**：各因子概率测度 → 乘积概率（第 20 章
   存在）——自动 Radon？**因子 Polish 时 ✓**：胎紧性从
   因子传递（各因子紧套的乘积套是乘积空间的紧套——
   Tychonoff），第 29 章机器收割；因子一般 LCH 时需逐例
   验收（σ-紧传递 σ-紧）；
3. **积分层照常**：Fubini 沿柱集逼近（先有限窗后取极限
   ——第 20 章柱集账 + 单调收敛）。

**关卡的现实意义**：Cantor 空间 2^ℕ（紧 Polish）与
ℝ^ℕ（Polish 非局部紧 σ-紧）上的乘积测度都 Radon——
随机过程（第 43 章）的样本空间因此安全；但**非胎紧的
乘积族**（质量逃逸到无穷）会卡在关卡 2——第 32 章
Prokhorov 正题的入口。

## 28.5 数值实验：矩形账的正则传递

**Julia（`28_product_topological.jl`）**：

- **紧有限传递**：K = [0,1]² 上 μ×ν 账 = 1·1 = 1；挖洞紧集
  K = [0,1]²∖(0.4,0.6)² 的账 = 1 − 0.04 精确（闭包差）；
- **截口一致连续引理的显影**：f(x,y) = sin(xy) 于
  [0,1]×[0,π]（T = [0,π] 紧），对每个 x₀ 打印
  sup_y|f(x,y) − f(x₀,y)| 随 x → x₀ 的收敛（一致收敛的
  数值证据：Δx = 10⁻ᵏ 序列，sup 差 ~ O(Δx)）；
- **外正则传递**：开集 W = 单位圆盘的 μ×ν 账 = π/4（闭式），
  由外接方块的账下逼近（网格化开集族的 inf 账）；
- **RMK 视角对账**：I(f) = ∫∫f dxdy（累次）vs ∫f d(λ×λ)
 （2D 网格积分）对 5 个测试函数一致（第 18 章数值 + 本章
  拓扑层的双通道合流）。

**Python（`28_product_topological.py`）**：Fraction 精确版——
矩形与挖洞紧集的账（1/25 型精确分数）、圆盘的 π/4 数值与
Leibniz 级数对拍、截口 sup-差的精确上界（Lipschitz 常数
的显式账）。

## 28.7 要点回顾

1. 拓扑层三层对账：σ-代数（B⊗B = B(×)）/ 测度（μ⊗ν 是
   Radon）/ 积分（Fubini 照常）——两条唯一性（π-系与 RMK）
   合流。
2. 传递证明的心脏：紧有限（投影）+ 外正则（box 下确界）+
   内正则（**截口一致连续引理** 5.6.5——紧性的 Heine-Cantor
   高维版，后文两借）。
3. RMK 视角的乘积构造：累次积分泛函的 Riesz 测度 = 乘积
   测度——三套构造（Carathéodory/Daniell/Riesz）的最后
   一次汇流。
4. n 因子迭代 + 无穷乘积的 Radon 前景（σ-紧 Polish 自动
   Radon，第 29 章收割）。
5. 机器侧：对齐与矩形账机器化；截口引理由 docs+数值承载
