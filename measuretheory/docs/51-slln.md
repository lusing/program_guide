# 第 51 章 强大数定律（袁 ch20 / 严 §7.3）

弱大数定律（50 章）说：频率依概率收敛——"大概率不会偏太多"。
强大数定律说：频率**几乎必然**收敛——"几乎每条轨道上，偏差
最终永远消失"。这一字之差隔了两百年：Borel 的强大数定律
诞生于 1909 年（Bernoulli 情形），比 Bernoulli 的弱大数定律
（1713）晚了整整两个世纪；严格化由 Cantelli 于 1917 年完成。
本章引擎：随机级数收敛（Kolmogorov 准则 + 三级数定理）→
Kronecker 引理 → Kolmogorov/MZ 强大数律 → 四个经典应用。

## 51.1 为什么 a.s. 比 P 强一个量级

依概率收敛的断言 P(|X̄ₙ−μ|>ε) → 0 对每个固定 n 度量偏差；
a.s. 收敛 P(∃N, ∀n≥N, |X̄ₙ−μ|≤ε) = 1 度量的是**整条轨道的
最终行为**。统计推断里前者给"大样本渐近无偏"，后者给"强相合
估计"（样本均值几乎必然钉在真均值上）——点估计理论的基石。
a.s. 收敛还是尾事件（前有限项不影响），故 Kolmogorov 零一律
（35 章）保证其概率非 0 即 1：**研究 a.s. 收敛就是判定
0/1 的归属**，这就是本章一切"充要条件"的来源。

## 51.2 随机级数的收敛：Kolmogorov 三定理（袁 20.1）

独立随机变量级数 ΣXₙ 或者 a.s. 收敛于某实数、或者 a.s. 发散
（零一律，推论 13.27）——问题只剩"哪个"。

**定理 51.A（Kolmogorov 收敛准则，袁 20.1）。** 独立 r.v. 序列
{Xₙ} 满足 Σₙ Var Xₙ < ∞，则 Σₙ(Xₙ − EXₙ) a.s. 收敛。

**证明解剖（三行骨架）。** 不妨 EXₙ = 0。任取 n, m，把 48 章的
Kolmogorov 最大不等式（袁 14.31）用于 Xₙ₊₁,…,Xₙ₊ₘ：

  P(max_{1≤k≤m} |Sₙ₊ₖ − Sₙ| ≥ ε) ≤ ε⁻² Σ_{k=n+1}^{n+m} Var Xₖ。

令 m→∞（测度下连续）得 P(⋃_{k≥1}{|Sₙ₊ₖ−Sₙ|≥ε}) ≤
ε⁻²Σ_{k>n} Var Xₖ，再令 n→∞，右端因 ΣVar Xₙ < ∞ 而 →0——
{Sₙ} 是 a.s. Cauchy 列（定理 6.10），故 a.s. 收敛。□

**这是全章的引擎**：一切强收敛都通过"方差级数有限 + 最大不等式
把偏差升级到 max"这条链完成。本例的 Lean 对照：mathlib 的
`ProbabilityTheory.strong_law_ae`（51.9 节实弹）内部正是这套
截尾 + 方差控制 + Borel-Cantelli 的 Etemadi 变体。

**逆何时成立？** 需要代价：

**定理 51.B（袁 20.2）。** 独立、一致有界（|Xₙ| ≤ c a.s.）时，
Σ(Xₙ−EXₙ) a.s. 收敛 **⟺** Σ Var Xₙ < ∞。

"⇒" 用极大不等式的**下界版**（袁 14.33）：若 ΣVar Xₙ = ∞，则
P(max_{k≤m}|Sₙ₊ₖ−Sₙ| ≥ 1) ≥ 1 − (1+c)²/ΣVar Sₖ → 1（m→∞），
故 sup_{k≥1}|Sₙ₊ₖ−Sₙ| ≥ 1 a.s. 对每个 n 成立——{Sₙ(ω)} 几乎
必然不是 Cauchy 列，级数 a.s. 发散。

**定理 51.C（袁 20.3）。** 独立、有界：ΣXₙ a.s. 收敛 ⟺ ΣEXₙ 与
ΣVar Xₙ 都收敛。"⇒" 用**对称化**：取独立复本 Xₙ′（同分布），
Xₙˢ = Xₙ−Xₙ′ 对称且 |Xₙˢ| ≤ 2c，EXₙˢ = 0，Var Xₙˢ = 2Var Xₙ；
由 ΣXₙ a.s. 收敛 ⟹ ΣXₙ′ 亦然 ⟹ ΣXₙˢ 亦然，51.B 给出
ΣVar Xₙˢ < ∞ 即 ΣVar Xₙ < ∞，回代 51.A 得 Σ(Xₙ−EXₙ) 收敛，
于是 ΣEXₙ = ΣXₙ − Σ(Xₙ−EXₙ) 收敛。对称化是本章的标准手术：
**把非对称问题换成对称问题，结论再换回来**。

## 51.3 三级数定理：无矩假设的充要条件（袁 20.1.2）

51.B/51.C 都要界。去掉界的工具是**截尾等价**：

**定义 51.D（袁 20.4）。** 两序列 {Xₙ}、{Xₙ′}：
- **尾等价**：P{Xₙ ≠ Xₙ′, i.o.} = 0（几乎必然只有有限处不同）；
- **收敛等价**：Σₙ P{Xₙ ≠ Xₙ′} < ∞。

Borel-Cantelli（36 章）说收敛等价 ⟹ 尾等价。**等价引理**
（袁 20.5）：收敛等价的 {Xₙ}、{Xₙ′} 满足 (i) 尾等价；
(ii) Σ(Xₙ−Xₙ′) a.s. 收敛（几乎必然只有有限项非零！）；
(iii) ΣXₙ a.s. 收敛 ⟺ ΣXₙ′ a.s. 收敛；(iv) 对 bₙ↑∞ 与任意
r.v. X，bₙ⁻¹ΣXₖ → X a.s. ⟺ bₙ⁻¹ΣXₖ′ → X a.s.。四条全是
"有限项差在规范化下消失"的直接结算。

**定理 51.E（Kolmogorov-Hinchin 三级数定理，袁 20.6；1924 年
Kolmogorov 大四时的成果）。** 独立 {Xₙ}：ΣXₙ a.s. 收敛 ⟺
对每个 c > 0，三级数皆收敛（Xₙᶜ = XₙI{|Xₙ|<c}）：
  (i) ΣP{|Xₙ|≥c} < ∞（尾项稀少）；
  (ii) ΣEXₙᶜ 收敛（截尾期望可和）；
  (iii) ΣVar Xₙᶜ < ∞（截尾方差可和）。
反过来，存在某个 c 使三条成立即可。

"⇒"：ΣXₙ 收敛 ⟹ Xₙ → 0 a.s. ⟹ (i)（Borel-Cantelli 反用，
例 13.23）⟹ {Xₙ} 与 {Xₙᶜ} 收敛等价，由等价引理 (iii) ΣXₙᶜ
收敛，51.C 给 (ii)(iii)。"⇐"：(i) 给收敛等价，(ii)(iii) 经
51.C 给 ΣXₙᶜ 收敛。注意 51.A 是 51.E 的直接推论（取 c→∞
不动截尾）——三级数定理是全章的**万有准则**。

## 51.4 子序列方法与 Kronecker 引理（袁 20.1.3 / 20.2.2）

a.s. 收敛证明的另一条腿：**先沿子序列证，再摊到全序列**。

**定理 51.F（袁 20.7）。** 独立事件 {Aₙ}，ΣP(Aₙ) = ∞，则
ΣI_{Aₖ} / ΣP(Aₖ) → 1 a.s.（相对频率强相合；独立可减弱为两两）。

骨架：记 Xₙ = I_{Aₙ}，Sₙ = ΣXₖ；取 nₖ = inf{n: ESₙ ≥ k²}
（ESₙ→∞ 保证良定义），由 EX_{nₖ} ≤ 1 得 k² ≤ ES_{nₖ} < k²+1
⟹ ES_{nₖ₊₁}/ES_{nₖ} → 1。Chebyshev + Var Sₙ ≤ ESₙ（指示函数
Var ≤ E）给 P(|S_{nₖ}−ES_{nₖ}| > εES_{nₖ}) ≤ 1/(ε²k²)，对 k
可和 ⟹ Borel-Cantelli：S_{nₖ}/ES_{nₖ} → 1 a.s. 沿子序列成立；
Xₙ ≥ 0 的单调性把全序列夹在相邻子序列点之间（习题 20.13 的
子序列法）。**k² 子序列是标准动作**：它让 Σ1/k² 收敛（B-C 的
入场费），同时相邻点比值 →1（夹得住）。

**引理 51.G（Kronecker，袁 20.9）。** 0 < bₙ ↑ ∞，Σxₙ/bₙ
收敛 ⟹ bₙ⁻¹Σ_{k≤n} xₖ → 0。

证明是 Abel 分部求和：记 yₙ = Σ_{k<n} xₖ/bₖ → y，则
bₙ⁻¹Σxₖ = y_{n+1} − bₙ⁻¹Σ(bₖ−bₖ₋₁)yₖ；后项与 y 之差按 n₀ 分
两段（前段被 bₙ⁻¹·常数 杀死，后段被 ε·(bₙ−b_{n₀})/bₙ ≤ ε
控制）→ 0。**级数收敛 ⟹ 加权平均趋于零——强大数律的全部
"平均化"都经此引理。**

**定理 51.H（袁 20.10）。** 独立、σₙ² = Var Xₙ < ∞，0 < bₙ↑∞，
Σσₙ²/bₙ² < ∞ ⟹ (Sₙ − ESₙ)/bₙ → 0 a.s.。

证明两行：Yₙ = (Xₙ−EXₙ)/bₙ 满足 ΣVarYₙ < ∞，51.A 给 ΣYₙ
a.s. 收敛，Kronecker 引理收割。Kolmogorov 1930 年的原始版
bₙ = n；一般形式首现于 Loève 1962 专著。

## 51.5 Kolmogorov 强大数定律（袁 20.2.3）

**定理 51.I（袁 20.11，1933）。** {Xₙ} iid ~ X：
  (i) E|X| < ∞ ⟹ Sₙ/n → μ = EX a.s.；
  (ii) Sₙ/n → c a.s.（c 常数）⟹ E|X| < ∞ 且 c = EX。

**(i) 的截尾解剖。** 令 Xₙ′ = XₙI{|Xₙ|<n}。由同分布与
Σₙ P{|Xₙ|≥n} = Σₙ P{|X|≥n} ≤ E|X| < ∞（习题 20.3 之 (1)：
ΣP{|X|≥n} ≤ E|X| ≤ 1+ΣP{|X|≥n}——**层饼公式**的离散版），
{Xₙ} 与 {Xₙ′} 收敛等价，只需证 Sₙ′/n → μ a.s.（等价引理
(iv)）。又 EXₙ′ → μ（单调收敛），只需 51.H 型估计：

  Σₙ Var Xₙ′/n² ≤ Σₙ EXₙ²I{|X|<n}/n²
    = Σₙ n⁻² Σ_{k≤n} EX²I{k−1≤|X|<k}
    ≤ Σₖ k² P{k−1≤|X|<k} Σ_{n≥k} n⁻²
    ≤ c Σₖ k P{k−1≤|X|<k} ≤ c(1+E|X|) < ∞

（Σ_{n≥k}n⁻² ≤ c/k 是习题 20.24 的初等账）。51.H + Kronecker
收割。**整个证明 = 截尾等价 + 层饼换序 + 51.H**，三块积木全部
已在前文落户——这就是"工具先行"的回报。

**(ii) 的一行必要性。** Sₙ/n → c a.s. ⟹ Xₙ/n = Sₙ/n −
(n−1)/n·Sₙ₋₁/(n−1) → c − 1·c = 0 a.s. ⟹ ΣP{|Xₙ|≥n} < ∞
（B-C 反用）⟹ E|X| < ∞，再由 (i) c = EX。**iid 情形，强律的
极限只能是均值，均值必须存在**——干净利落的双向。

**例 51.J（袁 20.12，样本相关系数强相合）。** 二维样本
(Xₖ,Yₖ)，EX²,EY²<∞：rₙ → ρ a.s.（分子分母各自强律，连续
映射收拢）。

**例 51.K（袁 20.13，高维立方体几乎是球面）。** X~U[−1,1]
iid：n⁻¹ΣXₖ² → EX² = 1/3 a.s.——[−1,1]ⁿ 中的点几乎全在球面
S(0, √(n/3)) 附近（Lebesgue 测度 →1）。**高维概率的第一课：
体积不住在中心，住在球壳上。**

## 51.6 MZ 强大数定律与 p = 2 的边界（袁 20.2.4）

**定理 51.L（Marcinkiewicz-Zygmund 1937，袁 20.14）。** iid，
p ∈ (0,2)：n^{−1/p}(Sₙ − na) → 0 a.s.（某常数 a）⟺
E|X|ᵖ < ∞；且 1 ≤ p < 2 时 a = EX，0 < p < 1 时 a 任意
（常取 0）。

**谱系读法**：p = 1 即 Kolmogorov；p < 1 时连期望都可以不
存在（无中心化——重尾分布的和大数律）；p 越大归一化越粗、
矩条件越强。**矩存在性直接兑换归一化速率**——与 50 章 WLLN
的 MZ 版同构，但收敛模式升级。

"⇐" 骨架：截尾 Xₙ′ = XₙI{|Xₙ|<n^{1/p}}（层饼换序给
ΣP{Xₙ≠Xₙ′} ≤ E|X|ᵖ < ∞），证明 Σn^{−1/p}EXₙ′ 收敛分
0<p<1 与 1<p<2 两档（都用 Σ_{n≥k}n^{−1/p} 的初等界），
Kronecker + 51.H 型方差账（习题 20.25）收割。
"⇒" 一行：Xₙ/n^{1/p} = n^{−1/p}(Sₙ−na) − ((n−1)/n)^{1/p}·
(n−1)^{−1/p}(Sₙ₋₁−(n−1)a) + a/n^{1/p} → 0 a.s. ⟹
E|X|ᵖ < ∞（习题 20.6：E|X|ᵖ<∞ ⟺ n^{−1/p}Xₙ→0 a.s.）。

**定理 51.M（边界，袁 20.15）。** iid 非退化，p ≥ 2：对任何
常数列 {aₙ}，limsup n^{−1/p}|Sₙ−aₙ| = ∞ a.s.——MZ 在 p=2
处**破产**。原因深：p = 2 时 Sₙ 的涨落尺度已是 √n·Φ（CLT，
52 章），任何常数平移都压不住正态尾。证明用对称化 +
Hartman-Wintner 之前的正态近似（(20.12) 式：P{n^{−1/2}|Sₙˢ|
> 3C} → 2Φ(−3C/√(2VarX₁)) > 0 与上极限 = 0 矛盾）。
**MZ 的 (0,2) 与 CLT 的 √n 在同一点会师——52 章正是
p = 2 的替补舞台。**

## 51.7 应用四连（袁 20.3）

**① 正规数（Borel 1909 的原问题）。** Ω = [0,1) 配 Lebesgue
测度，十进位数字 ωₙ 是 iid 均匀 {0,…,9}（个别点双展开取
前者，可数集零测无碍）。Xₙ⁽ᵏ⁾ = I{ωₙ = k} 是 Bernoulli(1/10)
iid，Kolmogorov 强律给 Nₙ⁽ᵏ⁾/n → 1/10 a.s.——**[0,1) 中几乎
所有数都是正规数**（每个数字频率 1/10）。0.1234567890123…
（循环）是正规数，0.123123… 不是，但非正规数全体 Lebesgue
零测。本章 Lean 实弹（51.9）用二进制版完整机器化此定理。

**② Monte Carlo 积分（Ulam-von Neumann，曼哈顿计划）。**
I = ∫₀¹g(x)dx = Eg(X)，X~U[0,1]：n⁻¹Σg(Xᵢ) → I a.s.——
**强相合给出合法性的 a.s. 版**（不只是大概率，是几乎每条
采样轨道都收敛）。一般区间经线性变换 s = (x−a)/(b−a) 归一。

**③ 强更新定理（袁 20.17）。** 更新过程：寿命 Xₙ iid 非负，
EX₁ = μ < ∞，Tₙ = ΣXₖ，N_t = max{n: Tₙ ≤ t}。三明治
T_{N_t}/N_t ≤ t/N_t < T_{N_t+1}/N_t = T_{N_t+1}/(N_t+1)·
(N_t+1)/N_t，两端由 SLLN 同趋于 μ ⟹ **t/N_t → μ a.s.，即
N_t/t → 1/μ a.s.**（长期更新率 = 均值的倒数）。弱版
EN_t/t → 1/μ 由 Markov 不等式另证。

**④ Glivenko-Cantelli（1933，统计学的基本定理）。** 经验分布
F̂ₙ(x) = n⁻¹ΣI{Xₖ≤x} 逐点强相合（20.14：I{Xₖ≤x₀} 是
Bernoulli(F(x₀)) iid，SLLN 直接给 F̂ₙ(x₀) → F(x₀) a.s.）。
定理 20.18 升级为**一致**：Dₙ = sup_x|F̂ₙ(x)−F(x)| → 0 a.s.。
证明解剖：取 k > 1/ε，网格 −∞ = x₀ < x₁ ≤ … ≤ x_{k−1} <
xₖ = ∞ 使 F(xⱼ−0) ≤ j/k ≤ F(xⱼ)（每层概率 ≤ 1/k）；2k 个
网格点上 F̂ₙ → F 与 F̂ₙ(·−0) → F(·−0) 同 a.s. 成立 ⟹
Δₙ = max_j{|F̂ₙ(xⱼ)−F(xⱼ)| ∨ |F̂ₙ(xⱼ−0)−F(xⱼ−0)|} → 0；
任意 x 落在某 [x_{j−1}, xⱼ)，单调性把 F̂ₙ(x)−F(x) 夹在
±(Δₙ+ε) 之间 ⟹ Dₙ ≤ Δₙ+ε → 0。**逐点强律 + 单调性三明治
= 一致强律**——"统计推断以样本为依据"的全部合法性在此。
分位数版（袁 20.19）：F 在 F^←(p) 严格增 ⟹ F̂ₙ^←(p) →
F^←(p) a.s.（ε 夹逼 + 逆映射连续性）。

**⑤ 密度估计三部曲**（袁 20.3.6-7）：直方图（固定窗 h，频率/
nh 估计 f）→ Rosenblatt 1956（窗随 x 滑动 [x−h/2, x+h/2]）
→ Parzen 1962 **核估计** f̂ₙ(x) = (nhₙ)⁻¹ΣK((x−Xⱼ)/hₙ)
（一般密度核 K，窗宽 hₙ→0 但不能太快——nhₙ→∞ 是均方收敛
的门槛，nhₙ²→∞ 是一致强相合的门槛）。定理 20.28 的证明有
一座漂亮的 **Fourier 桥**（引理 20.26）：经验特征函数
Zₙ(t) = n⁻¹Σe^{itXⱼ} 经反演 (17.10) 把 f̂ₙ 写成
(2π)⁻¹∫e^{−itx}φ_K(hₙt)Zₙ(t)dt，于是 sup 偏差被 ∫|φ_K| 与
正交账 E|Zₙ(t)−EZₙ(t)|² ≤ 4/n（习题 20.34：复值零均值独立
和的二阶矩 = 各二阶矩之和）控制——**特征函数方法（49 章）
在密度估计里的完整出场**。

## 51.8 分界账：WLLN 成立而 SLLN 破产（袁习题 20.18/20.20）

对称分布 P{|X|>x} = e/(x log x)（x ≥ e）：E|X| =
e∫_e^∞ dx/(x log x) = ∞（log 积分发散）⟹ SLLN 破产
（51.I (ii) 的逆否）；但 WLLN 成立（Sₙ/n →ᵖ 0——截尾到 n 的
期望账 E|X|I{|X|≤n} = e(log log n − 1) = o(n)）。**弱强分界的
精确形状：E|X| = ∞ 但截尾均值增长慢于 n。**

圣彼得堡分布（50 章）的强版账（习题 20.20）：
limsup Xₙ/(n log₂ n) = ∞ a.s.，进而 limsup Sₙ/(n log₂ n) =
∞ a.s.——**截尾期望 (k+1)/2 的 log 增长与"真实"归一化
n log₂ n 精确会师**：圣彼得堡悖论没有经典意义的强大数律，
它的大数律活在 n log₂ n 尺度上（50 章的截尾账在此闭环）。

## 51.9 机器通道

**Lean（`Ch51SLLN.lean`）**：旗舰实弹——**Borel 正规数定理的
二进制版全机器证**。链条：硬币空间 `coin = Measure.infinitePi
(λ _ => bern2)`（20 章工程）上，坐标投影的独立性由
`iIndepFun_iff_map_fun_eq_infinitePi_map₀'` 反向收割
（`infinitePi_map_eval` 给每个边际 = bern2，`map_id'` 给联合 =
自身），同分布由同一引理直接读；X n ω = if ω n then 1 else 0
的复合保持两性质（`iIndepFun.comp` / `IdentDistrib.comp`）；
可积性由有界（≤1）白拿；于是 `ProbabilityTheory.strong_law_ae`
（Etemadi 两两独立版，Banach 空间值）直接给出

```text
∀ᵐ ω ∂coin, Tendsto (fun n ↦ (n:ℝ)⁻¹ • ∑ i ∈ range n, X i ω)
                    atTop (𝓝 (𝔼 X 0))
```

而 𝔼 X 0 = 1/2 由 dirac 折叠账（`integral_smul_measure` +
`integral_add_measure` + `integral_dirac`）结清——**频率 →
1/2 a.s.**，即二进制展开中几乎处处一半位是 1。
这正是 1909 年 Borel 定理的完全形式化（b = 2 情形）。
`strong_law_Lp`（Lᵖ 版，p≥1 有限）同套假设免费再收一份
L¹ 收敛账。

**Julia（`51_slln.jl`）**：① 正规数频率轨道（二进制位流的
**端点带** |Sₙ/n−1/2| ≤ 2/√n 覆盖 200/200——LIL 墙纪律：只判
端点）；② Monte Carlo 积分 ∫₀¹eˣdx 的 a.s. 轨道（误差压进

⑤ 分界账（习题 20.18 型对称重尾 P{|X|>x}=e/(xlogx)，尾函数

## 51.10 历史注记与要点回顾

Borel（1909）开 Strong Law 之先河（Bernoulli 情形，证明有洞，
Cantelli 1917 补严）；Kolmogorov 大四（1924）与 Khinchin 建
三级数定理，1929-1933 完成强大数律双向版；MZ（1937）推广到
p 阶矩；Etemadi（1981）把独立性需求降到两两独立——mathlib
的 `strong_law_ae` 形式化的正是 Etemadi 版（注释明言）。
Glivenko-Cantelli（1933）被尊为"统计学基本定理"；Parzen
（1962）核估计是 SLLN 在非参数统计的最大遗产。

要点回顾：
1. 引擎 = Kolmogorov 准则（ΣVar<∞ + 最大不等式 + Cauchy）
   + 等价引理（截尾换不掉渐近行为）+ Kronecker（级数收敛 ⟹
   加权平均 →0）——三块积木组装一切。
2. Kolmogorov SLLN 双向：E|X|<∞ ⟺ Sₙ/n→μ a.s.；极限只能是
   均值（Xₙ/n→0 的一行必要性）。
3. MZ 谱系：E|X|ᵖ<∞ ⟺ n^{−1/p}(Sₙ−na)→0（p<2）；p=2 破产，
   CLT 接棒（52 章）。
4. 应用四连：正规数 / MC 积分 / 更新率 / Glivenko-Cantelli
   （逐点强律 + 单调三明治 = 一致）。
5. 分界账：E|X|=∞ 但截尾均值 o(n) ⟺ WLLN 活 SLLN 死；
   圣彼得堡活在 n log₂ n 尺度。
6. 机器侧：Lean 正规数定理全证（坐标独立性 + SLLN 实例化）；
   数值通道四轨道账 + 分界双轨演示。
