## 31.1 定义与 Portmanteau：一张等价清单七种说法

度量空间 (S, d) 上概率测度列 **μₙ 弱收敛于 μ**（记 μₙ ⇒ μ）：
∫f dμₙ → ∫f dμ 对一切有界连续 f : S → ℝ。

**Portmanteau 定理（严书 6.2.x / 袁 12.2.2）**：以下等价——

1. ∫f dμₙ → ∫f dμ（一切有界连续 f）；
2. limsup μₙ(F) ≤ μ(F)（一切**闭** F）；
3. liminf μₙ(G) ≥ μ(G)（一切**开** G）；
4. μₙ(B) → μ(B)（一切 μ-**连续集** B：μ(∂B) = 0）；
5. （变体）limsup d(x, F) 型函数的积分不等式族。

证明的枢纽是**磨光不等式**：闭 F 的函数距离 d(x,F) 给出
1_F 的连续上逼近（f_ε = 1 − min(d(x,F)/ε, 1)），开集对偶
下逼近——(1)⟹(2) 的全部技术；连续集则闭包/内部双向夹逼。
**教学读法**：弱收敛是"上闭下开"的单边纪律——闭集不许
超收（质量不得凭空聚到边界），开集不许欠收（质量不得凭空
消失），边界零测的集合两者夹成精确收敛。

## 31.2 基本性质与判据

**连续映射定理（严书 6.2 / 袁 12.2.3）**：g : S → T 连续
（或 μ-a.s. 连续——不连续点集 μ-零测即可！）⟹ μₙ ⇒ μ ⟹
g(μₙ) ⇒ g(μ)。一维 cdf 收敛（30 章）是其特例（g = 评价
泛函 x ↦ x 于连续点）。**Slutsky 定理（袁 12.5.2）**：
Xₙ ⇒ X（S 值）、Yₙ →p c（常数），则 (Xₙ, Yₙ) ⇒ (X, c)——
"退化方向的依概率收敛可以和弱收敛自由组合"，统计学的
日常工具（样本均值 + 相合估计的组合极限）。

**依分布收敛 vs 依概率收敛（袁 12.5.3）**：Xₙ →p X ⟹
Xₙ ⇒ X；反向成立当且仅当极限 X 退化（常数）——依分布是
"形状收敛"，丢掉了样本空间上的配对信息。反例教材：Xₙ =
X·(−1)ⁿ 与 X 同分布（若 X 对称）⟹ Xₙ ⇒ X 处处成立但
|Xₙ − X| = 2|X| 不趋 0。

**Skorokhod 表示定理（袁 12.6.2）**：μₙ ⇒ μ 于可分 S ⟹
存在同一概率空间上的随机元 X̃ₙ, X̃ 使 L(X̃ₙ) = μₙ、L(X̃) = μ
且 **X̃ₙ → X̃ a.s.**——把"形状收敛"升舱为"轨道收敛"。
证明走量化函数的左连续逆（袁 12.6.1 的 Q(u) = inf{x :
F(x) ≥ u}）+ U ~ U(0,1) 的显式构造。**用途**：弱收敛的
a.s. 化处理（期望收敛、矩的 UI 传递——第 38 章的接口）。

## 31.3 乘积与独立性场景

**Cramér-Wold（多维入口）**：ℝᵈ 上 μₙ ⇒ μ ⟺ 一切线性
组合 t·Xₙ ⇒ t·X——多维弱收敛化归一维（cdf 字典逐方向
套用）。**连续映射定理的乘积版**：Xₙ ⇒ X、Yₙ ⇒ Y 且
**两列独立**（列内）⟹ (Xₙ,Yₙ) ⇒ (X,Y)；独立性缺失时
结论可败（边缘收敛不保证联合——经典反例 Xₙ = X, Yₙ = −X
与 X 对称）。**经验测度视角**：μₙ = (1/n)Σδ_{Xᵢ}（样本
经验测度）⇒ μ（Glivenko-Cantelli 强形式，第 51 章完全体）
——31 章的 portmanteau 条款即经验过程的逐条验收单。

## 31.2.5 Skorokhod 构造的完整骨架（分位函数路线）

设 μₙ ⇒ μ 于可分 S（一维叙述，高维同理）：

1. **分位函数**：Q(u) = inf{x : F(x) ≥ u}（左连续逆，
   袁 12.6.1 的系统性质：Q(U) ~ μ 当 U ~ U(0,1)）；
2. **同源采样**：X̃ₙ = Qₙ(U)、X̃ = Q(U)（**同一个 U**）——
   各自的分布恰为 μₙ、μ；
3. **轨道收敛**：u ∈ (0,1) 为 F 的连续点的原像（F(Q(u)−)
   < u < F(Q(u)) 型"好 u"集，Lebesgue 满测）上 Qₙ(u) →
   Q(u)（cdf 收敛 + 单调逆的夹逼）；a.s. 收割。∎

**用途显影**：① 期望收敛：X̃ₙ → X̃ a.s. + 一致可积（38 章）
⟹ E X̃ₙ → E X̃——弱收敛 + UI 传矩的标准流水线；② 泛函
连续映射：h 可测 + 不连续点 μ-零测 ⟹ h(X̃ₙ) → h(X̃) a.s.
（连续映射定理的表示证明）。**表示定理是"把测度论问题
搬进概率空间"的传送门**——本书后半的常备工具。

## 31.3.5 独立性与边缘的裂缝（反例详解）

**边缘收敛 ≠ 联合收敛**：X 对称（如 N(0,1)），Xₙ = X、
Yₙ = −X。边缘：Xₙ ⇒ X、Yₙ ⇒ X（−X 与 X 同分布）——但
(Xₙ,Yₙ) = (X,−X) 恒在反対角线上，极限若有必集中于反对角
线，而"独立拼合"(X, X) 在对角线——形状完全不同。**裂缝
根源**：联合分布含有边缘之外的**耦合信息**，弱收敛的边缘
条款不约束耦合。补丁两枚：① 两列独立（耦合唯一）⟹ 联合
收敛；② 确定一个变量（Slutsky：Yₙ →p c 把耦合锁死）。
第 49 章特征函数方法将以 Cramér-Wold 绕开耦合问题（一切
线性组合的边缘定联合）。

## 31.3.6 Portmanteau 清单的完整证明地图

七条款的循环证明路线图（严书 6.2 的顺序重组）：
(1)⟹(2)：磨光三连（30.2.5 母版）；(2)⟺(3)：补集翻译
（闭开对偶）；(2)+(3)⟹(4)：闭包 ≤ B ≤ 内部，边界零测
使两侧极限夹成 μ(B)；(4)⟹(1)：f 的分布分层积分
（Stieltjes 型：∫f dμ = ∫fₜ dt 型切片，每层是连续集的
账）+ 控制收敛。**每步的技术半径都不超过磨光 + 夹逼**——
第 31 章的全部智慧在定义的选择（C_b 检验）而不在证明
难度。这也是它成为标准语言的原因：**好用不在于强，而在
于刚好**。

## 31.4.5 实验断言清单（数值通道验收单）

1. **闭集条款**：μₙ = N(0,1/n) 于 F = {0}：μₙ(F) = 0 ≤
   μ(F) = 0 ✓；于 F = [0.1, 0.2]：μₙ(F) → 0 = μ(F) ✓；
2. **开集条款**：逃逸例 μₙ = (1−1/n)δ₀+(1/n)δₙ 于
   G = (−1,1)：μₙ(G) = 1−1/n → 1 = μ(G) ✓；于 G = (0,2)：
   μₙ(G) = 1/n → 0 = μ(G)（δ₀ 无质量于 (0,2)）✓；
3. **连续集条款**：δ_{1/n} 于 B = (−∞,t]（t ≠ 0 精确
   收敛）；t = 0 失败账；
4. **Skorokhod**：同一 U 的 Qₙ(U) 轨道（10⁵ 条 U 采样）
   |X̃ₙ − X̃| → 0 的频率 → 1；
5. **Slutsky**：Xₙ ~ N(0,1)、Yₙ = 1/n 的和 Xₙ+Yₙ ⇒ N(0,1)
  （sup 差 < 1/n 的数值账）。

## 31.5.5 习题账单（自检清单）

1. 用磨光三连补全 Portmanteau (2)⟹(1)（闭集条款 ⟹ 连续
   检验收敛——提示：f 的水平集分层 + Stieltjes 积分表示）；
2. 构造 Xₙ ⇒ X 且 Yₙ ⇒ Y 但 (Xₙ,Yₙ) 不联合收敛的三个
   机理不同反例（耦合翻转/共尾/滑相）；
3. 证明：μₙ ⇒ μ ⟺ 对一切有界一致连续 f 收敛（检验族可
   缩小——磨光的等度连续性）；
4. Slutsky 的二维证明（表示定理路线 vs 直接 portmanteau
   路线各写一遍）；
5. 经验测度 μₙ = (1/n)Σδ_{Xᵢ}（iid）⇒ μ 的 portmanteau
   逐条款验证（G 上 liminf：Bernoulli 大数定律的集合版）。

## 31.4 数值实验：Portmanteau 四条款的逐条验收

**Julia（`31_weak_convergence.jl`）**：μₙ = N(0, 1/n)
（方差坍缩到 δ₀）与 μₙ = (1−1/n)δ₀ + (1/n)δₙ（逃逸污染）
两族：

- **条款 2（闭集）**：F = {0} 的 μₙ 账 limsup ≤ μ 账；
- **条款 3（开集）**：G = (−1, 1) 的 liminf 检查（逃逸例
  中开集吃不到跑掉的质量——liminf = 1−1/n ≥ 1 ✓ 极限
  达标；反之若 G 装不下逃逸方向则 liminf < μ(G) 反例
  现场改用 G = (0, 2) 对 δₙ 例）；
- **条款 4（连续集）**：B = (−∞, t] 于 μ-连续 t 的精确
  收敛 + 于跳点 t 的失败（δ_{1/n} 例）；
- **Skorokhod 构造**：分位函数逆采样 X̃ₙ = Fₙ⁻¹(U) 用同一
  U——轨道收敛的蒙特卡罗显影（同 U 下 |X̃ₙ − X̃| 的 a.s.
   收敛频率）。

**Python（`31_weak_convergence.py`）**：Fraction 精确版
——离散 μₙ（二项 B(n, 1/2) → 正态的 cdf 差账）、Cramér-Wold
的线性组合账（二维两点分布族）、连续集判据的精确分数。

## 31.5.6 检验族的缩减清单（工程口径）

哪些检验函数族仍等价于弱收敛（可按场景换用）：

| 检验族 | 等价? | 场景 |
|---|---|---|
| C_b 全体 | 定义 | 一般 |
| 有界一致连续 | ✓ | 度量空间（等度连续的磨光） |
| 1-Lipschitz 有界 | ✓ | 距离化的 BL 版（33 章） |
| {d(x,F) 型生成的层级} | ✓ | Portmanteau 的原始形式 |
| σ(C_b) 的可数子集 + 分离点 | ✓（可分空间） | **可数检验集**（对角线的进料） |
| 光滑函数（C^∞_b） | ✓（ℝᵈ） | 特征函数路线（49 章） |
| 连续集的示性 | ✓ | 离散/格子分布（连续集富余） |

最后一行是"连续集条款"的独立使用：当极限测度的连续集
族足够富余（如非原子极限），逐集验收即可——格点上的
泊松逼近（30.2.6）走这条路。

## 31.6.5 历史注记与文献口径

"弱收敛"的名称经历了口径漂移：Aleksandrov（1940-43，一般
拓扑上的完全可加集函数）的原始术语是"弱收敛"；概率论
传统（Gnedenko-Kolmogorov 1949）同词；Billingsley（1968）
普及了 Portmanteau 清单与现代证法；法国学派（Lévy-
Prokhorov 线）称 étroite（窄收敛）。**文献穿越提示**：
概率文献的 weak convergence = 泛函分析的 weak\* 收敛
（对偶视角，26 章）——两个社群各自命名同一结构。本教程
统一"弱收敛（= C_b 检验）"，在 34 章淡收敛处标注与 weak\*
的精确对应。

## 31.7 要点回顾

1. 弱收敛 = 有界连续检验；Portmanteau 七等价（上闭下开 +
   连续集精确）；磨光不等式是枢纽。
2. 连续映射（a.s. 连续即可）/Slutsky/Cramér-Wold——组合
   与降维的三板斧；边缘不保证联合（独立性反例）。
3. Skorokhod 表示：形状收敛升舱轨道收敛（分位逆构造）。
4. 依分布 < 依概率（非退化极限）；经验测度是主应用现场。
5. 机器侧：mathlib `TendstoInDistribution`+`portmanteau`；
   Isabelle `weak_conv_sequence`；数值四条款逐条验收。
