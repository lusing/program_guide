## 29.1 定义与第一代家谱

**Polish 空间**：可分 + 完备度量的拓扑空间（存在某个完备
距离诱导其拓扑）。家谱（概率论的全部常住地址）：

| 空间 | 距离 | 地位 |
|---|---|---|
| ℝⁿ、ℂⁿ | 欧氏 | 基础户口 |
| 可数离散空间 ℕ | d(m,n)=1_{m≠n} | 最简成员 |
| [0,1]^ℕ、ℝ^ℕ | 乘积（紧/完备） | **序列空间的典范** |
| C[0,1]（连续轨道） | 一致范数 | 随机过程的家 |
| Baire 空 ℕ^ℕ | 树距离 | "泛型"对象的家（第 40 章） |
| Cantor 空 2^ℕ | 树距离 | 紧零维典范 |
| Lp(μ)（σ-有限） | Lp 范数 | 第 13 章空间的可分版 |
| Polish 的开/闭/Gδ 子空间 | 继承完备化 | 29.2 的封闭性 |

**家规**：Polish 对可数并、可数积、开/闭/Gδ 子空间、
连续像（紧像）封闭；**不可数离散、ℚ（不完备可分）、
Baire 空 × Cantor 空的某些商**不是（或需小心）——ℚ 是
"可分但不完备"的反例招牌（任何距离下不可能 Polish：
Polish 空间是 Baire 空间（纲定理），ℚ 是第一纲）。

## 29.2 完备化技术：Gδ 嵌入定理（严书 5.7.1-5.7.5）

**核心引理（距离改造）**：d 与 d/(1+d)（有界化）、d ∧ 1
诱导同一拓扑且保完备性——距离的**等价改造**工具箱（第
20 章无穷乘积距离、本节 Gδ 定理都要用）。

**Alexandrov 定理（严书 5.7.x）**：X 的子空间 Y 是 Polish
⟺ Y 是 X 中的 **Gδ 集**（可数开交）。两个方向：

1. **（⟸）Gδ 完备化**：Y = ∩Uₙ（X 完备）——在 X × ℝ^ℕ
  （完备）中造闭嵌入 F(y) = (y, d(y,Uₙᶜ)⁻¹...)，把 Y 实现
  为完备空间的闭子集（**继承完备性**——严书 p.175 的 ρ₀
  距离构造现场：U 上的显式完备距离）；
2. **（⟹）Polish 必 Gδ**：Y 完备可分 ⟹ 在 X 中做 ε-网
  展开 Y = ∩ₙVₙ（每层开集收敛到 Y 的闭包深度）——严书
  p.177 的 Nₙ、Vₙ 构造。

**直接推论**：ℚ ⊆ ℝ 非 Gδ（Baire 纲）⟹ ℚ 非 Polish——
反例的机制化；C[0,1] 中可微函数集非 Gδ（同法）——分析学
的"病态集合地址学"。

**嵌入定理**：可分度量空间同胚于 Hilbert 方块 [0,1]^ℕ 的
子空间；Polish 同胚于其 Gδ 子集——**一切 Polish 是具体
序列空间的 Gδ 子集**（抽象度量的具体化，第 31 章弱收敛
的可度量化讨论的地基）。

## 29.3 主定理：Polish 有限 Borel 测度正则（严书 5.7.6）

**定理**：X Polish、μ 为 B(X) 上**有限** Borel 测度 ⟹ μ
正则（从而 Radon：Polish 局部紧？不——Polish 不必局部紧，
但测度仍内正则于**闭集**，σ-紧情形升级为紧）。

**证明骨架（胎紧路线，三步）**：

1. **完全有界的铺砖**：可分 ⟹ 对每个 n 取有限 2⁻ⁿ-网
   {B(xᵢⁿ, 2⁻ⁿ)}；有限性 ⟹ 选覆盖 μ ≥ 1 − ε·2⁻ⁿ 的有限
   子族 Kₙ := 闭包之并（闭集、有限并）；
2. **紧套**：K = ∩ₙKₙ 满足**全有界 + 完备**（闭 ⊆ 完备
   X）⟹ 紧（Heine-Borel 度量版），且 μ(K) ≥ 1 − ε——
   **胎紧性（tightness）**：紧集吸收 1−ε 质量；
3. **内外正则收尾**：先证开集 U 的账 = sup{μ(K)：K ⊆ U
   紧}（U 本身 Polish（Gδ）对 μ|_U 用胎紧）；一般 Borel 集
   由外正则（有限 Borel 的开逼近——σ-有限的右连续性）+
   差集传递。∎

**推论族**：(a) 概率测度恒胎紧（ε 任意）——**第 32 章
Prokhorov 定理的单测度版**（Ulam 定理）；(b) σ-有限 Polish
测度在 σ-紧集上 σ-有限；(c) Lusin 定理（第 27 章）在
Polish 全营业。

## 29.4 标准概率空间：概率论的正典户口

**标准 Borel 空间**：Polish 空间的 Borel σ-代数。**定理
（Kuratowski）**：不可数标准 Borel 空间彼此同构（= B(ℝ)
的 σ-同构）——一切"具体概率模型"共享同一 σ-代数骨架。
概率论据此把一切 Polish 值随机变量当作"ℝ 值多看几个坐标"
处理；**标准概率空间**（Polish + 概率测度）是条件期望/
正则条件分布（第 36-37 章） existence 定理的天然舞台：
非标准空间上这些定理都会失效（第 37 章的反例土壤）。
本教程的第三幕（第 30 章起）默认一切值空间 standard——
本章发放牌照。

## 29.2.5 距离改造工具箱（Gδ 定理的零件）

Alexandrov 定理的构造全靠"距离的等价改造"——工具箱清单：

1. **有界化**：d' = d/(1+d)（或 min(d,1)）——保拓扑、保
   完备性（Cauchy 列在 d 与 d' 下互相 Cauchy：d' < ε ⟹
   d < ε/(1−ε) 型显式换算）；
2. **加权和**：d''(x,y) = Σ2⁻ⁿ·min(1, dₙ(x,y))——可数个
   距离的融合（收敛按所有坐标一致；ℝ^ℕ 的标准距离）；
   完备性逐坐标传递；
3. **开集距离**：ρ_U(x,y) = d(x,y) + |d(x,Uᶜ)⁻¹ − d(y,Uᶜ)⁻¹|
  （严书 p.175 的 ρ₀ 现造）——把"趋近边界"变成距离爆炸，
   使 (0,1) 等开集在 ρ_U 下**完备**（边界逃逸列不再
   Cauchy）——Gδ 完备化的发动机。

**使用纪律**：改造距离只保拓扑与完备性，**不保 Lipschitz/
一致结构**——积分与测度账对距离的选择通常迟钝（拓扑决定
Borel），但**数值实验与构造性证明**必须声明所用距离。

## 29.4.5 标准空间判据表（第三幕的牌照条例）

| 判据 | 结论 | 出处 |
|---|---|---|
| Polish 的 Borel 子集 | 标准 Borel（同构于 Polish 开/闭/Gδ 子空间） | 29.2 |
| 两标准 Borel 同构 | 双射 Borel 且逆 Borel（σ-同构） | Kuratowski |
| 不可countable 标准 Borel | ≅ B(ℝ) | Kuratowski |
| 标准 Borel + 概率 | 标准概率空间：条件期望/正则条件分布存在 | 36-37 |
| 可数生成 σ-代数 + 分离点 | 标准 Borel（若还具有…） | 40 章 |

**"标准"的豪赌**：Kuratowski 同构定理说 ℝⁿ、C[0,1]、
ℝ^ℕ 的 Borel 结构**完全一样**——概率论的模型选择在
σ-代数层是自由的（一切具体模型等价）；差别只在**拓扑与
距离层**（连续性/紧性依空间而异）。这就是本书前半（抽象
测度）→ 中段（拓扑测度）→ 后段（标准空间上的概率论）的
设计动机：**σ-代数管账目、拓扑管逼近、Polish 管存在性**。

## 29.5 数值实验：胎紧性的构造现场

**Julia（`29_polish.jl`）**：

- **铺砖账**：[0,1] 上 Lebesgue（代表 μ），对 n = 1..12
  构造 2⁻ⁿ-网与闭覆盖 Kₙ（闭球之并的闭包），数值验证
  μ(Kₙ) ≥ 1 − ε·2⁻ⁿ（ε = 0.01）且 K = ∩Kₙ 的网格近似账
  ≥ 1 − ε——29.3 第 1-2 步的可运行版；
- **Gδ 完备化的距离构造**：开区间 (0,1) 上 ρ₀(x,y) =
  |x−y| + |d(x,{0,1})⁻¹ − d(y,{0,1})⁻¹| 型距离（严书 p.175
  构造的数值版）——验证 ρ₀ 与通常距离同拓扑（序列收敛
  等价抽样）且 (0,1) 在 ρ₀ 下完备（Cauchy 列数值演示：
  xₙ = 1/n 在通常距离下不完备的列，在 ρ₀ 下不 Cauchy——
  **完备化的机制显影**）；
- **ℚ 非 Polish 的纲账**：ℚ = ∪{qₖ}（第一纲）在 ℝ 中稠密
  ——打印 Baire 纲论证的有限影子（每个单点 nowhere dense）。

**Python（`29_polish.py`）**：Fraction 精确版——铺砖覆盖的
测度账（闭球半径的精确分数）、Kuratowski 的有限影子（{1..n}
与 {1..m} 的 σ-代数同构计数 n ↔ 2ⁿ 个集合）、ℚ 枚举的
nowhere dense 账。
