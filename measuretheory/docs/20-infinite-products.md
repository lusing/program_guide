## 20.1 造一枚"无穷次硬币"

"独立重复投掷一枚均匀硬币无穷多次"——概率论的第一句话，
但它的样本空间 Ω = {0,1}^ℕ 与"每次正面概率 p"的测度 P 需要
**构造**：没有一个先验的"无穷维 Lebesgue 测度"等着我们（第
47 章将证明无穷维 Hilbert 上根本没有平移不变的 Lebesgue 型
测度）。本章的构造是**柱集账本 + σ-可加性验收**两步；验收
通过的本质原因是有限维空间有**紧性垫底**（{0,1}^n 紧、ℝⁿ
中的有界闭盒紧），第 21 章将把这一步抽象成"紧类"概念并推广
到 Kolmogorov 相容性定理。

## 20.2 柱集代数上的账本

Ω = ∏_{n≥1} Ω_n（可数族），每个 (Ω_n, F_n, P_n) 是概率空间。
**柱集**（有限支集矩形）：

  C = {ω : ω_{i₁} ∈ A₁, …, ω_{i_k} ∈ A_k}，A_j ∈ F_{i_j}。

柱集全体 Z 是**代数**（第 17 章三级台阶第 2 级——可数指标集
下有限支集柱集对补、有限并封闭）。**账本**：

  P(C) := P_{i₁}(A₁) · … · P_{i_k}(A_k)——其余坐标自由，
  概率 1，不进账。

账本良定义（同一柱集的两种写法给同一值——把表示标准化到
同一支集后由独立性账目吸收）、有限可加（不交柱集可标准化到
公共支集，化为有限乘积空间上的有限可加）。**全部技术难点
集中在 σ-可加性验收**：

**验收（严书 §4.4 的核心引理）**：设 Cₙ ∈ Z、Cₙ ↓ ∅，要证
P(Cₙ) ↓ 0。若不然，P(Cₙ) ≥ ε 对一切 n。核心构造：**在每个
有限截段内找"紧见证"**——Cₙ ∩ (∏_{i≤m} K_i) 非空（K_i 为
Ω_i 的紧子集，存在性靠 P_n 在紧集上的近似集中性：{0,1} 离散
紧；ℝ 用 [-M,M]）且测度 ≥ ε/2。紧性的乘积有限交性质
（紧集套原理）给出嵌套非空的有限截段见证，对角线抽取
ω* ∈ ∩ₙ Cₙ——与 Cₙ ↓ ∅ 矛盾。∎（细节在严书 p.98；第 21
章把"紧集 + 近似集中"抽象为紧类/紧测度，证明骨架完全同构。）

验收通过后，第 04 章延拓机器把 P 从代数 Z 唯一延拓到
σ(Z) = ⊗ₙF_n（**独立乘积测度**，记 ∏ₙPₙ）。

## 20.2.5 验收论证的完整细账

把 20.2 的灵魂步骤开成可复查的账单（Cₙ ↓ ∅、P(Cₙ) ≥ ε）：

1. **标准化支集**：一切 Cₙ 限制到前 N 坐标的柱集 Cₙᴺ，对固定
   n 有 Cₙᴺ ↑ Cₙ（N → ∞），故选 N₁ 使 P(C₁^{N₁}) ≥ ε − ε/4；
2. **紧见证**：C₁^{N₁} 是有限乘积空间中的集合，用有限维概率
   的内紧正则性（{0,1}ⁿ 离散紧时免费；ℝⁿ 用紧盒）取紧
   K₁ ⊆ C₁^{N₁} 使 P(C₁^{N₁} ∖ K₁) ≤ ε/8——递归地对 n 做：
   得 N_n ↑ 与紧 K_n ⊆ C_n^{N_n} ∩ π^{-1}(K_{n-1} 前段)，
   每步损耗 ε·2^{-(n+2)}；
3. **紧类套**：D_n := π_{N_n}^{-1}(K_n∩…∩K₁ 的截段) 非空
  （测度 ≥ ε/2 > 0），有限交性质给出嵌套非空的紧截段套；
4. **对角线**：逐层选点 ω_{N_n} ∈ D_n 相容（粘合映射把
   D_{n+1} 压进 D_n），极限 ω* := "坐标取到"的相容族属于
   ∩ₙCₙ——与 ↓ ∅ 矛盾。∎

第 2 步的"有限维紧正则"在 ℝ 上 = **胎紧性**（P( [-M,M] ) ≥
1-δ），第 29/32 章将其定理化为 Polish 空间的普适属性；第
21 章把整个账单抽象成"紧类 + ε/2ⁿ 摊派"的标准件。**读熟
这份账单，第 21 章的推广定理就是换皮重放**。

## 20.3 乘积测度的性质清单

1. **坐标独立**：π_n 在 ∏Pₙ 下的像测度 = P_n；有限族
   {π_{i₁},…,π_{i_k}} 联合独立（第 35 章独立性的定义原文：
   联合分布 = 乘积分布）；
2. **柱集逼近**：一切 E ∈ ⊗F_n 可由柱集在测度内逼近
  （π-λ 定理：柱集代数是 π-系且生成 σ-代数）；
3. **截口/Fubini**：∏ₙPₙ 与有限乘积 (P₁×…×P_m) 经投影对齐，
   有限维分布完全复原——`Measure.pi` 的有限维边际公式；
4. **尾部事件**：σ(π_n : n ≥ N) 的下降交集 𝓣（尾部 σ-代数）
   中事件的概率待第 35 章 Kolmogorov 0-1 律宣判（只能是 0/1）
   ——频率极限 {lim ω̄ₙ = 1/2} 正是尾部事件（第 51 章强大数
   定律的现场）；
5. **任意族推广**：不可数指标集 I 的独立乘积由 Kolmogorov
   相容性定理（第 21 章）或直接柱集延拓（袁 10.4.3：先做
   可数子族，再用有限支集柱集的相容网拼装）得到——每个事件
   只依赖可数坐标（第 17 章"可数本质"），不可数族并没有
   产生新事件，只是允许"任意可数观测窗"。

## 20.3.5 尾部事件的初判：频率极限事件

𝓣 := ∩_N σ(π_n : n > N)（尾部 σ-代数）里的明星事件：

  A := {ω : limₙ (ω₁+…+ωₙ)/n = 1/2}（频率极限）。

**A ∈ 𝓣 的三行证明**：对每个 N，前 N 位换掉不改变极限
（ Cesàro 平均的前 N 项贡献 1/n → 0），故 A 关于 σ(π_n :
n > N) 可测；N 任意 ⟹ A ∈ 𝓣。**A 的概率是多少？**第 20 章
的柱集机器只说"可由柱集逼近"，算不出值——Kolmogorov 0-1 律
（第 35 章）先判 A 的概率 ∈ {0,1}，强大数定律（第 51 章）
再判其为 1。数值通道的频率轨道（20.4 第三组账）正是这条
定理链的蒙特卡罗影子：包络 ~ n^{-1/2} 收缩，极限事件"看起来
概率 1"——**数值证据 ≠ 定理**，但为定理的直觉垫场。同型
尾部事件：limsup ωₙ = 1（概率 1）、Σωₙ/ₙ 收敛（0-1 律判
0/1，三级数定理（第 51 章）判 0）。

## 20.3.6 任意族独立乘积（袁 10.4.3 路线）

I 不可数时的构造：对 I 的每个可数子集 S，20.2 的机器给出
∏_{i∈S}P_i；两个可数 S ⊆ S' 的乘积在 S 上边缘一致（独立性
账目吸收删坐标）。于是柱集账 P(π_S⁻¹(A)) := (∏_S P_i)(A)
**良定义**（不同 S 的收账一致），且有限可加显然。σ-可加性
验收：递减柱集列的支集整体落在**一个可数子集** S* 里
（可数个有限支集的并），一切归结为已验收的 ∏_{S*}——
**不可数族的验收全部转包给可数子族**。这正是第 17 章
"可数本质"定理的第一次实战收益：不可数坐标的表象之下，
测度论的能动范围止于可数窗口。

## 20.4 数值直觉：柱集的测度衰减

均匀硬币柱集 {前 n 个坐标 = 指定花样} 的概率 = 2⁻ⁿ——
**柱集是测度的"望远镜"**：约束越长，窗口越亮（概率越低）。
数值通道的三组账：

- **指定花样**：n = 4, 8, 12，P = 2⁻ⁿ 与模拟频率对拍（10⁶ 段
  投掷，容差随期望命中数缩放：n = 12 时期望命中 ≈ 20，容差 50%）；
- **坐标泛函**：ω ↦ ω_k 的分布 = Bernoulli(1/2) 逐 k 验证
  （独立性 = 联合计数比 1/4，40 万样本、容差 0.01）；
- **频率轨道**：前 n 位均值 mₙ 的轨迹（n 到 10⁴）：|mₙ - 1/2|
  的包络 ~ n^{-1/2}（Chebyshev 界 2/√n 覆盖 ≥ 95% 的轨道点）。

## 20.6 Isabelle：PiM

`HOL-Probability.Infinite_Product_Measure` 的
`product_prob_space` locale：`PiM`（无穷乘积）+ `emeasure_PiM`
（有限框账）+ `distr_PiM_restrict_finite`（有限维边际复原）。
`MT20/T20_InfiniteProducts.thy` 实弹：均匀硬币（`uniform_
count_measure` 于 Bool）的 **n 次全正面柱集账 = inverse 2 的
n 次幂**（局部 interpret + `emeasure_PiM` + `prod_constant`）
与 UNIV 指标下的边际复原。**实测纪律**：全局 `interpretation`
在本版触发子 locale 注册事故（"Illegal fixed variable I"），
必须证明内局部 `interpret` 且带两参（M 与指标集 I）；ennreal
的 `/` 与 `inverse` 在 simp 层不可互换——结论说本地方言
（`inverse (2::ennreal)`）。

## 20.8 要点回顾

1. 无穷乘积不是免费的：柱集代数上的账本要过 σ-可加性验收，
   紧性垫底（有限维紧见证 + 对角线）是验收的灵魂。
2. 验收骨架 = 第 21 章紧类定理的有限维预演。
3. 性能清单：坐标独立、柱集逼近、有限维边际复原、尾部 σ-代数
   交给 0-1 律；任意族靠"每个事件只依赖可数坐标"消化。
4. 机器侧：`Measure.pi`/`pi_pi`/`measurable_pi_apply`；
   Isabelle `PiM`；数值通道三组账（花样/坐标/轨道）。
