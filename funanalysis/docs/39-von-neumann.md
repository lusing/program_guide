# 39 · von Neumann 代数与泛函演算终章

> C* 代数问"范数闭包是什么"，von Neumann 代数问"与谁交换"。

本章覆盖 Conway §IX.7–§IX.8：交换子、双交换子定理、
von Neumann 代数的基本事实、Borel 泛函演算的归宿。

## 39.1 交换子

**定义**。S ⊆ B(H)。**交换子**（commutant）

  S' = {T ∈ B(H) : TS = ST ∀S ∈ S}。

**基本性质**：S' 是范数闭的**酉自伴代数**
（含 1，* 封闭）；S ⊆ T ⟹ T' ⊆ S'；S ⊆ S''。

**有限维例子**（数值实验的主角）：
- D = diag(1..n)（互异对角）⟹ {D}' = 对角阵全体；
- 循环移位 S ⟹ {S}' = 循环阵全体 = {p(S) : p 多项式}。

第二个例子深刻：移位的交换子恰好是移位生成的代数——
**双交换子定理的有限维化身**。

## 39.2 双交换子定理

**定理（von Neumann 1929）**。M ⊆ B(H) 是 *-子代数（含 1）。
则：

  **M'' = vN(M) = M 的 SOT 闭包**。

三个集合一体：双交换子 = 生成的 von Neumann 代数 =
强闭包。

**证明骨架**。⊆ 难方向：设 T ∈ M''，x ∈ H，
要证 Tx ∈ M x 的 SOT 闭包（近似投影论证）：
1. 构造 M 作用在 x 上的轨道闭包 K = closure(Mx)，
   正交投影 P_K 与 M 交换（M 是代数 ⟹ K 不变）；
2. P_K ∈ M'，而 T ∈ M'' ⟹ T 与 P_K 交换 ⟹ TP_Kx ∈ K；
3. 但 P_Kx = x（x ∈ K），故 Tx ∈ K = closure(Mx)：
   **Tx 可被 M 的元素强逼近**；
4. 多向量情形（同时逼近 x₁..xₘ）用 H 的直和幂技巧。∎

**意义**："SOT 闭 *-代数"（拓扑定义）= "双交换子"
（纯代数定义）。判断一个算子属于 vN 代数不需要拓扑：
**只查交换表**。数值实验正是这么做的：
解线性方程 SX = XS，数核的维数。

## 39.3 von Neumann 代数的基本事实

**定义**。B(H) 的 *-子代数 M 含 1 且 SOT 闭
（等价：M = M''），称 **von Neumann 代数**（W*-代数）。

**对比 C* 代数**：
| | C* 代数 | vN 代数 |
|---|---|---|
| 闭包 | 范数闭 | SOT 闭 |
| 判据 | — | M = M''（代数判据） |
| 对偶 | 一般无预对偶 | 有预对偶 M*（唯一） |
| 函数演算 | 连续 | **有界 Borel** |
| 例子 | K(H) | B(H), L∞(μ), 群生成代数 |

**Borel 演算落户 vN 代数**：正规 N ∈ M(vN) ⟹
f(N) ∈ M 对一切有界 Borel f（谱投影 E(Δ) ∈ M）。
这是 vN 代数比 C* 代数"大"的实质：
谱测度的全部投影都留在代数内。

**因子**（factor）：中心 M ∩ M' = ℂ·1。
B(H) 是因子；M ≅ ⊕ 因子（直积分解）是分类纲领。
量子力学的超选择结构 = 因子分解。

**Abelian 模型**：L∞(μ) 作用在 L²(μ) 上是
交换 vN 代数的万有模型（谱定理的 vN 版）。

## 39.4 Kaplansky 稠密定理

**定理**。M 是 B(H) 的 *-子代数，M̄^{SOT} = M''。
则**单位球**（乃至任意范数球）内也稠：
ball M 在 ball M'' 中 SOT 稠密。

**用途**：证明 vN 代数性质时可以"降到范数有界"，
配合第 23 章的可度量化结果把网收敛换成序列收敛。

## 39.5 谱定理的 vN 总结

正规算子 N 生成的 vN 代数：

  vN(N) = {f(N) : f 有界 Borel} = {N}''。

三重等式把本书第二篇以来的主线收拢：
- 谱测度 E 的值域投影全部住在 vN(N)（第 36 章）；
- 中心 vN(N) ∩ vN(N)' = {g(N)}（g Borel）；
- N 的**重数**（第 40 章）= vN(N)' 的结构。
