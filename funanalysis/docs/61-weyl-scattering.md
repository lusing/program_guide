# 61 · Weyl 交换关系与散射理论

> 量子力学的数学骨架是一条交换关系 [A,B] = iI 与它的 Weyl 指数
> 形式；散射理论则问：扰动后的动力学在 t = ±∞ 时与自由动力学
> 差多少。两个主题共享酉群的语言。——Lax 第 35.6、37 章（意译）

本章覆盖 Lax 第 35.6 节（Heisenberg 交换关系、不确定性原理的
判别式证明、Wielandt 无界性、**Weyl 形式**、**von Neumann 唯一性
定理**）与第 37 章主干（Rellich 扰动论、Weyl 本质谱定理、波算子、
散射算子、Lax-Phillips 理论概览）。

## 61.1 Heisenberg 交换关系与不确定性原理

**定义**。状态 = 单位向量 u；可观测量 = 自伴算子 A；期望值
a = (u, Au)；**不确定度** Δ(A, u) = ‖Au − au‖（(27)）——零当且
仅当 u 是 A 的本征态。

**Heisenberg 交换关系**：

```
AB − BA = iI。                                        (28)
```

**定理 10（不确定性原理）**。满足 (28) 的自伴对：

```
Δ(A, u)·Δ(B, u) ≥ 1/2。                              (29)
```

**证明**（判别式法，四行）：对任意实 t，Schwarz 给

```
|(u, Au + itBu)|² ≤ ‖Au + itBu‖²。
```

展开两侧，(28') 的交叉项恰为 −t·(‖u‖²)·1/2 型的线性项，整理成
t 的二次多项式非负 ⟹ **判别式 ≤ 0** ⟹ (29)。∎

**Wielandt 论证**：(28) 无有界解。归纳给 i·nB^{n−1} = ABⁿ − BⁿA，
取范数：n‖B^{n−1}‖ ≤ 2‖A‖‖B‖‖B^{n−1}‖ ⟹ n ≤ 2‖A‖‖B‖ 矛盾。∎

**标准实现**：L²(ℝ) 上 A = i(d/dμ)、B = 乘以 μ——本教程 44 章的
数值主角（Heisenberg 不等式 Gaussian 饱和 0.5）。

## 61.2 Weyl 形式与 von Neumann 唯一性

**Weyl 形式**：把 (28) 积分成群语言：

```
U(s)BU(−s) = B − sI，      U(s) = e^{isA}。             (32)
```

等价的**对偶形式**（Ex.5，对 t 求导）：

```
U(s)V(t) = e^{ist}V(t)U(s)，    V(t) = e^{itB}。        (33)
```

——两酉群的**交换扭曲**关系，优点是一切算子有界、等式在全域成立
（(28) 的域问题消失）。

**定理 11（von Neumann 唯一性）**。满足 Weyl 关系的自伴对 (A, B)
实现为：H ≅ L²(N, ℝ)，B = 乘以 μ，A = i(d/dμ)（N = 重数空间）。

**证明骨架**：B 的谱测度 E 经 (35) U(s)E(T)U(−s) = E(T+s)——
**平移表示定理**（35.5 节，Sinai 的独立证明）把 H 映成 L²(N, ℝ)
且 B 成为乘 μ、U(s) 成为平移；A 的生成元性质补完。∎

这是量子力学的数学基础定理：**正则共轭对在酉等价意义下唯一**。

## 61.3 扰动论：孤立的简单特征值

**定理 1**。α 是 A 的孤立单重特征值，D 有界对称（‖D‖ ≤ 1）。
则 ε 小时 A + εD 在 [α−ε, α+ε] 有孤立单重特征值，且**解析依赖
于 ε**。

**证明**：**Riesz 投影**（围道积分）：

```
P = (1/2πi)∮_C (ζ − A)⁻¹dζ，    P_ε = (1/2πi)∮_C (ζ − A − εD)⁻¹dζ。
```

P 是到特征空间的投影；‖P − P_ε‖ → 0；**引理 2**（投影差范数 < 1
⟹ 秩相同）给单重性保持。特征值对 ε 的解析性来自 **Puiseux 论证**：
代数函数的 Puiseux 展开若有 e^{1/r} 分支（r > 1）则复值分支出现，
与 A + εD 的自伴性（谱实）矛盾 ⟹ 解析。∎

## 61.4 Weyl 本质谱定理与谱凝结

**定理 3（Weyl）**。α 属于 A 的本质谱（E(I) 无穷维），C 对称
紧：则 α 属于 A + C 的本质谱。

**证明**：C = F + S（有限秩 + ‖S‖ < η）；在 E(α−η, α+η) 的无穷维
值域中取 x ⊥ 一切 F 的特征向量：(4) ‖(A + C − α − iη)x‖ < 3η‖x‖
⟹ 预解范数 > 1/3η ⟹ α ∈ 谱且本质。∎

**谱凝结（spectral curdling）**：反面警告——存在任意小的紧（甚至
迹类外任意 p-范，von Neumann/Kuroda）扰动 C 使 A + C 的谱变成
**稠密的纯点谱**！连续谱对紧扰动**不稳定**；但 **Rosenblum 定理**
（Kato 形式）：迹类扰动保持绝对连续谱——第 56 章的迹类在此成为
正面的主角。Weyl 定理说"本质谱集合不动"，Rosenblum 说"连续部分
的类型也不动"——两句话层次不同。

## 61.5 波算子与散射算子

**定义**。A、B 自伴，波算子

```
W(t) = e^{itB}e^{−itA}，    W± = s-lim_{t→±∞} W(t)。
```

**基本性质**（(7)(9)(9″)）：W± 等距；** intertwining**：
W±A = BW±（差商 + 极限）——谱的 A-部分被共轭到 B-部分。

**存在性**（Rosenblum-Kato，述）：resolvent 差为迹类（Kato smooth
条件）时 W± 存在且完备。

**散射算子**：

```
S = W₊* W₋：    与 A 交换，S 的谱乘法刻画（谱表示下 S = 乘
以单位模函数 s(λ)）。
```

物理意义（Møller 1945 的时变图像）：t → +∞ 时扰动系统渐近自由
态 u₊，t → −∞ 时渐近 u₋；**S 把 u₋ 送到 u₊**——实验的全部信息
（截面）都在 S 的矩阵元里。Heisenberg 1943 的纲领：从 S 重建
位势（逆散射）；历史上 OSS 刺杀 Heisenberg 的轶事，Lax 原书
注记（Hoyt 审查其 1943 年两篇论文后判定与武器无关——"这可能
救了 Heisenberg 的命"）。

**Lax-Phillips 理论**（37.7，概览）：入子空间 F₋ 与出子空间 F₊
（(17a-c)：不变性、交零、并稠）⟹ 平移表示（35.5 定理）把酉群
变成 L²(N, ℝ) 的平移，F∓ 变成 L²(N, ℝ∓)。**散射算子 S：k₋ ↦ k₊**
满足：酉、与平移交换（因果性）、保 L²(ℝ∓)——因果的酉"滤波器"。
波方程外障碍散射与自守波动方程（Riemann 假设的联系！）是两大
应用，本书从略。

## 61.6 Julia 数值实验

实验文件 `examples/julia/61_weyl_scattering.jl`。

**实验 1：Weyl 关系的数值验证**。ℓ² 截断上 S = 移位（B = S+S*），
U = 对角相位（A = diag）：验证 U(s)V(t) = e^{ist}V(t)U(s)（离散
有限维版本，残差 ~ 1e-14）与 U(s)BU(−s) = B − sI 的形式差。

**实验 2：一维势散射的 Jost 解与散射矩阵**。Schrodinger 方程
−u″ + V u = k²u，V = sech² 型位势（可解势，反射系数已知）：
数值打靶（从 ±∞ 的指数行为积分进来）求 Jost 解，匹配出透射/反射
系数 |T(k)|² + |R(k)|² = 1（幺正性）；与无反射势（sech² 特定
系数）的解析透射 T = 1 对照。

**实验 3：波算子的有限维影子**。B = A + 紧扰动的有限维对：
W(t) = e^{itB}e^{−itA} 的演化在"相位平均"意义下收敛的演示——
取 A、B 谱错开的对角矩阵，W(t) 的对角元振荡不收敛，但对角平均
收敛到投影的形态（有限维中波算子退化的诚实说明）。

**实验 4：不确定性原理的饱和**。Gaussian 族 u_σ = e^{−μ²/2σ²}：
ΔA·ΔB 随 σ 的曲线在 σ = 1 处取最小 1/2（44 章数值在此以 Weyl
语言重述），偏离 σ=1 两侧上升。

## 61.7 Python 数值实验

实验文件 `examples/python/61_weyl_scattering.py`。

**实验 1：Wielandt 论证数值演示**。随机有界矩阵对 A、B：归纳
计算 ‖ABⁿ − BⁿA‖/n 随 n 的衰减（有界情形必衰减）与 iI 的下界
矛盾——交换关系不可有界满足的数值形态。

**实验 2：紧扰动的本质谱稳定 + 谱凝结对照**。A = 对角（含聚类
的本征值模拟本质谱），C = 小秩一扰动：谱集合稳定（区间级）；
再取 C = 随机小扰动（von Neumann 型，在聚类内撒点）：点谱稠密
化——两种扰动的谱图对照。

**实验 3：一维散射的 Lippmann-Schwinger 数值**。用格林函数
积分方程 (I − V G₀)ψ = ψ₀ 的离散求解（k 三档）：|T|²+|R|² = 1
幺正性检查；散射矩阵元 s(k) 的辐角绕数（相移 δ(k) 的单调性）。
