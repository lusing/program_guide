# 51 · 弱收敛的应用：求和法、Fourier 发散、Galerkin 方法

> 弱收敛不是拓扑装饰：它是把"不存在的好对象"换成"存在的一致
> 估计"的工艺。Toeplitz 的 δ 函数判据、Fourier 级数的发散、
> Galerkin 的存在性证明、Dunford 的弱=强解析——四件事共享同一
> 台引擎：一致有界原理。——Lax 第 11 章（意译）

本章覆盖 Lax 第 11 章全部六节：δ 函数的连续逼近（Toeplitz 定理）、
Fourier 级数的发散（du Bois-Reymond）、逼近求积、向量值函数的
弱解析 ⟹ 强解析（Dunford 定理）、偏微分方程解的 Galerkin 存在性、
正实部解析函数的表示（Herglotz-Riesz 定理）。

## 51.1 Toeplitz 定理：δ 函数的连续逼近

**定义**。[kₙ] 是 [−1, 1] 上的连续函数列。称 kₙ → δ，若

```
∫ f(t) kₙ(t) dt → f(0)    对一切连续 f。
```

（即 kₙ 在测度意义下弱* 收敛于 Dirac 测度。）

**定理（Toeplitz，Lax 第 11 章定理 1）**。kₙ → δ 当且仅当：

1. ∫kₙ dt → 1（总质量归一）；
2. 对每个支集不含 0 的 C∞ 函数 g：∫g·kₙ dt → 0（质量向 0 集中）；
3. **∫|kₙ| dt ≤ C 对一切 n 一致有界**（绝对质量不失控）。

**证明**。（⟸）设 f(0) = 0。取 C∞ 的 g 与 f 差 < ε 且在 0 附近
为零，则 |∫f kₙ| ≤ |∫(f−g)kₙ| + |∫g kₙ| ≤ Cε + o(1)。ε 任意。
一般 f 减去 f(0)·(单位质量的核) 归结到此情形。

（⟹）1、2 是取特定检验函数的特例。3 的必要性是弱* 收敛的一致
有界原理（第 10 章定理 3）：kₙ ∈ C[−1,1]′，逐点收敛于 δ ⟹
算子范数 ‖kₙ‖ = ∫|kₙ|dt 一致有界。∎

**推论 1′**。若条件 3 破坏，则存在连续 f 使 ∫f·kₙ dt → ∞——
坏的核不仅是"不收敛"，而是**必然找到受害者**。

## 51.2 Fourier 级数的发散

**定理（Lax 第 11 章定理 2）**。存在连续周期函数，其 Fourier
级数在某点发散。

**证明**。连续函数 f 的 Fourier 级数在 0 处的部分和是

```
S_N f(0) = ∫ f(θ)·k_N(θ) dθ，k_N = D_N/2π
```

其中 **Dirichlet 核**

```
D_N(θ) = Σ_{|n|≤N} e^{inθ} = sin((N+1/2)θ)/sin(θ/2)
```

（有限几何级数求和）。于是"每个连续函数的 Fourier 级数在 0
收敛" ⟺ k_N 满足 Toeplitz 三条件。条件 1、2 成立（正交性），
但条件 3 **崩溃**：

```
∫|D_N| dθ ≥ c·log N
```

（用 |sin t| ≤ |t|：被积函数在 |θ| < 1/(N+1/2) 外 ≥ c/|θ|，
积分发散于 log N。）由推论 1′，存在连续 f 使 |S_N f(0)| → ∞。∎

这与第一卷 06 章（Fourier 级数 L² 收敛）形成精确的对偶：**L²
里一切美好，C⁰ 里连逐点收敛都保不住**——因为 L² 的正交结构
控制的是 ℓ² 系数，而逐点求值是 C⁰ 的泛函。数值实验 1 将测量
‖D_N‖₁ 的对数增长，并构造"受害者"函数。

**对照**：Fejér 核 K_N（Dirichlet 核的 Cesàro 平均）非负，故
∫|K_N| = ∫K_N = 2π——三条件全满足，Fejér 平均对一切连续函数
一致收敛（第一卷 06 章的 Fejér 定理）。**取平均治愈了发散**，
代价是收敛速率失去对角化结构。

## 51.3 逼近求积

**定理（Lax 第 11 章定理 3）**。求积公式 q_N(f) = Σⱼ wⱼ^(N) f(tⱼ^(N))
对一切连续 f 收敛于 ∫f 当且仅当：

1. q_N 对每个单项式 t^k 收敛于 ∫t^k（多项式层校准）；
2. Σⱼ|wⱼ^(N)| ≤ C 一致有界（权的绝对和有界）。

证明：1 + Weierstrass + 2（一致有界）= 一致逼近收敛。逆向由
一致有界原理的逆（第 10 章定理 3 的逆形式）。若权**非负**，
则 2 由 1 自动给出（Σw = q_N(1) → 2）。∎

这解释了数值积分的黄金律：**Gauss 求积（权恒正）对一切连续
函数收敛；高阶 Newton-Cotes（权出现大负数）不收敛**——不是
精度不够，是 Toeplitz 条件 2 被破坏。实验 3 将实测。

## 51.4 Dunford 定理：弱解析 ⟹ 强解析

设 f 取值于复 Banach 空间 X、定义于域 G。**强解析**：差商依
范数收敛。**弱解析**：对每个有界泛函 l，l(f(ζ)) 经典解析。

**定理（Dunford，Lax 第 11 章定理 4）**。弱解析 ⟹ 强解析。

**证明**（二阶差商的技巧）。由 Cauchy 积分公式，对足够小的
h、k（|h| ≤ |k|）：

```
l[ (f(ζ+h) − f(ζ))/h − (f(ζ+k) − f(ζ))/k ] = (1/2πi)∮ l(f(x))·[hk 之核] dx
```

曲线上一致估计给 |l(X_{h,k})| ≤ M(l)（X_{h,k} 是二阶差商向量，
h、k 一致小时）。**X 的元素作为 l 的函数逐点有界 ⟹ 一致有界
原理 ⟹ ‖X_{h,k}‖ ≤ C**。于是 f 的差商是 Cauchy 序列方向，
X 完备 ⟹ 强差商极限存在。∎

这个证明是**一致有界原理最漂亮的应用**：弱条件 + PUB ⟹ 强
结论。数值实验 4 以矩阵值函数 F(ζ) = e^{ζA} 为模型：随机场
泛函 l_v(x) = ⟨v, x⟩ 下 l_v(F) 的解析性（CR 方程）与 F 差商
的范数收敛同时验证。

## 51.5 Galerkin 方法：PDE 解的存在性

**定理（Lax 第 11 章定理 5）**。L = ΣAⱼ∂/∂sⱼ + B 是周期向量
函数上的一阶算子，Aⱼ 对称一次可微、B 连续，且

```
B + Bᵀ − Σ∂Aⱼ/∂sⱼ ≥ kI（一致正定）
```

则周期方程 Ly = f 对每个平方可积 f 有平方可积的分布解。

**证明骨架**（完整谱系值得逐条看）：

1. **能量估计**：(u, Lu) = ½([B+Bᵀ−ΣA_{j,j}]u, u) ≥ (k/2)‖u‖²
   ——由 Aⱼ 对称性，一阶项的反对称部分在配对中消失。
2. **有限维解**：对任 N 维子空间 Y ⊆ C¹ 周期函数，Galerkin
   方程 (Ly, v) = (f, v)（v ∈ Y）有唯一解 y_N——能量估计给
   齐次方程无非零解，线性代数收尾。
3. **一致界**：‖y_N‖ ≤ (2/k)‖f‖——能量估计 + Schwarz。
4. **弱极限**：L² 自反 ⟹ 弱收敛子列 y_{n_j} ⇀ y（第 10 章定理 7）。
5. **传递极限**：对每个可微检验 v，(L*v, y) = (v, f)——弱收敛
   恰好足够把线性配对穿过极限。
6. **分布解**：上式即 Ly = f 的分布意义；Friedrichs 的正则化
   论证进一步给强解与唯一性。∎

**Galerkin 方法是理论构造也是实用算法**（Lax 原话）：现代有限
元法的一切收敛性证明都是这六步的变奏。数值实验 2 在一维周期
模型 u′ + u = f 上演示 Fourier-Galerkin 的谱收敛。

## 51.6 Herglotz-Riesz 定理

**定理（Lax 第 11.6 节）**。f 在单位圆盘解析、Re f ≥ 0。则存在
圆周上的正有限测度 μ 使

```
f(ζ) = i·Im f(0) + ∫ (e^{it} + ζ)/(e^{it} − ζ) dμ(t)，
μ(圆周) = Re f(0)。
```

反之，任何这种积分给出正实部解析函数。

**证明思路**。h = Re f ≥ 0 调和。Poisson 积分公式把 h(Re^{iθ})
从半径 R < 1 的边界值恢复；h(Rₙe^{iθ}) 是圆周上**非负、总质量
= h(0) 一致有界**的函数列（中值公式），故测度列弱* 紧（对偶
的弱* 紧性——Banach-Alaoglu 的可分形式，第 12 章的预告），
极限测度 μ ≥ 0 给出表示。∎

正实部解析函数 = **圆周上的正测度**：这是第 44 章（矩问题）
与第 57 章（自伴算子的谱测度）都将重演的模式——**正性 + 解析
性 ⟹ 测度表示**。数值实验 3 验证典型例 f(ζ) = (1+ζ)/(1−z)（μ =
2δ₀ 型）的 Poisson 重构。

## 51.7 Julia 数值实验

实验文件 `examples/julia/51_weak_applications.jl`。

**实验 1：Dirichlet 核的 log 增长与 Fejér 的治愈**。测量
‖D_N‖₁/(2π) 在 N = 2^k（k ≤ 15）：与 (4/π²)log N 线性拟合
（斜率 ∈ (0.35, 0.48)）；‖K_N‖₁/(2π) = 1 恒定。构造受害者
f = Σⱼ εⱼσⱼ·(光滑化 sign D_{Nⱼ})（Nⱼ 倍增、权递减保连续），
实测 S_N(f)(0) 沿子列增长。

**实验 2：Fourier-Galerkin 谱收敛**。周期问题 u′ + u = f 取
f = exp(cos t)：对角系统 (in+1)ûₙ = f̂ₙ，系数按 |f̂ₙ| ~ e^{−n}
指数衰减（f 解析），断言 L² 误差 ~ 机器精度，并验证能量估计
‖u‖ ≤ ‖f‖（k = 2 的情形）。

**实验 3：求积公式的分水岭**。Gauss-Legendre（N ≤ 60 权全正）
对 e^t 积分误差 → 0；Newton-Cotes 高阶（N ≥ 20 权出现负、绝对和
指数增长）对病态函数（|t−1/2|^{1/2} 型）发散。输出两类公式
的 Σ|w| 表。

**实验 4：Dunford 定理的数值影子**。F(ζ) = e^{ζA}（随机 6×6
矩阵）：(a) 随机场 v（500 个）下 l_v(F) 的 CR 残差 O(h²)；
(b) F 的差商范数 ‖(F(h)−F(0))/h − A‖ → 0（谱方法 expm 对照）。

**实验 2：Galerkin 与能量估计**。同 Julia 实验 2 的周期问题 +
