# 43 · 无界谱定理与 Stone 定理

> 谱定理对无界自伴算子一字不改地成立；Stone 定理把它变成"时间演化"。

本章覆盖 Conway §X.4–§X.5：无界自伴算子的谱定理、
Borel 函数演算的无界版、**Stone 定理**
（强连续酉群 ⟺ 自伴生成元）。

## 43.1 无界谱定理

**定理**。T 自伴（无界，稠定闭）。存在唯一 PVM E
（支撑于 ℝ，可能无界），使

  **T = ∫_{ℝ} t dE(t)**，Dom(T) = {x : ∫ t² dμ_x < ∞}。

一切定理照旧：三形态（谱积分/函数演算/乘法模型）
互相翻译，只是函数与测度允许无界。

**乘法模型**：T 酉等价于 L²(μ) 上的 M_t（乘以自变量），
Dom = {f : ∫t²|f|² < ∞}。

**无界谱长什么样**：
- M_x 在 L²(ℝ)：σ = ℝ（整条实轴）；
- -d²/dx² 在 [0,1]（DD）：σ = {n²π²}——无界**离散**谱；
- 调和振子：σ = {n + ½}——等距伸向无穷。

数值化身：diag(1²,...,n²) 是最纯的模型：
域 = {x : Σn⁴|xₙ|² < ∞}。xₙ = n⁻³ 在域内（Σn⁻² < ∞）、
xₙ = n^{-3/2} 不在（Σn 爆炸）；√T = diag(n) 的演算照常
（(√T)² = T 到机器精度）。**无界只是"权重无界"，
对角化结构一根毫毛都没少。**

## 43.2 Borel 演算（无界版）

f: ℝ → ℂ Borel 可测 ⟹

  f(T) = ∫ f dE，Dom = {x : ∫|f|² dμ_x < ∞}。

f 实值 ⟹ f(T) 自伴；f 有界 ⟹ f(T) 有界；
f = 1/(t-z) ⟹ f(T) = (T-z)⁻¹（预解式重回怀抱）。
谱映射 σ(f(T)) = f(σ(T)) 的**本性值域**版照常成立。

## 43.3 Stone 定理

**定理（Stone 1932）**。{U(t)}ₜ∈ℝ 是 B(H) 上的
**强连续**酉群（U(s)U(t) = U(s+t)，U(t)* = U(-t)，
t ↦ U(t)x 连续）。则存在**唯一**自伴算子 A（可无界）：

  **U(t) = e^{itA}**，A 称群的生成元。

**证明骨架**。
1. 弱意义下构造 A：对 x ∈ Dom（使极限存在的 x），
   Ax = lim_{t→0} (U(t)x - x)/(it)；
2. 验证 A 稠定对称自伴（群性质 ⟹ 域在 U(t) 下不变）；
3. Cayley 变换（第 42 章）把问题化为酉算子的谱理论；
4. 用谱积分反解 U(t) = ∫e^{itλ}dE(λ)。∎

**强连续不可省**：酉群只在弱/强下连续（范数连续 ⟺ 生成元有界，
对无界演化物理上恰恰需要）。数值化身：‖U(t)x - x‖ ≤ |t|‖Ax‖
——生成元给强连续一个 Lipschitz 界（实验直接验证）。

**物理**：量子时间演化 ψ(t) = e^{-iHt/ℏ}ψ₀；
Schrödinger 方程 = Stone 定理的微分侧。
经典力学对应：Hamilton 流 = 李群作用。

## 43.4 生成元与扩散

- 群 ↦ 生成元：A = dU/dt|₀（弱导数）；
- 生成元 ↦ 群：指数级数一般不收敛（A 无界），
  必须走谱积分或 Yosida 逼近（有界逼近 + 极限）；
- **乘法模型下 Stone 平凡化**：M_λ 生成的群 =
  乘 e^{itλ}——一切酉群都是"某个乘法模型上的相位旋转"。

## 43.5 谱定理的最终统一视图

| 算子类 | 谱定理形式 | 章节 |
|---|---|---|
| 紧正规 | 可数对角 ΣλₙPₙ | 13 |
| 有界正规 | 谱测度积分 ∫z dE | 36-37 |
| 无界自伴 | ∫t dE（域内） | 43 |
| 酉群 | e^{itA} = ∫e^{itλ}dE | 43 |

从紧算子的可数对角化到无界自伴的谱积分，
**同一根脊柱**：对角化 = 找到那个 PVM。
数值线性代数的 eig/eigh 每天都在兑现这个承诺。
