# 14 · 赋范空间与 Banach 空间

> Banach 空间的几何处于黑暗之中。——Conway 第 II 章开篇（意译）

Hilbert 空间有内积提供的丰富几何；Banach 空间只有范数。本章覆盖
Conway §III.1–§III.4：赋范空间的基本结构、完备化、商空间、
有限维的刻画。

## 14.1 赋范空间与 Banach 空间

**定义**。线性空间 X + 范数 ‖·‖（三角不等式、齐性、正定）。
度量 d(x,y) = ‖x−y‖ 自动生成。**Banach 空间** = 完备赋范空间。

**标准例子**。
- 𝔽ⁿ（任何范数，都完备）。
- L^p(μ)（1 ≤ p ≤ ∞）：Riesz-Fischer 定理 ⟹ 完备。
- C(K)（紧 K 上的连续函数，上确界范数）：一致收敛 ⟹ 完备。
- c₀（趋于零的序列，上确界范数）：完备。
- ℓ^p（p-可和序列）：完备。

**不完备的例子**。
- c₀₀（有限支撑序列）在 ‖·‖_∞ 下不完备（完备化为 c₀）。
- C[0,1] 在 L¹ 范数下不完备（完备化为 L¹）。
- C[0,1] 在 L² 范数下不完备（完备化为 L²）。

**完备化定理**。任何赋范空间有唯一的（等距意义下）完备化。
构造：取 Cauchy 列的等价类（如同 Cantor 从 ℚ 构造 ℝ）。

## 14.2 有界线性算子

第 07 章的全部结果（B(X,Y) 是赋范空间、次乘性、完备性条件）
对 Banach 空间同样成立。

**关键事实**：Y 完备 ⟹ B(X,Y) 完备——不需要 X 完备。
这使得"取逐点极限"永远可行。

## 14.3 有限维赋范空间

**定理**。有限维赋范空间：
- 自动完备（等距同构于 𝔽ⁿ + 某个范数，𝔽ⁿ 一切范数完备）。
- 单位球**紧**（Heine-Borel）。
- 一切范数**等价**（相互控制，拓扑相同）。

**Riesz 引理**。X 赋范空间，Y ⊊ X 闭子空间，0 < θ < 1。
则存在 xθ，‖xθ‖ = 1，dist(xθ, Y) ≥ θ。

**推论**。赋范空间局部紧（某有界集有紧闭包）⟺ 有限维。

这是 Hilbert 空间与 Banach 空间的第一个深刻分歧：无穷维
Hilbert 空间有很多紧集（有限秩算子的像），但无穷维空间的
单位球永远不紧。

## 14.4 商空间

**定义**。M ⊆ X 闭子空间。商空间 X/M：元素是陪集 x + M。
范数：‖x + M‖ = inf{‖x + m‖ : m ∈ M} = dist(x, M)。

**定理**。(X/M, ‖·‖) 是赋范空间，且：
- M 闭 ⟹ 范数正定；
- X 完备 ⟹ X/M 完备；
- 商映射 π: X → X/M 满足 ‖πx‖ ≤ ‖x‖（范数 ≤ 1 的开映射）。

商空间是 Fredholm 理论（第 45 章）的基本构造。

## 14.5 积空间

X × Y 赋范 ‖(x,y)‖ = max(‖x‖, ‖y‖)（或任何等价范数）。
完备 ⟺ 两个分量都完备。

## 14.6 数值实验

**Julia**（`14_banach_spaces.jl`）：
(1) **完备化**：e^x 的 Taylor 级数在 C[0,1] 中 Cauchy 且收敛
（度 5 误差 < 0.002，度 15 误差 < 10⁻¹²）；(2) **商范数**：
M = span{e₁} ⊂ ℝ³，‖x+M‖ = √13 精确；(3) **Riesz 引理的数值
化身**：1000 维随机单位向量的 |cos| < 0.1——高维空间中可以
构造几乎正交的向量序列 ⟹ 单位球不紧。

**Python**（`14_banach_spaces.py`）：同组实验。
