# 34 · C* 代数与 Gelfand-Naimark 定理

> 一条恒等式 ‖a*a‖ = ‖a‖²，撑起整个算子代数大厦。

本章覆盖 Conway §VIII.1–§VIII.2：C* 代数公理、
伴随代数的基本事实、**Gelfand-Naimark 定理**
（交换 C* 代数 = 连续函数代数）。

## 34.1 C* 代数公理

**定义**。复 Banach 代数 A 带**对合** a ↦ a*
（共轭线性 + 反序 + 幂等：(ab)* = b*a*，a** = a），
满足 **C* 恒等式**

  **‖a*a‖ = ‖a‖²**

则称 A 为 **C* 代数**。

**首要例子**：B(H)（伴随 = Hilbert 伴随）。
‖T*T‖ = ‖T‖² 的证明是 Hilbert 空间理论的经典练习：
‖T*T‖ ≤ ‖T‖² 显然；反向取 y = Tx/‖Tx‖，
‖T*T‖‖x‖² ≥ ⟨T*Tx, x⟩ = ‖Tx‖²，再对 x 取 sup。∎

**公理的苛刻性**：C* 恒等式强到
- **范数被 * 结构唯一决定**：满足恒等式的范数只有一个
  （对自伴元 ‖a‖² = ‖a²‖ 递归固定）；
- **乘法范数自动次乘**；
- 例子：C(K)（f* = f̄，sup 范数）；
  紧算子 K(H)；矩阵代数 Mₙ(ℂ)；任何 B(H) 的闭 *-子代数。

数值化身：随机复矩阵上 ‖A*A‖ = ‖A‖² 到机器精度
（注意必须用**算子范数**，Frobenius 范数不满足）。

## 34.2 基本事实速览

- a 自伴（a* = a）⟹ σ(a) ⊆ ℝ；
- a 正规（aa* = a*a）⟹ r(a) = ‖a‖；
- **a = b + ic**（b, c 自伴）：b = (a+a*)/2, c = (a-a*)/2i
  ——任何元素拆成两个自伴元，C* 代数 = "自伴部分的复化"；
- **U(a) = {u : u*u = uu* = 1}**（酉元）：
  σ(u) ⊆ 单位圆周，u ↦ σ 的结构在第 42 章 Cayley
  变换再度登场（无界版）。

## 34.3 Gelfand-Naimark 定理（交换版）

**定理（Gelfand-Naimark 1943）**。A 交换 C* 代数。
则 Gelfand 变换 Γ: A → C(Δ(A)) 是**等距 *-同构**：

  A ≅ C(Δ(A))。

**证明骨架**。
1. a 自伴 ⟹ σ(a) ⊆ ℝ（若 λ = α+iβ ∈ σ(a)，β≠0，
   用 It = exp(i t a*)-型扰动列推出矛盾）；
2. 对任意 a：Γ(a*)(φ) = φ(a*) = φ(a)‾
   （特征在 * 下共轭）⟹ Γ 保对合；
3. ‖Γ(a)‖² = ‖Γ(a*a)‖ = r(a*a)^{1/2·} = … =
   ‖a‖²（自伴元上谱半径 = 范数）⟹ Γ 等距；
4. 等距 + 含 1 + Stone-Weierstrass（Γ(A) 是 C(Δ) 的
   闭自伴子代数且分离点）⟹ Γ 满。∎

**意义**：交换 C* 代数**只有一种**——某个紧空间上的
连续函数。代数结构（乘法、对合、范数）完整编码了
几何（空间 Δ）。与 Banach-Stone（第 27 章）合读：
**几何 ↔ 代数的双语词典自此完备**。

非交换推广（Gelfand-Naimark 一般版）：任何 C* 代数
都同构于某 B(H) 的闭 *-子代数——证明需要 GNS 构造
（第 35 章）。

## 34.4 谱的函数演算（连续版）

对正规元 a ∈ A 与 f ∈ C(σ(a))，定义

  **f(a) := Γ⁻¹(f ∘ Γ_a)**

其中 Γ_a 是由 a 生成的交换 C* 子代数 C*(a) ≅ C(σ(a))
的 Gelfand 变换。性质：
- 连续泛函演算：C(σ(a)) → C*(a) 是等距 *-同构；
- σ(f(a)) = f(σ(a))（谱映射，连续版）；
- 把第 31 章的全纯演算**扩张**到连续函数——
  正规算子的 f(T) 从此对任何连续 f 有意义，
  这是第 36–37 章谱定理的代数侧写。

## 34.5 单位化与理想

- 无单位元的 C* 代数 A ⟹ 单位化 A₁ 仍是 C* 代数；
- **闭双边理想自动是 *-理想**（I 理想 ⟹ I* = I，
  C* 恒等式的礼物）；
- 商 A/I 仍是 C* 代数——理想与商比一般 Banach 代数
  （第 29 章）规矩得多。这条链通向第 35 章的表示论。
