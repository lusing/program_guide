# 50 · 对偶逼近：Müntz 定理与 Runge 定理

> "一族函数张成全空间吗？"——把这个定性问题交给对偶空间：
> 张成 ⟺ 没有非零泛函在它上面消失。Banach 的对偶理论把逼近论
> 的一批存在性问题变成了复分析的计算。——据 Lax 第 9 章（意译）

本章覆盖 Lax 第 9 章：张成判据（第 8 章定理 8 的复述）、加权幂的
完备性（定理 1）、**Müntz 逼近定理**（定理 2，Blaschke 乘积证明）、
**Runge 定理**（定理 3，Hörmander 的证明——"这个漂亮的证明属于
Lars Hörmander"，Lax 原注），以及对偶变分问题与共形映射（定理 4，
Garabedian-Schiffer）。

## 50.1 张成判据

**定理（张成判据，Lax 第 8 章定理 8）**。X 是赋范线性空间，
{x_α} ⊆ X。则 span{x_α} 稠密于 X 当且仅当：X 上每个在所有 x_α
处为零的有界线性泛函 l 必为零泛函。

**证明**。（⟸）若闭包 Y ≠ X，取 y ∉ Y；Y 闭子空间，由 Hahn-Banach
分离（第一卷 15 章推论），存在有界泛函 l 使 l|_Y = 0 而 l(y) ≠ 0，
与假设矛盾。（⟹）连续泛函在稠密集上为零则处处为零。∎

这是本章所有定理的**总开关**：把"逼近存在性"翻译成"泛函的刚性"。
配合下一条引理使用：

**引理（解析依赖原理）**。若 x(ζ) 是取值于 X 的解析函数（依范数
拓扑解析），l 是有界线性泛函，则 ζ ↦ l(x(ζ)) 是经典解析函数，且
l(dx/dζ) = d(l(x))/dζ。

证明：差商与 l 交换（线性 + 有界 ⟹ 连续），极限在 l 下穿过。∎

## 50.2 加权幂的完备性

**定理（Lax 第 9 章定理 1）**。w(t) > 0 是 ℝ 上指数衰减的连续权
（w(t) < a·e^{−c|t|}）。C 是 ℝ 上连续、∞ 处为零的函数空间（上确界
范数）。则 {tⁿw(t)} 的闭线性张成是整个 C：**每个消失的连续函数
可用加权多项式一致逼近**。

**证明**（展示解析依赖原理的标准用法）。设 l 是 C 上有界泛函，
l(tⁿw) = 0 对 n = 0, 1, …。对 |Im ζ| < c 定义

```
f(ζ) = l(w·e^{iζt})
```

w·e^{iζt} ∈ C（|Im ζ| < c 时指数衰减），且对 ζ 解析（依范数）。
由引理，f 解析，且逐次求导给出

```
f⁽ⁿ⁾(0) = iⁿ·l(tⁿw) = 0，n = 0, 1, 2, …
```

于是 f ≡ 0 于带域，特别地对一切实 s：l(w·e^{ist}) = 0——即 l
在所有加权三角函数上为零。由 Weierstrass，周期函数被三角多项式
一致逼近，故 l(wh) = 0 对一切连续周期 h；再截断（w 指数衰减控制
尾部），紧支连续函数 y ≈ wh，l(y) = 0；紧支函数稠密于 C，张成
判据收尾。∎

## 50.3 Müntz 逼近定理

Weierstrass 定理说多项式稠密于 C[0,1]。由于 x(t) = y(t^{1/n})
保持连续性，**只用幂 {1, tⁿ, t^{2n}, …} 也够**——不是所有幂都
需要。Bernstein 问：哪些指数序列 {λⱼ}（λⱼ → ∞）使 {t^{λⱼ}} 的
闭张成是 C[0,1] 中在 0 点为零的函数空间 C₀？Müntz 的回答：

**定理（Müntz，Lax 第 9 章定理 2）**。λⱼ > 0，λⱼ → ∞。则
{t^{λⱼ}} 张成 C₀[0,1] 当且仅当

```
Σ 1/λⱼ = ∞。
```

**证明（充分性，Lax 原文）**。设 l 是 C 上的有界泛函，l(t^{λⱼ}) = 0。
对 Re ζ > 0 定义

```
f(ζ) = l(t^ζ)
```

t^ζ 连续、在 0 为零、在 (0,1] 解析依赖 ζ（差商以 (log t)t^ζ →
依范数收敛），故 f 在右半平面解析、有界（‖l‖·1 ≥ |f|）。取前 N
个 λⱼ 构造 **Blaschke 乘积**

```
B_N(ζ) = Π (λⱼ − ζ)/(λⱼ + ζ)
```

它满足：B_N(λⱼ) = 0（j ≤ N）；Re ζ → 0⁺ 时 |B_N| → 1；
|ζ| → ∞ 时 |B_N| → 1；且 **|B_N(ζ)| ≤ 1** 于右半平面（每个因子
是右半平面到单位圆盘的 Möbius 自同构）。f 与 B_N 有公共零点，
g_N = f/B_N 在闭右半平面解析、有界、|g_N| ≤ 1（边界估计 + 最大
模原理）。取正整数 k，|f(k)| = |g_N(k)|·|B_N(k)|，而

```
|B_N(k)| = Π |λⱼ − k|/|λⱼ + k|，因子 (2k)/(λⱼ + k) 当 λⱼ < k
```

若 Σ1/λⱼ = ∞，则 Π (λⱼ − k)/(λⱼ + k) → 0（对数展开
log(λ−k) − log(λ+k) ≈ −2k/λ，Σ 2k/λⱼ = ∞ 而有限个 λⱼ ≤ 2k 的
因子有界）。**g_N 一致有界、B_N(k) → 0 ⟹ f(k) = 0 对一切正整数
k**。即 l 消灭 tᵏ（k = 1, 2, …），再由 Weierstrass（t 的多项式
稠密），张成判据给出结论。∎

（必要性 Lax 从略，本书如实转述；要点是 Σ1/λⱼ < ∞ 时可构造
非零泛函——幂的"总密度"不足。Szász 已推广到复 λⱼ。）

**注**：证明的三个组件——解析依赖、Blaschke 乘积消零、调和级数
发散——各自的数值影子在本章实验中重现。

## 50.4 Runge 定理

**定理（Runge，Lax 第 9 章定理 3）**。D 是有界单连通域。D 内的
解析函数可在紧子集 K ⊂ D 上被多项式一致逼近。

**证明（Hörmander）**。由单连通性，K 含于某个单连通紧集 K₀ ⊂ D
内；取 D − K₀ 中绕 K 一周的闭光滑曲线 Γ，Cauchy 积分公式把 f(ζ)
（ζ ∈ K）表为 Γ 上 (χ − ζ)^{-1} 的积分，用 Riemann 和逼近积分，
问题化为：**每个 (χ − ζ)^{-1}（χ ∉ K）可被多项式逼近**。

对 |χ| > R = max|ζ|（ζ ∈ K）：几何级数

```
(χ − ζ)^{-1} = χ^{-1}·Σ (ζ/χ)ⁿ
```

在 K 上一致收敛，多项式逼近直接可得。对一般的 χ：用张成判据。
设 l 是 C(K) 上有界泛函，消灭一切多项式。定义

```
g(χ) = l((χ − ζ)^{-1})
```

(χ − ζ)^{-1} 作为 K 上的连续函数解析依赖于 χ（χ 在 K 外部），
故 g 在 K 的外部解析。对 |χ| > R，(χ − ζ)^{-1} 已是多项式的一致
极限，l 连续 ⟹ g(χ) = 0。**关键一步**：单连通 ⟹ K 的外部连通
（无洞），g 在一个无界连通开集上解析且在一非空开集上为零 ⟹
g ≡ 0（唯一性沿连通开集传播）。张成判据收尾。∎

无洞条件是本质的：圆环 {1 < |ζ| < 2} 上的 1/ζ 不能被多项式在
圆环上逼近（∫l(ζ^0) 类泛函分离——见实验 3 的数值验证：多项式在
圆环上的最佳逼近误差有正下界）。

## 50.5 对偶变分与共形映射（概览）

**定理（Lax 第 9 章定理 4，Garabedian-Schiffer）**。D 有界、边界
C¹，A 是 D 内解析、连续到边界的函数空间。则

```
M = sup{|f′(ζ₀)| : f ∈ A, ‖f‖_∞ ≤ 1}
  = inf{∫_{∂D} |u₀ − g||ds| : g ∈ A} = m，
```

其中 u₀(ζ) = (2πi(ζ − ζ₀)²)^{-1}，且上确界可取到。

证明分两步：M ≤ m 由 Cauchy 积分公式 f′(ζ₀) = ∮(u₀ − g)ds 与
|∫| ≤ ∫|·|；m ≤ M 用对偶：m 是 u₀ 到子空间 A 的 L¹ 距离，其
对偶刻画（第 8 章定理 7）给出极值泛函 l₀，而 f₀(χ) = l₀((ζ − χ)^{-1})
正是取等的极值函数——在 D 单连通时它**把 D 共形映射到单位圆盘**
（Radon 曲边多边形论证：|f₀| = 1 于边界且辐角单调绕行）。∎

这就是 Riemann 映射定理的变分法证明骨架：**共形映射 = 极值问题
的解**。数值实验 4 在单位圆上验证 M = m = 1/2π 尺度下的取等。

## 50.6 Julia 数值实验

实验文件 `examples/julia/50_muntz_runge.jl`。

**实验 1：Müntz 张成的分水岭（L² + 精确 Gram）**。逼近 f = √t
（∈ C₀[0,1]）于 span{t^{λⱼ}}：Gram 有闭式 [1/(λᵢ+λⱼ+1)]，投影
误差² = 1/2 − cᵀb。四族指数在 N = 2→4→8 下的 L² 误差：

- λⱼ = j（Σ1/j = ∞）：0.061 → 0.021 → **0.0066**（→ 0）；
- λⱼ = 2^j（Σ < ∞）：0.193 → 0.135 → **0.120**（停在正极限）；
- λⱼ = j²（Σ < ∞）：停在 0.053；
- λⱼ = 素数（Σ1/p = ∞ 但发散极慢）：0.168 → 0.089 → 0.052——
  **在可及的 N 内与收敛族表现无异**。Müntz 定理是渐近定理，
  Σ1/p 的发散要天文级 N 才显形。这是定理数值上的诚实一面。

**实验 2：Blaschke 乘积三性质**。对 λⱼ = 2^j 构造 B_N（N = 10）：
(a) B_N(λⱼ) = 0（数值 ~10⁻¹⁵）；(b) 右半平面 500 个随机点上
|B_N| ≤ 1；(c) 虚轴附近 |B_N| → 1（|Re ζ| = 0.01 处实测 0.9925）。

**实验 3：Runge 与无洞条件**。三组对照：

- Taylor：1/(z−2) 在 |z| ≤ 0.9 上，20 项误差 4×10⁻⁸（几何衰减，
  比率 ~0.45 = 0.9/2）；
- **孔中有极点**：1/z 在圆环 0.5 ≤ |z| ≤ 0.9 上的多项式最小
  二乘（度 30）残差**停滞**在 2.1——Laurent 负幂 1/z 无法被
  多项式替换；
- 对照：1/(z−2) 在同一圆环上收敛到 5×10⁻¹²——**孔本身不妨碍
  逼近，孔中的奇异性才妨碍**。这正是"外部连通"的数值内容。

**实验 4：对偶变分在单位圆**。ζ₀ = 0：u₀(ζ) = 1/(2πiζ²)，
|u₀| = 1/2π 于 |ζ| = 1。M = 1（Schwarz 引理，等号 f(z) = e^{iθ}z），
m ≤ ∫|u₀ − 0||ds| = 1（g = 0 是可行点）。4096 点离散弧长验证
∫|u₀||ds| = 1.000000000000——M = m 取等。

## 50.7 Python 数值实验

实验文件 `examples/python/50_muntz_runge.py`。

**实验 1：Müntz 误差表 + Gram 病态**。与 50.6 实验 1 同款四族
（L² + 精确 Gram），另附 Gram 条件数：全幂族 N=8 时 2.1×10¹¹
（Hilbert 型病态），2^j 族反而只有 2.5×10⁵——Müntz 数值的难点
在稠密族而不是稀疏族。

**实验 2：环域失败的最优性**。1/z 在圆环 1/2 ≤ |z| ≤ 1 上的
多项式最小二乘（L²，度 10/20/40）：残差停在 **1.35** 不动（三档
相同到第三位）；对照 1/(z−2) 收敛到 5×10⁻¹⁴。

**实验 3：解析依赖原理**。l = 等距格点求积泛函，x(ζ) = w(t)e^{iζt}，
w = e^{−|t|}。数值验证 f(ζ) = l(x(ζ)) 的 Cauchy-Riemann 方程
（中心差分）：|∂ᵤf + i∂ᵥf| 在 h = 0.1 → 0.05 时 2.0×10⁻² →
4.9×10⁻³（比率 4.0，O(h²)）——引理 50.1 的机器影子。

1. **（纸笔）**补全 50.3 中 B_N(k) → 0 的对数估计：由
   Σ 2k/λⱼ = ∞ 与有限个负因子的有界性，说明乘积趋于零。
2. **（纸笔）**证明 Möbius 因子 |λⱼ − ζ|/|λⱼ + ζ| ≤ 1 在
   Re ζ > 0 成立（平方展开）。
3. **（纸笔）**Müntz 必要性轮廓：Σ1/λⱼ < ∞ 时构造泛函
   l(t^μ) = ∫(μ − λⱼ)^{-1}…（提示：对 log t 做变量替换，
   区间 (−∞, 0] 上的指数 e^{λⱼs}，用共轭性）。
4. **（纸笔）**证明 1/z 在圆环 {1 < |z| < 2} 上与一切多项式的
   L² 距离恰为（Laurent 尾范数），并算出数值。
5. **（机器）**把实验 1 的指数族换成 λⱼ = j·log j（Σ1/(j log j)

   1/(2πi(ζ − r)²)，M = 1/(1 − r²)（Schwarz-Pick），数值验证
   m = M。
