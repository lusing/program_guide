# 59 · 半群与 Hille-Yosida 定理

> 范数连续的半群只有 e^{tG}——太穷了。热方程的半群在 t = 0 处
> 连范数连续都做不到，却是最重要的对象。Hille 与 Yosida 各自发现
> 了强连续半群的完全刻画：生成元的预解式在右半平面的界。
> ——Lax 第 34 章（意译）

本章覆盖 Lax 第 34 章：范数连续半群的指数刻画（定理 1）、强连续
半群的指数增长界（定理 2）、生成元的五条性质（定理 4：域稠密、
闭、预解式 = Laplace 变换）、**Hille-Yosida 定理**（定理 7，
Yosida 的逼近证明全文 + Hille 的后向差分证明）、**Lax 等价定理**
（定理 8：相容 + 稳定 ⟺ 收敛，含望远镜恒等式证明）、Lumer-Phillips
耗散性判据与 Trotter 扰动。

## 59.1 从范数连续到强连续

**定理 1**。(i) 有界算子 G 的幂级数 e^{tG} 是范数连续半群；
(ii) 反之，范数连续（在 t = 0）的半群必为 e^{tG}。

(ii) 的证明用**算子对数**：‖Z−I‖ < 1 时 log Z = Z − I − (Z−I)²/2 −…
（幂级数），半群律 ⟹ L(t+s) = L(t)+L(s)（小 t），有理稠密 + 连续
给 L(t) = tG，指数化收尾。∎

**热方程的教训**：u_t = Δu 的解算子 Z(t) 把连续初值映到解；
‖Z(t)‖ ≤ 1（最大值原理）且构成半群，但**不能延拓到 t < 0**
（倒向热方程不适定）⟹ 不是 e^{tG} 形。需要弱一档的连续性：

**强连续**：s-lim_{t→0} Z(t)x = x 对一切 x。

**定理 2**。强连续半群满足 ‖Z(t)‖ ≤ b·e^{kt}（(8)），且 Z(t)x
对 t 强连续。

**证明**：(8) 的关键一步是**一致有界原理**：若 ‖Z(t_j)‖ → ∞
沿 t_j → 0，则 Z(t_j)x 不可能对一切 x 收敛。之后 t = na + r
分解 + 半群律。∎

## 59.2 生成元

**定义**。Gx = s-lim (Z(h)x − x)/h，域 D(G) = 极限存在处。

**定理 4**。设 G 是强连续半群 Z(t) 的生成元：

1. G 与 Z(t) 交换（差商的双分解 (13)）；
2. **D(G) 稠密**（x 用 (1/n)∫₀ⁿZ(s)x ds 的光滑化逼近）；
3. D(Gⁿ) 对一切 n 稠密；
4. G 闭；
5. Re ζ > k 的 ζ 都在预解集，且**预解式是 Laplace 变换**：

```
(ζI − G)⁻¹x = ∫₀^∞ e^{−ζt}Z(t)x dt。                     (15)
```

对压缩半群（‖Z(t)‖ ≤ 1，(19)）取 k = 0，(15) 的估计给
**‖R(ζ)‖ ≤ 1/Re ζ**。

## 59.3 Hille-Yosida 定理

**定理 7**。(i) 压缩半群的生成元满足：正实数 a ∈ res(G) 且

```
‖R(a)‖ = ‖(aI − G)⁻¹‖ ≤ 1/a。                            (20)
```

(ii) 反之，稠定算子 G 若满足 (20)，则生成一个强连续压缩半群。

**(ii) 的 Yosida 证明**（全文；这是"用有界逼近无界"的模范）：

1. **Yosida 逼近**：Gₙ = nGR(n) = n²R(n) − nI（(21)）——
   **有界**算子；恒等式 nR(n) − I = R(n)G 与 (20) 给
   **nR(n)x → x**（(22)）：先在 D(G) 上（‖nR(n)x − x‖ ≤ ‖Gx‖/n），
   再用 ‖nR(n)‖ ≤ n·(1/n) = 1 与稠密性传递。
2. **Gₙx → Gx**（(23)，x ∈ D(G)）：Gₙx = nR(n)Gx 套用 (22)。
3. **指数逼近**：Zₙ(t) = e^{tGₙ} = e^{−nt}e^{n²R(n)t}
   （展开为级数，每项压缩 ⟹ (24) ‖Zₙ(t)‖ ≤ 1）。
4. **Cauchy 控制**：交换性 + 差商估计 (25)：

   ```
   ‖Zₙ(s)x − Z_k(s)x‖ ≤ s·‖Gₙx − G_kx‖，
   ```

   结合 (23) 给 Zₙ(s)x 在有界 s 集上一致收敛（(26)）；极限 Z(s)
   继承半群律、强连续、压缩性。
5. **生成元还原**：积分方程 Zₙ(t)x − x = ∫Zₙ(s)Gₙx ds 取极限，
   极限半群的生成元 H ⊇ G；但 H 与 G 都以一切正实数为预解点，
   真扩张不可能（扩张会撞掉预解性）。∎

**Hille 的另一证明**（后向差分）：W(t) = (I − hG)⁻¹W(t−h) 迭代给

```
Zₙ(t) = (I − (t/n)G)⁻ⁿ → Z(t)，
```

每一项是压缩（(20)）；这就是**后向 Euler 格式**的收敛性——
它与 Lax 等价定理的连接见下节例 1。

## 59.4 Lax 等价定理

**设定**：离散逼近 uⁿ⁺¹ = C_h uⁿ 近似 Z(nh)x。两条公理：

- **相容性**（(30)）：‖(C_h − Z(h))u(t)/h‖ → 0，对稠密集上的
  x 的解 u(t) = Z(t)x 一致（0 ≤ t ≤ 1）；
- **稳定性**（(32)）：‖C_hⁿ‖ ≤ const（nh ≤ 1）。

**定理 8（Lax 等价定理）**。对相容格式，

```
收敛（C_hⁿx → Z(t)x，nh → t）⟺ 稳定。
```

**证明**。必要性：一致有界原理。充分性的心脏是**望远镜恒等式**
（非交换的高中学代数）：

```
Cⁿ − Z(h)ⁿ = Σ_{j=0}^{n−1} C^{n−1−j}[C − Z(h)]Z(h)^j。
```

代入 C = C_h，把 (C_h − Z(h))u 拆成 (C_h − I − hG)u（相容性
对象）与 o(h) 项，(33′) 逐段估计：相容性压掉第一项，稳定性压住
几何和，稠密性收尾。∎

这是**数值 PDE 的元定理**："一切有限差分格式的收敛性问题 =
稳定性问题"。相容性是局部的（Taylor 展开即可验证）；稳定性是
整体的（谱分析的对象）。两者合起来，收敛不需要单独证明。

**例 1**（后向 Euler = Hille 格式）。C_h = (I − hG)⁻¹：
相容性 (C_h − I − hG) = h(I − hG)⁻¹G²h → 0（G² 域上）；
稳定性 = (20) 的直接推论。Hille 证明的收敛性是等价定理的特例。

## 59.5 Lumer-Phillips 与 Trotter

**引理 10（Lumer-Phillips）**。预解集含 ℝ₊ 的稠定 G 生成压缩
半群 ⟺ **耗散**：Re(x, Gx) ≤ 0（(20′)）。

证明是 (20) 的代数改写：令 x = (αI − G)⁻¹u 展开 ‖u‖² ≤ ‖x‖²·α²
即 (x,Gx) 实部 ≤ 0，α → ∞。∎

**定理 11（Trotter 扰动）**。G 生成压缩半群，H 耗散、D(H) ⊇
D(G)、且 ‖Hx‖ ≤ a‖Gx‖ + b‖x‖（a < 1）：则 G + H 也生成
压缩半群。（与 58 章 Rellich 定理平行的半群版。）

**Trotter 乘积公式**（34.3 节）：生成元之和的半群可由交替乘积
逼近：

```
e^{t(G+H)} = s-lim_{n→∞} (e^{(t/n)G}·e^{(t/n)H})ⁿ
```

——Lie-Trotter 分裂格式的理论根据；Strang 分裂（半步对称化）
是其二阶加速版。数值实验 3 演示。

## 59.6 Julia 数值实验

实验文件 `examples/julia/59_semigroups.jl`。

**实验 1：热半群的生成元与谱**。周期热方程 u_t = u_xx 的
Fourier 对角化半群 Z(t)：系数乘 e^{−k²t}。验证：‖Z(t)‖ = 1
（压缩）；生成元在对角系上是 −k²（差商验证 |(Z(h)−I)/h eₖ +
k²eₖ| → 0）；预解式 (ζI−G)⁻¹ = 对角 1/(ζ+k²) 与 Laplace 变换
∫e^{−ζt}e^{−k²t}dt 数值一致（k = 0..5，1e-12）。

**实验 2：Lax 等价定理的双面演示**。对流方程 u_t = u_x（周期）：
- 前向 Euler + 中心差分：相容但不稳定（‖Cⁿ‖ = (1+h²)ⁿ/2·…
  增长）——n 步后解发散（数值演示 blow-up）；
- 后向 Euler + 迎风：相容且稳定（‖C‖ ≤ 1）——收敛（误差 O(h)）；
- Lax-Friedrichs：稳定收敛。三种格式的误差-步数表，稳定与收敛
  的对应逐格核对。

**实验 3：Trotter 乘积公式**。A、B 为随机矩阵（A+B 不可交换）：
‖e^{t(A+B)} − (e^{(t/n)A}e^{(t/n)B})ⁿ‖ 随 n = 4..256 收敛
（O(1/n)）；Strang 分裂 (e^{tA/2n}e^{tB/n}e^{tA/2n})ⁿ 收敛
O(1/n²)——两种阶的实测。

**实验 4：Yosida 逼近的逐步还原**。对 G = 三对角 Laplacian：
Gₙ = nGR(n) 的特征值随 n → ∞ 逼近 G 的特征值（每档 n 的
相对误差表）；nR(n) → I 的范数收敛。

## 59.7 Python 数值实验

实验文件 `examples/python/59_semigroups.py`。

**实验 1：生成元的域**。热半群：u = 随机 Fourier 系数，检验
(Z(h)u − u)/h 当 h → 0 时的收敛性：系数级 e^{−k²h} 的差商对
高频分量以 h·k⁴ 速率发散——**域的刻画** ∫k⁴|ûₖ|² < ∞ 的数值
形态（有域内向量收敛、域外向量（白噪声）发散）。

**实验 2：稳定性谱判据**。von Neumann 稳定性分析数值化：对流
方程各格式的放大矩阵 C(θ)（Fourier 符号）的最大特征值模：
前向中心差分 max|λ| > 1 + c·h²（不稳定），迎风 ≤ 1（稳定），
与实验 2 的实测 blow-up/收敛一一对应。

**实验 3：半群律与强连续的量化**。热半群：‖Z(s)Z(t) − Z(s+t)‖
（机器精度）；‖Z(t)u − u‖ ~ O(√t)（对 L² 向量）——强连续的
收敛速率与范数连续失败的对照（‖Z(t) − I‖ = 2 对一切 t > 0：
谱底 0 使范数永不收缩到 I）。
