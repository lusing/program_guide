# 41 · 无界算子基础

> 微分算子无处不在，却不在 B(H) 里——是时候放开"处处定义且有界"了。

本章覆盖 Conway §X.1：稠定算子、闭算子与闭图像定理的无界版、
可闭性、伴随的域问题。

## 41.1 为什么要无界

B(H) 的元素有界、处处定义。但分析学的核心算子大多**无界**：
- 微分 d/dx（在 C¹ 或 Sobolev 域上）：‖f'‖ 可以任意大
  while ‖f‖ = 1（高频振荡）；
- 乘法算子 (M_x f)(x) = x f(x) 在 L²(ℝ) 上：‖M_x f‖/‖f‖ 无界；
- Schrödinger 算子 -Δ + V：位势无界时同病。

它们无法进入 B(H)，但**闭图像定理**指出一条活路：
无界但**闭**的算子保有大部分好性质。

**定义**。T: Dom(T) → H，Dom(T) ⊆ H 稠密线性子空间。
- T **闭**：图 Graph(T) = {(x, Tx)} 在 H⊕H 中闭
  ⟺ xₙ ∈ Dom, xₙ → x, Txₙ → y ⟹ x ∈ Dom 且 Tx = y；
- T **可闭**：存在闭延拓 T̄（极限唯一可传递时）。

**闭图像定理（无界版）**。T 闭且 Dom(T) = H（处处定义）
⟹ T 有界。反之：**无界算子必然不能处处定义**——
它们的"病"全部藏在定义域里。

## 41.2 例子：三个微分算子

在 L²[0,1] 上：
1. T₁ = d/dx，Dom = C¹[0,1]：不闭（可闭，闭包是 Sobolev H¹）；
2. T₂ = i d/dx，Dom = {f ∈ H¹ : f(0) = f(1) = 0}：闭，
   对称但**不**自伴（第 42 章主角）；
3. M_x，Dom = {f : ∫x²|f|² < ∞}：闭（乘法算子天然闭）。

判闭性的万能招：图上的收敛 + 微分论的封闭性。
乘法算子的闭性直接可验：xₙ → x 且 x·fₙ → g ⟹ g = x·f a.e.。

## 41.3 伴随的域

T 稠定 ⟹ T* 可定义：

  Dom(T*) = {y ∈ H : ∃z, ⟨Tx, y⟩ = ⟨x, z⟩ ∀x ∈ Dom(T)}，T*y = z。

**与有界的差别**：T* 的域可以**严格小**于 H（甚至 {0}），
判断"谁在域里"本身就是定理。核心恒等式仍活：
⟨Tx, y⟩ = ⟨x, T*y⟩ 对 x ∈ Dom(T), y ∈ Dom(T*)。

**谱照样定义**：λ ∈ ρ(T) ⟺ T - λ 把 Dom(T) 双射到 H
（逆自动有界，闭图像）。σ(T) 现在可以是**无界闭集**——
例如 d/dx 的谱是虚轴。

## 41.4 代数规则（带域警告）

- (S + T)* ⊇ S* + T*（域可以严格大）；
- (ST)* ⊇ T*S*（注意反序 + 域损失）；
- T 可闭 ⟺ T* 稠定，且 T̄ = T**（二次伴随 = 闭包）。

无界算子的运算规律是"包含关系"而非等式——
每个等式都要用域条件去挣。这是无界理论所有技术难度的来源。

## 41.5 数值通道的无界算子

数值上"无界"= 谱随离散加细发散：
diag(1², 2², ..., n²) 截断的最大特征值随 n 增长无界，
但每个有限截断都是良态的有界矩阵。
**无界性是极限现象**：谱定理（第 43 章）保证即便极限无界，
对角化结构仍然完整保留。
