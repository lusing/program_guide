## 66.1 Hellinger-Toeplitz：对称 ⟹ 连续

**定理（Hellinger-Toeplitz，Rudin 5.1）**。X、Y 是 F-空间，Y* 在
Y 上可分点，T: X → Y 线性且对每个 Λ ∈ Y*，xₙ → 0 ⟹ Λ(T xₙ) → 0。
则 **T 连续**。

**证明**（闭图像的弱形式）：设 xₙ → x 且 T xₙ → y。对每个 Λ：
Λ(T(xₙ−x)) → 0（假设）与 Λ(T xₙ) → Λy（连续）⟹ Λy = Λ(Tx)。
Y* 可分点 ⟹ y = Tx。图像闭 + 闭图像定理（F-空间）⟹ T 连续。∎

对称 Hilbert 空间算子 (Tx, y) = (x, Ty) 是直接推论（弱收敛到 0
由对称性传递）。**反例显示完备性不可去**：C^∞ 紧支函数上
(Tf)(x) = f(x+1)（平移出紧支）对称但不连续——域不完备。

## 66.2 Grothendieck：Lᵖ ∩ L^∞ 的刚性

**定理（Rudin 5.2）**。0 < p < ∞，μ 是概率测度，S 是 Lᵖ(μ) 的
闭子空间且 S ⊆ L^∞(μ)。则 **S 有限维**。

**证明**：恒等映射 i: S → L^∞ 满足闭图像（S 中的 Lᵖ 极限与
L^∞ 极限几乎处处一致）⟹ ‖f‖_∞ ≤ K‖f‖_ₚ。若 S 无限维，
**Riesz 引理**（第一卷 14 章）给范数 1、两两距离 ≥ 1/2 的序列
(fₙ)；‖fₙ − fₘ‖_∞ ≥ ‖fₙ − fₘ‖_ₚ ≥ 1/2 与 {fₙ} ⊆ K·单位球
（L^∞ 范数控制 p 范数，概率空间）矛盾（有限维球的完全有界性）。∎

## 66.3 向量测度的值域：Lyapunov 定理

**定理（Rudin 5.5）**。μ₁,…,μₙ 是 σ-代数 M 上的**非原子**实测度。
则值域

```
μ(E) = (μ₁(E), …, μₙ(E))，E ∈ M
```

是 ℝⁿ 的**紧凸**子集。

**证明**（Krein-Milman 的模范应用）：

1. **承载**：λ = Σ|μᵢ|，Radon-Nikodym 给 μᵢ = hᵢdλ；映射
   A(g) = (∫g dμ₁,…,∫g dμₙ) 是 L^∞(λ) → ℝⁿ 的 w*-连续线性映射。
2. **紧凸**：K = {g ∈ L^∞ : 0 ≤ g ≤ 1} 凸、w*-闭、含于闭单位球
   ⟹ **Banach-Alaoglu** ⟹ w*-紧 ⟹ A(K) 紧凸。
3. **特征函数取端点**：μ(M) ⊆ A(K)（特征函数 ∈ K）。取 p ∈ A(K)，
   K_p = A⁻¹(p) ∩ K 是非空 w*-紧凸集 ⟹ **Krein-Milman 有端点 g₀**。
   若 g₀ 不是特征函数（某集 E 上 δ ≤ g₀ ≤ 1−δ，λ(E) > 0），
   非原子性给无穷维空间 χ_E·L^∞(λ)，从中取 g ≠ 0 使 **Ag = 0**
   （n 个约束 vs 无穷维）且 |g| ≤ δ ⟹ g₀ ± g ∈ K_p——g₀ 不是
   端点，矛盾。∎

**评注**：这就是 **Lyapunov 定理**（向量测度值域凸性）的函数分析
证明。控制论中的"bang-bang 原理"（最优控制可取特征函数/端点）
正是"端点 = 特征函数"的对偶读法。

## 66.4 Bishop 定理：推广的 Stone-Weierstrass

**定义（Rudin 5.6）**。A ⊆ C(S) 的闭子代数。E ⊆ S 是 **A-反对称**
的：E 上的限制代数 A_E 不含非常数实函数。等价类 p ~ q（同属一个
极大反对称集）划分 S。

**定理（Bishop，Rudin 5.7）**。g ∈ C(S)。若对每个**极大 A-反对称
集 E**，g|_E ∈ A_E，则 **g ∈ A**。

**Stone-Weierstrass 是特例**：A 自伴 + 分点时反对称集全为单点，
假设平凡化。

**证明**（Krein-Milman 于零化子）：

1. 零化子 A⊥ = {μ : ∫f dμ = 0 ∀f ∈ A}；K = A⊥ ∩ 单位球是
   w*-紧凸（Banach-Alaoglu）。只需证 μ ∈ K ⟹ ∫g dμ = 0
   （零化 A 的泛函都零化 g ⟹ g ∈ A，Hahn-Banach 分离）。
2. **端点的支撑是反对称集**：取端点 μ，支撑 E。若 f ∈ A、f|_E
   实、−1 < f < 1，定义 μ₁ = (1+f)dμ/‖…‖、μ₂ = (1−f)dμ/‖…‖
   ∈ K（A 是代数：f·A ⊆ A ⟹ μᵢ ∈ A⊥），μ = ½(μ₁+μ₂) 的凸
   分解 ⟹ 端点性给 μ₁ = μ₂ ⟹ **f|_E 常数**。
3. g 的假设 ⟹ g|_E ∈ A_E ⟹ 存在 f ∈ A 使 f = g 于 E ⟹
   ∫g dμ = ∫f dμ = 0。Krein-Milman：端点的凸壳稠密 + 积分的
   w*-连续性 ⟹ 一切 μ ∈ K 零化 g。∎

**推论（Rudin 5.8）**：K ⊆ ℝⁿ×ℂ 紧，每个竖切片 K_t 不隔离 ℂ
（内部连通补），g 在切片内部全纯 ⟹ g 可由多项式一致逼近
（Mergelyan 型定理的 Bishop 框架版）。

## 66.5 Pick-Nevanlinna 插值

**定理（Rudin 5.10）**。数据 {z₀,…,zₙ} ⊂ U，{w₀,…,wₙ} ⊂ U。
若存在全纯 f: U → U 使 f(zᵢ) = wᵢ，则存在**有限 Blaschke 乘积**
B 使 B(zᵢ) = wᵢ。

**证明骨架**（Krein-Milman 于概率测度）：Cayley 变换化目标为
Re F > 0、F(zᵢ) = βᵢ；集合 {F_μ(z) = ∫(e^{iθ}+z)/(e^{iθ}−z)dμ}
（μ 遍历圆周概率测度）是**凸紧**集，其端点是**点质量**（同 5.5
的机制）⟹ 端点解 = 点质量产生的初等变换的复合 = 有限 Blaschke
乘积。∎

Neumann-Pick 的**矩阵条件** [(1−wᵢw̄ⱼ)/(1−zᵢz̄ⱼ)] ≥ 0 是解存在
的判据（数值实验 3 实测）；Rudin 的端点论证给出"最好解"的
结构。

## 66.6 投影、可余性与 Haar 平均

**投影（Rudin 5.15–5.16）**。P² = P ⟺ X = R(P) ⊕ N(P)。
F-空间中 **闭子空间可余 ⟺ 它是连续投影的值域**（⟸ 平凡；
⟹ 闭图像验证 P 连续）。

**定理（Rudin 5.18，Haar 平均造投影）**。X 是 Fréchet，Y 可余，
G 是 X 上的**紧**线性算子群（连续作用），T(Y) ⊆ Y ∀T。则存在
**与每个 T 交换**的连续投影 Q: X → Y：

```
Q x = ∫ s⁻¹P s x dm(s)     （m = Haar 测度，P 任一投影）
```

——与 49 章 Agnew-Morse 磨光、65 章不变 Hahn-Banach 一脉相承：
**平均消去群作用**。

**不可余子空间（Rudin 5.19–5.22）**。应用：disk algebra A
（圆盘上连续、内部全纯）作为 C(T) 的子空间——若 A 可余，Haar
平均造出与一切平移交换的投影 Q；Q 与平移交换 ⟹ Q 的核/值域是
平移不变子空间 ⟹ Fourier 分析迫使 Q 是"删负频率"的条件期望
——但 Poisson 核之和（Rudin 5.21：Σ Re zₙ 沿非切稠密集发散）
显示该投影无界 ⟹ **A 在 C(T) 中不可余**。同法 l¹ 的闭平移不变
真子空间在 L¹ 中不可余（Wiener 定理的对偶面）。

## 66.7 Julia 数值实验

实验文件 `examples/julia/66_banach_rigidity.jl`。

**实验 1：Hellinger-Toeplitz 的两面**。对称矩阵（连续 ✓）；对称
但域不完备的差分算子（C^∞ 紧支网格上对称，加细网格时范数爆炸
——离散形态的不连续性）。

**实验 2：Lyapunov 定理的数值面**。非原子概率空间 [0,1] 上两个
测度 μ₁ = f₁dx、μ₂ = f₂dx：随机取 200 个可测集 E，散点
(μ₁(E), μ₂(E)) 落在值域内；理论值域是紧凸集（包含内点）——
散点的凸包随样本增多填满；对照原子测度（两点质量）：值域退化为
4 个点的有限集（非凸性消失）。

**实验 3：Pick-Nevanlinna 数值**。(a) Neumann-Pick 矩阵
[(1−wᵢw̄ⱼ)/(1−zᵢz̄ⱼ)] 的半正定性判定（数据可行 ⟺ PSD）；
(b) Blaschke 乘积插值的构造性求解（两点的显式公式
B(z) = (z−a)/(1−āz) 复合）验证 |B| = 1 于圆周、B(zᵢ) = wᵢ。

**实验 4：disk algebra 的"删负频率"投影无界**。C(T) 的函数
fₙ = Σ_{k≤n} c_k e^{ikθ}（只正频率，‖fₙ‖_∞ = 1）：其到 disk
algebra 的恒等投影就是删负频——数值验证对只含负频率的 g
（‖g‖_∞ = 1），投影后 0 但中间量（Fourier 系数级数的部分和）
最大值随 n 增长（Lebesgue 常数 log n 增长）——投影无界的数值
指纹。

## 66.8 Python 数值实验

实验文件 `examples/python/66_banach_rigidity.py`。

**实验 1：Grothendieck 刚性**。L²[0,1] 的 m 维随机子空间 S_m：
S_m ∩ {‖f‖_∞ ≤ K} 的体积占比随 m 指数衰减（固定 K，子空间中的
sup 范数增长 ~ √(m log m)）——有限维时可行、维度增长时"全空间
L^∞ 界"逐渐不可达的数值形态。

**实验 2：Bishop 的反对称集**。A = {e^{ikθ} : k ≥ 0}（解析三角
多项式）：C(T) 中 A 的极大反对称集 = 整个 T（A 无实非常数函数）
⟹ Bishop 说 g ∈ A ⟺ g 本身解析——数值验证：g = Re z（非解析）
与 A 的最小二乘距离有正下界；对照 A' = 含共轭的三角多项式：
反对称集 = 单点 ⟹ 一切连续函数可逼近。

**实验 3：Lyapunov 的 bang-bang**。最优控制的 toy：max ∫g·u
s.t. u ∈ [0,1]、∫u = c：线性规划解在端点（u ∈ {0,1}）取到
——"端点 = 特征函数"的线性规划形态。

**实验 4：Lebesgue 常数增长**。Fourier 部分和算子的范数
L_n = ‖D_n‖₁/(2π)（n = 2^k）：数值积分 Dirichlet 核，验证
~ (4/π²)log n 增长（51 章同一对象的不可余性读法：条件期望型
投影的 log 发散）。
