# 30 · 谱与预解式

> 谱是特征值的"连续版"：无穷维空间上，求逆可能以连续的方式失效。

本章覆盖 Conway §VII.3、§VII.5–§VII.6：谱的基本理论、
预解式、谱的非空性与紧性、Gelfand 谱半径公式、
各类算子谱的样例目录。

## 30.1 谱的定义

设 A 是含单位元的复 Banach 代数，a ∈ A。

- **预解集** ρ(a) = {λ ∈ ℂ : a - λ1 可逆}；
- **谱** σ(a) = ℂ \ ρ(a)；
- **预解式** R(λ, a) = (a - λ1)⁻¹，λ ∈ ρ(a)。

对 A = B(H)，σ(T) = 特征值 ∪ 连续谱 ∪ 剩余谱：
"求逆失效"在无穷维有**三种**失效方式（不可逆 = 不单射 /
不值域不满 / 值域不稠）。有限维只有第一种。

## 30.2 谱的基本性质

**定理**。σ(a) 是 ℂ 的**非空紧**集，且 |λ| ≤ ‖a‖。

**证明骨架**。
- **有界**：|λ| > ‖a‖ ⟹ λ⁻¹a 的 Neumann 级数收敛 ⟹ λ ∈ ρ(a)；
- **闭**：ρ(a) 开（可逆元群开，求逆连续）；
- **非空**：若 ρ(a) = ℂ，则预解式 R(λ,a) 是整函数且
  |λ|→∞ 时 ‖R‖ → 0，Liouville 定理迫使 R ≡ 0，矛盾。∎

非空性是**复数独有**的福利（本质用了 ℂ 的代数闭性 + 全纯结构）——
实 Banach 代数上谱可以空。

**预解恒等式**：λ, μ ∈ ρ(a) 时

  R(λ,a) - R(μ,a) = (λ-μ) R(λ,a) R(μ,a)。

它说明 λ ↦ R(λ,a) 是 ρ(a) 上的**全纯算子值函数**
（可微，导数 R·R），谱点是它的极点/本性奇点聚集处。
数值上直接可见：λ 逼近谱时 ‖(λI-A)⁻¹‖ 爆破。

## 30.3 Gelfand 谱半径公式

**定理（Gelfand）**。谱半径

  r(a) = max{|λ| : λ ∈ σ(a)} = lim_{n→∞} ‖aⁿ‖^{1/n}。

且极限存在、右端恒 ≥ r(a)（上界单侧逼近）。

**证明骨架**。
- 上界：λⁿ ∈ σ(aⁿ)（谱的多项式映射）⟹ |λ|ⁿ ≤ ‖aⁿ‖；
- 收敛性：次乘性 ⟹ ‖aⁿ‖^{1/n} 关于 log n 次可加，Fekete 引理
  给出极限 = inf；
- 反向：用预解式 Laurent 展开与解析延拓的唯一性。∎

**实用性**：谱半径可**纯幂法**计算——不需要解特征值问题，
只要反复乘矩阵。数值实验里 ‖Bᵏ‖^{1/k} 从 1.05 单调滑向 0.9
的全过程就是这一定理的可视化。

## 30.4 谱样例目录

| 算子 | 谱 |
|---|---|
| ℓ² 对角 diag(λₙ) | {λₙ} 的闭包 |
| 单侧移位 S | 闭单位圆盘 ‖·‖≤1（特征值：开圆盘） |
| 双侧移位 U | 单位圆周（正规，无特征值） |
| Volterra V | {0}（拟幂零：σ = {0} 但 V ≠ 0） |
| 紧 T（无穷维） | 可数点集聚于 0（第 32 章） |
| 有限维 A | 特征值多项式的根 |

注意 S vs U：两者只差"一个方向"，谱从圆盘塌缩成圆周——
谱对算子的"边角"极其敏感，这正是谱理论丰富性的来源。

## 30.5 谱映射定理（多项式版）

**定理**。p 多项式 ⟹ σ(p(a)) = p(σ(a))。

**证明**。λ ∈ σ(p(a))，把 p(t) - λ 在 ℂ 上分解为
c·∏(t - zⱼ)，若所有 zⱼ ∈ ρ(a) 则乘积可逆，矛盾；
故某个 zⱼ ∈ σ(a) 且 p(zⱼ) = λ。∎

这是第 31 章 Riesz 泛函演算的种子：把 p(a) 的谱完全归约为
p 在 σ(a) 上的取值——函数演算在多项式层面已经"忠实"。
