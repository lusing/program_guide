# 21 · 几何 Hahn-Banach：分离定理

> 分析的 Hahn-Banach 延拓泛函；几何的 Hahn-Banach 分离凸集。
> 一个定理的两副面孔。

本章覆盖 Conway §IV.3：**分离定理**——泛函分析的几何核心。

## 21.1 分离的定义

**定义**。A, B ⊆ X 凸集。超平面 H = {x : F(x) = c}：
- **分离** A 和 B：F(a) ≤ c ≤ F(b) ∀a∈A, b∈B。
- **严格分离**：F(a) < c < F(b)。

## 21.2 分离定理

**定理（Conway IV.3.4，分离形式）**。X 局部凸，A ⊆ X 非空
**开**凸集，B ⊆ X 非空凸集，A ∩ B = ∅。则存在连续线性泛函
F ≠ 0 和实数 c，使 A 和 B 被超平面 {F = c} 分离。

**证明思路**。
1. 平移使 0 ∈ A。取 b₀ ∈ B，令 C = A − b₀（仍开凸含 0）。
2. **Minkowski 泛函** p_C(x) = inf{t > 0 : x/t ∈ C}：
   次线性、p_C ≤ 1 在 C 上。
3. 在一维子空间 span(b₀) 上定义 f(αb₀) = α，则 f ≤ p_C。
4. Hahn-Banach 延拓 f 到 F ≤ p_C。则 F|_A ≤ 1 而 F(b₀) = 1。∎

**Minkowski 泛函是连接几何（凸集）与分析（半范数）的桥梁**。

## 21.3 严格分离

**定理**。X 局部凸，A **紧**凸，B **闭**凸，A ∩ B = ∅。
则存在 F 和 c₁ < c₂ 使 A ⊆ {F ≤ c₁}，B ⊆ {F ≥ c₂}。

**证明**。对每个 a ∈ A，取 a 的邻域 Uₐ 与 B 不交。
紧性给有限覆盖；A 的开凸包与 B 不交；再用分离定理 + 紧性
推知余量。∎

## 21.4 支撑超平面

**推论**。K 是有内点的紧凸集，x₀ ∈ ∂K。则存在 F ≠ 0 使
F(x) ≤ F(x₀) ∀x ∈ K（x₀ 处的**支撑超平面**）。

这是凸分析的基本工具：最优解在边界上的刻画（KKT 条件）、
对策论中的 minimax、经济学中的分离均衡。
