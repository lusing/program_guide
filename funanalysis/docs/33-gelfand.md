# 33 · 交换 Banach 代数与 Gelfand 理论

> 把代数的"乘法结构"换成空间的"点"：极大理想就是几何。

本章覆盖 Conway §VII.8–§VII.9：交换 Banach 代数的极大理想空间
（谱空间）、Gelfand 变换、对 C(K) 与 ℓ¹ 的应用。

## 33.1 特征与极大理想

设 A 交换复 Banach 代数（含 1）。

**定义**。**特征**（multiplicative linear functional）
φ: A → ℂ 是非零代数同态：φ(ab) = φ(a)φ(b)，φ(1) = 1。

**关键事实**：特征**自动连续**，且 ‖φ‖ = 1。
（证明：若 |φ(a)| > ‖a‖ 对某 a，则 1 - a/φ(a) 可逆，
但 φ(1 - a/φ(a)) = 0 与可逆元不进特征核矛盾。）

**定理（极大理想 = 特征的核）**。
φ ↦ ker φ 是 {特征} → {极大理想} 的一一对应。

证明骨架：ker φ 余维 1，商 A/ker φ ≅ ℂ 是域 ⟹ 极大；
反向，A/M 是 Banach 代数且是域，**Gelfand-Mazur 定理**
（Banach 代数若为域则 ≅ ℂ）给出特征。∎

## 33.2 极大理想空间与 Gelfand 变换

**定义**。Δ(A) = 全体特征，赋**弱*拓扑** σ(Δ, A)
（即逐点收敛：φₙ → φ ⟺ φₙ(a) → φ(a) ∀a）。

**定理**。Δ(A) 是弱*紧 Hausdorff 空间（Banach-Alaoglu
闭子集，第 23 章）。

**Gelfand 变换**：Γ: A → C(Δ(A))，

  Γ(a)(φ) = φ(a)。

**定理（谱的几何化）**。

  **σ(a) = { φ(a) : φ ∈ Δ(A) } = 值域 Γ(a)**。

于是：r(a) = ‖Γ(a)‖∞（谱半径 = Gelfand 变换的 sup 范数），
a 可逆 ⟺ Γ(a) 处处非零。谱不再靠解方程，
而是"看 Δ 上的函数取值"——**代数问题几何化**。

**数值化身**：对 n×n 对角可交换矩阵代数，
Δ = {n 个取对角元的特征}，Γ( diag(d₁..dₙ) ) 就是
函数 φᵢ ↦ dᵢ——谱 = 值域，一目了然。

## 33.3 例子目录

| 代数 A | Δ(A) | Gelfand 变换 |
|---|---|---|
| C(K) | K 本身（点特征 δₓ） | 恒等 |
| 解析函数代数 A(𝔻)（闭盘上连续、内部全纯） | 闭盘 𝔻̄ | 恒等 |
| ℓ¹(ℤ) 卷积 | 圆周 𝕋（φ_z(Sequence) = Σ aₙzⁿ） | Fourier 级数！ |
| ℓ¹(ℕ) 卷积 | 闭盘（z 变换） | 生成函数 |
| Wiener 代数（绝对收敛 Fourier 级数） | 𝕋 | 嵌入 |

**Wiener 定理**（Gelfand 理论的第一场胜仗）：
f 绝对收敛 Fourier 级数且处处非零 ⟹ 1/f 也绝对收敛。
传统证明繁琐；Gelfand 一行：f 在 Δ = 𝕋 上无零点
⟹ Γ(f) 可逆 ⟹ f 在代数中可逆。∎

ℓ¹(ℤ) 的 Gelfand 变换 = **Fourier 级数**：
卷积代数的特征空间是圆周，变换把卷积变成乘法——
这就是 Fourier 分析的代数本质（第 44 章回归）。

## 33.4 谱半径的几何重述与半单性

- **r(a) = ‖Γ(a)‖∞**：谱半径公式（第 30 章）在此获得
  几何解释；
- **核** rad A = ∩{M : M 极大理想} = {a : Γ(a) = 0}。
  rad A = 0 称**半单**——Gelfand 变换是嵌入；
- **反例**：拟幂零元全在根基里（Volterra 型代数的
  Gelfand 变换把非零元压成 0——变换未必忠实）。

## 33.5 走向 C* 代数

若 A 还是 C* 代数（第 34 章）：‖Γ(a*a)‖ = ‖Γ(a)‖²，
Gelfand 变换成为**等距**同态，A 交换 ⟹ A ≅ C(Δ)。
这是 Gelfand-Naimark 定理的交换版——下一章的主角。

**主线回顾**：第 29 章给了代数骨架 → 第 30 章谱论 →
第 31 章泛函演算 → 本章把谱几何化 → 第 34 章加上 * 运算
得到完全分类。
