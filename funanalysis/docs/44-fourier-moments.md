# 44 · Fourier 变换、微分算子与矩问题

> Fourier 变换是 L²(ℝ) 的酉算子，把微分变成乘法——无界谱定理的第一个应用现场。

本章覆盖 Conway §X.6–§X.7：Fourier 变换的酉性、
微分算子的谱分析、Heisenberg 不确定性、矩问题。

## 44.1 Fourier 变换：L² 的酉自同构

**定义**（L¹ ∩ L² 起步，延拓）：Ff(ξ) = (2π)^{-1/2}∫e^{-ixξ}f(x)dx。

**Plancherel 定理**。F 延拓为 **L²(ℝ) 的酉算子**：
‖Ff‖ = ‖f‖，F⁻¹ = F*。

**对角化定理**。
- **微分**：F (d/dx) F⁻¹ = M_{iξ}——
  d/dx 酉等价于乘 iξ（无界乘法算子，σ = iℝ）；
- **乘法**：F M_x F⁻¹ = i d/dξ——位置与动量互为 Fourier 像。

这是**位置-动量对偶**的算子语言：
x 与 i d/dx 的交换子 = i（正则对易关系 CCR），
谱定理把两边同时放进乘法坐标。数值上：
谱方法求导（FFT → 乘 iξ → IFFT）把无界微分
变成逐点乘法，机器精度复现 f' = -2x·e^{-x²}。

**注意实现的两个坑**（本项目实测）：
①Julia 的 `fftfreq(n, d)` 参数 d 是**采样率**，
NumPy 的是**采样间距**——语义相反；
②网格必须排除右端点（真周期化），否则误差 ~1/n。

## 44.2 微分算子的谱

D = i d/dx 在 L²(ℝ)（域 H¹）：**自伴**、σ(D) = ℝ、无特征值
（广义特征向量 e^{iξx} ∉ L²——"连续谱"的教科书例子）。

对照紧区间的情形（第 42 章）：
- [0,1] + 边条件：σ 离散（n²π²），自伴扩张有家族；
- ℝ 全线：σ 连续（整条轴），本质自伴。

**频率离散 vs 连续 = 几何有界 vs 无界**——
谱的类型编码了底层空间的几何。

## 44.3 Heisenberg 不确定性

**定理**。f ∈ Dom(x·) ∩ Dom(D)，‖f‖ = 1：

  **σ_x(f) · σ_ξ(f) ≥ 1/2**（σ = 标准差；等号 ⟺ Gaussian）。

**证明骨架**（两句）：[x, D] = i（CCR）+ Cauchy-Schwarz：
σ_xσ_ξ ≥ ½|⟨[x,D]⟩| = ½。∎

- Gaussian e^{-x²/2}：σx·σξ = 1/2·(约定系数)——
  **唯一饱和者**（数值：0.500000 精确命中）；
- 双峰函数：乘积显著增大（数值 ~4）；
- 物理读法：位置测量越准 ⟹ 动量越糊。
  数学读法：x 与 D 不交换，方差积被交换子顶住下限。

高维版本（[xᵢ, pⱼ] = iδᵢⱼ）同构；
Robertson 关系给任意算子对的一般形式。

## 44.4 矩问题

**问题**。(mₖ)ₖ≥₀ 何时是某正测度 μ 的矩序列
（mₖ = ∫tᵏ dμ）？

**定理（Hamburger）**。序列是矩序列 ⟺ **Hankel 矩阵**
H = (m_{i+j}) 全体半正定。

必要性显然（Σcᵢc̄ⱼm_{i+j} = ∫|Σcᵢtⁱ|²dμ ≥ 0）；
充分性是表示论的精细构造。数值化身：
均匀分布 [0,1] 的矩 mₖ = 1/(k+1)：各阶 Hankel 全 PSD；
反例 (1,0,0,1,...)：3 阶 Hankel 出现负特征值——
"方差为零却有四阶矩"的代数不可能。

**唯一性（确定性问题）**是深水区：
- 紧支撑 / Carleman 条件（Σm_{2k}^{-1/2k} = ∞）：确定；
- **对数正态分布**：矩不定——存在异己测度同矩系
  （Stieltjes 1894 的经典惊奇）。

**联系谱定理**：矩序列 ⟷ 自伴算子 + 循环向量
（mₖ = ⟨Tᵏx, x⟩）——矩问题 = 谱测度的
"从一个向量的视角能否重构"。

## 44.5 本章的数值方法论

- FFT：Parseval（酉性）到 10⁻¹⁰；
- 谱求导：机器精度（对带限函数）；
- 不确定性：归一化离散方差，Gaussian 饱和下界；
- Hankel PSD：eigvalsh 最小特征值符号判定。

## 44.6 机器化与数值实验

**Lean**：Fourier 分析在 mathlib 有独立开发线
（`Mathlib.Analysis.Fourier.*`），矩问题与不确定性
不等式由数值通道承载。

**Julia/Python**（`44_fourier_moments.*`）：
- Parseval 酉性；
- 谱方法求导（误差 < 10⁻⁶）；
- Heisenberg：Gaussian 0.5 饱和 vs 双峰 4.0；
- Hamburger：正例全 PSD、反例负特征值。

## 44.7 习题

1. **（纸笔）** 证明 Plancherel（在 Schwarz 类上验证
   ‖Ff‖=‖f‖ 再稠密延拓）。
2. **（纸笔）** 证明 [x, D] = i 并推出不确定性不等式。
3. **（数值）** 取截断 Gaussian（宽度→窗口）观察
   不确定性乘积的变化——截断 = 频域拖尾。
4. **（纸笔）** 证明对数正态的矩序列满足 Hankel PSD
   但不唯一（找异己测度的构造思路即可）。
