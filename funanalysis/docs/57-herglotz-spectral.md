# 57 · Herglotz 表示与自伴算子的谱分解

> 自伴算子的谱分解定理有十几条路。Doob 与 Koopman 的这条路最
> 优雅：把预解式的对角元当成解析函数，用 Herglotz-Nevanlinna
> 表示把它变成测度，再用 Cauchy 变换的唯一性把测度的性质搬运成
> 投影值测度的公理。——Lax 第 32.1 节（意译）

本章覆盖 Lax 第 32 章：Hellinger-Toeplitz 定理与 von Neumann 的
自伴定义、谱分解定理（定理 1，PVM 五公理）、上半平面 Herglotz
表示（定理 2）、**Nevanlinna 表示**（定理 3，全证明）、Cauchy
变换的单射性（引理 4）、非实预解集（定理 5）、以及 **Doob-Koopman
谱分解证明**的全骨架（引理 6–7 及五条性质的传播）。这是第一卷
42 章（Cayley 变换路线）的姊妹篇：同一定理的另一条解剖路径。

## 57.1 Hellinger-Toeplitz 与自伴的精确定义

**定理（Hellinger-Toeplitz）**。处处定义且满足 (Mx, y) = (x, My)
的算子 M 必有界。

**证明**：先证 M 闭：xₙ → x、Mxₙ → u 时，(Mxₙ, y) = (xₙ, My)
取极限给 (u, y) = (x, My) = (Mx, y)，故 u = Mx。处处定义的闭
算子由闭图像定理有界。∎

**推论**：无界的"自伴"只能在稠密真子空间上定义。von Neumann 的
定义：A: D → H（D 稠密），A* 的域 D* = {u : ∃A*u, (Au, v) =
(u, A*v) ∀u ∈ D}；**自伴 = D* = D 且 A* = A**（对称只要求
(Au, v) = (v, u)，是严格弱的条件——42 章的亏指数理论刻画差距）。

## 57.2 谱分解定理（目标陈述）

**定理 1**。自伴算子 A 有**谱分解**：Borel 集上的投影值测度 E，
满足：

1. E(∅) = 0，E(ℝ) = I；
2. E(S∩T) = E(S)E(T)（乘性）；
3. E(S)* = E(S)；
4. E 与 A 交换（E(S) 映 D 入 D 且 AE(S)u = E(S)Au）；
5. D = {u : ∫t²d(E(t)u, u) < ∞} 且 **Au = ∫t dE(t)u**。

## 57.3 Herglotz–Nevanlinna 表示

第 51 章 Herglotz-Riesz（单位圆盘正实部 ⟹ 圆周正测度）经 Cayley
型变换 ζ = (z−i)/(z+i)（单位圆盘 → 上半平面）变成：

**定理 2**。上半平面解析、虚部 ≥ 0 的 g 可唯一表示为

```
g(z) = a + mz + ∫ (1 + tz)/(t − z) ds(t)
```

（a 实、m ≥ 0、s 有限正测度——点 ∞ 处的质量变成 mz 项）。

**定理 3（Nevanlinna）**。若再满足增长条件 lim sup y|g(iy)| < ∞，
则 m = 0，可写成**纯 Cauchy 变换**：

```
g(z) = ∫ dn(t)/(t − z)，    n(R) = lim y·Im g(iy)。
```

**证明**：从定理 2 出发。虚部条件在 z = iy 处分离实虚两部分：
(7b) 迫使 ∫(1+t²)^{-1}ds 的 y 增长有限 ⟹ m = 0；(7a) 给
∫(1+t²)ds ≤ M。换测度 dn(t) = (1+t²)ds(t)（(10)），整理即得 (8)。
∎

**引理 4（Cauchy 变换单射）**。复测度由其 Cauchy 变换唯一决定。

**证明**：n = n⁺ − n⁻（正负部），两者 Cauchy 变换相同 ⟹ 由定理 3
唯一性 n⁺ = n⁻ ⟹ Re n = 0；虚部同理。∎

——这条单射性是整个证明的**搬运引擎**：两个测度的 Cauchy 变换
相同 ⟹ 测度相同。

## 57.4 非实预解集与预解式估计

**定理 5**。自伴 A 的预解集包含一切非实 z。

**证明**：值域闭：‖v‖ ≤ ‖u‖/|Im z|（(11)：虚部配对 + Schwarz，
本教程 42 章已推）；值域稠密（核 = ran(A − z̄I)^⊥ = {0} 由对称性）；
闭 + 稠 = 全空间。∎

预解式 R(z) = (A − z)⁻¹ 满足：‖R(z)‖ ≤ 1/|Im z|（(13)）、
解析（差商恒等式 R(z+h) − R(z) = hR(z)R(z+h)）、R(z)* = R(z̄)、
**预解恒等式** R(z) − R(w) = (z − w)R(z)R(w)。

## 57.5 Doob-Koopman 证明骨架

**核心函数**：对每个 u ∈ H 定义

```
g_u(z) = (R(z)u, u)，    Im z ≠ 0。
```

**引理 6（g_u 的四性质）**。

1. 上半平面解析且 Im g_u ≥ 0（(17)：Im g = −Im z·‖v‖²/|z|² 型
   直接计算）；
2. y|g_u(iy)| ≤ ‖u‖²（Schwarz + (13)）；
3. **lim y·Im g_u(iy) = ‖u‖²**（(18)：‖u‖² = Re(Av,v) + y·Im g，
   而 ‖AR(iy)‖ ≤ 2 一致有界 + D 上衰减 ⟹ 首项消失）；
4. g_u(z̄) = conj g_u(z)（由 R(z)* = R(z̄)）。

⟹ g_u 满足 Nevanlinna 条件：**存在正测度 n_{u,u}** 使

```
(R(z)u, u) = ∫ dn_{u,u}(t)/(t − z)，    n_{u,u}(ℝ) = ‖u‖²。      (20)(21)
```

**极化**：u ± v、u ± iv 的线性组合给出 (R(z)u, v) 的复测度表示
n_{u,v}（(22)），满足引理 7（Hermite、双线性、总变差 ≤ ‖u‖‖v‖）。

**构造 E**：对每个 Borel 集 S，n_{u,v}(S) 是有界半双线性型 ⟹
（第 31 章定理 1）存在有界对称算子 E(S) 使 n_{u,v}(S) = (E(S)u, v)。
**这就是谱投影**。

**五公理的传播**（全部靠 Cauchy 单射）：

- E(∅) = 0、E(ℝ) = I：测度在 ∅/ℝ 的值直接读出；
- **乘性**：R(z) 与 R(w) 交换 ⟹ (25) 两侧分别表示成 Cauchy 变换
  ((26)(26′)) ⟹ 测度相等 ⟹ R(w)E(S) = E(S)R(w)；再用预解恒等式
  重新展开 (27)（特征函数 c_S 出现）⟹ E(T)E(S) = E(S∩T)；
- 对称性：n_{u,v} 的 Hermite 性；
- 与 A 交换：u = Rw ⟹ AR = I + zR 的恒等式两侧对称使用；
- 域的刻画：z = i 处 (E(S)v, v) = ∫(1+t²)^{-1}d(Eu,u) 型计算
  （(28)链）给 ∫t²d(Eu,u) < ∞ ⟺ u ∈ D，且 Au = ∫t dE(t)u。∎

**评注**：整个证明没有一个 "逼近" 步骤——解析函数论（Nevanlinna
表示）+ 一个唯一性引理（Cauchy 单射）+ 线性代数（半双线性型的
表示）就完成了。这是"泛函分析 = 线性代数 + 解析函数论"的最佳
广告。第一卷 37 章的有界谱定理走了 Gelfand-C*-代数的路，两条路
在 PVM 处会师。

## 57.6 Stieltjes 反演（实用面）

谱测度如何从 g_u "取回"？**Stieltjes 反演公式**：

```
n((a, b)) + ½n({a, b}) = lim_{ε→0} (1/π)∫_a^b Im g_u(t + iε) dt。
```

数值实验 2 直接实现它：Im 1/(t − z) = ε/((t−s)² + ε²) 是 Poisson
核，所以这恰是"Poisson 平均恢复边界测度"——51 章 Herglotz-Riesz
的 Poisson 机制反向运转。

## 57.7 Julia 数值实验

实验文件 `examples/julia/57_herglotz_spectral.jl`。

**实验 1：对角算子的全程**。A = diag(tₖ)（tₖ = k 或交错），u =
随机权重：谱测度 n = Σ|uₖ|²δ_{tₖ}；计算 g_u(z) = Σ|uₖ|²/(tₖ−z)，
验证：Im g > 0（上半平面）、y·Im g(iy) → ‖u‖²（Nevanlinna 条件
(iii) 的数值形态，y = 10..10⁵）。

**实验 2：Stieltjes 反演往返**。从实验 1 的 g_u 出发，用 (1/π)∫Im g
(t+iε)dt 在 ε → 0 时恢复原子的质量（区间套在 tₖ 上的积分 →
|uₖ|²，误差 < 2%）——Cauchy 变换 ↔ 测度的机器往返。

**实验 3：差分 Laplacian 的谱测度**。A = −d²/dx² 的差分矩阵
（DD 边界），u = 归一化鼓包向量：g_u 的 Stieltjes 反演给出的
密度恰是 Σ|⟨u, eₖ⟩|²集中在 (kπ)² 处的峰——离散谱的数值形态，
并与解析特征值 (kπ)² 对照。

**实验 4：预解式界与解析性**。‖R(iy)‖ ≤ 1/y（数值检查 5 档 y）；
R(z) 在上半平面的 CR 方程（差分）——定理 5 与预解式解析性。

## 57.8 Python 数值实验

实验文件 `examples/python/57_herglotz_spectral.py`。

**实验 1：Nevanlinna 类的边界行为**。g(z) = ∫dn/(t−z) 对三种
测度（纯原子 / 均匀密度 / 半原子半密度）：验证 y·Im g(iy) →
n(ℝ) 的收敛速率（原子 O(1/y)、密度 O(1/y)——含 ½t 项的对比
反例：g = z 不满足 Nevanlinna 条件）。

**实验 2：谱投影公式的数值**。E([a,b])u = (1/2πi)∮_{[a,b]}
(R(t−iε)−R(t+iε))u dt（围道形式）：对角算子上数值积分恢复
投影（在 [a,b] 内的原子权重和）。

**实验 3：Cayley 变换对照**。C = (A − i)(A + i)⁻¹ 酉（42 章），
谱测度经 t = −cot(θ/2) 从圆周搬到直线：数值验证两套测度在
Cayler 映射下互相变换（42 章路线与本章路线的会师点）。
