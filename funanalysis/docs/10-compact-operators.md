# 10 · 紧算子

> 大多数有限维线性变换的陈述都能推广到无穷维空间上的一类算子——
> 紧算子。——Conway §II.4 开篇（意译）

紧算子是有限维与无穷维之间的桥梁：它们"几乎"是有限维的——
单位球的像有紧闭包，等价地，可以被有限秩算子逼近到任意精度。
本章覆盖 Conway §II.4 全部核心内容。

## 10.1 紧算子的定义与基本性质

**定义（Conway 4.1）**。T: ℋ → K 线性。T **紧**（compact），若
T(ball ℋ) 的闭包在 K 中紧。全体紧算子记 B₀(ℋ, K)。

直观：紧算子把无穷维空间"压"到近似有限维。
有限维空间的闭有界集自动紧（Heine-Borel），所以有限维算子全紧。

**命题（Conway 4.2）**。
- (a) B₀(ℋ,K) ⊆ B(ℋ,K)：紧算子有界（紧集有界）。
- (b) B₀(ℋ,K) 是线性空间，且**对范数极限封闭**：
  ‖Tₙ − T‖ → 0 且 Tₙ 紧 ⟹ T 紧。
- (c) **理想性质**：A ∈ B(ℋ), B ∈ B(K), T ∈ B₀(ℋ,K) ⟹
  TA ∈ B₀(ℋ,K) 且 BT ∈ B₀(ℋ,K)。

**证明 (b) 的核心**（完全有界性）：给定 ε > 0，取 n 使 ‖T − Tₙ‖ < ε/3。
Tₙ 紧给出有限 ε/3-网 {Tₙhⱼ}。则 {Thⱼ} 是 T(ball ℋ) 的 ε-网：
‖Th − Thⱼ‖ ≤ ‖Th − Tₙh‖ + ‖Tₙh − Tₙhⱼ‖ + ‖Tₙhⱼ − Thⱼ‖ < ε。
完全有界 + 完备 = 紧。∎

(c) 的证明：T(ball ℋ) 含于紧集，A 连续保持紧性（BT 紧）；
TA(ball ℋ) = T(A·ball ℋ) ⊆ T(c·ball ℋ)（A 有界）含于紧集。∎

**定义（Conway 4.3）**。T **有限秩**（finite rank），若 ran T 有限维。
有限秩连续算子记 B₀₀(ℋ, K)。

有限秩算子紧（有限维的闭有界像集自动紧），所以
B₀₀ ⊆ B₀。

## 10.2 有限秩逼近定理

**定理（Conway 4.4）**。T ∈ B(ℋ,K)。以下等价：
- (a) T 紧；
- (b) T* 紧；
- (c) 存在有限秩算子序列 Tₙ 使 ‖Tₙ − T‖ → 0。

**证明要点**。
(c)⟹(a)：有限秩紧 + 范数极限封闭（4.2b）。
(a)⟹(c)：cl(ran T) 紧（T 紧⟹像闭包紧）⟹ 可分。取可分空间的标准正交
基 (eₙ)，Pₙ = 到 span(e₁..eₙ) 的投影。令 Tₙ = PₙT（有限秩：像含于
有限维空间）。**关键 Claim**：‖PₙTh − Th‖ → 0 对 h ∈ ball ℋ 一致。
这是 Parseval（第 05 章 4.13）+ 紧性的联合应用。∎

(c)⟹(b)：Tₙ* 有限秩 + ‖Tₙ* − T*‖ = ‖Tₙ − T‖（C\* 恒等式，第 08 章）。
(b)⟹(a)：对 T* 用 (a)⟹(c)，得 T** = T 紧。∎

这个定理说：**紧算子 = 有限秩算子的范数闭包**。这是"紧算子近似
有限维"的精确表述，也是数值线性代数中截断 SVD 逼近的理论基础。

**推论（Conway 4.5）**。T 紧 ⟹ cl(ran T) 可分，且按 4.4 的构造
有 ‖PₙT − T‖ → 0。

## 10.3 对角算子的紧性

**命题（Conway 4.6）**。ℋ 可分，(eₙ) 基，(αₙ) 有界数列。
A eₙ = αₙ eₙ 延拓为有界算子，‖A‖ = sup|αₙ|。
**A 紧 ⟺ αₙ → 0**。

**证明**。Pₙ = 到 span(e₁..eₙ) 的投影。A Pₙ 有限秩。
A − APₙ 的范数 = sup_{j>n}|αⱼ|。
若 αₙ → 0，则 ‖A − APₙ‖ → 0，故 A 紧。
反之若 A 紧，由 4.5，‖A − PₙA‖ → 0；而 ‖A − PₙA‖ ≥ ‖(A − PₙA)e_{n+1}‖
= |α_{n+1}|，故 αₙ → 0。∎

对角算子是紧算子理论的"原子"——第 11 章将证明一切紧自伴算子
（在某个基下）都是对角的。

## 10.4 Hilbert-Schmidt 积分算子

**命题（Conway 4.7）**。k ∈ L²(X×X)。则
(Kf)(x) = ∫k(x,y)f(y)dμ(y) 是紧算子，且 ‖K‖ ≤ ‖k‖₂。

**证明思路**：取 L²(X) 的基 (eᵢ)，令 Φᵢⱼ(x,y) = eᵢ(x)ēⱼ(y)——
这是 L²(X×X) 的标准正交系（4.8）。⟨k, Φᵢⱼ⟩ = ⟨Keⱼ, eᵢ⟩。
有限截断 Kₙ = PₙKPₙ 是有限秩的，且
‖K − Kₙ‖ ≤ (Σ_{k>n,m>n}|⟨k,Φₖₘ⟩|²)^{1/2} → 0（Parseval）。∎

**例（Conway）**。Volterra 算子 (Vf)(x) = ∫₀ˣf(t)dt 的核
k = χ_{t≤x} ∈ L²([0,1]²)，所以 V 紧且 ‖V‖ ≤ 1/√2（实际 ‖V‖ = 2/π）。

## 10.5 特征值理论

**定义（Conway 4.9）**。A ∈ B(ℋ)。α ∈ 𝔽 是 A 的**特征值**
（eigenvalue），若 ker(A − α) ≠ {0}。非零向量 h ∈ ker(A − α) 称
**特征向量**。σₚ(A) = 全体特征值。

**例（Conway 4.10-4.12）**。
- 对角算子 A eₙ = αₙeₙ：σₚ(A) = {αₙ}，特征空间 = span(eⱼ : αⱼ = α)。
- **Volterra 算子无特征值**（σₚ(V) = ∅）——紧但"无谱"！
- 卷积算子 Kf = h*f 在 L²(−π,π) 上以 eₙ = (2π)^{-1/2}e^{inx}
  为特征向量：Keₙ = ĥ(n)eₙ。

**命题（Conway 4.13）**。T 紧，λ ∈ σₚ(T)，λ ≠ 0。则
ker(T − λ) **有限维**。

**证明**。若 (eₙ) 是 ker(T−λ) 中的无穷标准正交序列，T 紧给出
子列 Te_{nₖ} 收敛。但 ‖Te_{nₖ} − Te_{nⱼ}‖² = |λ|²‖e_{nₖ}−e_{nⱼ}‖²
= 2|λ|² > 0（标准正交 + λ ≠ 0），矛盾。∎

**命题（Conway 4.14）**。T 紧，λ ≠ 0。若
inf{‖(T−λ)h‖ : ‖h‖=1} = 0，则 λ ∈ σₚ(T)。

**证明**。取单位向量 hₙ 使 ‖(T−λ)hₙ‖ → 0。T 紧给出子列 Th_{nₖ} → f。
则 λh_{nₖ} = Th_{nₖ} − (T−λ)h_{nₖ} → f，故 ‖f‖ = |λ| ≠ 0 且
Tf = λf（连续性传递）。∎

**推论（Conway 4.15）**。T 紧，λ ≠ 0，λ ∉ σₚ(T)，λ̄ ∉ σₚ(T*)。
则 ran(T−λ) = ℋ 且 (T−λ)⁻¹ 有界。

这是**Fredholm 二择一**的雏形：紧扰动下，要么 λ 是特征值，
要么 λ 有有界逆。第 45 章将展开完整的 Fredholm 理论。
