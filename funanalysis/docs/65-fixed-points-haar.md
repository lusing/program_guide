## 65.1 Markov-Kakutani 定理

**定理（Rudin 5.23）**。K 是 TVS X 中的非空**紧凸**集，Γ 是 K 到
K 中的**连续仿射**映射的**交换族**。则存在 p ∈ K 使 T p = p 对
一切 T ∈ Γ。

**证明**（全文；两个组件：平均值半群 + 有限交性质）。

对 T ∈ Γ 记 T⁰ = I，Tⁿ⁺¹ = T∘Tⁿ，其** Cesàro 平均**

```
T_n = n⁻¹(I + T + ⋯ + T^{n−1})                      (1)
```

仍是 K→K 的仿射映射，且任何两个 T_n（不同 T、不同 n）**彼此交换**
（交换族 + 多项式演算）。令 Σ 为全体 T_n 的复合生成的半群。

**有限交性质**：若 f, g ∈ Σ，则 h = f∘g = g∘f ∈ Σ 且
f(K) ∩ g(K) ⊇ h(K) ≠ ∅（(2)：f(g(K)) ⊆ f(K)）。归纳：{f(K) : f ∈ Σ}
是紧集族，任一有限子族之交非空 ⟹ **全族之交含 p**：p ∈ f(K)
对一切 f ∈ Σ。

**p 是不动点**：固定 T ∈ Γ，V 是 0 的任一邻域。n ≥ 1 时
p ∈ T_n(K)，即 p = T_n x（某 x ∈ K）。于是

```
p − T p = n⁻¹(x − Tⁿx) ∈ n⁻¹(K − K)                  (3)(4)
```

K − K 紧 ⟹ 有界（Rudin 1.15(b)），n 充分大时 n⁻¹(K−K) ⊆ V。
V 任意 ⟹ p − T p = 0。∎

**评注**：证明的关键是平均 (1) 的**范数压缩效应**——因子 n⁻¹ 把
紧差集 K−K 压进任何邻域。这与 49 章 Banach 极限的 Cesàro 组合
C_n(I−A) = n⁻¹(I−Aⁿ) 是**同一个机制**：可交换性让差商成为 telescoping，
平均让幅度除以 n。

## 65.2 不变 Hahn-Banach 定理与有限可加不变测度

**定理（Rudin 5.24，不变 Hahn-Banach）**。Y ⊆ X 子空间，f ∈ Y*，
Γ ⊆ B(X) 两两交换，T(Y) ⊆ Y 且 f∘T = f。则 f 有延拓 F ∈ X*
满足 ‖F‖ = ‖f‖ 且 **F∘T = F** 对一切 T ∈ Γ。

**证明**：K = {A ∈ X* : ‖A‖ ≤ 1, A|_Y = f/‖f‖} 凸、弱*闭、含于
闭单位球 ⟹ **Banach-Alaoglu ⟹ 弱*紧**。映射 A ↦ A∘T 是 K 到 K
的弱*连续仿射映射，Γ 交换 ⟹ Markov-Kakutani 给不动点 F。∎

（对照 49 章 Agnew-Morse：Lax 用支配泛函 p 的凸组合磨光；Rudin
用弱*紧凸集上的平均不动点——**同一目标的两条施工路线**。）

**定理（Rudin 5.25）**。任何 Abel 群 G 上存在 μ: 幂集 → [0,1]
使：

1. 有限可加（不交并）；
2. **平移不变**：μ(E+a) = μ(E)；
3. μ(G) = 1。

**证明**：X = l^∞(G)，Y = 有极限的序列（极限泛函 A ∈ Y*，‖A‖=1）。
平移算子 τ_a 交换、保 Y、A∘τ_a = A。5.24 给不变延拓 **L**（Banach
极限的群论版！）。定义 μ(E) = L(χ_E)：

- 有限可加：χ_{E₁∪E₂} = χ_{E₁}+χ_{E₂}（不交）+ L 线性；
- 平移不变：χ_{E+a} = τ_a χ_E；
- 0 ≤ μ ≤ 1 由**引理 5.26**（‖L‖ = L(1) = 1 + 0 ≤ f ≤ 1 ⟹
  0 ≤ Lf ≤ 1——二次式判别式）。∎

**反例（Rudin 5.27，非交换）**：二人自由群按首字母分四类 I∪II∪III∪IV，
平移不变性迫使 μ(III) = μ(I) 与 μ(I) = μ(I∪II)，单点测度 0 ⟹ μ ≡ 0。
**交换性不可去**——Hausdorff/Banach-Tarski 的代数根源。

**会师**：49 章（Lax 4.3）用旋转交换群 + Agnew-Morse 证明了圆周
上的旋转不变有限可加测度；本章 (5.25) 是任意 Abel 群的代数版。
两者互相不能替代：Lax 版带拓扑（旋转连续性），Rudin 版纯代数
（任意 Abel 群，包括不可数）。

## 65.3 Kakutani 定理

**定理（Rudin 5.11）**。K 局部凸空间中的非空紧凸集，Γ 是 K 到 K
的**等度连续**仿射映射群（不必交换！）。则存在 p ∈ K 使
T p = p 对一切 T ∈ Γ。

**证明思想**（比 Markov-Kakutani 弱在等度连续、强在不要交换）：
取 K 的闭包套 K ⊇ K₁ ⊇ K₂ ⊇ …（Kₙ = 闭包 of Γₙ-平均的像），
Arzelà-Ascoli 式的紧性沿嵌套传递到交集。∎（细节 Rudin 5.11–5.12。）

**评注**：Markov-Kakutani 要交换但只取平均；Kakutani 用等度连续
换掉交换——这正是 Haar 测度存在性需要的形式（左移群 L_s 不交换
当 G 非交换，但**等距** ⟹ 等度连续）。

## 65.4 Haar 测度：存在与唯一

**设定**：G 紧群（拓扑群 + 紧），C(G) 上确界范数。左移 (L_s f)(x)
= f(sx)，右移 (R_s f)(x) = f(xs)。

**定理（Rudin 5.13）**。f ∈ C(G) 的左移集 {L_s f : s ∈ G} 的
凸壳 H_f 在 C(G) 中**紧**。

**证明**：s ↦ L_s f 连续（一致连续性论证：紧群上 f 一致连续 ⟹
s⁻¹t ∈ V ⟹ ‖L_s f − L_t f‖ < ε）⟹ {L_s f} 紧 ⟹ 凸壳紧
（C(G) 中紧集的凸壳的闭包紧——局部凸空间的 Krein 定理，Rudin
3.20(c)）。∎

**定理（Rudin 5.14，Haar）**。紧群 G 上存在**唯一**正则 Borel
概率测度 m 使

```
∫ L_s f dm = ∫ f dm    （左不变，一切 s ∈ G, f ∈ C(G)），
```

且 m 同时右不变、反演不变（∫f(x⁻¹)dm = ∫f(x)dm）。

**存在性证明**（全文，Kakutani 路线）：

1. **左移群等度连续**：L_s 都是 C(G) 的等距（sup 范数），
   群性质 L_s L_t = L_{st}。
2. **Kakutani 应用**：K_f = H_f 的闭包紧凸、L_s(K_f) ⊆ K_f ⟹
   存在 φ ∈ K_f 使 **L_s φ = φ 对一切 s**。s = e 给 φ(x) = φ(ex)
   = φ(x)；取 s = x⁻¹：φ(x) = φ(x⁻¹x) = φ(e)——**φ 是常数**！
3. **M 泛函**：每个 f ∈ C(G) 至少有一个常数 c 可被 f 的左移的
   凸组合一致逼近。左逼近常数与右逼近常数相同（交换混合和
   Σαᵢβⱼ f(aᵢbⱼ) 的双重读法 (6)(7)）⟹ **Mf 良定义**。
4. **M 的性质**：M ≥ 0（正性）、M(1) = 1、线性（凸壳的组合
   论证 (13)–(18)）、M(L_s f) = M(f) = M(R_s f)。
5. **Riesz 表示**：C(G) 上的正线性泛函 ⟹ 正则 Borel 测度 m 使
   Mf = ∫f dm。左/右不变从 M 的不变性继承。∎

**唯一性**：若 μ 也左不变，用 m 的右不变性：

```
∫f dμ = ∫dm(y)∫f(yx)dμ(x) = ∫dm(y)∫f(yx)dμ(x) = ∫f dμ·? ...
```

——内层积分 = ∫f(x)dμ（μ 左不变），于是 ∫f dμ = (∫f dm)·μ(G)
⟹ μ = m（概率归一）。∎

**对照 mathlib**：本树 `MeasureTheory.Measure.Haar` 走 **Weil–
Cartan 路线**（prehaar 泛函的紧集上的函数 + Tychonoff 乘积紧性），
Rudin 走 **Kakutani 路线**（C(G) 中的不动点）——同一结果的两条
独立施工，正是"第二证明通道"原则在数学本身层面的体现。

## 65.5 Schauder-Tychonoff 定理

**定理（Rudin 5.28）**。K 局部凸空间中的非空紧凸集，f: K → K
连续（**不仿射、不线性**）。则 f 有不动点。

**证明骨架**（全文要点；Brouwer 的无穷维推广）：

1. 假设无不动点 ⟹ 图像与对角线不相交 ⟹（分离 1.10）取凸均衡
   邻域 V 使 f(x) ∉ x+V。
2. V 的 **Minkowski 泛函 μ**（64 章的工具！）连续；截断函数
   α(x) = max(0, 1−μ(x)) 给 K 的有限覆盖 x₁+V, …, x_n+V 的
   **单位分解** βᵢ(x) = αᵢ(x)/Σαⱼ(x)。
3. 有限维单形 H = conv{x₁,…,x_n} ≅ ℝⁿ 中的连续映射
   g: H → H（g(x) = Σβᵢ(x)·xᵢ 的组合），**Brouwer 不动点**给
   g(y) = y。
4. β 的构造保证 f(y) − y ∈ V 的任意小倍数 ⟹ V 任意 ⟹ f(y) = y，
   矛盾。∎

**评注**：这是"Brouwer ⟹ Schauder"的标准桥：紧凸集上的连续
映射被**单位分解**投影到有限维单形上，Brouwer 收尾。C(K) 的
Arzelà-Ascoli 紧性是验证"K 紧凸"假设的日常工具（第一卷 10 章）。

## 65.6 Julia 数值实验

实验文件 `examples/julia/65_fixed_points_haar.jl`。

**实验 1：Markov-Kakutani 平均迭代的收敛**。ℝ² 紧凸集 K = 三角形，
两个交换仿射映射 T₁, T₂（各自收缩率 < 1 但和可能慢）：迭代
(T₁∘T₂)ₙ 的平均序列 pₙ = Tₙ(x₀) 收敛到公共不动点（误差幂律）；
对照非交换对（T₁T₂ ≠ T₂T₁）：平均序列可能发散/游走。

**实验 2：Haar 测度的经验构造（紧群的数值积分）**。SO(2)（圆周
旋转群）：Haar 测度 = 弧长测度。数值：对 f ∈ C(SO(2))，用随机
群元素 s₁..sₙ 的左移平均值 (1/n)ΣL_{sᵢ}f 与均匀积分对照——
收敛到常数（Mf），验证 5.14 的 M 泛函机制；再对 SO(3)（用
四元数表示随机采样）：经验 Haar 测度在球面上的均匀性（对
若干类函数的群平均 = 表面积分，误差 O(n^{-1/2})）。

**实验 3：不变测度 vs 概率测度的单点质量**。有限群 S₃：Haar
= 均匀测度（每点 1/6）；数值验证均匀测度是唯一左不变的（随机
初始测度经多次随机群元素平移的平均 → 均匀）——5.25 的有限群
情形（平凡）但平均收敛机制是唯一的可视窗口。

**实验 4：Schauder-Brouwer 桥的数值演示**。K = [0,1]²，连续
非仿射映射 f（例如旋转 30° + 平移）：Brouwer 不动点迭代（单纯
形重心迭代 or 不动点迭代）收敛；统计不动点数与指标（在边界
环绕数）。对照 f 在非凸域上不动点可缺失。

## 65.7 Python 数值实验

实验文件 `examples/python/65_fixed_points_haar.py`。

**实验 1：凸壳逼近常数的速度**。圆周群：f(θ) = exp(cos θ) 的
左移凸组合（等距采样 n 个移位的平均）收敛到常数 = Mf =
弧长平均（Fourier 求和公式逐系数验证：只有零频存活）；
收敛率 O(1/n²)（等距）vs O(n^{-1/2})（随机移位）。

**实验 2：非 Abel 反例的数值面**。二人自由群的平移不变性矛盾
（5.27 的四类分解）：数值构造四类代表元的转移图（邻接矩阵），
验证任何"平移不变测度"的线性方程组只有零解——不可满足性的
线性代数形态。

**实验 3：Weil–Cartan vs Kakutani 的数值对照**。两条路线都收敛
到同一 Haar 积分：(a) Rudin 路线（左移凸组合平均）；(b) 格点
计数（prehaar 的 index 函数数值版：K+V 的 V-覆盖数的比值收敛）。
对 S¹ 与 S₃（四元数）双群验证。

**实验 4：Schauder 的有限维投影**。K = 二维单形，f = 非线性
连续自映射（分段线性扰动）：实现证明中的 βᵢ 分解 + 单形重心
坐标下的 Brouwer 求解（scipy.optimize.root 多起点），不动点与
直接迭代对照。
