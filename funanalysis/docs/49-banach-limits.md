# 49 · Banach 极限与不变平均

> 极限不存在时，能不能给每个有界数列指派一个"极限"，
> 使得它线性、平移不变、且夹在 liminf 与 limsup 之间？
> Banach 用 Hahn-Banach 定理证明：能。——Lax 第 4 章（意译）

本章覆盖 Lax 第 3.3 节（Agnew-Morse 不变 Hahn-Banach 定理）、
第 4.2 节（Banach 极限）与第 4.3 节（旋转不变的有限可加测度）。
这是 Hahn-Banach 定理（第一卷 15 章）最出人意料的应用群：
**不可计算的极限**与**不可数可加的测度**——它们存在，但不唯一，
而且原则上无法显式写出（任何构造都要用选择公理式的延拓）。

## 49.1 引擎：Agnew-Morse 不变 Hahn-Banach 定理

Hahn-Banach 定理（支配延拓形式）说：p 正齐次 + 次可加、l 在子空间
Y 上被 p 支配，则 l 可延拓到全空间仍被 p 支配。**Agnew 与 Morse
（1938）的加强版**让延拓额外与一族交换的线性算子交换：

**定理（Lax 第 3 章定理 7）**。设 X 是实线性空间，A 是 X 上一族
**两两交换**的线性映射 A_γ。p: X → ℝ 正齐次、次可加，且**在每
个 A_γ 下不变**：p(A_γ x) = p(x)。Y 是不变子空间（A_γ Y ⊆ Y），
l 是 Y 上的线性泛函，被 p 支配且**在每个 A_γ 下不变**：
l(A_γ y) = l(y)。则 l 可延拓到全空间 X，仍被 p 支配，且在每个
A_γ 下不变。

**证明**（Lax 原文，两步，值得完整看）。

**第一步：磨光 p**。先把 A 扩充为半群（添入恒等与所有有限乘积，
交换性保证仍是半群）。定义

```
g(x) = inf { p(C x) : C ∈ conv(A) }
```

其中 conv(A) 是 A 中映射的**凸组合** C = ΣαⱼAⱼ（αⱼ ≥ 0，Σαⱼ = 1）。
断言 g 满足：

- g ≤ p：取 C = I（凸组合允许取一个成员）。
- **g 仍正齐次、次可加**：次可加性的证明是本定理的心脏。对 ε > 0
  取 C, D ∈ conv(A) 使 p(Cx) ≤ g(x)+ε、p(Dy) ≤ g(y)+ε。注意
  **CD = DC**（交换半群的凸组合相乘仍是凸组合），于是

  ```
  g(x+y) ≤ p(CD(x+y)) = p(DCx + CDy) ≤ p(Cx) + p(Dy) ≤ g(x)+g(y)+2ε
  ```

  （第一个不等号因为 CD ∈ conv(A) 可作为下确界的候选；中间用了
  p 的次可加性与**不变性** p(Dz) ≤ p(z)——由 (21)：p(Cₙz) 型的
  凸组合不放大 p）。ε 任意，得次可加。
- 在 Y 上 l ≤ g：由 l(Aⱼy) = l(y) 凸组合下 l(Cy) = l(y) ≤ p(Cy)，
  对 C 取下确界。

于是普通 Hahn-Banach 给出延拓 l ≤ g ≤ p。

**第二步：延拓的不变性**。这是**几何平均技巧**：对任一 A ∈ A 与
自然数 n，取 Cesàro 型凸组合 Cₙ = n⁻¹(I + A + ⋯ + A^{n−1}) ∈ conv(A)。
几何级数恒等式 Cₙ(I − A) = n⁻¹(I − Aⁿ) 给出

```
g(x − Ax) ≤ p(Cₙ(x − Ax)) = (1/n)·p(x − Aⁿx) ≤ (1/n)(p(x) + p(−x))
```

右端随 n → ∞ 趋于 0，故 g(x − Ax) ≤ 0，从而 l(x − Ax) ≤ 0。把
x 换成 −x 得反向不等式，两式合一：**l(Ax) = l(x)**。∎

**评注**。证明的关键一步"p(Dz) ≤ p(z) 对凸组合 D 成立"来自
次可加 + 正齐次 + 不变性的合成：

```
p(Cx) = p(ΣαⱼAⱼx) ≤ Σαⱼp(Aⱼx) = Σαⱼp(x) = p(x)
```

而 Cₙ 的 Cesàro 结构消去了 Aⁿ 的增长——这和第 51 章将见到的
Toeplitz 求和判据、第 60 章的平均遍历定理是**同一个机制**：
用平均化把不可压缩的漂移除掉。

## 49.2 Banach 极限

**构造**（Lax 第 4.2 节）。B 是有界实数列 x = (a₁, a₂, …) 的空间。
定义

```
p(x) = lim sup aₙ
```

p 显然正齐次；次可加性是经典练习（limsup(aₙ+bₙ) ≤ limsup aₙ +
limsup bₙ，本章 Lean 通道将完整机器化）。左平移算子

```
A x = (a₂, a₃, …)
```

是线性、双射的，且 **p(Ax) = p(x)**（去掉有限项不改变 limsup——
本章 Lean 锚点 `limsup_nat_add` 的内容）。取 Y = 收敛数列空间，
l(y) = lim y。Y 平移不变、l 平移不变、l ≤ p（收敛列的极限 =
其 limsup）。Agnew-Morse 定理给出延拓 LIM。

**定理（Lax 第 4 章定理 3）**。对每个有界数列可指定**广义极限**
（Banach 极限）LIM，满足：

1. 收敛数列上 LIM = lim；
2. 线性：LIM(x + y) = LIM x + LIM y，LIM(cx) = c·LIM x；
3. **平移不变**：LIM(a_{n+k}) = LIM(aₙ) 对一切 k；
4. **夹逼**：lim inf aₙ ≤ LIM aₙ ≤ lim sup aₙ。

证明：性质 2 是 l 的线性；3 是 Agnew-Morse 给的不变性；4 来自
l(x) ≤ p(x) 与 l(−x) ≤ p(−x)（即 −liminf）。∎

**三个值得记住的事实**：

- **不唯一**：LIM 对 (1, 0, 1, 0, …) 的取值只被夹逼限定在 [1/2, 1]
  内，取哪个值依赖延拓的选择。事实上可以构造取 1/2 的 Banach
  极限（见习题 3），也可以构造取其它值的。
- **不可显式化**：任何 Banach 极限都不能写成可计算的公式（这可以
  严格化：Banach 极限的存在性等价于某种非构造选择）。数值实验
  能做的只是用**平移平均族**（Cesàro、对数平均、Gauss 平均……）
  逼近它——这些平均都满足定理 3 的性质 1、3、4 的"有限版"。
- **与可数可加性的张力**：LIM 把"数密度"变成测度（下节），但
  平移不变与可数可加不可兼得（否则 {n} 的测度矛盾：单点集平移
  不变测度全等，可数可加迫使密度测度非 σ 有限——见习题 5）。

## 49.3 旋转不变的有限可加测度

**定理（Lax 第 4 章定理 4）**。可在单位圆周的**所有**子集上定义
非负、有限可加、旋转不变的集函数 m。

**证明**。S = 单位圆周，B(S) = S 上有界函数空间。取 Y = 有界
Lebesgue 可测函数，l(y) = ∫y dθ（Lebesgue 积分）。旋转 ρ 诱导
算子 A_ρ，**旋转交换** ⟹ A_ρ 组成交换群；l 与 p（由支配构造的
p(x) = inf{l(y) : y ≥ x, y 可测}）都旋转不变。Agnew-Morse 给出
延拓：线性、旋转不变、被 p 支配（从而单调）。

对任意子集 P ⊆ S，定义 m(P) = l(χ_P)。则：χ_P ≥ 0 与 l 单调给
m ≥ 0；χ_{P∪Q} = χ_P + χ_Q（P, Q 不相交）与 l 线性给有限可加；
χ_{P+ρ} = A_ρ χ_P 与 l 的不变性给旋转不变。∎

**注记（Hausdorff / Banach-Tarski）**。二维成功的原因是圆周的
旋转群**交换**。三维球面的旋转不交换，Agnew-Morse 不适用——而且
Hausdorff 证明了三维版本**为假**：S² 上不存在旋转不变的有限可加
测度。其证明基于 S² 的有限分解（把不可交换性兑现为旋转的自由
乘积结构），这就是 Banach-Tarski 悖论的源头。**交换性不是技术
条件，是本质条件**——本章 Prolog 通道在有限群上重演这一点。

**有限群对照**。n 阶循环群 ℤ/n 上，"平移不变 + 非负 + 归一"的
集函数只有均匀测度（各点 1/n）：不变性沿传递轨道传递，唯一确定。
Prolog 实验 `49_invariant_mean.pl` 把这个推理自动化：给定轨道生成
的等式链，推出每个点的测度必须相等。无穷群（ℤ）上轨道也是传递
的，但没有归一化的可数可加不变测度；Banach 极限正是放弃可数可加
（只要有限可加）后的替代品，代价是失去唯一性。

## 49.4 Cesàro 平均与数值逼近

Banach 极限不可计算，但它的**影子**可计算。对有界序列 x 定义
一族**平移不变平均**（Toeplitz 矩阵的特殊情形，51 章系统化）：

```
σ_n(x) = (1/n) Σ_{i<n} aᵢ                 （Cesàro）
λ_n(x) = (1/H_n) Σ_{i≤n} aᵢ/i             （对数平均）
```

两者都满足：liminf ≤ lim ≤ limsup（当 lim 存在时 = lim），
|x| ≤ C ⟹ |σ_n| ≤ C（一致有界）。它们是 Banach 极限的"可计算
逼近"：对任何具体的 x，σ_n(x) 收敛到的值（若收敛）恰是某个 Banach
极限可以取到的值（Lax 习题 2：Banach 极限可选取成与一切 Cesàro
可和序列的 Cesàro 值一致——本章习题 4 给出思路）。数值实验对照
三类序列（收敛、周期、缓发散）上各平均的行为。

**平移不变性的数值形态**：|σ_n(x) − σ_n(Ax)| → 0，速率 ~ C/n
（前 n 项差被 2/n 压平）。这是有限截断对不变性的"近似满足"，
在实验中可直接测量。

## 49.5 Julia 数值实验

实验文件 `examples/julia/49_banach_limits.jl`。

**实验 1：三族平均对照表**。对四个序列——aₙ = 1/n（收敛到 0）、
(−1)ⁿ（周期）、aₙ = sin(√n)（缓振荡不收敛）、aₙ = (−1)ⁿ·(1+1/n)
（周期 + 收敛调制）——计算 n = 10³, 10⁴, 10⁵ 处的 Cesàro 与
对数平均。断言：收敛列两者都 → 极限；周期列两者都落在夹逼区间
[liminf, limsup] 内；(−1)ⁿ 的 Cesàro 值以 1/n 速率 → 0。

**实验 2：同窗平移差的精确形态**。Cesàro 平均的平移不变性在有限
截断上"差一个尾巴"：σ_n(x) − σ_n(Ax) = (a₁ − a_{n+1})/n，模 ≤ 2/n
（序列有界于 [−1,1]）。实验对随机序列在三档 n 上验证 n·|差| ≤ 2
且实际触到典型值——不变性的有限近似恰好是 O(1/n)。

**实验 3：不同不变平均给出不同值**。序列 xₙ = 0（n ≤ N/2）、1（后
半段）：Cesàro 平均 → 1/2，而对数平均 → ln2/ln N ≈ 0.057（权重
1/n 偏头部）。两个都是合法的"广义极限候选"（线性、夹逼、渐近平移
不变），但对同一序列给出不同值——**Banach 极限非唯一性**的数值
影子。这正是 Lax 习题 3 的内容：可以构造取 1/2 的 Banach 极限，
也可以构造取别的值的。

**实验 4：有限循环群上的唯一不变平均**。n = 12 的循环群上，解
线性方程组 m_{i+1} = m_i（i mod 12）、Σm_i = 1、m_i ≥ 0：唯一解
均匀测度。与无穷情形（49.2-49.3：存在但不唯一）对照。

## 49.6 Python 数值实验

实验文件 `examples/python/49_banach_limits.py`。

**实验 1：Cesàro 不可和、对数平均可和**。构造 aₙ = (−1)^⌊log₂ n⌋
（块长翻倍的符号序列）。数值显示其 Cesàro 平均在块边界 2^k 处振荡
于 ±1/3 不收敛（0/1 版本 b = (a+1)/2 即 [1/3, 2/3]），而对数平均
λ_n(b) → 1/2（Hardy-Littlewood 型结论的数值影子：对数平均严格强
于 Cesàro）。这也说明"Banach 极限与 Cesàro 值一致"（Lax 习题 2）
是选择而非必然——对这种序列别的 Banach 极限可以取别的值。

**实验 2：旋转不变测度的有限模型**。64 点离散圆周上，随机子集
P 的"均匀测度" |P|/64 在旋转下不变；构造 Lebesgue 不可测集的
有限类比（按 2-adic 陪集拆分），显示任何有限加细仍均匀——有限
世界里不存在"不可测"现象，不可测性是无穷的本质。

**实验 3：Banach 极限的一致性检验**。对 (1,0,1,0,…) 与
(0,1,0,1,…)（互为平移）验证各平均给出相同的极限值——平移不变性
在可计算平均上成立；再对照 (1,1,0,0,1,1,0,0,…)（平移两次回到
自身，周期 4）：任何不变平均必须给 1/2，Cesàro 收敛到 1/2。

## 49.7 Prolog：有限不变平均的推理

实验文件 `examples/prolog/49_invariant_mean.pl`。三件事：

1. **轨道传递 ⟹ 均匀**：`same_orbit(X,Y)` 由平移边的传递闭包
   定义，不变平均强迫 `m(X) = m(Y)`；连通性 + 归一化推出全部
   相等 = 唯一性。用具体数值（n = 6）算出 1/6。
2. **不连通轨道的反例**：群 ℤ/6 的子半群生成的轨道若不连通
   （故意构造），解不唯一——显示"传递性 ⟹ 唯一"的逻辑依赖。
3. **Toeplitz 条件的有限检查**：谓词 `regular(+M)` 检查求和矩阵
   的三条（行和 → 1、列 → 0、行绝对和一致有界）在给定有限截断
   上是否成立，对 Cesàro / 点值（恒等）/ 加权三类矩阵给出判定。

## 49.8 Lean 机器化

文件 `examples/lean/Funanalysis/Ch49BanachLimits.lean`。mathlib 树中
没有 Banach 极限（`BanachLimit` 全树检索不存在），但 **p = limsup
的关键性质**——Banach 极限构造的引擎——可以机器化：

```lean
-- 平移不变（Lax (13)）：去掉前 k 项不改变 limsup
example (f : ℕ → ℝ) (k : ℕ) :
    limsup (fun i => f (i + k)) atTop = limsup f atTop :=
  limsup_nat_add f k

-- 夹逼（定理 3 (iv) 的骨架）：liminf ≤ limsup（需两侧有界）
example (f : ℕ → ℝ) (h1 : BddAbove (Set.range f)) (h2 : BddBelow (Set.range f)) :
    liminf f atTop ≤ limsup f atTop :=
  liminf_le_limsup (isBoundedUnder_of_bddAbove h1) (isBoundedUnder_of_bddBelow h2)
```

`isBoundedUnder_of_bddAbove/bddBelow` 是本章搭的桥：把经典的
BddAbove (range u) 转成 filter 语言的 `IsBoundedUnder`（后者是
map-像的界，不能直写 `⟨C, eventually⟩`——这是实测坑）。

**没能证成的**：p 的次可加性 limsup(f+g) ≤ limsup f + limsup g。
计划走 `eventually_le_limsup`（f 最终 ≤ limsup f）加法组合收尾，
但本树（2026 版 mathlib）把 `CountableInterFilter` 与
`IsCountablyGenerated` 解耦成无桥接的两个类，全树不存在
`CountableInterFilter atTop` 实例，该引理对 atTop 根本不可实例化。
次可加性留给纸笔习题 1——API 断层如实记录，不为凑绿降格陈述。
