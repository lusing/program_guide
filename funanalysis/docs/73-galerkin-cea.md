# 73 · 弱解与 Galerkin 误差：边值问题的 Riesz 路线

> 古典解 u ∈ C² 的存在性很难直接证明；近代路线是先在更弱的意义下
> 求解并证其唯一，再回头补光滑性——正是这条路把泛函分析变成了
> 偏微分方程理论的必需品。——《工科泛函分析基础》6.4 节（意译）

本章是工科篇的高潮：书 6.4 节把前六章的零件——距离空间的完备性
（第 2 章）、Banach 空间与算子（第 3 章）、Hilbert 空间的内积与
Riesz 表示（第 4 章）、延拓定理（第 5 章）、Sobolev 空间（第 6 章
前半）——全部装进一台机器：**狄氏边值问题弱解的存在唯一性**。
本章再向前一步，把工程师的下一步（离散化求解）也纳入理论：
Galerkin 投影与 **Céa 引理**——书没有展开但它是书 6.4 与有限元法
之间的桥，也是本教程 48 章（Lax-Milgram）的工科续篇。

## 73.1 从古典解到弱解

**问题（狄氏边值问题）**。求 u 使

```
−Δu = f(x)（x ∈ Ω），   u|_{∂Ω} = 0，   f ∈ L²(Ω)
```

古典解要求 u ∈ C²(Ω)——两个二阶导数逐点存在且连续。但存在性证明
在一般区域上碰壁（特征函数展开只在特殊区域可用），而且 f 只属于
L² 时逐点方程根本没有意义。**弱化**：两边乘以检验函数 v ∈ C₀^∞，
分部积分（Green 公式，边界项被 v 的零边值抹掉）：

```
∫_Ω f v dx = ∫_Ω ∇u·∇v dx        对一切检验函数 v
```

左边的 f 只需可积，右边的 u 只需一阶弱导数（71 章）——方程从
"逐点"降到"积分"，对解的要求从 C² 降到 W^{1,2}。

**定义（弱解，书 6.4.1）**。u ∈ H₀¹(Ω) = W₀^{1,2}(Ω) 满足

```
∫_Ω ∇u·∇v dx = ∫_Ω f v dx       对一切 v ∈ H₀¹(Ω)
```

就称 u 是狄氏边值问题的弱解。（检验函数放宽到 H₀¹：C₀^∞ 在其中
稠密，积分等式按范数连续，二者等价。）**古典解必是弱解**（分部
积分一遍）；反方向（弱解的正则性提升）在 f 与 ∂Ω 足够正则时成立，
是 PDE 理论的大章节，书 6.4 的注记如实指出。

## 73.2 存在唯一性：Riesz 路线三步

**定理（书 6.4.2）**。对任意 f ∈ L²(Ω)，弱解存在且唯一。

**证明（书的路线，完整给出——全教程变分法的缩影）**。

**第一步（Poincaré 造内积）**。72 章的 Poincaré 不等式
‖v‖_{L²} ≤ C‖∇v‖_{L²} 保证 ⟨u, v⟩₁ := ∫∇u·∇v 在 H₀¹ 上是真内积
（常数函数不在 H₀¹ 里——零迹杀死退化方向），诱导范数 ‖v‖₁ = ‖∇v‖_{L²}。

**第二步（Hölder 造泛函）**。定义 l(v) = ∫fv。积分 Hölder（70 章）：

```
|l(v)| ≤ ‖f‖_{L²}‖v‖_{L²} ≤ C‖f‖_{L²}·‖v‖₁
```

第二个 ≤ 恰是 Poincaré——l 是 (H₀¹, ⟨·,·⟩₁) 上的**有界线性泛函**。

**第三步（Riesz 收尾）**。Riesz 表示定理（本教程 04 章）：Hilbert
空间上每个有界线性泛函都是内积——存在唯一 u₀ ∈ H₀¹ 使

```
⟨u₀, v⟩₁ = l(v)，即 ∫∇u₀·∇v = ∫fv     对一切 v
```

u₀ 就是弱解。**唯一性**：若 u₀、u₁ 都是弱解，差 w = u₀ − u₁ 满足
∫∇w·∇v = 0 对一切 v；取 v = w 得 ‖∇w‖² = 0，Poincaré 给 w = 0。∎

三步各用了前面一章的支柱：Poincaré（72）、Hölder（70）、Riesz（04）。
对称形式的 Lax-Milgram 版本（非对称情形：对流项）见 48 章；本章
数值实验 4 会把非对称强制矩阵也纳入检验。

## 73.3 Galerkin 投影：把无穷维压进有限维

弱解仍住在无穷维空间里。工程师的做法：取 H₀¹ 的 n 维子空间
Vₕ = span{φ₁, …, φₙ}（一维帽函数基是标准选择），求**离散弱解**
uₕ ∈ Vₕ 使

```
∫∇uₕ·∇v dx = ∫fv dx        对一切 v ∈ Vₕ
```

代入 v = φⱼ 求和系数 c = (c₁,…,cₙ)：**K uₕ = Σcᵢφᵢ，得刚度方程**

```
K c = F，   K_ij = ∫∇φᵢ·∇φⱼ（刚度矩阵），   F_i = ∫f φᵢ（载荷向量）
```

K 对称正定（Poincaré 内积的 Gram 矩阵）——离散的 Riesz 路线自动
成立，高斯消元即得 c。两条等价观点：Galerkin 方程法（上面）与
**Ritz 能量法**——J(v) = ½∫|∇v|² − ∫fv 在 Vₕ 上取最小值的一阶条件
J′(uₕ)v = B(uₕ,v) − l(v) = 0 恰是 Galerkin 方程（Python 实验 2：
梯度 = Kc − F ≈ 0、Hessian 正定、扰动能量严格更大）。

**帽函数刚度矩阵**（一维单元 [xₑ, xₑ₊₁]，h 为步长）：

```
∫φᵢ′² = 2/h（对角），  ∫φᵢ′φⱼ′ = −1/h（相邻），0（其他）
```

装配就是"对每个单元枚举两个顶点"的规则循环——Prolog 通道
（`prolog/73_galerkin_cea.pl`）把这条循环做成纯规则：
`stiffness_contrib(E, I, J, C)` 三条子句，N=2 时装配出
A = [[4,−1],[−1,4]] 与质量阵 M = [[2/3,1/6],[1/6,2/3]]（h=1）——
有限元装配的"推理化"版本。

## 73.4 Céa 引理：误差被最优逼近控制

离散解好不好？**Céa 引理**给出结构性回答。

**定理（Céa）**。B: V×V→ℝ 双线性、强制（B(v,v) ≥ b‖v‖²）、连续
（|B(x,y)| ≤ c‖x‖‖y‖）。u 是变分问题 B(u,v) = l(v) 的解，uₕ ∈ Vₕ
满足 Galerkin 方程 B(uₕ,v) = l(v)（v ∈ Vₕ），则

```
‖u − uₕ‖ ≤ (c/b) · inf_{v ∈ Vₕ} ‖u − v‖
```

**证明（三行不等式的焊接）**。记误差 e = u − uₕ。两方程相减得
**Galerkin 正交性** B(w, e) = 0 对一切 w ∈ Vₕ。对任意 v ∈ Vₕ
（注意 v − uₕ ∈ Vₕ）：

```
b‖e‖² ≤ B(e, e)                    （强制性）
      = B(e, u−v) + B(e, v−uₕ)     
      = B(e, u−v)                   （正交性，第二槽 v−uₕ ∈ Vₕ）
      ≤ c‖e‖·‖u−v‖                  （连续性）
```

相除（‖e‖ > 0 时）即得。∎

读法：**Galerkin 解在 Vₕ 中是拟最优的**——误差最多比"Vₕ 能做到
的最好逼近"差一个常数 c/b（对称情形恰是算子谱的条件数）。剩下的
是逼近论：帽函数插值误差 ‖u − Iₕu‖_{H¹} = O(h)（中点超收敛使 L²
端达 O(h²)，48 章已数值重演），Céa 把它原样（乘常数）传递给真误差
——有限元的收敛性证明就此封顶。

**方差约定要注意**：正交性必须落在**第一变元在 Vₕ**（B(w, e) = 0），
而分解动的是**第二变元**（e = (u−v) + (v−uₕ) 的第二项 v−uₕ ∈ Vₕ
做 B 的第二槽）——两者通过"哪一槽装检验函数"对上。Lean 证明里
这段就是第一槽 map_add 的两行。

Lean 通道（`Funanalysis/Ch73Cea.lean`）把引理完整形式化：

```lean
theorem cea_lemma (B : V →L[ℝ] V →L[ℝ] ℝ)
    (b : ℝ) (hb : 0 < b) (hcoe : ∀ v, b * ‖v‖ * ‖v‖ ≤ B v v)
    (c : ℝ) (hc : 0 ≤ c) (hcont : ∀ x y, |B x y| ≤ c * ‖x‖ * ‖y‖)
    (Vh : Submodule ℝ V) {u uh : V} (huh : uh ∈ Vh)
    (horth : ∀ w ∈ Vh, B w (u - uh) = 0) {v : V} (hv : v ∈ Vh) :
    ‖u - uh‖ ≤ (c / b) * ‖u - v‖
```

证明与 73.4 逐步对应：`Submodule.sub_mem`（v − uₕ ∈ Vₕ）、第一槽
`map_add` 分解 + 正交性消项、`le_abs_self` 桥接绝对值、
`mul_le_mul_iff_of_pos_right` 消去 ‖e‖。文件同时给出 mathlib 官方
Lax-Milgram 的接口衔接（`IsCoercive.continuousLinearEquivOfBilin`：
强制形式的表示算子是连续等价——48 章的锚点在此复用，变分问题的
解 u 由此取出，满足 Céa 的一切前提）。

## 73.5 数值实验全景

**Julia（`julia/73_galerkin_cea.jl`）**四个实验共用一个装配器：
① Galerkin 正交性数值残差 ~ 5×10⁻¹⁴（方程残差 = 正交性）；
② Céa 拟最优性：H¹ 误差 ≤ (λmax/λmin)·插值误差，节点超收敛使
实际误差近乎为零；③ 收敛阶：H¹ 半范恰 1.00 阶、L² 恰 2.00 阶
（每单元 2 点 Gauss 测量——见下面的实测坑）、节点误差 10⁻¹⁰ 级；
④ 非对称强制（β=5 对流刚度阵）：强制常数 0.15 > 0，可解 + 唯一 +
Lax-Milgram 范数界 ‖y‖ ≤ ‖f‖/b 全过。

**Python（`python/73_galerkin_cea.py`）**三个实验：① Riesz 路线
三步对账——广义特征值 λmin(K, M) = 9.87 ≥ π²（Poincaré 的离散
形态：注意是**刚度阵对质量阵**的广义谱，纯刚度阵谱最小值 ~ π²h → 0，
见实测坑）、Hölder 抽查、节点超收敛；② Galerkin = Ritz（一阶/二阶
条件 + 极小性扰动）；③ Céa 常数的谱解释：条件数 ~ n² 增长
（n=200 时 16373），O(h) 插值补偿使收敛率不受影响。

**Prolog**：规则化装配（3 条子句的 `stiffness_contrib`）、2×2
正交性残差手解、广义谱 {6, 18}（粗网格的 π² 近亲）。

### 本章实测坑（数值通道）

1. **3 点 Gauss 中心权重是 8/18 不是 4/18**——[0,1] 区间映射把
   Legendre 的 (8/9, 5/9, 5/9) 变成 (8/18, 5/18, 5/18)。写错时载荷
   系统性偏低，节点超收敛消失（实测 nodal diff 从 1e-10 涨到 0.22），
   且 Galerkin 残差仍 ~ 0（解的是"错误方程"）——残差检查抓不住
   装配错，对真解的误差检查才能。
2. **帽基方向**：单元 e 的左顶点用 1−t、右顶点用 t（局部坐标），
   写反等于把载荷搬到隔壁节点。
3. **误差测量点**：节点处误差恒零（超收敛）、单元中点是导数的
   超收敛点（割线斜率以 O(h²) 逼近中点真导数）——H¹ 误差必须用
   每单元 2 点 Gauss 全域积分，在节点或中点单点采样会量出"假零"
   或"假四阶"。
4. **离散 Poincaré 是广义谱**：‖u′‖²/‖u‖² 的离散化是 cᵀKc/cᵀMc
   （刚度/质量），纯 K 的谱最小值 ~ π²h 会随加密归零——把
   "λmin(K) ≥ π²"写进断言必炸（Python 实验 1 的第一版教训）。

## 73.6 回望与前瞻

书 6.4 的三步证明是变分法的最小完整样本：Poincaré 提供内积、Hölder
提供连续性、Riesz 提供表示。48 章的 Lax-Milgram 把第三步换成
非对称形式（对流项开门）、58 章（Friedrichs-Rellich）把谱聚 0 与
紧性接入、本教程 26 章（Brouwer/Schauder）提供另一条不动点路线。
工科篇到此把书第 6 章全部机器化：71 章的空间、72 章的估计、本章的
解——三件套合龙。
