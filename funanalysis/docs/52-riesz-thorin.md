# 52 · Riesz-Thorin 插值与 Hilbert 变换

> 两个端点的好性质，中间自动继承——而且范数是对数凸的。
> Thorin 的证明把算子藏进一个解析族，让三线定理替你干活。
> ——Lax 第 16.2–16.3 节（意译）

本章覆盖 Lax 第 16.2 节（Marcel Riesz 凸性定理 = Riesz-Thorin 插值，
含 Hadamard 三线定理与 Thorin 的完整证明）与第 16.3 节的三个应用：
Hausdorff-Young 不等式、Hilbert 变换的 Lᵖ 有界性（M. Riesz 的
"astonishing proof"）、Laplace 变换的 L² 理论与 Hilbert-Hankel
算子范数恰为 π。

## 52.1 Hadamard 三线定理

**定理（三线）**。φ(ζ) 在带域 0 ≤ Re ζ ≤ 1 上有界解析，
N(a) = sup_n |φ(a + in)|。则

```
N(a) ≤ N(0)^{1−a}·N(1)^a。
```

**证明**。取 c = log N(0)/N(1)。函数 φ(ζ)e^{cζ} 在两条边界线
|·| ≤ N(0)（Re ζ = 0 时验证），带域上最大模原理给出内部估计，
展开即得。∎

这是"对数凸性"的原型：log N(a) 是凸函数。

## 52.2 Riesz-Thorin 凸性定理

**定理（M. Riesz / Thorin，Lax 第 16 章定理 4）**。M 把 (T, n) 上
的可测函数映到 (S, m) 上的可测函数，且关于**两对**指标有界：

```
M : L^{p₀}(T) → L^{q₀}(S)    范数 M(p₀, q₀)
M : L^{p₁}(T) → L^{q₁}(S)    范数 M(p₁, q₁)
```

则对 0 ≤ a ≤ 1，以

```
1/p(a) = (1−a)/p₀ + a/p₁，    1/q(a) = (1−a)/q₀ + a/q₁
```

定义的中间指标对，M : L^{p(a)} → L^{q(a)} 有界，且范数**对数凸**：

```
M(p(a), q(a)) ≤ M(p₀,q₀)^{1−a}·M(p₁,q₁)^a。
```

**证明（Thorin）**。核心是三件事的无缝拼接：

**第一，把范数对偶化**。由 Hölder 的取等情形（Lax 第 5 章定理 5），
‖g‖_q = sup{ |(g,h)| : ‖h‖_{q'} = 1 }（q′ 为共轭指标），于是

```
M(p,q) = sup{ |(Mf, h)| : ‖f‖_p = 1, ‖h‖_{q′} = 1 }。
```

**第二，构造解析族**。把单位向量写成 f = |f|e^{iφ}、h = |h|e^{iψ}，
对带域内的 ζ 定义

```
f(ζ) = |f|^{p(a)/p(ζ)}·e^{iφ}，    h(ζ) = |h|^{q′(a)/q′(ζ)}·e^{iψ}
```

（1/p(ζ) 是 ζ 的线性函数，所以幂次是解析的）。令

```
Φ(ζ) = (M f(ζ), h(ζ)) = ∫ M f(ζ)·h(ζ) dm
```

Φ 在带域上解析，且 Φ(a) = (Mf, h)。

**第三，边界估计 + 三线定理**。在边界 Re ζ = 0 上（ζ = in），
幂指数 p(a)/p(in) = p(a)/p₀ + 纯虚部，直接计算给

```
‖f(in)‖_{p₀} = ‖f‖_{p(a)}^{p(a)/p₀} = 1（单位化传递），
```

同理 ‖h(in)‖_{q₀′} = 1。于是 ‖Mf(in)‖_{q₀} ≤ M(p₀,q₀)，Hölder 给

```
|Φ(in)| ≤ M(p₀, q₀)    （对一切 n），
```

即 N(0) ≤ M(p₀,q₀)；同理 N(1) ≤ M(p₁,q₁)。三线定理收尾：

```
|(Mf, h)| = |Φ(a)| ≤ N(a) ≤ M(p₀,q₀)^{1−a}·M(p₁,q₁)^a。
```

对 f、h 取上确界即得。∎

**评注**：证明的魔法在于 f(ζ) 的幂次构造——它在 Re ζ = 0 处恰好
"退化"为 p₀-范数单位元、在 Re ζ = 1 处退化为 p₁-单位元，而在
ζ = a 处回到原来的 f。解析性把这三个要求同时满足。

## 52.3 Hausdorff-Young 不等式

Fourier 变换 (Ff)(s) = (2π)^{−1/2}∫f(t)e^{ist}dt 是 L¹ → L^∞
（范数 (2π)^{−1/2}）和 L² → L²（Plancherel，范数 1）有界的。两个
端点 + Riesz-Thorin：

**定理（Hausdorff-Young，Lax 第 16 章定理 6）**。对 1 ≤ p ≤ 2，
F : L^p(ℝ) → L^{p′}(ℝ) 有界，且

```
‖Ff‖_{p′} ≤ ‖F‖^{(2−p)/p}·‖f‖_p，  ‖F‖ = 1（规范化后）。
```

注意方向只能 1 ≤ p ≤ 2：插值沿 (p₀,q₀) = (2,2)、(p₁,q₁) = (1,∞)
连线，中间点是 p ∈ (1,2)、q = p′ ≥ 2。

## 52.4 Hilbert 变换

**定义**。h ∈ C¹(ℝ)、衰减 O(t⁻²)。Cauchy 积分

```
f(ζ) = (1/πi)·PV∫ h(t)/(t−ζ) dt
```

在上半平面解析，边界值把实部还给 h，虚部由

```
(Hh)(ξ) = (1/π)·PV∫ h(t)/(t−ξ) dt
```

给出——**Hilbert 变换**：解析函数边值的实部与虚部的换算器。

**定理 7（L² 等距）**。H 是 L²(ℝ) → L²(ℝ) 的等距。

**证明**。f² 在上半平面解析，Cauchy 定理给 ∮f²dζ = 0；取半圆盘
边界（ε → 0，R → ∞，大圆弧由衰减估计消失），得

```
∫ (h + iHh)² dξ = 0。
```

取实部：∫(h² − (Hh)²)dξ = 0，即 ‖Hh‖₂ = ‖h‖₂。∎

**习题（Lax Ex.1）**：H² = −I（对 −if 的实虚关系做同样论证）。

**定理 8（Lᵖ 有界，1 < p < ∞）**。证明的 p = 4 情形值得逐字看：
对 f⁴ 用 Cauchy 定理，取实部得

```
∫(h⁴ − 6h²k² + k⁴) = 0，
```

用初等不等式 6h²k² ≤ 18h⁴·(1/6·…) 的 Lax 版本 ab ≤ ca²/2 + b²/2c
（取 a = h², b = k², c = 6）：6h²k² ≤ 18h⁴·(1/18·6²/2)… 直接代入
得 k⁴ ≤ C·h⁴ 积分——L⁴ 有界，‖H‖₄ ≤ 3^{1/2} 量级。偶数 p 同法；
**偶数 p 的结果 + Riesz-Thorin 凸性 ⟹ 一切 2 ≤ p < ∞**。对 p < 2
用转置：H 的核 K(s,t) = 1/(s−t) 反对称 ⟹ H′ = −H，而 H : L^{p′} →
L^{p′} 有界 ⟹（对偶）H : L^p → L^p 有界。∎（"Theorem 8, and the
astonishing proof above, are due to M. Riesz"——Lax 原注。）

**反例**（Lax Ex.2）：H 在 L^∞ 与 L¹ 上**无界**——取 hₙ 集中在
原点附近尖峰，Hhₙ 在远处 ~ 1/t 尾巴，L^∞ 与 L¹ 范数失控。这与
Fourier 部分和的 Dirichlet 核（51 章）是同一现象：核的绝对质量
发散。

## 52.5 Laplace 变换与 Hilbert-Hankel 算子

**定理 9（Lax 第 16 章定理 9）**。Laplace 变换 (Lf)(s) = ∫₀^∞ f(t)e^{−st}dt
是 L²(ℝ⁺) → L²(ℝ⁺) 的有界算子，**范数恰为 √π**。

**证明**（Schwarz 的乘积拆分技巧）：

```
|g(s)|² ≤ (∫|f|e^{−st/2−t/4}dt)·(∫e^{−st/2+t/−…}…) 
```

关键一步是把 e^{−st} 拆成 (e^{−st/2−t/4})·(e^{−st/2+t/4})，两个
因子各自积分后对称化：变量替换 u = st 给出核 s^{−1/2}t^{−1/2} 型
的对称形式，常数 C = ∫u^{−1/2}e^{−u}du = √π。近极值函数
f = t^{−1/2}（截断在 [a,b]）把比率顶到 √π(1−ε)。∎

**定理 10**。对称有界算子满足 ‖L²‖ = ‖L‖²（次乘性的反向）：
(Lu, Lu) = (u, L²u) ≤ ‖u‖‖L²u‖ 取上确界。∎

**定理 11（Hilbert-Hankel）**。核为 1/(s+t) 的积分算子

```
g(r) = ∫₀^∞ f(t)/(t+r) dt
```

是 L²(ℝ⁺) → L²(ℝ⁺) 的算子，**范数恰为 π**。

由 L² = L∗L（对称核），‖L²‖ = ‖L‖² = π。这个"范数可精确算出"
的算子是检验各种理论的试金石——第 55 章它以 Hankel 矩阵的离散
化身再现。

## 52.6 Julia 数值实验

实验文件 `examples/julia/52_riesz_thorin.jl`。

**实验 1：三线定理与对数凸性**。取 φ(ζ) = Γ(ζ+1)（带域 0.1 ≤
Re ζ ≤ 0.9 上有界），采样 N(a) 验证 N(a) ≤ N(0)^{1−a}N(1)^a
（逐点检查 200 个 a）。

**实验 2：矩阵 Riesz-Thorin**。随机 64×64 矩阵 A 作为 ℓᵖ → ℓ^q
算子：端点 (p₀,q₀) = (2,2)（最大奇异值）与 (p₁,q₁) = (1,∞)
（最大元素）。数值计算中间 p = 3/2 的算子范数（ℓ^p 对偶幂迭代），
断言 ≤ 两端范数的几何插值——定理的有限维化身。

**实验 3：Hilbert 变换三性质**。FFT 实现 H（乘 −i·sign(ω)）：
(a) 去掉 DC 与 Nyquist 特殊频点的随机 f：‖Hf‖₂/‖f‖₂ = 1 − 10⁻¹²
级（等距）；(b) H² = −I（FFT 舍入级）；(c) 高斯函数的 L⁴ 比值
0.842——非极值函数可以 <1，定理给的是上界 √3。

**实验 4：Hilbert-Hankel 范数 = π**。核 1/(s+t) 在对数网格上的
测度加权矩阵 WAW 的最大奇异值：2.945 → 2.996 → 3.029（区间
[10⁻⁶, 10⁴→10⁸] 三档）单调逼近 π，收敛律 ~ 1/√log L——精确常数
的数值验证必须在对数尺度上加密。

## 52.7 Python 数值实验

实验文件 `examples/python/52_riesz_thorin.py`。

**实验 1：Hausdorff-Young 数值**。ℤ/n 上的离散 Fourier：对
p ∈ {1, 1.3, 1.7, 2}，随机与结构化（尖峰/平坦）向量 x 上测
‖x̂‖_{p′}/‖x‖_p 的最坏比值，断言对 p ≤ 2 比值 ≤ 1（离散 Plancherel
归一化下 Hausdorff-Young 常数 1）而 p > 2 立即出现反例。

**实验 2：插值范数表**。同一核矩阵（Gaussian 核 K(i,j) = e^{−(i−j)²σ²}
离散化）在 ℓᵖ→ℓᵖ 意义下的范数随 p ∈ [1, 4] 的对数凸性曲线——
log‖K_p‖ 关于 1/p 的凸函数形态可视化（数值微分二阶差分 ≥ 0）。

**实验 3：Laplace 变换的 √π**。对数网格加权离散 L：最大奇异值
1.677 → 1.725 → 1.745（下截止 10⁻⁴ → 10⁻⁸）单调逼近 √π = 1.7725
——与 Hilbert-Hankel 同样的对数慢收敛（近极值向量 ~ t^{−1/2}，
质量集中在原点附近，任何线性截断都损失它）。

**实验 4：共轭函数对**。解析信号 f(t) = e^{−t²/4}·e^{iω₀t} 的
实部 h 与虚部 k 满足 k = Hh（单边谱 ⟹ Hilbert 关系）——数值验证
Lax (25) 的边值机制。
