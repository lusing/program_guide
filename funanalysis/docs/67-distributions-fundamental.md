## 67.1 𝒮 上的 Fourier 变换与反演

**Schwartz 空间 𝒮ₙ**：速降 C^∞ 函数。半范数族

```
N_{αβ}(f) = sup_x |x^α D^β f(x)|
```

（可数族 ⟹ Fréchet，64 章的度量化公式适用）。

**变换对**（归一化 d mₙ = (2π)^{−n/2}dx）：

```
f̂(t) = ∫ f(x) e^{−i x·t} dmₙ(x)，    f̌(x) = ∫ f(t) e^{i x·t} dmₙ(t)。
```

**定理（Rudin 7.7，反演）**。

1. f ∈ 𝒮 ⟹ **f̌̌ = f**（即变换的逆 = 反变换）；特别地 **𝒮 上的
   Fourier 变换是连续线性双射**，逆连续（开映射定理）。
2. f, g ∈ 𝒮 的 **Parseval**（由 Fubini 的恒等式 (3)）：

```
∫ f ĝ dmₙ = ∫ f̂ g dmₙ。
```

3. f ∈ L¹，f̂ ∈ L¹ ⟹ 反演公式对 f 的连续代表逐点成立。

**证明骨架**：(3) 由 Fubini 于重积分；取 f_λ(x) = f(λx) 型伸缩 +
**逼近恒等** Φ_λ（Gauss 核经 7.6 的计算 (2/π)^{n/2} 归一），(5)
式在 λ → ∞ 时两边夹出反演在 0 处的值；平移传递到一般点。∎

**基本性质表**（7.2，皆经分部积分与变量替换）：

- 微分 ↔ 乘法：**(D^α f)̂ = (i t)^α f̂**、**(x^α f)̂ = (i D)^α f̂**
  ——多项式系数微分方程变成**多项式乘法方程**，这是分布求解
  PDE 的全部杠杆。
- 卷积定理：(f * g)̂ = f̂ ĝ。
- 伸缩：f_s(x) = f(sx) ⟹ f̂_s(t) = s^{−n} f̂(t/s)。

## 67.2 缓增分布的 Fourier 变换

𝒮 的对偶 𝒮′（**缓增分布**）。𝒮 上的双射变换经对偶延拓：

```
⟨û, φ⟩ = ⟨u, φ̂⟩    （u ∈ 𝒮′, φ ∈ 𝒮）。
```

𝒮 → 𝒮 的连续性 ⟹ û ∈ 𝒮′，且变换是 𝒮′ 的双射（7.13）。**例**
（7.12）：

- 缓增函数 f（∃N, |f(x)| ≤ C(1+|x|)^N）⟹ f ∈ 𝒮′（正则分布）；
- **Dirac δ̂ = 常数 1**；**1̂ = (2π)^{n/2}δ**（经反演与 δ 的取样
  性质）；
- 多项式 P 的变换是 P(iD)δ 型的 δ 导数组合。

## 67.3 基本解：Malgrange–Ehrenpreis 定理

**定义（Rudin 8.1）**。E ∈ 𝒟′(ℝⁿ) 是常系数算子 P(D) 的**基本解**，
若

```
P(D)E = δ。
```

**定理（Malgrange–Ehrenpreis，Rudin 8.5）**。每个常系数**非常数**
多项式 P 的算子 P(D) 都有基本解 E ∈ 𝒟′(ℝⁿ)。

**应用链（先看回报）**：E 存在 ⟹ 对紧支 U，

```
u = E * U    满足    P(D)u = P(D)E * U = δ * U = U     (3)
```

——**P(D)u = U 的一般存在定理**；解在 E * (齐次解) 意义下分类；
E ∈ C^∞ ⟹ u ∈ C^∞（光滑性沿卷积传递）。E 不可能紧支（否则 Ê
整函数且 P·Ê = 1，矛盾）——但 Ê = 1/P 作为**缓增广义函数**时，
其逆变换直接给缓增基本解（习题 5–9 的路线：P(D) 的"缓增可除性"）。

**证明（全文；两步：环面估计 + Hahn-Banach）**

**引理（Rudin 8.3，环面积分估计）**。P 是 n 变量非常数多项式，
r > 0。则存在 A < ∞ 使对一切 φ ∈ 𝒟(ℝⁿ)：

```
|φ̂(0)| ≤ A r^{−N} ‖P(D)φ‖_1 · ∫_{Tⁿ} |P̂ ... | ... 
```

确切机制（OCR 原文的公式 (2)(3)）：以 τ_w（w ∈ Tⁿ 环面）平移
的 **Weierstrass 预备式的几何形态**——对每个 w，t ↦ P(t + r w)
在"好点"处的下界通过环面平均兑现：

```
∫_{Tⁿ} 1/|P(t + r w)| dmₙ(w) ≤ A r^{−N}    （关于 t 一致）     (2)
```

证明用 **Plancherel + Schwarz**：‖(I−Δ)^s φ̂‖₂ 的加权控制
（(6)(7)：(1+|t|²)^s |φ(t+r w)|² 的 L² 积分对 w 平均有界），
其中 s 充分大把多项式的倒数吸收进权重。∎

**定理收尾**：定义 Y = P(D)𝒟（值域子空间）。φ = P(D)ψ 时

```
|ψ(0)| = |φ̂(0) 反演| ≤ A r^{−N} ‖φ‖_1                    (12)
```

——φ ↦ ψ(0) 是 Y 上关于 𝒟 拓扑连续的线性泛函（(13)）。
**Hahn-Banach 延拓**为 u ∈ 𝒟′（(10)：u(P(D)ψ) = ψ(0)）。换元
ψ ↦ ψ̌ 并用 P(−D) 的对称性：

```
⟨P(D)u, ψ⟩ = ⟨u, P(−D)ψ⟩ = ψ̌(0) = ψ(0)·(2π)^{n/2}·（归一配平）= ⟨δ, ψ⟩
```

⟹ **P(D)u = c·δ**，归一化给 E = u/c。∎

**评注**：证明的杠杆是"**值域上的泛函连续 ⟹ 延拓**"——开映射/
闭图像定理的另一副面孔。与 48 章 Lax-Milgram、66 章闭图像
一脉：**泛函分析的三大定理都是"在正确的拓扑下值域足够大"**。

## 67.4 椭圆正则性（概览）

**定义（Rudin 8.7）**。L = Σ_{|α|≤N} f_α D^α 的**主部**是 |α| = N
的部分；**特征多项式** p(x, y) = Σ_{|α|=N} f_α(x) y^α。L **椭圆**
：p(x, y) ≠ 0 对一切 y ≠ 0（在每点 x）。

Laplace 算子主部 −(y₁²+…+yₙ²) 椭圆；∂²/∂x∂y 主部 −y₁y₂ 非椭圆
（y = (1,0) 零）。

**Sobolev 空间 H^s（Rudin 8.8）**：缓增分布 u 的 Fourier 侧范数

```
‖u‖_s² = ∫ |û|² (1 + |y|²)^s dmₙ(y)
```

——u ∈ H^s ⟺ û ∈ L²(μ_s)。H⁰ = L²；s 增大 = 更多可微性（每
个导数换 s − 1 的权重）。

**定理（Rudin 8.12，椭圆正则性）**。L 椭圆（阶 N）、u ∈ 𝒟′(Ω)、
Lu ∈ H^s_loc ⟹ u ∈ H^{s+N}_loc。特别地 **Lu ∈ C^∞ ⟹ u ∈ C^∞**
（Weyl 引理的一般化：光滑性沿椭圆算子上传 N 阶）。

机制：Fourier 侧 P(i y) û(y) = f̂(y)，椭圆性给 |P(i y)| ≥ c|y|^N
（大 y）⟹ û 的权重 (1+|y|²)^{s+N} 被 f̂ 的 s 权重控制——**符号的
下界就是正则性的上传率**。26 章的 Weyl 引理（分布调和 ⟹ 调和）
是 N = 2、f = 0 的特例。

## 67.5 Julia 数值实验

实验文件 `examples/julia/67_distributions_fundamental.jl`。

**实验 1：𝒮 变换的机制表**。Gauss 核 g 的 f̂ = Gauss（自对偶）；
逐条验证 (D^α f)̂ = (it)^α f̂（f = Hermite 型函数，一阶与二阶导
的变换与乘 it、−t² 的对照，FFT 实现，误差 O(h²)）；(x f)̂ =
i D f̂（乘 x ↔ 求导的对称对）；卷积定理 (f*g)̂ = f̂ ĝ。

**实验 2：δ 的变换与 δ 的导数**。δ̂ = 1（离散：δ 脉冲的 DFT =
常数向量）；P(D)δ 的变换 = P(it)（数值：脉冲的一阶差分的 DFT
= 1 − e^{−iθ} 型）；多项式 × δ 导数 ↔ 频域乘法（Laplacian 的离
散 δ 响应 = 特征值表 4sin²(θ/2)）。

**实验 3：基本解的数值动物园**。(a) Laplace 2D：E = −(1/2π)log|x|
（数值验证 ΔE = δ：对偶格点上的 5 点差分作用 = 单位脉冲）；(b)
热算子 ∂t − Δ：E = Gauss 核（t > 0），数值验证卷积解 E * f 满足
方程；(c) 波算子 1D：E = ½H(t−|x|)（d'Alembert），数值验证
E * δ = E 与传播。三例对应 P̂(ξ) = |ξ|²、iτ+|ξ|²、τ²−|ξ|² 的
不同零点结构（全实/无实/光锥）。

**实验 4：卷积解的存在性回报**。P(D) = 1 − Δ（Helmholtz 平移），
随机紧支 f：u = E * f 数值实现（E = Bessel 位势核的截断），验证
残差 ‖(1−Δ)u − f‖/‖f‖ < 1e-3——Malgrange-Ehrenpreis 的"免费
存在定理"实测。

## 67.6 Python 数值实验

实验文件 `examples/python/67_distributions_fundamental.py`。

**实验 1：缓增性判据**。(1+|x|²)^{−s} 型缓增函数族的 Fourier
变换侧形态：s = 1 的变换是指数衰减核 e^{−|t|} 型（Bessel 势），
s = 2 更光滑——多项式增长 ⟹ 频域分布性（δ 导数）的对照。

**实验 2：Malgrange 引理的环面平均数值面**。固定 t = 0，数值
积分 ∫_{T¹} 1/|P(rw)| dw 对 P(z) = 1 + z₁²（r = 1, 2, 4）：
平均有界且 ~ r^{−N} 型衰减（P 在环面上的倒数可平均——引理 8.3
的 (2) 式机制）。

**实验 3：椭圆正则性的谱机制**。离散 Laplacian 的特征值
λ_k = 4sin²(πk/n)：椭圆下界 |λ| ≥ c k² 的数值验证；Lu = f 的
解的 Fourier 系数 û_k = f̂_k/λ_k——f 的系数衰减 1 阶 ⟹ u 的
系数多衰减 2 阶（N = 2 上传）：随机 f 的系数谱对照表。

**实验 4：非椭圆的反例**。∂²/∂x∂y 的离散主部（符号 −sin θ₁
sin θ₂ 在轴上为零）：构造 f 使 Lu = f 的解 u 需要更差的正则性
（沿轴的零频率不被控制）——数值上解沿轴方向震荡不衰减。
