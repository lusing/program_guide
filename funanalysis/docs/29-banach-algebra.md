# 29 · Banach 代数：理想与商

> 把"乘法"放进 Banach 空间，谱理论就有了自己的家。

本章覆盖 Conway §VII.1–§VII.2：Banach 代数公理、可逆元群、
理想与商代数、Neumann 级数。谱的详细理论留给第 30 章。

## 29.1 Banach 代数公理

**定义**。复 Banach 空间 A 带乘法，满足
- 双线性、结合律；
- **次乘性**：‖ab‖ ≤ ‖a‖·‖b‖。

（若需要，可等价改赋范使含单位元 1 且 ‖1‖ = 1。）

**例子**。
- B(H)：有界算子，乘法 = 复合（范数 = 算子范数，次乘性即
  ‖ST‖ ≤ ‖S‖‖T‖）；
- C(K)：连续函数，乘法 = 逐点乘（ sup 范数）；
- ℓ¹(ℤ) 卷积代数（第 33 章 Gelfand 理论的主角之一）；
- 矩阵代数 Mₙ(ℂ)。

**为什么次乘性是灵魂**：它让"几何级数"存在——
‖aⁿ‖ ≤ ‖a‖ⁿ，于是 Σ aⁿ 的收敛性被 ‖a‖ < 1 一举控制。

## 29.2 可逆元群与 Neumann 级数

**定理（Neumann 级数）**。‖a‖ < 1 ⟹ 1 - a 可逆，且

  (1-a)⁻¹ = Σₖ₌₀^∞ aᵏ。

**证明**。部分和 Sₙ = Σ₀ⁿ aᵏ 是 Cauchy（几何控制），
(1-a)Sₙ = 1 - aⁿ⁺¹ → 1。∎

**推论**。
- 可逆元群 A⁻¹ 是**开集**：a 可逆、‖b‖ < 1/‖a⁻¹‖ ⟹ a - b 可逆；
- 求逆映射 a ↦ a⁻¹ 连续（甚至解析）；
- ‖a⁻¹‖ ≥ 1/dist(0,σ(a)) 类型的定量控制。

数值化身：归一化到 ‖A‖ = 0.5 的随机矩阵上，
Neumann 级数 Σ Aᵏ 与 inv(I-A) 重合到 10⁻¹⁰ 以下。

**谱半径（Gelfand 公式预告）**：r(a) = lim ‖aⁿ‖^{1/n}
存在且等于 sup{|λ| : λ ∈ σ(a)}。收敛是**从上方单调**的：
‖aⁿ‖^{1/n} ≥ r(a) 恒成立，数值上能亲眼看它滑向 r(a)
（第 30 章实验的主菜）。

## 29.3 理想与商

**定义**。闭子空间 I ⊆ A 是**（双边）理想**，若 aI ⊆ I 且 Ia ⊆ I。

**例子**。
- B(H) 上的紧算子 K(H)：唯一的非平凡闭双边理想（可分 H）；
- C(K) 上 "在闭集 F 外为零的函数" 全体；
- 数学结构：商 A/I 带商范数 ‖a+I‖ = inf_{x∈I} ‖a+x‖ 仍是
  Banach 代数（I 闭是商完备的必要条件）。

**定理**。A Banach 代数，I 闭理想。则 A/I 是 Banach 代数，
商映射 π: A → A/I 连续开映射，且 ker π = I。

**第 27 章的零化子字典**在这里兑现为：对偶 (A/I)* ≅ I⊥
（泛函的商提升），谱的对应 σ_{A/I}(π(a)) ⊆ σ_A(a)
（商只能"丢"谱点，不能"造"谱点——对应 C(K) 限制到闭子集）。

**重要节奏**：Calkin 代数 B(H)/K(H) 是 Fredholm 理论
（第 45 章）的舞台——"模掉紧算子"后可逆性恰好是 Fredholm 性。

## 29.4 无单位元的代数：单位化

没有 1 的 Banach 代数 A 可以嵌入 A ⊕ ℂ（乘法
(a,α)(b,β) = (ab + αb + βa, αβ)），得到**单位化** A₁。
谱理论对无单位元代数的约定：σ(a) := σ_{A₁}(a) ∪ 按需处理。
