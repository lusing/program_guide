# 55 · Toeplitz 算子与 Hankel 算子：绕数指标

> 圆周上一个连续函数 s，决定 H⁺ 上一个算子 T_s = "乘以 s 再投影"。
> 它的 Fredholm 指标是 s 绕原点的圈数的负值。拓扑进入了算子代数。
> ——Lax 第 27.2–27.3 节（意译）

本章覆盖 Lax 第 27.2 节（Toeplitz 算子的指标定理，含紧摄动引理、
绕数同伦引理与 Wiener-Hopf 因子分解的全证明）与第 27.3 节
（Hankel 算子、Nehari 定理）。

## 55.1 H⁺ 与 Toeplitz 算子

L²(S¹) 以 {e^{ikθ}} 为正交基；**H⁺** = 负系数为零的函数（单位圆盘
内解析函数的边值），P₊ 是正交投影。连续符号 s 定义 **Toeplitz
算子**：

```
T_s u = P₊(s·u)，    u ∈ H⁺。
```

Fourier 系数下它是截断卷积 (T_s u)_k = Σ_{j≥0} s_{k−j}uⱼ——常数
对角线的半无穷 **Toeplitz 矩阵**。

**定理 7（指标定理，Lax 第 27 章）**。s 连续、处处非零。则

1. ‖T_s‖ ≤ ‖s‖_∞；
2. T_s 是 Fredholm 算子（有限指标）；
3. **ind T_s = −W(s)**，W(s) 是 s 绕原点的圈数：

```
W(s) = (1/2π)·Δ arg s(θ) = (1/2πi)∮ s′/s dθ。
```

## 55.2 定理的证明（三件套）

**引理 8（紧摄动）**。C = P₊(s·) − s·（即 P₊ 减恒等在乘法上的差）
是紧算子。

**证明**：三角多项式 s_ε 一致逼近 s；C_ε 的值域含于有限维空间
（ annihilates 高频），故紧；‖C − C_ε‖ ≤ ‖s − s_ε‖_∞ → 0，
紧算子的范数极限紧。∎

于是 s 处非零时，**T_{1/s}·T_s = I + 紧**、对称方向同理——T_s 与
T_{1/s} 互为伪逆 ⟹ Fredholm（第 27.1 节 Atkinson-Gohberg 判据）。

**引理 9（绕数同伦分类）**。S¹ 上两个处处非零连续函数可以在此类
中连续变形相连 ⟺ 绕数相等。证明：W = 0 时取单值对数 s = e^{σ}，
沿 t·σ 变形到 1；一般 W = N 时先变形 e^{iNθ}，再乘因子剥离。∎

**标准形的指标（(31)）**。s = e^{iNθ}（N > 0）：T_s = 乘以 z^N，
核为零、值域余维数 N（缺 e⁰,…,e^{N−1}）⟹ ind = −N。N < 0 时
T_s 满射、核维数 |N| ⟹ ind = −N ✓。一般 s 同伦到 e^{iNθ}，且
**指标在同伦下不变**（定理 5′：紧摄动的伪逆族）⟹ ind T_s =
−W(s)。∎

## 55.3 定理 10：W = 0 时的可逆性与 Wiener-Hopf 因子分解

**定理 10(iii)**。W(s) = 0 ⟹ T_s 可逆，且逆有显式公式。

**证明**（光滑情形的全套）。W = 0 ⟹ s 有单值对数 σ = log s。把 σ
分裂为解析与反解析部分：

```
σ = σ₊ + σ₋，  σ₊ ∈ H⁺，σ₋ ∈ H⁻。
```

指数化：**s = s₊·s₋**，s±(0) = 1，s₊ 解析非零、s₋ 反解析非零
（闭圆盘上）。解方程 T_s u = f 即 s·u = f + g₋（g₋ ∈ H⁻）。
用 s₋ 除两边：s₊·u = s₋⁻¹f + s₋⁻¹g₋。左边属于 H⁺；右边第二项
属于 H⁻（反解析函数环对乘法封闭）。作用 P₊ 把第二项杀死：

```
s₊·u = P₊(s₋⁻¹·f)      ⟹      u = s₊⁻¹·P₊(s₋⁻¹·f)      (32′)
```

**顺序不能换**（实测教训，见 55.5）：若误写成 s₋⁻¹P₊(s₊⁻¹f)，
得到的向量不在 H⁺ 且残差 O(1)；正确公式给 u ∈ H⁺（负频系数
机器零）且 T_s u = f 严格成立。——公式既是理论也是**实用反演
算法**（Lax 原注）。连续情形用光滑逼近（‖T_{r⁻¹s} − I‖ < 1 ⟹
Neumann 级数收尾）。(i)(ii)：s·e^{−iNθ} 的绕数归零，化为 (iii)。∎

## 55.4 Hankel 算子

**定义**。H_s : H⁺ → H⁻，H_s u = P₋(s·u)。矩阵形式

```
(H_s u)_k = Σ_{j≥0} s_{−(k+j)}uⱼ
```

——**常数反对角线**（sinister diagonals）的 Hankel 矩阵。

- **每个 Hankel 算子是紧的**（Lax 习题 2：与 Toeplitz 的截断结构
  对偶，有限秩逼近）；
- **Nehari 定理**：‖H_s‖ = inf{‖s − q‖_∞ : q 解析}——Hankel 范数
  恰是"到解析函数的距离"（Lax (36) 给 ≤ 方向，等号是 Nehari 的
  深刻定理）。

Hankel 算子把第 52 章的 Hilbert-Hankel 积分算子（核 1/(s+t)）
离散化——那个范数恰为 π 的算子，正是本节框架在半个平移群上的
化身。

## 55.5 Julia 数值实验

实验文件 `examples/julia/55_toeplitz_hankel.jl`。

**实验 1：绕数的两种算法**。(28) 的辐角积分（FFT 频域：W =
(1/2πi)·⟨ŝ′, 1/s⟩ 型）与格点辐角累加，对 W = −2..3 的六个符号
（e^{iNθ}·(2 + cos θ) 型）双算法一致。

**实验 2：截断 Toeplitz 矩阵的指标指纹**。n×n 截断 T_n(s)：
W(s) = N > 0 的符号给**恰 N 个接近零的奇异值**（截断把无穷维的
"值域余维数"编码为最小奇异值塌陷）+ 一个方向上的伪零空间；
W = 0 的符号（正实部族 2 + cos θ + 0.5 sin θ）最小奇异值有正下界
（定理 10(iii) 的可逆性）。对照 W < 0：塌陷移到另一侧。

**实验 3：Wiener-Hopf 反演 (32′)**。W = 0 符号 s = e^{cos θ}：
σ = cosθ 分裂 σ₊ = e^{iθ}/2、σ₋ = e^{−iθ}/2，数值实现
u = s₊⁻¹·P₊(s₋⁻¹f)：u 的负频系数严格为零（u ∈ H⁺ 的机器验证），
对照直接解截断方程 T_n(s)u = f，相对差 **4×10⁻¹⁶**——显式反演
公式逐位可用。（实现过程中曾把两个因子的顺序写反：u 跑出 H⁺、
残差 3.7%——顺序是本公式的灵魂。）

**实验 4：Hankel 紧性与 Nehari 上界**。截断 Hankel 矩阵
(h_{jk} = s_{j+k+1}) 的奇异值谱随 n 增长的塌陷（紧性）；‖H_s‖ ≤
‖s − s 的解析部分‖_∞ 数值验证（q 取 s 的非负频率部分）。

## 55.6 Python 数值实验

实验文件 `examples/python/55_toeplitz_hankel.py`。

**实验 1：指标 = −绕数 的数值全表**。对 8 个符号（含纯绕数、
正实部族、含零符号的反例）输出 W(s) 与截断矩阵 T_n(s) 的
"数值指标"（阈值化的奇异值塌陷计数，ker 侧 vs coker 侧），
断言 ind = −W 对非零符号成立；零符号（s 触 0）奇异值塌陷无定值
——Fredholm 性失效的数值形态。

**实验 2：不连续符号**。符号带跳变（θ ∈ [0,π) 取 2、[π,2π) 取
1，绕数 0）：截断矩阵最小奇异值仍有正下界（_piecewise 常量绕零
符号仍可逆）；跳变不破坏 Fredholm 性，只破坏 Nehari 等号的温和
情形——指标理论的鲁棒性。

**实验 3：Hilbert-Hankel 常数再现**。对数网格 1/(x+y) Hankel 矩阵
的奇异值衰减谱与第 52 章 σ_max → π 的衔接（同一算子的 Hankel
矩阵视角）。

## 55.8 习题

1. **（纸笔）**验证 (T_s u)_k = Σs_{k−j}uⱼ 的卷积形式与 Toeplitz
   矩阵的常数对角线结构。
2. **（纸笔）**计算 s(θ) = 2 + cos θ + i·sin θ 的绕数（提示：
   写成 2 + e^{iθ}，圆心 2 半径 1 的圆不含原点）。
3. **（纸笔）**证明 N < 0 时 T_{e^{iNθ}} 的核 = span{1, e^{iθ}, …,
   e^{i(|N|−1)θ}}。
4. **（纸笔，Lax 习题 2）**证明 Hankel 算子紧（有限秩逼近：
   截断 Fourier 系数）。
5. **（机器）**实验 2 中构造 W = 2 的符号但含"窄颈"（min|s| 很
   小）：观察塌陷计数仍 = 2 但第二个奇异值也很小——指标稳定而
   条件数恶化。
6. **（数值）**矩阵符号 S(θ) ∈ ℂ^{2×2}：特征值绕数不一致时
   （一个 +1 一个 −1）截断块 Toeplitz 的指标 = 取和——数值验证。
