# 53 · Wiener Tauberian 定理

> 卷积代数 L¹ 的乘法泛函只有 Fourier 取值——这一条把"平移张成"
> 变成了"Fourier 变换无零点"。Gelfand 理论最漂亮的一击。
> ——Lax 第 19.6 节（意译）

本章覆盖 Lax 第 19.6 节：卷积代数的单位化、乘法线性泛函的完全
分类（Lax 引理 8–9、定理 10 的全文证明）、**Wiener Tauberian
定理**（定理 11 与引理 12 的全文证明——含 e − h + f*f^c 可逆性
的著名构造）、Tauberian 应用（定理 13），以及 Corona 定理注记。

## 53.1 无单位代数的单位化

L¹(ℝ) 在卷积下没有单位元。形式地添加一个：C = {λe + k : λ ∈ ℂ,
k ∈ L¹}，乘法按分配律 (λe+M)(μe+N) = λμe + λN + μM + MN，
范数 ‖λe + M‖ = |λ| + ‖M‖₁。L¹ 本身是 C 的一个极大理想。

**引理 8（次乘性）**。‖f*g‖₁ ≤ ‖f‖₁‖g‖₁。

**证明**（离散化逼近的原型）：对连续紧支的 f、g，卷积是 Riemann
和 Σf(s−jΔ)g(jΔ)Δ 的 L¹ 极限，而平移不改变 L¹ 范数，故该和的
范数 ≤ ‖f‖₁·Σ|g(jΔ)|Δ → ‖f‖₁‖g‖₁。一般 f、g 用连续紧支函数
逼近。同法给出更一般的 (31)：**任何平移不变范数都满足
‖f*g‖ ≤ ‖f‖·‖g‖**——这个推广在第 51 章的 Toeplitz 理论里重现。∎

## 53.2 乘法线性泛函 = Fourier 取值

**定理（Lax 第 19 章定理 10）**。卷积代数 L¹ 的每个非零乘法线性
泛函 ρ 都形如

```
ρ(g) = ĝ(ξ) = ∫g(t)e^{iξt}dt     对某个实 ξ；
```

反之每个这样的 ρ 都是乘法泛函（Fourier 变换把卷积变成乘积）。

**证明**（全文，四步，是"函数方程杀解析"的范本）。

**第一步：连续性骨架**。取 f 使 ρ(f) = 1。记 f_t(s) = f(s−t)
（平移）。**引理 9**：t ↦ f_t 连续（L¹ 范数意义）——先对连续
紧支函数用一致连续性，再用稠密性传递。于是

```
x(t) := ρ(f_t)
```

是 t 的**连续有界**函数。

**第二步：指数函数方程**。恒等式 f_{t+r} * f = f_t * f_r（换元
验证）作用 ρ，乘法性给

```
x(t+r) = x(t)·x(r)。
```

连续 + 有界 + 指数方程 ⟹ **x(t) = e^{iξt}**（经典结果；ξ 实——
有界性排除了实指数）。

**第三步：从 f 传到一切 g**。卷积又是 Riemann 和的极限：
f*g = lim Σf_{jΔ}·g(jΔ)Δ。ρ 线性连续，故

```
ρ(f*g) = lim Σρ(f_{jΔ})g(jΔ)Δ = lim Σe^{iξjΔ}g(jΔ)Δ = ĝ(ξ)。
```

而 ρ(f*g) = ρ(f)ρ(g) = ρ(g)。∎

**评注**：结论 = **L¹ 卷积代数的极大理想空间是 ℝ**（每个 ξ 给出
极大理想 {g : ĝ(ξ) = 0}），Gelfand 拓扑下同胚于 ℝ——第 33 章
Gelfand 理论的一般机制在此具体化。

## 53.3 Wiener 定理

**定理（Wiener，Lax 第 19 章定理 11）**。f ∈ L¹ 的 Fourier 变换
ᶠ 处处非零，则 f 的平移的线性组合在 L¹ 中稠密：任何 L¹ 函数
可用 f 的平移的有限线性组合按 ‖·‖₁ 逼近。

**必要性**立即：ᶠ(ξ₀) = 0 ⟹ 任何平移组合及其 L¹ 极限在 ξ₀ 处
Fourier 变换为零，张不成 L¹。

**证明**（充分性，经引理 12）。f*g 是 f 的平移组合的 L¹ 极限
（引理 8 证明中的 Riemann 和），所以要证 {f*g : g ∈ L¹} 稠密。

**引理 12**。设 ᶠ 处非零，m ∈ L¹ 且 m̂ 紧支。则 m = f*g 对某个
g ∈ L¹。

**证明**（Wiener 的构造，值得逐行看）：

1. 取紧区间 I ⊇ supp m̂。构造 h ∈ L¹ 使 ĥ **实值**、在 I 上 = 1、
   在 m̂ 支集外……（(44)：ĥ = 1 on I，且 ĥ 处处）。
2. 定义 f 的**共轭** f^c(s) = conj(f(−s))，则 f̂^c = conj(ᶠ)。
   于是 **f * f^c 的 Fourier 变换 = |ᶠ|² > 0 处处**。
3. 在单位化代数 C 中考察元素 **e − h + f * f^c**。它在乘法泛函下：
   - 单位泛函 ρ₀(λe+k) = λ 给 ρ₀ = 1（非零）；
   - ρ_ξ 给 1 − ĥ(ξ) + |ᶠ(ξ)|²，由 ᶠ ≠ 0 与 (44) 处处**正**。

   不属于任何乘法泛函的零空间 ⟹ **在 C 中可逆**（Gelfand：可逆
   ⟺ 不含于任何极大理想）。设其逆为 d。
4. 乘等式 (e − h + f*f^c)*d = e 以 m：

   ```
   (e − h)*d*m + f*(f^c*d*m) = m。
   ```

   而 (e − h)*m = 0：其 Fourier 变换是 (1−ĥ)·m̂，两因子支集不相交
   （ĥ = 1 于 supp m̂）。于是 **m = f*g，g = f^c*d*m**。∎

紧支 m̂ 的函数在 L¹ 稠密（习题 3），定理得证。∎

这个证明是**Gelfand 理论的第一个重大胜利**（1941）：Wiener 1932
的原始证明是冗长的实分析。代数化的思路：把"张成"翻译成"理想"，
把"稠密"翻译成"不含于真理想"，再用极大理想空间分类一笔勾销。

## 53.4 Tauberian 应用与 Corona

**定理（Lax 第 19 章定理 13）**。n 有界、ᶠ ≠ 0 处处、∫f = 1。
若 (f*n)(s) → a（s → ∞），则 n 在均值意义下趋于 a：

```
lim_{s→∞} ∫_s^{s+d} n(u)du = a·d    对每个 d。
```

证明思路：(50) 蕴含对 f 的每个平移卷积也趋于 a；由 Wiener 定理
任何 L¹ 函数可用平移逼近，均值条件逐层传递。∎

**Corona 定理注记**（Lax 定理 7/7′）：若 f₁,…,f_m 在闭单位圆盘
解析且 Σ|fⱼ(z)| ≥ δ > 0 处处，则存在 gⱼ 使 Σgⱼfⱼ = 1。这是
"H¹ 的极大理想空间"版的 Wiener 定理，深层得多——Carleson 证明
（复分析），Wolff 1979 给出 PDE 证明。第 62 章 Hardy 空间再见。

## 53.5 Julia 数值实验

实验文件 `examples/julia/53_wiener_tauberian.jl`。

**实验 1：平移张成的两态**。f = Gaussian（ᶠ > 0 处处）：目标
g = 鼓包×振荡，以 {f(·−tⱼ)} 等距平移族最小二乘逼近，误差
0.285 → 10⁻⁴ 级；对照 f = Gaussian 的一阶导数（均值为零 ⟹
ᶠ(0) = 0）：误差停在 0.37——均值分量结构性不可及。**实验设计的
教训**：窗口必须远大于平移范围（窗口截断会给"零均值"基函数泄漏
小均值，破坏障碍的严格性），目标也要集中在平移可达区内。

**实验 2：乘法泛函验证**。随机 f、g：数值验证 (f*g)^(ξ) = ᶠ(ξ)ĝ(ξ)
（FFT 卷积），并验证 ρ_ξ(f) = ᶠ(ξ) 满足乘法性——定理 10 的机器
影子。

**实验 3：Tauberian 平均先行**。n(s) = a + sin(s)/√(1+s)（有界、
尾部仍振荡 ±0.06）；f = 归一化 Gaussian：(f*n) 尾部均值偏离 a
仅 10⁻⁵ 级——**平均先于逐点收敛**，定理 13 的数值内容。（注意
假设的方向：定理设 (f*n) → a，这里由 Riemann-Lebesgue 型振荡
平均保证。）

## 53.6 Python 数值实验

实验文件 `examples/python/53_wiener_tauberian.py`。

**实验 1：逼近失败的最优性**。均值零的 f：对目标 g = 常数 1 的
平移最小二乘误差随 N 增加不减（结构性下界 1 = ‖g‖，因每个基元
均值 0）；换 ᶠ 无零点的 f 后误差指数下降。两态对比输出。

**实验 2：圆周版本（离散 Wiener）**。ℤ/n 上：f 的离散 Fourier
变换无零点 ⟹ circulant 矩阵（f 的循环平移为列）可逆 ⟹ 平移张成
全空间（解线性方程的误差 ~ 机器精度）；f̂ 有零点 ⟹ 矩阵奇异
（最小奇异值 = min|f̂| = 0）。有限群上 Wiener 定理变成初等线性
代数——这正是它代数本质的展示。

**实验 3：引理 12 的机制**。取 ᶠ = Gaussian（无零点）与 m̂ 紧支的
m：数值求 g = ifft(m̂/ᶠ)，验证 f*g = m（卷积定理反演）——引理 12
构造在 Fourier 域就是除法，可逆性条件 = ᶠ 无零点。

## 53.8 注记：为什么这一章住在 Banach 代数里

Wiener 定理的叙述（平移张成）一个字不提代数，但证明的每一步都
是 Gelfand 理论：**张成 ⟺ 理想**（f 的平移生成的闭子空间 = f 生
成的闭理想），**稠密 ⟺ 不含于任何极大理想**，而极大理想空间由
定理 10 完全算出（ℝ = 频率轴）。把这三步走完，定理就"自己证明
了自己"。

对比第 50 章：张成判据在那里由 Hahn-Banach 分离驱动（泛函的刚性），
这里由理想论驱动（代数的结构）。同一个"张成"问题在两套语言里
各有自然的解法——本教程特意两章并置，展示泛函分析的两种基本
冲动力。

Lax 的书在此章前后（19.5 节）还处理了解析函数代数 C(Δ̄)、多圆盘、
开圆盘三类域上的 Gelfand 应用——其中开圆盘情形连接到内函数理论
（第 62 章 Beurling 的舞台），本卷在 62 章从 Hardy 空间一侧进入
同一片领地。
