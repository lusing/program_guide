# 35 · 正元、理想与 GNS 构造

> 正元是 C* 代数的"序结构"，GNS 构造把代数变成希尔伯特空间上的算子。

本章覆盖 Conway §VIII.3–§VIII.5：正元锥、正泛函、
表示论、**GNS 构造**与 Gelfand-Naimark 一般版。

## 35.1 正元

**定义**。a ∈ A 自伴。若 a = b*b（某 b），称 a **正**，记 a ≥ 0。

**定理（谱刻画）**。a 自伴时：

  **a ≥ 0 ⟺ σ(a) ⊆ [0, ∞)**。

（⟸ 方向用连续泛函演算取平方根：
σ(a) ⊆ [0,∞) ⟹ f(t)=√t ∈ C(σ(a)) ⟹ a = f(a)² = f(a)*f(a)。）

**正元锥 A₊**：
- 闭凸锥（a,b ≥ 0, t ≥ 0 ⟹ a+b, ta ≥ 0）；
- **A₊ ∩ (-A₊) = {0}** ⟹ 自伴元上诱导**偏序**：
  a ≤ b ⟺ b - a ≥ 0；
- 每个 a 有唯一分解 a = a₊ - a₋（a₊, a₋ ≥ 0，a₊a₋ = 0）
  ——"绝对值" |a| = (a²)^{1/2} 顺带诞生。

数值化身：随机 B'B 的特征值全正；正矩阵的谱方法平方根
S = V√ΛV* 满足 S² = A 到 10⁻¹² 且 S 仍正（唯一性的数值面）。

## 35.2 平方根与模

**定理**。a ≥ 0 ⟹ 存在**唯一** b ≥ 0 使 b² = a（记 √a）。

证明：连续泛函演算给出存在；唯一性用
σ 逼近 + 交换 C* 代数中的多项式稠密性。∎

由此得到 C* 代数的"模结构"：|a| = √(a*a)，
以及极分解的存在性通道（B(H) 上 T = U|T|，第 38 章）。

## 35.3 正泛函与态

**定义**。φ: A → ℂ 线性。若 φ(a*a) ≥ 0 ∀a，称 φ **正**；
若还满足 ‖φ‖ = 1（等价 φ(1) = 1），称**态**（state）。

**事实**。
- 正泛函自动连续，且 |φ(b*a)|² ≤ φ(b*b)φ(a*a)
  （**Cauchy-Schwarz 不等式**——内积的雏形！）；
- 态的凸紧集记 S(A)，纯态 = 极值点。

Cauchy-Schwarz 是关键伏笔：φ(b*a) 长得就像内积
⟨b, a⟩。GNS 构造就是把这句话当真。

## 35.4 GNS 构造

**定理（Gelfand-Naimark-Segal）**。φ 是 A 的正泛函。
则存在 Hilbert 空间 H_φ、表示 π_φ: A → B(H_φ)
与向量 ξ_φ ∈ H_φ，使

  **φ(a) = ⟨π_φ(a) ξ_φ, ξ_φ⟩**。

**构造**（证明即构造）：
1. 在 A 上定义半内积 ⟨b, a⟩ := φ(b*a)（正性 ⟹ 半正定）；
2. 模掉零向量空间 N = {a : φ(a*a) = 0}，完备化得 H_φ；
3. π_φ(a)(b + N) := ab + N（左乘作用，
   C* 恒等式保证 ‖π_φ(a)‖ ≤ ‖a‖ 有界）；
4. ξ_φ = 1 + N，直接验证。∎

**直和技巧**：把**全部**态的 GNS 表示直和
π = ⊕_φ π_φ，得到**忠实**表示
（a ≠ 0 ⟹ 存在态 φ 使 φ(a*a) > 0 ⟹ π(a) ≠ 0）。

**Gelfand-Naimark 一般版**：任何 C* 代数同构于
某 B(H) 的闭 *-子代数。∎

这就是"C* 代数 = 算子代数"的严格含义：
公理（第 34 章）完备到只有一个模型族。
非交换几何的全部野心建立在这一点上。

## 35.5 理想与商（C* 版）

- 闭双边理想 I：自动 *-封闭（第 34 章），
  且 I = ∩{ker π : π 满射表示}（理想 = 表示论的核）；
- **纯态与理想的对偶**：左核理论把
  "极大理想空间"（交换情形，第 33 章）推广为
  "不可约表示空间"（非交换谱空间）；
- 商 A/I 的谱对应：σ_{A/I}(a+I) = σ(a) \ 
  （被 I 吃掉的谱点）。

（正算子：自伴 + ⟨Tx,x⟩ ≥ 0）。
