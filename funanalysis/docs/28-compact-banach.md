# 28 · Banach 空间上的紧算子

> 紧算子是"无穷维世界里的有限秩影子"：单位球被压成准紧集。

本章覆盖 Conway §VI.3–§VI.5：Banach 空间上紧算子的基本理论、
Schauder 定理（T 紧 ⟺ T* 紧）、紧算子的不变子空间（Lomonosov 定理）、
弱紧算子一览。

## 28.1 紧算子

**定义**。T: X → Y 有界线性。若 T 把 X 的闭单位球映成
**准紧**（precompact，全有界）集，则称 T **紧**。

**等价刻画**：任意有界序列 (xₙ) 的像 (Txₙ) 有收敛子列。

**例子**。
- 有限秩算子紧；
- 核为连续函数的积分算子 (Kf)(x) = ∫ k(x,y) f(y) dy 紧
  （Arzelà–Ascoli）；
- ℓ² 上对角算子 diag(λₙ) 紧 ⟺ λₙ → 0；
- 恒等算子在无穷维空间上**不**紧（Riesz 引理）。

**代数性质**：紧算子构成 B(X,Y) 的闭线性子空间
（范数极限下封闭）与 B(X) 的**双边理想**：
紧 ∘ 有界 与 有界 ∘ 紧 都紧。

**数值化身**：紧 = 有限秩一致逼近。Hilbert 矩阵
（核 1/(x+y) 的积分算子截断）的奇异值衰减到机器零以下，
截断到 k 项的误差恰为 σ_{k+1}（Eckart–Young）——
这就是"紧算子的谱截断"在数值线性代数里的日常形态。

## 28.2 Schauder 定理

**定理（Schauder）**。T: X → Y 紧 ⟺ T*: Y* → X* 紧。

**证明骨架**。⟸ 方向：设 T* 紧，要证 T 紧。取 (xₙ) 有界，
要抽 (Txₙ) 收敛子列。对角线论证：T*(ball Y*) 准紧 ⟹
函数族 {x ↦ f(Tx) : ‖f‖≤1} 等度连续且逐点有界，Arzelà–Ascoli
给出在 ball Y* 上一致收敛的子列，而 ‖Txₙ - Txₘ‖ =
sup_{‖f‖≤1} |f(Txₙ - Txₘ)|（Hahn-Banach 达范），得 Cauchy 子列。∎

## 28.3 谱的 Riesz 理论（预告）

紧算子的谱结构在第 32 章完整展开，骨架在此：

**定理（Riesz–Schauder）**。T ∈ B(X) 紧，X 无穷维。则
- σ(T) \ {0} 中每点都是**特征值**，特征空间**有限维**；
- σ(T) 是至多可数集，唯一可能的聚点是 **0**；
- 0 ∈ σ(T)。

本章数值实验用三件事把它"摸到手上"：
diag(1/k) 截断的谱值 1, 1/2, 1/3, … 填充逼近 0；
三角阵的谱 = 对角元（严格下三角扰动不改谱）；
Volterra 型算子谱半径随离散加细收缩到 0（拟幂零）。

## 28.4 不变子空间：Lomonosov 定理

**定义**。M ⊆ X 闭子空间，T(M) ⊆ M，称 M 为 T 的**不变子空间**。

**定理（Lomonosov 1973）**。T ∈ B(X) 与某非零紧算子交换，
且 T 没有公共特征向量，则存在非平凡闭子空间同时不变于
T 与该紧算子。

**证明骨架（Schauder 不动点 + Fekete 引理的组合）**：
取紧算子 K 的向量 x₀ 使 ‖Kx₀‖>… 构造值域含于小球连续映射，
Schauder 不动点（第 26 章）给出不动向量，其张成的空间即为所求。∎

这是"不变子空间问题"最强的正面结果：**紧算子必有非平凡
不变子空间**（Aronszajn–Smith）。一般的"每个算子是否都有
不变子空间"在 Hilbert 空间上仍是公开问题（Enflo 1987 的
反例只在 Banach 空间上成立）。

## 28.5 弱紧算子

**定义**。T 把闭单位球映成**弱紧**集，称 T 弱紧。

对照第 23 章：自反空间的闭单位球弱紧，故
X 自反 ⟹ X 上恒等算子弱紧。谱线索：
- 紧 ⟹ 弱紧（范数收敛 ⟹ 弱收敛）；
- Dunford–Pettis：弱紧算子把弱收敛序列映成范数收敛序列。
