# 38 · 星循环算子、应用与 B(H) 上的拓扑

> B(H) 不止一种收敛：范数太强，SOT/WOT 才是算子代数的家常拓扑。

本章覆盖 Conway §IX.3–§IX.6：星循环向量的谱定理细化、
谱定理的应用选讲、B(H) 上三拓扑（范数/SOT/WOT）的比较。

## 38.1 星循环向量

**定义**。N 正规。x ∈ H 称 **N 的星循环向量**，若
{f(N)x : f ∈ C(σ(N))} 在 H 中稠密。
N 称**星循环算子**，若存在星循环向量。

**定理**。N 星循环 ⟺ N 酉等价于 L²(μ) 上的
乘法算子 M_z（单一测度！不需要直和拼接）。

对照第 37 章证明骨架：星循环情形不需要 Zorn 引理，
直接一个测度搞定——谱定理的"最小模型"。
**重数理论**（第 40 章）回答"一般正规算子需要几个
循环子空间"，即谱定理的直和有几个块。

单侧移位 S 不是正规的，但 S*S 循环结构清晰
（S*S = I - 投影到 e₁），是练习星循环的最佳非常规样本。

## 38.2 谱定理应用选讲

**（a）自伴算子的函数演算落地**：
T 自伴 ⟹ e^{itT} 定义良好且是酉群（Stone 定理的种子，
第 43 章：t ↦ e^{itT} 是强连续酉群，生成元 T）。

**（b）正算子**：T ≥ 0 ⟺ T = S*S（第 35 章），
⟨Tx, x⟩ ≥ 0 ⟺ σ(T) ⊆ [0,∞)——三条线在此汇合。

**（c）算子不等式的函数**：
A ≤ B 不保证 A² ≤ B²（序不与乘法相容！），
但 f 增 + 谱条件时 f(A) ≤ f(B) 对 commute 情形成立。
谱定理把"算子不等式"翻译成"函数不等式"逐点验证。

**（d）极分解**：T = U|T|，
U 是 ran|T| → ranT 的部分等距（第 35 章平方根的兑现）。

## 38.3 B(H) 上的三拓扑

**定义**。对网 (Tᵢ) ⊂ B(H)：
- **范数收敛**：‖Tᵢ - T‖ → 0；
- **强算子拓扑 SOT**：‖Tᵢx - Tx‖ → 0 ∀x（逐点）；
- **弱算子拓扑 WOT**：⟨Tᵢx, y⟩ → ⟨Tx, y⟩ ∀x,y。

**严格层级**：范数 ⟹ SOT ⟹ WOT，均不可逆：
- **移位幂 Sⁿ**：WOT → 0（⟨Sⁿx, y⟩ = 尾部内积 → 0）
  但 SOT 不 → 0（‖Sⁿx‖ = ‖x‖ 恒定）——
  单侧移位是"保范但弱消失"的完美样本；
- **秩一投影 Pₙ = eₙeₙ***：SOT → 0（对 ℓ² 中每个 x，
  ‖Pₙx‖ = |xₙ| → 0）但 ‖Pₙ‖ = 1 恒定。

数值化身：指数衰减向量的移位序列，
‖Sᵏx‖ 一动不动而 ⟨Sᵏx, y⟩ 指数式衰减——
两种收敛的分裂肉眼可见。

## 38.4 拓扑比较的定理

**定理**。
- SOT 与 WOT 在 B(H) 的**凸集**上一致
  （闭包相同——Hahn-Banach 分离的推论）；
- 范数拓扑的闭球在 SOT 下**不闭**（单位球 SOT 闭但
  边界行为不同）；B(H) 的范数闭子代数可以 SOT 稠密
  （这正是 von Neumann 代数的定义性现象，第 39 章）；
- **乘法的连续性分层**：乘法 (S,T) ↦ ST 在范数拓扑
  联合连续；SOT 下分别连续（固定一个变另一个）但
  **不联合连续**（反例：S*ᵏ Sᵏ⁺¹ —— 各自 SOT 收敛，
  乘积 I 不收敛到 0）；
- **伴随不 SOT 连续**：Sᵏ → 0 (SOT) 但 S*ᵏ 不 → 0
  （‖S*ᵏ e₁‖ = 1）。WOT 下伴随连续。

这些 pathology 不是杂音，而是 von Neumann 代数
（第 39 章）选 SOT 作"正确拓扑"的原因：
极限要保 * 且保乘积的类，需要闭包与交换子打交道。

## 38.7 习题

1. **（纸笔）** 证明 ⟨Sⁿx, y⟩ → 0 对 ℓ² 的 x, y
   （Cauchy-Schwarz + 尾部范数）。
2. **（纸笔）** 证明 SOT 与 WOT 在凸集上闭包一致。
3. **（数值）** 构造 Tₙ = Uⁿ（酉群），验证 WOT 不收敛
   （取 x = y = Σeₖ/k 的内积振荡）。
4. **（纸笔）** 证明乘法在 SOT 下不联合连续
   （用 S*ᵏ 与 Sᵏ⁺¹ 的反例补全细节）。
