# 58 · Friedrichs 扩张与 Rellich 扰动定理

> 半有界的对称算子永远有自伴扩张——Friedrichs 的构造用内积完备化

> 的机器。——Lax 第 33.3–33.5 节（意译）

## 58.1 半有界性与 L-内积

**定义**。稠定对称算子 L **半有界**（下有界），若

```
c‖u‖² ≤ (u, Lu)    对一切 u ∈ D。
```

（加常数归一 c = 1。）在 D 上定义新内积

```
(u, v)_L = (v, Lu)，
```

对称性给半双线性、半有界性给正性；L-范数控制原范数（‖u‖ ≤ ‖u‖_L）。
**完备化** D 得 H_L；因 L-Cauchy 列也是 H-Cauchy 列，有自然映射
H_L → H。

**引理（嵌入单射）**。(uₙ) L-Cauchy → u_L，若在 H 中极限 u = 0，
则 (u_L, v)_L = lim(uₙ, Lv) = 0 对一切 v ∈ D，稠密性给 u_L = 0。∎

于是 H_L ⊂ H（D ⊆ H_L），u_L 由 u 唯一决定。

## 58.2 Friedrichs 扩张的构造

三步（Lax 原文）：

1. **泛函**：取 g ∈ H，在 H_L 上定义 ℊ(v) = (v, g)。由 ‖v‖ ≤ ‖v‖_L
   （(14′)）：|ℊ(v)| ≤ ‖v‖_L‖g‖——**有界泛函**。
2. **Riesz 表示**：存在唯一 w ∈ H_L 使 ℊ(v) = (v, w)_L（(13′)）。
   记 DF = 所有这样的 w；g ↦ w 线性，定义 **L_F w = g**（(15)）。
3. **扩张性**：g = Lu（u ∈ D）时 ℊ(v) = (v, Lu) = (v, u)_L ⟹
   w = u 且 L_F u = Lu——**L_F ⊇ L**。∎

**定理 4（L_F 自伴）**。

- **对称**：(v, w)_L = (v, L_F w)（(16)），v、w 都限制在 DF 上交换
  位置比较，两个半双线性给对称性；
- **自伴**：g ∈ H 任意 ⟹ L_F: DF → H 是双射。记逆 M。M 对称
  （逆的对称性，Lax 习题 5）且**处处定义** ⟹ Hellinger-Toeplitz
  （57 章！）给 M 有界 ⟹ 非实 z 属于 M 的预解集 ⟹ 恒等式
  (z⁻¹I − M⁻¹) = M⁻¹(M − zI)z⁻¹ 给 z⁻¹ ∈ res(M⁻¹ = L_F) ⟹
  L_F 有非实预解点（一实一虚两点即可，第 31 章定理 2）⟹ 自伴。∎

注意证明链的精妙：**Hellinger-Toeplitz（"处处定义的对称算子有界"）
在这里正面出场**——它禁掉了无界的处处对称算子，却正好保证了
L_F 的逆有界。

## 58.3 边界条件自动出现（例 4/5）

**例 4**。L = −d²/dx² + q 于 C₀^∞(0,1)：(u, Lu) = ∫(u′² + qu²) ≥
(min q)‖u‖² ⟹ 半有界。

**命题**。H_L 中每个函数连续到端点且**端点为零**。

**证明**：(18)：|u(b) − u(a)| ≤ √|b−a|·‖u‖_L（Schwarz 于
∫u′²）⟹ L-Cauchy 列一致收敛 ⟹ 极限连续；C₀^∞ 函数端点为零
保持到极限。∎

于是 **L_F 的定义域自动满足 Dirichlet 边界条件**——扩张过程本身
选定了边界条件！这正是第一卷 42 章"DD 扩张"的机制解释：42 章
数值看到的三套谱中，DD 一套就是 −d²/dx² 的 Friedrichs 扩张。
例 5（二维 −Δ on C₀^∞(G)）：Friedrichs 域的函数沿边界法向平均
趋于零（Ex 8），同样自动 Dirichlet。

## 58.4 Rellich 扰动定理

**定理 5（Rellich/Kato 小性）**。A 自伴，T 对称、D(T) ⊇ D(A)，
且存在 a 与 **b < 1** 使

```
‖Tu‖² ≤ a²‖u‖² + b²‖Au‖²    对一切 u ∈ D(A)。       (19)
```

则 A + T（域 D(A)）自伴。

**证明**（两段）：

1. **闭性**：平方根估计 (19′) ‖Tu‖ ≤ a‖u‖ + b‖Au‖，三角不等式给
   ‖Au‖ ≤ (1−b)⁻¹(‖(A+T)u‖ + a‖u‖)——A+T 的闭包的向量落入
   A 的域 ⟹ A+T 闭（A 闭）。
2. **预解点**：证 ±ic ∈ res(A+T)（c > a）。值域闭（已证）＋
   正交补论证：若 v ⊥ ran(A+T+ic)，则对一切 u，
   ((A+T+ic)u, v) = 0 (20)；A 自伴给 w：v = (A+ic)w，代回
   展开出 ((A−ic)... )‖w‖² 型正项和 = 0 ⟹ w = 0 ⟹ v = 0 ⟹
   值域稠密 ⟹ 全空间。∎

**Schrödinger 应用（例 6/7）**。B = −d²/dx²（基本不等式链
(21)–(23)：u 的 sup 与 L² 范数对 u′ 的插值 + 分部积分 +
ε-Young），T = 乘以 q：

- q ∈ L²(ℝ)：(24) ‖Tu‖² ≤ (ε‖Bu‖² 项 + Q‖u‖²)，ε 取小 ⟹ (19)；
- q 有界（|q| ≤ p < 1 内部）+ L² 外部（例 7，断点在 0 的情形）：
  (25)–(28) 的两段估计同样落入 (19)。

结论：**−d²/dx² + q 对 L² 位势自伴**——数学物理的基石定理之一。

## 58.5 Hamburger 矩问题：谱定理的应用

**定理 6（Hamburger）**。实序列 (aₙ) 是 Hankel 正定（二次型
(30) 对一切有限选择为正）⟺ 存在正测度 m（支撑无穷）使
aₙ = ∫tⁿdm。

**证明**（算子论，Lax 33.5）：

1. 有限序列空间 D 上以内积 (x, y) = Σa_{n+k}ξₙηₖ（(31)）——
   正定性正是假设；
2. **右移算子** R（(32)）在此内积下**对称**（(34)：求和指标平移）；
   (e, Rⁿe) = aₙ（(33)）；
3. 实 Hilbert 空间的对称算子有自伴扩张（第 33 章定理 3 推论：
   复化后亏指数相等）；
4. 取谱分解 E：**aₙ = (e, Rⁿe) = ∫tⁿd(E(t)e, e)**——测度
   dm = d(Ee, e) 即所求。∎

这是"谱定理当机器用"的模范：矩问题（第一卷 44 章数值做过
Hankel 矩阵半正定判据）在算子论里变成三行。44 章的 PSD 判据
= 本章的 (30′)：∫(Σξₙtⁿ)²dm ≥ 0。

## 58.6 Julia 数值实验

实验文件 `examples/julia/58_friedrichs_rellich.jl`。

**实验 1：Friedrichs = Green 正定逆**。L = −d²/dx² + q（q ≥ 1）
离散：刚度矩阵 K 对称正定；验证 (K + qM)⁻¹ 的核是 min 型
（正性、对称、边界行衰减）——定理 4 的"L_F 双射且逆有界"的
数值化身（逆核 = Green 函数全正）。

**实验 2：Rellich 条件的数值检查**。位势 V(x) = c/x²（截断在
网格尺度）：数值测 ‖Vu‖/‖Bu‖（B = 差分 −d²/dx² 的离散）随
c 增大逼近临界；断言 c ≤ 1/8（离散安全区）时比值 < 0.9，
并检查 A+V 的离散谱保持实对称性（对称矩阵 ⟹ 自动成立——
连续情形的 Kato 临界 c = 1/4 在离散中表现为条件数的先兆）。

**实验 3：矩问题的移位算子**。取测度 m = 对数正态（矩 aₙ = e^{n²/2}）
的前 12 个矩：构造 Hankel 内积下的移位矩阵（H·R = S_H），验证
(34) 对称性（HRS = (HRS)ᵀ 数值），且 e 的谱测度经移位的特征
分解恢复矩：Σλᵏ|v₁ᵢ|² ≈ aₖ（k ≤ 6 误差 < 5%）——定理 6 的
数值路线图。

## 58.7 Python 数值实验

实验文件 `examples/python/58_friedrichs_rellich.py`。

**实验 1：边界条件自动出现**。半有界 L 的 L-内积离散
（(u,v)_L = Σu′v′ + quv 的矩阵 A_L）：u ∈ 域 ⟺ u = A_L⁻¹g
（g ∈ L²）——数值验证解在边界节点值为 ~0（首末分量 < 1e-12
级）**无需外加约束**：Friedrichs 域的 Dirichlet 性质是构造的
副产品，不是边条输入。

**实验 2：扰动稳定性**。A = −d²/dx² 离散 + V = c·随机有界位势
（‖V‖_∞ ≤ p < 1 类）：对 100 个随机 V，A+V 的特征值实性（对称
矩阵自动）；与 c > 阈值时把 V 换成反对称大扰动的对照（谱立
即复化）——Rellich 条件"对称 + 相对小"的每一条都必要。

**实验 3：Hamburger 往返**。高斯测度 N(0,1) 的矩 aₙ = (n−1)!!
(= 0,1,1,3,15,105,…)：Hankel 矩阵 H_{jk} = a_{j+k} 半正定
（Cholesky 成功）且正定；移位算子在 H-内积下的特征值近似
标准正态的分位点（矩匹配）——(31)(32)(33) 的机器实现。
