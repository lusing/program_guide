# 17 · 对偶理论：商、子空间、自反性与 L^p/C_0(X) 对偶

> 知道一个空间的所有连续线性泛函，就"知道"了这个空间。
> ——Hahn-Banach 的对偶视角

本章覆盖 Conway §III.10–III.11 与附录 B/C：对偶空间的结构、自反性、
以及两个最重要的显式对偶计算：(L^p)* = L^q 和 (C_0(X))* = M(X)。

## 17.1 对偶空间的基本关系

**定理（Conway III.10）**。M ≤ X（闭子空间）。
- **(X/M)\*** **等距同构于** M^⊥ = {F ∈ X* : F|M = 0}。
- **M\*** 是 X* 的商：X*/M^⊥。

**证明要点**。商映射 π: X → X/M 的转置 π*: (X/M)* → X* 的像是
M^⊥，且是等距。反过来，限制映射 X* → M* 的核是 M^⊥。∎

## 17.2 自反空间

**定义（Conway III.11）**。J: X → X**，J(x)(F) = F(x)。
X **自反**，若 J 是满射（因此是等距同构）。

**例子**。
- **自反**：ℝⁿ、L^p（1 < p < ∞）、Hilbert 空间。
- **不自反**：L¹、L^∞、C[0,1]、c₀。
- c₀** = ℓ¹，ℓ¹** = ℓ^∞，ℓ^∞** ⊋ ℓ¹（严格包含）。

**命题**。X 自反 ⟹ X* 自反 ⟹ X Banach。X 自反 ⟹ X 可分
⟺ X* 可分。

**James 定理**（深结果，不证）：X 自反 ⟺ 每个 F ∈ X* 在
闭单位球上达到范数。

## 17.3 (L^p)* = L^q（附录 B）

**定理**。1 ≤ p < ∞，1/p + 1/q = 1。则每个 Φ ∈ (L^p)* 都有
唯一表示 Φ(f) = ∫f·g dμ，g ∈ L^q，且 ‖Φ‖ = ‖g‖_q。

**证明思路**。
- **g 的构造**：对 σ-有限测度，取 |g_n| 上升列，令 g = sup g_n。
- **唯一性**：若 ∫f·g = 0 ∀f ∈ L^p，取 f = sign(g)|g|^{q-1}。
- **范数**：Hölder 给 ≤；取 f = sign(g)|g|^{q-1}/‖g‖_q^{q-1} 给 =。∎

**p = ∞ 的反例**：(L^∞)* ⊋ L¹（有"纯电荷"泛函）。

## 17.4 (C_0(X))* = M(X)（附录 C，Riesz 表示定理）

**定理**。X 局部紧 Hausdorff。则每个正线性泛函 Φ: C_c(X) → ℝ
对应唯一的正 Radon 测度 μ，使 Φ(f) = ∫f dμ。

对 C_0(X)（在无穷远趋于零的连续函数），每个有界线性泛函
对应唯一的有限符号 Radon 测度 μ，‖Φ‖ = |μ|(X)（全变差）。

这是**测度论与泛函分析的汇合点**：测度就是对偶空间的元素。
