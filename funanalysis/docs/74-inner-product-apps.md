# 74 · 内积的应用：相关系数、Gram 矩阵与最佳逼近

> 由内积给出，剩下的不可约误差由**规范相关系数**刻画——Schwarz
> 不等式在工程里的名字。——《工科泛函分析基础》4.5 节（意译）

## 74.1 信号相似性：从最小二乘到相关系数

**问题（书 4.5.1）**。两个离散信号 x = (x₁,…,xₙ) 与 y = (y₁,…,yₙ)
（都属于内积空间 ℝⁿ，⟨x,y⟩ = Σxᵢyᵢ）。x 变形后与 y 相似：找尺度
λ 使 x ~ λy，能量误差

```
Q(λ) = ‖x − λy‖²
```

最小。求导置零（dQ/dλ = −2⟨x,y⟩ + 2λ‖y‖² = 0）：

```
λ* = ⟨x, y⟩ / ‖y‖²
```

最小误差与**规范相关系数**：

```
min Q = ‖x‖² − ⟨x,y⟩²/‖y‖² = ‖x‖²(1 − ρ²)，   ρ = ⟨x,y⟩ / (‖x‖·‖y‖)
```

Schwarz 不等式（|⟨x,y⟩| ≤ ‖x‖‖y‖）恰是说 **|ρ| ≤ 1**；ρ = ±1 ⟺
x 与 y 线性相关 ⟺ min Q = 0（完全相似）；ρ = 0 ⟺ 正交 ⟺ min Q =
‖x‖²（y 完全帮不上忙）。工程师的直觉："相关系数衡量相似性"，其
数学实质是"最小二乘不可约误差的能量占比 1 − ρ²"。

**配平方的机器版**。整个计算的核心是恒等式

```
‖x − λy‖² = ‖y‖²·(λ − λ*)² + ‖x‖²(1 − ρ²)
```

——任意 λ 的误差 = 偏离最优尺度的平方（可避免）+ 不可约误差（由
几何决定）。Lean 通道（`Funanalysis/Ch74InnerProductApps.lean`）把它
完整形式化：

```lean
theorem least_squares_square (x y : H) (hy : y ≠ 0) (lam : ℝ) :
    ‖x - lam • y‖ ^ 2
      = ‖y‖ ^ 2 * (lam - ⟪x, y⟫_ℝ / ‖y‖ ^ 2) ^ 2
        + (‖x‖ ^ 2 - ⟪x, y⟫_ℝ ^ 2 / ‖y‖ ^ 2) := by
  have hexp : ‖x - lam • y‖ ^ 2
      = ‖x‖ ^ 2 - 2 * lam * ⟪x, y⟫_ℝ + lam ^ 2 * ‖y‖ ^ 2 := by
    rw [norm_sub_sq_real, real_inner_smul_right, norm_smul]
    simp only [mul_pow, Real.norm_eq_abs, sq_abs]
    ring
  ...
```

证明主干是 mathlib 现成的范数恒等式 `norm_sub_sq_real`（‖x−y‖² =
‖x‖² − 2⟪x,y⟫ + ‖y‖²）加数乘范数展开——数学上的一行"配平方"在
机器里是三个引理的焊接。`least_squares_min` 推论确认最优尺度取到
下界（偏离项为零）。|ρ| ≤ 1 的机器对应是 `abs_real_inner_le_norm`。

**数值通道**。Julia 实验 1（`julia/74_inner_product_apps.jl`）做带噪
检测：5Hz 模板对上有相移 + 30% 噪声的信号，ρ = 0.902、相对误差 =
1 − ρ² 恒等式数值吻合；对照的随机信号 ρ ≈ 0——检测判决就落在内积
上。Python 实验 1 用 500 组随机对逐一验证三条公式（λ* 最优性、
minQ = ‖x‖²(1−ρ²)、|ρ| ≤ 1）。Prolog 通道把相似度做成分类规则
`similarity/3`（perfect / similar / weak / decorrelated 四档），
并复算 λ* = 0.5（x = 0.5y 的精确关系）与 minQ = 0。

## 74.2 最佳逼近与法方程

**问题（书 4.5.2）**。赋范空间 X 中给定向量组 e₁,…,eₙ 与目标 x，
求系数 a₁,…,aₙ 使 ‖x − Σaᵢeᵢ‖ 最小。在内积空间里这就是投影定理
（03 章）：最佳逼近系数由**法方程**（正规方程）给出——正交性条件
⟨x − y₀, eⱼ⟩ = 0 展开即

```
Σᵢ ⟨eᵢ, eⱼ⟩ aᵢ = ⟨x, eⱼ⟩   （j = 1..n）—— Gram 矩阵方程 G a = b
```

**例（书 4.5.3，完整重算）**。在 L²([−π,π]) 中用 M = span{sin x,
cos x} 逼近 f(x) = x。三个积分：⟨sin,sin⟩ = ⟨cos,cos⟩ = π、
⟨sin,cos⟩ = 0（正交！）、⟨x,sin⟩ = 2π（分部积分）、⟨x,cos⟩ = 0
（奇偶性）。法方程解得

```
a₁ = 2π/π = 2，  a₂ = 0     ——   y₀ = 2 sin x
```

距离平方 d² = ‖f‖² − bᵀG⁻¹b = 2π³/3 − 4π。Julia 实验 2 数值复核
全链：Gram 对角 π、载荷 [2π, 0]、解 [2.000, 0.000]、d² = 8.105 与
解析值吻合。"x 的最好正弦近似是 2sin x"——Fourier 级数首项系数
的迷你预演（05-06 章）。

## 74.3 Gram 矩阵：可逆性、正定性与距离公式

**定义（书 4.5.4）**。n 阶方阵 G(α₁,…,αₙ) = (⟨αᵢ, αⱼ]) 称为
**Gram 矩阵**。

**定理（书 4.5.5）**。α₁,…,αₙ 线性无关 ⟺ G 可逆，且此时 G 正定。

证明：aᵀGa = ⟨Σaᵢαᵢ, Σaⱼαⱼ⟩ = ‖Σaᵢαᵢ‖² ≥ 0，取等 ⟺ Σaᵢαᵢ = 0
⟺（无关）a = 0。正定 ⟹ 可逆。∎ 二向量情形的 aᵀGa > 0 就是
**Lagrange 恒等式** ‖x‖²‖y‖² − ⟨x,y⟩² > 0——Schwarz 不等式的
行列式形态。Prolog 通道的 `gram2/3` 计算 D = ‖x‖²‖y‖²−⟨x,y⟩²，
`independent/2` 与 `dependent/2` 按 D 是否为零分档（平行向量 D=0）。

**定理（Gram 行列式距离公式，书 4.5.6）**。E = span{α₁,…,αₙ}，
则

```
d(x, E)² = G(x, α₁, …, αₙ) / G(α₁, …, αₙ)
```

（分子是 x 加进队伍后的 n+1 阶 Gram 行列式。）证明是 Cramer 法则
解法方程后代入 d² = ‖x‖² − bᵀG⁻¹b 的行列式改写。Julia 实验 3 验证：
二维子空间上公式值与 QR 投影残差一致到 10⁻¹⁰；四个 ℝ³ 向量必相关
⟹ 4 阶 Gram 行列式恰 0（无关性判据的机器版）。Python 实验 2 展示
Gram 的**条件数**面：无关随机族 SPD 良态；第四向量取前三之和加
10⁻⁸ 微扰 ⟹ 条件数 10¹⁶——法方程在近相关时病态，正交基（G = I）
是唯一稳的选法（数值线性代数 Prefer QR 的内积理由）。

## 74.4 弱收敛的内外积刻画（书 4.4.5）

**定理（书 4.4.5）**。Hilbert 空间中 xₙ ⇀ x（弱收敛）⟺ 对一切 y，
⟨xₙ, y⟩ → ⟨x, y⟩。且

```
xₙ → x（强） ⟺ xₙ ⇀ x 且 ‖xₙ‖ → ‖x‖
```

充分性的全部机制是一条恒等式：

```
‖xₙ − x‖² = ‖xₙ‖² − 2⟨xₙ, x⟩ + ‖x‖²
```

右端三项在"弱收敛 + 范数收敛"下分别趋于 ‖x‖² − 2⟪x,x⟫ + ‖x‖²
= 0。Lean 通道把它形式化为两层：`norm_sq_expand`（恒等式，由
内积的双线性展开）与 `weak_plus_norm_implies_strong`（三 Tendsto
的加法复合 + 开方连续性）。**弱收敛不保范数**的数值对照（Julia
实验 4）：标准正交列 eₖ 弱收敛于 0（⟨eₖ, y⟩ = y[k] → 0）而 ‖eₖ‖
= 1 恒定；傅里叶列 sₘ = √2 sin(mπx) 同理（内积以 1/(mπ) 衰减）。
恒等式右端"两顶相消"正是 23 章（弱拓扑）与 60 章（平均遍历）里
反复出现的模式——范数必须单独跟踪。

## 74.5 机器通道全览

**Lean**：配平方恒等式 + 最小尺度推论全证（74.1）、Schwarz 锚点、
弱收敛恒等式 + 弱强提升定理（74.4）、L² 内积实例锚点
（`L2.innerProductSpace`）。**Julia**：带噪检测、x ≈ 2sinx 全链、
Gram 距离公式 + 相关性判据、弱收敛对照。**Python**：500 组随机
三公式、Gram 条件数谱系（良态/病态/白化）、多通道相关阵去相关。
**Prolog**：相似度分类规则、λ* 与 minQ、Lagrange 行列式无关性、
正交基对角法方程。

一个跨通道的小结：本章所有公式都是"内积 + 非负性"的化身——
配平方（平方 ≥ 0）、ρ（Schwarz）、Gram（正定行列式）、弱收敛
（恒等式开方）。**Hilbert 空间理论的可计算部分，本质是"算内积、
查非负"**。
