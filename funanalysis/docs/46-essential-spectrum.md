# 46 · 本质谱与谱的精细分析

> 把谱里"无关紧要的离散点"抠掉，剩下的刚性骨架叫本质谱。

本章覆盖 Conway §XI.4–§XI.6：本质谱的多种定义及其等价性、
Weyl 定理（紧摄动不变性）、Toeplitz 算子选讲。

## 46.1 为什么需要本质谱

紧算子 K 摄动 I：谱点可以乱跑，但只能**离散地**乱跑——
聚点结构纹丝不动（第 45 章数值已见：I + tK 的谱锁在 1 附近）。
"摄动不变的那部分谱"值得一个名字。

**本质谱的三种定义**（等价，各有用处）：

| 名称 | 定义 | 直觉 |
|---|---|---|
| **Weyl** | λ ∈ σ_ess ⟺ 存在 Weyl 列 | 有近似特征向量（弱零） |
| **Calkin** | λ ∈ σ_ess ⟺ T - λ 在 B(H)/K(H) 中不可逆 | 模掉紧算子后还在谱里 |
| **重数** | λ ∈ σ_ess ⟺ λ 是谱聚点或无穷重特征值 | 离散有限重点不算 |

**Weyl 列**：单位向量列 (xₙ)，弱→0，‖(T-λ)xₙ‖ → 0。
——把"特征向量"放松到"近似 + 消失"。

**数值化身**（单侧右移 S，σ(S) = 闭圆盘，σ_ess(S) = 圆周）：
相位斜坡 x = (1, λ̄, λ̄², ..., λ̄^{m-1})/√m：
- |λ| = 1：内部项相消，残差 = 边界丢失 = 1/√m → 0
  ——真 Weyl 列（弱零：能量摊平）；
- |λ| < 1：等距性给 ‖(S-λ)x‖ ≥ (1-|λ|)‖x‖ 一致下界
  ——数值 0.866 = √(1-|λ|²) 稳定不动。

## 46.2 Weyl 定理

**定理（Weyl）**。K 紧 ⟹

  **σ_ess(T + K) = σ_ess(T)**。

**证明骨架**：Weyl 刻画下显然——K 把弱零序列映成
范数零序列（紧 ⟹ 完全连续），残差 ‖(T+K-λ)xₙ‖
与 ‖(T-λ)xₙ‖ 同敛。∎

**谱的分层**：
σ(T) = σ_ess(T) ⊔ {离散特征值：有限重、孤立}
——紧摄动只能增删第二层。数值可见：
I + 0.3·Hilbert（30 阶）的特征值大批坍缩到
1 的 10⁻³ 邻域（≥ 20 个），离散点向本质谱缴械。

**应用**：证明谱不等于某集合的万能招——
找一个紧摄动把谱算清楚：
- σ_ess(S) = 圆周（S* S - SS* = rank-one ⟹ 模紧后正规
  且 σ = 圆周）；
- Schrödinger 算子 -Δ + V（V 紧摄动型）：
  σ_ess = [0,∞)（自由算子的谱）+ 离散负特征值。

## 46.3 本质谱的例子目录

| 算子 | σ_ess | 离散层 |
|---|---|---|
| 恒等 I | {1} | ∅ |
| 单侧移位 S | 单位圆周 | 开圆盘（S* 的特征值） |
| 紧算子 K | {0} | 非零特征值（可数聚 0） |
| -Δ + V（短程位势） | [0,∞) | 束缚态 < 0 |
| 对角 diag(λₙ) | λₙ 的聚点集 | 孤立有限重 λₙ |

## 46.4 Fredholm 与本质谱的合流

**定理**。λ ∉ σ_ess(T) ⟺ T - λ 是 **Fredholm** 算子。

于是（第 45 章）：
- ρ_F(T) = ℂ \ σ_ess(T) 上指标恒定义；
- 指标在 ρ_F 的每个连通分量上常数；
- 对正规算子指标恒 0（谱投影给同伦）。

**Toeplitz 算子**（选讲）：T_φ = P M_φ |_{H²}
（Hardy 空间上的压缩乘法）。
**定理（Gohberg-Krein）**：φ 连续无零点 ⟹
T_φ Fredholm 且 index = -wind(φ)（绕数）。
指标理论的几何面在此完全展开：
**分析指标 = 拓扑绕数**——单侧移位是 φ(z)=z 的
特例：index = -1 = 负一绕。
