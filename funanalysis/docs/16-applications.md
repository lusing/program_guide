# 16 · 应用三讲：Banach 极限、Runge 定理、序空间

> 理论的价值在于应用。本章三个应用各走一条不同的路。

本章覆盖 Conway §III.7–§III.9*，展示 Hahn-Banach 定理的三个
不同面向的应用。

## 16.1 Banach 极限（Conway III.7*）

**问题**：ℓ^∞ 上的通常极限只对收敛序列有定义。能否对**所有**
有界序列定义一个"广义极限"LIM，满足：

1. **线性**：LIM(αx + βy) = α·LIM(x) + β·LIM(y)；
2. **正性**：xₙ ≥ 0 ∀n ⟹ LIM(x) ≥ 0；
3. **平移不变**：LIM(x₁,x₂,...) = LIM(x₂,x₃,...)；
4. **范数 ≤ 1**：|LIM(x)| ≤ ‖x‖_∞；
5. **与通常极限一致**：x 收敛 ⟹ LIM(x) = lim xₙ。

**构造（Hahn-Banach 应用）**。定义 p(x) = limsup|xₙ|（次线性）。
在线性子空间 c（收敛序列）上定义 f(x) = lim xₙ。则
f(x) ≤ p(x)。由 Hahn-Banach（次线性形式），f 延拓到 ℓ^∞
全空间，保持 f ≤ p。这个延拓就是 Banach 极限。

**注意**：Banach 极限**不唯一**（Hahn-Banach 延拓不唯一）。

**应用**：遍历论中的时间平均、不变测度的存在性、
经济学中的无穷期贴现。

## 16.2 Runge 定理（Conway III.8*）

**定理**。K ⊂ ℂ 紧集，ℂ∖K 连通。E ⊆ K 有限集，每点 e ∈ E
指定一个"极点" aₑ（或在 e 处允许极点）。则任何在
K∖E 的邻域上全纯的函数 f 可以被**有理函数**一致逼近
（极点只在 E 中）。特别地，ℂ∖K 连通且 E = ∅ 时，
**f 可以被多项式一致逼近**。

**证明思路（泛函分析侧）**。假设 f 不能被逼近。由 Hahn-Banach
的对偶分离（推论 2 + Riesz 表示定理），存在 ℂ∖K 上的
一个测度 μ"垂直"于所有多项式但不对 f 垂直。然后用
Cauchy 积分公式和 ℂ∖K 的连通性导出 μ 也必须对 f 垂直，
矛盾。∎

这是**复分析与泛函分析的交汇**：Hahn-Banach 提供分离工具，
Cauchy 理论提供全纯结构。

## 16.3 序向量空间（Conway III.9*）

**定义**。实向量空间 X + 子集 X₊（**正锥**）：
- x, y ∈ X₊ ⟹ x + y ∈ X₊；
- α ≥ 0, x ∈ X₊ ⟹ αx ∈ X₊；
- x, −x ∈ X₊ ⟹ x = 0。

**序**：x ≤ y ⟺ y − x ∈ X₊。

**正线性泛函**：f(x) ≥ 0 当 x ≥ 0。

**Riesz 空间（格）**：任何两个元素有上确界（格运算）。
Banach 格：完备 + 格运算连续。这是第 26 章的正算子理论的
基础。

## 16.4 数值实验

**Julia**（`16_applications.jl`）：
(1) **Banach 极限的影子**：振荡序列 xₖ = (−1)^k + 1/k 的
Cesàro 均值（Banach 极限在收敛序列上的行为 = 极限；平移不变
性的数值验证——前 k 项丢弃不显著改变 Cesàro 均值）；
(2) **Runge 逼近**：1/z 在不含 0 的圆环上被多项式（Taylor
展开）一致逼近（度 10 误差 < 0.004，度 20 误差 < 10⁻⁵）。

**Python**（`16_applications.py`）：同组实验。
