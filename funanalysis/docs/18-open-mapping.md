# 18 · 开映射、闭图像与补子空间

> 有界性不再需要验证——Banach 空间的完备性替你验证了。

本章覆盖 Conway §III.12–III.13：三大原理之二（开映射 + 闭图像），
以及补子空间理论。

## 18.1 开映射定理

**定理（Conway III.12）**。X, Y Banach 空间，T: X → Y 有界线性
**满射**。则 T 是**开映射**（开集的像是开集）。

**证明核心（Baire 纲）**。
1. X = ⋃ₙ n·B_X，T 满射 ⟹ Y = ⋃ₙ T(n·B_X)。
2. Y 完备 ⟹ Baire ⟹ 某个 cl(T(n·B_X)) 有内点。
3. 对称性 + 凸性 ⟹ cl(T(B_X)) 包含以 0 为中心的球 c·B_Y。
4. 迭代 + 级数论证 ⟹ T(B_X) 包含 c/2·B_Y（真正的开性）。∎

第 4 步是"摄动法"的原型：给定 y，找 xₙ 使 ‖y − Σxₙ‖ 递归减半。
完备性保证 Σxₙ 收敛。

## 18.2 闭图像定理

**定理（Conway III.12）**。X, Y Banach，T: X → Y 线性。
若 T 的**图像** {(x, Tx)} 在 X × Y 中闭，则 T 有界。

**证明**。图像 Γ(T) 是 Banach 空间（X×Y 的闭子空间）。
投影 π₁: Γ(T) → X 是双射有界线性映射。开映射定理 ⟹ π₁⁻¹
有界 ⟹ T = π₂∘π₁⁻¹ 有界。∎

**应用**：闭算子（微分算子！）只需验证"xn → x, Txn → y ⟹ y = Tx"
就自动连续——这比直接验证连续性容易得多。

## 18.3 逆算子定理

**推论**。X, Y Banach，T: X → Y 有界线性双射。
则 T⁻¹ 有界（‖T⁻¹‖ < ∞）。

**应用**：两个范数都完备 + 相互控制 ⟹ 等价。
特别地：Banach 空间上"代数同构 + 连续"自动是同胚。

## 18.4 补子空间

**定义**。M ≤ X 存在 N ≤ X 使 X = M ⊕ N（拓扑直和），
称 M **可补**（complemented）。

**刻画**。M 可补 ⟺ 存在有界投影 P，ran P = M。
P² = P + ‖P‖ < ∞。

**例子**。
- **有限维或余有限维**子空间总可补。
- **Hilbert 空间**中一切闭子空间可补（P_M 正交投影，‖P‖ ≤ 1）。
- **c₀ ⊆ ℓ^∞ 不可补**（Phillips, 1940）——Banach 空间不是所有
  子空间都有投影！
