# 48 · Lax-Milgram 引理与变分法

> Riesz-Frechet 定理说 Hilbert 空间上每个有界线性泛函都是内积；
> Lax-Milgram 说：只要把内积换成**强制的双线性形式**，这件事照样成立。
> 一举打开了椭圆边值问题的大门。——据 Lax 第 6 章定理 6（意译）

本章起进入教程的第二卷：以 Peter D. Lax《Functional Analysis》（Wiley 2002）
为纲的增补篇。第一卷（01–46 章）走 Conway 路线，覆盖了 Hilbert 空间、
Banach 空间、Banach 代数与谱定理的主干；Lax 的书在选择材料上有不同的
侧重——变分法、弱收敛的应用、迹类算子、半群、遍历理论、散射理论——
这些是 Conway 基本不碰而 Lax 深入展开的内容。第二卷逐章提炼这些主题，
编号从 48 续起。

本章覆盖 Lax 第 6.3–6.4 节（Lax-Milgram 引理）与第 7.2 节（Dirichlet
问题的三条 Hilbert 空间路线：Riesz-Frechet、Lax-Milgram、正交分解），
外加第 5.1 节中 Sobolev 空间与 Zaremba 引理的必要部分。

## 48.1 为什么需要不对称的形式

Riesz-Frechet 表示定理（本教程 04 章）说：Hilbert 空间 ℋ 上每个有界
线性泛函 l 都形如 l(x) = ⟨x, y⟩。它是**对称**的表示——泛函通过内积实现。

但微分方程给出的天然形式不是内积。以 Poisson 方程 −Δv = f（带零边值）
为例，两边乘以检验函数 u 并分部积分，得到的是

```
∫ f u dx = ∫ ∇v · ∇u dx  =:  B(v, u)
```

B 是双线性的、有界的，但一般**不对称**（例如方程带上对流项
−Δv + b·∇v = f 时）。问题变成：给定 B 与泛函 l，求 v 使

```
l(u) = B(u, v)      对一切 u
```

Riesz 定理不直接适用。Lax 与 Milgram 在 1954 年指出：只要 B **强制**
（coercive，下文条件 (iii)），表示照样存在唯一。这就是椭圆边值问题
现代理论（弱解、有限元法）的逻辑基石。

## 48.2 引理与证明

**定义（双线性形式的三个条件）**。设 ℋ 是实 Hilbert 空间（复情形取
B 对第二变元共轭线性，证明相同）。B: ℋ×ℋ → ℝ 称为

1. **双线性**：对固定 y 线性于 x，对固定 x 线性于 y；
2. **有界**：存在 c 使 |B(x, y)| ≤ c‖x‖‖y‖；
3. **强制**：存在 b > 0 使 B(y, y) ≥ b‖y‖² 对一切 y。

**定理（Lax-Milgram 引理，Lax 第 6 章定理 6）**。B 满足上述三条件，
则每个有界线性泛函 l 都可唯一表示为

```
l(x) = B(x, y),     y 由 l 唯一确定。
```

**证明**（按 Lax 原文）。

**第一步：把 B 换成算子。** 固定 y，则 x ↦ B(x, y) 是有界线性泛函，
由 Riesz-Frechet 定理存在唯一 z 使

```
B(x, y) = ⟨x, z⟩                    (20)
```

记 z = Ay。由 z 对 y 的唯一性，A 是线性映射；其值域 Ran(A) 是线性子空间。

**第二步：Ran(A) 是闭子空间。** 在 (20) 中取 x = y：

```
B(y, y) = ⟨y, z⟩ = ⟨y, Ay⟩
```

左边用强制性、右边用 Schwarz 不等式，两边除以 ‖y‖（y ≠ 0）得

```
b‖y‖ ≤ ‖Ay‖                          (21)
```

这是关键不等式：A 把范数放大至少 b 倍（下有界）。设 zₙ = Ayₙ 是值域中
收敛于 z 的序列。由 (21)（作用于 yₙ − yₘ）得 b‖yₙ − yₘ‖ ≤ ‖zₙ − zₘ‖，
故 (yₙ) 是 Cauchy 列，收敛于某个 y。由 B 的有界性，B(x, yₙ) → B(x, y)；
由内积的连续性，⟨x, zₙ⟩ → ⟨x, z⟩。在 (20) 中取极限得 B(x, y) = ⟨x, z⟩，
即 z = Ay ∈ Ran(A)。值域闭。

**第三步：Ran(A) = ℋ。** 若不然，由正交分解定理（04 章定理 3），
存在非零 x 与整个 Ran(A) 正交。于是 ⟨x, Ay⟩ = 0 对一切 y，即 B(x, y) = 0
对一切 y；取 y = x 得 B(x, x) = 0，与强制性 b‖x‖² ≤ B(x, x) 矛盾。

**第四步：收尾。** A 满射（第三步）+ 下有界 (21) ⟹ A 可逆。任给有界
泛函 l，由 Riesz-Frechet 定理写成 l(x) = ⟨x, z⟩；取 y = A⁻¹z，则
B(x, y) = ⟨x, Ay⟩ = ⟨x, z⟩ = l(x)。唯一性：若 B(x, y₁) = B(x, y₂) 对
一切 x，取 x = y₁ − y₂ 得 B(y₁−y₂, y₁−y₂) = 0，强制性给出 y₁ = y₂。∎

**评注**。证明的结构值得记住：**(21) 是全局引擎**。"强制性 ⟹ 下有界 ⟹
值域闭"这条链在数值分析里反复出现（它正是"强制矩阵条件数有限"的
无穷维影子）。对比 Riesz-Frechet 定理的证明（零空间余维数 1 的初等
路线，见 04 章），Lax-Milgram 的证明反而是"算子论"的：把形式变成
算子，证算子可逆。

**推论（算子形式）**。定义 A: ℋ → ℋ 如上，则 A 是线性同胚，且

```
‖A⁻¹‖ ≤ 1/b。
```

证：把 (21) 写成 ‖y‖ ≤ b⁻¹‖Ay‖，令 x = Ay 即 ‖A⁻¹x‖ ≤ b⁻¹‖x‖。∎
特别地，若 B 对称，A 是自伴的可逆算子，且 ⟨Ax, x⟩ ≥ b‖x‖²——
"强制 = 自伴 + 一致正"。这就是数值线性代数里**对称正定（SPD）矩阵**
的无穷维版本。

## 48.3 Zaremba 引理：Poincaré 不等式

要把 Lax-Milgram 用到 Dirichlet 问题上，先要有处理"函数本身范数"
的工具：H¹ 型范数只控制导数，函数本身的范数要靠**边界条件**补偿。

**引理（Zaremba，Lax 第 7 章引理 1）**。D 是 ℝⁿ 中有界域，宽度为 d
（即 D 含于某两条距离为 d 的平行超平面之间）。则对一切
f ∈ C₀^∞(D)（光滑、紧支于 D）：

```
‖f‖₀² = ∫ f² dx ≤ d² ∫|∇f|² dx = d² ‖f‖₁²。
```

**证明**（一维写法，n 维同型）。f 在边界上为零，故对 D 内任一点 x，
沿第一个坐标方向积分：

```
f(x) = ∫ f₁(x₁', t) dt
```

其中 x₁' 是其余坐标，积分从边界点跑到 x₁。Schwarz 不等式：

```
f²(x) ≤ d · ∫ f₁² dt
```

对 x 于 D 上积分即得。∎

注意常数 d 是**次优的**：在区间 (0, d) 上，−u″ 的 Dirichlet 特征值
问题给出最优常数 (d/π)²（第一个特征函数 sin(πt/d) 恰好取等）。数值
实验 2 将同时验证两个常数——Lax 的初等证明给 d，谱分析把常数磨到
d/π，但**对变分法的应用而言，任何有限常数都够用**。

**Sobolev 空间 H₀¹ 的定义**（Lax 第 7 章）。C₀^∞(D) 在内积

```
(f, g)₁ = Σⱼ ∫ fⱼ gⱼ dx    （下标 j 指偏导数）
```

下的完备化记作 H₀¹(D)；在内积 (f, g)₀ = ∫fg 下的完备化是 L²(D)。
Zaremba 引理说明 H₀¹ 恒等嵌入 L²，且 H₀¹ 中元素的分布导数仍在 L²
（Lax 第 7 章引理 2：(z, uⱼ)₀ = −(z_{xⱼ}, v)₀）。这正是本教程 22 章
（分布）与 12 章（Sturm-Liouville）用过的框架，此处按 Lax 的方式
从完备化直接重建，不依赖前文。

## 48.4 Dirichlet 问题：第一条路线（Riesz-Frechet）

**问题**。给定 f ∈ L²(D)，求 v 满足 −Δv = f、v 边值为零。

**弱解的存在性**（Lax 第 7.2 节）。定义 l(u) = (u, f)₀。由 Schwarz
与 Zaremba：

```
|l(u)| ≤ ‖f‖₀‖u‖₀ ≤ d‖f‖₀‖u‖₁
```

故 l 是 H₀¹ 上的有界泛函（注意这一步用了 Poincaré：L² 范数被 H¹
范数控制）。由 Riesz-Frechet 定理，存在 v ∈ H₀¹ 使

```
(u, f)₀ = (u, v)₁ = Σⱼ (uⱼ, vⱼ)₀      对一切 u ∈ H₀¹。
```

现在取 u ∈ C₀^∞(D) 并分部积分（分布意义）：

```
(u, v)₁ = −(u, Δv)₀
```

于是 (u, f)₀ = −(u, Δv)₀ 对一切检验函数 u 成立，即**分布意义下**
−Δv = f。这就解出了方程；边界条件的意义由 Lax 第 7 章引理 3 给出：
v 属于 H₀¹ 保证它在平均意义下趋零（边界附近小矩形上 |v| 的平均值
→ 0，证明是对 Zaremba 引理的一步加细）。弱解到手。∎

**对称情形到此为止**；若方程带一阶项（对流、反应项）：

```
−Δv + Σⱼ bⱼ v_{xⱼ} + c v = f
```

相应的形式 B(u, v) = (uⱼ, vⱼ) + (bⱼu_{xⱼ}, v)₀ + (cu, v)₀ 不再对称。
**有界性**：一阶项用 Schwarz 控制，|B(u,v)| ≤ (1 + ‖b‖_∞ d + c)d²‖u‖₁‖v‖₁
（常数不必精确）。**强制性**：由 Schwarz 与 Young 不等式
2|ab| ≤ εa² + ε⁻¹b²，取 ε 足够小，

```
B(u, u) ≥ ‖u‖₁² − ‖b‖_∞‖u‖₀‖∇u‖ − c_−‖u‖₀² ≥ (1 − ε‖b‖_∞ − d²c_−/…)‖u‖₁²
```

当对流项不太大、反应项不太负时 B 强制，**Lax-Milgram 直接给出弱解**。
这是 Lax 第 7.2 节公式 (22)–(24) 的内容。数值实验 4 将在有限维构造
一个"非对称但强制"的刚度矩阵并验证可解性与范数界。

## 48.5 第三条路线：正交分解与 Green 函数

对**齐次**方程 Δu = 0（边值给定），Lax 给出一条不依赖泛函表示的
路线，它美在几何。设边值由 C¹ 函数 f 给出，把问题改写为分解

```
f = u + z，    u 调和，   z ∈ H₀¹。
```

**关键观察**：Green 公式给出

```
(u, z)₁ = ∫ ∇u·∇z = −∫ (Δu) z + ∮ z ∂u/∂n ds = 0
```

（Δu = 0 于内部，z = 0 于边界）。**调和函数空间与 H₀¹ 在 (·,·)₁ 下
正交**。于是分解 f = u + z 就是正交投影：把 H¹ 中的 f 投到闭子空间
V = {调和函数，一阶导平方可和} 上。（(·,·)₁ 严格说只是半正定——
常数函数零范数——按模常数作商后成为内积，细节见 Lax 原文；这不
影响分解的存在唯一性。）

从 z ∈ H₀¹ 到"z 在边界上确实为零"再到"u 是真解"，需要 Weyl 引理
（分布调和 ⟹ 经典调和，本教程 22 章已证）与平均值的调和性论证；
Lax 随后用 Green 函数（基本解 log|p−q| 的正则化）给出解的积分表示
（Garabedian–Schiffer 论证）。第三条路线是 19 世纪位势理论（Dirichlet
原理）的严格化：**解 = 正交投影**。

三条路线总结：

| 路线 | 用的定理 | 方程 | 边值 |
|---|---|---|---|
| 泛函表示 | Riesz-Frechet | −Δv = f | 零边值（弱） |
| 强制形式 | Lax-Milgram | 非对称椭圆 | 零边值（弱） |
| 正交分解 | 投影定理 + Weyl | Δu = 0 | 给定边值（真解） |

## 48.6 Julia 数值实验

实验文件 `examples/julia/48_lax_milgram.jl`，四个实验共用一个输出块。

**实验 1：非对称强制形式的可解性**。取 2×2 矩阵

```
M = [1 0.8; 0 1]
```

B(x, y) = xᵀMy。对称部分 (M+Mᵀ)/2 的最小特征值 b ≈ 0.6 > 0，故
B 强制（xᵀMx = xᵀ((M+Mᵀ)/2)x）。对 200 个随机 f 解 My = f，断言
‖y‖ ≤ ‖f‖/b 逐次成立，且解唯一（M 可逆）。Lax-Milgram 有限维化身
的每个条款都检查到：

```julia
b = minimum(eigvals((M + M') / 2))
for k in 1:200
    f = randn(2); y = M \ f
    @assert norm(y) ≤ norm(f) / b * (1 + 1e-12)
end
```

（断言里留了 1e-12 的浮点余量：‖y‖ ≤ ‖f‖/b 在理论等值点上可能差
一个舍入——这是第一卷 46 章实测过的教训。）

**实验 2：Poincaré 两个常数**。区间 (0, d) 上做 −u″ 的有限差分
（网格 h = d/(m+1)，内点未知数），最小特征值 λ₁ ≈ (π/d)²。断言：

- λ₁ 与 (π/d)² 相对偏差 < 1e-3（差分特征值从下方逼近，见 12 章）；
- 对差分的特征向量 x（离散 L² 范数）：‖x‖₀ ≤ (d/π)‖x′‖₀ 以 1e-3
  容差近似取等（连续谱常数恰在极限取等，离散略偏小）；
- ‖x‖₀ ≤ d‖x′‖₀ 宽裕成立（Zaremba 的初等常数，非最优）。

```julia
ev = eigen(Tridiagonal(-ones(m-1), 2ones(m), -ones(m-1)) ./ h^2)
λ1 = ev.values[1]
```

**实验 3：hat 基有限元的节点超收敛**。在 [0,1] 上解 −u″ = sin(πt)、
u(0)=u(1)=0，解析解 u* = sin(πt)/π²。装配 hat 基刚度矩阵 K =
(1/h)·tridiag(−1,2,−1)，载荷用三点 Gauss 求积。实验展示两个层次的
现象：

- **节点误差 ~ 机器精度**（10⁻¹⁶ 级，加细单调下降）。这不是巧合：
  φᵢ′ 分片常数，对真解分部积分 ∫u*′φᵢ′ = −(u*(t_{i−1}) − 2u*(t_i) +
  u*(t_{i+1}))/h **没有截断误差**——真解的节点值精确满足有限元方程
  K u = F，离散解的节点误差只来自 Gauss 载荷积分（单元误差 O(h⁷)）。
  这是线性元对 −u″ 问题的经典超收敛。
- **全局 L² 误差回到 O(h²)**：单元内部只有线性插值，中点误差
  ≈ (h²/8)|u″|，L² 范数 h 每减半误差约 ×1/4。
- **条件数 κ(K) ~ h⁻²**：强制常数（最小特征值 ≈ π²h）趋于零而最大
  特征值 ≈ 4/h 发散——"良定问题 + 病态离散化"共存的现象（Lax 等价
  定理的伏笔，59 章回到这里）。

**实验 4：非对称 Galerkin 矩阵**。方程 −u″ + u′ + u = f 的 hat 基
Galerkin 矩阵 K = 刚度 + 对流项 C + 反应项 R，其中 C 不对称。断言：
矩阵不对称（‖C − Cᵀ‖ > 0）；对称部分最小特征值 > 0（强制）；解
存在唯一；余量 ‖Ku − f‖/‖f‖ < 1e-12。

**实验 1：二维 Poisson 五点差分 SPD 验证**。64×64 网格，五点差分
矩阵 A（scipy.sparse）。断言：对称（‖A − Aᵀ‖ = 0）、正定

```python
u = spsolve(A, f)
assert norm(u) <= norm(f) / lam1 * (1 + 1e-10)
```

**实验 2：二维 Zaremba**。域取 (0, d)×(0, 1)，d = 2。随机生成若干

**实验 3：两条表示路线的差异**。同一个泛函 l(x) = ⟨x, f⟩：
- Riesz 表示 y_R = f（内积情形 B = (·,·)）；
- Lax-Milgram 表示 y_L 满足 B(x, y_L) = ⟨x, f⟩，取非对称强制 B。

断言 y_R ≠ y_L（不对称时两个表示向量不同——Lax-Milgram 真正推广了
Riesz），且两者给出同一泛函值：⟨x, y_R⟩ = B(x, y_L) 对随机 x 抽查。

**实验 4：离散 Green 函数与正交分解**。A 的逆的列就是离散 Green
函数。断言：(a) G = A⁻¹ 对称正定（离散版"调和 ⊥ H₀¹"的自伴性）；
(b) Green 函数沿对角衰减（取 G 的中列，检查单调性近似成立）；
(c) 离散调和向量（A 的零空间之外：取边界延拓的线性函数 t，其
Laplacian = 0）与紧支向量 z 的离散内积 ⟨∇t, ∇z⟩ = 0（分部求和
逐项验证）——48.5 的正交分解在格点上的化身。

## 48.8 Lean 机器化

文件 `examples/lean/Funanalysis/Ch48LaxMilgram.lean`。mathlib v4.33.1
没有 Lax-Milgram（也无 BanachLimit、迹类、半群——第二卷多处如此，
通道分工原则：Lean 证核心不等式与有限维影子，无穷维主体由数值通道
承载并如实标注）。机器化三步，第一步是引擎不等式 (21)：

```lean
/-- 引擎不等式（Lax (21)）：强制性 ⟹ 下有界 -/
theorem coercive_bound (A : H →L[ℝ] H) {b : ℝ} (hb : 0 < b)
    (hcoe : ∀ x, b * ‖x‖ * ‖x‖ ≤ ⟪A x, x⟫_ℝ) : ∀ x, b * ‖x‖ ≤ ‖A x‖ := by
  intro x
  rcases eq_or_ne x 0 with rfl | hx
  · simp
  · have h1 : b * ‖x‖ * ‖x‖ ≤ ‖A x‖ * ‖x‖ :=
      le_trans (hcoe x) (le_trans (le_abs_self _) (abs_inner_le_norm (A x) x))
    exact (mul_le_mul_iff_of_pos_right (norm_pos_iff.mpr hx)).mp h1
```

实内积下 ⟪Ax,x⟫ ≤ |⟪Ax,x⟫| ≤ ‖Ax‖·‖x‖（`le_abs_self` 接
`abs_inner_le_norm`），两边除以正数 ‖x‖——`mul_le_mul_iff_of_pos_right`
是 iff，要用 `.mp` 取方向。推论一 `coercive_injective`：`A.map_sub`
把单射化为核平凡后反证（b>0 与范数为正矛盾）。推论二在
`EuclideanSpace ℝ (Fin 2)` 上以 `LinearMap.injective_iff_surjective`
收尾——"强制 ⟹ 表示方程 B(x,y)=l(x) 对一切右端可解"的 ℝ² 全文。

## 48.9 Isabelle 机器化

会话 `examples/isabelle/FA48/T48_LaxMilgram.thy`，在 real^2 上重演
同样的两步。`ker_trivial` 完全照 Lax 第二步：M *v x = 0 与 x 点积得
x∙(M*v x) = 0，接强制性 b(x∙x) ≤ 0，反证 x ≠ 0 则 b(x∙x) > 0 矛盾。
主定理 `lax_milgram_real2`：

```isabelle
theorem lax_milgram_real2:
  fixes M :: "real^2^2"
  assumes hb : "0 < b"
      and hcoe: "\<forall>x. b * inner x x \<le> inner x (M *v x)"
  shows "\<forall>(f::real^2). \<exists>!y. M *v y = f"
```

结构：`matrix_vector_mul_linear` 给线性性；核平凡给单射；
`linear_inj_imp_surj`（Vector_Spaces 的有限维定理）给满射；最后对
每个 f 取原像 y 并用差分配律证唯一。两个实测坑值得记录：

- **`∀f. ∃!y. M *v y = f` 里未定型的 f 会以 "Malformed command
  syntax" 的外层语法错误伪装报告**——类型重建无法穿过 ∃! 下的 `*v`
  推断 f，必须写 `∀(f::real^2)`。症状与语法问题一模一样，先查类型
  再查语法。
- `M *v (x − y) = M *v x − M *v y` 用库配方
  `(vector matrix_vector_mult_def sum.distrib algebra_simps)+`——
  注意结尾的 `+`（重复应用），单次不够。
