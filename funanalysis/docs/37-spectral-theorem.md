# 37 · 谱定理

> 三种语言说同一件事：谱测度、连续泛函演算、乘法算子模型。

本章覆盖 Conway §IX.2：正规算子的谱定理——
Hilbert 空间理论的顶点。三种等价表述及其互相翻译。

## 37.1 定理的三种形态

设 N ∈ B(H) 正规（NN* = N*N）。

**形态一（谱积分）**。存在唯一 PVM E，支撑于 σ(N)，使

  **N = ∫_{σ(N)} z dE(z)**。

**形态二（连续泛函演算）**。存在等距 *-同态

  **C(σ(N)) → B(H)，f ↦ f(N) = ∫ f dE**，

把 z ↦ 恒等函数送回 N。谱映射 σ(f(N)) = f(σ(N))。

**形态三（乘法算子）**。存在测度空间 (X, μ)、
有界可测函数 φ 与酉算子 U: H → L²(μ)，使

  **U N U⁻¹ = M_φ**（乘法算子：(M_φ f)(x) = φ(x) f(x)）。

三种形态的**互译**：
一 → 二：f(N) := ∫ f dE；二 → 一：取 f(z) = z；
三 ↔ 一：X = σ(N)（或谱的拷贝并），E(Δ) 对应
"1_{φ⁻¹(Δ)} 的乘法算子"。
凡证明其一，另两个自动成立。

## 37.2 证明骨架（星循环路线，第 38 章展开）

1. **星循环分解**：N 生成的 C*(N) 有循环向量 x 时
  （x 的轨道 {f(N)x} 稠密），构造 φ: C(σ(N)) → ℂ，
   φ(f) = ⟨f(N)x, x⟩——Riesz 表示给出测度 μ，
   f ↦ f(N)x 延拓成 L²(μ) 的酉等价，N 变成 M_z；
2. **Zorn 拼接**：一般情形把 H 分解成可数个循环子空间
   的正交直和，每个上做第 1 步，直和得乘法模型；
3. **唯一性**：由 ∫ z dE = ∫ z dE' 推出
   ∫ f dE = ∫ f dE' 对一切有界 Borel f
   （单调类定理），E = E'。∎

## 37.3 推论雨

谱定理一旦在手，整批定理变成"查表"：

- **自伴** T ⟹ σ(T) ⊆ ℝ（f 实值 ⟹ 乘法算子自伴）；
- **酉** U ⟹ σ(U) ⊆ 𝕋（|φ| ≡ 1）；
- **谱映射**：σ(f(N)) = f(σ(N))；
- **正规 ⟹ ‖N‖ = r(N)**（乘法算子范数 = sup |φ|）；
- **正** N ⟺ σ(N) ⊆ [0,∞) ⟺ N = S*S（第 35 章）；
- **Fuglede 定理**：与 N 交换的算子与 N* 交换
  （在乘法模型里显然）；
- **极分解**：T = U|T|，|T| = √(T*T)（第 35 章平方根）。

有限维化身就是线性代数：
Hermite 矩阵 H = V Λ V*，谱定理三形态分别对应
V Λ V*（积分）、f(H) = V f(Λ) V*（演算）、
坐标变换后变成对角阵（乘法算子）。
数值实验验证：特征分解重构 ‖H - VΛV*‖ < 10⁻¹²、
特征值全实、f(H) 双通道一致。

## 37.4 Borel 泛函演算

连续演算可扩张到**有界 Borel** 函数：
f ↦ ∫ f dE 定义 C(σ(N))^{强闭包} → B(H)。
新增能力：**谱投影** E(Δ) = 1_Δ(N) 对任意 Borel Δ。
连续演算做不到（1_Δ 不连续），这是谱测度存在的理由。

链条：多项式 → 连续 → 有界 Borel →
（无界可测，闭稠定算子，第 41 章）。
每一层扩张都换来自由度：
多项式只有代数、连续有拓扑、Borel 有测度论的全部力量。

## 37.5 谱定理的用途示例

- **算子函数**：√T、e^{tT}、log T（正 T）全部就位；
- **谱集定位**：σ(N) = φ 的本性值域（乘法模型直读）；
- **量子力学**：观测量的统计 = 谱测度
  μ_x(Δ) = ⟨E(Δ)x, x⟩（Born 规则，第 36 章）；
- **矩阵分析**：eigh/eig 的全部定理保证。
