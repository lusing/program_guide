# 11 · 紧自伴算子的对角化

> 这是紧自伴算子的谱定理。利用它，关于紧自伴算子的几乎所有
> 问题都能得到回答。——Conway §II.5（意译）

本章是整个紧算子理论的高潮：**谱定理**（Conway 5.1）——任何紧自伴
算子都有"对角表示" T = Σ αₙPₙ，其中 αₙ 是实特征值、Pₙ 是两两正交
的有限秩投影。这是有限维对称矩阵对角化的完美无穷维推广。

## 11.1 谱定理的陈述

**定理（Conway 5.1）**。T 是紧自伴算子。则 T 的不同非零特征值
至多可数。设 (α₁, α₂, ...) 是不同的非零特征值，Pₙ = 到
ker(T − αₙ) 的投影。则：

- PₙPₘ = PₘPₙ = 0（n ≠ m）：特征空间两两正交；
- 每个 αₙ 是**实数**（自伴性）；
- **T = Σₙ αₙPₙ**（按算子范数收敛；可能只有有限项）。

这就是说：紧自伴算子在对角化后"完全透明"——一切性质
（范数、核、像、逆、方程解）都从特征值读出。

**推论（Conway 5.3）**。
- (a) ker T = ⋂ₙ (ran Pₙ)⊥ = (∨ₙ ran Pₙ)⊥；
- (b) 每个 Pₙ 有限秩（4.13）；
- (c) **‖T‖ = sup|αₙ|** 且 αₙ → 0。

**推论（Conway 5.4）**。存在实数序列 (μₙ) 和 (ker T)⊥ 的标准
正交基 (eₙ)，使 Th = Σ μₙ⟨h,eₙ⟩eₙ。μₙ 可重复
（重复次数 = 特征空间维数）。

**推论（Conway 5.5）**。T 紧自伴且 ker T = {0} ⟹ ℋ 可分。

## 11.2 预备结果

**命题（Conway 5.6）**。A 正规，λ ∈ 𝔽。则 ker(A−λ) = ker(A−λ)*
且 ker(A−λ) 约化 A。

**证明**。A 正规 ⟹ A−λ 正规 ⟹ ‖(A−λ)h‖ = ‖(A−λ)*h‖（第 08 章
2.16）。两核相等。约化性：Ah = λh 时 A*h = λ̄h（核等式），两个方向
都封闭。∎

**命题（Conway 5.7）**。A 正规，λ ≠ μ 是不同特征值。则
ker(A−λ) ⊥ ker(A−μ)。

**证明**。h ∈ ker(A−λ), g ∈ ker(A−μ)。由 5.6，A*g = μ̄g。则
λ⟨h,g⟩ = ⟨λh,g⟩ = ⟨Ah,g⟩ = ⟨h,A*g⟩ = ⟨h,μg⟩ = μ⟨h,g⟩。
(λ−μ)⟨h,g⟩ = 0，λ ≠ μ ⟹ h ⊥ g。∎

**命题（Conway 5.8）**。A = A* 且 λ ∈ σₚ(A)。则 λ ∈ ℝ。

**证明**。Ah = λh ⟹ Ah = A*h = λ̄h（5.6 的核等式）⟹ (λ−λ̄)h = 0
⟹ λ = λ̄。∎

## 11.3 关键引理：±‖T‖ 是特征值

**引理（Conway 5.9）**。T 是紧自伴算子。则 ±‖T‖ 中至少有一个
是 T 的特征值。

**证明**。T ≠ 0 时，由第 08 章 2.13（自伴算子的范数 = 二次型的 sup），
取单位向量 hₙ 使 |⟨Thₙ,hₙ⟩| → ‖T‖。取子列，设 ⟨Thₙ,hₙ⟩ → λ，
|λ| = ‖T‖。则

‖(T−λ)hₙ‖² = ‖Thₙ‖² − 2λ⟨Thₙ,hₙ⟩ + λ² ≤ λ² − 2λ⟨Thₙ,hₙ⟩ + λ² → 0。

（用 ‖Thₙ‖ ≤ ‖T‖ = |λ|。）由 4.14（inf ‖(T−λ)h‖ = 0 ⟹ λ ∈ σₚ），
λ ∈ σₚ(T)。∎

这个引理是谱定理证明的**发动机**：它保证每一步"剥掉一个特征空间"
后，剩余的算子仍有特征值——直到用完所有非零谱。

## 11.4 谱定理的证明

**证明（Conway 5.1）**。归纳构造：

1. 由 5.9，取 α₁ ∈ σₚ(T)，|α₁| = ‖T‖。ℳ₁ = ker(T−α₁)，
   P₁ = 投影。由 5.6，ℳ₁ 约化 T。ℳ₁ᗮ 也约化 T。

2. T₂ = T|_{ℳ₁ᗮ}：紧自伴。由 5.9，取 α₂ ∈ σₚ(T₂)，
   |α₂| = ‖T₂‖ ≤ ‖T‖。ℳ₂ = ker(T−α₂) ⊆ ℳ₁ᗮ。
   由 5.7，α₁ ≠ α₂（不同特征值自动正交）。

3. 归纳：得 (αₙ)，|α₁| ≥ |α₂| ≥ ...，ℳₙ 两两正交。

4. **αₙ → 0**：取 eₙ ∈ ℳₙ 单位向量。T 紧 ⟹ Te_{nₖ} 有收敛子列。
   但 eₙ ⊥ eₘ (n≠m) ⟹ ‖Te_{nₖ} − Te_{nⱼ}‖² = |α_{nₖ}|² + |α_{nⱼ}|²
   ≥ 2·(lim|αₙ|)²。Cauchy ⟹ lim|αₙ| = 0。

5. **余项范数**：T − Σₙ₌₁^N αₙPₙ = T|_{(ℳ₁⊕...⊕ℳ_N)⊥}，其范数
   = |α_{N+1}| → 0。∎

## 11.5 谱定理的应用

### 范数公式
‖T‖ = sup|αₙ|——**范数 = 最大特征值的绝对值**。

### 核与像
ker T = (⊕ₙ ℳₙ)⊥——T 的核是所有特征空间的正交补。
cl(ran T) = ⊕ₙ ℳₙ——像的闭包是特征空间的正交和。

### 方程 Th = f 的可解性（Conway 习题 5.4）
给定 f，存在 h 使 Th = f ⟺ f ⊥ ker T 且
Σ |⟨f,eₙ⟩/μₙ|² < ∞（Picard 条件）。通解 = 特解 + ker T。

### 正则性（Conway 习题 5.5）
λ ∉ {0, μₙ} 时 (λ−T)⁻¹ 存在且有界：
f = λ⁻¹[h + Σₙ (μₙ/(λ−μₙ))⟨h,eₙ⟩eₙ]。
