# 27 · Banach 空间上的算子伴随与 Banach-Stone 定理

> Hilbert 空间上的伴随靠内积；Banach 空间上没有内积，伴随只能"住"在对偶空间里。

本章覆盖 Conway §VI.1–§VI.2：Banach 空间算子的伴随 T*、
零化子运算、值域与核的对偶刻画，以及 **Banach-Stone 定理**
（C(K) 空间的等距同构 ⟺ 紧空间的同胚）。

## 27.1 Banach 伴随的定义

设 T: X → Y 有界线性。定义 **T*: Y* → X***：

  (T* f)(x) = f(T x)，   f ∈ Y*。

**定理（伴随的基本性质）**。
- T* 线性有界，且 **‖T*‖ = ‖T‖**；
- (S∘T)* = T*∘S*（反序）；
- T 可逆 ⟹ T* 可逆且 (T*)⁻¹ = (T⁻¹)*。

**证明（‖T*‖ = ‖T‖）**。
‖T*‖ = sup_{‖f‖≤1} ‖T* f‖ = sup_{‖f‖≤1} sup_{‖x‖≤1} |f(Tx)|
≤ sup_{‖x‖≤1} ‖T x‖·‖f‖… 交换 sup 后由 Hahn-Banach，
对每个 x 取 f 在 Tx 处达范，得反向不等式。∎

**与 Hilbert 伴随的差别**。Hilbert 伴随 T† 把 H 映回 H 自己
（Riesz 定理把 H* 等同为 H）；Banach 伴随 T* 在**对偶空间之间**
作用，且没有共轭线性性（因为对偶空间本身是线性的）。
在 ℓ¹ₙ 上，T 的矩阵是 A，则 T* 在 (ℓ¹ₙ)* = ℓ∞ₙ 上的矩阵是 **A 的转置**——
这就是数值实验验证的恒等式 ‖A‖₁ = ‖Aᵀ‖∞。

## 27.2 零化子：值域与核的对偶字典

**定义**。M ⊆ X 的**零化子** M⊥ = {f ∈ X* : f|_M = 0}；
N ⊆ X* 的零化子 ⊥N = {x ∈ X : f(x)=0 ∀f ∈ N}。

**定理（对偶字典）**。对有界线性 T: X → Y：
- ker T* = (ran T)⊥；
- (ker T*)⊥ 的闭包关系：**closure(ran T) = ⊥(ker T*)**；
- T 稠值域 ⟺ T* 单射；T 单射 ⟺ T* 稠值域。

第二条是核心：值域未必闭，但取零化子自动"闭包化"。
线性代数里的 rank–nullity 定理在这里升格为闭包陈述。

## 27.3 商空间与对偶

**定理**。(X/M)* ≅ M⊥，且 X*/M⊥ ≅ M*（限制映射）。
商的范数 ‖x+M‖ = inf_{m∈M} ‖x+m‖ 对偶地表现为
M⊥ 上的一致范数。这套字典是第 29 章（Banach 代数的理想与商）
的直接预备：理想 I 的商 A/I 上范数正是由零化式不等式控制的。

## 27.4 Banach-Stone 定理

**定理（Banach-Stone）**。K, L 紧 Hausdorff。若
U: C(L) → C(K) 是**满射等距**（实值情形），则存在同胚
h: K → L 与连续函数 α: K → {±1}，使

  (Uf)(x) = α(x)·f(h(x))。

**证明骨架**。
1. U* 把 C(K)* 的极值点（Dirac 测度 ±δₓ）映到 C(L)* 的极值点：
   等距的伴随保持单位球面结构，而由 Krein-Milman（第 25 章）
   Dirac 测度恰是测度球的极值点集；
2. 得到映射 x ↦ h(x) 与符号 α(x) = ±1；
3. 等距满射 ⟹ h 是同胚（连续双射 + 紧性）。∎

**意义**：**紧空间可以被它的连续函数空间的等距结构完全重构**。
几何（K 的点）↔ 代数（C(K) 的范数）。这是"非交换几何"思想的
古典原型：把 X 换成非交换的 C* 代数，就是 Gelfand-Naimark（第 34 章）。

有限维化身：ℓ¹ₙ 的等距恰好是**符号置换矩阵**——置换对应 h，
符号对应 α。数值实验直接验证这一分类。

## 27.5 紧性与伴随

**定理**。T 紧 ⟺ T* 紧（Schauder 定理，第 28 章展开）。
伴随还保持：有限秩、Fredholm 性（第 45 章）、谱（σ(T*) = σ(T)）。

## 27.6 机器化与数值实验

**Lean**（`examples/lean/Funanalysis/Ch27AdjointBanach.lean`）：
mathlib 锚点 `ContinuousLinearMap.adjoint`——Banach 伴随作为
CLM 的标准构造。

**Julia/Python**（`27_adjoint_banach.*`）：
- ‖A‖₁ = ‖Aᵀ‖∞、‖A‖∞ = ‖Aᵀ‖₁（伴随保范的 ℓ¹/ℓ∞ 实现）；
- 亏秩矩阵上验证 ker(Aᵀ) ⊥ ran(A)（零化子关系）；
- 符号置换矩阵保持 ℓ¹ 范数，一般矩阵不行（Banach-Stone 分类）。
