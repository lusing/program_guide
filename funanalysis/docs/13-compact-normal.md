# 13 · 紧正规算子的谱定理与泛函演算

> 紧正规算子恰好是可对角化的紧算子。这是复数类比中"紧 + 正规
> = 复数序列趋于零"的精确化。——§II.7-8 的主题

第 11 章处理了紧自伴（特征值全实）；本章推广到紧**正规**
（特征值可以是复数），并建立**泛函演算**——把函数应用到算子上。
覆盖 Conway §II.7-§II.8。

## 13.1 恒等分割与可对角化算子

**定义（Conway 7.2-7.3）**。(Pᵢ)_{i∈I} 是 ℋ 上的**恒等分割**，
若它们是两两正交的投影（PᵢPⱼ = 0, i≠j）且 ⊕ᵢPᵢ = 1。

A **可对角化**：A = ⊕ᵢ αᵢPᵢ，sup|αᵢ| < ∞，Ah = αᵢh 当
h ∈ ran Pᵢ。此时 ‖A‖ = sup|αᵢ|。

**命题（Conway 7.4）**。A 可对角化 ⟺ ℋ 有由 A 的特征向量组成
的标准正交基。

**定理（Conway 7.5）**。A = ⊕αᵢPᵢ 可对角化且 αᵢ 互异。则
B 与 A 交换 ⟺ 每个 ran Pᵢ 约化 B。

"与对角算子交换 = 分块对角"——这是第 39 章 von Neumann 代数
理论的种子。

## 13.2 紧正规算子的谱定理

**定理（Conway 7.6）**。T 是复 Hilbert 空间上的紧正规算子。
则 T 的不同非零特征值至多可数。设 (αₙ) 是不同的非零特征值，
Pₙ = 到 ker(T−αₙ) 的投影。则 PₙPₘ = 0 (n≠m) 且

**T = Σₙ αₙPₙ**（按算子范数收敛）。

**证明思路**。T = A + iB（实部虚部分解，第 08 章）。A, B 紧自伴
（T 紧 ⟹ A,B 紧；T 正规 ⟹ AB = BA）。由第 11 章谱定理，
A = Σ aₙEₙ（实特征值分解）。AB = BA ⟹ Eₙ 约化 B（7.5）。
在每个有限维空间 Eₙℋ 上，B|_{Eₙℋ} 是有限维自伴矩阵，可对角化。
合并得到 T 的特征向量基，对应特征值 aₙ + ibₙ。∎

**推论（Conway 7.8-7.9）**。
- ker T = (∨ₙ ran Pₙ)⊥；
- 每个 Pₙ 有限秩；
- ‖T‖ = sup|αₙ|，αₙ → 0（或有限）；
- **T 紧正规 ⟺ T 可对角化**（紧 ⟺ 特征值趋于零 + 有限维特征空间）。

## 13.3 泛函演算

**定义（Conway 7.10）**。T 紧正规，T = ΣαₙPₙ + 0·P₀
（P₀ = 到 ker T 的投影）。Φ: ℂ → ℂ 有界函数。定义

**Φ(T) = Σ Φ(αₙ)Pₙ + Φ(0)P₀**。

这是对角算子：在特征值 αₙ 上"取值" Φ(αₙ)。

**定理（Conway 7.11，泛函演算）**。映射 Φ ↦ Φ(T) 满足：

- **(a) 乘法线性**：(ΦΨ)(T) = Φ(T)Ψ(T)；1(T) = 1；
  z(T) = T（恒等函数给出 T 自身）；
- **(b) 范数**：‖Φ(T)‖ = sup{|Φ(α)| : α ∈ σₚ(T) ∪ {0}}；
- **(c) 伴随**：Φ(T)* = Φ̄(T)（共轭函数）；
- **(d) 交换性**：AT = TA ⟹ AΦ(T) = Φ(T)A。

**定理（Conway 7.12）**。{Φ(T) : Φ ∈ B(ℂ)} =
{B ∈ B(ℋ) : BA = AB 当 AT = TA}——**T 的交换子恰是 T 的泛函演算**。

## 13.4 正算子与平方根

**定义（Conway 7.13）**。A ≥ 0（**正算子**）：⟨Ah,h⟩ ≥ 0 ∀h。

（复空间上正算子自动自伴——第 08 章 2.12。）

**命题（Conway 7.14）**。T 紧正规。T ≥ 0 ⟺ 所有特征值 ≥ 0（实）。

**定理（Conway 7.15，Jordan 分解）**。T 紧自伴。则存在**唯一**的
正紧算子 A, B 使 T = A − B 且 AB = BA = 0。

**定理（Conway 7.16，正平方根）**。T ≥ 0 紧。则存在唯一的正紧
算子 A 使 A² = T。

**证明**。T = ΣαₙPₙ，αₙ ≥ 0（7.14）。取 Φ(αₙ) = √αₙ。
A = Φ(T) = Σ√αₙPₙ。∎

这些构造是**极分解**（Conway 习题 16）的基石：任何紧算子 T
都可以写为 T = U|T|，其中 |T| = (T*T)^{1/2} 是正紧算子，
U 是部分等距。

## 13.5 酉等价与重数

**定义（Conway 8.1）**。A ∈ B(ℋ), B ∈ B(K) **酉等价**
（unitarily equivalent）：存在同构 U: ℋ → K 使 UAU⁻¹ = B。

**定义（Conway 8.2）**。T 紧算子的**重数函数**：
mult(λ) = dim ker(T−λ)（λ ≠ 0 时有限）。

**定理（酉等价分类）**。两个紧正规算子酉等价 ⟺ 它们的
非零特征值（含重数）相同。重数函数是完全不变量。

这是**分类定理**（第 06 章 Hilbert 空间分类的算子版）：
紧正规算子的"形状"由其特征值清单完全决定——特征值是什么、
每个重复几次。没有其他自由度。

## 13.7 数值实验

**Julia**（`13_compact_normal.jl`）：
(1) **正规性**：随机酉 × 对角 × 酉⁻¹ 给出的 T 满足
‖TT* − T*T‖ < 10⁻¹⁰；(2) **泛函演算**：Φ(z) = z²+1 时
‖Φ(T) − (T²+I)‖ < 10⁻⁸；(3) **正算子**：A*A 的特征值全非负、
√T 的平方恢复 T；(4) **酉等价**：不同基下的对角算子酉等价。

**Python**（`13_compact_normal.py`）：同组实验（scipy.sqrtm）。

   单位算子的倍数。
