# 36 · 谱测度与交换 C* 代数的表示

> 谱定理的最终形态：算子 = 积分，被积的是投影值测度。

本章覆盖 Conway §IX.1：投影值测度（PVM）的定义、
谱积分的构造、谱测度与泛函演算的互相生成。

## 36.1 投影值测度

**定义**。设 (X, Ω) 是可测空间（本章 X = ℂ 或 ℝ）。
映射 E: Ω → B(H) 称**投影值测度**（PVM），若
1. 每个 E(Δ) 是**正交投影**；
2. E(∅) = 0，E(X) = I；
3. E(Δ ∩ Γ) = E(Δ)E(Γ)（⟹ 不相交集的投影正交）；
4. 可数可加：Δ = ⊔Δₙ ⟹ E(Δ) = Σ E(Δₙ)（强算子收敛）。

**类比**：概率测度把"事件"映到 [0,1] 中的数；
PVM 把事件映到投影算子——"事件发生时量子态落在哪个子空间"。
量子力学的观测算子理论就是 PVM（Born 规则：
测量 Δ 后态坍缩到 E(Δ) 的值域）。

有限维化身：Hermite 矩阵 H 的特征分解
H = Σ λᵢ vᵢvᵢ* 生成 PVM

  **E(Δ) = Σ_{λᵢ ∈ Δ} vᵢ vᵢ***，

即"落在 Δ 里的特征向量张成的投影"。数值实验直接验证
全部 PVM 公理（空集、全集、正交、可加、幂等）。

## 36.2 谱积分

**构造**。对简单函数 s = Σ cⱼ 1_{Δⱼ} 定义

  ∫ s dE := Σ cⱼ E(Δⱼ)。

对有界可测 f：一致逼近取极限。对无界 f：
定义 Dom(f) = {x : ∫|f|² dμ_x < ∞}（其中
μ_x(Δ) = ⟨E(Δ)x, x⟩ 是 H 上的正测度——**标值测度**），
得到闭稠定算子 ∫ f dE。

**定理**。
- ‖∫ f dE‖ ≤ ‖f‖∞（有界 f）；
- (∫ f dE)* = ∫ f̄ dE；
- ∫ f dE · ∫ g dE = ∫ fg dE（乘法性！）；
- f 实值 ⟹ ∫ f dE 自伴；|f| = 1 ⟹ ∥。

乘法性是核心：**积分把逐点乘法变成算子复合**——
函数代数 L∞(μ) 被表示成 B(H) 的子代数，
这是 C(K) → B(H) 的可测版 Gelfand-Naimark。

## 36.3 谱测度 ↔ 正规算子

**正规算子 N（NN* = N*N）的谱测度**：
N = ∫ z dE(z)，E 是唯一支撑在 σ(N) 上的 PVM。

**谱定理的积分形式（第 37 章主角）**：

  N = ∫_{σ(N)} z dE(z)，f(N) = ∫ f(z) dE(z)。

有限维时退化成 H = V Λ V*：E({λᵢ}) = vᵢvᵢ*，
∫ z dE = Σ λᵢ E({λᵢ}) = Σ λᵢ vᵢvᵢ* = H。
数值实验验证 ∫ λ dE = H 与 f(H) = ∫ f dE
（f = λ² 与 e^λ 双验证，误差 < 10⁻¹²）。

## 36.4 从谱测度到谱集

给定 PVM E 支撑于紧集 K ⊆ ℂ，N = ∫ z dE：
- σ(N) ⊆ K（支撑控制谱）；
- λ₀ ∈ σ(N) ⟺ E(λ₀ 的任何邻域) ≠ 0；
- **点谱** = {λ : E({λ}) ≠ 0}（特征投影非零的特征值）。

对照第 32 章：紧算子的谱测度是**纯原子**的——
E(σ\{0}) = Σ 离散原子，0 处是连续堆积。
Volterra 型拟幂零算子的谱测度全部压在 {0} 上但非原子——
"谱测度的形状"编码了算子的全部病态程度。

## 36.5 L² 空间的乘法算子：万有模型

**定理（谱定理的乘法算子形式，预告）**。
正规算子酉等价于 L²(μ) 上的乘法算子 M_φ:
f ↦ φ·f（某测度 μ 与函数 φ）。

单侧移位 vs 双侧移位的谱差异（第 30 章目录）
在此透明：它们是不同 φ 上的乘法算子。
数值通道的 eig/eigh 分解就是"把算子带到乘法算子坐标"
的有限维版本——对角化即坐标变换。

## 36.7 习题

1. **（纸笔）** 证明 E(Δ)E(Γ) = E(Δ∩Γ) ⟹
   不相交集的投影互相正交（值域正交）。
2. **（纸笔）** 证明 μ_x(Δ) = ⟨E(Δ)x, x⟩ 是正测度，
   且 ‖∫ f dE · x‖² = ∫ |f|² dμ_x。
3. **（数值）** 取三个 Borel 集 Δ₁,Δ₂,Δ₃ 两两相交的
   一般组合，验证 E(Δ∪Γ) = E(Δ) + E(Γ\Δ)。
4. **（纸笔）** 证明 f 实值 ⟹ ∫ f dE 自伴。
