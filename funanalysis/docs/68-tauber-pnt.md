# 68 · Tauber 理论与素数定理

> Wiener 的 Tauber 型定理说：一个卷积平均趋于零，且核的 Fourier
> 变换无零点，则**一切**卷积平均趋于零。Rudin 用它证明**素数定理**
> ——π(x) ~ x/log x。泛函分析在此抵达数论的最深处。——Rudin 第 9 章（意译）

本章覆盖 Rudin 第 9 章全部：Tauber 哲学（9.1：从平均到渐近的
三种形式与 Tauber 条件）、**Wiener 定理**（9.4–9.5：L¹(ℝⁿ) 的闭
平移不变子空间 = L¹ ⟺ 傅里叶变换无零点——53 章 Lax 路线的 Rudin
版本，经分布支撑的局部化引理 9.2–9.3）、**慢振荡**（9.6）与
**Wiener-Tauber + Pitt**（9.7 全证明）、**素数定理**（9.9–9.12
全推导：von Mangoldt 函数 Λ、Chebyshev 函数 ψ、ζ 函数、Ingham
核 K 的构造与 K̂ ≠ 0、挤压收尾）、**更新方程**（9.13–9.16 概览）。

## 68.1 Tauber 哲学

**三种性质**（序列 sₙ = a₀+…+aₙ）：

- (a) sₙ → s（收敛）；
- (b) Abel 平均 f(r) = Σaₙrⁿ → s（r → 1）；
- (c) n aₙ → 0（Tauber 条件）。

(a) ⟹ (b) 平凡（Abel 定理）；**(b) + (c) ⟹ (a)**（Tauber 1911，
也容易）；把 (c) 减弱为 **n aₙ 有界**（Littlewood）结论不变但证明
骤然变难——**Tauber 型定理的本质：平均的收敛在何条件下可以
"去平均"**。

**卷积形态**（Rudin 9.1 末）：Φ ∈ L^∞，K ∈ L¹，‖K‖₁ = 1 时
(K*Φ)(x) = ∫K(x−y)Φ(y)dy 是 Φ 的**平均**。若 K*Φ → 0（x→∞）
且某核的傅里叶变换无零点，则**一切** f ∈ L¹ 有 f*Φ → 0——
Wiener 的逆转。Tauber 型条件（如慢振荡）再进一步给 Φ(x) → 0。

## 68.2 局部化与 Wiener 定理

**引理（Rudin 9.2）**。f ∈ L¹(ℝⁿ)，t ∈ ℝⁿ，ε > 0。则存在
h ∈ L¹（‖h‖₁ < ε）使 **h 的傅里叶变换在 t 的某邻域中恒等于
f̂(t)**。

证明：取 g ∈ L¹ 在原点邻域 = 1，令 g_λ(x) = e^{it·x}g(x/λ)，
则 ĝ_λ(s) = λⁿĝ(λ(s−t)) 在 t 附近 = 1；h = f(t)g_λ − f*g_λ 的
变换 = f(t)ĝ_λ − f̂·ĝ_λ = **(f(t) − f̂(s))ĝ_λ(s)** 在 t 的邻域
（|f̂(s) − f(t)| < ε 于 ‖h‖₁ < ε‖g‖₁）中近似 0，且 h 的变换
**恰在 t 点 = 0**。∎

**定理（Rudin 9.3，局部化）**。Φ ∈ L^∞ 使 (f*Φ)(x) → 0 对某
f ∈ L¹ 且 f̂ 在开集 V 中恒不为零，则**一切** g ∈ L¹ 使 ĝ 在 V
上无零点者都有 (g*Φ)(x) → 0（在 V 的每个紧子集上一致）。

证明：ĝ/f̂ 是 V 上的有界函数（紧子集上），h = g − (ĝ/f̂)·f 的
构造（经 9.2 的逼近 + 截断）使 ‖h‖₁ 任意小 ⟹ h*Φ 一致小；
f*Φ → 0 传递。∎

**定理（Rudin 9.4，Wiener，分布形式）**。Y 是 L¹ 的闭平移不变
子空间。若 Y 的零集

```
Z(Y) = {t ∈ ℝⁿ : f̂(t) = 0 对一切 f ∈ Y}
```

为空，则 **Y = L¹**。

证明：Y⊥ 中的 Φ 满足 f*Φ = 0（∀f ∈ Y，平移不变性）；9.3 的
分布版给 supp(Φ̂) ⊆ Z(Y) = ∅ ⟹ Φ̂ = 0 ⟹ Φ = 0（变换单射）
⟹ Y⊥ = {0} ⟹ Y = L¹（Hahn-Banach）。∎

**定理（Rudin 9.5）**。K ∈ L¹，Y 是含 K 的最小闭平移不变子
空间。则 **Y = L¹ ⟺ K̂ 处处非零**。（Z(Y) = K̂ 的零集。）

**与 53 章会师**：Lax 用极大理想（Gelfand 理论）证 Wiener 代数
版本；Rudin 用**分布支撑的局部化**证 L¹ 版本——同一现象（"无
零点 ⟹ 平移张成"）的两条独立路线。Rudin 版更强：直接给出子
空间 Y 的完全刻画（Z(Y) 是唯一的共性不变量）。

## 68.3 Wiener-Tauber 型定理与慢振荡

**定义（Rudin 9.6）**。Φ ∈ L^∞ **慢振荡**：ε > 0 ⟹ A < ∞ 与
δ > 0 使 |x|, |y| > A 且 |x−y| < δ ⟹ |Φ(x) − Φ(y)| < ε。
（一致连续有界 ⟹ 慢振荡；逆不真。）

**定理（Rudin 9.7，Wiener + Pitt）**。Φ ∈ L^∞，K ∈ L¹，
K̂(t) ≠ 0 ∀t，且

```
lim_{x→∞}(K*Φ)(x) = a·K(0)（K 的特定归一下 a·∫K）。
```

则：

1. 对**一切** f ∈ L¹：(f*Φ)(x) → a·∫f；
2. 若 Φ 还**慢振荡**，则 **Φ(x) → a**（x → ∞）。

**证明**（全文，干净利落）：

记 Ψ = Φ − a。Y = {f ∈ L¹ : (f*Ψ)(x) → 0}。验证：

- **闭**：‖f−fₙ‖₁ → 0 ⟹ ‖(f−fₙ)*Ψ‖_∞ ≤ ‖f−fₙ‖₁‖Ψ‖_∞ → 0
  一致控制；
- **平移不变**：(τ_y f)*Ψ = τ_y(f*Ψ)（卷积的平移协变性 (6)）；
- **K ∈ Y**：假设 (K*Φ) → aK(0) ⟹ (K*Ψ)(x) = (K*Φ)(x) −
  aK(0)·… → 0（归一配平）。

9.5 ⟹ Y = L¹：一切 f 满足 (f*Ψ)(x) → 0，即 (f*Φ)(x) →
a∫f。(a) 完。

**(b) 慢振荡的收尾**：取 f ≥ 0、∫f = 1、supp ⊆ [−δ, δ]。
则 (f*Φ)(x) = ∫Φ(x−y)f(y)dy → a，而慢振荡给

```
|Φ(x) − (f*Φ)(x)| ≤ sup_{|y|<δ} |Φ(x) − Φ(x−y)| < ε（|x| > A+δ）
```

（(8)(9) 式：差被 f 的支撑内的振荡控制）。ε 任意 ⟹ Φ(x) →
a。∎

## 68.4 素数定理

**定理（素数定理，PNT）**。π(x) = #{p ≤ x 素数}，则

```
lim_{x→∞} π(x)·log x / x = 1。
```

**Rudin 的路线**（9.9–9.12，本教程全文提炼；把不规则的 π 换成
渐近可控的 Chebyshev 型函数，再用 Tauber 定理换回 π 的结论）：

**第一步（9.10）：von Mangoldt 函数与 F**。Λ(n) = log p（n =
p^k 时）否则 0。定义

```
F(x) = Σ_{n≤x} Λ(n)⌊x/n⌋。
```

关键恒等式：**Σ_{d|n} Λ(d) = log n** ⟹

```
F(x) = Σ_{n≤x} Σ_{d|n} Λ(d) = Σ_{m≤x} log m = log⌊x⌋!    (7)
```

（每个 Λ(d) 在 n = d, 2d, … 中出现 ⌊x/d⌋ 次；重排 = log 的
叠加）。

**第二步：Stirling 控制**。log n! = n log n − n + O(log n)
（Stirling），被积比较 (8)–(10) 给

```
F(x) = x log x − x + O(log x)。                         (5)
```

（Rudin 的 (8)：J(x) = ∫₁ˣ log t dt = x log x − x + 1 与
F 的单调阶梯夹逼。）

**第三步：θ(x) 的等价目标**。θ(x) = Σ_{p≤x} log p。部分和
关系（9.11 前的 (4)：⌊log x/log p⌋ 是 ≤ x 的 p 的幂的个数）
给

```
θ(x) ≤ ψ(x) := Σ_{p^k≤x} log p = Σ Λ(n) ≤ θ(x) + O(√x log²x)，
```

而 **ψ(x) ~ x ⟹ PNT**（(4) 的双重不等式换算到 π：π(x) =
θ(x)/log x + O(θ(x)/log²x)，分部积分）。

**第四步：h(x) 与 Φ 的构造（9.12）**。令 g = ψ 的计数分布
（g(x) = Σ_{x/n...}），变量代换 x = e^t：

```
h(t) = g(e^t)，    H(t) = Σ_n Λ(n)·U(t − log n)，
```

(6)：H(t) = e^t(a t + b + ε(t))，ε(t) → 0——F(x) = e^t 形态的
对数坐标像。取

```
Φ(t) = e^{−t} h(t)      （有界：(4) 的 g(t) ≤ 2At 上界）
```

目标变成 **Φ(t) → a = 1**。

**第五步：Ingham 核 K 的构造**。关键一步——找一个核 K 使
K̂ 恰好是 **ζ 函数的倒数的显式组合**（ζ 在 Re = 1 上无零点
的等价物）。Rudin 取（(9)：λ 无理）

```
K = k − k(·−λ)·c₁ − k(·+λ)·c₂ 型的组合，
k(x) = [eˣ]e^{−x}·χ_{[0,∞)}
```

其变换（(10)）：

```
K̂(t) = (2 − e^{−iλt}·c₁(...)) · (1 + it)^{−1}·Γ 型 = (2 − e^{−λ(1+it)} − e^{...})(1+it)^{-1} 型
```

——分母 1+it 只在 t = 0 有单极点，**分子的 ζ 结构**使
**K̂(0) ≠ 0 且 K̂(t) ≠ 0 ∀t**（λ 无理 ⟹ 指数函数 e^{−iλt} 与
1 在 t ≠ 0 处不抵消；t = 0 处极限 = 1 + λ ≠ 0）。

**第六步：K*Φ 的控制**。(11)–(12)：H = h*μ（μ 是 log n 处的
单位点质量测度）的结构给

```
(K*Φ)(t) = （(1+λ)a 型常数）+ ε₂(t)，ε₂(t) → 0
```

——即 K*Φ 有 Wiener 定理所需的渐近常数。

**第七步：定理 9.7 收官**。K̂ ≠ 0 + (K*Φ)(t) → 常数 ⟹ 对一切
f ∈ L¹：(f*Φ)(t) → a∫f。取支撑在 [0, ε] 与 [−ε, 0] 的两个
非负 f₁, f₂（积分 1）：e^t 的**单调性**（Φ(t)e^t = h(t)
非降）给夹逼

```
e^{−ε}·(f₁*Φ)(t) ≤ Φ(t) ≤ e^{ε}·(f₂*Φ)(t)    (15)
```

t → ∞ 时上下极限夹在 ae^{−ε} 与 ae^{ε} 之间；ε 任意 ⟹
**Φ(t) → a** ⟹ ψ(x) ~ a·x（换回 x = e^t）⟹ **PNT**。∎

**评注**：

- 核心洞察是**ζ(1 + it) ≠ 0**（Hadamard–de la Vallée Poussin
  的原始入口）被**打包**进核 K 的构造——分析的重活全部浓缩在
  "K̂ 无零点"这一验证里。
- Tauber 定理的作用：F(x)（好函数，= log n!）的信息经
  **卷积结构**（F = ΣΛ(n)⌊x/n⌋ 是 Λ 的离散卷积）传回 Λ 与
  ψ（坏函数）——"从平均到逐点"的兑现。
- 慢振荡的化身：e^t 单调 ⟹ Φ(t)e^t 非降 ⟹ Φ 慢振荡
  （(15) 的夹逼正是 9.7(b) 的证明机制）。

## 68.5 更新方程（概览）

**定理（Rudin 9.13，唯一性）**。μ 是 ℝ 上支撑不在任何循环
子群的概率测度，Φ 有界 Borel 且 Φ − Φ*μ = 0。则 Φ = 常数
（a.e.）。

证明骨架：μ̂(t) = 1 ⟺ t = 0（支撑不在循环子群 ⟹ e^{−ita} ≡ 1
无解）；分布 Φ̂ 满足 (1 − μ̂)Φ̂ = 0 ⟹ supp(Φ̂) ⊆ {0} ⟹ Φ̂ =
δ 的有限导数组合 ⟹ Φ 是多项式型；有界性杀掉非常数部分。∎

**更新定理（9.15–9.16）**：Φ − Φ*μ = f 的解渐近于 (∫f)·
(更新密度)——概率论中马尔可夫链平稳分布的理论基础。

## 68.6 Julia 数值实验

实验文件 `examples/julia/68_tauber_pnt.jl`。

**实验 1：Tauber 三角的数值演示**。序列 aₙ = (−1)ⁿ/n 的
Abel 平均 f(r) = Σaₙrⁿ → −log 2（收敛 ⟹ Abel）；Tauber 条件
naₙ = (−1)ⁿ ↛ 0 但 |naₙ| = 1 有界（Littlewood 版）⟹ sₙ →
−log 2 验证。对照 aₙ = (−1)ⁿ（Abel 平均 → 0 但 sₙ 发散——
n aₙ 无界，Tauber 条件必要性的数值形态）。

**实验 2：Λ 与 log n! 的恒等式**。n ≤ 5000：逐项验证
Σ_{d|n}Λ(d) = log n（分解恒等式）；F(x) = ΣΛ(n)⌊x/n⌋ 与
log⌊x⌋! 的三档 x 对照（机器精度级一致）。

**实验 3：ψ(x) ~ x 的数值验证**。x = 10³, 10⁴, 10⁵, 10⁶（筛法
生成素数表）：θ(x)、ψ(x)（素数幂贡献）与 x 的比值表——
比值收敛到 1（误差 ~ x^{−1/2}log 型，慢收敛如实显示）；
**π(x)log x/x → 1** 同表（PNT 的直接数值验证）。

**实验 4：Ingham 核的谱验证**。K̂(t) = (2 − e^{−iλt}·…)(1+it)^{−1}
型：数值计算 K̂ 的模在 t 网格上的最小值（λ = √2 无理）——
inf |K̂| > 0 的数值验证（K̂(0) = 1+λ 的归一与 t ≠ 0 处指数项
不抵消的机制）。
