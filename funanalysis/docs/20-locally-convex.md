# 20 · 局部凸空间

> 当范数太多而没有一个能"看到全部"时，就需要半范数族。
> ——局部凸空间的设计哲学

本章覆盖 Conway §IV.1–§IV.2：半范数族生成的拓扑、局部凸性的刻画、
可度量化与可赋范的判据。

## 20.1 半范数与局部凸拓扑

**定义**。p: X → [0,∞) 是**半范数**（seminorm），若：
- p(αx) = |α|p(x)（齐性）；
- p(x+y) ≤ p(x)+p(y)（三角不等式）。

（不要求 p(x)=0 ⟹ x=0——"半"字之所在。）

**局部凸拓扑**。给半范数族 {pᵢ}，定义基：
B(x; ε; i₁,...,iₙ) = {y : p_{iₖ}(y−x) < ε, k=1..n}。

这给出一个**平移不变**、（若族分离点则）Hausdorff 的拓扑，
其中每个点的邻域基由**凸**集组成——"局部凸"之名由此而来。

**Hausdorff 判据**：{pᵢ} 分离点（∀x≠0, ∃i: pᵢ(x)>0）⟺ 拓扑 Hausdorff。

## 20.2 局部凸空间的例子

- **赋范空间**：单半范数族 {‖·‖}。
- **弱拓扑 σ(X,X*)**：半范数族 {p_F(x) = |F(x)| : F ∈ X*}。
- **弱*拓扑 σ(X*,X)**：{p_x(F) = |F(x)| : x ∈ X}。
- **C^∞(Ω)**（光滑函数）：半范数族 p_{K,m}(f) = sup|D^α f| 在紧 K 上，
  |α| ≤ m。这是 Fréchet 空间（完备可度量局部凸）。
- **分布空间 D'(Ω)**：D(Ω) 的对偶，弱*拓扑。

## 20.3 可度量化与可赋范

**定理**。局部凸空间 (X, {pᵢ})：
- **可度量化** ⟺ 半范数族有可数等价子族。
  度量：d(x,y) = Σ 2⁻ⁿ min(1, pₙ(x−y))。
- **可赋范** ⟺ 存在**单个**半范数定义同一拓扑
  ⟺ 原点有有界邻域。

弱拓扑 σ(X,X*) 可赋范 ⟺ dim X* < ∞（即 dim X < ∞）。
无穷维空间的弱拓扑**永不可赋范**——这是"局部凸但非赋范"
的最重要例子。

## 20.4 连续线性映射

**定理**。T: (X,{pᵢ}) → (Y,{qⱼ}) 线性。T 连续 ⟺
对每个 qⱼ，存在有限 {p_{i₁},...,,p_{iₙ}} 和 C > 0 使
qⱼ(Tx) ≤ C·max(p_{iₖ}(x))。

连续线性泛函 F: X → 𝔽 连续 ⟺ |F(x)| ≤ C·max(p_{iₖ}(x))。
**X 的对偶 X'**（连续线性泛函全体）在弱*拓扑下是局部凸的。
