# 54 · Fredholm 行列式

> 无穷维空间上线性方程的可解性，第一次被完整回答是在 1900 年——
> 用的是行列式。新理论（Banach 空间）把它埋葬了七十年；但散射
> 理论和可积系统又把它挖了出来。"Since this determinant appears
> in some modern theories, it is time to resurrect it."——Lax 第 24 章

本章覆盖 Lax 第 24 章全部三节：Fredholm 行列式 D 的构造（从离散
Riemann 和到级数 (6)）、预解核 R 与可逆性判据（D ≠ 0 ⟺ I + K 可逆）、
乘法性质 D_L = D_H·D_K 的变分证明、迹公式 D(λ) = Π(1 − λλⱼ) 与
Gelfand-Levitan-Marchenko 方程的 D′(a) = −R(a,a)。

## 54.1 从行列式到级数

**方程**。u(x) + ∫₀¹K(x,y)u(y)dy = f(x)，K 连续。

Fredholm 的路线：把积分离散成步长 h = 1/n 的 Riemann 和，得到
n 元线性方程组，解是行列式之比；然后让 n → ∞ 取极限。

**有限维**。D(h) = det(I + hK_{ij}) 是 h 的多项式。对行列式求导
的规则（对列求导 (3)）在 h = 0 处的极端简化（列退化为单位向量）
给出主子式展开：

```
D(h) = 1 + h·K₁₁ + h²·(K₁₁K₂₂ − K₁₂K₂₁)/2! + …
```

**连续极限**。记号（Fredholm 的缩写）

```
[K(x₁,…,xₖ)] = det(K(xᵢ, xⱼ))_{1≤i,j≤k}
```

令 h = 1/n、n → ∞，k 项 Riemann 和收敛为 k 重积分：

```
D = 1 + Σ_{k≥1} (1/k!) ∫₀¹…∫₀¹ [K(x₁,…,xₖ)] dx₁…dxₖ      (6)
```

**引理 1（收敛）**。级数 (6) 收敛。

**证明**用的是 **Hadamard 不等式**：

```
|det(C₁,…,C_k)| ≤ Π‖Cⱼ‖                                        (7)
```

（平行多面体体积 ≤ 各边长之积；几何意义即 Gram-Schmidt 正交化不
减体积——第一卷 05 章证过等价形式）。|K| ≤ M 给出 |[K(x₁…xₖ)]| ≤
M^k·k^{k/2}，第 k 项 ≤ (M√k)^k/k! ~ (Me)^k/k^{k/2}（Stirling），
收敛。若 K 满足 Hölder 条件，列相减技巧 + 算术-几何平均给更强
估计 (8')：第 k 项 ≤ C^k/k^{(1/2+α)k}。∎

**评注**：D 是"体积"的无穷维推广——(6) 的第 k 项正是 K 在 k 维
格点上的"平均体积元"。第 56 章将看到 (6) 的现代形式：
**det(I + T) = Π(1 + λⱼ)**（迹类的 Fredholm 行列式）。

## 54.2 预解核与可逆性

同法处理逆矩阵的余子式，得到**预解核**：

```
R(x,y) = K(x,y) + Σ_{k≥1} (1/k!) ∫…∫ [K(x,x₁,…,xₖ; y,x₁,…,xₖ) —
         划去首行首列的行列式] dx₁…dxₖ                        (10)
```

把 (10) 中行列式按第一行展开，把第 j 项积分的变量 x₁ ↔ xⱼ 换名
（一次行置换 + j−2 次列置换不变号），恰好重新组织成：

```
R(x,y) + ∫K(x,z)R(z,y)dz = D·K(x,y)      (12)
R(x,y) + ∫R(x,z)K(z,y)dz = D·K(x,y)      (12′)
```

**定理 2**。D ≠ 0 ⟹ I + K 可逆，逆 = I − D⁻¹R。（(12) 即
(I+K)(I − D⁻¹R) = I 的核语言。）∎

**定理 3**。D = 0 ⟹ I + K 有非平凡零空间。（直接论证有漏洞
（R 可能恒零），改为：引入复参数 λ，D(λ) 与 R(x,y;λ) 都是 λ 的
**整函数**（引理 4），D(0) = 1 ≠ 0，故 D 的零点离散；D(λ₀) = 0
处的分析给出特征函数。）∎

特征值与行列式零点一一对应：

**定理 6（谱-零点对应）**。D(λ) = 0 ⟺ −1/λ 是 K 的特征值，
零点重数 = 特征空间维数。

## 54.3 乘法性质：变分法的证明

**定理 11（Fredholm）**。(I+H)(I+K) = I+L ⟹ **D_L = D_H·D_K**。

**证明**（"Fredholm's beautiful argument"——Lax 原话；变分法）。

**第一步：变分公式**。对 D_K 作变分 δK。对 (6) 逐项变分（对
k 阶行列式用求导规则），行/列换名整理成两类项：

```
δ log D_K = ∫(I+K)⁻¹δK(x,x)dx − D⁻¹∫∫R(y,x)δK(x,y)dxdy     (27)
```

算子形式（(I+K)⁻¹ = I − D⁻¹R）：

```
δ log D_K = ∫(I+K)⁻¹δK(·,y)dy = ∫(I+K′)⁻¹δK(x,·)dx     (28)(28′)
```

**第二步：乘积的变分**。L = K + H + HK 给 δL = (I+K′)δH + (I+H)δK
（(29″)）。代入 (28) 并用 (I+L)⁻¹ = (I+K)⁻¹(I+H)⁻¹：

```
δ log D_L = ∫(I+H)⁻¹δH(x,x)dx + ∫(I+K)⁻¹δK(x,x)dx = δlogD_H + δlogD_K。
```

**第三步：延拓**。δ(log D_L − log D_H − log D_K) = 0 沿任何变形
路径；把 H、K 同乘 λ(t)（绕开 D 的零点）连续变形到 0，两端 D=1
⟹ log D_L = log D_H + log D_K 处处成立（D_K ≠ 0 区域），由连续性
覆盖零点情形。∎

## 54.4 迹公式与 GLM 方程

**定理 8（迹公式）**。K 的特征值 λⱼ（按重数）满足

```
∫₀¹ K(x,x)dx = Σλⱼ，      D(λ) = Π(1 − λλⱼ)。      (20)(20′)
```

**证明骨架**：D(λ) 是阶 < 1 的整函数（引理 10 的增长估计），
Hadamard 因子分解给乘积公式 (22')；两边在 λ = 0 求导——左边按
(6) 是 ∫K(x,x)dx，右边是 Σλⱼ（一致收敛保证逐项）。∎

这是 **Lidskii 迹公式**（第 56 章）在积分算子上的原型：**迹 =
对角积分 = 特征值之和**。

**定理（D′(a) = −R(a,a)，GLM/Dyson）**。把积分区间换成 (a, ∞)，
记相应的 Fredholm 行列式为 D(a)。则

```
dD(a)/da = −R(a,a)。                                        (35)
```

证明：平移变量把区间固定、核换成 K(x+h, y+h)，δK = K_x + K_y；
对 (27) 做 (33)(33′) 的分部积分整理，双重积分坍缩成单积分
D⁻¹(R_x + R_y)(a,a)，恰是 d/da log D 的形态。∎

这是**逆散射**（Gelfand-Levitan-Marchenko 方程）与 **Dyson 公式**
（量子场论）的共同源头——Lax 专门复活这一章的原因。

## 54.5 Julia 数值实验

实验文件 `examples/julia/54_fredholm_determinant.jl`。

**实验 1：秩一核的闭式对照**。K(x,y) = xy 是秩一算子（uv 型，
u = v = x）：行列式引理给 D = 1 + λ∫xy = 1 + λ/3，唯一"特征值"
λ₁(K) = 1/3，D 的零点在 λ = −3。数值：级数 (6) 截断 k ≤ 4 与闭式
一致到 1e-12；离散化 det(I + λK_n) 的最小特征值随 n 收敛到 1/3。

**实验 2：一般光滑核**。K = e^{−(x²+y²)}：D(λ) 级数（k ≤ 3）与
大 n 离散行列式 det(I + λK_n) 三点（λ = 0.5, 1, 2）吻合到 1e-6。

**实验 3：乘法性质**。两个核 H、K（秩一 + 秩二）的复合 L =
K + H + HK：数值 D_L vs D_H·D_K 相对误差 < 1e-8。

**实验 4：迹公式**。对称正定核 K(x,y) = min(x,y)（Brownian 协方差）：
特征值解析已知 λⱼ = 1/((j−1/2)²π²)。验证 Σλⱼ = ∫K(x,x)dx = 1/2
（取前 200 项，误差 < 1e-3）；D(λ) 与 Π(1+λλⱼ) 数值重合。

## 54.6 Python 数值实验

实验文件 `examples/python/54_fredholm_determinant.py`。

**实验 1：行列式引理阶梯**。秩 r = 1..4 的随机核（uⱼvⱼ 型）：
D = det(I + λK_n) 与闭式 Π(1 + λ⟨vⱼ,uⱼ⟩) 一致；非正交支撑时用
det(I + λV′U) 的广义形式逐位检查。

**实验 2：谱-零点对应**。K = min(x,y) 的离散特征值 λⱼ ↑ 解析值；
数值求 D(λ) 的根（割线法）与 −1/λⱼ 对照。

**实验 3：D′(a) = −R(a,a)**。核 K(x,y) = e^{−|x−y|} 在区间 (a, 1]
上：数值微分 D(a) 与离散 R(a,a)（预解核的离散近似）随 a 的演化
对照——GLM 方程的机器影子。

## 54.7 Isabelle 机器化

会话 `examples/isabelle/FA54/T54_FredholmDet.thy`。2×2 矩阵的
特征多项式恒等式——迹公式的种子：

```isabelle
lemma det_trace_formula_2:
  fixes a b c d :: real
  shows "det (mat (1 + t*a) (t*b) (t*c) (1 + t*d)) =
         1 + t*(a + d) + t^2*(a*d - b*c)"
```

它同时给出：D(t) 的零点 = −1/λ（谱-零点对应）与 D′(0) = tr
（迹公式的 2×2 全文）。证明是 `algebra_simps` 的直接展开。
