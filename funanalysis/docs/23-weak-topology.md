# 23 · 弱拓扑、Alaoglu 定理与自反性再访

> 弱拓扑是 Banach 空间分析中仅次于范数拓扑的第二重要拓扑。

本章覆盖 Conway §V.1–§V.5：弱拓扑 σ(X,X*)、弱*拓扑 σ(X*,X)、
**Banach-Alaoglu 定理**（对偶单位球弱*紧）、自反性的拓扑刻画。

## 23.1 弱拓扑

**定义**。σ(X,X*)：由半范数族 {p_F(x) = |F(x)| : F ∈ X*}
生成的拓扑。X 上的**弱拓扑**。

**性质**。
- 比 norm 拓扑**弱**（少开集）。
- Hausdorff（Hahn-Banach 分离点）。
- 局部凸（半范数族）。
- 一般**不可度量化**（除非 dim X < ∞）。

**弱收敛**：xₙ → x 弱 ⟺ F(xₙ) → F(x) ∀F ∈ X*。

**关键事实**：
- 强收敛 ⟹ 弱收敛；反之不真（eₙ → 0 弱但不强 in ℓ²）。
- 弱极限**唯一**（Hausdorff）。
- 弱收敛序列**范数有界**（Banach-Steinhaus）。

## 23.2 弱*拓扑

**定义**。σ(X*,X)：由 {p_x(F) = |F(x)| : x ∈ X} 在 X* 上生成的拓扑。

这比 σ(X*,X**) 弱——只"看到"来自 X 的元素。

**弱*收敛**：Fₙ →* F ⟺ Fₙ(x) → F(x) ∀x ∈ X。

## 23.3 Banach-Alaoglu 定理

**定理（Conway V.3）**。X 赋范空间。则 X* 的闭单位球
在弱*拓扑中**紧**。

**证明（Tychonoff）**。闭单位球 B ⊆ ∏_{x∈X} {z : |z| ≤ ‖x‖}。
每个因子是紧 Hausdorff 空间。Tychonoff 定理（选择公理等价）
给出乘积紧。B 是闭子集（逐点条件的交），故紧。∎

这是**弱*拓扑存在的理由**：范数拓扑中单位球不紧
（无穷维 Riesz 引理），但弱*拓扑中**总是紧**——即使 X 不完备。

## 23.4 自反性再访

**定理（Conway V.4）**。X 自反 ⟺ X 的闭单位球在弱拓扑中紧。

**证明**。J: X → X** 是等距满射 ⟺ 弱拓扑 σ(X,X*) =
σ(X**,X*)。由 Alaoglu（对 X**），X** 的球弱*紧。J 把 X 的球
映到 X** 的球。J 满 ⟹ 紧性传回 X。∎

**Goldstine 定理**。J(ball X) 在 ball X** 中弱*稠密
（无论 X 是否自反）。

**推论**。
- X 自反 ⟺ 每个 F ∈ X* 在 ball X 上达到范数（James）。
- X 自反 ⟹ X* 自反 ⟹ X 可分 ⟺ X* 可分。
- **Pettis 定理**：X 自反 ⟺ 每个闭子空间自反。

## 23.5 可分性与可度量化

**定理（Conway V.5）**。X 可分 ⟹ ball X* 弱*可度量化。

弱*拓扑一般不可度量化，但在**可分**空间上单位球可度量化——
这使得"取弱*收敛子列"成为可能（序列紧 ⟺ 紧 + 可度量）。
