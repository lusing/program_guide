# 71 · 弱导数：从 δ 到 Sobolev 空间 W^{k,p}

> 工程师在解电路方程时对 Heaviside 阶跃函数求微商，把结果记作
> δ(x)——一个"只在原点 nonzero、积分却等于 1"的假想函数。数学家的
> 回应：别把 δ 当函数，把它当**连续线性泛函**；求导也就顺势改成
> 分部积分。一条规则救活了一整个运算体系。——《工科泛函分析基础》
> 3.7 节（意译）

本章对应书的两条线索：3.7 节（广义函数与分布空间的工科导引）与
第 6 章的前半（弱导数定义、两种定义的等价、W^{k,p} 的范数与完备性）。
第 6 章是全书的压轴，也是前三卷唯一没有系统覆盖的领地——48 章
（Lax-Milgram）只是把 H₀¹ 当作现成的舞台用过，67 章（Rudin）的
Sobolev H^s 走的是 Fourier 侧谱定义。本章按书的方式从零重建：
**δ 危机 → 分布 → 弱导数 → 完备化定义 → W^{k,p} → 等价定理**。

## 71.1 δ 危机：两个工程场景

**场景一（书例 3.7.1）**：无限长细棒上，全部单位质量集中在原点。
想写一个密度函数 δ(x) 表达它：δ(0) = "∞"、δ(x) = 0（x ≠ 0）、
且 ∫δ dx = 1。矛盾立现——只在一点不为零的函数几乎处处为零，
其勒贝格积分（70 章零积判据）应当是 0，不是 1。δ 不是函数。

**场景二（书例 3.7.2）**：算子演算（Heaviside 的运算微积）要对
阶跃函数 Y(x) = 1_{x>0} 求微商并记作 δ(x)，还要对 δ 继续求微商、
做卷积。Y 在原点不连续，经典导数不存在；"δ 的导数"更无从谈起。
但这套演算在电路方程里屡试不爽——错的不是答案，是"函数"这个词。

## 71.2 基本空间 D 与分布

解药是把"函数"升级为"泛函"。先固定舞台：

**定义（基本空间 D，书 3.7.3）**。C₀^∞(ℝ)（无限次可微、紧支撑）
全体按通常加法与数乘构成线性空间，记 D。D 中的收敛：φₙ → φ 指
（i）存在公共紧区间 [a,b] 使所有 φₙ 在其外为零；（ii）对每个
非负整数 q，φₙ^{(q)} 一致收敛到 φ^{(q)}。

书 3.7.3 的注记一针见血：这个收敛**不能**由任何距离或范数导出，
D 不是距离空间、更不是赋范空间——它是第一卷 20 章（局部凸拓扑）
里归纳极限拓扑的原型。工科路线不展开这层拓扑，只把"D 中的收敛"
当作一个显式定义使用。

**例（磨光函数，书 3.7.4）**。M(x) = c·exp(−1/(1−x²/4))（|x|<2，
否则 0；c 归一化使 ∫M = 1）。M ∈ C₀^∞：光滑且紧支撑。它非平凡地
证明了 D ≠ {0}，更是"磨光"手术的刀：卷积 M_ε * u 把粗糙函数变成
C^∞ 函数并在 L¹ 中逼近 u（书 3.7.5，ε = ε 尺度缩放）。Julia 实验 5
对不连续的 sgn(x) 做磨光卷积：输出导数有界（光滑化）、L¹ 距离
O(ε) 收敛——"稠密性"的数值形态。

**定义（广义函数/分布，书 3.7.6）**。D 上的连续线性泛函称为
**广义函数**（分布），全体记 D*。

**例（局部可积函数嵌入分布，书 3.7.7）**。f ∈ L¹₀c(ℝ)（局部可积），
定义 (f, φ) = ∫f(x)φ(x)dx。这是连续线性泛函——连续性正是用 D 的
收敛定义 + **勒贝格控制收敛定理**（70.6）验证的：φₙ → φ 时控制
函数取公共紧区间上的 max|φₙ − φ|。70 章的收敛定理在此处进入
泛函分析。特别地 Y ∈ L¹₀c 给出分布；而 **δ ∉ L¹₀c 却 ∈ D\***
（书 3.7.8）：δ(φ) := φ(0)，连续性来自 |φₙ(0) − φ(0)| ≤ max|φₙ − φ|。
D* 严格大于 L¹₀c——δ 是第一个"真分布"。

## 71.3 广义导数：分部积分的规则化

设 f ∈ C¹，φ ∈ D。分部积分（边界项被紧支撑抹掉）：

```
∫ f'(x) φ(x) dx = −∫ f(x) φ'(x) dx
```

右端只用到 f 本身（没求导）。**定义（广义导数，书 3.7.9）**：
f ∈ D*，若存在 g ∈ D* 使 (g, φ) = −(f, φ') 对一切 φ ∈ D，就称 g 为
f 的广义导数，记 g = f′。

三条立刻的性质（书 3.7 延续 + 6.3.2）：**可微函数的广义导数就是
经典导数**（上式即定义）；**唯一性**（至多差零测集——两个候选的差
消灭一切检验函数，由 70 章零积判据的推广得 a.e. 为零）；**局部性
与可加性**（限制到子域、指标相加）。

**例（Y′ = δ，书 3.7.10）**。Y ∈ L¹₀c ⊂ D*。对 φ ∈ D：

```
(Y′, φ) = −(Y, φ′) = −∫_0^∞ φ′(x) dx = −(0 − φ(0)) = φ(0) = (δ, φ)
```

一步到位。Julia 实验 2 的数值版：用陡峭化序列 Yε(x) = 1/(1+e^{−x/ε})
逼近 Y，验证 ∫Yε φ′ → φ(2) − φ(0)（有限窗口的边界项 + 跳跃贡献）
且 ∫Yε′ φ → φ(0)——Yε′ 是高度 ~1/ε 的尖峰，ε → 0 时质量全聚到
原点：**δ 就是这族尖峰的分布极限**。"对 δ 积分"从来不是对函数
积分，而是对尖峰族取极限——工程师的直觉与数学家的定义在此会师。

Lean 通道（`Funanalysis/Ch71WeakDerivative.lean`）把动机恒等式
形式化为两层。第一层是全直线分部积分、边界项为零：

```lean
theorem ibp_zero_boundary (u v u' v' : ℝ → ℝ)
    (hu : ∀ x ∈ tsupport v, HasDerivAt u (u' x) x) ...
    (hbot : Tendsto (u * v) atBot (𝓝 0)) (htop : Tendsto (u * v) atTop (𝓝 0)) :
    ∫ x, u x * v' x = -∫ x, u' x * v x
```

第二层 `ibp_compact_support` 把边界趋零从假设变成结论：u、v 支撑
有界 ⟹ x 滑出支撑即 u x = 0 ⟹ 乘积在 ±∞ 处恒为零。证明用
`eventually_lt_atBot`/`eventually_gt_atTop` 取严格事件——支撑边界
点上函数可以非零，Icc 的闭端点要求严格大于才能断矛盾。这两个定理
就是"把求导转移给检验函数、负号留下"的完整机器版。

## 71.4 弱导数：定义与例子

第 6 章换一种口吻讲同一件事（这次导数必须还是函数）。

**定义（弱导数，书 6.3.1）**。u ∈ L¹₀c(Ω)，若存在 v ∈ L¹₀c(Ω) 使

```
∫_Ω u D^α φ dx = (−1)^{|α|} ∫_Ω v φ dx    对一切 φ ∈ C₀^{|α|}(Ω̄)
```

则称 v 为 u 的 |α| 阶**弱导数**，记 v = D^α u。

与 71.3 的关系：广义导数允许 g 是任意分布，弱导数要求 g 是函数
（L¹₀c）。**δ 是 Y 的广义导数但不是弱导数**——于是"有广义导数
没有弱导数"成为常态边缘，Prolog 实验 4 的三重否决（`is_function`、
`lp_member`、`no_functional_weak_deriv`）把它做成了可查询的规则。

**例一（|x|，书 6.3.3）**。u(x) = |x| 在 (−1,1) 上经典导数在 0 不
存在，但弱导数存在且为 sgn。验证即分部积分：∫|x|φ′ = −∫sgn·φ
（0 点单个点不影响积分）。Julia 实验 1 对三个检验函数
φ = e^{−cx²} 数值验证等式两侧吻合到 10⁻³；软化族 sqrt(x²+ε²) 的
经典导数 x/sqrt(x²+ε²) 逐点收敛到 sgn（远离 0 处贴住 ±1）。
Python 实验 3 的另一半给出反面：**阶梯函数 1_{(0,∞)} 没有弱导数**——
若有 L² 候选 g，则 −∫gφ = φ(0) 对一切 φ；但取峰化检验函数列
（宽 → 0、值 φ(0)=1），Cauchy-Schwarz 给出 ‖g‖₂ ≥ φ(0)/‖φₙ‖₂ → ∞。
导数"能量"在跳跃点无限集中（Julia 实验 3：软化导数的 L² 能量随
ε 缩小按 ε^{−1/2} 发散）——任何平方可积函数都接不住。

**例二（ln|x|，书 6.3.4）**。n ≥ 3 时 u(x) = ln|x| 在 B₁(0) ⊂ ℝⁿ
有弱导数 Dᵢu = xᵢ/|x|²（经典计算在 |x|>0 区域成立，原点是零测集）。
关键在成员资格：|∇ln r| = 1/r，而

```
∫_{B₁} (1/r)² dx = c ∫₀¹ r^{n−3} dr   —— n ≥ 3 收敛，n = 2 发散
```

**W^{1,2} 成员资格是维数临界的**。Julia 实验 4 数值复核两端：
n = 3,4,5 时 ∫r^{n−2} 的离散和与精确值 1/(n−2) 吻合，n = 2 时
截断积分 −ln(a) 随下限 a → 0 发散；同时 ln r 本身 L²（n=3 时
∫₀¹ r²(ln r)² dr = 2/27，分部积分精确值，数值 0.0739 vs 0.0741）。
一个函数"进不进 Sobolev 空间"可以仅仅取决于所在维数——这为
72 章的嵌入定理（维数出现在临界指数里）埋下伏笔。

## 71.5 W^{k,p}：完备化定义与范数

书 6.1 的定义走了一条独特的路线——**先有空间（完备化），再发现
空间里人人都有导数**。

**定义（W^{1,2}₀ 与 W^{1,2}，书 6.1.2/6.1.3）**。Ω 是有界区域。

- C₀¹(Ω)（紧支撑 C¹ 函数）关于内积 ⟨u,v⟩ = ∫uv dx + ∫∇u·∇v dx
  的完备化记作 **W^{1,2}₀(Ω)**；
- C¹(Ω̄) 关于同一内积的完备化记作 **W^{1,2}(Ω)**（也称 H¹(Ω)）。

完备化是书 2.4 节的主题：Cauchy 列理应有极限，没有就把极限点
补进来（有理数 → 实数的老故事，函数空间的翻版）。W 空间正是
"带导数能量的函数类"的完备化。

**广义导数的完备化定义（书 6.1.4）**。u ∈ W^{1,2}₀，取 C₀¹ 中的
Cauchy 列 uₖ → u。Poincaré 不等式（72 章主角）保证 uₖ 也在 L² 中
Cauchy，且每个 Dᵢuₖ 同样 Cauchy——由 L² 完备性（Riesz-Fischer，
70.7），Dᵢuₖ → 某 vᵢ ∈ L²。**定义 Dᵢu := vᵢ**：完备化空间的元素
自动携带"L² 值的导数"。Python 实验 1 完整数值重演：uₖ(x) =
sqrt(x² + 1/k) 是 W-Cauchy 列，极限是 |x|——不在 C¹ 里，但在
完备化后的 W^{1,2} 里安居乐业（极限范数² = 2.642，|x| 的理论值
2.667，O(ε) 慢收敛留余量）。"W 空间里人人有导数"第一次落在了
具体函数上。

**定义（W^{k,p}，书 6.2.1）**。k 正整数、1 ≤ p，赋范

```
‖u‖_{k,p} = ( Σ_{|α|≤k} ∫_Ω |D^α u|^p dx )^{1/p}
```

其中 D^α u 取弱导数。W^{k,p} 是 Banach 空间（完备性同 70.7 的
Riesz-Fischer 论证，逐指标进行）。书 6.2.1 的注给出等价范数
（∑_{|α|=k} 与 ∑_{|α|≤k} 两种取法等价——低阶项被 Poincaré 控制），
Python 实验 2 验证 ‖u′‖ ≤ ‖u‖_A ≤ C‖u′‖ 对三个测试函数成立。
p = 2 时 W^{k,2} = Hᵏ 关于内积 ⟨u,v⟩ = Σ_{|α|≤k} ∫D^αu D^αv
还是 Hilbert 空间——72-73 章的变分法全程住在 H₀¹ 里。

**等价定理（书 6.3.5）**。u 有 |α| 阶弱导数 ⟺ u 是某 C^{|α|} 函数列
在 L¹₀c 中的极限、且各阶导数列也 L¹ 收敛。两条定义路线（检验函数
式 vs 完备化式）描述同一个对象。证明（书引文献 [3]）的技术核心是
磨光函数：M_ε * u 的经典导数逼近弱导数——正是 Julia 实验 5 的
数值现象。

## 71.6 mathlib 的第三条路线与通道分工

mathlib 没有书里的"完备化式"或"检验函数式"定义，它走 **Fourier/Bessel
位势**路线：缓增分布 f ∈ MemSobolev s p，当 f = (1+|ξ|²)^{−s/2}ĝ
（某 L^p 函数的 Fourier 侧光滑化，`Mathlib/Analysis/Distribution/
Sobolev.lean`）。三者的关系是同一空间的三个实现：工科书面向手算、
mathlib 面向 Fourier 分析（微分变成多项式乘法）。本章 Lean 通道
（`Funanalysis/Ch71WeakDerivative.lean`）的 API 巡礼：

```lean
#check @TemperedDistribution.MemSobolev      -- 定义（Bessel 位势）
#check @TemperedDistribution.memSobolev_zero_iff  -- s=0 ⟺ L^p 成员
#check @SchwartzMap.memSobolev               -- 速降函数全在 Sobolev 中
#check @TemperedDistribution.MemSobolev.add  -- 加法封闭（子空间）
#check @TemperedDistribution.MemSobolev.mono -- s 大 ⟹ s 小（嵌入的单调性）
```

五个锚点对应书 6.2 的五条初等事实。**"逐点不可微函数的弱导数等于
某个具体函数"**（|x|′=sgn、Y′=δ）在 mathlib 中没有现成 API——
分布层缺少"分布等于某经典函数"的判别基础设施，这由 Julia/Python
数值通道承载（分部积分等式 + 尖峰能量发散的双向证据）与 Prolog
规则通道承载（弱导数对表 + 成员资格推理）。诚实分工，各得其所。

Prolog 通道（`prolog/71_weak_derivatives.pl`）的规则模型值得一看：
`weak_deriv/2` 对表收录 |x|→sgn、Y→delta(0)、relu→Y、ln|r|(n≥3)→
x/r² 等；`in_wp1/2` 组合"有弱导数、导数是函数、双方 L^p"三条件；
`no_functional_weak_deriv/1` 抓出 Y 的导数是 δ（非函数）⟹ Y 没有
W 意义弱导数。查询即证明：`in_wp1(log_abs_r(3), 2)` 成功而
`in_wp1(log_abs_r(2), 2)` 失败——71.4 例二的维数临界在规则引擎里
是一条 `between(3, 4, D)`。

## 71.7 习题

1. **（纸笔）**验证 relu(x) = max(x,0) 的弱导数是 Y(x)：对
   φ ∈ C₀^∞(ℝ) 分部积分（在 (−∞,0) 与 (0,∞) 上分别用经典导数）。
2. **（纸笔）**证明弱导数的唯一性（书 6.3.2(2)）：若 v、w 都是 u
   的弱导数，则 v = w a.e.（提示：v−w 消灭一切检验函数；对
   ‖v−w‖₂² 用磨光函数逼近检验集）。
3. **（纸笔）**书 6.3 的性质 (4)：u 在 Ω 有弱导数 D^αu、在子域
   Ω′ ⊂⊂ Ω 有 D^βu，证明 D^{α+β}u 存在且等于 D^β(D^αu)。
4. **（机器）**Lean：把 `ibp_compact_support` 的支撑假设从
   `∃R, tsupport u ⊆ Icc (-R) R` 减弱为"u 有紧支撑"
   （`HasCompactSupport u`，提示 `IsCompact.bddAbove/bddBelow`
   或 `Compact.exists_bound` 类引理）。
5. **（数值）**Julia 实验 3 中把软化参数改为 ε = 10⁻⁵：能量发散
   更陡，但浮点求积在尖峰上开始欠采样——找出"能量还能算准"的
   ε 下界（提示：网格步长与 ε 之比）。
6. **（数值）**Python 实验 1 中把 uₖ 换成 (x² + 1/k)^{1/4}（极限

   L² 吗？（∫x²/|x|³ dx = ∫1/|x| dx 发散——**临界指数之外**，
   这是 72 章嵌入定理 p 临界又一预演。）
