## 64.1 拓扑向量空间的公理

**定义（Rudin 1.6）**。向量空间 X 上的拓扑 τ 称为**向量拓扑**，
若：

1. X 的每一点是闭集；
2. 加法 (x,y) ↦ x+y 与标量乘法 (α,x) ↦ αx 关于 τ 连续。

(X, τ) 称为**拓扑向量空间（TVS）**。

最基本的代数事实：**平移 T_a(x) = a+x 与伸缩 M_λ(x) = λx
（λ ≠ 0）是同胚**（1.7）。推论是全文反复使用的：

- 向量拓扑是**平移不变的**：E 开 ⟺ a+E 开；
- **拓扑由原点的任一局部基确定**（"局部基"一词在本教程中
  恒指 0 点的局部基）。

三条构造性引理值得单独记忆（证明都是加法连续性的两行应用）：

**引理（对称邻域加细）**。0 的每个邻域 W 含 0 的对称邻域
U（U = −U）使 U + U ⊆ W。（0+0=0 与加法连续。）

**分离定理（Rudin 1.10）**。K 紧、C 闭、K∩C = ∅ ⟹ 存在 0 的
邻域 V 使 (K+V)∩(C+V) = ∅。证明：对每个 x ∈ K 用上一引理取
V_x 使 x+V_x+V_x 不交 C；紧性取有限交。**推论**：TVS 自动
Hausdorff（1.12，取 K = {x}、C = {y}）；局部基的每个元含另一
元的闭包（1.11）。

**均衡邻域加细（Rudin 1.14）**。0 的每个邻域含 0 的**均衡**
（balanced：|α| ≤ 1 ⟹ αB ⊆ B）邻域；局部凸空间的凸邻域可
加细为**均衡凸**邻域。证明：标量乘法在 (0,0) 连续给
{|α| < δ}·V ⊆ U，取全体 αV 的并。

**有界性（Rudin 1.6 末）**。E ⊆ X **有界**：对 0 的每个邻域 V
存在 s 使 t > s ⟹ E ⊆ tV。（这是拓扑有界性，与度量有界性
在不变度量下一致——1.30。）

## 64.2 线性映射与泛函的连续性

**定理（Rudin 1.17）**。线性 A: X → Y 在 0 连续 ⟹ A 一致连续。

**定理（Rudin 1.18，泛函连续性四判据）**。线性泛函 Λ 满足
Λ ≠ 0。以下等价：

1. Λ 连续；
2. **零空间 N(Λ) 闭**；
3. N(Λ) 不稠密；
4. Λ 在 0 的某邻域上有界。

证明链：(1)⟹(2) 平凡；(2)⟹(3) 由 N ≠ X；(3)⟹(4)：余集有内点，
取均衡 V 使 (x+V)∩N = ∅，则 Λ(V) 是 𝔽 的均衡子集——或者有界
（完成），或者 = 𝔽，后者给 x+V 中两点落入 N，矛盾；(4)⟹(1)
直接估计。∎

这条定理的用法贯穿第三卷：**证明泛函连续的捷径是证零空间闭**
——第 65 章不变 Hahn-Banach、第 67 章 Hellinger-Toeplitz 都走
这条路。

**有界线性变换（Rudin 1.32）**。A: X → Y 把有界集映为有界集称
为有界。可度量化时四条等价：连续 ⟺ 有界 ⟺ 序列有界 ⟺
xₙ→0 ⟹ Axₙ→0。注意对非可度量化空间 (b) ⇏ (a)（Rudin 习题 13）。

## 64.3 有限维的三个拓扑刻画

**定理（Rudin 1.21）**。n 维子空间 Y ⊆ TVS X：**Y 闭**，且
每个线性同构 𝕊ⁿ → Y 是同胚。

证明的妙处：f: 𝕊ⁿ → Y 线性，球面 S 的像 K = f(S) 紧、不含 0，
取均衡邻域 V 不交 K，则 f⁻¹(V) 是 𝕊ⁿ 中连通（均衡）不含 S 的
集 ⟹ 落在球内 ⟹ f⁻¹ 把 V∩Y 压回球内——**1.18 的 (4)⟹(1)**
给 f⁻¹ 连续。∎

**定理（Rudin 1.22）**。**局部紧 ⟺ 有限维**。（⟸ 由 1.21；
⟹：V̄ 紧被有限平移覆盖，张成有限维闭子空间 Y，反复用
V ⊆ Y + ½V ⊆ … 收敛到 V ⊆ Y，再由局部基性 X = Y。）

**定理（Rudin 1.23）**。**Heine-Borel 性质（有界闭集全紧）
⟹ 有限维**。（局部有界 + Heine-Borel + 1.22。）

**评注**：1.22 是"无穷维赋范空间单位球不紧"的 TVS 版（第一卷
14 章从 Conway 角度证过 Riesz 引理）；1.23 说明 H(Ω) 这类空间
（有 Heine-Borel 性质但无穷维，见 1.45）**不可能局部有界**，
从而由 Kolmogorov 定理不可赋范——这是本章结尾的伏笔闭环。

## 64.4 度量化定理

**定理（Rudin 1.24）**。TVS 可度量化（存在相容度量）⟺ **有
可数局部基**。且度量可取**平移不变**。

构造（1.38(c) 的精确形式）：可数局部基 {Vₙ} 加细为对称嵌套
链 Vₙ₊₁ + Vₙ₊₁ ⊆ Vₙ 之后，不变度量 d 由级数组装；d 的球
{d(0,x) < 2⁻ⁿ} 夹在 Vₙ 的两个倍数之间，故拓扑相容。

**F-空间**：拓扑由**完备不变度量**诱导的 TVS。**Fréchet 空间**：
局部凸的 F-空间。（Rudin 1.8 的术语约定。）

## 64.5 半范数与 Minkowski 泛函的字典

**定义（Rudin 1.33）**。**半范数** p: X → ℝ：次可加 +
绝对齐次（p(αx) = |α|p(x)），但不要求 p(x) = 0 ⟹ x = 0。
族 𝒫 **可分点**：∀x≠0 ∃p ∈ 𝒫, p(x) > 0。

**Minkowski 泛函**：凸吸收集 A 的

```
μ_A(x) = inf{t > 0 : t⁻¹x ∈ A}。
```

**完全字典（Rudin 1.34–1.37）**：

- **1.34**：p 是半范数 ⟺ p = μ_B，B = {p < 1} 凸均衡吸收；
  {p = 0} 是子空间；p(x) ≤ p(y) + p(x−y)。
- **1.35**：凸吸收 A 的 μ_A 次可加、正齐次；A 均衡 ⟹ μ_A
  半范数；B = {μ_A < 1} ⊆ A ⊆ {μ_A ≤ 1} = C 且 μ_B = μ_A = μ_C。
- **1.36（局部凸 ⟹ 半范数族）**：均衡凸局部基 𝔅 的 Minkowski
  泛函 {μ_V} 是可分点连续半范数族，且 V = {μ_V < 1}。
- **1.37（半范数族 ⟹ 局部凸拓扑）**：可分点族 𝒫 经
  **次基** V(p,n) = {x : p(x) < 1/n} 的有限交生成局部凸拓扑，
  每个 p 连续，且 **E 有界 ⟺ 每个 p 在 E 上有界**。

- **1.38(c)（不变度量的显式公式）**：可数半范数族 {pᵢ} 给

```
d(x, y) = Σᵢ cᵢ · pᵢ(x−y)/(1+pᵢ(x−y))，    cᵢ ↓ 0。
```

——球 B_r 是有限个 {pᵢ < rᵢ} 的交，凸均衡；d 不变且相容。
（这是构造 Fréchet 空间度量的标准公式。）

**对照（mathlib 现代化身）**：本树 mathlib 的
`SeminormFamily` + `gauge`（= Minkowski 泛函）+
`gaugeSeminormFamily`（一切均衡凸开邻域的 gauge 全体）正是
1.36–1.37 字典的机器化——`gaugeSeminormFamily_ball`：gauge 的
单位球 = 原集合，即 1.36 的 V = {μ_V < 1}。

## 64.6 Kolmogorov 可赋范性定理

**定理（Rudin 1.39）**。TVS 可赋范 ⟺ **局部凸 + 局部有界**。

（⟸：局部有界给有界凸邻域 V，其 μ_V 是范数——单点半范数族
诱导同一拓扑；⟹ 平凡。）

这条定理给"为什么 H(Ω) 不可赋范"一个三步闭环：
1.23（Heine-Borel ⟹ 无局部有界）⟹ 1.39（不可赋范）。
第一卷 14 章的"lp 空间无范数"讨论在此得到一般理论的收编。

## 64.7 商空间

**定义（Rudin 1.40）**。闭子空间 N 上的商拓扑 τ_N：使商映射
π: X → X/N 连续的最大拓扑。**定理 1.41**：π 线性、连续、**开**；
局部基像 {π(V)}；局部凸/可度量化/可赋范/F-空间全部**继承**；
商不变度量 ρ(πx, πy) = inf{d(x−y, z) : z ∈ N}；赋范情形得
**商范数** ‖π(x)‖ = inf_{z∈N}‖x−z‖（第一卷 17 章用过）。

**定理 1.42（应用）**：闭子空间 + 有限维子空间之和 **N + F 闭**
——经 π(F) 有限维闭（1.21）+ π 连续收尾。

**半范数的商（1.43）**：p 的零空间 N 上 p(πx) = p(x) 良定义，
商空间的半范数族 {pᵢ} ⟹ X/N 的拓扑——局部凸构造对商的封闭性。

## 64.8 三个标志性 Fréchet 空间（1.44–1.47）

**H(Ω)（1.45）**：开集 Ω ⊆ 𝕊 上全纯函数，半范数族
pₙ(f) = sup{|f(z)| : z ∈ Kₙ}（Kₙ 紧涨列穷竭 Ω）。Montel 定理
（有界族等度连续 ⟹ 紧）给 **Heine-Borel 性质**：H(Ω) 是
Montel 空间。**无穷维 + Heine-Borel ⟹ 不局部有界 ⟹ 不可赋范**
（64.3 闭环）。

**C^∞(Ω)（1.46）**：半范数族 p_{Kₘ,k}(f) = sup_{|α|≤k, Kₘ} |D^α f|。
完备性：逐导数一致收敛。测试函数空间 𝒟_K = C^∞_K（支于 K）取
诱导拓扑；𝒟(Ω) = lim ind 𝒟_K（归纳极限，Rudin 第 6 章的舞台，
本教程 22 章已从 Conway 角度用过）。

**L^p，0 < p < 1（1.47，病理标本）**：Δ(f) = ∫|f|^p 满足
**次三角** (a+b)^p ≤ a^p + b^p ⟹ d(f,g) = Δ(f−g) 是完备不变
度量 ⟹ **F-空间**，球 B_r = r^{1/p}B₁ 有界 ⟹ 局部有界。
但**没有非平凡凸开集**！证明：凸开 V ∋ 0 含 B_r；任一 f 分成
n 段等 Δ 的 gᵢ（Δ(gᵢ) < r），f = (g₁+…+gₙ)/n ∈ V。于是
**L^p(0,1)（p<1）到任何局部凸空间的连续线性映射只有 0**——
连续线性泛函全为零！与 p ≥ 1 的对偶理论（第一卷 17 章）形成
断层对照。

## 64.9 Julia 数值实验

实验文件 `examples/julia/64_tvs_frechet.jl`。

**实验 1：H(Ω) 的半范数族与不变度量**。f(z) = 1/(z−a)（a = 1.2，
圆外极点）：pₙ(f) = sup_{|z|≤1−2⁻ⁿ}|f| 随 n 指数逼近 |a|−1
的倒数级界；按 1.38(c) 用 cᵢ = 2⁻ⁱ 组装 d(f, g)（g = 1/(z−b)），
验证平移不变性与 Cauchy 完备形态（截断极点序列是 d-Cauchy）。

**实验 2：Kolmogorov 判据的双面**。(a) L^p(0,1)（p = 1/2）：
验证次三角 (a+b)^p ≤ a^p+b^p（随机采样）与"凸包爆炸"——
B₁ 的凸包含任意远点（无凸开集的数值形态）；(b) 同一空间
**没有非零连续线性泛函**：对随机 c，泛函 f ↦ ∫cf 在拓扑球
B_r 上的振荡（上确界）为 ∞（把 f 换成 tf 的尺度律 t^p ⟹
p < 1 时 t^{p}→0 慢于任何 t·c —— 生成数据验证 sup 无界）。

**实验 3：s（速降序列）的可数半范数度量化**。s = {x :
|x|ₙ = sup_j jⁿ|xⱼ| < ∞ ∀n}，半范数 pₙ(x) = sup_j jⁿ|xⱼ|。
验证 1.38(c) 的 d 是不变度量；两个速降序列与一个非速降序列
（xⱼ = 1/log(j+2)）的距离（后者 = ∞）。

**实验 4：有限维 ⟺ 局部紧的数值面**。ℓ² 截断 n 维单位球面的
紧性：对 n = 2, 20, 200 构造 2⁻ᵏ-网的覆盖数（体积论证 N(k,n)
≈ (1/2ᵏ)ⁿ 增长），n 大时覆盖数爆炸——"无穷维单位球不紧"
的定量形态；对照紧集 K = {e₁, …, e_m} 有限集的覆盖数恒 m。

## 64.10 Python 数值实验

实验文件 `examples/python/64_tvs_frechet.py`。

**实验 1：Montel 紧性的数值面**。H(圆盘) 中由 p₁ ≤ 1 界定的
函数族（系数 aₖ 满足 Σ|aₖ|²(1+|k|) ≤ 1）：随机采样系数，
验证高阶系数被半范数自动压低（|aₖ| ≤ C/√k 型衰减的分布形态），
Montel（紧 ⟺ 系数衰减一致）的数值影子。

**实验 2：C^∞ 的半范数层级**。f(t) = exp(−1/t²)（t>0，光滑
延拓）：计算 p_k(f) = max_{[0,1]} |f^{(k)}| 对 k = 0..10 的
值表——半范数层级每个有限、随 k 增长；对照不光滑函数
g = |t−1/2|：p₁(g) 已"爆破"（分布导数），落在 C^∞ 拓扑之外。

**实验 3：商范数的数值实现**。X = ℝⁿ（n = 6），N = 前三维
子空间：随机 x 的商范数 ‖π(x)‖ = inf_{z∈N}‖x−z‖ = ‖后三分量‖
（投影计算）与直接投影对照（机器精度）；商空间维数 = 3 的验证。

**实验 4：L^p (p<1) 的"零对偶"数值验证**。对 p = 0.5：随机
泛函方向 c，计算 sup{|∫cf| : Δ(f) ≤ 1} 的有限截断逼近序列
（f = t^{−1/p}·截断 的尺度族攻击）——截断上确界随截断参数
增长 ⟹ 无界 ⟹ 非连续（1.18 判据 (4) 失败的数值形态）。
