> H² 的闭不变子空间 = 内函数的倍数。乘以 z 这一个算子的不变

> ——Lax 第 38 章（意译）

本章覆盖 Lax 第 38 章全部：Hardy 空间 H⁺ 的两种实现（ℓ² 系数与

## 62.1 Hardy 空间 H⁺

ℓ²(ℤ₊) = {x = (a₀, a₁, …) : Σ|aⱼ|² < ∞} 经母函数

```
f(z) = Σ aₙzⁿ                                    (2)
```

实现为单位圆盘内的解析函数空间——**Hardy 空间 H⁺**（55 章
Toeplitz 理论的 H⁺ 同款）。范数：圆周均值的上确界

```
‖f‖² = sup_{r<1} ∫|f(re^{iθ})|²dθ/2π = Σ|aₙ|²     (3′)
```

（单调收敛：|f(re^{iθ})|² 的积分 = Σ|aₙ|²r^{2n} ↗ Σ|aₙ|²。）
差估计 ‖f(re) − f(se)‖² = Σ|aₙ|²|r^{2n} − s^{2n}|² ⟹ 边值
f(e^{iθ}) 在 L² 中存在（(4)），Parseval 保持范数。

**B** = 圆盘上有界解析函数代数（sup 范数 [b]），边界值 a.e. 存在。

**定理 1**。(i) H⁺ 函数的边值有界 ⟹ f ∈ B（磨光 + 最大值原理）；
(ii) 乘法算子 B_b: f ↦ bf 有界且 **‖B_b‖ = [b]**。

(ii) 的 ≥ 方向反证法漂亮：若 ‖B_b‖ < 1 < [b]，则 ‖B_bⁿ‖ → 0 但
B_bⁿf 的圆周范数 = [b]ⁿ‖f‖ → ∞，矛盾。∎

## 62.2 Beurling 定理

**定理 2（Beurling）**。N ⊆ H⁺ 闭、对乘以一切 b ∈ B 不变
（bN ⊆ N）。则存在**内函数** p（解析、|p(e^{iθ})| = 1）使

```
N = pH⁺ = {pg : g ∈ H⁺}。
```

p 在模单位常数因子下唯一。

**Halmos 证明**（全文——四步，每步一小段代数）：

1. **zN 真含于 N**：若 zN = N，每个 f ∈ N 可写 f = zf₁ = z²f₂ = …
   ⟹ f 在 0 处有任意阶零点 ⟹ f ≡ 0，N = {0}（平凡情形）。乘 z
   是等距 ⟹ zN 闭。定义 **M = N ⊖ zN**（N 中与 zN 正交的补）。
2. **逐层正交分解**：把 (10) 叠代 k 次：

   ```
   N = M ⊕ zM ⊕ … ⊕ z^{k−1}M ⊕ z^kN → N = M ⊕ zM ⊕ z²M ⊕ …    (12)
   ```

   （k → ∞：若 g ⊥ 一切 zʲM，则 g ∈ z^kN ∀k ⟹ g 无穷阶零点 ⟹ 0。）
3. **M 一维**：m ∈ M ⟹ m ⊥ z^k N（k ≥ 1），特别 m ⊥ z^k m：

   ```
   0 = (z^k m, m) = ∫e^{ikθ}|m(e^{iθ})|²dθ    (k = 1, 2, …)，
   ```

   取共轭给 k < 0 同样成立 ⟹ **|m|² 的 Fourier 系数除零次外全零**
   ⟹ |m(e^{iθ})| = 常数。若 m, p ∈ M，则 |m + αp|² 恒常数对一切
   α ⟹ p̄m 常数 ⟹ p 与 m 成比例。∎
4. **组装**：取 p ∈ M 单位模。f ∈ N 按 (12) 分解 f = Σzʲaⱼp =
   p·g，|f| = |g| ⟹ g ∈ H⁺ ⟹ N ⊆ pH⁺；反向由 p ∈ N + 不变性。∎

**内函数**的结构（后续理论，Lax 提及）：p = Blaschke 乘积 ×
奇异内函数——零点部分与非绝对连续奇异测度部分。这是 50 章
Blaschke 乘积的回归：Müntz 定理证明里的消零因子在此成为
不变子空间的完全分类。

## 62.3 内外因子分解

**定理 3（Beurling）**。每个 b ∈ B 本质唯一地分解为

```
b = p·u，  p 内函数，u ∈ H⁺ 且 u 的倍式稠密（uH⁺ 稠于 H⁺）。
```

u 称**外函数**（outer）：不含内因子 ⟹ 完全由模 |u| 决定（对数
模的 Poisson 积分给出 u 的相位）。**证明**：N = bH⁺ 的闭包是
不变子空间 ⟹ Beurling 定理给 N = pH⁺；b = pu（|u| = |b| ⟹
u 有界）；uH⁺ 稠密否则 u 含内因子，与 N 的构造矛盾。∎

- **内函数**：全部信息在零点与奇异测度（"相位"）；
- **外函数**：全部信息在模（"幅度"）。

信号处理的语言：最小相位部分 + 全通部分的分解。**Corona 定理**
（53 章注记的回归）：u 外 ⟺ |u| 在圆盘内不退缩（Σ|uⱼ| ≥ δ），
证明深（Carleson）。

## 62.4 Julia 数值实验

实验文件 `examples/julia/62_beurling_hardy.jl`。

**实验 1：H⁺ 的范数与边值**。截断系数向量 → 解析函数：(a) 圆周
范数 ∫_{r}|f|² 随 r → 1 单调上升到 ‖a‖₂（(3) 的数值）；(b) 边值
f(e^{iθ}) 的 Parseval；(c) 乘以 z 是等距（系数移位）。

**实验 2：Beurling 分解的数值实现**。给定不变子空间 N = pH⁺
（p = 有限 Blaschke 乘积，如 p = (z−a)/(1−āz)·(z−b)/…）：(a) N 的
格点逼近：{p·g} 的系数支撑；(b) M = N ⊖ zN 的数值提取：对 N 的
正交基做 Gram-Schmidt 对 z 的循环——M 一维且张成元 = c·p；
(c) 步骤 3 的 Fourier 论证：|m|² 的系数除 0 外全零（1e-14）。

**实验 3：内外分解（模驱动的重构）**。取 b = 已知内×外的函数
（p = Blaschke，u = exp((z+1)/(z−1)) 型外函数的截断）：数值验证
|b| = |u|（内因子不改变模）；外函数由模重构：ũ = exp(Poisson
(log|b|))，比较 ũ 与 u（相位常数差内逐点吻合）。

**实验 4：不变子空间的探测**。随机多项式 q：N = qH⁺ 截断的
"近似不变性"（乘 z 后仍在 N 的距离随度数增长衰减）；对照
q 不变的方向：qH⁺ 对乘 q 不变但一般对乘 z 不变 ⟹ Beurling
说不变性必须由内函数承载——数值演示非 p 型的 q 给出的空间
只对乘 q 不变、不对乘 z 不变。

## 62.5 Python 数值实验

实验文件 `examples/python/62_beurling_hardy.py`。

**实验 1：内函数的判定与构造**。有限 Blaschke 乘积 p（a = 0.3,

Toeplitz 矩阵结构（乘 p 在 H⁺ 上的矩阵 = 解析 Toeplitz，55 章
连接）。

**实验 2：正交分解 (12) 的数值**。N = span{zʲp}_{j≤J}：M、zM、
z²M… 的 Gram 矩阵对角（正交性验证，1e-13）；M 的维数 = 1。

**实验 3：外函数的 Poisson 重构**。|b| 已知 → log|b| 的 Poisson
积分 → 共轭调和函数 → ũ = exp(...)：与真 u 的相对误差随格点
加密收敛（Hilbert 变换的 52 章工具在此复用——外函数相位 =
模的对数的 Hilbert 变换）。
