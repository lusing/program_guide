# 22 · 归纳极限与分布

> 分布论是 20 世纪分析的最大成就之一。
> Laurent Schwartz 因此获得 Fields 奖（1950）。

本章覆盖 Conway §IV.4–§IV.5*：检验函数空间 D(Ω)、
归纳极限拓扑、分布空间 D'(Ω) 及其基本运算。

## 22.1 检验函数空间

**定义**。Ω ⊆ ℝⁿ 开集。D(Ω) = C_c^∞(Ω)：
紧支撑的光滑函数全体。

D(Ω) 不是赋范空间，但它是**归纳极限**：
D(Ω) = ⋃_K D_K（K 紧，D_K = 支撑在 K 中的光滑函数），
每个 D_K 是 Fréchet 空间（半范数 p_{K,m}）。

**归纳极限拓扑**（LF-拓扑）：D(Ω) 上使所有包含映射
D_K → D(Ω) 连续的最强局部凸拓扑。

## 22.2 分布

**定义**。T: D(Ω) → ℂ 线性。T 是**分布**，若 T 连续
（对归纳极限拓扑）。D'(Ω) = 全体分布。

**等价刻画**：T ∈ D'(Ω) ⟺ 对每个紧 K，存在 C 和 m 使
|T(φ)| ≤ C·max_{|α|≤m} sup_K |D^α φ|（支撑在 K 中）。

**例子**。
- **正则分布**：f ∈ L¹_loc，T_f(φ) = ∫f·φ dμ。
- **δ 分布**：δ_a(φ) = φ(a)（阶数 0）。
- **δ'**：δ'_a(φ) = −φ'(a)（阶数 1）。
- **偶极子**：(δ_a − δ_b)/|a−b|。

## 22.3 分布的运算

**微分**：D^α T(φ) = (−1)^|α| T(D^α φ)。
每个分布无穷次可微！这是分布论的最大红利。

**乘法**：(gT)(φ) = T(gφ)，g ∈ C^∞。
（分布之间**不能**一般地相乘——这是 Schwartz 理论的基本限制。）

**卷积**：(T * φ)(ψ) = T(φ̌ * ψ)，φ̌(x) = φ(−x)。

## 22.4 分布的局部阶与结构

**定理**。T ∈ D'(Ω)。则 T 是有限阶的：在每个紧 K 上，
|T(φ)| ≤ C·max_{|α|≤m_K}|D^α φ|。

**结构定理**。T 是分布 ⟺ T = Σ_{|α|≤m} D^α μ_α（局部），
其中 μ_α 是 Radon 测度。每个分布是测度的导数。
