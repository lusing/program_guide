# 12 · 应用：Sturm-Liouville 系统

> 微分方程的边界值问题可以化归为紧自伴积分算子的特征值问题。
> 这是谱定理最古老也最深远的应用。——§II.6 的主题（意译）

Sturm-Liouville 理论是泛函分析的诞生地之一：Fourier 的热传导
方程、振动弦问题、量子力度的薛定谔方程，都是 Sturm-Liouville 系统。
本章覆盖 Conway §II.6 的核心：如何把微分算子转化为紧积分算子，
然后用谱定理求解。

## 12.1 Sturm-Liouville 系统的定义

**定义（Conway 6.1-6.3）**。[a,b] 是有限区间。考虑微分方程

−h'' + qh − λh = f

其中 q ∈ C[a,b]，λ ∈ ℂ，f ∈ L²[a,b]，加上**分离边界条件**：

αh(a) + α₁h'(a) = 0，βh(b) + β₁h'(b) = 0

（α² + α₁² > 0，β² + β₁² > 0）。方程 + 边界条件 = **正则
Sturm-Liouville 系统**。

**算子形式**：𝒟 = {h ∈ C²[a,b] : 满足边界条件}，
L: 𝒟 → L²[a,b]，Lh = −h'' + qh。问题变为：给定 λ，什么时候
ran(L − λ) = L²[a,b]（方程有解）？

## 12.2 Green 函数

关键思路：**积分是微分的逆**。定义 (L−λ)⁻¹（当它存在时）是
积分算子，其核就是 **Green 函数**。

设 ker L = {0}（假设 6.4；否则平移 λ）。取两个线性无关的齐次解：

- hₐ ∈ 𝒟ₐ（满足左边界条件），L hₐ = 0；
- h_b ∈ 𝒟_b（满足右边界条件），L h_b = 0。

**Wronskian** W(x) = hₐ(x)h_b'(x) − hₐ'(x)h_b(x) 是常数（非零，
由 ker L = {0}）。令 c = −W(a)。

**Green 函数（Conway 6.7）**：

g(x,y) = c⁻¹hₐ(x)h_b(y)（x ≤ y），c⁻¹hₐ(y)h_b(x)（y ≤ x）。

g 连续、实值、对称：g(x,y) = g(y,x)。

## 12.3 Green 算子的性质

**定理（Conway 6.9）**。假设 6.4。定义
(Gf)(x) = ∫ₐᵇ g(x,y)f(y)dy。则：

1. **G 是紧自伴算子**（核对称 + L² 核 ⟹ Hilbert-Schmidt ⟹ 紧）；
2. **ran G = 𝒟**（G 的值域恰好是微分方程的定义域）；
3. **LGf = f** 对所有 f ∈ L²[a,b]（G 是 L 的右逆）；
4. **GLh = h** 对所有 h ∈ 𝒟（G 也是 L 的左逆）。

**证明思路**。(1) 由 4.7（Hilbert-Schmidt 核给出紧算子）。
(2)-(4) 分部积分 + Green 函数的跳跃条件：
g 在 x = y 处连续但 ∂g/∂x 有跳跃 c⁻¹，这恰好使二阶导数产生
δ 函数效应。∎

## 12.4 特征值分解

**推论（Conway 6.10）**。Lh = λh ⟺ Gh = λ⁻¹h。
L 的特征值 λ ≠ 0 对应 G 的特征值 1/λ。

**引理（Conway 6.11）**。α ∈ σₚ(G)，α ≠ 0 ⟹ dim ker(G−α) = 1
（**简单特征值**：二阶 ODE 只有两个线性无关解，边界条件砍掉一个）。

**定理（Conway 6.12）**。假设 6.4。则存在实数列 (λₙ) 和
L²[a,b] 的标准正交基 (eₙ)，使：

- (a) 0 < |λ₁| ≤ |λ₂| ≤ ...，|λₙ| → ∞；
- (b) eₙ ∈ 𝒟 且 Leₙ = λₙeₙ；
- (c) λ ≠ λₙ ∀n ⟹ (L−λ) 可逆（方程有唯一解）；
- (d) λ = λₙ ⟹ 方程有解 ⟺ f ⊥ eₙ（Fredholm 二择一）。

**证明**。G 紧自伴 ⟹ 谱定理（第 11 章）给出 G = Σ αₙPₙ。
αₙ = 1/λₙ，λₙ = 1/αₙ → ∞（因 αₙ → 0）。简单性由 6.11。∎

## 12.5 经典例子

**例（Conway 习题 1a）**。L = −d²/dx²，[0,1]，h(0) = h(1) = 0。
- 特征值：λₙ = n²π²；
- 特征函数：eₙ(x) = √2 sin(nπx)——**Fourier 正弦基**；
- Green 函数：g(x,y) = min(x,y)(1−max(x,y))。

这就是** Fourier 正弦级数的泛函分析解释**：三角函数系不是
偶然的，它是微分算子的特征基。一般的 Sturm-Liouville 系统
给出"广义 Fourier 级数"。

## 12.6 数值实验

**Julia**（`12_sturm-liouville.jl`）：
(1) **Green 函数验证**：G·sin(πx) = sin(πx)/π²（误差 < 10⁻⁴）；
(2) **特征值**：G 的前 5 个特征值 ≈ 1/(k²π²)（误差 < 1%）；
(3) **特征函数**：第 3 个特征向量与 sin(3πx) 的余弦相似度 > 0.999。
