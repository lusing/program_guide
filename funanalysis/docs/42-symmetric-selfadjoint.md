# 42 · 对称、自伴与 Cayley 变换

> 对称是代数条件，自伴是拓扑条件——无界世界里两者分道扬镳。

本章覆盖 Conway §X.2–§X.3：对称算子、亏指数、自伴扩张的
存在唯一性、Cayley 变换的对应。

## 42.1 对称 vs 自伴

设 T 稠定。**对称**：⟨Tx, y⟩ = ⟨x, Ty⟩ 对一切 x, y ∈ Dom(T)
（⟺ T ⊆ T*，图包含）。**自伴**：T = T*（含域相等！）。

- 有界情形：对称 ⟺ 自伴（域被迫是全空间）；
- 无界情形：对称只给 **T ⊆ T***，中间的差距
  Dom(T*) \ Dom(T) 就是"扩张的空间"。

**反例主角**：T = i d/dx 在 L²[0,1]，
Dom₀ = {H¹ 函数：f(0) = f(1) = 0}（最小域）。
分部积分给对称性；但 T* 的域只要求 f(0) = f(1)
**边界值存在**（H¹），中间差一个二维的边界自由度。

## 42.2 自伴扩张与亏指数

**定理（von Neumann）**。T 对称。定义**亏子空间**

  N± = ker(T* ∓ i)，   n± = dim N±（**亏指数**）。

则 T 有自伴扩张 ⟺ **n₊ = n₋**；
扩张与 N₊ → N₋ 的酉算子 U 一一对应：

  Dom(T_U) = Dom(T) ⊕ (I + U)N₊，T_U = T* 限制其上。

对称算子的自伴扩张是**一个家族**，由一个酉参数标记。
数值化身：-d²/dx² 在 [0,1] 的三种扩张
（DD / NN / DN）谱各不同——(nπ)²、n²π² 含 0、((n+½)π)²——
同一个微分表达式的不同"边界条件"给出不同算子。

**本质自伴**：闭包唯一 ⟺ n₊ = n₋ = 0
（只有一个自伴扩张，物理上"边条件被方程自己决定"）。

## 42.3 Cayley 变换

**定义**。T 对称 ⟹ ±i ∈ ρ(T) 的替代品：
**Cayley 变换** U_T = (T - i)(T + i)⁻¹，
Dom = ran(T + i)。

**定理**。
- T 对称 ⟹ U_T **等距**（保内积）；
- T 自伴 ⟺ U_T **酉**；
- 对应可逆：对称算子 ↔ 等距算子（ran(I-U) 稠），
  自伴算子 ↔ 酉算子——**谱分析变成酉群分析**。

数值化身：自伴矩阵 A 的 (A-i)(A+i)⁻¹
特征值全落在单位圆上、算子严格酉（残差 < 10⁻¹²）。
无界对称算子的 Cayley 变换把虚轴谱搬到单位圆——
第 43 章 Stone 定理的入口。

## 42.4 判据工具箱

- **对称 ⟹ 可闭**，T̄ 对称；
- T 自伴 ⟺ T 闭对称 且 ran(T ± i) = H
  （±i 都是预解点）；
- **半有界对称算子**（⟨Tx,x⟩ ≥ c‖x‖²）必有自伴扩张
  （Friedrichs 扩张，取闭二次型的域）——
  Schrödinger 理论的地基；
- Kato-Rellich：T 自伴 + V 对称相对有界（界 < 1）
  ⟹ T + V 自伴。

## 42.5 物理坐标

量子力学的可观测量 = 自伴算子（不是对称！）：
- 动量 -i d/dx 在半直线 [0,∞)：n₊ = n₋ = 1——
  一维参数族自伴扩张，参数 = 边界相位（物理：墙上怎么反射）；
- 不自伴的"可观测量"导致概率不守恒（虚谱 ⟹ 指数增长模）。

数值实验的三谱对比正是这句话的化身：
**边条件 = 物理**。
