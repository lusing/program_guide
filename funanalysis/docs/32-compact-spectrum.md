# 32 · 紧算子的谱理论

> 紧算子的谱长得几乎像有限维：可数、离散、只聚于 0。

本章覆盖 Conway §VII.7：紧算子谱的完整结构定理
（Riesz–Schauder 理论）、Fredholm 二择一、紧正规算子的对角化
（与第 13 章呼应）。

## 32.1 谱结构定理

**定理（Riesz–Schauder）**。X Banach，T ∈ B(X) 紧，X 无穷维。
则：
1. σ(T) \ {0} 的每点都是**特征值**，且特征空间**有限维**；
2. σ(T) 至多可数，唯一可能的聚点是 0；
3. 0 ∈ σ(T)；
4. 对应不同特征值的特征空间线性无关（正常）且
   非零谱点总数按重数计的求和 ‖·‖-离散。

**证明骨架（要点）**。
- λ ≠ 0 时 T - λ 写成 -λ(I - λ⁻¹T)，其中 λ⁻¹T 紧；
  Riesz 理论把问题化为 I - 紧 的分析；
- 特征空间有限维：单位球在紧算子下的像是准紧集，
  无穷维特征空间会违反 Riesz 引理；
- 谱点聚点若 λ* ≠ 0，取互异 λₙ → λ*，对应特征向量 xₙ，
  构造近乎正交的序列推出 (T - λ*)xₙ 有下界 → 与紧性矛盾。∎

## 32.2 Fredholm 二择一

**定理（Fredholm alternative）**。K 紧，λ ≠ 0。则：

  要么 (K - λ)x = y 对一切 y 可解，
  要么 (K - λ)x = 0 有非零解——两者恰居其一。

**证明核心**：I - λ⁻¹K 的核有限维、值域闭（Riesz 引理链），
dim ker = codim ran（指标为零，第 45 章正式化），
由 dim ker = 0 ⟹ ran 全空间。∎

这是积分方程理论的中枢：**唯一性 ⟹ 存在性**。
对 Fredholm 积分方程 φ - λKφ = f，
"齐次方程只有零解"直接推出"非齐次方程处处可解"——
有限维线性代数的直觉在紧扰动下完整存活。

## 32.3 紧正规算子：谱定理的预演

T 紧正规（Hilbert 空间）时结构完全透明：

**定理**。存在**有限或趋于 0 的**序列 (λₙ) 与一列
有限秩正交投影 Pₙ（两两正交），使

  T = Σₙ λₙ Pₙ（范数收敛）。

这就是第 13 章紧正规算子谱定理——现在可以从泛函演算的
角度重新看它：σ(T) = {λₙ} ∪ {0}，每个孤立点 λₙ 的
Riesz 投影（第 31 章）**恰是**特征空间投影 Pₙ，
T 的全部信息 = 谱点 + 特征空间。

数值上：对角截断 diag(1/k) 是最纯的模型——谱值 1/k
按模降序趋于 0，特征空间 = 坐标轴；
严格下三角扰动不改谱（三角阵谱 = 对角元），
展示 Riesz–Schauder 的"结构不变"面。

## 32.4 拟幂零算子

**定义**。σ(T) = {0} 的算子称**拟幂零**。

紧算子可以拟幂零：Volterra 算子 (Vf)(x) = ∫₀ˣ f(t) dt。
‖Vⁿ‖ ≤ 1/n! ⟹ r(V) = 0。它**没有特征向量**（ker V = 0），
谱 = {0} 却"无谱可看"——谱理论与对角化理论的分水岭：
**谱离散 ⟹ 可分解（Riesz 投影），但不 ⟹ 可对角化**。

数值化身：离散化 (h·下三角全 1 矩阵) 的谱半径随加细
n = 20 → 400 单调收缩向 0，正是 r(V) = 0 的有限维逼近。

## 32.5 紧摄动下的谱稳定性

谱在紧摄动下"本质部分"不动：
σ(T + K) 与 σ(T) 至多差可数个离散点，聚点结构保持
（第 46 章本质谱的入口）。有限维直觉：
A + 扰动只移动特征值的位置，不改变"有个谱"这件事。
