# 70 · 勒贝格积分与 L^p：从区间长度到完备化

> 狄利克雷函数的达布大和恒为 b−a、小和恒为 0——黎曼积分对它束手无策。
> 勒贝格的改造：不切定义域，切**值域**；"性质不好的点"只要凑成零测集，
> 就对积分毫无贡献。——《工科泛函分析基础》1.4 节（意译）

本章是第四卷（工科篇）的第一章。前三卷分别以 Conway、Lax、Rudin 为纲，
默认读者已有测度论背景；本卷底本是《工科泛函分析基础》（2019），它的
定位是从高等数学与线性代数出发、只用最少的抽象工具把泛函分析讲通。
其中 1.4 节的勒贝格积分简介是全书的地基，而前三卷恰好没有一章自包含
地重建过这套地基——本教程 01 章讲拓扑与 Baire 纲，14 章把 L^p 完备性
当作 Banach 空间的例子一句话带过。本章按书 1.4 + 1.7 的路线补上这块：
**外测度 → 可测集 → 可测函数 → 切值域的积分 → 三大收敛定理 →
L^p 空间与 Riesz-Fischer 完备性**，全程不引用书外文献。

## 70.1 黎曼积分的两宗罪

黎曼积分的定义（书 1.4.1）：对 [a,b] 作分割 Δ，在每个小区间上取
f 的上确界与下确界，作达布（Darboux）大和与小和；当分割加细时
大小和趋于同一个数 I，就称 f 黎曼可积。

这个定义有两处先天的短板，它们正是勒贝格改造的动机。

**第一宗罪：可积函数类太小。** 狄利克雷函数

```
D(x) = 1（x 为有理数），0（x 为无理数）
```

在任意小区间上总有最大值 1、最小值 0（有理数与无理数都稠密），于是
**任何**分割下大和恒为 b−a、小和恒为 0（书例 1.4.2）。inf 与 sup
永远夹不拢，D 黎曼不可积——尽管它有界、且"坏点"（取值 1 的点）在
直觉上少得可以忽略。

**第二宗罪：极限换序的门槛太高。** 黎曼理论里，从 fₙ → f 推出
∫fₙ → ∫f 需要一致收敛（书 1.3.9）——这是一个全局条件，验证起来
往往比结论本身还难。分析学真正需要的是**逐点**收敛加一个可积控制，
这就是后文 70.6 的控制收敛定理。

病根在于黎曼"切定义域"：它要求函数在每个小区间上振动很小，狄利克雷
函数在每个小区间上都满幅振荡，于是处处碰壁。勒贝格改切值域——先数
清楚"取值落在 [yₖ₋₁, yₖ) 的点有多少"（这正是测度要做的事），坏点
集的测度为零就自动出局。Julia 实验 1（`examples/julia/70_lebesgue_lp.jl`）
把这两宗罪变成了可运行的证据：浮点数全是有理数，逐点求值 D(x) ≡ 1，
"黎曼式"逐点平均给出 1；而勒贝格真值是 0。语义鸿沟一目了然——
逐点采样原理上看不见测度，因为非理点占满测度，浮点格点却全是有理点。

## 70.2 数一数：可数集

要度量"点集有多少"，先把无穷分出层次。

**定义（可数集，书 1.4.3）**。集合 X 与正整数集 Z₊ = {1,2,...} 之间
存在一一对应，就称 X **可数**。等价地，X 的元素可以排成无穷序列
X = {a₁, a₂, ...}。

**例（ℚ 可数，书 1.4.4）**。每个有理数唯一写成既约分数 p/q（q > 0）。
按 N = |p| + q 把分数装桶：N = 1 时只有 0/1；N = 2 时是 −1/1, 1/1；
N = 3 时是 −2/1, −1/2, 1/2, 2/1……每个桶有限，桶按 N 排序，桶内按
字典序排——全体有理数就排成了一列。Prolog 实验 1
（`examples/prolog/70_lebesgue_lp.pl`）把这套桶排列写成了可运行的
枚举程序 `rationals_by_level/3`：对 N ≤ 4 枚举出 11 个既约分数，
`p_q(1,2)`（即 1/2）在列——"可数 = 可编号"从口号变成了查询。

同样的桶技巧给出：**可数个可数集之并可数**；有理系数多项式全体可数
（书 1.4.5，按系数高度装桶）。反过来，任何区间、实数集、无理数集都
不可数（对角线论证，书 1.4 节引用文献，此处不展开——本教程 24 章
Stone-Čech 一节给过更强的基数事实）。

## 70.3 量一量：外测度、可测集与零测集

有了"多少"，还要"多长"。

**定义（外测度，书 1.4.6）**。E ⊆ ℝ 有界，称

```
m*(E) = inf { Σᵢ (bᵢ − aᵢ) ： E ⊆ ∪ᵢ (aᵢ, bᵢ) }
```

为 E 的**外测度**——用可数个开区间覆盖 E，区间长度之和的下确界。

**定义（可测集，书 1.4.7）**。若外测度满足可加性：对一切 A、B ⊆ ℝ，

```
m*(A ∪ B) = m*(A) + m*(B)   （当 A ∩ B = ∅）
```

则称 E **勒贝格可测**，其测度记 m(E) = m*(E)。无界集用截断极限
定义（书 1.4.8）：m(E) = lim_{α→∞} m(E ∩ (−α, α))。

书里把"可测"直接定义为"外测度可加"，把 Carathéodory 判据的完整
理论藏在文献里——这是工科路线的典型取舍：**只用结论，不造机器**。
本教程 67 章（Rudin 卷广义函数）给过分布理论的完整版；测度论的
完整构造在机器世界里由 mathlib 的 `MeasureTheory.Measure` 层级
承担（数万行工程），本章 70.8 只在应用层做形式化。

**性质（书 1.4.9）**：开集、闭集可测；可数个可测集的交并与余集可测
（σ-代数封闭性）。Prolog 实验 3 把封闭性写成规则：

```prolog
measurable(open_interval).
measurable(complement(E)) :- measurable(E).
measurable(union(E, F))  :- measurable(E), measurable(F).
measurable(inter(E, F))  :- measurable(E), measurable(F).
```

查询 `measurable(union(complement(cantor), inter(rationals,
open_interval)))` 一步命中——σ-代数"对补与可数并封闭"在规则引擎里
就是三条子句，这是本章最直观的机器化。

**定义（零测集，书 1.4.10）**。对任意 ε > 0 存在开区间覆盖使总长
< ε，就称 E 零测。**可数集零测（书例 1.4.11）**：把 E = {a₁, a₂, …}
编号后，第 i 个点配半径 ε/2ⁱ⁺¹ 的区间——总长恰为 ε，与点数无关。

这个 ε/2ⁱ 编号衰减是"可数性送的红利"：Julia 实验 1 的对照组里，
M = 100 000 个点配 ε/2ⁱ 覆盖总长仍 ≤ ε = 10⁻⁴；而若给每个点配
**固定**半径 δ，无穷多个点的总长就是 ∞·δ——固定半径对无穷集破产，
只有编号衰减才扛得住。Prolog 实验 2 的 `total_cover/3` 同样验证
M = 30 与 M = 100 的总长都贴住 ε 上界。

**例（康托尔集，书 1.4.13）**。从 [0,1] 挖去中间三分之一开区间，再
对剩下两段各挖中间三分之一……第 k 步共挖去 2ᵏ⁻¹ 个长 3⁻ᵏ 的开区间，
剩余测度 (2/3)ᵏ → 0。但 Cantor 集不可数（与 [0,1] 一一对应：三进制
展开只用 0 和 2 的点集）。**零测 ≠ 可数**——这是"测度不是计数"的
第一个警示。Julia/Python 双通道都验证了它：Python 实验 4
（`examples/python/70_lebesgue_lp.py`）追踪 60 步后剩余测度
2.7 × 10⁻¹¹，并以 20 万随机采样命中率为零复核；Prolog 实验 4 的
`cantor_removed/2` 用前缀和给出 step10 → 0.017、step20 → 0.0003。

## 70.4 可测函数

**定义（书 1.4.14）**。f 是可测集 E 上的广义实值函数，若对一切
a ∈ ℝ，截口集 E(f < a) = {x ∈ E : f(x) < a} 可测，就称 f **可测**。

判据里的 `< a` 可以换成 ≤、>、≥ 任一形式。三个立刻的例子：
连续函数可测（开集的原像是开集——Python 习题 8 的证明方向）；
**狄利克雷函数可测**（例 1.4.16：{D ≤ a} 是 ℝ、ℚ 或 ℝ∖ℚ，都可测）；
可测函数列的逐点极限可测（例 1.4.17）——第三条是收敛定理的入场券，
它保证了 lim fₙ 这个函数本身"配谈测度"。

**几乎处处（a.e.，书 1.4.12）**。两函数除一个零测集外相等，记
f = g a.e.。狄利克雷函数 = 0 a.e.（ℚ 可数零测）——它在测度世界的
"真实身份"就是零函数。这也解释了 70.1 的数值鸿沟：逐点求值问的是
"这一点值多少"，积分问的是"值的分布如何"，两个问题在零测集上
可以给出完全相反的答案。

## 70.5 切值域：勒贝格积分的定义

**有界情形（书 1.4.18）**。f 在 E 上可测有界，值域含于 [α, β]。
对值域作分割 α = y₀ < y₁ < … < yₙ = β，令

```
Eₖ = {x ∈ E : yₖ₋₁ ≤ f(x) < yₖ}
```

作**勒贝格大和与小和** S_L = Σ yₖ m(Eₖ)、s_L = Σ yₖ₋₁ m(Eₖ)。
当分割加细时 inf{S_L} = sup{s_L} = I，就定义 ∫_E f dx = I。

对比达布和：黎曼按 x 切条，每条问"函数这窗里最高多高"；勒贝格按
y 切层，每层问"这层值的点集多宽"。狄利克雷函数只有两个值层：
值 1 的层 E₁ ⊆ ℚ 测度零、值 0 的层测度 m(E)——于是大和小和全部
塌缩到同一个数，**D 的勒贝格积分为 0**（书例 1.4.19）。一句口诀：
∫ D dx = 1 × m(ℚ ∩ E) + 0 × m(E ∖ ℚ) = 1 × 0 + 0 × m(E) = 0。

**非负函数（书 1.4.20）**。截断 fₙ = min(f, n)，令

```
∫_E f dx = lim_{n→∞} ∫_E fₙ dx
```

截断序列单调不降、每个 fₙ 有界——积分概念从有界函数沿单调极限
延伸到一切非负可测函数。Julia 实验 3 取 f(x) = x^{−1/4}（无界但
L¹ 可积，∫₀¹ = 4/3）：min(f, n) 随 n = 2, 4, …, 256 单调上升逼近
总积分，n = 256 时已收回 98% 以上——**单调收敛定理的定义性版本**
在数值上先行现身。

**零积判据（书 1.4.24）**：非负可测函数积分为零 ⟺ f = 0 a.e.。
**绝对连续性（书 1.4.25）**：非负可积函数满足——对任意 ε，存在 δ，
使 m(F) < δ ⟹ ∫_F f < ε。积分对小集合"连续"，这是后续把积分看成
测度（f dx 作为一个新测度）的根基。

## 70.6 三大收敛定理

现在可以正面回答 70.1 的第二宗罪了。设函数列都定义在可测集 E 上。

**Fatou 引理（书 1.4.26）**。{fₙ} 非负可测，则

```
∫_E liminf fₙ dx ≤ liminf ∫_E fₙ dx
```

不等号可以严格：滑动条反例 fₙ = 1_{[n,n+1]}——每个 ∫fₙ = 1，但
liminf fₙ = 0 逐点，∫liminf = 0。Julia 实验 2 在观察窗 [0,6] 上
数值复现：六个滑动条的积分全是 1，liminf 函数的积分是 0，差恰 1。
"质量可以滑向无穷远"——Fatou 允许积分漏掉逃逸的质量，只保证不多算。

**Levi 单调收敛定理（书 1.4.27）**。{fₙ} 非负递增（a.e.），逐点极限
f，则 ∫fₙ → ∫f。70.5 的截断定义已经用过它的精神；此时"漏质量"
被单调性堵死——质量只能往上叠，不能滑走。

**勒贝格控制收敛定理（DCT，书 1.4.28）**。若 |fₙ| ≤ F a.e.（F 可积，
称为控制函数），且 fₙ → f a.e.，则 f 可积且 ∫fₙ → ∫f。

DCT 把"一致收敛"换成了"逐点收敛 + 一个可积上界"，门槛骤降。书的
例 1.4.29 与习题 1.7 给了标准练习：fₙ(x) = 1/(1 + n²x²) 在 [0,1]
上逐点 → 0 且被 1 控制，故 ∫fₙ → 0（精确值 arctan(n)/n）。Python
实验 3 双向验证：被控制的一族积分确实归零；而姊妹序列 hₙ = n·1_{(0,1/n)}
逐点 → 0、积分恒为 1——它**没有**可积控制（尖峰高度 n 无界），
DCT 的前提不满足，结论也就不欠它。定理的前提与结论如此对称地
各自找到了数值化身。

三个定理的机器对应（Lean，`examples/lean/Funanalysis/Ch70Lebesgue.lean`）：

```lean
#check @MeasureTheory.lintegral_iSup          -- Levi 单调收敛
#check @MeasureTheory.lintegral_liminf_le'    -- Fatou
#check @MeasureTheory.tendsto_integral_of_dominated_convergence  -- DCT
```

mathlib 把它们造在非负积分（`lintegral`，值域 ℝ≥0∞）之上，再经
正负部分解转到 Bochner 积分——三层结构比书的陈述更细，但三具定理
内核与书一一对应。

## 70.7 L^p 空间与三大不等式

**定义**。1 ≤ p < ∞，可测函数 f 的 L^p 范数（ 书 1.7 的记号）：

```
‖f‖_p = ( ∫_E |f|^p dx )^{1/p}
```

‖f‖_p < ∞ 的函数按 a.e. 相等取等价类后构成 **L^p(E)**。

三大不等式（书 1.7"常用不等式"的主干）：

**Young 不等式**。p、q > 1 共轭（1/p + 1/q = 1），a, b ≥ 0：

```
ab ≤ a^p / p + b^q / q，等号 ⟺ a^p = b^q
```

它是 a^p/p 的凸性（切线在下方）的直接推论。Python 实验 2 用两万
组随机 (a,b) 验证不等式恒成立、等号判据在 a^p = b^q 处近似取等。

**Hölder 不等式**。对 f ∈ L^p、g ∈ L^q（共轭）：

```
∫ |fg| dx ≤ ‖f‖_p ‖g‖_q
```

证明是 Young 的逐点应用：对 |f|/‖f‖_p 与 |g|/‖g‖_q 用 Young 再积分，
各项恰为 1/p + 1/q = 1。p = q = 2 时它就是 Schwarz 不等式——Hilbert
空间理论的 L² 特例。

**Minkowski 不等式**。f, g ∈ L^p：

```
‖f + g‖_p ≤ ‖f‖_p + ‖g‖_p
```

证明把 |f+g|^p 拆成 |f||f+g|^{p−1} + |g||f+g|^{p−1}，两项各用
Hölder（指数对 (p, q = p/(p−1))，注意 |f+g|^{p−1} ∈ L^q）再除以
(‖f‖_p + ‖g‖_p)^{p−1}。这确立了 L^p 是赋范空间——三角不等式。

**Riesz-Fischer 定理**。L^p（1 ≤ p ≤ ∞）在上述范数下完备，是
Banach 空间。证明骨架（1 ≤ p < ∞）：取 Cauchy 列 {fₙ}，抽子列
使 ‖f_{n_{k+1}} − f_{n_k}‖_p ≤ 2^{−k}；部分和 g_K = Σ_k |f_{n_{k+1}} − f_{n_k}|
满足 ‖g_K‖_p ≤ 1（Minkowski + 等比级数），Fatou 给出 g = lim g_K
有限 a.e.——于是级数 f_{n₁} + Σ (f_{n_{k+1}} − f_{n_k}) 逐点绝对收敛
于某 f，且 f − f_{n_K} ∈ L^p、‖f − f_{n_K}‖_p ≤ (Σ_{k≥K} 2^{−k(p−1)...})^{...}
→ 0。Cauchy 性把整列拉回极限。∎（细节是标准的，此处按教程纪律给
全骨架；机器版本见下。）

回顾 2.4 节的完备化视角（书第 2 章）：C[0,1] 配 L¹ 距离 d(f,g)=∫|f−g|
不完备——斜坡函数列 xₙ（在 [1/2−1/n, 1/2] 上线性爬升）是 Cauchy 列
却收敛到阶跃函数，不在 C[0,1] 里。**L^p 正是那个补全后的空间**：
把"所有 Cauchy 列的极限"正式收编为成员。Riesz-Fischer 说的是这次
收编一步到位——完备化之后不再有新的洞。Julia 实验 4 用傅里叶部分和
sₙ(x) = Σ_{k≤n} k^{−1.1} sin(kπx) 演示：Parseval 等式给出 ‖s₂₀₀ − s_n‖₂²
= Σ_{k>n} aₖ²/2，尾项可精确计算——Cauchy 性与"极限函数在 L² 中"
都由数值直接复核（n=200 时尾范数 0.027）。

## 70.8 机器通道全览

本章五通道分工如下，全部代码可在 `examples/` 下运行。

**Lean（`Funanalysis/Ch70Lebesgue.lean`，主证通道）**。狄利克雷函数
的完整形式化是本章的招牌：ℚ 作为 ℝ 的子集（`Set.range Rat.cast`）
可数（`Set.countable_range`）⟹ 零测（`Set.Countable.measure_zero`）
⟹ D = 0 a.e.（`MeasureTheory.ae_iff` 把 a.e. 断言翻译成零测集方程）
⟹ 积分为零（`integral_congr_ae`）：

```lean
theorem dirichlet_integral_zero :
    ∫ x in Icc (0 : ℝ) 1, (if x ∈ Set.range (Rat.cast : ℚ → ℝ) then (1 : ℝ) else 0)
      ∂volume = 0 := by
  have hQ : volume (Set.range (Rat.cast : ℚ → ℝ)) = 0 :=
    Set.Countable.measure_zero (Set.countable_range _) _
  -- D ≠ 0 的点集 ⊆ ℚ ⟹ 零测 ⟹ a.e. 为零 ⟹ 换积分
  ...
  rw [integral_congr_ae hae]
  simp
```

证明里 `Measure.restrict_apply'` 把限制测度拆回交集测度——这套
"零测 ⟹ a.e." 的翻译链是 mathlib 测度论应用的日常。第二层是 L^p
成员资格的工具箱：`memLp_const`（常函数）、`memLp_indicator_const`
（示性函数——勒贝格大小和的基石）、`MemLp.of_le`（受控判据）；
第三层是收敛定理与完备性的锚点巡礼（70.6 的三个 `#check` 加
`MeasureTheory.Lp.instCompleteSpace`——Riesz-Fischer 的官方形态）。
mathlib 没有把"狄利克雷函数不可黎曼积分"形式化（黎曼积分本身在
mathlib 中只有 `Integrable` 的 Henstock-Kurzweil 版本），故黎曼一侧
由数值通道作证——诚实的通道分工。

**Julia（`julia/70_lebesgue_lp.jl`）**。四个实验：狄利克雷语义鸿沟 +
