# x86-64 汇编简介

## 什么是汇编语言

汇编语言（Assembly Language）是一种低级编程语言，它与计算机的机器指令几乎一一对应。每条汇编指令通常映射为一条机器码（Machine Code），但使用人类可读的助记符（Mnemonic）代替二进制编码。

例如，下面这条 NASM 语法指令将立即数 42 存入 RAX 寄存器：

```nasm
mov rax, 42          ; 机器码: 48 B8 2A 00 00 00 00 00 00 00
```

### 为什么要学习汇编

- **理解程序本质**：汇编让你看到 CPU 真正执行的指令，理解高级语言（C/C++/Rust）背后的运行机制。
- **性能优化**：在对延迟极度敏感的场景（游戏引擎、音视频编解码、加密算法）中，手写汇编可榨干硬件性能。
- **逆向工程与安全**：漏洞分析（Vulnerability Analysis）、恶意软件研究（Malware Analysis）、CTF 竞赛都需要阅读汇编。
- **系统编程**：编写引导加载器（Bootloader）、驱动程序、运行时库时，部分代码必须用汇编实现。
- **调试能力**：当高级语言调试器无法定位问题时，直接阅读汇编往往能找到根因。

## x86-64 架构发展简史

x86-64（又称 AMD64 / x64）是 x86 架构的 64 位扩展，其演进历程如下：

| 年份 | 里程碑 | 说明 |
|------|--------|------|
| 1978 | Intel 8086 | 16 位 x86 起源，20 位地址线，1MB 寻址 |
| 1985 | Intel 80386 | 首款 32 位 x86（IA-32），引入保护模式与分页 |
| 1995 | Pentium Pro | 引入乱序执行，奠定现代 x86 微架构基础 |
| 2003 | AMD Athlon 64 | 首款 64 位 x86 处理器，定义 AMD64 指令集 |
| 2004 | Intel EM64T | Intel 采纳 AMD64，后更名为 Intel 64 |
| 2011 | AVX | 引入 256 位高级向量扩展指令集 |
| 2013 | AVX2 | 扩展整数运算至 256 位 |
| 2017+ | AVX-512 | 512 位向量扩展，逐步在服务器与桌面平台普及 |

x86-64 相比 32 位的主要改进：

- 通用寄存器从 8 个扩展到 16 个，位宽从 32 位增至 64 位
- 虚拟地址空间从 4GB 扩展到 256TB（48 位虚拟地址）
- 新增 RIP 相对寻址（RIP-relative Addressing），利于位置无关代码（PIC）
- 增加 SSE2 作为基准指令集，保证所有 x64 处理器支持 SIMD

## CISC vs RISC

x86-64 属于 **CISC**（Complex Instruction Set Computer，复杂指令集计算机），与 ARM 等 **RISC**（Reduced Instruction Set Computer，精简指令集计算机）形成对比：

| 特性 | CISC（x86-64） | RISC（ARM64） |
|------|---------------|---------------|
| 指令长度 | 可变长度（1-15 字节） | 固定长度（4 字节） |
| 指令数量 | 数千条，功能丰富 | 精简，单条指令功能单一 |
| 寻址模式 | 丰富，支持内存参与运算 | 较少，运算仅在寄存器间（Load/Store 架构） |
| 典型指令 | `add rax, [rbx+rcx*4+8]` 内存直接参与加法 | 必须 `ldr`/`str` 先加载到寄存器再运算 |
| 硬件复杂度 | 解码器复杂，内部转换为微指令（μops） | 解码简单，直接执行 |

> 现代 x86 处理器内部实际上将 CISC 指令拆解为类 RISC 的微操作（Micro-ops）后乱序执行，因此 CISC 与 RISC 的界限在现代硬件上已逐渐模糊。

## 汇编语言的应用场景

1. **性能关键路径（Performance-critical Code）**
   编解码器（FFmpeg）、加密库（OpenSSL）、数学库（BLAS）的核心循环常用汇编手写优化。

2. **逆向工程与安全研究（Reverse Engineering & Security）**
   分析闭源软件行为、挖掘漏洞、编写漏洞利用（Exploit）时，汇编是必备技能。

3. **系统底层开发（Systems Programming）**
   操作系统内核上下文切换、中断处理、引导代码等无法用高级语言实现的部分。

4. **嵌入式与固件（Embedded & Firmware）**
   在资源受限或需要直接操控硬件寄存器的场景中，汇编不可或缺。

5. **编译器后端（Compiler Backend）**
   理解汇编有助于阅读编译器生成的代码，进而优化源码或调试编译器本身。
