# 22 · 定点与十进制实数

> 示例：[`examples/ch22_fixed.adb`](../examples/ch22_fixed.adb)
> 运行：`./run-all.sh 22`

[03 章](03-types.md)的浮点是"给个相对精度，机器随便放"；本章讲 Ada
实数类型的另一半——**定点类型（fixed point）**：精度和范围都由你钉死，
硬件按纯整数运算。何诚第 16 章"实数类型"用半本书的篇幅讲清了动机，
结论今天一个字不用改：

> 浮点给的是**相对精度**（数值计算的最爱），但要专用硬件或慢速模拟；
> 定点给的是**绝对精度**，只用整数运算——实时系统、数字信号处理、
> 控制系统的选择。

Ada 在这点上依然独树一帜：**定点类型是标准语言的一部分**，钱该算准
就算得准，滤波器该快就快，不靠第三方库。

## 22.1 定点的心智模型：小数点是"虚"的

老教材的十进制例子最直观：四位数字、小数点位置由类型记住——

- `02.40` 与 `0.240` 在硬件层**都是整数 0240**；
- 它们**不能直接相加**（小数点位置不同）——要么前者 ÷10、要么后者 ×10，
  **对齐刻度**后才能算；
- 乘法 `02.46 × 2.000` 硬件做 `246 × 2000 = 492000`，结果的刻度是
  两刻度之和（2+3=5，即 `04.92000`）——**几乎双倍长**，落地前必须
  重新定刻度（截位）。

这个小数点位置叫**刻度**，Ada 里就是 **delta**。上表换成 Ada 语法：

| 十进制演示 | Ada 里的对应 |
|-----------|-------------|
| 刻度 | `delta`（请求精度）/`'Small`（实际刻度，必为 2 的幂或 10 的幂） |
| "对齐刻度后加减" | 只有**同类型**（同刻度）才能加减 |
| "乘积双倍长、截位落地" | `F * F` 结果是**通用定点**，必须类型转换后才能赋值 |
| `02.40 × 10` | `V * 10`（定点 × 整数 → 同类型） |

## 22.2 普通定点：`delta` + `range`

```ada
type Volts is delta 0.25 range -100.0 .. 100.0;
```

三件事必须同时看懂：

1. **`delta 0.25` 是请求**——实际刻度 `'Small` 是不超过它的最大
   2 的幂（0.25 恰是 2⁻²，被原样采纳；`delta 0.01` 会被实现成
   1/128，因为 0.01 不是 2 的幂）。
2. **`range` 必写**（类型定义里不能省，这是定点与浮点的语法差异）；
   位数由 delta 和 range 共同推出：本例 `Volts'Size = 10` 位。
3. **同类型才能加减；结果是同类型**——精度永不"漂移"。

实跑：

```text
  Volts'Delta =  2.50000E-01（请求的精度）
  Volts'Small =  2.50000E-01（实际刻度 = 2 的幂）
  Volts'Size  =  10 位
  1.25 + 0.5 =    1.75 —— 可精确判等: TRUE
  1.25 + 0.1  =>    1.25   （0.1 被舍入到最近刻度）
```

判等 `A + B = 1.75` 敢用 `=`（浮点代码的头号禁忌），因为值域就是
0.25 的整数倍集合；`+ 0.1` 立刻被舍到最近刻度——**误差在每次落点
处显式发生**，而不是藏在尾数里发酵。

## 22.3 十进制定点：钱的家

普通定点的刻度是 2 的幂，`0.01` 存不进；**十进制定点（decimal
fixed point）**的刻度是 **10 的幂**，专治货币：

```ada
type Money is delta 0.01 digits 8;   -- 精度 1 分，共 8 位十进制数字
```

`digits 8` 替代 range（±999999.99）；`'Small = 0.01` 恰是 10 的幂。
三段实测：

```text
  0.10 + 0.20 = 0.30 ?  TRUE    （十进制刻度，精确）
  Money'Small =  1.00000E-02（= 0.01，10 的幂）
  3 x 0.33 摊 1.00，余 0.01 元 —— 精确可追溯
```

对照浮点的灾难（本示例第 1 段实测）：

```text
  Long_Float: 0.1 + 0.2 = 0.3 ?  FALSE   （二进制存不准 0.1）
```

分账、计息、发票，差额必须可解释——十进制定点让每一分钱的去向
都是**精确算术**而非"近似后四舍五入"。顺带一提：COBOL 靠这个吃饭
吃了六十年，Ada 把同样的能力放进了通用类型系统。

## 22.4 通用定点与单位常量：乘除的正确姿势

定点乘除的核心规则（编译器**强制**你重定刻度）：

```ada
V / R          -- F / F → 通用定点（universal fixed，双倍长）
A * B          -- F * F → 通用定点
V * 3          -- F * Integer → 同类型 F（整数缩放）
1000.0 * V     -- 编译不过！实数字面量不能与定点直接相乘
```

通用定点"精度任意好"但**不能直接落地**——赋值前必须类型转换。
实数比例因子怎么办？老教材（及全世界的 Ada 数值代码）用**单位常量**：

```ada
type Ohms      is delta 0.5 range 0.0 .. 1000.0;
type Milliamps is delta 0.5 range 0.0 .. 5000.0;

Amp : constant Milliamps := 1000.0;    -- 单位常量：1 安培 = 1000 毫安

I : Milliamps := Milliamps (Milliamps (V / R) * Amp);
--               └─转换①─┘└──── F*F → 通用定点 ────┘└─转换②─┘
--               5.0V / 2.5Ω = 2.0 → 2.0 * 1000.0 = 2000.0 mA
```

两次转换各自完成一次"定刻度"：①把通用商落到 Milliamps 的刻度，
②把乘积再落回去。`Duration`（`delay 0.1` 用的那个类型）就是标准库
里活生生的普通定点，`Ada.Real_Time` 的时间量同理——你在 15 章用过的
每一个 `delay`，底下都是本章的运算。

## 22.5 案例：三阶切比雪夫滤波器的定点实现（何诚 §16.5）

数字信号处理的教科书场景：对采样信号做低通滤波，差分方程

```text
y(n) = C1·(x(n) + 3x(n-1) + 3x(n-2) + x(n-3))
       + C2a·y(n-1) − C2b·y(n-2) + C2c·y(n-3)

C1 = 0.011956,  C2a = 1.9749,  C2b = 1.5243,  C2c = 0.4538
```

何诚的**类型设计**是本案例的精华——每个量一个专门类型，16 位机
的每一比特都花在刀刃上：

```ada
type Xfix is delta 1.0        range -16384.0 .. 16383.0;  -- 输入：整数样值
type Yfix is delta 2#1.0#E-4  range -2048.0 .. 2047.0;    -- 输出：1/16 刻度
type Zfix is delta 2#1.0#E-17 range -8192.0 .. 8191.0;    -- 中间量：双倍长
type C1fix is delta 0.000001  range 0.0 .. 0.02;          -- 前馈系数
type C2fix is delta 0.0001    range 0.0 .. 20.0;          -- 反馈系数
```

选型理由（照抄老教材，条条是嵌入式工程学）：

- **Xfix delta 1.0**：ADC 样本本来就是整数，`x + 3(x+x) + x` 的
  最大值决定范围放宽到 ±16384；
- **Yfix** 刻度取 2⁻⁴：同样 16 位，滤波器增益 ≤1 → 范围 ±2048 够用，
  把省下的位全换成精度；
- **Zfix** 是"双倍长"中转站：`2#1.0#E-17` 的刻度让乘积在截位前
  保留最大精度——老教材算术表里"乘积几乎双倍长"的落点；
- **系数类型**范围卡到刚好（C1 ∈ 0..0.02）——越界即编译错误，
  把"系数抄错"扼杀在编译期。

核心运算（注意每个表达式的类型转换都是**必须**的，不是装饰）：

```ada
Z := Zfix (C1 * (Xn + 3 * (Xn1 + Xn2) + Xn3));   -- 前馈：C1fix*Xfix→通用→Zfix
Yn := Yfix (Z + Zfix (C2a * Yn1)                  -- 反馈：乘积先落 Zfix
                 - Zfix (C2b * Yn2)
                 + Zfix (C2c * Yn3));
Xn3 := Xn2; Xn2 := Xn1; Xn1 := Xn;               -- 移位历史
Yn3 := Yn2; Yn2 := Yn1; Yn1 := Yn;
```

给幅度 1000 的冲激输入，前 12 拍输出（全定点、逐位可复现）：

```text
  n      x(n)      y(n)
  0     1000      11.9375
  1        0      59.4375
  2        0     135.0000
  3        0     193.3750
  4        0     203.0625    <- 峰值
  5        0     167.5000
  6        0     109.0000
  7        0      52.0625
  8        0      12.6250
  9        0      -4.9375    <- 轻微过冲后收敛（低通特性）
  10        0      -5.3125
  11        0       2.7500
```

低通滤波器的冲激响应：快速爬升、轻微振铃、指数收敛——定点算术
把每一个 1/16 刻度的台阶都钉死了，**换一台支持同类型的机器结果
逐位相同**（浮点做不到这一点，这是可移植数值算法的圣杯）。
真实系统里把输入输出换成 ADC/DAC 任务的会合
（[17 章](17-select-family.md)何诚原版就是这么接的），本例用确定性
数组换掉设备以便教学验证。

## 22.6 属性速查

| 属性 | 含义 |
|------|------|
| `F'Delta` | 请求的精度 |
| `F'Small` | 实际刻度（普通定点=2 的幂；十进制=10 的幂） |
| `F'Size` | 表示位数 |
| `F'Fore` / `F'Aft` | 文本 IO 的整数位/小数位默认值 |
| `Flt'Digits` | 浮点：请求的十进制有效位 |
| `Flt'Machine_Mantissa` | 浮点：实际尾数二进制位 |
| `Flt'Epsilon` / `Flt'Model_Small` | 浮点模型参数（老教材 §16.4 详述） |

## 22.7 常见坑

1. **实数字面量直接乘定点**：`1000.0 * V` 编译不过——比例因子
   做成**定型的单位常量**（22.4）。
2. **通用定点直接赋值**：`Z := C1 * X;` 编译不过——每步落地都要
   `T (...)` 转换。这不是冗余，是你在**显式选择舍入点**。
3. **delta 不是 2 的幂时想精确**：`delta 0.01` 的普通定点实际刻度
   1/128，存不进 0.01——要十进制精确就**必须**用十进制定点
   （`delta 0.01 digits N`）。
4. **定点类型定义漏 range**：语法错误；只有子类型/对象约束可以省。
5. **范围照抄浮点习惯**：定点位数由 delta+range 联合推出，范围
   放太宽就吃掉精度（同一 16 位，二者此消彼长——见滤波器选型）。
6. **定点判等可以、浮点判等不行**：`F1 + F2 = F3` 在浮点是经典
   bug（本示例实测 FALSE），在定点反而安全——别把浮点习惯
   带进定点，也别反过来。

## 22.8 小结

| 类型 | 刻度 | 典型场景 |
|------|------|---------|
| 浮点 `digits N` | 相对精度 | 科学计算、图形 |
| 普通定点 `delta D range R` | 2 的幂 | DSP、控制、`Duration` |
| 十进制定点 `delta D digits N` | 10 的幂 | 货币、计量、报表 |

Ada 把"实数怎么表示"从机器手里拿了回来：**delta 是你的合同，
类型是你的刻度尺**。至此，类型系统之旅（03 → 08 → 09 → 21 → 22）
全部走完——下一章回到工程现场，看标准容器库怎么替你干活。
