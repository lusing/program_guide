# 04 · 项

> 对应示例：[`examples/04_terms/04_terms.pl`](../examples/04_terms/04_terms.pl)

## 4.1 只有一种数据结构

别的语言有 `int` / `string` / `array` / `struct` / `object` 一堆类型；**Prolog 只有一种
东西：项（term）**。它由四种零件拼成：

| 零件 | 例子 | 判断谓词 | 说明 |
|---|---|---|---|
| 原子 atom | `apple` `'Hello World'` `+` `[]` | `atom/1` | 小写开头，或引号包起来；**自身就是值** |
| 数字 number | `42` `-7` `3.14` | `number/1` `integer/1` `float/1` | 整数与浮点是两个子类 |
| 变量 variable | `X` `_` `_First` | `var/1` `nonvar/1` | 大写或 `_` 开头；**本身没有名字，只有绑定** |
| 复合项 compound | `point(3,4)` `[1,2]` `a-b` | `compound/1` | `函子(参数1, 参数2, ...)` |

**「列表」「字符串」「结构体」全是复合项的不同写法。**

```text
  原子   : apple Hello World +
  整数   : 42
  负数   : -7
  浮点   : 3.14
  变量   : pair(A,B)
  复合项 : point(3,4)
  嵌套   : tree(1,tree(2,leaf,leaf),leaf)
```

关键推论：

- **`[]` 是原子**，`[1,2,3]` 是复合项，等价于 `'.'(1, '.'(2, '.'(3, [])))`。列表没什么
  神奇，就是嵌套的二元项；`[H|T]` 只是 `'.'(H, T)` 的语法糖。
- **参数本身可以是任意项**，所以「嵌套结构」不需要额外语法 —— `tree(1, tree(2, leaf,
  leaf), leaf)` 就是一棵树。
- **元数（arity）是名字的一部分。** `f(1)` 和 `f(1,2)` 是**两个不同的项**，`f/1` 和 `f/2`
  是**两个不同的谓词**。

> **打印未绑定变量会打出引擎内部编号**（SWI 是 `_1234`，GNU 是 `_G123`），两边不一样，
> 逐字节比对会挂。示例的解决办法是先用 `numbervars(T, 0, _)` 把变量固定成 `A`、`B`、`C`…
>
> ```prolog
> T = pair(_First, _Second),
> numbervars(T, 0, _),
> format("  变量   : ~w~n", [T]).        % pair(A,B)
> ```
>
> 这是本教程处理「要打印含自由变量的项」的标准手法（23 章的测试报告也用它）。

## 4.2 解剖复合项：`functor/3` 与 `arg/3`

```text
  functor(point(3,4)) = point/2
  arg(1) = 3 , arg(2) = 4
  functor(_, point, 2) 造骨架 = point(A,B)
  compare(f(1), f(1,2)) = <（先比元数）
```

```prolog
functor(T, Name, Arity).      % 拆：T 的函子名与元数
arg(N, T, Arg).               % 拆：T 的第 N 个参数
functor(Skeleton, point, 2).  % 装：造出 point(_,_) 全是新鲜变量
```

`functor/3` 是**双向**的，这一点非常有用：

- 给 `T`，得到 `Name` 和 `Arity`（拆解）；
- 给 `Name` 和 `Arity`，造出一个「参数全是新鲜变量」的骨架（构造）。

第二个方向是写通用代码的基础 —— 21 章的 `count_clauses/3`、23 章的 `expect_throw/2` 都
用它「造一个模板头」再 `clause/2` 查。**没有 `functor/3`，就没法写「对任意谓词做某件事」
的代码。**

`arg/3` 的第一个参数是**从 1 开始**的下标（不是 0，和 C 系语言不同）。超过元数会直接失败。

## 4.3 `=..`（univ）：项 ↔ 列表 的双向桥

```text
  f(a,b,c) =.. [f,a,b,c]
  [g,1,2] =.. g(1,2)
  f(a,b) 拆出来是 [f,a,b]
```

```prolog
T =.. [Functor | Args].       % 拆：项 → 函子 + 参数列表
T =.. [g, 1, 2].              % 装：列表 → 项，T = g(1,2)
```

有了它，你可以在**运行时**拆开、改写、重组任意项：

```prolog
rename_functor(Term, NewF, Out) :-
    Term =.. [_ | Args],
    Out  =.. [NewF | Args].
```

这是元编程的基础设施，也是**跨引擎调用专有谓词**的标准手法（21 章的
`swi_meta/2`、22 章的 `mcall/2` 都在用）：

```prolog
mcall(Name, Args) :- Goal =.. [Name|Args], call(Goal).
```

> 为什么要绕这一圈？因为 `gplc` 是**静态链接**的：源码里**字面出现**的每个谓词调用都会
> 被链接器找实现。如果某谓词只在运行时才存在（或只在另一套引擎上存在），字面调用就会
> 报 `Undefined symbols for architecture x86_64: "predicate(area/3)"`。
> **用 `=..` + `call/1` 组装出来的调用对链接器是不可见的**，绕开了这个问题（22 章细讲）。

## 4.4 标准项序

**所有项之间有一个全序**，排序和集合操作都基于它：

```text
变量 < 数字 < 原子 < 复合项
```

同类型内部：数字按值比，原子按字典序比，复合项**先比元数**，元数相同再逐个比参数。

```text
  compare(1, 2)       = <
  compare(2, 1)       = >
  compare(1, 1)       = =
  compare(abc, abd)   = <
  compare(_, 1)       = <        % 变量 < 数字
  compare(1, a)       = <        % 数字 < 原子
  compare(f(1), f(1,2)) = <      % 元数 1 < 元数 2
```

| 谓词 | 用途 |
|---|---|
| `X @< Y` `@>` `@=<` `@>=` | 按标准项序比较（**不**算术） |
| `compare(O, X, Y)` | `O` 得到 `<` / `=` / `>` |
| `sort/2` | 排序 **+ 去重** |
| `msort/2` | 排序，**保留重复** |
| `keysort/2` | 按 `Key-Value` 对的 Key 排序，**稳定**且不去重 |

列表也是复合项，所以列表之间也按标准序比：

```text
  msort 数字        = [1,2,3]
  msort 原子        = [a,b,c]
  msort 列表        = [[a],[a,c],[b]]        % 先比头，再比尾
  msort 复合项      = [f(a),f(b),f(a,x)]     % f/1 全在 f/2 前面
```

**这个序决定了 `sort` 的顺序，你不需要也不能传自定义比较函数。** 想按自定义键排序，就把
键做成 `Key-Value` 再 `keysort/2`；想按数值降序，就把数值取负当键（22 章词频统计用的就是
这一招）。

> **整数与浮点混排时两套引擎的次序不同**（ISO 把数字内部细分的方式有解释空间），
> 所以本教程的纪律是：**排序列表里不要混整数和浮点**。

## 4.5 `copy_term/2`

```text
  原件 = pair(A,B)
  副本 = pair(A,B)
  原件与副本可以合一（结构相同）
  term_variables(原件) 个数 = 0
  term_variables(副本) 个数 = 0
```

```prolog
copy_term(f(X, Y), C).        % C = f(_A, _B)，变量是崭新的，两边不共享
```

「崭新」意味着**副本里的变量和原件里的变量没有任何关系**：后面把 `C` 里的变量绑成什么，
都不会影响原件。

什么时候需要它：

- **做模板**：模板里的变量必须每次都是新的，否则第二次套用会沿用上一次的绑定（12 章）。
- **写元解释器**：`clause/2` 取出的子句头里变量本来就是新鲜的，但如果你自己缓存了子句，
  取用时就必须 `copy_term/2`。
- **做搜索/规划**：把当前状态复制一份去试探，失败了原状态不受污染。

相关工具：`term_variables(T, Vars)` 收集项里所有变量（按出现顺序），
`numbervars/3` 把变量固定成 `A`/`B`/`C` 便于打印。

## 4.6 坑位清单

1. **打印自由变量** → 引擎内部编号两边不同，逐字节比对必挂。先 `numbervars/3`。
2. **`f(1)` 与 `f(1,2)` 当成同一个谓词** → 元数是名字的一部分。
3. **`arg/3` 下标从 0 开始** → 从 **1** 开始；越界直接失败，不报错。
4. **`=..` 用在原子或数字上** → `f =.. L` 得到 `L = [f]`（单元素列表），不是你以为的
   样子。它只对「函子 + 参数」这条结构有意义。
5. **想给 `sort` 传比较函数** → 做不到。用 `keysort/2` + 自定义键。
6. **`sort/2` 会去重** → 想保留重复用 `msort/2`。这对频次统计是致命的（13 章）。
7. **整数浮点混排** → 两套引擎次序不同。
8. **`'.'` 当函子随便用** → 写列表的本质用 `[a|[b]] == [a,b]` 更安全（SWI 对 `'.'` 有保留
   的配置）。
