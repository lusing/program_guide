# 08 · 列表

> 对应示例：[`examples/08_lists/08_lists.pl`](../examples/08_lists/08_lists.pl)

## 8.1 列表的本体

**Prolog 没有数组、没有下标运算符、没有 `for`。列表就是链表**，而 `[H|T]` 只是复合项
`'.'(H, T)` 的语法糖：

```prolog
[a,b,c]  ==  '.'(a, '.'(b, '.'(c, [])))
[a]      ==  '.'(a, [])
[]       ==  原子 []
```

```text
  [a,b,c] 的头 = a，尾 = [b,c]
  单元素列表 [a] 的头 = a，尾 = []
  [a|b] 的尾是原子 b，整体是不完整列表 [a|b]
  内建谓词遇到不完整列表行为各异，可移植代码一律用完整列表。
  length([], N)    N = 0（这才是判空的可靠写法）
  is_list([a,b])  成立（两套引擎都提供）
  is_list([a,b|c]) 不成立 —— 尾部不是列表
```

三个判断「列表」的坑：

- **`[]` 是不是原子？** ISO 规定它是原子，但 SWI 的 `atom/1` 对它返回 `false`。
  **不要拿这个当判断依据**，判空用 `length(L, 0)` 最稳。
- **`[a|b]` 是合法的项**（尾是原子 `b`），它**不是**列表。内建谓词碰到它各家行为不同，
  所以本教程的纪律是：**只用完整列表**。
- **`is_list/1` 两套引擎都有**，可以放心用；它只对「以 `[]` 结尾」的链返回真。

## 8.2 `length/2` 是关系，不是函数

```text
  length([a,b,c], N)  N = 3
  length(L, 2)        L = [A,B]
  my_length([a,b,c,d])  = 4
```

```prolog
my_length([], 0).
my_length([_ | T], N) :-
    my_length(T, N0),
    N is N0 + 1.
```

给 `L` 数长度，给 `N` **生成**一个「长度 N、元素全是新变量」的列表 —— **一次调用同时
约束长度与内容**。这在「先定形状、再填内容」的写法里非常有用，也是让 `member/2` 这类
生成器能够终止的关键：

```prolog
?- findall(L, ( length(L, 2), member(1, L) ), Gen).
Gen = [[1,A],[B,1]].
```

**必须先 `length/2` 限定长度，否则 `member(1, L)` 会无限生成下去**（每次多一个元素）。
这是 8.5 节里最实用的一个模式。

## 8.3 `append/3`：一个谓词四种用法

```text
  append([1,2],[3,4],L)      L = [1,2,3,4]
  拆一次：P = []，S = [1,2,3,4]
  用 findall 看全部拆法：[[]-[1,2],[1]-[2],[1,2]-[]]
  后缀固定时：P = [1,2]
  前缀限定长度 1：[[a]-[b]]
```

```prolog
append([], L, L).
append([H | T], L, [H | R]) :- append(T, L, R).
```

**`append/3` 是理解 Prolog 的试金石。** 四种用法：

| 用法 | 调用 | 结果 |
|---|---|---|
| 拼接 | `append([1,2],[3,4],L)` | `L = [1,2,3,4]` |
| **枚举所有切分** | `append(P,S,[1,2,3,4])` | 回溯给出 5 种 `P`/`S` 组合 |
| 求前缀/后缀 | `append(P,[3,4],[1,2,3,4])` | `P = [1,2]` |
| 生成（需限长） | `length(P,1), append(P,S,[a,b])` | `[a]-[b]` |

第二种用法（**枚举所有切分**）是命令式语言里没法直接表达的：

```prolog
?- append(X, Y, [1,2]).
X = [],     Y = [1,2] ;
X = [1],    Y = [2]   ;
X = [1,2],  Y = [].
```

而它是很多解析算法的核心（19 章的手写解析器就是靠它「试每一种切分」）。

> **第四种用法必须配 `length/2` 限长**，否则 `append(P,S,L)` 会一路生成越来越长的 `P`
> 永不终止。**「生成器 + 限长」是 Prolog 里避免无限搜索的常规手段**（23 章会看到
> 不限长的生成器怎么让测试挂死）。

## 8.4 `reverse`：朴素版 vs 累加器版

```text
  朴素版   [3,2,1]
  累加器版 [3,2,1]
  内建版   [3,2,1]
  reverse 也能反着用：reverse(R, [1,2,3]) -> R = [3,2,1]
```

```prolog
% 朴素版：递归回来再往结果末尾追加 —— O(n²)
naive_reverse([], []).
naive_reverse([H | T], R) :-
    naive_reverse(T, R0),
    append(R0, [H], R).            % 每次都要走一遍 R0

% 累加器版：往下走的时候就把元素攒进累加器 —— O(n)
acc_reverse(L, R) :- acc_reverse(L, [], R).
acc_reverse([], Acc, Acc).
acc_reverse([H | T], Acc, R) :- acc_reverse(T, [H | Acc], R).
```

**累加器是 Prolog 最重要的性能手段**：把「递归回来再拼」改成「往下走的时候顺手攒」，
就省掉了 `append` 的复制开销。**尾递归 + 累加器 ≈ 命令式循环的成本**（09 章细讲尾递归）。

`reverse/2` 也是关系式的：`reverse(R, [1,2,3])` 反着给出 `R = [3,2,1]`。

**注意 `reverse/2` 两套引擎都有**，可以放心用 —— 上面的手写版是用来「看懂原理」的，
不是让你不用内建。

## 8.5 定位与筛选

```text
  nth0(0,[a,b,c])   a（下标从 0 起）
  nth1(1,[a,b,c])   a（下标从 1 起）
  nth0 反向枚举     [0-a,1-b,2-c]
  last([a,b,c])     c
  select(b,[a,b,c]) 剩下的 = [a,c]
  反向枚举所有可能  [[b,a],[a,a],[a,b]]
  member(b,[a,b,c])      成立
  memberchk(b,[a,b,c])   成立（确定性的，只认第一个解）
  反向用 member：length=2 且含 1 的列表 = [[1,A],[B,1]]
  注意必须先限定长度，否则 member(1,L) 会无限生成下去。
```

| 谓词 | 语义 | 关系式？ |
|---|---|---|
| `nth0(I, L, E)` | `I` 从 **0** 起 | ✅ 三者任意两个已知就能求第三个 |
| `nth1(I, L, E)` | `I` 从 **1** 起 | ✅ |
| `last(L, E)` | 最后一个元素 | ✅ |
| `select(E, L, Rest)` | 取出一个 `E`，剩下 `Rest` | ✅ **会回溯给出所有位置** |
| `member(E, L)` | 成员关系 | ✅ 会有多个解 |
| `memberchk(E, L)` | 同上但**确定性** | ❌ 只认第一个 |

`select/3` 的「反向枚举」很值得注意：`findall(S, select(_E, [a,b,c], S), Sels)` 会给出
三个结果（分别在 3 个位置取出元素）。**「取出并回溯」是排列、组合、约束求解里最常用的
模式**（21 章）

**`memberchk/2` 比 `member/2` 快**，因为找到第一个就砍掉选择点 —— 只问「在不在」时用它。

## 8.6 排列与排序

```text
  permutation([1,2]) 共 2 种：[[1,2],[2,1]]
  sort([c,a,b,a])   [a,b,c]（去重）
  msort([c,a,b,a])  [a,a,b,c]（保留重复）
  keysort/2         [a-2,a-3,b-1,b-0]（只按键，稳定）
  按长度升序排      [[a],[1,2],[1,2,3]]
```

| 谓词 | 排序 | 去重 | 稳定 | 备注 |
|---|---|---|---|---|
| `sort/2` | ✅ | ✅ | — | 按标准项序，**会吃掉重复** |
| `msort/2` | ✅ | ❌ | — | 只排序 |
| `keysort/2` | 按键 | ❌ | ✅ | 元素须是 `K-V` 形式 |

**`permutation/2`** 两套引擎都有，生成全排列。8 个元素就是 40320 种 —— **别拿它做
大规模搜索**，那是 21 章约束求解的活。

**自定义排序只有一条可移植的路**：把准则做成「键」，`keysort` 之后再脱掉键。

```prolog
sort_by_length(L, Sorted) :-
    keyed(L, Keyed),                 % [[1,2,3],[a],[1,2]] → [3-[1,2,3], 1-[a], 2-[1,2]]
    keysort(Keyed, SortedKeyed),
    unkey(SortedKeyed, Sorted).

keyed([], []).
keyed([H | T], [K - H | KT]) :- length(H, K), keyed(T, KT).

unkey([], []).
unkey([_ - H | T], [H | UT]) :- unkey(T, UT).
```

> **`predsort/3` 与 `sort/4` 是 SWI 专有**，GNU Prolog 没有 —— 所以「传一个比较谓词进去」
> 这条最自然的路走不通。**「做键 + `keysort` + 脱键」是唯一可移植的自定义排序**，值得
> 背下来。

## 8.7 手写 `map` / `filter` / `fold`

```text
  my_map(double, [1,2,3])       [2,4,6]
  my_filter(>0, [-1,2,-3,4])    [2,4]
  my_fold(+, [1,2,3,4], 0)      10
```

```prolog
my_map(_, [], []).
my_map(P, [H | T], [R | RT]) :-
    call(P, H, R),                 % call/N：把 P 当谓词调，追加 N-1 个参数
    my_map(P, T, RT).

my_filter(_, [], []).
my_filter(P, [H | T], R) :-
    (   call(P, H)
    ->  R = [H | RT]
    ;   R = RT
    ),
    my_filter(P, T, RT).

my_fold(_, [], Acc, Acc).
my_fold(P, [H | T], Acc, R) :-
    call(P, H, Acc, Acc1),
    my_fold(P, T, Acc1, R).
```

这三个谓词把**「怎么遍历」和「对元素做什么」拆开了** —— 传进去的 `P` 是一个**闭包**
（closure）：一个「还没凑齐参数的谓词」。`call(P, H, R)` 把 `H`、`R` 追加到 `P` 后面调用。

`my_filter` 用 `(C -> T ; E)` 而不是 `\+`，是因为前者能**保留 `H` 的绑定**，而 `\+` 会把
绑定丢掉（05 章）—— 这是写出正确 `filter` 的关键。

第 11 章会用内建的 `maplist/3`、`include/3`、`exclude/3`、`foldl/4`，**不需要手写**；
这里先手写一遍是为了看清「高阶谓词」的机制。

## 8.8 坑位清单

1. **`atom([])` 当判断依据** → ISO 说它是原子，SWI 的 `atom/1` 返回 false。判空用
   `length(L, 0)`。
2. **`[a|b]` 当列表用** → 不是完整列表，内建谓词行为不一致。
3. **`member(X, L)` 且 `L` 是自由变量** → 无限生成。先 `length/2` 限长（8.5）。
4. **`append(P,S,L)` 且全是自由变量** → 无限生成，同样要限长。
5. **`sort/2` 当 `msort/2` 用** → 重复元素被静默吃掉（频次统计必挂）。
6. **`keysort` 的元素不是 `K-V`** → 按标准项序排了，结果看起来很怪但不报错。
7. **想给 `sort` 传比较谓词** → `predsort/3`/`sort/4` 是 SWI 专有。做键 + `keysort`。
8. **`nth0`/`nth1` 搞混** → 0 起还是 1 起，差一位。
9. **朴素 `reverse` 当默认写法** → O(n²)。用内建或累加器版。
10. **`\+ call(P, H)` 写 `filter`** → 绑定丢了，结果里元素变成自由变量。
11. **`permutation/2` 做大规模搜索** → 阶乘爆炸，改用约束求解（21 章）。
