# 07 · 算术与比较

> 对应示例：[`examples/07_arithmetic/07_arithmetic.pl`](../examples/07_arithmetic/07_arithmetic.pl)

## 7.1 `=` 不算术，`is` 才算术

这是 Prolog 里最反直觉、也最必须一次记住的一条：

```text
  X = 1+2   之后 X 是  1+2（还是个项）
  X is 1+2  之后 X 是  3
  3 + 4 * 5   = 23
  (3 + 4) * 5 = 35
```

**`1+2` 是项，不是数字。** `=/2` 只是把它「装」进 `X`（04 章的 `+` 是一个普通函子），
`is/2` 才是求值器：

```prolog
?- X = 1 + 2.
X = 1+2.           % 没算

?- X is 1 + 2.
X = 3.             % 算了
```

运算符优先级与结合性两套引擎**完全一致**，可以放心依赖括号：

```prolog
?- X is 3 + 4 * 5.        X = 23      % * 比 + 紧
?- X is (3 + 4) * 5.      X = 35
```

> **`is/2` 是「计算式」，不是「等式」。**
>
> ```prolog
> ?- X is Y + 1.      % Y 未绑定 → 抛 instantiation_error
> ```
>
> 它**不能反着解方程**。要做反解就得用**关系式谓词**（7.6 节）：
> `succ/2`、`between/3`、`length/2`、`plus/3` 这些是「关系」而不是「函数」，正反都能用。

## 7.2 整数运算（无界）

```text
  7 + 2     = 9
  7 - 2     = 5
  7 * 2     = 14
  7 // 2    = 3
  7 div 2   = 3
  -7 // 2   = -3
  -7 div 2  = -4
  // 向零截断，div 向下取整 —— 负数时才看得出区别。
  7 rem 2   = 1
  7 mod 2   = 1
  -7 rem 2  = -1
  -7 mod 2  = 1
  rem 的符号跟被除数，mod 的符号跟除数。
  abs(-7)   = 7
  sign(-7)  = -1
  min(3,9)  = 3
  max(3,9)  = 9
  2 ^ 10    = 1024
  gcd(12,18) = 6
  整数是无界的（不像 C 会溢出）——这是 ISO 要求，两套引擎都满足。
```

四组容易混的：

| 运算 | 结果符号/行为 | 例 |
|---|---|---|
| `//` | 向**零**截断 | `-7 // 2 = -3` |
| `div` | 向**下**取整 | `-7 div 2 = -4` |
| `rem` | 符号跟**被除数** | `-7 rem 2 = -1` |
| `mod` | 符号跟**除数** | `-7 mod 2 = 1` |

`mod` 的「跟除数」性质在做循环下标时很有用（`X mod 3` 永远落在 `0..2`）；`rem` 的
「跟被除数」性质更符合 C 的 `%`。**选哪个要先想清楚负数时的期望。**

两个幂运算符要分清：

```prolog
2 ^ 10     % = 1024，整数幂
2 ** 10    % = 1024.0，浮点幂（** 总是返回浮点）
```

> **整数是无界的。** `2 ^ 100` 能算出精确的 31 位整数，不会溢出 —— 这是 ISO 要求，两套
> 引擎都满足。用它算大数很舒服。

## 7.3 位运算

```text
  12 /\ 10 = 8
  12 \/ 10 = 14
  \ 12   = -13
  1 << 4  = 16
  16 >> 2 = 4
  没有通用的异或运算符：X = (A \/ B) /\ \ (A /\ B) 才是可移植写法。
  （SWI 额外提供 xor/2，GNU Prolog 不认，所以本教程不用。）
```

| 运算 | 写法 |
|---|---|
| 与 | `A /\ B` |
| 或 | `A \/ B` |
| 取反 | `\ A` |
| 左移 / 右移 | `A << N` / `A >> N` |

**没有 `xor/2`。** SWI 有，GNU 没有 —— 可移植写法是用恒等式：

```prolog
x = (A \/ B) /\ \ (A /\ B).
```

`\` 是一元的（`xfy` 还是 `fy` 取决于实现），**出现在中缀表达式里时注意加空格或括号**。

## 7.4 浮点运算：**打印**才是真正的坑

```text
  7 / 2 = 3.500
  sqrt(2) = 1.414
  sqrt(16) = 4.000
  floor(3.7) = 3.000
  ceiling(3.2) = 4.000
  round(3.7) = 4.000
  truncate(3.7) = 3.000
  float_integer_part(3.7) = 3.000
  float_fractional_part(3.75) = 0.750
  float(3) = 3.000
  exp(0) = 1.000
  log(1) = 0.000
  sin(0) = 0.000
  cos(0) = 1.000
  pi = 3.142
```

`floor` / `ceiling` / `round` / `truncate` 返回的都是**浮点**（`3.000` 而不是 `3`）。要整数
就再 `float_integer_part/1` 或 `round/1` 配 `//` 处理。

三条必须知道的事实：

1. **二进制浮点不能精确表示 `0.1` / `3.14` 这类十进制小数。** 这是 IEEE 754，不是 Prolog
   的问题。
2. **`~w` 打浮点，两套引擎的输出不一致。**
   SWI 打「能读回来的最短写法」，GNU 打 17 位有效数字 —— 同一个 `3.14`，SWI 给 `3.14`，
   GNU 给 `3.1400000000000001`。**逐字节比对直接挂。**
3. **定点 `~2f` / `~3f` 与科学计数 `~e` / `~g` 两边算法一致，可以放心用。**

于是本教程的约定：**浮点一律用 `~2f` / `~3f` / `~e` / `~g` 打印。**
只有 `0.25`、`0.75` 这类二进制可精确表示的浮点，用 `~w` 才安全。

> **还有一条更隐蔽的：`/` 的结果类型两边不一致。**
>
> ```text
>   7 / 2 = 3.5    两边都是浮点（没问题）
>   4 / 2 = ?      SWI 给整数 2，GNU 给浮点 2.0
> ```
>
> 所以可移植代码里「整除」一律写 `//`，**别指望 `/` 帮你约分**。24 章的解释器就因此
> 把除法定成 `//` —— 否则表达式的打印结果两边不同。

## 7.5 算术比较 vs 项比较

```text
  2 =:= 2.0   成立
  2 =\= 3     成立
  2 <  3      成立
  2 >  3      不成立
  2 =< 2      成立
  2 >= 3      不成立
  2 @< 2.0    不成立
```

| 用途 | 算术（**先求值**） | 项（**不求值**） |
|---|---|---|
| 相等 | `=:=` | `==` |
| 不等 | `=\=` | `\==` |
| 小于 | `<` | `@<` |
| 小于等于 | `=<` | `@=<` |
| 大于 | `>` | `@>` |
| 大于等于 | `>=` | `@>=` |

四条注意：

- **`=<` 不是 `<=`。** 方向反的，这是全世界 Prolog 新手都踩过的坑。
- **`=:=` 会先求值。** `1+1 =:= 2` 为真，而 `1+1 == 2` 为假（项的写法不同）。
- **两套「序」不能混用。** `2 =:= 2.0` 成立（数值相等），`2 @< 2.0` 也成立（标准项序里
  整数排在浮点前面）—— 一句话里两个结论看似矛盾，其实是两套完全不同的序。
- **整数与浮点混排在两套引擎上的标准项序不一致。** 所以 `sort/msort` 里**绝不要混整数和
  浮点**（04 章已提，23 章会再遇到）。

## 7.6 关系式算术：不用 `is` 也能算

```text
  succ(4, X)          X = 5
  succ(X, 5)          X = 4
  between(1, 5, X)    [1,2,3,4,5]
  between(1, 9, X) 且 X mod 3 = 0：[3,6,9]
  length([a,b,c], N)  N = 3
  length(L, 3)        L = [A,B,C]
```

这几个谓词都是**关系**而不是函数：

- **`succ(A, B)`**：`B` 是 `A` 的后继。正反都能用 —— 给定谁求另一个。
- **`between(Lo, Hi, X)`**：`X` 在 `[Lo, Hi]` 内。**它可双向**：`X` 自由时枚举，`X` 绑定时
  判断在不在范围内。这就是「生成 + 测试」的生成器（06 章）。
- **`length(L, N)`**：列表长度。`N` 自由时数，`L` 自由时**生成一个长度 N 的列表（元素全是
  新变量）**。

```prolog
?- length(L, 3), member(1, L), L = [_, X, _].
L = [1, X, _] ...
```

**一个谓词多种用法，是 Prolog 区别于函数式与命令式的核心特征：它描述的是「关系」。**
这些「关系式算术」的谓词是写可移植代码的关键 —— 用 `is` 做不到的事（反解、生成），
用它们都能做。

## 7.7 坑位清单

1. **`X = 1+2` 当算术** → 得到的是项。要算用 `is/2`。
2. **`is` 左边是已绑定变量** → 变成比较，不匹配就失败（不是错误）。
3. **`is` 右边有未绑定变量** → `instantiation_error`。
4. **`=<` 写成 `<=`** → 语法错误。
5. **`1+1 == 2`** → 假。项比较要用 `=:=`。
6. **`2 @< 2.0`** → 整数排在浮点前，所以为真；别和 `=:=` 的结论混起来想。
7. **`~w` 打浮点** → SWI 与 GNU 输出不同，逐字节比对挂。
8. **`/` 求整除** → `4 / 2` 在 SWI 是整数 `2`，GNU 是浮点 `2.0`。整除一律 `//`。
9. **`1 = 1.0`** → 合一是结构比较，失败（05 章）。
10. **`floor/ceiling/round` 以为是整数** → 返回浮点。
11. **`sort` 里混整数浮点** → 两套引擎次序不同。
12. **`0 is X mod 7` 当过滤器失败** → 失败即回溯，会继续枚举；在 23 章会看到它会
    **永不终止**（`is/2` 只失败、不剪枝）。
