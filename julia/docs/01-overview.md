# 01 · 全景：Julia 是什么，为什么值得学

> 本章无示例（从第 02 章起每章配一个可运行示例）。

## 1.1 一段话定位

Julia 是一门**为科学计算与数值性能而生的高级动态语言**——目标自诞生起就写在论文标题里："Walks like Python, runs like C"。它给你 Python 的交互体验（REPL、动态类型、无需编译的脚本），底层却用 **JIT 即时编译**把每个函数按实参类型编译成原生机器码；同时把 Lisp/Matlab 血统的类型系统、多重派发与元编程做成语言核心，而不是库的约定。

一句话：**Julia = C 的速度 + Python 的手感 + Lisp 的元编程 + Matlab 的数学记法**。它不为通用 Web 后端而设计，但在数值仿真、数据分析、科学机器学习领域是"一门语言写到底"（原型即生产）的答案。

## 1.2 设计哲学四大支柱

| 支柱 | 做法 | 对比 |
|---|---|---|
| 多重派发 | 方法按**全部实参类型**选择，操作符也是函数 | C++/Java 只看接收者（单分派）；Python 靠鸭子类型运行期试错 |
| 类型系统"可选标注" | 动态类型，但标注类型 = 给编译器假设 = 提速 | Python 标注只是文档；C++ 全静态 |
| JIT + 类型特化 | 每个函数按实参类型编译专属版本 | 解释器逐次翻译；C++ 提前编译无交互 |
| 数组与数学一等公民 | 列主序数组、`A\b` 解方程、`π`/`2im` 字面量、Unicode 运算符 | 这些在通用语言里都是库的事 |

第 06/07 章讲派发与类型、第 09/10 章讲数组与广播、第 13 章讲线性代数与稀疏、第 14 章讲元编程、第 16 章讲性能工程、第 21 章讲随机统计——语言核心与科学计算双主线，是本教程着墨最多的部分。

### 与 C++ / Python / MATLAB 对照

| 特性 | Julia | C++ | Python | MATLAB |
|---|---|---|---|---|
| 执行模型 | JIT（LLVM） | AOT | 解释 + C 扩展 | 解释 + JIT |
| 类型 | 动态 + 可标注 | 静态 | 动态 | 动态（矩阵优先） |
| 泛型 | 多重派发 | 模板 |鸭子 | 重载有限 |
| 元编程 | 宏 + 表达式（Lisp 级） | 模板（另一门语言） | 装饰器（受限） | 无 |
| 并行 | 任务/线程/分布式内置 | std::thread | GIL 之痛 | 工具箱 |
| 部署 | 单进程脚本/包 | 二进制 | 解释器依赖 | 商业软件 |
| 学习曲线 | 中（类型系统要过槛） | 高 | 低 | 低（数学背景友好） |

## 1.3 版本现状：1.13，新前端已落地

Julia 采用 `1.x` 持续演进（1.0 是 2018 年的稳定基线，此后无破坏性语法变更承诺）。本教程写作时最新稳定版 **1.13.0**。近年值得知道的里程碑：

| 版本 | 年份 | 关键变化（本教程直接相关） |
|---|---|---|
| 1.9 | 2023 | 包原生代码缓存（预编译大幅提速）、package extensions |
| 1.10 | 2024 | 启动/编译时延显著下降、新错误展示、`@main` 提案酝酿 |
| 1.11 | 2024 | **`Base.@main` 入口宏**、环境栈行为完善 |
| 1.12 | 2025 | 世界年龄语义更严格（全局绑定访问警告）、交互线程池默认存在 |
| 1.13 | 2026 | **新前端 flfrontend 落地**（错误行内标注 └┘、Suggestion/Hint 段）；`catch_stacktrace` 等旧 API 移除 |

**这意味着：网上大量资料（1.9/1.10 时代）在 1.13 上有静默差异**——本教程所有代码在 1.13.0 实测，每章末尾"坑位清单"收录实测差异（如 13/23 章的栈跟踪 API 变更、02 章的 `@main` 形式）。

## 1.5 本教程怎么学

- **读者定位**：会编程（C++/Python 背景最佳），从零学 Julia。不教编程本身。
- **主线是 1.13 现代写法**：`@main` 入口、`[sources]` 路径依赖、线程池并行从第一天就是默认姿势，旧写法只在坑位清单里教"认得"。
- **每章节奏**：读讲解 → 跑示例 → 改代码再跑。示例全在 `examples/NN_topic/`，章号 = 目录号，每目录含 `main.jl`（演示 + @assert 自检）与 `runtests.jl`（Test 断言套件）。
- **三层验证**：`build.ps1` 对每个示例执行 运行层（`--check-bounds=yes` 跑 main.jl → exit 0 + 结束标记）→ 测试层（runtests.jl @testset → exit 0）→ 特判层（17/24 走 Pkg 工程、21/24 加 `-t 4`）——全部通过才收工，你手上的代码是可信的。
- 与本仓库其他教程对照：[cpp20](../cpp20/README.md)、[zig](../zig/README.md)（同为编译型主线）、[python 类脚本对照]（[dart](../dart/README.md)）。

## 1.6 坑位清单

1. **默认单线程**：不传 `-t` 时 `Threads.nthreads() == 1`，多线程代码静默串行——先怀疑旗标再怀疑代码（20 章）。
2. **首次运行慢是编译**：函数第一次调用要 JIT 编译，计时对比必须先预热（16 章）；这不是"Julia 慢"，是"Julia 在编译"。
3. **网上资料版本漂移**：1.9/1.10 时代的写法（`@code_warntype` 裸用、`catch_stacktrace`、无 `@main`）在 1.13 会有"不存在/行为不同"——先查版本再查语法（02/23 章）。
4. **中文标点紧贴 `$var`**：`"你好，$name！"` 解析错误——统一写 `$(name)`（02 章实测坑）。
5. **注释是 `#` 不是 `//`**：`//` 是有理数除法（`1 // 3`），C++ 肌肉记忆会造出非法表达式（03 章实测坑）。
6. **脚本与 REPL 作用域不同**：同一段顶层循环，REPL 能跑、脚本报 UndefVarError（soft scope，04 章实测坑）。
