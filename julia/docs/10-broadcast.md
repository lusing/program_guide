# 10 · 广播 ⭐

> 对应示例：`examples/10_broadcast/`
>
> `.` 是 Julia 最有辨识度的语法：逐元素、融合、就地——向量化代码的性能根基。

## 10.1 `.` 的语义：函数逐元素施用

```julia
v = [1.0, 4.0, 9.0]
sqrt.(v)          # [1.0, 2.0, 3.0]——任何函数后加 .
v .+ 1            # [2.0, 5.0, 10.0]
v .^ 2            # [1.0, 16.0, 81.0]
2 .^ (1:3)        # [2, 4, 8]——左右两侧都能广播
abs.(-1:2)        # 作用于 range 得 Vector
string.("a", 1:2) # ["a1", "a2"]——多参数按位配对
```

## 10.2 维度扩展：低维沿高维复制

```julia
[10, 20] .+ [1, 2]' == [11 12; 21 22]       # (2,1) + (1,2) → (2,2)
fill(1, (2, 3)) .* [1, 2] == [1 1 1; 2 2 2]  # (2,3) .* (2,)：向量沿"列方向"复制到每行
```

**对齐规则与 NumPy 相反（实测坑）**：一维向量对齐**第一维**（行方向）。`(2,3) .* [1,2]` 把长度 2 的向量沿"每列"广播；`(2,3) .* [1,2,3]` 直接 `DimensionMismatch`。想要"行向量沿列广播"先转置：`m .* [1 2 3]` 或 `m .* v'`。

## 10.3 `*` vs `.*`：头号混淆点

```julia
A = [1.0 2.0; 3.0 4.0]
A * A    # [7 10; 15 22]   矩阵乘
A .* A   # [1 4; 9 16]     对应元素乘
```

## 10.4 融合与就地：零中间数组

一条广播表达式**只遍历一次、只分配结果一次**（多操作融合成单循环）：

```julia
x = Float64.(1:1_000_000)
fused = x .+ 1 .* 2        # 融合：一个结果数组（非 (x.+1).*2 的两个）
```

实测分配对比：单广播 8,000,103 B vs 融合表达式 8,000,103 B——**同量级而非翻倍**。

就地写入（零分配）用 `.=`：

```julia
y = similar(x)
y .= x .* 2 .+ 1           # 写进既有数组
z = [1, 2]; z .+= 10       # 语法糖：z .= z .+ 10
```

## 10.5 `@.` 宏：整条表达式"点全上"

```julia
w = [1.0, 4.0]
(@. sqrt(w) + 1) == [2.0, 3.0]     # 等价 sqrt.(w) .+ 1
(@. w^2 + 1) == [2.0, 17.0]
```

**实测坑**：`@.` 连 `==` 也会变成 `.==`——`@. w^2 + 1 == [...]` 的结果是 **BitVector** 不是 Bool，放进 `@assert` 抛 "non-boolean (BitVector) used in boolean context"。**比较留在括号外**：`(@. 表达式) == 期望值`。

## 10.6 广播自定义标量类型：broadcastable

```julia
struct Celsius
    c::Float64
end
Base.:+(a::Celsius, b::Celsius) = Celsius(a.c + b.c)
Base.broadcastable(x::Celsius) = Ref(x)     # ★ 声明"我是标量"（官方推荐姿势）

ts = [Celsius(1), Celsius(2)]
ts .+ Celsius(10)          # Vector{Celsius}，逐元素调我们的 +
```

不写 `broadcastable` 会怎样（实测）：广播把 `Celsius(10)` 当**可迭代物**去 collect → `MethodError: no method matching length(::Celsius)`。`Ref(x)` 把值包成"零维容器"，广播时按标量复制。数组和已支持类型无需此步骤。

## 10.7 广播 vs map：怎么选

```julia
map(x -> x^2, 1:3) == broadcast(x -> x^2, 1:3)   # 常等价
map((a, b) -> a + b, [1, 2], [10, 20])           # 多容器按位 zip（无维度扩展）
[1, 2] .+ [10 20] == [11 21; 12 22]              # 广播支持维度扩展，map 不支持
[0.5, 1.5] .|> round                             # 向量化管道 .|>
round.(Int, [1.6, 1.4])                          # 带类型参数的广播
```

经验：**数值变换用广播（融合+就地）、容器到容器用 map、惰性过滤用 Iterators.filter/generator（11 章）**。

## 10.8 坑位清单

1. **向量对齐第一维（与 NumPy 相反）**：`(2,3) .* [1,2,3]` 是 DimensionMismatch；行广播用 `[1 2 3]` 或 `v'`（10.2 实测）。
2. **`@.` 连 `==` 都加点**：结果是 BitVector——比较写在括号外（10.5 实测）。
3. **`&&`/`||` 不能向量化**：数组逻辑用 `.&`/`.|`（`&&` 抛 TypeError）；标量短路与向量逻辑是两套运算符。
4. **自定义 struct 直接广播会当容器**：`length(::YourType)` MethodError——加 `Base.broadcastable(x::T) = Ref(x)`（10.6 实测）。
5. **`= ` 与 ` .= ` 天壤之别**：`y = x .* 2` 新建绑定；`y .= x .* 2` 就地写入既有数组——热循环里后者零分配（10.4）。
