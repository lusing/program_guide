# 03 · 数值类型与数值稳定

> 对应示例：`examples/03_numbers/`
>
> 数学语言的数值章要回答两件事：**类型怎么用**（前面各节）和**浮点什么时候骗你**（3.7）——后者是数值计算的基本功，24 章求解器的误差控制全靠它。

## 3.1 整型族：固定位宽，溢出静默环绕

`Int` 是平台原生宽度（64 位系统即 `Int64`）；一族固定位宽类型 `Int8/16/32/64`、`UInt8/16/32/64`。**没有"任意大整数默认化"**——溢出按补码环绕、不抛错：

```julia
typemax(Int64) + 1 == typemin(Int64)     # true：环绕
UInt8(255) + UInt8(1) == UInt8(0)        # true
```

任意精度用 `BigInt`（`big"..."` 字面量构造），代价是堆分配与慢一个量级：

```julia
big"2" ^ 100        # 1267650600228229401496703205376
BigInt(2)^100       # 等价
```

## 3.2 浮点族与特殊值

默认 `Float64`；`Float16/Float32` 显式标注或由字面量（`1.0f0`）触发。IEEE 754 语义全套：

```julia
0.1 + 0.2 != 0.3                    # true——经典精度
isapprox(0.1 + 0.2, 0.3)            # true——比较浮点用 ≈ / isapprox
1 / 0 == Inf && -1 / 0 == -Inf      # 浮点除零不炸
isnan(0.0 / 0.0)                    # true
eps(Float64)                        # 2.220446049250313e-16（机器精度）
```

实测坑：**`typemax(Float64)` 就是 `Inf` 本身**——最大有限浮点用 `floatmax(Float64)`。

## 3.3 整除家族：/ ÷ div fld cld rem mod

Julia 把 C 里一个 `/` 的四种语义拆成六个名字——值得背下的一张表：

| 运算 | 例 | 结果 | 语义 |
|---|---|---|---|
| `/` | `7 / 2` | `3.5` | 永远浮点 |
| `÷`（div） | `7 ÷ -2` | `-3` | 向零截断 |
| `fld` | `fld(-7, 2)` | `-4` | 向下取整（floor） |
| `cld` | `cld(7, 2)` | `4` | 向上取整（ceil） |
| `rem` | `rem(-7, 2)` | `-1` | 与被除数同号（配合 ÷） |
| `mod` | `mod(-7, 2)` | `1` | 与除数同号（数学模） |

验证恒等式：`div(x,y)*y + rem(x,y) == x` 恒成立；`fld(x,y)*y + mod(x,y) == x` 恒成立。

## 3.4 有理数与复数：`//` 与 `im` 是语法的一部分

```julia
1 // 3 + 1 // 6 == 1 // 2       # 精确分数
numerator(3 // 9)               # 1（自动约分；函数是全称 numerator/denominator）
(2 // 3) * 3 == 2               # 与整数混算自动提升
(1 + 2im) * (1 - 2im)           # 5 + 0im
abs(3 + 4im)                    # 5（勾股）
```

`im` 是虚数单位字面量后缀（不是变量！），`//` 是有理数构造（**不是注释**——见坑位 1）。复数、有理数、整数、浮点统一挂在 `Number` 类型树下，运算符按 promote 规则自动汇合（3.5）。

## 3.5 promote 与 convert：提升是规则不是玄学

```julia
promote(1, 2.0)             # (1.0, 2.0)
promote(1, 2.0, 3 // 4)     # (1.0, 2.0, 0.75)
convert(Float64, 3)         # 3.0
```

- `promote` 把一组值抬到公共类型（查 `promote_rule` 表，可自定义——06/15 章给自己的类型加规则）；
- `convert(T, x)` 显式转换，语义"无损或愿意承担精度损失"。

**转换的纪律**（与 C 截然不同，实测坑）：

```julia
Int(3.99)        # ❌ InexactError——Int() 只接受精确可表示的值，不截断！
trunc(Int, 3.99) # 3   向零
floor(Int, 3.99) # 3   向下
ceil(Int, 3.99)  # 4   向上
round(Int, 3.5)  # 4；round(Int, 2.5) == 2 —— 四舍六入五取偶
```

## 3.6 常用数值函数速查

```julia
gcd(12, 18) == 6 && lcm(4, 6) == 12
isqrt(10) == 3          # 整数平方根（不碰浮点）
abs(-5) == 5 && sign(-5) == -1
clamp(15, 0, 10) == 10  # min/max 夹逼
parse(Int, "42")        # 字符串 → 数
string(255, base = 16)  # "ff" 数 → 字符串（进制任意）
```

## 3.7 数值稳定性：抵消、ulp、补偿求和、稳定求根

**灾难性抵消**——相近数相减，有效位成片丢失：

```julia
bad(x)    = (1 - cos(x)) / x^2     # x→0 应 → 1/2
good(x)   = 2 * sin(x / 2)^2 / x^2 # 等价恒等式，无相近相减
bad(1e-8)     # 0.0！——cos(1e-8) 舍入成 1.0，差值全丢
good(1e-8)    # ≈ 0.5 ✓
```

**ulp（最后位单位）直觉**——大数附近"分辨率"变粗：

```julia
(1e16 + 1) - 1e16 == 0.0     # 1e16 处 ulp=2：加 1 被吞
(1e16 + 2) - 1e16 == 2.0     # 加 2 恰好一个 ulp：精确保留
```

**Kahan 补偿求和**——把每步丢失的低位记回来：

```julia
function kahan_sum(v)
    s = c = 0.0
    for x in v
        y = x - c; t = s + y; c = (t - s) - y; s = t
    end
    s
end
vals = [1e16; ones(10_000)]              # 一个大数 + 一万个小数（真增量 10000）
# 实测（--check-bounds=yes 下）：朴素累加差 10000，内置 sum 差 626，Kahan 差 0
```

两个要点：内置 `sum` 用 pairwise 分块求和，比手写循环好两个数量级——**但不要指望它逐位精确**；而且**它的舍入随编译旗标变**（实测 `--check-bounds=yes` 下归约路径不同，差值 38 ↔ 626）——要跨机器逐位复现，固定旗标或用 Kahan/BigFloat 拿参考值。

**稳定求根**——二次方程避免 `b ± √Δ` 的抵消：

```julia
function stable_quad(a, b, c)
    Δ = b^2 - 4a * c
    Δ < 0 && error("复根")
    s = b >= 0 ? 1.0 : -1.0          # 别用 sign(b)：sign(0)==0，b=0 时 c/q=Inf！
    q = -0.5 * (b + s * sqrt(Δ))     # 同号相加，绝不抵消
    (q / a, c / q)                   # 另一根走韦达定理（积 = c/a）
end
# x² - 1e8x + 1 的小根：稳定式 1.0e-8 ✓，教科书公式 7.45e-9（丢了一半有效位）
```

方法论一句话：**相近数相减是原罪**——改写恒等式、有理化、或换算法（`expm1`/`log1p` 同族思想：Julia 内置了这两个"避开抵消"的函数，小 x 的 `eˣ-1`、`ln(1+x)` 请直接用）。

## 3.8 坑位清单

1. **`//` 是有理数除法不是注释**：C++ 肌肉记忆写 `x = 5  // 赋值` 会得到 `5 // 赋值` 的解析错误或意外有理数——注释只有 `#`。
2. **`Int(3.99)` 抛 InexactError**：浮点转整必须显式选 trunc/floor/ceil/round（3.5）。
3. **`typemax(Float64) == Inf`**：想要最大有限值用 `floatmax`（3.2）。
4. **`num`/`den` 不存在**：公开函数是 `numerator`/`denominator`（3.4）。
5. **`round` 的五取偶**：`round(2.5) == 2`、`round(3.5) == 4`——银行家舍入，跟 C 的 `round`（远离零）不同。
6. **比较浮点永远 `≈`**：`isapprox(a, b; rtol, atol)` 可调容差；`==` 只配整数/位级比较用。
7. **相近数相减是原罪**：`(1-cos x)/x²` 在小 x 全错——改写恒等式；`eˣ-1`/`ln(1+x)` 用内置 `expm1/log1p`（3.7）。
8. **`sign(0) == 0` 不是 1**：二次方程稳定求根里用它 → 除零得 Inf——手写 `b >= 0 ? 1.0 : -1.0`（3.7 实测）。
9. **`sum` 的舍入随编译旗标变**：`--check-bounds=yes` 走不同归约路径（实测 38 ↔ 626）——逐位复现要固定旗标或 Kahan/BigFloat（3.7 实测）。
