## 72.1 秩序集与序型

> **定义 1.68（秩序）** 线性序 < 是 W 上的**秩序**（良序）当且仅当
> W 的每个非空子集都有 <-最小元。(W,<) 称秩序集。

**例 1.21（换顶序）** 在 ω 上定义 <₀：n <₀ 0 对一切 n ≠ 0，其余
照抄通常的 <。则 (ω,<₀) 仍是秩序：非空子集 S 若不含 0，就取通常
最小元；若 S={0}，最小元就是 0；若 S 同时含 0 与非零数，则非零部分
的通常最小元仍小于 S 中其余每个元素（包括 0）。所以任何 S 都有
<₀-最小元；只是 0 从全序的底部被移到了顶部，成为**最大元**。
(ω,<) 与 (ω,<₀) 不同构（一个无最大元一个有）——**同一个集合可以背着不同
的秩序**，序不在集合里，在"怎么排"里。

**前段**：秩序集 (W,<) 与 u ∈ W 的**线段** W[u] = {y ∈ W | y < u}
（= 半开区间 [min, u)）。**例 1.22**：序数的非空集合在 ∈ 序下是
秩序集。**例 1.23**：(ω,<)、(ω+1,<)、(ω,<₀) 三个秩序：后两个
同构，第一个同构于它们的前段。**例 1.24**：[α]^<ω（α ≥ ω 序数的
有限子集全体）按 max-差序（max(x∩y) ∈ x 或相等后比大小——即 69
章典型序的高维版）是秩序集。

**定义 1.69** 保序映射（a <A b → f(a) <B f(b)）、倒序映射、同构
（保序+满射）、自同构、嵌入。线性序世界的这些词与 69.8 的稠密序
词汇共享语法。

**问题 1.3（可秩序化问题）**：每个集合都能排成秩序吗？——冯琦挂
出这个问号，76 章选择公理给出"是"的答案（良序定理），而 75 章的
Hartogs 思路（74 章 ω₁ 的推广）将说明 ZF 单独给不出反例。这是
全教程最重要的悬念线之一。

## 72.2 刚性、可比较与表示

> **引理 1.13** f: (W,<) → (W,<) 单增 → ∀a ∈ W(a ≤ f(a))。
> *证明*：X = {a | f(a) < a} 非空则取最小 z，w = f(z) < z 给
> f(w) < f(z) = w，w ∈ X 更小——矛盾。∎（68 章九条事实之 (5)(6)
> 的序论抽象。）

> **定理 1.62（刚性定理）** (1) 秩序集的自同构只有恒等；(2) 两个
> 同构秩序集之间的同构唯一；(3) **没有秩序集与自己的前段同构**。
> *证明*：(3) 反例给单增 f: W → W 使 f(u) < u，与引理 1.13 冲突；
> (1)(2) 由 (3) 与分解技术导出。∎

秩序是"一点变换余地都没有"的结构——69 章说过稠密无端点序正相反
（康托尔同构定理：可数范围内只有一个）。两个极端之间是模型论的
整片光谱。

> **定理 1.63（秩序可比较定理）** (W₁,<₁)、(W₂,<₂) 两个秩序集：
> (1) 同构；(2) W₁ ≅ W₂ 的某前段；(3) W₂ ≅ W₁ 的某前段——三者恰居
> 其一。*证明*：f = {(x,y) | (W₁[x],<₁) ≅ (W₂[y],<₂)}，刚性保证
> f 单值，dom(f) 是前段之并；若两边都没吃满，最小缺口处又能延拓
> 一步——矛盾。∎

> **定理 1.64（表示定理）** 每个秩序集唯一地同构于一个序数。
> *证明*：Ψ(x,α) := (W[x],<) ≅ (α,∈) 是泛函定义式（唯一性由刚
> 性）。若某 x₀ 无序数对应，取 <-最小反例 x₀；对每个 x < x₀ 取唯一
> 对应序数，**替换公理**收成集合 y = {α_x | x ∈ W[x₀]}——y 传递
> 且元素皆序数，故 y 是序数，且 (W[x₀],<) ≅ (y,∈)，矛盾于 x₀ 是
> 反例。再对整个 W 用一次替换，得全局的序数。∎

**定义 1.70（序型）** ot(W,<) := 与 (W,<) 同构的唯一序数。W 是序
数的集合且 < 为 ∈ 时简记 ot(W)。71 章定义 1.57 的"内禀序数"与
"秩序长度"自此合一：**序数 = 序数的序型 = 自身**。

**定理 1.65**：X 可秩序化 ⟺ X 与某序数双射（表示定理 + 反向把序
数上的 ∈ 拖回 X）。**定理 1.66**：有限集必可秩序化；两个有限线性
序集同构 ⟺ 集合间有双射；有限线性序集都是秩序集。

## 72.3 雪崩映射：序数集合的自然列表

> **定义 1.71** 序数集合 X 的**雪崩映射**：X → ot(X)，x ↦ ot(x∩X)
> （x 的名次 = x 之前 X 里元素的个数）；逆映射称为 X 的**自然列表**。

**引理 1.14** 恰好刻画了自然列表的两条等价读法：f 是同构 ⟺ f 满足
"雪崩递归式" f(α) = f[α∩X]；且此时 f(α) = ot(α∩X)。**命题 1.22**：
T 是自然列表时 T↾α 就是 T(α)∩A 的自然列表——**前段的列表是列表
的前段**（68 章定理 1.11 的序数版）。

**递归计算**：给定非空序数集 A，g(X) = min(X)（X 非空）或 A 的补
集算子；f(α) = g(A − rng(f↾α))；到耗尽处 f: θ → A 就是自然列表。
逐项形式：f(0) = min(A)，f(β+1) = min(A − rng(f↾β+1))，极限处
继续——与 ω 情形（68 章命题 1.12(3)）一脉相承。机器通道把这条
"贪心取最小"流水线跑成程序：Prolog/Julia 对有限序数集现场生成
自然列表并验证保序。

## 72.4 极限点与闭集：club 的序数侧写

> **定义 1.72**（λ 非零极限，A ⊆ λ 或序数集）：
> (1) A 在 λ 中**无界**：∀β<λ ∃α∈A(β<α)；
> (2) λ 是 A 的**极限点**：A∩λ 在 λ 中无界；A′ := 全体极限点；
> (3) C 是**闭集**：C 的每个极限点都在 C 中；
> (4) C 是 λ 的闭子集：C∪{λ} 是闭集；
> (5) C 是 λ 的**无界闭子集**（club）：既无界又闭。

**命题 1.23**：α 是 A′ 的极限点 → α∩A′ 保序嵌入 α∩A 且
ot(α∩A′) ≤ ot(α∩A)；A′ 总是闭集。

> **定义 1.73** 序数函数 f: α → β；f 的上确界 sup(rng(f))；
> f **单增连续**（连续嵌入、正规函数 normal function）：严格单增 +
> 极限处 f(λ) = ⋃{f(β) | β < λ}。

> **定理 1.67（三大刻画）** (1) A 是闭集 ⟺ A 的自然列表定义在后
> 继序数上的单增连续函数；(2) 极限序数上的严格单增函数连续 ⟺ 值
> 域是上确界的闭子集；(3) A 是 λ 的 club ⟺ A 的自然列表是从 ot(A)
> 到 λ 的无界连续嵌入。

"闭集 = 连续列举"——拓扑语言与函数语言互译的字典，77 章讲滤子与
非荟萃理想时直接调用。

## 72.5 共尾度与正则序数

> **定义 1.74（共尾度）** 非零极限序数 α：
> cf(α) = min{ot(A) | A ⊆ α 无界}——最短无界子集的长度。

**定理 1.68**（cf 的刻画）、**定理 1.69**（cf(α) = 最短无界**闭**
子集的长度——用连续化技巧 g(β) = ⋃(f(s+1)) 把任意无界列加密成
club）、**定理 1.70**（**cf(cf(α)) = cf(α)**——共尾度是自己的
共尾度）、**推论 1.10**、**定理 1.71**（无界子集必含长为 cf(α)
的无界子集；单调列的 cf 传递：sup(f) = α → cf(α) = cf(dom)）。

> **定义 1.75** α **正则** ⟺ cf(α) = α。**例 1.26**：ω 正则；
> cf(α) 总是正则序数。**问题 1.4**：存在 > ω 的正则序数吗？
> （74 章：ω₁ 正则——不可数正则序数的第一个样本；更大的正则
> 序数是否存在的问题在 76-79 章与大基数、选择公理纠缠。）

> **定理 1.72** α 正则 ⟺ 任意两个无界子集 ∈-同构 ⟺ 任意两个
> 无界闭子集连续同构。
> **定理 1.73** κ > ω 正则时：C 是 club ⟺ C 的自然列表连续 ⟺ C
> 是某连续嵌入的值域。
> **定理 1.74（正规函数的不动点定理）** κ > ω 正则、f: κ → κ 连
> 续嵌入 → {ξ < κ | f(ξ) = ξ} 是 club。
> *证明*：不动点集的闭性由连续性；无界性：任给 β < κ，递归
> β_{n+1} = f(β_n)+1，λ = sup_n β_n < κ（cf(κ) = κ > ω 截断），
> 则 f(λ) = ⋃f(β_n) = λ。∎

——闭包算子的经典模式："从任意种子迭代 ω 次取 sup 就落进不动点
集"。递归论的不动点定理、模型论的正则基数理论共享这个骨架；73
章 ε₀ = sup{ω, ω^ω, ω^ω^ω, …} 正是它在序数算术上的第一次点火。

## 72.6 序数算术：三条装配线

先给**结构定义**（康托尔式的"先造结构再取序型"）：

- **直和**（定义 1.76）：(A + B, <) 把 B 整体摞在 A 上（A 的元素
  都小于 B 的元素）。
- **字典序乘积**（定义 1.77）：A × B 按 (a,b) < (a′,b′) ⟺ a < a′
  ∨ (a = a′ ∧ b < b′)——**垂直**字典序（先比 A）。
- **水平字典序**（定义 1.78）：(a,b) < (a′,b′) ⟺ b < b′ ∨
  (b = b′ ∧ a < a′)——**水平**（先比 B）。冯琦的几何直觉：把 B
  立成垂线，每个点换成一整条 A 色的水平线。

**命题 1.24**：这些构造都产出秩序集（对第二分量归纳）。

> **定义 1.79 + 命题 1.25（加法）** α + β := ot(α×{0} + β×{1})，
> 且满足递归式：
> α + 0 = α；α + (β+1) = (α+β)+1；β 极限时 α+β = ⋃{α+γ | γ<β}。
> （0/后继/极限三款——定理 1.59 装配线的标准产品。）

**不可交换**：1 + ω = ω ≠ ω + 1。**引理 1.15（连续性）**：β =
sup βₛ ⟹ α+β = sup(α+βₛ)。**定理 1.75**：结合律 α+(β+γ) =
(α+β)+γ（对 γ 超限归纳，极限处用连续性）；**左消去律** α<β →
γ+α < γ+β（及 α+β = α+γ → β = γ）；**右弱保序** α<β →
α+γ ≤ β+γ（只弱不严：ω+1 ≤ ω+2 都后继，但 1+ω = 2+ω = ω）；
**补差律** α ≤ β → ∃!γ(α+γ = β)。

> **定义 1.80 + 命题 1.26（乘法）** α·β := ot(β 张 A 色水平线的
> 水平字典序)，递归式：α·0 = 0；α·(β+1) = α·β + α；极限取并。
> 2·ω = ω（水平排 ω 条两元素线 = ω），ω·2 = ω+ω ≠ ω。

**定理 1.76**：左分配律 α·(β+γ) = α·β + α·γ（对 γ 归纳）、结合
律、左消去律、右弱保序——**没有右分配律**：(ω+1)·2 ≠ ω·2 + 1·2。

> **定义 1.81（指数）** α⁰ = 1；α^{β+1} = α^β·α；极限取并。
> **引理 1.17**：α≤β → ω^α ≤ ω^β；1<α ∧ β<γ → α^β < α^γ；
> β < γ <ω ⟹ γ·ω^β < ω^γ。

**引理 1.18（三连续）**：加、乘、指数对第二变量都连续（极限取
sup）。**推论 1.11**：α ↦ ω·α 与 α ↦ ω^α 都是正规函数——后者
的不动点链就是 ε₀（73 章）。**定理 1.77**（正则 κ 上三种运算的
界：α,β < κ → α+β < κ、α·β < κ、α^β < κ）。**引理 1.19**
（α ≤ β 时 {γ | α·γ ≤ β} 与 {γ | α^γ ≤ β} 有最大元）。
**引理 1.20（带余除法）**：∀δ ∀α≠0 ∃!⟨β,ρ⟩: δ = α·β + ρ ∧
ρ < α。（除法的余数唯一——序数算术里少见的"硬"唯一性。）

> **定理 1.80（康托尔范式）** 每个非零序数 α 唯一地写成
> **α = ω^{β₁}·k₁ + ω^{β₂}·k₂ + … + ω^{βₙ}·kₙ**，
> 其中 β₁ > β₂ > … > βₙ，0 < kᵢ < ω（自然数系数）。
> *证明*：存在性对 α 归纳：取最大的 ω^β ≤ α（引理 1.19），带余
> 除法剥出系数 k₁，余数 ρ < ω^{β₁} 递归展开。唯一性由引理 1.17(3)
> （最大指数被 α 唯一钉死）+ 归纳。∎

例 1.28：ω+ω、ω²、ω³、ω^ω = ⋃{ωⁿ} 的展开。定理 1.78/1.79
（自然数的带余除法与基 b 展开）是它的有限投影——70 章二进制定理
1.47 的一般化。康托尔范式是**序数的十进制**：一切序数算术可以机
械地在范式上进行（73 章的机器通道实现范式加法器），而 ε₀ = ω^ε₀
是"范式写不出的最小序数"——帕夫洛维茨边界、帕里斯-哈林顿与古德
斯坦定理的分水岭。

## 72.7 机器通道

序数算术是本章机器化的主战场。三条证明通道各有官方锚点：Lean
的序数算术全在 mathlib（含康托尔范式与正规函数不动点的成品）、
Isabelle/ZF 的 `OrderType.thy` 正是"秩序—序型—oadd/omult"的
官方影子、Coq/Agda 承载刚性与自然列表的有限截面。三条计算通道

### Lean：官方算术锚点与 ε₀

Lean（examples/lean/Settheory/Ch72Wellorder.lean）先对齐三款
递归式：加法的后继款 α+(β+1) = (α+β)+1 恰是 `add_assoc` 的对称
形式（`Ordinal.add_succ` 在本版已弃用——用弃用名会触发 warning
直接判 FAIL；且 add_assoc 本身是 (a+b)+c → a+(b+c) 方向，书页
公式要取 `.symm`）：

```lean
example (a b : Ordinal) : a + (b + 1) = a + b + 1 := (add_assoc a b 1).symm
```

不可交换三见证全部官方化：`Ordinal.one_add_omega0`（1+ω = ω）、
`Ordinal.natCast_mul_omega0`（2·ω = ω；陈述用显式 ↑(2:ℕ) 避开
数字与转换的 defeq 泥潭）。反侧 ω < ω·2 需要手工拆解：数字 2
与 `Order.succ 1` 的互认分两步——succ ≡ +1 是 rfl 级（SuccAddOrder
实例本身就是 rfl 证明），但 2 与 1+1 之间必须走 `one_add_one_eq_two`
（B1 轮实测：正向 rfl 对 (2:Ordinal) = 1+1 失败，得反向 rw 后
靠 succ ≡ +1 的 rfl 收尾）：

```lean
private theorem two_eq_succ_one : (2 : Ordinal) = Order.succ 1 := by
  rw [← one_add_one_eq_two]
  rfl                                -- 1+1 = succ 1 是 rfl 级，但 rw 的自动 rfl 太弱

theorem omega_mul_two : ω * 2 = ω + ω := by
  rw [two_eq_succ_one, Ordinal.mul_succ, mul_one]
```

右分配律失效的见证 (ω+1)·(1+1) ≠ ω·(1+1)+1·(1+1) 用一条 calc
链把左侧化到 ω·(1+1)+1（中途用 `one_add_omega0` 吃掉中段的
1+ω——这正是"左吸收"在起作用），右侧经 `one_mul` 与
`add_assoc` 归位成 succ(ω·(1+1)+1)，后继严格增大收尾。
**定理 1.80 的官方化身**是
`Ordinal.CNF ω o`：`CNF.eval_coeff` 重构（存在性）、`CNF.coeff_inj`
（唯一性）、`CNF.snd_lt`（系数 < ω）。**定理 1.74 的官方化身**
是 `Ordinal.nfp` 一族：`nfp_fp` 给不动点 f(nfp f a) = nfp f a、
`iSup_iterate_eq_nfp` 把 nfp 写成 ω-迭代的 sup——书页
"β_{n+1} = f(β_n)、λ = sup_n β_n"的逐字版、`not_bddAbove_fp`
给不动点集的无界性。ε₀ 一行落账：

```lean
theorem omega_opow_epsilon : (ω : Ordinal) ^ ε₀ = ε₀ := by
  rw [Ordinal.epsilon_zero_eq_nfp]
  exact Ordinal.nfp_fp (Ordinal.isNormal_opow Ordinal.one_lt_omega0) 0
```

雪崩映射（定义 1.71）落在 `Ordinal.enumOrd` 一族：
`enumOrd_strictMono`（保序）、`range_enumOrd`（吃满）、
`id_le_enumOrd`（处处 ≥ 恒等——引理 1.13 的影子）。另一条实测
坑账：陈述 ω 幂的正规性不能写 `IsNormal (a ^ ·)`——匿名洞 `·`
被贪婪定型为 ℕ，`^` 随即解析成 Monoid 的 npow（指数 ℕ）而非
`Ordinal.opow`，宇宙签名以 {0, u+1} 分裂告终；写成
`IsNormal (fun x : Ordinal => a ^ x)` 钉死指数类型即可。

### Isabelle/ZF：刚性定理与 oadd 三款

Isabelle（examples/isabelle/ST72/Wellorder.thy）的 `Order.thy`
就是冯琦 72.2 的官方版：`well_ord_trichotomy`（定理 1.63）、
`well_ord_iso_unique`（同构唯一）、`well_ord_iso_predE`（无秩序
集同构于自己的前段——定理 1.62(3)）、`ordertype_ord_iso`（表示
定理 1.64）。本章完整证明的引理 1.13 按书页路线走：良基归纳
（`well_ord_is_wf` + `wf_on_induct`），反例集取极小元 z，w = f(z)
< z 的单增性逼出更小的反例 w：

```isabelle
lemma mono_map_le:
  assumes wfA: "well_ord(A,r)" and fA: "f ∈ A->A"
      and mono: "∀x∈A. ∀y∈A. ⟨x,y⟩∈r ⟶ ⟨f`x,f`y⟩∈r"
  shows "∀a∈A. ⟨f`a,a⟩ ∉ r"
```

（ZF 逻辑里变元的函数应用必须写反引号形 ``f`x``；括号形 ``f(x)``
只对库常量合法，对变元 ``f :: i`` 会直接报 "operator not of
function type"——本轮实测的类型坑。）

oadd/omult 的三款递归式逐字对齐库锚点（`oadd_0`/`oadd_succ`/
`oadd_Limit`、`omult_0`/`omult_succ`/`omult_Limit`）。不可交换
见证 1++nat = nat 的完整证明是本章的"实弹"：极限款拆成
⋃k∈nat. 1++k，一个方向 `Union_least` + 按自然数归纳的辅助引理
（1++k ∈ nat），另一个方向每个 x 用 x ≤ 1++x 与 `oadd_succ`
落进 1++succ(x)——右邻不塌缩由 `oadd_1` + `ltI` 收尾
（nat < nat++1）。⚠️ ZF 的 `1` 是 succ(0) 的缩写（`nat_1I` 的
证明就是 `nat_0I THEN nat_succI`）——数字与 succ 的互换是 rfl 级。
`oadd_0`/`oadd_succ` 带 `Ord(·)` 侧条件，但不用手喂：`Ord_0`/
`Ord_succ_iff`/`nat_into_Ord` 都是 iff/simp 规则，simp 自动销账。
本轮两个实测坑：`erule nat_induct` 之后归纳步的变量是新鲜的
`x`，`subgoal_tac` 里写原来的 `n` 会静默失配、把目标搅成两个
变量混串的残局；辅助引理 `one_oadd_fin_nat` 因此直接两行
`simp add: oadd_0/oadd_succ + nat_1I/nat_succI` 收掉。另一坑：
`OrdmemD` 的结论是 `j<=i`——本版 `le` 是 `x < succ(y)` 的缩写
（序数 ≤），**不是**子集关系；要从 `x ∈ nat` 得 `x ⊆ nat`，
正路是 `Ord_is_Transset` + 展开 `Transset_def`（∀x∈A. x⊆A）。

### Coq/Agda：刚性与自然列表的有限截面

Coq（examples/coq/Ch72_wellorder.v）把引理 1.13 的无穷下降
反证在自然数上展开成一步归纳（f n < f(n+1) + n ≤ f n）：

```coq
Lemma mono_le : forall f, strict_mono f -> forall n, n <= f n.
Proof.
  intros f Hmono n. induction n as [|n IH].
  - apply Nat.le_0_l.
  - assert (Hs : f n < f (S n)) by (apply Hmono, Nat.lt_succ_diag_r).
    lia.
Qed.
```

它立刻产出定理 1.62(3) 的有限版 `no_segment_iso`（长链嵌不进
短链：m-1 ≤ f(m-1) < n ≤ m-1 三面夹墙）与定理 1.62(1) 的完整
有限版 `rigid_fin`——对 k 强归纳，取 k 的前像分三种情形
（更小：归纳假设钉回原位；相等：直接得手；更大：严格单增越过 k
与引理 1.13 冲突），**有限秩序的自同构只有恒等**全程机器化。
Agda（examples/agda/Ch72_wellorder.agda）承载自然列表：升序
snoc 列表 `up n`、雪崩赋名次 `av`（x 的名次 = x 之前 X 里的
元素个数）、名次恒等 `av≡`（k ≤ n → av k n ≡ k——引理 1.14 的
方向一）、截断 `av-trunc`（k > n → 名次 = ot(X)——命题 1.22
"前段的列表是列表的前段"）与保序 `av-mono`（名次单调）。

### Julia/Python/Prolog：康托尔范式演算器

计算通道的统一表示：序数 < ε₀ = 指数-系数表 [(β₁,k₁),…,(βₙ,kₙ)]
（指数递归也是范式表；有限 n = [(0,n)]，无尾数设计——表示即
范式，相等即范式相等，定理 1.80 的唯一性内建于表示）。加法的
核心是**等指数项合并系数**：

```julia
extra = 0
if length(keep) < length(a.terms) && a.terms[length(keep)+1][1] == eb
    extra = a.terms[length(keep)+1][2]      # ω+ω = ω·2：合并！
end
```

（老坑正账：漏写合并则 ω+ω = ω 假绿——B1 轮的原坑，本通道明写
成不变量。）乘法是四情形装配线：双方有限（系数相乘）、
α 有限 β 无穷（首项吞并 + 尾递归：2·(ω+3) = ω+6）、β 有限 ≥ 2
（α·m = α+…+α——(ω+1)·2 = ω·2+1 的来源，右分配律失效的机制
现场可见）、双方无穷（头项 ω^(ea+eb)·cb）。勘误连带：02 章
Julia 旧演算器的"有限×无穷"分支曾丢有限尾巴（2·(ω+1) 会算成
ω+1），本轮机器审计抓出并一并修正（n·(ω+m) = ω+n·m），02 章
补回归断言 2·(ω+3) = ω+6。网格里 9³ 组加法结合/乘法结合/
左分配/右弱保序全量通过（平局如实计数：1+ω = 2+ω = ω）。

Python 通道（examples/python/72_wellorder.py）加两件重器：**序数
差 odiff**（y ≤ x 时唯一 γ 使 y+γ = x——定理 1.75 补差律的可执行
版，按首项剥层：低指数整块被吞 / 同指数差系数 / 首项相同递归）
与**带余除法的唯一性对拍**（引理 1.20）：候选池封闭化（掺入全部
两两乘积）后对 72 对 (δ,α) 用穷举搜索断言"满足 δ = α·β+ρ ∧ ρ<α
的 (β,ρ) 恰一组"——存在性与唯一性同时落账。两座不动点塔现场
点火（定理 1.74）：x ↦ ω·x 从 1 出发 1→ω→ω²→…，塔顶实弹验证
ω·ω^ω = ω^ω（1+ω = ω 在指数层吞并）；x ↦ ω^x 的塔就是 ε₀ 的
逼近序列（73 章发射台）。

Prolog（examples/prolog/72_wellorder.pl）在 ω^ω 以下的多项式带
（指数为自然数）复刻同一演算器：乘法用互斥 if 链免 cut 防串
（坑账：带 cut 的分情形子句若卫式在后，剪枝会吞掉后续子句），
带余除法用 findall 回溯搜索天然合体，自然列表用贪心取最小
（`greedy`/`rank_in`：名次恒等于位次——雪崩映射的谓词形态）。

### 边界如实标注

共尾度与不动点定理（定理 1.74）的无穷本体（cf(α) 的最小化、
club 的闭性）机器不可全达：Lean 的 `Ordinal.nfp`/`not_bddAbove_fp`
覆盖了不动点的构造与无界，但"κ > ω 正则"层面的滤子/club 理论
要等 77 章；Prolog 的多项式带天花板 ω^ω 正是 ε₀ 之下的第一道
断流。这些边界不是缺陷而是结构——"为什么 ε₀ 恰是类型论里可证
终止性的边界"在 73 章正式展开。

## 72.8 收束：长度的算术

秩序的可比较（定理 1.63）让"长度"成为全序类上良定义的量，表示定
理把每个长度钉在一个序数上，序数算术再让长度可以做加、乘、指数
——但每一项运算都**以第二变量为递归轴**：左严右弱、连续不交换。
这套"带着方向性的算术"在康托尔范式处获得标准形，然后立刻显示
其深度：自然数系的算术（交换、良基、完全可计算）只是 ω 层楼的
投影，楼上每升一层，可计算性的边界就退一步。73 章沿这条楼梯上行
到 ε₀，在古德斯坦定理处与帕亚诺算术的证明论极限正面相撞。
