# 14 · Lévy 层级：Σₙ/Πₙ 类、关系与函数

> 公式的复杂度不是深度，是量词的**交替**——一层交替一级阶梯。
> ——Lévy 层级的格言

本章覆盖 Jech §14：Σₙ/Πₙ/Δₙ 层级的定义、引理 14.1-14.5
（封闭规则与函数运算）、方向性绝对性、良基性的 Δ₁ 地位、
基数概念的 Π₁ 地位。

## 14.1 层级定义

Σ₀ = Π₀ = Δ₀（受限公式）；**Σ_{n+1}** = 形如 ∃x₁...∃xₖ ψ
（ψ 是 Πₙ）的公式；**Π_{n+1}** 对偶；**Δₙ = Σₙ ∩ Πₙ**
（可证等价于两个形态）。类 C 是 Σₙ 的若 C = {x : φ(x)} 对
某 Σₙ 公式 φ；函数 F 是 Σₙ 的若 y = F(x) 是 Σₙ 关系。

**引理 14.1** 十个 Gödel 运算都是 Σ₀ 函数——证明沿复合
结构归纳，四条款同时推进（(14.1)-(14.4)：成员关系、受限量词、
等于关系、代入）。

## 14.2 封闭规则：九条运算律

**引理 14.2**（n ≥ 1）：
(i) Σₙ 封闭于 ∃x、∧、∨、受限量词——**受限量词的封闭靠
收集原则**（(14.5) 的 ∀u∈x∃z 改写为 ∃y∀u∈x∃z∈y——第 09
章的秩技巧正式上岗）；
(ii) Πₙ 封闭于对偶运算；
(iii) ¬ 翻转 Σₙ↔Πₙ；
(iv) → 的组合规则；
(v) Δₙ 全封闭；
(vi)-(ix) 函数规则：Σₙ 函数的定义域 Σₙ、带 Πₙ 定义域的
Σₙ 函数是 Πₙ、复合 Σₙ、P(F(x)) 替换 Σₙ。

**引理 14.5**：超穷递归 F(α) = G(F↾α) 保 Σₙ——层级的
动力学稳定性。

机器化的核心是**可执行判定器**（三通道同构实现）。Julia
（`examples/julia/14_levy.jl`）：

```julia
ex_over(::L0) = Sg(1)                      # 受限上 ∃ → Σ₁
ex_over(s::Sg) = s                         # Σₙ 上 ∃ 同层吸收
ex_over(p::Pi_) = Sg(p.n + 1)              # Πₙ 上 ∃ 升层

all_over(l) = dual(ex_over(dual(l)))       # 全称 = 对偶
```

量词链解析器（相邻同型压缩 + 交替计数）：`∃x∀y∃z ψ₀ → Σ₃`、
`∀x∃y ψ₀ → Π₂`、`∃x∃y ψ₀ → Σ₁`（同型吸收）。Python
（`14_levy.py`）同构规则 + **算术直觉**：Σ₁ = 可枚举见证
（"y|x" = ∃z. y·z = x 的见证搜索）；Π₁ = 无限反驳（素数性
作为**有界** Π₁ 是 Δ₀ 可判定——受限量词的"有限性红利"）。
Prolog（`14_levy.pl`）的 `alternate_depth` 推理机输出全部
示例正确（含吸收与对偶）。Coq（`Ch14_levy.v`）把 lev 标签
代数做成证明对象：`dual_involutive`、`all_over_sg`（∀ over
Σₙ = Π_{n+1}）由 reflexivity 关闭。Agda（`Ch14_levy.agda`）
同构 + `is-Δ` 数据类型的构造性声明。

## 14.3 方向性绝对性

**Σ₁ 上绝对**：M ⊨ ∃z φ₀ ⟹ V ⊨ 同（见证 z 在 M 内，受限
部分绝对——**向上安全**）。**Π₁ 下绝对**（对偶：V 的无
反例 ⟹ M 无反例）。**Δ₁ 双向绝对**——引理 12.1 的全部
Δ₀ 概念 + 良基性：

**引理 14.3** "E 良基" 是 Δ₁：Σ₁ 形态 ∃秩函数（ρ : P → Ord
严格保序）；Π₁ 形态 无下降列（(12.19-12.20)）。双向 ⟹ 对
一切传递 ZF 模型绝对。

**引理 14.4（反方向的界碑）** "x 是基数/正则/极限基数"
是 **Π₁** 且非 Σ₁（"非基数" = ∃双射是 Σ₁）。P(X) 运算同样
Π₁ 非 Σ₁。**非绝对性的根源是见证逃逸**：模型 M 内的双射
缺席使 M 误认基数身份（第 10 章 Skolem 悖论的形式解剖）。
习题 14.2-14.3：可数性、|X| ≤ |Y|、|X| = |Y| 是 Σ₁（上绝对：
模型内的等势见证外部有效）。

Lean（`Ch14Levy.lean`）给方向性的语义核（见证的嵌入安全性
一行 example）+ 地位表讲义。Isabelle（`ST14/Levy.thy`）锚定
受限公式的绝对性基线（引理 10.1 回响：Transset 的成员闭包
验证）——Lévy 层级的完整形式化不在 ZF 库（如实标注），由
判定器通道承载。

## 14.4 层级与 L 篇的合流

Lévy 层级是 L 篇的语法心脏：def(U) 的"可定义"以 Δ₀/Σ₁ 分
层后，Condensation 的绝对性论证（第 13 章）精确地说就是
"y = L_α 是 Δ₁"；OD/HOD（第 15 章）按 Σₙ 参数定义分层；
0#（第 30 章）的存在性等价于 L 的 Σ₁ 不可定义类突破了
L 的层级。**语法的分层最终成为集合论宇宙的解剖学**。
