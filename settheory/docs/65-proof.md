# 65 · 证明与后承：链条、Tarski 条件与分层策略

> 本章提炼 Makinson 第 10 章：初等推导（树形式与线性形式）、
> 后承关系的 Tarski 三条件（强自反、单调、累积传递）、链条的
> 可靠性定理及证明、条件证明（→I）与分层策略（∨ 消除、反证
> 法、任意实例化）。它是 51 章可靠性/完备性的证明论侧——61 章
> (p→q) ⊢ (q→p) 的"直觉答案为何对"在此得到操作语义。

## 65.1 初等推导

**动机例**：{（p∨¬q)→(s→r), ¬s→q, ¬q} ⊨ r。不用真值表而用
"链"：¬q → ∨⁺ p∨¬q → MP s→r；¬q + ¬s→q → MT ¬¬s → DN s；
s + s→r → MP r。

**树形式**：叶标前提（可重复），父节点标从子节点推断出的公式。
树揭示结构但占空间且重复叶。

**线性形式**（chain）：带注记的有限序列——第 i 行标公式与
"从哪几行由什么规则得到"。两者可互相转化（squeeze/unfold）。

**为什么链条有效**——Tarski 三条件：

1. **强自反**：a ∈ A ⟹ A ⊢ a
2. **单调**：A ⊢ b 且 A ⊆ B ⟹ B ⊢ b
3. **累积传递**（cut）：A ⊢ b 对一切 b ∈ B，且 A∪B ⊢ c ⟹ A ⊢ c

满足三者的关系称为**后承关系**（consequence relation）。命题
永真蕴含 ⊨ 与一阶逻辑蕴含 ⊨ 都满足（验证：对任意赋值逐一检查）。

**链条可靠性定理**：⊨ ⊆ ⊢（即 ⊨ 的每条规则都在 ⊢ 中）且 ⊢
满足 Tarski 三条件，则存在初等推导 ⟹ A ⊢ a。证明用**累积归纳**
（59 章）——对推导长度 n 归纳，每步用到三条件之一。

## 65.2 后承作为运算

后承关系 ⊢ 可等价地表达为**后承运算** Cn(A) = {a : A ⊢ a}，
满足：包含（A ⊆ Cn(A)）、单调（A ⊆ B ⟹ Cn(A) ⊆ Cn(B)）、
幂等（Cn(Cn(A)) = Cn(A)）。后承运算即**闭包算子**——57 章
R[X] 闭包的又一化身。

**非演绎推理**中单调可败（新证据推翻旧结论——DNA 反证）；传递
也可疑（小风险链起来变大风险——"链不如最弱环节"）。非单调
逻辑的形式化由此出发。

## 65.3 条件证明（→I）

**分层证明**：允许在推导中引入**临时假设**（supposition），
在其作用域内做初等推导，最后**撤销**（discharge）假设得结论。
这使 → 的引入规则成为可能——**二级策略**。

- **条件证明（CP）**：假设 a，推导得 b，撤销假设得 a→b。
  可靠性论证：若 A∪{a} ⊨ b，则 A ⊨ a→b（对任意赋值分情况）。
- **∨ 消除**（分情况证明）：假设 a 得 c，假设 b 得 c，撤销两假设
  从 a∨b 得 c。
- **反证法**（RAA）：假设 ¬a 推出矛盾（b∧¬b），撤销得 a。
  可靠性：A∪{¬a} 不一致 ⟹ A ⊨ a。
- **∀ 任意实例化**：对任意新鲜常项 c，从 ∀x(a) 得 a[x:=c]。

**分层推导的压平**：任何二级推导可转化为等价的一级推导——
条件证明 a→b 的撤销对应于将假设 a 加入前提集，RAA 对应于
归谬。压平不改变结论的有效性。

## 65.4 推导的正式定义

**二级推导**：序列 a₁,…,aₙ 满足每项要么是前提、要么是当前活跃
假设、要么由前面的项经规则得到、要么由子推导撤销假设得到。

**可靠性定理（二级版）**：初等规则可靠 + 二级策略可靠 ⟹ 一切
二级推导的结论由前提蕴含。

## 65.5 机器通道

Lean 的 `Nat.rec`/`induction` 战术即条件证明的结构化身——假设
P(n) 得 P(n+1)，撤销得 ∀n P(n)。Isabelle 的 `Isar` 框架是
线性推导的工业级化身（`have`/`show`/`obtain` 对应注记链）。
Coq 的 `apply`/`intro`/`destruct` 即条件证明/分情况/反证法的
Curry-Howard 对应。Prolog 的 proof search 是链条的自动化。

## 65.6 收束

证明论 = 语义的"操作化"：⊨ 定义"什么应该推出"，⊢ 定义"怎么
推出"，可靠性定理保证二者一致。Tarski 三条件是链条合法性的
公理基础——它们不仅在经典逻辑中成立，也是一切"合理的"推理
系统的最低要求。66 章讨论它们的边界。
