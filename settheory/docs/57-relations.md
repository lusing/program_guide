# 57 · 关系：表格、有向图与关系代数

> 一辆车超过另一辆车；一个男孩爱一个女孩；一个整数整除另一个；
> 一个集合包含于另一个——它们都是"关系"。数学与计算机科学把这些
> 场景剥离成最裸的概念：**有序对的集合**。本章提炼 Makinson 第 2 章：
> 从有序对、笛卡尔积出发，建立关系的表格/有向图表象，发展逆、连接、
> 投影、选择、复合、像六种运算（其中三种直接来自数据库理论），
> 研究自反/对称/传递三性质，证明**等价关系与划分的一一对应**，
> 认识偏序、线性序、严格序，最后用传递闭包与集合在关系下的闭包
> 收束。它是 02 章序数理论、16 章偏序力迫的离散前身，也是数据库
> 关系代数的一阶课堂。

## 57.1 有序对与笛卡尔积

**有序对** (x₁, x₂) 与无序对 {x₁, x₂} 的区别在于次序。同一性判据：

    (x₁, x₂) = (y₁, y₂) 当且仅当 x₁ = y₁ 且 x₂ = y₂

对比无序对的判据（原书 Exercise 2.1.1，值得完整证一遍）：
{x₁, x₂} = {y₁, y₂} 当且仅当 (x₁ = y₁ 且 x₂ = y₂) 或
(x₁ = y₂ 且 x₂ = y₁)。从右到左显然；从左到右设 x₁ ≠ y₁，由
{x₁,x₂} ⊆ {y₁,y₂} 得 x₁ = y₂，再由反向包含得 y₁ = x₂，得第二种
配对；x₁ = y₁ 时类似。∎ n 元组的判据照推：逐坐标相等。

有序对能否还原为集合？可以——Kuratowski 编码 (a,b) := {{a},{a,b}}，
02 章 von Neumann 序数的构造里我们用过它的表亲。本篇按 Makinson
把有序对当原始概念（Alice Box 称之为"螺旋而非循环"：理解有序对
只需"一个东西排在另一个前面"这点点顺序感，不需要任何关系理论）。

**笛卡尔积**：A × B = {(a,b) : a ∈ A, b ∈ B}。Descartes 用 ℝ² 把
平面点变成数对，几何问题代数化——这是"数据表示"的鼻祖。基本
事实：

- **计数**：#(A × B) = #(A)·#(B)。证明是乘法原理的第一次正式
  使用：固定 a ∈ A 恰有 #(B) 个对 (a,b)，换一个 a 产生的对与之前
  全不相同（首坐标不同）。∎ 60 章计数篇将把乘法原理公理化。
- A ⊆ A′ 且 B ⊆ B′ 推出 A × B ⊆ A′ × B′。
- **非平凡刻画**（原书 Exercise 2.1.2 (2)(b)）：当 A、B 皆非空时，
  A × B = B × A 当且仅当 A = B。"←"显然；"→"证其逆否：设
  A ≠ B，不妨有 a ∈ A \ B；取 b ∈ B（非空！），则 (a,b) ∈ A × B
  而 (a,b) ∉ B × A。∎ 注意非空性不可省：A × ∅ = ∅ = ∅ × A 对
  任何 A 成立，但 A 不必等于 ∅。这个"空集例外"在 56 章广义交
  （空族交）已现过一次，还将反复出现。

注意 A × B ≠ B × A（一般地），但**计数**交换：#(A × B) = #(B × A)。
运算不交换、计数交换——这是 58 章等势（equinumerosity）思想的
预演：结构不同、大小相同。

## 57.2 关系作为集合

**定义**：从 A 到 B 的**二元关系**是 A × B 的任意子集。n 元关系
类似地取 A₁ × … × Aₙ 的子集；一元关系的极限情形就是子集本身。

因为关系是集合，56 章的一切立即适用：包含（**子关系** subrelation）、
交、并、补（相对 A × B）、空关系（= ∅，是任何关系的子关系）与
**全关系** A × B。计数：A 到 B 的关系恰有 2^(#(A×B)) 个——又见
幂集。

两个新概念：**域** dom(R) = {a : 存在 b，(a,b) ∈ R} 与**值域**
range(R) = {b : 存在 a，(a,b) ∈ R}。注意"source/target"（任一
满足 dom(R) ⊆ A、range(R) ⊆ B 的 A、B）不唯一——一个关系有无数
个 source/target，但 dom/range 是**最小**的那对。

**Warning Box（codomain 一词两义）**：有的书用 codomain 指 target，
有的指 range。本教程遵循 Makinson：domain/range 为最小者，
source/target 为任何上界。

## 57.3 表格与有向图

有限关系有两种经典表象：

- **表格**：行标 A、列标 B，格子填 1/0 表示 (a,b) 是否 ∈ R。
  这就是布尔矩阵——数据库的表、63 章真值表、46 章正则开代数的
  特征表，全是它。对 A × A 上的关系，**对角线**上的 1/0 记录
  自反性；沿对角线折叠的**对称性**检查正是 R = R⁻¹ 的表格版。
- **有向图 digraph**：每个元素画一点，(a,b) ∈ R 画一条 a→b 的
  箭头。56 章的 Hasse 图是它的"只画骨架边 + 约定箭头朝上"的
  压缩版——从 Hasse 图沿上行路径读出的就是包含关系的传递闭包。

**Warning Box（图不是证明）**：图示启发直觉、帮助构造反例，但
一般命题不能靠图证明；过度拥挤的图反而毁掉直觉。

## 57.4 关系上的运算

### 57.4.1 逆（converse）

R⁻¹ := {(b,a) : (a,b) ∈ R}。**逆不是补**：loves 的逆是 is loved
by，不是 doesn't love。基本律（Exercise 2.3.1 (2)）：

- dom(R⁻¹) = range(R)，range(R⁻¹) = dom(R)；
- (R⁻¹)⁻¹ = R；(R ∩ S)⁻¹ = R⁻¹ ∩ S⁻¹；(R ∪ S)⁻¹ = R⁻¹ ∪ S⁻¹
  ——与补对照：补把 ∩/∪ 对调，逆保持它们不变。

表格观点：沿对角线旋转 90°；有向图观点：全部箭头反向。

### 57.4.2 连接、投影、选择：关系代数三件套

设 R ⊆ A × B、S ⊆ B × C（人事数据库 R 记"工号—姓名"，S 记
"姓名—分机"）：

- **连接 join(R,S)** := {(a,b,c) : (a,b) ∈ R 且 (b,c) ∈ S}——
  三元关系，信息无损合并。数据库文化的 join 一词，在代数学家
  那里是"并"的意思——术语方言不同。
- **投影**：如 R 在第一坐标的投影 proj₁(R) = {a : 存在 b，
  (a,b) ∈ R}——恰好是 dom(R)！投影**降低元数**。
- **选择/限制**：R 限制到 A′ ⊆ A：{(a,b) ∈ R : a ∈ A′}——
  元数不变。

逆与选择保持元数，投影降元、连接升元——四种运算组合起来就能
做数据库查询的一切。本书 2.3.2 的数字例子（A = {2,3,13}、
B = {12,15,17}、C = {11,16,21}，R 为整除关系，S 为同奇偶关系）
值得手工全算一遍，57.9 节机器复算。

### 57.4.3 复合（composition）

**复合** S ∘ R := {(a,c) : 存在 x，(a,x) ∈ R 且 (x,c) ∈ S}。
它是 join(R,S) 向首尾两坐标的投影。de Morgan 称之为 relative
product；小孩认识"爷爷"用的就是它：F = father of，
P = parent of，则 P ∘ F = grandfather of。

**Alice Box（顺序之惑）**：为什么"father of a parent"写成 P ∘ F
而不是 F ∘ P？——为了与函数复合的记号传统一致（58 章）。记忆法：
(a,c) ∈ S ∘ R 读作"a 是某个 R-对象 c 的 S-对象"：**先用 R，后用
S**。复合的家族关系练习（原书 Exercise 2.3.3）有三个经典陷阱：

- M ∘ F（father of a mother）= 外公，不是"爷爷"（爷爷还包括
  父系）——**太宽**的答案错；
- S ∪ P 风格的"parent of a sister of"不能简写成 parent——a 是
  c 的 parent 未必经由 c 的姐妹——同样是太宽；
- B ∘ B（brother of a brother of）≠ brother：既太宽（c 可能没有
  第二个兄弟充当中介 x）又太窄（a 与 c 可能是同一人！）。

**代数律**（Exercise 2.3.3 (2)，两条都完整证明）：

**(S ∪ R) ∘ T = (S ∘ T) ∪ (R ∘ T)**：(a,c) ∈ 左边 iff 存在 x：
(a,x) ∈ T 且 (x,c) ∈ S ∪ R，iff (存在 x：(a,x) ∈ T 且 (x,c) ∈ S)
或 (存在 x：(a,x) ∈ T 且 (x,c) ∈ R)，iff (a,c) ∈ 右边。∎
（∃ 对 ∨ 的分配在这里两个方向都成立。）

**(S ∘ R)⁻¹ = R⁻¹ ∘ S⁻¹**：(a,c) ∈ 左边 iff (c,a) ∈ S ∘ R iff
存在 x：(c,x) ∈ R 且 (x,a) ∈ S，iff 存在 x：(x,c) ∈ R⁻¹ 且
(a,x) ∈ S⁻¹，iff (a,c) ∈ R⁻¹ ∘ S⁻¹。∎ 复合与逆**交换次序**——
与"脱袜子先脱鞋后脱袜"同理。

### 57.4.4 像（image）

元素版：R(a) := {b : (a,b) ∈ R}；子集版：R(X) := {b : 存在 x ∈ X，
(x,b) ∈ R}。像对并永远分配：R(X ∪ Y) = R(X) ∪ R(Y)；对交只有
⊇ 方向。**Warning（记号歧义）**：当 X 既是 A 的元素又是 A 的子集
时（如 A = {1,2,{1,2}}），R(X) 两种读法不同——有的作者改写
R[X]。分层类型系统（Lean/Agda 的 Set (Set α)）天然免疫此病，
朴素集合论要靠小心。

原书 Exercise 2.3.4 (3) 的自指小珍品：A₁ = ∅，A₂ = {∅}，
A₃ = {∅,{∅}}，…，每个 Aᵢ 既是元素又是（自身的）子集族成员
——von Neumann 自然数 0 = ∅、1 = {∅}、2 = {∅,{∅}}、… 的
雏形，02 章序数的正式构造。Makinson 说"这超出了本书范围"——
但它在我们的 02 章范围内。

## 57.5 自反、传递、对称

设 R 是 A 上关系（A² 的子集）：

- **自反**（reflexive over A）：一切 (a,a) ∈ R。例：≤、整除 ∣。
  **非自反**（irreflexive）：一切 (a,a) ∉ R。例：<。二者之外还有
  第三态（既非自反也非非自反）：如"互素"于自身有 2 与 2 不互素、
  1 与 1 互素。
- **传递**：aRb 且 bRc 推出 aRc。
- **对称**：aRb 推出 bRa。**不对称**（asymmetric）：aRb 与 bRc…
  不，aRb 推出非 bRa。例：<。同样有第三态（≤ 既非对称亦非
  不对称）。

三个 Warning 值得背下来：

1. **定义域依赖**：R 可能"在子集 B ⊆ A 上自反而非在 A 上自反"。
   谈自反/非自反必须指明相对哪个集合。
2. **传递关系的并可以不传递**：R = {(1,2)}、S = {(2,3)} 各自
   传递，R ∪ S 不传递（缺 (1,3)）。根子：传递律的前件有两个
   前提，(a,b) ∈ R 而 (b,c) ∈ S 时哪个假设都用不上。
3. **对称关系的复合可以不对称**：R = {(1,2),(2,1)}、
   S = {(2,3),(3,2)} 对称，但 S ∘ R 含 (1,3) 不含 (3,1)。
   反之，**交**保持对称与传递（逐条检查即可），**逆**保持一切
   三性质。

## 57.6 等价关系与划分：一一对应

自反 + 对称 = **相似关系**；再加传递 = **等价关系** ≈。例：
相等 I_A 是最小等价关系（含于一切等价关系——因为它们自反）；
A² 是最大等价关系；同奇偶、同余 mod n、同素因子集都是。

**划分**（partition）：A 的非空子集族 {Bᵢ}ᵢ∈I 满足两条件——
**两两不相交**（i ≠ j ⟹ Bᵢ ∩ Bⱼ = ∅）与**穷尽 A**
（⋃ᵢ Bᵢ = A）。Bᵢ 称**胞腔 cell**。最细划分 {{a} : a ∈ A} 对应
相等关系；最粗划分 {A} 对应全关系。

**定理（划分 ↔ 等价，双向）**——本章最重的证明，两方向完整给
出（原书 2.5.4 节）。

**划分 → 等价**：定义 aRb := a、b 同胞腔（存在 i：a,b ∈ Bᵢ）。
- 自反：穷尽性给每个 a 一个 i，a,a ∈ Bᵢ。∎
- 对称：显然。∎
- 传递：设 (a,b)、(b,c) ∈ R：有 i 使 a,b ∈ Bᵢ，有 j 使 b,c ∈ Bⱼ。
  则 b ∈ Bᵢ ∩ Bⱼ，两两不相交迫使 Bᵢ = Bⱼ（否则交空），故
  a,c ∈ Bᵢ。∎

**等价 → 划分**：对 a ∈ A 定义等价类 |a|≈ := {x : a ≈ x}
（即像 ≈(a)）。取类族 {|a| : a ∈ A}：
- 非空：自反给 a ∈ |a|。∎
- 穷尽：同上。∎
- 两两不相交（证其逆否）：设 |a| ∩ |a′| ≠ ∅，取 y 属于交。
  则 a ≈ y 且 a′ ≈ y；对称给 y ≈ a；两次传递（a′ ≈ y、y ≈ a 得
  a′ ≈ a；再与 a ≈ x 合成 a′ ≈ x）得 |a| ⊆ |a′|；对称地反向
  包含，故相等。∎

注意三个性质各用到什么：非空与穷尽只用**自反**；不相交用到
**全部三条**——少一条就垮（练习：找一个自反对称但不传递的关系，
看它的"类"如何重叠——如"分享至少一位共同祖先"）。

来回一趟回到原点：划分 → 等价 → 划分 复原原划分；等价 → 划分 →
等价 复原原等价。这就是一一对应（同构）的含义。**商集** A/≈ 就是
全体等价类的集合——11 章 Mostowski 坍缩、52 章 Łoś 定理的商构造
都是这个简单思想的层层升级。

机器通道把两头都做实：Python 对 2..16 的"同素因子集"关系算出
划分——恰为原书 Exercise 2.5.4 (b) 的答案：
{{2,4,8,16}, {3,9}, {5}, {6,12}, {7}, {10}, {11}, {13}, {14}, {15}}；
Isabelle 用官方锚点 `Union(A//r) = A`（商集穷尽）与
quotient 的等同刻画直接点亮。

## 57.7 序关系

### 57.7.1 偏序

传递 + 自反 + **反对称**（(a,b)、(b,a) ∈ R 推出 a = b——不对称
的最强可达形式，因为非空集上的自反关系不可能不对称）= **偏序**
⊑，(A,⊑) 称 **poset**。两大例：

- (𝒫(A), ⊆)：56 章已证反对称。
- (ℕ₊, ∣)（整除）：a ∣ a（k=1）；a ∣ b、b ∣ c 推出 a ∣ c
  （c = j·b = jk·a）；反对称：b = ka、a = jb 推出 kj = 1 故
  k = j = 1。∎ **换域要重证**：同一公式在 ℤ 上失败（1 ∣ −1 且
  −1 ∣ 1 但 1 ≠ −1，k = j = −1）；在 ℚ₊ 上更失败（2 ∣ 3 且
  3 ∣ 2！k = 3/2）。定义相同、宇宙不同、性质迥异——"定义域
  依赖"的又一课。

**极小 vs 最小**（minimal vs least，Ex 2.6.1 (2) 的五连断言）：
极小 = 没有严格更小者；最小 = ≤ 一切元素。

- (a) 最小 ⟹ 极小（否则有 b ⊏ a，与 a ≤ b 及反对称矛盾）。∎
- (b) 反之不成立：A = {1,2}、⊑ = I_A：两个极小，无最小。∎
- (c) 极小可无（ℤ 上的 ≤）、可一（ℕ 的 0）、可多（上例）。∎
- (d) 最小若存在则唯一（反对称）。∎
- (e) **有限非空 poset 必有极小元**：否则可造无限降链
  a₀ ⊐ a₁ ⊐ a₂ ⊐ …（传递性保证两两不同），与有限性矛盾。∎
  这个"粗糙归纳"的严格化是 59 章；它的超穷版本（关系良基 ⟹
  良基归纳）是 02 章超穷归纳的引擎。

对偶地有极大/最大。上下界与 glb（inf）：X 的下界 a：a ≤ 一切
x ∈ X；glb = 下界中的最大者。glb 若存在则唯一（反对称），且
a ≤ glb(X) ⟺ a 是 X 的下界（传递）。**反对称与传递对 glb 理论
缺一不可**——这正是 18 章格论的公理来源。

### 57.7.2 线性序与严格序

**完全性**：任给 a,b ∈ A，(a,b) ∈ R 或 (b,a) ∈ R。偏序 + 完全性
= **线性序/链**。ℕ 的 ≤、字典序是线性的；(𝒫(A), ⊆) 当 #A ≥ 2
不是（{a} 与 {b} 不可比）。**Warning（total ordering ≠ total
relation）**：全关系 A² 不是线性序（无反对称）——"total"一词
的两个用法毫无关系。线性序至多一个极小元，且极小即最小
（Ex 2.6.2 (2)：完全性逼出）。

**严格序** = 不对称 + 传递（严格偏序）。与偏序互相生成：
⊑ 的**严格部分** a ⊏ b := a ⊑ b 且 a ≠ b（(<) = (⊑ ∩ ≠)）；
反之 ⊑′ := (<) ∪ I_A 是偏序。两个方向都是恒等往返
（Ex 2.6.3 (4)，逐 iff 验证）。< 于 ℕ、真包含 ⊊ 于 𝒫(A) 是也。
**不对称 ⟹ 非自反**（a < a 与不对称立即矛盾）——但非自反 +
  传递**不**必不对称（需要反证一步，Ex 2.6.3 (1)(a)）。

Hasse 式图：只画**立即前驱**（b ⊏ c 且中间无 x）。原书
Exercise 2.6.3 (3)：2..13 上的整除偏序，立即前驱恰 9 对：
(2,4), (2,6), (2,10), (3,6), (3,9), (4,8), (4,12), (5,10), (6,12)。
素数 7、11、13 孤立。57.9 节机器复算。

## 57.8 闭包：把关系"补好"

### 57.8.1 传递闭包

想把不传递的 R"变传递"？不能改 R 本身，但可以扩大它。存在唯一
的**最小传递扩容**——传递闭包（Makinson 记 R*，本教程按惯例记
R⁺，把 R* 留给自反传递闭包 = R⁺ ∪ I_A）。三种等价定义，一个
概念的三张脸：

1. **有限路径版**（自下而上，适合计算）：(a,b) ∈ R⁺ iff 存在
   n ≥ 2 与序列 x₁,…,xₙ：a = x₁、b = xₙ、每步 xᵢ R xᵢ₊₁。
2. **迭代版**：R₀ = R；Rₙ₊₁ = Rₙ ∪ {(a,c) : 存在 x，(a,x) ∈ Rₙ、
   (x,c) ∈ R}；R⁺ = ⋃ₙ Rₙ。
3. **交版**（自上而下，适合证明）：R⁺ = ⋂{S : R ⊆ S ⊆ A²，S
   传递}——一切传递扩容之交。最小性立得：交保持传递
  （Ex 2.4.2：逐元素验证），且任何传递扩容都在交的族里。∎

三种定义的等价性是 59 章"递归定义三模式"的第一次预告——**同一
个递归概念，计算视角与证明视角各有 удоб**。基本律（57.9 机器验证）：

- 对称关系的传递闭包对称（路径反转即可）；
- 不对称关系的传递闭包**不必**不对称：R = {(1,2),(2,3),(3,1)}
  的闭包是全关系（含 (1,2) 与 (2,1)）；
- **(R⁺)⁻¹ = (R⁻¹)⁺**（用迭代版两边同时归纳）。

图论侧写：R⁺ 是有向图的**可达性**（正路径），R* 是含零步路径的
可达性。26 章 Suslin/Aronszajn 树的"树"是这棵概念树的无穷侧枝。

### 57.8.2 集合在关系下的闭包

姊妹概念：给定 R 与 X ⊆ A，**R[X]**（X 在 R 下的闭包）:= 包含 X
且对 R-像封闭的最小集合。迭代版：X₀ = X，Xₙ₊₁ = Xₙ ∪ R(Xₙ)，
R[X] = ⋃ₙ Xₙ。与像的两点区别：闭包**包含初始集**（像不必），
且**反复施用** R（像只一次）。原书 Exercise 2.7.2 六问（X = {2,5}
于 ℕ）：

| R | R[X] | 备注 |
|---|---|---|
| n = m+1 | {n ≥ 2} | 单调升链 |
| n = m−1 | {0,1,2,3,4,5} | 降到 0 封界 |
| n = 2m | {2,4,8,…} ∪ {5,10,20,…} | 两条倍增链 |
| n = m/2 | {1,2,5} | 只往下除 |
| ∅ | {2,5} | 平凡闭包 |
| < | {n ≥ 2} | 别忘了 X ⊆ R[X]！ |

(d)(f) 两问的典型错误正是忘掉"闭包含 X 本身"。R⁺ 可视为特例：
把关系作用于"对的集合"。

## 57.9 机器通道

### 57.9.1 Lean：Rel 代数与 TransGen

mathlib 的关系类型 `SetRel α β`（= `Set (α × β)`，v4.33 新设），
逆 `R.inv`、复合 `R ○ S`、传递闭包 `Relation.TransGen` 都是官方件：

```lean
-- examples/lean/Settheory/Ch57Relations.lean（节选）
variable {α β γ : Type*} (R : SetRel α β) (S : SetRel β γ)

-- (R₁ ∪ R₂) ○ S = (R₁ ○ S) ∪ (R₂ ○ S)：左分配（官方库只有右分配
-- comp_iUnion，这里补左向并手证——∃ 对 ∨ 的分配逐点成立）
theorem comp_union_left_distrib (R₁ R₂ : SetRel α β) (S : SetRel β γ) :
    (R₁ ∪ R₂) ○ S = (R₁ ○ S) ∪ (R₂ ○ S) := by
  ext ⟨a, c⟩
  simp only [mem_comp, Set.mem_union]
  constructor
  · rintro ⟨b, hb | hb, hbc⟩
    · exact Or.inl ⟨b, hb, hbc⟩
    · exact Or.inr ⟨b, hb, hbc⟩
  · rintro (⟨b, hb, hbc⟩ | ⟨b, hb, hbc⟩)
    · exact ⟨b, Or.inl hb, hbc⟩
    · exact ⟨b, Or.inr hb, hbc⟩

-- (R ○ S)⁻¹ = S⁻¹ ○ R⁻¹：复合与逆交换次序——官方锚点
theorem converse_comp_swap : (R ○ S).inv = S.inv ○ R.inv :=
  SetRel.inv_comp R S

-- TransGen 的最小性：任何包含 R 的传递关系都包含 R⁺
-- （官方件 Relation.transGen_minimal 用 IsTrans 实例；这里按
--   TransGen 的两个构造子 single/tail 直接归纳，与 Agda 通道同构）
theorem TC_minimal {r T : α → α → Prop}
    (hR : ∀ a b, r a b → T a b)
    (hT : ∀ a b c, T a b → T b c → T a c) :
    ∀ a b, Relation.TransGen r a b → T a b := by
  intro a b h
  induction h with
  | single h => exact hR _ _ h
  | tail _ hc ih => exact hT _ _ _ ih (hR _ _ hc)
```

逆复合与域值域互换（`dom_inv`、`cod_inv`）是一行官方件；左分配
要手写——`mem_comp` 的 ∃ 与 ∨ 的交互正是 57.4.3 手证的镜像。
`TC_minimal` 是闭包的"交版定义"（57.8.1 第 3 种）的机器化身。

### 57.9.2 Isabelle/ZF：converse/comp/trancl/equiv

ZF 的 `converse`、`O`（复合）、`r^+`（传递闭包）、`equiv`/`A//r`
（商集）齐备，两条代数律与一条官方闭包律：

```isabelle
-- examples/isabelle/ST57/Relations.thy（节选）
lemma comp_union_distr: "(S ∪ R) O T = (S O T) ∪ (R O T)"
  by (blast intro!: equalityI)

lemma converse_comp_swap: "converse(S O R) = converse(R) O converse(S)"
  by (blast intro!: equalityI)

lemma conv_trancl: "converse(r^+) = (converse(r))^+"
  by (rule trancl_converse)
```

前两条交给 `blast`——元素级一阶推理是它的主场（谓词式的教训
在 46-55 章已吸收）；第三条直接引用官方 `trancl_converse`。
商集侧用 `Union(A//r) = A` 与等同刻画点亮"划分三条件"里的两个
（非空 + 穷尽），第三个（两两不交）由类相等刻画 `⟨a,b⟩ ∈ r ⟺
r``{a} = r``{b}` 间接承载。

### 57.9.3 Coq/Julia：3 元集上 512 个关系的机器普查

3 点集上共有 2⁹ = 512 个关系。逐一检查性质，得到一张人口普查表
（两通道独立实现、数字一致）：

| 性质 | 个数 | 备注 |
|---|---|---|
| 自反 | 64 | = 2⁶：对角线强制 1，余 6 格自由 |
| 对称 | 64 | = 2⁶：上三角 3 格自由 × 镜像 |
| 非自反 | 64 | 对角线强制 0 |
| 传递 | **171** | 无闭式，穷举/递推才知（OEIS A006905） |
| 反对称 | 216 | = 3³·2³：每对角外格子三选一 × 对角线自由 |
| 等价 | 5 | = Bell(3)：划分数——57.6 的对应定理数值化！ |
| 偏序 | 19 | 自反+反对称+传递（A001035） |
| 线性序 | 6 | = 3! |

**等价关系 = 划分数**（Bell 数）这一行是 57.6 节定理的数值化石：
3 点的划分恰是 {{1,2,3}}、{{1},{2,3}}、{{2},{1,3}}、{{3},{1,2}}、
{{1},{2},{3}} 五个。传递关系的 171 无简单公式——数学事实的
"硬度分层"在此可见一斑。

Coq 通道（`vm_compute` 判定证书）与 Julia 通道（Warshall 闭包 +
分类统计）双实现；Julia 的传递闭包用位矩阵 Warshall，与迭代法
对照一致。

### 57.9.5 Prolog：谓词即关系

Prolog 的谓词天生就是关系：家族数据库 fact 化，复合用元调用
`call`，传递闭包就是递归谓词：

```prolog
% examples/prolog/57_relations.pl（节选）
rel_comp(R, S, A, C) :- call(R, A, X), call(S, X, C).
tclosure(R, A, B) :- call(R, A, B).
tclosure(R, A, C) :- call(R, A, X), tclosure(R, X, C).

parent(tom, mary).  parent(mary, ann).
grandparent(A, C) :- rel_comp(parent, parent, A, C).   % tom–ann
ancestor(A, C) :- tclosure(parent, A, C).              % R⁺
```

`rel_comp/4` 是 S ∘ R 的定义直译；`tclosure` 的两条子句正是
传递闭包的"有限路径版"（单步 + 至少两步）。

### 57.9.6 Agda：传递闭包的归纳与最小性

```agda
-- examples/agda/Ch57_relations.agda（节选）
data TC (R : ℕ → ℕ → Set) : ℕ → ℕ → Set where
  step : ∀ {a b}   → R a b → TC R a b
  trans : ∀ {a b c} → TC R a b → R b c → TC R a c

TC-minimal : (T : ℕ → ℕ → Set) → (∀ a b → R a b → T a b) →
             Transitive T → ∀ a b → TC R a b → T a b
TC-minimal T hR hT a b (step r)        = hR a b r
TC-minimal T hR hT a b (trans tc r) =
  hT a _ b (TC-minimal T hR hT _ _ tc) (hR _ b r)
```

`TC` 是"右递归"的传递闭包（对应迭代版），`TC-minimal` 按闭包的
结构归纳证明最小性——构造性通道把"交版定义"变成了一次对归纳
原理的直接调用。
