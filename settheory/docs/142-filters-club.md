## 142.1 滤与理想：大与小的公理化

> **定义（书 6.1.1/6.1.3）**　S 上的**滤** F ⊆ P(S)：S∈F、∅∉F；
> 交封闭；扩封闭。**理想** I：∅∈I、S∉I；并封闭；缩封闭。
> F ↦ {S−X | X∈F} 给出对偶。

直观（书 6.1 开篇）：[0,1] 上测度 1 的集族是滤（"几乎处处
在"）、测度 0 的族是理想（"几乎处处不在"）——**大/小是测度的
公理化替身**。

例（6.1.2/6.1.4）：平凡滤 {S}；主滤 {X | A ⊆ X}；**Fréchet 滤**
（余有限集，非主）；理想侧照抄对偶。

**生成的滤（6.1.6）**：有限交性质的族 G 总可扩成滤——
F = {X | 某个 G 的有限交 ⊆ X}（最小这样的滤）。

**超滤（6.1.7）**：对每个 X，X∈U 或 S−X∈U（"完全的划分"）。
命题 6.1.10：超滤 ⟺ 极大滤（完全 = 彻底——证明是标准的"加上
X 会撞空集"论证）。

> **定理（书 6.1.11，Tarski 超滤存在定理）**　任何滤可扩成超滤
> （Zorn：滤的链之并是上界滤，极大元即超滤）。ZF 不可证——
> 第 137 章 Zorn 应用清单的兑现。

**κ-完全（6.1.12）**：滤对 <κ 交封闭（理想对 <κ 并封闭）。
练习 6.1.14：可数集上的 ω₁-完全滤都是主的；|X|≤ℵ₀ 的集族是
ω₁-完全理想（在不可数的 S 上）。

机器侧（`examples/python/142_filters_club.py`）做了有限滤子全
景：4 点集上**恰 15 个滤（全部主滤）、4 个超滤（全部单点主超
滤）**——有限世界没有非主超滤（这正是"非主超滤存在"是无穷现
象的注脚）；15 对滤-理想对偶逐对验证；生成的滤在 {{1,2},{2,3}}
上闭出含 {1} 的最小滤。Prolog 通道（`18_filters_club.pl`）的
判定器与生成器同款。

Lean 侧（`Ch18FiltersClub.lean`）锚定 mathlib 的滤子代数：
`Filter` 结构体（三条件即构造子要求）、`Filter.principal`（主
滤）、`Filter.cofinite`（Fréchet）、以及超滤存在定理
`Ultrafilter.exists_ultrafilter_of_finite_inter_nonempty`
（6.1.6+6.1.11 的合体：有限交非空 ⟹ 扩成超滤）。

## 142.2 club 集：ω₁ 上的"大"集（书 6.2）

> **定义（书 6.2.1）**　C ⊆ α（cf α > ω）：**无界**（sup C = α）
> 且**闭**（C 的极限点都属于 C）。称 C 是 **club**。

闭 = 序拓扑下的闭集（练习 6.2.3）；极限点 λ：sup(C∩λ) = λ。

基本例（书 6.2.4）：α 自身；尾部 [β,α)；**极限序数的全体**；
以及 X'（X 的极限点集，6.2.4(4)：X 无界 ⟹ X' 是 club——对角
化原始形态）。

**闭 ↔ 严格递增连续函数的值域（6.2.5）**：f : α → α 严格递增
+ 连续（f(λ) = ⋃_{ξ<λ} f(ξ)）⟺ ran(f) 是 club——club 与正规
函数（normal function）一一对应。这是 club 在不动点定理里的
身份（Fodor 定理、不动点引理的入口）。

**club 滤（书 6.2.6+）**：club 集的族在"对 <cf α 交封闭"意义
下生成一个 cf α-完全滤——**包含 club 的集是"大"的**，与 club
不相交的集是"非平稳的"。**平稳集**（stationary）：与每个 club
相交——"不小"的集。三者：club ⊆ 平稳 ⊆ 无界，包含都严格。

Julia 通道（`18_filters_club.jl`）在窗口里演示：偶尾部 ∩ 3 倍
尾部 = 6 倍尾部（两个"大"集之交仍"大"——club 交封闭的影子）；
但偶尾部 ∩ 奇尾部 = ∅（无界集之交可空——**闭性不可省**的现
场）；孤立点非极限点（极限点判定的窗口语义）。

## 142.4 代码精选与方法论

Python 的有限滤子全景有教学价值的三层发现：

```python
all_filters = []
for A in P4:                                   # 每个非空 A 生成主滤
    if A:
        F = {X for X in P4 if A <= X}
        all_filters.append((A, frozenset(F)))
assert len(all_filters) == 15                  # 4 点集上滤子数 = 非空子集数
```

**层一**（数据层）：15 个滤全部主滤——有限世界的滤没有"自由
度"，每个都由一个核 A 撑起。**层二**（超滤）：4 个超滤全部是
单点主滤 {a}↦{X | a∈X}——**非主超滤的存在是纯无穷现象**
（Fréchet 滤的任何超滤延拓都非主——但那个延拓恰恰需要 Zorn）。
**层三**（方法论）：is_filter 判定器的三条件在有限域上穷举可判
——这是"定义即程序"的又一实例，但窗口边界诚实：非主超滤在窗
口里永远缺席，正如 ω₁ 在 ω 窗口里缺席。

Prolog 版（`18_filters_club.pl`）在此前踩了本教程最大的一个坑
（坑账 #63）：sub(S, Y) 以 member 逐位生成子集——**会生成重复
元素的列表**，无限分支炸栈。正解是教科书式的 subselect2（头部
include/exclude 二叉），与 ch04 的 subselect 同款——同一个坑
在两个章重踩，写入肌肉记忆清单。

Julia 的偶/奇尾部之空交是"无界 ∩ 无界 = ∅"的最小现场——数学
解释：偶尾部与奇尾部在真正的 ω₁ 中都不是**闭**集（它们的极限点
互相渗透），club 的交封闭定理需要闭性参与；窗口里 6 倍数尾部
（偶∩3 倍）保持了"逼近顶部"，是 club∩club 的合格影子。

## 本章要点

1. 滤 = 大集族（S∈F、∅∉F、交封闭、扩封闭）；理想对偶；生成的
   滤 = 有限交闭包。
2. 超滤 = 完全划分 = 极大滤；Tarski：滤可扩成超滤（Zorn）——
   ZF 不可证。有限集上超滤 = 单点主滤（无oracle）。
3. κ-完全：可数集上的 ω₁-完全滤都是主的。
4. club = 无界 + 闭（cf > ω 的 α 上）；闭 = 正规函数值域；
   club之交 club；含 club 者大（club 滤）；
   平稳 = 与一切 club 相交。
5. 机器面：mathlib Filter/Ultrafilter 代数 + IsClub 结构体；
   Python 有限全景（15 滤 4 超滤）；Julia 的交封闭/闭性现场。
