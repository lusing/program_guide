# 23 · Martin 公理

> CH 可以推广为一条在 ¬CH 下仍有用的公理——Martin 公理
> 把"可数稠密集族的泛型滤波器存在"推广到 <2^ℵ₀ 个。
> ——MA 是 CH 的"可替代品"

本章覆盖 Jech §23 前半：MA_κ 的定义（(23.1)）、等价形式
（引理 23.2）、MA_ℵ₁ 杀 Suslin 树（引理 23.1）、Solovay-
Tennenbaum 定理（定理 51）的陈述。

## 23.1 MA_κ 的定义

**Rasiowa-Sikorski 引理**（引理 16.1）保证可数稠密集族有
泛型滤波器。对不可数族这不一定成立（习题 23.1 的反例：
崩塌 ω₁ 的力迫有 ω₁ 个稠密集无泛型滤波器）。

**MA_κ** (23.1)：若 (P,<) 满足 ccc 且 ℘ 是 ≤κ 个稠密集的
族，则存在 ℘-泛型滤波器。

- MA_ℵ₀ = Rasiowa-Sikorski（ZFC 可证）。
- **Martin 公理**：MA_κ 对一切 κ < 2^ℵ₀。
- MA_κ ⟹ κ < 2^ℵ₀（习题 23.2：Cohen 偏序有 2^ℵ₀ 个稠密
  集族无泛型滤波器）。
- CH ⟹ MA（平凡——2^ℵ₀ = ℵ₁ 时只有 MA_ℵ₀ 需要验证）。

## 23.2 等价形式

**引理 23.2** 以下等价：
(i) MA_κ；
(ii) |P| ≤ κ + ccc → ≤κ 稠密集有泛型滤波器；
(iii) cBa B 的 ≤κ 个子集族 → 存在 ℘-完备超滤。

(i)→(iii)：构造稠密集 D_X 使泛型滤波器扩展为超滤。
(iii)→(ii)：B = r.o.(P) 的典范嵌入搬运。
(ii)→(i)：提取 ≤κ 大小的子偏序 Q（包含极大反链）。

**拓扑形式**：紧 Hausdorff ccc 空间中 <2^ℵ₀ 个稠密开集的
交仍稠密。

## 23.3 MA + ¬CH 杀 Suslin 树

**引理 23.1** MA_ℵ₁ ⟹ 无 Suslin 树。

*证明*：设 T 是正规 Suslin 树，P_T = T^op 满足 ccc。对每个
α < ω₁，令 D_α = {x ∈ T : ot(x) > α}——每个 D_α 稠密。
MA_ℵ₁ 给出泛型滤波器 G 击中一切 D_α。G 是 T 的分支，
长度 ω₁——与 Suslin 树无不可数分支矛盾。∎

## 23.4 Solovay-Tennenbaum 定理

**定理 51** Con(ZFC) ⟹ Con(ZFC + MA + 2^ℵ₀ > ℵ₁)。

*证明思路*（迭代力迫）：逐阶段杀掉 MA 的反例——每一步用
ccc 力迫破坏一个潜在的 Suslin 树/反例，迭代 ω₂ 步。关键：
ccc 力迫的有限支撑迭代保持 ccc（非平凡定理——§23 后半
的正题）。∎

推论：**Suslin 假设独立于 ZFC**（定理 50）——Tennenbaum-
Jech 一侧 + Jensen（V=L → ◊ → SH）一侧。

## 23.5 迭代力迫：两步迭代

设 P 是地面模型中的力迫，Q ∈ M^B 是名字（‖Q 是 cBa‖=1）。
**两步迭代** B*Q 是 M 中的 cBa，使 M^{B*Q} = M^B[G][H]。

构造：(23.3) 取 V^B 中极大反链的等价类代表集 D，
(23.4)-(23.5) 定义 D 的布尔运算——M 中的完备布尔代数。

迭代力迫是证明 Solovay-Tennenbaum 的技术核心——有限支撑
迭代保持 ccc 是关键引理（§23 后半的 Lévy 引理）。
