# 131 · 不可数集合

> 康托用对角线方法证明实数是不可数的，这实际上打开了对更高阶
> 无穷研究的大门，也是集合论的真正开始。——原书 3.6 节结语

本章覆盖书 3.6 节与第三章习题课（PDF 69-73 页）：对角线法的
完整形态、康托集与三进地址、以及无穷世界的第一批"户口管制"。

## 131.1 区间套定理：完备性的拓扑面孔

> **定理（书 3.6.1）**　若闭区间序列 I₀ ⊇ I₁ ⊇ I₂ ⊇ …（每个
> I_{n+1} ⊆ I_n），则 ⋂ₙ Iₙ ≠ ∅。（证明留作习题 3.7.18。）

证明的骨架值得写出（它是 sup 的直接应用）：令 Iₙ = [aₙ, bₙ]。
左端点 aₙ 单调上升且被任何 b_k 上界（闭区间的嵌套保证 aₙ < b_m
对一切 n,m），故 a = sup{aₙ} 存在；同理 b = inf{bₙ} 存在且
a ≤ b；[a,b] ⊆ ⋂Iₙ。——注意**没有"长度趋于 0"的假设**：交是
非空**闭区间**（可能退化为一点，也可能是胖区间）。加上长度
→ 0（如本章康托集的场景）交才缩成一点。第 130 章的最小上界
性质在此第一次展示工程能力。

## 131.2 第一个不可数：对角线法

> **定理（书 3.6.2，康托）**　[0,1]^N（全体 0-1 无穷序列）不可数。

**证明**：反设可数，则存在 N → [0,1]^N 的满射 α，值域
{α₀, α₁, …}，每个 αₙ 是 0-1 序列 (αₙ(0), αₙ(1), …)。定义

    β(n) = 1 − αₙ(n)。　　(3.19)

则 β ∈ [0,1]^N，但对每个 n，β 与 αₙ 在第 n 位不同——β ∉ ran(α)，
与满射矛盾。∎

这就是**对角线法**：把"列表"排成无穷方阵，沿对角线逐位取反，
造出与每一行都不同的新行。机器侧的三份审计（Julia/Python/
Prolog）各自给它照了相：

- **Julia**（`examples/julia/131_uncountable.jl`）：确定性"伪列表"
  αₙ(k) = (nk+n+k) mod 2，翻转对角线后逐行断言 β(k) ≠ α_k(k)；
- **Python**：与第 123 章的对角线小玩具接续——这次的列表是 50 行；
- **Prolog**（`examples/prolog/131_uncountable.pl`）：**全量终审**——
  3×3 的 0-1 矩阵共 512 个，对**每一个**矩阵，翻转对角线得到的
  行都与三行各自不同：
  ```prolog
  check_diagonal :-
      forall((matrix(3, 3, M), flip_diag(M, F)),
             (forall(member(Row, M),
                     (nth1(I, Row, _), differs_at(F, Row, I))))),
  ```
  对角线论证对一切有限方阵成立——无穷版本只是把"每个 3×3"换
  成"每个 ℕ×ℕ"。

对角线法的亲戚在第 124 章（罗素类）、第 125 章（习题 1.4.8 的
P(X) ≠ X）已经露过面；本章它终于获得正式定理的地位，并将在
第 140 章（Cantor 定理 κ < 2^κ）升格为基数算术的引擎。

## 131.3 实数不可数：康托集与三进地址

> **定理（书 3.6.3）**　ℝ 不可数。

证明的路线漂亮：把 [0,1]^N **单射**进 ℝ。构造康托集 C = ⋂ₙ Cₙ：
C₀ = [0,1]，C_{n+1} 把 Cₙ 的每个区间挖去中间三分之一开段。对
每个 0-1 序列 γ，递归选闭区间 F₀ ⊇ F₁ ⊇ …（γ(n)=0 取左三分之
一、=1 取右三分之一），由区间套定理 ⋂Fₙ 恰含一点，定义为
f(γ)。则 f 把 2^N（基数同 [0,1]^N）单射进 ⋂Cₙ = C。∎

**单射的证明**是精巧的一笔：若 α ≠ β、首次差异在 n，则 F_{n+1}(α)
与 F_{n+1}(β) 分别落进 Cₙ 当前区间的**左、右**三分之一——两个
闭区间不相交，f(α) ≠ f(β)。

机器侧把整套构造跑成精确算术。**三进地址的封闭形式**：
f(α) = Σₖ 2α(k)·3^{-(k+1)}（地址数字 0/1 对应三进数字 0/2）。
Python 单元（`examples/python/131_uncountable.py`）用 Fraction
精确计算：

```python
def faddr(a, depth):
    """三进地址 α ↦ Σ 2α(k)·3^{-(k+1)}（k 从 0 起），精确有理数。"""
    return sum(F(2 * a[k], 3 ** (k + 1)) for k in range(depth))

a1 = [0] + [1] * 14                                    # 0.0222…₃
assert faddr(a1, 15) == F(1, 3) - F(1, 3 ** 15)        # 截断恒等式：前 d 项 = 1/3 − 3^{-15}
```

三个地址的故事浓缩了康托集的全部微妙：

- **(0,1,1,1,…) ↦ 1/3**：三进表示 0.0222…₃。著名的"1/3 = 0.1₃ =
  0.0222…₃ 双重表示"事故里，另一个表示 0.1000…₃ 含**数字 1**——
  而地址系统的三进数字只有 0 和 2！双重表示恰好都有一侧落在地址
  系统之外，**f 的单射性因此得救**（机器审计：截断恒等式
  f(前 d 项) = 1/3 − 3^{-d}，差值精确可见）。
- **(1,0,0,0,…) ↦ 2/3**：有限支撑的地址，精确等于 2/3。
- **首差异账**：α、β 首次差异在第 n 位（α(n)=0, β(n)=1）⟹
  f(β) − f(α) ≥ 3^{-(n+1)}——因为 β 在第 n 位至少多出 2·3^{-(n+1)}，
  而 α 后续全 1、β 后续全 0 的极端情形也只能追回 3^{-(n+1)}。
  这是单射性证明的**定量版**，逐对断言精确通过。

**区间套定理的实例化**：沿地址嵌套的区间长度恰为 3^{-n}（精确
Fraction 断言），f(α) 的部分和始终落在区间内——"交非空 + 长度
→ 0 ⟹ 唯一点"的全部内容都在这几行代码里：

```python
for a in (a1, a2, a3):
    for depth in range(1, 13):
        lo, hi = nest(a, depth)
        assert hi - lo == F(1, 3 ** depth)             # 长度精确 3^{-n}
        assert lo <= faddr(a, depth) <= hi              # 部分和落在区间内
```

Julia 侧同样精确（Rational{BigInt}），并附数值版本的嵌套审计。

**康托定理的有限全量审计**（Python ③/Prolog ②）：第 125 章
习题 1.4.8 的对角线——X 到 P(X) 无满射——在 |X|=3 上穷举全部
8³ = 512 个函数，对每个 f 构造 D = {x | x ∉ f(x)}，断言 D 不在
值域中。512/512 通过。加上 Prolog 的 512 矩阵审计，本章的机器
面覆盖了对角线法的一切有限彩排。

## 131.4 同款事故在二进制：|P(ℕ)| = |ℝ| 的预告

把对角线法从 [0,1]^N 搬到 P(N)（每个集合是特征函数 = 0-1 序列）
一步之遥：|P(N)| = |[0,1]^N| ≥ |ℝ|。反方向 ℝ 单射进 P(ℚ)（每个
实数对应它的左分割——一个有理数的集合！第 130 章的戴德金构造在
这里突然多了一个身份：**实数就是有理数集合**）。两向夹逼给出

    |P(N)| = |ℝ| = 2^{ℵ₀} = c。

顺带一提，二进制小数也有双重表示的事故（0.1000…₂ = 0.0111…₂），
且这次**两侧都合法**（二进制数字 0/1 全允许）——所以"N → [0,1]
的满射不存在"的直接二进制定理需要小心处理可数多个事故点（或
干脆像书一样用三进地址绕开）。康托选三进制不是偶然：**三进制的
多余数字正好吸收双重表示的病态**。

**康托集花絮**（自证明起的三个层叠事实，正文不再展开证明）：
C 的勒贝格测度为零（Cₙ 总长 (2/3)ⁿ → 0——Julia 单元审计了
逐层长度）；C 与 [0,1] 等势（本章的 f）；C 完全不连通但无孤立点
（每个点都是极限点）。"零测度却与整个区间等势"——有限直觉在
这里彻底失效，这正是集合论要训练的新直觉。

## 131.5 习题课：第三章的收尾账

- **3.7.7**（不存在 f : N → N 使 f(n) > f(n+1) 对一切 n）：若存在，
  值域非空子集 {f(n)} 无最小元——与良序（书 3.1.10）冲突。良序
  原理的第一批应用之一。
- **3.7.10**（course-of-values 递归）：fₙ = g(f↾n)——第 n 步可以
  看到全部前史而不只是上一步。证明思路与 3.2.1 相同（近似序列），
  只是把"值"换成"前段"。这个形态的递归是良基递归（第 143 章）与
  超穷递归（第 134 章）的直系祖先。
- **3.7.16**（x + y = {p+q} 是分割）：三条性质逐条验证——向下
  封闭与无最大元都靠"两个分割各自无最大元"来传；这是 7.4 节
  良定性的补票。
- **3.7.17**（有限支撑函数按字典序良序）：A = {r : N → N | r 的
  支持有穷}，在"最后差异处"比较。这是 ω^ω 型良序的雏形——
  第 135 章（古德斯坦）与第 139 章（共尾）的伏笔。
- **3.7.8/3.7.13/3.7.14**（有穷性的传递）：S ⊆ T ⟹ |S| ≤ |T|；
  有穷集的子集有穷；f[X] ≤ |X|；并、有限族并、幂集保持有穷。
  这些是鸽笼原理与第 129 章可数性代数的"有穷版"，机器侧的
  `Finite`/`Fintype` typeclass（Lean 06 单元）正是这套传递律的
  类型系统化身。
- **3.7.9**：ℕ 的有上界子集有最大元——良序的对偶面（对 −序用
  良序取最小上界即最大元）。与区间套定理的 sup 引擎同源。
- **3.7.15**：可数并/有限积/有穷序列/有穷子集全可数——第 129 章
  推论 3.3.10 的四件套，配对函数的迭代练习。
- **3.7.18**：区间套定理（8.1 节已给出骨架）。

## 131.6 两代证明的对读：1874 与 1891

值得知道的历史：康托证明 ℝ 不可数用的是**嵌套区间法**（1874），
对角线法是十七年后（1891）的再发明。两个证明的气质不同：

- **1874 版**（≈书 3.6.3 的路线骨架）：给定实数序列，逐层选区间
  避开第 n 个数，交非空给出漏网实数。用到的实数性质只有"稠密 +
  区间套"（本质是完备性），因此**它同时证明了任何完备稠密线序
  不可数**——这与 3.5.11 的唯一性定理遥相呼应。
- **1891 版**（书 3.6.2）：只需要"序列的集合"这个组合对象，与
  实数结构完全无关——所以它能**无限推广**：对任何集合 X，
  X 到 2^X 无满射（第 125 章习题 1.4.8、第 140 章 Cantor 定理），
  给出没有顶的基数阶梯 2^ℵ₀ < 2^{2^ℵ₀} < …。

原书先教对角线（3.6.2，一般原理）再教嵌套区间（3.6.3，落到 ℝ），
顺序与历史相反、与逻辑相同：**一般原理先行，特殊结构负责落地**。
本教程的三通道分工也照此对齐——Prolog/Python 审计对角线的组合
内核，Julia/Python 的精确分数算术承载嵌套区间的解析结构。

## 本章要点

1. 区间套定理 = 最小上界性质的直接应用；无长度条件时交是胖区间，
   长度 → 0 才缩成一点。
2. 对角线法（3.19）：β(n) = 1 − αₙ(n) 与每个 αₙ 都不同——
   [0,1]^N 不可数；有限版对一切 n×n 方阵成立（512 矩阵终审）。
3. ℝ 不可数：康托集三进地址 f : 2^N → C 单射；首差异 ⟹ 相距
   ≥ 3^{-(n+1)}（定量单射）；1/3 双重表示的"数字 1 侧"恰好
   在地址系统外——单射性因祸得福。
4. 至此数系三层楼完工：ℕ（良序）→ ℤ、ℚ（商构造、可数）→
   ℝ（分割、完备、不可数）；下一章起进入序数的一般理论，
   良序从 ℕ 的特例升格为研究对象本身。
