# 48 · Stone 对偶与布尔环

> 47 章给了布尔代数的"内部解剖"（公理、序、理想、PIT）。本章向外
> 看：每个布尔代数 B 都长出一个紧 Hausdorff 零维空间 St(B)——它的
> 超滤子空间；反过来每个紧零维 Hausdorff 空间 X 都长出一个布尔代数
> CLOP(X)。**Stone 对偶定理**说这两架机器互逆。之后引入**布尔环**
> 视角（Δ 当加法、∧ 当乘法），它把商、同态、理想的一整套环论定理
> 免费搬进布尔世界，并给 C(St(B), ℤ₂) 一个代数身份。
>
> 本章覆盖 Viale §3.8-3.11 与附录 D.3（Stone-Čech）的精髓。

## 48.1 Stone 空间：超滤子的拓扑

**定义（Viale §3.8）** 对布尔代数 B，
St(B) := {G ⊆ B : G 超滤子}，
以 {N_b := {G ∈ St(B) : b ∈ G} : b ∈ B} 为子基（实为基，见下）
生成拓扑 τ_B。偶对 (St(B), τ_B) 是 B 的 **Stone 空间**。

四个一步事实（每个都用超滤子的超性一行收）：
1. N_b ∩ N_¬b = ∅ 且 N_b ∪ N_¬b = St(B)——**每个 N_b 都 clopen**；
2. N_{b∧c} = N_b ∩ N_c；N_{b∨c} = N_b ∪ N_c；
3. 于是 {N_b} 对有限交封闭，是**基**（不只子基）；
4. b ≤ c ⟺ N_b ⊆ N_c——序与包含的字典互译。

## 48.2 对偶定理：四合一

**定理（Viale Thm 3.8.2，Stone 对偶）** 对任意布尔代数 B：
1. **(St(B), τ_B) 紧、Hausdorff、零维**；
2. **b ↦ N_b 是 B → CLOP(St(B)) 的同构**（每个 clopen 都是某个 N_b）；
3. **开集 ↔ 理想、闭集 ↔ 滤子**：对 X ⊆ St(B)，
   I_X = {c : N_c ⊆ X} 是理想，F_X = {c : N_c ∩ X ≠ ∅} 是滤子；
   且 X 开 ⟺ X = ⋃{N_c : c ∈ I_X}，X 闭 ⟺ X = ⋂{N_c : c ∈ F_X}；
4. G 是孤立点 ⟺ G 是原子 a 生成的主超滤 G_a。

*证明纲要*（完整证明见 Viale pp. 44-46，此处按其结构复原）。
(1) 零维：基由 clopen 组成（48.1）。Hausdorff：G ≠ H 取
b ∈ G∖H，则 N_b、N_¬b 分离（H 超滤必含 ¬b）。**紧性是 PIT 的
消费现场**：设闭集族 𝓕 有有限交性质，令
𝒢 = {N_b : ∀C ∈ 𝓕, N_b ∩ C ≠ ∅}
（每个成员与所有 C 相交的基元素）。先证 ⋂𝒢 = ⋂𝓕：⊇ 显然；
⊆ 用"闭集是基元素之并的余"展开。再证 𝒢 有有限交性质：
N_{b₁}∩…∩N_{b_k} = N_{b₁∧…∧b_k}，若空则 C ⊆ N_¬(b₁∧…∧b_k)
对某 C ∈ 𝓕 矛盾于 N_{bᵢ} ∩ C ≠ ∅。于是 H := {b : N_b ∈ 𝒢}
是预滤，**PIT** 给出超滤 G ⊇ H，G ∈ ⋂𝓕 ≠ ∅。∎
(2) 同态：48.1 的 (2)(3) 正是 b ↦ N_b 保 ∧∨¬。单射：b ≠ c 时
bΔc > 0，PIT 给超滤含 b∧¬c，落在一个 N 而非另一个。满射
（每个 clopen 是某 N_b）：clopen U 开 ⟹ U = ⋃{N_c : c ∈ I_U}
（理想展开）；U 又紧（闭于紧空间）⟹ 有限子覆盖 ⟹ U = 有限并
= N_{c₁∨…∨c_k}。
(3) 理想/滤子对应是 (2) 的展开练习。
(4) {G} 开 ⟺ {G} = N_a 某个 a；a 必是原子（否则 a 劈成
b, c < a，两个含 a 的超滤一个含 b 一个含 ¬b，都在 N_a 里），
而 N_a = {G_a} 单点。∎

**反向（Viale Prop 3.8.3）** 紧零维 Hausdorff 空间 X 与
St(CLOP(X)) 同胚，映射 x ↦ G_x = {U ∈ CLOP(X) : x ∈ U}：
良定义与单射用零维 Hausdorff 分离；满射（每个 CLOP 超滤的
交是单点）用紧性；开且连续因为 φ[U] = N_U。

于是 **B ↦ St(B)** 给出布尔代数与紧零维 Hausdorff 空间之间
的（反变）双射。它还可加强为范畴对偶（同态 ↔ 连续映射），
Viale 不展开，我们在 48.6 用 Lean 的 `Stonean` 锚点注记。

## 48.3 sup 与 inf 的拓扑算法

RO(X) 与 CLOP(X) 里的 sup 不等于集论并——46 章已见 (1,1.5)∪
(1.5,2) 要"缝合"。Stone 空间上有个普适算法：

**命题（Viale Prop 3.11.2）** a = ⋁X ⟺ {N_b : b ∈ X} 是 N_a
的稠密开子集（相对拓扑）。

*证明*：设稠密。a 是上界（N_b ⊆ N_a 即 b ≤ a）。若不是最小，
有 c < a 也是上界；取 d = a∧¬c > 0，则 N_d ⊆ N_a 非空开，与
{N_b} 不相交——与稠密矛盾。反向同理反推。∎

**推论（Viale Cor 3.11.3）** ⋁X ∧ r = ⋁{b∧r : b ∈ X}；
¬⋁X = ⋀{¬b : b ∈ X}（De Morgan 升格到无穷）。

**事实（Viale Fact 3.11.7）** 换骨公式：⋁X = ⋁↓X = ⋁A（A 是
↓X 内任一极大反链）；X 前稠密 ⟺ ⋁X = 1。这些公式在 49 章
布尔补全的唯一性证明与 50 章 ccc 论证中反复出现。

**Remark 3.11.5（Cantor 空间上的实例）** 在 C = 中取
X₀ = {U_{2n} : n ∈ ℕ}（三进制区间偶数层）：X₀ 开但没有任何
clopen 集以它为稠密子集（任何含 X₀ 的闭集必含聚点 1 的邻域，
其中混入奇数层区间）——**X₀ 在 CLOP(C) 中没有 sup**。这正是
"CLOP(X) 不完备"的典型现场，49 章用 RO(X) 缝合它。

## 48.4 布尔环：Δ 当加法

**定义（Viale Def 3.9.1）** 布尔环：乘法幂等的交换环
（a² = a）。

**注（Viale Remark 3.9.2）** 布尔环自动特征 2：(a+a)² = a+a
展开得 a + a + 2a − 2a = a + a = 0——减法与加法合一。

**定理（Viale Thm 3.9.3，双向）**
(→) 布尔代数 B 配 **加法 = Δ、乘法 = ∧** 是布尔环；
(←) 布尔环 R 配 **a∨b := a+b+ab、a∧b := ab、¬a := 1+a**
是布尔代数。

*证明要点*：(→) 方向的分配律对 ∧ 是环律，对 Δ 用 Δ 的双线性
（在 𝒫(X) 中就是集合恒等式，一般 BA 里由对称差的表达式
aΔb = (a∨b)∧¬(a∧b) 展开）。(←) 方向的补律：
a∧(1+a) = a+a² = a+a = 0，a∨(1+a) = a+(1+a)+a(1+a) = 1；
分配律是三次展开的多项式等式（Viale p.50 逐项列出）。∎

这条定理的**工程红利**（Viale Remark 3.9.6）：布尔代数的
理想 = 布尔环的理想、同态 = 环同态（Exercise 3.4.3/3.4.6），
于是**第一同构定理、核-理想对应等环论标准件全部免费**——
Prop 3.9.8（B/ker π ↪ C）的证明一句"环论标准结果"了事。

**幂等元的空间化身（Lemma 3.9.5）** B ≅ C(St(B), ℤ₂)：
b ↦ 特征函数 f_b(G) = [b ∈ G]。f_b 连续因为 f_b⁻¹(1) = N_b
clopen；同构因为两边都是 clopen 的"坐标"。这是 52 章
C(St(B), 2^ω) 大例子的第一块砖。

**零因子刻画（Prop 3.9.7 (2)）** 布尔环无零因子 ⟺ 同构于 ℤ₂。
（x(x−1) = 0 说每个元素是 0 或 1。）于是 B/I 是域 ⟺ I 极大
（= 素，对偶于超滤子）——环论字典与 47 章序论字典在此对齐。

## 48.5 Stone-Čech 与极不连通（App D.3 展望）

附录 D.3 给 Stone-Čech 紧化的构造（X 上一切连续 [0,1] 值函数
的像嵌入积空间 [0,1]^C(X,[0,1]) 的闭包）与一个难得的刻画：
**紧 Hausdorff X 极不连通 ⟺ C(X, ℝ) 的每个有界闭集有上确界**
（序结构反射拓扑）。而 49 章的主定理之一正是：**B 完备 ⟺
St(B) 极不连通 ⟺ RO(St(B)) = CLOP(St(B))**——Stone-Čech 机器
（βX 与 RO(X) 的关系）在 Viale 的路线里埋伏于此。本节正文只
存骨架，细节随 49 章的 Prop 4.1.5 一起兑现。

(c) 孤立点 = 全部点 = 主超滤（定理 4 的有限化身）。

**Python（`examples/python/48_stone.py`）**：换 Div(30) 做同一
