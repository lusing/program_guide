# 58 · 函数：单射、满射与鸽笼原理

> 函数概念的两百年抽象史：从"因果规律的规则"到"满足单值条件的
> 有序对集合"。本章提炼 Makinson 第 3 章：函数作为特殊关系、
> 限制/像/闭包、复合与逆、单射/满射/双射三剑客、用函数比较大小
> ——等势原理、比较原理与**鸽笼原理**，然后盘点五件趁手小函数
> （恒等、常值、投影、特征、选择），最后用"族与序列"收束。
> 它是 03 章 Cantor/Schroeder-Bernstein 的前奏、05 章选择公理的
> 朴素预演，也是 60 章计数原理的地基。

## 58.1 什么是函数

一部微缩观念史：函数最初是**规则**（方程式），描述一个量如何
因果地决定另一个量（自变量→因变量）；两百年抽象化把"数""规则"
"因果"逐层剥掉——取到极限，**函数不过是满足一个条件的关系**：

**定义**：从 A 到 B 的一元函数是二元关系 R ⊆ A × B，满足：对
每个 a ∈ A，**恰有一个** b ∈ B 使 (a,b) ∈ R。

两个斜体词各藏一刀：

- **恰有一个** = 至少一个（存在性）+ 至多一个（唯一性）。砍掉
  "至多"得**偏函数**（partial function）——程序部分崩坏、查找
  失败的数学化身；砍掉"至少"则连关系都不是函数。
- **对每个 a ∈ A** = 声明的 source 必须整个是定义域。表格判读：
  每行恰一个 1；有向图判读：A 圈每点恰一条出箭头。

原书 Exercise 3.1 的判例值得一秒过一遍（A = {a,b,c,d}，
B = {1,..,5}）：{(a,1),(b,2),(c,3)} 不是函数（d 缺）但是偏函数；
{...,(d,4),(d,5)} 连偏函数都不是（d 双值）；{(a,1),(b,2),(c,3),(d,5)}
是函数——**目标漏掉 4 无妨**；{(a,1),(b,2),(c,2),(d,1)} 是——
**2 被打两次无妨**；{(a,5),(b,5),(c,5),(d,5)} 是——常值函数。
在 ℤ 上的七个经典：|a| 是函数；(¬a|,a) 不是（非单值+定义域只剩
ℕ）；a² 是；(a²,a) 不是；a+1 是；a−1 是；(2a,a) 是偏函数
（定义域 = 偶数）。**偏函数的复合仍是偏函数**——这正是程序语言
里 Maybe/Option 单子的集合论骨架。

n 元函数归约为一元：A₁ × … × Aₙ → B。Alice Box 为 f((x,y)) 的
双层括号辩护：外层是函数记号，内层是序对——类型系统里这就是
currying 与非 currying 之别。

## 58.2 函数上的运算

- **域与值域**照旧：f : A → B 时 dom(f) = A、range(f) ⊆ B。唯一
  的空函数 ∅ → B 同时是唯一值域为空的函数。
- **限制** f|X（X ⊆ A）：照抄 f 于 X 上。
- **像** f(X) = {f(a) : a ∈ X}：f(A) = range(f)，f(∅) = ∅，
  f({a}) = {f(a)}——像≠值，一字之差。
- **闭包** f[X]：最小包含 X 且对 f 封闭的集合（f : A → A 时才有
  意义！）。bottom-up：X₀ = X，Xₙ₊₁ = Xₙ ∪ f(Xₙ)。

原书 Exercise 3.2.2 的四函数（mod/square/succ/pred 于 ℤ）像与
闭包对照表是概念试金石（A = {−1,0,1,2}）：

| f | f(A) | f[A] |
|---|---|---|
| mod | {0,1,2} | A（不动） |
| square | {0,1,4} | A ∪ {4,16,256,…} |
| succ | {0,1,2,3} | {−1} ∪ ℕ |
| pred | {−2,−1,0,1} | ℤ⁻ ∪ {0,1,2} |

**注意 X ⊆ f[X] 恒真而 X ⊆ f(X) 不必**——闭包含初始集，像不必。

**复合**：g ∘ f(a) = g(f(a))。结合律逐点验证（书本给出"冗长得
可爱"的完整展开）；**不交换**：f(1) = f(2) = 1、g 交换 1↔2 时
g∘f(1) = 2 而 f∘g(1) = 1。ℕ 上 f(n) = n+1、g(n) = 2n 也行：
f∘g(1) = 3 ≠ 4 = g∘f(1)。复合的记号顺序（先 f 后 g 写作 g∘f）
至此得到辩护——与右侧 g(f(a)) 的阅读顺序一致。

**逆**：converse（关系文化的词）= inverse（函数文化的词），同一
操作 R⁻¹。函数的逆有三种命运：不是函数（f 双值处翻车）、是
偏函数（定义域 = range(f)）、是全函数（f 双射时）。术语上，
学校里说"逆不存在"是粗话——精确的说法是"作为关系永远存在，
作为函数未必"。

## 58.3 单射、满射、双射

- **单射**（injective / one-one）：a ≠ a′ ⟹ f(a) ≠ f(a′)；逆否：
  f(a) = f(a′) ⟹ a = a′；表格：每列至多一个 1。
- **满射**（surjective / onto B）：每个 b ∈ B 被打到；iff
  range(f) = B。**每个函数都onto某个集合——它的值域**，所以
  "onto"必须说清 onto 谁。
- **双射**（bijective）：两者兼得；旧称一一对应。

三条复合定律，各给两行证明：

**单射∘单射 = 单射**：a ≠ a′ ⟹ f(a) ≠ f(a′)（f 单）⟹
g(f(a)) ≠ g(f(a′))（g 单）。∎

**满射∘满射 = 满射**：任取 c ∈ C，g 满给 b 使 g(b) = c，f 满给
a 使 f(a) = b，故 c = g(f(a))。∎（双射∘双射 = 双射随之。）

**单射 ⟺ 逆是（range 上的）函数**：单值性翻译即"至多一个 a
对应每个 b"。∎

**双射 ⟺ f⁻¹ 是 B → A 的函数**（Exercise 3.3.3 (1) 双向证）：
"⟹" 单射给 f⁻¹ 函数性（于 range(f)），满射给 range(f) = B；
"⟹"反跑：f⁻¹ 函数给单射，dom(f⁻¹) = B 给满射。∎

**定义域依赖的教学明星**——平方函数在五个域上的单/满射矩阵：

| 域 | 单射 | 满射到自身 |
|---|---|---|
| ℕ | ✓ | ✗（2 非平方数） |
| ℕ₊ | ✓ | ✗ |
| ℤ | ✗（3²=（−3）²） | ✗ |
| ℚ | ✗ | ✗ |
| ℝ | ✗ | ✗（−1 无实根） |
| ℝ₊ | ✓ | ✓（双射！） |

同一公式，六种命运。**有限集定理**（鸽笼预演）：有限集到自身的
单射必是双射——range(f) 有 n 个元素（单射不重不漏地列出），
若漏掉 x 则 range ∪ {x} 有 n+1 个元素塞进 A。∎ 03 章的
Dedekind 有限性（ℕ 与真子集等势 ⟹ 无穷）正是这句话的无穷倒影。

集值逆：非单射时 f⁻¹(b) := {a : f(a) = b} 是 B → 𝒫(A) 的函数——
"逆像"运算，测度论与拓扑的基本工具（46 章已用过 preimage）。

## 58.4 用函数比大小

**等势原理**（有限版）：#(A) = #(B) ⟺ 存在双射 f : A → B。
证明是"数数"的形式化：正向逐位配对；反向，f 把 A 的枚举变成
B 的无重复枚举。∎ 书中两例：多边形的边与顶点（边 ↦ 右端点）；
握手数 = 无序对数（握手 ↦ 参与人对）——后者把日常集合双射到
"抽象但可数"的集合，**双射是计数的先导**。

**比较原理**：#(A) ≤ #(B) ⟺ 存在单射 f : A → B。同样双向
"数数"即得。∎

**鸽笼原理**（比较原理的逆否形式）：#(A) > #(B) 时没有单射
——必有 b ∈ B 承接两个不同的 a。**广义版**：#(A) > k·#(B) 时
必有 b 承接至少 k+1 个 a。三道名菜：

1. **400 村民**：生日函数入 366 洞 → 两人同天；400 > 33×12 →
   一月内至少 34 人生日。
2. **首字母缩写**：26×26 = 676 个字母对，677 个会员必有两人
   同缩写。
3. **答题卡**：5 题二选一 → 2⁵ = 32 种答案，97 = 3×32+1 个
   学生必有四人同卷。

解鸽笼题的第一步永远是**选好 A、B、f**——在具体数据里认出抽象
模式（序对、位串）。

## 58.5 五件趁手函数

### 58.5.1 恒等函数

i_A : A → A，i_A(a) = a。双射；复合单位元 f ∘ i_A = f = i_B ∘ f
（两行验证）。A ≠ B 时 i_A ≠ i_B（定义域即指纹）。Alice 问"为何
不定义宇宙级大恒等函数"——因为它的定义域得是"万有之集"，而
标准集合论没有（01 章 Russell 悖论），**恒等函数必须相对局部
宇宙**。这是"全集不存在"的函数版再现。

### 58.5.2 常值函数

f(a) = f(a′) 对一切 a, a′。等价刻画藏着全书最重要的量词课：

    ∃b ∈ B ∀a ∈ A: f(a) = b        （常值）
    ∀a ∈ A ∃b ∈ B: f(a) = b        （任何函数都满足！）

**量词换序改变一切**——∃∀ 比 ∀∃ 强得多。64 章 9.4.1 节将把
QxQ′y 的八种排列系统化。计数：非空 A、B 时常值函数恰 #B 个；
#A > 1 时无常值单射，#B > 1 时无常值满射（两行反证）。

### 58.5.3 投影函数

二元函数 f : A×B → C 固定一元得一元函数：f_a(b) = f(a,b)
（右投影）。乘法的 f₂(n) = 2n 与 f³(m) = 3m 是同一枚硬币的两面
（乘法交换）。currying 的数学实质。

### 58.5.4 特征函数

A ⊆ U 对应 χ_A : U → {1,0}。**子集 ↔ 布尔函数一一对应**
（56 章"位串表征"的函数形态），且运算完全同构：

    χ_{A∩B} = χ_A ∧ χ_B    χ_{A∪B} = χ_A ∨ χ_B    χ_{U∖A} = ¬χ_A

56 章的 Logic Box 至此兑现：集合代数就是布尔值的逐点逻辑。63 章
的赋值（valuation）不过是把字母表当宇宙的特征函数。

### 58.5.5 选择函数与选择公理

对非空集族 𝒜，选择函数 f : 𝒜 → ⋃𝒜 满足 f(A) ∈ A。**Russell
的袜子**：鞋有左右可分（选择规则可定义），袜子无以名状（选择
存在但不可指定）——**非构造性**的一课。有限族可逐对列出（构造）；
无穷族则须假设——**选择公理 AC**。书中给出三版本等价的完整证明
（值得全文呈现）：

- **标准版**：任意非空集族有选择函数。
- **Russell 版**：任意**两两不交**非空集族有"穿越集" C——与每族
  元恰交一个元素。
- **函数版**：任意关系 R 有 f ⊆ R 与 dom(f) = dom(R)。

**标准 ⟹ Russell**：C := {f(A) : A ∈ 𝒜}；两两不交保证 C 不多
取。**Russell ⟹ 函数版**：把 R 切成竖条 S_a = {(a,b) : b ∈ R(a)}
——**故意带上 a 做前缀正是为了造出两两不交**（妙手！）；穿越集
每条取一元，定义 f(a) := 该元的第二分量。**函数版 ⟹ 标准**：
取 R = {(A,a) : a ∈ A ∈ 𝒜}，f ⊆ R 即选择函数。∎

不交性不可省：𝒜 = {{1,2},{2,3},{1,3}} 无穿越集（试三个元素皆
失败——2 取 1 必然多取）。函数版的日常用法：把"∀x∃y R(x,y)"
压缩成"∃f ∀x R(x, f(x))"——59 章 4.7 与 65 章的构造都要用。
AC 的等价形式（良序定理、Zorn 引理）在 05 章已展开——那里
Zorn 是主角，这里只需记住：**AC = 同时做无穷多次选择**。

## 58.6 族与序列

**集族 family** := 以 I 为定义域、值为集合的函数（56 章埋的伏笔
兑现）。族 ≠ 集合族 collection（= 族的值域）：**族保留指标、
collection 忘掉指标**。I = {1,…,n} 而 A₁ = A₂ 时，族有 n 个元素、
collection 只有 n−1 个——60 章计数法则（尤其加法原理的"不交"
前提）全靠这个区分。序列 = 以 ℕ₊（或 ℕ）为指标集的函数；有限
序列 = 定义域 {1,…,n} 的函数。下标记号 Aᵢ 是隐式的函数调用
——"第 i 个素数 pᵢ"就是函数 p : ℕ₊ → 素数集。

## 58.7 机器通道

Lean 把三性做成 `Function.Injective/Surjective/Bijective`，复合
`Function.comp`，全部官方件：

```lean
-- examples/lean/Settheory/Ch58Functions.lean（节选）
variable {α β γ : Type*} (f : α → β) (g : β → γ)

-- 单射∘单射 = 单射：官方件直呼（注意参数序：外层函数的见证在前）
theorem inj_comp (hf : Function.Injective f)
    (hg : Function.Injective g) : Function.Injective (g ∘ f) :=
  hg.comp hf

-- 双射∘双射 = 双射：分解为两个分量
theorem bij_comp (hf : Function.Bijective f) (hg : Function.Bijective g) :
    Function.Bijective (g ∘ f) :=
  ⟨hg.1.comp hf.1, hg.2.comp hf.2⟩

-- 逆是双射的见证版：Bool 上的取反是对合双射
example : Function.Bijective (fun b : Bool => !b) := by
  refine ⟨?_, ?_⟩
  · intro a b h
    cases a <;> cases b <;> simp_all
  · rintro (false | true) <;> simp
```

`hg.comp hf` 一行就是 58.3 的两行手证——**注意参数序**：dot 记号
把外层函数的单射性放前面。v4.33 的 mathlib 没有
`Bijective.invFun_bijective` 这个名字，逆的双射性用 Bool 取反的
对合见证（`!(!b) = b` 两行 rfl）承载。鸽笼原理在 Lean 里有
`Fintype` 版官方件；这里用列表版自证（Coq 通道给完整证明）。

Isabelle/ZF 的 `Perm.thy` 有全套 `inj/surj/bij` 谓词与复合保持律：

```isabelle
-- examples/isabelle/ST58/Functions.thy（节选）
lemma inj_comp_example:
  assumes "g ∈ surj(B,C)" "f ∈ surj(A,B)" shows "g O f ∈ surj(A,C)"
  using assms by (rule comp_fun)

lemma id_is_bij: "id(A) ∈ bij(A,A)"
  by (rule id_bij)
```

Coq 通道证明**鸽笼原理本体**（列表版）：单射 f 与 NoDup 源表，
则像表与源表等长——10 只鸽子 9 个洞必冲突：

```coq
(* examples/coq/Ch58_functions.v（节选） *)
Definition injective_on (f : nat -> nat) (l : list nat) : Prop :=
  forall x y, In x l -> In y l -> f x = f y -> x = y.

Lemma nodup_map_inj : forall (f : nat -> nat) l,
    NoDup l -> injective_on f l -> NoDup (map f l).
```

证明对 l 归纳：`in_map_iff` 把 `f a ∈ map f xs` 拆成"某 xs 元素
同像"，单射回推 `a = y`，与 NoDup 的头部条件矛盾。碰撞检测器
`collision_on` 再把三道名菜证书化（10 鸽 9 洞 = true、9 鸽 9 洞
= false）。

Julia/Python 做实验剧场：400 村民生日蒙特卡洛（验证"至少两人
同天"100% 发生）、26×26 缩写空间的碰撞阈值（生日悖论曲线——
只需 ~25 人就有 50% 碰撞，比 677 的确定阈早得多）、特征函数与
位串的双向翻译。Prolog 用有限族构造选择函数（**有限时 AC 免费**）
并在三对{1,2},{2,3},{1,3} 上验证无穿越集。

## 58.8 收束

函数 = 关系 + 单值：一章之内，57 章的关系代数全部继承，再添三性
（单/满/双）与两大原理（等势、比较/鸽笼）。三性在 03 章变成基数
算术的引擎（Cantor、SB、Hartogs），鸽笼在 31 章变成 Ramsey 定理
的种子（拉姆齐 = 鸽笼的染色升级），选择函数在 05 章长成 AC 三
巨头的等价网络。下一章处理"函数如何被定义"——递归——那是
所有这些构造的生产线。
