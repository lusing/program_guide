## 25.1 几乎不交族

**几乎不交**：A, B ⊆ ω 使 A ∩ B 有限。

**引理 23.9** 存在 2^ℵ₀ 个两两几乎不交的 ω 的子集。

*构造*：S = 2^{<ω}（有限 0/1 序列全体——可数集）。对每个
f : ω → {0,1}，令 A_f = {f↾n : n ∈ ω}（f 的初始段集）。
f ≠ g ⟹ A_f ∩ A_g 有限（公共初始段只有到首个分歧点）。∎

**MA 的应用**（引理 23.10）：MA_κ + {A_α : α < κ} 几乎
不交族 ⟹ 对每个 X ⊆ κ 存在 A ⊆ ω 使
  α ∈ X ⟺ A_α ∩ A 无穷
（分离/独立族的存在）。力迫构造：条件 p 是部分 0/1 函数
使 dom(p) ∩ A_α 有限对 α ∈ X——ccc + 稠密性论证。

**推论**：MA + κ < 2^ℵ₀ ⟹ 2^κ ≤ 2^ℵ₀。

## 25.2 Δ-系统引理

**引理 22.6**（§22 已介绍）不可数族 → 不可数子族使任意
两元的交相同（根）。

*证明骨架*（对 ω₁）：
1. 可数个有限集之一覆盖不可数族中不可数个域——WLOG
   域大小 = n 固定。
2. 对 n 归纳：找最大公共根 R 使不可数个子族的每两个的
   交 = R。∎

Δ-系统是 ccc 验证的标准工具——力迫条件的域结构分析。
