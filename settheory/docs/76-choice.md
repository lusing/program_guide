## 76.1 选择函数与可秩序化

设 X 是由非空集合组成的集合。X 上的**选择函数**是
c:X→⋃X，满足 c(A)∈A。等价地，可以写成 c∈∏_{A∈X}A。
“每个元素都可取”只给出 ∀A∈X ∃x(x∈A)；选择函数要求把这些存在
见证同时封装成**一个集合函数**。一阶逻辑逐次提供见证，并不自动提供
这根总装线，这正是选择公理的位置。

> **定理 2.1** 若 TC(X) 可秩序化，则 X 上存在选择函数。
> *证明*：取 TC(X) 上的良序 <。X 是传递闭包的子集，故每个 A∈X
> 都满足 A⊆TC(X)。非空的 A 有唯一 <-最小元；定义 c(A)=min_<A。
> 单值性与 c(A)∈A 同时成立。∎

> **定理 2.2** 集合 X 可秩序化，当且仅当 𝒫(X)∖{∅} 上存在选择函数。
> *证明*：良序方向同上。反过来，设 c 选取 X 的每个非空子集的一点。
> 用 71 章超限递归依次定义 x_α=c(X∖{x_ξ|ξ<α})；集合尚未取尽时
> 继续，取尽时停止。若永不停止，替换公理会把从 Ord 到 X 的单射的
> 一段任意延长，与 Ord 是真类矛盾。因此过程在某个序数 θ 停止，
> α↦x_α 是 θ→X 的双射；把 θ 的 ∈-良序经双射搬到 X 即可。∎

这里“停止”不是外加算法假设，而是集合与真类的差别：递归不能把真类
Ord 全部注入一个集合 X。

### 三种选择原理

- **AC**：任何非空集族都有选择函数。
- **AC_ω**：任何由非空集合组成的可数集族都有选择函数。
- **DC（相关选择）**：若非空集合 X 上的关系 R 满足
  ∀x∈X ∃y∈X(xRy)，就存在序列 (x_n|n<ω) 使 x_n R x_{n+1}。

AC 蕴含 DC：用选择函数依次为每个 x 选定一个后继。DC 蕴含 AC_ω：
把“当前已走到的有限路径”作为状态，关系取“再选一个尚未编号的族成员”。
反向蕴含在 ZF 中一般不可证；本章只使用这些蕴含方向，不把它们混称等价。

> **定理 2.3** 以下命题等价：(1) AC；(2) 每个集合可秩序化；
> (3) 每个集合都与某个基数等势；(4) 任意两个集合的势可比较。
> *证明*：定理 2.2 给出 (1)⇔(2)，(2)⇒(3) 是把良序集合同的序数
> 等势搬到原集合；(3)⇒(4) 因为序数可比较。最后设 (4)。对 X 取
> Hartogs 序数 h(X)：它是所有能由 X 的子集上的良序产生的序数的上界，
> 因而不能注入 X。可比较性便迫使 X 注入 h(X)；像集作为序数的子集
> 有良序，所以 X 可秩序化。于是 (4)⇒(2)。∎

### 问题 2.1：正则公理为什么不等于 AC

一种伪证说：“非空 A 按 ∈-极小原理有极小元 b，令 c(A)=b，所以选择
函数无需新公理。”裂缝是**极小元不唯一**。例如
A={{0},{1}}，两个元素都与 A 不相交，因而都是 ∈-极小元；正则公理
只承诺至少一个，没有规范地指定哪一个。“任取一个”重复作用于整个
集族，恰好又是选择问题。良序则把每个非空子集的候选缩成唯一最小元，
这就是定理 2.1 的关键。

## 76.2 佐恩引理与选择公理的日常形态

偏序集中的**链**是两两可比较的子集；上界 u 满足链中每个 x≤u；
极大元 m 是不存在严格更大元素的点。极大元不必是最大元，也不必唯一。

> **定理 2.4（Zorn 引理）** 若偏序集 (P,≤) 的每条链在 P 中都有上界，
> 则 P 有极大元；它与 AC 等价。
> *证明（AC⇒Zorn）*：给 P 一个良序 ≺。从任一点出发构造严格递增
> 序列。已有链 C 若有严格上界，就用 ≺ 在严格上界集中选唯一最小者
> 作为下一点；极限步把此前整段作为链，再取其上界。若某一步只有上界
> 而没有严格上界，这个上界就是极大元。序列若永不停止，就会把 Ord
> 注入 P，故必停止。∎
>
> *证明（Zorn⇒良序）*：固定 X，令 P 由所有“从某序数到 X 的单射”
> 组成，按函数延拓排序。链 C 是和谐函数系统，⋃C 仍是单射，所以每链
> 有上界。取极大元 F:α→X。若 X∖rng(F) 非空，取其中 a 并定义
> H=F∪{⟨α,a⟩}，便得到严格延拓，矛盾。因此 F 是双射，X 被良序化。∎

定理 2.5 再补两张常用面孔：AC 等价于“每个等价关系的商集都有代表元
选择”，也等价于“非空集族的笛卡尔积非空”。前一形式到后一形式，把
每个因子 X_i 换成带标签的不交块 {i}×X_i，并从商类中选代表；后一形式
到选择函数则直接读 f(i)∈X_i。

### AC 的五个基数推论

> **定理 2.6** 在 ZFC 中：(1) 可数个可数集合的并可数；
> (2) 每个后继基数 ℵ_{α+1} 正则；(3) 每个无穷集合含可数无穷子集；
> (4) |f[A]|≤|A|；(5) 若 |S|≤ℵ_α 且每个 A∈S 满足 |A|≤ℵ_α，
> 则 |⋃S|≤ℵ_α。
>
> *证明要点*：(1) 为每个 A_i 选择一个到 ω 的单射，再把 ω×ω 配对回
> ω；选择这列单射正是 AC_ω 的用途。(5) 是同一论证的 ℵ_α 版：
> 选双射 A↔|A| 和每块 A_i↔κ_i，以索引集×ℵ_α 覆盖并集，再用
> ℵ_α·ℵ_α=ℵ_α。(2) 若 f:ℵ_α→ℵ_{α+1}，其值域是 ℵ_α 个、每个
> 至多 ℵ_α 的序数之并；由 (5)，值域至多 ℵ_α，故在 ℵ_{α+1} 中有界。
> (3) 取 |X|→X 的双射，ω 的像即所求。(4) 对每个 b∈f[A] 选一个
> 原像，便把 f[A] 单射回 A。∎

选择在这里不是装饰：没有 AC，逐块存在的双射未必能拼成整体双射。
定理 2.7 同样用这个拼接思想：若线性序 A 的每个初始段
{y|y≤a} 的势小于 ℵ_α，则 |A|≤ℵ_α。递归造无界递增序列；序列长度
若超过 ℵ_α，某个初始段就含 ℵ_α 个互异元素，矛盾。于是长度至多
ℵ_α，再用 (5) 估计各段之并。

在分析中，AC_ω/DC 出现在“邻域意义下接触集合”与“存在序列趋近”的
等价、序列连续与 ε–δ 连续的等价中。Zorn 则给出实数作为 ℚ-向量空间
的 Hamel 基：所有 ℚ-线性无关子集按包含排序，链的并仍线性无关，极大元
因而张成全空间。固定基元 b₀，令坐标泛函 f(b₀)=1、其余基元坐标为 0，
再作 ℚ-线性延拓，便得到加法同态 f(x+y)=f(x)+f(y)。它不是实数倍数
函数：若 f(x)=cx，由 f(b₀)=1 得 c=1/b₀，但另一基元 b₁ 会同时要求
f(b₁)=0 与 cb₁≠0。于是这个“存在基”的选择性构造同时打开了非连续
加法函数的大门。

## 76.3 基数无穷和与奇异性的刻画

给定互不相交的集合 A_i，定义
Σ_{i∈I}κ_i := |⋃_{i∈I}A_i|，其中 |A_i|=κ_i。
若另有 B_i 与 A_i 逐点等势，为每个 i 选双射 f_i:A_i→B_i，则 ⋃f_i
是两块不交并之间的双射；所以定义不依赖代表集合。任何集族都可先换成
A_i×{i} 来消去交叠，故“不相交”不是实质限制。

> **定理 2.8** 设 λ=|I| 为无穷基数，κ_i≠0，κ=sup_iκ_i，则
> Σ_iκ_i = max{λ,κ}。
> *证明*：每块嵌入并集，故和 ≥κ；每块非空又给和 ≥λ。反向用
> κ_i≤κ 得 Σ_iκ_i≤Σ_iκ=λ·κ=max{λ,κ}。两边相等。∎

例如 Σ_{n<ω}1=ℵ₀，Σ_{α<λ}1=|λ|。公式也说明：真正让无穷和变大的
只有“项数”与“各项的上确界”两个尺度。

> **定理 2.9** 无穷基数 κ 奇异，当且仅当它能写成“少于 κ 个、每项
> 都小于 κ 的基数之和”。
> *证明*：若 cf(κ)=λ<κ，取递增收敛到 κ 的序数列
> (α_ξ|ξ<λ)，把 κ 分成差段 α_{ξ+1}∖α_ξ（极限处取前面各段的差）。
> 每段势 <κ，总段数 λ<κ。反之，若 κ=Σ_{ξ<λ}κ_ξ、λ<κ 且
> κ_ξ<κ，定理 2.8 给 κ=max{λ,supξκ_ξ}；因 λ<κ，必有
> κ=supξκ_ξ。递归抽取严格增的子列，其长度 ≤λ<κ，故 cf(κ)<κ。∎

## 76.4 无穷积、指数与特征函数

集族 (A_i|i∈I) 的笛卡尔积是
∏_{i∈I}A_i={f:I→⋃_iA_i | ∀i(f(i)∈A_i)}。
定义 Π_iκ_i 为它的势。逐项等势或逐项单射可由 AC 选出一族双射/单射
后逐坐标拼接，所以积的定义同样不依赖代表。常值 κ_i=κ 时
Π_{i<λ}κ=κ^λ=|{f|f:λ→κ}|。

最重要的实例是 **2^κ=|𝒫(κ)|**。对 A⊆κ 定义特征函数
χ_A(α)=1（α∈A），否则为 0；A↦χ_A 是双射，逆映射是
f↦{α<κ|f(α)=1}。因此 Cantor 的幂集定理可以写成 κ<2^κ。

指数律来自函数重参数化：κ^{λ+μ}=κ^λ·κ^μ 来自把定义域拆成两块；
(κ^λ)^μ=κ^{λ·μ} 来自柯里化 f↦((ξ,η)↦f(ξ)(η))；
(κ·ν)^λ 与 κ^λ·ν^λ 则来自逐坐标在两边取值。它们不是数值巧合，
而是函数空间之间的显式双射。

## 76.5 König 不等式：和严格小于积

> **定理 2.10（König）** 若对每个 i∈I 都有 κ_i<λ_i，则
> Σ_iκ_i < Π_iλ_i。
>
> *证明第一步：≤。* 取 A_i=κ_i×{i}、B_i=λ_i×{i}。因 κ_i<λ_i，
> 可选 b_i∈B_i∖A_i。对 a=(α,i)∈A_i 定义乘积元素 h_a：
> h_a(i)=a，而 j≠i 时 h_a(j)=b_j。若 a,a′ 同属一块，第 i 坐标
> 区分它们；若分属第 i、j 两块，则 h_a(i)=a∈A_i，而
> h_{a′}(i)=b_i∉A_i。故 a↦h_a 是单射。
>
> *证明第二步：严格。* 反设和等于积，便把 Π_iB_i 分成互不相交的
> X_i，且 |X_i|=κ_i。固定 i，投影 X_i 到第 i 坐标所得
> C_i={h(i)|h∈X_i} 满足 |C_i|≤κ_i<λ_i=|B_i|，所以 B_i∖C_i
> 非空。用 AC 为每个 i 选 f(i)∈B_i∖C_i。于是 f∈Π_iB_i，却又
> 对每个 i 都有 f∉X_i，与这些 X_i 覆盖整个乘积矛盾。∎

第二步就是推广的对角线：第 i 个坐标只负责躲开第 i 个候选覆盖块；
所有坐标合起来，便躲开整个候选覆盖。Cantor 定理是 κ_i=1、λ_i=2
的特例。由此得到连续统函数的三条 ZFC 硬约束：

1. κ<2^κ；
2. κ≤λ ⇒ 2^κ≤2^λ；
3. **cf(2^κ)>κ**。

第三条证明：反设 λ=cf(2^κ)≤κ，把 2^κ 写成 λ 个更小基数 κ_i 之和。
König 给出
2^κ=Σ_iκ_i < Π_i2^κ=(2^κ)^λ=2^{κ·λ}=2^κ，
矛盾。因此 2^{ℵ₀} 不能是任何共尾度为 ω 的基数；例如它不能是 ℵ_ω。
但“大于 ℵ₀、共尾度大于 ℵ₀”远不能唯一决定它，CH 的独立性仍成立。

## 76.6 极限幂、Hausdorff 公式与指数递推

记 2^{<κ}=sup_{μ<κ}2^μ。

> **定理 2.11** 若 κ 是极限基数，则 2^κ=(2^{<κ})^{cf(κ)}。
> *证明*：取长度 cf(κ)、递增收敛到 κ 的序列 (α_ξ)。把 κ 的子集
> A 切成 A∩(α_{ξ+1}∖α_ξ)，就把 2^κ 嵌入各段幂集的乘积，得
> 2^κ≤(2^{<κ})^{cf(κ)}。反向，(2^{<κ})^{cf(κ)}≤(2^κ)^{cf(κ)}
> =2^{κ·cf(κ)}=2^κ。∎

> **定理 2.12（Hausdorff）** ℵ_{α+1}^{ℵ_β}
> = ℵ_{α+1}·ℵ_α^{ℵ_β}。
> *证明*：若 β≥α+1，两边都由定理 2.13(1) 化为 2^{ℵ_β}。设
> β≤α。ℵ_{α+1} 正则，所以每个 f:ℵ_β→ℵ_{α+1} 的值域有界，
> 即落在某个 γ<ℵ_{α+1} 内；这样的 γ 只有 ℵ_{α+1} 个，且
> |γ|≤ℵ_α，故函数总数 ≤ℵ_{α+1}·ℵ_α^{ℵ_β}。反向，
> ℵ_{α+1}≤ℵ_{α+1}^{ℵ_β}，而
> ℵ_α^{ℵ_β}≤ℵ_{α+1}^{ℵ_β}；两者乘积又被右项吸收。∎

若 κ 是极限基数且 λ≥cf(κ)，还有引理 2.7：
κ^λ=(sup_{μ<κ}μ^λ)^{cf(κ)}。证明与定理 2.11 相同：把函数按
κ 的共尾分段拆开，再用无穷基数乘法坍缩。

> **定理 2.13（指数递归计算）** 固定无穷 λ，κ^λ 可按 κ 递归：
> (1) κ≤λ 时 κ^λ=2^λ；
> (2) 若存在 μ<κ 使 μ^λ≥κ，取最小这样的 μ，则 κ^λ=μ^λ；
> (3) 若 κ>λ 且所有 μ<κ 都有 μ^λ<κ，则 cf(κ)>λ 时 κ^λ=κ，
> cf(κ)≤λ 时 κ^λ=κ^{cf(κ)}。
>
> *证明*：(1) 用 2^λ≤κ^λ≤(2^κ)^λ=2^λ。(2) 用
> μ^λ≤κ^λ≤(μ^λ)^λ=μ^λ。(3) 后继情形归入 Hausdorff；极限情形中，
> 题设给 κ=sup_{μ<κ}μ^λ。cf(κ)>λ 时每个 f:λ→κ 有界，故
> κ^λ=κ；cf(κ)≤λ 时用引理 2.7 与 κ^{cf(κ)}≥κ 得等式。∎

这是一套**相对连续统函数**的算法，不是宣称 ZFC 给每个指数一个独立
数值。它把未知量压缩到 2^λ 等表达式；是否还能化简，常取决于 CH/GCH。

## 76.7 强极限、不可达、GCH 与 SCH

无穷基数 κ 是**强极限基数**，若 μ<κ ⇒ 2^μ<κ；不可数、正则且强
极限的 κ 称为**不可达基数**。强极限必为极限基数：若 κ=ν⁺，Cantor
已给 2^ν≥ν⁺=κ。

强极限 κ 满足 2^{<κ}=κ，因此定理 2.11 化为 2^κ=κ^{cf(κ)}。
并且 λ,μ<κ 时
λ^μ≤(2^λ)^μ=2^{λ·μ}<κ。
不可达 κ 进一步保证：少于 κ 个、每个小于 κ 的集合之并仍小于 κ；
|X|<κ 时 |𝒫(X)|<κ；任何 f:X→κ 在 |X|<κ 时都有界。由这些封闭性
递归估计 V_α，可得 |V_κ|=κ，而且 {|V_α|=α 的 α<κ} 在 κ 中无界闭。

令 b(α)=|V_α|。则 b(α+1)=2^{b(α)}，极限处取上确界；b 严格递增且
连续。从任意 α 出发迭代 β_{n+1}=b(β_n+1)，取 β=sup_nβ_n，便有
b(β)=β。这样的不动点是强极限基数：μ<β 时，取足够大的 n 使
μ<β_n，则 2^μ≤b(μ+1)<b(β)=β。这把“幂集塔爬多快”与“强极限”
直接接上了。

- **GCH**：对所有 α，2^{ℵ_α}=ℵ_{α+1}。
- **SCH**：若 κ 奇异且 2^{cf(κ)}<κ，则 κ^{cf(κ)}=κ⁺。

GCH 蕴含 SCH：此时 2^{<κ}=κ，故
κ^{cf(κ)}=2^κ=κ⁺。SCH 弱得多，它只约束奇异基数的指数。
固定奇异 κ，并假设 SCH 的前提 2^{cf(κ)}<κ 成立。若连续统函数
在 κ 以下最终恒为 ρ，取 μ<κ 同时大于 cf(κ) 并落在恒定段内，则
2^κ=ρ^{cf(κ)}=(2^μ)^{cf(κ)}=2^μ=ρ=2^{<κ}。
若并非最终恒定，令 θ=2^{<κ}。连续性与非最终恒定给出
cf(θ)=cf(κ)：共尾幂值列给出 θ 的短共尾列；反过来，θ 的短共尾列
可被严格更大的 2^μ 逐项压住，而这些 μ 必须在 κ 中共尾。于是
2^{cf(θ)}=2^{cf(κ)}<κ≤θ，对奇异基数 θ 使用 SCH 得
2^κ=θ^{cf(κ)}=θ^{cf(θ)}=θ⁺=(2^{<κ})⁺。

于是，在 SCH 下，对无穷 λ 固定并按 κ 归纳，指数只有三种面貌：
κ≤2^λ 时 κ^λ=2^λ；2^λ<κ 且 λ<cf(κ) 时 κ^λ=κ；
2^λ<κ 且 λ≥cf(κ) 时 κ^λ=κ⁺。后两式都有 λ≤2^λ<κ。第二式
用有界函数：λ<cf(κ) 使每个 f:λ→κ 值域有界，故
κ^λ≤Σ_{α<κ}|α|^λ；对每个 ν<κ，归纳给 ν^λ≤κ（ν≤2^λ 时
ν^λ=2^λ<κ；否则 ν^λ 是 ν 或 ν⁺，都 ≤κ），于是 κ^λ≤κ·κ=κ，
而 κ≤κ^λ 平凡。第三式中 cf(κ)≤λ<κ 迫使 κ 奇异，先排除
定理 2.13(2)：若最小 μ<κ 满足 μ^λ≥κ，则 μ>2^λ，归纳给
μ^λ≤μ⁺；但奇异的 κ 是极限基数，μ⁺<κ，矛盾。于是走
定理 2.13(3)，且 2^{cf(κ)}≤2^λ<κ，SCH 给
κ^λ=κ^{cf(κ)}=κ⁺。这就是
“奇异基数假设把指数归约为连续统函数在正则基数上的取值”的精确含义。

## 76.8 H_κ：彻底小于 κ 的集合

70 章的彻底有限集满足 |TC(x)|<ω。把它推广：对无穷基数 κ，定义
**H_κ={x | |TC(x)|<κ}**。H_ω 是彻底有限集合，H_{ω₁} 是彻底可数
集合。这里的“小”沿整条 ∈-闭包测量，不是只看 x 自己的元素个数。

为什么 H_κ 是集合？先估计秩。对任意集合 a，若 α<RK(a)，
沿秩的上确界定义逐层下降，可在 TC(a) 中找到秩恰为 α 的元素；
因此 RK(a) 可以单射进 TC(a)，|RK(a)|≤|TC(a)|。现在 x∈H_κ，
令 M=TC(x)、|M|=λ<κ。若 RK(M)≥λ⁺，上式会迫使
|M|≥λ⁺，矛盾，故 RK(M)<λ⁺。因 κ 是基数，λ⁺≤κ，于是
RK(x)≤RK(M)+1<κ。所以 H_κ⊆V_κ，分离公理保证 H_κ 是集合。

对 λ<κ，每个 A⊆λ 都有 |TC(A)|≤λ<κ，故 A∈H_κ；
于是 2^λ≤|H_κ|。这里不是说整个 𝒫(λ) 本身必属于 H_κ——它的
彻底大小可能达到 2^λ。反向，为每个 x∈H_κ 选择一个把
TC(x)∪{x} 编入某 λ<κ 的单射；x 可由该集合上的 ∈-关系与指定根
经 Mostowski 坍缩唯一恢复。全部这样的编码可由各 λ<κ 的子集与
关系统计，得 |H_κ|≤Σ_{λ<κ}2^λ=2^{<κ}。因此

> **|H_κ|=2^{<κ}，且 H_κ⊆V_κ。**

当 κ>ω 正则时，H_κ=V_κ 当且仅当 κ 不可达。若 κ 不可达，归纳得
每个 α<κ 都有 |V_α|<κ，而 V_κ 中任何 x 的 TC 都落在某个 V_α，
故 x∈H_κ。反过来若 H_κ=V_κ，则每个 λ<κ 的幂集属于 V_κ=H_κ，
其彻底大小迫使 2^λ<κ；结合已设正则性，κ 不可达。H_κ 因而不是
随意造出的集合容器，而是“秩低于 κ”与“彻底大小低于 κ”两条尺度
在不可达处的汇合点。

## 76.9 机器通道：选择、对角线与符号递推

### Isabelle/ZF：把 AC 的假设显式记在库里

ZF 的 `AC` 理论把选择公理作为显式公理，`Cardinal_AC` 再推导良序化
和 AC 下的基数定理。以下就是非空积与幂集选择函数的官方形式：

```isabelle
lemma nonempty_product:
  "0 \<notin> A \<Longrightarrow> \<exists>f. f \<in> (\<Prod>X \<in> A. X)"
  by (rule AC_Pi0)

lemma powerset_choice:
  "\<exists>f \<in> (Pow(C)-{0}) -> C. \<forall>X \<in> Pow(C)-{0}. f`X \<in> X"
  by (rule AC_func_Pow)
```

`0∉A` 表示族 A 不含空集；结论中的 f 同时选完所有因子。`Zorn_po`
与 `AC_well_ord` 分别给出偏序版 Zorn 和良序定理，`cardinal_eqpoll`
给出 |A|≈A。它们与本章定理 2.2–2.6 一一对应，而不是在 HOL 类型层
悄悄借用选择算子。

### Lean/mathlib：无穷基数的官方锚点

```lean
theorem power_eq_two_power_official (κ ν : Cardinal)
    (hν : ℵ₀ ≤ ν) (hκ : 2 ≤ κ) (hκν : κ ≤ ν) : κ ^ ν = 2 ^ ν :=
  Cardinal.power_eq_two_power hν hκ hκν

theorem cantor_power (κ : Cardinal) : κ < 2 ^ κ := Cardinal.cantor
```

第一条正是定理 2.13(1)：在 2≤κ≤λ 且 λ 无穷时，一切 κ^λ 都等于
2^λ。第二条是 König 的 Cantor 特例。`mk_iUnion_le_sum_mk` 给出并集
的基数和上界，`isStrongLimit_beth` 给出 beth 极限项的强极限性。
当前 mathlib 没有与本章定理 2.10 同形的、任意指标集的 König 定理，
所以这里不虚报“完整 König 已库证”；对角构造由下面的有限证明与计算
通道承担。

### Coq/Agda：最小元选择与二坐标对角的完整证明

Coq 沿良序列表扫描，找到第一个仍属于子集 A 的元素：

```coq
Fixpoint choose_by_order (order A : list nat) : option nat :=
  match order with
  | [] => None
  | x :: xs => if existsb (Nat.eqb x) A
               then Some x else choose_by_order xs A
  end.
```

`choose_by_order_sound` 证明返回值必属于 A，`choose_by_order_complete`
证明只要 order 与 A 有公共元素就不会返回 `None`。这给出定理 2.2
“良序⇒选择”的可执行有限截面。

König 的对角思想可压成两个布尔坐标。设两个候选函数为 h₀,h₁，
取 f(0)=¬h₀(0)、f(1)=¬h₁(1)：

```coq
Definition diagonal2 (h0 h1 : bool * bool) : bool * bool :=
  (negb (fst h0), negb (snd h1)).

Theorem diagonal2_escape : forall h0 h1,
  diagonal2 h0 h1 <> h0 /\ diagonal2 h0 h1 <> h1.
```

证明分别取等式的 `fst`、`snd` 投影，布尔取反立即排除相等。Agda 对
同一构造逐布尔值写出不可能等式；Coq 给一般逻辑证明，Agda 让“取反
必不同”直接归约为空模式，两者互相核对。

### Python/Julia：从选择函数生成良序

```python
def wellorder_from_choice(X, c):
    X = set(X)
    seq = []
    while X:
        a = c(frozenset(X))
        seq.append(a)
        X.discard(a)
    return seq

def choice_from_wellorder(order):
    rank = {x: i for i, x in enumerate(order)}
    return lambda A: min(A, key=lambda a: rank[a])
```

第一段就是定理 2.2 的有限递归：每一步从剩余集选择一点；第二段把
顺序转换成“最小元选择器”。实验先做 c→order→c′，再用 c′ 重走
`wellorder_from_choice`，得到同一 order。它验证构造的相容性，不把
有限循环冒充超限递归定理。

König 实验取 I={0,1}、κ=(1,1)、λ=(2,2)，所以 Σ=2<Π=4。
Python 穷举每块至多一个候选函数的 25 种覆盖（含两块皆空），每一种
都构造出逃逸 f；Julia 排除两块皆空的无效“覆盖”，检查其余 24 种。
数量不同是口径不同，不是结果矛盾。Prolog 则检查 16 种单点候选对，
展示每个坐标如何独立避开投影。

### 符号指数求值器：只使用 ZFC 已证的支配关系

```python
def exp_eval(k, lam, depth=0):
    steps = []
    def rec(k, lam, depth):
        if idx_le(k, lam):
            steps.append("κ≤λ，定理 2.13(1)")
            return cpow(lam)
        if k[1] != "ω" and isinstance(k[1], int) and k[1] > 0:
            kp = aleph(k[1] - 1)
            steps.append("豪斯多夫公式，定理 2.12")
            r = rec(kp, lam, depth + 1)
            return cmul(k, r)
        steps.append("引理 2.7：cf(ℵ_ω)=ω")
        return ("sup", k, lam)
    return rec(k, lam, 0), steps
```

求值器保留每一步依据。ℵ₂^{ℵ₃} 直接归约为 2^{ℵ₃}；
ℵ₃^{ℵ₁} 经 Hausdorff 化为 ℵ₃·2^{ℵ₁}，但不能擅自吞掉 ℵ₃，
因为 ZFC 不保证 2^{ℵ₁}≥ℵ₃。ℵ_ω^{ℵ₀} 则停在
( sup_n ℵ_n^{ℵ₀} )^ω 的引理 2.7 形态。这里的“不能继续”是逻辑
信息，不是程序功能不足：是否还有额外等式取决于连续统函数。

## 76.10 收束：ZFC 能算什么，不能算什么

选择公理把逐个存在的 witnesses 拼成整体函数，于是良序、Zorn、势比较、
非空积全部连通；基数和积获得稳定定义，后继基数正则，无穷并的大小
可以按“项数×单项上界”估计。König 又标出不可消除的严格不等式，
特别是 cf(2^κ)>κ。Hausdorff 与定理 2.13 把指数计算归约为连续统
函数，却不消除 CH/GCH 的独立性。下一章转入滤子与理想：非荟萃集、
无界闭集和对角线交，将为本章的正则基数配备一套“几乎处处”的尺度。
