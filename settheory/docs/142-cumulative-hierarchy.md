# 142 · 层垒谱系与绝对性

> 实无穷源于3种情形：首先，当它在绝对独立的超自然世界中……
> 其次，当它出现于变动不拘的造化世界中；其三，当它在观念中被
> 心灵把握为一个数学量。——格奥尔格·康托（第七章题词）

本章覆盖书第七章前半（7.1-7.4；PDF 149-170 页）：一阶模型与
初等嵌入的句法面、层垒谱系 V_α 与 WF、相对化与绝对性——通往
L 与力迫的最后基础设施。

## 142.1 又一点数理逻辑：模型与满足

第 124 章"对象理论与元理论"的分层在此深化。**可表示性定理
（7.1.1）**：递归关系 R 在任何含初等数论的理论 T 中可被公式 φ
"表示"（对真命题 T ⊢ φ，对假命题 T ⊢ ¬φ）——哥德尔编码的
核心工具。**哥德尔第二不完备性（7.1.3）**：T ⊬ Con(T)——
一致性不可自证。

**模型（7.1.5）**：(M,E) 是结构；M ⊨ φ 的满足关系对公式归纳
定义——书对"把 ∈ 解释为 E"的强调正是相对化的种子。初等嵌入
f : M ≺ N（一切公式在 f 的像上保持真值）；**Tarski–Vaught
测试（7.1.7）**是构造初等子模型的实际工具；司寇伦函数（7.1.8）
给出可数下降链——日后 Löwenheim–Skolem 的入口。

## 142.2 层垒谱系：WF = ⋃V_α

> **定义（书 7.2.2）**　V₀ = ∅；V_{α+1} = P(V_α)；V_λ =
> ⋃_{β<λ} V_β。**WF = ⋃_{α∈On} V_α**。

本章工作于 **ZF⁻**（去掉基础公理）——因为要证明基础公理的相
对一致性，不能预设它（书 7.2.1 注）。

**引理 7.2.3**　(1) V_α 传递；(2) β ≤ α ⟹ V_β ⊆ V_α；(3)
κ 不可达 ⟹ |V_κ| = κ。

**秩函数（7.2.4）**　rank(x) = min{β | x ∈ V_{β+1}}。核心性
质（7.2.5）：V_α = {x ∈ WF | rank(x) < α}；WF 传递；**x ∈ y
⟹ rank(x) < rank(y)**；rank(y) = sup{rank(x)+1 | x ∈ y}。

机器侧四通道各持一角：

**Lean**（`Ch19Hierarchy.lean`）锚定 mathlib 的 `ZFSet.rank`
与 `rank_lt_of_mem`——书 7.2.5(3) 的原文在 mathlib 是一行：

```lean
example {x y : ZFSet} (h : y ∈ x) : ZFSet.rank y < ZFSet.rank x :=
  ZFSet.rank_lt_of_mem h
```

**Coq**（`Ch19Hierarchy.v`）以归纳类型 `pset`（PSet : list
pset → pset，即 HF 宇宙的树形表示）从零定义 rank 并**证**书
7.2.5(3)——fold_max_lt 引理做 fold_right 逐项 max 的 Klimali
式归纳，rank_lt_of_mem 直接收割。

**Python**（`19_hierarchy.py`）实现 rank 的 memo 化递归、V_3
内 7.2.5(1)(3)(4) 的全量审计、传递闭包 trcl（7.2.12 (7.5) 式
的 BFS 实现），并验证 7.2.13 的三条恒等式：(1) x 传递 ⟹
trcl(x) = x；(2) y∈x ⟹ trcl(y) ⊆ trcl(x)；(3) trcl(x) =
x ∪ ⋃{trcl(y) | y∈x}（坑账 #69：⋃ 是**求并**不是收集——
`frozenset().union(*list)` 而非 `frozenset(list)`）。

**Julia**（`19_hierarchy.jl`）做数值侧：|V₀..₄| = 0,1,2,4,16
的增长曲线、V_4 的秩直方图（rank 0 → 1 个 ∅；rank 1 → 1 个
{∅}——而非直觉的 4 个！）、深度 d 链的 trcl 大小恰为 d。

**序数住在谱系里（7.2.6）**：rank(α) = α 且 V_α ∩ On = α。
**具体的数学在 WF 中（7.2.7）**：ℤ, ℚ, ℝ ∈ V_{ω+ω}——数学
活动全部发生在层垒谱系的"低层"。**AC 下（7.2.8）**：任何群/
拓扑空间同构于 WF 中的副本。

**WF 中的 ∈ 是良基的（7.2.10）**：rank 取最小元即极小元。逆
不成立（y = {x}, x = {y}, x≠y——∈ 在 y 上平凡良基但 y ∉ WF）
，但传递性修补了（7.2.11）：A 传递 + ∈ 良基于 A ⟹ A ∈ WF。
**传递闭包（7.2.12）** 把任意集的 ∈-后裔打包成集合。

**定理 7.2.14**　x ∈ WF ⟺ trcl(x) ∈ WF ⟺ ∈ 良基于 trcl(x)。

**定理 7.2.15（本章高潮之一）**　以下在 ZF⁻ 中等价：
基础公理 ⟺ ∈ 良基于任意集 ⟺ **V = WF**。

——接受 ZF 的公理就等于接受"每个集合都有秩"——层垒谱系就是
集合宇宙的形状。

## 142.3 相对化：把公式限制到 M

> **定义（书 7.3.1）**　φ^M：把 φ 的量词 ∃y/∀y 换成
> ∃y∈M / ∀y∈M。

φ^M 读作"φ 在 M 中真"。函数符号的相对化 f^M = f ∩ (M×M)
（要求 M 对 f 的定义封闭，7.3.2）。

> **定义（书 7.3.3）**　M ⊨ T ⟺ T 的每条公理 φ 在 M 中真。

**定理 7.3.4（本章主定理之一）**　**WF ⊨ ZF**（ZF⁻ 中证）。

证明逐条验证：存在公理（M 非空即可）；**外延**（M 传递即可，
引理 7.3.5）；**分离**（M 对子集封闭即可——P(X)⊆M 的强条件
在 WF 中免费）；对集/并集（WF 对构造封闭，7.2.7）；**幂集**
（传递 M 中 (u⊆X)^M ⟺ u∩M⊆X，WF 满足 P(X)^WF = P(X)）；
替换（WF 的像不逃逸）；基础（取秩最小元）。∎

Lean 侧的对应（`Ch19Hierarchy.lean`）：**相对化的日常形态就是
Lean 的受限量词**——`(∀ x ∈ M, P x)` 即 `(∀x P x)^M` 的
typeclass 版。受限量词在 Lean 里是定义性语法而非元操作——
"绝对性"变成了"Iff.rfl 级"的事实。

## 142.4 绝对性：M 里的 φ 和 V 里的 φ 一致吗？

> **定义（书 7.4.1）**　φ 对 M⊆N **绝对**：∀x̄∈M(φ^M(x̄)
> ↔ φ^N(x̄))。

**Δ₀ 公式（7.4.4）**：只用受囿量词（∀x∈y、∃x∈y）的公式。
**引理 7.4.5**　Δ₀ 公式对传递模型绝对；Σ₁ 向上保持；Π₁ 向下
保持。

**定理 7.4.8——绝对性的弹药库**：以下 14 个概念在 ZF⁻−Pow−Inf
中等价于 Δ₀ 公式（故对一切传递模型绝对）：x⊆y、x=y、x∪{y}、
{x,y}、{x}、(x,y)、∅、x+y、x∩y、x−y、x⁺、传递集、⋃x、⋂x。

证明模式：为每个概念找到显式 Δ₀ 定义。例：(x,y,z) 定义
z = (x,y)（7.21 式）；∅ 定义 z 没有元素（7.23 式）。**这些
公式的形状本身就是机器检查的对象**——受限量词形态即 Lean 的
`∀ x ∈ M` 语法。

**复合封闭（7.4.9）**：绝对函数的复合绝对——绝对性库的引擎。

**定理 7.4.10**　有序对、卡氏积、关系、dom、ran、函数、f(x)
、单射——全部对 ZF⁻−Pow−Inf 的传递模型绝对。

这些结果为 7.5 节的基础公理相对一致性扫清道路：无穷公理的
验证需要 ∅ 和后继函数的绝对性——7.4.8 的 (7)(11) 恰好供应。

## 142.5 相对一致性的模板

> **定理（书 7.5.2）**　T ⊢ M ≠ ∅ + T ⊢ M ⊨ Z ⟹ Con(T)
> ⟹ Con(T ∪ Z)。

这是哥德尔 L（第 145 章）和 Cohen 力迫（第 146 章）共享的证明
模板：找到 ZF⁻ 中的类 M，证明它满足 ZF + 额外公理，就得到相
对一致性。

> **推论（书 7.5.3）**　Con(ZF⁻) ⟹ Con(ZF)：基础公理相对于
> ZF⁻ 一致——WF 是 ZF 的内部模型。

**V_ω 是 ZFC−Inf+¬Inf 的模型（7.5.5）**：有限宇宙否定无穷但
满足 AC（有限集总可良序——7.5.4 良序的绝对性）——这是相对
一致性方法的**最小实例**。

## 本章要点

1. 层垒谱系 V_α：递归构造（∅/幂集/并）；WF = ⋃V_α 是传递真
   类；V=WF ⟺ 基础公理（7.2.15 三等价）。
2. rank(x) = sup{rank(y)+1|y∈x}；x∈y ⟹ rank x < rank y——
   ∈ 的良基性即秩的严格下降。
3. trcl(x)（7.2.12）：最小传递扩张；x∈WF ⟺ trcl(x)∈WF。
4. 相对化 φ^M：量词限制到 M；M⊨T 逐公理验证；WF ⊨ ZF。
5. 绝对性：Δ₀ 公式对传递模型绝对（7.4.5）；14 个基本构造是
   Δ₀ 的（7.4.8）；复合封闭（7.4.9）。
6. 机器面：Lean ZFSet.rank 原文；Coq pset 的归纳证明；Python
   的 trcl 三恒等式；Julia 的秩直方图。
