# 134 · 超穷递归与序数算术

> ω + 1 与 1 + ω 不是一回事——序数算术的第一课是"方向感"。

本章覆盖书 4.3-4.4 节（PDF 84-90 页）：超穷递归的算术兑现——
序数的加法、乘法、幂按三段式定义，证明它们正是第 132 章"和与积"
的序型，并推出左消去律、减法、除法与康托正则形式。

## 134.1 加法：递归定义与非交换性

> **定义（书 4.4.1）**　对固定的 β：
> (1) β + 0 = β；(2) β + (α+1) = (β+α) + 1；
> (3) 非零极限 α：β + α = sup{β + ξ | ξ < α}。

递归定理的用法（书原样演示）：G₁(z) = z、G₂(z) = z+1、
G₃(t) = sup(ran t)，带参数得到 F(z,α) = β+α。三条款逐字对应
超穷递归的三段式。

**例（书 4.4.2）全录**——每个例子都是"方向感"训练：

- (β+1)+1 = β+2，……（后继步串链）；
- ω + ω = sup{ω+n | n<ω} = ω·2；
- **m + ω = sup{m+n | n<ω} = ω**（左边的有限项被极限步冲走）
  ——于是 ω + m ≠ m + ω；
- **1 + ω = 2 + ω = ω**（不同的有限数 + ω 相等！）。

加法的集合论意义（定理 4.4.3）：**α₁ + α₂ 是良序集"和"的序型**
（对 α₂ 超穷归纳：后继步把同构延长一格，极限步取并）。左单调
（书 4.4.4）：

> β + α₁ < β + α₂ ⟺ α₁ < α₂；β + α₁ = β + α₂ ⟺ α₁ = α₂。

**左消去**成立、**右消去**一般失败（1+ω = 2+ω 正是右消去的反例
——但自然数幂次的右消去 `add_right_cancel` 在 Lean 里对
a + n = b + n 成立，见下）。

## 134.2 乘法与幂

> **定义（书 4.4.5）**　β·0 = 0；β·(α+1) = β·α + β；
> 极限 α：β·α = sup{β·ξ | ξ<α}。
>
> **定义（书 4.4.8）**　β⁰ = 1；β^{α+1} = β^α · β；
> 极限 α：β^α = sup{β^ξ | ξ<α}。

**例（书 4.4.6/4.4.9）**：β·1 = β；β·2 = β+β；β·ω =
sup{β·n}；**1·α = α**（"并非显然，需要归纳证明"——原书特意
注明）；**2·ω = ω ≠ ω·2**；2^ω = ω、n^ω = ω（n ≥ 2），
但 ω^ω > ω。定理 4.4.7：α·β 是良序集"积"（字典序）的序型，
显式同构 f(ξ,η) = α·η + ξ——**积的每一层是加法的一个尾巴平移**
。

## 134.3 尾巴账：减法、除法与正则形式

> **引理（书 4.4.10）**　α + β = α ∪ {α + ξ | ξ < β}。

（对 β 归纳；几何读法：α+β 是把"α 之上的 β 层尾巴"摞在 α 上。）
**推论（4.4.11）**：α < β 时存在唯一 γ 使 α + γ = β——**序数
减法**合法。**引理（4.4.12）**与**推论（4.4.13）**：除法——
对 1 ≤ α < β，存在唯一的 (ξ, ρ)：ρ < α 且 β = α·ξ + ρ——
"带余除法"，余数严格小于除数。

> **定理（书 4.4.14，康托正则形式）**　每个非零序数 β 唯一地表为
> β = ω^{ξ₀}·c₀ + ω^{ξ₁}·c₁ + … + ω^{ξ_{k-1}}·c_{k-1}，
> 其中 ξ₀ > … > ξ_{k-1} 是序数、cᵢ ∈ ω\{0}。

（更一般版本对任意底 α > 1 成立；证明对 β 归纳，关键是指数集
{ξ | α^ξ ≤ β} 有最大元。）

## 134.4 机器侧：ω^ω 窗口内的完整算术

CNF 在 ω^ω 窗口（指数为自然数）内可以**完整机器化**：序数 =
系数向量 (c₀,…,c_k)。三个通道各领一块。

**Coq：加法的定理化**（`examples/coq/Ch134OrdinalArith.v`）。加法
的闭式（三段式递归展开的结果）：设 β 的最高非零项在指数 k，则

    α + β = Σ_{e<k} β_e·ω^e + (α_k + β_k)·ω^k + Σ_{e>k} α_e·ω^e

——β 之下全按 β、交叉处相加、之上全按 α。Coq 实现为
`firstn/skipn` 切段，右吸收律变成 `reflexivity` 级的定理：

```coq
Theorem nat_plus_omega : forall n : nat, oadd [n] omegaC = omegaC.
Proof. reflexivity. Qed.

Theorem nat_plus_limit : forall n m : nat, oadd [n] [m; 1] = [m; 1].
Proof. intros; reflexivity. Qed.

Theorem omega_plus_nat : forall m : nat, oadd omegaC [m] = [m; 1].
Proof. intros; reflexivity. Qed.
```

三条定理分别是"有限+ω=ω"、"有限+(m+ω)=m+ω"（右吸收的一般化）
与"ω+m 保留"——**方向不对称被三个 reflexivity 钉死**。书例
4.4.2 的六个样本（e1-e6）逐条 `reflexivity`，含 (3+ω)+ω = ω·2
（低项 3 被吸收）与 1+ω = 2+ω（右消去失败）。

**Python：全引擎**（`examples/python/134_ordinal_arith.py`）。加、
乘、幂、减、除全部实现，书例全录精确复算：

```python
def omul(a, b):
    a, b = canon(a), canon(b)
    if not b:
        return ()
    d = len(a) - 1                 # α 的最高指数
    c = a[-1]                      # α 的首系数
    res = [0] * (d + len(b))
    for i in range(d):             # α 的低位尾巴：仅当 β0≠0 保留一次
        res[i] = a[i] if b[0] else 0
    res[d] = c * b[0]              # e=0：首系数放大
    for e in range(1, len(b)):     # e≥1：搬到 d+e，首系数归一
        res[d + e] = b[e]
    return canon(res)

assert oeq(omul((2,), W), W)                       # 2·ω = ω
assert oeq(omul(W, (2,)), (0, 2))                  # ω·2 ≠ 2·ω
assert oeq(omul((1, 2), (5, 1)), (1, 10, 1))       # (ω·2+1)(ω+5) = ω²+ω·10+1
```

乘法公式的来历值得写进注释：由右分配律 α·β = Σₑ α·β_e·ω^e
（降序相加）——e ≥ 1 的项 α·ω^e = ω^{d+e}（首系数**归一**，极
限步冲走一切细节）；e = 0 的项 α·m = ω^d·(c·m) + 尾巴（首系数
**放大**，尾巴只活一次）。**首系数的两种命运**——归一或放大——
正是"极限冲刷 vs 后继叠加"的算术面。乘法审计还包括一个机器
教训：初版公式漏了首系数 c 与尾巴门控，被 (ω·2+1)·(ω+5) =
ω²+ω·10+1 的样本当场打回（坑账 #45）。4.4.10 的尾巴平移、
4.4.11 减法（交叉指数处做系数减法）、4.4.13 除法回收
（3·(ω·2+1)+2 = ω·2+5、ρ < α）都有窗口审计。

**Julia：三段式的执行面**（`examples/julia/134_ordinal_arith.jl`）
。加法按三段式语义实现（与闭式等价），乘法幂与除法样本齐备：
2·ω = ω、ω·ω = ω²、(ω+1)(ω+5) = ω²+ω·5+1、
3·(ω·2+1)+2 = ω·2+5。幂的样本：ω² = ω·ω、ω³、2³ = 8（有限
情形回到普通算术）、2^ω = ω。

**Lean：结构律的定理化**（`examples/lean/Settheory/Ch134OrdinalArith.lean`）
。mathlib 把序数算术的结构律做成库定理，机器直接点名：

```lean
example (a b c : Ordinal) : a + b + c = a + (b + c) := by ac_rfl

/- 左严格单调（书 4.4.4(1)）——经 Covariant 实例走根命名空间。 -/
example (β α₁ α₂ : Ordinal) (h : α₁ < α₂) : β + α₁ < β + α₂ :=
  (add_lt_add_iff_left β).mpr h

example (m : ℕ) : (m : Ordinal) + Ordinal.omega0 = Ordinal.omega0 :=
  Ordinal.add_omega0 (Ordinal.natCast_lt_omega0 m)

example : Ordinal.omega0 + (1 : Ordinal) ≠ (1 : Ordinal) + Ordinal.omega0 := by
  simp
```

结合律对序数成立（`ac_rfl` 一行）；左消去的 iff 形态、
`add_omega0`（右吸收）、非交换性见证全部定理化。超穷递归定理本
体在 mathlib 的名字是 `Ordinal.limitRecOn`（三段式的打包）。

## 134.5 非交换性速查表

序数算术与读者熟悉的算术的差异集中在"右极限冲刷、左细节保留"。
一表收账（ω 为基准）：

| 等式 | 成立？ | 机制 |
|---|---|---|
| m + ω = ω | ✓ | 右极限步冲走左部 |
| ω + m > ω | ✓ | 左部原样保留 |
| 1 + ω = 2 + ω | ✓ | 右消去失败的标准反例 |
| ω + 1 ≠ 1 + ω | ✓ | 非交换 |
| (α+β)+γ = α+(β+γ) | ✓ | 结合恒成立 |
| β + α₁ < β + α₂ ⟺ α₁ < α₂ | ✓ | 左消去（4.4.4） |
| 2·ω = ω | ✓ | 右极限步：首系数归一 |
| ω·2 = ω + ω > ω | ✓ | 后继步：首系数放大 |
| n^ω = ω（n ≥ 2） | ✓ | 幂的极限冲刷 |
| ω^ω > ω | ✓ | 窗口外：需更高指数表示 |

几何读法总纲：**把右参数想成"层数"，左参数想成"每层的内容"**——
加法是往右摞层（左边旧层被右边新结构冲掉），乘法是每层一份左参数
的拷贝（层与层之间，低细节只能活一次）。速查表的每一行都能在
三通道的断言里找到逐字对应的机器复算。

## 本章要点

1. 加法：三段式定义；**右吸收**（m+ω = ω、1+ω = 2+ω）而**左
   保留**（ω+m）——方向不对称是序数算术的第一课；左消去成立、
   右消去失败。
2. 乘法/幂同款三段式；2·ω = ω ≠ ω·2；n^ω = ω（n≥2）而
   ω^ω > ω；α·β = 积（字典序）的序型，层 = 尾巴平移。
3. 尾巴账：α+β = α ∪ {α+ξ}；减法（4.4.11）与带余除法
   （4.4.13：β = α·ξ + ρ、ρ<α）唯一存在。
4. 康托正则形式（4.4.14）：每个非零序数的 ω-多项式展开唯一——
   本教程三通道的 CNF 表示就是它的 ω^ω 窗口化身。
5. 机器面：Coq 把右吸收钉成 reflexivity；Python 全引擎复算全部
   书例（乘法首系数的两种命运）；Lean 把结构律（结合、左消去、
   吸收、非交换）定理化。
