## 50.1 泛型滤子：三个世界

**定义（Viale Def 5.1.1/7.1.11）** 族 𝓕 = {Dᵢ} 的**泛型滤子** G：
与每个 Dᵢ 相交的滤子。对可数传递模型 M 与 P ∈ M：G 是
**M-泛型**的，若 G 与 M 中每个稠密集相交。

**泛型滤子引理（Viale Lemma 5.1.2）** 对预序 P 与**可数**族
{Dₙ : n ∈ ω} 的前稠密集、任意 p ∈ P：存在 𝓕-泛型滤子 G ∋ p。

*证明*：AC + 递归：p₀ = p；pₙ₊₁ ≤ pₙ 且 pₙ₊₁ ∈ Dₙ（前稠密给
相容精化，取一个）。G := {pₙ} 的上闭包——递增链自动是滤子基。∎

一行证明，一行哲学：**可数个要求可以逐个满足**。三个世界：

1. **V 里的可数族**：总是行——Lemma 5.1.2。
2. **V 里的全族**（所有 D_f, f ∈ 2^ω）：**不行**——Exercise
   5.1.6：G 与 {Eₙ} 交齐后 ⋃G 是全函数 g，但 G ∩ D_g = ∅
   （G 的元素与 g 处处相容，g ∉ G 则 D_g 咬空——自指陷阱）。
   Fact 5.1.7 更狠：(ω₁)^<ω 上 ω₁ 个稠密集 {B_α} 没有共同
   泛型滤子（否则 ⋃G : ω₁ → ω₁ 是满射）。**"全知"与"滤子"
   不相容**。
3. **可数 M 里的全族**：M 可数 ⟹ M 里的稠密集族可数（在 V
   中看）⟹ 回到世界 1：M-泛型滤子存在。且 **G ∉ M**（Fact
   5.1.8）：P∖G 在 M 中稠密（原子性与可分离性保证），G ∈ M
   会自咬。**泛型 = 从外面来的新东西**。

**M[G] 的定义预告**：M[G] := {τ_G : τ ∈ M^B}——54 章的主菜。

## 50.2 Baire 纲定理：泛型性的拓扑化身

**定理（Viale Cor 5.1.3）** 紧 Hausdorff 空间 X 中可数个稠密开
集之交稠密。

*证明*：给定非空开 A。正则性给 Cl(B) ⊆ A 的非空开 B。在
(τ_B∖{∅}, ⊆) 上令 Fₙ := {O : Cl(O) ⊆ Eₙ ∩ B}（Eₙ = Dₙ ∩ B）——
Fₙ 稠密开（紧 Hausdorff 的正规性：每点有闭包缩进的邻域）。
泛型滤子引理给 G 与一切 Fₙ 相交；{Cl(Bₙ) : Bₙ ∈ G} 具有限交
性质，紧性给交点 x ∈ A ∩ ⋂Dₙ。∎

反向也成立：泛型滤子引理 ⟹ Baire。**"泛型滤子 = 穿过一切
大集合的点"**——St(B) 上的 M-泛型点。这一视角在 51-52 章
（Forcing Lemma I：b ⊩ φ ⟺ {G : M/G ⊨ φ} 稠密于 N_b）兑现。

## 50.3 Fn(X, Y, κ)：Cohen 偏序族

**定义（Viale Def 5.2.1）** Fn(X,Y,κ) := {s : s 是函数，
dom(s) ⊆ X，|dom(s)| < κ，ran(s) ⊆ Y}，序为**反包含**
s ≤ t := t ⊆ s（延拓 = 精化）。Fₛ := {f ∈ Y^X : s ⊆ f}。

关键恒等式（Remark 5.2.2）：**Fn(ω,2) 的布尔补全 = RO(2^ω)**
（乘积拓扑）；s ↦ N_s = Fₛ 是稠密嵌入——Cohen 迫使"加一个
新实数"的偏序身份由此定型。Fn(2^ω, 2) 则是 54 章 ¬CH 的主角。

**Fact 5.2.3（Odd/Even）** RO(2^ω) 中有非闭正则开：奇偶层
Odd/Even 开、不交、闭包交于常零列——正则开 ≠ 闭集的活例，
也是 St(RO) → 2^ω 非单射（Rmk 5.2.5）的原因：RO 看得见
"奇偶性"这种 2^ω 看不见的边界信息。

## 50.4 Δ 引理与 ccc

**定义（Viale Def 5.3.1）** 集族 S 是 **Δ-系（sunflower）**：
存在根 r 使任意 a ≠ b ∈ S 有 a ∩ b = r。

**引理（Viale Lemma 5.3.2，Δ 引理）** κ 正则不可数，A 是 κ 个
有限集的族，则 A 有大小 κ 的 Δ-子系。

*证明*（对固定尺寸 n 归纳——Viale 的初等版本）：
尺寸统一：κ 正则 ⟹ 某 n 有 κ 个成员尺寸恰 n。
n = 1：空根。n > 1：对某 p，或 {X : p ∈ X} 有 κ 个（归纳于
X∖{p}，尺寸 n−1，根加回 p），或每个 p 只属 <κ 个——则可递归
取 κ 个两两不交的成员（空根 Δ-系）。∎

（对照 26 章 Jech 路线的 Δ 引理——同一引理的两种烹饪：Jech
书用 dom 色数论证，Viale 用尺寸归纳；机器通道验证有限版。）

**定理（Viale Prop 5.3.4）** **Fn(X, 2) 有 ccc**（对一切 X）。

*证明*：反链 A ⊆ Fn(X,2)；把定义域打包进 |A| 大的 X₀ ⊆ X。
若 |X₀| ≤ ℵ₀：A 按有限定义域 r 分桶 2^r 个，可数桶装不下
不可数 A——矛盾。若 |X₀| = ℵ₁：固定值型 t_s（有限 0-1 串），
正则性给 ℵ₁ 个同型成员；其定义域族有 ℵ₁ 大小 Δ-子系（根 r）；
同型 + 定义域交恰为 r ⟹ 两两相容——与反链矛盾。∎

**推论（Viale Cor 5.3.6）** RO((2^ω)²) 有 ccc（Fn(2^ω,2) 的
补全保 ccc——49 章 Lemma 4.3.2）。这是 54 章 ¬CH 模型"基数
不塌"的保证。

ccc 记号——本文件自建 `IsDeltaSystem`（三集版本）并证明
**有限 Δ 引理**：{1,2},{1,3},{1,4} 型三条集合已是 Δ-系；以及
Fn(3,2) 的反链上界（2³ = 8 元偏序的反链 ≤ 4——穷举性引理）。

**Julia（`examples/julia/50_fnxy.jl`）**：**Δ 引理穷举实验室**——
对 n = 4 个点的全部 2-元/3-元子集族，随机抽取大族，验证总能
找到 Δ-子系（大小 ≥ 阈值）；再对 Fn(5,2)（2^5 = 32 条件）
枚举**极大反链**，验证 ccc 的有限形态（反链 ≤ 2⁵/最短长度）；
泛型滤子构造器：对可数稠密集族的有限截段跑 Lemma 5.1.2 的
递归，打印穿链过程。

**Python（`examples/python/50_fnxy.py`）**：**Odd/Even 与

**Agda（`examples/agda/Ch50_fnxy.agda`）**：泛型滤子构造的
