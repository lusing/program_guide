# 49 · 完备布尔代数：布尔补全唯一性与测度代数

> 46-48 章备齐了三块地基：RO(X) 的五律、超滤子拓扑、布尔环。
> 本章合拢成 Viale 路线的**枢纽定理**：每个预序 Q 都有唯一的
> 完备布尔代数 B_Q 使 Q 稠密嵌入其中（布尔补全）；B 完备当且
> 仅当 St(B) 极不连通；测度代数 MALG 是"完备 + 无原子 + ccc"
> 三合一的旗舰实例。
>
> 本章覆盖 Viale 第 4 章全部。

## 49.1 完备性与原子分解

**定义** 布尔代数 B **完备（cba）**：每个子集 X ⊆ B 都有 sup
⋁X 与 inf ⋀X（等价地有其一——由 De Morgan 互换）。

**分解引理（Viale Lemma 4.0.3）** 任何 cBa B 可拆成原子部与
无原子部的直和：取 c := ⋁{原子}，则 B ≅ B↾c × B↾¬c，前者
原子化、后者无原子（b ↦ (b∧c, b∧¬c) 是布尔环同构——48 章
环视角的免费标准件）。力迫只关心无原子侧（46 章 Fact 2.2.13：
原子使泛型平凡）。

**同态三档的完备版（Viale Def 4.0.4/Lemma 4.0.7）** 完备同态 =
保前稠密集的映射 = 保任意 sup/inf 的同态；且**保序 + 保不相容 +
保 sup** 已蕴含保补、保 inf——检查三个条件就够。这是下一节
唯一性证明的技术引擎。

## 49.2 RO(X) 是完备布尔代数

**定理（Viale Thm 4.1.2）** 对任何拓扑空间 (X,τ)，
(RO(X), ∧, ∨, ¬, ∅, X) 是 cBa，其中
U ∨ V := Reg(U∪V)，U ∧ V := Reg(U∩V)，¬U := X∖Cl(U)。

*证明*。46 章五律已给出布尔代数结构（⊥⊥ 即 Reg；对交封闭）。
完备性：对族 {Uᵢ} ⊆ RO(X)，令 V := Reg(⋃Uᵢ)：
- **上界**：每个 Uᵢ ⊆ ⋃Uᵢ ⊆ V（46 章引理 2.1.7 的 Reg 单调）；
- **最小**：若 W 是 RO(X) 中的另一上界（Uᵢ ≤ W 即 Reg(Uᵢ∪W) = W
  亦即 Uᵢ ⊆ W），则 ⋃Uᵢ ⊆ W ⊆ Cl(W)，取正则化
  V = Int(Cl(⋃Uᵢ)) ⊆ Int(Cl(W)) = W。∎

注意 **∨ 不等于 ∪**（46 章的"缝合"教训），但 48 章的 sup 拓扑
算法（Prop 3.11.2）给出计算方法：{Uᵢ} 的 sup 恰是使
{N_{Uᵢ}} 在 N_a 中稠密的最小 a。

## 49.3 完备性的拓扑判据

**命题（Viale Prop 4.1.5）** B 完备 ⟺ RO(St(B)) = CLOP(St(B))
⟺ St(B) **极不连通**（开集的闭包开）。

*证明*。（⟹）设 A 开：A = ⋃{N_{bᵢ}}；令 b := ⋁bᵢ（完备性）。
断言 Cl(A) = N_b：⊇ 显然（b ≥ bᵢ）；⊆ 用 48 章 sup 算法的
"最小性"翻译成"N_c 与 A 不交则 N_c ∩ N_b = ∅"。故 Cl(A)
clopen ⊆ RO。
（⟹ 逆）B = CLOP(St(B)) = RO(St(B)) 是 cBa（49.2）。∎

与 48 章 Lean 锚点 `Stonean` 的连线在此接通：**cba 的范畴对偶
= Stonean 空间**——Viale 附录 D.3 的 Stone-Čech 表征
（紧 Hausdorff X 极不连通 ⟺ C(X,ℝ) 有界闭集有上确界）是
这条对偶的分析学回声。

## 49.4 布尔补全：存在与唯一

本节是 Viale 路线对 Jech 路线 17 章（r.o.(P) 手工构造）的
定理化收编。

**定理（Viale Thm 4.2.4，布尔补全）** 任何预序 (Q, ≤) 都存在
cba B_Q 与映射 j : Q → B_Q：
1. j 保序且保不相容；
2. j[Q] 在 (B_Q⁺, ≤) 中稠密；
且 B_Q 在同构意义下唯一（j 不必唯一）。

*存在的证明（Lemma 4.2.5）*：取 **B_Q := RO(Q, τ_Q)**——Q 的
**序拓扑**（46 章：↓p 为基）上的正则开集族！映射
j(p) := Reg(↓p)。
- **保序**：p ≤ q 给 ↓p ⊆ ↓q 且 ↓p 在 Reg(↓p) 中稠密，
  Fact 2.1.7 给 Reg(↓q) ⊆ Reg(↓p)，即 j(p) ≤ j(q)（注意
  ⊆ 与 ≤ 的反向：包含越大 = 条件越强）。
- **保不相容**：p ⊥ q ⟺ ↓p ∩ ↓q = ∅ ⟺（Fact 2.1.8）
  Reg(↓p) ∩ Reg(↓q) = ∅ = j(p) ∧ j(q)。
- **稠密像**：非空正则开 A 取 p ∈ A，则 ↓p ⊆ A（A 下闭），
  j(p) = Reg(↓p) ≤ A。∎

*唯一的证明（Lemma 4.2.6）*：设 k : Q → B 是另一组（B cba，
k 保序保不相容、像稠密）。定义
φ : RO(Q) → B，φ(A) := ⋁{k(p) : p ∈ A}。
逐步验证：φ 保序（定义）、保不相容（稠密像 + 不相容传递）、
φ∘j = k（反证：φ(j(q)) > k(q) 处用稠密性找 r ∈ Q 落在差集，
导出 r 与 q 既相容又不相容）、满（b = ⋁{k(p) ≤ b} 的
A := {p : k(p) ≤ b} 是正则开、φ(A) = b——稠密性又一次）、
单（两个正则开不同则有一个 j(q) 落差，像被推开）。由
Lemma 4.0.7，φ 是完备同构。∎

**这条定理的力度**：Jech 17 章的正则割构造只是 RO(Q) 的一个
坐标选择；Viale 把它升格为"**任何 cba + 稠密序嵌入都同构于
RO(Q)**"的普适性质。50 章起所有力迫构造（Fn(X,Y) 等）自动
获得布尔补全，不再逐例手工。

**三个推论（Viale Cor 4.2.7/4.2.8 + Rmk 4.2.10）**：
1. Q **可分离** ⟺ j 单射 ⟺ ↓p = Reg(↓p) 对一切 p——可分离
   预序"已经是自己的稠密子代数"；
2. Q 无原子 ⟺ B_Q 无原子（稠密像搬运原子性）；
3. **可数无原子 cba 唯一**（有可数稠密子集的无原子 cba 彼此
   同构）：ℝ 的开集族、有理端点区间格、2^<ω、Cantor 空间的
   RO、(2^ω, 乘积拓扑) 的 RO——五种面目一个代数。Cohen
   力迫的布尔身份从此定型。

## 49.5 链条件

**定义** P 满足 **κ-cc**：所有反链大小 ≤ κ（ccc = ℵ₀-cc）。

**引理（Viale Lemma 4.3.2）** P 有 κ-cc ⟹ RO(P)⁺ 亦然。
*证*：反链 A ⊆ RO(P)⁺，每个 a ∈ A 用稠密性找 p_a ∈ P 精化
a；{p_a} 仍是反链（j 保不相容），a ↦ p_a 单（a ≠ b 则
a∧b = 0 迫使 p_a ⊥ p_b）。∎

**引理（Viale Lemma 4.3.4）** B 是 <κ-cc 且 <κ-完备（<κ 大小
的子集有 sup）⟹ B 完备。*证*：对 X ⊆ B，Zorn 取 ↓X 内的极大
反链 A（练习 3.11.4 的第一部分），|A| < κ，故 b := ⋁A 存在；
Fact 3.11.7 的换骨公式给 ⋁X = ⋁A = b。∎——**这个引理是
测度代数完备性的全部秘密**。

## 49.6 测度代数 MALG

**定义** 𝓜([0,1]) = Lebesgue 可测集族；Null = 零测集理想；
**MALG := 𝓜([0,1])/Null**（等价类 [A] = {B : AΔB 零测}）。

零测：∀ε ∃可数开区间覆盖 Σ|Iᵢ| < ε。商运算良定（零测差不
改变可测性与测度）。三定理：

**定理（ccc，Viale Prop 4.3.6）** MALG 无不可数反链。
*证*：反链 = 两两不交（mod Null）正测集族。令
Aₙ = {[X] : μ(X) > 1/n}；若 |Aₙ| > n 则 n+1 个成员的不交并
测度 > 1 与 ⊆ [0,1] 矛盾，故 |Aₙ| ≤ n；反链 ⊆ ⋃Aₙ 可数。∎

**定理（可数完备，Viale Prop 4.3.7）** 可数族 {[Bₙ]} 的 sup =
[⋃Bₙ]（可数个零测并不改变零测性）。∎

**定理（无原子，Viale Prop 4.3.8）** 任何正测度集可二分为
两个正测度集。
*证*：反设 A 不可分。二分区间套 [iₙ/2ⁿ, (iₙ+1)/2ⁿ]：每层
A∩Iₙ 测度必等于 μ(A)（否则左右两半就是分裂），套收缩到单点
x，μ(A) = μ(∩(A∩Iₙ)) ≤ μ({x}) = 0（测度的可数单调性），
矛盾。∎

**合体（Viale Cor 4.3.9）** MALG 是**完备、无原子、ccc** 的
布尔代数——由 49.5 的引理（可数完备 + ccc ⟹ 完备）收官。
它是 52 章布尔值模型大例子（L⁺([0,1]) 可测函数空间）的代数
底座，也是随机实数力迫（44 章 Solovay 模型的 Jech 路线预告）
的偏序。

## 49.7 机器通道

**Lean（`Settheory/Ch49Completion.lean`）**：mathlib 官方
CompleteBooleanAlgebra 锚点——𝒫(X) 的完备实例、完备格 sup/inf
的 De Morgan 互换；自证 Lemma 4.0.3 的映射单射性（
b ↦ (b⊓c, b⊓¬c) 单）：三行 `BooleanAlgebra` 推理。MALG 的
正式形式化 mathlib 尚缺（如实标注——`MeasureTheory` 有
`NullMeasurableSet` 但无商代数构造），数值侧由 Python 承载。

**Julia（`examples/julia/49_completion.jl`）**：**有限偏序的
布尔补全实操**（Lemma 4.2.5 的可执行版）——取 V 形偏序
P = {a, b, c, d}（c ≤ a, c ≤ b，d 为顶）：枚举序拓扑的开集
（下闭集）、算 Reg(↓p)，验证 j 保序（包含反向）、保不相容、
像稠密；再枚举 RO(P) 全体，确认它是含 P 稠密的**最小** cBa
（4 元布尔代数——V 形偏序"看不见" d 以下的裂缝，补全只到
𝒫({a,b})）。Jech 17 章的正则割在此被定理化构造取代。

**Python（`examples/python/49_completion.py`）**：**MALG 数值
实验室**——dyadic 区间上的可测集运算：(a) ccc 数值版：随机
生成两两不交正测度集，验证个数 ≤ 1/(最小测度)（Prop 4.3.6
的量化形式）；(b) 无原子二分（Prop 4.3.8）：对任意正测度
dyadic 集，二分搜索找左右半都正测度的切点；(c) 可数完备：
嵌套区间并的测度 = 上确界（测度的连续性数值验证）。

**Coq（`examples/coq/Ch49_completion.v`）**：有限预序 RO 补全
的决定性验证——3 元链 {0 < 1 < 2} 的序拓扑、Reg 计算、
j 保序/保不相容/稠密三断言（vm_compute 后 reflexivity）；
对照：链的补全是 2 元代数（链太"细"——任何两个非底元素相容，
补全坍缩为 {0,1}）——**稠密像的唯一性定理的边界现场**。

**Agda（`examples/agda/Ch49_completion.agda`）**：2^≤2 前缀序
的 RO 补全：Reg(↓s) 的显式表 + "j[Q] 在 RO⁺ 中稠密"的
布尔检查（每个非空正则开集被某 j(s) 精化）。

**Prolog（`examples/prolog/49_completion.pl`）**：V 形偏序的
补全查询：下闭集枚举、正则开判定、稠密性 forall 检查——
Julia 版的 Prolog 镜像，双通道互证。

**Isabelle/ZF（`examples/isabelle/ST49/Completion.thy`）**：
谓词式嵌入（48 章教训）：`regopen` 谓词 + **j 保序** 与
