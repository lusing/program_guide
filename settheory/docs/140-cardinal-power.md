# 140 · 基数幂与连续统

> 对于基数的幂运算，除了共尾的限制外，我们只是知道 κ ≤ λ 时
> κ^λ = 2^λ——可这不过是把无知归于无知！——原书 5.4 节末

本章覆盖书 5.5 节（PDF 122-126 页）：幂函数 κ^λ 在 ZFC 下的
完整行为分类（定理 5.5.4）、吉莫尔函数、SCH，以及 GCH 下的
完全计算。

## 140.1 幂函数的三分律

> **引理（书 5.5.1）**　κ 无穷：
> (1) λ ≥ cf κ 时 κ^λ = (sup_{μ<κ} μ^λ)^{cf κ}；
> (2) λ < cf κ 时 κ^λ = sup_{μ<κ} μ^λ ⊙ κ。

(2) 的证明干净：λ < cf κ 时每个 f : λ → κ 落在某个 α < κ 内
（正则性 = 小并不大！），故 κ^λ = ⋃{α^λ} ≤ κ ⊙ sup μ^λ。

> **定理（书 5.5.4）——ZFC 下 κ^λ 的完整分类**：
> (1) κ 非 λ-强（∃μ<κ: μ^λ ≥ κ）⟹ κ^λ = μ^λ；
> (2) κ ≤ λ ⟹ κ^λ = 2^λ；
> (3) κ > λ 且 κ λ-强：
>　　(a) cf κ > λ ⟹ κ^λ = κ；
>　　(b) cf κ ≤ λ ⟹ κ^λ = κ^{cf κ}（吉莫尔函数 ℷ(κ)）。

**吉莫尔函数** ℷ(κ) = κ^{cf κ} 是幂函数的最小未知核——其余
一切情况都能化归到它或 2^λ。

Python 通道（`17_cardinal_power.py`）把这个三分律做成了**符号
计算器**，全部分支窗口化：

```python
if exp[0] == 'aleph' and base[0] == 'aleph' and exp[1] <= base[1]:
    return kpow(FIN(2), exp)     # κ ≤ λ: κ^λ = 2^λ（递归算出 C 记号）
return ('gimel', base, exp)      # 吉莫尔函数
```

审计包括 2^ℵ₀ = c、ℵ₀³ = ℵ₀、ℵ₁^ℵ₁（= 2^ℵ₁ 的窗口形态）、
GCH 三分支（5.5.11）的预演、beth 函数（习题 5.6.31）。

## 140.2 连续统函数：König 之外的灯

> **定理（书 5.5.7）**　κ 极限：(1) 2^κ = (2^{<κ})^{cf κ}；
> (2) κ 强极限时 2^κ = κ^{cf κ} = ℷ(κ)。

> **推论（5.5.10）**——连续统函数的吉莫尔表示：
> - κ 后继：2^κ = ℷ(κ)
> - κ 极限且 cf 下有不动点：2^κ = 2^{μ₀} ⊙ ℷ(κ)
> - κ 极限无不动点：2^κ = ℷ(2^{<κ})

**奇异基数假设 SCH**（书 5.5.12）：2^{cf κ} < κ ⟹ κ^{cf κ} =
κ⁺——强极限奇异处 2^κ 取最小可能值 κ⁺。SCH 是幂函数黑暗森林
中最著名的路标（Solovay 证明它与某大基数假设等价性的否定——
现代集合论的深水区，本教程如实标注边界）。

## 140.3 GCH 下的完全计算

> **定理（书 5.5.11）**　GCH 下：κ^λ = 2^λ（κ ≤ λ）；
> κ⁺（cf κ ≤ λ < κ）；κ（λ < cf κ）。

GCH 把吉莫尔函数全部坍缩（ℷ(κ) = κ⁺），幂函数从此完全可算。
第 145 章（L 中的 GCH）将给出"假设一致性"的证明，第 146 章
（力迫）给出"否定也一致"。

## 140.5 代码精选与细节

Lean 的"两级火箭"（cantor 给出无穷 → 吸收律开动）值得整段：

```lean
example (κ : Cardinal) (hκ : Cardinal.aleph0 ≤ κ) :
    (2 : Cardinal) ^ κ * (2 : Cardinal) ^ κ = (2 : Cardinal) ^ κ := by
  have h2 : Cardinal.aleph0 ≤ (2 : Cardinal) ^ κ :=
    le_trans hκ (le_of_lt (Cardinal.cantor κ))
  exact Cardinal.mul_eq_self h2
```

第一级 le_trans 把"κ 无穷"升级为"2^κ 无穷"（Cantor：κ < 2^κ）；
第二级把 mul_eq_self 用在 2^κ 上。**证明的形状即数学的结构**——
"2^κ·2^κ = 2^κ"本质是"2^κ 无穷 + 无穷吸收律"，两级火箭把它拆
得一目了然。

Prolog 的函数集合全枚举是 |A^B| = |A|^|B| 的最朴素机器化——
funcs(B, A, F) 回溯生成 B 到 A 的全部函数（值元组），length 计
数与算术幂逐对核对。有限窗口内 A≤4、B≤3（4³=64 个函数）在毫
秒级完成；窗口外由 Lean 的幂恒等式接棒。

细节三则：① (κ^μ)^ν = κ^{ν·μ} 用了 rw [← power_mul] + mul_comm
的换向——注意 Cardinal 乘法交换律是**定理**（第 138 章 max 吸收
的推论），非公理；② GCH 分支的实现顺序有讲究：先查 κ ≤ λ（命
题 5.2.10 最先适用），再查 κ > λ 时的 cf 分岔；③ beth_1 的记号
在本计算器中是 ('pow', 2, ℵ₀) 而非 'c'——两者的等同（= c）是
一条定理（8 章），计算器诚实分层。

## 本章要点

1. 三分律 5.5.4 是 ZFC 对 κ^λ 的完全分类；未知核 = 吉莫尔
   ℷ(κ) = κ^{cf κ}。
2. cf κ > λ 时 κ^λ = κ（正则性吃掉小指数）；cf κ ≤ λ 时归入
   ℷ。
3. 连续统函数：后继处 2^κ = ℷ(κ)；强极限奇异处 2^κ = ℷ(κ)；
   SCH 是关于 ℷ 在奇异处的最小性假设。
4. GCH ⟹ 幂函数完全可算（三分支 5.5.11）；GCH 本身的独立性
   是第 145-146 章的主题。
5. 机器面：Lean 的 cantor→absorb 火箭、Python 的三分律计算器、
   Prolog 的函数集合枚举。
