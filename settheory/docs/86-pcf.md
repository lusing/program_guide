# 86 · 模型分析应用：谢旯 pcf 理论

上一章把传递模型、初等子模型、斯科伦闭包和镜像原理装进了工具箱。这一章把同一套工具用到基数算术上：当 ℵ_ω 是强极限时，2^{ℵ_ω} 是一个严格小于 ℵ_{ω₄} 的后继基数。这就是谢旯（Shelah）的共尾可能性理论给出的经典不等式，也是冯琦第二卷 §1.3 的终点。

第一卷已经陈述过这个结论（定理 I.2.40），但证明需要超积、可定义性和初等链，留到了第二卷。本章把证明完整写出来。机器通道只能做有限样品：一段短标尺、主超滤子的梯度、生成元的传递性。完整的 ℵ_{ω₄} 上界超出当前 mathlib 与 Isabelle/ZF 的库覆盖。

## 86.1 从序数函数到真共尾度

嘎尔文–海纳定理的证明已经表明：无穷基数算术里，真正干活的是定义在某个指标集 A 上的序数函数，以及它们模某个理想之后的偏序。谢旯的 pcf 理论从这里起步。

**定义 1.45（模理想比较）。** 设 A 是无穷集合，I 是 A 上的理想。对 A 上的序数函数 f、g，规定

- f =_I g 当且仅当 {a ∈ A | f(a) ≠ g(a)} ∈ I；
- f ≤_I g 当且仅当 {a ∈ A | f(a) > g(a)} ∈ I；
- f <_I g 当且仅当 {a ∈ A | f(a) ≥ g(a)} ∈ I。

若 F 是滤子、I 是它的对偶理想，则 f ≤_F g 就是 f ≤_I g。关系 ≤_I、<I 传递；=_I 是等价关系。当 A 是不可数正则基数、I 是非荟萃理想时，这回到第一卷定义 I.2.29。

把这些关系限制在乘积空间

Π(A, K) = ∏_{a∈A} K(a)

上（K 是正序数函数），=_I 给出商空间上的偏序。

**定义 1.46（上界与最小上界）。** g 是函数族 F 的上界，当且仅当每个 f ∈ F 都满足 f ≤_I g。g 是最小上界，当且仅当它是上界，并且对任意上界 h 都有 g ≤_I h。

**定义 1.47（共尾度与梯度）。** X ⊆ Π(A, K) 共尾，当且仅当每个 f ∈ Π(A, K) 都有某个 g ∈ X 满足 f ≤_I g。共尾度

gwd(Π(A, K)) = min{|X| | X ⊆ Π(A, K) 且 X 共尾}

总存在。梯度（真共尾度）cf(Π(A, K)) 是使得存在长度为 λ 的线性共尾子集的最小正则基数 λ——它可能不存在。存在梯度，当且仅当存在下面定义的标尺。

**定义 1.48（标尺序列）。** H : λ → Π(A, K) 是长度为 λ 的标尺，当且仅当

1. α < β < λ 推出 H(α) <_I H(β)；
2. rng(H) 在 Π(A, K) 中共尾。

有一根长度为正则基数 λ 的标尺，乘积就有梯度 λ。

## 86.2 可数共尾强极限上的标尺

**定理 1.31（Shelah）。** 设 κ 是共尾度为 ω 的强极限基数。则存在单调递增、收敛于 κ 的正则基数序列 ⟨λ_n | n < ω⟩，使得乘积 Π(ω, ⟨λ_n⟩) 在有限子集理想 [ω]^{<ω} 下的真共尾度为 κ⁺。

**证明概要。** 令 I = [ω]^{<ω}。从任意收敛于 κ 的不可数正则序列 ⟨κ_n⟩ 出发。

断言一：势 ≤ κ 的任意 F ⊆ Π(ω, ⟨κ_n⟩) 都有上界。把 F 写成递增并 ∪ F_n，|F_n| ≤ κ_n，再取

g(0) = ω， g(n+1) = κ_n + sup{f(n+1)+1 | f ∈ F_n} < κ_{n+1}。

对 α < κ⁺ 递归，得到长度 κ⁺ 的 <_I-递增序列 F = ⟨f_α | α < κ⁺⟩。

断言二：F 有 ≤_I-极小的 <_I-上界 g。用递降序列逼近：若当前上界不是极小，就换一个严格更小的上界。极限步用 Erdős–Rado 划分（定理 I.2.53）：若递降链长度 ≥ (2^ω)⁺，则某坐标上出现无穷严格递降的序数，矛盾。故链在某个后继处停下，得到极小上界。

断言三：任意 f <_I g 都被某个 f_α 压住。否则把 {n | f(n) > f_α(n)} 粘在一起，会造出一个严格小于 g 的上界，与极小性矛盾。

把 g(n) 微调成极限序数，取无界闭子集 Y_n ⊆ g(n) 并把 F 投影到 ∏ Y_{κ_n}，再同构搬回 ∏ λ_n，就得到长度 κ⁺ 的标尺。□

这个定理是纯组合的。下一节的恰好上界引理，才真正把初等子模型拉进来。

## 86.3 恰好上界与共尾三选一

**定义 1.49。** 在偏序 (P, <) 中，p 是子集 S 的恰好上界，当且仅当 S 在 {q ∈ P | q < p} 中共尾。

**引理 1.22。** 设 A 无穷，I 是 A 上的理想，λ > 2^{|A|} 正则。则任意 <_I-递增、长度 λ 的序数函数序列都有恰好上界。

**证明。** 设 F = ⟨f_α | α < λ⟩。取足够大的正则 θ，使 F、I、𝒫(A) ∈ H_θ。用斯科伦函数族造初等子模型 M ≺ (H_θ, ∈)，满足

|M| = 2^{|A|}， ^{|A|}M ⊆ M， F, I, 𝒫(A) ∈ M。

对每个 α < λ，令

g_α(a) = min(β ∈ M ∩ Ord | β ≥ f_α(a))。

因 ^{|A|}M ⊆ M，每个 g_α ∈ M。|M| < λ，故某个 f ∈ M 被 λ 多个 α 取成 g_α = f。这个 f 是 F 的上界。

它是恰好上界：若 h ∈ M 且 h <_I f，取 α 使 g_α = f，令 B = {a | h(a) < g_α(a)}。对 a ∈ B，由 g_α 的最小性得 h(a) < f_α(a)，故 h <_I f_α。由元素性，同一结论对所有 h <_I f 成立。□

**定义 1.50。** 相对 X ∈ I⁺，把理想换成 I ↾ X（由 I ∪ {A \ X} 生成），得到相对比较 f ≤_{I↾X} g 等。F 在上界 g 之下有界，指存在上界 h <_I g；共尾，指 F 在 ∏ g(a) 中共尾。

**推论 1.7（共尾三选一）。** 在引理 1.22 的设定下，若 g 是 F 的上界，则三者居一：

(a) F 在 g 下有界；
(b) F 在 g 下共尾；
(c) 存在 X ∪ Y = A，X, Y ∈ I⁺，使 F 相对 X 有界、相对 Y 共尾。

证明：取恰好上界 f，令 X = {a | f(a) < g(a)}，Y = A \ X。□

**定义 1.51（λ-共顶）。** ∏_{a∈A} α_a 在 ≤_I 下是 λ-共顶的，当且仅当每个势 < λ 的子集都有共同上界。

有长度 λ 的标尺，则乘积有真共尾度 λ，且是 λ-共顶的；常值函数 ⟨α_a⟩ 既是最小上界也是恰好上界。

**推论 1.8（共顶三选一）。** 若 ∏ α_a 是 λ-共顶但不是 λ⁺-共顶，则三者居一：它有 λ-标尺；或存在分割 X ∪ Y = A，使相对 X 有 λ-标尺、相对 Y 是 λ⁺-共顶。

证明思路：取势 λ 且无共同上界的集合 S，用共顶性递归造长度 λ 的递增序列压住 S；再把所有可能的标尺粘起来，用共尾三选一切开。□

**定义 1.52（μ-快速增长）。** F = ⟨f_α | α < λ⟩ 是 μ-快速增长的，当且仅当每个共尾度 μ、小于 λ 的极限序数 β，都有无界闭 C ⊆ β，使扫描函数

scn_α(a) = sup{f_ξ(a) | ξ ∈ C ∩ α}

满足 scn_α <_I f_α（α ∈ C）。

**引理 1.23。** 若 F 是 μ-快速增长，且每个 a 配一个 |S_a| < μ 的集合 S_a ⊆ Ord，则存在 α < λ，使得凡 h ∈ ∏ S_a 满足 f_α <_I h 的，都是 F 的上界。

**推论 1.9。** 快速增长序列的最小上界 f 满足 {a | cf(f(a)) < μ} ∈ I。

## 86.4 非荟萃理想上的标尺

**定理 1.32（Shelah）。** 设 κ 不可数正则，I 是 κ 上的非荟萃理想。设 ⟨η_ξ | ξ < κ⟩ 连续递增收敛于 η，且 2^κ < ℵ_η。则偏序 ∏_{ξ<κ} ℵ_{η_ξ+1} 在 ≤_I 下的梯度为 ℵ_{η+1}。

**证明概要。** 令 λ = ℵ_{η+1}。先验证乘积是 λ-共顶：势 < λ 的函数族按 κ 切成递增并，逐点取上确界，因 ℵ_{η_ξ} 的共尾度与势的关系，上确界仍落在 ℵ_{η_ξ+1} 里。

假设没有 λ-标尺。由共顶三选一，某个荟萃集 S 上乘积是 λ⁺-共顶。在 S 上造对一切不可数正则 μ < λ 都快速增长的序列 F。引理 1.22 给出恰好上界 g。若 {ξ ∈ S | g(ξ) < ℵ_{η_ξ+1}} 荟萃，则某 μ 使 {ξ | cf(g(ξ)) < ℵ_μ} 荟萃，与推论 1.9 矛盾。故 g 在荟萃多处等于 ℵ_{η_ξ+1}，F 成为标尺——与 S 的选取矛盾。□

可数共尾用有限理想，不可数共尾用非荟萃理想：两种标尺定理，覆盖了强极限奇异基数的「平移后继乘积」。

## 86.5 共尾可能性

从乘积转向超积。A 从现在起是正则基数的无穷集合。选择函数全体

Π A = {f : A → ∪A | ∀a ∈ A (f(a) ∈ a)}。

超滤子 U 给出线性序

f <_U g ⟺ {a ∈ A | f(a) < g(a)} ∈ U，

其梯度

cf(U) = min{λ | 存在 λ → ΠA 的无界保序映射}

必为正则基数。

**定义 1.53（共尾可能性）。**

pcf(A) = {cf(U) | U 是 A 上的超滤子}。

**事实。**

1. A ⊆ pcf(A)：主超滤子 U_a = {X ⊆ A | a ∈ X} 满足 cf(U_a) = a。
2. A ⊆ B 推出 pcf(A) ⊆ pcf(B)。
3. pcf(A ∪ B) = pcf(A) ∪ pcf(B)。

证明 (1)：ΠA / U_a 同构于序数 a，梯度即 a。(2)(3)：超滤子的限制与提升给出超积同构。□

机器通道里，主超滤子的事实可以直接看见。取玩具正则集合 A = {3, 5, 7}：

```python
A = [3, 5, 7]

def principal(a, X):
    return a in X

def reduced_product_cf(ultrafilter_sets):
    for a in A:
        if all(a in X for X in ultrafilter_sets):
            return a
    return None

assert principal(3, [3])
assert reduced_product_cf([[3], [3, 5]]) == 3
```

包含 3 的集合族对应主超滤子 U_3，梯度就是 3。Lean 里同一句话是

```lean
def principal (a : Nat) (X : List Nat) : Prop := a ∈ X

theorem principal_contains_singleton (a : Nat) (_ha : a ∈ A) :
    principal a [a] := by
  simp [principal]
```

**引理 1.24（幂等律）。** 若 |pcf(A)| < min(A)，则 pcf(pcf(A)) = pcf(A)。

**证明。** 令 B = pcf(A)。对每个 λ ∈ B 固定超滤子 D_λ 与共尾序列 ⟨f^λ_α⟩。设 μ ∈ pcf(B)，D 实现 cf(D) = μ，⟨g_α⟩ 共尾于 ΠB / D。定义

E = {X ⊆ A | {λ ∈ B | X ∈ D_λ} ∈ D}，

以及

h_α(a) = sup{f^λ_{g_α(λ)}(a) | λ ∈ B}。

因 |B| < min(A)，h_α(a) ∈ a。验证 ⟨h_α⟩ 在 ΠA / E 中共尾，故 cf(E) = μ，μ ∈ pcf(A)。□

称正则基数的无穷集合 X 是**区间**，当且仅当凡正则 λ 满足 min(X) ≤ λ < sup(X) 都有 λ ∈ X。

**引理 1.25。** 若 A 是无穷区间且 min(A) = (2^{|A|})⁺，则 pcf(A) 也是区间。

思路：取 U 与正则 λ 满足 min(A) ≤ λ < cf(U)。对共尾序列用引理 1.22 取最小上界 g，令 h(a) = cf(g(a))。在 ∏ h(a) / U 上得到长度 λ 的共尾序列，再把 h 拉回 A（必要时缩小）定义

D = {X ⊆ A | h^{-1}[X] ∈ U}，

则 cf(D) = λ。□

**推论 1.10。** 若 ℵ_ω 强极限，A = {ℵ_n | n < ω}，则 pcf(A) 是区间，且

sup(pcf(A)) < ℵ_{(2^{ℵ₀})⁺}。

把 A 放大到从 (2^{ℵ₀})⁺ 起的正则区间，用引理 1.25，再截回。

## 86.6 最大元等于幂

**定理 1.33（Shelah）。** 若 ℵ_ω 是强极限，A = {ℵ_n | n < ω}，则 pcf(A) 有最大元，且

max(pcf(A)) = 2^{ℵ_ω}。

因此 2^{ℵ_ω} 必是后继基数。

**证明。** 令 λ = sup(pcf(A))。由柯尼希定理 cf(2^{ℵ_ω}) > ℵ_ω，由推论 1.10 有 λ < ℵ_{(2^{ℵ₀})⁺}，故 2^{ℵ_ω} 是后继；又 pcf(A) 是区间，故只需证 2^{ℵ_ω} = λ。

四个断言：

断言一。对 2^{ℵ_k} ≤ α ≤ λ，存在 K_α ⊆ [α]^{ℵ_k}，|K_α| = λ，且每个 Z ∈ [α]^{ℵ_k} 都有 X ∈ K_α、X ⊆ Z。归纳构造：基数处取并，非基数处经双射搬运。

断言二。存在 F ⊆ ∏_n ℵ_n，|F| = λ，且 F 在点态 ≤ 下共尾于整个乘积。对每个超滤子 D 取共尾序列，再对有限指标组与有限序数组取逐点 max；势的计算用 2^{2^{ℵ₀}} < ℵ_ω < λ。若某 g 压不住，有限交性质延拓成超滤子 U，与共尾性矛盾。

断言三、四。固定断言二的 F。对 a ∈ [ℵ_ω]^{ℵ_k}，用斯科伦闭包造初等链 ⟨M^a_α | α < ω_k⟩，特征函数 x^a(n) = sup(M^a ∩ ℵ_n) 被 F 中的函数压住。证明 x^a = x^b 推出 M^a ∩ ℵ_ω = M^b ∩ ℵ_ω，以及 {x^a} 的势 ≤ λ。于是

|[ℵ_ω]^{ℵ_k}| ≤ λ · ℵ_k = λ，

令 k 变化得 2^{ℵ_ω} = λ。□

## 86.7 生成元定理

**定理 1.34（Shelah，pcf 基本定理）。** 设 A 是正则基数的无穷集合，2^{|A|} < min(A)。则存在生成元序列 ⟨B_λ ⊆ A | λ ∈ pcf(A)⟩，满足：

1. λ = max(pcf(B_λ))；
2. λ ∉ pcf(A \ B_λ)（即 cf(D) = λ 推出 B_λ ∈ D）；
3. cf(D) = min{λ ∈ pcf(A) | B_λ ∈ D}；
4. {B_ν | ν ∈ pcf(A) ∩ λ} 生成 A 上的真理想 J_<λ；
5. (Π B_λ, <_{J_<λ}) 有长度 λ 的标尺。

**证明概要。** 对基数 κ ≤ sup(pcf(A)) 递归构造理想 J_κ：

- κ ≤ min(A) 时 J_κ = {∅}；
- 极限处取并；
- 后继 κ = δ⁺：若 δ ∉ pcf(A) 则 J_κ = J_δ；若 δ ∈ pcf(A) 则用共顶三选一取出 B_δ ∈ J_δ⁺，令 J_κ = J_δ[B_δ]。

验证：若 κ ∉ pcf(A) 则 J_κ 是 κ⁺-共顶（否则三选一造出 κ-标尺，延拓成超滤子得 κ ∈ pcf(A)）。若 κ ∈ pcf(A) 且非最大，则 J_κ 既非 κ⁺-共顶也无 κ-标尺，三选一给出 B_κ。最大元处令 B_κ = A。性质 (1)–(5) 由构造直接读出。□

玩具生成元：对 A = {3, 5, 7}，令 B_λ = {x ∈ A | x ≤ λ}。

```python
def generator(lam):
    return [x for x in A if x <= lam]

assert generator(3) == [3]
assert generator(5) == [3, 5]
assert generator(7) == [3, 5, 7]
```

Coq 证明传递性（引理 1.27 的有限影子）：

```coq
Lemma generator_transitive :
  forall mu lam, In mu (generator lam) ->
    forall x, In x (generator mu) -> In x (generator lam).
Proof.
  intros mu lam Hmu x Hx.
  apply generator_mem in Hmu.
  apply generator_mem in Hx.
  apply generator_mem.
  destruct Hmu as [_ HmuLe].
  destruct Hx as [HinX HxLe].
  split; [exact HinX|]. lia.
Qed.
```

Isabelle 里同一传递性：

```isabelle
lemma generator_transitive:
  assumes "mu \<in> generator(ell)" and "x \<in> generator(mu)"
  shows "x \<in> generator(ell)"
proof -
  from assms have "mu \<in> A" "mu \<le> ell" "x \<in> A" "x \<le> mu"
    by (simp_all add: generator_mem)
  from \<open>x \<le> mu\<close> \<open>mu \<le> ell\<close> have "x \<le> ell" by (rule le_trans)
  with \<open>x \<in> A\<close> show ?thesis by (simp add: generator_mem)
qed
```
（参数名用 `ell`：ZF 里 `lam` 是集合论 λ-抽象的常量。）

**推论 1.11。** |pcf(A)| ≤ 2^{|A|}（生成元是 A 的子集）。

**推论 1.12。** ℵ_ω 强极限 ⇒ 2^{ℵ_ω} < ℵ_{(2^{ℵ₀})⁺}。

由 1.11、1.10、1.33：pcf(A) 是区间、势 ≤ 2^{ℵ₀}、最大元 = 2^{ℵ_ω}。

**推论 1.13。** pcf(A) 有最大元。否则 {A \ B_λ} 有限交，延拓成超滤子 D，得 B_{cf(D)} ∈ D，矛盾。

**推论 1.14（紧致性）。** 对任意 X ⊆ A，存在 pcf(X) 的有限子集 {ν_1, …, ν_m} 使 X ⊆ B_{ν_1} ∪ ⋯ ∪ B_{ν_m}。

**推论 1.15。** 设 κ 不可数正则，η 共尾度 κ 且 2^κ < ℵ_η。则存在无界闭 C ⊆ η，使

max(pcf({ℵ_{α+1} | α ∈ C})) = ℵ_{η+1}，

且 ∏_{α∈C} ℵ_{α+1} 在有界理想下真共尾度为 ℵ_{η+1}。这是定理 1.32 的生成元加强版。

**引理 1.26。** J_κ = {X ⊆ A | ∀D ∈ βX (cf(D) < κ)}，故理想与生成元的具体选取无关。

**推论 1.16。** 若 B △ B_λ ∈ J_<λ，则 B 同样满足生成元的 (1)(2)。

## 86.8 传递生成元与局部化

**引理 1.27（传递生成元）。** 设 (2^{|A|})⁺ < min(A) 且 A = pcf(A)。则存在生成元序列满足

μ ∈ B_λ ⇒ B_μ ⊆ B_λ。

**证明概要。** 从任意生成元出发，在每个 B_λ 上取 <_{J}-共尾序列，并对 cf > 2^{|A|} 的位置取恰好上界。造长度 (2^{|A|})⁺ 的初等链，用模型里的斯科伦闭包重定义生成元，使隶属关系沿链传递。□

**引理 1.28（局部化）。** 设 2^{|pcf(A)|} < min(A)，X ⊆ pcf(A)，λ ∈ pcf(X)。则存在 W ⊆ X、|W| ≤ |A|，使 λ ∈ pcf(W)。

**证明。** 由 1.34，取 Y ⊆ X 使 λ = max(pcf(Y))。令 Ā = pcf(A)，用幂等律与传递生成元。对 ν ∈ Y 令 B_ν^A = B_ν ∩ A，E = ∪_{ν∈Y} B_ν^A。则 λ ∈ pcf(E)。取 W ⊆ Y、|W| ≤ |A| 覆盖 E。若 λ ∉ pcf(W)，紧致性给出有限覆盖，传递性把 E 推进严格小于 λ 的生成元并，与 λ ∈ pcf(E) 矛盾。□

## 86.9 谢旯不等式

**定理 1.35（Shelah）。** 若 ℵ_ω 是强极限基数，则 2^{ℵ_ω} < ℵ_{ω₄}。

**证明。** 令 A = {ℵ_n | n < ω}。由定理 1.33 与推论 1.12，

max(pcf(A)) = 2^{ℵ_ω} = ℵ_{γ+1} < ℵ_{(2^{ℵ₀})⁺}。

只需证 γ < ω₄。

事实一。在 [ω₄] 上存在序数函数 F，满足：

(a) X ⊆ Y ⇒ F(X) ≤ F(Y)；
(b) 若 η < ω₄、cf(η) > ω，则存在无界闭 C ⊆ η 使 η = F(C)；
(c) 若 X ⊆ ω₄ 序型为 ω₁，则存在可数 Y ⊆ X 使 F(Y) ≥ sup(X)。

构造：对 X ⊆ ω₄，令 E(X) = {ℵ_{α+1} | α ∈ X}（必要时丢掉有限前段使 2^{|E|} < min(E)）。令

F(X) 满足 max(pcf(E(X))) = ℵ_{F(X)+1}。

单调性显然。性质 (b) 来自推论 1.15。性质 (c) 来自局部化引理 1.28：序型 ω₁ 的集合有可数子集把最大值抬到上确界。

事实二（无界闭集猜测）。设 κ ≥ ℵ₃ 正则，ω₁ ≤ λ < λ⁺ < κ，E = {α < κ | cf(α) = λ}。则存在 ⟨c_α | α ∈ E⟩，每个 c_α ⊆ α 无界闭，且对任意无界闭 C ⊆ κ，集合 {α ∈ E | c_α ⊆ C} 在 κ 上荟萃。

证明用反证：对 ν < λ⁺ 递归造无界闭 C_ν 与猜测序列，使「猜中 C_ν」的集合非荟萃。取交 C = ∩_{ν<λ⁺} C_ν，在荟萃多处稳定化，与某一步的选择矛盾。

断言：γ < ω₄。假设 γ ≥ ω₄。令 E = {α < ω₄ | cf(α) = ω₁}，取事实二的猜测序列 ⟨c_α⟩。造长度 ω₃ 的初等链 ⟨M_α | α < ω₃⟩，|M_α| = ℵ₃，含 F 与全部 c_α，且 ⟨M_β | β ≤ α⟩ ∈ M_{α+1}。令 η(α) = M_α ∩ ω₄，得连续严格递增 η : ω₃ → ω₄。

由事实一 (b)，存在无界闭 C ⊆ ω₃ 使 F(η[C]) = sup(η[ω₃])。取 α ∈ E、c_α ⊆ C。由事实一 (c)，存在 β < α 使

F(η[c_α ∩ β]) ≥ η(α)。

令 X = η[c_α ∩ β]。则 X ∈ M_α（因 c_α、η↾β ∈ M_α），且 F(X) ≤ F(η[C]) < ω₄。但 F ∈ M_α，故 F(X) ∈ M_α，从而 F(X) < η(α)，矛盾。□

ω₄ 这个具体指数，来自「ω₃ 长的初等链 + ω₁-共尾的猜测序列」这一组合：链的长度要用 ℵ₃ 控制模型大小，猜测要用 ω₁，两者叠在 ω₄ 下面刚好卡住。

## 86.10 标尺的有限样品

完整标尺定理的机器版本，缩成三段常值函数：

```python
scale0 = {3: 0, 5: 0, 7: 0}
scale1 = {3: 1, 5: 1, 7: 1}
scale2 = {3: 2, 5: 2, 7: 2}

def le_pw(f, g):
    return all(f[n] <= g[n] for n in A)

def lt_pw(f, g):
    return le_pw(f, g) and any(f[n] < g[n] for n in A)

assert lt_pw(scale0, scale1)
assert lt_pw(scale1, scale2)
```

Lean：

```lean
theorem scale_increasing_01 : ltPointwise scale0 scale1 := by
  refine ⟨?_, ⟨3, by simp [A], by simp [scale0, scale1]⟩⟩
  intro n hn
  simp [A] at hn
  rcases hn with (rfl | rfl | rfl) <;> simp [scale0, scale1]
```

Agda：

```agda
scale-increasing-01 : le-pw scale0 scale1 × (scale0 3 ≤ scale1 3)
scale-increasing-01 = (λ _ → z≤n) , z≤n

scale-increasing-12 : le-pw scale1 scale2 × (scale1 3 ≤ scale2 3)
scale-increasing-12 = (λ _ → s≤s z≤n) , s≤s z≤n
```

Prolog 把同一比较写成查询：

```prolog
lt_pw(I, J) :-
    le_pw(I, J),
    member_a(N),
    scale(I, N, FI), scale(J, N, FJ), FI < FJ.
```

三段函数严格递增且共尾于「高度 2 的常值乘积」——这是定义 1.48 在有限世界里的全部内容。

## 86.12 这一章留下了什么

模理想的序数函数偏序有共尾度，梯度则需要标尺。可数共尾强极限用有限理想造 κ⁺ 标尺；不可数共尾用非荟萃理想。恰好上界引理把初等子模型嵌进组合论证，导出共尾/共顶三选一与快速增长的梯度控制。

超滤子的梯度全体组成 pcf(A)。它包含 A、对并封闭、在势假设下幂等，并在区间假设下无洞。对 A = {ℵ_n}，最大元恰好是 2^{ℵ_ω}。生成元序列把每个 λ ∈ pcf(A) 钉在一个子集 B_λ 上，给出势界、最大元、紧致性与俱乐部形式的标尺。传递生成元加上局部化，把 pcf 计算缩到小集合上。最后，用 ω₄ 上的单调函数 F 与无界闭猜测，初等链给出矛盾，得到 2^{ℵ_ω} < ℵ_{ω₄}。
