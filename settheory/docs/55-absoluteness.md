# 55 · 绝对性补篇：H_χ、Lévy 绝对性、反射与 Shoenfield

> 力迫定理吃掉的最后一个假设：ZFC⁺（存在可数传递模型）。本篇
> 讲怎么把它去掉——**Lévy 层级 + 反射定理**给出"任何证明都
> 能在够小的 H_χ 里照抄"；Shoenfield 绝对性再给 Σ₁² 一层保险。
> 这是 Viale 附录 A+B 的完整提炼，也是整个第八篇的闭环。
>
> 本章覆盖 Viale 附录 A、B 全部。

## 55.1 问题的形状

53-54 章用了 "M 是可数传递 ZFC 模型"——Gödel 不完全性说
ZFC 不能证它（否则 ZFC 证自己的 consistency）。两条出路：
1. **假设减弱**：ZFC + ∃不可达 ⟹ ZFC⁺（Viale A.5.1 的
   下行 Löwenheim-Skolem + Mostowski 坍缩流水线）；
2. **假设消除**：反射定理把任意 ZFC 有限片段反射到某个
   V_θ / H_χ 上——"每条形式证明只用到有限条公理"。
本篇把两条路都铺好。

## 55.2 Σ₁ 性质与模型论绝对性

**Σ₁ 性质**（Viale A.1）：形如 ∃x ψ(x,ȳ) 的性质，ψ 无未绑定
量词（Δ₀）。**核心事实**：
- **Σ₁ 在子结构下保持**（方向 ↑）：M ⊆ N、φ Σ₁、参数在 M：
  M ⊨ φ ⟹ N ⊨ φ（见证留在 M 里）；
- **"Σ₁ on Σ₁ 仍是 Σ₁"**：复合封闭；
- **Δ₀ 的传递绝对性**：M ⊆_trans N ⟹ M ⊨ Δ₀ ⟺ N ⊨ Δ₀
  （量词有界，见证跑不出传递闭包）。

**超穷递归保绝对性**（Viale A.1 末）：由绝对谓词出发的超穷
递归定义的类（rank、trcl、V_α、L_α、Mostowski 坍缩、Tarski
满足谓词 Sat）都是 Δ₁-可定义——**53 章名字身份的 Δ₁ 性**
（Fact 7.1.8）正是这条一般原理的实例。

## 55.3 集合论的"对的语言"

**问题**：∈ 语言里 "x = {y : φ}" 是 Δ₀ 不可能的（分离要跑
整个 x 的元素）。
**解（Viale A.2）**：展开语言 ℒ_∈* := ∈ ∪ {P_φ : φ ∈ Δ₀}
——每个 Δ₀ 公式一个谓词符号。在ℒ_∈* 里：
- **每个"简单集合论概念"都是原子的**（有序对、并、定义域、
  函数性、良基……全部 Δ₀）；
- **Lévy 复杂度 = ℒ_∈* 的通常量词层数**——分离后的分层与
  直觉对齐；
- **传递模型在ℒ_∈* 上的 Δ₀-理论相同**（原子按定义还原）。

## 55.4 H_χ：正确大小的容器

**定义**（Viale A.5）H_χ := {x : |trcl(x)| < χ}。
H_{ℵ₀} = HF；H_{ℵ₁} ⊇ 可数集全体。

**为什么 H_χ 够用**：ZFC 的任何**形式证明** π 只涉及有限
多条公理；其中幂集/收集用到的复杂度被 χ > 2^{|参数|} 吸收。
**反射定理**（下方）给 H_χ ⊨ "π 的一切公理"——证明照抄。

**Lévy 反射定理**（Viale B.2）：对每个公式 φ 存在不可数
序数集 C（club）使每个 χ ∈ C：H_χ 反射 φ——
H_χ ⊨ φ(a) ⟺ V ⊨ φ(a)（参数 a ∈ H_χ）。

**Lévy 绝对性**（Viale B.1）：Σ₁ 公式对 H_θ（θ 任意不可数）
绝对：H_θ ⊨ σ(a) ⟺ V ⊨ σ(a)。
——"存在性断言只需正确大小的容器"。

**Shoenfield 绝对性**（Viale B.3）：**Σ₁²**（实数上的 Σ₁）
公式对任何包含 ω₁ 的传递模型绝对——φ(a) 在 L 中真 ⟺ 在
V 中真。证明走 **树表征**（分析集 = 良基树的投影）：Σ₁²
为真 ⟺ 对应树良基 ⟺ 在 L 中树良基。∎
CH 本身是 Σ₁² 的前缀形态（∃g: ω₁→2^ω 双射 = Σ₂ 实际上）——
**Shoenfield 适用范围之外**，所以 CH 的独立性需要力迫而非
绝对性论证：力迫篇的正确历史注脚。

## 55.5 构造性 L 的最小回声
