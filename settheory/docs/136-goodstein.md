# 136 · 古德斯坦定理

> 九头蛇（Hydra）游戏：无论英雄怎么砍，终将砍光所有头——但这个
> 事实的证明躲不开超穷序数。——图 4.2 的传说（本章的姊妹问题）

本章覆盖书 4.5 节（PDF 91-94 页）：超穷序数算术在**数论**中的
应用——一个只涉及自然数的定理，证明却必须爬到 ε₀ 附近；并且
（Kirby-Paris 1982）它在皮亚诺算术中**不可证**。

## 136.1 超底展开与换底函数

每个自然数有唯一的**超底展开**（superbase expansion）：反复把
指数也写成该底的展开。例如（书 4.5 节）：

    27 = 2⁴ + 2³ + 2 + 1 = 2^(2²) + 2^(2+1) + 2 + 1。

> **定义（书 4.5.1）**　Sₙ（n ≥ 2）：把 m 的 n 进超底展开里的
> 每个底 n 换成 n+1。递归形态：
> m < n 时 Sₙ(m) = m；m = k·nᵗ + b（k<n, b<n, t≥1）时
> Sₙ(m) = k·(n+1)^{Sₙ(t)} + Sₙ(b)。

书例 4.5.2 是黄金审计锚点：**S₂(89) = 3^{3³}+3^{27}+3³+1 =
213516729579718**。练习 4.5.3：S₃(4) = 5（4 = 3+1 → 4+1 = 5）。

> **定义（书 4.5.4）**　fₙ：把 m 的 n 进超底展开里的底换成 **ω**
> ——一个自然数到序数的赋值。fₙ(m) < ω^ω^…（嵌套），fₙ 严格增
> （习题 4.7.23）。

> **引理（书 4.5.5）**　(1) fₙ 严格增；(2) **f_{n+1}(Sₙ(m)) =
> fₙ(m)**——换底不换序数值！这是整个证明的枢纽：底从 n 到 n+1
> 的增长，在序数世界里**原地不动**（ω 不在乎底是谁）。

## 136.2 古德斯坦序列与定理

> **定义（书 4.5.6）**　g₁(m) = m；g_{n+1}(m) = S_{n+1}(gₙ(m)) − 1
> （若非零），否则 0。

序列先疯狂增长。书载 m = 13 的表（79-80 页）：

    g₁=13, 108, 1279, 16092, 280711, 5765998, 134219479,
    3486786855, 100000003325, …

**机器自纠**：本教程双通道复算发现，书载第 7 项 134219591 与
书载第 8 项 3486786855 **不自洽**——后者只能从前项 134219479
推出（S₇(5765998) = 8⁹ + 1752，因为指数 8 = 7+1 也要换底到
9）。机器链从 134219479 出发精确复现书载 g₈、g₉，故第 7 项应
为 134219479（OCR/原书笔误，坑账 #49）。

> **古德斯坦定理（书 4.5.7）**　对任意 m，存在 n 使 gₙ(m) = 0。

**证明**是三行的魔术：考察序数序列 Fₙ = f_{n+1}(gₙ(m))。若
g_{n+1} > 0，则

    F_{n+1} = f_{n+2}(S_{n+1}(gₙ) − 1) < f_{n+2}(S_{n+1}(gₙ))    （引理 (1)：减 1 严格降）
              = f_{n+1}(gₙ) = Fₙ                                   （引理 (2)：换底不动）

——Fₙ 是序数的**严格下降链**。而序数没有无穷下降链（第 134 章
的 ∈-良序），故某步 gₙ(m) = 0。∎ **每个自然数里的爆炸，在序数
里都是一步一步的下行楼梯。**

## 136.3 不可证明性：PA 的边界

Goodstein 1944 年证明此定理；Kirby-Paris 1982 年证明它**不能在
皮亚诺算术（PA）中证明**。直觉：PA 的归纳只在 ℕ 上爬，而下降链
的终止性住在 ε₀（满足 ω^ε = ε₀ 的序数，恰好是 PA 的证明论序数）
——PA 的梯子够不到自己的高度。这是"超穷方法对初等数学必要"的
第一个铁证，也是哥德尔不完备性最具体的展品之一。（严格的不可证
明性证明超出本书与本教程范围；机器边界如实标注。）

## 136.4 机器侧

**Python**（`examples/python/136_goodstein.py`）做全套：
Sₙ 递归、嵌套 CNF 序数赋值 fₙ（指数本身也是序数——表示必须递归，
因为 f 值在第三步就爬出了 ω^ω 窗口）、下降链审计：

```python
cur = 13
prev = fn(13, 2)
for n in range(2, 11):
    cur = g(cur, n) if cur else 0
    nxt = fn(cur, n + 1)
    descents.append(olt(nxt, prev))     # F_{n+1} < Fₙ 逐步验证
    prev = nxt
assert all(descents)
```

m ≤ 3 的完整终止（步数 1/3/5）逐个跑出；m = 4 的前段
4, 26, 41, 60, 83, 109, 139 由 Julia 复核——而它的完整终止需要
**3·2^402653211 − 3 步**，只能存在于注释里。

**Julia**（`examples/julia/136_goodstein.jl`）用 BigInt 复现书表
九项 + 第十项 3138428381103，并把 m=4 的攀爬曲线摆出来——
"先涨"肉眼可见，"后跌"要等天文数字的步数。

两通道都以书例 S₂(89) = 213516729579718 为精确锚点。

## 136.5 九头蛇与快星系：同一家族的两门亲戚

书图 4.2 的**九头蛇游戏**是古德斯坦定理的姊妹：英雄砍头，蛇把
砍口下方的子树复制 n 份（n 为步数）。Kirby-Paris 同一篇论文证明：
九头蛇必死，且该事实同样不可在 PA 中证明。复制的增长与换底的
增长同构——都是"底在长、序数值在跌"的把戏。另一门亲戚是
**Kirby-Paris 的"好树"序列**与 Hercules 游戏，它们共享同一个
证明模式：给局面赋一个 ε₀ 以下的序数，每步严格下降。

家谱总览：

| 成员 | 参数 | 下降链住的序数区 | PA 可证？ |
|---|---|---|---|
| Goodstein gₙ | 起始数 m | < ε₀ | 否（Kirby-Paris 1982） |
| Hydra 游戏 | 树的形状 | < ε₀ | 否（同上） |
| Hercules | 同上 | < ε₀ | 否 |
| Ackermann 函数全定义 | — | < ω（PR 递归） | 是（PA 可证其全定义） |
| 普通原始递归终止 | — | < ω^ω | 是 |

Ackermann 之所以 PA 可证全定义、而 Goodstein 不可证终止，是因为
前者的下降链长在**每个输入**上都有统一的原始递归界，而后者
（m=4 就要 3·2^402653211−3 步）的界函数本身超出了 PA 的表达力。
"证明论序数" ε₀ 正是 PA 能证明的良序的**高度上限**——Goodstein
的赋值恰好用到这个高度，一分不多、一分不少。

## 136.8 引理 4.5.5 的证明细节

**（1）fₙ 严格增**：对 m 归纳。设 n < k < m，写
k = r·nˢ + u、m = v·nᵗ + b（标准分解）。由 k < m 得 s < t、或
s = t ∧ r < v、或 s = t ∧ r = v ∧ u < b——三种情况都由归纳假设
给出 fₙ(k) 的每个对应项小于 fₙ(m) 的对应项，高位优先比较即胜。

**（2）f_{n+1}(Sₙ(m)) = fₙ(m)**：对 m 归纳。m ≤ n 时两边都等于
m（数本身比底小，换底与换 ω 都不动它）。m > n 时写
m = k·nᵗ + b：

    f_{n+1}(Sₙ(m)) = f_{n+1}(k·(n+1)^{Sₙ(t)} + Sₙ(b))
                    = ω^{f_{n+1}(Sₙ(t))}·k + f_{n+1}(Sₙ(b))    （CNF 加法）
                    = ω^{fₙ(t)}·k + fₙ(b)                        （归纳假设×2）
                    = fₙ(m)。

注意 (n+1)^{Sₙ(t)} 的**指数**正是 Sₙ(t)——引理在指数上递归调用
自己，超底展开的自嵌套结构保证了归纳的完整覆盖。∎

这两条引理合起来就是定理的全部准备：**（1）提供"减一严格降"、
（2）提供"换底免费"**——4.5.7 的三行证明把它们串成下降链。

## 136.9 双通道代码对照

Python 与 Julia 的分工值得注明：**Python 通道持有嵌套 CNF 的序数
引擎**（fₙ 的值在第三步就爬出 ω^ω——指数必须是递归的序数结构，
`olt` 沿指数递归比较）；**Julia 通道持有完整的数值表**（BigInt
把 3.1e12 的第十步算得毫不费力，并给出 m=4 的七步攀爬曲线
4, 26, 41, 60, 83, 109, 139——教科书标准前段）。两条通道在书例
S₂(89) = 213516729579718 处交叉验证，在 g 表九项上双签——
其中第 7 项的笔误正是双通道的**内部一致性**暴露的：单通道只能
报"与书不符"，双通道才能裁决"书错了"。

终止判据的实现细节：Python 的 `while cur > 0` 循环带着 200 步
的保险丝（`assert steps < 200`）——对 m=4 这样的怪物，若误把
它放进循环，保险丝会在天文数字之前烧断，而那时 cur 已是 BigInt
天文数字。保险丝不是装饰：它是"有限 ≠ 可及"的工程化表述。

读者自测三题：S₄(26) 等于多少？（提示：26 = 2·4²+2·4+2，底
换 5：2·25+10+2 = 62。）g₂(3) 为什么等于 3 而不是别的数？（3 =
2+1，底换 3 得 3+1 = 4，减 1 得 3——第一次换底恰好自愈。）以及
最烧脑的一问：goodstein(4) 的第 402653211 层楼梯上，数字有多大？
（没有封闭表述——它的位数本身就是天文数字。这正是 ε₀ 之墙的
手感。）

## 本章要点

1. 超底展开唯一；Sₙ 换底 +1，fₙ 换底成 ω；**f_{n+1}∘Sₙ = fₙ**
   ——底在变，序数值不动。
2. 古德斯坦序列疯狂增长但终归零——证明是把序列映到序数的严格
   下降链，而序数无下降链。
3. Kirby-Paris：PA 证不了它——超穷序数不是奢侈，是必需；ε₀
   是 PA 的天花板。
4. 机器自纠：书表第 7 项笔误被双通道复算链条内部一致性检验纠正。
