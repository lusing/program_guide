# 26 · 力迫与完备布尔代数的对应

> 每个力迫产生一个完备布尔代数，反之亦然——力迫的代数
> 面与语法面是同一枚硬币的两面。

本章覆盖 Jech §25：力迫与 cBa 的对应、支配族与崩塌代数。

## 26.1 力迫 → cBa 的对应

每个分离性偏序 P → B = r.o.(P)（§17 的正则开集代数）。
力迫关系 p ⊩ φ ⟺ e(p) ≤ ‖φ‖（§18 的 (18.26)）。

**反向**：每个 cBa B 的 B-{0} 是分离性偏序——r.o.(B-{0}) = B。
这建立了偏序与 cBa 的**双射对应**（在等价意义下）。

**力的不变形**：
- ccc(P) ⟺ ccc(B)
- λ-闭(P) ⟺ λ-分配(B)
- |P| vs |B|（B 可以比 P 大——|B| ≤ |P|^ℵ₀ 对 ccc P）

## 26.2 支配族

**引理 24.10**：
(a) 可数族不支配一切 f : ω → ω（对角化）。
(b) MA + |ℋ| < 2^ℵ₀ ⟹ ℋ 不支配。

力迫构造：P = ω^{<ω}（有限序列，ccc），D_n = {p : n ∈ dom(p)}
和 E_h = {p : ∃n, p(n) ≥ h(n)} 都稠密。泛型滤波器给出
f = ⋃G 不被任何 h 支配。

## 26.3 崩塌代数

**Col(κ, λ)** = r.o.({p : dom(p) ⊆ κ, |dom(p)| < κ, ran(p) ⊆ λ})
——把 λ 崩塌到 κ 的力迫的布尔代数形态。

**关键定理**：每个 cBa 可嵌入可数生成的 cBa——Col(ℵ₀, λ)
的子代数足以承载一切力迫。

## 26.4 Theorem 57 的骨架

**Theorem 57** MA + ¬CH 的一致性证明中，迭代力迫的
每一步都是 Col(κ, λ) 的某种组合——崩塌代数是"万能力迫"
的建筑材料。
