# 13 · L 是 ZFC 的模型：AC 与 GCH 在 L 中

> Gödel 1938：如果 ZF 一致，那么 ZF + AC + GCH 一致。
> ——二十世纪数学基础的第一场伟大胜利

本章覆盖 Jech §13：L 的典范良序 <_L、定理 33（V=L ⟹ AC）、
定理 34（V=L ⟹ GCH）、Condensation（凝聚）论证与充分集。

## 13.1 L 的典范良序与 AC

L 的每个元素携带**出生证**：首次构造的层号 + 该层的 Gödel
分解（(13.7)：x = 𝔽ᵢ(u,v) 的最小分解（i, u, v)）。定义

    x <_L y ⟺ (层号, 分解 i, 分解 u, 分解 v) 字典序

**定理 33** <_L 良序 L——于是 V=L ⟹ 全局良序 ⟹ AC。

**Isabelle/ZF 的官方机器化**（`ST13/ACinL.thy`）——AC_in_L.thy
是 Constructible 会话的招牌：

```isabelle
thm well_ord_L_r    (* L_r 良序化：(13.8) 的官方版本 *)
thm L_implies_AC    (* L(x) ⟹ ∃r. well_ord(x, r) *)
```

`L_implies_AC` 对每个 L(x) 实例化即全局 AC——Gödel 1938 的
机器化身。计算通道把 <_L 做成**可执行比较器**。Julia
（`examples/julia/13_L_order.jl`）维护出生证表：

```julia

    birth = Dict{String,Int}()
    birth["{}"] = 0
    ...
end
```

∅ 层 0、{∅} 层 1、{∅,{∅}} 层 2——出生证与 <_L 的（层，结构，
字典）序。Prolog（`13_Lorder.pl`）的 `predsort(ord_L, ...)` 
输出全序 `[{},{{}},{{{}}},{{},{{}}},{{{},{{}}}}]`——**良序的
可执行化身**。Agda（`Ch13_Lorder.agda`）的 birth 函数（mutual
块——HFL 与列表辅助互递归）+ 成员层号严格下降 `birth-mem<`；
Coq（`Ch13_Lorder.v`）的燃料版 birth_bound + **精确等式**
`birth_pair`（配对层号恰 +1，Nat.max_0_r 收尾——嵌套 guard
坑的第三次入账，燃料解法）。

## 13.2 GCH 在 L：Condensation 论证

**定理 34（Gödel）** V=L ⟹ 2^ℵα = ℵ_{α+1}。

**引理 13.1** X ⊆ ω_α ⟹ 存在 γ < ω_{α+1} 使 X ∈ L_γ。

*证明*（Condensation 四步链）：
① 反射原理取**可数充分集** M ⊇ {X, ω_α}（充分 (13.9)：
封闭 + 含 cl(U) + 含 ⟨<_{L_β} : β < δ⟩ 序列）；
② Mostowski 坍缩 M ≅ 传递 N（X ⊆ 传递部分上 π = 恒等）；
③ **绝对性**（引理 13.2：y = L_α 与 x ∈ L_α 对充分 M 绝对）
   给 N = L_γ——N ⊨ V=L 且传递 ⟹ N 是某个 L_γ；
④ γ 可数 < ω_{α+1}，X ∈ N = L_γ。∎

于是 P(ω_α) ⊆ L_{ω_{α+1}}，配合 **|L_γ| = |γ|** 的归纳
（后继层被公式数封顶：|def(L_α)| ≤ |α|·ℵ₀ = |α|；极限层取
sup），|L_{ω_{α+1}}| = ℵ_{α+1} ⟹ 2^ℵα ≤ ℵ_{α+1}；Cantor 给
反向。合流：**2^ℵα = ℵ_{α+1}**。

Python（`13_condensation.py`）把四步链做成讲义动画 + 出生证
Python 版；Julia 的对照叙事：V 增长 1→2→4→16→65536→2^65536
（幂集全取）vs L 到 ω 层同步、**ω+1 层分歧**（V 取全部子集
2^ℵ₀，L 只取可定义子集 ℵ₀）——"GCH 的全部秘密：定义性封顶"。

## 13.3 充分集与绝对性的精细结构

**引理 13.2** α ↦ L_α 对一切充分传递集 M 绝对——证明的
三件套：Gödel 运算绝对（受限公式）；cl(U) 的成员关系绝对
（W(n) 迭代的 (13.13)）；y = L_α 绝对（对构造序列的归纳
(13.14)）。**引理 13.3**："充分"本身是 ZF 可证的句子 θ——
充分集恰好是 ⊨ θ 的传递集。这组精细绝对性是 Condensation
的形式基础：**坍缩像 N 落回 L 的层级**是"L 的自我修复能力"。

**与第 11 章的对话**：反射原理（选 M）+ Mostowski（坍缩）+
绝对性（识别 N = L_γ）——三件前章工具的合奏。L 篇的证明
美学：**每个引理都是前章引擎的精准调度**。

## 13.4 历史与方法论

Gödel 1938 的证明（L + 良序 + Condensation）确立了**内模型
方法**：要证 Con(T) ⟹ Con(T+A)，构造 T 的最小内模型并验证
A 在其中成立。第 31 章 L[U]（可测基数的内模型）与第 33 章
（0# 与覆盖引理）是同一方法的深水区。Cohen 1963 的力迫（第
三篇）从另一侧进攻：证 Con(T) ⟹ Con(T+¬A)——两个方向合流
成独立性证明的完整艺术。

**Isabelle 的独特资产**：AC_in_L 是本章官方机器化的锚——
Paulson 按 Kunen 的教科书组织（"standard textbook"），完整
走完 L 的构造到 AC 的链条。GCH 的机器化（Condensation 的
完整形式化）在库中缺席——由讲义 + 数值通道承载，与
Reflection.thy 的孤儿状态一起如实标注。
