# 125 · 罗素悖论与一点数理逻辑

> 对于一个科学工作者来说，最不幸的事情莫过于：当他的工作接近完成
> 时却发现那大厦的基础已经动摇。——哥特洛布·弗雷格

本章覆盖书第一章前半（1.1 罗素悖论、1.2 一点数理逻辑；PDF 15-19
页）：弗雷格的逻辑主义工程如何在 1902 年 6 月被罗素的一封信击穿；
数学界的三种回应；以及为了避免悖论，我们需要先讲清楚"形式理论"
本身是什么——公式、证明、理论如何成为数学对象。

## 125.1 弗雷格的工程与罗素的信

弗雷格（Gottlob Frege）用二十多年建造一个纲领：**把全部数学置于
纯逻辑的牢固基础之上**。他相信：用他的逻辑演算，加上"集合间的
属于"这一个简单概念，可以表达出全部数学。1902 年 6 月，巨著
《算术基本规律》第二卷已送印刷厂，罗素（Bertrand Russell）的来信
到了。翌年出版的第二卷多出一篇《附录二》，开头便是本章的题词：
"而贝特兰·罗素的一封信却置我于这样的境地。"

是什么击穿了弗雷格？集合论之父康托是在**素朴**意义上理解集合的。
他在《超穷数理论基础》中的"定义"：

> 我们将集合理解为任何将我们思想中那些确定而彼此独立的对象
> 放在一起而形成的聚合。

按这种理解，弗雷格使用的**概括原则**应该毫无问题：

> 对任意性质 φ，存在集合 X = {x | φ(x)}：X 恰好含有所有具有
> 性质 φ 的对象。　　(*)

罗素指出这是一条自相矛盾的原则。取 φ(x) 为"x 是集合并且
x ∉ x"（不属于自身）。由 (*)，罗素类

    R = {x | x ∉ x}

是集合。R 本身是集合，所以可以问 R 是否属于 R：

- 若 R ∈ R：按 R 的定义，R 有性质 φ，而 φ 说的是 x ∉ x，故
  R ∉ R——矛盾；
- 若 R ∉ R：则 R 是"不属于自身的集合"，有性质 φ，按定义 R ∈ R
  ——矛盾。

所以 **R ∈ R 当且仅当 R ∉ R**。这个矛盾就是罗素悖论。

> **前奏**：罗素悖论不是从天而降。此前康托自己已发现"最大基数
> 悖论"（所有集合的集合会有最大的基数，与幂集定理冲突），布拉里-
> 福尔蒂（Burali-Forti）发现了所有序数的序列不能是集合。但它们
> 不如罗素悖论那样**纯逻辑**：不需要基数、序数这些集合论专有概念，
> 只要有"性质"与"属于"就够了。所以在动摇弗雷格工程这件事上，
> 罗素的版本最致命。

## 125.2 三种回应：抛弃、元数学、还是乐园依旧？

原书在此有一段少见坦率的哲学梳理（对数学读者同样必要——集合论
"是不可能完全避免哲学讨论的"）。

**布劳维尔、外尔、彭加勒**：悖论是康托集合论的致命一击，人类应当
抛弃这个学科、放弃对超穷数的探索。彭加勒据传曾说康托的理论是
"数学的疾病，应当被治愈"。

**希尔伯特**：数学王国因弗雷格、戴德金、康托的工作已经"武装齐备，
空前强固"；布劳维尔的纲领"只不过是在重演一场有人尝试过的暴动，
这场暴动在当初曾以更凶猛的形式进行，结果却彻底失败了"。他的方案
不是抛弃，而是给无穷的数学一个**一致性的证明**——把数学本身当作
研究对象，用有穷的方法证明它不含矛盾。这就是**希尔伯特计划**
（元数学）的起点。

**哥德尔**：悖论出现在"数学的边界上"，靠近哲学的边界，对数学本身
影响不大；通过对康托集合论的公理化，悖论已经被"完美地"解决。他
的立场是**柏拉图主义**（数学实在论）：数学世界独立于我们而客观
存在，悖论只说明**我们对集合宇宙的认识不够清楚**——就像麦克斯韦
方程与伽利略变换的矛盾不推翻物理学，而是把物理学推进到相对论。
原书弁言把这套立场称为"哥德尔主义"，并预告整套丛书将在《数学
哲学》中为它辩护。

本教程的路线正是哥德尔式的：公理化没有"打发"无穷，而是把它变成
可以精确研究的对象。第 126 章起，(*) 被拆解成受限的公理组（ZFC）。

## 125.3 一点数理逻辑：理论本身也是数学对象

要精确地陈述"ZFC 是什么"、"ZFC 证不出 CH"，句法概念得先成为
**数学对象**。原书 1.2 节的账目如下（完整背景见姊妹丛书《数理
逻辑——证明及其限度》）。

**语言**。集合论的语言 ℒ_∈ 只有一个非逻辑符号：二元谓词 **∈**
（相等 = 由逻辑自带）。公式由原子公式 x ∈ y 经 ¬、∧、∨、→、↔
与量词生成。实践中的缩写记号（⊆、⋃、P(X)、{x : φ}……）都能展开
回只含 ∈ 和 = 的公式。

**编码：公式是自然数**。把初始符号指定为自然数（书上的例子：1
表示左括号，5 表示否定词），公式就是自然数的有穷序列
φ = (n₁, …, n_m)。令 p₁, …, p_m 为前 m 个素数，则

    ⟨φ⟩ = p₁^n₁ · p₂^n₂ ⋯ p_m^n_m

由 φ 唯一决定——**素因子唯一分解**保证从数能读回整个序列：第 i
个符号码是第 i 个素数的指数。机器侧（`examples/python/125_russell.py`）：

```python
FIXED = {'(': 1, ')': 2, 'in': 3, '=': 4, 'not': 5, 'and': 6,
         'or': 7, 'imp': 8, 'iff': 9, 'all': 10, 'ex': 11}

def code(tok):
    if tok in FIXED:
        return FIXED[tok]
    assert tok.startswith('v')
    return 12 + int(tok[1:])

def encode(seq):
    """公式（符号串）→ 素数幂乘积 p_i^{n_i}。"""
    out = 1
    for i, tok in enumerate(seq, start=1):
        out *= nth_prime(i) ** code(tok)
    return out
```

注意一个细节：所有符号码都 ≥ 1（变元取 12+i）。**指数非零**是
编码可逆的关键——若允许 0，序列 (3) 与 (3, 1) 会给出同一个数 2³。
审计单元验证了三件事：

```python
phi = ['all', 'v0', 'ex', 'v1', 'not', '(', 'v0', 'in', 'v1', ')']
n_phi = encode(phi)
assert decode(n_phi) == [code(t) for t in phi]        # 往返
```

公式 ∀v₀∃v₁¬(v₀ ∈ v₁) 的编码是一个具体的大数；84 个短公式两两
编码不同（单射）；分解中素数的个数恰等于公式长度。而**证明**是
公式的有穷序列——再套一层同样的编码，整个证明也成为一个自然数。
"证明"于是可以像自然数一样被枚举、被判定，这是 1.4 节全部元理论
操作的地基。

**推演与理论**。从语句集 Γ 到 φ 的一个**推演**是有穷公式序列
φ₁, …, φ_n，其中每个 φᵢ 或者属于 Γ、或者是逻辑公理、或者由在它
之前的公式经推理规则（肯定前件）得到，且 φ_n = φ，记作 Γ ⊢ φ。
若 T 对证明封闭（对任意语句 α，T ⊢ α 当且仅当 α ∈ T），称 T 为
**理论**；若存在递归的语句集 A ⊆ T 使 T 中每个语句都可由 A 推出，
称 A 为 T 的一组**公理**，T 是**可公理化的**。"递归"意为：任给
一个语句，可以在有穷步内用完全机械的方法判定它是否属于 A——这
些概念能用在语句上，正因为语句是自然数。

理论 T（作为自然数的集合）通常**不是递归的**，只是**递归可枚举**
的：若 α ∈ T，有穷步内可以知道；若 α ∉ T，可能永远得不到结论。
最后，**一致性**：T 一致当且仅当不存在语句 α 使 T ⊢ α 且 T ⊢ ¬α。

**对象理论与元理论**。这里出现一个层次的划分，全书都要靠它：
ZFC 谈论的是任意大的无穷（甚至不可达基数），但**叙述 ZFC 的语言
和 ZFC 本身却是有穷对象**——自然数、自然数序列、自然数上的递归
关系。ZFC 是**对象理论**；我们用来谈论它的**元理论**是直观的，
至少要含初等算术（否则没有"公式"、"证明"、"编码"这些概念）。
不同哲学立场容许不同强度的元理论：柏拉图主义者容许强元理论，
有穷主义者要求元理论不涉实无穷——而句法概念都是递归的、严格
有穷的，所以不与任何立场冲突。第 147 章讲力迫时，"在哪个元理论里
说话"会再次成为关键。

## 125.4 机器侧：悖论的三种机器形态

### 形态一（Coq）：悖论是一条"不可能性定理"

悖论的正确身份是什么？在一致的系统里，"概括原则不一致"本身是
一条**可证明的定理**。Coq 单元（`examples/coq/Ch125Russell.v`）把
这句话变成了机器检查的证明。先把"集合"与"属于"设为不透明的原语：

```coq
Parameter set : Type.
Parameter mem : set -> set -> Prop.

Axiom comprehension : forall P : set -> Prop,
  exists X : set, forall y : set, mem y X <-> P y.
```

`Axiom comprehension` 就是朴素概括原则 (*) 的形式化。喂给 Coq：

```coq
Theorem naive_inconsistent : False.
Proof.
  destruct (comprehension (fun x => ~ mem x x)) as [R HR].
  specialize (HR R).                    (* mem R R <-> ~ mem R R *)
  tauto.
Qed.
```

四行：取出罗素类的代表 R；把 R 自己代入隶属刻画，得到
`mem R R ↔ ¬ mem R R`；`tauto` 从"命题等价于自己的否定"推出
`False`。**注意这不是 Coq 出了问题**——恰恰相反：任何一致的系统
都不可能实现这条公理，而 Coq 证明了这一点。罗素悖论从"矛盾"变身
为"关于朴素集合论的不可能性定理"。

同文件的第二个定理把书 1.3 节的修复方案先行排练。把公理换成
**分离**版（性质只能从已有集合中裁出子集）：

```coq
Axiom separation : forall (P : set -> Prop) (X : set),
  exists Y : set, forall y : set, mem y Y <-> (mem y X /\ P y).
```

于是罗素推理变成一条建设性定理——**任何集合都有一个不属于它的
子集**：

```coq
Theorem russell_relative : forall X : set,
  exists Y : set, (forall y : set, mem y Y -> mem y X) /\ ~ mem Y X.
```

证明是书 1.3 论证的逐字翻译：Y = {u ∈ X | u ∉ u} 显然 ⊆ X；反设
Y ∈ X，则由隶属刻画，mem Y Y ↔ mem Y X ∧ ¬mem Y Y，无论 mem Y Y
真假都得出矛盾。"所有集合的集合"因此不存在——第 126 章的定理
1.3.7 的机器预演。

还有一个反方向的观察：**罗素类在类型论里根本写不出来**。试试

```coq
Definition R (x : Prop) := ~ x x.
```

这一行无法通过类型检查——x : Prop 不是函数，x x 非良型。Coq 的
类型系统用"宇宙分层"（Prop、Type₁、Type₂……）先天挡住了自指。
同一枚硬币的两面：公理化路线（ZF）把自指挡在公理外，类型论路线
把它挡在语法外。

### 形态二（Prolog）：有限宇宙的穷举终审

Prolog 单元（`examples/prolog/125_russell.pl`）把悖论放到 3 元宇宙
{a,b,c} 上做**全量扫描**。一个"隶属图"是 9 个可能有序对 (x,y) 的
任意子集（x ∈ y 当且仅当 (x,y) 在图中）——共 2⁹ = 512 个模型：

```prolog
russell_rep(G, X) :-
    member(X, [a,b,c]),
    forall(member(Y, [a,b,c]),
           ((gm(G,Y,X), \+ gm(G,Y,Y)) ; (\+ gm(G,Y,X), gm(G,Y,Y)))).
```

`russell_rep` 问：图 G 里是否存在代表 X，其隶属列恰为"y ∉ y"？
对角线论证保证答案永远是"否"——X 的列必须在 Y = X 那一行等于
¬(X ∈ X)，而它恰是 X 自己的隶属行。穷举验证：

```prolog
check_russell :-
    pairs3(Ps),
    findall(G, (subset(Ps, G), russell_rep(G, _X1)), Hits1),
    length(Hits1, 0),
```

512 个图逐一检查，**0 个**含有罗素代表。同法验证**全概括在有限
宇宙内无模型**：8 个子谓词都需要代表，而 3 个候选至多提供 3 个
不同的隶属列。理发师悖论（"理发师刮且只刮不自己刮脸的人"）的
村庄指派穷举同样无解。单元还数出：恰有 2⁶ = 64 个图满足"没有
x ∈ x"——这是基础公理（第 126 章公理 7）的有限影子。

## 本章要点

1. 素朴概括原则 (*) 矛盾：罗素类 R = {x | x ∉ x} 给出
   R ∈ R ↔ R ∉ R。前奏是最大基数悖论与 Burali-Forti 悖论。
2. 三种回应：抛弃（布劳维尔/外尔/彭加勒）、元数学（希尔伯特）、
   公理化+实在论（哥德尔）。本教程走哥德尔路线。
3. 公式与证明经素数幂编码成为自然数；推演是变形为有穷序列的
   纯组合对象；理论=对证明封闭的语句集；可公理化=有递归的公理集；
   一致性=推不出一对矛盾。
4. ZFC 是有穷的对象理论；元理论是直观的、至少含初等算术——
   层次划分贯穿全书。
5. 机器三形态：Coq 把悖论证成"不可能性定理"；Prolog 在 512 个
   有限模型里终审对角线；Python 让编码成为可运行的对象。

*对应示例：`examples/coq/Ch125Russell.v`、`examples/python/125_russell.py`、
`examples/prolog/125_russell.pl`。*
