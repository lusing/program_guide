# 第 92 章 · 布尔值模型

> 对应原书：冯琦《集合论导引（第二卷）》§3.5（布尔值模型）。
> 前置：[第 90 章 力迫基本理论](90-forcing2.md)、[第 91 章 迭代力迫](91-martin.md)；布尔代数与 Stone 表示的 Viale 视角见[第 47-49 章](47-ba.md)。

第 90-91 章的力迫论站在「存在 ZFC 的可数传递模型」这一假设之上——为的是让泛型滤子的存在性（定理 3.1）有处安放。布尔值模型方法去掉这层脚手架：直接在集合论当前论域 V 之上构造一个取值于完备布尔代数的「模型」，每个语句 φ 都有一个布尔真值 ⟦φ⟧；ZFC 的每条公理的布尔值都是 1，而独立性只需造出使 ⟦¬φ⟧ > 0 的代数。冯琦在这一章还证明了更深的一层：布尔值语义与偏序力迫（定理 3.25 的等价）以及 Vopénka 定理（内模型之上的泛型扩张可就地实现）——同一件事的两种等价表现。

## 92.1 完备布尔代数（§3.5.1）

**定义 3.38** 布尔代数 B = (B, +, ·, −, 1, 0) 满足六组公理 Ba1-Ba6：交换、结合、分配、吸收、互补（u + ū = 1，u·ū = 0）、单位元。由公理自动导出偏序 u ≤ v ⟺ u·v = u ⟺ u + v = v 与相冲 u ⊥ v ⟺ u·v = 0（引理 3.59）。B⁺ = B ∖ {0} 是力迫的自然条件空间。

**定义 3.40-3.43** 理想与滤子、素理想与超滤子、商代数 B/I。**定理 3.20（Stone 表示）**：任何布尔代数同构于某个集合代数的子代数——正则截断（regular cuts）给出标准表示；**定理 3.21（完备化）**：任何偏序 P 都稠密嵌入唯一的（同构意义下）完备布尔代数 B(P)——这正是第 91 章迭代理论中「P 的完备化」的来源；B⁺ 还具备**可分性**（任何两条件有非平凡下确界或者可分）。**定理 3.22（饱和数）**：sat(B)——最大冲突子集的势的上确界——要么 ≤ ℵ₀ 要么 ≥ ℵ₁，且由 cf(κ) < κ 时 κ-链条件逐层崩溃的论证给出精确分界。

幂集代数的公理账在机器上是最便宜的（`examples/lean/Settheory/Ch92Boolval.lean`）：

```lean
theorem bMeet_self_compl (a : B4) : bMeet a (bCompl a) = bBot := by
  funext i; simp [bMeet, bCompl, bBot]

theorem bJoin_self_compl (a : B4) : bJoin a (bCompl a) = bTop := by
  funext i; simp [bJoin, bCompl, bTop]
```

计算通道把 Ba1-Ba6 在 B = 2²（四元素）上全部穷举（Python/Julia/Prolog 的第一节，含分配律的三重量化验证）。

## 92.2 布尔值结构与布尔值算法（§3.5.2）

**定义 3.50（布尔值结构）** 𝔄 = (A, B, F∈, F=) 其中 A 非空、B 完备、F∈, F= : A×A → B 满足四条基本性质：(a) F=(a,a) = 1；(b) F=(a,b) = F=(b,a)；(c) 传递 F=(a,b)·F=(b,c) ≤ F=(a,c)；(d) 包容 F∈(a,b)·F=(a,c)·F=(b,d) ≤ F∈(c,d)。

**定义 3.51（布尔值算法）** 公式的布尔值按结构递归：原子式取 F∈/F=；¬φ 取 1 − ⟦φ⟧；φ∧ψ 取 ⟦φ⟧·⟦ψ⟧；φ∨ψ 取 ⟦φ⟧ + ⟦ψ⟧（B 中上确界）；φ→ψ 取 ⟦¬φ⟧ + ⟦ψ⟧；∀x φ 取 ∧（B 中下确界）、∃x φ 取 Σ（上确界）。**定义 3.52**：φ 为真当且仅当 ⟦φ⟧ = 1。

**定理 3.23（基本布尔值不等式）** 八条不等式构成力迫关系的骨架：(1) ⟦φ⟧·⟦¬φ⟧ = 0；(2) 任何 u ∈ B⁺ 都有 w ≤ u 落在 ⟦φ⟧ 或 ⟦¬φ⟧ 一侧；(5) w ≤ ⟦φ∧ψ⟧ ⟺ w ≤ ⟦φ⟧ 且 w ≤ ⟦ψ⟧；(8) w ≤ ⟦∃xφ⟧ ⟺ 每个 w′ ≤ w 都能被某 a 见证到 ⟦φ[a]⟧——正是定理 3.26 力迫关系基本性质的直接来源。

**引理 3.70** 一阶逻辑公理的布尔值为 1，推理规则保真。**定义 3.53（富有性）** 结构对每个 ∃ 语句提供混合见证 a：⟦∃uₙ₊₁φ⟧ = ⟦φ[a]⟧。**引理 3.72（布尔 Łoś 定理）** 超滤子 U 上的商结构满足 𝔄/U ⊨ φ ⟺ ⟦φ⟧ ∈ U——按公式结构归纳，情形一至情形九全部翻译。

机器件把这套算法做成公式上的递归函数（Lean 的 `bval`、Coq 的 `bval`、Agda 的 `bval`），并对定理 3.23 的关键条款给出完整证明：

```lean
theorem bval_not_self (v : Fin 1 → B4) (φ : Fm) :
    bMeet (bval v φ) (bval v (Fm.not φ)) = bBot := by
  funext i
  have key : ∀ b : Bool, (b && !b) = false := by decide
  exact key (bval v φ i)

theorem bval_decides (v : Fin 1 → B4) (φ : Fm) (u : B4) :
    ∃ w : B4, bLe w u ∧ (bLe w (bval v φ) ∨ bLe w (bCompl (bval v φ)))
```

同一律 ⟦φ→φ⟧ = 1（Lean `bval_identity`、Coq `bval_identity`、Agda `bval-identity`）是引理 3.70 的最小样本；计算通道再验证爆炸律 ⟦φ∧¬φ → ψ⟧ = 1 与矛盾值为 0 的全赋值穷举。

## 92.3 布尔值模型 V^B（§3.5.3）

**定义 3.54（布尔值论域）** 按秩层次递归：V₀^B = ∅；V_{α+1}^B = 全体定义域 ⊆ V_α^B、值域 ⊆ B 的函数；极限层取并。**V^B = ⋃_α V_α^B**——「名字」的布尔化：每个元素把每个候选成员标注一个布尔权重。

**定义 3.56（基本布尔值度量）** 对 τ, σ ∈ V^B：

  ⟦τ ∈ σ⟧ = Σ_{t∈dom σ} (⟦τ = t⟧ · σ(t))，
  ⟦τ = σ⟧ = Π_{t∈dom τ}(−τ(t) + ⟦t ∈ σ⟧) ∧ Π_{t∈dom σ}(−σ(t) + ⟦t ∈ τ⟧)。

**引理 3.73/3.74** 验证四公理 (a)-(d)：⟦τ=τ⟧ = 1 的证明把 ⟦t=t⟧ = 1 的归纳假设压进每个权重（a(t) ≤ ⟦t ∈ a⟧）；传递与包容由三条不等式的三元组归纳（引理 3.74 的 (i)(ii)(iii)）。**推论 3.9**：(V^B, B, F∈, F=) 是布尔值结构——一阶逻辑在其中整体有效。

**定义 3.57/3.58（检查名与泛型名）** x̌ = {(ŷ, 1) : y ∈ x}；Ġ = {(ǔ, u) : u ∈ B⁺}。**引理 3.75（泛型特性）**：⟦ǔ ∈ Ġ⟧ = u——名字里的权重恰是它在泛型滤子中出现的概率；Ġ 的布尔值账（滤子性、泛型性遇稠密集、遇极大冲突集）逐条为 1。

机器面（Lean `#eval`、Coq 的 `mem1`/`Compute`、计算通道第三节）在两层 V^B 上核算最小样本：

```coq
Compute (mem1 0 (gen_diag p0)).
(* = (true, false) = p0：⟦ǔ ∈ Ġ⟧ = u 的最小影子 *)
```

**定理 3.24（ZFC 在 V^B 中真）** 逐条验证：同一性（引理 3.76：⟦∀t(t∈a→t∈b)⟧·⟦∀t(t∈b→t∈a)⟧ ≤ ⟦a=b⟧ 的不等式链）；配对（名字 {(a,1),(b,1)}）；分解原理（名字 η = {(b, ⟦φ[b]⟧) : b ∈ dom τ}——权重就是力迫条件）；并、幂集、无穷（Δ₀ 绝对性引理 3.80：V 中成立者布尔值为 1）；映像存在；∈-极小（秩最小反例法）；选择（引理 3.77 反链混合名字 + 引理 3.78 富有性：极大冲突子集上各配一个名字，混合而成的新名字同时见证全部——这正是第 90 章引理 3.9 极大原理的布尔版）。**推论 3.11（相对独立性原理）**：ZFC ⊢ φ ⟹ ⟦φ⟧ = 1；于是若某完备 B 使 ⟦¬φ⟧ > 0，则 ZFC ⊬ φ——CH 的独立性（例 3.33：Add(ω,ω₂) 的完备化上 ⟦2^{|ω|} ≥ ω₂⟧ = 1）。

## 92.4 布尔值 = 偏序力迫（§3.5.4）

**定义 3.59/3.60** P-名字空间 V^P（关系版本）经名字嵌入 h* : V^P → V^B 转成布尔版（每个权重 p ↦ h(p) = ↆp 的正则截断）。**定理 3.25**：

  p ⊩ φ[T₁,…,Tₙ] ⟺ ⟦φ[h*T₁,…,h*Tₙ]⟧ ≥ h(p)

——力迫关系就是布尔值不小于条件。由此定理 3.26（力迫关系基本性质）成为定理 3.23 的逐条翻译；定义 3.61 的整合方案把 P 稠密嵌入 B(P) 后直接用 ⟦⟧ ≥ p 定义 ⊩。**V-泛型超滤子**（定义 3.62/3.63 + 引理 3.83 的大并封闭刻画）、扩张 V[G] 与真相引理（定理 3.27/3.28）在「当前论域之外存在泛型滤子」的假设下重建第 90 章的全部账目——两种表现手法殊途同归。

**定理 3.29（Vopénka）** 若 V = L[A]（A 是序数的集合），则 V = HOD[G]：基于 κ 的 Vopénka 代数 B_κ = F[OD ∩ 𝒫_κ(Ord)] 属于 HOD 且在 HOD 中完备，超滤子 H = {u ∈ C_κ : A ∈ u} 与它的像 G 就在 V 中给出 HOD 之上的泛型扩张。**泛型滤子未必在论域之外**——内模型自己就能携带自己的泛型。

## 92.5 完备子代数与中间模型（§3.5.5）、广义分配律（§3.5.6）

完备子代数 C ≤ B 给出中间模型链 V ⊆ V[G∩C] ⊆ V[G]；反过来（定义 3.66/3.67）由 X 生成的完备子代数满足 V[G] = V[X∩G]（引理 3.85：G 由 A = X∩G 经布尔运算逐层可定义地重建），于是 κ-生成的代数满足 V[G] = V[A]（推论 3.12），且 V[G] 中每个 A ⊆ κ 都由某 κ-生成子代数实现 V[A] = V[D∩G]（推论 3.13）——「中间模型多大程度上是子力迫的」的精确账。引理 3.88 把商代数做成 V^B 中的名字 D:B（D ≅ B*(D:B)），推论 3.14 给出泛型滤子的扩展：B-泛型 G 总能扩成 D-泛型 H 且 G = H∩B。

**定义 3.68（广义分配律）** B 满足 κ-分配律，当且仅当对每个长度 κ 的指标序列

  ∧_{α<κ} Σ_{β<λ} a_{αβ} = Σ_{f ∈ Π I_α} ∧_{α<κ} a_{α,f(α)}——

这是定义 3.24 贝尔纲式 θ-分配的真实代数面目。机器件在 (κ,λ) = (2,2) 上穷举全部 256 个矩阵验证恒等式（计算通道第四节）。

## 92.6 超滤子商与 Łoś 换算的机器面

Isabelle 通道（`ST92/Boolval.thy`）承载两个抽象 locale：布尔值结构的 (c)(d) 换位推导与超滤子的交-补账：

```isabelle
lemma meet_in_imp_both:
  assumes xB: "x \<in> B" and yB: "y \<in> B" and h: "bm(x, y) \<in> U"
  shows "x \<in> U \<and> y \<in> U"

lemma ultra_exclusive:
  assumes xB: "x \<in> B" and h1: "x \<in> U" and h2: "bc(x) \<in> U"
  shows False
```

柱超滤子 U₀ = {a : a 的第 0 坐标为 true} 是四元代数上的具体超滤子，Lean/Coq/Agda/计算通道验证 ⟦φ∧ψ⟧ ∈ U ⟺ 各自 ∈ U、a 与 ¬a 恰取其一、滤子上 ⟦φ→ψ⟧ ∈ U ⟺ ⟦ψ⟧ ∈ U——引理 3.72 的原子换算，商结构 𝔄/U 的二值世界由此逐层搭起。

## 92.8 本章要点

- 布尔值方法把「泛型扩张里的真相」编码为当前论域中的布尔计算：⟦φ⟧ ≥ p 就是 p ⊩ φ（定理 3.25）——力迫论从此不需要可数传递模型的脚手架。
- V^B 的元素是「加权名字」：σ(t) 是 t 作为 σ 成员的权重；基本度量（定义 3.56）的递归形状与引理 3.73/3.74 的三条不等式是整个上层建筑的承重墙。
- 富有性（引理 3.78，反链混合名字）是 AC 进入布尔值世界的通道——它把 ∃ 的见证在 V 内部制造出来。
- 推论 3.11 是独立性的布尔判据：ZFC 的定理布尔值恒为 1，所以任何使 ⟦¬φ⟧ > 0 的完备代数都是 φ 独立于 ZFC 的证据。
- Vopénka 定理揭示内模型的自我泛型性（V = HOD[G]）；完备子代数账（引理 3.85-3.88）回答中间模型问题；广义分配律（定义 3.68）才是「不添小序列」的代数本体。
