# 87 · 可构造宇宙 L 与一般连续统假设

前两章把传递模型、初等子模型、塔尔斯基准则和镜像原理装进了工具箱，并在谢旯 pcf 上演练了一遍。从这一章起，冯琦第二卷进入正题：**集合论内模型**。内模型比传递模型更强——它不仅要满足公理，还要包含全部序数。第一个、也是最著名的内模型，是哥德尔 1938 年的可构造宇宙 L；本章完整重建它，并把一般连续统假设 GCH 在 L 中的证明（定理 2.11）一步一步写出来。

与第 12–13 章（Jech 路线）相比，冯琦的讲法有两个鲜明特点。第一，他把「可定义子集」运算 𝒟 当作 KP 之上的依定义扩张（第 84 章的定义 1.31），整个 L 层次从这一个集合运算生长出来，然后用**十个哥德尔集合运算**把这朵逻辑之花「代数化」：传递集合上的可定义子集恰好等于哥德尔运算闭包的成员（定理 2.4）。第二，GCH 的证明不经过「L 中基数 = 真基数」的外部核算，而是把凝聚化引理（定理 2.10）——Σ₁ 初等子结构的坍缩必然还是某个 L_β——与第一卷的传递化定理（定理 I.1.97）直接焊接起来。机器通道照旧只能做有限样品：L_n = V_n 的引擎、位置配对对角线、<_L 典范秩序的末端延伸；完整的凝聚化与 GCH 证明由正文自包含给出。

## 87.1 可构造层次

第 84 章定义 1.31 引进了集合运算 𝒟：对非空传递集合 M，𝒟(M) 是 M 的全部可定义子集（带 M 中参数）组成的集合。现在拿它当发动机：

**定义 2.1（可构造层次）。** 递归定义：
1. L₀ = ∅，L₁ = {∅}；
2. 对每个序数 α，L_{α+1} = 𝒟(L_α)；
3. 对每个非零极限序数 α，L_α = ⋃_{β<α} L_β。

称 L = ⋃_{α∈Ord} L_α 为**可构造集论域**。一个集合是**可构造的**当且仅当 x ∈ L，当且仅当存在序数 α 使 x ∈ L_α。

**引理 2.1（ZF）。** 对可构造层次：
1. α ≤ β 蕴含 L_α ⊆ L_β；
2. 每个 L_α 都是传递集合，从而 L 是传递类；
3. 每个 L_α ⊆ V_α，且 α ≤ ω 时 L_α = V_α；
4. α ∈ β 蕴含 α, L_α ⊆ L_β，从而 Ord ⊆ L；
5. 对每个序数 α，L ∩ Ord... 更精确地：L_α ∩ Ord = α；
6. （AC）对每个 α ≥ ω 都有 |L_α| = |α|。

**证明。** (1)(2) 同时对 α 归纳：极限步由并集直接给出；后继步用引理 1.15(1)——L_β ∪ [L_β]^{<ω} ⊆ 𝒟(L_β) 且 𝒟 保持传递性。注意 (1) 只需要扩张性 M ⊆ 𝒟(M) 一条——这正是机器通道里 `Lh_mono` 证的东西。

(3) 对 α < ω 已知 L_α = V_α（有限载体上每个子集都带参数可定义，见 87.10 的引擎）；α ≥ ω 归纳：L_{β+1} = 𝒟(L_β) ⊆ 𝒫(L_β) ⊆ 𝒫(V_β) = V_{β+1}。

(4) 对 α 归纳：后继步中 β < α 时 L_β ∈ 𝒟(L_α)（用公式 v₀ = v₁ 带参数 L_β 在 L_α 上定义出 {L_β}，再并入），α 本身由「v₀ ∈ Ord」定义出；极限步取并。于是序数全都落在 L 里，而且 L_α ∩ Ord = α（(5)）：更大的序数还没被造出来，更小的已经作为元素就位。

(6) 是**整个 GCH 证明的算术心脏**：α = ω 时 |L_ω| = |V_ω| = ℵ₀；极限步取并；后继步数公式——用来定义 L_α 子集的公式只有 ω 个，参数只有 |L_β| 个有限序列，所以

|L_{β+1}| = |𝒟(L_β)| ≤ ℵ₀ · |L_β|^{<ω} = max(ℵ₀, |L_β|) = |β+1|。∎

这条计数不等式的有限影子，就是机器通道里「深度受限公式族 vs 幂集」的对角线实验（87.10 第二组）：在无穷载体上，公式可数而子集不可数，缺口永远存在；正是这个缺口让 L_ω = V_ω 之后立即分道扬镳——|L_{ω+1}| = ℵ₀ < 2^{ℵ₀} = |V_{ω+1}|。

**推论 2.1。** 若 φ(v₀,…,v_{n-1}) 是 Δ₀ 解析表达式，则语句 ∀v₀∈L…∀v_{n-1}∈L (φ^L ↔ φ) 在 V 中成立——传递类对 Δ₀ 性质绝对（第 84 章 Δ₀ 相符性定理的又一次使用）。

**定理 2.1（L-镜像原理）。** 对任何彰显自由变元的表达式 φ，L 中存在无界多的 β 使

L_β ⊨ φ[a₀,…,a_n] ⟺ L ⊨ φ[a₀,…,a_n]（对一切 a₀,…,a_n ∈ L_β）。

这是第 85 章广义镜像原理（定理 1.29）限定到 L 上的形态：把「充分大的 H_κ」换成「充分高的 L_β」。

**定义 2.2（内模型）。** 传递类 W 是理论 T 的**内模型**，当且仅当 W 包含全体序数，且 T 的每条公理 θ 都满足 θ^W 在 V 中成立。

**定理 2.2。** L 是 ZF 的内模型。

证明是逐公理核对相对化解释，套路只有两种。外延公理：传递类上「元素相同」就是「L 中元素相同」——第 85 章例 1.7 已机器化。配对、并集、无穷：直接验证（ω ∈ L_{ω+1} 见证无穷公理）。真正要动 L-镜像原理的是**分解原理与映像存在原理**：对固定的表达式 φ 与可构造参数 a₀,…,a_{n-1}、a_n，先在 V 中得到 a_{n+1} = {a ∈ a_n | φ^L}，再用定理 2.1 把足够高的 L_λ 里的求值与 L 里的求值对齐，于是 a_{n+1} 恰好是 L_λ 中由同一表达式定义的子集，落进 𝒟(L_λ) = L_{λ+1}。映像存在原理同理，只是还要先对 a_n 的每个元素收集「见证出现的最低层」取上确界。E-极小原理（基础公理的方案）用 V 中的 ∈-极小元直接传递过来。∎

这一段的机器对应：ST87 里 `Lset_succ`（L_{α+1} = DPow(L_α) 的官方形态）与 `trans_M_subset_DPow`（M ⊆ 𝒟(M) 的成员形态）。

## 87.2 哥德尔集合运算

**定义 2.3（可构造集公理）。** 语句 V = L：∀x ∃α (α ∈ Ord ∧ x ∈ L_α)。

要证 ZF ⊢ (V=L)^L——L 里的每个集合都是 L 里的可构造集合——需要把「可定义」这朵逻辑之花变成**代数**：十个固定的一阶集合运算，复合封闭、逐条绝对。

**定义 2.4（哥德尔基本集合运算）。**

| 记号 | 运算 |
|---|---|
| G₁(x,y) | {x,y} |
| G₂(x,y) | x × y |
| G₃(x,y) | {(a,b) \| a∈x ∧ b∈y ∧ a∈b} |
| G₄(x,y) | x − y |
| G₅(x,y) | x ∩ y |
| G₆(x) | ⋃x |
| G₇(x) | dom(x) |
| G₈(x) | {(a,b) \| (b,a) ∈ x} |
| G₉(x) | {(a,c,b) \| (a,b,c) ∈ x} |
| G₁₀(x) | {(b,c,a) \| (a,b,c) ∈ x} |

由这十个运算经复合得到的集合运算叫**哥德尔集合运算**。G₉、G₁₀ 两个三元组轮换看着突兀，它们是为了在「项的变元替换」时保持坐标不乱——引理 2.2 的归纳里会反复出现。

**定义 2.5。** n-元组左结合：(a₁,…,a_{n+1}) = ((a₁,…,a_n), a_{n+1})；n-元笛卡尔积同理迭代。

**定义 2.6。** 对彰显自由变元的 Δ₀ 表达式 φ(v₀,…,v_n)，称（n+1）元集合运算 F **计算** φ，当且仅当 KP ⊢ F(a₀,…,a_n) = {(a₀,…,a_n) ∈ a₀×⋯×a_n | φ[a₀,…,a_n]}。

**引理 2.2（可计算性）。** 每个彰显自由变元的 Δ₀ 表达式 φ：
1. 有哥德尔运算 G_φ 计算它；
2. 对每个 0 ≤ i ≤ n，有哥德尔运算 G_{(i,φ)} 满足 G_{(i,φ)}(x, a₀,…,â_i,…,a_n) = {a_i ∈ x | φ[a₀,…,a_n]}。

证明是对表达式结构的归纳。先把语法标准化：只留下 ∈、∧、¬、有界 ∃ 四种符号（=、∨、→、↔、有界 ∀ 都可互相改写；u_i ∈ u_i 改写为 ∃u_{i+1} ∈ u_i (u_{i+1} = u_i)；约束变元下标整体抬高，保证有界量词总是绑最大下标的变元）。然后四类情形：

- **冗余变元（A1）**：复合 Cartesian 积 G₂ 补出多余变元坐标；用 G₇（dom）把多余坐标投影掉；变元改名用 G₉/G₁₀ 的轮换对齐坐标。
- **初始属于关系（A2）**：u_i ∈ u_j 的特征函数就是 G₃(x,y)（当 i,j 都不在边缘）或 G₈∘G₃（轮换到边缘）——受限积「a∈x ∧ b∈y ∧ a∈b」正是「有序对属于 x×y 当且仅当左坐标属于右坐标」的化身。
- **布尔连接（A3）**：¬φ 的特征集 = 全积 G₂(x,…,y) − F_φ（G₄）；∧ 用 G₅。
- **有界存在量词（A4）**：∃u_k ∈ u_j φ 的特征集 = dom^m(受限积 G₃ 之后投影)——把 u_j 坐标限制进 φ 的计算集，再用 m 次 dom 折叠掉中间坐标。

(2) 是 (1) 的参数化版本：把其它变元钉在单点集 {a₀}×⋯×{a_i}×x×⋯ 上再投影。∎

**引理 2.3。** 下述概念在 KP 之上都等价于某个 Δ₀ 表达式，因而都是哥德尔运算可计算的：x = y、x = (y,z)、x 是传递集、(x,∈) 线性序、x 是序数/极限序数/自然数、x = ω、X = Y×Z、X = Y∪Z、X = Y−Z、u ∈ dom(X)、u ∈ rng(X)、X = dom(Y)、X 是函数、y = f(x)、g = f↾x 等。

证明全是直接的公式改写，例如「x 是传递集」= ∀u∈x (u ⊆ x) = ∀u∈x ∀v∈u (v ∈ x)（有界）。∎

反方向——每个哥德尔运算都可定义——需要一条新性质：

**定义 2.7（可替换性）。** n 元函数符号 F 具备**可替换性**，当且仅当在任何 Δ₀ 表达式中用 F 替换变元符号后仍是 Δ₀ 可表达的（不提升层次）。

**引理 2.4。** 1. 可替换性对复合封闭；2. F 可替换 ⟺ 每个含 F 的有界存在式可改写；3. ⟺ 每个含 F 的有界全称式可改写；4. F 可替换且 G(x,z̄) = {F(y,z̄) | y ∈ x}，则 G 可替换。

**引理 2.5（可定义性）。** 每个哥德尔集合运算 G(a₁,…,a_n)：
1. 关系 u ∈ G(a₁,…,a_n) 与一个 Δ₀ 表达式对等；
2. ∃u∈G、∀u∈G 与 Δ₀ 对等；
3. 等式 y = G(a₁,…,a_n) 与 Δ₀ 对等，从而 G 可在 KP 上依定义引进；
4. G 具备可替换性。

证明对复合复杂性归纳。基例是十个基本运算逐条验证——比如 G₁：u ∈ G₁(x,y) ↔ (u=x ∨ u=y)；∃u ∈ G₁(x,y) φ ↔ φ(x) ∨ φ(y)；y = G₁(x,y) ↔ ∀u∈y (u=x ∨ u=y) ∧ ∀u∈{x,y} (u ∈ y)——全都是有界量词。G₃、G₉、G₁₀ 的验证最长（要展开三元组的坐标），但模式相同。归纳步（B1）–（B10）逐个复合检查四个结论在「内层运算已具备」时保持。∎

合起来：**哥德尔运算 = 传递结构上「计算可定义集合」的代数完全集**。这就是把逻辑代数化的全部含义。

## 87.3 从运算到可定义：闭包定理

**定义 2.8。** M 关于**基本**哥德尔运算封闭：∀x,y ∈ M (G_i(x,y) ∈ M)（1≤i≤5）且 ∀x∈M (G_{5+i}(x) ∈ M)（1≤i≤5）；关于**全体**哥德尔运算封闭：任何（n+1）元哥德尔运算 G 都满足 ∀a₀,…,a_n ∈ M (G(a₀,…,a_n) ∈ M)；M 在哥德尔运算下的闭包 cl(M) 是包含 M 的最小封闭集合。

**引理 2.6（KP）。** 传递集合 M：基本封闭蕴含全封闭；闭包存在（十个运算都 Δ₀ 可定义，KP 的 Δ₀ 映像存在原理供出像集，递归定义定理供出闭包）。

**定理 2.3。** 关于哥德尔运算封闭的传递类 (M,∈) 是 Δ₀-分解原理的模型。

证明：Y = {u ∈ X | φ(p̄,u)}；由引理 2.2 取计算 G，则 Y = dom⋯dom(G(X,{p₁},…,{p_n}))，每一步都在 M 里。∎

**定理 2.4。** 对传递集合 M：𝒟(M) = cl(M ∪ [M]^{<ω} ∪ (𝒟(M) ∩ M))。

两个方向各有要害。⊆：φ 在 M 上的相对化 φ^M 是 Δ₀ 的（量词被 M 界定），由引理 2.2 算出 {a ∈ M | (M,∈) ⊨ φ[p̄,a]} = G(p̄,M)——定义子集是哥德尔项的值。⊇：由引理 2.5，哥德尔运算 Δ₀ 可定义且可替换，在 M 上求值与在 V 中求值一致（传递 + Δ₀ 绝对），于是项值落回 𝒟(M)。∎

**定理 2.5。** 传递类 M 是 ZF 的传递模型，当且仅当： M 关于哥德尔运算封闭； 具备**可覆盖性**：每个含于 M 的集合 X 都被某个 Y ∈ M 覆盖（X ⊆ Y）。

必要性：内模型对绝对运算封闭；X ⊆ V_α ∩ M 而 V_α ∩ M ∈ M。充分性：除分解原理外的公理照定理 2.2 验证（配覆盖性），分解原理对带 k 个量词的表达式做归纳——把无界量词逐步换成「被 M 中某个 Y 界定」的有界量词，覆盖性在每个归纳步供出这样的 Y；最后用定理 2.3 收尾。∎

## 87.4 简朴运算与 S-闭包

下一层精化来自 Jensen：把十个哥德尔运算重新组装成**十七个简朴二元运算**（定义 2.9 的 F₀,…,F₁₆），前十个是配对、无序对、并、差、积、像 F₅(x,y) = x[y]、dom、逐点像 F₇(x,y) = ⋃{x[z] | z ∈ y}、受限积 e(x,y)、对角 Δ(x,y)；后七个 F₁₀–F₁₆ 专为**保持传递性**与**三元组左右结合换向**而设（引理 2.7 逐条给出 KP 中的存在唯一性）。

**例 2.1。** 常函数 F(x) = ω 在 KP 上 Δ₀ 可定义（「y 是极限序数 ∧ ∀z∈y (z∪{z}∈y) ∧ 没有别的元素」），但**不是**简朴运算：简朴运算输出的秩相对输入只有有限增幅，而 rank(ω) = ω 对任何 x 都跳到无穷。可定义 ⊋ 简朴——但一元封闭之后差别消失（定理 2.6）。

**引理 2.11（映像引理）。** 对每个 i < 17，(x,y) ↦ F_i[[x×y]] 是简朴运算。

这是简朴运算清单设计的真正目的：把「F 在整个 x×y 上的像」保持为同一族的运算。证明是对每个 F_i 手工给出 W_i ⊆ (u×u)×(⋃⁴u) 的显式定义（十七段直接计算，正文从略——模式见 87.10 机器通道 `def_closure` 的补/并封闭）。对**单点闭包**情形：

**定义 2.12（S-运算）。** S₀(u) = ⋃_{i<17} F_i[[u×u]]，S(x) = S₀(x ∪ {x} ∪ ⋃x)，S_{n+1}(x) = S(S_n(x))，𝒥𝒫(x) = ⋃_{1≤n<ω} Sⁿ(x)。

**引理 2.13。** U 非空传递 ⟹ S₀(U)、S(U)、𝒥𝒫(U) 都传递。证明是逐条核对每个 F_i(a,b) ⊆ S₀(U)：a,b ∈ U ⟹ 各中间对象（有序对、三元组、坐标分量）都经 F₁₂–F₁₆ 的换向构造留在 S₀(U) 里。

**定理 2.6（KP）。** 对非空传递 M：𝒥𝒫(M) 简朴封闭；𝒥𝒫(M) 是 M ∪ [M]^{<ω} 的简朴闭包；𝒟(M) = {A | A ∈ 𝒥𝒫(M) 且 A ⊆ M}。

（证明参照定理 2.4 的两个方向；(3) 说明「一元简朴闭包之后，逻辑定义与代数计算给出同样的子集」。）

## 87.5 可构造性的复杂性与最小内模型

**引理 2.14 / 推论 2.2。** 「y = cl_J(x)」与「y = 𝒥𝒫(x)」在 KP 上是 Δ₁ 表达式；从而 (α, L_α) 的类函数可 Δ₁ 引进，特别地「x 是可构造集」（x ∈ L）是 **Σ₁** 概念：x ∈ L ↔ ∃α∃y (y = L_α ∧ x ∈ y)。

Σ₁——这就是「可构造」这个概念的逻辑复杂度下限。第 88 章 Jensen 组合原理将反复使用它。

**引理 2.15 / 定理 2.7 / 推论 2.3。** 对 KP 的任何内模型 M：L^M = L；特别地 (L_α)^L = L_α，L^L = L。可构造性在所有内模型之间绝对不变。

**定理 2.8（最小内模型定理）。**
1. ZF ⊢ (V=L)^L；
2. L ⊨ ZF + (V=L)；
3. M 是 ZF 的内模型 ⟹ L = L^M ⊆ M；
4. 「可构造」对 ZF 的所有内模型绝对。

证明骨架：L ⊨ ZF 是定理 2.2；(V=L)^L 由推论 2.3（L^L = L）；最小性来自 M 传递含序数 + 对 𝒥𝒫 封闭的归纳：L_α ⊆ M 对 α 归纳——后继步 𝒟(M) ∩ M ⊇ 简朴闭包成员（定理 2.6(3) 在 M 内应用）。∎

## 87.6 可构造集合之秩序

**定理 2.9（哥德尔）。** KP ⊢ L 上有一个 Σ₁ 可定义的秩序（全域良序）。

冯琦给出两个对等的证明，想法都是「比较两个集合**谁先被造出来**」。

**路线 A（计算序）**：对每个 α 递归定义 L_α 上的秩序 <_α，要求末端延伸（α < β 时 <_β 在 L_α 上与 <_α 一致，且新元素全部排后）。后继层的元素来自 Sⁿ(L_α) 的逐层生成，于是按（生成的步数 n，首次用到的运算指标 i，运算参数在 W_k 中的字典序）三元组排序；极限层取并。整个递归由 Σ₁ 表达式实现。

**路线 B（定义序，定义 2.13–2.17）**：先把变元与公式编上号（引理 2.16：位配对 R ⊆ ω×ω 给出 (ω,R) ≅ V_ω，全部语法对象落进 ω）；引理 2.17 把定义式标准化为恰好彰显 v₀,…,v_n。对非空传递 M：

- D(M,i,b̄) = {a ∈ M | (M,∈) ⊨ φ_i[a,b̄]}；
- n(A) = 定义出 A 的最小公式指标 i；
- W(M,R) = 𝒟(M) 上按（n(A)，参数的 R-字典序）排的秩序（引理 2.18：确是秩序）；
- <_L：先比出生层 min{β | x ∈ L_{β+1}}，同层用该层的 W(L_β, <_β)——递归定义，末端延伸由出生层比较自动保证（定义 2.14/2.15）。

细化版 <_L^**（定义 2.17）用引理 2.19（**定义标准式**：L_{α+1} 的每个成员都能用**序数参数** L_{γ₁},…,L_{γ_n} 定义——参数本身被更早的层解释）把参数侧也标准化，参数比较用序数有限序列的字典序 <^*（定义 2.16，引理 2.20：(Ord^{<ω},<^*) ≅ (Ord,<)）。三种成分全部 Σ₁ 可定义，合出 L 的全域 Σ₁ 秩序。∎

**推论。** V=L 蕴含 AC：每个集合 x ∈ L 被 <_L 限制良序化，而 <_L 是一个**可定义的**关系——选择函数无需任何外在选择地存在于 L 内部。机器形态：ST87 的 `Nat_Times_Nat.well_ord_L_r` 与 `L_implies_AC`（Isabelle/ZF Constructible 官方证明，第 13 章已引证过）。

<_L 的有限影子见 87.10 第三组：出生层优先、同层用码排序，验证了严格全序与末端延伸两条。

## 87.7 凝聚化引理

整个 GCH 证明的引擎在这里。

**定理 2.10（凝聚化引理）。** 设 α > ω 是极限序数，X ⊆ L_α，(X,∈) ≺₁ (L_α,∈)（Σ₁ 初等子结构）。则存在唯一的 π 与序数 β ≤ α：
1. π : (X,∈) ≅ (L_β,∈)；
2. π 在 X 的每个传递子集上是恒等；
3. ∀x ∈ X (π(x) ≤_L x)。

**证明。** α = ω 的情形：证 X = L_ω（π 取恒等）。对 m 归纳证 L_m ⊆ X：设 a ∈ L_{m+1}\L_m，a = {a₁,…,a_k} ⊆ L_m ⊆ X。公式

ψ(v₀,…,v_{k-1}) := ∃v_k (v₀∈v_k ∧ ⋯ ∧ v_{k-1}∈v_k ∧ ∀v_{k+1}∈v_k (v_{k+1}=v₀ ∨ ⋯ ∨ v_{k+1}=v_{k-1}))

在 (L_ω,∈) 中被 [a₁,…,a_k] 满足（见证 v_k = a），于是也被 (X,∈) 满足——见证 a_k ∈ X 满足同一解析式，但 a_k ∩ X 与 a_k ∩ L_ω 两边都等于 a（有限集合的元素全在 X 里），故 a ∈ X。

α > ω 的情形分四步：
1. (X,∈) 是外延结构：x ≠ y ∈ X 时，L_α 中有 z 见证 z ∈ x Δ y；「∃v₂ (v₂∈v₀ ⊕ v₂∈v₁)」是 Σ₁ 的，搬到 X 中有见证。
2. 由第一卷传递化定理（定理 I.1.97），存在传递 M 与唯一 π : (X,∈) ≅ (M,∈)，且 π 在 X 的传递子集上恒等（结论）。
3. M = L_β：β = M ∩ Ord 是极限序数（Σ₁ 表达式「v₀ ∈ Ord」在 M 与 L_α 间转移）；(V=L) 是 Π₂ 语句且 L_α ⊨ (V=L)，初等嵌入给 M ⊨ (V=L)；「x ∈ L」是 Σ₁ 的，对每个 a ∈ M 反解出 a ∈ (L)^M = L_β，得 M = L_β 且 β ≤ α。
4. 结论：若 x₀ 是「π(x₀) <_L x₀」的最小反例，则 π(x₀) ∈ L_β 有更小的原像 x₁ ∈ X 与之冲突——用 <_L 在所有 >ω 极限层上的 Σ₁ 定义一致性。∎

**引理 2.21。** α > ω 极限，X ⊆ L_α。令 M 为包含 X 的最小 Σ₁ 初等子结构（对每个 a ∈ L_α，把「定义出 a 的最低代价公式」的斯科伦函数值全塞进去；第 85 章塔尔斯基准则验证 M ≺₁ L_α）。则 X ⊆ M ⊆ L_α，M ⊆ N ⊆ L_α 对任何 N ≺₁ L_α 含 X 者成立，且 |M| = max(|X|, ℵ₀)。

## 87.8 一般连续统假设

**引理 2.22（V=L）。** κ 无穷基数，α < κ（或 α ⊆ κ）：α ∈ L_κ（相应地 α ∈ L_{κ⁺}）。

证明：取足够大的极限 λ 使 α ∈ L_λ。令 X = L_α ∪ {α}（传递集合），由引理 2.21 取最小 Σ₁ 初等子模型 M ⊇ X，|M| = max(|α|,ℵ₀) < κ。凝聚化给 π : M ≅ L_β，|β| = |L_β| = |M| < κ 故 β < κ；π 在传递子集 X 上恒等，特别地 π(α) = α，于是 α ∈ L_β ⊆ L_κ。子集情形（α ⊆ κ）把种子换成 L_κ ∪ {α}（仍是传递的：α 的元素是序数，全在 L_κ），同样论证给出 α ∈ L_{κ⁺}。∎

**定理 2.11（ZFC）。** V = L ⟹ GCH：对每个无穷基数 κ，2^κ = κ⁺。

**证明。** 设 A ⊆ κ。V=L 给 A ∈ L，取 λ 极限使 A ∈ L_λ。种子 X = L_κ ∪ {A} 是传递集合；引理 2.21 的 M ⊇ X 满足 |M| = κ；凝聚化给 M ≅ L_β，|β| = κ 故 β < κ⁺；π(A) = A（传递子集逐点恒等），于是

A ∈ L_β ⊆ L_{κ⁺}。

即 𝒫(κ) ⊆ L_{κ⁺}。配引理 2.1(6)：2^κ ≤ |L_{κ⁺}| = κ⁺；Cantor 给 κ⁺ ≤ 2^κ。∎

**推论 2.4。**
1. ZF ⊢ (GCH)^L；
2. Con(ZF) ⟹ Con(ZFC + GCH)。

(2) 是相对一致性的开山之作：若 ZF 有模型 M，则 L^M ⊨ ZFC + GCH，由完备性定理 ZFC + GCH 一致。哥德尔由此（加上第 90 章的力迫方向）得出 CH 独立于 ZFC 的完整图景。∎

注意证明对 κ 没有任何正则性/奇异性的区分——GCH 在 L 中对**一切**无穷基数同时成立，这正是「内模型方法」的威力：一条结构性假设（V=L）一举压平全部连续统函数。第 92 章（布尔值模型）将从外部重新审视这个层次。

## 87.9 机器通道：有限层上的 L

七通道共用的三组样品，全部运行在彻底有限的世界（V_n，n ≤ 4）里。

**第一组：L_n = V_n 的引擎（引理 2.1(3)）。** 有限载体上「带参数可定义」与「子集」无差别——每个子集 B 都由析取式 x = a₁ ∨ ⋯ ∨ x = a_k 定义。Lean 把这条引擎写成定理（`Ch87Constructible.lean`）：

```lean
/-- 由参数表生成析取式：x = a₁ ∨ ⋯ ∨ x = a_k。 -/
def disj : List α → Fm α
  | [] => .ff
  | a :: as => .or (.eq a) (disj as)

/-- 引理 2.1(3) 的引擎：有限载体 L 的每一个子集都由一个带参数的公式定义。 -/
theorem finite_definable (mem : α → α → Prop) (L B : List α) :
    ∃ φ : Fm α, ∀ x, x ∈ L → (sat mem φ x ↔ x ∈ B) :=
  ⟨disj B, fun _ _ => sat_disj mem B _⟩
```

公式语言 `Fm` 只含等式原子、属于原子与布尔连接词——对有限载体已足够。Coq 与 Agda 通道证同一条定理（`finite_definable` / `definable→`、`definable←`），Agda 版还把 filter 成员刻画（`∈-filter₁/₂`）手卷了一遍；层次单调性 `Lh_mono` 在 Lean 与 Coq 里都是「归纳在大端」的三行证明。Isabelle 通道走官方锚点：`Lset_succ`（L_{α+1} = DPow(L_α)，正是定义 2.1(2)）与 `trans_M_subset_DPow`：

```isabelle
lemma trans_M_subset_DPow:
  assumes tr: "Transset(M)"
  shows "M ⊆ DPow(M)"
proof (rule subsetI)
  fix x assume xM: "x ∈ M"
  from tr have un: "⋃(M) ⊆ M" by (simp add: Transset_iff_Union_subset)
  have xsub: "x ⊆ M"
  proof (rule subsetI)
    fix y assume yx: "y ∈ x"
    from xM have hx: "x ⊆ ⋃(M)" by (rule Union_upper)
    from hx yx have hy: "y ∈ ⋃(M)" by (rule subsetD)
    from un hy show "y ∈ M" by (rule subsetD)
  qed
  from xM xsub show "x ∈ DPow(M)" by (rule elem_subset_in_DPow)
qed
```

这正是引理 1.15(1) 的成员形态：传递集合的每个成员 x 都是（以 x 为参数）自己的可定义子集的元素——层次增长的发动机。计算通道把同一引擎跑成数字：Python/Julia 的 `def_closure` 从 ∅、全集与单点出发对补与并封闭，在 V_3（4 个元素）上恰好达到 16 = 2⁴ 个子集；Prolog 的 `all_subsets_definable` 用 `ext_disj` 逐对核对全部 16 个子集。

**第二组：公式可数 vs 子集更多的对角线。** 把深度 ≤ 1、参数取自 4 元载体的公式排成序列（原子 + 否定 + 析取，共 120 个），对角线集合 D 让第 k 个位置恰好躲开第 k 个公式：

```coq
(* 对角线集合：第 k 个位置上的元素 x 恰好躲开第 k 个公式的扩张。 *)
Definition D : list nat :=
  filter (fun x => negb (satb Nat.eqb memF (nth x Fs fff) x)) L4.

Theorem diagonal : forall j, In j L4 -> D <> ext Nat.eqb memF L4 (nth j Fs fff).
```

Coq 的 `diagonal` 是纯逻辑证明：无论第 j 个公式在 j 处取真取假，D = ext(F_j) 都在 j 处自相矛盾——Agda 版（`diagonal`，经 `Bool-elim` 分派到 `contra-true`/`contra-false`）与 Python/Julia 的数值实验（D = (1,2,3)，与全部 120 个扩张在配对位置互异）交叉印证。这是 |L_{ω+1}| = ℵ₀ < 2^{ℵ₀} = |V_{ω+1}| 在有限尺度的全部内容：**把公式排成序列的任何尝试都躲不开对角集合**。有限载体上深度 1 已覆盖全部子集（L_n = V_n），无穷载体上缺口永不闭合——两组实验合起来正是引理 2.1(3) 与 (6) 的一体两面。

**第三组：<_L 典范秩序的出生层与末端延伸。** Python/Julia 按（出生层，最小定义码）给 L_4 排出 16 元秩序，数值验证三分性、传递性与末端延伸——L_4 序限制在 L_3 上与 L_3 自身的秩序逐项一致，这就是定义 2.14(b) 的要求：

```prolog
% 末端延伸（定义 2.14(b)）：L_4 序限制在 L_3 上 = L_3 序。
orders_agree(NBig, NSmall) :-
    level_order(NBig, Big),
    vlevel(NSmall, Ln),
    findall(X, (member(X, Big), member(X, Ln)), Restricted),
    level_order(NSmall, Small),
    Restricted == Small.
```

Prolog 还做了一个凝聚化的影子实验：<_L 的后继函数是可定义的（斯科伦函数的最小样品），单点种子在其下的闭包吞下整个 L_3——引理 2.21「初等闭包把小集合撑满」在 4 元世界的形态。

## 87.11 这一章留下了什么

可构造层次从唯一的集合运算 𝒟 生长：L_{α+1} = 𝒟(L_α)。有限层与 V 完全重合，ω 层之后「公式可数、子集不可数」的缺口把两条层次永远分开。十个哥德尔集合运算是可定义性的代数完全集（引理 2.2 与 2.5 互为逆命题；定理 2.4 把闭包与 𝒟 划等号），十七个简朴运算进一步把「代数化」打磨成保持传递、映像封闭的形状。V=L 在 L 中成立，且 L 是 ZF 的最小内模型：一切内模型都包含它、都同意「谁可构造」。

L 带 Σ₁ 可定义的全域秩序 <_L（定理 2.9），出生层比较 + 最小定义码，末端延伸。凝聚化引理（定理 2.10）是 L 的刚性：Σ₁ 初等子结构坍缩之后**还是 L 的某一层**。配上「可构造是 Σ₁ 的」与 |L_α| = |α|，凝聚化把每个 A ⊆ κ 钉进 L_{κ⁺}，GCH 在 L 中无差别地对一切无穷基数成立（定理 2.11），相对一致性 Con(ZF) → Con(ZFC + GCH) 随之落地。
