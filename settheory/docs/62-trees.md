# 62 · 树：有根树、二叉树与生成树

> 松鼠数学（squirrel math）——分支结构无处不在：文件夹、族谱、
> 组织架构图、语法分析树、推理树。本章提炼 Makinson 第 7 章：
> 有根树的显式与递归定义（新叶法/新根法）、标记与有序树、
> Łukasiewicz 的无括号记法、二叉搜索树的搜索与插入算法、
> 无根树的六等价刻画（含全书最精巧的极小连通性证明）。
> 它是 23/26 章 Suslin/Aronszajn 树的有限乡亲，也是 63 章公式
> 语法树的地质基础。

## 62.1 第一棵树

书中的 15 节点例子（根 a；a 的孩子 b,c；b 的孩子 d；d 的孩子
i,j,k；c 的孩子 e,f,g,h；i 的孩子 m；k 的孩子 n；h 的孩子 l）供
"动手术"训练（Exercise 7.1）——每个判断都直击定义：

- **叶子/分支**：8 个叶子（m,j,n,o,e,f,g,l）对应 8 条分支
  （分支 = 根到叶的**整条**路径）；(b,d,i) 不起于根、(a,c,h) 不
  达于叶、(a,b,k,n) 跳过了 d——都不是分支。
- **链长 = 节点数 − 1**；最短分支链长 2、最长 4。
- **删节点 m 连边一起删**仍是树；单独删任何一个都不再是树。
- **加边 m→n 或 c→l**：目标节点会有两个父——不是树。
- **加孤立点 p**：不可达；**加 b→p**：是树；**加 p→b**：p 不可达
  且当不了新根；**加 p→a**：是树——**新根 p**。

## 62.2 有根树的两种定义

**显式定义**：有限有向图 (G,R)（G 集 + R 二元关系）是有根树，
若 (a) G 空，或 (b) 存在 a ∈ G（**根**）使 (i) 每个 x ≠ a 有**唯一**
路径从 a 到 x，(ii) 无 a 到 a 的路径。路径 = 有限序列 a₀,…,aₙ
（n ≥ 1，相邻有 R-关系，**不要求元素互异**——圈与环在一般图里
是路径，但树性将排除它们）。

五条基本性质，全部反证（书给全文）：

1. **R 无圈**（acyclic）：a 到 x 的唯一路径 + x 到自身的圈拼出
   更长的第二条路径——矛盾。
2. **根唯一**：两根互达拼出根到自身的路径。
3. **根无父**：父的父链闭合成根的圈。
4. **非根节点恰一父**：两父给两条根到该点的路径。
5. **分叉的路径不再相遇**：相遇点将有两父。

**高度**的两种口径：link-height（根为 0）与 node-height（根为 1），
相差 1。n ≥ 2 个节点的树：最大高度 = 单链（n−1 链 / n 节点）、
最小 = 根带 n−1 个孩子（1 链 / 2 节点）。

**递归定义两式**（59 章结构递归的主场应用）：

- **新叶法**（画树的手势）：基——空树与单点树；步——取已有
  节点 b 与新元素 x，连 b→x，根不变。
- **新根法**（计算机的宠爱）：基同；步——取**两两不交**的有限
  树族与新鲜元素 a，以 a 为新根连接诸根。诸 Ti 称原树的**直接
  子树**。不交性与新鲜性缺一不可。

**n − 1 条边**用两种递归各证一遍（Exercise 7.2.2）：新叶法——
每步节点、边各 +1；新根法——节点 (Σnᵢ)+1，边 (Σlᵢ)+m，归纳
假设 nᵢ = lᵢ+1 恰好闭合。∎

## 62.3 树上作业：标记与有序

**树长在哪**：家族树有陷阱（人有两个父母、远亲结合使分支重聚
——男性单系才是树）；文件夹系统、组织架构图、**语法分析树**
（自然语言 parse、程序与公式的 syntactic tree）。

**标记树**：树 + 函数 k : T → L（可偏、**可非单射**！）——节点是
挂标签的钩子。算术表达式 (5+(2·x))−((y−3)+(2+x)) 的分解树里
两个节点都标 2、两个都标 x：**节点身份 ≠ 标签值**（Alice Box 的
关键一课——与 56 章"{8} ≠ 8"一脉相承）。压缩标法：内部节点只
标主运算符。**求值 = 爬树**：自叶向根，先算孩子再算父（x=4,
y=7 代入后逐层归约）。逻辑公式 (p↔(q∨r))→((s∧t)↔(q↔r)) 的
分解树与算术例**同一棵有序树**只换标签——语法结构的同构。

**有序树**：每个节点的孩子排成线性序（从左到右书写约定）。
镜像树与原树作为有序树**不同**、作为无序树相同。

## 62.4 无括号记法：Łukasiewicz 的妙计

59.4.2 的伏笔兑现：**把运算符写在参数之前**，括号彻底冗余——
**前缀/波兰记法**：(5+(2·x))−((y−3)+(2+x)) 写作
`− +5·2x +−y3 +2x`。解码法：**从叶到根**建分解树。f(x,y) 记号
本就是前缀思想的残留（括号逗号只是给肉眼用的）。**后缀/逆波兰**
反之（运算符在参数后），范畴论者零星使用；带 arity 标记可推广
到任意元运算。Principia 的点记法（p ⊃ .q ∨ r: ⊃ :s ∧ t . ⊃ .q ⊃ r）
是死掉的技术路线。练习：(p→¬q)→(¬r↔(s∧¬p)) 的前缀
`→→p¬q↔¬r∧s¬p` 与后缀 `pq¬→r¬sp¬∧↔→`——63 章的公式将在
此再次服役。

## 62.5 二叉树与二叉搜索树

**二叉树**：每节点至多两孩子，且孩子带 left/right 标记——
**独子也分左右**（画图时用斜向而非垂直连线表达）。四图判读：
无左右标记的独子不是二叉树；同形而左右互换是**不同的**二叉树。

**二叉搜索树 BST**：标签入线性序 <（且单射）的二叉树，满足每个
节点 **大于其左子树的全部节点**、**小于其右子树的全部节点**——
不只是直接孩子！四图判读中只有 (d) 是 BST（(a) 三处违规、(b) 一
处、(c) 标签非单射）。

**搜索算法**（递归三分支）：x 与根比，等则 yes；x < 根则入左子树
（无左则 no）；x > 根入右子树。搜 6：6>5 → 6<7 → 6=6 ✓；搜 8：
8>5 → 8>7 → 8<10 → 8<9 且 9 无左 → no。**插入**：搜索失败处
挂新叶（8 挂为 9 的左孩子）。**从表构造**：九词（this, is, how,
to, construct, a, binary, search, tree）按字典序逐词插入；**同一批
词换序则树形不同**（已序的表产生右斜链——高度=表长，最坏情形）。
理想是**满平衡**（每分支等长，节点数 2^h−1），一般能做到相邻
分支差至多 1。

## 62.6 无根树

**定义**：有根树 (T,R) 的链接关系 R 取**对称闭包** S = R ∪ R⁻¹
（删去箭头）。术语换装：节点→**顶点**、有序对链接→无序对
**边** {x,y}。Cayley 1857：饱和烃 CₙH₂ₙ₊₂ 的同分异构体都是
（无根）树——化学是图论的产房。Porphyry 之树（公元三世纪）则
是有根树的古代先声。

**连通性**：任两顶点有 S-路径——三分支证明（根=x、根=y、根
在别处时两段 R-路径拼接）。

**极小连通性**（**全书最精巧的证明**，值得逐行啃）：删去任一条
边 (x,y) ∈ S 即不连通。反设删后仍有从根 a 到 y 的 S-路径，取最短
者（wlog——嵌套在第一层反证内的 wlog）；其末段分析迫使全程
沿 R-逆向爬回根——与"根无入路径"矛盾。Logic Box 点出两个
新逻辑特征：**嵌套反证**（reductio 套 reductio）与 **wlog**（不失
一般性——记号经济的合法手段）。

**简单圈**：无重复**边**的圈（顶点可重复）。无根树充满平凡圈
（x,y,x——对称性使然），但**没有简单圈**（证明：三情形反证，
情形三里"两父唯一性"逼出更短简单圈）。更强的对偶：**极大无
简单圈**——任添一条边必生简单圈。

**六等价刻画**（书列而不证，任一可作定义）：对称闭包性、极小
连通、连通 + n−1 边、连通 + 无简单圈、极大无简单圈、无简单圈
+ n−1 边。注意"**n−1 条边**从有根树平移过来：链接与边之间有
一一对应（Exercise 7.6.1）。

**生成树**：连通关系的极小连通子关系。算法思想：逐步删去简单
圈中的一条边（避免破坏连通）直至无简单圈——网络协议的
spanning tree protocol 是它的工业化身。

## 62.7 机器通道

mathlib 有 `SimpleGraph.IsTree`（`Mathlib.Combinatorics.SimpleGraph.
Trees.Basic`）官方件；本章走轻量自建 + 计算剧场：

```lean
-- examples/lean/Settheory/Ch62Trees.lean（节选）
-- 二叉搜索树的搜索：三分支递归的直译
inductive BTree | leaf | node : BTree → Nat → BTree → BTree

def search (t : BTree) (x : Nat) : Bool :=
  match t with
  | leaf => false
  | node l a r =>
      if x = a then true
      else if x < a then search l x
      else search r x
```

Isabelle/ZF 侧用 ZF 的关系语言定义树性（unique path from root）
与 n−1 边公式（结构归纳由 59 章 nat_induct 承载）。Coq/Agda 的
归纳类型就是"新根法递归定义"的原生化身——树在类型论里**就是**
数据类型。Julia/Python 剧场：九词 BST 构造、有序/无序表的两
种树形对比、表达式树求值（x=4,y=7）、波兰/逆波兰记法的栈式
求值器。Prolog 的树谓词天生（parent/child 事实 + 递归遍历）。

## 62.8 收束

树 = "分叉不重聚"的拓扑。有根版给计算以层级（递归的结构化身），
无根版给网络以骨架（生成树）。63 章的公式语法树在此奠基；23/26
章的无穷树（Suslin/Aronszajn）是这片有限森林在不可数世界里的
两株奇木；65 章的推导树将把"证明"本身变成树。
