# 61 · 概率：有限空间、条件、辛普森与贝叶斯

> 概率论是"把计数变成算命"的学问。本章提炼 Makinson 第 6 章：
> 有限样本空间上的分布与概率函数、八条基本性质、两种哲学解读、
> 条件概率（比值的定义与三个 Alice 陷阱）、辛普森悖论的完整数字、
> 独立性、贝叶斯法则与基础率谬误、期望与赌局。全程只做**离散**
> 情形——测度论的连续世界留给 29 章；这里的每个定义都是那边的
> 特例。

## 61.1 有限概率空间

**样本空间** S：任意非空有限集（名字只是声明意图）。**概率分布**：
p : S → [0,1] 满足 Σp(s) = 1。判例五则（S = {a..e}）：值和 1.5 的
不是；允许零值的是；负值的不行；全部 0.2 的是——**均匀分布**
p(s) = 1/n，恰有一个。**切记均匀是特例**——奢谈"等可能"是初学
者的第一原罪。

分布**提升**到幂集：p⁺(A) = Σ{s∈A} p(s)（A = ∅ 时取 0）——
**概率函数**。序对 (S, p⁺) 称**概率空间**。术语对照表（书表 6.1）
值得贴在墙上：样本点 = 元素、事件 = 子集、初等事件 = 单点集、
零事件 = ∅、**互斥 = 不交**、"实验" = 被建模的情境、随机变量
= （收益）函数 f : S → ℝ。传统语言与集合语言全靠这张表互译。

八条基本性质（Exercise 6.1.2 (1) 的完整清单，证明全是一行）：
p(∅) = 0；p(S) = 1；**单调性** A ⊆ B ⟹ p(A) ≤ p(B)；**容斥**
p(A∪B) = p(A)+p(B)−p(A∩B)（60.6 的直译）；不交加法；**补律**
p(−A) = 1−p(A)；交版容斥；A∪B = S 时的 Bonferroni 型下界。
另一组三则：p(A∩B) ≤ min(p(A),p(B))；p(B) = 1 时 p(A) = p(A∩B)
（概率 1 的事件被"吸收"）；以及 p(A∩B) 与 p(A)·p(B) 的三种
关系都可能——为 61.5 的独立性埋伏笔。

## 61.2 哲学与应用的两难

**主观派**：概率 = 理性主体的相信度（对稀缺、独特事件更顺手——
核战概率？）。**客观派/频率派**：概率 = 长程频率（对数据充足的
事件更顺手——保险、药品检验）。两派各有深坑（"理性主体的相信
度"还主观吗？"相似情境"如何界定？"长期我们都死了"）。惊人
的事实是：**不解决哲学问题，数学与应用照样全速前进**。

应用是艺术：本节最重要的警告——样本空间的选取本身就是建模
决定，"任意选取"的语言把**比例**升级为**概率**；数据不足时只能
求上下界（书中作家协会的 p(N|S) ≤ 0.2 的迂回推演是精彩一例）；
隐含的独立性假设必须显式声明，否则是危险的编造。

## 61.3 条件概率

骰子对：已知和为 5（事件 B），问至少一枚是 3（事件 A）——直觉
是把样本空间缩到 B 再数比例。**比值定义**把这固定下来：

    p(A|B) = p(A∩B)/p(B)    （p(B) ≠ 0 时；p(B) = 0 时**未定义**）

例中 p(A|B) = (2/36)/(4/36) = 1/2 > 11/36 = p(A)——**条件化可以
升高概率**。四个必踩的坑（Alice Box 三连）：

1. **p(A|B) ≠ p(B|A)**：本例 p(B|A) = 2/11。与 a→b ≠ b→a、
   X ⊆ Y ≠ Y ⊆ X 同构的混淆，日常话语里比比皆是——检察方的
   "作案概率"与律师的"有罪概率"之争常源于此。
2. **除零**：p(B) = 0 时未定义（偏函数！）。补救三案：留空
  （比值定义）、填哑值 1、或"修正派"条件化——作者选留空。
3. **A|B 不是集合**：它只是有序对 (A,B) 的速记；p(A|(B|C)) 与
   p((A|B)|C) 均无意义。**条件化的迭代**走函数路线：p_B(A) :=
   p(A|B) 本身是 S 上的概率函数（**条件化**），且 (p_B)_C =
   p_{B∩C} = (p_C)_B——**迭代坍缩、次序无关**（Exercise 6.4.2 (5)
   的三行验证）。
4. p(B) = 0 而基本条件概率式仍成立的各种"极限检查"——作者的
   方法论：**先大胆算，回头逐条补极限情形**。

作家协会数字例（60% 小说 N、30% 诗 P、10% both）：p(N|P) = 1/3
而 p(P|N) = 1/6；S ⊆ P 时 p(P|S) = 1；N∩P∩L = ∅ 时条件概率
未定义——**数据可以"未定义"你的问题**。

## 61.4 辛普森悖论

两性两系的招聘数据可以：**每个系内女性录用率都更高**，而**全校
女性录用率更低**——两方向同时成立！书中的诉讼数字（26 名申请
者）：

| | 计算机系 | 数学系 | 合计 |
|---|---|---|---|
| 女 | 2/8 = 0.25 | 4/5 = 0.80 | 6/13 ≈ 0.46 |
| 男 | 1/5 = 0.20 | 6/8 = 0.75 | 7/13 ≈ 0.54 |

分系不等式 0.25 > 0.20 与 0.80 > 0.75 都成立，合计 6/13 < 7/13
反转。**这不是悖论而是算术**：a₁/x₁ > a₂/x₂ 且 b₁/y₁ > b₂/y₂
不保证 (a₁+b₁)/(x₁+y₁) > (a₂+b₂)/(x₂+y₂)——加权平均的权重
（各系申请人数）可以偏到翻转结论。教训：**直觉在概率里不是
可靠向导，专家也会翻车**；聚合数据与分层数据讲的可以是两个
故事。机器通道用 Fraction 精确复算全部八个比值。

## 61.5 独立性

两个等价定义：**概念版** p(A) = p(A|B)（条件化不改变 A 的概率；
p(B) = 0 的极限情形也算独立）；**乘法版** p(A∩B) = p(A)·p(B)。
等价性一行（两边乘 p(B)）。独立性是**关于 p 的事实**而非事件
的内在属性——同一对事件在一个分布下独立、在另一个下不独立。
三骰子例（Exercise 6.9 (1)(b) 的 5/28）演示独立性假设如何在
复合实验里成为乘法规则的通行证。

## 61.6 贝叶斯法则

从 p(A|B)·p(B) = p(A∩B) = p(B|A)·p(A) 立得：

    p(A|B) = p(B|A)·p(A) / p(B)

再由全概率展开 p(B) = p(B|A)·p(A) + p(B|−A)·p(−A) 得**第二形**。
**基础率谬误**：Devlin 癌症检查——p(C) = 0.01、无假阴性、
20% 假阳性。直觉（丢掉基础率）给 0.83；全公式给 **0.05**——
差 16 倍！先验低时，阳性证据远不如想象中硬。HIV 例：先验
0.15 → 后验 0.841；先验 0.60 → 0.978——**先验抬高，后验跟着
抬高**。接线员例（Alfred/Betty/Clarice 33/37/30%、解决率
60/70/90%）：成功解决的问题由 Clarice 处理的概率
0.9·0.3/(0.6·0.33+0.7·0.37+0.9·0.3) ≈ 0.371——**分划版贝叶斯**
p(Aᵢ|B) = p(B|Aᵢ)p(Aᵢ)/Σⱼ p(B|Aⱼ)p(Aⱼ)，57.6 节的划分在此
服役。

贝叶斯派 vs 反对派的争端在**应用的条件**而非数学——规则本身
是可证事实；"garbage in, garbage out" 是两条路线共同的座右铭。

## 61.7 期望

**收益函数** f : S → ℝ（传统名"随机变量"——其实是确定性的
函数！）、分布 p：**期望** μ(f,p) = Σ_{s∈S} f(s)·p(s)。
三马例：p = (0.1, 0.3, 0.6)、f = (12, −1, −1)：μ = 1.2 − 0.3 −
0.6 = **0.3** > 0——"值得赌"。等价形式 μ = Σ_{x∈f(S)} x·p(f⁻¹(x))
（对收益值而非样本点求和——57 章的集值逆在此营业）。期望
≠ 平均（本例平均 = 10/3）：概率加权与简单平均只在**均匀分布**
下重合。

**Alice 的冷汗**：只赌一次，0.9 概率输 1 元——期望为正也不
诱人！Hatter：重复多次则结果高概率接近期望（大数定律的诺言），
**但须有足够本金熬过初期的连输**。期望的数学一行，应用的
陷阱一坑接一坑。

## 61.9 收束

有限概率 = 计数 + 归一化；条件概率 = 比值；独立性 = 乘法；
贝叶斯 = 换方向；期望 = 加权和。五个定义撑起整个应用宇宙，
而每个定义脚下都是 56-60 章的集合—函数—计数三件套。29 章
的测度论是这套结构的无穷连续升级；44-45 章的可测性与决定性
则在更高处回望此地。
