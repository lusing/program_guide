# 18 · 力迫与布尔值模型 V^B

> 布尔值模型把"真"从 {0,1} 解放到整个完备布尔代数——
> 泛型超滤再把 B 切割回两值，但切割的方式由 G 决定。
> ——力迫的代数灵魂

本章覆盖 Jech §18：布尔值模型 V^B 的构造、布尔值 ‖φ‖ 的
归纳定义 (18.11)-(18.14)、外延性与满性（引理 18.2-18.6）、
力迫关系 (18.26)、力迫定理 (18.30)、泛型模型 M[G]。

## 18.1 V^B 层级

    V^B_0 = ∅
    V^B_{α+1} = {x : dom(x) ⊆ V^B_α, ran(x) ⊆ B}
    V^B_λ = ⋃_{α<λ} V^B_α

V^B 的元素是**布尔值函数**：每个"成员" t ∈ dom(x) 被赋以
布尔值 x(t) ∈ B——x 以"成员 t 的隶属度为 x(t)"的方式编码。

## 18.2 布尔值的归纳定义

对 x, y ∈ V^B，按秩对 (ρ(x), ρ(y)) 归纳：

    ‖x ∈ y‖ = ⋁_{t ∈ dom(y)} (‖x = t‖ ⇒ y(t))         (18.11)
    ‖x ⊆ y‖ = ⋀_{t ∈ dom(x)} (x(t) ⇒ ‖t ∈ y‖)        (18.12)
    ‖x = y‖ = ‖x ⊆ y‖ · ‖y ⊆ x‖                     (18.14)

Coq（`examples/coq/Ch18_vb.v`）把这三条做成**抽象接口下的
定义骨架**：VB 是 V^B 的抽象类型，dom_list/yval/eq_val/mem_val
是接口函数，bVal_mem/bVal_sub/bVal_eq 逐字翻译 (18.11)-(18.14)。

Lean（`examples/lean/Settheory/Ch18Forcing.lean`）给出力迫关系：

```lean
def Forces {B : Type} [CompleteBooleanAlgebra B]
    (p : B) (val : B) : Prop := p ≤ val
```

——**力迫 = 序比较**（(18.26) 的机器化：p ⊩ φ ⟺ e(p) ≤ ‖φ‖）。

Julia/Python（`18_vb.jl` / `18_vb.py`）在三值布尔代数 {0,½,1}
上做**可计算演示**：‖x ∈ y‖ 的 ⋁ 计算、‖x ⊆ y‖ 的 ⋀、
½⇒0=½ / 0⇒½=1 的直觉、泛型超滤的两个选择（½∈G vs ½∉G）
对应 M[G] ⊨ φ 的两种真值。Agda（`Ch18_vb.agda`）给出 B3 数据
类型与 Forces 关系（refl 验证 ½≤1 但 1≰½）。Prolog（`18_vb.pl`）
做三值代数的力迫规则推理（bsup/bneg/bimp 的子句 + forces 谓词）。

## 18.3 V^B 的基本性质

**引理 18.2** ‖x = x‖ = 1（自反性——对 ρ(x) 归纳）。
**引理 18.3** 布尔值的等式与 ∈ 的传递（三方归纳）。
**引理 18.4** V^B 满足外延性 (18.7)。
**引理 18.5-18.6** V^B 满（(18.3) 的存在见证可达）——
    **这是唯一用到 AC 的地方**（极大不相容族的选择）。

## 18.4 力迫关系

给定偏序 (P, <)，B = r.o.(P)，e : P → B-{0} 典范嵌入。
力迫语言 = V^B 上的集合论语言。

    p ⊩ φ ⟺ e(p) ≤ ‖φ‖    (18.26)

**引理 18.7** (a) 单调性（q ≤ p 增强）；(b) 无矛盾
（p 不同时 ⊩ φ 与 ⊩ ¬φ）；(c) 决定性（每个 p 可被延伸到
decide φ 的 q）。

**引理 18.8** 的分解规则：
- p ⊩ ¬φ ⟺ 无 q ≤ p 使 q ⊩ φ
- p ⊩ φ∧ψ ⟺ p ⊩ φ 且 p ⊩ ψ
- p ⊩ ∃xφ ⟺ ∀q≤p ∃r≤q ∃a, r ⊩ φ(a)

## 18.5 力迫定理

**定理 40**（完整证明）：

    M[G] ⊨ φ(x₁,...,xₙ) ⟺ ‖φ(x̄₁,...,x̄ₙ)‖ ∈ G'  (18.30)

其中 x̄ᵢ 是 xᵢ 的名字，G' 是 G 诱导的 B 上泛型超滤。

证明分两步：**引理 18.9**（原子情形——对 (ρ(x),ρ(y)) 归纳，
G-解释 i_G 的定义 (18.28) 使 ∈ 与 = 的布尔值被 G' 精确切割）
+ 对公式复杂度归纳（联结词由超滤性质；量词由满性）。

**G-解释** (18.28)：

    i_G(x) = {i_G(y) : (∃p∈G) e(p) ≤ x(y)}

M[G] = {i_G(x) : x ∈ M^B}——传递模型，含 M 与 G。

## 18.6 ZFC 在 V^B 中的有效性

定理 39 的证明要点：M[G] ⊨ ZFC——分离（V^B 的定义层封闭）、
替换（满性）、选择（M 内的选择函数 + 布尔值保持）。完整
细节在 Jech 正文 §18 后半与 §20。
