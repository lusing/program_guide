# 129 · 等势与可数

> 要知道 X 的元素个数，最简单的办法是"数一数"——可在 X 与 N 的
> 前段之间建立一一对应。可一个自然的问题是：N 总是够的吗？
> ——原书 3.3 节的开场

本章覆盖书 3.3 节（PDF 56-61 页）：等势——康托探索无穷的出发点；
康托-伯恩斯坦定理的完整证明；有穷/无穷/戴德金有穷的等价刻画；
可数集的代数（并、积、有穷子集全可数）。下一章把数系扩展到 ℤ、ℚ、ℝ
后，本章的机制立刻兑现红利。

## 129.1 等势：把"数数"抽象化

> **定义（书 3.3.1）**　X 与 Y **等势**（|X| = |Y|），若存在以 X
> 为定义域、Y 为值域的双射。|X| ≤ |Y|：存在 X 到 Y 的单射（等价
> 地，|X| = |Z| 对某个 Z ⊆ Y）。|X| < |Y|：|X| ≤ |Y| 且
> |X| ≠ |Y|。

练习 3.3.2 的坑要小心：X ~ Y ⟺ |X|=|Y| 是"等价关系"——**自反、
对称、传递都对**（恒等、逆、复合），但"等价类"的说法有陷阱：把
X 的基数定义为等价类 [X]~，罗素式的定义会让 [X]~ 对所有集合而言
**是真类**（与一切等势的集合搜集太多了）。这个困难要到第 137 章
（基数的正式定义：取每个等价类中最小的序数——Hartogs/von Neumann
方案）才解决。此刻我们只用 ≼ 与 = 当**记号**，靠下面的定理保证
它们表现良好。

> **≤ 的自反与传递**是显然的（恒等、复合）；**反对称性**是大定理：

> **康托-伯恩斯坦定理（书 3.3.3）**　若 |X| ≤ |Y| 且 |Y| ≤ |X|，
> 则 |X| = |Y|。

**证明**（书的路线）。设 f : X → Y、g : Y → X 都是单射。则
g[f[X]] ⊆ g[Y] ⊆ X，而 |g[f[X]]| = |X|、|g[Y]| = |Y|。于是化归为
核心引理：

> **引理**　若 A' ⊆ B ⊆ A 且 |A'| = |A|，则 |B| = |A|。

设 h : A → A' 是双射。递归定义两个集合序列（第 128 章递归定理的
集合值版！）：

    A₀ = A, B₀ = B；A_{n+1} = h[A_n]，B_{n+1} = h[B_n]。

由 A₁ ⊆ B₀ ⊆ A₀ 归纳得 A_{n+1} ⊆ B_n ⊆ A_n。令 C_n = A_n − B_n，
C = ⋃ₙ C_n。关键的账：

    h[C_n] = h[A_n] − h[B_n] = A_{n+1} − B_{n+1} = C_{n+1}，
    故 h[C] = ⋃ₙ₌₁ C_n = C − C₀。

现在定义 j : A → B 分片：

    j(a) = h(a)（若 a ∈ C）；j(a) = a（若 a ∈ A − C）。

j 单：h 单、恒等单、两段像 h[C] 与 D = A−C 不交。j 满：值域 =
h[C] ∪ D = (C − C₀) ∪ (A − C) = A − C₀ = A − (A − B) = B。∎

这个证明是**能行的**——Julia 单元（`examples/julia/129_equipollence.jl`）
把它当作算法运行。由于引理的场景本质上无穷（有限时 |A'|=|A| 与
A'⊆A 强制 A'=A=B），演示用 ℤ 的有限窗口：A = ℤ、B = 2ℤ ∪ {1}、
h(x) = 2x，窗口 [−64,64] 只截断观察范围：

```julia
function csb_layers(depth)
    An = Set(-W:W)
    Bn = Set(x for x in -W:W if is_B(x))
    C = Set{Int}()
    for _ in 1:depth
        union!(C, setdiff(An, Bn))
        An = Set(filter(x -> -W <= x <= W, h.(collect(An))))
        Bn = Set(filter(x -> -W <= x <= W, h.(collect(Bn))))
    end
    C
end

C7 = csb_layers(7)
C8 = csb_layers(8)
@assert C7 == C8                                   # 交替序列稳定：C 不再增长
```

机器揭示：交替序列在深度 7 处**稳定**（每层把偶部再减半，7 层后
差集为空）。分片函数 j 的单射性、D ⊆ B、内窗满射逐条断言——
书上的等式链 `h[C] = C − C₀` 在代码里变成 `imgC ∩ D = ∅` 的
集合断言。

## 129.2 有穷与无穷：四种定义一台戏

> **定义（书 3.3.4）**　X **有穷**，若 |X| = n 对某 n ∈ N；否则
> **无穷**；**可数**（可数无穷），若 |X| = |N|；至多可数 = 有穷或
> 可数；不可数 = 无穷且不可数。

**鸽笼原理（书 3.3.5）**　不存在 n 到其真子集的双射。

证明对 n 归纳，两种情形（n ∈ X 与 n ∉ X）都把 (n+1) 上的双射
改造成 n 上的双射到真子集——第二种情形要把 f(k)=n 的那个 k 与
n 对调（构造 g 的换位技巧）。∎ 于是：

> **命题（书 3.3.11）**　以下等价：(1) X 有穷；(2) X 上有线序使
> 每个非空子集有最大最小元；(3) X 的每个非空子集族有 ⊆-极大元；
> (4) X **戴德金有穷**：不存在 X 到其真子集的双射。

(1)→(4) 是鸽笼；(4)→(1)：若 X 无穷，取可数子集（下一条定理），
在其中做 n ↦ n+1 的"旅馆搬迁"再恒等延拓到全 X——真子集双射
就造出来了。**"与真部分等势"从有限集的禁区变成无穷集的入场券**
（第 123 章伽利略对应的形式化）。机器侧的三份审计：Prolog 穷举
n=3 的一切映射（`examples/prolog/129_equipollence.pl`）：

```prolog
check_pigeonhole :-
    forall(between(0, 2, Size),                   % 目标集 {0..Size-1} ⊊ {0,1,2}
           \+ (tuple(3, Size, F), no_dup(F))),    % 不存在单射
```

Python 侧对 n ≤ 4 穷举；Lean 侧则是定理形态
`Finite.injective_iff_surjective`（有限集上单射⟺满射——鸽笼的
代数化身）加上具体见证（5 到 2 的常值映射不单，`h rfl` 一步）。

## 129.3 可数集的代数

> **定理（书 3.3.6）**　每一无穷集合有可数子集。

证明用**选择公理的第二形式**：取 P(A) 上的选择函数 f，递归定义
a₀ = f(A)，a_{n+1} = f(A − {a₀,…,a_n})——序列 (aₙ) 一一，值域
是 A 的可数子集。∎ 注意：这一步**用了 AC**（从一族群无穷多非空
集里逐个挑元素）。在 ZF 内"每个无穷集有可数子集"不可证——
存在无穷的戴德金有穷集。原书在此不声不响地用了 AC，第 136 章会
把这类"隐蔽用 AC"的账目摊开。

> **定理（书 3.3.7）**　两个可数集的并可数：交错序列
> c_{2k} = a_k, c_{2k+1} = b_k。

> **定理（书 3.3.9）**　N×N 可数：显式双射
> **f(k,n) = 2^k(2n+1) − 1**。

单射：若 2^{k₁}(2n₁+1) = 2^{k₂}(2n₂+1)，比较 2 的幂次（奇数
因子唯一分解）；满射：m+1 分解为 2^k·奇数。这个配对函数是全书
第一个"把二维摊平成一维"的机器——第 124 章的哥德尔编码同款
结构（素数幂）。机器侧三通道齐审（Python 往返 0..299、Julia
网格单射+满射影子、Prolog `unpair` 复原）：

```python
def unpair(m):
    """m+1 分解为 2^k · 奇数——第 124 章的素数分解在这里复用。"""
    q, k = m + 1, 0
    while q % 2 == 0:
        q //= 2
        k += 1
    return k, (q - 1) // 2

for m in range(300):
    k, n = unpair(m)
    assert pairkn(k, n) == m                       # 往返复原
```

> **推论（书 3.3.10）**　可数集的可数并、有穷多个可数集的卡氏积、
> A^<N（有穷序列全体）、可数集的有穷子集全体——都可数。

（证明留作习题 3.7.15，思路：N×N 可数 + 交错/配对迭代。）

至此"数一数"的抽象化完成：ℵ₀ = |N| 是最小的无穷，可数集在并、
有限积、序列化下封闭——**很难超出可数层级**。但第 131 章将证明
对角线法跨过这道墙：|R| > ℵ₀。在那之前，第 130 章先把 ℤ、ℚ、ℝ
构造出来（ℤ、ℚ 是本章红利：商构造 + 可数性传递；ℝ 则是新的
不可数世界）。

## 129.4 机器侧总账

- **Lean**（`examples/lean/Settheory/Ch129Equipollence.lean`）：
  `Function.Embedding.schroeder_bernstein`（两单射合双射——与
  书的交替序列构造同源）、`Finite.injective_iff_surjective`
  （鸽笼）、可数性的 typeclass 形态：
  ```lean
  example : Countable (ℕ × ℕ) := by infer_instance
  example : Countable ℚ := by infer_instance
  example (s t : Set ℕ) (hs : s.Countable) (ht : t.Countable) :
      (s ∪ t).Countable := hs.union ht
  ```
  `Countable` 这个 typeclass 就是书 3.3.4(3) 的机器化——instance
  的自动推导（ℕ×ℕ、ℚ 的 `infer_instance` 一次通过）正是
  3.3.9/3.3.10 的"可数性传递"在类型系统里的日常运转。

## 本章要点

1. 等势=双射；≤=单射；康托-伯恩斯坦：两向单射合出双射（反对称
   性），证明是能行的交替序列构造——机器可跑（C 在深度 7 稳定）。
2. 罗素的"基数=等价类"定义卡在真类上——第 137 章 Hartogs 方案
   解决。
3. 鸽笼：有限集无真子集双射；命题 3.3.11 四种有穷的等价刻画
   （戴德金有穷与普通有穷在 ZFC 中重合，但在 ZF 中可能分离）。
4. 每个无穷集有可数子集——**用了 AC**（第 136 章摊账）。
5. 可数集在并/有限积/序列/有穷子集下封闭；配对函数
   f(k,n)=2^k(2n+1)−1 是显式的 N×N ≃ N。
