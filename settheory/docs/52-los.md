# 52 · 商、满性与 Łoś 定理：混合性质三例

> 51 章造出了 B-值语义，本章问：**取商之后真值还作数吗？**
> 答案是"满性恰好刻画了这件事"——Łoś 定理只在满模型上成立。
> 混合性质（antichain 上的拼装）是满性的充分条件，Viale 用
> 三个大例子喂饱它：可测函数、超积、C(St(B), 2^ω)。
>
> 本章覆盖 Viale §6.3-6.4。

## 52.1 商构造与它的坑

**定义（Viale Def 6.3.1）** M 是 B-值模型，F 是 B 上滤子。
**F-商** M/F：
- 域 M/F := {[h]_F : h ∈ M}，[h]_F := {f : f =ᴹ h ∈ F}；
- R^{M/F}([f̄]) 成立 ⟺ Rᴹ(f̄) ∈ F。
F 超滤时 M/F 是 **Tarski 商**（2-值模型）。

**坑（Viale Example 6.3.5，反例的艺术）** 商**不保量词**！
在 C(ℝ) 上取语言 {<, C}（C = "局部常值"谓词）与公式
φ := ∃y (f < y ∧ C(y))：在 ℝ 的右端滤子
F = {(a,+∞)} 扩出的超滤下，M ⊨ φ(id)（每个 a 处取 y = a+1），
但 M/G ⊨ ¬φ([id])——商里的 y 必须是**单个**函数处处胜过 id，
而 id 无上界。**量词在商里变成"全域"，局部见证不够。**
满性就是修补这个坑的精确条件。

## 52.2 满性与 Łoś 定理

**定义（Viale Def 6.3.6）** M **满（full）**：对每公式 φ(x,ȳ)
与 f̄ ∈ M，存在**有限**见证 h₁,…,h_k ∈ M 使
⟦∃x φ(x, f̄)⟧ = ⋁ᵢ ⟦φ(hᵢ, f̄)⟧。
（sup 在域内被有限个元素实现——"存在量词有穷达"。）

**定理（Viale Thm 6.3.7，Łoś 定理）** M 满、G ∈ St(B)：
M/G ⊨ φ([f̄]) ⟺ ⟦φ(f̄)⟧ ∈ G。

*证明*（对 φ 复杂度归纳）：原子/¬/∧ 直接展开；∃ 是关键：
M/G ⊨ ∃x φ([h], [f̄]) ⟺ 某个 h 的 ⟦φ(h,f̄)⟧ ∈ G（商的存在是
见证的）⟸ 方向显然；⟹ 方向用满性：⋁ᵢ⟦φ(hᵢ)⟧ = ⟦∃xφ⟧ ∈ G，
超性给某个 hᵢ 落在 G 中。∎

**满性被商保持**（Lemma 6.3.8）——可以叠商不塌。

## 52.3 力迫引理：真值的拓扑读法

**定义（Viale Def 6.3.9）** b ⊩ φ（b **力迫** φ）:⟺ b ≤ ⟦φ⟧。

**力迫引理 I（Viale Lemma 6.3.10）** M 满、b ∈ B⁺：
b ⊩ φ ⟺ {G ∈ St(B) : M/G ⊨ φ} 在 N_b 中**稠密**。

——真值 ⟦φ⟧ 就是"φ 成立的那些泛型点"的拓扑踪迹。这正是
46-50 章"泛型点 = 大集合的交点"字典的语义升级，54 章的
Cohen 力迫定理直接踩在上面。

**力迫引理 II（Viale Lemma 6.3.11）** ⊩ 的递归定律：
- b ⊩ φ∧ψ ⟺ b ⊩ φ 且 b ⊩ ψ；
- b ⊩ ¬φ ⟺ 无 c ≤ b 使 c ⊩ φ；
- b ⊩ ∃x φ ⟺ {c ≤ b : 某见证 c ⊩ φ(h)} 在 b 下方稠密。

Kunen 式三值力迫关系（18 章 Jech 路线的 p ⊩ φ 递归定义）是
这套定律的语法侧——两条路线在此接轨（54 章 App C 的对照）。

## 52.4 混合性质

**定义（Viale Def 6.3.13）** M 有 **κ-混合性质**：任何 ≤κ 大小
的反链 A ⊆ B 与任何 {a_d : d ∈ A} ⊆ M，存在 b ∈ M 使
b =ᴹ a_d ≥ d（在每个 d 上"值等于 a_d"）。M 满时 = |B|-混合。

**命题（Viale Prop 6.3.14）** κ-混合（κ ≥ min{|B|,|M|}）⟹ 满。
*证明的机关*：把 {⟦φ(e,f̄)⟧ : e ∈ M} 贪心精化成反链 {a_d}，
混合出见证 b，则 ⟦φ(b,f̄)⟧ ≥ ⋁a_d = ⟦∃xφ⟧。∎

## 52.5 三大例子

**例一（Viale Prop 6.4.1/6.4.3）：L⁺([0,1]) 可测函数域**
B := MALG（49 章！）。M := L⁺([0,1])（[0,1] → ℝ 的可测
a.e. 有限函数），f = g := [ {x : f(x) = g(x)} ]，f < g :=
[ {f < g} ]。**M 是 MALG-值模型且满足混合性质**：反链
{[X_d]} 可数（MALG ccc！），拼装 g = ⋃ f_d·χ_{X_d} 仍可测。
更有：**M ⊨ 域公理**——每个非零函数有逆（在核上置 0）。
**函数空间成了域**——泛函分析与布尔值逻辑的握手。
（Julia 通道数值复刻混合拼装与可逆性。）

**例二（Viale Fact 6.4.6）：超积**
𝒫(X)-值模型 N := ⨉ M_x（逐点真值）；混合性质来自坐标拼装；
商 N/G（G ⊆ 𝒫(X) 非主超滤）= **经典超积**；Łoś 定理退化为
**经典 Łoś**。布尔值语义是超积的推广——一阶模型论的两条
大动脉（紧致性路线、超积路线）在此汇流。

**例三（Viale Ex 6.4.7）：C(St(B), 2^ω)**
连续函数 f : St(B) → 2^ω，按 Borel 关系 R 逐点定义真值
⟦f R g⟧ := Reg({G : f(G) R g(G)})——**满 B-值模型**，且是
53 章 V^B 的直系预告：V^B 就是"把 St(B) 上的连续函数换成
B-名字"的同一思想的集合论化身。

## 52.6 机器通道

**Lean（`Settheory/Ch52Los.lean`）**：自建 `FullModel` 骨架
（BValued + full 字段），证满性的**有限形态**：B = Bool 时
一切模型满（sup = max = 某个原子）；混合性质的最小实例
（2 元反链上拼装存在）。

**Coq（`examples/coq/Ch52_los.v`）**：**Łoś 定理的命题片段
机器复刻**——浅嵌入公式 + B = 4 元代数 + 一个固定超滤 G；
对 ¬/∧/∃（有限域）三情形验证 ⟺。反例 6.3.5 的有限版：
构造小模型使 M ⊨ ∃yφ 但 M/G ⊨ ¬∃yφ（满性失败的现场）。

**Agda（`examples/agda/Ch52_los.agda`）**：混合性质的
构造版：给定 2 元反链 {u, v}（钻石代数）与两个元素 a_u, a_v，
构造混合元素 b 并验证 b 在 u 上等于 a_u、v 上等于 a_v
（4 分支 refl）。

**Julia（`examples/julia/52_los.jl`）**：**L⁺ 混合实验室**——
(a) 随机生成 MALG 反链（两两不交正测度 dyadic 集）；(b) 拼装
g = ⋃ f_d·χ_{X_d}（Prop 6.4.1 的构造）；(c) 可逆性：随机的
a.e. 非零函数构造 g⁻¹ = 1/f·χ_{f≠0}，验证 f·g = 1 mod Null。

**Python（`examples/python/52_los.py`）**：**超积实验室**——
三个有限结构 M₁ M₂ M₃（不同大小的群/序）；P(X)-值模型
⨉Mᵢ；对主超滤（= 取某坐标）与非主超滤（X 无限化——用
Fréchet 滤子的有限模拟）分别做商，验证 Łoś 在主超滤下
逐坐标成立；量词在商里的行为对照。

**Prolog（`examples/prolog/52_los.pl`）**：钻石代数上的
满性检查器：小域模型的 ⟦∃x φ⟧ 是否被有限见证达（sup 分解）；
混合拼装的搜索。

**Isabelle/ZF（`examples/isabelle/ST52/Los.thy`）**：谓词式
`full_on` 定义 + 主超滤商的 Łoś 原子情形（正向 blast 区）。
