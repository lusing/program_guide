# 19 · CH 与 AC 的独立性

> Cohen 1963：即使 ZFC 一致，也不能证明连续统假设；
> 即使 ZF 一致，也不能证明选择公理。
> ——二十世纪数学基础的第二场伟大胜利

本章覆盖 Jech §19：加 κ 个泛型实数（引理 19.1）、ccc 与
基数保持（引理 19.2-19.3）、子集上界（引理 19.4）、加正则
基数的子集（κ-封闭力迫，引理 19.5-19.7）、崩塌基数（引理
19.9）、**AC 独立性**（定理 45：置换自同态论证）。

## 19.1 ¬CH 的一致性

**引理 19.1** 在 M 中 κ^ω = κ，则存在力迫 P 使 M[G] 保持
一切基数与共尾性且 2^ℵ₀ = κ。

*构造*：P = {p : dom(p) 有限 ⊆ κ×ω, ran(p) ⊆ {0,1}}，
序 = 反包含。⋃G : κ×ω → {0,1} 给出 κ 个泛型实数
a_α = {n : f(α,n) = 1}——两两不同（稠密集 D_{αβ} 击中）。

**ccc**：P 满足可数链条件（无不可数不相容族）——
**引理 19.3** 的计数论证：不相容族 W 的每个 p 的域被
可数集 A 覆盖（逐步扩张 W₀ ⊆ W₁ ⊆ ... 的构造，每步
只加可数个元素）⟹ |W| ≤ ℵ₀。

**基数保持**（引理 19.2）：λ-ccc 的 P 保持 ≥ λ 的正则基数。
ccc（λ=ℵ₁）⟹ 一切基数保持。

**上界**（引理 19.4）：2^λ 在 M[G] 中 ≤ |B|^λ（每个新子集
由名字 ⟦ A ⟧ 的布尔值函数编码）。

合流：κ ≤ 2^ℵ₀（泛型实数两两不同）+ 2^ℵ₀ ≤ κ（|B| ≤ κ^ω = κ
+ 引理 19.4）= **2^ℵ₀ = κ**。取 κ = ℵ₂ 得 **¬CH**。∎

Julia（`examples/julia/19_independence.jl`）验证 Cohen 条件
的相容/不相容判定（同域不同值 → 不相容 ✓，不同域 → 相容 ✓），
Python（`19_independence.py`）同构 + **置换论证骨架**（交换
i,j 后 a_0 与 a_1 角色互换——HOD(A) 中的定义无法区分，引理
19.12 的数值直觉）。Prolog（`19_independence.pl`）做条件
相容性的推理机。

## 19.2 加正则基数的子集

**引理 19.7** κ 正则且 2^{<κ} = κ，λ^κ = λ，则可加 λ 个
κ 的子集使 2^κ = λ 且保持基数。构造：P = Fn(λ×κ, 2, <κ)
（大小 <κ 的域）。

**κ-封闭**：任何 <κ 长的递降链有下界——⟹ **κ-分配**
（引理 19.5：<κ 个开稠密集的交仍稠密）⟹ 无新 <κ 序列
（引理 19.6）⟹ ≤κ 的基数保持。

**κ⁺-饱和**（引理 19.8）：2^{<κ} = κ + 正则 κ ⟹
Fon(S, C, <κ) 是 κ⁺-ccc 的——推广的计数论证。

## 19.3 崩塌基数

**引理 19.9** κ 正则，λ > κ，P = Fn(κ, λ, <κ)（大小 <κ 的
域，值 <λ）崩塌 λ 到 κ（M[G] 中 |λ| = κ）。P κ-封闭 ⟹ ≤κ
基数保持；λ^{<κ} = λ 时 λ⁺-ccc ⟹ >λ 基数保持。

**习题 19.7 的观察**：加 ω₁ 的子集（19.7 式）与崩塌 2^ℵ₀
到 ω₁（19.12 式）给出**相同的完备布尔代数**——两个看似
不同的力迫产生相同的泛型扩张。

## 19.4 AC 的独立性

**定理 45（Cohen）** 存在 ZF 模型使实数不可良序。

*证明骨架*（对称子模型法）：
1. 地面模型 M = L；加 ℵ₀ 个 Cohen 实数：P = Fn(ω×ω, 2)。
2. 泛型扩张 M[G]，实数族 A = {a_i : i < ω}（(19.18)-(19.19)）。
3. 取 𝔑 = HOD(A)——**遗传 A-序数可定义**的子模型。
4. 𝔑 ⊨ ZF（定理 38 的推广），含 A，但不含 A 的良序。

**关键**：**引理 19.12** A 在 𝔑 中不可良序。证明：
- 反设 f : A → Ord 单射且 f ∈ OD[s, A]（s 是 A 中有穷序列）。
- 取 a = a_i 不在 s 中（i 不同于 s 的指标）。
- **ω 的置换** π 交换 i 与 j（j 不在 dom(p₀) 中）诱导 P 的
  自同态 → V^B 的自同态（(19.13)-(19.15)）→ **引理 19.10**：
  ‖φ(πx₁,...,πxₙ)‖ = π(‖φ(x₁,...,xₙ)‖)——布尔值与自同态交换。
- π(a_j) = a_i 而 π 固定 s 与 A 的名字 ⟹ a_i 与 a_j 满足
  相同的"OD[s,A]"定义 ⟹ f 不能区分它们 ⟹ 矛盾。∎

**引理 19.10**（自同态与布尔值交换）是**对称模型法**的核心
引擎——第 21 章将系统化。

## 19.5 定理 43/44/45 的合流

**定理 43** Con(ZF) ⟹ Con(ZFC + ¬CH)。
**定理 44** CH 独立于 ZFC（Gödel + Cohen 合流）。
**定理 45** AC 独立于 ZF。

三条定理合流成：**连续统的值在 ZFC 中完全自由**（Easton
进一步：正则基数上的连续统函数只受单调性与 König 约束）。
