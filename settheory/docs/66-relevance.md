# 66 · 相关性：经典怪原理与可接受性

> 本章提炼 Makinson 第 11 章（收官内容章）：经典逻辑中"前提
> 与结论无内容关联"的怪原理（爆炸律家族）、Lewis 推导的
> 拆解（哪条规则是罪魁）、系统 R 的公理化与 Routley-Meyer
> 语义的局限、以及 Makinson 自己的**真值树分析**与**直接可接
> 受性**判据——变量共享条件。它是全书对"经典逻辑边界"的
> 反思收束，也是对 65 章 Tarski 三条件适用范围的哲学侧写。

## 66.1 经典怪原理

三类"怪"——按字母共享递升：

1. **无字母共享**：(p∧¬p)→q（**爆炸律**）、p→(q∨¬q)（左爆
   炸）、(p∧¬p)→(q∨¬q)（对称爆炸）——前件与后件无任何公共
   命题字母，"内容完全无关"。
2. **有字母共享但直觉仍怪**：¬q→(q→p)、p→(q→p)、
   (¬q∨p)→(q→p)——"p 真就能保证任意 q 相关地蕴含 p"？
3. **主连接词非 →**：(p→q)∨(q→p)（可比性）——"任意两命题
   有一个蕴含另一个"？

所有这些都是经典重言式——**经典逻辑接受它们**，但把 → 读作
某种"相关性"时它们值得质疑。

## 66.2 Lewis 推导的拆解

从 p∧¬p 到 q 的五步推导（Neckam 十二世纪已知的 Lewis 困境）：

    1. p ∧ ¬p     [假设]
    2. p          [1, ∧⁻]
    3. ¬p         [1, ∧⁻]
    4. p ∨ q      [2, ∨⁺]
    5. q          [3, 4, DS]

要拒绝爆炸律，必须在 ∧⁻、∨⁺、DS、或二阶规则（累积传递、
单调）中**至少放弃一个**。各有代价：

- **放弃 ∨⁺**（加法规则）：直觉上最有说服力——"表在上抽屉
  ⟹ 表在柜子里"看似 Trojan 马。但导致的系统不太有趣。
- **放弃 DS**（析取三段论）：Makinson 的选择——狗追 scent 的
  Stoic 故事和数独都是 DS 的日常应用，失去代价大但理论更丰富。
- **放弃单调/累积传递**：伤到 65 章的链条基础。

Makinson 的立场：**逻辑的游戏而非改革使命**——不否定经典
逻辑，而是探索一种"监控其应用"的方式。

## 66.3 系统 R 与 Routley-Meyer 语义

**系统 R**：接受 Lewis 推导中除 DS 以外的所有规则。两规则
（分离 a, a→b / b；邻接 a, b / a∧b）+ 约 12 条公理模式（同一
a→a、双否消除、逆否、∧⁻∨⁺、分配、后缀、收缩、断言…）。
读作经典 → 时全为重言式——R 是经典逻辑的**真子逻辑**。

**Routley-Meyer 语义**：三元关系 R + 星函数 * 的"状态"语义。
与 R 的公理系统有健全性-完备性定理。但约束晦涩、否定非经典
——两个主要短板。

## 66.4 Makinson 的真值树分析

Makinson 用**语义分解树**（63 章 8.5 的真值树）来分析怪原理的
"怪"在哪。对爆炸 (p∧¬p)→q 的树：

    0: (p∧¬p)→q
    ├ 1: ¬(p∧¬p)     [← 0 的 counter-case]
    │  ├ 1: p         [→ 再分解…]
    │  └ 0: p∧¬p
    │    ├ 1: p ✓
    │    └ 1: ¬p
    │      └ 0: p ✗ crash!
    └ 0: q
      └ …no crash → dead? no, alive!

树分析揭示：爆炸式的**活支**上前提 p∧¬p 是"永远不可能"的
——活支不是因为前提与结论有内容关联而活，而是因为前提自毁。
Makinson 由此提炼出以下判据。

## 66.5 直接可接受性

**变量共享条件**（variable-sharing）：a→b 可接受的一个**必要
条件**是 a 与 b 至少共享一个命题字母。这不是充分条件
（¬q→(q→p) 有共享但直觉仍怪），但是**必要**的——无共享则
"内容无关"。

**直接可接受性**：Makinson 定义——公式 a→b **直接可接受**
iff 对每个使 a 真的赋值 v，在真值树分解 a→b 时，v 对应的活支
上 b 的"相关字母"与 a 的"相关字母"有交互。形式化需用分解树
的活支结构。

**可接受性**：更宽松的判据——a→b 可接受 iff a 与 b 的某个
"共享字母变体"满足直接可接受性。Makinson 证明：可接受性
⟹ 变量共享，但不反过来。

## 66.6 机器通道

本章的机器化以**判定程序剧场**为主：Julia/Python 对全部
p,q-公式扫描爆炸律家族的字母共享、验证 Lewis 推导的每步
在经典语义下有效、搜索无字母共享的重言式。Prolog 的真值树
搜索用于"活支读出反例见证"。Lean/Coq 做变量共享判据的
形式化。

## 66.7 收束：全书的逻辑弧线

从 56 章的朴素集合到本章的相关性边界，Makinson 走完了一条：
**集合 → 关系 → 函数 → 递归 → 计数 → 概率 → 树 → 命题逻辑
→ 量词逻辑 → 证明与后承 → 相关性**。三底本（Jech 的公理化
高路、Viale 的布尔值力迫、Makinson 的计算者工具箱）在"数学
事实唯一但表达方式多样"的主题下合流。
