# 145 · 不可达基数与反映定理

> 在 ZFC 中不能证明"存在不可达基数"——因为如果 κ 不可达，
> V_κ 就是 ZFC 的模型，而 ZFC 不能证明自己的模型存在。
> ——推论 7.8.5 的直观

本章覆盖书 7.8-7.9 节（PDF 183-193 页）：V_κ 与 H_κ 作为 ZFC
模型的条件、不可达基数的地位、Montague-Lévy 反映定理——以及
它们与哥德尔第二不完备性定理的精妙互动。

## 145.1 V_α 与 H_κ 作为模型（书 7.8）

**定理 7.8.1**　λ > ω 极限 ⟹ V_λ ⊨ ZC（在 ZF 中）；AC 下
V_λ ⊨ ZC（良序绝对性 7.5.4 帮 AC 过关）。但**替换公理**不一定
成立——习题 7.10.10：V_{ω+ω} 不满足替换（f(n) = V_{ω+n} 的
值域是集合但不在 V_{ω+ω} 内）。

**定理 7.8.4（本章高潮之一）**　κ 不可达 ⟹ **V_κ ⊨ ZFC**。

替换公理的验证用到不可达的两个半边：|V_κ| = κ（强极限——
引理 7.2.3(3)）保证一切 A ∈ V_κ 有 |A| < κ；正则性保证
|A| 步的函数值有界（落在某个 V_α 内，α < κ）——替换的像
不逃出 V_κ。∎

> **推论 7.8.5**　ZFC ⊬ "存在不可达基数"——否则在 ZFC 内可
> 证 V_κ ⊨ ZFC，违反哥德尔第二不完备性。

> **推论 7.8.8**　Con(ZFC) ↛ Con(ZFC + "存在不可达")——不
> 可达的一致性强度严格更高。

Python 单元（`21_inaccessible.py`）做了窗口审计：V_n 的严格
增长（P(V_n) = V_{n+1} 逃出 V_n——幂集公理在有限层的失效现
场）；H_{ℵ₀} 的窗口版（V_3 内一切元素遗传有穷，trcl ≤ 4）；
**强极限的有限不可能性**（n ≤ 2^{n-1} 恒真——不可达是纯无穷
现象）。Julia 单元（`21_inaccessible.jl`）做 beth 阶梯的数值
面与**反映层扫描**（对给定的性质列表，找到最小 α 使 P 在
V_α 中成立——定理 7.9.2 的最小实例）。

## 145.2 H_κ：遗传小于 κ 的宇宙（书 7.8 续）

> **定义（7.8.9）**　H_κ = {x | |trcl(x)| < κ}——遗传基数
> 小于 κ 的集。H_{ℵ₀} = 遗传有穷集；H_{ℵ₁} = 遗传可数集。

H_κ 是 ZFC−Pow 的模型（定理 7.8.13：κ 不可数正则），且
H_κ ⊨ ZFC ⟺ H_κ = V_κ ⟺ κ 不可达（定理 7.8.14）——三等
价把不可达与"两个宇宙的重合"焊接。

**非不可达正则 κ**（如 ℵ₁）给出 ZFC−Pow+¬Pow 的模型——
**幂集公理独立于 ZFC 的其余公理**（推论 7.8.15 更强：
H_{ℵ₁} ⊨ "一切集合可数"）。

## 145.3 反映定理：V 的性质总在某层 V_α 成真（书 7.9）

> **反映定理（7.9.2，Montague–Lévy）**　(ZF) 对任意有限公式集
> F = {φ₁,…,φₙ}，对任意 V_α，存在 V_β ⊇ V_α 使 φ₁,…,φₙ
> 相对于 V_β 绝对。

证明的骨架（司寇伦壳的层谱版）：对 F 中每个 ∃ 形公式，定义
Skolem 型函数 h_φ(y₁,…,y_m) = 最小的 V_ε 使证人在其中；递
归叠 V_{i+1} = V_i ∪ ⋃ h 的值域；β = sup 的极限层就是反映
层。∎

**推论 7.9.3**　对 ZF 的任意有限公理子集 F，存在 V_β ⊨ F。
**推论 7.9.4**　ZF 不可有穷公理化（F ⊨ ZF 会给 ZF 一个模型
——违反第二不完备性）。

**可数版本的反映（7.9.6，ZFC）**：存在可数的 M ⊨ F——但 M
不能是传递的（可数传递模型上幂集运算不绝对）。这个"可数非传
递"的反映模型是力迫法的前奏（第 147 章的可数传递模型假设是另
一回事——那是增加的假设，不是定理）。

## 145.4 与哥德尔定理的三重奏

本章的三个结果围绕哥德尔第二不完备性旋转：

| 结果 | 与 Gödel II 的关系 |
|---|---|
| 7.8.5：不可达不可证 | 若可证则 ZFC 有内部模型 |
| 7.8.8：不可达的一致性强度更高 | Con(ZFC) ↛ Con(ZFC+不可达) |
| 7.9.4：ZF 不可有穷公理化 | 有限公理给 ZFC 一个模型 |

**Solovay 题词的回响**（第六章）："每个自然数是四个平方数的
和"比"存在不可达基数"更是真的吗？——从 ZFC 的视角看，后者
是一致性强度更高但无法反驳的公理候补，与前者"同真"只是更
"显然"。大基数理论的全部张力正在此处。

## 145.5 机器侧

- **Python**：V_n 增长 / 幂逃逸 / H_{ℵ₀} 窗口 / 强极限有限
  不可能 / 反映层影子。
- **Julia**：|V_n| 的 BigInt 阶梯（0,1,2,4,16,65536——|V_{n+1}|
  = 2^|V_n|）/ beth 记号 / 反映层扫描（最小 α 的算法化）。

## 145.6 Julia 反映层扫描的代码讲解

```julia
function find_reflection_layer(props, layers)
    for (i, V_a) in enumerate(layers)
        if all(p(V_a) for p in props)
            return i
        end
    end
    return -1
end

p1(V_a) = Set() in V_a                          # "∅ 存在"
p3(V_a) = Set([Set()]) in V_a                   # "{∅} 存在"
@assert find_reflection_layer([p1], layers) == 2     # V_1 起有 ∅
@assert find_reflection_layer([p1, p3], layers) == 3 # 需要到 V_2
```

算法是书 7.9.2 证明的"反向"：证明构造 β（通过叠 Skolem 函数），
扫描从底层往上找。有限窗口中两条性质分别在第 1 层和第 2 层首
次同时成立——**"每个有限性质集在某个 V_α 反映"的最小实现**。

Python 侧的强极限不可能性同样值得引：

```python
is_strong_limit_in_window(n) = all(2**k < n for k in range(n))
# 对一切 n ≥ 1 为 False（n ≤ 2^{n-1} 恒真）
```

这不是代码 bug 而是数学事实：**有限宇宙中不存在强极限序数**
——不可达基数的"强极限"半边需要真正的无穷（μ < κ ⟹ 2^μ < κ
的第一个见证者是 ℵ₀ 之后的 beth 不动点候选）。机器在此诚实
地承认窗口边界。

## 145.7 与后续章节的对账

**第 146 章（L）**：反映定理 7.9.2 在 L ⊨ ZF 的分离公理验证
中是关键引擎（L_α 中的可定义性需要足够高的 L_β 反射真值）。

**第 147 章（力迫）**：可数传递模型 M ⊨ ZFC 的存在性是力迫的
工作假设（不能从 ZFC 证明——正是 7.8.5 的逻辑）；反映定理的
可数版（7.9.6）提供"可数非传递"的替代品。

**习题选讲（7.10）**：7.10.17（一般层谱的反映定理——把 V_α
换成任何满足三条单调性的 U_α）；7.10.18（每个公式 φ 的反映
层构成无界闭集——club 的首次正式登场于元定理）；7.10.19
（传递模型内的基数保序）。

## 本章要点

1. V_λ ⊨ ZC（λ 极限 > ω）但替换可失败；**V_κ ⊨ ZFC ⟺ κ
   不可达**（强极限给大小上界 + 正则给步数上界，夹住替换）。
2. ZFC ⊬ ∃不可达；Con(ZFC) ↛ Con(ZFC+∃不可达)——大基数的
   一致性阶梯由此起步。
3. H_κ = {x | |trcl(x)| < κ}：遗传小于 κ 的宇宙；H_κ ⊨ ZFC−
   Pow；H_κ = V_κ ⟺ κ 不可达。
4. 反映定理：任意有限条性质在某 V_β 同时成真；推论——ZF 不
   可有穷公理化；可数非传递反映模型是力迫的前奏。
5. 机器面：V_n 阶梯 + 强极限有限不可能（纯无穷现象）+ 反映层
   扫描的最小实例。
