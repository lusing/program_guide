## 一、从 Σ¹₂ 到 Σ¹₃：树表示的资源问题

第 112 章的收官一击是 Shoenfield 绝对性：Σ¹₂ 与 Π¹₂ 语句对
包含 {α}∪ω₁ 的传递模型绝对。它背后的引擎是 Σ¹₂ 的
ω₁-Souslin 表示——ω₁ 还在 ZFC 的「地面资源」之内。到了
第三层 Σ¹₃，情况质变：**ω₁-Souslin 表示不够用了**。要给
Π¹₂（从而 Σ¹₃）配补树，必须在更大的序数塔上工作，而这座
塔的天然高度由**可测基数**给出。本章前半（§3.1.4）讲这座
塔怎么搭；后半（§3.1.5）转而问一个 ZFC 内部的问题：哪类
实数集在**一切力迫扩张下**保持正则性？答案——广泛贝尔
特性——恰好把解析集推广成一个对力迫封闭的 σ-代数，并
在可测基数下与 Σ¹₃ 正则性会师。

一个自然的疑问：为什么不直接问「Σ¹₃ 有没有 ω₁-
Souslin 表示」？答案是它**有**——Σ¹₃ 是 Σ¹₂ 的投影，
把 Σ¹₂ 的 ω₁ 树再投影一层即可——但这样的表示**不配
补树**：补集的表示需要在更高的序数层闭包，而闭包的
高度正是大基数的第一个用武之地。另一个自然的疑问：
既然 Shoenfield 绝对性覆盖 Σ¹₂，Σ¹₃ 语句在力迫下会
怎样？这正是 §3.1.5 的入口——**广泛贝尔特性**把「在
力迫下稳定」本身提炼成一个组合性质，然后反向询问：
哪些投影层自动享有它？两条线在 Magidor 与 FMW 处
交汇。本章的路线图因此是：先上塔（大基数造树），后
问稳（力迫稳定），最后合龙。

## 二、布劳威尔-克林序：把「树枝」翻译成「递降链」

树 T ⊆ ω^<ω 有秩（即 [T]=∅，无无穷树枝）这件事，可以
完全改写成某个线性序的良基性。定义 **ω^<ω 上的布劳威尔-
克林序**：

> s <_BK t ⟺ t ⊏ s（t 是 s 的真前段），或者 s 与 t 在首个
> 相异位 k 上满足 s(k) < t(k)。

注意方向：**延伸者更小**——真前段 t 排在延伸 s 之前；首个
分叉处数码小的排在前。空序列是最大元（一切非空序列都
延伸它）。这个序是 ω^<ω 上的线性序（书上的断言；机器件
在 2^≤3 的 15 节点窗口上逐对验证了完全性、反对称与传递，
并在全二叉树 depth d 上算出最长递降链恰为 2^(d+1)−1——
线性序之下全部节点可排进一条链）。

**引理 3.20**：树 T 有秩 ⟺ <_BK 在 T 上的限制是良序。

- （⟸ 的反面，即树枝→递降链）设 [T]≠∅，取 y∈[T]。序列
  ⟨y↾n | n<ω⟩ 沿 <_BK 严格递降——因为 y↾(n+1) 延伸
  y↾n，延伸者更小。这一步就是机器件里的一行引理：
  对一切 k，x↾(k+1) <_BK x↾k。
- （⟦⟧⟹ 方向，即递降链→树枝）设 ⟨t_i | i<ω⟩ 沿 <_BK
  严格递降。对 m 归纳证明断言：(a) 集合 {i | dom(t_i)<m}
  有限；(b) 序列 ⟨t_i(m)⟩ 最终稳定。归纳步取 i_m 使
  i≥i_m 后 dom(t_i)≥m 且 t_i↾m = t_{i_m}↾m；由于递降，
  至多一个 i≥i_m 见证 t_i = t_{i_m}↾m（那就是 i_m 自己），
  于是 i>i_m 的都有 dom≥m+1，且 t_{i_m+1}(m)≥t_{i_m+2}(m)≥⋯
  在自然数上递降而稳定。令 y(m) 为稳定值，则每个 y↾n 都是
  某个 t_i 的前段，故 y∈[T]。

**定理 3.15** 把引理 3.20 装配成 Π¹₂ 的第三种刻画：A 是
Π¹₂ ⟺ 存在定义在 ω^<ω 上的函数 s↦<_s 使得 (a) 每个 <_s
是 dom(s) 上的线性序且 ∅ 是最大元；(b) s ⊏ t 时 <_s =
<t↾dom(s)；(c) 对每个 α∈ω^ω，令 <_α = ⋃_n <_{α↾n}，则
α∈A ⟺ <_α 是良序。证明的 (1)→(3) 方向取 ω^<ω 的单一
罗列 ⟨s_n⟩（前段先行的枚举），用 (2) 的关系 R 定义
<：把满足 ¬R(p↾dom(s_m), s_m) 的下标 m 排在开头保持
自然序，其余下标按 <_BK 的序同构嵌入——T = {t |
R(α↾dom(t), t)} 是树，R 的性质 (d) 保证 α∈A ⟺ [T]=∅，
再由引理 3.20 翻译成 <_α 的良序性。

### 引理 3.20 的证明再细一层

把两个方向各自拆开看清楚。

**方向一（树枝→递降链）**。设 y∈[T]。对每个 n，y↾(n+1)
真延伸 y↾n，按 <_BK 的第一条款（t ⊏ s 时 t <_BK s——注意
书的方向约定是延伸者更小），y↾(n+1) <_BK y↾n。于是

  y↾1 >_BK y↾2 >_BK y↾3 >_BK ⋯

是 T 中沿 <_BK 的严格递降链，良序性被破坏。这个方向的
全部内容就是「延伸者更小」这一个局部事实对 n 的无限
重复——机器件的 `bk_snoc`（Lean）/`bkLT-app`（Agda）/
`bk_snoc`（Isabelle）/`bkLT_snoc`（Coq）证明的正是这个
局部事实，`bk_take_step`/`bkLT_firstn_step` 再把它装配到
具体的前缀链上。

**方向二（递降链→树枝）**。设 t₀ >_BK t₁ >_BK t₂ >_BK ⋯。
对 m 归纳证明断言：

- (a) {i | dom(t_i) < m} 有限；
- (b) 存在 i_m，使 i ≥ i_m 时 dom(t_i) ≥ m 且
  t_i↾m = t_{i_m}↾m。

m=0 时两条都平凡（一切序长 ≥0）。归纳步：取 i_m 如 (b)。
在 i ≥ i_m 的范围内，若有某个 i 使 t_i = t_{i_m}↾m，由
严格递降它只能是 i_m 自己（若 i>i_m 也等于 t_{i_m}↾m，
则 t_{i_m} >_BK t_i >_BK t_{i_m} 矛盾于反自反）。于是
i > i_m 的都有 dom(t_i) ≥ m+1——这正是 (a) 对 m+1 的
情形。再看数码：对 i > i_m，t_i 与 t_{i_m} 在前 m 位一致
（都等于 t_{i_m}↾m），若 dom(t_i) > m，则 t_{i_m+1}(m)、
t_{i_m+2}(m)、⋯ 是自然数上的不增列，必然稳定；取稳定点
i_{m+1} ≥ i_m，则 i ≥ i_{m+1} 时 t_i↾(m+1) 一致——(b)
对 m+1 成立。

现在令 y(m) = 稳定值 lim_i t_i(m)。对每个 n，y↾n 与某个
t_i 的前段一致，而 T 前段封闭，故 y↾n ∈ T，即 y∈[T]。
**关键机关**：BK 序的「延伸者更小」让递降链的长度只能
往下走，而「首异位数码小的更小」让每个坐标位上的数码
在链尾单调稳定——两个条款分工合作，缺一不可。

### 定理 3.15 的三份刻画怎么互相翻译

(1)⟺(2) 书上留作练习。(1)→(3) 的构造值得过一遍手：

1. 取 ω^<ω 的**单一罗列** ⟨s_n | n<ω⟩：若 s_m ⊏ s_n 则
   m<n——即枚举任何节点之前先枚举它的全部真前段（层
   级优先序）。s₀ = ∅。
2. 对 p∈ω^k 与 m,n < k，定义 m <_p n ⟺ 下列之一：
   (i) m<n 且 ¬R(p↾dom(s_m), s_m) 且 ¬R(p↾dom(s_n), s_n)；
   (ii) m<n 且 ¬R(p↾dom(s_m), s_m) 且 R(p↾dom(s_n), s_n)；
   (iii) s_m <_BK s_n 且 R(p↾dom(s_m), s_m) 且
   R(p↾dom(s_n), s_n)。
   直观：把「不满足 R」的下标放在 <_p 的开头保持自然
   序，剩下的下标按 <_BK 同构嵌入。
3. 单一罗列的前段优先性保证 <_p 无歧义且是 dom(p) 上
   的线性序；s₀=∅ 与 R 的性质 (a)（R(∅,∅) 成立）使 ∅
   成为 <_p 的最大元——(3)(a) 得证。
4. (3)(b)（协调性）由罗列的定义直接继承；(3)(c) 的
   验证：固定 α，令 T = {t | R(α↾dom(t), t)}——R 的
   (b)(c) 保证 T 是树，(d) 保证 α∈A ⟺ [T]=∅，再用
   引理 3.20 翻译成 <_α = ⋃_n <_{α↾n} 的良序性。

这份构造是「BK 序是 Π₁¹ 的组合骨架」的精确含义：<_α
良基 ⟺ 树无枝，两条腿走的是同一个引理。

## 三、Martin-Solovay-Mansfield：可测基数造补树

第 112 章的 κ-Souslin 表示给 Σ¹₂ 配了树 T，但**补集的树**
要到大基数才有。**定理 3.16**：κ 可测（带正规超滤子 U），
λ = sup_{s,t} j_{s,t}(κ)，则每个 Π¹₂ 实数集 A 有 ω×λ 树
T 与 T* 使 A = π[T]、ω^ω−A = π[T*]。构造的机关：

1. 从 A 的 Π¹₂ 定义取关系 R（定理 3.15(2) 形），对每对
   (s,t) 定义线性序 <_{s,t}，超滤子 U 诱导 U_{s,t}，超幂
   嵌入 j_{s,t}；
2. T 的节点携 (s,t) 使 <_{s,t} 良序的部分；T* 携使
   <_{s,t} 有无穷递降链的部分——由引理 3.20 这正是「补集
   侧」；
3. **事实 3.1.4**：π[T^]⊆C（C = sup 边界）会制造无穷
   递降序数列，与 j_{s,t}(κ) 的取法矛盾——所以表示封闭
   在正确的层内。

**定理 3.17（Magidor）**：κ 可测且 NS_κ 峭壁（非荟萃理想
是峭壁理想），则一切 Σ¹₃、Σ¹₄ 实数集都有贝尔性质、都
勒贝格可测、都有完美子集性质。证明走泛型嵌入：取
P(ω₁)/I 上的泛型 G，j_G: V→M[G]，四条断言分别处理
j(T)=T（树在嵌入下不动）、j(U)=U∩M（超滤子表示）、
序数函数的表示、以及把 j_G(f) 降回 M。峭壁性保证嵌入的
闭性足够强。**定理 3.18（Silver）**：ℝ∩L[U] 是 Σ¹₃——
这是「内模型的实数可在第三层被定义」的标杆；书中注明
峭壁理想假设**不可省**：没有它，L[U] 的实数可以停在更
高层。这三条定理的完整证明都在超穷层，机器不碰；本章
机器件吃下的是它们的公共前提——**把「无穷树枝」翻译成
「无穷递降链」的那个 BK 机关**。

### 定理 3.16 的构造逐件过

设 A 是 Π¹₂(α)：A = {x | ∀y R(x,y,α)}，R 算术。由定理
3.15(2) 取关系 R 与线性序族 <_{s,t}（s 是实数前段，t 是
证据前段）。对每对 (s,t)：

1. **超滤子搬运**：U_{s,t} = {X ⊆ κ | X ∈ 某个由 <_{s,t}
   的秩函数诱导的集族}——把 κ 上的正规超滤子 U 沿
   <_{s,t} 的结构搬运过去；
2. **超幂嵌入**：j_{s,t}: V → Ult(V, U_{s,t})，令
   λ = sup_{s,t} j_{s,t}(κ)；
3. **树对**：T 的第二坐标走「<_s 良序」侧的序数值，
   T* 走「<_s 有递降链」侧——由引理 3.20 的对偶，T*
   恰好接住补集的实数。

**事实 3.1.1–3.1.4** 的核心是 3.1.4：π[T^]⊆C（C 是各
j_{s,t}(κ) 的上确界以下的一段）将给出序数的无穷递降列，
与 λ 的取法冲突。这条事实把「树对的高度不能超过塔顶」
钉死，于是 A = π[T]、ω^ω−A = π[T*] 在 ω×λ 上封闭。

### Magidor 定理 3.17 的四断言

取 P(ω₁)/I（I 是峭壁理想）上的泛型 G，j_G: V→M[G] 是
泛型嵌入。对 Σ¹₃ 集 A = π[T]（定理 3.16 给出的 ω×λ 树）：

- **断言一**：j_G(T) = T。树是序对前段的集合，j_G 在
  第二坐标上的作用被 T 的定义（序数值 < j(κ) 的初段）
  吸收——树在嵌入下不动。
- **断言二**：j_G(U) = U∩M。超滤子的表示在 M 内复原。
- **断言三**：M 内的序数函数可被 V 的函数表示。
- **断言四**：把 j_G(f) 的值降回 M——峭壁性（I 是
  峭壁理想）提供所需的闭性。

四断言合起来：泛型扩张里的「A 有贝尔性质/可测/完美
子集」语句被拉回 V，对一切 Σ¹₃（再对偶一层到 Σ¹₄）成立。
**Silver 定理 3.18**（ℝ∩L[U] 是 Σ¹₃）从内模型侧补上
另一半：L[U] 的典范良序在第三投影层可定义；书上强调
峭壁假设不可省——只有可测没有峭壁时，这个表示可以
停在 Σ¹₃ 之外。

## 四、广泛贝尔：对一切力迫扩张的量化

§3.1.5 换一个提问方式。与其问「A ⊆ ω^ω 有什么组合表示」，
不如问「A 在所有力迫扩张下还认得出来吗」。**定义 3.9
（冯-Magidor-Woodin）**：A 广泛贝尔，若对一切紧豪斯多夫
空间 X 与连续 f:X→ω^ω，f⁻¹[A] 有贝尔性质（等于某开集
模稀疏集）。A 是 λ-广泛贝尔，若只要求 X = λ^ω（λ 无穷
基数）。**命题 3.3**：广泛贝尔 ⟺ 对一切 λ 是 λ-广泛贝尔。
例 3.3 给出四条封闭性：开集、补集、可数并、连续前像。

这个定义的重量全在**全称量词**上：「广泛」不是在当前宇宙
验证一次的性质，而是**对一切相关力迫扩张的同时承诺**。
定理 3.19 把它翻译成双树语言：

> **定理 3.19**：下列等价：
> (1) A 广泛贝尔；
> (2) 对每个无穷基数 λ，存在 ω×λ 上的树 T 与 T*，势都
> >λ，A = π[T]，ω^ω−A = π[T*]，且对一切力迫 P，
> ⊩_P π[T]∪π[T*] = ω^ω；
> (3) 存在树对 T、T* 与「检查力迫」Col(ω,λ) 的对应版本。

(1)→(3) 方向的证明是本章最长的构造：从 λ^ω 上的连续
函数 e 与 G_δ 分解出发，造 B₀、B₁ 与稠密开集列 D_n 使
e⁻¹[A]、e⁻¹[ω^ω−A] 分别紧贴 B₀∩⋂D̄_n、B₁∩⋂D̄_n；
然后定义 T、T*——节点是 (o,(τ,p₀,…,p_k)) 形，强制条件
把泛型实数压进 B₀ 或 B₁ 与 D_j 的交。(3)→(1) 方向取
实数的典型名字 τ 与既开又闭的 B_τ = {f | f(0)=τ}，
Col(ω,λ) 下的泛型 g 落进 (B₀∪B₁)∩⋂D̄_n 之外的稀疏部分
就导出矛盾。**推论 3.14** 把三等价整理成 A 广泛贝尔 ⟺
∀λ ∀连续 f f⁻¹[A] 贝尔 ⟺ 双树对一切力迫覆盖；**推论
3.15**：每个解析集（从而余解析集）都广泛贝尔——解析集的
树表示天然满足 (3)。

**定理 3.20（Oxtoby）** 用赛事刻画稀疏：Banach-Mazur 赛事
G_X（张三、李四轮流伸长同一个实数前段，结果实数落在 X
则张三胜）中张三有稳赢策略 ⟹ 补集可数稀疏。书上证明的
(1)→(3) 给出张三策略的显式构造：双射 π:ω→ω×ω、可数同质
模型链 M_n（⋃[q_n]∪M_{n−1}⊆M_n）、逐层泛型滤子 G_n 与
条件 p_{n+1} 强制 (σ_G)_G(n) 的值——稳赢验证靠事实 3.1.6
的绝对性与 M_ω=⋃M_n 上的泛型性。

### 定理 3.19 的 (1)→(3)：e 函数与 B₀/B₁ 分解

设 A 广泛贝尔。在 λ^ω 上取典型的连续满射结构：令 S ⊆ λ^ω
同胚于 ω^ω 的 G_δ 像，定义

  e(f) = {(n,m) | ∃k ((f↾k, (n,m)) ∈ f(0))}

则 e:S→ω^ω，且在 S 的某个 G_δ 子集 S′ 上连续。由广泛
贝尔（对 λ），e⁻¹[A] 与 e⁻¹[ω^ω−A] 都有贝尔性质。取
B₀、B₁ 与稠密开集列 ⟨D_n | n<ω⟩ 实现：

  e⁻¹[A] △ (B₀ ∩ ⋂_n D̄_n) 稀疏，e⁻¹[ω^ω−A] △ (B₁ ∩ ⋂_n D̄_n) 稀疏

三条事实随之：(a) e⁻¹[A]∩⋂D̄_n ⊆ B₀∩⋂D̄_n；(b)
e⁻¹[ω^ω−A]∩⋂D̄_n ⊆ B₁∩⋂D̄_n；(c) B₀∪B₁ 稠密开。
(a) 的验证：设 α∈A，τ 是 α 的典型名字，B_τ = {f∈S |
f(0)=τ} 既开又闭；对 f∈B_τ 有 e(f)=α∈A，而 B_τ∩⋂D̄_n
在 B_τ 中稠密，于是 f 落进 B₀∩⋂D̄_n。

然后定义树对：T 的节点形如 (o, (τ, p₀, …, p_k))，其中
τ∈ω^<ω 是实数前段、p₀,…,p_k 是 λ^<ω 的层链，满足
各 p_i 是前一段的延伸、层条件对齐，且强制条件

  ⟦τ⌢p₀⌢⋯⌢p_k⌢s ⊆ f → f ∈ B₀∩⋂D_j⟧

成立——T* 把 B₀ 换成 B₁。势的估计给出 |T|,|T*| > λ。
**(i)** A = π[T]、ω^ω−A = π[T*] 由 (a)(b) 的包含与
稀疏差集给出；**(ii)** 对任意力迫 P：若 g 是 V 上的
Col(ω,λ)-泛型（P 可吸收进 Col），则 g 落在
(B₀∪B₁)∩⋂D̄_n 之外的部分稀疏，于是 g 必被 T 或 T*
之一接住——⊩ π[T]∪π[T*] = ω^ω。

### 定理 3.20 的张三策略：逐层构造

赛事 G_X：张三、李四轮流伸长一个实数（第 0 步张三给
无穷序列的开头，此后各自轮填一段），无穷局的结果实数
∈X 则张三胜。**定理 3.20**：张三有稳赢策略 ⟹ C₀−X
稀疏（C₀ 是基本开集族的可数并骨架）。证明 (1)→(3)：

1. 取双射 π:ω→ω×ω 使 π 满足「坐标还原延迟有界」；
2. 归纳造可数同质模型链 M₀≺M₁≺⋯：M_n ⊇ [q_n]∪M_{n−1}
   （李四第 n 步的条件与旧模型一并收进新模型）；
3. 在 M_n 上取 P_n 的泛型滤子 G_n，令 c_n = (σ_G)_{G_n}，
   则 c_n∈π[T] 且 c_n↾n = c_{n−1}↾n（层间嵌合）；
4. 张三的应手：p_{n+1} ⊆ c_n 强制 (σ_G)_G(n) = c_n(n)
   ——把泛型实数的第 n 位钉死；
5. 终局：M_ω = ⋃M_n，赛局生成的滤子 G_ω 是 M_ω 上的
   泛型滤子，⋂[p_n] = ⋂[q_n] = {(σ_G)_{G_ω}} ⊆ π[T]。

稳赢的根源：**每一步都把对手的应手吸收进更大的可数
模型，再用泛型性把「赢的条件」钉进层链**。事实 3.1.6
（语句的绝对性）保证 σ 在各层之间的含义不变。

## 五、正则性回报：测度、拉姆齐、伯恩斯坦

**定理 3.21（FMW）**：广泛贝尔 ⟹ 勒贝格可测且有拉姆齐
特性。测度侧：取测度代数 B_m = B(R)/I_m（正测度博雷尔集
模零测理想），随机实数名字 G，B₀ = ⟦G∈π[T]⟧、B₁ =
⟦G∈π[T*]⟧；**断言一**：B₀△A 零测——对足够大的正则 κ
取可数同质子模型 M，M 上的随机实数落在 B₀ 就把
π[T]-成员资格带进 V，M 可数 + 测度代数 ccc 把误差压成
零测。拉姆齐侧：Mathias 力迫 B(α)（(t,X) 条件、X∈[ω]^ω）
的泛型实数 x_G 与每个 y∈[x_G]^ω 仍生成泛型滤子——由
⊤_B π[T]∪π[T*]=ω^ω 与条件所侧，得 V⊨[x_G]^ω⊆π[T]。
**推论 3.16（Galvin-Prikry）**：博雷尔集有拉姆齐特性；
**推论 3.17（Silver）**：解析集有拉姆齐特性。

伯恩斯坦特性走 **Sacks 力迫**：P = {p ⊆ 2^<ω | p 完备树}，
Sacks 实数 s_G = ⋃{s | ∀p∈G, s∈p}。**事实 3.1.8**：若
p ⊩ s∈π[T]，则张三在赛事 G**(A)（双方轮流出**完备树**，
所出必须是对手前树的子树）中有以 p 开局的稳赢策略 σ。
策略的融合构造：分叉点 s（p_s⌢0、p_s⌢1∈p），映射
t ↦ (p_t, q_t⌢0, q_t⌢1) 保持递降完备树列，极限交集是
单点 {f*}，且 t↦f* 是连续单射——由此 [q]⊆π[T] 的强条件。
事实本身的证明用可数模型链 M_n 与逐层泛型 c_n，尾条件
p_{n+1} ⊩ (σ_G)_G(n) = c_n(n) 钉住数码。

**定理 3.23** 把本章两端缝合：对无穷基数 λ，下列等价——
(1) 一切 |P|≤λ 的力迫保持 Π₂(α) 语句的真值；(2) 只需检查
P = Col(ω,λ)；(3) 一切 Δ¹₂ 集是 λ-广泛贝尔；(4) 对一切
连续 f:λ^ω→ω^ω 与 Π¹ 函数 g，存在余稀疏 A⊆λ^ω 与连续
h 使 h = g∘f 于 A 上。(2)→(3) 用 Δ¹₂ 的双向树表示 +
Shoenfield（把 ⊩ Col 的语句在 V 中解码）；(3)→(4) 与
(4)→(2) 分别是稀疏例外分解与展示函数定理（定理 3.6）的
对偶搬运。**广泛贝尔因此是「小力迫绝对性」的实数侧面孔**。

### 定理 3.21 的两个半场

**测度半场**。设 A 广泛贝尔，取定理 3.19(2) 的树对。
在测度代数 B_m = B(ℝ)/I_m（正测度博雷尔集模零测理想，
完备布尔代数、ccc）中，⊤_{B_m} ⊩ π[T]∪π[T*] = ω^ω。
令 G 为随机实数的典型名字，B₀ = ⟦G∈π[T]⟧、
B₁ = ⟦G∈π[T*]⟧。**断言一：B₀△A 零测。**

证明取足够大的正则 κ 与包含一切相关对象的可数同质
子模型 M。设 r 是 M 上的随机实数：

- r∈B₀ ⟹ M[r] ⊨ r∈π[T]（B₀ 的定义），且由
  π[T] 的绝对性（树的具体性），V ⊨ r∈π[T]=A；
- r∉B₀ ⟹ r∈B₁，同理 V ⊨ r∉A。

于是 B₀△A ⊆ 「M 上非随机方向的实数集」。M 可数 ⟹
M 中只有可数多个 B_m 的极大反链方向；ccc + 可数链
条件下，非随机方向的并是零测集——B₀△A 零测，A 勒贝格
可测。

**拉姆齐半场**。Mathias 力迫 B(α) 的条件是 (t,X)：
t∈[ω]^<ω、X∈[α]（无穷子集），(t,X) ≤ (t′,X′) ⟺
t′⊇t 末段于 X′ 且 X⊆X′。泛型实数 x_G = ⋃{s |
∃X (s,X)∈G} 严格单调。**关键引理**：对每个 y∈[x_G]^ω，
H_y = {(y↾n, B) | ∃m (n<m ∧ (y∖m)⊆B ∈ G)} 仍是
V 上的 B-泛型滤子且 x_{H_y} = y。于是 ⊤_B 的覆盖
判断（y∈π[T] 或 y∈π[T*]）在层间不翻转，而泛型性使
x_G 侧的判断对一切 y∈[x_G]^ω 一致：V ⊨ [x_G]^ω ⊆ A
或 ∩A——拉姆齐特性成立。推论 3.16/3.17 把「广泛」
换成「博雷尔/解析」，树表示给出同样的双树覆盖。

### Sacks 力迫与伯恩斯坦特性

伯恩斯坦特性：对每个完备子集 P，A∩P 或 A^c∩P 含
完备子集。例 3.4：闭集全体有伯恩斯坦特性且构成
σ-代数的种子。**事实 3.1.8** 的赛事 G**(A)：双方轮流
出**完备树**，每手必须是对手前树的子树：

  p₀ ⊇ q₀ ⊇ p₁ ⊇ q₁ ⊇ ⋯（完备树降链）

终局交集 D = ⋂[p_n] = ⋂[q_n]。若 p ⊩ s_G∈π[T]，则
张三有以 p₀=p 开局的稳赢策略 σ。策略的**融合构造**：
对 t∈2^<ω 归纳定义 (p_t, q_{t⌢0}, q_{t⌢1})，使

  q_{t⌢0} ≤ p_t ≤ p、q_{t⌢1} ≤ p_t、q_{t⌢0}⊥q_{t⌢1}、
  p_t = q_{t⌢0}∪q_{t⌢1}（分叉覆盖）

且沿每条 f∈2^ω，⟨p_{f↾n}⟩ 是一场 σ 应对的赛局，
⋂[p_{f↾n}] = {f*}，映射 f↦f* 连续单射。由此把
[q]（李四首手以下的全部结果）压进 π[T]。稳赢性的
证明与定理 3.20 同构：可数模型链 + 逐层泛型 + 数码
钉死（p_{n+1} ⊩ (s_G)_G(n) = c_n(n)）。

### 定理 3.23：四等价的搬运路线

(1)⟺(2)：|P|≤λ 时 P×Col(ω,λ) 与 Col(ω,λ) 同构
（吸收引理），Π 性质向上保持。
(2)→(3)：Δ¹₂ 集 A = π[T]∩π[S]（双向表示），由 (2)
的绝对性，⊩_{Col} 的覆盖语句在 V 解码，得定理 3.19
的双树条件——A 是 λ-广泛贝尔。
(3)→(4)：对连续 f 与 Π¹ 函数 g，每个 g⁻¹[N_s] 是
Δ¹₂（Π¹ 函数的原像是 Δ¹₂——111 章的范数机构），
λ-广泛贝尔给出开集 D_s 与稀疏差集；令 A = 余稀疏的
交，h = g∘f 于 A 上连续。
(4)→(2)：反证——若 V[G] ⊨ ∃α∀β¬φ(α,β) 而
V ⊨ ∀α∃βφ(α,β)，取典型名字 τ 与函数表示 f（G_δ
连续化），展示函数定理（定理 3.6）给 Π¹ 的 g 分解
α；由 (4) 的分解在余稀疏集上复原见证，矛盾。

四条里 (3) 是「实数侧的稳定正则」，(2) 是「语句侧的
力迫不变」——定理 3.23 是把广泛贝尔与力迫绝对性焊在
一起的焊点。

## 六、机器件与边界声明

七通道吃下三件机制，全部在有限层：

1. **BK 件**（引理 3.20 机制核）：`bkLT` 递归扫描（右表
   先尽为真；表头相等下移；相异比大小）；定理「s⌢a <_BK s」
   （延伸者更小）与「沿实数前缀链每步递降」；ε 最大元。
   Julia/Python 另在有限窗口上验证线性序与最长递降链。
2. **双树件**（定理 3.19 机制核）：`caught`（全前缀在树中）；
   首位分裂对 pT/pS；覆盖定理（**对一切深度成立**——「广泛」
   的有限影子）；根交独占 ⟹ 投影不交。
3. **稳定件**（定理 3.19(3) 的 ⊩ 面）：`caught_shrink`——
   细化的实数被接住 ⟹ 截断（旧实数）仍被接住；Julia/Python
   枚举**截断对反例**（覆盖深度 1 成立、深度 2 失守）与
   2^≤2 上全部 25 个前缀闭节点集、81 个根交独占对、其中
   64 个覆盖@1、4 个侥幸覆盖@2、**60 个不稳定对**；Prolog
   检查扩张前后投影不变。

> **边界声明**：本章机器件只验证有限结构上的机制步骤。
> 「对一切深度 d 覆盖」是「对一切力迫扩张 ⊩ π[T]∪π[T*]=ω^ω」
> 的有限影子，**不是**其证明；60 个不稳定对说明「当前宇宙
> 覆盖一次」在扩张下可以失守，这正是定义 3.9 要全称量化
> 的原因。可测基数、泛型嵌入 j_G、测度代数与 Mathias/
> Sacks 力迫的定理（3.16–3.18、3.21、3.23）是超穷层的
> 本体，机器不伪造它们的结论。

## 七、Lean：递归扫描与三件定理

Lean 把 BK 序写成双表递归函数，`bk_snoc`（延伸者更小）
一行归纳，`bk_take_step` 用自建方程（沿 108 章纪律不依赖
外部 `List.take` 引理形态）把「前缀链递降」钉死；双树件
给出 `caught`（注意 Lean 里 `catch` 是关键字，故用
`caught`）、首位分裂对的覆盖定理、`no_dual_catch`（首位
不能既是 0 又是 1——`omega` 收尾）；稳定件 `caught_shrink`
用自建 `take_append_le`。

```lean
# 第 113 章 · Σ¹₃ 集合与广泛贝尔特性

namespace Settheory.Ch113Sigma13

/-- 布劳威尔-克林序 s <_BK t：递归扫描双表头——右表先尽（t ⊏ s）为真；
表头相等则下移一位；表头相异则比大小（首异位 s(k) < t(k)）。 -/
def bkLT : List Nat → List Nat → Bool
  | [], _ => false
  | _ :: _, [] => true
  | s₀ :: s', t₀ :: t' => if s₀ = t₀ then bkLT s' t' else decide (s₀ < t₀)

/-- 引理 3.20 的核心一步：s ++ [a] <_BK s（延伸者更小）。 -/
theorem bk_snoc (s : List Nat) (a : Nat) : bkLT (s ++ [a]) s = true := by
  induction s with
  | nil => simp [bkLT]
  | cons b s' ih =>
    have e1 : (b :: s') ++ [a] = b :: (s' ++ [a]) := by simp
    rw [e1]
    have e2 : bkLT (b :: (s' ++ [a])) (b :: s') = bkLT (s' ++ [a]) s' := by
      simp only [bkLT, reduceIte]
    rw [e2]
    exact ih

/-- 自建方程（108 章纪律：不依赖外部 take 引理形态）：
k < x.length 时 take (k+1) x = take k x ++ [x.getD k 0]。 -/
theorem take_step (x : List Nat) : ∀ k < x.length,
    x.take (k + 1) = x.take k ++ [x.getD k 0] := by
  induction x with
  | nil => intro k hk; simp at hk
  | cons a t ih =>
    intro k hk
    match k with
    | 0 => simp
    | m + 1 =>
      have hm : m < t.length := by simpa using hk
      have e := ih m hm
      show a :: t.take (m + 1) = (a :: t.take m) ++ [t.getD m 0]
      rw [List.cons_append, e]

/-- 沿实数前缀链每步严格递降：take (k+1) x <_BK take k x。 -/
theorem bk_take_step (x : List Nat) (k : Nat) (hk : k < x.length) :
    bkLT (x.take (k + 1)) (x.take k) = true := by
  rw [take_step x k hk, bk_snoc]

/-- ε 是布劳威尔-克林序下的最大元（定理 3.15(3)(a)）。 -/
theorem bk_nil_max (s : List Nat) (hs : s ≠ []) : bkLT s [] = true := by
  match s with
  | [] => exact absurd rfl hs
  | b :: t => rfl

/-- caught p x：实数 x 的每一段前缀都被树 p 接住（π[p] 的有限替身）。 -/
def caught (p : List Nat → Bool) (x : List Nat) : Prop :=
  ∀ k ≤ x.length, p (x.take k) = true

/-- 稳定对之一：首位 0 树（T = {ε} ∪ 0⌢2^<ω）。 -/
def pT : List Nat → Bool
  | [] => true
  | b :: _ => decide (b = 0)

/-- 稳定对之二：首位 1 树（T* = {ε} ∪ 1⌢2^<ω）。 -/
def pS : List Nat → Bool
  | [] => true
  | b :: _ => decide (b = 1)

/-- 定理 3.19 的「广泛」面：首位 0 的实数在一切深度都被 pT 接住。 -/
theorem caught_pT_of_zero (t : List Nat) : caught pT (0 :: t) := by
  intro k _
  match k with
  | 0 => rfl
  | m + 1 => rfl

/-- 同上：首位 1 的实数在一切深度都被 pS 接住。 -/
theorem caught_pS_of_one (t : List Nat) : caught pS (1 :: t) := by
  intro k _
  match k with
  | 0 => rfl
  | m + 1 => rfl

/-- 根部独占交（T ∩ T* = {ε}）⟹ 投影不交：首位不可能既是 0 又是 1。 -/
theorem no_dual_catch (b : Nat) (t : List Nat) :
    ¬ (caught pT (b :: t) ∧ caught pS (b :: t)) := by
  intro ⟨h1, h2⟩
  have e1 : pT [b] = true := h1 1 (by simp)
  have e2 : pS [b] = true := h2 1 (by simp)
  simp only [pT, pS] at e1 e2
  rw [decide_eq_true_iff] at e1 e2
  omega

/-- 自建方程：k ≤ x.length 时 take k (x ++ [a]) = take k x
（细化的前段仍是原前段）。 -/
theorem take_append_le (x : List Nat) : ∀ (a : Nat) (k : Nat), k ≤ x.length →
    (x ++ [a]).take k = x.take k := by
  induction x with
  | nil => intro a k hk; match k with
    | 0 => rfl
    | m + 1 => simp at hk
  | cons b t ih =>
    intro a k hk
    match k with
    | 0 => rfl
    | m + 1 =>
      have hm : m ≤ t.length := Nat.le_of_succ_le_succ hk
      show b :: (t ++ [a]).take m = b :: t.take m
      rw [ih a m hm]

/-- 外延稳定性（力迫扩张影）：新实数 x ++ [a] 被接住 ⟹ 旧实数 x 仍被接住。
有限影子中「扩张」即细化一层——定理 3.19 (3) 的 ⊩ 面。 -/
theorem caught_shrink (p : List Nat → Bool) (x : List Nat) (a : Nat)
    (h : caught p (x ++ [a])) : caught p x := by
  intro k hk
  rw [← take_append_le x a k hk]
  exact h k (Nat.le_trans hk (by simp))

/-- 交接样本：bkLT 在二元窗口上的取值（0 < 1 决定首异位方向）。 -/
example : bkLT [0, 1] [1, 0] = true := by rfl

example : bkLT [1, 0] [0, 1] = false := by rfl

example : bkLT [0, 0, 1] [0, 0] = true := by rfl

end Settheory.Ch113Sigma13
```

要点：`bkLT` 的三行匹配恰是数学定义的三分——右表先尽
（真前段）、表头相等（下移）、表头相异（比大小）；`decide`
化的大小比较让 `bk_snoc` 的归纳一步成功（`if h : s₀ = t₀`
的 `if_pos` + `reduceIte`）。`caught_pT_of_zero` 的证明是
两个 `rfl`：`take 0` 与 `take (m+1)` 在构造子上一步归约，
`pT`（首位判 0）跟着归约——「对一切深度」就体现在这个
对 k 的任意性里。

### Lean 逐段精讲

**定义层**。`bkLT` 的三行函数方程对应 BK 序的三分：
第一行 `[], _ => false`（空序列不小于任何东西——它是
最大元）；第二行 `_ :: _, [] => true`（非空序列小于
空序列——真前段条款，右表先尽）；第三行对两个非空表
比较表头：相等则下移一位递归（共同前段的延后判决），
相异则 `decide (s₀ < t₀)` 当场判决。注意这不是字典序：
字典序把短前段排在前（小），BK 序把延伸者排在小侧——
方向恰好相反，而正是这个反向让「无穷树枝」对应「无穷
递降链」而不是递升链。

**`bk_snoc`**。归纳于 s：s=[] 时 `[] ++ [a] = [a]`，非空
对空，第二行直接给 true；s=b::s′ 时 cons 追加可换位
（`(b::s′) ++ [a] = b::(s′++[a])`），表头相等的事实由
`simp only [bkLT, reduceIte]` 处理——`if s₀ = t₀` 的
条件在 `s₀ = t₀ = b` 时被 `reduceIte` 消解成 `if True`，
露出归纳假设。这一步是全章最常复用的局部引理。

**`take_step` 与 `bk_take_step`**。`take_step` 是自建
方程（不依赖 `List.take_succ` 的外部形态——108 章立下
的纪律：take/drop 的库引理名在各版本间漂移，自建归纳
最稳）：k=0 时两侧都是 `[]`/`[x[k]]` 的平凡形；k=m+1
时 cons 下的 take 逐步剥离，`List.cons_append` 把
`(a :: t.take m) ++ [t.getD m 0]` 重排成
`a :: (t.take m ++ [t.getD m 0])`，正好接上归纳假设。
`bk_take_step` 把 `bk_snoc` 装配上去：前缀链的每一对
相邻段（k+1 段与 k 段）构成 snoc 关系。

**`caught` 与覆盖定理**。`caught p x` 量词是
`∀ k ≤ x.length`——「不超过长度的每一段」正是有限影子
里 π[p] 的成员资格（无穷情形要求一切前段，有限实数的
前段只有有穷多段）。`caught_pT_of_zero` 的证明体是两
个 `rfl`：对 k 的分案（0 或 m+1）各自一步归约——
`take 0 _ = []` 与 `take (m+1) (0::t) = 0::take m t` 都
是定义性归约，`pT` 对 `[]` 与 `0::_` 的方程也是构造子
级归约。**「对一切深度」体现在 k 的任意性**：定理没有
对深度的任何限制，任何长度的首位 0 实数都被接住。

**`no_dual_catch`**。在 k=1 处取段：`take 1 (b::t)` 即
`[b]`，`pT [b] = decide (b = 0)`、`pS [b] = decide (b = 1)`，
两个 `decide_eq_true_iff` 解码后 `omega` 收出 0≠1。
这就是「根部独占交 ⟹ 投影不交」在有限层的全部内容：
共享的只有 ε（k=0 段），一旦进入 k=1，首位分裂立即
排除同时接住的可能。

**`take_append_le` 与 `caught_shrink`**。前者自建
（k≤长度时先取段与 snoc 可交换——空表分支的
`succ ≤ 0` 由 `simp at hk` 关闭）；后者把稳定性钉死：
`caught p (x ++ [a])` 给出的是细化实数的全前缀成员
资格，对 k ≤ |x| 用 `take_append_le` 把细化前段换回
原前段，得 `caught p x`。有限层的「力迫扩张」就是
snoc 一层；本体层是任意力迫 P。

## 八、Coq：change 定向与 lia 的类型盲区

Coq 版与 Lean 同账。两处工程点：其一，`firstn` 的
`succ` 步方程若用 `simpl` 会被过度展开成对尾表的 `match`
（`simpl` 对变量表的 `firstn (S k)` 一展到底），故用
`change` 精确钉住目标形再 `rewrite IH`；其二，`lia` 把
`length` 当不透明原子，跨 `length (a::t)` 与 `length t`
的算术必须先 `simpl in Hk` 归一。`no_dual_catch` 在
k=1 处取段，`Nat.eqb_eq` 解码后 `lia` 收出 0≠1。

```coq
(* 第 113 章：Σ¹₃ 集合与广泛贝尔——布劳威尔-克林序、双树互补、
   外延稳定性（定理 3.19 的机制核；本体留在正文 docs/113-sigma13.md）。 *)
Require Import List Arith Lia.
Import ListNotations.

(* ── 一、布劳威尔-克林序（引理 3.20 机制核） ──
   s <_BK t ⟺ t ⊏ s（真前段）∨ 首异位 s(k) < t(k)。
   递归扫描：右表先尽为真；表头相等下移；表头相异比大小。 *)
Fixpoint bkLT (s t : list nat) : bool :=
  match s, t with
  | [], _ => false
  | _ :: _, [] => true
  | s0 :: s', t0 :: t' => if Nat.eqb s0 t0 then bkLT s' t' else Nat.ltb s0 t0
  end.

(* 延伸者更小：s ++ [a] <_BK s（树枝的每一步都是递降）。 *)
Lemma bkLT_snoc : forall (s : list nat) (a : nat),
  bkLT (s ++ [a]) s = true.
Proof.
  induction s as [|b s' IH]; intros a; simpl.
  - reflexivity.
  - rewrite IH. now rewrite Nat.eqb_refl.
Qed.

(* ε 是最大元（定理 3.15(3)(a)）。 *)
Lemma bkLT_nil_max : forall s : list nat, s <> [] -> bkLT s [] = true.
Proof. intros [|b t] Hne; [contradiction | reflexivity]. Qed.

(* 自建方程：k < length x 时 firstn (S k) x = firstn k x ++ [nth k x 0]。 *)
Lemma firstn_step : forall (x : list nat) (k : nat), k < length x ->
  firstn (S k) x = firstn k x ++ [nth k x 0].
Proof.
  induction x as [|a t IH]; intros k Hk.
  - simpl in Hk; lia.
  - destruct k as [|m].
    + reflexivity.
    + change (firstn (S (S m)) (a :: t)) with (a :: firstn (S m) t).
      change (firstn (S m) (a :: t)) with (a :: firstn m t).
      change (nth (S m) (a :: t) 0) with (nth m t 0).
      simpl in Hk. rewrite IH by lia.
      reflexivity.
Qed.

(* 沿实数前缀链每步严格递降：firstn (S k) x <_BK firstn k x。 *)
Lemma bkLT_firstn_step : forall (x : list nat) (k : nat), k < length x ->
  bkLT (firstn (S k) x) (firstn k x) = true.
Proof.
  intros x k Hk.
  rewrite firstn_step by assumption.
  apply bkLT_snoc.
Qed.

(* ── 二、双树互补（定理 3.19 机制核） ──
   catch p x：x 的每一段前缀都被树 p 接住（π[p] 的有限替身）。 *)
Definition catch (p : list nat -> bool) (x : list nat) : Prop :=
  forall k, k <= length x -> p (firstn k x) = true.

(* 首位分裂对：T = {ε} ∪ 0⌢ω^<ω，T* = {ε} ∪ 1⌢ω^<ω（T ∩ T* = {ε}）。 *)
Definition pT (s : list nat) : bool :=
  match s with [] => true | b :: _ => Nat.eqb b 0 end.
Definition pS (s : list nat) : bool :=
  match s with [] => true | b :: _ => Nat.eqb b 1 end.

(* 「广泛」面：首位 0 的实数在一切深度都被 pT 接住。 *)
Lemma catch_pT_zero : forall t : list nat, catch pT (0 :: t).
Proof.
  intros t k _. destruct k as [|m]; reflexivity.
Qed.

Lemma catch_pS_one : forall t : list nat, catch pS (1 :: t).
Proof.
  intros t k _. destruct k as [|m]; reflexivity.
Qed.

(* 根部独占交（T ∩ T* = {ε}）⟹ 投影不交（π[T] ∩ π[T*] = ∅）。 *)
Lemma no_dual_catch : forall (b : nat) (t : list nat),
  ~ (catch pT (b :: t) /\ catch pS (b :: t)).
Proof.
  intros b t [H1 H2].
  assert (Hlen : 1 <= length (b :: t)) by (simpl; lia).
  specialize (H1 1 Hlen). specialize (H2 1 Hlen).
  simpl in H1, H2.
  apply Nat.eqb_eq in H1. apply Nat.eqb_eq in H2.
  subst. lia.
Qed.

(* ── 三、外延稳定性（定理 3.19 (3) 的 ⊩ 面） ── *)

(* 自建方程：k ≤ length x 时 firstn k (x ++ [a]) = firstn k x。 *)
Lemma firstn_app_snoc_le : forall (x : list nat) (a k : nat), k <= length x ->
  firstn k (x ++ [a]) = firstn k x.
Proof.
  induction x as [|b t IH]; intros a k Hk.
  - simpl in Hk. destruct k as [|m].
    + reflexivity.
    + simpl in Hk; lia.
  - destruct k as [|m].
    + reflexivity.
    + change ((b :: t) ++ [a]) with (b :: (t ++ [a])).
      change (firstn (S m) (b :: (t ++ [a]))) with (b :: firstn m (t ++ [a])).
      change (firstn (S m) (b :: t)) with (b :: firstn m t).
      simpl in Hk. rewrite IH by lia. reflexivity.
Qed.

(* 新实数 x ++ [a] 被接住 ⟹ 旧实数 x 仍被接住。 *)
Lemma catch_shrink : forall (p : list nat -> bool) (x : list nat) (a : nat),
  catch p (x ++ [a]) -> catch p x.
Proof.
  intros p x a H k Hk.
  rewrite <- (firstn_app_snoc_le x a k Hk).
  apply H. rewrite length_app. simpl. lia.
Qed.

(* ── 四、样本对拍（与 Julia/Python 同账） ──
   首异位 0 < 1 定方向；真前段定方向。 *)
Example bk_sample_01 : bkLT [0; 1] [1; 0] = true.
Proof. reflexivity. Qed.

Example bk_sample_10 : bkLT [1; 0] [0; 1] = false.
Proof. reflexivity. Qed.

Example bk_sample_prefix : bkLT [0; 0; 1] [0; 0] = true.
Proof. reflexivity. Qed.

(* 样本实数 [0;1;1]：前缀链 [ []; [0]; [0;1]; [0;1;1] ] 逐对递降。 *)
Example branch_chain_sample :
  bkLT [0;1;1] [0;1] = true /\ bkLT [0;1] [0] = true /\ bkLT [0] [] = true.
Proof. repeat split; reflexivity. Qed.
```

样本对拍（`bk_sample_01` 等）与 Julia/Python 的输出同账：
首异位 0<1 定方向、真前段定方向；`branch_chain_sample`
把 [0;1;1] 的前缀链三对递降一次断言。

### Coq 逐段精讲

**`bkLT` 的 Fixpoint**。三分与 Lean 同构，比较用
`Nat.eqb`/`Nat.ltb`（bool 版），`bkLT_snoc` 的归纳步里
`Nat.eqb_refl` 处理表头自反。注意 Coq 的 `match s, t with`
四分支里 `[], _` 与 `_, []` 的次序——右表先尽的分支必须
在两个非空分支之前，否则 `[] @ [a]` 对 `[]` 的情形会
漏匹配。

**`firstn_step` 的三处定向**。这条自建方程最容易踩
`simpl` 的坑：对变量表 t，`simpl` 会把 `firstn (S m) t`
展开成对 t 的 `match`（stdlib 的 firstn 在表为变量时
暴露 match 骨架），归纳假设的 `firstn (S m) t` 形态就对
不上了。解法是 `change` 三连：先把目标里的
`firstn (S (S m)) (a :: t)` 钉成 `a :: firstn (S m) t`、
`firstn (S m) (a :: t)` 钉成 `a :: firstn m t`、
`nth (S m) (a :: t) 0` 钉成 `nth m t 0`——三个 change
都是定义性等价（firstn/nth 在 cons 上的方程），然后
`rewrite IH` 直接收口。`simpl in Hk` 的位置也讲究：
lia 把 `length (a :: t)` 当不透明原子，先 simpl 归一成
`S (length t)`，lia 才能从 `S m < S (length t)` 给出
`m < length t`。

**`catch_pT_zero` 的两行**。`destruct k` 后两个
`reflexivity`：k=0 时 `firstn 0 _ = []`、`pT [] = true`；
k=S m 时 `firstn (S m) (0::t) = 0::firstn m t`、
`pT (0::_) = Nat.eqb 0 0 = true`——都是一键归约。

**`no_dual_catch` 的链**。k=1 处（`1 <= length (b::t)`
由 `simpl; lia` 给出），两个特化后的假设经 `simpl`
归一到 `Nat.eqb b 0 = true` / `Nat.eqb b 1 = true`，
`Nat.eqb_eq` 解码成 b=0 与 b=1，`subst; lia` 收尾。
注意 `subst` 只能替换其中一个（另一个变成 0=1 的
线性矛盾），`lia` 对 0≠1 的自然数矛盾直接关闭。

**`firstn_app_snoc_le` 与 `catch_shrink`**。前者同样用
change 三连避开 simpl 过展；后者的 `apply H` 需要
`k <= length (x ++ [a])`——`rewrite length_app`（8.20 起
`app_length` 改名）把长度拆成 `length x + length [a]`，
simpl 后 lia 从 `k ≤ length x` 给出。这条引理的 Isabelle
对应物（`take_snoc_le`）因为 ZF 的 take 机构更原始，
工程量大得多——两相对照能看清「库的成熟度」如何影响
同一个数学事实的证明形状。

## 九、Agda：方程按构造子保留

Agda 走 110–112 章立的 Dec/构造子路线：自建 `eq?`/`lt?`
判定（方程按构造子保留），`bkLT-app` 用 `eq?-refl` 一步
改写；`caught-pT-zero` 的两个 `refl` 靠 `take` 的定义性
归约；`no-dual-caught` 用 `trans` 把 `b≡0` 与 `b≡1` 焊成
`0≢1`；稳定件 `caught-shrink` 需要 `length-snoc` 桥接
（`length (x ++ [ a ])` 不能一步归约到 `suc (length x)`，
自建引理 + `m≤n⇒m≤1+n`）。

```agda
-- 第 113 章：Σ¹₃ 集合与广泛贝尔——布劳威尔-克林序、双树互补、
-- 外延稳定性（定理 3.19 的机制核；本体留在正文 docs/113-sigma13.md）。
module Ch113_sigma13 where

open import Data.Nat using (ℕ; zero; suc; _≤_; z≤n; s≤s)
open import Data.Nat.Properties using (≤-refl; ≤-trans; m≤n⇒m≤1+n)
open import Data.List using (List; []; [_]; _∷_; _++_; take; length)
open import Data.Bool using (Bool; true; false; if_then_else_)
open import Data.Product using (_×_; _,_; proj₁; proj₂)
open import Relation.Binary.PropositionalEquality using (_≡_; refl; sym; cong; trans)
open import Relation.Nullary using (¬_)
open import Data.Empty using (⊥; ⊥-elim)

-- ── 零、自建件（沿 110-112 章纪律：方程自建、不依赖外部形态） ──

-- 自建相等/小于判定：方程按构造子保留。
eq? : ℕ → ℕ → Bool
eq? zero zero = true
eq? zero (suc _) = false
eq? (suc _) zero = false
eq? (suc m) (suc n) = eq? m n

lt? : ℕ → ℕ → Bool
lt? zero zero = false
lt? zero (suc _) = true
lt? (suc _) zero = false
lt? (suc m) (suc n) = lt? m n

eq?-refl : ∀ n → eq? n n ≡ true
eq?-refl zero = refl
eq?-refl (suc n) = eq?-refl n

-- ── 一、布劳威尔-克林序（引理 3.20 机制核） ──
-- s <_BK t ⟺ t ⊏ s（真前段）∨ 首异位 s(k) < t(k)。
-- 递归扫描：右表先尽为真；表头相等下移；表头相异比大小。
bkLT : List ℕ → List ℕ → Bool
bkLT [] _ = false
bkLT (_ ∷ _) [] = true
bkLT (s₀ ∷ s') (t₀ ∷ t') = if eq? s₀ t₀ then bkLT s' t' else lt? s₀ t₀

-- 延伸者更小：s ++ [a] <_BK s（树枝的每一步都是递降）。
bkLT-app : ∀ (s : List ℕ) (a : ℕ) → bkLT (s ++ [ a ]) s ≡ true
bkLT-app [] a = refl
bkLT-app (b ∷ s') a rewrite eq?-refl b = bkLT-app s' a

-- ε 是最大元（定理 3.15(3)(a)）。
bkLT-[]-max : ∀ s → ¬ (s ≡ []) → bkLT s [] ≡ true
bkLT-[]-max [] h = ⊥-elim (h refl)
bkLT-[]-max (b ∷ t) h = refl

-- ── 二、双树互补（定理 3.19 机制核） ──
-- caught p x：x 的每一段前缀都被树 p 接住（π[p] 的有限替身）。
caught : (List ℕ → Bool) → List ℕ → Set
caught p x = ∀ k → k ≤ length x → p (take k x) ≡ true

-- 首位分裂对：T = {ε} ∪ 0⌢ω^<ω，T* = {ε} ∪ 1⌢ω^<ω（T ∩ T* = {ε}）。
pT : List ℕ → Bool
pT [] = true
pT (b ∷ _) = eq? b 0

pS : List ℕ → Bool
pS [] = true
pS (b ∷ _) = eq? b 1

-- 「广泛」面：首位 0 的实数在一切深度都被 pT 接住。
caught-pT-zero : ∀ t → caught pT (0 ∷ t)
caught-pT-zero t zero h = refl
caught-pT-zero t (suc m) h = refl

caught-pS-one : ∀ t → caught pS (1 ∷ t)
caught-pS-one t zero h = refl
caught-pS-one t (suc m) h = refl

-- 根部独占交（T ∩ T* = {ε}）⟹ 投影不交（π[T] ∩ π[T*] = ∅）。
eq?-0-true : ∀ b → eq? b 0 ≡ true → b ≡ 0
eq?-0-true zero h = refl
eq?-0-true (suc b) ()

eq?-1-true : ∀ b → eq? b (suc zero) ≡ true → b ≡ suc zero
eq?-1-true zero ()
eq?-1-true (suc zero) h = refl
eq?-1-true (suc (suc b)) ()

0≢1 : zero ≡ suc zero → ⊥
0≢1 ()

no-dual-caught : ∀ b t → ¬ (caught pT (b ∷ t) × caught pS (b ∷ t))
no-dual-caught b t (h1 , h2) =
  0≢1 (trans (sym (eq?-0-true b e1)) (eq?-1-true b e2))
  where
  e1 : pT (take (suc zero) (b ∷ t)) ≡ true
  e1 = h1 (suc zero) (s≤s z≤n)
  e2 : pS (take (suc zero) (b ∷ t)) ≡ true
  e2 = h2 (suc zero) (s≤s z≤n)

-- ── 三、外延稳定性（定理 3.19 (3) 的 ⊩ 面） ──

-- 自建方程：k ≤ length x 时 take k (x ++ [a]) = take k x。
take-snoc≤ : ∀ (x : List ℕ) (a k : ℕ) → k ≤ length x →
  take k (x ++ [ a ]) ≡ take k x
take-snoc≤ [] a zero h = refl
take-snoc≤ [] a (suc k) ()
take-snoc≤ (b ∷ t) a zero h = refl
take-snoc≤ (b ∷ t) a (suc k) (s≤s h) =
  cong (_∷_ b) (take-snoc≤ t a k h)

-- 自建方程：snoc 后长度恰加一。
length-snoc : ∀ (x : List ℕ) (a : ℕ) → length (x ++ [ a ]) ≡ suc (length x)
length-snoc [] a = refl
length-snoc (b ∷ t) a = cong suc (length-snoc t a)

-- 新实数 x ++ [a] 被接住 ⟹ 旧实数 x 仍被接住。
caught-shrink : ∀ p x a → caught p (x ++ [ a ]) → caught p x
caught-shrink p x a h k hk =
  trans (cong p (sym (take-snoc≤ x a k hk))) (h k (≤snoc x a k hk))
  where
  ≤snoc : ∀ y a j → j ≤ length y → j ≤ length (y ++ [ a ])
  ≤snoc y a j hj rewrite length-snoc y a = ≤-trans hj (m≤n⇒m≤1+n ≤-refl)

-- ── 四、样本对拍（与 Julia/Python/Lean/Coq 同账） ──

bk-sample-01 : bkLT (0 ∷ 1 ∷ []) (1 ∷ 0 ∷ []) ≡ true
bk-sample-01 = refl

bk-sample-10 : bkLT (1 ∷ 0 ∷ []) (0 ∷ 1 ∷ []) ≡ false
bk-sample-10 = refl

bk-sample-prefix : bkLT (0 ∷ 0 ∷ 1 ∷ []) (0 ∷ 0 ∷ []) ≡ true
bk-sample-prefix = refl

branch-chain-sample :
  (bkLT (0 ∷ 1 ∷ 1 ∷ []) (0 ∷ 1 ∷ []) ≡ true)
  × ((bkLT (0 ∷ 1 ∷ []) (0 ∷ []) ≡ true)
  × (bkLT (0 ∷ []) [] ≡ true))
branch-chain-sample = refl , refl , refl
```

注意 `take-snoc≤` 的空表 succ 分支用空模式 `()`：`suc k ≤ 0`
本身是空类型（`≤` 的构造子 `z≤n` 要求左侧为 `zero`、
`s≤s` 要求右侧为 `suc`）。

### Agda 逐段精讲

**自建判定件**。`eq?`/`lt?` 按 110–112 章的纪律自建：
方程按构造子保留（zero 对 zero、suc 对 suc 递归），
交叉情形直接给布尔常量。`eq?-refl` 是后续一切改写的
支点：`bkLT-app` 的 cons 情形里 `rewrite eq?-refl b`
把 `eq? b b` 换成 true，函数体露出递归调用，接上归纳
假设。stdlib 的 `_≟_` 也能用，但 stdlib 路线在 with
分支里会丢掉方程（112 章的教训），自建件把方程留在
构造子层面。

**`caught-pT-zero` 的两个 refl**。`take zero (0 ∷ t) = []`
与 `take (suc m) (0 ∷ t) = 0 ∷ take m t` 都是 Data.List
的 take 在构造子上的定义性归约；`pT [] = true` 与
`pT (0 ∷ _) = eq? 0 0` 也一步归约——所以两个分支都是
裸 `refl`。这与 Lean 的两个 `rfl`、Coq 的两个
`reflexivity` 是同一个事实的三份投影。

**`no-dual-caught` 的焊接**。`e1`/`e2` 在 k=1（写
`suc zero`——数字字面量在此文件未引入）处特化：
`take (suc zero) (b ∷ t)` 定义性归约为 `b ∷ []`，
`pT (b ∷ []) = eq? b 0`。`eq?-0-true`/`eq?-1-true` 把
布尔等式翻回 `b ≡ 0`/`b ≡ 1`（注意 `eq?-1-true` 要分
b=1 与 b≥2 两案——`suc zero` 情形可证、`suc (suc _)`
情形空模式），最后 `trans (sym b≡0) b≡1` 焊出
`zero ≡ suc zero`，`0≢1` 的空模式收口。

**`take-snoc≤` 与 `caught-shrink`**。snoc 长度引理
`length-snoc` 必须自建：`length (x ++ [ a ])` 在 x 为
变量时不能一步归约（++ 在左参数为变量时卡住），归纳
一层（cons 情形 `cong suc`）即得。`caught-shrink` 的
主证明把 `sym (take-snoc≤ …)` 与 `h k (≤snoc …)` 用
`trans` 接起来——前者把目标里的 `p (take k x)` 换回
`p (take k (x ++ [ a ]))`，后者是细化实数的成员资格；
长度侧的 `≤snoc` 走 `length-snoc` 改写加
`m≤n⇒m≤1+n`（`≤-step` 在 stdlib 2.0 起改名，本章用
新名）。

## 十、Isabelle/ZF：归纳关系与确定性规则链

Isabelle 版吃 ZF.List 的现成机构，但 o 型 primrec 写不了
命题值函数，BK 序改用**归纳定义的关系版**（`prefixI`：
真前段；`diffI`：首异位）——`bk_snoc` 与 `bk_Nil_max`
各自一条规则一步到位。双树件是 set 版 `caught`（有界

其中两处工程坑值得记录：`bspec` 的实例改经 `subgoal_tac`

整步拒绝）；`take_snoc_succ` 的结论取 `Cons(a, l@[b])`

### Isabelle/ZF 逐段精讲（含本章实测坑账）

**为什么 BK 序写成归纳关系**。ZF 的 `primrec` 方程要求
两边是集合（`=` 作用于 i 型），命题值（o 型）函数写不进
primrec 方程。改用 `inductive` 关系版：`prefixI`（真前段：
u 非空时 ⟨t@u, t⟩∈bkre）与 `diffI`（公共前段 p 后首异位
a<b）两条 intro 规则——数学定义的两个条款各成一条规则，
`bk_snoc`（u=[b] 的 prefixI 特例）与 `bk_Nil_max`（t=Nil、
u=s 的 prefixI 特例，需 `subgoal_tac` 先把目标摆成
⟨[]@s, []⟩ 形再由 simp 收——⟨s,[]⟩ 与 ⟨[]@s,[]⟩ 的
差异在 app 的定义性归约，规则匹配不做这层红展）。

**`caught` 的条件形定义**。`∀k ∈ nat. k ≤ length(x) ⟶
take(k,x) ∈ T` 是 107 章立的有界 ∀∈ 条件形——比
`succ(length x)` 的 Ball 形更顺 `erule_tac n = k in natE`
的分案。

**本章实测坑账（ZF 侧五记）**：

1. **条件式 `take_0` 在简化器里击发不了**：前提
   `xs:list(A)` 需要类型检查，而 ZF 的 simp 不跑 TC
   （`nat_succI`、`list.intros` 是 intro/TC 不是重写
   规则）。解法：`caught_one` 的 k=0 分支走
   `subgoal_tac` + `take_0` + 显式类型链
   （`list.intros` → `nat_succI` → `nat_0I` →
   `assumption`）；`take_zero_cons` 干脆自建无条件版
   （`simp add: take_def` 展开递归算子）。
2. **`erule list.cases` 不钉参数会高阶飘移**：cases
   规则的 scrutinee 必须用 `erule_tac a = u in
   list.cases` 钉住，否则 unify 在目标上乱配（实测
   挂死）。同理 `list.induct` 的参数名是 x 不是 a。
3. **`[OF]` 只解析元级前提**：对象级 `⟶` 要过
   `[THEN mp]` 桥——`himp0 [OF kle]` 直接炸 THM 0，
   `himp0 [THEN mp, OF kle]` 才通。
4. **规则结论要取规范形**：`take_snoc_succ` 的结论
   写 `take(K, Cons(a, l @ [b]))`（app 已展开）而不是
   `take(K, Cons(a,l) @ [b])`——simp 早把目标规范化了，
   一阶统一不做 app 红展。natE 分案留下的等式假设
   `k = succ(x)` 由引理前提 `hK` 直接吸收。
5. **链式事实与规则前提序失配**：`drule bspec` 产生
   的链式前提必须与规则第一条前提同类，否则 `rule`
   整步拒绝。解法：改经 `subgoal_tac` 把实例化前提
   送入目标上下文（`take_snoc_le` 的 Cons 支）。

**`no_dual_caught` 的全长取段**。ZF 侧不在 k=1 处取段
（`take 1` 的类型链麻烦），改在全长处：`take_all` 给出
`take(length(Cons(b,l)), Cons(b,l)) = Cons(b,l)`，于是
「被两树接住」直接落在 Cons(b,l) 上，`T0_T1_inter`
（交恰为 {Nil}）+ `simp` 收出矛盾。`himp0`/`himp1` 用
`[THEN bspec, OF kn]` 的事实链方向（事实先走 THEN，
前提吸收在 OF——与 `bspec [OF X]` 的规则方向相比，
事实方向让谓词保持具体，避免高阶多义）。

**`caught_shrink` 的两座桥**。长度桥 `le_succ_step`
（自建：`succ_iff`+`ltI`+`leI` 三连）+ `le_trans`；
取段桥 `take_snoc_le [OF hx kn kle]`（meta 形的
rule_format 直接三参 OF——注意它已经不是 Ball，不能再
走 bspec）。两桥合龙后 `simp` 收尾。

## 十一、Julia：枚举账本

Julia 承担两件：BK 序的有限窗口实验（线性序三性质、最长
递降链 DP、16 条序列的前缀链递降）与双树枚举账本（25 个

```julia
# 第 113 章：Σ¹₃ 与广泛贝尔——布劳威尔-克林序、双树互补、外延稳定性
# 的有限对拍（与 Python 独立同账；四证明通道见 Lean/Coq/Agda/Isabelle）。
println("==== 113")

# ── 一、布劳威尔-克林序（引理 3.20 机制核） ──
# bkLT(s, t) ⟺ t ⊏ s（真前段）∨ 首异位 s(k) < t(k)。延伸者更小。
function bkLT(s::Vector{Int}, t::Vector{Int})::Bool
    if length(t) < length(s) && s[1:length(t)] == t
        return true
    end
    m = min(length(s), length(t))
    for k in 1:m
        if s[k] != t[k]
            return s[k] < t[k]
        end
    end
    return false
end

# 窗口 2^≤d 的全部节点（含空段）。
allnodes(d) = vcat([Int[]],
    [[(i >> (k - j)) & 1 for j in 1:k] for k in 1:d for i in 0:(2^k - 1)])

# 长度 d 的全部实数（细化宇宙）。
space(d) = [[(i >> (d - 1 - j)) & 1 for j in 0:(d - 1)] for i in 0:(2^d - 1)]

# 二元窗口 2^≤3：全 15 节点——BK 是线性序（书断言），逐对验证。
nodes3 = allnodes(3)
@assert length(nodes3) == 15
pairs = [(a, b) for a in nodes3 for b in nodes3 if a != b]
total = sum(bkLT(a, b) != bkLT(b, a) for (a, b) in pairs)
anti = sum(!bkLT(a, a) for a in nodes3)
transok = all(!(bkLT(a, b) && bkLT(b, c)) || bkLT(a, c)
             for a in nodes3 for b in nodes3 for c in nodes3)
nilmax = all(bkLT(s, Int[]) for s in nodes3 if !isempty(s))
println("[BK] 2^≤3 线性序: 节点 15, 完全对 $(length(pairs)) 中恰好一向 $(total), 无自环 $(anti)/15, 传递 $(transok), ε 最大元 $(nilmax)")
@assert total == length(pairs) && anti == 15 && transok && nilmax

# 全二叉树 depth d 的最长 BK 递降链（按线性序排序后 DP）。
function longest_chain(d::Int)::Int
    ns = allnodes(d)
    sorted = sort(ns, lt = (x, y) -> bkLT(x, y))
    len = Dict(n => 1 for n in ns)
    for s in sorted
        for t in ns
            if bkLT(t, s)
                len[s] = max(len[s], len[t] + 1)
            end
        end
    end
    maximum(values(len))
end
chains = [longest_chain(d) for d in 0:3]
println("[BK] 全二叉树最长递降链: d=0→$(chains[1]) d=1→$(chains[2]) d=2→$(chains[3]) d=3→$(chains[4])（= 2^(d+1)-1，线性序容纳全部节点）")
@assert chains == [2^(d + 1) - 1 for d in 0:3]

# 长度 4 的全部 16 条序列：前缀链逐对递降（树枝即递降链）。
branch_ok = sum(all(bkLT([(i >> (3 - j)) & 1 for j in 0:3][1:k+1],
                        [(i >> (3 - j)) & 1 for j in 0:3][1:k]) for k in 0:3)
                for i in 0:15)
println("[BK] 16 条长度 4 序列前缀链递降: $(branch_ok)/16")
@assert branch_ok == 16

# ── 二、双树互补（定理 3.19 机制核） ──
# caught(T, x)：x 的每一段前缀都在树 T 中（π[T] 的有限替身）。
caught(T, x) = all(x[1:k] in T for k in 0:length(x))

# 稳定对：首位分裂 T = {ε}∪0⌢2^<ω，T* = {ε}∪1⌢2^<ω（对一切深度成立）。
pT(s) = isempty(s) || s[1] == 0
pS(s) = isempty(s) || s[1] == 1

for d in 1:6
    cov = all(x -> pT(x) || pS(x), space(d))
    dis = all(x -> !(pT(x) && pS(x)), space(d))
    @assert cov && dis
end
println("[双树-稳定对] 深度 1..6 全覆盖 ✓ 不相交 ✓（对深度无量化限制=「广泛」的影子）")

# 投影不变（外延稳定性）：细化的实数被接住 ⟹ 截断（旧实数）仍被接住。
refine_ok = sum(begin
    x = y[1:d]
    (pT(y) ? pT(x) : true) && (pS(y) ? pS(x) : true)
end for d in 1:5 for y in space(d + 1))
nref = sum(1 for d in 1:5 for y in space(d + 1))
@assert refine_ok == nref
println("[双树-稳定对] 投影不变: $(refine_ok)/$(nref) 条细化路径的截断保持接住 ✓")

# 截断对（覆盖当前宇宙 ≠ 广泛贝尔）：T = {ε,0}，T* = {ε,1}。
tt(s) = s == Int[] || s == [0]
ts(s) = s == Int[] || s == [1]
cov1 = all(x -> tt(x) || ts(x), space(1))
cov2 = all(x -> tt(x) || ts(x), space(2))
fails = [x for x in space(2) if !(tt(x) || ts(x))]
println("[双树-截断对] 覆盖深度 1: $(cov1)；覆盖深度 2: $(cov2) — 失败见证 $(fails)")
@assert cov1 && !cov2 && length(fails) == 4

# ── 三、枚举反例（Julia/Python 独立对拍） ──
# 2^≤2 上含根前缀闭节点集共 25 个；根交仅 {ε} 的有序对中
# 覆盖@1 但不覆盖@2 者即「不稳定对」（当前宇宙成立 ≠ 扩张后成立）。
prefix_closed(sub) = all(s[1:k] in Set(sub) for s in sub for k in 0:length(s) - 1)
inner = [[0], [1], [0, 0], [0, 1], [1, 0], [1, 1]]
subsets = [Set(vcat([Int[]], [inner[i] for i in 1:6 if (mask >> (i - 1)) & 1 == 1]))
           for mask in 0:63]
closed = unique(Set, filter(prefix_closed, subsets))
@assert length(closed) == 25
println("[枚举] 2^≤2 前缀闭节点集(含根): $(length(closed)) 个")

root_only = [(A, B) for A in closed for B in closed if intersect(A, B) == Set([Int[]])]
cov1pairs = [(A, B) for (A, B) in root_only if all(x -> x in A || x in B, space(1))]
cov2pairs = [(A, B) for (A, B) in cov1pairs if all(x -> caught(A, x) || caught(B, x), space(2))]
unstable = setdiff(Set(cov1pairs), Set(cov2pairs))
println("[枚举] 根交={ε} 有序对 $(length(root_only))；覆盖@1 $(length(cov1pairs))；其中覆盖@2 $(length(cov2pairs))；不稳定 $(length(unstable))")
bytotal = sort(collect(unstable), by = AB -> length(AB[1]) + length(AB[2]))
A1, B1 = bytotal[1]
minimal = sort(collect(A1), by = length)
minimal2 = sort(collect(B1), by = length)
println("[枚举] 最小不稳定对: T=$(repr(minimal)) / T*=$(repr(minimal2))（覆盖@1、扩张后失守——见证 [0,0]）")

println("BK 序线性/最长链/树枝递降；稳定对全覆盖+投影不变；截断对反例；枚举 25/不稳定账")
println("END ====")
```

输出对账：`[枚举] 根交={ε} 有序对 81；覆盖@1 64；其中

T={ε,1}/T*={ε,0}**（或对称）覆盖深度 1 却在深度 2 全军
覆没：这就是「当前宇宙验证一次 ≠ 广泛」的机器证据。

### Julia 逐段精讲

**BK 件的三项实验**。`bkLT` 的 Julia 版按定义直写：
先查真前段（长度与逐位比较），再扫首个相异位。三项
实验各有寓意：其一，2^≤3 的 15 节点两两验证「恰好一向」
（完全性+反对称）与三元传递（15³=3375 组）——书的
「线性序」断言在有限窗口的全检；其二，全二叉树 depth
d 上的最长递降链 DP：按 BK 升序排序后逐节点向前看，
`len[s] = max(len[t]+1)`——结果 1,3,7,15 恰为 2^(d+1)−1，
线性序下全部节点排进一条链（排链的显式形态：
d=2 时 [0,1] > [0,0] > [0] > []，首异位条款把同层
节点按字典序倒挂）；其三，16 条长度 4 序列的前缀链
逐对递降——`bkLT(x[1:k+1], x[1:k])` 对 k=0..3 全真，
这是 `bk_snoc` 的可执行化身。

注意 `longest_chain` 的复杂度是 O(n²)（对每个 s 扫全
体 t）——15 节点的窗口无所谓；线性序下其实排序后
一遍扫描即可，保留双层是为了让「BK 递降」的判断显式
可见。

**双树件**。`caught(T, x)` 的集合版与 `pT`/`pS` 的谓词
版并存：谓词版用于「对一切深度」的覆盖断言（深度 1..6
的双循环），集合版用于枚举账。`refine_ok` 段验证投影
不变：对深度 1..5 的每条细化路径 y（共 2²+...+2⁶=124
条），y 被接住 ⟹ 截断仍被接住——Julia 侧用嵌套生成器
避免顶层循环的全局变量坑（1.13 的老坑：顶层 for 里的
`+=` 需 `global`）。

**枚举账本**。六位掩码枚举 2^≤2 的非根节点子集，前缀
封闭性过滤后恰 25 个（结构：根必在；0 的孩子要 0 在；
1 的孩子要 1 在——按 {0,1} 的选中组合算，1+4+4+16=25）。
根交独占的有序对 81 个、覆盖@1 的 64 个（0 与 1 各被
恰一棵树接住）、其中真正覆盖@2 的只有 4 个（树恰好在
深度 2 长满的侥幸对）、**60 个不稳定对**。最小的稳定
失守对 T={ε,1}/T*={ε,0}（Python 侧找到的是
T={ε}/T*={ε,0,1}——同尺寸的另一极小元）：覆盖深度 1
因为两条实数 [0]、[1] 分别被接住；深度 2 的四条实数
全部落空——**覆盖一次 ≠ 广泛**，这就是定义 3.9 全称
量词的机器证据。

## 十二、Python 与 Prolog：对拍与扩张检查

Python 与 Julia 独立同账（元组版），计数逐项相等。Prolog
检查「扩张前后投影不变」：`stable_around` 验证稳定对在
深度 D 与 D+1 都覆盖且不相交，`refine_stable` 验证细化
路径的截断保持接住，`trunc_witness` 列出截断对在深度 2

```python
# 第 113 章：Σ¹₃ 与广泛贝尔——与 Julia 独立对拍：BK 序、双树互补、
# 外延稳定性与枚举反例（四证明通道见 Lean/Coq/Agda/Isabelle）。
import io
import sys
from itertools import product

sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding="utf-8")


# ── 一、布劳威尔-克林序（引理 3.20 机制核） ──
# bk_lt(s, t) ⟺ t ⊏ s（真前段）∨ 首异位 s(k) < t(k)。延伸者更小。
def bk_lt(s, t):
    if len(t) < len(s) and s[: len(t)] == t:
        return True
    for k in range(min(len(s), len(t))):
        if s[k] != t[k]:
            return s[k] < t[k]
    return False


def all_nodes(dmax):
    out = [()]
    for k in range(1, dmax + 1):
        out.extend(product((0, 1), repeat=k))
    return out


def space(d):
    return list(product((0, 1), repeat=d))


def main():
    print("==== 113")

    # 二元窗口 2^≤3：全 15 节点——BK 是线性序（书断言），逐对验证。
    nodes3 = all_nodes(3)
    assert len(nodes3) == 15
    pairs = [(a, b) for a in nodes3 for b in nodes3 if a != b]
    total = sum(bk_lt(a, b) != bk_lt(b, a) for a, b in pairs)
    anti = sum(not bk_lt(a, a) for a in nodes3)
    transok = all(
        not (bk_lt(a, b) and bk_lt(b, c)) or bk_lt(a, c)
        for a in nodes3
        for b in nodes3
        for c in nodes3
    )
    nilmax = all(bk_lt(s, ()) for s in nodes3 if s)
    print(f"[BK] 2^≤3 线性序: 节点 15, 完全对 {len(pairs)} 中恰好一向 {total}, "
          f"无自环 {anti}/15, 传递 {transok}, ε 最大元 {nilmax}")
    assert total == len(pairs) and anti == 15 and transok and nilmax

    # 全二叉树 depth d 的最长 BK 递降链（按线性序排序后 DP）。
    def longest_chain(d):
        ns = all_nodes(d)
        order = sorted(ns, key=lambda x: 0)  # 占位，下面用 cmp 排
        import functools

        order = sorted(ns, key=functools.cmp_to_key(
            lambda x, y: -1 if bk_lt(x, y) else (1 if bk_lt(y, x) else 0)))
        best = {n: 1 for n in ns}
        for s in order:
            for t in ns:
                if bk_lt(t, s):
                    best[s] = max(best[s], best[t] + 1)
        return max(best.values())

    chains = [longest_chain(d) for d in range(4)]
    print(f"[BK] 全二叉树最长递降链: d=0→{chains[0]} d=1→{chains[1]} "
          f"d=2→{chains[2]} d=3→{chains[3]}（= 2^(d+1)-1，线性序容纳全部节点）")
    assert chains == [2 ** (d + 1) - 1 for d in range(4)]

    # 长度 4 的全部 16 条序列：前缀链逐对递降（树枝即递降链）。
    branch_ok = sum(
        all(bk_lt(x[: k + 1], x[:k]) for k in range(4)) for x in space(4)
    )
    print(f"[BK] 16 条长度 4 序列前缀链递降: {branch_ok}/16")
    assert branch_ok == 16

    # ── 二、双树互补（定理 3.19 机制核） ──
    # caught(T, x)：x 的每一段前缀都在树 T 中（π[T] 的有限替身）。
    def caught(T, x):
        return all(x[:k] in T for k in range(len(x) + 1))

    # 稳定对：首位分裂 T = {ε}∪0⌢2^<ω，T* = {ε}∪1⌢2^<ω（对一切深度成立）。
    def pT(s):
        return not s or s[0] == 0

    def pS(s):
        return not s or s[0] == 1

    for d in range(1, 7):
        assert all(pT(x) or pS(x) for x in space(d))
        assert not any(pT(x) and pS(x) for x in space(d))
    print("[双树-稳定对] 深度 1..6 全覆盖 ✓ 不相交 ✓（对深度无量化限制=「广泛」的影子）")

    # 投影不变（外延稳定性）：细化的实数被接住 ⟹ 截断（旧实数）仍被接住。
    nref = 0
    for d in range(1, 6):
        for y in space(d + 1):
            x = y[:d]
            if pT(y):
                assert pT(x)
            if pS(y):
                assert pS(x)
            nref += 1
    print(f"[双树-稳定对] 投影不变: {nref}/{nref} 条细化路径的截断保持接住 ✓")

    # 截断对（覆盖当前宇宙 ≠ 广泛贝尔）：T = {ε,0}，T* = {ε,1}。
    tt = {(), (0,)}
    ts = {(), (1,)}
    cov1 = all(x in tt or x in ts for x in space(1))
    cov2 = all(x in tt or x in ts for x in space(2))
    fails = [x for x in space(2) if x not in tt and x not in ts]
    print(f"[双树-截断对] 覆盖深度 1: {cov1}；覆盖深度 2: {cov2} — 失败见证 {fails}")
    assert cov1 and not cov2 and len(fails) == 4

    # ── 三、枚举反例（与 Julia 独立对拍） ──
    # 2^≤2 上含根前缀闭节点集共 25 个；根交仅 {ε} 的有序对中
    # 覆盖@1 但不覆盖@2 者即「不稳定对」（当前宇宙成立 ≠ 扩张后成立）。
    def prefix_closed(sub):
        S = set(sub)
        return all(s[:k] in S for s in sub for k in range(len(s)))

    inner = [(0,), (1,), (0, 0), (0, 1), (1, 0), (1, 1)]
    closed = set()
    for mask in range(64):
        sel = {inner[i] for i in range(6) if (mask >> i) & 1}
        sel.add(())
        if prefix_closed(sel):
            closed.add(frozenset(sel))
    assert len(closed) == 25
    print(f"[枚举] 2^≤2 前缀闭节点集(含根): {len(closed)} 个")

    root_only = [(A, B) for A in closed for B in closed
                 if set(A) & set(B) == {()}]
    cov1pairs = [(A, B) for A, B in root_only
                 if all(x in A or x in B for x in space(1))]
    cov2pairs = [(A, B) for A, B in cov1pairs
                 if all(caught(A, x) or caught(B, x) for x in space(2))]
    unstable = [p for p in cov1pairs if p not in cov2pairs]
    print(f"[枚举] 根交={{ε}} 有序对 {len(root_only)}；覆盖@1 {len(cov1pairs)}；"
          f"其中覆盖@2 {len(cov2pairs)}；不稳定 {len(unstable)}")
    assert (len(root_only), len(cov1pairs), len(cov2pairs),
            len(unstable)) == (81, 64, 4, 60)

    A1, B1 = min(unstable, key=lambda AB: len(AB[0]) + len(AB[1]))
    print(f"[枚举] 最小不稳定对: T={sorted(A1, key=len)} / T*={sorted(B1, key=len)}"
          "（覆盖@1、扩张后失守——见证 (0,0)）")

    print("BK 序线性/最长链/树枝递降；稳定对全覆盖+投影不变；截断对反例；枚举 25/不稳定账")
    print("END ====")
```

```prolog
:- encoding(utf8).

% 第 113 章：Σ¹₃ 与广泛贝尔——BK 序、双树互补、外延稳定性与
% 「扩张前后投影不变」的检查（与 Julia/Python 对拍；四证明通道另见）。

% ── 一、布劳威尔-克林序（引理 3.20 机制核） ──
% bk(S, T)：S <_BK T 即 T 是 S 的真前段，或首异位 S(k) < T(k)。
% 地基递归：右表先尽为真；表头相等下移；表头相异比大小。
bk([_|_], []).
bk([S0|Ss], [T0|Ts]) :-
    (   S0 =:= T0
    ->  bk(Ss, Ts)
    ;   S0 < T0
    ).

% 前缀取段：pfx(X, K, P) —— P 是 X 的前 K 段。
pfx(_, 0, []).
pfx([H|T], K, [H|R]) :- K > 0, K1 is K - 1, pfx(T, K1, R).

% 长度 D 的二元实数全集。
bits(0, []).
bits(D, X) :- D > 0, D1 is D - 1, bits(D1, Y), (X = [0|Y] ; X = [1|Y]).

% 整数到位串（地基枚举 2^D 条长度 D 序列）。
int_bits(0, 0, []).
int_bits(I, N, [B|Bs]) :-
    N > 0, N1 is N - 1, H is 1 << N1,
    (   I >= H
    ->  B = 1, I1 is I - H
    ;   B = 0, I1 = I
    ),
    int_bits(I1, N1, Bs).

% 沿实数前缀链逐对递降（树枝即递降链：k+1 段 <_BK k 段）。
branch_desc(X) :-
    length(X, N), N1 is N - 1,
    forall(between(0, N1, K),
           (K2 is K + 1, pfx(X, K2, P1), pfx(X, K, P0), bk(P1, P0))).

% ── 二、双树互补（定理 3.19 机制核） ──
% 稳定对（首位分裂）：p_t 与 p_s 对一切深度成立。
p_t([]).
p_t([0|_]).
p_s([]).
p_s([1|_]).

% caught(P, X)：X 的每一段前缀都被树 P 接住（pi[P] 的有限替身）。
caught(P, X) :-
    length(X, N),
    forall(between(0, N, K), (pfx(X, K, Q), call(P, Q))).

% 覆盖：深度 D 的每条实数被两树之一接住。
cover2(P, Q, D) :-
    forall(bits(D, X), (caught(P, X) -> true ; caught(Q, X))).

% 不相交：没有实数被两树同时接住。
disjoint2(P, Q, D) :-
    forall(bits(D, X), \+ (caught(P, X), caught(Q, X))).

% 截断对（覆盖当前宇宙不等于广泛贝尔）：T = {eps,0}，T* = {eps,1}。
tt([]).
tt([0]).
ts([]).
ts([1]).

% ── 三、外延稳定性：扩张前后投影不变 ──
% 细化一层（深度 D+1）被接住 => 截断（深度 D，旧实数）仍被同一棵树接住。
refine_stable(D) :-
    forall((bits(D + 1, Y), append(X, [_], Y)),
           ((p_t(Y) -> p_t(X) ; true), (p_s(Y) -> p_s(X) ; true))).

% 稳定对的覆盖在扩张前后（深度 D 与 D+1）都成立——「广泛」的量化面向。
stable_around(D) :-
    cover2(p_t, p_s, D), disjoint2(p_t, p_s, D),
    D1 is D + 1,
    cover2(p_t, p_s, D1), disjoint2(p_t, p_s, D1).

% 截断对的反例见证：覆盖@1 成立、@2 失守，四条路径全数落空。
trunc_witness(X) :-
    bits(2, X), \+ caught(tt, X), \+ caught(ts, X).

main :-
    % BK：样本取值与 Julia/Python 同账（0<1 定首异位；真前段定方向）。
    bk([0,1], [1,0]), \+ bk([1,0], [0,1]),
    bk([0,0,1], [0,0]), bk([0,1,1], [0,1]),
    % 16 条长度 4 序列前缀链逐对递降。
    forall(between(0, 15, I), (int_bits(I, 4, X), branch_desc(X))),
    % 稳定对：深度 1..3 覆盖 + 不相交；投影不变；扩张前后覆盖。
    forall(between(1, 3, D), stable_around(D)),
    forall(between(1, 3, D), refine_stable(D)),
    % 截断对：覆盖@1 成立、@2 失守，四条见证全数落空。

    findall(W, trunc_witness(W), Ws),

    format("截断对覆盖@1 失守@2（四条见证）；扩张前后投影不变~n"),
```

### Prolog 逐段精讲

**`bk/2` 的地基递归**。两条子句：`bk([_|_], [])`（右表
先尽——真前段）与表头比较（相等下移、相异 `S0 < T0`）。

## 十五、小结

本章把 Σ¹₃ 的两条入场券摆在桌上：大基数（可测 + 峭壁）
换来树表示与全正则，而广泛贝尔特性把「正则性」重新定义
为**对一切力迫扩张的稳定性**。二者在 Magidor 定理会师。
机器件的三件——BK 序的延伸者更小、双树的根交独占与
全深度覆盖、细化-截断的稳定性——都是本体证明里「本地
一步」的化身；60 个不稳定对是「广泛」的全称量词不可
省略的机器证据。

回看全章的三次视角切换：§二–§三站在**组合**一侧
（序、树、链——BK 序把「无穷」压缩成「递降」的可检
局部）；§四站在**拓扑**一侧（贝尔性质、稀疏集、连续
前像——广泛贝尔把正则性翻译成开集的可逼近性）；
§五站在**力迫**一侧（随机实数、Mathias 泛型、Sacks
融合——正则性由扩张下的稳定性反哺回来）。三次切换
共用同一批对象（树对、稀疏集、泛型滤子），这正是
描述集合论在 1970–1990 年间成型的思维方式：**不问
集合的大小，问集合在扰动下的形状保持**。

下一章带着这张票进入 Solovay 内模型与 HOD(Ω)：那里
「一切实数集都正则」首次在一致性的意义上落地，而
广泛贝尔特性将作为 HOD(Ω) 侧的可定义性接口再度
出场。
