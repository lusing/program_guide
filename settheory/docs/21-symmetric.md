# 21 · 对称子模型：ZF + ¬AC 的模型

> 在 ZFA 中原子的置换诱导宇宙自同构——在 ZF 中布尔代数的
> 自同态扮演同样的角色。两种"对称性"都杀死选择公理。
> ——对称模型法的世界观

本章覆盖 Jech §21：ZFA（带原子的集合论）、置换模型、
正规滤子与对称性、两个经典反例、对称模型（ZF 版本）。

## 21.1 ZFA：带原子的集合论

**原子**：无成员但可属于集合的对象。外延性 (21.1) 只约束
非原子（任意两原子有相同的成员——都没有——但不相等）。
宇宙分层 V_α(A)（从原子集 A 出发的累积层级）。

原子上的**置换** π : A → A 诱导 V 的 ∈-自同构：

    π(x) = π[x] = {π(t) : t ∈ x}   (21.4)

这是 ZFA 的独特特征——ZF 的宇宙无非平凡自同构，但 ZFA 的
可以任意置换原子。

## 21.2 正规滤子与对称性

**群** 𝔊 ⊆ Sym(A)。**正规滤子** 𝔽（子群族，(21.5)）：
(i) 𝔊 ∈ 𝔽；(ii) 上封闭；(iii) 交封闭；(iv) 共轭封闭
（πHπ⁻¹ ∈ 𝔽 当 H ∈ 𝔽）。

**对称集**：sym(x) = {π ∈ 𝔊 : π(x) = x} ∈ 𝔽。
**遗传对称类** 𝔐 = {x : TC({x}) 的每个元素对称}。

**引理 21.1** 𝔐 ⊨ ZFA——传递 + Gödel 封闭 + 几乎通用。

**有限支撑滤子**：𝔽 由 {fix(E) : E ⊆ A 有限} 生成
（fix(E) = 固定 E 中每个原子的置换）。此时 x 对称 ⟺ x 有
**有限支撑** E（固定 E 的置换固定 x）。

## 21.3 两个经典反例

**例 I（引理 21.2）** 𝔊 = Sym(A)，有限支撑滤子。
**A 在 𝔐 中无可数子集**——AC 失败。

*证明*：反设 f : ω → A 单射且 f ∈ 𝔐（有支撑 E）。取
a = f(n) ∈ A-E，取 b ∈ A-E-{a}。π 交换 a,b 且固定 E。
则 πf = f（π 固定支撑），但 π(f(n)) = π(a) = b ≠ a——
矛盾。∎

**例 II（引理 21.3）** A = ⋃ Pₙ（可数对的不交并），
𝔊 = 保对的置换。**{Pₙ} 无选择函数**——可数 AC 失败。

*证明*：反设 f 选择 f(Pₙ) ∈ Pₙ 且有支撑 E。取 n 使
aₙ, bₙ ∉ E。π 在 Pₙ 内交换 aₙ↔bₙ 且固定 E。则 πf = f
但 π(f(Pₙ)) = bₙ ≠ aₙ——矛盾。∎

Python（`examples/python/21_symmetric.py`）验证置换效果
（固定支撑、交换目标原子）与例 II 的对族选择矛盾。
Julia（`21_symmetric.jl`）同构骨架。

## 21.4 对称模型（ZF 版本）

在 ZF 中，用 **Aut(B)** 代替 Sym(A)：完备布尔代数 B 的
自同态群 𝔊 作用于 V^B 的名字（(19.13) 的自同态提升）。

**对称名**：sym(x) ∈ 𝔽；**HS** = 遗传对称名（对 ρ(x)
归纳：dom(x) ⊆ HS 且 x 对称 ⟹ x ∈ HS）。

**对称模型**：

    𝔑 = (i_G)"HS = {i_G(x) : x ∈ HS} ⊆ M[G]

**定理** 𝔑 ⊨ ZF——传递 + Gödel 封闭 + 几乎通用（对称性
的正规滤子条件 (iv) 保证 𝔑 对构造封闭）。

𝔑 可以不满足 AC——第 19 章的 HOD(A)（定理 45）是对称模型
的特例。对称模型法是构造 ¬AC 各种 weaken 形式的**标准工具**
——每个 ¬AC 后果都可以通过选择适当的 𝔊 与 𝔽 在对称模型
中独立验证。
