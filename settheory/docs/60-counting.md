# 60 · 计数：四式选取、排列组合与重排

> "俱乐部有 20 名成员，需要 6 名志愿者在一周的六天里轮流打扫咖
> 啡室——有多少种方式？"这个问题**没有答案**——或者说有好几个
> 答案，取决于你如何理解它。本章提炼 Makinson 第 5 章：加法与乘
> 法两大原理、次序与重复的 2×2 矩阵（四式选取）、排列与组合的
> 公式及其证明、容斥原理、允许重复的选取（隔板法）、重排
> （banana 有 60 种排法）。它是 26 章 Ramsey 组合与 31 章分划
> 演算的有限地基，也是 03 章基数算术的具体而微。

## 60.1 加法原理与减法原理

两个出发点（前者是第 1 章习题的正式化）：

- **减法原理**（差）：#(A\B) = #(A) − #(A∩B)。移项即得"一般并"的关键。
- **加法原理**（不交并）：A∩B = ∅ 时 #(A∪B) = #(A) + #(B)；n 个
  两两不交集推广为求和。**不交性不可省**：A = {1,2}、B = {2,3} 时
  #(A∪B) = 3 ≠ 4。

不交条件下 #(A∪B) = #(A) 当且仅当 B ⊆ A（另一方向：若 B 有元素
在 A 外，并至少比 A 多一）。

**一般并**（容斥的两集版）——拆成三块不交组件 A∩B、A\B、B\A，
各用减法原理展开：

    #(A∪B) = #(A∩B) + #(A\B) + #(B\A)
            = #(A∩B) + [#(A) − #(A∩B)] + [#(B) − #(A∩B)]
            = #(A) + #(B) − #(A∩B)

直觉账目：**交被数了两次，退一次**。两道应用：教室 17 男 + 18 女
+ 1 教授 = 36（三块不交）；逻辑班 (20 + 9 − 2) + 11 = 38（先用
一般并算"选了微积分或哲学"的，再加两者都不选的——不交！）。

## 60.2 乘法原理

**#(A×B) = #(A)·#(B)**；n 元组推广为连乘。证明即 57.1 的笛卡尔
积计数（按首坐标分层，层内 n 个、层间不交）。

应用速写：菜单四道工序 2·3·2·3 = 36 种套餐；伦敦号码 10⁸；车牌
23²·10⁴。**两原理联用**是常态：四位数以 5 或 73 开头的有
10³ + 10² = 1100 个（拆两个不交集，各自乘法原理）。

两则必须记住的忠告：

1. **Alice 的 maverick diner**（不点咖啡、水果先行）：现实计数问题
   常常**欠定**——"每人恰选一道、类序固定"是隐含假设，松动即得
   全然不同的数字。**最难的不是套公式，而是认定该套哪个公式**：
   什么算"同一选择"？
2. "衬衫×牛仔裤±领带"的 6·4 + 6·4·5 = 144，或引入"无领带"作第
   六种领带 6·4·6 = 144——**补虚拟选项**把不交并化成笛卡尔积，
   是计数的标准技巧。

## 60.3 四式选取：次序 × 重复

20 人选 6 志愿者的问题为什么没有唯一答案？因为先要回答两个
问题：**次序算不算**（周一我、周二你 与 对调 是两种还是一种）？
**重复允不允许**（同一人可否值两班）？2×2 得四模式：

| 模式 | 名称 | 函数对应 |
|---|---|---|
| O⁺R⁺ | 重复排列 | {1..k} → A 的**全体函数** |
| O⁺R⁻ | 排列 permutation | {1..k} → A 的**单射** |
| O⁻R⁻ | 组合 combination | A 的 **k 元子集**（= 单射的值域） |
| O⁻R⁺ | 重复组合 | A → {0..k} 的**和恰为 k 的计数函数**（多重集/bags） |

书中的 5×5 值日表是四模式的显微镜：五人选两人值两天，25 个格子里
——O⁺R⁺ 全数（25）；O⁺R⁻ 划掉对角线（25−5=20）；O⁻R⁺ 划掉
对角线下半（25−10=15）；O⁻R⁻ 两处都划（10）。**同一情景，四个
答案**。当 k > n：禁重复的两式（O⁺R⁻、O⁻R⁻）无解（单射不存在
——鸽笼！），允许重复的两式照常。

## 60.4 排列公式

    P(n,k) = n!/(n−k)!    （k ≤ n）

**推导**（乘法原理）：首位 n 选、次位 n−1 选（不能重）、……第 k 位
n−k+1 选，连乘恰为 n!/(n−k)!。三个要点：

- **0! = 1 的约定**为覆盖 k = n（P(n,n) = n!/0! = n!）——"从 n 个
  里不选任何东西恰有一种方式：什么都不做"。极限情形的约定以
  **让一般原理最顺**为准（n⁰ = 1 同理，甚至 0⁰ = 1："从空集里
  不选东西"也是做了一次空选择）。
- P(n,n) = n! = n 元集到自身的**双射个数**——58 章的会师。
- P(6,0..6) = 1, 6, 30, 120, 360, 720, 720——注意 P(6,5) = P(6,6)
  （1! = 0!），一般 P(n,n−1) = P(n,n)。
- 15 条领带穿五天不重样：15!/10! = 360360 周 ≈ **7000 年**——
  "十五条领带实在太多了"。

## 60.5 组合公式

    C(n,k) = n!/[k!·(n−k)!]

**证明**：C(n,k) 数的是 k 元子集；每个 k 元子集恰有 k! = P(k,k)
个排序；故有序选取数 = 无序数 × k!，即 P(n,k) = C(n,k)·k!。∎

C(6,0..6) = 1, 6, 15, 20, 15, 6, 1——**杨辉三角的第 6 行**：先升
后降、两端对称。对称律 C(n,k) = C(n,n−k) 由公式直接验证（分母
两因子互换）。投资顾问的 8 只股票：选 3 只买等额是组合 C(8,3) =
56；买 1千/2千/4千三级是排列 P(8,3) = 336——**同一情景，钱的
结构决定次序是否算数**。而"风险递减的三级投资"一题则超出了
四式（每步的选择空间依赖前步）——真实计数问题的" nasty"一课。

## 60.6 容斥原理

**三集版**（在两集版之上再"多退少补"）：

    #(A∪B∪C) = #A + #B + #C − #(A∩B) − #(B∩C) − #(A∩C)
              + #(A∩B∩C)

账目直觉：三交集的元素在 singles 里数了 3 次、在 pairs 里减了
3 次——净 0 次，须在 triples 加回。**一般 n 集**：交替加减
（单个加、成对减、三个加……），第 j 层恰有 C(n,j) 项——组合
系数在计"容斥本身有多少项"。名题：Amal 打给 5 人、Bertrand 10
人、Clarice 7 人，交叠 3/2/2、三人同 1：
5+10+7−3−2−2+1 = **16 人**。60.9 节机器复核。

## 60.7 允许重复的选取

**重复排列 O⁺R⁺**：n^k——每步都是 n 选（乘法原理直给）。函数
视角即 {1..k} → A 的全体函数个数 = |A|^k（57 章的表格又有新解）。
15 领带可重复版：15⁵ = 759375 周——比 7000 年更长。

**重复组合 O⁻R⁺**：**隔板法**（stars and bars）完整证明——把
计数函数 f（f(aᵢ) = 第 i 种物品取几个，Σf(aᵢ) = k）编码成一行
k + (n−1) 个槽：先写 f(a₁) 个"1"，一个"+"，f(a₂) 个"2"，一个
"+"，……（**末尾不放加号**，共 n−1 个）。模式由"哪 n−1 个槽放
加号"完全决定（其余按规则回填），故

    选取数 = C(k+n−1, n−1) = (n+k−1)!/[k!·(n−1)!]

——**O⁻R⁺ 被化归为更大池子上的 O⁻R⁻**。冰淇淋五味选三球：
次序有别的重复排列给 5³ = 125，次序无别的重复组合给
C(7,3) = 35——两种读法的合计分别是 155 与 55（差三倍）。
**题意的"歧义管理"是计数课的真功课**。

## 60.8 重排：banana 有 60 种排法

banana：次序重要、重复量**预定**（3 个 a、2 个 n、1 个 b）——
不是从 3 字母池里选 6 个，而是 6 个**字母出现**的排列。两种
gestalt，同一答案：

**方法一（下标字母 + 排列）**：写成 b₁a₁n₁a₂n₂a₃，6 个带标物体
有 6! = 720 种排列；抹掉 a 的下标每 3! 种塌缩成一种、n 每 2! 种
塌缩成一种：720/(3!·2!) = **60**。

**方法二（槽位 + 组合）**：6 个槽 s₁..s₆，选 3 个给 a
（C(6,3) 种），余 3 槽选 2 个给 n（C(3,2)），余 1 给 b（C(1,1)）：
C(6,3)·C(3,2)·C(1,1) = 6!/(3!2!) = **60**。

**一般公式**：n 个字母出现、k 种字母各出现 m₁,…,m_k 次（Σmᵢ = n），
重排数 = **n!/(m₁!·…·m_k!)**（方法二的丑连乘 C(n,m₁)·C(n−m₁,m₂)·…
逐项相消后恰化为此形——消元的美感值得亲手做一遍）。

三城假期投票——**机器审计书本字母账**（60.9 节 Julia/Python
按实拼写逐字母计数）：Mississippi 11!/(4!4!2!) = 34650 ✓（与书
一致）；Ouagadougou 的真实字母频（O1,o2,u3,a2,g2,d1）给
11!/48 = **831600**（书载 554400 ✗——书本的下标账漏了字母）；
Woolloomooloo 的真实频（W1,o8,l3,m1）给 13!/(8!·3!) = **25740**
（书载 4324320 ✗）。三城排序不变——**假期还是去 Woolloomooloo**
（拼写越怪、重排越多在此例不成立，但 Woolloomooloo 仍以 25740
领先？不——831600 > 25740，Ouagadougou 才是冠军！）。书本的
结论"去 Woolloomooloo"依赖其错误计数；机器修正后应去
Ouagadougou。**这是"公式对、输入账错"的活例**——garbage in,
garbage out 的组合版。（"同字母邻接"变体：捆块成 4 字母的普通
排列 4! = 24。）

## 60.9 机器通道

mathlib 的 `Nat.choose` 与 `Finset` 计数件是官方地基：

```lean
-- examples/lean/Settheory/Ch60Counting.lean（节选）
-- 组合的对称律：官方锚点（注意方向与前提 k ≤ n）
example {n k : ℕ} (hk : k ≤ n) : Nat.choose n (n - k) = Nat.choose n k :=
  Nat.choose_symm hk

-- 帕斯卡递推 C(n+1,k+1) = C(n,k) + C(n,k+1)：官方锚点
example (n k : ℕ) :
    Nat.choose (n + 1) (k + 1) = Nat.choose n k + Nat.choose n (k + 1) :=
  Nat.choose_succ_succ' n k

-- 杨辉三角第 6 行：1 6 15 20 15 6 1（decide 直接点亮）
example : [Nat.choose 6 0, Nat.choose 6 1, Nat.choose 6 2, Nat.choose 6 3,
    Nat.choose 6 4, Nat.choose 6 5, Nat.choose 6 6] = [1, 6, 15, 20, 15, 6, 1] := by
  decide
```

（文件里另有 P(6,k) 全表、banana = 60、Turramurra = 37800、
容斥 = 16、C(15,6) = 5005 等 `decide` 证书；注意 `6.choose` 会被
词法分析吃成小数——必须写 `Nat.choose 6 k`。）

Coq 通道把四式全部**枚举验证**：对 5 元集选 2 的四模式生成器
（乘积表 25、去对角 20、商集 15、子集 10）与公式对照；banana
重排用去重排序生成器数出恰 60；容斥用三人电话的具体集合复算
16。Julia/Python 用 `itertools`（product/permutations/combinations）
做同一件事并外推到大数（15 领带两版、Woolloomooloo）。Prolog
的 `permutation/2` 与自写组合生成器数 banana 的 60。

## 60.10 收束

两大原理（不交加、笛卡尔乘）× 两问（次序？重复？）= 四式选取，
再加上容斥与重排两件利器，构成有限组合的工具箱。61 章把这些
计数本能升级为**概率**：样本空间上的均匀分布让"数数"变成"算命"；
26 章的 Ramsey 理论则是本箱在无穷染色问题上的远征。
