## 79.1 树：把「前导」做成偏序

> **定义 2.31（树）** 偏序集 (T,<) 是一棵树，当且仅当：
>
> 1. T 有唯一的 <-最小元，称为**树根**；
> 2. 对每个 x∈T，其前导集 {y∈T | y<x} 在 < 下是一个秩序集。
>
> 节点 x 的**高度** hT(x) 是其前导集的序型；第 α **层**
> T_α = {x∈T | hT(x)=α}；树**高** ht(T)=min{α | T_α=∅}。
> 一根**树枝** b 是 T 的极大 <-秩序子集，长度 l(b)=ot(b,<)；
> l(b)=ht(T) 时称为**等高树枝**。截断 T↾α=⋃_{β<α}T_β；
> 子集 T′⊆T 是**子树**当且仅当它包含其中每个元素的全部前导。
> **反链**是两两不可比较的节点集。

第二条公理是树的灵魂：每个节点看到的「来路」不仅是线性的，而且是
良序的，所以它的序型是一个序数——高度因此有定义。树序常常写成
前缀序。三个标准例子（例 2.17）：

1. 任何秩序集 (W,<) 本身是一棵树：每个元素的前导集是它下面的
   序数初始段，根是最小元。
2. 给定非空集合 A 与序数 λ，令 A^{<λ}=⋃_{α<λ}A^α，规定
   f<g 当且仅当 dom(f)<dom(g) 且 f⊂g（f 是 g 的真前缀）。
   那么 (A^{<λ},<) 是树，ht=λ，第 α 层恰为 A^α，每一层都是极大
   反链；b 是等高枝当且仅当 ⋃b∈A^λ。这是一切序列树的母型。
3. 令 T={f∈ℕ^{<ω} | 对所有 i<j<dom(f) 都有 f(i)>f(j)}，即
   自然数严格下降有限序列之集。它作为 ω^{<ω} 的子树高度为 ω，
   **却没有等高树枝**：一根等高枝的并将是一条无穷严格下降的自然数
   序列，不可能。

例 3 是后面阿朗谢树的有限直觉原型：树可以很高、每层不空，却没有
任何一根枝走到底——差别只在例 3 的每层本身是有限的，而下面会看到
ω 上的这种树必定无限分叉；阿朗谢树正是把「每层不大、无等高枝」
搬到 ω₁ 上。

**Isabelle/ZF 通道**把例 2 完整地做成形式对象。文件
`examples/isabelle/ST79/Trees.thy` 用 ZF 的 Pi 类型表示「域为 n 的
函数」，定义与层如下（这里把文件中的 ASCII 控制形式还原成数学
记号阅读）：

```isabelle
definition Seq :: "i => i" where
  "Seq(A) ≡ ⋃n∈nat. n -> A"

definition PrefTree :: "[i,i] => o" where
  "PrefTree(T,A) ≡
     T ⊆ Seq(A) ∧ 0 ∈ T ∧
     (∀g∈T. ∀n∈nat. n ⊆ domain(g) ⟶ restrict(g,n) ∈ T)"

definition lvl :: "[i,i,i] => i" where
  "lvl(A,T,n) ≡ {f ∈ T . f ∈ n -> A}"
```

`n -> A` 是 ZF 库的 Pi 记号 `Pi(n,λ_.A)`，`0` 既是空集又是空序列。
`PrefTree` 直接把定义 2.31(7) 的「包含全部前导」落成「任意更短
限制 restrict(g,n) 仍在树中」。第一件机器核对的事实是：节点的层由
定义域唯一确定。

```isabelle
lemma fun_domain: "f ∈ n -> A ==> domain(f) = n"
```

证明用库里的 `Pi_iff`：f∈Pi(n,const A) 同时给出 n⊆domain(f) 与
f⊆Sigma(n,const A)，后者把 domain(f) 压回 n，两边包含即等。于是
不同层互不相交——若 f 同时在第 n、m 层，则 n=domain(f)=m：

```isabelle
lemma levels_disjoint:
  assumes nm: "n ∈ nat" "m ∈ nat" and ne: "n ≠ m"
  shows "lvl(A,T,n) ∩ lvl(A,T,m) = 0"
```

根在第 0 层由 `Pi_empty1`（Pi(0,A)={0}）核对。直接前导
restrict(g,n) 的存在性来自前缀闭包与 `restrict_type2`；唯一性
`predecessor_unique` 则是函数外延性的小练习：h 与 g↾n 都是域 n 的
函数、逐点值相同（h⊆g 加上函数性排除同一坐标挂两个值），由
`fun_extension` 判等。最后两个总结论把例 2 的两条断言钉死：

```isabelle
lemma Seq_pref_tree: "PrefTree(Seq(A),A)"
lemma full_level: "n ∈ nat ==> lvl(A,Seq(A),n) = n -> A"
```

注意这个通道的诚实边界：`Seq(A)` 只并了 n∈nat（即 A^{<ω}），
机器证明的是**有限序列树**的层结构；A^{<λ} 在任意序数 λ 上的
同一事实是逐字的超穷复制，但需要序数、传递闭包等更重的 ZF 基建，
正文的叙述对一切序数成立，机器只担保读者已经能亲手核验的有限段。

**Lean 通道**（`examples/lean/Settheory/Ch79Trees.lean`）换一个
角度：不表示具体树，而把本章所有无穷论证反复使用的「沿父链秩
递减」抽象成一个结构并证明它必然终止。

```lean
structure RankedTree (α : Type*) where
  rank : α → ℕ
  parent : α → Option α
  root : α
  parent_root : parent root = none
  rank_lt_parent : ∀ {x y : α}, parent x = some y → rank y < rank x

def RankedTree.ancestor (x : α) : ℕ → Option α
  | 0 => some x
  | n+1 => (T.ancestor x n).bind T.parent
```

`ancestor x n` 是沿父函数上溯 n 步的结果（some 节点或 none 断链）。
主定理说每上溯一步秩至少减 1：

```lean
theorem ancestor_rank (x : α) :
    ∀ {n z}, T.ancestor x n = some z → T.rank z + n ≤ T.rank x
  | 0, z, h => by
    obtain rfl : z = x := Option.some_inj.mp h
    omega
  | n+1, z, h => by
    obtain ⟨w, h₁, h₂⟩ := Option.bind_eq_some.mp h
    exact le_trans (by omega) (T.ancestor_rank x (n := n) h₁)
```

归纳步从 `bind=some z` 拆出中间节点 w：先上溯 n 步到 w，再由 w
走到 z；归纳假设给 rank w + n ≤ rank x，结构公理给 rank z < rank w，
两处相加用 `omega` 收口。立刻得到两条推论：上溯步数超过秩必断
（`ancestor_terminates`，反设到达某 z 就有 rank z + rank x + 1
≤ rank x，omega 判矛盾），以及节点不可能是自己的真祖先
（`no_self_ancestor`，会导致 rank x + n ≤ rank x 而 n>0）。文件
末尾用三节点链 0←1←2 做具体核对：

```lean
def chain3 : RankedTree (Fin 3) where
  rank := ![0, 1, 2]
  parent := ![none, some 0, some 1]
  ...
example : chain3.ancestor 2 2 = some 0 := by decide
example : chain3.ancestor 2 3 = none := by decide
```

这个「自然数秩 + 严格下降」的有限骨架，正是下一节柯尼希引理选择
函数证明里「每一步都合法、链不能在 ω 之前走完」的终止性内核——
只不过柯尼希的秩是节点之下**无穷**子树的高度，下降发生在序数上。

## 79.2 柯尼希引理与树特性

> **定理 2.41（柯尼希引理）** 高度为 ω 的有限分叉树必有等高树枝。
> 即树 (T,<) 高 ω，且每个节点的直接后继集有限，则 T 有长度 ω 的枝。

证明是选择函数的标准用法。对节点 x 记 S(x) 为其直接后继的有限集，
并记「y 的后继无穷」为 {z | y<z} 是无穷集。固定 ℘(T) 上的选择函数
c，从根 b₀ 开始归纳：若 b_n 的后继集无穷，由于

```
{y | b_n < y} = ⋃_{u∈S(b_n)} {y | u=y ∨ u<y},
```

右边是有限个集合之并，其中至少一个（事实上所有非空项）无穷；令
b_{n+1} 为 S(b_n) 中「后继无穷」的节点（有限集上不需要选择公理，
命题本身在 ZF 中可证）。于是 b_n<b_{n+1} 且每一步的候选集无穷。
B={b_n | n<ω} 的极大化就是等高枝。推论 2.6：二叉树 2^{<ω} 的任意
高 ω 子树必有长 ω 的枝。

柯尼希引理立刻诱发问题 2.7：把 ω 换成不可数正则基数 κ，假设树高
κ、每一层 T_α 的势都小于 κ，是否一定有等高枝？

> **定义 2.32（树特性）** 正则基数 κ 具有**树特性**，当且仅当任何
> 高 κ、每层势 <κ 的树都有等高树枝。

ω 具有树特性就是柯尼希引理。下一节的阿朗谢树说明 ω₁ 在 ZFC 中
**不**具有树特性；而树特性在不可达基数上重新出现，恰好是弱紧基数
的等价刻画之一（79.8）。

**Agda 通道**（`examples/agda/Ch79_trees.agda`）在有限 rose tree
上机器化「树高」的递归计算，这是定理 2.41 中「高度」概念的构造性
侧影：

```agda
data Tree (A : Set) : Set where
  leaf : A → Tree A
  node : A → List (Tree A) → Tree A

mutual
  height : ∀ {A} → Tree A → ℕ
  height (leaf _) = zero
  height (node _ ts) = suc (heightList ts)

  heightList : ∀ {A} → List (Tree A) → ℕ
  heightList [] = zero
  heightList (t ∷ ts) = height t ⊔ heightList ts
```

叶高 0，内节点高为子树最大高度加 1。这里必须用 `mutual` 写成
height 与 heightList 相互结构递归：最初的写法
`height (node _ ts) = suc (maxList (map height ts))` 被 Agda 终止
检查器拒绝——高阶参数 `map height` 不是可见的子项递归；改成在
子树表的头上直接递归，终止检查器才认得「heightList 作用在表尾、
height 作用在表头子树」这条结构下降链。两条算术事实
`max-zero (n⊔0=n)`、`max-idem (n⊔n=n)` 结构归纳自证后，满二叉树
的高度被精确算出：

```agda
fullTree zero = leaf tt
fullTree (suc n) = node tt (fullTree n ∷ fullTree n ∷ [])

height-full : ∀ n → height (fullTree n) ≡ n
height-full zero = refl
height-full (suc n) =
  cong suc (trans (dup-height (fullTree n)) (height-full n))
```

`dup-height` 说两个等高孩子合并后高度不变（heightList(t∷t∷[])=
height t），于是每深一层高度恰好加 1。单链树 `chain` 是另一极端，
高度同样等于深度。文件末尾还有一个混合样本 `sample`（叶加上一棵
深 2 满二叉树，机器算出高 3）。这些全部是**有限**树的结构归纳：
柯尼希的无穷枝需要选择函数逐次走「有无穷后继」的孩子，不能由这里
的递归推出——文件头注释明确写出了这条边界。

## 79.3 阿朗谢树：ω₁ 没有树特性

> **定义 2.33（阿朗谢树）** 树 (T,<) 是一棵阿朗谢树（怪树）当且仅当
> ht(T)=ω₁，每层 T_α 可数（α<ω₁），但 T 没有等高树枝。

> **定理 2.42** ω₁ 不具有树特性：存在一棵阿朗谢树。

构造在 ω^{<ω₁} 中递归选一棵子树，每层 T_α 满足四条要求：

- (a) T_α⊆ω^α 且可数；
- (b) 每个 f∈T_α 是单射，且 ω−rng(f) 无穷（**永远留无穷多个没用过
  的自然数**，这是构造能继续的燃料）；
- (c) 前缀封闭：f∈T_α、β<α 蕴含 f↾β∈T_β；
- (d) 稠密延展：对任意 β<α、g∈T_β、有限集 X⊂ω−rng(g)，存在
  f∈T_α 使 g⊂f 且 X∩rng(f)=∅（任意有限多个自然数可以被「躲开」）。

零层 T₀={∅}。后继层简单：T_{γ+1}={g∪{(γ,n)} | g∈T_γ，
n∈ω−rng(g)}。可数个 g、每个有可数多种 n，(a)–(d) 直接验证。

关键是**极限层** α。固定 β<α、g∈T_β、有限的 X。取单调递增收敛于
α 的序列 α_n（α₀=β），递归造 f_n∈T_{α_n}：先把有限集 X_n 扩大成
X_{n+1}（仍有限、仍避开 rng(f_n)），再用条件 (d) 在 T_{α_{n+1}}
中取 f_{n+1}⊃f_n 躲开 X_{n+1}。令 f(g,X)=⋃_n f_n。那么：
(i) f:α→ω 是单射；(ii) X⊂⋃X_n 整个被避开，所以 ω−rng(f) 无穷；
(iii) 每个真前缀落在对应层。令

```
T_α = { f(g,X) | g∈⋃_{β<α}T_β, X∈[ω−rng(g)]^{<ω} }。
```

可数乘可数仍可数，(a)(d) 成立，(b)(c) 由构造自带。令
T=⋃_{α<ω₁}T_α，序为前缀包含。若 B 是一根枝，则 ⋃B 是从某个
序数（B 的长度）到 ω 的**单射**。等高枝将给出 ω₁→ω 的单射，
不可能；所以每根枝的长度都 <ω₁，而树高 ω₁。证毕。

这个构造与 79.1 例 3 的对照值得点破：例 3 的下降序列树把「字母表」
用尽（严格下降的自然数序列长度有穷），阿朗谢树则在每一步都留无穷
储备，使每个可数极限都能继续——真正挡住等高枝的不是燃料耗尽，而是
「一根 ω₁ 长的枝会把可数字母表用成不可数单射」。

**Julia 通道**（`examples/julia/79_trees.jl`）的实验三就做这个
对照的有限版。字母表 {0,…,m} 上严格下降序列之集按子集（位掩码）
枚举，最大枝长恰为 m+1：

```julia
function decreasing_nodes(m)
    nodes = Vector{Int}[]
    for submask in 0:(1<<(m+1))-1
        push!(nodes, [x for x in m:-1:0 if (submask >> x) & 1 == 1])
    end
    return nodes
end
function max_branch(m)
    return maximum(length(n) for n in decreasing_nodes(m))
end
```

程序对 m=0,…,6 核对 `max_branch(m)==m+1`：树高 m+1 但无更长枝。
输出里这一行是有限直觉原型；它**不**是阿朗谢树的证据——阿朗谢树
的存在是上述 ω₁ 递归构造的定理，机器只帮读者确认「每层不大 + 无
长枝」这一现象在有限世界已经可以亲眼看见。

## 79.4 苏斯林树、规范树与钻石原理

> **定义 2.34（苏斯林树）** 树 (T,<) 是苏斯林树当且仅当 ht(T)=ω₁，
> T 既没有不可数反链，也没有等高树枝。

每棵苏斯林树都是阿朗谢树（不可数反链不存在蕴含每层可数：每层本身
就是一条反链），反之未必。苏斯林树的存在性在 ZFC 中**不可判定**：
它等价于苏斯林假设 SH 的否定；下面先看它在 ♦ 之下被造出来。

> **定义 2.35（规范树）** 高 α（α≤ω₁）的树是规范的，当且仅当：
> 每层可数；每个节点有可数无穷多个直接后继；高度较低的节点在每个
> 更高层都有后继（「不死」）；极限层由其前驱集合唯一确定
> （{z | z<x}={z | z<y} 蕴含 x=y）。

> **定理 2.43** 如果钻石原理 ♦ 成立，则存在一棵规范苏斯林树。

构造梗概（77 章的钻石序列在这里兑现）。设 (S_α)_{α<ω₁} 是钻石
序列。在可数序数上递归造树，节点直接取序数、树序 <_T 逐段扩张。
极限层 α 时：若 S_α 是当前截断树 T↾α 的极大反链，就为每个节点
t∈T↾α 选一根长度 α、经过 S_α 中与 t 可比较节点的枝 b_t，在 α 层
放可数个新节点，每个 t 沿对应枝延长；若 S_α 不是极大反链，则任取
可数根覆盖 T↾α 的长度 α 的枝同样延长。后继层则让每个节点长出可数
多个后继。规范性逐段保持。

为什么成品没有不可数反链？设 A⊆ω₁ 是一条极大反链，令

```
C = {α | A∩(T↾α) 是 T↾α 的极大反链},
D = {α | α = T↾α}（所有节点都已在 α 之前出现）。
```

C、D 都是 ω₁ 的无界闭集：C 的无界性由「每阶段把当前可数多个节点
与 A 中元素配对、ω 步取上确界」得到，D 的闭性来自高度映射的
单调性。♦ 给出 α∈C∩D 使 S_α=A∩(T↾α)。构造在这一层特意让
S_α 保持为后续一切截断的极大反链，于是 A=S_α 可数。为什么没有
等高枝？若 B 是长 ω₁ 的枝，对每个 α 取 t_α∈B∩T_α，再在
T_{α+1} 中取一个**不在** B 中的 t_α 后继 τ_α；不同层的 τ_α 两两
不可比较（否则较晚的那个必经过 t_β∈B，与选取矛盾），{τ_α} 就是
不可数反链。两件事合起来给出规范苏斯林树。

这是本书第一次正面展示「♦ 这种组合原理能决定 ZFC 决定不了的
命题」。它的独立性将由力迫完成（84 章以后的主线）：苏斯林假设
SH（无苏斯林树）与 MA_{ℵ₁} 相容，而 ♦ 在 L 中成立。

## 79.5 稠密子集与泛善子集：可数情形是定理

把「沿树走到底」抽象出来。

> **定义 2.36（稠密、泛善子集）** 偏序 (P,<) 上 D⊆P **稠密**当且仅当
> 对每个 p∈P 存在 q∈D 使 p≤q（q 是 p 的加强）。对稠密子集的集合
> 𝒟，F⊆P 是 **𝒟-泛善子集**当且仅当：
>
> 1. 定向：p₁,p₂∈F 蕴含存在 q∈F 使 p₁≤q 且 p₂≤q；
> 2. 下闭：p∈F、q≤p 蕴含 q∈F；
> 3. 与每个 D∈𝒟 相交（F∩D≠∅）。

例 2.18 给出与树的精确对应：在 (ω^{<ω},<) 上令
D_n={t | dom(t)>n}，每个 D_n 稠密；F 是 {D_n}-泛善子集当且仅当
F 是这棵树的一根等高枝（下闭给出全部前缀，定向给出单一枝，相遇
全部 D_n 给出长度 ω）。

> **定理 2.44** 任意偏序上，给定可数个稠密子集 𝒟={D_n | n<ω} 与
> 任意 p∈P，必有包含 p 的 𝒟-泛善子集。

证明就是贪心链：固定 P 的秩序，p₀=p，归纳取 p_{n+1} 为 D_n 中
满足 p_n≤q 的 <-最小元，最后令 F={q | 存在 n，q≤p_n}。相遇性由
构造直接给出，下闭是定义，定向由链性给出。

两个推论值得记住。推论 2.7 用它重证柯尼希引理：给定有限分叉树
T，先修剪出「有任意高后继」的子树 T′，D_n={t∈T′ | ht(t)>n}
稠密，泛善子集就是等高枝——79.2 的选择函数证明与这里的稠密集
证明是同一个构造的两种语言。推论 2.8 是**贝尔纲定理的可数版本**：
实数轴上可数个稠密开集的交仍稠密；证明以非空开区间内的闭区间（按
逆包含序）为偏序，每个稠密开集对应一个稠密集，泛善子集给出有限交
性质的闭区间族，紧致性保证交非空。

那 ω₁ 个稠密集呢？答案是否定的（例 2.19）：在树 (ω^{<ω₁},<) 上
对每个 α<ω₁ 令 D_α={f | α∈rng(f)}，它稠密（把 α 接到末尾
即可）；若 F 与每个 D_α 相遇，⋃F 就是定义在 ω₁ 上、值域覆盖 ω₁
的函数，与「序列长度可数、值域可数」矛盾。**可数是定理，不可数
要加假设**——这正是马丁公理的切入点。

**Prolog 通道**（`examples/prolog/79_trees.pl`）用搜索把定理 2.44
的有限形态做成三个可运行的关系。第一块枚举二叉前缀树的枝：

```prolog
bit(0). bit(1).
branch_of(K, B) :- length(B, K), maplist(bit, B).
n_branches(K, N) :- findall(B, branch_of(K, B), Bs), length(Bs, N).
zero_branch(0, []) :- !.
zero_branch(K, [0|Rest]) :- K > 0, K2 is K - 1, zero_branch(K2, Rest).
```

`n_branches` 对 K=1..8 核对枝数恰为 2^K；逐次补 0 的 `zero_branch`
是「与 D_n={长度≥n} 全部相遇」的构造性见证，它的全部前缀两两
可比较（`comparable` 用两个子句分别试「P 是 Q 的前缀」和反向，
前缀长度必须先 `length` 求值再代入——这是实现时踩到的 Prolog
求值序坑：把 `length(P)` 直接当参数传进去永不会被实例化）。

第二块是有限子集偏序上的泛善滤子：底集 {1,…,B}，链
∅⊂{1}⊂…⊂{1,…,B} 在第 a 步与 D_a={S | a∈S} 相遇，取其下闭，
机器核对定向性、下闭性与六个稠密集全部相遇：

```prolog
generic_filter(B) :-
    chain(B, Chain),
    all_subsets(B, F),
    numlist(1, B, Top),
    forall(between(1, B, A), meets(Chain, A)),
    directed(F, Top),
    downclosed(F, F).
```

第三块是例 2.17(3) 的关系化：`desc_node(M,L)` 用子集反演生成
{0,…,M} 上的严格下降序列，`max_desc_len` 核对最大长度恰 M+1。
运行 `swipl -f 79_trees.pl -g main -t halt` 输出三行中文结论与
`END ====` 标记。边界同样要说清楚：有限幂集偏序的顶元素让下闭
自动成为全幂集，这与 ω^{<ω₁} 上 ω₁ 个稠密集**不可**全部相遇毫无
矛盾——例 2.19 的障碍本质上是「可数序列的值域不能覆盖 ω₁」，
任何有限模型都不触及它。

## 79.6 可数反链条件、同根引理与马丁公理

> **定义 2.37（相容、ccc）** 偏序中 p,q **相容**当且仅当存在 r 同时
> 加强两者；反链是两两不相容的子集。偏序满足**可数反链条件**
> （ccc）当且仅当它的每条反链都可数。

典型例子（例 2.20）：有限部分函数 p:κ⇀2（定义域为 κ 的有限
子集）按包含序构成的偏序 Fn(κ,2) 满足 ccc。证明依赖下面的组合
引理。

> **定理 2.45（同根引理 / Δ-系统引理）** 任意不可数个有限集合之族
> {A_α | α<ω₁}，都存在无界 S⊆ω₁ 与有限集 R（「根」），使
> α≠β∈S 时 A_α∩A_β=R。

证明思路：先把所有 A_α 缩成统一大小 n（不可数个集中必有某个固定
大小出现不可数次）；令 h(α)=max A_α，集合
C={γ | ∀α<γ, h(α)<γ} 是无界闭集。在 C 上按「第 i 个元素」展开：
第 1 个元素在 C 的某个荟萃子集上取常值（佛多压引理），在其中再让
第 2 个元素取常值，n 次后得到荟萃集 T，各 A_α 在 T 上共享同一个
固定部分 Q；不同部分因为最大值 h(α) 随 α 严格上升而互不相交，
Q 正是公共的根。把同根引理用到 {dom(f_α)} 上：不可数反链要么有
不可数个条件共享定义域（有限定义域上只有有限个 0/1 赋值，必有两个
相同，矛盾），要么定义域们以有限集 X 为根两两只在 X 上相交——
2^X 有限，又有不可数个条件在 X 上取值相同，它们相容，再矛盾。
Fn(κ,2) 的 ccc 由此得证。

> **定义 2.38（马丁公理）** 对 ω≤κ，**MA_κ** 是命题：任何满足 ccc
> 的偏序与任意不超过 κ 个稠密子集，都存在泛善子集。MA 即
> 「对一切 κ<2^{ℵ₀}，MA_κ 成立」。

MA_ω 就是定理 2.44，是 ZFC 定理；有趣的事情从 MA_{ω₁} 开始。

> **定理 2.46** MA_{ω₁} 蕴含没有苏斯林树。

证明极其漂亮。苏斯林树本身按树序是一个 ccc 偏序（反链都可数是
定义）。每层 T_α 是极大反链，故
D_α={t | 存在 s∈T_α，s<t} 稠密开。MA_{ω₁} 给出与所有
D_α（α<ω₁）相遇的滤子 G；G 在每层恰有一个元素（同层不可比较，
滤子定向排除两个），⋃G 就是等高枝——与苏斯林树定义矛盾。

MA 还决定连续统以下的基数算术。

> **定理 2.47/2.48** MA 成立时，对任意不可数 κ<2^{ℵ₀}，
> 2^κ=2^{ℵ₀}。推论 2.9：2^{ℵ₀} 是正则基数。

证明的机制（**几乎不相交偏序力迫**）是后面力迫章节的预演，值得
完整走一遍。ℕ 的无穷子集族 𝒜 称为**几乎不相交**的，若任意两个的
交有限；**极大**几乎不相交族不能再加入新的无穷集。可数无穷的几乎
不相交族绝不极大（引理 2.23：递归在每个 A_n 中取一个避开前 n 个
集合的新点，得到与每个 A_n 交有限的无穷集）。

给定无穷几乎不相交族 𝒜，偏序
P_𝒜={(s,F) | s∈[ω]^{<ω}，F∈[𝒜]^{<ω}}，规定
(s₁,F₁)≤(s₀,F₀) 当且仅当 s₀⊆s₁、F₀⊆F₁，且每个 A∈F₀ 都有
A∩s₁⊆s₀（新加入的点都躲开旧集合）。这个偏序满足 ccc
（引理 2.25：相同有限部分 s 的两个条件自动相容，而 s 只有可数种）。
两类稠密集（定义 2.41）：

```
D_A   = {(s,F) | A∈F}          （A∈𝒜，把 A 提进有限集 F）
E_{A,n} = {(s,F) | s⊄n}        （s 中有点大于 n，保证导出集无穷）
```

泛善滤子 G 的**导出集** g=⋃{s | ∃F, (s,F)∈G} 满足：对 F 中提过
的 A，g∩A 有限（新增点永远躲开旧 A）；而与全部 E_{A,n} 相遇保证
g 无穷（引理 2.26）。MA_κ 让我们同时与 |𝒜|+ω 个稠密集相遇：
取 𝒜=B 得到与 B 中每个集合几乎不相交的无穷 g，说明 B 不极大；
取 B 的任意无穷真子族 𝒜 并对 B−𝒜 中的集合反向使用稠密性，得到
g 恰好与 𝒜 中集合有限相交、与 B−𝒜 中集合无穷相交——g 给 𝒜
编了码。于是 𝒫(B) 除去平凡情形可以单射入 [ω]^ω，
2^κ≤2^{ℵ₀}；反向不等式显然。推论 2.9 再用柯尼希不等式
cf(2^{ℵ₀})>ω：若 cf(2^{ℵ₀})<2^{ℵ₀}，定理给出
cf(2^{ℵ₀})=cf(2^{cf(...)})，矛盾。

## 79.7 划分命题：无穷 Ramsey 与有限 Ramsey

> **定义 2.42（划分箭头）** 设 r,s,κ,λ 为基数。**κ→(λ)^r_s**
> 表示：任何势 κ 的集合 X 与任何 f:[X]^r→s，都存在势 λ 的
> **齐一子集** H⊆X，使 f 在 [H]^r 上取常值。

> **定理 2.49（无穷 Ramsey 定理）** 对任意有限 r,m≥1，
> ω→(ω)^r_m。

r=2、m=2 的证明是「嵌套无穷选择」：从 a₀=0 出发，a₀ 到其余各点
的边只有 m 种颜色，无穷多个邻点中必有某色 i₀ 出现无穷次，记这个
无穷集为 H₀；取 a₁=min H₀，在 H₀ 中再分出无穷的同色尾集 H₁；
如此得到 a_n∈H_{n-1}、嵌套无穷集 H_n 与颜色 i_n，使 a_n 到每个
更晚的 a_k 的边都是 i_n 色。颜色序列 i_n 取某个值无穷多次，对应
的 a_n 之集就是无穷齐一集。一般的 r 用对 r 的归纳（每点诱导一个
r−1 元染色，反复取无穷齐一尾集），颜色数 m 的推广用嵌套归并。

> **定理 2.51（有限 Ramsey 定理）** 对任意正整数 n,m,k，存在 l 使
> l→(k)^n_m；而且该命题是佩亚诺算术（PA）可证的。

证明给出两层信息。存在性：对二元二色用递归
R(p,q)≤R(p−1,q)+R(p,q−1)（边界 R(2,q)=q），任取一点 v，与其
相连的边按颜色把其余 R(p−1,q)+R(p,q−1)−1 个点分成两类，鸽子笼
保证一类达到对应阈值，补上 v 得齐一集；一般 n、m 用归纳归并。
这个递归只用到自然数加法，所以整个论证可在 PA 中形式化。书里还
给了第二个、用柯尼希引理的紧致性证明：若任意大都有反例，则反例按
前缀构成一棵有限分叉的无穷树，等高枝给出 ω 上一个处处无大小 k
齐一集的染色，与定理 2.49 矛盾。**无穷 Ramsey 通过柯尼希引理
压出有限 Ramsey**——两条定理在这里闭环。

> **定理 2.52（巴黎-哈灵顿原理）** 对任意 n,k,m，存在 l，使得任意
> f:[l]^n→k 都有齐一子集 Y 满足 |Y|≥max{m, min Y}（齐一集要
> 「相对自己的最小元足够大」）。
>
> 巴黎-哈灵顿原理在 PA 中**不可证**（独立于 PA，假设 PA 相容）。

证明本身仍用柯尼希引理（故在更强系统中成立），但这个看似只是
有限 Ramsey「加强版」的语句编码了 PA 的相容性——这是数学上第一个
自然的、有穷组合外观的 PA 独立性命题。定理 2.51 与 2.52 只隔一个
大小条件，可证性却有天壤之别。

**三个计算通道**在小值上把有限 Ramsey 彻底算清，且互相对账。

**Coq 通道**（`examples/coq/Ch79_trees.v`）做的是**可判定的完整
穷举证明**，不依赖 Ssreflect，全部手写布尔枚举。K_n 有
n(n−1)/2 条边，`edgesn` 列边、`trisn` 列三角形、`colorings m`
递归列出全部 2^m 种染色；边索引 `eidx n i j = i(2n−1−i)/2+(j−i−1)`
把 (i,j) 压缩到字典序位。两个主结论：

```coq
Theorem R33_le_6 : forallb (fun c => has_mono 6 c) (colorings 15) = true.
Proof. vm_compute. reflexivity. Qed.

Theorem R33_gt_5 : has_mono 5 k5_witness = false.
```

R(3,3)≤6 是对 K₆ 全部 2^15=32768 种二染色逐一检查、全部含单色
三角形；R(3,3)>5 用显式见证 k5_witness：红边是五循环
0-1-2-3-4-0，蓝边（补集）是另一个五循环 0-2-4-1-3-0，两者都
不含三角形。文件还机器计数 K₅ 的 2^10=1024 种染色中恰有 12 种
不含单色三角形（它们正是标号五循环及其补），1012 种含有：

```coq
Example k5_mono_count :
  length (filter (fun c => negb (has_mono 5 c)) (colorings 10)) = 12.
```

**Julia 通道**用完全独立的位掩码实现重演同一普查（实验一）：
每条边取枚举整数的一个二进制位，`scan(n)` 穷举所有染色并报告
无单色三角形者的个数，断言 K₅ 得 (1024, 12)、K₆ 得 (32768, 0)；
显式五循环集合 `red5` 单独构造见证。实验二实现定理 2.51 证明里的
上界递归：

```julia
function ramsey_upper(s, t)
    s == 2 && return t
    t == 2 && return s
    return get!(memo, (s, t)) do
        ramsey_upper(s-1, t) + ramsey_upper(s, t-1)
    end
end
```

机器值 R(3,3)≤6、R(3,4)≤10、R(3,5)≤15、R(4,4)≤20。注释里
诚实标注：10/15/20 是**原始 Pascal 递归**给出的界，利用偶数和
情形的标准改进可把 R(3,4)  sharpen 到 9（事实上 R(3,4)=9）、
R(4,4) sharpen 到 18——写作时最初把精确值直接断言给了递归函数，
运行立刻抓出这个错误：递归本身只产出 10 和 20，证明改进需要额外
论证，不能冒名顶替。

**Python 通道**（`examples/python/79_trees.py`）第三遍独立枚举，
用 itertools.product 生成染色元组，得到完全相同的 (1024,12) 与
(32768,0)，并用 `@lru_cache` 复算上界递归（6/10/15/20）。三种
语言、三种数据结构（Coq 表、Julia 位掩码、Python 笛卡尔积）在
同一组数字上会合，杜绝单通道 off-by-one。

这些机器证据的逻辑分量要讲准确：K₆ 的 32768 种染色全含单色
三角形，这就是有限命题 6→(3)²₂ 的**完整证明**（有限论域上的
布尔求值是严格数学论证，不是「实验」）；K₅ 见证给出 5↛(3)²₂。
两者合起来是精确等式 **R(3,3)=6**。但它们对 ω→(ω)²_m
（定理 2.49）一言不发：无穷多个染色不能被有限枚举覆盖，后者靠的
是嵌套无穷选择。

**Python 通道的第三幕**与 Prolog 呼应：在有限幂集偏序上手工造泛善
滤子——取初始段链 ∅⊂{0}⊂…⊂{0,…,K−1}，令 F 为链上所有集合的
子集之集，断言 F 等于整个幂集、定向、下闭，并与每个
D_a={S | a∈S} 相遇；同文件还数出深 8 满二叉树 2^9−1=511 个节点、
补零枝穿过全部层。有限世界里「与所有稠密集相遇」平凡成立，再次
提醒 79.5 的可数/不可数分界。

## 79.8 不可数划分：谢尔品斯基染色与弱紧基数

无穷 Ramsey 在 ω 上完美，ω₁ 呢？

> **例 2.22/2.23（谢尔品斯基染色）** 2^λ↛(λ⁺)²₂。

取 A=2^λ（长度 λ 的 0/1 序列集），在 A 上放两个序：字典序 <_lex
（第一个不同位上较小）与一个秩序 ≺。按两序是否一致给无序对染色。
若存在势 λ⁺ 的齐一子集，它在其中一个序下给出长度 λ⁺ 的严格单调
序列。引理 2.27 证明这不可能：若 (f_α)_{α<λ⁺} 字典序严格单增，
考察最小分歧位 ε_α，必有不可数多个 α 的 (f_α↾ε_α, ε_α) 相同，
而相同前缀、同一位由 0 翻 1 的两个序列会迫使后来者落到先行者
下方，矛盾。取 λ=ω 得 2^{ℵ₀}↛(ω₁)²₂；特别地，连续统上的二染色
可以没有不可数齐一集。拉姆齐性质不能平凡推广到不可数。

但并非全无是处。

> **定理 2.53（埃德斯-拉铎）** (2^{ℵ₀})⁺→(ω₁)²_{ℵ₀}：连续统的
> 后继基数上，任意用可数种颜色染二元集，都有势 ω₁ 的齐一集。

证明是「同色型闭包」。设 κ=(2^{ℵ₀})⁺，F:[κ]²→ω。对 β 记
F_β(α)=F({α,β})（β 之前的颜色型）。递归造长度 ω₁ 的递增链
A₀⊂A₁⊂…（每个势 2^{ℵ₀}）：给定 A_α，对每个可数 C⊂A_α，把
κ−C 中按 F_β↾C 的型分类（至多 2^{ℵ₀} 种型），每型选一个代表，
令 A_{α+1} 包含全部代表。取 A=⋃A_α。则对任意可数 C⊂A 与
α∉C，都能在 A 中找到与 α 同型的 β。现在从 κ−A 取起点递归：
第 α 步在 A 中选 α_α 使其对已选集合 C={α_ξ | ξ<α} 的颜色型与
起点完全相同。于是 {α_α} 中任意两点的颜色都等于起点对该点的
颜色；这是一个 ω₁ 序列到 ω 的函数，取其不可数纤维即得齐一集。

> **定义 2.43（极化箭头）** κ→(κ,ω+1)² 表示：任意 f:[κ]²→2，
> 或者有色 0 的势 κ 齐一集，或者有色 1 的序型 ω+1 齐一子集。

> **定理 2.54（埃德斯-杜希尼克-米勒）** κ≥ω₁ 正则时
> κ→(κ,ω+1)²。

κ=ω₁ 的证明：若对每个极限 α 都存在序型 ω 的 X⊂α 使 X∪{α}
色 1 齐一，结论成立；否则用选择函数对每个 α 选一个最小有限集
g(α) 与 α 构成色 0 齐一集、且不能再向前扩张，h(α)=max g(α)
在荟萃集上取常值，再用 [γ+1]^{<ω} 可数、佛多引理逐次压缩，得到
荟萃集 U，使任意 α<β∈U 之间色 0——U 即势 ω₁ 的 0 齐一集。

最后是高阶无穷的门槛。

> **定义 2.44（弱紧基数）** 不可数基数 κ 是**弱紧基数**当且仅当
> κ→(κ)²₂。

> **定理 2.55** 对 κ>ω，下列命题等价：
>
> 1. κ 是弱紧基数（κ→(κ)²₂）；
> 2. κ 是不可达基数且具有树特性；
> 3. 对一切 1<n<ω、r≥2，κ→(κ)^r_n。

(1)→(2) 的三步是全章的汇合点：(a) κ 必正则——若 κ 是小于 κ 个
每个 <κ 的集合之并，按「两点是否在同一块」染色得无 κ 齐一集的
划分；(b) 对任意 ω≤λ<κ 有 2^λ<κ——否则谢尔品斯基染色（例
2.23）给出 2^λ↛(λ⁺)²₂，而 λ⁺≤κ≤2^λ，与弱紧矛盾；正则加强极限
即不可达。(c) 树特性：高 κ、每层 <κ 的树有 κ 个节点，把树序
线性化（不可比较时按第一个分叉层的左右定向），再按「树序与
线性序是否一致」给二元组染色；κ→(κ)²₂ 给出势 κ 的齐一集 H，
在每层取 H 中可达的节点，齐一性保证这些节点两两可比较，它们
构成等高枝。(2)→(3) 则把 n 色染色编码成一棵「颜色型前缀树」：
节点是序数初始段上的染色型，不可达性保证每层 <κ，树特性给出的
等高枝在每个节点处分出 n 种后继颜色，必有一色占据 κ 多个节点。

弱紧基数是本书遇到的第一种**小大基数**：它的存在性不是 ZFC 定理
（若 ZFC 相容，ZFC 证不出「存在弱紧基数」的相容性），但它只用
一个划分命题就等价地收拢了不可达性、树特性与全谱划分齐一性。
第三卷的高阶无穷之旅，正从这道门槛开始——93 章将给出各种大基数
公理按相容性强度排成的谱系，而弱紧基数是谱系上第一个用组合
语言完整刻画的站点。

## 79.9 七通道对账与诚实边界

本章七个通道的分工汇总：

| 通道 | 文件 | 机器承担的内容 |
| --- | --- | --- |
| Lean 4 | `examples/lean/Settheory/Ch79Trees.lean` | 父函数秩树结构；上溯 n 步秩至少降 n；超限断链；无自身真祖先；链实例 |
| Isabelle/ZF | `examples/isabelle/ST79/Trees.thy` | Seq(A) 前缀树、层定义；层互斥、根在 0 层、直接前导存在唯一、第 n 层恰 A^n |
| Coq | `examples/coq/Ch79_trees.v` | 32768 种 K₆ 染色全含单色三角形；五循环见证；K₅ 无单色三角形恰 12 种 |
| Agda | `examples/agda/Ch79_trees.agda` | rose tree 互递归高度；满二叉树高=深度；单链高=深度；混合样本 |
| Julia | `examples/julia/79_trees.jl` | K₅/K₆ 独立穷举；Ramsey 上界递归 6/10/15/20；下降树与有限泛善滤子 |
| Python | `examples/python/79_trees.py` | 第三遍染色普查对账；上界递归；满二叉树计数；幂集偏序泛善滤子 |
| Prolog | `examples/prolog/79_trees.pl` | 2^K 根枝关系搜索；有限泛善滤子三性质；下降序列最大长度 |

三类命题的证据来源必须分开记账：

1. **有限命题由机器完整证明**。6→(3)²₂ 的 forallb 反射在有限论域
   上就是证明；Isabelle 的层互斥、Lean 的终止定理、Agda 的高度
   定理都是一般的（虽只针对 ℕ 秩/有限序列模型）可靠命题。
2. **可数无穷命题由正文的无穷论证承担，机器只演其有限内核**。
   柯尼希引理的选择函数证明、定理 2.44 的贪心链、无穷 Ramsey 的
   嵌套无穷集——程序里的 `for n=1:8`、K=6 泛善滤子只是让读者
   亲手摸到构造的每一步；它们在任何意义上都不「近似证明」 ω 版本。
3. **不可数与大基数命题纯由正文承担**。阿朗谢树的存在（定理
   2.42）、♦→苏斯林树（2.43）、MA_{ω₁} 杀死苏斯林树（2.46）、
   谢尔品斯基染色、弱紧基数的等价（定理 2.55）都涉及 ω₁ 或
   不可达基数，有限计算不构成证据，通道设计里也没有任何文件
   声称验证了它们。

实现层面积累的具体教训（供后续章节复用）：Isabelle/ZF 的 term
语法必须写 ASCII 控制形式（`\<in>`、`\<Union>`、`->`、`%x.`、
`\<equiv>`，字面 ⇒/≡/λ 触发 inner lexical error），ZF 库里没有
`Pi_member2`，取函数图像序对要用 `apply_Pair`、两函数同坐标
判重用 `apply_equality2`，`UN_I` 用 `[OF nn]` 只填见证所属集合、
结论合一自动钉死其余参数（喂第二个事实会产生多个合一子）；Agda
高阶 `map` 递归不被终止检查器接受，改 mutual 结构递归，多态引理
的隐式类型参数要显式标注 `∀ {A} (t : Tree A)`；Julia 顶层 for 里
的软全局变量作用域会把同名变量判成 UndefVarError，实验包进函数；
Prolog 的 `length(P)` 作为未求值项传入永不定向，必须先在子句体
里求值，`forall` 里出现的小写「变量」是原子，汇合目标要用大写
X。
