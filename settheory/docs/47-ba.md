## 47.1 等式刻画：十条公理

**定义（Viale Def 3.1.1）** 布尔代数是六元组 (B, ∧, ∨, ¬, 0, 1)，
满足十条等式公理——对任意 a, b, c ∈ B：

| 律 | ∧ 版 | ∨ 版 |
|---|---|---|
| 结合律 | a∧(b∧c) = (a∧b)∧c | a∨(b∨c) = (a∨b)∨c |
| 分配律 | a∧(b∨c) = (a∧b)∨(a∧c) | a∨(b∧c) = (a∨b)∧(a∨c) |
| 交换律 | a∧b = b∧a | a∨b = b∨a |
| 单位律 | a∧0 = a？**否**：a∧**1** = a | a∨**0** = a |
| 补律 | a∧¬a = 0 | a∨¬a = 1 |

注意公理表里"单位律"的微妙：**∧ 的单位是 1**（顶），∨ 的单位是
0（底）——与算术直觉相反，与集合论一致（A∩X = A，A∪∅ = A）。
有界分配格是去掉补律的 (B, ∧, ∨, 0, 1) 部分。

**三个直接例子**：
1. 幂集 𝒫(X)：∧=∩、∨=∪、¬=补、0=∅、1=X——**完备**布尔代数
   （一切子集的 sup/inf 都存在）。
2. 拓扑 (X,τ)：τ 与闭集族 cτ 都是有界分配格（一般不完备、不布尔）。
3. **CLOP(X,τ)**：clopen 集族是 𝒫(X) 的布尔**子代数**（一般不完备——
   49 章会看到 RO(X) 是它的"完备化"）。

**派生运算**：a \ b := a∧¬b；对称差 aΔb := (a\b)∨(b\a)。在 𝒫(X)
中它们就是集论差与对称差——Δ 在 48 章布尔环里升格为"加法"。

## 47.2 序：从运算长出的偏序

幂集里 A ⊆ B ⟺ A∩B = A ⟺ A∪B = B。把这个观察抽象化：

**命题（Viale Prop 3.2.1）** 在布尔代数 B 上定义
a ≤ b :⟺ a∧b = a。则：
(i) ≤ 是偏序；
(ii) a∧b 是 {a,b} 的下确界；
(iii) a∨b 是 {a,b} 的上确界；
(iv) a ≤ b ⟺ a∨b = b。

*证明*。(i) 自反：a = a∧1 = a∧(a∨¬a) = (a∧a)∨(a∧¬a) = (a∧a)∨0
= a∧a，故 a∧a = a。传递：a∧b = a 且 b∧c = b 给
a∧c = (a∧b)∧c = a∧(b∧c) = a∧b = a。反对称显然。
(ii) (a∧b)∧a = a∧(b∧a) = a∧(a∧b) = a∧b，同理 ⊆ b；任一下界 c
满足 c∧a = c、c∧b = c，故 c∧(a∧b) = (c∧a)∧b = c∧b = c。
(iii) 先证 b ≤ a∨b：b = b∨0 = b∨(a∧¬a) = (b∨a)∧(b∨¬a) ≤ a∨b
（用了 (3.1) 式 c∨d ≤ c∨d∨e 型的单调性——由 (ii) 的 ∨ 对偶）。
再证它是最小上界：(3.2) 若 c ≤ e 且 d ≤ e 则 c∨d ≤ e（对 (ii)
取对偶）。(iv) 由 (iii)：a∨b = b 说 b 是 {a,b} 的上确界。∎

从此 **B = (B, ≤) 是分配格**，∧/∨ 恰是 inf/sup——48 章将证明反
过来"有余分配格 = 布尔代数"（Viale Lemma 3.10.3）。

## 47.3 五组恒等式

**命题（Viale Prop 3.3.1）** 任何布尔代数中：
(i) 幂等律 a = a∧a = a∨a；
(ii) **补唯一**：若 b∧a = 0 且 b∨a = 1，则 b = ¬a；
(iii) 双重补 ¬¬a = a；
(iv) ¬(a∨b) = ¬a∧¬b；¬(a∧b) = ¬a∨¬b。

*证明*。(i) 是 47.2(i) 的直接推论。
(ii) 核心：b = b∧1 = b∧(a∨¬a) = (b∧a)∨(b∧¬a) = 0∨(b∧¬a) = b∧¬a，
故 b ≤ ¬a；对偶地 b = b∨0 = b∨(a∧¬a) = (b∨a)∧(b∨¬a) = 1∧(b∨¬a)
= b∨¬a，故 ¬a ≤ b。合并。
(iii) 由 (ii)：¬¬a 与 a 都满足"与 ¬a 配对"的两方程。
(iv) 用 (ii) 一次验证 (¬a∧¬b)∨(a∨b) = 1 且 (¬a∧¬b)∧(a∨b) = 0
——各项分配展开即可。∎

这五组律的机器验证见 47.8（Coq 抽象证明 + Agda/Julia 穷举）。
补唯一律 (ii) 是"否定是唯一的"的代数化身——直觉主义里它失效
（见 00 章与 18 章的讨论），所以整套布尔值语义天然是**经典**逻辑
的推广。

## 47.4 理想与同态：核的抽象

**定义（Viale Def 3.4.5）** I ⊆ B 是**理想**，若对 a,b∈I 有 a∨b∈I
（对有限 ∨ 封闭），且 b∈I、a ≤ b 蕴含 a∈I（下封闭）。对偶地，
**滤子** F：对有限 ∧ 封闭、上封闭。理想是"假/小"的化身——它
正是布尔同态的核：

**事实（Viale Prop 3.9.8 节选）** π : B → C 的核 ker π = {b : π(b)=0}
是理想；反过来每个理想 I 给出商代数 B/I 与自然投射 π_I : B → B/I，
且 B/ker π 嵌入 C——**群论的第一同构定理在布尔代数里原样重演**
（48 章布尔环视角下这是"环论的定理免费搬运"，见 Viale Remark 3.9.6）。

**记号（Viale Notation 3.4.7）** B⁺ := B∖{0}。今后常把 B 当作偏序
(B⁺, ≤) 使用——这与 16 章 Jech 路线的"偏序世界"完全接轨：
**力迫偏序 = 布尔代数挖掉 0**。X ⊆ B⁺ 稠密 ⟺ ∀b∈B⁺∃a∈X (a ≤ b)
——同 46 章预序字典。

## 47.5 原子与有限布尔代数

**定义** B 的**原子**是 (B⁺, ≤) 的极小元；B **原子化**：原子在 B⁺
中稠密；B **无原子**：无原子。

**注（Viale Remark 3.5.2）** a 是原子 ⟺ 无 0 < b < a ⟺ 对一切 b，
a∧b = a 或 a∧b = 0。𝒫(X) 总是原子化的（原子 = 单点集）。**每个
有限布尔代数都原子化**：若 b₀ 不被任何原子精化，归纳构造无穷严格
降链 b₀ > b₁ > …（每步取不可再分者），与有限性矛盾——Viale 还给
出了用 Zorn 引理的"正式化"论证（把递归链的初始段当偏序族取极大元）。

**定理（Viale Prop 3.5.3）** 有限布尔代数 B 同构于 𝒫(At(B))
（原子集的幂集），映射 F(b) = {a ∈ At(B) : a ≤ b}。

*证明*。F 保运算：F(b∧c) = F(b)∩F(c)（原子 a ≤ b∧c ⟺ a≤b 且
a≤c）；F(¬b) = At(B)∖F(b)（原子与 b 的关系非此即彼，由三刻画）；
F(1) = At(B)。单射：b ≠ c 时不妨 b∧¬c > 0，原子化给原子
a ≤ b∧¬c，a ∈ F(b)∖F(c)。满射：给定原子集 S ⊆ At(B)，令
b_S := ⋁S（有限并存在），则每个原子 a：a ≤ b_S ⟺ a ∈ S
（a ∉ S 时 a 与 S 中一切原子不相容，a∧⋁S = ⋁_{s∈S}(a∧s) = 0）。∎

**例（Div(30) 实验室）** D = {1,2,3,5,6,10,15,30}（30 的因子），
配 n∧m := gcd(n,m)、n∨m := lcm(n,m)、¬n := 30/n、0 := 1、1 := 30。
这是一个 8 元布尔代数！原子恰为素因子 {2,3,5}，映射
F(n) = {p : p 素且 p | n} 实现 D ≅ 𝒫({2,3,5})。
反例：Div(18)（18 = 2·3²）**不是**布尔代数——但要崩对地方：
因子格 Div(n) 恒为**分配格**（n 的素因子幂次链之积，链分配、
积保分配），崩的是**补律**：3 的补元要求 gcd(3,x) = 1 且
lcm(3,x) = 18，六个因子逐一试尽无解（Julia 通道先全扫分配律
确认 216 组合全过，再抓补律崩坏现场——"分配恒真、补在平方
因子处崩"）。一般规律：Div(n) 是布尔代数 ⟺ n 无平方因子。
Julia/Prolog 通道把这两件事都做成可运行实验（47.8）。

## 47.6 六个例源（Viale §3.6）

Viale 用六族例子喂饱"布尔代数无处不在"的直觉：

1. **n 变量 Lindenbaum 代数 Bₙ**：命题公式按逻辑等价分类，[φ]∧[ψ]
   := [φ∧ψ] 等。**|Bₙ| = 2^(2^n)**、原子数 2^n——原子恰是"恰在一
   行取 1 的真值表"，即极大合取项 minterm。n=3 时 256 元；这与
   Div(30) 不同构（8 ≠ 256），但同构判定本身是个好习题。
2. **可数变量 Lindenbaum 代数 B_ω**：仍然每个公式只用有限个变量，
   但整体**无原子**——任何可满足公式 φ 都能被 φ∧A_{m+1} 严格
   精化（新变量切半真值表）。它是 Bₙ 的上升并。
3. **一阶理论 T 的 Lindenbaum 代数 B_T**：[φ]_T := {ψ : T ⊨ φ↔ψ}。
   T 完备 ⟺ B_T 是 2 元代数。T₁ ⊇ T₀ 给出理想 I_T 与商
   B_{T₁} ≅ B_{T₀}/I_T（习题 3.6.5）——**理论扩张 = 商代数**。
4. **可定义集代数**：结构 M 的 n 维可定义集族 ⊆ 𝒫(Mⁿ) 是布尔
   子代数（对参数封闭）。
5. **特征函数环 B_X**：连续 f : X → ℤ₂ 逐点运算——拓扑版本，
   48 章布尔环的主角。
6. **M([0,1]) 与 MALG**：Lebesgue 可测集是原子化但不完备的布尔
   代数（非可测集是原子族 {{r} : r ∈ V} 无 sup 的反例）；
   **MALG = M([0,1])/Null 是无原子且完备的**——49 章三定理的
   主角在此预告。

## 47.7 素理想定理：Zorn 的两步舞

**定义（Viale Def 3.7.1）** G ⊆ B 是：
- **预滤（prefilter）**：任何有限子族的 ∧ > 0；
- **超（ultra）**：∀b，b ∈ G 或 ¬b ∈ G；
- **滤子**：含有限 ∧ 且上闭；
- **超滤子**：超的滤子；**主滤子** G_a := {b : a ≤ b}（a 原子时超）；
- **素理想** I：p,q ∉ I ⟹ p∧q ∉ I；等价地 I = ¬[G] 对某超滤子 G
  （习题 3.7.2 的对偶字典：极大理想 = 素理想 = 超滤子的补）。

**定理（Viale Thm 3.7.4，素理想定理 PIT）** 任何预滤 F 可扩成
超滤子 G ⊇ F。

*证明*。令 𝒜 = {预滤 H : F ⊆ H}。
**第一步（链并）**：𝒜 中链 {Hᵢ} 之并 H 仍是预滤——有限个元素
b₁,…,bₖ ∈ H 各来自某个 H_{jᵢ}，链中取最大者 H_{j*} 包含全部，
预滤性给 b₁∧…∧bₖ > 0。Zorn：𝒜 有极大元 G。
**第二步（极大预滤是超的）**：设 b ∉ G。若 G∪{b} 与 G∪{¬b} 都
不是预滤，则有 a₁,…,aₙ, c₁,…,c_m ∈ G 使
a := a₁∧…∧aₙ∧b = 0 且 c := c₁∧…∧c_m∧¬b = 0。那么
0 < a₁∧…∧aₙ∧c₁∧…∧c_m（G 是预滤）≤ b∨¬b 的分配展开：
a₁∧…∧c_m∧(b∨¬b) = (a₁∧…∧c_m∧b) ∨ (a₁∧…∧c_m∧¬b) ≤ a∨c = 0，
矛盾。故两者之一可扩 G，由极大性 b ∈ G 或 ¬b ∈ G。
最后"超预滤 = 超滤子"：由 b ∈ G、a ≤ b 得 ¬a ∉ G（否则
a∧¬a ∧ b = 0 违反预滤性），超性给 a ∈ G——上封闭；∧ 封闭同型。∎

两个观察：
- **PIT 是 AC 的弱形式**（P(X) 上它就是 07 章的 Tarski 超滤
  定理；一般 BA 上它严格弱于 AC——Boole bells 在此敲响，见习题）。
- **原子是免费的超滤子**：主超滤 G_a 自动超（a∧b ∈ {a,0} 二选一）。
  无原子世界里超滤子的存在完全靠 PIT——这正是力迫需要它的地方：
  50 章 St(B) 的存在性、51 章商 M/G 的构造，全都踩在 PIT 上。

  Variable B : Type.
  Variables (bmeet bjoin : B → B → B) (bnot : B → B) ...

证明按 47.3 的纸笔路线三步走（`rewrite <- (meet_top b) at 1`
的 `at 1` 定点防止 `←` 重写在全目标乱命中）：(1) b = b⊓⊤ = b⊓(a⊔¬a)

= ¬a⊓b；(3) 合并。Section 末尾在 Bool 上验证七条公理假设全部
成立——"公理记帐式"证明的样板：哪些等式真被用到，Hypothesis
名字一清二楚。
