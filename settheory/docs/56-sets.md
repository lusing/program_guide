## 56.1 集合的直观概念

Makinson 的开场白值得逐句咀嚼：集合就是"把若干东西当成一个整体
来想"。一个班里有绿眼睛的学生可能很多、可能没有、可能恰有一个，
但**绿眼睛学生的集合永远恰有一个**——它是单一的对象，即使它有
很多元素。集合是抽象物，不同于它的元素：即使 Achilles 是班里
唯一绿眼睛的人，{Achilles} 也不是 Achilles。这个"单元素集 ≠ 元素"
的区分将贯穿全书（57 章的有序对、58 章的函数图象、62 章的树都要
用到），也是集合论入门的第一个绊脚石。

记号照旧：x ∈ A 读作"x 是 A 的元素"。Makinson 引入一个方便的
分层：**度 0 集合**（元素本身不是集合，"平面集合论"flatland）
与**度 1 集合**（集合的集合，为免绕口又称 collection / class）。
全书绝大部分时候只需要这两层——这恰好是 01 章 von Neumann 分层
V = ⋃ V_α 的"底部两层"的朴素版，我们在 09 章已经见过它的公理化
形态。

## 56.2 包含、等同与真包含

三个基本关系一次定义清楚：

- **包含**：A ⊆ B 当且仅当 A 的每个元素都是 B 的元素；反方向读作
  "B 包含 A"（B 是 A 的超集，写作 B ⊇ A）。
- **等同**：**外延公理**说，凡是元素完全相同的集合就是同一个集合。
  于是 A = B 当且仅当 A ⊆ B 且 B ⊆ A——这是日后一切"证明两个集合
  相等"的双包含法的出处。
- **真包含**：A ⊊ B 当且仅当 A ⊆ B 且 A ≠ B。此时必有见证元素
  witness：某个 x ∈ B 而 x ∉ A。

Makinson 用一组真假判断训练这三个概念（原书 Exercise 1.2.2 (4)），
我们完整证明其中的四条，其余留作练习：

**(a) A ⊆ B 且 B ⊆ C 推出 A ⊆ C**（包含的传递性）。任取 x，设
x ∈ A；由 A ⊆ B 得 x ∈ B；再由 B ⊆ C 得 x ∈ C。∎

**(b) A ⊆ B 且 C ⊆ B 推出 A ⊆ C——假**。反例：A = {1}，
B = {1,2}，C = {2}。前两个包含都成立，但 1 ∈ A 而 1 ∉ C。

**(e) A ⊆ B 当且仅当 A ⊊ B 或 A = B——真**。从左到右：若 A ⊄ B
则按定义 A ⊊ B；若 A ⊆ B 则二择一成立。从右到左：两种情形都直接
给出 A ⊆ B。

**(f) A = B 当且仅当既非 A ⊊ B 也非 B ⊊ A——假**。"左推右"成立，
但"右推左"失败：反例 A = {1}，B = {2}，互不真包含却不同。

把 (a) 重复有限次，就得到**循环链原则**（原书 (c)）：若
A₁ ⊆ A₂ ⊆ … ⊆ Aₙ 且 Aₙ ⊆ A₁，则所有 Aᵢ 相等。注意这本质上是
对正整数的一次归纳——我们到 59 章才把"归纳"本身作为研究对象，
这正是 Makinson 全书的安排：先用后讲。

**Warning Box（子集 vs 元素）**：避免说"A 包含于 B contained in
B"这种歧义话——它可以指 A ⊆ B 也可以指 A ∈ B。2 ∈ ℕ₊ 但
2 ⊄ ℕ₊；偶数集 E ⊆ ℕ₊ 但 E ∉ ℕ₊。混用二者是初学者最快的翻车
方式。

Lean 通道把 (a)(b)(e) 直接写成三条引理。第一条用 mathlib 现成的
`Set.Subset.trans`，第二条用一个具体的反例集合，第三条是纯逻辑
等价：

```lean
-- examples/lean/Settheory/Ch56Sets.lean（节选）
theorem subset_trans' {A B C : Set α} (h1 : A ⊆ B) (h2 : B ⊆ C) :
    A ⊆ C := h1.trans h2          -- (a)：mathlib 官方锚点

-- (b) 的反例：{1} ⊆ {1,2} 且 {2} ⊆ {1,2}，但 {1} ⊄ {2}
example : ¬ ({1} : Set ℕ) ⊆ {2} :=
  fun h => absurd (h (by decide)) (by decide)   -- 1 ∈ {1}，1 ∉ {2}

-- (e)：A ⊆ B ↔ (A ⊊ B ∨ A = B)
theorem subset_iff_ssubset_or_eq {A B : Set α} :
    A ⊆ B ↔ (A ⊊ B ∨ A = B) := by
  rw [← ssubset_iff_subset_ne]
  constructor
  · rintro (h | rfl); exact Or.inl h; exact Or.inr rfl
  · exact fun h => h.elim (fun x => Or.inl x.1)
      (fun e => Or.inr (Or.inl e))
```

第一段不需要任何证明脚本：`h1.trans h2` 就是包含传递性的函数式
写法。第二个例子展示了"反例如何机器化"：把 1 的两个成员事实
交给 `decide`，矛盾由 `absurd` 打包。第三个定理中我们借助 mathlib
的 `ssubset_iff_subset_ne`（A ⊊ B ↔ A ⊆ B ∧ A ≠ B）把真包含
翻译回"包含且不等"，再做情形拆分——注意 Lean 里 `Or` 的两支
要分别处理，与手写证明的"从左到右/从右到左"完全同构。

## 56.3 图示：Euler 图与 Venn 图

两种图**不是一回事**（chalk and cheese）：

- **Euler 图**（欧拉给公主写信用的）：用圆的嵌套/分离直接画出集合
  的实际关系。A ⊊ B 画成 A 圆在 B 圆内；A = B 画成一个圆。缺点：
  普通的 A ⊆ B（不知是否真包含）无法用单一图形表达——要画两种
  情形分别检查。
- **Venn 图**：两个圆**永远相交**，布局固定；在区域里做记号——
  "∅ 记号"表示该区域无元素，叉号表示有元素。A ⊆ B 用"月牙区域
  为空"表达，A ⊊ B 再加"B 独有区域非空"。

Venn 图的优点恰是 Euler 图的缺点：单一图形即可表达包含而不歧义，
而且能顺带表达集合运算（56.6 节）。缺点是集合一多（三个以上）就
迅速复杂化，直觉价值衰减。Makinson 的告诫值得记住：**图示是启发
工具，不是证明**——图形不能证明一般命题，但能帮你构造反例、或
让证明的路数变得显然。

## 56.4 定义集合的三种方式

1. **枚举**：{1, 2, 3}。只对有限集可行；顺序与重复无实质影响
   （{1,2,3} = {3,2,1} = {1,1,2,3}，由外延公理保证）。
2. **性质**（概括记号）：A = {x ∈ ℕ₊ : x < 10}。冒号读"使得"。
   它是 01 章分离公理模式的朴素形态——在那里我们看到"全体 x 使得
   φ(x)"的无界概括会制造 Russell 悖论，所以必须相对一个已有集合
   分离。
3. **递归**：给出初始元素和从旧元素生成新元素的规则。这是 59 章
   的主题，也是"悬置点记号" {2,4,6,…} 的严格化。

一个训练同一性的好练习（原书 Exercise 1.2.2 (3)）：{8} = {{8}}
吗？不——左边唯一的元素是数 8，右边唯一的元素是集合 {8}。
{London, Beijing} = {Londres, Pekin} 吗？是的——元素相同（同一
城市的不同名字）。{+} = {`+`} 吗？不是——一个是加法运算本身，
一个是它的名字（符号）。**对象与它的名字之别**在计算机科学、
逻辑与语言学里反复出现，57 章讲关系记号时会再次遇到。

## 56.5 空集

没有元素的集合**至多一个**（外延公理：元素完全相同——都没有），
故空集 ∅ 存在则唯一。它毫不"次等"，正如 0 毫不次等于正数。

**∅ ⊆ A 对一切 A 成立**。证明只有一句：要有 x ∈ ∅ 而 x ∉ A 才能破坏
包含，但根本没有 x ∈ ∅。∎ 这是"虚空真"（vacuous truth）的第一个
样本：**假前提的条件句恒真**。63 章的真值表会告诉我们为什么数学
这样约定（条件句只在"前件真后件假"时为假）。

两个进一步的概念：

- A 与 B **不相交**（disjoint）iff 没有公共元素，iff A ∩ B = ∅；
  有公共元素则称**重叠**（overlap）。
- A₁, …, Aₙ **两两不相交** iff 每两个不同的 Aᵢ, Aⱼ 都不相交。

注意"两两"不可省：X = {1,2}, Y = {3}, Z = {1,4} 三者满足 X 与 Y
不相交、Y 与 Z 不相交，但整体并非两两不相交（X 与 Z 共享 1）。
这个三集合反例在 50 章 Δ 引理（Δ-system）那里以"根 = ∅ 的情形"
重新出现过——那里我们要的是一族两两交相同的集合，比两两不交
更强也更微妙。

## 56.6 布尔运算：交、并、差、补

### 56.6.1 交（meet）

x ∈ A ∩ B 当且仅当 x ∈ A 且 x ∈ B。七条基本律，每条都可由定义
"拆开—重排—打包"直接验证：

| 律 | 陈述 |
|---|---|
| 下界 | A ∩ B ⊆ A，A ∩ B ⊆ B |
| 最大下界 | X ⊆ A 且 X ⊆ B 推出 X ⊆ A ∩ B |
| 交换 | A ∩ B = B ∩ A |
| 结合 | A ∩ (B ∩ C) = (A ∩ B) ∩ C |
| 幂等 | A ∩ A = A |
| 底 | A ∩ ∅ = ∅ |
| 刻画 | A ⊆ B 当且仅当 A ∩ B = A |

"最大下界"值得单独看：它说 A ∩ B 是 {A, B} 在包含序下的**交**
——这正是 18 章格论语言里 inf 的原型。Makinson 的点评是：交的
行为完全镜像逻辑联结词"且"（合取）的行为，因为定义里用的就是
"且"。合取真值表（1 表真、0 表假）：仅当 a、b 皆为 1 时 a ∧ b
为 1。交换律 A ∩ B = B ∩ A 之成立，根子在于"a 且 b"与"b 且 a"
真值条件相同。

### 56.6.2 并（union）与对偶

x ∈ A ∪ B 当且仅当 x 属于 A、B 至少之一（**可兼析取**，inclusive
or）。并的定律是交的定律"上下颠倒"：上界、最小上界、交换、结合、
幂等、A ∪ ∅ = A。所谓**对偶**，此刻只是直觉，到 47 章（BA 的
对偶原理）与 48 章（Stone 空间的开/闭对换）才获得精确形态。

交与并的相互作用（原书 Exercise 1.4.2 (4)，全部可证）：

- A ∩ B ⊆ A ∪ B；
- **吸收律** A ∩ (A ∪ B) = A = A ∪ (A ∩ B)；
- **分配律（双向）** A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)，
  A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)；
- A ⊆ B 当且仅当 A ∪ B = B。

双向分配律值得完整证一遍（以"交对并"为例）。设 x ∈ 左边，则
x ∈ A 且 x ∈ B ∪ C。分情况（disjunctive proof）：若 x ∈ B，则
x ∈ A ∩ B，故属于右边；若 x ∈ C，同理 x ∈ A ∩ C。反向包含同法：
x ∈ (A∩B) ∪ (A∩C) 时 x 至少落在 A∩B、A∩C 之一，两种情形都给
出 x ∈ A 且 x ∈ B∪C。∎ 注意这里用到的**分情况证明**（两个情形
不必互斥——重叠也无妨，覆盖两次不碍事）是 65 章要形式化的策略
之一。

分配律在分配格上成立，但在一般格里"交对并"与"并对交"互不
可得（mathlogic 教程 34 章与本书 47 章都记过这个坑： (∨⊢)/(⇒∨)
型演算对一般格不可靠）。𝒫(U) 是分配格的最典型实例——因为底层
逻辑 ∧、∨ 本身双向分配。

### 56.6.3 差与补

**差**：x ∈ A \ B 当且仅当 x ∈ A 且 x ∉ B。它与交、并性格迥异：

- **不交换**：{1,2} \ {2,3} = {1} ≠ {3} = {2,3} \ {1,2}。
- A \ A = ∅；A \ ∅ = A。
- 单调性各自独立：A ⊆ A′ 推出 A \ B ⊆ A′ \ B；B ⊆ B′ 推出
  A \ B′ ⊆ A \ B（注意方向反转——差对第二个变元**反变**）。
- 相对 De Morgan：A \ (B ∪ C) = (A \ B) ∩ (A \ C)；
  A \ (B ∩ C) = (A \ B) ∪ (A \ C)。
- (A \ B) \ C = (A \ C) \ B（差可以换位），但
  A \ (B \ C) = (A \ B) \ C **假**：取 C = B = A ≠ ∅，左边
  = A \ ∅ = A，右边 = ∅。
- 包含式 A \ (B \ C) ⊆ (A \ B) ∪ C 成立。

当调查限定在某个大集合 U（如 ℕ₊）的子集范围内时，U 称**局部宇
宙**，U \ B 简写为 −B（补）。补的定律：−(−B) = B，−U = ∅，
−∅ = U，以及大名鼎鼎的 **De Morgan 律**：

    −(B ∪ C) = (−B) ∩ (−C)        −(B ∩ C) = (−B) ∪ (−C)

至此，𝒫(U) 连同 ∩、∪、−、⊆、∅、U 构成一个**布尔代数**。47 章
的公理化（十律）与 48 章 Stone 对偶（𝒫(U) ≅ CLOP(2^U)）不过是把
这张代数表的抽象结构提取出来。Makinson 在这里只说了一句"after
George Boole, who first studied them systematically"——但布尔代数
的历史线我们已经在 47.1 节走过：Boole 1847 → Boole 1854 代数化
逻辑 → Stone 1936 对偶 → 本书 46-55 章的力迫大厦。

Julia 通道用位串把这张代数表**穷举验证**一遍——对 6 元宇宙的全
部 64 个子集两两组合，逐条检查定律是否成立：

```julia
# examples/julia/56_sets.jl（节选）
meet(a, b) = a & b; uni(a, b) = a | b; diff(a, b) = a & ~b

ok = true
for a in 0:63, b in 0:63, c in 0:63        # 6 元宇宙的全部 64 个子集
    ok &= meet(a,b) == meet(b,a)           # 交换律
    ok &= uni(a,b) == uni(b,a)
    ok &= meet(a, uni(b,c)) == uni(meet(a,b), meet(a,c))   # 分配律（双向）
    ok &= uni(a, meet(b,c)) == meet(uni(a,b), uni(a,c))
    ok &= meet(a, uni(a,b)) == a           # 吸收律
    ok &= diff(a, uni(b,c)) == meet(diff(a,b), diff(a,c))  # 相对 De Morgan
    ok &= diff(a, meet(b,c)) == uni(diff(a,b), diff(a,c))
end
println("  交并差九律（64^3 穷举）：", ok ? "全部成立 ✓" : "有反例！")
```

穷举的对象不是"证明"（定律已经手证过了），而是**证伪性的普查**
——如果哪条定律被我们抄错（例如把 De Morgan 的 ∩ 写成 ∪），机器
会立刻以反例打脸。这正是多通道教程的方法论：证明给 Lean/Isabelle，
证伪的敏感度给计算通道。

## 56.7 广义并与广义交

从平面集合论抬起一只脚：设 {Aᵢ}ᵢ∈I 是一个由指标集 I 索引的集合
族。定义

    ⋃ᵢ∈I Aᵢ = {x : 存在 i ∈ I，x ∈ Aᵢ}        （广义并）
    ⋂ᵢ∈I Aᵢ = {x : 对一切 i ∈ I，x ∈ Aᵢ}        （广义交）

二元情形是特例（I = {1,2}）。四条一般律（相对任意局部宇宙取补）：

- **分配**：A ∩ (⋃ᵢ Bᵢ) = ⋃ᵢ (A ∩ Bᵢ)；A ∪ (⋂ᵢ Bᵢ) = ⋂ᵢ (A ∪ Bᵢ)。
- **De Morgan**：−⋃ᵢ Aᵢ = ⋂ᵢ (−Aᵢ)；−⋂ᵢ Aᵢ = ⋃ᵢ (−Aᵢ)。

证明依旧"拆开—重排—打包"，例如第一条：x ∈ 左边 iff x ∈ A 且
存在 i 使 x ∈ Bᵢ，iff 存在 i 使 x ∈ A ∩ Bᵢ，iff x ∈ 右边。∎
底层逻辑的对应物是**量词对合取/析取的分配**（∃x(a∧b) ↔ ∃xa ∧ ∃xb
的一半，∀ 同理）——64 章将把它作为量词等价式的重头戏。

Isabelle/ZF 通道用官方集合族记号 `Union`/`Inter` 把广义 De Morgan
做出来（注意 ZF 里 `Pow(U)` 就是幂集、`-` 就是补）：

```isabelle
-- examples/isabelle/ST56/Sets.thy（节选）
lemma general_de_morgan:
  assumes "A ⊆ U"
  shows "U - (⋃x∈A. f(x)) = (⋂x∈A. U - f(x))"
proof (rule equalityI)
  show "U - (⋃x∈A. f(x)) ⊆ (⋂x∈A. U - f(x))"
  proof (rule subsetI)
    fix y assume "y ∈ U - (⋃x∈A. f(x))"
    hence "y ∈ U" and "∀x∈A. y ∉ f(x)" by blast+
    thus "y ∈ (⋂x∈A. U - f(x))" by blast
  qed
  show "(⋂x∈A. U - f(x)) ⊆ U - (⋃x∈A. f(x))"
    using assms by blast
qed
```

双向包含里"容易的一向"交给 `blast`（ZF 的元素推理对这种一阶
形态非常可靠），"难的一向"手工展开——因为从"y 不在大并里"要
拆出"对一切 x，y ∉ f(x)"，这一步的量词方向是初学者最常见的
失分点，值得在正文里看见它被显式写出。

**Alice Box：collection 与 family**。"set of sets"读着拗口，所以
说 collection/class——词变内容不变。但 **family** 在 Makinson 的
术语里是保留字：严格指一种函数（指标化），58 章 3.6 节才定义。
本书前八篇一直混用"族"，从本篇起尊重这个区分：集合族（索引族）
= family。

## 56.8 幂集

**幂集** 𝒫(A) = 2^A = {B : B ⊆ A}。对 A = {1,2,3}：

    𝒫(A) = {∅, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3}}

共 8 个元素。**Warning**：别漏掉两个极端元素 ∅ 与 A 本身；也别把
1 与 {1} 弄混——1 ∉ 𝒫(A) 而 {1} ∈ 𝒫(A)。

**计数定理**：有限集 A 有 n 个元素，则 𝒫(A) 有 2ⁿ 个。证明是
乘法原理的第一次亮相：把 A 的元素列成 a₁, …, aₙ，子集 B 的身份
由 n 个独立二元选择决定（aᵢ ∈ B 与否），共 2×2×…×2 = 2ⁿ 种。∎
这个证明同时给出了**位串表征**：子集 ↔ 特征向量 ∈ {0,1}ⁿ。58 章
3.5.4 的特征函数是它的函数形态，63 章命题逻辑的赋值又是它的
"字母表"形态——同一个 2ⁿ 出现在三个剧场。

𝒫(A) 的包含关系有一张经典的 **Hasse 图**：元素按 ⊆ 排层，连线
只画"立即包含"（B ⊊ C 且中间无第三者）。对 {1,2,3}，底部是 ∅，
中层三个单元素集，顶层向下连到 {1,2}、{1,3}、{2,3}，顶是 A。
57 章将把 Hasse 图认作偏序的**有向图压缩**——只画传递闭包的
"骨架边"。

对计算者，2ⁿ 是一声警钟：**指数爆炸**。若某算法的代价随输入
规模 n 按 2ⁿ 增长（如穷举所有子集），n = 10 尚可（1024），n = 100
即 2¹⁰⁰ ≈ 1.27×10³⁰ 步——宇宙热寂都算不完。这也是为什么本教程
的机器通道永远优先"结构性"验证而非暴力枚举，以及为什么 26 章
Ramsey 型问题要用数学（而非搜索）拿界。

Coq 通道把计数定理完整证明：幂集生成为函数（对每个元素选择
"留/去"），归纳证明长度恒为 2ⁿ：

```coq
(* examples/coq/Ch56_sets.v（节选） *)
Fixpoint powerset (l : list nat) : list (list nat) :=
  match l with
  | [] => [[]]
  | x :: xs => let rest := powerset xs in
               rest ++ map (cons x) rest
  end.

Theorem card_powerset : forall l,
    NoDup l -> length (powerset l) = 2 ^ length l.
Proof.
  induction l as [|x xs IH]; intros Hnd; simpl.
  - reflexivity.
  - inversion Hnd; subst.
    rewrite length_app, length_map.
    rewrite IH by assumption. lia.
Qed.
```

`powerset` 的递归形状就是乘法原理：对表头 x，每个子集要么不含 x
（原样继承 xs 的子集），要么含 x（在 xs 的子集前加 x）。归纳步骤
里 `length_app`（表连接长度可加）与 `length_map`（映射保长度）把
"|rest| + |rest| = 2·2^|xs|"算干净——顶层 `simpl` 已把 2^(n+1)
展开为 `2^n + (2^n + 0)`，最后一步纯交给 `lia`。`NoDup` 前提是
必要的：幂集的定义域得是真正的集合（无重复元素），否则计数会
翻倍。文件末尾的 `Example cert_pow3 : length (powerset [1;2;3]) = 8`
用 `vm_compute` + `reflexivity` 秒验，与手数一致。

Prolog 通道用同一思路生成幂集并验证 2ⁿ：

```prolog
% examples/prolog/56_sets.pl（节选）
pow([], [[]]).
pow([X|Xs], P) :- pow(Xs, P0),
                  findall([X|S], member(S, P0), Add),
                  append(P0, Add, P).

card_pow(N) :- numlist(1, N, L), pow(L, P), length(P, K),
               K =:= 2^N, format("  幂集计数：|P({1..~d})| = ~d = 2^~d ✓~n", [N,K,N]).
```

`pow/2` 的两条子句与 Coq 的 `Fixpoint` 一一对应（空表的幂集是
{∅}；一般表的幂集 = 不含表头的继承 + 含表头的追加）。查询
`card_pow(4, K)` 会回 `K = 16`。

## 56.9 数集速览与本章机器账本

全书的数字舞台：ℕ₊ = {1,2,3,…}；ℕ = ℕ₊ ∪ {0}（注意有作者用 ℕ
指 ℕ₊——读书要防）；ℤ；ℚ = {p/q : p, q ∈ ℤ, q ≠ 0}；ℝ（十进制
展开表示）。它们在 03-04 章的构造论版本（von Neumann 序数、
Cantor 实数）与本篇的朴素用法互为表里。

七通道分工总结：

| 通道 | 承载 | 关键锚点 |
|---|---|---|
| Lean | 包含传递、真包含反例、分配律、幂集 | `Set.Subset.trans`、`Set.inter_union_distrib_left`、`Finset.card_powerset` |
| Isabelle/ZF | 广义 De Morgan、𝒫({0,1}) 四元素枚举 | `equalityI`+`subsetI`、`Pow_iff`、equalities 库 |
| Coq | 幂集函数 + 2ⁿ 计数定理 | `powerset`/`card_powerset`、`length_app` |
| Agda | membership 级子集格律 | 自写 `_⊆_`、`∅-最小` |
| Julia | 64×64×64 位串穷举定律普查 | 位运算即集合运算 |
| Python | 特征函数/位串双向翻译、指数增长 | `itertools.product` |
| Prolog | 幂集生成、两两不交判定 | `pow/2` |

Agda 通道的选材说明：命题相等在列表层面证明交换律需要外延性，
故 Agda 在**成员级**（membership-level）重建——A ∩ B ⊆ B ∩ A 的
元素版证明是 `fun x h → record{ proj1 = h.proj2; proj2 = h.proj1 }`，
一句话交换合取的两个分量，恰是"交的交换律根植于且的交换律"的
构造性注脚：

```agda
-- examples/agda/Ch56_sets.agda（节选）
_⊆_ : List A → List A → Set
xs ⊆ ys = ∀ x → x ∈ xs → x ∈ ys

∩-comm-sub : ∀ xs ys → (xs ∩ ys) ⊆ (ys ∩ xs)
∩-comm-sub xs ys x h = record { proj1 = h .proj2 ; proj2 = h .proj1 }
```

## 56.10 收束：从平面到分层

本章的集合论是"平面的"：元素不是集合，最多到度 1。但三个方向
已经悄悄指向深处：𝒫(A) 上的布尔运算预告 47-48 章的抽象布尔代数
与 Stone 空间；Hasse 图与 ⊆ 偏序预告 57 章的关系理论；"子集 ↔
位串"预告 63 章的赋值语义。下一章把两个集合的元素**配对**，从
平面走向 (a, b) 的世界——关系、函数、等价、序，全部从有序对
生发。
