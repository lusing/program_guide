# 85 · 传递模型与内在模型论

> 第 84 章把公式、证明和满足关系做成了集合，并在 KP 里分出三个传递模型：(V_ω, ∈) ⊨ KP⁻，正则 κ > ω 时 (H_κ, ∈) ⊨ KP，不可达时 (H_κ, ∈) = (V_κ, ∈) ⊨ ZFC。那些模型还只是例子。本章把模型论本身写进集合论：依定义扩充为什么不改变一致性，Δ₀ 公式为什么在传递类上绝对，初等子模型怎样用塔尔斯基准则和斯科伦函数制造出来，以及一条公式怎样被反射到某个 V_α。相对一致性的句式
>
> Con(T) → Con(T₁)
>
> 从此有了内部的说法。编号沿用第二卷 §1.2 的定义 1.35 至定理 1.30。证明写在下面。

## 85.1 依定义扩充

集合论的初始语言只有一个二元谓词 ∈。子集、幂集、无序对、并、交都是后来添上的写法。添法有两种。一种是随便加一个新符号，再单独加一条非逻辑公理规定它的含义。符号和公理可以无限加下去，一致性要重新证明，理论也越来越难读。另一种是只加那些已经能被旧公式定义出来的符号。第二种不增加能证明的旧句子，只缩短写法。

子集是谓词。它的定义式是

a ⊆ b ↔ ∀z (z ∈ a → z ∈ b)。

凡是写了 ⊆ 的公式，把 ⊆ 按这个双条件换回 ∈，真假不变。幂集是函数符号。定义式是

z = 𝒫(a) ↔ ∀u (u ∈ z ↔ u ⊆ a)。

幂集公理给出存在性：∀a ∃z ∀u (u ∈ z ↔ u ⊆ a)。外延公理给出唯一性：两个候选若元素相同则相等。存在并且唯一，才可以合法地写 𝒫(a)。无序对 {a, b}、并 ⋃a、交 a ∩ b 是同一模式：配对公理、并集公理、分离公理分别提供存在性，外延公理提供唯一性。

> **定义 1.35（谓词的定义性扩充）** 设 L 是一阶语言，T 是 L 的理论，φ(v₁,…,vₙ) 是 L 的公式，自由变元都在 v₁,…,vₙ 之中。P 是一个新的 n 元谓词。令
>
> L₁ = L ∪ {P}，
>
> T₁ = T ∪ {∀v₁…∀vₙ (P(v₁,…,vₙ) ↔ φ(v₁,…,vₙ))}。
>
> L₁ 是 L 的依定义扩充，那条双条件句是 P 的定义公理，T₁ 是 T 的定义性扩充。

谓词没有额外的存在性要求。φ 可以什么都不定义成“处处成立”，P 仍然是合法的缩写。

> **定义 1.36（函数符号的定义性扩充）** 设 φ(v₁,…,vₙ, vₙ₊₁) 是 L 的公式，并且 T 已经证明存在性
>
> ∀v₁…∀vₙ ∃vₙ₊₁ φ(v₁,…,vₙ, vₙ₊₁)
>
> 和唯一性
>
> ∀v₁…∀vₙ∀vₙ₊₁∀vₙ₊₂ (φ(v₁,…,vₙ, vₙ₊₁) ∧ φ(v₁,…,vₙ, vₙ₊₂) → vₙ₊₁ = vₙ₊₂)。
>
> F 是一个新的 n 元函数符号。定义公理是
>
> ∀v₁…∀vₙ∀vₙ₊₁ (vₙ₊₁ = F(v₁,…,vₙ) ↔ φ(v₁,…,vₙ, vₙ₊₁))。
>
> 把这条公理加进 T 得到 T₁。

函数符号和谓词的差别就在这里：函数必须处处有值，而且值唯一。这两件事由基础理论 T 证明，不能靠定义公理自己保证。常元是 0 元函数，条件退化成 ∃!z φ(z)。

> **定理 1.17（保守性）** L₁ 是 L 的定义性扩充，T₁ 是 T 加上相应定义公理。φ 是 L 的语句时，T₁ ⊢ φ 当且仅当 T ⊢ φ。更一般地，L₁ 的每个公式 ψ(v₁,…,vₙ) 都有一个 L 公式 ψ*(v₁,…,vₙ)，自由变元相同，并且
>
> T₁ ⊢ ∀v₁…∀vₙ (ψ ↔ ψ*)。

翻译是按公式递归做的。原子公式里若出现新谓词 P(t₁,…,tₙ)，就换成定义式 φ(t₁,…,tₙ)。若出现新函数符号，先用定义式把它从项里消去：t = F(s) 换成 ∃z (z = t ∧ φ(s, z))，再对 z 用唯一性收回。布尔联结词和量词保持不动。对证明的长度做归纳：逻辑公理的翻译仍是逻辑公理，T 的公理翻译成自己，定义公理翻译成 φ ↔ φ 这种重言，肯定前件在翻译之后仍是肯定前件。所以 T₁ 的证明翻译成 T 的证明。反方向显然，因为 T ⊆ T₁。旧语言的语句翻译之后就是自己，于是 T₁ 与 T 证明同样的旧语句。一致性是这个事实的特例：T₁ 证明矛盾，当且仅当 T 证明矛盾。

空集、ω、ℤ、ℚ、ℝ 在各自的定义里都满足 ∃!z φ(z)，所以它们是依定义引进的常元。序数谓词 Ord 不是常元。若 φ(v) 定义 Ord，则

ZF ⊢ ¬∃z ∀a (a ∈ z ↔ φ(a))，

因为全体序数不构成集合。Ord 仍是定义 1.35 意义下的合法谓词，只是不能把“Ord 的外延”写成一个集合常元。基数、共尾度、彻底有限这些概念也是这样：讨论里用的是概念，形式语言里对应的是一条定义式，不一定再单独立一个常元。

> **定理 1.18（扩充可以叠）** 设 L₀ ⊆ L₁ ⊆ L₂，Tᵢ 是 Lᵢ 的理论。若 T₁ 是 T₀ 的定义性扩充，T₂ 是 T₁ 的定义性扩充，则 T₂ 与 T₀ 的某个定义性扩充证明同样的 L₂ 语句。

把两次翻译接起来即可。先把 L₂ 翻回 L₁，再把 L₁ 翻回 L₀。复合翻译就是直接从 L₂ 到 L₀ 的定义性翻译。因此在已有的 ⊆、𝒫、⋃ 上再定义笛卡尔积、函数、序数，每一步都是保守的。后面所有“ZF 加上这些符号”都与原来的 ZF 证明同样的 ∈ 语句。

传递模型关心的是另一件事：定义式若是 Δ₀ 的，新符号在传递模型里的解释不随模型改变。这就是下一节。

## 85.2 Δ₀ 绝对性

第 84 章在两个传递集合之间比较了 Δ₀ 公式。这里把其中一边换成类，并把量词的相对化写明确。设 W 是类，φ 是公式。φ^W 是把 φ 里每个无界量词 ∀x、∃x 收成 ∀x∈W、∃x∈W，有界量词 ∀x∈t、∃x∈t 保持原样，原子公式 x ∈ y、x = y 保持原样。参数若已经在 W 里，就不再被量词移动。

> **定理 1.19（Δ₀ 绝对性）** 设 φ(v₁,…,vₙ) 是 Δ₀ 公式。
>
> (1) 若 M、N 是传递集合，M ⊆ N，a₁,…,aₙ ∈ M，则
>
> (M, ∈) ⊨ φ[a₁,…,aₙ] 当且仅当 (N, ∈) ⊨ φ[a₁,…,aₙ]。
>
> (2) 若 M 传递，a₁,…,aₙ ∈ M，则
>
> (M, ∈) ⊨ φ[a₁,…,aₙ] 当且仅当 V ⊨ φ[a₁,…,aₙ]。
>
> (3) 若 W 是传递类，a₁,…,aₙ ∈ W，则
>
> V ⊨ (φ(a₁,…,aₙ) ↔ φ^W(a₁,…,aₙ))。

(1)(2) 是 (3) 的特例：令 W 先取 N 再取 V，或者令 W = M 而外层结构取 N。(3) 对 φ 的复杂度做归纳。

原子公式 x ∈ y、x = y 不含量词，相对化不改变它们。φ^W 与 φ 是同一个 ∈ 断言。

若 φ 是 ¬ψ、ψ ∧ θ、ψ ∨ θ、ψ → θ，归纳假设对 ψ、θ 已经给出双条件，布尔真值表在两边同时翻转，双条件保持。

现在设 φ 是 ∃u∈a₁ ψ(a₁,…,aₙ, u)，a₁,…,aₙ ∈ W。先假设 φ^W。相对化之后这是

∃u (u ∈ W ∧ u ∈ a₁ ∧ ψ^W)。

取这样的 u。u ∈ a₁ ∈ W，W 传递，所以 u ∈ W 其实被 u ∈ a₁ 强制，归纳假设把 ψ^W 换成 ψ，于是 φ 在 V 中成立。反方向：φ 给出 u ∈ a₁ 且 ψ。传递性把 u 送进 W，归纳假设把 ψ 换成 ψ^W，于是 φ^W 成立。

全称 ∀u∈a₁ ψ 写成 ¬∃u∈a₁ ¬ψ，或者直接对两边做同样的拉回：W 传递保证 a₁ 的元素都在 W 里，所以“对 a₁ 的每个元素”在 W 里说和在 V 里说是同一批元素。归纳假设再把矩阵换掉。

有界量词是唯一用到传递性的步骤。没有传递性，界 a₁ 的元素可以落在 W 外面，φ 看得到它，φ^W 看不到。第 84 章的机器证明把这个步骤写成了有界全称的两个方向。本节的定理 1.22 是无界量词的对应物：无界存在不能靠传递性自动拉回，必须单独假设见证已经在子模型里。

## 85.3 结构、赋值、满足

从这里起，语言、项、公式都是集合。第 84 章已经把它们编码进 V_ω。结构也是集合。

语言 L 的一个结构是有序对 𝔄 = (A, I)。A 非空，叫做论域。I 把 L 的符号解释进 A：常元 c 的解释 I(c) ∈ A；k 元函数符号 F 的解释是函数 I(F): Aᵏ → A；n 元谓词 P 的解释是 I(P) ⊆ Aⁿ。

赋值 v 把变元符号送进 A。项的值 v̄ 由 v 和 I 递归算出：变元 vᵢ 的值是 v(vᵢ)，常元 c 的值是 I(c)，复合项 F(t₁,…,tₖ) 的值是 I(F)(v̄(t₁),…,v̄(tₖ))。项 t 里只出现有限个变元，所以 v̄(t) 只依赖 v 在这有限个变元上的值。

> **定义 1.37（塔尔斯基满足）** 设 φ 是 L 公式，𝔄 = (A, I)，v 是赋值。
>
> 1. (𝔄, v) ⊨ t₁ = t₂ 当且仅当 v̄(t₁) = v̄(t₂)。左边的 = 是公式里的符号，右边的 = 是集合的外延相同。
> 2. (𝔄, v) ⊨ P(t₁,…,tₖ) 当且仅当 (v̄(t₁),…,v̄(tₖ)) ∈ I(P)。
> 3. (𝔄, v) ⊨ ¬ψ 当且仅当并非 (𝔄, v) ⊨ ψ。
> 4. (𝔄, v) ⊨ (ψ → θ) 当且仅当并非 (𝔄, v) ⊨ ψ，或者 (𝔄, v) ⊨ θ。
> 5. (𝔄, v) ⊨ ∀vₘ ψ 当且仅当每一个与 v 在 φ 的自由变元上一致、只可能在 vₘ 上不同的赋值 v′ 都满足 (𝔄, v′) ⊨ ψ。

自由变元决定真假：若 v 与 μ 在 φ 的自由变元上一致，则 (𝔄, v) ⊨ φ 当且仅当 (𝔄, μ) ⊨ φ。因此可以写 𝔄 ⊨ φ[a₁,…,aₙ]，意思是每一个把 vᵢ 送到 aᵢ 的赋值都满足 φ。φ 是语句时，赋值不再起作用，写成 𝔄 ⊨ φ。

结构的理论是

Th(𝔄) = {φ | φ 是语句且 𝔄 ⊨ φ}。

公式或公式集可满足，就是存在某个赋值结构使它成立。𝔄 ⊨ T 表示 T 的每条语句都在 𝔄 中成立，这时 𝔄 是 T 的模型。每个结构都是自己的理论的模型。

T ⊨ φ 表示：任何一个满足 T 的赋值结构也满足 φ。这是语义推论。T ⊢ φ 仍是第 84 章那个有限证明。完备性定理说这两件事重合。

## 85.4 完备性与紧致性

> **定理 1.20（哥德尔完备性）** 设 T 是一阶语言 L 的公式集，φ 是 L 的公式。
>
> (1) T ⊢ φ 当且仅当 T ⊨ φ。
> (2) T 一致当且仅当 T 可满足。因此一个理论一致当且仅当它有模型。

可靠性（⊢ 推出 ⊨）直接检查。逻辑公理在任何结构里都真：命题重言式按真值表，量词公理 ∀x φ(x) → φ(t) 按赋值的定义，等式公理按项值的递归。肯定前件保持真。所以证明的每一行都在所有模型里真。若 T ⊢ φ 且 T ⊢ ¬φ，则没有结构能同时满足两者，T 不可满足。

完全性（⊨ 推出 ⊢）走亨金构造。设 T 不证明 φ。则 T ∪ {¬φ} 一致：否则由归谬已经得到 T ⊢ φ。往语言里为每个形如 ∃x ψ 的公式加一个新常元 c_ψ，并加亨金公理 ∃x ψ → ψ(c_ψ)。新理论仍一致，因为一段用到新常元的矛盾证明可以换成“取一个见证”的存在推理，回到旧语言。语言若可数，就把公式枚举出来，一轮轮加见证；语言更大时，用选择公理把这个构造做到与语言等势的序数上。然后用佐恩引理或同样的枚举把一致集扩成极大一致集 Γ：对每条公式，它或它的否定在 Γ 里，而且 Γ 在肯定前件下封闭。

项模型的论域是闭项的等价类，t ∼ s 当且仅当 Γ ⊢ t = s。函数符号按代表元作用，谓词按 Γ 是否证明该原子公式来解释。真值引理：对每个语句 θ，项模型满足 θ 当且仅当 Γ ⊢ θ。归纳的存在步骤用亨金常元：Γ 证明 ∃x ψ 时，ψ(c) 也在 Γ 里，c 的等价类就是见证。于是项模型是 T ∪ {¬φ} 的模型，T 并不在语义上推出 φ。

(2) 是 (1) 的改写。T 不一致就是 T ⊢ ∃x (x ≠ x)，按 (1) 等价于每个模型都满足矛盾，也就是没有模型。

这个构造全程是集合论里的构造：公式是集合，极大一致集用幂集上的选择或佐恩得到，项模型是闭项集的商。所以完备性是 ZF（带选择时对任意语言，可数语言不用选择）的定理。第 84 章说“V ⊨ φ”不能写成一条 ∈ 公式，指的是整个真类 V；这里的 𝔄 是集合，定义 1.37 的递归在集合上停得下来。

> **定理 1.21（紧致性）** T 是语句集。T 一致当且仅当 T 的每个有限子集都一致。

证明是有限的。一段形式证明只引用有限条公理。若 T 不一致，矛盾的证明只用到某个有限子集 T₀，T₀ 也不一致。反方向：有限子集都一致，则 T 不能有矛盾证明，T 一致。再由定理 1.20，T 有模型。

群、环、域、代数闭域的公理都有集合模型，所以这些理论在 ZF 里就被证明是一致的。佩亚诺算术 PA 以 (ω, 0, 1, +, ·) 为模型，因此 ZF ⊢ Con(PA)。这一步用到无穷公理：没有 ω，就没有这个模型。哥德尔第二不完全性定理说 PA 自己证明不了 Con(PA)，ZF 也证明不了 Con(ZF)。集合论比算术多出来的，是给一批更强的理论提供模型的能力。下面几节就是在制造这些模型。

## 85.5 同构、初等等价、子结构

设 𝔄 = (A, I)，𝔅 = (B, J) 是同一语言的两个结构。

同构 𝔄 ≅ 𝔅 是一个双射 f: A → B，保常元、保函数、保谓词：f(I(c)) = J(c)，并且

aₖ₊₁ = I(F)(a₁,…,aₖ) 当且仅当 f(aₖ₊₁) = J(F)(f(a₁),…,f(aₖ))，

(a₁,…,aₖ) ∈ I(P) 当且仅当 (f(a₁),…,f(aₖ)) ∈ J(P)。

同构保持一切一阶公式的真假，所以 Th(𝔄) = Th(𝔅)。反过来不成立。两个理论相同的结构叫初等等价，写成 𝔄 ≡ 𝔅。实数域和某个非阿基米德的实闭域可以初等等价而不同构；紧致性给得出这样的例子，这里不展开。

𝔅 是 𝔄 的子结构，写成 𝔅 ⊆ 𝔄，当且仅当 B ⊆ A，常元的解释相同，函数在 B 上的值仍落在 B 里并且与 I 一致，谓词是 I 在 B 上的限制。子结构保原子公式和它们的布尔组合，不保量词。

初等子结构 𝔅 ≺ 𝔄 是子结构再加一条：对每个公式 φ(v₁,…,vₙ) 和每个 a₁,…,aₙ ∈ B，

𝔅 ⊨ φ[a₁,…,aₙ] 当且仅当 𝔄 ⊨ φ[a₁,…,aₙ]。

嵌入是到某个子结构上的同构。初等嵌入是到某个初等子结构上的同构。

## 85.6 塔尔斯基准则

初等性不用逐个公式去比。存在量词的见证若能选在子论域里，其余公式跟着走。

> **定理 1.22（塔尔斯基准则）** 设 𝔄 = (A, I)，B ⊆ A 非空。B 是 𝔄 的某个初等子结构的论域，当且仅当 B 满足下面的封闭条件：若 φ(v₁,…,vₙ, vₙ₊₁) 的自由变元都在这些变元里，a₁,…,aₙ ∈ B，并且存在 a ∈ A 使 𝔄 ⊨ φ[a₁,…,aₙ, a]，则存在 b ∈ B 使 𝔄 ⊨ φ[a₁,…,aₙ, b]。

必要性。设 B ≺ A，并且 𝔄 ⊨ ∃x φ[a₁,…,aₙ, x]。初等性把存在句搬到子结构，子结构给出 b ∈ B，再搬回来得到 𝔄 ⊨ φ[a₁,…,aₙ, b]。

充分性。先按子结构的条款解释 B 上的符号：常元已在 A 里，封闭条件用于“存在函数值”把函数值留在 B 里；谓词取限制。然后对公式复杂度做归纳，证明 a₁,…,aₙ ∈ B 时两边真假相同。原子公式和布尔组合只用到子结构的定义。存在公式：若 𝔄 ⊨ ∃x φ，封闭条件给出 b ∈ B 且 𝔄 ⊨ φ[…, b]，归纳假设把 φ 搬进 B，所以 B 也满足存在句。反方向，B 里的见证本来就在 A 里，归纳假设把矩阵搬回 A。

机器通道把这条充分性做成了归纳定理。公式只有相等、否定、合取、存在四种构造子，其余联结词是缩写。载体是类型上的一个谓词，环境是变元到元素的函数。`closed` 就是定理 1.22 的封闭条件。

Lean 里的陈述是：

```lean
theorem tarski_agreement
    (A B : S → Prop) (sub : ∀ {x}, B x → A x)
    (closed : ∀ (p : Fm) (e : Nat → S) (i : Nat),
      envIn B e → val e (.ex i p) A → ∃ x, B x ∧ val (update e i x) p A)
    (p : Fm) (e : Nat → S) (he : envIn B e) :
    val e p B ↔ val e p A
```

`envIn B e` 说环境的每个值都在 B 里。`update e i x` 只改第 i 个变元。存在一支的从 A 回到 B 就是把 `closed` 给的见证代进归纳假设：

```lean
| ex i p ih =>
    · intro h
      rcases closed p e i he h with ⟨x, hxB, hxA⟩
      have he' : envIn B (update e i x) := envIn_update he hxB
      exact ⟨x, hxB, (ih (update e i x) he').2 hxA⟩
```

另一方向不需要 `closed`：B 里的见证按 `sub` 已经是 A 的元素。

Coq 把同一个双条件写成归纳。存在从 B 到 A 的那一支是：

```coq
+ intros [x [HxB Hx]].
  exists x. split.
  * apply Hsub. exact HxB.
  * apply IHp. apply envIn_update; assumption. exact Hx.
```

Agda 不产生经典的当且仅当，而产生一对函数。存在公式的两支是：

```agda
tarski A B sub closed (ex i p) e he =
  (λ h → let x = proj₁ h
             hx = proj₂ h
         in x , sub (proj₁ hx) ,
            proj₁ (tarski A B sub closed p (update e i x)
                     (envIn-update {B = B} {e = e} {i = i} {x = x} he (proj₁ hx)))
                  (proj₂ hx)) ,
  (λ h → let w = closed p e i he h
             x = proj₁ w
             hx = proj₂ w
         in x , proj₁ hx ,
            proj₂ (tarski A B sub closed p (update e i x)
                     (envIn-update {B = B} {e = e} {i = i} {x = x} he (proj₁ hx)))
                  (proj₂ hx))
```

前一支把 B 的见证经 `sub` 送进 A。后一支先用 `closed` 取见证，再把 A 上的矩阵值经归纳假设送回 B。`envIn-update` 要显式标出载体 B，否则更新后的环境不知道自己还在哪个谓词里。

Isabelle 用集合论里的公式类型 `fm`，满足关系是取值 0/1 的集合函数 `sat`。存在量词把见证接到环境表头，所以只有一个 `fex(p)`，没有变元下标。定理是：

```isabelle
theorem tarski_agreement:
  assumes sub: "B ⊆ A"
    and closed: "⋀p env. ⟦p ∈ fm; env ∈ list(B); strue(A,fex(p),env)⟧
                   ⟹ ∃x∈B. strue(A,p,Cons(x,env))"
    and pt: "p ∈ fm"
  shows "∀env∈list(B). strue(B,p,env) ⟷ strue(A,p,env)"
```

`list_mono` 把 `list(B)` 的环境送进 `list(A)`。归纳假设用 `bspec` 从全称里取出。从 B 到 A 时，B 里的见证经 `subsetD` 进入 A，再套 `strue_ex_iff`。从 A 到 B 时直接调用 `closed`。

## 85.7 斯科伦函数与勒文海姆–斯科伦

> **定义 1.38** h: Aⁿ → A 是 φ(v₁,…,vₙ, vₙ₊₁) 的斯科伦函数，当且仅当对所有 a₁,…,aₙ ∈ A，只要存在 a ∈ A 使 𝔄 ⊨ φ[a₁,…,aₙ, a]，就有 𝔄 ⊨ φ[a₁,…,aₙ, h(a₁,…,aₙ)]。

选择公理为每个公式挑出一个斯科伦函数：在非空的见证集合里选一个元素；没有见证时随便送一个固定元素。

> **定义 1.39** 一组斯科伦函数叫做完备的，当且仅当它对函数复合封闭。

给定完备的斯科伦函数组，任何一个非空 X ⊆ A 的斯科伦闭包 SH(X) 是把 X 按这些函数做下去得到的最小集合。定理 1.22 说 SH(X) ≺ 𝔄：任何一个存在公式的见证都被对应的斯科伦函数算进了闭包。

> **定理 1.23（勒文海姆–斯科伦）** 可数语言的理论若有无穷模型，则有可数的初等子模型。

设 𝔄 无穷，语言可数。公式可数，斯科伦函数可数。取一个可数无穷的 X ⊆ A。从 X 出发，逐次把可数个函数在已有元素上的值加进来。每一步仍可数，ω 步的并 SH(X) 可数，并且 SH(X) ≺ 𝔄。限制到 SH(X) 上的解释就是所要的可数初等子模型。它满足 𝔄 满足的每一条语句，因此是 Th(𝔄) 的可数模型。

这就是斯科伦悖论的来源。若 (H_κ, ∈) ⊨ ZFC 且 κ 不可达，定理 1.23 给出可数的 X ≺ H_κ。X 满足“实数不可数”。可数性是外部的：从 V 看 X 可数，从 X 看那个双射不是 X 的元素。

## 85.8 初等子模型的无界闭集

把定理 1.23 用到一串函数上，得到的可数初等子模型构成闭无界集。

> **定理 1.24** 设 ⟨Fₙ | n < ω⟩ 是可数个函数符号，κ ≥ ω₁ 正则。对每个 n，fₙ: κ^{kₙ} → κ 解释 Fₙ。令 ℋ = (κ, ∈, ⟨fₙ⟩ₙ<ω)，
>
> 𝒞 = {M ∈ [κ]^ω | M ≺ ℋ}。
>
> 则 𝒞 是 κ 上的无界闭集。

先把 ℋ 按定义 1.38 扩充成带完备斯科伦函数的 ℋ*。语言仍可数。

无界。任给可数 X ⊆ κ，令 M = SH(X)。则 X ⊆ M，M 可数，并且 M ≺ ℋ*，因此 M ≺ ℋ，M ∈ 𝒞。

封闭。设 ⟨Mₙ | n < ω⟩ 是 𝒞 中的递增链，M = ⋃ₙ Mₙ。M 可数。要证 M ≺ ℋ*。用定理 1.22。参数 a₁,…,aₘ ∈ M 落在某个 Mₙ 里。若 ℋ* ⊨ ∃y φ(a₁,…,aₘ, y)，则 Mₙ ≺ ℋ* 把见证选进 Mₙ，因而选进 M。

κ 本身要够大，才放得下这些函数的值。函数的值域在 κ 里，所以论域写成 κ 是合适的：这里的元素是序数，函数是序数上的运算，不需要把任意集合编码进论域。下一节的例子要谈任意可数集合和满射，论域就换成 H_κ。

## 85.9 可数初等子模型里的 ω 与 ω₁

> **例 1.6** 设 κ ≥ ω₂ 正则，X ≺ (H_κ, ∈)，X 可数。则
>
> (1) ω ∈ X，ω₁ ∈ X，并且 ω ⊆ X；
> (2) 若 a ∈ X 且 a 可数，则 a ⊆ X；
> (3) α = X ∩ ω₁ 是可数序数，而且是不属于 X 的最小序数；
> (4) (X, ∈) 有唯一的传递化 (M_X, ∈) 和唯一的同构 π: X ≅ M_X。π 在 α 上是恒等，π(ω₁) = α。逆映射 j = π⁻¹: M_X → H_κ 是初等嵌入，临界点是 α，并且 j(α) = ω₁。

论域取 H_κ 而不是序数 κ。证明里要量化的满射是集合，它属于论域的条件正是“传递闭包的势小于 κ”。κ 正则且大于 ω₁ 时，可数集、ω 上的函数、ω₁ 都在 H_κ 里。

(1) 先看 ω。“存在唯一的非零极限序数，它属于其他每一个非零极限序数”在 H_κ 里由 ω 实现，因为 ω < κ。这句话是一阶的：极限、非零都是 Δ₀ 的，唯一性是全称。X ≺ H_κ 把见证 a 选进 X。同一个公式在 H_κ 里只有 ω 这一个解，所以 a = ω，ω ∈ X。

0 是唯一的空集，空集公式在 H_κ 里真，所以 0 ∈ X。若 n ∈ X，n ∪ {n} 由“元素恰好是 n 的元素或 n 自己”定义，见证在 X 里，所以 n+1 ∈ X。归纳得到 ω ⊆ X。

ω₁ 是最小的不可数序数，也就是“非零极限序数，并且每个可数序数都属于它”的最小解。可数性能在 H_κ 里写出来：存在从 ω 到该序数的双射，而这个双射属于 H_κ。X 里取出的见证在 H_κ 里仍满足这句话，所以它就是 ω₁。

(2) a ∈ X 可数。存在满射 f: ω → a。f ∈ H_κ。公式 ∃f (f 是函数 ∧ dom(f) = ω ∧ ran(f) = a) 在 H_κ 里真，参数 ω 和 a 都在 X 里，所以 X 里有这样一个 f。对每个 n ∈ ω ⊆ X，∃y∈a (y = f(n)) 在 X 里有见证，所以 f(n) ∈ X。于是 a = ran(f) ⊆ X。

(3) 由 (2)，β ∈ X ∩ ω₁ 时 β 可数，所以 β ⊆ X，从而 β ⊆ X ∩ ω₁。X ∩ ω₁ 传递，因而是序数。X 可数，所以 α = X ∩ ω₁ 可数，α < ω₁。α ∉ X：否则 α+1 ∈ X，而 α+1 仍可数，α+1 ⊆ X，于是 α+1 ⊆ α。比 α 小的序数都在 X 里，所以 α 是不属于 X 的最小序数。

(4) H_κ 满足外延公理，X 初等，所以 (X, ∈) 外延。∈ 在 X 上良基，因为 ∈ 在 V 上良基。第 84 章的传递化定理给出唯一的传递集合 M_X 和唯一的双射 π: X → M_X，保持 ∈。α 的元素都在 X 里，而且 π 在属于关系的下方先被定义，所以 π ↾ α = id，从而 π(ω₁) = π``(X ∩ ω₁) = α。j = π⁻¹ 把 M_X 嵌回 H_κ。它在 α 以下是恒等，j(α) = ω₁ > α，所以临界点是 α。初等性跟着同构和 X ≺ H_κ 走。

临界点是后面所有初等嵌入的原型：j 移动的最小序数，以及它被送到的那个更大的序数。这里最小的移动是 α ↦ ω₁。

## 85.10 可定义集

> **定义 1.40** 设 𝔄 = (A, I)，n ≥ 1。D ⊆ Aⁿ 在 𝔄 上可定义，当且仅当存在 m、公式 φ(v₁,…,vₙ, vₙ₊₁,…,vₙ₊ₘ) 和参数 b₁,…,bₘ ∈ A，使
>
> D = {(a₁,…,aₙ) ∈ Aⁿ | 𝔄 ⊨ φ[a₁,…,aₙ, b₁,…,bₘ]}。
>
> m = 0 时叫无参数可定义。参数都来自 X ⊆ A 时，叫由 X 的参数可定义。

“𝔄 ⊨ φ[…]”是集合论语言里的一句解析表达式。分离公理把满足它的 n 元组收成集合 D。固定 n 和 X，

Defⁿ(X) = {D ⊆ Aⁿ | D 由 X 的参数可定义}

对并、交、相对补封闭，因为析取、合取、否定还是一阶公式。

> **定理 1.25（塔尔斯基准则的可定义形式）** B ⊆ A 非空。B 是初等子结构的论域，当且仅当每个非空的 D ∈ Def¹(B) 都满足 D ∩ B ≠ ∅。

这是定理 1.22 的改写。∃x φ(a₁,…,aₙ, x) 在 A 里有解，就是参数 a₁,…,aₙ ∈ B 定义的一元集合 D 非空。D ∩ B ≠ ∅ 就是有一个解落在 B 里。

代数结构上的可定义集是模型论的另一大块，这里不用。后面用到的可定义性都是 ∈ 语言里的，偶尔按定义 1.35 加几个被定义出来的符号。

定义性扩充在模型上有唯一的扩展。设 𝔄 = (A, I) ⊨ T，L₁ 是定义性扩充。新谓词 P 的解释是定义式在 𝔄 里割出的那个子集，新函数 F 的解释是定义式割出的那个函数。存在性和唯一性在 𝔄 里成立，因为它们是 T 的定理。得到的 (A, J) 满足扩充后的理论，并且 J 在旧符号上与 I 相同。反过来，忘掉新符号就回到 𝔄。语言之间也一样：L₁ ⊆ L₂ 时，把 L₂ 结构限制到 L₁ 的符号上，得到裁减；论域不变。

## 85.11 传递集合满足哪些公理

> **例 1.7** 若 M 是非空传递集合，则外延公理在 (M, ∈) 中成立。这里 ∈ 解释成 {(a, b) ∈ M × M | a ∈ b}。

外延公理是

∀v₁∀v₂ (v₁ = v₂ ↔ ∀v₃ (v₃ ∈ v₁ ↔ v₃ ∈ v₂))。

在 M 里，这是：对 a, b ∈ M，

a = b 当且仅当 ∀x∈M (x ∈ a ↔ x ∈ b)。

左到右不用传递性。右到左：设 M 里 a 与 b 的元素相同。任取宇宙里的 x ∈ a。a ∈ M 且 M 传递，所以 x ∈ M，于是 x ∈ b。对称地 b ⊆ a。外延公理在 V 里给出 a = b。

不传递时，右边只看见 M 内部的元素，两个集合可以在外面不同、在里面看起来一样。令 a = {∅}，b = {{{∅}}}，M = {a, b}。∅ 属于 a 却不属于 M，{a} 属于 b 却不属于 M。在 M 内部，a 和 b 都没有元素，所以 ∀x∈M (x ∈ a ↔ x ∈ b) 成立，但 a ≠ b。

Lean 把这件事写成：外层宇宙有外延公理 `ext`，载体有传递性 `tr`，则相对化的元素相同等价于相等。

```lean
theorem relativized_extensionality
    (mem : S → S → Prop) (M : S → Prop)
    (ext : ∀ {a b : S}, (∀ x, mem x a ↔ mem x b) → a = b)
    (tr : ∀ {x y}, M x → mem y x → M y)
    {a b : S} (ha : M a) (hb : M b) :
    (∀ x, M x → (mem x a ↔ mem x b)) ↔ a = b
```

证明的右到左先用 `tr` 把 a 的元素拉回 M，再用假设把属于 a 换成属于 b，最后调用 `ext`。Coq 的 `relativized_extensionality` 和 Agda 的 `trans-ext` 是同一句话。Isabelle 在 ZF 里直接用 `Transset`：

```isabelle
lemma transitive_relativized_extensionality:
  assumes tr: "Transset(M)" and aM: "a ∈ M" and bM: "b ∈ M"
  shows "(∀x∈M. x ∈ a ⟷ x ∈ b) ⟷ a = b"
```

`Transset_def` 给出 a ⊆ M。于是 a 的元素都在 M 里，假设把它们送进 b，`equalityI` 得到 a = b。

下面的闭包条件把例 1.7 推广到其余公理。记 ZF₀ 为 ZF 去掉幂集和基础，ZF₁ 为 ZF 去掉基础。W 是类。

> **引理 1.16（ZF₀）**
>
> (1) 若 ∀a∈W ∀y∈a (y ∈ W)，即 W 传递，则外延公理在 W 中成立。
> (2) 若 W 的每个元素都落在某个 V_α 里，则基础公理在 W 中成立。
> (3) 若 ∀a∈W ∀y (y ⊆ a → y ∈ W)，则分离在 W 中成立。
> (4) 若 ∀a∈W ∀b∈W ({a, b} ∈ W)，则配对在 W 中成立。
> (5) 若 ∀a∈W (⋃a ∈ W)，并且 W 传递，则并集公理在 W 中成立。
> (6) 若每个函数 f，只要 dom(f) ∈ W 且 ran(f) ⊆ W，就有 ran(f) ∈ W，并且 W 传递，则替换在 W 中成立。

(1) 就是例 1.7。(2) 用秩。设 a ∈ W 且存在 b ∈ W ∩ a。令 β 是 {ρ(x) | x ∈ a ∩ W} 的最小元，取 ρ(c) = β 的 c ∈ a ∩ W。若还有 y ∈ c ∩ a ∩ W，则 ρ(y) < ρ(c)，与最小性矛盾。c 就是基础公理在 W 里要的那个 ∈ 极小元。这一步用 V 里的基础来比较秩；W 自己的基础是结论，不是前提。(3) 对 a ∈ W 和公式 φ，令 b = {x ∈ a | φ^W}。b ⊆ a，闭包把 b 送进 W。定理 1.19 保证 φ^W 与“在 W 的满足关系下 φ 成立”是同一件事。(4)(5) 把配对公理、并集公理在 V 里给出的那个集合用闭包送回 W。并集的见证元素要靠传递性留在 W 里。(6) 公式定义的函数类在 a 上的限制是一个函数 f，ran(f) ⊆ W 由“每个值都在 W 里”给出，闭包把 ran(f) 送进 W。

> **引理 1.17（ZF₁）** 设 W 传递，是真类或非空集合。
>
> (1) 若 ∀a∈W (𝒫(a) ∩ W ∈ W)，则幂集公理在 W 中成立。
> (2) 若幂集和分离都在 W 中成立，则 ∀a∈W (𝒫(a) ∩ W ∈ W)。

“x ⊆ a”是 Δ₀ 的。定理 1.19 说它在 W 里和在 V 里一致。因此幂集公理在 W 里说的就是：存在 b ∈ W，使 W 的元素中那些含于 a 的，恰好是 b 的元素。令 b = 𝒫(a) ∩ W，(1) 的假设把 b 放进 W。(2) 先用 W 内部的幂集拿到一个够大的 b ∈ W，再用分离把 {x ∈ b | x ⊆ a} 切出来，它就是 𝒫(a) ∩ W。

## 85.12 V_α 与 H_κ

> **例 1.8** 设 α ≥ ω 是极限序数。
>
> (1) V_α 满足外延、空集、幂集、分离、配对、并集、基础。
> (2) V_ω 还满足替换，并且每个集合都与某个自然数等势，因此 V_ω ⊨ ¬Inf。
> (3) V_α ⊨ Inf 当且仅当 α > ω。
> (4) 若有 γ < α 和带 V_α 中参数的公式，它定义了一个以 γ 为定义域、值域在 α 中无界的函数，则这条公式是 V_α 里替换的反例。ω+ω 上的 n ↦ ω+n，以及 ℵ_ω 上的 n ↦ ℵ_n，都是这种公式。
> (5) 若 V ⊨ AC，则 V_α ⊨ AC。

V_α 传递，而且 x ∈ V_α、y ⊆ x 时 ρ(y) ≤ ρ(x) < α，α 是极限，所以 y ∈ V_α。引理 1.16 的 (1)(3)(4)(5) 和引理 1.17 的幂集闭包都成立：{a, b} 的秩是 max(ρ(a), ρ(b))+1，⋃a 的秩不超过 ρ(a)，𝒫(a) 的秩是 ρ(a)+1，极限序数对这些后继封闭。基础是引理 1.16(2)，因为 V_α 的元素本来就在某个更低的 V_β 里。空集在 V_1 里。

(3) 每个自然数 n 属于 V_{n+1}。它们的并 ω 属于 V_{ω+1}。α > ω 且 α 是极限时 ω+1 < α，所以 ω ∈ V_α，无穷公理成立。α = ω 时 ρ(ω) = ω，ω ∉ V_ω。

(2) V_ω 的每个元素都是有限的，而且元素的元素仍有限。一条函数式公式在有限集合 a ∈ V_ω 上的值只有有限个，每个值的秩是自然数，有限个自然数有最大值 n，值域含于 V_n，因而值域属于 V_{n+1} ⊆ V_ω。这就是替换。每个这样的集合与一个自然数等势。无穷公理失败，已在 (3)。

(4) 以 α = ω+ω 为例。公式 φ(n, y) 说 y = ω+n。定义域 ω ∈ V_α。值 y = ω+n 的秩是 ω+n < α，所以每个值都在 V_α 里。值域 {ω+n | n < ω} 的秩是 ω+ω，不属于 V_α。替换要求这个值域是 V_α 的元素，因此失败。ℵ_ω 上 n ↦ ℵ_n 同样：每个 ℵ_n 属于 V_{ℵ_ω}，值域的并是 ℵ_ω，值域本身的秩不低于 ℵ_ω。任意一个共尾序列若能由 V_α 的参数定义出来，都给出同样的反例。序列本身的秩往往等于 α，进不了 V_α，所以不能直接拿它当参数；要有一条在模型内部写得出来的定义。

(5) 选择公理是“每个非空集族有选择函数”。集族属于 V_α 时，V 里的选择函数是它的元素的一组挑选。这些元素的秩低于 α，选择函数作为有序对的集合，秩仍低于极限序数 α，所以选择函数属于 V_α。

> **例 1.9** 设 κ 是不可数正则基数。
>
> (1) H_κ ⊨ ZF 减去幂集。这里 H_κ = {x | |TC(x)| < κ}。
> (2) 下列三条等价：κ 不可达；H_κ = V_κ；H_κ ⊨ ZF。
> (3) 若 V ⊨ AC，则 H_κ ⊨ AC。

H_κ 传递：y ∈ x ∈ H_κ 时 TC(y) ⊆ TC(x)。它也对子集封闭，对配对、并封闭，因为少于 κ 个势小于 κ 的集合，在 κ 正则时并起来的势仍小于 κ。ω ∈ H_κ。引理 1.16 给出外延、基础、分离、配对、并、替换、无穷。

幂集看 λ < κ。λ 的每个子集的传递闭包的势不超过 |λ| + ℵ₀ < κ，所以 𝒫(λ) 的元素全都在 H_κ 里，𝒫(λ) ∩ H_κ = 𝒫(λ)。|𝒫(λ)| = 2^|λ|。若某个 λ < κ 使 2^|λ| ≥ κ，则 𝒫(λ) ∉ H_κ，引理 1.17 说幂集公理在 H_κ 里失败。若 κ 是强极限，则每个这样的幂集的势仍小于 κ，幂集属于 H_κ，幂集公理成立。

不可达就是不可数、正则、强极限。这时每个秩小于 κ 的集合都是遗传地小于 κ 的，反过来遗传地小于 κ 的集合秩也小于 κ，所以 H_κ = V_κ。V_κ 在 κ 不可达时满足替换：一条函数在 V_κ 里的定义域的势小于 κ，值的秩小于 κ，κ 正则，值域的秩之并仍小于 κ。于是 H_κ ⊨ ZF。反过来 H_κ ⊨ ZF 已包含幂集，所以 κ 是强极限；正则性来自例 1.9 的假设，或者从 H_κ = V_κ 且 V_κ 对小于 κ 的并封闭看出来。三条因此等价。

(3) 与例 1.8(5) 相同：集族属于 H_κ 时可以选择函数也属于 H_κ，因为它的传递闭包不会把势抬到 κ。

## 85.13 相对化解释

集合大小的结构可以用定义 1.37 谈满足。真类不行：{(φ, a) | V ⊨ φ[a]} 若是一条公式能定义的类，塔尔斯基的不可定义定理就给出矛盾。第 84 章已经把这件事说成“V ⊨ φ 不是 ∈ 公式”。这里用它得到第二不完全性的一个直接推论。

> **定理 1.27** 设 T 是 ZF 或 ZFC。若 T 一致，则 T 不证明 Con(T)。

假如满足关系能在 ZFC 里定义，ZFC 的公理都在 V 中成立，就会得到 V ⊨ ZFC，再由定理 1.20 得到 ZFC ⊢ Con(ZFC)，与定理 1.27 矛盾。所以不可定义不是技术上的不方便，而是一致性所要求的。

真类上仍可以做语法上的相对化。φ^W 是把量词限制到 W 的那个公式，它本身是一条 ∈ 公式，不需要“W ⊨ φ”这个满足关系作为对象。

> **定义 1.41（相对解释）** 设 T 是 ∈ 语言的理论，L 由有限个常元、函数符号、谓词组成。W 是真类，由公式 ψ(v) 定义，并且 T ⊢ ∃v ψ(v)。再给每个常元一个 T 能证明唯一存在于 W 的定义，给每个谓词一个外延含于 W 的相应幂的定义，给每个函数一个 T 能证明的、取值唯一且落在 W 里的定义。这些定义合在一起，叫做 L 在 T 上的一个相对解释 𝔐。

项和公式沿着 𝔐 翻译：函数符号和常元换成它们的定义式，量词 ∀x、∃x 换成 ∀x∈W、∃x∈W，谓词换成定义它的 ∈ 公式。翻译的结果是一条 ∈ 公式，写成 φ^𝔐。

> **引理 1.18** 若 𝔐 是 L 在 T 上的相对解释，并且 T 证明了语句 θ₁,…,θₖ 的翻译，则 T 证明 (θ₁ ∧ … ∧ θₖ → φ) 的翻译，只要原来的语言能从 θ₁,…,θₖ 证明 φ。

对证明长度归纳。逻辑推理在翻译之后仍是逻辑推理，因为量词限制到同一个 W，肯定前件和概括规则都保形。

> **推论 1.4** 若 T 证明 L 理论 T′ 的每条公理的翻译，则在元数学里有 Con(T) → Con(T′)。

若 T′ 不一致，则有有限条公理推出矛盾。引理 1.18 把这段证明翻译成 T 的一段证明，T 也不一致。

> **例 1.10** 设 ZF₁ 是 ZF 去掉基础公理。令 V* = ⋃_α V_α，也就是有秩的那些集合构成的类。则
>
> (1) ZF₁ ⊢ (ZF)^{V*}；
> (2) ⊢ Con(ZF₁) → Con(ZF)。

V_α 的递归定义只用幂集、替换和序数归纳，不用基础。所以 ZF₁ 仍能定义 V*。引理 1.16 和 1.17 的闭包在 V* 上成立：它传递，对配对、并、幂集、分离、替换封闭。基础的相对化要用秩的最小元。设 a ∈ V* 非空，a 的元素的秩构成一个非空序数集，取最小秩的那个元素 c。c 的任何元素秩更小，所以 c ∩ a = ∅。定理 1.19 把这个 Δ₀ 断言从 V 搬到 V*。于是 ZF 的全部公理都在 V* 上被 ZF₁ 证明。(2) 是推论 1.4。

这是相对一致性的第一个完整样品：去掉基础公理并不会更危险，因为有秩部分已经是原来理论的模型。

## 85.14 镜像原理

Δ₀ 公式对每个传递类都绝对。任意公式没有这么好，但总能找到一个传递集合，使这条公式和它的相对化重合。

> **定义 1.42** φ(v₁,…,vₙ) 是公式，M 是非空集合。M 镜像 φ，写成 M ≺_φ V，是指
>
> ∀a₁…∀aₙ ∈ M (φ^M(a₁,…,aₙ) ↔ φ(a₁,…,aₙ))。

> **定义 1.43** Z 是 ZF 去掉替换。ZF/𝒫 是 ZF 去掉幂集。

> **引理 1.19** 设 T 是 Z 或 ZF/𝒫，M 传递且 M ⊨ T。若 T 证明 ∀v (φ ↔ ψ)，则
>
> V ⊨ (M ≺_φ V ↔ M ≺_ψ V)。

T 的定理在 M 里成立，所以 M 里 φ 与 ψ 互换。V 里 φ 与 ψ 互换是因为 T 的公理在 V 里成立。两边一起换，镜像关系保持。因此证明镜像时可以把全称量词写成 ¬∃¬，只处理存在型公式。

> **引理 1.20** 设 φ(v₁,…,vₙ, vₙ₊₁) 是公式，M₀ 是任意集合。则存在极限序数 α，使
>
> (a) M₀ ⊆ V_α；
> (b) 对任意 a₁,…,aₙ ∈ V_α，若 ∃y φ(a₁,…,aₙ, y)，则 ∃y∈V_α φ(a₁,…,aₙ, y)。
>
> 有选择公理时，还可以取到 M ⊆ V_α，M₀ ⊆ M，|M| ≤ |M₀| · ℵ₀，并且 (b) 对 M 成立。有限条公式可以同时被同一个 α 或同一个 M 照应。

对参数 a = (a₁,…,aₙ)，令 C(a) = {y | φ(a, y)}，D(a) 是 C(a) 中秩最小的那些元素，E(a) = D(a)。E 是依定义引进的函数符号：有见证时，E(a) 里的元素仍是见证，而且秩最小。令

α₀ = ρ(M₀) + 1，

M_{i+1} = V_{αᵢ} ∪ ⋃ {E(a) | a ∈ V_{αᵢ}ⁿ}，

α_{i+1} = ρ(M_{i+1}) + 1，

α = ⋃_{i<ω} αᵢ。

α 是极限序数。M₀ ⊆ V_{α₀} ⊆ V_α。若 a ∈ V_αⁿ 且存在见证，则 a 已经落在某个 V_{αᵢ} 里，秩最小的见证被放进 M_{i+1}，因而落在 V_α。这就是 (a)(b)。

有选择时，从 E(a) 里只挑一个元素 h(a)，不把整个 D(a) 收进来。令 N₀ = M₀，N_{i+1} = Nᵢ ∪ {h(a) | a ∈ Nᵢⁿ}，N = ⋃_{i<ω} Nᵢ。每一步的势乘一个 ℵ₀，可数并之后 |N| ≤ |M₀| · ℵ₀。N 对 h 封闭，定理 1.22 的见证条件对这条公式成立。

> **定理 1.28（镜像原理）** 对每个公式 φ，
>
> ZF ⊢ ∃M (M 传递 ∧ M ≠ ∅ ∧ M ≺_φ V)，
>
> 并且存在极限序数 α 使 V_α ≺_φ V。有选择公理时，还可以要求 |M| = ℵ₀。

把 φ 里的全称换成 ¬∃¬。设 φ₀,…,φₖ 是 φ 的全部子公式。引理 1.20 给一个 V_α，同时为每一条存在型子公式准备见证。然后对子公式做归纳：原子公式绝对；布尔组合跟着归纳假设；存在公式的见证被 (b) 收进 V_α，矩阵再由归纳假设在 V_α 和 V 之间对上。于是 V_α ≺_φ V。传递集合 M 的情形相同，把 V_α 换成引理 1.20 里的 N 的传递闭包，或直接对 N 使用定理 1.22。可数性在 M₀ 取可数、再乘 ℵ₀ 时得到。

> **推论 1.5**
>
> (a) 若 φ 是在 V 中成立的语句，则 φ 有一个集合模型；若再假设选择公理，则有可数模型。
> (b) ZF 不能有限公理化。

(a) 是定理 1.28：V ⊨ φ 时，镜像给出 M ⊨ φ。

(b) 设 ZF 等价于有限条公理 θ₁,…,θₖ 的合取 θ。θ 是一个语句，ZF ⊢ θ，所以 V ⊨ θ。由 (a)，ZF 证明存在集合 M 使 M ⊨ θ。定理 1.20 把集合模型变成一致性，于是 ZF ⊢ Con(ZF)。这与定理 1.27 矛盾。所以不存在这样的有限公理 θ₁,…,θₖ。

镜像原理的证明里实际用到的是塔尔斯基准则的有限形式。

> **定义 1.44** 公式列表 ⟨φ₀,…,φ_{m-1}⟩ 罗列了全部子公式，当且仅当每个 φᵢ 的子公式都在列表里，并且列表里的公式都不使用全称量词 ∀。

> **引理 1.21** 设 ⟨φ₀,…,φ_{m-1}⟩ 是这样一个列表，∅ ≠ U ⊆ W 是两个类。则下列两条等价。
>
> (1) 对每个 i < m，U ≺_{φᵢ} W。
> (2) 对每条存在型公式 ∃vₙ₊₁ φᵢ(v₁,…,vₙ, vₙ₊₁)，以及 U 中的参数 a，
>
> φᵢ^W(a) 蕴涵存在 b ∈ U 使 φᵢ^W(a, b)。

(1) 推出 (2)：存在句在 W 里真，就在 U 里真，U 给出见证，再搬回 W。(2) 推出 (1)：对列表做归纳。存在步骤里，W 的见证被 (2) 换成 U 的见证，矩阵由归纳假设对齐。这就是定理 1.22，只是公式只查这有限张表，并且外层结构是类 W 的相对化，不是集合结构上的满足关系。

> **定理 1.29（广义镜像）** 设 ⟨φ₀,…,φ_{k-1}⟩ 是公式列表，W 是非空类，⟨U_α⟩ 是集合的递增连续链，并且 W = ⋃_α U_α。则
>
> ∀α ∃β (α < β ∧ β 是极限序数 ∧ U_β ≠ ∅ ∧ U_β ≺_{φ₀,…,φ_{k-1}} W)。

对每条存在型公式 φᵢ(a)，若 W 里有见证，令 Fᵢ(a) 是最小的 ξ 使 U_ξ 已经含有一个见证；否则令 Fᵢ(a) = 0。令

Gᵢ(α) = sup {Fᵢ(a) | a ∈ U_αⁿ}，

E(α) = max{α+1, max_{i<k} Gᵢ(α)}。

从任意 α 出发，取 β₀ > α 使 U_{β₀} 非空，β_{n+1} = E(βₙ)，β = supₙ βₙ。β 是极限序数。U_β 对这有限张表的见证封闭：参数落在某个 U_{βₙ} 里，见证的层次被 E 推到 βₙ₊₁ < β。引理 1.21 给出 U_β 与 W 对列表里的每条公式镜像。

> **定理 1.30（ZFC）** 设 κ 不可数正则，⟨U_α | α ≤ κ⟩ 递增、在极限处连续，U_κ = ⋃_{α<κ} U_α，并且每个 α < κ 都有 |U_α| < κ。则
>
> ∀α < κ ∃β (α < β < κ ∧ β 是极限序数 ∧ U_β ≺ U_κ)，
>
> 这里的 ≺ 是对事先固定的那有限张公式列表而言的。这样的 β 构成 κ 的无界闭集。

证明与定理 1.29 相同，只是 E(α) 的值仍小于 κ：每个 U_α 的势小于 κ，有限个公式，κ 正则，sup 抬不出去。闭性来自定义 1.21 的链：一串这样的 β 的并仍对见证封闭。

> **推论 1.6** 若 κ 不可达，则对每一张有限公式列表，
>
> {α < κ | α 是极限序数且 V_α 与 V_κ 对这张列表镜像}
>
> 是 κ 的无界闭集。

κ 不可达时 V_κ = H_κ ⊨ ZFC，而且 ⟨V_α | α < κ⟩ 满足定理 1.30 的势条件：α < κ 时 |V_α| < κ。把 W 取成 V_κ、U_α 取成 V_α 即可。一张列表只反射这有限条公式。把所有公式同时反射成 V_α ≺ V_κ 的单个 α，会要求 α 自己是不可达的，从而在最小的不可达基数下面做不到。固定复杂度、固定有限张表，闭无界集是有的。

## 85.15 机器上的三个有限样品

四个证明助手证的是例 1.7 和定理 1.22，上面已经引用过。Python、Julia、Prolog 在有限集合上把三个现象算出来：不传递则外延失败，斯科伦闭包把薄子集补成整段序数，一条存在公式的见证在某一层 V_n 里关住。

外延检查只看载体内部：

```python
def same_inside(m, a, b):
    return {z for z in m if z in a} == {z for z in m if z in b}

def extensional(m):
    return all(same_inside(m, a, b) == (a == b) for a in m for b in m)
```

令 a = {∅}，b = {{{∅}}}，M = {a, b}。a 的元素 ∅ 和 b 的元素 {{∅}} 都不在 M 里，所以 `same_inside` 认为 a 和 b 在 M 中元素相同，`extensional` 返回假，`transitive` 也返回假。V₄ 有 16 个元素，传递，外延检查通过。这就是例 1.7 的正反两面。

后继见证是定理 1.22 里的那一个存在公式。在 0,…,5 上，y 是 x 在 z 之下的后继，就是 y = x+1 且 y < z。

```python
def successor_witness(x, z, universe):
    for y in universe:
        if x < y < z and all(not (x < w < y) for w in universe):
            return y
    return None
```

子集 {0, 2, 4, 5} 不封闭：0 与 2 之间的后继是 1，1 不在子集里。从 {0, 5} 出发把见证不断加进去：

```python
def skolem_hull(seed, universe):
    hull = set(seed)
    changed = True
    while changed:
        changed = False
        for x in list(hull):
            for z in list(hull):
                y = successor_witness(x, z, universe)
                if y is not None and y not in hull:
                    hull.add(y)
                    changed = True
    return hull
```

闭包等于 {0, 1, 2, 3, 4, 5}，也就是整段论域。整段对后继见证封闭，定理 1.22 说它与自己初等。Julia 用同样的循环得到 `SH({0,5}) = [0, 1, 2, 3, 4, 5]`。Prolog 的 `hull([0,5], H)` 把缺少的后继一次次接到表头，排序后也是 0..5；`Thin = [0,2,4,5]` 既不传递，也不满足 `reflects`。

引理 1.20 的一个公式样品是 ∃y (y = {x})。V₂ 的元素是 ∅ 和 {∅}，见证分别是 {∅} 和 {{∅}}，秩是 1 和 2，都落在 V₃ 里。Python 把这件事写成

```python
witnesses = {frozenset([x]) for x in v2}
witness_ranks = {rank(y) for y in witnesses}
assert witness_ranks <= {1, 2}
assert all(y in levels[3] for y in witnesses)
```

一条存在公式的秩最小见证在有限步里进入更高一层。定理 1.28 是同一构造对任意公式、对 ω 步极限序数做出来的结果。

## 85.16 这一章留下了什么

依定义扩充是保守的。Δ₀ 公式在传递类上绝对，所以外延、配对、并、幂集这些 Δ₀ 形状的公理能否在一个类里成立，完全由这个类是否对相应的集合运算封闭来决定。无界量词改由塔尔斯基准则负责：见证若能选在子模型里，子模型就初等。可数语言的无穷模型因此有可数初等子模型，可数初等子模型在正则基数上构成无界闭集。可数的 X ≺ H_κ 含有 ω 和 ω₁，含有自己的全部可数元素，坍缩之后以 X ∩ ω₁ 为临界点嵌入回去。

镜像原理把任意一条公式反射到某个传递集合、某个 V_α，有选择时还可以反射到可数模型。ZF 因此不能有限公理化。广义镜像把同一构造做成闭无界的反射点；在不可达基数下面，每一张有限公式列表都在一个闭无界集上被 V_α 反射到 V_κ。

相对解释把这些模型翻译回一致性语句。去掉基础公理的 ZF₁ 把全套 ZF 解释进有秩集类，所以 Con(ZF₁) 推出 Con(ZF)。下一章把同一套模型分析用到谢旯的共尾可能性上：基数不等式不再只靠组合，也靠初等子模型和它们的临界点。
