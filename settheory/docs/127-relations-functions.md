# 127 · 关系与函数

> 逻辑主义的论点分为两个部分加以讨论：（1）数学概念能通过明确的定义
> 从逻辑概念中导出。（2）数学定理能通过纯粹的逻辑演绎从逻辑公理中
> 推导出来。——鲁道夫·卡尔纳普

本章覆盖书第二章前半（2.1 关系、2.2 函数及习题 2.5.1-2.5.14；PDF
29-43 页）：用集合论的语言把"有序对、关系、函数"这些日常数学概念
重新地基化。一个重要的事实预告：本章**不需要**无穷公理、基础公理

## 127.1 有序对：把"顺序"编码进集合

集合 {a,b} = {b,a} 不分顺序，但有序对 (a,b) ≠ (b,a)（除非 a=b）。
"有序性"的精确要求是刻画条件：

> **命题（书 2.1.3）**　(a,b) = (a',b') 当且仅当 a = a' 且 b = b'。

Kuratowski 的编码把它变成集合论内部的事实：

> **定义（书 2.1.1）**　(a,b) := {{a}, {a,b}}。

证明 2.1.3 是第一次"解剖式"的集合论证，值得完整过。设
{{a},{a,b}} = {{a'},{a',b'}}。**情形 a = b**：左边 = {{a}}，故
{a'} = {a,b} = {a}，得 a = a' 且 b = a = a' = b'。**情形 a ≠ b**：
{a} 是左边的单元素成员，而 {a',b'} 有两个元素，只能 {a} = {a'}，
即 a = a'；于是 {a,b} = {a,b'}，两边再与 a≠b 联立得 b = b'。∎

机器侧，Python 单元（`examples/python/127_relations.py`）把这个刻画
在 4 元宇宙上**全量验证**——16×16 = 256 对有序对两两比较：

```python
def pair(a, b):
    return frozenset([frozenset([a]), frozenset([a, b])])

U = [0, 1, 2, 3]
ok = True
for a, b, ap, bp in product(U, U, U, U):
    same = (pair(a, b) == pair(ap, bp)) == (a == ap and b == bp)
    ok = ok and same
assert ok
assert len({pair(a, b) for a in U for b in U}) == 16   # 4×4 全不重
```

`frozenset` 的相等即外延公理的相等（同元素即同对象），所以这两条
断言就是"定义 2.1.1 实现了命题 2.1.3"的机器证书。三元组有两种
打包（习题 2.5.3）：((a,b),c) 与 (a,(b,c))，都满足三元版的刻画；
同一单元验证了两者都单射、且互不相同（习题 2.5.5 的微观见证：
(X×X)×X ≠ X×(X×X)）。数学中"有序对"的具体编码并不唯一，刻画
条件才是本质——这正是接下来"关系与函数"的通用工作方式：**只要
刻画条件成立，任何实现都同样好**。

## 127.2 关系及其运算

> **定义（书 2.1.6）**　R 是二元关系，若存在集合 X、Y 使
> R ⊆ X×Y。X×Y := {(x,y) | x∈X ∧ y∈Y} 是卡氏积（练习 2.1.5：
> 它是集合——X×Y ⊆ P(P(X∪Y))，由对集、并、幂集公理保证）。

平面坐标系是最好的直觉：整个平面 = x 轴 × y 轴；每条曲线是有序对
的集合。关系的基本运算（书 2.1.8/2.1.11）：

- 定义域 dom(R) = {x | ∃y R(x,y)}；值域 ran(R) = {y | ∃x R(x,y)}；
- 像 R[A] = {y ∈ ran R | ∃x∈A R(x,y)}；逆像 R⁻¹[B]（同一集合，两种
  读法——练习 2.1.13 要求证明它们相等）；
- 逆关系 R⁻¹ = {(x,y) | (y,x) ∈ R}；
- 复合 S∘R = {(x,z) | ∃y ((x,y)∈R ∧ (y,z)∈S)}——先 R 后 S。

n 元组按 (x₁,…,xₙ) = ((x₁,…,x_{n−1}), xₙ) **递归定义**——书在这里
埋下伏笔："我们将在以后专门研究这种定义方法"（第 129 章的递归定理）。

**习题 2.5.1** 是个好的热身：令 A = ⋃(⋃R)，则 (x,y)∈R 蕴涵 x,y∈A。
因为 (x,y) = {{x},{x,y}} ∈ R，故 {x},{x,y} ∈ ⋃R，故 x,y ∈ ⋃⋃R。
——每一个"新造的对象"都要能被定位到已存在的集合里，这是集合论
的卫生习惯（第 143 章的**秩函数**把这个习惯精确化）。

## 127.3 函数：单值的关系

> **定义（书 2.2.1）**　二元关系 f 是函数，若
> (x,y)∈f ∧ (x,z)∈f → y=z（单值性）。f(x)=y、f:X→Y、dom、ran
> 等记法照常。

单值性排除"一对多"——原书的键盘比喻：若敲 a 键有时出 a 有时出
b，这样的电脑令人发疯。函数的外延判定（练习 2.2.3）：f = g 当且
仅当 dom 相同且逐点相等——注意这是**两条公理**的组合：外延公理
（集合相同 ⟺ 元素相同）+ 单值性（逐点相等自动给出元素相同）。

**复合还是函数**（练习 2.2.4），dom(g∘f) = dom f ∩ f⁻¹[dom g]；
**逆未必是函数**——函数可逆当且仅当单射（练习 2.2.6）。三性：

- **单射**（一一）：x₁ ≠ x₂ → f(x₁) ≠ f(x₂)；
- **满射**：ran(f) = Y；
- **双射**：既单又满。

关于逆，习题 2.5.12 的账目值得精确记忆：

- 若 g∘f = id_{dom f}（g 是**左逆**），则 f 单射，且 f⁻¹ = g↾ran f；
- 存在 h 使 f∘h = id_{ran f}（h 是**右逆**）**不**保证 f 可逆——
  常值函数 f:{p,q}→{c} 有右逆 h:{c}→{p}（f∘h = id_{c}），但它
  显然不单。单侧逆的信息是不对称的：左逆约束定义域端（单射），
  右逆只约束值域端（满射的影子）。

Prolog 单元（`examples/prolog/127_relations.pl`）把这笔账演成机器：

```prolog
% 左逆存在 ⟹ 单射：双射 f 与其逆 g，g∘f = id
F = [(0,a),(1,b),(2,c)], G = [(a,0),(b,1),(c,2)],
rcomp(G, F, GF), seteq(GF, [(0,0),(1,1),(2,2)]),
injective(F),
% 右逆不 ⟹ 可逆：常值 f: {p,q}->{c}，h: {c}->{p}，f∘h = id_{c}
Cf = [(p,c),(q,c)], H = [(c,p)],
rcomp(Cf, H, CH), seteq(CH, [(c,c)]),
\+ injective(Cf),
```

**限制与相容**。f↾A = f ∩ (A×V)；g 是 f 的扩张。函数的交仍是函数；
但**并**需要条件（书 2.2.8-2.2.10）：f、g 相容 ⟺ 公共定义域上
取值一致 ⟺ f∪g 是函数；相容系统 F 的 ⋃F 是函数，定义域为
⋃dom。Julia 单元用字典的合并语义演示（`examples/julia/127_relations.jl`）：

```julia
compatible(f, g) = all(f[k] == g[k] for k in intersect(keys(f), keys(g)))
function merge_or_nothing(f, g)
    compatible(f, g) || return nothing
    Dict(pairs(f)..., pairs(g)...)
end
f1 = Dict(0 => 'a', 1 => 'b');  f3 = Dict(1 => 'x')     # 在 1 上冲突
@assert merge_or_nothing(f1, f2) == Dict(0 => 'a', 1 => 'b', 2 => 'c')
@assert isnothing(merge_or_nothing(f1, f3))
```

`merge_or_nothing` 返回 `nothing` 的那一行，就是"f∪g 不是函数"
的可执行形态。这个不起眼的小机制将在第 137 章成为 Zorn 引理应用
的标准姿势（习题 2.5.27 已经预演：Fn(X,Y) 的子族有上确界当且仅当
它是相容系统，且 sup F = ⋃F）。

## 127.4 指标系统、一般卡氏积与 AC 第二形式

> **定义（书 2.2.12/2.2.14）**　以集合为值的函数 {Xᵢ | i∈I} 称为
> 指标系统；一般卡氏积 Πᵢ∈I Xᵢ = {f | f 是 I 上的函数且
> ∀i∈I f(i)∈Xᵢ}；πᵢ(f) = f(i) 是投影。

注意 Π 的元素是**函数**而非有序对——I={1,2} 时 ΠXᵢ 与 X₁×X₂
不是同一个集合（元素形态不同），但存在典范的一一对应（书 2.2.15
注），实践中视为等同。习题 2.5.4 埋着一颗深水炸弹：

> X×Y = ∅ 当且仅当 X=∅ 或 Y=∅。这对两个集合成立。但对一般卡氏积：
> **若 I 是无穷集，Πᵢ∈I Xᵢ = ∅ 当且仅当某个 Xᵢ = ∅，还成立吗？**

方向"某 Xᵢ=∅ → 积空"显然。反方向"处处非空 → 积非空"要求从每个
Xᵢ **同时**取一个元素——这恰是选择公理！在 ZF 内不可证。原书把
问题留在习题里，第 137 章回收。

于是书顺势给出 AC 的第二形式（2.2 节末）：

> **选择公理（第二形式）**　对任意不含空集的非空集合族 F，存在
> 选择函数 f: F → ⋃F 使 f(x) ∈ x。

第 126 章的"两两不交族的选择集"形式与此等价（第 137 章证明）。

**Y^X 与空函数**（书 2.2.11）：X 到 Y 的全体函数 Y^X = {f | f:X→Y}
是集合（习题 2.5.14——不是平凡事！需要对每个 x∈X 的取值用替换
公理，细节见习题提示；机器侧先记账）。边角账：∅ 到任何 Y 恰有
一个函数（空函数 ∅），故 Y^∅ = {∅}；而 X≠∅ 时 ∅^X = ∅——没有
函数能把非空定义域映进空集。Python 单元枚举全部函数核对：

```python
def all_funcs(X, Y):
    return [dict(zip(X, values)) for values in product(Y, repeat=len(X))]

for n, m in ((0, 0), (0, 2), (2, 0), (2, 2), (3, 2)):
    Xs, Ys = list(range(n)), list(range(m))
    assert len(all_funcs(Xs, Ys)) == m ** n
    if n == 0 and m == 2:
        assert all_funcs(Xs, Ys) == [dict()]      # 空函数唯一
```

|Y^X| = |Y|^|X| 的记法在有限情形是算术等式，在无穷情形则成为基数
算术的指数律（第 15、17 章——那里它不再是平凡的）。

## 127.5 像的代数：哪些等式成立，哪些只是包含

习题 2.5.2/2.5.10/2.5.11 的系统账目（并、交、差与像、逆像、复合
的交换性）值得成表记忆。机器侧的完整审计见 Python/Prolog 单元，
这里给出证明纲要与反例：

**成立为等式的**：
- R[A∪B] = R[A]∪R[B]（元素追踪：y ∈ 左边 ⟺ ∃x∈A∪B …）；
- f⁻¹[A∩B] = f⁻¹[A]∩f⁻¹[B]，以及并、差、补版本——**逆像保持
  一切布尔运算**（f⁻¹[A−B] = f⁻¹[A] − f⁻¹[B]）；
- 复合的结合律 (T∘S)∘R = T∘(S∘R)（习题 2.5.8）与复合对并的分配
  （习题 2.5.10(1)(2)）；
- 逆的账（习题 2.5.9）：(R⁻¹)⁻¹ = R、dom(R⁻¹) = ran(R)、
  (S∘R)⁻¹ = R⁻¹∘S⁻¹。

**只成立为单向包含的**：
- R[A∩B] ⊆ R[A]∩R[B]，反向不成立；
- f[A∩B] ⊆ f[A]∩f[B]，反向不成立（f 不单射时）；
- (X∩Y)∘Z ⊆ (X∘Z)∩(Y∘Z)（习题 2.5.10(3)(4)）。

单向包含的**见证**要具体：R 把 0 和 2 都映到 c，A={0,1}、B={1,2}
时 (R[A]∩R[B]) − R[A∩B] = {c}。Python 单元：

```python
Rw = frozenset({(0, 'c'), (1, 'a'), (2, 'c')})        # 0 与 2 同像：交像吃掉 'c'
assert (rimg(Rw, A) & rimg(Rw, B)) - rimg(Rw, A & B) == {'c'}
```

Lean 单元（`examples/lean/Settheory/Ch127Relations.lean`）给出等式版的
完整证明与包含版的见证：

```lean
/-- R[A ∪ B] = R[A] ∪ R[B]（书 2.5.2(1)）：双向。 -/
example (R : α → β → Prop) (A B : Set α) :
    rimage R (A ∪ B) = rimage R A ∪ rimage R B := by
  ext y
  constructor
  · rintro ⟨x, hx | hx, hR⟩
    · exact Or.inl ⟨x, hx, hR⟩
    · exact Or.inr ⟨x, hx, hR⟩
  · rintro (⟨x, hx, hR⟩ | ⟨x, hx, hR⟩)
    · exact ⟨x, Or.inl hx, hR⟩
    · exact ⟨x, Or.inr hx, hR⟩

/-- 逆的复合律（书 2.5.9）：(S∘R)⁻¹ = R⁻¹ ∘ S⁻¹。 -/
example (R : α → β → Prop) (S : β → γ → Prop) :
    flip (R ∘r S) = flip S ∘r flip R := flip_comp
```

`∘r` 是 mathlib 的关系复合（先施左项），`flip` 是逆；`flip_comp`
恰是书 2.5.9 的复合律。单元同时自建 `dom/ran/rimage` 三个定义——
每条定律都落在读者看得见的定义上，而不是藏在库的内部约定里。

**为什么逆像 behave 更好**？直觉：y ∈ f[A] 说的是"**存在**一个
A 中的原像"——存在量词与交运算天然不和（两个"存在"可以来自不同
的原像）；而 x ∈ f⁻¹[A] 说的是"f(x) ∈ A"——单点查询，与布尔
运算完美交换。第 130 章等势的证明会反复用到这条不对称性。

## 127.6 幂和三例与本章其余习题

书 2.2.2 的三个例子是"函数"概念的第一批老朋友：

S₁(n) = 1+…+n = n(n+1)/2；S₂(n) = 1²+…+n² = n(n+1)(2n+1)/6；
S₃(n) = 1³+…+n³ = n²(n+1)²/4 = S₁(n)²（Nicomachus 定理）。

Julia 单元对 n = 0..60 全部精确核对（`sum(k -> k^3, 1:n; init=0)`——
注意 `init=0`：n=0 时空求和在 Julia 里必须显式给初值，这是第 124 章以来反复出现的机器侧边角）；Lean 单元则给出 n=5、n=4 的形式化
判定（`norm_num [Finset.sum_range_succ]`）。

其余习题的要点提示：2.5.6 卡氏积对并交差的分配（逐坐标追踪）；
2.5.7 X×Y ⊆ U×V 且 X×Y≠∅ 则 X⊆U、Y⊆V（非空假设不可少：∅×∅ ⊆
任何东西）；2.5.15-2.5.17 指标系统的德摩根律族（第 142 章滤子的
预演）；2.5.18 h[⋃Xᵢ] = ⋃h[Xᵢ] 且 h⁻¹ 保一切（再次：逆像更好）。

## 本章要点

1. 有序对、关系、函数全部**编码为集合**；刻画条件（而非具体编码）
   才是数学对象的本体。
2. 函数=单值关系；可逆 ⟺ 单射；左逆 ⟹ 单射而右逆不保证可逆。
3. 相容系统的并是函数——Zorn 引理应用的标准姿势在此成型。
4. 一般卡氏积"处处非空 ⟹ 积非空"= 选择公理——无穷首次在习题里
   露出獠牙。
5. 像保并（等式）、保交（单向）；逆像保一切布尔运算——存在量词
   与交的不和是根源。
6. |Y^X| = |Y|^|X|：有限时是算术，无穷时是第 139 章的基数算术。
