# 132 · 良序集

> 每一序数都是排在它之前的序数组成的集合。这不是关于序数的一个
> 已证命题，相反，这是给它们下的定义。——冯·诺依曼（本章题词）

本章覆盖书 4.1 节（PDF 75-78 页）：良序集的基本引理群——前段、
增函数、同构唯一，直到**良序集基本定理**（任何两个良序集可比较）
。这是通往序数的最后一级台阶。

## 132.1 前段：良序集的"尺子"

> **定义（书 4.1.1）**　线序 (L,<) 的子集 S 是**前段**，若
> x ∈ S 且 y < x 蕴涵 y ∈ S。∅ 与 L 自身是前段；≠ L 的称真前段。

对良序集 W 与 w ∈ W，集合 W[w] = {x ∈ W | x < w}（书 4.1 式）
是前段——每个自然数都是 ω 的前段（且"自然数 n 的前段是小于它的
自然数"，第 128 章的老朋友）。反过来：

> **引理（书 4.1.2）**　良序集的每个真前段 S 都有 W[w] 的形态。

*证明*：X = W−S 非空，取 < 最小元 a。x ∈ S ⟺ x < a（"x < a ⟹
x ∈ S"由前段性；"x ∈ S ⟹ x < a"否则 a ≤ x 且 x ∈ S 给 a ∈ S）
。∎ 良序性在这里不可省——线序的真前段未必是 W[w]（例：ℚ 的
(−∞,0) 不是任何 ℚ[q]——ℚ 里没有"贴着 0 左边"的元素）。机器侧
的有限审计（`examples/python/132_wellorders.py`）：

```python
for order in orders3:                    # 3 元素集的全部 6 个线序
    initials = {order[:k] for k in range(len(order) + 1)}
    proper = initials - {order}
    assert proper == {seg(order, a) for a in order}     # 真前段恰是 W[a]
```

## 132.2 增函数引理与三个唯一性

> **引理（书 4.1.4）**　f : W → W 是良序集到自身的（严格）增函数，
> 则对一切 a，f(a) ≥ a。

*证明*：反设 X = {x | f(x) < x} 非空，取最小元 a。则 f(a) < a，
而 f 增函数作用给 f(f(a)) < f(a)——即 f(a) ∈ X 且 f(a) < a，与
a 最小矛盾。∎ ——这是"良序 = 无无穷下降链"的第一手使用：增函数
把下降链 `a ∋ f(a) ∋ f(f(a)) ∋ …` 造了出来。

三个唯一性立刻跟进（书 4.1.5）：

1. **良序集不同构于自己的真前段**（同构 f : W → W[a] 是增函数，
   f(a) < a 违反 4.1.4）；
2. **良序集的自同构只有恒等**（f 与 f⁻¹ 都满足 f(x) ≥ x，两头夹）
   ；
3. **两个良序集之间的同构若存在则唯一**（g⁻¹∘f 是自同构）。

Lean 单元（`examples/lean/Settheory/Ch132Wellorders.lean`）把 4.1.4
的自然数版证成定理——注意证明结构就是书上的最小反例法，机器上
以第二归纳原理一次调用实现：

```lean
theorem increasing_ge_self (f : ℕ → ℕ) (hf : ∀ a b, a < b → f a < f b) :
    ∀ n, n ≤ f n :=
  fun n =>
    Nat.strongRecOn n fun m ih => by
      rcases m with _ | k
      · exact Nat.zero_le _
      · exact
          Nat.succ_le_of_lt
            (lt_of_le_of_lt (ih k (Nat.lt_succ_self k))
              (hf k (k + 1) (Nat.lt_succ_self k)))
```

Prolog 单元对 3 元良序的**全部**严格递增映射穷举验证 f(a) ≥ a；
Python 同。

## 132.3 良序集基本定理：任何两个良序集可比较

> **定理（书 4.1.6）**　对良序集 W₁、W₂，以下恰居其一：
> (a) W₁ ≅ W₂；(b) W₁ 同构于 W₂ 的前段；(c) W₂ 同构于 W₁ 的前段。

**证明是本章的华彩**，值得逐字读懂。定义

    f = {(x,y) ∈ W₁ × W₂ | W₁[x] 同构于 W₂[y]}。　　(4.2)

三步：

- **f 是函数且单射**：若 W₁[x₁]、W₁[x₂] 都同构于 W₂[y]，由 4.1.5(1)
  （前段不同构）x₁ = x₂；对称地单；
- **f 保序**：若 h : W₁[x'] → W₂[f(x')] 是同构，则 h 限制到 W₁[x]
  （x < x'）是 W₁[x] 到 W₂[h(x)] 的同构，故 f(x) = h(x) < f(x')。
  同一论证顺带证明 dom(f) 是 W₁ 的前段、ran(f) 是 W₂ 的前段；
- **三情况收口**：若 dom(f) ≠ W₁，则 dom(f) = W₁[w]；再断言
  ran(f) = W₂——否则 ran(f) = W₂[w']，f 便Witness了 W₁[w] ≅ W₂[w']，
  于是 w ∈ dom(f) = W₁[w]，矛盾（w < w）。对称地第三种情况；
  两者都不发生时 f 是全程同构。∎

由 4.1.5，三种情况互斥。**这个 f 就是"逐点配对到不能再配"的
构造**——两副骨牌从左端开始一一对齐，配到一边先枯竭为止。

机器侧最大的惊喜来自 Isabelle/ZF：**书 4.1.6 的构造 f 在 ZF 库里
有一个名字**——`ord_iso_map`（`examples/isabelle/ST132/Wellorders.thy`）：

```isabelle
thm ord_iso_map_def
(* ord_iso_map(A,r,B,s) =
   ⋃x∈A. ⋃y∈B. ⋃f ∈ ord_iso(pred(A,x,r), r, pred(B,y,s), s). {⟨x,y⟩} *)
thm domain_ord_iso_map
thm range_ord_iso_map
```

ZF 的 `pred(A,x,r)` 正是书的前段 W[x]，`ord_iso` 是同构——
"Construction for linearity theorem"的库注释说的就是基本定理。
同会话还给出良序的官方定义（`well_ord` = wf_on + 线性）、
保序映射（`mono_map` = 书 4.1.3 的增函数）的实名，并亲手证明
单点集上的空关系是良序（线序由 x=y 支起、良基来自 `wf_on_any_0`）。

有限侧，Python 单元枚举 3 元与 4 元良序的全部 6×24 对，验证三
情况互斥且恰居其一——在有限世界，"同构 ⟺ 等长、前段同构 ⟺ 更短"
，但审计按**显式同构**检查；同构唯一与自同构唯一（4.1.5(2)(3)）
也在 6×6 对上穷举：等长良序间的保序双射**恰好一个**。

## 132.4 和与积：下一章运算的几何

> **引理（书 4.1.7）**　不交良序集的并（W₁ 全排在前）是良序——
> 和 (W₁,<₁) + (W₂,<₂)。
>
> **引理（书 4.1.8）**　W₁ × W₂ 上的字典序（第二坐标优先）是
> 良序——积 (W₁,<₁) × (W₂,<₂)。

两个证明都是"非空子集取最小元"的一次练习（积的情形：先取第二
坐标最小的层，再在层内取第一坐标最小）。这两个构造是**序数加法
与乘法的几何形态**——书 4.4 节将证明 α+β、α·β 的递归定义恰是
和、积的序型（定理 4.4.3/4.4.7）。图 4.1（ω² 的图示：ω 条 ω-链
首尾相接）就是积 W₂ × W₁ 的直观。

Lean 单元锚定 mathlib 的字典序件：`Prod.lex`（把第二坐标优先的
字典序打包成 `WellFoundedRelation`——良基性正是 4.1.8 的内容）
与 `Prod.lex_def`（首坐标优先版本；书的积序 = 同一构造用在交换
乘积上）；`Sum.Lex` 则是 4.1.7 的不交并字典序（左块一律在前）：

```lean
example : Prod.Lex (· < ·) (· < ·) (1, 0) (5, 2) := by
  rw [Prod.lex_def]
  exact Or.inl (by decide)

example : Sum.Lex (· < ·) (· < ·) (Sum.inl 3 : ℕ ⊕ ℕ) (Sum.inr 0) := by
  simp
```

（注意 mathlib 的 `Prod.Lex` **首**坐标优先，与书 4.1.8 的次坐标
优先互为镜像——两个约定在文献中都常见，识别即可。）

## 132.5 有限良序实验室

Prolog 单元（`examples/prolog/132_wellorders.pl`）把本章做成了可查询
的实验室。良序判定器是四条否定的合取——连接、反对称、传递、以及
"每个非空子集有最小元"（有限域上对全部子集穷举）：

```prolog
wellorder(R, U) :-
    connex(R, U), antisym(R), transitive(R), has_least(R, U).

has_least(R, U) :-
    \+ (subselect(U, S), S \= [],
        \+ (member(Z, S), \+ (member(W, S), related(R, W, Z)))).
```

反例同样被机器拒绝：缺连接的残序、含环的反对称破坏者都过不了
`wellorder/2`。同构搜索则用回溯枚举全部双射（`pairs_of` 生成、
`order_preserving` 逐对验证）——3 对 3 恰好**一个解**（4.1.5(3)），
跨长度**零解**；增函数审计枚举全部 4 个严格递增映射（链源下递增
映射由值组唯一决定），无一违反 f(a) ≥ a。

值得对照记忆的边界事实：**良序 ⊆ 线序，且差距恰在"前段的形状"**。
(ℚ,<) 是稠密线序而非良序；它的前段 (−∞,0) 不是任何 ℚ[q]——引理
4.1.2 的证明在"取 W−S 的最小元"一步卡死。而有限线序全部是良序
（最小元可以逐层剥出来）——三个计算单元都默认站在这一事实上。

最后是编号预告：本章全部内容将在第 135 章立刻兑现——古德斯坦
定理的证明把"增函数引理"用在序数赋值的严格下降上；第 136 章
的选择公理等价形式中，"良序定理"（每个集合可良序化）直接依赖
本章的比较结构；第 137 章的基数则干脆定义为"初始序数"——序数
阶梯的等势代表。良序集是集合论的枢纽，此言不虚。读者若想在本章多留一会儿，
不妨用实验室自查两问：4 元素集上有多少个线序？（24——全部互不同
构吗？不，有限良序同构类只看长度，24 个里每 4! 个共享一个序型；
比较要在"同构类对同构类"之间做。）以及：把 ω 的逆序 ω*（…
< 3 < 2 < 1 < 0）拿来与 ω 比较，三歧性落在哪一支？（ω* 不是良
序——无穷下降链 0 > 1 > 2 > …，基本定理不适用。）

## 本章要点

1. 前段 W[w] 是良序集的尺子；真前段 = 某个 W[w]（4.1.2，良序性
   不可省）。
2. 增函数引理 f(a) ≥ a（4.1.4）一次收割三个唯一性：无自同构、
   无前段自同构、同构唯一——最小反例法即"无下降链"。
3. 基本定理（4.1.6）：配对构造 f = {(x,y) | W₁[x] ≅ W₂[y]}，三
   情况恰居其一——**任何两个良序集可比较**；Isabelle/ZF 的
   `ord_iso_map` 就是这个 f 的官方实现。
4. 良序集的和与积（4.1.7/4.1.8）是序数加法、乘法的几何形态；
   mathlib 的 `Prod.lex`/`Sum.Lex` 是其字典序化身。
