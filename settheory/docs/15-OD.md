# 15 · 相对可构造性与序数可定义：L[A]、OD、HOD

> 把 A 当作一盏灯：L[A] 是灯光下的可构造宇宙；把序数当作
> 唯一合法的参数：OD 是不用其他坐标系的定义。
> ——本章两大推广的世界观

本章覆盖 Jech §15：序数集决定模型（引理 15.1）、相对可构造
L[A]（定理 37）、OD/HOD（定理 38）、Berry 型自指的边界
（习题 15.17）、HOD[A]/OD(A) 的推广谱系。

## 15.1 序数集决定模型

**引理 15.1** 传递 ZF 模型 𝔐（满足 AC）与 𝔑 有相同序数集族
⟹ 𝔐 = 𝔑。证明的骨架：𝔐 中 X 的传递闭包被双射 f: θ ≅ TC({X})
编码为序数对的关系 E；E 良基外延（**Δ₁ 绝对**——引理 14.3
上场）⟹ 𝔑 中也可坍缩，坍缩像 = TC({X}) ⟹ X ∈ 𝔑。反向用
∈-归纳。**AC 的角色**：编码（良序）只在 𝔐 内可用。

## 15.2 L[A]：相对可构造

    L₀[A] = ∅；L_{α+1}[A] = def_A(L_α[A])；L_λ[A] = ⋃

def_A(U) = 带谓词 A 的可定义子集（(15.7)——cl(V ∪ {V} ∪
{A ∩ V}) ∩ P(V)）。**定理 37**：(i) L[A] ⊨ ZFC；(ii)
L[A] ⊨ ∃X(V=L[X])；(iii) 最小性（A ∩ 𝔐 ∈ 𝔐 的模型 ⊇ L[A]）；
(iv) **渐近 GCH**：存在 α₀ 使 α ≥ α₀ 后 2^ℵα = ℵ_{α+1}——
相对化的 Condensation（引理 15.7：A ⊆ L_{ω₁}[A] 时每
X ⊆ ω_α 落进某 L_γ[A]，γ < ω_{α+1}）。

关键引理 15.2：L[A] = L[Ã]（Ã = A ∩ L[A]）——**A 只有
"看得见的部分"起作用**。L[A] 是第 31 章 L[U]（可测基数内
模型）的模板。

## 15.3 OD：序数可定义

X ∈ **OD** ⟺ X = {u : φ(u, α₁,...,αₙ)} 对某公式与序数参数。
等价刻画（(15.16)）：X ∈ cl({V_α : α ∈ Ord})——反射原理
架起"参数形式"与"闭包形式"的桥。**引理 15.8**：OD 有可定义
单射入 Ord（V_α 的可定义枚举的拼接）——OD 的每个成员拿到
"定义身份证"。

**习题 15.17（Berry/Richard 自指的边界）**："X 可定义"本身
**不可**用集合论语言表达——否则"最小不可定义序数"被该表达
式定义，自爆。机器化：Coq（`Ch15_od.v`）给出**强归纳引擎**
（最小反例原理的完整证明——第 02 章的回响）并精确标注机器化
边界：最小反例的构造是对象语言的，"自指命名"是元语言动作
——**分层的证明结构本身**。Julia/Python（`15_od.jl` /
`15_od.py`）做 Berry 的数值形态：≤N 字符可命名的数有名字集，
"最小不可命名数"的名字长度 53 > N——**长度分层消解悖论**；
集合论版本是 Tarski 分层。

## 15.4 HOD：遗传序数可定义

    HOD = {x : TC({x}) ⊆ OD}

**定理 38** HOD ⊨ ZFC：传递 ✓；Gödel 封闭 ✓（可定义运算保
可定义性）；几乎通用（V_α ∩ HOD 本身序数可定义 ⟹ ∈ HOD）；
**AC 在 HOD 中**：OD 的可定义良序（引理 15.8）限制到每个
V_α ∩ HOD。HOD 是 AC 相对一致性的**第二条路**（不依赖 L）。

HOD ⊇ L；可一致地 HOD ≠ L；**OD 不绝对**——可一致地
HOD^HOD ≠ HOD（第 25 章伏笔：HOD 的多值性是力迫的舞台）。
Prolog（`15_od.pl`）的参数安全检查器：φ(u, ω, 17) ✓（序数
参数）vs ψ(u, x) 被拒（集合参数越界）——OD 定义合法性的
可执行判定。Agda（`Ch15_od.agda`）的 Param 代数（ord/set）
与 in-OD 布尔判定（def1-in-OD ≡ true / def2-not-OD ≡ false
的 refl 验证）。

## 15.5 推广谱系与 B3 收官

**HOD[A]**（从 A 序数可定义）与 **OD(A)**（在 A 上序数可
定义——(15.19)：X ∈ OD[A, s] 对 A 中有穷序列 s）：两个方向
的参数化给出内模型/外模型的完整词汇表。𝔐-definable 与
HW𝔐D（习题 15.22）把"定义者"抽象化——L^D = OD（习题
15.23）。

**B3（L 篇）收官**：第 10-15 章走完了从模型论方法（Δ₀ 绝对
性）、坍缩（Mostowski）、反射、L 的构造、AC+GCH 在 L、
Lévy 层级到 OD/HOD 的完整链条——Gödel 1938 相对一致性的
全部技术要素。Isabelle/ZF 的 Constructible 会话（Lset/DPow/
AC_in_L）是官方机器化锚；孤儿理论（Reflection.thy）与缺席
（GCH/OD）如实标注。下一大幕：**Cohen 力迫**（B4，第 16 章
起）——从"最瘦的内模型"转向"自由的宇宙扩张"。
