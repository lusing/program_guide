# 33 · 可测之下：弱紧、Ramsey 与分层

> 可测基数之下有一条丰富的层级——每一步都有组合/模型论/
> 拓扑的等价刻画。

本章覆盖 Jech §32：弱紧基数、Ramsey 基数、不可描述性
层级。

## 33.1 弱紧基数

κ **弱紧**：
- κ 不可达 + κ → (κ)²
- 等价：κ 不可达 + Π¹₁-不可描述
- 等价：κ 不可达 + κ 上的 κ-树有 κ-分支
- 等价：κ 不可达 + κ-cc cBa 的积保持 κ-cc

## 33.2 Ramsey 基数

κ **Ramsey**：κ → (κ)^<ω_{<κ}。
（比 Erdős 弱——每个有限分划有大小 κ 的同质集。）

可测 → Ramsey → 弱紧 → Mahlo → 不可达。

## 33.3 不可描述性层级

κ 是 Π^m_n-不可描述的：对每个 Π^m_n 句子 φ（V_κ 的
m 阶逻辑），V_κ ⊨ φ ⟹ 存在 α < κ 使 V_α ⊨ φ。

- Π¹₁-不可描述 = 弱紧
- Π¹₂-不可描述严格强于弱紧

## 33.4 层级总图

    可测 ⟹ Ramsey ⟹ Erdős ⟹ 弱紧 ⟹ Mahlo ⟹ 不可达

每一层的不可在 ZFC 中证明（从下层出发）。大基数层级的
一致性强度形成严格的线性序（到目前为止的共识）。
