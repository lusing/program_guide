# 70 · 第二递归定义定理与彻底有限集合

> 第一递归定义定理（68 章）造的是 ω 上的序列；本章提炼冯琦 §1.5-1.6
> 的两次升维：先引入 ZF 的第八条公理**映像存在原理**（替换公理），
> 把递归定理升级为**第二递归定义定理**——步进关系只需"泛函定义式"
> 而不必是现成的函数；用它立刻造出两件大件：**传递闭包 TC(X)**
> 与累积层次的底层 **V_ω**。然后是第九条公理 **∈-极小原理**（基础
> 公理/正则公理）——它是"没有 ∈-无穷下降链"的公理化，也是本章
> 定理 1.45（V_ω 恰为全体**彻底有限集合**）的证明引擎。压轴是
> 冯琦的招牌编码：二进制分解 + **阿克曼式双射** f: ℕ → V_ω
> （f(n+1) = f(r(n)) ∪ {f(lg2(n))}），整个自然数系统在 V_ω 里有
> 一面一一对应的镜子，ℤ 与 ℚ（69 章的全部构造）也住在里面。
> 与 09 章（Jech 秩层级 V = ⋃V_α 的全景）互为放大镜：本章是
> "只看第一层无穷"的显微镜版本。

## 70.1 公理不够用了

68 章末冯琦盘点公理：同一律、第一存在性、分解原理、幂集、配对、
并集、无穷——七件套。∞ 的迭代立刻榨干它们：ω 有了，那么
⋃ω、𝒫ω、𝒫𝒫ω、…，甚至"把 ω, 𝒫ω, 𝒫𝒫ω, … 收集成一个集合"
——能吗？想证
∃w(ω ∈ w ∧ ∀a∀b(a ∈ w ∧ b ∈ w → a∪{b} ∈ w))
（一个对"并加单元"封闭且含 ω 的集合）：现有的七条公理给不出
正面回答。当然可以把无穷公理加强，但"总不能一遇到无法回答的
问题就引进一条公理"——ZF 还有最后两块通用积木：映像存在原理
（本节）与 ∈-极小原理（70.7）。

## 70.2 映像存在原理：替换公理

> **公理 8（映像存在原理）** 设表达式 Φ(u,v) 中 y、z、w 不自由。
> 若 ∀u∀v∀w(Φ(u,v) ∧ Φ(u,w) → v = w)（Φ 是**泛函定义式**，
> 定义 1.51：每个 u 至多配一个 v），则
> ∀z∃y∀v(v ∈ y ↔ ∃u(u ∈ z ∧ Φ(u,v)))。

一句话：**泛函的像存在**。z 经过"部分函数" Φ 之后的值域
{v | ∃u ∈ z, Φ(u,v)} 是集合。分解原理从 x 里**筛**子集；映像
存在原理把 z 的元素**搬运**成新集合——搬运比筛选强：像的元素
可以完全不在原来的集合里（𝒫ω 的成员不在 ω 里）。它与幂集公理
配合（冯琦注：由分解+幂集，"图象" {(a,b) | a ∈ x ∧ Φ(a,b)} 与
"值域" {b | …} 两种存在性互推）就足够灵活。

替换公理在 ZF 里的名分：弗伦克尔 1922 年为"幂集迭代收敛性"补
的公理（67 章引言的历史线在此兑现）。机器视角：Lean 的 `Set.image`
、Isabelle 的 `RepFun`/`Replace`、Coq 的 `map` 都是这条公理的类型
论化身——类型论里替换是免费的（`Set.image f h s` 直接构造），
集合论里它值一条公理。

## 70.3 第二递归定义定理

> **定理 1.40（第二递归定义定理）** 设 Φ(τ₁,τ₂,τ₃) 是表达式，
> 定义 G(n,r) = y ⟺ n ∈ ω ∧ Φ(n,r,y)，且对每个 n ∈ ω、r、y，
> Φ 泛函（至多一个 y）。则对任何集合 a 存在唯一的 f：
> (1) dom(f) = ω；(2) f(0) = a；(3) ∀n(f(n+1) = G(n, f(n)))。

与定理 1.12 的差别不在表面（都写 f(n+1) = G(n,f(n))），而在
**G 的资格**：第一定理要求 g: A×ω → A 是**现成的函数**（一个
集合）；第二定理只要求 G 由**泛函定义式**给出——y 怎么从 (n,r)
来，可以是任意复杂的一阶描述，不必先成集合。步子迈得大的递归
（如 Vₙ₊₁ = 𝒫(Vₙ)：值不在任何预先给定的 A 里）只有第二条定理
罩得住。

*证明*（三段式的替换版）：定义表达式 ψ(x,y)：
(i) x ∉ ω 时 y = ∅；(ii) x = 0 时 y = a；(iii) x = n+1 ∈ ω 时
y 满足：存在定义在 n+1 上的函数 h，h(0) = a，∀i∈n(h(i+1) =
G(i,h(i)))，且 y = G(n,h(n))。**断言一**（对 n 归纳，同定理
1.12）：对每个 n 存在唯一的 (h,y) 满足 (iii) 的要求——所以 ψ
是泛函定义式。**由映像存在原理**，
A = {y | ∃n∈ω ψ(n,y)}
是集合；令 f = {(n,y) ∈ ω×A | ψ(n,y)}，逐条验证 (1)(2)(3)。
唯一性照抄第一定理的归纳。∎

证明的骨架与 68 章完全同构（有限近似 → 相容 → 焊接），只是
"焊接"这一步的合法性从"和谐函数系统取并"换成了"替换公理造值
域"。**推论**（断言二）：对泛函定义式 Ψ(r,y)，存在唯一 f: ω→V
使 f(0) = a、∀n Ψ(f(n), f(n+1))——步进直接拿"当前值"喂泛函，
连 n 都不用。

## 70.4 第一发：无穷公理的强形式

> **定理 1.41** ∀u∃w(u ∈ w ∧ ∀a∀b(a ∈ w ∧ b ∈ w → a∪{b} ∈ w))。

*证明*：Φ(u,v) := (u = (a,b) → v = a∪{b}) ∧ (u 非有序对 → v = ∅)
是泛函定义式；给定 u，令 y₀ = u∪{u}，用推论递归 y_{n+1} =
{a∪{b} | a,b ∈ yₙ}（每次的合法性都是映像存在原理），w = ⋃yₙ。
∎

70.1 的问题正面解决——不需要加强无穷公理，替换公理一只手就够。

## 70.5 第二发：传递闭包

> **定理 1.42** 对任何集合 X 存在唯一 Y：(1) Y 传递；(2) X ⊆ Y；
> (3) Z 传递 ∧ X ⊆ Z → Y ⊆ Z（Y 是覆盖 X 的最小传递集）。
> *证明*：X₀ = X，Xₙ₊₁ = Xₙ ∪ (⋃Xₙ)，Y = ⋃ₙXₙ。传递性：a ∈ Y、
> b ∈ a → b ∈ ⋃Y ⊆ Y（每个 Xₙ 的贡献都被下一层吸收）；最小性：
> Z 传递 → ⋃Z ⊆ Z，归纳 Xₙ ⊆ Z。∎

**定义 1.52（传递闭包）** TC(X) := 该唯一 Y。显式：
TC(X) = ⋃{Xₙ | n ∈ ℕ}。事实：X 传递时 TC(X) = X；
TC(X) = ⋂{Y | X ⊆ Y ∧ Y 传递}。

传递闭包是"把 X 的元素、元素的元素、……全部显式搬进一个集合"。
n ∈ ω 时 TC(n) = n（自然数传递）；TC({{∅}}) = {∅, {{∅}}}。
09 章的秩函数 rank(x) = sup{rank(y)+1 | y ∈ x} 依赖 TC 的存在
（秩的归纳走的就是传递闭包链）；75 章的传递化定理更是拿 TC 当
建材。机器通道里 TC 是可执行迭代：Xₙ₊₁ = Xₙ ∪ ⋃Xₙ 在有限集
合的世界上有限步收敛。

## 70.6 V_ω 与彻底有限集合

> **定义 1.53** V₀ = ∅；Vₙ₊₁ = 𝒫(Vₙ)；V_ω = ⋃{Vₙ | n ∈ ω}。
> （合法性：G(n,x) = y ⟺ y = 𝒫(x) 泛函（幂集唯一性，67 章命题
> 1.2），第二递归定义定理给出序列 ⟨Vₙ⟩，值域取并。）

> **定义 1.54（彻底有限 / hereditarily finite）** a 彻底有限 ⟺
> TC(a) 是有限集合。

**例 1.19** (1) 有限传递集合彻底有限（TC = 自身）；(2) 每个 Vₙ
彻底有限（TC(Vₙ) ⊆ Vₙ∪{Vₙ}…有限塔）；(3) a ∈ V_ω → a 彻底有
限；(4) **ℚ ⊆ V_ω**——69 章的承诺兑现：每个有理数（带符号位的
两层有序对嵌套自然数）都是彻底有限集合。ℤ、ℚ 与其上的运算全是
"有限数据"。

Vₙ 的规模是一张会让人瞳孔放大的表：|V₀| = 1、|V₁| = 2、|V₂| = 4、
|V₃| = 16、|V₄| = 65536、|V₅| = 2^65536——每上一层取幂集，第
n 层是 2 的 2 的 … 的 2（n 次）。V_ω 是第一个"超出全部有限层"
的集合；它是 09 章累积层次 V = ⋃V_α 的 α = ω 截面。

## 70.7 ∈-极小原理：ZF 的第九条公理

> **公理 9（∈-极小原理 / 基础公理）** (∃v₂(v₂ ∈ v₁)) →
> (∃v₂(v₂ ∈ v₁ ∧ ¬∃v₃(v₃ ∈ v₁ ∧ v₃ ∈ v₂)))。
> ——非空集合必有 ∈-极小元素：与集合相交为空的成员。

它排除"自含"与"∈-下降链"：{a} ∈ a 会让 {a} 无极小元；
a₀ ∋ a₁ ∋ a₂ ∋ … 无穷下降链的集合 {aₙ} 无极小元。

> **定理 1.43（∈-极小性，模式版）** 对任何表达式 Φ(x, a₁,…,aₙ)：
> ∃xΦ(x,a⃗) → ∃x(Φ(x,a⃗) ∧ ∀y(y ∈ x → ¬Φ(y,a⃗)))。
> *证明*：取见证 a，令 A = {x ∈ TC({a}) | Φ(x,a⃗)}（分解原理；
> 注意要往 TC 里找才保证 A 有"底"），A 非空，公理 9 取极小
> x ∈ A 满足 x∩A = ∅。若 y ∈ x ∧ Φ(y,a⃗)，则 y ∈ TC({a})
> （TC 传递），y ∈ A——与 x∩A = ∅ 冲突。∎

> **定理 1.44（三等价）** (1) 模式版（定理 1.43）；(2) 传递集 M、
> 非空 X ⊆ M → ∃a∈X(a∩X = ∅)；(3) 每个非空集合 A 有极小元。
> ——(1)→(2) 取 Φ(u) := u ∈ X；(2)→(1) 取 M = TC({a})；(3)
> 与 (2) 经 TC(A) 互推。

09 章（Jech 路线）的正则公理讲的是同一件事的全景版（秩函数、
V = ⋃V_α、无下降链）；冯琦在此只取他马上要用的"极小元"形态。
推论 1.7：¬∃x(x ∈ x)、¬(a∈b ∧ b∈a)（罗素定理的集合论升级版，
对照 67 章定理 1.1 的纯逻辑版）。

## 70.8 V_ω 恰是全体彻底有限集合

> **定理 1.45** ∀a(a ∈ V_ω ⟺ ∃n(|n| = |TC(a)|))。
> *证明*：→ 已见（例 1.19(3)）。**断言一**（有限子集封闭性）：
> {a₀,…,aₘ} ⊆ V_ω → ∈ V_ω——取 n = max{层级} + 1，有限个
> V_ω 的成员挤进同一层 Vₙ。**断言二**：a 彻底有限 → a ∈ V_ω。
> 反证：令 Y = TC({a}) 有限传递，若 a ∉ V_ω 则 Y − V_ω 非空，
> 公理 9 取极小 z ∈ Y−V_ω（z∩(Y−V_ω) = ∅），由 Y 传递 z ⊆ Y
> 给 z ⊆ V_ω；z 有限（⊆ 有限 Y），由断言一 z ∈ V_ω——矛盾。∎

∈-极小原理在这里的用法是标准的"拿正则性当归纳法"：在"越降越
小"的世界里，反例必有极小反例，而极小反例的"小"恰好自我矛盾。
这与 68 章模板"考虑 z = {a ∈ ω | …} 证 Inf(z)"是同一个灵魂的
两种显形——一个用无穷公理的最小性，一个用基础公理的极小性。

> **定理 1.46（V_ω 的六性质）** V_ω 是 (1) 全体彻底有限集合；
> (2) 传递集合；(3) Inf 集（验证无穷公理）；(4) ⊇ ℕ；(5) 对
> 配对、并、交、差、笛卡尔积、**幂集**全部封闭；(6) 有限子集
> 皆属于它。
> （(5) 的幂集款最惊人：u ∈ V_ω → 𝒫(u) ∈ V_ω——彻底有限集合
> 的幂集仍彻底有限；验证：u ⊆ Vₙ → 𝒫(u) ⊆ 𝒫(Vₙ) = Vₙ₊₁ ∈
> V_ω。推论 1.8：X, Y ∈ V_ω → X∪{Y} ∈ V_ω。）

V_ω 是 ZF 减去无穷公理的**全集模型**：在 V_ω 眼里，除无穷公理
外的全部 ZFC 公理都成立（69-70 章的五条封闭律 + 幂集封闭就是
证明的骨架；73 章快速增长层次还会回来用它）。这正是有限数学的
集合论宇宙——也是 PA 的集合论影子（下节编码给出同构）。

## 70.9 二进制分解与阿克曼编码：ℕ ≅ V_ω

冯琦最后给出 ℕ 到 V_ω 的**典型双射**。先备料：

> **定理 1.47（二进制分解）** (1) 每个 n ∈ ℕ 有唯一 (i,m)：
> i ≤ n、m ≤ n、2^i ≤ n+1 < 2^{i+1}、2^i + m = n+1；(2) 每个
> n > 0 有唯一递降序列 k₁ > k₂ > … > kₘ ≥ 0 使 n = 2^{k₁} +
> 2^{k₂} + … + 2^{kₘ}。（对 n 归纳：(1) 的 (i,m) 推到 n+1 时
> 要么 i 加一要么 m 加一；(2) 剥掉最高位。）

**推论 1.9** f(∅) = 0、f(a) = Σ_{i∈a}2^i 是 [ℕ]^<ω → ℕ 的典型
双射——**有限集的二进制展开**（ℕ 的每个子集模式恰好编码一个
自然数）。**定义 1.56**：lg2(n) = 满足 2^i ≤ n+1 < 2^{i+1} 的 i
（二进制位数−1）；r(n) = n+1 − 2^{lg2(n)}（去掉最高位后的余数）。

> **定理 1.48（阿克曼编码）** 定义 f: ℕ → V_ω：
> f(0) = ∅；f(n+1) = f(r(n)) ∪ {f(lg2(n))}。
> 则 f 是 ℕ → V_ω 的双射。
> *证明*六断言：**三**（形状公式）f(n) = {f(k₁),…,f(kₘ)}，其中
> n = 2^{k₁}+…+2^{kₘ} 是定理 1.47(2) 的分解（对 n 强归纳：n+1
> 的二进制分解 = 最高位 2^{k₁} + 余数 l，f(n+1) = f(l)∪{f(k₁)}
> 归纳假设展开）；**四**（单射）：若 f(t) = f(n) 取最小反例 n，
> 二进制分解给出 f(ke) ∈ f(n) = f(t) 与极小性矛盾；**五**（有限
> 子封闭）：{f(n₁),…,f(nₘ)} = f(2^{n₁}+…+2^{nₘ})；**六**（满
> 射）：f[ℕ] ⊇ ∅ 且对有限子集封闭，若 V_ω − f[ℕ] 非空，∈-极小
> 元 a ⊆ f[ℕ] 有限由断言五 ∈ f[ℕ]，矛盾。∎

> **定理 1.49（最小性刻画）** V_ω 是满足 ∅ ∈ W、x ∈ W → {x}
> ∈ W、u,w ∈ W → u∪w ∈ W 的最小集合 W。

三个算子（空集、单集化、二元并）生成一切彻底有限集合——就像 0
与后继生成一切自然数。f 的递归式 f(n+1) = f(r(n))∪{f(lg2(n))}
正是"**前 n 个自然数的集合运算历史**"的压缩存储：n 的二进制位
串说明 n+1 这个集合是由哪些更早的集合用"并+单集"拼出来的。这
个编码属于阿克曼（1928 年用它证明 ZF−Infinity+¬Infinity 的一致
性可化为 PA 的一致性——V_ω ⊨ ZF−Inf，而 V_ω ≅ ℕ 的算术化）。
它与 63 章（命题逻辑的编码）、73 章（快速增长层次在 V_ω 上的演
算）遥相呼应。

## 70.10 机器通道

本章机器化的主轴是"**把 V_ω 当数据类型**"：七条通道各自给出
彻底有限集合的原生表示（Lean/Coq/Agda 的归纳类型、Python/
Julia 的 frozenset、Prolog 的规范列表），然后在同一批锚点上会
师——TC 迭代（定理 1.42）、三算子生成（定理 1.49）、阿克曼编码
（定理 1.48 + 推论 1.9 的互逆）、∈-极小原理的有限版（定理
1.44(3)）。

### Lean：HF 结构体与燃料递归

Lean（examples/lean/Settheory/Ch70Recursion2.lean）把 V_ω 的居民
做成**结构体** `HF`——成员就是孩子列表，"属于"就是列表成员：

```lean
-- 归纳类型没有字段投影（.children 不存在）——structure 才带投影；
-- 单构造子结构体与书上的"集合 = 孩子列表"完全同构
structure HF where
  children : List HF
deriving Repr

/-- 集合成员：孩子列表里出现 -/
def mem (a b : HF) : Bool := b.children.contains a

/-- 冯琦的"属于"：a ∈ b -/
scoped infixl:50 " ∈ᴴᶠ " => HF.mem

/-- 并：孩子列表拼接（推论 1.8 的 X ∪ {Y}） -/
def union (a b : HF) : HF :=
  if a.children.contains b then a
  else ⟨a.children ++ [b]⟩
```

`DecidableEq` 不能 deriving——核心版不支持 List 递归字段上的
派生（4.33 实测拒绝）；手工装一个**跨类型互递归**：HF 层与孩子
列表层互调，Lean 的方程编译器接受这种互结构递归（对照：Coq 8.20
的 guard 会拒绝教科书式的互递归 size/sum_sizes——见下文 Coq 段）：

```lean
mutual
def decEqHF : (x y : HF) → Decidable (x = y)
  | ⟨a⟩, ⟨b⟩ =>
      match decEqChildren a b with
      | isTrue h => isTrue (by subst h; rfl)
      | isFalse h => isFalse (fun he => HF.noConfusion he (fun e => h e))

def decEqChildren : (l1 l2 : List HF) → Decidable (l1 = l2)
  | [], [] => isTrue rfl
  | x :: xs, y :: ys =>
      match decEqHF x y, decEqChildren xs ys with
      | isTrue hxy, isTrue hxs => isTrue (by rw [hxy, hxs])
      | isFalse hxy, _ => isFalse (fun h => by injection h with h1 h2; exact hxy h1)
      | _, isFalse hxs => isFalse (fun h => by injection h with h1 h2; exact hxs h2)
  | [], _ :: _ => isFalse (fun h => nomatch h)
  | _ :: _, [] => isFalse (fun h => nomatch h)
end

instance : DecidableEq HF := decEqHF
```

`empty`/`singleton`/`union` 三算子（定理 1.49 的生成器）各带
成员引理（`empty_mem`、`singleton_mem`、`union_mem_of_mem`、
`union_mem_right`）——三算子的"生成完备性"由阿克曼编码来兑现。
编码 f 的递归账目是 r(n) ≤ n（因 2^lg2(n) ≥ 1）与 lg2(n) ≤ n；
但良基递归编译为 `WellFounded.fix` 后 kernel 难以归约，`rfl`/
`decide` 全数失效——与 Coq 版一致改用**显式燃料**（结构递归）：

```lean
def ackVaux : ℕ → ℕ → HF
  | 0, _ => empty
  | _ + 1, 0 => empty
  | fuel + 1, n + 1 => union (ackVaux fuel (rrem n)) (ackVaux fuel (lg2 n))

/-- 书页 84：f(0) = ∅；f(n+1) = f(r(n)) ∪ {f(lg2(n))}（燃料版） -/
def ackV (n : ℕ) : HF := ackVaux n n
```

顺带一提，lg2 也是自写的除二循环——本版 mathlib 的 `Nat.log2`
引理族断代（log2_lt_pow/log2_le_mono 均不存在，唯 log2_le_self
幸存），两条对数不变量（`lg2aux_le` 燃料上界、`two_pow_lg2_le`
即 2^lg2(n) ≤ n+1）在文件内自给自足。决定性验证随即跟上：
`f(3) = {f(0), f(1)}`（断言三的形状公式；孩子列表的**计算序**
是 [f(0), f(1)]，集合意义上与书页 {f(1), f(0)} 同一）与"前 16
个值两两不同"都由 `rfl`/`decide` 闭账。

### Coq 与 Agda：燃料递归与 ∈-极小的构造性选元

Coq（examples/coq/Ch70_recursion2.v）同一编码用**燃料参数**显式
承载良基性——`ackV (fuel n : nat)`，先证 `rrem_le` 与 `lg2_le`
两条引理再递归：

```coq
(* 每次递归第二参数严格变小（rrem m ≤ m、lg2 m ≤ m），燃料 n 足够 *)
Fixpoint ackV (fuel n : nat) : HF :=
  match fuel with
  | 0 => hf_empty
  | S f =>
      match n with
      | 0 => hf_empty
      | S m => hf_union (ackV f (rrem m)) (ackV f (lg2 m))
      end
  end.
```

Lean 通道最终也采用同款燃料结构（良基递归的 `WellFounded.fix`
让 kernel 归约举步维艰，`rfl`/`decide` 双双失效——两种语言的
答案殊途同归：把"下降性"从证明义务翻译成数据参数）。Agda
（examples/agda/Ch70_recursion2.agda）的主戏则是定理 1.44(3)
——非空列表必有 ∈-极小元。策略与书页同构：**取尺寸最小者**，
孩子的尺寸严格更小，故无人能落入它的成员。Agda 的互递归（尺寸
与孩子列表尺寸）由作用域检查器放行——它对跨类型互递归的态度
与 Lean 相同、与 Coq 相反。尺寸的互递归下降引理两行拿下：

```agda
mutual
  size : HF → ℕ
  size (node cs) = suc (sum-size cs)

  sum-size : List HF → ℕ
  sum-size [] = zero
  sum-size (c ∷ rest) = size c + sum-size rest

size-child-< : ∀ {cs y} → y ∈ cs → size y < size (node cs)
size-child-< (here refl) = s≤s (m≤m+n _ _)
size-child-< (there p) = ≤-trans (size-child-< p) (s≤s (m≤n+m _ _))
```

选元过程做成 record `Pick`（元素 + 属于证据 + 尺寸最小性），
`pick` 沿列表递归、用 `≤-total` 二选一；极小性由"b ∈ a 给
size b < size a ≤ size b——自相矛盾"闭账：

```agda
minimal-goal : ∀ {l} (p : Pick l) → ∀ b → b ∈ l → ¬ hf-in b (Pick.elem p)
minimal-goal p b b∈ b∈ᴴ =
  not-suc≤self (size b)
    (≤-trans (hf-in-size-< b∈ᴴ) (Pick.size-min p b b∈))
```

Coq 的 `hf_minimal` 同一骨架；正则公理"没有无穷 ∈-下降链"
的影子在这里第一次可执行——尺寸函数就是下降链的"杀死器"。

### Python/Julia：frozenset 的 V_ω 全息馆

Python（examples/python/70_recursion2.py）用 frozenset 直接把
集合论对象当一等公民。TC 迭代（定理 1.42）是 while 到不动点
——Xₙ₊₁ = Xₙ ∪ ⋃Xₙ 在代码里是"把新区块并入、剥掉旧元素"：

```python
def tc(x):
    Y, Xn = set(), set(x)          # X₀ 的元素起步（Y 不含 x 本身）
    while Xn:
        Y |= Xn
        Xn = {e for a in Xn for e in a} - Y
    return frozenset(Y)

def vn(n):                        # 冯诺伊曼自然数：n 重 S(x) = x ∪ {x}
    r = EMPTY
    for _ in range(n):
        r = r | frozenset([r])
    return r

assert tc(vn(5)) == vn(5)                              # TC(n) = n
assert tc(frozenset([vn(1)])) == frozenset([EMPTY, vn(1)])
```

两条 assert 对应书页两个验算：TC(n) = n（自然数传递）、
TC({1}) = {0,1}。阿克曼编码与逆是双字典记忆化——f 的孩子就是
n+1 的二进制位，逆是"每个成员贡献 2^inv(e)"：

```python
ACK = {0: EMPTY}
def ack(N):
    if N not in ACK:
        i = lg2(N)
        r = N - 2 ** i
        ACK[N] = ack(r) | frozenset([ack(i)])
    return ACK[N]

INV = {EMPTY: 0}
def inv(a):
    if a not in INV:
        INV[a] = sum(2 ** inv(e) for e in a)
    return INV[a]

assert all(inv(ack(n)) == n for n in range(512))         # 互逆
```

0..511 全部往返恒等——定理 1.48 与推论 1.9 的"双射"在半 KB
的范围内被逐点验证。文件末段还有定理 1.45/1.46 的有限验证（并/
配对/幂集封闭、TC 全有限）与例 1.19(4) 的实测：书版有理数
（Kuratowski 对嵌套）TC 有限、深度 < 12——ℚ ⊆ V_ω 不是口号，
是 34 个样本的实测。Julia 版（examples/julia/70_recursion2.jl）
同一剧目以 Set{Any} 重演并报出 |V₅| = 2^65536 的十进制位数。

### Prolog：不动点迭代与规范列表

Prolog（examples/prolog/70_recursion2.pl）把集合包装成规范列表
`s/1`，TC 的不动点迭代是一条递归子句——"新区块为空即停"：

```prolog
tc(X, TC) :- tc_iter([X], [], TC).
tc_iter(Xn, Y0, TC) :-
    flat_union(Xn, U1),
    ord_subtract(U1, Y0, New),
    ( New == [] -> sort(Y0, TC)
    ; append(Y0, New, Y1), sort(Y1, Y2),
      tc_iter(New, Y2, TC) ).
```

阿克曼编码以 `msb/1`（最高位）实现 lg2，`ack_memo/2` 动态表
记忆化，0..63 全程往返恒等；∈-极小元走"尺寸最小者即极小"的
书页路线（`size` 递归求和、`list_min` 选元、`hf_minimal` 验
"无人落入极小者的成员"），四个候选的族里机器选出 ∅——定理
1.44(3) 的有限剧场谢幕。
