# 32 · 内模型 L[U]

> L[U] 是含可测基数的"最小内模型"——正如 L 是 ZFC 的
> 最小内模型，L[U] 是 ZFC + 可测的最小内模型。

本章覆盖 Jech §31：L[U] 的构造与基本性质。

## 32.1 L[U] 的层级

给定正规测度 U on κ：

    L_0[U] = ∅
    L_{α+1}[U] = def_U(L_α[U])（带谓词 U∩L_α[U] 的可定义子集）
    L[U] = ⋃ L_α[U]

## 32.2 L[U] ⊨ ZFC + κ 可测

L[U] 中的 U 是 κ 上的正规测度（Silver 定理）。
L[U] ⊨ GCH（与 L 类似的 Condensation 论证）。

## 32.3 L[U] 的唯一性

如果 U₁ 和 U₂ 都是 κ 上的正规测度，则 L[U₁] = L[U₂]。
（在 L[U] 内，测度是唯一的——这是内模型理论的核心定理。）

## 32.4 与 L 的比较

- L ⊆ L[U] ⊆ V
- L[U] ⊨ 2^ℵ₀ = ℵ₁ + κ 可测（GCH + 可测并存）
- L ⊨ V=L ⟹ 无可测（Scott）

L[U] 证明了 Con(ZFC + 可测) ⟹ Con(ZFC + GCH + 可测)。

## 32.5 习题精选

1. **（纸笔）** L[U] ⊨ GCH 的骨架。
2. **（纸笔）** L[U] 中测度的唯一性。
