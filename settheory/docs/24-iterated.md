# 24 · 迭代力迫

> 把多个力迫串成一列：先 P 后 Q 的两步扩张等于一个力迫
> P*Q 的单步扩张——迭代力迫是现代集合论的标准工具。

本章覆盖 Jech §23 后半：两步迭代的构造（B*Q）、有限支撑
迭代、ccc 的迭代保持（Solovay-Tennenbaum 的技术核心）。

## 24.1 两步迭代的构造

设 B 是 M 中的 cBa，C ∈ M^B 使 ‖C 是 cBa‖ = 1。定义
**迭代** D = B*C：

1. 取 V^B 中使 ‖c ∈ C‖ = 1 的**极大反链代表集** D
   （(23.3)：等价类的代表——两两不相容）。
2. D 的布尔运算由 V^B 中的运算诱导：
   c₁ +_D c₂ = 唯一 c 使 ‖c = c₁ +_C c₂‖ = 1。

**关键**：D 是 M 中的 cBa 且 M^{B*C} = M^B[G][H]——
两步力迫可合并为一步。这就是迭代力迫的基础。

## 24.2 有限支撑迭代

**α-步有限支撑迭代** P_α 的递归定义：

    P_0 = {∅}（平凡偏序）
    P_{α+1} = P_α * Q̇_α（Q̇_α 是 P_α-名字）
    P_λ = ⋃_{α<λ} P_α（极限步取并）

条件 p ∈ P_α 是函数 dom(p) ⊆ α 使 supp(p) = {β :
p(β) ≠ 1} 有限。

## 24.3 ccc 的迭代保持

**核心问题**：ccc 力迫的迭代是否 ccc？

- 单步迭代：P ccc + ‖Q ccc‖ → P*Q ccc ✓
- **有限支撑迭代**：ccc × ccc × ... 仍 ccc ✓
  （Solovay-Tennenbaum 的关键引理——ccc 的迭代保持）

*证明思路*：对迭代长度归纳。关键步骤：有限支撑使条件
的"支撑"有限——对不可数反链用 Δ-系统引理找到公共根，
在根上做 ccc 论证。

## 24.4 Solovay-Tennenbaum 定理的完整证明

**定理 51** Con(ZFC) ⟹ Con(ZFC + MA + 2^ℵ₀ > ℵ₁)。

*证明骨架*：
1. 地面模型满足 GCH。
2. 迭代 ω₂ 步：第 α 步枚举 P_α-名字的潜在 Suslin 树，
   如果存在则用 ccc 力迫破坏它。
3. 迭代的每步是 ccc（有限支撑保持 ccc）。
4. 最终模型 M[G] 满足：2^ℵ₀ = ℵ₂ > ℵ₁ 且一切 Suslin 树
   被杀 → MA_ℵ₁。
5. MA 的完整验证需要更多工作（对一切 ccc 偏序验证）。∎

## 24.5 与 Product Lemma 的比较

Product Lemma（§20）：G 在 P×Q 泛型 ⟺ G = G₁×G₂。
迭代 P*Q 是"先 P 后 Q"的方向性版本——Q 是 P-名字而非
固定的偏序。两者在 Q 不依赖 P 时重合。
