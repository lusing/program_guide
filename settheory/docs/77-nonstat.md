## 77.1 无界闭子集与 κ-完全性

设 κ 是**不可数正则基数**。回顾 71 章（冯琦定义 1.72）：C ⊆ κ 是
**无界闭子集**（club），若

1. **无界**：∀β∈κ ∃α∈C (β<α)；
2. **闭**：对每个非零极限序数 α<κ，若 α∩C 在 α 中无界
   （即 α = ⋃(α∩C)），则 α∈C。

71 章的定理 1.73/1.74 给了第二个面孔：C 是 club 当且仅当 C 是某个
连续严格递增函数 f:κ→κ 的像集；也正因如此，"闭"说的只是**极限点
必须落回来**，与实数拓扑的闭集同构但更简单——κ 上的序拓扑而已。

κ-正则性第一次发力，是把"两个 club 之交仍是 club"推到"少于 κ 个
club 之交仍是 club"。

> **定理 2.23（κ-完全性）** 设 κ 是不可数正则基数，μ<κ，
> (C_α | α<μ) 是 κ 中长度为 μ 的 club 序列。则 ⋂_{α<μ}C_α 也是 club。
>
> *证明* 对 2≤μ<κ 施归纳。**μ=2**：设 C₀,C₁ 是 club，交显然闭；
> 证无界。给定 β∈κ，递归造 ω-序列：
> α₀ = min(C₀∖(β+1))，α₁ = min(C₁∖(α₀+1))，
> α₂ₘ₊₂ = min(C₀∖(α₂ₘ₊₁+1))，α₂ₘ₊₃ = min(C₁∖(α₂ₘ₊₂+1))。
> 每步的最小元存在，因为 club 无界。令 α = supₙαₙ：κ 不可数正则，
> 故 α<κ；C₀ 闭且 α∩C₀ 无界（偶数项共尾于 α），所以 α∈C₀；同理
> α∈C₁。于是 α ∈ C₀∩C₁ 且 α>β。**μ=β+1**：⋂_{α<μ}C_α =
> (⋂_{α<β}C_α)∩C_β，归纳假设加 μ=2 的情形。**μ 极限**：令
> D_α = ⋂_{β<α}C_β；归纳假设给每个 D_α 是 club，且 β<α 时
> D_α⊆D_β，⋂_{α<μ}C_α = ⋂_{α<μ}D_α。闭是显然的；证无界：给定
> β，递归定义 α₀ = min(D₀∖(β+1))，αₙ₊₁ = min(D_{n+1}∖(αₙ+1))，
> 令 α = supₙαₙ。正则性给 α<κ。对每个 p<μ：当 n≥p 时
> αₙ∈Dₙ⊆D_p，故 α∩D_p 无界，D_p 闭给 α∈D_p。于是 α 落在
> 全部 D_p 中。∎

注意证明里"交替乒乓"（zig-zag）的形状：两个 club 轮流往高处跳，
ω 步之后的极限点同时落回两个 club。κ 不可数正则是**极限点不逃出
κ** 的保证；归纳长度 μ<κ 则保证对角化过程中每步还有余地。

> **例 2.11** 对 α<κ 令 C_α = κ∖(α+1)。每个 C_α 都是 club
> （去掉一段有界前缀不影响无界性与闭性），但 ⋂_{α<κ}C_α = ∅。

这个例子说明定理 2.23 的长度限制 μ<κ 不能再放宽：κ 个 club 的交
可以是空的。κ-完全（κ-complete）恰好是"差一步"的完全性——这也预告
了 77.5 节的问题 2.4：κ-完全的超滤子在 κ 上根本不存在。

## 77.2 对角线交与正规性

既然 κ 个 club 的交可以塌掉，就要一种更聪明的"斜着取交"的操作。

> **定义 2.17（对角线交）** 设 κ 是不可数正则基数，(C_α | α<κ) 是
> κ 中 club 序列。定义
> △_{α<κ}C_α = {ξ∈κ | ∀α<ξ (ξ∈C_α)}。

读法：ξ 进入对角线交，当且仅当 ξ 对**它下标以下**的每个 C_α 都
交账——第 ξ 个位置只被前 ξ 个集合投票。每个坐标只承担比自己小的
任务，这正是它比逐点交强壮的原因。

> **定理 2.24（正规性）** 设 κ 是不可数正则基数，(C_α | α<κ) 是
> κ 中 club 序列。则 △_{α<κ}C_α 也是 κ 的 club。
>
> *证明* 第一步换序：令 D_α = ⋂_{β≤α}C_β。定理 2.23 给每个 D_α
> 是 club，且 β<α 时 D_α⊆D_β；关键恒等式
> △_{α<κ}C_α = △_{α<κ}D_α
> 成立，因为"ξ∈D_α 对所有 α<ξ"与"ξ∈C_α 对所有 α<ξ"互相蕴含
> （D_α⊆C_α 给一个方向；反方向用 β≤α<ξ 时 ξ∈C_β 恰好是
> ξ∈D_α 的定义）。于是可设序列单调递减：C_α⊇C_β（α<β）。
>
> **闭**：设 ω≤α=⋃(α∩C)，C = △C_α。对 β<α：由单调性
> (α∩C)∖(β+1) ⊆ C_β，故 α∩C_β 无界，C_β 闭给 α∈C_β；对每个
> β<α 都如此，即 α∈C。**无界**：给定 β∈κ，递归定义
> α₀ = β，αₙ₊₁ = min(C_{αₙ}∖(αₙ+1))，令 α = supₙαₙ。
> 对任意 γ<α，取 n = min{m | γ<αₘ}：当 k≥n+1 时
> γ < αₖ ∈ C_{αₖ₋₁}，而单调性给 C_{αₖ₋₁} ⊆ C_γ（γ<αₖ₋₁？
> 注意 γ<αₙ≤αₖ₋₁），于是 γ∈… 逐层推得 α∈C_γ。故 α∈C。∎

对角线交是 76 章 König 对角线的"滤子版"：König 用第 i 个坐标躲开
第 i 块覆盖，这里用第 ξ 个位置吸收前 ξ 个 club 的义务。逐点交要
ξ 同时属于**所有** C_α（κ 个任务），对角线交只要 ξ 属于前 ξ 个
（<κ 个任务），正则性把差额补齐。

> **例 2.12（典型 club 序列）** 设 κ≥ω₁ 正则，A⊆κ 无界。令
> A′ = {α∈κ | A∩α 在 α 中无界}，
> 则 A′ 是 A 的全体极限点组成的 club（闭：极限点的极限仍是极限点；
> 无界：从任何 β 出发交替在 A 中往高处取 ω 步，极限点即见证）。
> 特别地，κ 中全体非零极限序数之集是 club，而其后继序数集
> Succ(κ) 与它的交为 ∅——后继序数集是非荟萃集。
>
> 在此基础上递归定义 (C_α | α<κ⁺)：C₀ = 非零极限序数集；
> C_{β+1} = C_β′；极限 λ<κ⁺ 处沿 λ 的共尾序列取交或取对角线交
> （cf(λ)<κ 时用 κ-完全性逐点交，cf(λ)=κ 时用定理 2.24）。得到
> 单调递减的 club 序列，C_κ 满足：α∈C_κ 当且仅当 α 是所有
> C_β（β<α）的共同极限点。这列 (C_α | α<κ⁺) 称为 κ 的
> **典型无界闭子集序列**，是后面构造"模 NS 的规范函数塔"的原料。

## 77.3 club 滤子、非荟萃集理想与佛多定理

> **定义 2.18（无界闭集滤子）** 设 κ 是不可数正则基数。
> 𝒢_κ = {X⊆κ | ∃C⊆X，C 是 κ 的 club}，
> 称为 κ 上的**典型滤子**或 club 滤子。

> **定理 2.25** 𝒢_κ 是 κ 上的 κ-完全正规滤子：
> (1) 𝒢_κ 是滤子（含 κ、不含 ∅、向上封闭、有限交封闭）；
> (2) κ-完全：μ<κ 且 (X_α|α<μ)∈𝒢_κ^μ 时 ⋂_{α<μ}X_α∈𝒢_κ；
> (3) 正规：(X_α|α<κ)∈𝒢_κ^κ 时 △_{α<κ}X_α ∈ 𝒢_κ。
>
> *证明* (1) club ⊆ X 的向上封闭显然；(2)(3) 各取见证 club
> C_α⊆X_α，定理 2.23 与 2.24 给 ⋂C_α 与 △C_α 是 club，且分别
> 含于 ⋂X_α 与 △X_α（对角线交对包含单调：ξ∈△C_α 即
> ∀α<ξ ξ∈C_α⊆X_α，故 ξ∈△X_α）。∎

对偶地把"小集合"收进理想：

> **定义 2.19（非荟萃集理想）** NS_κ = {X⊆κ | κ∖X ∈ 𝒢_κ}。
> X∈NS_κ 当且仅当存在 club C 与 X∩C = ∅；这样的 X 叫**非荟萃集**
> （nonstationary）。

κ 的每个有界子集都属于 NS_κ：X⊆β 时 κ∖(β+1) 是 club 且与 X
不交。所以 NS_κ 至少包含"有界 = 有限身影"这一层小集合。

> **定义 2.20（荟萃子集）** S⊆κ 是**荟萃集**（stationary），若
> ∀C∈𝒢_κ (S∩C ≠ ∅)。

荟萃集就是 NS_κ-正测度集：它躲不开任何一个 club。κ 本身、每个
club、Succ(κ) 的补里的极限点集都是荟萃集；有界集、后继序数集
Succ(κ)（与极限点 club 不交）都不是。

club 滤子的正规性有一个对偶的函数形态，就是著名的**佛多引理**
（Fodor， pressing-down lemma）：

> **定理 2.26（选择函数定理 / Fodor）** 设 κ 是不可数正则基数，
> X⊆κ 荟萃，f:X→κ 是**压小函数**（regressive）：∀α∈X∖{0}
> (f(α)<α)。则 f 必在 X 的某个荟萃子集上取常值。
>
> *证明* 反设结论不成立。则对每个 α∈κ，纤维 f⁻¹(α) =
> {β∈X | f(β)=α} 都是非荟萃集。为每个 α 取 club C_α 与
> f⁻¹(α) 不交，令 C = △_{α<κ}C_α——定理 2.24 给 C 是 club。
> X 荟萃，取 β∈X∩C，令 α = f(β)。β<α 不可能（f 压小）；
> 于是 α<β（α=β 被 f(β)<β 排除，0 的情形单独并入常值纤维）。
> 对角线交的定义给 β∈C_α；但 f(β)=α 意味着 β∈f⁻¹(α)，而
> f⁻¹(α)∩C_α = ∅。矛盾。∎

证明的形状值得停一秒：**对角线交把 κ 个"躲避任务"打包进一个
club**，然后一个点 β 同时踩中打包的 club 和自己的纤维——这是 76 章
König 对角线在滤子层面的回声。

> **例 2.13** 压小条件不能丢。令 X = {α+1 | α∈ω₁}∈NS_ω₁，
> f(α+1) = α 是 X 上的**单射**压小函数，每条纤维只有一个点。
> 更一般地，X∈NS_ω₁ 时取 club C∩X=∅，对 0<α∈X 令
> f(α) = max(α∩C) < α，则每条纤维 f⁻¹(β) 有界、因而非荟萃——
> 在非荟萃集上压小函数可以完全不服从佛多。荟萃性正是佛多的
> "正测度"前提。

对偶操作把交换成并：

> **定义 2.21（对角线并）** ∇_{α<κ}X_α = {ξ∈κ | ∃α<ξ (ξ∈X_α)}。

> **推论 2.3** 设 κ 是不可数正则基数。
> (1) μ<κ 且 (X_α|α<μ)∈NS_κ^μ 时 ⋃_{α<μ}X_α ∈ NS_κ——
> NS_κ 是 **κ-可加理想**；
> (2) (X_α|α<κ)∈NS_κ^κ 时 ∇_{α<κ}X_α ∈ NS_κ——NS_κ 对
> 对角线并封闭。
>
> *证明* 取补集：κ∖⋃X_α = ⋂(κ∖X_α)∈𝒢_κ 由定理 2.25(2)；
> κ∖∇X_α = △(κ∖X_α)∈𝒢_κ 由定理 2.25(3)。补集把对角线交和对角
> 线并互换：ξ∈△C_α ⟺ ∀α<ξ (ξ∈C_α) ⟺ ¬∃α<ξ (ξ∉C_α)
> ⟺ ξ∉∇(κ∖C_α)。∎

这条对偶恒等式 κ∖△C = ∇(κ∖C) 是纯粹的逻辑德摩根，Agda 与
Python 通道会对它做机器核对（77.8 节）。

滤子与理想的这套性质可以抽象出来当作定义：

> **定义 2.22** 设 κ 不可数正则，X 是势 ≥κ 的集合，𝔉 是 X 上的
> 滤子，𝔍 是 X 上的理想。
> (1) 𝔉 是 **κ-完全的**：少于 κ 个成员的交仍在 𝔉；
> (2) 𝔍 是 **κ-可加的**：少于 κ 个成员的并仍在 𝔍；
> (3) 𝔉 是**正规的**：∀A∈𝔉⁺（正测度集，即不属于对偶理想的
> 集合），A 上的每个压小函数 f:A→⋃A 都在某个 B∈𝔉⁺ 上取常值；
> (4) 𝔍 正规 ⟺ 其对偶滤子 𝔉* = {A | X∖A∈𝔍} 正规。

> **例 2.14** (1) 𝒢_κ 是 κ-完全正规滤子，NS_κ 是 κ-可加正规
> 理想（定理 2.25、2.26、推论 2.3）。
> (2) 有界子集理想 [κ]^{<κ} = {X⊆κ | |X|<κ} 是 κ-可加的
> （κ 正则：少于 κ 个、每个 <κ 的集合并起来 <κ，76 章定理 2.6(5)），
> 但**不正规**：正测度集 A = {α+1 | α<κ} 上有单射压小函数
> α+1↦α（例 2.13），没有任何正测度子集能让它取常值。

于是 NS_κ 与 [κ]^{<κ} 是两个都 κ-可加、却只有一个正规的理想——
正规性是有内容的额外信息。冯琦接着问：模 NS_κ 几乎处处比较函数，
能爬多高？

> **定理 2.27** 设 κ 是不可数正则基数。存在长度为 κ⁺ 的函数序列
> (f_α | α<κ⁺)，f_α:κ→κ，满足（模 NS_κ 几乎处处）：
> (1) f₀(α)=0；(2) f_{n+1}(α)=f_n(α)+1（n<ω）；
> (3) 极限步 λ：若 λ<κ⁺ 是可数共尾，f_λ(α) = sup_{β<α}(f_λ(β)+1)
> 型的对角极限；一般地存在双射 π:κ→λ 使
> f_λ(α) = ot(π[α])（α 的前 π-像段的序型）。
>
> 这列函数模 NS 严格递增，是 κ^κ/NS 中的"规范序数函数塔"。
> 原书把证明留作练习；思路是用典型 club 序列（例 2.12）把每个
> f_α 定义为"到 C_α 的距离函数"，正规性保证塔不倒。

## 77.4 ω-club 滤子：把共尾度 ω 的序数单独拎出来

κ-完全性在 μ=ω 时最便宜，但 ω 共尾的序数在 κ 中占多大份额？

> **定义 2.23（ω-无界闭子集滤子）** 设 κ 是不可数正则基数。令
> C_ω(κ) = {α<κ | cf(α)=ω}。
> (1) A⊆C_ω(κ) 是 **ω-闭**的：对每个 α∈C_ω(κ)，若 A∩α 在 α 中
> 无界则 α∈A；**ω-无界**：在 C_ω(κ) 中无界（∀β<κ ∃α∈A
> β<α 且 cf(α)=ω）。ω-club = 既 ω-无界又 ω-闭。
> (2) 𝒢_ω(κ) = {A⊆C_ω(κ) | ∃B⊆A，B 是 ω-club}。

> **定理 2.28** 设 κ 是不可数正则基数。
> (1) C_ω(κ) 是 κ 的荟萃集，也是 C_ω(κ) 上的 ω-club；
> (2) 𝒢_ω(κ) 是非平凡的 ω₁-完全滤子；
> (3) 其对偶理想 ℐ_ω(κ) = {A⊆C_ω(κ) | ∃C∈𝒢_κ (C∩C_ω(κ)⊆
> C_ω(κ)∖A)}——即 A 非正测度当且仅当某个 κ-club 与 C_ω(κ) 的交
> 完全躲开 A；
> (4) 𝒢_ω(κ) 是正规滤子。
>
> *证明要点* (1) 荟萃：给定 club C，交替递归 α₀∈C、
> αₙ₊₁∈C∖(αₙ+1)，α=supₙαₙ 有 cf(α)=ω 且 α∈C∩C_ω(κ)。
> ω-闭与 ω-无界按定义直接验证。
> (2) 非平凡：|A|<ω₁ 的有界集 A⊆C_ω(κ) 躲得开——取上界 γ，
> {α∈C_ω(κ) | α>γ} ∈ 𝒢_ω(κ)。ω₁-完全：两个 ω-club 之交是
> ω-club（ω-闭显然；无界用 77.1 的乒乓，但只在 C_ω(κ) 里跳：
> 每步从 A∖(β+1)、B∖(α+1) 交替取，极限 cf=ω 自动落回）；
> ω 个 ω-club (Aₙ) 之交：先化单调 Bₙ = ⋂_{k≤n}A_k，再对
> β 递归 αₙ ∈ Bₙ∖(αₙ₋₁+1)，极限 α 有 cf(α)=ω，且对每个 n，
> 尾段 {αₘ}ₘ≥ₙ ⊆ Bₙ 在 α 中共尾，Bₙ ω-闭给 α∈Bₙ。
> (3) 双向包含：C∈𝒢_κ 时 C∩C_ω(κ) 是 ω-club（(1) 的构造同时
> 给出交的性质）；反过来对 ω-club A 令 A′ = A 的极限点集、
> C_A = {α | ∀β<α ∃γ∈A∩α (β<γ)}，则 C_A 是 κ-club 且
> A′ = C_A∩C_ω(κ) ⊆ A。
> (4) 由 (3)，X∈𝒢_ω(κ)⁺ ⟺ X 是 κ 的荟萃集；对荟萃 X 与
> ω-club A，取 C_A 使 α∈X∩C_A∩C_ω(κ) 存在，压小函数在 X 上的
> 常值纤维由佛多定理给出。∎

把 cf(α)=ω 换成 cf(α)=λ（λ<κ 正则），同样得到 C_λ(κ) 上的
非平凡 λ⁺-完全正规滤子 𝒢_λ(κ)。这一族滤子是共尾度分层研究的
入口：κ 上的"几乎处处"其实按共尾度分成互不干扰的层。

## 77.5 分裂定理与钻石原则

club 滤子有多大？第一个惊人事实：荟萃集可以被**同时撕成 κ 块**。

> **引理 2.11** 令 Λ 为 ω₁ 中全体非零极限序数之集。对每个
> α∈ω₁ 固定 h_α:ω→α 单调递增收敛于 α（cf(α)=ω 的见证序列）。
> 则 ∃n₀∈ω，使 {α∈ω₁ | h_α(n₀) ≥ ξ} 对每个 ξ<ω₁ 都是荟萃集。
>
> *证明* 反设每个 n 都有最小反例 ξₙ 与 club Cₙ ⊆ ω₁∖
> {α | h_α(n)≥ξₙ}。令 ξ = supₙ(ξₙ+1) < ω₁（可数并！），
> C = ⋂ₙCₙ（ω₁-完全性）。C 是 club，取 α∈C 且 α>ξ、cf(α)=ω。
> α∈Cₙ 给 h_α(n)<ξₙ<ξ<α 对所有 n——但 h_α 收敛于 α，矛盾。∎

注意这里的"可数并 < ω₁"就是正则性；反例序列若不可数，sup 就逃出
ω₁ 了。

> **定理 2.29（分裂定理）** 存在 ω₁ 个两两不交的 ω₁ 荟萃集。
>
> *证明* 取引理 2.11 的 n₀，对 ξ<ω₁ 令 X_ξ = {α | h_α(n₀)≥ξ}
> （荟萃集）。递归构造 (S_α, ξ_α | α<ω₁)：
> **起点**：X₀ 荟萃；f(α)=h_α(n₀)<α 是 X₀ 上的压小函数，佛多
> 给出 (S₀,ξ₀)：S₀⊆X₀ 荟萃，f 在 S₀ 上恒取 ξ₀。
> **后继步** α=β+1：ξ_{β+1} > ξ_β，X_{ξ_{β+1}} 荟萃，对压小函数
> 再用佛多，得 S_α⊆X_{ξ_{β+1}} 荟萃、h_α(n₀) 在其上恒取 ξ_α>ξ_β。
> **极限步** α 极限：ξ_α 候选 = sup_{β<α}(ξ_β+1) < ω₁（可数！），
> X_{ρ_α} 荟萃，其中 ρ_α = sup_{β<α}(ξ_β+1)；对 α∈X_{ρ_α} 用
> h_α(n₀) 做压小函数，佛多给常值 ξ_α ≥ ρ_α。
> 每个 S_α 荟萃，且 α∈S_β 时 h_α(n₀)=ξ_β 唯一决定 β——所以
> β≠γ 时 S_β∩S_γ=∅。∎

递归的三种步各用一个工具：佛多负责"榨出常值"，可数性负责"极限步
不逃逸"，n₀ 的存在（引理 2.11）负责"起点合法"。

> **定理 2.30** 设 λ>ω₁ 是不可数正则基数（原书对一般不可数正则
> λ 陈述），则 C_ω(λ) = {α<λ | cf(α)=ω} 是 λ 个两两不交的
> λ-荟萃集之并。证明与 2.29 逐字平行，把 ω₁-完全性换成
> 𝒢_ω(λ) 的 ω₁-完全性（定理 2.28）。

于是 C_ω(λ) 被**均匀地**撕成 λ 块——每块和整体一样"大"（都荟萃）。
这直接回答"club 滤子是不是超滤子"：不是，而且差得远。

> **问题 2.3** ω₁ 上是否存在 ω₂ 个模 NS_ω₁ 几乎处处不交的荟萃集？
> 若不存在，称 NS_ω₁ **饱和**。这个问题的答案独立于 ZFC，而且
> "NS_ω₁ 饱和"是一种大基数性质（第三卷内容）——一个关于 ω₁ 的
> 组合问题把宇宙推到大基数门口，这是 20 世纪集合论的典型剧情。

在一个独立于 ZFC 的公理下，问题 2.3 有肯定回答：

> **定义 2.24（钻石序列）** (S_α | α<ω₁)（每个 S_α⊆α）是**钻石
> 序列**，若 ∀X⊆ω₁，{α<ω₁ | X∩α = S_α} 是荟萃集。
> **钻石原则 ♦**：存在钻石序列。Jensen 证明 ♦ 在 L 中成立，故 ♦
> 与 ZFC 相对一致。

♦ 的内容是：一个 ω₁-长度的猜测序列，对**每个** X⊆ω₁ 都在荟萃多
（比无界强得多）的位置上猜中 X 的初始段。

> **定理 2.31** 假设 ♦。则 ω₁ 上存在 2^{ℵ₁} 个模 NS_ω₁ 几乎处处
> 不交的荟萃集。
> *证明* 取钻石序列 (S_α)。对 X⊆ω₁ 令 T_X = {α | X∩α = S_α}
> （荟萃）。X≠Y 时令 ξ = min(X△Y)：α∈T_X∩T_Y 给
> X∩α = S_α = Y∩α，故 α≤ξ，即 T_X∩T_Y ⊆ ξ+1 有界——两两
> 模 NS 不交。X↦T_X 单射，共 2^{ℵ₁} 个。∎
>
> **定理 2.32** 假设 ♦。则 CH 成立。
> *证明* T_X 荟萃故非空，取 g(X) = min(T_X)：S_{g(X)} =
> X∩g(X) 唯一决定 X∩g(X)；X≠Y ⟹ g(X)≠g(Y)（否则同一 S_β
> 同时等于 X∩β 与 Y∩β）。g:𝒫(ω)→ω₁ 单射，2^{ℵ₀}≤ℵ₁，
> 加 Cantor 得 CH。∎

♦ 只谈 ω₁ 上的猜测，却顺手决定了连续统的大小——钻石比它的外表
锋利得多。

> **问题 2.4** ω₁ 上是否存在 ω₁-完全的超滤子 𝒰 ⊇ 𝒢_ω₁？
> （ω₁-完全：可数个成员的交仍在 𝒰。）
>
> *解答（ZFC 内否定）* 设 𝒰 是 ω₁ 上的非平凡 ω₁-完全超滤子。
> 取 X 为 ω→{0,1} 的函数集中势为 ℵ₁ 的子集（2^{ℵ₀}≥ℵ₁ 时存在；
> 若 2^{ℵ₀}=ℵ₁ 直接取全部），H:X→ω₁ 双射，把 𝒰 搬运成 X 上的
> ω₁-完全超滤子 𝒱 = {A⊆X | H[A]∈𝒰}。对每个 n<ω，二分的两块
> X_n⁰ = {f∈X | f(n)=0}、X_n¹ = {f∈X | f(n)=1} 恰有一个属于
> 𝒱，记 εₙ ∈{0,1} 为选中的那支。令 Y = ⋂ₙX_n^{εₙ}：ω₁-完全性
> 给 Y∈𝒱，特别地 Y≠∅，取 f∈Y。但 f 由它的坐标序列完全决定，
> 而坐标被 (εₙ) 钉死——至多一个 f 能属于 Y，|Y|≤1。Y 至多一个
> 元素与 𝒱 非平凡矛盾。∎

这个证明的结构（可数个二分交出一个至多单点的集合）正是"超滤子的
完全性不能超过底集的大小"的原型。问题 2.5 顺势而立：**是否存在
不可数基数 κ，其上有非平凡的 κ-完全超滤子？** 答案（存在这样的
κ = 可测基数）把集合论带进大基数宇宙——29 章已经从 Jech 路线讲过
它，这里看到的是它从 ω₁ 滤子理论里长出来的必然性。

## 77.6 广义无界闭子集 I：可数子集空间 [X]^ω

现在做冯琦路线的招牌推广。先看一个把 club 从"序数拓扑"里解放出来
的事实：

> **事实** 设 κ 是不可数正则基数，f:κ→κ，g:[κ]^{<ω}→κ。则
> (1) C_f = {α<κ | ∀β<α (f(β)<α)} 是 club；
> (2) C_g = {α<κ | ∀e∈[α]^{<ω} (g(e)<α)} 是 club；
> (3) f 单调连续时 C_f = {α | f(α)=α}（不动点集）。
>
> *证明* (1) 闭：α∩C_f 无界时，对 β<α 取 β<γ∈α∩C_f，
> f(β)<γ<α，故 α∈C_f。无界：给定 β，α₀ = sup(f[β+1]∪{β+1})，
> αₙ₊₁ = sup(f[αₙ+1]∪{αₙ+1})，α=supₙαₙ <κ（正则），对 γ<α
> 取大 n 使 γ<αₙ，f(γ)<αₙ₊₁≤α。(2) 同型，只是每步要对有限子集
> e⊆αₙ 关闭：αₙ₊₁ = sup(g[[αₙ+1]^{<ω}]∪{αₙ+1})，可数并不逃 κ。
> (3) α∈C_f 时 β<α ⟹ β≤f(β)<α，连续性给 f(α)=sup_{β<α}f(β)=α；
> 反向 f(α)=α 且 β<α 时 f(β)<f(α)=α。∎

结论：**club = 某函数的闭包点集**。无界闭与"序数上的拓扑"没有
本质纠缠——它只是"对某个操作封闭且够大"。操作可以搬到任何不可数
集合上。第一个目的地是可数子集空间：

> **定义 2.25** 设 X 是不可数集合，[X]^ω = {A⊆X | |A|=ℵ₀}。
> (1) C⊆[X]^ω **无界**：∀a∈[X]^ω ∃b∈C (a⊆b)；
> (2) C **闭**：C 中任意 ⊆-单调递增 ω-序列 a₀⊆a₁⊆… 的并
> ⋃ₙaₙ ∈ C；
> (3) C 是 [X]^ω 的 **club**：既无界又闭；
> (4) S⊆[X]^ω **荟萃**：与每个 club 相交。

> **例 2.15** 关键观察：每个可数序数 α 本身就是 ω₁ 的一个可数子集
> （冯·诺依曼记法 α={β|β<α}），于是 ω₁ 天然嵌入 [ω₁]^ω，可把序数
> club 看作空间 club 的特例。在这一认同下：
> (1) **ω₁∖ω = {α∈ω₁ | α≥ω} 是 [ω₁]^ω 的 club**。无界：给 a∈[ω₁]^ω，
> 取 β=(sup a)+ω，则 β 是可数无穷序数（β∈ω₁∖ω），且 a⊆β（a 的每个
> 元素 <sup a<β）。闭：ω-链 α₀⊆α₁⊆… 之并 = supₙαₙ 仍是可数无穷序数。
> (2) **C⊆ω₁∖ω 是 ω₁ 的（序数意义）club ⟺ C 是 [ω₁]^ω 的 club**。
> ⇒：无界性——给 a∈[ω₁]^ω，sup a∈ω₁，C 序数无界给出 γ∈C、sup a≤γ，
> 则 a⊆γ∈C；闭性——[ω₁]^ω 中 ⊆-链的并即序数极限，C 序数闭即含之。
> ⇐：把 [ω₁]^ω 的无界/闭限制在"序数形"成员上即得序数 club 条件。
> (3) **S⊆ω₁∖ω 在 ω₁ 中荟萃 ⟺ S 在 [ω₁]^ω 中荟萃**。⇒：给空间
> club C，交 C∩(ω₁∖ω) 仍是空间 club（定理 2.33(1) 的可数交——其实
> 二元交就够），它含于 ω₁∖ω，由 (2)⇐ 是序数 club；S 序数荟萃给
> S∩C∩(ω₁∖ω)≠∅。⇐：给序数 club D，D∖ω⊆ω₁∖ω 仍是序数 club
> （去掉有界集 ω 不伤无界与闭），由 (2)⇒ 是空间 club，S 空间荟萃给
> S∩(D∖ω)≠∅。故 ω₁ 上的非荟萃集理想 NS_{ω₁} 正是空间 NS 在序数
> 上的限制——本章前六节的序数理论是广义理论 X=ω₁ 的实例。

闭性有一个看起来更强、用起来更顺的等价形态：

> **引理 2.12** C⊆[X]^ω 闭 ⟺ C 的每个可数**共顶**子集 D
> （∀A,B∈D ∃C∈D (A∪B⊆C)）满足 ⋃D∈C。
> *证明* ⇐ 显然（链是共顶的）。⇒：设 D = {Aₙ | n<ω} 可数共顶。
> B₀=A₀；给定 Bₙ，取 k = min{m | Bₙ∪Aₙ₊₁ ⊆ Aₘ}，Bₙ₊₁=A_k。
> 共顶性保证 k 存在。则 Bₙ⊆Bₙ₊₁ 且 ⋃ₙBₙ = ⋃D，闭性给
> ⋃D∈C。∎

> **定理 2.33** 设 X 是不可数集合。
> (1)（ω₁-完全性）(Cₙ|n<ω) 是 [X]^ω 的 club 序列，则 ⋂ₙCₙ 是 club；
> (2)（正规性）(C_a | a∈X) 是以 X 为指标、取值 [X]^ω-club 的
> 函数，则对角线交
> △{C_a | a∈X} = {A∈[X]^ω | ∀a∈A (A∈C_a)}
> 是 club；
> (3)（佛多）S⊆[X]^ω 荟萃，f:S→X 是选择函数（f(A)∈A），则 f
> 在 S 的某个荟萃子集上取常值。
>
> *证明* (1) 两个 club 之交：给定 A，交替递归 A⊆A₀∈C₁、
> A₀⊆B₀∈C₂、Bₙ⊆Aₙ₊₁∈C₁、Aₙ₊₁⊆Bₙ₊₁∈C₂，B=⋃Aₙ=⋃Bₙ
> 可数、含于 C₁∩C₂。ω 个：化单调 Dₙ=⋂_{k≤n}C_k，对递增序列取
> 并逐层验证（引理 2.12 的形状）。
> (2) 闭：A₀⊆A₁⊆… 都在 △C 中，A=⋃Aₙ；对 a∈A 取 m 使
> a∈Aₘ，则 n≥m 时 Aₙ∈C_a，链并 A∈C_a。无界：给定 A₀，递归
> Aₙ₊₁ = ⋃{B(n,a) | a∈Aₙ}，其中 B(n,a)∈C_a 覆盖 Aₙ（无界性）；
> Aₙ₊₁ 是可数并可数。A=⋃Aₙ 对每个 a∈A：链 B(0,a)⊆A₁⊆
> B(1,a)⊆… 的并是 A，闭性给 A∈C_a。
> (3) 反证：每个 T_a = {A∈S | f(A)=a} 非荟萃，取 club C_a 避开
> 它；C = △{C_a} 是 club，取 A∈S∩C，a=f(A)∈A：A∈C_a（对角
> 线交），又 A∈T_a——与 C_a∩T_a=∅ 矛盾。∎

对照 77.2/77.3：三条性质一字不差地平行于序数版定理 2.23/2.24/2.26，
只是"β<α"换成了"a∈A"，"sup"换成了"⋃"。这就是"club 的本质是
闭包点"的第一次兑现。

再把"函数闭包"搬进来：

> **定义 2.26（可数子代数）** 设 X 不可数，f:[X]^{<ω}→X。令
> C_f = {A∈[X]^ω | ∀e∈[A]^{<ω} (f(e)∈A)}，
> 称 C_f 的成员为代数 (X,f) 的**可数子代数**。
>
> **引理 2.13** C_f 是 [X]^ω 的 club。
> *证明* 闭：递增链的并对有限子集 e（落在某节 Aₙ）封闭。无界：
> 给定 A₀，Aₙ₊₁ = Aₙ ∪ {f(e) | e∈[Aₙ]^{<ω}}——可数并不逃；
> A=⋃Aₙ 对每个有限 e⊆A（e⊆Aₙ）有 f(e)∈Aₙ₊₁⊆A。∎
>
> **引理 2.14** f:[X]^{<ω}→[X]^ω 时 D_f = {A∈[X]^ω |
> ∀e∈[A]^{<ω} (f(e)⊆A)} 也是 club。（证明同型，练习。）

于是 club 与代数闭包互为表里：

> **定理 2.34（Jech）** 设 X 不可数，C⊆[X]^ω 是 club。则存在
> f:[X]^{<ω}→X 使 C_f ⊆ C。
>
> *证明思路* 不妨 X=λ 基数。第一步：对每个 e∈[λ]^{<ω} 选
> G(e)∈C，e⊆G(e)，且 e₁⊆e₂ ⟹ G(e₁)⊆G(e₂)（按 |e| 归纳，
> 每步用 C 的无界性覆盖已定的可数个 G(a)，a∈[e]^{≤n}）。
> **断言一** D_G ⊆ C：A∈D_G 时枚举 A={aₙ}，eₙ={a_k|k≤n}，
> A = ⋃ₙG(eₙ) 是 C 中递增链之并。
> 第二步：把每个可数集 G(e) 编码成单变量函数。固定枚举
> h_e:ω→G(e)，g_k(e)=h_e(k)；用配对双射 π:ω≅ω×ω 定义
> f:[λ]^{<ω}→λ：f({α})=α+1（保证后继在闭包内）；对
> e={α₀<…<αₘ}，令 n=π(k,m+1)，用 max(e)+1,…,max(e)+(n−m)
> 把 e 垫长到 n 个元素，f(e∪垫片) = g_k(e)——垫片元素可由 f({α})
> =α+1 逐次生成，所以 A∈C_f 时垫片也在 A 中。
> **断言二** C_f ⊆ D_G：A∈C_f 时每个 G(e)（e⊆A 有限）的全部
> 枚举值 g_k(e) 都是 f 在 A 的有限子集上的值，落在 A 中，故
> G(e)⊆A，A∈D_G。合起来 C_f ⊆ D_G ⊆ C。∎

> **推论 2.4** S⊆[X]^ω 荟萃 ⟺ 每个代数 (X,f) 都有可数子代数
> A∈S（即 f[[A]^{<ω}]⊆A）。
> *证明* ⇒：C_f 是 club，S∩C_f≠∅。⇐：每个 club C 由定理 2.34
> 含某个 C_f，而 S 里有 C_f 的成员。∎

"荟萃 = 躲不开任何可数子代数"——这是模型论里"子结构存在性"的
集合论原型，力迫与大基数理论里反复出现。

## 77.7 广义无界闭子集 II：提升降落与理想空间 P_κ(λ)

> **定义 2.27（提升与降落）** 设 X⊆Y 不可数。
> D⊆[X]^ω 的**提升** D↑Y = {A∈[Y]^ω | A∩X∈D}；
> D⊆[Y]^ω 的**降落** D↓X = {A∩X | A∈D}∩[X]^ω。

> **定理 2.35** 设 X⊆Y 不可数。
> (1) [X]^ω 的 club 提升后是 [Y]^ω 的 club；从而 [Y]^ω 的荟萃集
> 降落后是 [X]^ω 的荟萃集；
> (2) [Y]^ω 的 club 降落后**包含** [X]^ω 的 club；从而 [X]^ω 的
> 荟萃集提升后是 [Y]^ω 的荟萃集。
> *证明* (2) 的构造：C 是 [Y]^ω 的 club，定理 2.34 取 f 使
> C_f⊆C；对 e∈[Y]^{<ω} 令 G(e) = e 在 f 下的闭包（可数），
> D_G 是 club（引理 2.14）且 D_G⊆C_f。令
> D = {A∈[X]^ω | ∀e∈[A]^{<ω} (G(e)∩X⊆A)}：A∈D 时取 A 在
> f 下的闭包 B，B∈D_G 且 B∩X=A，故 A∈D_G↓X⊆C↓X。∎

提升降落是"大小空间之间搬运荟萃性"的桥，后面力迫篇（第八篇）里
它会以 elementary substructure 的面目再次登场。

最后的推广把"可数"换成"<κ"：

> **定义 2.28（理想空间）** 设 κ 是不可数正则基数，λ≥κ。
> P_κ(λ) = [λ]^{<κ} = {X⊆λ | |X|<κ}——这是 κ-可加理想
> ℐ_{[κ]}(λ) 的成员空间（κ=ω₁ 时就是 [λ]^ω 的放大版）。
> (a) X⊆P_κ(λ) **无界**：∀a∈P_κ(λ) ∃b∈X (a⊆b)；
> (b) X **闭**：对每个 α<κ，X^α 中每个 ⊆-单调递增序列 f
> （∀ξ<η<α (f(ξ)⊆f(η))）满足 ⋃rng(f)∈X；
> (c) club = 无界 + 闭；(d) 荟萃 = 与每个 club 相交；
> (e) club 滤子 𝒢(κ,λ) = {X⊆P_κ(λ) | ∃C⊆X，C 是 club}。

λ=κ 时 P_κ(κ) 上的 ⊆-递增与 <-递增重合，回到序数版；κ=ω₁ 时回到
[X]^ω。这是 Jech 首先完成的推广：

> **定理 2.36（Jech）** 𝒢(κ,λ) 是 κ-完全的，且对**主对角线交**
> 封闭：(C_a | a∈P_κ(λ)) 是 club 族时
> △_{a∈P_κ(λ)}C_a = {X∈P_κ(λ) | ∀a∈X (X∈C_a)}
> 也是 club。
>
> *证明* (a) 两个 club 之交：交替递归 a⊆c₀∈C、c₀⊆d₀∈D、
> d₀⊆c₁∈C、…，并 ⋃cₙ=⋃dₙ 是 <κ 个 <κ 之并（κ 正则），
> 属于 C∩D（闭性对 ω-链已够）。
> (b) 长度 μ<κ 的交：对 μ 归纳。后继步用 (a)；极限步令
> D_β=⋂_{ξ<β}C_ξ（单调递减），给定 a 递归 α_ξ ∈ D_ξ 递增
> （ξ<μ），并 ⋃_{ξ<μ}α_ξ 势 <κ（μ<κ、每步 <κ、κ 正则），
> 且属于每个 D_β（β 之后的尾段全在 D_β 中）。
> (c) 主对角线交 D：闭——⟨c_ξ | ξ<α⟩ 递增链在 D 中，
> c=⋃c_ξ；对 a∈c 取 ξ 使 a∈c_ξ，尾段全在 C_a 中，c∈C_a。
> 无界——给定 a∈P_κ(λ)：a∈P_κ(λ) 时 ⋂_{b∈a}C_b 是 club
> （|a|<κ，(a)），递归 a⊆e₀、eₙ⊆eₙ₊₁∈⋂_{b∈eₙ}C_b，
> y=⋃ₙeₙ：对 a′∈y 取 n 使 a′∈eₙ，则 m≥n+1 时 eₘ∈C_{a′}，
> 闭性给 y∈C_{a′}。∎

> **推论 2.5** T⊆P_κ(λ) 荟萃且 ∅∉T，则 T 上任何选择函数
> f:T→⋃T（f(x)∈x）都在 T 的某个荟萃子集上取常值。
> *证明* 与定理 2.33(3) 逐字平行：反设每个纤维非荟萃，取避开的
> club C_a，主对角线交 D 是 club，取 x∈D∩T，a=f(x)∈x 给
> x∈C_a 与 x∉C_a 的矛盾。∎

> **命题 2.2（强 club）** 设 |A|≥κ，f:[A]^{<ω}→A，则
> D_f = {X∈P_κ(A) | ∀e∈[X]^{<ω} (f(e)∈X)}
> 是 club——而且是**强** club：由单个有限元操作生成。证明同引理
> 2.13：Xₙ₊₁ = Xₙ∪f[[Xₙ]^{<ω}]，并 ⋃Xₙ 势 <κ（κ 正则）。

强 club 与 club 何时重合？κ=ω₁、A=ω₁ 时两者一致（例 2.15 的
对应）；λ 更大时就分家了：

> **例 2.16** κ=ω₁、λ=ω₂：[ω₂]^ω = {x∈P_{ω₁}(ω₂) | |x|=ω}
> 是 P_{ω₁}(ω₂) 的 club（闭：ω-链之并可数；无界：任何可数 a 可以
> 扩充成可数 b⊇a——平凡），但它的补 {x | |x|<ω}（有限集）不含任何
> 强 club D_f：D_f 的成员对 f 封闭，从任何单点出发迭代 f 就生成
> 可数无穷闭包，必与 [ω₂]^ω 相交，故有限集之族 [ω₂]^{<ω} 不含任何
> 强 club。结论：[ω₂]^{<ω} 是 P_{ω₁}(ω₂) 的非荟萃集（它与 club
> [ω₂]^ω 不交），而强 club 概念在 λ>κ 时
> 严格强于 club——𝒢(κ,λ) 会"聚集"在 [λ]^κ 附近，这种聚集正是
> 超紧基数定义的舞台（35 章从 Jech 路线见过它）。

## 77.8 机器通道：七台机器上的滤子

### Lean/mathlib：IsClub 与 IsStationary 的官方锚点

钉版 mathlib（4.33.1）在 `Mathlib.SetTheory.Cardinal.Cofinality.Club`
里有完整的 club/平稳集开发：`IsClub` 把"闭"表述成 `DirSupClosed`
（有向上确界封闭），把"无界"表述成 `IsCofinal`；`IsStationary`
定义为与每个 club 相交。教程把本章的定理逐条挂上去：

```lean
import Mathlib.SetTheory.Cardinal.Cofinality.Club

open Cardinal Order Set

namespace Settheory.Ch77

universe u v

variable {α : Type v} [LinearOrder α] {s t : Set α}

/-- 定义 2.18 的成员资格：club 就是无界闭集。mathlib 的 IsClub
    拆成 DirSupClosed + IsCofinal 两个字段。注意 IsClub.nonempty 需要
    Nonempty α：否则 α = PEmpty 时 ∅ 也满足 club 的两条而结论为假。 -/
theorem isClub_iff_unbounded_closed [Nonempty α] [WellFoundedLT α]
    (hs : IsClub s) : s.Nonempty ∧ IsCofinal s :=
  ⟨hs.nonempty, hs.isCofinal⟩

/-- 定理 2.23 的可数片段：cof α ≠ ℵ₀ 时可数个 club 之交仍是 club。
    mathlib 甚至有任意少于 cof α 个的版本 IsClub.sInter。 -/
theorem countable_inter_isClub [WellFoundedLT α] {f : ℕ → Set α}
    (hα : cof α ≠ ℵ₀) (hf : ∀ n, IsClub (f n)) : IsClub (⋂ n, f n) :=
  IsClub.iInter_of_countable hα hf

/-- 71 章定理 1.73 的官方形态：正规函数（单调连续）的像是 club。 -/
theorem club_range_of_isNormal [WellFoundedLT α] {f : α → α}
    (hf : IsNormal f) : IsClub (.range f) :=
  Order.IsNormal.isClub_range hf

/-- 77.6 节"事实"(3) 的官方形态：cof α ≠ ℵ₀ 时正规函数的不动点集
    是 club。 -/
theorem club_fixedPoints [WellFoundedLT α] {f : α → α}
    (hα : cof α ≠ ℵ₀) (hf : IsNormal f) : IsClub f.fixedPoints :=
  Order.IsNormal.isClub_fixedPoints hα hf

/-- 逆方向：club 集的枚举函数是正规函数——"C 是 club ⟺ C 是连续
    递增函数的像"的 mathlib 形态（要求 α 是正则基数序，且 < 良基；
    IsRegularCardinalOrder 只把 WellFoundedLT 当参数、不自动供给实例）。 -/
theorem isNormal_enum_of_isClub [WellFoundedLT α] [IsRegularCardinalOrder α] {s : Set α}
    (hs : IsClub s) : IsNormal (Subtype.val ∘ enum s hs.isCofinal) :=
  IsClub.isNormal_enum hs

/-- 定理 2.25 的对偶：club 是荟萃集。 -/
theorem club_isStationary [Nonempty α] [WellFoundedLT α]
    (hα : cof α ≠ ℵ₀) (hs : IsClub s) : IsStationary s :=
  IsClub.isStationary hα hs

/-- 非荟萃 = 被某个 club 躲开：定义 2.19 的对偶刻画。 -/
theorem not_isStationary_iff_disjoint (s : Set α) :
    ¬ IsStationary s ↔ ∃ t, IsClub t ∧ Disjoint s t :=
  not_isStationary_iff

/-- 推论 2.3(1) 的对偶：少于 cof α 个集合之并荟萃 ⟺ 有一个荟萃。
    取补即"NS 是 κ-可加理想"。指标类型 ι 与底空间 α 可能住在不同
    宇宙，故势的比较要经 Cardinal.lift 抬到同一宇宙。 -/
theorem isStationary_iUnion_iff' [WellFoundedLT α] {ι : Type u}
    {f : ι → Set α} (hα : cof α ≠ ℵ₀) (hι : lift.{v} #(ι) < lift.{u} (cof α)) :
    IsStationary (⋃ i, f i) ↔ ∃ i, IsStationary (f i) :=
  isStationary_iUnion_iff hα hι
```

`iInter_of_countable` 是定理 2.23 的 μ≤ω 片段；完整的"少于 cof α
个"版本 `IsClub.sInter` 也在库里，它的证明用的正是正文的乒乓构造
（`Nat.rec` 交替取上确界）。这条 `isStationary_iUnion_iff'` 逼出两处
mathlib 与直觉的缝隙：`IsClub.nonempty` 要 `Nonempty α`（空型上 `∅`
也是 club），`isStationary_iUnion_iff` 的势比较要写成 `lift.{v} #(ι) <
lift.{u} (cof α)` 显式对齐宇宙——直接写 `#(ι) < cof α` 会卡在宇宙约束
上。mathlib **没有**对角线交与 Fodor 引理——定理 2.24/2.26 由
Coq/Agda/Prolog 的有限模型与下面的 Isabelle 通道分担。

### Isabelle/ZF：在 ZF 对象逻辑里手工搭 club 理论

ZF 库没有滤子与 club（那是 HOL 侧资产），ST77 会话从零定义五个概念
并证明四件事。定义部分：

```isabelle
definition Unbounded :: "[i,i] \<Rightarrow> o" where
  "Unbounded(K,C) \<equiv> C \<subseteq> K \<and> (\<forall>b\<in>K. \<exists>a\<in>C. b < a)"

definition Closed :: "[i,i] \<Rightarrow> o" where
  "Closed(K,C) \<equiv> \<forall>a\<in>K. a \<noteq> 0 \<and> a = \<Union>(a \<inter> C) \<longrightarrow> a \<in> C"

definition IsClub :: "[i,i] \<Rightarrow> o" where
  "IsClub(K,C) \<equiv> Unbounded(K,C) \<and> Closed(K,C)"

definition Stationary :: "[i,i] \<Rightarrow> o" where
  "Stationary(K,S) \<equiv> S \<subseteq> K \<and> (\<forall>C. IsClub(K,C) \<longrightarrow> S \<inter> C \<noteq> 0)"

definition DiagInt :: "[i,i] \<Rightarrow> i" where
  "DiagInt(K,Cf) \<equiv> {x \<in> K. \<forall>a \<in> x. x \<in> Cf`a}"
```

`Closed` 的条件带 `a ≠ 0`：正文 77.1 解释过，0 = ⋃(0∩C) 恒真，
若不排除 0 会把"0∈C"强加给每个 club，κ∖(β+1) 这类基本例子就全灭。
这是把冯琦定义 1.72 落进机器时发现的第一个缝隙。

会话证三件事。**第一件：κ 自己是 club。** 无界性 `unbounded_K` 只需
`Limit(K)`——对任意 `b ∈ K`，极限序数吸收后继（`Limit_has_succ`），
故 `succ(b) ∈ K` 且 `b < succ(b)`：

```isabelle
lemma unbounded_K: "Limit(K) ⟹ Unbounded(K,K)"
lemma closed_K: "Closed(K,K)"
lemma K_is_club: "Limit(K) ⟹ IsClub(K,K)"
```

闭性 `closed_K` 平凡（`a = ⋃(a∩K)` 时 `a ∈ K` 已是假设），二者合成
`K_is_club`。**第二件：两个闭集之交仍闭**——这是定理 2.23 在 μ=2 时的
"闭"一半。夹逼是全部难点：由 `a = ⋃(a∩(C0∩C1))`，因 `a∩(C0∩C1) ⊆
a∩C0 ⊆ a`，取并（`Union_mono`）再用 `a` 是序数（`Ord_Union_subset`：
`⋃(a) ⊆ a`），三段夹成 `a = ⋃(a∩C0)`，于是 `C0` 的闭性给 `a ∈ C0`；
对 `C1` 同理，合成 `a ∈ C0 ∩ C1`：

```isabelle
lemma closed_inter_closed:
  "⟦Ord(K); Closed(K,C0); Closed(K,C1)⟧ ⟹ Closed(K, C0 ∩ C1)"

lemma club_inter_closed:
  "⟦Ord(K); IsClub(K,C0); IsClub(K,C1)⟧ ⟹ Closed(K, C0 ∩ C1)"
```

会话**只**做实闭性这一半：定理 2.23 完整的"少于 cof κ 个 club 之交仍是
club"还需要无界性，那是交替取上确界的乒乓构造，mathlib 的 `IsClub.sInter`
已完整承担（见上一节），ZF 会话不重复造轮子。**第三件：对角线交的
成员判定**——`DiagInt` 落在 `K` 内，且 `x ∈ DiagInt(K,Cf)` 当且仅当
`x ∈ K` 且每个 `a ∈ x` 处都有 `x ∈ Cf`a`：

```isabelle
lemma DiagInt_subset: "DiagInt(K,Cf) ⊆ K"
lemma DiagInt_mem_iff:
  "x ∈ DiagInt(K,Cf) ⟷ x ∈ K ∧ (∀a ∈ x. x ∈ Cf`a)"
```

对角线交的无界性（定理 2.24）与 Fodor 引理（定理 2.26）需要正则性与
pressing-down 论证，交给下面的 Coq/Agda/Prolog 有限模型分担。

### Coq：对角线对偶、有限正规性与例 2.11 的机器见证

Coq 通道证明三个**真定理**（不是模拟）。第一，对角线交/并的德摩根
对偶（推论 2.3 的补集恒等式），对任意谓词序列 C 与任意位置 i：

```coq
Definition inDiagInt (C : nat -> nat -> bool) (i : nat) : Prop :=
  forall j, j < i -> C j i = true.

Definition inDiagUn (X : nat -> nat -> bool) (i : nat) : Prop :=
  exists j, j < i /\ X j i = true.

Theorem diag_demorgan : forall C i,
  inDiagInt C i <-> ~ inDiagUn (fun j k => negb (C j k)) i.
```

补集写成 `fun j k => negb (C j k)`（逐位取反），证明就是"全称 ⟺ 否定
存在"的布尔版：正向对 `⟨j,⟨Hj,Hneg⟩⟩` 用 `H j Hj` 得 `C j i = true`
与 `negb (C j i) = true` 冲突；反向对 `C j i` 分类，取 `false` 时把
`⟨j,Hj⟩⟩` 塞进 `inDiagUn` 制造矛盾。第二，**有限正规性**：在有限序数
模型 n 里，"club = 含顶点 n−1"，则每个 C_j 含顶点时对角线交也含顶点
——定理 2.24 在有限截断上的真实缩影：

```coq
Theorem diag_top : forall n C,
  0 < n -> (forall j, j < n - 1 -> C j (n - 1) = true) ->
  inDiagInt C (n - 1).
```

第三，例 2.11 的见证：ω 上尾集族 C_k(i)=(i>k) 每个都"无界"，但全体
之交为空——机器给出逃逸点构造 i ↦ k=i。成员判定用 `inTail k i = negb
(i ≤? k)`（即 i>k）：

```coq
Definition inTail (k i : nat) : bool := negb (leb i k).

Theorem tail_clubs_empty_inter : forall i, exists k, inTail k i = false.
Theorem tail_unbounded : forall k, exists i, inTail k i = true.
```

（`inTail i i = negb (i ≤? i) = negb true = false`，取 k=i 即逃逸；
`inTail k (S k) = true` 见证无界。）这正是"长度限制不能放宽到 κ"的
可计算内核。

### Agda：对偶恒等式的构造性证明

Agda 把 Coq 的第一条定理做成构造性的：成员资格用递归谓词定义，
`memΔ` 沿 i 归纳（0 处平凡真，suc i 处要求 C i (suc i) 与递归），
`mem∇` 对偶地用 ⊎。德摩根对偶是两个显式函数（正反方向），不需要
排中律：

```agda
memΔ : (ℕ → ℕ → Bool) → ℕ → Set
memΔ C 0 = ⊤
memΔ C (suc i) = (C i (suc i) ≡ true) × memΔ C i

demorgan₁ : ∀ C i → memΔ C i → mem∇ (¬∘ C) i → ⊥
demorgan₂ : ∀ C i → notΔ C i → mem∇ (¬∘ C) i
```

并给出具体计算例：C_k(i) = (k ≤ᵇ i)（尾集）在 i=3 处的对角线交
成员资格逐位验证为真——Agda 的类型检查就是计算。

### Julia/Python：ω 处的死亡实验与有限佛多

Julia 通道做两个"定理在 ω 处失效"的数值实验加一个闭包构造。**实验
一**（例 2.11）：C_k = {i>k} 在 ω 上每个都无界闭（ω 内没有非零
极限点，闭性空虚真），但 ⋂C_k=∅——程序对每个 i≤10^5 输出逃逸指标
k=i。**实验二**（正规性之死）：C_k = (k+1) 的倍数之集，每个在 ω 上
无界闭；对角线交 ΔC = {i : ∀k<i, (k+1)! | i} 数值算到 10^6 只有
{0,1,2}——有限！定理 2.24 在 κ=ω 处失败，失败原因就是 κ-完全性
没了。**实验三**（引理 2.13 的闭包构造）：f(e) = (Σe) mod 7 在
{0..9} 上，从种子 {3,5} 迭代 A_{n+1} = A_n ∪ {f(e) : e ⊆ A_n}，
2 步内到达不动点 {0,1,…,6}=Z_7（验证 ∀e⊆A: f(e)∈A），机器复演"C_f
无界"的证明步骤——Z_7 是域，任何含非零元的加法闭子集只能是全体，
所以只要种子里有两个不共线的元，闭包两步就撑满。

Python 通道对有限模型 n≤7 做**全枚举**验证：(1) 有限 club 滤子公理
（club = 含顶点集族：向上封闭、交封闭、∅ 不属于）；(2) 德摩根对偶
κ∖ΔC = ∇(κ∖C) 对 20000 个随机谓词序列逐点断言（与 Agda 的构造性
证明互为核对）；(3) 推论 2.3(2) 的有限影：n=4 时对全部 2^16 个序列
验证"每个 X_α 不含顶点 ⟹ ∇X 不含顶点"；(4) 有限佛多：对每个含顶点
的 S 与每个压小函数 f:S→n，验证 {顶点} 是 f 取常值的荟萃子集——
平凡，但恰好演示"有限模型里佛多没有内容"，它的牙齿要等 ω₁。

### Prolog：对角线交搜索与压小函数纤维

Prolog 把 Δ 的成员判定写成生成器-检验器：给定 n 与 club 序列
（列表的列表），`diag_members/3` 搜索所有 ξ 使 ∀j<ξ member(ξ,C_j)；
`fodor_fiber/4` 对给定压小函数搜索最大常值纤维并验证例 2.13 的
单射压小函数（f(i)=i−1 的纤维全是单点——非荟萃集上佛多失效的
现场）；`closure_under/3` 迭代搜索 f(e)=(Σe) mod 7 的可数子代数
不动点（与 Julia 实验三对拍）。

## 77.9 收束：从滤子到指数

本章把"κ 上的几乎处处"精确化：club 滤子 𝒢_κ κ-完全、正规，
NS_κ κ-可加、对对角线并封闭，佛多定理是正规性的函数形态，分裂定理
说明荟萃集富得流油（ω₁ 块互不相交），♦ 说明它还能顺带决定 CH，
问题 2.4 说明它永远升不上超滤子（除非撞见可测基数）。广义 club
把整套机器搬到 [X]^ω 与 P_κ(λ)：无界闭的本质是**代数闭包点**，
定理 2.34 与推论 2.4 是这句话的精确形式。

下一章这些工具立刻兑现成真金白银：银杰定理用"几乎不交函数族 +
佛多 + 线性序"证明 GCH 之下第一个不可数共尾奇异基数满足 SCH；
嘎尔文-海纳用 club 滤子给函数赋**范数**，把强极限奇异基数的指数
压到确定上界。非荟萃集理想不是摆设，它是连续统函数的裁判。
