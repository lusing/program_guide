# 64 · 量词逻辑：语言、等价与两种语义

> 本章提炼 Makinson 第 9 章：量词语言（项与公式的递归定义、自由
> 与约束出现）、三大等价组（量词互换/分配/空约束与换名）、两种
> 语义（代入读法与变体读法）及其等价条件、逻辑蕴含与同一性的
> 基本规则。它是 51 章 B-值语义的一阶原型——"赋值延拓"从布尔
> 升级为塔斯基结构，"商与满性"的骨架在此预演。

## 64.1 量词语言

**成分**：常项 a,b,c…（命名特定对象）；变项 x,y,z…（与量词配合
表达一般性）；函数字母 f,g,h…（从项到项）；谓词字母 P,Q,R…
（一元到 n 元）；**同一性符号 =**（特殊谓词，中缀）；量词 ∀∃；
真值联结词。括号保唯一可分解。

**项**的递归定义：基——常项与变项是项；步——f(t₁,…,tₙ) 是项。
**公式**的递归定义：基——原子公式 P(t₁,…,tₙ) 与 (t₁=t₂)；步——
在 ¬∧∨→ 与 ∀x ∃x 下封闭。

十个书本例句的符号化训练了直觉：全称条件化 ∀x(C→P) 与特称
合取化 ∃x(C∧P) 的不对称、双重量词 ∀x∃y vs ∃y∀x 的不可交换、
个体常项与函数字母的用法、"恰两个"的冗长展开（∃x∃y[Px∧Py∧
∀z(Pz→z=x∨z=y)]）。

**自由与约束**：量词 ∀x(a) 的**辖域**是括号内的 a；x 在 a 中的
出现被该量词**约束**（除非被内层同变元量词先占）；不被约束的
出现称**自由**。无自由变元的公式称**闭公式/语句**——英文完整
句的翻译必为闭式。

## 64.2 三大等价组

**量词互换**（四式，取一得三）：

    ¬∀x(a) ≡ ∃x(¬a)      ¬∃x(a) ≡ ∀x(¬a)
    ∀x(a) ≡ ¬∃x(¬a)      ∃x(a) ≡ ¬∀x(¬a)

对应 De Morgan 的量化版。由它们派生的四个等价（¬∀(a→b) ≡
∃x(a∧¬b) 等）是"全称条件句"与"特称合取句"否定式的翻译速查表。

**分配**：

    ∀x(a∧b) ≡ ∀x(a) ∧ ∀x(b)      ∃x(a∨b) ≡ ∃x(a) ∨ ∃x(b)

直觉：∀ 像长合取、∃ 像长析取——有限论域的**有限变换**使这一
点精确：论域 {a₁,…,aₙ} 上 ∀x(Px) "≡" Pa₁∧…∧Paₙ。**注意**
∀ 对 ∨ 不分配（∀x(P∨Q) ⊨ ∀xP ∨ ∀xQ 假），∃ 对 ∧ 同理。

**空约束与换名**：

- 空约束：a 中无 x 的自由出现时，∀x(a) ≡ a ≡ ∃x(a)；以及
  ∀x(a∨b) ≡ a∨∀x(b)（a 无 x 自由出现）。
- 换名：y 对 u 新鲜时，u ≡ u′（u′ 将 u 中 x 的约束出现替换为 y）。
  换名不可改变约束变元的**位置**（∀x∃y Rxy ≢ ∀x∃y Ryx）。
- 前束范式：一切量词"提到最前"——每个公式等价于某个前束式。

## 64.3 两种语义

**共享部分**：论域 D（非空集）；**赋值** v 为每个常项/变项指 D
中元素、为每个 n 元函数字母指 Dⁿ→D 的函数、为每个 n 元谓词指
Dⁿ 上的关系。v⁺ 对**项**同态延拓（v⁺(f(t₁,…,tₙ)) = v(f)(v⁺(t₁),…,
v⁺(tₙ))），对**原子公式**按关系成员判定，对**真值联结词**按命题
逻辑真值表，对**同一性** v(t₁=t₂) = 1 iff v(t₁) = v(t₂)。

**量词的两种读法**：

- **代入读法**（substitutional）：v⁺(∀x(a)) = 1 iff 对每个**闭项**
  t，v⁺(a[x:=t]) = 1。适合有限论域与计算机科学（Herbrand 模型）。
- **变体读法**（x-variant）：v⁺(∀x(a)) = 1 iff 对每个与 v 仅在 x
  处可不同的赋值 v′，v′⁺(a) = 1。数学的标准读法。

**等价条件**：当每个 D 中元素都被某个闭项命名时，两种读法等价。
否则可能分歧（如 D = ℝ 而语言只有可数多个常项）。

## 64.4 逻辑蕴含与同一性

**逻辑蕴含** A ⊨ b iff 无赋值使 A 全真而 b 假。由两种读法给出
同一概念（等价条件下）。**同一性规则**：

- = 引入：⊨ t = t（自反）
- = 消除（替换）：t = t′, P(…t…) ⊨ P(…t′…)（不可分辨者同一
  的使用形态）

**清洁代入**（clean substitution）：代入 t/x 在 a 中**清洁** iff
a 中无自由变元 y 出现在 ∀x/∃x 的辖域内而 t 含 y。清洁时
∀x(a) ⊨ a[t/x]（全称实例化）与 a[t/x] ⊨ ∃x(a)（存在见证化）
可靠。

## 64.5 机器通道

Lean 的 `Mathlib.Logic.FirstOrder` 有完整的语言/结构/语义但过重；
本章自建小语料：

```lean
-- examples/lean/Settheory/Ch64Quant.lean（节选）
-- 有限论域上的代入读法：∀ 的有限变换
def evalQ (D : List Nat) (P : Nat → Bool) : Form → Bool
  | .forall_ x body => D.all (fun d => evalQ D P (subst body x d))
  ...
```

Coq/Julia/Python 对 3 元论域穷举量词互换/分配等价式。Prolog 的
量词即"全知识库上的 forall/exists"。
