# 89 · 内模型 HOD、L[A] 与 L(ℝ)

第 87 章的 L 是「从零开始可定义地收集一切」的最小内模型；第 88 章看到 L 的组合刚性。但内模型论真正的用武之地是**带着外部信息构造模型**：给定一个集合 U（一个实数、一个超滤、一族谓词），能不能造出一个包含全部序数、又恰好「接纳」U 的传递模型？这就是冯琦第二卷 §2.2 的主题——兼容内模型。

本章沿四条路线展开。其一是**相对可构造集** L[U]（定义 2.21–2.23）：在第 87 章的可定义子集运算 𝒟 上增加一个一元谓词 U，重跑 L 的层次递归；关键事实是 L[U] 只看得到 U 在自己内部的截断 Ũ = U∩L[U]，故 L[U] = L[Ũ] 且 U ∈ L[U]（引理 2.24），并由此得到 U-可定义秩序、L[U] 版凝聚化、以及「自某个基数起 GCH 成立」（定理 2.17–2.19）。其二是**序数可定义内模型 HOD**（定义 2.27–2.29）：不用任何参数、只用序数就能定义的集合的彻底化；HOD ⊨ ZFC（定理 2.20），V=L 时 HOD=V（定理 2.21）。其三是允许实数参数的 ODR/HODR（定义 2.30–2.32，定理 2.22–2.23）。其四是从任意集合 a 与从全体实数出发的 L(a)、L(ℝ)（定义 2.33），以及 L(ℝ) 保持相关选择原理 DC（定理 2.25）。

机器通道处理这套理论中真正形式化的引擎：谓词原子让 U∩M 免参可定义（引理 2.24 的成员层根源）、彻底性对 ∈ 向下传递（引理 2.27(2)，HOD 传递性的引擎）、OD(V₃)=V₃ 的序数参数见证（例 2.2）、以及谓词原子对免参定义力的扩张实验。需要 ω₁ 以上递归或凝聚化的部分由正文自包含给出。

## 89.1 相对于谓词的可定义性：定义 2.21、2.22

先推广第 84 章定义 1.30/1.31 的可定义性。在集合论纯语言 ℒ_∈ 中增加一个一元谓词符号 U，得到语言 ℒ_{∈,U}。

**定义 2.21。** 设 U 是一个一元谓词（一个集合或一个类），M 是非空传递集合，A ⊆ M。称 A 是 M 的**相对于 U 可定义子集**，当且仅当存在纯语言公式 φ(v₀,…,v_{n-1},v_n) 与参数 a₀,…,a_{n-1} ∈ M，使

A = {b ∈ M | (M,∈,U∩M) ⊨ φ[a₀,…,a_{n-1},b]}。

注意谓词符号在 M 上的具体解释是 **U∩M**——谓词在结构之外的部分对 M 上的定义毫无贡献。这一句看似平凡的截断规定，是引理 2.24 全部内容的种子。参数表为空时称免参可定义子集。

**定义 2.22。** 对非空传递集合 M，令

𝒟_U(M) = {A ⊆ M | A 是 M 的相对于 U 可定义子集}。

**引理 2.23（ZF）。** M 非空传递、U 是集合时：

1. M ∪ [M]^{<ω} ⊆ 𝒟_U(M)，且 𝒟_U(M) 仍是传递集合；
2. 𝒟_U(M) 对布尔运算封闭：A ∈ 𝒟_U(M) ⇒ M−A ∈ 𝒟_U(M)；A,B ∈ 𝒟_U(M) ⇒ A∪B、A∩B ∈ 𝒟_U(M)。于是 (𝒟_U(M),∅,M,−,∪,∩) 是布尔代数；
3. 𝒟_U(M) ⊆ 𝒫(M)。

证明与第 87 章引理 1.15 逐条对应：M 的元素 a 由公式 v₀ = v₁（参数 a）定义；有限集由元素枚举式定义；传递性来自参数 b ∈ a ∈ 𝒟_U(M) 时 b ∈ M（M 传递）且 b 由有界公式配合参数定义；补、并、交分别由否定词、析取、合取直接实现。唯一新增的事实是：**U∩M 本身是 𝒟_U(M) 的免参成员**——它就是原子公式 U(v₀) 的扩张。新增谓词没有破坏任何旧簿记，只多送进来一个集合。∎

## 89.2 L[U] 层次与截断定理：定义 2.23、引理 2.24、定理 2.17

**定义 2.23。** 设 U 是集合。相对于 U 的可构造层次递归为：

- L₀[U] = ∅；
- L_{α+1}[U] = 𝒟_U(L_α[U])；
- 极限 λ：L_λ[U] = ⋃_{α<λ} L_α[U]；L[U] = ⋃_{α∈Ord} L_α[U]。

若 U 本身在 L_{ω+1} 中（有穷对象或自然数集那种已在有限层之下的东西），L[U] = L——谓词没有带来新信息；但若 U ⊆ ω 不可构造，L[U] 一般严格大于 L。V=L 时对任何 U 都有 L[U] = L，所以这个构造只在 V≠L 的世界里 nontrivial——它是大基数内模型（可测基数的 L[U]）的入口，第三卷会专门展开。

**引理 2.24。** 设 U 是集合，令 Ũ = U ∩ L[U]。则 L[U] = L[Ũ]，并且 U ∈ L[U]。特别地 U ⊆ ω 时（ω ⊆ L[U]，故 Ũ=U），U ∈ L[U]。

**证明。** 对 α 归纳证 L_α[U] = L_α[Ũ]。极限层由定义与归纳假设立得。后继步设 W = L_α[U] = L_α[Ũ]，则

W ∩ U = W ∩ U ∩ L[U] = W ∩ Ũ

（第一个等号因为 W ⊆ L[U]）。可定义性只依赖谓词在论域上的截断：𝒟_U(W) = 𝒟_{U∩W}(W)。于是

L_{α+1}[U] = 𝒟_U(W) = 𝒟_{U∩W}(W) = 𝒟_{Ũ∩W}(W) = 𝒟_Ũ(W) = L_{α+1}[Ũ]。

层次相等，故 L[U] = L[Ũ]。再证 U ∈ L[U]：U 是集合，秩有界；由映像存在原理取序数 α 使 U ⊆ L_α[U]（层次的并包含每个集合的全部元素——对 U 中元素出现的层数取上确界）。则 U = U∩L_α[U]，而谓词原子 U(v₀) 在 L_α[U] 上的扩张正是 U∩L_α[U] = U，故 U ∈ 𝒟_U(L_α[U]) = L_{α+1}[U]。∎

这条引理的哲学分量：**外谓词被模型「吞下」之后就成了内谓词**。L[U] 不需要外部的 U 作为语义参数就能被重新刻画——它自己带着对 U 的解释。

**定理 2.17（ZF）。** U 是集合时：

1. L[U] 是 ZF 的传递模型；
2. L[U] ⊨ ∃X (V = L[X])（见证 X = U∩L[U]）；
3. 若 N 是 ZF 的内模型且 U∩N ∈ N，则 L[U] ⊆ N。

**证明要点。** (1) 与第 87 章定理 2.2 同构，逐公理核对。外延用传递性；配对、并集直接由可定义式给出（并集 ⋃a₀ 是 L_α[U] 上公式 ∃v₃(v₀∈v₃∧v₃∈v₁) 的扩张，传递性保证内外求值一致）；ω ∈ L[U] 见证无穷公理。幂集公理：a₀ ∈ L[U] 的内部幂集 a₁ = 𝒫(a₀)∩L[U] 先用 V 中的分解原理收成集合，对每个元素取「出现的最低层」f(a)，映像存在给上界 λ 使 a₁ ⊆ L_λ[U]，则 a₁ 恰是 L_λ[U] 上内部幂集公式的扩张，落进 L_{λ+1}[U]。分解原理是唯一动镜像原理的地方：固定 φ 与参数，用广义镜像原理（第 85 章定理 1.29）把 (L[U],∈,U) 中的求值对齐到某个 L_γ[U] 上，分离结果成为该层的可定义子集。映像存在与 ∈-极小原理同 L 的情形。

(2) 由引理 2.24：Ũ = U∩L[U] 是 L[U] 的成员（谓词原子在某层定义出它），而 L[U] = L[Ũ]，故在 L[U] 内部看来 V = L[Ũ]。

(3) 对 α 归纳：N 是含全部序数的传递内模型，U∩N ∈ N 意味着每一层 𝒟_U(L_α[U]) 的定义（公式、参数、谓词截断 U∩N）都能在 N 内部重演，L_α[U] ⊆ N。∎

## 89.3 U-简朴运算、U-秩序、L[U] 版凝聚化与 eventual GCH

第 87 章把 𝒟 代数化为十七个简朴运算与 S-闭包；带谓词的版本只多一个运算。

**定义 2.24（第 18 种简朴运算）。** F₁₈(x,y) = {u ∈ x | u ∈ U}（**U-分离**；第二变元 y 仅为与其余简朴运算保持二元齐性而保留）。由 F₀,…,F₁₇ 与 F₁₈ 复合得到的运算称 **U-简朴运算**。它正是以 U 为谓词的最简单 Δ₀-分离。

**定义 2.25、2.26。** M 关于 U-简朴运算封闭、X 的 U-简朴闭包，定义照第 87 章定义 2.10/2.11 逐字平移；S^U 运算在原 S 的十七个像之外并上 U∩(A∪⋃A) 一项，迭代取并得 𝒥𝒫^U(A)。对传递 M 且 U ⊆ M，有与定理 2.6 平行的等式：

𝒥𝒫^U(M) ∩ 𝒫(M) = 𝒟_U(M)。

一边是代数闭包中落在 M 内部的集合，一边是谓词可定义子集——加了 F₁₈ 之后两边重新相等。

**定理 2.18。** U 是集合且 U ∈ L[U] 时，L[U] 上有一个由 U 可定义的秩序，故 L[U] ⊨ ZFC。

证明是第 87 章定理 2.9 的构造加一个簿记：出生层比较照旧；同层的项编码允许使用 F₁₈，而 U 本身是 L[U] 的成员（引理 2.24），可以作为定义中的参数出现，整个秩序因此在结构 (L[U],∈,U) 中可定义。∎

**引理 2.25（L[U] 版凝聚化）。** 设 λ 是极限序数，X ≺ (L_λ[U],∈,U∩L_λ[U])，π : X → N 为传递化。则 N 形如 (L_β[Ū],∈,Ū)；当 X 包含足够长的序数前段使谓词被逐点固定时，Ū = U∩L_β[U]，从而 N = L_β[U]。

（证明为练习：传递化与第 87 章定理 2.10 相同；谓词随坍缩成为 π[U∩X]，而「V=L[U]」经初等嵌入转移给 N，故 N 必是某个相对可构造层。）

**定理 2.19（eventual GCH）。** 存在序数 ξ，使对所有 α ≥ ξ：

(L[U] ⊨ 2^{ω_α} = ω_{α+1})。

**证明。** 不妨设 U ⊆ ω_ξ（由引理 2.24，U 在某层出现；取足够大的 ξ 即可），并在 L[U] 内部工作（V=L[U]，故 U ∈ L[U]）。设 X ⊆ ω_α、α ≥ ξ。取基数 λ 使 U,X ∈ L_λ[U]。令 M 为 [U,X] ∪ ω_α 在结构 (L_λ[U],∈,U) 中的同质子模型（斯科伦壳），种子大小 ω_α，故 |M| = ω_α。设 π : M → N 为传递化。因为 ω_α ⊆ M，π 在 M∩ω_α 上逐点恒等，所以 π(X) = X、π(U) = U∩N。由凝聚化引理 2.25，N = L_β[U] 对某个 β；又 |N| = |M| = ω_α，而 |L_β[U]| = |β|，必有 β < ω_{α+1}。于是

X ∈ L_β[U] ⊆ L_{ω_{α+1}}[U]，即 𝒫(ω_α) ⊆ L_{ω_{α+1}}[U]。

配第 87 章引理 2.1(6) 的基数账 |L_{ω_{α+1}}[U]| = ω_{α+1}，得 2^{ω_α} ≤ ω_{α+1}，Cantor 给反向。∎

与 L 中 GCH 的唯一差别：U 可能影响有界多个低基数（它要在某一层被吞下），过了那个阈值一切照旧。这正是可测基数内模型「GCH 在可测基数之上成立」的原型。

## 89.4 序数可定义性：定义 2.27、2.28，引理 2.26

**定义 2.27。** 设 M 是非空传递集合。元素 a ∈ M 称为在 M 中**序数可定义**，当且仅当存在公式 φ 与 M 中的一组序数 α₀,…,α_{n-1}，使

1. (M,∈) ⊨ φ[α₀,…,α_{n-1},a]；
2. a 是唯一的：(M,∈) ⊨ ∃!v_n φ[α₀,…,α_{n-1},v_n]。

记 OD(M) = {a ∈ M | a 在 M 中序数可定义}。

序数在任何传递结构中都是 canonical 的（不依赖结构的编码选择），「只许用序数当参数」因此是一个内外皆准的限制。

**例 2.2。** (1) 对每个 n < ω，OD(V_n) = V_n；(2) OD(V_ω) = V_ω；(3) OD(V_{ω+1}) 可数，而 |V_{ω+1}| = 2^{ℵ₀}。

(1) 的样品层 n = 3：V₃ = {0,1,2,{1}}。0、1、2 是序数，由公式 v₀ = α（参数 α 取自身）定义；{1} 不是序数，但公式

1 ∈ a ∧ ∀y ∈ a (y = 1)

用序数参数 1 唯一挑出它。一般情形对 n 归纳：每个元素用「成员恰好是某几个已定义集合」的枚举式（配合它们的序数参数）定义。(3) 是缺口出现的地方：V_{ω+1} = 𝒫(V_ω) 有 2^{ℵ₀} 个元素，但公式只有可数个、序数参数有限序列也只可数——可数对一，OD(V_{ω+1}) 至多可数。这是第 87 章「公式可数、子集不可数」在序数参数版的重现。

**定义 2.28。** a 序数可定义（记 a ∈ OD）当且仅当 ∃α ∈ Ord (a ∈ OD(V_α))。

**引理 2.26。** (1) 若 φ(α₀,…,α_{n-1},a) 在 V 中成立且唯一见证 a（序数参数），则 a ∈ OD：用镜像原理（定理 1.28）取足够大的 V_η ≺ V 包住参数与 a，则同一公式在 V_η 中唯一挑出 a。

(2) OD 上存在可定义的秩序。构造：取序数有限序列上的典范秩序 <^*（第 87 章定义 2.16，序型 Ord）与序同构 F : Ord ≅ Ord^{<ω}；取公式的典范编码 g : ω → V_ω。定义 ψ(α,a)：解码 F(α) = ⟨k,n,α₀,…,α_{n-1}⟩，g(k) 是含 n+1 个自由变元的公式，且 a 是 V_n 中唯一满足 φ_k(α₀,…,α_{n-1},a) 的元素；否则令 a = ∅。则

∀α ∃!a ψ(α,a)，且 a ∈ OD ⟺ ∃α ∈ Ord ψ(α,a)。

ψ 把 OD 排成可定义良序（每个 OD 集被一个序数「编了号」）。等价地，OD = ⋃_α cl({V_β | β<α})：序数可定义集恰是对累积层次的诸 V_β 实施哥德尔运算闭包的结果。∎

注意 OD **不传递**（若 OD ≠ V）：每个 V_α ∈ OD（公式「v₀ = V_α」只用序数参数 α），但 V_α 的元素未必 OD。为了得到内模型，必须彻底化。

## 89.5 HOD：定义 2.29、引理 2.27、定理 2.20、2.21

**定义 2.29。** a **彻底序数可定义**（a ∈ HOD）当且仅当

∀y ∈ TC({a}) (y ∈ OD)，

即 a 自身以及它的传递闭包里的每个集合都序数可定义。

**例 2.3。** V_ω ∈ HOD 且 V_ω ⊆ HOD：彻底有限集由外延形状唯一确定，不需要参数。

**引理 2.27。**

1. Ord ⊆ HOD ⊆ OD；
2. HOD 是传递的；
3. a ∈ HOD ⟺ a ∈ OD ∧ a ⊆ HOD；
4. α 是序数 ⇒ V_α ∩ HOD ∈ HOD。

**证明。** (1) 由定义直接（序数的传递闭包全是序数，都 OD）。

(2)：设 a ∈ HOD、x ∈ a。则 {x} ⊆ a，TC({x}) ⊆ TC(a) ⊆ TC({a})；后一集合的每个元素都 OD，故 x ∈ HOD。即 a 的成员都在 HOD 中。

(3) ⇒：a 自己在 TC({a}) 中，故 a ∈ OD；由 (2) 的论证 a ⊆ HOD。⇐：a ⊆ HOD 配 (2) 的传递性得 TC(a) ⊆ HOD ⊆ OD；a ∈ OD 补上 TC({a}) = {a} ∪ TC(a) 的最后一个元素，故 a ∈ HOD。

(4)：令 A = V_α ∩ HOD。由引理 2.26 的闭包刻画，「z ∈ OD」可写成以序数为参数的公式（z ∈ cl({V_β | β<γ}) 对某个 γ），于是

A = {u ∈ V_α | ∀z ∈ TC({u}) (z ∈ cl({V_β | β<…}))}

在 V 中序数可定义（只用参数 α），A ∈ OD；又 A 的元素都在 HOD 中，A ⊆ HOD，由 (3) A ∈ HOD。∎

**定理 2.20。** HOD ⊨ ZFC。

**证明。** HOD 对哥德尔集合运算封闭（运算是 Δ₀ 可定义的，OD 输入必给 OD 输出，彻底性同时保持）。由第 87 章定理 2.5，传递类是 ZF 模型只差覆盖性：任何 HOD 中的集合 X ⊆ V_α 都被 V_α∩HOD 覆盖，而后者由引理 2.27(4) 属于 HOD。ZF 各公理落地。

选择公理：由引理 2.26(2)，OD 上有可定义单射 H : OD → Ord。给定序数 α，限制 g = H↾(V_α∩HOD) 是 V_α∩HOD 到 Ord 的单射且 g ∈ OD（限制式只用序数参数 α）。g 的元素是 HOD 成员的有序对，故 g ⊆ HOD；g ∈ OD 且 g ⊆ HOD，由引理 2.27(3) g ∈ HOD。于是 HOD 中的每个集合（被某个 V_α∩HOD 包住）在 HOD 内部可良序化，AC 在 HOD 中成立。∎

**定理 2.21。** V = L ⟹ V = HOD。

证明为练习，思路：L 中每个集合 x ∈ L_{α+1} 由 L_α 上的某个公式定义；而 L_α 本身只用序数参数 α 即可序数可定义（层次是 Σ₁ 类函数），把「在 L_α 中满足」展开，x 的定义只用到序数（出生层 α 与公式的自然数编码）。故 L ⊆ OD；彻底性随传递闭包同步（x 的成员出生更早），L ⊆ HOD。∎

HOD 是第一个**不依赖分层构造**的内模型：它直接由「可定义性的复杂程度」切出来。它可以很像 L（V=L 时等于 V），也可以很不像——HOD 中可以失败 CH、可以容纳大基数，现代内模型纲领中 HOD 猜想是中心问题之一。

## 89.6 实数参数：ODR/HODR，以及 L(a)、L(ℝ)

**定义 2.30–2.32。** 把定义 2.27–2.29 中的「序数参数」放宽为「实数与序数参数」（参数属于 𝒫(ω) ∪ Ord），依次得到 OD^R(M)、ODR（∃α 之并）与彻底版 HODR。平行于引理 2.26 有三元公式 ψ(α,z,y)（z 是实数参数）给出 ODR 的可定义枚举；ODR = ⋃_α cl({V_β | β<α} ∪ ℝ) ∪ ℝ。例 2.5：V_{ω+1} ∈ HODR 且 V_{ω+1} ⊆ HODR（每个实数 r 用自己当参数即可定义——参数库包含全体 ℝ）。

**定理 2.22。** HODR ⊨ ZF（哥德尔运算封闭 + 引理 2.29(4) 的覆盖性，证如定理 2.20）。

**定理 2.23。** HODR ⊨ AC 当且仅当存在 W ∈ HOD 使 (ℝ,W) 是一个秩序（即实数在 HOD 内部可良序化）。

也就是说，HODR 自带 ZF，但选择公理是否成立被精确归约为「ℝ 能否在 HOD 中被秩序化」——在 AD（决定性公理）的世界里 HODR 是 AC 失败的天然模型。

**定义 2.33（L(a) 与 L(ℝ)）。** 给定集合 a，令 ℒ_a 为在纯语言上对每个 b ∈ TC({a}) 添加一元谓词 P_b（解释为 ∀c(c ∈ b ↔ P_b(c))，即用谓词逐一点名 a 的传递闭包中的成员）的语言。定义：

- L₀(a) = TC({a})（注意起点不是 ∅：a 与其全部成员一开始就进场）；
- L_{α+1}(a) = L_α(a) 在 ℒ_a 下的全体可定义子集；
- 极限取并；L(a) = ⋃_α L_α(a)。

对 A ⊆ ℝ 有对等的常元版本（每个 r ∈ A 一个常元）；当 A = ℝ ∩ L(A) 时，L(A) 的每个元素都由 A 中元素与序数可定义。

**定理 2.24（ZF）。** (1) L(a) 是 ZF 的内模型且 a ∈ L(a)；(2) L(a) ⊨ V = L(a)；(3) 最小性：N 是 ZF 内模型且 TC({a}) ⊆ N ⟹ L(a) ⊆ N。

**定理 2.25（ZF + DC）。** L(ℝ) ⊨ DC（相关选择原理：若 R 是 A 上全的二元关系，则存在 ω-链 ⟨f(n)⟩ 使 (f(n),f(n+1)) ∈ R）。

**证明梗概。** 修改 L 的秩序构造得到满射 Φ : Ord × ℝ → L(ℝ)，使每个截段 Φ↾(α×ℝ) 都属于 L(ℝ)（每一层只涉及一个实数参数与序数，层前截段是 L(ℝ) 中的集合）。设 R ⊆ A×A 在 L(ℝ) 中且处处有后继。Δ₀-绝对性下 R 在 V 中也全；由 V 中的 DC 取链 f : ω → A。用可数选择对每个 f(n) = Φ(ξ_n,a_n) 选实数见证 a_n；单个实数即可编码整个序列 ⟨a_n⟩，故它属于 L(ℝ)。在 ξ×ω 上定义关系 ≺：(η,j) ≺ (ξ,i) 当 j = i+1 且 (Φ(ξ,a_i), Φ(η,a_j)) ∈ R。截段 Φ↾(δ×ℝ) ∈ L(ℝ) 与实数序列都在 L(ℝ) 中，故 ≺ ∈ L(ℝ)；≺ 在 V 中无秩（f 的值给出无 ≺-极小元的集合 rng），由有秩关系的绝对不变性，≺ 在 L(ℝ) 中也无秩。取无极小元的集合 B ∈ L(ℝ)，每步取满足条件的最小序数 ξ_n，递归定义出的序列 ⟨Φ(ξ_n,a_{i₀+n})⟩ 全部在 L(ℝ) 中，即为所求 DC 链。∎

L(ℝ) 是决定性理论的主场：ZF + DC 而 AC 可以失败，全体实数进场，投射集合的正则性质在此表达。它也是「内模型能离 V 多近又不被迫接受选择」的样板。

## 89.7 机器通道：谓词原子与彻底性

七通道围绕两组**可在一阶类型中陈述**的引擎组织，另加三组有限计算。

**引擎一：谓词原子让 U∩M 免参可定义。** Lean 在第 87 章的公式语言上增加一个构造子 `inA`（`Ch89InnerModel.lean`）：

```lean
inductive FmA (α : Type) where
  | tt | ff
  | eq (p : α) | mem (p : α)
  | inA                         -- 新谓词原子：x ∈ U
  | neg (φ : FmA α) | or (φ ψ : FmA α)

/-- U∩M 由原子公式免参定义：引理 2.24「L[U] 只看到 U∩L[U]」的成员层引擎。 -/
theorem UA_definable (mem : α → α → Prop) (U : α → Prop) (M : List α) :
    ∃ φ : FmA α, ∀ x, x ∈ M → (satA mem U φ x ↔ U x) :=
  ⟨.inA, fun _ _ => Iff.rfl⟩
```

证明就是 `Iff.rfl`：按 satA 的定义，inA 在 x 处的真值就是 U(x)——89.2 中「U∩L_α[U] 是该层免参可定义子集，故 U ∈ L_{α+1}[U]」的那一步，其全部逻辑内容就是这个原子条款。同文件的 `finite_definable_UA` 补上对偶一面：有限载体上参数全开放时，谓词不增加定义力——析取式 `disjA` 照旧覆盖每个子集，这正是 L_n[U] = V_n（有限层与谓词无关）的影子。Coq（`UA_definable`、`FmA` 的 Arguments 隐参声明）与 Agda（`UA-definable`，证据就是 `finA , λ x _ h → h`）证同一件事。

**引擎二：截断不变性的 locale。** Isabelle/ZF 把引理 2.24 的层次证明抽象成一条交换律（`ST89/InnerModel.thy`）：

```isabelle
locale relative_def =
  fixes DU :: "i ⇒ i"
  fixes DUs :: "[i, i] ⇒ i"
  fixes U :: i
  assumes trunc: "⋀M. DU(M) = DUs(U ∩ M, M)"
```

DU 是「带谓词的可定义子集」运算，公理只声明一件事：DU 在 M 上的行为完全由 U∩M 决定。引理 2.24 的后继层链等式 L_{α+1}[U] = 𝒟_{U∩W}(W) = L_{α+1}[Ũ] 就是这条公理逐层展开；ZF 中 nat 不是 datatype、层次递归的 primrec 化会踩外层语法，完整的超限归纳由正文承载，locale 钉死的是它唯一的实质输入。

**引擎三：彻底性对 ∈ 向下传递。** HOD 传递性（引理 2.27(2)）的抽象引擎是可达关系上的归纳。Lean 用归纳类型刻画「沿 ∈ 下降可达」（TC 的归纳化身）：

```lean
inductive Reach (mem : α → α → Prop) : α → α → Prop
  | head (x : α) : Reach mem x x
  | step {x y z : α} (h : mem x y) (hr : Reach mem y z) : Reach mem x z

def Hered (P : α → Prop) (mem : α → α → Prop) (x : α) : Prop :=
  ∀ y, Reach mem y x → P y

theorem hered_down {P : α → Prop} {mem : α → α → Prop} {x y : α}
    (hx : Hered P mem x) (hxy : mem y x) : Hered P mem y :=
  fun z hz => hx z (reach_trans hz (Reach.step hxy (Reach.head x)))
```

`reach_trans` 先证可达关系传递（对第一变元结构递归：head 直接给，step 把新边接到递归结果前）；彻底性向下传递就是把「z 可达 y」与「y 是 x 的成员、x 可达 x」接成「z 可达 x」。把 P 实例化为「∈ OD」、mem 实例化为 ∈，这就是引理 2.27(2) 的证明；把结论对成员 y 再用一次得到 Hered P x → P x ∧ ∀y∈x Hered P y（Coq 的 `hered_split`，引理 2.27(3) 的必要方向）。Coq 的 `Reach` 用 Arguments 手工声明隐参，Agda 版 `hered-down` 的关键改写是 `reach-trans hz (rstep hxy (rhead _))`。反方向（成员全彻底 ⇒ 自身彻底）需要 ∈ 的良基性来做归纳，抽象类型里没有它——这个方向由计算通道在有限良基世界 V₄ 上补成等价。

Isabelle 版把同一件事放进第二个 locale：`hered_class` 假设 TC 的单调性 y∈x ⇒ TC({y}) ⊆ TC({x})（集合论 TC 的标准簿记），`HODm(a) ≡ TCf(cons(a,0)) ⊆ OD`，引理 `HOD_trans` 用 subset_trans 两行推出——与 Lean/Coq/Agda 的归纳证法是同一个事实的「集合包含」与「可达谓词」两副面孔。

**计算一：OD(V₃) = V₃ 的四个见证（例 2.2(1)）。** Python/Julia/Prolog 在 HF 世界构造 V₃ = {0,1,2,{1}}，为四个元素各写一条带序数参数的 Δ₀ 公式并核对其在 V₃ 中的扩张恰为单点：

```python
witnesses = {
    NAT[0]: lambda x: x == NAT[0],                                  # x = 0
    NAT[1]: lambda x: x == NAT[1],                                  # x = 1
    NAT[2]: lambda x: x == NAT[2],                                  # x = 2
    frozenset({NAT[1]}): lambda x: (ball(x, lambda y: y == NAT[1])  # x = {1}
                                    and bex(x, lambda y: y == NAT[1])),
}
```

{1} 的见证正是书中公式「1∈a 且所有成员等于 1」的代码形态（bex 保证非空，排除 a=∅）。Prolog 用 `witness/2` 事实表 + `findall(...,[X])` 核对唯一扩张。

**计算二：引理 2.27(3) 等价式的数值验证。** 在 V₄（16 个元素）上把彻底性实现为 TC 闭包版 `hered_tc`（深度优先收集传递闭包，逐个检查 P）与分解版 `hered_split`（P(x) 且每个成员 hered_tc），断言两者对 V₄ 全体 16 个元素逐点相等：

```
V_4 全体：Hered_TC(x) = (P x 且成员全 Hered)——引理 2.27(3) 等价成立 OK
```

良基归纳在代码里就是 `tcplus` 的遍历必然终止（每步秩下降）——抽象证明回避的反方向，在有限世界免费成立。

**计算三：谓词原子对免参定义力的提升。** 在二元载体 V₂={0,1} 上枚举免参公式的扩张：没有谓词原子时，tt/ff 及其否定、析取只能给出 ∅ 与 V₂ 两个子集；加入 inA 后，原子 U(v₀) 与它的否定、析取立即给出全部 4 个子集（∅、{0}、{1}、V₂，取 U={0}）：

```
V_2 上免参可定义子集：无谓词 2 个 -> 带谓词 4 个——U 截断进入免参定义 OK
```

2 → 4 就是「新谓词白送一个免参子集 U∩M」的全部数值内容。最后 `def_closure(V2,U)` 在带谓词闭包下达到全部 4 个子集（= 𝒫(V₂)），且 U ∈ V₃ = L₃[U]——L_n[U] = V_n 与引理 2.24「U ∈ L[U]」在同一次运行里对账。Julia 通道用 HS 互递归结构类型复现同一实验（冯诺依曼后继必须写成 n ∪ {n}：`hs(vcat(prev.elems,[prev])...)`，否则只得到 {n}）；Prolog 用嵌套列表与 `tc_loop` 复刻前两组。

## 89.9 这一章留下了什么

内模型不必从零开始：给定集合 U，带谓词的可定义层次 L[U] 是接纳它的最小 ZF 模型，而截断定理 L[U] = L[U∩L[U]] 保证外谓词一旦被吞下就成为内谓词（引理 2.24）——U-简朴运算、U-可定义秩序、L[U] 版凝聚化随之而来，GCH 至多在有界多个低基数处受影响，其上照旧（定理 2.18、2.19）。这套结构是可测基数与一切现代内模型的底座。

另一族内模型由参数的贫富切分：只许序数参数给出 OD，彻底化给出 HOD——一个对哥德尔运算封闭、有覆盖性、靠可定义单射满足 AC 的 ZFC 模型（定理 2.20），V=L 时它就是 V（定理 2.21）；允许实数参数给出 ODR/HODR，AC 是否成立被归约为实数能否在 HOD 中被秩序化（定理 2.23）；从任意集合 a 的传递闭包出发给出 L(a)，从全体实数出发给出 L(ℝ)——最小的包含全体实数的 ZF + DC 内模型（定理 2.24、2.25），AC 在此不再免费。下一章（90）离开内模型，转向从外部改变论域的工具：力迫，以及 CH 独立性的另一半证明。
