# 54 · Cohen 力迫定理与 CH 独立性全程

> 毕其功于一役：布尔值语义（51）、满性（52）、V^B（53）在此
> 合流为 **Cohen 力迫定理**——外定义（谈泛型扩张）与内定义
> （谈布尔真值）等价。然后是皇冠应用：**CH 的独立性**，
> ¬CH 与 CH 两个模型的完整构建，以及 **M^B ⊨ ZFC** 的九公理
> 逐条名字构造。
>
> 本章覆盖 Viale §7.2-7.4 + 附录 C。

## 54.1 力迫定理

**关键引理（Viale Lemma 7.2.3）** G 是 M-泛型滤子：
(a) 若 b ∈ G 且 X ∈ M 在 b 下方前稠密，则 G ∩ X ≠ ∅；
(b) 若 A ∈ M 且 ⋁A ∈ G，则某 a ∈ A ∩ G。
(b) 的证明是泛型性的精妙消费：把 {¬⋁A} ∪ {¬a : a ∈ A} 的
上闭包做成 M 中的稠密集，G 切入则要么 ¬⋁A ∈ G（矛盾于
⋁A ∈ G）要么某 ¬a ∈ G 且 a ∈ G（矛盾）。∎

**定理（Viale Thm 7.2.4，商-坍缩同构）** M-泛型 G 给出
**M^B/G ≅ M[G]**：[τ]_G ↦ τ_G 是 Mostowski 坍缩。
证明按秩对归纳验证 ∈/= 两关系保持——Lemma 7.2.3 在每个
"sup 被实现"的关口出鞘。∎

**定理（Viale Thm 7.2.5，Cohen 力迫定理）**
1. b ≤ ⟦φ(τ̄)⟧ ⟺ 对一切含 b 的 M-泛型 G：
   M[G] ⊨ φ(τ̄_G)；
2. M[G] ⊨ φ(τ̄_G) ⟺ ⟦φ(τ̄)⟧ ∈ G。

*证明*：由同构 7.2.4 + Łoś 定理 6.3.7 + "M-泛型滤子在
St(B) 中稠密"（50 章）三件套组装。∎

**外定义 = 内定义**——M 可以在内部计算一切力迫事实。
这就是力迫方法的全部魔法：**泛型扩张的一阶理论被 M 内的
布尔计算完全控制**。

**用法示范（Viale Example 7.2.8）** 证明 {b : b ⊩ φ_α} 是
反链的绝招：若 b_α ∧ b_β > 0，取含它的泛型 G，力迫定理给
M[G] ⊨ f(α) = α ∧ f(β) = β，故 α = β——**在 V 中推出矛盾**，
M 内的反链性无需直接计算。这是"借 V 之力证 M 内事实"的
标准范式。

## 54.2 ccc 保基数：¬CH 的组合引擎

**引理（Viale Lemma 7.3.1）** B 满足 ccc（在 M 中）⟹
M 与 M[G] 的共尾度一致。
证明核心（Fact 7.3.2）：M[G] 的每个函数 f : λ → λ 被 M 中
的可数集 A_ξ ⊆ λ 围堵（反链论证：{b ⊩ f(ξ) = η} 按 ξ 分组
是可数反链的并），正则基数 λ 的 M-正则性收尾。∎
——**ccc = 泛型扩张不塌基数**。

## 54.3 ¬CH 模型

**定理（Viale Thm 7.3.3）** B := RO((2^ω)²)^M（Fn(2^ω, 2) 的
补全——ccc！）：M[G] ⊨ ¬CH。

证明三步：
1. **泛型实数族**：名 τ = {((α,n),i) ↦ N_{α,n,i}} 读出
   g_α(n) = G ∩ 层 N_{α,n}；稠密集 D_{α,n}（把 (α,n) 塞进
   定义域）与 E_{α,β}（在某个 n 处分化 g_α 与 g_β）保证
   {g_α : α < (2^ω)^M} 两两不同（50 章 5.2.1 的 D/E 族）；
2. **ccc 保基数**：(2^ω)^M 在 M[G] 中仍是第二不可数基数
   （Lemma 7.3.1）；
3. 合并：M[G] ⊨ 2^ω ≥ (2^ω)^M > ℵ₁。∎

## 54.4 CH 模型

**技术**：**κ-分配性**（Viale Def 7.3.4）：⋂_{δ<κ} D_δ 稠密
对 κ 个稠密集；**<κ-闭**（Def 7.3.5）：长度 <κ 的降链有下界。
Lemma 7.3.6：<κ-闭的可分离偏序的 RO 是 <κ-分配。

**坍塌偏序（Def 7.3.7）** P_κ := {f : γ → κ | γ < ω₁, f 单射}
（反包含序）——可数闭且可分离（Fact 7.3.8）。

**定理（Viale Thm 7.3.9）** κ := (2^ω)^M 正则 ≥ ℵ₂：
B := RO(P_κ)^M 给 M[G] ⊨ CH。
Prop 7.3.10 三条：(1) ω₁ 不动；(2) **实数不增**（P_κ 可数
分配 ⟹ 2^ω ∩ M[G] = 2^ω ∩ M——每个新"实数"名字被 M 内的
实数完美实现——**最大原理的分配版**）；(3) M[G] ⊨ 存在
ω₁ ↔ κ 的双射（泛型枚举）。合并：2^{ω,M[G]} = ω₁。∎

**两端合体**：Con(ZFC⁺) ⊢ Con(ZFC + ¬CH) 且 Con(ZFC⁺) ⊢
Con(ZFC + CH)——**CH 独立**（ZFC⁺ = ZFC + "存在可数传递
模型"；去 ZFC⁺ 化由反射定理承担——55 章）。

## 54.5 M^B ⊨ ZFC：九公理的名字证书

**定理（Viale Thm 7.1.1=7.4.1）** M ⊨ ZFC、B ∈ M 是（M 中
的）cBa：一切 ZFC 公理的布尔真值为 1。

逐公理的名字证书（Viale §7.4 的完整清单）：
- **外延/基础/无穷**：传递真（Δ₁ / M[G] ⊆ V）+ ω̌ ∈ M^B；
- **配对**：up(τ,σ) := {(τ,1), (σ,1)}；
- **并**：∪τ := {(ξ,1) : ξ ∈ ∪dom(τ)}；
- **幂集**：P^B(τ) := {σ ∈ dom(τ)^dom(τ) 的限制}——关键
  引理 7.2.9（⟦σ ⊆ τ'⟧ 被 dom-保持的名字实现）；
- **分离**：{(ξ, ⟦φ(ξ,τ̄)⟧) : ξ ∈ dom(τ)}——**分离的名字
  把 φ 的真值当标号用**（力迫与语义的最美合体）；
- **收集**：对 R = {(ξ,b) : b ⊩ ∃y φ} 取 M 内的集合界 Z，
  名 := {((ξ,ζ),1) : ζ ∈ Z}；
- **选择**：M 内良序 τ 的域，名 := {(op(ξ,f(ξ)),1)}。
∎

**推论（Viale Cor 7.4.4）** M[G] 是包含 M ∪ {G} 的最小传递
ZFC 模型，且 Ord^{M[G]} = Ord^M。

## 54.6 附录 C：与 Kunen 路线的接轨

**Definability + Truth Lemma（Viale C.1.4/5）** Kunen 的
P-名 V^P（标签 ∈ P）与 Viale 的 V^{RO(P)} 通过
î(a) := {(î(b), p) : (b, p) ∈ a, i(p) = ...} 同构
（Thm C.1.8）——**两条路线是同一个定理的两个坐标系**。
18 章（Jech 路线的 p ⊩ φ 递归定义）与本章的 b ≤ ⟦φ⟧ 由
此对齐：**Definability = ⟦φ⟧ ∈ M 可算；Truth = ⟦φ⟧ ∈ G**。
