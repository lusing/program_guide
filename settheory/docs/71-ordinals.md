## 71.1 序数的内禀定义

> **定义 1.57（序数）** 集合 α 是序数当且仅当：
> (a) **Φ₀(α)**：α 是传递集合（∀y(y ∈ α → y ⊆ α)）；
> (b) **Φ₁(α)**：α 的任意两个元素 ∈-可比较——u, v ∈ α 时 u ∈ v、
> u = v、v ∈ u 三者恰居其一；
> (c) **Φ₂(α)**：α 的每个非空子集 y 有 ∈-极小元（∃z ∈ y(z ∩ y = ∅)）。

三个条件全部只用 ∈ 与 = 一阶可写——序数性是集合的**内在属性**，
不需要"与某个良序同构"这类外在参照。这正是冯·诺伊曼方案与康托尔
"序型"方案（同构类作对象）的分野：冯·诺伊曼让每个良序有唯一的
集合代表（72 章表示定理），康托尔的序型则活在高层抽象里。

**后继与极限**（定义 1.57(2)(3)）：α 是**后继序数** ⟺ ∃β ∈ α
(α = β∪{β})，记 α = β+1；**极限序数** ⟺ 非零且不是后继。

**例 1.20** (1) ∅ 是序数（三条件真空成立）——最小的序数 0，也约
定为极限序数；(2) ω 是序数且每个自然数都是序数；(3) ω 是非零极限
序数；(4) ω+1 = ω∪{ω} 是后继序数。—— 68 章的九条事实（定理 1.6/
1.7）在这里被重新读作"Φ₀Φ₁Φ₂ 的 ω 特例"。

**命题 1.18** α 序数 → α∪{α}（= α+1）也是序数。传递性与
∈-连通性直接由 α 的三条件继承。验证 Φ₂：任取非空
y ⊆ α∪{α}。若 y = {α}，则 α 是极小元，因为 α∉α；否则
y∩α 非空，在 α 内取它的 ∈-极小元 z。此时 z 与 y∩α 无公共元素；
又 z∈α，故 α∈z 会形成 ∈-循环而被 Φ₂ 禁止，所以 z 与 y 也无公共
元素。于是 z 就是 y 的 ∈-极小元。∎

## 71.2 序数的基本事实链

冯琦用"极小反例"法连推五条，每条都是超限思维的体操：

**引理 1.9** α 序数 ∧ β ∈ α → β 传递。*证明*：若 β 不传递，
就有 γ∈β、δ∈γ 而 δ∉β。α 传递，所以 γ,δ 也都属于 α；对 δ 与 β
使用 Φ₁ 的三择一。δ∈β 与所取 δ 矛盾；δ=β 给出 β∈γ∈β；
β∈δ 给出 β∈δ∈γ∈β。后两种情形分别产生二元素、三元素 ∈-循环，
该循环作为 α 的非空子集不可能有 ∈-极小元，违反 Φ₂。故 β 必传递。∎

**命题 1.19** α 序数 ∧ β ∈ α → β 序数（在引理 1.9 之上验收 Φ₁Φ₂：
极小性自 α 下传）。**——序数的元素是序数**：序数是"序数之塔"。

**引理 1.10** α 序数 ∧ A ⊆ α ∧ A 序数 → A = α ∨ A ∈ α。*证明*：
A ⊊ α 时取 β ∈ α−A 的 ∈-极小元，断言 A = β（双向包含用极小性与
可比较性）。∎

> **定理 1.50（序数可比较性）** 任意两个序数 α, β：α ∈ β、β ∈ α、
> α = β 三者恰居其一。*证明*：令 δ = α∩β（交是序数）；由引理 1.10，
> δ = α 或 δ ∈ α，δ = β 或 δ ∈ β。两个等式都成立则 α = β；恰一
> 个成立则得到 ∈ 关系；两个都不成立则 δ ∈ α ∩ δ，与 Φ₂ 冲突。∎

**定理 1.51** 序数的非空集合 τ 有 ∈-最小元 min(τ)。（取 α ∈ τ，
在 α+1 里找 τ 的极小元。）**命题 1.20**：τ（序数之集）是序数 ⟺ τ
传递；⋃τ 是序数；∀α∈τ(α ⊆ γ) → ⋃τ ⊆ γ。由此定义 **sup(τ) = ⋃τ**。

**定理 1.52** 对任何序数 α 存在极限序数 λ ≥ α。*证明*：定理 1.41
（70 章）给一个对 β↦β+1 与 α∪{β} 封闭的 W；X = {β ∈ W | β 序数}，
λ = ⋃X 是极限序数且 α ∈ λ。∎——**任意大的极限序数存在**。

**推论（Ord 是真类）**：若全体序数 Ord 是集合，则 ⋃Ord 传递且其元素
皆序数，故 ⋃Ord 是序数且包含一切序数——包括它自己，违反 Φ₁
（α ∈ α 不可能）。**Ord 不是集合**——"所有序数的全体"只是类。这
是布拉利-福尔蒂悖论的公理化驯服版：悖论变成定理（"那个类不是集合"），
正如 67 章罗素定理驯服了罗素悖论。

## 71.3 超限归纳法

> **定理 1.53（最小序数原理）** 若存在序数满足 Φ，则存在满足 Φ 的
> **最小**序数。*证明*：B = {δ ∈ α+1 | Φ(δ)} 是序数非空集，取
> min(B)。∎

> **定理 1.54（超限归纳法一）** 若对每个序数 α 都有
> (∀β ∈ α Φ(β)) → Φ(α)，则一切序数满足 Φ。
> （最小反例 α 使 ∀β∈α Φ(β)，条件给出 Φ(α)——与反例矛盾。）

> **定理 1.55（超限归纳法二）** 若 (a) Φ(0)；(b) Φ(β) → Φ(β+1)；
> (c) β 极限且 ∀γ∈β Φ(γ) → Φ(β)，则一切序数满足 Φ。

三款式（0/后继/极限）是数学实践的惯用形态——68 章的自然归纳法
正是其 β < ω 截面。注意极限款的" ∀γ∈β Φ(γ) → Φ(β)"把"逐项归
纳"换成了"整段归纳"：在极限处，前驱没有"最后一个"，只能整段
取并。这是超限世界与自然数世界的根本差异，下一节递归定义将把
这个差异写进定义本身。

## 71.4 超限递归定义

先升两级词汇（定义 1.62/1.63）：**类函数** G 是由泛函定义式 Φ(τ,y)
给出的"未必成集的函数"——对每个序数 α 恰有一个 y = G(α)；**类
序列**是定义在全体序数上的类函数，记 ⟨α_ξ | ξ ∈ Ord⟩。类函数是
"规则的蓝图"，只有在具体集合上取像时才动用替换公理落成集合。

> **定理 1.56（超限递归定义）** 对任何类函数 G，存在唯一的类序列 F
> 满足 **F(α) = G(F↾α)**——第 α 项由**之前所有项**整体决定。

*证明*分四步。(1) **相容性**：若 f, g 都是满足 f(ξ) = G(f↾ξ) 的
α-序列，对 ξ 归纳得 f = g。（"过去决定现在"的单值性。）(2) **每段
存在**：对每个序数 α 存在满足要求的 α-序列 f_α——超限归纳：α =
β+1 时 f_α = f_β ∪ {⟨β, G(f_β)⟩}；α 极限时，对每个 ξ ∈ α 的 f_ξ
由归纳假设存在，**映像存在原理**把它们收进集合 T = {t | ∃ξ∈α
Ψ_G(ξ,t)}，T 是和谐函数系统（(1) 保证），f_α = ⋃T。(3) 令
F(α) = f_{α+1}(α)。(4) 唯一性由 (1) 粘合。∎

注意极限步的构造与 68 章定理 1.12 的"和谐系统取并"完全同构，只是
"有限近似"换成了"更短的超限近似"，而"取并"的合法性从分解原理
换成了替换公理——70 章预告的"同一发动机"第三次点火。

**定理 1.57**（无参版）：θ 非零极限、A 非空、g: A^<θ → A，则存在
唯一 f: θ → A 使 ∀α<θ(f(α) = g(f↾α))——68 章推论 1.2（强递归）
的超限版。**定理 1.58**（参数版）：二元类函数 G(z,·) 给出
F(z,α) = G(z, F_z↾α)。**定理 1.59**（**分情形版**，最常用）：
由三个一元类函数 G₁, G₂, G₃ 按"零/后继/极限"分情形定义 G，得到
类序列 F：
F(0) = G₁(0)；F(α+1) = G₂(F(α))；β 极限 → F(β) = G₃(F↾β)。
——V_α、序数算术（72 章）、秩函数，全部用这条装配线定义。

## 71.5 累积层次：V = ⋃V_α 的全塔

> **定义 1.64（累积层次）** 类序列 (V_α | α ∈ Ord)：
> V₀ = ∅；V_{α+1} = 𝒫(V_α)；λ 极限时 V_λ = ⋃{V_α | α ∈ λ}。
> V* = ⋃{V_α | α ∈ Ord}。

70 章的 V_n 塔是从这条装配线上截下的第一段。三条基本性质（引理
1.11，同时归纳）：(1) 每个 V_α 传递；(2) β ∈ α → V_β ∈ V_α 且
α ⊆ V_α；(3) V* 是传递类且 Ord ⊆ V*。

**定理 1.60（V_λ 的封闭律，λ ≥ ω 极限）**：{a,b,A,B} ⊆ V_λ →
(a,b), A×B, ⋃A, 𝒫(A), 分离 {a ∈ A | Φ[a, a⃗]} 全在 V_λ 里。——
V_λ 是 ZF−Replacement 的雏形模型；引理 1.12 补上"每个成员都有秩"
的导流：A 非空且每元落在某 V_α → A ∈ V*。

> **定理 1.61（V = V*）** 每个集合都属于某个 V_{α+1}。
> *证明*：对 a 取 M = TC(a)（70 章传递闭包）。若某 b ∈ M 不落进
> 任何 V_β，则 Y = {b ∈ M | ¬∃β(b ∈ V_β)} 非空，∈-极小原理取
> 极小 b₀ ∈ Y；M 传递故 b₀ ⊆ M，b₀ 的每个元素都落进某 V_β，取
> sup 得 b₀ ⊆ V_α，于是 b₀ ∈ V_{α+1}——矛盾。∎

TC + ∈-极小 = 一次干净的"良基归纳"。09 章（Jech 路线）用同样的
骨架证 V = ⋃V_α 并推进到 BG 类理论与 ¬Foundation 的相对一致性；
冯琦的版本把火力集中在"秩"上：

> **定义 1.66（秩）** RK(a) := 满足 a ∈ V_{α+1} 的最小序数 α。
> **命题 1.21** (1) b ∈ a → RK(b) < RK(a)；(2) **S∘RK = RK∘S**：
> ∀a(RK(a)+1 = RK(a∪{a}))。

(2) 的证明是一段小双围：S(a) ⊆ V_{RK(a)+1} 给 RK(S(a)) ≤ RK(a)+1；
(1) 给 RK(a) < RK(S(a))。两个方向夹出等式。——**后继函数与秩函数
交换**：在累积塔的每一层，"加一个自己"恰好在塔上爬一层。自然数的
RK(n) = n（68 章的冯诺伊曼结构在秩轴上排成斜率为 1 的直线），ℚ 的
成员 RK ≤ ω（70 章 例 1.19(4) 的精确化）。

## 71.6 机器通道

序数是机器验证的重镇，四家证明助手都有官方序数库，路线各异：
**Lean/mathlib** 的 `Ordinal`（商 von Neumann 序数类）、
**Isabelle/ZF** 的 `Ordinal.thy`（公理化集合论内建 Ord/lt/Limit）、
**Coq** 与 **Agda** 以有限冯诺伊曼序数承载内禀三条件的可判定截面，
**Julia/Python** 把秩函数做成可执行程序，**Prolog** 做谓词化的三择一
与最小元。本章没有一个通道需要"造"序数——要验证的全是三条件
（Φ₀Φ₁Φ₂）与事实链（定理 1.50-1.52、命题 1.21）的机器形态。

### Lean：官方序数类上的三定理

Lean（examples/lean/Settheory/Ch71Ordinals.lean）落在官方锚点上。
定理 1.50（可比较性）在商序数类上浓缩成一条 `lt_trichotomy`——
冯琦的 Φ₁（∈-连通）+ Φ₂（良基）的官方化身：

```lean
theorem comparable (a b : Ordinal) : a < b ∨ a = b ∨ b < a :=
  lt_trichotomy a b
```

定理 1.51（最小序数原理）用良基最小元：`wellFoundedLT` 实例
给出 `WellFounded.min`，一行拿到非空集合的最小元与最小性两条
证书——Φ₂ 的另一半在这里兑现：

```lean
theorem min_of_nonempty {s : Set Ordinal} (h : s.Nonempty) :
    ∃ m ∈ s, ∀ b ∈ s, m ≤ b :=
  ⟨Ordinal.wellFoundedLT.wf.min s h, WellFounded.min_mem _ s h,
    fun _ hb => WellFounded.min_le _ hb⟩
```

定理 1.52（任意大的极限序数）由官方引理 `isSuccLimit_add` 承载：
a + ω ≥ a 且是极限——"冲出任何一层楼"的构造性版本。例 1.20 的
(2)(3) 则分别落在 `Ordinal.isSuccLimit_omega0` 与 `lt_omega0`
（ω 之下恰是自然数）上。布拉利-福尔蒂驯服不做 example——
"全体序数"是类论陈述，类型论的回答写在宇宙分层里
（`Ordinal.{u} : Type (u+1)`，"序数全体"住在下一层宇宙），文件内
以注释明说。

### Isabelle/ZF：公理化集合论的实名锚点

Isabelle（examples/isabelle/ST71/Ordinals.thy）的三分律是
`Ord_linear_lt`（obtains 形式逐案 blast）：

```isabelle
lemma comparability:
  assumes "Ord(i)" "Ord(j)" shows "i < j ∨ i = j ∨ j < i"
  using assms
  apply (rule_tac i = i and j = j in Ord_linear_lt)
   apply blast+
  done
```

命题 1.19（元素更小）一行：`blast intro: ltI lt_Ord`（j∈i 先经
`ltI` 升成 j<i，再由 `lt_Ord` 给 Ord(j)；注意库里的 `OrdmemD`
只给 j≤i，方向不够用）。V 塔的三条装配线（定义 1.64）逐字对应
`Vfrom_0`/`Vset_succ`/`Limit_Vfrom_eq`（本版 Isabelle 的 `Vset`
是缩写 `Vset(x) ≡ Vfrom(0,x)`，没有 `Vset_def`/`Vset_0` 这两个
事实名；而名为 `Vset` 的引理是递归展开式，库中明注"不适合重写"
——把它喂给 simp 会无限展开直至内存耗尽，三条装配线必须走
`by (rule …)` 的零搜索形态）；秩函数（定义 1.66）落在 `rank_of_Ord`
（RK(α) = α——"序数的秩恰是自己"，命题 1.21 的一般形态）与
`Vset_Ord_rank_iff`（b ∈ V_α ⟺ rank(b) < α——"每个集合住在
第 rank+1 层"）上。

### Coq/Agda：有限序数段的内禀三条件

Coq（examples/coq/Ch71_ordinals.v）与 Agda 用 70 章同款
`vonn`/`Von` 类型承载有限序数。核心是"成员 ⟺ 更小"的内核引理
——Φ₁Φ₂ 在有限段的全部内容：

```coq
Lemma vmem_lt : forall b a, vmem a b = true -> vsize a < vsize b.
Lemma vmem_ge : forall b a, vsize a < vsize b -> vmem a b = true.
```

两条夹出定理 1.50 的有限截面（`trichotomy`：三择一恰一成立）与
`vmem_irrefl`（a ∉ a——Φ₂ 的直接推论）；定理 1.51 的有限版
`min_element`（非空列表必有 ∈-最小元）按"取尺寸最小者"证明：
更小者入内则尺寸下降，自相矛盾。Agda 版多走一步：`pick` 产出
一个 record（元素、成员资格、尺寸最小性三证书），`minimal` 由
"成员严格更小 + 尺寸 ≤"挤出矛盾——同一证明的依赖类型写法。
RK(n) = n（命题 1.21 的有限版）在两家都是 `refl`：冯诺伊曼数字
在秩轴上排成斜率为 1 的直线，机器一眼看穿。

### Julia/Python：秩函数的可执行版本

计算通道把定义 1.66 做成程序——RK(a) = sup{RK(b)+1 | b ∈ a}：

```julia
function rank(a)
    isempty(a) && return 0
    1 + maximum(rank(e) for e in a)
end

@assert [rank(vn(n)) for n in 0:15] == collect(0:15)   # RK(n) = n
succ(x) = union(x, Set([x]))
@assert all(rank(succ(vn(n))) == rank(vn(n)) + 1 for n in 0:15)
```

命题 1.21 两条全量验证：RK(n) = n（0..15/0..19 直线）与
S∘RK = RK∘S（数字与混合集合样本全对）；Python 版还把 Vₙ 塔的
规模表打出来（|V₀..V₃| = 1, 2, 4, 16——|V₄| = 2^16，塔的爆炸率
第一次现形）。三择一与 sup/min（定理 1.50/1.51、命题 1.20）
在 0..9 的网格上决定性验证：`a ⊆ b ⟺ a ≤ b`、
sup{0,1,2} = ⋃ = 2、min{3,1,2} = 1。

### Prolog：谓词化三择一

Prolog（examples/prolog/71_ordinals.pl）把三择一写成三个互斥
出口谓词 `tri(a_lt_b, A, B)`/`tri(a_eq_b, ...)`/`tri(a_gt_b, ...)`，
主检定用 findall 收集出口并断言恰有一个——"三择一恰居其一"的
字面机器化；`vmin`（递归取尺寸最小者）与 `vunion`（线性链之并
= 最大者）分别承载定理 1.51 与命题 1.20 的 sup = ⋃。

### 边界如实标注

超限递归定义（定理 1.56）本体是类论陈述，机器不可全达：证明的
"每段存在"一步用替换公理把 f_ξ 的像收进集合，类型论里没有这一
步——对应的义务由归纳类型的 guard 条件承担（Coq/Agda 的终止
检查器是它的受限化身）。这正是"为什么类型论里定义序数算术不用
Replacement"的答案，也是 73 章 ε₀ 边界的伏笔。

## 71.7 收束：三定义一塔

序数的三副面孔在本章合流：**内禀三条件**（定义 1.57）、**传递集
合之塔**（命题 1.19：元素皆序数）、**秩序的长度**（72 章表示定理
