## 68.1 ω：最小无穷传递集合

无穷公理给了我们至少一个 Inf 集合——含 ∅、对后继 S(x) = x∪{x}
封闭。但 Inf 集合可能"太大"（比如 ω ∪ {ω} 也是 Inf 集）。要拿到
自然数集合，需要**最小**的那一个。冯琦的取法干脆利落：对任意
Inf 集合 u，令

W(u) = {a | a ∈ u ∧ ∀v(Inf(v) → a ∈ v)}

——u 中那些**落在每一个 Inf 集合里**的元素。

> **定理 1.5** (1) Inf(u) → Inf(W(u))；(2) Inf(u₁) ∧ Inf(u₂) →
> W(u₁) = W(u₂)；(3) 存在唯一的 u 同时满足 Inf(u) ∧ W(u) = u。

*证明*：(1) 设 Inf(u)。∅ ∈ u 且 ∅ 属于每个 Inf 集，故 ∅ ∈ W(u)。
设 a ∈ W(u)，则 a ∈ u 且 a 属于每个 Inf 集；于是 S(a) ∈ u（u 对
后继封闭）且 S(a) 属于每个 Inf 集，故 S(a) ∈ W(u)。得 Inf(W(u))。
(2) 任取 a ∈ W(u₁)：a ∈ u₂ 且 a 属于每个 Inf 集（u₁ 本身是 Inf
的），故 a ∈ W(u₂)；对称得反向包含；双包含即相等。(3) 存在性：
取任一 Inf 集 u₀，令 u* = W(u₀)；由 (1) 它是 Inf 集，由 (2)
W(u*) = W(W(u₀)) = W(u₀) = u*。唯一性：W(u) = u 与 W(v) = v 给出
u = W(u) = W(v) = v。∎

**定义 1.24** 这个唯一的集合记作 **ω**（或 ℕ），称为**自然数
集合**；a 是一个自然数当且仅当 a ∈ ω。

**例 1.7** 0 = ∅，1 = {0} = {∅}，2 = {0,{∅}} = {0,1}，
3 = {0,1,2}，……，n+1 = n ∪ {n} = {0,1,…,n}。这些集合都在 ω 里。

冯·诺伊曼的定义在此兑现：**每个自然数是所有严格小于它的自然数
之集合**。要害在"所有"——3 不只是有三个元素，3 的元素**恰是**
0、1、2，于是"m ∈ n"读作"m 小于 n"，属于关系本身就是大小关系。

> **定义 1.25（传递集合）** τ 是传递集合当且仅当
> ∀a(a ∈ τ → a ⊆ τ)。
> ——元素都"溶"在集合里：属于 τ 的东西，其元素仍属于 τ。

**例 1.8** (1) ω 是传递集合；(2) ω 的每个元素都是传递集合。

*证明*：(1) 即定理 1.6(3)，见下节。(2) 令 x ∈ ω。若 y ∈ x 且
a ∈ y，则由 (1) 的传递性两次下渗：y ∈ x ∈ ω 给 y ∈ ω，再
a ∈ y ∈ ω 给 a ∈ ω；于是 y 的元素全在 ω 里——但还需要 y ⊆ x
而不是 y ⊆ ω：这正是下节定理 1.6(4)（∈ 的传递性）。∎

"传递集合"这个名词在本教程 09 章（秩层级）与 11 章（传递模型）
都出现过；冯琦把它提前到第 1 章，因为他的整座大厦——自然数、
序数、累积层次 V_α——全是传递集合的塔。

**命题 1.8** Inf(u) → ω ⊆ u。*证明*：ω = W(ω) = W(u) ⊆ u。∎
——ω 是所有 Inf 集合的公共"芯"。与 Jech 路线（02 章）对照：
Jech 直接取所有归纳集的交 ⋂{u | Ind(u)}，冯琦用 W(u) = "u 中
属于每个 Inf 集的元素"绕开了"交需要先有集合族"的小循环
（⋂A 的定义 1.10 要求 A 非空集合——这里 A 是类不是集合！）。
这是一个漂亮的细节：**W(u) 只用分解原理**（{a ∈ u | ∀v(Inf(v)
→ a ∈ v)}），全程不碰类上的交。

## 68.2 ∈-归纳：ω 的九条基本事实

冯琦接下来一口气证明九条关于 (ω, ∈) 的基本事实，全部用同一个
模板：**"考虑 z = {a ∈ ω | ……}，证 Inf(z)，于是 z = ω"**。
这个模板就是归纳法原理的雏形——z 是 ω 的对后继封闭的子集，而
Inf 的 ω 是最小者，故 z = ω。

> **定理 1.6** 对任意 a, b, c ∈ ω：
> 1. a = ∅ ∨ ∃b(b ∈ a)（每个自然数要么空要么有 ∈-最小元般的前身）；
> 2. a ∈ S(b) ↔ (a ∈ b ∨ a = b)；
> 3. a ∈ ω → a ⊆ ω（ω 传递，例 1.8(1)）；
> 4. a ∈ b ∧ b ∈ c → a ∈ c（∈ 在 ω 上传递）。

*证明*（各取模板集 z）：(1) z = {a ∈ ω | a = ∅ ∨ ∃b(b ∈ a)}：
∅ ∈ z；若 a ∈ z 且 a ≠ ∅，取 b ∈ a，则 b ⊆ a（b 的元素也是 a
的元素——这里用到 (a=∅∨∃b∈a) 对 S(a) 的验证）得 S(a) ∈ z。
(2) 显然（S(b) = b∪{b}）。(3) z = {a ∈ ω | a ⊆ ω}：∅ ∈ z；
a ∈ z → S(a) = a∪{a} ⊆ ω。 (4) z = {c ∈ ω | ∀a,b∈ω(a ∈ b
∧ b ∈ c → a ∈ c)}：对 c 归纳，b ∈ S(c) 时 b ∈ c 或 b = c，
两种情况都用 (2) 化归。∎

> **定理 1.7** 对任意 x, y ∈ ω：
> 5. x ∉ x（反自反）；
> 6. x ∈ y → y ∉ x（无二循环）；
> 7. x ∈ y → (y = S(x) ∨ S(x) ∈ y)（前驱紧邻性）；
> 8. x ∈ y ∨ x = y ∨ y ∈ x（三分律）；
> 9. x ≠ ∅ → ∃y(x = S(y))（非零自然数有前驱）。

*证明*：(5) z = {x ∈ ω | x ∉ x}：∅ ∈ z；若 S(a) ∈ S(a) 则
S(a) ∈ a 或 S(a) = a，前者由定理 1.6(4) 得 a ∈ a 矛盾于归纳
假设，后者因 a ∈ S(a) = a 也矛盾。故 S(a) ∉ S(a)。(6) x∈y∧y∈x
由 1.6(4) 给 x ∈ x，违反 (5)。(7)(8)(9) 同款模板（(8) 的 z 对
"与所有 y 可比较"的 x 归纳，用 (7) 处理 y 与 S(x) 的关系）。∎

九条事实的证明没有用到任何新公理——只有无穷公理 + 分解原理 +
模板。读者应当把"考虑 z = {a ∈ ω | …}"读成本章的第一件重武器：
**内建于分解原理的归纳法**。下一节把它正式命名为定理。

## 68.3 自然数之序：最小数原理、归纳法与鸽子笼

**定义 1.26（大小比较）** 对 x, y ∈ ω：x ≤ y ↔ (x ∈ y ∨ x = y)。
定理 1.7(8) 说 ≤ 是全序，且 x ∈ y ↔ x < y（严格小于）。

**定义 1.27（线性序 / 偏序）** 非空集合 W 上的二元关系 < 是
**线性序**当且仅当：(1) 反自反 ∀x(x∈W → ¬(x<x))；(2) 传递；
(3) 可比较 ∀x∀y(x,y∈W → (x<y ∨ x=y ∨ y<x))。只满足 (1)(2) 的
叫偏序。——这是 57 章（Makinson 偏序）的集合论原生版；线性序
概念在本篇 72 章（秩序）升格为主角。

> **定理 1.8** 10. ∀a∈ω∃b(b ∈ a ∧ ∀x(x ∈ b ↔ (x ∈ a ∨ x = a)))
> 每个非空自然数有 ∈-最大元般的结构（此款为 a 的"前驱"结构式
> 表述）；11. ∅ ≠ A ⊆ ω → A 有 ≤-最小元 min(A)；12. 上确界式
> 的"后继覆盖"；13. 有上界的非空 A ⊆ ω 有最大元 max(A)。

*证明*（11，最小数原理）：A 非空，取 a ∈ A。若 a ∩ A = ∅，
则 a 是最小元（任何 x ∈ A 有 x ∉ a，而 x 与 a 可比较，得
a ≤ x）。若 a ∩ A ≠ ∅：a ∩ A ⊆ a 是**集合 a 的非空子集**，
由 (10)（对 a 用模板）取 b ∈ a∩A 满足 b ∩ (a∩A) = ∅——b 是
a 的"最深"元素；则 b ∩ A = (b∩a)∩A = b∩A = ∅，b 即最小元。∎
（12)(13) 练习。）

> **定理 1.9（数学归纳法原理）** 设 P(x, a₁,…,aₙ) 是带自由变元
> x 与参数的表达式。若 (1) P(0) 成立；(2) ∀n∈ω(P(n) → P(n+1))；
> 则 ∀n∈ω P(n)。

*证明*：令 A = {n ∈ ω | P(n)}（分解原理，P 带参数照样合法）。
由 (1)(2)，A 是 Inf 集合（含 ∅、对后继封闭）。由命题 1.8，
ω ⊆ A，而 A ⊆ ω，故 A = ω。∎

另一种证明：若 A ≠ ω，则 ω − A 非空，取最小元 m；m ≠ 0（因
0 ∈ A），取前驱 m = k+1，k ∈ A 而 k+1 ∉ A，违反 (2)。两种证明
分别对应"最小 Inf 集"与"最小数原理"两种归纳观——它们是同一
件事的两面（本教程 59 章的"归纳四阶"走的是后者的良基化推广）。

**归纳法的第一个应用：鸽子笼原理。**

> **定理 1.10（鸽子笼原理）** 设 n ∈ ℕ。若 f: n → n 是单射则
> f 必是满射；从而 f: (n+1) → n 不可能是单射。

*证明*：对 n 归纳。n = 0 时空函数，平凡。设结论对 n 成立，
证 f: (n+1) → (n+1) 单射则满射：
**情形一** f[n] ⊆ n。则 f↾n: n → n 单射，由归纳假设是满射；
又 f 单射且 f[n] = n，故 f(n) ∉ n，而 f(n) ∈ n+1 = n∪{n}，
只能 f(n) = n。于是 f 满。
**情形二** f[n] ⊄ n。存在唯一 k ∈ n 使 f(k) = n。定义 g: n → n：
g(i) = f(i)（i ≠ k 时）、g(k) = f(n)。g 是单射（f 的值换位），
由归纳假设 g 满；进而 f 满（g 的像里每个值要么是 f 的值，要么
经换位后仍是 f 的值）。∎

> **推论 1.1** (1) ∀n(|n| < |n+1|)；(2) ∀n∀m(n ∈ m → |n| < |m|)；
> (3) ∀n(|n| < |ω|)。
> ——任何自然数（作为集合）都严格小于 ω：**ω 是第一个无穷**。

配套的两个小件：**定义 1.28** X ⊆ ω **无界**当且仅当
∀n∃m∈X(n < m)，否则**有界**（∃n∀m∈X(m ≤ n)）；**引理 1.1**
m ∈ ω ∧ f: m → ω → f[m] 有界（对 m 归纳：n = max({k, g(m)+1})
盖住 g[m+1]）。有限个自然数有最大者——这也是 (13) 的内核。

**定义 1.29（∈-同构）** f: X → Y 是 (X,∈) 与 (Y,∈) 的同构映射
当且仅当 f 是双射且 ∀a,b(a,b ∈ X → (a ∈ b ↔ f(a) ∈ f(b)))。

> **定理 1.11（雪崩映射）** (1) X ⊆ n ∈ ω 时，存在唯一的序对
> (m_X, π_X)：π_X: (X,∈) ≅ (m_X,∈) 且 ∀i∈X(π_X(i) = π_X[i∩X])；
> (2) X ⊆ ω 无界时，存在唯一的 π_X: (X,∈) ≅ (ω,∈) 满足
> ∀k∈X(π_X(k) = π_X[k∩X])。π_X 称为无界子集 X 的**雪崩映射**，
> π_X[k∩X] 称为 X 的**自然列表**。

*证明思路*：(1) 对 n 归纳：X ⊆ n+1 时分解 X = (n∩X) ∪ {n}，
由归纳假设得 n∩X 的同构，把 n 映到 m_{n∩X} 延拓之。(2) 对每个
k ∈ X 用 (1) 得 π_{k∩X}；k < n（X 中）时这些片段可拼接
（π_{n∩X}↾(k∩X) = π_{k∩X}），令 π_X = ⋃_{k∈X}π_{k∩X}。满射性
反证：若 π_X[X] = m 是自然数，则 π_X↾m: m → X 双射，由引理
1.1 X 应有界——矛盾。∎

雪崩映射说的是：**任何无界子集 X ⊆ ω 的"长度"都是 ω**——
偶数集、素数集、平方数集……都能数到无穷。π_X(k) = |{x ∈ X |
x < k}| 就是"k 在 X 中的名次"。这是"可数无穷"的序结构原型，
也是 71 章序数同构唯一性的第一现场。冯琦取"雪崩"意象：π_X 从
每个 k 出发把 k 以下的所有 X 元素"推"下去，越推越长，永不回头。

到此冯琦总结公理进度：同一律、第一存在性、分解原理、幂集、
配对、并集、无穷——已齐；预告**映像存在原理**与 **∈-极小原理**
（70、75 章）补全 ZF。

## 68.4 第一递归定义定理

先备好语言（定义 1.30）：n ∈ ω 时 Aⁿ 的元素是 A 上**长度 n 的
序列**，A^<ω = ⋃{Aⁿ | n ∈ ω} 是有限序列全体，[A]^<ω = {a ∈
𝒫(A) | ∃n(|a| = |n|)} 是有限子集全体。

**定义（和谐）** 函数 f 与 g **和谐**（无冲突）当且仅当
∀x(x ∈ dom(f) ∩ dom(g) → f(x) = g(x))；函数的集合 F 是**和谐
函数系统**当且仅当其中任何两个函数彼此和谐。

> **命题 1.9** (1) f、g 和谐 ↔ f ∪ g 是函数；(2) F 和谐系统 →
> H = ⋃F 是函数，dom(H) = ⋃{dom(f) | f ∈ F}，且每个 f ∈ F
> 都 ⊆ H。（练习：全部是定义的机械验证。）

数学实践中的递归定义——加法（f_m(m,0) = m；f_m(m,n+1) =
f_m(m,n)+1，然后 + = ⋃{f_m | m ∈ ℕ}）、乘法、指数 2⁰ = 1、
2^{i+1} = 2^i·2、阶乘——全靠下面这条定理撑腰：

> **定理 1.12（第一递归定义定理）** 设 A 非空、a ∈ A、
> g: A×ω → A。则存在唯一的 f: ω → A 满足：
> (1) f(0) = a；(2) ∀n(f(n+1) = g(f(n), n))。

*证明*：**唯一性**：设 f、h 都满足，对 n 归纳证 f(n) = h(n)：
n = 0 时 f(0) = a = h(0)；归纳步 f(n+1) = g(f(n),n) = g(h(n),n)
= h(n+1)。

**存在性**分两引理：
**引理 1.2（有限近似存在）** 对每个 m ∈ ω 存在长度 m+1 的序列
f_m: m+1 → A 满足 (a) f_m(0) = a；(b) ∀n ∈ m(f_m(n+1) =
g(f_m(n), n))。——对 m 归纳：m = 0 取 f₀ = {(0,a)}；由 f_m 造
f_{m+1} = f_m ∪ {(m+1, g(f_m(m), m))}。
**引理 1.3（有限近似相容）** n ≤ m 时，f_m↾(n+1) = f_n，即任何
两个近似在公共定义域上一致。——对 i ∈ n+1 归纳，每步用 g 的
单值性。

令 F = {t ∈ 𝒫(ω×A) | ∃m ∈ ω(t: m+1 → A 是满足 (a)(b) 的
近似)}（分解原理）。由引理 1.2 F 非空，由引理 1.3 F 是和谐函数
系统。令 f = ⋃F：由命题 1.9，f 是函数且 dom(f) = ω（每个 m+1
都被某个近似覆盖）。验证 (1)：所有 t ∈ F 都有 t(0) = a，故
f(0) = a。验证 (2)：f(n) = t(n)、f(n+1) = t(n+1) 对长度足够的
t 成立，而 t(n+1) = g(t(n), n) = g(f(n), n)。∎

证明结构值得逐层品味：**先把无穷对象拆成有限片段（引理 1.2），
再证片段彼此咬合（引理 1.3），最后把咬合的片段焊接成整体
（命题 1.9）**。这个"有限近似 + 和谐系统 + 取并"三段式将原样
复制到 70 章第二递归定义定理与 71 章超限递归——它就是"归纳
定义"在集合论里的通用发动机。68.7 的 Python/Prolog 通道把三段式
做成可执行程序：近似序列 f₀ ⊆ f₁ ⊆ f₂ ⊆ … 逐步生成，取并。

两条加强版推论：

> **推论 1.2（强递归 / course-of-values）** 设 g: B^<ω → B。
> 则存在唯一的 f: ω → B 满足 ∀n(f(n) = g(f↾n))，其中
> f↾0 = ⟨⟩ 且 n = (n−1)∪(n−1)（即 f(n) 由**之前所有值**决定）。
> *证明*：对 A = B^<ω 用定理 1.12：F(0) = ⟨⟩、F(n+1) =
> F(n)∪{(n, g(F(n)))}；rng(F) 是和谐系统，取并。∎

> **推论 1.3（带参递归）** 设 a: P → A、g: P×A×ω → A。则存在
> 唯一的 f: P×ω → A 满足 f(p,0) = a(p)、f(p,n+1) =
> g(p, f(p,n), n)。

**例 1.10（迭代）** f⁰ = Id、f¹ = f、f^{n+1} = f ∘ f^n（图序：
先 f 后 f^n）；S⁰ = Id、S¹ = S、S^{n+1} = S⁰ ∘ S^n。注意例 1.9
的加法 f_m、乘法 g_m 都是推论 1.3 的实例——**每个 m 一个递归，
然后取并**是冯琦算术定义的固定句式。

## 68.5 应用一：三明治引理与 Cantor-Bernstein

> **引理 1.4（三明治引理）** 若 C ⊆ B ⊆ A 且 |C| = |A|，
> 则 |A| = |B|。

*证明*：令 f: A → C ⊆ B 为双射。递归定义两个序列（推论 1.3，
G(X,n) = f[X]）：

A₀ = A，B₀ = B，A_{n+1} = f[Aₙ]，B_{n+1} = f[Bₙ]。

由归纳法 A_{n+1} ⊆ Bₙ ⊆ Aₙ。令 Eₙ = Aₙ − Bₙ、E = ⋃{Eₙ | n ∈ ω}、
D = A − E。关键观察：f[Eₙ] = E_{n+1}（差与像交换），故
f[E] = E − E₀ ⊆ E；而 B = f[E] ∪ D（归纳验证）。定义

g(x) = f(x)（x ∈ E 时）、g(x) = x（x ∈ D 时）。

g 把 E 段"往下压一层"、把 D 段保持不动——两段无重叠地拼成
A → B 的双射（单射：两段各自单且 f[E]∩D = ∅；满射：B 的每个
元素要么在 f[E] 里要么在 D 里）。∎

> **定理 1.13（Cantor-Bernstein）** |A| ≤ |B| ∧ |B| ≤ |A| →
> |A| = |B|。

*证明*：f: A → B、h: B → A 单射。则 h∘f[A] ⊆ h[B] ⊆ A（图序：
先 f 后 h），且 |h[f[A]]| = |A|（f 双到像、h 单）。对三明治
（C = h[f[A]], B̂ = h[B], Â = A）得 |A| = |h[B]| = |B|。∎

对照 03 章：Jech 路线的 SB 定理用对称闭包（Cantor-Bernstein 的
经典走法），冯琦的三明治把"收缩序列 A ⊇ B ⊇ f[A] ⊇ f[B] ⊇ …"
显式递归出来，配 E/D 二分拼双射——**递归定理直接变现成等势
构造**。68.7 的 Python 通道把三明治做成有限可执行实验：给定
具体单射，现场算出 Aₙ、Bₙ、E、D 并验证拼出的 g 确实双射。

## 68.6 应用二：自然数序特征定理

> **定理 1.14（序特征）** 设 (A, ≺) 是线性序且满足：
> (1) A 无 ≺-最大元；(2) 每个非空 X ⊆ A 有 ≺-最小元；(3) 每个有
> 上界的非空 X ⊆ A 有 ≺-最大元。则 (A,≺) ≅ (ℕ,<)——存在双射
> h: A → ℕ 使 a ≺ b ↔ h(a) < h(b)。

*证明*：令 a₀ = min(A)。递归定义 f: ℕ → A：f(0) = a₀；
f(n+1) = g(f(n), n)，其中 g(x,n) = min{y ∈ A | x ≺ y}（由 (2)
良定义——A 无最大元保证集合非空，(2) 给最小元）。f 单调递增
（严格），故单射。**满射性反证**：若 A − f[ℕ] ≠ ∅，取 p =
min(A − f[ℕ])（用 (2)）。令 B = {q ∈ A | q ≺ p}。B 非空（否则
p = a₀ = f(0)）且 p 是 B 的上界，由 (3) 取 B 的最大元 q。q ≺ p
且 p 是 A 中紧随 q 之后的元素：若 q ∈ f[ℕ]，q = f(m)，则
g(q,m) = p，即 p = f(m+1)，矛盾；若 q ∉ f[ℕ] 则 q ∈ A − f[ℕ]
与 p = min 矛盾——两种都不可能，故满。h = f⁻¹ 即所求。∎

三条性质——无顶、最小数原理、有界最大数原理——恰好把 (ℕ,<)
从一切线性序中挑出来。72 章将把 (2) 单独提出来定义**秩序**
（well-order），届时 (1)(3) 合并成"秩序 + 无尾元"的刻画；
71 章的序数则是"传递的秩序"。特征定理的递归构造 f（每步取
"下一个"）正是雪崩映射的逆操作。

## 68.7 自然数算术：递归定义定理的第一次实战

> **定理 1.15（加法）** 在 ω 上存在唯一的加法函数满足
> +(m, 0) = m；+(m, n+1) = S(+(m, n))。按传统记 +(m,n) = m+n：
> m + 0 = m；m + (n+1) = (m+n) + 1。

存在性是推论 1.3（a(m) = m，g(p,a,n) = a+1）；唯一性是定理
1.12 唯一性的逐参数版。**乘法** m·0 = 0、m·(n+1) = m·n + m，
**指数** m⁰ = 1、m^{n+1} = m^n · m，同款。

> **定理 1.16** (1) 交换律 m+n = n+m；(2) 结合律 m+(n+k) =
> (m+n)+k；(3) 消去律 m+n = m+k → n = k；(4) 单调性 m < n →
> m+k < n+k。

冯琦把 (1) 的双归纳证明完整写出——它同时是"归纳法怎么嵌套"的
教学样本，全文照录：

*证明*（对 n 归纳，证 ∀m(n+m = m+n)）：
**基础 n = 0**：对 m 归纳证 0+m = m。m = 0 平凡；设 0+m = m，
则 0+(m+1) = (0+m)+1 = m+1。故 ∀m(0+m = m)，即 ∀m(0+m = m+0)。
**归纳步**：设 ∀m(n+m = m+n)，证 ∀m((n+1)+m = m+(n+1))。对 m
归纳：m = 0 时用基础情形：(n+1)+0 = 0+(n+1)。设 (n+1)+m =
m+(n+1)，则

(n+1)+(m+1) = ((n+1)+m)+1　　　　（定义）
　　　　　　= (m+(n+1))+1　　　　（对 m 的归纳假设）
　　　　　　= ((m+n)+1)+1　　　　（定义）
　　　　　　= ((n+m)+1)+1　　　　（对 n 的归纳假设）
　　　　　　= (n+(m+1))+1　　　　（定义）
　　　　　　= ((m+1)+n)+1　　　　（对 n 的归纳假设）
　　　　　　= (m+1)+(n+1)　　　　（定义）∎

六步推导、三种身份的交替（定义、内层归纳假设、外层归纳假设）——
交换律不是显然的，它是递归定义不对称性（递归在第二变元上）的
代价。68.7 机器通道里，Coq/Agda/Lean 逐字复刻这个双归纳：Coq 与
Agda 的 `induction n; induction m` 嵌套就是"对 n 归纳、内层再对
m 归纳"的原生语法。(2)(3)(4) 的证明同款（练习，冯琦 1.3.4 留给
读者；机器通道补齐）。
