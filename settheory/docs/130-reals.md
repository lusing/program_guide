# 130 · 整数、有理数、实数

> 数是人类心灵的自由创造。——戴德金（本章题词，接续第 128 章）

本章覆盖书 3.4-3.5 节（PDF 61-69 页）：从 ℕ 出发经两次商构造造出
ℤ 与 ℚ（并证明它们的可数性与"典型性"——康托往复法），然后面对
ℚ 的结构性缺陷，用戴德金分割造出 ℝ——第一个不可数的世界。

## 130.1 整数：减法的缺口

自然数对减法不封闭：m < n 时没有 p 使 m = n + p。解决方案是
**对称化**：

> **定义（书 3.4.1）**　在 ℕ×ℕ 上定义
> (m₁,n₁) ~ (m₂,n₂) ⟺ m₁ +ₙ n₂ = m₂ +ₙ n₁。
> **ℤ := ℕ×ℕ / ~**。

直观：对 (m,n) 读作 m − n；(m,n) ~ (m',n') 说的是 m−n = m'−n'。
序与运算按 (3.14) 逐项定义（例如加法是坐标相加；乘法是
(m₁m₂ + n₁n₂, m₁n₂ + n₁m₂)——"十字相乘"的配方）。

**良定性**是这里真正的工作量（练习 3.4.2 等）：定义引用了代表，
必须验证换代表不换结果——例如 [(1,0)] + [(0,1)] 无论取什么代表
都得 [(1,1)]。这正是第 127 章"商构造"机制的第一次实战。

> **命题（书 3.4.4）**　对任意 a = [(m,n)]，a + [(n,m)] = 0_Z——
> 负元就是**交换坐标**。

> **定理（书 3.4.6）**　ℕ 嵌入 ℤ：f(n) = [(n,0)]，保序、保加、
> 保乘。"ℤ 是 ℕ 的扩张"的严格含义是**存在这样的单射**，而不是
> ℕ ⊆ ℤ 这个字面命题。

机器侧的精确实现（`examples/python/130_reals.py`）把 (3.14) 原样
落地并与内建 int 对拍：

```python
def zcanon(m, n):
    k = min(m, n)
    return (m - k, n - k)                              # 规范形让一翼归零

def zmul(a, b):
    (m1, n1), (m2, n2) = a, b
    return zcanon(m1 * m2 + n1 * n2, m1 * n2 + n1 * m2)   # (3.14) 乘法

zof = lambda a: a[0] - a[1]                            # 解释映射到内建 int

ints = [(m, n) for m in range(4) for n in range(4)]
for a in ints:
    for b in ints:
        assert zof(zmul(a, b)) == zof(a) * zof(b)      # 十字相乘 = 乘法
```

16×16 对代表逐条核对——**良定性**（与代表选取无关）在机器上的
形态是：所有代表经规范形/解释映射后与内建运算一致。负元
（交换坐标）也在网格上全量验证。

## 130.2 有理数：除法的缺口

同样的对称化再来一次，这次修补**除法**：

> **定义（书 3.4.7）**　ℤ⁺ = {a ∈ ℤ | a > 0}（分母不用负数）。
> 在 ℤ×ℤ⁺ 上：(a₁,b₁) ~ (a₂,b₂) ⟺ a₁·b₂ = a₂·b₁。
> **ℚ := ℤ×ℤ⁺ / ~**。

运算按 (3.16)：加法是交叉相加（a₁b₂+a₂b₁, b₁b₂），乘法是坐标
相乘，序是交叉比较。0_Q = [(0,a)]，1_Q = [(a,a)]。

> **命题（书 3.4.10）**　(1) −p = [(−a,b)]；(2) 若 p = [(a,b)]、
> a ≠ 0：a > 0 时 1/p = [(b,a)]；**a < 0 时 1/p = [(−b,−a)]**。

(2) 的分情况不可省——分母 b 恒正的约定迫使负数的倒数要同时翻转
两个坐标（分母必须回到正数）。Python 单元在正负两个象限逐一对拍
`qmul((a,b), (b,a)) == (1,1)` 与 `qmul((a,b), (−b,−a)) == (1,1)`。

**可数性红利**（书 3.4.12-3.4.13）：可数集上的等价关系至多可数
多个等价类（x ↦ [x] 是满射）；ℤ、ℚ 都是"可数集的商"，且无穷，
故都**可数**。第 129 章的机制第一次兑现。

> **定义（书 3.4.14）**　线序 (X,<) **稠密**：至少两元素且任意
> a < b 之间有第三个元素。(ℚ,<) 稠密、可数、无端点。

> **定理（书 3.4.15，康托）**　任何可数的无端点稠密线序与
> (ℚ,<) 同构。

**证明（往复法 back-and-forth）**是本章的技术高潮。先定义**局部
同构**（书 3.4.16）：有穷子集间的保序双射。

**扩张引理（书 3.4.17）**　若 h 是局部同构、p ∈ P、q ∈ Q，则存在
局部同构 h_{p,q} ⊇ h 使 p ∈ dom、q ∈ ran。

证明：p 落在 h 定义域的某个"缝"里（三种位置：最左、两元素之间、
最右）；由 (Q,<) 稠密无端点，Q 侧同结构的缝里**必有**还未用过的
q_n（取下标最小者）；把 (p, q_n) 添进 h。若 q 恰已被用掉，就换到
对称的方向（用 P 侧的稠密性找 p_m）。∎

**主证明**：递归构造 h₀ = ∅，h_{n+1} = (h_n)_{p_n, q_n}（第 2n 步
照顾 P 侧第 n 个元素、第 2n+1 步照顾 Q 侧——这就是"往复"），
h = ⋃ₙ hₙ 是全定义、满、保序的双射。∎

机器侧，Julia 单元（`examples/julia/130_reals.jl`）把往复法当作
**算法**在 (ℚ,<) 与二进有理数 D = {k/2^m} 之间运行：

```julia
# 扩张引理（书 3.4.17）：稠密 + 无端点保证空隙里总找得到未用的伙伴
function extend!(h, p, side)
    if side == :q2d                                   # 把 p（ℚ 侧）加进 dom
        lo, hi = bounds(h.dom, p)
        ylo = lo == SENT_LO ? SENT_LO : h.ran[findfirst(==(lo), h.dom)]
        yhi = hi == SENT_HI ? SENT_HI : h.ran[findfirst(==(hi), h.dom)]
        c = findfirst(c -> ylo < c < yhi && !(c in h.ran), unique_d)
        c === nothing && return false
        push!(h.dom, p); push!(h.ran, unique_d[c])
    ...
```

120 步循环每步断言 `is_partial_iso(h)`（保序 + 单值 + 满 into）——
扩张引理的"缝里必有伙伴"在代码里是 `findfirst` 在稠密枚举中的
成功返回。往复法的现代后裔（模型论里的 Fraïssé 极限、可数饱和
模型的构造）都长这个样子。

## 130.3 ℚ 的缺陷：一个平方根引发的血案

> **定义（书 3.5.1）**　线序集 (X,≤) 有**最小上界性质**：每个
> 有上界的非空子集在 X 中有上确界。

> **定理（书 3.5.2）**　ℚ **没有**最小上界性质：A = {p ∈ ℚ⁺ |
> p·p < 2} 有上界而无上确界。

证明的核心是一条**魔法公式**：对任意有理 p > 0，令

    q = p − (p² − 2)/(p + 2)。　　(3.17)

直接计算（书 3.18）：p ∈ A ⟹ p < q ∈ A（A 无最大元）；p ∈ B =
{p | p² > 2} ⟹ q < p ∈ B（B 无最小元）。于是 A 的上界都不在 A
中（落在 B 里），而 B 没有最小元——上确界不存在。∎

这条公式的来历值得一问：它是 p² 的**牛顿迭代变体**（以 p+2 代
2p 做分母），收敛速率 |g′(√2)| = 2/(2+√2)² ≈ 0.17。两个机器单元
从不同侧面把它跑实——Lean（`examples/lean/Settheory/Ch130Reals.lean`）
把它证成定理：

```lean
/-- 书 (3.17) 的魔法公式：q = p − (p²−2)/(p+2)。
方向一：p ∈ A（0 < p 且 p² < 2）⟹ 存在更大的 q 仍在 A。 -/
example (p : ℚ) (hp : 0 < p) (h : p * p < 2) :
    ∃ q : ℚ, p < q ∧ q * q < 2 := by
  refine ⟨p - (p * p - 2) / (p + 2), ?_, ?_⟩ <;>
    [skip; skip]
  · field_simp
    nlinarith
```

清分母后两个目标都是多项式恒等式，`nlinarith` 收割——**书上的
"直接计算"在机器上就是两条恒等式**。Julia 侧把公式当迭代跑 40
步：序列单调上升、平方永小于 2、误差比率 < 0.23——(3.17)(3.18)
两式的动态版本。

还有一个**计数论证**预告实数的形态（书 3.5 节）：实数不能表示
为有理数的有序对——有序对全体可数，而实数不可数（下章证明）。
每个实数需要**一个有理数的无穷集合**来表示。这把路标直接指向
戴德金。

## 130.4 戴德金分割：实数

> **定义（书 3.5.3）**　A ⊆ ℚ 是**戴德金分割**，若：
> (1) A ≠ ∅ 且 A ≠ ℚ；(2) A 向下封闭；(3) A 无最大元。
> **ℝ := 全体戴德金分割**。

直观：每个分割是一条"刀口"。有理数 p 对应刀口 p_R = {q | q < p}
——刀口从有理数的"缝"里落下；而 √2 = {q ∈ ℚ⁺ | q² < 2} ∪ ℚ⁻
落在无理的位置上。注意负半轴的写法：q ≤ 0 全体属于 √2 的分割
（机器审计里我们就在这摔过一跤——坑账 #33）。

**序 = 包含**（书 3.5.5）：x ≤ y ⟺ x ⊆ y。核心定理：

> **定理（书 3.5.6）**　(ℝ, ≤) 有最小上界性质，且 **sup X = ⋃X**。

证明就是验证 ⋃X 还是分割（非空：并入任一成员；向下封闭：属于
某 x 的元素下方全在；无最大元：每个成员内部就没有最大元）——
三条性质的**并运算下封闭**是整个证明的引擎。∎ 对比第 127 章
习题 2.5.24（(P(X),⊆) 中 sup = ⋃）：实数的完备性在结构上就是
**幂集格的完备性在分割子格上的限制**。

加法（书 3.5.7）：x + y = {p + q | p ∈ x, q ∈ y}；负元（书 3.5.8）：
−x = {p | ∃q > p (−q ∉ x)}；乘法（书 3.5.9）对符号分四种情况，
正情形取下闭包。ℚ 嵌入 ℝ（书 3.5.10：p ↦ p_R），此后把 ℚ 视作
ℝ 的子集。最后：

> **定理（书 3.5.11）**　任何包含可数稠密子集的无端点完备线序
> 与 (ℝ, ≤) 同构。

证明把 7.2 节的往复法（在可数稠密子集 D 与 ℚ 之间）与完备性焊接：
f(c) = sup(h[K_c])，K_c = {d ∈ D | d ≤ c}——**实数是被"康托
往复 + 完备化"唯一确定的**。ℝ 的三个特征（稠密、完备、可数
稠密子集）缺一不可，去掉任何一个都有别的线序满足剩余条件
（ℚ 去完备、二进有理数加细则同构于 ℚ……）。

机器侧的窗口审计（`examples/python/130_reals.py`）在有限网格上
验证分割的三个条件（条件(3)只能降格为"边界余量版"——有限集恒
有最大元，无穷条件的有限影子必然带边角）、序 = 包含、深处一致
的加法、以及递增族的 ⋃ = 最大者的分割（sup = ⋃ 的有限彩排）：

```python
big = frozenset().union(*[cut_below(p) for p in (F(1, 2), F(2, 3), F(3, 4))])
assert big == cut_below(F(3, 4))                       # ⋃ 递增族 = 最大者的分割
```

Lean 侧锚定 ℝ 的最小上界性质与 √2 的无理性：

```lean
example : ∃ x, IsLUB {r : ℝ | r * r < 2} x := by
  apply Real.exists_isLUB ⟨1, by norm_num⟩
  refine ⟨2, ?_⟩
  rintro r hr
  rcases lt_or_ge r 2 with h | h
  · exact le_of_lt h
  · -- r ≥ 2 时 r² ≥ 4 > 2，与 hr 矛盾
    have h1 : 0 ≤ r - 2 := by linarith
    have h2 : 0 ≤ (r - 2) * (r - 2) := mul_nonneg h1 h1
    have key : 4 ≤ r * r := by nlinarith [h2]
    exact absurd hr (not_lt.mpr ((by norm_num : (2:ℝ) ≤ 4).trans key))

theorem sqrt_two_not_rational : Irrational (Real.sqrt 2) :=
  irrational_sqrt_two
```

`Real.exists_isLUB` 是书 3.5.6 的 mathlib 名字；`irrational_sqrt_two`
则是第 3.5.2 节的完整故事的终章——那个"不存在的上确界"在 ℝ 里
有名字，而它不是有理数。稠密性以 instance 形态存在
（`DenselyOrdered ℚ` / `DenselyOrdered ℝ` 各一行 `infer_instance`），
嵌入链 ℕ⊂ℤ⊂ℚ⊂ℝ 的保运算用 `push_cast; ring` 一步核账。

## 本章要点

1. ℤ = (ℕ×ℕ)/~、ℚ = (ℤ×ℤ⁺)/~：对称化修补逆运算；良定性（与代表
   无关）是商构造的入场费；负元 = 交换坐标；负数的倒数要翻转两翼。
2. ℤ、ℚ 可数（可数集的商至多可数）；(ℚ,<) 是可数无端点稠密线序的
   **唯一代表**——康托往复法（局部同构 + 扩张引理 + 交替递归）。
3. ℚ 无最小上界性质：A = {p | p²<2} 的魔法公式 q = p − (p²−2)/(p+2)
   同时封死"A 有最大元"与"B 有最小元"两条退路（牛顿迭代的亲戚）。
4. 实数 = 戴德金分割；序 = 包含；**sup = ⋃X**——完备性是幂集格的
   完备性在分割上的继承；(ℝ,≤) 由"稠密 + 完备 + 可数稠密子集"
   唯一确定（3.5.11）。
5. 机器面：商构造与内建数系的逐条对拍、往复法可执行、魔法公式
   两副面孔（Lean 定理 / Julia 迭代）、Lean 锚定 exists_isLUB 与
   √2 无理性。
