# 第 120 章　投影集合稳赢性 I：闭博弈提升与整齐树

## 1. 本章的任务与边界

本章进入原书第三卷第 3.3.4 节“投影集合稳赢性”。
主线从一个已经熟悉的有限事实出发：在完美信息博弈中，若每个位置都只有有限多个后续，便可以从终点向前计算胜负。
无限博弈不能直接照搬这个算法，因为一棵无限树未必有终点层可供第一次回填。
开集与闭集的决定性提供了第一类无限推广。
Martin 的进一步思想是把投影集合的博弈提升为带隐藏序数坐标的闭博弈。
本章依次讲清 Gale–Stewart 博弈、开闭决定性、Martin 的可测基数证明、测度塔、整齐树以及定理 3.55。
第 121 章再处理弱整齐性、投影、补集以及投影层归纳所需的进一步表示。
七份程序只处理一个四步二进制有限博弈。
它们验证逆向归纳和一个显式稳赢策略证书。
它们不实现超滤子，不构造序数树，不运行无限博弈，也不证明 Martin 或 Martin–Steel 定理。

## 2. 从第 119 章接过什么

第 119 章结束时，原书推论 3.33 给出了交错链的一根良枝。
若交错链在某枝之外连续无秩，那么该枝的直接极限有秩。
这个结论将在后续补树表示中发挥作用。
它本身还不是投影决定性。
投影决定性要求对每个相应实数集合，博弈双方之一拥有稳赢策略。
“某个直接极限有秩”和“某方有稳赢策略”属于不同类型的命题。
前者讨论模型与嵌入，后者讨论策略对所有合法应对的胜率。
Martin–Steel 的工作正是用前者所依赖的大基数资源建立后者。
因此本章不能把上一章的有限父表直接当作博弈策略。
本章另设有限博弈模型，并在正文中保持两种证书的名称和语义分离。

## 3. Gale–Stewart 博弈的基本数据

取一个非空动作集合 \(X\)，通常取 \(X=\omega\)。
赛局由张三与李四轮流给出动作，形成无限序列
\[
x=\langle a_0,a_1,a_2,\ldots\rangle\in X^\omega.
\]
张三选择偶数位置，李四选择奇数位置。
预先给定胜负集合 \(A\subset X^\omega\)。
若最终序列属于 \(A\)，张三获胜；否则李四获胜。
这个博弈记作 \(\mathcal G(A)\)。
一个位置是有限序列 \(p\in X^{<\omega}\)。
张三的策略在偶数长度位置上给出下一动作，李四的策略在奇数长度位置上给出下一动作。
策略只看当前有限历史，不能偷看对方未来动作。
固定双方策略后，归纳地产生唯一完整赛局。
若张三的策略对李四的每个策略都使结果属于 \(A\)，它就是张三的稳赢策略。
李四的稳赢策略则要求所有按它进行的结果都不属于 \(A\)。
集合 \(A\) 胜负确定，是指双方至少一方拥有稳赢策略。
双方不可能同时拥有稳赢策略，因为让两个策略相互对局会得到矛盾。

## 4. 为什么开集与闭集特殊

给 \(X^\omega\) 赋予通常的乘积拓扑，其中 \(X\) 取离散拓扑。
开集由有限前缀圆柱集合的并组成。
如果张三以开集 \(A\) 为获胜目标，那么每一次获胜都能在某个有限阶段得到认证。
此后无论双方如何行动，结果仍属于 \(A\)。
闭集则把角色反过来：若结果不在闭集 \(A\) 中，张三的失败会在有限阶段暴露。
这使“尚未失败”的位置具有可持续搜索的结构。
Gale–Stewart 定理断言开集以及闭集的博弈胜负确定。
证明不是把所有无限分支穷举一遍，而是沿没有稳赢策略的位置保持应对。
若李四没有稳赢策略，张三便始终选择仍不让李四获得稳赢策略的后续。
这样形成的赛局不可能落在闭集之外，否则有限失败前缀会与位置选择冲突。
开集情形通过交换玩家和取补得到。
这里使用的是无限位置空间上的策略论证，而不是有限深度算法。

## 5. 有限模型中的同一胜负原则

我们的有限模型把无限赛局截成恰好四步。
动作只有 0 与 1。
张三在第 0、2 步行动，李四在第 1、3 步行动。
张三的获胜条件是第二个动作与第三个动作相同。
完整历史写为 \([a,b,c,d]\)，终点收益就是 \(b=c\)。
终点的 16 种历史全部可列出。
内部位置共有 \(1+2+4+8=15\) 个，加上 16 个终点，共 31 个位置。
张三位置取两个子值的析取，因为只要有一种好动作即可。
李四位置取两个子值的合取，因为张三必须能应付两种动作。
这就是逆向归纳。
它同时体现“存在一步”和“对所有应对”的交替量词。
如果把析取与合取交换，根值就不再表示原博弈的张三胜率。

## 6. 一个可读的稳赢策略

张三开局选择 0。
李四第一步选择 \(b\) 后，张三第二步也选择 \(b\)。
李四最后一步 \(d\) 不影响第二个与第三个动作的相等性。
因此证书产生的完整赛局是
\[
[0,b,b,d].
\]
对 \(b,d\in\{0,1\}\) 的四种组合，终点收益都为真。
反过来，若张三开局为 0，李四选 1，而张三第二步又选 0，就得到 \([0,1,0,d]\)。
无论 \(d\) 是什么，这个历史都不满足获胜条件。
这条坏历史说明证书确实检查了关键动作，而不是对任何策略都打印成功。
Coq 与 Agda 的 `open_strategy_wins` 对两个布尔应对穷举并给出无公理证明。
Lean 与 Isabelle 也检查同一策略。
Julia、Python 和 Prolog 则输出四份具体证书。

## 7. 逆向归纳与策略证书不是同一件数据

根值为真表示张三存在稳赢策略。
显式函数 `certifiedMove` 则给出其中一个策略。
只计算根值而不保存选择，通常还不能恢复完整策略。
只展示四条获胜路径而不检查逆向归纳，也可能遗漏其他位置。
本章同时保留两种结果：根值为真，以及证书对全部应对获胜。
程序还检查张三第二轮的两个位置 \([0,0]\) 与 \([0,1]\) 都有获胜值。
这对应策略在李四每种第一步之后都能继续获胜。
有限穷举因此覆盖完整应对空间，而不是只挑有利对手。
这条纪律在无限定理中对应“对所有合法策略”的全称量词。

## 8. 开闭决定性不能直接推出投影决定性

开闭定理由拓扑条件提供有限失败见证。
一般投影集合未必具有这样的拓扑形式。
对 \(A\subset\omega^\omega\times\lambda^\omega\)，其投影为
\[
p[A]=\{x\in\omega^\omega:\exists\xi\in\lambda^\omega\ ((x,\xi)\in A)\}.
\]
即使 \(A\) 是闭集，投影也通常不是闭集。
对原博弈直接引用开闭决定性，前提便不成立。
对提升博弈可以引用闭集决定性，但必须把提升博弈的策略翻译回原博弈。
张三方向的翻译较直接，因为张三可以暗中保存额外坐标。
李四方向困难得多：李四不能依赖张三所选的某一个隐藏坐标。
Martin 的解决办法是用完全测度在所有隐藏坐标上取“几乎所有”的共同回答。
可数完备性再把这些局部共同回答拼成一条完整隐藏分支。
所以闭集决定性只是证明的一半，测度塔提供另一半。

## 9. Martin 定理 3.53 的陈述

定理 3.53 说：若存在一个可测基数，那么每个 \(\Pi^1_1\) 实数集合都是胜负确定的。
设 \(\kappa\) 可测，\(U\) 是 \(\kappa\) 上非平凡、\(\kappa\)-完全、正规的超滤子。
利用 \(\Pi^1_1\) 集合的特征表示，把每个实数 \(x\) 关联到 \(\omega\) 上的线性序 \(<_x\)。
关键等价是
\[
x\in A\quad\Longleftrightarrow\quad <_x\text{ 是一个秩序}.
\]
若 \(<_x\) 是秩序，就能保序嵌入足够大的序数 \(\kappa\)。
反过来，若存在这样的保序嵌入，\(<_x\) 不可能含无限下降序列。
这把“\(x\in A\)”改写成“存在序数坐标见证”。
提升博弈让张三在走出自然数动作的同时，暗中给出这些坐标。

## 10. 乘积超滤子

从正规测度 \(U\) 递归构造 \([\kappa]^n\) 上的 \(U^n\)。
第一层为
\[
U^1=\{\{\{\alpha\}\in[\kappa]^1:\alpha\in X\}:X\in U\}.
\]
给定 \(U^n\)，对 \(X\subset[\kappa]^{n+1}\)，令 \(X\in U^{n+1}\) 当且仅当
\[
\{\alpha<\kappa:\{\{\beta_1,\ldots,\beta_n\}\in[\kappa-(\alpha+1)]^n:
\{\alpha,\beta_1,\ldots,\beta_n\}\in X\}\in U^n\}\in U.
\]
每个 \(U^n\) 都是 \(\kappa\)-完全的非平凡超滤子。
有限子集按递增顺序枚举，因此它也记录一个有限序数序列。
乘积构造使较短的见证恰好是较长见证的限制。
这一点后来成为测度塔的投影相容性。

## 11. 提升博弈 \(G(A^*)\)

定义
\[
(x,\xi)\in A^*\quad\Longleftrightarrow\quad
\forall m,n\in\omega\ (m<_x n\longleftrightarrow\xi_m<\xi_n).
\]
张三的第 \(k\) 次动作是 \((a_{2k},\xi_k)\)，李四仍只给自然数 \(a_{2k+1}\)。
张三赢得提升赛局，当且仅当最终 \((x,\xi)\in A^*\)。
换言之，\(\xi\) 必须给出从 \((\omega,<_x)\) 到 \((\kappa,<)\) 的序嵌入。
条件对任意有限 \(m,n\) 都可检查，违反条件会在有限阶段出现。
所以 \(A^*\) 是闭集，提升博弈由 Gale–Stewart 定理胜负确定。
若张三获胜，他不仅得到 \(x\in A\)，还公开构造了一个秩序见证。
这个“额外证明义务”正是提升博弈变严格的地方。

## 12. 张三策略的投影

假设 \(\sigma^*\) 是张三在 \(G(A^*)\) 中的稳赢策略。
原博弈中的张三暗中运行 \(\sigma^*\)，保存所有 \(\xi_k\)，但只公布自然数分量。
形式地，开局取
\[
\sigma(\varnothing)=(\sigma^*(\varnothing))_0.
\]
在已有隐藏历史之后，面对李四的 \(a_{2k+1}\)，仍取 \(\sigma^*\) 回答的自然数分量。
任何按 \(\sigma\) 进行的原赛局都能补回张三暗中保存的序数序列。
补出的提升赛局遵循 \(\sigma^*\)，故属于 \(A^*\)。
于是 \(<_x\) 是秩序，原结果 \(x\in A\)。
这个方向不需要消去量词，因为同一个张三同时控制自然数与隐藏坐标。

## 13. 李四策略为何需要测度平均

假设 \(\tau^*\) 是李四在提升博弈中的稳赢策略。
若原博弈的李四只固定一组 \(\xi\)，张三可能换一组坐标使提升策略失效。
李四必须在所有可能的有限隐藏历史上统一回答。
设 \(p=\langle a_0,\ldots,a_{2n}\rangle\)，\(v\in[\kappa]^{n+1}\)。
按 \(<_p\) 的顺序把 \(v\) 写成 \(\langle\xi_0,\ldots,\xi_n\rangle\)，并组成提升历史 \(q^*(p,v)\)。
定义
\[
\tau(p)=m\quad\Longleftrightarrow\quad
\{v\in[\kappa]^{n+1}:\tau^*(q^*(p,v))=m\}\in U^{n+1}.
\]
自然数只有可数个，而 \(U^{n+1}\) 是 \(\kappa\)-完全且 \(\kappa>\omega\)。
因此恰有一个回答 \(m\) 在测度意义下占优。
这就是原博弈中李四的第 \(n\) 次回答。

## 14. 一个共同的测度一大集合

对每个有限位置 \(p\)，令
\[
Z_p=\{v\in[\kappa]^{n+1}:\tau(p)=\tau^*(q^*(p,v))\}.
\]
则 \(Z_p\in U^{n+1}\)。
由乘积测度的定义，可取 \(X_p\in U\) 使 \([X_p]^{n+1}\subset Z_p\)。
位置只有可数个，取 \(X=\bigcap_pX_p\)，仍有 \(X\in U\)。
于是对所有位置，来自 \(X\) 的有限见证都给出同一个测度平均回答。
若按 \(\tau\) 进行的原赛局结果 \(x\) 竟属于 \(A\)，秩序 \(<_x\) 便可嵌入 \(X\)。
把该嵌入作为张三的隐藏坐标，就得到遵循 \(\tau^*\) 的提升赛局。
但它同时属于 \(A^*\)，与 \(\tau^*\) 是李四稳赢策略矛盾。
所以原结果必不在 \(A\) 中，\(\tau\) 是李四的稳赢策略。

## 15. 从证明中抽取树表示

Martin 证明不仅给出胜负，还提示一种可复用的树结构。
对 \(p\in\omega^{<\omega}\)，令 \(<_p\) 是特征表示给出的有限线性序。
定义 \(\omega\times\kappa\) 上的树
\[
T=\{(p,s):\operatorname{dom}(p)=\operatorname{dom}(s),\
s:(\operatorname{dom}(p),<_p)\to(\kappa,<)\text{ 保序}\}.
\]
若 \(g\in[T(x)]\)，则 \(g\) 把整个 \(<_x\) 保序嵌入 \(\kappa\)，所以 \(x\in A\)。
若 \(x\in A\)，秩序表示给出这样的 \(g\)，所以 \(x\in p[T]\)。
因此 \(A=p[T]\)。
树把无限存在量词分解为逐层有限序列的相容延伸。
下一问是：哪些测度结构能保证“逐层测度一大”真的产生无限分支。

## 16. 测度与投影的形式定义

原书定义 3.35 把 \(X\) 上的 \(\sigma\)-完全超滤子称为测度，集记作 \(m(X)\)。
对 \(\mu\in m(X)\)，记 \(\mu(A)=1\) 当且仅当 \(A\in\mu\)。
测度诱导超幂嵌入 \(j_\mu:V\to M_\mu\)。
若 \(X=Y^{<\omega}\)，\(k(\mu)\) 表示测度实际所在的有限长度。
较长序列到较短序列的限制映射诱导测度投影。
若 \(\mu_2\) 投影到 \(\mu_1\)，记作 \(\mu_1<_{RK}\mu_2\)。
这是 Rudin–Keisler 序的特例：对每个 \(A\)，\(\mu_1(A)=1\) 当且仅当其限制逆像的 \(\mu_2\)-测度为 1。
相应超幂之间有典型嵌入 \(j_{\mu_1,\mu_2}\)，并满足
\[
j_{\mu_2}=j_{\mu_1,\mu_2}\circ j_{\mu_1}.
\]
投影相容不仅是集合同一性的要求，也是模型能够形成正向系统的原因。

## 17. 测度塔与可数完备性

塔序列 \(\langle\mu_n:n<\omega\rangle\) 要求 \(k(\mu_n)=n\)，且 \(m<n\) 时 \(\mu_n\) 投影到 \(\mu_m\)。
称它可数完备，是指任意选择 \(A_n\in\mu_n\)，都存在 \(f\in Y^\omega\) 使
\[
\forall n<\omega\ (f\upharpoonright n\in A_n).
\]
注意 \(A_n\) 可以逐层缩小，不能只要求每层非空。
可数完备性要求一个共同的无限线程同时穿过所有被选的大集合。
引理 3.92 说，这等价于相应超幂模型和嵌入系统的正向极限有秩。
若直接极限无秩，下降序列可以转化为某些大集合之间没有共同线程。
若有共同线程，则可借助它验证直接极限的良基性。
本章采用原书陈述，不把这条练习证明伪装成七通道机器定理。

## 18. \(\Pi^1_1\) 树上的测度族

固定 \(p\)，每个 \(v\in[\kappa]^{\operatorname{dom}(p)}\) 都唯一确定一个保序有限序列 \(s_v^p\)。
对 \(X\subset\kappa^{\operatorname{dom}(p)}\)，定义
\[
X\in U_p\quad\Longleftrightarrow\quad
\{v\in[\kappa]^{\operatorname{dom}(p)}:s_v^p\in X\}\in U^{\operatorname{dom}(p)}.
\]
于是 \(U_p\) 是相应序列空间上的 \(\kappa\)-完全测度。
合法截面 \(T_p\) 具有测度一。
若 \(q\) 延伸 \(p\)，则 \(U_q\) 投影到 \(U_p\)。
更关键的是
\[
x\in p[T]\quad\Longleftrightarrow\quad
\langle U_{x\upharpoonright n}:n<\omega\rangle\text{ 可数完备}.
\]
若已有分支，可利用一个共同的齐次集 \(X\in U\) 让分支的有限段落入任意所选大集合。
反之，每层合法截面本身测度一，可数完备线程就是所求分支。
定理 3.54 因而说：可测基数下，每个 \(\Pi^1_1\) 实数集合都是 \(\kappa\)-整齐苏斯林集合。

## 19. 定义 3.36：整齐树

设 \(T\) 是 \(\omega\times\kappa\) 上的树。
它是 \(\delta\)-整齐树，需要非空 \(B\subset\omega^{<\omega}\) 和函数
\[
\pi:B\to m(\kappa^{<\omega}).
\]
对每个 \(s\in B\)，测度 \(\pi(s)\) 是 \(\delta\)-完全的，并且 \(\pi(s)(T_s)=1\)。
对任意实数 \(x\)，要求 \(x\in p[T]\) 当且仅当以下两件事成立。
第一，所有前缀 \(x\upharpoonright n\) 都属于 \(B\)。
第二，序列 \(\langle\pi(x\upharpoonright n):n<\omega\rangle\) 是可数完备塔。
“\(<\delta\)-整齐”表示对每个 \(\alpha<\delta\) 都是 \(\alpha\)-整齐。
“整齐”表示存在某个这样的序数。
平凡测度都是 \(\sigma\)-完全的，所以 \(\omega\times1\) 上的树提供了最简单的例子。
定义 3.37 把树的性质转移到其投影集合，得到整齐苏斯林集合。

## 20. 定理 3.55：整齐表示推出决定性

定理 3.55 假设 \(\kappa\) 是不可数正则基数，\(T\) 是 \(\omega\times\lambda\) 上的 \(\kappa\)-整齐树，且 \(A=p[T]\)。
结论是 \(A\) 胜负确定。
证明把定理 3.53 的两个策略翻译方向推广到任意整齐树。
定义
\[
A^*=[T]=\{(x,\xi):\forall m\ ((x\upharpoonright m,\xi\upharpoonright m)\in T)\}.
\]
这是闭集，所以提升博弈胜负确定。
张三的稳赢策略仍可通过隐藏坐标投影下来。
若李四在提升博弈有稳赢策略 \(\tau^*\)，则利用测度族定义原博弈回答
\[
\tau(p)=m\quad\Longleftrightarrow\quad
\{s\in T_{p\upharpoonright(n+1)}:\tau^*(q^*(p,s))=m\}
\in U_{p\upharpoonright(n+1)}.
\]
这里使用 \(\kappa>\omega\) 的完全性，保证可数多个自然数回答中有唯一测度一大者。

## 21. 可数完备性怎样完成反证

假设按 \(\tau\) 对局的结果 \(x\in A\)。
由整齐树定义，相关测度塔可数完备。
令 \(Z_0=\{\varnothing\}\)，并逐层收集使 \(\tau^*\) 的实际回答等于 \(x(2n+1)\) 的合法隐藏历史。
每个 \(Z_n\) 都在相应测度中。
可数完备性给出 \(f:\omega\to\lambda\)，使所有 \(f\upharpoonright n\in Z_n\)。
于是 \((x,f)\in[T]\)，同时提升赛局遵循李四的 \(\tau^*\)。
前者说张三赢得提升赛局，后者说李四必赢，矛盾。
所以 \(x\notin A\)，\(\tau\) 在原博弈稳赢。
这里可数完备性不是装饰条件，而是把有限阶段的一致性变成完整反证赛局的枢纽。

## 22. 为什么开闭结果仍不是全部投影决定性

定理 3.55 只覆盖拥有整齐树表示的集合。
要证明整个投影层级胜负确定，必须知道这种表示在补集和投影下怎样传递。
实数的投影操作对应集合层级的存在量化，补集则对应否定。
如果只知道某一层部分集合有表示，就不能对下一层任意集合引用定理。
Martin–Steel 的归纳需要同时追踪集合的复杂度和见证表示所需的大基数强度。
在偶数层与奇数层之间，树表示、弱整齐表示和补树表示交替出现。
武丁基数提供交错链与张子的强度，使补集也能获得适当的整齐表示。
可测基数推出 \(\Pi^1_1\) 决定性只是入口，不是全投影层级结论。
第 121 章将从弱整齐树开始展开这条接口。

## 23. 交给第 121 章的明确接口

下一章首先使用定义 3.38 的弱整齐树。
弱整齐性允许测度族依赖两个实数前缀 \((s,t)\)，并要求某个辅助实数 \(y\) 与 \(x\) 共同提供可数完备塔。
它正好适合表示再取一次投影后的集合。
随后需要理解弱整齐集合与整齐集合的投影关系，以及整齐集合关于补集的表示。
原书后续定理 3.56、3.57 处理投影方向，定理 3.61 起处理补树方向。
投影层归纳的接口可写成：若某层集合具有适当大基数支持的整齐表示，则其补集和下一层投影也要获得足够强度的表示，再应用定理 3.55。
本章没有证明这些后续命题。
尤其没有把“开闭决定性”误写成“所有投影集合决定性”。

## 24. 七通道有限实现总览

下面七份代码共享相同的四步博弈和收益函数。
Lean、Coq、Agda、Isabelle 使用各自的递归或定义机制计算逆向归纳值。
Coq 与 Agda 额外把四种对手应对逐一列成证明分支。
Julia 使用自底向上字典填表，Python 使用从根向下的独立递归。
Prolog 用关系式析取与合取求解，并生成四份可打印证书。
源码全部逐字收入本章，便于脱离示例目录阅读。
阅读时应先理解前面的量词解释，再检查代码如何表达它们。
有限实现的价值在于验证算法和证书语义，而不是替代无限集合论证明。

## 25. Lean：布尔值递归与可判定证书

Lean 的 `value` 消耗燃料，燃料为零时读取终点收益。
历史长度为偶数时使用布尔析取，为奇数时使用布尔合取。
`certifiedMove` 开局返回 `false`，在长度二的历史中复述李四动作。
`open_strategy_wins` 对两个布尔参数分情形，四种情况都由计算完成。
`root_has_winning_value` 则检查完整 31 位置的递归求值。
代码中的 `decide` 只判定这些有限命题，不涉及任何实数或超滤子。

```lean
/- 第 120 章：四步有限开博弈、逆向归纳与显式稳赢策略。
   这里只证明有限前缀博弈，不声称证明无限投影决定性。 -/

def payoff (h : List Bool) : Bool :=
  match h with
  | _ :: b :: c :: _ => b == c
  | _ => false

def value : Nat → List Bool → Bool
  | 0, h => payoff h
  | fuel + 1, h =>
      if h.length % 2 = 0 then
        value fuel (h ++ [false]) || value fuel (h ++ [true])
      else
        value fuel (h ++ [false]) && value fuel (h ++ [true])

def certifiedMove (h : List Bool) : Bool :=
  match h with
  | [] => false
  | [_, b] => b
  | _ => false

def play (b d : Bool) : List Bool :=
  [certifiedMove [], b, certifiedMove [false, b], d]

theorem root_has_winning_value : value 4 [] = true := by decide

theorem every_second_round_position_is_winning :
    ∀ b : Bool, value 2 [false, b] = true := by decide

theorem open_strategy_wins (b d : Bool) : payoff (play b d) = true := by
  cases b <;> cases d <;> decide

theorem losing_reply_is_visible : payoff [false, true, false, false] = false := by
  decide
```

## 26. Coq：开前缀收益的穷举证明

Coq 版本使用 `Bool.eqb` 比较第二个和第三个动作。
递归中的回合判断显式写成 `Nat.eqb` 与 `Nat.modulo`，避免记号解析歧义。
`open_strategy_wins` 的 `intros [] []` 同时穷举李四的两次布尔应对。
随后 `reflexivity` 验证每种完整历史的收益。
根值和两个第二轮位置的定理也均由计算闭合。

```coq
(* 第 120 章：有限开前缀博弈；不冒充无限投影决定性。 *)
Require Import List Bool.
Import ListNotations.

Definition payoff (h : list bool) : bool :=
  match h with
  | _ :: b :: c :: _ => Bool.eqb b c
  | _ => false
  end.

Fixpoint value (fuel : nat) (h : list bool) : bool :=
  match fuel with
  | O => payoff h
  | S f =>
      if Nat.eqb (Nat.modulo (length h) 2) 0
      then orb (value f (h ++ [false])) (value f (h ++ [true]))
      else andb (value f (h ++ [false])) (value f (h ++ [true]))
  end.

Definition certified_move (h : list bool) : bool :=
  match h with
  | [] => false
  | [_ ; b] => b
  | _ => false
  end.

Definition play (b d : bool) : list bool :=
  [certified_move [] ; b ; certified_move [false ; b] ; d].

Theorem root_has_winning_value : value 4 [] = true.
Proof. reflexivity. Qed.

Theorem every_second_round_position_is_winning :
  forall b : bool, value 2 [false ; b] = true.
Proof. intros []; reflexivity. Qed.

Theorem open_strategy_wins :
  forall b d : bool, payoff (play b d) = true.
Proof. intros [] []; reflexivity. Qed.

Theorem losing_reply_is_visible :
  payoff [false ; true ; false ; false] = false.
Proof. reflexivity. Qed.
```

## 27. Agda：显式回合参数与结构递归

Agda 版本把“是否张三回合”作为布尔参数随递归交替。
这样不必在证明器中计算列表长度取模。
收益用布尔等价的展开式表示：两动作都真或都假。
`open-strategy-wins` 的四个分支全部是 `refl`。
这是一份直接的有限策略正确性证明，而非依靠外部求解器导出的结论。

```agda
module Ch120_pd1 where

open import Data.Bool using (Bool; false; true; not; if_then_else_; _∨_; _∧_)
open import Data.List using (List; []; _∷_; _++_)
open import Data.Nat using (ℕ; zero; suc)
open import Relation.Binary.PropositionalEquality using (_≡_; refl)

payoff : List Bool → Bool
payoff (_ ∷ b ∷ c ∷ _) = b ∧ c ∨ not b ∧ not c
payoff _ = false

value : ℕ → Bool → List Bool → Bool
value zero _ h = payoff h
value (suc fuel) even-turn h =
  if even-turn
  then value fuel false (h ++ false ∷ []) ∨
       value fuel false (h ++ true ∷ [])
  else value fuel true (h ++ false ∷ []) ∧
       value fuel true (h ++ true ∷ [])

certified-move : List Bool → Bool
certified-move [] = false
certified-move (_ ∷ b ∷ []) = b
certified-move _ = false

play : Bool → Bool → List Bool
play b d = certified-move [] ∷ b ∷ certified-move (false ∷ b ∷ []) ∷ d ∷ []

root-has-winning-value : value 4 true [] ≡ true
root-has-winning-value = refl

every-second-round-position-is-winning :
  (b : Bool) → value 2 true (false ∷ b ∷ []) ≡ true
every-second-round-position-is-winning false = refl
every-second-round-position-is-winning true = refl

open-strategy-wins : (b d : Bool) → payoff (play b d) ≡ true
open-strategy-wins false false = refl
open-strategy-wins false true = refl
open-strategy-wins true false = refl
open-strategy-wins true true = refl

losing-reply-is-visible : payoff (false ∷ true ∷ false ∷ false ∷ []) ≡ false
losing-reply-is-visible = refl
```

## 28. Isabelle/ZF：0/1 动作与列表递归

Isabelle 版本使用 ZF 列表和自然数 0、1 表示布尔数据。
`Value0` 至 `Value4` 显式逐层回填，张三回合取两个子值之一，李四回合要求两者都为一。
`Play(b,d)` 明确构造 \([0,b,b,d]\)。
收益证明只需要展开定义，因为首尾指定动作始终相等。
这里的 `Value` 也只在四层有限树上运行。

```isabelle
theory Pd1 imports "ZF.List" "ZF.equalities" begin

text \<open>第 120 章：四步有限开博弈。0/1 表示动作，张三在偶数长度位置行动。
这里不形式化无限投影博弈、测度塔或 Martin--Steel 定理。\<close>

definition Payoff where
  "Payoff(h) \<equiv> (if hd(tl(h)) = hd(tl(tl(h))) then 1 else 0)"

definition Value0 where "Value0(h) \<equiv> Payoff(h)"

definition Value1 where
  "Value1(h) \<equiv> (if Value0(h @ [0]) = 1 then Value0(h @ [1]) else 0)"

definition Value2 where
  "Value2(h) \<equiv> (if Value1(h @ [0]) = 1 then 1 else Value1(h @ [1]))"

definition Value3 where
  "Value3(h) \<equiv> (if Value2(h @ [0]) = 1 then Value2(h @ [1]) else 0)"

definition Value4 where
  "Value4(h) \<equiv> (if Value3(h @ [0]) = 1 then 1 else Value3(h @ [1]))"

definition CertifiedMove where
  "CertifiedMove(h) \<equiv>
    (if h = [] then 0 else if h = [0,0] then 0 else
       if h = [0,1] then 1 else 0)"

definition Play where
  "Play(b,d) \<equiv> [CertifiedMove([]),b,CertifiedMove([0,b]),d]"

lemma root_has_winning_value: "Value4([]) = 1"
  by (simp add: Value4_def Value3_def Value2_def Value1_def Value0_def Payoff_def)

lemma second_round_false: "Value2([0,0]) = 1"
  by (simp add: Value2_def Value1_def Value0_def Payoff_def)

lemma second_round_true: "Value2([0,1]) = 1"
  by (simp add: Value2_def Value1_def Value0_def Payoff_def)

lemma open_strategy_wins: "b=0 | b=1 \<Longrightarrow> Payoff(Play(b,d)) = 1"
  by (erule disjE; simp add: Play_def CertifiedMove_def Payoff_def)

lemma losing_reply_is_visible: "Payoff([0,1,0,0]) = 0"
  by (simp add: Payoff_def)

end
```

## 29. Julia：自底向上填完整位置表

Julia 先枚举 16 个终点，再从长度三一路填到空历史。
每个位置用完整元组作键，所以不会把不同历史混成同一个状态。
最终字典含 31 个条目。
程序独立断言根值、两个第二轮位置、四份策略证书和一条坏历史。
输出中的 `certificate=4/4` 指四种对手应对，不是四个不同策略。

```julia
# 第 120 章：自底向上的有限博弈表；不冒充无限投影决定性。

payoff(h) = length(h) == 4 && h[2] == h[3]

function solve_bottom_up()
    values = Dict{Tuple{Vararg{Bool}},Bool}()
    for bits in Iterators.product(ntuple(_ -> (false, true), 4)...)
        values[bits] = payoff(bits)
    end
    for len in 3:-1:0
        for prefix in Iterators.product(ntuple(_ -> (false, true), len)...)
            children = (values[(prefix..., false)], values[(prefix..., true)])
            values[prefix] = iseven(len) ? (children[1] || children[2]) :
                                               (children[1] && children[2])
        end
    end
    return values
end

certified_play(b, d) = (false, b, b, d)

function check_chapter()
    values = solve_bottom_up()
    @assert length(values) == 31
    @assert values[()]
    @assert all(values[(false, b)] for b in (false, true))
    @assert all(payoff(certified_play(b, d))
                for b in (false, true), d in (false, true))
    @assert !payoff((false, true, false, false))
    println("==== 120")
    println("positions=31 root=true certificate=4/4")
    println("END ====")
end

check_chapter()
```

## 30. Python：独立递归求解

Python 不复用 Julia 的表格，而从空历史递归展开完整树。
终点直接调用收益函数，内部节点按历史长度选择 `any` 或 `all`。
主程序另外枚举全部 16 个叶节点并检查策略证书。
两种实现采用相反的遍历方向，可对同一有限数学对象形成交叉检查。

```python
"""第 120 章：递归有限博弈求解器；与 Julia 的填表法独立。"""

from itertools import product


def payoff(history):
    return len(history) == 4 and history[1] == history[2]


def value(history):
    if len(history) == 4:
        return payoff(history)
    children = [value(history + (move,)) for move in (False, True)]
    return any(children) if len(history) % 2 == 0 else all(children)


def certified_play(b, d):
    return (False, b, b, d)


def main():
    assert value(())
    assert all(value((False, b)) for b in (False, True))
    leaves = list(product((False, True), repeat=4))
    assert len(leaves) == 16
    assert all(payoff(certified_play(b, d)) for b in (False, True) for d in (False, True))
    assert not payoff((False, True, False, False))
    print("==== 120")
    print("leaves=16 root=true certificate=4/4")
    print("END ====")


if __name__ == "__main__":
    main()
```

## 31. Prolog：把证书作为关系查询结果

Prolog 的张三节点只要一个子节点返回真，李四节点则要求两个都返回真。
`certified_move` 把策略写成关系。
`winning_certificate` 同时构造完整历史并检查收益，因此查询结果包含可审计的动作序列。
`findall` 收集四种应对的证书，并要求数量恰为四。
这里的有限搜索不用于搜索无限策略，也不模拟测度平均。

```prolog
:- encoding(utf8).
/* 第 120 章：逆向归纳与可打印稳赢策略证书；仅限四步有限博弈。 */

payoff([_, B, C, _], true) :- B == C, !.
payoff(_, false).

value(H, V) :-
    length(H, 4), !,
    payoff(H, V).
value(H, true) :-
    length(H, L), 0 is L mod 2, !,
    ( value_with_move(H, 0, true) ; value_with_move(H, 1, true) ).
value(H, true) :-
    value_with_move(H, 0, true),
    value_with_move(H, 1, true).

value_with_move(H, M, V) :- append(H, [M], H1), value(H1, V).

certified_move([], 0).
certified_move([0, B], B).

play(B, D, [A, B, C, D]) :-
    certified_move([], A),
    certified_move([0, B], C).

winning_certificate(B, D, certificate(A, B, C, D, true)) :-
    play(B, D, [A, B, C, D]),
    payoff([A, B, C, D], true).

main :-
    value([], true),
    forall(member(B, [0, 1]), value([0, B], true)),
    findall(C, (member(B, [0, 1]), member(D, [0, 1]),
                winning_certificate(B, D, C)), Cs),
    length(Cs, 4),
    writeln('==== 120'),
    maplist(writeln, Cs),
    writeln('root=true certificates=4/4'),
    writeln('END ===='),
    halt.
:- initialization(main).
```

## 32. 结果核对与有限边界

四个证明通道都检查根值、第二轮位置和显式证书。
Julia 与 Python 独立求解同一博弈，Prolog 输出四份证书。
有限开前缀博弈在这里被完整判定，因为其 31 个位置全部可计算。
但无限开集决定性不是把燃料继续增加就能得到的定理。
无限证明需要位置空间的拓扑与策略推理。
投影集合证明还需要树、测度、可数完备性和大基数假设。
因此本章对有限机器件和原书无限定理分别记账，不把前者当作后者的形式化。

## 33. 本章小结

Gale–Stewart 定理处理开集与闭集，为提升博弈提供决定性。
Martin 用可测基数和乘积超滤子把 \(\Pi^1_1\) 博弈转成闭博弈，再把双方策略翻译回来。
测度塔的可数完备性保证逐层测度一大的有限历史能拼成完整分支。
整齐树把这一资源抽象出来，定理 3.55 因而把决定性推广到所有整齐苏斯林集合。
投影层级的完整归纳还需弱整齐性和补树表示，这正是第 121 章的入口。
有限七通道程序则把逆向归纳、全称应对和策略证书变成可执行、可证明的小模型。
