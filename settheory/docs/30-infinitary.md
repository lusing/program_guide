# 30 · 无穷组合：Erdős 基数与分划演算

> 分划关系 κ → (λ)^<ω_μ 是大基数的组合指纹——每个大基数
> 都有一条属于自己的箭头关系。

本章覆盖 Jech §29：分划演算（partition calculus）、
Erdős-Rado 定理、Rowbottom 与 Jonsson 基数。

## 30.1 分划关系

**κ → (λ)^<ω_μ**：对每个 f : [κ]^<ω → μ，存在 H ⊆ κ
|H| = λ 使 f 在 [H]^<ω 上常数（同质集）。

**κ → (κ)^<ω₂**（Erdős 基数）：κ → (α)^<ω₂ 对一切 α < κ。

## 30.2 Erdős-Rado 定理

**定理** beth_n^+ → (ℵ₁)^{n+1}（对每个 n < ω）。

**推论**：对每个 κ 存在 λ 使 λ → (κ)^ω。

## 30.3 Rowbottom 与 Jonsson

**Rowbottom**：κ → (κ)^<ω_{<ℵ₀}——每个分划有大小 κ 的
同质集使每个有限元的像集可数。

**Jonsson**：每个代数结构有真初等子结构。

可测基数是 Rowbottom 的（超幂论证）；Jonsson 与 Rowbottom
的关系是活跃的研究领域。
