# 27 · 更多应用：Kurepa 树等

> 力迫的应用远不止独立性证明——它产生了现代集合论的全
> 部主要工具箱。

本章覆盖 Jech §26：力迫的其他应用——Kurepa 树、更多
组合/拓扑应用。

## 27.1 Kurepa 树

**Kurepa 树**：height = ω₁，每层可数，但**有多于 ℵ₁ 个
分支**（与 Suslin 树不同——Suslin 要求分支可数）。

Kurepa 树的存在独立于 ZFC（Jech 1972 在 L 中构造了
Kurepa 树；Silver 证明了某些大基数下不存在）。

**与 Suslin 树的关系**：两者都是 ω₁-树的极端行为——
Suslin 树分支/反链都少，Kurepa 树分支极多。

## 27.2 Jensen 的 ◊ 与 Suslin 假设

**◊**（diamond）：存在 ⟨A_α : α < ω₁⟩ 使对每个 A ⊆ ω₁
集合 {α : A ∩ α = A_α} 平稳。

V = L ⟹ ◊（Jensen 1972）⟹ SH（无 Suslin 树）。

◊ 是比 CH 更强的组合原则——它在 L 中免费获得。

## 27.3 力迫的更广泛应用

- **正规树力迫**：构造各种特殊树（Suslin/Kurepa/Aronszajn）
- **崩塌+Easton**：连续统函数的全域控制
- **迭代+对称**：各种弱选择公理的独立性层级
