## 123.1 这本教程讲什么

集合论有两个面孔。作为**语言**，它是整个数学的底座：函数、关系、
数系、空间，一切现代数学对象最终都用集合写出——本教程第 125-131 章
就是这件事的完整演示，从九条公理一路搭到实数。作为**对象**，它本身
是一门深邃的数学：无穷有没有大小之分？实数有多少个？每条命题都能
被证明或者证伪吗？这些问题在十九世纪末还带着哲学气质，到二十世纪
变成了精确的数学问题，并得到精确到令人震惊的回答：

- **无穷确实有大小之分**：偶数和自然数一样多，但实数严格更多
  （Cantor，1874）。
- **"多少"可以无休止地分下去**：没有最大的无穷——任何集合的幂集
  都严格更大（Cantor 定理）。
- **有些问题数学回答不了**：连续统假设（"实数恰是第二小的无穷"）
  在标准公理系统 ZFC 中既不可证也不可驳（Gödel 1938 + Cohen 1963）。

原书出自复旦大学多年的集合论课程讲义，听众从数学系到哲学系都有；
作者的立场（"哥德尔主义"的数学实在论）写在弁言里，并且贯彻全书：
逻辑与形而上学自古就是一体的，集合论是"数学化了的哲学"。本教程
保留原书的这条思想线索——每章开头的引文与哲学注记都如实提炼——
同时把所有定理的证明完整讲清，不需要读者去翻原书。

**机器通道**。本书的每个主题都配一台"影子机器"：

## 123.2 潜无穷与实无穷：两千年的犹豫

"无穷能不能当作**完成了的整体**？"——这个问题折磨了数学两千多年。

**潜无穷**（potential infinity）的立场由亚里士多德确立：无穷只在
"可以不断进行"的意义上存在，绝不是一个现成的对象。原书引《形而上学》
（吴寿彭译）：

> 至于"无穷"虽在潜能上有此存在，然而这类潜能的命意并不指望其实现，
> 这只在意识上有此潜在而已。……在分割过程中，潜在的"无穷"是有的。
> 但这无限毕竟不得实现为独立的存在。

从这时起到康托的时代，整个数学界基本只接受潜无穷。高斯 1831 年
致舒马赫的信是这种认识论的典型表态：

> 我极力反对把无穷量当成一种完成的东西来使用，这在数学上是绝对
> 不允许的。无穷只不过是在实际谈论极限时的一个说法。

但数学实践不断挑战这条禁令。最疼的一处是**无理数**。任何有理数
都能写成整数之比，而 √2 不能用有穷个有理数表达——在拒绝实无穷的
数学里，无理数概念无法得到说明。克莱因在《古今数学思想》中的慨叹
（原书引）：

> 数学史上最使人惊奇的事实之一，是实数系的逻辑基础竟迟至 19 世纪
> 后叶才建立起来。

柯西用极限救场：√2 是有理序列 1.4, 1.41, 1.414, 1.4142, … 的极限。
这保住了潜无穷的认识论——序列只是不断接近的过程。但其中有循环：
按柯西的定义，要确认序列收敛于 √2，必须先知道 √2 是什么；而在
定义出无理数之前，我们并不知道 √2 是什么。魏尔斯特拉斯的改进是
把"极限"换成"集合本身"：

> 无理数 √2 就被定义为集合 {1.4, 1.41, 1.414, 1.4142, …}。

这样无理数总算用有理数定义出来了——但代价是把一个**无穷集合当作
完成了的整体**。潜无穷的认识论在此走到了尽头：要么接受实无穷，
要么没有实数系。这正是康托出场的舞台。

## 123.3 康托的探索：等数、对角线与超穷数

### 等数：不数数的计数

一个集合的基数是元素的"个数"。我们通常靠"数数"确定它，但数数
的本质是在待数集合与 {0,1,2,3,…} 的前段之间建立**一一对应**。所以
一一对应本身就足以断言"一样多"：

> A 与 B **等数**，当且仅当 A 与 B 之间存在一一对应。

康托的关键观察：可以**先知道等数、而不知道任何一方的基数**。原书
的例子——你看到教室里座无虚席，又没有人站着，就能断言椅子与人的
基数相等，尽管你不知道具体数目。机器侧，"等数"就是一张不重不漏
的配对名单（`examples/python/123_intro.py`）：

```python
chairs = ["c%d" % i for i in range(30)]
people = ["p%d" % i for i in range(30)]
seating = dict(zip(chairs, people))                  # 一人一椅，无空椅无人站
assert len(seating) == len(chairs) == len(set(seating.values()))
```

`seating` 是一个字典：每个键（椅子）配一个值（人），键不重、值不漏
——这正是"函数是单射且映满"的原始形态。判断"等数"不需要数出 30，
只需要这张名单本身。

### 部分与整体：伽利略的困惑

全体自然数与全体平方数等数——n ↦ n² 是一一对应。原书导言里画了
两行对应（0,1,4,9,16,25 对 0,1,2,3,4,5）。这似乎违背"整体大于部分"。
康托的回答：**整体大于部分只是有穷集合的性质；与自身的真部分等数，
恰恰是无穷集合的定义性特征**。偶数同理：

```python
galileo = {n: n * n for n in range(K + 1)}
assert len(set(galileo.values())) == K + 1          # 单射：不同 n 给不同 n²
assert set(galileo.values()) == {n * n for n in range(K + 1)}   # 满到平方数
squares = set(galileo.values())
assert squares < set(range(K * K + 1))               # 平方数是自然数的真部分
```

三条断言依次说：对应是单的、对应映满平方数全体、平方数确实只是
自然数的真部分。无穷的"反直觉"从第一条主定理之前就开始了。

### 更大的无穷：对角线

平方数、偶数都"不过如此"，康托接着发现**有理数也与自然数等数**
（第 129 章给出证明与机器名单——沿对角线 p+q = d 爬行、只取互素对，
就能不重不漏地列出 Q⁺：0, 1, 1/2, 2, 1/3, 3, …）。也许所有无穷都
一样大？不——对角线法证明**实数不与自然数等数**：假设把实数列成
表，构造一个第 i 位与第 i 个实数的第 i 位都不同的新数，它与表中
每一行都不同，故漏网。第 131 章完整展开；机器彩排（同一文件）：

```python
rows = [[(i * j + i + j) % 2 for j in range(n)] for i in range(n)]
c = [1 - rows[i][i] for i in range(n)]               # 翻转对角线
for i in range(n):
    assert c[i] != rows[i][i]                        # c 与第 i 行在第 i 位不同
```

`c` 的构造保证了它与每一行至少差一位——这张 12×12 的表就是"实数
不可数"论证的有限排练。Julia 侧（`examples/julia/123_intro.jl`）用
同样的手法做了 16×16 的版本。

对角线法还能更强：**对任意集合 X，幂集 P(X) 严格大于 X**。所以
无穷的阶梯没有顶：ℵ₀（自然数的基数）< 2^ℵ₀ = c（实数的基数，
"连续统"）< 2^c < …。机器侧的有限影子：

```python
for k in range(0, 8):
    assert 2 ** k > k
assert 2 ** (2 ** 3) > 2 ** 3 > 3                    # 阶梯可无限续
```

### 希尔伯特旅馆：等数的直观训练场

无穷集合"与真部分等数"最著名的直观化是希尔伯特旅馆（原书虽未
展开，但它是第 128-129 章等势训练的最好热身）：无穷多间房全满，
新客到了——让全体客人从 n 号房搬去 n+1 号房，1 号房就空出来了；
甚至无穷多位新客——让 n 号房客搬去 2n 号房，奇数房全部腾空。
Julia 单元做了有限彩排（`examples/julia/123_intro.jl`）：

```julia
N = 100
guests = 1:N
new_rooms = [2n for n in guests]
new_rooms = new_rooms[new_rooms .<= N]               # 有限旅馆内住得下的部分
occ = Set(new_rooms)
freed = setdiff(Set(1:N), occ)
@assert length(new_rooms) == length(Set(new_rooms))  # 注入：无人撞房
```

注意 `@assert` 审计的两件事：搬迁后无人撞房（单射），腾出的奇数房
数量对账（⌈N/2⌉ 间）。有限旅馆只能装下"住得下"的那一半客人——
这个"住不下"恰恰是有限与无穷的分界；无穷端没有第 N+1 号房的墙，
全体右移一次到位。等数概念的伸缩性，读者现在可以先"摸到"，第 129 章再形式化。

## 123.4 希尔伯特第一问题：一个世纪的悬案

1900 年夏，巴黎国际数学家大会。38 岁的希尔伯特在报告中提出 23 个
问题，向新世纪挑战——其中第一个就是康托的连续统假设：

> **连续统假设（CH）**：实数连续统的基数 c 是第二小的无穷，
> 即 c = ℵ₁。

康托本人认为很快就能证明。此后的发展出乎所有人的预料：

- **1938 年，哥德尔**证明：在现有数学的框架（ZFC）内，**不能证明
  连续统假设是假的**（构造了满足 CH 的内模型 L，见第 145 章）。
- **1963 年，科恩**（Paul Cohen）证明：在 ZFC 内，**不能证明连续统
  假设是真的**（发明力迫法，见第 146 章）。科恩因此获菲尔兹奖。

两个结果合起来：**连续统问题在 ZFC 中不可判定**。这回答了一个
"数学问题"吗？它把问题变成了另一个问题：ZFC 之外还需要什么新公理？
原书正是为这个现代议题预备知识——这也是"对无穷概念的探索"一名的
由来。第 22、23 章将把两个独立性证明的**思想**完整讲清；机器在
那里能走多远、为什么元定理本身难以机器化，教程会如实标注。

## 123.5 原书的结构与本教程的路线

全书九章：集合与公理（1）→ 关系与函数（2）→ 实数的构造（3）→
序数（4）→ 基数（5）→ 滤、理想与无界闭集（6）→ 集合的宇宙（7）→
可构成集（8）→ 力迫（9）。本篇按同样的骨架展开为 25 章（123 导引
+ 124–147 正文），每章末尾有 Zig 式导航。读法建议：

- **第一遍（124-131 章）**：公理到实数——数学系读者的"重新地基"，
  哲学系读者的逻辑体操；机器通道在这里最密集。
- **第二遍（132-141 章）**：序数、基数、选择公理、滤子——集合论的
  引擎室，也是对角线法与递归的大本营。
- **第三遍（142-146 章）**：宇宙、L、力迫——元数学深水区；定理的思想
  全讲，机器边界如实交代。
- 第 147 章是全书速查表。

机器单元的运行方式：仓库根目录 `pwsh -NoProfile -Command

## 本章要点

1. 无穷有两种姿态：潜无穷（过程）与实无穷（完成的对象）；实数系
   的逻辑基础迫使数学选择实无穷（魏尔斯特拉斯的集合定义）。
2. **等数 = 存在一一对应**；与真部分等数是无穷集合的标志。
3. 对角线法给出第一个"更大的无穷"；幂集定理给出没有顶的阶梯
   ℵ₀ < c < 2^c < …；CH 是阶梯上的第一个空位。
4. CH 在 ZFC 中独立（Gödel 1938 不可驳、Cohen 1963 不可证）——
   本教程第 145-146 章的终点。
