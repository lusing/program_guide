# 63 · 命题逻辑：真值函数、范式与真值树

> 本章提炼 Makinson 第 8 章：真值函数连接词与二值原理、五种
> 逻辑关系（永真蕴含 ⊢、永真等价 ≡、不一致、永真式、可满足性）、
> 范式（DNF/CNF/最字母集/最模块化版）与真值树（语义分解树）。
> 它是 51 章 B-值语义的二值化身、47-48 章布尔代数的语法侧、
> 56 章"特征函数即真值"逻辑箱的兑现。全程只用 {¬,∧,∨} 三连接词
> 为原始件，{→,↔,⊕} 为缩写。

## 63.1 逻辑是什么

Makinson 开篇定位：逻辑 = **信念管理**（belief management）之学，
分三大件——推理（inference）、信念组织（organization）、信念变更
（contr变更/修订/更新）。本书只做推理中最基础的**演绎推理**：
前提真则结论必真（无懈可击的链接）。日常推理多为"似真"而非
"必然"——但数学与计算机科学只玩后者的游戏。

## 63.2 真值函数与二值原理

**二值原理**：每命题或真或假，不同真。真值函数 = {1,0}^n → {1,0}。
一位真值函数恰 **4** 个（f₁ 恒 1、f₂ 恒等、f₃ 否定、f₄ 恒 0）；二位
恰 **16** 个（2⁴ = 16——四行真值表每行二选）。幂级数：n 位真值
函数共 2^(2^n) 个。

**{¬, ∧, ∨} 函数完备**：对任一真值函数，取真值为 1 的行，
每行做**基本合取**（该行中为 1 的字母取正、为 0 的取负），再
取这些基本合取的**析取**——即 DNF。∎（矛盾式无 1 行，用
p ∧ ¬p 充当。）16 个二位函数的辨认表（书表 8.4）值得过一遍：
f₂=∨、f₈=∧、f₅=→、f₃=←、f₇=↔、f₁₀=⊕。

## 63.3 五大关系与状态

**语言** L：初等字母 p,q,r,… 在 {¬,∧,∨} 下闭包（59 章结构递归
的纯语法化身；括号保唯一可读性）。**赋值** v : E → {1,0}，**延拓**
v⁺ : L → {1,0} 唯一确定（结构递归定义原理的语义版）。

| 概念 | 记号 | 定义 |
|---|---|---|
| 永真蕴含 | A ⊨ b | 无 v 使 A 全真而 b 假 |
| 永真等价 | a ≡ b | v(a) = v(b) 对一切 v |
| 不一致 | A ⊨ ⊥ | 无 v 使 A 全真（⊥=falsum） |
| 永真式 | ⊨ a | ∅ ⊨ a（一切 v 下真） |
| 可满足 | 无 v 使 A 全假 | — |

**⊢ 是元语言记号**（turnstile），不是对象语言的连接词——p ⊢ q
不是公式、p→q 是公式。这个区分在 51 章（Viale 的 ⊩ vs ⟦·⟧）已经
预演过。

九条永真蕴含（书表 8.5，应背）：化简 ∧⁻、组合 ∧⁺、析取引入 ∨⁺、
分离规则 MP、拒取式 MT、析取三段论 DS、传递性、实质蕴涵、
两条爆炸律（a∧¬a ⊢ b 与 a ⊢ b∨¬b——空真与永真前提的边界效应，
66 章的相关性讨论由此起爆）。⊢ 自反、传递、不对称、不完备。
每条的真值表验证两行（MP 行检查、MT 四行全检查——书给全程）。

等价表（书表 8.9-8.10 核心）：双重否定、De Morgan ×2、分配 ×2、
幂等 ×2、交换 ×2、结合 ×2、吸收 ×2、→ 与 ↔ 的翻译等价、
⊕ 与 ¬↔ 翻译、扩展律 a ≡ (a∧b)∨(a∧¬b)。

## 63.4 范式四件套

**文字** = 字母或其否定。**基本合取** = 不重复字母的文字合取。
**DNF** = 基本合取之析取。**满 DNF**（full dnf）：每个析取支含全部
字母。语义构造法：真值表中 1 行 → 基本合取 → 析取（唯一、满）。
矛盾式无 DNF。

**语法构造法**（等价变换流水线）：翻译 →/↔ 为 ¬∧∨ → De Morgan
推 ¬ 入内（消除双重否定）→ 分配 ∧ 于 ∨ 之内 → 幂等清重复 → 清除
同时含正负同字母的基本合取。所得 DNF 通常非满，可用扩展律补满。

**CNF** = 对偶（基本析取之合取），三构造法：语法（对偶分配律）、
语义（0 行 → 基本析取——"非我行"）、搭桥法（先求 ¬a 的 DNF 再
否定 + De Morgan）。CNF 的逻辑程序化身：Horn 子句（恰一正文字
的基本析取）——Prolog 的骨架。

**最字母集**（least letter set）：字母 p 可从 a 中消除 iff a ≡ a′ 而
p 不现于 a′。引 falsum ⊥ 后矛盾式有最字母集 ∅。**定理**：每个公式
有唯一的**最**字母集（不只是极小——证明用代入 ⊥ 的技巧反证）。
例：(p∧q∧r)∨(p∧¬q∧r) ≡ p∧r；((p↔q)∨(p↔r)∨(q↔r)) ≡ ⊤。

**最模块化版**（most modular version）：将字母集**划分**成若干
胞腔，每个公式只取一个胞腔内的字母——使字母间的纠缠最小化。
Parikh 1999（有限情形）与 Makinson 2007（无穷情形）证明最细
分裂唯一。例：A = {¬p, r→((¬p∧s)∨q), q→p} ≡ {¬p, r→s, ¬q}
——四字母分裂为 {p},{r,s},{q} 三胞。56-57 章的划分-等价对应在
字母管理中的再现。

## 63.5 真值树

**动机**：真值表 2^n 行太笨；真值树 = 语义分解 + 分支剪除。
**方法**：根标 0:a（要证 a 永真）；按**分解规则**（书表 8.12-8.13）
逐步分解——**确定规则**（不分支）：1:¬a → 0:a、0:¬a → 1:a、
1:a∧b → 1:a, 1:b、0:a∨b → 0:a, 0:b、0:a→b → 1:a, 0:b
（counter-case——66 章主角）；**分叉规则**：1:a∨b、0:a∧b、
1:a→b、1:a↔b（双输出两侧）、0:a↔b（双输出两侧）。

**判读**：每支含**撞车对**（crash-pair：同式异号）为死（closed）；
全支皆死 → 根标签不可能 → a 永真。有活支 → 从活支**读出赋值**
（a 非永真的反例见证）。

**效率技巧**：先确定后分叉（推迟分支）；早死即停；活支即判。

**万能变换**：测矛盾 ⇔ 测 ¬a 永真；测 a ≡ b ⇔ 测 a↔b 永真；
测 a ⊢ b ⇔ 测 a→b 永真；测 {a₁,…,aₙ} ⊢ b ⇔ 测 (a₁∧…∧aₙ)→b。
永真性是**一切命题问题的总归**——判定程序的统一入口。

终止性：分解使公式变短、最终到字母——结构归纳可证。

## 63.6 机器通道

mathlib 的 `Mathlib.Logic.Propositional` 有 `Formula`/`evalAtoms`/
`isSat`（v4.33 新增），本章走自建：

```lean
-- examples/lean/Settheory/Ch63Prop.lean（节选）
inductive Form | var : String → Form | neg : Form → Form
  | conj : Form → Form → Form | disj : Form → Form → Form

def implies (a b : Form) : Form := .disj (.neg a) b   -- → 的缩写

-- MP 的语义验证：{a, a→b} ⊨ b 的逐赋值检查（2 变量 4 行）
-- 真值表即函数：63 章的赋值延拓是 51 章 B-值的二值特例
```

Coq 的 `Formula` 归纳 + `vm_compute` 判定真值是主战场；真值树
在 Python/Prolog 做搜索剧场（活支读出反例见证）；DNF 构造的
语义法与语法法在 Julia/Python 双实现对照。

## 63.7 收束

永真蕴含是数学推理的命题级骨架；范式是公式的"标准形"（同构
于多项式的标准形）；真值树是决策程序的骨架——它们的机器化
程度是全书最高的（每个概念都有直接的算法化身）。64 章把二值
语义推广为量词语义；65 章给 ⊢ 以证明论侧（推导树）；66 章回望
爆炸律的边界。
