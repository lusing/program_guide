# 53 · V^B：名的宇宙、混合引理与最大原理

> 三章的地基（语义、满性、混合）在集合论语言上的总装：
> **V^B**——真值在 B 中的"宇宙的影子"。每个集合有 check 名，
> 每个名字被泛型滤子读出一个集合，而全部一阶事实由 ⟦·⟧ 控制。
>
> 本章覆盖 Viale §7.0-7.1。

## 53.1 为什么需要名

经典两难（50 章世界 2 的重述）：泛型对象 G ∉ M——M 看不见
G，无法直接谈"M 加了 G 之后的真"。**解法：在 M 内部预制
"图纸"**。名字 τ 是一个集合论的描述，配上泛型滤子 G 后被
"读出"为真集合 τ_G。M 知道一切名字，V 知道一切 G；两者在
M[G] = {τ_G : τ ∈ M^B} 处会师。

Cohen 的原话（经由 Viale 复述）：M-泛型的 r ∉ M 虽不可在 M
内指名，但**关于 r 的一切有限信息**（r 的初始段们）都在 M 中；
把"信息的组织方式"当作对象——这就是名字。

## 53.2 V^B 的递归构造

**定义（Viale Def 7.1.2）** M 是 ZFC 的传递模型，B ∈ M 且
M ⊨ "B 是 cBa"：
- M^B_0 := ∅；
- M^B_{α+1} := {f : M^B_α → B 的部分函数}；
- M^B_λ := ⋃_{α<λ} M^B_α（λ 极限）；
- **M^B := ⋃_{α ∈ Ord^M} M^B_α**。

对照 V_α = 𝒫(V_β)：**部分函数替代子集**——"x ∈ y"的真值是
τ(x) ∈ B（τ 在 x 处的标号），不再是 0/1。B = 2 时部分函数 =
特征函数 = 幂集——**V^2 ≅ V**（49 章布尔环的对偶回声）。

**check 名（Viale Def 7.1.4）** 对 u ∈ V：
ǔ := {(v̌, 1) : v ∈ u}（按秩递归）。
例：∅̌ = ∅；{∅}̌ = {(∅̌, 1)}。**M 里的每个集合都有名字**，
且 M ⊆ 可被 G 读出复原（Viale Eq 7.1：ǔ_G = u 对一切 G）。

**名字的身份刻画（Fact 7.1.8）**：τ ∈ V^B ⟺ τ 是函数、
ran(τ) ⊆ B、且 trcl(τ) 中每个元素都如此——**Δ₁ 可定义**，
在传递模型间绝对（55 章 App A 的第一次实战）。

## 53.3 ⟦∈⟧ 与 ⟦=⟧：三条式的同时递归

**定义（Viale Def 7.1.25）** 对 τ, σ ∈ V^B，按秩对的**平方序**
（(α,β) <₂ (α',β') ⟺ max < max' 或 max 相等且字典序）同时
递归：

- **⟦τ ∈ σ⟧ := ⋁_{ξ ∈ dom(σ)} (σ(ξ) ∧ ⟦τ = ξ⟧)**；
- **⟦τ ⊆ σ⟧ := ⋀_{ξ ∈ dom(τ)} (¬τ(ξ) ∨ ⟦ξ ∈ σ⟧)**；
- **⟦τ = σ⟧ := ⟦τ ⊆ σ⟧ ∧ ⟦σ ⊆ τ⟧**。

三条式互相咬合（∈ 用 =，= 用 ⊆，⊆ 用 ∈）——平方序保证归纳
合法。一阶联词/量词沿用 51 章的语义（量词的 sup 在 V^B 上取）。

**外延公理成立（Viale Fact 7.1.33）**：
⟦∀u(u ∈ τ ↔ u ∈ σ)⟧ = ⟦τ = σ⟧——两条式的设计恰好把"同元素"
编码为"相等"。

**同构 ⇄ 连续函数（Def/Prop 7.1.34-35）** τ ∈ V^B 对应
f_τ : St(B) → 2^ω 型的连续函数（ω^B ↔ B^ω 的特例），且
τ ↦ f_τ 保持 ∈/= 的真值——52 章例三 C(St(B), 2^ω) 的
集合论升级。**名字 = St(B) 上的连续（半连续）图纸**。

## 53.4 两条硬定理

**定理（Viale Thm 7.1.27，V^B 是集合论的 B-值模型）**
(V^B, ∈, =) 满足 B-值模型的全部公理（等词三律 + 关系相容
——∈ 的相容律即 47.2 的序演算在 B 里的重演）。证明的骨架是
**立方归纳**：三个名字的秩三元组按立方序同时归纳，七个
不等式（对称、传递、∈-代换等）一揽子收割。

**混合引理（Viale Lemma 7.1.31）** 反链 A ⊆ B 与
{a_d : d ∈ A} ⊆ V^B：存在 τ ∈ V^B 使 ⟦τ = a_d⟧ ≥ d ∀d。
*证明的机关*：τ(t) := ⋁_{d ∈ A} (d ∧ a_d(t))——对 t ∈
⋃dom(a_d) 拼装标号；Exercise 3.3.5（c∧a ≤ b → c∧a ≤ c∧b）
承担"在 d 上值恰为 a_d"的检查。∎

**最大原理（Viale Thm 7.1.32）** V^B 满——强形式：
对一切 φ(x,ȳ) 与 f̄：**存在 τ** 使
⟦∃x φ(x, f̄)⟧ = ⟦φ(τ, f̄)⟧（不只是 ≤，是**等号**！）。
证明：sup 值 u₀ 下取稠密的见证层 d ∈ D，混合引理拼出 τ，
则 ⟦φ(τ)⟧ ≥ ⋁D = u₀ ≥ ⟦∃xφ⟧。∎

最大原理是 Viale 路线的"降龙十八掌"：**每一个存在量词都
有一个名字完美实现它的真值**——52 章满性哲学的集合论顶点。

## 53.5 外定义力迫（预告）

Viale §7.1.1 的戏剧：定义 b ⊩ φ :⟺ 对一切含 b 的 M-泛型
G：M[G] ⊨ φ_G。这个定义**在 M 中不可写**（量化泛型滤子超出
M 的能力域）——53-54 章的全部技术就是为了证明：内定义
（⟦φ⟧ ≥ b）与外定义**相等**（Cohen 力迫定理）。54 章收官。
