## 67.1 冯琦路线：为什么值得第四遍重讲

冯琦在引言里给出了一部浓缩的公理化史：策梅洛 1908 年为了回应罗素
悖论与函数的抽象定义问题，提炼出由已有集合获得新集合的四种基本
运算（配对、并、分离、幂集）加上同一律、无穷公理与选择公理；库拉
托夫斯基 1921 年补上有序对的集合定义，使函数与二元关系也成为集合
论论域中的**内在对象**；斯科伦指出策梅洛的"性质"表述有潜在二义性，
用一阶逻辑语言限定特性的表述，于是策梅洛的公理系统与弗雷格《概念
-文字》中的一阶逻辑发生融合；弗伦克尔为幂集迭代的收敛性问题补上
映像存在原理（替换公理）；冯·诺伊曼 1925 年给出"美妙绝伦、精湛
极致"的序数定义——序数在属于关系下**既是传递的又是有秩序的**，
于是每个序数就是所有比它严格小的序数之集合，自然数的集合定义
（每个自然数是所有严格小于它的自然数之集合）也随之免费得到。

这本书一开卷就区分了集合论的两副面孔：**一阶理论**探讨"论域中
都有什么对象存在、它们关系如何"；**二阶理论**（元数学）探讨"保证
这些对象存在的假设是否合理、是否多余、是否自洽"。一个**论域**是
所关注的一类数学对象的界定范围——有理数全体、实数全体分别是域论
的两个论域；论域中的对象叫**一阶对象**（域中的"数"），而子域、
同构、多项式这类以一阶对象为素材的结构叫**二阶对象**。本教程
00 章说过的"机器证明的七通道立场"正踩在这条分界线上：Lean/Coq
里的证明对象是一阶理论的内部推导，而"这个公理系统是否一致"只能
站在二阶（元理论）立场谈论——哥德尔第二不完备定理（引言里点名的
1931 年论文）说这个系统不能在自身之内证明自己的无矛盾性，除非它
本来就自相矛盾。

面对"什么是集合"这个直觉问题，冯琦的回答是一段方法论宣言：

> 面对诸如"集合"以及"属于"这样的初始概念（不加定义的概念），
> 我们不求给出数学定义，但求给出一系列条件来区分和限制我们所关注
> 的对象，这就是公理化：**不求初始定义，但求明确，但求准确，但求
> 用一系列的公理来有限度地表达我们对初始概念的"理解"或"期望"**。

这正是 01 章"公理不是真理而是承诺"的另一种说法。冯琦路线与前九
篇最大的组织差异是：**语言先行**。先把表达式怎么写、推理怎么走
讲清楚，公理才一句句登场。

## 67.2 集合论语言：表达式、等号的定义与罗素定理

### 67.2.1 基本符号与表达式

集合论语言的初始符号少得惊人：一族**变元**（表示论域中的集合），
一个二元关系符号 **∈**（属于），仅此而已。可读性所需的括号，以及
一阶逻辑提供的五个联结词与两个量词：

| 符号 | 名称 | 读法 |
|---|---|---|
| ¬ | 否定词 | "非" |
| ∧ | 合取词 | "与" |
| ∨ | 析取词 | "或" |
| → | 蕴涵词 | "蕴涵"（左为条件右为结论） |
| ↔ | 对等词 | "当且仅当"（相互蕴涵） |
| ∀ | 全称量词 | "所有的对象都……" |
| ∃ | 存在量词 | "存在一个对象……" |

**定义 1.1（表达式）**（冯琦 1.1.1）基本表达式是形如 (x ∈ y) 的
符号串；表达式由五条规则递归给出：(a) 基本表达式都是表达式；
(b) 若 Φ 是表达式则 (¬Φ) 是；(c) 若 Φ₁、Φ₂ 是表达式则 (Φ₁∧Φ₂)、
(Φ₁∨Φ₂)、(Φ₁→Φ₂)、(Φ₁↔Φ₂) 都是；(d) 若 Φ 是表达式则 (∀x Φ)、
(∃x Φ) 都是；(e) 表达式只能由上述四种途径得到。

注意这是本教程第一次见到**递归定义**——而且它出现在第一递归定义
定理（68 章）之前。语法层面的归纳不需要集合论的存在性公理背书：
表达式的世界是符号串的世界，归纳的是"怎样写成表达式"这条规则本身。
69 章 Agda 通道会把这种"语法归纳"变成原生数据类型。

**定义 1.2（自由与约束变元）**每个量词 ∀ 或 ∃ 出现时必有一个紧随
其后的受约束变元和一个明确的约束范围；范围内的每次出现叫受约束出
现；不在任何量词约束范围内的出现叫自由出现。有自由出现的变元叫表
达式的自由变元；出现而非自由者是约束变元。

**定义 1.3（替换）**若 y 在 Φ 中的每一次替换都不落入 ∀x/∃x 的约束
范围，则 y 可以在 Φ 中替换 x，记替换结果为 Φ(x;y)。

为什么要如此谨慎？冯琦给了一个量词交错的教学例子：欧几里得定理
"存在任意大的素数"形式化为 ∀x(x∈ℕ → ∃y(y∈ℙ ∧ x<y))；交换交错
量词的顺序得到 ∃y∀x(x∈ℕ → (y∈ℙ ∧ x<y))，翻译回来是"存在一个比
所有自然数都大的素数"——一目了然的假命题。**改变交错量词的顺序
可能改变命题的真假命运**；而作用范围相同的同类量词（∀x∀y 与
∀y∀x）交换则完全无害。日常思维错误的一大来源就是无意识地交换了
不该交换的量词。

### 67.2.2 等号：不是初始符号，而是公理定义

本路线最出人意料的决定：**等号不是集合论语言的初始符号**。语言里
只有 ∈。等式 x = y 怎么写？冯琦的做法是把**同一律**当作等号的定义
公理：

> **公理 1（同一律 / 外延公理）** ∀x∀y((x = y) ↔ ∀z(z ∈ x ↔ z ∈ y))

两个集合相等同的充分必要条件是它们具有完全相同的元素（成员）。
读法上，这"断言任何一个集合都唯一地由它的外延所确定"，所以又叫
外延公理（与 01 章 Jech 的 Extensionality 是同一条，只是此处它兼任
等号的定义：先用含 = 的表达式作为缩写，再用同一律把这个缩写展开成
纯 ∈ 语言）。集合论语言由此扩充为含 ∈ 与 = 两个基本符号，而 = 的
全部行为由公理 1 与 67.6 的恒等律、等同律两条逻辑公理管辖。

在公理 1 之前还有三条**等号三律**作为先行的逻辑约定：自反律
∀x(x=x)、对称律 ∀x∀y(x=y → y=x)、传递律
∀x∀y∀z(x=y ∧ y=z → x=z)。它们是逻辑层面的（67.6 的逻辑公理
(5)(6) 将把它们接走），公理 1 则是集合论层面的：**外延决定等同**。
于是证明两个集合相等的唯一法门是双包含：

**命题 1.1** x = y → (x ⊆ y ∧ y ⊆ x)（其中 x ⊆ y 即定义 1.4 的
子集合关系 ∀z(z ∈ x → z ∈ y)），且反过来也成立。
*证明*：→ 方向任取 z，由 x=y 及公理 1 得 z∈x ↔ z∈y。← 方向即
公理 1 本身。∎

此后每一处"证明两个集合相等"（比如幂集唯一性、ω 的唯一性、并集
的无歧义性）都走这条双包含路。

### 67.2.3 罗素定理：纯逻辑的悖论

用刚建好的语言，罗素悖论变成一条**定理**：

> **定理 1.1（罗素定理）** ¬∃a∀y(y ∈ a ↔ y ∉ y)

*证明*：假设不然，∃a∀y(y ∈ a ↔ y ∉ y)。取一个见证集合 M。于是对
任意集合 y 都有 y ∈ M ↔ y ∉ y。特别地取 y = M：M ∈ M ↔ M ∉ M，
断然不能成立。∎

冯琦特别提醒：这个证明是**纯粹的逻辑分析**，没有用到关于集合的
任何假设（连分解原理都没用）。它否定的只是"所有不属于自己的集合
之全体"是一个集合。语言里再配上**概括记号**：对显示全部自由变元
的表达式 Φ(a₀, a₁,…,aₙ) 与参数 a₁,…,aₙ，令

{a | Φ[a₁,…,aₙ, a]} := 由 Φ 在参数下规定的性质所确定的**类**。

类一般不是集合；当一个类被证明或被假设为集合时它才是。Φ 是内涵，
{a | Φ} 是外延——冯琦用概念/内涵/外延的哲学三联来解释这个区分。
罗素定理说 U = {a | a ∉ a} 这个类**不是集合**：¬(U = {a|a∉a} ∈ V)。
01 章的"安全网"叙事在冯琦这里化为一句冷静的话：概括记号合法，但
产物默认只是类。

## 67.3 存在性公理：七块积木

冯琦把 ZF 的非逻辑公理组织成"存在性公理"系列，一块块搭起来。

**公理 2（第一存在性）** ∃a(a = a)。
论域里有对象存在——"否则，我们将做毫无意义的事情"。这是全部大厦
的地基句：先有对象可关注，才谈得上别的。

**公理 3（幂集公理）** ∀x∃y∀z(z ∈ y ↔ z ⊆ x)。
**命题 1.2（幂集唯一性）**：满足要求的 y 至多一个。*证明*：设 y₁、
y₂ 都满足，则 ∀z(z∈y₁ ↔ z⊆x ↔ z∈y₂)，由公理 1 得 y₁ = y₂。∎
于是**定义 1.5** 幂集 𝒫(x) 名正言顺。注意这里的三步舞步——
存在（公理）、唯一（命题）、命名（定义）——是冯琦全书反复出现的
公理学节奏，后面 ω、并集、∅、加法运算全都照此办理。

**公理 4（分解原理 / 分离模式）** 对每个表达式 Φ(p₁,…,pₙ, z)
（z 不是 pᵢ 的自由变元）：
∀p₁…∀pₙ∀x∃y∀z(z ∈ y ↔ (z ∈ x ∧ Φ(p₁,…,pₙ, z)))。

这就是 01 章的 Separation：性质 Φ 只能从**已有**的集合 x 中分离
出子集合 {z ∈ x | Φ(z)}。同款三步舞：**命题 1.3** 给出分解唯一性
（练习，同样双包含）。分解原理的两个立即推论值得全文照录：

**例 1.3** ∀x∀z((z ∈ x) → (z ∈ x ∧ z = z))，即 {z ∈ x | z = z} = x
——平凡分离。

**例 1.4（万有集不存在）** 语句 ∃a∀y(y ∈ a) 被分解原理否定。
*证明*：假设 a 含一切集合。考虑表达式 (z ∉ z)，由分解原理
y = {z ∈ a | z ∉ z} 是一个集合。既然一切集合都在 a 中，y ∈ a。
问：y ∈ y 吗？若 y ∈ y，按 y 的定义 y ∉ y；若 y ∉ y，又因为
y ∈ a 且 y 满足分离性质，必须 y ∈ y。无论如何矛盾。∎

这正是罗素定理的"分解原理版"：罗素定理（纯逻辑）说类 {a|a∉a}
不是集合；例 1.4（用了分解原理）说**没有万有集合**。两者合起来
把朴素概括的门彻底关上：类可以是万有的，集合不行。顺便，
∀x∃y(y ≠ x)（配对公理的例 1.5）还说明集合宇宙没有"顶"。

**命题 1.4 + 定义 1.6（空集）** 存在唯一的不含任何元素的集合：
存在性——取任一集合 x（公理 2），∅ := {z ∈ x | z ≠ z}；唯一性——
练习（用公理 1：两个无元素的集合互相包含）。记号：∀x(x ∉ ∅)。

**公理 5（配对公理）** ∀x∀y∃u∀z(z ∈ u ↔ (z = x ∨ z = y))。
三步舞给出无序对 {x, y}；x = y 时退化为单点集 {x} = {x,x}。
**例 1.5** ∀y∃a(y ∈ a)：任何集合都被某集合包含（取 a = {y}）。

**公理 6（并集公理）** ∀x∃y∀z(z ∈ y ↔ ∃u(z ∈ u ∧ u ∈ x))。
定义 1.8 ⋃x = {z | ∃u(u ∈ x ∧ z ∈ u)}；注意记号无二义性
（命题：由公理 1）。定义 1.9-1.11 配套运算：
x ∪ y = ⋃{x,y}；非空族 A 的交 ⋂A = {y | ∀a(a ∈ A → y ∈ a)}
（交不需要新公理——它是分解原理的产物，但**必须**限制在非空族上，
否则罗素类就要钻进来）；差 x − y = {z ∈ x | z ∉ y}；对称差
x Δ y = (x−y) ∪ (y−x)。

**定义 1.12（后继）** S(x) = x ∪ {x}。

**公理 7（无穷公理）** ∃x((∅ ∈ x) ∧ ∀u(u ∈ x → S(u) ∈ x))。
满足它的集合 x 称为**验证无穷公理**，记 Inf(x)。∅ 在里面、对后继
封闭——x 至少含有 ∅, S(∅), S(S(∅)), … 无穷多个元素。"任何一个
验证无穷公理的集合一定是无限的，因为每一个自然数都是这一集合的
一个元素。那么，什么是自然数呢？"冯琦把这个问题悬在这里，留给
1.3 节（68 章）——这是冯琦路线最漂亮的悬念设置。

到此为止集齐了：同一律、第一存在性、分解原理、幂集、配对、并集、
无穷。冯琦预告还差两块：**映像存在原理**（替换公理，70 章第二递归
定义定理时真正登台）与 **∈-极小原理**（基础公理/正则公理，75 章
传递化时登台）。八块拼成 ZF；再加选择公理（76 章）拼成 ZFC。

## 67.4 关系与函数：一切皆集合

集合论里关系与函数的特殊之处在于：**它们自己也是集合**。有序对
（定义 1.13）(a, b) := {{a}, {a, b}}（库拉托夫斯基定义）。它的
全部意义在于：

> **定理 1.2** (a,b) = (u,v) 当且仅当 a = u ∧ b = v。

*证明*分三小步：(1) {a} = {u} → a = u（单点集由元素决定，用
公理 1）；(2) {a} ∈ {{a},{a,b}} = {{u},{u,v}} 意味着 {a} = {u}
或 {a} = {u,v}，两种情形都给出 a = u 或 {a} = {u,v}，进而
{a,b} = {u,v}；(3) 联立 {a,b} = {u,v} 与 a = u 得 b = v
（b ∈ {a,b} = {u,v}，若 b = u 则 b = a，退化情形；否则 b = v）。∎

这个证明没有任何花招，只是反复用"集合由外延决定"。由此有序对
的第一、第二元素可写成投影：(z)₀ 与 (z)₁，且 z = ((z)₀, (z)₁)。

**命题 1.5（内在性）**"z 是一个有序对"本身是集合论语言的一个
表达式所能表达的性质。证明的思路：z 是有序对当且仅当 z 恰有一或
两个元素、其元素都是一或二元集、且满足某种配对结构——全部可以
用 ∈ 与 = 写出来。这件事比看上去重要：它意味着"函数""关系"
"序列"这些概念不是集合论的**外来语**，而是论域内在的。冯琦在
引言里说，正是库拉托夫斯基的有序对让函数与二元关系"成为集合论
论域中的对象"——策梅洛原始系统里没有这一步。

**定义 1.14 + 定理 1.3（笛卡尔积）** A × B = {(a,b) | a ∈ A ∧
b ∈ B}。它存在：A×B ⊆ 𝒫(𝒫(A ∪ B))（每个 (a,b) = {{a},{a,b}}
的元素都是 A∪B 的子集的子集），由分解原理分离出来。存在性由
公理 3+6+4 组合给出——**这里没有"乘积公理"，只有积木的拼装**。

**定义 1.15（关系）** R 是二元关系当且仅当每个元素都是有序对。
dom(R) = {(z)₀ | z ∈ R}，rng(R) = {(z)₁ | z ∈ R}，
dom(R) ∪ rng(R) 叫作用域；逆关系 R⁻¹ = {(a,b) | (b,a) ∈ R}。

**定义 1.16（函数）** F 是函数当且仅当 ∀a∀y∀z(((a,y) ∈ F ∧
(a,z) ∈ F) → y = z)（单值性）。y = F(a) 即 (a,y) ∈ F。F: A → B
当且仅当 dom(F) = A ∧ rng(F) ⊆ B；满射 rng(F) = B；单射——
注意冯琦的表述：对任意 y ∈ rng(F)，方程 y = F(a) 只有唯一的
解 a ∈ A（用**值域**表述单射性，与"不同输入不同输出"等价）；
双射 = 单 + 满，又叫一一对应、可逆函数。

**定义 1.17** B^A := {f | f: A → B}（全体 A 到 B 的映射；冯琦
也允许记 Aᴮ = B^A——读的时候小心，指数在**下**）。这个记号马上
在命题 1.7 与 74 章基数算术里兑现：|B^A| 的组合意义。

**定义 1.18** 限制 f↾D = {(a,b) ∈ f | a ∈ D}；像 f[D] = f"D =
{b ∈ B | ∃a ∈ D((a,b) ∈ f)}；原像 f⁻¹[C] = {a ∈ A | ∃b ∈ C
((a,b) ∈ f)}。注意 f⁻¹ 在这里只是**关系记号**——f 未必可逆，
f⁻¹[C] 照样有意义（这是 57 章关系代数的集合论原生版）。

**定义 1.19（等价关系）** E ⊆ A × A 且自反、对称、传递。
最平凡的例子：等同关系 E₌ = {(a,b) | a = b}。

**定义 1.20（复合）** S ∘ T := {(a,b) | ∃c((a,c) ∈ S ∧
(c,b) ∈ T)}；函数版 F ∘ G := {(a,c) | ∃b((a,b) ∈ F ∧
(b,c) ∈ G)}。

> **记号警告（本篇专属）**：冯琦的复合是**图序**（diagram
> order）：S ∘ T 读作"先 S 后 T"，(S ∘ T) 的箭头从 S 的起点
> 流向 T 的终点。这与 Jech 路线（02 章）及 Makinson（57 章）的
> (g ∘ f)(x) = g(f(x))（先 f 后 g）**方向相反**。本篇内一律遵循
> 冯琦记号并逐处声明；跨篇交叉时回到"先……后……"的中文表述。

为什么两种约定并存？图序让复合图从左到右读（a →(S) c →(T) b），
在传递化、迭代、累积层次的结构图里顺流而下；函数序让"作用"从
右往左算，贴近代入记号。冯琦的选择服务于他的主线——**结构沿
属于关系向下游生长**。

## 67.5 势比较：康托尔不等式

**定义 1.21（等势与势比较）** x 与 y **等势**（|x| = |y|）当且仅当
它们之间存在双射；|x| ≤ |y| 当且仅当存在 x 到 y 的**单射**；
|x| < |y|（x 的势小于 y 的势，x 比 y 弱势）当且仅当 |x| ≤ |y|
∧ ¬(|x| = |y|)。

**命题 1.6** 七条基本事实：等势自反/对称/传递（(1)(2)(3)——
双射的恒等/逆/复合）；≤ 自反 (4)；等势双方可替换 (5)(6)；≤ 传递
(7)（单射的复合）。全部是定义 1.16-1.20 的直接操练。

注意这里 |x| 还是**记号**而不是对象——"基数"作为集合的存在要等
到 74 章（冯琦 1.9 节，以秩序与序数为依托）；此刻 |x| ≤ |y| 只是
"存在单射"的缩写。这与 03 章 Jech 直接用 Hartogs 序数定义 < 的
次序不同：冯琦把"比较"先于"基数对象"讲，用的工具只有函数。

> **定理 1.4（康托尔不等式）** |x| < |𝒫(x)|。

*证明*：先证 ≤：z ↦ {z} 是 x 到 𝒫(x) 的单射。再证 ≠（不等势）：
设 f: x → 𝒫(x) 是双射，构造**对角集合**
A = {a ∈ x | a ∉ f(a)} ∈ 𝒫(x)。由满射取 z ∈ x 使 A = f(z)。
问：z ∈ A 吗？若 z ∈ A，按定义 z ∉ f(z) = A，矛盾；若 z ∉ A =
f(z)，按 A 的定义 z ∈ A，矛盾。故 f 不满。∎

证明中用的方法叫**康托尔对角化方法**。把罗素定理（67.2.3）与它并
排看：罗素的 M ↔ "所有不含自身的集合"，康托尔的 A = "所有不落在
自己像里的元素"——同一个对角骨架，一个否定"万有集合"，一个否定
"满射到幂集"。67.7 的 Julia 通道会在有限宇宙里把这两个骨架演成
同一部木偶剧。

**命题 1.7** |𝒫(x)| = |2^x|，其中 2^x = {0,1}^x 是 x 上全体
特征函数之集（定义 1.17 的记号在此兑现）。子集 ↔ 特征函数的对应
A ↦ χ_A 是双射（练习——用双包含证明两个方向都是恒等翻译）。
这条命题是"幂集 = 指数 2 的幂"的函数论解释，也是 74 章基数算术
κ^λ 组合意义的种子。

与 03 章的关系：03 章的三大定理是 Hartogs（任何集合都可被某序数
 injective 比较）、Cantor（本定理）、Schroeder-Bernstein（|A| ≤
|B| ≤ |A| → |A| = |B|）。SB 定理在冯琦路线的 68 章用第一递归
定义定理重证——**三明治引理**的构造比 03 章的对称闭包法更直观，
而 Hartogs 要等 74 章秩序理论就位后才有自然位置。

## 67.6 形式推理：租借来的逻辑

到目前为止我们一直在"像数学家那样"推理。冯琦在 1.2.3 节做了一件
多数教材不做的事：把**从一阶逻辑那里租借过来的**逻辑公理与推理
规则逐条写明。

> **定义 1.22（逻辑公理）** 设 P₁、P₂、P₃ 为表达式：
> (1) 命题演算公理七条：
> (a) ((P₁→(P₂→P₃)) → ((P₁→P₂) → (P₁→P₃)))
> (b) (P₁ → P₁)
> (c) (P₁ → (P₂ → P₁))
> (d) (P₁ → ((¬P₁) → P₂))
> (e) (((¬P₁) → P₁) → P₁)
> (f) ((¬P₁) → (P₁ → P₂))
> (g) (P₁ → ((¬P₂) → (¬(P₁ → P₂))))
> (2) 特化原理：(∀x Φ) → Φ(x;y)（y 可替换 x）。
> (3) 全称量词分配律：(∀x(P₁→P₂)) → ((∀xP₁) → (∀xP₂))。
> (4) 无关量词引入：x 不是 Φ 的自由变元时，(Φ → (∀xΦ))。
> (5) 恒等律：每个变元符号 x 有 (x = x)。
> (6) 等同律：在 P₁、P₂ 中同时替换 x 的每次出现得到同一表达式时，
> (x=y) → (P₁ → P₂)。
> (7) 全域化法则：若 Φ 是逻辑公理，则 (∀xΦ) 也是。
> (8) 逻辑公理仅由上述方案递归得到，别无其他。
>
> **定义 1.23（形式推导规则）**由 Φ → Ψ 是定理且 Φ 是定理，得
> Ψ 是定理。（modus ponens，分离规则）

**定理**于是有了精确的含义：从（逻辑公理 + 集合论公理）出发，经
有限次分离规则得到的表达式。这套 (1a)-(1g) 是标准的 **Hilbert 式
命题演算**——只用 → 与 ¬ 两个联结词当初始符（∧∨↔ 都可由它们定
义），公理模式加单一推理规则。七条公理的分工：(a) 自由分配蕴涵
（"条件证明"的骨架）、(c) 弱化（真命题可加前提）、(d)(e)(f)(g)
处理否定——爆炸律 (d)、归谬律 (e)、否定前件之否定 (f)、逆否
(g)；(b) P→P 其实是 (a)(c) 的推论，冯琦把它单列以便初学。

举个最小的完整例子——**P → P 的五步推导**（本章机器通道的主角）：

1. P → ((P→P) → P)　　［公理 (c)：取 P₁=P, P₂=(P→P)］
2. (P → ((P→P)→P)) → ((P→(P→P)) → (P→P))　　［公理 (a)］
3. (P→(P→P)) → (P→P)　　［MP：1, 2］
4. P → (P→P)　　［公理 (c)：取 P₁=P, P₂=P］
5. P → P　　［MP：4, 3］

每一步要么是公理模式的实例，要么是对前面两步用一次分离规则。
验证"某一步是公理 (a) 的实例"就是**模式匹配**——这正是机器的
拿手好戏。67.7 的 Coq/Agda/Python/Prolog 四通道各自实现一个推导
检查器，把上面五步链验证一遍。

三条重要的教学注记：

- **为什么没有"演绎定理"**：Hilbert 系统里"要证 Φ→Ψ，只需从 Φ
  加 Ψ 推导"是元定理（演绎定理），不是公理。冯琦把它留给读者在
  实践中体会；数学家写证明时"假设 Φ……得 Ψ，故 Φ→Ψ"的日常操作
  对应的正是这条元定理加上全域化法则 (7)。
- **全域化法则的形状**：它是唯一一条"公理生成公理"的规则——
  对公理全称化。配合 (3)(4)，它把"对任意 x，……"的数学惯用语
  （"任取一个集合 z"）合法化。01 章公理表里每条 ∀ 开头的公理，
  内部都在用这条法则。
- **租借的立场**：冯琦说，"犹如任何一个其他数学分支那样，我们在
  分析论证时往往只提所涉及的非逻辑公理，而将所使用的逻辑公理和
  推理法则当成默认真理"。本教程的七通道恰恰把这笔"租借"还清：
  Lean 的 `exact`、Coq 的 `apply`、Isabelle 的 `blast` 内部就是
  这些逻辑公理与规则的机械实现。理解 1.2.3 节就是理解证明助手在
  替我们做什么。

## 67.7 机器通道

本章的机器化有两条线。**形式线**：Hilbert 推导检查器——表达式
数据类型 + 公理模式识别 + 分离规则，验证 P→P 五步链（Coq/Agda
原生归纳类型；Python/Prolog 用显式列表与递归判定）。**集合线**：
同一律 = 双包含（Lean `Set.ext` / Isabelle `extension`）、康托尔
对角线（Lean/Julia/Python 有限宇宙演示）、量词交错的语义翻转
（Julia 有限模型）。冯琦的"逻辑公理 + MP"与 Lean 的 `Eq.mpr`、
Coq 的 `exact` 之间的对应关系在正文中逐条点亮。

### Lean：同一律、对角线与表达式类型

Lean 通道用 mathlib 的集合论原生 API 复刻本章三个主角。同一律即
`Set.ext`：要证 `A = B`，只须证 `∀ x, x ∈ A ↔ x ∈ B`——这正是
公理 1 的证明式版本。康托尔对角线写成"无满射引理"：

```lean
/-- 康托尔对角线（定理 1.4 的核心）：不存在 α → Set α 的满射 -/
theorem noSurjOnPowerset (α : Type*) :
    ¬ ∃ f : α → Set α, Function.Surjective f := by
  rintro ⟨f, hf⟩
  -- 对角集合 D = {a | a ∉ f a}（书页 36 的 A = {a∈x | a ∉ f(a)}）
  obtain ⟨z, hz⟩ := hf {a | a ∉ f a}
  have key : z ∈ f z ↔ z ∉ f z := by
    conv_lhs => rw [hz]
    exact Iff.rfl
  by_cases h : z ∈ f z
  · exact absurd h (key.mp h)
  · exact h (key.mpr h)
```

关键一步 `conv_lhs => rw [hz]` 把等式 `f z = D` 只改写到左边——
若用普通 `rw [hz]`，等式右边的 `f z` 也会被换成 D，对角矛盾就
消失了（这是本通道的实测坑：全域改写后目标变成 D ∈ D ↔ D ∉ D，
Iff.rfl 失效）。`Iff.rfl` 之所以能闭合，是因为 `z ∈ {a | φ a}`
与 `φ z` 定义性相等——分离规则就住在集合的花括号里。

推导检查器则以归纳类型登场——表达式、以及"第 n 步是公理/由第
i、j 步分离而来"的步骤标注：

```lean
inductive Fml where
  | atom (n : ℕ)               -- (xₙ ∈ xₘ) 或命题变元（本章用变元版）
  | imp (p q : Fml)            -- (P → Q)
  | neg (p : Fml)              -- (¬ P)

/-- 公理模式 (a)：((P₁→(P₂→P₃)) → ((P₁→P₂) → (P₁→P₃))) -/
def axA (p q r : Fml) : Fml :=
  Fml.imp (Fml.imp p (Fml.imp q r))
          (Fml.imp (Fml.imp p q) (Fml.imp p r))
def axC (p q : Fml) : Fml := Fml.imp p (Fml.imp q p)  -- 公理 (c)
```

正文（examples/lean/Settheory/Ch67Transitive.lean）接着用 `axA`、
`axC` 与一个 `MP : Fml → Fml → Fml` 函数把五步链逐字写成数据，
并用 `decide` 型函数验证链的合法性。

### Isabelle/ZF：官方公理锚点

Isabelle 的 ZF object-logic 把本章公理全部官方化，名字可以直接
在理论里引用——这是"公理 1-7"在证明助手中的实名制：

```isabelle
text \<open>冯琦公理 1-7 的 ZF 官方形态：\<close>
(* extension : ∀A B. A = B <-> (∀x. x ∈ A <-> x ∈ B)  —— 公理1 同一律 *)
(* upair     : ∀a b. ∃c. ∀x. x ∈ c <-> x = a ∨ x = b  —— 公理5 配对 *)
(* Union     : ∀A. ∃B. ∀x. x ∈ B <-> ∃y∈A. x ∈ y      —— 公理6 并集 *)
(* Pow       : ∀A. ∃B. ∀x. x ∈ B <-> x ⊆ A            —— 公理3 幂集 *)
(* infinity  : ∃A. ∅ ∈ A ∧ (∀x∈A. succ(x) ∈ A)         —— 公理7 无穷 *)
```

Topic.thy 从 `extension` 出发证命题 1.1 的双包含形式、从 `Pow` 证
幂集唯一性（复刻命题 1.2 的三步舞），并展示 `succ` 即定义 1.12 的
S(x) = x ∪ {x}。

### Coq 与 Agda：推导检查器的主场

Coq 通道把五步链做成 `list (Fml * Just)`，`Just` 是归纳标注
（`Ax` / `MP i j`），检查器递归判定每步合法：

```coq
Inductive Fml : Type :=
  | Var (n : nat) | Imp (p q : Fml) | Neg (p : Fml).

Inductive Just : Type :=
  | AxC | AxA | MP (i j : nat).

Fixpoint is_axiom (j : Just) (f : Fml) {struct f} : bool :=
  match j, f with
  | AxC, Imp p (Imp q r) => eqb_fml p r   (* P → (P → P) 型 *)
  | _,  _ => false
  end.
```

（正文用完整模式：三条公理 a/c 各一个识别分支；`check` 遍历
推导列表，`MP i j` 步要求第 i 步形如 `Imp x y` 且第 j 步恰为 x。）
Agda 通道则把推导本身做成**证据类型的项**——`data _⊢_`，五步链是
一个原生证明项，检查器就是类型检查器。

### Julia / Python：量词交错与对角线剧场

Julia 在有限论域 {1,…,6} 上演"交换量词会翻车"：对谓词 `x < y`，
∀x∃y(x<y) 为真而 ∃y∀x(x<y) 为假；再演对角线：枚举 x = {1,…,n}
到 𝒫(x) 的任何函数 f（以特征向量表示），现场算出对角集合
`D = {a | a ∉ f(a)}`，并验证 D 不在 f 的像里——康托尔不等式的
有限预演。Python 通道实现完整的 Hilbert 检查器（与 Coq 同构的
列表版）外加概括记号的安全演示：`comprehend(x, phi)` 只在已给
列表上过滤——分解原理的编程形态。

### Prolog：推导链的搜索验证

Prolog 把公理模式写成 unify 规则，`derivation/1` 递归走列表：

```prolog
axiom((P -> (Q -> P))).                 % 公理 (c)
axiom(((P -> (Q -> R)) -> ((P -> Q) -> (P -> R)))).  % 公理 (a)

step_ok(step(F, ax)) :- axiom(F).
step_ok(step(Q, mp(I, J))) :-
  nth0(I, D, step(P -> Q, _)), nth0(J, D, step(P, _)).
```

（正文完整版含全部七条公理模式与五步链实例，`main` 打印每步的
合法性判定。）注意 Prolog 的项天然是语法树——表达式递归定义
（定义 1.1）与 Prolog 项的构造严丝合缝。

## 67.8 收束：语言、公理与租来的逻辑

冯琦第一课给了三件别的路线没有明说的宝物：**语言先行**（表达式、
自由/约束变元、量词交错——写不出就证明不了）；**等号被定义**
（同一律是等号的行为契约，外延性从"哲学原则"变成"一条公理"）；
**逻辑被租借并立据**（八组逻辑公理 + 一条 MP，"定理"有了组合式
定义）。三件宝在后续章节反复兑现：68 章的数学归纳法原理将作为
**定理**（而非公理）从无穷公理推出，第二递归定义定理（70 章）把
67.2.1 的语法归纳升格为集合论的存在性定理，而 67.5 的势比较记号
将在 74 章长成基数算术。
