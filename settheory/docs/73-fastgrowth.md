## 73.1 ε₀：范式的天花板

72 章的康托尔范式说：每个序数都唯一写成
α = ω^{β₁}·k₁ + … + ω^{βₘ}·kₘ（β₁ > … > βₘ，0 < kᵢ < ω）。但范式
里的指数 βᵢ 自己还是序数，还可以再写范式——这个自嵌套能走多远？
冯琦用一条塔把它封顶：

> **定义 1.82** (1) 递归定义长度为 ω 的序数序列 (δₙ | n ∈ ω)：
> δ₀ = ω；δ_{n+1} = ω^{δₙ}。(2) **ε₀** = sup{δₙ | n ∈ ω}。

**引理 1.21**：(1) α < ε₀ → α < ω^α < ε₀；(2) ω^{ε₀} = ε₀。
*证明*（(2) 即"塔封顶"）：ω^{ε₀} = ⋃{ω^α | α < ε₀} ≤ ε₀ ≤ ω^{ε₀}——
第一个等号用幂在极限处的连续性（72 章极限款），两个方向的夹逼靠
(1) 的单调链。∎

——ε₀ 是"指数塔封顶"的第一个序数：**ω^α = α** 的最小解。对
α<ε₀，把普通康托尔范式中的指数继续展开，指数严格下降，因而在有限
步内终止；所以每个 α<ε₀ 都有只含 0、1、ω、加法、乘法、指数的有限
嵌套表达式。ε₀ 本身不能再这样展开，因为 ε₀=ω^{ε₀} 的指数仍是它
自己；把它作为新常量后，更大的序数仍可有有限表达式。这里变化的
不是"序数突然失去有限范式"，而是**纯 ω 表达式的封闭范围到 ε₀ 为止**。
本章机器通道的一切计算都在 <ε₀ 的世界里进行。

**机器锚点一：Isabelle/ZF 自建序数幂。** ZF 库有 `oadd`/`omult` 却没有
`oexp`（OrdinalArith 在 ZF 侧缺席——本轮实测的库缺口），所以 ε₀ 的
定义要从 71 章的超限递归定义定理（定理 1.56）亲手点火。ZF 的
`transrec2`（Epsilon.thy）正是三情形超限递归器的官方化身——零款、
后继款、极限取并，与定义 1.81 的幂逐字对应：

```isabelle
definition oexp :: "[i,i] ⇒ i"  (infixr "^^" 75) where
  "a ^^ b ≡ transrec2(b, 1, λj r. r ** a)"

lemma oexp_0 [simp]: "a ^^ 0 = 1"
lemma oexp_succ [simp]: "a ^^ succ(i) = (a ^^ i) ** a"
lemma oexp_Limit: "Limit(i) ⟹ a ^^ i = (⋃j<i. a ^^ j)"
```

三条方程的证明就是把 `oexp_def` 展开后套用 `transrec2_0`/
`transrec2_succ`/`transrec2_Limit`——超限递归定义定理在这里不是
纸面定理而是每天用的工程件。塔与 ε₀ 随之落地：

```isabelle
definition otow :: "i ⇒ i" where
  "otow(n) ≡ rec(n, nat, λx r. nat ^^ r)"

definition eps0 :: "i" where
  "eps0 ≡ ⋃n∈nat. otow(n)"
```

`rec` 是自然数上的原始递归器（`rec(0,a,b) = a`、
`rec(succ(m),a,b) = b(m, rec(m,a,b))`），于是 otow(0) = nat = ω、
otow(succ n) = ω^{otow(n)}——δ₀ = ω、δ_{n+1} = ω^{δₙ} 逐字。
`Ord_oexp`（幂保持序数性，`trans_induct3` 三情形归纳 + `Ord_OUN`
收并——注意 `⋃j<i.` 与 `⋃j∈i.` 是内部不同的两个绑定词，前者配
`Ord_OUN`、后者配 `Ord_UN`，不能混用）与
`Ord_eps0`、`nat_subset_eps0`（ω 卧在塔底）在 ST73 里全部完整
证明。

**机器锚点二：Lean 的官方 ε₀。** mathlib 把 ε₀ 定义为 ω^· 的不动点，
与定义 1.82 的塔式 sup 互认只要一行：

```lean
theorem eps0_eq_iSup : (⨆ n : ℕ, (fun x : Ordinal => ω ^ x)^[n] 0) = ε₀ :=
  (Ordinal.iSup_iterate_eq_nfp _ _).trans Ordinal.epsilon_zero_eq_nfp.symm
```

左端是从 0 出发的迭代列 0 ↦ 1 ↦ ω ↦ ω^ω ↦ … 的上确界（冯琦的塔从
δ₀ = ω 起步，是同一列的尾巴）；`iSup_iterate_eq_nfp` 说"ω 次迭代的
sup = 最小不动点"，`epsilon_zero_eq_nfp` 说"ε₀ = 那个不动点"。
定义 1.82 与不动点定义的互认，在 mathlib 里是一次传递就完成的事。

## 73.2 基本序列：极限序数的"下一项"指针

超限递归（71 章定理 1.56）允许 F(λ) 依赖整段 F↾λ；但要定义**具体
可计算**的函数层次，需要给每个极限序数一条**规范逼近链**
α(0) < α(1) < … ↗ α。整条 [ω, ε₀] 区间能系统性地做到这件事，
全靠康托尔范式：

> **定义 1.83（基本序列）** 对每个极限序数 α ∈ [ω, ε₀] 递归定义
> α: ω → α：
> (1) ω(n) = n；
> (2) 写 α 的范式 α = ω^{β₁}·k₁ + … + ω^{βₘ}·kₘ（βₘ > 0），分四款：
> (a) m=1, k₁=1, β₁=γ+1：α(n) = ω^γ·n；
> (b) m=1, k₁=1, β₁ 极限：α(n) = ω^{β₁(n)}；
> (c) m=1, k₁>1：α(n) = ω^{β₁}·(k₁−1) + (ω^{β₁})(n)；
> (d) m>1：α(n) = 头部 + ω^{βₘ}·(kₘ−1) + (ω^{βₘ})(n)。
> (3) ε₀(0) = 0；ε₀(n+1) = ω^{ε₀(n)}。

设计原则一句话：**永远对"最右主项"动刀**。(c)(d) 两款把系数 k>1
的项拆成"(k−1) 份留下不动 + 最后一份递归"——这是 72 章带余除法
"从低位剥"的极限版。条款 (a) 的代表：ω²(n) = ω·n、ω³(n) = ω²·n；
条款 (b) 的代表：ω^ω(n) = ω^n、ω^{ω^ω}(n) = ω^{ω^n}。

**引理 1.22**：每个基本序列严格递增且收敛于 α 本身
（∀β < α ∃n β < α(n)）。——把"整段前史"压缩成"一条 ω-链"，
这是可计算性与超限结构之间的翻译器。

机器通道把四条款全实现。Julia 版（examples/julia/73_fastgrowth.jl，
Python/Prolog 同构）在 72 章的 CNF 演算器上递归下刀：

```julia
function fs(a::ON, n::Int)
    @assert is_limit(a) "fs: 只对极限序数取基本序列"
    m = length(a.terms)
    (βm, km) = a.terms[end]
    if m > 1                      # (d) 头部保留，末项系数减一后接 (ω^βm)(n)
        head = km > 1 ? oadd(ON(a.terms[1:end-1]), ON([(βm, km - 1)])) :
                        ON(a.terms[1:end-1])
        return oadd(head, fs(ON([(βm, 1)]), n))
    end
    (β, k) = a.terms[1]
    if k > 1                      # (c) α(n) = ω^β·(k−1) + (ω^β)(n)
        return oadd(ON([(β, k - 1)]), fs(ON([(β, 1)]), n))
    end
    if is_limit(β)                # (b) α(n) = ω^(β(n))
        return wexp(fs(β, n))
    end
    γ = opred(β)                  # (a) α(n) = ω^γ·n（ω(n)=n 为 γ=0 特例）
    return n == 0 ? oz() : ON([(γ, n)])
end
```

六条样本（ω、ω²、ω^ω、ω^ω^ω、ω^ω+ω³·2、ω^ω^ω+ω²）在 n = 0..5
上全量验证"严格递增且不越界"，收敛性抽查：β = ω²·7+5 被 ω³ 的
基本序列在第 8 项赶上（fs(ω³, 8) = ω²·8）。ε₀ 自己的链走特例
`fs_eps0(n+1) = wexp(fs_eps0(n))`：0 ↦ 1 ↦ ω ↦ ω^ω ↗ ε₀——
从 0 起步三步就追上塔的第一级。Isabelle 侧把条款 (a) 的收敛性做成
库背书：ω·ω = ⋃k∈ω. ω·k 正是 `omult_Limit` 的逐字实例——基本序列
的上确界回到序数本身：

```isabelle
lemma fs_omega2_sup: "nat ** nat = (⋃k∈nat. nat ** k)"
  by (rule omult_Limit [OF Ord_nat Limit_nat])
```

（`omult_Limit` 有两个前提——`Ord(i)` 在前、`Limit(j)` 在后；
`[OF Limit_nat]` 会拿 Limit(nat) 去撞 Ord(i) 而报 "OF: no
unifiers"，必须两前提齐供。这也是本轮的实测坑。）

## 73.3 快速增长层次 F_α

> **定义 1.84** (1) f⁰ = Id、f^{n+1} = f∘f^n（迭代）；
> (2) α ≤ ε₀ 时 F_α: ℕ → ℕ：
> F₀(n) = n+1；F_{β+1}(n) = F_βⁿ(n)（**n 次迭代**）；
> β 极限：F_β(n) = F_{β(n)}(n)（**沿基本序列取下一项**）。

品味三款定义的落差：F₀ 是后继；F₁(n) = F₀ⁿ(n) = n+n；F₂(n) = F₁ⁿ(n)
= n·2ⁿ；F₃ 已经是指数塔级；F_ω(n) = F_n(n) 超过一切固定层数的塔；
F_{ω+1} 再迭代 n 次……层次每升一阶，增长方式就**换一种语法**
（加→乘→指数→塔→对角线）。72 章的序数算术是这条楼梯的坐标系：
F_α 的增长强度 = α 在序数塔上的高度。

> **定义 1.85** f <\* g（g **几乎处处**大于 f）：∃m ∀n ≥ m (f(n) < g(n))。

> **定理 1.81（科比-巴黎六款）** (1) 每个 F_α (α ≤ ε₀) 递归全；
> (2) α < β ≤ ε₀ → F_α <\* F_β（层次严格）；(3) 初等递归 f →
> f <\* F_ω；(4) α < ε₀ → **PA ⊢ "F_α 全定义"**；(5) PA 证得了全
> 的递归 f → f <\* F_{ε₀}；(6) **PA ⊬ "F_{ε₀} 全定义"**。

(1)(2)(3) 是可计算性侧的算术；(4)-(6) 是证明论侧：PA 的证明论序数
是 ε₀，凡 PA 可证全的递归函数都被某个 α < ε₀ 的 F_α 控制，而
F_{ε₀} 自己站在边界**之外**——它在 ZF 中全定义，但 PA 不知道。

**机器通道的第一份作业：闭式的完整证明。** Lean（examples/lean/
Settheory/Ch73Fastgrowth.lean）把层次立在 `Function.iterate`（f^[n]）
上，F₁ 迭代的闭式是一段干净的双重归纳：

```lean
theorem F0_iter (k x : ℕ) : F0^[k] x = x + k := by
  induction k generalizing x with
  | zero => rfl
  | succ k ih =>
    rw [Function.iterate_succ_apply, ih, show F0 x = x + 1 from rfl]
    omega

theorem F1_iter (k x : ℕ) : F1^[k] x = x * 2 ^ k := by
  induction k generalizing x with
  | zero => simp
  | succ k ih =>
    rw [Function.iterate_succ_apply, ih, F1_step]
    ring

theorem F2_closed (n : ℕ) : F2 n = n * 2 ^ n := F1_iter n n
```

`F1_iter` 的归纳步就是定理 1.81(2) 在第二层的全部内容：F₁ⁿ 作用 =
翻倍 n 次 = 乘 2ⁿ。Coq 版（Ch73_fastgrowth.v）的同一证明多一层
体操：`iterate_F1 : forall k x, iterate F1 k x = x * 2^k` 的归纳步要
先 `rewrite IHk` 再用 `assert (HF: F1 x = x * 2)` 搭桥（`lia` 不展开
定义、`ring` 不吃变量指数的幂——本轮实测的两个 Coq 小坑，正文备查）。
Agda 版（Ch73_fastgrowth.agda）把等式链写成显式 `trans` 组合：
`iterate-F1` 的归纳步依次引用 IH、`F1-closed-x`、`*-assoc`——
依赖类型世界里"结合律也是一条要请出来的引理"。

**第二份作业：可计算性的物理边界。** 数值通道先做定义与加速的对拍
——`F`（F₀/F₁ 走闭式）与 `F_literal`（定义 1.84 的字面迭代）在
F₀..F₂（n ≤ 8）、F₃/F_ω（n ≤ 2）逐点一致，然后才有加速表：

```
F₀(n)=n+1、F₁(n)=2n、F₂(n)=n·2ⁿ（n=1..6 全对）✓
F₃(1)=2、F₃(2)=2048；F_ω(1)=2、F_ω(2)=8 ✓
F_ω(3) = F₂(402653184) = 402653184·2^402653184，约 121210687 位
```

**F_ω(3) 已经可定义而不可算**：F₃(3) = F₂(F₂(F₂(3)))，最内层
F₂(3) = 24，中层 F₂(24) = 402653184，最外层 F₂ 作用于四亿——
结果是四亿乘以 2 的四亿次方，一个约 1.2 亿位的十进制数。这里埋着
一条工具链对照：Lean 的 `native_decide` 毫秒级算出 F₂ 24 =
402653184（Lean Nat 是 GMP 字面量），Coq 的 `vm_compute` 与 Agda
的规范化器在一元 nat 上连这一步都咽不下（4 亿个 S 构造子）——
所以 Coq/Agda 通道只做**改写不求值**：
`F2 24 = 24 * 2^24`（闭式改写后两端同形，`reflexivity` 不展开）。
同一个数学事实，三种工具三种物理——这就是"可计算性"在机器上的
真实纹理。定理 1.81(2)(3) 的 <\* 见证在 n ≤ 50 的样本段上全绿：
F₀ <\* F₁（n ≥ 2）、F₁ <\* F₂（n ≥ 5）、n³+n <\* F₂（n ≥ 7）——
初等递归被 F₂ 单点全灭，更别说 F_ω。

## 73.4 古德斯坦序列：换基狂欢与序数刹车

> **定义 1.86（完全展开）** T_b(m)：m ≤ b 时 T_b(m) = m（原子）；
> m > b 时写 m = b^{n₁}·k₁ + … + b^{nₗ}·kₗ（n₁ > … > nₗ ≥ 0，
> 0 < kᵢ < b），**指数再递归完全展开**：T_b(m) = b^{T_b(n₁)}·k₁ + …。
> 例 1.29：37 = 2⁵+2²+1 = 2^{2²+1}+2²+1。

> **定义 1.87（古德斯坦序列）** m₀ = m > 0；给定 m_k，写完全展开
> T_{k+2}(m_k)，把**每个基 b = k+2 的出现换成 b+1**，再减 1 得
> m_{k+1}。

机器通道的核心设计发现：**完全展开树里根本不需要存基**。树形
HB = [(指数HB, 系数)] 与康托尔范式同构，基 b 只出现在"读法"里——
换基 = 换读法，影子序数 = 同一棵树读成 ω：

```julia
struct HB
    terms::Vector{Tuple{HB,BigInt}}
end

function hb_of(b::BigInt, m::BigInt)::HB
    m == 0 && return HB(Tuple{HB,BigInt}[])
    m < b && return HB([(HB(Tuple{HB,BigInt}[]), m)])   # 原子常数
    e, p = 0, one(BigInt)                 # 贪心取最大幂 b^e ≤ m
    while p * b <= m; p *= b; e += 1; end
    k, r = divrem(m, p)                   # 0 < k < b：系数永不换基
    HB(vcat([(hb_of(b, BigInt(e)), k)], hb_of(b, r).terms))
end

hb_eval(h::HB, b::BigInt) = sum(b^hb_eval(e, b) * k for (e, k) in h.terms)
hb_to_on(h::HB) = ON([(hb_to_on(e), Int(k)) for (e, k) in h.terms])
```

于是古德斯坦一步只剩一行：**树不动，读法 b ↦ b+1，再 −1**：

```julia
function gstep(b::BigInt, m::BigInt)
    m == 0 && return (zero(BigInt), HB(Tuple{HB,BigInt}[]))
    t = hb_of(b, m)
    m2 = hb_eval(t, b + 1) - 1
    (m2, hb_of(b + 1, m2))
end
```

这里藏着本轮唯一一处"机器改账"。写作初期按直觉以为"指数里的
2 ≤ b 是常数"，T₂(37) 的影子就会是 ω^{ω²+1}+ω²+1；机器一对拍，
`hb_to_on(t37)` 给出的是 **ω^{ω^ω+1}+ω^ω+1**——定义 1.86 的原子
条款是 m ≤ **b**（不是 m < b），原子 "2" 本身就是基 b 的一次出现，
换基时它要升、取影子时它读成 ω。书载例 1.31 逐行复核（m₀ = 21 时
α₀ = ω^{ω^ω}+ω^ω+1），机器与书完全一致——是直觉错了。系数
（0 < kᵢ < b）才永不换基。这棵"不存基的树"把换基语义钉死，
连书的旁注都能逐行验收。

**G(3) 全程**（数字原地踏步，影子一路下山）：

```
值链   [3, 3, 3, 2, 1, 0]         （5 步归零，G(3) = 5）
影子链 ω+1 > ω > 3 > 2 > 1 > 0    （严格下降 ✓）
```

**G(4) 前八步**（例 1.30 的微型重演，数字爆炸与影子下降同框）：

```
值链 [4, 26, 41, 60, 83, 109, 139, 173, 211] ——一路狂涨
影子 ω^ω > ω²·2+ω·2+2 > ω²·2+ω·2+1 > … ——一路下降 ✓
```

G(4) 的归零时刻是 3·2^402653209 − 2 步——七条通道没有一条能跑完，
只能展示机理。而机理就是定理 1.82 的证明：

> **定理 1.82（古德斯坦定理）** ∀m > 0 ∃n (mₙ = 0)。
> *证明*：给每个 m_k 配**影子序数** α_k：把 T_{k+2}(m_k) 中的
> b := ω（同一棵树读成康托尔范式）。换基 b → b+1 时影子不变
> （ω 处什么都不动），末尾的 −1 严格压低影子：若末项是大于 0 小于
> b 的常数则 α_k = α_{k+1} + 1；若末项是 b 的倍数则 α_k ≥ α_{k+1} + ω。
> 恒有 α_k > α_{k+1}。若 mₙ 永不归零，得到严格下降的无穷序数列
> α₀ > α₁ > …——与序数的良基性（71 章 Φ₂/超限归纳）矛盾。∎

Coq 通道（Ch73_fastgrowth.v）把整条下降链做成 `hb_cmp` 三态比较
下的逐环验证（`g3_shadows_decrease`：五个环节全部 `reflexivity`），
G(3) 的每一步 `gstep` 与 G(4) 书载前三步（26、41、60）都是
`vm_compute` 级别的重演——序数在幕后刹车，数字在台前狂欢，
机器把幕前幕后同时打开给你看。

> **定理 1.83（科比-巴黎，1982）** **PA 不能证明古德斯坦定理**。
> 定义 1.88：G(m) = 最小归零时刻（图灵可计算）。事实上 G 与
> F_{ε₀} 在 <\* 意义下互相绞杀，定理 1.81(6) 的边界效应直接压到
> G 头上。

——古德斯坦 1944 年证了定理，科比-巴黎 1982 年证了它的不可证性，
中间隔着近四十年的证明论。**PA 的公理里没有 ε₀，而古德斯坦定理里
藏着 ε₀**：证明中那步"严格下降序数列必有限"需要的良基归纳恰好
爬到 ε₀——比 CH 的独立性（19/54 章力迫）便宜得多但同样深刻。

## 73.6 收束：序数塔上的证明论

72 章末说"楼上每升一层，可计算性的边界就退一步"；本章给出了精确
的楼层表：F_α 的增长强度按 α 严格分层，初等递归住在 ω 层以下，
PA 的证明力住在 ε₀ 层以下。古德斯坦定理是这个楼层表的第一个自然
应用：一个小学就能讲清的数列问题，其"真"与"不可证"的分界线精确
落在 ε₀。下一章转向**基数**——不再问"多长"而问"多少"：ω₁、α⁺、
初始序数、ℵ 序列与乘法坍缩 ℵ·ℵ = ℵ。
