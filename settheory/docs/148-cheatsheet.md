## 148.2 序数与基数算术表

**序数算术（第 135 章）**——非交换是常态：

| 等式 | 成立？ | 机制 |
|---|---|---|
| α + (β + γ) = (α + β) + γ | ✓ | 结合恒成立 |
| α + β = β + α | ✗ | 1+ω = ω ≠ ω+1 |
| α · (β · γ) = (α · β) · γ | ✓ | 结合 |
| α · β = β · α | ✗ | 2·ω = ω ≠ ω·2 |
| α^β^γ = α^(β·γ) | ✓ | 幂律 |
| β + 1 > β | ✓ | 后继严格增 |
| 1 + ω = ω | ✓ | 右极限冲刷 |
| α < β ⟹ α + γ ≤ β + γ | ✓ | 左单调 |
| γ + α < γ + β ⟺ α < β | ✓ | 左消去 |

**基数算术（第 139 章）**——无穷吸收：

| 运算 | 有限 | 无穷（κ,λ ≥ ℵ₀） |
|---|---|---|
| κ ⊞ λ | n+m | **max(κ,λ)** |
| κ ⊙ λ | nm | **max(κ,λ)** |
| κ^0 | 1 | 1 |
| κ^n (n≥1) | k^n | κ |
| 2^κ | 2^n | > κ（Cantor），CH 问 c = ℵ₁？ |
| κ^λ (κ≤λ) | k^l | 2^λ |

**连续统函数的已知约束（第 141 章）**：单调 + König cf(2^κ) > κ
——其余大片未知（SCH/GCH 见 146-147 章独立性）。

## 148.3 层垒谱系与模型速查（第 143-147 章）

| 结构 | 定义 | 关键性质 |
|---|---|---|
| V₀ = ∅; V_{α+1} = P(V_α); V_λ = ⋃ | 全宇宙 | 传递、单调 |
| WF = ⋃V_α | 良基宇宙 | V = WF ⟺ 基础公理 |
| rank(x) = sup{rank(y)+1} | 秩 | x∈y ⟹ rank x < rank y |
| L₀ = ∅; L_{α+1} = Def(L_α); L_λ = ⋃ | 可构成宇宙 | \|L_α\| = \|α\|；L ⊨ ZF+V=L+AC+GCH |
| H_κ = {x : \|trcl(x)\| < κ} | 遗传宇宙 | H_κ = V_κ ⟺ κ 不可达 |
| M[G] = {τ_G : τ ∈ M^P} | 脱殊扩张 | M ⊆ M[G]; o(M)=o(M[G]); M[G] ⊨ ZFC |

**相对一致性链**：
```
Con(ZF⁻) → Con(ZF)              [基础公理：WF 模型]
Con(ZF)  → Con(ZFC)              [L 中的良序]
Con(ZFC) → Con(ZFC+V=L+GCH)     [L 模型，哥德尔 1938]
Con(ZFC) → Con(ZFC+¬CH)          [Cohen 力迫 1963]
Con(ZFC) → Con(ZFC+¬V=L)         [力迫的泛型 G ∉ L]
Con(ZFC) ↛ Con(ZFC+∃不可达)     [V_κ 模型 + Gödel II]
```

## 148.6 机器通道分工总结

| 通道 | 本教程单元数 | 强项 |
|---|---|---|
| Lean + mathlib | ~16 | ZFSet/Ordinal/Cardinal 的完整公理化；定理级证明 |
| Isabelle/ZF | 6 | ZF object-logic 的公理实名/AC 库/L 的机器化 |
| Coq | 6 | 浅嵌入（公理记账 + 构造性对照） |
| Julia | 9 | 数值/模拟（配对函数/CSB/序数算术/Cohen 实数） |
| Python | 13 | 精确计算（Kuratowski/V_k/CNF/滤子/力迫） |
| Prolog | 7 | 有限穷举终审（鸽笼/划分/良序/对角线/滤/力迫） |

**方法论五律**（沿 funanalysis/probability 协议）：
1. 定义即程序——每个数学定义在有限窗口内可运行。
2. 定理即测试——证明的每一步化为可断言的审计。
3. 有限窗口诚实——不可达的元定理如实标注。
4. 机器自纠——书本笔误由多通道交叉验证暴露。
5. 先机器后手抄——期望值经运行确认再写入断言。
