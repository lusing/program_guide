# 74 · 基数：和、积与典型秩序

> 本章提炼冯琦 §1.9，回答 72 章问题 1.5："一个无穷集合上能有多少种
> 秩序？"答案是：**序数比集合多**——ω 上有 ω₁ 种两两不同构的秩序
> （定理 1.84），从而定义第一个不可数序数 **ω₁**；一般地每个无穷
> 序数 α 都有"后继势"**α⁺**。于是"多少"有了精确的载体：与 α 等势的
> 最小序数 |α|（**初始序数**=基数），全体无穷基数排成 **ℵ 序列**
> ℵ₀ < ℵ₁ < … < ℵ_ω < …，配上 aleph 不动点定理、奇异/正则基数的
> 分类，以及冯琦以**序数乘积空间典型秩序 + Gödel 编码**一手证明的
> **ℵ_α·ℵ_α = ℵ_α**（推论：无穷基数算术坍缩 κ+λ = κ·λ = max）。
> 收束于**连续统问题**与 CH 的独立性——19/54 章力迫叙事的入口预告。
> 与 03 章（Jech 的 Hartogs-Cantor-SB）与 06 章（基数算术 κ^λ）
> 对照：冯琦把"势"完全锚定在初始序数上，不可秩序化集合的势用秩
> 最小代表元兜底（定义 1.95）——一条不依赖选择公理的精巧设计。

## 74.1 ω₁ 与 α⁺：序数比集合多

设 W(R,A) 表示 R 是 A 上的秩序，Wo(ω) = {R ⊆ ω×ω | ∃A ⊆ ω, W(R,A)}
——ω 上全体秩序的集合（它是集合：ω×ω 的幂集的子集）。

> **定理 1.84** 存在序数 α 使一切 R ∈ Wo(ω) 的序型都 < α。
> *证明*：对每个 R，表示定理（72 章定理 1.64）给出唯一 ot(R)；
> **替换公理**把全体 ot(R) 收成集合 D；D 是传递的序数之集，故 D
> 本身是序数。∎

> **定义 1.89** ω₁ := ω⁺ := min{λ | ∀R ∈ Wo(ω) ∃β ∈ λ (β = ot(R))}。

> **定理 1.85** (1) |ω| < |ω₁|；(2) α 不可数 ∧ |ω| < |α| → ω₁ ≤ α；
> (3) ω ≤ α ∈ ω₁ → |α| = |ω|（从而 ∀β ∈ ω₁ (|β| < |ω₁|)）。
> *证明*（(1) 的换顶技巧）：若 f: ω ≅ ω₁，由 f 传输得 ω 上的秩序
> ≺，序型恰为 ω₁；把 f⁻¹(0) 顶到最大元位置，得到序型 ω₁+1 的秩序
> ——仍是 ω 上的秩序，与 ω₁ 的定义（一切 ω 上秩序的序型 < ω₁）
> 冲突。∎

——**ω 上的秩序有 ω₁ 种，恰好把可数序数全部用完**。这就是 Hartogs
定理的冯琦版（03 章的 Hartogs 用序数截段计数，这里用秩序计数；
两者都不要选择公理）。一般化（定理 1.86/1.87 + 定义 1.90）：每个
α ≥ ω 有 **α⁺**（比 α 强势的最小序数），|α| < |α⁺|，且
α ≤ β < α⁺ → |β| = |α|。

**机器锚点**：Isabelle/ZF 的 CardinalArith 正是这套词汇的官方影子
——`Card(K)`（K 是自己的初始序数）、`csucc(K)`（μ-算子定义的
"比 K 强势的最小基数"，即 α⁺）、以及定理 1.85(1) 的官方形态
`lt_csucc`：

```isabelle
definition omega1 :: "i" where
  "omega1 ≡ csucc(nat)"

lemma Card_omega1: "Card(omega1)"
  unfolding omega1_def by (rule Card_csucc [OF Ord_nat])

lemma uncountable_omega1: "nat < omega1"
  unfolding omega1_def by (rule lt_csucc [OF Ord_nat])
```

最小性（定理 1.85(2)）对应 `csucc_le`：Card(L) ∧ K<L ⟹ csucc(K) ≤ L
——任何比 K 强势的基数都不小于 K⁺。

## 74.2 初始序数：基数即序数

> **定义 1.91（势）** |α| := 与 α 等势的最小序数。
> **定义 1.92（基数）** α 是基数 ⟺ α = |α|（α 是自己的初始序数）。
> 后继基数 κ = β⁺；极限基数 ∀β<λ (β⁺ < λ)。

**命题 1.27**：(1) 每个自然数是基数；(2) ω = |ω| 第一个无穷基数；
(3) ω₁ = |ω₁| 第一个不可数基数；(4) |α| ≤ α < α⁺ = |α⁺|（α⁺ 总是
基数）；(5) α 是基数 ⟺ ∀β∈α (|β| < |α|) ⟺（α ≥ ω 时）α 上任何
秩序的序型都达不到 α。

> **定理 1.88** 正则序数必是基数。*证明*：α 正则而 |α| = β < α：
> 取双射 f: β → α 与 β 中无界单增列 g: cf(β) → β；每个 f[g(ξ)] 在
> α 中有界（cf(α) = α > β ≥ ξ），令 h(ξ) = sup f[g(ξ)]，则 h[cf(β)]
> 无界且长度 ≤ cf(β) ≤ β < cf(α)——矛盾。∎

> **定理 1.89（基数连续性）** 基数的非空集合 X：⋃X 是基数；X 无
> 最大元时 ⋃X 严格强于 X 中一切基数。

机器锚点：命题 1.27(5) 的官方形态是 `Card_iff_initial`
（Card(K) ⟺ Ord(K) ∧ ∀j<K. |j| < K——比 K 小的序数势严格更小）；
(2) 是 `Card_nat`；(4) 的后半是 `Card_csucc`。全部在 ST74 里以
`thm` 引用落账。

## 74.3 ℵ 序列与不动点

> **定义 1.93（ℵ 序列）** ℵ₀ = ω；ℵ_{α+1} = (ℵ_α)⁺；λ 极限时
> ℵ_λ = ⋃{ℵ_α | α < λ}。

**引理 1.23** α ≤ ℵ_α。**定理 1.90**：每个 ℵ_α 都是无穷基数，且
**每个无穷基数都是某个 ℵ_α**（对 α 归纳：后继步由 (ℵ_β)⁺ 的最小性，
极限步由基数连续性收并）。例 1.32：ℵ_ω 是第一个不可数极限基数。

> **定理 1.91（aleph 不动点）** (1) α < β → ℵ_α < ℵ_β（严格递增）；
> (2) ∀α ∃λ > α (ℵ_λ = λ)——**任意大的 aleph 不动点**。
> (2) 的证明：从 κ₀ = ℵ_{α+1} 起迭代 κ_{n+1} = ℵ_{κ_n}，取
> λ = sup_n κ_n；序列严格递增给出 ℵ_λ = sup_n ℵ_{κ_n} = sup_n
> κ_{n+1} = λ（cf(λ) = ω 保证极限步的连续性）。∎

**定义 1.94**：cf(κ) < κ 为**奇异**，cf(κ) = κ 为**正则**。例 1.33：
ω 是正则极限基数；ℵ_ω 奇异（cf = ω）；不动点定理给出任意多
"梯度为 ω 的奇异极限基数"。**命题 1.28**：cf(α) 总是正则**基数**；
正则序数是正则基数；κ > ω 正则极限基数时 κ = ℵ_κ。

**问题 1.6**：奇异的后继基数存在吗？（76 章见：选择公理下后继基
数总是正则——答案是否定的，但这是 AC 的功劳。）**问题 1.7**：aleph
不动点中有正则序数吗？——冯琦点破：**任何一个都是"大基数"**，
独立于 ZFC（79 章弱紧基数的序数侧写）。挂起的两问是通往 76-79
章的桥。

机器通道把不动点构造做成程序。Julia/Python 的符号嵌套打印
（examples/julia/74_cardinals.jl）：

```
κ_0 = ℵ₀
κ_1 = ℵ_{ℵ₀}  = ℵ_ω（第一个奇异基数，例 1.33）
κ_2 = ℵ_{ℵ_{ℵ₀}}
κ_3 = ℵ_{ℵ_{ℵ_{ℵ₀}}}}
  …sup_n κ_n = λ 满足 ℵ_λ = λ——任意大的 aleph 不动点（定理 1.91(2)）
```

注意 κ₁ 的读法：**ℵ₀ 作为序数就是 ω**（初始序数的红利），所以
ℵ_{ℵ₀} = ℵ_ω。Agda 通道（Ch74_cardinals.agda）把这条链做成
`chain : ℕ → SCard` 的递归定义，κ₁ ≡ ℵ_ω 由 `refl` 一眼看穿：

```agda
chain : ℕ → SCard
chain zero = aleph (fin 0)
chain (suc n) = aleph (aleph-embed (chain n))   -- κ_{n+1} = ℵ_{κ_n}
  where
  aleph-embed : SCard → OIdx
  aleph-embed (fcard n) = fin n
  aleph-embed (aleph (fin n)) = ωp n        -- ℵ₀ 的指标作序数 = ω
  aleph-embed (aleph (ωp n))  = ωp n

ex7 : chain 1 ≡ aleph (ωp 0)
ex7 = refl
```

**推论 1.12 + 定义 1.95（势的通用定义）**：X 可秩序化 ⟺ X 与某
ℵ_α 等势；此时 |X| := 该唯一基数。X **不可秩序化**时（ZF 中确实
可能！），定义 |X| := {y | |y| = |X| ∧ ∀z (|z| = |X| → RK(y) ≤
RK(z))}——**秩最小的等势代表全体**。命题 1.29：|X| = |Y| ⟺ 等势。
——这个定义的妙处：不排秩序也能谈"势"，把"势"做成集合而非虚
名词；AC 下两条定义合流（一切集合可秩序化）。

## 74.5 基数算术：和与积

> **定义 1.96** κ + λ := |(κ×{0}) ∪ (λ×{1})|；κ·λ := |κ×λ|。
> （即：不相交并与笛卡尔积的势。）

## 74.6 序数乘积空间的典型秩序与 ℵ·ℵ = ℵ

69 章的"max-正方块"典型序推广到序数对（定义 1.97）：
(α,β) < (γ,δ) ⟺ max{α,β} < max{γ,δ} ∨ (max 相等 ∧ α < γ) ∨
(max 相等 ∧ α = γ ∧ β < δ)。几何解释照旧：**内点 < 上边界（从左
到右）< 右边界（自下而上）< 外点**。

**定理 1.92**：(1) 典型序是 Ord×Ord 上的泛线性序；(2) 非空集有
最小元；(3) **α×α = {(ξ,η) | (ξ,η) < (0,α)}——每个方块是前段**。

> **定义 1.98（Gödel 编码）** ⟨α,β⟩ := ot({(ξ,η) | (ξ,η) < (α,β)})
> ——典型序下的名次。**命题 1.31**：Γ: (Ord×Ord,<) → (Ord,<)
> 保序且**满**（每个序数都是某对的编码）。

> **定理 1.93** ℵ_α · ℵ_α = ℵ_α。
> *证明*：令 θ_α = Γ(0,ω_α) = ot(ω_α×ω_α)。由于方块是典型序的
> 前段，Γ[ω_α×ω_α] = θ_α；所以只需证 θ_α = ω_α。对角嵌入
> β↦(β,0) 给出 θ_α ≥ ω_α。若 θ_α > ω_α，就取 (β,γ)∈ω_α×ω_α
> 使 Γ(β,γ)=ω_α；令 δ=max{β,γ}+1<ω_α。于是 (β,γ)∈δ×δ，
> 故 ω_α≤θ_δ。另一方面，δ 若有限，θ_δ 也有限；δ 若无穷，则
> |δ|=ω_ξ，某 ξ<α，由 α 的最小性得
> |θ_δ|=|δ×δ|=ω_ξ·ω_ξ=ω_ξ<ω_α。两种情形都与 ω_α≤θ_δ 矛盾。
> 因而 θ_α=ω_α，方块与 ω_α 等势。∎

> **推论 1.13** κ + λ = κ·λ = max{κ, λ}（κ, λ 无穷）。

——无穷基数算术的"乘法坍缩"：无穷乘无穷还是无穷，不涨。这是
69 章 |ω×ω| = |ω| 的全谱推广，用的是 Gödel 配对的**结构**（方块
= 前段）而不只是计数。对照 06 章（Jech：κ·κ = κ 由良序化得到）
——冯琦的证法把基数锚定在初始序数上，序数自带良序，不另需选择。

**机器通道的主战场一：Gödel 配对的 ℕ 截面双射。** Julia/Python/
Prolog 三通道实现壳层名次公式与逆映射并全网格对拍：

```python
def gpair(a, b):
    m = max(a, b)
    if a < m: return m * m + a        # 上边界（从左到右）：偏移 a
    if b < m: return m * m + m + b    # 右边界（自下而上）：偏移 m+b
    return m * m + 2 * m              # 角点 (m,m)：偏移 2m

def gunpair(p):
    m = isqrt(p); t = p - m * m
    if t < m: return (t, m)
    if t < 2 * m: return (m, t - m)
    return (m, m)
```

0..1999 往返恒等、12×12 网格单射、m×m 网格名次恰占满 0..m²−1
（"方块=前段"的逐格对拍，m ≤ 12）全绿——ℵ₀·ℵ₀ = ℵ₀ 的构造性
身影。Coq 通道（Ch74_cardinals.v）给出**双射的完整证明**——
`sqrt_pair_shell` 用 `Nat.sqrt_unique` 的区间判据把名次钉回壳层，
然后两向 round-trip：

```coq
Theorem unpair_pair : forall a b, unpair (pair a b) = (a, b).
Theorem pair_unpair : forall p,
  pair (fst (unpair p)) (snd (unpair p)) = p.
```

证明的趣味点：壳层内三段（a<m 偏移 a、a=m>b 偏移 m+b、(m,m)
偏移 2m）与 sqrt 定位（m² ≤ p < (m+1)²）的咬合——每一段都是
`lia`/`nia` 的有限算术，但"名次 = m² + 壳内偏移"这个**定义**本身
就是定理 1.92(3)（方块=前段）的计算化：没有方块是前段，名次公式
就不闭合。Agda 通道以 0..200 的批量 `refl` 做构造性对拍。

**主战场二：方块层数 gsq 与坍缩点。** 机器算出典型序下方块 μ×μ
的序型 gsq(μ)：有限段 gsq(m) = m²；gsq(ω) = **ω**（配对双射！）；
gsq(ω+n) = ω·(2n+1)+n²——**离开初始序数就涨**：

```
gsq(ω+1) = ω·3+1、gsq(ω+5) = ω·11+25
```

ℵ·ℵ = ℵ 的内容正是"gsq 在每个初始序数处坍缩回自身"——机器能
展示有限与 ω 的坍缩点，一般定理（证明见上）是超限归纳的纸面功。

**主战场三：max 规则引擎。** 推论 1.13 做成符号演算
（Julia/Python/Prolog/Agda 四通道同款）：

```
ℵ₂ + ℵ₀ = ℵ_2、ℵ_ω · ℵ₃ = ℵ_ω、(ℵ₂ + ℵ₁) · ℵ₀ = ℵ_2
有限退化：3 + 7 = 10、3 · 7 = 21
```

## 74.7 收束：从长度到多少

72 章把序数立为"长度"的全谱标尺，本章把基数立为"多少"的全谱
标尺——且后者是前者的**子列**（初始序数）。ℵ 序列的连续统问题
（2^{ℵ₀} 在哪个位置）是全书的引力中心；而"基数算术坍缩到 max"
说明无穷世界的"加乘"是平凡的，**真正的断层只在指数**——这为
76 章（选择公理与无穷乘积不等式）与 78 章（奇异基数假设）搭好
了舞台。下一章回到结构侧：**传递化**——把一切有秩外延结构坍缩
成传递集合，冯琦版 Mostowski 定理。
