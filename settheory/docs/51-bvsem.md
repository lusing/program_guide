# 51 · 布尔值语义：B-值模型、可靠性与完备性

> 现在到了 Viale 路线的**理论心脏**：把一阶逻辑的真值从 {0,1} 推广
> 到任意布尔代数 B。Tarski 语义是 B = 2 的特例；本章将证明这套
> 推广**可靠且完备**——力迫关系不是发明，而是布尔值语义的定理。
>
> 本章覆盖 Viale §6.1-6.2。

## 51.1 B-值模型的定义

**定义（Viale Def 6.1.1）** 设 ℒ 为关系语言（无函数符号）、B
布尔代数。**B-值模型** M 由以下数据组成：
1. 非空域 M；
2. 等词的解释 =ᴹ : M² → B；
3. 每个关系符号 R 的解释 Rᴹ : Mⁿ → B；常元 c 的名字 cᴹ ∈ M；
满足三条**相容性公理**：
- (等词三律) ∀σ,τ ∈ M：σ =ᴹ σ = 1；σ =ᴹ τ = τ =ᴹ σ；
  σ =ᴹ τ ∧ τ =ᴹ ρ ≤ σ =ᴹ ρ；
- (关系相容) ⋀ᵢ (σᵢ =ᴹ τᵢ) ∧ Rᴹ(σ̄) ≤ Rᴹ(τ̄)。

**为什么等词要取值在 B**：布尔宇宙里"两个名字相等"本身就是
有真值的事件（54 章的 ⟦τ = σ⟧）。等词三律说"相等"必须是 B 上
的等价关系——1-对角、对称、传递（以 ≤ 的弱形式）。关系相容律
说"谓词不区分相等者"。

## 51.2 语义指派

**定义（Viale Def 6.1.2）** 对句子 φ，值 ⟦φ⟧ 在 **RO(B)** 中
定义（B 稠密嵌入其补全——46/49 章；B 足够完备时落回 B 内，
此时称 M **良行为 well-behaved**）：
- ⟦R(c̄)⟧ := Rᴹ(c̄ᴹ)，⟦σ = τ⟧ := σ =ᴹ τ；
- ⟦¬φ⟧ := ¬⟦φ⟧，⟦φ∧ψ⟧ := ⟦φ⟧∧⟦ψ⟧（∨、→ 派生）；
- **⟦∃x φ(x)⟧ := ⋁_{σ∈M} ⟦φ(σ)⟧**，∀ 对偶——量词是域上的 sup/inf，
  这正是需要完备性/RO(B) 的地方。

原子公式取值在 B 中，布尔组合留在 B 中，但量词可能"溢出"到
RO(B)——良行为性是模型的属性而非语义的属性。

## 51.3 可靠性与完备性

**定义** φ 在 M 中**有效**：⟦φ⟧ = 1。

**定理（Viale Thm 6.1.5，可靠性+完备性）** 对关系语言 ℒ：
φ 从理论 T **可证** ⟺ 对**一切**布尔代数 B、一切 B-值模型 M
与 T 的一切公理 ξ：⟦ξ⟧ ≥ ⟦φ⟧（T 有效则 φ 有效）。

*可靠性*的证明：对八条公理模式逐条计算值为 1、对八条推理规则
逐条验证保值。核心样板（公理 x = x →（代换）规则）：
- 公理 σ = σ：等词三律第一条款。
- 代换规则 φ(a), a = b ⊢ φ(b)：归纳于 φ 的复杂度——原子情形用
  关系相容律；¬、∧ 情形用布尔运算的单调性；∃ 情形：a =ᴹ b ≤
  ⟦φ(a)⟧ → ⟦φ(b)⟧ 给 sup 的传递。∎（Viale pp. 85-87 的完整
  逐条清单由 Coq 通道机器复刻。）

*完备性*：一行——Tarski 模型（B = 2 的 B-值模型）是特例，
经典完备性定理直接注入。∎

**教义**：布尔值语义**没有丢掉任何经典逻辑**——可证 = 全 B-有效。
它的"多值"不是削弱而是**细化**：在 2-值里"未定"被强行拍板成
真/假，在 B-值里未定就是 0 < ⟦φ⟧ < 1 的具体元素。

## 51.4 k-态射

**定义（Viale Def 6.1.6）** k : B → C 同态，f : M → N：
- **k-态射**：Rᴹ(ā) ≤ ⟹ Rᴺ(f(ā)) ≥ k(Rᴹ(ā)) 型的弱保持；
- **k-嵌入**：等号版本；
- **k-同构**：满的 k-嵌入。
Id₂-态射 = 经典同态。这套范畴语言在 52 章（商构造）与 54 章
（M^B 与 M[G] 的桥）出场。

## 51.5 C(ℝ) 大讨论：布尔扩张的直觉

Viale §6.2 的招牌例子——**把解析函数当作" ℝ 的布尔扩充"**：
- B := RO(ℝ)（欧氏拓扑的正则开——49 章的 cBa）；
- 域 := C(ℝ)（解析函数全体），常数 c_a 是 ℝ 的"check 名"；
- f < g := 最大的正则开 a 使 {x ∈ a : f(x) < g(x)} 在 a 中稠密。

sin < cos 的值是开集 ⋃ₖ(5π/4+2kπ, 9π/4+2kπ)（sin−cos =
√2·sin(x−π/4) < 0 的解带；Viale 原文写的是 (π/4,5π/4) 带——
那是 sin > cos 的带，PDF 提取的符号乱码由 Julia 通道数值
勘误）——**在哪些区段上 sin < cos 被强制成立**。两个震撼：
1. **0 < ⟦sin < cos⟧ < 1**：布尔扩充无法决定 sin 与 cos 的大小
   ——多值性的物理呈现；
2. **超滤子做决定**：任何 G ∈ St(RO(ℝ)) 恰选 sin<cos、sin=cos、
   sin>cos 之一（三者析取值为 1，超性二选一）。π/4 的邻域滤子
   **不够**（π/4 处 sin = cos，但两侧开集各执一词）；换成超滤
   子就够了。**泛型点 = 相容的裁决机**。
- Julia 通道用区间算术数值复刻 sin/cos 的布尔值与"π/4 邻域
  裁决失败、超滤裁决成功"的剧场。

这正是力迫的预演：V^B 是集合论的"C(ℝ)"，M-泛型滤子是那个
"做决定的外来者"。

## 51.6 机器通道

**Lean（`Settheory/Ch51BVsem.lean`）**：自建 `BValued` 结构
（等词 + 单关系 + 相容律）与命题片段的语义指派；验证等词三律
在 Bool 实例上的形态 + 代换规则的原子情形（关系相容律的应用）。

**Coq（`examples/coq/Ch51_bvsem.v`）**：**八条演算规则的可靠性
机器复刻**——浅嵌入：公式归纳类型 + B = 4 元布尔代数（Bool×Bool）
上的赋值函数 ⟦·⟧；逐条证明八公理值为 ⊤（completeness 方向
由"2-值特例"注记承载）。

**Agda（`examples/agda/Ch51_bvsem.agda`**：B-值模型的最小实例：
域 = Bool 上的 2 元、B = Bool×Bool；验证等词三律与语义指派的
布尔组合律（16 分支 refl）。

**Julia（`examples/julia/51_bvsem.jl`）**：**C(ℝ) 剧场**——
(a) sin < cos 的布尔值：区间扫描出 {x : sin x < cos x} 的连通
分量并（RO(ℝ) 元素的数值化身）；(b) π/4 邻域滤子不能裁决，
超滤（区段选择的极大相容族）能——裁决剧场三幕。

**Python（`examples/python/51_bvsem.py`）**：同一场剧的网格版 +
量词的 sup/inf 数值演示：∃x∈ℚ φ(x) 的值 = 域上取值的 max
（稠密域逼近连续 sup）。

**Prolog（`examples/prolog/51_bvsem.pl`）**：有限 B-值模型的
真值表生成器：给定 B = 4 元代数上的小模型，计算全部分子的值，
验证 ⟦¬(φ∧ψ)⟧ = ¬⟦φ⟧∨¬⟦ψ⟧ 等恒等式。

**Isabelle/ZF（`examples/isabelle/ST51/BVsem.thy`）**：B-值
等词三律的谓词式骨架：`beq_refl/beq_sym/beq_trans` 三引理
（在 B = 𝒫(A) 的实例上，手动 Isar）。
