# 28 · 测度问题：Ulam 与可测基数

> 可测基数是大基数理论的起点：κ 上的非平凡 σ-加性 0-1
> 测度的存在超越了 ZFC 的证明能力。

本章覆盖 Jech §27：测度问题、Ulam 矩阵、可测基数的定义。

## 28.1 测度问题

**测度** μ : P(S) → {0,1} 使 μ(S)=1、μ(∅)=0、σ-加性。
（非主：单点测度为零。）

**Ulam 的观察**：ω 上的非主 σ-加性 0-1 测度不存在
（可数集的单点并覆盖）。但更大的基数上呢？

**Ulam 矩阵**：对 ω₁ 的构造——⟨A^α_β : α < ω₁, β < ω⟩
使每行可数并、每列至多一个。若 ω₁ 上有非主测度则矛盾。

**可测基数**：κ 上存在非主 σ-加性 0-1 测度。

## 28.2 实值可测

**实值可测**：κ 上存在非主 σ-加性 [0,1]-值测度。
（比 0-1 测度弱——但 Ulam 证明：实值可测 + κ < 强不可达
⟹ 2^ℵ₀ = κ。Solovay 证明实值可测的一致性。）

## 28.3 可测基数的性质

- 可测 → 不可达（Ulam 的经典论证）
- 可测 → Mahlo（正规测度 → 平稳集有测度 1 的成员）
- 可测的存在不可在 ZFC 中证明（Scott：V≠L）

## 28.4 习题精选

1. **（纸笔）** Ulam 矩阵的构造细节。
2. **（纸笔）** 可测 → 不可达的完整证明。
3. **（纸笔）** 非主测度在 ω 上不存在的证明。
