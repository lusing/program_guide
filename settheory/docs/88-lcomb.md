# 88 · L 中的组合原理与弱紧基数

第 87 章把 L 的骨架立了起来：可构造层次、哥德尔运算、<_L 秩序、凝聚化引理，最终推出 GCH 在 L 中成立。这一章转向 L 的**组合相貌**。哥德尔 1938 年只证明了 L ⊨ GCH；二十多年后，Jensen 在同一个构造里挖出了更精细的东西：L 不仅决定基数算术，还决定 ω₁ 上的组合结构——L 中存在一棵苏斯林树（定理 2.12），更一般地，L 满足钻石原理 ◇（定理 2.14）。本章前半段完整重建这两个证明，看清「凝聚化 + <_L 最小反例」这个被 Jensen 反复使用的论证模式。

后半段转向大基数。弱紧基数 κ 在第一卷以两条组合性质登场（拉姆齐划分性质与树特性）；本章先按冯琦 §2.1.5 的讲法给它**第三种等价刻画**：无穷语言 ℒ_{κ,κ} 的弱紧致性定理（定理 2.15），再证明弱紧性与 L 相容——V 中的弱紧基数在 L 中仍然弱紧（定理 2.16）。这是「内模型保持大基数」的第一个范例。机器通道处理这四条定理中真正可有限化的引擎：封口保持性（性质 (4)）、钻石时刻表的 ω-影子、柯尼希树枝的贪心构造、无穷语言紧致性的有限骨架；完整的 ω₁ 递归与凝聚化反证由正文自包含给出。

## 88.1 苏斯林问题与规范树

先把问题摆正。实数轴（序完备、无端点、稠密可分的线性序）由这五条序性质唯一确定。**苏斯林问题**（1920）问：把「可分」（有可数稠子集）换成更弱的「可数反链条件」（任意两两不交的非空开区间族可数，简称 ccc），是否还唯一？答案在 ZFC 中不可判定。一棵**苏斯林树**——高度 ω₁、每一层可数、没有不可数反链也没有长度 ω₁ 的树枝的树——的存在性等价于苏斯林假设的否定。

Jensen 定理说的是：若 V=L，则苏斯林树存在。证明靠的是递归构造一棵**规范树**（normal tree）：

- 节点是 0-1 有穷/可数序列，树序是前缀延拓，T ⊆ [0,1]^{<ω₁}；
- 第 0 层只有空序列；每个节点在后继层恰有两个直接延拓 t∪{(α,0)} 与 t∪{(α,1)}（正常分叉）；
- 高度 α < ω₁，故每层可数、整树势 ℵ₁；
- 极限层的节点不是自动取所有树枝，而是**精心挑选**可数根树枝的并——全部构造的机关都在这里。

为什么不能直接让所有树枝都进极限层？那样长下去，一棵无人管束的树很可能在某个极限层之前就养出了不可数反链。Jensen 的对策是：在每个极限层「封口」一个极大反链，让它的极大性被未来永久继承，以至于最终不可能再有不可数反链。

## 88.2 定理 2.12 的递归构造

固定极限序数 α，假设 T↾α = ⋃_{β<α} T_β 已造好。先在 T↾α 上取一个特殊的极大反链：在所有「与 α 等高」的极大反链（即每个高度为 α 的树枝都经过它——对 T↾α 共尾的极大反链）中，取 <_L 最小者，记 A_α。

这样的反链一定存在。证明本身就是一次小构造：取 L 中 <_L 最小的收敛于 α 的单调递增序列 ⟨α_n | n<ω⟩；在每个高度 α_n 上 T_{α_n} 本身就是极大反链（该层每个节点高度一致，互不可比，且拦截所有等高树枝）。递归挑一条升链 t_n ∈ T_{α_n}：t₀ 取层上 <_L 最小者，t_{n+1} 取 T_{α_{n+1}} 中延拓 t_n 的最小节点；由此得到一根等高树枝 b。再在每个 t_n 旁边取一个「分叉伙伴」u_n（同一高度、与 t_{n+1} 不同向延拓 t_n 的最小节点），则 {u_n | n<ω} 是一根与 b 分叉的等高反链，把它扩张成 T↾α 的极大反链即可——候选集非空，<_L 最小者存在。

接着封口。对每个 t ∈ T↾α，令 b_t 为经过 t 且与 A_α 相交的等高树枝中 <_L 最小者；令

B_α = {b_t | t ∈ T↾α}，　T_α = {⋃b | b ∈ B_α}，　T↾(α+1) = T↾α ∪ T_α。

T_α 可数（T↾α 可数）。关键性质，也是全章机器件的主角：

> **性质 (4)。** A_α 在 T_α 的定义中被永久保持为极大反链：对任意 α ≤ γ < ω₁ 与任意 t ∈ T_γ，限制 t↾α 落在 T_α 中，于是 t↾α 延拓 A_α 的某个成员，t 自己也延拓那个成员。未来每一层的每个节点都从 A_α 的某成员下方长出来——A_α 从此不可能再被绕开。

整个序列 ⟨T_α | α<ω₁⟩ 连同封口数据 ⟨(A_α,B_α) | α 极限⟩ 全部由 <_L 最小选择递归定义。「x ∈ L」是 Σ₁ 的（第 87 章引理 2.14），递归定义定理在 L_{ω₂} 内合法实施，故 (T, T↾α, A_α, B_α) ∈ L_{ω₂}。最终 T = ⋃_{α<ω₁} T↾α 是高度 ω₁、势 ℵ₁ 的规范树，T ∈ L_{ω₂}。

**反证 T 没有不可数反链。** 假设有。取 <_L 最小的不可数极大反链 A ⊆ T（任何不可数反链都能扩张成极大反链；取最小者这一步在 (L_{ω₂},∈) 中完成，A ∈ L_{ω₂}）。定义

C_A = {α < ω₁ | A ∩ T↾α 是 T↾α 的极大反链，且 ∀β<α (A∩T_β 已就位)}。

**C_A 是 ω₁ 的无界闭子集。** 闭：α = sup α_n、每个 A∩T↾α_n 极大，则 A∩T↾α 拦截每根等高树枝（升链取极限）。无界：给定 β₀，递归 β_{n+1} 取一个足够大的序数，使得 β_n 之下每根树枝上 A 的拦截节点都落进 T↾β_{n+1}（每层可数、A 极大，只需可数步）；α = sup β_n 即在 C_A 中。且 C_A ∈ L_{ω₂}（定义参数全在 L_{ω₂}）。

取可数集合 X = (ω+1) ∪ {ω₁, T, A, C_A, (T↾α, T_α)…, (A_α,B_α)…}（把全部构造数据作为单点放进去）。令 M ≺ (L_{ω₂},∈) 为包含 X 的最小同质子模型（第 87 章引理 2.21 的斯科伦壳），则 M 可数且 X ⊆ M。令 α = M∩ω₁。由 ω+1 ⊆ M 与同质性，α 是极限序数；C_A ∈ M 且 C_A 无界，故 α ∈ C_A，且 L_α = M∩L_{ω₁}。

两个决定性的等式：

1. **T ∩ M = T↾α。** ⊆：t ∈ T∩M，β = dom(t)。「β 是可数序数」在 L_{ω₂} 中成立，由同质性在 M 中成立，故 β ⊆ M、β < α，t ∈ T↾α。⊇：β < α 时 T_β ∈ M；T_β 在 L_{ω₂} 中可数，于是 M 中也有枚举 f : ω → T_β；ω ⊆ M 保证每个 f(n) ∈ M，故 T_β ⊆ M。

2. **A ∩ T↾α = A_α。** 用凝聚化引理（第 87 章定理 2.10）：π : M ≅ L_β，π 在 L_α 上逐点恒等，π(ω₁) = α，π(T) = T↾α，π(A) = A∩T↾α。而 A 是「<_L 最小的不可数极大反链」，经初等嵌入，π(A) 成为 (L_β,∈) 中极限层 α 处按同一定义选出的最小反链 (A_α)^{L_β}；传递模型对 Δ₀ 性质绝对（第 87 章推论 2.1），真实的 A_α 就是它：A∩T↾α = (A_α)^{L_β} = A_α。

矛盾呼之欲出：构造 T_α 时 A_α 已被永久封口——未来每个节点都延拓 A_α ⊆ A 的某个成员。于是 A 不可能再有高度 ≥ α 的成员（它会与 A_α 中成员可比，违反反链性），A = A∩T↾α 可数，与其不可数矛盾。∎

注意整个论证的三个支柱：**<_L 最小选择**（让定义绝对、让凝聚化保持「最小」语义）、**可数同质子模型 + 凝聚化**（把全局反例截断到某个可数层）、**封口**（让截断处恰好撞上已被处理的反链）。下一节会看到同一个模式直接产出钻石原理。

## 88.3 封口引擎的机器件

性质 (4)——「封口一旦完成便永久保持」——不依赖 ω₁、可数性与 <_L，它是关于前缀序的一条纯归纳事实，七通道中有六个直接机器化它。Lean 的表述最精炼（`Ch88LComb.lean`）：

```lean
/-- 反链 A 在层 T 上「封口」：每个节点延拓 A 的某个成员。
被封口的反链在该层之上自动保持极大性。 -/
def sealed (A T : List (List Bool)) : Prop :=
  ∀ t ∈ T, ∃ a ∈ A, a <+: t

/-- 定理 2.12 性质 (4)：封口一旦完成便永久保持。 -/
theorem sealed_persists {A : List (List Bool)} {T : Nat → List (List Bool)}
    {k : Nat} (h0 : sealed A (T (k + 1)))
    (hstep : ∀ n ≥ k + 1, ∀ t ∈ T (n + 1), ∃ s ∈ T n, s <+: t) :
    ∀ n, k + 1 ≤ n → sealed A (T n)
```

输入只有两条：封口层 h0（第 k+1 层每个节点延拓 A），树步进 hstep（每一层的每个节点延拓前一层的某节点）。归纳在 n 上：基例就是 h0；后继步取 t ∈ T(n+1)，由 hstep 找到前层父亲 s，由归纳假设找到 a ∈ A 封到 s，再用前缀关系的传递性 `IsPrefix.trans` 把 a 接到 t。这条传递性正是 Jensen 证明里「t↾α 延拓 A_α 成员则 t 也延拓它」的有限形态。

Coq 通道把同一个归纳证在 Prop 层（`Ch88_lcomb.v` 的 `sealed_persists`），其中前缀传递性单独成引理：

```coq
Lemma prefix_trans : forall a s t,
  (exists r, s = a ++ r) -> (exists r, t = s ++ r) -> exists r, t = a ++ r.
Proof.
  intros a s t [r1 Hs] [r2 Ht].
  exists (r1 ++ r2).
  rewrite Ht, Hs, app_assoc. reflexivity.
Qed.
```

证据就是结合律：t = s++r₂ = (a++r₁)++r₂ = a++(r₁++r₂)。Agda 通道的 `prefix-trans` 同构（靠 `++-assoc` 与等式复合），其归纳因 Agda 没有自动 omega，改用 `n ≟ k` 可判定分叉：相等回到 h0，不等时把 `suc k ≤ n` 用 ≤∧≢⇒< 降成严格小于再递归。

Isabelle/ZF 通道把假设压到最薄的 locale（`ST88/LComb.thy`）：

```isabelle
locale prefix_tree =
  fixes R :: "i ⇒ i ⇒ o"
  fixes T :: "i ⇒ i"
  assumes R_trans: "⟦R(x, y); R(y, z)⟧ ⟹ R(x, z)"
  assumes step: "⟦n ∈ nat; t ∈ T(succ(n))⟧ ⟹ ∃s ∈ T(n). R(s, t)"
```

locale 里不出现前缀、序列、布尔——R 是任意传递的延拓关系。`sealed_persists` 在其中对 nat 归纳（ZF 的 nat 不是 datatype，用内置 `nat_induct` 规则），证明性质 (4) 只需要「步进 + 传递」这两条抽象公理。这恰好解释了封口技巧在 Jensen 论证里的普适性：88.4 的钻石证明、第三卷的 morass 构造，复用的都是这个 locale 的模型。

封口的**计算样品**由 Coq 与三个计算通道给出。Coq 在满二叉树的第 2 层封口单点反链 {[true;true]}：先把第 1 层正常延拓一层，再过滤出延拓该反链的节点作为新第 2 层，此后恢复正常分叉。守卫检查逼出了一个泛型递归 `Tfrom l m`（只在步数 m 上递归，避免「递归调用写死 Tdemo 1」被 guard 拒绝）；传播引理 `sealed_from` 证「封口层之上正常分叉仍封口」，核心子引理是延拓保前缀 `extends_children`（父亲延拓 a，则两个孩子都延拓 a）。最后

```coq
Theorem Tdemo_sealed_all : forall n, 2 <= n ->
  forall t, In t (Tdemo n) -> extends_some [[true; true]] t = true.
```

把性质 (4) 在每个具体的 n 上机器证实。`Compute` 给出的层规模是 1, 2, 1, 2, 4, 8：满二叉树第 1 层有 2 个节点，封口剪掉一支只剩 1 个，之后每层翻倍。

Python/Julia/Prolog 把实验做到**两次封口**（对应 Jensen 在每个极限层各封一个反链）：第 2 层封 {(1,1)}，第 6 层再封当时顶层的首节点，层规模为

```
层规模: [1, 2, 1, 2, 4, 8, 2, 4, 8, 16]（两次封口各剪掉一半）
```

每次封口把 16 个候选节点剪到只剩 2 个（新反链单点的两个孩子），随后正常翻倍；断言逐条检查 A0 自第 2 层、A1 自第 6 层起在每一层仍被延拓——「极大性永久保持」在 10 层、16 节点的小树上看得见摸得着。

## 88.4 钻石原理：定义 2.18、定理 2.13、定理 2.14

**定义 2.18（◇）。** 钻石原理是如下语句：存在序列 ⟨S_α | α < ω₁⟩，其中 S_α ⊆ α，使得对每个 X ⊆ ω₁，猜测命中集

{α < ω₁ | X ∩ α = S_α}

是 ω₁ 的荟萃子集（与每个无界闭集相交）。

一个长度 ω₁ 的序列，每个 S_α 只占 α 这么大，却要对 **2^{ω₁} 个** X 各自在荟萃多个阶段恰好猜中 X 的初始段——这听起来像免费午餐。它的分量由两条定理显示。

**定理 2.13。** ZFC ⊢ ◇ → CH。

**证明。** 令 ⟨S_α | α<ω₁⟩ 为钻石序列。任给 X ⊆ ω（把实数看成 ω 的子集）。命中集荟萃，故无界（荟萃集必无界），取其中一个 α > ω。此时 S_α = X∩α = X（X 的元素都是自然数，全在 α 之下）。于是每个实数 X 都至少在某个阶段被整段猜中。定义 f(X) = 最小的使 X = S_α 的 α：这是 𝒫(ω) → ω₁ 的单射（同一个 S_α 不可能等于两个不同的 X），故 2^{ℵ₀} ≤ ℵ₁；反向是 ZFC 的 ℵ₁ ≤ 2^{ℵ₀}。故 CH。∎

◇ 比 CH 严格更强（CH 不蕴含 ◇），但在 L 里二者都是定理。

**定理 2.14（Jensen）。** ZF + V=L ⊢ 存在钻石序列。

**证明。** 递归定义长度 ω₁ 的有序对序列 ⟨(S_α,C_α) | α<ω₁⟩：

- 起始：S₀ = C₀ = ∅；
- 后继：S_{α+1} = C_{α+1} = α+1（后继层不重要，随便喂一个俱乐部）；
- 极限：在 𝒫(α)×𝒫(α) 中考察「局部反例对」(S,C)：C 是 α 的无界闭子集且 ∀ξ ∈ C (S∩ξ ≠ S_ξ)（即 C 上处处猜不中 S）。若这种对存在，令 (S_α,C_α) 为其中 <_L 最小者；否则令 (S_α,C_α) = (α,α)。

全部数据由 <_L 最小选择递归给出，单点集 {⟨(S_α,C_α) | α<ω₁⟩} ∈ 𝒟(L_{ω₂})，序列在 L_{ω₂} 中。

验证 ⟨S_α⟩ 是钻石序列。若不然，存在 X ⊆ ω₁ 与 ω₁ 的无界闭集 C 使 ∀α ∈ C (X∩α ≠ S_α)。令 (X,C) 为所有这种反例对中 <_L 最小者；由绝对性，(X,C) 在 (L_{ω₂},∈) 中也是最小反例对。取包含序列、ω₁、(X,C) 的可数同质子模型 M ≺ L_{ω₂}，令 α = M∩ω₁。则 α ∈ C（C ∈ M 无界，老论证），凝聚化 π : M ≅ L_β 给出

π(X) = X∩α，π(C) = C∩α，π(⟨S_ξ | ξ<ω₁⟩) = ⟨S_ξ | ξ<α⟩，

且 (X∩α, C∩α) 是 (L_β,∈) 中极限层 α 处的 <_L 最小反例对；Δ₀ 绝对性把这个身份搬到 V。可递归定义在 α 这一步挑的恰恰就是最小反例对：

X∩α = S_α，　C∩α = C_α。

但 α ∈ C 给出 α ∈ C∩α = C_α，而反例对的定义要求 ∀ξ ∈ C_α ((X∩α)∩ξ ≠ S_ξ)；在 ξ = α 处（等价地，由假设 α ∈ C）正是 X∩α ≠ S_α，矛盾。∎

与定理 2.12 的同构一目了然：**最小反例 + 可数壳 + 凝聚化截断 + 截断点撞上递归定义**。Jensen 正是从苏斯林树证明里提炼出了 ◇；苏斯林树的存在性也是 ◇ 的推论（封口每个 <_L 最小极大反链所需的全部指令都由钻石序列提供），所以定理 2.12 也可经 ◇ 间接得到。

## 88.5 钻石时刻表与柯尼希树枝的 ω-影子

定理 2.14 的递归用了 ω₁、<_L 与凝聚化，无法整体搬进机器；但「一个序列猜中一族目标的每个成员无穷多次」这个**调度内核**有精确的 ω-影子，Lean 把它证成了定理。

想法：把可数多个目标集合 X₀, X₁, X₂, … 排成队，第 n 步用 2-进赋值 v₂(n)（n 中因子 2 的个数）决定该猜谁：

n = 1,3,5,7,…（v₂=0）猜 X₀；n = 2,6,10,…（v₂=1）猜 X₁；n = 4,12,20,… 猜 X₂；……

每个目标 i 分到全部形如 2^i·(2m+1) 的时刻，无穷多个。Lean 先把算术账证死（`Ch88LComb.lean`）：

```lean
theorem vtwo_pow_mul_odd (i m : Nat) :
    vtwo (2 ^ i * (2 * m + 1)) = i
```

对 i 归纳：基例奇数的 v₂ 为 0；后继步把 2^{i+1}·奇数 写成 2·(2^i·奇数)，用 `vtwo_double_pos`（翻倍使赋值加 1）接上归纳假设。然后定义时刻表 S（第 n 行是 X_{v₂ n} 的初始段）并证明调度定理：

```lean
theorem diamond_hit (X : Nat → Nat → Bool) (i K : Nat) :
    ∃ n, K < n ∧ vtwo n = i ∧ ∀ j < n, S X n j = X i j
```

见证取 n = 2^i·(2K+3)：它 > K（2^i ≥ 1）、是奇数 2K+3 的 2^i 倍故 v₂ 恰为 i，而第 n 行按定义就是 X_i 的前 n 位。任意界 K 之后都有一次对 X_i 的精确命中——「命中集无界（乃至荟萃）」在 ω 尺度的对应物。K 之上有无界多命中，正是荟萃性「与每个俱乐部相交」的算术内核。

计算通道把时刻表跑成数字。对前 479 个正时刻，各目标分到的时刻数为

```
时刻表各目标时刻数: [240, 120, 60, 30, 15, 7]
```

恰好是 ⌊480/2^{i+1}⌋ 的形状：一半时刻猜 X₀，四分之一猜 X₁，……每个目标仍分到无穷多（密度 1/2^{i+1} > 0）。Python/Julia/Prolog 三家数字一致，Prolog 还用 `vtwo(N,I), M is N >> I, 1 is M mod 2` 对每个 n 复核 n = 2^i·奇数的分解。

第三组样品为 88.6 的弱紧刻画做铺垫：**柯尼希无限树引理**（第一卷定理 I.2.41）——每层有限、任意深的 finitely branching 树必有无限树枝。考虑可判定无限树「每个前缀 p 满足 #1(p) ≤ #0(p)+2」：它每层有限且任意深（全 0 路径永远在内）。贪心构造每一步选一个「子树在更深处仍有节点」的孩子（试探：孩子本身在树内，且接上四个 0 之后仍在树内），三个计算通道都贪心走出长度 24 的树枝并逐前缀复核树条件。这里用到的正是弱紧基数树特性在 κ = ω 的形态：**层有限 + 无限深 ⇒ 有树枝**。不可数版本把「层有限」换成「层势 < κ」、选择孩子时的「存在有限深度见证」换成 κ-完备性——下一节的语言刻画会把这件事说精确。

## 88.6 无穷语言：定义 2.19、2.20

弱紧基数在第一卷有两条组合刻画（κ → (κ)²₂ 划分性质；高 κ、每层 < κ 的树有 κ-树枝的树特性）。冯琦 §2.1.5 给出第三条：**逻辑紧致性的不可数翻版**。先扩充语言。

**定义 2.19（ℒ_{κ,ω} 与 ℒ_{κ,κ}）。** 设 κ 为无穷基数。语言 ℒ_{κ,ω} 由下列因素构成：

1. κ 个变元符号；
2. 若干关系、函数、常元符号；
3. 五个基本联结词，此外对每个 α < κ 有长度为 α 的析取 ⋁_{ξ<α} φ_ξ 与合取 ⋀_{ξ<α} φ_ξ；
4. 普通的单个量词 ∃v、∀v（量词块长度有限）；
5. 表达式由上述符号递归形成。

ℒ_{κ,κ} 完全类似，额外容许长度 **α < κ** 的量词块 ∃⟨v_ξ | ξ<α⟩ 与 ∀⟨v_ξ | ξ<α⟩。

语义按有限情形逐条推广：无穷析取在某赋值下为真当且仅当某个支为真，无穷合取要求所有支为真；长度 α 的存在量词解释为变元序列 ⟨v_ξ | ξ<α⟩ 存在一个赋值使后续表达式成立，全称量词要求一切赋值都成立；否定词穿过无穷联结词时遵守德摩根律 ¬⋁φ_ξ = ⋀¬φ_ξ。κ = ω 时两种语言都退回普通一阶语言 ℒ_{ω,ω}（有限析取、有限量词块）。

**定义 2.20（弱紧致性定理）。** 称 ℒ_{κ,κ}（或 ℒ_{κ,ω}）具备弱紧致性定理，当且仅当：对任何**势不超过 κ** 的语句集 Σ，Σ 有模型 ⟺ Σ 的每个势严格小于 κ 的子集都有模型。

（不带势限制的版本叫紧致性定理；ℒ_{ω,ω} 的哥德尔紧致性定理是 κ=ω 的情形。）显然的链条：ℒ_{κ,κ} 紧致 ⇒ ℒ_{κ,ω} 紧致；弱紧致性同理。反方向不平凡——这正是定理 2.15 的内容。

## 88.7 定理 2.15：弱紧 = ℒ_{κ,κ} 弱紧致

**定理 2.15。** (1) κ 是弱紧基数 ⟹ ℒ_{κ,κ} 具备弱紧致性定理。(2) κ 不可达且 ℒ_{κ,ω} 具备弱紧致性定理 ⟹ κ 是弱紧基数。

**证明 (1)。** 设 Σ 是 ℒ_{κ,κ} 的势 κ 的语句集，每个 < κ 子集可满足。不妨语言本身势 κ（只保留 Σ 中出现的符号）。

*斯科伦化。* 迭代 ω 轮：每轮对当前语言中每个含自由变元块 ⟨v_ξ | ξ<α⟩ 的表达式 φ 引入新常元 ⟨c_ξ | ξ<α⟩，并加入斯科伦语句 ∃⟨v_ξ⟩φ → φ(c_ξ)。κ 不可达保证每轮新增符号 < κ（或恰 κ）、ω 轮后语言 ℒ* 的势仍为 κ，且任何表达式需要的见证常元都已备齐。令 Σ* 为 Σ 加全体斯科伦语句。Σ* 的任何势 < κ 子集仍可满足：取它的模型，再逐轮解释新常元实现斯科伦前件。

*二元树。* 枚举 ℒ* 语句 ⟨σ_α | α<κ⟩。令 t ∈ T（t: β → 2，β<κ）当且仅当存在模型 M 使对一切 α<β：t(α)=1 ⟺ M ⊨ σ_α。T 是高 κ 的二元分叉树；每一层 β 的节点数 ≤ 2^{|β|} < κ（κ 强不可达）。κ 弱紧 ⇒ 树特性 ⇒ T 有长度 κ 的树枝 b。令

Δ = {σ_α | ∃t∈b (t(α)=1)}。

树枝上的赋值彼此相容，Σ* ⊆ Δ，且 Δ 对每条 ℒ* 语句恰好做一个真假判定（完备、无矛盾、含全部斯科伦见证）。

*项模型。* 令 A₀ 为 ℒ* 所有常元项的集合，定义 τ₁ ~ τ₂ ⟺ (τ₁=τ₂) ∈ Δ，商集 A = A₀/~；常元 c 解释为 [c]，谓词 P 解释为 ([τ₁],…,[τ_n]) ∈ P^M ⟺ P(τ₁,…,τ_n) ∈ Δ，函数符号同理用等式句定义。对语句中量词块的个数归纳可证

(A,…) ⊨ φ ⟺ φ ∈ Δ。

关键步正是斯科伦句：存在量词块为真时，相应见证常元已在 A₀ 里。于是 A ⊨ Σ* ⊇ Σ。∎

**证明 (2)。** 只需从 ℒ_{κ,ω} 的弱紧致性推出 κ 的树特性。设 (T,<_T) 是高 κ、每层势 < κ 的树。造语言：一个表示树序的二元谓词 P；每个节点 t ∈ T 一个常元 c_t；一个一元谓词 B（标记选中的树枝）。语句集 Σ 收录四类句子：

- 节点可比的实情：s <_T t 时收 P(c_s,c_t)，否则收 ¬P(c_s,c_t)；
- 树枝反链条件：s、t 不可比时收 ¬(B(c_s) ∧ B(c_t))；
- 每层必选：对第 α 层 U_α 收 ⋁_{u∈U_α} B(c_u)（该层节点 < κ 个，析取合法）。

Σ 的任何势 < κ 子集只涉及 < κ 个高度，取 T 的一个足够高的前段，选一根到该高度的树枝解释 B，即为模型。由弱紧致性，Σ 有整体模型；B 在其中解释的节点集沿 P 可比、每层取一个，给出 T 的一根长度 κ 树枝。κ 不可达 + 树特性，由第一卷定理 I.2.55 即得 κ 弱紧。∎

机器通道里这组思想的有限骨架是 88.5 的柯尼希贪心树枝（树特性 ω 形态）加上第 87 章的公式枚举（斯科伦项落进 V_ω 的位配对编码）；完整的 κ 树构造与项模型归纳是讲义内容，Isabelle 理论 `ST88/LComb.thy` 的讲义锚点段逐条登记了定理 2.15 与 2.16 的出处与论证步骤。

## 88.8 定理 2.16：弱紧基数在 L 中保持

**定理 2.16。** 设 κ 是弱紧基数。则：

1. 对任何 U ⊆ V_κ，结构 (V_κ,∈,U) 有传递的初等扩张 (M,∈,U')，κ ∈ M；
2. 若 A ⊆ κ 且每个初始段 A∩α 都可构造（∀α<κ (A∩α ∈ L)），则 A ∈ L；
3. κ 在 L 中仍是弱紧基数。

**证明 (1)。** 考虑带谓词 U 且带 V_κ 中每个元素为常元的结构 𝔄 = (V_κ,∈,U,a)_{a∈V_κ}。令 Σ₀ 为 𝔄 中为真的全体 ℒ_{κ,κ} 语句；再加一个新常元 c 和句子 c ∈ Ord 以及 c > α（对每个 α<κ）。Σ 的势为 κ。任何非空 S ∈ [Σ]^{<κ} 可满足：令 F 为 S 中出现的常元所指元素（c 除外），γ = sup(F∩κ)+ω < κ，在 (V_κ,∈,U,a)_{a∈F} 中把 c 解释成 γ 即可。

由定理 2.15(1)，Σ 可满足，取模型 (A,E,U²,c,a)_{a∈V_κ}，不妨设 V_κ ⊆ A、E 与 ∈ 在 V_κ 上一致、U²∩V_κ = U、每个 a 的常元解释就是 a，于是 (V_κ,∈,U) ≺ (A,E,U²)。

E 在 A 上**自同一**：外延公理是 Σ₀ 中的语句，模型也满足同一律。E 在 A 上**有秩**：句子「不存在 ⟨u_n:n<ω⟩ 使 u_{n+1} ∈ u_n 对所有 n 成立」（用 ℒ_{κ,κ} 的无穷合取写成一个语句）在 (V_κ,∈) 为真，故模型中没有 E-下降链。由第一卷传递化定理，(A,E) 同构于传递结构 (M,∈)；令 U' = π[U²]、κ̄ = π(c)。则 V_κ ⊆ M、U'∩V_κ = U、κ ≤ κ̄，故 κ ∈ M，且 (V_κ,∈,U) ≺ (M,∈,U')。∎

**证明 (2)。** 对 U = A 应用 (1)：(V_κ,∈,A) ≺ (M,∈,A')，M 传递、κ ∈ M。考虑语句「对每个序数 α 存在 a ∈ L 使 a = A∩α」。它在 (V_κ,∈,A) 中为真（假设：所有 α<κ 的初始段可构造）。由初等性在 M 中为真；取 α = κ（κ 在 M 中是序数），存在 a ∈ L^M 使 a = A'∩κ。L 对内模型绝对（第 87 章定理 2.7），L^M = L；又 A ⊆ κ ⊆ V_κ，A'∩V_κ = A，故 A'∩κ = A。于是 A ∈ L。∎

**证明 (3)。** 在 L 中设 T = (κ,<_T) 是高 κ、每层势 < κ 的树。T 作为集合在 V 中仍是同样的树（传递内层模型）。κ 在 V 中弱紧，树特性给一根长度 κ 的树枝 b。对每个 α<κ，初始段 b∩α 是 T↾α 的一根树枝：T↾α ∈ L 且其势 < κ；可证明 b∩α ∈ L（< κ 大小的树枝对象在 L_{κ⁺} 中——这是 L 的基数算术：|L_{λ}| = |λ|，λ<κ 的层次足够装下它）。由 (2)，把 b 编码成 κ 的子集，b ∈ L。于是在 L 内部 T 也有 κ-树枝：树特性在 L 中成立。κ 在 L 中仍不可达（正则性与强极限对传递内模型向下保持：L 中的共尾映射也是 V 中的共尾映射；L 中 λ<κ 的子集总数 ≤ |L_{κ}| = κ，更精确地 𝒫^L(λ) ⊆ L_{λ⁺} 而 λ⁺<κ），由定理 I.2.55，κ 在 L 中弱紧。∎

这给出大基数与内模型相容的第一个模板：**在 V 中取树（或划分、扩张）→ 得到见证 b → 证明每个有界初始段已在 L 中 → 用 (2) 把完整见证收回 L**。第 89 章的相对可构造模型 L[U] 将把同一模板用于可测基数。

## 88.10 这一章留下了什么

L 的组合刚性来自同一个动作的三次重复：按 <_L 选最小反例，用可数同质子模型把它截断，凝聚化把截断模型塌成某个 L_β，而递归构造早已在截断层等着它——苏斯林树（定理 2.12）与钻石原理（定理 2.14）都是这个模式的产物。◇ 把「每层一个猜测、对每个 X 荟萃多次命中」公理化，它强到蕴含 CH 与苏斯林树存在；机器通道把它的调度内核（v₂ 时刻表）与封口内核（前缀传递归纳）剥出来反复验证。

弱紧基数这一面，无穷语言 ℒ_{κ,κ} 的弱紧致性与树特性、划分性质等价（定理 2.15）；斯科伦化 + 二元树 + 项模型是哥德尔紧致性证明在不可达基数上的忠实放大。定理 2.16 证明弱紧性可以被 L 接纳：传递初等扩张 (1) 是工具，「初始段全可构造则整体可构造」(2) 是把见证收回 L 的钥匙，树特性在 L 中保持 (3) 是结论。下一章离开 L 本身，进入带着外部信息的内模型：相对可构造集 L[U]、序数可定义内模型 HOD，以及包含全体实数的 L(ℝ)。
