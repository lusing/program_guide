# 22 · Suslin 问题与 Suslin 树

> Suslin 问题问：把"可分"换成"ccc"，实线的特征序还唯一吗？
> ——答案是独立的——Suslin 线既不能被证明存在，也不能被
> 证明不存在。——独立性的又一座丰碑

本章覆盖 Jech §22：树的基本概念、Suslin 树与 Suslin 线的
等价、Aronszajn 树（ZFC 中存在）、Tennenbaum-Jech 定理
（Suslin 树的一致性）、Δ-系统引理。

## 22.1 树与层级

**树** T：偏序集使每个 x 的前驱集 {y : y < x} 良序。
**第 α 层** = {x : ot(x) = α}；**height**(T) = sup{ot(x)+1}。
**分支** = 极大链（的序型）；**反链** = 两两不可比集。

## 22.2 Suslin 树与 Suslin 线

**Suslin 树** (22.2)：(i) height = ω₁；(ii) 每个分支可数；
(iii) 每个反链可数。

**引理 22.1** Suslin 线 ⟺ Suslin 树。

*证明*：(a) Suslin 线 S → 区间树：S 的闭区间的逆包含序。
ccc → 反链可数；无不可数分支 → 区间套的端点递增但 ccc
限制。逆：(b) Suslin 树 T → 分支空间：将每个节点的直接
后继排成有理数，分支按字典序排列——稠密 ccc 不可分。∎

**Suslin 代数**：B = r.o.(T^op)——ccc + 无原子 + σ-分配
（引理 22.2）的完备布尔代数。

## 22.3 Aronszajn 树

**Aronszajn 树**：height = ω₁ + 每层可数 + 无不可数分支
（比 Suslin 弱——去掉反链条件）。

**引理 22.3** Aronszajn 树在 **ZFC 中存在**。

*构造*：节点 = **有界递增有理数序列**。层的构造对 α 归纳：
后继层取延伸；极限层用 (22.4) 的**覆盖条件**（每个节点可被
延伸到上方任意有理上确界）——由有理数的可数性保证层可数。
无不可数分支因为 R 的递增序列有可数 cofinal。∎

Julia（`examples/julia/22_suslin.jl`）验证有理数递增序列
的增长形态；Python（`22_suslin.py`）给出序列样本与层结构。

## 22.4 Tennenbaum-Jech 定理

**定理 48** Con(ZFC) ⟹ Con(ZFC + Suslin 树存在)。

*力迫构造*：条件 = 可数正规树 T（(22.6) 的形态），序 = 真
扩张。G 泛型 ⟹ 𝔗 = ⋃G 是正规 ω₁-树。

- P 是 σ-闭的（可数链的并是条件）⟹ ω₁ 保持；
- 层的稠密性：{T : height(T) ≥ α} 稠密（对 α 归纳）；
- **反链可数**（核心步骤）：对极大反链 A，构造条件 T' 使
  A 的某子集 A' 在 T' 中有界且极大（引理 22.4-22.5 的
  "杀反链"论证）→ 𝔗 中的极大反链全部有界 → 可数。∎

## 22.5 Δ-系统引理

**引理 22.6** 不可数族 → 不可数子族使任意两元的交相同。

Δ-系统（combinatorists 的称呼）是 ccc 验证的标准工具——
第 24 章（组合问题）将系统使用。Python 演示有限 Δ-系统。

## 22.6 独立性的完整图景

Suslin 假设（SH = "无 Suslin 线"）的独立性：
- Tennenbaum-Jech 1968：Con(ZFC) ⟹ Con(ZFC + Suslin 树)；
- Jensen 1972：Con(ZFC) ⟹ Con(ZFC + V=L ⟹ ◊ ⟹ SH)。

SH 独立于 ZFC——与 CH 的独立性并列为力迫方法最深刻的应用。
