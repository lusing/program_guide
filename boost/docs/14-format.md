# 14 · 格式化：Boost.Format 的谢幕

> 对应示例：`examples/14_format/format.cpp`

Boost.Format（2002，Samuel Krembl 之外最广为引用的 Boost 库之一）解决的是 printf 的两大病：**不类型安全**（`%s` 传 int 是 UB）和**不可本地化**（翻译后的句子语序会变）。它的解法是流式喂参 + 位置占位符：

```cpp
boost::format("学生 %1% 得分 %2%") % name % score
boost::format("%1% %2% %1%") % "回声" % 7            // 占位符可复用
boost::format("[%8.3f] [%-8s]") % 3.14159 % "左"     // printf 规格也认
boost::format tmpl("x=%1%; y=%2%");                  // 格式对象可复用
```

运行输出（`format.cpp`）：

```text
学生 ada 得分 95
回声 7 回声
[   3.142] [左     ]
x=1; y=2
x=10; y=20
多喂参数被抓住: boost::too_m...
学生 ada 得分 95
[   3.142] [左      ]
[00062] [2.236   ] [ 123456789] [00030]
[first][first]（str 可重复取）[second]
1 × 7 = 7  2 × 7 = 14  3 × 7 = 21  解绑后需 3 参
[****ff] [右对齐十六进制]
[    42] [00003.14]
自检通过
```

与 printf 的关键差异（例程逐条实证）：参数多喂**抛异常**而不是 UB；格式串是对象，可以留空复用；`%1%` 位置占位符天生支持本地化语序。

## 14.x 深讲：语法变体与两件高级工具（书 5.2 全套）

**语法三套**（可混用）：printf 式 `%05d`（老代码无缝迁移）；竖线式 `%|05d|`（规格与普通字符分界更清楚，`%| 10s|` 里那个前导空格一目了然）；位置式 `%N%`（纯占位不带规格）。

**对象的复用合同**：`str()` 取结果**不清缓存**（可重复取同一结果）；`clear()` 只清"已喂的参数"（格式和绑定都保留）；`parse(新格式串)` 才是换格式重头再来。喂参必须恰好等于占位符数，多喂少喂都在 `str()` 时抛异常。

**bind_arg / clear_bind**：把第 N 位参数**固定**住——之后连 `clear()` 都不丢，循环里只喂剩下的位置（输出里的乘法表就是这么打的：第 2 位恒绑 7，循环只喂第 1、3 位）。`clear_bind(N)` 或 `clear_binds()` 解绑。

**modify_item + io::group**：运行期改**第 N 个格式位**的规格。`boost::io::group(hex, right, setw(6), setfill('*'))` 把一组 `<iomanip>` 操纵符打包塞给第 1 个占位符——输出里 `[****ff]` 就是 255 被改成 6 宽右对齐星号填充的十六进制。

**性能件**：反复使用同一格式时，先建 `const format` 模板、每次 `format(tmpl)` 拷贝再喂参——拷贝比从字符串重新解析快（书里的实测建议；std::format 时代这招已经用不上了，但老代码里常见）。

## 14.1 毕业档案：平行进化，不是直系

这里要澄清一个广泛流传的误会：**`std::format`（C++20）不是从 Boost.Format 毕业的**——它来自 Victor Zverovich 的 fmt 库（`{}` 语法、编译期解析、性能远超流式方案）。fmt 进标准（P0645）客观上终结了 Boost.Format 的历史使命，但这是"平行进化淘汰"，不是"直系毕业"：

| | Boost.Format（2002） | std::format（C++20，fmt 血统） |
|---|---|---|
| 占位符 | `%1%` / printf 规格 | `{}` / `{:8.3f}` |
| 类型安全 | 运行期检查（异常） | **编译期检查** |
| 性能 | 慢（流式拼接） | 快（编译期格式串） |
| 本地化语序 | 位置占位符 | 位置参数 `{0} {1}` |
| C++ 档位要求 | C++03 | C++20 |

```cpp
std::format("学生 {} 得分 {}\n", name, score);          // C++20
std::print("学生 {} 得分 {}\n", name, score);           // C++23 连 << 都省了
```

**2026 选型**：C++20 起一律 `std::format`/`std::print`；C++17 及以下的项目里，Boost.Format 仍是类型安全的正解（fmt 也行，但那是第三方依赖的取舍）。boost 版仅维护老代码时出现。
