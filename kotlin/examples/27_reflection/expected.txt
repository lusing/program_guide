== 27.1 声明注解 ==
注解实例字段直接访问: id=add, shouldPass=true
参数类型白名单: 基本类型/String/枚举/KClass/注解/数组；可空或自定义类直接编译不过
== 27.2 元注解四件套 ==
Route 上的元注解: [MustBeDocumented, Retention, Target]
允许位置: FUNCTION, CLASS
保留策略: RUNTIME（Kotlin 默认，Java 默认 CLASS——跨语言最常踩差异）
== 27.3 使用处目标 ==
字段 id   上看到: []
字段 score上看到: [幕后字段]
getter level: [getter]
getter id  看到: []（getter 没挂）
构造参数注解(按参数序): [[构造参数], [], [], [裸写]]
结论: @field: 挂字段、@get: 挂 getter、裸写落构造参数——库不生效先查挂点
== 27.4 ::class 与可调用引用 ==
KClass=String, 往返=String, javaClass=String
::isOdd 当值传: [1, 3]
函数引用即反射对象: name=isOdd, params=[x], 返回=kotlin.Boolean
绑定引用锁接收者: KOT（类型 () -> String，非 (String) -> String）
构造器引用: P(x=3, y=4)
属性引用可读可写: ::counter.get()=42
== 27.5 反射 API ==
declaredFunctions: [greet, twice]
primaryConstructor 调用造对象: P(x=1, y=2)
反射调用 call: 42, javaMethod.invoke: 42
== 27.6 泛型反射 ==
Box 形参: name=T, variance=INVARIANT, isReified=false, upperBounds=[kotlin.Comparable<T>]
StringList 继承链找回实参: kotlin.collections.ArrayList<kotlin.String> /* = java.util.ArrayList<kotlin.String> */ -> kotlin.String
原理: 直接 Box<String>::class 拿不回 String（擦除），匿名子类把实参刻进父类签名
