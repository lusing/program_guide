# 15 · 格式化输出：FORMAT、$...$ 与 printf

> 示例：[`examples/15_formats/15_formats.a68`](../examples/15_formats/15_formats.a68)
> 运行：`./run-all.sh 15`

第 14 章的 `print`/`put` 是"简单输出"：把值的字符表示直接吐出去，版式全靠
`whole`/`fixed` 手工拼。本章讲 Algol 68 真正的强项——**FORMAT**。它把版式写成
一段独立的"格式文本"（`$...$` 之间的图形串），与数据分离，可以命名、复用、
写文件，是报表级输出的语言级设施。本章还有全教程最阴的一个坑：**相邻整数图形
不加逗号分隔符会错绑**（§6），务必看完。

## 1. print/put 是简单输出，printf/putf 才吃 FORMAT

```algol68
  # print(x)  ≡ put(stand out, x)      —— 直接吐值的字符表示 #
  # printf(z) ≡ putf(stand out, z)     —— z 是 (FORMAT, 值...) 的行列 #
  print(("简单输出：", whole(42, 0), " ", fixed(3.5, 4, 2), new line));
  printf(($"格式化：整数=" 3d , " 实数=" zz.zz l$, 42, 3.5));
```

- **FORMAT** 的正文写在两个 `$` 之间，由三种东西组成：**图形（picture）**——
  如 `3d`、`zz.zz`、`8a`，规定下一个值怎么排版；**字面量**——`"..."` 原样输出；
  **分隔符**——如逗号 `,`、`l`（换行），控制结构、本身不输出字符。
- 两行代码的实测输出对照：

  ```text
  简单输出：42 +3.5
  格式化：整数=042 实数= 3.50
  ```

  `3d` 把 42 补零成 `042`；`zz.zz` 把 3.5 排成右对齐的 `" 3.50"`。

## 2. 关键调用形：printf(($fmt$, 值1, 值2, ...))——双层括号

```algol68
  printf(($"+5d -> [" +5d "]" l$, 42));
```

外层括号是**调用括号**，内层是**行列（row-display）**：`($格式$, 值...)` 整个作为
printf 的**单一实参**。这不是风格问题，是硬语法——实测少写内层括号：

```algol68
  printf($"x=" 3d l$, 42)        # 错 #
```

```text
a68g: error: 1: incorrect number of arguments for PROC ([] "SIMPLOUT") VOID, ...
```

编译期直接拒绝（退出码 1）。肌肉记忆：**printf 永远双括号**。（`$` 后多一个空格
写成 `$ "x=" 3d l$` 倒是无妨，实测正常。）

## 3. 整数图形：Nd 零填充、+Nd/-Nd 符号、z 零抑制

```algol68
  printf(($"3d  -> [" 3d "]" l$, 7));            # 007（补足 3 位） #
  printf(($"5d  -> [" 5d "]" l$, 42));           # 00042 #
  printf(($"+5d -> [" +5d "]" l$, 42));           # +00042（强制显号） #
  printf(($"-5d -> [" -5d , "] / [" -5d , "]" l$, 42, -42));  # 负才显号 #
  printf(($"zzzz-> [" zzzz "]" l$, 42));          # 零抑制："  42" #
```

实测输出逐行对照：

| 图形 | 值 | 输出 | 规则 |
|---|---|---|---|
| `3d` | 7 | `007` | N 位，前导零填充 |
| `5d` | 42 | `00042` | 同上 |
| `+5d` | 42 | `+00042` | 强制带符号：正数也打 `+`，数字仍补足 5 位 |
| `-5d` | 42 / -42 | ` 00042` / `-00042` | 只有负数显号，正号位打**空格** |
| `zzzz` | 42 | `"  42"` | z = 零抑制：前导零变空格 |

## 4. 实数图形：g 通用、zz.zzz 定点、d.ddde sdd 科学计数

```algol68
  printf(($"g(0)   -> [" g(0) "]" l$, 2.5));               # 通用，0=精度参数 #
  printf(($"zz.zzz -> [" zz.zzz "]" l$, 3.14159));         # 定点 3 位小数 #
  printf(($"d.ddde sdd -> [" d.ddde sdd "]" l$, 2718.28)); # 科学计数 #
```

实测输出：

```text
g(0)   -> [3]
zz.zzz -> [ 3.142]
d.ddde sdd -> [2.718e3]
```

- `g(0)`：通用图形，括号里是精度参数；实测精度 0 时 2.5 被舍入输出成 `3`——
  精度给 0 就真按最低精度来，别拿它做常规显示。
- `zz.zzz`：定点，小数点位置由 `.` 钉死，3 位小数四舍五入（3.14159 → `3.142`），
  整宽不足用空格右对齐（输出 `" 3.142"`）。
- `d.ddde sdd`：科学计数图形，`e` 是字面量、`sdd` 是指数位；实测 2718.28 输出
  `2.718e3`——**正指数没有 `+` 号**，与源码注释里设想的 `e+3` 不同，以实测为准。

## 5. 字符串图形：Na 要求"恰好 N 字符"

```algol68
  STRING code := "ABC";
  printf(($"3a -> [" 3a "]" l$, code));          # code 恰好 3 字符 → OK #
  printf(($"字面量 4a -> [" 4a "]" l$, "wxyz"));  # 字面量恰好 4 → OK #
```

`a` 图形是**定宽列**，不是"最多 N"也不是"至少 N"：被输出的字符串长度必须
**正好等于 N**，多一位少一位都是运行期错误。实测 `3a` 配两字符的 `"AB"`：

```text
a68g: runtime error: 1: error transputting [] CHAR value, ...
```

退出码 1，程序中止。所以源码注释的纪律是：**一般变长字符串输出直接用
print/put**（自动处理任意长度），FORMAT 的 `a` 只适合"字段本来就定宽"的场合
——比如 §7 的报表把名称字段统一补齐到 8 字符再用 `8a`。

## 6. ★ 最重要的坑：相邻整数图形必须用逗号分隔符，否则错绑 ★

先看源码注释记录的实测事故现场：格式写成
`$"a=" 3d " b=" 3d l$`（两个 `3d` 之间只有字面量，没有逗号），配值 `(999, 888)`，
你期待 `a=999 b=888`，实际打出的是——

```text
a=000 b=999
a=000 b=888
```

两件事同时发生：**只有最后一个整数图形绑到了值，前面的图形全得 0**；而且
**整个格式按值的个数重复输出**。正解是在图形之间加**逗号分隔符** `,`——
它是分隔符，本身不输出任何字符：

```algol68
  printf(($"正确：a=" 3d , " b=" 3d l$, 999, 888));   # a=999 b=888 ✓ #
  printf(($"三列：" 2d , 3d , 4d l$, 1, 22, 333));    # 010220333 ✓ #
```

实测输出：

```text
正确：a=999 b=888
三列：010220333
```

第二行还顺带印证"逗号不输出字符"：`01`、`022`、`0333` 三段紧贴在一起。

源码注释给出的记忆点：REAL 图形（g/f 系）多个并列时不加逗号也能绑对，
但**整数 d 图形必须加逗号**。与其分情况背规则，不如统一纪律：
**格式文本里相邻图形一律用 `,` 分隔，最稳。** 本章示例所有 FORMAT 都遵守这条。

## 7. 具名 FORMAT：声明一次，反复套用

FORMAT 可以声明成命名常量，报表每行套同一版式：

```algol68
  # Na 要求字符串恰好 N 字符，故名称字段统一补齐到 8 字符。 #
  # 各图形间用逗号分隔符（,）——整数图形相邻时这是硬纪律（见 15.5）。 #
  FORMAT row fmt := $"|" -4d , "|" 8a , "|" zz.zzz , "|" l$;
  printf((row fmt, 1, "widget  ", 9.5));
  printf((row fmt, 2, "gizmo   ", 12.25));
  printf((row fmt, -3, "doohic  ", 0.125));
```

实测输出：

```text
| 0001|widget  | 9.500|
| 0002|gizmo   |12.250|
|-0003|doohic  |  .125|
```

- `-4d`：正数首位是空格（`" 0001"`），负数显 `-`（`"-0003"`）——列对齐不跳位。
- `8a`：`"widget  "` 恰好 8 字符（补齐的尾随空格顶满列宽）。
- `zz.zzz` 配 0.125 输出 `"  .125"`：**z 把小数点前的前导 0 也抑制掉了**，
  只剩 `.125`——定宽报表里这是特性（列宽恒定），但初次见到会愣一下。
- 格式自带 `l`（换行），所以每次 printf 一行，不用再手动加 new line。

## 8. 用 FORMAT 写文件：putf(FILE, (格式, 值...))

printf/putf 的关系与 print/put 完全平行：`putf(文件, ($格式$, 值...))`。
示例生成一份库存报表再逐行读回核对：

```algol68
  STRING fname := "15_report.txt";
  FILE outf;
  INT rc := establish(outf, fname, stand out channel);
  put(outf, ("== 库存报表 ==", new line));         # 表头用简单输出即可 #
  FORMAT line fmt := $2d , " " 8a , " " zz.zz l$;  # 数据行用格式 #
  putf(outf, (line fmt, 1, "widget  ", 9.50));
  putf(outf, (line fmt, 2, "gizmo   ", 12.25));
  close(outf);
```

读回部分复用第 14 章的 on logical file end 惯用法，实测打印出报表内容并断言
共 3 行（1 表头 + 2 数据）：

```text
  == 库存报表 ==
  01 widget    9.50
  02 gizmo    12.25
报表行数 = 3
```

（每行行首的两个空格是读回代码 `print(("  ", buf, new line))` 加的缩进，
不是文件内容。）

## 9. whole/fixed 的符号位与填充：为什么断言长这样

示例最后把两个"手工排版"函数的行为钉死成断言（源码注释 + 断言均为实测）：

```algol68
  # 实测坑：whole/fixed 都会带【符号】且用空格（不是 0）补齐到指定宽度： #
  #   fixed(3.14159, 6, 3) = "+3.142"（6 宽，3 位小数，四舍五入，前导 +） #
  #   whole(42, 5)         = "  +42" （5 宽，右对齐，前导 +，空格填充） #
  assert(fixed(3.14159, 6, 3) = "+3.142", "fixed 定点：带符号、四舍五入到 3 位");
  assert(whole(42, 5) = "  +42", "whole 定宽：带符号、空格右对齐");
```

- **whole/fixed 永远带符号位**：正数是 `+`，填充用**空格**不用零。
  想要 `007` 这种零填充或无符号输出，用 FORMAT 的 `Nd`/`z` 图形（§3），
  别指望 whole。
- 宽度 0（如 `whole(42, 0)`、`whole(nlines, 0)`）表示最小宽度，此时正数
  **不带** `+`——第 14 章输出里的 `行3: <42>` 就是它。
- 宽度紧张时 fixed 会牺牲小数位保住符号：本章第 1 行输出 `fixed(3.5, 4, 2)`
  实测为 `"+3.5"`（`+3.50` 要 5 字符，宽 4 装不下，末位小数被舍掉）。
  整数部分都装不下时才整段打星号（第 14 章 §2 实测 `******`）。

## 11. 坑位清单（实测）

1. **相邻整数图形不加逗号 → 错绑 + 格式重复**：`$"a=" 3d " b=" 3d l$` 配
   `(999,888)` 打出 `a=000 b=999` 再 `a=000 b=888`——只有最后一个 d 图形绑到值，
   且整个格式按值个数重复。图形之间一律加 `,`（§6，本章头号大坑）。
2. **printf 必须双层括号**：`printf($...$, v)` 报
   `incorrect number of arguments for PROC ([] "SIMPLOUT") VOID`；
   实参必须是 `($格式$, 值...)` 这一个行列（§2）。
3. **Na 要求精确宽度**：`3a` 配 `"AB"` 运行期报
   `error transputting [] CHAR value`，退出码 1。变长字符串用 print/put（§5）。
4. **g(0) 精度极低**：2.5 输出 `3`。常规实数显示用 zz.zzz 之类的定点图形（§4）。
5. **科学计数正指数无 `+`**：实测 `2.718e3`，不是 `2.718e+3`（§4）。
6. **z 会抑制小数点前的前导 0**：0.125 打成 `.125`——列宽保住了，样子要习惯（§7）。
7. **-Nd 正数带前导空格**：符号位永远占一格，对齐时把它算进列宽（§3）。
8. **whole/fixed 带符号、空格填充**：`whole(42,5)="  +42"`、
   `fixed(3.14159,6,3)="+3.142"`；要零填充用 FORMAT 的 Nd（§9）。
9. **宽度不足时 fixed 先舍小数、再打星号**：`fixed(3.5,4,2)="+3.5"`（舍小数位），
   整数都放不下才 `******`（§9、第 14 章）。
