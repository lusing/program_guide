### 新 09 章 Pratt 分析（docs/09-pratt-parsing.md + examples/09_pratt_parsing）

取材 §6.3（jlox 中缀分发表）+§17.5（clox 的 C 版 Pratt）。内容：递归下降每层优先级一个函数的重复之痛 → 一张 (precedence, infix 回调) 表推广成 Pratt 循环；`parseExpression(precedence)` 双递归（先 prefix 回调，再按表内 infix 回调滚）；结合性由递归层级控制——左结合用同级递归、右结合用 prec+1；前缀/中缀/后缀（括号、一元负号、调用、字段访问）三类回调；与 06 章 LL(1) 分层法（每层手写函数）、07/08 章 LR 家族（表由构造器算出）三方对比——Pratt 是「手写优先级表、递归即文法」的第三条路；匠书陷阱反例（`-a.b`、`a^b^c` 右结合、`2+3*4` 层级）。示例：手写 Pratt 解析 TIP 表达式子集（算术/比较/一元/调用/解引用），产出 AST 并求值；右结合教学用幂运算符 `^`（TIP 无幂，明确标注为教学扩展）。
断言：(1) 表达式语料 Pratt 求值与期望值全等；(2) 以 06 章示例文法为交集对齐共同语料，Pratt 与 06 章 LL(1) 分析器求值一致，`^` 等超出交集者走独立期望值；(3) 右结合运算符结合方向正确（`(a^b)^c ≠ a^(b^c)` 反例裁决）；(4) 优先级错误的构造在修正前后求值不同。**无 ANTLR**（纯算法章）。

### 新 13 章 树遍历解释器与环境链（docs/13-tree-walk-interp.md + examples/13_tree_walk_interp）

取材 §7–§10 精要 +§11 语义陷阱。内容：无 IR 的第三条执行路——直接在 AST 上求值（Visitor 协议，10 章铺垫的消费者）；**Environment 链**：每个作用域一条 map + parent 指针，取值沿链查找、赋值沿链写回（与 12 章静态绑定互补：静态管「指谁」、环境管「值在哪」）；块作用域进出即建/弃节点；**闭包 = 函数体 + 定义时环境指针**（捕获即共享，可变状态经链回流）；return 用非局部退出实现（C++ 异常或结果参数，两案对比）；原生函数（clock 类）注册在全局环境；§11 四陷阱蒸馏为「求值前的静态检查」：(a) 声明前读自己的初始化器（`var a = a;`）必须抓到——环境先定义后初始化的窗口，(b) 块级遮蔽合法但同名同层重复非法，(c) 函数名与变量声明的绑定次序（名字在不同时刻指向不同实体），(d) return 只在函数体内合法。示例：复用 12 章（原 11）TIP AST+ANTLR 前端与 Resolver（本地副本），加 Interpreter 与 Environment 链。
断言：(1) 闭包计数器/递归/遮蔽/前向引用语料输出与期望全等；(2) 同一语料 LLVM JIT（若适用子集）对账或手算期望对账；(3) 四陷阱各一条违规程序被静态检查拒绝且诊断行号正确；(4) 赋值沿链写回——外层变量被内层闭包修改后外层读到新值。**需 ANTLR**（复用 12 章文法副本）。

### 新 54 章 字节码与栈式虚拟机（docs/54-bytecode-vm.md + examples/54_bytecode_vm）

取材 §14（chunk/常量池/行号）、§15（VM 大循环/栈求值/反汇编）、§24（CallFrame/调用栈/原生函数），值起步用 §18 带标签联合。内容：树遍历的性能天花板（每节点一次虚分派）；**chunk**：操作码+操作数字节流、常量池去重、行号表（运行期错误定位）；**反汇编**即文档——每条指令 human-readable 回读；**FETCH–DECODE–EXECUTE** 大循环；栈式求值：`OP_ADD` 弹二压一，后缀序即求值序（与 16 章 TAC 寄存器机对照：栈机无寄存器名、隐式操作数栈）；比较/取反/打印；**CallFrame**：ip/frame 指针对、帧布局（slots 起点即帧基）、调用序列（callee 帧 push→运行→pop 恢复 caller 现场）；栈溢出保护；原生函数走 C++ 直调旁路。示例：手写 chunk + VM，先手编字节码跑表达式，再加函数调用（由 55 章编译器生成的字节码也在此 VM 上跑）。
断言：(1) 手编字节码求值与期望全等；(2) 反汇编文本与手工反汇编逐行一致；(3) 递归阶乘/斐波那契调用栈深度正确（帧数=递归深度）；(4) 栈空断言在每条指令边界保持（指令后栈深符合手推）。**无 ANTLR**。

### 新 55 章 单遍编译与跳转回填（docs/55-single-pass.md + examples/55_single_pass）

取材 §16（即取即用扫描器）、§17（Pratt 直接发码）、§21（全局变量迟绑定）、§22（局部变量编译期槽位）、§23（跳转与回填）。内容：**无 AST**——扫描、语法、发码在一次遍历里完成（与 09–12 章多遍流水线对照：内存省、错误恢复弱、优化无门）；即取即用扫描器协议（advance/peek/match，无 token 缓冲）；**Pratt 直接发码**：infix 回调 = 弹二压一的 opcode；常量池去重查找；**局部变量槽位编译期分配**——进块记深度、出块弹栈、名字查不到就新槽（= 12 章 Resolver 的编译版，静态信息直接变成帧布局）；遮蔽与「声明前读自己」在此天然消失（槽位未入表即查不到） vs 匠书还抓 forward-declared local 的「尚未初始化」窗口——两个语义口径如实对比；**全局变量迟绑定**：名字留到运行期查表（早绑定/迟绑定的代价光谱）；**跳转回填 backpatch**：`emitJump` 占位跳转、语句编译完 `patchJump` 回填地址（前向跳转在单遍里目标还不存在）；if/else、&&/|| 短路电路（跳转即短路）、while 循环（向后跳直接回填）。示例：TIP 子集（表达式/var/赋值/if/while/return/print/函数）单遍编译到 54 章 VM 的字节码（VM 本地副本），驱动程序跑三个以上程序。
断言：(1) 编译产物反汇编与手工推演一致；(2) 程序输出与期望全等；(3) 设计一批 13 章树遍历解释器与本章共同接受的 TIP 子集语料（print/算术/if/while/函数/闭包），两解释器输出全等；(4) 短路求值确实短路（右侧副作用计数为 0）；(5) 嵌套块同名遮蔽槽位回收后总数正确。**无 ANTLR**。

### 新 56 章 值表示：NaN 装箱、驻留与散列表（docs/56-value-repr.md + examples/56_value_repr）

取材 §18（带标签联合）、§30.2–30.3（NaN 装箱：QNaN+tag 位、指针藏尾数位、`|1` 判布尔、值位往返）、§19（ObjString 与驻留）、§20（开放定址散列表：FNV-1a、线性探测、墓碑、装填因子、扩容三状态机）。内容：值宇宙决定一切运行时代价——带标签联合 16 字节（double 8 + tag 8 + padding）的浪费；**NaN 装箱**：IEEE 754 QNaN 的静默位模式留出 51 位空闲，tag 位分给 nil/true/false/obj，指针藏尾数位（51 位指针空间为什么够）；`(v & QNAN) != QNAN` 判数、`|1` 合并两布尔位型（宏二次求值陷阱）；随机 double 往返无损与指针往返；**字符串驻留**：值相等 → 同一指针 → `==` 退化为指针比较（互参 07 章常量去重思想在运行期重现）；**开放定址**：FNV-1a 位 avalanche、线性探测、删除为什么必须留墓碑（真删会截断探测链）、装填因子上限、扩容重散列把墓碑顺带清扫、扩容状态机（cap 翻倍序列）；与 std::unordered_map（链地址法）对照。示例：自带 Lox 风格值宇宙（number/bool/nil/ObjString——NaN 装箱需要 double，TIP 整数宇宙在此如实说明并展示 int64 直存对照）。
断言：(1) 随机 double/指针装箱往返逐位无损；(2) 布尔/nil 判定全对且无二次求值语义坑（副作用计数）；(3) 驻留后相等字符串指针相同；(4) 散列表：插入/查找/删除带墓碑后语义正确、扩容后墓碑清零、探测次数符合装填因子预期；(5) FNV-1a 已知测试向量对账。**无 ANTLR**。

### 新 57 章 上值：虚拟机里的闭包（docs/57-upvalues.md + examples/57_upvalues）

取材 §25。内容：13 章闭包 = 环境指针（整条链保留，捕获即共享）；54 章的值跑在栈上——**函数返回后帧就没了，逃逸闭包怎么读局部变量**；方案光谱：(a) 13 章整环境保留（最简单最浪费）、(b) 53 章（原 51）闭包转换装箱（编译期静态装箱单）、(c) **上值**：运行期按需捕获、单变量粒度搬家；**开放上值**：指进栈槽的 upvalue 链表（VM 全局持头指针，按栈地址排序插入）；捕获时先查链（同一变量两个闭包共享同一 upvalue）；**close**：栈收缩越过槽位时该 upvalue 关闭——把值搬进自己的堆盒子、指针改指盒子；已关闭的上值读写直通盒子；逃逸后多层嵌套捕获（上值链套上值）；与 19 章（原 17）访问链/display 的帧上方案对照（上值是「帧没了」世界的访问链）。示例：54 章 VM + 55 章编译器本地副本加 OP_GET_UPVALUE/OP_SET_UPVALUE/OP_CLOSE_UPVALUE 与捕获对象，跑闭包语料（计数器、加法器工厂、嵌套捕获、循环建多个闭包各捕各的）。
断言：(1) 闭包语料 VM 输出与 13 章树遍历解释器同语料全等；(2) 逃逸闭包在定义帧返回后读/写局部变量正确（计数器跨调用累加）；(3) 循环体建 N 个闭包各自捕获独立变量（匠书 §25.6 关键反例：共享 vs 各自）；(4) 开放上值在 close 后转为关闭（结构断言：链表节点状态）；(5) 同一变量被两个闭包捕获时共享同一 upvalue（一改俱改）。**无 ANTLR**。
