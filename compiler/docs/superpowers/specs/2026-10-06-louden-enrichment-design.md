内容：工具族谱（1975 lex/yacc → flex/bison → ANTLR 世代的表驱动 vs 递归下降分野；与 04 章 ANTLR、08 章 LALR 互参）→ **Lex 心脏**：规则表「正则→动作」、最长匹配、同长先声明优先（与 05 章 DFA scanner 同法）、yytext/行号；教学版迷你 Lex（规则定义文件 + DFA 引擎副本，吐 token 流）→ **Yacc 心脏**：LALR(1) 表复用 08 章构造器副本 + **值栈**——每状态一值槽、归约时 `$1..$n` 弹槽、`$$` 压槽、动作片段在归约时执行 → **任意值类型 %union**：值栈元素 = 带标签联合（数/串/树指针），%type 声明符号标签（与 59 章值表示的静态版呼应）→ **嵌入动作 = 空产生式改写**（`A → a {动作} b` ≡ `A → a N b; N → ε {动作}`），位置陷阱（嵌入动作后 `$n` 序号偏移）实测 → **优先级/结合性声明消冲突**：声明如何给 shift/reduce 投票（与 07 章 prefer-shift 对照）、悬空 else 在 yacc 下的缺省裁决 → error 记号预告（10 章主场）。
断言：(1) 迷你 lex+yacc 解析 TIP 表达式/语句子集并求值，输出与期望全等；(2) 同语料下 yacc 心脏与 08 章 LALR 分析器接受性逐句一致；(3) 嵌入动作展开改写前后求值结果与动作执行序一致（计数器证人）；(4) 优先级声明翻转实验（同文法声明前后归约序不同、结果可预期，一元负号/幂右结合语料）；(5) 最长匹配语料（`<=` vs `<`、`==` vs `=`）token 流正确。**无 ANTLR**（纯算法章）。

### 新 10 章 语法错误的恢复与校正（docs/10-error-recovery.md + examples/10_error_recovery）

取材 §4.5（递归下降与 LL(1) 的错误校正）、§5.7（自底向上：错误检测、应急方式、Yacc 错误校正、TINY 错误校正）、§3.3.2 相关（语法错误的性质）。

内容：**检测点理论**——错误首现点 vs 检测点；LL(1) 表项空才报（恰在错 token）；LR 任何可能动作集空即报，**LR 检测永不晚于、通常早于 LL**（栈上活前缀携带前文信息；§5.7.1 论断）→ **恐慌模式**：丢 token 至 FOLLOW 同步集；递归下降版（过程入口/出口同步集）、表驱动版；级联错误的抑制账（缺分号 → 3 个假错误 vs 恢复后 1 个）→ **短语级恢复**：查表做插入/删除/替换的局部修复；纯插入抖动 → 死循环风险与「不许连续两次纯插入」守卫 → **错误产生式与 yacc error 记号**：常见错误写进文法；归约到含 error 的产生式进入恢复态、丢到同步点、yyerrok 复位；**TINY 错误校正实例走读**（§4.5.3/§5.7.4）→ 诊断质量（报位置/期望集 vs 实际 token；最小编辑修复思想）。复用 06 章 LL 表驱动副本、08/09 章 LALR+yacc 心脏副本。
断言：(1) 同批错误语料下恐慌模式报错数 < 无恢复级联报错数（缺分号语料实测两版对照）；(2) LL 与 LR 对同一语料检测位置对照表（LR ≤ LL 的比例实测）；(3) error 产生式恢复后剩余合法语句仍被完整归约（AST 完整性证人）；(4) 插入守卫使抖动语料的恢复步数有界（构造 `((()` 类抖动反例）；(5) 恢复后无错部分仍可求值出结果。**无 ANTLR**。

### 新 22 章 参数传递的四种机制（docs/22-param-passing.md + examples/22_param_passing）

取材 §7.2（完全静态运行时环境）、§7.3.3（过程参数）、§7.5（值/引用/值结果/名字传递）、§1.5（参数传递对语言的影响）。

内容：开场 **完全静态运行时环境**——FORTRAN 世界：无递归 → 每过程一份静态帧、无栈；递归禁令的由来；「活动记录即全局变量」；与 21 章栈环境的自由对照 → 四机制总谱：**值传递**（参数 = 初始化的局部变量；`inc2(int x)` 反例；C 数组退化为指针的「假引用」）／**引用传递**（别名；FORTRAN 77 唯一机制；表达式实参 `p(2+3)` 编译器造临时格；Pascal `var`、C++ `&`、`const&` 大对象免拷贝）／**值结果传递**（copy-in copy-out；**`p(a,a)` 同一实参传两次：引用 → a=3，值结果 → a=2——别名是唯一分辨器**；Ada in/out；未指定问题：写回顺序、地址重算）／**名字传递**（延迟求值；thunk = 编译成无参过程；**Jensen 装置**：实参在每次使用处重求值）→ 编译器视角：每机制对调用序列/帧布局/访问代码的要求（值 = 直接拷贝；引用 = 帧存地址 + 间接访问；值结果 = 出口写回 + 被调者不能释放帧；名字 = thunk 调用每次访问）→ **过程参数**（7.3.3）：栈环境里传过程 = 代码地址 + 定义环境对（与 15 章闭包、21 章访问链互参）。实现：手写递归下降前端（Louden 路线，呼应 §4.4）+ 树遍历执行器，四种绑定策略一个开关。
断言：(1) `p(a,a)` 别名语料四机制输出与手推全等——值 1／值结果 2／引用 3／名字 3（引用与名字在此语料重合，它们的分辨语料是经典 `swap(i, a[i])`：引用正确交换、名字因 `i` 先被改而写错槽位 a[a[i]]）；(2) Jensen 语料名字传递求和正确且重求值次数 = 实参使用次数（计数器证人）；(3) 值结果写回按声明序（实现口径注明书上的未指定问题）；(4) 完全静态模式：无递归程序正确、递归程序被静态拒绝；(5) 引用传递的表达式实参落临时单元（地址稳定性断言：副作用后地址不变）。**无 ANTLR**。

### 27 章（原 24）补类型等价（L 书 §6.4.3）

补三块：(1) **结构等价 vs 名字等价 doctrine**：Pascal var 参数与记录的严格、C 结构的结构等价怪癖（匿名结构处处等价）、Ada 名字等价 + 子类型；（2) **判定算法**：结构等价 = 类型树同构递归（+ 递归类型的环处理：三元组标记/假设集）；名字等价 = 符号表身份比较；两算法复杂度与陷阱（参数名、字段序敏感性）实测；（3) **与 25 章合一的关系**：结构等价是无方向的结构合一——推断式语言把「等价」泛化成「求解」。示例：新增 typeequiv.hpp/.cpp（沿现有 ast/constraints/unify 的命名风格）——两模式判定器，语料含递归别名 `type t = record { t next; }`、字段序反例、匿名 vs 命名，断言两模式输出各异且与手推全等。
