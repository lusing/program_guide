# 第 53 章　收集语义与 Galois 连接：把"保守"写成定理

## 53.1 问题：第 25 章说"分析可靠"，证据在哪里

### 53.1.1 采样验证的天花板

第 25 章给常量与符号分析配过一台 soundness 检验器：随机（或
手工挑选）的输入流、真实执行、把具体值与静态预测逐点比对。
那台机器在它跑过的每一条输入上都没有说过谎——但"跑过的每
一条"恰恰是它的天花板。真实输入是无限集：整数取值无边、
input 出现次数无界、循环次数不定。采样验证的归纳力为零：
一万条输入全绿，第一万零一条仍然可能翻车。要跳出采样，就
必须找到"全部具体执行"的代言人——一个有限的数学对象，它
一字不漏地概括所有可能执行的全部信息。这个对象就是本章的
主角：收集语义（collecting semantics）。

### 53.1.2 收集语义的直觉：不选路径，全都要

第 12 章的具体语义是"一条输入流走一条路径"：解释器在每个
程序点持有**一个**环境（变量到值的映射），执行到哪环境跟到
哪。收集语义把"一个"换成"所有"：在每个程序点收集**全部可
能到达此点的环境**——所有输入流、所有路径选择、所有循环
次数，凡是可能发生的环境，一个不落全进集合。它在点 p 的值
记作 C[[p]]，是环境集合。这个对象显然不再可执行（谁也跑不
完无限条路径），但它是**良定义的数学对象**：给定程序与输
入域，C[[p]] 唯一确定。静态分析的一切可靠性主张，最终都是
对 C[[p]] 的主张。

### 53.1.3 "保守"的方向感

有了 C[[p]]，"分析可靠"可以精确成一句话：**分析的答案必须
覆盖 C[[p]] 里的一切可能，且永不虚构 C[[p]] 里没有的东西**。
符号分析在点 p 给出 x=⊤，意思是"x 的真实值可能正、可能负、
可能零"——只要 C[[p]] 里每个环境的 x 都落在这个承诺内，分
析就没撒谎；反过来若分析说 x=+ 而 C[[p]] 里存在 x=−1 的环
境，分析就撒了谎（漏报）。"保守"因此有了方向：**宁可承诺
得多（⊤），不可承诺错（具体而假）**。本章的定理
α(C[[p]]) ⊑ A 就是这句话的格论拼写：⊑ 的方向就是保守的方
向。

### 53.1.4 本章要机器检验的两件事

教程的惯例是不停留在陈述。本章实现两件可执行的事。其一，
**收集语义的有限切片**：对给定的一组输入流逐条展开路径，
得到 C 的一个有限近似——它是真的 C 的子集（只跑了部分流），
但已经是"多路径、多输入"的真实并集，足以暴露单路径语义
看不见的现象（分支汇合、循环多次）。其二，**定理的机器检
验**：在同一份切片上计算 α（收集语义的符号抽象）与 A（第
16/17 章式的工作表分析），逐点逐变量断言 α(C) ⊑ A；再在有
限代表域上枚举 γ(α(S))，断言收集到的每个环境都能被重现
（S ⊆ γ(α(S))）。两个断言全部由程序跑出、由对账脚本锁定
——"保守"二字第一次有了逐字节的证据。

### 53.1.6 术语小词典

本章术语集中在两节里出现，
一张小词典备查。

收集语义（collecting semantics）：
每点全部可能环境的集合，
C[[p]] 是它的记号。

切片（slice）：
对给定流清单展开得到的有限部分，
Cₛ ⊆ C[[p]]。

抽象映射 α：
环境集合 → 格点，
逐变量取符号再 join。

具体化 γ：
格点 → 环境集合（的代表枚举），
把"可能的符号"摊成"可能的环境"。

Galois 连接：
α 与 γ 之间的一对锁，
α(S) ⊑ m ⟺ S ⊆ γ(m)。

往返（roundtrip）：
S ⊆ γ(α(S))——
压过再摊必含自身，
连接的第三刻画之一。

成员不变式：
第 45 章的可靠性形状，
本章定理的指针版前身。

抽象解释：
Cousot 纲领的总名——
一切静态分析皆连接。

词典之外还有三个易混对：
"未初始化"与 ⊥
（前者是语义约定、后者是格点）；
"不可达"与 ⊥
（前者无路径、后者无信息，
本章实现里两者共用 ⊥）；
"TOP"与"任意值"
（前者是格的最大元、
后者是它的语义读法）。

## 53.2 收集语义的形式化

### 53.2.1 环境、路径、与 C[[p]] 的定义

环境是变量名到整数的全映射（TIP 的每个函数有固定的形参
与局部变量表，环境就在这张表上取值）。一条**具体执行**是
"输入流 + 路径选择"共同决定的环境序列：从入口环境出发
（本章约定变量初始为 0——与第 12 章 IR 生成器给每个槽 store
0 的约定一致），每经过一条 CFG 边，环境按边的语义更新（赋
值改一个变量、input 消耗一个输入、其他语句不动）。C[[p]]
定义为：**所有具体执行在到达点 p 时的环境的集合**。"所
有"跑遍输入流与路径选择两个维度——分支两支都算、循环绕
n 圈都算。

### 53.2.2 为什么它通常不可计算

三个来源使 C[[p]] 无限或不可判定。输入无限：input 可以取
任何整数，入口后第一条 x = input 就让集合无穷。路径无限：
含循环的程序有任意长路径。就算两者都有限（无 input、循环
有界），枚举全部路径的代价仍是路径数的指数——第 40 章内
联方案的账本在这里重演。所以静态分析从不直接算 C，而是构
造 A——一个在有限域上可算、且被证明覆盖 C 的对象。"可算
的近似 + 覆盖的证明"这对组合就是抽象解释的全部纲领。

### 53.2.3 有限切片：本章的可执行折衷

本章的展开器对**给定输入流清单**逐条执行，把沿途环境收进
集合。这样得到的切片 Cₛ 满足 Cₛ ⊆ C[[p]]（只跑了部分执
行）。切片虽小，五脏俱全：branch.tip 三条流让分支汇合点
的环境集合有三个元素（x 分别为 −1、0、1）——单条流永远
给不出这个景象；loop.tip 两条流让循环头出现两次迭代的环境
——路径的"多次"开始可见。切片是我们能拿在手里的 C 的
"样本并集"，本章所有机器断言都诚实地标注为"对切片"而非
"对全集"——定理对全集成立（29.6 的证明不依赖切片），检
验对切片执行（29.7 的实现只看切片）。

### 53.2.4 与第 12 章具体语义的精确关系

第 12 章的 JIT/解释器回答"这条输入流输出什么"；本章的展开
器回答"这组输入流在每个点上各自长什么样"。两者的语义约
定逐项对齐：变量 0 初始化、input 按流序消耗、整数除法截
断、比较产生 0/1——展开器 ConcEval 的每个分支都是那套语
义的复述。对齐不是巧合而是设计：切片若与具体语义有出入，
"α(Cₛ) ⊑ A"的检验就失去了基准（C 侧错，包含关系可能是假
绿）。第 12 章 JIT 与第 53 章展开器的最终一致性由 29.9 的交
叉对照背书——三台机器（JIT、展开器、工作表分析）在同一
批输入上两两对表。

### 53.2.5 C[[p]] 的另一种定义：语义方程的不动点

集合式定义（"所有执行在 p 的环境"）有一个等价的面孔：方程
组的最小不动点。给每个点 p 配一个集合变量 Xₚ，入口点的方程
是 Xₑₙₜᵣᵧ ∋ 初始环境，其余每条边 e: p→q 贡献一条方程
X_q ⊇ step_e(X_p)（边语义逐环境作用后全部并入）。最小解恰
是 C[[p]]——因为最小解从空集出发逐条方程逼出"必须属于"的
每个环境，而"必须属于"的判定正来自某条真实路径。这个面孔
的价值是结构性的：它说明 C 本身就是一台"工作表分析"，只不
过跑在无限域（环境集合）上——第 23 章的方程、第 24 章的
工作表、本章的收集语义，是同一台机器在三个域上的三次实
例。抽象解释的深刻之处由此可说：**A 不是 C 的替代品，是 C
在有限域上的影子**——把方程右边换成 α 之后的版本，最小不
动点自然落在有限格里。



### 53.2.7 环境即状态：一段语义学前史

"环境"这个词不是随手起的。
程序语义学里
给变量赋值的主流做法有两支：
环境论（environment，
名字到值的显式映射）
与存储论（store，
地址到值）。
第 12 章的解释器用环境、
第 45 章的指针片段用存储
（&x 把变量逼成地址）——
TIP 的两段历史
恰好演示了两支的分工。
本章的收集语义在环境支上
做到极致：
不只一个环境，
是全部环境的集合。
有趣的是下一站：
指称语义（denotational
semantics）把"程序"定义为
"初始环境到最终环境的函数"——
收集语义把"程序点"定义为
"环境集合的变换"，
两者只差一个
"要中间状态还是要端点"。
读者若继续往形式化方向走
（第 54 章的书单里有 Winskel），
会在指称语义的章节里
与今天的环境再碰面。

## 53.3 实现：路径展开解释器

### 53.3.1 ConcEval：环境上的表达式求值

coll.cpp 的第一段是纯具体求值器：IntLit 返回字面量、VarRef
查环境、InputE 从输入双端队列弹一个、Binop 递归求两枝按
运算符合并。四类结点与第 12 章 AST 一一对应，语义零发明。
值得停留的只有一处：输入用 std::deque 保存而非 vector——
弹出在头、无谓的搬动少，教学与工程都干净。求值器对环境的
读写只有 VarRef 的读；写发生在语句层（赋值改环境），求值
器保持纯函数形状——这让"环境在边上的更新"可以整体视为
"语句前环境 → 语句后环境"的一步映射，29.6 的归纳正好需要
这个形状。

### 53.3.2 runOneTrace：沿 CFG 走一条流

展开器的主循环拿一条输入流，从函数入口出发沿边走：每到一
个点，先把当前环境插进该点的集合（到达即收集）；然后按结
点类型行动——Exit 停止、Assign 求右端改环境、Branch 求条
件选边（真走排序后的第一条出边、假走最后一条——CFG 构造
器保证分支结点的出边恰好按 then/else 序排列）、其他结点
（Entry/Output/Return）原样通过。步数上限一万是防御性边
界：本章程序都终止，上限永不触发；若读者拿去改不终止的
程序（while(1) 无 output），循环会在上限处截断、集合停在
已收集的部分——切片语义对不终止程序的自然退化。

一个容易忽略的细节：收集的是**到达时**的环境（语句执行
前）——与第 17/26 章分析输出的"语句前状态"口径一致。三种
口径（前、后、双重）在文献里都有，教程全押"前"，输出对读
者才有统一的读法。

### 53.3.3 collect：多条流的并

collect 对清单里每条流调一次 runOneTrace，全部写进同一张
CollState（map<PP, set<TraceEnv>>）。并集的语义自然出现：
两条流经过同一点、环境不同，集合里两个都在。这就是"收集"
二字的机械实现——没有合并、没有摘要、没有抽象，环境原样
入库。map 的键 PP 是（函数名, 结点号），与第 25/26 章的程
序点编码一致；set 的序由 TraceEnv（map<string,int>）的字
典序决定——输出里环境的排列因此稳定。

### 53.3.4 打印层：每点几条环境

printCollect 逐函数逐点打印"到达环境数 + 每个环境一行"。
环境用 {x=1, y=0} 的形状印出。三流程序在汇合点打出三行、
两流循环程序在循环头打出三行（一条流两圈 + 另一条流零
圈）——集合的基数本身就是"路径多样性"的直观读数。这份
输出是 29.8 解读的第一栏底稿，也是切片语义的"事实证词"：
后面 α 与 A 的一切主张，都要回来对这份证词负责。

### 53.3.5 展开器与解释器的形状对比

把 runOneTrace 与第 12 章的树形解释器并排看，差异清单很短：
走图 vs 走树（CFG 边把控制流显式化，循环不再是递归调用而
是回到已访问的点）、收集 vs 只走（每点入库 vs 一路向前）、
输入从 stdin vs 从清单。相同的是语义核心——表达式求值、环
境更新、input 消耗序。这份"语义同、骨架异"的形状说明一件
事：收集语义不需要新的语义学，只需要把执行历史"记账"。
读者若在第 12 章改过解释器的某处语义（比如除法语义），本
章展开器的同一处必须同步——两台机器共享一套语义约定（29
.2.4 的三处一致清单是它的完整版）。

## 53.4 α：把环境集合压成符号

### 53.4.1 定义与三条代数性质

α 的定义分两层。单环境层：α₁(env) 把每个变量的值映成它的
符号（−/0/+）。集合层：α(S) 把 S 里所有环境的 α₁ 逐变量
join 起来——"x 在 S 的所有环境里的符号的最小上界"。三条
代数性质值得亲手验证（branch.tip 的汇合点是现成素材）。
性质一（单调）：S ⊆ S′ 蕴含 α(S) ⊑ α(S′)——集合变大，抽
象只能变宽。性质二（∪ 分配）：α(S ∪ S′) = α(S) ⊔ α(S′)
——这正是第 42 章"可分配性"在环境集合上的重现，也是收集
语义与格分析兼容的代数根基。性质三（幂等收缩）：α(α⁻¹
(m)) = m 对格点 m 成立的充要条件是 m 在 α 的像里——像外
的格点（比如某点永远到不了的 ⊥）不在讨论范围。三条性质
合起来划定 α 的角色：**它是具体世界与抽象世界之间的一座
单调、保并的桥**。

### 53.4.2 实现：runGalois 的第一段

α 的实现是十行：对每个程序点，先给全部变量置 ⊥（函数局部
的变量表来自 FunDecl），再把集合里每个环境逐变量 join 进
去。零环境点（不可达）保持全 ⊥——⊥ 的语义"无信息"与
"不可达"在此合流，与第 21 章的约定一致。实现里唯一的选择
是变量表的范围：本章用"全部函数的全部变量"的并——多函
数程序里不同函数的变量名互不干扰（TIP 无全局变量），混在
一张符号环境里只是打印宽一点，语义无损。

### 53.4.3 α 之后，世界小了多少

branch.tip 三流在汇合点的环境集合是三个完整环境（x、y 各
三值）；α 之后是一行"x=⊤, y=0"。压缩比是指数的：环境数可
以随路径数爆炸，符号向量只有变量数那么宽、每格五点。这
正是全部格分析的"内存预算"来源——第 21 章以来的一切工
具（符号、常量、区间）都是某个 α 的像。本章的贡献是把
"某个 α"挑明：**域即 α 的选择，分析即 α 之后的不动点**。

### 53.4.4 α 的三个手算例

把 α 按三种典型集合演算一遍，格感立刻落地。例一（单元素）：
S = {{x=5}}，α₁ 给 x=+，α(S) 一格 +——单路径无合并，抽象
无损。例二（同号合并）：S = {{x=2},{x=7}}，两个 + join 成
+——"同为正"这个信息完整保留，这正是符号域的分辨率。例
三（异号合并）：S = {{x=2},{x=−7}}，+ ⊔ − = ⊤——具体世界
里"非此即彼"的清晰，抽象世界里只好摊手。三个例子合起来
画出 α 的"信息漏斗"：路径多样性在集合层是自由的，进格层
只能保留"符号意义上的共同点"。branch.tip 的 main:3 正是例
三的三元素版（−1/0/1 三个符号 join 到 ⊤），main:4（then 支
内）是例一的现场（只有 {x=1}）——α 的输出栏就是这三种例
子在程序点上的分布图。

### 53.4.5 运算表的逐格核对清单

α 盖住关系（29.6 第二步）
依赖 sign.cpp 的四张运算表。

加法表 sAdd 的九个非平凡格：
负加负得负——具体 −3+(−4)=−7，格点 −，盖住；
负加零得负——0 是幺元，恒盖住；

零加正得正——精确；
正加正得正——精确；

含 ⊤ 的一律 ⊤——最宽承诺，恒盖住。

减法表由加法表加"右取反"导出，

负乘负得正、负乘正得负、

第 21 章讲过，第 43 章的 classify 里它

全部格子核对完毕的结论：
任何具体运算结果的符号，
都落在表给的格点之下。
这就是第二步证明在算术语义上的全部内容——
当年第 21 章造表时的"宁宽勿错"，
在今天是定理的一块砖。

### 53.4.6 α 保并的三行证明

性质二（α(S∪S′)=α(S)⊔α(S′)）
值得一个完整证明，
它是连接存在的半壁。

设 S、S′ 是环境集合。
α 的定义是逐变量
"先取每个环境的符号、再 join 全体"。
集合变大只影响第二步——
join 的操作数多了几个。

正向：α(S∪S′) 的每个变量格点
是 S 与 S′ 全部环境的符号 join，
join 的结合律与交换律
允许把它重排为
（S 的 join）⊔（S′ 的 join），
即 α(S)⊔α(S′)。
反向：等式两边来自同一批操作数，
无方向性。
三行完毕——
**保并不是 α 的美德，
是 join 的结合律的免费午餐**；
任何"逐点 join"式定义的抽象
都自动保并，
这也是为什么幂集域是连接的天然故乡。

## 53.5 γ：在代表域上把抽象摊开

### 53.5.1 定义与"反向"的直觉

γ 是 α 的反方向：格点 → 环境集合，γ(m) = "符号向量为 m 的
全部具体环境"。对 x=⊤ 来说，γ 里有 x 为任何整数的环境——
无限集合，不可枚举。本章用**代表域**做有限摊开：变量只在
{−1, 0, 1} 里取值，γ 限定在代表环境上枚举——x=⊤ 摊成 x ∈
{−1,0,1} 三种，x=+ 摊成 {1}，x=0 摊成 {0}。摊开是递归乘
积：每个变量独立选代表，k 个变量的 ⊤ 摊成 3^k 个环境。限
定在代表域上枚举，是 Galois 连接的**有限检验**——无限版
的陈述（S ⊆ γ(α(S)) 对全部环境成立）退化为可跑的断言：
收集到的每个环境若其变量值恰在代表域内，就必须出现在枚
举结果里。

### 53.5.2 往返检验：S ⊆ γ(α(S))

runGalois 的最后一段做这件事：对每个点，取 α 的结果、在代
表域上枚举 γ、把收集集合里的每个环境逐一查-membership。本
章程序的变量值恰好在 {−1,0,1} 与若干小整数（x = input 读
的流都是 −1/0/1）内，全部命中——输出行"17/17 collected
environments reproduced"。这个数字的语义：抽象没有丢掉任何
一个真实到过的环境（的代表）。它与 α(C) ⊑ A 是一枚硬币的
两面：⊑ 说"分析承诺的宽度盖住了抽象"，⊆ 说"抽象盖住了具
体"——两段盖板接起来，具体世界与分析之间没有缝。

### 53.5.3 反方向为什么不成立

γ(α(S)) ⊆ S（"摊开只含真实环境"）一般不真，而且**不该
真**。取 S = {{x=1}}：α(S) 给 x=+，γ 在代表域摊成
{{x=1}}——恰好相等。再取 S = {{x=1},{x=2}}（假想程序）：
α 给 x=+，γ 摊成 {1} 一个代表（代表域里 + 只有 1）……如
果代表域含 1 与 2 呢？γ = {{x=1},{x=2}}，仍相等。真正的缝
在符号粒度本身：S = {{x=1},{y=0}} 与 S′ = {{x=1,y=0},
{x=1,y=5}}（y=5 出代表域）的 α 相同（y 的 0 与 5 都映
+？——0 映 0、5 映 +，α(S′) 的 y=⊤）……构造严谨的反例：
S = {{x=1},{x=2}}，α(S) = +，γ(α(S))（代表域 {−1,0,1}）=
{{x=1}}——等一下，2 不在代表域。把代表域扩到 {−2,−1,0,
1,2}：γ = {{x=1},{x=2}}，又相等。真正不等要靠**格点合并的
虚构组合**：S = {{x=1,y=1},{x=2,y=2}}，α 给 x=+,y=+，γ 含
{x=1,y=2}——**从未真实出现过**的环境。这就是 γ 虚构的成
员：变量各自的"可能"做了笛卡尔积，积里就有没人组合过的
搭配。分析的未来消费者（优化器、验证器）必须接受"搭配虚
构"——这正是保守的上界语义。

### 53.5.4 枚举的账：3^k 与剪枝

γ 在代表域上的枚举是每个变量独立选代表，k 个 ⊤ 变量摊成
3^k 个环境——指数。本章程序 k=2（branch）与 k=2（loop），
3²=9 封顶，毫秒级。但读者应当看到墙在哪里：k=10 时两万
多环境、k=20 时三十五亿——枚举版 γ 只能当教具。工程版的
γ 从不显式枚举，它的消费者（定理检验、反例查询）需要的
是 membership 与"取一个代表"两个操作，都能在符号向量上
O(k) 完成。本章选择枚举，是因为"往返计数"（17/17）这个
教学输出需要数出 γ 的成员——数字比命题更可感。这个选择
本身也是一课：**抽象域的操作复杂度，取决于你为它配备了
哪些查询**——同样的域，配枚举是教具、配 membership 是工
具。

### 53.5.5 branch.tip 汇合点的 γ 完整展开

把 main:3 的 γ 枚举亲手写全。
α(main:3) = {x=⊤, y=0}。
y 的格点是 0，代表域里只有 0 一个候选；
x 是 ⊤，三个候选 −1、0、1。
枚举按变量表顺序做笛卡尔积：

> {x=−1, y=0}、{x=0, y=0}、{x=1, y=0}。

三个环境——恰好是收集集合本身
（本章的流清单选得刚好）。
于是 S ⊆ γ(α(S)) 在此点三人三座、分毫不差。
对比 main:6（output 处）：α = {x=⊤, y=⊤}，
γ 摊成 3×3=9 个环境，
而收集集合只有三个
（y 与 x 的取值实际相关——then 支 x=1,y=1、
else 支 x∈{−1,0},y=0）。
九座三客：{x=1,y=0}、{x=−1,y=1} 等
六个搭配是虚构的。
这就是 29.5.3 的"搭配虚构"在真实输出上的账目：
每个汇合点的虚构数 =
3^(⊤ 格点数) 减去真实环境数。
branch 程序全点合计虚构四十五个——
它们不进输出（计数只数命中），
但读者应当知道它们在那里：
**γ 的宽度是分析承诺的价格标签**。

## 53.6 定理：α(C[[p]]) ⊑ A

### 53.6.1 陈述

对每个程序点 p、每个变量 v：α(C[[p]])(v) ⊑ A(p)(v)。读
法：收集语义的抽象（"真实可能性的符号并"）必须落在分析
结果的格点之下。等价地：**分析承诺的每一个格点，都盖住全
部真实执行的对应符号**。A 说 x=⊤ 时定理平凡（⊤ 盖一切）；
A 说 x=0 时定理给出硬承诺——没有任何真实执行在 p 点让 x
非零。A 的格点越低（越精确），定理越有牙齿；⊥（不可达）
的牙齿最利：没有任何执行到得了 p。

### 53.6.2 证明的三步结构

第一步（初始）：入口的分析初值必须盖住 α(入口环境)。本章
约定变量 0 初始化，α(全 0 环境) = 全 0 符号，A 的入口初值取
全 0——恰为 α(C₀)，一步到位。若语义约定改成"未初始化可
为任意值"，入口就得取 ⊤——初值的选择永远是"α(具体初
态)"，不能拍脑袋。

第二步（传递）：对每条边 e: p→q 与每个到达 p 的环境 env，
传递后的环境 env′ 的符号必须被 A 的传递函数映出的格点盖
住：α₁(step(env)) ⊑ fₑ(α₁(env))。逐语句核对：赋值 x=e，
右端含 input 时具体符号任意、f 给 ⊤ 盖住；纯算术时 f 的抽
象运算（第 21 章的 sAdd 等）按定义盖住具体运算的符号——
每张运算表当年构造时就为这步留了余量（−+→⊤ 而非猜一
个）。这一步是"传递函数与 α 交换到足够"（不必严格交换，
盖住即可）的标准形状。

第三步（合并）：C[[q]] 是所有前驱贡献的并，α 按性质二把
并转成 join；A 的工作表在汇合点也做 join——两个 join 的
参数由前两步逐边盖住，join 的单调性传递盖住关系。三步合
起来对路径长度归纳：任何到达 q 的真实执行，其符号被
A(q) 盖住。证明从不终止性里救出来的部分只剩"input 的任
意性"（第一步与第二步的 ⊤ 处理）与"无限路径"（归纳对任
意有限长度路径成立，C 的定义恰好只需要有限到达）。

### 53.6.3 机器检验：把三步的结论一次对表

runGalois 的中段做检验：对切片的每个点、每个变量断言
sl.leq(α(Cₛ)(v), A(v))。任何一处翻车，theoremHolds 置
false，--check 的退出码变 1、对账脚本立刻红。这个检验的
力度值得如实说明：它验证的是**实现之间的一致**（展开器
与工作表在同一批输入上没有反例），不是定理本身（定理对
全部输入成立，检验只覆盖清单里的流）。但工程的信任正是
这样一层层攒起来的：证明给结构、检验给实现、对账给回归
——三层的任何一层在未来被改动时，另两层会守住它。

### 53.6.4 Galois 连接的完整定义

把本章用到的连接性质写成标准形式。α: P(Env) → L 与
γ: L → P(Env) 构成 Galois 连接，当且仅当对一切环境集合 S
与格点 m：

> α(S) ⊑ m ⟺ S ⊆ γ(m)。

两个方向互相锁死：左边说"m 盖住 S 的抽象"、右边说"S 被 m
的摊开装下"——同一句话在两个世界的两种说法。等价的第三
种刻画（常常更好用）：α 保并（α(S∪S′)=α(S)⊔α(S′)）、
α∘γ ⊑ id（摊开再压不超过自身）、id ⊑ γ∘α（压过再摊必含
自身——正是 29.5 的往返断言）。本章的机器检验对应第三刻
画的后一条；定理 α(C) ⊑ A 在连接存在时的等价形式是
C[[p]] ⊆ γ(A(p))——"分析格点的摊开装下全部真实执行"。
四种说法来回换算是本领域的日常体操，读者值得各写一遍例
证。

连接不要求 γ∘α = id（无损）也不要求 α∘γ = id（完全）——
两个方向的"损"正是抽象的代价：γ∘α 多出的成员是搭配虚
构（29.5.3），α∘γ 压丢的是粒度。无损连接（同构）存在时
两个世界一样大，抽象无从谈起——**抽象的本钱就是连接的
松弛**。

### 53.6.5 与第 45 章成员不变式的同构

第 45 章的可靠性是"pts 的每个成员都是真实可能"，本章的定
理是"α(C) ⊑ A"。把前者的术语搬过来：具体世界的"真实分配
历史"对应 C[[p]]、抽象折叠（语法点）对应 α、pts 对应
A——成员不变式逐字翻译成包含关系，包含关系就是 ⊑ 在幂
集格上的拼写。第 42 章的路径边定理（表覆盖全部有效路径）
同构：有效路径集合是 C 的路径版、路径边表是 A 的路径版。
三章三个化身，一个定理——29.11 的 Cousot 纲领"任何分析
都是一个连接"说的就是这种一稿多投。读者复习时可以拿任
意一章的"可靠性论证"小节，试着把它改写成 α/γ 术语——改
写顺了，抽象解释就毕业了。

### 53.6.6 从检验到证明的鸿沟

机器检验通过之后，
离"定理成立"还差多远？
把这段距离诚实地说清，
是本章方法论的最后一块。

检验覆盖的是：本实现、本程序、本流清单。
证明覆盖的是：一切实现、一切程序、一切输入。
中间隔着三层推广：
流清单之外还有无限输入——
检验对它们零担保，
但定理的证明（29.6.2）不依赖清单，
只要语义与传递函数的核对成立，
推广自动完成；
本程序之外还有任意程序——
证明的归纳对任意 CFG 成立，
检验只是采样；
本实现之外还有正确性——
如果展开器或工作表有 bug，
两台机器可能一起错
（比如两者的加法都写成减法，
对表永远和谐）。
第三层只能靠三方对证
（第 12 章语义、本章两台机器）

**证明给结构，检验给实现，对账给回归**——
三层各守一段，谁也不冒充谁。
这个读法适用于全书每一台
"soundness 检验器"——
第 25 章、第 45 章与本章的三台，

### 53.6.7 定理的对偶：完备性何时白送

⊑ 只证可靠性；
反向 A ⊑ α(C)
（分析不多说）叫完备性，
一般不成立——
但有两种情形白送。

情形一：程序无分支无循环
（直线程序）。
A 的传递与 α 的逐步抽象
在无合并时逐点相等
（每格运算表若都精确——
符号表的 ⊤ 格是例外，
输入含 input 就破功）。
所以"直线程序 + 无 input +
精确运算"时分析=收集的抽象，
双向成立。

情形二：分析的格点
恰好是收集集合的函数像
——这就是本章 α 的构造方式，
但 A 是工作表算的、
不保证到得了 α(C) 的格点
（loop 的 4 号 A=α(C)，
branch 的 main:4 A>α(C)）。
A 的"过度"来自合并的提前，
完备性的丢失量
=分歧格点数（29.8.4 的测量）。

两种白送情形划出完备性的
"非白送区"：
分支、循环、input——
恰好是控制流与数据的全部来源，
也是第 21/22 章
两种补救（widen、路径敏感）
的用武之地。

## 53.7 实现走读：runGalois 与分析 A 的构造

### 53.7.1 A 是谁：第 16/17 章机器的重装

runGalois 里那台工作表分析不是新机器——它是第 24 章工作表
+ 第 25 章符号传递的重装：状态是"每点每变量一格符号"，初
值入口全 0（α 的初始步）、其余 ⊥；弹出一点、按语句做传
递（赋值强更新：右端在**语句前状态**上抽象求值——这个
"前状态"口径是实现里最要紧的一行，i = i + 1 的右端 i 读
的是赋值前的 i，先 kill 再求值会把自引用读成 ⊥、循环里 i
就永远不动了）；沿出边把结果 join 进后继，涨了入队。三
个部件（初值、传递、合并）与 29.6 的三步证明一一对应——
证明的每一步都在代码里有一行落点，这种"证明与代码互为
台账"的写法是本章从第 25/26 章继承的家风。

### 53.7.2 抽象求值器 abstractValue

与 ConcEval 镜像的抽象求值器：IntLit 映常量符号、InputE 映
⊤、VarRef 查抽象环境、Binop 查第 21 章的运算表。两个求值
器的分支逐行对齐——这不是代码复用的懒惰，而是 29.6 第二
步（传递与 α 的盖住关系）的**可核对形态**：每对分支摆在一
起，"具体算的结果被抽象算的格点盖住"一眼可验。读者把两
段并排开两个窗口，逐分支问"左边永远落在右边之下吗"，就
是在手工复查证明的第二步。

### 53.7.3 工作表主循环的三个动作

主循环弹出点 p 后做三件事：查语句做传递得 after；遍历出
边；对每个后继逐变量 join，涨了才入队。与第 42 章路径边
制表、第 45 章约束工作表对照，三台机器的"纪律"完全同
构：**新信息才入队、集合去重、单调上升**。差别只在状态
的粒度（格点 / 路径边 / 集合成员）。至此教程的四种工作
表（16 数据流、25 制表、28 约束、29 环境）全部到齐——第 54 章的总表会把它们排成一列，读者应当已经能凭"流动的是
什么"一眼分类。

### 53.7.4 定理检查与往返检查的实现

两段检查都是纯查询。定理检查：遍历 α 的每个（点, 变量,
格点），查 A 的同位格点，leq 断言；计数 pointsCompared 供
输出。往返检查：对每个点的 α 结果在代表域 {−1,0,1} 上深
度优先枚举全部满足符号的组合（每变量独立选代表，选出的
符号必须 ⊑ 目标格点——⊤ 收三代表、+ 收 1、0 收 0、⊥ 收
零），构成 γ 的有限化身；再把收集集合逐个查 membership。
两段都没有副作用、不修改任何状态——检验是分析的"陪审
团"，不是参与者。

### 53.7.5 打印层：三节输出的分工

printGalois 分三节：α 的一节（每点每变量的符号）、A 的一
节（同形状）、结论两行（定理 HOLDS/FAILS、往返 x/y）。α
与 A 并排是本章输出的灵魂——两节行数相同、变量序相同，
肉眼 diff 直接落在分歧格点上（29.8 的 main:4 就是这么被
看见的）。结论行给对账脚本当锚：theoremHolds 映射退出
码，任何回归先在这里爆。

### 53.7.6 完整 trace：A 在 branch.tip 上的工作表旅程

把 29.7.1 的那台 A 在 branch.tip 上手工跑一遍，与第 42 章
的制表 trace 同款规格。初始：全部点全 ⊥，入口点置全 0
（x=0、y=0——α(初始环境)）。队首弹出入口：无语句动作（
Entry），沿出边把 {x0,y0} join 进 2 号点——2 号从 ⊥ 涨到
{x0,y0}，入队。弹出 2 号（x = input）：传递函数对 x 强更新
——右端 input 抽象为 ⊤，得 {x⊤,y0}；join 进 3 号（分支点
）：涨，入队。弹出 3 号：Branch 无变量动作，沿两条出边各
join 一次——4 号（then 支）与 5 号（else 支）都涨到
{x⊤,y0}。弹出 4 号（y = 1）：y 强更新为 +，得 {x⊤,y+}，join
进 6 号：6 号涨 {x⊤,y+}。弹出 5 号（y = 0）：得 {x⊤,y0}，
join 进 6 号：join({x⊤,y+}, {x⊤,y0}) = {x⊤,y⊤}——6 号再涨
（y 从 + 变 ⊤），入队。6 号（output）无动作，7 号（return）
无动作，8 号出口，全表稳定。最终 A：main:4 处 x=⊤——与
α(Cₛ) 的 x=+ 分歧的那一格，机械成因就在"3 号点的 ⊤ 逐边
复制进了 4 号"：**分析的路径宽度在分支点定型、不随分支内
部收窄**（要收窄需要路径敏感——第 32 章）。这份 trace 的
每个"涨"都能在输出的 A 栏找到定格，读者跑通一遍，29.8.1
的解读就从"读数"升级成"验账"。

## 53.8 输出逐行解读：branch 与 loop

### 53.8.1 branch.tip：三分支的完整旅程

第一栏（收集语义）按点展开：入口与赋值点各一条环境
（x=0，y=0——0 初始化的约定在此可见）；分支点三条（x=
−1/0/1——三流各到一次）；then 支的点一条（只有 x=1 的流
走这）；else 支两条（x=−1 与 0）；汇合后的 output/return/
exit 三条（y 分别为 1、0、0——then 支的 y=1 与 else 支的
两条 y=0）。集合基数一路是"活着的路径数"的读数：3→1→
2→3。

第二栏（α）是第一栏的逐点压缩：分支点 x=⊤（三个符号
join）、y=0；then 支 x=+；汇合 y=⊤（0⊔0⊔1）。压缩的每
一步都能在第一栏找到原料——这一栏是"α 在真实数据上工
作"的展览。

第三栏（A）与第二栏几乎相同，唯一的分歧在 then 支的入口
（main:4）：α 给 x=+（切片里只有 x=1 的流到过），A 给 x=⊤
（分析不知道只有一路——汇合的保守性提前到了分支内）。
**这一格分歧是全章的教学钉子**：A 并没有错（⊤ 盖住 +，
定理成立），它只是没有切片聪明——切片"见过"三条流，分
析只见过 CFG。收集语义与静态分析的差别被这一格说尽：前
者是历史的账本，后者是结构的推演。

### 53.8.2 loop.tip：循环里的两遍

第一栏：循环头的环境三条——{x=0,i=0}（流 0 直接过）、
{x=1,i=0}（流 1 第一圈前）、{x=1,i=1}（流 1 第二圈前）。
循环体一条 {x=1,i=0}。output 处两条。x=1 的流绕一圈后 i
变 1、条件 x>i 假、退出——两条流、三个循环头环境，"循环
次数"作为集合基数浮出水面。第二栏 α：循环头 i=⊤（0⊔0⊔
1=+？0⊔0=0、0⊔1=⊤）、x=⊤；体里 i=0、x=+。第三栏 A：
循环头 i=⊤ x=⊤（与 α 一致——这里连"切片聪明"都没有，
绕圈本身就产生并）。定理行 HOLDS、往返 14/14。

### 53.8.3 两份输出合起来的三个观察

观察一：α ⊑ A 处处成立、main:4 是唯一"严格大于"的格点
（branch.tip 里）——定理的"非平凡性"浓缩在一格。观察
二：环境数（17 与 14）远小于路径数的理论上限——切片的
"并"已经把同环境的重复合并（set 的天然行为）。观察三：
JIT 对照节的输出（1→1、−1→0、0→0 与 1→1、0→0）与收集
集里的环境互相印证——比如 branch 流 −1 的环境 x=−1 落在
else 支、输出 0 落在 output 点的环境 y=0。三台机器（展开
器、工作表、JIT）在同一份程序上三方对表，任何一台撒谎，
另外两台的对不上就是证词矛盾。

### 53.8.4 输出的行序契约与三层可读

expected/output.txt 的行序由程序序（branch 先于 loop）与点
序（结点号升序）叠加，环境在集合内按字典序。三栏（收集/
α/A）共享点序，肉眼 diff 有公共坐标轴。读输出的三层姿势
在 27.6.8 讲过（事实/来历/代价），本章加一层第四读法：
**对照读**——α 栏与 A 栏逐行并排，找"严格大于"的格点，
每个这样的格点都是"切片比分析聪明"的证据，都能追溯到一
条切片走过而分析合并了的路径。branch.tip 里只有 main:4
一处、loop.tip 里零处——两个数字合起来是"本分析的保守
性在本程序上的精确测量"。把这份测量用于回归（改分析后重
跑、数格点数）就是最便宜的性能指标。

### 53.8.5 loop.tip 的完整 trace

把 29.7.6 的 A 工作表在 loop.tip 上再跑一遍，
与收集栏逐点对表。
初始：入口 {i=0, x=0}（全 0 初值），
其余点 ⊥。
弹入口：join 进 2 号，{i0,x0}。
弹 2 号（x = input）：x 强更新 ⊤，
得 {i0,x⊤}，join 进 3 号（i = 0）。
弹 3 号：i 强更新 0（右端字面量），
得 {i0,x⊤}，join 进 4 号（循环头）。
弹 4 号（Branch）：两条出边——
体（5 号）与出口路（6 号）。
两边都 join {i0,x⊤}。
弹 5 号（i = i + 1）：右端在**前状态**上求值，
i 的前值此刻是 0，
0 + + = +，
得 {i+,x⊤}，join 回 4 号（回边）：
4 号的 i 从 0 涨到 ⊤（0⊔+=⊤），入队。
弹 4 号（新值 {i⊤,x⊤}）：
再沿两边 join——
5 号的 i 涨到 ⊤，6 号的 i 涨到 ⊤。
弹 5 号（{i⊤,x⊤}）：i+1 的右端 i=⊤，
⊤++=⊤，回 join 4 号无涨。
稳定。
最终 A：4 号 {i⊤,x⊤}，
与 α(Cₛ) 的 4 号 {i⊤,x⊤} 完全一致
——loop.tip 没有分歧格点。

对照收集栏读这个 trace：
收集的 4 号有三个环境
（{x0,i0}、{x1,i0}、{x1,i1}），
α 后 x=⊤（0⊔1=+？0⊔1=⊤）、i=⊤。
分析的 ⊤ 来自回边 join，
切片的 ⊤ 来自两条流两次迭代——
**同一个格点，两个来路**。
定理在这格上取等号，
相等不是巧合而是"本程序的分析恰好用尽了
切片提供的一切信息"。
branch 的 main:4 则相反——
切片的信息（只一路走过）分析用不上，
因为它的合并发生在更早的分支点。
一程序一处严格小于、一程序处处相等，
两个样本合起来给"分析质量"一个
极简的度量维度。

### 53.2.6 三个不可计算来源的各自深挖

29.2.2 列了 C 不可计算的三个来源，各自值得深挖一层。

输入无限：x = input 之后集合是
{x=n : n ∈ ℤ}——可数无限。
任何把"值的身份"留在域里的分析
（常量、区间端点）都要面对它：
常量域用 ⊤ 收编、区间域用 [−∞,+∞]、
符号域天然只看符号。
三种收编都是"先 α 后分析"的变体——
α 把无限压成有限，是第一道闸门。

路径无限：while 循环 n 圈是 n 条路径。
收集语义要全收，
分析只要不动点——
第 23 章的有限高度保证第 k 次迭代后
格点不再变，"绕一万圈"与"绕两圈"
在格上可能是同一个点
（loop.tip 的 4 号正是：两圈后稳定）。
**路径的无限被格的有限吸收**——
这是不动点方法的全部魔法。

枚举指数：就算输入与路径都有限，
"全部路径"仍按分支数指数增长。
收集语义按"环境集合"记账而非按路径——
set 合并了终点相同的路径
（29.8.3 观察二），
指数在集合的基数里被压缩成
"不同终态数"。
终态数最坏仍指数（每分支改一个变量），
但真实程序里远小于路径数——
这就是"收集"比"枚举路径"便宜的原因，
也是符号执行（第 32 章）与收集语义的分界：
前者记路径条件、保精度付指数，
后者丢路径条件、并环境换规模。

### 53.8.6 手算预测输出全流程

把"预测—运行—对账"的完整流程
在 branch.tip 上走一遍，
作为本章的实操毕业礼。

第一步，画 CFG 点序（7 章）：

## 53.9 JIT 交叉对照：第三台机器入场

--check 的最后一节把每条输入流交给 LLVM ORC 真跑一遍，输出
inputs→outputs 一行一条。它的角色不是装饰：收集切片的

对表）构成完整的证据链。第 25 章与第 45 章的 soundness 检
验器都是这个三方形状的两方简化版；本章把它补成三方——
教程的验证拓扑在最后一章分析里收官。

### 53.9.1 三方的分工与失效模式

三方各守一段：JIT 守"语义基准"（它坏了，正确性无从谈起）、
展开器守"收集形状"（它坏了，切片失真）、工作表守"抽象推
演"（它坏了，定理 FAIL）。两两组合的失效模式各不相同：
JIT 与展开器不一致——语义实现分歧，29.2.4 的口径清单是第
一嫌疑人；展开器与工作表不一致——定理红，29.6.2 的三步
里某步被实现破坏；JIT 与工作表没有直接对表——它们隔着
α，间接由前两对传递。三方一致性不是三次独立检验的叠加，
而是一张三角：任何一条边红，另外两条边把责任限定在唯一
的顶点。这种"用结构定位故障"的验证拓扑，比一锅炖的端到
端测试省力得多——读者在自己项目里配验证时，值得先画这
张三角再写代码。

### 53.9.2 JIT 对账行的读法

## 53.10 工程注意点

**切片的清单就是精度。** Cₛ 只覆盖跑过的流，检
验 α(Cₛ) ⊑ A 通过对"没跑的流"零担保——但定理（对全集）
靠证明不靠检验，切片只承担"暴露实现错误"的责任。选流的
原则与第 45 章 28.9.8 相同：每条流要么走新路要么验新值；
本章 branch 三条流把三分支全点亮、loop 两条流把零圈/一圈
两种循环形态分开——清单设计是切片语义的"测试设计"问
题，与分析本身同等重要。

**初值口径必须三处一致。** 变量 0 初始化的约定出现在三个
地方：展开器的环境初始化、A 的入口初值（α(全 0)）、IR 生成
器的 store 0。三处任何一处漂移（比如某天把 A 的入口改成
⊤），定理检验可能仍然通过（⊤ 更宽、盖住关系不破）——
但"α(初始)"的教学口径被破坏、γ 枚举的代表域假设也可能失
配。宽方向的漂移不翻车、只变钝，这是 sound 世界的典型故
障形态：没有红灯，只有性能与精度的静默流失。对账脚本锁
定输出全文，是防钝化的最后一道网。

**两个求值器必须镜形成对。** ConcEval 与 abstractValue 的
分支一一对应，改动永远成对：给 TIP 加一种运算，两边各长一
支、并排核对盖住关系。单独改一边的后果不会立刻爆（检验
可能恰好覆盖不到新分支），而是埋进未来某条流。成对纪律
在代码评审里一眼可查——两段相距不超过五十行，评审人应
当条件反射地把它们放一起看。

**代表域的选择要配程序。** {−1,0,1} 对本章程序恰好够用
（输入流只用了这三个值）；若流里出现 7，7 映 +、代表域里
+ 的代表是 1，7∉γ 的枚举——membership 失败、往返计数掉
齿。这不是 bug：7 的环境确实无法被代表重现，诚实的输出
应当把它计为未重现。工程上要么扩代表域（加 7 与 −7）、要
么换流。教程选 {−1,0,1} 是因为它刚好让"全部重现"成立，
把往返行变成一条干净的 17/17——设计演示数据也是设计验
证。

##### 53.10.7 流清单的设计法

切片的精度=清单的覆盖，
清单设计因此是一门"测试设计"。
本章两份清单的设计法可以复制：

第一步，画路径树：
branch 的 if 分两支、
loop 的 while 分零圈与多圈——
树上的每条根到叶路径是一个"形态"。
第二步，每形态配一条流：
branch 三流点亮三支，
loop 两流点亮零圈与一圈。
第三步，查交叉：
有没有"一条流点亮两个形态"的冗余
（branch 的 0 流同时是 else 支与
y=0 的输出证据——一石二鸟是好的）；
有没有两个形态共享全部流的浪费
（loop 的两圈与三圈形态同流——
诚实接受，切片不追全）。
第四步，对照代表域：
清单里的输入值是否都在
{−1,0,1} 的化身集里
（负/零/正各一）——
不在就扩域或换值。

四步做完，清单的每个字节都有理由。
同样的方法适用于第 17/28 章的
输入流设计——三家的 .inputs 文件
都是这份设计法的产物。

runOneTrace 的步数上限

没有它：

## 53.11.1 从连接到域的构造代数

Galois 连接给"域"一门构造语法，第 22 章玩过的积/提升/映射
在此获得理论身份：两个连接 (α₁,γ₁) 与 (α₂,γ₂) 的乘积连接
作用在积格上（逐分量抽象）——符号×常量的双域分析由此免
费；幂集提升把"集合的连接"升级为"集合族的连接"——第 45 章 pts 的 Var→2^Site 形状是它的实例（29.2.12 的函数格视角
换一种说法）；函数域连接把"环境上的连接"搬到"状态转移函
数上"——第 43 章的边缘函数是它的单变量版。构造语法保证
复合域的可靠性从分量域自动继承——**连接的复合保连接**，
这等于给"组装新分析"发了 algebraic 执照。教程没有实现域
构造子（第 22 章只实现了格构造），但读者应当知道工业分析
器（比如某器里的符号×区间×指向的乘积域）在这张执照下工
作。

## 53.11 文献坐标：Cousot 的纲领与 spa 第 20 章

抽象解释的出生证明是 Patrick Cousot 与 Radhia Cousot 1977
年的 POPL 论文 "Abstract Interpretation: A Unified Lattice
Model for Static Analysis of Programs"。它的纲领性主张正
是本章的骨架：**任何静态分析都是一个具体语义与一个抽象
语义之间的 Galois 连接**——α 把具体压进抽象、γ 把抽象摊
回具体、连接条件 α(S) ⊑ m ⟺ S ⊆ γ(m) 把两个方向拧成一
根。论文的第二个主张同样重要：抽象域的构造是代数活动
（乘积、提升、函数域——第 22 章玩过的那套），新域可以从
旧域组装。第三个主张最有工程味：分析的精度不在域本身、
在域与程序的互动（widening 的时机、路径的合并策略）——
第 21/22 章的深水区由此而来。

spa 第 20 章是这套纲领的教学版：先定义 collecting seman
tics（本书 29.2）、再给出 Galois connection 的定义与例
（29.4/29.5）、最后把"可靠的分析"定义成与 α 的连接兼容
的不动点（29.6）。本章与它的差异在实例的选择：spa 用区
间域做主例（无限格、widening 登场），本章用符号域（有限
格、widening 不需要）——把无限格的复杂度留给第 20/21
章、把连接的形状放在最亮处，是教学顺序上的取舍。读者读
完两份可以互验：spa 的区间例子拿到本章机器上跑（换
abstractValue 的运算表与代表域），定理陈述一字不改。

延伸阅读三件套：Cousot 夫妇 1979 年的第二篇（ widening 与
近似序列）、Nielson–Nielson–Hankin 的 *Principles of
Program Analysis* 第 4 章（连接的教科书标准叙述）、以及
Cousot 2000 年前后的系列讲义 "Abstract Interpretation
Fragments"（计算器式的迷你例子合集）。教程的下一站（第 54 章）将把全书三十个分析放回 α/γ 的框架下清点——本章
给出的词汇表届时是总账的记账单位。

## 53.13 小结

本章把"保守"从口语升格为定理。收集语义给全部具体执行立
账，α 把账本压成格点，γ 把格点摊回环境，Galois 连接把两
个方向拧紧，定理 α(C[[p]]) ⊑ A 把"分析盖住现实"钉成偏
序。机器检验让定理在切片上逐格对表，往返检验让抽象在代表域
上无一漏网——第 24 与 42 章的 JIT 执行台曾给具体语义当过
第三方对证，本章把这份对证收缩进展开器与第 12 章语义约定
的逐项对齐（29.2.4）里。
branch.tip 的 main:4 一格分歧（α=+、A=⊤）浓缩了历史账本
与结构推演的全部差别——切片聪明、分析稳健，定理保证稳
健者永远盖住聪明者。

三十章走到倒数第二章，读者手里的地图已经画完：格是地形
（21–23）、工作表是交通工具（16）、域是目的地选择（17/
20/26）、路径与上下文是路线精度（22/24）、过程间是跨城
高速（23/25）、约束是另一套路网（27/28）、而本章的连接
是整张地图的投影法则——任何分析画在任何域上，都要经得
起 α 与 γ 的往返检验。下一章收官：把三十个分析排在同一
张表上，用今天的词汇给每个格点标注它与具体世界的距离。

### 53.12.2 练习解答要点（练习一至六）

```cpp
// file: src/coll.hpp
// 第 53 章配套：收集语义（collecting semantics）与 Galois 连接。
//
// 收集语义 C[[p]]：在每个程序点记录"所有可能执行到这里的环境"的集合，
// 是具体语义最直接的静态形态——它不丢失信息，因而通常不可计算/无限；
// 本章对有限条给定输入流做路径展开，得到它的一个有限切片。
//
// 在收集状态上定义抽象映射 α（按符号分类、join）与具体化 γ
//（枚举匹配符号的环境），并检验两个核心命题：
//   可靠性定理：α(C[[p]]) ⊑ A（A 为 CFG 上的单调符号分析）；
//   Galois 连接：S ⊆ γ(α(S))（有限代表域上的往返检验）。
#pragma once

#include <map>
#include <set>
#include <string>
#include <utility>
#include <vector>

#include "ast.hpp"
#include "cfg.hpp"

namespace tip {

// 程序点 =（函数名, 函数内编号）。
```

```cpp
// ---------------- 具体表达式求值 ----------------
struct ConcEval {
    TraceEnv &env;
    std::deque<int> inputs;

    ConcEval(TraceEnv &e, std::vector<int> in) : env(e) {
        for (int v : in) inputs.push_back(v);
    }

    int value(const Expr *e) {
        if (const auto *x = dynamic_cast<const IntLit *>(e)) return x->v;
        if (const auto *x = dynamic_cast<const VarRef *>(e)) {
            auto it = env.find(x->name);
            return it == env.end() ? 0 : it->second;
        }
        if (dynamic_cast<const InputE *>(e)) {
            int v = inputs.front();
            inputs.pop_front();
            return v;
        }
        if (const auto *x = dynamic_cast<const Binop *>(e)) {
            int a = value(x->l.get());
            int b = value(x->r.get());
            switch (x->op) {
                case BOp::Add: return a + b;
                case BOp::Sub: return a - b;
                case BOp::Mul: return a * b;
                case BOp::Div: return a / b;
                case BOp::Gt: return a > b ? 1 : 0;
                case BOp::Eq: return a == b ? 1 : 0;
            }
        }
        return 0;
    }
};

int signOfConcrete(int v) {
    if (v < 0) return SMINUS;
    if (v == 0) return SZERO;
    return SPLUS;
}

// ---------------- 路径展开 ----------------
void runOneTrace(const Cfg &cfg, const ProgramA &program,
                 const std::vector<int> &inputStream, CollState &out) {
    std::map<std::string, const FunDecl *> decls;
    for (const auto &f : program.funs) decls[f->name] = f.get();

    for (const FunCfg &fc : cfg.funs) {
        const FunDecl *fd = decls.at(fc.name);
        std::map<int, std::vector<int>> succ;
        for (const auto &[a, b] : fc.edges) succ[a].push_back(b);
        for (auto &[a, bs] : succ) std::sort(bs.begin(), bs.end());

        TraceEnv env;
        for (const std::string &p : fd->params) env[p] = 0;
        for (const std::string &v : fd->vars) env[v] = 0;

        ConcEval ev(env, inputStream);
        PP cur{fc.name, fc.entry};
        int steps = 0;
        while (steps++ < 10000) {
            out[cur].insert(ev.env);
            const CfgNode &node = fc.nodes.at(cur.second);

            if (node.kind == CfgNode::Kind::Exit) break;

            if (node.kind == CfgNode::Kind::Assign) {
                const auto *a =
                    dynamic_cast<const AssignS *>(node.stmt);
                if (const auto *t =
                        dynamic_cast<const VarRef *>(a->target.get()))
                    ev.env[t->name] = ev.value(a->value.get());
            } else if (node.kind == CfgNode::Kind::Branch) {
                const auto *s = dynamic_cast<const IfS *>(node.stmt);
                const Expr *cond = nullptr;
                bool isWhile = false;
                if (s) {
                    cond = s->cond.get();
                } else {
                    const auto *w =
                        dynamic_cast<const WhileS *>(node.stmt);
                    cond = w->cond.get();
                    isWhile = true;
                }
                bool taken = ev.value(cond) != 0;
                const std::vector<int> &bs = succ[cur.second];
                int nextId = taken ? bs.front() : bs.back();
                (void)isWhile;
                cur = {fc.name, nextId};
                continue;
            }

            auto it = succ.find(cur.second);
            if (it == succ.end() || it->second.empty()) break;
            cur = {fc.name, it->second.front()};
        }
    }
}

// ---------------- 抽象：表达式的符号求值 ----------------
int abstractValue(const Expr *e,
                  const std::map<std::string, int> &signEnv) {
    if (const auto *x = dynamic_cast<const IntLit *>(e))
        return signOfConcrete(x->v);
    if (dynamic_cast<const InputE *>(e)) return STOP;
    if (const auto *x = dynamic_cast<const VarRef *>(e)) {
        auto it = signEnv.find(x->name);
        return it == signEnv.end() ? SBOT : it->second;
    }
    if (const auto *x = dynamic_cast<const Binop *>(e)) {
        int a = abstractValue(x->l.get(), signEnv);
        int b = abstractValue(x->r.get(), signEnv);
        switch (x->op) {
            case BOp::Add: return sAdd(a, b);
            case BOp::Sub: return sSub(a, b);
            case BOp::Mul: return sMul(a, b);
            case BOp::Div: return sDiv(a, b);
            case BOp::Gt:
            case BOp::Eq: return sCompare(a, b);
        }
    }
    return SBOT;
}

}  // namespace

CollectResult collect(const Cfg &cfg, const ProgramA &program,
                      const std::vector<std::vector<int>> &inputStreams) {
    CollectResult r;
    for (const auto &stream : inputStreams) {
        runOneTrace(cfg, program, stream, r.state);
        ++r.runs;
    }
    return r;
}

GaloisResult runGalois(const Cfg &cfg, const ProgramA &program,
                       const CollectResult &collected,
                       const std::vector<int> &representatives) {
    GaloisResult g;
    SignLattice sl;

    std::set<std::string> allVars;
    std::map<std::string, const FunDecl *> decls;
    for (const auto &f : program.funs) {
        decls[f->name] = f.get();
        for (const std::string &v : f->vars) allVars.insert(v);
        for (const std::string &p : f->params) allVars.insert(p);
    }

    // α(C[[p]])：逐点对环境集合抽象。
    for (const auto &[pp, envs] : collected.state) {
        std::map<std::string, int> s;
        for (const std::string &v : allVars) s[v] = SBOT;
        for (const TraceEnv &e : envs)
            for (const auto &[name, val] : e)
                s[name] = sl.join(s[name], signOfConcrete(val));
        g.alphaCollection[pp] = std::move(s);
    }

    // A：CFG 上的单调符号分析。入口取 α(初始具体状态)：解释器（和 IR 生成
    // 器）都把每个变量初始化为 0，α 之后是全 0——这正是第 24 章方程组
    // "初值取具体初态的抽象"一行的实例。其余点从 ⊥ 升起。
    std::map<PP, std::map<std::string, int>> states;
    std::map<PP, std::vector<PP>> succ;
    for (const FunCfg &fc : cfg.funs) {
        for (const auto &[a, b] : fc.edges)
            succ[{fc.name, a}].push_back({fc.name, b});
        for (const auto &[id, node] : fc.nodes) {
            PP p{fc.name, id};
            std::map<std::string, int> e;
            for (const std::string &v : allVars)
                e[v] = id == fc.entry ? SZERO : SBOT;
            states[p] = std::move(e);
        }
    }

    std::deque<PP> wl;
    for (const auto &[p, e] : states) wl.push_back(p);
    while (!wl.empty()) {
        PP p = wl.front();
        wl.pop_front();
        const std::string &fun = p.first;
        const FunCfg *fc = nullptr;
        for (const FunCfg &x : cfg.funs)
            if (x.name == fun) fc = &x;
        const CfgNode &node = fc->nodes.at(p.second);

        std::map<std::string, int> after = states[p];
        if (node.kind == CfgNode::Kind::Assign) {
            const auto *a =
                dynamic_cast<const AssignS *>(node.stmt);
            if (const auto *t =
                    dynamic_cast<const VarRef *>(a->target.get())) {
                // 右端必须在赋值前的状态上求值：
                // i = i + 1 的右端 i 指的是赋值前的 i（先 kill 再求值会把
                // 自引用读成 ⊥，循环里 i 就永远不动了）。
                after[t->name] =
                    abstractValue(a->value.get(), states[p]);
            }
        }

        auto it = succ.find(p);
        if (it == succ.end()) continue;
        for (const PP &q : it->second) {
            bool changed = false;
            for (const std::string &v : allVars) {
                int old = states[q][v];
                int joined = sl.join(old, after[v]);
                if (!sl.eq(old, joined)) {
                    states[q][v] = joined;
                    changed = true;
                }
            }
            if (changed) wl.push_back(q);
        }
    }
    g.analysis = std::move(states);

    // 定理：α(C[[p]]) ⊑ A 逐点逐变量。
    g.theoremHolds = true;
    for (const auto &[pp, signs] : g.alphaCollection) {
        ++g.pointsCompared;
        for (const auto &[v, s] : signs) {
            int a = g.analysis.at(pp).at(v);
            if (!sl.leq(s, a)) g.theoremHolds = false;
        }
    }

    // 往返检验：收集到的每个环境都属于 γ(α(S))（用代表域枚举）。
    // γ 只在当前函数自己的变量上枚举：环境不含其他函数的变量。
    for (const auto &[pp, envs] : collected.state) {
        const std::map<std::string, int> &signs = g.alphaCollection.at(pp);
        const FunDecl *fd = decls.at(pp.first);
        std::vector<std::string> names;
        for (const std::string &v : fd->vars) names.push_back(v);
        for (const std::string &v : fd->params) names.push_back(v);

        std::set<TraceEnv> gamma;
        std::vector<std::pair<std::string, int>> chosen;
        std::function<void(size_t)> enumerate = [&](size_t i) {
            if (i == names.size()) {
                TraceEnv e;
                for (const auto &[name, val] : chosen) e[name] = val;
                gamma.insert(std::move(e));
                return;
            }
            int wanted = signs.at(names[i]);
            for (int r : representatives) {
                int rs = signOfConcrete(r);
                if (sl.leq(rs, wanted)) {
                    chosen.emplace_back(names[i], r);
                    enumerate(i + 1);
                    chosen.pop_back();
                }
            }
        };
        enumerate(0);

        for (const TraceEnv &e : envs) {
            ++g.envsTotal;
            if (gamma.count(e)) ++g.envsRoundtrip;
        }
    }
    return g;
}

    return out.str();
```

```cpp
// 符号格（Sign lattice, spa 第 4 章）：把整数的具体值按"正负号"分五类。
//   ⊥（不可达/无信息） < −、0、+（三者互不可比） < ⊤（三者皆可能）

#pragma once

#include <string>

#include "lattice.hpp"

// 同一符号域的 Lattice<int> 形态：供通用构造（lift/product/maps/…）组装使用。
Lattice<int> signLatticeDomain();

// 编码：⊥=-2, −=-1, 0=0, +=1, ⊤=2。
// 用整数编码只是存储便利；序关系不是整数大小，join 必须查 join 表。
constexpr int SBOT = -2;
constexpr int SMINUS = -1;
constexpr int SZERO = 0;
constexpr int SPLUS = 1;
constexpr int STOP = 2;

std::string signShow(int s);

// 符号格的三要素：判定相等、偏序、最小上界。
// 后面所有单调框架的算法只依赖这三个操作（及 top/bot 边界）。
struct SignLattice {
    int top = STOP;
    int bot = SBOT;

    bool eq(int a, int b) const { return a == b; }
    bool leq(int a, int b) const;
    int join(int a, int b) const;
};

// 抽象算术：每个操作都对应整数运算"按符号分类"后的最小上界。
// 例如 +:(+,−)→⊤，因为正整数加负整数可能是 −、0 或 +。

int sSub(int a, int b);
int sMul(int a, int b);
int sDiv(int a, int b);  // 除数符号含 0 时按 ⊥ 处理（具体程序在此抛错/中止）

// 比较运算在 TIP 中产生 0/1：抽象结果恒为 {0,+}=⊤（⊥ 仍吸收）。
int sCompare(int a, int b);
```

```cpp
// file: src/sign.cpp
#include "sign.hpp"

#include <array>

namespace tip {

Lattice<int> signLatticeDomain() {
    SignLattice s;
    return Lattice<int>{
        STOP, SBOT,
        [](int a, int b) { return a == b; },
        [=](int a, int b) { return s.leq(a, b); },
        [=](int a, int b) { return s.join(a, b); }};
}

std::string signShow(int s) {
    switch (s) {
        case SBOT: return "⊥";
        case SMINUS: return "−";
        case SZERO: return "0";
        case SPLUS: return "+";
        case STOP: return "⊤";
    }
    return "?";
}

bool SignLattice::leq(int a, int b) const {
    if (a == SBOT || b == STOP) return true;   // 底最小、顶最大
    if (b == SBOT || a == STOP) return a == b; // 越过底/顶的唯一可能是相等
    return a == b;                             // −、0、+ 三者互不可比
}

int SignLattice::join(int a, int b) const {
    if (a == b) return a;
    if (a == SBOT) return b;                   // ⊥ ⊔ x = x
    if (b == SBOT) return a;
    return STOP;                               // 其余组合（含 −/0/+ 两两）= ⊤
}

namespace {

// 加法符号表（行=左操作数 [−,0,+,⊤]，列=右操作数）。
constexpr std::array<std::array<int, 4>, 4> ADD_TABLE = {{
    //  −      0      +      ⊤
    {{SMINUS, SMINUS, STOP,  STOP }},  // −
    {{SMINUS, SZERO,  SPLUS, STOP }},  // 0
    {{STOP,   SPLUS,  SPLUS, STOP }},  // +
    {{STOP,   STOP,   STOP,  STOP }},  // ⊤
}};

// 乘法符号表：同号得 +，异号得 −，任何一边是 0 得 0。
constexpr std::array<std::array<int, 4>, 4> MUL_TABLE = {{
    //  −      0      +      ⊤
    {{SPLUS,  SZERO,  SMINUS, STOP }},  // −
    {{SZERO,  SZERO,  SZERO,  SZERO}},  // 0
    {{SMINUS, SZERO,  SPLUS,  STOP }},  // +
    {{STOP,   SZERO,  STOP,   STOP }},  // ⊤
}};

int idx(int s) { return s + 1; }  // −(-1)→0, 0→1, +(1)→2, ⊤(2)→3

}  // namespace

int sAdd(int a, int b) {
    if (a == SBOT || b == SBOT) return SBOT;
    return ADD_TABLE[idx(a)][idx(b)];
}

int sSub(int a, int b) {
    if (a == SBOT || b == SBOT) return SBOT;
    // a − b = a + (−b)：−、+ 互换，0/⊤ 不变。
    const int negB = b == SMINUS ? SPLUS : b == SPLUS ? SMINUS : b;
    return ADD_TABLE[idx(a)][idx(negB)];
}

int sMul(int a, int b) {
    if (a == SBOT || b == SBOT) return SBOT;
    return MUL_TABLE[idx(a)][idx(b)];
}

int sDiv(int a, int b) {
    if (a == SBOT || b == SBOT) return SBOT;
    if (b == SZERO) return SBOT;  // 除以确定的 0：该路径具体不可行（抛错中止）
    // 排除"除数可能为 0"的情形后，商的符号规律与乘法相同。
    if (b == STOP) {
        // 除数 ∈ {−,0,+}：0 排除，剩下 {−,+}；结果符号对 −/+ 分别讨论后取 join。
        return sAdd(sMul(a, SMINUS), sMul(a, SPLUS));
    }
    return MUL_TABLE[idx(a)][idx(b)];
}

int sCompare(int a, int b) {
    if (a == SBOT || b == SBOT) return SBOT;
    return STOP;  // 比较结果只可能是 0 或 1：{0,+} 在本格中即 ⊤
}

}  // namespace tip
```

```cpp
// file: src/lattice.hpp
// 格的统一接口与四类通用构造（spa 第 4 章）。
// 一个"格"只需提供：顶/底两个边界、相等判定、偏序、最小上界。
// 提升(lift)、积(product)、映射(maps)、幂集(powerset)能把简单格组装成
// 程序状态所需的复合格——抽象环境就是"变量集合 → 值格"的映射格。
#pragma once

#include <functional>
#include <map>
#include <optional>
#include <set>
#include <tuple>
#include <utility>

namespace tip {

template <class A>
struct Lattice {
    A topV;
    A botV;
    std::function<bool(const A &, const A &)> eqF;
    std::function<bool(const A &, const A &)> leqF;
    std::function<A(const A &, const A &)> joinF;

    const A &top() const { return topV; }
    const A &bot() const { return botV; }
    bool eq(const A &a, const A &b) const { return eqF(a, b); }
    bool leq(const A &a, const A &b) const { return leqF(a, b); }
    A join(const A &a, const A &b) const { return joinF(a, b); }
};

// ---- 提升：给 A 加一个新底 ⊥=nullopt（"还没有值"） ----
template <class A>
Lattice<std::optional<A>> lift(const Lattice<A> &l) {
    using O = std::optional<A>;
    return Lattice<O>{
        O{l.top()}, O{std::nullopt},
        [](const O &a, const O &b) { return a == b; },
        [l](const O &a, const O &b) {
            if (!b.has_value()) return a == b;        // ⊥ 最小
            if (!a.has_value()) return true;
            return l.leq(*a, *b);
        },
        [l](const O &a, const O &b) {
            if (!a.has_value()) return b;
            if (!b.has_value()) return a;
            return O{l.join(*a, *b)};
        }};
}

// ---- 积：分量各自取 join，序为逐分量序 ----
template <class T, std::size_t... Is, class LTuple>
T tupleJoin(std::index_sequence<Is...>, const LTuple &lats, const T &a, const T &b) {
    return T{std::get<Is>(lats).join(std::get<Is>(a), std::get<Is>(b))...};
}
template <class T, std::size_t... Is, class LTuple>
bool tupleLeq(std::index_sequence<Is...>, const LTuple &lats, const T &a, const T &b) {
    return (... && std::get<Is>(lats).leq(std::get<Is>(a), std::get<Is>(b)));
}

template <class... As>
Lattice<std::tuple<As...>> product(const Lattice<As> &... ls) {
    using T = std::tuple<As...>;
    auto lats = std::make_tuple(ls...);
    T topT{ls.top()...};
    T botT{ls.bot()...};
    return Lattice<T>{
        std::move(topT), std::move(botT),
        [](const T &a, const T &b) { return a == b; },
        [lats](const T &a, const T &b) {
            return tupleLeq<T>(std::make_index_sequence<sizeof...(As)>{}, lats, a, b);
        },
        [lats](const T &a, const T &b) {
            return tupleJoin<T>(std::make_index_sequence<sizeof...(As)>{}, lats, a, b);
        }};
}

// ---- 映射：固定键集上逐点 join；键缺失按底处理 ----
template <class K, class V>
Lattice<std::map<K, V>> maps(const Lattice<V> &l, const std::set<K> &keys) {
    using M = std::map<K, V>;
    M topM, botM;
    for (const K &k : keys) {
        topM.emplace(k, l.top());
        botM.emplace(k, l.bot());
    }
    auto getOrBot = [&botM](const M &m, const K &k) {
        auto it = m.find(k);
        if (it != m.end()) return it->second;
        return botM.at(k);
    };
    return Lattice<M>{
        topM, botM,
        [](const M &a, const M &b) { return a == b; },
        [=](const M &a, const M &b) {
            for (const K &k : keys)
                if (!l.leq(getOrBot(a, k), getOrBot(b, k))) return false;
            return true;
        },
        [=](const M &a, const M &b) {
            M r;
            for (const K &k : keys) r.emplace(k, l.join(getOrBot(a, k), getOrBot(b, k)));
            return r;
        }};
}

// ---- 幂集：join=并，meet=交，序=包含；顶=给定全集（默认为空集） ----
template <class K>
Lattice<std::set<K>> powerset(const std::set<K> &universe = {}) {
    using S = std::set<K>;
    return Lattice<S>{
        universe, S{},
        [](const S &a, const S &b) { return a == b; },
        [](const S &a, const S &b) {
            for (const K &k : a)
                if (!b.count(k)) return false;
            return true;
        },
        [](const S &a, const S &b) {
            S r = a;
            r.insert(b.begin(), b.end());
            return r;
        }};
}

}  // namespace tip
```

```cpp
// file: src/ast_build.cpp
#include "ast_build.hpp"

#include <utility>
#include <vector>

namespace tip {

std::unique_ptr<ProgramA> AstBuilder::build(TIPParser::ProgramContext *tree) {
    auto program = std::make_unique<ProgramA>();
    for (auto *fc : tree->function()) program->funs.push_back(buildFun(fc));
    return program;
}

std::unique_ptr<FunDecl> AstBuilder::buildFun(TIPParser::FunctionContext *ctx) {
    auto f = std::make_unique<FunDecl>();
    f->name = ctx->IDENT()->getText();
    if (ctx->params()) {
        for (auto *p : ctx->params()->IDENT()) f->params.push_back(p->getText());
    }
    if (ctx->varDecls()) {
        for (auto *v : ctx->varDecls()->IDENT()) f->vars.push_back(v->getText());
    }

    std::vector<std::unique_ptr<Stmt>> body;
    for (auto *sc : ctx->stmt()) body.push_back(buildStmt(sc));
    f->body = std::make_unique<BlockS>(std::move(body));

    f->ret = std::make_unique<ReturnS>(buildExpr(ctx->expr()));
    return f;
}

std::unique_ptr<Expr> AstBuilder::buildLvalue(TIPParser::LvalueContext *lv) {
    std::unique_ptr<Expr> base;
    std::string field;
    if (auto *d = dynamic_cast<TIPParser::DirectLvalueContext *>(lv)) {
        base = std::make_unique<VarRef>(d->IDENT(0)->getText());
        if (d->IDENT().size() == 2) field = d->IDENT(1)->getText();
    } else {
        auto *p = dynamic_cast<TIPParser::PointerLvalueContext *>(lv);
        base = std::make_unique<Deref>(buildExpr(p->expr()));
        if (p->IDENT()) field = p->IDENT()->getText();
    }
    if (!field.empty())
        return std::make_unique<FieldA>(std::move(base), std::move(field));
    return base;
}

std::unique_ptr<Expr> AstBuilder::buildExpr(TIPParser::ExprContext *ctx) {
    if (auto *c = dynamic_cast<TIPParser::IntExprContext *>(ctx))
        return std::make_unique<IntLit>(std::stoi(c->INT()->getText()));
    if (auto *c = dynamic_cast<TIPParser::VarExprContext *>(ctx))
        return std::make_unique<VarRef>(c->IDENT()->getText());
    if (dynamic_cast<TIPParser::InputExprContext *>(ctx))
        return std::make_unique<InputE>();
    if (dynamic_cast<TIPParser::NullExprContext *>(ctx))
        return std::make_unique<NullE>();
    if (auto *c = dynamic_cast<TIPParser::ParenExprContext *>(ctx))
        return buildExpr(c->expr());

    if (auto *c = dynamic_cast<TIPParser::AddExprContext *>(ctx)) {
        const BOp op = c->PLUS() ? BOp::Add : BOp::Sub;
        return std::make_unique<Binop>(op, buildExpr(c->expr(0)), buildExpr(c->expr(1)));
    }
    if (auto *c = dynamic_cast<TIPParser::MulExprContext *>(ctx)) {
        const BOp op = c->STAR() ? BOp::Mul : BOp::Div;
        return std::make_unique<Binop>(op, buildExpr(c->expr(0)), buildExpr(c->expr(1)));
    }
    if (auto *c = dynamic_cast<TIPParser::CmpExprContext *>(ctx)) {
        const BOp op = c->GT() ? BOp::Gt : BOp::Eq;
        return std::make_unique<Binop>(op, buildExpr(c->expr(0)), buildExpr(c->expr(1)));
    }
    if (auto *c = dynamic_cast<TIPParser::NegExprContext *>(ctx)) {
        // TIP 没有负数字面量 token，-E 即 0-E。
        return std::make_unique<Binop>(BOp::Sub, std::make_unique<IntLit>(0),
                                       buildExpr(c->expr()));
    }
    if (auto *c = dynamic_cast<TIPParser::CallExprContext *>(ctx)) {
        std::vector<std::unique_ptr<Expr>> args;
        if (c->args())
            for (auto *a : c->args()->expr()) args.push_back(buildExpr(a));
        return std::make_unique<CallE>(buildExpr(c->expr()), std::move(args));
    }
    if (auto *c = dynamic_cast<TIPParser::FieldExprContext *>(ctx))
        return std::make_unique<FieldA>(buildExpr(c->expr()), c->IDENT()->getText());
    if (auto *c = dynamic_cast<TIPParser::DerefExprContext *>(ctx))
        return std::make_unique<Deref>(buildExpr(c->expr()));
    if (auto *c = dynamic_cast<TIPParser::AddrExprContext *>(ctx))
        return std::make_unique<AddrOf>(c->IDENT()->getText());
    if (auto *c = dynamic_cast<TIPParser::AllocExprContext *>(ctx))
        return std::make_unique<AllocE>(buildExpr(c->expr()));
    if (auto *c = dynamic_cast<TIPParser::RecExprContext *>(ctx)) {
        std::vector<std::pair<std::string, std::unique_ptr<Expr>>> fields;
        for (auto *fc : c->field())
            fields.emplace_back(fc->IDENT()->getText(), buildExpr(fc->expr()));
        return std::make_unique<RecLit>(std::move(fields));
    }
    return nullptr;  // 解析成功时不会到达
}

std::unique_ptr<Stmt> AstBuilder::buildStmt(TIPParser::StmtContext *ctx) {
    if (auto *c = dynamic_cast<TIPParser::AssignStmtContext *>(ctx))
        return std::make_unique<AssignS>(buildLvalue(c->lvalue()), buildExpr(c->expr()));
    if (auto *c = dynamic_cast<TIPParser::OutputStmtContext *>(ctx))
        return std::make_unique<OutputS>(buildExpr(c->expr()));
    if (auto *c = dynamic_cast<TIPParser::IfStmtContext *>(ctx)) {
        std::unique_ptr<Stmt> els;
        if (c->stmt().size() == 2) els = buildStmt(c->stmt(1));
        return std::make_unique<IfS>(buildExpr(c->expr()), buildStmt(c->stmt(0)),
                                     std::move(els));
    }
    if (auto *c = dynamic_cast<TIPParser::WhileStmtContext *>(ctx))
        return std::make_unique<WhileS>(buildExpr(c->expr()), buildStmt(c->stmt()));
    if (auto *c = dynamic_cast<TIPParser::BlockStmtContext *>(ctx)) {
        std::vector<std::unique_ptr<Stmt>> ss;
        for (auto *sc : c->stmt()) ss.push_back(buildStmt(sc));
        return std::make_unique<BlockS>(std::move(ss));
    }
    return nullptr;  // 解析成功时不会到达
}

std::unique_ptr<ProgramA> buildAst(TIPParser::ProgramContext *tree) {
    return AstBuilder{}.build(tree);
}

}  // namespace tip
```

```cpp
// 符号表与名字解析：把 AST 上的每个 VarRef 绑定到它的声明
// （函数 / 参数 / 局部变量），同时产出未声明、重复声明诊断。

#include <map>
#include <string>
#include <vector>

#include "ast.hpp"

namespace tip {

struct Symbol {

    std::vector<Diag> errors;
    std::map<const VarRef *, const Symbol *> uses;  // 解析成功的使用点
```

```cpp
// file: src/symtab.cpp
#include "symtab.hpp"

#include <utility>

namespace tip {

namespace {

// 解析器在遍历 AST 的同时完成绑定与诊断收集。
struct Resolver {
    Bindings bindings;
    Scope *current = nullptr;
    const FunDecl *owner = nullptr;

    void declare(const std::string &name, Symbol::Kind kind) {
        if (current->table.count(name)) {
            bindings.errors.push_back({"error: redeclared '" + name + "'"});
            return;  // 保留先声明者，后声明被忽略
        }
        current->table.emplace(name, Symbol{kind, name, owner});
    }

    void resolveExpr(const Expr *e) {
        if (const auto *x = dynamic_cast<const VarRef *>(e)) {
            const Symbol *s = current->lookup(x->name);
            if (!s) {
                bindings.errors.push_back({"error: undeclared '" + x->name + "'"});
            } else {
                bindings.uses[x] = s;
            }
            return;
        }
        if (const auto *x = dynamic_cast<const Binop *>(e)) {
            resolveExpr(x->l.get());
            resolveExpr(x->r.get());
            return;
        }
        if (const auto *x = dynamic_cast<const CallE *>(e)) {
            resolveExpr(x->callee.get());
            for (const auto &a : x->args) resolveExpr(a.get());
            return;
        }
        if (const auto *x = dynamic_cast<const Deref *>(e)) return resolveExpr(x->e.get());
        if (const auto *x = dynamic_cast<const AllocE *>(e)) return resolveExpr(x->e.get());
        if (const auto *x = dynamic_cast<const FieldA *>(e)) {
            resolveExpr(x->e.get());  // 字段名不是变量，无需解析
            return;
        }
        if (const auto *x = dynamic_cast<const RecLit *>(e)) {
            for (const auto &f : x->fields) resolveExpr(f.second.get());
            return;
        }
        // IntLit / InputE / AddrOf / NullE：无变量使用。
    }

    void resolveStmt(const Stmt *s) {
        if (const auto *x = dynamic_cast<const AssignS *>(s)) {
            resolveExpr(x->target.get());
            resolveExpr(x->value.get());
            return;
        }
        if (const auto *x = dynamic_cast<const OutputS *>(s)) return resolveExpr(x->e.get());
        if (const auto *x = dynamic_cast<const IfS *>(s)) {
            resolveExpr(x->cond.get());
            resolveStmt(x->then.get());
            if (x->els) resolveStmt(x->els.get());
            return;
        }
        if (const auto *x = dynamic_cast<const WhileS *>(s)) {
            resolveExpr(x->cond.get());
            resolveStmt(x->body.get());
            return;
        }
        if (const auto *x = dynamic_cast<const BlockS *>(s)) {
            for (const auto &st : x->ss) resolveStmt(st.get());
            return;
        }
        if (const auto *x = dynamic_cast<const ReturnS *>(s)) return resolveExpr(x->e.get());
    }
};

}  // namespace

const Symbol *Scope::lookup(const std::string &name) const {
    auto it = table.find(name);
    if (it != table.end()) return &it->second;
    return parent ? parent->lookup(name) : nullptr;
}

Bindings resolveNames(ProgramA &program) {
    Resolver resolver;
    resolver.bindings.global = Scope(nullptr);
    Scope *global = &resolver.bindings.global;

    // 第一遍：所有函数名进入全局作用域。
    for (const auto &f : program.funs) {
        if (global->table.count(f->name)) {
            resolver.bindings.errors.push_back({"error: redeclared '" + f->name + "'"});
            continue;
        }
        global->table.emplace(f->name, Symbol{Symbol::Fun, f->name, f.get()});
    }

    // 第二遍：每个函数开自己的作用域，父作用域是全局表；
    // 作用域所有权交给 Bindings，遍历结束后符号依然存活。
    for (const auto &f : program.funs) {
        auto functionScope = std::make_unique<Scope>(global);
        resolver.current = functionScope.get();
        resolver.owner = f.get();

        for (const std::string &p : f->params) resolver.declare(p, Symbol::Param);
        for (const std::string &v : f->vars) resolver.declare(v, Symbol::Local);

        resolver.resolveStmt(f->body.get());
        resolver.resolveStmt(f->ret.get());

        resolver.current = nullptr;
        resolver.bindings.scopes.push_back(std::move(functionScope));
    }
    return std::move(resolver.bindings);
}

}  // namespace tip
```

```cpp
// file: src/cfg.cpp
#include "cfg.hpp"

#include <map>
#include <set>
#include <sstream>
#include <vector>

#include "pretty.hpp"

namespace tip {
namespace {

// 两遍构造：第一遍按 AST 先序给所有程序点分配固定编号；第二遍连边。
// 先编号再连边，是为了让编号严格按源码顺序（连边时若先构造后继节点，
// 后继会抢在前面编号），从而输出与程序点编号都是确定的。
class CfgBuilder {
public:
    explicit CfgBuilder(const ProgramA &program) : program_(program) {}

    Cfg run() {
        Cfg cfg;
        for (const auto &fun : program_.funs) {
            FunCfg fc;
            cur_ = &fc;
            cur_->name = fun->name;
            nextId_ = 1;
            stmtId_.clear();

            const int entry = addNode(CfgNode::Kind::Entry);
            cur_->entry = entry;
            numberStmt(fun->body.get());
            const int retId = addNode(CfgNode::Kind::Return, fun->ret.get());
            const int exitId = addNode(CfgNode::Kind::Exit);
            cur_->exitNode = exitId;

            // 连边：语句构造返回它自己的入口点集合；空块没有节点，直接透传后继。
            std::vector<int> bodyEntries = wireStmt(fun->body.get(), {retId});
            if (bodyEntries.empty()) bodyEntries = {retId};
            link(entry, bodyEntries);
            link(retId, {exitId});

            // set 去重并排序：CFG 边不允许重复，输出顺序固定。
            std::set<std::pair<int, int>> uniq(cur_->edges.begin(), cur_->edges.end());
            cur_->edges.assign(uniq.begin(), uniq.end());
            cfg.funs.push_back(std::move(*cur_));
        }
        return cfg;
    }

private:
    const ProgramA &program_;
    FunCfg *cur_ = nullptr;
    int nextId_ = 1;
    std::map<const Stmt *, int> stmtId_;

    int addNode(CfgNode::Kind kind, const Stmt *stmt = nullptr) {
        const int id = nextId_++;
        cur_->nodes.emplace(id, CfgNode{id, kind, stmt});
        return id;
    }

    // ---- 第一遍：编号 ----
    void numberStmt(const Stmt *s) {
        if (const auto *b = dynamic_cast<const BlockS *>(s)) {
            for (const auto &x : b->ss) numberStmt(x.get());
            return;
        }
        if (const auto *x = dynamic_cast<const IfS *>(s)) {
            stmtId_[x] = addNode(CfgNode::Kind::Branch, x);
            numberStmt(x->then.get());
            numberStmt(x->els.get());
            return;
        }
        if (const auto *x = dynamic_cast<const WhileS *>(s)) {
            stmtId_[x] = addNode(CfgNode::Kind::Branch, x);
            numberStmt(x->body.get());
            return;
        }
        if (dynamic_cast<const AssignS *>(s)) {
            stmtId_[s] = addNode(CfgNode::Kind::Assign, s);
            return;
        }
        if (dynamic_cast<const OutputS *>(s)) {
            stmtId_[s] = addNode(CfgNode::Kind::Output, s);
        }
    }

    // ---- 第二遍：连边。返回进入该语句时首先到达的程序点集合 ----
    std::vector<int> wireStmt(const Stmt *s, const std::vector<int> &succ) {
        if (const auto *b = dynamic_cast<const BlockS *>(s)) {
            std::vector<int> cur = succ;
            for (auto it = b->ss.rbegin(); it != b->ss.rend(); ++it)
                cur = wireStmt(it->get(), cur);
            return cur;
        }
        if (const auto *x = dynamic_cast<const IfS *>(s)) {
            const int n = stmtId_[x];
            std::vector<int> targets = wireStmt(x->then.get(), succ);
            if (targets.empty()) targets = succ;
            if (x->els) {
                std::vector<int> e = wireStmt(x->els.get(), succ);
                if (e.empty()) e = succ;
                targets.insert(targets.end(), e.begin(), e.end());
            } else {
                targets.insert(targets.end(), succ.begin(), succ.end());
            }
            link(n, targets);
            return {n};
        }
        if (const auto *x = dynamic_cast<const WhileS *>(s)) {
            const int n = stmtId_[x];
            // 循环体执行完回到条件点；空体时条件点连一条自边（等于死循环）。
            std::vector<int> bodyEntries = wireStmt(x->body.get(), {n});
            if (bodyEntries.empty()) bodyEntries = {n};
            link(n, bodyEntries);
            link(n, succ);
            return {n};
        }
        const int n = stmtId_[s];
        link(n, succ);
        return {n};
    }

    void link(int from, const std::vector<int> &to) {
        for (int t : to) cur_->edges.emplace_back(from, t);
    }
};

const char *kindName(CfgNode::Kind kind) {
    switch (kind) {
        case CfgNode::Kind::Entry: return "entry";
        case CfgNode::Kind::Exit: return "exit";
        case CfgNode::Kind::Assign: return "assign";
        case CfgNode::Kind::Output: return "output";
        case CfgNode::Kind::Branch: return "branch";
        case CfgNode::Kind::Return: return "return";
    }
    return "?";
}

}  // namespace

Cfg buildCfg(const ProgramA &program) { return CfgBuilder(program).run(); }

    for (const FunCfg &f : cfg.funs) {
        out << "== " << f.name << " ==\n";

            out << "  " << id << ": " << kindName(node.kind);
            if (node.stmt) out << "  " << printStmtLine(*node.stmt);
            out << "\n";
        }
        out << "edges:\n";
        for (const auto &[a, b] : f.edges) out << "  " << a << " -> " << b << "\n";
    }
    return out.str();
}
```

```cpp
// file: src/pretty.cpp
#include "pretty.hpp"

#include <string>

namespace tip {

namespace {

// 表达式打印为前缀式：运算符与符号的对照表。
std::string exprText(const Expr *e) {
    if (const auto *x = dynamic_cast<const IntLit *>(e)) return std::to_string(x->v);
    if (const auto *x = dynamic_cast<const VarRef *>(e)) return x->name;
    if (dynamic_cast<const InputE *>(e)) return "input";
    if (dynamic_cast<const NullE *>(e)) return "null";

    if (const auto *x = dynamic_cast<const Binop *>(e)) {
        const char *sym = "+";
        switch (x->op) {
            case BOp::Add: sym = "+"; break;
            case BOp::Sub: sym = "-"; break;
            case BOp::Mul: sym = "*"; break;
            case BOp::Div: sym = "/"; break;
            case BOp::Gt: sym = ">"; break;
            case BOp::Eq: sym = "=="; break;
        }
        return "(" + std::string(sym) + " " + exprText(x->l.get()) + " " +
               exprText(x->r.get()) + ")";
    }
    if (const auto *x = dynamic_cast<const CallE *>(e)) {
        std::string s = "(call " + exprText(x->callee.get());
        for (const auto &a : x->args) s += " " + exprText(a.get());
        return s + ")";
    }
    if (const auto *x = dynamic_cast<const Deref *>(e))
        return "(* " + exprText(x->e.get()) + ")";
    if (const auto *x = dynamic_cast<const AddrOf *>(e)) return "(& " + x->name + ")";
    if (const auto *x = dynamic_cast<const AllocE *>(e))
        return "(alloc " + exprText(x->e.get()) + ")";
    if (const auto *x = dynamic_cast<const FieldA *>(e))
        return "(. " + exprText(x->e.get()) + " " + x->field + ")";
    if (const auto *x = dynamic_cast<const RecLit *>(e)) {
        std::string s = "{";
        for (size_t i = 0; i < x->fields.size(); ++i) {
            if (i) s += ", ";
            s += x->fields[i].first + ": " + exprText(x->fields[i].second.get());
        }
        return s + "}";
    }
    return "<unknown expr>";
}

std::string indent(int level) { return std::string(static_cast<size_t>(level) * 2, ' '); }

// 语句打印带缩进，一条语句一行（块内多行）。
void stmtText(const Stmt *s, int level, std::string &out) {
    if (const auto *x = dynamic_cast<const AssignS *>(s)) {
        out += indent(level) + exprText(x->target.get()) + " = " +
               exprText(x->value.get()) + " ;\n";
        return;
    }
    if (const auto *x = dynamic_cast<const OutputS *>(s)) {
        out += indent(level) + "output " + exprText(x->e.get()) + " ;\n";
        return;
    }
    if (const auto *x = dynamic_cast<const ReturnS *>(s)) {
        out += indent(level) + "return " + exprText(x->e.get()) + " ;\n";
        return;
    }
    if (const auto *x = dynamic_cast<const IfS *>(s)) {
        out += indent(level) + "if (" + exprText(x->cond.get()) + ")\n";
        stmtText(x->then.get(), level + 1, out);
        if (x->els) {
            out += indent(level) + "else\n";
            stmtText(x->els.get(), level + 1, out);
        }
        return;
    }
    if (const auto *x = dynamic_cast<const WhileS *>(s)) {
        out += indent(level) + "while (" + exprText(x->cond.get()) + ")\n";
        stmtText(x->body.get(), level + 1, out);
        return;
    }
    if (const auto *x = dynamic_cast<const BlockS *>(s)) {
        out += indent(level) + "{\n";
        for (const auto &st : x->ss) stmtText(st.get(), level + 1, out);
        out += indent(level) + "}\n";
        return;
    }
    out += indent(level) + "<unknown stmt>\n";
}

}  // namespace

std::string printExpr(const Expr *e) { return exprText(e); }

std::string printProgram(const ProgramA &program) {
    std::string out;
    for (const auto &f : program.funs) {
        std::string paramList;
        for (size_t i = 0; i < f->params.size(); ++i) {
            if (i) paramList += ",";
            paramList += f->params[i];
        }
        out += f->name + "(" + paramList + ") {\n";
        if (!f->vars.empty()) {
            out += indent(1) + "var ";
            for (size_t i = 0; i < f->vars.size(); ++i) {
                if (i) out += ",";
                out += f->vars[i];
            }
            out += " ;\n";
        }
        // 函数体是 BlockS；打印其内部语句而不是再嵌一层花括号。
        const auto *body = dynamic_cast<const BlockS *>(f->body.get());
        for (const auto &st : body->ss) stmtText(st.get(), 1, out);
        stmtText(f->ret.get(), 1, out);
        out += "}\n";
    }
    return out;
}

// 单行形式：CFG 节点标签等"节点旁边写一句话"的场合使用。
std::string printStmtLine(const Stmt &stmt) {
    std::string out;
    stmtText(&stmt, 0, out);
    if (!out.empty() && out.back() == '\n') out.pop_back();
    return out;
}

}  // namespace tip
```

```cpp
// file: src/irgen.hpp
// LLVM IR 生成：把 AST 翻译成 LLVM Module。
// 本章只覆盖整数核心：算术、比较、input/output、if/while、直接函数调用；
```

```cpp
// file: src/irgen.cpp
#include "irgen.hpp"

#include <stdexcept>
#include <utility>
#include <vector>

#include "llvm/IR/BasicBlock.h"
#include "llvm/IR/Constants.h"
#include "llvm/IR/DerivedTypes.h"
#include "llvm/IR/Function.h"
#include "llvm/IR/Verifier.h"
#include "llvm/Support/raw_ostream.h"

using namespace llvm;

namespace tip {

IRGen::IRGen()
    : ctx(std::make_unique<LLVMContext>()),
      mod(std::make_unique<Module>("tip", *ctx)),
      b(std::make_unique<IRBuilder<>>(*ctx)) {
    // 运行时入口先声明：input 无参返回 i32，output 吃一个 i32。
    auto *i32 = Type::getInt32Ty(*ctx);
    rtInput_ = mod->getOrInsertFunction(
        "tip_input", FunctionType::get(i32, false));
    rtOutput_ = mod->getOrInsertFunction(
        "tip_output", FunctionType::get(Type::getVoidTy(*ctx), {i32}, false));
}

namespace {

// TIP 的 main 改名 tip_main：真正的 @main 是我们生成的 C 入口。
std::string emitName(const std::string &name) {
    return name == "main" ? "tip_main" : name;
}

}  // namespace

void IRGen::gen(const ProgramA &program, const Bindings &resolved) {
    bindings = &resolved;

    // 先创建全部函数（含类型），函数体互相前向调用时也能查到声明。
    auto *i32 = Type::getInt32Ty(*ctx);
    for (const auto &f : program.funs) {
        std::vector<Type *> args(f->params.size(), i32);
        auto *ft = FunctionType::get(i32, args, false);
        Function::Create(ft, Function::ExternalLinkage,
                         emitName(f->name), *mod);
    }

    for (size_t i = 0; i < program.funs.size(); ++i) {
        const auto &f = program.funs[i];
        cur = f.get();
        genFun(f.get(), resolved.scopes[i].get());
    }

    const FunDecl *mainFun = nullptr;
    for (const auto &f : program.funs)
        if (f->name == "main") mainFun = f.get();
    if (!mainFun) throw std::runtime_error("program has no main");
    genWrapper(mainFun);
}

void IRGen::genFun(const FunDecl *f, Scope *scope) {
    auto *fn = llvm::cast<Function>(mod->getFunction(emitName(f->name)));
    auto *entry = BasicBlock::Create(*ctx, "entry", fn);
    b->SetInsertPoint(entry);

    // 形参：alloca 槽位 + 存入实参；var 局部：alloca + 零初始化。
    for (size_t j = 0; j < f->params.size(); ++j) {
        const Symbol *s = &scope->table.at(f->params[j]);
        auto *slot = b->CreateAlloca(b->getInt32Ty(), nullptr, f->params[j]);
        b->CreateStore(fn->getArg(j), slot);
        locals[s] = slot;
    }
    for (const std::string &v : f->vars) {
        const Symbol *s = &scope->table.at(v);
        auto *slot = b->CreateAlloca(b->getInt32Ty(), nullptr, v);
        b->CreateStore(b->getInt32(0), slot);
        locals[s] = slot;
    }

    stmt(f->body.get());
    b->CreateRet(expr(f->ret->e.get()));
}

Value *IRGen::expr(const Expr *e) {
    if (const auto *x = dynamic_cast<const IntLit *>(e))
        return ConstantInt::get(b->getInt32Ty(), x->v, true);

    if (const auto *x = dynamic_cast<const VarRef *>(e)) {
        const Symbol *s = bindings->uses.at(x);
        return b->CreateLoad(b->getInt32Ty(), locals.at(s), x->name);
    }

    if (dynamic_cast<const InputE *>(e))
        return b->CreateCall(rtInput_);

    if (const auto *x = dynamic_cast<const Binop *>(e)) {
        Value *l = expr(x->l.get());
        Value *r = expr(x->r.get());
        switch (x->op) {
            case BOp::Add: return b->CreateAdd(l, r);
            case BOp::Sub: return b->CreateSub(l, r);
            case BOp::Mul: return b->CreateMul(l, r);
            case BOp::Div: return b->CreateSDiv(l, r);
            case BOp::Gt: {
                Value *p = b->CreateICmpSGT(l, r);
                return b->CreateZExt(p, b->getInt32Ty());
            }
            case BOp::Eq: {
                Value *p = b->CreateICmpEQ(l, r);
                return b->CreateZExt(p, b->getInt32Ty());
            }
        }
    }

    if (const auto *x = dynamic_cast<const CallE *>(e)) {
        const auto *nameUse = dynamic_cast<const VarRef *>(x->callee.get());
        if (!nameUse)
            throw std::runtime_error("ch12: 间接调用留待第 44 章");
        const Symbol *s = bindings->uses.at(nameUse);
        if (s->kind != Symbol::Fun)
            throw std::runtime_error("ch12: 间接调用留待第 44 章");
        auto *callee = mod->getFunction(emitName(s->name));
        std::vector<Value *> args;
        for (const auto &a : x->args) args.push_back(expr(a.get()));
        return b->CreateCall(callee, args);
    }

    throw std::runtime_error("ch12: 指针与记录构造留待第 44 章");
}

void IRGen::stmt(const Stmt *s) {
    if (const auto *x = dynamic_cast<const AssignS *>(s)) {
        const auto *target = dynamic_cast<const VarRef *>(x->target.get());
        if (!target)
            throw std::runtime_error("ch12: 经指针/字段写入留待第 44 章");
        const Symbol *sym = bindings->uses.at(target);
        b->CreateStore(expr(x->value.get()), locals.at(sym));
        return;
    }

    if (const auto *x = dynamic_cast<const OutputS *>(s)) {
        b->CreateCall(rtOutput_, {expr(x->e.get())});
        return;
    }

    if (const auto *x = dynamic_cast<const IfS *>(s)) {
        Function *fn = b->GetInsertBlock()->getParent();
        auto *thenBB = BasicBlock::Create(*ctx, "then", fn);
        auto *elseBB = BasicBlock::Create(*ctx, "else", fn);
        auto *mergeBB = BasicBlock::Create(*ctx, "merge", fn);

        Value *cc = b->CreateICmpNE(expr(x->cond.get()), b->getInt32(0));
        b->CreateCondBr(cc, thenBB, elseBB);

        b->SetInsertPoint(thenBB);
        stmt(x->then.get());
        if (!b->GetInsertBlock()->getTerminator()) b->CreateBr(mergeBB);

        b->SetInsertPoint(elseBB);
        if (x->els) {
            stmt(x->els.get());
            if (!b->GetInsertBlock()->getTerminator()) b->CreateBr(mergeBB);
        } else {
            b->CreateBr(mergeBB);
        }
        b->SetInsertPoint(mergeBB);
        return;
    }

    if (const auto *x = dynamic_cast<const WhileS *>(s)) {
        Function *fn = b->GetInsertBlock()->getParent();
        auto *header = BasicBlock::Create(*ctx, "wh.cond", fn);
        auto *bodyBB = BasicBlock::Create(*ctx, "wh.body", fn);
        auto *exitBB = BasicBlock::Create(*ctx, "wh.exit", fn);

        b->CreateBr(header);
        b->SetInsertPoint(header);
        Value *cc = b->CreateICmpNE(expr(x->cond.get()), b->getInt32(0));
        b->CreateCondBr(cc, bodyBB, exitBB);

        b->SetInsertPoint(bodyBB);
        stmt(x->body.get());
        if (!b->GetInsertBlock()->getTerminator()) b->CreateBr(header);

        b->SetInsertPoint(exitBB);
        return;
    }

    if (const auto *x = dynamic_cast<const BlockS *>(s)) {
        for (const auto &st : x->ss) stmt(st.get());
        return;
    }

    if (const auto *x = dynamic_cast<const ReturnS *>(s))
        b->CreateRet(expr(x->e.get()));
}

void IRGen::genWrapper(const FunDecl *mainFun) {
    // C 入口：按 TIP main 形参数目读 input，再调用 tip_main。
    // 不命名为 main——MinGW 目标会向 main 注入对 CRT 符号 __main 的调用。
    auto *fn = Function::Create(FunctionType::get(b->getInt32Ty(), false),
                                Function::ExternalLinkage, "tip_entry", *mod);
    auto *entry = BasicBlock::Create(*ctx, "entry", fn);
    b->SetInsertPoint(entry);

    std::vector<Value *> args;
    for (size_t j = 0; j < mainFun->params.size(); ++j)
        args.push_back(b->CreateCall(rtInput_));
    Value *r = b->CreateCall(mod->getFunction("tip_main"), args);
    b->CreateRet(r);
}

bool IRGen::verify() const {
    std::string err;
    llvm::raw_string_ostream os(err);
    bool bad = llvm::verifyModule(*mod, &os);
    os.str();
    return !bad;
}

std::string IRGen::dump() const {
    std::string out;
    llvm::raw_string_ostream os(out);
    mod->print(os, nullptr);
    return os.str();
}
```

```cpp
// file: src/jitrun.cpp
#include "jitrun.hpp"

#include <cstdint>
#include <stdexcept>

#include "llvm/ExecutionEngine/JITSymbol.h"
#include "llvm/ExecutionEngine/Orc/Core.h"
#include "llvm/ExecutionEngine/Orc/LLJIT.h"
#include "llvm/ExecutionEngine/Orc/ThreadSafeModule.h"
#include "llvm/Support/TargetSelect.h"

using llvm::StringRef;
using llvm::JITSymbolFlags;
using llvm::orc::ExecutorSymbolDef;
using llvm::JITTargetAddress;
using llvm::jitTargetAddressToFunction;
using llvm::pointerToJITTargetAddress;
using llvm::orc::LLJITBuilder;
using llvm::orc::SymbolMap;
using llvm::orc::ThreadSafeModule;
using llvm::orc::absoluteSymbols;

namespace tip {
namespace {

// JIT 模块通过这两个宿主函数与外界交换数据。
const std::vector<int> *inQueue = nullptr;
std::vector<int> *outQueue = nullptr;
size_t inPos = 0;

extern "C" int32_t tip_input() {
    if (inPos >= inQueue->size()) return 0;
    return (*inQueue)[inPos++];
}

extern "C" void tip_output(int32_t value) {
    outQueue->push_back(value);
}

void initNative() {
    // 进程内只初始化一次。
    static const bool ready = [] {
        llvm::InitializeNativeTarget();
        llvm::InitializeNativeTargetAsmPrinter();
        return true;
    }();
    (void)ready;
}

[[noreturn]] void fail(llvm::Error e) {
    std::string text = llvm::toString(std::move(e));
    throw std::runtime_error(text);
}

}  // namespace

std::vector<int> runJit(IRGen gen, const std::vector<int> &inputs) {
    initNative();
    std::vector<int> outputs;
    inQueue = &inputs;
    outQueue = &outputs;
    inPos = 0;

    auto jitOrErr = LLJITBuilder().create();
    if (!jitOrErr) fail(jitOrErr.takeError());
    auto jit = std::move(*jitOrErr);

    auto defineHost = [&](StringRef name, void *addr) {
        SymbolMap symbols;
        symbols[jit->mangleAndIntern(name)] = ExecutorSymbolDef(
            llvm::orc::ExecutorAddr::fromPtr(addr), JITSymbolFlags());
        if (llvm::Error e =
                jit->getMainJITDylib().define(absoluteSymbols(symbols)))
            fail(std::move(e));
    };
    defineHost("tip_input", reinterpret_cast<void *>(&tip_input));
    defineHost("tip_output", reinterpret_cast<void *>(&tip_output));

    ThreadSafeModule tsm(std::move(gen.mod), std::move(gen.ctx));
    if (llvm::Error e = jit->addIRModule(std::move(tsm)))
        fail(std::move(e));

    auto mainAddr = jit->lookup("tip_entry");
    if (!mainAddr) fail(mainAddr.takeError());
    auto *entry = jitTargetAddressToFunction<int (*)()>(mainAddr->getValue());
    entry();

    return outputs;
}

}  // namespace tip
```

```cpp
//                    计算 α(C) 与单调符号分析 A，检验 α(C) ⊑ A，
//                    并在代表域 {-1,0,1} 上检验 S ⊆ γ(α(S))；
//                    末尾用 LLVM ORC JIT 真实执行每条流做交叉对照。
//   --emit-ir FILE : 打印未优化的 LLVM 模块
#include <fstream>
#include <iostream>
#include <memory>
#include <sstream>
#include <string>
#include <vector>

#include "TIPLexer.h"
#include "TIPParser.h"
#include "antlr4-runtime.h"

#include "ast_build.hpp"
#include "cfg.hpp"
#include "coll.hpp"
#include "irgen.hpp"
#include "jitrun.hpp"

class CollectErrorListener : public antlr4::BaseErrorListener {
public:
    std::vector<std::string> messages;

    void syntaxError(antlr4::Recognizer *, antlr4::Token *, size_t line,
                     size_t column, const std::string &msg,
                     std::exception_ptr) override {
        messages.push_back("syntax error line " + std::to_string(line) + ":" +
                           std::to_string(column) + " " + msg);
    }
};

namespace {

struct Parsed {
    std::unique_ptr<tip::ProgramA> ast;
    tip::Bindings bindings;
};

Parsed parseFile(const std::string &path) {
    std::ifstream src(path);
    if (!src) {
        std::cerr << "cannot open " << path << '\n';
        std::exit(1);
    }
    antlr4::ANTLRInputStream input(src);
    TIPLexer lexer(&input);
    antlr4::CommonTokenStream tokens(&lexer);
    TIPParser parser(&tokens);

    CollectErrorListener errors;
    lexer.removeErrorListeners();
    parser.removeErrorListeners();
    lexer.addErrorListener(&errors);
    parser.addErrorListener(&errors);

    TIPParser::ProgramContext *tree = parser.program();
    if (!errors.messages.empty()) {
        for (const std::string &m : errors.messages) std::cout << m << '\n';
        std::exit(2);
    }

    Parsed result;
    result.ast = tip::buildAst(tree);
    result.bindings = tip::resolveNames(*result.ast);
    if (!result.bindings.errors.empty()) {
        for (const tip::Diag &d : result.bindings.errors)
            std::cout << d.text << '\n';
        std::exit(3);
    }
    return result;
}

std::vector<int> parseStream(const std::string &line) {
    std::vector<int> values;
    std::istringstream ss(line);
    int v;
    while (ss >> v) values.push_back(v);
    return values;
}

// 输入流清单：与程序同目录的 FILE.inputs，每行一条流；# 开头是注释。
std::vector<std::vector<int>> loadStreams(const std::string &path) {
    std::vector<std::vector<int>> streams;
    std::ifstream in(path);
    if (!in) return streams;
    std::string line;
    while (std::getline(in, line)) {
        size_t a = line.find_first_not_of(" \t\r\n");
        if (a == std::string::npos || line[a] == '#') continue;
        streams.push_back(parseStream(line));
    }
    return streams;
}

std::string showInts(const std::vector<int> &xs) {
    std::ostringstream out;
    for (size_t i = 0; i < xs.size(); ++i)
        out << (i ? " " : "") << xs[i];
    return out.str();
}

}  // namespace

int main(int argc, char **argv) {
    if (argc >= 3 && std::string(argv[1]) == "--check") {
        Parsed p = parseFile(argv[2]);
        tip::Cfg cfg = tip::buildCfg(*p.ast);

        std::vector<std::vector<int>> streams =
            loadStreams(std::string(argv[2]) + ".inputs");
        if (streams.empty()) streams.push_back({});

        tip::CollectResult collected =
            tip::collect(cfg, *p.ast, streams);
        std::cout << tip::printCollect(cfg, *p.ast, collected);

        const std::vector<int> representatives{-1, 0, 1};
        tip::GaloisResult gal =
            tip::runGalois(cfg, *p.ast, collected, representatives);
        std::cout << tip::printGalois(gal);

        std::cout << "== concrete JIT cross-check (LLVM ORC) ==\n";
        for (const std::vector<int> &stream : streams) {
            tip::IRGen gen;
            gen.gen(*p.ast, p.bindings);
            if (!gen.verify()) {
                std::cerr << "generated module failed verification\n";
                return 1;
            }
            std::vector<int> outputs = tip::runJit(std::move(gen), stream);
            std::cout << "  inputs [" << showInts(stream) << "] -> outputs ["
                      << showInts(outputs) << "]\n";
        }

        return gal.theoremHolds ? 0 : 1;
    }

    if (argc >= 3 && std::string(argv[1]) == "--emit-ir") {
        Parsed p = parseFile(argv[2]);
        tip::IRGen gen;
        gen.gen(*p.ast, p.bindings);
        if (!gen.verify()) {
            std::cerr << "generated module failed verification\n";
            return 1;
        }
        std::cout << gen.dump();
        return 0;
    }

    std::cerr << "usage: tipa --check FILE | tipa --emit-ir FILE\n";
    return 1;
}
```
