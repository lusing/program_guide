无穷逻辑把「公式可以有任意（序数）长度的合取析取、量词可以绑定无穷多
个变元」变成严肃的证明论对象；决定逻辑把「博 Ramsey 式的量词依赖」
（Henkin 依赖量词）纳入矢列演算。这一章的压轴定理 23.34 是全书最惊人
的等价之一：**决定性公理 AD 成立 ⟺ M-可定义决定逻辑的切消定理成立**——
「证明论强度」与「集合论公理」直接挂钩。机器面取两块可判定的核心：打包
规则的形状纪律与有限博弈的决定性搜索。

## 一、从有穷到无穷（§22 语言与动机）

量词的 **arity** 从 1 推广到任意序数 α：Q^f x₍<α₎ 的 f:α→{∀,∃} 指定每个
变元位的量词种类——**齐次**（f 恒 ∀ 或恒 ∃）与**异质**（混合）分道扬镳。
Henkin 1959 依赖量词 (Vx∃u/Vy∃v)（u 只依赖 x、v 只依赖 y）是异质典型；
Mostowski 定理（Prop 24.9）证明它不能由普通 ∀∃ 表达——良基性（「< 非
良基」）恰好可由依赖量词表达而一阶量词不行。AD（决定性公理，p209）：对
每个公式 ψ，Q^f x₍<ω₎ψ 与 Q^f̄x₍<ω₎¬ψ（f̄ 对偶）**恰一为真**——每个
「无穷对局」都有人赢。

## 二、无穷矢列演算：打包规则与高度条件

Def 22.1 的演算与有穷 LK 的三点差异：

**其一，打包规则**——一次处理**一族**主公式 {·}_{λ<γ}。有穷 LK 的每条
规则只动一个主公式（γ=1 特例）；无穷演算把「同型公式批量分解」做成规则
形状。机器件的一步账（γ=2）：

```coq
Definition packAndSample : bool :=
  match ([1; 10], [20]), ([2; 11], [21]), ([10; 11; 1; 2], [20; 21]) with
  | (G1, D1), (G2, D2), (G, D) =>
      andb (existsb' (Nat.eqb 1) G)           (* A1 在下矢列 *)
           (andb (existsb' (Nat.eqb 2) G)     (* A2 同时在下矢列 *)
                 ...）
  end%nat.
```

与单主公式版（`singleAndSample`）并排——「一次消费两份」与「一次一份」
的对照就是打包的全部内容。〔⚠〕打包规则的逐条细形在扫描件中残缺（上下
标剥落），docs 按「规则族语法+语义可靠性论证+书中例 22.2/23.3 的用法」
三重交叉重构——机器面只覆盖已确证的形状。

**其二，证明=半证明+本征变元三条件**（p214-215）：(I) 同一变元多处本征
则主公式相同且阶相同；(II) 存在**高度函数** h（值域序数）：本征变元的
高度**大于其主公式中一切自由变元**的高度；(III) 本征变元不入末矢列。
高度条件取代有穷情形「本征变元不出现在其下矢列」的局部条件——是无穷
演算的灵魂。例 22.2 依赖选择公理 ∀x∃yF(x,y)→∀x₀∃x₁∃x₂…∧ₙF(xₙ,xₙ₊₁)
的无切证明里 h(aₘ)=m——本征变元沿证明**逐层抬升**：

```coq
Definition hDep (m : nat) : nat := m.     (* h(a_m) = m *)
Example heightAcct : heightOkSample = true.   (* a_m 高于参数 a_0，逐层账 *)
```

**其三，g.c. 广义切**（Def 22.13）：割公式以「公式集的分割」整体出现——
它是无穷演算中控制 cut 的正确抽象（普通 cut 是特例），齐次系统中 g.c.
可容许（Prop 22.14）。

## 三、完备性与切消：Maehara-Takeuti

定理 22.16/22.17（Maehara-Takeuti）：齐次无穷逻辑**可靠**（对每个前束形
做 Skolem 函数化+按高度良序本征变元做超穷代换）且**完备**（Schütte 式
归约树：五阶段轮转，∀:left 用论域项例化、∀:right/∃:left 用 Skolem 项）——
两相合并：**可证⟺无切可证**（切消作为推论）。这与 34 章归约树同一哲学
的无穷版。**Malitz 反例**（文档线）：插值定理在齐次无穷语言中**失效**——
用 F,G 隐定义两个良序集间的保序双射，若有插值子则可在齐次语言中显定义
该映射，但定义公式的长度给序型设上界——矛盾。插值的「信息守恒律」需要
有穷性付费。Lopez-Escobar 的 L_{ω₁,ω} 片段恢复插值（Problem 22.21，
可数 ∧/∨——文档线）。

## 四、决定逻辑 DL：AD 的矢列化（§23）

Def 23.2 的 DL 把 ∀/∃ 换成任意异质量词 Q^f，左右规则**不再对偶**（Q:left
的 ∃ 位是本征变元、Q:right 的 ∀ 位是本征变元——依赖结构不对称）。**例
23.3 是全节的起点：AD 本身在 DL 中可证**——→Q^fx A(x)∨Q^f̄x¬A(x) 两分支
各引一个分量、高度 h(a_λ)=1+λ 排好（`adShape` 账例的形状：两分支共享
同一变元=条件 I 的现场）。定理 23.4 的可靠性在**决定结构**上成立——
Skolem 化时博弈双方各持策略函数（f(γ)=∃ 位引入 g^{f,γ}(x_{<γ})：自变元
只取依赖位之前的 ∀ 位——**依赖图就是策略依赖**）；定理 23.11 加决定性
实例到前件得对决定结构的完备性。

**Gale-Stewart 定理**（23.13）：ZF 内存在双方均无胜策略的集合（策略
总数=连续统，超穷对角构造逐个「戳破」每个策略对）。开博弈（胜负有穷步
内判定）则**必决定**——例 24.14 的矢列证明自最内层逐对引入 ∀∃（本征
变元条件 6) 逐条核查）。机器面的 `gsEval` 做有限深度的完全搜索——
**Zermelo 定理**（1913，有限博弈必有一方必胜）：

```coq
Example gsFirstWins : gsEval 4 0 [] = Some true.   (* I 抢攻双 t *)
Example gsSecondWins : gsEval2 4 0 [] = Some false. (* II 擒 I 的双 t *)
Example zermeloTotal : ... = true.                 (* 二择一总成立 *)
```

后向归纳：叶子=胜集命中或 depth 耗尽（开博弈语义：未命中 I 的胜前缀
集=II 胜）；内点=当前方选最优分支。Prolog 版（`gsEval` 的回溯实现）输出
两局的判定。「有限开博弈的完全决定」是「无穷开博弈决定性」的可计算影子
——也正是 23.13 与例 24.14 之间的阶梯。

## 五、AD⟺切消：定理 23.34 与 BDL

**定理 23.34**（p260-261）：M⊨ZF+DC 传递且 P(ω)∈M，则 **AD 在 M 成立
⟺ M-可定义决定逻辑的切消定理成立**。

- (⇒)：AD 给决定结构的可靠+完备（23.31+23.33）⟹有效矢列无切可证。
- (⇐) 的机制（全书最漂亮的一步反证）：设 AD 失败——取非决定集 A 作谓词，
  两个 succedent-齐次矢列 ∀x₀∃y₀∀x₁∃y₁…A 与 ∃x₀∀y₀…¬A 配上原子账
  Γ₀→Δ₀ 均**有效**（「A 的解释偏离给定集」或「解释正确但双方均无胜策
  略」两情形都通）⟹ 若切消成立则两者无切可证 ⟹ cut 合成 Γ₀→Δ₀ 可证
  ——荒谬（原子矛盾）。**AD 失败=两条切不可消**。切消定理（一个「语法」
  陈述）与决定性（一个「组合」陈述）在 M 内等价——证明论强度与集合论
  公理直接互译。这也解释了为什么 LK 的左右对称性是切消的根基：异质量词
  破坏对称性，除非决定性把对称性**买回来**。

**BDL**（Def 23.38，Borel 决定逻辑）：异质量词限 arity ω、只作用于无量词
矩阵。Prop 23.39：(1) BDL 可推⟹有效——**恰为 Borel determinacy**（Martin
1975）；(3) 由 (1)+(2) 得 **BDL 切消成立**。但注意路线：这是「有效性⟹
无切可证」的语义路线；**BDL 切消的直接证明论证明至今 open**——书末点题
「直接证明将给出 Borel determinacy 的新证并对射影确定性有启发」。一个
open problem 停在「语义证法已知、语法证法缺失」——正是 Gentzen 传统
「构造性切消」价值的最后注脚。

## 小结

打包规则与高度条件把矢列演算拉伸到无穷；Maehara-Takeuti 完备性让切消
成为推论（Malitz 反例同时提醒：插值的有穷性代价）；决定逻辑用「左右不
对称的量词规则」装下博弈依赖；AD⟺切消把证明论与集合论焊在一起；BDL
停在「语义切消已得、构造切消 open」。下一章（54 章）回到有穷世界的归结
自动证明；76 章的序数图一瞥（文档线）将继续「更强系统需要更高序数」的
主线。92 章（μ 演算）与本章的无穷规则是同一主题（不动点量词）的两个
入口。
