# 29 CTL* 与表达能力的天梯

> 对书：H&R §3.5（两层语法/图 3.23/分离反例）/ §3.5.1（布尔组合的
> 可翻译性）/ §3.5.2（过去算子）
> 通道：C/L（两层语法+三组分离现场）

35 章讲 CTL、36 章讲 LTL 时各留了一句「另一边表达不了」。
本章把这句话变成**定理级现场**：H&R 图 3.23 的表达能力图——
LTL 与 CTL **互不包含**，CTL* 把两者都收编。机器面交付三组
**分离公式**：在精心构造的模型上，一侧真值成立、另一侧失败
——表达能力差距不再是口头断言，而是可判定的具体账本。

## 为什么需要 CTL*：两边的痛处

LTL 的痛（H&R §3.5 开篇例）：想表达「所有**有 p 的路径**也有
q」——LTL 写 `F p → F q` ✓；CTL 被迫给每个 F 配 A/E，写
`AF p → AF q` 语义完全走样（「一切路径有 p ⟹ 一切路径有
q」——路径之间的关联被量词对撞掉了）。CTL 的痛：想表达
「存在一条路径永远可能 p」——`EG EF p` 轻松；LTL 的全称视角
说不出「存在路径」。**CTL* 的解法简单粗暴：拆掉「量词必须
成对」的语法约束**——时态算子可以裸连：

```text
A[(p U r) ∨ (q U r)]    沿所有路径：p 直到 r，或 q 直到 r
A[X p ∨ X X p]          沿所有路径：下一拍或下下拍有 p
E[G F p]                存在一条 p 无穷经常的路径
```

三者都不是 CTL（H&R 给出前两个中第一个有冗长的 CTL 等价式，
后两个没有）。CTL* = CTL 的量词自由 + LTL 的路径内推理。

## 两层语法：互嵌归纳

CTL* 的定义性特征是**两类公式互相递归**（H&R §3.5）：

```text
状态公式 φ ::= p | ⊥ | ¬φ | φ∧φ | A ψ | E ψ     （在状态上读）
路径公式 ψ ::= φ | ¬ψ | ψ∧ψ | X ψ | G ψ | F ψ | ψ U ψ （沿路径读）
```

机器件（`examples/29_ctlstar/ex38_ctlstar.v`，Lean 同构）：

```coq
Inductive sform : Type :=
| sAtom : nat -> sform | sNeg : sform -> sform
| sAnd  : sform -> sform -> sform
| sA    : pform -> sform | sE : pform -> sform

with pform : Type :=
| pState : sform -> pform | pNeg : pform -> pform
| pAnd   : pform -> pform -> pform
| pX     : pform -> pform | pG : pform -> pform
| pF     : pform -> pform | pU : pform -> pform -> pform.
```

**互嵌归纳 + 互嵌 Fixpoint 语义**：sem（状态层）与 psem（路径层）
互相调用，每个递归都在严格子公式上——与 36 章 lsat 同一合法性
来源，只是从一层变两层。两个片段一眼可见：**LTL** = 状态层只剩
`A ψ` 且 ψ 内不出现 A/E（全称外套）；**CTL** = 每个 X/G/F/U 前面
立刻跟 A/E（量词成对）。语义沿 36 章「路径=位置函数」配方，A/E
量化模型的路径集（`ispath m s pi`）。

## 图 3.23 四角：分离公式清单

| 角 | 公式 | 表达力位置 | 机器现场 |
|---|---|---|---|
| ② | `AG (p → AF q)` ≡ LTL `G(p → F q)` | 两边都能写 | — |
| ① | `AG EF p` | **CTL 有、LTL 无** | M ⊨ / M' ⊭ ✓ |
| ③ | `A[GF p → F q]` | **LTL 有、CTL 无** | 文档（公平性形态，37 章） |
| ④ | `E[G F p]` | **CTL* 独有** | M ⊨ / M' ⊭ ✓ |

（机器件注记：①④共用一对「路径子集」模型 M/M'，一箭双雕；
③是 37 章公平性的 GF 形态，其 CTL 不可表达性是 Emerson 定理
——元论证，见下节。）

## 分离现场 (a)：AG EF p 的路径子集论证

H&R 对①的证明是模型论的标准手术（机器件把它做实）：

```text
M：0 → {1(p 环), 2}；2 → {2, 1}      M'：0 → 2；2 → 2（自环）
```

**M ⊨ AG EF p**（`M_AGEFp`）：每个可达状态（0/1/2）都有路到
p 态 1——状态 0 走 0→1；状态 1 自身；状态 2 走 2→1。证明对
路径分类引理（M 的路径只经过 {0,1,2}）三分后逐个给见证路径。

**M' ⊭ AG EF p**（`M'_not_AGEFp`）：M' 从 0 出发只有唯一路径
0,2,2,2,…；在位置 1（状态 2）EF p 失败——2 的所有后继都是 2，
永远到不了 p。

**为什么这说明 LTL 写不出 AG EF p**（元论证）：M' 的路径集是
M 的**真子集**；LTL 公式 A[φ] 只对路径做全称量化——路径变少
只会让全称式更真。M ⊨ A[φ] ⟹ M' ⊨ A[φ]；但 AG EF p 恰好在
M 真、M' 假——所以 A[φ] ≠ AG EF p。∎（这个论证的形式化需要
「LTL 公式在路径子集下保持」的归纳引理——登记为边界。）

## 分离现场 (b)：E[G F p] 的 CTL* 独占

④的同款双模型（`M_EGFp`/`M'_not_EGFp`）：M 中走 0→1 进 p 环的
路径见证 `G F p`（每个位置之后都有 p——环上恒真）；M' 的唯一
路径 2 环上无 p，E 失败。**不可表达性**是 Emerson 与 Halpern-
Sistla 等的定理（CTL 的量词成对结构无法表达路径内的无穷经常性
——公平性语义的深层结构）；LTL 写不出则因为全称外套（E 无处
安放）。元论证，文档交付。

## 分离现场 (c)：FG p 与 AF AG p 的缝隙（Remark 3.18）

「给 LTL 公式的时态算子逐个补 A」的朴素翻译**不保语义**——
H&R 给的分离模型：

```text
N：0(p, 自环+出边) → 1(¬p) → 2(p 自环)
```

- **A[F G p] 成立**（`N_AFGp`）：N 的路径分两类（分类引理
  `N_paths`）——永驻 0 的（每位置都 p），或某刻经 1 进 2 环的
  （终将永远 p）。两类都 F G p。
- **A[F (AG p)] 失败**（`N_not_AFAGp`）：永驻 0 的路径永远停在
  状态 0，而 AG p 在 0 失败（存在离 0 的路径经 ¬p 的 1）——
  这条路径上 F(AG p) 无处兑现。

直觉总结：`F G p` 说「这条路径终将只剩 p」；`AF AG p` 说「一切
路径终将到达一个**从那里出发的一切路径**都只剩 p 的状态」——
后者要求「未来的所有分支」都干净，严格更强。同款缝隙还有
`X F p ≡ F X p ≡ AX AF p` 都真但 `AF AX p` 严格更强（H&R
Remark 3.18 第二例——「奇怪的语义」）。**这正是 37 章公平性
要外置机制的根源**：CTL 写不出 FG 形态。

## 布尔组合的救赎（§3.5.1，文档）

CTL 的路径公式**不许布尔组合**看似大限，实则可救——翻译引理：

```text
E[F p ∨ F q] ≡ EF[p ∧ EF q] ∨ EF[q ∧ EF p]
```

（「路径上先有 p 或先有 q」=「到 p 且从 p 还能到 q」或对称——
同时发生归两支皆真。）H&R 指出**嵌套路径模态**（③④那类 GF/X 链）
才是真不可表达的硬核。工程结论：写 CTL 规格时布尔组合随意写
（预处理器会翻），但公平性诉求必须走 CTL* 或模型层公平约束。

## 过去算子（§3.5.2，文档）

LTL/CTL* 还可加过去算子 Y（昨天）、O（曾经）、S（since）——
表达「曾经到达过坏状态」这类**追溯性**质。工程上少用的原因：
无界过去使自动机构造的状态空间膨胀，而大多数验证目标
（安全/活性）用未来算子已够。表达力上过去算子**不增加**
LTL 的可定义类（Gabbay 分离定理：过去未来混合式可等价改写为
纯未来式）——这是它与未来算子的根本不对称。

## 本章小结

- CTL* = 拆掉量词成对约束：两层语法互嵌归纳；LTL=全称外套
  片段、CTL=量词成对片段，都是 CTL* 的语法子集。
- 三组分离现场：AG EF p（路径子集论证）、E[GF p]（Emerson）、
  FG p vs AF AG p（分支 vs 路径的语义缝隙）——机器交付真值
  账本，不可表达性论证文档化。
- 路径分类引理是机器面的七成工作量（「永驻 X」与「或走或留」
  两型）；元论证需要「LTL 在路径子集下保持」引理——登记边界。
- 布尔组合可翻译、嵌套模态不可救——公平性必须出走 CTL*。
- 过去算子：表达力免费（Gabbay），工程上昂贵——少用。

## 坑位速记（本章实测）

- **Coq/Rocq**：
  - 互嵌归纳 + 互嵌 Fixpoint 一次通过（递归在子公式上）；
    Notation 定义的总公式**不能 unfold**（「Cannot coerce to
    an evaluable reference」）——全走 simpl；
  - `destruct (ispath …)` 的第二分量是 ∀ 界变量——**先
    specialize 步前提再 rewrite**（界变量遮蔽外层同名）；
  - `In x [2]` 给 `2 = x` 方程（元素在左）——喂等式目标要
    symmetry；不等式消灭用 exfalso+apply（0≠0 不是构造子
    歧义，discriminate 不收）；`discriminate` 裸调不收「假等式
    目标」（0 = 2）——要 `discriminate H`（假设形）或 lia；
  - 「或走或留」分类引理的右支（n 之后永驻 2）用偏移归纳
    （∀j, π(S n + j) = 2），k 换算 lia——直接对 k 归纳基例
    错位；
  - F 见证的 destruct 是**对偶**（∃j, ≤ ∧ …）——`[j [_ Hj]]`
    两层拆，直接 [j Hj] 会把合取留在假设里。
- **Lean**：
  - `mutual inductive`/`mutual def` 直接支持两层语法与语义；
  - 列表字面量是**逗号** `[1, 2]`（不是分号——本章 7 处笔误
    一次清）；`simp [模型名] at hs` 常把成员命题收成**单个
    反向等式**（`2 = π (i+1)`）——别 rcases，直接
    `first | exact hs | exact hs.symm`；
  - `rcases hs with E | E` 在 simp 化简后的单等式上会「dependent
    elimination failed」——simp 已把 ∨ 的 False 支消掉时剩的是
    等式不是析取；
  - `decide` 对含未约简 def 的成员命题不燃——`simp [路径名,
    模型名]` 全展开后收；
  - `simp only` 列表里多余定义触发 unusedSimpArgs **警告**
    （通道门禁）——逐个删；`abbrev` 的公式名留在 simp 列表里
    也是 unused（abbrev 不产生方程引理）；
  - `show 目标具体形` 定形再 rw——sem/psem 的 Fixpoint 应用
    不展开时 rewrite 找不到模式；
  - `cases j` 的 zero 支自带矛盾上界（hj1 : 1 ≤ 0）——omega
    直接收，比构造性论证便宜。
