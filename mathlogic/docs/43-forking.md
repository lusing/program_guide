42 章把「复杂度」做成了秩；本章把「关系」做成独立性。核心
公式一句话：**a 对 B（在 A 上）独立 ⟺ tp(a/B) 是 tp(a/A) 的
不分叉延拓 ⟺ RM 不降**。在 ω-稳定理论里这个三元关系获得
五条代数律（单调、传递、有限基、对称、自反），成为「模型的
线性代数」——维数论、交换图、Lascar 强型全部长在这副骨架上。
机器面继续用 E_inf 实验室（分叉=秩降的逐例）加 F₂⁴ 的线性
代数（维数公式的完整算术）。

## 一、分叉：秩的下降（§6.3 前半）

**定义**：q∈S(B) 是 p∈S(A)（A⊆B）的**分叉延拓**（forking
extension），如果 RM(q)<RM(p)。**Thm 6.3.2（存在）**：ω-稳定
理论里每个型都有不分叉延拓到任意 B——取「最小秩的延拓」，
再用「度耗尽」论证钉死它不再分叉。**型是定义性的**（Lemma
6.3.5-6.3.8）：p∈S(M) 的每个公式 φ(v,w) 有 M-参数的「定义
模式」d_pφ(w)——φ(v,b)∈p 的 b-集是 M-可定义的；这把型空间
的拓扑翻译回结构内部（39 章 Stone 空间的「可定义截面」）。
**stationary 型**（Cor 6.3.12-6.3.13）：度 1 的型在代数闭包
上延拓唯一——「无歧义的最小实现」。

**机器面 I**（`examples/43_forking/` 第 1 节）：元素编码 10c+j
（类 c 的第 j 点），`rmTP a A` 按范式给 tp(a/A) 的秩——a∈A
给 0、a 的类被 A 触及给 1、新鲜类给 2。`rank_descent` 的五联
账：新鲜 a 对不相干 A 保持 2；B 触及 a 的类（55 与 50 同类 5）
降至 1——**类被点名是第一次分叉**；B∋a 降至 0——**元素被
点名是彻底分叉**。`forks` 就是 RM 的严格下降判定。`nonforkW`
用「B 与 A 的类集之外的新鲜类」做见证：`nonfork_ext_exists`
验证 Thm 6.3.2 的逐例——独立 a 的新见证对一切 B⊇A 保持
RM=2（新鲜类永远供应充足——42 章 `fresh_beyond` 的同款引擎）。

E_inf 的分叉语义清晰可讲：**「分叉=信息追上你」**。a 住在
匿名类里时它满足「generic」的型（秩 2）；参数一旦提及它的
类，a 的型被压到「类内余有限」（秩 1）；a 本身被点名，秩归
0。一般 ω-稳定理论的分叉同此——**RM 的每一层坍缩对应一段
「可定义的确定化」**。

## 二、独立性五律与维数算术（§6.3 后半）

**独立性**（Def 6.3.15）：a ⌣|_A B ⟺ tp(a/B) 不在 A 上分叉。
五律（Lemma 6.3.16-6.3.21）：

- **单调**：a⌣|_A B、C⊆B ⟹ a⌣|_A C；
- **传递**：a⌣|_A b,c ⟺ a⌣|_A b 且 a⌣|_{A,b} c；
- **有限基**：a⌣|_A B ⟺ 对一切有限 B₀⊆B；
- **对称**：a⌣|_A b ⟺ b⌣|_A a（ω-稳定的礼物——一般稳定理论
  要到超稳定才有）；
- **自反**：a⌣|_A acl(A)（代数闭包不添信息）。

在强极小理论里这一切塌缩成**维数算术**（42 章 Thm 6.2.19 +
Ex 6.6.12）：a⌣|_A B ⟺ dim(A∪B∪{a})=dim(A∪B)+dim(A∪{a})−dim A
——「新元素贡献满维」。ACF 版（Ex 6.6.16）：a⌣|_F b ⟺ F(a)
与 F(b) 在 F 上自由（域论的自由=代数无关）——**模型论独立
性=域论代数无关性**，两条百年老河在此汇流。

**机器面 II**（第 2 节）：F₂⁴ 上的完整线性代数——`xorb4`
（逐位模 2 加法）、`addVec`（高斯消元式基底插入：按主元低位
归约）、`dimOf`（消元后的基长）、`spanOf`（对 xor 闭包到不动
点）、`interL`（元素表交）。**维数公式**（`dim_formula`）：
dim(U+V)+dim(U∩V)=dim U+dim V 在六对样本子空间上全验——
这是独立性对称律的算术面（维数对称地计数双方）。**独立性
刻画**（`ideq`）：维数相加 ⟺ 互不在对方张成中——五组样本
（独立对/依赖对/带基依赖）双向对账。教学注记：初版实现把
消元的**主元丢掉**（addVec 的 then 分支没保留 p）——维数全
线塌缩被机器抓出；这恰是「独立性=交换图」容易写错的镜像。

## 三、构造模型与素模型扩张（§6.4）

**构造序列**（Def 6.4.1）：(a_α) 是 M 在 A 上的构造，如果每个
a_α 实现孤立型 tp(a_α/A∪{a_β:β<α})——「每步都走孤立型」的
超限装配。**Thm 6.4.5（唯一性）**：构造模型在同构意义下由
构造序型决定；ω-稳定理论的**素模型扩张存在且唯一**（Thm
6.4.6-6.4.7：M⊨T、A⊆M，存在 N≼M 构造于 A 上——「最小初等
扩张」）。38 章「原子=素」的有限账在这里升级成超限装配：
孤立型的稠密性保证构造永不卡壳，RM 的良基性给装配定序。
**文档线**：唯一性的证明用「同型对齐+逐步互嵌」（39 章齐次
性的构造版）；这条定理是 46 章可数模型谱系与 Shelah 分类
程序的地基。

## 四、Morley 序列（§6.5）

**定义**：(aᵢ)_{i<κ} 是 A 上的 **Morley 序列**，如果每个 aᵢ
实现「A∪前项上的不分叉（孤立度 1）延拓」。三条性质：**独立**
（每项对前项独立）、**不可辨**（序列是 A 上的序不可辨列——
41 章的概念在稳定性里兑现）、**型恒定**（一切项实现同一
A-型）。Thm 6.5.2：Morley 序列是不可辨集（不止序不可辨——
置换也保持，Lemma 5.2.12-5.2.15 的稳定理论版）。Morley 序列
是「随机样本」的模型论化身：46-48 章的群论与几何论证里，
它承担「取一列互不干扰的 generic 点」的全部角色。

**机器面 III**（第 3 节）：`morleySeq` 逐元取「避开 A 与前项
类集的新鲜类」元素（独立选取的 E_inf 版）；`morley_
indiscernible` 双账：五元序列两两在 E-原子族上同 profile
（**不可辨**——41 章 `indisc2` 的同款检查）+每项对
A∪前缀独立（`indep` 逐元）。序列的「型恒定」由同 profile
直接给出。小而完整：**独立选取⟹不可辨**在五步序列上闭环。

## 坑位速记（本章实测）

- **addVec 消元别丢主元**：then 分支必须 `p :: addVec t
  (xorb4 v p)`——丢 p 使维数全线塌缩（机器一抓一个准）。
- **同类的两个编码**：E_inf 元素 10c+j——「B 触及 a 的类」
  的见证要真同类（55 与 50 同类 5；写成 35 就成了类 3，
  分叉不发生）。
- **嵌套样本元组投影**：Coq 三元组左结合——`fst (fst spec)`
  不是 `fst spec`；Lean 右结合——`spec.1.1`。两通道同构件
  时投影方向相反（38 章同坑再犯）。
- **Lean λ 体吞布尔运算符**：`!l.any fun x => p x && q`——
  `&& q` 溜进 λ 体；`(fun x => p x)` 必须加括号。带 let 的
  长表达式在 example 里失败而命名函数里通过的怪象多源于此。
- **lowbit 递归**：x/2 非结构递归——燃料版（`lowbitF`）；
  Lean 的 `let rec step` 燃料递减写 `step f s'`（不能重置
  常数）。

## 小结

本章把 42 章的秩变成关系：分叉=RM 下降（「信息追上你」的
三级降落账）、不分叉延拓永远存在（新鲜类引擎）、独立性五律
（维数公式的 F₂⁴ 全算术账）、构造模型与素模型扩张唯一（超限
装配的文档线）、Morley 序列（独立选取⟹不可辨的五元闭环）。
ω-稳定世界的「线性代数」就此配齐：维数是标量、独立性是
正交、分叉是投影、Morley 序列是正交基。下一章（44 章）把
这套代数装到**群**上：DCC 让可定义子群格变良基、泛型把
「几乎处处」变成秩最大、Zil'ber 不可分解定理把群从「大块
并」里捏出来——ω-稳定群是 Morley 秩理论最锋利的应用。
