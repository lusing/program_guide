106 章造好了集合论的公理机器（NBG）。本章把公理方法铺开成**多学科
的风景**：同一种「公理+推导」的骨架，在算术（PA/ACA₀/Tarski 实数）
与几何（欧几里得/希尔伯特）结出完全不同的果实——而把它们串在一起
的方法论线索是第 9 章的**同态与解释性证明**。

## 一、同态与解释：换坐标不换真理

书第 9 章的方法论先行（8.1 节）：**同态** f(a∘b)=f(a)*f(b)——运算
结构在映射下保持；**同构**=双射同态——两个系统是同一结构的两个坐
标系。例 8.2 的 (R⁺,×)≅(R,+) 经 log 是最经典的现场。机器面做有限
影子：

```coq
Definition z7mul (x y : nat) : nat := (x * y) mod 7.
Definition z6add (x y : nat) : nat := (x + y) mod 6.
Definition log3 (x : nat) : nat :=
  match x with
  | 1 => 0 | 3 => 1 | 2 => 2 | 6 => 3 | 4 => 4 | 5 => 5 | _ => 99
  end.

Example log_iso_hom :
  forallb (fun p =>
    Nat.eqb (log3 (z7mul (fst p) (snd p)))
            (z6add (log3 (fst p)) (log3 (snd p))))
    (flat_map (fun x => map (fun y => (x,y)) [1;2;3;4;5;6]) [1;2;3;4;5;6])
  = true.
```

Z₇* 的乘法群与 Z₆ 的加法群经 log₃ 同构——36 对乘法逐对兑换成加法。
93 章离散对数的密码学价值正是这个同构的**单向性**：小域查表容易、
大素数域算 log 难。

8.2 节的**解释性证明**（I-解释，引 Kohlenbach）是同构证明的推广：
「理论 T₁ 的定理经翻译函子变成理论 T₂ 的定理」——由此得到**相对
相容性**：T₂ 相容则 T₁ 相容（矛盾会翻译过去）。机器骨架：

```coq
Definition embed2 (n : nat) : nat := 2 * n.   (* 嵌入：n ↦ 2n *)

Example interp_preserves_trans : ...   (* 线序的传递性经嵌入保真 *)
```

13.10 节的 E→L→R 包容链（欧氏几何 E ⊂ 罗氏几何 L ⊂ 黎曼几何 R，
公理 13.13 用「L=E∪X₁、R=L∪X₂」的析取论证）与 Beltrami 1868 的
模型法（非欧直线=常曲率面的测地线）都是这条方法的运用——**「证明
相容」的最高技巧不是直证而是搬家**。

## 二、PA 的 1889 原文：公理如何长成构造原理

Peano 1889 年的九公理（书 9.8.1，含 N 谓词与后继记法）：

```coq
Example pa3 : Nat.eqb (S 0) 0 = false.               (* (3) x'≠0 *)
Example pa56 :
  forallb (fun x =>
    andb (Nat.eqb (x + 0) x)                         (* (5) x+0=x *)
          (Nat.eqb (x + S 3) (S (x + 3)))) ...       (* (6) x+y'=(x+y)' *)
```

公理 (5)-(8)（加乘的递推方程）在 Coq 的 nat 上**不是公理而是定义
方程**——`rfl` 直接兑现。最有深意的是公理 (9)：

```coq
Definition pa9_induction (P : nat -> Prop) :=
  P 0 -> (forall k, P k -> P (S k)) -> forall n, P n.
```

这与 `nat_ind` 的类型逐字母相同——**Peano 原文的二阶归纳公理**
（∀Y(Y0∧∀x(Yx→Yx')→∀xYx)，书 p117 的二阶性分析）在类型论里长成
了归纳类型的构造原理。91 章「公理变定理」的现象在此追溯到源头：
公理与构造原理的分界，取决于你站在哪个基础系统里说话。

**ACA₀**（9.8.2，二阶算术的逆数学基线）：PA+算术概括公理
∃X∀u(Xu↔φ(u))（φ 无二阶量词——侧条件！）：

```coq
Definition arithSample (u : nat) : bool := Nat.eqb (u mod 3) 0.
Definition compX (u : nat) : bool := arithSample u.

Example aca_comp_instance :
  map compX [0;1;2;3;6;9] = [true;false;false;true;true;true].
```

「3 的倍数集」由概括公理收编——φ 是算术公式（无集合量词）。侧条
件划出的层级（RCA₀ 只收可计算 φ、ACA₀ 收全部算术 φ）正是 70 章
相容性天梯的逆数学刻度。Tarski 实数 20 公理（9.8.3：序三律+Dedekind
连续+域公理）记文档线：前 19 条在 33 章有序域机器上逐条可验，4''
的 Dedekind 连续性是二阶条款——恰是 30 章 L-S 定理留给实数系的
「不可一阶化」印记。

## 三、欧几里得：开放的知识库

《几何原本》的 E 系统（9.9.1）：5 公设+5 公理+定义，**开放累积知
识库**——每证一命题入库作下一步的依据，滚出 465 个命题。命题 1.29
（平行线的内错角/同位角/同旁内角，例 9.16）的依赖链：

```coq
Definition euclidDeps : list (nat * list nat) :=
  [ (129, [105; 113; 115; 1001])      (* 1001=公设 I.5 *)
  ; (113, [101; 102; 1001]) ].
```

1.29←{公设 I.5, 命题 1.13, 命题 1.15, 公理 I.1}；1.13 与 1.15 又各
有依据。三步证明的重演（书 p120：同旁内角和 180°→邻角和 180°→
代换）记文档线——依赖链的结构恰是 Prolog 证明搜索的「开放知识库
+归结」形态。书 p121 的两个评注同样值得留档：E 的**完全性**未被证
明（哪些命题在它的射程内没有描述）；**非欧几何没有在逻辑上否定第
5 公设**（罗氏几何的定理推不出 ¬公设 5——两者可以同真，因为模型
不同——这正是 27 章相对相容性的语义面）。

## 四、希尔伯特与坐标模型：公理的算术兑现

希尔伯特 1899《几何基础》把几何要素**逻辑化**：五组公理（关联
I.1-I.8/顺序 II/合同 III/平行 IV/连续 V）取代「自明性」。机器面做
**关联公理的解析模型**——点=F₃²、线=线性方程的解集：

```coq
Definition points : list (nat * nat) :=
  [ (0,0); (0,1); (0,2); (1,0); (1,1); (1,2); (2,0); (2,1); (2,2) ].

Definition onLine (l : nat * (nat * nat)) (p : nat * nat) : bool :=
  Nat.eqb ((fst (snd l) * fst p + snd (snd l) * snd p + fst l) mod 3) 0.

Definition lines : list (nat * (nat * nat)) :=
  flat_map (fun ab => map (fun c => (c, ab)) [0;1;2])
    [ (0,1); (1,0); (1,1); (1,2) ].       (* 4 方向×3 截距=12 线 *)
```

（实现注记：F₃ 中 (a,b) 与 2(a,b) 定义同一条线——方向要去重，
8 个「方向」实为 4 个。这个坑是 24 线版全枚举失败后现形的——重复
表示的线对交出 3 个点。）

三条公理的全枚举验证：

```coq
(* I.1 两点至少一线过之（81 点对全查） *)
Example hilbert_I1 :
  forallb (fun pq =>
    existsb (fun l => andb (onLine l (fst pq)) (onLine l (snd pq))) lines)
  (flat_map (fun p => map (fun q => (p,q)) points) points)
  = true.

(* 两直线至多一交点（144 线对全查：平行 0 点、相交 1 点） *)
Example hilbert_two_lines_meet_once : ...

(* I.3 每线至少两点（F₃ 每线恰 3 点） *)
Example hilbert_I3 : ...
```

**这一节做了什么**：希尔伯特公理在 F₃² 上逐条兑现——「几何公理
相容」被归约为「算术（mod 3 的乘加）无矛盾」。这正是希尔伯特自己
的做法（书 p121 差别 (3)：「引进解析几何的方法，使许多几何量被代
数化表示」）——**坐标模型=相对相容性证明**，与 1 节的解释函子方
法同一骨架。顺序公理 II、合同公理 III 需要有序结构（F₃ 上的「介
于」关系可再定义——文档线）；V 组连续公理在有限域必然失效（Dedekind
连续需要无穷——有限模型是「几何的算术影子」而非全貌）。

## 五、公理系统的风景

| 系统 | 论域 | 公理 | 相容性押金 |
|---|---|---|---|
| PA 1889 | 自然数 | 9（二阶归纳） | ε₀ 序数分析（70 章） |
| ACA₀ | 数+集合 | PA+算术概括 | ω^ω |
| Tarski 实数 | 实数 | 20（含二阶连续） | 集合论 |
| 欧几里得 E | 点线面 | 5 公设+5 公理 | 欧氏内未证 |
| 希尔伯特 | 点线面 | 五组（I-V） | 算术（坐标模型） |
| NBG（106 章） | 类与集合 | 有限条 | 有限片段可机器化 |

公理方法的两个方向在此合流：**向上**（每门数学自己的公理系统——
本章的算术与几何）与**向下**（全部数学回到一个基础——106 章的集合
论、类型论指南的类型论）。100 章的四家解悖方案各自长出的公理系统
（ZFC/NF/类型论）都在这张桌子上吃饭。公理化不是终点——69 章起
的每一步（从 Frege 的九公理到希尔伯特的五组）都在提醒：**公理是
选择，选择是自由，自由的代价是相容性账单**。

## 小结

同态与解释性证明给了本章的方法论脊柱（换坐标不换真理）；PA 原文
九公理与归纳类型的对照揭示了「公理变构造原理」的机制；欧几里得
的开放知识库与希尔伯特的坐标模型展示了公理方法在几何的两代形态；
F₃² 上 9 点 12 线的全枚举把「几何公理的算术兑现」做成了可跑件。
下一章（108 章）回到同一性问题——公理系统之间的同构与解释正是
「结构主义」的技术面。
