第 32 章用 Vaught 测试判完备，第 33 章用超积「平均」结构。这一章
是第三条路、也是最 constructive 的一条：**把量词真的消掉**。理论 T
有量词消去（QE），如果每个公式都 T-等价于某个无量词公式——可定义
集因此被原子关系的布尔组合完全描述，模型的同构嵌入只要保住原子
关系就保住一切。DAG/ACF 的完备性在书里正是走这条路证的（ch 7），
36 章的实闭域接力。

## 一、判据：一次一个量词

书 §7 的两个定理把 QE 从「无穷多公式」压缩成可操作的任务：

**Th 7.7（判据）**：φ(v̄) T-等价于某无量词式 ⟺ φ 在 T 的任意两
个模型中、沿公共**子结构** A 的相同参数取值相同。无量词式在子结
构间自动保持（20 章深化的嵌入术语），所以 ⟸ 方向平凡；⇒ 方向用
图方法+紧致性。

**Lemma 7.8（一次一个）**：只需对形如 ∃w θ(v̄,w)（θ 无量词）的
公式找到无量词等价——一般公式对复杂度归纳，¬/∧ 不动，∃ 逐层剥。
合成的 **Cor 7.9 测试**：若对任意模型 M,N ⊨ T、公共子结构 A、
参数 ā∈A：θ(ā,b) 在 M 有解 b 则在 N 有解 c——则 T 有 QE。

机器面把这个测试的**内容**压缩到 DLO（无端点稠密线序）的单变量
存在式上做实：文字集 {z>x, z<y, z=x}，参数赋值 P。消去程序是纯
区间推理——下界族、上界族，等词锁定：

```coq
Definition qfcond (fs : list zlit) (P : nat -> nat) : bool :=
  match allGts fs, allLts fs with
  | [], _ => true
  | _, [] => true
  | _, u :: rest =>
      lmax 0 (map P (allGts fs)) <? lmin1 (P u) (map P rest)
  end.
```

完备方向——「有见证则区间条件成立」——是零公理定理：

```coq
Theorem qe_complete_dir : forall fs P,
  evEx fs P = true -> qfcond fs P = true.
```

（证明：`forallb_forall` 提取每个下界/上界文字，`lmax_ub`/`lmin1_lb`
把全体约束汇成最大下界 < z < 最小上界，`lia` 收尾——两条列表引理
`lmax0_in`/`lmin1_in` 保证极值确实落在约束表内。）

反向（区间条件⟹有见证）在真 DLO(ℚ,<) 中由**密度**保证：ℓ<u 即有
中介。机器面在采样链 [0;21) 上只能验证步长 ≥2 的赋值
（`between_agree` 的守卫），而**相邻性反例**正是密度公理的活标本：

```coq
Example adjacency_counter :
  andb (qfcond [zGt 0; zLt 1] (pv2 2 3))       (* 2 < 3：区间条件真 *)
       (negb (evEx [zGt 0; zLt 1] (pv2 2 3)))   (* 采样链无中介 *)
    = true.
```

有限采样永远模拟不了密度——这不是机器的缺陷，而是「DLO 无有限
模型」的另一种说法（30 章 dense_never_finite 的回声）。等词文字
单独成例：∃z(z=x∧z>y) ↔ x>y（`eq_lit_case`），等式把 z 钉死、区间
推理退化为一个比较。

## 二、ACF 的量词消去：Euclid 除法引擎

书 §7 对 **DAG** 与 **ACF_p** 各做一遍 QE。ACF 的引擎是代数的：
∃y (f(y)=0 ∧ …) 中，把 f 对其余多项式做 **Euclid 除法**，根的存在
性归结为 gcd 条件；「非常数多项式在代数闭域中有根」是燃料（代数
基本定理的一阶化身）。消到底，ACF_p 的可定义集全是多项式方程/不
等的布尔组合——于是 Th 7.24 区间：**ACF_p 完备**（与 32 章
Vaught 路线殊途同归）、模型完备。

机器面不重造除法引擎，而是把引擎的**输出性质**逐条验证：

**暴根表**（`f3_roots_table`）：Horner 求值 `pevalc` + 穷举
`rootsFp`——x²+1 在 F₃ 无根（−1=2 非平方剩余）、x²−1 两根 ±1、
x² 一根。这是 QE 的原子层：每个原子式的解集就是一张根表。

**扩域见证**（`f9_x2p1_root`）：F₉ = F₃[t]/(t²+1) 显式构造——元素
是二元组 (a,b)=a+bt，乘法 t²=−1：

```coq
Definition f9mul (a b : nat * nat) : nat * nat :=
  ((fst a * fst b + 2 * snd a * snd b) mod 3,
   (fst a * snd b + snd a * fst b) mod 3).
Example f9_x2p1_root : pevalF9 [1;0;1] (0,1) = (0,0).   (* (0,1)² = −1 *)
```

x²+1 在 F₃ 无根、在 F₉ 有根 (0,1)（且恰两根）——**「无根变有根」
正是代数闭包的方向**：ACF 的每个因子分解都发生在这样的扩域塔里，
量词消去引擎的每一步「找根」都在消费它。

**强极小性影子**（`strong_min_table`）：F₃ 上全部 9 个首一二次式
的根数 `[1;0;2;2;1;0;2;1;0]`——每行 ≤ deg=2，域大小 3。一维可定
义集是这些原子解集的布尔组合，每个都**有限（≤deg）或余有限**：
这就是 **strong minimality**（书 Def 7.18 区）的数值影子。 tame
在这里第一次有了精确形状：维数 1 的可定义世界只有「小有限」与
「几乎全」两种大小，没有中间地带——对照 64 章 Th(ℕ) 的可定义集
（算术层级，wild），36 章 o-minimality 把这条线画到实数上。

## 三、模型完备性：扩张即初等

QE 的副产品：**模型完备**（T 的任意扩张嵌入保持全部公式真值——
M⊆N 都是 T 的模型则 M ≺ N）。链条：QE ⟹ 模型完备（无量词式在
子结构保持）；模型完备 + 联合嵌入 ⟹ 完备。DAG/ACF/RCF 都在链条
上（Cor 7.22 区）。机器面对账留在 32 章 iso 件与 20 章嵌入深化的
延长线上：子结构保持是判据 Th 7.7 的 ⟸ 半边，完整归纳记文档级。

## 小结

量词消去把「理论说得完」（完备）升级为「理论算得动」：可定义集
= 原子布尔组合，判定问题的复杂度从任意公式坍缩到多项式方程组。
判据 7.7 + 一次一个量词 7.8 是方法论，DLO 的区间推理是入门实例
（完备方向零公理定理+相邻性反例揭示密度公理的角色），ACF 的
Euclid 引擎以暴根表/扩域见证/强极小性计数留下可计算的脚印。下一
章把同一台引擎开到有序域上：Tarski 的实闭域量词消去、半代数集、
o-minimality，以及 Hilbert 第 17 问题——tame 数学的全景。
