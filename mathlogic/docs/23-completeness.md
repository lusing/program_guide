# 23 完备性定理：Henkin 构造

> 对书：Mendelson §2.7 / EFT V / Huth&Ryan §1.4 命题版

可靠性与完备性是一对：可靠性（证明 ⟹ 有效）已在
06 章（矢列）与 02 章（判定器）机器化；本章文档化
完备性（有效 ⟹ 证明）的 Henkin 构造。

## 命题完备性（已机器化的对应物）

命题层的完备性 = 02 章判定器的双向：
`check f = false ⟹ 反赋值存在`（穷举见证）。
有效式必可证——因为命题证明空间有限可搜索。
06 章矢列演算的可靠性（零公理）是证明方向。

## 一阶完备性的 Henkin 构造（文档主线）

```
① 一致集 Γ 的语言加入亨金常量 c₀, c₁, ...
② 逐公式扩展：对每个 ∃x.A(x) ∈ Γ 加入见证常量 c
   —— Γ ⊆ Γ'，保持一致，且 Γ' 有见证性质
③ Lindenbaum 引理：把 Γ' 极大化成极大一致集 Γ*
④ Γ* 的项模型 M_Γ：论域 = 闭项；解释 = 从 Γ* 读出
⑤ 真值引理：M_Γ ⊨ A ⟺ A ∈ Γ*
⑥ 故 Γ 有模型 —— 一致 ⟹ 可满足
⑦ 逆否：有效 ⟹ 一致 ⟹ 有模型 ⟹（反证）可证
```

**机器化难点**（诚实边界）：步骤 ③ 的极大化是 Zorn 引理
（或选择公理）；步骤 ④ 的项模型在构造性类型论中需要
商类型（闭项模 Γ*-等价）。完整机器化是高等工程——
各家先例：

| 系统 | 形式化 | 规模 |
|---|---|---|
| **Coq** | `herbrand` / ILL 的完备性 | 相关逻辑的完备性（含 Henkin） |
| **Lean mathlib** | `FirstOrder/Completeness.lean` | 完整的一阶完备性（2024 合入）|
| **Isabelle AFP** | `Completeness_Theorem` | FOL 完备性（含强完备性）|

## 完备性的推论（文档）

- **紧致性**：Γ 的每个有限子集有模型 ⟹ Γ 有模型
  （Henkin 构造的直接产物）；
- **Löwenheim–Skolem**：可数语言的一致理论有可数模型
  （项模型就是可数的）；
- **存在 ≠ 构造**：完备性是经典定理——构造性类型论中
  Gödel–Gentzen 负翻译（11 章 Glivenko 的 FOL 版）恢复
  一部分，但并非全部推论构造有效。

## 21 章的 SMT 联系（文档）

完备性 ⟹ 有效式 r.e.（证明可枚举）+ Church ⟹ 非递归
——半可判定的两面在 21 章的判定层级中标记。**sledgehammer
与 z3 的正是不完备性上的工程学**：不可判定空间中，
有限的引理组合搜索何时命中（sat/unsat 的片段判定）与
何时沉默（超时）。

## 坑位速记（文档章）

- **负翻译与 Glivenko**（11 章）：命题层 ¬¬A 经典可证
  ⟹ A 直觉可证；FOL 层需要 Gödel 翻译（双重否定 +
  量词改写），16 章的 drinker_nn 是其单点预演；
- **紧致性的非构造性**：用紧致性证明「若每个有限子集
  可满足则全可满足」时，模型的存在是选择公理级别的——
  构造性类型论中该陈述减弱（子模型的存在需要更多信息）。
