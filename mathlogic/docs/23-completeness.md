# 23 完备性定理：Henkin 构造七步

> 对书：Mendelson §2.7 / EFT V / H&R §1.4（命题版对照）
> 通道：文档章（构造七步+推论+先例索引）

可靠性与完备性是一对：可靠性（证明 ⟹ 有效）已在 06 章
（矢列）与 02 章（判定器）机器化；本章讲透完备性（有效 ⟹
证明）的 **Henkin 构造**——20 世纪逻辑的第三块基石（前两块：
Gödel 不完备、Tarski 不可定义）。它缝合的正是 02 章开场
留下的那道缝：**语义与证毕**。

## 完备性在缝什么

02 章 Peirce 律现场：语义恒真、构造演算沉默——当时说
「这道缝由可靠性与完备性缝合」。可靠性方向（可推皆有效）
便宜：对推导归纳逐条核规则。完备性方向（有效皆可推）是
**存在性断言**——对每个有效式承诺一个证明存在，但构造
它的统一方法本身是个深刻的数学定理。哥德尔 1929 年博士
论文首证（弱式）；Henkin 1949 的重构把证明变成了**造模型**
的技术——本章路线。

战略转换值得单独一读：要证「有效 ⟹ 可证」，Henkin 证
**逆否**「不可证 ⟹ 有反模型」——即「一致 ⟹ 可满足」。
从「寻找证明」转向「构造模型」：前者在证明空间里捞针
（无穷），后者把「拒绝一切矛盾」的一致性**兑现**成一个
具体的世界。**一致性是模型的欠条，Henkin 是兑付行**。

## 构造七步（每步先说「防什么」）

```
① 一致集 Γ 的语言加入亨金常量 c₀, c₁, ...
② 逐公式扩展：对每个 ∃x.A(x) ∈ Γ 加入见证常量 c
   —— Γ ⊆ Γ'，保持一致，且 Γ' 有见证性质
③ Lindenbaum 引理：把 Γ' 极大化成极大一致集 Γ*
④ Γ* 的项模型 M_Γ：论域 = 闭项；解释 = 从 Γ* 读出
⑤ 真值引理：M_Γ ⊨ A ⟺ A ∈ Γ*
⑥ 故 Γ 有模型 —— 一致 ⟹ 可满足
⑦ 逆否：有效 ⟹ 一致 ⟹ 有模型 ⟹（反证）可证
```

**① 加常量（防什么：见证不够用）**。要给 ∃x.A(x) 造见证，
语言里可能没有足够的「名字」——预备一整个新鲜常量池。

**② 见证扩张（防什么：存在式空洞）**。一致集可以含
∃x.A(x) 却没有任何 c 使 A(c) ∈ Γ——项模型上这句会失败
（论域全是闭项，见证必须是其中一员）。逐个存在式分配
新鲜常量 c，把 A(c) 加进去。一致性保持：若新集不一致，
有限推导出矛盾，可把 c 换回变元再全称化——把矛盾传播回
旧集（违反一致）。**每个存在式都拿到专属见证**（Henkin
性质）。

**③ Lindenbaum 极大化（防什么：补漏）**。见证扩张后仍
可能「既不含 A 也不含 ¬A」——项模型读不出确定语义。按
公式枚举序逐个试加：加 A 若保持一致，否则加 ¬A（二者必
居其一且恰一可加）。链并成**极大一致集** Γ*——对每个
句子判决立场。极大一致集是「鸟瞰一切句子的完整理论」：
命题层封闭（A∈Γ* 且 A→B∈Γ* 则 B∈Γ*）、见证封闭（②）、
且对每个 A 恰好收 A 或 ¬A。

**④ 项模型（防什么：论域悬空）**。论域 := 全部闭项
（每个闭项自己是自己的名字——**世界由语言自己组成**，
20 章 Herbrand 宇宙的近亲）。解释从 Γ* 读出：f^M(t…) :=
闭项 f(t…)（语法构造即函数）；P^M := {闭项组 | P(t…) ∈
Γ*}。没有创造性成分——**模型就是 Γ* 的语法镜像**。

**⑤ 真值引理（构造的心脏）**：对每个句子 A，

```text
M_Γ ⊨ A  ⟺  A ∈ Γ*
```

对 A 的复杂度归纳：原子由定义成立；¬/→/∧ 走极大一致集
的命题封闭性；**∀ 是见证性质发力处**——M ⊨ ∀x.A(x) ⟺
对一切闭项 t，M ⊨ A(t)（论域全是闭项）⟺ A(t) ∈ Γ* 对
一切 t ⟸ ∀x.A(x) ∈ Γ*（公理 K5 反复实例化）。反向用
见证：若 ∀x.A ∉ Γ* 则 ¬∀x.A ∈ Γ*，即 ∃x.¬A ∈ Γ*，见证
c 使 ¬A(c) ∈ Γ*——某闭项处失败。**②③④ 的全部工程在
此收口**。

**⑥⑦ 收束**：Γ ⊆ Γ* 且 M_Γ ⊨ Γ*，故 Γ 可满足。逆否
回去：若 ⊨ φ 则 ¬φ 无模型，故 {¬φ} 不一致，故有穷片段
⊢ φ（爆炸+演绎定理组装）——有效 ⟹ 可证。∎

## 推论两枚：构造白送的果实

**紧致性定理**：Γ 的每个有穷子集可满足 ⟹ Γ 可满足。
证明在 Henkin 构造里只多一步：Γ 不一致 ⟹ 有穷子集就不
一致（矛盾推导是有穷对象）——逆否即得。紧致性是 21 章
可达性反证的武器（「有穷一致拼不出整体不一致」）、
非标准分析的地基（无穷小=「x>0 且 x<1/n 对一切 n」的
紧致性模型——每个有穷片段可满足、整体模型含无穷小）。

**Löwenheim–Skolem 定理**：可数语言的一致理论有可数模型
——项模型就是可数的（闭项可数）。往下版本（LS 下行）：
无穷模型必有可数的初等等价缩影；「**Skolem 悖论**」的完整
走查见下节（ZFC 可数模型 vs 不可数集的表面冲突）。模型论
「内外有别」的第一课从这里开始。

**非标准分析的免费入口**（紧致性的赠品，补一段）：取 Γ =
{∃x. x>0} ∪ {x < 1/n | n ∈ ℕ⁺}（x 是正无穷小）。每个有限子集
可满足（取 x < min(1/n)），紧致性给整集一个模型 M——M 含一个
大于 0 且小于一切标准 1/n 的元素：**无穷小存在**。这正是
Robinson 非标准分析的构造内核（超幂构造是紧致性的代数化身）。
教学价值：一条「明显无标准模型」的无穷公理集如何被紧致性
白送一个怪模型——模型论的「造世界」能力第一次裸露。

## 与全书的接线

- **02 章**：Peirce 缝在此收口——构造演算对语义完备。
- **21 章**：完备性+Church ⟹ FOL 半可判定（r.e. 非递归）
  ——两章合成判定层级的中段。
- **22 章**：**不冲突**——本章完备性说**推理规则**对
  **一切模型**的语义完备；22 章不完备说**算术公理**对
  **标准模型**的真相不完备。两把尺子、两个对象。「FOL
  完备而 PA 不完备」的表面悖论经此化解。
- **13 章**：直觉逻辑的 Kripke 完备性是本章的「世界链」
  版——一致性分布在时间轴而非极大一致点。
- **20 章**：项模型=Herbrand 宇宙的模型版；Herbrand 定理
  是完备性的「基项版特化」。

## 命题完备性的机器对照（已交付的对应物）

命题层的完备性 = 02 章判定器的双向：`check f = false ⟹
反赋值存在`（穷举见证）。有效式必可证——因为命题证明空间
有限可搜索（07 章表列就是搜索过程）。06 章矢列演算的可靠
性（零公理）是证明方向。两层完备性的构造**同构**：

| 构件 | 命题版（02/07 章） | 一阶版（本章） |
|---|---|---|
| 「一致」 | 分支不闭（无互补对） | 不推出 ⊥ |
| 「饱和」 | 全原子分支 | 极大一致集 Γ*（③） |
| 「见证」 | 每变元有真值 | 每存在式有常量（②） |
| 「模型」 | readOff 读出的赋值 | 项模型 M_Γ（④） |
| 「真值引理」 | 饱和分支被 readOff 满足 | M ⊨ A ⟺ A ∈ Γ*（⑤） |

表列的「开饱和分支=反模型」与 Henkin 的「极大一致集=
模型」是**同一个构造的有限/无穷两版**——07 章学过的
手感全部迁移。差别在量词：表列的 α/β 规则只拆连接词
（有限深），量词实例化在 FOL 里无界（要造无穷多见证）——
这正是 21 章半可判定的结构性来源。

## Skolem 悖论走查（LS 定理的压力测试）

「ZFC 有可数模型」与「ZFC ⊢ 存在不可数集」如何共存——
逐步拆解：

```text
1. ZFC 语言可数、公理递归——若一致，LS 下行给可数模型 M。
2. ZFC ⊢ ∃x(x 不可数)——M ⊨ ∃x(x 不可数)，故 M 里有
   「M 看不可数」的集合 X。
3. 「M 看不可数」= M 里不存在从 ω 到 X 的双射。
4. 模型外（真实世界）：M 本身可数，X ⊆ M 可数——存在
   ω↦X 的双射 f，但 f ∉ M（M 缺这个函数）。
```

结论：**「可数」是模型相对概念**——双射函数必须是模型
的居民才算数。这不是悖论而是「内外有别」的教科书：语义
概念（可数/不可数）依赖于模型的居民资格。Tarski 不可
定义性（22 章）、非标准模型（紧致性）同族——**模型论
的核心敏感点都是「从模型内看 vs 从模型外看」的视角差**。

## 机器化难点与先例（诚实边界）

步骤③ 的极大化是 Zorn 引理（或选择公理）级；④ 的项模型
在构造性类型论中需要商类型（闭项模 Γ*-等价——闭项 t、t'
可以不同名同义）。完整机器化是高等工程——各家先例：

| 系统 | 形式化 | 规模 |
|---|---|---|
| **Coq/Rocq** | `herbrand` / ILL 的完备性 | 相关逻辑的完备性（含 Henkin）|
| **Lean mathlib** | `FirstOrder/Completeness.lean` | 完整的一阶完备性（2024 合入）|
| **Isabelle AFP** | `Completeness_Theorem` | FOL 完备性（含强完备性）|

mathlib 的合入证明 Henkin 路线在现代类型论中可完整走通
（商结构用 setoid 或 ultrfilter 替代方案绕开）；构造性
变体（Kripke 语义+ Beth 模型）覆盖直觉逻辑——「存在 ≠
构造」的经典鸿沟能填多少仍是活跃课题。

## 命题层的强完备与紧致性（Ben-Ari §3.8\*）

一阶完备性（本章七步）在命题层有轻量版：命题 Hilbert 系统
的**强完备性**——Γ ⊨ φ ⟹ Γ ⊢ φ（带前提集的完备），证明
只需把 02 章判定器的反赋值读出+ Lindenbaum 极大化两步拼起。
随之而来的**命题紧致性**：无穷命题集的每个有穷子集可满足
则整体可满足——Lindenbaum 链的直接推论。两件轻量兵器在
38 章证 LTL 反例环、41 章枚举对照里反复上阵；一阶版的
紧致性（本章推论）只是把同一论证换到 Henkin 域上。读法
建议：把命题版当作一阶版的「排练场」——七步里的 ③⑤ 两步
（极大化+真值引理）在命题层已经完整出现，一阶层新增的只是
见证（②）与项模型（④）两块 FOL 特有的积木。
## 本章小结

- 完备性=「一致 ⟹ 可满足」：从找证明转向造模型——
  一致性是模型的欠条。
- 七步各防一失：常量池防名字荒、见证防存在空洞、极大化
  防立场缺位、项模型防论域悬空、真值引理收口（∀ 分支
  见证发力）。
- 紧致性与 LS 是构造的白送果实——21 章武器与非标准
  分析/Skolem 悖论的地基；命题表列与 Henkin 构造同构
  （饱和分支 vs 极大一致集），07 章手感全迁移。
- Skolem 悖论走查：「可数」是模型相对概念——内外有别
  是模型论的核心敏感点。
- 「FOL 完备 vs PA 不完备」两把尺子划清——与 22 章
  零冲突。
- 机器化先例三家齐备（mathlib 2024 里程碑）；Zorn/商
  类型是两大工程关口。

## 坑位速记（文档章）

- **负翻译与 Glivenko**（11 章）：命题层 ¬¬A 经典可证
  ⟹ A 直觉可证；FOL 层需要 Gödel 翻译（双重否定+
  量词改写），16 章的 drinker_nn 是其单点预演；
- **紧致性的非构造性**：用紧致性证明「若每个有限子集
  可满足则全可满足」时，模型的存在是选择公理级别的——
  构造性类型论中该陈述减弱（子模型的存在需要更多信息）；
- **写作纪律**：「FOL 完备」「PA 不完备」并提时必须
  点明两把尺子——历届读者在这句话上的困惑率最高。
