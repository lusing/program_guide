## 一、结构规则的三宗罪

矢列演算里，除了公理和联结词规则，还有三类「搬运」规则：**交换**
（换序）、**弱化**（加公式）、**收缩**（把两份压成一份）。它们看
似无害，实则各藏一宗罪：

- **交换**让推导检查器要做序列同构——明明矢列是多重集，序没有意
  义。G1 的解法：结构改用**有穷可重公式集**（多重集），交换规则直
  接消失（书 4.1 节开篇）。
- **弱化**让「从少推多」要显式走一步规则。G2 的解法：把语境**烘进
  公理**——(Id) 变成 α,Γ⇒Δ,α，弱化变成可容许（引理 4.3/4.4）。
- **收缩**最麻烦：它是证明搜索循环的直接温床。G3 的解法：让联结词
  规则的**前提重复主公式**（(→⇒) 的两个前提都带着 α1→α2），收缩
  变成可容许（引理 4.8）。

机器的 `g3chk` 就是按 G3 纪律写的：前件用多重集比较（`meqb`——序
无关），`premsOf` 按规则名从结论算出前提（主公式重复），检查器逐
节点对账。25 章（原 23 章）EFT 风格的 S 演算是这个故事的另一支后裔。

## 二、G4 的循环问题：Dyckhoff 的手术

拆完三条结构规则后还剩最后一个循环源：**G3ip 的 (→⇒) 左前提重复
主公式**。搜 ⇒(α→α)→β 这类矢列时（书 4.4 节开篇的例子），每次对
(α→α) 用 (→⇒)，左前提把 α 再抄进前件——矢列逐圈**变大**，搜索程
序不停机。机器面把这条回归迹摆出来：

```coq
Example g3_loop_growth :
  map (fun G => length G) [ ... ] = [2; 3; 4; 5].
```

每一圈前件多一个 α——「同一矢列以更大前件重生」的循环机制现场。
Dyckhoff 1992 的手术：把 (→⇒) 按**主公式前件的形状**拆成四个分支
规则（书定义 4.8）：

| 前件形状 | 规则动作 | 降权依据 |
|---|---|---|
| ⊥→α | 空虚，直接丢弃 | μ 消减 |
| p→α（原子） | 双前提：Γ′⇒p 与 α,Γ′⇒β（**DROP** 主公式） | μ 消减 |
| (α₁∧α₂)→α | 改写为柯里化 α₁→(α₂→α) | 不等式 (1) |
| (α₁∨α₂)→α | 改写为 α₁→α 与 α₂→α 双份 | 两支皆降 |
| (α₁→α₂)→α | 嵌套分支（前提 1 经 (⇒→) 逆化） | 不等式 (4) |

每一行的**权重**严格下降——权重是乘法的（定义 4.9）：

```coq
Fixpoint mu (a : fform) : nat :=
  match a with
  | pvar _ | fbot => 2
  | fand x y => mu x * (1 + mu y)
  | forr x y => mu x + mu y + 1
  | fimp x y => mu x * mu y + 1
  end.
```

乘法是精心的设计：μ(α→β)=μ(α)·μ(β)+1 保证 α₁→α₂→…→αₙ 链的权重
指数式超过任何「半截」改写式。四条降权不等式在公式样本上逐点验证
（`mu_and_branch`/`mu_imp_branch`/`mu_or_branch`，定理 4.13 的机器
面）：机器搜索器 `g4prove` 按此实现，双向账如下：

```coq
Example g4_id : g4prove 200 ([], fimp p0 p0) = true.
Example g4_glivenko_instance :
  g4prove 400 ([], fneg (fneg (forr p0 (fneg p0)))) = true.
Example g4_not_dne : g4prove 400 ([], fimp (fneg (fneg p0)) p0) = false.
Example g4_not_lem : g4prove 400 ([], forr p0 (fneg p0)) = false.
Example g4_not_peirce :
  g4prove 400 ([], fimp (fimp (fimp p0 p1) p0) p0) = false.
```

三个直觉主义非定理（双重否定消去/排中律/Peirce 律）在有限搜索内返
回 false——而同一个搜索器对 G3ip 会永转的 (α→α)→β 型目标瞬时停机
（原子分支的 DROP 直接封死循环）。**这章的核心教学点**：证明搜索
的终止性不是程序员的运气，是演算设计（规则形状+权重函数）的定理。

（实现注记：搜索器的 (→⇒→) 分支采用 G3ip 等价形——前提 1 经 (⇒→)
逆化后保持主公式，可靠性由 G3ip 自己背书；书中的 μ 降权版本对应
Dyckhoff 原版的前提 1 替换，其不等式机器账已在 `mu_imp_branch` 兑
现。两版的选择记文档线。）

## 三、G1→G2→G3 逐级拆除的账

谱系的每一级都有等价定理兜底（书定理 4.4/4.5/4.7）：G0ip 与 G1ip
可推导性相同、G1cp 与 G2cp 相同、G2 与 G3 相同。拆规则的**代价**是
证明变得隐式——弱化/收缩从规则变成「可容许」的元定理（保持高度可
允许，引理 4.6/4.8），机器面用样本验证：

```coq
Example g2_weakening_admissible_sample :
  andb (g4prove 200 ([], fimp p0 p0))
       (g4prove 200 ([], fimp p1 (fimp p0 p0)))
  = true.
```

⇒p→p 可推导 ⟹ 随便加一个 q 仍可推导——弱化可容许的样本兑现。收
缩同理（双份 p,p ⇒ p 与单份同判）。G3 的红利随即到账：**子公式性
质**（推导只碰末端公式的子公式）、可判定性（G3cp 由权重直接得，
书定理 4.12：每个联结词规则前提权重严格小于结论权重——引理 4.16）。

## 四、嵌入定理：Glivenko 的纯句法证明

4.5 节用这套机器证 **Glivenko 嵌入定理**：对任意公式 α，⊢HK α 当
且仅当 ⊢HJ ¬¬α（推论 4.5）。路线（Negri–von Plato 2001）：给
G3ip 加**原子排中规则** (Ea)——

```text
¬p,Γ ⇒ β    p,Γ ⇒ β
───────────────────── (Ea)
        Γ ⇒ β
```

得到 G3ipEa。三步走：(1) 证明 (Ea) 与结构规则和谐（弱化/收缩/cut
全部保持可容许，引理 4.27/4.28/定理 4.15）；(2) 把 (Ea) 推广到任
意公式的 (Em)（定理 4.16——对公式复杂度归纳，∧∨→ 三情形逐一用
G3ip 的否定等值式拆解）；(3) **标准推导**引理（4.30）：任何推导可
变换成联结词规则在前、(Ea) 在后的标准形（六种变换 I-VI 把 (Ea) 往
下推），于是每个 (Ea) 的应用点都能局部替换成 G3ip 的 ¬¬ 环绕——
定理 4.17 得证。机器面给两端各一棵树：

```coq
Example eaLem_ok : g3chk true eaLem = true.      (* G3ipEa：一步 (Ea) *)
Example eaLem_no_ea : g3chk false eaLem = false. (* G3ip 拒收同一棵树 *)
Example glivenko_ok : g3chk false gGlivenko = true. (* G3ip 的 ¬¬ 环绕 *)
```

同一目标 ⇒p∨¬p：G3ipEa 里原子排中一步到位；G3ip 里要走完整的
¬¬ 环绕（(⇒→) 进 ¬X、(→⇒) 拆 ¬X、(⇒∨) 选支、(Id) 收口）。13 章
（原 12 章）Glivenko 的语义证法与 G3i 的搜索对账在这里合流——同一
条定理的语义、句法、搜索三条证路。

## 五、谱系全景与本书的去向

| 级 | 拆掉的规则 | 换来的红利 | 本章机器件 |
|---|---|---|---|
| G0 | —（显式 w/c/e+cut） | 与 HK/HJ 等价（定理 3.1/3.2） | 07 章 G 演算同源 |

Maehara 构造正是在无切割推导上做的归纳。

## 小结

结构规则不是逻辑的必然，是记法的税。G0 到 G4 的五级谱系把税逐条退
掉，最终换来一台直觉主义证明器：规则形状（四分支）+乘法权重（μ）
+回溯搜索（g4prove），三个非定理在有限空间内被否证。嵌入定理收尾：
加一条原子排中规则、证它可压缩成 ¬¬ 环绕——Glivenko 从语义现象变
成句法构造。
