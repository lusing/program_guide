# 17 FOL Hilbert 系统：Gen 侧条件的演绎定理

> 对书：Mendelson §2.3-2.6 / Ben-Ari 3e Ch8.2 / H&R §2.3（ND 对照）
> 通道：C（完整演绎定理）/ L（单假设版+三连坑实录）

05 章把命题逻辑装进 Hilbert 系统，学会了「推导归纳证元定理」
的范本（演绎定理）。本章做 FOL 扩展——立刻撞上一个新的结构
现象：**Gen 规则的侧条件把演绎定理撕开一个口子**。修好它的
过程，恰好是「侧条件为什么存在」的最深刻一课。读完本章，
14 章以来一路跟随的「侧条件文化」（代入的捕获纪律、∀i 的
新鲜变元、=e 的自由代入）将在元定理层收口。

## 公理系统（深嵌入）

命题骨架照抄 05 章（K1/K2 组合子公理），FOL 的行李是量词：

```
K1  P → (Q → P)
K2  (P→(Q→R)) → ((P→Q)→(P→R))
K5  ∀x.P → P[x:=t]              （量词消去/实例化）
K6  ∀x.(P→Q) → (∀x.P → ∀x.Q)    （量词对 → 分配）
Gen 从 A 得 ∀x.A                （概括规则）

GenMove（带侧条件的公理模式）：
    x ∉ FV(P) ⟹ ∀x.(P→Q) → (P→∀x.Q)
    （「Gen 后移」——Enderton 式通用实例公理）
```

逐条读：K5 是 16 章 ∀e 的公理化身（ ∀ 给实例）；K6 说 ∀
与 → 可交换推进（分配律的量词版）；**Gen** 是新规则里唯一
「产出量词」的——从 A 推 ∀x.A。注意 Gen 的合法性**没有内置
侧条件**：只要 A 可推，∀x.A 就可推——侧条件出现在**别处**
（演绎定理里），这是本章的戏核。

## K5/K6 逐条讲：量词公理的形态学

**K5（∀x.P → P[x:=t]）**是「全称给实例」的公理化。它正是
16 章 ∀e 的化身——ND 里一条规则，这里一条公理模式。侧条件
同源：t 对 x 在 P 中可自由代入（否则实例化捕获变元）。注意
K5 只往一个方向走（从 ∀ 到实例）——「从实例到 ∀」不是公理，
是 Gen 规则（且带元定理侧条件），方向的不对称就是本章主题。

**K6（∀x.(P→Q) → (∀x.P → ∀x.Q)）**是「∀ 分配过 →」——
若对一切 x 都有 P→Q，且对一切 x 都有 P，那对一切 x 都有 Q。
这条公理的 soundness 一眼可见（逐实例的 MP）；它的**用途**
是在 Gen 分支的装配里充当「先量化蕴含、再分离前件」的中转
（配合 GenMove 完成量词后移）。Mendelson 系统还有一条
K4 形态（∃ 的定义式展开），教程按 ¬∀¬ 定义 ∃ 从简。

**Gen（从 A 得 ∀x.A）**：唯一产出量词的规则。它的「无侧条件」
经常被误读为「安全」——本章反例正是要打破这个误读：规则层的
无条件把风险转嫁到了**使用规则的元环境**（假设表）上。把
Gen 想成「放大器」：任何可推的 A 都被放大成 ∀x.A——放大
本身没错，错的是假设的自由变元被顺带放大。

## Gen 侧条件不可省：演绎定理的反例先行

05 章的演绎定理（Γ,A ⊢ B ⟹ Γ ⊢ A→B）在 FOL 里**直接失效**。
反例一步到位：

```text
取 A := P(x)（x 自由出现）。
1  P(x)                    假设
2  ∀x.P(x)                 Gen 1（合法！Gen 本身无侧条件）
```

所以 `P(x) ⊢ ∀x.P(x)` 可推。**但** `⊢ P(x)→∀x.P(x)` 不可推
（也不有效——换个赋值让 x 处的两个取值一个满足 P 一个不满足，
前真后假）。若演绎定理无条件成立，两者必须同时成立——矛盾。

诊断：Gen 作用在了**假设的自由变元**上。假设 P(x) 只说「这个
特定的 x 有 P」，Gen 却把它放大成「一切 x」——假设的「临时性」
被量词偷走（与 16 章 ∀i 侧条件防的事故同源：把特定当普遍）。
修复版（Mendelson 定理 2.4）：演绎定理成立，只要**Gen 从不
作用于假设 A 的自由变元**。

## 旗舰：演绎定理的 Gen 侧条件版

```
fdeduction_closed : closedF A → fder (A :: G) B → fder G (A → B)
```

机器版把侧条件强化为「A 是闭公式」（无自由变元）——对任意 x
自动满足 Mendelson 条件。四分支归纳（深嵌入 `examples/17_folhilbert/`）：

- **假设分支**：B=A 时输出 identity（K1/K2 装配的 p→p）；
  B∈G 时 K1 弱化；
- **公理分支**：公理无所谓上下文，K1 弱化；
- **MP 分支**：K2 的柯里化分配两步接力（05 章同款）；
- **Gen 分支**（本章新内容）：IH 给出 `G ⊢ A→C`，要从它造
  `G ⊢ A→∀x.C`——**GenMove 出场**：

```text
GenMove 实例： ∀x.(A→C) → (A→∀x.C)     （x ∉ FV(A)：闭公式担保）
装配：  K6 + IH 得 ∀x.(A→C)；再 MP GenMove 实例得 A→∀x.C
```

为什么不能直接 Gen？`G ⊢ A→C` 上作用 Gen 得 `∀x.(A→C)`
——量词管到了整个蕴含，需要 GenMove 把 ∀ 从「管整体」挪到
「只管后件」。这一挪就是侧条件的舞台：x ∉ FV(A) 时挪动保
语义；x ∈ FV(A) 时挪动会偷换 A 的变元——反例的机制在此。

## 带侧条件的公理模式（深嵌入的处理）

GenMove 的侧条件 `x ∉ FV(P)` 是**可判定的语法条件**——深嵌入
中作为公理构造子的 Prop 前提合法：Lean 版
`gen_move (x P Q) (h : x ∉ fFV P) : IsAx …`。这与「公理模式
= 纯语法形状」的传统观念有微妙出入（公理带证明义务），
边界如实登记。另一条路线是把 GenMove 的实例全部预先枚举进
公理集（Enderton 的做法）——教学版选前者（机器上直接、
侧条件可见）。

## 与 16 章 ND 的对照：侧条件的两种安放

同一件事（防止把特定当普遍）在两个演算里的安放位置不同：

| | ND（16 章） | Hilbert（本章） |
|---|---|---|
| 防线位置 | ∀i 规则自带侧条件 | Gen 无侧条件；演绎定理带侧条件 |
| 侧条件内容 | x ∉ FV(活跃假设) | Gen 不作用于假设的自由变元 |
| 谁来检查 | 规则应用时（框纪律） | 元定理证明时（归纳分支） |
| 后果 | ND 的演绎定理免费（→i 即规则） | Hilbert 的演绎定理要修 |

结构原因：ND 的假设管理在**框**里（放电即消失），Hilbert 的
假设管理在**上下文表**里（全程可见）——Gen 碰到表里的自由
变元时无处躲，只能在元定理层设防。**演算设计里侧条件不会
消失，只会搬家**——搬到规则上（ND）还是搬到元定理上
（Hilbert），是设计取舍。

## Lean 版的完整边界实录（本章坑位之王）

Lean 版走**单假设环境（A :: G）**路线，其中踩出三个连环坑：

1. **FDer 的环境若做「参数」**——induction 的 IH 不携带环境
   （fweak 无法归纳）；做**双索引**后构造子字段的 G 又被
   induction 自动 unify、with 子句绑定数对不上；
2. **环境是封闭值 [A] 时**——induction 无法泛化索引（IH 固定
   A::G）——必须 A :: G（G 变量）才能泛化；
3. **with 子句的绑定顺序**——@fMP P B h1 **h2** ih1 **ih2**
   （字段全部在前、IH 在后）——写 h1 ih1 h2 ih2 会错位绑定
   （ih1 绑到 h2 的位置，报「Function expected」）。

G 版的完整演绎定理（含 weaken）在 Coq 通道；Lean 版边界如实
记录。

## GenMove 装配的完整走查

Gen 分支是本章证明的技术高潮，把装配逐行摆开（推导树形态）：

```text
IH（归纳假设）:   G ⊢ A→C
K6 实例：        G ⊢ ∀x.(A→C) → (∀x.A → ∀x.C)     …… (i)
需要的中转：      G ⊢ ∀x.(A→C)                      …… (ii)
GenMove 实例：   G ⊢ ∀x.(A→C) → (A→∀x.C)          …… (iii)
                  （侧条件 x ∉ FV(A)——闭公式担保）
目标：           G ⊢ A→∀x.C

装配：从 (ii)（IH 上 Gen 一步——G 里无 x 约束，合法）
      与 (iii) MP 得 A→∀x.C
```

注意 (ii) 的来源：**IH 上直接作用 Gen**——这一步在元层合法
（G 的公式都是定理语境），而它恰是演绎定理内部的「受控 Gen」：
规则还在用，但只作用于**已转换为定理形态**的 IH（假设 A 已被
→i 式的 K1/K2 装配吸收进前件）。**侧条件不是禁用 Gen，而是
给 Gen 划定安全的跑道**——演绎定理的证明就是把「假设语境里
的 Gen」改造成「定理语境里的 Gen」的整个过程。

机器现场（`ex17_folhilbert.v` 的 fdeduction_closed）里，这
段装配对应 Gen 分支的 `pose proof (fGen _ _ _ Hih)` +
`apply fMP with (fMP … (fAx … (gen_move …)))` 链——四个
构造子的接力，每个的侧条件各就各位。

## 本章小结

- FOL Hilbert = 命题公理 + K5/K6 + Gen；Gen 本身无侧条件，
  风险转嫁给使用它的元环境。
- K5 是 ∀e 的公理化（单向：从 ∀ 到实例）；K6 是 ∀ 对 → 的
  分配；GenMove 是带侧条件的「量词后移」零件。
- 演绎定理在 FOL 裸失效：P(x) ⊢ ∀x.P(x) 反例——Gen 偷走
  假设的临时性。
- 修复版侧条件「Gen 不碰假设自由变元」；闭公式假设自动满足；
  Gen 分支装配 = IH 上的受控 Gen + GenMove（「给 Gen 划跑道」
  而非禁用）。
- 侧条件在 ND（规则上）与 Hilbert（元定理上）的安放对照——
  「侧条件只会搬家不会消失」。
- 带侧条件的公理模式在深嵌入里是合法形态（构造子带 Prop 前提）。
- 05 章的 identity=SKK 与本章 GenMove 同族：装配零件的挑选
  决定元定理证明的形态。

## 坑位速记（本章实测）

- **Coq/Rocq**：`/\` 在 Python 字符串中被吃掉（K6 公理的合取
  符号变成 `/ + 空格`）；fFV 定义必须在 isAx 之前（公理引用
  它）；`right; right; right; right` 的析取层数=公理模式序号；
  `rewrite Hcl. intros Hc. destruct Hc.` 处理 `x ∈ []`。
- **Lean**：见上节三连坑；另有 fAx 的 A 字段显式
  （调用要 `fAx _ hax`）；`simp [List.not_mem_nil]` 在
  `hnil : B0 ∈ []` 上无 progress（直接 cases）。
