# 31 模态逻辑 K：真值的模态

> 对书：H&R §5.1（modes of truth）/ §5.2（语法与 Kripke 语义）/ §5.3.1（有效式库）
> 通道：C/L（K_valid/nec/dia_dual/box_and + T/4 反例框架）

命题逻辑里公式的真假一锤定音；但自然语言里我们常说「**必然**
真」「**知道**为真」「**相信**为真」「**将来**为真」——同一句话
在不同**模态**（mode）下真值不同。模态逻辑给「真值的模态」装上
算子：□φ（方框，读法随应用换）与 ◇φ（菱形）。本章建立最小的
模态逻辑 **K**——不带任何框架假设的纯演算层，并给足反例说明
「K 只担保 K」。

## 语法与读法（H&R §5.1-5.2）

基本模态逻辑的语言 = 命题逻辑 + 两个一元连接词（H&R 定义 5.1）：

```text
φ ::= p | ⊥ | ¬φ | φ→φ | φ∧φ | □φ | ◇φ
```

□ 的六种读法（H&R 表 5.2 精髓）决定整个逻辑工程的走向：

| □φ 读作 | ◇φ 读作 | 可达关系的直觉 |
|---|---|---|
| 必然 φ | 可能 φ | y 是 x 眼中的可能世界 |
| 主体 Q 知道 φ | 主体 Q 认为 …可能 | y 是 x 处 Q 排除不了的世界 |
| 主体 Q 相信 φ | … | 同上（信念可假） |
| 以后总是 φ | 某刻 φ | y 是 x 的未来 |
| 程序执行后 φ | 存在执行使 φ | y 是 x 的后继状态 |
| 应该 φ | 允许 φ | y 是 x 的合规世界 |

机器件（`examples/31_modal/ex31_modal.v`）□/◇ 都是**原生构造子**
（◇ 的语义条款直接是存在见证——对偶定理才有内容）：

```coq
Inductive mform : Type :=
| mAtom : nat -> mform | mNeg : mform -> mform
| mImp : mform -> mform -> mform
| mBox : mform -> mform | mDia : mform -> mform.

Record frame : Type := mkF {
  worlds : list nat;
  rel : nat -> nat -> bool;       (* 可达关系（任意！） *)
  val : nat -> nat -> bool }.

Fixpoint msat (F : frame) (w : nat) (f : mform) : Prop :=
  match f with
  | mBox a => forall v, In v (worlds F) ->
              rel F w v = true -> msat F v a
  | mDia a => exists v, In v (worlds F) /\
              rel F w v = true /\ msat F v a
  | ... end.
```

**框架（frame）**= 世界集 + 可达关系；**模型**再加赋值。关键设计：
`rel` 是 `nat → nat → bool`——**任意**二元关系（对照 13 章直觉主义
的预序 ⊑、28 章迁移系统）：模态逻辑对可达关系**零假设**（假设
从下一章开始按需添上）。

## 与 13 章的分工（承诺兑现）

13 章立过对照表，这里精确化三处：

1. **R 的约束**：直觉主义 ⊑ 是自反+传递的预序（时间之箭）；
   本章 R **无约束**（逻辑工程的自由度）；
2. **单调性**：直觉主义的赋值沿 ⊑ 单调（知识只增）——本章
   赋值各世界独立（无任何传播）；
3. **→ 的条款**：直觉主义 ∀w'⊒w（约束未来）；本章经典真值表
   （只在当前世界算）。

这些差异正是 04/13 章的「经典 LEM 反例」在模态世界的镜像：直觉
主义的构造性来自这三条结构约束。

## 旗舰：K 只担保 K

**K 模式**（分配律）是**一切框架**下有效的最小引擎：

```coq
Theorem K_valid : forall F w a b,
  msat F w (mImp (mBox (mImp a b)) (mImp (mBox a) (mBox b))).
```

「若一切可达世界都满足 φ→ψ，且都满足 φ，则都满足 ψ」——
逐点应用，零框架假设。证明四行：剥两层 → 应用。

**必然化规则**：

```coq
Theorem nec : forall a,
  (forall F w, In w (worlds F) -> msat F w a) ->
  (forall F w, In w (worlds F) -> msat F w (mBox a)).
```

「定理的必然化是定理」。**方向陷阱**（机器反例现场）：`p → □p`
**不是**有效式——`nec` 的前提是「对一切框架/世界真」的全称式，
而 `p → □p` 只要求 p 在**本世界**真。反例模型 `lone`：世界 0 真 p、
0→1、1 无 p——p 在 0 真但 □p 假。**「必然化是规则不是公理」**
的机器含义正在于此。

**◇ 对偶**（¬□¬ 方向零公理、反向经典入账——与 27 章
G_dual 同款口径）与 **□ 对 ∧ 的分配一半**（□(φ∧ψ) ⟹ □φ∧□ψ；
反向也成立但需要合取的语义组装——练习）。

## 反例现场：T 与 4 都不是 K 的（§5.3.1 图 5.3）

K 之上还该加什么？取决于 □ 的读法。**不加的话**：

```coq
Example T_fails : ~ msat fnoRef 1 (mImp (mBox (mAtom 0)) (mAtom 0)).
Example four_fails :
  ~ msat fnoTrans 2 (mImp (mBox (mAtom 0)) (mBox (mBox (mAtom 0)))).
```

- **T（□φ→φ）在非自反框架失效**：`fnoRef` 的世界 1 只有出边
  1→2（不自反），p 在 2 真——1 的可达世界全是 p（□p 真）但 1
  自己无 p——T 假。读「知道」时 T 说**知识必真**——信念不适用、
  知识适用的分界线；
- **4（□φ→□□φ）在非传递框架失效**：`fnoTrans` 的 2→1→2
  链（非传递）——2 的可达世界 {1} 全 p（□p 真），但 1 的可达
  世界 {2} 无 p——□□p 假。4 说**知道自己知道**（正自省）。

两个反例都是 H&R 图 5.3 的现场：x1（□p 真、p 假）与 x2 加边
（□p 真、□□p 假）。**这就是逻辑工程的起点**：每条想加的公理，
先看它的反模型长什么样（下一章的反方向定理把这件事做完）。

## 有效式库的取舍表（§5.3.1 收口）

H&R §5.3.1 的清单按「加不加」给设计者看账本：

| 公式 | K 下有效？ | 读「知道」时 | 读「相信」时 |
|---|---|---|---|
| K：□(φ→ψ)→(□φ→□ψ) | ✓ | ✓ | ✓ |
| T：□φ→φ | ✗（fnoRef） | ✓（知识必真） | ✗（信念可假） |
| D：□φ→◇φ | ✗（需 serial） | ✓ | ✓（信念一致） |
| 4：□φ→□□φ | ✗（fnoTrans） | ✓（正自省） | 争议 |
| 5：◇φ→□◇φ | ✗（需欧性） | ✓（负自省） | ✗ |

「知道 vs 相信」的分界线正是 T——这也预告了下一章 KT45 与
KD45 的分岔（知识逻辑 KT45 全收、信念逻辑 KD45 用 D 换 T）。

## □ 与 ◇ 的完全对偶表

31 章的最后把对偶律做成速查表（§5.2 的语义双面）：

```text
¬□φ ≡ ◇¬φ        ¬◇φ ≡ □¬φ        （DN：模态 de Morgan）
□(φ∧ψ) ≡ □φ ∧ □ψ   ◇(φ∨ψ) ≡ ◇φ ∨ ◇ψ   （分配——两个方向都成立）
□φ ∨ □ψ ⟹ □(φ∨ψ)   ◇(φ∧ψ) ⟹ ◇φ ∧ ◇ψ   （单向！反向反例留练习）
```

**单向分配的直觉**：两件必然的事合取还是必然；但「φ∨ψ 必然」
不要求哪个单独必然（可能世界 A 只有 φ、世界 B 只有 ψ）。这与
27 章 LTL 的 F 分配（F∨ 双向、F∧ 单向）形成家族对照——全称
算子对 ∧ 分配、存在算子对 ∨ 分配，方向性由量词性格决定
（16 章量词等价表的模态版）。

adequate set：{¬, →, □} 够用（◇ 定义为 ¬□¬）——与 08 章
命题逻辑的 adequate set 讨论同构；教学版直接双原生。

**模态词与量词的血缘**：把可达关系固定为「全关系」（一切世界
互达），□φ 退化为 ∀（谓词逻辑的全称量词）、◇φ 退化为 ∃。
模态逻辑因此常被称为「量词的局部化」——□ 只在可达邻域里
量化，而不是整个论域。这个观察解释了为什么对偶表与 16 章
的量词等价表逐行平行，也预告了 32 章「性质对公式」的对应
理论为什么会成立：框架性质就是在约束量词的辖域形状。

## 本章小结

- 模态 = 真值的模式：□/◇ 一对，读法六种、结构一种。
- Kripke 语义：框架（世界+任意 R）+ 赋值；□ 全称可达、◇ 存在
  可达。
- K 只担保 K（分配律）+ 必然化规则；T/4 各需框架性质——反例
  框架机器交付。
- 与 13 章分工：R 无约束/无单调性/→ 经典——直觉主义结构约束
  的缺席清单。
- nec 是规则不是公理：p→□p 反例（lone）。
- □ 对 ∧ 分配、◇ 对 ∨ 分配（双向）；交叉方向只单向——
  量词性格定方向（16 章量词等价表的模态版）。

## 坑位速记（本章实测）

- **Coq/Rocq**：
  - rel 用 bool 函数而非 Prop 谓词——字面量反例框架可以
    reflexivity 直算；
  - In 表的析取是**元素在右**（1 = v）——subst 前看清方向；
    分支序按世界编号排（T_fails 的 v=1 可证、v=2 才 discriminate，
    写反了报「Unable to find instance」）；
  - mImp 层的假设应用前 `simpl in H`（fixpoint 不自动展开）；
  - ◇ 别做成 ¬□¬ 的缩写——对偶定理会退化成定义展开
    （ConstructionError 教训：◇ 原生构造子 + 存在条款才有内容）；
  - dia_dual 反向要经典（从 ¬□¬ 提取见证）——classic 入账
    与 27 章 G_dual_bwd 同口径。
- **Lean**：
  - `x == w && p == 0` 的探针赋值在 Nat 上要 `Nat.beq` 直连
    （== 的 BEq 实例不定义性归约，10 章教训三度复现）；
  - `simp only [fnoRef] at hr` 对含**自由变量**的 match 不
    燃——先用世界表成员（v = 1 ∨ v = 2）收窄再分派；
  - `List.mem_cons` 的成员化简不含 mem_nil（核心库无名）；
  - 反例证明的常见形态：`hbox2`（□ 见证）按成员 rcases，
    冲突面 `Bool.noConfusion` 收。
