# 22 哥德尔不完备性：可表示性、算术化与对角化

> 对书：Mendelson ch3（主线）/ EFT X.7 / Huth&Ryan §2.5

数学逻辑的巅峰定理。本章为文档章——三步证明的机器化路线
与各家形式化先例索引；构件预演（不动点引理的机器面）已在
21 章的边界注记中给出。

## 证明的三步（Mendelson 路线）

### 第一步：形式算术系统 S（PA）

```
S1  x+0 = x                S5  0 ≠ Sx
S2  x+Sy = S(x+y)          S6  x < y ↔ ∃z(z≠0 ∧ x+z=y)
S3  x·0 = 0                S7  x < Sy ↔ (x<y ∨ x=y)
S4  x·Sy = x·y + x         （后继公理 + 归纳模式）
```

皮亚诺算术的一阶形式化。**可表示性定理**（Mendelson 3.2）：
每个递归关系 R 在 S 中可表示——存在公式 P_R 使得
R(n₁,…,nₖ) ⟹ S ⊢ P_R(n̄₁,…,n̄ₖ) 且 ¬R ⟹ S ⊢ ¬P_R。

### 第二步：算术化（Gödel 编码）

把「公式」「证明」「可证性」编码为自然数：
公式 A ↦ ⌜A⌝；证明序列 ↦ ⌜p⌝；可证谓词 Pf(n, m) 是
**原始递归**的（检查 m 是否是编号 n 的公式的证明——有限
机械过程）。「S ⊢ A」变成算术命题 Bew(⌜A⌝)。

### 第三步：对角化 + 不动点

**不动点定理**（Mendelson 3.5）：对任意公式 B(x) 存在句子 G
使得 `S ⊢ G ↔ B(⌜G⌝)`。取 B(x) = ¬Bew(x)，得**哥德尔句** G：

```
S ⊢ G ↔ ¬Bew(⌜G⌝)        「我不可证」
```

**第一不完备定理**：若 S 一致，则 G 与 ¬G 都不可证
（G 真——因为 G 说的是算术事实——但真不可证）。

**第二不完备定理**：S ⊢ Con(S) → G（一致性形式化蕴含哥德尔句），
故 S ⊬ Con(S)——**S 不能证明自身一致性**。

## 21 章构件预演的回顾

可表示性的机器面：`TP_mono`（20 章）证明了 **Horn 算子的
单调性**——定点理论的最小构件；而「不动点定理」的对角化
构造（自指）在类型论中的对应是**不动点组合子** Y =
λf.(λx.f(x x))(λx.f(x x))——typetheory 教程的 SKK=I 一节
（12 章）正是其命题层化身。**对角化的两副面孔**：逻辑层
（哥德尔句）与计算层（Y 组合子/自复制）在 Curry-Howard 下
同源。

## 坑位速记（文档章的「实测」）

- **Isabelle 归纳法与自由谓词**（21 章实录）：`induction_schema`
  对非自由 P 报 `dest_Free`——不完备性证明的机器化需要
  **方案的内部归纳**（Paulson 的 Isar 证明走
  `induct "n" arbitrary: ...` 结构化路线）；
- **哥德尔句的「真」**：G 在标准模型 ℕ 中真——但「真」
  是元概念（Tarski 不可定义性）；机器化时「真」只能以
  模型论方式（`ℕ ⊨ G`）表述，Isabelle AFP 的正是此路线。
