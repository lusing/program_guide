# 15 FOL 语义：模型、一致性引理与代入交换

> 对书：H&R §2.4（模型/语义蕴含/等式语义）/ EFT III / Mendelson §2.2
> 通道：C/A/L/I（一致性+完整代入交换+locale 理论样例）

14 章搭好语法骨架，本章给 M 和 ⊨：一阶公式的真假不再是一行
真值表，而是**相对于模型**的事实。按 01 章暗线问一句：本章的
M 是什么？——**模型**（论域+解释）。φ 呢？——带自由变元的
公式。⊨ 呢？——「在一切模型中……」的语义蕴含。这一层升级
带来三个技术新器官：环境（给自由变元发牌）、一致性（满足只
看自由变元）、代入交换（语法替换=环境更新）——它们合起来就是
「换牌合法性」的完整数学。

## 模型：论域加解释

**H&R 定义 2.14**：给定函数符号集 F 与谓词符号集 P，模型 M
由四件数据构成：

1. **论域** A：非空的具体值集合（学生、数、程序状态——任何
   你想谈论的东西）；
2. 每个零元函数符号（常量）c 配一个具体元素 c^M ∈ A；
3. 每个n 元函数符号 f 配具体函数 f^M : Aⁿ → A；
4. 每个n 元谓词符号 P 配**关系** P^M ⊆ Aⁿ。

符号 `f` 与解释 `f^M` 的区分是本章第一课：语法是符号，语义是
符号在模型里的化身。H&R 例 2.15 的模型可以整个搬来当教具——
论域 {a,b,c} 是程序状态集，i^M=a 是初始状态，R^M 是迁移关系
{（a,a),(a,b),(a,c),(b,c),(c,c)}，F^M={b,c} 是接受态。于是
`∃y.R(i,y)`（初始状态有后继）为真、`¬F(i)`（初始态非接受态）
为真——程序验证的语义底座就这么小。

**环境**（environment/valuation/lookup，各家叫法不同）给自由
变元发牌：e : var → A。机器版（`examples/15_folsem/ex15_folsem.v`，
沿 14 章一元片段）把模型参数化成两个解释函数加环境：

```coq
Definition fenv := nat -> nat -> nat.   (* 函数符号解释：论域取 nat *)
Definition penv := nat -> nat -> bool.  (* 谓词符号解释 *)
(* eform fe pe e f : Prop —— 满足关系的逐连接词定义 *)
```

满足 `eform` 对公式归纳定义：原子查谓词解释，连接词按命题
语义，量词分支**换环境不换模型**——`∀x.a` 为真当且仅当对一切
v，`eupd e x v` 下 a 为真。eupd 是 02 章 assignOf 的直系后代：
「给一个变元换个值，其余不动」。

## 语义蕴含：全称所有模型

**Γ ⊨ φ**（semantic entailment，H&R 定义 2.16 一带）读法：
对**一切**模型 M 与一切环境 e，若 Γ 中每个公式都真，则 φ 真。
注意「一切模型」的豪迈——包括所有「不讲道理」的模型。H&R
§2.4.3 特别提醒：没法在「合理模型」上划线（谁说了算？），
所以语义蕴含必须对**任意**模型成立。这个全称量词是 FOL 一切
不可判定性/不完备性现象的语义根源（21/22 章），也是紧致性
定理（23 章）能够「组装怪模型」的空间。

等价的局部形式（柯里化，H&R 式 1.41 的 FOL 版）：Γ ⊨ φ 当且
仅当 ⊨ Γ₁→(Γ₂→…→φ)，闭公式情形两者同用。

## 模型走查：例 2.15 的三连问

把 H&R 例 2.15 的三个非形式判断走到底（论域 {a,b,c}，迁移
R={(a,a),(a,b),(a,c),(b,c),(c,c)}，接受态 F={b,c}，初态
i=a）：

**问一** `∃y.R(i,y)`——初态有后继？逐 y 扫论域：y=a 时
R(a,a) ∈ R^M ✓。真，且见证就是 a。

**问二** `¬F(i)`——初态非接受态？a ∉ {b,c} ✓。真。注意这
是个「负事实」：为真靠的是**查验**而非构造见证——FOL 语义
里否定不要求反例（构造性读法见 16 章注记）。

**问三** `∀x∀y∀z.(R(x,y) ∧ R(x,z) → y=z)`——迁移确定性？
找反例：x=a 有三条出边（a,a)/(a,b),(a,c)，取 y=a、z=b：
R(a,a) ✓ ∧ R(a,b) ✓ 但 a=b 不成立——假。**反模型证据是一
组具体的 y,z**。

三问展示了 FOL 语义判断的完整谱系：存在式给见证、否定式靠
查验、全称式被一个反例推翻。见证/反例的「可取出性」正是
12 章 DP/EP 的模型侧预演——也是 28 章模型检查「反例轨」的
语义原型。三问全部可以在 15 章的机器件上重演：论域 nat 取
{0,1,2}，penv 按关系表写成函数，`eform` 的定义直接判定。

## 等式的语义锚点（H&R §2.4.3）

等式 = 是 FOL 的**唯一特权公民**：别的谓词随便解释（P^M 可以
是任何关系），等式的解释却被**锁定为论域上的真实相等**——
`t₁ = t₂` 为真当且仅当两边的项求值到同一个元素。为什么独独
给它特权？H&R 的回答很实际：等式承载「同一对象」这个元层次
概念，若允许随意解释，「计算相同东西的两个项」与「恰好落在
同一个解释关系里」就无法区分——数学实践里天天用的「等量代换」
（=a 与 P(a) 推 P(b)）会失去根基。证明规则侧（=i 自反公理与
=e 替换规则）在 16 章机器化；本章先立语义锚点：等式满足是
**逐模型的真相等**，与 16 章 =e 的可靠性互相呼应。

机器版把等式做进原子谓词表还是独立构造子是表示层选择——
16 章采用独立构造子 FEq（拿语义可靠性时一目了然），本章文档
锚点即可。

## 旗舰一：满足一致性引理

```
eform_coincidence : 赋值只在 fv f 上一致 → 两语义 iff
```

**满足只看自由变元**（EFT III.5 的 FOL 版）：两个环境在 f 的
自由变元上一致，则 f 在两环境下的真假一致。这是 02 章
agree_eval 的直系后代，也是「闭公式才有独立真假」的形式化：
fv 为空时一致性条件空真，任何两个环境给出同一答案。

证明五分支归纳（Coq 版）：atom 走 eterm 一致性、fimp/fneg 走
方向矩阵、**fall 分支是重头**——量化环境 `eupd e y v` 与
`eupd e2 y v` 在 fv a 上逐点一致（m=y 处同 v、否则归 h）。
Lean 版用 `have key` 前置统一处理双环境逐点等式。

## 旗舰二：代入交换的完整版

```
subst_all_eval : closedT s →
  eform e (subst f x s) ↔ eform (eupd e x (eterm e s)) f
```

14 章登记的边界在此兑现：**语法替换与语义更新交换**。白话：
「先在公式里换牌再求值」=「先发牌再改那张牌」。∀ 分支的两场
硬仗：

1. **y = x 路**（x 被束缚）：两层 `eupd (eupd e x U) x v` 的
   x 处「后写胜出」——pointwise 展开三个 if 直收；
2. **y ≠ x 路**：两层 eupd 的**换序**——
   `eupd (eupd e x U) y v` 与 `eupd (eupd e y v) x U'` 逐点一致
   （x 处同为闭项值 U=U'（闭项求值与环境无关）、y 处同 v、
   其他同 e）。闭项侧条件在这里兑现成 `closed_eval_inv` 引理。

侧条件 `closedT s`（s 无自由变元）的出场是教学重点：替换项
若是开项，它在**原环境**与**更新后环境**下的值可以不同
（它自己的自由变元被 eupd 改了牌）——交换等式随之失效。
侧条件不是装饰，是定理的承重墙。

## 旗舰三：一阶理论样例

「理论」（theory）= 公式集 + 模型必须满足的公理。机器化两条
路线的对照：

- Isabelle：locale `strict_order`（irrefl+trans）→ 无 2-环/3-环 +
  `interpretation (<)` 实例化 + coincidence 的 blast 一行版
- Lean：`structure StrictOrder` → `noCycle2` + `ltNoCycle2` 实例

locale 是 Isabelle 的招牌：把「严格偏序」的公理打包成命名
上下文，定理在 locale 内证明一次，任何满足公理的实例（<、
⊂、字典序）自动继承全部定理——**理论的模块化**。Lean 的
structure 是同思想的类型论拼写。一阶理论的形式化在 22 章
（算术 Q）与 23 章（完备性的公理集操作）都会回来。

## 与 02 章的器官对照

命题语义与 FOL 语义的零件表并排放，升级路径一目了然：

| 器官 | 命题（02 章） | FOL（本章） |
|---|---|---|
| M（世界） | 赋值 e : var→bool | 模型（论域 A+解释 f^M/P^M）+环境 e |
| φ 的求值 | eval e f : bool（可算） | eform … : Prop（一般不可判定） |
| 判定器 | 蛮力枚举（02 章 check） | **不存在**（21 章定理） |
| 一致性 | agree（只看 vars f） | eform_coincidence（只看 fv f） |
| 换牌 | assignOf（向量→赋值） | subst↔eupd 交换（本章旗舰二） |
| 等式 | 无 | 锁定为真相等（§2.4.3） |

两行值得停留：eval 从 bool 升到 Prop——「可计算」变成「可
陈述」；判定器那行的「不存在」预告 21 章的 PCP 归约。其余
器官全部同构——02 章学会的手感在这里直接复用。

## 本章小结

- 模型=论域+解释+环境三层；f 与 f^M 的符号/化身之分。
- 语义蕴含对一切模型（含不讲理的）——不可判定性的语义根源。
- 等式是唯一锁定语义的谓词：解释=真实相等（16 章 =i/=e 的
  语义锚点）。
- 一致性引理=「满足只看自由变元」=闭公式有独立真假。
- 代入交换=「换牌合法性」的完整定理；closedT 侧条件是承重墙。
- locale/structure：理论模块化的两套拼写，22/23 章回用。

## 坑位速记（本章实测——15 轮迭代）

- **Coq/Rocq**：`destruct (Nat.eqb y x) eqn:E` **会把目标里的
  scrutinee 替换掉**（后续 rewrite E 找不到）——simpl 后的 if
  已变成 true/false 字面量；destruct 的 sumbool 参数序要与
  remove 体一致（`Nat.eq_dec y a` 不是 `a y`）；iff 的分量
  要显式 `.mp/.mpr`（09 章同款）；「destruct (m =? x) eqn:E1」
  后分支里目标已是字面量——多余的 `rewrite E1` 反而报错；
  `subst m` 在 m 被 Ex 吸收后变量消失。
- **Lean**：iff 不能直接 apply（是结构不是函数）——`.mp/.mpr`
  全显式；`List.mem_eraseDups` 不存在（核心库无此引理）——
  fv 定义去掉 eraseDups；filter 的 Bool 条件用 `simp [hmy]`
  单独一步消 decide；structure Prop 的字段要 `so.` 前缀。
- **Isabelle**：locale 实例化后定理带前缀
  （`lt_order.no_cycle2`）；schema 变量让 `by (fact ...)` 失败——
  `of x y` 显式实例化或 nat 标注。
