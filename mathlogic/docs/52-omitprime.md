51 章的结论摆在这里：孤立型是「必须实现的」（任何满足孤立化
公式 φ 的元素都实现 p——Prop 4.2.2；完备理论里 ∃vφ 是定理，
所以孤立型在**每个**模型里都有代表），非孤立型是「或许可以
扔掉的」。本章证明后者成立——省略型定理——然后看到两个方向
的应用：素模型（把「只实现孤立型」做成一整个结构）与 PA 的
保守端扩张（扔掉「掉进 M 内部的假无穷点」型）。

## 一、省略型定理：三阶段的 Henkin 机器

**定理**（Thm 4.2.3）。L 可数，T 是 L-理论，p 是非孤立的 n-型。
则存在可数模型 M⊨T **省略** p。

**证明的机器结构**值得先看轮廓（`henkinTrace` 就是它的有限
重演）。扩张语言 L* = L ∪ {c₀,c₁,…}（可数新常量），构造句子链
θ₀⊨θ₁⊨θ₂…，令 T*=T∪{θᵢ}。设 φ₀,φ₁,… 枚举全部 L*-句子，
d₀,d₁,… 枚举常量的全部 n-元组。**阶段编号 s 按 mod 3 分工**：

- **s=3i+1（完备）**：若 T+θ_s+φᵢ 一致则 θ_{s+1}=θ_s∧φᵢ，
  否则 θ_{s+1}=θ_s∧¬φᵢ。每个句子最终被裁决——T* 完备。
- **s=3i+2（见证）**：若 φᵢ 形如 ∃vψ(v) 且 T⊨θ_s→φᵢ，取
  未用过的全新常量 c，θ_{s+1}=θ_s∧ψ(c)。T* 有见证性质
  ——33 章 Henkin 定理的同款步骤。
- **s=3i+3（省略）**：对元组 dᵢ，把 θ_s 里的常量「变量化」
  （dᵢ 换成 v̄、其余常量换成 ∃ 量化的新变元）得到 ψ(v̄)。
  **由 p 非孤立**，存在 φ∈p 使 T⊭∀v̄(ψ→φ)——于是有 N⊨T
  与 a 使 N⊨ψ(a)∧¬φ(a)，把常量解释挪到 a 上即知
  θ_{s+1}=θ_s∧¬φ(dᵢ) 保持一致。

三件事同时成立：T* 完备、有见证性质、且对每个常量组 dᵢ 都有
某 φ∈p 的否定落在它身上。规范模型（项的商结构——33 章同款）
的每个元素都是某常量的解释，于是没有任何元素组实现 p。∎

**为什么必须 L 可数**？反例（书 p127）：L 有不可数多个常量
C 与可数多个常量 D，T={a≠b : a,b∈C}，p={v≠d : d∈D}。T 的
模型都不可数（C 全体互异），于是总有元素落在 D 的解释之外
——p 被一切模型实现；但任何公式只提到可数多个 D 常量，
T+φ(d) 总可满足——p 非孤立。**可数性不是技术方便，而是
定理的实质假设**。Thm 4.2.4 加强版（同时省略可数多个非孤立
型）用 π:N×N→N 的配对把多张禁令表织进同一个 3-mod 轮转。

**机器面**（`examples/52_omitprime/` 第 1-2 节）。理论取
T_c={cᵢ≠cⱼ : i<j≤3}，被省略的型 p(v)={v≠cᵢ : i}——「非标准
点」型（任何公式只提有限多个常量、总有常量逃出禁集，故非
孤立）。`henkinTrace` 是 9 条阶段记录（0=init、1=完备、2=见证、
3=省略）：完备阶段提交永真式 c₀=c₀；见证阶段对 ∃v(v≠cᵢ) 指认
新常量；省略阶段把 ¬(v≠c_k)（即 c_k=c_k）放在 c_k 上。
`henkin_stages_sat` 逐阶段验证状态可满足（`satLits` 的指派
枚举：4 个常量指进 {0..3}，逐文字核验——可满足性检查是
穷举的，规模受控）；`omit_ledger` 验证**每个** c_k 都被某条
¬φ（φ∈p）钉住。诚实注记：T_c 的规范模型里省略是「自动」的
（每个元素本来就是某 cᵢ）——机器件展示的是**三阶段纪律与
逐阶段一致性维护**的形状；对非平凡理论，省略阶段的「挑 φ」
步骤（T⊭ψ→φ 的见证搜索）才是工作所在，其无限版无法全枚举，
下一个应用给出它的有限影子。

## 二、应用一：PA 的保守端扩张（Thm 4.2.5）

M⊨PA 可数，则存在真初等扩张 N⪰M 使 N 是 M 的**端扩张**
（M 的所有元素都在 N 的初始段里）。设 T=Diag_el(M)∪{c>m :
m∈M}（c 是新常量——「M 之外的远方」）；对每个 a∈M∖N?? 准确
地说对每个 a∈M，型 p_a={v<a, v≠m : m∈M} 表达「v 是 M 的
缺口里掉进 a 之下的假点」。N 省略全部 p_a ⟹ N 是端扩张
——没有新元素插进 M 的内部。

p_a 非孤立的证明是本章最漂亮的有限性论证。反设 φ(v)=θ(v,c)
孤立 p_a（θ 是带参数 c 的公式）。T+θ 一致迫使

> M ⊨ ∀x∃y>x ∃v<a θ(v,y)，

而**鸽洞原理在 PA 内可证**，于是 M 也满足

> M ⊨ ∃v<a ∀x∃y>x θ(v,y)。 (∗∗)

取那个 m<a：T+θ(m,c) 一致（∀x∃y>x 保证 c 可以躲过一切
上界）——m 这个「已在 M 里的点」也满足 θ，φ 不孤立 p_a，
矛盾。∎

**机器面**（第 3 节）：`pa_pigeonhole` 把 (∗∗) 做成可验证的
对象：θ 取六种形状（v=y、v<y、y<v、v≥y、v≠y、v≤y），
前提侧 ∀x∃y>x∃v<a θ（y 在 x 之上、v 在 a 槽内）、结论侧
∃v<a∀x∃y>x θ，在 {0..11} 的有限片段上枚举核验——**每个
θ 都过**。配套 `unbounded_needed` 是对照账：θ(v,y):=v<y 时
「∀y∃v<a θ」真而「∃v<a∀y θ」假——**y 必须无界**（结论侧
的 y 只须对每个 x 存在、可以随 x 增长），鸽洞才有活动的空间。
这正是「PA 可证的推理」与「朴素无限推理」的差异所在：
(∗∗) 的成立依赖算术归纳，机器件在有限片段上目击了它的
计算内容。

## 三、应用二：原子模型与素模型（Thm 4.2.8-4.2.15）

**素模型**：M⊨T 是素的，如果 M 初等嵌入每个 T-模型。**原子
模型**：每个有限元组都实现孤立型的模型。三个定理：

- **存在**（Thm 4.2.10）：T 有素模型 ⟺ 孤立型在 S_n(T) 中
  稠密（每个一致公式 φ 含孤立化公式 ψ）。(⇐) 用省略型定理
  同时扔掉全部非孤立型——剩下的模型每个元组都落在孤立型
  上（原子），而原子模型是素的（Lemma 4.1.6 的「一步扩张」
  逐元素装配初等嵌入）。(⇒) 素模型只实现孤立型（孤立型处处
  实现+初等嵌入把实现元送进素模型），非孤立点的 clopen 邻域
  与稠密性相撞。
- **唯一**（Thm 4.2.11）：完备理论的素模型唯一（至同构）——
  两个原子可数模型之间逐步 back-and-forth（每步的型孤立、
  两边都有唯一实现）。
- **链构造**（Lemma 4.2.14：原子⇒ℵ₀-齐次；Thm 4.2.15-4.2.18
  选讲）：可数原子模型链的并给出可数齐次模型——这条线在
  53 章（饱和与齐次）接棒。

**机器面**（第 4 节）：(Z₆,S,0) 的项模型。`termClosure` 从 0
出发对后继封闭：{S^k 0 : k<12} 去重恰得 6 个元素
（`prime_term_model` 的账：闭包=全域）；`prime_isolated` 验证
每个元素被 x=S^k 0 孤立——**项模型只实现孤立型**（51 章
`isolated_witness_z6` 的接力）。教学要点：素模型的通用构造
（扔掉全部非孤立型）在有限截断下退化为「取项闭包」——因为
有限语言的项在循环结构上已经穷尽了可命名的元素，而 DLO、
ACF 的素模型（Q、Q̄ 的代数闭包）则是「扔出 Q 与无理切割、
扔掉非主素理想」的无限版本。

## 四、谱系的一瞥（4.2.15-4.2.22 与后续）

ω-稳定理论有更强的素模型定理（Thm 4.2.20-4.2.22：任意
M⊨T、A⊆M，存在包含 A 的素模型扩张，且在强意义下唯一）——
其证明用到 Morley 秩（56 章）做「最小秩优先」的构造序。这
一簇结果在 54 章（可数模型数）和 57 章（素模型扩张唯一性）
各有一场正戏；本章只立骨架：**原子=素的存在判据（稠密）、
唯一的证明（逐步互嵌）、以及「素模型是型空间的孤立层骨架」
的几何图像**。

## 坑位速记（本章实测）

- **string_scope 劫持 `++`**：阶段记录用字符串标签+
  `Open Scope string_scope` 后，`acc ++ recLits r` 被解析成
  串拼接（acc 推成 string）——改用 nat 动作码（0/1/2/3），
  一了百了。
- **Coq 三元组左结合**：`nat * string * list lit` 是
  `(nat*string)*list lit`——`fst r` 是对不是 nat；命名投影
  （`recStage`/`recLits`）比嵌套模式匹配稳。
- **折叠函数要显式注类型**：`fold_left (fun acc r => …)` 在
  多重态上下文里 acc 类型漂移；注 `(acc : list lit)`。
- **省略记账要覆盖全部常量**：初版漏了 c₃ 的省略记录，
  `omit_ledger` 对 k=3 翻车——账本先全列再写断言。
- **(∗∗) 的有限核验需检查全部 θ 形状**：前提假的 θ 空洞地
  过（vacuous），前提真的 θ 才是压力测试——两者都在族里
  才是完整账。
- **Lean 元组右结合**：`Nat × Nat × Bool` 投影是 l.1/l.2.1/
  l.2.2（与 Coq 的左结合相反）——两通道同构件时投影名不同。

## 小结

本章把「非孤立型可以省略」变成机器：三阶段 Henkin 纪律
（完备/见证/省略轮转）在 T_c 上的有限重演展示了逐阶段一致性
维护与省略记账；PA 端扩张的鸽洞账 (∗∗) 是「无限论证的有限
内核」——y 无界性与算术归纳交换了位置；素模型的判据（孤立
型稠密）与唯一性把 51 章的拓扑（孤立点层）变成模型构造的
蓝图。省略与实现的张力到此织成一张网：下一章（53 章）在网
的另一端放下**饱和**——「尽可能多实现」的极限模型，与素
模型「尽可能少实现」互为镜像。
