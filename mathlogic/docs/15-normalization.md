# 第 15 章 正规化定理：把证明里的赘步洗掉

> 对书：马明辉《结构证明论》2.3 节（p39-44，定理 2.3/2.4）+2.4 节
> 完全性收尾。本章通道：C（`examples/15_normalization/
> ex15_normalization.v`）/ L（`examples/15_normalization/
> ex15_normalization.lean`）。

| 机器件 | 内容 | 通道 |
|---|---|---|
| `der`/`wf`/`conc` | 推导树数据+良构检查（每个节点的子推导结论与注记吻合） | C/L |
| `cutFmls`/`chD` | 切割公式检测（∧/→ 的引入-消去红元+∨-置换段）与**切割高度 ch(D)=(k,n)** | C/L |
| `red1`/`dnorm` | 一步归约（∧-变换/→-变换=β-归约+∨-置换）与归约解释器跑到底 | C/L |
| `dtrace` | 归约轨迹的 ch 序列：**严格降序账**（k 逐级下降的机器证据） | C/L |
| `allFmls`/`sub` | 子公式性质（推论 2.3）：正规推导全部公式 ⊆ SF(前提,结论) | C/L |

14 章把推导写成了程序；本章兑现 Curry-Howard 的第一个证明论红利
的**另一半**：程序可以化简，证明可以**正规化**。任何直觉主义推导
都能变换成没有「引入后立即消去」赘步的标准形——这条定理（Prawitz
1965，根岑 1936 的原始形式）是 14 章析取性质之外直觉主义逻辑的第二
块试金石，也是 87 章「矢列侧的同类定理」——切割消除——的姊妹篇。

## 一、引例：引入之后立即消去，是白干

看一个最白的推导（书例 2.4）：假设 α 与 β，先 ∧I 拼成 α∧β，紧接着
∧E 取出右支 β。中间的合取是纯粹的浪费：

```coq
Definition exDetour : der :=
  dAER p0 p1 (dAI (dHyp 0 p0) (dHyp 1 p1)).

Example exDetour_ch : chD exDetour = (1, 1).
Example exDetour_nf : dnorm 5 exDetour = dHyp 1 p1.
```

机器把这类「赘步」定义成**切割公式**（书定义 2.4）：推导中一个公式
的一次出现，既是引入规则的结论、又是消去规则的大前提。`chD` 给出
它的度量——**切割高度** (k,n)：k 是极大切割公式的复杂度，n 是极大
者的个数（书定义 2.7）。上面的例子 k=1（α∧β 复杂度 1）、n=1；归约
一步后 `(0,0)`——没有任何切割公式了。

## 二、两类变换：∧-变换与 →-变换

消除赘步的变换只有两种（NK° 的记法，书 p59）：

- **∧-变换**：`∧I` 后紧跟 `∧E` ⟹ 直接取对应分支的子推导；
- **→-变换**：`→I` 撤销假设后紧跟 `→E` ⟹ 把小前提**代换**进大前提
  撤销点——这正是 λ 演算的 β-归约（14 章的对应在此现形）。

机器上，代换是一个对推导树的递归函数 `dsubst`：把标记 n 的假设整
体替换为另一个推导。一步归约 `red1` 在全树最左位置找一个红元执行
变换；`dnorm` 反复执行到没有红元为止：

```coq
Fixpoint dnorm (fuel : nat) (d : der) : der :=
  match fuel with
  | O => d
  | S f => match red1 d with
           | Some d' => dnorm f d'
           | None => d
           end
  end.
```

β-赘步的账例——⊢p→p 的绕路证明（先 →I 再立即 →E）一步洗成单假设：

```coq
Example exBeta_nf : dnorm 5 exBeta = dHyp 1 p0.
```

## 三、终止性：字典序良序与复杂度下降

为什么归约一定会停？书定理 2.3 的证明骨架全在度量上：**ch(D)=(k,n)
按字典序比较，而 N×N 上这个序是良序**（没有无穷下降链）。每步变换
要么降 k 要么保 k 降 n，于是至多有限步后到 (0,0)——正规推导。

机器面用**轨迹账**验证这个下降。级联例（书引理 2.3/2.4 的机制现
场）：先用复杂度 2 的 β-红元（切割公式 (α∧β)→α），β 归约后**造出**
一个复杂度 1 的 ∧-红元，再一步消掉：

```coq
Example exCascade_steps :
  dtrace 5 exCascade = [(2,1); (1,1); (0,0)].
```

k 从 2 到 1 到 0 逐级下降——「切割高度沿良序下降」在这条三步轨迹上
逐点兑现。

## 四、∨ 的额外工作：置换变换与切割段

直觉主义逻辑不能把 ∨ 定义掉（经典 NK° 可以先限制语言到 {→,⊥}，
书引理 2.1/2.2 的语言变换——机器面记注释），所以 NJ 的正规化要多一
类**置换变换**（permutative conversion，书 p62）：∨E 的结论又被 ∧E
等消去时，把消去规则**下潜**进两个分支框：

```coq
Example exPerm_steps :
  dtrace 5 exPerm = [(1,1); (1,1); (0,0)].
```

注意轨迹里有一个**不降 k 的步**——置换本身只重排、不消除切割公式
（书引理 2.6 的原话：排列变换把消去规则上移，切割高度**不变大**，
然后用 ∧-变换消除）。这正是 NJ 比 NK 多出来的工作：书定义 2.10 为
此引入**切割段**（cut segment，一条轨迹上从引入结论到消去大前提的
整段出现），度量按段计算。机器的 `cutFmls` 把置换段计入同一账本，
轨迹的第二步才看到 k 的兑现。

置换例的终态还有个教学点：归约到底后 ∨E **还在**——它的大前提是
假设不是红元。正规推导仍然可以有「对假设的消去」（轨迹的消去段），
只是不再有引入后立即消去的赘步：

```coq
Example exPerm_nf :
  dnorm 5 exPerm =
  dOE p0 (fand p0 p1) p0
    (dHyp 9 (forr p0 (fand p0 p1)))
    (dHyp 1 p0)
    (dAEL p0 p1 (dHyp 3 (fand p0 p1))).
Example exPerm_nf_no_detour : chD (dnorm 5 exPerm) = (0, 0).
```

## 五、子公式性质与推论

正规化的第一笔红利（书推论 2.3）：**正规推导里出现的每个公式都是
末端公式（前提或结论）中某公式的子公式**。机器面把「推导的全部公
式」收集成 `allFmls`，对 SF(前提,结论) 做包含检查：

```coq
Example exCascade_subf :
  forallb (fun a => existsb (fun c => feqb a c) cascadeCtx)
          (allFmls (dnorm 5 exCascade)) = true.
```

直觉主义版干净无例外；经典版（推论 2.2）要排除被 RAA 撤销的假设
及其直接结论 ⊥——NK 的正规化证明（书引理 2.1/2.2）先把 ⊥E 与 RAA
的结论**限制到原子公式**（NK°）再搬移，教程记文档线。子公式性质的
直接推论是**析取性质的第二条证路**：⊢NJ α∨β 的正规推导末步只能是
∨I（14 章的语义路线在此换成纯句法路线）——84 章 G0ip 的无切割版
本（定理 3.6）将给出第三条证路。

书 2.4 节的**完全性**走的是翻译路线：把 NJ 推导逐规则翻译成 HJ⁺
（Hilbert 系统加 →I）推导（定理 2.5 的五个变换模板——(∧I)(∧E)
(∨I)(∨E)(→I) 各配一个公理装载模板），再去掉临时规则——22 章（原
05 章 Hilbert）的机器账将兑现这五个模板。

## 六、极性记号与 Harrop 定理（Mints ch5.4/6.1 深化）

Mints 给正规推导的结构定理配了一套**极性记号**（文档线）：子公式
出现是正/负/严格正的，取决于它埋在多少层蕴含前件之下。Thm 6.1
（子公式性质的精细化）：消除规则的主干上只出现**严格正**子公式。
这套记号的直接红利是 **Harrop 定理**（Thm 5.4(b)）：若前提都是
Harrop 公式（∨ 只出现在 ¬ 或 → 左侧辖域——负性条件），则
¬β ⊢ α₀∨α₁ ⟹ ¬β ⊢ αᵢ——析取性质从空前提扩张到否定型前提。
89 章的 `harrop` 检查器（Takeuti 版）与这里是同一件事的两个入口。
极性系统的另一应用是 14 章新加的 coherence 实验室：平衡矢列的
「每符号至多一次」按正负符号计数——唯一正规居元定理的坐标系。

## 小结

正规化把「证明的质量」变成可计算的账：赘步有名字（切割公式）、有
度量（(k,n) 字典序良序）、有洗法（两类变换+置换）、有验收（子公式
性质）。下一章（16 章）转回语义，把 Kripke 完备性补齐；86-87 章（结构规则谱系与插值）将看到矢列演算里同一件事的另一种做法——切
割消除。
