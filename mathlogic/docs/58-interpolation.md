如果说 57 章把结构规则当工程问题来拆，本章是拆完之后**最漂亮的一笔
分红**。Craig 插值定理（1957）：如果 α→β 有效，那么存在 γ 使得
α→γ、γ→β 都有效，且 γ 的变元全在 α 与 β 的公共变元里——「α 与 β
能共享的全部信息」被 γ 完整截获。这一定理对经典与直觉主义命题逻辑
同时成立，而它的标准证明——Maehara 方法——是一个**在无切割推导上
逐节点构造插值子的算法**：56 章（原 54 章）的切割消除不是炫技，是
插值定理的前置条件。

## 一、插值定理说什么

先看定理的形状。设 ⊢HK α→β。Craig 插值子 γ 满足三条：

1. ⊢ α→γ；
2. ⊢ γ→β；
3. var(γ) ⊆ var(α)∩var(β)。

极端情形最能说明它的内容：若 α 与 β **没有公共变元**，γ 只能是 ⊥
或 ⊤。γ=⊥ 时 α→γ 说「α 不可满足」，γ=⊤ 时 γ→β 说「β 永真」——
插值定理退化为：**α→β 有效且无公共变元时，α 矛盾或 β 永真**。信
息不能凭空穿过不存在的通道。

## 二、为什么需要无切割推导

Maehara 方法对推导做归纳——但 cut 规则会**毁掉构造**：cut 的切割
公式可以携带两侧都没有的变元，归纳到 cut 节点时插值子无从谈起。
所以证明的第一步是：把推导换成 56 章切割消除给出的**无切割推导**，
归纳只在 G0cp⁻ 的公理+联结词规则+结构规则上进行。

书定义 3.7 把归纳的载体做成**划分**：把矢列 Γ→Δ 的前件剖成
Γ₁⊎Γ₂、后件剖成 Δ₁⊎Δ₂，插值子 γ 对这个划分满足三条（前两条是可
推导性、第三条是变元条件）。推导的每个节点继承父节点的划分——规
则的主公式落在哪一侧，划分就怎么下放。机器把这个机制做成了数据结
构（`mder`）：每个节点直接携带四分划分。

## 三、Maehara 组合表全解

归纳的每个情形给出 γ 的组合方式。逐情形推导的要点（机器表 `interp`
的依据，定理 3.10 证明）：

**公理 (Id) α⇒α 的四格局**。左右两份 α 各落一侧，共四种组合：

| 左 α 位置 | 右 α 位置 | γ | 语义流向 |
|---|---|---|---|
| Γ₁ | Δ₂ | α | 信息直接共享 |
| Γ₁ | Δ₁ | ⊥ | **不一致性**从 1 侧流向 2 侧 |
| Γ₂ | Δ₂ | ⊤ | **可满足性**从 2 侧流向 1 侧 |
| Γ₂ | Δ₁ | ¬α | 否定信息跨侧 |

**单前提规则（(∧⇒)、(⇒∨)、(⇒→) 及全部结构规则）：γ 原样传递**——
主公式落在哪侧，划分相应下放，γ 不动。

**双前提规则**的组合表（γ₁,γ₂ 为两分支的归纳插值子）：

| 规则 | 主公式位置 | 新插值子 |
|---|---|---|
| (⇒∧) | Δ₁ | γ₁∨γ₂ |
| (⇒∧) | Δ₂ | γ₁∧γ₂ |
| (∨⇒) | Γ₁ | γ₁∨γ₂ |
| (∨⇒) | Γ₂ | γ₁∧γ₂ |
| (→⇒) | Γ₁ | γ₁∨γ₂ |
| (→⇒) | Γ₂ | γ₁∧γ₂ |

∧/∨ 的选择有诀窍：**主公式留在本侧（结论侧要「合取两支的贡献」）
用 ∧；跨侧传递（每个分支单独足以支撑对侧）用 ∨**。机器不背口诀
——`interp` 按表计算，算出的 γ 立即被三条件语义验证兜底：

```coq
Definition cond1 (d : mder) : bool := ... (* taut2: ΛΓ₁ → ∨Δ₁∨γ *)
Definition cond2 (d : mder) : bool := ... (* taut2: γ∧ΛΓ₂ → ∨Δ₂ *)
Definition cond3 (d : mder) : bool := ... (* var 条件 *)
```

任何一行组合表写错，`taut2` 的全枚举都会当场报错——**构造与验证
互为审计**。

## 四、端到端账例

**例 1（共享变元）**：(p∧q)∨(¬p∧q) ⇒ q，划分把前件归 1 侧、后
件归 2 侧。推导是 (∨⇒) 下分两个 (∧⇒)，各自到公理 q⇒q。逐节点算：
公理格局 (Γ₁,Δ₂) 给 γ=q；两个 (∧⇒) 传递；根部 (∨⇒) 主公式在 Γ₁
给 γ₁∨γ₂——

```coq
Example exShare_interp : interp exShare = forr p1 p1.
Example exShare_ok :
  andb (cond1 exShare) (andb (cond2 exShare) (cond3 exShare)) = true.
```

插值子 q∨q——α 的全部有效内容（「q 真」）恰好是它与 β 的公共变元
能携带的。注意第 2 步 (∨⇒) 若主公式落 Γ₂ 则表给 γ₁∧γ₂（也是合法
插值子，只是划分不同）——插值子不唯一，组合表按划分确定。

**例 2（双支合成）**：(p∧q) ⇒ (q∧p)，划分仍是前件 1 侧、后件 2
侧。(⇒∧) 的主公式 q∧p 落在 Δ₂，表给 **γ₁∧γ₂**：左支贡献 q、右支
贡献 p——

```coq
Example exSwap_interp : interp exSwap = fand p1 p0.
Example exSwap_ok : ...
```

q∧p 不是省事的答案（γ=p∧q 本身就是整个结论）——它是组合表机械计
算的产物，两侧各取所需。

**例 3（常值流）**：p ⇒ p 但划分把两份 p 都归 1 侧（Γ₂=Δ₂=∅）。
公理四格局的 (Γ₁,Δ₁) 行给 γ=⊥：

```coq
Example exConst_interp : interp exConst = fbot.
Example exConst_ok : ...
```

cond2 变成 ⊥∧⊤→⊥ 恒真——「1 侧如果一致，2 侧（空侧）无恙」；γ=⊥
正是「不一致性从 1 侧流向 2 侧」的载体。对偶格局（双落 2 侧）给
γ=⊤——可满足性流向 1 侧。

## 五、直觉主义版与推论

定理 3.11 把同样的方法搬到 G0ip（直觉主义）：后件不可分（单公式整
体归 2 侧），组合表大体同形，但 **(→⇒) 主公式在 Γ₁ 的情形出现跨侧
组合 γ=γ₁→γ₂**——直觉主义特有的蕴含组合子（划分把前提 Γ→α₁ 分给
(Γ₂:Γ₁′)，两分量跨侧，唯有 → 能把它们接起来）。推论 3.7 给出 HJ
的 Craig 插值。机器面：直觉主义侧的三条件验证需要 Kripke 语义而非
真值表（16 章的工具），记文档线。

推论 3.6 的兑现：对 ⊢HK α→β，取矢列 α,β⇒ 的划分 (α:∅);(β:∅)，
插值子即满足 α→γ→β。本章三个账例的 cond1+cond2 合起来正是这两条
有效性的机器验证。

**插值定理的下游**：Beth 可定义性（隐定义可显化——文档线）、模态
逻辑的插值（书习题 6.17 提及 15 个系统的插值性质）、统一插值（类
比 57 章 G4ip 的「最强后承」）——以及模型论侧的对应定理（与 26 章（原 24 章）
的模型论对应定理呼应）。Craig 插值是「逻辑的信息守恒律」：**推导能
传递的，恰好是公共语言能表达的**。

## 小结

Maehara 方法把插值定理变成一个算法：划分随推导下放，组合表逐节点
合成 γ，无切割性保证归纳合法。机器件三件套——划分注记树、组合表、
三条件语义验证——让每一步构造都被真值表审计。下一章（59 章）回到
模型论的算术侧；73 章将把「结构规则工程学」带进模态逻辑。
