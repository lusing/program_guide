「可判定」的精确含义（H&R §2.5 开头）：**对全体输入停机且
答案正确的程序**。单看某个公式能否判断真假不是问题——问题
是**一致的程序**对所有公式成立。允许「只对可满足的停机」
的弱条件给出**半可判定**（r.e.）——FOL 有效式恰是这个档次
（23 章完备性 ⟹ 有效式可枚举：轮流试推导长度）。

## Post 对应问题：一个「人畜无害」的不可判定问题

归约证明需要一块已知的「硬骨头」。H&R 选用 **Post 对应
问题**（PCP）——形式上是个玩具，实质上是图灵机停机问题的
字符串化身：

> 给定有穷的字符串对序列 (s₁,t₁),…,(sₖ,tₖ)（si、ti 是非空
> 二进制串），是否存在指标序列 i₁,…,iₙ（n≥1，**指标可
> 重复**）使得 s_{i₁}s_{i₂}…s_{iₙ} = t_{i₁}t_{i₂}…t_{iₙ}？

**可解实例**（H&R 例）：{(1,101), (10,00), (011,11)}——取
指标序列 (1,3,2,3)：s 侧 1·011·10·011 = 101110011，t 侧
101·11·00·11 = 101110011——相等 ✓。

**手算困难实例**（H&R 给的第二个，仍可解）：
{(001,0), (01,011), (01,101), (10,001)}——邀请读者手工
求解，体感「搜索空间爆炸」。**指标可重复**意味着搜索空间
是无穷的（任意长度的指标序列）——不可判定性的直觉来源。
（PCP 本身的不可判定性 H&R 不证——归约自图灵机停机，
属可计算性理论。）

## 旗舰：PCP ⟶ FOL 不可判定的归约（H&R 定理 2.22）

**归约的骨架**：假设 FOL 有效性可判定，则 PCP 可判定——
与 PCP 不可判定矛盾。核心是造一个**多项式时间的翻译**：
PCP 实例 C ⟼ FOL 句子 φ_C，使得

```text
⊨ φ_C  ⟺  C 有解
```

**编码**（H&R 构造）：函数符号取常量 e 与一元 f₀、f₁——
把二进制串编码为项（**倒拼**）：串 b₁b₂…b_l ↦ f_{b₁}(f_{b₂}
(…f_{b_l}(e)))。记 f_{b₁b₂…b_l}(t) 为简写。再取二元谓词 P，
**意图**：P(s,t) 表示「存在指标序列使 s 侧拼出的串=s、
t 侧拼出的串=t」。

**φ_C 的三段结构**（φ₁ ∧ φ₂ ∧ φ₃）：

```text
φ₁ = ⋀ᵢ P(f_{sᵢ}(e), f_{tᵢ}(e))                起点：单步可达
φ₂ = ∀v∀w ( P(v,w) → ⋀ᵢ P(f_{sᵢ}(v), f_{tᵢ}(w)) )   封闭：可延长一步
φ₃ = ∃z P(z, z)                                  会合：两侧拼出同一串
```

直觉逐段读：φ₁ 说「用任一单指标起步的配对在 P 里」；φ₂ 说
「P 对『再拼一个指标』封闭」——归纳起来，P 包含一切「同
一指标序列」拼出的 (s 侧串, t 侧串) 配对；φ₃ 说「存在两侧
相等的配对」——**正是 PCP 的解**。

**双向论证**（H&R 证明的精妙处）：

- (⟸) 若 C 有解 (i₁,…,iₙ)：造 Herbrand 式模型——论域=
  全体二进制串，e^M=空串，f₀^M/f₁^M=尾接 0/1，P^M=「同一
  指标序列拼出的配对」集。逐条验证 φ₁φ₂φ₃ 真（解序列本身
  见证 φ₃）；
- (⟹) 若 ⊨ φ_C：取上面的标准模型 M（它是模型，故满足
  φ_C）——M ⊨ φ₃ 给出 z₀：P^M(z₀,z₀)，按 P^M 的定义
  展开即得指标序列——C 的解。

注意双向都靠**同一个模型**——「串的世界」既是构造 witness
的工厂又是检验有效性的考场。归约是能行且一致的（对任意
C 机械地写出 φ_C）——若 FOL 可判定，PCP 随之可判定——
矛盾。**Church 定理**成立：FOL 有效性不可判定。

**半可判定性**的另一半（r.e.）：23 章完备性把「有效」与
「可证」缝合，而证明可枚举——有效式半可判定。合起来：
FOL 是「能确认的，终会确认；不能确认的，永远跑着」——
sledgehammer/SMT 的有限资源搜索正是活在这个夹缝里。

## 表达能力天梯（H&R §2.6）

不可判定是**代价**，表达力是**回报**——FOL 比命题逻辑强在
哪？H&R 用**可达性**（reachability）问题标定精确的疆界。

**可达性**：有向图中，从节点 n 到 n' 有有限路径吗？（H&R
例 2.23 的四状态图：s₂ 从 s₀ 可达，s₃ 不可达。）程序验证
的核心查询——「坏状态能否从好状态到达」——就是它。

**定理 2.26：可达性一阶不可表达**——不存在以 u、v 为自由
变元、R 为唯一谓词的公式 φ，使 φ 在一切图中真 ⟺ u 到 v
有路径。**证明是紧致性定理（23 章预告）的漂亮应用**，值得
整段讲：

反设 φ 表达可达性。造句子集 Γ = {¬φₙ | n≥0} ∪ {φ[c/c']}，
其中 φₙ 说「c 到 c' 有长为 n 的路径」：

```text
φ₀ = (c = c')，φ₁ = R(c,c')，φₙ = ∃x₁…xₙ₋₁.(R(c,x₁)∧…∧R(xₙ₋₁,c'))
```

Γ 整体**不可满足**（φ 说有路径，各 ¬φₙ 说没有任何长度——
路径必有有限长度，矛盾）。但 Γ 的任何**有穷子集**可满足
（取一条足够长的路径，让涉及的有限个 ¬φₙ 与 φ 同真——
其余 ¬φₙ 不在场）。紧致性说「有穷子集皆可满足 ⟹ 整体可
满足」——矛盾。故 φ 不存在。∎

直觉复盘：可达性是「**存在有限长路径**」——一个无界存在
量词叠在任意深度上；FOL 公式的量词深度是**固定**的，表达
不了「任意深」。20 章的 T_P 走查例（传递闭包）正是这个
现象的程序版：两条规则+lfp 表达了传递闭包，但那已经超出
FOL——**逻辑程序的最小不动点语义天然是二阶的**。

**二阶逻辑：花多少钱买回可达性**（H&R §2.6.1-2.6.2）：
把量词许可扩展到谓词符号——**存在二阶逻辑**（ESO）公式

```text
∃P ∀x∀y∀z (C₁ ∧ C₂ ∧ C₃ ∧ C₄)
```

（Cᵢ 为四个 Horn 条件——P 是传递的、包含 R、极小化……）
恰好表达可达性——H&R 式 (2.12)。ESO 的表达力定位：
**NP 恰好 = ESO 可表达的谓词**（Fagin 定理，复杂性理论的
逻辑刻画里程碑）。对偶的**全称二阶**（USO）抓 co-NP。
天梯总览：

```
命题 ⊂ FOL ⊊ ESO/USO（二阶）    每升一级：表达力↑ 可判定性↓
              ↑
        可达性在这层断掉（FOL 不够、ESO 够）
```

## 机器现场

**Isabelle（presburger 现场三连）**：

```isabelle
lemma presburger_demo:
  "∀x::int. ∃y. 2 * y ≤ x ∧ x < 2 * y + 2"
  by presburger
```

`presburger` 方法是 Cooper 算法的实现——整数量词消去，
线性算术的完全决策程序（非启发式）。与 DPLL（09 章）构成
「组合决策」的两半（布尔 + 算术 = SMT 的 DPLL(T) 架构）。
**DPLL(T)**：布尔骨架交给 SAT 求解器，理论原子（算术/数组/
未解释函数）交给理论求解器 T，两者按命题模型交换约束——
z3/cvc5 的架构。FOL 不可判定性决定了 SMT 只在**片段**上
完全（线性算术、数组……），全一阶只能半判定。

**Lean（Decidable 的命题面）**：

```lean
example (x y : Nat) : Decidable (x = y) := instDecidableEqNat x y
```

`Decidable P` 类型的**存在性**即「P 可判定」的机器表述——
decide 求值、instance 搜索、内核转换都走这里。bounded 量词的
可判定性来自 `List.all` 的有限性——unbounded 量词破坏
有限性正是一阶不可判定的起点。

## 本章小结

- 可判定=全输入停机的正确程序；半可判定=r.e.——FOL 有效式
  属后者。
- PCP：指标可重复的无穷搜索问题——归约的硬骨头；手算两个
  实例体感难度。
- 归约三段结构（起点/封闭/会合）+ 同一模型的双向论证——
  Church 定理的完整证明。
- 可达性一阶不可表达：紧致性的反证（任意深 vs 固定深度）；
  ESO 用谓词量词买回它（Fagin：ESO=NP）。
- SMT=DPLL(T) 组合决策——活在不可判定夹缝里的工程。
