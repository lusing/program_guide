## 一、BC：带二阶变元的 LK

Def 15.3 的基演算 BC=「带二阶变元的 LK」，不加任何 comprehension。二阶
量词四条规则与一阶**逐字平行**——对偶在「左/右」：

```coq
(* 二阶 !:left：!P_n F 实例化为 F(V)——V 任意（左=无约束侧） *)
| ballL2 (s : sqt) (n : nat) (V : s2f) (sub : bdr)
(* 二阶 !:right：F(P_q)——P_q 本征：不入下矢列（右=泛型侧） *)
| ballR2 (s : sqt) (n q : nat) (sub : bdr)
```

机器件 `bchk` 逐节点对账。正例：⇒∀P₀(P₀→P₀)——内层 →:right（公理
P₁⇒P₁ 升为 ⇒P₁→P₁），外层二阶 ∀:right（本征 P₁ 异于量化变元、不入
下矢列）：

```coq
Definition dAllR2 : bdr :=
  ballR2 ([], [pall 0 (simp (pvar 0) (pvar 0))]) 0 1
    (bsimpR ([], [simp (pvar 1) (pvar 1)])
      (bax ([pvar 1], [pvar 1]))).
Example bcAllR_ok : bchk dAllR2 = true.
```

反例抓住 eigenvariable 违规（Def 15.3 条件：本征变元不出现在下矢列）——
把 P₁ 放进下矢列前件，检查器立即拒绝：

```coq
Example bcAllR_bad : bchk dAllR_bad = false.
```

左规则账例：∀P₀P₀ 实例化 V:=R₀(c₁)（任意抽象都行——comprehension 的
「读入侧」）。**左任意实例 vs 右本征变元**——这对偶就是 34 章（语义侧）
「∃X 跑全部关系表」的语法面。

## 二、comprehension 谱系与「模式=代入像」

BC 之上加 comprehension 得谱系（Def 15.14-15.17）：**K₁C**=抽象限一阶
公式（预备性）、**G²LC**=全 comprehension。K₁C 有构造性切消（定理 16.5：
三重归纳——对（二阶量词数 c, 度 g, 秩 rank）的字典序，关键引理 c(F(V))
=c(∀φF)−1 使归纳可行；文档线）。**命题 16.7（有限实例化）**是谱系的灵魂：
无切 K₁C 证明中，前件的 ∀φF(φ) **只被打开有限次**，每开一次代一个一阶
抽象——二阶全称在无切层退化为「有限多个一阶实例的合取」。三个立刻的
红利（保守性三连）：BC 保守于 LK、PA′（二阶归纳单句版）保守于 PA、
BG 保守于 ZF（问题 16.10/16.11——89 章 NBG 的「有限公理化不添力」在
这里是证明论定理）。

「模式=代入像」机制（例 15.12 三连）：**等词公理模式**、**归纳模式**、
**替换公理模式**各是一条二阶单句经抽象代入生成的像——

```coq
Definition indSchema : s2f :=
  pall 0 (simp (sand (pvar 0) (pvar 0)) (pvar 0)).  (* 命题级示意 *)
Definition instancesOf (sch : s2f) (Vs : list s2f) : list s2f :=
  map (instOf sch) Vs.
```

一阶归纳模式 VJ 的每个实例 = VJ 实例化 P:={x|B(x)} 的像——「一条二阶
句装载全部一阶模式」。命题 16.7 说这个装载在无切证明里**只兑现有限张**：
这正是「PA′ 不比 PA 强」的机制内核。

## 三、相对化：翻译+搬运+一致性传递

§17 的三件套（机器件 `rel`）：

**翻译**（Def 17.1）：每个量词出膛时挂域闸门——

```coq
Fixpoint rel (r0 : s2f) (a : s2f) : s2f :=
  match a with
  | tall b => tall (simp r0 (rel r0 b))   (* !x b ↦ !x (D(x) -> b^r) *)
  | ttex b => ttex (sand r0 (rel r0 b))   (* ?x b ↦ ?x (D(x) /\ b^r) *)
  | ...
```

∀ 挂 ⊃、∃ 挂 ∧（经典语义的标准搭配——47 章 53 章的双否定翻译是它的
直觉主义近亲）。**域闭包** Φ_r：常元在域内、函数保域、域非空（引理
17.6：项落域）。**搬运**（引理 17.5）：对证明的推理数归纳、逐规则过闸
——Γ⇒Δ 可证则 D(ā),Γ^r⇒Δ^r 可证。**出口**（定理 17.8）：解释=翻译
+一致性传递——𝔄∪𝔅 可解释在 𝔅 中则 𝔅 一致⟹𝔄∪𝔅 一致。定理 17.10
两步复合证「经典分析相对一致」：先把二阶等词闸到「等词不变谓词」、
再把数论域闸到「属于每个归纳集的自然数」——两步都是 `rel` 的实例。

语义对账（机器面在有限结构上）：**全域真⟺限域相对化真**（引理 17.5
的样本面）——∃xR₀(x) 全域真（c₁ 见证）且相对化真；∀xR₀(x) 全域假
（c₂ 反例）且限域版同假（c₂ 在域内）。**分离账**最能说明「翻译无损」
的方向性：结构 B 中 R₀={c₁,c₂} 而域={c₁,c₂}——∀xR₀(x) **全域假**（c₃
反例）但**限域真**（域内无反例）：

```coq
Example relSemSplit :
  andb (negb (s2ev iextB ... (tall (sat 0 0))))    (* 全域假 *)
       (s2ev iextB ... (rel (sat 1 0) (tall (sat 0 0)))) = true.  (* 限域真 *)
```

量词被关进域内——外部的反例不再作数。一致性传递正是靠这个「关」：
翻译后的系统只在域内说话，域外的麻烦与它无关。

## 四、分层真值定义：绕开 Tarski 的机制

§18 的主线（机器件 `truthDef`/`extend` 的三层迷你版）：**真值定义不一次
给出，而是逐层逼近+归纳焊接**。F(α,n)：「α 是复杂度≤n 层的真值定义」
（三条款：¬/∧/量词按真值条件逐款定义）；E(β,α,n)：「β 是 α 的 n+1 层
扩张」（引理 18.5(4)：扩张总存在——机器件的 `extend` 给第 4 号新句子
按析取真值条款打补丁）；T(a):=∃层 α 查值。**全部代价只有一个非算术
步骤**：Π¹₁-ind 焊接「每层真值定义都存在」（命题 18.6）。定理 18.13：
**T('A')≡A 在 S₁ 中可证**——「在二阶算术里定义了一阶算术的真」。

```coq
Definition truthDef (iext : nat -> nat -> bool) (alpha : nat -> bool) : bool :=
  andb (layerOK iext alpha)                       (* 层内正确 *)
       (andb (Bool.eqb (alpha 2) (negb (alpha 0)))      (* ¬ 条款 *)
             (Bool.eqb (alpha 3) (andb (alpha 0) (alpha 1)))). (* ∧ 条款 *)
Example tdHolds : truthDef iextA (trueAlpha iextA) = true.
Example extPreserves :
  andb (truthDef iextA (extend iextA (trueAlpha iextA)))
       (Bool.eqb (extend iextA (trueAlpha iextA) 4)
                (orb (iextA 0 1) (iextA 1 2))) = true.
```

**为什么不算违反 Tarski**（54 章的正面对照）：Tarski 不可定义说的是
「PA 的真不在 **PA 的语言**里」；T 是 Π¹₁ 公式——量了二阶变元（一层层
的真值表），PA 语言里没有这种量词。**语言升一层，禁区落在脚下**。下游
三连（18.16 反射 Pr('A')⊃T('A')、18.17 Consis(PA) 在 S₁ 可证）由「逐规则
搬运」完成——与 §17 的搬运引理同一母题。

## 五、S₁⊂S₂⊂S₃ 与 Takeuti 猜想（谱系表+文档线）

§19 把分层真值升级为**解释**：S₂=算术 comprehension+完全归纳；S₃=
Π¹₁-comprehension+Π¹₁ 归纳（≈Π¹₁-CA₀）。关键款：二阶全称 ∀φ 翻译成
「对全部**闭算术抽象的码**的数字量词」——谓词变元的域=算术可定义集合
（`cab` 域）。定理 19.16：**Consis(S₃) 在 S₂ 可证**——语义读法：「算术
集合构成 Π¹₁-CA 的内模型」。谱系表数据件 `hierarchy` 收录三系统的一句话
档案。逆数学（Simpson 附录）：日常数学定理按「证明所需的最小子系统」
定位——RCA₀<ACA₀<Π¹₁-CA₀ 的标尺正是这里的 S 谱系。

**§20-§21 Takeuti 猜想（文档线）**：简单类型论=「抽象升格为形式对象
（项）」的 G²LC，量词作用于一切型；其切消即 Takeuti 1954 猜想，Tait 证
二阶情形、Takahashi/Prawitz 独立全解、Girard 1971 改进（可还原性方法的
前身）。方法对照表（digest_C §21 整理）：**Gentzen 原法**=纯语法重写+
序数测度（构造性）；**Tait 法**=对切割度归纳+可换性引理；**Takahashi-
Prawitz 法**=语义反证（归约树→半赋值→诱导 Henkin 结构→反例模型，与
完备性一枚硬币两面——**非构造**）。命题 15.18 的警示在此兑现：G²LC 的
切消是非构造的，故有穷主义立场不能据此声称其一致性。另一件珍品是
**pre-Henkin 序对语义**（Def 21.16）：无外延性公理时同外延的两谓词不可
等同——语义对象取「名字+外延」序对，把 intension 显式带入语义——这是
Henkin 广义语义（34 章文档线）的严格形状。

## 小结

BC 的左右对偶是二阶量词的语法指纹；「模式=代入像」解释了为什么一条二阶
句能装载全部一阶公理模式，而有限实例化（命题 16.7）又把这装载压回有限；
相对化把「解释」变成翻译函数+逐规则搬运（一致性传递的语法机器）；分层
真值用「逐层逼近+一次 Π¹₁-ind 焊接」绕开 Tarski（语言升层的艺术）；
S 谱系通向逆数学。下一章（37 章）把「量词」推到无穷 arity——无穷逻辑
与决定逻辑，AD 与切消的等价将把「证明论强度=集合论公理」的暗线挑明。
