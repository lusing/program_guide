上一章（90，旧 89）从模型论的外部逼近算术的天花板：非标准模型、
overspill、Paris–Harrington。本章走一条反向的路——**从算术身上一件件
减衣服**，看哪一件是「不完备性」的真正成本。郝书第八章的纲领：把标
准模型 ℕ 的语言逐步削弱为 (ℕ,0,S)、(ℕ,0,S,<)、(ℕ,0,S,<,+)，逐级证明
**量词消去、完备性、可判定性**；最后一件衣服 + 脱掉之后只剩乘法
(ℕ,0,×)，竟然**还是可判定的**（Skolem）；可一旦把加法用乘法定义回
来（习题 8.5.7），整个 (ℕ,S,+,×) 就回来了——不可判定与不完备（76/78
章）在门口等着。这条「完备阶梯」是可判定性理论的发源地，也是理解
「加法无害、乘法致命」这句行话的最好教具。

## 一、非标准模型与上下行 Löwenheim–Skolem（8.1）

一切从紧致性出发。先把**皮亚诺算术一阶化**：语言
L_ar = {0,S,+,×}，PA = 七条公理的全称概括——Sx≠0、S 单射、非零元
有前驱、x+0=x、x+Sy=S(x+y)、x·0=0、x·Sy=x·y+x——加上**归纳公理模
式** I_φ（对每个 L_ar 公式 φ 的归纳公理）。Peano 本人的原始版本是
二阶的（归纳取遍「一切子集」），一阶化后归纳只能取遍「一切公式」，
这个降格正是不完备性的入口。

**例 8.1.1（非标准模型的存在）**：扩展语言加新常量 c，考察
PA ∪ {0<c, S0<c, SS0<c, …}。任何有限子集在 ℕ 中可满足（c 解释为足
够大的数），故由紧致性整体可满足，且可取可数模型。若它与 ℕ 同构，
c 的像须大于一切标准数——与抽屉原则矛盾。于是 PA 有**非标准模型**。

配套的基数工具箱在 8.1.2–8.1.3 一页内给齐：等势、康托尔定理
(P(ω) 不可数)、基数算术吸收律（κ≤λ、λ 无穷 ⟹ κ+λ=λ、κ·λ=λ）、
「无穷集上有穷序列集与它等势」。然后是两条 **Löwenheim–Skolem 定
理**：下行版（可满足公式集有 ≤κ 的模型，κ 为语言势——证明走完全性
定理的 Henkin 商结构，论域是项的等价类）与上行版（无穷模型可膨胀
到任何 λ≥κ——加 λ 个互异常量再压回）。43 章已把这两条当作工具用
过；郝书的价值在于给出**证明概要**本身。

本节的收官是**斯寇伦伴谬**（Skolem paradox，书据杨东屏建议译「伴
谬」——与悖论不同，它本身不含矛盾）：ZFC 语言可数，下行 L-S 给出
ZFC 的可数模型 A；而康托尔定理是 ZFC 内定理，A 里自然有「不可数
集」P(ω)。「可数模型里有不可数集」并不矛盾——「不可数」是**里面
的**概念（没有到 ω 的双射住在 A 里），78 章反复演练的内外之辨在这
里第一次以悖论面目出场。书里还留了段花絮：Skolem 本人是不信不可
数集的形式主义者，据说认为自己的名字与这定理挂钩是耻辱。

## 二、完备理论与可判定理论（8.2）

先把名词钉死。**理论** T 是对语义蕴涵封闭的闭句集；Th 𝔄 是 𝔄 中
真闭句全体；**完备**理论对每个闭句 α 有 α∈T 或 ¬α∈T（引理 8.2.1 给
五个等价刻画：真扩张不一致 / T=Th𝔄 / 任意两模型初等等价 / …）；
**可公理化**=有递归公理集；**可判定**=成员资格递归（精确版要等哥德尔
编码：#T 递归）。三条引理构成本节主轴：

- **引理 8.2.2**：完备+可公理化 ⟹ 可判定。枚举证明序列，完备性保证
  α 或 ¬α 迟早出现——「正反互补可枚举 ⟹ 可判定」，正是 71 章递归
  论里「r.e. 且余 r.e. 则递归」的模型论应用。
- **康托尔定理（8.2.1）**：可数无端点稠密线序都同构于 (ℚ,<)——
  DLO 是 ℵ₀-范畴的（来回法，44 章 EF 博弈的同门）。
- **Łoś–Vaught 判别法（8.2.2）**：可数语言 + 某无穷基数 λ-范畴 + 无
  穷模型 ⟹ 完备。证明是漂亮的三明治：任两模型用上下行 L-S 压到 λ、
  λ-范畴给同构、同构强于初等等价。ACF_p 的 ℵ₁-范畴（Steinitz）与
  DLO 的 ℵ₀-范畴立刻产出推论 8.2.1：Th(ℚ,<) 与 ACF_p 可判定——
  48/47 章的量词消去在这里先以「范畴性」的面目立功。

## 三、只含后继的自然数模型（8.3）：ℤ-链与量词消去

现在正式登上阶梯。最底层：𝔑ₛ=(ℕ,0,S)，语言 Lₛ={0,S}。刻画它的公理
集（全称概括）：

- (S1) ∀x 0≠Sx；(S2) Sx=Sy→x=y；(S3) x≠0→∃y x=Sy；
- (S4.n)（模式）从 a₀ 出发 n+1 步后继回不到 0。

**模型长什么样**（引理 8.3.1）：任何模型都含**标准部分**
{0,S0,SS0,…}；非标准元素 a 拖着自己的前驱链与后继链——「像整数一
样的一条 **ℤ-链**」。定义 a∼b ⟺ Sⁿ(a)=b 或 Sⁿ(b)=a，则每个 ∼-类或
是标准部分、或是一条 ℤ-链，**模型由 ℤ-链的条数完全决定**。推论
8.3.1：Tₛ 非 ℵ₀-范畴（可数模型可带任意有穷/可数条链）但 ℵ₁-范畴
（ℵ₁·ℵ₀=ℵ₁），于是 Łoś–Vaught 给出**完备+可判定**（推论 8.3.2/8.3.3）。

机器面给这条定理两份「有限影子」。Prolog 通道枚举 [4] 上的全部函
数：24 个双射（(S2)+(S3) 的有限化身）**全部分解为圈**——有限世界里
ℤ-链蜷成了圈，(S4.n) 模式存在的意义就是逐个杀死它们；而同时满足
(S1)+(S2) 的全函数**一个也没有**（单射+0 不在像中+有穷域，鸽笼直
接矛盾）——**Tₛ 没有有限模型，标准部分与 ℤ-链都必须无穷**。Coq 通
道把后一条定理化（`no_finite_successor`：自证 `NoDup_map_seq` 小件
+`NoDup_incl_length` 计数，n 个互异像塞进 n−1 个位置），Isabelle 通
道用 `card` 一行结账：

```isabelle
lemma no_finite_successor:
  fixes f :: "nat \<Rightarrow> nat"
  assumes "0 < n" and "\<forall>i<n. f i < n" and "\<forall>i<n. f i \<noteq> 0"
          "\<forall>i<n. \<forall>j<n. f i = f j \<longrightarrow> i = j"
  shows False
```

**量词消去**（8.3.2）是本章的手艺核心。定义：理论 T **接受量词消去**，
若每个公式都 T-等价于某个无量词公式。塔斯基引理（8.3.2）把检验量砍
到最低：只需处理 **∃x(α₀∧…∧αₙ)**，αᵢ 是原子式或其否定——把任意公
式化前束范式、母式化析取范式、量词逐层往外剥即可。

**定理 8.3.1**：Th𝔑ₛ 接受量词消去。证明的三个断言是全部技术所在：
断言 1 把原子式归约到「Sᵐx ~ t 或其否定」；断言 2 说全否定情形恒真
（无穷多个 x 总能避开有穷多个禁值——这就是 ℤ-链的「两头无穷」在
语法侧的兑现）；断言 3 是 **bump 引理**：有等式 Sᵐx~t 时，把其余原子
式里的 x 统一「垫高」代入（Sᵏx~u 变成 Sᵏt~Sᵐ⁺ᵏ... 型的 x-自由式）。
机器面把断言的语义核写成等价定理：

```coq
Lemma bump_sem : forall k m t u,
  (exists x, x + k = t /\ x + m = u) <-> (t + m = u + k /\ k <= t).
Proof. intros; split; [intros [x [H1 H2]]; split; lia
                     | intros [H1 H2]; exists (t - k); lia]. Qed.
```

（S 的迭代即加法：Sᵏx = x+k。）`Scancel`（注入性约层）、`no_cycle`
（无圈）两条陪跑。Prolog 通道把整个流程做成**消去器**（第六节详解），
对拍三题：E1/E2「∃u. x=Su」（补有限集）、E3「∀u. x≠Su」——机器语义
是 ℤ 的（见第六节的内外之辨）。

## 四、包含后继和序的自然数模型（8.4）：min-见证

第二级：𝔑₍ₛ₎=(ℕ,0,S,<)。模型仍是标准部分+有序 ℤ-链，但**链的序
型**可以不同（(ℕ,<)-索引与 (ℚ,<)-索引的链序不同构），于是对任何 λ
都不范畴——**Łoś–Vaught 判别法失效**（习题 8.4.1），完备性只能靠量
词消去直接拿。

**定理 8.4.1**：Th𝔑₍ₛ₎ 接受量词消去。原子式多了 Sᵐu<Sⁿv；断言 1 用
线序把否定式裂掉（¬(u<v) ≡ v<u ∨ v=u）。核心是纯不等式情形
∃x(Λᵢ tᵢ<S^{mᵢ}x ∧ Λⱼ S^{nⱼ}x<uⱼ) 的三个子情形：无上界则恒真（子
情形 2.1）；无下界取 x:=0 见证（子情形 2.2——ℕ 有最小元，这是 ℕ 侧
独有的账）；双侧都有则取 **d = minⱼ(uⱼ−nⱼ)−1** 为见证（子情形 2.3，
断言 5 的 min-演算：d 满足全部上界因 d≤一切候选，满足全部下界因
S^{mᵢ}tᵢ<u_{j₀} 恰好说 tᵢ 的垫高够不到 d）。消去后的 δ₃ 形如
∧ᵢⱼ S^{mᵢ+nⱼ}tᵢ<uⱼ——习题 8.4.3 特意要求给反例说明垫高项不可省
（否则「见证」可能是负数）。机器面的语义核：

```lean
theorem min_witness (w u : Nat) : (∃ x, w < x ∧ x < u) ↔ (w + 1 < u) := by
  constructor
  · intro ⟨x, h1, h2⟩; omega
  · intro h; exact ⟨w + 1, by omega, by omega⟩
```

与 `zero_witness`（(∃x. x < u) ↔ 1 ≤ u）。推论 8.4.1 给可判定性；推
论 8.4.2 刻画可定义集：**X⊆ℕ 在 𝔑₍ₛ₎ 中可定义 ⟺ X 有穷或余有穷**
（对拍账见第六节）。8.4.5 习题列出 A₍ₛ₎ 的一组公理（(S1)(S2)(S3)
+离散线序五律），T₍ₛ₎ 是 Th𝔑₍ₛ₎ 的有穷公理化；习题 8.4.4 顺带证
明**加法图像在 𝔑₍ₛ₎ 中不可定义**——序还不足以定义加法，这是阶梯
下一级的悬念。

## 五、普莱斯伯格算术（8.5）：同余是唯一的阻碍

第三级：𝔑₊=(ℕ,0,S,<,+)。加法一来，非标准 ℤ-链的序型立刻被锁死：
a+a 必须落在**另一条**链里（同一链内元素之差都是标准数），平均值
∃y(y+y=a+b) 保证链序**稠密无端点**——与 PA 非标准模型的链序同款。
**定理 8.5.1（Presburger 1929）**：Th𝔑₊ 可判定。

纯 + 语言的量词消去**失败**，而且失败得恰到好处：∃y(y+y=x)（「x
是偶数」）不等价于任何无量词的 + 公式（习题 8.5.1——第六节的对拍
账就是这句话的机器证据）。但这是**唯一的**阻碍：把语言扩张为
L≡ = L₊ ∪ {≡₂,≡₃,…}（≡ₖ 为模 k 同余），则 **Th𝔑≡ 接受量词消去**——
同余谓词是量词消去必须付出的语法税。

消去的流水线（断言 1–5）：
- 断言 1：否定裂解——¬(u≡ₘv) 裂成 m−1 个同余式的析取；
- 断言 3（**系数归一**）：用引理 a≡ₘb ⟺ ka≡_{km}kb 把 x 的系数统一
  到公倍数 K，换元 y:=Kx 并撒下同余 y≡_K 0——一切原子式变成 y 的
  系数恰为 1；
- 断言 4（**候选表**）：纯界+同余 ∃y(∧下界 ∧∧上界 ∧∧同余) 的解若
  存在，则在表 {Lᵢ..Lᵢ+(M−1)} ∪ {0..M−1}（M=诸模数的 lcm，Lᵢ=下
  界多项式）中必有一行命中——解只需在「最小残类点」附近找；
- 断言 5：把候选表回填成无量词的 ∨∧ 布尔组合。

闭句于是化归为 Sᵐ0<Sⁿ0、Sᵐ0≡ₖSⁿ0 的布尔组合——一眼可判。
**定理 8.5.2**（可定义集刻画）：X⊆ℕ 在 𝔑₊ 中可定义 ⟺ X **最终周
期**（∃M,p ∀n>M: n∈X ⟺ n+p∈X）——原子式定义的集合最终周期，布
尔组合保持；反向把周期编码成同余式的有限析取。**推论 8.5.1**：乘法
图像不可定义（{(m,n,p): p=mn} 不最终周期）。**定理 8.5.3（Skolem）**：
只含乘法的 (ℕ,0,×) 理论也可判定——证明是一次漂亮的换元：原子式
n·u~v 取「对数形式」nX+U~V（变元 Z=log₂z），对数形式是 Presburger
的，消去后同余式 n≡ₘr 还原成指数形式 ∃y(2ⁿ=yʳ) 即可判定。

最后是习题 8.5.7 的彩蛋：**加法在 (ℕ,S,×) 中可定义**。考虑方程

$$S(ac)\cdot S(bc) = S\big(c\cdot c\cdot S(ab)\big)$$

展开：(ac+1)(bc+1) = c²(ab+1)+1 ⟺ abc²+c(a+b)+1 = abc²+c²+1 ⟺
**c·(a+b) = c²** ⟺ c=0 ∨ a+b=c。三通道都把它写成定理：

```coq
Lemma id857 : forall a b c,
  (a * c + 1) * (b * c + 1) = c * c * (a * b + 1) + 1 <-> (c = 0 \/ a + b = c).
```

注意 c=0 的行对一切 a,b 都满足——方程本身定义的是 {c=0}∪加法图，
严格定义公式要加 c≠0 边条件（或补 (a=0∧b=0∧c=0) 分支）；Prolog 通
道用 [0..6]³ 网格全验证恒等式并打印这个边条件警示。这条习题的意
义是致命的：(ℕ,S,×) 能定义加法 ⟹ 它与 (ℕ,S,+,×) 一样复杂 ⟹ 其理
论不可判定——**乘法单独无害（Skolem），加法单独无害（Presburger），
二者相会即是哥德尔的领地**。

## 六、机器面：消去器、对拍与三处实战坑

Prolog 通道是本章的发动机（`ex91_presburger.pl`，约 420 行）。语法：
项 z/v(N)/s/add/sub/mulc，公式 eq/lt/cg(K,A,B)/neg/andd/orr/ex/all。
消去流水线忠实于书：`negfree`/`negnf` 做否定裂解，`dnf` 出析取支，
`split_atom` 把每个原子式劈成「a·x+P ⋈ 0」的线性形（`poly` 多项式
正规形），`rescale` 做断言 3 的系数归一（不等式乘正数保号、同余乘 c
连模数一起乘——引理 a≡ₘb⟺ca≡_{cm}cb），然后等式解出代入或走
候选表。三阶测试全绿：

```text
--- stage 1: L_s = {0,S} (thm 8.3.1) ---
  [OK] E1/E2/E3 ...
--- stage 2: L_o = {0,S,<} (thm 8.4.1) ---
  [OK] O1/O2/O3 ...
--- stage 3: L_+ = {0,S,+,<,=_k} (thm 8.5.1) ---
  [OK] P1 ex y. y+y=x (evens, cong 2) ...
  [OK] P2/P3/P4 ...
--- closed sentences ---
  [OK] D1 every number even or odd / D2-D4 ...
```

对拍口径：一元公式消去结果与暴力求值在 [0..13) 逐点比对；闭句用有
穷窗口搜索。三处实战坑记录在案（CHEATSheet 同步）：

1. **候选表的 off-by-one**。行基点最初抄书的「下界 Lᵢ」，对拍 O1
   （∃u(x<u∧u<x+2)）全线翻车：见证 u=x+1 是 L+1。数学复盘：严格
   下界 L<u 的最小残类点是 L+1 起算的；且**ℤ 语义**下无下界时残类
   向下无界（恒真），与书在 ℕ 语义用「x:=0 见证」的子情形 2.2 是两
   套话。终稿行族＝下界+1 ∪ {0} ∪ 上界−1。
2. **ℤ/ℕ 内外之辨**。书的 u−t 记法自认「严格地说不规范」——机器面
   以 sub/2 项镜像之，语义按 ℤ 实现（ℕ 理论=ℤ 理论加 x≥0 界，可表
   达故归约无损）；暴力对拍的窗口也按 ℤ 开。D3 的测试名干脆写明
   「Z-true; N-false at 0」——同一句子的两套真值，正是 78 章「外面
   /里面」的算术版。
3. **窗口分层**。∀x∃u. x=Su 的暴力判定最初全错：∀ 用窗 [−14..26]，
   x 落在窗缘时见证 u=x−1 掉出 ∃ 的窗。分层窗口（∃ 宽 ∀ 窄）后，
   「见证余量」成为对拍协议的一部分。

Isabelle 通道的主角是战术现场：`bump_sem`、`min_witness`、
`even_or_odd`、`cong_elim` 全部 `by presburger` 一行清账——郝书第八
章的断言在 Isabelle 内建的 Cooper 算法面前不值一行证明脚本，这本身
就是「量词消去作为可执行算法」的最好展品（对比 90 章的 `presburger`
现场，这里按书的断言逐条对号）。Lean 侧 `omega` 同样清掉线性部分，
但**不解 ∃ 目标**（只吃无量词片段+∀ 假设）——奇偶递推只能手工走
归纳，分支内 omega 收尾；这是 omega 与 presburger 战术面的真实差
距，90 章的 SMT 梯子在此多了一格。

qf-阻碍账（习题 8.5.1 的证据面）在 Prolog 通道：取 14 个纯 + 语言单
变元原子式（x=k, k≤4 与 2x=k, k≤8），计算 [0..24) 上的「签名类」。
原子式把 [0..9) 打成单点、[9..24) 留成一整类，于是 qf 可定义集恰是
「有限或余有限（样本内）」；偶数集需要在大类里挑偶不挑奇——**混
parity 类的存在**一句话封死。这是 10 章式「独立性检查器」的模型论
版：不可定义性的有限证据。

## 小结

阶梯走完，账目如下：后继算术——ℤ-链分类、范畴性两极、QE、可判
定；序算术——范畴性失效、min-见证 QE、有限/余有限；Presburger—
—同余税、候选表、最终周期、可判定；乘法算术——log₂ 换元、可判
定；加乘相会——8.5.7 恒等式、崩塌。下一级台阶就是 76/78 章的不完
备性：从「加法定义乘法/乘法定义加法」的那一刻起，对角化引理有了
立足之地。郝书把这架梯子放在不完全性定理**之前**讲授，本教程把它
放在模型论（90）与可判定性总论（92）之间——无论哪种顺序，它回答
的都是同一个问题：**表达力的哪一克重量压垮了可判定性？**
