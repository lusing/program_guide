第 22 章把完备性做成了「协调必有模型」的机器现场；这一章收割完备
性的三个推论：Löwenheim–Skolem（可数语言的可满足理论有小模型）、
紧致性（有限可满足⟹可满足）、以及初等等价的刻画。EFT 第 VI 章的
路线与 H&R 不同：紧致性从完备性/Henkin 直接推（不是独立公理），
所以上一章的构造在本章处处回声。

## 一、Löwenheim–Skolem：模型大小的自由度

**向下 L-S**：可数语言的可满足句子集有至多可数的模型。证明骨架：
给任意模型取「闭于 Skolem 函数」的可数子集——函数闭包保持初等性
（对每个公式，Skolem 化后见证留在闭包里）。机器面取最简现场：论
域 Z_n 配环绕后继 f，从种子 {1} 出发做**函数闭包**：

```coq
Fixpoint skclose (n : nat) (seed : list nat) (fuel : nat) : list nat :=
  match fuel with
  | O => seed
  | S fuel' =>
      let S' := seed ++ map (succ_wrap n) seed in
      if subsumeq S' seed then seed
      else skclose n (nodup_eq S') fuel'
  end.
```

Z₅ 里从 {1} 出发：f 的轨道走遍全域（环绕！）——闭包=Z₅；Z₆ 里从
{0} 出发同理。**向上 L-S**（有任意大的模型：加 n 个新常量+互异公
理，紧致性收尾）的形态正是下面 σₙ 族的用法。Skolem 悖论（可数
模型里「谈论」不可数集）在 22 章（原 23 文档线）已走查。

## 二、紧致性：一阶逻辑的「局部-整体」原理

**定理**（VI.2.1）：Φ 的每个有限子集可满足 ⟹ Φ 可满足。EFT 的证
明走完备性路线：有限子集可满足 ⟹ 有限子集协调（可靠性）⟹ Φ 协调
（矛盾推导只用有限多条前提）⟹ Φ 有模型（Henkin）。

机器证词取**「有限性不可单句定义」**这个经典推论：

> 不存在一阶句子 σ 使得「σ 真 ⟺ 论域有限」。

反证：若有 σ，考察 Φ := {σ} ∪ {σₙ : n∈ℕ}，其中

$$\sigma_n := \exists x_1 \cdots \exists x_n \bigwedge_{i<j} x_i \not\equiv x_j$$

（「至少 n 个不同元素」）。Φ 的每个有限子集在足够大的**有限**结构
上可满足（σ 真、有限个 σₙ 真）；但 Φ 整体要求模型有限又无界大——
不可满足。矛盾于紧致性。机器面把两端算死：

```coq
Example sigmas_satisfiable :
  andb (trueZn 2 sigma2) (andb (trueZn 3 sigma3) (trueZn 4 sigma4)) = true.
Example sigma4_fails_small : negb (trueZn 3 sigma4) = true.
```

σ₄ 在 Z₃ 上假——元数下界随 n 严格增长，任何有限结构终会「不够
大」。这就是「有限可满足但整体只有无限模型」的最小现场。

## 三、DLO：只有无限模型的公理组

稠密线序无端点（DLO）六公理：线序三（反自反、传递、完全）+ 稠密
+ 无端点两侧。机器在 Z₁..Z₇ 上穷举：

```coq
Example dlo_no_finite_model :
  forallb (fun n => negb (forallb (fun φ => trueZn (S n) φ) dlo_axioms))
    (seq 0 7) = true.
```

三个失守点各有一个「罪魁」：**无端点**在任何有限线序上假（最左元
素无左邻）；**稠密**在任何 ≥2 元有限线序上假（相邻对之间没有第三
个元素——Z₂ 与 Z₃ 都倒在这里）；线序三公理则在 Z₃ 上安然成立。
DLO 的每个有限**子集**呢？线序三公理的子集有有限模型；带稠密的
子集就只余无限模型了——「有限子集可满足」要逐子集看，这是紧致
性使用时的常见精细处。

## 四、初等等价：量化秩的梯子

两个结构**初等等价**（A ≡ B：满足完全相同的句子）当且仅当（Fraïssé，
24 章）它们有限同构。本章埋线：按**量化秩**给公式分层——rank 0
（无量词的原子布尔组合）、rank 1（一层量词）……——秩 n 内同值是
「n 阶初等等价」A ≡ₙ B。机器面：

```coq
Example eeq_r0_Z2Z3 :
  forallb (eeq_pair 2 3) samples_rank0 = true.      (* rank0：Z₂≡₀Z₃ *)
Example rank1_separates :
  negb (eeq_pair 2 3 sigma3) = true.                (* σ₃ 一层分离 *)
```

五个 rank-0 抽样在 Z₂/Z₃ 上同值；σ₃（三层量词——按书 XII 的口径
是秩 3，此处作「量词层」示意）立刻把两结构分开：Z₃ 有三个两两不
同的元素、Z₂ 没有。**梯子每升一层，能分辨的结构对更多**——24 章
的 EF 博弈把这个梯子做成 n 轮游戏，并证「duplicator 赢 n 轮 ⟺
≡ₙ」。初等类 EC/EC_Δ（被句子集/句子集补刻画）与 Lindström 第一
定理的语境（关系语言、正则逻辑系统）记文档级——L-S 的「上下自由」
+紧致性的「有限定无限」合起来正是 Lindström 定理证明里压垮「超
过一阶的表达力」的两块砝码。

## 坑位速记（本章实测）

- **数学先于战术（两处）**：初稿想在 Z₃ 上验「线序+稠密」——**有限
  线序永不可能稠密**（相邻对无中介），机器当场拒证是对的；紧致性
  证词的「不可有限公理化」对象搞错（DLO 本就**是**有限公理组），
  正确形态是「**有限性**不可单句定义」的 σₙ 族。写例前先过数学。
- **空真陷阱**：稠密在 Z₁（单点）上**空真**（前件 x<y 恒假）——
  「稠密无有限模型」要 n≥2；穷举范围 seq 1 7 而非 seq 0 7。
- **σₙ 括号生成**：手写 σ₃σ₄ 的嵌套括号数错一次——程序生成
  （Python 拼串）后一次成型；镜像文件手写 σ₄ 同样八层闭括号，
  双通道对照就是括号审计。
- **Lean where 子句/占位语法残留**：草稿里的 `sorry` 块与
  `where` 局部定义混入——清理后全绿；`native_decide` 系例照旧。

## 小结

完备性的三大推论在机器上各有落点：L-S 的函数闭包（skclose 的轨道
计算）、紧致性的 σₙ 族（有限可满足/整体无模型的张力）、初等等价
的秩梯子（rank0 同值、量词层分离）。下一章把梯子的顶端做成游戏：
spoiler 与 duplicator 的 n 轮对局，赢策略的可计算判定——Fraïssé
定理的机器面。
