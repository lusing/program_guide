第 06 章把命题逻辑的矢列演算 G 做成了「规则即构造子」；这一章把同一配方
升到一阶逻辑，并补上 EFT 矢列演算的两块新肌肉：**量词规则**（∃S 的见证
式、∃A 的新变元侧条件）与**等词规则**（反身与替换）。与 06 章的分工：
那边命题级、九规则+可靠性旗舰；这边 FOL 级、侧条件的机器化是主角。

——ND 是树、Hilbert 是列表、矢列是「前件表+单后件」，等词的待遇也
不同（ND 有 Eq 公理与 Cong，这里浓缩成 Sub 一条替换规则）。

## 一、最小语言与矢列

EFT 的矢列演算刻意用**最小语言**：连接词只留 ¬ 和 ∨（∧、→ 由缩写定
义），量词只留 ∃（∀x φ 定义为 ¬∃x¬φ），加等词 ≡。这不是省事，而是
为了让「规则数最少」——每个保留连接词只配一对规则，缩写的规则全部
变成**可导规则**（derive），机器化时正好练习「定义展开+推导」的功夫：

```coq
Definition conj (φ ψ : fm) : fm := neg (disj (neg φ) (neg ψ)).
Definition imp  (φ ψ : fm) : fm := disj (neg φ) ψ.
Definition all (x : nat) (φ : fm) : fm := neg (exq x (neg φ)).
```

**矢列**是 Γ ⊢ φ：一个（可能空的）公式**表**做前件，单一公式做后件。
它读作「证明的一个阶段」——前件是当前累积的假设，后件是当前声称。
书 §IV.1 的动机值得在机器侧重演：间接证明时把 ¬φ 加进假设、得到
矛盾再丢掉它，正对应 PC/Ctr 两条规则对前件的增删。

公式的归纳定义与 14 章同骨架，但注意 `fv`（自由变元）在 ∃ 处要**删光**
约束变元的全部出现——我们自造 `wipe`（Rocq 9.1 的 `Stdlib.remove` 带
判等参数，不便）：

```coq
Fixpoint wipe (x : nat) (l : list nat) : list nat :=
  match l with
  | [] => []
  | a :: l' => if a =? x then wipe x l' else a :: wipe x l'
  end.
```

## 二、规则即构造子：S 的完整机器化

`der` 的归纳定义把书 §IV.6 总结表的十条规则逐条翻译成构造子。结构
规则两条（Assm/Ant），联结词四条（PC 分情况证明、Ctr 反证、∨A 析取
假设消除、∨S 左右引入），量词两条，等词两条：

```coq
Inductive der : list fm -> fm -> Prop :=
| Assm : forall Γ φ, In φ Γ -> der Γ φ
| Ant : forall Γ Γ' φ, incl Γ Γ' -> der Γ φ -> der Γ' φ
| PC : forall Γ ψ φ, der (ψ :: Γ) φ -> der (neg ψ :: Γ) φ -> der Γ φ
| Ctr : forall Γ φ ψ,
    der (neg φ :: Γ) ψ -> der (neg φ :: Γ) (neg ψ) -> der Γ φ
| ExS : forall Γ x φ t, der Γ (substf φ x t) -> der Γ (exq x φ)
| ExA : forall Γ x φ ψ y,
    ~ In y (fv_l (exq x φ :: ψ :: Γ)) ->
    der (substf φ x (var y) :: Γ) ψ -> der (exq x φ :: Γ) ψ
| Ref : forall Γ t, der Γ (eqf t t)
| Sub : forall Γ x φ t t',
    der Γ (substf φ x t) -> der (eqf t t' :: Γ) (substf φ x t').
```

**∃S（∃-succedent 引入）**是「见证式」：要证 ∃xφ，给出一个具体项 t
并证 φ[t/x]。**∃A（∃-antecedent 消除）**是数学里「设 y 是一个满足 φ
的元素」的形式化：从 φ[y/x] ⊢ ψ（用一个新鲜变元 y 代表那个元素）得
到 ∃xφ ⊢ ψ。侧条件——y 不得自由出现在 Γ、∃xφ、ψ 里——做成了构造
子的一个证明参数。书 §IV.4 用反例展示侧条件的必要性：

$$\exists x\, x \equiv fy \;\vdash\; y \equiv fy$$

对它非法地应用 (∃A)（忽略侧条件，取 y 作「新」变元）会得到
$x \equiv fy \vdash y \equiv fy$——这在把 f 解释为后继、y 解释为 0 的
结构里不成立：见证 x 只能是 0，而 0 ≢ 1。侧条件不可去。

**等词两条**浓缩了等词逻辑的全部：≡ 说每个项等于自己；Sub 说「相等的
项可以替换」——从 Γ ⊢ φ[t/x] 得到 (t≡t′::Γ) ⊢ φ[t′/x]。注意 Sub 的
形状：等式 t≡t′ 是**加进前件**的，不是前提——这使得「用已知等式改写」
时要配合链式规则（见下）。

## 三、可导规则：Ch 与等词代数

书 §IV.3/IV.5 的可导规则是本章机器化最重的部分。第一条要务是**链式
规则 Ch**（书里处处用它却不在规则表中）：

> 从 Γ ⊢ χ 与 χ::Γ ⊢ ψ 得 Γ ⊢ ψ。

它的机器推导是 PC+Ctr+Ant+Assm 的组合拳：在 Γ,¬χ 里用 χ（Ant 弱化）
与 ¬χ（Assm）制造矛盾，Ctr 弸出任意目标。有了 Ch，「Sub+等式」就
能合成「改写」：先证 Γ ⊢ t≡t′，再在 (t≡t′::Γ) 里用 Sub 得目标，
Ch 把两段焊起来。

等词的**对称**（5.3(a)）与**传递**（5.3(b)）各需要一点技巧：对称的
推导要挑一个**新鲜变元**做 Sub 的槽——φ := (x ≡ t₁)，从 ⊢ t₁≡t₁
（Ref）经 Sub 得 (t₁≡t₂::Γ) ⊢ t₂≡t₁，再 Ch 上 Γ ⊢ t₁≡t₂。新鲜性
保证代入不碰 t₁ 里的变元（`substt_fresh`：x ∉ fvt t 则代入不动 t）。
同余规则（5.4(b)：等式两边可以塞进同一个上下文）在机器版里特化为
乘法的左右两个槽位，书里群例要用。

量词侧：**∀-左实例化**（5.5(a1)）从 Γ ⊢ ¬∃x¬φ 得 Γ ⊢ φ[t/x]——机
器推导是 PC 的分情况：若 ¬φ[t/x]，则它本身见证 ∃x¬φ（ExS），与 ∀
矛盾（Ctr）。**∃-自引入**（5.1(a)）用 x 自己做见证：ExS 配合
`substf φ x (var x) = φ`（代入恒等引理）。

## 四、群论例：等式链的完整机器化

书 §IV.6 的招牌例子：从群公理（结合律 ϕ₀、右幺 ϕ₁、右逆 ϕ₂）形式
证明**左逆存在** ∀x∃y y·x≡e。机器版把整条等式链做实：

$$yx \equiv (yx)e \equiv (yx)(yz) \equiv y(x(yz)) \equiv y((xy)z)
\equiv y(ez) \equiv yz \equiv e$$

每一步都是 `d_trans`（传递）焊接的：右幺的实例化、A2（yz≡e）的对称
塞进右槽（同余）、两条结合律实例、A1（xy≡e）的替换、再次结合律反向
(y(ez)≡(ye)z——注意这里**不需要**左幺！)、右幺实例化收口。变元命名
有讲究：公理的约束变元用 3,4,5 与 7,8，主元 x=0、见证 y=10、z=11，
实例化时代入不会撞上约束变元（撞了就是假命题——见坑位）。

打包阶段是 ϕ₂ 的两次表演：从 ϕ₂ 实例化出 ∃-形式，用 **ExA** 消解
见证（先 z=11 消 A2，再 y=10 消 A1），每次消解前把目标 generalize
（ExS 引入 ∃y），让侧条件里的见证变元变成约束的。最后两段 **d_ch**
把 ∃-假设剪掉——这是书里 5.5(b3)（∀-左）的机器化身：

```coq
Theorem grp_left_inv : der Γgr (exq 10 G0).
```

（完整的 34 行推导见源文件；正文不重复。）诚实止步说明：书里最终
定理带外层 ∀x；把 ∀ 打上去需要 5.5(b4)（∀-引入，侧条件 x ∉ fv Γ），
它的推导在 EFT 的**联立代入**形式化里轻巧，在我们的单代入编码里
要绕很远——机器版停在「自由变元 0 的存在左逆」这一步，数学内容等
价（0 是任意取定的），∀-包装记文档级。

## 五、协调性与可靠性片段

书 §IV.7 的定义：Φ **协调**当且仅当不存在 φ 使 Φ⊣φ 且 Φ⊣¬φ。
**7.2 引理**（Inc Φ ⟺ Φ 推出一切公式）的机器证明是 Ctr 的直接应用
——两个矛盾推导的前件并起来，矛盾臂里什么都能证：

```coq
Lemma inc_ders_all : forall Φ ψ0,
    ders Φ ψ0 -> ders Φ (neg ψ0) -> forall ψ, ders Φ ψ.
```

演算**本身**的协调（空前件推不出闭原子式）走可靠性路线。完整 S 的
可靠性（书 Thm 6.2：Φ⊣ϕ ⟹ Φ⊨ϕ）需要 FOL 语义与代入引理的机器化
（15 章的配方+），本章取**命题片段**：只含命题规则的子演算 `derp`
在布尔赋值下可靠（对推导结构归纳，七条规则逐一验证），配合赋值
val₀（原子 (rat 0 []) 取假、其余真）得 derp 的协调性。全 S 的可靠
性在 22 章完备性处接续。

## 坑位速记（本章实测）

- **Coq：嵌套归纳的 IH 缺失**——`fsym (f) (list tm)` 的 list 参数不给
  逐元素归纳假设，`substt_self` 直推失败；按 tsize 测度归纳，`fr_pos`
  （foldr 正性）喂给 lia（fold_right 是 lia 的黑盒原子）。
- **Lean：嵌套归纳类型无 induction**——Lean 4 对含 `List tm` 字段的
  归纳类型不支持 `induction` 策略（无生成递归子）；同样按测度归纳，
  且**内层** `induction ts` 会自动泛化依赖假设（ht 提进 IH）——用
  `map_self_gen`（元素级事实做参数的列表引理）绕开。
- **Lean：符号项上 defeq 卡死**——`d_all_inst` 的结论是 `substf φ x t`
  计算形，与手写目标形在符号 t 上不可定义相等（if 卡在实例归约）；
  处方：`have h := d_all_inst …; simpa [substf, substt, mul, eg,
  List.map_cons, List.map_nil] using h`——tactic 侧归一化后 rfl。
- **Coq：名字遮蔽 stdlib**——第 1 节定义的公式缩写 `conj`（fm 上的 ∧）
  遮蔽了 stdlib 合取构造子 `conj`，命题可靠性的 `conj Hn Ho` 悄悄变
  成把 Hn 当 fm 用；处方：`mkcomp` 引理用 tactic 级 split 造见证。
- **∃A 侧条件的机器化**——新鲜性 `~In y (fv_l …)` 在具体公式上用
  vm_compute 全算死（Coq）/ simp+全部定义展开（Lean；`decide` 会卡在
  Decidable 实例归约上）。
- **变元命名撞 binder 即假命题**——群例的公理约束变元（3,4,5,7,8）与
  主元/见证（0,10,11）错开；若在 ϕ₂ 的 ∃8 下代入 8，捕获立即制造
  假公式（机器在侧条件/类型检查处当场报错）。
- **账本对照**——Coq 版三账本全部零公理；Lean 版 grp_left_inv 带
  `[propext, Classical.choice, Quot.sound]`（by_cases 的经典分叉拉入
  choice）。同一演算、同一证明思想，两台机器的公理底账不同——这正是
  「账本文化」要看的东西。
