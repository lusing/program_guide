# 33 模态自然演绎与知识逻辑 KT45n

> 对书：H&R §5.4（模态 ND 四规则）/ §5.5（KT45n 与 muddy children）
> 通道：C/L（mnd 深嵌入+派生件+泥孩子 decide 现场）

43-44 章立完语义层（框架+对应理论），本章回到**演算层**：给模态
逻辑装自然演绎，然后把 KT45n（知识逻辑）用在 H&R 的招牌谜题
——muddy children（泥孩子）上。语义是骨架、演算是肌肉、谜题
是舞台。

## 模态 ND：四条新规则（H&R §5.4）

命题 ND（03 章）全套照用；模态的新行李是 □/◇ 的引入/消除：

```text
□i（严格）      □e
  [虚线框] φ        □φ
 -----------      ------      φ 想装进 □，框内
    □φ              φ         只许用必然知识
```

**□i 的虚线框是模态 ND 最微妙的机制**（H&R 用虚线区别于实线
证明框）：进入 □ 框后，**只有 □ 形的既有前提可以引用**——因为
「必然真」的论证不能依赖偶然为真的假设。机器件
（`examples/33_modalnd/ex45_modalnd.v`）把虚线框纪律**类型化**
为侧条件：

```coq
Fixpoint allBoxed (G : list mform) : bool :=
  match G with
  | [] => true
  | mBox _ :: G' => allBoxed G'
  | _ :: _ => false
  end.

Inductive mnd : list mform -> mform -> Prop :=
| ...
| mnBoxI : forall G f,
    allBoxed G = true ->          (* 严格性：上下文全 □ 形 *)
    mnd G f -> mnd G (mBox f)
| mnBoxE : forall G f, mnd G (mBox f) -> mnd G f
| mnDiaI : forall G f, mnd G f -> mnd G (mDia f)
| mnDiaE : forall G f g,
    mnd G (mDia f) -> mnd (mBox f :: G) g -> mnd G g.
```

读设计要点：

- **侧条件是数据**（allBoxed 计算上下文形状）——深嵌入里
  「纪律类型化」的直接形态；`allBoxed [mAtom 0] = false` 一行
  `reflexivity` 就是拦截现场；
- **上下文条目跨框存活**（mnHyp 对 cons 后的表仍适用）——
  「推导」不能 wander 进框（推导的构造是固定的），「前提的
  □ 化引用」可以（前提就在表里）。这条区分是深嵌入教给我们的
  最精确的虚线框语义；
- **◇e 的见证框**：mnDiaE 把见证 f 以 `mBox f` 的形状挂进
  上下文（伪装成必然知识——H&R 的 ◇ 消去纪律），推出的 g
  不依赖见证。

## 派生件：¬◇φ ⊢ □¬φ

```coq
Theorem notDia_to_boxNeg : forall G f,
  allBoxed G = true ->
  In (mNeg (mDia f)) G ->
  mnd G (mBox (mNeg f)).
```

推导四行：mnBoxI（严格性由前提担保）→ mnNegI 开 ¬ 框 →
框内 φ 经 mnDiaI 造 ◇φ → 与跨框存活的 ¬◇φ（mnHyp）对撞出
⊥。「不可能 ⟹ 必然不」——模态对偶的演算化身。

**边界（诚实登记）**：无侧条件版（任意上下文）需要「框化」
引理——把上下文逐条 □ 化并保持可推性（演绎定理的模态版，
与 17 章 Gen 侧条件同族）。深嵌入里这条引理的代价与教学价值
不成比例，登记为边界；K_mnd（□ 分配）同样受此限。

## KT45n：多主体知识逻辑（H&R §5.5.1-5.5.3）

**公理选择即语义选择**（44 章选型表的落点）：□ᵢ 读「主体 i
知道」，可达关系 = i 的不可区分——KT45n 全收：

| 公理 | 语义 | 知识读法 |
|---|---|---|
| **K** | 分配 | 知道蕴含 |
| **T** | 自反 | 知识必真（不可区分含现实） |
| **4** | 传递 | 正自省（知道自己知道） |
| **5** | 欧性 | 负自省（不知道时知道自己不知道） |

n 个主体各一个 □ᵢ（共享同一框架）。「4+5 全收」意味着理想的
知识主体有完全内省——这是 KT45n 的**建模假设**（真实人不完全
内省，KD45 的信念更宽松）。

## 招牌谜题：muddy children（§5.5.1 形式化）

> n 个孩子玩泥巴，额头沾泥互相可见、自己不可见。父亲宣布：
> 「至少一人额头有泥。」然后问「谁知道自己有泥？」全体沉默。
> 再问一次——所有有泥的孩子举手：「我知道。」为什么？

两孩版（`ex45_modalnd` 双通道的表计算现场）：

```text
世界 = (m1, m2) 泥额组合；主体 i 可达 = 只看对方额
  （vis1 u v := snd u = snd v——自己额不可见）
宣告₁ = 滤掉 (0,0)（公开「至少一泥」= 消灭无人有泥的世界）
宣告₂ = 滤掉「有人第一轮就举手」的世界
```

机器件三步（全 `reflexivity` 直收）：

```coq
Example r1_nobody_knows : ... (true,true) 第一轮谁都不知道.
Example r1_kid2_knows : ... (false,true) 第一轮主体 2 就知道.
Example r2_kid1_knows : reach1' (true, true) = [(true, true)].
```

推理链的语义化：

1. **(1,1)（都有泥）第一轮没人知道**：主体 1 的可达表
   {(1,1),(0,1)}（m2=1 的两个世界）——两个世界 m1 不同——
   「我有泥」不确定；
2. **(0,1) 第一轮主体 2 就知道**：主体 2 的可达表（m1=0 的
   宣告₁后世界）只剩 {(0,1)}——宣告₁滤掉了 (0,0)，主体 2
   看到 m1=0，唯一可能是自己有泥——举手；
3. **沉默是信息**：第一轮全体沉默 = 公开宣告「没人第一轮就
   知道」——滤掉 (0,1)/(1,0)（那些世界里有人会举手）；
   (1,1) 处主体 1 的可达表只剩 {(1,1)}——「我有泥」兑现。

**宣告即过滤**（public announcement = world elimination）——
动态认知逻辑的最小教学模型。理性推理者的**共同知识**沿宣告
链演化：每轮沉默都在收窄世界表。n 孩推广：k 个泥孩需要 k
轮沉默——第 k 轮全体泥孩同时举手（H&R 习题；n=2 的机器
件已把机制做完，推广是同一台机器的规模放大）。

**n 孩推广的归纳论证**（为什么恰好 k 轮）：k 个泥孩时，
第 i 轮沉默公告「没有任何孩子看到 k−i 个泥额就确定自己」。
归纳：k=1（一泥孩）：看见零泥 → 宣告₁后立即知道（第 1 轮
举手——「至少一泥」+「我没看见」⟹「是我」）。k 个泥孩：每
个泥孩看到 k−1 个泥额，与「自己干净」的假想世界在 k−1 轮
沉默前不可区分——第 k−1 轮的沉默恰好消灭假想世界（那里
只有 k−1 个泥孩、他们在第 k−1 轮会举手），第 k 轮全体泥孩
同时举手。机器面：n=2 的表计算就是这台归纳机的 k=2 实例；
推广只需把世界表从 4 元组换成 2ⁿ 元组（decide 的规模增长、
结构零增长）。

Wise men（三智者）谜题同构（H&R §5.5.1 另一例）：国王问
智者帽色、逐个回答「不知道」——每次「不知道」都是宣告过滤。
文档对照，机器面与泥孩子同款（世界表换成帽色三元组的过滤
链，三轮恰好与泥孩子 k=3 对齐）。

## KT45n 的 ND 系统注记（§5.5.3 的教学版对照）

H&R 给 KT45n 配了专用 ND：每条公理（K/T/4/5）配一条推演
规则或公理模式，□ᵢ 的引入规则吸收公理——例如 T 直接变成
「□ᵢφ 的前提可当 φ 用」。教学版（ex33）走的另一条路：**公理
选择语义化**（44 章的等价关系框架）+ 演算层只装纯 K 的 mnd
——公理的有效性由框架性质担保（44 章五正一逆），不需要演算
内重复。两条路线各有教益：H&R 版展示「演算可按公理定制」，
本章版展示「公理=框架性质」的语义杠杆——合起来正是逻辑工程
的完整闭环。

## 本章小结

- 模态 ND 四规则：□i 严格性（虚线框=上下文全 □ 形）是
  核心；◇e 的见证伪装（mBox f 挂框）是巧思。
- 深嵌入教学：侧条件类型化（allBoxed）；上下文条目跨框
  存活、推导不 wander——虚线框的最精确语义。
- ¬◇φ ⊢ □¬φ 四行推导；无侧条件版需框化引理——边界登记。
- KT45n：知识=等价关系上的 □ᵢ；T/4/5 = 知识必真/正自省/
  负自省。
- 泥孩子：宣告即过滤；沉默是信息；n 孩 k 轮推广（归纳机的
  k=2 实例已机器化，推广只放大表规模）。

## 坑位速记（本章实测）

- **Coq/Rocq**：
  - 构造子的 `apply (mnNegE (f := mDia f))` 与局部 f 撞名
    ——「Wrong argument name」；改**位置参数**
    `apply (mnNegE _ (mDia f))`；
  - 侧条件拦截现场用**两个独立 Example**（allBoxed …=true /
    =false 各一行 reflexivity）——合取版会撞「and 不是自反
    关系」（reflexivity 的目标层级）；
  - 泥孩子的过滤链全走 Definition——Example 的等式 reflexivity
    直收；零推理负担是「语义推理程序化」的回报。
- **Lean**：
  - `List.mem_cons_self` 无参数（隐式版直接 `Mnd.mnHyp
    List.mem_cons_self`）；
  - 泥孩子的 `filter`+`all` 组合在 `(true,true)` 字面量上
    `rfl` 直收——教学生用 **`decide` 的表计算心法**（07 章）
    迁移到认知场景。
