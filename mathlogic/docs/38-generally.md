# 第 38 章 「一般」逻辑与滤子

> 对书：Leonardo B. Vana, Paulo A. S. Veloso & Sheila R. M. Veloso
> 《On the Structure of Natural Deduction Derivations for "Generally"》
> （Prawitz 祝贺卷第 6 篇）。机器件：`examples/38_generally/
> ex38_generally.v` 与 `.lean`。

「巴西人一般刮腿毛」「巴西人一般刮脸」——接受这两句的人多半也接
受「巴西人一般既刮腿毛又刮脸」。这不是 ∀（没人会说「每个巴西人都
如此」），也不是 ∃（太弱了）。为这类**模糊量词**（一般/大多数/若
干）给一套严格演算，就是「一般」逻辑（logics of generally）的出
发点：在 FOL 上加一个新量词 ∇，读作「对象**一般**满足……」，语义
靠一族「重要的」子集（复形，complex）给出——∇v A 真，当且仅当 A
的扩展集在复形里。

## 37.1 复形与模块：五性质拼出四种「一般」

复形 K 是论域 U 的子集族。「重要」的不同强度对应五条性质：⊕ 全域
（U ∈ K）、∈ 非空（∅ ∉ K）、∩ 交封闭、∪ 并封闭、⊇ 扩集封闭。
取不同的性质组合，得到不同的「一般」：

| 模块 | 性质组合 | 直觉 |
|---|---|---|
| **P** proper | ⊕ ∈ | 至少不是废话 |
| **S** proper up-closed | ⊕ ∈ ⊇ | 「重要」集合的超集仍重要 |
| **L** proper lattice | ⊕ ∈ ∩ ∪ | 交并都重要 |
| **F** proper filter | ⊕ ∈ ∩ ⊇ | 数学里的真滤子 |

∇ 落在 ∀ 与 ∃ 之间：P 模块就有 ∀vA→∇vA 与 ∇vA→∃vA。机器件
把整个表格做成**穷举式机器证明**——论域取 U={0,1,2}（3 世界、8
个子集位掩码），复形是 256 个可能族，赋值 64 个（2 原子×3 世界），
`gvalid md f` 在满足模块条件的一切 (K,V) 上核验 f：

```coq
Definition gvalid (md : module_) (f : gform) : bool :=
  forallb (fun K => forallb (fun v => evG K v f) allVals)
          (allComplexes md).
```

语义分两层（对应书里「标记式」把 ∇ 公式当作不可分解的整体）：
内层是世界层公式，取**扩展**——`extOf v a` 算出 a 为真的世界位掩
码，补集是 `Nat.lxor 7 s`；外层是 ∇ 层，`grad a` 判 `extOf v a`
是否入 K，`gall/gex` 是有限宇宙版的 ∀/∃：

```coq
| grad a => inFam K (extOf v a)
| gall a => Nat.eqb (extOf v a) univ
| gex a => negb (Nat.eqb (extOf v a) 0)
```

## 37.2 公理表的完全枚举

五组断言把模块格逐格钉死（每一条都是 256×64 全枚举的结论，不是
抽样）：

- **⊕/∈（P 即真）**：`∀vA→∇vA` 与 `∇vA→∃vA`——电一。
- **∩（F 有 S 无）**：`∇A∧∇B→∇(A∧B)` 在 F 有效；在 S **无效**。
  S 反模型即书里的直觉：交封闭缺失，两个「重要」集合的交可以掉
  出复形（`counterOf` 交出 K={U,{0,1},{0,2}} 型反例）。
- **⊇（F 有 L 无）**：单调性 `∀(A⊃B)∧∇A→∇B` 在 F 有效；在 L
  **无效**。注意 L 与 F **不可比**——L 有 ∪ 无 ⊇，F 反之。这正是
  书 §2 模块格「不是一个塔」的机器面（电三）。
- **一致性（F 有 P 无）**：`∇A∧∇¬A→⊥` 在 F 有效（∩ 封闭把两个
  重要集交出 ∅，与 ∈ 冲突）；在 P 无效。
- **反例方向**：`∇A→∀A` 在 F 也无效——「一般」永远够不到「全
  部」，反模型当场交出（主滤子 ↑S + 只在 S 上真的原子）。

```coq
Example ax_mono_F : gvalid MF monoAx = true.
Example ax_mono_L_fails : gvalid ML monoAx = false.
Example grad_not_all : gvalid MF (gimp (grad A0) (gall A0)) = false.
```

一个方法论注记（代码头也写了）：这些公理的成立只依赖公式的**扩
展集**，所以「原子样本公式 + 全赋值枚举」就是对一切扩展组合的完
全覆盖——这不是抽样测试，是真正的穷举证明。

## 37.3 两件计数账

机器顺手交出两条书里默认但没算的账：

**真滤子计数**（电六）：3 元宇宙上恰 **7** 个真滤子——每个非空
S ⊆ U 给出主滤子 ↑S = {T : S ⊆ T}，7 个非空子集各给一个。
「有限论域上滤子皆主」的构造性面孔。

```coq
Example filter_count : length (allComplexes MF) = 7.
```

**模块格的严格性**（电七）：|F| < |S| < |P|（机器实测 7 < 18 <
64；L=16 夹在中间但与 S/F 都不可比）。严格性各有一个见证复形：P
有非升封闭族、S 有非交封闭族。

## 37.4 ND 系统：标记式与操作规则

书的主体在**证明论**一侧，教程把语义侧做成机器后，证明论侧用文
字把机制讲清：

**标记式**。∇ 公式 `∇x A(x)` 被当作不可分解的整体——「一般变量
不能实例化」（∇vA ⊬ A(t)！）。要操纵它内部，先进入**标记环境**：
把 ∇x A(x) 换成标记式 ⟨A[v/_]⟩，其中 `_` 是**泛型对象**（不是任
何特定 t）。基本三规则：∇E（从 ∇vA 进标记环境）、∇I（新鲜变量
z 不出现后离开）、(Ext)（等价替换：若 A 与 B 在普通环境下互相推
出，则 ⟨A⟩ 可换 ⟨B⟩——「扩展性」）。

**操作规则随性质而来**。五条性质各对应一条标记环境内的规则：

| 性质 | 规则 | 形状 |
|---|---|---|
| ⊕ 全域 | (˙∗I) | ⟨A⟩ ⊢ ∀A（逆读：∀ 引入标记） |
| ∈ 非空 | (⊥∗E) | ⟨⊥⟩ ⊢ ⊥ |
| ∩ 交 | (⊃∗I) | ⟨M⟩,⟨N⟩ ⊢ ⟨M⊃N⟩ |
| ∪ 并 | (∨∗I) | ⟨M⟩,⟨N⟩ ⊢ ⟨M∨N⟩ |
| ⊇ 扩集 | (⊃∗E) | ⟨M⊃N⟩,⟨M⟩ ⊢ ⟨N⟩ |

ND(P) = ND(B)+前两条，ND(S) 再加 (⊃∗E)，ND(L) 加 (⊃∗I)(∨∗I)，
ND(F) 加 (⊃∗I)(⊃∗E)。书例：`∀v(A⊃B),∇vA ⊢ ∇vB` 在 ND(S) 可导
——正是我们电三的 F/S 有效、L 无效的单调公理；`∇v¬A ⊢ ¬∇vA` 在
ND(F)——电四的一致性。

**正规化与最低段**。正规推导的每条路径切成三段：**TM**（普通消
去规则收尾、∇E 或 ˙∗I 进入标记环境）→ **MS**（操纵标记式：
⊃∗E/(Ext)/⊃∗I/∨∗I 的「最低段」）→ **FM**（∇I 或 ⊥∗E 离开、普
通引入规则开场）。标记公式在路径中**恰经一次 ∇E 进、一次 ∇I 出**
——这是把 Prawitz 最低段分析搬到 ∇ 上的直接成果，其证明（极大
段消除、换位归约先压成单段再消）与第 15 章的经典账同构，教程不
再重复机器化。

## 37.5 与本教程其余章节的关系

- 第 21 章（直觉主义插值）的有界有效性枚举是「小模型完全性」的
  同门手艺；本章把同一手艺用在**子集族**而非世界上。
- 滤子语义是拓扑语义的近亲（Kripke 拓扑化、第 19 章锥拓扑）——
  「重要集族」就是 Alexandrov 拓扑的开集格选法之一。
- 单调公理的模块依赖（F/S 有、L 无）与第 16 章 Kripke 单调性的
  框架条件是同一现象在两个语义维度的投影。

## 坑位速记（本章实测）

- **补集不是自交**：`comp s = Nat.lxor 7 s`；初稿写成 `subAnd 7
  (subAnd s 7)`（= s 自身）——gimp 的扩展全错，单调公理「莫名
  有效」。位掩码世界先在纸上对 3 个世界验一遍再落码。
- **upClosed 的包含判定**：s ⊆ t ⟺ `subAnd s t = s`（不是
  `Nat.leb s t`——数值比较与位包含无关）。
- **滤子计数初算 4 忘了 ↑{0,1} 型**：主滤子 ↑S 对**每个**非空 S
  都存在，3 元宇宙 7 个——「计数断言先跑再写」的老规矩。
- **Lean 前导点续行**：表达式闭合后的下一行 `.find? ...` 不被认
  作续接——let 绑定后再 `.find?`；`List.flatMap` 配 lambda 要加
  括号。
- **Bool 蕴含**：Lean 里 `(b1 : Bool) ≤ b2` 能算但费解——直接
  `!b1 || b2`。

## 小结

「一般」是一个谱系而不是一个算子：五条封闭性质拼出 P/S/L/F 四
档，滤子只是其中数学上最熟的一档。本章把这个谱系整个装进 3 世界
的位掩码宇宙——每一条「哪个模块有效/无效」都是完全枚举的机器证
明，反模型随手提取；证明论侧的标记式/操作规则/最低段结构则把
Prawitz 的正规化机器延伸到一个非标准量词上。「一般」的严格化最
终教导的是：**量词的语义自由度比 ∀/∃ 大得多**。
