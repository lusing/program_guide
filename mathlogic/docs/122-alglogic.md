前面各章的逻辑都有「有效公式」概念（赋值全真）。第 7 章反其道而
行之：**把「后承」当原始对象**——α⊢β 不再由「α→β 有效」定义，而
直接作为代数上的不等式 θ(α)≤θ(β)（定义 7.6）。这个视角下，没有
「真值」的代数结构（格、分配格、德摩根代数）也能长出自己的「逻辑」
——带证明搜索、切割消除、可判定性的完整证明论。

## 一、把后承当作原始：T-型代数逻辑

书 7.1 节的定义链：类型 T=(F,ς) 给出项语言；**T-型代数逻辑**（定义
7.5）是后承集 L，满足三条：自返（α⊢α）、切割封闭（α⊢β,β⊢γ⟹α⊢γ）、
代入封闭。三条恰好是 07 章（原 06 章）矢列演算的 (Id)/cut/(sub)——
**同一套骨架，一边长出逻辑，一边长出代数**。命题 7.2：任意代数类 K
的有效后承集 Log(K) 是 T-型代数逻辑——语义侧自动合法。

## 二、分配律的代价：格的两个方向

格的公理 (L1)-(L4)（结合/交换/幂等/吸收，定义 7.7）生成后承演算
L（定义 7.8：公理 (Id)+规则 (∧⊢)(⊢∧)(∨⊢)(⊢∨)+cut）。定理 7.1/7.2
（L 对全体格可靠完全）之后，书给出一个漂亮的否定结果——**推论
7.4：分配律在格演算中不可推导**。

「分配律」作为等式有两个方向，语义上命运不同。机器面在**五点菱形
M3**（0 底、4 顶、1/2/3 三个互不可比中点——最小非分配格）上把两个
方向分开验证：

```coq
(* ≤ 方向：(p∧q)∨(p∧r) ≤ p∧(q∨r)——对偶半分配，全格有效 *)
Example semiDistr_holds :
  allA3 (fun v =>
    le3 (m3e v (tor (tand (tv 0) (tv 1)) (tand (tv 0) (tv 2))))
        (m3e v (tand (tv 0) (tor (tv 1) (tv 2))))) = true.

(* ≥ 方向：p=1,q=2,r=3 时 左=中点、右=底——M3 反例 *)
Example distr_fails : ... = false.
```

反例的算术：p∧(q∨r) = 1∧(2∨3) = 1∧4 = 1（中点），而
(p∧q)∨(p∧r) = (1∧2)∨(1∧3) = 0∨0 = 0（底）——1 ≰ 0。**方向教学
点**：书说的「不可推导」指等式，即 ≥ 方向；≤ 方向（命题 7.4(7) 的
半分配不等式）是全格有效的，GDL 里可推导。

格演算 L 有完整的证明论：切割消除（定理 7.3）⟹ 子项性质（推论
7.2）⟹ 可判定（推论 7.3）。分配格 DL 加公理 (D) 后**没有**切割消
除（例 7.2：分配律的推导必须用 cut），但其根岑式 GDL 恢复了它（定
理 7.7）——「Hilbert 式后承演算 vs 矢列演算」的分层是本章的骨架，
与 06 章（原 05 章）HK vs 07 章 G 的关系同构。（GDL 推导检查器受
书规则图形 OCR 限制，机器面以语义侧双方向账承载本节——两侧对账由
定理 7.2 兜底。）

## 三、德摩根代数与 GDM

7.3 节的算子不是模态词 □，而是一元德摩根否定 ~（定义 7.13）：
有界分配格加 ~(a∧b)=~a∨~b（DM1）、~(a∨b)=~a∧~b（DM2）、~0=1/
~1=0（DM3）、~~a=a（DN）。机器面在**三元 Kleene 链 DM3**（0=假<
1=不定 < 2=真，~ 交换 0↔2、固定 1）上验证：

```coq
Example dm1_holds : ...   (* ~(α∧β) = ~α∨~β：9 组赋值逐对 *)
Example dm2_holds : ...   (* ~(α∨β) = ~α∧~β *)
Example dn_holds : ...    (* ~~α = α *)
Example lem_fails_at_n : Nat.eqb (m3join 1 (m3neg 1)) 2 = false.
```

第四条是本章的「分界线时刻」：p∨~p 在 DM3 的**不定点**取值 1≠2
（顶）——排中律失败。121 章（原 112 章）的 Boole 代数里 p∨~p=1 恒真：
**德摩根代数是 Boole 代数摘掉排中律后剩下的部分**，正如直觉主义逻
辑之于经典逻辑（13 章 Glivenko 的对应在代数侧同样成立——文档线）。
反向：GDM 的推导在 DM3 全赋值下有效（~~p ⊢ p 的抽查账）。

GDM 的证明论红利由**权重**支付（定义 7.16+定理 7.15）：每条规则的
分子权重严格小于分母权重（w(变元)=0，二元联结 w+1，~ 另 +1）——
反向搜索每步减重 ⟹ 停机 ⟹ **GDM 可判定**。这与 84 章 Dyckhoff 的
μ 权重是同一个发明的两个实例：**给演算造一个递减度量，就得到一台
证明器**。引理 7.12 的对偶变换（从 Γ⊢α 的推导机械造出 ~α⊢~T(Γ)
的推导——(CP) 反位律可允许）是格演算的「镜子」：对换 ∧/∨、给每项
戴 ~、倒转矢列，推导照旧合法。

## 四、与结构章的合流

本章把三股线接到了一起：**84 章的工程学**（结构规则→可判定性：L
的子项性质、GDM 的权重）、**06/07 章的矢列骨架**（后承演算=无「→」
的矢列演算）、**121 章的代数语义**（Boole 代数之于经典逻辑，正如德
摩根代数之于 Kleene 三值逻辑——代数类与逻辑类的 Galois 对应）。
逆数学方向的伏笔：每个「后承演算+代数类」对（L/格、DL/分配格、
DM/德摩根代数）都是 80 章（原 88 章）层级表的一个代数刻度。

## 小结

把后承当原始，格论就变成了逻辑：L 有自己的可靠完全与切割消除；分
配律的代价在 M3 上现形（一个方向免费、另一个方向 M3 拒收）；德摩
根代数在 Kleene 链上划出与 Boole 的界（排中律在不定点失败）；权重
支付可判定性。下一章（113 章）回到图论的组合世界；123 章收官将把本
轮的「结构规则谱系」放进全书频谱。
