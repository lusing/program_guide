## 一、GI 组：常规系统的分析规则

矢列取 Γ⇒β（单后件），模态规则按系统叠加（书表 6-3；机器检查器实
现书页已目核的三式）：

```text
α, □Γ ⇒ β                    α, □Γ ⇒ β
────────── (K)              ────────── (T)
□α, □□Γ ⇒ □β               □α, □Γ ⇒ β

□α, □Γ ⇒ β
────────── (S4)
□α, □□Γ ⇒ □β
```

(K) 的形状值得盯住：结论里 □Γ 变成 **□□Γ**（每份多套一框）——因
为结论的后件 □β 只约束「一步之后」的世界，而 □Γ 说「所有后继满
足 Γ」，□□Γ 说「所有后继的后继也满足」——在前提（对 α 成立、□Γ
成立的一步后世界）与结论（□α 的后继世界）之间正好错开一层框。
(T) 则把自返性变成「□α 的世界自己就满足 α」。

机器检查器 `mchk` 从结论按规则名算出期望前件再对账。书例 6.4 的两
则重演：

```coq
(* 例 6.4(2)：GKT ⊢ □α⇒α——一步 (T) 自公理 *)
Example ex_T_step :
  mchk (mnode ([mbox p], p) mT [ mnode ([p], p) mId [] ]) = true.

(* 例 6.4(5)：(K) 在 GS4 可允许——T 先升框、S4 再收尾 *)
Definition chainGS4 : mder :=
  mnode ([mbox p; mbox (mbox p)], mbox p) mS4
    [ mnode ([mbox p; mbox p], p) mT
        [ mnode ([p; mbox p], p) mId [] ] ].
Example chainGS4_ok : mchk chainGS4 = true.
```

第二条链的结论 □p,□□p⇒□p 恰是 (K) 规则的结论形状（α=p、□Γ=[□p]、
β=p 代入）——「(K) 可由 (T)+(S4) 模拟」的书证机制在三节点上现形。
六系统与框架条件的对应（命题 6.8 的模态侧：D↔持续、T↔自返、4↔传
递、B↔对称、5↔欧性）在 `giTable` 留数据影子。

## 二、GIII 组的反例：分析性切割的正面价值

书 6.2 的分组（GI：K/KT/KD/K4/KD4/S4；GII：K45/KD45；GIII：KB/
KTB/KDB/K4B/**S5**；GIV：K5/KD5）中，GI/GII 组享有完全的切割消除
（定理 6.2/6.3），而 **GIII 与 GIV 组的切割不可消除**——书中明确
指出 GS5 里 p⇒□◇p 型推导的 (cut)ᵃ 无法消去。这不是缺陷而是深意：
B 型公理（对称性）要求「回头看」对侧世界，矢列的线性语境装不下这
种双向约束。Takano 的解法是接受**分析性切割**（cut 的割公式限制在
子公式集内），用「子公式性质/扩展子公式性质」替代切割消除——证明
搜索依然有限、完全性依然成立（定理 6.4/6.5）。这与 62 章 G4ip 的
「改规则形状换终止性」形成对照：**另一条路是控制切割而非消灭切
割**。（GIII/GIV 的规则分数式在书的扫描件中辨认受限〔⚠〕，机制与
元定理记文档线——本段即其内容。）

## 三、超矢列：分量级操作

6.3 节换武器。**超矢列**是矢列的可重集：

```text
G ::= Γ₁⇒Δ₁ | Γ₂⇒Δ₂ | … | Γₙ⇒Δₙ        （「|」读作「或者」）
```

语义：超矢列有效 ⟺ 某个分量有效。分量级操作分**内部**（分量内加
公式：Iw/Ic）与**外部**（整条分量的增删合并：Ew/Ec）：

| 规则 | 从 | 到 | 机器件 |
|---|---|---|---|
| (Ew) 外部弱化 | G | G \| Γ⇒Δ | `ewRel` |
| (Ec) 外部收缩 | G \| Γ⇒Δ \| Γ⇒Δ | G \| Γ⇒Δ | `ecRel` |
| **(MG) 合成** | G \| Γ⇒Δ \| Σ⇒Π | G \| Γ,Σ⇒Δ,Π | `mgRel` |

(MG)（引理 6.23）是超矢列的**专属规则**：把两个分量合并成一个
——「或」的分量的合取。正是它让 S5 的等价类结构（一个世界的「可
能世界集」是全体的等价类）能在证明里被拼出来。机器的一步关系账：

```coq
Example mg_step : mgRel [([p;q],[p;q])] [([p],[p]); ([q],[q])] = true.
```

p⇒p | q⇒q 合并成 p,q⇒p,q——两个「或者」分量的信息合流。

## 四、HS5 与 S5 完全性

超矢列演算 HC（经典命题部分）之上，加模态规则得 HS5（定义 6.15，
S5 部分引 Poggiolesi 2008）：(□1⇒) 在分量内原位去框（可靠性用
S5⊨□α→α 的自返性）——

```coq
Example b1_from_axiom :
  andb (compAxiom ([p], [p])) (b1Rel [([mbox p],[p])] [([p],[p])]) = true.
```

□p⇒p 的两步拼合：(Id)ᴴ 公理分量 → (□1⇒) 原位加框。HS5 的两条大
定理：**切割消除**（定理 6.6，(Hcut) 可允许——□ 情形 (5.3) 要经
MG+Ec+Ic 三件结构规则收尾，超矢列的分量操作在消除中不可缺）与
**S5 完全性**（定理 6.7+推论 6.5：HS5⊢G ⟺ Fr(S5)⊨T(G)——公理
(K)(T)(5) 逐条在 HS5 推导、(mp) 用 (Hcut)、(nec) 用 (⇒□)）。线性
矢列装不下的 S5，多分量的「或者」装下了——**给逻辑换证明演算，
有时要给证明演算换容器**。

## 五、本章在谱系里的位置

62 章的教训是「结构规则可以被拆掉」；本章的教训是「有的逻辑逼你
把结构规则**加回来**——但加在更高的层上（分量级）」。GIII 的分析
性切割与 HS5 的超矢列是同一问题的两个解法，共同的前史是 Gentzen
1934 的原始困境（S5 的矢列化自 1950 年代起就是公开难题）。84 章
（原 80 章 μ 演算）将把「符号级证明搜索」推到不动点；94 章
的代数逻辑则给出这些证明论结果的语义对偶。

## 小结

GI 组的分析规则干净利落（(K) 的双层框、(T) 的自返一步、(S4) 的传
递收尾），书例 6.4 在检查器上重演；GIII 组的切割不可消除逼出 Ta-
kano 的分析性切割；超矢列用分量级操作（尤其 MG 合成）把 S5 装进切
割消除的框架。模态证明论的三条路——控制规则形状、控制切割、更换
容器——是 62 章「结构规则工程学」在模态世界的完整展开。
