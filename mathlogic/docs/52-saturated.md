51 章造「尽可能少实现」的模型（素）；这一章造「尽可能多实现」的
模型（饱和）。两个极端共享同一套型空间语言，而中间的谱系
（齐次、泛、原子）由三条等价线（Prop 4.3.2、Thm 4.3.18）编织
起来。饱和模型的用处在于：**在模型内部就能做原本要去初等扩张
才能做的事**——Prop 4.3.25-4.3.28 的三条「饱和论证法」把可定义
性的不变量判据（自同构不动⟺可定义）、代数闭包的轨道判据和
量词消去的新判据全部搬进了模型内部。

## 一、κ-饱和：三条等价线与第一串定理

**定义**（Def 4.3.1）。M 是 κ-饱和的，如果对一切 |A|<κ 的
A⊆M 与 p∈S_n^M(A)，p 都在 M 中实现。M 饱和=M_{|M|}-饱和。

三条等价（Prop 4.3.2）：(i) κ-饱和 ⟺ (ii) 不完全型也全实现
（取完全扩张）⟺ (iii) 只查 1-型（n-型按「先实现前 n-1 个坐标、
再在余下参数上实现第 n 个」归纳）。**「只查 1-型」是机器检查
的许可证**——本章的 `satCheck` 只扫一维 profile。

第一串定理（可数侧）：

- **饱和⟹齐次**（Prop 4.3.3）：部分初等映射 f、点 b∈M，造
  Γ={φ(v,f(ā)) : M⊨φ(b,ā)}——f 初等保证 Γ 一致，饱和给出
  实现元 c，f∪{(b,c)} 仍初等。
- **ℵ₀-饱和⟺ℵ₀-齐次+实现全部 S_n(T)**（Prop 4.3.4）：参数型
  化成无参数的 n+m 型，把「a 的型」用齐次性搬回目标。
- **可数饱和模型唯一**（Cor 4.3.5：两个都实现全部型+都齐次
  ⟹ 逐步 back-and-forth）。
- **可数饱和存在 ⟺ 一切 |S_n(T)|≤ℵ₀**（Thm 4.3.7）：链构造
  M₀≺M₁≺… 逐个实现 p₀,p₁,…，并到 M 后再套 Prop 4.3.6 补齐次性。
- **有趣的不对称**（Cor 4.3.8）：有可数饱和模型 ⟹ 有素模型
  （型空间可数⟹孤立型稠密——51 章 Thm 4.2.10 的钩子）；
  可数模型数 <2^ℵ₀ ⟹ 既有素又有饱和。「大」与「小」在可数
  世界里手拉手。

三例定位（Ex 4.3.9-4.3.11）：**(Q,<) 饱和**——有限 A 上
|S₁(A)|=2m+1 且全部实现（密度保证每个区间有活口）——它同时
是素的！ℵ₀-范畴理论里饱和与素合流（53 章 Thm 4.4.1 的推论）。
**ACF_p**：|S_n|=ℵ₀（48 章素理想账），可数饱和模型=超越次数
ℵ₀ 的代数闭域。**RCF**：S₁ 已是 2^ℵ₀（每个实数 r 给出有理
逼近型 p_r），**没有饱和模型**——「有界」与「无界」的战争
在型空间大小上决出。

## 二、机器面 I：有界饱和检查器与两个宇宙的对账

`examples/52_saturated/` 复用 50 章的 profile 方法论（章内自含）：
项语言 S^k 0 / S^k p_i / S^k x，等词原子+布尔，赋值的 profile=
公式表上的真值向量；**型在 dom 中实现 ⟺ dom 里有同 profile
的元素**（`realizedIn`）；`satCheck` 对「证据宇宙」evid 的每个
候选型逐一检查（evid 通常取得比 dom 宽——代表初等扩张中可能
出现的元素）。

**(N,S,0) 逐层饱和账**（`n_saturated_bounded`）：B=3 层公式、
A={0,2}、证据 0..14——全部 profile 在 0..14 内有实现。关键
角色是 ∞ 型：证据 7、8、9… 的 profile 彼此相同（对一切 k≤3：
x≠S^k 0、x≠S^k 2），而这个型**由 4、5、6 等大元素接住**——
N 的无界性就是它的饱和性（在有界口径内）。

**钳位结构的破口**（`clamp5_unsaturated`）：M₅={0..4}、
S(4)=4（后继到顶就停）。∞ 型（证据 x=7 的 profile）在 M₅ 中
**无实现**——每个元素都被 S^k 0 命名，而「比一切命名元素更
远」的点不存在。一个饱和性破口=一处「本该有元素却没有」的
缺口；51 章省略型定理反着用：**破口是设计出来的**——素模型
就是「主动留下全部非孤立破口」的结构。

## 三、机器面 II：DLO 的 2m+1 与「密度=实现」

DLO 带有限参数集 A（|A|=m）的 1-型=**切割**（50 章 §五），
型数恰 2m+1：m+1 个切割位（下方/各区间/上方）+m 个实现型。
`dloTypes` 把切割型直接构造为 profile（`cutProfile`：第 p 位
切割的原子真值模式是「p_i<x ⟺ i<p」），`dlo_type_count` 验证
|A|=2、3 时型数=5、7——**实现型与切割型两两不同**（等词与
不等词的分离）。

「密度=实现」的三段账（`cutRealized`）：

- **稠密 dom**：A=[0;5]、中割（0<v<5），dom=[0;2;5] 有中点
  2——型实现（`dlo_realization_gap` 第一分量）；
- **稀疏 dom**：dom=[0;5] 缺中点——同一型破口（第二分量）；
- **(Q,<) 全型实现**（`q_saturated_over_finite`）：A=[1;5]、
  dom=[0..6]，三个切割位全有代表——下方由 0、区间由 2/3/4、
  上方由 6 接住。

这三段合起来就是 Ex 4.3.9 证明的机器面：「Q 的饱和性=密度+
无端点」，每个切割位都需要一个活口，密度保证开区间非空、
无端点保证两端有界外有物。

## 四、机器面 III：齐次性的延拓账

`sameType` 是有界口径的「初等等价」（同 profile）。两组样本：

- **尾平移**（`tail_same_type`）：7 与 8 同型、9 与 10 同型
  ——∞ 区的元素在 B=6 层公式下不可区分，映射 7↦8、9↦10 是
  「尾平移自同构」的有界影子（真正的 Aut(N,S,0) 中，平移
  n↦n+1 固定「∞ 型」但挪动一切）。
- **命名点不可挪**（`named_immovable`）：0 与 1 不同型——
  v=S^0 0 与 v=S 0 分离。**可定义的元素没有初等舞伴**，齐次
  映射只能搬「匿名区」。

**饱和⟹齐次的装配**（`sat_implies_hom_sample`，Prop 4.3.3 的
样本）：f={7↦8} 已知初等（同型），取 b=9——搜索 c 使
f∪{9↦c} 仍初等：c=10（或任何∞区元素）通过。Γ 的「实现元
搜索」在有限宇宙里就是 profile 匹配；在无限侧，它需要饱和性
兜底（Γ 的一致性由 f 初等保证，实现由 κ-饱和保证）。

## 五、大基数侧与饱和论证法（Thm 4.3.12-4.3.28）

**存在性**（Thm 4.3.12）：任何 M 都有 κ⁺-饱和的初等扩张
N⪰M、|N|≤|M|^κ——链构造（先把「A⊆M、|A|≤κ 上的全部 1-型」
逐个实现一遍得 M′，再迭代 κ⁺ 轮让参数集跟进）。GCH 侧注
（Cor 4.3.13/4.3.14）：2^κ=κ⁺ 时有 κ⁺-饱和的 κ⁺ 元模型；
κ 正则且 2^λ≤κ 时有 κ-饱和的 κ 元模型。**κ-stable ⟹ κ-饱和
模型存在**（Thm 4.3.15）——稳定性（型空间小）直接换饱和模型，
55 章的 ω-稳定由此兑现成「一切基数都有饱和模型」的谱系。

**大定理**（Thm 4.3.18/4.3.20）：M κ-饱和 ⟺ M κ-齐次且
κ-泛（每个 ≤κ 的模型都初等嵌入）；同基数的饱和模型同构。
「饱和=齐次+泛」把三个直观（多实现/可延拓/装得下）拧成一
股；唯一性是 back-and-forth 的饱和版。

**饱和论证法**三件（Prop 4.3.25-4.3.28）——「在饱和模型里
能做初等扩张里的事」的兑现：

- **可定义性判据**：X A-可定义 ⟺ X 被一切固定 A 的自同构
  集合式固定。证明的机关：若 X 非 A-可定义，造「a∈X、b∉X、
  a 与 b 同 A-型」的 Γ，饱和性在模型内部实现它，齐次性把
  实现对搬成自同构——矛盾。推论 4.3.26：b 可由 A 定义 ⟺
  b 被一切固定 A 的自同构固定（「可定义=不动点」）。
- **代数闭包判据**（Prop 4.3.27）：b 代数于 A ⟺ b 在固定 A
  的自同构下轨道有限 ⟺ tp(b/A) 实现元有限。三条线在饱和
  模型里等价——**acl 的轨道语义**（58 章预几何的模型论根基）。
- **QE 新判据**（Prop 4.3.28）：T 有 QE ⟺ 任何部分嵌入
  f:A→N（N 为 |M|⁺-饱和）都能扩成 M 的嵌入。判据的用法
  在 DCF₀（微分闭域，Def 4.3.29）兑现：微分多项式按「阶」
  排优先级，部分嵌入沿「低阶先安置」的归纳扩张——DCF₀ 有
  QE、完备、可判定，且是 ω-稳定的（微分代数版本的 ACF
  故事；90 章微分 Galois 会回来取这件工具）。

## 坑位速记（本章实测）

- **规模三连**：B=6 层+3 参数的公式宇宙=1.5M 条、×15×15
  的 profile 匹配爆到 3.4 亿次——缩到 B=3+2 参数（66k 公式）
  后 47 秒绿；**枚举件先估公式数（项数²的量级）再定参数**。
- **`(x asg : nat)` 双名绑定**：Definition 参数表里写
  `(x asg : nat)` 绑了两个名字、签名错位五个位置——报错点
  在调用处而非定义处（看 environment 里的 evT 签名）。
- **Q 的下方切割需要负方向代表**：nat 宇宙里「v<最小元」
  的实现元只能是更小的 nat——把 A 抬到 [1;5]、dom 从 0
  起，三向切割才都有活口。
- **同构检查必须保序**：只查常量固定的双射会被「常量错位
  但排列凑巧」的 f 骗过（L1/L3 的 c₀ 位置 0 对 1——排列
  [1,2,3,0] 恰好把常量对上）；加保 < 检查后无一通过。
- **Lean 侧**：多段 `++` 需要外括号（右结合歧义会吃掉
  flatMap 的返回类型）；`forms` 用 `Pf.andP`/`orP` 避开
  核心的 `And`/`Or` 解析。

## 小结

本章把「多实现」做成机器：有界饱和检查器在 (N,S,0)（逐层
饱和）与钳位 M₅（破口）之间划出界线——饱和性的本质是「每个
一致型都有活口」，无界性是它的供给侧；DLO 的 2m+1 型计数与
「密度=实现」链把 Ex 4.3.9 的证明拆成三段可触摸的账；齐次性
的延拓账（尾平移/命名点/Γ 搜索）是 Prop 4.3.3 的有限影子。
大基数侧的存在性链、齐次+泛=饱和、以及三条饱和论证法（可
定义性/代数闭包/QE 判据——DCF₀ 的入场券）在文档线完成。下
一章（53 章）数模型：可数饱和与素模型的两极之间，Ryll-
Nardzewski 把 ℵ₀-范畴钉在「型空间逐层有限」上，Ehrenfeucht
的三个模型演示中间地带的生态。
