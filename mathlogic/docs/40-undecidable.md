# 第 40 章 通用性与不可判定性：停机、Rice 与递归定理

> 对书：Marker《An Invitation to Mathematical Logic》ch 10。本章通道：C（`examples/40_undecidable/ex40_undecidable.v`）/ L（`examples/40_undecidable/ex40_undecidable.lean`）。

39 章（递归函数）把「可计算」做成归纳数据；37 章（寄存器机）
给了第一台机器。这一章到达 Marker Part III 的中心事件：**通用
机器、停机问题不可判定、以及两条把不可判定性扩散出去的大定理
（Rice、Kleene 递归定理）**。书 ch 10 的路线：通用机（可计算地
解释编码程序）⟹ 停机集 K 不可判定（对角）⟹ index set 只有
∅/ℕ 可计算（Rice）⟹ Church 定理（FOL 有效性不可判定，θ_P 归约）
⟹ 递归定理（任何全可计算 f 有不动点 e：φ_e=φ_{f(e)}——自指的
建设性一面）。

## 一、通用机：演算作为数据

通用机 U 满足 U(e,x) = φ_e(x)：**程序与数据同层**。这是全书
「演算作为数据」暗线（04 章编码、21 章 G 系统嵌入、36→43 章哥
德尔编码）的机器化收束。真实构造需要一个 Gödel 编码
prog ↔ ℕ：本章机器面用**程序表索引**——24 个程序的有限编号
片段（`U`/`decP`），通用机 `urun e x fuel := run (decP e) …`
逐字面直译。真实的 cp 链编码在 Coq 的 unary nat 下**随程序长度
指数爆炸**（三条小指令 ≈ 15 万、四条 ≈ 10⁷——43 章平方配对的
教训在此加倍），表索引是诚实的替代：编号定理的完整形式（存在
可计算双射 prog↔ℕ）在文档线交代，机器件全部落在可算的小宇宙
里。通用性与直接解释的一致性由 `urun_agrees` 对账。

## 二、停机问题：对角的两张现场票

**定理（Turing）**：K = {e : φ_e(e)↓} 不可判定。

证明是本书最短的伟大证明：设 h 全可计算且 h(e,x)=1 ⟺ φ_e(x)↓。
造 D_h :=「h(e,e)=1 则转死循环，否则立即停」，设其码 d。问
h(d,d)：答 1 则 D_h(d) 转不停——错；答 0 则 D_h(d) 停——错。

机器面把两张「翻车票」直接开出来：h≡true（声称全停）时对角
程序是 4 号自转（`diag_true_diverges`：60 个燃料档全 None）；
h≡false（声称全不停）时对角程序是 5 号立即停（`diag_false_
halts`）。一般 h 的 D_h 装配（把 h 的调用编进程序体）是 s-m-n
的练习，文档线讲。**停机检测的语义坑**先在此填平：`halted`
判「当前指令是 rhalt（或越界）」——37 章的「pc 不动=停」判据
在自环跳转 `rife r k k` 上会误判（pc 恒在 k 但程序在转），
`Kstage` 的账本里 4 号被正确排除正是新判据的功绩。

K_s 的**单调性**（燃料加倍只会多停：`k_monotone`）是「K 是
K_s 的并」的有限影子——这正是 41 章算术层级的 Σ₁ 台阶。

## 三、Rice 定理：语义性质全体不可判定

**定义（index set）**：X ⊆ ℕ 是 index set，若 φ_i=φ_j ⟹
(i∈X ⟺ j∈X)——只看程序**算什么**，不看它**怎么写**。例：
Tot={e:φ_e 全定义}、Con={e:φ_e 常值}、Fin={e:定义域有限}。

**定理（Rice）**：可计算的 index set 只有 ∅ 与 ℕ。

证明（书 Th 10.11）：非平凡 X 取 e₀∉X（处处发散）、e₁∈X；
对任意 x∈K 造 g(x) := 「x∈K 则跑 φ_{e₁} 否则跑 φ_{e₀}」的码
（s-m-n）——g(x)∈X ⟺ x∈K；X 可计算 ⟹ K 可计算，矛盾。

机器面验证前提的一半：**同语义 ⟹ 必同答**——恒等的两种写法
（2 号/3 号）与 +2 的两种写法（1 号/17 号）在全部测试输入上
行为一致（`rice_same_behavior` ×2）而码不同。任何「行为谓词」
在这两对上被迫取同值——Rice 的结论是这个约束+对角化的必然。
完整装配记文档线。

## 四、Church 定理与递归定理

**Church 定理**：FOL 有效性不可判定。归约路线：给 RM 程序 P
造 FOL 句子 θ_P（「配置可达性」的形式化——配置关系 R 用 44 章
的表示性样板可定义），证 **P 停机 ⟺ θ_P 有效**：停机方向用
标准模型 ℕ 上的计算表；不停方向用书里显式造的模型 M（R 解释为
计算历史+一个「逃逸点」）。有效性若可判定，停机即可判定。完
整构造在 44 章算术化的延长线上，记文档线。

**Kleene 递归定理**（Th 10.12）：任何全可计算 f 有 e 使
φ_e = φ_{f(e)}。证明的装配：对 h(w) := f(U(w,w))（先跑 w 于
自身、再把结果喂给 f）用 s-m-n 得 g（φ_{g(x)}(y) = φ_{h(x)}(y)），
取 c 为 g 的码在通用机中的自举点 e := g(c)——φ_e = φ_{f(e)}
逐步成立。**quine**（输出自身码的程序）是 f := 「code of
output-x」时的不动点：程序把自己写出来。这条定理是 43 章
（旧 36）自引句构造的可计算化身——语义不动点取代语法对角。
机器面承载 s-m-n 的数值影子（`smn_shadow`：F(x,y)=2x+y 特化
x=3 与 6 号程序逐点一致）；不动点装配的全形式记文档线。

## 小结

通用机把程序变成数据，对角法把「自己说自己」变成不可判定的
火种：停机、Rice（全部语义性质）、Church（有效性）成片倒下；
递归定理显示同一枚硬币的另一面——自指不止能破坏，还能**构造**
（任何变换 f 都有程序在语义上与自己的像重合）。下一章给「不可
判定」分层：算术层级 Σₙ/Πₙ 把可定义性排成塔，Kolmogorov 复杂
度是塔上最优雅的房客。
