# 13 Kripke 语义：不可证性的机器证据

> 对书：Mints ch7 / H&R §5.2（模态 Kripke 的对照入口）
> 通道：C/A/L（两世界反例零公理）

04 章说经典原理「构造内核下证不出」，11 章说「差距恰好一层 ¬¬」
——但「证不出」还只是**演算侧的观察**（没人找到证明）。本章
补上语义侧的铁证：构造一个**模型**，在其中经典原理的某个实例
为假。有了它，「不可证」从「没找到」升格为「不存在」（一致性
论证：若可证则在一切模型为真——而它在此模型为假）。这类模型
就是 **Kripke 语义**——Saul Kripke 1959 年为直觉主义逻辑发明的
可能世界语义。

## 世界的直觉：知识状态而非真值

经典语义里命题「有真值」；直觉主义语义里命题「有知识状态」。
设世界 w 代表「研究进展到某个时刻」，w ⊩ p 读作「到 w 时刻
为止，已确认 p」。两个设计决定塑造了整个语义：

1. **知识只增**（单调性）：时间前进（w ⊑ w'），已确认的不会
   翻案——w ⊩ p 且 w ⊑ w' 则 w' ⊩ p；
2. **蕴含看全部未来**：w ⊩ a→b 不是「此刻 a 蕴含 b」，而是
   「**任何未来时刻**确认了 a 就（在同刻）确认 b」——证明
   a→b 是造一台「永动机式的推理装置」。

第二点是 LEM 倒台的地方：w₀ 时刻可能既没确认 p（所以左支不
成立），也不能确认 ¬p（因为 ¬p 要求杀死**一切未来**的 p 证据，
而未来可能确认 p——右支也不成立）。语义的精细度恰好容纳
「p 现在未知、将来或知」的认知状态——经典二值没有这个房间。

## 两世界框架（最小反模型）

```
世界 0：无原子知识          世界 1：知道一切原子
        0 ⊑ 1（知识只增）
```

机器表示（`examples/13_kripke/` 三通道）：世界是两个构造子
`w0/w1`，可达 `⊑` 是归纳关系（`le01 : w0 ⊑ w1` 加自反），
原子赋值 `val : world -> nat -> bool` 只在 w1 给真。强制
关系 `⊩`（forces）按连接词归纳定义，→ 条款是全场主角：

```text
w ⊩ a→b := ∀ w' ⊒ w, w' ⊩ a → w' ⊩ b
```

注意量词**所有可达世界含未来**——这正是上面第二条设计决定。
其余条款（∧/∨/¬）与经典真值表同形（¬ 按 →⊥ 展开），差别
全部藏在 → 的量词里。

## 强制关系逐条款：与经典真值表的逐行对照

`⊩`（forces，Kripke 的原文术语）按连接词归纳定义。把六个条款
与 02 章 eval 的布尔条款并排放，差异一目了然（`examples/13_kripke/
ex13_kripke.v`）：

| 连接词 | 经典（02 章） | 直觉 Kripke（本章） | 差异 |
|---|---|---|---|
| 原子 p | e p = true | w ⊩ p := val w p（世界自己的账） | 账本按世界分 |
| ⊥ | false | 任何 w 都不强制 | 同形 |
| a∧b | andb (eval a) (eval b) | w ⊩ a ∧ w ⊩ b | 同形（逐世界） |
| a∨b | orb … | w ⊩ a ∨ w ⊩ b | **同形**——∨ 的分歧不在条款而在「∨ 证明须携带侧别」（12 章 DP） |
| ¬a | negb (eval a) | ∀ w' ⊒ w, w' ⊩ a → ⊥ | 否定=「杀死一切未来」 |
| a→b | implb … | ∀ w' ⊒ w, w' ⊩ a → w' ⊩ b | **全场唯一的实质差异** |

看见了吗：**整张表的「直觉主义性」全部集中在 →（和作为其特例
的 ¬）的全未来量词上**。∧/∨ 的条款是经典条款的「逐世界化」
——每个世界内部仍然按布尔规则算。这个结构性的观察解释了
11 章 Glivenko 为什么在命题层干净成立：¬¬ 翻译只在 →/¬ 的
「未来量词」上做文章，∧/∨ 原样通过。也预告了 43 章模态 Kripke
的 □ 条款（∀可达）与本章 → 条款的同构——模态逻辑界干脆把
直觉主义的 a→b 读成 □(a ⊃ b) 的形态（Gödel–McKinsey–Tarski
翻译）。

## 旗舰：LEM 反例（三通道零公理）

```
¬ (w0 ⊩ p ∨ ¬p)
```

两支皆倒的机器证据：

- **左支**：`w0 ⊩ p` 需要世界 0 的原子知识，而 w0 的赋值是
  **空数据类型**——空模式一击必杀（Agda `inj₁ ()`；Coq/Lean
  对 val 构造子 inversion）；
- **右支**：`w0 ⊩ ¬p` 要求吸收一切未来世界的 p 证据——把
  世界 1 的 `k1`（p 的证据）喂进去即得 ⊥。

两条合起来：w0 不强制 p∨¬p——**LEM 在此模型失败**，因此
直觉逻辑不可证 LEM。注意这个论证的构造完全「在模型内」
——它本身是一个直觉主义的证明（三通道 `Print Assumptions`/
`#print axioms` 全零公理）。用构造手段证明「经典原理不可
构造证明」——这个自反的优雅是直觉主义元数学的标志。

## 反例的机器走查：两支怎么倒的

反例定理的证明体值得逐行走一遍（Coq 版骨架，Lean/Agda 同构）：

```coq
Theorem lem_counter : ~ (forces w0 (FOr (FVar 0) (FNeg (FVar 0)))).
Proof.
  intro H. inversion H as [Hl | Hr].
  - (* 左支：w0 ⊩ p 0 *)
    inversion Hl.       (* forces w0 (FVar 0) 展开 = val w0 0 = true *)
    (* val w0 0 的定义是「空知识」构造子——inversion 直接关闭目标 *)
  - (* 右支：w0 ⊩ ¬p 0 *)
    inversion Hr as [w' Hle Habs].
    (* forces w0 (FNeg _) 展开：∀w' ⊒ w0, w' ⊩ p 0 → False *)
    apply (Habs w1 le01).
    (* 喂世界 1（未来）与其原子知识 k1 *)
    inversion …（val w1 0 = true 的构造子证据）
Qed.
```

两支的死法不同：左支死于**当下没有**（空数据类型的 inversion），
右支死于**未来翻案**（全称量词的可满足性——存在一个 w1 见证
摧毁 ¬p 的承诺）。左支是「证据缺失」的静态不可能，右支是
「承诺过载」的动态崩溃——LEM 的两个析取支分别撞上 Kripke
语义的两根柱子。这种「一个反例、两种死法」的结构分析比反例
本身更有教学价值：它告诉你经典原理失败的**原因分布**，而
不只是失败的事实。

## 单调性引理（Coq/Lean 通道）

```
monotone : w ⊑ w' → w ⊩ f → w' ⊩ f
```

知识只增的语义骨架。对公式归纳，→ 分支要复合可达关系
（`leTrans r r'`）：w ⊩ a→b 给的是「对一切 w'' ⊒ w」的装置，
要在 w' 用它需要 w'' ⊒ w' ⟹ w'' ⊒ w 的传递性。Agda 版的
对应现场是 `⊑-trans r01 r00` 被检查器直接拒绝——w1 不回到
w0，多余分支写不出来（可达关系的「时间之箭」被类型系统
守卫）。

## 本章 vs 43 章：两种 Kripke 的分工

名字撞车的两章必须一次说清。**直觉主义 Kripke**（本章）与
**模态 Kripke**（43 章）共享「可能世界+可达关系」的骨架，但
设计目标相反：

| | 直觉主义（本章） | 模态（43 章） |
|---|---|---|
| 可达关系 | 预序 ⊑（自反+传递），**时间之箭** | 任意二元关系 R，无约束 |
| 语义基础 | 单调赋值（知识只增） | 任意赋值（各世界独立真值） |
| □/◇ 对应物 | 无（¬ 和 → 的条款自带「全未来」量词） | □φ = ∀可达.φ；◇φ = ∃可达.φ |
| → 的条款 | ∀w'⊒w.（w'⊩a → w'⊩b）——**约束未来** | 经典真值函数（→ 按布尔语义） |
| 反例产出 | LEM/DNE 的直觉不可证性 | 框架性质↔模态公理的对应理论 |
| 谱系 | Beth/Kripke 为直觉逻辑造 | Kripke 为模态逻辑造（同期两文） |

一句话：**本章的 ⊑ 是「信息序」，43 章的 R 是「关系词」**——
前者把可达解释成认知进程，后者把它解释成可能性/时间/知识
（ KT45n 的「主体可达」）等多种模态。同一个数学骨架（图+
二元关系）承载两套语义学，是「语义=骨架+解释」的好教材。
43 章开篇会回指本表。

## DNE 为什么不是这个框架的反例（本章最有价值的认知修正）

草稿版 DNE 反例（`¬(w0 ⊩ ¬¬p→p)`）被三轮机器检查推翻：
`¬¬p` 在 w0 **不被强制**（w0 自身的 ¬p 真而无法吸收——¬p
要吸收一切未来，w1 的 p 证据挡在那里），蕴含在 w0 **空真
成立**。DNE 的 Kripke 反例需要原子知识「未来真假交替」的
三世界框架（Mints §7.2 有构造）。诚实删除，文档说明。

**元教训**：反例也要被机器审——「直觉上的反例」与「真正的
反例」之间隔着一次空真检查。蕴含式的反例必须先验证前件在
该世界**真的被强制**。这条纪律在 38 章（CTL* 表达能力反例）
还会用到——反模型的验证和反模型的构造同等重要。

## 完备性侧注

Kripke 语义对 NJp 是**可靠且完备**的（Γ ⊢ φ ⟺ Γ 在所有
Kripke 模型中强制 φ）——直觉主义的「模型论」与「证明论」
在此缝合，恰如经典逻辑的 Henkin 完备性（22 章）。有趣的不
对称：经典完备性用极大一致集造**单世界**模型；直觉完备性
造的是**世界链**——每个世界吸收一条「未来知识」，一致性
被分布在时间轴上。本教程不机器化这条完备性（22 章只做经典
方向），但 13 章的反模型技术正是完备性构造的「局部零件」。

## 本章小结

- Kripke 世界=知识状态；单调性+全未来量词是语义的两根柱。
- 两世界框架是 LEM 的最小反模型：左支空知识、右支未来翻案
  ——不可证性从「没找到」升格为「不存在」。
- 单调性引理=知识只增的形式化；→ 分支的传递性复合是重点。
- 直觉主义 ⊑（信息序）vs 模态 R（关系词）：同骨架两语义，
  43 章的对照入口。
- 反例须过空真审查——DNE 事故的教训写进方法论。
- Kripke 完备性=分布在世界链上的 Henkin（22 章经典版对照）。

## 坑位速记（本章实测）

- **Coq/Rocq**：`forces` 的 → 定义里的合取 `(w <= w' /\
  w' <= 1)` 在 apply 后显示为链 `w <= w' <= 1`——一个目标
  而非两个，`split` 后再喂；`val_mono` 的 val 定义带
  `match n`——destruct 世界前先 destruct n 否则 reflexivity
  关不掉。
- **Agda**：`⊑-trans r01 r00` 是非法模式（w1 不回到 w0）——
  可达关系三分支穷尽后 Agda 检查器直接拒绝多余分支；
  `¬k a` 在 LHS 要加括号 `(¬k a)`（前缀/中缀混排解析）；
  `Relation.Nullary` 的 `¬_` 别忘了 open。
- **Lean**：`by cases r <;> cases r' <;> exact ‹_›` 的自动
  求解会**挂死**（180s 超时）——Le 复合必须显式 leTrans；
  doc comment `/-- … -/` 后不能跟 `#print axioms`（解析期
  报错）。
- **通用**：反例先过「空真」审：蕴含前提不成立时反例不成立；
  三世界 DNE 反例的构造留作 43 章后的回练（Mints §7.2）。
