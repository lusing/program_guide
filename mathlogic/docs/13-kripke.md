# 13 Kripke 语义：不可证性的机器证据

> 对书：Mints ch7 / Huth&Ryan §5.2（模态对应）

04/11 章的「写不出来」在本章升级为「**有反例**」：两世界 Kripke
框架给 LEM 提供最小反模型。

## 两世界框架

```
世界 0：无原子知识          世界 1：知道一切原子
        0 ⊑ 1（知识只增）
```

强制关系 `⊩` 的关键在 **→ 分支量词所有可达世界**（含未来）：
`w ⊩ a→b := ∀ w' ⊒ w, w' ⊩ a → w' ⊩ b`。

## 旗舰：LEM 反例（三通道零公理）

```
¬ (w0 ⊩ p ∨ ¬p)
```

两支皆倒：

- **左支**：`Knows w0 0` 无构造子——世界 0 的「无知」被类型化为
  **空数据类型**，空模式一击必杀（Agda `inj₁ ()`）；
- **右支**：`¬p` 在 w0 被强制则须吸收**一切未来世界**的 p 证据——
  喂世界 1 的 `k1` 即得 ⊥。

## 单调性引理（Coq/Lean 通道）

```
monotone : w ⊑ w' → w ⊩ f → w' ⊩ f
```

→ 分支的复合 `leTrans r r'` 是重点——知识只增的语义骨架。

## DNE 为什么不是这个框架的反例（本章最有价值的认知修正）

草稿版 DNE 反例（`¬(w0 ⊩ ¬¬p→p)`）被三轮机器检查推翻：
`¬¬p` 在 w0 **不被强制**（w0 自身的 ¬p 真而无法吸收），蕴含
在 w0 **空真成立**。DNE 的 Kripke 反例需要原子知识「未来真假
交替」的三世界框架（Mints §7.2）。诚实删除，文档说明。

**元教训**：反例也要被机器审——「直觉上的反例」与「真正的反例」
之间隔着一次空真检查。

## 坑位速记（本章实测）

- **Coq**：`forces` 的 → 定义里的合取 `(w <= w' /\ w' <= 1)`
  在 apply 后显示为链 `w <= w' <= 1`——一个目标而非两个，
  `split` 后再喂；`val_mono` 的 val 定义带 `match n`——destruct
  世界前先 destruct n 否则 reflexivity 关不掉。
- **Agda**：`⊑-trans r01 r00` 是非法模式（w1 不回到 w0）——
  可达关系三分支穷尽后 Agda 检查器直接拒绝多余分支；
  `¬k a` 在 LHS 要加括号 `(¬k a)`（前缀/中缀混排解析）；
  `Relation.Nullary` 的 `¬_` 别忘了 open。
- **Lean**：`by cases r <;> cases r' <;> exact ‹_›` 的自动求解
  会**挂死**（180s 超时）——Le 复合必须显式 leTrans；
  doc comment `/-- … -/` 后不能跟 `#print axioms`（解析期报错）。
- **通用**：反例先过「空真」审：蕴含前提不成立时反例不成立。
