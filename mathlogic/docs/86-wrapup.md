## 一、自动推理的频谱（SAT→SMT→MC→ITP）

```
完全自动              ─────────────►           交互证明
SAT            SMT              模型检查        ITP
DPLL(10)       presburger(55)   CTL(56/58)      Coq/Lean/Isabelle/HOL4/Agda/HoTT
复杂度(45)     Nelson-Oppen     LTL(57)         67/68 霍尔+变体
BDD(11)                         符号MC+μ(63)    不完备性(48)住最右
归结(33)                        自动机(63)      泥孩子(66)
```

**模型检查三站式**（Ben-Ari 轮扩充新增）：显式标记（54）→
工作流与公平性（56：反例轨+饥饿+宣告过滤）→ 符号 μ 演算
（61：preE+不动点编码）——表达力在 57（CTL*）处再分一档，
与 56 章 ESO 天梯同构。模态线（62-64）则是「逻辑工程」的
完整案例：K → 对应理论选型 → KT45n 知识应用。

**频谱的本质是「表达能力 vs 自动化程度」的交易**：

- **SAT**（10 章 DPLL）：命题逻辑，NP 完全但工程上惊人地快。
  单元传播 = `upd` 复合装配——本教程把它做成零公理定理。
  **复杂度宪章位**（45 章）：证书验证 O(|F|) vs 蛮力 2^n 的
  步数双账、SAT→3SAT→CLIQUE 归约链——「最坏指数与典型可解
  并存」的账本。
- **BDD**（11 章）：同态压缩的命题语义——树形 vs DAG 的坍缩
  在现场实录里裸奔。
- **SMT**（56 章）：SAT 骨架 + 理论求解器（等式、算术、数组）。
  presburger 在 Isabelle 里是 `by presburger` 一行——但它的
  可判定性证明本身住在元理论那侧。
- **模型检查**（57 章）：时序逻辑 + 有限状态空间 = 算法。
  AG/EU 的不动点刻画（Knaster-Tarski）是 34 章 T_P 单调性的
  亲兄弟。
- **ITP**（全部 65+ 章）：任意数学，人类出点子机器查证明。
  48 章的不完备性定理恰好是这个频谱的「宪章」——没有任何
  自动系统捕获全部真理，所以交互证明永有一席之地；49/50 章
  把宪章写全（理论证不出自身一致、真谓词逃出全部定义）。
- **应用位**（75 章）：逻辑训练出的数论在文化里兑现——RSA、
  Shamir 三趟、哈希链、纠缠锥：45 章的复杂度赌注在这里变成
  真金白银。

25 章的完备性（Henkin 构造）是另一头的宪章：一阶逻辑的证明
系统不多不少刚好够用——SAT/SMT/归结/MC 的**可靠性**都从它
的证明侧借来合法性。

## 二、总坑位清单（六通道 86 章精选）

### Coq（Rocq 9.1）

- `apply (proj1 (iff…)) in H` 会 shelve 前提目标——Qed 爆
  open goals（ch01）；解法 destruct + pose proof
- `destruct eqn:` 分支序 = 模式序（ch05）；destruct 会替换
  目标里的 scrutinee（ch15）
- `lia` 把 2^S n 与 2^n 当两个原子（ch08）；`hd` 与 stdlib
  类型冲突（ch24）；Python 转义的字符串 `/\` 被吃（ch17）
- remember + revert 让方程进归纳动机（ch25 的 while 规则）

### HoTT（Rocq 9.1 + Coq-HoTT）

- 顶层无 Prelude——`Require Import HoTT.HoTT`（旧版布局）
- False_ind/Empty_rect 双失败 → set + destruct Empty（ch04）
- 截断当「丢标签」读——析取性质的直觉主义证法（ch12）

### Lean 4（core 无 Mathlib）

- `lemma` 不是命令关键字（ch25）——全用 `theorem`
- `while` 是 do 记法保留字（ch25）
- induction 拒绝构造子头索引（ch25）；`induction … with`
  构造子字段全在前、IH 在后（ch17）；doc comment 后不能接
  #print axioms（ch13）；`‹_›` 求解器会挂死（ch13，等式 OK
  ch25）；构造子头索引的守卫 elaboration 分叉（ch25 的
  decide 统一法）
- 冒号前参数、纯 Nat 减法截断（typetheory 教程的坑在此复用）

### Agda（2.8 + stdlib 2.3）

- with 定义的函数在引理处卡 with-under-with（ch25）——换
  Bool-if + cong
- `⌊ _≟_ ⌋` 的 because/Reflects 构造不做定义性归约（ch25）
  ——`_≡ᵇ_` 纯 Bool
- with 抽象 `s x` 留悬空约束 `_s _x = s x`（ch25）——with
  抽象判定本身或换 ≡ᵇ
- where 块的隐式元变量在组装位悬空（ch25）——构件提顶层
- case-tree 互卡边界（ch08）；with 只作用于子句目标（ch05）

### Isabelle/HOL（2025-2 Windows）

- 字面 Unicode 词法坑（ch04 二次实锤）；`∃c∈set` 害 eval
  （ch24）；induction 与 arbitrary 打架（ch24）
- `lemma[of a b]` 实参按变量出现顺序（ch01）
- 构造子头索引要显式实例化 + arbitrary（ch25）；auto 深度
  不够换 blast（ch25）

### HOL4（develop + Poly/ML 5.9.2）

- `bin/hol run` 是唯一可信入口（REPL 管道假绿）；metis
  爆炸时 hol run **静默中止**（exit 0 无错误输出，ch25）
- 战术位引文是静态上下文 elaboration——目标绑定变量看不见
  （ch25 全类型注解救命；`!s1 s2.` 注解版反而解析失败）
- REPEAT STRIP_TAC 双向工作（前件 ∨ 分情况、目标 ∧ 拆开，
  ch03）；DISJ1/DISJ2 签名不对称（ch03）
- Hol_reln 返回 3 元组、strongind/cmd_11 要 fetch（ch25）；
  弱 ind 案例 Exec' 没有 exec 副推导——strongind 才能用
  （ch25）；exec 反演只能一层（级联污染，ch25）

### 工具链层

### 第七轮（Müller-Stach 轮）新坑

- **N_scope 三连劫持**（49/85 章）：`Open Scope N_scope` 后
  nat 参数 match 的数字模式 `0` 变 N 构造子（改写构造子 O）、
  `S e` 的 nat 后继撞 N（改 `N.succ`）、nat 字面量表整体劫持
  （分段 `Open Scope nat_scope` 切回）
- **guard 第六撞**（75 章 powmod）：指数减半走 `Nat.div2` 非
  结构子项——教学件降级朴素线性版，平方-乘记文档线（Lean 的
  GMP Nat 无此劫）
- **nat 截断减法判零**（75 章纠缠锥）：`a·d − b·c =? 0` 在积
  差为负时塌成 0 误判可分离——改等式判定
- **unary mod 的归约步数**（75 章哈希链）：mod 9973 每次折叠
  三十万步 kernel 操作整链卡死——教学件降模 97（8 秒全绿）
- **65537 字面量在 rfl 下抽象**（85 章）：of_num_uint 不展开
  ——期望侧用同形表达式对账
- **Definition 自引用**（85 章 fermat）：递推必须 Fixpoint
- **Zermelo 编码层数依赖值**（85 章）：扁平 list 每层类型不
  同——归纳树类型 zset 忠实编码
- **Lean flatMap 笛卡尔积方向**（45 章）：展开 rest 元素当
  后缀语义全错——`l.flatMap (x => (cartProd rest).map (x::))`
- **Lean dot-前缀断点**（49 章）：换行后行首 `.map` 不解析；
  #eval 自定义类型需 `deriving Repr`
- **Prolog between/3 要已求值整数**（75 章）：`between(1, P-1,
  Y)` 传 compound——先 `P1 is P-1`；**is_gen 费马陷阱**：直接验
  g^(p−1)≡1 把全群误判生成元——先找最小阶再比对
- **元工作坑**：python `str.replace` 未命中时静默返回原串
  （永远校验替换计数）；`coqc | tail` 管道退出码是 tail 的
  ——失败被假绿掩盖（用输出文件判定）


### 第八轮（张寅生轮）新坑

- **Coq `&&`/`||` 记号在 From Stdlib List Arith 语境不可用**（15/63 章
  实锤）——一律 andb/orb 显式前缀；`Nat.pow2` 不存在（Nat.pow 2 n）
- **Coq 三元组字面量左结合**：`(a,b,c)`=(a,b),c 与嵌套对类型不合——
  清单/构造全部显式 `(a,(b,(c,d)))`（15 章 256 格式账的教训）
- **`at` 是 Coq 关键字**（78 章 assignOK 的 lambda 参数撞名）
- **`seq` 自定义类型撞 List.seq**（54 章 gseq 改名）
- **map2 不存在**（79 章矩阵逐位或——手写 zipOr 递归）
- **Lean 列表字面量首元素须全限定**（`.pvar` 无法回推类型——20 章
  抽样列表的 PForm.pvar 前缀）
- **Lean zipWith 方法调用语法参数序错**（79 章——用全应用
  List.zipWith f a b）
- **DFA 缺省转移=自环是语义 bug**（63 章）：越轨词「免费跳过一个
  符号」继续读——缺省必须 sink 态；Prolog 对账件当场抓获（Coq 侧
  因字母表漏 e 符号「空对空」假绿——测试的字母表必须覆盖终态字符）
- **Smullyan 对角集的简化编码会「避开对角点」**（78 章）：φ 的
  定义域/值域混同后可绕开自指——g 的对角作用须压成公理
  （cmap m m=m）
- **F₃ 方向表成比例即同线**（84 章）：8 个「方向」实为 4 个
  （(0,2)=2·(0,1)）——重复表示的线对交 3 点破坏唯一性
- **CNF 序数 natSum 左对齐错位**（54 章）：高位在前编码长度不齐时
  自然和错算——改低位在前（常数在头，天然对齐）
- **例 9.5 类「条件证明」目标式非永真**（20 章）：书例的前提
  ⊢b→a 排除反例赋值——目标式挂前提后才是永真式（推导正确性=
  条件式永真性）

## 五、Lingua Universalis：Leibniz 之梦的时间线（收官）

全书弧线在此收拢——「证明即计算」的三百年长征（时间线全部
自包含，出处见原书 p29-41/p125/p151-152）：

```
13c  Llull     Ars magna——机械组合推理的第一次尝试
1629 Descartes 致 Mersenne：「通用语言的构想」
     Hobbes    「推理即计算」
1668 Wilkins    《论真实符号与哲学语言》——分类即命名
1666 Leibniz    Dissertatio de arte combinatoria（20 岁）
1714 Leibniz    致 Rémond：「一切理性真理化为计算」
     ——— 二百年断层 ———
1847/1879 Boole/Frege  逻辑的代数化与概念文字（二阶逻辑）
1889/1900 Peano/Dedekind  算术公理化
1900 Hilbert    纲领：一致性=数学的合法性证明
1931 Gödel      打击：不完备性——纲领在原形式内不可达
1936 Turing/Church  精确化：可计算性——Leibniz 之梦的
                   可计算部分被圈定边界
1934/1969 Curry–Howard  证明即程序的类型论读法
     ——— 梦的部分实现 ———
2005 四色定理（Coq）       2012 Feit–Thompson（Coq）
2017 Kepler 猜想（HOL Light+Isabelle）
2021 液体张量实验（Lean）——数学前沿的正式化
```

**三基础互译圆环**（书 p150-152 的收束）：集合论（83 章 NBG）、
类型论（13 章 CH+univalence 桥）、高阶范畴论（文档线桥）——
互为对象语言与元语言、互相解释。从这种俯瞰看，「语义被祛魅：
无非是更丰富演绎系统中的可证性」（原话）——50 章的真理理论
（Tarski 分层/Kripke 不动点）与 49 章的一致性扩张梯子在圆环
上重逢：**真理是层级的极限，证明是层级的踏步**。Leibniz 的
Lingua Universalis 没有全部实现——不完备性是它的宪章边界
（86 章频谱的右端）——但「calculemus」（我们来算吧）已从
口号变成日常：本教程 222 个验证单元就是这条时间线的最新一串
脚印。
