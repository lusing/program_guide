第 36 章结束了 tame 语义的代数侧；从这一章起，我们进入 GTM 217
第二部分的主线——**模型构造的通用机械**。第一个概念是「型」：
一个元素（或元素组）在结构中可能满足的全部一阶性质的打包。
型是模型论的显微镜：它把「结构里有什么」从元素级分辨率提升到
「初等等价类」级分辨率，而所有后续机件——省略、素模型、饱和、
ω-稳定、分叉——都是在型空间上做拓扑。

## 一、型：完全一致的公式集

**定义**（Def 4.1.1-4.1.2 的机器面）。固定结构 M 与参数集 A⊆M。
一个 **n 型** 是含自由变元 v₁..vₙ 的公式集 p，满足 p∪Th_A(M)
一致；**完全 n 型**还要求对每个公式 φ 恰有 φ∈p 或 ¬φ∈p 之一。
元素 a∈Mⁿ **实现** 型 p 如果 p⊆tp(a/A)（a 的完全型）；
模型**省略** p 如果没有元素实现它。

两个基本事实值得先说透：

- **型可以在初等扩张中实现**（Prop 4.1.3/Cor 4.1.4）：任何
  p∈S_n^M(A) 都是某个初等扩张 N⪰M 里某元素的真实型。型是
  「潜在的元素」——这把 28 章 Henkin 构造的「见证」抽象成了
  拓扑对象。
- **同型⟹初等扩张里自同构相连**（Prop 4.1.5 + Lemma 4.1.6/7）：
  tp(a/A)=tp(b/A) 时，把 f:a↦b 逐元素扩张成链 M=M₀⪯N₀⪯M₁⪯N₁…
  取并得到 σ∈Aut(N) 固定 A 且 σ(a)=b。证明的核心引理（Lemma
  4.1.6）是「部分初等映射可以一步加一个元素」——紧致性保证
  Γ={φ(v,f(ā)) : M⊨φ(b,ā)}∪Diag_el(N) 一致。「型=轨道」的
  直觉由此获得严格形态（在 monster 模型里完全成立）。

## 二、Stone 空间：型空间的拓扑

S_n(A) 上取 **Stone 拓扑**：基是 [φ]={p : φ∈p}。三条基本律
（Lemma 4.1.8-4.1.9）：

- **紧**：任何基本开覆盖有有限子覆盖——否则 {¬φ_i} 与
  Th_A(M) 联合有限一致（每个有限段被某个型避开），紧致性给
  出同时避开全部 [φ_i] 的型，矛盾。
- **全不连通**：p≠q 时有 φ 分离（φ∈p、¬φ∈q），[φ] 是 clopen。
- **限制映射连续且满**（p↦p\|A 从 S_n(B) 到 S_n(A)）；初等
  嵌入诱导同胚（f(p)={φ(v,f(ā))}）。

机器面 `stonePair`/`stone_laws`（`examples/37_types/`）：在
(Z₆,S,0) 的小公式宇宙上，把 [φ] 实现为「逐赋值真值向量」
（`bracket`），对全部 544×544 对公式验证 [φ∨ψ]=[φ]∪[ψ] 与
[φ∧ψ]=[φ]∩[ψ]（`vecOr`/`vecAnd` 逐点布尔）——**clopen 集族
恰是布尔代数**，这就是「对偶 Stone 空间」的构造性含义。

**孤立型**（Def 4.1.10/Prop 4.1.11）：p 孤立 ⟺ {p}=[φ] 对某
φ（φ **孤立** p）⟺ φ∈p 且 ψ∈p ⟺ T_A(M)⊨φ→ψ。孤立型在下一章
是「必须实现的型」（Prop 4.2.2），非孤立型是「可以省略的型」
——省略型定理的全部张力就在这对概念之间。

## 三、型枚举器：机器面的方法论

怎么让「所有公式」变成机器可处理的对象？答案是**深度截断 +
语义分桶**（`examples/37_types/` 第 1-2 节）：

- 语言：项 = S^k 0 或 S^k x_i（`term`），原子 = 等词
  （`AEq`），公式加布尔连接（深度 ≤1 的 `formsD`）；
- **profile**：赋值 a 在公式表 fs 上的真值向量；
- **型枚举**：全部赋值的 profile 去重（`dedupProf`，累加器版
  ——朴素的两次递归去重是指数爆炸，本轮实测坑）。

这个方法的合法性强（对**有限结构**截断深度与公式空间，型=
语义等价类的划分模式），弱点是「深度有界」——无限结构的完整
型空间是极限对象。本章的设计是：**能全枚举的讲计数，不能的
讲形状**（∞ 型、切割），两者都有诚实账本。

**Bell 数对账**（`bell_pure_eq`）：纯等词理论（无常量、无函数）
的 S_n：公式只能表达「x_i=x_j 模式」，型=**划分模式**——
S₁=1、S₂=2、S₃=5、S₄=15，恰是 Bell 数。两个加强账：
`bell_invariance`（Z₅/Z₆/Z₇ 同数——型不依赖载体，只依赖理论）；
`bell_depth_stable`（d=0 与 d=1 同数——布尔组合不产生新分离，
原子已把划分模式分尽）。注意一个容易踩的坑：**常数 0 混进
语言会把 Bell(n) 变成 Bell(n+1)**（0 是第 n+1 个「元素」，参
与划分）——机器件为此准备了无常量版 `typeCountNC`。

**剁碎账**（`smash_zm`）：(Z_m,S,0) 的 S₁=m——每个元素被
x=S^k 0 分离。`isolated_witness_z6` 对每个 v 搜索到单点分离
公式：[x=S^v 0]={v 的型}——**孤立型 ⟺ [φ]={p}** 的机器面。
对照：纯等词理论里 (x=x) 孤立唯一的 1 型、其余维度的型也孤立
（等词模式的否定合取式）；而下面 (N,S,0) 的 ∞ 型是第一个
**非孤立**的现场。

## 四、∞ 型：非孤立的第一个现场

(N,S,0) 的 1-型：截断到 B=8 层迭代（项 S^k 0、S^k x，k≤8），
赋值 v∈0..11 的 profile 数 `inf_type_count` = **10**：v=0..8
各自成型（被 x=S^v 0 命名），v=9,10,11 **共享同一个 profile**
——「∞ 型」p∞（在任何截断深度下都「比一切被命名元素更大」的
元素型）。

关键账 `inf_type_nonisolated`：**任何在 v=9 处真的公式都在某个
v≤8 处真**。为什么？公式的原子只提到有限多个 S^k 0（k≤8），
它对 v 的约束是一张有限禁集（若干个「v≠S^k 0」型条件），
9 个被命名元素（0..8）里总有一个逃出禁集。于是 [φ] 永远
⊆{∞} 不成立——p∞ 非孤立，且**在每一层截断下都非孤立**
（加大 B 只是把同一个论证推后）。这正是省略型定理的燃料：
非孤立型可以被省略——38 章将把这台 Henkin 机器造出来。

## 五、DLO 的型=切割（Ex 4.1.12 / Prop 4.1.13）

(Q,<) 的 1-型是什么？无参数时只有 x=x（一个型）；但**带参数
集 A** 时，型由**切割**（cut）决定：L_p={a∈A : a<v∈p} 与
U_p={a∈A : v<a∈p} 构成 (A,<) 的割，且（由 QE）割完全决定型。
|S₁(Q)|=2^ℵ₀：对每个实数 r∉Q 有 p_r（L={a : a<r}），对每个
c∈Q 还有**两个**贴壁型 p_c⁺/p_c⁻——Q 的割比 Q 本身多得多，
这是 DLO 非 ω-稳定的根源（42 章回头清算）。

机器面（第 6 节）：`cutLU` 开出有限 A=[1;3;4;7] 的全部五个割
（`cuts_of_A` 的 L/U 划分逐点对账）；`cutIsolated` 验证**有限
A 上一切割孤立**——有限集处处有相邻对（或端点），a<v<b、
a<v、v<b 都是孤立化公式；`cutOf` 把「割决定型」落在计数上
（cutOf A v = #{a∈A : a<v}，v 的型由它唯一决定——`cut_determines`
的表）。Prop 4.1.13 的另一半在文档侧：**密度杀死相邻性**——
当 A=Q 时，任何割都没有相邻端点，全部非实现型非孤立。
「有限处处孤立、稠密无一孤立」——孤立性是拓扑对密度的回应。

## 六、ACF 的型=素理想（Ex 4.1.14 / Prop 4.1.16-4.1.18）

ACF 的 n-型由**素理想**决定：p↦I_p={f∈k[X] : f(v)=0∈p} 是
S_n^M(k) 到 Spec(k[X₁..Xₙ]) 的**连续双射**（不是同胚——Stone
拓扑更细）。机制与 35 章同源：QE 把型压缩到多项式方程的布尔
组合，而「素」来自 K⊨∀v(fg=0→f=0∨g=0)。三个后果：

- **Zariski 拓扑紧**（Cor 4.1.17）：连续像 of 紧空间——
  Stone 空间的拓扑第一次反哺代数（Spec 的紧性）；
- **型计数**（Cor 4.1.18）：|S_n(k)|=|k|+ℵ₀（Hilbert 基定理：
  理想有限生成，素理想只有 |k|+ℵ₀ 个）——**ACF 是 ω-稳定的
  第一个现场**（42 章的定义就此落地）；
- 型的几何意义：n-型=簇的「泛点」——V(I_p) 是 p 的闭包轨迹，
  型空间是簇的空间的(pro-)几何细化。

## 坑位速记（本章实测）

- **朴素去重是指数炸弹**：`dedupProf` 若写成 `if existsb …
  (dedupProf t) then dedupProf t else pr :: dedupProf t`——
  每层两次递归、vm_compute 无共享，5⁴ 个 profile 直接爆炸
  （实测 >7 分钟不出结果）；**累加器版 0.02 秒**。
- **公式全集的平方账**：stone_laws 若在全宇宙（64 原子→
  8256 公式→68M 对）上跑，编译卡死；缩到 B=1 小宇宙
  （16 原子→544 公式→30 万对）秒过——**枚举件先算规模再
  开火**。
- **常数项会污染纯等词宇宙**：terms 里 TZ 0 无条件在场把
  Bell(n) 变 Bell(n+1)；「纯」语言需要独立的 `typeCountNC`。
- **截断宇宙的型数要手数**：B=8 截断下型数=10 而非 9——
  0..8 共 9 个被命名元素+1 个 ∞ 型（写期望值时数了两遍 8）。
- **`cutOf` 的边界**：v=a 处 a<v 为假——割位置在「v=a」处
  与「v 刚好超过 a」处相同（型不分贴壁方向；贴壁型的区分
  需要密度语言，见 §五的 p_c±）。
- **Lean 侧**：`Nat.iter` 不在 core（自备 `iterK`）；嵌套 ++
  需要 extra 括号（右结合歧义）；helper 定义必须在用点之前。

## 小结

本章把「元素的全部一阶性质」做成了三个对象：**语法对象**
（完全一致公式集）、**拓扑对象**（Stone 空间的点）、**机器
对象**（真值向量 profile）。三例定位法：纯等词（型=划分，
Bell 数）、(Z_m,S,0)（常量剁碎型空间、孤立见证）、(N,S,0)
（∞ 型——非孤立的活体）；DLO 的切割与 ACF 的素理想给出
无限侧的两张全景图。孤立型实现了必留、非孤立型可以被扔——
下一章（38 章）的省略型定理将把这句话变成一台 Henkin 机器，
并用它造出素模型与 PA 的保守端扩张。
