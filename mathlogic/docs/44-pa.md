上一章我们**用**归纳法；这一章把镜头转向归纳法赖以成立的**结构本身**。
Jongsma 的安排有三步：先讲递推关系的闭式求解（归纳的对象从「命题」变成
「序列」），再讲结构归纳（归纳的对象从数变成串和公式），最后把自然数本身
公理化成 Peano 算术——「数」从背景走到了前台。机器化沿同一条路走，但每一步
都会多出一个视角：递推闭式要变成可判定的定义，结构归纳要变成 `induction`
对归纳定义的直接作用，而 Peano 公理中最有趣的两条会在归纳类型里**消失**——
变成免费的定理。

## 一、递推关系的闭式：三招与机器的分工

书 §3.3.1 给出求解递推式的三招，全部是「先发现、后验证」的结构：

- **展开找规律**：写出前几项（4, 6, 10, 16, 24），肉眼猜闭式；
- **裂项望远镜**（例 3.3.1）：a₀=4、aₖ=aₖ₋₁+2k。把 aₖ−aₖ₋₁=2k 逐项写下再
  全部相加，中间项对消，剩 aₙ−a₀=2(1+⋯+n)=n(n+1)，闭式 aₙ=n²+n+4；
- **回代**（例 3.3.2）：a₀=1、aₖ=2aₖ₋₁+3。从 aₙ 逐层代入到 a₀，得
  aₙ=2ⁿa₀+3(1+2+⋯+2ⁿ⁻¹)=2ⁿ⁺²−3；
- **特征方程**（例 3.3.3）：二阶齐次递推 Fₙ₊₂=Fₙ+Fₙ₊₁ 设 Fₙ=rⁿ 代入得
  r²−r−1=0，两根线性组合定系数，得出含黄金比 φ=(1+√5)/2 的 Binet 公式。

前三招的「发现」部分机器做不了（也没有必要做），但「验证」是归纳法的
标准功课。两个闭式在机器里各是一行归纳（Coq 版）：

```coq
Fixpoint aseq (n : nat) : nat :=
  match n with
  | 0 => 4
  | S k => aseq k + 2 * S k
  end.

Lemma aseq_closed : forall n, aseq n = n * n + n + 4.
```

```coq
Lemma bseq_closed : forall n, bseq n + 3 = pow2b (n + 2).
Proof.
  induction n as [|k IH].
  - reflexivity.
  - simpl bseq.
    replace (S k + 2) with (S (k + 2)) by lia.
    simpl pow2b.
    lia.
Qed.
```

`bseq` 的归纳步值得看一眼：两边同乘 2 的关键变形被 `lia` 在原子层面完成
（`bseq k` 与 `pow2b (k+2)` 是两个不透明原子，归纳假设给出它们的线性关系，
2·bₖ+6=2·2^(k+2) 即闭式）。Binet 公式留在文档层——nat 上没有 √5，第 43 章
的 `no_sqrt2` 恰好从反面证明这一点。

Fibonacci 的**部分和**恒等式（练习 3.3.6b：裂项法对 Fibonacci 递推的产物）
是递推节的收官件：

```lean
theorem sumfib_shift : ∀ n, sumfib n + 1 = fib (n + 2) := by
  intro n
  induction n with
  | zero => rfl
  | succ k ih =>
    rw [fib_step2] at ih
    show sumfib k + fib (k+1) + 1 = fib (k+1+2)
    rw [fib_step2, fib_step2]
    omega
```

又是那个 +1 技巧：书写 ΣFᵢ=Fₙ₊₂−1，nat 上改写成 `sumfib n + 1 = fib (n+2)`。
证明里先把归纳假设用 `fib_step2` 展开，让等式两边的原子（`sumfib k`、
`fib (k+1)`、`fib k`）线性对齐，`omega` 收尾。

## 二、结构归纳：串与公式

书 §3.3.2 的纲领：凡是**递归定义**的结构，就有配套的归纳证明原理——
按结构的生成方式归纳。书用字母表上的串（空串 ε 为基、右端添字符为递推步），
机器里最贴近的对应物是列表：`[]` 是 ε，`x :: t` 是添字符。

结构归纳的三件套证明全部是「按列表结构归纳」的标准动作。长度对拼接的
同态律（书 Prop 3.3.1：ℓ(s•t)=ℓ(s)+ℓ(t)）：

```coq
Theorem app_len : forall s t : list nat,
  length (s ++ t) = length s + length t.
Proof.
  induction s as [|x s IH]; intros t; simpl.
  - rewrite app_nil_r. reflexivity.
  - rewrite IH. reflexivity.
Qed.
```

（基例里 Coq 的 `simpl` 把 `length []` 消成 0，但 `rev t ++ []` 的 `app_nil_r`
要手工调用——见坑位。）反转与拼接的交换律是结构归纳的招牌：

```lean
theorem rev_app_distr : ∀ (s t : List Nat), rev (s ++ t) = rev t ++ rev s := by
  intro s t
  induction s with
  | nil => simp [rev]
  | cons x s ih =>
    show rev (s ++ t) ++ [x] = rev t ++ (rev s ++ [x])
    rw [ih]
    exact List.append_assoc (rev t) (rev s) [x]
```

注意 `show` 的用法：先把 `(x::s) ++ t` 与 `rev (x :: (s++t))` 按定义改写，
归纳假设才能接上；最后一步是拼接的结合律。反转的对合性 `rev (rev s) = s`
（结构归纳双杀的第二件）在两个文件里都用 `rev_app_distr` 一步装配。

**wff（合式公式）**是书 §3.3.3 的主角：命题逻辑的公式本身是递归定义的结构。
机器版公式抽象成四构造子的归纳类型（变元/否定/合取/蕴涵），书里每个复合式
带一对括号的约定，化成了两个计数函数的相等：

```lean
def lp : Wf → Nat
  | var _ => 0
  | neg g => lp g + 1
  | conj g h => lp g + lp h + 1
  | imp g h => lp g + lp h + 1

theorem lp_cn : ∀ f : Wf, lp f = cn f := by
  intro f
  induction f with
  | var i => rfl
  | neg g ih => simp only [lp, cn]; omega
  | conj g h ihg ihh => simp only [lp, cn]; omega
  | imp g h ihg ihh => simp only [lp, cn]; omega
```

这正是书例 3.3.6（每个 wff 左括号数=连接词数）：基例零对零，复合一次
「括号+1、连接词+1」，归纳步是两行 `omega`。更重要的是书的**唯一分解定理**
（Thm 3.3.2：wff 的构造方式唯一——证明靠「wff 的真前缀括号不配平」这条
引理，纯字符串论证，整整一页）。在类型论里它不需要证明：

```coq
Theorem conj_inj : forall a b c d : wff,
  Conj a b = Conj c d -> a = c /\ b = d.
Proof.
  intros a b c d H. injection H. auto.
Qed.

Theorem neg_conj_disj : forall a c d : wff, Neg a <> Conj c d.
Proof.
  intros a c d H. discriminate H.
Qed.
```

构造子**单射**（injection）与**互斥**（discriminate）是归纳类型的内置事实：
`Conj a b` 只能由 `Conj` 构造、且由唯一的 a 和 b 构造——字符串层面的唯一
可读性论证，在归纳类型层面是免费的。这是本章第一个「表述方式的迁移让定理
消失」的现场，第二个马上来。

## 三、Peano 算术：公理化自然数

书 §3.4 的历史线：Dedekind（1888，集合论路线）与 Peano（1889，公理路线）。
五条 Peano 公设里，FOL 的约定吃掉两条（0 是自然数、后继唯一——函数符号
自带），剩三条正式公理：

| # | 公理 | FOL 形式 |
|---|---|---|
| 1 | 0 不是任何数的后继 | ∀n(Sn ≠ 0) |
| 2 | 后继的前驱唯一（S 单射） | ∀m∀n(Sm=Sn → m=n) |
| 3 | 数学归纳公理 | P(0) ∧ ∀k(P(k)→P(Sk)) → ∀nP(n) |

**关键观察**：前两条在类型论里是归纳类型的免费礼物。自造后继结构 `Sn`
（Coq 文件里叫 `sn`：构造子 `z` 与 `s`）后：

```coq
Theorem s_nonzero : forall n, s n <> z.
Proof.
  intros n H. discriminate H.
Qed.

Theorem s_inj : forall m n, s m = s n -> m = n.
Proof.
  intros m n H. injection H. auto.
Qed.
```

在 PA 里它们必须作为公理假设（因为模型可以耍赖）；在归纳类型里「构造子
互斥、单射」是定义的一部分。**公理与定义的边界会随表述方式移动**——这是
本章的核心一课。

第三条（归纳公理）的对应物更深刻：PA 里它是**公理模式**——每个公式 P 一条
实例，无穷多条公理；类型论里它是**消去子**（eliminator）——一条规则覆盖
所有谓词。`induction n` 这一行命令，就是归纳公理全部无穷实例的合一化身。
书 §3.4.4 的论证（PMI 证明技术由归纳公理+CP+UG+MP 合法化）在机器面就是
「`induction` 战术调用消去子」这一个动作。

### 加法：从定义方程到交换律

加法按书 Def 3.4.1 定义（对第二参递归），两条定义方程**就是**计算规则：

```coq
Fixpoint sadd (a b : sn) : sn :=
  match b with
  | z => a
  | s k => s (sadd a k)
  end.
```

`sadd m z = m` 与 `sadd m (s k) = s (sadd m k)` 都是 `reflexivity` 级别的
事实。接下来按书的顺序把算术律一座座立起来（全部零公理）：

- **0 单位元**（书 Prop 3.4.2）：右单位是定义方程；左单位 `sadd z n = n`
  对 n 归纳；
- **1 交换**（书 Prop 3.4.3）：`sadd (s z) n = sadd n (s z)`，为一般交换律
  铺路；
- **结合律**（书 Prop 3.4.4）；
- **交换律**（书练习 3.4.11）：需要后缀左移引理 `sadd (s k) m = s (sadd k m)`——
  书里练习 11b 特别问「你能不用结合律先证交换律吗」，机器答案：能，
  但你会想要它；

```coq
Theorem sadd_comm : forall m n, sadd m n = sadd n m.
Proof.
  induction n as [|k IH]; simpl.
  - rewrite sadd_0_l. reflexivity.
  - rewrite IH. rewrite sadd_succ_l. reflexivity.
Qed.
```

- **消去律**（练习 3.4.12）：右消去 `l+n = m+n → l = m` 对 n 归纳+`s_inj`；
  左消去由交换律导出。

注意这一节**完全没有算术自动化**：`sadd` 项对 lia/omega 不透明，所有
重排都要显式调用 assoc/comm/swap 引理。`(a+b)+(c+d)=(a+c)+(b+d)` 的挪移
（分配律证明的关键步）单独做成 `sadd_shuffle`。这恰好复现了书里那句警告：
「发展算术的演绎证明对高年级学生反而难，因为他们知道太多」——机器也一样，
`lia` 的算术常识在这里一概失效，只能老老实实按公理走。

### 乘法与 ≤

乘法按书 Def 3.4.4 定义（`m·0=0`、`m·(k+1)=m·k+m`），然后是链式装配：
分配律（练习 16b，用 shuffle 一步收）→ 1 单位元 → 后缀左移 → 交换律
（练习 18）。序关系按书练习 3.4.20 的定义：

```lean
def sle (m n : Sn) : Prop := ∃ d, sadd m d = n
```

`≤` 不再是内置符号，而是「差一个 d」的存在命题。四条性质各是一次小演练：
自反（d=0 是定义方程）、传递（d 复合用结合律）、反对称（练习 25：两次
`≤` 得 `m+d₁+d₂=m+0`，左消去后 `d₁+d₂=0`，分解出 `d₁=0`）、完全性
（练习 26：双重归纳，`d` 是 0 还是后继分叉）：

```coq
Theorem sle_total : forall m n, sle m n \/ sle n m.
Proof.
  induction n as [|k IH].
  - right. exists m. apply sadd_0_l.
  - destruct IH as [Hmk | Hkm].
    + left. destruct Hmk as [d Hd]. exists (s d).
      simpl. rewrite Hd. reflexivity.
    + destruct Hkm as [d Hd].
      destruct d as [|d'].
      * left. exists (s z).
        simpl in Hd. simpl.
        rewrite Hd. reflexivity.
      * right. simpl in Hd.
        exists d'. rewrite sadd_succ_l. exact Hd.
Qed.
```

（`Sn` 上的证明全是这种形状：分情况、单射、定义方程，没有一个算术战术。）
到这一步，「PA 能发展出全部计算算术」这句话就有了机器形态的证词：交换、
结合、分配、消去、序律，全部从 `z`/`s` 两个构造子和三条定义出发。

## 四、元理论余响

三个不进机器但值得记住的点：

1. **前两条公理管不住模型**（书练习 3.4.32）：只有公理 1、2 时，「双链」
   ℕ+ℤ（ℤ 段上后继循环绕回）、「非标准起点」等模型都合法——归纳公理才是
   把宇宙钉死在 {0, S0, SS0, …} 上的那颗钉子。这正是书 §3.4.4 说「归纳公理
   不能当成定理来证」的模型论根据。
2. **良序 ⟺ 归纳公理**（练习 3.4.34）：第 43 章已经用强归纳证出良序（可判定
   版零公理）；反过来良序也能推出归纳公理——两者在 PA 内等价。
3. **PA 与 Gödel**：PA 是第 22 章不完备定理的标准对象。本章机器化的一切
   （加法交换律、≤ 反对称……）都是 PA 定理，而 PA 里存在既不可证也非可否证
   的命题——归纳公理模式再强，也封不死哥德尔缝隙。Jongsma 在 §5.3 会从
   集合论方向回到这里，我们在第 47 章接上。

## 坑位速记（本章实测）

- **Coq：`induction` 自动引入前导量词**。目标 `∀ m n, P m n` 上 `induction n`
  会先把 m 引入上下文再对 n 归纳——随后 `intros m` 撞名（"m is already used"）；
  且 IH 被**特化**到这个 m（不再是 ∀m）。若归纳步需要换 m（如一般的换元
  论证），先 `intros m n; revert m` 再归纳。
- **Coq：`simpl` 会顺带展开无关定义**。`simpl sumfib` 想只展开 sumfib，
  但 `fib (S k)` 被一并展开成 match 项，后续 rewrite/lia 全瞎。处方：
  `cbn [sumfib]` 白名单限定展开对象。
- **Coq：`rewrite sadd_comm` 无参数会振荡**。它改写第一个匹配，第二个
  `rewrite sadd_comm` 又把它改回去（交换律是对称的）。必须写
  `rewrite (sadd_comm l n), (sadd_comm m n)` 指定实例。
- **Coq：`rw`/`rewrite` 结尾的自动 rfl 只用可约透明度**，定义展开层面的
  定义等价（如 `sadd m z ≡ m`）收不掉，要补显式 `reflexivity`/`rfl`。
  Lean 同坑（`rw` 后 `exact` 前常需一行裸 `rfl`）。
- **Coq：`replace A with B` 在目标无 A 时仍生成副目标**，报错位置在
  `by lia` 处而非 replace 处——先看 replace 是否真的找到出现。
- **Lean：match 分支里裸写 ⟨…⟩ 不是 tactic**——匿名构造子要 `exact ⟨…⟩`；
  方程上的分情况用 `cases m with` 而不是把方程塞进 match 模式。
- **Lean：`fun m => ⟨ze, rfl⟩` 的绑定变量会被 linter 判 unused**（warning
  即失败）：改成 `by intro m; exact ⟨ze, rfl⟩`。
- **Lean：`rw [hd]` 方向**——`hd : sadd k ze = m` 要把目标里的 m 换掉时用
  `rw [← hd]`；方向反了报「Did not find occurrence」。
- **两通道：自定义结构对算术自动化全盲**。`sadd`/`smul` 项不是 nat 算术，
  lia/omega 一概无能为力——这正是「公理化发展」的手感；挪移类等式提前做
  swap/shuffle 引理。

## 小结

三件事在这一章合流：递推闭式（发现靠人、验证靠机器）、结构归纳（列表与
公式——唯一分解定理免费化）、Peano 算术（两条公理变定理、归纳公理变
消去子、算术律全链零公理）。「数」第一次成为被审视的对象而不是默认工具。
下一章继续在算术里深耕：整除、gcd、Euclid 算法、素数——PA 的乘法结构
开足马力。
