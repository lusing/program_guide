# 20 Herbrand 与 SLD：T_P 算子与 Horn 语义

> 对书：Ben-Ari 3e Ch9/Ch11 / EFT XI / H&R Prolog 附录（§2.7 微模型旁注）
> 通道：C/L（TP 单调+头原子三件，零公理）

26 章的归结是**规则**，本章给它的完备性**兜底**：Herbrand
定理把一阶可满足性归约到纯语法的 Herbrand 宇宙，而 Horn
片段（09 章的老朋友）在这个宇宙上有特别干净的语义——逻辑
程序的最小模型。两条线合起来正好是 Prolog 的理论基础：
「程序=理论，求解=推理」的宣言在这里变成定理。

## Herbrand 宇宙：语法自己当论域

26 章归结有个悬而未决的问题：消互补文字前要合一，**代换的
材料从哪来**？Herbrand 的回答：不需要任何外部论域——**用
公式自己的项造论域**就够了。

给定符号集 F（无常数时补一个哑常量）：

- **Herbrand 宇宙** H(F) = F 上全部**基项**（ground terms，
  无变量的项）：常量、以及函数符号作用于已有基项——
  f(a)、g(f(a))、……；
- **Herbrand 基** = 全部基原子 P(t₁,…,tₙ)（tᵢ ∈ H）。

**Herbrand 模型**：论域就是 H，函数符号解释为「语法构造」
（f^M(t) := f(t)——项造项），谓词随意。于是「模型」坍缩成
「基原子的选集」——**一个真值指派**。一阶可满足性在此
归约为命题可满足性（基原子当命题变元）——09 章的手感
全部复用。

**Herbrand 定理**（归结完备性的基石）：子句集 S 不可满足
⟺ S 的全部基实例的某个有穷子集不可满足。两个方向各有一句
直觉：「⟸」平凡（Herbrand 模型是模型）；「⟹」是内容——
不可满足性若成立，必有**有穷证据**（有穷多个基实例已经
矛盾）——归结的搜索因此是半可判定的（33 章：能停的都会停，
只是失效时可能永远跑下去）。

## 从归结到逻辑程序：Horn 世界的语义

09 章认识了 Horn 子句（每子句至多一个正文字）。把它改写成
「规则形」：

```text
a :- b₁, b₂, …, bₖ.     （读：body 全真则头真；k=0 为事实）
```

Horn 程序 P = 规则与事实的集合——这就是 Prolog 程序的
全部语法。机器件（`examples/20_herbrand/`）：

```text
hclause := hfact a | hrule a body
TP P I a = ∃c ∈ P: (c = hfact b ∧ b = a)
                    ∨ (c = hrule b body ∧ b = a ∧ body 全真于 I)
```

**T_P 算子**的直觉：**一次应用规则能直接推出什么**——事实头
直接真；规则头在 body 全真时真。I 是「已知的真原子集」，
T_P I 是「在 I 之上再推一步的收获」。

## 旗舰三条（零公理）

```
TP_mono     I ⊆ J ⟹ T_P I ⊆ T_P J      算子单调（Knaster-Tarski 前提）
fact_head   hfact a ∈ P ⟹ T_P P ⊥ a       事实头
rule_head   hrule a body ∈ P ∧ body 全真 ⟹ T_P P I a   规则头
```

`TP_mono` 的证明走 `existsb_exists` 的 witness 提取 +
`forallb_forall` 的双向（单调假设正向用于 body 元素）；
`rule_head` 是 SLD 的「规则头」构件——`fact_head` 是其
body=[] 的特例化。

## 最小不动点：T_P 的语义身份

T_P 从空集出发迭代：

```text
I₀ = ⊥,   I₁ = T_P ⊥,   I₂ = T_P (T_P ⊥), …   单调升链
lfp(T_P) = ⋃ₙ T_Pⁿ(⊥)
```

**Knaster-Tarski 定理**：单调算子在完全格上有最小/最大
不动点——T_P 单调（旗舰一）所以 lfp 存在。它的语义身份：
**lfp(T_P) 恰是程序 P 的最小 Herbrand 模型**——「刚好把
程序能推出的原子收进来，一个不多」。

「一个不多」（最小性）的论证方向：任何 Herbrand 模型 M 都
满足 T_P M ⊆ M（模型对规则封闭——body 真则头真）；归纳
可证 T_Pⁿ(⊥) ⊆ M 对一切 n（⊥ 最小起步）——所以 lfp ⊆ M。
「一个不少」（是模型）：T_P 的连续性（每条规则的推导只
用有穷信息）保证 lfp 是不动点 T_P(lfp) = lfp。**09 章
Horn 标记集=最小模型的现场在此升格为定理**——那章的
「标记即必真」不变量就是本处最小性论证的算法版本。

完整反向（连续性）的机器化属定点理论教程范围——本章交付
单调性（正向半边）+ 头原子（构件），**边界如实登记**。

## T_P 迭代走查：一个三代程序

把 lfp 的升链在具体程序上走一遍（纸面版，机器件同构）：

```text
程序 P：
  edge(a, b).  edge(b, c).              （事实×2）
  path(X, Y) :- edge(X, Y).             （规则 R1）
  path(X, Z) :- edge(X, Y), path(Y, Z). （规则 R2，传递闭包）
```

Herbrand 宇宙 H = {a, b, c}（无常量函数，基项=常量）。迭代：

| n | T_Pⁿ(⊥) | 新收入 |
|---|---|---|
| 0 | {} | — |
| 1 | {edge(a,b), edge(b,c)} | 事实直入（R1 的 body 是 edge——不真，R2 同） |
| 2 | 上 + {path(a,b), path(b,c)} | R1 触发（edge 已真） |
| 3 | 上 + {path(a,c)} | R2 触发（edge(a,b) ∧ path(b,c)） |
| 4 | 同 3 | 无新——**不动点** |

lfp = 三条 path + 两条 edge——正是「图的传递闭包」。这个
例子同时是 33 章的伏笔：**传递闭包一阶不可表达**（无辅助
谓词时写不出 path 的定义），但**逻辑程序用两条规则+lfp 就
表达了**——程序=「最小不动点规格」，执行=不动点迭代/其
逆搜索。数据日志（Datalog）与数据库递归查询的理论内核
就是这台机器。

## SLD 归结：自顶向下的 Prolog

T_P 的迭代是 **bottom-up**（从事实向上推到结论）；Prolog
的执行是 **top-down**（从目标向下找规则）：

```text
?- a  ←  找 hrule a body，递归证明 body 中的每个原子
```

`rule_head` 的方向恰好是 SLD 的求解方向。两端在最小不动点
会合——**Prolog 的完全性定理**：目标 ?- a 在 SLD 树里有
成功分支 ⟺ a ∈ lfp(T_P)。选择点（规则次序、body 内目标
次序）只影响搜索路径，不影响「能否推出」——深度优先的
Prolog 会迷路（无穷分支），但 SLD 树（全分支搜索）不会。

Prolog 教程（仓库内）的 SLD 解释器与此处的 T_P 构件构成
同一理论的两个视角：那边「算」，这边「证」。Herbrand 宇宙
把两者焊在一起——执行轨迹=不动点迭代的逆序展开。

## Knaster-Tarski：不动点的格论户口

T_P 的类型是「原子集→原子集」——幂集格 (𝒫(B), ⊆) 上的自
映射。**Knaster-Tarski 定理**（1927/1955）：完全格上的单调
映射必有最小不动点，且

```text
lfp(f) = ⋂ { x : f(x) ⊆ x }     （全部前封闭点的交）
```

「前封闭」（f(x) ⊆ x）=「对 f 的推理封闭」=候选模型；最小
者=交集——**最小模型的语义身份由格论白送**。对照构造式
定义（⋃fⁿ(⊥) 的升链）：两者相等需要 f **连续**（保定向并，
Scott 语义的地基）——每步推导只消费有穷信息。本章的 T_P
显然连续（规则 body 有穷），教学版机器化单调半边、连续性
登记。这套格论在 35 章（CTL 的最大/最小不动点刻画）与 42 章（μ 演算）将以「有限格」形态三度登场——本章是它第一次
以「无穷格」原形出场。

## 从 T_P 到 SLD：操作语义的钥匙（Ben-Ari ch11 桥）

本章的 T_P 最小不动点回答「**什么**是真的」；Prolog 运行时
回答的「**怎么**求出来」由 SLD 消解承担——两者由**计算规则
独立性**与**搜索规则语义**连接：30 章机器化了「最左/最右选元
解出同一答案集」的实例，并清点了 cut/NAF/CWA 三次工程偏离
的账本。理论要点在这里说透：SLD 的正确答案代换恰是 T_P
不动点中的原子在 Herbrand 模型里的真值（逻辑编程自己的
完备性定理——Ben-Ari §11.2 的定理族）；Prolog 的 DFS 策略
会掉进无穷支（45 章泥孩子的「沉默是信息」与 41 章 Büchi
的「无穷多次」在这里遥相呼应——无穷行为的有限判据是时态
与逻辑编程共享的深层结构）。
## 本章小结

- Herbrand 宇宙=语法自己的论域；Herbrand 模型=基原子选集
  ——一阶可满足性坍缩为命题可满足性。
- Herbrand 定理：不可满足⟹有穷基实例矛盾——归结完备性
  与半可判定性的共同根源。
- T_P 单调 ⟹ Knaster-Tarski 最小不动点 = 最小 Herbrand
  模型；「一个不多不少」双方向，本章机器化单调半边。
- SLD（top-down）与 T_P（bottom-up）在 lfp 会合——Prolog
  完全性定理；选择点只影响路径。
- 09 章标记算法与本章算子互为算法/语义两版；T_P 走查例
  （传递闭包）预告 33 章「一阶不可表达、程序可表达」的分界。

## 坑位速记（本章实测）

- **Coq/Rocq**：`rule_head` 的全参应用须带程序表（`apply
  (rule_head P a body I)` 程序表漏写报 unify 失败）；
  `In (hrule 1 [0]) P` 的展开是 `hfact 0 = hrule … ∨ In …`
  ——right 后仍要 left（**双分支**）；forallb 单元素表
  `[x]` 化简后 `I x && true`——reflexivity 直收
  （Nat.eqb_refl 重写多余）。
- **Lean**：`cases c with | hrule b body` 的依赖消除在
  `b == a` 的 match 上失败——先 `rw [Bool.and_eq_true]
  at hval ⊢` 拆合取再处理；`refine ruleHead _ _ _ _` 的
  四下划线推断不出（refine 不 apply）——命名参数
  `(P := …) (a := …)` 全显式。
