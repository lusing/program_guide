# 40 SLD 与逻辑编程语义

> 对书：Ben-Ari 3e ch11（SLD/计算规则/Prolog）+ 2e §8.3（cut/NAF）与 §8.5（CLP）精选
> 通道：C/L——最小合一+SLD+双计算规则+实例级独立性；P——cut/NAF/CWA/CLP 现场三连

27 章给逻辑编程立了语义地基（T_P 最小不动点 = 最小 Herbrand 模型），
但没回答「程序怎么跑」。本章补上操作语义：**SLD 消解**——从 26 章
的归结特化到 Horn 子句，就是 Prolog 的求值器。然后清点 Prolog 对
纯逻辑的三次工程偏离（cut、NAF、CWA），每一次都在「可执行性」与
「声明语义」之间做交易——账本要逐笔记清。

## SLD：归结的 Horn 特化

Horn 子句 `H :- B1, …, Bn` 与目标 `:- A1, …, Am` 的归结一次只做
一件事：**选一个目标原子 Aᵢ，与某子句头 H 合一**，Aᵢ 被子句体
替换、合一子作用到全目标。两个自由度由此分家（Ben-Ari 3e §11.3）：

- **计算规则**：选**哪个原子**（位置）；
- **搜索规则**：选**哪个子句**（顺序）。

机器件的最小实现（`ex30_sldprolog.v`，两通道同构）：

```coq
Definition resolve (c : clause) (g : goal) (i : nat) (k : nat)
  : option (goal * sub) :=
  let (h, body) := coff k c in          (* 子句变元按偏移 k 换新鲜 *)
  match nth_error g i with
  | Some sel =>
      match unifyA sel h with
      | Some s => Some (gsub s (body ++ remove_first i g), s)
      | None => None
      end
  | None => None
  end.
```

三个工程细节各有一课。**子句变元换新鲜**（`coff k`，偏移随归结
深度递增）：同一子句在递归里反复使用，不换名就会把上一轮的绑定
错当本轮的——26 章 occurs check 之外的另一条合一纪律。**答案沿链
累积**（`s ++ acc`）：SLD 树每步的合一子必须组合进运行代换，空
目标时的 acc 才是答案——丢掉这一步，「成功」就查无实据（本章实测
的 None×4 现场）。**换名链追踪**（`chaseX`）：x₀ ↦ x₁₀ ↦ dave 的
间接绑定要追到底才是可读的答案。

## 独立性：计算规则不改变答案集（3e 定理 11.x）

> fair 计算规则下，存在 SLD 反驳这件事**不依赖**选哪个原子。

直觉：目标里的原子早晚都要被消解（fairness = 不饿死任何原子），
选谁先谁后只是改变推导的形状，不改变可解性。机器件把定理做成
实例级现场——祖先族谱（2e 例 8.19 的数据），同一程序同一目标：

```coq
Example indep_left_answers :
  answersX (sldAll 30 leftmost progA 10 goalG [])
  = [Some 103; Some 106; Some 102].      (* dave, ellen, fred *)
Example indep_right_answers :
  answersX (sldAll 30 rightmost progA 10 goalG [])
  = [Some 103; Some 106; Some 102].
Example indep_sld : setEqA … = true.     (* 集合相等 *)
```

**搜索规则则不然**：DFS 按子句序深入，左边有无穷支时右边的解
永远排不上队（Prolog 掉进非终止支的经典死法）——3e 同一节的原话
对照。计算规则自由、搜索规则不自由，这条不对称是 Prolog 程序员
排clause 顺序的全部理论依据。

一般性定理（任意 fair 规则的独立性证明，对 SLD 树结构归纳）登记
为边界——实例级机器化 + 语义论证已在文档走查。

## Prolog 的三次偏离（`ex30_sldprolog.pl` 现场三连）

纯逻辑程序 = 最小 Herbrand 模型的声明语义。Prolog 为了工程效率
偏离它三次，每次的代价与收益：

**cut（!）**：砍掉 SLD 树的兄弟分支，禁止回溯。运行输出：

```text
member all solutions : [4,1,4,2]
green cut first-only : [4]  (same existence answer)
red cut solutions    : [1]  (2,4 lost: semantics changed)
```

**green cut** 只砍重复解（对存在性查询答案不变——「在表里吗」
的语义保住了，只是不再枚举）；**red cut** 把过程性条件（X<3）混进
砍枝决策，2 与 4 被砍掉——**声明语义变了**。Ben-Ari 的忠告：
green cut 勉强可用（要能证明「砍掉的确实冗余」），red cut 是
纯过程性动物，声明式读法彻底失效。

**NAF（\+）与 CWA**：「有限失败即否定」。john 不在 likes 表里
⟹ `\+ likes(john, food)` 成功。但这是**封闭世界假设**——把
「不知道」当「假」。对照经典否定：显式否定事实表（`not_likes/2`，
零子句）一无所知——**开放世界**里未知既不真也不假。运行输出
的双行对照就是两个世界的分界线。语义地洞：NAF 否定的是
「可解性」不是「假」——`\+ likes(P, food)` 带**自由变元** P 时
是存在式的否定（有任一解即整体失败），与一阶 ¬∀ 混淆是 Prolog
第一大坑（改用定人查询的现场版就是为此）。

**CLP（约束逻辑编程，2e §8.5）**：把「生成-测试」倒过来——
约束传播先于标签生成：

```text
CLP x^2+y^2=25, x<y  : [[3,4]]  (3,4 only)
```

`X in 1..9, X*X+Y*Y #= 25` 不枚举 81 个组合——传播 X≤5、剪枝，
标签阶段只剩个位数候选。这是 09 章 DPLL「传播先于分裂」的亲戚：
两者都是把搜索的力气花在约束推理上（CLP(H) 框架把 Herbrand 域
换成约束域，27 章 T_P 定点语义换到约束格上照常成立——文档级）。

## 三通道分工

Coq/Lean 做算法层的可靠部分（合一、归结、独立性）；Prolog 做
工程偏离的活体展示（cut/NAF/CLP 只有真引擎才能演出症状）。
`cross/0` 为 gprolog 留了无 clpfd 的抽查入口。

## SLD 树的形状学

把搜索规则的选择画成一棵树——节点是目标、分支是子句选择
——**SLD 树**的形状决定 Prolog 的命运：**有限树**（所有分支
终結于成功或失败）→ 一切答案有限枚举；**有成功支的无穷树**
→ DFS 若先掉进无穷支则丢解（非完备）；**纯无穷失败树** →
发散但语义上「无解」（有限失败才报 no）。三个经典病理：
左递归 `p :- p, q` 让 DFS 空转；`member(X,[1,2,3])` 的
无穷答案流（表尾开放变元）让 top-level 无限打印；cut 放在
错误位置把无穷树剪成「恰好漏掉真解」的有限树——三者都
只能靠**看树**诊断，这也是为什么 Ben-Ari 坚持先教树再教
语言。与 39 章 lasso 的呼应：SLD 树的「无穷支」与 LTL 的
「无穷路径」同构——有限系统上的无穷行为都要有限判据
（SLD 的答案完备性条件≈公平性条件）。
## 从 Horn 到 Prolog 语言的工程距离

30 章的语义件（SLD+合一）到真正的 Prolog 还有一层「语言
糖与编译」：**第一变元索引**（首参相同的子句才进入搜索——
谓词的参数序决定性能）；**尾调用优化**（最后一递归位置复用
栈帧—— Accumulator 惯例的由来：`rev/2` 朴素版 O(n²)、
acc 版 O(n) 的差距全在尾位置）；**截断编译**（cut 编译成
跳转——green cut 免费的效率红利）；**统一假接口**（freeze/
when 的延迟统一——把逻辑变量变成并发原语的通道）。这些
工程层不改变语义账本（除 cut/NAF 已清账的三偏离），但
决定「同一逻辑程序跑出十倍差距」的现实——Ben-Ari 2e 的
Prolog 节正是按这个顺序展开的。本教程的取舍：语义件全
机器化（本章），工程件以 SWI 实测点睛（CLP 现场即一例）。
## 声明式与过程式的张力总账

逻辑编程的原始承诺是「程序=理论、执行=演绎」——但本章的
三偏离账本显示完整故事：cut 让程序只能过程式读、NAF 把
未知当假、CWA 把开放世界焊死——每一步都离经典语义远一点、
离可执行性近一点。反过来，本章机器件证明的独立性定理
又显示纯语义的部分**确实**实现稳定（换选元答案集不变）。
张力的现代调解人是**答案集编程**（ASP）与**mercury/datalog**
一系：ASP 把 NAF 升格为稳定模型语义（非单调逻辑的严格化——
「不知道」与「假」重新分家）、datalog 砍掉函数符号换终止
保证。读 Ben-Ari ch11 与 H&R §2.3（Horn 的模型论）后再
看这两个后裔，能看到逻辑编程五十年演化的完整弧线——
起点正是本章的 SLD 树。
## 本章小结

- SLD = 归结的 Horn 特化；计算规则（选原子）与搜索规则（选
  子句）分家；fairness 下前者不改变答案集（独立性），后者
  决定次序与完备性。
- 机器件三纪律：子句变元换新鲜、答案沿链累积、换名链追踪。
- Prolog 三偏离的账本：green cut 保语义砍冗余、red cut 改
  语义；NAF = 有限失败 = CWA 的「未知即假」，与经典否定隔
  一个开放世界；CLP 把传播提到生成前。
- 三通道分工：算法层可靠件在 C/L，工程偏离的活体在 P。

## 坑位速记（本章实测）

- **Coq/Rocq**：
  - **子句头写错成野变元**：第二个子句的头误用 `(2,[VV0;VV2])`
    （Y 位占了 x2）——body 里的 x1 成无头之蛙，答案集全部
    错位（fred 消失、出现幽灵绑定）。Horn 子句的「体变元 ⊆
    头变元」要用眼睛盯；
  - **答案不累积 = None×4**：sldAll 只返回步内合一子、不组
    合运行代换——空目标时两手空空；`s ++ acc`（新的在前，
    find 首中即最新绑定）是正确形状；
  - **chaseX 追链**：x₀↦x₁₀↦常量的间接绑定，答案提取必须
    沿链追（带 fuel 防环）；
  - `unifyL` 双表递归不能 `map` 后自调（猜不出递减参）——
    改累积式 `unifyL (s1 ++ s) r1 r2` 结构递归才过；
  - Compute 探针的**探针自身别造变量碰撞**：手工模拟中间
    状态时目标变元号撞上换新偏移，会看到假故障。
- **Lean**：
  - **`Sub` 是核心类名**（减法的 typeclass）——代换命名撞车
    全盘类型错；改 `Subst`；
  - `open Tm` 后裸 `c`/`n` 等与构造子同名的**模式绑定子**会被
    解析成构造子应用（Not enough arguments）——绑定子避开
    构造子名；
  - 递归调用里的 `_` fuel 占位推不出（don't know how to
    synthesize placeholder）——模式里给名字 `fr + 1`；
  - `| .c _ => ·` 的点号匿名函数在 match 臂右侧不受支持——
    老实写 `| .c n => .c n`。
- **Prolog**：
  - clpfd 要 `:- use_module(library(clpfd)).`（忘了在 `#</2`
    处报 Operator expected）；
  - 零子句谓词要 `:- dynamic not_likes/2.`，否则 findall 报
    Unknown procedure（unknown 的是**过程**不是失败）；
  - `\+` 带自由变元 = 存在式否定——NAF 演示一律用定人查询。
