一个完备理论 T 有多少个可数模型？记 I(T,ℵ₀)。上界 2^ℵ₀（可数
语言的可数结构至多连续统多个）；已知光谱：DLO 是 1、Ehrenfeucht
例是 3、ACF_p 是 ℵ₀、RCF 与 Th(N) 是 2^ℵ₀。两个自然问题：
**I(T,ℵ₀)=2 可能吗？**（Vaught：不可能——Thm 4.4.6）；
**ℵ₀<I(T,ℵ₀)<2^ℵ₀ 可能吗？**（Vaught 猜想：不可能——仍是
公开问题；Morley 的最好结果：>ℵ₁ ⟹ =2^ℵ₀）。本章的主定理
Ryll-Nardzewski 刻画 I(T,ℵ₀)=1 的那一端：**ℵ₀-范畴 ⟺ 型空间
逐层有限**——数模型变成数型。

## 一、Ryll-Nardzewski 定理：四条等价线

**定理**（Thm 4.4.1）。以下等价：

1. T 是 ℵ₀-范畴的（可数模型在同构意义下唯一）；
2. 每个 S_n(T) 里的型都孤立；
3. 对每个 n，|S_n(T)|<ℵ₀；
4. 对每个 n，存在有限公式表 φ₁..φ_m 使得任何公式 ψ 都
   T-等价于其中某一个。

证明的四步各有教益：

**(1)⟹(2)**：非孤立型 p 可被某可数模型省略（38 章省略型定理）、
又被另一可数模型实现（紧致性）——两个不同构的可数模型，
矛盾。**范畴性把「省略」与「实现」焊死在一起**。

**(2)⟹(3)**：孤立型两两分离（各自的孤立化公式互斥），而
S_n(T) 紧（37 章 Lemma 4.1.8）——开覆盖 {[φ_p]} 有有限子覆盖，
每片是单点，故有限。**紧性在这里第一次「反向使用」：有限
子覆盖的存在把无穷个孤立型压成有限个**。

**(3)⟹(4)**：有限型空间里给每个型挑分离公式 θᵢ，任何 ψ
等价于 ⋁_{ψ∈pᵢ}θᵢ——公式模 T-等价只有有限多个类。

**(4)⟹(1)**：任何可数模型都是原子的（每个元组被有限表的
真值模式孤立化），而原子可数模型=素模型（38 章）且唯一——
于是唯一可数模型。

**机器面对账**（`examples/40_countmodels/`，profile 计数器
复用 37 章方法论、章内自含）：

- **例一（`rn_pure_eq`）**：纯等词理论。|S_n|=Bell(n)：
  1、2、5、15——每个 n 有限 ✓。RN 说它 ℵ₀-范畴 ✓（任何
  可数无穷纯集同构——Bell 数是「有限的逐层性」的精确读数）。
- **例二（`rn_dlo`）**：DLO 无参数。原子 x_i<x_j 把 n-型
  分成**弱序**（预序）模式：|S_n|=有序 Bell 数 1、3、13 ✓
  ——逐层有限，ℵ₀-范畴（Cantor 定理的型空间重述）。
- **例三（`rn_N_infinite`）**：(N,S,0)。原子 x=c_j 把 0..5
  各自成型——8 元证据宇宙已数出 ≥6 个 1-型，且随宇宙增长
  无上限：|S₁|=ℵ₀，RN 反向适用——**非 ℵ₀-范畴**（紧致性
  造出的「非标准尾巴」模型是第二个可数模型的雏形）。

三个理论、三种计数行为（有界 Bell/有界弱序/无界），RN 定理
的「逐层有限」判据在机器上就是 `typeCount` 的输出。

## 二、推论：有界 acl 与两个代数否证

**Cor 4.4.2**：ℵ₀-范畴 ⟹ 存在 f:N→N 使 |A|≤n ⟹ |acl(A)|≤f(n)
——代数闭包一致有界。证明：n+1 元型有限个，「代数型」（某公式
限定 ≤N 个解）各自有 N 上限，取全部上限之和。

两个漂亮的否证：**无穷域的理论不 ℵ₀-范畴**（Cor 4.4.3）——
初等扩张里有超越元 t，acl(t)∋t,t²,t³,… 无穷，违反有界性。
**群的正反例**（Cor 4.4.4）：ℵ₀-范畴的无穷群局部有限且有界
指数；反过来，有界指数的无穷 Abel 群 ℵ₀-范畴——Ax 的特征
0/素数分类在这类结构上开花（(Z/p)^ω 型群的完全理论由「每个
阶恰好 p^k 的元素个数」的有限表决定）。79 章（可除 Abel 群
与 (Z/p)^ω 的无限对话）会再遇到这批形状。

## 三、Ehrenfeucht 三模型：中间地带的生态

I(T,ℵ₀)=3 的经典例子：T=Th(Q,<,c₀<c₁<c₂<…)（DLO+上升常量
链）。三个可数模型按「链的上确界切割型」分类：

- **M₁**：sup c̄ 存在且被实现，其上无元素——Q∩(-∞,0] 带
  c_n↦-1/n；
- **M₂**：sup 存在，其上有元素——Q 带 c_n↦-1/n；
- **M₃**：链无上界——Q 带 c_n↦n。

两句话子分离三者：σ_sup=∃x(c̄ 上方有极大元)、σ_above=
∃x∃y(c̄<x<y)。M₁⊨σ_sup∧¬σ_above；M₂⊨σ_sup∧σ_above；
M₃⊨¬σ_sup。**可数模型数=切割类型的分布**——这是「数模型」
变成「数型」的第二个现场（第一个是 RN）。

**机器面**（`ehrenfeucht_separation`）：有限影子 L1=[0..3]（链
在底部，sup=3，其上无物）、L2=[0..4]（sup=3，其上有 4）、
L3=[0..3]（链在顶部 [1,2,3]，无上界）。`sigmaSup`/`sigmaAbove`
按序语言+常量求值——真值表恰为 (T,F)/(T,T)/(F,F)。同尺寸的
L1 与 L3（都是 4 元）由句子分离；`no_iso_L1_L3` 枚举全部 24
个双射，「保常量+保序」无一通过——**非同构的两种证明**（分离
句子给出「初等不等价」的强版本，同构搜索失败给出「非同构」
的弱版本；初等不等价⟹非同构，机器两账都记）。

真正的 Ehrenfeucht 例用无穷链（c₀<c₁<…），三个模型在「链的
极限切割」处分岔；有限影子承载的是同一不变量的骨架——
**「有限结构+切割类型」是无限模型论生态的最小标本**。

## 四、I(T,ℵ₀)≠2 与 Morley 分析（文档线）

**Thm 4.4.6**（Vaught）：I(T,ℵ₀)≠2。证明的机关：反设恰两个
——由 Cor 4.3.8 ii) 必是素模型 N 与可数饱和模型 M。T 非
ℵ₀-范畴（有两个模型！）⟹某 S_n 有非孤立型 p——M 实现、N
省略。取 a∈M 实现p，把 a 加为常量：理论 T*=Th(M_a) 仍非
ℵ₀-范畴（无穷多不等价公式在参数化后仍不等价——Lemma 4.4.5
保证 M_a 饱和），于是 T* 有素模型 A——它的 L-归约 B 实现 p
（B≇N）却又不饱和（A 省略某非孤立 T*-型；若 B 饱和则 A
饱和——Lemma 4.4.5 反向）——第三个模型，B≇M。∎ 
「实现一半、省略一半」的中间模型总能被造出来——**2 是一个
不可能的数**。

**Morley 分析**（Def 4.4.7 起选讲）：把一阶逻辑放宽到
L_{ω₁,ω} 的可数 fragment，数 fragment-型；scattered 理论
（一切 fragment 的型空间可数）满足 I(T,ℵ₀)≤ℵ₁（高度
归纳：每个可数模型有 <ω₁ 的 Scott 高度 γ，同高度模型由
γ-型等价类数控制）。**Morley 定理**：I(T,ℵ₀)>ℵ₁ ⟹
=2^ℵ₀——光谱的「中段」（ℵ₀ 与 2^ℵ₀ 之间）只剩 ℵ₁ 一个
可能的洞。**Vaught 猜想**：中段不存在——对 ω-稳定理论已证
（Shelah），一般情形仍是模型论的圣杯之一。31 章的 Scott
同构定理（可数结构被单个 L_{ω₁,ω} 句钉住）在这里变成数模型
的发动机——两个知识岛在暗处早已相连。

## 坑位速记（本章实测）

- **计数器的原子模式要匹配理论**：mode 1 初版用
  「SS x_i=x_j」做 (N,S,0) 的原子——单变元下恒假、全部赋值
  塌缩成一个 profile（计数=1 的假绿）；换成 x_i=c_j
  （j∈0..8）才把命名型逐个开出。
- **同构检查双条件**：只保常量的双射会被错位排列骗过（见
  39 章同坑）——常量固定+保 < 双检后，24 个双射全灭。
- **弱序数不是 Bell 数**：DLO 的无参数 n-型=**有序**分拆
  （Fubini 数 1/3/13/75…），比集合分拆（Bell 1/2/5/15）多
  一层「块有序」——两族数在 docs 里并排时最容易抄错行。
- **型数「≥k」的写法**：无限型空间的机器证据是「随宇宙
  增长的计数」（8 元宇宙 ≥6），写成等式断言会在更大的
  B 下翻车——用 `Nat.leb 6 …` 留出单调增长空间。

## 小结

本章把「数模型」翻译成「数型」：Ryll-Nardzewski 的四价
（范畴/全孤立/逐层有限/有限公式表）在三个理论（纯等词的
Bell 数、DLO 的弱序数、(N,S,0) 的无界增长）上对账；Ehrenfeucht
三模型的有限影子由两句话子分离、由双射搜索判非同构——
「切割类型」是不变量的最小载体；Vaught 的 ≠2 与 Morley 的
中段定理在文档线铺开，Vaught 猜想悬在中段上方。下一章
（41 章）转入本书最锋利的组合工具——**不可辨元**：Ramsey
定理从「数」的深处送来免费的齐次序列，EM 定理用它给任意
理论装配任意线序的自同构群。
