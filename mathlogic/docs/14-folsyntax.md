# 14 一阶逻辑：语法、自由变元与代入

> 对书：H&R §2.2（terms/formulas/自由约束/代入）/ EFT II / Mendelson §2.2
> 通道：C/A/L（fv 特征条款+项级代入交换，零公理）

命题逻辑谈「整句」的真假；一阶逻辑（predicate logic，谓词逻辑）
深入句子**内部**：对象（项）、性质与关系（原子公式）、以及
「所有/存在」（量词）。代价是语法层立刻长出三个命题逻辑没有的
器官：**项、约束、代入**——本章专讲这三个器官。按 01 章暗线：
本章 φ 的骨架从布尔函数升级为带量词的树，M 与 ⊨ 留给 15 章。

## 项与公式：两层 BNF

H&R 定义 2.1/2.3 给的两层语法。**项**（term）是「对象语言」
——变量、常量（零元函数）、函数符号作用于项：

```text
t ::= x | c | f(t, …, t)
```

项不是公式：`mother-of(john)` 是项（某人），`Male(john)` 才是
公式（关于某人的断言）。**公式**在项之上再架一层——谓词符号
吃**项**吐原子公式，量词绑定变量：

```text
φ ::= P(t₁,…,tₙ) | ¬φ | (φ∧φ) | (φ∨φ) | (φ→φ) | ∀x.φ | ∃x.φ
```

注意两个设计事实：谓词的参数必须是项（不能是公式——类型分层
防止「关于陈述的陈述」 sneak in）；符号集 F（函数）与 P（谓词）
是**参数**——换掉它们，项与公式的集合就变了。机器版把这套
两层结构压进一对归纳类型（`examples/14_folsyntax/ex14_folsyntax.v`，
一元片段——一元函数+一元谓词，机制完整而记号最省）：

```coq
Inductive term : Type :=
| tvar : nat -> term
| fapp : nat -> term -> term.

Inductive form : Type :=
| atom : nat -> term -> form
| fimp : form -> form -> form
| fneg : form -> form
| fall : nat -> form -> form.
```

（教程片段省略了 ∧/∨/∃——它们按惯例由 →/¬/∀ 定义；完整
连接词族在文档里按定义展开不影响任何机制。）

## 自由与约束：量词的作用域

变量在公式里有两种出场方式（H&R 定义 2.6，图 2.2 的解析树
是最直观的讲法）：

- **约束出现**：叶子 x 向上走会遇到 ∀x 或 ∃x 节点——它被那个
  量词**绑定**，代表「任意/某个值」；量词的**辖域**（scope）
  是它的子树（减去内部重新绑定同一变量的子树）；
- **自由出现**：向上走遇到的量词都与自己无关——它的值需要
  外部供给（环境的记忆单元）。

`∀x.((P(x)∨∃x.Q(x)) ∨ S(x,y))` 是标准考题：外层 ∀x 的辖域里
`∃x.Q(x)` 又把 x 抢走了——同一个变量名在公式里可以同时有
自由与约束出现（不同位置）。`fv`（自由变元集）的机器定义
就是这条「向上走」规则的转写：∀y 分支只在 y≠x 时把 y 从
候选里刨掉。

「自由变元」是命题变元的直系后代：闭公式（无自由变元）才有
独立的真假，带自由变元的公式像 02 章的 p∧q 一样等环境发牌。
15 章的一致性引理将把它做成定理。

`fv`（自由变元集）的机器定义就是这条「向上走」规则的转写：

```coq
Fixpoint fv (f : form) : list nat :=
  match f with
  | atom p t => fv_term t
  | fimp a b => fv a ++ fv b
  | fneg a => fv a
  | fall x a => remove (Nat.eq_dec) x (fv a)  (* 量词绑走一个名字 *)
  end.
```

量词分支把名字 y 从子公式的自由集中**注销**——约束即除名。
注意 `remove` 注销的是名字而非出现次数（多次约束同名只除一次，
但语义无差）；项层 `fv_term` 收集变量叶子。这个定义直接服务
于两条元定理：一致性引理（15 章：满足只看 fv）与本章的代入
特征条款。

## 代入：本章节的真正主角

变量是占位符，就得有「换牌」操作。**定义 2.7**：
`φ[t/x]` = 把 φ 中 x 的**每个自由出现**替换为项 t。

规则听起来简单，坑在「只换自由的」。H&R 的例子：对
`∀x.((P(x)∨Q(x)) → S(x,y))`（x 全约束）做 `[f(x,y)/x]`——
公式原样不动（没有自由 x 可换）；而对有自由 x 的公式，替换
只发生在自由叶子，约束叶子不碰。

真正的危险叫**变量捕获**（capture）：替换项 t 自己带着自由
变量 y，而替换位置外面恰好有 ∀y——替换后 t 的 y 被「误绑」
到人家的量词上，语义完全变了。标准例子：

```text
φ = ∃y. x < y，    做代入 [y/x]：
朴素替换 → ∃y. y < y     ← y 被捕获！断言「存在大于自身的数」——假
正确代入 → ∃z. y < z     ← 先 α-换名（y→z），再替换——「存在大于 y 的数」——真
```

机器实现有两条路线：**换名式**（capture 时先 α-换名）与
**保守式**（撞车就保留原式）。本章教学版走保守式——`subst` 的
量词分支：

```coq
Fixpoint subst (f : form) (x : nat) (s : term) : form :=
  match f with
  | atom p t => atom p (subst_term t x s)
  | fimp a b => fimp (subst a x s) (subst b x s)
  | fneg a => fneg (subst a x s)
  | fall y a =>
      if Nat.eqb y x then fall y a     (* 撞车：保留，不替换 *)
      else fall y (subst a x s)
  end.
```

`∀y.a` 且 y=x 时整体不动——不是偷懒：此时若强行替换，s 里的
x 语义上本来指外层，替换进去会被 ∀x 捆住。保守式的语义
正确性靠**侧条件**表达：「t 对 x 在 φ 中可自由代入」（t 的
自由变量不落入 φ 中 x 的替换位置的约束范围）——26 章归结的
合一、18 章前束的穿越规则都在这个侧条件上再进一步。项层的
`subst_term` 没有量词、无捕获风险，直接替换。

## 交付内容（三通道零公理）

```
fv_subst_clause   fv(subst t x s) 的特征条款（含 In x (fv t) 条件）
subst_term_eval   eterm e (subst t x s) = eterm (eupd e x v) t
                  ——项代入与语义代入交换
substF 的 capture 规则现场（x 被 ∀ 束缚时代入不动）
```

**项级代入交换引理**是本章旗舰：语法上的「先替换后求值」
等于语义上的「先改环境再求值」——代入操作与解释可交换。
它是 15 章完整代入引理（公式级）的地基，也是「语法操作有
语义意义」的第一块砖。

## 本章最有价值的两个翻车

**1. fv 特征条款的第一版漏了 `In x (fv t)` 条件**：

```
错：In y (fv (subst t x s)) ↔ (In y (fv t) ∧ y≠x) ∨ In y (fv s)
对：... ↔ (In y (fv t) ∧ y≠x) ∨ (In x (fv t) ∧ In y (fv s))
```

错版在「y ∈ fv s 但 y ∉ fv t」时 RHS 真而 LHS 假——机器在
destruct 的第二分支上把矛盾顶了出来（`H : False` 而目标
`In y []`）。**变元重合的联动**是这种条款的隐藏维度。

**2. 语义代入引理的 RHS 写法**（Coq 版实锤）：

```
错：eupd e x (eterm fe e s) (eterm fe e t)   ← 对 eupd 求函数值！
对：eterm fe (eupd e x (eterm fe e s)) t     ← 环境级求值
```

变元号与论域同为 nat——**同型不挡混淆**，类型错误当场抓获；
`symmetry` 补上等式方向后通关。

## Agda 的 with 抽象作用域（本章坑位之王）

`with (y ≡ᵇ x)` 的抽象只作用于**子句目标**——where 块里
`(y ≡ᵇ x)` 保持原样，嵌套 with 各自归约互不通气。正确解法：
不用 where，两分支都 `refl`（外层 with 已把目标里的布尔归约掉）。
字面量 `3 ≡ᵇ 3` 归约成 true 后 false 分支**仍要求穷尽**——
给恒真 refl（语义无损）而非 `λ()`（等式目标不是函数，
ShouldBePi 拒绝）。

## 边界

公式层的 `subst_comm`（代入与语义交换的 ∀ 情形带 y ∉ fv s
侧条件）需要满足一致性引理（EFT III.5 的 FOL 版）与两次 eupd
的复合交换——15 章（FOL 语义）的内容，本章文档登记。

## 本章小结

- 两层语法：项=对象语言，公式=谓词吃项；符号集是参数。
- 自由/约束由「向上走找量词」定义；fv 是它的机器转写；
  闭公式才有独立真假。
- 代入只换自由出现；变量捕获是头号敌人——换名式 vs 保守式
  两条实现路线，教学版保守式+侧条件。
- 项级代入交换=「语法操作有语义意义」的第一砖；公式级在
  15 章合龙。
- 侧条件文化从此开始：可自由代入、y ∉ fv s、 occurs check
  （26 章）——一阶逻辑的每条定理都带着自己的边防检查站。

## 坑位速记（本章实测）

- **Coq/Rocq**：`destruct (Nat.eqb z x) eqn:E` 会把目标里的
  `z =? x` 替换掉（后续 rewrite E 找不到）；`tauto` 对
  `x = y` 与 `y ≠ x` 的原子不匹配视为无关（等式方向要
  symmetry/cong 手动桥）。
- **Agda**：见上节；另有 `Data.Nat.Properties` 无 `≡ᵇ-refl`
  导出（自造或删引用）。
- **Lean**：`simp [substTerm, eterm, eupd, hz]` 的 hz（z ≠ x
  事实）要进 simp 列表才能消 if。
