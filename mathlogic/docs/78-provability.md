第 77 章用 Müller-Stach 的三页把 Gödel 第二不完备性定理的**故事**讲完了：
理论证不出自身的一致性、一致性梯子可以一直爬。但那条通道里，证明
的**技术核心**——为什么「T 是一致的」这句话到了 T 内部就变成不可证
的——被压在 `d1_shadow` 一个机制账里。本章按郝书第十章的路线把这台
发动机整个拆开：**可证性条件 D1–D3**（Hilbert–Bernays 从 Gödel 1931
的证明中提炼、Löb 1955 补完的三条公理）+ **对角化引理**（9.3 节），
足以机械地推出第二定理的全部形态，甚至更多——Löb 定理会作为副产品
出现，并回答一个书中提到的有趣问题（辛钦问题：「我可证」的自指句
说的是真话吗？）。

## 一、外面与里面：第二定理到底说了什么

郝书第十章开篇花了一整节澄清「通俗表达」与「定理本尊」的差距，这
是初学者最大的坎，值得原样保留。通俗版说：**如果 PA 是一致的，那么
它的一致性在 PA 中不可证**——这句话解释了希尔伯特纲领为何不能按原
样实现，但它有一个致命的含糊：「它的一致性」是语言里的一个闭语句
con_T（马上严格定义），而「PA 一致」「在 PA 中可证」却是**外面**的、
元数学中的概念。定理本尊强得多：

> **Gödel 第二不完备性定理（形式化版）**：T ⊢ con_T → ¬bwb_T(⌜con_T⌝)。
> ——「若我一致，则我证不出 con」这句话**本身**是 T 的内定理。

注意三个角色全变了：前提里的「一致」与结论里的「可证」都被形式化
成了 L_ar 中的句子（con_T 与 bwb_T），而且整条蕴含式要在 T **内部**
证明。这就是郝书反复强调的「**外面/里面**」之分：一个断言在外面成
立指它在标准模型中为真；在「里面」成立则要在 T 的**所有**模型（包
括非标准模型）中为真。非标准模型里的「M-证明」「M-有穷序列」从外面
看可能是无穷的——形式化的概念在每个模型里有自己的化身，这是理解
D2/D3 证明的关键直觉（本章第七节）。

先把主角请出来。固定一个递归可公理化的、包含 Q 的理论 T（可以就想
成 PA）。第九章已经造好了：递归谓词 `bew_T(y,a)`（「y 是公式 a 在 T
中的证明序列的编码」）在 Q 中可表示，于是 L_ar 中有公式 `bwb_T(a)`
（「a 在 T 中可证」；Bew 的德文缩写）。书里引入新记号：

$$\Box\alpha := \textsf{bwb}_T(\ulcorner\alpha\urcorner)$$

即「把 α 的哥德尔码代入 bwb 的那个闭句子」。注意一个细节：bwb_T(u)
是以 u 为自由变元的公式，而 □α 总是**闭句子**——哪怕 α 自己带自由
变元。定义一致性句子：

$$\textsf{con}_T := \neg\Box(0\neq 0)\;$$

（书里写 ¬□(0≁0)；推论 10.1.1 说明选哪个矛盾句是非本质的——由 D0，
证出任何一个自相矛盾的闭句子都能形式化地导出 □⊥）。

## 二、可证性条件：Hilbert–Bernays–Löb 三条款

书 10.1 把整个第十章的引擎压缩成三条（对 L_ar 中任意闭句子 α、β）：

- **(D1)** 若 T ⊢ α，则 T ⊢ □α；
- **(D2)** T ⊢ □(α→β) → (□α → □β)；
- **(D3)** T ⊢ □α → □□α。

引理 10.1.1 从 D1+D2 立刻榨出 **(D0)**：若 T ⊢ Γ→Δ 则 T ⊢ □Γ→□Δ——
「条件可导性」的形式化。这一步很短但意味深长：D2 是**一次**分离规则
的形式化，D0 则是任意长推导的形式化，二者可以互相翻译。

D1 的证明（引理 10.1.2）门槛极低：T 只需包含 Q。设 T ⊢ α，取一个证
明序列的编码 n，则「bew_T(n, ⌜α⌝)」是 Σ₁ 真句子，由 Q 的 Σ₁-完全
性（71 章的账）在 Q 内可证，存在量词一放即得 bwb_T(⌜α⌝)。书里两个
漂亮的注记值得记录：**D1 的逆命题不成立**——取 T=Q、α=∀x(Sx≠x)：
□α 是 Q 的内定理（外面有一条一致的证明），但 α 本身不是（例 9.1.1
的 ℕ∪{∞} 模型里 S∞=∞）；ω-一致性恰好刻画了这条沟（习题 10.1.1）。
更妙的是由此预演了第十章后面的大戏：T = PA+¬con_PA 将是**一致的但
ω-不一致的**理论——它「说自己不一致」却其实一致（第八节）。

D2 与 D3 的证明需要真正的算术化肉身（第七节概述），但本章的机器面
故意把它们**抽象化**：只保留这三条作为公理，看能走多远。答案是：
一直走到 Löb。

## 三、机器面一：抽象演算与三个组合子

四个证明助手中的 Coq 版开局如下（Lean 用 `structure Prov`、Isabelle
用 `locale prov` 打包同一组假设，Prolog 在有限宇宙上撒种，见第六节）：

```coq
Inductive Form : Type :=
| atom : nat -> Form | fbot : Form
| fimp : Form -> Form -> Form | fbox : Form -> Form.
```

语法只有四个构造子：原子、⊥、→、□。这是**模态式的抽象语法**——
`atom n` 是第 n 个算术公式的化身，`fbox α`（记 □α）是 bwb_T(⌜α⌝) 的
化身。真算术里 □ 不是一个真值函数，所以它的语义也只能抽象：

```coq
Fixpoint mval (v : nat -> Prop) (bx : Form -> Prop) (a : Form) : Prop :=
  match a with
  | atom n => v n
  | fbot => False
  | fimp b c => mval v bx b -> mval v bx c
  | fbox x => bx x
  end.
Definition Taut (a : Form) : Prop :=
  forall (v : nat -> Prop) (bx : Form -> Prop), mval v bx a.
```

赋值 `v` 管原子、`bx` 管 □-子式（任意一元谓词）。注意 `mval` 是**纯
直觉主义**的 Prop 解释——本章所有命题步骤都不需要经典逻辑，这个细
节后面还会回来。然后是六条假设：

```coq
Variable der : Form -> Prop.                          (* T ⊢ α *)
Hypothesis Htaut : forall a, Taut a -> der a.         (* 重言式都是内定理 *)
Hypothesis Hmp   : forall a b, der (fimp a b) -> der a -> der b.
Hypothesis Hd1   : forall a, der a -> der (fbox a).   (* (D1) *)
Hypothesis Hd2   : forall a b,
  der (fimp (fbox (fimp a b)) (fimp (fbox a) (fbox b))).        (* (D2) *)
Hypothesis Hd3   : forall a,
  der (fimp (fbox a) (fbox (fbox a))).                          (* (D3) *)
Hypothesis Hdiag : forall b, exists g,
  der (fimp g (fimp (fbox g) b)) /\ der (fimp (fimp (fbox g) b) g).
```

最后一条是**对角化引理**（9.3 节）的化身：对任意 β(u₁) 存在闭句 g 使
T ⊢ g ↔ (□g→β)。它在真实算术里由 75 章的代入函数与编码供给；这里作
为显式假设挂在账上——「证明论骨架」与「算术化肉身」的分离正是本章
的设计。

三个组合子把全部推导机械化。`tauti` 把语义蕴涵提升为推演（Hilbert
系统「所有重言式都是公理」的那一半）；`imp_trans` 是链式传递：

```coq
Lemma imp_trans : forall a b c,
  der (fimp a b) -> der (fimp b c) -> der (fimp a c).
Proof.
  intros a b c Hab Hbc.
  assert (Ht : Taut (fimp (fimp a b) (fimp (fimp b c) (fimp a c)))).
  { intros v bx H1 H2 H3; exact (H2 (H1 H3)). }
  exact (Hmp _ _ (Hmp _ _ (Htaut _ Ht) Hab) Hbc).
Qed.
```

注意证明结构：先**手工验证**一个二阶形状是重言式（`intros` 三连后的
那行就是命题演算），再用两次分离规则装配。`imp_distr`（S 组合子：
⊢a→(b→c)、⊢a→b ⟹ ⊢a→c）同理。D0 则是 D1 与 D2 的直积：

```coq
Lemma D0 : forall a c, der (fimp a c) -> der (fimp (fbox a) (fbox c)).
Proof.
  intros a c Hac.
  exact (Hmp _ _ (Hd2 a c) (Hd1 (fimp a c) Hac)).
Qed.
```

读法：把 a→c 用 D1 装进盒子得到 □(a→c)，再喂给 D2 的实例。习题
10.4.1（Rautenberg 书中作引理用的等价替换：⊢α↔β ⟹ ⊢□α↔□β）就是
D0 用两次。

## 四、对角化引理：打破「这句话」的循环

9.3 节是全书最富哲学意味的三页。**不动点引理**说：给定只有一个自由
变元 u₁ 的公式 β(u₁)，可以**能行地**找到闭句 α 使 Q ⊢ α ↔ β(⌜α⌝)
——「α 说 β 对我成立」。证明三步：取表示代入函数 (#γ,n)↦#γ(n) 的公
式 θ；令 γ(u₁) := ∀u₂∀u₃(θ(u₁,u₁,u₃)→β(u₃))；则 α := γ(⌜γ⌝)。

书中两段解说值得全文保留。其一是**祛魅**：不动点本身可能「什么都没
说」。取 β(u₁) :=「u₁ 是偶数」：由于编码方案保证任何闭句的哥德尔数
都是偶数，0~0 或 0≠0 都是不动点——与奇偶毫无关系。说谎者悖论「这句
话为假」是真正的循环论证（我们无法直接定义「这句话」），而 Gödel
的构造里**没有任何循环**：γ 先完全造好，⌜γ⌝ 只是碰巧又可以被选作
代入值。其二是对角表（书表 9.2/9.3）：把所有单变元公式 p₀(u₁),p₁(u₁),…
排成行、自然数排成列，第 i 行 j 列记 Q 是否证 p_i(⌜p_j⌝)。「对 β 施
于对角线」得到的公式 ψ_q(u₁)（等价于 β(⌜p_{u₁}⌝)）必然出现在某一行
q，于是对角线位置上 ψ_q 与 β(⌜p_q⌝) 同真同假——对角化策略「失败」
的地方正是不动点诞生的地方。这与 76 章 Cantor 对角线、114 章 Russell
对角线是同一台机器的三次开动。

递归论一侧的孪生定理（Kleene 9.3.1：对任何递归 f 存在 e 使
P_{f(e)} = P_e）书中只陈述不证（需要 s-m-n 定理）；双不动点习题
9.3.2（找 α₀、α₁ 使 α₀ ↔ β₀(⌜α₀⌝,⌜α₁⌝) 且 α₁ ↔ β₁(⌜α₀⌝,⌜α₁⌝)）
是 Rosser 技巧的预备件——文档线在此存档，机器面见 76 章。

## 五、第二定理的证明：一条断言两条腿

现在可以原样重演书 10.4.1 的证明。**断言**：¬□ 的任何不动点（即满
足 T ⊢ g ↔ ¬□g 的 g）都等价于 con_T。机器面：

```coq
Theorem godel_sentence_iff_con : forall g,
  der (fimp g (fimp (fbox g) fbot)) ->
  der (fimp (fimp (fbox g) fbot) g) ->
  der (fimp g conf) /\ der (fimp conf g).
```

两条腿共用一段「关键账」：

```coq
Lemma boxg_boxbot : forall g,
  der (fimp g (fimp (fbox g) fbot)) -> der (fimp (fbox g) (fbox fbot)).
Proof.
  intros g Hfwd.
  assert (H1 := D0 g (fimp (fbox g) fbot) Hfwd).  (* ⊢ □g→□(□g→⊥) *)
  assert (H2 := Hd2 (fbox g) fbot).               (* ⊢ □(□g→⊥)→(□□g→□⊥) *)
  assert (H3 := Hd3 g).                           (* ⊢ □g→□□g *)
  exact (imp_distr _ _ _ (imp_trans _ _ _ H1 H2) H3).
Qed.
```

用话说：把 g→(□g→⊥) 装盒（D0/D1），与 D2 实例链接得 □g→(□□g→□⊥)，
再用 D3 把 □□g 兑现成 □g 自己的承诺——三步之后 □g 整体塌缩成 □⊥。
**这正是「g 不可证」的形式化**：如果 T 连「g 可证」都推不出 □⊥（一
致性的样子），g 就真的不可证。然后 con→g 方向：从 □⊥ 可推出 □g
（⊥→g 是重言式，D0），于是 (□g→⊥)→(□⊥→⊥)，与不动点反向合拢；
g→con 方向同理反向。两条腿拼起来：**每个 Gödel 句都是一致性句子**。

接着 (10.2) 水到渠成：

```coq
Theorem con_unprovable_formal : der (fimp conf (fimp (fbox conf) fbot)).
```

证明：由断言取 con→g 的镜像 D0 得 □con→□g，接上关键账的 □g→□⊥，
再做一次命题整理（(□con→□⊥)→(con→(□con→⊥)) 是重言式）。最后是
定理本尊的机器面：

```coq
Theorem goedel_second : der conf -> der fbot.
```

若 T ⊢ con，则 D1 给 ⊢□con，与 (10.2) 分离得 ⊢¬□con，再分离得 ⊢⊥。
元数学读法：**一致的 T 不可能证明自身的一致性**——「一致」这个前提
在结论里被烧掉了。

## 六、Löb 定理与辛钦问题的答案

书 10.4.2 的动机来自辛钦（书脚注作 Khinchin）的问题：¬□ 的不动点
本质上是 con（第五节断言），那 **□ 的不动点**——断言「我可证」的自
指句——又是什么？Löb 定理给出惊人的答案：

> **定理 10.4.2（Löb）**：(1) ⊢ □(□α→α)→□α（此式也被称作 (D4)）；
> (2) 若 T ⊢ □α→α，则 T ⊢ α。

机器面的核心是**步引理**（书中 (10.4) 的前半）：

```coq
Lemma lob_step : forall a h,
  der (fimp h (fimp (fbox h) a)) -> der (fimp (fbox h) (fbox a)).
```

它与 `boxg_boxbot` 共享同一条骨架（D0+D2+D3 三连），只是把 ⊥ 换成
了任意的 α。D4 的完整推导：取 h ↔ (□h→α) 的不动点；步引理给
⊢□h→□a；于是 (□a→a)→(□h→a)→h（重言式），即 ⊢(□a→a)→h；D0 装
盒再接步引理：⊢□(□a→a)→□a。规则形 (2) 更短：假设 ⊢□a→a，与步引
理链接得 ⊢□h→a，反向不动点给 ⊢h，D1 装盒后一路分离到 ⊢a。

推论 10.4.1 就是辛钦问题的答案：**□ 的不动点恰为内定理**。若
x ↔ □x，则 □x→x 直接就是 Löb 规则的假设，于是 ⊢x——「我可证」的
自指者说的必定是真话（在 T 看来）。而 Gödel II 本身成了 Löb 的练习
题：取 α=⊥，⊢□⊥→⊥ 即 ⊢con，Löb 给 ⊢⊥：

```coq
Theorem goedel_second_via_lob : der conf -> der fbot.
Proof. intros Hcon; exact (lob_rule fbot Hcon). Qed.
```

一行。这就是 Boolos《The Logic of Provability》前几章的标准重构——
郝书参考书目里的第一条。历史顺序恰好相反（Gödel 1931 → Hilbert–
Bernays 1930s 提取 D 条件 → Löb 1955 解答 Henkin 1952 的提问），但
教学上「D 条件 ⟹ Löb ⟹ II」是最短路径。

Prolog 通道把这套演算做成**程序表宇宙**（70 章配方）：固定 Löb 推导
用到的约五十个公式为宇宙，把「宇宙内全部命题重言式」（对 box-子式
作原子处理后穷举赋值检测——正是 `mval` 思想的可执行版）与 D2/D3 的
全部实例作为种子撒入，规则只有 mp 与 D1，递归饱和到不动点。带假设
□a→a 时推导树完整打出——D1→D2 链、D3 兑现、命题桥、Hrev 封口、再
D1 反推，九步一个不少；去掉假设后 der(a₀) 与 ⊥ 都不在饱和闭包中
（有限宇宙内的归纳证据：结论确实依赖假设；抽象账本自身一致——con
的影子）。饱和循环必须写成「step 成功则递归重开」：写成
`(step,fail;true)` 的经典回溯式会**永远不再重试已穷尽的左支**——
mp 支在早期无解后就被回溯跳过，这是本轮实测掉进去的坑。

## 七、D2 与 D3 的肉身：文档线概述

机器面把 D2/D3 当公理，真实算术里它们是 10.2/10.3 两节的工程。骨架
如下，细节的机器件已在 75/77 章支付。

**D2**（10.2）：把「证明序列的串接」形式化。难点是「有穷序列」这个
概念本身——非标准模型里的「M-有穷」从外面看可能无穷。书先做**语言
扩张**的合法性论证（10.2.1：由 Δ₀/Σ₁-可定义函数与谓词添加符号是保
守扩张，引理 10.2.1–10.2.3：可证递归函数对尾节扩张绝对），然后在 PA
内发展算术：整除/余数/素数/互素（引理 10.2.4–10.2.8，欧几里得引理
的 PA 版用强归纳），**形式化的中国剩余定理**（定理 10.2.2——陈述时
巧妙地用「可证递归函数 m(i) 给出的模数」回避了还没定义的「序列」），
由此得到 **β 函数的 PA 版**（定理 10.2.3：对每个可证递归 h 存在编码
c 使 β(c,i)=h(i) 对 i<k 成立，且 c 有可证递归上界——比第九章的版本
多了上界，且证明避开了阶乘）。然后 FinSeq、串接 `s⌢s'`、项/公式/
公理/ModusPonens 逐层形式化，最后验证 y = u⌢⌜β⌝ 确实是证明序列
（10.2.6）。**D3**（10.3）换了思路：它是对 Σ₁-完全性的形式化。麻烦
在于 □φ(u) 是闭句而归纳需要对带自由变元的公式进行——书为此引入
**□[φ]** 装置（定义 10.3.1：用 su/sub 函数「激活」被锁在数码里的自
由变元，引理 10.3.7 是其交换律），证明**可证 Σ₁-完全性引理**
（引理 10.3.6：对一切严格 Σ₁ 公式 φ，⊢ φ→□[φ]，对原子公式逐条归纳
——断言 1–6 的分层账），D3 是其闭句特例。这套 □[] 装置后来发展成
可证性逻辑的谓词版（GLP），文档线在此挂账。

## 八、PA\*：从「庐山」里看自己；自然的不可判定语句

10.4 的收尾与 10.5 是全书的情感高潮。令 PA\* = PA+¬con_PA。**引理
10.4.1**：PA\* 一致，但 PA\* ⊢ ¬con_{PA\*}。一致性来自第二定理（若
PA\* 不一致则 PA ⊢ con_PA）；「说自己不一致」则需要**形式化的演绎
定理**（习题 10.4.4：T'=T+α 的证明谓词在 T 内可定义）。书引苏东坡
「不是庐山真面目，只缘身在此山中」点题：从外面看 PA\* 一致，从里面
看它宣布自己不一致——「一个一致的理论可以断言自己的不一致性，却永
不断言自己的一致性」。PA\* 也是 ω-不一致理论的标准样本（第二节伏
笔的回收）。习题 10.4.2（¬con→□α：不一致理论形式化地证明一切）在
机器面上有一处边界：它需要的命题整理是**经典**重言式（¬¬-消去），
而本章 `mval` 是直觉主义解释——直觉主义骨架到 D4/Löb 为止全部够用
（书中的推导也全是构造性的），这一差异本身就是「D 条件演算是直觉
主义上层建筑」的有趣注脚。

10.5 转向「**自然的不可判定语句**」：除了刻意构造的自指句，数学关心
的命题会不会独立？三条里程碑：**Gentzen**（TI(α) 对一切 α<ε₀ 是 PA
内定理而 TI(ε₀) 不是——79–81 章的整条线）；**Paris–Harrington 1977**
（有限 Ramsey 定理的相对化版本在 ℕ 中真而 PA 不可证——90 章的账）；
**Kirby–Paris 的 Goodstein 定理**（纯 n 进制换底递降序列必归零——
79 章 `goodstein` 机器件的背景）。书指出三者强度都恰好等价于 TI(ε₀)，
并把这类现象命名为「由一致性强度的不同带来的不可判定性」；结尾留
下开放问题：是否存在不依赖一致性强度的算术独立性证明——内模型与
力迫注定带不来算术的独立句（123→125 收官章的当代地图正接在此处）。

## 小结

本章把第二不完备性定理从「故事」拆到「公理」：六条假设（重言封闭、
分离、D1、D2、D3、对角化）+ 三个组合子，四个证明通道各自完整推演出
断言、(10.2)、Gödel II、Löb（公理形与规则形）、辛钦问题的答案——
全部零公理（`Print Assumptions`/`#print axioms` 记账：Coq/Lean 的闭
式定理只依赖 propext/Quot.sound 级别的基础设施）。Prolog 的有限宇宙
饱和器把「演算作为数据」走到可打印的推导树。算术化的肉身（β 函数
的 PA 版、形式化中国剩余、□[] 装置）留在文档线，与 75/77 章的机器
件互为表里。下一章把镜头拉回模型论：在算术的「简化版本」上，量词
消去会把「可判定」变成一门手艺。
