# 08 范式：NNF 与 CNF

> 对书：H&R §1.5.1-1.5.2 / Ben-Ari 3e §4.1 / Mendelson §1.2 / EFT VIII.4
> 通道：C/A/L（Agda 止步 NNF——case tree 互卡实录）

范式（normal form）回答一个工程问题：**公式长得千奇百怪，能不能
先规整成统一形状再处理**？SAT 求解器的输入格式就是 CNF。本章
走 H&R §1.5 的两步棋：先立**语义等价**的概念（变换的合法性
标准），再做两级变换——NNF 把否定压到原子，CNF 再把 ∨ 分配
进 ∧。旗舰等式：

```text
eval e f = eval e (cnf (nnf f))
```

两次变换都保语义——这是 09 章 DPLL「只要考虑子句集」的前提。

## 语义等价、可满足、有效：三概念精确化

§1.5.1 先修三个基本词的精确含义（它们在全书的出场率极高）：

- **语义等价**（semantic equivalence，φ ≡ ψ）：φ ⊨ ψ 且 ψ ⊨ φ
  ——两个方向的语义蕴含互相成立。直觉：两个公式「说同一件事」。
  注意定义不要求语法相似：`p → q` 与 `¬p ∨ q` 真值表逐行相同；
  而 `p → q → p` 与 `r ∨ ¬r` 连原子都不同、真值表行数都不同，
  但**都恒真**——所以等价。用蕴含互相定义而不是「真值表相同」，
  就是为了涵盖后一种情形。
- **有效**（valid，⊨ φ）：所有赋值下为真——重言式。
- **可满足**（satisfiable）：存在赋值使之为真——有效的对偶：
  φ 可满足 ⟺ ¬φ 非有效。SAT 求解器回答的是可满足性，
  有效性检查是它的对偶应用（查 ¬φ 不可满足）。

§1.5.1 还有一个低调但关键的桥（H&R 引理 1.41）：**矢列有效性
归结为单公式有效性**——`φ₁,…,φₙ ⊨ ψ` 当且仅当
`⊨ φ₁ → (φ₂ → … → (φₙ → ψ)…)`。这就是为什么「判定器只处理
单公式」不损失一般性：任何有限前提集都能柯里化进一条蕴含链
（05 章演绎定理的语义版倒影）。

顺带一个跨层注记：语义等价 ≡ 与 03 章的**可证等价** ⊣⊢ 是
两个层面的事；可靠+完备定理把它们粘成同一个关系——但在缝合
之前（23 章），写作时要分清自己站在哪一层。

## CNF 的语法与「为什么有效性好查」

§1.5.2 的定义链（定义 1.42）：**文字**（literal）=原子或原子的
否定；**子句**（clause）=文字的析取；**CNF**=子句的合取：

```text
L ::= p | ¬p
D ::= L | L ∨ D
C ::= D | D ∧ C
```

例如 `(¬q ∨ p ∨ r) ∧ (¬p ∨ r) ∧ q` 是 CNF（三个子句，单文字 q
也算子句——语法第一条规则允许文字升格）。`(¬(q ∨ p) ∨ r) ∧ (q ∨ r)`
不是：子句里塞了复合否定。

CNF 的全部意义在 H&R 引理 1.43：**文字的析取有效 ⟺ 其中存在
互补对**（某个 Lᵢ 是某个 Lⱼ 的否定）。方向一显然（p ∨ ¬p ∨
任意东西恒真）；方向二构造反赋值：没有互补对时，把每个正文字
置假、每个负文字的原子置真——子句整体为假。这个引理把 CNF 的
有效性检查从 2ⁿ 真值表降到**子句内线性扫描**：CNF 有效 ⟺
每个子句含互补对。工程上更常用的是对偶面：CNF **可满足性**才是
SAT 问题本体——引理 1.43 管不了它（子句间有交互），这正是
09 章 DPLL 存在的理由。

## NNF：把否定压到原子

进 CNF 之前先做 NNF（negation normal form）：消去 →（用
§1.5.1 的等价 `φ→ψ ≡ ¬φ∨ψ`），再用 de Morgan 与双否把 ¬
一路压到原子层：

```text
¬(a ∧ b) ↝ ¬a ∨ ¬b     ¬(a ∨ b) ↝ ¬a ∧ ¬b     ¬¬a ↝ a
```

机器实现是**互递归**两个函数：`nnf` 处理正面，`nneg` 处理
「否定下」的公式（`examples/08_cnf/ex08_cnf.v`）。正确性也
合并成一条合取引理对公式单归纳：

```coq
Lemma nnf_nneg_correct : forall e f,
  eval e (nnf f) = eval e f /\ eval e (nneg f) = negb (eval e f).
```

读法：nnf 保真值；nneg 恰好实现「求补」。两个函数共享一次
归纳——互递归的正确性证明的标准打包法。

## dist 与 cnf：分配律的机器化

CNF 化=NNF 之后把 `∨` 分配进 `∧`：`a ∨ (b ∧ c) ↝ (a ∨ b) ∧
(a ∨ c)`。`dist` 处理「两个已 CNF 公式的析取」，递归双进；
`cnf` 自底向上组装。Coq 版的点睛是 **fuel 化+语义安全兜底**：

```coq
Fixpoint dist (fuel : nat) (p q : form) : form := ...
(* fuel=0 兜底返回 FOr p q ——不分配了，但语义仍对 *)

Lemma dist_correct : forall fuel p q e,
  eval e (dist fuel p q) = orb (eval e p) (eval e q).
```

`dist 0 p q = FOr p q`——分配不完也**不断言错误命题**：兜底子句
直接保留析取，语义等式无条件成立。终止性（fuel 够不够）与
正确性（等式成立）**解耦**——这是燃料化设计比「硬证终止性」
优雅的点：正确性引理里没有尺寸条件，干净。

膨胀警告必须讲：分配律是**指数的**——`(a₁∧b₁) ∨ (a₂∧b₂) ∨ …
∨ (aₙ∧bₙ)` 分配成 2ⁿ 个子句。工业 SAT 用 Tseitin 变换绕开
（引入新变元替换子公式，只保**等可满足性**不保等价，尺寸线性）；
本教程的机器单元做保等价的朴素版（教学清晰），Tseitin 留一句
预告（09 章的工程背景）。

## 完整 trace：一个公式走到 CNF

把 `(p → q) ∧ ¬(¬p ∨ r)` 从头到尾走一遍（纸面版，机器版的
`Example cnf_demo` 是同一笔账的 `reflexivity` 收口）：

```text
原式        (p → q) ∧ ¬(¬p ∨ r)
消 →        (¬p ∨ q) ∧ ¬(¬p ∨ r)        ← φ→ψ ≡ ¬φ∨ψ
NNF 压 ¬    (¬p ∨ q) ∧ (¬¬p ∧ ¬r)       ← de Morgan：¬(a∨b)↝¬a∧¬b
双否消去    (¬p ∨ q) ∧ (p ∧ ¬r)         ← ¬¬a↝a
            —— 此时已是 NNF；检查形状：∧ 里嵌着 ∧，拍平成三子句候选
CNF         (¬p ∨ q) ∧ p ∧ ¬r           ← 本来就是合取，三个子句：
                                          {¬p,q}、{p}、{¬r}
```

三步各对应一条保语义变换，所以最终 CNF 与原式**等价**（不止
等可满足）。有效性检查演示：子句 {¬p,q} 无互补对、{p} 没有、
{¬r} 没有——由引理 1.43，该 CNF **非有效**；而可满足性呢？
取 p=T、q 任意、r=F，三个子句全真——可满足。这个例子同时是
09 章 Horn 求解器的反面教材：子句 {¬p,q} 有一个正文字、{p}
有一个、{¬r} 零个——全部 ≤1 个正文字，**它其实是 Horn 公式**，
09 章的线性算法能直接判。

## DNF 对照：对偶的另一极

与 CNF 对偶的是**析取范式** DNF（文字的合取再析取）。两者的
分工由检查目标决定：CNF 让**有效性**好查（引理 1.43），DNF
让**可满足性**好查（某个合取支无互补对即可满足——把引理
1.43 整段对偶化）。SAT 求解器选 CNF 作输入格式，历史原因
是归结规则（19 章）在子句集上是单规则演算；而 BDD（10 章）
干脆两种范式都不要，用决策图表示。三种表示的对照表：

| 表示 | 有效性检查 | 可满足检查 | 尺寸风险 |
|---|---|---|---|
| CNF | 线性（互补对） | NP 完全（DPLL 的活） | 分配律指数膨胀 |
| DNF | 对偶线性 | 线性 | 同样指数膨胀 |
| BDD | 约简后看是否 ⊥ 节点 | 看是否 ¬⊥ | 变量序敏感（10 章） |

## 三家路线对照

| | NNF | dist（分配） | 收尾 |

## Agda 边界实录（最有教学价值的坑）

Agda 的模式匹配按参数序编译成 case tree：若某子句先约束 p 的
∧-形状，则 `dist (suc k) p q`（p 是变量）整个卡死——第三个子句
（q 侧分配）根本轮不到；换序后 var-q 同病。**双侧形状约束在
单一定义里互卡**。三种解法：

1. Coq：fuel 化 + 兜底子句（本章采用）；
2. Lean：重叠模式生成的方程带侧条件，绕开 `simp only [dist]`，
   按构造子显式 `cases` 分派（本章采用）；
3. Agda：把 q 侧分配交给独立的 dist2/mutual——但 dist2 回调 dist
   又在 var 上卡（试过，不通）。**Agda 版止步 NNF**，CNF 归
   Coq/Lean 双通道。

这个边界的教学价值：三家模式匹配编译器对「重叠+互递归」的
容忍度是语言实现的真实差异，不是用户水平问题——教程选择诚实
止步并记录，而不是硬拧一个扭曲的编码。

## 本章小结

- 三概念：语义等价（互蕴含）/有效（恒真）/可满足（有模型）；
  可满足=非有效的对偶，SAT 求解器回答前者。
- 引理 1.41：矢列有效性柯里化成单公式——判定器只管单公式不亏。
- CNF=子句合取；引理 1.43：析取子句有效 ⟺ 含互补对——
  有效性线性可查，可满足性留给 09 章。
- NNF 互递归保语义；dist 的 fuel 兜底把终止性与正确性解耦。
- 分配律指数膨胀：教学用朴素版，工程用 Tseitin（等可满足）。
- Agda 止步 NNF：模式匹配编译差异的诚实边界。

## 坑位速记（本章实测）

- **Coq/Rocq**：互递归正确性并成一条合取引理对 form 单归纳；
  `destruct (eval e f1)` 会换掉假设里的形——NNF 的 ¬ 分支要
  `rewrite A1` 再 bash；dist 正确性各分支：rewrite IH 前先
  `simpl` 把 eval 的 match 打开，否则 rewrite 找不到
  `eval e (dist …)` 模式。
- **Lean**：`rw [ih p t]` 的 ih 是 generalized 后的**两参**形式；
  rw 之后新引入的 `eval e (fvar n)` 要再补一发 `simp only [eval]`
  才能被 cases 消掉；合取形式的定理不能直接 rw——先 `.1`/`.2`。
- **Agda**：`open ≡-Reasoning` 放模块顶层（mutual 块里的 where
  摸不到）；`nnf-correct (¬f a)` 直给 `nneg-correct e a`（目标
  LHS iota 归约到 nneg 侧）；反向才需要 not-not 链。
