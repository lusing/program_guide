## 定理在说什么（先把话语说清）

**第一不完备定理**（1931）：任何包含初等算术的、一致的、
递归可公理化的形式系统 S 中，存在句子 G，使 G 与 ¬G 都在
S 中不可证。三个前提各自把守一道门：**一致**（不证矛盾，
否则什么都可证）；**递归可公理化**（公理集可机械识别——
「系统」的底线）；**包含算术**（表达力门槛）。**第二定理**：
S（满足加强的一致性条件）不能证明自身的 Con(S)。

读者需警惕的三个误读：不完备性**不是**「数学里有永远说不清
的命题」（G 是明确的算术命题，在标准模型里有确定真值——
只是系统内不可证）；**不是**「机器不如人」（人知道 G 真，
靠的是「看穿」S 一致的元层推理——S 自己做不到，但更强的
系统可以）；**不是**对特定系统的指控（对任何满足前提的
S 都有对应的 G_S——不完备是「足够强的形式化」的结构性
代价）。

## 证明的三步（Mendelson 路线）

### 第一步：形式算术系统 S（PA）

```
S1  x+0 = x                S5  0 ≠ Sx
S2  x+Sy = S(x+y)          S6  x < y ↔ ∃z(z≠0 ∧ x+z=y)
S3  x·0 = 0                S7  x < Sy ↔ (x<y ∨ x=y)
S4  x·Sy = x·y + x         （后继公理 + 归纳模式）
```

皮亚诺算术的一阶形式化。S1-S4 定义加乘的递归行为（0 与后继
两个基座），S5-S7 是序的基本事实，归纳模式是引擎（每个
一阶实例：φ(0)∧∀x(φ(x)→φ(Sx)) ⟹ ∀x φ(x)）。**注意归纳
只是「模式」**——无穷多条公理实例，不是二阶的单条归纳公理
（那是 PA 的二阶版本，categoric 但不可递归公理化——这条
分岔正是不完备性的空间）。

**可表示性定理**（Mendelson 3.2）：每个递归关系 R 在 S 中
可表示——存在公式 P_R 使得 R(n₁,…,nₖ) ⟹ S ⊢ P_R(n̄₁,…,n̄ₖ)
且 ¬R ⟹ S ⊢ ¬P_R。n̄ 是数字项 S(S(…S(0)))。「**可表示**」
= 算术语言能**谈论**每个递归事实且双向判决——这是「S 足够
强」的精确含义。证明对递归函数的结构归纳（零/后继/投影/
复合/原始递归/极小化各一分支）——「证明是有限对象，可被
算术谈论」的全部根据。28 章 TP_mono 的机器现场是这条定理
的 Horn 预演：语法对象上的算子被证明可完全内嵌。

### 第二步：算术化（Gödel 编码）

把「公式」「证明」「可证性」编码为自然数：

```text
符号 ↦ 数（素数幂积编码序列）→ 公式 A ↦ ⌜A⌝
证明序列 p ↦ ⌜p⌝（每步引用前面的行——序列编码）
可证谓词 Pf(m, n)：「m 是编号 n 的公式的证明」——原始递归
Bew(x) := ∃m. Pf(m, x)：「x 可证」——Σ₁ 算术谓词
```

Pf 的原始递归性是**可判定性进入算术的通道**：检查一个证明
合法与否是有限机械过程（逐步核对规则应用），所以它是递归
的，所以可表示（第一步），所以**「可证」成为算术内部可谈
论的谓词**。注意 Bew 本身只是 Σ₁（存在量词叠在递归谓词上）
——它的否定「不可证」是 Π₁——**不对称性将在哥德尔句的
真实性论证里发力**。

### 第三步：对角化 + 不动点

**不动点定理**（Mendelson 3.5，对角化引理）：对任意恰含一
自由变元的公式 B(x)，存在句子 G 使得

```text
S ⊢ G ↔ B(⌜G⌝)
```

构造的直觉：造一个「自 applying」函数——定义 Sub(x) =
「把编号 x 的公式中自由变元替换为数字 x 后的新公式的编号」
（代入运算是原始递归，故可表示为函数项 sub）。取 B' (x) :=
B(sub(x))，设其编号为 b，则 G := B'(b̄) 展开 = B(sub(b̄)) =
B(⌜B'(b̄)⌝) = B(⌜G⌝)——**G 谈论的对象恰好是 G 自己的
编号**。这是「本句话」悖论的合法版：悖论靠的是真值谓词
（Tarski：不可定义），而 sub 只做**语法替换**——完全合法。

**哥德尔句**：取 B(x) = ¬Bew(x)：

```text
S ⊢ G ↔ ¬Bew(⌜G⌝)        「我不可证」
```

**第一定理收尾**（一致性论证）：若 S ⊢ G，则存在证明 p，
故 Bew(⌜G⌝) 是真的 Σ₁ 事实，可表示性给出 S ⊢ Bew(⌜G⌝)，
与 G ↔ ¬Bew 矛盾一致；若 S ⊢ ¬G，同理 S ⊢ Bew(⌜G⌝)，且
¬G 蕴含 Bew(⌜G⌝)（双向等价），而「Bew(⌜G⌝) ⟹ 确有证明
⟹ S ⊢ G」与 S ⊢ ¬G 撞成不一致。两侧都推不出——**G 独立**。
且 G 在标准模型 ℕ 中**真**：G ↔ ¬Bew(⌜G⌝) 在 ℕ 中成立
（不动点定理的构造保证），¬Bew(⌜G⌝) 在 ℕ 中真（G 确实
无证明）——「真而不可证」。

**第二定理**：把第一定理的元推理（「若 S 一致则 G 不可证」）
形式化为 S ⊢ Con(S) → G（需要 Con 的合适形态 + 哥德尔-
Rosser 加强）。但 G ↔ ¬Bew(⌜G⌝) 给出 S ⊢ G → ¬Con(S)
（若 G 可证则 S 证出了假 Σ₁ 句，即不一致）。若 S ⊢ Con(S)
则 S ⊢ G——与第一定理矛盾。故 **S ⊬ Con(S)**。元教训：
「我知道 S 一致」这个知识**超出了 S 的表达能力**——一致性
的证明总要用更强的手段（Gentzen 用超穷归纳 ε₀）。

## 机器件一：表示性样板（C/L）

第一步的「可表示性定理」说每个递归关系都有 S-公式双向刻画它。全定理
的机器化要 PA 推导能力（先例索引里的 AFP 工程）；本章机器面给它的
**标准模型面**：mini-S 语言（+,×,=,¬,⇒,∃）在 ℕ 上的求值器，加上
四条「表示公式确实刻画了算术关系」的真定理——S ⊢ 侧是文档线，
ℕ ⊨ 侧是机器的。

```coq
Inductive tm : Type :=
| var (n : nat) | num (n : nat) | pls (t1 t2 : tm) | mul (t1 t2 : tm).

Fixpoint teval (t : tm) (s : asn) : nat :=
  match t with
  | var n => s n | num n => n
  | pls a b => teval a s + teval b s
  | mul a b => teval a s * teval b s
  end.

Fixpoint feval (φ : fm) (s : asn) : Prop :=
  match φ with
  | eqt a b => teval a s = teval b s
  | neg a => ~ feval a s
  | imp a b => feval a s -> feval b s
  | exq x a => exists v, feval a (upd s x v)
  end.
```

四条样板定理（ℕ ⊨ 侧，双向都真证）：

```coq
Definition rep_add : fm := eqt (pls (var 0) (var 1)) (var 2).
Theorem rep_add_ok : forall x y z,
  feval rep_add (s3 x y z) <-> x + y = z.

Definition rep_le : fm := exq 2 (eqt (pls (var 0) (var 2)) (var 1)).
Theorem rep_le_ok : forall x y, feval rep_le (s2 x y) <-> x <= y.

Definition rep_even : fm := exq 1 (eqt (pls (var 1) (var 1)) (var 0)).
Theorem rep_even_ok : forall x,
  feval rep_even (upd (fun _ => 0) 0 x) <-> exists y, y + y = x.
```

读法：加法图的公式就是 x+y=z 本身（S5/S6 在 54 章是**公理**，这里是被
表示的**事实**）；≤ 的公式藏一个存在量词（ witnesses d=y−x 构造性给出）；
偶性同理。「可表示」的证明侧——S ⊢ rep_add 对应 S5-S6 的定理版、
归纳模式吃下递归行为——是 54 章 PA 机器件的反向视图（那里的分工表）。

## 机器件二：有限域可判定与 Tarski 对照（C/L）

第二定理侧的真谓词问题有个精确的有限对照：**有限论域上真值可判定**。
把量词换成有界搜索：

```coq
Fixpoint fevalb (φ : fm) (K : nat) (s : asn) : bool :=
  match φ with
  | eqt a b => Nat.eqb (teval a s) (teval b s)
  | neg a => negb (fevalb a K s)
  | imp a b => implb (fevalb a K s) (fevalb b K s)
  | exq x a => bexists K (fun v => fevalb a K (upd s x v))
  end.
```

与命题语义的一致性对无量词式是**真定理**（qf_agree，按公式结构归纳，
联结词各一分支）；带量词的句子则演示**论域相对性**：

```coq
Definition sen_even2 : fm := exq 0 (eqt (pls (var 0) (var 0)) (num 2)).
Example finite_even_K5 : fevalb sen_even2 5 (fun _ => 0) = true.
Example finite_even_K1 : fevalb sen_even2 1 (fun _ => 0) = false.
Theorem even2_true : exists v, v + v = 2.
```

同一个句子 ∃x(x+x≡2)：论域 {0..4} 上真（x=1 在场）、论域 {0} 上假
（证人缺席）——**有限域真是相对的**；而 ℕ 上它是定理（量词跑遍全体
自然数，1 永远在场）——**标准模型的真是绝对的**。Tarski 不可定义定理
说这个绝对的真在算术内部没有谓词（否则说谎者悖论合法化）——有限/
无穷正是可判定与不可定义的分水岭，机器面把「分水岭」的有限一侧
做成了可按 K 键调的现场。

## Rosser 加强与两条现代路线（文档注记）

**Rosser 句**（1936）把前提从「一致」减弱到「ω-一致」以下：
取 B_R(x) := ¬∃y.(Pf(y,x) ∧ ∀z≤y.¬Pf(z,¬x 的编号))——
「对我与对我否定的证明里，**我的更早**不存在」。R 句只需
**单纯一致**（不证矛盾）即独立——比哥德尔原版弱的前提。
教学价值在于「不动点 + 谓词工程的微调」能调出不同强度的
独立句。

**布尔吉亚证明**（Boolos 1989 的二阶路线）与 **Kripken-
模型路线**是二十世纪的两条重构：前者用可满足性谓词替代
可证谓词，三页纸走完第一定理；后者把 G 放进模态逻辑框架
（□=Bew 的正规模态逻辑 **GL**，Löb 公理 □(□p→p)→□p 是
第二定理的模态化身）。GL 的不动点定理（每个模态 λ 有
明确不动点）是本章 sub 构造的模态双胞胎——模态逻辑教程
（47-49 章）与证明论的又一条暗线。

**第二定理的形式细节**（补一段工程注记）：Con(S) 的形态选择
影响结论——「无矛盾」的一阶算术化有多种写法（无证明号为
Gödel 数的证明 / 不存在 p 使 Pf(p,⌜0=1⌝)），不同形态在 S 内
不等价（Σ₁ vs Π₁ 层次）。Rosser 句 R 的好处是只需**单纯一致**
（不证矛盾），而哥德尔原版需要 ω-一致。这两条细化在 H&R 的
参考书目（Smullyan、Boolos）里有完整展开——本教程在机器层
只交付到「三步舞的形状」，细粒度的一致性层级登记边界。

## 与全书的接线

- **38 章**：不可判定性（无程序判有效性）是「外部的墙」；
  不完备性是「内部的墙」（系统自己够不着自己的真）——
  前者归约自 PCP，后者归因于对角化。
- **23 章**：完备性（FOL 的可靠+完备）与本章不冲突——
  完备性说的是**推理规则**对**语义**的完备；不完备说的是
  **算术公理系统**对**标准模型真**的不完备。两把尺子不同。
- **13 章**：DP/EP 是「证明携带内容」的正面现象；哥德尔句
  是「真值脱离证明」的负面现象——同一枚硬币（证明与真的
  分离度）的两面。

## 本章小结

- 三步舞：可表示性（算术能谈论一切递归）→ 算术化（证明
  变数字）→ 对角化（句子谈论自己的编号）。
- 哥德尔句 = ¬Bew 的不动点：「我不可证」的合法版——靠
  语法替换而非真值谓词（Tarski 界限）。
- 第一定理：一致则 G 独立且真；第二定理：Con(S) 不可内证
  ——元知识超出系统表达力。
- 三个误读的拒绝：不是「说不清」、不是「机器不如人」、
  不是对特定系统的指控。
- Rosser 句把前提减弱到单纯一致；GL 模态逻辑（Löb 公理）
  是第二定理的模态化身——47 章后的暗线。
- 对角化的四副面孔（否定/Drinker/Y 组合子/sub）——本书
  暗线在此汇合；与 38 章（外部的墙）、23 章（推理规则的
  完备）划清三把尺子的边界。

## 坑位速记（本轮实测）

- **Lean 的 if 计算不自动**：`(upd … 2 d) 0` 的化简停在
  `if (0 == 2) = true`——`change x + d = y at h` 让转换检查做闭式
  iota（比 simp 可靠）；**iff 不能裸 apply**——`apply IH` 在 iff 上
  方向歧义，用 proj1/proj2 显式取边；Coq 侧 `destruct … eqn:E` 会把
  假设里的项一并重写（后续 exact E 失配——改 reflexivity/按新形写）。
- **Bool↔Prop 桥**：`(!b) = true ↔ b = false`（Lean `Bool.not_eq_true'`）
  与 `¬(b = true)` 之间要手工搭桥（`absurd`+`Bool.noConfusion`）；
  Coq 的 `negb_true_iff/implb_true_iff` 是 iff——`rewrite` 进假设，
  别 `apply … in`。
- **Isabelle 归纳法与自由谓词**（38 章实录）：
  `induction_schema` 对非自由 P 报 `dest_Free`——不完备性证明的
  机器化需要**方案的内部归纳**（Paulson 的 Isar 证明走
  `induct "n" arbitrary: ...` 结构化路线）；
- **哥德尔句的「真」**：G 在标准模型 ℕ 中真——但「真」是元概念
  （Tarski 不可定义性）；机器化时「真」只能以模型论方式（`ℕ ⊨ G`）
  表述，Isabelle AFP 的正是此路线；
- 账本：Coq 三件零公理；Lean repEven_ok 零公理、repLe_ok/qf_agree
  带 [propext, Quot.sound]（simp 层）。

- **Isabelle 归纳法与自由谓词**（38 章实录）：
  `induction_schema` 对非自由 P 报 `dest_Free`——不完备性
  证明的机器化需要**方案的内部归纳**（Paulson 的 Isar 证明
  走 `induct "n" arbitrary: ...` 结构化路线）；
- **哥德尔句的「真」**：G 在标准模型 ℕ 中真——但「真」
