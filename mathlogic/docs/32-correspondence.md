# 32 对应理论与逻辑工程

> 对书：H&R §5.3.2（可达关系的性质）/ §5.3.3（对应理论）/ §5.3.4（一些模态逻辑）
> 通道：C/L（五条正向 + T 的逆）

31 章看到 K 之上加 T/4 各需框架性质——本章把「各需」升级为
**精确对应**（correspondence）：每个公式模式对应 R 的一条数学
性质，双向锁死。这是模态逻辑最漂亮的定理族，也是**逻辑工程**
（logic engineering，H&R 的招牌概念）的工具箱：设计逻辑 =
挑公式 = 挑框架性质。

## 可达关系的五种性质（H&R 表 5.7）

| 性质 | 定义 | 直觉（「知道」读法下） |
|---|---|---|
| 自反 reflexive | R(x,x) | 你排除不了现实本身 |
| 传递 transitive | R(x,y)∧R(y,z)→R(x,z) | 排除不掉的排除不掉 |
| 对称 symmetric | R(x,y)→R(y,x) | 反过来看等价 |
| 欧性 Euclidean | R(x,y)∧R(x,z)→R(y,z) | 不可区分关系传递 |
| serial | ∀x∃y R(x,y) | 至少有一个可能世界 |

「知道」的可达 = **排除不了**：R(x,y) 即「y 可能是现实」。
自反显然（现实排除不了自己）；传递/欧性刻画「不可区分」的
等价性——注意**自反+欧性 ⟹ 对称+传递**（欧性给 R(x,x) 与
R(x,y) ⟹ R(y,x)；配合自反得 R(y,y)，再欧性给传递）——这正是
S5 的可达关系是等价关系的代数原因。

## 五条正向定理（机器件）

性质 ⟹ 公式在该框架类上有效（`examples/32_correspondence/`，
双通道）：

```coq
Theorem T_valid : forall F,
  (forall w, In w (worlds F) -> rel F w w = true) ->
  forall w f, In w (worlds F) -> msat F w (mImp (mBox f) f).
Theorem D_valid : ... (serial) -> ... (mImp (mBox f) (mDia f)).
Theorem B_valid : ... (symmetric) -> ... (mImp f (mBox (mDia f))).
Theorem four_valid : ... (transitive) -> ... (mImp (mBox f) (mBox (mBox f))).
Theorem five_valid : ... (Euclidean) -> ... (mImp (mDia f) (mBox (mDia f))).
```

读法对照（H&R 表 5.12 的精髓）：

- **T**：一切可达世界 φ，而现实自己可达（自反）——φ 在现实真。
  「知识必真」；
- **D**：□φ 说一切可达世界 φ；serial 保证**存在**可达世界——
  它满足 φ，◇φ 兑现。「信念一致」（不至于相信矛盾——注意 D
  不保真，只保一致）；
- **B**：φ 在 x 真；对称说可达回来的也看到 x——「现在真的事
  在一切可能眼里都可能真」；
- **4**：□φ 在 x；传递使「可达的可达」还在可达内——□φ 在每个
  可达世界也真——□□φ。「知道自己知道」（正自省）；
- **5**：◇φ 有见证 y（R(x,y)）；**欧性**说 x 的两个后继 y、z
  互达——任意后继 z 都能到达 y——◇φ 在每个后继真——□◇φ。
  「不知道时知道自己不知道」（负自省）。5 的机智在**见证复用**：
  原来的 ◇ 见证 y 被每个新后继 z 重新看见（R(z,y) 由欧性）。

五条证明的共性：性质直接喂给 □/◇ 的语义条款——语义层几乎
是抄写，全部零公理。

## 逆方向：探针世界法（T 的机器化）

反方向（公式有效 ⟹ 框架有性质）的通法（H&R §5.3.3）：**拿
一个世界当探针，给否定方向造反赋值**。T 的逆（机器件）：

```coq
Theorem T_converse : forall (ws : list nat) (r : nat -> nat -> bool),
  (forall (V : nat -> nat -> bool) (w : nat) (f : mform),
     In w ws -> msat (mkF ws r V) w (mImp (mBox f) f)) ->
  forall w, In w ws -> r w w = true.
```

证明骨架（探针三步）：

1. 反设某 w 不自反（r w w = false）；
2. **造探针赋值** V₀：原子 0 恰在 w 假、其他世界真（这是
   「一切赋值」量词的用武之地——有效性必须对 V₀ 也成立）；
3. □p 在 w 真（w 的可达世界都 ≠ w——不自反把 w 自己挡在可达
   集外——而 V₀ 在别处真）；p 在 w 假（V₀ 的定义）——T 失败，
   与有效性矛盾。∎

**陈述的精确性教训**（本章最重要的机器教训）：有效性必须遍历
**赋值**——如果 T_converse 的前提写成「某个固定赋值下有效」，
探针赋值就造不出来（你无法改变别人的赋值），定理直接不可证。
「有效 = 一切模型」，而模型 = 框架 + 赋值——两个全称都要在。
其余四条的逆（B/4/5 的方向性同构）留作练习，方法一模一样。

## 逆方向的通法详解（其余四条怎么做）

T 的逆已机器化；B/4/5 的逆用同一个探针模板（H&R 称为
Sahlqvist 方法的手工版）。以 **4 的逆**（□φ→□□φ 有效 ⟹ 传递）
为例走一遍模板：

1. 反设不传递：∃x,y,z（R(x,y)、R(y,z)、¬R(x,z)）；
2. 探针赋值：p 只在 z 真（其他世界假）；
3. 在 x 处：□p 假吗？x 可达 y，y 处 p 假——□p 假。但 □□p
   呢？需要某个 y-可达世界 u 使 □p 在 u 假——y 可达 z，z 处
   p 真……换个探针：p 只在 **y 可达但 x 不可达**的世界真
   ——z 恰好是这样的世界（R(y,z) ✓、¬R(x,z) ✓）；
4. 于是 □p 在 x **真**（x 可达 y，y 处 p 假？——需要 y 处
   p 假：y 在 x 的可达里且 y ≠ z——按构造 p 只在 z 真，y 处
   p 假 ✓；若 x 还有别的可达世界 w，w ≠ z 所以 p 假 ✓）；
   而 □□p 在 x 假（x 可达 y，y 可达 z 处 p 真 → □p 在 y 假
   → □□p 在 x 假）——4 失败，与有效性矛盾。∎

**5 的逆**最难（欧性的探针要两个见证世界的对偶编排——
Emerson 手册有完整展开）；D 的逆最易（serial 缺失 = 有死点
世界，□φ 空真而 ◇φ 假）。全部登记为练习——方法已交付。

## 逻辑工程：选逻辑 = 选框架性质（§5.3.4）

把公式打包成逻辑（H&R 定义 5.15 的直觉版）：

| 逻辑 | 公理集 | 可达关系 | 典型应用 |
|---|---|---|---|
| **K** | 仅 K | 无约束 | 最小演算/程序后置条件（部分正确） |
| **KT**（T） | K+T | 自反 | 知道（最弱版） |
| **KD45** | K+D+4+5 | serial+传递+欧性 | **信念**（D 换 T：信念可假但一致） |
| **KT4**（S4） | K+T+4 | 预序（自反+传递） | 数学直觉主义（∀∃ 消去后） |
| **KT45**（S5） | K+T+4+5 | 等价关系 | **知识**（完全内省） |
| **K4** | K+4 | 传递 | 时态「以后总是」 |

设计流程（H&R 的逻辑工程循环）：确定 □ 的读法 → 列出直觉上
该有效的公式 → 查对应性质 → 检验性质在读法下的合理性 → 微调。
例：「信念」不接受 T（相信的可以假）但接受 D（相信不至于
矛盾）——KD45 就是这么选出来的。「知识」全收 T/4/5——下一章
的 KT45n。

S4 的特殊身份：直觉主义逻辑可以翻译进 S4（Gödel–McKinsey–
Tarskey 翻译：直觉 φ ↦ S4 的 □φ 形态）——13 章直觉主义 Kripke
的预序 ⊑ 正是 S4 的框架性质，这不是巧合而是定理。

## S5 的可达关系 = 等价关系（一步代数）

32 章最重要的结构推论值得单独走一遍代数：**自反 + 欧性 ⟹
对称 + 传递**。

```text
设 R 自反且满足欧性（R(x,y) ∧ R(x,z) → R(y,z)）：
对称：R(x,y) 时，取 z := y——R(x,x)（自反）+ R(x,y) ⟹ R(y,x) ✓
传递：R(x,y) ∧ R(y,z) 时——由对称 R(y,x)，于是 R(y,x) ∧ R(y,z)
      ⟹ R(x,z)（欧性以 y 为枢纽）✓
```

所以 **KT45（S5）的可达关系是等价关系**（自反+对称+传递）——
这正是「知识」的语义要求：可达 = 主体排除不了的世界 = 与
现实**不可区分**，而不可区分天然是等价关系。反过来，任何
等价关系都满足自反+欧性——**S5 ⟺ 等价关系框架**。33 章的
KT45n 直接继承这个结论：n 个主体的知识各有自己的等价关系
（泥孩子的「看得到对方额」）。

对照 KD45（信念）：D+4+5 对应 serial+传递+欧性——**不含
自反**（由上推不出），所以可达关系是「等价关系减自反」的
形态——信念可达的现实可能被排除（信念可假的结构根源）。

## 本章小结

- 五性质五公式：T↔自反、D↔serial、B↔对称、4↔传递、5↔欧性
  ——正向机器件全零公理；5 的见证复用最巧。
- 逆方向 = 探针赋值法：有效性必须遍历赋值（两个全称）——
  陈述的精确性是可证性的前提。
- 自反+欧性 ⟹ 等价关系——S5 可达 = 知识的不可区分。
- 逻辑工程选型表：KD45 信念、KT45 知识、S4 直觉主义、K4 时态
  ——公式集与框架性质的双向菜单。
- S5 ⟺ 等价关系（自反+欧性 ⟹ 对称+传递的一步代数）——
  「不可区分」的语义户口；KD45 少自反=信念可假的结构根源。

## 坑位速记（本章实测）

- **Coq/Rocq**：
  - 传递性的应用 `apply Htr with (y := v)` 会被 In 的
    unify 岔开——**全参显式** `apply (Htr w v u)` 一步到位；
  - T_converse 的探针赋值用双 `Nat.eqb` match：后继 v ≠ w 处
    的真值化简先 rewrite `(proj2 (Nat.eqb_neq v w) Hvw)`
    （bool 等式版的 neq 提取），外层 match 对 false 直接
    iota 归约（reflexivity 收）——别多写一条 eqb_refl；
  - `destruct (r w w) eqn:E`（bool 案分）而非 bool_dec
    （那是等式决策，签名不同）；
  - 记录投影 `rel (mkF ws r V0)` 要 simpl 后 rewrite 才
    认得 `r`。
- **Lean**：
  - 探针赋值 `fun x p => !(x == w && p == 0)` 的化简链：
    `Nat.beq_eq` 展开 → `Bool.and_true`/`not_true` 逐步收
    ——收尾 `Bool.noConfusion`；
  - `by_contra` 在目标 r w w = true 上直接可用（bool 的
    Decidable 实例核心库自带）；
  - five_valid 的欧性应用参数序（w u v 的轮换）——与 Coq
    版的 (w v u) 不同名同构，别照抄参数名。
