## 一、隐定义→显定义（Prop 6.11）

Def 6.10：句子 A(R,R₁,…,Rₘ) **隐定义** R=「∀x̄(R(x̄)↔R′(x̄))」可证
（把 R 换名成新谓词 R′ 后 A 仍成立——「A 唯一确定 R 的外延」）；**显
定义**=存在只用参数谓词的公式 F 使 A⊢∀x̄(R(x̄)↔F(x̄))。**Beth 定理**：
隐定义⟹显定义——「唯一性自动给出表达式」。证明一步：对 A(R)→(A(R′)⊃
R′(c̄)) 的矢列形用 Craig 插值，插值子 C 恰是显定义核（C 只含参数谓词，
两侧可证性合成 R(c̄)↔C）。机器件在命题级把三步走实：隐定义的两种「同
真值」赋值为真、分离赋值为假；显定义核 F=R 与隐定义的端到端账。

## 二、Robinson 联合一致性（Prop 6.12）

两一致公理系统 S₁、S₂，若没有句子 A 使「S₁⊢A 且 S₂⊢¬A」（无公共矛
盾句），则 S₁∪S₂ 一致。证明用 Maehara 分拆引理（73 章 Lemma 6.5）：
联合不一致时取公理序列 Γ₁（来自 S₁）、Γ₂（来自 S₂）使 Γ₁,Γ₂⇒——分拆
的插值子 C 只含公共符号、依赖双方——C 与 ¬C 各从一侧可证，与假设冲突。
机器件 `jointly` 的小宇宙账：`{p}` 与`{p→q}` 联合一致（存在同真赋值）、
`{p}` 与 `{¬p}` 不一致——「无公共矛盾句」的判定化身。

## 三、Harrop 定理：极性换析取性质（Thm 6.14）

直觉主义逻辑的 DP（Γ⊢A∨B ⟹ Γ⊢A 或 Γ⊢B）并非对一切 Γ 成立——它要求
Γ 满足**极性条件 (\*)**：每个 ∨/∃ 出现都处于 ¬ 的辖域或 → 的左辖域
（**负位**）。Thm 6.14 对无切 LJ 证明归纳：末推理若是 ∨:right 则分解；
否则逐规则上推——关键是 →:left/¬:left 的「右件/体自动满足 (\*)」（极性
在规则中遗传）。(2) 给出五条经典有效直觉无效矢列（¬¬ 洗不干净 ∨/∃ 的
正位出现）。机器件 `harrop` 的极性检查器：

```coq
Example harropYes : harrop (band (bng (bor (bp 0) (bp 1))) (bp 2)) false = true.
Example harropNo  : harrop (bor (bp 0) (bp 1)) false = false.
```

（工程实录：第一版把「∨ 只许负位」写成 `implb neg …`——假前件恒真，
正位 ∨ 被放行；正确形状是负位标记上的显式 match。与 17 章 kRefute 的
implb 坑同族：**过滤条件的方向决定搜索器的诚实性**。）Prob 12.13
（Scarpellini）把 DP/EP 推广到直觉主义算术 HA——证明用**沿证明序数的
超限归纳+归约法**（71 章机器的又一用武之地，文档线）。

## 四、极性谱系与保持定理（文档线）

Prob 8.4（Feferman 多种类插值）把「∨/∃ 负位」精确化为**本质存在/普遍
量词**（数 ¬ 与 → 左辖域的计数奇偶）；插值子的量词按 Sort/Ex/Un/Fr/Pr
五张映射约束。Cor 8.6（Łoś-Tarski）：存在公式恰为「保持到扩张」的公式
——由二种类编码+插值导出。**极性**是贯穿 Harrop 条件、Feferman 插值、
Łoś-Tarski 保持的同一根线——29 章归约树的极性一瞥在此收口。Thm 6.13
（Gentzen 命题判定程序：reduced sequent 的三拷贝上限+有限饱和搜索）是
08 章 tableau 判定性的矢列版亲戚（文档线）。

## 小结

插值子是「万能插头」：插进隐定义得到显定义（Beth）、插进联合一致性检查
得到 Robinson、配合极性遗传得到析取性质（Harrop）。切消→插值→三个下游
定理——「结构性质换语义红利」的完整流水线在 63-64-65 三章闭合。下一章
（76 章）回到算术的模型。
