# 11 直觉主义与 Glivenko 现象

> 对书：Mints §2.9 / H&R §1.2.5（反证法旁白）/ Ben-Ari 3e §2.5
> 通道：C/A/L/T（四通道同构，全部零公理）

03 章看到派生规则家族里有一条分界线：MT、¬¬i 构造白送，PBC、
LEM 记账 classic；04 章把五条经典原理排成互相可推的矩阵。本章
回答一个更深的问题：**经典证明与直觉证明的差距到底有多大？**
Glivenko 定理（1929）给出精确到令人吃惊的答案：在命题逻辑里，
差距恰好是**一层双重否定**。

## 直觉主义立场：三条被拒的规则

H&R §1.2.5 把直觉主义者的诉求说得很直白：证明 φ 就该**直接**
证明它——拆开前提、组合成分、给出见证；「φ 不可能假」不是
「φ 真」的证据。据此他们拒绝三条规则（及其等价形态）：

- **PBC**（反证法）：从 ¬φ 导出矛盾就断言 φ——「排除反面」
  不是「正面证据」；
- **LEM**（排中律）：要证 φ∨¬φ，就必须给出 φ 的证明或 ¬φ 的
  证明——两个都给不出，这个析取就没有辩护；
- **¬¬e**（双否消去）：从 ¬¬φ 得 φ——「不能证伪两次」仍然
  不是见证。

拒绝不是意气：H&R 的练习要求读者验证三条在直觉系统里互相等价
（恰是 04 章矩阵的构造性半边）。直觉主义逻辑 = NJp **不加**这三条
= 03 章那套引入/消除规则的本来面目。数学史上最有名的对照是
实分析：经典证明「存在 x 使 P(x)」可以只证「非不存在」，而
直觉主义要求把 x **造出来**——比如证明「存在无理数 a,b 使
a^b 有理」，经典用 √2^√2 的排中分情况，直觉主义直接给出
a=b=√2、见证 √2·√2=2（ witnessed 证明反而更短）。

## ¬¬ 翻译：把经典真「藏进」双重否定

Glivenko 的思想：经典原理挂上 ¬¬ 后全部变成直觉定理。机器现场
（`examples/11_glivenko/ex11_glivenko.v`，四通道同构）：

```coq
Theorem n3 : forall A : Prop, ~ ~ ~ A -> ~ A.

Theorem nn_mono : forall A B : Prop,
  (A -> B) -> ~ ~ A -> ~ ~ B.

Theorem nn_lem : forall A : Prop, ~ ~ (A \/ ~ A).

Theorem nn_dne : forall A : Prop, ~ ~ (~ ~ A -> A).
```

逐条读：

- **n3**（三重否定坍缩一层）：¬¬¬A → ¬A。三重否定是「过度
  包装」——剥掉一层还剩 ¬A 的直觉内容。这条是 Glivenko 证明的
  **引擎**（下文可见）；
- **nn_mono**（¬¬ 单调）：A→B 的证明可以推进 ¬¬ 层里——双重
  否定对直觉蕴含封闭，翻译因此可以逐连接词组装；
- **nn_lem / nn_dne / nn_demorgan**：04 章矩阵的三个主角分别
  ¬¬ 化——全部零公理构造可证。最耐看的仍是 `nn_lem`：
  `fun h => h (Or.inr (fun a => h (Or.inl a)))`——**证伪器
  两次吃到由它自己担保存在的析取**（04 章精读过的自指喂食）。

## 三板斧：构造细节

1. **自指喂食**（nn_lem）：把「或右」构造出来喂给否定假设，
   其中的 a 又来自把「或左」喂给同一假设——一台证伪器被诱导
   自毁；
2. **常函数造 ¬A**（nn_dne）：有 A 的证据就能造出 ¬¬A→A 的
   证据——`λ_ → a`（无视 ¬¬A 的常函数）。于是 ¬(¬¬A→A) 反推
   出 ¬A，再喂回 ¬¬A 得 False；
3. **¬¬ 合取合成**（nn_demorgan）：从 ¬(¬A∨¬B) 抽出 ¬¬A 与
   ¬¬B，合成 ¬¬(A∧B) 与原假设 ¬(A∧B) 对撞。

这三招是「在否定世界里搬运正面证据」的通用手法——后面 13 章
Kripke 语义的强制关系、16 章 FOL 直觉演算里会反复出现同构动作。

## Glivenko 定理的陈述与证明骨架

**定理**（命题层）：对任意命题公式 φ，

> φ 经典可证 ⟺ ¬¬φ 直觉可证。

(⟸) 方向：直觉可证自然经典可证（NJp 是 NKp 的子系统——03 章
`nn_i` 白送、¬¬e 补票）。(⟹) 方向是内容所在：对经典推导的长度
归纳。关键步：

- 全部**公理/规则前提** A 的 ¬¬ 化由 `cl_to_nn`（同文件，
  `A → ¬¬A`，即 03 章 nn_i）推进；
- **MP 步**（从 A→B 与 A 得 B）：由 nn_mono 两次应用把
  ¬¬(A→B) 与 ¬¬A 组装成 ¬¬B；
- **经典规则步**（PBC/LEM/¬¬e 之一）：这是 n3 的出场处——
  例如 ¬¬e 的 ¬¬ 化是 ¬¬(¬¬A→A)，恰是 `nn_dne`，白送。

归纳收口：经典推导的每一步都能镜像成直觉世界里的 ¬¬ 链。整个
证明不需要任何语义——纯粹是**演算层的重写论证**（「演算作为
数据」方法论的又一次应用：推导归纳）。

## FOL 层的边界：Glivenko 不整体平移

一个必须交代的边界：Glivenko 定理是**命题逻辑的**定理。到一阶
逻辑，¬¬ 化的平移需要加强为 Gödel–Gentzen 翻译（¬、∧、∨、→、∃
各配专门的 ¬¬ 嵌入形态——比如 ∃x.φ 翻成 ¬∀x¬¬φ 的形态），并且
**翻译后的公式不再是原公式加一层 ¬¬**。命题层的「经典=直觉+一层
¬¬」的干净等式在量词下失效——这正是 16 章 FOL ND 里量词规则侧
条件的深度来源之一。Mints §2.9 给出精确表述；本教程在 16 章
Drinker 悖论的直觉版本处再回扣这条线。

## Glivenko 的两个免费推论

定理的边角料里藏着两件宝，值得单独点名：

**推论一（否定公式的完全平移）**：若 ¬φ 经典可证，则 ¬φ **直觉**
可证——否定公式根本不需要 ¬¬ 化。证法：¬¬¬φ → ¬φ 是 n3，把
经典证明的结论 ¬φ 再 ¬¬ 一次走 Glivenko，然后用 n3 坍缩回来。
工程含义：**反驳是构造性安全的**——经典逻辑证出的「不可满足/
不一致」结论，直觉主义照单全收（09 章判定器报 UNSAT 的语义
论证可以放心用经典手段）。这解释了表列法（07 章）与归结法
（19 章）这些「经典搜索」系统为什么在直觉语境里仍然能当
反驳检查器用。

**推论二（一致性归约）**：经典命题逻辑一致 ⟹ 直觉命题逻辑
一致。若直觉逻辑证出 ⊥，则 ¬¬⊥ = ⊥ 经典可证，经典逻辑也不
一致。一致性的「 hardness」在直觉侧——这个方向在证明论里
一路通向 Gentzen 的 cut elimination 一致性证明（06 章的
Hauptsatz 注记）。

## 与 04/13 章的精确接线

把三章放在一张图里：

```text
04 章（演算层）   五原理两两构造等价；本体证不出，账本 classic
11 章（翻译层）   本体的 ¬¬ 化全部构造可证——差距=一层 ¬¬
13 章（语义层）   Kripke 反模型证明本体确实不可证——差距是本质的
```

三层合起来是一个完整的不可证性论证闭环：04 章说「等价」，
11 章说「差多远」，13 章说「差距是真的」——语义反模型给演算
层的「写不出来」提供**独立证据**（不是「我没找到证明」而是
「不存在证明」）。这个「演算现象+翻译度量+语义反例」的三件套
结构，在 22 章（不完备性）还会以更大尺度重演：可证性演算、
算术化编码、标准模型反例。

## HoTT 侧注记

这四条构件在 HoTT 里是 **h-level 无关**的纯构造事实——不需要
`IsHProp` 截断。截断层级只在**陈述** LEM 时才进入游戏（04 章
的 `LEM_hprop`）：现象属于纯类型论，形态属于语义层。这个分工
与 12 章「DP 是未截断证明的现象」一脉相承。

## 构造走查：nn_demorgan 逐行读

把三板斧的第三斧完整走一遍（其余两条同构）。目标：
`¬(A∧B) → ¬¬(¬A ∨ ¬B)`——经典 de Morgan 对偶方向的 ¬¬ 化。
直觉上「合取的证伪器」应该能造出「一支否定的析取」，但构造上
造不出（04 章本体账）；挂上 ¬¬ 后怎么造？反着推：

- 要证 `¬¬X`，假设 `¬X`（记 h），造 ⊥；
- h 是 ¬(¬A∨¬B)——一台「否定析取证伪器」。喂它任何一个
  ¬A 或 ¬B 的注入都能得 ⊥。所以**出路是造出一支否定**；
- 造 ¬A：假设 a:A，需要 ⊥——把 `Or.inl (这边)` 喂 h？不行，
  h 吃的是 ¬A 本身。重新组：由 a 能造 ¬¬A（nn_i），而
  ¬¬A 与「h 蕴含 ¬A」对撞——需要先证 **h → ¬A**；
- h → ¬A：假设 a:A，若再有 ¬A∨¬B 的证据就喂 h……循环了？
  不——拆开写：`fun a => h (Or.inl (fun _ => …))`——这里
  `fun _ => …` 需要在「已有 a」的语境里产 ⊥，而 h 的入参
  Or.inl 要求一支 ¬A……干净的做法是二步走：先从 h 抽
  `¬¬A`（假设 ¬A，注入 inl 喂 h 得 ⊥——这台造 ¬¬A 的机器
  与 nn_lem 的自指喂食同构），同理抽 ¬¬B；
- 最后：¬¬A ∧ ¬¬B 与原假设 ¬(A∧B) 对撞——若 A∧B 成立，
  两支 ¬¬ 分别吸收出 A、B，重组 A∧B 喂回自身……收口。

这一段「绕」正是 ¬¬ 世界的典型体感：每一步都是构造性的，但
**信息要经过否定机器的两次反射**才可用。读者若在 16 章 FOL
的 Drinker 直觉版里感到似曾相识——那就是同一台机器加了量词
齿轮。

## 四通道现场对照

| 通道 | 构件表示 | 特色 |
|---|---|---|
| Coq/Rocq | `Theorem nn_lem : forall A : Prop, ~ ~ (A \/ ~ A)` | tactic 链与项式可互换；`Print Assumptions` 全 Closed |
| Agda | 点式 `¬¬-lem = λ h → inj₂ (λ a → h (inj₁ a))` | 每行即 Curry–Howard 证，依赖顺序即证明顺序 |
| Lean | `theorem nnLem : ¬¬(p ∨ ¬p) := fun h => h (Or.inr (fun a => h (Or.inl a)))` | 项式一行流；`absurd` 是 nnDne 直收件 |
| HoTT | 同构件 + Empty 侧注 | `-noinit` 下 False_ind 不可用——destruct Empty 假设直收 |

四家的证明体**逐字符同构**（除了语法糖）——这是「构造性内容
不依赖实现」的最直接展示：同一篇数学证明，四种护照。

## 本章小结

- 直觉主义拒 PBC/LEM/¬¬e 三条等价规则；NJp 本来面目即直觉逻辑。
- Glivenko：命题层经典可证 ⟺ 直觉可证 ¬¬ 化——差距恰好一层
  双重否定；证明是推导归纳+三板斧。
- 引擎构件：n3 坍缩、nn_mono 单调、自指喂食——「否定世界搬运
  正面证据」的手法库。
- FOL 层要换 Gödel–Gentzen 翻译——干净等式在量词下失效，
  16 章回扣。
- HoTT：构件 h-level 无关；截断只管 LEM 的**陈述**。

## 坑位速记（本章实测）

- **Coq/Rocq**：`n3` 的直觉走 `H (fun ha' => ha' ha)`——
  ¬¬¬A 直接吃 ¬A 的证据链；写错顺序会得到「A 与 False 无法
  统一」；`False_ind A (…)` 显式指定消除目标类型。
- **HoTT**：`False_ind` 在 -noinit 下不可用，`Empty_rect` 的
  unification 也失败——最终 `set (he := …). destruct he.` 直收
  （destruct 一个 Empty 假设关闭任意目标）。
- **Agda**：where 块的局部定义（nnA/nnB）按依赖顺序排；
  点式书写的每行就是 Curry–Howard 证。
- **Lean**：`absurd` 是 nn_dne 的直收件；nn_demorgan 的嵌套 λ
  就是 Coq assert 链的化简。
