# 18 前束范式：量词穿越的等价保持

> 对书：Mendelson §2.10 / EFT VIII.4 / Ben-Ari 3e §9.2 / H&R §2.3.2（等价表）
> 通道：C/L（量词穿越四条零公理）

16 章末尾的量词等价表（H&R 定理 2.13）是运算规则箱，本章把它
的**可机器化内核**做实：前束范式（prenex normal form，PNF）——
把公式改写成「全部量词连续排在最前、后跟无量词矩阵」的等价
形式。PNF 是 19 章归结的输入格式（再进一步 Skolem 化成子句），
也是检验「量词等价表不是纸面装饰」的试金石。

## 前束形是什么、为什么要

```text
φ 的前束形：  Q₁x₁.Q₂x₂.…Qₙxₙ. M     （Q ∈ {∀,∃}，M 无量词）
```

矩阵 M 是纯命题骨架（连接词+原子），量词全部升到屋顶。任何
公式都**等价地**可改成前束形（经典逻辑下；直觉逻辑里部分
穿越失效——16 章等价表的边界注记）。

为什么要前束？后续工序的流水线需要：19 章归结要先把公式
否定、前束、再 Skolem 化（消 ∃）得到全称子句集——**量词
挤在前面才好成批处理**。这与 08 章 CNF 的动机同构（连接词
规范化便于逐子句处理）——范式是「让算法只对付一种形状」
的通用战术。

## 穿越的四条基本等价（机器化主体）

完整算法 = 变元标准化（α-换名消除撞名）+ 逐层前移 + ¬/→ 的
经典改写（¬∀x.P ↝ ∃x.¬P 等）。全做是大工程；本章机器化其
**循环不变式核心**——量词穿越 ∧/∨ 的四条（`examples/18_prenex/`）：

```
all_and_split  ∀x.(P∧Q) → (∀x.P ∧ ∀x.Q)         分配
all_or_mono    (∀x.P) → ∀x.(P∨Q)                  单调
all_and_join   (∀x.P) ∧ Q → ∀x.(P∧Q)（x∉FV Q）   穿越合取
all_or_swap    (∀x.P) ∨ Q → ∀x.(P∨Q)（x∉FV Q）   穿越析取
```

前两条是无侧条件的「安全方向」：∀ 分配进 ∧ 永远合法；∀
「弱化」进 ∨ 也合法（前件的蕴含方向天然单向）。后两条是
真正把量词**从里往外搬**的运输规则——带侧条件。

## 侧条件的不对称：为什么条件只在 Q 侧

`all_and_join`/`all_or_swap` 的条件 `x ∉ FV(Q)` 只看 **Q 侧**
（P 被量词管住不需要条件）——这不是不对称的偏心，是本质：

- **P 侧为什么安全**：P 里的 x 全被 ∀x 管住（约束出现），
  穿越前后都是同一些约束出现——语义身份不变；
- **Q 侧为什么危险**：Q 里的 x 若自由，穿越后落在 ∀x 辖域
  **之内**——被捕获。对照具体反例：

```text
穿越合法（x ∉ FV Q）：  (∀x.P(x)) ∧ Q(y) ≡ ∀x.(P(x) ∧ Q(y))
穿越非法（x ∈ FV Q）：  (∀x.P(x)) ∧ Q(x) ≢ ∀x.(P(x) ∧ Q(x))
```

第二行左边读「P 对一切 x 成立，且（这个特定）x 有 Q」；右边
读「对一切 x，P(x) 且 Q(x)」——右边更强。取论域 {0,1}、
P 恒真、Q(0) 真 Q(1) 假：左边真（特定 x=0 有 Q）右边假。
**穿越的方向性由量词辖域的伸缩决定**——把量词往外拉，
辖域变大，圈进来的自由变元遭殃。

同样的不对称将出现在 19 章（归结的 lifting 需要变元标准化）
与 21 章（可达性不可表达证明里 φₙ 的路径长度公式）——
「谁被量词管住」是一阶逻辑永恒的户口问题。

## 对偶视角：∃ 的穿越与直觉边界

四条都写成了 ∀ 形态；∃ 的对偶族（∃ 分配进 ∨、∃ 穿越进 ∧/∨）
由对偶原理免费获得（两边取否定换 ∀）。但**方向性要对齐**：
∀ 的穿越是「往外拉」，∃ 的穿越是「往外拉」——两者在**合取/
析取的选择**上镜像（∀ 愿与 ∧ 交换分配、∃ 愿与 ∨）。

直觉逻辑的边界值得记：`∀x.(P∨Q) → (∀x.P ∨ Q)`（x∉FV Q）
**直觉不成立**（16 章等价表注记过 ¬∀↔∃¬ 的经典性）——前束
化的某些穿越步骤是经典步骤。直觉逻辑有自己的「非对称前束」
理论（部分量词可前移）——本教程不展开，登记边界。

## 证明骨架走查：all_and_join 的 v-论证

四条定理的证明共享一个骨架——**∀ 目标的「任取 v」仪式**。以
`all_and_join`（最典型）走一遍（Coq 版）：

```text
目标：(∀x.P(x)) ∧ Q → ∀x.(P(x) ∧ Q)     （x ∉ FV Q）
打法：intro 前提 [HP HQ]；apply ∀ 目标 → intro v；
      拆 ∧ 目标 → 两支：
      支一：P(x)[v 处赋值] ← HP v 直接实例化（∀ 的应用）；
      支二：Q[v 处赋值]   ← peval_irrelevant_at：
                            Q 在 v 处无关（x ∉ FV Q），
                            换牌回 HQ 的原环境
```

**支二是全部戏肉**：右边的 Q 在「x 换成 v」的环境下求值，
左边的 Q 在原环境——侧条件经无关性引理桥接两个环境。四条
定理的差别只在支的形状（∧ 双支/∨ 单向）与方向（split 要
双向、mono 只单向）——骨架复用率高，正说明「穿越 = 换牌+
无关性」的统一机制。

机器证明里 ∀ 目标是 `fall` 构造子的语义定义（对一切 v 的
Prop），intro v 即任意取值——与 16 章 ndAllI 的「语义 ∀」
对照：这里在证**元定理**（语义等价），不在演算内操作——
层数不同、仪式同形。

## 与 19 章的接口：Skolem 化预告

前束形只是流水线第一站。19 章归结的完整预处理：

```text
φ（要证有效）
  → ¬φ（改证不可满足）           经典对偶
  → 前束形                       本章
  → Skolem 化：消 ∃（引入 Skolem 函数 witnessing 存在），
    得全称子句集
  → CNF（08 章）                 子句集就绪
```

Skolem 消 ∃ 的直觉：∃x.P(x) 说「有个见证」——干脆造一个
函数符号 f 把见证「抓出来」（P(f())）；∀ 里的 ∃ 要抓相对
见证（∀y∃x.P(x,y) → P(f(y),y)——见证依赖 y）。**Skolem 化
保等可满足性不保等价**（与 Tseitin 同款契约）——这是 19 章
的开工内容，此处只立接口：本章的四条穿越正是 Skolem 化前
把量词整理成「∀∃∀∃…」交替序的工具。

## 侧条件的引擎：一致性 + 无关性

```
peval_coincidence   赋值在 FV 上一致 → 语义 iff（15 章配方复用）
peval_irrelevant_at x ∉ FV(f) → 换 x 处赋值不改变语义
```

`irrelevant_at` 是 `coincidence` 的直接推论：`e` 与
`eupdb e x v` 只在 x 处不同，而 x ∉ FV(f)。两条引理撑起全部
四条穿越：∀ 分支要「对任意 v 换 x 处赋值」，穿越后的公式
在同一换了牌的环境下求值——侧条件 x ∉ FV(Q) 保证 Q 这部分
**感受不到换牌**（无关性），于是两边逐点对齐。这是 15 章
「换牌合法性」基础设施的第二次消费（第一次是 16 章等式侧）。

## 论域设计

布尔论域（`∀ v : bool`）——避免 nat 无穷量化的语义复杂度，
量词穿越的等价结构完全保留。二元下的 `eupdb` 就是 15 章
`eupd` 的 bool 特化。论域选择不影响等价式的机器证明结构
（任何论域的证明同构）——这是「语义引理按形状而非按载体
复用」的设计经验。

## 一个完整走查：两层穿越

把 `∀x.P(x) ∧ (∀y.Q(y) ∨ R(z))` 前束化（x,y,z 互异——已
标准形）：

```text
原式            (∀x.P(x)) ∧ ((∀y.Q(y)) ∨ R(z))
内层穿越        all_or_swap：∀y.(Q(y) ∨ R(z))     （y ∉ FV R(z) ✓）
                得 (∀x.P(x)) ∧ ∀y.(Q(y) ∨ R(z))
外层穿越        all_and_join：∀x.(P(x) ∧ ∀y.(Q(y) ∨ R(z)))
                （x ∉ FV(右式)：右式自由变元只有 z ✓）
量词顺序        x 与 y 互不纠缠，∀x∀y 交换（16 章等价表）：
                ∀x.∀y.(P(x) ∧ (Q(y) ∨ R(z)))      ← 前束形，矩阵纯命题
```

两步穿越、每步一次侧条件检查——完整算法就是这个循环的
机械化（加上 ¬/→ 改写与 α-标准化）。若原式是
`(∀x.P(x)) ∧ Q(x)`（x 撞车），必须先 α-换名（Q 的 x 改
x'）才能穿越——变元标准化是前束化的第 0 步。

## 本章小结

- 前束形 = 量词全部升顶 + 纯命题矩阵；与 08 章 CNF 同一
  「形状先行」战术，是 19 章归结流水线的第一站。
- 四条穿越：两条无侧条件的安全方向（分配/单调）+ 两条带
  x∉FV(Q) 的运输规则；侧条件只在 Q 侧是辖域伸缩的本质。
- 反例（(∀x.P)∧Q(x) ≢ ∀x.(P∧Q)）值得亲手算一遍——
  「谁被量词管住」的户口问题贯穿 19/21 章。
- 证明骨架统一为「∀ 目标的 v-仪式 + 无关性桥接」——15 章
  换牌基础设施的第二次消费。
- 直觉边界：部分穿越（∀∨ 型）是经典步骤，登记不展开。
- Skolem 化接口：前束是「消 ∃ 抓见证」的前置工序，契约是
  保等可满足性（非等价）——19 章开工。

## 坑位速记（本章实测）

- **Coq/Rocq**：
  - `keep_remove` 的 `In z (a::l)` 等式是 `a = z`（头=元素）——
    与 `Heq : y = a` 的链条方向 `eq_trans (eq_sym Heq') (eq_sym Heq)`；
  - `right` 对 `In z (remove …)` 报 not inductive——remove 后
    In 是 fixpoint 应用，需分支内再 `simpl`；y=a 分支 remove
    直接变 `l'`（不是 cons）——直接 `apply IH` 不带 `right`；
  - `peval_irrelevant_at` 的 iff 方向：e → eupdb 是 `.mp`
    （all_and_join 用的是从 e 到 eupdb 的正向）；
  - `pull_one` 的侧条件 `[H|H]`——`discriminate H` 对
    `1 = 2` 有效但 `In 1 []` 要 `contradiction`。
- **Lean**：
  - `patom` 的语义 `pe p x = true` 与赋值 **e 无关**（谓词
    作用于变元号本身）——一致性引理的 patom 分支是
    `simp only [peval]` 后直接 rfl，无需 h；
  - `peval` 必须返回 `Prop`（`= true`），裸 `pe p x` 是 Bool；
  - `(m == y) = false` 的建立走 `cases hb : (m == y)` +
    `simpa using hb`（`Nat.eq_of_beq_eq` 在独立 Lean 不存在）；
  - iff 的所有分支 `.mp/.mpr`（17 章坑复现）。
