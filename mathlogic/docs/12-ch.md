# 12 Curry–Howard 对应与析取性质

> 对书：Mints ch4-5（演绎项/正规化）/ H&R §1.2（ND 规则的
> 程序读法）/ Prawitz 文集
> 通道：C/A/L/T（双 canonical 零公理）

03 章已经反复用了「规则即程序」这句话：∧i 是配对、→i 是 λ、
∨e 是分情况。本章把这个观察升格为正式的**对应**（correspondence，
Howard 1980 命名，Curry 1958 已有形态），并兑现它的第一个
证明论红利：**析取性质**（disjunction property，DP）——直觉
逻辑里闭的 ∨ 证明必然单侧携带。这条性质经典逻辑**没有**
（LEM 就是反例：p∨¬p 闭证明双侧都不携带）——它是「构造性
有内容」的第一块可机器验证的试金石。

## 对应表：命题即类型，证明即程序

把 03 章的 ND 规则表重排成类型/程序两列：

| 命题世界 | 类型世界 | ND 规则 | 程序动作 |
|---|---|---|---|
| ⊥ | 空类型 | ⊥e | 空消解（对不可能模式匹配） |
| A ∧ B | 积类型 A×B | ∧i / ∧e₁ / ∧e₂ | 配对 / 投影 |
| A ∨ B | 和类型 A+B | ∨i₁ / ∨i₂ / ∨e | 注入 / 分情况 |
| A → B | 函数类型 A→B | →i / →e | λ / 应用 |
| ¬A | A → ⊥ | ¬i / ¬e | （→ 的特化） |
| 证明 φ | 项 t : φ | 推导 | t 的类型检查 |

读法两遍：从左往右，**每个逻辑连接词是一个类型构造子**；
从右往左，**每个良类型程序是一个形式证明**。证明的检查
（这个推导合法吗？）= 程序的类型检查——这是「证明助手为什么
可能」的根本答案：内核只需要做类型检查，就等于在验证证明。

两个方向的微妙处：→i 的「开框放电」对应 λ 的**变量绑定**
（假设=绑定变量，出框=出作用域）；∨e 的双分支对应模式匹配的
** exhaustive 分支**——两个分支必须返回同一类型，正如分情况
讨论必须结论同一公式。ND 的「证明框纪律」与程序的作用域纪律
是同一件事的两种记法。

## 一个完整对照：同一证明的两种写法

取 `A → A ∧ A`（对角函数）。ND 推导树（03 章框记法）：

```text
1 │ A        假设（开框）
2 │ A        1 重述
3 │ A        1 重述
4 │ A ∧ A    ∧i 2,3
5  A → A∧A   →i 1-4（放电）
```

程序写法：`λa. (a, a)`——推导的每一行对应程序的每一步：
框=绑定（a 的作用域就是框内）、重述=变量引用、∧i=配对、
放电=λ 抽象。再看一个用 ∨e 的：`A∨A → A`：

```text
1 │ A ∨ A     假设
2 │┌ A        左框假设
3 ││ A        2 重述
4 │└ A        框收（左分支完成）
5 │┌ A        右框假设
6 ││ A        5 重述
7 │└ A        框收（右分支完成）
8  A          ∨e 1, [2-4], [5-7]
```

程序：`fun s => case s of inl a => a | inr a => a`——两个
框=case 的两个分支，每个分支独立绑定自己的 a（作用域互不见）。
这两张对照表是「ND 记法为什么长这样」的最终答案：它是
λ 演算的前史，Gentzen 比 Church 晚两年，但两人画的是同一头
动物。

## 归约视角：证明的化简

对应不止于静态形状，还延伸到**动力学**：β 归约
`(λx.t) u → t[u/x]` 对应 Prawitz 的证明化简——「→i 紧跟 →e」
的冗余推导段可以直接消除（引入又消除=白做）。完整的规则族
（每个连接词一对）构成**正规化**：任何证明都能化简到没有
「引入后立即消除」的**正规形**。正规形的结构定理（本章的
canonical forms 是其特例）是直觉主义证明论的发动机：

- 正规闭证明的主连接子必是引入规则（消除规则永远「在内部」）；
- 由此自动流出 DP、以及存在性质 EP（∃ 的闭证明携带见证——
  FOL 版的同款定理，16 章会用到它的语义对照）。

归约的强正规化（任意归约序列终止）是 typetheory 教程的机器
 flagship；本章不做、引用衔接。值得注意的是「正规化作为
证明化简」给了数学实践一个解读：**数学证明里「先引入假设再
立即撤掉」的迂回段落是可消除的噪音**——化简后的证明是
「更直」的证明。Prawitz 文集把这发展为「推理的意义=其正规
形的行为」——proof-theoretic semantics 的纲领。

## STLC：对应的最小机器化载体

要机器化「闭证明的形状」推理，需要一个显式的项语言。本章用
STLC（简单类型 λ 演算）+ 求和类型的机器（`examples/12_ch/`
四通道）：

```text
项 t ::= x | λx.t | t t | inl t | inr t | case t of inl x → t | inr x → t
类型 T ::= 基类型 | T → T | T ∨ T
```

（`ex12_ch.v` 里是 `var / tlam / tapp / tinl / tinr / tcase`
六个构造子；typing 是「环境+项+类型」的三元归纳关系。）关键
定义两个：

- **值**（value）：λ、inl、inr 开头的项——「已完工的证明」；
- **中性项**（neutral）：var 开头、或 app/case 的主项是中性——
  「卡住的证明」（等待一个永远不会来的输入）。

DP 的证明论路线三步：**正规化**（任意证明可归约到不含「消除
紧跟引入」的正规形——β 归约的尽头）→ **正规值分类**（闭正规
证明的主连接子必是引入规则）→ **DP**。本章机器化后两步；
强正规化定理属元理论（typetheory 教程对应章有完整机器版），
文档化衔接。

## 机器化的两个 canonical forms

```
canonical_arrow   闭值 : T1→T2  必是 λ
disjunction_property  闭值 : T1∨T2 必单侧且携带子证明
```

证明的骨干是**闭中性项不存在**（`neutral_not_typed_nil`）：
中性项的头部变元在空环境无 `get`——类型化直接不可能。于是
闭的值类证明只剩 λ/inl/inr 三形，inversion 完成 DP。
`canonical_arrow` 是热身版（同构论证、更少的构造子），
`disjunction_property` 是正片：

```text
DP 的完整断言（Coq 版签名）：
  forall t T1 T2, type [] t (TOr T1 T2) ->
    value t -> (exists t', t = tinl t' /\ type [] t' T1)
                \/ (exists t', t = tinr t' /\ type [] t' T2)
```

注意结论不只是「t 单侧」——还**携带子证明 t' 与其类型**。
这是构造性的精髓：知道「存在」不够，要能**取出**。对照
04/11 章的语言：LEM 若在直觉逻辑可证，DP 会立刻给出 p 或 ¬p
之一的闭证明——而 13 章的 Kripke 反模型说这不可能。DP 与
Kripke 反例是同一个事实的**证明论侧/语义侧**两副面孔。

## 四家分工

| 通道 | 内容 |
|---|---|
| Coq/Rocq | 完整 STLC+case（六条 typing 规则含分支代入环境）+ 中性/值分类 + 双 canonical |
| Agda | 骨架（五条规则）+ Lookup 自带 + DP 的模式匹配内核（`v-lam ()` 空模式一击必杀） |
| Lean | 完整同构 + `cases ht with | tapp h1' _` 命名绑定 |
| HoTT | `destruct t` 直收 DP（sum 构造子即单侧证据）+ 截断破坏 DP 的文字边界 |

Agda 的「空模式一击必杀」值得展开：闭中性项不存在的引理，
在 Agda 里写成对 lookup 空表的模式匹配——`lookup () []` 直接
用空模式（absurd pattern）关闭，连证明体都不用写。这是
「不可能的数据形态」被类型系统吸收的极致形态；Coq/Lean 里
对应物是 inversion + 区分构造子。

## HoTT 的观点：截断正是丢标签

`∥A+B∥` 的 elim 只能往 h-level 1 目标走——「提取 inl/inr」的
非命题性目标被**类型系统**禁止。DP 是**未截断**证明的现象；
命题化（截断）正是丢掉「哪个构造子」信息的那一步。

这个观察的分量：它解释了为什么「经典逻辑没有 DP」不只是技术
障碍——命题化的世界里，「A∨B 为真」与「A 真或 B 真」的区分
被有意抹去。LEM 在截断世界完全自洽（∥A+¬A∥ 对 mere prop A
就是普通命题）。反过来说，**DP 的存在本身证明了直觉主义的 ∨
不是经典的 ∨**：同一个符号，两个不同的语义承诺（证据携带式
真 vs 真值式真）。同伦层还有更深的一层：A+B 的 h-level 一般
高于 1，其「命题化」∥A+B∥ 与 A、B 各自命题化的析取
∥A∥+∥B∥ 的关系正是范畴论教程里讲过的「截断不保持和」——
完整的一致化不存在性证明属同伦论，通道内文字说明。

## 本章小结

- Curry–Howard：连接词↔类型构造子、规则↔程序动作、证明检查↔
  类型检查——证明助手的合法性根源。
- ND 的框纪律 = 作用域纪律：放电即绑定。
- DP 机器化 = 闭中性不存在 + 值分类 + inversion；结论携带
  子证明（构造性的「可取出」）。
- DP 与 13 章 Kripke 反例是同一事实的证明论/语义两副面孔；
  LEM 是经典逻辑无 DP 的反例。
- HoTT：截断=丢构造子标签——「∨ 的两种语义」的类型论显影。

## 坑位速记（本章实测）

- **Coq/Rocq**：`neutral_not_typed_nil` 的签名必须
  `forall t, neutral t -> forall T, ...`——T 放 neutral **之后**
  IH 才对 T 全称（放前面 IH 固定 T 而 inversion 产生的是
  `TArrow T1 T` 形）；value/typing 构造子错位时 `inversion HT`
  直接关闭目标（无 match goal 必要）。
- **Agda**：`tlam` 的注解类型 T 与结论的 T₁ 必须同一（写成
  两个隐式会产生 unsolved meta）；DP 的子证明直接用构造子
  前提——不需要任何「搬运」辅助函数。
- **Lean**：`cases ht with | tapp h1' _` 的命名绑定比编号稳；
  `absurd ht (by intro h; cases h)` 一行处理错位。
- **HoTT**：DP 的 destruct 版本依赖 sum 的构造子穷尽——
  与 IsHProp 无关，纯归纳事实。
- **通用**：DP 的完整故事=「正规化 + 值分类」，本章只机器化
  后半——诚实记录在案；正规化的机器版在 typetheory 教程
  （强正规化章），两教程在此接壤。
