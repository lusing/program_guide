# 12 Curry–Howard 与析取性质

> 对书：Mints ch4-5（演绎项/正规化）/ Huth&Ryan §1.2 / Prawitz 文集

命题即类型、证明即 λ 项。析取性质（DP）：

```
NJp ⊢ A∨B  ⟹  NJp ⊢A 或 NJp ⊢B
```

证明论路线三步：**正规化**（任意证明归约到正规形）→ **正规值分类**
（闭正规 ∨ 证明必是 inl/inr）→ DP。本章机器化后两步——
强正规化定理属元理论（见 typetheory 教程对应章），文档化衔接。

## 机器化的两个 canonical forms

```
canonical_arrow   闭值 : T1→T2  必是 λ
disjunction_property  闭值 : T1∨T2 必单侧且携带子证明
```

证明的骨干是**闭中性项不存在**：中性（var/app/case 开头）项的
头部变元在空环境无 `get`——类型化直接不可能。于是闭的值类证明
只剩 λ/inl/inr 三形，inversion 完成 DP。

## 四家分工

| 通道 | 内容 |
|---|---|
| Coq | 完整 STLC+case（六条 typing 规则含分支代入环境）+ 中性/值分类 + 双 canonical |
| Agda | 骨架（五条规则）+ Lookup 自带 + DP 的模式匹配内核（`v-lam ()` 空模式一击必杀） |
| Lean | 完整同构 + `cases ht with | tapp h1' _` 命名绑定 |
| HoTT | `destruct t` 直收 DP（sum 构造子即单侧证据）+ 截断破坏 DP 的文字边界 |

## HoTT 的观点：截断正是丢标签

`∥A+B∥` 的 elim 只能往 h-level 1 目标走——「提取 inl/inr」的
非命题性目标被**类型系统**禁止。DP 是**未截断**证明的现象；
命题化（截断）正是丢掉「哪个构造子」信息的那一步。
（完整的一致化不存在性证明属同伦论，通道内文字说明。）

## 坑位速记（本章实测）

- **Coq**：`neutral_not_typed_nil` 的签名必须 `forall t, neutral t -> forall T, ...`——T 放 neutral **之后** IH 才对 T 全称（放前面 IH 固定 T 而 inversion 产生的是 `TArrow T1 T` 形）；value/typing 构造子错位时 `inversion HT` 直接关闭目标（无 match goal 必要）。
- **Agda**：`tlam` 的注解类型 T 与结论的 T₁ 必须同一（写成两个隐式会产生 unsolved meta）；DP 的子证明直接用构造子前提——不需要任何「搬运」辅助函数。
- **Lean**：`cases ht with | tapp h1' _` 的命名绑定比编号稳；`absurd ht (by intro h; cases h)` 一行处理错位。
- **通用**：DP 的完整故事=「正规化 + 值分类」，本章只机器化后半——诚实记录在案。
