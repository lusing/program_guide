# 第 41 章 归约分解：抽象归约系统

> 对书：Ernst Zimmermann《Decomposition of Reduction》（Prawitz 祝贺
> 卷第 11 篇）。机器件：`examples/41_ars/ex41_ars.v` 与 `.lean`。

证明论里「合流」与「终止」的定理从来都是对**任意**抽象归约系统
（ARS）陈述的——→ 只是 A×A 上的一个关系。Zimmermann 本篇的方法论
正在于此：把合流/终止的证明**分解**成小子系统的证明加一张交换图
，全部推理留在抽象层。本章把这套元理论装进一个 3 点 ARS 的完全枚
举器：512 个关系全体过筛，经典引理变成**穷举式机器证明**，假设的
必要性变成**现场抓拍**。

## 41.1 ARS 与五件检查器

ARS = (A, →)。3 点宇宙上关系是 9 位掩码（`step R x y` 读第 3x+y 位
），全部 512 个关系就是整个样本空间。`ex41_ars.v` 的检查器五件：

| 检查器 | 定义 | 备注 |
|---|---|---|
| `reach R x` | →* 可达闭包 | 4 轮不动点迭代即饱和（3 点） |
| `terminatingR` | 无 x→⁺x（无环） | 有限集上终止 ⟺ 无环 |
| `locallyConfluent` | 一步分叉 y,z 可联接 | 经 →* 闭包 |
| `confluent` | →* 全对可联接 | joinable = ∃w 双方可达 |
| `commutes` | R1 一步与 R2 一步可换 | Hindley-Rosen 意义：经闭包交换 |

合流的定义取标准形：∀x, ∀y,z ∈ →*(x)：∃w∈→*(y)∩→*(z)。

## 41.2 Newman 引理的穷举式机器证明

定理 3（Newman）：**终止 ∧ 局部合流 ⇒ 合流**。Huet 的良基归纳证
法（对「x 的归约树高度」归纳、反证找极小反例）是证明论的教科书段
落。机器侧的版本更直接——3 点宇宙的**完全枚举**：

```coq
Example newman_exhaustive :
  forallb (fun R => implb (andb (terminatingR R) (locallyConfluent R))
                          (confluent R)) allRels
  = true.
```

512 个关系逐个核验，零反例。这是「机器证明」最朴素的形态：样本
空间有限时，全称命题就是一张可以数完的表。

更有趣的是机器**顺手多送的**一条（电二）：

```coq
Example lc_implies_conf_3 :
  forallb (fun R => implb (locallyConfluent R) (confluent R)) allRels
  = true.
```

在 3 点上，**局部合流自己就推出合流**——终止假设是多余的！这不是
Newman 的反例缺失，而是小宇宙的几何：经典的「LC 但不合流」反例
（如 a→b, a→c, b→a 型的摆动圈）需要 4 个点才摆得开，3 点装不下。
教科书不会告诉你这件事，枚举器免费赠送。

## 41.3 归约分解：定理 5 与 Hindley-Rosen

本篇的正题是两张转移图：

- **定理 5（合流转移）**：若存在 ⊐ ⊇ →，⊐ 合流且与 → 交换，则 →
  合流；
- **定理 6（终止转移）**：若 ⊐ 合流、终止且与 → 交换（Zimmermann
  的特定交换图：⊐ 一步可被 →ⁿ·⊐·→ᵐ 吸收），则 → 终止。

定理 5 的引理内核是 Hindley-Rosen 引理：两个**各自合流**且**互相
交换**的关系，其并仍合流。机器版把整个论域扫了一遍（电三）：

```coq
Example hindley_rosen_exhaustive :
  forallb (fun p => ...   (* 512×512 全部对 *)
    implb (andb (confluent R1) (andb (confluent R2) (commutes R1 R2)))
          (confluent (unionR R1 R2))) ...
  = true.
```

262144 对 (R1,R2) 逐对核验——「合流+合流+交换 ⇒ 并合流」在 3 点宇
宙无例外。（这是全章最贵的一条断言：Coq 的 vm_compute 与 Lean 的
native_decide 都要跑一阵；算术是干净的 512×512×合流检查。）

**假设的必要性**由电四现场抓拍：R1={0→1}、R2={0→2}——各自合流
，但**不交换**（0 的两条出边 1、2 无处汇合）；其并 0→1, 0→2 既不
局部合流也不合流。三个假设缺一个，结论立刻塌——「假设必要性」不
再是习题，是一行 `= true` 的合取。电五给正样本：R1={0→1,1→2}、
R2={2→1}——交换 vacuous 成立（没有点同时有 R1、R2 出边），并
0→1→2→1 带圈仍合流。

定理 6 的终止转移依赖 Zimmermann 的**特定**交换条件（不是定理 5
的那张图），其逐案检查属文献线；IL/ILL 的应用（下节）走的就是定
理 6 的通道。

## 41.4 应用到自然演绎：严格局部合流

本篇的另一半在 IL/ILL 的自然演绎上：**严格局部合流**（strictly
locally confluent）——分叉后一方**一步**就并入另一方的 →* 图。书
中把直觉逻辑全部联结词的绕道/换位红ex逐案验证（cut 段的度 d、长
度 k 为度量），ILL 同构（重复来自「语境对」而非假设集）。三件值
得记住的机制：

- **换位归约先压平**：极大段 (A₁,…,Aₙ) 若 n>1，先做 permutative
  conversion 压成单段，再对单段做主归约——这是「分解」思想在推导
  内部的镜像；
- **析取/存在消去的复制账**：∨E 换位时副推导被复制 k=|[A]| 次，
  分解图里体现为并集中一方的多步；
- **度量合成的加法性**：D→D′ 需 |D′|<|D| 时 k 步复制让合成步数精
  确相加——Zimmermann 的图证明为什么「严格局部」比「局部」好用
  （一步并图免掉 Newman 的终止依赖）。

我们的第 15 章（(k,n) 字典序）与第 34 章（GE 绕道）已经把这套机
制的样本面机器化；本章的 ARS 层给出它们的公共骨架：**一切「先换
位后消去」的程序都是定理 5/6 分解图的实例**。

## 坑位速记（本章实测）

- **Definition...with 不合法**：`with` 只跟 Fixpoint；非互递归的
  两半拆成两个 Definition（reachNoSelf 先行）。
- **定义顺序**：`reach` 用了 `remove_dup` 而其定义在后——Coq 不做
  前向引用，报「reference not found」于调用点。
- **重量账的通道分工**：512×512×合流检查在 Coq vm_compute 里要跑
  分钟级；Lean 决定性例子直接 native_decide（kernel 归约会超心跳
  ）。穷举断言的写法要预估成本再选通道。
- **Lean 管道占位**：`reach R y |>.contains w` 解析成 `reach R
  (y|>…)`——括号 `(reach R y).contains w`；燃料 `n + 1` 命名（五
  现的老坑）。
- **「先跑再写」再立功**：电二（3 点上 LC⇒Conf）不是设计出来的
  是枚举器跑出来的免费定理——穷举器值得多问一句「把假设去掉还成
  立吗」。

## 小结

把证明论的合流/终止定理放到抽象层，它们就变成可以**完全枚举**的
组合命题。3 点宇宙里：Newman 成立、Hindley-Rosen 成立、假设的必
要性一目了然，还白捡一条「3 点上局部合流即合流」。Zimmermann 的
分解方法——把大系统的元性质拆成小子系统加交换图——是全章的方
法论主角：它既是书中 IL/ILL 逐案证明的引擎，也是本教程所有「先
换位、后收缩」机器件的公共名字。
