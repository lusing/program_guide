第 20 章把矢列演算的**推导**做成了机器对象；这一章换一个方向——
**语言本身**是可塑的。EFT 第 VIII 章的中心问题是：换一套符号集 S，
表达力会不会变？答案分四层：词项可以化简（每个公式等价于一个
term-reduced 的）、符号集可以互相翻译（语法解释）、定义性扩张是
保守的（加定义不加定理）、每个公式可以放到标准形状（范式）。机器
化的策略与 20 章相反：那边是**证明对象**，这边是**可计算对账**——
把「等价」落在具体有限结构上逐点验证，一般定理保持文档级。

## 一、有限结构上的 FOL 求值器

一切对账的地基是一个直接递归的求值器：论域 `D` 是 nat 的有限表，
函词与关系按符号编号查解释表，量词枚举论域：

```coq
Fixpoint evf (f : interp_fn) (r : interp_rel) (D : list nat)
    (β : nat -> nat) (φ : fm) : bool :=
  match φ with
  | rat s ts => r s (map (evt f β) ts)
  | eqf t1 t2 => Nat.eqb (evt f β t1) (evt f β t2)
  | neg ψ => negb (evf f r D β ψ)
  | disj ψ χ => orb (evf f r D β ψ) (evf f r D β χ)
  | exq x ψ => existsb (fun a => evf f r D (bump β x a) ψ) D
  | allq x ψ => forallb (fun a => evf f r D (bump β x a) ψ) D
  (* conj/imp 同构，本章直连全连接词 *)
  end.
```

现场结构 S₃：论域 {0,1,2}，f=环绕后继，g=环绕前驱（f∘g=恒等！），
R₀=标准 <，R₁=相等，R₂=按定义扩张出来的 ≤。注意 15 章的 FOL 语义
是**抽象结构+满足关系证明**，这里是**具体结构+布尔求值**——两个
层面在 25 章（EF 博弈）还会合流。

## 二、词项化简：嵌套函数拍平成等式链

书 Thm 1.2：每个公式等价于一个 term-reduced 的——原子式里最多一个
函数符号在顶部。招牌例子：

$$\forall x\, fgx \equiv y \;\Longleftrightarrow\; \forall x \exists u\,(gx \equiv u \wedge fu \equiv y)$$

机器版在 S₃ 上对账：`fg = f∘g = 恒等`（环绕后继∘环绕前驱），所以
左边说「y 等于一切元素」——假；右边的见证 u 被 gx≡u 钉死为 prev(x)，
于是 fu≡y 逼出 y=x——同样假。**两式逐赋值同值**：

```coq
Example tred_ex_equiv : satis3 (iff_form orig_ex tred_ex) = true.
Proof. reflexivity. Qed.
```

第二个例子取 `∃x f(fc)≡x`——恒真（见证就是 f(fc) 自己）——化简式
`∃x∃u(fc≡u ∧ fu≡x)` 同真。一真一假两个方向都对上了，翻译保真才
算有证词。诚实说明：通用的递归翻译器（任意深度嵌套逐层拆）在 Coq
的 guard 检查下不可直写——`fsym` 挂着 `list tm`，元素不是结构子项
（与 20 章 substt 同病）——示例对手工内联，一般定理（书 Thm 1.2 的
完整证明走联立代入归纳）记文档级。

## 三、定义扩张：≤ 是 < 加等号

书 VIII.2.B 的引导例：给序语言 {<} 加一个 ≤，定义公理

$$\delta_{\le} := \forall x \forall y\,(x \le y \leftrightarrow (x < y \vee x \equiv y))$$

机器现场：S₃ 的 R₂ 解释**按定义**取 `a<b ∨ a=b`，于是 δ≤ 在 S₃ 上
成立（`delta_le_holds`）。VIII.3 的三条性质里机器做 E2（消去）：翻译
`elim_le` 把每个 ≤-原子换成定义体，三个用 ≤ 的公式 χ₁χ₂χ₃ 与其消去
像逐赋值同值：

```coq
Fixpoint elim_le (φ : fm) : fm :=
  match φ with
  | rat 2 [t1; t2] => disj (rat 0 [t1; t2]) (eqf t1 t2)
  | ...（其余结构递归）
  end.
```

E1（保守性）的机器脚印：≤-free 的公式在 `elim_le` 下不动（翻译是
恒等）——加定义对原语言的句子零影响。E3（消去尊重理论）与书里的
一般定理（定义扩张的消除定理 3.2——Beth 可定义性的用法见书 Exercise
3.5）记文档级。

## 四、⟨Φ⟩ 范式：析取合取形

VIII.4 的两步：4.1 引理说「两个结构在原子集 Φ 上逐点一致，则在
⟨Φ⟩（Φ 对 ¬ ∨ 封闭的最小类）上一致」；4.2 说 ⟨Φ⟩ 的成员都等价于
**文字行的析取**——每行是各原子取正/负的合取，至多 2ⁿ⁺¹ 行。机器
面：命题骨架（原子用命题变元 `rat i []` 化身——绕开嵌套类型的结构
相等判定，见坑位），8 个赋值全枚举，`dnf_of` 从满足行生成范式：

```coq
Definition dnf_of (φ : fm) : fm :=
  match filter (fun βv => peval βv φ) betas8 with
  | r0 :: rest => fold_right disj (row_conj r0) (map row_conj rest)
  | [] => neg (eqf (var 0) (var 0))   (* 无满足行：矛盾式的范式 *)
  end.
```

三个 ⟨Φ⟩ 成员（含 → 的 member1、含 ∧¬ 的 member2、否定开头的
member3）都与自己的 DNF 在全部 8 个赋值下同值。这就是 4.2 的
「有限多个不等价类」在机器上的样子：真值表即等价类。

## 五、ZF：公理作为一阶句子

§VII.3 的主张「数学在一阶逻辑框架内」的最小现场：把 ∈ 当二元关系
符号（编号 4），四条公理直接写成公式——外延（同元素则相等）、
配对（存在恰好含两元的集合并刻画其成员）、并集（存在包含所有
∪-成员的集）、分离的一个实例（对固定 φ 的模式化身）。冒烟：外延
公理在「单点域+空∈」结构里成立——唯一元素与自己同成员，推出它
等于自己。分离模式的一般形式（对任意 φ 的模式）与替换/无穷/幂集
公理记文档级——模式公理的「公式即数据」处理是 22 章完备性构造的
前置伏笔。

## 坑位速记（本章实测）

- **嵌套递归再临**：通用的词项化简翻译器与 tm_eqb（结构相等）都
  撞 guard 检查（`fsym` 的 list 参数）——示例对手工内联；命题骨架
  用 `rat i []` 做原子化身避免相等判定。
- **Lean 的 reflexivity/decide 不吃深匹配**：解释表用 `match s, args
  with | 0, [a] => …` 写时，`by rfl` 与 `by decide` 都卡在实例归约
  （match 编译成的依赖 elim 阻塞 Decidable）——`by native_decide`
  一次全过（编译成 IR 求值）。Coq 侧 reflexivity 无此问题。
- **Bool 等值别用 =?**（nat 的 eqb）——`Bool.eqb`（Coq）/`==`
  （Lean 的 Bool）。
- **语义先算再讲**：化简对账的「一真一假」两例是翻译保真的双向
  证词——只验一个方向不算数（假方向的等值恰好说明翻译没把信息
  弄丢也没引入）。

## 小结

这一章把「语言的可塑性」做成了可计算的对账：化简翻译保真、定义
扩张可消去、范式存在——三件事在有限结构上逐点验证，一般定理的
证明思想（联立代入归纳、消除引理、枚举赋值）在正文讲清。ZF 公理
的现场化是「一阶逻辑作为数学底座」的第一块砖。下一章进入本书的
皇冠：完备性定理——可靠方向的证明机器化已经就位，现在把 Henkin
构造的**另一侧**（协调必有模型）做实。
