第 26 章用紧致性造出了「无法用单个句子定义有限性」的 σₙ 族，第 27 章把初等等价变成了 EF 博弈的赢策略。这一章回答一个更早就该问的问题：
**给定一个公理集 Γ，怎么知道它「说完了」——对每个句子 φ，Γ 要么
证出 φ 要么证出 ¬φ？** 这就是**完备性**（completeness，注意与哥德尔
完备定理的「完备」同词不同义：前者是理论的性质，后者是证明系统的
性质）。Marker ch 5 的答案分成三步：κ-范畴性 ⟹ Vaught 测试 ⟹
DAG/ACF 完备 ⟹ 可判定性；再往深处走一步，就是 Ax 的「多项式映射
单射必满射」——用有限域+紧致性证明一条关于 ℂ 的定理。最后，随机
图的 **0-1 律**把「完备」变成一句概率论的话：每个句子的极限概率
只能是 0 或 1。

## 一、完备理论：什么叫「说完了」

**定义（完备理论）**：理论 T（句子的集合）是**完备的**，如果对每个
句子 φ，要么 T ⊨ φ，要么 T ⊨ ¬φ。

等价说法（书 Prop 5.6 区）：T 完备 ⟺ T 的任意两个模型初等等价。
第 26 章已经见过这个概念的身影——`(ℚ,+) ≡ (ℝ,+)` 当时是靠「两
边都是无挠可除阿贝尔群」直接验证的；这一章把它变成定理。

完备性为什么值得追求？书里给出一条最实用的推论：**完备 + 公理集
递归可枚举 ⟹ 可判定**（Cor 5.13 区）。理由：给定句子 φ，同时枚举
T 的公理推演 φ 与推演 ¬φ 的两个方向——完备性保证其中一方终将
命中，停机给出答案。这是「T 的理论问题可判定」的标准路线，比逐
个模型检查便宜得多。反过来，Th(ℕ) 不可判定（48 章）恰恰因为
Th(ℕ) 虽完备但**不可递归公理化**。

## 二、κ-范畴性与 Vaught 测试

**定义（κ-范畴）**：T 是 **κ-范畴**的，如果 T 的任意两个基数 κ 的
模型都同构。

两个经典事实（书 Prop 5.8/5.9）：

- **DAG**（无挠可除阿贝尔群理论）对所有 κ>ℵ₀ 范畴。证明的代数
  骨架：DAG 的模型就是 ℚ-向量空间——可除给出「g/n」的唯一性，
  无挠保证良定义；两个 ℚ-向量空间同构 ⟺ 维数相同；不可数基数 κ
  的空间维数 = κ。于是维数这个**代数不变量**吃掉了全部模型差异。
- **ACF_p**（特征 p 的代数闭域理论）对所有不可数 κ 范畴。同构
  不变量是特征+超越度；代数闭包把超越度以上的部分完全焊死。

注意 ℵ₀ 处两者都**不**范畴：可数维 ℚ-空间有维数 1,2,3,…,ℵ₀ 无数
多种；ℚ̄ 与 ℚ̄(t) 的代数闭包也不同构。范畴性是「大基数处的刚性」。

**定理（Vaught 测试，书 Th 5.10）**：若 T 无有限模型、κ ≥
max(|L|,ℵ₀) 且 T 是 κ-范畴的，则 T 完备。

证明只有三行，但每行都是前两章的积累：若 T 不完备，取 φ 使
T∪{φ} 与 T∪{¬φ} 都可满足；两者都无有限模型，由向上 L-S（26 章
Th 5.5 的影子）各取基数 κ 的模型 M₀、M₁；κ-范畴性给 M₀ ≅ M₁，
同构保持一切句子真值（17 章深化的「同构 ⟹ 初等等价」），与
M₀⊨φ、M₁⊨¬φ 矛盾。

「无有限模型」不可省：书上的反例是每个元素阶都为 2 的阿贝尔群
理论——它对所有无穷 κ 范畴，但句子「存在 3 个不同元素」在二元
群假、在大群真。

机器面把 DAG 的代数骨架压到 F_p 上验证（ℚ 换成 F_p：向量空间
结构完全平行，且**可枚举**）。「维数定同构」的有限影子是：F₃²
上的换基映射是全空间的一个排列：

```coq
Definition vaddp (a b : nat * nat) : nat * nat :=
  ((fst a + fst b) mod 3, (snd a + snd b) mod 3).
Definition smulp (k : nat) (v : nat * nat) : nat * nat :=
  ((k * fst v) mod 3, (k * snd v) mod 3).
(* v = a·e0 + b·e1 ↦ a·w0 + b·w1：基 e0,e1 ↦ w0=(1,0), w1=(1,1) *)
Definition iso2p (w0 w1 v : nat * nat) : nat * nat :=
  vaddp (smulp (fst v) w0) (smulp (snd v) w1).
(* 换基映射是 F_3^2 的排列 *)
Example iso2_perm : nodupb2 (map (iso2p (1,0) (1,1)) Vs2) = true.
Example iso2_len : length (map (iso2p (1,0) (1,1)) Vs2) = 9.
(* 负面对照：非基向量组 w0=w1 塌缩——不是排列 *)
Example iso2_bad_not_perm : negb (nodupb2 (map (iso2p (1,0) (1,0)) Vs2)) = true.
```

`nodupb2` + 长度守恒 = 排列（有限集上的单射即双射——这正是 Ax
定理在有限域上的原形，见下节）；负面对照说明「维数定同构」的
前提是**基**——无关向量组把 9 个点塌缩到 3 个。完整代码见
`examples/28_categoricity/ex28_categoricity.v` 第一节。

## 三、Ax 定理：从有限域「平均」到 ℂ

**定理（Ax，书 Th 5.16）**：多项式映射 f: ℂⁿ → ℂⁿ 若单射，则满射。

这条定理惊人的地方在于证明路线完全离开 ℂ：单射性是一条一阶句子
（∀x̄∀ȳ f(x̄)=f(ȳ)→x̄=ȳ），满射性的否定也是（∀表决「差一个点」
可以省略：对每个多项式映射，∃ 表「像缺一点」）。若它在 ℂ 假，
紧致性（26 章）给出有限子集的要求；关键引理（书 Cor 5.15）：一条
多项式恒等式（如 f 的分量间的关系式）在 ℂ 成立 ⟺ 在每个特征 0
的素域 ℚ 成立 ⟺ 在「几乎所有」有限域 F_p 成立——素特征足够多的
地方成立就能抬回特征 0。而**在有限域上，「单射 ⟹ 满射」是鸽笼
原理**：F_pⁿ 只有 pⁿ 个点，单射自映射没有理由不满。于是反例在
每个有限域上都活不下去，紧致性把矛盾送回 ℂ。

机器面在两个层面留脚印：

**第一层（有限域鸽笼）**：x ↦ x³ 在 F₅ 上单射（gcd(3,4)=1），
全表验证它是排列；在 F₇ 上**不**单射（gcd(3,6)=3：1³=2³=1）。
「x³ 是否单射」随 p 的算术性质起伏，但「单射⟹满射」在两侧都成立
——因为它根本是有限集的鸽笼：

```coq
Example ax_f5_inj : inj_cubic 5 = true.
Example ax_f5_surj : surj_cubic 5 = true.
(* p=7：3 | 6，1^3 = 2^3 = 1——不单；像=三次剩余子群——也不满 *)
Example ax_f7_notinj : negb (inj_cubic 7) = true.
Example ax_f7_notsurj : negb (surj_cubic 7) = true.
(* p=11：gcd(3,10)=1——单且满；p=13：3|12——两皆不成立 *)
Example ax_f11_inj_surj : andb (inj_cubic 11) (surj_cubic 11) = true.
Example ax_f13_both_fail : negb (orb (inj_cubic 13) (surj_cubic 13)) = true.
```

**第二层（特征迁移表）**：x³ 在素域 F_p 上单射 ⟺ 3 ∤ p−1。枚举
p=2..19 打表（`inj_cubic` 随 p 的真值），素数行干净地落在「p≡1
(mod 3) 失败」的规律上；合数行（如 p=4、8）因为 mod 8 根本不是域，
规律立刻散架——这张表本身就是「域公理在说话」的证据。单射性是
一阶性质，它在有限域族上的真值分布就是 Ax 证明里「除有限多个 p
外成立」的数值缩影；证明的紧致性骨架（ℂ 反例 → 恒等式的有限要
求 → 素特征抬升）在文档线讲清，机器面不假装能对 ℂ 穷举——这正
是 29 章超积要正面处理的对象：**对一族结构「平均」**是超积的天职。

## 四、随机图与 0-1 律

最后一块拼图来自组合侧。固定语言 L={E}（单个二元关系），在 n 个
顶点上**均匀随机**取一张图：每条边独立以概率 1/2 出现。对任意固定
句子 φ，令 μₙ(φ) 为随机图满足 φ 的概率。

**定理（0-1 律，书 Th 5.21 区）**：对每个句子 φ，lim μₙ(φ) 存在
且等于 0 或 1。

书里的证明走**扩张公理**（extension axioms）：σ_{k,l} 说「任意 k
个不同点 x̄、与它们相邻模式为 l 指定的 y 恰好实现」（准确形式：
对每个 disjoint 的 k 点组与 l 条边模式，存在新点 y 按模式连边）。
每条 σ_{k,l} 在随机图中的概率 → 1（候选 y 有 n−k 个，每个命中的
概率 2^{−k}，全miss 的概率指数小）。关键的两步：**(a)** 满足全部
扩张公理的理论（随机图理论）是完备的——back-and-forth：两个可数
模型互相 forth/back 延拓部分同构，正是 27 章 `dup_wins` 策略在无穷
上的化身；**(b)** 于是任何 φ 与某条 σ_{k,l} 在随机图理论中可证
等价（完备性二选一+紧致性），而 σ_{k,l} 概率 →1，故 μₙ(φ) → 0
或 → 1——具体是哪个，取决于 φ 本身可否由扩张公理推出。

机器面：n≤5 个点的图一共 2^{n(n−1)/2} 张（n=5 时 1024 张），
全部枚举，数「无孤立点」（σ 的最简特例 σ₁：∀x∃y E(x,y)）的比例：

```coq
Fixpoint bits (m : nat) : list (list bool) := ...
Definition no_isolated (n : nat) (b : list bool) : bool := ...
(* n=2..5 的分子（分母 2^m = 2,8,64,1024）：1/2, 4/8, 41/64, 768/1024 *)
Example frac_sigma1_table : map fracnum [2;3;4;5] = [1;4;41;768].
```

频率**递增**趋 1（期望孤立点数 = n·2^{−(n−1)} → 0，与表一致）；
补句「存在孤立点」趋 0。而一个**与扩张公理无关**的局部句子如
「恰好 3 条边」的分子是 C(m,3)（m 为边位总数），占分母 2^m 的
比例雪崩式 → 0——不同句子的极限不同，但都钉死在 0 或 1 上。
期望值先在 `.scratch` 用 `Compute` 探出再写定——**先探后写**是
26 章 iso_eex 教训的纪律。Prolog 面（`ex28_categoricity.pl`）
做同一张枚举的搜索版：`graph(N, Bits)` 生成 + `frac/3` 计数，
三通道对账。

0-1 律的哲学与 Ax 定理同源：**一阶逻辑「看不见」随机结构的局部
噪声，只看得见渐近的、概率 1 的刚性**。这句话在 31 章 o-minimality
（一阶逻辑「看不见」ℝ 的任意集合，只看得见半代数的 tame 结构）
会再出现一次——tame 与 wild 的对照是 Marker 全书的暗线，从这
一章正式开始。

## 小结

完备理论 = 把「说完了」形式化；Vaught 测试用「大基数处同构刚性」
换完备性，DAG/ACF 是教科书级的应用，机器面在 F₃²/F₅/F₇ 上留下
代数不变量与鸽笼的脚印；Ax 定理把 ℂ 上的定理拆成「有限域全真 +
紧致性回抬」，是 26 章紧致性最漂亮的一次消费；0-1 律把完备性翻译
成概率，扩张公理+back-and-forth 是 27 章博弈策略的无穷化身。下一
章正面处理这一章反复暗示的工具：对一族结构「平均」——超积与
Łoś 定理。
