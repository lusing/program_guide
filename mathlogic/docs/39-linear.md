# 第 39 章 线性逻辑的自然演绎与范畴语义

> 对书：Valeria de Paiva《Categorical Semantics of Linear Logic for
> All》（第 9 篇）＋ Ernst Zimmermann 篇的 ILL 应用面（第 11 篇）。
> 机器件：`examples/39_linear/ex39_linear.v` 与 `.lean`。

把「每个假设恰用一次」写进演算的语法，得到线性逻辑。Girard 1987
的原动力是分析直觉逻辑的证明等价类；三十年后它成了资源敏感推理
（线性 λ 演算、会话类型、量子类型论）的公共底盘。de Paiva 本篇是
一篇给逻辑学家的范畴语义巡礼——四个模型概念怎么来、差在哪、为什
么她仍推荐「最老最复杂」的那个。本章前半把 ILL 的**资源纪律**做成
证明搜索器（这部分与 Zimmermann 篇的 ILL 消归类账对接），后半沿
de Paiva 的阶梯讲范畴语义。

## 39.1 资源纪律=多重集算术

ILL 片段 {⊗,−∘,&,!} 的规则全部用多重集语言写就。`ex39_linear.v`
的语境是公式表（视作多重集），每条规则都是一次多重集算术：

| 规则 | 多重集操作 | 直觉 |
|---|---|---|
| ⊗I | 语境**分裂** Γ=Γ₁+Γ₂，各证一半 | 一份资源劈两半 |
| ⊗E | A⊗B 展开成 A、B 两假设 | 分解 |
| −∘I | 前件**恰好加入**语境 | 消耗一束 |
| −∘E | 余语境分裂：一半造 A，一半带 B | 线性应用 |
| &I | **同一语境用两次** | 加性：复制免费 |
| &E | 只取一支，另一支**不计账** | 加性投影 |
| !I | 语境**全 banged** 才能提升 | 无限资源须整存 |
| !E | 三口：降 bang／收缩（有预算）／弱化 | 花利息 |

公理也是多重集等式：`identity` 要求语境**恰为** `[目标]`——多了
少了都不行。搜索器 `der fuel budget G c` 以「恒等/右规则/左规则」
三口递归，分裂用位掩码枚举全部 2^|Γ| 种（|Γ|≤5），收缩带预算
（防 ! 的无限复制）。

## 39.2 电池：线性世界的三堵墙

可导组七件照章通过（A⊢A、A,B⊢A⊗B、A⊗B⊢B⊗A、A−∘B,A⊢B、
!A⊢A⊗A、A⊢A&A、A&B⊢A）。真正有教学价值的是**三堵墙**——直觉
逻辑里天经地义、线性世界全部倒塌：

**墙一：线性复制不存在**。`A ⊬ A⊗A`——想把一份 A 用两次，⊗I 的
分裂步就把它拆空。要复制先存款：`!A ⊢ A⊗A` 走收缩+降 bang。

**墙二：资源不能闲置**。`A,B ⊬ A−∘B`——这是本章最反直觉的一条。
「假设 A、手里还有 B，当然能造 A 蕴含 B」？不行：−∘I 把 A 放进语
境后，剩下的 B 必须被**用掉**，而目标 B 已经被前件侧「白拿」，无
处安放的 B 让公理的多重集等式失败。丢弃资源同样要 !（弱化口）。

**墙三：K 公理失效**。`A ⊬ B−∘A`——直觉逻辑（乃至 Hilbert 系统
的 K）依赖「无关假设可以不理」，线性世界直接拒绝。对照成立的是
`!A ⊢ !B−∘!A`：注意 B 也必须以 `!B` 身份进场——提升规则要求语境
**全部** banged，连「无关」的假设都要先办存款手续。

```coq
Example nder_idle_resource : derOK [A; B] (llolli A B) = false.
Example nder_k : derOK [A] (llolli B A) = false.
Example der_bang_k :
  derOK [lbang A] (llolli (lbang B) (lbang A)) = true.
```

加性与乘性的对照同样锋利：`A ⊢ A&A` 成立（&I 同一语境用两次——
**加性复制免费**），`A ⊢ A⊗A` 失败（乘性复制收费）。一句话总结
ILL：**乘性管账本怎么分，加性管选择怎么省，! 管利息怎么算**。

## 39.3 范畴语义阶梯（de Paiva 巡礼）

语法侧的每个联结词都在语义侧问「我住在哪种结构里」。de Paiva 的
阶梯四级：

**对称幺半闭范畴（SMC）**。⊗ 是张量积（带结合律与单位元的双函
子，一般**不是**笛卡尔积），−∘ 是右伴随：Hom(A⊗B, C) ≅ Hom(A,
B−∘C)——curry 化。这是 ILL {⊗,−∘} 的最小家。本章机器件里
`A⊗B ⊢ B⊗A` 的可导性就是对称 braiding 的语法影子。

\*-自守范畴。经典线性逻辑加 ⊥ 与对偶：每件事都有补，A⊥ =
A⊸⊥。Barr 的 \*-自守范畴是其语义；Seely 用它给线性逻辑建模型时
发现了一个尴尬——**语法里合法的等式，语义里对不上**。

**线性范畴（Lafont 模型）**。关键升级：! 不能只是「指数」，必须
带**群语义**——!A 上有自然的交换幺半群结构（收缩=!A→!A⊗!A 的
comonoid 余乘），且这个结构与任意映射相容。Lafont 的观察：这个
「免费 comonoid」条件让语法的证明等式与范畴的态射等式严格对齐
——直觉逻辑里对 ∧/∀ 良性的同构（如 A⊗B ≅ B⊗A 的 coherence）
不再捣乱。

**Seely 范畴。**用「线性范畴+笛卡尔闭范畴+两个函子对接」的方案
：! 把线性世界映到笛卡尔世界、Girard 的翻译把直觉逻辑嵌进来。
表面上更好用——de Paiva 的评语是它「模型更多、更易懂」，但
Seely 模型里证明的相等比 Lafont 模型**粗**（某些语法上不同的证
明被认成同一个态射）。

de Paiva 的裁决：**要语法↔语义的对应最紧，选线性范畴**——尽管它
更老、更难。她的理由是证明论者的理由：模型的价值不在多，而在
「每个方程都说得清是哪条证明等式」。这条裁决与本教程的主题（证
明是对象，等式是数据）一脉相承——第 35 章 Urban 引用的「从语义
观点说得通的怪规则」正是这类范畴方程的语法投影。

Zimmermann 篇的 ILL 部分（第 41 章正面展开其一般理论）把 ILL 自
然演绎的归约分解成「严格局部合流」可用的子系统——乘性蕴含按直
觉蕴含处理（重复来自**语境对**而非假设集）、加性合取按直觉合取
、⊗ 与 ⊕ 按析取的换位路线。本章搜索器的多重集算术正是这套归约
可定义性的地基：能导=有归约可终止的推导。

## 坑位速记（本章实测）

- **Coq 互递归降参**：der → rightRules 必须传 **k**（不是 fuel）
  ——传满额被 guard 拒；非递归的 identity/包装函数（subOf）必须
  拆出互组。
- **递归 Definition**：`rmv1` 自递归却写成 Definition——Rocq 直接
  "reference not found"（同一文件内后向引用失败，报错位置迷惑）。
- **let 作用域**：`existsb (fun m => let rest := … in …) (…
  (lengthG rest))`——rest 出了 lambda 作用域；let 提到 existsb 外。
- **漏 &E**：初稿左规则没有 & 的投影分支，`A&B⊢A` 失败——「加性
  丢弃不计账」必须显式立法，否则加性合取在搜索器里形同虚设。
- **K 公理对照样本**：`!A ⊢ B−∘!A` 是**错**的样本——裸 B 进不了
  提升语境；正确对照是 `!A ⊢ !B−∘!A`（B 也要 banged）。样本期
  望先手推再落码。

## 小结

线性逻辑把「用了几次」从元理论拖进演算：乘性分账、加性省账、
! 算利息，K 公理与资源闲置一起倒塌。范畴阶梯则给这套语法配了四
级语义住宅——de Paiva 的结论是老宅（线性范畴）隔音最好：每个等
式都能听清对应哪条证明。本章搜索器 150 行，把「线性=多重集算术」
这句话变成了可向机器提问的判定器。
