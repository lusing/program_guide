# 第 34 章 广义消去规则与高层次规则

> 对书：Schroeder-Heister《Generalized Elimination Inferences, Higher-Level
> Rules, and the Implications-as-Rules Interpretation of the Sequent
> Calculus》（Prawitz 祝贺卷第 1 篇）。
> 机器件：`examples/34_ge/ex34_ge.v` 与 `ex34_ge.lean`（双通道同构）。

自然演绎的教科书版式里，每条消去规则都长得不一样：合取有两个投影
（∧E₁/∧E₂），蕴涵是肯定前件（→E），析取却是一个带两个副前提的「分
情况」规则（∨E）。Prawitz 的老师辈直觉是：**析取消去才是范式**——
它把「从 A∨B 能推出什么」说成「凡是从 A 可推、从 B 也可推者，从
A∨B 皆可推」。Schroeder-Heister 在本篇把这条直觉推到尽头：让**每
个**联结词的消去规则都长成 ∨E 的样子（广义消去，generalized
elimination），并为此付出一个惊人的代价——为了给 → 写出广义消去，
你必须在前提里**假设一条规则**，于是「规则」本身成了可以被假设、
被卸除的实体：这就是高层次（higher-level）自然演绎。

## 34.1 从 (cE) 模式说起：消去 = 定义条件的后承之交

设联结词 c 有 m 条引入规则，第 i 条引入规则的前提结构记为
βᵢ(A₁,…,Aₙ)。广义消去模式是一条统一的大纲：

- **(cI)**：βᵢ(A₁,…,Aₙ) 各前提 ⊢ c(A₁,…,Aₙ)（i = 1..m）；
- **(cE)**：从 c(A₁,…,Aₙ)，以及每个 [βᵢ] 下的一支副推导 ⊢ C，得 C。

两种读法等价。**定义读法**：引入规则是 c 的「定义」，消去规则说的是
「凡从每个定义条件可推者，从 c 亦可推」——Gentzen 1936 年「引入近
乎定义」的正式化。**公共内容读法**（作者本人偏爱）：c(A₁,…,Aₙ) 表达
的是 β₁,…,βₘ 的**公共内容**——c 的后承集恰为诸 βᵢ 后承集之交。
本章机器件把这个「交」直接做成了可执行的翻译函数（见 34.4）。

对 ∧ 与 →，模式落地为：

```
A  B                A∧B  [A B]                A→B  [A⇒B]
──── (∧I)           ───────────── (∧EGEN)     ────────── (→EHL)
A∧B                    C                        C
```

∧EGEN 是层 3 规则（卸除两个公式假设）；而 →EHL 的副前提假设的是
**规则 A ⇒ B**（不是公式！）——「B 已从 A 推出」与「从 A 到 B 的规
则已经确立」是同一件事的两种说法。规则假设的出现把演算的层次抬了
一级：层 1 = 公式；层 α+1 = (R₁,…,Rₙ) ⇒ A，其中 Rᵢ 是层 ≤α 的规
则。→EHL 卸除一条层 2 规则，自身是层 4。标准自然演绎的全部规则都
在层 ≤3——**层 3 = 标准层，层 ≥4 = 真高层次**。

机器件把这套体系压进一个推导 AST。`ex34_ge.v` 的语境条目有两种
（`EF a` 公式假设 / `ER a b` 规则假设 a⇒b），规则假设只能通过应用点
`dRule x y d1` 显形——「应用一条规则=同时假设它」的形式化：

```coq
Inductive entry := EF (a : form) | ER (a b : form).

Inductive der :=
| dHyp (a : form)                    (* 公式假设 *)
| dRule (x y : form) (d1 : der)      (* 用规则假设 x⇒y：d1 : x ⊢ y *)
| ...                                (* 三套消去系统并存 *)
| dAndGEN (d0 d : der)               (* ∧EGEN *)
| dImpSL (d0 d1 d : der)             (* →ESL *)
| dImpHL (d0 d : der).               (* →EHL *)
```

类型检查器 `typeOf` 一遍读完三套系统：`dImpHL` 分支给副前提的语境
**加的是 `ER x y`**——这是全章「高层次」三个字在代码里的落点：

```coq
| dImpHL d0 d =>
    match typeOf G d0 with
    | [fimp x y] => typeOf (ER x y :: G) d   (* 规则进入语境！ *)
    | _ => [] end
```

## 34.2 标准层对手：→ESL（Dyckhoff/Tennant/López-Escobar/von Plato）

不给 → 上层 4 规则的替代方案是把 ∨E 的「平行」形状压回标准层：

```
A→B   A   [B]
────────────── (→ESL)
      C
```

它保留广义消去的「C 重复出现在结论」的平行感，但副前提只假设公式
B，层次不抬。书 §2 的名单（Dyckhoff 1988、Tennant 1992、
López-Escobar 1999、von Plato 2001-02）说明这不是一个人的发明——
「平行化自然演绎」（Tennant 语）是同期多人的收敛选择。

三套系统在同一判断上会合。`ex34_ge.v` 电一用 p→q, p ⊢ q 的三种推导
钉死互认：

```coq
Definition mpD  : der := dMP (dHyp imp_pq) (dHyp p).
Definition eslD : der := dImpSL (dHyp imp_pq) (dHyp p) (dHyp q).
Definition hlD  : der := dImpHL (dHyp imp_pq) (dRule p q (dHyp p)).

Example three_systems_same :
  andb (wtdOK G0 mpD q)
       (andb (wtdOK G0 eslD q) (wtdOK G0 hlD q)) = true.
```

注意 `hlD`：副前提是 `dRule p q (dHyp p)`——把假设的规则 p⇒q 应用在
假设 p 上得 q。这一行是「规则作为可假设实体」的最小完整样本。

## 34.3 六个翻译：等价论证的程序化

书 §1-§4 的全部等价论证都是**替换构造**：拿到一个规则的各前提推
导，改用另一个规则拼出同一结论。替换有两种，`ex34_ge.v` 各给一个
函数：

- `substF a E d`：把 d 中公式假设 a 的出现全换成推导 E（Barendregt
  约定的教学简化版——样本避开同名再绑定）；
- `substR x y D1 d`：把 d 中**规则假设 (x⇒y) 的应用点** `dRule x y d1`
  换成 C:=y 的平凡 →ESL：`dImpSL D1 d1 (dHyp y)`。

六个翻译随即各就各位（Lean 版同名）：

| 翻译 | 方向 | 书页 |
|---|---|---|
| `mpFromEsl x y D1 D2` | →ESL ⊢ →EMP（恒等副前提即 MP） | p.23 |
| `mpDerivesEsl y D1 D2 d` | →EMP ⊢ →ESL 实例（B 假设全换 MP） | p.23 |
| `hlFromEsl x y D1 D2 d` | →ESL ⊢ →EHL（B 假设换规则应用点） | p.24 |
| `eslFromHl x y D1 d` | →EHL ⊢ →ESL（应用点全换平凡 ESL） | p.25 |
| `andFromGenL/R` | ∧EGEN ⊢ ∧E（实例化 C:=A 与 C:=B） | p.6 |
| `genFromAnd x y D0 d` | ∧E ⊢ ∧EGEN（假设换成两投影） | p.6 |

其中 `mpDerivesEsl` 的电二是替换论证最干净的一次演出——副前提
[q] ⊢ q∧q 换掉 q 假设后，**语境里不再需要 q**（输出在
`[EF imp_pq; EF p]` 下良型）：

```coq
Example mp_derives_esl :
  andb (derEqb (mpDerivesEsl q (dHyp imp_pq) (dHyp p) D3qq)
               (dAndI mpD mpD))
       (wtdOK [EF imp_pq; EF p]
              (mpDerivesEsl q (dHyp imp_pq) (dHyp p) D3qq) (fand q q))
  = true.
```

## 34.4 实例级 vs 图案级：→EHL 严格强于 →ESL

三系统「等价」要加星号。书 §3 的精细账目：

- **MP ↔ ESL：逐实例等价**（对任意固定的 A,B,C，单条规则互推）；
- **HL → ESL：逐实例成立**——把副前提里每个规则应用点换成「平凡
  ESL」（C 强制取 B）；
- **ESL → HL：必须让 C 取 B**——即只在**图案级**（C 作为可代换变
  元）成立。若 C 固定，想从 `D1 : A→B` 与 `[B]⊢C` 造 `[A⇒B]⊢C` 的
  副前提是造不出的：原文给出的失败原因——`D3` 里可能有「在 D4 才被
  卸除、但 D3 里开放」的假设，硬拆成两个独立推导会把这些假设悬空。

`eslFromHl` 的实现把「C:=B 强制」写进了代码形状——每个替换点的
输出都是 `dImpSL D1 d1 (dHyp y)`，副推导只能是 `[B]⊢B`。电二断言
`esl_from_hl_shape`：`eslFromHl` 作用在 `dRule p q (dHyp p)` 上输出
**恰好等于** `eslD`，且在**不含规则假设**的语境 `[EF imp_pq; EF p]`
下良型——HL 的推导被彻底洗成了标准层推导。

这条「实例不等价」的极限形式是 **Olkhovikov–Schroeder-Heister 不可
扁平化定理**（2011）：形如 ((A⇒B)⇒C)⇒D 的高层规则**不可能**由任何
有限组标准层规则表达。本章不机器化该定理（其证明超出教程范围），
但 34.6 的嵌套规则样本给出它的直觉面。

## 34.5 广义消去的 β：类型驱动的收缩

广义消去规则有一个被低估的工程红利：**绕道（detour）消去在 GE 形
状下是纯替换**。∧I 后接 ∧EGEN、→I 后接 →ESL/→EHL，收缩就是把引入
规则卸除的假设在副推导里替换回引入规则的前提推导——不需要 case
分析投影方向。

`ex34_ge.v` 的 `beta1` 实现里藏着一个本章实测最深的设计决策：**收
缩需要的「公式坐标」（绑定式、前后件、左右成分）在 AST 顶构造里读
不出来**，必须由类型演算 `typeOf` 在红ex现场喂入（`ty1` 取「该推导
的唯一类型，失配则回退」）。且 `beta1` 下穿引入规则时语境必须同步
扩张——`dImpI` 下穿加 `EF x`、GE 副前提下穿加 `EF x, EF y`、HL 副
前提下穿加 `ER x y`。**少加一条，内层红ex的坐标就算错**：

```coq
| dImpSL d0 d1 d =>
    match d0 with
    | dImpI x db =>
        substF (ty1 (EF x :: G) db q) (substF x d1 db) d
    | _ => (* 非红ex：下穿，副前提语境加 EF y *)
        match typeOf G d0 with
        | [fimp x y] =>
            dImpSL (beta1 G d0) (beta1 G d1) (beta1 (EF y :: G) d)
        ...
```

三型绕道的电池（电三/四/五）各自验证收缩落点：

- `gen_beta`：`dAndGEN (∧I hp hq) (∧I hp hq)` 收缩回 `∧I hp hq`；
- `sl_beta`：→I 体真用绑定式（`db_pq := MP(imp_pq, p)`），副前提
  [q]⊢q∧q，收缩后 q 假设全部换成「喂过 p 的 db」——`dAndI db_pq
  db_pq`；
- `hl_beta`：两步账——HL 红ex先把规则应用点换成平凡 ESL，留下一个
  ESL 红ex再被吸收，最终 `dMP (dHyp imp_pq) db_pq`。

电六验证**子公式性质**：正规形里出现的每个公式都是端式 p∧q 的子公
式（`subF` 的「或」方向——本章实测踩过一次「写成且」的坑，见速记）。
这正是书 §5 说的「正规化与子公式定理从高层情形平移到标准层」的机
器面：因为 HL↔SL 互译不产生新的极大公式，高层次已证的正规化结果
直接覆盖 von Plato/Tennant 的 GE 系统。

## 34.6 和谐账本与高层次的红利

**和谐（harmony）**是证明论语义的关键词（第 42 章正面攻坚）：引入
与消去规则要「匹配」——消去不能强于引入（局部可靠性，β 可收缩：
`betaAnd`），也不能弱于引入（局部完备性，η 可展开：从 d 恢复
`∧I(∧E₁ d)(∧E₂ d)` 再收缩回 d）。电七/电八的 `eta_beta_roundtrip`
把 η∘β = id 钉在引入形上：

```coq
Definition etaAnd (d : der) : der := dAndI (dAndE1 d) (dAndE2 d).

Example eta_beta_roundtrip :
  derEqb (normalize 30 (etaAnd (dAndI (dHyp p) (dHyp q))))
         (dAndI (dHyp p) (dHyp q)) = true.
```

注意账目的诚实性：η 再 β 恒等于 id **只对引入形的 d 成立**——对假
设形的 d，投影不是红ex（投影的主前提必须是 ∧I），β 推不动 η 展开
的结果。GE 系的 η 同理需要专门的 η-规则（`dAndGEN d (∧I hA hB) ↝ d`），
书 §5 的「强统一性」叙事正建立在这类形状统一的 η 上。

最后的电九（`nested_rule_application`）展示高层次真正的表达力：语
境里放两条规则假设 p⇒q 与 (p→q)⇒r，则

```coq
Definition viaRules : der :=
  dImpI p (dRule (fimp p q) r2 (dImpI p (dRule p q (dHyp p)))).
```

内层：假设规则 p⇒q 在 →I 体里当肯定前件用；外层：把这样造出的
p→q 证据喂给层 3 规则 (p→q)⇒r。两层规则咬合的推导在标准层没有对
应物——这就是「不可扁平化」的日常直觉。书 §6-§8 把这套演算接到矢
列演算上（蕴含即规则 vs 蕴含即链条两种读法、Avron 式变体与
「proudness」性质），属文献综述线，教程不再展开。

- 规则假设 → 定义反思（definitional reflection）→ 证明论有效性的
  基扩张语义：一路通向第 42 章（Prawitz 本人），那里「原子规则系
  统」就是本章 `ER` 条目的无穷化。

  的 GE 系统）。

## 坑位速记（本章实测）

- **收缩坐标**：β 收缩需要的公式（绑定式/后件/左右成分）不能从
  顶构造语法读出，必须 `typeOf` 现场喂入；`beta1` 下穿引入规则时
  **语境必须同步扩张**，否则内层红ex坐标静默算错（症状：收缩结果
  里残留错误假设、断言假）。
- **`subF` 方向**：`c ⊑ a ∧ x` 的子公式递归是「或」不是「且」——
  写成 andb 时 `[p;q]` 对 `p∧q` 的检查全灭，断言 `true≠false`。
- **η 回程的前提**：β∘η = id 只对**引入形**成立；拿假设形或绕道形
  做样本会假——选 `∧I hp hq` 当 d。
- **嵌套规则样本的类型**：`dRule x y d1` 的 d1 必须恰有类型 x；初
  稿拿 MP 的结论 q 去喂 (p→q)⇒r 的应用点，`typeOf` 直接拒收
  （`eqF z x` 检查）。
- Lean 侧：`typeOf` 返回 `Option Form` 时 `== some x` 需要 BEq 实例
  ——Option/Form 未 derive，改 match 展开；`normalize` 的
  `n + 1` 模式必须命名 n（`_ + 1` 里递归调用 `normalize _ d'` 的洞
  合成不出）；`eqF · c` 的 `·` 中缀写法非法（`(· + 1)` 类括号才
  合法）——直接写全 `eqF (.atom a) c`。
- Coq 侧：`.1/.2` 不可用（用显式 match）；Example 一律
  `Proof. vm_compute. reflexivity. Qed.`；`Definition ... with` 只
  对 Fixpoint 合法（本文件用不到——分层定义即可）。

## 小结

广义消去把 ∨E 的形状立为所有联结词的宪法：消去规则=定义条件的后
承之交。→ 是宪法的第一块试金石——认真对待它就得上「规则假设」，
演算升到层 4；退而求其次的 →ESL 在层 3 保住形状，但实例级表达力
让了一步，极限处是 Olkhovikov–Schroeder-Heister 不可扁平化定理。
本章的三系统 AST + 六翻译 + 类型驱动 β 把这条谱系全部做成了可执
行程序：规则形状不再是不容置疑的背景，而是可以在同一判断上并排
比较、互相翻译、逐实例证伪的对象。
