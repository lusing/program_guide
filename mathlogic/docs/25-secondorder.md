# 第 25 章 二阶逻辑与弱二阶系统

> 对书：EFT ch IX（§IX.1-9.3）+ §X.5 的伏笔。本章通道：C（`examples/25_secondorder/ex25_secondorder.v`）/
> L（`examples/25_secondorder/ex25_secondorder.lean`）。

| 机器件 | 内容 | 通道 |
|---|---|---|
| `soev` 求值器 | 二阶语义的有限结构实现：关系变量跑**幂枚举域**（全部 k 元关系表），∃X 逐关系尝试 | C/L |
| 偶数性 | 环后继上的**交替着色** ∃X[X(0) ∧ ∀x∀y(Sxy → (X(x) ↔ ¬X(y)))]——4 域真 5 域假 | C/L |

第 24 章把一阶的初等等价做成了可算的表；这一章跨过一阶的天花板，
看**二阶逻辑**：量词可以量化关系变量 X。表达力暴涨——有限性、
连通性、良序性都变得可定义——但代价同样惨烈：完备性、紧致性、
L-S 成片倒塌（EFT ch IX 的主题），有效性不可判定甚至不可枚举。

## 〇、与全书各章的接线

本章在教程里是「表达力天梯」的顶点一站：02 章的命题判定器枚举
布尔赋值（2ⁿ），09 章 DPLL 把同一枚举剪枝加速，23/24 章把一阶
的分辨力按量化秩分层（σₙ 族与 EF 博弈同尺），本章让量词直接跑
**关系**——幂枚举域 2^(n^k) 个关系一次搜尽。四层枚举，同一个
「有限域上语义=穷举」的母题，规模一次比一次狠：2ⁿ → 子句组合
→ nᵏ 元组 → 2^(n^k) 关系。这也是为什么二阶的可满足性在有限域
仍可判定、在无限域直接不可枚举——规模本身成为元定理的分界。

与 16 章（FOL ND）的分工：那边是一阶证明的**演算**面；本章是
二阶**语义**面——二阶没有完备演算（这正是要点），机器化的切入
口只能从语义侧走。与 34 章（不完备性）的伏笔：二阶 PA 的范畴
性给出「一阶 PA 必有非标准模型」的对照系——一阶归纳公理模式
只覆盖可数多条公式，二阶归纳一句话量化全部子集；不完备定理的
「真·不可证」 gap 在二阶里被语义强行闭合、代价是没有任何可信
的证明演算能覆盖全部二阶有效式。

## 一、二阶语义的机器化：关系跑幂枚举域

二阶求值器 `soev` 在一阶骨架上加一个**关系环境** ρ（变量号 ↦ 关系，
表示为论域 k 元组的表）和一个量词：

```coq
| soexq k ψ =>
    existsb (fun R => soev f r D β (bumpR ρ k R) ψ) (pow_tuples D k)
```

`pow_tuples D k` 枚举论域上**全部 k 元关系**（k 元组全枚举的幂
集）——有限结构上二阶量词是有限搜索，可判定。这正是「二阶语义
= 量化一切关系」的全语义（full semantics）在有限域的可计算化身；
Henkin 的广义语义（关系跑指定类）是保持完备性的弱化，文档级对照。

## 一点五、求值器逐行读

soev 的骨架与 21 章 evf 完全同构（六条布尔连接词 + 一阶量词
枚举论域），新增的只有两处：`relv k ts` 查关系环境——把项求值
成自然数表后，在 ρ(k)（一个元组表）里找完全匹配（lseqb 逐位
相等）；`soexq xv k ψ` 枚举幂域——对每个候选关系 R，用
`bumpR ρ xv R` 把它绑定到变量后递归。注意 bumpR 与一阶的 bump
是同一个「环境更新」母题：一阶更新赋值（点），二阶更新关系环
境（表）。Prolog 通道未开（幂枚举在回溯里就是 sublists 的找出
全部子表——可作为练习；本章 C/L 已把语义两侧钉死）。

初始化环境 ρ := fun _ => []（空关系），所以闭句从空环境出发；
X 的候选空间由 pow_tuples 现场生成——4 元论域上的一元关系有
2⁴ = 16 个、二元有 2¹⁶ = 65536 个。evenSO 只用一元（16 个候选
× 每个候选 O(n²) 的全称检查——瞬间）；connSO 用二元（65536
个候选 × O(n²)——仍瞬间）。规模上二阶量词是「指数上的指数」，
这是它的根本暴力，也是它表达力的来源。

## 二、偶数性：交替着色

**even(dom) 在一阶不可定义**（23/24 章的 EF 博弈结论：偶环与奇
环高轮不分），二阶一句话：

$$\exists X\big[X(0) \wedge \forall x \forall y\,(S(x,y) \to (X(x) \leftrightarrow \neg X(y)))\big]$$

X 沿环交替着色（相邻反色）；绕环一圈回到起点时相容 ⟺ 环长为
偶。机器在 (Zₙ, S)（环绕后继）上验证：

```text
n  :  1  2  3  4  5  6  7  8
∃X :  ✗  ✓  ✗  ✓  ✗  ✓  ✗  ✓
```

这是「二阶定义一阶不可定义性质」的最小现场——表达力分层的活
标本。

## 二点五、从着色到划分：二阶定义的两副面孔

偶数性与连通性代表二阶定义的两种典型用法：**着色式**（∃X 刻画
一个不变量——X 是交替 2 着色，绕环相容性即偶性）与**划分式**
（∃R 刻画一个等价关系必须平凡——连通=每个含边等价关系都全）。
一阶不可定义的证明都在 24 章：偶环 Z₂ₖ 与奇环 Z₂ₖ₊₁ 的 EF 博
弈在轮数 k 内不分（后继结构上 spoiler 摸不到「绕一圈回到出发
点」的全局信息）；分裂图与连通图的区分需要「存在一对无路可达
的点」——一阶可以逐步逼近（路径长度 ≤n 可定义）但无法定义
「任意长路都不通」。两个现场合起来读：二阶量词买到的正是这种
**全局/任意尺度**的语义。

## 三、连通性：否定式的等价关系刻画

图连通 ⟺ **不存在**「包含边关系 E 且漏掉某对的等价关系 R」：

$$\lnot\exists R\big[\mathrm{Eq}(R) \wedge E \subseteq R \wedge \lnot\forall x \forall y\, R(x,y)\big]$$

注意**否定式**不可省：正向写「∃R[Eq ∧ ⊇E ∧ 全域]」会被全关系
平凡满足（任何图都真）。机器现场：链 0-1-2-3（连通）真、链 0-1
+ 岛 2,3（分裂）假——首次实现就栽在正向式的平凡满足上（见坑位）。

## 三点五、Lindström 视角的前置练习

EFT ch XIII 的两条定理将在此后收官章对账：**没有既紧致又对
L-S 封闭的超一阶逻辑**。本章的三个现场正好给出「为什么」的直
觉材料：偶数性的二阶定义量化了任意子集——紧致性（有限子集
的模型拼出整体模型）在「子集」这种高阶对象上没有有限的组合
骨架；L_Q 在有限域退化成常假量词，说明「不可数」这种基数语
汇根本落不进一阶的模型论。把 23 章 σₙ 族的紧致性用法、24 章
的秩梯子、本章的幂枚举域并排看，Lindström 的「一阶=紧致∧
L-S 的极大点」就不再是抽象口号，而是三组机器现场的合流。

## 四、弱二阶系统与元定理的倒塌

**L_ω₁ω**（可数合取）：∀ 之外允许可数个 ∨/∧——能表达「每个元
素有有限多个前驱」等；无完备演算（可满足性复杂度暴涨）。**L_Q**
（Keisler）：量词 Qx φ :=「满足 φ 的元素**不可数**多」——在有限
结构上恒假（机器面 `Q_finite := false`），在无限结构上能定义
ℵ₁-范畴性等。二阶 PA 的**范畴性**（唯一模型=标准算术——只需
二阶归纳公理一句话）、二阶有效性不可枚举（Church–Kleene，经
Trakhtenbrot 的有限模型不可判定性，书 X.5 的链路）——文档级讲
清。一章之内的分野：**一阶的元定理群（完备/紧致/L-S）依赖「量
词只跑论域」；二阶让量词跑幂集，模型论的自由度立即消失。**

## 四点五、L_ω₁ω 与 L_Q 的取材口径

EFT 对 L_ω₁ω 的招牌例子是「每个元素的先驱集有限」——它需要
可数无穷析取 ∨ₙ「至多 n 个先驱」。对 L_Q 则给 (Z, S) 的 ℵ₁-
范畴性片段。本章机器面只做 Q 的有限退化（恒假）——诚实的边界
说明：L_ω₁ω 的公式是**无穷对象**（可数高度的树），本章的 fm
是有限归纳类型，装不下；要做它得引入「公式=树的余归纳表示」，
超出预算，记为后续工作。L_Q 的无限侧语义（在可数模型上 ∀ 与
Q 的相互作用）同样需要无限论域的求值，文档级讲清陈述与书证
思想即可——机器件的取舍原则一以贯之：**有限域可算的做双通道，
无限的做文档线**。

## 坑位速记（本章实测）

- **连通式的平凡满足**：正向「∃ 等价+含边+全域」被全关系满足
  ——必须否定式「不存在漏对的等价关系」；首版现场连通/分裂全
  真，机器抓包。
- **链的边写漏**：chain4 只写了 (0,1),(1,2) 漏了 (2,3)——连通
  例失败后逐边检查发现；**结构定义先于公式断言自检**。
- **函数/关系混用**：环后继若用函词 fsym 施于项，一阶求值器里
  无解释（fid 恒 0）——偶数式改**关系式** S(x,y)（∀x∀y(S→…)）
  才对；Lean 的 `!`（Bool 反）不能作用在公式上——iff 要用
  conj/imp 组合（iff_f）。
- **嵌套括号计数**：conn_inner 四层 conj 链的闭括号连错四次——
  终以「每层参数写单行+程序平衡检查」收场；σₙ 式长公式同样
  程序生成（23 章坑位的延续）。

## 六、正文引用的全部代码（供「不看源码」的读者）

偶数性主定义（Coq 版）：

```coq
Definition evenSO : fm :=
  soexq 0 1 (conj (Xv (var 0))
    (allq 1 (allq 2 (imp (Sat (var 1) (var 2))
                         (iff_b (Xv (var 1)) (neg (Xv (var 2)))))))).
```

连通性的否定式骨架（Lean 版，iff_f 为 conj/imp 组合）：

```lean
def conn_inner : fm :=
    .conj (.allq 0 (Rv (.var 0) (.var 0)))                    -- 自反
    (.conj (.allq 0 (.allq 1 (.imp (Rv x y) (Rv y x))))       -- 对称
    (.conj (.allq 0 (.allq 1 (.allq 2 (.imp                    -- 传递
              (.conj (Rv x y) (Rv y z)) (Rv x z)))))
    (.conj (.allq 0 (.allq 1 (.imp (Ev x y) (Rv x y))))        -- 含边
          (.neg (.allq 0 (.allq 1 (Rv x y)))))))               -- 漏对
def connSO : fm := .neg (.soexq 1 2 conn_inner)
```

幂枚举域的构造（Coq 版，二阶量词的论域）：

```coq
Fixpoint tuples_k (D : list nat) (k : nat) : list (list nat) :=
  match k with
  | O => [[]]
  | S k' => flat_map (fun a => map (fun l => a :: l) (tuples_k D k')) D
  end.

Fixpoint subsets {A} (l : list A) : list (list A) :=
  match l with
  | [] => [[]]
  | a :: l' => let S := subsets l' in
               map (fun s => a :: s) S ++ S
  end.
```

验证输出（两通道一致）：偶数性 [✗✓✗✓✗✓✗✓]；连通链 true、
分裂图 false。

## 小结

二阶逻辑在有限结构上保住了可判定性（幂枚举域），表达力挣脱一阶
天花板（偶数、连通）；但无限结构上的元定理成片倒塌——这正是
Lindström 定理要精确化的边界：「一阶之外，紧致性与 L-S 不可兼
得」。下一章回到**可计算性**本源：寄存器机——把「程序」本身变
成数学对象，为不完备性铺最后一层地基。
