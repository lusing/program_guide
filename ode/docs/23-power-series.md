# 23 幂级数解法

**对应书 §6.1 Convergence of Power Series、§6.2 Series Solutions
Near an Ordinary Point、§6.3 Regular Singular Point（Frobenius）。**

---

## 23.1 为什么回到级数

线性方程 y″ + p(x)y′ + q(x)y = 0 的解法至今依赖"猜基本组"——
但 p、q 稍微一般化（如 q(x) = x，Airy 方程）后初等函数全军覆
没。**幂级数法**是第一个普适方案：把解写成

    y = Σₙ aₙ(x − x₀)ⁿ

代入方程，逐项求导（幂级数在收敛圆内可逐项微分），匹配系数得
**递推关系**——解方程变成"生成系数的算法"。这是特殊函数的出生
证明：Bessel、Legendre、Airy、Hermite 全部诞生于幂级数。

**预备知识**（书 §6.1）：幂级数的收敛半径 R（比值判别法：
R = lim|aₙ/aₙ₊₁|）；在收敛圆内绝对收敛、可逐项求导任意次；
和函数在 |x − x₀| < R 内解析。

## 23.2 常点：泰勒式展开

x₀ 是**常点** ⟺ p、q 都在 x₀ 解析。此时两个线性无关解都在 x₀
解析（收敛半径至少到最近的奇点）。

**协议**：设 y = Σaₙxⁿ（取 x₀ = 0），代入：
y′ = Σ(n+1)aₙ₊₁xⁿ，y″ = Σ(n+2)(n+1)aₙ₊₂xⁿ；把 p、q（若非
多项式，也展成级数）逐幂匹配，得两项递推

    aₙ₊₂ = −[pₙ 项 + qₙ 项] / (n+2)(n+1)。

初值 a₀ = y(0)、a₁ = y′(0) 自由——泰勒级数与 IVP 一一对应。

**例 A（书 §6.2）** y″ − xy = 0（Airy）。递推
(n+2)(n+1)aₙ₊₂ = aₙ₋₁（n ≥ 1），a₂ = 0：三个独立链
（a₀ 链：a₀, a₃, a₆, …；a₁ 链：a₁, a₄, a₇, …；a₂ = 0 链死）。
两支级数就是 Airy 函数 Ai、Bi 的泰勒芽——特殊函数就是这样"被
算法定义"的。收敛半径 ∞（q(x) = x 整函数）。

## 23.3 正则奇点：Frobenius 方法

x₀ 是**正则奇点** ⟺ (x − x₀)p(x) 与 (x − x₀)²q(x) 都解析
（奇点"至多一阶/二阶"）。此时解一般是 (x − x₀)^r × 解析函数：
猜 **Frobenius 级数**

    y = x^r Σₙ aₙxⁿ（a₀ ≠ 0），

代入后 x 的最低幂系数给**指标方程**（indicial equation，关于 r
的二次方程）。三种情形：

- **根差非整数**：两个 Frobenius 解线性无关；
- **根相等**：第二解含 **ln x** 项（y₂ = y₁ ln x + x^r Σbₙxⁿ）；
- **根差整数**：第二解可能含 ln 也可能侥幸纯 Frobenius（递推在
  差值处需要相容条件）。

**例 B（Euler 方程的重逢）** x²y″ + 4xy′ − 4y = 0：x = 0 是
正则奇点，指标方程 k(k−1) + 4k − 4 = 0 给 k = 1, −4——差 5 是
整数但两根都给出纯幂解 x、x⁻⁴（第 09/13 章的答案在级数框架下
重逢）。

**例 C（Bessel 预告）** x²y″ + xy′ + (x² − ν²)y = 0：指标方程
r² = ν²，r = ±ν；r = ν 支给 J_ν(x) = Σ(−1)ᵏ(x/2)^{2k+ν}/
(k!Γ(k+ν+1))——第 27 章的主角在此完成出生登记。

## 23.4 机器验证

**Julia（`23_series.jl`）/ Python（`23_series.py`）**：
(a) Airy 递推生成 20 项系数，部分和与 scipy.special.airy 数值
对照（< 10⁻¹⁰）；(b) 收敛半径的比值判据核对（Airy：∞；log 型
方程：有限）；(c) 例 B 的 Frobenius 指标方程数值核对（两根
1、−4）与幂解族；(d) 常点展开 vs 泰勒：y″ + y = 0 的递推产
生 sin/cos 的泰勒系数（a₂ₖ = (−1)ᵏa₀/(2k)! 交替链）——机器"重
新发明"三角函数；(e) 根差整数危险例：x²y″ + xy′ + (x² − 1)y = 0
（ν = 1 Bessel）：r = −1 支在 n = 1 处相容性破坏 ⟹ 第二解含
ln（J₁ 与 Y₁ 的分工，数值对照）。

**Prolog（`23_series.pl`）——递推引擎。** `recur(F, N, A)`：
由方程的 p、q 多项式生成 aₙ 递推（多项式系数表的卷积账）；
`series_coeffs(N, A0, A1, Coeffs)`：Airy 三链递推的精确有理数
生成；断言：Airy 前 8 项系数与手工账一致。

## 23.5 要点回顾

1. 常点 ⟹ 两解析解，泰勒递推 aₙ₊₂ 由 aₙ, aₙ₋₁ 表出；初值即前
   两项系数。
2. 正则奇点 ⟹ Frobenius y = x^rΣaₙxⁿ；指标方程定 r；根差整
   数时警惕 ln x 第二解。
3. 幂级数法把"解方程"变成"生成系数的算法"——特殊函数的定义方
   式；收敛半径由最近奇点决定。
4. Euler 方程是 Frobenius 的退化情形（级数只有一项）。
