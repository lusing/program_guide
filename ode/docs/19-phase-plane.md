# 19 相平面与奇点分类

**对应书 §5.1 Phase Plane Approach、§5.2 Phase Portraits and
Stability in the Case of Linear Autonomous Systems。**

---

## 19.1 相平面：把解画成轨道

自治系统 **x′ = f(x)**（f 不显含 t）的解曲线在**相空间**（这里
是 x₁–x₂ 平面）里的投影叫**轨道**（trajectory）。轨道族织成的图
景叫**相图**（phase portrait）。相平面分析三板斧：

1. **零斜线**（nullclines）：f₁(x) = 0 与 f₂(x) = 0 的曲线——轨道
   在 f₁ = 0 上竖直（x₁ 不变号方向）、在 f₂ = 0 上水平；
2. **奇点**（equilibrium）：f(x*) = 0 的点——两零斜线的交点；
3. **轨道方向**：向量场 f 在每点给出箭头——手绘相图的骨架。

第 07 章的一维相线是它的特例（n = 1）。

## 19.2 线性系统奇点分类：迹–行列式图

线性系统 **x′ = Ax**（A 2×2 常数）的奇点只有原点，分类完全由
A 的特征值决定（书 §5.2.3–5.2.6）。用 τ = tr A、Δ = det A 写判
据（特征方程 λ² − τλ + Δ = 0，判别式 τ² − 4Δ）：

| 区域 | 特征值 | 奇点类型 | 相图 |
|---|---|---|---|
| Δ < 0 | 异号实 | **鞍点** saddle | 双曲线族，两条稳定/不稳定直线 |
| Δ > 0, τ² > 4Δ, τ < 0 | 同负实 | **稳定结点** node | 轨道流入（放射状） |
| Δ > 0, τ² > 4Δ, τ > 0 | 同正实 | **不稳定结点** | 轨道流出 |
| Δ > 0, τ² < 4Δ, τ < 0 | 共轭复、负实部 | **稳定焦点** spiral | 旋入 |
| Δ > 0, τ² < 4Δ, τ > 0 | 共轭复、正实部 | **不稳定焦点** | 旋出 |
| τ = 0, Δ > 0 | 纯虚 | **中心** center | 闭轨圆/椭圆族 |
| Δ > 0, τ² = 4Δ | 重根 | **退化结点** | 介于结点与焦点 |

**迹–行列式平面**（τ 横轴、Δ 纵轴）把这张表画成一张地图：抛物
线 Δ = τ²/4 分隔结点/焦点区，横轴以下全是鞍点，纵轴 τ = 0 上
（Δ > 0 段）是中心——**整张分类图是参数平面上的相图字典**，工
程师扫一眼 (τ, Δ) 就知道系统行为。

**闭轨与中心**：中心情形（如 x′ = −y, y′ = x 的圆族）轨道是闭曲
线——周期解。闭轨是"永动的振荡"：非线性扰动会破坏它（变成螺
旋）或保护它（变成极限环，第 22 章）。

## 19.3 线性化：非线性系统的局部字典

非线性系统 x′ = f(x) 在奇点 x* 附近**线性化**：

    x′ = f(x*) + Df(x*)(x − x*) + … = **A(x − x*)** + 高阶项，
    A = Df(x*)（雅可比矩阵）。

**Hartman–Grobman 定理**（书 §5.2 的实务版）：A 的特征值实部都
不为零（**双曲奇点**）时，非线性相图在奇点附近与线性化相图**拓
扑等价**——分类照搬。特征值实部有零时（中心等）线性化不足以定
论（须看高阶项，第 22 章 van der Pol 的原点就是"看高阶"的例
子）。

例：单摆 x′ = y, y′ = −sin x。奇点 (0,0)（下垂）与 (π, 0)（倒
立）。Jacobian [[0,1],[−cos x, 0]]：(0,0) 处 [[0,1],[−1,0]]：
τ=0, Δ=1 ⟹ 中心（小幅摆动）；(π,0) 处 [[0,1],[1,0]]：Δ = −1 ⟹
鞍点（倒立不稳定）。相图上的分界线（separatrix，过鞍点的轨道）
分开"来回摆"与"绕圈转"两种定性不同的运动——非线性相图的签名
结构。

## 19.4 机器验证

**Julia（`19_phase.jl`）/ Python（`19_phase.py`）**：
(a) 迹–行列式分类器：7 组 (τ, Δ)（鞍点/稳定结点/稳定焦点/中心/
不稳定焦点/不稳定结点/退化）数值构造 A = [[0,1],[−Δ,τ]]，积分
初值轨道，断言行为（轨道范数单调性、旋向、是否闭轨——一个周期
后回到起点）；(b) 单摆相图：从 6 个初值积分，分类轨道（小幅闭
轨/大幅绕圈/分界线附近），奇点类型与线性化预言一致；
(c) 零斜线核对：f₁ = 0 上轨道竖直（数值积分中 x₁ 的极值点恰好落
在零斜线上）。

**Prolog（`19_phase.pl`）——分类字典。** `classify(Tau, Delta,
Type)`：迹–行列式判据全表；`jacobian_classify(Sys, Point, Type)`：
单摆的雅可比 + 分类。断言：七情形 + 摆的两个奇点。

## 19.5 要点回顾

1. 相图三要素：零斜线（方向骨架）、奇点（两零斜线交点）、轨道
   方向。一维相线是 n=1 特例。
2. 线性系统分类由 (τ, Δ) 唯一决定：鞍（Δ<0）、结点/焦点（抛物
   线 Δ=τ²/4 两侧）、中心（τ=0, Δ>0）——参数平面地图。
3. 非线性奇点看雅可比：双曲（实部≠0）照搬线性分类；中心型
   （实部=0）须看高阶项。
4. 分界线（过鞍点轨道）分割定性不同的运动区域——相图的灵魂
   结构。
