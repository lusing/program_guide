**对应书 §4.1–4.3 General Considerations / Systems of First-Order

## 15.1 为什么要研究方程组

两个理由让方程组成为**更本原**的对象：

**其一：任何高阶方程都能化为一阶方程组。** n 阶方程
y⁽ⁿ⁾ = f(x, y, y′, …, y⁽ⁿ⁻¹⁾) 令

    x₁ = y, x₂ = y′, …, xₙ = y⁽ⁿ⁻¹⁾

就变成 n 元一阶组 xᵢ′ = xᵢ₊₁ (i < n)、xₙ′ = f(x, x₁, …, xₙ)。
例：弹簧振子 mx″ + cx′ + kx = 0 ⟹ [x; v]′ = [v; (−cv − kx)/m]。
**反过来不成立**——方程组一般不能合并成单个高阶方程。所以方程组
的世界更大。

**其二：物理天生是方程组。** 牛顿力学 n 个自由度就是 2n 个一阶方
程（位置+动量）；电路多个回路、生态多个物种、化学多组分——
"状态向量"随时间演化的观点（**相空间**）是现代动力学的语言，第
19–22 章全面展开。

**向量记法**：x′ = f(t, x)，x ∈ ℝⁿ。存在唯一性定理照搬：f 关于 x
Lipschitz ⟹ 局部存在唯一；初值 x(t₀) = x⁰ 一次性给定 n 个分量。
解曲线是 (t, x) 空间里的曲线，或 x 空间（相空间）里的轨道。

## 15.2 线性方程组：结构定理全套搬进向量世界

    **x′ = A(t)x + g(t)**（g ≡ 0 齐次；A(t) 是 n×n 矩阵函数）

结构理论与第 10 章逐字平行（书 §4.3）：

- 齐次解集是 **n 维向量空间**；基本解组 x₁, …, xₙ 线性无关；
- **基本矩阵** X(t) = [x₁ … xₙ]（列是解），通解 x = X(t)c；
- **Wronskian** W(t) = det X(t)，满足 Abel 型方程
  W′ = tr A(t)·W ⟹ **W = W₀·e^(∫tr A dt)**；
- 非齐通解 = 齐通解 + 特解；参数变易给 x_p = X(t)∫X⁻¹g dt。

与标量版唯一的差别：乘法变成矩阵乘法、除法变成矩阵求逆——所有
"顺序"都要小心（矩阵不可交换）。

**消元法（标量化）**：二元线性组可以通过求导消元化成单个二阶方
程（书 §4.2 的例子大量使用），这是手算的常用路；但矩阵观点
（第 16/17 章）才是系统理论。

## 15.3 机器验证

**Julia（`15_systems.jl`）/ Python（`15_systems.py`）**：
(a) 高阶⟺一阶组互化实验：弹簧振子两个形态（二阶标量 vs 二元组）
同初值数值积分，解的 x 分量逐点一致（< 10⁻¹⁰）；(b) 基本矩阵的
Wronskian Abel 核对：变系数 A(t) = [[0, 1], [−t, 0]]（Airy 型），
数值积分两组初值装配 X(t)，det X 与 e^(∫tr A) = 1（tr = 0）对照；
(c) 参数变易：非齐次 x′ = Ax + g 的解 = X(t)c + X∫X⁻¹g 数值核对。

**Prolog（`15_systems.pl`）——互化器。** `to_system(N, Sys)`：n 阶
标量方程的规则化改写（y⁽ᵏ⁾ ↔ xₖ′）；`wronskian_det(A, W)`：Abel 公
式 W = W₀e^(∫tr A)（tr 计算 + 符号积分表）；断言：弹簧振子与
Airy 型两组。

**Lean（`Ode/Ch15Systems.lean`）**：二元线性组 x′ = y、y′ = −x 的
解 (cos t, −sin t)... 取 (x, y) = (cos t, sin t)：x′ = −sin t = −y
✗——应为 x′ = y ⟹ (sin t, cos t)：x′ = cos t = y ✓，y′ = −sin t =
−x ✓。两份 HasDerivAt（sin/cos 导数）逐字核对旋转系统。

## 15.4 要点回顾

1. 高阶 ⟹ 一阶组（升维化）；一阶组 ↛ 高阶（不可逆）。相空间观点
   是现代动力学的语言。
2. 线性组结构定理与标量版逐字平行：n 维解空间、基本矩阵 X、
   W = det X、Abel W = W₀e^(∫tr A)、参数变易 x_p = X∫X⁻¹g。
3. 矩阵不可交换——标量直觉搬运时"顺序"是新风险点。
4. 消元法（求导消元降维）适合手算小系统；大系统交给第 16/17 章
   的特征值与矩阵指数。
