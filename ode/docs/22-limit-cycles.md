# 22 非线性振动与极限环

**对应书 §5.4.4 Nonlinear Oscillations（极限环、van der Pol、
张弛振荡、Poincaré–Bendixson）。**

---

## 22.1 极限环：孤立的周期解

**极限环**（limit cycle）是孤立的闭轨：附近的轨道都盘旋趋向它
（稳定极限环）或离开它（不稳定）。与中心的闭轨族（连续统、非孤
立、边缘稳定）不同，极限环是**自我选定的振幅**——系统自激出等
幅振荡，无需周期外力。

线性系统没有极限环（解 e^{At}x₀ 的结构决定轨道要么发散要么收敛
要么闭族）；**极限环是非线性独有的现象**。它是自激振动（电子
振荡器、心脏起搏、机床颤振）的数学模型：小扰动指数增长（能量
注入）、大振幅衰减（能量耗散），两者平衡在一个振幅上。

## 22.2 van der Pol 振子：极限环的旗舰

    **x″ − μ(1 − x²)x′ + x = 0**（μ > 0）

负阻尼的来历：阻尼系数 −μ(1 − x²) 在 |x| < 1 时为**负**（小振
幅获能、增长），|x| > 1 时为正（大振幅耗能、衰减）——振幅自动
稳定在两者平衡处。系统形式：

    x′ = y，y′ = μ(1 − x²)y − x。

原点处线性化 [[0,1],[−1,μ]] 特征值实部 μ/2 > 0（不稳定焦
点）——小扰动起振；全局看振幅被非线性饱和 → 极限环。μ 小时近
正弦（弱非线性，振幅 ≈ 2）；μ 大时**张弛振荡**（relaxation
oscillation）：快慢交替——沿曲线 y = x − x³/3 的慢漂移 + 两端
的快速跳变，周期 T ≈ (3 − 2ln2)μ（书 §5.4.4 的渐近账）。

**能量账**：一个周期内能量变化 ∮ μ(1 − x²)y² dt = 0——注入 =
耗散，定出振幅。这是"平均法/谐波平衡"的雏形：设 x ≈ a cos t，
平衡能量得 a = 2（一次谐波）。

## 22.3 Poincaré–Bendixson：极限环存在性的地理学

**定理**：有界闭区域 D 内若 (i) 无奇点（或奇点全不稳定），(ii)
t 大时轨道进入 D 不再离开，则 D 内必有闭轨。

用法（**环域法**）：造两个闭曲线 C_in、C_out，验证向量场在 C_in
上向外、C_out 上向内（边界条件），中间挖掉奇点——极限环被夹在
环内。这给了"**存在性不用求解**"的几何证明。配套的**否定工具**
是 Bendixson 判据：单连通域内 div f = ∂f₁/∂x + ∂f₂/∂y 不变号
（≠ 0）⟹ 无闭轨。

## 22.4 机器验证

**Julia（`22_vanderpol.jl`）/ Python（`22_vanderpol.py`）**：
(a) 极限环存在性：μ = 1，从内外两侧初值（(0.1, 0) 与 (5, 5)）
积分到 t = 60，两侧轨道都贴上同一条闭轨（终态相位差内范数差
< 0.01）；(b) 振幅律：μ ∈ {0.2, 1, 2} 的环上 max|x| ≈ 2（谐波
平衡预言）拟合；(c) 周期律：大 μ 扫描 T(μ)/μ → 3 − 2ln2 ≈
1.614（张弛渐近）；(d) 谐波平衡：x ≈ 2cos t 的能量账 ∮μ(1−x²)
y²dt ≈ 0（数值积分核对）；(e) Poincaré–Bendixson 数值版：环域
（r_in = 1，r_out = 4）边界上的径向分量符号（内正外负）——夹逼
证明的数值版；(f) Bendixson 判据反例：x′ = −y + x(1−r²)…
div 计算说明为何此系统**可以有**环（div 变号）。

**Fortran（`22_vanderpol.f90`）**：μ = 4 的张弛振荡 RK4：记录
x(t) 的逐次极大，断言相邻极大差 → 0（轨道贴环）+ 周期近似账。

**Prolog（`22_limitcycle.pl`）**：`harmonic_balance(Mu, Amp)`
（一次谐波振幅 = 2 的符号账）；`relaxation_period(Mu, T)`（渐近
公式）；`poincare_bendixson_ring(Rin, Rout, Verdict)`（环域判据
的数值点核对表）。

## 22.5 要点回顾

1. 极限环 = 孤立闭轨，非线性独有；自激振动的数学模型——小振幅
   注能、大振幅耗能、振幅自选。
2. van der Pol：负阻尼 −μ(1−x²) 的机制；μ 小近正弦（振幅 ≈ 2），
   μ 大张弛振荡（T ≈ 1.614μ）。
3. Poincaré–Bendixson 环域法给存在性（夹逼）；Bendixson div 判
   据给不存在性。
4. 谐波平衡/能量账是振幅的快捷估算，与数值极限环互证。
