# 06 未解出导数的方程：Lagrange 与 Clairaut

**对应书 §2.6 Equations Unresolved with Respect to a Derivative。**

---

## 6.1 解出 y′：一个方程，多个方向场

到目前为止方程都写成 y′ = f(x, y)（导数已解出）。一般形式是

    F(x, y, y′) = 0，

y′ 藏在函数关系里。对 y′ 解代数方程，可能得到**几个分支**

    y′ = f₁(x, y), …, y′ = f_m(x, y)，

每个分支一个方向场，各积各的。通解是各分支通解的并集；**正则解**
指在每点唯一性成立的分支解，**奇异（不规则）解**是分支场相切、可
以"换轨"的地方长出来的解（第 03 章例 4 已经预演过换轨）。

**二次型方程** y′² + 2P(x,y)y′ + Q(x,y) = 0 的求根公式

    y′ = −P ± √(P² − Q)

在 P² − Q ≥ 0 的区域给出两个分支。判别式为零的曲线 P² = Q 是两个
方向场汇合之处——奇异解只能从这里长出（还要代回原方程核对，见
例 1）。

**例 1**（书例 2.24）y′² − 2(x + y)y′ + 4xy = 0。求根：
y′ = (x + y) ± (x − y)，即 y′ = 2x 或 y′ = 2y。两支分别积分：

    y = x² + C    与    y = C·e^(2x).

判别式曲线 x = y 上：y = x 代入原方程得 x²·1 − 4x² ≠ 0，**不满足
原方程**——本例无奇异解，两族解全是正则的。

**例 2**（书例 2.25）y′² − 4x² = 0 ⟹ y′ = ±2x ⟹ y = ±x² + C，
两族抛物线。过点 M(1, 1) 有两条积分曲线：y = x² 与 y = −x² + 2
（两支斜率 2 与 −2 不同，各过一条——正则）。但在原点 O(0, 0)：
两支斜率都是 0，方向场相切，解可以从 y = x² 换轨到 y = −x²
（书给出的换轨解 y = x²(x≤0), −x²(x≥0) 等）——**初值点落在分支
场相切处时 Cauchy 问题的唯一性破产**。这与第 01 章 √|y| 反例同源：
不唯一总发生在"定理条件失效"的几何现场。

**例 3**（书例 2.26，F(x, y′) = 0 型）e^{y′} + y′ = x。对 y′ 解不
出（Lambert W 才能反解），但对 x 一眼解出：令**参数** t = y′，则

    x = eᵗ + t，dy = y′dx = t(eᵗ + 1)dt，积分 y = eᵗ(t − 1) + t²/2 + C.

通解以参数形式 (x(t), y(t)) 给出——参数化是未解出型方程的标准出
口。

**例 4**（书例 2.27）y²(y′)² + y² = 1。两支 y′ = ±√(1−y²)/y，
交换变量 dx/dy = ±y/√(1−y²)（|y| < 1 处），积分得圆族

    (x − C)² + y² = 1，

而 **y = ±1 是奇异解**——它是圆族的**包络**（每个圆在顶部/底部与
直线 y = 1 / y = −1 相切；两支方向场在 y = ±1 处汇合相切，判别式
为零之处正是分支场交汇处）。奇异解的几何身份就是包络：通解族的每
条曲线都与它相切，但它不属于通解族（没有 C 能取到它）。这是本章
最深的图像，Clairaut 方程把它做成定理。

## 6.2 Lagrange 方程：y = f(y′)·x + g(y′)

**Lagrange 方程**是对 y′ 解不出的特殊结构：y 显式出现，且 y 与 x
都以 y′ 为参数线性出现：

    y = f(p)·x + g(p)，其中 p = y′(x).

对 x 求导（p = p(x) 是未知函数）：

    p = f′(p)·p′x + f(p) + g′(p)·p′x    ⟹    [f′(p)·x + g′(p)]·dp/dx = p − f(p).

把 x 看成 p 的函数（x′(p) = 1/p′(x)），得到**x(p) 的线性方程**：

    dx/dp = [f′(p)·x + g′(p)] / (p − f(p))，

用第 04 章方法解出 x = x(p, C)，代回 y = f(p)x + g(p) 得参数化通
解。另外，若某 t₀ 使 f(t₀) = t₀（f 的不动点），则 **y = t₀x +
g(t₀) 是一条特解直线**（p ≡ t₀ 使 dp/dx 方程两边同时为零）。

## 6.3 Clairaut 方程：通解直线族 + 包络奇异解

**Clairaut 方程**是 Lagrange 方程 f(t) ≡ t 的极端情形：

    y = x·p + g(p)，p = y′.

求导：p = p + [x + g′(p)]·p′，即

    [x + g′(p)]·dp/dx = 0.

**乘积为零，两支各给一类解**：

- **支 1：dp/dx = 0** ⟹ p = C（常数）⟹ 通解是**直线族**
  y = Cx + g(C)，C 任意；
- **支 2：x + g′(p) = 0** ⟹ x = −g′(t)，代回方程 y = −t·g′(t)
  + g(t)——一条**参数曲线**。

支 2 的曲线在每个参数值 t₀ 处的点 (−g′(t₀), g(t₀) − t₀g′(t₀)) 恰
好落在支 1 的直线 y = t₀x + g(t₀) 上，且该直线在此点的斜率是 t₀、
曲线在此点的切线斜率 dy/dx = [−g′ − tg″]/(−g″) = t + g′/g″…
直接计算（dx/dt = −g″，dy/dt = −g′ − tg″ + g′ = −tg″，故
dy/dx = t）——**曲线与直线族中的每条直线相切**：支 2 曲线是直线
族的**包络**，它是奇异解（除个别退化点外不属于直线族）。

**例 5**（书习题 14）y = xy′ + y′²。g(t) = t²：通解直线族
y = Cx + C²；包络 x = −2t、y = −2t² + t² = −t²，消 t 得

    y = −x²/4（奇异解）.

数值/符号通道都会核对：直线族 y = Cx + C² 与抛物线 y = −x²/4 在
x = −2C 处相切（交点处斜率同为 C）。

**为什么奇异解危险**：以例 5 的 Cauchy 问题为例，从抛物线下方一
点出发的解可以在切点"换乘"直线族——无穷多解穿过同一点。几何上，
包络是通解族的"临界线"；数值上，跨过包络的步进积分会静默换轨
（第 03 章例 4 的换轨是它的低配版）。

## 6.4 机器验证

**Prolog（`06_clairaut.pl`）——主通道：Clairaut/Lagrange 规则引擎。**
`clairaut(G, Family, Envelope)` 由 g(t) 的表达式（多项式/常用函
数表）生成通解族与包络（符号微分 + 消参）；`tangent_point(G, C,
X, Y)` 给出直线 C 与包络的切点；`lagrange(F, G, ...)` 完成化归为
x(p) 线性方程的第一步。断言例：

```prolog
?- clairaut(pow(t,2), Family, Env).
Family = line(C, add(mul(C,x), pow(C,2))),   % y = Cx + C²
Env = para(mul(-1,div(pow(x,2),4))).         % y = -x²/4
?- tangent_point(pow(t,2), 3, X, Y).
X = -6, Y = -9.                               % 切点（-2C, -C²）
```

另加换轨检测：`switch_solution(From, At, To)` 枚举穿过给定点的解
（直线族解 + 奇异解 + 换轨拼合解），数一数穿点解的个数——Cauchy
问题解不唯一的机器账。

**Julia（`06_clairaut.jl`）/ Python（`06_clairaut.py`）**：
(a) 例 5 数值核对——对 C 网格求直线 y = Cx + C² 与抛物线
y = −x²/4 的交点（解二次方程），验证交点处两者斜率相等（残差 <
10⁻¹²）：包络的相切性质；(b) 例 1 两族解代入原方程的残差核对
（y = x² + C 支：2x 代入应使 y′² − 2(x+y)y′ + 4xy = 0 恒成立）；
(c) 换轨数值实验——从 (−1, −1/4)（在包络上）附近用 RK4 积分例 5
的方程（以 p = y′ 为变量解出两支 y′ = (y − x·p − p²)=0 的求根公
式……实际按分支场积分），演示初始点在包络两侧时解分别贴直线族与
贴包络；(d) 例 2 换轨解的连续可微性核对（拼接点 x = 0 处左右导数
相等）。

**Lean（`Ode/Ch06Clairaut.lean`）——例 5 的两份逐字证明。**
直线族解：对任意 C，y = Cx + C² 满足 y = xy′ + y′²（y′ = C，
代入右端 xC + C² = 左端——一次 `HasDerivAt` + `ring`）；奇异解：
y = −x²/4 也满足（y′ = −x/2，右端 x·(−x/2) + (−x/2)² = −x²/4
= 左端）——**两份证明并排就是"通解 + 奇异解"的机器版**：

```lean
/-- Clairaut y = xy' + y'²：直线族解 y = Cx + C²（任意 C）。 -/
theorem clairaut_line (C : ℝ) (x : ℝ) :
    (fun x => C * x + C ^ 2) x = x * C + C ^ 2 := by ring
/-- 奇异解 y = -x²/4：y' = -x/2，x·(-x/2) + (-x/2)² = -x²/4 ✓。 -/
example (x : ℝ) : HasDerivAt (fun x => -x ^ 2 / 4) (-x / 2) x := by
  -- (x²/4)' = x/2 的 HasDerivAt 组合子账
  ...
```

（第一行的"平凡"正是要点：通解族的验证是平凡的，奇异解的验证
也平凡——不平凡的是**它不在族里**，Lean 文件里用"y = −x²/4 不存
在 C 使其恒等于 Cx + C²"（取 x = 0 与 x = 1 两点得矛盾 C² = 0 与
C + C² = −1/4）补上这一刀。）

## 6.5 要点回顾

1. F(x, y, y′) = 0 对 y′ 解出多个分支 ⟹ 多个方向场；通解 = 各支
   通解之并；分支相切处（P² = Q）可能长出奇异解。
2. F(x, y′) = 0 型用参数化：令 t = y′，解出 x(t)，dy = t·dx 积出
   y(t)。
3. Lagrange 方程 y = f(y′)x + g(y′) 求导后化成 x(p) 的线性方程；
   f 的不动点 t₀ 给特解直线。
4. Clairut 方程（f ≡ t）两支：p′ = 0 给直线族通解 y = Cx + g(C)；
   x = −g′(t) 给包络奇异解。包络与每条直线相切、不属于族——
   Cauchy 唯一性在包络上破产，数值步进可能静默换轨。
5. "验证解"永远比"求解"容易：直线族与奇异解的机器验证都是一阶
   求导账，但"奇异解不在族中"需要单独的反证。
