# 30 变分法

**对应书 §12 Calculus of Variations：泛函、Euler 方程、特殊情
形、几何应用（brachistochrone）、多函数/高阶/动边界/等周、直接
方法（Ritz）。**

---

## 30.1 函数的函数：泛函极值

**泛函** J[y] = ∫ₐᵇ F(x, y, y′) dx 把整条曲线映成一个数。变分法
求"哪条曲线让 J 取极值"——最短线、最速降、最小曲面、最小作用
全是这类问题。

**一阶变分**：给 y 加小扰动 εη（η(a) = η(b) = 0），展开
J[y + εη] = J[y] + εδJ + O(ε²)。极值的必要条件 δJ = 0 对一切 η：

    δJ = ∫ (F_y η + F_{y′} η′) dx = ∫ [F_y − d/dx F_{y′}] η dx
   （分部积分，边界项被 η = 0 吸收）

η 任意 ⟹ **Euler(-Lagrange) 方程**：

    **F_y − d/dx F_{y′} = 0**。

这是 ODE 教程里变分法的接口：**泛函极值 ⟺ 解一个（常）微分方
程**——ODE 回到了舞台中央。

**特殊情形**（书 §12.3.2 的速查表）：F 不含 y′ ⟹ F_y = 0（代数）；
F 不含 y（Beltrami）⟹ F_{y′}y′ − F = C（首次积分）；F 不含 x ⟹
F − y′F_{y′} = C（能量积分）；F 只含 y′ ⟹ 直线。

## 30.2 应用四连：几何变分的名场面

**最速降线（brachistochrone）**（书 §12.4.1）：重场中从 A 滑到 B
的最快曲线是**摆线**（cycloid）——不是直线！T[y] = ∫√((1+y′²)/
(2gy)) dx，Beltrami 给 1/√y·1/√(1+y′²) = C ⟹ 摆线。时间账：
直线用时比摆线多 ~15%（A=(0,0), B=(1,−1) 时 T_line/T_cyc ≈ 1.147）
——反直觉的定量化。

**最短线**：F = √(1+y′²) ⟹ 直线；球面上是大圆（书 §12.4.5）。
**最小旋转面**：悬链线（肥皂膜）。**等周问题**（书 §12.8）：
周长固定围最大面积 ⟹ 圆（拉格朗日乘子进变分）。

**最小作用原理**（书 §12.5.2）：L = T − V 的作用量驻定 ⟹ 牛顿
方程——力学的变分重构。多自由度/多函数版本给方程组形式的 EL。

## 30.3 直接方法：Ritz 近似

Euler 方程解不出时**不经过微分方程**：把 y 近似成基函数组合
y ≈ Σcᵢφᵢ，代入 J 得 c 的**多元函数** J(c₁,…,cₙ)，求偏导为零
——变分问题降维成代数方程组（书 §12.10 的 Ritz 法）。这是有限
元法的思想祖先，量子化学（氢原子基态的试探函数，书 §12.10.2：
ψ = e^{−βr} 给 E₁ = −½ Hartree 精确值）的经典操作。

## 30.4 机器验证

**Julia（`30_variational.jl`）/ Python（`30_variation.py`）**：
(a) Euler 方程核对：J = ∫(y′² − y²)，Euler 方程 y″ + y = 0——
解 y = sin x 上 J 达到驻定（一阶变分数值为零：扰动 J[驻定解 +
εη] − J[驻定解] = O(ε²) 数值验证）；(b) **brachistochrome 时间
账**：摆线 vs 直线 vs 抛物线的下滑时间数值积分（1 : 1.147 :
1.025），摆线最短 ✓；(c) Beltrami 积分核对：摆线参数解满足
1/(√y√(1+y′²)) = 常数；(d) **Ritz 法**：J = ∫(y′² − y²)/2 +
fy、y(0) = y(1) = 0，基 {sin nπx}，系数方程解出 y₁ = f₁·
(π²−1)⁻¹ —— 与精确解 Fourier 系数一致；氢原子试探：E(β) =
β²/2 − β 的最小在 β = 1 给 E = −0.5。

**Prolog（`30_variational.pl`）**：Euler 方程推导规则（F 的三项
符号微分 → y″ 系数表）、Beltrati 情形分类、Ritz 一基系数公式、
brachistochrone 时间常数表。

## 30.5 要点回顾

1. δJ = 0 + η 任意 ⟹ Euler 方程 F_y − d/dx F_{y′} = 0：泛函极值
   化为 ODE。
2. 速查表：缺 y′（代数）、缺 y（Beltrami 首次积分）、缺 x（能
   量积分）——对症下药省一半推导。
3. 名场面：最速降 = 摆线（比直线快 15%）、最短 = 直线/大圆、最
   小旋转面 = 悬链线、等周 = 圆、最小作用 ⟹ 牛顿。
4. Ritz 直接法：基函数 + 代数方程组——不经过 Euler 方程的数值
   路线，有限元的祖先。
