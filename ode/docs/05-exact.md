# 05 恰当方程与积分因子

**对应书 §2.5 Exact Equations。**

---

## 5.1 微分形式：一阶方程的第二种记法

任何一阶方程都能写成**微分形式**

    P(x, y) dx + Q(x, y) dy = 0，

（y′ = f(x,y) 即 −f dx + dy = 0；反过来除以 dx 也行）。这种记法
不指定谁是自变量——x 与 y 平起平坐，为"交换自变量"（4.5(a)）和
本章的"原函数"观点铺路。

若左端恰好是某个二元函数 F(x, y) 的**全微分**

    dF = (∂F/∂x) dx + (∂F/∂y) dy = P dx + Q dy，

则方程成为 dF = 0，解立即可写：

    F(x, y) = C（隐式通解）.

这样的方程叫**恰当方程**（exact）。沿解曲线 x → y(x)，链式法则给
dF/dx = F_x + F_y·y′ = P + Q·y′ = 0，正合方程；反过来说，恰当方程
的解就是 F 的等高线。

## 5.2 恰当性判据：P_y = Q_x

P dx + Q dy 是全微分 ⟺ 混合偏导相容。微积分的定理（单连通域上）
说：F 存在使 F_x = P、F_y = Q，当且仅当

    **∂P/∂y = ∂Q/∂x.**

必要性一眼看穿：F_xy = F_yx；充分性是构造性的——正是下面的求 F
协议。先验证判据，再动手，永远按这个顺序。

**求 F 的协议**（"积分一路、求导另一路、定 C(y)"）：

1. 由 F_x = P 对 x 积分（视 y 为常数）：
   F(x, y) = ∫P dx + C(y)——"积分常数"是 y 的函数（对 x 积分时 y
   是参数）；
2. 代入 F_y = Q：∂/∂y[∫P dx] + C′(y) = Q；
3. 若方程恰当，右侧 Q − ∂/∂y∫P dx **只含 y**（x 全部抵消——这一步
   就是充分性的现场证明），积分定出 C(y)；
4. 通解 F(x, y) = C₁（把两个常数并成一个）。

**例 1**（书例 2.22）(3x²y² + 7) dx + 2x³y dy = 0。判据：
∂P/∂y = 6x²y = ∂Q/∂x ✓。求 F：F_x = 3x²y² + 7 给
F = x³y² + 7x + C(y)；F_y = 2x³y + C′(y) = 2x³y 给 C′ = 0。通解：

    x³y² + 7x = C.

**例 2**（习题风格）2xy dx + (x² − y²) dy = 0。判据：
∂P/∂y = 2x = ∂Q/∂x ✓。F = x²y + C(y)；F_y = x² + C′ = x² − y²
给 C′ = −y²，C = −y³/3。通解 **x²y − y³/3 = C**。

## 5.3 积分因子：不恰当时的补救

不恰当的方程，有时乘一个**积分因子** μ(x, y) 后变恰当：

    μ(P dx + Q dy) = dF.

乘 μ 后的恰当条件 (μP)_y = (μQ)_x 是 μ 的一阶线性**偏**微分方程
——一般情形解它和解原方程一样难，所以**没有通用方法**。但两个特
殊情形有公式可套（推导都是把恰当条件改写成 μ 的 ODE）：

**情形 A：只依赖 x 的 μ。** 若

    (P_y − Q_x)/Q = φ(x)（只含 x），

则 μ(x) = e^(∫φ dx)。验证：代入 (μP)_y = (μQ)_x 化为
μ′Q + μQ_x = μP_y，即 μ′/μ = (P_y−Q_x)/Q = φ(x)。

**情形 B：只依赖 y 的 μ。** 若

    (Q_x − P_y)/P = ψ(y)（只含 y），

则 μ(y) = e^(∫ψ dy)。

而第 04 章的线性方程 [p(x)y − f(x)]dx + dy = 0 的 μ = e^(∫p dx)
正是情形 A——线性方程的积分因子法是本章的特例（书的 Reading
Exercise，机器通道会核这条桥）。

**例 3**（书例 2.23）[x + x²(x² + y²)]dx + y dy = 0。判据先算：
∂P/∂y = 4x³y ≠ 0 = ∂Q/∂x，不恰当。观察结构（x dx + y dy 与
x²(x²+y²)dx 的组合）：猜 μ = 1/(x²+y²)。乘开后

    [x/(x²+y²) + x²]dx + [y/(x²+y²)]dy = 0，

前一部分是 (1/2)ln(x²+y²) 的全微分，后一部分是 x³/3 的——恰当！
通解 (1/2)ln(x²+y²) + x³/3 = C₁，整理成

    √(x² + y²)·e^(2x³/3) = C.

μ ≠ 0 处处成立，无多余解。这个例子说明：套公式之外，**看结构猜
μ**（把 P dx + Q dy 拆成熟悉的全微分块）是实战主力——μ = 1/(x²+y²)
之所以想到，是因为 x dx + y dy = (1/2)d(x²+y²) 与分母 x²+y² 的配
对。乘 μ 的另一个账单：μ = 0 的解可能是**多余解**，要剔除（书特
别提醒）。

## 5.4 机器验证

**Julia（`05_exact.jl`）/ Python（`05_exact.py`）**：
(a) 判据数值核——对例 1 的 P、Q 在网格点用中心差分算 P_y、Q_x，
最大差 < 10⁻⁶（解析上恒等，数值上只受差分精度限制）；
(b) 通解核验——沿 F = x³y² + 7x = 7 的隐式曲线数值求 y′（隐函数
求导 y′ = −F_x/F_y），代回 P + Qy′ 应为 0：抽样最大残差 < 10⁻¹⁰；
(c) 例 3 的乘 μ 变换：数值验证 μ(P_y − Q_x)…不对，直接验证乘 μ
后 (μP)_y = (μQ)_x 数值成立；(d) 符号偏导——用有限差分对
μ = 1/(x²+y²) 全套重算，等高线 F = C 抽样点全部落在数值解曲线
上（RK4 从等高线一点出发积分，法向偏差 < 10⁻⁸）。

**Prolog（`05_exact.pl`）——恰当性判定 + 求势函数 + 积分因子探测。**
对多项式 P、Q（表达式树）符号执行：`exact(P, Q)` 算 ∂P/∂y 与
∂Q/∂x 化简比对；`potential(P, Q, F)` 执行 5.2 协议（对 x 逐项积分、
求导比对、定 C(y)——多项式域内完全机械化）；`try_mu_x(P, Q, Mu)`
检验 (P_y−Q_x)/Q 是否只含 x 并给出 μ。断言例：

```prolog
?- exact(add(mul(3,mul(pow(x,2),pow(y,2))), 7), mul(2,mul(pow(x,3),y))).
true.
?- potential(add(mul(3,mul(pow(x,2),pow(y,2))), 7),
              mul(2,mul(pow(x,3),y)), F).
F = add(add(pow(x,3),mul(pow(y,2),0)), ...).   % F = x³y² + 7x（+C(y)=0）
?- try_mu_x(sub(mul(p(x), y), f(x)), n(1), Mu).  % 线性方程的桥
Mu = exp(integral(p(x))).                        % μ = e^{∫p}，5.3 情形 A
```

**Lean（`Ode/Ch05Exact.lean`）——判据与势函数的严格账。**
对例 1：取 F(x, y) = x³y² + 7x，证 `hasDerivAt` 意义下沿任何满足
F = C 的可微曲线 y(x)（以 F_x = −P、F_y = Q 的隐函数求导假设为
前提，用 `HasDerivAt` 直接计算）有 P + Q·y′ = 0。更朴素也更有力
的一版：证明 F 的两个偏导确实等于 P、Q——

```lean
/-- 例 1 的势函数核对：∂F/∂x = 3x²y² + 7，∂F/∂y = 2x³y。 -/
example (x y : ℝ) :
    HasDerivAt (fun x => x ^ 3 * y ^ 2 + 7 * x) (3 * x ^ 2 * y ^ 2 + 7) x := ...
example (x y : ℝ) :
    HasDerivAt (fun y => x ^ 3 * y ^ 2 + 7 * x) (2 * x ^ 3 * y) y := ...
```

两个单变量偏导命题（另一个变量冻结成参数），各一行 `HasDerivAt`
组合子。再加混合偏导对易的现场版：∂/∂y(∂F/∂x) = ∂/∂x(∂F/∂y)
= 6x²y——**判据的必要性在这个 F 上被逐字验算**。

## 5.5 要点回顾

1. 微分形式 P dx + Q dy = 0 让 x、y 平起平坐；恰当 ⟺ 左端是全微
   分 dF ⟺ 判据 P_y = Q_x（单连通域）。
2. 求 F 协议：对 x 积分得 F = ∫P + C(y)，对 y 求导比对定 C(y)；
   C(y) 中 x 项全部抵消本身就是充分性证明。
3. 积分因子无通用方法；两个可套的情形：(P_y − Q_x)/Q 只含 x ⟹
   μ = e^(∫φdx)；对称情形只含 y。线性方程的 μ = e^(∫p dx) 是情
   形 A 的特例。看结构猜 μ（拆全微分块）是实战主力。
4. 乘 μ 可能引入 μ = 0 的多余解，也可能丢解——账单纪律照旧。
5. "∫P dx + C(y) 含任意函数"是 PDE 世界的预告：n 阶 PDE 通解含 n
   个任意**函数**（书 Remark）。
