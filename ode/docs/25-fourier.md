# 25 Fourier 级数

**对应书 §8 Fourier Series：系数、收敛、任意区间、正弦/余弦级
数、复形式、广义级数、Gibbs 现象、Fourier 变换。**

---

## 25.1 周期函数的"坐标分解"

以 2π 为周期的函数 f 展成三角正交基：

    f(x) ~ a₀/2 + Σ [aₙcos nx + bₙsin nx]，
    aₙ = (1/π)∫_{−π}^{π} f cos nx dx，bₙ = (1/π)∫ f sin nx dx。

**正交性**是全部机制的引擎：∫cos mx·cos nx = 0（m ≠ n）等三
组恒等式（积化和差直接验证）让系数公式"自动投影"。几何观点：
{1, cos x, sin x, cos 2x, …} 是函数空间的一组正交基，Fourier 系
数就是坐标——**线性代数在无穷维的重演**。

**收敛**（书 §8.3）：f 分段光滑 ⟹ 级数在连续点收敛到 f(x)、
跳跃点收敛到左右极限的**中点** (f⁺+f⁻)/2。这不是瑕疵而是本性：
部分和是连续函数，极限在跳跃点只能取折中。

**任意区间** [−L, L]：换元 x → πx/L；正弦/余弦级数（书 §8.6）：
半区间上延拓（偶延拓给余弦级数、奇延拓给正弦级数）——边界值问
题（第 26 章）的标配。

## 25.2 Gibbs 现象与收敛速率

**Gibbs 现象**（书 §8.11）：在跳跃点附近，部分和**过冲**约
8.95%（(1/π)∫₀^π sin t/t dt − 1 ≈ 0.0895）——不随 N 减小，只
是区间变窄。Fourier 级数逐点收敛但对"跳"无能为力：过冲是截断
的固有代价。

**速率**：系数衰减 aₙ ~ O(1/n)（跳跃）、O(1/n²)（连续但导数
跳）、O(1/n³)……越光滑衰减越快——**谱精度**的雏形。

**Parseval**（书 §8 广义级数的推论）：
(a₀²/2 + Σ(aₙ²+bₙ²)) = (1/π)∫f² —— 时域能量 = 频域能量，滤
波的守恒账本。

## 25.3 复形式与 Fourier 变换

**复形式**（书 §8.8）：f = Σ cₙe^{inx}，cₙ = (1/2π)∫f e^{−inx}
——把两组实基合成一组复基，公式对称化，工程（信号处理）的标
准记法。**Fourier 变换**（书 §8.12）：周期 → ∞ 的极限，
F(ω) = ∫f e^{−iωx} dx——连续谱替代离散谱。ODE 的应用：正弦驱
动通过系统 = 每个频率分量独立放大/相移（第 14 章的频域重述），
RLC 全响应的频域分析。

## 25.4 机器验证

**Julia（`25_fourier.jl`）/ Python（`25_fourier.py`）**：
(a) 系数公式核对：方波（±1）的 bₙ = 4/(πn)（奇 n）数值积分复
算；(b) 部分和收敛：N = 10/50/200 在远离跳跃点的误差（→ 0，
O(1/N) 速率拟合）；跳跃点收敛到中点 0；(c) **Gibbs 过冲**：部
分和的极值 − 1 ≈ 0.0895（对 N = 200 拟合，断言 0.085..0.095）；
(d) Parseval：Σbₙ² = (1/π)∫f²（截断 200 项对照，误差 O(1/N)）；
(e) 光滑性-速率：f = x²（余弦系数 ~1/n²）与方波（~1/n）的系数
衰减拟合；(f) 复形式：cₙ 与 aₙ, bₙ 的换算（cₙ = (aₙ − ibₙ)/2）
数值核对。

**Prolog（`25_fourier.pl`）——系数引擎。** `coeffs(F, N, Table)`：
对符号可积的右端（多项式/|x| 型）生成系数表；方波与锯齿波的
bₙ 闭式（rational）；`parseval_partial` 截断能量账。

## 25.5 要点回顾

1. Fourier 级数 = 正交基上的坐标分解；正交性给系数公式，机制全
   在"投影"。
2. 收敛：连续点 → f，跳跃点 → 中点；速率由光滑度决定（谱精度
   雏形）。
3. Gibbs 8.95% 过冲是截断的固有代价，不随 N 消失。
4. Parseval：能量守恒账本；复形式对称化；FT = 周期无穷大的极限。
5. 半区间延拓（奇/偶）配边界条件——第 26 章 Sturm–Liouville 的
   第一课。
