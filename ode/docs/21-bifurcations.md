# 21 分岔：参数扫过临界点

**对应书 §5.4.1 Systems Depending on Parameters、§5.4.2 Monotonic
Instability（鞍结/跨临界/叉式）、§5.4.3 Oscillatory Instability
（Hopf）。**

---

## 21.1 分岔：定性行为的突变

含参数系统 x′ = f(x, μ) 在参数 μ 扫过**分岔值** μ_c 时，相图的
定性结构（奇点个数/类型/稳定性）发生突变——这个事件叫**分岔**
（bifurcation）。第 07 章一维相线已经见过（y′ = ky 的 k 过零：
sink 变 source）。分岔理论把突变的"模板"分类——**范式**
（normal form）：低维多项式系统浓缩了所有一般情形的局部行为。

**分析协议**：① 解 f(x, μ) = 0 得奇点曲线 x*(μ)；② 对每个 μ 分
析稳定性（Jacobian / 一维符号分析）；③ 标出稳定性改变的 μ 值
——分岔点；④ 画**分岔图**（x* 对 μ 的曲线，稳定实线/不稳定虚
线）。

## 21.2 单调失稳三范式（一维）

**鞍结分岔**（saddle-node）y′ = μ − y²：μ < 0 无奇点；μ = 0 半
稳定；μ > 0 两个奇点 ±√μ（上稳下不稳）——奇点**成对产生/湮
灭**。生态例：收获模型 y′ = ry(1 − y/K) − h，收获量 h 扫过临界
值 h_c = rK/4 时种群灭绝（ saddle-node of equilibria）——
"过度捕捞崩溃"。

**跨临界**（transcritical）y′ = μy − y²：两条奇点线 y = 0 与
y = μ 在 μ = 0 **交换稳定性**——激光阈值（μ < 0 暗态稳定，
μ > 0 亮态稳定）是教科书案例。

**叉式**（pitchfork）y′ = μy − y³：μ < 0 只有 y = 0（稳）；
μ > 0 时 y = 0 失稳，**对称破缺**出 ±√μ 两支稳定奇点——磁化
（Ising）、屈曲（杆受压）的原型。超临界（如上，新支稳定）与亚
临界（y′ = μy + y³ − y⁵，新支不稳定、滞后回线）两种。

## 21.3 振荡失稳：Hopf 分岔（二维）

一维只能单调失稳；**振荡失稳**需要二维：特征值**共轭对穿过虚
轴**（τ = tr A 从负过零，Δ > 0 保持）。范式（书 §5.4.3）：

    x′ = μx − y − x(x² + y²)，y′ = x + μy − y(x² + y²)，

极坐标下 r′ = r(μ − r²)、θ′ = 1：μ < 0 原点稳定焦点；μ > 0
原点失稳、**冒出半径 √μ 的稳定闭轨（极限环）**——小振荡从平衡
点连续长出（超临界 Hopf）。**物理签名**：特征值实部过零
⟹ 增长率从负变正、振荡频率 √Δ 有限——系统从"安静"自激出等
幅振荡（水管哨、激光自脉动、心脏起搏细胞）。

## 21.4 机器验证

**Julia（`21_bifurcation.jl`）/ Python（`21_bifurcation.py`）**：
(a) 三范式分岔图数据：对 μ 网格解奇点方程 + 符号/线性化判稳，
输出 (μ, x*, 稳定性) 表，断言范式行为（鞍结对、交换、对称破
缺）；(b) 收获模型崩溃：h 扫过 rK/4 前后奇点数与稳定性；数值积
分 h = h_c + 0.01 时种群灭绝时间 < h_c − 0.01 时存活；
(c) Hopf：极坐标范式 r′ = r(μ − r²) 的解析解 r(t) → √μ 对照
数值；μ 过零时原点稳定性翻转 + 闭轨半径 √μ 的标度律（三点拟
合指数 0.5）；(d) 亚临界叉式的滞后回线：μ 上扫 vs 下扫的跳变点
不同。

**Prolog（`21_bifurcation.pl`）——范式识别器。**
`normal_form(Eq, Kind)`：识别三范式（μ、y 的多项式形态匹配）；
`equilibria(NormalForm, Mu, Es)` + `stability(Es, Mu, Map)`：奇点
与稳定性的符号计算（多项式根 + 符号）；`hopf_check(Mu, Type)`。
断言：三范式各一 + Hopf。

## 21.5 要点回顾

1. 分岔 = 参数扫过临界值时相图定性结构突变；分岔图（稳定实线/
   虚线）是标准输出。
2. 一维三范式：鞍结（成对生灭）、跨临界（交换稳定性）、叉式
   （对称破缺 ±√μ）；滞后是亚临界的签名。
3. Hopf（二维）：共轭特征值对穿虚轴，稳定焦点失稳冒出极限环
   （超临界半径 √μ）——自激振荡的数学机制。
4. 分析协议：奇点曲线 → 判稳 → 定分岔点 → 画图；数值通道扫参
   数复算全表。
