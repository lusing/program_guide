# 20 Lyapunov 稳定性

**对应书 §5.3 Stability of Solutions in the Case of Nonlinear
Systems（Lyapunov 稳定性、线性化、轨道稳定性）。**

---

## 20.1 三级稳定性：定义先于直觉

平衡点 x*（f(x*) = 0）的稳定性有严格分级（Lyapunov 意义）：

- **稳定**（Lyapunov 稳定）：初值离 x* 近 ⟹ 解**始终**留在 x*
  附近（ε–δ 语言：∀ε ∃δ，|x(0) − x*| < δ ⟹ |x(t) − x*| < ε 对
  一切 t ≥ 0）。中心是稳定但不吸引的例子。
- **渐近稳定**：稳定 + 吸引——t → ∞ 时 x(t) → x*。
- **不稳定**：连"留在附近"都做不到。

**轨道稳定性**（书 §5.3.3）：对闭轨 Γ（如极限环），解不必同步
（相差相位），只要求轨道形状靠近：初值靠近 Γ ⟹ 解的轨道永远贴
着 Γ。极限环是"渐近轨道稳定"的闭轨——第 22 章主角。

## 20.2 线性化判据：特征值说话

第 19 章的线性化 + 分类立刻给稳定性判据（书 §5.3.2）：

- A = Df(x*) 的特征值**实部全负** ⟹ x* 渐近稳定；
- 任一特征值**实部为正** ⟹ x* 不稳定；
- 有零实部、无正实部 ⟹ **临界情形**，线性化不定论。

对二维系统这正是迹–行列式图上的"左半平面"区域（τ < 0, Δ > 0）。
指数收敛速率由最靠近虚轴的特征值（谱横坐标）决定。

## 20.3 Lyapunov 函数：不用解方程的稳定性证明

**直接方法**（Lyapunov 第二方法）是稳定性理论的皇冠：找一个
**Lyapunov 函数** V(x)（正定：V(x*) = 0、V > 0 否则），沿轨道求
导

    V̇(x) = ∇V(x)·f(x)，

- V̇ ≤ 0 ⟹ 稳定；V̇ < 0（除 x* 外）⟹ **渐近稳定**（能量单调
  衰减，轨道必然沉向最低点）；
- V̇ > 0 某处 ⟹ 不稳定。

直觉就是**能量**：阻尼振子的能量 E = ½v² + ½ω₀²x² 沿轨道
Ė = −cv² ≤ 0——"能量 downhill"逼着解回到平衡。Lyapunov 方法把
"能量"抽象化：任何正定递减的量都能当证明。**幂级数式的找法**：
二次型 V = xᵀPx（P 正定）对线性系统总可行（解 Lyapunov 方程
AᵀP + PA = −Q）；非线性时加高阶修正。

**例 A**：阻尼振子 x″ + 2δx′ + ω₀²x = 0 的 V = ½(v² + ω₀²x²)：
V̇ = −2δv² ≤ 0 ⟹ 渐近稳定（δ > 0）。
**例 B**：x′ = −x³ 的 V = x²/2：V̇ = −x⁴ < 0 ⟹ 渐近稳定（但速
率是幂式 1/√t——第 07 章例 4 的重逢）。
**例 C**（线性化失效）：x′ = −x³ 在 x* = 0 处 A = 0（临界情
形），Lyapunov 方法照样判稳——直接方法比线性化更强。

## 20.4 机器验证

**Julia（`20_stability.jl`）/ Python（`20_stability.py`）**：
(a) 线性化判据扫奇点：单摆两个奇点 + van der Pol 原点（线性化
临界、Lyapunov 接管的前哨）；(b) Lyapunov 函数数值实验：阻尼振
子沿轨道 E(t) 单调降（断言 dE/dt ≤ 0 逐点成立）与指数衰减率
e^{−2δt} 对照；x′ = −x³ 的幂式衰减 1/√(2t) 拟合；(c) 稳定性三
级数值区分：中心（轨道范数守恒）、渐近稳定（→0）、不稳定（离
开）；(d) 轨道稳定性预热：闭轨（中心圆族）附近轨道保持有界。

**Lean（`Ode/Ch20Stability.lean`）**：x′ = −x 的解 e^{−t}x₀ 趋

## 20.5 要点回顾

1. 稳定/渐近稳定/不稳定是三层定义；中心稳定但不吸引；轨道稳定
   性对闭轨放宽"同步"要求。
2. 线性化判据：实部全负 ⟹ 渐近稳定；有正 ⟹ 不稳定；零实部 ⟹
   临界不定论。
3. Lyapunov 直接方法：正定 V + V̇ ≤ 0（< 0）⟹ 稳定（渐近稳定）；
   能量是原型，二次型是工程标配（Lyapunov 方程）。
4. 直接方法在临界情形仍然有效（x′ = −x³），是线性化的加强版。
