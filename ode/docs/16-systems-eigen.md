# 16 常系数方程组：特征值方法

**对应书 §4.4 Systems of Linear Homogeneous Differential Equations
with Constant Coefficients、§4.5 非齐次。**

---

## 16.1 消元法与特征值：二元系统的两张面孔

**x′ = Ax**（A 常数矩阵）。手算路线是**消元**（书 §4.4 的主力）：
从 x′ = a x + b y、y′ = c x + d y 中把 y 解出来代入另一式，得到
x 的二阶方程

    x″ − (a + d)x′ + (ad − bc)x = 0，

特征方程 λ² − (tr A)λ + det A = 0——**矩阵的特征多项式**！特征值
方法从此登场：A 的特征值 λ₁,₂ 决定解的形态：

- **实异根** λ₁ ≠ λ₂，特征向量 v₁, v₂：通解
  **x = C₁e^{λ₁t}v₁ + C₂e^{λ₂t}v₂**；
- **复根** α ± iβ（共轭成对）：实解 e^{αt}(cos βt·u − sin βt·w)
  与 e^{αt}(sin βt·u + cos βt·w)，其中 v = u + iw 是复特征向量；
- **重根** λ（几何重数 1）：第二解 t·e^{λt}v + e^{λt}w（广义特
  征向量 w 满足 (A − λI)w = v）——二阶重根升次规则的矩阵版。

n 元系统完全同理（书 §4.4 末）：特征多项式 det(A − λI) = 0 的根
配特征向量/广义特征向量链，解 = Σ Cᵢe^{λᵢt}(vᵢ + t·… )。

**稳定性速判**（第 19 章的预告）：所有特征值实部 < 0 ⟹ 一切解
→ 0（渐近稳定）；任一实部 > 0 ⟹ 有解指数增长；有零实部且无重
根 ⟹ 有界但不衰减。

## 16.2 非齐次：待定系数的向量版

x′ = Ax + f(t)：通解 = 齐次通解 + 特解。特解工具箱：

- f = 常向量 b：试 ȳ = −A⁻¹b（A 可逆时）；
- f = e^{γt}b：试 ȳ = e^{γt}w，解 (γI − A)w = b（共振 γ = λ 时
  升次 t·e^{γt}）；
- f = cos/sin 型：化成复指数处理（欧拉公式），取实虚部。

叠加原理照旧：f 拆件、特解相加。

## 16.3 机器验证

**Julia（`16_eigen.jl`）**：(a) 消元 vs 特征值双算：A = [[2, 1],
[1, 2]]（特征 1, 3），消元得到的二阶方程特征多项式
λ² − 4λ + 3 对照 det(A − λI)；(b) 三情形的解析解 vs 数值积分
（RK4 向量化）：实异根、复根（旋转+衰减）、重根（Jordan 型
[[1,1],[0,1]]）各一组；(c) 非齐次 e^{γt}b 的待定系数特解代入残
差；(d) Wronskian：X(t) 的 det 与 e^{(tr A)t} 对照。

**Python（`16_eigen.py`）**：scipy.linalg.eig 交叉——特征值/特征
向量与手算对照；solve_ivp 数值解 vs 解析解组合；重根情形的
t·e^{λt} 项核对。

**Prolog（`16_eigen.pl`）——2×2 分类器。** `eigs2(Tr, Det, Case)`
（判别式三分 + 有理根）；`solution_form(Case, Form)`；`classify
stability(Eigs, Stable)`（实部符号判定）。断言：三情形各一例 +
稳定性判定。

## 16.4 要点回顾

1. 消元 ⟹ 特征多项式 λ² − (tr A)λ + det A：特征值是"矩阵的DNA"。
2. 解 = e^{λt}·(特征向量方向)；复根给旋转（cos/sin），重根升次
   t·e^{λt}，广义特征向量链接手。
3. 非齐次待定系数的向量版：解线性方程组 (γI − A)w = b，共振升次。
4. 稳定性 = 特征值实部的符号——第 19 章奇点分类的全部输入。
