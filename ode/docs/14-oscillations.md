# 14 振动应用：机械振动、RLC 电路与浮体

**对应书 §3.10 Applications。**

---

## 14.1 弹簧–质量系统：三种阻尼

质量 m、劲度 k、阻尼 c 的弹簧振子（书图 3.12 型）：

    mx″ + cx′ + kx = 0    ⟹    x″ + 2δx′ + ω₀²x = 0，
    2δ = c/m，ω₀ = √(k/m)（固有频率），δ/ω₀ 决定 regime。

特征方程 k² + 2δk + ω₀² = 0，判别式 δ² − ω₀²：

- **δ² < ω₀²（欠阻尼）**：复根 −δ ± iω，ω = √(ω₀² − δ²)，
  x = e^{−δt}(A cos ωt + B sin ωt)——衰减振荡，准周期 2π/ω，
  包络 e^{−δt}；
- **δ² = ω₀²（临界阻尼）**：重根 −δ，x = (A + Bt)e^{−δt}——最快
  无振荡回平衡（门吸、天平指针的设计点）；
- **δ² > ω₀²（过阻尼）**：两负实根，x = Ae^{k₁t} + Be^{k₂t}——缓
  慢蠕回，无振荡。

**品质因数** Q = ω₀/2δ：能量 ∝ 振幅²，每准周期损失
ΔE/E = 4πδ/ω ≈ 4π/Q。

## 14.2 受迫振动与共振：完整的频率响应

加周期外力 F₀cos ωt：

    x″ + 2δx′ + ω₀²x = (F₀/m)cos ωt.

特解（待定系数，非共振 ω ≠ ω₀... 含阻尼时永不真正共振因为根是
复的）：

    x_p = X(ω)cos(ωt − φ)，X(ω) = F₀/m / √((ω₀²−ω²)² + (2δω)²)，

  tan φ = 2δω/(ω₀² − ω²)。**振幅放大率 X(ω)** 的峰值在 ω_r =
√(ω₀² − 2δ²)（幅值共振），δ → 0 时 ω_r → ω₀ 且峰值 → ∞（第
11 章的共振）。**带宽**：半功率点 ω₁,₂ ≈ ω_r ± δ，Q = ω_r/2δ。
瞬态（齐次解）衰减后只剩稳态 x_p——这是"扫频实验"读出系统参数
的理论基础。

## 14.3 RLC 电路：同一个方程，另一套单位

基尔霍夫电压定律给串联 RLC（书 §3.10.2）：

    Lq″ + Rq′ + q/C = E₀cos ωt（q 是电容电荷），

与 14.1 **逐字同构**：L ↔ m（惯性），R ↔ c（耗散），1/C ↔ k
（恢复），E ↔ F（驱动）。m–k–c 的三种阻尼、共振、带宽全部翻译
成电路语言：欠阻尼 = 振铃（ringing），临界阻尼 = 最佳脉冲响应，
共振 = 选频（收音机调谐、无线充电）。机电类比是"一个数学结构、
多个物理化身"的教科书范本。

**数字例**（书型）：L = 0.1 H，C = 10⁻³ F，R = 2 Ω：
ω₀ = 1/√(LC) = 100 s⁻¹，2δ = R/L = 20 ⟹ δ = 10，ω = √(10000−100)
≈ 99.5——欠阻尼，Q = ω₀/2δ = 5。受迫时峰值在 ω_r =
√(10000 − 200) ≈ 98.99。

## 14.4 浮体：常系数方程的静力学起源

半浸圆柱/浮标竖直小振动（书 §3.10.3）：吃水深度 h，浮力 = ρgAwim
（A 水线面积）。竖直位移 z 的恢复力 = −ρgA·z，运动方程

    mz″ = −ρgA·z −（阻尼项）⟹ z″ + (ρgA/m)z = 0，
    ω = √(ρgA/m) = √(g/h)（因为 m = ρAh）。

浮体是"重力弹簧"：周期 T = 2π√(h/g) 只依赖吃水深度——与钟摆
周期只依赖摆长同构。加上水动力阻尼（波浪辐射）与附加质量，就是
船舶耐波性理论的雏形。

## 14.5 机器验证

**Julia（`14_oscillations.jl`）**：(a) 三种阻尼的 IVP 数值解形
态判定：欠阻尼有 ≥ 3 个过零点、临界无过零且回零最快、过阻尼最
慢（同一 t_end 下 |x| 对比）；(b) 包络核对：欠阻尼解的峰值序列
按 e^{−δt} 衰减（相邻峰比 e^{−δT}，T = 2π/ω）；(c) 频率响应曲线
X(ω)：数值扫频（每 ω 积到稳态取幅值）与解析公式曲线对照（峰位
ω_r、半功率带宽 2δ ≈ Q 公式核对）。

**Python（`14_oscillations.py`）**：同一套 + solve_ivp 长时积分
的稳态相位差 φ(ω) 与反正切公式对照；RLC 数字例：峰值 ω_r ≈
98.99、Q = 5 断言。

**Fortran（`14_oscillations.f90`）**：经典扫频账：固定 δ, ω₀，
ω 从 0.2ω₀ 扫到 2ω₀ 共 61 点，每点 RK4 积 20 个周期、取最后周期
的峰–峰幅值，输出响应表并断言峰值位置（±带宽容差）。

**Prolog（`14_oscillations.pl`）**——regime 判定器。
`damping_regime(Delta, W0, Type)`（δ² vs ω₀² 三分）；`regime_form
(Type, Form)`（通解形态表）；`q_factor(Delta, W0, Q)`（rational
精确）；`rlc_map(L, R, C, Delta, W0)`（机电类比换算）。断言：
数字例 type = underdamped、Q = 5。

## 14.6 要点回顾

1. m x″ + cx′ + kx = 0 的三 regime 由 δ² − ω₀² 判定；临界阻尼
   是工程最优点（最快无振荡回零）。
2. 受迫响应：X(ω) 的 Lorentz 峰，ω_r = √(ω₀²−2δ²)，带宽 2δ，
   Q = ω₀/2δ——扫频实验反演系统参数的标准协议。
3. RLC 与机械振子逐字同构（L↔m, R↔c, 1/C↔k）；浮体是"重力弹
   簧"，周期 2π√(h/g)。
4. 数学结构单一、物理化身众多——线性振子是全书出场率最高的模型。
