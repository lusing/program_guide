# 02 方向场、积分曲线与等斜线

**对应书 §2.2 Integral Curves and Isoclines（含 §2.1 末的 Euler 方法）。**

---

## 2.1 把方程看成"斜率配方"

方程 y′ = f(x, y) 有一种几何读法：它是平面上每点 (x, y) 与该点积
分曲线**斜率**之间的一份配方——给一个点，还你一个方向。在每点画一
小段有该斜率的短线段（**斜率标**），成百上千个标铺开，就得到**方向
场**（direction field）。于是"解方程"的几何含义变成：找一条曲线，
它**处处与方向场相切**——这样的曲线就是**积分曲线**。

这个视角的价值在于：即使解的公式求不出来，方向场也画得出来（f 是
已知函数，逐点代入即可），解的定性行为（增减、拐弯、渐近）从场中
就能读出。这是第 19 章定性理论的二维预告。

例：y′ = 2x 的方向场里，积分曲线是抛物线族 y = x² + C——每条抛物
线在每个点处的切线斜率恰是 2x。更快的例子：y′ = y 在上半平面斜率
为正、下半平面为负、x 轴上斜率为零，因此任何初值 y₀ > 0 的解单调
增、越走越陡，y₀ < 0 单调减，y₀ = 0 时解恒为零——**不用解出
y = y₀eˣ 就读出了全部单调性**（书例 2.2）。

## 2.2 等斜线：方向场的等高线图

逐点画斜率标太费。先画**等斜线**（isoclines）：斜率取定值 k 的点的
轨迹，即曲线

    f(x, y) = k.

它是函数 f 的等高线。在等斜线 f = k 上所有斜率标平行（斜率都是
k），先画几条等斜线、在每条上布好斜率标，方向场的骨架就立起来了
（书：等斜线是画方向场的"脚手架"）。

两个经典例（书例 2.2/2.3）：

- **y′ = y**：等斜线是水平线 y = k。k 越大线越陡；y = 0 本身是一条
  积分曲线（斜率处处为零）。
- **y′ = y/x**：等斜线 f = k 即 y = kx——过原点的射线族。注意方向场
  本身沿射线方向：解曲线族是 y = Cx（直线），每条解直线与它穿过的
  每条等斜线相切——等斜线与积分曲线重合的特殊局面。f 在 x = 0 无
  定义，y 轴不属于场的定义域（但每条 y = Cx 都合法穿过它——方程
  的定义域与解的定义域不必相同，第 01 章"局部存在"的又一注脚）。

再如 y′ = x + y：等斜线 x + y = k 是斜率 −1 的平行直线族。沿直线
y = −x + k 斜率全为 k；从 (0, 1) 出发沿场走，曲线下坠到 y = x − 1
之下后（那里 x + y < 0、场向下）转头上扬，最终与 2eˣ − x − 1 的
形态吻合——第一章的常驻解在方向场里第一次"显形"。

## 2.3 反问题：从曲线族反推方程

书 §2.2 末尾的反问题在符号通道里是天然素材：已知通解族 Φ(x, y, C)
= 0，求它满足的 ODE。协议：把 y 视为 x 的函数对 Φ 求导（链式法
则），再用 Φ = 0 消去 C。

例（书）：y = Cx³。求导得 y′ = 3Cx²；由通解解出 C = y/x³ 代入：
y′ = 3y/x。检验：y = Cx³ ⟹ y′ = 3Cx² = 3y/x ✓。这类"族 → 方程"
的配对是训练"通解含一个任意常数 ⟺ 一阶方程"直觉的最好练习，而且
完全是机械操作——求导 + 代入消元，Prolog 通道（`02_field.pl`）就把
它做成一个查表化简引擎：给定族 y = C·g(x)，产出的方程一律是
y′ = g′(x)·y/g(x)，再用符号微分核实。

## 2.4 Euler 方法：方向场的算法化

书 §2.1 末把方向场的直觉直接变成第一个数值方法。在 [x₀, b] 上取
步长 h = (b − x₀)/n 的等距网格。既然每点知道斜率，就从初值出发，
每步沿当前点的斜率走一小段直线：

    y_{i+1} = y_i + h·f(x_i, y_i),    i = 0, 1, …, n−1.

这就是 **Euler 方法**。它把积分曲线近似成切线段的折线链——正是
"方向场里走格子"的算术版。误差有两层：

- **局部截断误差**：一步内真解弯出切线的偏差，量级 O(h²)（Taylor
  展开的二阶项）；
- **全局误差**：n = (b−x₀)/h 步累加，量级 O(h)。**Euler 是一阶方法**。

改进方向直白：用区间两端斜率的平均（**改进 Euler / Heun 法**，
O(h²)），或用区间内四次采样的加权平均（**经典 Runge–Kutta 四阶**，
O(h⁴)，简称 RK4）：

    k₁ = f(x_i, y_i)
    k₂ = f(x_i + h/2, y_i + h·k₁/2)
    k₃ = f(x_i + h/2, y_i + h·k₂/2)
    k₄ = f(x_i + h,   y_i + h·k₃)
    y_{i+1} = y_i + h·(k₁ + 2k₂ + 2k₃ + k₄)/6     （加权 1:2:2:1）

RK4 是全书数值通道的主力发动机（Julia/Python/Fortran 的例程都从
它起步），第 12 章 Floquet 矩阵、第 20 章轨道、第 22 章极限环都用
它积分。"几阶方法"不是修辞：把 h 减半，一阶方法误差减半、二阶减
四分之一、四阶减十六分之一——**收敛阶**是可以从对数图上量出来的
斜率，本章机器验证的主菜就是量这个斜率。

## 2.5 机器验证

**Julia（`02_field.jl`）/ Python（`02_field.py`）**：
(a) 方向场的数值重建——在网格上打印 y′ = x + y 的斜率矩阵（ASCII
表），人工可见沿对角线斜率增大、跨过 x + y = 0 变号；
(b) 等斜线核对——f(x,y) = k 的等斜线上采样点斜率全等于 k；
(c) 三方法收敛阶测量——对 y′ = x + y、y(0) = 1（真解 2eˣ − x − 1）
分别用 Euler/Heun/RK4 以 h, h/2, h/4, … 积分到 x = 1，拟合
log(误差) 对 log(h) 的斜率：

```julia
function err_at_x1(method, h)
    n = round(Int, 1 / h); y = 1.0
    for i in 0:n-1
        y = step(method, i * h, y, h)   # Euler/Heun/RK4 单步
    end
    abs(y - (2exp(1) - 2))
end
hs = 0.5 .^ (4:10)
order(method) = slope_of(log.(err_at_x1.(method, hs)), log.(hs))
@assert 0.8 < order(:euler) < 1.2   "Euler 阶数 ≈ 1"
@assert 1.8 < order(:heun)  < 2.2   "Heun 阶数 ≈ 2"
@assert 3.6 < order(:rk4)   < 4.3   "RK4 阶数 ≈ 4"
```

断言带 ±0.2 的带宽：最小 h 下 RK4 误差逼近机器精度时斜率会略跌
（进入舍入噪声层），这是数值课的老常识——量阶数要用"误差还在
O(h⁴) 层"的中段拟合。

**Fortran（`02_field.f90`）**：经典三方法阶数测量的 Fortran 版
（复用同一 RK4 内核，之后各章直接引用这里的代码模式），输出三列误
差表与拟合阶数。Fortran 通道此后承担"经典数值"角色。

**Prolog（`02_field.pl`）**：反问题引擎 + 等斜线代数。对族
y = C·g(x)（g 从小型函数表取：x³、eˣ、sin x、x^(1/2)…）符号求导
生成 ODE y′ = g′·y/g 并化简；对给定 (f, k) 解代数方程输出等斜线
表达式（f 限于多项式与线性分式）。全部有理数运算，断言例：

```prolog
?- family_ode(x^3, E), simplify(E, S).     % y = Cx^3 ⟹ y' = 3y/x
S = mul(3, div(y, x)).
?- isocline(add(x, y), 2, L).              % y' = x+y 的等斜线 f=2
L = sub(2, x).                             % 即 y = 2 - x
```

## 2.6 要点回顾

1. y′ = f(x, y) 的几何本体是方向场；积分曲线 = 处处与场相切的曲线；
   等斜线 f = k 是场的等高线，画场的脚手架。
2. 反问题（族 → 方程）：求导 + 消去 C；一阶方程与"单参数曲线族"
   相互对应。
3. Euler 方法 = 方向场走折线，全局误差 O(h)；Heun O(h²)；RK4
   O(h⁴)。收敛阶可从 log–log 拟合斜率读出，是数值方法的第一体检
   指标。
4. 方向场的定义域（f 有定义处）与解的存在域不必重合；y′ = y/x 在
   x = 0 无场，但解直线 y = Cx 完好。
