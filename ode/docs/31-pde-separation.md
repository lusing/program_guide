# 31 分离变量与三大方程

**对应书 §13 Partial Differential Equations：热传导方程、波动方
程、Laplace 方程（分离变量、圆域、球域）。**

---

## 31.1 从 ODE 到 PDE：多维的舞台

未知函数依赖多个变量时，偏微分方程登场。三大经典方程（物理的
三根支柱）：

- **热传导方程** u_t = a²u_xx：扩散、平滑、不可逆（书 §13.2）；
- **波动方程** u_tt = c²u_xx：传播、振荡、可逆（书 §13.3）；
- **Laplace 方程** u_xx + u_yy = 0：稳态、平衡、调和（书 §13.4）。

边界/初始条件：热（初温 + 边界温度）、波（初位移 + 初速度 + 边
界）、Laplace（边值）。

## 31.2 分离变量：SL 理论的总回收

**核心招式**：猜 u(x, t) = X(x)T(t)，代入 PDE，两边除以 XT——
变量分离成功时方程一侧只含 x、另一侧只含 t，都等于**分离常数**
−λ：

    热方程：T′/T = a²X″/X = −a²λ ⟹ T = e^{−a²λt}，X″ + λX = 0。

X 的方程 + 边界条件 = **Sturm–Liouville 问题**（第 26 章！）——
特征值 λₙ 离散、特征函数正交完备。解是**模式叠加**：

    **u(x,t) = Σₙ cₙ Xₙ(x)·Tₙ(t)**，cₙ 由初始条件投影（Fourier
    系数）。

整条流水线：分离 → SL 特征值 → 模式 → 投展开系数。第 25/26 章
的全部机器在这里合流。物理图像：每个模式独立演化（热的模式指数
衰减 e^{−a²λₙt}，高阶衰减快——"高频先死"；波的模式是驻波
cos(c√λₙ t)）。

**圆域/球域**（书 §13.2.3、§13.4.3/4）：极坐标分离给 Bessel
（径向）× e^{inθ}（角向）；球坐标给 Legendre×幂——第 27/28 章
的特殊函数正是为此而生。**全书的螺旋结构在此收拢**。

## 31.3 三大方程的性格对比

| | 热方程 | 波动方程 | Laplace |
|---|---|---|---|
| 时间 | 一阶（不可逆） | 二阶（可逆） | 无（稳态） |
| 信息 | 无限传播但指数衰减 | 有限速度 c 传播 | — |
| 最大值 | 极值在初始/边界（抛物极值原理） | 无极值原理 | 极值在边界（调和极值原理） |
| 模式 | e^{−a²λₙt} 衰减 | cos(c√λₙt) 振荡 | λₙ 双曲/幂 |
| 平滑化 | t > 0 立即 C^∞ | 保持正则性 | 解析 |

d'Alembert 公式 u = ½[f(x+ct)+f(x−ct)] + (1/2c)∫g：波的行波分
解（与驻波观点对偶）。

## 31.4 机器验证

**Julia（`31_pde.jl`）/ Python（`31_pde.py`）**：
(a) 热方程模式衰减：初温 f(x) = x(1−x)，条形域 [0,1] 两端零度：
前 5 个 Fourier 模式系数 + 模式衰减 e^{−n²π²t}——t = 0.1 时只剩
第一模式主导（|c₁|/|c₂| > 100）✓"高频先死"；(b) 波方程驻波：
初位移 sin πx、零初速的解 cos(πt)sin(πx)——RK4 直接积分 PDE 半
离散（空间二阶差分）对照；(c) **FTCS 格式**（显式差分）：热方程
格点解 vs 级数解（相对误差 < 1e−3，稳定性条件 r = a²Δt/Δx² <
1/2 内外对照）；(d) Laplace：方域 Dirichlet 问题的级数解满足方
程（数值二阶差分残差）+ 极值原理（最大值在边界）；
(e) d'Alembert：行波分解对 g = 0 情形数值核对。

**Fortran（`31_pde.f90`）**：FTCS 热传导经典账：r = 0.4 稳定、
r = 0.6 增长（演示不稳定），与级数解对照。

**Prolog（`31_pde.pl`）**：分离变量协议引擎（方程 → 分离常数 →
SL 问题 → 模式形态表）、三方程性格对比表（结构事实的谓词化）。

## 31.5 要点回顾

1. 分离变量 = 猜乘积解 + 分离常数；X 的方程 + 边界 = SL 问题
   ——离散谱 + 正交完备是解可以叠加的根据。
2. 热的模式指数衰减（高频先死、平滑化、不可逆）；波的模式驻波
   振荡（可逆、行波分解）；Laplace 稳态（极值原理）。
3. 圆/球域给 Bessel/Legendre——特殊函数 = 分离变量的坐标遗产。
4. FTCS 显式格式的稳定性 r < 1/2——数值与解析的一致性互相检验。
