**对应书第 1 章 Introduction。**

## 0.1 从微积分的反问题说起

微积分教会我们两件事：给定函数 y(x)，求它的导数 y′(x)；给定
f(x)，求它的原函数 ∫f dx。**常微分方程**（Ordinary Differential
Equation，ODE）问的是另一类问题——把导数与函数本身放在同一个等式
里，反过来求函数：

> 求 y(x)，使得它与其各阶导数满足关系式
>
> F(x, y, y′, …, y⁽ⁿ⁾) = 0。

"常"（ordinary）字是说未知函数只依赖**一个**自变量；依赖多个自变量、
出现偏导数的情形叫偏微分方程（PDE），那是第 31 章的展望主题。

这不是数学家凭空发明的游戏。任何描述"**变化如何依赖于当前状态**"的
学科都会自然产出 ODE：

- 种群增长：个体数 N 的变化率 dN/dt 正比于 N 本身（马尔萨斯模型
  dN/dt = λN）；
- 放射性衰变：原子数 dN/dt = −λN；
- 牛顿冷却：物体温度 dT/dt = −k(T − T_env)；
- 牛顿第二定律本身就是 ODE：m·dv/dt = F，力 F 通常依赖于位置与
  速度，例如带空气阻力下落 m·dv/dt = mg − kv²。

书第 1 章用三个物理实例引入主题：竖直下落物体（二阶方程
m·z″ = −mg）、单摆（θ″ = −(g/L)·sin θ）、以及种群模型的修正
（当增长率依赖种群规模 r = r(N) 时得到 dN/dt = r(N)·N，最著名的
修正版就是逻辑斯蒂方程 dN/dt = rN(1 − N/N₁)）。本教程完全自包含，
但这些例子会在第 03、08 章作为主力反复出现。

## 0.2 基本词汇：阶、解、通解、初值问题

**阶**：方程中出现的最高导数阶数。y′ = x + y 是一阶；θ″ = −sin θ
是二阶。n 阶方程的标准形式是 y⁽ⁿ⁾ = f(x, y, y′, …, y⁽ⁿ⁻¹⁾)——
最高阶导数被解出来。第 06 章会专门处理解不出 y′ 的情形（克莱罗
方程等）。

**解**：区间 I 上有定义、有足够阶导数、代入方程后使其成为恒等式的
函数 y = φ(x)。这个定义朴素但重要：**"是不是解"是一件可以逐字核对
的事实**，不依赖任何求解技巧。这正是本教程五通道验证的哲学起点——
机器最擅长的就是"代入、求导、化简到 0"。

**隐式解**：很多时候解写不成显式 y = φ(x)，只能写成 G(x, y) = 0
（如恰当方程的首次积分）。只要在一段曲线上能确定 y 是 x 的函数且
满足方程，就称其为隐式解。

**通解与任意常数**：n 阶方程的通解通常含 n 个独立任意常数
C₁, …, Cₙ。几何直觉：一阶方程在每点给定斜率 y′ = f(x, y)，积分
曲线族是铺满方向场的一族曲线，一个常数挑选一条；二阶方程相当于
同时给定位置与速度，两个常数对应"初始位置 + 初始速度"。

**初值问题**（Cauchy 问题，IVP）：

    y⁽ⁿ⁾ = f(x, y, …, y⁽ⁿ⁻¹⁾),  y(x₀) = y₀, y′(x₀) = y₁, …, y⁽ⁿ⁻¹⁾(x₀) = y_{n−1}.

初值条件把通解里的常数钉死，得到**特解**。工程与物理几乎永远在解
初值问题：t = 0 时刻的位置与速度决定了此后的一切（如果解唯一的
话——"如果"二字正是第 01 章的全部内容）。

**边值问题**则是在区间两端各给条件（如 y(0) = y(L) = 0），它是
第 26 章 Sturm–Liouville 理论的舞台，性质与初值问题截然不同。

## 0.3 机器核对一个解：五通道的第一课

"代入后成为恒等式"是可以编程的。取本教程的常驻例子：

> 初值问题 y′ = x + y，y(0) = 1。

猜一个解 y = 2eˣ − x − 1。核对三件事：

1. y′ = 2eˣ − 1；
2. x + y = x + 2eˣ − x − 1 = 2eˣ − 1 = y′ ✓；
3. y(0) = 2 − 0 − 1 = 1 ✓。

于是它是解。这个 y 从哪来？——第 04 章的积分因子法会系统产出它。
现在先看机器如何"逐字核对"。Lean 4 通道（`examples/lean/Ode/
Ch00Intro.lean`）用导数的严格定义 `HasDerivAt` 做第一性核对：

```lean
/-- y = 2eˣ - x - 1 处处可导，导数为 2eˣ - 1。 -/
example (x : ℝ) : HasDerivAt (fun x => 2 * exp x - x - 1) (2 * exp x - 1) x := by
  have h1 : HasDerivAt (fun x => 2 * exp x) (2 * exp x) x := by
    simpa using (hasDerivAt_exp x).const_mul 2
  exact h1.sub (hasDerivAt_id x) |>.sub_const 1
```

这段代码在讲什么：`HasDerivAt f f' x` 是 mathlib 对"f 在 x 可导、
导数为 f′"的原始表述——不是"求导规则算出来了"，而是差商极限存在
且等于该值。证明分两步：先由 `eˣ` 的可导性乘常数得到 `2eˣ` 的可导
性（`const_mul` 组合子），再用和差法则（`.sub`、`.sub_const`）装配
出整体。第二段代码把右端 x + y(x) 改写成 2eˣ − 1（一次 `ring`），
从而结论里"导数 = x + y(x)"与第一段的"导数 = 2eˣ − 1"是同一句话
——**方程 y′ = x + y 被逐字验证**。初值条件则是一次 `norm_num`。

数值通道（Julia，`examples/julia/00_intro.jl`）核对的是同一件事的
离散版本：把解代入方程右端，看残差是否为机器零：

```julia
# 残差核对：y' - (x + y) 在一组点上应为 0
rhs(x, y) = x + y
ysol(x) = 2exp(x) - x - 1
resid = maximum(abs((ysol(x + h) - ysol(x - h)) / 2h - rhs(x, ysol(x)))
                for x in -1.0:0.1:1.0)
@assert resid < 1e-4 "代入残差应为 0"
```

中心差商近似 y′，与右端 x + y 之差（残差）在 x ∈ [−1, 1] 上逐点
抽样，最大值必须低于 10⁻⁴（差商误差 O(h²) 的量级）。这不是证明，
是**数值证据**；Lean 那份才是证明。Prolog 通道（`examples/prolog/
00_intro.pl`）则做符号核对：对表达式树执行求导规则，代入后化简为
零——介于两者之间，规则是可靠的，但化简器只覆盖写进表里的情形。

三条通道对同一个命题给出三种强度的"核对"，这是全书反复出现的
模式：**Lean 给证明，Prolog 给符号演算，Julia/Python/Fortran 给数
值证据**。

## 0.4 线性方程：本书的骨架概念

称 n 阶方程为**线性的**，若它关于 y 及其导数是一次式：

    aₙ(x)y⁽ⁿ⁾ + aₙ₋₁(x)y⁽ⁿ⁻¹⁾ + … + a₁(x)y′ + a₀(x)y = g(x).

系数 aᵢ(x) 只是 x 的函数。g ≡ 0 时称**齐次**，否则**非齐次**。
线性是全书最重要的分水岭：

- 线性齐次方程的解构成向量空间（解的和、解的倍仍是解）——叠加
  原理，第 10 章把它做成完整的理论（Wronskian、基本解组）；
- 非线性方程没有这种结构，必须逐个处理（第 03–06 章的可解类型
  全是"能变换成可积形式"的特例），定性方法（第 19–22 章）正是
  对"求不出显式解"的回应。

一阶线性 y′ + p(x)y = q(x) 有通用的万能解法（第 04 章）；
n ≥ 2 的线性方程除特殊系数外没有初等解法，于是有了级数法
（第 23 章）、Laplace 变换法（第 24 章）与特殊函数（第 27–28 章）。
这个"从万能到特殊"的退化链条，就是本书后半部的剧情主线。

## 0.5 方程组、定性与应用：全书地图

**方程组**（第 15–18 章）：n 个未知函数联立，x′ᵢ = fᵢ(t, x₁, …, xₙ)。
高阶方程总可以化为一阶方程组（令 x₁ = y, x₂ = y′, …），反之不然
——方程组才是更本原的对象。常系数线性方程组 x′ = Ax 的全部理论
就是矩阵指数 e^{At}（第 17 章），它是第 11 章特征方程法的高维推广。

**定性理论**（第 19–22 章）：当显式解求不出时，直接从方程本身读出
解的长期行为——平衡点类型、稳定性、分岔、极限环。这部分是现代动
力系统的入口，也是本书第 5 章的主题。

**应用**贯穿全书：机械振动与 RLC 电路（第 14 章）、带电粒子在磁场
中的螺旋运动与磁矩进动（第 18 章）、非线性振子与自激振动（第 22
章）、量子系统的 Ritz 近似（第 30 章）、热传导与波动（第 31 章）。

**积分方程**（第 29 章）与**变分法**（第 30 章）是两门近亲学科：
前者把 ODE 写成积分形式后产生的新的分析对象（Picard 迭代在第 01
章就会预演它），后者求的是"函数的函数"的极值，其 Euler 方程恰好
是 ODE——变分法给 ODE 装上了变分原理的引擎（最小作用原理）。

## 0.7 要点回顾

1. ODE 是"变化率与状态的关系"的数学抽象；n 阶方程的通解含 n 个
   独立常数，初值问题把它们钉死。
2. "是不是解"可以逐字核对（求导、代入、化简为零）——这是全书
   机器验证的哲学起点。
3. 线性/非线性是第一分水岭：线性有叠加原理与系统解法；非线性靠
   特殊变换与定性方法。
4. 五通道分工：Lean 证明、Prolog 符号演算、Julia/Python/Fortran
   数值证据。
