## 32.1 方法选择树：拿到方程怎么办

    方程到手
    ├── 一阶？
    │   ├── y' = f(x,y) 一般式 → 方向场/等斜线定性（02）→ 数值 RK4（02）
    │   ├── 可分离 f₂(x)/f₁(y)？→ 分离积分 + 丢解账单（03）
    │   ├── 线性 y' + p y = q？→ 积分因子/参数变易，万能（04）
    │   ├── M dx + N dy = 0？→ P_y = Q_x 判恰当（05）→ 找 μ（05）
    │   ├── F(x, y') = 0？→ 参数化 / Clairaut 包络（06）
    │   └── 自治 y' = f(y)？→ 相线 + 平衡点分类（07）
    ├── 高阶线性？
    │   ├── 常系数 → 特征方程 + 待定系数/共振升次（11, 13）
    │   ├── 变系数已知一解 → 降阶求第二解（09）
    │   ├── Wronskian/Abel 全程把关（10）
    │   └── Euler 型 x^k → 指标方程（13）
    ├── 方程组？
    │   ├── 常系数 → 特征值（16）→ 矩阵指数 e^{At}（17）
    │   └── 变系数 → 基本矩阵 + Abel/参数变易（15）
    ├── 定性问题（不求显式解）？
    │   ├── 奇点分类 → 迹-行列式图（19）
    │   ├── 稳定性 → 线性化 / Lyapunov 函数（20）
    │   ├── 参数变化 → 分岔范式（21）→ 极限环/Poincaré-Bendixson（22）
    │   └── 周期系数 → Floquet 平移矩阵（12）
    ├── 解析工具？
    │   ├── 幂级数/Frobenius（23）
    │   ├── Laplace 变换（24）：分段右端/冲激/共振
    │   └── Fourier 级数（25）：周期/边界
    ├── 边值/特征值？
    │   └── Sturm–Liouville + Green 函数（26）→ 特殊函数（27, 28）
    ├── 积分形式？→ 逐次逼近/Neumann/差核 Laplace（29）
    ├── 泛函极值？→ Euler 方程 → 或直接 Ritz（30）
    └── 多变量？→ 分离变量 → SL → 模式叠加（31）

## 32.2 结构性的三条主线

**线一：线性结构定理**。齐次解空间是向量空间（一阶 1 维 → 二阶
2 维 → n 阶 n 维 → 方程组 n 维）——叠加原理从第 04 章一路长到
第 17 章的 e^{At}；非齐 = 齐 + 特解；Wronskian/Abel 是解空间的"
体积守恒"。

**线二：特征展开**。特征向量（16）→ 特征多项式（11/13）→ 特征
值（SL，26）→ 特征函数展开（Fourier 25/Bessel 27/Legendre 28）
→ 分离变量的模式（31）——**"找一组好基，把算子对角化"**是贯穿
全书的同一招。

**线三：逼近与验证**。Picard 迭代（01）→ 逐次逼近（29）→ Neumann
级数 → 级数解（23）→ 谐波平衡（22）→ Ritz 法（30）——把解不动
的方程换成会收敛的迭代；同时全书五通道把每个结论按可信度分级：
Lean 证明 > Prolog 符号规则 > Julia/Python/Fortran 数值证据。

## 32.3 五通道分工回顾

| 通道 | 角色 | 本教程代表性成果 |
|---|---|---|
| Lean 4 + mathlib | 严格证明 | Picard–Lindelöf 存在唯一性、非唯一性双解反例、Abel 恒等式、Clairaut 包络"奇异解不在族中"、e^{−t}x₀ 渐近稳定 |
| Prolog | 符号演算 | 表达式树微分+项表化简内核、五个求解器（分离/线性/恰当/Clairaut/指标）、相线与奇点分类器、Laplace 表引擎 |
| Julia | 数值主力 | RK4 家族、收敛阶测量、Floquet 单值矩阵、极限环与张弛周期、单摆周期 2K/π |
| Python | 数值独立复算 | scipy 全家桶（solve_ivp/expm/special/ellipk/mathieu）、双实现交叉验证 |
| Fortran | 经典数值 | Picard、收敛阶、Meissner 单值矩阵、矩阵指数级数、FTCS 稳定性 |

验证纪律（全书的隐形课程）：**确定性、精确算术优先、容差要有理
由、双实现交叉、守恒律当免费质检**。

## 32.4 机器验证（收官章）

**Julia（`32_summary.jl`）**：一条 IVP 走完全书流水线——y″ + 2y′
+ y = sin t + e^{−t}（共振混合右端）：解析（待定系数+共振升次）/
Laplace（部分分式）/RK4/Fortran 四路同解；再走一条定性流水线
——迹-行列式分类 + 数值轨道行为核对。

**Prolog（`32_summary.pl`）**：**方法选择器**——`select_method(
Eq, Path)` 对 32.1 的选择树做谓词化：输入方程特征（阶数/系数/
结构标记），输出推荐的章节路径；对全书样例方程逐一分类核对。

## 32.5 结课

常微分方程是一个**两层世界**：显式解的世界（分离/线性/级数/变
换——本书前半与后半的工具箱）和定性行为的世界（相平面/稳定性/
分岔/极限环——几何与动力系统）。两层之间靠线性化、特征值和变
分原理互相翻译；而机器验证（从 HasDerivAt 的逐字核对到 RK4 的
收敛阶测量）给两层都装上了"说一不二"的质检。原书（Henner 等
2023）的 13 章在此全部回收：解析方法（书 1-12 章）+ 分离变量通
向 PDE（书 13 章）——继续前进的方向是动力系统、偏微分方程与数
值分析，它们各自把本教程的一条主线拉成新的世界。

*本章示例：`examples/julia/32_summary.jl`、`examples/prolog/
32_summary.pl`。*
