## 9.1 n 阶方程：更多的初值，更多的常数

n 阶方程的标准形式把最高导数解出来：

    y⁽ⁿ⁾ = f(x, y, y′, …, y⁽ⁿ⁻¹⁾)，

Cauchy 问题要 **n 个初值**：y(x₀) = y₀, y′(x₀) = y′₀, …,
y⁽ⁿ⁻¹⁾(x₀) = y₀⁽ⁿ⁻¹⁾。存在唯一性定理照搬第 01 章：f 在初值点
的邻域内连续、对各变量 y, y′, …, y⁽ⁿ⁻¹⁾ 的偏导有界（或
Lipschitz），则 IVP 局部存在唯一。通解含 n 个独立常数——物理坐标
里它们就是"初始位置、初始速度、……"。

最简情形 y⁽ⁿ⁾ = f(x)：积分 n 次，

    y(x) = ∫dx∫dx…∫f dx + C₁xⁿ⁻¹/(n−1)! + … + Cₙ

（n−1 次多项式的自由项）。牛顿第二律 m x″ = F(t) 在常力下给
x(t) = at²/2 + v₀t + x₀——抛物线运动是一切常力问题的通解模板
（书 §3.1 的开场例）。变质量 m(t)、变力 F(t) 时（书例 3.1）解
是双重积分的累积形式，常数照样由 x(t₀), v(t₀) 定。

**二阶的几何**（书 §3.2）：初值 y′(x₀) = y′₀ 给积分曲线在初值点
的**切线倾角** α = arctan y′₀。一阶方程的方向场在二阶升级为
"位置 + 斜率"的相空间——第 19 章相平面的伏笔。

**定理失效的现场**（书例 3.4）：yy″ − 2y′² = 0。显式化
y″ = 2y′²/y 在 y = 0 处无界。通解 y = 1/(C₁x + C₂)：
(a) 初值 y(0) = 0, y′(0) = 2 无解（通解在 x = 0 处 1/C₂ ≠ 0）；
(b) 初值 y(0) = 1, y′(0) = 0 给 C₁ = 0, C₂ = 1，特解 y ≡ 1 ✓。
同一个方程，两组初值，一存一亡——定理条件逐点核对的必要性。

## 9.2 降阶法第一式：左端是全导数

若方程左端恰是某个 G 的全导数

    d/dx G(x, y, y′, …, y⁽ⁿ⁻¹⁾) = 0，

则立刻降一阶：G = C₁（**首次积分**）。

**例 A**（书例 3.5）yy″ + (y′)² = 0。左端 = d(yy′)/dx（乘积法
则！），故 yy′ = C₁，分离 y dy = C₁ dx，通解

    y² = C₁x + C₂（抛物线族，隐式）。

识别全导数的窍门：yy″ + y′²、yy′ 的导数、sin y·y′ 的导数
（(−cos y)′）……乘积法则倒着用。

## 9.3 降阶法第二式：缺 y（或缺前 k 阶）

方程不含 y（也不含 y″ 以下……准确说：缺 y 到 y⁽ᵏ⁻¹⁾）：

    F(x, y⁽ᵏ⁾, …, y⁽ⁿ⁾) = 0，

令 **z = y⁽ᵏ⁾**，方程降为 n − k 阶。解出 z(x, C₁, …) 后再积分
k 次回 y。二阶缺 y（k = 1）：y′ = z, y″ = z′，得一阶方程。

**例 B**（书例 3.7）y″ − y′/x = x。缺 y：令 z = y′ 得线性一阶
z′ − z/x = x（第 04 章！）：齐次解 C₁x，参数变易 u′ = 1，
z = x² + C₁x；再积分：

    y = x³/3 + C₁x²/2 + C₂。

注意结构：通解 = 齐次通解 + 特解——二阶线性的叠加原理预告。

**例 C**（书例 3.6）y⁽⁵⁾ − y⁽⁴⁾/x = 0。令 z = y⁽⁴⁾：z′ = z/x
⟹ z = Cx；四次积分 y = C₁x⁵ + C₂x³ + C₃x² + C₄x + C₅（积分
Cx 得 Cx⁵/...，吸收常数）。

## 9.4 降阶法第三式：缺 x（自治二阶）

方程不含 x：F(y, y′, y″) = 0。把 y 当新自变量：令 p(y) = y′，
则 y″ = dp/dx = (dp/dy)(dy/dx) = p·dp/dy——二阶降为一阶
F(y, p, p·dp/dy) = 0。

**例 D**（书例 3.8 型）yy″ − 2y′² = 0（例 A 的姊妹）。p dp/dy
·y − 2p² = 0 ⟹ p ≠ 0 时 dp/p = 2dy/y ⟹ p = C y²；dy/dx = Cy²
⟹ y = −1/(Cx + C₂)——正是例 3.4 引用的通解 1/(C₁x + C₂)。
y′ = 0 支给常数解（已含于 C₁ = 0）。

## 9.5 已知一个特解：线性方程降阶

线性齐次 y″ + p(x)y′ + q(x)y = 0 已知一解 y₁ 时，令 y = v·y₁
（**降阶法求第二解**，书 §3.4.2）：代入得 v 的方程不含 v 本身
（y₁ 是解，v 的零阶项消失），w = v′ 满足一阶线性方程，解出

    y₂(x) = y₁(x)·∫ [e^(−∫p dx) / y₁²] dx。

**例 E**（书例 3.11）x²y″ + 4xy′ − 4y = 0。猜 y₁ = x（幂试探），
代换 v = y/x 后得 v″x + 6v′ = 0 ⟹ w′x + 6w = 0 ⟹ w = C₂x⁻⁶
⟹ v = −C₂x⁻⁵/5 + C₁，通解

    y = C₁x + C₂/x⁴。

（与 Euler 方程理论对照：x² 特征方程 k(k−1) + 4k − 4 = 0 给
k = 1, −4 ✓——第 13 章会从另一头走到同一答案。）

## 9.6 机器验证

**Julia/Python（`09_reduction.jl` / `09_reduction.py`）**：
(a) 例 A 隐式解族核对：y² = C₁x + C₂ 沿曲线数值求导，验证
yy″ + y′² = 0（二阶中心差商）；(b) 例 B/C 通解代入残差核对
（解析导数精确算）；(c) 例 D 的 1/(C₁x+C₂) 代入 yy″ − 2y′² = 0；
(d) 例 E 两解 x 与 x⁻⁴ 的 Wronskian W = x·(−4x⁻⁵) − 1·x⁻⁴ =
−5x⁻⁴ ≠ 0（线性无关的判据，下一章主角）核对；(e) 牛顿抛物线
IVP：x(0)=1, v(0)=2, a=3 ⟹ x(t) = 1.5t² + 2t + 1 数值积分与
公式比对。

**Prolog（`09_reduction.pl`）——降阶模式识别器。** `reduce_kind
(Eq, Kind)`：识别全导数型（例 A：yy″+y′² ↔ d(yy′)/dx）、缺 y 型
（y″ 与 y′ 出现而 y 不出现）、缺 x 型（x 不出现）；对缺 y 型执行
z = y′ 化归输出降阶后的方程；对全导数型输出首次积分。断言例：

```prolog
% yy'' + y'^2 = 0 是 d(yy')/dx = 0 型
?- reduce_kind(ode(add(mul(y, ypp), pow(yp, 2)), total_derivative).
% y'' - y'/x = x 缺 y：化归 z' - z/x = x
?- reduce_missing_y(sub(ypp, div(yp, x)), x, reduced(z, sub(zp, div(z, x)), x)).
```

**Lean（`Ode/Ch09Reduction.lean`）——通解的逐字二阶账。**
例 A：y = √(C₁x + C₂)（C₁x + C₂ > 0 支）满足 yy″ + y′² = 0；
用复合求导链（sqrt、线性函数）装配 HasDerivAt 两层。例 E：y = x⁻⁴
满足 x²y″ + 4xy′ − 4y = 0（x ≠ 0 上）——两个 HasDerivAt + 代数
对账。

## 9.7 要点回顾

1. n 阶 IVP 要 n 个初值；存在唯一性条件逐点成立，失效点附近解可
   以不存在（yy″ = 2y′² 的 y = 0 线）。
2. 降阶三板斧：左端全导数（首次积分 G = C₁）；缺 y（z = y⁽ᵏ⁾）；
   缺 x（p = y′ 视为 y 的函数，y″ = p dp/dy）。
3. 线性齐次已知一解 y₁ ⟹ 第二解 y₁∫e^(−∫p)/y₁²——"猜一个幂，
   机器降阶"是实战套路。
4. 解完降阶方程后**必须积分回去并核对阶数**：n 阶通解恰有 n 个独立
   常数，多一个少一个都说明账没算平。
