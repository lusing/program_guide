## 8.1 建模协议：变化率账本

第 00 章说过 ODE 是"变化如何依赖状态"的语言。本章把这句话落成
**建模协议**——遇到实际问题，按固定四步走：

1. **选状态量**：要跟踪什么量（温度 T、质量 m、浓度、电流 i、速度
   v）？它的单位、定义域；
2. **写变化率账本**：d(状态)/dt = 流入 − 流出（守恒类：质量、盐、
   电荷），或 = ∑力/m（牛顿类），或 ∝ 驱动−响应（唯象类：冷却、
   摩擦）；
3. **定参数与初值**：比例常数从实验来，初值从场景来；
4. **解与核对**：第 03–04 章的工具上（多数是一阶线性或可分离），
   解完做量纲检查与极限检查（t → 0、t → ∞ 的行为是否物理合理）。

书 §2.8 的十一个例子全部落进这套协议。本章挑六个代表做全流程，
数值通道全部复算。

## 8.2 摩擦减速与火箭：牛顿类

**例 1（摩擦减速，书例 2.32）** 质量 m 的物体仅受与速度成正比的
阻力 F = −kv。牛顿第二定律直接给一阶线性方程

    m dv/dt = −kv  ⟹  v(t) = v₀·e^(−kt/m)，

再积分得路程 x(t) = (v₀m/k)(1 − e^(−kt/m))。两个物理读数：速度指
数衰减，**滑行总距离 v₀m/k**（t → ∞ 的极限，与直觉"阻力小滑得
远"定量一致）。量纲检查：[k] = N/(m/s) = kg/s，v₀m/k 的量纲
(m/s)(kg)/(kg/s) = m ✓。

**例 2（齐奥尔科夫斯基火箭方程，书例 2.33）** 火箭质量 m(t) 随燃
料喷出减少，喷气相对速度 vₑ。动量守恒给

    m·dv/dt = −vₑ·dm/dt   ⟹   Δv = vₑ·ln(m₀/m_f).

注意这是"以质量为自变量"的分离方程。数字（书的例子）：m_p/m_f
= 6、vₑ = 3 km/s ⟹ Δv = 3·ln 7 ≈ 5.85 km/s——**不到逃逸速度**
（11.2 km/s），单级火箭物理上到不了轨道，多级串联的必要性是这条
对数公式的直接推论（每级把"干重"抛掉，重置 m₀/m_f 比值）。

## 8.3 冷却、衰变与复利：唯象指数类

**例 3（牛顿冷却，书例 2.34）** 物体温度 T(t) 在环境温度 T_env 中
的变化率正比于温差：

    dT/dt = −k(T − T_env)，T(0) = T₀  ⟹  T(t) = T_env + (T₀ − T_env)e^(−kt).

解的结构一眼可读：温差指数衰减、时间常数 1/k。量纲与直觉检查：
T₀ = T_env 时解恒定 ✓（平衡解，第 07 章相线的 sink 在这里）。

**例 4（放射性衰变，书例 2.35）** dN/dt = −λN ⟹ N = N₀e^(−λt)。
**半衰期** T_{1/2} = ln2/λ——实验测半衰期比测 λ 直接，两者互算就
是解方程：N₀/2 = N₀e^(−λT) ⟹ λT = ln2。断代（碳-14）的核心公
式：t = (1/λ)ln(N₀/N(t))。

**例 5（复利与通胀，书例 2.39/2.40）** 离散复利（年率 r，一年 n
次）lim_{n→∞}(1 + r/n)^{nt} = e^{rt}——连续复利是离散复利的极
限，ODE 语言 dS/dt = rS。书的数字：\$100,000 借 15 年、年息 6%，
年末复利还 100000·1.06¹⁵ ≈ \$239,655.82，月度复利
100000·(1.005)¹⁸⁰ ≈ \$245,409.36，连续复利 100000·e^{0.9} ≈
\$245,960.31——连续比年末多还约 \$6,304，"复利频率"是真实成本。通胀同理
（价格的对数线性增长）。**离散→连续的极限过程把 e 推上了舞台**，
和例 4 的半衰期共用同一条指数曲线（一涨一跌）。

## 8.4 混合问题：守恒账本类

**例 6（盐水冲洗，书例 2.36）** 水槽初装 150 L 海水、盐浓度 4%。
清水以 4 L/min 入，混合液以 6 L/min 出（体积不守恒！）。问 1 小时
后槽内还剩多少盐。

账本：盐量 V(t)（升，以体积计）的变化 = 流入盐 − 流出盐 = 0 −
(流出浓度)·(流出速率)。关键是流出浓度 = V(t)/槽内水体积，而体积
= 150 − 2t（每分钟净减 2 L）。于是

    dV/dt = −6·V/(150 − 2t)，V(0) = 6（4% × 150）。

线性方程（第 04 章积分因子，p(t) = 6/(150−2t)），解出

    V(t) = 6·(150 − 2t)^3 / 150³ × (150/ (150−2t))…——通解形如
    V = C·(150 − 2t)³（直接验证：d/dt[C(150−2t)³] = −6C(150−2t)²
    = −6V/(150−2t) ✓），初值 C = 6/150³。

t = 60 分钟（体积 30 L）时 V = 6·(30/150)³ = 6/125 L ≈ 0.048 L。
数值通道会逐步复算这页账。**混合问题的通病是把体积当常数**——体
积漂移时浓度项 V/(V₀ + (q_in − q_out)t) 必须带 t，这是本题的教学
点。

## 8.5 RL 电路：一阶线性的电学版

**例 7（书例 2.41）** 电阻 R、电感 L、电源 E 串联回路，合闸后电流
满足（基尔霍夫电压定律）

    L di/dt + R i = E，i(0) = 0  ⟹  i(t) = (E/R)(1 − e^(−t/τ))，
    τ = L/R。

结构 = 例 3 的冷却方程换字母：i 的"环境值"是 E/R（稳态电流，纯
电阻行为），时间常数 τ = L/R 是电感惰性的度量。t = τ 时电流到达
稳态的 1 − 1/e ≈ 63.2%。RLC 完整电路是二阶的，第 14 章接续——
一阶电路是它的"半个自由度"预演。

## 8.6 机器验证

**Julia（`08_models.jl`）/ Python（`08_models.py`）**——六个模型的
复算账，全部断言收口：
(a) 摩擦：v(1.0) 与 v₀e^(−k/m) 比对 + 总距离数值积分
∫₀^∞ v dt 与 v₀m/k 比对（相对误差 < 10⁻⁶）；
(b) 火箭：Δv = vₑ ln(m₀/m_f)，断言 3·ln(7) ≈ 5.838 km/s，并画多
级账（两级各 m_p/m_f = 6：Δv_total = 2vₑln7 ≈ 11.68 km/s > 逃逸速
度 11.2）；
(c) 冷却：解曲线在 t = 3τ 处温差衰减到 e^(−3) ≈ 4.98%；
(d) 半衰期：λ = ln2/30（30 天半衰期），断言 N(30)/N₀ = 0.5（10⁻¹²
容差）与 t = 60 时 = 0.25；
(e) 复利：离散年末 1.06¹⁵、月度 (1.005)¹⁸⁰ 与连续 e^{0.9} 的三列
对照，断言连续比年末多还约 \$6304；
(f) 盐水：RK4 积分 dV/dt = −6V/(150−2t) 到 t = 60，断言
V(60) = 6·(30)³/150³（解析 0.048 L）误差 < 10⁻¹⁰；RL：i(τ) =
(E/R)(1 − 1/e)。

**Fortran（`08_models.f90`）**——经典数值版：摩擦、冷却、盐水三
模型的 RK4 账本，输出对照表（解析 vs 数值），断言最大误差 <
10⁻⁸。Fortran 通道从本章起承担"物理模型主力"角色。

**Prolog（`08_models.pl`）——量纲与极限检查器。** 建模协议第 4 步
的机器化：`dim_check(Expr, Units)` 对指数类模型核对量纲一致性
（e 的指数必须无量纲：λt、kt/m、t/τ 各项的量纲账）；`limit_check
(Model, T→∞, Limit)` 符号求 t → ∞ 极限并与物理直觉表比对（冷却
→ T_env、RL → E/R、摩擦距离 → v₀m/k）。断言例：

```prolog
?- limit_check(cooling, infinity, L).
L = t_env.                       % T → T_env
?- dim_check(exp(mul(k,t)), over(m,k), ok).   % kt/m 无量纲 ✓
```

## 8.7 要点回顾

1. 建模协议：选状态量 → 写变化率账本（守恒/牛顿/唯象）→ 定参数
   初值 → 解与核对（量纲 + 极限）。
2. 指数家族一网打尽：冷却、衰变、复利、摩擦、RL 电路都是
   x′ = −k(x − x_∞) 或其变体——一条曲线，万物皆备。
3. 半衰期 ln2/λ、时间常数 τ = L/R、滑行距离 v₀m/k：**特征量**是模
   型的"名片"，先算它们再谈其他。
4. 混合问题记住体积漂移：浓度 = 含量/当前体积，体积可以是 t 的
   函数。
5. 火箭方程 Δv = vₑ ln(m₀/m_f)：对数壁垒直接论证多级火箭的必要性
   ——数学结论反哺工程决策的样板。
