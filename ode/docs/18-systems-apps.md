# 18 方程组的物理应用

**对应书 §4.7 Applications：带电粒子在磁场中、磁矩进动、弹簧–
质量–弹簧系统、互感电路。**

---

## 18.1 带电粒子在磁场中：螺旋运动

电荷 q、质量 m 的粒子在匀强磁场 B = B ẑ 中受洛伦兹力
F = qv × B（无碰撞、忽略重力）：

    m v̇ = qv × B    ⟹    v̇ = (qB/m)(v_y, −v_x, 0)。

**垂直于 B 的平面内做圆周运动**（ω_c = qB/m 回旋频率），平行方向
自由漂移——合成**螺旋线**。手算：x″ = ω v_y、y″ = −ω v_x 消元得
x⁗ + ω²x″ = 0... 更快的是复数记法 u = x + iy：u̇ = iω u? 直接
u″ = −ω²u ⟹ 圆。半径 r = v_⊥/ω_c：**磁约束**（托卡马克、质谱仪、
回旋加速器的共同原理）。能量守恒：F ⊥ v ⟹ 不做功，|v| 常数。

## 18.2 磁矩进动：Landau–Lifshitz 方程的线性版

磁矩 M 在匀强磁场中受力矩 τ = M × B，角动量正比于 M（旋磁比 γ）：

    **Ṁ = −γ B × M**（书 §4.7.2）

B = B ẑ 时：M_x, M_y 做圆周进动（频率 ω_L = γB，拉莫尔频率），
M_z 常数——磁矩绕磁场方向**进动**，锥角不变。这是磁共振（NMR/
MRI）的经典力学底座：再加交变场就到共振（第 12 章参数共振的
近亲）。

## 18.3 弹簧–质量–弹簧：两自由度耦合振子

两个质量 m 用弹簧 k 连接、两端固定（书 §4.7.3 型）：

    m x₁″ = −k x₁ − k(x₁ − x₂),  m x₂″ = −k x₂ − k(x₂ − x₁)

矩阵形式 x″ = (−k/m)[[2, −1], [−1, 2]]x。特征模式（简正模）：
λ = −k/m（同相，v = (1,1)）与 −3k/m（反相，v = (1,−1)）——**同相
模像单个振子（中间弹簧不吃力），反相模频率高 √3 倍**。一般运动
是两模的叠加，出现**拍**（能量在两质量间来回）。这就是多原子分
子振动谱（简正模分析）的机械模型。

## 18.4 互感电路：电学的耦合振子

两个 RLC 回路通过互感 M 耦合（书 §4.7.4）：矩阵方程出现非对角项
M·i₂′——结构与 18.3 完全同构。工程意义：能量在回路间传递（变压
器、无线充电、滤波器组的耦合设计）。

## 18.5 机器验证

**Julia（`18_apps.jl`）/ Python（`18_apps.py`）**：
(a) 螺旋运动：v(0) = (1, 0.5, 0.3)，B 沿 z——数值积分断言：
v_z 常数、v_x² + v_y² 常数（能量守恒）、轨迹投影为圆（回到起点
的周期 2π/ω_c）；(b) 磁矩进动：|M| 常数、M_z 常数、M_x + iM_y 以
ω_L 旋转（t = 2π/ω_L 时回到初值）；(c) 耦合振子：简正模初值
(1,1) 只激发同相频率 ω（能量不交换）、(1,−1) 只激发 √3ω；一般
初值出现拍——两质量的能量包络互补（E₁(t) + E₂(t) 常数）；
(d) 互感：对称双回路的模式拆解与能量往复。

**Fortran（`18_apps.f90`）**：螺旋运动的 RK4 账本：一个回旋周期
后回到起点（误差 < h⁴ 量级）、z 方向线性漂移距离 = v_z·T。

## 18.6 要点回顾

1. 洛伦兹力 ⊥ v：圆 + 漂移 = 螺旋；回旋频率 ω_c = qB/m、半径
   r = v_⊥/ω_c——磁约束三件套的共同语言。
2. 磁矩进动 Ṁ = −γB×M：绕场进动、锥角与模长守恒——NMR 的经典
   力学。
3. 耦合振子的简正模：对角化 = 找"集体坐标"，同相/反相两模叠加
   出拍；互感电路同构。
4. 守恒律是数值验证的免费质检：|v|²、|M|²、总能量——好的数值格
   式应保持它们（RK4 在这里表现良好）。
