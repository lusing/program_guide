# 26 Sturm–Liouville 理论与 Green 函数

**对应书 §9 Boundary-Value Problems for Second-Order ODEs：Sturm–
Liouville 问题、实例、非齐次与可解性、Green 函数。**

---

## 26.1 从 IVP 到 BVP：问题换了灵魂

边值问题（BVP）在区间**两端**各给条件：y(a) = y(b) = 0（Dirichlet）、
y′(a) = y′(b) = 0（Neumann）或混合。与 IVP 的存在唯一性截然不同：
BVP 可以**无解**（条件打架）也可以**无穷多解**（共振）。

**模型问题**（齐次 SL 的样板）：

    y″ + λy = 0，y(0) = y(π) = 0。

λ < 0 无非零解；λ = 0 只有零解；λ > 0 时 sin √λ x 过边界要求
√λπ = nπ：**λₙ = n²，yₙ = sin nx**——特征值离散且无界！这就是
**Sturm–Liouville 问题**的样板：

    **[p(x)y′]′ + [q(x) + λr(x)]y = 0** + 边界条件（p > 0, r > 0）。

## 26.2 自伴结构与四大定理

SL 算子 L[y] = (p y′)′ + q y 是**自伴的**（分部积分：
∫u Lv = ∫v Lu + 边界项，边界条件吸收边界项）。自伴性带来
Fourier 级数同款的整套结构（书 §9.1）：

1. **特征值实数**、可排成 λ₁ < λ₂ < … → +∞；
2. **正交性**：λₘ ≠ λₙ ⟹ ∫r yₘ yₙ = 0（权 r）；
3. **完备性**：{yₙ} 张成 L²_r[a,b]——任意（分段光滑）函数按特征
   函数展开（广义 Fourier 级数，第 25 章的正交基观点推广到任意
   SL 问题）；
4. **振动理论**：yₙ 在 (a,b) 内恰有 n − 1 个零点（Sturm 振荡定
   理），特征值越大振荡越快。

正弦基（λₙ = n²）只是最简单的 SL；Bessel（第 27 章）、Legendre
（第 28 章）都是 SL 的具体化身——**特征函数展开是统一框架**。

## 26.3 非齐次 BVP 与 Green 函数

非齐次 y″ + λy = f、y(0) = y(π) = 0：λ ≠ n² 时唯一解可写成

    **y(x) = ∫₀^π G(x, ξ) f(ξ) dξ**，

G 是 **Green 函数**——点源响应：G 满足 (i) 每侧是齐次方程的解；
(ii) 在 x = ξ 连续但导数跳 1（单位点源的分布导数）；(iii) 两端
边界条件。对样板问题 G(x,ξ) = sin(x₋)sin(x₃ − x₊)/√λ·sin√λπ 型
的显式拼装。**可解性条件**（书 §9.3.1）：λ = λₙ（共振）时解存
在 ⟺ f 与 yₙ 正交（Fredholm 择一）；此时解不唯一（可加 cyₙ）。
Green 函数观点 = 线性代数的"逆矩阵"：L 的逆是积分算子，核就是
G——微分方程论的算子观点入口。

## 26.4 机器验证

**Julia（`26_sturm.jl`）/ Python（`26_sturm.py`）**：
(a) 打靶法求特征值：y″ + λy = 0、y(0)=0, y(π)=0，对 λ 扫描
打靶残差 y(π; λ) 的零点 = n²（n = 1..5，误差 < 1e-6）；
(b) Rayleigh 商 R[y] = ∫(p y′² − q y²)/∫r y² ≥ λ₁：用试探函数
逼近 λ₁ = 1（sin πx 精确达到），断言 R ≥ 1 且 sin 达到下确界；
(c) Green 函数：对 λ = 0.5（非共振）数值装配 G（两侧齐次解拼
装）验证对称性 G(x,ξ) = G(ξ,x) 与导数跳跃；y = ∫G f 与 RK4 BVP
解对照；(d) 共振可解性：λ = 1，f = sin x（不合正交）打靶发散
（无解）；f = x（合）解不唯一（两条数值解差 c sin x）。

**Prolog（`26_sturm.pl`）**：特征值表（样板问题 λₙ = n² 闭式）、
正交性数值核对（∫sin mx sin nx = 0）、可解性判定表。

## 26.5 要点回顾

1. BVP 与 IVP 灵魂不同：可无解/唯一/无穷多，特征值问题是核心。
2. SL 四大定理：实特征值 → ∞、加权正交、完备（广义 Fourier 展
   开）、振动计数——自伴性是全部机制。
3. Green 函数 = L 的逆的核：两侧齐次解 + 导数跳跃 + 边界条件；
   共振时 Fredholm 择一（f ⟂ yₙ 才有解，解差 c yₙ）。
4. 正弦、Bessel、Legendre 都是 SL 的化身——特征函数展开是全书
   后半的统一语言。
