# 03 可分离方程

**对应书 §2.3 Separable Equations（含齐次方程 y′ = F(y/x) 与平移代换）。**

---

## 3.1 分离变量：第一类可解方程

不存在对一切一阶方程有效的解法——解析可解的只有若干**类型**，每类
配一个变换。第一类也是最基本的一类：**可分离方程**。若
f(x, y) = f₂(x)/f₁(y)——x 和 y 可以被拆到等号两侧——则

    f₁(y) dy = f₂(x) dx，

两侧分别积分，得**隐式通解**

    F₁(y) = F₂(x) + C,    其中 F₁′ = f₁，F₂′ = f₂.

若能从隐式式解出 y，就得到显式通解 y = Φ(x, C)；解不出也不要紧——
**隐式解已经是解**：沿曲线 F₁(y) − F₂(x) = C，由隐函数求导
F₁′(y)y′ = F₂′(x) 即 y′ = f₂(x)/f₁(y)，恰好是原方程。甚至积分
积不出初等函数时，数学传统也宣布"方程已解"——解被化归为两个显式
的求积（quadrature）。

初值问题有免常数的写法（书式 (2.13)）：

    ∫[y₀..y] f₁(r) dr = ∫[x₀..x] f₂(r) dr.

右端积分出来的就是过 (x₀, y₀) 的那条特解——代入 (x₀, y₀) 两侧同
为零，自动满足初值。

**例 1（圆族）** y dy = −x dx（即 y′ = −x/y）。积分得
x² + y² = 2c：以原点为心的同心圆族。初值 y(3) = 4 挑出圆
x² + y² = 25，在上半平面取 y = +√(25 − x²)、下半平面取负号——
注意隐式解在 x = ±5 处 y′ → ∞（竖直切线），方程右端 −x/y 在 y = 0
无定义：**解的存在区间止于方向场失义处**，这正是第 01 章定理的
"局部"二字的具体形状。

**例 2（Malthus 模型）** y′ = ky。除以 y 分离：dy/y = k dx，积分
ln|y| = kx + C，指数化 y = C·e^{kx}（C 可正可负，C = 0 收编除以 y
时丢失的零解——见 3.2）。初值 y(x₀) = y₀ 给出特解
y = y₀·e^{k(x−x₀)}：k > 0 指数增长（人口/复利/链式反应），k < 0
指数衰减（放射性衰变、牛顿冷却的温差）。这是全书出场率最高的解。

**例 3（双曲族）** y′ = −y/x。分离 dy/y = −dx/x，积分
ln|y| = ln C − ln|x|，通解 y = C/x（C ≠ 0，外加除以 y 丢掉的
y ≡ 0？不——此例除的是 y，丢失解 y = 0；通解 y = C/x 取 C = 0
恰好收编）。积分曲线是双曲线族，x = 0 是场的间断线：初值只能取在
x₀ ≠ 0，解生活在 x > 0 或 x < 0 单侧。

**例 4（非唯一性现场）**（书例 2.10）
x√(1+y²) dx = y√(1+x²) dy。除以 (1+y²)(1+x²)（恒正、不丢解）分
离积分：ln(1+x²) = ln(1+y²) + c，即 **x² + 1 = C(y² + 1)**。初值
y(1) = 1 给 C = 1，特解 x² = y²，即 y = ±x——但只有 y = x 过
(1, 1)。若改问 y(0) = 0：y = x 与 y = −x **都**过原点！没有矛盾：
原方程 y′ = x√(1+y²)/(y√(1+x²)) 在 y = 0 处无界，存在唯一性定理
的条件在原点失效。书的图 2.10 演示了戏剧性后果：沿 y = x 从
(1, 1) 走到原点后，可以"滑"到 y = −x 上继续走到 (−1, 1)——非唯
一性意味着积分曲线可以在分叉点换轨。数值方法在这里尤其脆弱（步进
跨过间断线时无从察觉换轨），第 01 章 (c) 实验的又一次预告。

## 3.2 除法的账单：丢失解的纪律

分离变量必然做除法（除以 f₁(y)），而**分母的零点可能是解**。纪律：
动手除之前，先解 f₁(y) = 0，把每个根 y ≡ y*（常函数）代回原方程
核对，登记在案；分离积分得到的通解若能通过取参数极限收编它们
（如 y = C·e^{kx} 的 C = 0 收编 y ≡ 0），就收编；否则作为**奇异
解**单独列出。三例对照：

| 方程 | 除以 | 丢失解 | 通解收编？ |
|---|---|---|---|
| y′ = ky | y | y ≡ 0 | 是（C = 0） |
| y′ = y/x | y | y ≡ 0 | 是（y = Cx，C = 0） |
| y dy = −x dx | ——（除 x? 无）| y′=−x/y 在 y=0 无义 | 不适用（场失义） |

Prolog 通道（`03_separable.pl`）把这条纪律做成机器检查：`lost_
solutions(f1, Lost)` 解 f₁(y) = 0 并逐个核对原方程，`solve_separable`
输出通解 + 丢失解清单，两侧都要打勾。

## 3.3 齐次方程：y′ = F(y/x)

可分离类的第一次扩张。若方程能写成 **y′ = F(y/x)**（F 是一元函数；
判据：f(λx, λy) = f(x, y)，即右端在尺度缩放下不变），令

    z = y/x （即 y = xz），则 y′ = z + x·z′，

代入得 z + x z′ = F(z)，即 **dz/(F(z) − z) = dx/x**——一个可分离方
程。解出隐式关系 G(z) = ln|x| + C 后回代 z = y/x。变换的几何含
义：齐次方程的方向场沿过原点的射线平移不变（射线 y = kx 正是第
02 章的等斜线），所以沿射线"走到同一斜率处"只差一个尺度因子——
一维问题。

**例 5**（书例 2.13）(x² + y²) dx − 2xy dy = 0，即
y′ = (x² + y²)/(2xy)。检验齐次性：分子分母同除 x² 得
(1 + z²)/(2z)，只依赖 z = y/x ✓。代入 z + xz′ = (1+z²)/(2z)，
分离 dx/x = 2z dz/(1 − z²)，积分 ln|x| = −ln|1 − z²| + c，整理得
x(1 − z²) = C，回代 z = y/x：x − y²/x = C，即 **y² = x² − Cx**。
除以 2xy 时丢失 x = 0（作为 x(y) 的解）——账单照记。

**例 6**（书例 2.14）y′ = y/x + tan(y/x)。令 z = y/x 得
z + xz′ = z + tan z，分离 cos z dz/sin z = dx/x，积分
ln|sin z| = ln|x| + ln c，通解 **sin(y/x) = Cx**。取 C = 1 的特解
y = x·arcsin x（0 ≤ x < 1）会被 Lean 通道逐字核对（3.5 节）。

**平移代换**：形如 y′ = G(ax + by + c) 的方程，令 u = ax + by + c
（u′ = a + b·y′ = a + b·G(u)）化为可分离。书习题 23 的
y′ = (y + x + 3)(y + x + 1) 即令 u = y + x：u′ = (u+3)(u+1) + 1
——部分分式积分即可。**先找结构（齐次/平移/可分离），再套变换**
是整个"初等解法"篇的方法论。

## 3.4 机器验证

**Julia（`03_separable.jl`）/ Python（`03_separable.py`）**：
(a) 隐式解核对——对例 1 的隐式解 x² + y² = 25：上半圆
y(x) = √(25 − x²) 数值求导，与 −x/y 比对（残差 < 10⁻¹⁰，解析导
数 −x/√(25−x²) 可作精确对照）；(b) 免常数定积分式 (2.13) 直接当
求解器用：对 y′ = ky、y(0) = 2，Newton 迭代解 ∫[2..y] dr/r = kx
中的 y，与 y₀e^{kx} 比对；(c) 齐次方程数值验证：例 5 的隐式解
y² = x² − Cx（取 C = 1，初值 x = 2 时 y = √2）沿曲线数值求导与
(x²+y²)/(2xy) 比对；(d) 例 4 的分叉演示：从 (1,1) 用 RK4 积分到
x = −1，显式追踪解在原点附近的"贴轨"行为（小步长下数值解沿
y = x 走向原点后受舍入误差支配——非唯一性的数值指纹）。

**Prolog（`03_separable.pl`）——符号求解器第一版。** 表达式树 +
符号微分 + 小型积分表（xⁿ、1/x、eˣ、sin、cos、1/(1+x²)），
`separable(ODE, Sol)` 识别 f₂(x)/f₁(y) 结构、执行分离积分、输出
隐式通解；`lost_solutions/2` 执行 3.2 的纪律；`homogeneous(ODE, Z)`
检测齐次性并完成 z = y/x 化归。断言例：

```prolog
% y' = ky ⟹ y = C·e^{kx}（外加丢失解 y = 0 被通解收编）
?- solve_separable(ode(div(mul(k,y), n(1))), S).
S = implicit(sub(ln(abs(y)), mul(k, x))) ...   % ln|y| = kx + C
% 齐次检测：(x²+y²)/2xy 的 z 化归
?- homogeneous_step(div(add(pow(x,2),pow(y,2)), mul(n(2),mul(x,y))), Fz).
Fz = div(add(n(1), pow(z,2)), mul(n(2), z)).  % F(z) = (1+z²)/2z
```

**Lean（`Ode/Ch03Separable.lean`）——两份"逐字证明"。**
其一，例 2 的特解核对：y = 5/x 满足 y′ = −y/x：

```lean
example (x : ℝ) (hx : x ≠ 0) :
    HasDerivAt (fun x => 5 / x) (-(5 / x) / x) x := by
  have h : HasDerivAt (fun x => 5 / x) (-5 / x ^ 2) x := by
    simpa using (hasDerivAt_id x).const_div 5   -- (a/x)' = -a/x²
  rwa [neg_div, div_div] at *  -- -5/x² = -(5/x)/x 的代数恒等式
```

其二，例 6 的 C = 1 特解核对：y = x·arcsin(x) 满足
y′ = y/x + tan(y/x)。左端乘积法则给 arcsin x + x/√(1−x²)；右端
y/x = arcsin x，tan(arcsin x) = x/√(1−x²)（由 sin θ = x、
cos θ = √(1−x²) 的直角三角形代换）——两侧逐项相等。求导的每一
步都由 mathlib 的 `HasDerivAt` 组合子完成，没有一步"显然"。

## 3.5 要点回顾

1. 可分离 = 右端拆成 f₂(x)/f₁(y)；两侧积分得隐式通解 F₁(y) =
   F₂(x) + C；隐式解也是解（隐函数求导回收方程）。
2. 除法丢解要记账：先解 f₁(y) = 0、逐个核对、能收编则收编
   （C = 0），不能收编列为奇异解。
3. 齐次方程 y′ = F(y/x) 用 z = y/x 化归为可分离；平移型
   y′ = G(ax+by+c) 用 u = ax+by+c 同理。找结构先于套公式。
4. 非唯一点（场失义/定理失效处）是积分曲线的分叉口，可以换轨——
   解的存在区间与唯一性都要在定理条件下逐点核对，不是全局赠品。
5. 定积分式 ∫[y₀..y] f₁ = ∫[x₀..x] f₂ 本身就是数值求解器（配
   Newton 解 y）——"解析式"与"算法"的界线比想象中模糊。
