# 12 周期系数：Hill 方程与 Mathieu 方程

**对应书 §3.6 Linear Second-Order Equations with Periodic
Coefficients。**

---

## 12.1 周期系数：全新的现象

常系数方程的解是 e、sin/cos 的组合，行为温和。系数**周期变化**
（p(x + L) = p(x), q(x + L) = q(x)）时出现全新的现象：**参数共
振**——在某些参数区间里解指数增长，即使没有任何外力项。这就是
秋千的原理：站在秋千上的人周期性改变重心（改变系统的系数），
小扰动被放大成大摆动。

标准处理先把方程规范化。y″ + p(x)y′ + q(x)y = 0 中的一阶项可以
**除掉**：令 y = a(x)u，选 a(x) = e^(−½∫p dx)，方程变成无阻尼
形式（书式 (3.60)–(3.65)）：

    u″ + Q(x)u = 0，Q(x + L) = Q(x)，Q = q − p′/2 − p²/4.

这叫 **Hill 方程**。两个代表：Mathieu 方程 u″ + (a − 2q cos 2x)u
= 0（余弦调制）与 Meissner 方程（方波调制，手算友好）。

## 12.2 平移矩阵与特征乘子（Floquet 理论的二阶版）

周期性的直接推论（书 §3.6.1）：若 u(x) 是解，则 u(x + L) 也是解
（方程平移不变）。于是基本组 u₁, u₂ 满足

    [u₁(x+L); u₂(x+L)] 矩阵关系 = T·[u₁(x); u₂(x)]，

T 是**平移矩阵**（translation matrix，周期 L 的单周期传播矩阵）。
由 Abel 恒等式 W 不变 ⟹ **det T = 1**。T 的特征值 λ±（**特征乘
子**）满足

    λ² − (tr T)λ + 1 = 0    ⟹    λ± = ½ tr T ± ½√(tr²T − 4).

|tr T| < 2 时 λ± 是单位圆上的复共轭对（λ = e^{±iθ}）——解**有界
振荡**（稳定）；|tr T| > 2 时 λ± 是互倒实数，|λ₊| > 1——解含
指数增长因子 |λ₊|^{x/L}（**不稳定**，参数共振带）；|tr T| = 2 是
带边界。整个 (a, q) 参数平面被稳定舌（tongue）与不稳定带分割——
这就是 Mathieu 方程著名的**稳定性图**。

**Meissner 方程的手算**（本教程的机器主戏）：u″ + (ω² + ε·s(x))u
= 0，s(x) = +1（0 ≤ x < L/2），−1（L/2 ≤ x < L）。单周期平移矩
阵 T = P₊·P₋（两段常系数方程的传播矩阵乘积），每段

    P_± = [[cos κ_± L/2, sin(κ_± L/2)/κ_±], [−κ_± sin(κ_± L/2), cos(κ_± L/2)]],

κ_±² = ω² ± ε。tr T 是 ε, ω 的显式三角多项式——数值通道直接算
出稳定带边界，与 Floquet 数值实验交叉验证。

## 12.3 Mathieu 方程与参数共振

Mathieu 方程 u″ + (a − 2q cos 2x)u = 0（周期 π）。物理出场名单：
秋千（摆长周期变化）、Paul 阱（射频离子阱，q 是调制深度）、
晶体中的电子（周期势）、月球轨道摄动。第一不稳定带从 a ≈ 1 − q
附近发出（小 q 时边界 a ≈ 1 ± q + O(q²)），第 n 带从 a ≈ n² 发
出。**参数共振的直觉**：调制频率取系统固有频率两倍附近（a = 1,
cos 2x 的频率 2 对应半周期 π = 固有周期之半）时最有效地泵入能量。

## 12.4 机器验证

**Julia（`12_mathieu.jl`）**：(a) Meissner 方程解析 T 与数值 T
双算（数值版：RK4 积两个基本解过一个周期）对照（< 10⁻¹⁰）；
(b) 扫 (ω, ε) 网格算 |tr T| > 2 的不稳定区域，断言 (1, 0.8) 在带
内、(1, 0.01) 在带边附近、(2.3², 0.5) 稳定；(c) 单轨数值实验：
不稳定参数下初值 (1, 0) 的解在 10 个周期增长 e^{10μ}（μ =
ln|λ₊|/L 与数值增长率拟合对照）。

**Python（`12_mathieu.py`）**：scipy.special 有 Mathieu 函数全家
桶——`mathieu_a(a_order, q)` 是特征值 aₙ(q)：断言 a₀(1) ≈
−0.4551386、a₁(1) ≈ 1.8591081（带边界）；对 q 扫描画 a₀(q),
a₁(q) 曲线数据，验证第一带宽度 |a₁ − a₀| 随 q 增大（解析小 q
近似 a₀ ≈ −q²/2, a₁ ≈ 1 − q − q²/8 + 5q³/128 对照）；数值
Floquet（solve_ivp 过一个周期 × 1000 周期）验证 a = 1, q = 1 时
指数增长 vs a = 1, q = 0.1 的 a₀ 与 a₁ 之间稳定。

**Fortran（`12_mathieu.f90`）**：Meissner 方程数值 T 的经典版：
RK4 双轨（初值 (1,0) 与 (0,1)）积分一个周期装配 T，输出
tr T 与稳定性判定；ω = 1 扫 ε ∈ [0, 3]，输出稳定/不稳定边界点
（与 Julia 的解析边界对照）。

## 12.5 要点回顾

1. 周期系数 ⟹ 解平移一个周期仍是解 ⟹ 平移矩阵 T；det T = 1
   （Abel）；稳定 ⟺ |tr T| < 2（乘子在单位圆）。
2. 去阻尼代换 y = e^{−∫p/2}u 把一般周期方程化成 Hill 形式。
3. Mathieu 稳定图：不稳定带从 a = n² 发出、随 q 展宽；参数共振
   = 系数调制把能量泵进系统，无需外力项。
4. 数值协议：RK4 双基本解过一个周期 ⟹ T ⟹ tr T ⟹ 判稳——
   Floquet 数值分析的标准动作，第 22 章极限环研究复用。
