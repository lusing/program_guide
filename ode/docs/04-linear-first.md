## 4.1 万能解法的对象：y′ + p(x)y = f(x)

第 03 章的可分离方程靠"运气"（右端能拆开）；本章的对象不靠运气——
**一阶线性方程**

    y′ + p(x)·y = f(x)

是第一类拥有**通用解法**的方程：只要 p、f 连续，解法必然成功，而
且解存在唯一、定义在 p、f 连续的整个区间上（第 01 章定理 + f 关于
y 的 Lipschitz 常数 = sup|p|）。线性红利在这一章兑现为三件事：
万能、全局、结构清晰（4.4 节）。

先解**齐次方程** y′ + p(x)y = 0：分离变量 dy/y = −p(x)dx，积分得

    y = C·e^(−∫p(x)dx)

（除以 y 丢失的零解被 C = 0 收编——第 03 章的纪律照旧）。例：
y′ + 5y = 0 的通解 y = C·e^(−5x)。注意记号约定：∫p(x)dx 表示**某
一个**原函数，积分常数省略——因为通解里的 C 已经包揽一切常数自由
度。

## 4.2 参数变易法：让常数动起来

非齐次方程的解法有两个等价面貌，先看书的主推——**参数变易法**
（variation of a parameter，Lagrange 的发明）：把齐次通解里的常数
C 换成待定函数 u(x)，即设

    y(x) = u(x)·e^(−∫p dx).

代入原方程：y′ = u′e^(−∫p) − u p e^(−∫p)，于是

    y′ + p y = u′·e^(−∫p) = f(x)，

含 u 的两项**恰好抵消**（这就是 e^(−∫p) 的深意），剩下
u′(x) = f(x)·e^(∫p dx)，积分得 u = ∫f e^(∫p) + C。代回：

    y(x) = C·e^(−∫p dx) + e^(−∫p dx)·∫ f(x)·e^(∫p dx) dx.      （★）

抵消不是巧合：选 e^(−∫p) 做"底座"，正是让算子 L[y] = y′ + py 作用
在"底座 × 系数"上时只对系数求导。

**例 A**（书例 2.16）y′ + 5y = eˣ。齐次解 y_h = C e^(−5x)；设
y = u e^(−5x)，代入得 u′ e^(−5x) = eˣ，u′ = e^(6x)，u = e^(6x)/6
+ C，故

    y = C·e^(−5x) + eˣ/6.

**例 B**（书例 2.17）y′ − y/x = x（p = −1/x，只在 x > 0 或 x < 0
上谈）。齐次解 y = Cx；设 y = ux，代入得 u′x = x，u = x + C：

    y = Cx + x².

## 4.3 积分因子：同一个机关的另一个扳手

**积分因子法**把 (★) 的机关直接亮出来。乘 μ(x) = e^(∫p dx)：

    μ(y′ + py) = μ·f    ⟹    (μ·y)′ = μ·f，

因为 μ′ = μp，乘积法则展开后左端正是 μy′ + μpy。于是一次积分

    y = μ⁻¹·(∫μ f dx + C).

两法产出完全一致（书的说法：(2.27) 与 (2.23) 相同），但视角不同：
参数变易是"结构化猜测"，积分因子是"配完全导数"。后者的机关在第
05 章（恰当方程找积分因子）将以一般形式回归——线性方程的
μ = e^(∫p dx) 是那里"只依赖 x 的积分因子"的特例。

例 A 用积分因子走一遍：μ = e^(5x)，(e^(5x)y)′ = e^(6x)，积分
e^(5x)y = e^(6x)/6 + C，y = C e^(−5x) + eˣ/6。与 4.2 相同，一步
到位。

## 4.4 解的结构：通解 = 齐次通解 + 一个特解

（★）式的形状揭示结构：第一项 C·e^(−∫p) 是**齐次方程的通解**
Y(x)，第二项是不含常数的**一个特解** ȳ(x)。通解 = Y + ȳ。

这不是线性方程 y′ + py = f 独有的怪事，而是**线性叠加原理**的第一
次显灵：若 y₁、y₂ 是非齐次方程的解，则 y₁ − y₂ 是齐次方程的解
（L[y₁−y₂] = f − f = 0）；反之齐次解加特解仍是非齐次解。第 10 章
（二阶）、第 15 章（方程组）会把同一原理逐字重演，那时"齐次解空
间是向量空间、维数 = 方程阶数"会成为完整理论。本章先记口诀：
**解齐次、找特解、相加**。

## 4.5 非线性方程的线性化变装

三类方程不是线性的，但一次代换就现出线性原形。

**(a) 隐藏线性（交换自变量）**。若方程对 y(x) 非线性，对 x(y) 却
线性——用 x′(y) = dx/dy = 1/y′ 互换。例（书例 2.19）：

    (2eʸ − x)·y′ = 1   ⟹   2eʸ − x = dx/dy   ⟹   x′ + x = 2eʸ

对 x(y) 是线性方程！齐次解 x = C e^(−y)，参数变易 u′ = 2e^(2y)，
u = e^(2y) + C：

    x = C·e^(−y) + eʸ（隐式解，y 为自变量）。

**(b) Bernoulli 方程** y′ + p(x)y = f(x)·yⁿ（n ≠ 0, 1）。除以
yⁿ：y^(−n)y′ + p y^(1−n) = f。令 **z = y^(1−n)**，则
z′ = (1−n)y^(−n)y′，方程化为线性：

    z′/(1−n) + p·z = f.

**例 C**（书例 2.20）y′ − y = 3/y（n = −1）。乘 y：yy′ − y² = 3；
令 z = y²，z′/2 − z = 3。齐次解 z = C e^(2x)；参数变易
u′e^(2x)·(1/2)…直接积分因子 2e^(−2x)：得 z = C e^(2x) − 3：

    y² = C·e^(2x) − 3（隐式解；n ≥ 1 时除法丢失的 y ≡ 0 要记账）。

**(c) Riccati 方程** y′ + p y + q y² = f。一般不可解，但**已知一
个特解 y₁ 时**：令 y = y₁ + w，代入后 y₁ 满足的部分整体抵消，剩下
w′ + (p + 2q y₁)w + q w² = 0——w 的 Bernoulli（n = 2，右端为 0），
再令 z = w^(−1) 化为线性。**例 D**（书例 2.21）y′ = y² − 2/x²。
猜 y₁ = 1/x（多项式特解试探：y = a/x 代入得 a 项平衡），代换化简
后 z′ = −2z/x − 1，齐次解 z = C/x²，特解 z = −x³/3，回代两级
（w = 1/z，y = 1/x + 1/z）得通解。Riccati 与二阶线性方程有更深
的等价（z = w′/w 型代换把它变成二阶线性）——第 10 章再回来。

"猜一个特解"听起来像玄学，其实是**常数/多项式试探协议**：右端与
系数都是 x 的幂时，特解大概率是幂（例 D 的 1/x）；共振情形（第 11
章待定系数法）才需要升次。机器通道把"猜后核对"自动化——猜错立
刻被代入残差抓出来。

## 4.6 机器验证

**Julia（`04_linear.jl`）/ Python（`04_linear.py`）**：
(a) 万能解法数值版——公式 (★) 直接数值化（自适应积分 + Newton），
对 y′ + 5y = eˣ 输出 y(0.3)，与解析 Ce^(−5x) + eˣ/6 的 C=0 分支比
对（初值 y(0) = 1/6 定 C）；(b) RK4 独立核对——同一 IVP 用 RK4 积
分，两条完全不同路径的解在 10⁻¹⁰ 内一致（公式 vs 步进的交叉验
证）；(c) Bernoulli 数值：y′ − y = 3/y、y(0) = 2（C = 7/…由初值
定），RK4 与隐式解 y = √(C e^(2x) − 3)（C = 7）比对；(d) 叠加原
理数值实验：三个 IVP（f = 0、f = eˣ、f = 2eˣ 同初值改齐次支）验
证 L[y₁+y₂] 分解。

**Prolog（`04_linear.pl`）——线性求解器。** `solve_linear(P, F, Sol)`
执行参数变易全流程：齐次解（积分表）、u′ 方程（表）、回代，输出
u(x) 表达式与通解；`bernoulli(N, P, F, ZSol)` 完成代换协议；所有
例子用书的例 A/B/C 断言：

```prolog
?- solve_linear(n(5), exp, S).
S = add(mul(C, exp(mul(-5,x))), div(exp(x), 6)).   % y = Ce^{-5x} + e^x/6
?- bernoulli(n(-1), n(-1), n(3), S).
S = implicit(sub(pow(y,2), sub(mul(C,exp(mul(2,x))), 3))). % y² = Ce^{2x}-3
```

**Lean（`Ode/Ch04Linear.lean`）——通解公式的逐字证明。** 对 p、f
取常数的模型方程 y′ + 5y = eˣ：证明 y = C e^(−5x) + eˣ/6 对**任意**
C 都是解（导数 5Ce^(−5x)·(−1)…，加 5 倍函数值恰好抵成 eˣ——
`HasDerivAt` 组合子装配 + `ring` 收尾）。再证例 B：y = Cx + x² 满足
y′ − y/x = x（x ≠ 0 上，除法用 `div` 的求导规则）。两例合起来把
（★）的"通用公式"在两个采样点上完全钉死：

```lean

theorem exA_solve (C : ℝ) (x : ℝ) :
    HasDerivAt (fun x => C * exp (-5 * x) + exp x / 6)
      (-(5 * (C * exp (-5 * x) + exp x / 6)) + exp x) x := by
  -- 导数 = -5C·e^{-5x} + e^x/6，与 -(5y) + e^x 逐项相等的代数账
  ...
```

（完整证明在示例文件里展开：两支函数各自 `HasDerivAt`，再
`ring` 对账。）

## 4.7 要点回顾

1. 一阶线性是第一类"万能可解"方程：齐次解 C·e^(−∫p) + 特解，全
   局存在唯一（p、f 连续区间上）。
2. 参数变易（设 y = u·e^(−∫p)，u 抵消）与积分因子（乘
   μ = e^(∫p)，配成 (μy)′ = μf）是同一机关的两个扳手。
3. 结构律：通解 = 齐次通解 + 任一特解；y₁ − y₂ ∈ 齐次解空间——
   叠加原理的第一次显灵，10/15 章重演。
4. 三件变装：交换变量（隐藏线性）、z = y^(1−n)（Bernoulli）、
   已知特解 + w = y − y₁ 再 z = 1/w（Riccati）。猜特解用幂试探 +
   机器核对。
5. 记号 ∫p dx 约定取一个原函数，常数自由度全部归入 C。
