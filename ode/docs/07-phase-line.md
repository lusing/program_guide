# 07 自治方程的相线：平衡点与稳定性初判

**对应书 §2.7 Qualitative Approach for Autonomous First-Order
Equations。**

---

## 7.1 不解方程，先看全局

**自治方程**（autonomous，AE）指右端不含自变量的方程

    dy/dt = f(y)，

物理读法：t 是时间，系统的演化规律不随时间改变（"autonomous" =
自我驱动，不靠外部时间表）。自治方程当然可分离（第 03 章：
t = ∫dy/f(y)），但本章的目标是**不解方程**而读出全部解的定性行
为——工程师关心的是"反应器温度最终稳定还是爆炸"（书的开场例），
不是解的公式。

方法叫**相线法**（phase line）。数值方法的短板正好衬托它：数值一
次只算一条轨道，初值选漏一类行为就整体误判；相线一步给出**全部解**
的定性分类。

## 7.2 相线三步协议

**第一步：平衡解。** 常数解 y ≡ yₑ ⟺ f(yₑ) = 0——解代数方程即得。
平衡解也叫平衡点/临界点，是相线的"锚点"。

**第二步：标号区间。** 平衡点把 y 轴切成若干区间；每区间内 f 不变
号（零点都是平衡点），取一个测试点定号：f > 0 记 ↑（解在该区间
单调增），f < 0 记 ↓。把 y 轴竖起来画、配上箭头，就是相线。

**第三步：读相线。** 初值落在 ↑ 区间的解单调增。增到哪里？不能穿
过平衡解（唯一性定理禁止解曲线相交或合并——第 01 章的定理第一次
变成几何禁令），所以只有两种结局：渐近趋于平衡点，或奔向无穷/有
穷爆破。相邻箭头**相向（↓ 上 ↑ 下？不：左箭头指向平衡点）**——
两个区间箭头都指向平衡点 ⟹ 平衡点**吸引**（attractor/sink/稳定
结点）；都背离 ⟹ **排斥**（source/不稳定结点）；一半一半 ⟹ 退化
结点或更高阶情形。

**判据版**（导数判别）：平衡点 yₑ 处

    f′(yₑ) < 0 ⟹ sink（稳定）；f′(yₑ) > 0 ⟹ source（不稳定）；
    f′(yₑ) = 0 ⟹ 退化结点（需回到符号分析）。

导数判据快但有盲区（见例 4），**符号分析才是完整版**。

## 7.3 四个样板例（书例 2.28–2.31）

**例 1：y′ = ky。** 平衡点 y = 0。k > 0：y > 0 处 f > 0（↑）、
y < 0 处 f < 0（↓）——箭头背离 0，**source**；k < 0 相向，**sink**。
对照解析解 y = y₀e^{kt}：k < 0 时一切解 → 0 ✓。k 从负过零变正
时，sink 变 source——**分岔**（bifurcation）的第一次亮相，k = 0
是分岔值（第 21 章专题）。

**例 2：y′ = y(y − 1)。** 平衡点 0 与 1。符号：y > 1 时 ↑，
0 < y < 1 时 ↓，y < 0 时 ↑。y = 1 被两侧背离：source；y = 0 被两
侧指向：sink。导数判据 f′ = 2y − 1：f′(0) = −1 < 0 ✓ sink，
f′(1) = 1 > 0 ✓ source。解析解 y = 1/(1 ± Ce^t) 可逐条核对定
性（图 2.15 的竖直渐近线是解析信息，定性分析不提供——书特别指
出**定性方法的边界**：它不给爆破时刻）。

**例 3：y′ = ky²。** 平衡点 0（二重根）。k > 0 时两侧都是 ↑：左
侧解从负值升向 0？不能穿过 0……注意：y < 0 区间 ↑ 但 0 是平衡
点，解只能**渐近趋于 0**（t → ∞）；y > 0 区间 ↑ 且无处可去——
**有限时间爆破**（解析解 y = 1/(y₀⁻¹ − kt)：分母在 t = (ky₀)⁻¹
处归零）。相线只说"增"，不说何时爆——退化结点（f′(0) = 0）的
两侧行为要靠解析或数值补完。**0 是不稳定平衡点**（一侧发散）。

**例 4：y′ = ky³（导数判据的盲区）。** 平衡点 0，f′(0) = 0。符号
分析：k > 0 时 y > 0 ↑、y < 0 ↓——**两侧相背，source**（且有限时
间爆破，解析解 y = ±1/√(C − 2kt) 在 C − 2kt = 0 处发散）；k < 0
时两侧相向，**sink**，且收敛是**幂式**的：y(t) ~ 1/√(2|k|t)。导数
判据对两种情形都哑火（f′(0) = 0 什么也没说）。结论（书）：**相线/
符号分析比导数判据强，导数判据必须辅以邻域符号检查**。例 3 与例 4
同为 f′(0) = 0，一个半稳定一个真不稳定（或真稳定）——退化情形没
有捷径。

## 7.4 相线能做什么、不能做什么

能：定全部解的单调性与渐近归属；判定平衡点类型（sink/source/退
化）；随参数扫相线即可读出分岔（例 1 的 k 过零）。
不能：给爆破时刻（例 3）；给收敛速率（sink 是指数式还是幂式——
例 2 的 0 是指数式，例 4 的 0 是 1/√t 幂式，相线不分）；非自治方
程不适用（f 显含 t 时没有相线）。

收敛速率的判别其实有后手：sink 处局部线性化 y′ ≈ f′(yₑ)(y − yₑ)
给指数速率 e^{f′(yₑ)t}；f′(yₑ) = 0 时要看更高阶——例 4 的幂式衰
减正来自三次非线性。这是第 20 章 Lyapunov 方法的一维预告。

## 7.5 机器验证

**Julia（`07_phaseline.jl`）/ Python（`07_phaseline.py`）**：
(a) 相线构造器——给定 f 与区间，数值求根（bisection 扫描）得平
衡点，逐区间符号采样输出相线表（点 + 箭头方向的文本图）；
(b) 分类核对——对例 1–4 的每个平衡点，比较符号分析结论与导数判
据（例 4 应显示判据失效、符号分析接管）；(c) 轨道族抽查——对例 2
从 y₀ ∈ {0.3, 0.7, 1.3, −0.2} 用 RK4 积分到 t = 12，断言 sink 侧
解 |y(12)| < 10⁻⁴、source 侧解离开 1 至少 0.5（渐近行为与相线预
言一致）；(d) 例 3 爆破时刻——解析爆破点 t* = 1/(ky₀) 与数值解
最后有限值时刻比对（RK4 在 t* 前后溢出/越过，报告实际越界步）；
(e) 收敛速率——例 4 拟合 log|y(t)| 对 log t 的斜率 ≈ −1（1/t decay，
即 y ~ 1/√(2kt) 的平方量级核对）。

**Prolog（`07_phaseline.pl`）——符号相线引擎。** 对多项式 f(y)：
`equilibria(F, Es)` 符号求根（有理根 + 二次公式）；`sign_regions(F,
Regions)` 逐区间定号（测试点代入，rational 算术零舍入）；`classify
(F, Yₑ, Type)` 按相向/相背/混合规则输出 sink/source/degenerate；
`derivative_check(F, Yₑ, Verdict)` 输出导数判据结论并检测其与符
号结论的分歧（例 4 的分歧是断言之一）。断言例：

```prolog
?- f(y(y-1)) 式表示: classify(mul(y,sub(y,1)), 0, T).
T = sink.
?- classify(mul(y,sub(y,1)), 1, T).
T = source.
?- classify(mul(k,pow(y,3)), 0, T), derivative_check(mul(k,pow(y,3)), 0, V).
T = sink, V = degenerate(undetermined).   % 判据失效，符号分析接管
```

（完整代码里谓词以表达式树为参数，上面是示意。）

## 7.6 要点回顾

1. 自治方程 y′ = f(y) 有相线：平衡点 f(yₑ) = 0 分割 y 轴，逐区间
   定号画箭头，一步读出全部解的定性分类。
2. 平衡点分类：箭头相向 = sink（稳定），相背 = source（不稳定），
   退化结点需符号细看。导数判据 f′(yₑ) ≶ 0 是快捷方式但有盲区
   （f′(yₑ) = 0 时哑火，例 3/4 反向）。
3. 唯一性定理的几何禁令：解曲线不得相交/合并 ⟹ 单调解只能渐近贴
   平衡解或爆破。
4. 相线不给爆破时刻与收敛速率；速率看局部线性化（指数）或高阶项
   （幂式）——第 20 章的预告。
5. 参数扫过相线 ⟹ 分岔初现（k 过零 sink↔source）——第 21 章专
   题预告。
