## 24.1 把微分方程变成代数方程

**Laplace 变换**把 [0, ∞) 上的函数 f 映成

    F(s) = L{f}(s) = ∫₀^∞ e^{−st} f(t) dt（s 大于某收敛横标）。

一维积分把 t-域的**求导**变成 s-域的**乘多项式**：

    **L{f′} = sF(s) − f(0)**，L{f″} = s²F(s) − s f(0) − f′(0)。

线性 IVP 两边取变换：微分方程坍缩成 F(s) 的**代数方程**；解出
F(s) 再**反变换**（查表 + 部分分式）回 f(t)。工作流：

    微分方程 + 初值 →（变换）→ 代数方程 →（解出 F）→ 部分分式
    →（查表反变换）→ 解。

三条性质撑起整个工具箱（书 §7.2）：

- **线性**：L{af + bg} = aF + bG；
- **平移**：L{e^{at}f} = F(s − a)（指数因子左移）；L{f(t−a)·H
  (t−a)} = e^{−as}F(s)（延迟，H 是单位阶跃）；
- **卷积**：L{f ∗ g} = F·G，其中 (f ∗ g)(t) = ∫₀ᵗ f(τ)g(t−τ)dτ
  ——乘法与卷积互变，Duhamel 积分（用阶跃响应构造任意输入的响
  应）的来源。

## 24.2 变换表与部分分式：计算的实际形态

核心表（右边是 f(t)，左边 F(s)）：

| f(t) | F(s) |
|---|---|
| 1 | 1/s |
| tⁿ | n!/sⁿ⁺¹ |
| e^{at} | 1/(s−a) |
| sin ωt | ω/(s²+ω²) |
| cos ωt | s/(s²+ω²) |
| e^{at} sin ωt | ω/((s−a)²+ω²) |

**例 A**（书 §7.3 型）y″ + 4y = cos 2t、y(0) = y′(0) = 0（共
振）：(s² + 4)Y = s/(s² + 4) ⟹ Y = s/(s²+4)² ⟹ 反变换
y = (t/4) sin 2t——共振升次的线性增长解，第 11 章的旧相识从变
换侧重现。
**例 B** y″ + 3y′ + 2y = 1、零初值：Y = 1/[s(s+1)(s+2)]，部分
分式 = ½/s − 1/(s+1) + ½/(s+2) ⟹ y = ½ − e^{−t} + ½e^{−2t}。
**例 C**（卷积/Duhamel）零初值时 Y = G(s)F(s)/特征多项式 ⟹
y = g ∗ f——冲激响应与传递函数的观点，控制理论的入口。

变换法的三件独家兵器：**分段右端**（阶跃/方波：延迟性质直接处
理）、**冲激输入**（L{δ} = 1）、**初值自动内置**（无需先解常数）。

## 24.3 机器验证

**Julia（`24_laplace.jl`）/ Python（`24_laplace.py`）**：
(a) 数值 Laplace：对 f ∈ {1, t², e^{−t}, sin 2t} 用截断积分
（e^{−st} 衰减）算 F(s)，与表值对照（相对误差 < 10⁻⁸）；
(b) 例 A/B 全流程：代数解出 Y、部分分式（Julia 用 SymPy？——不
引包：手写部分分式系数公式）后反变换，与 RK4 数值解对照；
(c) 卷积定理：数值 (f ∗ g)(t) 的变换 = F·G（两点核对）；
(d) 共振例 A 的 t/4 sin2t 振幅线性增长数值验证。

**Prolog（`24_laplace.pl`）——变换表引擎。** `laplace(F_t, F_s)`
表驱动（上表 + 线性 + 平移规则）；`solve_ivp_laplace`：二阶常系
数 + 表内右端的 IVP 全流程（变换 → 代数解 → 部分分式（一阶实
极点）→ 反变换），例 B 端到端符号跑通；`convolution_check` 数
值点核对卷积定理。

## 24.4 要点回顾

1. L 把求导变乘 s、初值自动携带：IVP ⟹ 代数方程 ⟹ 部分分式
   ⟹ 查表回程。
2. 性质三件套：线性、平移（e^{at} 左移 / 延迟 e^{−as}）、卷积
   （乘积 ⟺ 卷积，Duhamel）。
3. 独家领域：分段右端（延迟性质）、冲激（L{δ}=1）、传递函数观
   点。
4. 共振升次在 s-域自动出现（部分分式出现重极点 ⟹ t·e^{at} 型
   反变换）。
