# 30 · 附录：学习资源

## 官方文档

- **Lean 4 手册**: https://leanprover.github.io/lean4/doc/
- **Mathlib4 API 文档**: https://leanprover-community.github.io/mathlib4_docs/ （全文检索定理）
- **Lean 4 源代码**: https://github.com/leanprover/lean4
- **Mathlib4 源代码**: https://github.com/leanprover-community/mathlib4
- **Lean 4 版本发布说明**: https://leanprover.github.io/lean4/doc/releases.html （查版本间语法变化）

## 教程与书籍

- **Functional Programming in Lean**: https://leanprover.github.io/functional_programming_in_lean/
- **Theorem Proving in Lean 4**: https://leanprover.github.io/theorem_proving_in_lean4/
- **Mathematics in Lean**: https://leanprover-community.github.io/mathematics_in_lean/ （本教程第二部分的进阶版）
- **Logic and Proof**: https://leanprover.github.io/logic_and_proof/
- **The Mechanics of Proof**: https://hrmacbeth.github.io/math2001/ （数学本科生视角）

## 定理搜索工具

- **Loogle**: https://loogle.lean-lang.org/ （按类型模式搜）
- **Moogle**: https://www.moogle.ai/ （自然语言搜）
- **LeanSearch**: https://leansearch.net/ （基于 leansearch-client）

## 社区资源

- **Lean Zulip**: https://leanprover.zulipchat.com/ （最活跃的社区，新人频道 #new members）
- **Lean 社区主页**: https://leanprover-community.github.io/
- **Lean 博客**: https://leanprover-community.github.io/blog/

## 工具

- **VS Code Lean 4 扩展**: 扩展市场搜索 "lean4"
- **lean4web**: 在线 Lean + Mathlib https://live.lean-lang.org/
- **doc-gen4**: mathlib 文档生成器（`lake -Kdoc=on build` 可为自己的项目生成同款文档）
