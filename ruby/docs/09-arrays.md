# 09 · 数组：索引、增删、排序与共享引用

> 对应示例：`examples/09_arrays/`

数组是 Ruby 最常用的容器，API 面广到可以按「家族」记忆：索引家族、增删家族、排序家族、集合运算家族、分组变换家族。这章的主线不是罗列 API，而是三处最容易流血的地方：**越界行为**、**排序稳定性**、**共享引用**。

## 9.1 字面量与 %w / %i

```ruby
[1, "二", :three, nil]   # 同一数组可混装任意类型
%w[红 绿 蓝]             # => ["红", "绿", "蓝"]   按空白切词成字符串数组
%w[a\ b c]               # => ["a b", "c"]         反斜杠转义空白
%i[x y z]                # => [:x, :y, :z]         切词成符号数组
%W[#{1 + 1}]             # 大写 W 支持插值
Array.new(3) { |i| i * 2 }  # => [0, 2, 4]
Array(nil)               # => []（Array() 把可枚举转数组，nil → []）
```

```text

---- 9.1 字面量与 %w / %i ----
%w[红 绿 蓝] = ["红", "绿", "蓝"]；%i 切出符号，%W 能插值
```

`%w`/`%i` 是「词组数组」的糖，但注意边界：**%w 里的引号是字面字符**——`%w["a"]` 切出来的是 `"\"a\""`，想要带引号的元素老老实实写普通数组。`Array()` 的 nil → [] 特性在处理「可能为 nil 的可选输入」时很省事。

## 9.2 索引家族与越界行为

```ruby
a = %w[甲 乙 丙 丁 戊]
a[0]        # => "甲"；a[-1] => "戊"
a[1, 2]     # => ["乙", "丙"]   [起点, 长度]
a[1..3]     # => ["乙", "丙", "丁"]  闭区间
a[1...3]    # => ["乙", "丙"]   半开区间，不含终点
a.at(2)     # => "丙"（只收单个索引）
a[99]       # => nil   越界静默
a.fetch(99) # => IndexError！响亮
a.fetch(99, "默认")  # => "默认"
a.first(2)  # => ["甲", "乙"]；last/take/drop 同族
```

```text

---- 9.2 索引家族与越界行为 ----
a[99] 是 nil（静默），a.fetch(99) 抛 IndexError（响亮）—— 拿错数据宁可早炸
```

`[]` 越界给 nil 与 `fetch` 越界抛 `IndexError` 的分野，是「防御性编程」在 Ruby 的具象：**数据结构必须含某元素时用 fetch，让错误在出生地炸掉**；nil 一路传播到千里之外的 `NoMethodError`，排查成本高一个数量级。

## 9.3 增删一族：头尾进出与按值/按位删除

```ruby
stack = [1, 2]
stack.push(3) << 4          # push 与 << 都是尾部追加；<< 只收一个、返回自身可链式
stack.pop                   # => 4   尾部弹出
stack.shift                 # => 1   头部弹出（O(n)，大数组慎用）
stack.unshift(0)            # 头部插入
[1, 2, 3].insert(1, :x, :y) # => [1, :x, :y, 2, 3]
[1, 2, 1, 3].delete(1)      # => 1   按值删：删掉所有 1，返回被删的值
[1, 2, 3].delete_at(1)      # => 2   按位删：只删那一格
[1, nil, 2, nil].compact    # => [1, 2]
[1, 1, 2, 2, 3].uniq        # => [1, 2, 3]（保第一个出现的位置）
[[1, [2, 3]], 4].flatten    # => [1, 2, 3, 4]
```

```text

---- 9.3 增删一族：头尾进出与按值/按位删除 ----
push/pop 是尾门，shift/unshift 是头门，delete 按值全删、delete_at 按位单删
```

两组易混对照：`delete`（按值、全删、返回值）vs `delete_at`（按位、单删、返回被删元素）；`push`/`<<` 尾门 O(1) vs `shift`/`unshift` 头门 O(n)。百万级数组上循环 shift，复杂度直接平方——队列场景见 9.8 的取舍。

## 9.4 排序：sort / sort_by / min_by / max_by

```ruby
[3, 1, 2].sort                          # => [1, 2, 3]
[3, 1, 2].sort { |x, y| y <=> x }       # => [3, 2, 1]  倒序只需交换 <=> 两边
%w[梨 苹果 无花果].sort_by(&:length)    # => ["梨", "苹果", "无花果"]
%w[pear apple fig].min_by(&:length)     # => "fig"
```

**稳定性注意**：Ruby 的 sort 不保证等值元素维持原相对顺序（CRuby 实现恰好稳定，但语言契约如此）。需要稳定排序时，把原始位置并进键里：

```ruby
pairs = [["b", 1], ["a", 2], ["b", 3]]
pairs.each_with_index.sort_by { |(k, _), i| [k, i] }.map(&:first)
# => [["a", 2], ["b", 1], ["b", 3]]
```

```text

---- 9.4 排序：sort / sort_by / min_by / max_by ----
sort 块靠 <=> 定序；sort_by 先算键再排；等值顺序没有语言保证，要稳定就补位置进键
```

`sort_by` 先对每个元素算一次键再排（Schwartzian 变换的内置化），键计算昂贵时远快于块内 `sort`。多键排序的数组字典序玩法在 11.8 展开。

## 9.5 集合运算：& | + - *

```ruby
a5 = [1, 2, 3, 3]; b5 = [2, 3, 4]
a5 & b5    # => [2, 3]            交集：去重，保左操作数顺序
a5 | b5    # => [1, 2, 3, 4]      并集：去重
a5 + b5    # => [1, 2, 3, 3, 2, 3, 4]  拼接：不去重
a5 - b5    # => [1]               差集
%w[a 2] * 2     # => ["a", "2", "a", "2"]  * 整数 = 重复拼接
[1, 2] * "-"    # => "1-2"                 * 字符串 = join
```

```text

---- 9.5 集合运算：& | + - * ----
& 求交 | 求并 - 求差（都去重），+ 拼接（不去重），* 重复或 join
```

`&`/`|`/`-` 都会去重且保左操作数的首次出现顺序，`+` 原样拼接。真把数组当集合用（大量成员判断、频繁交并差）时，换 10.8 的 `Set`——`include?` 数组是 O(n)，Set 是 O(1)。

## 9.6 分组与变换：处理数据的手筋

```ruby
[1, 2, 3, 4].partition(&:even?)   # => [[2, 4], [1, 3]]      一刀切两半
[1, 2, 3, 4, 5].group_by { |n| n % 3 }  # => {1=>[1,4], 2=>[2,5], 0=>[3]}
[["a", 1], ["b", 2]].zip([:x, :y])  # 拉链：逐位配对
[[1, 2, 3], %w[a b c]].transpose    # 行列互换
[1, 2, 3, 4, 5].each_slice(2).to_a  # => [[1,2],[3,4],[5]]   定长分片（尾片可短）
[1, 2, 3, 4].each_cons(2).to_a      # => [[1,2],[2,3],[3,4]] 滑动窗口（等长）
%w[张三 李四 王五].zip([90, 85, 77]).to_h  # => {"张三"=>90, ...}  zip+to_h 建映射
```

```text

---- 9.6 分组与变换：处理数据的手筋 ----
partition 二分、group_by 多分、zip 逐位配对、each_slice 切片、each_cons 滑窗
```

`partition` 永远返回两半（真/假两桶），`group_by` 按键值分任意多桶——「二分用 partition、多分用 group_by」别记反。`each_slice` 与 `each_cons` 只差一个词：切片**不重叠**、滑窗**重叠一位**，数据分析里一个是分批、一个是移动平均。

## 9.7 共享引用陷阱：object_id 说话（但不打印它）

数组变量存的是**引用**，不是副本：

```ruby
box = [1, 2]
outer = [box]               # 外层只存了 box 的引用
box << 3
outer                       # => [[1, 2, 3]] —— 改 box，outer 跟着变
outer.first.equal?(box)     # => true（equal? 比对象身份）

shared = Array.new(3, [])   # 三个格子指向同一个 []！
shared[0] << "x"
shared                      # => [["x"], ["x"], ["x"]]

fresh = Array.new(3) { [] } # 块形式：每个格子单独 new 一个 []
fresh[0] << "x"
fresh                       # => [["x"], [], []]
```

```text

---- 9.7 共享引用陷阱：object_id 说话（但不打印它） ----
Array.new(3, []) 三格同对象，Array.new(3) { [] } 三格独立 —— 默认值形态只求值一次
```

`Array.new(3, [])` 的 `[]` 只**求值一次**，三个格子共享同一对象——这是 Ruby 入门题里出镜率最高的坑。规则：**默认值是可变对象时，一律用块形式**。另外区分「换格子」与「改内容」：`shared[0] = []` 只是让第一格改指新对象，其他格子纹丝不动；原地把共享对象改了才是全员遭殃。

## 9.8 栈与队列：一个数组顶两个用

```ruby
# 栈（LIFO）：push / pop 都在尾部，O(1)
stack.push(:甲) << :乙 << :丙
stack.pop   # => :丙  后进先出

# 队列（FIFO）：push 进尾 + shift 出头；头门 O(n)，大流量换 Queue（20 章）
queue.shift # => :甲  先进先出
```

示例还演示了用栈消费嵌套结构（展平树）：

```ruby
work = [1, [2, [3, 4]], 5]
stack_gen = [work]; flat = []
until stack_gen.empty?
  item = stack_gen.pop
  item.is_a?(Array) ? stack_gen.concat(item) : flat << item
end
flat.sort   # => [1, 2, 3, 4, 5]
```

```text

---- 9.8 栈与队列：一个数组顶两个用 ----
栈 = push/pop（同端，O(1)）；队列 = push + shift；嵌套结构遍历就是「遇数组压栈」
```

方向纪律：栈的两端操作同在尾部（O(1)），队列的 shift 在头部（O(n)）——教学演示够用，生产高并发队列用 `Thread::Queue`。

## 9.9 坑位清单

1. **`%w` 里的引号是字面字符**：`%w["a"]` 带着引号切出来，不是 `["a"]`（9.1）。
2. **`[]` 越界静默给 nil，`fetch` 越界抛 IndexError**：必须有值的场合用 fetch，别让 nil 流窜（9.2）。
3. **`a[1,2]` 是「起点+长度」不是区间**：与 `a[1..3]` 的闭区间语义只差一个逗号（9.2）。
4. **`shift`/`unshift` 是 O(n)**：大数组循环 shift 平方级炸裂，队列换专用结构（9.3、9.8）。
5. **`delete` 按值全删且返回被删值**：想只删一处用 `delete_at`（9.3）。
6. **sort 等值顺序无语言保证**：CRuby 恰好稳定≠契约稳定，要稳定就把位置并进键（9.4）。
7. **`& | -` 去重、`+` 不去重**：以为 `+` 会去重的人写出隐藏重复数据的 bug（9.5）。
8. **`partition` 恒两半、`group_by` 任意多桶**：`group_by` 永远返回哈希，`partition` 永远返回二元数组（9.6）。
9. **`each_slice` 尾片可短、`each_cons` 等长**：分批处理尾批要特判（9.6）。
10. **`Array.new(3, [])` 三格同一对象**：可变默认值必须 `Array.new(3) { [] }`——默认值形态只求值一次（9.7）。
11. **改共享对象全员遭殃 vs 赋值换格子只动一格**：`a[0] = []` 安全，`a[0] << x` 危险，取决于对象是否共享（9.7）。
12. **`<<` 只收一个元素但可链式**（返回自身）：`a << 1, 2` 不是一次追加两个（9.3）。
