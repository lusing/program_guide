# 17 分离变量与 Turing 不稳定性

**对应书 §4.1（分离变量法：矩形/圆域；应用：Turing 不稳定性）。**

---

## 17.1 分离变量

热/波/Laplace 在矩形域上：设 u = X(x)Y(y)（+T(t)），PDE 拆成
ODE 特征值问题。零边值方域的特征对是双正弦

    φ_{mn} = sin(mπx)sin(nπy)，λ_{mn} = π²(m²+n²)，

解 = 初值系数 × e^{−λ_{mn}t}（热）/cos(√λ t)（波）。圆域则换成
**Bessel**：第一零点 λ₁ = 2.4048…（单位圆 Dirichlet 最慢模式）。

## 17.2 Turing 不稳定性（书 §4.1.2 的明星应用）

反应扩散系统 u_t = f(u,v) + d_uΔu、v_t = g(u,v) + d_vΔv。
**无扩散时稳定的均匀态**（Jacobian tr < 0、det > 0）在**扩散系数
悬殊**（d_v ≫ d_u）时可以被某个有限波数的模式 destabilize——
det(λI − J + k²D) 在中间 k 处变负。这是生物模式形成（斑纹、条
纹）的数学机制。

Julia 通道 `examples/julia/17_separation_turing.jl`：

- (a) 方域第一模式 e^{−2π²t} 衰减与谱选择（高模式衰减更快）；
- (b) 圆域 Bessel 零点 2.4048255577（10 位）与两域第一特征值对比；
- (c) **Schnakenberg 系统**：均匀态 (u*,v*) = (1, 0.9)；无扩散
  tr = −0.2 < 0、det = 1 > 0（稳定）；加扩散 (1, 40) 后 **k ≈ 0.19
  起失稳**，最不稳定波数 k* = 0.62（特征波长 2π/k* ≈ 10）——
  Turing 失稳的完整数值剖面：**扩散使稳定态失稳**，且选择有限
  波长（不是 k → ∞）。

## 17.3 要点回顾

1. 分离变量 = 特征函数展开；域几何决定特征对（矩形双正弦/圆域
   Bessel）。
2. Turing：无扩散稳定 + 扩散比悬殊 ⟹ 有限波数失稳 ⟹ 自发模式。
3. det(k) 的符号分析是判定工具（数值扫描给失稳窗口）。

*本章示例：`examples/julia/17_separation_turing.jl`。*
