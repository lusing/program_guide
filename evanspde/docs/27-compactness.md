# 27 紧性、Poincaré、差商与 Hardy

**对应书 §5.7（Rellich-Kondrachov 紧嵌入）与 §5.8（Poincaré 不等
式、差商、Hardy 不等式、Fourier 方法）。**

---

## 27.1 紧嵌入与三件工具

**Rellich-Kondrachov**：W^{1,p} ⊂⊂ L^q（q < p\*）——有界序列有
L^q 收敛子列。直觉：H¹ 有界压不住振荡（v_k = sin(kπx) 的导数爆），
紧性要求**导数也受控**。

**Poincaré**（零边值）：‖u‖_{L²} ≤ (1/√λ₁)‖∇u‖_{L²}，λ₁ 是第
一特征值（(0,1) 上 π²）——梯度控制函数本身。

**差商**（§5.8.2）：u ∈ W^{1,p} ⟺ 差商 D^h u = (u(·+h)−u(·))/h
的 L^p 范数对 h 一致有界——弱导数的有限差分刻画（正则性理论
29 章的主力工具）。

**Hardy**（§5.8.4）：∫u²/x² ≤ 4∫|u′|²（u(0) = 0）。

## 27.2 机器验证（Julia `27_compactness.jl`）

- (a) 紧性签名：u_k = sin(kπx)/k 的 H¹ 范数有界且 L² → 0（k = 20
  时 0.035）；对照 v_k = sin(kπx) 的 L² 恒 0.707、H¹ 爆炸——
  **预紧 vs 不紧**的成对样本；
- (b) Poincaré 常数：差分谱 λ₁^{(N)} = 2(1−cos πh)/h² 在 N =
  40/80/160 时 9.8648/9.8684/**9.8693** → π² = 9.8696（收敛签名）；
- (c) 差商刻画：x^{3/4}（W^{1,2}）的差商范数 1.45 有界；x^{1/4}
  （非 W^{1,2}）在 h = 10⁻³ 时已 5.2 且随 h → 0 爆——**成员资格
  的数值判据**；
- (d) Hardy：∫u²/x²/∫|u′|² = 2.0008 < 4（x·e^{−x} 样本；常数 4
  的最优性要取 1/|log| 型极值族，这里验证不等式本身）。

## 27.3 要点回顾

1. Rellich：能量有界 + 紧嵌入 = 弱解方法的收敛引擎（30 章起反复
   用）。
2. Poincaré 常数 = 第一特征值：能量控制函数值的谱来源。
3. 差商一致有界 ⟺ W^{1,p}——内部正则性的差商技术预热。
