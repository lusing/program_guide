# 29 弱解与 Lax-Milgram

**对应书 §6.1（椭圆性、弱解）与 §6.2.1（Lax-Milgram 定理）。**

---

## 29.1 从古典到弱

散度型 −Σ(a^{ij}u_{x_j})_{x_i} + … = f 的**弱解**：u ∈ H¹₀ 使

    B[u,v] = (f,v)　∀v ∈ H¹₀

其中 B 是双线性形式（系数的 L∞ 假设 + 一致椭圆性 θ|ξ|² ≤ aξ·ξ）。

**Lax-Milgram**：B 有界 + **强制** B[u,u] ≥ α‖u‖² ⟹ 变分问题
唯一可解且‖u‖ ≤ ‖f‖/α。比 Riesz 表示定理强（B 不必对称）——不对
称问题（对流项）也在覆盖范围。

## 29.2 机器验证（Julia `29_lax_milgram.jl`）

有限元离散上验证 Lax-Milgram 的结构：

- (a) 刚度矩阵谱：强制性 α = λ_min ~ 2/h（随网格缩小），有界性
  M = λ_max ~ 2N——条件数 O(N²)（离散化后常数恶化， preconditioning
  的动机）；
- (b) 解的 O(h²) 收敛：N = 16/32/64 误差 3.2×10⁻³ → 8.0×10⁻⁴ →
  2.0×10⁻⁴（精确四次比）；

> 坑账：初版把边界点 x = 1 当自由度——解右端不落零、误差退化
  O(h)。**自由度语义必须与 Dirichlet 边界一致**（差分/有限元装配
  的第一课）。另一坑：变系数装配漏掉贴边单元，条件数 2×10¹⁶ 的
  奇异签名当场暴露。

- (c) **Galerkin 正交性**：K u − b 的残差 2.5×10⁻¹⁶——变分方程在
  离散层面精确成立；
- (d) 变系数（跳变 a = 4|1，界面调和平均）：SPD 条件数 2.3×10⁴
  ——Lax-Milgram 的离散核。

Lean 侧：Lax-Milgram 的代数核即 Ch05 的 `rrEnergy_minimal`/
`rrEnergy_unique`（强制性 ⟹ 存在唯一）——有限维原型的完整证明已
经在那里。

## 29.3 要点回顾

1. 弱解 = 双线性形式的变分方程；椭圆性 + 有界系数 ⟹ 强制。
2. Lax-Milgram 是全部二阶椭圆存在唯一性的发动机（对称时退化为
   Riesz + 能量最小化）。
3. 有限元的自由度/边界纪律是数值面第一大坑。
