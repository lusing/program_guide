# 38 半群理论：Hille-Yosida

**对应书 §7.4（压缩半群、生成元、Hille-Yosida 定理、应用）。**

---

## 38.1 抽象框架

线性发展方程 u_t = Au 的解 = **半群** S(t) = e^{tA}。Hille-Yosida
定理：A 是压缩半群的生成元 ⟺ A **耗散**（⟨Au,u⟩ ≤ 0）且
(λ−A)⁻¹ 对 λ > 0 存在且压缩。三大实例：

| 半群 | S(t) | 范数 |
|---|---|---|
| 热 | e^{−tA} | ≤ 1（解析、强压缩） |
| 波 | cos(tA^{1/2}) 等 | = 1（酉**群**，可逆） |
| 传输 | g(·−tb) | = 1（等距群） |

## 38.2 机器验证（Julia `38_semigroups.jl`）

- (a) 半群律 S(t)S(s) = S(t+s) **逐位**；‖S(t)‖ ≤ 1（压缩）；
- (b) 生成元：(S(h)−I)/h → −A（数值微分 10⁻⁴ 还原 −π²）；
- (c) 耗散性：正谱 ⟹ ⟨Au,u⟩ = −λ‖u‖² ≤ 0；
- (d) 三大半群对照表（热压缩 vs 波/传输等距）；
- (e) 波生成元 [[0,1],[−π²,0]] 的特征**纯虚** ±iπ——谱在虚轴 ⟹
  群（不是耗散半群）。

## 38.3 第二部分收官
