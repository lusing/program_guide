## 00.1 偏微分方程是什么

一个**偏微分方程**（PDE）是一个含有两个及以上变量的未知函数及其
某些偏导数的方程。用书的记号：固定整数 k ≥ 1，U ⊂ ℝⁿ 为开集，
形如

    F(Dᵏu(x), Dᵏ⁻¹u(x), …, Du(x), u(x), x) = 0    (x ∈ U)

的等式称为 **k 阶偏微分方程**，其中 F 是给定的函数，u: U → ℝ 是
未知函数，Dᵏu 表示 u 的全部 k 阶偏导数（按**多重指标** α = (α₁,
…, αₙ) 编号，D^α u = ∂^{|α|}u/∂x₁^{α₁}⋯∂xₙ^{αₙ}，|α| = α₁+⋯+αₙ）。

**解 PDE** 意味着找出所有满足方程的 u——理想情形是简单的显式
解；退而求其次是推断解的**存在性与其他性质**。允许在 ∂U 的一部
分上附加**边值条件**（auxiliary boundary conditions）后再求解，
这就得到边值问题/初值问题。

### 分类的四个台阶

书 §1.1 按非线性出现在哪里把 PDE 分成四级（k 阶方程）：

| 类型 | 形式 | 非线性位置 |
|---|---|---|
| 线性 | Σ_{\|α\|≤k} a_α(x) D^α u = f(x) | 只在系数 a_α(x) 里 |
| 半线性 | Σ_{\|α\|=k} a_α(x) D^α u + a₀(D^{k−1}u, …, u, x) = 0 | 低阶项整体非线性 |
| 拟线性 | Σ_{\|α\|=k} a_α(D^{k−1}u, …, u, x) D^α u + a₀(…) = 0 | 最高阶系数依赖 u |
| 完全非线性 | F 对 Dᵏu 非线性 | 最高阶导数本身 |

**方程组**（system）则是 m 个未知函数 u = (u¹, …, uᵐ) 配 m 个
方程 F(…) = 0，F 取值于 ℝᵐ。分类用语对方程组逐条适用。

这个台阶不是学究式的：本书第二部分（线性理论，ch5–7）对线性方程
给出相当统一的存在-唯一-正则性框架；而第三部分（非线性，ch8–12）
必须对不同位置的非线性用完全不同的武器——变分法（ch8）、不动点
（ch9）、粘性解（ch10）、Riemann 问题（ch11）、能量与临界指数
（ch12）。

## 00.2 为什么没有普遍理论

书 §1.2 开宗明义：

> There is no general theory known concerning the solvability of all
> partial differential equations. Such a theory is extremely unlikely
> to exist…

PDE 建模的范围横跨物理、几何、概率，现象的丰富性使得"一个定理
解决所有方程"的希望渺茫。研究因此聚焦于**个别重要方程**——从它们
的来源（物理、几何、概率）获取解的结构线索。书随后列出约 25 个
"名方程"：从 Laplace、热、波、Schrödinger、KdV、Navier–Stokes
到调和映射。本教程 Prolog 通道把这份清单做成了可查询的数据库
（`examples/prolog/00_intro.pl`）：

```prolog
pde(laplace,          linear, 2, scalar, 'elliptic: sum u_ij = 0').
pde(transport,        linear, 1, scalar, 'first-order: u_t + b.Du = 0').
pde(eikonal,          fully_nonlinear, 1, scalar, '|Du| = q(x,u): ...').
pde(burgers,          quasilinear, 1, scalar, 'u_t + u u_x = 0: shocks').
pde(navier_stokes,    semilinear, 2, system, 'viscous fluid').
```

字段是（名字，分类台阶，阶数，标量/组，一句话主部）。main 里做
**分类一致性审计**——每条方程恰有一个 kind——并按类统计：

    linear 15 / semilinear 4 / quasilinear 4 / fully nonlinear 2

一阶标量方程（transport、liouville、eikonal、burgers）恰好就是
第 3 章特征线方法的全部主角——数据库查询直接给出学习路线图。

## 00.3 序言的三大主题

Evans 在序言里写给读者的三句话，是全书方法论的纲领：

1. **广义解（generalized solutions）是根本。** 许多 PDE（尤其非
   线性一阶方程）根本没有光滑解，必须设计某种"弱解"或"广义解"
   的概念。这是微妙而困难的事业，书中一些最难的定理（ch3 弱解唯
   一性、ch10 粘性解、ch11 熵条件）都在回答"什么才算解"。
2. **先验估计（a priori estimates）是主要技术。** 在不知道解是否
   存在的情况下，先"假设解存在"去推导它必须满足的能量不等式；
   估计式本身就是构造解与理解解的钥匙。
3. **没有免费午餐。** 不存在普遍理论；不同来源的方程要用不同的
   方法，来源本身（物理/几何/概率直觉）是方法选择的向导。

本教程给这三句话各配一条机器验证的注脚：

- 对（1）：03 章起我们将反复看到"光滑解的公式在弱意义下仍然成
  立"，并在 Lean 里证明弱解概念的**代数核**（叠加原理）；
- 对（2）：05 章起每个"能量估计"都配数值实验：能量单调性曲线 +
  断言，估计常数逐位对账；
- 对（3）：00.4 的动物园里六个方程六种结构，任何"通用算法"都会
  在其中至少两个上碰壁。

## 00.4 制造解对表：方法论演示

本教程的基本验证手法是**制造解对表**（manufactured solutions）：
对每个方程显式写下一个解，把它代回方程计算**残差**，断言残差在
机器精度（解析导数）或截断误差（数值导数）量级。残差不归零就说明
"解"或推导错了——机器立刻抓出。

Julia 通道 `examples/julia/00_intro.jl` 对书 §1.2 清单的六个代表
方程做了一遍。逐段看：

**Laplace 方程**（椭圆原型）：u = x² − y² 是调和的，因为
∂ₓₓu = 2、∂_yy u = −2。数值上用五点中心差分验证——对二次多项式
中心差分是精确的：

```julia
lap5(u, x, y, h) = (u(x+h,y) + u(x-h,y) + u(x,y+h) + u(x,y-h) - 4u(x,y)) / h^2
u1(x, y) = x^2 - y^2
r1 = abs(lap5(u1, 0.3, 0.7, 1e-3))
```

实测 |Δ_h u| = 2.2×10⁻¹⁰（纯舍入，无截断项——多项式二次使差分
恒等）。断言 `< 1e-9` 通过。

**热方程**（抛物原型）：热核 G(x,t) = (4πt)^{−1/2} e^{−x²/4t}。
解析导数硬编码后相消：

```julia
# G_t = G * (-1/(2t) + x^2/(4t^2))，G_xx = G * (x^2/(4t^2) - 1/(2t))
r2 = abs(G(x0,t0)*(-1/(2t0) + x0^2/(4t0^2)) - G(x0,t0)*(x0^2/(4t0^2) - 1/(2t0)))
```

两个括号**逐项相同**，残差 = 0.00e+00。这不是巧合：G_t = G_xx
就是热核的定义性质，解析式的恒等性在浮点里逐位兑现。热核是 06
章的主角（它是热方程的基本解）。

**波方程**（双曲原型）：u = sin(x−t) + cos(2(x+t))。数值二阶差分
（h = τ = 10⁻⁴）给出 |u_tt − u_xx| = 0（差分相消恰好精确——两个
方向差分对同一函数形状求值）。sin(x−t) 是**右行波**：x 方向与 t
方向的二阶导数同号相消；cos(2(x+t)) 是左行波，倍频加倍。

**传输方程**（一阶线性原型）：u = e^{−(x−t)²}，u_t + u_x = 0。
残差逐位为零——u 沿特征线 x − t = const 平移不变。02 章将证明
这是**全部**解。

**Eikonal 方程**（一阶完全非线性原型）：|Du| = 1 的解 u = |x|
（到原点的距离函数），梯度模长 1。它不光滑（原点处），第一次预演
"广义解"主题：非线性一阶方程的光滑解一般只在局部存在（ch3 的
特征线理论），距离函数是全局解但带角点。

**Burgers 方程（粘性行波）**：u_t + u u_x = ν u_xx 的行波解
u = 2 − 2 tanh(x − 2t)（参数 a = c = 2, ν = 1 的通式
u = c − a tanh(a(x−ct)/(2ν))）。链式法则逐项算出：

```julia
ut  = 4 * sech2        # u_t  = (a²c/2ν) sech²(s)
ux  = -2 * sech2       # u_x
uxx = 4 * sech2 * tanh(s)
r6 = abs(ut + u6(0.3, 0.7) * ux - uxx)
```

残差 2.2×10⁻¹⁶（机器精度）。注意 u u_x 里的 u 本身出现在残差
里——拟线性的"系数依赖 u"第一次现身。这条行波在 15 章是激波的
粘性剖面。

**叠加原理**（线性性的报酬）：热核平移叠加 w = G(x−1,t) +
3G(x+2,t) 仍是热方程解，残差 0——因为方程线性，两个解的任何线
性组合都是解。Lean 通道把这个"显然"证成定理。

## 00.5 Lean：叠加原理的完整机器证明

线性性的核心是：**齐次方程解的线性组合仍是解**。书中一句话的事，
Lean 里要用两层导数表述并完整证明（`examples/lean/Evanspde/
Ch00Intro.lean`）。算子取谐算子样本 L u = u″ + u：

```lean
theorem superposition {u u' u'' v v' v'' : ℝ → ℝ} (a b : ℝ)
    (hu1 : ∀ x, HasDerivAt u (u' x) x) (hu2 : ∀ x, HasDerivAt u' (u'' x) x)
    (hv1 : ∀ x, HasDerivAt v (v' x) x) (hv2 : ∀ x, HasDerivAt v' (v'' x) x)
    (hEu : ∀ x, u'' x + u x = 0) (hEv : ∀ x, v'' x + v x = 0) (x : ℝ) :
    deriv (deriv (fun y => a * u y + b * v y) x) x + (a * u x + b * v x) = 0 := by
```

假设的形式值得停一秒：`(hu1, hu2)` 说的是"u 的导函数是 u′，u′
的导函数是 u″"——这就是 Lean 里"二阶导数存在"的写法（不需要引
入二次可微的类型类）。证明分三步：

1. **一阶**：`HasDerivAt (a•u + b•v) (a•u′ + b•v′)`——由
   `.const_mul` 与 `.add` 逐项组合；
2. **换名**：`funext` + `HasDerivAt.deriv` 把"导函数等于…"固
   化为函数等式 `deriv (a•u+b•v) = a•u′+b•v′`；
3. **二阶**：对导函数再做一次同样的事，得 `deriv (deriv (a•u+b•v))
   x = a•u″(x) + b•v″(x)`，代入 hEu、hEv 相消。

最后落到具体函数：2cos + 3sin 是解，因为 cos 的两层导数链
cos → −sin → −cos 与 sin 的链 sin → cos → −sin 各自闭合：

```lean
example (x : ℝ) :
    deriv (deriv (fun y => 2 * cos y + 3 * sin y) x) x + (2 * cos x + 3 * sin x) = 0 := by
  refine superposition (a := 2) (b := 3)
    (u := fun y => cos y) (u' := fun y => -sin y) (u'' := fun y => -cos y) ...
```

这就是全书的"代数核"风格：**把书中证明里非数值的那一半交给
Lean，数值的那一半交给 Julia/Python，规则/分类的那一半交给
Prolog**。三路对表，谁也糊弄不了谁。

## 00.6 全书地图

按书的三个部分（本教程章号）：

- **第一部分：解的表示公式**（ch1–4 → 01–23 章）：传输方程特征
  线；Laplace/热/波四大方程的基本解、平均值公式、Green 函数、能
  量方法；非线性一阶（特征线、Hamilton–Jacobi、守恒律）；表示
  技巧大杂烩（分离变量、相似解、变换法、渐近、幂级数）。
- **第二部分：线性理论**（ch5–7 → 24–38 章）：Sobolev 空间；
  二阶椭圆（Lax–Milgram、正则性、极值原理、特征值）；线性发展
  方程（抛物、双曲、对称双曲组、半群）。
- **第三部分：非线性理论**（ch8–12 → 39–50 章）：变分法（直接
  方法、山路定理、Noether）；非变分技巧（单调性、不动点、上下解、
  梯度流）；粘性解；守恒律组；非线性波。

51 章收束全书。每章开头给"对应书 §x.y"锚，但讲解完全自包含——
不需要翻原书。

## 00.7 要点回顾

1. PDE 按"非线性出现在哪"分四级：线性 / 半线性 / 拟线性 / 完全
   非线性——这个台阶预告了全书方法的分裂（统一线性理论 vs 五花
   八门的非线性武器）。
2. 没有普遍理论（Hadamard 之后更没有）：研究对象是从物理/几何/
   概率来的名方程，来源即线索。
3. 三大主题：广义解、先验估计、无免费午餐。
4. 制造解对表：显式解 + 残差 = 机器验证的最小闭环；解析导数对出
   机器零，数值差分对出截断阶。
5. 叠加原理 = 线性性的全部报酬，Lean 完整证明。
