# 45 粘性解：定义、一致性与唯一性

**对应书 §10.1-10.2（粘性解定义、一致性、比较原理与唯一性）。**

粘性解：在局部极值点验子微分不等式（上解 ≤、下解 ≥）——不可微
处用"测试函数从一侧触碰"。Julia（`45_viscosity.jl`）：尖点初值
−|x| 的 Hopf-Lax 粘性值 −t/2 与尖点处粘性判据**等式成立**；光滑区
域与经典解一致（残差 10⁻¹²，一致性定理的数值面）；比较原理
（初值单调 ⟹ 解单调）与唯一性推论。

要点：粘性解 = 弱解概念在 HJ 方程的正确版本；比较原理 ⟹ 唯一性。

*本章示例：`examples/julia/45_viscosity.jl`。*
