# 22 渐近方法：奇异摄动、Laplace 方法、驻相与均匀化

**对应书 §4.5（§4.5.1 奇异摄动、§4.5.2 Laplace 方法、§4.5.3
几何光学/驻相、§4.5.4 均匀化）。**

---

## 22.1 四种渐近

1. **奇异摄动**：εu″ + u′ = 0 的边界层——外解满足降阶方程，边
   界附近宽 O(ε) 的层补足边值；
2. **Laplace 方法**：I(λ) = ∫e^{λf} 集中于极大点，I ~ e^{λf(a)}
   √(2π/(−λf″(a)))；
3. **驻相**：I(k) = ∫e^{ikφ} 由驻点 φ′ = 0 主导，贡献带相位
   e^{iπ sgn(φ″)/4}——几何光学的波前构造；
4. **均匀化**：周期系数 a(x/ε) 的解当 ε → 0 收敛到常系数（有效
   介质）的解；1D 有效系数 = **调和平均**。

## 22.2 机器验证（Julia `22_asymptotics.jl`）

- (a) 边界层：精确解 (e^{−x/ε}−e^{−1/ε})/(1−e^{−1/ε})，半点值
  在 x = ε ln2（偏差由末端项 e^{−1/ε} 定标——ε 大时不可忽略，
  容差带它）；
- (b) Laplace 方法：λ = 50/200/800 的比值 → 1（首项修正 O(1/λ)）；
- (c) 驻相：|I(k)| / √(2π/k) 从 0.84（k=50）→ 0.945（k=800）——
  **端点贡献 O(1/k) 的干涉**使收敛非单调，断言用"比值随 k 上升"
  的签名；

> 坑账（数学）：均匀化闭式初版写 1/√(a0²−a1²)——那是 ⟨1/a⟩，
> 有效系数 a\* 是它的**倒数** √(a0²−a1²)。数值调和平均 1.41421
> = √2 当场指出套错倒数。

- (d) 均匀化：a\* = √(2) 九位对账。

## 22.3 要点回顾

1. 奇异摄动 = 外解 + 边界层；层宽 O(ε)，剖面 e^{−x/ε}。
2. Laplace（实指数）与驻相（振荡）是平行的鞍点技术，首项 + 修正
   阶要按理论断言。
3. 1D 均匀化：有效系数 = 调和平均；闭式的倒数方向是常见笔误。
