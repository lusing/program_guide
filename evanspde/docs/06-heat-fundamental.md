# 06 热方程 I：基本解、卷积解与 Duhamel

**对应书 §2.3.1（伸缩不变性导出热核、归一性引理、初值问题卷积解、
非齐次 Duhamel 公式）。**

---

## 06.1 伸缩不变性 → 热核

热方程 u_t − Δu = 0 的一个先验观察：u 解 ⟹ (x,t) ↦ λ²u(λx, λ²t)
解——**比值 r = |x|/√t 无量纲**。找伸缩不变解 u(x,t) = t^{−α}w(|x|/
t^β)，配平 β = 1/2 后化为径向 ODE（书式 (6)）：(w′r)′ 型方程解出
Gauss 形 w = ae^{−r²/4}。规范化常数由**归一性引理**（∫Φdx = 1）定死：

    **Φ(x,t) = (4πt)^{−n/2} e^{−|x|²/4t}**    (x ∈ ℝⁿ, t > 0)。

它是热方程的**基本解**（−分布意义 Φ_t − ΔΦ = δ₀ 于 t = 0）。

## 06.2 初值问题与卷积解

u_t − Δu = 0、u(·,0) = g 的解是**卷积**

    u(x,t) = ∫ Φ(x−y,t) g(y) dy，

热核在 t → 0⁺ 时逼近恒等算子（δ 族）。Julia 通道
`examples/julia/06_heat_fundamental.jl` 四段实验：

**(a) 归一性与标度律**：截断 Simpson + erf 闭式尾段，t = 0.1/1/5
的积分全部 = 1（1e-10）；标度律 Φ(λx, λ²t) = λ^{-1}Φ(x,t) 十五位。

**(b) 阶梯初值的磨光**：g = 1_{y<0} 的解是 ½erfc(x/2√t)——间断
**瞬时**磨成误差函数坡。数值卷积与闭式对到 1e-8；t → 0 时中心值
→ ½（间断点的半点值，热核逼近恒等的分配行为）。

> **坑账两笔（本章最值钱）**：①被积函数在跳点处的 Simpson 端点值
> 歧义——左段端点必须取**左极限**（g(0) 的右值 0 会留下恰好
> h/3·Φ(0) ≈ 2×10⁻³ 的缺口，被闭式对账精确锁定）；②Duhamel 内层
> 卷积的截断**必须包含核峰 x**——以 0 为中心的对称截断在 τ 小时
> 把核的右尾砍掉，τ = 0.005 时误差 1.3×10⁻²（诊断脚本逐 τ 打印
> 定位），改为 L = |x| + 10√τ 后 Duhamel 对账 1×10⁻¹²。

**(c) 无穷传播速度**：紧支初值（|y|<1 的帐篷），t = 0.01 时
u(5, 0.01) = 8×10⁻¹⁷⁷ > 0——热方程的解在**任意远处在任意小时刻**
都严格正（Gauss 尾巴永不为零）。与波方程的有限传播（10 章）对照，
这是抛物与双曲的分水岭。

**(d) Duhamel**：非齐次 u_t − Δu = f 的解

    u = ∫₀ᵗ ∫ Φ(x−y, t−s) f(y,s) dy ds + 卷积初值项。

制造解对账：f = sin x 的解 (1−e^{−t})sin x，双重 Simpson 数值与闭
式差 1e-12（τ→0 端点显式取极限 f(x) 避免 0^{-1/2} NaN）。

## 06.3 Fortran 与 Lean

**Fortran**（`06_heat_kernel.f90`）：指示初值 {|y|<1} 的闭式解
u(x,t) = ½[erf((x+1)/2√t) − erf((x−1)/2√t)]，三段常值 Simpson
（跳点为段端点、每段 g 取常值——无端点歧义）。断言三组：中心值
闭式 1e-14、质量守恒 ∫u = 2（截断 [-10,10] 后 6e-8）、核峰衰减律
Φ(0,4t)/Φ(0,t) = ½ 精确。

> **坑账（数学断言错）**：初版断言"卷积解中心值比 = ½"——错！
> t^{−1/2} 衰减的是**核峰**；卷积解中心 u(0,t) = erf(1/2√t)，
> 大 t 渐近 u·√(πt) → 1（质量扩散稀释）。数值 0.5309 ≠ 0.5 当场
> 推翻断言，改为核律 + 渐近律两条（后者 t = 64 时 0.9987 → 1）。
> **断言要区分对象：核 vs 解。**

**Lean**（`Ch06HeatFundamental.lean`）：**分离变量解**的完整证明
——u = e^{−k²t}sin(kx) 满足 u_t − u_xx = 0 对一切波数 k。t 方向
exp 链一层、x 方向正弦二层链（Ch01 成熟模式）。热核作为 Fourier
分量的叠加（Ch00 叠加原理 + 逐项取极限），其"是解"的核由每个分
量承载。

> **Lean 坑账（Ch06 战果）**：①`hasDerivAt_const` 参数序是
> **（点, 常数值）**——反着写不报错但语义全错（第一次就抓）；
> ②组合子产出值自带 `0*t + …`、`… * 0` 形状，**声明直接采用产出
> 形状**（`_raw` 定理），整洁式放最终定理 `rw + ring`——不与
> elaborator 争辩；③嵌套 `HasDerivAt.mul/add` 的独立 `have` 声明
> 过不了 defeq 检查（Pi-实例不展开），**整链内联直给** `.deriv`
> 则无碍；④**mathlib 无裸标识符 `pi`**——只有 `π` 记号（`Real.pi`），
> 写 `pi` 会变成自由变量、定理悄悄变成对任意 pi 的命题（Ch07 抓
> 出，全局替换 π 修复）。

## 06.4 要点回顾

1. 伸缩不变性（|x|/√t 无量纲）→ 径向 ODE → Gauss 热核；归一常数
   定死分布强度。
2. 卷积解 = 热半群作用于初值；阶梯 → erfc 坡（瞬时磨光）；热核逼
   近恒等（半点值）。
3. 无穷传播：紧支初值的解即刻全场为正——抛物特征。
4. Duhamel 双重积分，τ→0 端点取极限 f(x)；卷积截断包含核峰。
5. 分离变量解 u = e^{−k²t}sin kx 是热核的 Fourier 分量，Lean 完
   整证明。
