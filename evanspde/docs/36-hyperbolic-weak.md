# 36 双曲方程弱解：Galerkin 与能量

**对应书 §7.2.1–§7.2.3（弱解、Galerkin 构造、能量守恒、正则性）。**

---

## 36.1 双曲的 Galerkin

与抛物平行的三步，但模式方程是**振子** c̈_k + λ_k c_k = f_k：

- 弱解：u ∈ L^∞(0,T;H¹₀)、u_t ∈ L^∞(0,T;L²)；
- **能量守恒** E(t) = ½‖u_t‖² + ½‖∇u‖² = const（代替抛物的衰减）；
- 正则性门槛：g ∈ H¹、h ∈ L²——比抛物高（没有免费光滑化）。

## 36.2 机器验证（Julia `36_hyperbolic_weak.jl`）

- (a) 模式振子的 **velocity-Verlet**（辛积分）vs cos(πt)（10⁻⁵）；
- (b) 能量守恒：E = π²/2 于三个时刻**12 位不变**（动能势能互换）；
- (c) 两模式叠加的能量**可加性**（正交模式无交叉项，逐位）；
- (d) 正则性门槛：系数 1/k 的初速度 L² 收敛（Σ1/k²），平坦系数
  发散（δ ∉ L²）——h ∈ L² 条件的谱面。

## 36.3 要点回顾

1. 振子 vs 衰减：双曲/抛物 Galerkin 的全部差别在模式 ODE。
2. 能量守恒（等距）vs 能量耗散（压缩）。
3. 弱解正则性保持初始数据的正则性（无光滑化）。
