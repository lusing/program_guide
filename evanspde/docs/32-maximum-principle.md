# 32 极值原理与 Harnack 不等式

**对应书 §6.4（弱极值原理、强极值原理与 Hopf 引理、Harnack）。**

---

## 32.1 三个层次的极值原理

1. **弱**：Lu ≤ 0（c ≡ 0）⟹ max_Ū u ≤ max_{∂U} u（比较原理）；
2. **强**：连通域上内部取到最大值 ⟹ u 常数（Hopf 传播论证，04
   章平均值版在椭圆算子上的推广）；
3. **Hopf 引理**：边界最大值点的外法向导数 ∂u/∂ν > 0 严格。

推论串：唯一性（两次）→ 比较原理 → 先验界。**Harnack**：非负调
和函数 sup_{B_r} ≤ C(r)inf_{B_r}——震荡控制，椭圆方程的刚性。

## 32.2 机器验证（Julia `32_maximum_principle.jl`）

用分离变量造的精确调和函数 u = sinπx·sinhπ(1−y)/sinhπ（单位方、
上边 1 其余 0）：

- (a) 调和性数值核对（sinh 放大截断，容差按理论定标）；内部采样
  最大 0.729 < 1 = 边界最大；
- (b) 强极值原理：中心值严格小于 1（非常数解不能在内部达最大）；
- (c) **Hopf 引理**：最大边界点 (½, 0) 的 ∂u/∂y = −3.15 严格
  （外法向 −y ⟹ 法向导数严格符号）；
- (d) **Harnack**：正调和 u = eˣsin y 于圆 B(0, π/2)，r = 0.3/0.6
  的 sup/inf = 1.82/3.32 ≤ (1+r)/(1−r) = 1.86/4.00——二维 Harnack
  常数的数值检验。

## 32.3 要点回顾

1. 弱/强/Hopf 三级递进：界的存在、常数的刚性、法向的严格性。
2. 比较原理是上下解方法（44 章）的根基。
3. Harnack：非负解的震荡被常数控制——紧性论证的关键输入。
