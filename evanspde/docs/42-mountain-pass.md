# 42 山路定理与 Noether 定理

**对应书 §8.5（山路定理、半线性应用）与 §8.6（不变变分问题、
Noether）。**

**山路定理**：0 局部极小 + 存在 e 使 I(e) < I(0) ⟹ 山路水平
c = inf_{paths} max I 是临界值——极小化找不到的解由拓扑（min-max）
找出。Julia（`42_mountain_pass.jl`）：I(a) = a²(π²−15)/4 + (3/32)a⁴
的地形表（0 局部极小、I(1) < 0、I(4) > 0）、山路水平 c ≈ 3.48、
临界振幅 a* = 2.6154（dI/da = 0 逐位）。

**Noether**：连续对称 ⟺ 守恒律。时间平移 ⟹ 能量（38 章）、空间
平移 ⟹ 动量 P = ∫u_tu_x（行波样本恒 −½）。

要点：min-max 把变分法从"找谷底"扩展到"找山口"；对称性是守恒律
的生成器。

*本章示例：`examples/julia/42_mountain_pass.jl`。*
