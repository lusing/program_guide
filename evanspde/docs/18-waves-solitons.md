# 18 行波、孤子与相似解

**对应书 §4.2（平面波/行波/孤子；伸缩相似解）。**

---

## 18.1 行波与孤子

KdV 方程 u_t + u u_x + u_{xxx} = 0 的**孤子**

    u = 3c·sech²(√c(x−ct)/2)

——振幅 3c 与速度 c **绑定**：高的跑得快，这是碰撞现象的根源。
**双孤子**由 Hirota 双线性式给出：u = 12∂²ₓlog F，

    F = 1 + e^{η₁} + e^{η₂} + A e^{η₁+η₂}，ηᵢ = 2kᵢ(x − 4kᵢ²t − xᵢ)，
    A = ((k₁−k₂)/(k₁+k₂))²。

碰撞后两孤子保持形状、只带**相移**——非线性方程的"粒子式"行为。

## 18.2 相似解：Barenblatt

多孔介质方程 u_t = (u²)_{xx} 的 Barenblatt 解

    u = t^{−1/3}(1 − |y|²/12)₊，y = x t^{−1/3}

——**紧支**、支撑按 t^{1/3} 外扩（有限传播，对比热方程的 √t 无
穷传播）、质量精确守恒。

## 18.3 机器验证（Julia `18_waves_solitons.jl`）

- (a) 单孤子 PDE 残差 1.7×10⁻⁴（三阶差分精度）；
- (b) 双孤子：分离区（t = −2）残差 ~2×10⁻²、快孤子峰高 48.00
  = 12k₁² 精确；

> **坑账（三连击，本章精华）**：Hirota 式对应**系数 6** 的 KdV——
> ①ηᵢ 前因子是 2kᵢ（不是 kᵢ）；②孤子速度 4kᵢ²（不是 kᵢ²）；
> ③换算到系数 1 版本要 u = 12∂²ₓlogF（不是 2）。三处系数初版全
> 错，峰值对账（期望 48/12 实测 12/4.3）逐步翻案。另外**差分套
> 差分**（数值 ∂²ₓlogF 再做三阶数值差分）噪声放大 10⁴ 倍——必须
> 把 ∂²ₓlogF 写成闭式 (F″F−F′²)/F² 再差分。双孤子有**相移**，
> 峰位/峰高断言只能在渐近分离区做。

- (c) Barenblatt：质量 t = 1 与 t = 8 **八位一致**；支撑 √12·t^{1/3}
  外扩律。

## 18.4 要点回顾

1. 孤子 = 非线性 + 色散的平衡；振幅-速度绑定 ⟹ 碰撞 + 相移。
2. Hirota 双线性式是显式 N 孤子的生成器；系数纪律：前因子、速
   度、幅值三处。
3. Barenblatt：紧支、有限速度、质量守恒——退化抛物的标度律。
