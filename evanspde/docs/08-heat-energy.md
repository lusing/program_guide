# 08 热方程 III：能量方法

**对应书 §2.3.4（能量方法：唯一性、能量不等式、衰减估计）。**

---

## 08.1 唯一性与能量不等式

书 §2.3.4 的能量法（与 §2.2.5 平行）：设 u 是 u_t − Δu = 0 于
U_T = U×(0,T]、零边值的解，分部积分（对时间求导 + 空间分部）：

    d/dt (½∫_U u² dx) = −∫_U |∇u|² dx ≤ 0。

于是 e(t) := ½∫u² 单调不增；两个同初值的解之差满足零初值 +
能量不等式 ⟹ e(t) ≡ 0 ⟹ w ≡ 0——**唯一性**。加上 Poincaré
（‖v‖ ≤ C_p‖∇v‖，零边值） Gronwall 化：

    **e(t) ≤ e(0)·e^{−2t/C_p²}**——指数衰减。

区间 (0,1) 上 C_p = 1/π，衰减率 2π²。

## 08.2 谱版数值实验

Julia 通道 `examples/julia/08_heat_energy.jl`：初值 g = x(1−x) +
0.3sin(3πx) 的 40 模式谱展开（系数中点求积）：

- **能量恒等式**：dE/dt 与 −∫|∇u|² 在谱表示下逐位相同（都是
  −Σλₖbₖ²/2·e^{−2λₖt}）；
- **衰减估计**：e(t) ≤ e(0)e^{−2π²t} 全程成立，且比值恒 0.4099
  ——g 在第一模式的投影决定渐近速度，其余模式衰减更快（谱间隙
  π²(4−1) = 3π² 的可视化）；
- **长时渐近**：e(3)·e^{2π²·3} = 0.01664258 = b₁²/4 **十二位精
  确**——高模式死光后能量完全由第一模式承载；
- **收缩性**：两组初值的解差能量 ≤ 初值差能量（半群是 L² 收缩
  的谱体现：每个模式乘 e^{−λt} ≤ 1）。

## 08.3 三章一体的能量观

05（椭圆：能量极小化）、07（模式：能量恒等式闭式）、08（抛物：
能量单调 + 衰减）构成能量方法三部曲。它们的 Lean 承载分别是配
方法恒等式（Ch05）、单模式能量恒等式（Ch07）、以及这里直接复用
两条——衰减估计的核 `e^{−2λ₁t}·e(0)` 与 Gronwall 的代数结构将在
34 章（抛物弱解）以完整形式重现。

## 08.4 要点回顾

1. d/dt·½∫u² = −∫|∇u|²：解的时间行为由梯度控制——弱解能量估
   计的原型。
2. 唯一性 = 能量不等式 + 零初值；衰减 = 能量不等式 + Poincaré
   + Gronwall。
3. 谱视角：衰减率 = 2λ₁，长时行为由第一模式主导（数值 12 位）。
