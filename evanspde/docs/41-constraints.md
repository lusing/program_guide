# 41 极小正则性与约束问题

**对应书 §8.3（二阶导估计、高正则性）与 §8.4（非线性特征值、
单边约束/变分不等式、调和映射、不可压缩）。**

- **正则性**：变分极小的正则性（p-拉普拉斯的退化样本 u′ ~
  (1−x)^{1/3} ⟹ u″ ∉ L^∞）；
- **非线性特征值**：−Δu = λuᵖ 的分支 λ(a) ~ a^{−2}；
- **单边约束**：障碍问题 u ≥ ψ 的**变分不等式**（互补系统）。

Julia（`41_constraints.jl`）：p=3 拉普拉斯制造解（符号坑账：u′ 取
正支才满足 −(|u′|²u′)′ = 1）；分支曲线；障碍问题的投影 GS——接触
集 23/200、自由区互补残差 10⁻³。

要点：极小自动获得正则性（退化方程打折）；约束 ⟹ 变分不等式
（32 章 pdenum 障碍问题的理论侧）。

*本章示例：`examples/julia/41_constraints.jl`。*
