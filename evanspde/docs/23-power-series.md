## 23.1 CK 定理

**Cauchy-Kovalevskaya**：解析系数、解析 Cauchy 数据、初始面**非
特征** ⟹ 解析解**局部存在唯一**。这是 PDE 里**唯一的一般存在
定理**——代价是解析性（刚性）与局部性。

**非特征条件**：初始面的法向 ν 满足主部条件 F_{k 阶}(ν) ≠ 0。
特征面上数据不能任意给（波的 Cauchy 数据给在 x±t = const 上过定）。

**收敛域**：由到最近奇异的"特征距离"决定——u = 1/(1−x−t) 的级
数收敛域 |x|+|t| < 1，奇异沿特征 x+t = 1 传播。

## 23.2 机器验证（Julia `23_power_series.jl`）

- (a) 双重几何级数 ΣC(m+n,m)xᵐtⁿ 收敛到 1/(1−x−t)（域内 10⁻⁹），
  域外部分和 1.4×10³ 发散签名；
- (b) 非特征 Cauchy：u_x = u、u(0,t) = e^t 的级数递推
  a_{m+1,n} = a_{mn}/(m+1) 收敛到 e^{x+t}（10⁻⁸）；
- (c) 分离级数 cos·cos 的 Taylor 截断（波方程解析解）；特征面
  y = x 上数据过定的结构说明（递推退化）；
- (d) 奇异传播：收敛域边界 = 奇异特征的位置。
