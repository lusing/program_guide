# 33 椭圆特征值

**对应书 §6.5（对称算子的谱：Rayleigh-Ritz、min-max、离散性；
非对称算子的主特征值）。**

---

## 33.1 谱理论

对称椭圆算子 L 的特征值问题 Lu = λu：

    0 = λ₁ < λ₂ ≤ …（离散谱 → ∞），
    λ₁ = min Rayleigh 商 R[u] = B[u,u]/(u,u)（正交约束下 min-max
    逐个刻画）。

特征函数构成正交基（紧凑自伴算子谱定理，Fredholm 二择一的续篇）。
**非对称**算子（对流项）：对称化变换后谱实且 λ_k = (kπ)² + b²/4
——主特征值（Krein-Rutman，最大实部、单重、正特征函数）。

## 33.2 机器验证（Julia `33_eigenvalues.jl`）

- (a) Rayleigh-Ritz：差分谱 λ₁ → π²（40/80 网格）；第二模式的
  Rayleigh 商 = λ₂ > λ₁（正交约束抬高最小值）；
- (b) 显式谱 (kπ)² 与间距 3π²；
- (c) 离散谱（N = 100 三对角）前三个特征值 vs π²/4π²/9π²；
- (d) **非对称**：−u″ + 1.5u′ 的数值主特征值 10.4318 vs 理论
  π² + b²/4 = 10.4321（对称化偏移的三位对账）；
- (e) Weyl 律（1D 精确）：N(λ) = ⌊√λ/π⌋。

> 坑账：Weyl 计数断言初版写 N(100π²) = 100——实际 √λ/π = 10。
> **√ 的量纲别丢**。
