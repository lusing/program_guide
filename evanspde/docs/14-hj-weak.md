# 14 Hamilton-Jacobi II：弱解、粘性消失与唯一性

**对应书 §3.3.3（弱解、半凹性、比较原理与唯一性）。**

---

## 14.1 为什么要弱解

特征线解在梯度爆破（11 章 t*）后失效；Hopf-Lax 公式继续给出函
数，但它在爆破后**不再处处可微**——只能谈弱解。书 §3.3.3 的路
线：

1. Hopf-Lax 给出的 u 自动**半凹**（u − C|x|²/2 是凸的，书定理 4）
   ——凸性差控制保证 a.e. 可微 + 一侧二阶导；
2. 弱解 + 半凹 + 初值 ⟹ **比较原理** ⟹ **唯一性**（书定理 5、6）；
3. 粘性扰动 u^ε（加 εΔu^ε）的解收敛到同一极限——与 ch10 的粘
   性解理论接轨（45 章正式化）。

## 14.2 机器验证（Julia `14_hj_weak.jl`）

**(a) 爆破时刻**：g = −cos x ⟹ 特征 Jacobian 1 + cos(ξ)t 首次
归零在 t* = 1（数值 1.000000，9 位）。

**(b) 粘性消失实验**（本章主角）：粘性方程

    u^ε_t + (u^ε_x)²/2 = ε u^ε_xx

经 **Hopf-Cole 变换**（21 章正式推导）线性化为热方程，解

    u^ε(x,t) = −2ε log ∫ exp(−g(y)/2ε)·(4πεt)^{−1/2}e^{−(y−x)²/4εt} dy

数值积分后与 Hopf-Lax 粘性解对照：三个时刻（t = 0.6 光滑区、
t = 2.0、t = 3.5 爆破后），ε = 0.08 → 0.02 → 0.005 逐级逼近
（差 1.1×10⁻¹ → 2.8×10⁻² → 7×10⁻³，单调收敛，速率 O(ε|log ε|)
符合理论）。**特征线死掉的地方，粘性极限与 Hopf-Lax 活得一致。**

**(c) 半凹性**：Hopf-Lax 解的二阶差分 u(x+h)−2u(x)+u(x−h) > 0
（数值 +0.003/+0.0008 随 h² 缩）——凸差常数的数值面。

## 14.3 要点回顾

1. 弱解不唯一（可造反例），但**粘性解/半凹弱解唯一**—— Hopf-Lax
   挑出的正是它。
2. 粘性消失 u^ε → u 是粘性解的存在构造——数值上速率 O(ε|log ε|)。
3. 半凹性是 Hopf-Lax 的免费礼物，也是唯一性证明的关键杠杆。
