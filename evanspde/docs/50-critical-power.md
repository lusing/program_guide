# 50 半线性波：符号条件与临界指标

**对应书 §12.3（符号条件、三维、次临界）、§12.4（临界指标）、
§12.5（非存在）。**

- **符号条件** u·f(u) ≤ 0 ⟹ 势能非正 ⟹ 能量下界 ⟹ 全局存在；
- **临界指标** p_c = 1 + 2/(n−1)（Strauss 线；n = 3 时 p_c = 2）——
  次临界小数据全局散射、超临界存在爆破数据；
- **非存在**：负能量 ⟹ 有限爆破；小数据超临界爆破。

Julia（`50_critical_power.jl`）：势能 F = −u⁴/4 ≤ 0 的符号表
（Hamilton 总能量守恒 ~10⁻⁴ 漂移）；p_c = 2 与 Sobolev 线 5 的
对照；ODE 尺度 t* ~ u₀^{−(p−1)/2}（p 大爆破快）；次临界散射
（振幅不增长）。

要点：指标把非线性强度量化为阈值——两侧是散射与爆破的世界。

*本章示例：`examples/julia/50_critical_power.jl`。*
