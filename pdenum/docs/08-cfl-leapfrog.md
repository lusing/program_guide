# 08 CFL 条件、特征线与蛙跳格式

**对应书第 3 章 §1.4（Courant–Friedrichs–Lewy 条件）、§1.6（蛙跳
格式）与 §1.7（数值例子）。**

---

## 8.1 依赖区域与 CFL 条件

计算 u_jⁿ 要用到哪些初值？以 LW 格式为例：u_jⁿ 依赖 u^{n−1} 的
j−1, j, j+1 三点，递推下去，u_jⁿ 依赖初值在区间 **[x_{j−n}, x_{j+n}]**
上所有网格点——这是**差分格式的依赖区域**（书图 3.4）。

微分方程那边（a > 0），解 u(x_j, t_n) = g(x_j − at_n) 依赖初值在
**一个点** x_j − at_n（特征线足点 D）。若 D ∉ [x_{j−n}, x_{j+n}]，
则改变 g 在 D 附近的值会改变真解、却不改变差分解——差分格式不可
能收敛。于是得到收敛的**必要条件**：

> **CFL 条件**：差分格式的依赖区域必须包含微分方程初值问题的
> 依赖区域，即 x_j − at_n ∈ [x_{j−n}, x_{j+n}] ⟺ **|λ| = |a|τ/h ≤ 1**。

（推导：|a·nτ| ≤ n·h，约去正数 n 即得。第 08 章 Lean 通道把这条
"约去"做成了定理。）

**必要不充分**：LW 满足 CFL ⟺ 稳定（相容 + Lax 定理 ⟹ 收敛，CFL
对其充要）；但 03 章的中心格式（FTCS-advection）同样满足 CFL
（三层依赖 [j−n, j+n]）却无条件不稳定——**满足 CFL 只是入场券**。

## 8.2 蛙跳格式：三层、二阶、几乎免费

**蛙跳格式（leapfrog，书 (1.18)）**：时间空间都用中心差分：

    (u_j^{n+1} − u_j^{n−1})/(2τ) + a(u_{j+1}ⁿ − u_{j−1}ⁿ)/(2h) = 0。

二层化后增长矩阵 G = [[−iλsinθ·2? ,1],[1,0]] 的特征值
μ± = −iλsinθ ± √(1−λ²sin²θ)：**|μ| = 1 当 |λ| ≤ 1**（模方 =
λ²sin²θ + 1 − λ²sin²θ = 1）。|λ| < 1 时两根互异，用第 2 章定理
3.7 得稳定。

**λ = 1 的退化**（书 §1.6 末）：取 λ = 1、kh = π/2，G 不可对角化，
‖Gⁿ‖ 按 2^{n/2} 增长——恰在 CFL 边界上不稳定。蛙跳的实用建议：
λ 留有余量地取 < 1。

**起步层**：三层格式需要 u¹。书 §1.7/§5.3 用 Taylor 展开取
u¹ = g − τg′ + O(τ²)（或更高二阶起步）。**格式每步只要一次加减乘
的稀疏模板**——蛙跳是"最便宜的二阶格式"。

## 8.3 机器验证

### 依赖域锥的精确宽度

单点扰动经 LW 推进 n 步后，支撑**恰好**为 2n+1 个格点（Julia，
`examples/julia/08_cfl_leapfrog.jl`）：

```julia
u = zeros(J); u[100] = 1.0
...
supp = findall(abs.(u) .> 1e-50)   # 边缘振幅 ~λ^n 量级，阈值须远低于此
width = supp[end] - supp[1] + 1
@assert width == 2 * nst + 1 "支撑宽度应为 2n+1（实测 $width）"
```

实测 30 步后支撑 = 61 = 2·30+1。注意阈值坑：支撑最边缘的振幅是
模板系数的 n 重乘积（~λⁿ 量级），阈值 1e−12 会把它误判为零——
须放到 1e−50。

### CFL 边界的两侧

LW λ = 0.9 稳定、λ = 1.1 爆炸（max|u| > 1e4）；蛙跳 λ = 0.8 推进
方波稳定（max|u| = 1.254）。λ = 1 的退化模式（书 §1.6 的特殊解
u_jⁿ = (−1)^{j+n}(1−2n)）：

```julia
# λ=1：4 周期退化模式线性增长（书 §1.6：u_j^n = (-1)^{j+n}(1-2n) 型）
...
growth = maximum(abs.(uc))
@assert growth > 100 "λ=1 退化模式应线性增长"
@assert growth < 4 * 200 "增长应线性量级 ~2n，而非指数"
```

实测 200 步后 max|u| = 200.0——**线性增长**（指数增长会在 200 步
内到 1e30+），与书上的 2^{n/2} 矩阵范数/线性特解的分辨一致。

### 起步层精度：一次数学自纠

设计实验时的预判是"一阶起步 ⟹ 整体一阶"。**机器给出否决**：

```julia
e1a, e2a = lf_err(2.0e-2, 1), lf_err(1.0e-2, 1)   # 一阶起步
@assert 3.0 < r1 < 4.5 "一阶起步在 τ=O(h) 下也应二阶（实测 $r1）"
```

实测一阶起步的收敛比 3.813——**仍是二阶**。数学账：起步公式 p 阶
的误差是 O(τ^{p+1})；τ = λh 下"一阶"起步只贡献 O(h²)，与蛙跳内点
误差同阶，差别只在常数（细网格上 0.0934 < 0.1002 ✓）。书上说
"二层格式一般取为二阶为宜"的真正收益是压低常数、并在 τ 与 h 独立
细化时保持配位——对比第 10 章（波动方程）的起步实验，那里朴素
起步**真的拖到一阶**，机理不同（见 10 章的共振账）。

Prolog 通道（`08_cfl_leapfrog.pl`）实现 CFL 计算器（λ = 0.8/1.0/1.2
三组依赖区间包含判定）、必要性/充分性裁决表（lw 充分、ftcs_
advection 不充分）、蛙跳 |μ|² = 1 规则与 λ=1 退化的 2^{n/2} 增长
律。Lean 通道（`Ch08CflLeapfrog.lean`）两条：CFL 算术内核
`|a·nτ| ≤ n·h ↔ |λ| ≤ 1`（h > 0, n > 0——n = 0 时左端平凡成立而
右端未必，定理陈述必须排除；证明是 `abs` 恒等式 + `field_simp` +
`nlinarith`），以及蛙跳的一阶模板恒等式
`sin((j+1)θ) − sin((j−1)θ) = 2sinθ·cos(jθ)`。

## 8.4 要点回顾

1. CFL：差分依赖域 ⊇ 微分依赖域，|λ| ≤ 1；收敛的必要条件，对 LW
   恰好充分，对 FTCS-advection 不充分。
2. 蛙跳：时间空间双中心差分，二阶精度、模板最稀疏；|λ| ≤ 1 稳定，
   λ = 1 退化（矩阵不可对角化、特殊模式线性增长）。
3. 三层格式需要起步层；起步公式 p 阶 ⟹ 初始层误差 O(τ^{p+1})。
4. 实验设计三坑：支撑判定阈值要低于模板系数的 n 重乘积；"线性
   vs 指数增长"用上界分辨；预判的收敛阶要交给机器裁决。
