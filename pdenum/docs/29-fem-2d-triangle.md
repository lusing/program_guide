# 29 二维三角形线性元

**对应书第 7 章 §2（单元剖分及试探函数空间的构造、有限元方程的
形成、例子，三角形线性元与面积坐标）。**

---

## 29.1 三角剖分与分片线性空间

二维区域 Ω 剖分为三角形 {e}（顶点集合 = 节点）。试探空间

    U_h = {v ∈ C(Ω̄) : v|_e 线性 ∀e}，

基函数 φ_i 仍是"hat"：节点 i 处取 1、其余节点取 0——但二维 hat 的
支撑是**共享节点 i 的所有三角形**（书图 7.x）。

**线性元的局部自由度**：三角形 3 顶点值唯一确定平面
u(x,y) = a + bx + cy。

## 29.2 单元刚度：面积坐标的代数

在单元 e（顶点 (x₁,y₁),(x₂,y₂),(x₃,y₃)，面积 A）上，线性基的梯度
是**常数向量**（书 §2.2 的推导）：

    ∇φ_a = (b_a, c_a)/(2A)，b_a = y_j − y_k，c_a = x_k − x_j
    （(a,j,k) 轮换），

于是**单元刚度有闭式**：

    k^{(e)}_ab = (b_a b_b + c_a c_b)/(4A)·1（Poisson）

——面积坐标（barycentric）L_a = (b_a x + c_a y)/(2A) + 常数，满足
L₁+L₂+L₃ = 1。载荷用重心规则 f(L̄)·A/3（一个 Gauss 点）。

**装配**与一维同构：单元 e 的三个局部基映射到全局顶点号，累加。
Dirichlet 边界节点划去。

## 29.3 机器验证

### 单位直角三角形的闭式

顶点 (0,0),(1,0),(0,1)：b = (−1,1,0)、c = (−1,0,1)、A = 1/2——

    k = [[1, −½, −½], [−½, ½, 0], [−½, 0, ½]]

**行和为零**（常数向量零模式）——Lean（`Ch29Fem2d.lean`）逐行
`norm_num` 证明三行和均为 0（`row0/row1/row2`），加对称性定理。
这是"划边界后可逆"（22 章极值原理的有限元版）的代数前提。

### Poisson 全流程

单位正方形一致三角化（每矩形两三角形），−Δu = 2π²sinπx sinπy、
零边界。Julia（`examples/julia/29_fem2d.jl`）：

```julia
b1 = y2 - y3; b2 = y3 - y1; b3 = y1 - y2
c1 = x3 - x2; c2 = x1 - x3; c3 = x2 - x1
A2 = x1 * (y2 - y3) + x2 * (y3 - y1) + x3 * (y1 - y2)   # 2×面积
ke[a, b] = (ba * bb + ca * cb) / (4 * (A2 / 2))
```

N = 8/16 两档：节点误差 2.1×10⁻² / 5.4×10⁻³，比值 **3.996**——
P1 三角元节点二阶收敛（与五点差分同阶，但网格灵活性与边界适应性
完全不同）。Python 通道逐位复现。

Prolog：局部-整体映射（三角版，3 顶点）、闭式表、面积坐标规则。

## 29.4 要点回顾

1. 三角形 P1 元：3 顶点自由度，梯度 = 常数向量 (b,c)/(2A)——单元
   刚度纯代数闭式，无数值积分。
2. 面积坐标 L₁+L₂+L₃ = 1 是三角元的"局部坐标系"；载荷重心规则。
3. 单元刚度行和为零（零模式）——划边界后正定的代数前提。
4. P1 元与五点差分在一致矩形三角化上给出同一方程（精度同阶），
   但有限元天然支持任意三角化与非均匀网格。
