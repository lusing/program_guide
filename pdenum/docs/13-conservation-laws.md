# 13 守恒律与守恒型差分格式

**对应书第 3 章 §7（守恒律的初值问题、Lax–Friedrichs 差分格式、
守恒型差分格式，式 (7.1)–(7.11)）。**

---

## 13.1 从特征线相交到弱解

最简单的非线性双曲方程是 **Burgers 方程** u_t + u u_x = 0，其守恒
形式 u_t + f(u)_x = 0（f(u) = u²/2）。单个**守恒律**（书 (7.2)）
设 f 严格凸，a(u) = f′(u)。特征线 dx/dt = a(u) 是直线，解沿特征线
为常数——但**右侧快、左侧慢**的初值会让特征线**相交**：相交后
连续解不存在。即使 f 与初值都充分光滑，整体连续解也不存在，必须
推广解的概念：

**弱解**（定义 7.1）：对一切紧支撑光滑试验函数 φ 满足积分恒等式
（书 (7.5)）。弱解允许间断；穿越间断线 x = ξ(t) 时满足**跳跃条件
（Rankine–Hugoniot）**：

    s·(u_R − u_L) = f(u_R) − f(u_L)，  s = dξ/dt 为间断传播速度。

（在守恒律上跨间断积分 Green 公式立得。）Burgers 的 Riemann 问题
（左 u_L、右 u_R）：

- u_L > u_R：唯一物理解是**激波**，s = (f(u_L) − f(u_R))/(u_L − u_R)
  （Burgers 即 (u_L + u_R)/2）；
- u_L < u_R：**稀疏波** u = x/t（|x| < t）。

## 13.2 弱解不唯一：熵条件

弱解**不唯一**（有的问题有无穷多个）。从弱解中挑出物理解要加
**熵条件**（书 (7.7)(7.8)）：间断线上

    a(u_L) ≥ s ≥ a(u_R)，

几何解释：**两边的特征线都走向间断线**（进入激波）。等价的凸包
不等式 (7.7) 对一般凸 f 更好用。满足熵条件的弱解唯一。

## 13.3 守恒型差分格式

**Lax–Friedrichs 格式**（书 §7.2 由 Green 公式导出）：在矩形
[x_{j−1/2}, x_{j+1/2}] × [t_n, t_{n+1}] 上积分守恒律、用中点近似
各边积分，得

    u_j^{n+1} = ½(u_{j+1}ⁿ + u_{j−1}ⁿ) − (λ/2)(f(u_{j+1}ⁿ) − f(u_{j−1}ⁿ))。

**守恒型格式**：形如

    u_j^{n+1} = u_jⁿ − λ(ĝ_{j+1/2} − ĝ_{j−1/2})，

ĝ 是**数值通量**；**相容性** ĝ(u, u) = f(u)。LF 的数值通量
ĝ = ½(f(u_j) + f(u_{j+1})) − (1/(2λ))(u_{j+1} − u_j)；Lax–Wendroff
的守恒形式用半点状态 u_{j+1/2} = ½(u_j + u_{j+1}) − (λ/2)(f_{j+1}
− f_j) 组装。

**Lax–Wendroff 定理**（书 §7.3 的纲领）：守恒 + 相容的格式若收敛，
极限是弱解。加上熵粘性（LF 自带大耗散）收敛到**熵解**。**反面对
照**：非守恒离散（把 u_t + u u_x = 0 直接迎风）不满足通量形式，
收敛极限的激波速度**错**——这是非线性计算的第一戒律。

## 13.4 机器验证

### 激波速度：守恒 vs 非守恒的生死对账

Burgers Riemann 问题 u_L = 1、u_R = 0：Rankine–Hugoniot 给
s = (½·1² − 0)/(1 − 0) = **1/2**，t = 0.4 时激波应在 0.5 + 0.2 =
0.7。激波位置用 u = 0.5 等值线的线性插值定位（Julia，
`examples/julia/13_conservation.jl`）：

```julia
for kind in (:lf, :lw)
    u = conservative_scheme(kind, uL, uR, lam, h, T)
    pos = front_position(u, h)
    @assert abs(pos - (0.5 + s_exact * T)) < 5 * h "守恒格式的激波速度应正确"
end
u_nc = conservative_scheme(:noncons, uL, uR, lam, h, T)
@assert abs(front_position(u_nc, h) - (0.5 + s_exact * T)) > 10 * h "非守恒格式应给出错误速度"
```

实测（h = 1/512，λ = 0.4）：

| 格式 | 激波位置 | 误差 |
|---|---|---|
| 守恒 LF | 0.6986 | 0.0014 (< 5h) ✓ |
| 守恒 LW | 0.6985 | 0.0015 ✓ |
| **非守恒迎风** | **0.4990** | **0.201（≈ 100h）✗** |

非守恒格式的"激波"**原地不动**（0.499 ≈ 初始位置 0.5）——它以
通量不对账的方式输运，间断速度完全错误。Lax–Wendroff 定理的
正反两面在 4 位小数上对清。

### 稀疏波与熵条件

u_L = −1、u_R = 1：熵解是稀疏波 u = x/t。LF（自带耗散，天然选
熵解）在 t = 0.25 的中心区与稀疏波解最大误差 0.105（耗散抹宽了
扇形边缘，但形态正确）。熵条件判据的规则版：

```julia
check_entropy(uL, uR) = a_of(uL) >= ((flux(uR) - flux(uL)) / (uR - uL)) >= a_of(uR)
@assert check_entropy(1.0, 0.0)   "激波 (1,0)：特征走向间断"
@assert !check_entropy(-1.0, 1.0) "稀疏数据：熵条件不满足，等熵解是稀疏波"
```

实验设计注记：周期域上放 Riemann 初值会在**对边**生成第二个
Riemann 问题（u=+1 → u=−1 的驻定激波），稀疏波对账必须限制在
中心区域——第一版全区间对账误差 1.37，被断言逼着看清了双间断
结构。

Prolog 通道（`13_conservation.pl`）把理论做成规则引擎：RH 速度
（(1,0)→1/2、(2,0)→1、(1,−1)→0）、熵条件与 Riemann 判据
（shock/rarefaction）、数值通量存在性判定（lf/lw 守恒、
noncons_upwind 无通量形式）与 Lax–Wendroff 定理事实。

## 13.5 要点回顾

1. 守恒律的特征线会相交 ⟹ 整体连续解不存在 ⟹ 弱解（积分形式）；
   间断满足 Rankine–Hugoniot：s = [f]/[u]。
2. 弱解不唯一；熵条件 a(u_L) ≥ s ≥ a(u_R)（特征走向间断）挑出
   物理唯一解。
3. 守恒型格式 = 数值通量的差 + 相容性；LF 与守恒 LW 都是；非守恒
   离散的间断速度错（实测差 100 个网格）——非线性计算第一戒律。
4. LF 的大耗散自带"熵粘性"，收敛到熵解；稀疏波也能正确展开。
5. 实验坑：周期域双 Riemann 问题；间断定位用等值线插值而不是
   找第一个跳变点。
