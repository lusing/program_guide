# 19 多维抛物方程：ADI、LOD 与预测-校正

**对应书第 4 章 §5（一维格式的直接推广、交替方向隐式格式、局部一维
格式、预测-校正格式、跳点格式、三维问题，式 (5.1)–(5.6 节）。**

---

## 19.1 多维的三重惩罚

把 FTCS 直接推广到二维（书 §5.1）：空间四邻点平均——增长因子
G = 1 − 4r(sin²θ₁/2 + sin²θ₂/2)，稳定条件收紧为

    **r = τ/h² ≤ 1/4**（d 维是 r ≤ 1/(2d)）。

维数越高显式越严；同时**隐式**格式的矩阵不再是三对角（五对角带状），
直接解代价高企。多维抛物的全部主题就是绕开这两堵墙。

## 19.2 ADI：交替方向隐式

**Peaceman–Rachford ADI**（书 §5.2）：把一步劈成两个**半步**，每半步
只在一个方向隐式：

    半步 1：(I − (r/2)δ_x²)u* = (I + (r/2)δ_x²)uⁿ
    半步 2：(I − (r/2)δ_y²)uⁿ⁺¹ = (I + (r/2)δ_y²)u*

每个半步是**逐行（列）的三对角追赶**——宽带问题化为 2J 次一维求解。
增长因子 G = G_x·G_y，每因子形如 (1−2rs²)/(1+2rs²)，模恒 ≤ 1——
**无条件稳定**，且时间方向对称、**二阶精度**。

## 19.3 LOD 与预测-校正

- **LOD（局部一维）**（书 §5.3）：u^{n+1} = (I − rδ_y²)⁻¹(I − rδ_x²)⁻¹uⁿ
  ——两个方向的**全隐式串联**，无条件稳定，一阶精度（BTCS 型分裂）；
  写成算子乘积后每步仍是两次三对角。
- **预测-校正**（书 §5.4）：半步显式预估 + 半步校正，二阶精度、
  稳定域 r ≤ 1（显式放宽一倍）。
- **三维**（书 §5.6）：ADI 推广为三方向轮流（Douglas 格式），或 LOD
  三连。

## 19.4 机器验证

### r ≤ 1/4 的两侧

二维 FTCS：r = 0.24 推进 400 步有界；r = 0.26 爆（需播种 10⁻⁶ 的
棋盘噪声——光滑单模在超界处也会增长，但纯模式数据增长太慢，是
12 章同款实验设计坑）（Julia，`examples/julia/19_multidim.jl`）。

### PR-ADI：测阶与稳定性分开报告

```julia
e1 = adi_err(0.05, 1.0)
e2 = adi_err(0.025, 1.0)
@assert 3.4 < r19 < 4.6 "PR-ADI 应二阶（实测 $r19）"
u5err = adi_err(0.05, 5.0)
@assert u5err < 0.05 "PR-ADI r=5 应稳定收敛"
```

实测：r = 1 收敛比 **3.929**（二阶）；r = 5（显式禁区的 20 倍）稳
定收敛、误差 2×10⁻⁴。**实验自纠**：初版在 r = 5 下测阶得 1.82——
大 τ 使 (λτ)³ 的时间误差项污染了空间二阶信号；把"测阶"与"无条件
稳定"分设两个参数（r=1 测阶、r=5 验稳）后两边都干净。初版还把
半步的右端写错成"另一方向"的显式（应为本方向）——r=5 下直接
发散，被稳定性断言当场抓住。

Fortran 通道（`19_adi.f90`）实现完整 ADI（行/列两次追赶），r = 5
稳定、误差 1.1×10⁻³（坑账：`call thomas(N,a,b,c,d,u(i,1))` 把第 i 行
首元素地址当数组用——行内元素在内存不连续，追赶被别名污染；用
`urow` 缓冲行数据再回写修复）。

### LOD

BTCS 分裂（两个全隐方向串联）在 r = 5：误差 0.005、加密比 4.1
（空间二阶、时间一阶在 r 固定时由 h² 项主导）。

## 19.5 要点回顾

1. 显式多维惩罚：r ≤ 1/(2d)；隐式多维惩罚：宽带矩阵。
2. ADI/LOD 共同思路：按方向分裂，每方向三对角追赶；PR-ADI 二阶
   无条件稳定，LOD 一阶无条件稳定。
3. 实验纪律：收敛阶测量与稳定性验证用不同参数（大 τ 的时间误差
   会污染测阶）；光滑数据的超界增长慢，判稳须播种网格噪声。
4. Fortran 列主序陷阱：行方向的三对角求解必须缓冲行。
