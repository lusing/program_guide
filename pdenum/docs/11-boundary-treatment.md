# 11 初边值问题与数值边界处理

**对应书第 3 章 §5（二阶双曲的边界处理、一阶方程及方程组的边界
条件、数值边界处理，式 (5.1)–(5.32)）。**

---

## 11.1 二阶双曲的边界处理与加权隐式格式

波动方程初边值问题的三类边界条件中：第一类直接转移
u⁰ⁿ = μ₁(t_n)、u_Jⁿ = μ₂(t_n)（书 (5.4)）；第三类用单侧差分离散
∂u/∂x（书 (5.5)）。隐式求解用**加权格式**（书 (5.6)）：对 n−1、n、
n+1 三层的空间二阶差分加权：

    u_j^{n+1} − 2u_jⁿ + u_j^{n−1} = λ²[θ(δ²u^{n+1} + δ²u^{n−1})
                                       + (1−2θ)δ²uⁿ]，

θ = 0 退回显式 (4.10)。通过辅助变量 v = (u^{n+1} − uⁿ)/τ 改写
（书 (5.7)–(5.9)），隐式部分是三对角方程组——追赶法求解，v 显式
回代。**稳定性**（书 §5.1 的 Fourier 分析）：增长矩阵 G 满足
GᴴG = I——**酉矩阵**，|μ| = 1，**无条件稳定**（第 02 章定理 3.2
推论的完美案例）。

## 11.2 一阶方程的边界条件：出流不给条件

对流方程 a > 0 在 [0,1] 上：特征线从**左边界**进入区域——只能在
x = 0 给条件 u(0,t) = β(t)（书 (5.12)）；右边界 x = 1 是**出流**，
信息由内部流出，**给条件会破坏适定性**。a < 0 时左右互换。

方程组 u_t + A u_x = 0：用 S⁻¹ 化特征形式后逐个特征方向判断——

> **x = 0 处边界条件的个数 = A 的负特征值个数（进入区域的特征）；
> x = 1 处 = 正特征值个数。** 零特征值不需要条件。

这条"计数规则"是双曲问题边界处理的第一定律。

## 11.3 数值边界条件：差分比微分要得更多

差分格式的模板常比微分问题需要**更多的边界值**（出流侧的 stencil
悬空），必须增补**数值边界条件**。处理不当会毁掉整个计算——书
例 5.1 给出完整反例：蛙跳格式解 a > 0 的对流，出流边界用线性外推

    u_Jⁿ = 2u_{J−1}ⁿ − u_{J−2}ⁿ（书 (5.20)），

在四分之一平面上取特殊初值，解按 ~n² 增长——**不行**；换 (5.21)
的二阶外推——**也不行**。两个可行方案：

- **迎风边界**（书 (5.22)）：u_J^{n+1} = u_Jⁿ − λ(u_Jⁿ − u_{J−1}ⁿ)
  ——把边界点当局部对流用迎风格式推进，几乎总是可行；
- **特征插值**（书 (5.28)）：方程组情形沿特征方向在内部点插值，
  书中证明**边界处理可以比内点低一阶而不影响整体精度**——内点
  二阶格式配一阶边界足够。

## 11.4 机器验证

### 加权隐式：λ = 2 下的二阶收敛

θ = 1/2 的加权格式在 λ = 2（显式格式的死亡区）依旧稳定（Julia，
`examples/julia/11_boundary.jl`）：

```julia
e1 = wave_weighted_err(2.0e-2, 2.0, 0.5)
e2 = wave_weighted_err(1.0e-2, 2.0, 0.5)
@assert 3.5 < r < 4.5 "加权隐式应二阶（λ=2 无条件稳定）"
```

实测 h → h/2 误差比 3.644——**λ = 2 下二阶收敛**（G 酉 ⟹ 无条件
稳定的数值版）。三对角追赶法每步 O(J)。

### 数值边界反例：外推 vs 迎风

蛙跳 + a > 0 在 [0,1]，入流边界给 0，出流边界分别用线性外推 (5.20)
与迎风 (5.22)。初值含 10⁻³ 的网格尺度种子（外推反例需要网格内容；
舍入误差迟早也会注入同形态噪声）：

```julia
long_ex = leapfrog_bc(:extrap, 4000)
long_up = leapfrog_bc(:upwind, 4000)
@assert long_ex > 1.0 "外推边界应缓慢增长"
@assert long_up < 0.01 "迎风边界应保持有界"
```

实测 4000 步后：外推 max|u| = 10⁸（缓慢增长到爆）；迎风 max|u| =
2.5×10⁻⁹（脉冲流出区域后归零）。**500 步时两者都还好**（0.64 vs
10⁻⁴）——外推的病是慢性的，短跑看不出，这正是书里"必须小心处理
附加边界问题"的数值形态。Python 通道逐位复现。

### 计数规则

Prolog 通道（`11_boundary.pl`）实现计数引擎：标量 a > 0 ⟹ 左 1
右 0；方程组特征值 [−1, 2, −3] ⟹ 左 2（负特征值个数）右 1；[−1, 1]
⟹ 每边一个。数值边界方法知识表：外推 (5.20)(5.21) 判 fails、
迎风 (5.22)/特征插值 (5.28)/有限体积梯形判 works，外加"边界可比
内点低一阶"的定理事实。

## 11.5 要点回顾

1. 二阶双曲边界：第一类直接转移、第三类单侧差分；加权隐式格式
   的增长矩阵是酉的——无条件稳定，追赶法解三对角。
2. 双曲边界计数定律：入流侧条件数 = 指向域内的特征值个数；
   出流侧不给条件（给了就不适定）。
3. 数值边界是差分额外向出流侧要的值；外推类方案会有慢性不稳定
   （特殊初值下 ~n 增长），迎风/特征插值是安全选择。
4. 边界处理可比内点低一阶而不损整体精度——省心定理。
5. 实验教训：慢性病要长跑暴露（500 步健康、4000 步爆掉）。
