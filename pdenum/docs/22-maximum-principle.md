# 22 极值原理：存在唯一性与收敛性

**对应书第 5 章 §2（差分格式的性质：极值原理、存在惟一性、差分方程
解的收敛性，定理 2.1–2.4，式 (2.1)–(2.8)）。**

---

## 22.1 离散极值原理

**定理 2.1（极值原理）**：设 Δ_h u_{i,j} ≥ 0（书 (2.1) 的左端）对一
切内点成立，则

    max_{D_h} u ≤ max_{∂D_h} u；

Δ_h u ≤ 0 时 min 类似。

证明（书）用反证 + **传播**：设内点 P 取严格最大值 M，则 Δ_h u ≥ 0
（系数全非负的凸组合）强迫 P 的四邻**全部等于 M**——否则凸组合严格
小于 M。对等于 M 的邻点继续论证，最终传播到边界，得边界某点也取
M，与边界最大值 < M 矛盾。这是连续极值原理的逐字离散版，其代数
内核与 06 章的凸性不等式同源：δ²u ≥ 0 ⟺ u₀ ≤ 邻居平均。

## 22.2 存在唯一性

**定理 2.2**：差分边值问题 (2.1)(2.2) 的解存在唯一。证明：齐次问题
（f = 0、边界 0）的解 u 满足 max ≤ 0 且 min ≥ 0（两个方向的极值原
理），故 u ≡ 0；线性方程组齐次只有零解 ⟹ 系数矩阵非奇异。

谱的视角（与 06 章矩阵法接续）：五点矩阵对称、弱对角占优且**不可约**
（网格连通）⟹ 非奇异；其特征值有闭式

    λ_{i,j} = 4 − 2cos(iπh) − 2cos(jπh) = 4sin²(iπh/2) + 4sin²(jπh/2) > 0，

最小特征值 8sin²(π/2N) ~ 2π²h²——**正定**，唯一性另证。

## 22.3 收敛性：闸函数技巧

**定理 2.3**：对 D_h ∪ ∂D_h 上任意函数有先验估计（书 (2.5)）——用
**比较函数** w = (x² + y²)/4（Δ_h w = 1）做上下闸：

    max|u| ≤ max|∂u| + a²·max|Δ_h u|/8（a 为区域边长）。

**定理 2.4**：若真解 u ∈ C⁴，则差分解收敛且

    **max|u_{i,j} − u(x_i,y_j)| ≤ C(h² + k²)**（书 (2.7)），

其中 C 由 u 的四阶导数界出。证明：误差 e 满足 Δ_h e = 截断误差
（Taylor 展开主部 (h²/12)u⁗ₓ + (k²/12)u⁗_y），零边界；用定理 2.3
的闸函数估计立得。极值原理是**先验估计**的工具，闸函数是它的
"脚手架"。

## 22.4 机器验证

### 极值原理的数值版

构造 Δ_h u ≥ 0 的解（Poisson 正源 + 上下起伏的边界，Julia，
`examples/julia/22_max_principle.jl`）：

```julia
allsub, umax, bmax = discrete_max_principle(20, (x, y) -> 0.5 + 0.3 * sin(3x) * cos(2y))
@assert allsub "构造的解应满足 Δ_h u ≥ 0"
@assert umax <= bmax + 1e-12 "极值原理：内点最大值 ≤ 边界最大值"
```

实测内点最大 0.75544753 ≤ 边界最大 0.79924850——定理 2.1 的(1)逐字
兑现。坑账一笔：构造源时初版把方程写成 Δ_h u = −rng ≤ 0（次调和），
断言当场翻车——**超调和/次调和的符号方向**是极值原理实验的第一坑。

### 特征值闭式对账

五点矩阵（(N−1)² 阶）的数值特征值与闭式 4−2cos(iπh)−2cos(jπh)
全谱吻合到 10⁻⁸（N = 10/20）；Jacobi 迭代谱半径 cos(π/N) = 0.9877
< 1（迭代收敛的谱理由）。

### Lean：传播矛盾与正性

`Ch22MaxPrinciple.lean` 两条：

```lean
/-- 关键传播步：若 δ²u_j ≥ 0 且 u_j 严格大于两邻，则两邻之和 < 2u_j，
与 δ²u ≥ 0 矛盾——极值原理证明的代数内核。 -/
theorem max_propagation (u _j : ℝ) (um1 up1 : ℝ)
    (hsub : um1 - 2 * u + up1 ≥ 0) (hnotmax : u > um1 ∧ u > up1) : False
```

配 `subharmonic_is_average`（δ²u ≥ 0 ⟺ u ≤ 邻居平均——与 06 章
凸性恒等式同一张脸）和 `five_point_min_eig_positive`（cos x < 1 ⟹
4 − 4cos x > 0——最小特征值正性）。Prolog（`22_max_principle.pl`）
把证明骨架做成规则：严格内点最大 ⟹ 邻点全等 ⟹ 传播到边界 ⟹ 矛盾；
谱知识（min eig = 8sin²(π/2N)、Jacobi 半径、Hermite + 弱占优 + 不可约
⟹ 非奇异）与唯一性论证链。

## 22.5 要点回顾

1. 离散极值原理：Δ_h u ≥ 0 ⟹ max 在边界；内核是凸组合论证（严格
   内点最大强迫邻点全等，传播到边界矛盾）。
2. 存在唯一性两条路：齐次问题只有零解（极值原理）/ 五点矩阵正定
   （特征值闭式 + Hermite + 不可约）。
3. 收敛性 O(h²)：闸函数 w = (x²+y²)/4 的先验估计 + Taylor 截断主部。
4. 实验第一坑：源项符号决定超/次调和方向，断言先于直觉。
