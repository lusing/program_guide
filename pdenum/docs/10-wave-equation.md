## 10.1 从 d'Alembert 到显式格式

一维波动方程初值问题 u_tt = a²u_xx、u(x,0) = f、u_t(x,0) = g 的解
由 d'Alembert 公式给出（01 章），解在 (x,t) 依赖初值区间
[x − at, x + t·a]（两条特征线在 x 轴上截出的**依赖区间**）。

**显式格式（书 (4.10)）**：时间空间都用中心差分的三层格式：

    (u_j^{n+1} − 2u_jⁿ + u_j^{n−1})/τ² = a²(u_{j+1}ⁿ − 2u_jⁿ + u_{j−1}ⁿ)/h²，

截断误差 O(τ²) + O(h²)。波动的等价一阶组形式（u_t = v, v_t = a²u_x，
对称双曲）说明第 09 章的全套方法都适用——稳定性两路殊途同归。

**起步层**：三层格式需要 u¹。两种离散（书 (4.12)、(4.14)）：

- 朴素版：u¹ = u⁰ + τg（对 g 直接前差）——作为离散关系的截断误差
  O(τ)，与内点的 O(τ²) **不匹配**；
- 精化版：引入虚拟层 u^{−1} 消去 g 的离散，得
  u¹ = ½λ²(f_{j+1} − 2f_j + f_{j−1})·? + f_j + τg_j —— 二阶匹配。

**稳定性**：代入波型得特征方程 μ² − (2 − 4λ²sin²(θ/2))μ + 1 = 0
（两根之积为 1），根在单位圆上 ⟺ |2 − 4λ²sin²(θ/2)| ≤ 2 ⟺
**λ = aτ/h ≤ 1**。λ = 1 时在 θ = π 退化（重根 −1、矩阵 defective），
书 §4.2 用特殊初值 u_jⁿ = (−1)^{j+n}(1−2n) 证不稳定——**稳定条件
是 aλ < 1（严格）**。

**CFL**：格式的依赖区间 [x − nh, x + nh] ⊇ 微分的 [x − at_n, x + at_n]
⟺ aλ ≤ 1——必要但不充分（λ = 1 满足 CFL 却不稳定）。

## 10.2 机器验证

### 起步层精度：与 08 章相对照的"共振账"

08 章的对流蛙跳里，一阶起步只压低常数不降阶。波动方程**不同**：
朴素起步 u¹ = u⁰ + τg 真的把整体拖成一阶（Julia，
`examples/julia/10_wave.jl`）：

```julia
e1, e2 = wave_err(2.0e-2, 2), wave_err(1.0e-2, 2)
@assert 3.5 < r2 < 4.5 "二阶起步应二阶收敛"
e1a, e2a = wave_err(2.0e-2, 1), wave_err(1.0e-2, 1)
# 数学账：朴素起步 u^1 = f + tau*g 的 O(tau^2) 初始层误差对波方程等效于
# O(tau) 的初速度误差（响应含 1/sin(omega tau) ~ 1/tau 的共振因子），
# 整体拖成一阶——书"截断误差不匹配"的实证。
@assert 1.7 < r1 < 2.4 "一阶起步应拖累为一阶（实测 $r1）"
```

实测：二阶起步收敛比 4.039（err(0.01) = 5.0×10⁻⁶）；朴素起步
2.055（err(0.01) = 6.4×10⁻⁴，慢 128 倍）。机理：初始层的 O(τ²)
偏差相当于初速度错了 O(τ)，而波动格式对初速度误差的响应带
1/sin(ωτ) ≈ 1/τ 的共振因子——误差被放大到 O(τ)。对流方程没有这个
共振（特征单方向），所以 08 章不降阶。**同一张"起步精度"考卷，
两种方程给出不同答案**——这是本教程机器实验最值得记的一课。

### aλ = 1 边界的三个世界

- λ = 0.99：max|u| = 0.957，稳定；
- λ = 1.0：以 (−1)ʲ 模式 + 零速度起步（u¹ = u⁰，恰好落在若尔当块
  的增长方向），200 步后 max|u| = **399.0 = |1 − 2·200|**——与书
  (4.15) 节的特殊解 u_jⁿ = (−1)^{j+n}(1−2n) **逐字吻合**（线性增长
  而非指数）；
- λ = 1.01：400 步内 max|u| = 10⁸（指数爆炸）。

设计注记：第一版把退化模式取成 4 周期模式（θ = π/2，那是**蛙跳**
的退化角），波动的退化角是 θ = π 且需要 u¹ = u⁰ 的特定起步——猜错
的模式给出"稳定"的假象，靠断言逼出了正确构造。

### 方波分裂与能量有界

Fortran 通道（`10_wave.f90`）：方波脉冲在 CFL = 0.8 下分裂成左右
两个行波（中心值 −0.017 ≈ 0）；λ = 1.01 时 max|u| = 1.2×10⁶。
Julia 通道补充：λ = 0.5 时波幅推进 T = 0.5 后保持 1.000（|μ| = 1
的范数守恒）。

Lean 通道（`Ch10Wave.lean`）把判别式条件做成双向定理：

```lean
/-- `λ ≤ 1`、`s² ∈ [0,1]` 时特征方程系数 `c = 2 − 4λ²s²` 满足
`|c| ≤ 2`（两根共轭、模为 1——von Neumann 条件）。 -/
theorem wave_vn_stable (lam s2 : ℝ) (hlam : 0 ≤ lam) (hlam2 : lam ≤ 1)
    (hs1 : 0 ≤ s2) (hs2 : s2 ≤ 1) :
    |2 - 4 * lam ^ 2 * s2| ≤ 2 := by
  ...
/-- `λ > 1` 时取 θ = π（s² = 1）得系数 `2 − 4λ² < −2`。 -/
theorem wave_vn_unstable (lam : ℝ) (hlam : 1 < lam) :
    2 - 4 * lam ^ 2 * 1 < -2 := by nlinarith
```

配一条装配件 `wave_characteristic`（模板恒等式 → 模式放大），
三层格式的分析链条在 Lean 里闭合。

## 10.3 要点回顾

1. 波动显式格式：双中心差分三层模板，O(τ²+h²)，稳定条件
   **aλ < 1（严格）**；λ = 1 在 θ = π 退化（线性增长的特解存在）。
2. 起步层的精化 (4.14) 不是锦上添花：朴素起步的 O(τ²) 偏差经波方程
   的 1/ωτ 共振放大成 O(τ)——对流方程无此共振（08 章对照）。
3. CFL 必要不充分又一次上演：λ = 1 满足 CFL 却不稳定。
4. 等价一阶组视角（对称双曲）把方程组工具全数接入（LF/LW (4.16)
   (4.17)，稳定条件同为 aλ ≤ 1）。
