2.1–2.3、定理 2.1 Lax 等价定理，式 (2.1)–(2.17)）。**

---

## 4.1 截断误差与相容性

把**微分方程的光滑解**代入差分格式，两边之差称为**截断误差**。
以 FTCS 热传导格式为例（书 (2.7)）：

    T(x,t) = [u(x,t+τ) − u(x,t)]/τ − a²[u(x+h,t) − 2u(x,t) + u(x−h,t)]/h²，

代入 Taylor 展开（利用 u_t = a²u_xx 消去低阶项）：

    T(x,t) = (τ/2)·u_tt − (h²/12)·u_xxxx + 高阶项。

前两项称为截断误差**主部**。若 T = O(τ^p) + O(h^q)，称格式对 τ
p 阶、对 h q 阶精度；p = q 时称为 p 阶格式。

**相容性**（定义 2.1）：τ, h → 0 时 T(x,t) → 0。相容是用差分格式
逼近微分方程的底线条件——本书构造的格式全部相容（Taylor 展开到
几阶，相容性就有几阶的保障）。差分记号（向前 δ₊、向后 δ₋、中心
δ、二阶中心 δ²）与平移算子 T（Tu_j = u_{j+1}）给出格式的算子表述
u^{n+1} = L_h uⁿ，第 05 章 Fourier 分析将直接使用它。

## 4.2 收敛性：两个正反面例子

**收敛性**（定义 2.2）：当 τ, h → 0 时，差分格式的解 u_jⁿ 逼近微
分方程问题的解 u(x_j, t_n)。两个直接分析的例子值得完整复盘。

**反例：迎风方向的顺风格式不收敛**（书 §2.3）。设 a > 0，考察顺
风格式（1.7）。用平移算子展开后（书 (2.11)）：

    u_jⁿ = Σ_k C(n,k)(1+aλ)^{n−k}(−aλ)^k g_{j+k}，

它只用到初始值在点集 {x_j, x_{j+1}, …, x_{j+n}} 上的值（(2.12)）。
而微分方程的解 u(x_j, t_n) = g(x_j − at_n)——依赖点在**左边**且
不属于该点集。于是：改变 g 在 x_j − at_n 附近的值，真解变了，差
分解纹丝不动——误差不可能趋于零。

**正例：FTCS 热传导在 r ≤ 1/2 时收敛**（书 §2.3 末）。令 e_jⁿ =
u(x_j,t_n) − u_jⁿ，代入截断误差得误差方程（(2.13)）：

    e_j^{n+1} = (1−2r)e_jⁿ + r(e_{j+1}ⁿ + e_{j−1}ⁿ) + τ·T_jⁿ。

关键一步：**r ≤ 1/2 时右端三项系数全非负**，可取绝对值放大为
E^{n+1} ≤ Eⁿ + Mτ(τ + h²)，递推得 Eⁿ ≤ M·nτ(τ + h²) = MT(τ+h²)
→ 0。注意条件 r ≤ 1/2 **不可省略**——系数变号时放大约束失效。

## 4.3 稳定性：误差的传播控制

按层推进时，任何一层引入的误差（舍入、初始资料）都会被格式传递。
**稳定性**（定义 2.3，(2.15)）要求存在常数 K 使

    ‖εⁿ‖ ≤ K·‖ε⁰‖   (对一切 nτ ≤ T 一致成立)，

即初始误差在演化中被控制。线性格式下等价于传播算子幂一致有界
‖(L_h)ⁿ‖ ≤ K（(2.16)(2.17)）。

稳定性既与格式本身有关，也与网格比有关。书 §2.4 的数值实验（图
2.11）用 Lax–Friedrichs 格式（第 07 章正式介绍）解对流方程：λ = 0.9、
1.0 时计算结果与解析解相符，λ = 1.1 时解出现振荡并随计算时间增长。
本教程把它复现为数字（Julia 通道 `examples/julia/04_ccs.jl`）：

```julia
gsq(x) = (0.25 < x < 0.75) ? 1.0 : 0.0   # 方波脉冲（书的实验形态）
for lam in (0.9, 1.0, 1.1)
    u = advect(:lf, gsq, lam, 0.02, 40)
    println("  lambda = ", lam, "  max|u| after 40 steps = ", round(maximum(abs.(u)), digits=4))
end
```

实测：λ = 0.9 与 1.0 时幅值恰好保持在 1.0（|G| ≤ 1 的直接表现）；
λ = 1.1 时 40 步后幅值 7.37 并持续增长——**稳定性条件就是格式的
生命线**。

## 4.4 Lax 等价定理

**定理 2.1（Lax 等价定理，1953）**：给定一个**适定的线性初值问题**
（含周期边界条件的初边值问题）以及与其**相容**的差分格式，则

    差分格式的稳定性 ⟺ 差分格式的收敛性。

三个前提缺一不可：①初值问题（或周期边值）；②适定；③线性——非
线性问题没有这么简洁的关系。定理的价值在于**转移劳动**：直接证明
收敛性一般很困难，而稳定性有许多可操作的判据（第 05 章起）。此后
本书（与本教程）分析一个格式的例行三问是：**相容吗？（代入 Taylor
展开）稳定吗？（von Neumann/矩阵/能量法）收敛阶多少？（相容阶 +
Lax 定理）**

## 4.5 机器验证

### 稳定性的本义：扰动传播实验

稳定性定义的对象是**误差**，最直接的数值实验就是注入扰动、观察
其命运（Julia，`examples/julia/04_ccs.jl`）：

```julia
# 取 θ=π/2 的网格波型扰动 δ⁰_j = ε·sin(πj/2)
# （FTCS 增长因子的峰所在：|G(π/2)|=√(1+λ²)；
#   注意中心差分把 Nyquist 模式 (−1)^j 打到 G=1，峰不在 θ=π）
u = [eps0 * sin(pi * (j - 1) / 2) for j in 1:J]
...
grow_ftbs = perturb_growth(:ftbs, lam, h, n)
grow_ftcs = perturb_growth(:ftcs, lam, h, n)
@assert grow_ftbs < 1.0e-3 "稳定格式应压缩扰动（|G|=0.825 per step）"
@assert grow_ftcs > 100.0 "不稳定格式应指数放大（|G|=sqrt(1+lam^2)=1.28 per step）"
```

50 步后实测：迎风格式把 θ = π/2 的扰动压缩到初值的 6.17×10⁻⁵
（理论 0.825⁵⁰ = 6.6×10⁻⁵，吻合到第三位）；FTCS-对流把它放大
1.72×10⁵ 倍（理论 1.28⁵⁰ = 2.2×10⁵ 同量级）。注释里的坑值得记
住：**中心差分的 Nyquist 模式 (−1)ʲ 增长因子是 1 而非峰值**——
因为 (j±1) 与 j 反号，中心差分恰好取到两个同号邻居之差为零。
不稳定格式的增长峰在 θ = π/2。这类"想当然选扰动模式"的坑只有
机器断言能当场抓住。

### 依赖域错配：书 §2.3 论证的数值版

顺风格式不收敛的论证可以在机器上完整复盘。取 x* = 0.6、T* = 0.4、
a = 1：真解依赖 g(0.2)；FTFS 的依赖点集是 {0.6, 0.62, …, 1.1}（右
侧），永远不读 0.2。取两组初值：g₁ = 平滑脉冲，g₂ = g₁ + 0.2 处的
单位脉冲：

```julia
gbump(x) = exp(-((x - 0.2) / 0.01)^2)
g1(x) = exp(-100 * (x - 0.5)^2)
g2(x) = g1(x) + gbump(x)
...
u1 = advect(:ftfs, g1, 0.8, h, nst)
u2 = advect(:ftfs, g2, 0.8, h, nst)
...
@assert ev1 + ev2 > 0.9 "两组真解相差 ≈1 而 FTFS 给出同一个数：不可能同时收敛"
```

对 g₁ 的误差 e₁ 与对 g₂ 的误差 e₂ 满足 e₁ + e₂ ≥ |真解₂ − 真解₁| −
|u₁ − u₂| ≈ 1——**无论 h 多小，两组误差之和压不下去**，不可能同时
收敛。实测 e₁ 在 h = 0.04 → 0.005 加密过程中从 5.5 涨到 452/204：
不稳定的顺风格式把采样数据的网格尺度分量按 (1+2λ)ⁿ 放大，数值本
身就是不收敛的证词。

### 条件不可省 + 收敛阶组合

FTCS 热传导：r = 0.25 时误差 1.5×10⁻⁵（O(h²)），r = 0.6 时误差
10⁸（爆炸）——书 §2.3 收敛性证明里"2r ≤ 1 不可省略"的数值版。

BTCS 则展示**观测收敛阶 = 精度组合**：截断误差 O(τ) + O(h²)，τ 与
h 的耦合方式决定观测阶。τ = h 时误差比 1.93（一阶）；τ = 5h² 时
误差比 3.98（二阶）。做收敛性实验前先想清楚 τ(h) 怎么取，是数值
实验设计的必修课。

### Prolog：Lax 三问协议引擎

Prolog 通道（`examples/prolog/04_ccs.pl`）把 Lax 等价定理做成
规则引擎：

```prolog
% ---------- Lax 协议 ----------
lax(S, convergent) :-
    scheme(S, Prob, _, _, Stab),
    problem(Prob, linear, wellposed),
    consistent(S),
    stable_kind(Stab).
lax(S, not_convergent_guaranteed) :-
    scheme(S, Prob, _, _, unstable),
    problem(Prob, linear, wellposed),
    consistent(S).
```

查询结果：ftbs / lf / ftcs_heat / btcs_heat 判 convergent；ftcs_
advection / ftfs / richardson（相容但不稳定）判 not_convergent_
guaranteed；navier_stokes（非线性）查无结论——定理边界之外。另
外实现了书 (2.11) 的二项式误差账：迎风格式上交替符号初值误差的
放大率 (1+2aλ)ⁿ（aλ = 0.5 时 n = 9 得 512、n = 20 得 10⁶+）。

## 4.6 要点回顾

1. 截断误差 = 光滑解代入格式的残差；主部给出 (τ, h) 的精度阶；
   相容性 = 截断误差 → 0，是格式的底线。
2. 收敛性直接证明难：顺风格式靠依赖域错配证不收敛；FTCS 热传导
   靠误差方程 + 系数非负放大证收敛（条件 r ≤ 1/2 不可省）。
3. 稳定性 = 初始误差传播受控（‖εⁿ‖ ≤ K‖ε⁰‖）；它与格式和网格比
   都有关（LF：λ ≤ 1 稳、λ > 1 增长）。
4. Lax 等价定理：适定线性初值问题 + 相容格式下，稳定 ⟺ 收敛。
   例行三问从此改为：相容？稳定？几阶？
5. 数值实验三坑：扰动模式要选在增长因子的峰上（Nyquist ≠ 峰）；
   不稳定格式的数值被网格尺度分量支配；收敛阶取决于 τ(h) 耦合。
