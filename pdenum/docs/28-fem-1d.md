# 28 一维有限元：线性元

**对应书第 7 章 §1（单元剖分及试探函数空间、有限元方程的形成、
数值例子，式 (1.1)–(1.3 节)）。**

---

## 28.1 有限元 = 变分原理 + 分片多项式基

古典变分方法（27 章）用整体光滑基（幂、三角函数），对一般区域
难以构造。**有限元方法**（书 §7 开篇）的突破在于：基函数与**区域
剖分**绑定——

- 剖分 [a,b] 为单元 e_i = [x_{i−1}, x_i]；
- 试探函数空间 U_h = {分片线性、整体连续的函数}——维数 N+1；
- 基函数取**hat 函数** φ_i：节点 i 取 1、相邻节点取 0、线性过渡
  （书图 7.1）。

系数 c_i 就是 u_h(x_i) 的近似值——有限元**兼具**变分法（近似解析
解）与差分法（节点值）的特点，且对复杂区域、非均匀网格天然适应。

## 28.2 单元装配

书 §1.2 的流程（以 −(pu′)′ + qu = f、Robin 端点 p u′(b) + αu(b) = g
为例）：

**单元刚度与载荷**（局部基 φ_L = 1−ξ、φ_R = ξ，参考单元 [0,1]）：

    k^{(e)}_ab = ∫_e (p φ_a′φ_b′ + q φ_aφ_b)dx，
    f^{(e)}_a = ∫_e f φ_a dx。

p = q = 1 时闭式：k = (1/h)[[1,−1],[−1,1]] + (h/6)[[2,1],[1,2]]、
载荷 (h/6)[2f_L + f_R, f_L + 2f_R]（线性 f 精确）。

**局部 → 整体**：单元 e 的左/右局部基映射到全局节点 e−1、e，
贡献**累加**进总刚 K、总载荷 F。内点行 [−1/h+h/6, 2/h+2h/3,
−1/h+h/6]——与 25 章 hat 基 D 的闭式**逐字相同**（同一件事的两种
说法）。

**边界**：Robin 项 αu(b)v(b) 加在 K_{NN}、gv(b) 加在 F_N；Dirichlet
u(0) = 0 划去行列。

## 28.3 机器验证

### 装配 + 求解 + 收敛阶

Julia（`examples/julia/28_fem1d.jl`）完整装配（含 Robin）：

```julia
ke = (pfun((xe + xf) / 2) / h) * [1 -1; -1 1] + (qfun((xe + xf) / 2) * h / 6) * [2 1; 1 2]
fe = (h / 6) * [2 * ffun(xe) + ffun(xf); ffun(xe) + 2 * ffun(xf)]
# Robin 边界（x = 1，节点 N）：D 加 α u(b)v(b)，F 加 g v(b)
K[N + 1, N + 1] += alpha_robin
F[N + 1] += g_robin
```

制造解 u = sin πx（f = (π²+1)sinπx、α = 2、g = −π）：N = 40 节点误差
6.8×10⁻⁴；h → h/2 误差比 **3.999**——节点二阶收敛。能量（H¹ 半范）
在单元中点采样的比 3.996（中点对线性插值的导数恰好超收敛，采样点
选择影响观测阶——文档如实记录）。

单元刚度闭式核对：h = 0.1 时 [10.0333, −9.9833] = 1/h + h/3 与
−1/h + h/6 **逐位一致**。

Fortran 通道坑账（经典）：局部-整体映射 `K(e-1+a, …)` 是 **Julia
1 基**的正确式；照搬到 Fortran **0 基**数组上整体错位一格——装配
出错误方程（残差 2.26），改为 `K(e-2+a, …)` 后误差 6.8×10⁻⁴ 与
Julia 一致。多通道对照在这里直接抓了一个"看似合理"的索引移植 bug。

Prolog（`28_fem1d.pl`）把局部-整体映射、单元闭式、装配行做成规则
引擎（同样修正 0 基映射）。Lean（`Ch28Fem1d.lean`）：单元刚度的
有理恒等式 + 装配对角 2/h + 2h/3 的代数核。

## 28.4 要点回顾

1. 有限元 = 变分原理（Galerkin）+ 分片多项式 hat 基；未知量的
   物理意义是节点值。
2. 装配协议：单元闭式 → 局部/整体映射 → 累加 → 边界修正 →
   划行求解。内点行与 25 章 hat 基 D 闭式同一。
3. Robin 边界在变分形式中自动进入 K、F（一个对角元 + 一个载荷项）。
4. 索引移植陷阱：1 基 ↔ 0 基的局部-整体映射差一，多通道对账是
   最好的杀虫剂。
