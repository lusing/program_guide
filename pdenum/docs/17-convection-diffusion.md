# 17 对流扩散方程的差分格式

**对应书第 4 章 §3（中心显式、修正中心显式、迎风差分、Samarskii
格式、指数型差分格式、隐式格式，式 (3.1)–(3.7 节)。**

---

## 17.1 中心显式：双条件稳定

对流扩散方程 u_t + a u_x = ν u_xx（书 (3.1)）。时间前差 + 空间中心
（书 (3.3)）：

    (u_j^{n+1} − u_jⁿ)/τ + a(u_{j+1}ⁿ − u_{j−1}ⁿ)/2h =
        ν(u_{j+1}ⁿ − 2u_jⁿ + u_{j−1}ⁿ)/h²。

增长因子 G = 1 − 2μ(1−cosθ) − iλsinθ（λ = aτ/h，μ = ντ/h²），
|G|² ≤ 1 的推导（书 §3.1）给出**两个条件**（(3.4)(3.5)）：

    **2μ ≤ 1 且 λ² ≤ 2μ**。

第一个是纯扩散的 FTCS 条件；第二个说对流项的存在进一步压时间步长。
对流占优（a ≫ ν，μ ≪ λ）时 λ² ≤ 2μ 极难满足——中心格式在实用中
几乎不可用。

## 17.2 修正中心与迎风：人工扩散的艺术

**修正微分方程**视角（书 §3.2）：中心格式等价于在求解

    u_t + a u_x = [ν + h²(16μ − λ²)/(12τ)]u_xx + …

扩散系数被**人工修改**了。对流占优时增量为负（反扩散）——振荡之源。

**迎风格式**（书 §3.3）：对流项用单侧差分（按 a 的符号选方向）+
扩散中心差。它等价于中心格式 + **人工扩散 |a|h/2**——恒单调（解不
产生新的极值），代价是把边界层多抹宽 O(h)。**Samarskii 格式**给
人工扩散乘个 <1 的因子，减小抹平。

**指数型格式**（书 §3.5）：在定态格子问题（−a u_x + ν u_xx = const）
上取**精确解**为形状函数——格点值用 exp(±pe)（pe = ah/ν 为网格
Peclet 数）的精确转移。对任何 pe 都单调且精确刻画边界层。

## 17.3 网格 Peclet 数：单调性的门槛

定态问题 −a u_x + ν u_xx = 0 的三点格式解单调 ⟺ **pe = ah/ν ≤ 2**
（中心格式的特征根在 pe > 2 时变号）。迎风格式的有效 Peclet 数是
pe/(1+pe) < 2 恒成立——单调无条件。这是"对流占优问题要用迎风/
指数型"的定量表述。

## 17.4 机器验证

### 稳定双条件与单调性

Julia 通道（`examples/julia/17_convection_diffusion.jl`）：

```julia
@assert central_cd(0.6, 0.4, 400) < 1.001 "λ²=0.36 ≤ 2μ=0.8 ≤ 1 应稳定"
@assert central_cd(0.6, 0.15, 400) > 1.01 "λ²=0.36 > 2μ=0.3 应不稳"
```

时间推进的双条件逐侧验证。定态三点递推（解三对角）看单调：

```julia
is_monotone(u) = all(d -> d >= -1e-12, diff(u)) || all(d -> d <= 1e-12, diff(u))
```

pe = ah/ν = 2.5（J = 8）时：**中心格式解振荡**（差分出现符号翻转），
**迎风格式解单调**；pe = 0.4（J = 50，单调区）时中心格式误差
0.0049 vs 迎风 0.063——**单调区内中心格式精确 13 倍**（迎风的人工
扩散代价可见）。

实验自纠两笔：①精确解公式第一版写成 e^{Pe(1−x)}（应为 e^{Pe·x}，
边界层在 x=1）——"指数型精确"的对账成了同错对照，被 pe=1 误差全为
1.0 的反常逼出；②单调判据第一版只查 diff ≥ 0（把单调**递减**判成
非单调）——改为"无符号翻转"判据。

### Lean：双条件 ⟹ 耗散括号非负

Lean 通道（`Ch17ConvectionDiffusion.lean`）证明 |G|² ≤ 1 的代数核：
耗散括号 B(C) = 4μ − 4μ²(1−C) − λ²(1+C) 关于 C 仿射，故为**两端点
的凸组合**：

```lean
have hconv : 4 * mu - 4 * mu ^ 2 * (1 - C) - lam ^ 2 * (1 + C)
    = ((1 + C) / 2) * (4 * mu - 4 * mu ^ 2 * (1 - 1) - lam ^ 2 * (1 + 1))
    + ((1 - C) / 2) * (4 * mu - 4 * mu ^ 2 * (1 - (-1)) - lam ^ 2 * (1 + (-1))) := by
  ring
```

B(1) = 4μ − 2λ² ≥ 0（λ² ≤ 2μ）、B(−1) = 4μ − 8μ² ≥ 0（μ ≤ 1/2），
权重非负 ⟹ B ≥ 0——书 §3.1 的不等式推导浓缩为凸组合一步。（坑账：
Lean 标识符不能用 λ——保留字，全文件改写为 mu/lam。）

Prolog 通道（`17_convection_diffusion.pl`）规则库：双条件判定、
pe 单调阈、迎风有效 Peclet pe/(1+pe) 恒 < 2、指数型格子精确事实。

## 17.5 要点回顾

1. 中心显式的双条件 2μ ≤ 1 ∧ λ² ≤ 2μ：对流占优时几乎不可满足。
2. 迎风 = 中心 + 人工扩散 |a|h/2：恒单调，代价 O(h) 抹宽；Samarskii
   折中；指数型对定态格子精确。
3. 网格 Peclet pe = ah/ν 是单调性的旋钮：中心格式 pe ≤ 2、迎风恒
   单调（有效 pe/(1+pe)）。
4. 凸组合论证：仿射线函数在区间上的最值在端点——稳定条件的代数
   证明因此只需检查两个端点。
