# 31 变分差分格式与抛物型有限元

**对应书第 8 章 §1–§2（基于变分原理的差分格式、抛物型方程的有限
元方法）。**

---

## 31.1 变分原理列差分格式

前几章的差分格式都从**微分方程**出发（Taylor 展开/积分方法）。书
§8.1 给出另一条路：从 **Galerkin 变分问题**出发，用 hat 基直接得到
差分方程——对一维自伴问题 −(p u′)′ + q u = f（书 (1.1)）：

- 剖分 + hat 基 φ_k（内部节点）；
- Galerkin 内积 + 分部积分（书 (1.4)(1.5)）；
- 系数 p 在单元上取**平均** p̄（书 (1.6)）；
- 得到的三点格式与 28 章**有限元装配完全一致**。

变分差分 = 有限元的另一种说法：同一条 Galerkin 路线，只是书在这里
强调它"产生差分格式"的视角（对变系数、间断系数，自动给出正确的
界面系数——正是 18 章调和平均的出处）。

## 31.2 抛物型方程的有限元

对 u_t = u_xx 的**半离散**（空间 FEM、时间连续）：

    M du/dt = −K u + F(t)

其中 M（**质量矩阵**，hat 内积 (h/6)[1,4,1]）与 K（刚度）都是装配
产物。**全离散**：对时间用差分——

- 向后 Euler-Galerkin / **Crank–Nicolson-Galerkin**：
  (M + τ/2·K)uⁿ⁺¹ = (M − τ/2·K)uⁿ——**无条件稳定**（θ = 1/2）；
- **质量集中**（lumping）：把 M 的行和放到对角（M_lump = h·I），
  方程组退化为对角——显式化，但精度降为差分格式。

## 31.3 机器验证

### 变分差分：制造解对账

−((1+x)u′)′ + u = f（p = 1+x），制造解 sin πx。闭式源项（注意
−(pu′)′ = −πcos + (1+x)π²sin 的**符号**——初版正负写反，被 3.996
的收敛比断言逼出修正）：Julia（`examples/julia/31_var_diff.jl`）：

```julia
# -(p u')' = -p'u' - p u'' = -pi cos + (1+x) pi^2 sin（p' = 1）——pi cos 项取负号
f31(x) = (1 + x) * pi^2 * sin(pi * x) - pi * cos(pi * x) + sin(pi * x)
```

实测 err(20) = 2.2×10⁻³、err(40) = 5.4×10⁻⁴、比值 **3.996**——
变分差分 O(h²)。

### CN-Galerkin：大时间步 + 质量矩阵

τ = h（等效网格比 r = τ/h² = 1600，一切显式格式的死区）：
一致质量 CN-Galerkin 误差 4.3×10⁻⁴、集中质量 3.5×10⁻⁴——都稳定
（无条件稳定性）。时间二阶：τ → τ/2 误差比 3.879。

**坑账**：两种质量矩阵在本例（纯模式初值）下精度几乎相同——
"集中质量精度略低"的直觉不成立于单一模式数据，断言改为"差异不
显著"如实记录。

## 31.4 要点回顾

1. 变分差分与有限元装配是同一件事：Galerkin + hat 基 + 分部积分；
   对变系数/间断系数自动给出守恒界面系数。
2. 抛物 FEM 半离散是 ODE 系统 M u̇ = −Ku + F；CN-Galerkin 无条件
   稳定、时间二阶。
3. 质量集中把 M 变对角（显式化），代价是失去 Galerkin 最优性；
   单模式数据下两者精度差异不显著。
