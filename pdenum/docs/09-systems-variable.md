# 09 一阶方程组与变系数双曲方程

**对应书第 3 章 §2（一阶线性常系数方程组：LF/LW/迎风）与 §3（变系数
方程及方程组）。**

---

## 9.1 方程组的双曲性与特征形式

一阶常系数方程组 u_t + A u_x = 0（u ∈ ℝᵖ，书 (2.1)）：

**定义 2.1**：A 的特征值全实且可对角化（∃S, S⁻¹AS = Λ 对角）⟹
**双曲型**；A 对称 ⟹ 对称双曲型；特征值两两相异 ⟹ 严格双曲型。

对角化后令 w = S⁻¹u 得**特征形式**：每个分量 w⁽ᵐ⁾ 满足独立的
对流方程 w⁽ᵐ⁾_t + λₘ w⁽ᵐ⁾_x = 0（λₘ 为 A 的特征值）——方程组
解耦成 p 个标量输运。这是构造迎风格式的钥匙。

## 9.2 三个格式的推广

**LF（书 (2.3)）**：把标量 LF 中的 a 换成矩阵 A：

    u_j^{n+1} = ½(u_{j+1}ⁿ + u_{j−1}ⁿ) − (λ/2)A(u_{j+1}ⁿ − u_{j−1}ⁿ)。

增长矩阵 G = cos(kh)·I − iλsin(kh)·A，特征值
μₘ = cos(kh) − iλₘ sin(kh)：|μₘ|² = 1 − (1−λ²λₘ²)sin²(kh)。
用 S 把 G 对角化（一致有界的相似变换，第 2 章定理 3.5），稳定条件

    **λ·max_m|λₘ| = λ·ρ(A) ≤ 1**（书 (2.4)）。

**LW（书 (2.5)）**：同样推广，含 λ²A²/2 的修正项，稳定条件同 (2.4)。

**迎风（书 (2.8)）**：不能直接换入（特征值可正可负，方向各异）。
先化特征形式，每个分量按 λₘ 的符号选一侧差分；写回原变量得到
紧凑形式（书 (2.7) 式的矩阵版）：

    u_j^{n+1} = u_jⁿ − (λ/2)A(u_{j+1}ⁿ − u_{j−1}ⁿ)
                + (λ/2)|A|(u_{j+1}ⁿ − 2u_jⁿ + u_{j−1}ⁿ)，

其中 |A| = S diag(|λₘ|) S⁻¹。增长因子
μₘ = 1 − iλλₘsin(kh) + |λλₘ|(cos(kh) − 1)，
|μₘ|² = 1 − 4|λλₘ|(1−|λλₘ|)sin²(kh/2)——稳定条件同为 λρ(A) ≤ 1。

## 9.3 变系数：特征线弯曲、能量法与冻结系数

变系数方程 u_t + a(x,t)u_x = 0 的特征线 dx/dt = a(x,t) 是**曲线**，
解仍沿特征线为常数。差分格式的推广直白（LF 把 aⁿ = a(x_j,t_n) 代入、
迎风按 a 的**符号**逐点选方向，书 (3.4)(3.8)），但分析工具要换：

- **能量不等式法**（严格，第 06 章的凸性内核）：条件 (3.5)
  max|a|λ ≤ 1 加上 (3.6) sup|∂a/∂t| ≤ M，得稳定性。
- **冻结系数法**（实用、非严格）：把 a(x_j, t_n) 在每点当常数看待，
  用 Fourier 方法得条件 |a|λ ≤ 1，再对全体格点取最大：
  **max_{x,t}|a(x,t)|·λ ≤ 1**（书 (3.7)）。实际计算中最常用。

变系数方程组的 LW 还要注意 A = A(x) 时出现 A_{j+1/2} 的中途取值
（书 (3.11)）——系数与解耦合使推导"比较麻烦"，这正是迎风格式在
变系数世界里更受欢迎的原因。

## 9.4 机器验证

### 声学方程组：特征形式的精确解与三格式对账

取 p_t + u_x = 0、u_t + p_x = 0（A = [[0,1],[1,0]]，特征值 ±1，
特征变量即 **Riemann 不变量** w± = p ± u）。初始 p = g(x)、u = 0
时 w± = g，精确解是两个反向行波（Julia，`09_systems.jl`）：

```julia
function exact_acoustics(x, t, gfun)
    gm = gfun(((x - t) % 1.0 + 1.0) % 1.0)
    gp = gfun(((x + t) % 1.0 + 1.0) % 1.0)
    (0.5 * (gm + gp), 0.5 * (gm - gp))
end
```

三格式在 h = 0.01、λ = 0.8、T = 0.5 的最大误差：特征迎风 0.0859、
系统 LF 0.1665、系统 LW **0.0108**——排序与标量情形一致（LF 耗散
最重，LW 二阶最准）。收敛阶：系统迎风 1.93（一阶）、系统 LW
3.888（二阶）。这里有两笔被机器断言抓住的实验设计账：**收敛测量
要用宽脉冲初值**（窄高斯在粗网格上欠分辨，假性降阶）和**结束时间
按实际步数对账**（nst 取整偏差会把二阶污染成一阶——08 章同款坑）。

### 变系数：特征线核对与冻结系数条件

变系数 a(x) = 1 + 0.5sin(2πx)（恒正，max = 1.5）。迎风格式按
a(x_j) 的符号逐点选方向；"精确解"由特征线给出：从 (x*, T) 用 RK4
**反向**积分 dx/dt = a(x) 回到 t = 0 的足点 x₀，u(x*,T) = g(x₀)：

```julia
u = varcoef_upwind(h, tau, 0.5)             # tau 使 max(a)·λ = 0.6
for jstar in [round(Int, 0.3 / h) + 1, ...]
    x0 = char_back((jstar - 1) * h, 0.5, 2000)
    maxerr = max(maxerr, abs(u[jstar] - g(x0)))
end
@assert maxerr < 0.05 "变系数迎风应沿特征线核对"
```

三个探针点误差最大 0.0054——差分解确实收敛到"沿弯曲特征线传输"
的真相。违反冻结系数条件（max(a)·λ = 1.3 > 1）时长积分后
max|u| = 1.2×10⁶——超界区虽只在 a ≈ 1.5 的窄带，增长照样积累
（实验设计注记：局部超界的增长要跑足够长时间才可见，第一版只跑到
T = 0.5 时误差被截断项掩盖，是被断言逼着加长积分才发现的）。

Python 通道（`09_systems.py`）全部数字与 Julia 逐位一致（0.0859 /
0.1665 / 0.0108；1.930 / 3.888；0.0054；1.212e6）。

## 9.5 要点回顾

1. 方程组双曲性 ⟺ A 实特征值 + 可对角化；特征形式解耦成 p 个
   标量对流（Riemann 不变量是声学方程的特征变量）。
2. LF/LW 直接把 a 换成 A；稳定条件 λ·ρ(A) ≤ 1；迎风必须走特征
   形式（各特征方向独立选边），矩阵形式用 |A|。
3. 变系数：特征线弯曲、解仍沿特征常数；严格分析用能量法，日常
   用冻结系数法（max|a|·λ ≤ 1）。
4. 实验设计：收敛测量初值要充分分辨；结束时间按实际步数对账；
   局部超界的增长需要足够积分时间显形。
