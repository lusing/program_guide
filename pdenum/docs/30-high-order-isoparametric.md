# 30 高次插值与等参元

**对应书第 7 章 §3（一维 Lagrange/Hermite 高次插值、二维三角形二次/
三次插值与面积坐标、矩形双线性/双二次/Hermite 元、等参数单元，
式 (3.1)–(3.4 节)）。**

---

## 30.1 为什么要高次

线性元每单元 2（一维）/3（三角形）自由度、C⁰ 连续、O(h²) 节点精
度。提高精度的两条路：加密网格（h 收敛）或**提高次数**（p 收敛）。

**一维 Lagrange 二次元**（书 3.1.1）：单元加中点，基函数在参考元
[−1,1] 上为

    L₁ = ξ(ξ−1)/2，L₂ = 1−ξ²，L₃ = ξ(ξ+1)/2，

三自由度，节点精度升到 **O(h³)**。

**一维 Hermite 三次元**（书 3.1.2）：自由度取**节点值 + 节点导数**
（各 2），基为两点三次 Hermite 多项式 H₀₀、H₁₀ 等——**C¹ 连续**，
是双调和方程（需要 ∫ΔuΔv 的 C¹ 元）的标准配置。

## 30.2 二维高次元

**三角形二次元**（书 3.2.2）：6 节点 = 3 顶点 + 3 边中点，基用
面积坐标（29 章）：

    顶点基 N_i = L_i(2L_i − 1)，边中点基 N_{ij} = 4L_iL_j。

**三次元**（3.2.3）：10 节点（再加形心）。**矩形双线性元**（3.3.1）：
张量积基 N(ξ,η) = Nˣ(ξ)Nʸ(η)，4 节点。**双二次**（3.3.2）：9 节点。

## 30.3 等参元

**等参数**（书 3.4）：**几何映射与未知量插值用同一组基**——

    x(ξ,η) = Σ N_i(ξ,η) x_i，u_h(ξ,η) = Σ N_i(ξ,η) u_i。

曲边区域：给边加中点节点，几何映射本身是二次的——**曲边单元**
精确贴合边界。Jacobi 矩阵由基导数与节点坐标算出，单元刚度在参考
元上数值积分（Gauss 求积）。

## 30.4 机器验证

### 一维二次元：O(h³) 节点精度

同一问题（−u″+u = (π²+1)sinπx、Robin 端点）。二次 Lagrange 元
（参考元基 L₁、L₂、L₃ + Simpson 数值积分装配，Julia
`examples/julia/30_high_order.jl`）：

```julia
L1(ξ) = ξ * (ξ - 1) / 2; L2(ξ) = 1 - ξ^2; L3(ξ) = ξ * (ξ + 1) / 2
# 刚度：(2/h)∫L_i'L_j'，质量：(h/2)∫L_iL_j
```

N = 5/10 两档：误差 6.2×10⁻⁵ / 3.8×10⁻⁶，比值 **16.2 ≈ 2³**——
节点三阶收敛兑现（与 28 章线性元的比值 4 形成漂亮的 2ᵖ 对照）。

### 双线性矩形元系数表

参考正方形上 ∫∇N_i·∇N_j 的 4×4 闭式：首行
[2/3, −1/6, −1/3, −1/6]——教科书经典数字，双通道同表输出。

### 面积坐标与等参规则

Prolog（`30_high_order.pl`）：二次 Lagrange/Hermite 基表、面积坐标
取值规则（顶点 L_i=1、边中 ½、二次基 N_i = L_i(2L_i−1)、N_ij = 4L_iL_j）、
等参规则（几何与场同基、曲边需中边节点）。

## 30.5 要点回顾

1. 高次元增加每单元自由度换精度阶：二次 Lagrange O(h³)、三次
   Hermite O(h⁵) 且 C¹（双调和方程的门票）。
2. 二维三角形二次元 = 面积坐标的 L_i(2L_i−1) 与 4L_iL_j；矩形元
   = 一维基张量积。
3. 等参元：几何与场同基；曲边单元用二次几何映射。
4. p 收敛与 h 收敛正交：工程实践常固定 p = 1/2 自适应加密。
