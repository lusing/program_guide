# 03 差分格式的构造

**对应书第 2 章 §1"有限差分格式"（网格剖分、Taylor 展开建立差分
格式、积分方法、隐式差分格式，式 (1.1)–(1.16)）。**

---

## 3.1 网格剖分：先把连续问题搬到格点上

有限差分法的第一步是把求解区域剖分成**网格**。发展方程的初值问题
区域 {(x,t) : x ∈ ℝ, t ≥ 0} 用两族平行线剖分：

    x_j = j·h (j = 0, ±1, ±2, …),    t_n = n·τ (n = 0, 1, 2, …)，

h 称**空间步长**、τ 称**时间步长**，网格节点 (x_j, t_n) 简记 (j, n)。
同一时刻 t_n 上全体节点称为一个**层**。初边值问题的区域 [0,l]×[0,T]
剖分后，节点分为内点与边界点；椭圆问题的二维区域还要区分"四个邻点
都属于区域"的内点与边界节点。

差分法求解的未知量是网格函数 u_jⁿ ≈ u(x_j, t_n)。下面所有的"格式"
都是关于 u_jⁿ 的代数关系式。

## 3.2 Taylor 展开：差商代替微商

构造格式的最常用方法是对充分光滑的解 u 做 Taylor 展开（书 (1.5)、
(1.6)）：

    u(x_j, t_{n+1}) − u(x_j, t_n) = τ·u_t + O(τ²)
    u(x_{j+1}, t_n) − u(x_{j−1}, t_n) = 2h·u_x + O(h³)
    u(x_{j+1}, t_n) − 2u(x_j, t_n) + u(x_{j−1}, t_n) = h²·u_xx + O(h⁴)

于是有四条基本差商（时间向前、空间向后/向前/中心、二阶中心），
各自的逼近阶是：前差/后差 O(h)，中心差 O(h²)，二阶中心差 O(h²)。
机器上先"对表"这些阶数（Julia，`examples/julia/03_schemes.jl`）：

```julia
fwd_err(h) = abs((f(1 + h) - f(1)) / h - df(1))
bwd_err(h) = abs((f(1) - f(1 - h)) / h - df(1))
ctr_err(h) = abs((f(1 + h) - f(1 - h)) / (2h) - df(1))
sec_err(h) = abs((f(1 + h) - 2 * f(1) + f(1 - h)) / h^2 - d2f(1))

orders = [measured_order(fn, 1.0e-2, 5.0e-3) for fn in (fwd_err, bwd_err, ctr_err, sec_err)]
```

对 f = sin x 实测阶数 **1.002 / 0.998 / 2.0 / 2.0**——四条差商的
宣言全部兑现（Python 通道独立复算，逐位一致）。

## 3.3 对流方程的三个格式

用 τ 的一阶前差配上 h 的各种一阶差商，得到对流方程
u_t + a u_x = 0 的三个两层格式（书 (1.7)、(1.9)、(1.10)，设 a > 0，
网格比 λ = aτ/h）：

- **迎风格式（FTBS）**：空间**向后**差分——
  `u_j^{n+1} = u_jⁿ − λ(u_jⁿ − u_{j−1}ⁿ)`；
- **顺风格式（FTFS）**：空间向前差分——
  `u_j^{n+1} = u_jⁿ − λ(u_{j+1}ⁿ − u_jⁿ)`；
- **中心格式（FTCS）**：空间中心差分——
  `u_j^{n+1} = u_jⁿ − (λ/2)(u_{j+1}ⁿ − u_{j−1}ⁿ)`。

三个格式都只联系两个时间层、第 n+1 层可逐点直接算出，故都是
**两层显式格式**。迎风与顺风统称偏心格式。

哪个能用？机器先给出速览（同一周期平移问题，λ = 0.8）：

```julia
u_ftcs = advect(:ftcs, g0, 1.0, h, 6 * nst)
u_ftfs = advect(:ftfs, g0, 1.0, h, 6 * nst)
@assert maximum(abs.(u_ftcs)) > 10 "FTCS-advection 应不稳定"
@assert maximum(abs.(u_ftfs)) > 10 "FTFS(a>0) 应不稳定"
```

迎风格式的最大误差 0.0715 且随 h 减半而减半（**一阶收敛**）；
FTCS 与 FTFS 的振幅在若干步后越过 10——a > 0 时顺风与中心格式
**不稳定**，第 05 章的 von Neumann 分析将给出系统判据。直觉在这里
就能给出：a > 0 时信息沿特征线**向右**传播，(x_j, t_{n+1}) 的解依赖
**左边**的初值；迎风格式取左差分（u_{j−1}）恰好顺着依赖方向，顺
风格式背对依赖方向，中心格式两边各取一半但引入了虚假的对称性。

## 3.4 扩散方程的显式格式与积分方法

对扩散方程 u_t = a²u_xx，τ 前差配 h 二阶中心差（书 (1.11)）：

    (u_j^{n+1} − u_jⁿ)/τ = a²(u_{j+1}ⁿ − 2u_jⁿ + u_{j−1}ⁿ)/h²，
    即 u_j^{n+1} = u_jⁿ + r(u_{j+1}ⁿ − 2u_jⁿ + u_{j−1}ⁿ)，  r = a²τ/h²。

这也是两层显式格式。它还可以用**积分方法**（有限体积法）推导：
在矩形 [x_{j−1/2}, x_{j+1/2}] × [t_n, t_{n+1}] 上积分方程，左端对 t
积分直接算出，右端对 x 的导数用中矩形公式 + 中心差分代入，整理后
恰好得到 (1.11)——两种构造殊途同归。积分方法的真正威力在第 18 章
（间断系数）和第 23 章（一般区域）才展开。

数值对表（FTCS 在 r = 0.25 固定时）：误差随 h 减半除以 4——**二阶
收敛**；r = 0.6 时 200 步内振幅越界——**稳定性条件 r ≤ 1/2 的另一
侧**（第 05 章正式证明）：

```julia
e1 = heat_ftcs(2.0e-2, 0.25, 0.1)
e2 = heat_ftcs(1.0e-2, 0.25, 0.1)
@assert 3.5 < e1 / e2 < 4.5 "FTCS 热传导固定 r 时应 O(h^2)"
```

## 3.5 隐式格式与追赶法

时间用**向后**差分配空间二阶中心差（书 (1.14)），得到扩散方程的
**隐式格式**（BTCS）：

    −r·u_{j+1}^{n+1} + (1 + 2r)u_j^{n+1} − r·u_{j−1}^{n+1} = u_jⁿ。

新时间层上有三个未知量联立，不能逐点算出——须解三对角线性方程组。
加上离散边界条件后写为矩阵形式 A U^{n+1} = Uⁿ，A 严格对角占优，
方程组唯一可解，用**追赶法**（Thomas 算法）O(J) 工作量求解：

```julia
"""三对角方程组追赶法：a*u_{j-1} + b*u_j + c*u_{j+1} = d（a、c 为次对角向量）。"""
function thomas(a, b, c, d)
    n = length(b)
    cp = zeros(n); dp = zeros(n)
    cp[1] = c[1] / b[1]; dp[1] = d[1] / b[1]
    for i in 2:n
        m = b[i] - a[i] * cp[i - 1]
        cp[i] = c[i] / m
        dp[i] = (d[i] - a[i] * dp[i - 1]) / m
    end
    x = zeros(n); x[n] = dp[n]
    for i in n-1:-1:1
        x[i] = dp[i] - cp[i] * x[i + 1]
    end
    x
end
```

追（消去下对角）赶（回代），每步一次乘加，总工作量 3J−3 次乘除。
显式与隐式的分工从此定型：**显式省代数、受稳定性限制；隐式多解
方程组、换来大时间步长**。数值证据：BTCS 在 r = 5（显式格式早就
爆炸的区域）依旧稳定且保持二阶：

```julia
e1 = heat_btcs(2.0e-2, 5.0, 0.1)
e2 = heat_btcs(1.0e-2, 5.0, 0.1)
@assert ratio > 3.5 && ratio < 4.5 "BTCS 固定 r 时应 O(h^2)"
```

实测 h → h/2 误差比 3.975——r = 5 下的二阶收敛。

## 3.6 Lean：差商恒等式与模板特征恒等式

Lean 通道（`examples/lean/Pdenum/Ch03Schemes.lean`）把本章的分析
基础做成三条多项式恒等式与一条三角恒等式。前差商对二次多项式的
主项：

```lean
/-- 对 P(x) = x²：`(P(x+h) − P(x))/h = 2x + h`，即 `P'(x) + (h/2)P''(x)`。 -/
theorem forward_diff_quadratic (x h : ℝ) (hh : h ≠ 0) :
    ((x + h) ^ 2 - x ^ 2) / h = (2 * x + 1 * h) := by
  field_simp
  ring
```

二阶中心差商对三次多项式**精确**（`field_simp; ring` 闭核）、对
四次多项式误差主项 `(h²/12)·P⁗(x)`——这正是 00 章"五点格式对二次
调和函数精确"现象的一般解释：差分算子对低次多项式截断误差恒为零。

更重要的一条是**模板特征恒等式**——第 05、06、21 章共用的内核：

```lean
/-- 模板恒等式：`sin((j−1)θ) + sin((j+1)θ) − 2·sin(jθ)
= (2cosθ − 2)·sin(jθ)`。 -/
theorem stencil_eigen_identity (j θ : ℝ) :
    sin ((j - 1) * θ) + sin ((j + 1) * θ) - 2 * sin (j * θ)
      = (2 * cos θ - 2) * sin (j * θ) := by
  have hj1 : (j - 1) * θ = j * θ - θ := by ring
  have hj2 : (j + 1) * θ = j * θ + θ := by ring
  rw [hj1, hj2, Real.sin_sub, Real.sin_add]
  ring
```

任何形如 u_{j+1} − 2u_j + u_{j−1} 的三点模板作用在波型
sin(jθ) 上都退化为**乘一个数** 2cosθ − 2——这就是 von Neumann
分析（代入 e^{ijθ} 求增长因子）与矩阵法（求三对角矩阵特征值）
能算出同一个数的代数原因。证明只用了两角和差公式加 `ring`。

## 3.7 Prolog：判阶引擎与格式知识表

Prolog 通道（`examples/prolog/03_schemes.pl`）做两件事。判阶引擎
对任意表达式树数值测量差商阶（求值点直接平移 X±H）：

```prolog
dq_err(forward, E, DE, X, H, Err) :-
    ev_at(E, X, FX), ev_at(E, X + H, FXP),
    ev_at(DE, X, DFX),
    Err is abs((FXP - FX) / H - DFX).
```

四个方向的实测阶 1.002 / 0.998 / 2 / 2 与 Julia 通道一致。格式
知识表则把本章的构造性结论存为可查询事实：五个格式（ftbs / ftfs /
ftcs_advection / ftcs_heat / btcs_heat）的模板节点与 (τ, h) 精度阶、
相容性规则 `consistent(S) :- scheme(S,_,_,P,Q), P>0, Q>0`、迎风
方向规则（a > 0 取后差、a < 0 取前差）、追赶法工作量 3J−3——第 34
章的方法选择树将直接复用这张表。

## 3.8 要点回顾

1. 网格、层、网格函数是差分法的语言；格式 = 网格函数的代数关系。
2. Taylor 展开构造：τ 前差 + 各种空间差商；两层显式格式逐层推进。
3. 迎风格式顺依赖方向（a>0 取左差）一阶收敛；顺风与中心格式在
   a>0 时不稳定（第 05 章系统化）。
4. 积分方法（有限体积）与 Taylor 方法在模型问题上给出同一格式，
   在间断系数/复杂区域上更有力。
5. 隐式格式 BTCS 须解三对角方程组（追赶法 3J−3 工作量），换来
   无条件稳定——显隐之争贯穿全书。
6. 模板恒等式 `三点模板 × sin(jθ) = (2cosθ−2)·sin(jθ)` 是 von
   Neumann 分析与矩阵特征值分析的共同代数内核。
