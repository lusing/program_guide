# 18 变系数方程：Keller 盒式与有限体积法

**对应书第 4 章 §4（Taylor 级数展开方法、Keller 盒式格式、有限体积
法、间断系数问题、隐式方程的解法，式 (4.1)–(4.5 节)。**

---

## 18.1 变系数扩散：通量形式是正解

变系数扩散方程 u_t = ∂/∂x(k(x)·∂u/∂x) 的差分化有讲究：把 k 在
**界面** x_{j+1/2} 取值、写成**通量形式**（书 §4.1 的 Taylor 方法
收敛于此）：

    u_j^{n+1} = u_jⁿ + τ·[F_{j+1/2} − F_{j−1/2}]/h，
    F_{j+1/2} = k_{j+1/2}·(u_{j+1} − u_j)/h。

通量形式自动保证**守恒**（相邻格子的进出通量共用同一个界面值）。
k 光滑时 k_{j+1/2} 取中点平均即可；冻结系数稳定条件
max|k|·r ≤ 1/2。

## 18.2 Keller 盒式：把二阶降成一阶

**Keller 盒式格式**（书 §4.2）：把二阶方程写成**一阶方程组**
（u′ = v，v′ = …），在**每个格子**（box）上积分离散：未知量 u 在
格点、v 在半点（交错网格），中心差分天然二阶。优点：对变系数与
间断系数稳健（系数全部在格子中心取值）、对边值问题的第三类边界
处理自然、可推广到方程组。消去辅助变量 v 后与紧凑三点格式同阶。

## 18.3 有限体积与间断系数

**有限体积法**（书 §4.3）：在控制体上积分方程，界面通量是唯一
交换量——间断系数（k 在界面跳变）时，界面系数应取**调和平均**
（串联热阻的数学等价物）：

    k_{界面} = 2k_L·k_R/(k_L + k_R)，

它保证**通量连续**（物理界面条件）。用算术平均会破坏通量守恒、
给出错误的界面温度跳变。间断系数问题的差分方程是三对角的，追赶
法求解（书 §4.5）。

## 18.4 机器验证

### 光滑变系数：制造解对账

k(x) = 1 + 0.5x，制造解 u* = e^{−t}sin(πx)（源项 f = u*_t −
(k u*_x)_x 解析给出，Julia `examples/julia/18_variable.jl`）。中点
通量格式的收敛比 **4.004**——通量形式在变系数下保持二阶。

### 间断系数：调和界面 = 精确

k = 1（x < 0.5）、k = 10（x > 0.5）的定态问题 u(0)=0、u(1)=1。
精确解是两段线性（通量 q = 1/(0.5/1 + 0.5/10) = 1.818，界面值
u(0.5) = 0.909）。调和界面 FV：

```julia
kface(xf) = begin
    kl = kmat(xf - 1e-9); kr = kmat(xf + 1e-9)
    kl == kr ? kl : 2 * kl * kr / (kl + kr)
end
```

实测 J = 10/40/160 的最大误差全部为 **0.0**——精确解是分段线性
的，而 FV 的形状函数恰是分段线性，**格式解与精确解在格点上逐位
一致**。这是"有限体积 = 分段线性重构"的最干净演示。

### 盒式紧凑形式

−u″ + u = (1+π²)sin(πx) 的盒式（消去 v 后的三对角）收敛比 4.003
——二阶兑现（Python 通道同判）。

## 18.5 要点回顾

1. 变系数扩散务必写**通量形式**（界面系数），保守恒且二阶。
2. Keller 盒式：二阶降一阶组、格子（box）上积分、交错网格——对
   变系数/间断/方程组/第三类边界全面稳健。
3. 间断系数：界面调和平均保证通量连续；对分段线性解 FV 格点精确。
4. 差分方程三对角，追赶法是标配求解器。
