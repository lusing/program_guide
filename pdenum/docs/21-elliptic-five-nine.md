# 21 椭圆方程：五点、九点差分与极坐标

**对应书第 5 章 §1（五点差分格式、九点差分格式、极坐标下的差分格式，
式 (1.1)–(1.11)）。**

---

## 21.1 五点差分格式

Poisson 方程 Δu = f 在矩形区域上，对两个方向的二阶导数都用三点中
心差分（书 (1.4)）：

    (u_{i+1,j} − 2u_{i,j} + u_{i−1,j})/h² +
    (u_{i,j+1} − 2u_{i,j} + u_{i,j−1})/k² = f_{i,j}，

截断误差 O(h² + k²)。Laplace 方程（f ≡ 0）的内点公式退化为
"四邻平均"。第一类边界条件直接转移。书 §1.1 的例子（h = k = 1/3、
4 个内点、精确解 log((x+1)²+y²)）给出 4×4 线性方程组，解
0.634804 / 1.059993 / 0.798500 / 1.169821——本教程完整复现。

## 21.2 九点差分格式：四阶精度的代数代价

为提高精度，把对角点也拉进模板（书 §1.2）。引入平移算子表示，
对称和 S₁（四邻）、S₂（对角四点）的 Taylor 展开给出

    4S₁ + S₂ − 20u₀ = 6h²·Δu + (h⁴/2)·Δ²u + O(h⁶)。

用 Δu = f 消去并**把 Δ²u = Δf 也移到右端**：

    **4S₁ + S₂ − 20u₀ = 6h²·f + (h⁴/2)·Δf**（书 (1.7)），

截断误差 O(h⁴)。代价：右端要多算 Δf（对一般 f 是额外微分；对常
见解析 f 可闭式给出）。

## 21.3 极坐标格式

圆/环/扇形区域用极坐标（书 (1.8)：u_rr + u_r/r + u_θθ/r² = f）。
内点 (r_i, θ_j) 的差分（书 (1.10)）用**守恒形式**（乘 r 积分）：

    [(r_{i+1/2}u_{i+1} − (r_i + r_{i−1})u_i·? + r_{i−1/2}u_{i−1})/Δr²]/r_i
    + (u_{i,j+1} − 2u_{i,j} + u_{i,j−1})/(r_i²Δθ²) = f。

r = 0 处方程奇异，用有限体积在中矩形求积得到特殊公式（书 (1.11)），
等价于四邻 θ 平均。

## 21.4 机器验证

### 书例的逐位复现

Julia（`examples/julia/21_elliptic.jl`）组装 4×4 方程组（边界值取
精确解在网格线上的值）：

```julia
alpha = A \ b
book_vals = [0.634804, 1.059993, 0.798500, 1.169821]
for (k1, v) in enumerate(book_vals)
    @assert abs(alpha[k1] - v) < 5e-6 "书例 α$k1 与复现不符"
end
```

数值解与书表**全部吻合到 5×10⁻⁶**；与解析解（格点上 0.635989…）
差约 10⁻³——O(h²) 截断误差在 h = 1/3 下的可见规模。

### 五点 + SOR 的 O(h²) 与九点的 O(h⁴)

同一制造解 u = x² − y² + sin(πx)sin(πy)（Δu 闭式）：

- 五点 + 最优 SOR（ω = 2/(1+sin π/N)）：h → h/2 误差比 **4.004**；
- 九点（含 (h⁴/2)Δf 修正项）：误差比 **16.05**——四阶兑现。

九点的实现坑账两笔：①修正项初版写成 (h²/2)Δf（少一个 h），残差核
对（精确解代入离散方程）显示 O(h²) 而非 O(h⁴)，被相容性检查抓住；
②Δf 的符号（Δ²u 对 sin·sin 模式是 +4π⁴）也错了一次。两次都在
"残差 = 精确解代入"的例行核对下现形——椭圆格式的对账第一工具。

### 极坐标

圆域 Δu = 0、边界 cos 2θ：精确解 r²cos 2θ。守恒形式（(1.10)）+
r=0 四邻平均，Gauss–Seidel 收敛后误差 2.4×10⁻³（r > 0.1 区域）。
坑账：初版把 (r±Δr/2) 的通量除以 Δr² 而漏掉**除以 r_i**（守恒形式
是 (1/r)(r u_r)_r），误差 0.53 被抓。

Fortran（`21_five_point.f90`）：五点 + SOR 求解同一 Poisson 问题，
179 步收敛、误差 5.1×10⁻⁴。Lean（`Ch21Elliptic.lean`）：五点对二次
多项式精确（ring 恒等式）+ 九点展开第一步（模板恒等式组装 16cosθ +
4cos²θ）。Prolog：格式知识库（模板、精度阶、九点权 20/−4/−1、
极坐标结构）。

## 21.5 要点回顾

1. 五点格式：四邻平均 + 直接转移边界，O(h²)；书例 4 未知数可手算。
2. 九点格式：4S₁ + S₂ − 20u₀ = 6h²f + (h⁴/2)Δf，O(h⁴)——右端的
   Δf 修正是四阶的全部代价与全部来源。
3. 极坐标用守恒形式；r = 0 由有限体积导出四邻平均。
4. 对账工具：精确解代入离散方程看残差阶数（比直接跑收敛更早暴露
   实现错误）。
