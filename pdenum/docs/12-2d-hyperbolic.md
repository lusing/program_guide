# 12 二维双曲问题与分数步长法

**对应书第 3 章 §6（一阶双曲方程/方程组、隐式格式与 ADI 格式，
式 (6.1)–(6.22)）。**

---

## 12.1 二维 LF：稳定条件立刻变严

二维对流方程 u_t + a u_x + b u_y = 0（等步长 h）。LF 的直接推广
（书 (6.3)）：

    u_{i,m}^{n+1} = ¼(u_{i+1,m} + u_{i−1,m} + u_{i,m+1} + u_{i,m−1})ⁿ
                    − (λ/2)[a(u_{i+1,m} − u_{i−1,m}) + b(u_{i,m+1} − u_{i,m−1})]ⁿ。

代入二维波型 e^{i(k₁x+k₂y)} 得增长因子，|G|² 的上界（书 (6.4)）：

    **λ²(a² + b²) ≤ 1/2**。

对 a = b：λ·a ≤ 1/2——**比一维严一倍**（一维是 λa ≤ 1）。原因：
时间方向的"耗散预算"只有一份，两个空间方向都要分。维度越高越严，
这是多维显式格式的普遍规律。

## 12.2 分数步长法（LOD）：把二维拆成两个一维

**分数步长法**（书 (6.5)(6.6)，也称局部一维格式 LOD）：

    第一步（x 方向）：ũ = (I + D₁)uⁿ，
    第二步（y 方向）：u^{n+1} = (I + D₂)ũ，

其中 D₁、D₂ 是各自方向的一维差分算子。合成
u^{n+1} = (I + D₂)(I + D₁)uⁿ 与二维 LW (6.7) 比较：

- **精度**：D₁D₂ 交叉项恰好在 τ² 展开中重现交叉导数 u_xy——
  用一维 LW 组装的分数步长法是**二阶精度**；
- **稳定性**：总增长因子 G = G₂(θ₂)·G₁(θ₁)，两个一维因子的乘积
  各自 ≤ 1 ⟹ **稳定条件回到一维**：|a|λ ≤ 1 **且** |b|λ ≤ 1
  （书 (6.8)）。对 a = b = 1：λ ≤ 1——二维 LF 禁区的 λ ∈ (1/2, 1]
  全部解放。

## 12.3 隐式与 ADI：无条件稳定的二阶格式

- **隐式 BTCS（6.16）**：G = 1/(1 + iλ(asinθ₁ + bsinθ₂))，
  |G| < 1 无条件稳定；但二维隐式的系数矩阵是**宽带状**，直接解贵。
- **Crank–Nicolson（6.17）**：G = Π(1 − i·/2)/(1 + i·/2)，|G| = 1
  精确守恒——无条件稳定、二阶。
- **ADI（交替方向隐式，书 (6.18)(6.21)）**：每步拆成 x 隐 y 显、
  y 隐 x 显两个三对角解——**把宽带问题化为两次一维追赶**。
  LOD 隐式版 (6.18) 无条件稳定；Beam–Warming 二维格式 (6.20) 及
  其 ADI 实现 (6.21) 无条件稳定且二阶；δ-公式 (6.22) 是等价的
  省存量写法。

Strang 分数步长（书 §6.2 末）：L(τ/2)L₁(τ)L(τ/2) 的对称分裂保
二阶精度且各方向独立满足一维稳定条件。

## 12.4 机器验证

### 二维 LF 的稳定边界：先找对坏模式

数学自纠一次：初版以为坏模式是 Nyquist×Nyquist（(−1)^(i+j)），
实测它恰好 |G| = 1 不增长。数值扫描确认真正的增长峰在
**θ₁ = θ₂ = π/2（4 周期乘积模式）**，|G| = 2λ——书 (6.4) 的边界
λ = 1/2 精确复现（Julia，`examples/julia/12_2d.jl`）：

```julia
# 高斯脉冲 + 微小 4 周期乘积模式种子：增长峰在 θ₁=θ₂=π/2（|G| = 2λ），
# 纯光滑数据激发不出它，须显式播种（舍入迟早也会注入同形态噪声）
u = [(...) + 1.0e-8 * sin(pi * (i - 1) / 2) * sin(pi * (j - 1) / 2) ...]
...
@assert lf2d_run(0.45, 300) < 1.001 "二维 LF λ=0.45（λ²·2 < 1/2）应稳定"
@assert lf2d_run(0.55, 300) > 10 "二维 LF λ=0.55（λ²·2 > 1/2，|G|=2λ>1）应爆"
```

实测 λ = 0.45 稳（max 0.224）；λ = 0.55 时种子被放大到 13091——
边界两侧各就各位。

### LOD：禁区里的二阶收敛

x、y 各一维 LW 的分数步长在 λ = 0.8（二维 LF 的禁区）稳定
（max|u| = 0.973），对角平移的高斯脉冲问题**二阶收敛**：

```julia
e1 = lod_err(2.0e-2)
e2 = lod_err(1.0e-2)
@assert 3.2 < r < 4.6 "LOD-LW 应二阶"
```

实测误差比 4.019——稳定条件回到一维、精度保持二阶，两条宣言同时
兑现（Python 通道 4.019 逐位一致）。

这里有一笔值得入账的实现坑：周期域上对平移解的对账，**% 回绕会
选错周期像**——Python 把 −0.016 映到 0.984，误差瞬间假性放大到
0.96；Julia 的负数 % 保号只是侥幸蒙对。正确写法是最近周期距离
`d − round(d)`。双通道对账正是为了逼出这种"单通道看起来还行"的
错误。

### 二维 CN 的 |G| ≡ 1

对 (θ₁, θ₂, λ) 三重网格扫描 |G| = |(1−iα/2)/(1+iα/2)|·|(1−iβ/2)/
(1+iβ/2)|，与 1 的最大偏差 < 10⁻¹²——**精确守恒**（每个因子都是
单位模复数，乘积当然也是）。

## 12.5 要点回顾

1. 多维显式格式的稳定条件随维度变严：二维 LF 是 λ²(a²+b²) ≤ 1/2，
   坏模式在 θ₁ = θ₂ = π/2（不是 Nyquist）。
2. 分数步长法：一维算子串联，精度二阶、稳定条件回到各方向的一维
   条件——多维问题的标准解法。
3. 隐式无条件稳定但宽带贵；ADI 把它拆成两次三对角追赶——多维
   问题的另一个标准答案。
4. Crank–Nicolson 的 |G| ≡ 1：零耗散的代价是振荡不衰减（第 15 章
   热传导上会更细看）。
5. 实验坑：周期对账用 `d − round(d)` 取最近周期距离；坏模式先扫描
   再播种。
