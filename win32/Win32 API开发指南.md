# Win32 API 开发指南

> Win32 API 是 Windows 操作系统暴露给应用程序的官方 C 语言服务接口——不只是"窗口库"。它覆盖两大板块：窗口、消息、控件、GDI 等界面能力（被各代 UI 框架不断封装），以及进程、线程、同步、内存、文件等系统服务能力（**至今没有任何替代品**）。

本教程面向初学者，按依赖链组织为 12 章，全部示例可编译验证。
