# 第 9 章 日期时间与反馈控件

> **本章回答的问题**：Windows 日历弹出来给你选日期的控件怎么用？"某月某日加粗"的日状态是什么？动画控件为什么只能放**无声** AVI？工具提示明明不是我的窗口，鼠标消息怎么到它手里的？
>
> **前置章节**：第 8 章（输入控件族的消息套路）、第 21 章（`SYSTEMTIME` 的完整讲解——本章直接使用）。
>
> **你将做出什么**：一个"预约设置"面板（`examples/34_datetime_feedback`）：日期检出器 + 月历 + 动画 + 三种工具提示。

本章示例：`examples/34_datetime_feedback/main.cpp`（附 `demo.avi`）。

> 本章素材参考《Win32 开发人员参考库·第 4 卷》第 6/9/12/18/25 章的控件参考（日期与时间检出器、月历、动画、工具提示）。

## 9.1 时间与反馈的两对控件

| 控件 | 类名常量 | ICC 家族 | 定位 |
|------|---------|----------|------|
| 日期时间检出器 | `DATETIMEPICK_CLASSW` | `ICC_DATE_CLASSES` | 单行输入框，点开弹出月历选日期/时间 |
| 月历 | `MONTHCAL_CLASSW` | `ICC_DATE_CLASSES` | 整块日历，可多选、可给日期加粗 |
| 动画 | `ANIMATE_CLASSW` | `ICC_ANIMATE_CLASS` | 播放无声 AVI 剪辑（耗时操作的"活着的"指示） |
| 工具提示 | `TOOLTIPS_CLASSW` | `ICC_TAB_CLASSES` 等 | 悬停弹出的小黄条 |

前两个处理 `SYSTEMTIME`，后两个回答"操作进行中/这个按钮干什么"——都是小而独立的积木。

## 9.2 日期时间检出器（DTP）：一行搞定选日期

DTP（date and time picker）默认显示当前日期，点击右侧下拉箭头弹出一个月历。创建与读写：

```cpp
HWND dtp = CreateWindowExW(0, DATETIMEPICK_CLASSW, nullptr,
    WS_CHILD | WS_VISIBLE | DTS_SHORTDATEFORMAT,     // 也可 DTS_LONGDATEFORMAT / DTS_TIMEFORMAT
    20, 20, 180, 24, hwnd, (HMENU)(INT_PTR)IDC_DTP, hInst, nullptr);

SYSTEMTIME st = { 2026, 9, 3, 19 };                  // 年/月/星期/日（星期会被忽略）
SendMessageW(dtp, DTM_SETSYSTEMTIME, GDT_VALID, (LPARAM)&st);   // 写
SendMessageW(dtp, DTM_GETSYSTEMTIME, 0, (LPARAM)&st);           // 读（返回 GDT_VALID/GDT_NONE）
```

要点：

- **数据模型就是 `SYSTEMTIME`**（第 21 章的老朋友）——DTP 是它在 UI 层的标准编辑器。用户清空控件（`DTS_SHOWNONE` 样式时）后 `DTM_GETSYSTEMTIME` 返回 `GDT_NONE`，这个"无日期"状态要判；
- 变化通知是 `DTN_DATETIMECHANGE`（`WM_NOTIFY`，`NMDATETIMECHANGE` 里带着新值）；
- 显示格式用 `DTM_SETFORMAT` 给一个自定义格式串（`"yyyy-MM-dd HH:mm"`），语法与 `wcsftime` 同族。

参考库第 12 章还介绍了一个进阶特性——**回叫域（callback field）**：格式串里放一个自造字符（如 `X`），DTP 会在显示到该位置时发 `DTN_FORMAT`/`DTN_FORMATQUERY` 通知**问你要文本**。经典用法是把"今天星期几"或农历这类系统给不了的字段做成回叫域。初学知道机制即可。

## 9.3 月历：日状态与"加粗日"

月历控件独立成块使用时，最实用的能力是 **day state（日状态）**：给某些日期加粗——日历上标节假日、标有日程的日子。机制（参考库第 18 章）：

```cpp
HWND mc = CreateWindowExW(0, MONTHCAL_CLASSW, nullptr,
    WS_CHILD | WS_VISIBLE | MCS_NOTODAYCIRCLE,
    230, 20, 190, 160, hwnd, (HMENU)(INT_PTR)IDC_MC, hInst, nullptr);

// 选日期 / 读选择：
SYSTEMTIME st{};
SendMessageW(mc, MCM_SETCURSEL, 0, (LPARAM)&st);
```

加粗日的流程是**控件来问、你来答**：月历在每次需要重画前发 `MCN_GETDAYSTATE`（`WM_NOTIFY`），结构 `NMDAYSTATE` 告诉你"从哪个月起、要几个月"；你填一个 `MONTHDAYSTATE` 数组（每月一个 DWORD，第 n 位 = 1 表示该月第 n+1 日加粗）：

```cpp
if (nm->code == MCN_GETDAYSTATE) {
    NMDAYSTATE* ds = (NMDAYSTATE*)lParam;
    for (int i = 0; i < (int)ds->cDayState; ++i)
        ds->prgDayState[i] = (1u << 4) | (1u << 18);    // 每月 5 日、19 日加粗
    return TRUE;                                        // 已处理
}
```

两个配套细节：

- 需要几个月用 `MCM_GETMONTHRANGE` 问控件（可见区域通常跨 2~3 个月）；
- 选区变化通知是 `MCN_SELCHANGE`（注意没有"点确定"的概念——月历的选择是即时的）；多选要 `MCS_MULTISELECT` 样式 + `MCM_SETSELRANGE`。

DTP 与月历是一套：DTP 的下拉箭头弹出的就是内嵌月历——独立月历用在"日程面板"这种常驻场景。

## 9.4 动画控件：无声 AVI 的播放器

动画控件是资源管理器"搜索时飞动的放大镜"那一族 UI 的实现载体。参考库第 9 章把它的边界说得很清楚：**只能播放无声 AVI**（带音轨的文件直接打开失败），格式支持未压缩与 RLE8 压缩。

```cpp
#include <commctrl.h>   // ANIMATE_CLASSW

HWND anim = CreateWindowExW(0, ANIMATE_CLASSW, nullptr,
    WS_CHILD | WS_VISIBLE | ACS_CENTER | ACS_TRANSPARENT | ACS_AUTOPLAY,
    20, 200, 60, 44, hwnd, (HMENU)(INT_PTR)IDC_ANIM, hInst, nullptr);

SendMessageW(anim, ACM_OPENW, 0, (LPARAM)L"demo.avi");   // 或用宏 Animate_OpenW
SendMessageW(anim, ACM_PLAY, 3, MAKELONG(0, (WORD)-1));  // 播 3 遍，从头到尾
SendMessageW(anim, ACM_STOP, 0, 0);                      // 停（画面停在最后一帧）
```

要点速记：

- `ACS_AUTOPLAY`：打开即播；`ACS_CENTER`：帧在控件里居中；`ACS_TRANSPARENT`：把首帧左上角像素色当透明色融进背景；`ACS_TIMER`：不用内部线程、改用 `WM_TIMER` 驱动（避免线程时选它）；
- 播放发生在**后台线程**、不阻塞消息循环——这正是它适合"耗时操作进行中"提示的原因（配合第 17 章的 `PostMessage` 回传模式：工作线程干活，动画控件转圈）；
- 通知是 `ACN_START`/`ACN_STOP`，走的是 **`WM_COMMAND`**（`HIWORD(wParam)` 为通知码）——又一个不走 `WM_NOTIFY` 的特例（和第 8 章轨迹条并列的两个例外）；
- 播自己 exe 里的资源：`ACM_OPENW` 的 lParam 换成 `MAKEINTRESOURCEW(id)`（资源类型必须是 `"AVI"`）。示例用外部文件 `demo.avi`（本仓库用 ffmpeg 生成，避免引入资源编译步骤）。

现代替代提示：动画控件源自 Win95 时代；今天做"加载中"效果更常见的是 `PGM`/自绘或 Direct2D 帧动画（第 28 章），但它胜在零依赖、三行代码能用。

## 9.5 工具提示：一个"寄生"的顶层窗口

工具提示（tooltip）的机制与其他控件都不同：**它是一个寄生窗口**——平时不可见，鼠标在"工具"上悬停约半秒后弹出小黄条。它有自己的三步仪式（参考库第 25 章）：

```cpp
// ① 创建（顶层窗口样式，不是 WS_CHILD）
HWND tip = CreateWindowExW(WS_EX_TOPMOST, TOOLTIPS_CLASSW, nullptr,
    WS_POPUP | TTS_NOPREFIX | TTS_ALWAYSTIP,
    0, 0, 0, 0, hwnd, nullptr, hInst, nullptr);

// ② 登记"工具"：哪块区域、显示什么文本
TOOLINFOW ti = { .cbSize = sizeof(ti) };
ti.uFlags   = TTF_SUBCLASS | TTF_IDISHWND;   // ★ SUBCLASS：tooltip 自己子类化目标窗口取鼠标消息
ti.hwnd     = hwnd;                          //   "工具"的宿主
ti.uId      = (UINT_PTR)hSomeButton;         //   TTF_IDISHWND 时 = 控件句柄
ti.lpszText = (LPWSTR)L"点我打开文件";
SendMessageW(tip, TTM_ADDTOOLW, 0, (LPARAM)&ti);
```

`TTF_SUBCLASS` 是关键一步：tooltip **不是**你窗口的子窗口，鼠标消息本来到不了它——这个标志让控件自己动手子类化目标窗口（第 11 章讲的机制），把 `WM_MOUSEMOVE` 接过去。不给这个标志就得自己在宿主的 `WM_MOUSEMOVE` 里转发 `TTM_RELAYEVENT`。第 7 章工具栏的 `TBSTYLE_TOOLTIPS` 干的正是这套全流程的自动化（工具栏建好 tooltip 并登记所有按钮）。

动态文本：登记时不写死 `lpszText = LPSTRTEXTCALLBACKW`（即 `(LPWSTR)-1`），tooltip 显示前来问你要（`WM_NOTIFY` 的 `TTN_GETDISPINFO`）：

```cpp
if (nm->code == (UINT)TTN_GETDISPINFOW) {
    NMTTDISPINFOW* di = (NMTTDISPINFOW)lParam;
    lstrcpynW(di->szText, L"当前温度：26°C", 80);   // 每次显示时现算
    return TRUE;
}
```

参考库第 6 章的进阶用法——**同位工具提示**（in-place tooltip）：资源管理器里文件名被截断时，悬停显示的提示**盖在原文本上**而不是旁边。做法是在 `TTN_SHOW` 里用 `TTM_ADJUSTRECT` 把目标矩形换算成提示窗口矩形，再 `SetWindowPos` 定位——机制了解即可，需要时查 `TTM_ADJUSTRECT`。另一个常用设置：`TTM_SETMAXTIPWIDTH`（默认一行到底，设了宽度才自动换行成多行提示）。

## 9.6 完整示例解剖

`examples/34_datetime_feedback/main.cpp` 的四段：

1. `WM_CREATE`：注册（`ICC_DATE_CLASSES | ICC_ANIMATE_CLASS | ICC_TAB_CLASSES`），建 DTP、月历、动画（`ACM_OPENW` 打开 `demo.avi`，失败时状态栏提示"AVI 不存在"）、给按钮登记 tooltip（`TTF_SUBCLASS` 路线）；
2. `WM_NOTIFY`：`DTN_DATETIMECHANGE` 把新日期写进月历选中；`MCN_GETDAYSTATE` 给每月 5/19 日加粗；`TTN_GETDISPINFO` 动态提供提示文本；
3. `WM_COMMAND`：`ACN_START/STOP` 更新状态栏（体会它走 `WM_COMMAND`）；"预约"按钮读 DTP+月历汇总弹出；
4. 布局：`WM_SIZE` 里左列（DTP+动画）右列（月历）两栏摆位。

## 9.7 易错清单

| 症状 | 原因 | 解法 |
|------|------|------|
| DTP 读到 `GDT_NONE` | 控件被清空（`DTS_SHOWNONE`） | 判返回值再取 `SYSTEMTIME`（9.2） |
| 月历日期没加粗 | 没处理 `MCN_GETDAYSTATE`，或没 `return TRUE` | 9.3（控件来问你才答） |
| 加粗的日子错位一个月 | `prgDayState[0]` 对应的是 `stStart` 所在**月** | 用 `NMDAYSTATE.stStart` 对齐（9.3） |
| AVI 打开失败 | 文件带音轨 / 路径错 / 资源类型不是 "AVI" | 无声 AVI（9.4），`ACM_OPENW` 返回值要查 |
| 动画一动界面就卡 | 用 `ACS_TIMER` 且消息循环忙 | 默认线程驱动即可（9.4） |
| `ACN_START` 一直等不到 | 它走 `WM_COMMAND` 不走 `WM_NOTIFY` | 9.4（与轨迹条并列的例外） |
| tooltip 建了不出现 | 少 `TTF_SUBCLASS` 又没转发 `TTM_RELAYEVENT` | 9.5（寄生窗口的代价） |
| tooltip 文本超宽不换行 | 默认单行 | `TTM_SETMAXTIPWIDTH`（9.5） |
| 动态文本显示"-1" | `lpszText` 填了回调标记但没处理 `TTN_GETDISPINFO` | 两件套成对出现（9.5） |

## 9.8 小结

1. DTP 与月历共享 `SYSTEMTIME` 数据模型：DTP 是"单行输入 + 弹月历"，月历是常驻日历面板。
2. 日状态是"控件来问（`MCN_GETDAYSTATE`）你来答（`MONTHDAYSTATE` 位图）"——加粗日、节假日标记的标准做法。
3. 动画控件三件事：无声 AVI、后台线程播放不阻塞 UI、通知走 `WM_COMMAND`；`ACS_*` 四个样式决定播放行为。
4. 工具提示是寄生顶层窗口：`TTM_ADDTOOL` 登记工具 + `TTF_SUBCLASS` 解决鼠标消息来源；动态文本用 `TTN_GETDISPINFO` 回叫。
5. 通用控件的通知通道有三类：`WM_NOTIFY`（绝大多数）、`WM_HSCROLL/VSCROLL`（轨迹条）、`WM_COMMAND`（动画的 `ACN_*`）——写处理器前先确认走哪条。

## 9.9 动手练习

1. 把 DTP 换成 `DTS_TIMEFORMAT`，再用 `DTM_SETFORMAT` 改成 24 小时制自定义格式，验证 `DTN_DATETIMECHANGE` 的触发时机。
2. 给月历开 `MCS_MULTISELECT`，用 `MCM_GETSELRANGE` 读出"入住~退房"区间，算天数差（`SYSTEMTIME` → `SYSTEMTIME` 的天数差可以用第 21 章的 `SystemTimeToFileTime` 做）。
3. 挑战：实现同位工具提示——给一个被截断的静态文本登记 tooltip，在 `TTN_SHOW` 里 `TTM_ADJUSTRECT` + `SetWindowPos` 让提示覆盖原文（参考库第 6.2 节的三矩形模型）。
