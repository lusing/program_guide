# 10 · 序数与超穷归纳

> 序数概念是自然数的推广；现在标准的序数定义源自冯·诺依曼。
> ——原书 4.2 节开篇

本章覆盖书 4.2-4.3 节（PDF 79-85 页）：von Neumann 序数的定义
与结构定理（每个良序集同构于唯一序数）、序数的良序、Hartogs 引
理、超穷归纳与超穷递归。

## 10.1 序数：序型的标准代表

第 09 章末的难题：同构的良序集有相同"序型"，但**序型作为等价类
是真类**（与等势的困境同款，第 06 章 3.3.2 练习）。解法：找一族
**标准的**良序集当代表——由基本定理 4.1.6 任意良序集都能与代表
比较。代表就是序数。

> **定义（书 4.2.1/4.2.3）**　集合 T **传递**，若 T 的元素都是
> T 的子集。集合 α 是**序数**，若 α 传递且 ∈ 是 α 上的良序。
> 记 α < β ⟺ α ∈ β。

传递性是"元素皆子集"——von Neumann 的设计让**隶属与大小合一**
（第 05 章在自然数上已经排练过：m ∈ n ⟺ m < n）。例（书 4.2.4）：
每个自然数都是序数；N 本身是序数（第一个无穷序数，记 ω）；序数
的后继 α⁺ 还是序数。α+1 := α⁺ 称后继；不是后继的序数称**极限
序数**（ω 是第一个）。全体序数从 0 起的队列（书 4.2 节）：

    0, 1, 2, …, ω, ω+1, …, ω+ω, ω+ω+1, …, ω·ω, …, ω³, …

结构定理群（书 4.2.6-4.2.8）：序数的元素都是序数（α = {β | β <
α}——题词的定理化）；序数的传递子集属于它（β ⊊ α ⟺ β ∈ α）；
对序数的集合 X：**⋂X 是序数且 = inf(X)，⋃X 是序数且 = sup(X)**
；序数全体上 < 是良序（传递、反对称、线性、良基四条逐一验过）。
特别地（书 4.2.9）**自然数恰是有穷序数**——第 05 章的双向奔赴
至此合龙。

Isabelle/ZF 在这里几乎是书的镜像（`examples/isabelle/HS10/Ordinals.thy`）：

```isabelle
thm Transset_def     (* Transset(i) ≡ ∀x∈i. x ⊆ i *)
thm Ord_def          (* Ord(i) ⟷ Transset(i) ∧ (∀x∈i. Transset(x)) *)
thm Ord_nat          (* ω 是序数 *)
thm Ord_linear_lt    (* 序数三歧——4.2.8(c) *)
thm Ord_Union        (* sup = ⋃ 的序数性 *)
thm lt_def           (* i < j ⟷ i ∈ j ∧ Ord(j)：∈ 即 < 的官方读法 *)
```

注意 ZF 对 Ord 的定义用"传递且元素皆传递"代替"∈ 是良序"——
两者等价（后者更强的良基部分由公理背景保证），ZF 的版本让归纳
启动更顺手。会话中亲手证明 0 < 2：`0 ∈ 2` 由 `succI2 [OF succI1]`
（0 ∈ 1 且 1 的元素进 2），再按 `lt_def` 展开——**序数的 < 就是
∈** 的读法在 ZF 里是一行定义。

## 10.2 每个良序集同构于唯一序数；Hartogs

> **定理（书 4.2.10）**　每个良序集同构于唯一序数。定义
> type(X,R) = 该序数，称为序型。

证明是替换公理的漂亮应用：对每个 x ∈ W，W[x] 同构于唯一的序数
α_x（唯一性来自序数间同构 ⟺ 相等）；由**替换公理**，
S = {α_x | x ∈ W} 是集合。验证 S 是序数（传递、∈-良序）、
{x | W[x] 型 < γ} 是前段，最后 f(x) = α_x 是 W 到 S 的同构——
若 A = dom 侧有残余则 c ∈ A 造成 W[c] ≅ α_c 但 c 已被覆盖的
矛盾。∎ 于是第 09 章的"和与积"获得数值化身：type(和) = 型的和
（下一章定义）。

> **引理（书 4.2.12，Hartogs）**　对任意集合 X，存在序数 H(X)，
> 不与 X 的任何子集等势，且是最小的这样的序数。

证明**不用选择公理**：令 W = {w ⊆ X | w 可良序化}（⊆ P(X)，是
集合），对每个 w 取其序型，H(X) := {α | ∃w ∈ W, α 是 w 的型}
是序数集之集合——它本身是序数，且若 H(X) 与 X 的某子集等势，
则 H(X) ∈ H(X)，违反序数不自属。∎ 两个后果：**全体序数是真类**
On（否则 On 是序数且 On ∈ On）；以及——即使没有 AC——任何集合
X 都有"装不下"的序数。H(X) 在第 13 章（良序定理与 AC 的等价性）
与第 14 章（基数的存在）都是主角。有限影子：对 n 元集 X，
H(X) = n+1（第一个装不下的序数）——Python 单元
（`examples/python/10_ordinals.py`）在 CNF 窗口内逐序数搜索验证。

## 10.3 超穷归纳：从 n 到 α

> **超穷归纳原理（书 4.3.1）**　若对一切序数 α，"∀β<α φ(β)"
> 蕴涵 φ(α)，则 ∀α φ(α)。

证明与自然数版同型（反设反例集非空，取 < 最小元——序数的良序
4.2.8(d) 撑腰）。**第二形式**（书 4.3.2）拆成三条腿：φ(0)；
后继步 φ(α) → φ(α+1)；极限步"∀β<λ φ(β) → φ(λ)"——实践
中按序数的解剖（0/后继/极限）分别下手的常规形态。

Lean 单元（`examples/lean/Sethao/Ch10Ordinals.lean`）：

```lean
/-- 超穷归纳（书 4.3.1）：4.33 里推荐 WellFoundedLT.induction。 -/
example (p : Ordinal → Prop) (h : ∀ α, (∀ β < α, p β) → p α) : ∀ α, p α :=
  fun α => WellFoundedLT.induction α h

example : IsWellOrder Ordinal (· < ·) := inferInstance   -- 4.2.8(d)
```

序数类型 `Ordinal` 上 < 的良序是**instance**——书里一页纸的定理
4.2.8(d)，在类型系统里是一行可推断的背景。同单元还锚定
`Ordinal.type`（定理 4.2.10：良序集的序型）与
`natCast_lt_omega0`（自然数 < ω，即 4.2.9）。

## 10.4 超穷递归：函数值的On梯

> **超穷递归定理（书 4.3.5）**　对任意函数 G : V → V，存在唯一
> F : On → V 使 F(α) = G(F↾α)——**第 α 个值允许看到全部前史**。

证明与第 05 章的近似序列法平行：长度为 α 的"近似"t（dom = α+1，
各步 t(β) = G(t↾β)），全体的并是函数（相容性）、定义域满 On
（逐层延长）、满足方程、唯一（超穷归纳）。带参数版与三段式
（书 4.10）：

    F(0) = G₁(0)；F(α+1) = G₂(F(α))；F(λ) = sup{F(β) | β < λ}。

> **例（书 4.3.7）**　层垒谱系：V₀ = ∅；V_{α+1} = P(V_α)；
> V_λ = ⋃_{β<λ} V_β。WF = ⋃_α V_α——良基集合的类，第 19 章的主角
> 在此挂上第一个号牌。

序数的 CNF（康托正则形式，4.4.14 预告）在 ω^ω 窗口内可以完整
机器化——本章两台计算单元先行试水：序数 = 系数向量
[c₀, c₁, …, c_k]（值 = ω^k·c_k + … + ω·c₁ + c₀）。Julia 单元
（`examples/julia/10_ordinals.jl`）实现右字典序比较与后继：

```julia
function olt(a, b)                       # 高位优先的字典序
    a, b = canon(a), canon(b)
    n = max(length(a), length(b))
    a = vcat(a, zeros(Int, n - length(a)))
    b = vcat(b, zeros(Int, n - length(b)))
    for k in n:-1:1
        a[k] != b[k] && return a[k] < b[k]
    end
    false
end

@assert olt([5], w) && olt(w, [1,1]) && olt(w, [0,2])    # 5 < ω < ω+1 < ω·2
@assert olt(w_sq, [1,0,1])                               # ω² < ω²+1
```

sup = 最大、inf = 最小（4.2.8 的窗口版）；`α < α+1` 跨有穷与极限
样本成立。Python 单元则做**元素表**：α 的元素 = {β | β < α}
（题词的机器版）——ω 的元素表以 ()，(1,)，(2,)，… 开头（自然数
恰是有穷序数的显式形态），sup/inf 与元素集的 ⋃/⋂ 对账，Hartogs
的有限影子收尾。

## 10.5 两张速查表

**归纳家族对照**：

| 原理 | 适用域 | 证明引擎 | 机器名 |
|---|---|---|---|
| 归纳原理 | ℕ | 最小归纳集 | `Nat.rec` / `nat_induct` |
| 第二归纳 | ℕ | 良序 | `Nat.strongRecOn` / `complete_induct` |
| 超穷归纳 | On | 序数的 ∈-良序 | `WellFoundedLT.induction` |
| 良基归纳 | 任意良基关系 | wf 递归 | `WellFounded.induction`（第 20 章） |

后两行的区别要到第 20 章才真正展开——良基关系允许非线性的"证据
树"，而序数的归纳是它的全线性特例。

**层垒谱系回访**：第 02 章的 V_k 宇宙审计（|V₀..V₅| =
0,1,2,4,16,65536）现在获得了递归定理的正式编号——例 4.3.7 的
V_α 序列正是那台审计的理论背景；而"对集/幂集结果逃到下一层"的
观察，将在第 19 章升级为"V = ⋃V_α = WF"的大定理（基础公理下的
宇宙形状）。超穷递归的三个经典客户——层垒谱系（按 α 递归）、
序数算术（按右参数递归）、下章的古德斯坦赋值（按基递归）——
恰好示范了递归变量的三种选法。

一个务实的提醒：本章的机器窗口是 ω^ω（指数为自然数的 CNF）。
它覆盖了书 4.4 节的全部例子与习题，但 ω^ω、ε₀（满足 ω^ε = ε₀
的最小序数）及以上需要指数本身也是序数的嵌套表示——第 12 章
（古德斯坦）的赋值恰好爬到 ε₀ 附近，届时窗口边界会再次出现，
教程会如实标注。

编号自查三题（答案都在本章定理里）：ω+ω 的元素里有没有 ω？
（有——ω ∈ ω+ω，因为 ω < ω+ω 而 ∈ 即 <。）ω² 的元素里有没有
ω+5？（有——ω+5 < ω²。有没有 ω·2？（有。有没有 ω² 自己？
（没有——序数不自属。）"元素即更小者"的读法熟练之后，序数
算术的直觉就建起来了。

## 本章要点

1. 序数 = 传递 + ∈-良序；α = {β | β < β < α}；∈ 即 <；自然数
   恰是有穷序数；ω 是第一个极限序数。
2. 每个良序集同构于唯一序数（type）——替换公理的关键应用；
   Isabelle/ZF 的 Ord/lt_def/Ord_linear_lt 是定义与三歧的实名。
3. 序数的集合有 inf = ⋂、sup = ⋃；序数全体 On 是良序真类。
4. Hartogs：不用 AC，任何集合都有装不下的序数 H(X)——On 是真类
   的原因，也是第 13/14 章的伏笔。
5. 超穷归纳（强归纳的 On 版）与超穷递归（F(α) = G(F↾α)，允许
   看全部前史）——三段式 0/后继/极限是实践的常规形态；V_α 层垒
   谱系是第一个大客户。
