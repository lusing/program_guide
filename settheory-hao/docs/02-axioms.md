## 2.1 为什么是公理，为什么是这九条

我们不可能证明所有的命题——任何理论都要有不加证明的出发点。
形式主义者说：只要满足一致性，公理可以随便选。但数学实践的选取
始终有原则，**最重要的标准是直观上的显然性**。原书举了两个前科：
早的如欧几里得第五公设，晚的如选择公理——都曾为"自明性"争论。
而下文九条公理中的绝大部分（"有相同元素的两个集合相等"、"存在
无穷集合"），绝大多数数学家认为一目了然。

任何公理系统还包含**逻辑公理**（读者在任何数理逻辑教材中都能
找到），本书不细究。但有一条值得单独强调，原书把它编号为**公理 0**：

> **存在公理 (Exi)**　∃x (x = x)。　　(1.1)

这条逻辑公理是本体论承诺：我们谈论的世界不能虚无，至少存在一个
事物——具体到当前课题，至少存在一个集合，所有讨论才有意义。
策梅罗（Zermelo）1908 年用的是更强的版本"存在一个不含任何元素的
集合"，但下面会看到：**空集可以由分离公理定义出来**，无须单独
假设。

九条公理按功能分三组：**存在性**（0 存在、6 无穷）、**构造性**
（2 分离、3 对集、4 并集、5 幂集、8 替换——"如果 X 是集合，则
存在集合 Y…"，由已知造新）、**否定性**（7 基础：某些类不是集合；
9 选择虽是构造性的形式，但气质独特，见 2.7）。公理 0 到 9 组成
**ZFC**；0 到 8 组成 **ZF**（选择公理在第 13 章专门讨论）。

## 2.2 外延与分离：集合是什么、集合不是什么

> **外延公理 (Ext)**　两个有相同元素的集合相等：
> ∀X ∀Y [∀u (u ∈ X ↔ u ∈ Y) → X = Y]。　　(1.2)

（反方向 X = Y → 元素相同是逻辑定理。）外延说**集合由其元素决定**
——除此之外它没有任何隐蔽的属性。这个看似平凡的公理是后面一切
"唯一性"声明的许可证：空集唯一、{a,b} 唯一、并集唯一……都靠它。

> **分离公理模式 (Sep)**　令 φ(u) 为公式。对任意集合 X，存在集合
> Y = {u ∈ X | φ(u)}。　　(1.4)

"模式"意味着它代表无穷多条公理——每个公式 φ 对应一条。分离公理
有很多名字：由于它是对概括原则的限制，有人仍称**概括公理**；由于
Y 是 X 的子集，有人称**子集公理**。策梅罗本人对限制的说明（原书
引）：集合不能凭空定义，**必须从已存在的集合中分离出来**——"所有
集合的集合"这类概念正是被这一限制挡住的。

分离公理下的罗素推理是本章第一场完整证明。取 φ(x) 为 x ∉ x。
分离公理不再断定 R = {x | x ∉ x} 是集合，而是断定对任意已存在的
集合 X：

    R_X = {x ∈ X | x ∉ x}

是集合。问 R_X 是否属于 R_X？若 R_X ∈ R_X，则按定义 R_X ∈ X 且
R_X ∉ R_X，矛盾——**但这次没有悖论**：结论只是 R_X ∉ R_X，它
进一步蕴涵 R_X ∉ X（R_X 若在 X 中且不自属，就该属于 R_X）。于是：

> **定理（书 1.3 推论）**　对任意集合 X，存在集合 R_X 使 R_X ∉ X。
> 因此"所有集合的集合"不存在。∎

注意这个论证的构造性收获：它不仅排除全集，还说明对任何集合都有
"集合之外的对象"——这正是第 08 章 Cantor 定理（|P(X)| > |X|）的
雏形。

**空集**。令 φ(u) 为 u ≠ u：∅ = {u | u ≠ u} 是集合且唯一（外延），
记为 0（书 1.3.2）。

**类与真类**。既然形如 {u | φ(u)} 的对象不一定是集合，就给它们
一个统一的名字：**类**（class）；不是集合的类称为**真类**
（proper class）。每个集合都是类；罗素类 R = {x | x ∉ x} 与"所有
集合"的类 V 都是真类。书 1.3.5 注记澄清记法：类是**记法方便**，
"x ∈ V"不过是"x 是集合"的缩写——V 不是集合论语言中的对象。这一
层次（集合/真类/语言外记法）在第 19 章（V 作为层垒谱系）与第 22
章（可定义类）会反复出现。

**交与差**。由分离公理立得（书 1.3.6）：X ∩ Y = {u ∈ X | u ∈ Y}
与 X − Y = {u ∈ X | u ∉ Y} 是集合；若 X ≠ ∅，任意交
⋂X = {u | ∀Y (Y ∈ X → u ∈ Y)} 也是集合——对 X 中任一固定成员
Z 分离即可（思考题 1.3.7：X = ∅ 时 ⋂X 应是什么？约定它等于全集
V——但 V 不是集合！所以任意交的定义域必须排除空族，这是个"习惯
约定泄漏本体论"的小例子）。

## 2.3 对集、并集、幂集：构造性三剑客

> **对集公理 (Pai)**　对任意 a、b，存在集合只以 a、b 为元素：
> ∀a ∀b ∃c ∀x (x ∈ c ↔ x = a ∨ x = b)。　　(1.5)

由外延，这个集合唯一，记 {a,b}；单点集 {a} = {a,a} 随之而来。
对集公理造的集合"浅而窄"——只打包两个已知的对象。

> **并集公理 (Uni)**　对任意集合 X，存在集合 Y 满足 u ∈ Y 当且仅当
> 存在 Z ∈ X 使 u ∈ Z。　　(1.6)

Y 唯一，称为 ⋃X；X ∪ Y := ⋃{X,Y}。原书的比喻值得照录：X 是一罐
**独立包装**的饼干（元素是包），⋃X 是把包装全拆开的同一罐饼干
（元素是块）。并集公理造的集合"宽"——它把一层包装摊平。

> **幂集公理 (Pow)**　对任意集合 X，存在集合 Y 满足 u ∈ Y 当且仅当
> u ⊆ X。　　(1.7)

Y 唯一，记 P(X)。幂集公理造的集合"深"——它把"子集"这个关于
X 的**性质**提升为对象。这是最强的一条构造公理，也是 Cantor 阶梯
ℵ₀ < c < 2^c < … 的公理源头。

现在可以看构造的流水线（书 1.8 式）。从公理 0 的某个集合分离出 ∅，
再对集、再对集：∅、{∅}、{{∅}}、{∅,{∅}} 都是集合；有了并集，
∅、{∅}、{∅,{∅}}、{∅,{∅},{{∅}},{∅,{∅}}} 也都是集合。若把它们
记为 0, 1, 2, 3, …，则 **{0,1,2,3,…} 是不是集合？** 以上公理都不
足以回答——需要新公理。为了表述它，先给出：

> **定义（书 1.3.10）**　S(x) = x ∪ {x} 称为 x 的**后继**。

## 2.4 无穷公理

> **无穷公理 (Inf)**　存在集合 X：∅ ∈ X，且对任意 x ∈ X，
> S(x) ∈ X：
> ∃X [∅ ∈ X ∧ ∀x (x ∈ X → S(x) ∈ X)]。　　(1.9)

满足这两条的对象就是**归纳集**（第 05 章将证明最小归纳集唯一，
它就是自然数集 ω）。无穷公理是 ZFC 中唯一**直截了当断言无穷存在**
的公理；没有它，以上全部构造都在有限层级打转。原书脚注给了一个
有趣的旁注：蒯因的新基础（NF）中无穷公理可证——因为 Specker 证明
了 NF 中选择公理的否定，而有穷集合上的选择公理可证，于是 NF 中
必有无穷集合。一条"否定性"定理反过来保证了无穷，公理系统之间的
微妙互动由此可见。

## 2.5 基础公理：∈-世界的地板

> **基础公理 (Fnd)**　对任意集合 x ≠ ∅，存在 y ∈ x 使 y ∩ x = ∅：
> ∀x [x ≠ ∅ → ∃y ∈ x ∀u (u ∈ y → u ∉ x)]。　　(1.10)

（基础公理也叫**正则公理**。）y 是 ∈ 限制在 x 上的"最小元"——
y 的元素都不属于 x，所以从 y 无法继续往 x 内部走。

**定理（书 1.3.11）**　任意集合 x 都不属于自身。

*证明*。反设 x ∈ x。令 A = {x}（对集公理）。A ≠ ∅，由基础公理取
y ∈ A 使 y ∩ A = ∅；A 只有元素 x，故 y = x，于是 x ∩ {x} = ∅。
但 x ∈ x 且 x ∈ {x}，与 x ∩ {x} = ∅ 矛盾。∎

习题 1.3.12 进一步：不存在无穷下降链 x₀ ∋ x₁ ∋ x₂ ∋ …（"基础
公理确保不存在无穷下降链"——严格的表述见第 20 章良基关系；用类
语言可以证明 ∀n (x_{n+1} ∈ x_n) 的序列不是集合）。直观图景：∈ 
世界没有环路、没有无限深井，每个集合都"坐"在地板上——第 19 章
的层垒谱系 V = ⋃_α V_α 将把这幅图景精确化，并证明基础公理下的
集合宇宙恰好就是层垒谱系。

值得说明：ZF 的大部分数学（实数、分析）**不需要**基础公理；它是
"宇宙形状"的公理，反基础的集合论（含 x ∈ x 的宇宙）是活跃的研究
分支。本教程按书的主线采用 Fnd。

## 2.6 替换公理：像仍是集合

> **替换公理模式 (Rep)**　给定公式 φ(x,y)，若对任意 x 都有**唯一**
> 的 y 使 φ(x,y) 成立，则对任意集合 A，以下集合存在：
> B = {y | ∃x ∈ A φ(x,y)}：
> ∀A [∀x ∈ A ∃!y φ(x,y) → ∃B ∀x ∈ A ∃y ∈ B φ(x,y)]。　　(1.12)

"模式"同分离：每个公式一条。前件 ∀x∃!y φ 说的正是"φ 表示一个
函数"；所以替换公理说：**任何集合在函数下的像仍是集合**。像不会
比原像更大，因此"没有危险"——原书的断语值得记住：**引起麻烦的
集合都是因为太大了**。概括原则的病灶正是允许造出"所有满足 φ 的
对象"这种可能太大的整体；分离与替换分别从"裁剪"和"换标签"两个
方向限制造集的野心。

替换公理是 Fraenkel（与 Skolem）1922 年对策梅罗系统的关键补充，
它保证超穷递归（第 11 章）能造出 ω+ω、ω₁ 这类"长度超出已有序列"
的集合——第 10 章序数的存在性证明要用它。习题 1.3.14 的小型应用：
由替换证明 {{0},{1},{2},…} 是集合（把每个 n 换成 {n}）。

## 2.7 选择公理：存在的许可证

> **选择公理 (AC，第一形式)**　对任意集合 X ≠ ∅，若
> (1) 每个 x ∈ X 非空，(2) X 中元素两两不交，则存在集合 S 使对
> 任意 x ∈ X，S ∩ x 恰为单点集。　　(1.13)

S 称为 X 的**选择集**。第 03 章将给出等价的第二形式：对任意不含
空集的非空集族 F，存在**选择函数** f : F → ⋃F 使 f(x) ∈ x。

AC 在形式上是构造性公理，气质却完全不同：它断言的选择集**不是唯
一的**，而且公理只说"存在"、不给出构造它的方法。这种非构造性曾
引起激烈争论——拒绝者中包括博雷尔（Borel）与勒贝格（Lebesgue）
这样的大数学家（他们质疑的是：对**不可数**多个非空集合同时选取，
究竟是不是一个明确的数学行为？）。今天多数数学家接受 AC——它在
集合论中的角色太重要了。第 13 章将系统讨论：它与 Zorn 引理、良序
定理等一整族命题等价，以及它在 ZFC 中不可判定的事实。

## 2.8 公理账本与"更省"的版本

**账本**：公理 0-9 = **ZFC**；0-8 = **ZF**（第 05 章起凡不涉选择
的证明都在 ZF 中进行；第 13 章审查哪些定理偷偷用了 AC）。

原书第二章脚注还指出一个"省公理"的事实：**对集公理与替换公理
模式只要其一即可**（配对可由替换导出）。习题 1.4.9 更进一步：
对集、并集、幂集公理都可换成"弱形式"——只要求存在**包含**目标
的集合（如弱对集：存在 Y 使 a ∈ Y 且 b ∈ Y），再配合分离公理裁出
精确的目标。比如弱对集给出 a, b ∈ Y，分离出 {u ∈ Y | u = a ∨
u = b} 即 {a,b}。**机器侧的印证**：Isabelle/ZF 的公理系统真的只有
**六条实公理**（外延、并集、幂集、无穷、基础、替换模式），对集
与分离全部由替换导出（见 2.10 节）——"公理组的选择有相当的自由
度"在证明助手里是活的现实。

## 2.9 习题课：集合代数与三道"非集合"证明

**习题 1.4.1（集合代数）**　对任意集合 X、Y、Z：

- 自反与反对称：∅ ⊆ X；X ⊆ X；(X ⊆ Y ∧ Y ⊆ X) → X = Y（后者
  就是外延）；传递：X ⊆ Y ∧ Y ⊆ Z → X ⊆ Z。
- 交换律：X ∪ Y = Y ∪ X；X ∩ Y = Y ∩ X。
- 结合律：(X ∪ Y) ∪ Z = X ∪ (Y ∪ Z)；(X ∩ Y) ∩ Z = X ∩ (Y ∩ Z)。
- 分配律：X ∩ (Y ∪ Z) = (X ∩ Y) ∪ (X ∩ Z)；对偶的并交版本。
- 德摩根律：X − (Y ∪ Z) = (X − Y) ∩ (X − Z)；X − (Y ∩ Z) =
  (X − Y) ∪ (X − Z)。

全部证明是"元素追踪"：要证 X − (Y ∪ Z) ⊆ (X − Y) ∩ (X − Z)，
任取 u ∈ 左边，则 u ∈ X 且 u ∉ Y ∪ Z——即 u ∉ Y 且 u ∉ Z（否定
的析取是合取）——于是 u 同时落在右边两支；反向同理。Python 单元
`02_axioms.py` 把这组定律连同对称差五律（习题 1.4.2：X△Y = Y△X、
(X△Y)△Z = X△(Y△Z)、X△X = ∅、X ∩ (Y − Z) = (X ∩ Y) − Z、
X = Y ↔ X△Y = ∅）放在 frozenset 上全部精确验证（见 2.10 节）。

**习题 1.4.6（−X 不是集合）**　对任意集合 X，令 −X = {x | x ∉ X}。
若 −X 是集合，问 −X ∈ −X 与否：若在，则 −X ∉ X（定义），但 −X
自属说明 −X 不满足"不属于自身"，而 −X 的元素恰是所有不属于 X 的
对象……更直接的账：−X ∈ −X ↔ −X ∉ X；另一方面 −X 若是集合且
−X ∉ X 则 −X ∈ −X。若 −X ∈ X，则按定义 −X ∉ −X；两者相容？
——再想一层：−X ∈ X 与 −X ∉ X 必有一真。若 −X ∉ X，则 −X ∈ −X，
即 −X ∈ −X ↔ ¬(−X ∈ X) 恒真，无矛盾出现——真正的证明用基础：
−X ∈ −X 违反 x ∉ x。结论：**补集运算只能在固定全集内谈**
（X − Y 合法，−X 非法）。

**习题 1.4.7（全集不存在）**　(1) 若 V = 所有集合的集合存在，由
分离公理 R = {x ∈ V | x ∉ x} = {x | x ∉ x} 是集合——回到罗素
矛盾。(2) 对任意集合 X，2.2 节的定理给出 R_X ∉ X。

**习题 1.4.8（P(X) ≠ X，Cantor 前奏）**　对任意 X，P(X) ⊄ X
（特别地 P(X) ≠ X）。证明用书中的提示：令 Y = {u ∈ X | u ∉ u}
（分离：Y 是集合，且 Y ∈ P(X)）。反设 P(X) ⊆ X，则 Y ∈ X。于是：
若 Y ∈ Y，则按定义 Y ∉ Y；若 Y ∉ Y，则 Y ∈ X 且 Y ∉ Y 按定义
给 Y ∈ Y——矛盾。故 Y ∉ X，与 P(X) ⊆ X 不符。∎ 把"Y ∉ Y 的两难"
与第 08 章 Cantor 对角线并读：**这就是对角线论证**，只是把"实数表"
换成了"集合 X 自己"。

## 2.10 机器侧：三张公理的脸

### Lean：公理在那里是定理

mathlib 的 `SetTheory.ZFC` 维护着一个真正的 ZFC 宇宙：先造**前置集**
`PSet`（树形表示），再按"有相同元素"的等价关系取商，得到 `ZFSet`。
于是**ZFC 的公理在 Lean 里是定理**——单元
`examples/lean/Sethao/Ch02Axioms.lean` 把九条公理逐一点名。几例：

```lean
/-- 公理 2 分离：`sep` 把性质限制在已有集合内，只能裁剪不能扩大。 -/
example (p : ZFSet → Prop) (x : ZFSet) : x.sep p ⊆ x := ZFSet.sep_subset

/-- 公理 6 无穷：ω 含 ∅ 且对后继 S(x) = x ∪ {x} 封闭——
与书 1.3 中无穷公理的形式逐字对应。 -/
example : (∅ : ZFSet) ∈ ZFSet.omega := ZFSet.omega_zero

example (n : ZFSet) (h : n ∈ ZFSet.omega) : insert n n ∈ ZFSet.omega :=
  ZFSet.omega_succ h

/-- 公理 7 基础的结论形态：x ∈ y → y ∉ x。
取 y := x 立得书 1.3.11 定理"任何集合不属于自身"。 -/
example (x : ZFSet) : x ∉ x := fun h => ZFSet.mem_asymm h h
```

注意三处与书的对位：`ZFSet.omega_zero` 与 `omega_succ` 恰是无穷
公理的"∅ ∈ X 且后继封闭"形式（mathlib 甚至用了同一个词 omega）；
`insert n n` 恰是后继 S(n) = n ∪ {n}；替换公理的影子是 `ZFSet.image`，
其类型参数 `[Definable₁ f]` 正是"公式 φ 定义 f"这个条件的化身：

```lean
#check @ZFSet.image
#check @ZFSet.mem_image
```

真类侧，mathlib 另设 `Class` 类型：所有集合的类 `Class.univ` 与
罗素类 `Class.sep (fun x => x ∉ x) Class.univ` 作为**类**存在——
但 `Class.univ` 的类型是 Class 而非 ZFSet，"V 是真类"直接写在类型
里。单元最后对照两张地基图：

```lean
#print axioms ZFSet.mem_asymm
-- 'ZFSet.mem_asymm' depends on axioms: [propext, Quot.sound]
#print axioms Classical.em
-- 'Classical.em' depends on axioms: [propext, Classical.choice, Quot.sound]
```

Lean 逻辑自身的公理只有三条：命题外延 `propext`、选择
`Classical.choice`、商合法 `Quot.sound`。有趣的是 `mem_asymm`（书
1.3.11 定理的强化）只用前两条而**不碰 choice**——ZFC 的"基础"部分
在 Lean 里比排中律还便宜。

### Isabelle/ZF：六条实公理的实名表

Isabelle 的 ZF object-logic 把 ZFC 当**原始对象**：公理是库里
`axiomatization` 声明的实体，有名字、可打印。会话
`examples/isabelle/HS02/Axioms.thy` 的第一段就是公理表本体：

```isabelle
thm extension      (* 外延：A = B ⟷ A ⊆ B ∧ B ⊆ A *)
thm Union_iff      (* 并集：A ∈ ⋃C ⟷ (∃B∈C. A ∈ B) *)
thm Pow_iff        (* 幂集：A ∈ Pow(B) ⟷ A ⊆ B *)
thm infinity       (* 无穷：0 ∈ Inf ∧ (∀y∈Inf. succ(y) ∈ Inf) *)
thm foundation     (* 基础：A = 0 ∨ (∃x∈A. ∀y∈x. y ∉ A) *)
thm replacement    (* 替换模式 *)
```

两点值得细看。其一，`infinity` 与 `foundation` 的形状与书 1.3 的
(1.9)、(1.10) **逐字对应**（0、succ、最小元刻画）。其二，表里
**没有**对集与分离——它们是从替换**导出的定理**：

```isabelle
thm Upair_iff      (* c ∈ Upair(a,b) ⟷ c = a ∨ c = b *)
thm separation     (* b ∈ {x∈A. P(x)} ⟷ b ∈ A ∧ P(b) *)
```

这正是 2.8 节"对集与替换取一即可"的机器实现（Suppes 式公理化）。
会话随后把书 1.3.11 定理从公理直接重演一遍：

```isabelle
lemma x_not_mem_x: "x \<notin> x"
proof
  assume A: "x \<in> x"
  have ne: "{x} \<noteq> 0"
  proof
    assume "{x} = 0"
    then have "x \<in> 0" using singletonI [of x] by simp
    then show False by (rule emptyE)
  qed
  from foundation [of "{x}"] ne
  obtain u where u1: "u \<in> {x}" and u2: "\<forall>y\<in>u. y \<notin> {x}"
    by (auto simp: singleton_iff)
  then have ux: "u = x" by (simp add: singleton_iff)
  from u2 ux A have "x \<notin> {x}" by blast
  then show False using singletonI [of x] by blast
qed
```

与 2.5 节的手写证明逐步对位：反设 x ∈ x；单点集非空；基础公理给出
最小元 u；u 必是 x 自身；把 x（∈ x = u）代入"u 的元素都不在 {x}
中"得 x ∉ {x}，与 x ∈ {x} 冲突。**机器证明没有跳步**——书上说
"留给读者"的地方，Isabelle 替读者走了。

### Python：有限宇宙审计——每条公理住在哪一层

第 19 章的层垒谱系 V₀ = ∅、V_{k+1} = P(V_k) 在这里提前出场，不过
只用它的前几层当**有限宇宙**（`examples/python/02_axioms.py`）：

```python
V = [frozenset()]
for _ in range(1, 5):
    V.append(frozenset(all_subsets(V[-1])))
V5 = frozenset(all_subsets(V[4]))                    # V_5：65536 元素
```

|V₀,…,V₄| = 0,1,2,4,16，V₅ 有 65536 个元素——三层之后宇宙暴涨，
幂集公理的威力先在数值上露一手。审计逐条公理：

```python
# ① 分离：V_4 的任何成员的任何子集仍在 V_4 内（穷举审计）
for X in V[4]:
    for Y in all_subsets(X):
        assert Y in V[4]

# ② 对集：a,b ∈ V_4 则 {a,b} ∈ V_5；但未必在 V_4——见证 a = V_3, b = ∅
a, b = V[3], frozenset()
pair = frozenset([a, b])
assert a in V[4] and b in V[4]
assert pair in V5 and pair not in V[4]
```

结果是一张"居住分布表"：

- **分离、并集、基础：封闭在 V₄ 内**。分离只裁剪（子集的元素必在
  更低层）；并集摊平一层包装（⋃X ⊆ V₂）；基础在每一层 V_k 都成立
  （每个非空集的元素里挑秩最小的，必与它不交）。
- **对集、幂集：结果逃到下一层**。{a,b} ⊆ V₄ 不是 V₃ 的子集，落
  在 V₅；P(V₃) = V₄ 本身不在 V₄ 内——**每用一次构造公理，宇宙就
  需要更高一层来容纳结果**。
- **"全集不存在"的影子**：V_k ∉ V_k 对所有 k 成立；Cantor 的影子：
  2^|X| > |X| 对所有 X ∈ V₄ 穷举成立（习题 1.4.8 的数值面）。

这张分布表预告了第 19、21 章的两条大定理：层垒谱系定理（基础公理
下 V = ⋃_α V_α）与反映定理（任何公式在足够高的 V_α 中"局部成真"
——公理们逐层成立正是其微观机制）。

## 本章要点

1. 九条公理分三组：存在性（Exi、Inf）、构造性（Sep、Pai、Uni、Pow、
   Rep）、否定性（Fnd）+ 气质独特的 AC；0-8 为 ZF，0-9 为 ZFC。
2. 分离是概括的"裁剪版"：罗素推理在分离公理下变成定理
   ∀X ∃R_X ⊆ X (R_X ∉ X)——全集不存在。
3. 类是记法方便；真类（R、V）不是集合论语言的合法对象。
4. 基础公理给 ∈ 世界装地板：x ∉ x、无无穷下降链；层垒谱系是其
   宇宙形状的精确化。
5. 替换=函数下的像仍是集合；"惹麻烦的集合都太大"。对集/并/幂
   都可弱化（习题 1.4.9），Isabelle/ZF 干脆只用六条实公理。
6. 机器三面：Lean 里公理是 ZFSet 的定理（且 mem_asymm 不依赖
   choice）；Isabelle/ZF 公理有实名、x ∉ x 从 foundation 直接重演；
   Python 有限宇宙给出公理的"居住分布表"。

*对应示例：`examples/lean/Sethao/Ch02Axioms.lean`、
`examples/isabelle/HS02/Axioms.thy`、`examples/python/02_axioms.py`。*
