# 16 · 共尾与无穷和积

> 比起 ω₁，ℵ_ω 是很大的基数，但存在从 ω 到 ℵ_ω 的无界映射
> f(n) = ℵ_n——我们能在 ω 步内从下面达到它。从这个角度，ℵ_ω
> 比 ω₁ "小"。——原书 5.3 节开篇的直观

本章覆盖书 5.3-5.4 节（PDF 114-121 页）：共尾 cf、正则/奇异
基数、König 引理、无穷和与积、正则基数的四等价刻画。

## 16.1 共尾：从下面够到 α 需要几步

> **定义（书 5.3.1）**　A ⊆ α 无界：∀β<α ∃γ∈A(β ≤ γ)。
> **cf(α)** = 最小的 β 使存在共尾映射 f : β → α（f[β] 无界）。
> cf(α) = α 的序数称**正则**；否则**奇异**。

基本事实（书 5.3.2）：无界 ⟺ α = ⋃{γ+1 | γ∈A}；cf(α) ≤ α；
后继序数 cf = 1；极限序数 cf ≥ ω。所以只有极限序数的共尾有趣。

**定理（5.3.3）**　极限 α 存在**严格递增**的共尾映射 f（把任意
g 磨光：f(η) = max(g(η), ⋃_{ξ<η}(f(ξ)+1))——递归定义 (5.11)）。
**推论（5.3.4）**　cf(cf(α)) = cf(α)——共尾总是正则的，且总是
基数。

**定理（5.3.6）**　κ⁺ 总是正则的。证明干净：若 α < κ⁺ 且
f : α → κ⁺，则 |⋃f[α]| ≤ κ·|α| < κ⁺——α 步够不到。∎ 于是
**奇异的基数都是极限基数**。而 ℵ_ω（= sup ℵ_n）奇异：f(n) =
ℵ_n 是 ω 步的无界映射——书 5.3.6 后注：任何无穷基数 κ 都有比
它大的奇异基数（ℵ_{α+ω}）。

机器侧三通道分工：**Lean**（`Sethao/Ch16Cofinality.lean`）点出
`Ordinal.cof_add_one`（5.3.2(3)）、`cof_add`、`cof_ord_cof`
（5.3.4）、`isRegular_succ`（5.3.6 后继正则）、`isRegular_aleph0`
（ω 正则）：

```lean
example (o : Ordinal) : Ordinal.cof (o + 1) = 1 :=
  Ordinal.cof_add_one o

example : Cardinal.aleph0.IsRegular := Cardinal.isRegular_aleph0
```

**Python**（`16_cofinality.py`）在可数窗口内做 cf 的实例化：后继
= 1（CNF 首系数非零）、极限 = ω——窗口内 cf 值恰 {0,1,ω} 三个，
全部正则（cf(cf α) = cf α 的窗口审计）；ℵ_ω 的影子 ω² =
sup{ω·n} 共尾 ω（奇异）。

**Julia**（`16_cofinality.jl`）跑两台构造：① ω·n 序列在 ω² 中
无界的显式核对（81 个窗口点逐一被超越）；② 磨光构造 (5.11) 的
执行——任意"乱序"共尾 g 经 running-max 变成严格递增共尾 f
（f(n) = max(g(n), f(n-1)+1) 的窗口版）。

## 16.2 König 引理：κ < κ^{cf κ}

> **König 引理（书 5.3.7）**　对任意无穷基数 κ：κ < κ^{cf(κ)}。

证明的对角线构造：对任意 G : κ → κ^{cf κ}，定义 h(α) =
min(κ − {G(ξ)(α) | ξ < f(α)})——h 与每个 G(ξ) 都在第 f(ξ) 位
不同。∎

> **推论（5.3.8）**　cf(2^κ) > κ。**这是 ZFC 对连续统基数的唯一
> 硬约束**：2^{ℵ₀} 不能是 ℵ_ω（cf = ω 违反）、不能是 ℵ_{ω+ω}
> 等——它必须是正则的或共尾足够的。

书 5.3.9 注的坦率值得引："除单调性与 König 外，ZFC 对连续统函数
2^α 的限制一无所知"——**幂函数是集合论的黑暗森林**，第 17 章全
章就是在森林边缘点灯。

## 16.3 无穷和与积（书 5.4）

> **定义（5.4.1）**　⊕_{i∈I} κᵢ = |⋃Xᵢ|（不交）；⊗ κᵢ = |ΠXᵢ|。

**命题（5.4.2）**　λ 无穷时 ⊕_{i<λ} κᵢ = λ ⊙ sup κᵢ——无穷
和被 max 吸收（第 15 章的推广版）。注 5.4.3 的三个平庸推论罗列
了 max 的各种变形。

**König 定理（5.4.6）**　∀i κᵢ < λᵢ ⟹ ⊕κᵢ < ⊗λᵢ——引理 5.3.7
的推广（对角线：Zᵢ = {f(i)|f ∈ Yᵢ} 真子集，取 f 逐坐标逃离）。

**正则基数的四等价（5.4.7）**：(1) κ 正则 ⟺ (2) <|κ| 个 <κ 的
集之并 <κ（"小并不大"）⟺ (3) <κ 个 <κ 的基数之和 <κ ⟺ (4) <κ
长的 <κ 集序列之并 <κ。这是"正则 = 拒绝被小族覆盖"的全部含义。

## 16.4 Hausdorff 公式与 Bernstein 公式（书 5.4.8-5.4.9）

> **Hausdorff 公式**　ℵ_{α+1}^{ℵ_β} = ℵ_{α+1} ⊙ ℵ_{β+1}。
>
> **Bernstein 公式**　ℵ_n^{ℵ₀} = 2^{ℵ₀} ⊙ ℵ_n（n ∈ ω）。

这两个公式是幂函数在 ℵ 梯上的局部照明——第 17 章的系统化由此
展开。

## 16.5 弱不可达：正则极限的不存在性之谜

书 5.3.6 后的讨论预告大基数理论：正则极限基数（**弱不可达**）
的存在性在 ZFC 中不可证；若再加上强极限（对一切 μ<κ 有 2^μ<κ）
则称**（强）不可达**。不可达基数是 ZFC 宇宙的"不可及的顶棚"——
第 21 章的反映定理将把这件事说清楚。

## 16.6 三通道代码精选

Julia 磨光构造的完整实现值得整段引用（`16_cofinality.jl`）：

```julia
g(n) = (n * 7) % 13                                   # "乱序"的无界序列
f = Int[]
for n in 0:20
    cand = g(n)
    isempty(f) || (cand = max(cand, f[end] + 1))
    push!(f, cand)
end
@assert all(f[i] < f[i+1] for i in 1:length(f)-1)     # 严格递增
@assert maximum(g.(0:20)) <= maximum(f)               # f 仍无界 ≥ g
```

g 是模 13 的余序列——乱序但无界（有限窗口内 max = 12）；f 逐位取
max(g(n), 前值+1)，既严格递增又保持无界。书 (5.11) 的 f(η) =
max(g(η), ⋃_{ξ<η}(f(ξ)+1)) 中 ⋃ 就是序数版的"前值"——窗口内
以 f[end]+1 代言（可数序数中 ⋃{f(ξ)+1 | ξ<n} = f(n−1)+1）。

Python 侧的 cf 三值结论值得再看一眼：窗口内 cf 的像恰为
{0, 1, ω}——0（零序数）、1（后继）、ω（一切可数极限序数）。这
三个值各自正则（cf 0 = 0、cf 1 = 1、cf ω = ω），验证了推论
5.3.4 的"共尾总是正则"。ℵ₁ 及以上在窗口外——它们的 cf（全部
正则或至少 > ω）只能由 Lean 侧的 isRegular_aleph_one/isRegular_
succ 以定理形态担保。

## 16.7 与前后章的对账

**向前**：第 10 章的 Hartogs 数为 cf 提供了"存在性上限"——
cf(α) ≤ α 恒真（5.3.2(2)），而更精细的"κ⁺ 正则"（5.3.6）用的
正是 Hartogs 式的计数论证（α 步的并之基数 ≤ κ·|α| < κ⁺）。

**向后**：本章的 cf 是第 17 章三分律的分岔点（λ vs cf κ 的比
较决定 κ^λ = κ 还是吉莫尔）、第 18 章 club 滤的 κ-完全度
（cf κ-完全）、第 21 章不可达定义（正则 + 强极限）的正则半。

**习题选讲（5.6）**：5.6.19（ℵ₀^{ℵ₀} = 2^{ℵ₀}——单调夹逼）；
5.6.24（⊕_{ξ<λ} 2^{ℵ_ξ} = 2^{ℵ_λ}，极限处连续）；5.6.31
（beth_ω 的共尾 = ω）；5.6.32-33（吉莫尔函数在 ℵ_ω 处的两种
命运：由 2^{ℵ₀} vs ℵ₁ 的关系分岔）。

## 本章要点

1. cf(α) = 从下面够到 α 的最少步数；后继 cf=1、ℵ₀ cf=ω（正则）、
   κ⁺ 正则、ℵ_ω 奇异（cf=ω）。
2. cf(cf α) = cf α——共尾总是正则基数。
3. König：κ < κ^{cf κ}；推论 cf(2^κ) > κ 是 ZFC 对连续统函数的
   唯一硬约束（单调是另一条）。
4. 无穷和 = max 吸收；König 定理 ⊕κᵢ < ⊗λᵢ；正则 = 小并不大
   （四等价 5.4.7）。
5. 机器面：Lean 的 cof/add_one/cof_ord_cof/isRegular_succ 全
   点名；Julia 的磨光构造 (5.11) 可执行；Python 窗口内 cf ∈
   {0,1,ω} 全正则。
