# 22 · 可构成集 L

> 加入公理 V = L 似乎是对集合论公理的一个自然的完备化。
> 因为它以一种确定无疑的方式决定了任意无穷这一模糊概念。
> ——库尔特·哥德尔（第八章题词）

本章覆盖书第八章（PDF 197-212 页）：哥德尔的可构成集 L——
第一个里程碑式的相对一致性证明：Con(ZF) ⟹ Con(ZF + V=L +
GCH + AC)。L 的构造、L ⊨ ZF + V=L、以及在 L 中 AC 与 GCH
成立的思想。

## 22.1 可定义性与哥德尔运算（书 8.1）

> **定义（书 8.1.1）**　Def(M) = 所有相对于 M **参数可定义**
> 的子集：X ⊆ M 属于 Def(M) ⟺ 存在公式 φ 和参数 y₁,…,y_m
> ∈ M 使 X = {x ∈ M | φ^M(x, ȳ)}。

哥德尔的关键观察：用 **十个初等运算** G₁–G₁₀ 的复合就可以
生成一切 Δ₀ 公式定义的集合——从而 Def(M) = cl_G(M ∪ {M}) ∩
P(M)（定理 8.1.8，哥德尔闭包的刻画）。这十个运算
（书 8.1.2）是：配对 G₁、卡氏积 G₂、∈ 图像 G₃、差 G₄、交
G₅、单点 G₆、定义域 G₇、逆 G₈、坐标轮换 G₉/G₁₀——全部对
传递模型绝对（引理 8.1.7）。

**定理 8.1.5**　对每个 Δ₀ 公式 φ，存在哥德尔运算的复合 G
使 G(X₁,…,X_n) = {x̄ ∈ X₁×…×X_n | φ(x̄)}——**哥德尔运算
的生成力恰是 Δ₀ 的表达力**。

Coq 单元（`Ch22Constructible.v`）实现了 G₄/G₅/G₇ 的可计算
版本并做样例计算；Python 单元（`22_constructible.py`）实现
了 G₃/G₄/G₅/G₇/G₈ 并审计运算律。

## 22.2 L 的层谱（书 8.2）

> **定义（书 8.2.1）**　L₀ = ∅；**L_{α+1} = Def(L_α)**；
> 极限 λ：L_λ = ⋃_{β<λ} L_β。**L = ⋃_{α∈On} L_α**。

L 与 V 的唯一区别在后继步：V 用**全部**子集，L 只用**可定义**
子集。

| 性质 | V_α | L_α |
|---|---|---|
| 传递 | ✓（7.2.3） | ✓（8.2.2） |
| 单调 | ✓ | ✓ |
| 含全部序数 | ✓ | ✓（8.2.5：L_α ∩ On = α） |
| 有限层 | V_n | **L_n = V_n**（8.2.7） |
| ω 层 | V_ω | **L_ω = V_ω**（8.2.7） |
| 无穷大小 | \|V_{ω+1}\| = 2^ℵ₀ | **\|L_{ω+1}\| = ℵ₀**（8.2.8） |

Python 单元的审计：L_n = V_n 对有限 n 精确成立（8.2.7 的窗
口投影）；L_α 传递、单调（8.2.2）——层谱的每条引理都在 frozenset
宇宙中逐条验证。

**|L_α| = |α|（引理 8.2.8）**是 L 瘦身的定量刻画：AC 下一切
α ≥ ω 的 L_α 大小恰为 |α|——而 V_α 在 ω 之后指数式膨胀
（beth 阶梯）。**L 是宇宙的"骨架版"**。

## 22.3 L ⊨ ZF（书 8.2.9）

证明逐条公理验证。难点在**分离**：对任意公式 φ（不只 Δ₀），
Y = {x ∈ X | φ^L(x, t̄)} 需要属于 L。取 X, t̄ ∈ L_α，由
L_{α+1} = Def(L_α)，Y' = {x ∈ L_α | x∈X ∧ φ^{L_α}} ∈
L——但 **Y' ≠ Y**（φ 在 L_α 中为真不等于在 L 中为真）。
此时**反映定理（7.9.2）**救场：找 β > α 使 φ 对 L_β 绝对
——Y = {x ∈ L_β | x∈X ∧ φ^{L_β}(x)} ∈ L_{β+1}。∎

**反映定理是分离公理在 L 中成立的技术引擎**——第 21 章的
"抽象"定理在此处兑现为具体应用。

## 22.4 V=L、AC 与 GCH 在 L 中（书 8.3）

> **可构成公理（8.3.1）**　V = L：一切集合可构成。

**引理 8.3.2**　α ↦ L_α 对 ZF 的传递模型绝对（超穷递归 +
Def 的绝对性——7.7.7 的良基递归绝对性定理）。

> **定理 8.3.3**　L ⊨ ZF + V=L。
>
> **定理 8.3.4**　Con(ZF) ⟹ Con(ZF + V=L)。

**内模型（8.3.6）**：包含所有序数的传递真类。**L 是最小的
内模型**（定理 8.3.5：L^M = L 对一切 ZF−Pow 传递模型 M——
L 在"内部"被唯一确定）。

**L ⊨ AC** 的思想：L 中可以**定义**一个全局良序——按 (rank_L,
构造公式编码, 参数编码) 的字典序。每个 L 中的集合有唯一的
"生日"（进入 L 层谱的最小 α）和唯一的"出生证明"（定义它的
公式编码）——这给 L 一个可定义的良序。∎

Isabelle/ZF-Constructible 会话（`HS22/ConstructibleSets.thy`）
是此定理的机器化：**`L_implies_AC`**——每个可构成集可良序
（Paulson 的完整开发，从 Formula.thy 的公式编码开始）。

**L ⊨ GCH** 的思想（书 8.3.4 后注提及，完整证明超出本书）：
L_α 层中 α ≤ ω 的子集个数 = |Def(L_α)| = |α|（引理 8.1.10(4)）
——恰是最小可能值 2^ℵ_α = ℵ_{α+1}。**L 的瘦身使 GCH 免费**。

> **总结（Con(ZF) ⟹ Con(ZFC + V=L + GCH)）**——**CH 的否定
> 不可从 ZFC 证明**（哥德尔 1938）。另一半（CH 也不可证——
> Cohen 1963）是第 23 章力迫的主角。

## 22.6 Python 代码讲解

```python
L = [frozenset()]
V = [frozenset()]
for _ in range(3):
    L.append(frozenset(Def_transitive(L[-1])))
    V.append(frozenset(all_subsets(V[-1])))

for n in range(4):
    assert L[n] == V[n]    # 引理 8.2.7：有限层 V=L
```

Def_transitive 在有限宇宙中退化为 all_subsets（每个子集都可
"定义"——有限集上可定义性无约束力）。这使 L_n = V_n 成为
8.2.7 的窗口投影：**有限层的 V 和 L 不可区分，分歧在 ω 处**
——那里 Def(ω) 只含可数多个可定义子集（|Def(M)| = |M|，引理
8.1.10(4)），而 P(ω) 有 2^ℵ₀ 个。**L 的瘦身从第一层无穷开始**。

哥德尔运算的审计值得整段（Python 22）：

```python
A = frozenset({1, 2, 3})
B = frozenset({2, 3, 4})
assert g4(A, B) == frozenset({1})           # G₄: X−Y
assert g5(A, B) == frozenset({2, 3})        # G₅: X∩Y
assert g4(A, B) | g5(A, B) == A             # 差∪交 = 原
```

G₄ ∪ G₅ 的分解恒等式是"哥德尔运算的生成力"的最简佐证——
它们能表达一切布尔组合，加上 G₃（∈ 图像）和 G₇（dom）就能
表达一切 Δ₀ 公式（定理 8.1.5 的构造性内核）。

## 本章要点

1. Def(M)：参数可定义子集的族 = 哥德尔闭包 ∩ 幂集（8.1.8）
   ——G₁₀ 的复合恰生成一切 Δ₀ 可定义集。
2. L_{α+1} = Def(L_α)：后继层只加"可定义"子集——L 是骨架
   宇宙；|L_α| = |α|（无穷处的瘦身）。
3. L ⊨ ZF 的分离公理需要**反映定理**做中介（L_α 中的真值在
   某个足够高的 L_β 与 L 一致）。
4. L ⊨ V=L（引理 8.3.2 的超穷递归绝对性）；L ⊨ AC（可定义
   良序）；L ⊨ GCH（Def 的计数恰取最小值）。
5. Con(ZF) ⟹ Con(ZFC+V=L+GCH)——**CH 不可反驳**。
6. 机器面：ZF-Constructible 的 L_implies_AC 是整个理论的
   机器化锚点；Coq/Python 持有 G 运算与 L 层谱的有限面。
