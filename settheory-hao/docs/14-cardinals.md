# 14 · 基数

> 无穷！从未有其他问题能如此震撼人类的精神；从未有其他观念能
> 如此激励人类的理智，让它结出丰硕的果实；也从未有其他概念比
> 无穷更需要澄清。——大卫·希尔伯特（第五章题词）

本章覆盖书 5.1 节（PDF 105-109 页）：基数的正式定义——**初始
序数**，它的五条等价刻画、Cantor 定理、后继/极限基数与 ℵ 序列。

## 14.1 从"等势类"到"初始序数"

第 06 章的悬案在此收案：把 X 的基数定义为等势类 [X]~ 会撞上
真类。解法与序数如出一辙——找标准代表：

> **定义（书 5.1.2）**　|A| := 与 A 等势的**最小序数**。
> （选择公理下良序定理保证它存在：与 A 等势的序数是非空序数集，
> 有最小元。）

> **命题（书 5.1.1）**　|X| ≤ |Y| ⟺ α_X ≤ α_Y——定义合法。

> **命题（书 5.1.3，五等价）**　对序数 α：
> (1) α 是基数；⟺ (2) |α| = α；⟺ (3) β<α → β<|α|；
> ⟺ (4) β<α → |β|<|α|；⟺ (5) β<α → |β|≠|α|。

这样的序数叫**初始序数**（initial ordinal，书称前段序数）。要害
在 (5)：**基数是不与任何更小者等势的序数**。

**无穷的第一次"贬值"**（书 5.1 开篇）：ω, ω+1, ω+2, …, ω·ω
全部彼此等势（第 10 章的自查题！）——序数敏锐地分辨它们，基数
却把它们压成同一个 ℵ₀。**序数是"长度"，基数是"大小"**——
同一个集合的两个影子，从此要分开记账。

Isabelle/ZF 的官方定义恰是书 5.1.3(5) 的形态
（`examples/isabelle/HS14/Cardinals.thy`）：

```isabelle
thm Card_iff_initial    (* Card(K) ⟷ Ord(K) ∧ ∀j<K. ¬ j ≈ K *)
thm Card_cardinal_eq    (* 基数 K 的"基数"就是 K 自己 *)
thm Card_nat            (* nat = ω 是基数 *)
```

会话中亲手证明 Card(1)：展开 `Card_iff_initial` 后，唯一的活儿是
反驳 0 ≈ 1——把 `eqpoll_def bij_def surj_def` 展开给 auto，空
定义域造不出满射。**每个自然数都是基数**（鸽笼原理：n 不与更小
的自然数等势，书 5.1.5(1)）。

Python 通道（`examples/python/14_cardinals.py`）在 ω² 窗口里做
初始序数识别实验——并在此摔了一跤后学到窗口方法论的要点：窗口
截断会**扭曲等势计数**（ω 的元素被砍到 6 个，ω+1 有 7 个，两者
竟被判不等势！），修正后的做法是把等势判定建立在**结构事实**
上（有限序数只与自身等势；窗口内一切 ≥ω 者可数、彼此等势——
后继平移 n↦n+1 显式可造）。结论在窗口内精确成立：

```python
def card_of(alpha):
    """窗口内的等势类：有限 → n；≥ω → 'aleph0'。"""
    if len(canon(alpha)) <= 1:
        return canon(alpha)[0] if canon(alpha) else 0
    return 'aleph0'

assert W in initials                    # ω 是基数
assert (1, 1) not in initials           # ω+1 不是（与 ω 等势）
assert (0, 2) not in initials           # ω·2 也不是
```

## 14.2 Cantor 定理：没有最大的无穷

> **定理（书 5.1.6，康托）**　对任意 X，|X| < |P(X)|。

单射 x ↦ {x} 给 ≤；无双射的反证正是第 01 章罗素类、第 02 章习
题 1.4.8、第 08 章对角线的同一台引擎：Y = {x ∈ X | x ∉ f(x)}
不在 ran(f)。∎ **第三遍出场，这次以"定理 5.1.6"的身份**——
阶梯 ℵ₀ < 2^{ℵ₀} = c < 2^c < … 没有顶。

Lean 通道（`examples/lean/Sethao/Ch14Cardinals.lean`）：

```lean
example (a : Cardinal) : a < 2 ^ a := Cardinal.cantor a

example : Cardinal.mk (Set (Fin 3)) = 8 := by simp
```

mathlib 的 `Cardinal.cantor` 就是书 5.1.6；有限版本
|P({0,1,2})| = 2³ = 8 顺手现场兑现。

## 14.3 后继基数与 ℵ 序列

> **定理（书 5.1.7）**　(1) 每个基数 κ 都有"大于它的最小基数"
> κ⁺；(2) 基数集的并 ⋃ 是基数（sup 保基数性）。

(1) 的证明把 Cantor 与良序焊在一起：μ = |P(κ)| 是基数，{λ ≤ μ |
λ 是基数，λ > κ} 非空序数集取最小元。于是：

> **定义（书 5.1.8/5.1.10）**　κ⁺ = 后继基数；ω₀ = ℵ₀ = ω；
> ω_{α+1} = ℵ_{α+1} = (ℵ_α)⁺；极限 λ：ℵ_λ = sup{ℵ_α | α < λ}。

> **引理（书 5.1.11）**　ℵ_α 恰是"第 α 个无穷基数"——每个无穷
> 基数都是某个 ℵ_α。

**每个无穷基数是极限序数**（书 5.1.5(2)）：β 无穷时 β ≈ β+1，
故 β+1 非初始。但注意"极限基数"（非后继的基数，如 ℵ_ω）与
"极限序数"是两个概念——ℵ₁ 是后继基数但是极限序数！

Isabelle 的 csucc 家族给出 κ⁺ 的官方件：`csucc_basic`
（Ord(K) ⟹ Card(csucc K) ∧ K < csucc K）。Lean 侧：

```lean
example (α : Ordinal) : Cardinal.aleph α < Cardinal.aleph (α + 1) :=
  Cardinal.aleph_lt_aleph.mpr (by norm_num)
```

ℵ 函数严格增——后继基数的存在性在两个证明助手里都是一行。

## 14.4 速查与展望

| 概念 | 序数侧 | 基数侧 |
|---|---|---|
| 计量 | 长度（序型） | 大小（等势类代表） |
| ω 与 ω+1 | 不同 | 相同（都 = ℵ₀） |
| 后继 | α+1 总存在 | κ⁺ 总存在但跳过一堆序数 |
| 极限 | λ = sup 前段 | ℵ_ω = sup ℵ_n（跳过 2^ℵ 等） |
| 层级 | On 真类 | 全体基数也是真类（Cantor 无顶） |

**开放伤口**：ℵ₀ 与 ℵ₁ 之间有什么？Cantor 只保证 2^{ℵ₀} > ℵ₀；
它是否恰为 ℵ₁——连续统假设——是下一批（第 17 章）的主角，
也是第 22-23 章独立性证明的靶心。基数算术的"幂"运算是整个领域
的黑暗森林：⊞ 和 ⊙ 在下一章会被完全驯服（= max），而 ^ 至今
（在 ZFC 内）大片未知。

## 14.5 与既有章节的对账

**第 06 章**的等势理论在此获得"数值化身"：|X| = |Y|（第 06 章
的双射语言）⟺ α_X = α_Y（本章的初始序数语言）——命题 5.1.1。
第 06 章的 Cantor-伯恩斯坦定理（双向单射合出双射）现在可以改写
成基数不等式的反对称性：κ ≤ λ ∧ λ ≤ κ ⟹ κ = λ——它甚至
不依赖 AC（本章定义依赖 AC，但 CSB 本身是 ZF 定理）。

**第 10 章**的 Hartogs 数在基数定义的门口站岗：没有 AC 时，"
与 X 等势的序数"可能一个都不存在（X 不可良序化），但 Hartogs
数 H(X)（不注入 X 的最小序数）仍然存在——ZF 世界里 X 的"大小"
只能用 ≤-关系网刻画，而不能赋值。**AC 的一个等价面相正是"每个
集合都有基数"**。

**第 08 章**的 |P(ℕ)| = |ℝ| = 2^{ℵ₀} = c 现在是阶梯的第二级：
ℵ₀ < c < 2^c < …。CH 的位置：c 是不是恰好 ℵ₁（紧跟 ℵ₀ 的
下一个基数）？Gödel（1938）证明 ZFC 推翻不了 CH，Cohen（1963）
证明也证不了它——**独立**。第 22-23 章将把两个独立性证明的
思想完整讲解。

**历史注**：康托 1874 年的第一个不可数性证明走的不是对角线而是
实数的区间套性质（第 08 章的对读）；1883 年他已有基数三层论；
初始序数定义（每个基数取等势类中最小序数）普遍归功于 20 世纪
20 年代的 von Neumann——与他的序数定义配套。

## 本章要点

1. |A| = 与 A 等势的最小序数（初始序数）——AC 下合法、唯一、
   保序；五等价刻画（5.1.3）的核心是 (5)：不与更小者等势。
2. ω+1 ≈ ω：序数分辨长度、基数只认大小；无穷序数全都"贬值"。
3. Cantor：|X| < |P(X)|——第三次登场的对角线成为正式定理，
   阶梯无顶。
4. κ⁺ 与 ℵ_α 序列；"第 α 个无穷基数"；极限基数 ≠ 极限序数。
5. 机器面：ZF 的 Card_iff_initial 逐字对应 5.1.3(5)；mathlib 的
   cantor/aleph_lt_aleph；窗口实验的方法论教训（等势判定须用
   结构事实而非截断计数）。
