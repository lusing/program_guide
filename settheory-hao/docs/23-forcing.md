## 23.1 力迫的基本思想：从内模型到外模型

第 22 章用**内模型**（L ⊆ V，比 V"细"）证 Con(ZF) ⟹ Con(ZF+
V=L+GCH)。但内模型方法对 ¬CH 无效：任何 ZFC 中可定义的传递
真类 N 都满足 L ⊆ N，而 L ⊨ V=L——要得到 V≠L 必须**扩张**宇
宙而不是收缩它。

**力迫法 = 外模型方法**：从 ZFC 的可数传递模型 M 出发，添加
M 之外的"泛型"对象 G，构造**脱殊扩张 M[G]** ⊋ M。

**可数传递模型的地位（书 9.1）**：Plato 主义者直接假设 M 存在
（ZFC 一致 + Löwenheim-Skolem）；非 Plato 主义者走有限片段路
线——对 ZFC 的任意有限子集 S，找到有限片段 T 和传递模型
M ⊨ T，使 M[G] ⊨ S+α（定理 9.1.1 的构造性证明用反映定理）。
两种路线给出同一结论：Con(ZFC) ⟹ Con(ZFC+α)。

## 23.2 力迫偏序与脱殊滤（书 9.2）

> **定义（9.2.1）**　力迫偏序 (P,≤,1)：条件 p ≤ q（p 更强）。
> D ⊆ P 稠密：∀p∃q∈D(q ≤ p)。滤 G：上封闭 + 两两相容。
> **M-脱殊滤**：G 与 M 中每个稠密集相交非空。

> **引理 9.2.2（脱殊滤存在）**　M 可数 ⟹ 对任意 p 存在含 p 的
> M-脱殊滤 G。

证明的算法骨架：把 M 中的稠密集排成序列 (Dₙ)，递归取 qₙ₊₁ ∈
Dₙ 且 qₙ₊₁ ≤ qₙ——链的极限生成滤。**可数性正是让序列可枚举的
前提**。∎

**无原子性（9.2.3-9.2.4）**：P 无原子 ⟹ 脱殊滤 G ∉ M——扩张
是真的。

机器侧 Python/Julia/Prolog 三通道实现：
- **Python**（`23_forcing.py`）：Func(I,J) 的条件枚举（product
  而非 combinations——值可独立选）、稠密性判定、build_generic
  _filter 算法（引理 9.2.2 的代码化）、Δ-系统引理的有限演示
  （两两不交族根为 ∅；共享点族根为 {0}）、**Cohen 实数的出生
  现场**（⋃G 是全长函数，含基础模型没有的信息）。
- **Julia**（`23_forcing.jl`）：同款算法的 Dict 实现 + 链相容
  性全对审计。
- **Prolog**（`23_forcing.pl`）：条件/滤/脱殊的**判定器**——
  Func(2,2) 的 9 个条件全枚举、具体 G 通过 is_filter 与
  is_generic 验证、反链相容性穷举。

## 23.3 P-名字与 M[G]（书 9.2 续）

"生活在 M 中的人"不知道 G 是什么，但他们可以准备**名字**——
用 M 中的对象描述 M[G] 中集合的"构造模板"。

> **定义（9.2.6-9.2.7）**　P-名字 τ = {(σ, p) | σ 是 P-名字,
> p ∈ P}。检查名 x̃ = {(ỹ, 1) | y ∈ x}。
>
> **值的解释（9.2.8）**　τ_G = {σ_G | (σ,p) ∈ τ ∧ p ∈ G}。
>
> **M[G] = {τ_G | τ ∈ M^P}**（9.2.10-9.2.12）。

引理 9.2.11 的六条性质中，最关键的是 **o(M) = o(M[G])**——扩
张不增加序数（名字的秩受控于原模型）。这保证了 L^M = L^{M[G]}
——第 22 章推论 9.4.3（V≠L 的一致性）的基础。

## 23.4 力迫关系（书 9.3）

> **定义（9.3.1）**　p ⊩ φ(τ₁,…,τₙ) ⟺ 对一切含 p 的脱殊滤
> G，M[G] ⊨ φ(τ₁^G,…,τₙ^G)。

这是"真值向前看"的定义——M 中的人用它讨论 M[G] 中的事实。
问题是：** ⊩ 在 M 中可定义吗？**

哥德尔的解答（定义 9.3.3）：定义语法版力迫 ⊩*，对原子公式用
"p 下稠密"条件、对复合公式用归纳。**力迫定理（9.3.7）**：

> p ⊩ φ(τ̄) ⟺ (p ⊩* φ(τ̄))^M，且 M[G] ⊨ φ(τ̄^G) ⟺ ∃p∈G
> (p ⊩ φ(τ̄))。

——M 中的人**确实可以**通过 ⊩* 讨论 M[G] 的一切。

## 23.5 M[G] ⊨ ZFC 与 CH 独立性（书 9.4-9.5）

> **定理 9.4.1**　M ⊨ ZFC + P ∈ M + G 脱殊 ⟹ M[G] ⊨ ZFC。

分离公理用 ⊩ 定义名字（9.37 式）；幂集公理用"名字的名字"（
9.38 式）；替换公理用反映定理在 M 中截取有界的名字集（9.42
式）；选择公理用 M 中的良序传递到 M[G]。∎

> **定理 9.5.12（本章终点）**　Con(ZFC) ⟹ Con(ZFC + ¬CH)。

**证明骨架**：
1. 取 P = Func(ℵ₂^M × ω, 2)（把 ℵ₂^M 个 ω-序列"钉"到 2 上）；
2. **Δ-系统引理（9.5.6）**：不可数的有限集族中有不可子族共享
   同一根——由此 P 满足 **c.c.c.**（引理 9.5.7：任意反链可数）；
3. **c.c.c. ⟹ 保持基数**（引理 9.5.11：M 的 ℵ₁、ℵ₂ 在 M[G]
   中仍是 ℵ₁、ℵ₂）；
4. 引理 9.5.4：G 给出 ℵ₂^M 个不同的 ω-序列（f_β ≠ f_β' 的
   见证集稠密）——故 (2^{ℵ₀} ≥ ℵ₂)^{M[G]}，即 **¬CH**。∎

**9.6（GCH 的相对一致性）**：Easton 式论证的思想——用更精细
的力迫使 2^{ℵ_α} = ℵ_{α+1} 对一切 α 同时成立（完整证明超出本
书范围）。

## 23.7 Python 脱殊滤构造的代码讲解

```python
def build_generic_filter(P, dense_sets, start):
    """递归构造穿过一切稠密集的滤（引理 9.2.2 的窗口版）。"""
    q = frozenset(start)
    trace = [q]
    for D in dense_sets:
        cands = [r for r in D if r >= q]       # r ⊇ q 即 r ≤ q（更强）
        assert cands, "dense set should extend any condition"
        q = min(cands, key=len)                  # 取最短的加强
        trace.append(q)
    # 生成滤：若 p ∈ G 且 p ≤ q（p ⊇ q）则 q ∈ G
    G = frozenset(p for p in P if any(p <= q for q in trace))
    return G, trace
```

两行注释值得展开：`r >= q` 在 frozenset 中是**超集**（r ⊇ q），
在力迫中是**更强**（r ≤ q）——两个偏序方向恰好相反，代码注释
铭记这一点（坑账 #78 的教训）。滤的生成取**子方向**（p ⊆ 某
链元素）——因为 p ≤ q 意味着 p ⊇ q，滤是向上封闭（在力迫序中
向上 = 在包含序中向下）。

Prolog 版（`23_forcing.pl`）的判定器提供了互补视角：
`is_dense`/`is_filter`/`is_generic` 三个谓词把定义转化为**可
查询**的约束——一个具体的 G 是否真的是滤？是否脱殊？答案由
回溯搜索自动裁决。

## 23.8 Δ-系统的最小演示

Python 的 delta_system 函数用穷举找"两两交恰为根"的子族：

```python
disjoint = [frozenset({i}) for i in range(5)]
sub, root = delta_system(disjoint)
assert root == frozenset()                          # 两两不交 → 根 ∅

shared = [frozenset({0, i}) for i in range(1, 5)]
sub2, root2 = delta_system(shared)
assert root2 == frozenset({0})                      # 共享 0 → 根 {0}
```

这是 Δ-系统引理（9.5.6）的核心直觉：**有限集族足够大时必然出
现"结构重复"——两两交退化为共同根**。真正的引理说不可数族中
有不可数子族成为 Δ-系统——有限窗口只能演示模式，不可数部分由
数学保证（机器边界如实标注）。

Δ-系统 → c.c.c. → 基数保持 → ¬CH 的四步链条是力迫法标准操作
流程（FSP）的第一个实例——每个学习力迫的人都会在此走一遍。
