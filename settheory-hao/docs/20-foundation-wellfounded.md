# 20 · 基础公理与良基归纳

> V = WF——接受 ZF 就等于接受层垒谱系是宇宙的形状。
> 但良基归纳比基础公理更普适：它对任意良基关系工作。

本章覆盖书 7.5-7.7 节（PDF 170-180 页）：基础公理的相对一致性
（Con(ZF⁻)⟹Con(ZF)）、良基关系上的归纳与递归、Mostowski 塌缩
、基础公理下新增的绝对性。

## 20.1 基础公理的相对一致性（书 7.5）

第 19 章定理 7.3.4 证了 WF ⊨ ZF（只差无穷公理）。引理 7.5.1
补上最后一环：传递类 M ⊨ ZF⁻−Pow−Inf 且 ω ∈ M ⟹ 无穷公理
在 M 中真——∅ 与后继函数的绝对性（19 章 7.4.8 的弹药）把无穷
公理的相对化约化为"M 中有个含 ω 的归纳集"。

> **定理（书 7.5.3）**　Con(ZF⁻) ⟹ Con(ZF)。基础公理相对于
> ZF⁻ 一致。

**相对一致性模板（7.5.2）**：T ⊢ M≠∅ 且 T ⊢ M ⊨ Z ⟹
Con(T) ⟹ Con(T∪Z)——下一章的 L 和第 23 章的力迫都走这条路。

**良序的绝对性（7.5.4）**：R∈M 是 X 上良序 ⟹ (R 是 X 上
良序)^M——这允许在 M 内部"看见"自己的良序。**V_ω 的故事
（7.5.5）**：V_ω ⊨ ZFC−Inf+¬Inf——有限宇宙满足选择公理
（有限良序总存在）但否定无穷——ZFC 的"减无穷加非无穷"片段
有模型，因而一致（若 ZF⁻ 一致）。

## 20.2 良基归纳与递归（书 7.6）

本章工作于 ZF⁻−Pow 中。

> **定义（7.6.1）**　R 良基于 X ⟺ X 的每个非空子集有
> R-极小元。

注意这是一个**定义模式**（对每个公式 φ_R 有一个实例），因为
量词只能约束集合不能约束类——"V 上良基"即基础公理。

**似集合性（7.6.2）**　R 在 X 上似集合 ⟺ ∀x∈X, {y∈X|yRx}
是集合。∈ 天然似集合。

**前驱（7.6.3）**　pred(X,x,R) = {y∈X|yRx}；cl(X,x,R) =
⋃ₙ predⁿ——传递闭包的推广（R=∈ 时 cl = trcl）。

> **定理（7.6.5）**　R 似集合良基 ⟹ X 的每个非空**子类**也
> 有 R-极小元（极小元Witness取 cl(X,x,R) 的交）——类上的
> 归纳从此合法。

> **良基递归定理（7.6.6）**　R 似集合良基，F : X×V → V 是
> "函数"（类函数），则存在唯一 G : X → V 使
> G(x) = F(x, G↾pred(X,x,R))。

——序数递归（4.3.5）是 R=∈ 的特例；基于良基关系的递归是
全部现代集合论构造（rank、L 层级、力迫名）的引擎。

**机器侧三通道**：

**Lean**（`Ch20Foundation.lean`）——良基递归是 Lean 的
**核心原语**：`WellFounded.fix`（结构递归的引擎）与
`WellFounded.induction`（归纳原理）是类型系统的内建：

```lean
example (α : Type) (r : α → α → Prop) (hwf : WellFounded r)
    (P : α → Prop) (h : ∀ a, (∀ b, r b a → P b) → P a) : ∀ a, P a :=
  fun a => WellFounded.induction hwf a h
```

书 7.6.6 的"函数 G"在 Lean 里是 `WellFounded.fix` 的计算
体——每个 structurally recursive 定义都在调用它。

**Isabelle/ZF**（`HS20/Foundation.thy`）——`wf_induct`（书
(7.48) 式逐字）与 `wfrec`（7.6.51 的良基递归算子）是 WF.thy
的主件：

```isabelle
thm wf_def       (* wf(r)：每个非空集有 r-极小元 *)
thm wf_induct    (* 良基归纳 *)
thm wfrec_def    (* 良基递归 *)
thm foundation   (* 基础公理 *)
```

**Python**（`20_foundation.py`）——良基归纳的可计算审计器
+ 下降链终止性 + Mostowski 塌缩的两个实例（见下节）。

## 20.3 Mostowski 塌缩（书 7.6.9-7.6.15）

> **定义（7.6.9）**　R 良基似集合于 X。Mostowski 函数
> G(x) = {G(y) | y∈X ∧ yRx}。M = ran(G) 是 (X,R) 的塌缩。

**引理 7.6.10**　(1) xRy ⟹ G(x) ∈ G(y)；(2) M 传递；
(3)（Pow 下）M ⊆ WF；(4) rank(x,X,R) = rank(G(x))。

**外延性（7.6.11）**　R 在 X 上外延 ⟺ 前驱不同则元素不同。
∈ 在传递集上天然外延（7.6.13）。

> **Mostowski 塌缩定理（7.6.15）**　R 良基似集合外延于 X
> ⟹ 存在唯一传递类 M 与同构 G : (X,R) ≅ (M,∈)。

良序的塌缩是序数（M 为序数或 On）；任何良基外延结构都可以
"变成传递集"——这是 L（第 22 章）与力迫（第 23 章）的核心
工具。

**Python 现场两个实例**（`20_foundation.py`）：

1. **R = ∈**：mostowski(x) = frozenset(mostowski(y) for y∈x)
   是**恒等**（WF 已经传递——书 7.6.13）；
2. **DAG 的合并**：a 有两个孩子 b, c（都是叶子）——b 和 c 塌
   缩为**同一个** ∅（前驱同为空——非外延关系把不同节点合并
   为同集合）。外延性条件 7.6.11 的必要性以反例形式现身。

## 20.4 基础公理下的新绝对性（书 7.7）

在 ZF 中（基础公理可用），大量新概念变得绝对：

> **定理（7.7.1）**　以下在 ZF−Pow 中是 Δ₀ 的（故对传递模型
> 绝对）：x 是序数；x 是极限序数；x 是后继序数；ω；x 是有穷
> 序数；数字 0,1,2,…,20,…。

"是序数"= "传递集 + ∈ 是线序"——后者是 Δ₀ 的（受限量词），
前提是 ∈ 良基（基础公理）使"传递集+线序"蕴含"传递集+良序"。

> **定理（7.7.3）**　x 有穷、xⁿ、x^{<ω}——全部绝对。

这些为 L 的定义（第 22 章：Def(X) 中的量词跑遍 X 的子集）和
力迫的绝对性检验（第 23 章）铺路。

## 20.5 与前后章的对账

**向前**（第 05 章）：自然数的递归定理（3.2.1）是良基递归的
最简实例（R = ∈ 限于 ω）。第 10 章的超穷递归（4.3.5）是
R = ∈ 限于 On 的情形。本章的 7.6.6 把它们统一为"任意良基关
系上的递归"——**从特殊到一般的第三步**。

**向后**（第 22 章）：L 的定义 L_α = Def(L_α) 涉及"可定义子
集"——Def(X) 的量词受限到 X，而 7.4.10/7.7.1 保证关键运算
绝对，从而 L 是传递的且 L ⊨ ZF。第 23 章力迫中的脱殊滤子构
造 M[G] 需要名空间的良基递归（7.6.6 的类版本）。

## 本章要点

1. Con(ZF⁻)⟹Con(ZF)：WF 是内部模型；相对一致性模板
   （7.5.2）是 L 和力迫的公共入口。
2. 良基归纳/递归（7.6.5/7.6.6）：任意良基似集合关系上的归纳
   与递归——序数递归是一特例；Lean 的 WellFounded.fix 是
   类型系统原语；ZF 的 wfrec/wf_induct 是库主件。
3. Mostowski 塌缩：良基外延 ≅ 传递集；R=∈ 时恒等；非外延
   关系合并节点——外延性 7.6.11 的反例现身。
4. 基础公理带来的新绝对性：序数/极限/后继/有穷/数字全部
   Δ₀ 化（7.7.1）。
5. 机器面：WellFounded.fix/induction（Lean 原语）、wfrec/
   wf_induct（ZF 库）、Python 的塌缩双实例。
