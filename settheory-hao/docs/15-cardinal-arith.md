# 15 · 基数算术

> ℵ₀ + ℵ₀ = ℵ₀，ℵ₀ · ℵ₀ = ℵ₀——无穷的算术第一次露面就把
> "加法让东西变多"的直觉送进了博物馆。

本章覆盖书 5.2 节（PDF 109-113 页）：基数的加法、乘法与幂。
⊞ 与 ⊙ 被完全驯服（= max），^ 打开通向连续统假设的大门。

## 15.1 加法与乘法：定义与良定

> **定义（书 5.2.1/5.2.3）**　κ ⊞ λ = |A ∪ B|（不交）；
> κ ⊙ λ = |A × B|。引理 5.2.2/5.2.4 保证与代表选取无关。

交换、结合、分配、单调全部照常成立；有限情形回归自然数算术。
但**无穷立刻反常**（书 5.2.2 后注）：

- κ ⊞ κ = κ（{0}×A ∪ {1}×A 不交两块拼回 κ——希尔伯特旅馆的
  算术形式）；
- ℵ₀ ⊞ ℵ₀ = ℵ₀、ℵ₀ ⊙ ℵ₀ = ℵ₀（第 06 章的交错序列与配对
  函数，现在是定理的特例）。

## 15.2 κ · κ = κ：标准序的分层证明

> **定理（书 5.2.5）**　对任意无穷基数 κ：κ ⊙ κ = κ。

**证明**是本章的技术核心（对 κ 归纳）。在 κ × κ 上定义**标准
序** ≺（书 5.4 式）：

    (α₁,β₁) ≺ (α₂,β₂) ⟺ max(α₁,β₁) < max(α₂,β₂)，
    或 max 相等且 α₁ < α₂，或 max、α 都相等且 β₁ < β₂。

三步：(≺) 是良序（连接性逐层比较；良基性：非空子集先取 max 最
小的层，层内先取 α 最小的列、再取 β 最小的点——三重取最小）；
每个真前段的序型 < κ（前段落在 (γ+1)×(γ+1) 内，γ < κ，归纳
假设 κ' ⊙ κ' = κ' 对一切无穷 κ' < κ 给出 |前段| ≤ κ' < κ）；
于是 κ × κ 的序型 ≥ κ（单射 α ↦ (α,α)）且每个元素的前段 < κ
迫使序型 ≤ κ——夹出 κ ⊙ κ = κ。∎ 图 5.1 的螺旋就是它。

> **推论（书 5.2.6）**　κ ⊞ λ = κ ⊙ λ = max(κ,λ)（无穷基数）。

**机器现场**（`examples/julia/15_cardinal_arith.jl`）把标准序跑
在 ω×ω 的 100×100 窗口上：按层枚举恰好 10⁴ 对不重不漏、枚举
严格递增、第 n 层恰 **2n+1** 个元素：

```julia
function std_enum(N)
    out = Tuple{Int,Int}[]
    for n in 0:N-1
        layer = [(a, n) for a in 0:n-1]        # 边的上半（α<n, β=n）
        append!(layer, [(n, b) for b in 0:n])  # 边的下半含角 (n,n)
        append!(out, layer)
    end
    out
end

layers = [length(std_enum(n+1)) - length(std_enum(n)) for n in 0:8]
@assert layers == [1, 3, 5, 7, 9, 11, 13, 15, 17]
```

"每层 < κ、κ 层相并"正是证明的骨架——窗口里的 1,3,5,7,… 就
是归纳假设要吃掉的每一口。κ⊞κ=κ 的偶奇分解现场也在同一单元
（evens + odds = ω 的两个不交 ω-块）。

Lean 通道（`examples/lean/Sethao/Ch15CardArith.lean`）把整组定律
定理化——**书 5.2.5 与 5.2.6 在 mathlib 里各是一行**：

```lean
example (κ : Cardinal) (h : Cardinal.aleph0 ≤ κ) : κ * κ = κ :=
  Cardinal.mul_eq_self h

example (κ μ : Cardinal) (hκ : Cardinal.aleph0 ≤ κ) :
    κ + μ = max κ μ :=
  Cardinal.add_eq_max hκ

example (κ μ : Cardinal) (hκ : Cardinal.aleph0 ≤ κ) :
    κ * μ = max κ μ :=
  Cardinal.mul_eq_max hκ (Or.inl hκ)
```

有限对照（3+3=6、3·3=9，`norm_num`）画清吸收律的**无穷专利**。

## 15.3 幂：连续统的哨所

> **定义（书 5.2.7）**　κ^λ = |A^B|（B 到 A 的函数全体）。

基本性质：单调、κ^λ·κ^μ = κ^{λ⊞μ}（拆定义域）、κ^{λ⊙μ} =
(κ^λ)^μ（柯里化）、**κ² = κ ⊙ κ**（二元函数即对偶）。Cantor
定理给 κ < 2^κ——幂总是往上走。**2^{ℵ₀} = c**（实数基数，康托
的名字）；**CH：c = ℵ₁？**——第 17 章正式摆桌，第 22-23 章证明
它在 ZFC 内不可判定。

## 15.4 符号计算器与算术地形图

Python 通道（`examples/python/15_cardinal_arith.py`）做成了
**基数算术的符号计算器**：基数 = ('fin', n) 或 ('aleph0',)，
⊞/⊙ 按 max 吸收、幂走 Cantor 梯（2^ℵ₀ 返回 'c' 记号——计算器
**拒绝假装知道 c 在 ℵ 梯上的位置**，这正是 CH 的问号）：

```python
assert kadd(A0, A0) == kmul(A0, A0) == A0          # 5.2.6
assert kpow(FIN(2), A0) == ('c',)                  # 2^ℵ₀ = c
assert kpow(A0, FIN(3)) == A0                      # ℵ₀³ = ℵ₀
```

书 5.2 的每条定律（交换/结合/分配/单调/κ⊙2=κ⊞κ）逐条审计。
算术地形图总览：

| 运算 | 有穷 | 无穷 | 驯服程度 |
|---|---|---|---|
| κ ⊞ λ | 算术 | max(κ,λ) | 完全 |
| κ ⊙ λ | 算术 | max(κ,λ) | 完全 |
| κ^λ | 算术 | **大片未知** | CH 只是第一格 |

第 16 章（共尾）将解释"为什么 ⊞/⊙ 如此温顺而 ^ 如此狂野"——
答案藏在奇异基数的共尾性里。

## 15.5 细节三则与速查表

**κ⊙2 = κ⊞κ 的来历**（书 5.2.4 末）：{0,1}×A = {0}×A ∪
{1}×A 是两个不交 κ-块——按 ⊞ 定义恰是 κ⊞κ，按 ⊙ 定义又是
κ⊙2——两个运算在此首次握手。**n·ℵ₀ = ℵ₀（n ≥ 2）**与
**κ ≥ 2 ⟹ κ^{ℵ₀} ≥ c** 同款。

**对角线的第四次出场**：Cantor 不等式 a < 2^a 的证明就是对角
集（第 01 章罗素类 → 第 02 章 1.4.8 → 第 08 章对角线 → 本章
a < 2^a）——四次同一个构造，四个定理。模式识别练习：把
"f : X → P(X)" 的假设换成 "g : ℕ → ℝ"（第 08 章）、
"R = {x | x ∉ x}"（第 01 章），对角集的形态分别是什么？

**五通道分工**：Lean 持有全部结构律的定理化（mul_eq_self/
add_eq_max 各一行）；Isabelle 持有初始序数的官方定义与 csucc；
Julia 持有标准序的分层枚举（层尺寸 1,3,5,7,… 的骨架）；
Python 持有符号计算器（c 保留为记号——计算器的诚实）；本章
无 Coq/Prolog 单元（结构律全部被 Lean 覆盖，穷举侧无新内容——
这是"每条定理至少一个通道"原则的反向应用：不重复覆盖）。

速查总表：

| 等式 | 有限 | 无穷 | 出处 |
|---|---|---|---|
| κ⊞λ | n+m | max | 5.2.6 |
| κ⊙λ | nm | max | 5.2.6 |
| κ⊙κ | n² | κ | 5.2.5 |
| κ^0 | 1 | 1 | 定义 |
| κ^n | k^n | κ（n≥1, κ 无穷） | 幂吸收 |
| 2^κ | 2^n | > κ，ZFC 不定位于 ℵ 梯 | Cantor/CH |

## 本章要点

1. 基数加乘良定（与代表无关）；交换结合分配单调照常。
2. **κ⊙κ = κ**（标准序分层证明：层 < κ、κ 层并集；窗口里
   1,3,5,7,… 的层尺寸就是骨架）；推论 κ⊞λ = κ⊙λ = max。
3. 幂：κ < 2^κ；2^{ℵ₀} = c；CH 的问号从这里升起——⊞/⊙ 已被
   完全驯服，^ 是集合论的黑暗森林。
4. 机器面：Lean 的 mul_eq_self/add_eq_max 一行定理化；Julia 的
   分层枚举；Python 的符号计算器（c 保留为记号）。
