# 13 · 选择公理

> "选择公理显然为真，良序定理显然为假；佐恩引理只有天知道。"
> ——数学 folklore（原书 4.6 节引）

本章覆盖书 4.6 节（PDF 94-101 页）：选择公理的四种等价形式、
Zorn 引理与 Hausdorff 极大原理、Tychonoff 定理的等价性、以及
选择公理的怪异推论（不可测集）。

## 13.1 四种等价形式

> **定理（书 4.6.1）**　以下等价：
> (1) 非空族的积非空（∀i, X_i ≠ ∅ → Π X_i ≠ ∅）；
> (2) 两两不交非空族有选择集 S（|S ∩ X_i| = 1）；
> (3) 每个非空族有选择函数 f（f(X_i) ∈ X_i）；
> (4) **良序定理**：每个集合可良序化。

证明环：(1)→(2) 取 g ∈ Π X_i，S = ran(g)；(2)→(3) **不交化
技巧**：Y_i = {i} × X_i 打标签，选完撕标签；(3)→(4) 对 P(X)−{∅}
的选择函数做超穷递归：H(α) = f(X − H[α])，用 **Hartogs 数**
（第 10 章 4.2.12！）保证递归在装满 X 之前终止——枚举即良序；
(4)→(1) 良序取最小元即得选择。∎ 注意 (3)→(4) 是唯一实质使用
超穷递归的一环，Hartogs 数再次扮演"无 AC 世界里的序数天花板"。

机器侧：Coq 把 (3)→(2) 的影子证成定理（`ac2_shadow`：选择函数
的像集与每块之交至多单点）；Python/Prolog 演示不交化技巧——
打标签族两两不交（平凡），撕标签后选择合法（不平凡处在于原族
可以相交）。

## 13.2 Zorn 引理与 Hausdorff 极大原理

> **定理（书 4.6.2）**　以下等价：
> (1) AC；(2) **Hausdorff 极大原理**：任何偏序集有极大链；
> (3) **Zorn 引理**：每个链都有上界的偏序集有极大元。

(1)→(2)：用选择函数超穷递归地"爬链"——每步选一个能延长链的
元素，Hartogs 数保证过程终止，爬出来的链不能再延长即极大；
(2)→(3)：极大链的上界就是极大元（若有人严格在其上，链可延长，
矛盾）；(3)→(1)：Zorn 应用于"部分选择函数"偏序集（第 03 章
的相容系统！⋃C 上界、极大元的定义域必须全覆盖——否则还能扩一
格）。∎

Lean 通道点名 mathlib 的 Zorn 原文——注意 4.33 里它在**根命名
空间**且要求显式传递性：

```lean
#check @exists_maximal_of_chains_bounded

example (α : Type) (r : α → α → Prop) (trans : ∀ a b c, r a b → r b c → r a c)
    (h : ∀ c : Set α, IsChain r c → ∃ ub, ∀ a ∈ c, r a ub) :
    ∃ m, ∀ a, r m a → r a m :=
  exists_maximal_of_chains_bounded h (fun h1 h2 => trans _ _ _ h1 h2)
```

（mathlib 把"极大"写成弱化的 r m a → r a m。）有限版 Zorn 在
Python/Prolog 中是**构造**：P({1,2,3}) 挖掉顶后仍有三个极大元
{1,2}、{1,3}、{2,3}；极大链恰有两条（经 {a} 或经 {b}）——
有限世界里"每链有上界⟹有极大元"是鸽笼式的平凡事，**公理的
重量全在无穷**。

## 13.3 有限选择不需要公理

Coq 通道把这条界线画得最清楚：对**有限**族，选择函数是纯构造
（`choice_list` 逐表取头，`choice_length`/`choice_picks_member`
两条定理零公理）；而 `Axiom AC1` 声明之后，Coq 明确报告它未被
证明——类型论不能白送无穷选择。这正是原书所说"引起争论的不是
选择，是**同时**对无穷多个集合做选择"的机器化表述。

## 13.4 Tychonoff 定理与不可测集（讲解）

**Tychonoff**（书 4.6.4）：紧空间的任意积仍紧 ⟺ AC。正向证明
用超滤（第 18 章伏笔）：有穷交性质的闭集族生成超滤 F，每个坐标
投影的闭包族有交，AC 选出交点，反证它在 ⋂C 中。反向则把每个
非空集 X_i 加一个孤立点 * 变成紧空间，积的紧性给出选择。本
教程不机器化此定理（需要超滤引理的全装置），指向第 18 章。

**不可测集**（书 4.6.9-4.6.10）：取 ℚ-陪集的选择集 S（Vitali
构造），S 的有理平移两两不交、并覆盖 ℝ——若 S 可测，或测度 0
（则 ℝ 测度 0）或正测度（则 [0,1] 内装不下有限个平移），矛盾。
故 **AC ⟹ 存在不可测集**。ℝ 上的"长度"无法对全体子集定义——
这是 AC 送来的第一个反直觉礼物。

## 13.5 习题与机器侧总账

书 4.7 习题里本章相关的：4.7.25（AC 的又一等价形式：每个集合

ZF-AC 库以十九个 AC/WO 编号命题（AC0-AC19、WO1-WO8）及其两两

与书 4.6.1 直接对应的四件。

## 13.6 公案简史：从 Zermelo 到 Martin

- **1904**：Zermelo 用选择公理证明良序定理，掀起风波；
- **1908**：Zermelo 发表公理化集合论（AC 列为公理）回应批评；
- **1938**：Gödel 证明 AC 与 ZF 一致（可构成宇宙 L）；
- **1963**：Cohen 力迫证明 ¬AC 也与 ZF 一致——AC 真正"独立"；
- 争议史的名句即本章题词：选择公理显然真、良序定理显然假——
  而它们**等价**（4.6.1），说明"显然性"不是可靠的逻辑向导。

原书立场（4.6 开篇）值得整段回味：van der Waerden《近世代数》
第二版迫于压力删去 AC，代数学家激烈反对，第三版又加回来——
"代数学家们坚持认为这个公理对他们的学科变得必不可少"。而
Martin 的辩护则代表了当代主流：不能**定义**选择函数与选择函数
**存在**是两回事。

## 13.7 Zorn 引理使用指南（未来章节的路标）

本教程后续章节将多次按下 Zorn 按钮，此处立牌：

| 应用 | 偏序集 | 链的上界 | 极大元给出 |
|---|---|---|---|
| 每个向量空间有基（代数） | 线性无关子集族 | 并 | 基 |
| 滤子延拓到超滤（第 18 章） | 滤子族 | 交 | 超滤 |
| 每个理想含于极大理想（代数） | 理想族 | 并 | 极大理想 |
| 偏序集的线性扩张（组合） | 部分线性序 | 并 | 线性扩张 |

模式永远相同：对象 = 部分解答，序 = 部分解答的相容比较，
上界 = 部分解答的并（第 03 章相容系统的遗产），极大元 = 不能
再扩的解答，最后论证"不能再扩"恰好是"完整"。读者到第 18 章
（滤子延拓）时会看到这张表的第二次兑现。

## 13.8 (3)→(4) 的 Hartogs 递归：良序定理证明的展开

四形式等价中最实质的一环展开如下（书 4.6.1 证明的 (3)→(4)）。
给定集合 X 与 P(X)−{∅} 上的选择函数 f，**超穷递归**定义：

    H(α) = f(X − H[α])，只要 X − H[α] ≠ ∅。

三个观察收尾：

1. **H 单射**：α < β 时 H[α] ⊆ H[β] 且 H(β) ∉ H[α]（每步选的
   都是新元素）；
2. **dom(H) 是序数且 ≤ H(X)**：若 dom(H) 超过 Hartogs 数
   H(X)（第 10 章 4.2.12！），单射 H : dom(H) → X 与 Hartogs 的
   极小性矛盾——递归**必然在装满 X 之前停止**；
3. **H 满**：若 X − H[dom H] ≠ ∅，递归能再走一步，矛盾。

于是 H 是某个序数 γ 到 X 的双射，x < y ⟺ H⁻¹(x) < H⁻¹(y)
拉回 X 上的良序。∎ **Hartogs 数在此从"装不下的序数"变身"递归
的刹车"**——这是它在本教程的第二次出场（第一次：第 10 章证
On 是真类），第三次在第 14 章（基数 = 初始序数的存在性）。

## 13.9 Vitali 构造的细节

书 4.6.9 的不可测集构造，逐步展开：

1. ℚ 把 ℝ 分成不可数多个可数陪集 r + ℚ；AC 选出每个陪集的
   代表，得 S（每个陪集恰取一点）；
2. S 的有理平移两两不交：s₁+p = s₂+q ⟹ s₁−s₂ ∈ ℚ ⟹ 同陪集
   ⟹ s₁ = s₂（且 p = q）；
3. ⋃_{p∈ℚ∩[0,1]} (S+p) ⊆ [inf S−?, sup S+?] 有界（取 S∩[0,1]
   的版本），但覆盖 ℝ；
4. 若 μ(S) = 0：可数并给 μ(ℝ) = 0，荒谬；若 μ(S) > 0：n 个
   平移的并的测度 n·μ(S) 超过容器——荒谬。故 S 不可测。∎

证明里 AC 只用在第一步（选代表）——**测度的可数可加性与 AC
在 P(ℝ) 上不相容**。勒贝格的补救（书 4.6.7）：外测度限制到
"可测集"类 M 上，可数可加性恢复——代价正是 P(ℝ) ⊄ M。

## 13.10 五通道分工总账

| 通道 | 单元的灵魂 |
|---|---|
| Lean | Zorn 根命名空间原文 + Classical.choice/em 的地基图 + 有限选择的零公理构造 |
| Isabelle | ZF-AC 库等价网络（AC1/WO1/ex_choice_fun/AC1_WO2/WO1_AC1）——Rubin & Rubin 全书的机器化 |
| Coq | AC1 记账 Axiom + 有限选择构造（choice_length/choice_picks_member 零公理） + (3)→(2) 影子定理 |
| Python | 不交化技巧、有限 Zorn/Hausdorff（P({1,2,3}) 挖顶后三极大元）|
| Prolog | member 回溯即选择、打标签/撕标签、极大链恰两条的终审 |

五个单元合起来恰好覆盖书 4.6 的证明骨架：(3)→(2) 的 Coq 定理、
(2)→(3) 的打标签审计、(3)→(4) 的 Isabelle 官方件、Zorn 应用的
有限预演、有限/无穷分界的构造性对照。等价网络的每一环都有机器
着落——这是 B6 批次"每条定理至少有一个通道作证"原则的完整体现。

## 本章要点

1. AC 四形式等价：积非空 ⟺ 选择集 ⟺ 选择函数 ⟺ 良序定理；
   (3)→(4) 靠超穷递归 + Hartogs，是唯一的"硬"环节。
2. Zorn = AC = Hausdorff 极大原理；Zorn 的标准用法是"部分选择
   函数"偏序集（第 03 章相容系统的收割）。
3. 有限选择是构造（Coq 零公理两定理）；无穷同时选择才是公理。
4. Tychonoff ⟺ AC（超滤装置，第 18 章）；Vitali：AC ⟹ 不可测
   集存在——"长度"不可能对 P(ℝ) 全定义。
5. 机器面：Lean 根命名空间 Zorn（显式传递性）；Isabelle ZF-AC
   库的等价网络官方件；Coq 公理记账与有限选择的构造性对照；
   Python/Prolog 的不交化与有限 Zorn 实验。
