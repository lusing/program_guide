This Section presents a language for writing realizations of formulas derivable
in NJp. Basic constructs of this language are pairing p with projections po,pi
satisfying:
Pi(p(to,ti)) = ti, i = 0, 1

and lambda abstraction providing explicit definitions:
(Ar.t)(u) = t[r /u],
(4.2)
where t[r/u] stands for the result of substituting a term u for all free occurrences

containing a variable x, it is possible to define a function (denoted by Xa.t) that
outputs the value t[r/u] when the value of x is set to u. Sometimes we omit a
dot and write Art.

constructions are connected with disjunction and case distinction.
