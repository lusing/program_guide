# 12 · OOP I：构造、析构、属性、静态成员

> 对应示例：`examples/12_oop1/`

FB 从 0.90（2004）起给 Type 长出了完整的 OOP 能力：构造/析构、属性、静态成员、继承与多态（13 章）、运算符重载（14 章）。语法是 `Declare` + 体定义分离的"两段式"——声明写在 Type 里，实现写在 Type 外并带 `Type名.` 前缀。

## 12.1 构造器与析构器

```freebasic
Type Widget
    Public:
        Declare Constructor(id As Integer, w As Double = 1.0)   ' 可带默认参数
        Declare Destructor()
    Private:
        Dim As Integer id
        Dim As Double w_
End Type

Constructor Widget(id As Integer, w As Double)
    This.id = id        ' This. 显式指字段（形参同名时必须）
    This.w_ = w
End Constructor

Destructor Widget()
    ' 离开作用域时自动执行
End Destructor
```

- 局部 Type 变量**离开作用域自动调析构器**（实测：`Scope ... End Scope` 出来计数归零）——FB 版 RAII，`Allocate` 的裸指针可得自己 `Deallocate`。
- `This` 指当前实例；字段与形参同名时 `This.x = x` 是唯一正确写法（14 章有个我亲踩的自赋值坑）。

## 12.2 Property：带逻辑的字段

```freebasic
Declare Property width() As Double          ' 读
Declare Property width(w As Double)         ' 写（同名重载，按形参区分）

Property Widget.width(w As Double)
    If w < 0 Then w = 0                     ' 写时校验：负值钳 0
    This.w_ = w
End Property
```

外界用起来和字段一模一样（`b.width = -5` / `Print b.width`），但读写都过你的代码。数据字段放 `Private:`，对外只开 Property——C# 同款口味。

## 12.3 静态成员与静态方法

```freebasic
Type Widget
    Static count As Integer                      ' 声明
    Declare Static Function created() As Integer ' 静态方法：不绑实例
End Type

Static Widget.count As Integer = 0               ' 定义在 Type 外（Static 前缀）
```

- 静态成员**所有实例共享**，`Widget.count` 直接用类型名访问。
- 定义必须放 Type 外（`Static Widget.count As Integer = 0`），与 C++ 的类外初始化一个道理。
- `Static` 方法里只能碰静态成员。

## 12.4 访问区

```freebasic
Type Widget
    Public:          ' 外界可见（默认）
        ...
    Private:         ' 只有本 Type 的过程可见
        ...
    Protected:       ' 本 Type + 派生类可见（13 章）
        ...
End Type
```

访问区是"标签式"的：写下后对后续所有成员生效，直到下一个标签。

## 12.5 坑位清单（1.10.1 实测）

1. 静态成员**声明在 Type 内、定义在 Type 外**（`Static Widget.count As Integer = 0`），漏定义链接报错。
2. `Property` 读写两个版本靠**同名不同参**重载，缺一个另一方向就编译错。
3. 析构按作用域自动触发；`New` 的堆对象要手动 `Delete`（13 章）。
4. 形参遮蔽字段时 `x = x` 是静默自赋值——构造器里统一 `This.` 前缀。
5. Type 过程的实现写在 Type 外时，签名要带 `Type名.` 前缀（`Property Widget.width(...)`）。
