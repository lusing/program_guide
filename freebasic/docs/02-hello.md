# 02 · 第一个程序

> 对应示例：`examples/02_hello/`

## 2.1 写下来、编出来

```freebasic
Print "Hello, FreeBASIC!"
```

存成 `hello.bas`，编译运行：

```bash
G:/scoop/apps/freebasic/current/fbc.exe hello.bas          # 产出 hello.exe
./hello.exe
```

`fbc` 直接用源文件名当输出名；`-x` 指定输出（本教程标准用法）：

```bash
fbc -w all hello.bas -x build/hello.exe
```

单文件编译**不留中间 .o**（fbc 自动清理），仓库里只有源码和 exe。

## 2.2 Print 的细节

| 写法 | 行为 |
|---|---|
| `Print a; b; c` | 分号连接不换行；**数字两侧自动补一个空格**，字符串原样 |
| `Print a, b` | 逗号跳到下一个打印区（约 14 列一区） |
| `Print` | 空行 |
| `Print x & "元"` | `&` 字符串拼接（自动把数字转字符串） |
| `Print Using "#.##"; x` | 模板格式化（04 章细讲） |

注意 `Print "a ="; 42` 输出 `a = 42`——那个空格是运行时给数字加的，不是我们写的。

## 2.3 编码纪律：无 BOM 是铁律 ⭐

本教程所有源码 **UTF-8 无 BOM**，控制台先 `chcp 65001`。这不是洁癖，是 fbc 1.10.1 实测行为：

| 源码形态 | String 字面量 | 控制台输出 |
|---|---|---|
| **无 BOM** | 按字节原样透传（UTF-8 字节） | CP 65001 下中文完美；管道重定向也是干净 UTF-8 |
| **带 BOM** | 被 fbc 当作"UTF-8 源"**转成系统 GBK** 存储 | 走宽字符 API，重定向管道里是 UTF-16 字节流（`w\0s\0`），自动化验证全乱 |

实测带 BOM 后 `"你好"` 的 `Len()` 从 6（UTF-8 字节）变成 4（GBK 字节），整个程序的输出管道里变成 UTF-16——**CI/脚本验证直接报废**。无 BOM + `chcp 65001` 是唯一确定性行为。副作用见 07 章：无 BOM 时 `WString` 字面量会按系统 GBK 误解 UTF-8 源码，宽字符场景用 `ChrW` 拼或走转换函数。

> 平台标注：上表的 GBK 转码/宽字符输出是 **Windows 构建**行为（"系统编码"是 GBK 所致）。Linux 构建的系统编码就是 UTF-8，终端原生 UTF-8、无 `chcp` 一说；但**无 BOM 纪律跨平台不变**——Linux 下带 BOM 同样改变字面量的存储语义，别指望平台帮你兜底。

## 2.4 结束与暂停

```freebasic
Sleep 500      ' 暂停 500 毫秒（gfx 程序限时自退出的标准写法）
Sleep          ' 无参：等按键
End 0          ' 立即结束并给退出码 0（验证脚本的判定基准）
```

`End 0` 之外的路径出错时，FB 运行时会打印错误并返回非零退出码（如 `-exx` 下数组越界 = 退出码 6）。

## 2.6 fbc 常用选项速览

| 选项 | 作用 | 本教程用法 |
|---|---|---|
| `-x 路径` | 指定输出文件 | 全部示例 |
| `-w all` | 全部警告级别 | 全部示例（要求零诊断） |
| `-exx` | 数组边界/空指针运行时检查 | 与 -g 组成验证第一层 |
| `-g` | 调试信息 + **激活 Assert**（1.10.1 实测：不是 -exx！） | 与 -exx 组成验证第一层 |
| `-lang qb` | QB 兼容方言 | 22 章 |
| `-pp` | 只输出预处理结果 | 23 章 |
| `-target xxx` | 交叉编译目标 | 23 章 |

## 2.7 坑位清单（1.10.1 实测）

1. **BOM 大坑**：带 BOM 的 UTF-8 源 → 字面量转 GBK + 宽字符输出，管道验证报废。全仓库无 BOM。
2. 数字两侧自动补空格：`Print "["; 5; "]"` 是 `[ 5 ]` 不是 `[5]`；要紧凑用 `Print "["; Str(5); "]"`。
3. `Print` 到 gfx 窗口：`ScreenRes` 之后 `Print` 输出进图形窗口的文字层，不再进控制台——要往真控制台输出用 `Open Cons`（18 章）。
4. 单文件 `fbc x.bas -x out.exe` 不留 `.o`；多文件同样自动清理（11 章实测）。
