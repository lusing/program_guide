# 18 · 编译期魔法：Template Haskell 与 Generics ⭐

> 对应示例：`examples/18_th/`

## 18.1 引号与拼接

Template Haskell（TH）让代码生成代码。**引号**取语法树，**拼接**在编译期执行：

```haskell
{-# LANGUAGE TemplateHaskell #-}

answer :: Int
answer = $( [| 40 + 2 |] )       -- 编译期算成字面量 42，运行时零计算
```

typed TH（带类型检查的引号，`$$` 拼接）：

```haskell
typedAnswer :: Int
typedAnswer = $$( [|| 41 + 1 ||] )
```

**9.12 实测坑**：`$$` 必须紧贴括号——`$$ ( … )` 带空格直接 parse error（`$` 无此限制）。

## 18.2 reify：向编译器提问

编译期读取类型的元信息——`Maybe` 有几个构造子？

```haskell
maybeCons :: Int
maybeCons = $( do
    info <- reify ''Maybe                    -- ''T 是类型引号（'f 是函数名引号）
    case info of
        TyConI (DataD _ _ _ _ cons _) -> litE (integerL (fromIntegral (length cons)))
        _                                 -> fail "不是数据类型" )
```

编译完 `maybeCons` 就是 `2`。这是"宏"与"生成"之外 TH 的第三种用法：**自省**。

## 18.3 lift：把值抬成表达式

```haskell
compileTimeTable :: [Int]
compileTimeTable = $( lift (map (^ 2) [1 .. 8 :: Int]) )   -- 编译期预计算 [1,4,…,64]
```

## 18.4 阶段限制

**拼接不能引用同模块的定义**（先有鸡还是先有蛋：拼接展开时同模块还没编译完）。TH 与被引用
的定义必须分两个模块——24 章工程里如果生成访问器，就拆 `Defs.hs` + `TH.hs`。

## 18.5 GHC.Generics：不写宏的结构自省

不想碰 TH？`deriving Generic` 送你一套"形状"类型（Rep），元信息用普通类型类读：

```haskell
import GHC.Generics (Generic (..), Datatype (datatypeName))

data Rec = Rec { ra :: Int, rb :: String }
    deriving (Show, Eq, Generic)

recTypeName :: Rec -> String
recTypeName r = datatypeName (from r)       -- "Rec"——零模板代码
```

与 `deriving stock`（编译器生成）/ `deriving newtype`（借底层实例）合为三路：**stock 派生、
Generics 泛型函数、TH 生成**——按"要现成的、要自省的、要生成的"选型。

## 18.6 生态一瞥

lens 的 `makeLenses`、aeson 的 `deriveJSON`、spectacle 的样板生成——全是 TH 的应用层。
理解 `$(…)` 就能读懂那些魔法行。

## 18.7 坑位清单

1. **`$$` 紧贴括号**（9.12 实测）：`$$ (` 空格版 parse error（18.1）。
2. **导入路径坑（实测连环）**：`DataD` 是 `Dec` 的构造子（`Dec (DataD)`）、`TyConI` 是 `Info`
   的构造子（`Info (TyConI)`）、`lift` 在 `Language.Haskell.TH.Syntax`——TH 的导出层级比直觉绕。
3. **阶段限制**：拼接引用同模块定义直接报"not in scope at splice time"——拆模块（18.4）。
4. **拼接在 do 里返回值不再套 pure**：`$( do … litE … )` 的 do 块本身是 Q Exp——`pure (litE …)`
   类型就错了（实测，返回 ExpQ 套了一层）（18.2）。
5. **TH 拖慢编译**：生成代码也要编译——工业项目节制使用（18.6）。
