# 11 泛等公理 —— 等价就是相等

> 对照代码：[`examples/11_univalence.v`](../examples/11_univalence.v)

这是 HoTT 的心脏。泛等公理用一句话说完：

> 对任意类型 A、B，**(A = B) ≃ (A ≃ B)**。两个类型相等，当且仅当它们等价。

这一章解释这句话的精确含义、它为什么合理、它带来的第一个震撼结论（`Type` 不是集合），以及它与 transport 的接口——后面所有覆叠证明都走这个接口。

## 11.1 一个免费的方向

先看不需要公理的那一半。若有路径 `p : A = B`，沿 `p` 搬运（把 `Type` 看成自身上的类型族）给出一个函数 `A -> B`，它是等价——路径归纳：`p` 是恒等时它就是恒等映射。

这和第 07 章的“路径与等价构成平行的群胚”相呼应：从路径到等价有一个自然的函子。泛等断言的是：这个函子本身是等价。

## 11.2 泛等：这个方向是等价

于是有逆映射，把等价变成路径。两者互逆：把路径变成等价再变回来，得到原路径；把等价变成路径再变回来，得到原等价。

和函数外延一样，泛等做成空的类型类。需要它的定理写成假设，或者导入全局实例。`Require Import HoTT` 并不包含这一步。

## 11.3 它为什么合理

**从数学实践看。** 数学家一直把同构的结构当成相同的——“ℝ 的完备有序域在同构意义下唯一”之后，就放心地说“那个实数域”。泛等把这个习惯变成了形式系统里的定理：等价的类型字面上相等，所以关于一个类型证明的任何性质自动对等价的类型成立（第 18 章）。

**从同伦论看。** 把 `Type` 想成“所有空间构成的空间”。在这个空间里，两个点（空间）之间的一条路径应该是什么？同伦论的答案是同伦等价。泛等说：`Type` 的路径结构就是等价结构。它让类型论的宇宙真的像一个分类空间。

**从一致性看。** 泛等在 Voevodsky 的单纯集模型里成立，所以加上它不会导致矛盾。它和经典逻辑里的排中律相容，但与 UIP 不相容——下一节就是不相容的证据。

## 11.4 第一个后果：`Type` 不是集合

如果 `Type` 是集合，那么 `Bool = Bool` 的任意两条路径相等。但泛等给出两条不同的路径：一条来自恒等等价，一条来自取反。

要证这两条路径不等，用第 05 章的套路：找一个区分它们的观测。沿“取反这条路径”搬运 `true` 得到 `false`，沿恒等路径搬运得到 `true`，而 `true ≠ false`。如果两条路径相等，搬运结果就该相等，矛盾。

这个结论的意义：**宇宙 `Type` 有非平凡的路径结构。** 它至少是 1-型（事实上任何层级都不是——`Type` 里有任意高阶的同伦）。于是“两个类型相等”这件事本身有内容：`Bool = Bool` 恰好对应 `Bool` 的自同构，有两个。

泛等不抹平差别。它增加了相等的证据，而不是把等价的类型“变成同一个”。`Bool` 还是 `Bool`，只是它们之间现在有两条不同的路径。

## 11.5 泛等的计算律——也是唯一的计算律

泛等是公理，由等价造出的路径不会归约。它唯一的“计算规则”是搬运的行为：

> **沿“由等价 f 造出的路径”搬运，就是作用 f。**

这是泛等与 transport 的接口。库里所有关于这类路径的推理最终都化到这一条上。第 13 章与第 24 章会一再使用：覆叠的纤维沿环路走一圈，效果就是那个自等价。

其他行为律把路径运算和等价运算对应起来：恒等等价给出恒等路径，逆等价给出逆路径，等价的复合给出路径的复合。这正是说“把等价变成路径”是群胚之间的函子——第 07 章的那张对照表，现在合为一张。

因为不会归约，`simpl` 和求值都动不了它。实践中的应对：想清楚要在哪一层化开，用行为律改写。这是泛等的已知代价——加上它之后失去了规范性：存在不能归约成构造子形式的闭项。立方类型论解决了这个问题，但那是另一个系统。

## 11.6 对等价做归纳

有了泛等，第 07 章“沿等价归纳”升级成真正的路径归纳：要对所有 `V` 和所有 `w : U ≃ V` 证明某个断言，只需对 `(U, 恒等等价)` 证明。证明思路：把等价变成路径，对路径做归纳，再变回来。

这意味着**关于等价的所有性质，只要在恒等等价上成立就处处成立**——和路径归纳一样强大，也一样要求终点自由。

## 11.7 结构沿等价搬运（预告）

泛等最实用的后果：任何 `S : Type -> Type` 定义的结构都能沿等价搬运。`S X` 可以是“X 上的一个群结构”“X 是集合”“X 上有一个判定相等的算法”——只要 `X ≃ Y`，`Y` 就自动拥有同样的东西。第 18 章展开这件事。

## 小结

- 从相等到等价零公理；泛等说这个方向是等价，逆映射把等价变成路径。
- 泛等让 `Type` 的路径结构等于等价结构：数学里“同构即相同”的形式化。
- `Type` 不是集合：`Bool = Bool` 有两条不同的路径（恒等与取反）。
- 唯一的计算律：沿由等价造出的路径搬运，就是作用这个等价。
- 等价归纳：关于等价的性质在恒等等价上成立即可。

## 常见误区

1. **以为泛等让所有等价的类型“变成同一个”。** 不是。路径是有内容的；泛等增加了相等的证据，而不是抹平差别。
2. **期待由等价造出的路径能计算。** 它是公理，不会归约；只能用搬运行为律改写。
3. **以为泛等与排中律冲突。** 不冲突；泛等与命题层面的排中律相容。它冲突的是 UIP。
4. **以为“等价保持性质”自动成立。** 对一般的 `S : Type -> Type` 需要泛等。截断层级是例外，因为等价已经对齐了路径。

## 练习

1. `Bool + Bool` 与 `Bool * Bool` 等价。泛等给出它们之间的一条路径。这条路径“是什么”？
2. 用 11.4 的思路证明 `Type` 不是集合，不必写出全部路径代数。
3. `Unit = Unit` 有几个元素？`Bool = Bool` 有几个？`nat = nat` 呢？（后者在泛等下等价于 `nat` 的所有自同构构成的类型。）
