# 07 等价 —— 什么叫“两个类型一样”

> 对照代码：[`examples/07_equivalences.v`](../examples/07_equivalences.v)

集合论里“两个集合一样”有一个清楚的答案：存在双射。类型论里这个问题微妙得多，因为类型不只是点的集合，还有路径、路径之间的路径……“一样”必须把所有这些层次都对上。这一章给出 HoTT 的回答——**等价**——并解释为什么它的定义看起来比“有逆函数”复杂一点，以及这点复杂换来了什么。

## 7.1 第一次尝试：有逆函数

直觉的定义：`f : A -> B` 是等价，如果有 `g : B -> A` 使得往返都同伦于恒等。这个概念叫**拟逆**。

它在“是否存在”的意义上完全正确：`f` 有拟逆当且仅当它是等价。问题出在**数据**上。所有拟逆构成的类型不是命题——同一个 `f` 可以有“不同”的拟逆证据，因为两个同伦（往、返）可以独立选取，它们之间缺少一个相容条件。这会导致“带拟逆的函数”和“A 与 B 的等价”这个概念在高阶上对不齐：你本想谈论一个性质，结果多带了一份无关的结构。

一个思想实验：取圆上的恒等映射。左逆同伦可以选“处处停在原地”，也可以在某些点上绕几圈再回来——这些选择在拟逆的类型里是不同的点。我们不想让“恒等是等价”这件事记住绕了几圈。

## 7.2 补上相容条件：伴随等价

补上那个相容条件，就得到库里的定义。四份数据：

1. 反函数 `g`；
2. 右逆同伦：`f (g b) = b`；
3. 左逆同伦：`g (f a) = a`；
4. **伴随条件**：用右逆同伦消掉 `f (g (f x))` 里的外层，与用左逆同伦消掉内层再让 `f` 作用，这两条从 `f (g (f x))` 到 `f x` 的路径**相等**。

第四条就是范畴论里伴随的三角恒等式之一，故名**伴随等价**。加上这一条之后，“`f` 是等价”成为一个**命题**：对给定的 `f`，这件事至多有一种方式成立。于是两个等价相等当且仅当底层函数相等——这正是我们想要的“一样”。

`A <~> B` 打包了函数和“它是等价”的证据。等价可以当成函数用；反函数写成 `e^{-1}`。

好消息是你几乎永远不需要手工构造第四条。给定拟逆（两个同伦），可以**修正其中一个同伦**使伴随条件成立，这个修正是机械的。日常构造等价，只需给出反函数和两个同伦。

## 7.3 等价构成群胚——与路径平行

和路径一样，等价有单位元、复合、逆。这张对照表不是巧合：

| | 路径 | 等价 |
|---|---|---|
| 单位 | 恒等路径 | 恒等映射 |
| 复合 | `p @ q` | `g ∘ f` |
| 逆 | `p^` | `e^{-1}` |

第 11 章的泛等公理会说：**等价就是 `Type` 里的路径。** 那时这两列将真的合为一列。现在它们只是平行的两个群胚；泛等把它们粘成同一个。

## 7.4 等价保持结构

若 `f` 是等价，则它在路径上的作用 `ap f` 也是等价：它不仅把点一一对应，还把路径一一对应。这是“等价保持所有结构”的第一个例子。第 17 章会把这条性质推广成嵌入的定义——嵌入要求的正是 `ap f` 为等价，但 `f` 本身不必是等价。

等价还穿过类型构造器：乘积、Σ、和、函数类型都把等价映到等价。要证明两个复杂类型等价，把它们拆成构造器，在每个分量上给等价，再拼回去。第 14 章与第 18 章大量依赖这一点。注意函数类型是**逆变的**：定义域上的等价方向要反过来。

路径归纳说：要对所有 `y` 和 `p : a = y` 证明某事，只需在 `(a, 1)` 上证明。等价有一个类似的原则——要对所有 `b : B` 证明 `P b`，只需对所有 `a : A` 证明 `P (f a)`。直觉：`f` 是满的，沿 `f` 把 `b` 换成 `f a` 不丢失一般性。配合泛等后，它会升级成真正的“对等价做路径归纳”。

## 7.5 预告：另一种刻画

还有一种与伴随等价**逻辑等价、并且同样是命题**的刻画：

> **`f` 是等价，当且仅当它的每个同伦纤维可缩。**

“纤维可缩”是说对每个 `b`，方程 `f a = b` 的解空间不仅非空、不仅唯一，而且“唯一性的证明也唯一”……一直到所有层次。这是第 08 章的主题，也是把等价放进截断层级这把标尺的入口。

这个刻画的价值在于它不提反函数。要证明某个映射是等价，可以不去构造逆，而是直接分析它的纤维。在高阶类型里，构造逆并证明伴随条件常常非常繁琐，而纤维分析可以机械地进行。

## 小结

- “有逆函数”（拟逆）在存在性上够用，但作为数据不是命题；补上伴随条件后，“是等价”成为命题。
- 日常构造只需给左右逆，伴随条件可以机械补齐。
- 等价构成群胚，与路径的结构平行——泛等会让它们合一。
- 等价保持路径，穿过类型构造器，支持归纳。
- 等价 ⟺ 所有纤维可缩，下一章展开。

## 常见误区

1. **以为等价就是“有左右逆”。** 少了伴随条件的版本不是命题，不能作为“等价”的定义。但日常构造只需给左右逆。
2. **把等价当成“同构”的同义词。** 对类型而言等价就是正确的“一样”。范畴里对象的同构是另一个层次的事（第 20 章）。
3. **忘记函数类型上的等价是逆变的。** 定义域的方向要反过来。
4. **把反函数和逆等价当成同一个东西。** 一个是函数，一个是等价。

## 练习

1. 写出 `A + B ≃ B + A` 和 `Unit * A ≃ A` 的反函数与两个同伦。不必写伴随条件。
2. 思考：为什么拟逆不是命题？构造一个映射和它的两个“不同”的拟逆证据。提示：取圆上的恒等映射，左逆同伦可以选恒等，也可以选别的环路——第 13 章之后再回来想。
3. 若 `f` 是等价，`ap f` 为什么也该是等价？用“一样必须在所有层次对齐”解释，不必写证明。
