# 18 泛等的应用 —— 同构的东西有相同的性质

> 对照代码：[`examples/18_univalence_apps.v`](../examples/18_univalence_apps.v)

第 11 章确立了泛等：等价给出相等。这一章回答“那又怎样”。答案是数学实践里最常用却最少被形式化的原则——**同构的东西有相同的性质**——在 HoTT 里成了一行推理。不用再为每种结构、每种性质分别证明“同构保持它”。

本章全程需要泛等。

## 18.1 第一原则

任何 `S : Type -> Type` 都可以看成“类型上的一种结构或性质”：`S X` 可以是“X 是集合”“X 上的一个二元运算”“X 上的群结构”“X 可判定”。

若 `X ≃ Y`，泛等给出 `X = Y`，然后沿这条路径搬运把 `S X` 变成 `S Y`。就这么简单。这一步的代价只有一个：公理。没有泛等，`S X -> S Y` 对一般的 S 是**证不出来**的——类型论内部不知道“等价的类型表现一致”。

截断层级是一个例外：等价保持“是集合”“是命题”，这一条其实不需要泛等，因为等价已经在每一层对齐了路径。但它展示了原则的形态。对任意的、没有特殊结构的 S，就必须走泛等。

## 18.2 结构的搬运：共轭

给任意 X 和 `Bool ≃ X`，X 上自动有一个“取反”：用等价把 X 的元素送到 Bool，取反，再送回来。合取也一样。这就是**共轭**。

这些定义可以直接写出，不经过“把等价变成路径”，所以是可以计算的——它们是搬运的手工版。泛等的作用是**证明手工版就是沿路径搬运给出的那个**：沿泛等路径搬运一个函数，就是预复合逆等价。对于更复杂的 S（函数类型嵌套、Σ 类型），搬运沿泛等路径的行为由一组结构归纳的引理逐层给出。

取 X 为 Bool、等价为恒等，共轭退化回原来的运算。这是健全性检查：搬运不该凭空造出新结构。

## 18.3 结构同一性原理

上面的例子是**结构同一性原理**（SIP）的雏形。完整表述：

> 对一类“结构化类型”（群、环、偏序集……），两个结构化类型相等，当且仅当它们之间存在保结构的等价。

意义在于：数学里的“在同构意义下唯一”在 HoTT 里就是“唯一”。不需要再说“实数域在同构意义下唯一”——它就是唯一的，因为同构的实数域相等。

搬运的是数据；SIP 还要保证搬运后**定律**也成立（比如结合律）。做法是把定律本身也写成类型上的谓词，一并搬运。这些工作是机械的，泛等保证它们总能完成。

## 18.4 三类应用，同一个精神

泛等的三类应用：

1. **搬运**（本章）：性质和结构沿等价自动传递。
2. **计算路径空间**（第 13 章）：`Type` 里的路径就是等价，于是可以用自等价造覆叠。
3. **高阶结构**（第 20 章）：范畴的对象之间“同构即相等”（单叶范畴）是泛等在范畴层面的回声。

三者的共同点：泛等让 `Type` 成为一个**行为良好的宇宙**——它的路径结构有数学意义，而不是形式系统的偶然。

因为泛等是公理，由等价造出的路径不会归约。实践中的应对不变：所有关于这类路径的推理都通过行为律进行，而不靠计算。想清楚要在哪一层化开。

## 小结

- 任何结构沿等价搬运：把等价变成路径，再 transport。
- 搬运的手工版是共轭；泛等保证手工版与 transport 一致。
- 结构同一性原理：结构化类型的相等就是同构。“在同构意义下唯一”升级为“唯一”。
- 由等价造出的路径不可计算；用行为律代替。

## 常见误区

1. **以为“等价保持性质”在类型论里自动成立。** 对一般的 S 它需要泛等。
2. **期待求值穿过泛等路径。** 不会；改用行为律。
3. **以为 SIP 只是哲学。** 它是定理：对一个具体群证明的任何事，对所有同构的群自动成立，不需要重做。
4. **分不清哪些搬运需要泛等。** 关于路径结构的性质（截断层级）不需要；关于任意函数（运算、序）需要。

## 练习

1. 把“取反”沿 `Bool ≃ Unit + Unit` 搬走。手工共轭和 transport 应该给出同一个函数。
2. 可判定性沿等价搬运。这一次能不能不用泛等？提示：可判定性是 `X + (X -> Empty)`，而和、函数都对等价函子性。
3. 为什么搬运“是集合”不需要泛等，而搬运“有一个二元运算”需要？
