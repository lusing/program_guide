# 15 截断操作 —— 两种存在

> 对照代码：[`examples/15_truncations.v`](../examples/15_truncations.v)

第 09 章讲的是如何**判断**一个类型落在第几层。这一章讲一个**操作**：把任意类型强行压成 n-型。最重要的特例是压成命题——它给出 HoTT 里“存在但不告诉你是谁”的精确表达，也让“满射”“连通”这些拓扑概念有了定义。

## 15.1 为什么需要截断

第 03 章说 Σ 类型是构造性存在：依赖对的元素里真的装着见证。但数学里很多“存在”不是这样。“存在一个实数 x 使得 x² = 2”——我们不想（也不该）区分这个陈述的两个证明 √2 和 −√2。又比如“A 非空”：这应该是一个命题，不管 A 里有多少元素，“A 非空”的证据应该只有一种。

Σ 做不到：`{x : A & Unit}` 就是 A 本身，有多少元素就有多少“非空的证据”。需要一个把 A **压扁成命题**的操作，忘掉“是哪个元素”，只记得“有元素”。

## 15.2 把类型压到第 n 层

n-截断是一个 HIT：它有原来类型的所有点，并且**添加足够多的路径构造子使它成为 n-型**。对 n = -1，它添加“任意两点之间有路径”；对 n = 0，添加“任意两条平行路径相等”；等等。

它满足泛性质——从截断出发的映射，只要目标已经是 n-型，就由原类型上的映射唯一决定。这正是“截断”这个词的全部含义：信息被压到 n 层，所以只能被 n-型的目标接收。目标不是 n-型时，消去子拒绝工作。

若原类型本来就是 n-型，截断什么都没做：它等价于原类型。

## 15.3 `merely`：命题化的存在

-1 截断有专名，读作“仅仅有居民”（mere existence）。它是命题：任意两个“有居民”的证据相等。于是 HoTT 里有**两种**存在和两种析取：

| | 构造性（有信息） | 命题性（无信息） |
|---|---|---|
| 存在 | 依赖对 `{x & P x}` | `hexists P`（依赖对的 -1 截断） |
| 析取 | 和类型 `A + B` | `hor A B`（和类型的 -1 截断） |
| 非空 | `A` 本身 | `merely A` |

哪一种对应数学里通常说的“存在”？**命题性的那种。** “存在 x 使 P x”作为一个数学命题，应该是命题。Σ 类型应该叫“带见证的存在”或者干脆叫“依赖对”。HoTT 的一个贡献就是把这两个长期被混淆的概念分开。

## 15.4 存在消去：目标必须是命题

从“仅仅有居民”出发能得到什么？按泛性质，只能得到**命题**级别的结论。这正是数理逻辑里的存在消去规则：“从 ∃x.P x 推出 Q，可以假设有一个具体的 x 满足 P x，前提是 Q 不依赖 x 的选择”。在 HoTT 里“不依赖选择”被精确化为“Q 是命题”。

反过来，若目标**不是**命题——比如要**构造**一个元素——“仅仅非空”帮不上忙。“知道 A 非空”不能让你从中挑出一个元素。这就是选择公理在 HoTT 里的位置：它恰好断言某些情形下可以从截断里挑元素，而这不是定理。

## 15.5 连通性与满射

有了“仅仅”，拓扑概念可以定义了。

**满射**：每个点的纤维仅仅有居民——每个点至少有一个原像，但不说是哪个。对比第 08 章：纤维可缩是等价，纤维是命题是嵌入，纤维仅仅非空是满射。三个概念在同一把标尺上。截断管“至多”，连通管“至少”。

**连通**：一个类型是 0-连通的，如果它的 0-截断可缩——直觉上“只有一个连通分支”。圆是 0-连通的：任意两点之间仅仅有路径。它不可缩（有非平凡环路），但从“有几块”的角度看只有一块。

满射加嵌入就是等价：每个纤维既仅仅非空又是命题，于是可缩。任何映射都能分解成“满射后接嵌入”，中间是它的像。像的定义里的“仅仅”不可或缺：若写成带见证的纤维，那就是原定义域本身，不是像。

## 15.6 `merely` 不是 `Prop`

Coq 标准库用 `Prop` 宇宙和消去限制实现“无信息”。HoTT 没有 `Prop`，“仅仅”是一个普通的 HIT，“无信息”是它的定理（它是命题），而“不能从中挑元素”是消去子的类型约束。两套机制目标相同，但 HoTT 的版本是内部可证的，并且与截断层级的整条标尺无缝衔接。

## 小结

- n-截断把类型压成 n-型；引入是“还记得原来的点”，消去要求目标已经是 n-型。
- “仅仅有居民”是“A 非空”这个命题；命题性存在与析取由此而来。
- 两种存在：Σ 带见证，截断不带。数学里的“存在”通常是后者。
- 存在消去要求目标是命题；从截断里挑元素是选择公理，不是定理。
- 满射 = 纤维仅仅非空；0-连通 = 只有一块。满射 + 嵌入 = 等价。

## 常见误区

1. **用 Σ 表达“存在”然后期望它是命题。** 要命题就用命题性存在。
2. **从“仅仅非空”构造一个元素。** 这需要选择公理。只有目标是命题时才能剥掉截断。
3. **把命题性析取当成和类型。** 前者忘了是哪一边，后者记得。
4. **以为 0-连通意味着可缩。** 圆 0-连通但不可缩；连通只管“几块”，不管高阶结构。

## 练习

1. “仅仅有居民”是幂等的：截断两次等于截断一次。为什么？
2. 从 `merely (A + B)` 推不出 `merely A + merely B`。直觉理由是什么？反方向为什么成立？
3. `merely Bool` 和 `Unit` 是什么关系？`merely Empty` 呢？
