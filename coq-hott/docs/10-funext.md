# 10 函数外延 —— 逐点相等与相等之间的鸿沟

> 对照代码：[`examples/10_funext.v`](../examples/10_funext.v)

“两个函数在每个点上都相等，所以它们相等。”这句话听起来理所当然，但在 Martin-Löf 类型论里**证不出来**。本章讲三件事：为什么证不出来、把它作为公理引入意味着什么、以及它为什么和泛等一样属于“同伦”的世界观。

## 10.1 为什么证不出来

从一个方向看，完全没有问题。给定函数之间的一条路径 `p : f = g`，对每个 `x` 把“在 x 处求值”这个函数作用在 `p` 上，就得到 `f x = g x`。这是纯定义的，零公理。

反方向为什么不行？类型论的内部语言对函数的看法是**内涵的**：两个函数相等意味着它们作为“算法”相同（可以互相归约）。`fun n => n + 0` 和 `fun n => n` 在每个输入上值相同，但归约形式不同——内部没有任何规则能把它们合二为一。相等的证明都从恒等路径来，而恒等路径只能证明定义性相等的东西。

所以“逐点相等推出相等”是一条**独立于类型论的公理**。它的名字叫**函数外延**。拒绝它的模型存在（比如纯语法模型），所以它不是“显然漏写的规则”，而是一个真正的选择。

## 10.2 正确的表述：两条路径类型一样

HoTT 的表述比“逐点相等推出相等”更强、也更对：

> 对任意两个依赖函数 `f` 和 `g`，从 `f = g` 到 `f == g` 的那个映射是**等价**。

这比只要求一个反向映射强在哪？它保证路径类型 `f = g` 与同伦类型 `f == g` 作为**类型**是一样的——不仅元素对应，路径结构也对应。这正是同伦类型论要求的“对”的定义。弱版本（只要反向映射）其实能推出强版本，但强版本才是日常使用的形态。

于是有逆映射：从逐点同伦造出函数之间的路径。这就是日常说的“由逐点相等得到函数相等”。

## 10.3 公理是假设

和泛等一样，函数外延被做成一个空的类型类：本身不断言任何事。需要它的定理把它写成假设。出了假设的范围，它成为定理的一个参数。于是机器可以诚实地报告：这条定理用了函数外延。

没有实例时，从同伦造路径的那个映射用不了。这不是 bug，是设计：**公理必须被显式请求。** 写库时把公理当参数，让使用者决定；写应用时可以导入全局实例。两种方式各有用处，原则相同——不把公理藏在空气里。

## 10.4 函数外延买到了什么

**截断层级穿过 Π 类型。** 若每个 `P x` 是 n-型，则 `forall x, P x` 也是 n-型。特别地，命题的 Π 还是命题，集合的 Π 还是集合。没有函数外延这一条证不出来，因为要比较两个函数就得比较它们的路径类型。

**“是命题”本身是命题，“是等价”本身是命题。** 两者的定义里都有 Π 类型，证明它们是命题需要函数外延。这意味着“是等价”真的是一个性质而不是额外结构——第 07 章承诺的事，在这里兑现。

**同伦的行为和路径一致。** 第 08 章说基于一点的路径空间可缩。函数外延给出对应物：与一个函数同伦的所有函数构成可缩类型。函数空间里的几何，开始像底空间里的几何。

## 10.5 两条公理的关系

函数外延与泛等是 HoTT 的两条公理。它们不是独立的：**泛等蕴含函数外延。** 但库仍然把两者分开，因为很多结论只需函数外延，分开管理能让公理用量更精确。

此外，函数外延还能从一个高阶归纳类型——区间——推出来（第 12 章）。那时会看到：公理之间是可以互相兑换的。路径构造子的存在本身就是一种外延性。

## 10.6 为什么这是“同伦”的

把 `A -> B` 看成“从 A 到 B 的所有连续映射构成的空间”。两个映射之间的一条路径，在拓扑上是一个同伦：一块以 A 为底、以区间为时间的膜。而逐点相等给的是对每个 x 一条从 `f(x)` 到 `g(x)` 的路径——这正是同伦的另一种写法（固定 x，让时间变化）。两者在拓扑里显然等价。

函数外延说的就是：类型论里的函数类型应当表现得像拓扑里的映射空间。这和泛等（`Type` 应当表现得像“所有空间构成的空间”）是同一个精神。

## 小结

- 从函数相等到逐点相等永远可以；反方向是函数外延公理。
- 正确的表述：这两个类型等价，而不只是有一个反向映射。
- 函数外延是显式假设；需要它的定理必须请求它。
- 它让截断层级穿过 Π 类型，让“是命题”“是等价”成为命题。
- 泛等蕴含函数外延；区间 HIT 也能推出函数外延。

## 常见误区

1. **以为函数外延是“显然的”。** 它在类型论内部不可证；拒绝它的模型存在。
2. **只把它理解成“逐点相等推出相等”。** 正确的表述是两条路径类型等价。
3. **忘记请求它。** 从同伦造路径的映射依赖这个假设。
4. **把漂亮打印当成定义被改了。** 打印成 `idmap` 的函数仍然是你写的那个 λ 项。

## 练习

1. 若 `B` 是命题，为什么 `A -> B` 也是命题？缺了函数外延，哪一步走不下去？
2. `fun n => n + 0` 和恒等函数逐点相等。为什么在没有函数外延时，它们之间不一定有路径？
3. 为什么“基于一个函数的同伦空间可缩”需要函数外延，而“基于一点的路径空间可缩”不需要？
