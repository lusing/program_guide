# 08 同伦纤维与可缩性

> 对照代码：[`examples/08_fibers.v`](../examples/08_fibers.v)

上一章结尾留了一句话：“等价当且仅当每个纤维可缩”。这一章把这句话里的两个概念——**同伦纤维**和**可缩**——讲清楚，然后说明为什么这个刻画和伴随等价是一回事。顺带会遇到一条看似平凡却极其有用的引理：以某点为起点的所有路径构成的类型是可缩的。它其实就是路径归纳的另一种说法。

## 8.1 同伦纤维：方程的解空间

给定 `f : A -> B` 和 `b : B`，方程 `f a = b` 的解是什么？集合论里是一个子集 `f⁻¹(b)`。类型论里，解不只是一个 `a`，还要带着“它确实是解”的证据：

> 同伦纤维 `hfiber f b` 是依赖对 `{a : A & f a = b}`。

几何图像：把 `f` 想成一个把 `A` 铺在 `B` 上方的映射，纤维是 `b` 正上方的那一片。

同伦纤维衡量的是解的**结构**，不只是“有没有解”。对所有 `b`：

| 纤维是…… | `f` 是 |
|---|---|
| 可缩（恰好一个解，而且唯一性也唯一） | 等价 |
| 命题（至多一个解） | 嵌入（第 17 章） |
| 仅仅非空（至少一个解，不说是哪个） | 满射（第 15 章） |

这张表是第 17 章的全部内容，这里先种下种子。截断管“至多”，连通管“至少”，等价是两者的交。

## 8.2 可缩：收缩到一个点

一个类型**可缩**，如果有一个中心点，并且每个点都有一条路径连到中心。几何上：整个空间可以连续地收缩到一个点。

可缩比“恰好一个元素”强得多，强在**路径层面**：任意两点有路径，任意两条平行路径也相等，路径类型本身还可缩。换言之，可缩性会向上传播到所有高阶路径——从同伦的角度看，可缩类型和一个点无法区分。

`Unit` 当然可缩。可缩性沿等价保持：与可缩类型等价的类型也可缩。若 Y 是可缩类型 X 的收缩（往返于恒等），则 Y 也可缩。

## 8.3 基于某点的路径空间可缩

固定一点 `x`，考虑“所有以 `x` 为起点的路径，连同它们的终点”——类型 `{y & x = y}`。它可缩，中心是 `(x; 恒等路径)`。

为什么任何 `(y; p)` 都能连到中心？这正是路径归纳：要对所有 `(y, p)` 证明它等于中心，只需在 `(x, 恒等)` 上证明——而那是恒等。

这条引理是**路径归纳的类型化表述**。J 规则说“从 x 出发的路径可以全部收缩到恒等”，这里把它说成“基于 x 的路径空间可缩”。两者是一回事。一个直接推论：如果每个纤维都可缩，Σ 类型就等价于底空间——可缩的纤维可以忘掉。

注意对比：基于一点的路径空间**对任何类型**都可缩；而“可缩类型里的路径类型可缩”需要可缩假设。前者是 J，后者是可缩性向上传播。

## 8.4 纤维可缩 ⟺ 等价

**方向一：等价的纤维可缩。** 直觉：`f` 有逆 `g`，`b` 上方的纤维以 `(g b, 右逆同伦)` 为中心；任何其他解都能用左逆同伦和伴随条件连到它。第四条伴随条件正是在这里起作用——没有它这个证明做不下去，这也是为什么伴随等价是“对”的定义。

**方向二：纤维全可缩则是等价。** 反函数取每个纤维的中心；右逆同伦就是中心自带的证据；左逆同伦来自“`(a; 恒等)` 是纤维里的一个点，中心到它有路径，取第一分量”。三份数据全部来自可缩结构，不必事先构造逆。

这个刻画的价值在于：**它不提反函数。** 要证明某个映射是等价，可以直接分析它的纤维。在高阶类型里，这常常比构造逆并验证伴随条件更干净。

## 8.5 纤维内部的路径

纤维里两个点 `(a₁; p₁)` 和 `(a₂; p₂)` 之间的路径是什么？一条底空间路径 `q : a₁ = a₂`，加上一个相容条件：`p₁` 等于“先沿 `ap f q` 走到 `f a₂`，再沿 `p₂` 走到 `b`”。这是 Σ 类型路径结构（第 14 章）在纤维上的特例。嵌入的刻画（`ap f` 是等价）就是从这里读出来的。

## 8.6 可缩只是开始

可缩是截断层级的最底层（-2）。往上一层是命题（-1），再往上是集合（0）。两条连接它们的事实：

- 可缩的类型是任何更高层的 n-型：复杂度上限可以放宽。
- 一个命题只要有居民就可缩。这正是“命题没有信息量”的精确表述——它要么空，要么和一个点一样。

第 09 章把这条标尺完整展开。

## 小结

- 同伦纤维是方程 `f a = b` 的解空间，带证据。
- 可缩：有中心，所有点都连到中心；可缩性向上传播到所有高阶路径。
- 基于一点的路径空间可缩——这是路径归纳的另一种说法。
- 等价 ⟺ 所有纤维可缩；后一个方向只用中心与收缩路径，不需要先构造逆。
- 可缩是截断层级的起点。

## 常见误区

1. **把“可缩”等同于“恰有一个元素”。** 可缩还要求连接到中心的路径作为数据给出，并且由此所有高阶路径都平凡。
2. **忘记纤维带证据。** 它是 Σ 类型，不是子集；两个解即使第一分量相同，第二分量不同也算不同的点。
3. **以为纤维可缩必须先有反函数。** 恰恰相反，这个刻画的意义就在于绕开反函数。
4. **混淆“基于一点的路径空间可缩”与“可缩类型的路径类型可缩”。** 前者对任何类型成立，后者需要可缩假设。

## 练习

1. 从可缩推出“任意两点有路径”。再想一步：为什么任意两条平行路径也相等？
2. 基于 x 的路径空间等价于 `Unit`。怎么看出反函数？
3. 恒等映射的纤维是什么？常值映射 `Unit -> Bool` 送到 `true` 时，`false` 上方的纤维是什么？
