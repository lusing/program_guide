# 06 路径代数 —— 每个类型都是一个群胚

> 对照代码：[`examples/06_path_algebra.v`](../examples/06_path_algebra.v)

第 04 章派生了路径的逆与复合。这一章退后一步，看它们合起来构成什么结构：一个**群胚**——每个态射都可逆的范畴。然后往上走一层：路径之间的路径也有代数，而且它们满足一条出人意料的交换律。最后说明为什么这些“记号游戏”其实是几何。

## 6.1 一维：路径构成群胚

把恒等路径看成单位元、复合看成乘法、逆看成取逆，路径满足全部群公理：左单位、右单位、结合律、左右逆、反同态、对合。

和普通的群有一个关键差别：这些律**不是定义上成立的，而是路径**。`p @ (q @ r)` 和 `(p @ q) @ r` 是两个不同的项，结合律是它们之间的一条路径。这正是“群胚”而非“群”的意思——在一个类型里，每个 `x = y` 都是一个群胚的态射集，而群胚公理本身是更高一层的态射。

几何上：点是对象，路径是态射，2-路径是态射之间的相等。一直往上走，每个类型都是一个 ∞-群胚。这是 HoTT 的基本图像：**空间、∞-群胚、类型，是同一个东西的三种说法。**

## 6.2 二维：路径之间的路径

既然 `p` 和 `q` 是同一类型的两个元素，就可以问 `p = q`——这是一条 **2-路径**，几何上是两条道路之间的连续形变（同伦）。2-路径也有自己的运算。

- **横向复合**：如果 `p` 可以形变成 `p'`、`q` 可以形变成 `q'`，那么拼接 `p @ q` 可以形变成 `p' @ q'`。两条形变并排放。
- **须化**：在 2-路径的一侧补上一条不变的 1-路径。像给同伦的一边粘一条辫子。
- **纵向复合**：两条 2-路径首尾相接。这就是普通的路径复合——因为 2-路径本身就是路径类型里的路径。

这些就是 2-群胚的结构。每一层都重复同一套：单位、复合、逆，而定律活在再上一层。

## 6.3 Eckmann–Hilton：二阶环路必交换

一阶环路一般不交换：圆的基本群 ℤ 恰好是交换的，但一般空间的 π₁ 可以是任何群。然而**二阶**环路——以恒等路径为基点的环路，即 `1 = 1` 里的元素——总是交换的。

为什么？在 `1 = 1` 这个类型里有两种复合：纵向的（把两条 2-路径接起来）和横向的（把它们并排放）。两者有相同的单位元，并且满足交换律（interchange law）：先横后纵等于先纵后横。一个经典的代数论证说：**一个集合上两个有共同单位元且满足交换律的二元运算必定相同且交换。** Eckmann–Hilton 论证就是这个。

这解释了代数拓扑里一个著名事实：π₁ 可以非交换，但 π₂、π₃、…… 全是交换群。在 HoTT 里它是一条可以逐步展开的路径等式，不需要额外的拓扑输入。

注意范围：它只对**以恒等路径为基点的二阶环路**成立。圆的一阶环路 `loop` 和 `loop^` 当然也交换，但那是因为 ℤ 恰好交换，不是 Eckmann–Hilton。

## 6.4 逆的唯一性：一个完整的小证明

**命题**：若 `p @ q` 是恒等路径，则 `q` 等于 `p` 的逆。换言之，右逆是唯一的。

对 `p` 做路径归纳：现在 `p` 是恒等，目标变成 `q` 等于恒等；假设说恒等接上 `q` 等于恒等。左单位律给出恒等接上 `q` 等于 `q`，与假设拼接即得。

这个结论有一般的意义：在任何群胚里逆元唯一。但注意这里“唯一”是一条路径 `q = p^`，而不是元素层面的相等——高阶类型里，这条路径本身可能是有内容的。

证明的教训：**先把每一步的类型写出来**，比盲目尝试改写快得多。路径证明是在写一条具体的道路，不是在打勾。

## 6.5 为什么路径代数值得学

初学者容易觉得这些引理是记号游戏。它们的真实作用有三个：

1. **HIT 的消去条件**几乎总是一条“沿路径搬运后等于……”的路径等式，把它化成能证的形状全靠路径代数。
2. **编码-解码**要在路径类型上定义函数并证明互逆，每一步都是路径代数。
3. **2-路径的结构**是 HoTT 区别于集合论数学的地方。集合里 `p @ 1 = p` 无所谓；在圆或球面上，这些律之间的相容性（例如五边形恒等式）是真正的几何信息。

移项、把改写锁定在等式的一侧——这些是把上述计算写下来的手法，不是本章的要点。需要时到速查表里找对应的名字即可。

## 小结

- 路径在恒等、复合、逆下构成群胚；群胚律本身是路径，不是定义等式。
- 2-路径有横向复合、须化、纵向复合。每个类型是一个 ∞-群胚。
- Eckmann–Hilton：以恒等路径为基点的二阶环路总交换。这是 π₂ 以上都是交换群的类型论形式。
- 逆唯一；“唯一”是一条路径。
- 路径证明的第一步是把每个项的类型写清楚。

## 常见误区

1. **把结合律当成定义等式。** 两种括号之间需要一条显式的 2-路径。
2. **把 Eckmann–Hilton 用在一阶环路上。** 它只对二阶环路成立。
3. **分不清横向与纵向复合。** 横向是并排形变，纵向是首尾相接。
4. **归纳之后立刻套用一般情形的引理。** 目标形状可能已经变了；先看目标现在是什么。

## 练习

1. 结合律为什么需要对三条路径都做归纳？少做一条会卡在哪里？
2. 不用上面的证明，用“两边同时左乘 `p^`”的直觉，重新说明为什么右逆唯一。
3. 把“左侧须化”和“右侧须化”对两条 2-路径的两种组合顺序画出来。为什么它们都等于横向复合？（这就是 interchange law。）
