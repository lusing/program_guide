# 03 依赖类型 —— Π、Σ，以及“元素之间的路径是什么”

> 对照代码：[`examples/03_dependent_types.v`](../examples/03_dependent_types.v)

第 01 章给了一张“逻辑 ↔ 类型”的对照表。这一章把表里的每一行拿出来，看它的元素是什么。同时开始培养一种眼光：

> **每个类型构造器都在回答两个问题：它的元素是什么，以及它的元素之间的路径是什么。**

第二个问题到第 14 章才会系统回答，但从现在起就要带着它看。HoTT 的一个工作方式是：每引入一个类型，就搞清楚它里面的“相等”是什么——这个问题的答案往往就是关于这个类型最有用的定理。

## 3.1 恰好一个，与一个都没有

`Unit` 是“真”的类型：有一个居民 `tt`，而且只有一个。“只有一个”在类型论里要**证明**而不是宣布——任意 `u : Unit` 都等于 `tt`。证法是对 `u` 做情形分析：唯一可能的情形就是 `tt`，而 `tt = tt` 由恒等路径给出。

`Empty` 是“假”。它的消去规则说：从一个 `Empty` 的元素可以造出**任何**类型的元素。这正是逻辑里的“假命题蕴涵一切”。因为没有任何构造子，情形分析一个分支都没有。

否定就是到 `Empty` 的函数。`x <> y` 读作 `x = y -> Empty`：假设有一条从 x 到 y 的路径，推出矛盾。本教程最常用的反例是 `true <> false`。它怎么证？第 05 章会讲（造一个类型族，沿假想的路径搬运出空类型的元素）。现在先知道：两点不等，不是靠构造子名字不同自动得到的，而是一条要证明的定理。

## 3.2 两个点：`Bool` 作为判别器

`Bool` 有两个居民，`true` 和 `false`。它在这本教程里的戏份比想象中重。它是最小的“有两个不同点”的类型，所以常被用作判别器：要证明两个东西不等，就造一个把它们分别送到 `true` 和 `false` 的函数。到第 13 章，它还会充当圆上一个两叶覆叠的纤维——绕圆一圈，两叶对调。

和类型 `A + B` 是析取：元素要么是左边来的 `inl a`，要么是右边来的 `inr b`。它保存了“是哪一边”这个信息——`inl a` 和 `inr b` 永远不相等。这与第 15 章的“命题化析取”形成对比，后者只记得“至少有一边成立”，忘了是哪边。

## 3.3 Σ 类型：带见证的存在

Σ 类型 `{x : A & P x}` 的元素是一个有序对 `(a; p)`，其中 `a : A`，`p : P a`。它和乘积 `A * B` 的区别是：**第二分量的类型依赖于第一分量的值**。

逻辑读法：`{x : A & P x}` 是“存在 x 使得 P x”，而且是构造性的存在——元素里真的装着那个 x。这和经典数学里“存在但不知道是谁”不一样。后者在 HoTT 里由截断表达（第 15 章）。在那之前，请把 Σ 读成“依赖对”，而不是随口说“存在”。

两个常见特例：

- 当 `P` 是常值族 `fun _ => B` 时，Σ 就是乘积 `A * B`。
- 当 `P` 恒为 `Unit` 时，`{x : A & Unit}` 就是 `A` 本身——“非空的证据”有多少，`A` 就有多少元素。这正是后面需要截断的原因。

任何依赖对 `u` 都等于 `(u.1; u.2)`。这是 η 律：打包和拆开互为逆。

## 3.4 Π 类型：依赖函数，以及两种“函数相等”

`forall x : A, P x` 的元素是一个函数，对每个 `a : A` 返回 `P a` 的元素。返回类型随输入变化，所以叫依赖函数。逻辑读法：对所有 x，P x 成立；证明就是一个“对每个 x 生产 P x 的证明”的程序。

对两个函数 `f` 和 `g`，有两个自然的“相等”概念：

| 概念 | 含义 |
|---|---|
| 逐点相等（同伦）`f == g` | 对每个 x，`f x = g x` |
| 相等 `f = g` | 作为函数，它们之间有一条路径 |

从 `f = g` 到 `f == g` 永远可以：一条函数之间的路径，限制到每个点上，就是值之间的路径。反方向——逐点相等推出函数相等——在 Martin-Löf 类型论里**证不出来**。它就是函数外延公理，第 10 章的主题。

现在只需记住：`==` 弱、`=` 强，两者的鸿沟是一条公理。这个鸿沟不是吹毛求疵。类型论对函数的看法是内涵的：两个函数相等意味着它们作为“算法”相同。`fun n => n + 0` 和 `fun n => n` 在每个输入上值相同，但归约形式不同——内部没有任何规则能把它们合二为一。

## 3.5 回头看那张表

现在可以把第 01 章的对照表再读一遍，带上“元素是什么”和“路径将是什么”两列：

| 类型 | 元素 | 元素之间的路径（第 14 章） |
|---|---|---|
| `Unit` | 只有 `tt` | 只有恒等路径 |
| `Empty` | 没有 | — |
| `A * B` | `(a, b)` | 一对路径 |
| `A + B` | `inl a` 或 `inr b` | 同侧的一条路径；跨侧没有 |
| `{x : A & P x}` | `(a; p)` | 底空间一条路径 + 纤维里一条依赖路径 |
| `forall x, P x` | 函数 | 逐点路径（需要函数外延） |
| `x = y` | 路径 | 2-路径 |

第三列现在只是预告。但它已经提示了后文的节奏：要比较两个有序对，拆成两个分量的路径；要比较两个依赖对，还得先把第二分量搬到同一根纤维里。路径类型自己的“相等”就是 2-路径——同伦。

## 小结

- `Unit`、`Empty`、`Bool`、和、乘积是基本类型构造器；它们的消去就是情形分析。
- Σ 类型是构造性存在：元素里装着见证。数学里无信息的“存在”是另一回事。
- Π 类型是全称量词：元素是依赖函数。
- 函数之间有逐点相等和相等两个概念，前者弱、后者强，鸿沟是函数外延。

## 常见误区

1. **`(a; b)` 和 `(a, b)` 不同。** 分号是 Σ，逗号是乘积。
2. **把 Σ 随口叫“存在”，然后期望它是命题。** 它一般不是命题；它有多少元素，就有多少种见证。
3. **`negb` 不是逻辑否定。** 前者翻转布尔值，后者是到空类型的函数。
4. **以为逐点相等的函数“当然”相等。** 在内涵类型论里这不是定理。

## 练习

1. 写出 `A * B -> B * A` 与 `A + B -> B + A`。它们是不是“一样”（第 07 章的等价）？先凭直觉。
2. 定义“n 是偶数”作为一个 `nat -> Type` 的谓词，并给出一个带见证的偶数。
3. 写出 `(forall x, P x * Q x) -> (forall x, P x) * (forall x, Q x)`。反方向成立吗？缺什么？
