# 24 综合实战 —— 圆上的螺旋覆叠

> 对照代码：[`examples/24_capstone.v`](../examples/24_capstone.v)

最后一章不引入新概念，而是把前面的东西拧成一股绳：**自己实现一个覆叠空间，算出它的单值变换，再用它证明圆的环路非平凡。** 第 13 章用两叶做过一个最小版本；这里把它推广成一个对任意类型和任意自等价都适用的构造，并且走完“绕 n 圈”的归纳。

需要的公理只有泛等。涉及的概念都有出处：路径与搬运（04、05），等价（07），泛等（11），圆（13），迭代（22）。

## 24.1 问题

拓扑学里，螺旋线 ℝ → S¹ 是圆的万有覆叠：每个整数对应螺旋的一层，绕底部的圆一圈就上升一层。这个几何对象证明了 π₁(S¹) = ℤ。

类型论的版本更一般。给任意类型 X 和它的任意自等价 f，在圆上造一个类型族，使得：

- 基点上方的纤维是 X；
- 绕一圈正好执行 f；
- 绕 n 圈的效果是 f 迭代 n 次；
- 若 f 对某个点不是恒等，则环路不是恒等路径。

取 X 为整数、f 为后继，就是经典螺旋；取 X 为 `Bool`、f 为取反，就是第 13 章的两叶覆叠。同一个构造，两种几何。

## 24.2 构造：泛等在这里进入

用圆的非依赖消去造类型族：目标是 `Type`，基点处的值是 X，环路处的自环是“由 f 造出的类型路径”。**泛等在这里进入构造**：它把自等价变成了字面意义上的类型相等，于是“绕一圈”就是“沿这条类型路径搬运”。

没有泛等，自等价变不成可以沿着走的路径，覆叠就没有非平凡的单值变换。

## 24.3 绕一圈：单值变换

第一个定理：沿环路搬运纤维里的点，就是作用 f。三步，三条已知规则：

1. 沿复合族搬运，等于沿 `Type` 搬运“族在环路上的作用”（第 05 章）。
2. 族在环路上的作用，按 HIT 计算规则，就是由 f 造出的那条类型路径（第 13 章）。
3. 沿由等价造出的路径搬运，就是作用这个等价（第 11 章）。

反方向绕一圈是 f 的逆，多两步：函数作用保逆，泛等把逆等价变成逆路径。方向性成对出现是路径代数的常态。

## 24.4 绕 n 圈：单值变换是群同态

路径的 n 次幂：零次是恒等，后继是再接一次。函数的 n 次迭代同理。然后对 n 归纳：**绕 n 圈 = 迭代 f 共 n 次。**

零圈：沿恒等路径搬运是恒等，定义性成立。归纳步：沿拼接搬运等于先走前 n 圈再走一圈——前 n 圈用归纳假设，最后一圈用 24.3。这正是覆叠空间理论里“单值变换是群同态”的类型论形式。

（库里有整数次幂，覆盖负圈；自然数版本已经把机制讲清楚。负圈用 24.3 的反向定理即可。）

## 24.5 环路非平凡

若 f 真的动了某个点——`f x ≠ x`——那环路不可能是恒等路径。反设它是，则绕一圈和不绕效果相同；但绕一圈是作用 f，不绕是原地不动，于是 `f x = x`，矛盾。

推理链：

1. 绕一圈把 x 变成 f(x)；
2. 若环路等于恒等，绕一圈就把 x 变成 x（沿恒等搬运是定义性的恒等）；
3. 于是 f(x) = x。

这个证明没有任何巧妙之处——它就是几何事实的直译。所有的实质内容都在 24.3 里：泛等把 f 变成了可以沿着走的路径。

取 X 为 `Bool`、f 为取反、被移动的点为 `false`，就得到 `loop ≠ 1`。公理清单里赫然写着泛等。这不是巧合：一个看似纯拓扑的事实——“圆的环路不能收缩”——之所以能证，是因为宇宙的路径结构就是等价结构。没有泛等，HoTT 与“所有类型都是集合”相容，圆当然也就可能是可缩的。

清单里的 HIT 规则是圆的构造性归纳规则，不是逻辑公理（第 23 章）。

## 24.6 与完整结果的距离

库把 X 为整数、f 为后继的情形做成了编码，并算出完整的等价：环路空间 ≃ ℤ。我们的“绕 n 圈 = 迭代 n 次”是这个定理的自然数版本。从这里到完整结果，只差把自然数次幂换成整数次幂，并证明编码与解码互逆——那一步需要对圆做依赖归纳，相容条件是一通路径代数。第 13 章讲了它的结构。

## 24.7 回顾全书

走到这里，用到的每一样东西都有出处：

| 工具 | 章 | 在本章的角色 |
|---|---|---|
| 路径、路径归纳 | 01、04 | 沿恒等搬运是定义性的恒等 |
| 搬运、沿复合族、沿拼接 | 05 | 单值变换的拆分 |
| 函数作用 | 04 | 把“环路等于恒等”变成“搬运结果相等” |
| 等价、逆 | 07 | 覆叠的数据是一个自等价 |
| 泛等、沿泛等路径搬运 | 11 | 自等价变成可以沿着走的路径 |
| 圆的消去与计算规则 | 12、13 | 造覆叠 |
| `true ≠ false` | 03、05 | 判别：取反真的动了点 |
| 公理清单 | 23 | 确认只用了泛等 |

从“相等是路径”到“自等价驱动的覆叠证明环路非平凡”，每一步都是把一条已知规则用一次。HoTT 的力量不在于某个高深的定理，而在于**类型、路径、等价、搬运这几个概念之间的接口足够干净**，以至于拓扑直觉可以逐字翻译成证明。

## 小结

- 覆叠 = 圆上的类型族，纤维为 X，绕一圈作用自等价 f。泛等让 f 成为类型路径。
- 单值变换三步：拆开复合族 → HIT 计算规则 → 泛等的搬运律。
- 绕 n 圈 = 迭代 n 次；归纳步是“沿拼接 = 先后两段”。
- `f x ≠ x` 推出环路非平凡；证明是直译。
- 公理只有泛等（外加 HIT 规则）。

## 常见误区

1. **以为环路非平凡可以不用泛等。** 不行；没有泛等，自等价变不成类型路径。
2. **期待化简完成单值变换的任何一步。** 三步都是命题性规则。
3. **取错判别点。** 需要一个被 f 真正移动的点。
4. **把这个构造当成只对整数或只对布尔有意义。** 它对任意自等价成立；那两个只是实例。

## 练习

1. 负一圈的单值变换是 f 的逆。把它和“绕 n 圈再绕回去”拼起来，应该得到什么？
2. 取三元集合上的轮换，证明绕两圈仍不是恒等。两叶覆叠为什么做不到这件事？
3. 如果把圆换成区间，用同样方法造族，`seg` 会是非平凡的吗？提示：区间可缩。
