# 09 截断层级 —— 可缩、命题、集合，以及更高

> 对照代码：[`examples/09_truncation.v`](../examples/09_truncation.v)

HoTT 的一个核心洞察：**类型可以按“路径结构有多复杂”分级。** 有些类型里任意两点之间至多一条路径（集合），有些类型里任意两点之间都有路径而且只有一条（命题），有些类型干脆只有一个点（可缩）。而圆这样的类型，两点之间有可数无穷条互不相等的路径。这条标尺叫**截断层级**，它把“集合”“命题”“可缩”这些日常概念统一到一个归纳定义里。

## 9.1 路径降一层

定义是归纳的：

- **-2 层**：可缩（第 08 章）。
- **n+1 层**：任意两点之间的路径类型是 n 层。

于是“路径类型比原类型低一层”是定义自带的，不需要证明。层级从 -2 开始数，是为了让一个习惯成立：**集合是 0 层**。集合的路径类型（命题）低一层是 -1，命题的路径类型（可缩）再低一层是 -2。数字是倒推出来的。

三个最常用的层级有专名：

| 层级 | 名字 | 含义 |
|---|---|---|
| -2 | 可缩 | 有中心，所有点连到中心 |
| -1 | 命题 | 任意两点之间有路径（因此路径类型可缩） |
| 0 | 集合 | 任意两条平行路径相等（因此路径类型是命题） |
| 1 | 1-型 | 路径类型是集合（圆就是这样） |

读法：说一个类型是 n-型，意思是它的高阶路径在 n 层以上全部平凡。层级是**复杂度上限**，不是精确刻度——集合当然也是 1-型。

## 9.2 命题：有则唯一

一个类型是命题，当且仅当任意两点都有路径相连。直觉：命题是“没有信息量”的类型。它要么空，要么它的所有元素都互相等同——知道它有居民就知道了一切。这是 HoTT 对“命题”这个词的精确定义，取代了 Coq 标准库里那个 impredicative 的 `Prop` 宇宙。

两个直接后果：

- 命题之间，逻辑等价就是等价。普通类型之间当然不成立（`Bool` 和 `Unit` 互相有函数，但不等价），但对命题成立，因为没有内部结构可以被破坏。
- 一个命题只要有居民就可缩。空，或者和一个点一样——没有第三种可能。

`Empty` 是命题：从空类型的元素可以推出任何事，包括两点相等。`Unit` 是命题，而且可缩。

## 9.3 集合：路径是命题

一个类型是集合，当且仅当任意两条平行路径都相等——这正是 UIP / 公理 K。标准 Coq 里 UIP 对所有类型成立；HoTT 里它是**集合的定义**。

常见的数据类型都是集合：`Bool`、`nat`、整数。有了“是集合”这个性质，证明两条路径相等只需一步：它们平行，所以相等。第 16 章和第 22 章会看到：在集合里做数学，HoTT 和普通数学毫无区别。所有“高阶”的复杂性都是为非集合的类型准备的。

## 9.4 层级怎么推理

**往上抬**：低层蕴含高层。可缩的类型是命题，命题是集合，集合是 1-型。上限可以放宽。

**沿等价保持**：等价保持全部路径结构，自然保持路径结构的复杂度。有趣的是，这一条不需要泛等——等价已经在每一层都对齐了。

常常需要谈论“所有 n-型构成的类型”，比如“所有命题”或“所有集合”。把类型和它的层级证据打包，就得到这样的宇宙。一个有意思的事实：当两个命题逻辑等价时，它们作为“命题”这个宇宙里的元素相等——但这需要泛等（第 11 章）。这是“命题外延性”，在 HoTT 里是泛等的推论而不是独立公理。

## 9.5 把前几章放到这把尺子上

- 第 08 章：可缩是 -2 层；基于一点的路径空间是 -2 层。
- 第 07 章：“是等价”是 -1 层（命题）——这是伴随等价比拟逆好的精确意义。兑现“是命题”需要函数外延（第 10 章），因为定义里有 Π。
- 第 11 章：`Type` **不是** 0 层——它至少是 1-型，因为 `Bool = Bool` 有两条不同的路径。
- 第 13 章：圆是 1 层，不是 0 层：`base = base` 是集合 ℤ，但不是命题。
- 第 15 章：截断操作把任意类型强行压成 n-型。
- 第 17 章：把层级从类型搬到映射上：映射是 n-截断的，当且仅当所有纤维是 n-型。

## 小结

- n+1 型意味着所有路径类型是 n 型；-2 可缩、-1 命题、0 集合、1 一型。
- 命题：任意两点相连；有居民则可缩；逻辑等价即等价。
- 集合：平行路径相等（UIP），这是集合的定义而非公理。
- 层级可以往上抬，沿等价保持。层级是复杂度上限。

## 常见误区

1. **把“是命题”当成 Coq 的 `Prop`。** HoTT 里没有 `Prop` 宇宙；“是命题”是对任意类型的一个性质。
2. **以为所有类型都是集合。** 这是标准 Coq（有 UIP）的世界观；在 HoTT 里 `Type`、圆、甚至“所有集合构成的类型”都不是集合。
3. **把“逻辑等价即等价”推广到任意类型。** 它只对命题成立。
4. **认为层级越高越“好”。** 说 `A` 是 1-型只是说它不比圆更复杂；集合当然也是 1-型。

2. “是命题”本身是不是命题？“可缩”呢？两者都是，但证明前者需要函数外延。为什么？
3. 凭直觉把这些类型放到尺子上：`Empty`、`Unit`、`Bool`、`nat`、圆、`Type`。读到第 13 章后再核对。
