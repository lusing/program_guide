# 17 截断映射与嵌入 —— 一条标尺上的三个刻度

> 对照代码：[`examples/17_trunc_maps.v`](../examples/17_trunc_maps.v)

第 09 章把截断层级用在**类型**上。这一章把它搬到**映射**上：一个映射是 n-截断的，当且仅当它的每个同伦纤维是 n-型。这个简单的定义把“等价”“嵌入”“满射”三个看似不同的概念排在同一把尺子上，并且揭示了一个在集合论里看不见的区别：**嵌入不等于单射**。

## 17.1 纤维的层级就是映射的层级

“每个纤维是 n-型”。沿着第 08 章的表往下走：

| 纤维是 | 映射是 | 直觉 |
|---|---|---|
| 可缩（-2） | 等价 | 每个点恰有一个原像，唯一性也唯一 |
| 命题（-1） | 嵌入 | 每个点至多一个原像 |
| 集合（0） | 0-截断映射 | 原像构成集合 |

而“至少一个原像”不在这把尺子上——它是**连通性**（第 15 章的满射），纤维仅仅非空。截断管“至多”，连通管“至少”。

## 17.2 嵌入：路径上的等价

嵌入有一个更常用的刻画：

> `f` 是嵌入，当且仅当对所有 x、y，`ap f : (x = y) -> (f x = f y)` 是等价。

为什么等价？纤维是命题，意味着纤维里任意两点相等；把这种相等翻译成底空间的语言，正好是“`ap f` 满”；结合纤维是命题，`ap f` 还是单，于是是等价。等价当然是嵌入，所以等价的 `ap` 也是等价——这就是第 07 章已经见过的事实。

几何上：嵌入是“子空间”。它不仅把点一对一地放进去，还把路径结构原样保留——子空间里从 x 到 y 有多少条路，大空间里从 f(x) 到 f(y) 就有多少条，不多不少。

## 17.3 嵌入 ≠ 单射

**单射**是集合论的概念：`f x = f y` 推出 `x = y`。**嵌入**要求更多：不仅能得到 `x = y`，而且这个“得到”是等价——`f x = f y` 里的每条路径恰好来自 `x = y` 里的一条。嵌入蕴含单射；反方向不成立。

反例：把一个点塞进圆。它当然单射（定义域只有一个元素）。但 `ap f` 把“点上的路径”（只有恒等）映到“圆上的环路”（ℤ），不可能是等价。几何上：圆的环路在“点”里没有对应物，所以这不是子空间。

在集合之间，两者一致：`f x = f y` 和 `x = y` 都是命题，有来回函数就是等价。所以集合论里从没需要区分它们。HoTT 的高阶结构让这个区分浮现出来，而正确的“子类型”概念是嵌入。

子类型的标准形式：`{x : A & P x}` 嵌入 A，其中 P 逐点是命题。投影记住底元素，忘掉作为命题的证据。P 的纤维有多个元素时，投影的纤维就不是命题，投影也就不是嵌入。

## 17.4 满射 + 嵌入 = 等价

每个纤维既仅仅非空又是命题。命题一旦有居民就可缩，而“仅仅”可以剥掉——因为“可缩”是命题目标。于是每个纤维可缩，映射是等价。

这是像分解的关键：任何映射分解为先满射后嵌入，中间是像。一般的 n-像分解把映射拆成“n-连通后接 n-截断”，这是同伦论里 Postnikov 分解在 HoTT 里的形态。

从集合论来的读者要调整的直觉只有一处：**“单射”要换成“嵌入”**。其他一切——满射、双射、像——与熟悉的版本一致，只是“至少一个原像”现在被精确地写成“仅仅”。

## 小结

- 映射是 n-截断的：每个纤维是 n-型。-2 等价、-1 嵌入。
- 嵌入 ⟺ `ap f` 是等价。嵌入强于单射；对集合两者一致。
- 把一个点塞进圆：单射但不是嵌入。
- 子类型的正确形式是“性质为命题的 Σ 再投影”。
- 满射 + 嵌入 = 等价；任何映射分解为满射后接嵌入。

## 常见误区

1. **把嵌入理解为单射。** 嵌入要求路径层面也是等价。
2. **以为满射在截断标尺上。** 满射是连通性（“至少”），不是截断（“至多”）。
3. **期待任意 Σ 的投影都是嵌入。** 只有纤维是命题时才是。
4. **以为集合论里的单射、满射、双射在 HoTT 里原样可用。** 单射要升级为嵌入；其余的加上“仅仅”即可。
