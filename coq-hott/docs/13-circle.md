# 13 圆与编码-解码

> 对照代码：[`examples/13_circle.v`](../examples/13_circle.v)

圆是第一个**真正有非平凡环路**的类型。有了它，“相等的证明可以不止一个”不再是抽象的可能性，而是一个具体的对象：从基点出发又回到基点的那条生成元 `loop`，并且 `loop ≠ 1`。这一章做两件事：用圆讲 HIT 的泛性质，以及介绍 HoTT 里计算路径空间的标准方法——**编码-解码**——并看清为什么 `loop ≠ 1` 必须依赖泛等。到最后，圆的环路空间将被算出来是整数 ℤ。

## 13.1 一个点，一条自环

拓扑里的圆：一个点，加一条从这个点出发又回到它的路。作为 HIT：一个点构造子 `base`，一条自环路径构造子 `loop : base = base`。

套第 12 章的模板。依赖消去：在基点给一个值 `b`，并要求沿 `loop` 把 `b` 搬一圈回到 `b`。非依赖消去：给一个点 `b` 和一条自环 `l : b = b`，就有从圆到目标的映射，并且映射在 `loop` 上的作用就是 `l`。

这立刻给出一个观察：**映到集合的圆是无趣的。** 若目标是集合，自环只有恒等路径，所以从圆出发的映射等价于目标里的一个点——圆在集合眼里和一个点没区别。反过来，若目标本身有非平凡自环，映射才有内容。最有趣的目标是 `Type`：它的自环是类型的自等价（泛等），这正是下面要用的。

泛性质把这件事说精确：从圆到 `P` 的映射，不多不少就是 `P` 里的一个点加一条自环。这和拓扑里“从 S¹ 出发的映射对应于环路”完全一致。

## 13.2 问题：`base = base` 是什么？

直觉上，基点到自身的路径是绕圆走若干圈：零圈、一圈、两圈、反向一圈……猜想：这个路径空间等价于整数 ℤ。

**困难在于**：路径归纳对环路无能为力——J 要求终点自由，而环路的两端固定。不能通过对 `p : base = base` 做归纳来证明任何事。需要别的工具。

## 13.3 编码-解码法

这是 HoTT 里计算路径类型的标准方法。精髓只有一句话：

> **把“固定两端的环路”问题，转化成“一端自由的路径”问题加上一个覆叠。**

路径归纳在后者上能用；覆叠的搬运行为把拓扑信息（绕几圈）编码成代数信息（整数）。

**第一步：造一个覆叠。** 在圆上定义一个类型族，用圆的非依赖消去：基点上方挂 ℤ，绕一圈执行“加一”这个自等价——通过泛等变成 `ℤ = ℤ` 的路径。几何上这就是螺旋：每个整数是螺旋上的一层，绕底部的圆一圈就上升一层。

**第二步：编码。** 把路径变成码：把纤维里的零沿路径搬运。注意这里用了终点自由的形式 `base = x`，所以可以用路径归纳定义它。

**第三步：解码。** 把码变回路径。在基点上，整数 n 对应 `loop` 的 n 次幂。对终点做圆归纳，环路情形需要证明“n 次幂”与“加一”相容——这是一通路径代数。

**第四步：互逆。** 编码再解码，对整数归纳；解码再编码，对自由终点的路径做归纳，化到“零解码成恒等路径”。

于是 `(base = base) ≃ ℤ`。

## 13.4 最小的覆叠：用两叶证明 `loop ≠ 1`

不必动用整数。一个两叶覆叠就够：基点上方挂 `Bool`，绕一圈执行取反。如果 `loop` 是恒等路径，绕一圈和不绕效果应该相同——但取反改变了 `true`。

证明的骨架只有三步，每一步都是一条已知规则：

1. 沿复合族搬运，等于沿 `Type` 搬运“族在环路上的作用”（第 05 章）。
2. 族在环路上的作用，按 HIT 计算规则，就是由取反造出的那条类型路径（本章）。
3. 沿由等价造出的路径搬运，就是作用这个等价（第 11 章，泛等的计算律）。

于是绕一圈把 `true` 变成 `false`。若 `loop` 等于恒等路径，绕一圈就不该改变任何东西，矛盾。

这个证明没有任何巧妙之处——它就是“如果绕一圈和不绕效果相同，那取反就没动任何东西”的直译。所有的实质内容都在泛等里：要让自等价成为“可以沿着走的路径”，这一步只有泛等能做。

## 13.5 为什么必须有泛等

没有泛等，HoTT 与“所有类型都是集合”相容，圆当然也就可能是可缩的。`loop ≠ 1` 和 `(base = base) ≃ ℤ` 都不是圆的定义的一部分，它们是定理，而且依赖泛等。

审计这个证明的公理清单时，还会看到 HIT 的路径构造子。它们在数学上是构造性的归纳规则，不是逻辑公理；但 Coq 没有原生 HIT，库用公理模拟它们，机器分不出来。判断方法：名字里带 glue、beta、ind 的通常是 HIT 规则。第 23 章会把这件事讲清楚。

## 13.6 圆落在尺子的哪一层

圆是 **1-型**：不是集合（有非平凡自环），但它的路径类型 `base = base ≃ ℤ` 是集合。圆是 **0-连通**的：任意两点之间“仅仅”有路径（第 15 章解释这个“仅仅”）。两者合起来就是拓扑里的“S¹ 是 K(ℤ, 1)”。

一般化：圆上任意覆叠绕 n 圈的效果是那个自等价迭代 n 次。第 24 章会从零实现这个定理的自然数版本，把本章的三步套路走成一条完整的归纳。

## 小结

- 圆：一个点，一条自环。消去子要求沿环路搬运一圈回到原值。
- 泛性质：从圆出发的映射 ≃ 目标里的一个点加一条自环。映到集合的圆是常值的。
- 路径归纳对环路无效；计算环路空间要用编码-解码：造覆叠 → 编码 → 解码 → 互逆。
- 覆叠类证明三步：拆开复合族 → HIT 计算规则 → 泛等的搬运律。
- `loop ≠ 1` 和 π₁(S¹) = ℤ 都依赖泛等。
- 圆是 1-型、0-连通。

## 常见误区

1. **试图对两端固定的路径做路径归纳。** 这正是需要编码-解码的原因。
2. **以为 `loop ≠ 1` 是圆定义的一部分。** 它是定理，而且需要泛等。没有泛等的 HoTT 与“圆可缩”相容。
3. **把公理清单里的 HIT 规则当成又一条逻辑公理。** 它们是构造性规则。
4. **期待化简算出覆叠在环路上的作用。** 那是命题性计算规则，必须显式使用。

## 练习

1. 用两叶覆叠证明 `loop @ loop ≠ loop`。绕两圈和绕一圈，纤维里的值差在哪？
2. 两叶覆叠能不能证明 `loop @ loop ≠ 1`？为什么不能？换成三叶覆叠（三元集合上的轮换）呢？
3. 从圆到圆有多少“本质不同”的映射？提示：泛性质，然后环路空间 ≃ ℤ。
