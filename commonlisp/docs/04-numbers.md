# 04 · 数字：数值塔与两套实现的脾气

> 配套示例：[`examples/04_numbers/`](../examples/04_numbers/main.lisp)（channel: both）

Common Lisp 把数字分成**整数、有理数、浮点、复数**四类，它们之间自动转换，
规则是「精度只升不降」。理解这一章能避免大量「为什么结果不是我算的那个」。
本章还集中了一批 **SBCL vs CLISP 的数值差异**——它们是 22 章可移植性军规的弹药库。

## 4.1 整数：不会溢出，只会变慢

多数语言的整数会静默回绕（`int` 溢出成负数）。CL 的实现**必须**保证正确性——
超出机器字长时自动切换成大整数（bignum）：

```lisp
(expt 2 100)                    ; => 1267650600228229401496703205376
(* 99999999999 99999999999)     ; => 9999999999800000000001
(integer-length (expt 2 1000))  ; => 1001
```

「小整数」叫 `fixnum`，是立即数（不分配内存、最快）。但它的**位宽是实现自由**：

```lisp
most-positive-fixnum
;; SBCL 2.6.8（x86-64） => 4611686018427387903   （62 位）
;; CLISP 2.49.95（同机） => 281474976710655      （48 位）
(type-of (1+ most-positive-fixnum))   ; SBCL => (INTEGER 4611686018427387904)
```

注意 `type-of` 返回的不是 `INTEGER` 而是**精确区间**——SBCL 编译器靠它优化，
也意味着：**别拿 `type-of` 做类型判断**，要判断用 `integerp` / `typep`（13 章）。

固定范围的整数类型（性能敏感代码用）：

| 类型 | 含义 |
|---|---|
| `fixnum` | 不分配内存的小整数（位宽随实现） |
| `bignum` | 超出 fixnum 的整数 |
| `(integer 0 255)` | 0 到 255 的整数（区间类型） |
| `(unsigned-byte 8)` | 0..255 |
| `(signed-byte 32)` | -2³¹ .. 2³¹-1 |

## 4.2 有理数：算得准

两个整数相除，如果除不尽，得到的是**精确有理数**而不是浮点近似：

```lisp
(/ 10 4)              ; => 5/2        （不是 2.5）
(+ 1/3 1/6)           ; => 1/2
(+ 1/3 1/3 1/3)       ; => 1          （完全等于 1，无误差）
(* 1/3 3)             ; => 1
(expt 2 -1)           ; => 1/2
```

有理数字面量直接写 `分子/分母`；自动约分；取分子分母：

```lisp
(numerator 3/4)       ; => 3
(denominator 3/4)     ; => 4
```

浮点也可以转成它**精确**代表的那个有理数——结果可能让你惊讶：

```lisp
(rational 0.5)        ; => 1/2
(rational 0.1)        ; => 13421773/134217728
```

`0.1` 转出来不是 `1/10`：因为字面量 `0.1` 默认是单精度浮点（下一节），存的是近似值，
`rational` 忠实告诉你那个近似值是多少。**想要 1/10 就写 `1/10`，不要写 `0.1`。**

## 4.3 浮点：默认是单精度，这是个陷阱

**这一节是本章最值得先记住的。**

```lisp
*read-default-float-format*    ; => SINGLE-FLOAT
(type-of 1.5)                  ; => SINGLE-FLOAT
(type-of 1.5f0)                ; => SINGLE-FLOAT     （f = single）
(type-of 1.5d0)                ; => DOUBLE-FLOAT     （d = double）
```

按 ANSI，**没加后缀的浮点字面量是单精度**（约 7 位十进制有效数字）；
双精度必须显式写 `d0`。后果：

```lisp
(+ 0.1 0.2)                    ; => 0.3        ← 单精度下「看不出来」有问题
(+ 0.1d0 0.2d0)                ; => 0.30000000000000004d0
(= (+ 0.1d0 0.2d0) 0.3d0)      ; => NIL        ← 经典浮点误差
```

单精度把误差藏起来了（打印精度不够），双精度把它暴露出来。所以：

- **要浮点精度就写 `1.5d0`**，别写 `1.5`；
- **不要用 `=` 比较浮点**，用 `(<= (abs (- a b)) 容差)`；
- 能不用浮点就不用——金融计算用整数（以「分」为单位）或有理数。

其它实测：

```lisp
(* 1.0 1/3)            ; => 0.33333334
(float 1/3 1.0d0)      ; => 0.3333333333333333d0
pi                     ; => 3.141592653589793d0   （SBCL：双精度）
(sqrt 2)               ; => 1.4142135
(sqrt 2d0)             ; => 1.4142135623730951d0
```

**⚠️ CLISP 差异（实测）**：CLISP 的默认浮点是**长浮点**（long-float，任意精度十进制），
`pi` 在 CLISP 里打印 `3.1415926535897932385L0`；SBCL 是 `3.141592653589793d0`。
想要两实现一致，用 `(float pi 1.0d0)` 归一——这是双通道示例的标准动作。

## 4.4 类型提升金字塔（与 CLISP 的传染坑）

ANSI 规定混合运算取「更宽」的类型，方向是
**整数 → 有理数 → 单精度 → 双精度 → 复数**（SBCL 逐条实测）：

```lisp
(+ 1 1/2)         ; => 3/2            （整数 + 有理数 → 有理数）
(+ 1/2 0.5)       ; => 1.0            （有理数 + 单精度 → 单精度）
(+ 1/2 0.5d0)     ; => 1.0d0          （有理数 + 双精度 → 双精度）
(+ 1 2.0)         ; => 3.0
(+ 1 2)           ; => 3
```

**关键点：一旦沾上浮点，精确性就永久丢了。** `(+ 1/2 0.5)` 得浮点 `1.0`，
而 `(+ 1/2 1/2)` 得精确的 `1`。把浮点混进金融计算是经典事故。

**⚠️ CLISP 差异（实测）**：CLISP 默认的浮点传染规则是**非 ANSI** 的——

```lisp
(+ 1.5f0 2.25d0)
;; SBCL  => 3.75d0    （按 ANSI 取更高的 double）
;; CLISP => 3.75      （type-of 是 SINGLE-FLOAT！）
```

CLISP 提供开关 `ext:*floating-point-contagion-ansi*` 置 `t` 后遵循 ANSI；
跨实现代码的正确姿势是**显式归一**：`(float (+ 1.5f0 2.25d0) 1.0d0)`。

## 4.5 除法与取余：四个函数，两种语义

`/` 给有理数，但很多场合要的是「商和余数」。CL 有四个函数，区别在**取整方向**：

| 函数 | 取整方向 | 余数符号 |
|---|---|---|
| `floor` | 向下（向 −∞） | 与除数同号 |
| `ceiling` | 向上（向 +∞） | 与除数反号 |
| `truncate` | 向零 | 与被除数同号（C 的行为） |
| `round` | 就近（平局取偶） | — |

它们都返回**两个值**（商和余数）：

```lisp
(multiple-value-list (floor 7 2))      ; => (3 1)
(multiple-value-list (floor -7 2))     ; => (-4 1)     ← 向下取整！
(multiple-value-list (truncate -7 2))  ; => (-3 -1)    ← 向零截断
(multiple-value-list (ceiling 7 2))    ; => (4 -1)
(multiple-value-list (round 7 2))      ; => (4 -1)
```

从 C / Python 来的人最容易栽在这里：**`floor` 不是截断**。`-7/2` 在 C 里是 `-3`，
在 CL 的 `floor` 下是 `-4`。

`mod` 和 `rem` 是「只要余数」的版本：

```lisp
(mod -7 2)     ; => 1      （符号跟除数）
(rem -7 2)     ; => -1     （符号跟被除数）
(mod 7 -2)     ; => -1
(rem 7 -2)     ; => 1
```

**记住：`mod` 跟除数，`rem` 跟被除数。** 判断奇偶用 `evenp`/`oddp`，
别自己写 `(zerop (rem x 2))`——对负数会翻车。

## 4.6 舍入是「四舍六入五成双」

`round` 遇到正好一半时取**最近的偶数**（银行家舍入）：

```lisp
(round 2.5)    ; => 2
(round 3.5)    ; => 4
(round 0.5)    ; => 0
(round 5/2)    ; => 2       有理数也一样
(round 7/2)    ; => 4
(fround 2.5)   ; => 2.0     返回浮点
```

这条在**统计和财务**里真会算错。要传统四舍五入通常写 `(floor (+ x 1/2))`。

## 4.7 开方、对数、复数（CLISP 的「精确洁癖」）

```lisp
(sqrt 4)         ; => 2.0        ← 返回浮点，不是整数 2！
(sqrt 4.0)       ; => 2.0
(isqrt 17)       ; => 4          ← 整数开方（向下）
(sqrt -4)        ; => #C(0.0 2.0) ← SBCL：负数开方给浮点复数，不报错
(log 100 10)     ; => 2.0
(expt 8 1/3)     ; => 2.0
(expt 2 10)      ; => 1024       ← 整数指数给整数
```

`(sqrt 4)` 给 `2.0` 而不是 `2`，是新手最常见的「类型意外」。要整数用 `isqrt`。

**⚠️ CLISP 差异（实测）**：CLISP 的数学函数能精确就精确——

```lisp
(sqrt -4)    ;; SBCL => #C(0.0 2.0)   CLISP => #C(0 2)   （精确复数！）
(log 8 2)    ;; SBCL => 3.0           CLISP => 3         （精确整数）
(exp 0)      ;; SBCL => 1.0           CLISP => 1
```

跨实现一致的老办法：**给浮点输入**（`(sqrt -4.0)`、`(log 8.0 2.0)`）或**输出归一**
（`(float (log 8 2) 1.0d0)`）。

复数是内建类型：字面量 `#C(3 4)`，`realpart`/`imagpart`/`conjugate`/`abs` 齐全：

```lisp
(* #C(0 1) #C(0 1))     ; => -1
(abs #C(3.0 4.0))       ; => 5.0
```

## 4.8 位运算与数论

```lisp
(ash 1 10)       ; => 1024        ← 左移 10 位
(ash 1024 -5)    ; => 32          ← 负数右移
(logand 12 10)   ; => 8
(logior 12 10)   ; => 14
(logxor 12 10)   ; => 6
(lognot 0)       ; => -1
(logcount 15)    ; => 4           ← 1 的个数
(gcd 12 18)      ; => 6
(lcm 4 6)        ; => 12
```

> **注意**：`exptmod`（模幂）**不是**标准函数，SBCL/CLISP 都没有（实测 undefined function）。
> 需要模幂自己写快速幂。

## 4.9 比较：`=` 比数值，`eql` 比类型

```lisp
(= 1 1.0)         ; => T      ← = 只比数值，跨类型也相等
(eql 1 1.0)       ; => NIL    ← 类型不同就不相等
(= 1/2 0.5)       ; => T
```

比大小支持**多个参数连写**（C 里得 `&&`）：

```lisp
(< 1 2 3)         ; => T
(< 1 3 2)         ; => NIL
(<= 1 1 2)        ; => T
```

其余谓词：`(max 1 2.0)` ; => 2.0（混类型按提升规则）、`(zerop 0.0)` ; => T、
`(plusp 0.0)` ; => NIL（0 既不正也不负）、`(evenp 4)` ; => T。

## 4.10 坑位清单

| 症状 | 原因 | 解法 |
|---|---|---|
| 小数算出来差一点 | 浮点字面量默认**单精度** | 写 `1.5d0`，或用有理数 |
| 跨实现输出不一致 | pi/长浮点/传染规则/精确数学，四坑全在 CLISP 侧 | 显式后缀 + `float` 归一（22 章） |
| `(/ 7 2)` 得 `7/2` 不是 `3` | `/` 给精确有理数 | 要整数商用 `floor` / `truncate` |
| 负数取模和 C 不一样 | `mod` 跟除数、`rem` 跟被除数 | 想清楚要哪个 |
| `(round 2.5)` 得 2 不是 3 | 银行家舍入 | 传统舍入写 `(floor (+ x 1/2))` |
| `(sqrt 4)` 得浮点 | `sqrt` 一律返回浮点（精确输入时 CLISP 例外） | 要整数用 `isqrt` |
| `type-of` 结果不是预期类名 | 返回精确区间且形态随实现 | 判断用 `integerp` / `typep` |
