# 16 · format：CL 的 printf，但更强也更危险

> 配套示例：[`examples/16_format/`](../examples/16_format/main.lisp)（channel: both）

`format` 的第一个参数决定输出到哪：`t` 是标准输出、`nil` 是「返回字符串」、
也可以是任意流：

```lisp
(format nil "~A" 1)              ; => "1"      ← 拼字符串的标准做法
(format t "")                    ; => NIL      ← 输出到流时返回 NIL
```

## 16.1 `~A` 与 `~S`

| 指令 | 行为 | 例子 |
|---|---|---|
| `~A` | 给人看（字符串不带引号） | `"abc"` → `abc` |
| `~S` | 给读入器看（带引号、会转义） | `"abc"` → `"abc"` |

```lisp
(format nil "~S / ~A" "字符串" "字符串")   ; => "\"字符串\" / 字符串"
(format nil "~S / ~A" '(1 "two") '(1 "two"))   ; => "(1 \"two\") / (1 two)"
```

**日志和错误消息用 `~S`**——`~A` 会把 `nil`、`""`、`0` 打成容易混淆的样子。

## 16.2 数字全家桶

```lisp
(format nil "~D ~B ~O ~X" 255 255 255 255)     ; => "255 11111111 377 FF"
(format nil "~R / ~:R / ~@R" 4 4 4)            ; => "four / fourth / IV"
(format nil "~36R" 1234567890)                 ; => "KF12OI"（任意进制）
(format nil "~F / ~,2F / ~10,2F" 3.14159d0 3.14159d0 3.14159d0)
; => "3.14159 / 3.14 /       3.14"
(format nil "~E / ~,2E" 31415.9265d0 31415.9265d0)   ; => "3.14159265d+4 / 3.14d+4"
(format nil "~$ / ~3$" 1234.567d0 1234.567d0)        ; => "1234.57 / 1234.567"
(format nil "~:D" 1234567)                     ; => "1,234,567"  千分位
```

实测事实四条：

1. **`~R` 只接受整数**——`(format nil "~R" 1/2)` 报错；
2. **`~D` 固定十进制**——不受 `*print-base*` 影响，要进制用 `~B/~O/~X/~VR`；
3. **mincol 必须非负**——`~-10D` 直接报错（不是左对齐！）；
4. **`~A` 右补空格（左对齐），`~D` 左补空格（右对齐）**——方向相反，
   「左对齐的数字」用 `~10A`，补零用 `~10,'0D`。

**⚠️ 双实现差异（实测）**：`~E` 打**单精度**数时，指数标记大小写与有效位数
两实现不同（SBCL `3.1415926e+4` / CLISP `3.1415924E+4`）——双精度输入两边一致；
`~F`/`~E`/`~$` 跨实现都喂 `d0` 字面量最稳（04 章浮点军规的 format 版）。

## 16.3 大小写与复数

```lisp
(format nil "~(~A~)" "hEllo")        ; => "hello"     全小写
(format nil "~@(~A~)" "hEllo")       ; => "Hello"     每词首字母大写
(format nil "~:(~A~)" "hello world") ; => "Hello World"（句式：首词大写）
(format nil "1 item~P / 3 item~P" 1 3)  ; => "1 item / 3 items"
```

## 16.4 换行与制表（以及那个最著名的坑）

- `~%` 无条件换行；`~&` 只在「不在行首」时换行（避免空行）；
- `~T` 跳列：`~10T` 跳到 10 的倍数列；`~~` 输出波浪号本身。

**`~|` 不是表格竖线，它是「换页」指令**——往输出里塞 `#\Page`（字节 `0x0C`）：

```lisp
(let ((s (format nil "a~|b")))
  (list (length s) (char-code (char s 1))))     ; => (3 12)   ← 中间藏了个控制字符
```

`~S` 打印 `#\Page` 时显示不出来（看着像 `"ab"`，长度却是 3）。这个错误非常常见：
**有人拿 `~|` 当表格分隔线，输出里全是控制字符**——本仓库验证判定的
「stdout 不得含多余控制字符」抓的就是它。要竖线写 `|`，要对齐用 `~T`。

**⚠️ 双实现差异（实测）**：CJK 内容的 `~T` 列宽两实现数法不同
（按字符还是按显示宽度），对齐表格请用 ASCII 内容或 `~A` 定宽（08 章方向）。

## 16.5 参数跳位、迭代与条件

```lisp
(format nil "~A ~* ~A" :第一个 :被跳过 :第三个)   ; => "第一个 第三个"（~* 跳参）
(format nil "~A ~:* 再用一次" :同一份)            ; => "同一份 再用一次"（~:* 回退）

(format nil "~{<~A>~^ ~}" '(1 2 3))               ; => "<1> <2> <3>"
;; ~{...~} 吃一个列表逐项迭代；~^ 让最后一项不带分隔符——打印列表的万能写法
(format nil "~@{[~A]~^,~}" :a :b :c)              ; => "[A],[B],[C]"（@版吃剩余实参；~A 打关键字不带冒号）
(format nil "~{~{~2D~^ ~}~^ | ~}" '((1 2) (3 4)))  ; 嵌套迭代 → 1 2 | 3 4（两位右对齐）

(format nil "~[红~;绿~;蓝~:;其他~]" 2)            ; => "蓝"（按参数下标选分支）
(format nil "~:[假~;真~]" nil)                    ; => "假"（按 NIL 二选一）
```

## 16.6 打印控制变量

`~S` 与 REPL 回显都受这些变量影响：

```lisp
(let ((*print-pretty* nil)) (format nil "~S" '(1 2 3)))       ; => "(1 2 3)"
(let ((*print-case* :downcase)) (format nil "~S" 'hello))     ; => "hello"
(let ((*print-length* 3)) (format nil "~S" '(1 2 3 4 5)))     ; => "(1 2 3 ...)"
(let ((*print-level* 2)) (format nil "~S" '(1 (2 (3 (4))))))  ; => "(1 (2 #))"
```

`*print-circle*` 专治**循环结构**（不开会无限递归）：

```lisp
(let* ((cyc (list 1 2 3)) (*print-circle* t))
  (setf (cddr cyc) cyc)
  (format nil "~S" cyc))
; => "#1=(1 2 . #1#)"
```

**做输出比对（测试、黄金文件）时统一打印变量**，否则会把「打印设置不同」
误判成「程序行为不同」——最典型的连锁反应是引号缩写：
SBCL 只在 `*print-pretty*` 打开时才把 `(quote x)` 打成 `'x`（03 章实测）；
CLISP 恒用缩写。

**⚠️ 双实现差异（实测）**：CLISP 的 `~A` 遇到**含换行的字符串**会自动在它
前后断行（pretty 填充行为），SBCL 原样内联——跨实现一致的输出里，
别把带换行的字符串交给 `~A`，换行自己用 `~%` 显式打。

## 16.7 指令写错会怎样

指令是**运行期解析**的（字符串字面量编译期预编译），拼错编译时未必告诉你：

```lisp
(format nil "~A ~A" 1)     ; 报错：No more arguments（出错位置标在指令上）
(format nil "~A" 1 2)      ; => "1"     ← 参数多了静默忽略！
(format nil "~K" 1)        ; 报错：Unknown directive
(format nil "~-10D" 1)     ; 报错：mincol must be non-negative
```

**最常犯的错**：想输出 `~A` 这几个字符，结果被当指令执行——
**要显示波浪号必须写 `~~`**：`(format nil "~~A")` ; => `"~A"`。

## 16.8 坑位清单

| 症状 | 原因 | 解法 |
|---|---|---|
| 输出里混进控制字符 | `~\|` 是换页不是竖线 | 竖线写 `\|`，对齐用 `~T` |
| 想输出 `~A` 却少了参数 | 没写 `~~` | 转义 `~~A` |
| `~E` 两实现输出不同 | 单精度的指数标记实现自定 | 双精度 `d0` 输入 |
| CJK 表格对不齐 | `~T` 列宽数法不同 | ASCII 内容 / `~A` 定宽 |
| CLISP 输出多出空行 | `~A` 打含换行字符串触发断行 | 换行显式 `~%` |
| `(format nil "~R" 1/2)` 报错 | `~R` 只收整数 | `~A` / `~D` |
| 测试比对不稳定 | 打印变量不统一 | 比对双方绑同一组变量 |
| 打印循环结构卡死 | 没开 `*print-circle*` | 绑 `t` |
