## 四、渐近记号与递归式速查

- **O（上界）**：f = O(g) ⟺ ∃c,n₀，n≥n₀ 时 f(n) ≤ c·g(n)。**Ω（下界）**：同理 ≥。**Θ（紧确）**：同时 O 与 Ω。
- 常见比较排序下界：**Ω(n log n)**（决策树 n! 叶子的 log 归并，第 21 章）。
- **Master 定理**：T(n) = a·T(n/b) + f(n)，f(n) = O(n^d)：
  - **情形 1** d < log_b a：T(n) = Θ(n^(log_b a))（子问题主导，如 merge 的 O(n log n)）；
  - **情形 2** d = log_b a：T(n) = Θ(n^d · log n)（如 BST 中序输出、T(n)=2T(n/2)+n）；
  - **情形 3** d > log_b a：T(n) = Θ(n^d)（合并主导，如 heapify 的 T(n)=2T(n/2)+n 步场景依 f 而定）。
- 常见递归式：T(n)=T(n/2)+1 → Θ(log n)（折半查找）；T(n)=2T(n/2)+n → Θ(n log n)；T(n)=T(n−1)+n → Θ(n²)；T(n)=2T(n−1)+1 → Θ(2ⁿ)（汉诺塔，第 03 章）。
- 主导项相加取最大：O(n² + n log n) = O(n²)。

## 六、C++23 实现备忘（全书通用约定）

- 未初始化存储：`std::byte` 缓冲 + `std::construct_at`/placement new；析构用 `std::destroy_at`（第 04 章）。
- 五特殊函数：`=default` 可拷贝类型（`std::copyable` concept 约束）、移动须 `noexcept` 否则 `std::vector` 扩容退回拷贝。
- 错误处理：编程错误 throw 标准异常；可预期失败返回 `std::expected`/`std::optional`（第 16 章查找接口）。
- 接口窄化：`std::span`（连续只读）、`std::string_view`（字符串只读）——不看实现只用合同。
- 确定性测试：随机只用 `std::mt19937 rng{5489}` 固定种子；平局按编号/字典序决胜；禁打印指针/地址/capacity 原始值。
- 打印：`std::println`/`std::print`（`<print>`）；树形/网格输出用多行字符串拼接后一次打印（第 10、24 章）。
- 强异常保证：扩容/重组先在新存储上完成全部可能抛出的工作，再指针互换（第 04 章拷贝交换惯用法）。
