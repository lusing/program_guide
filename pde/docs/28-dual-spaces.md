# 28 H^{-1} 与时空空间

**对应书 §5.9（H^{-1} = H¹₀ 的对偶；时空 Sobolev 空间）。**

---

## 28.1 负范数与 Bochner 框架

**H^{-1}**：H¹₀ 的对偶。谱刻画（(0,1) 上）：f = Σf_kφ_k ⟹

    ‖f‖_{H^{-1}}² = Σ f_k²/(1 + λ_k)

——δ 分布属于 H^{-1}（窄 Gauss 近似列范数有界）但不属于 L²。
嵌入链 L² ⊂ H^{-1}（‖f‖_{H^{-1}} ≤ C‖f‖_{L²}）。

**时空空间**（§5.9.2）：发展方程弱解住在

    L²(0,T; H¹₀) ∩ H¹(0,T; H^{-1})，

u_t 作为 H^{-1} 值函数有意义——能量恒等式 d/dt·½‖u‖² = −‖∇u‖²
在此框架里是基础账目。

## 28.2 机器验证（Julia `28_dual_spaces.jl`）

- (a) δ 的近似列：ε = 0.1/0.05/0.01 的窄 Gauss 的 H^{-1} 范数有
  界（→常数）——分布进负 Sobolev 空间的数值面；
- (b) L² ⊂ H^{-1}：单模式比值 1/√(1+9π²) ÷ 1/√2 < 1；
- (c) 时空范数闭式：u = e^{−t}sinπx 的 L²(0,T;H¹) 与
  L²(0,T;H^{-1}) 范数平方逐项积分闭式；**能量恒等式**对**热方程
  解** e^{−π²t}sinπx 数值成立；

> 坑账：初版拿 e^{−t}sin(πx)（任意函数）验能量恒等式——恒等式
> 只对热方程解成立，被数值当场打回。**恒等式的适用对象也是定理
> 的一部分。**

- (d) Riesz 配对饱和：u* = f/(1+λ) 使 ⟨f,u*⟩ = ‖f‖²_{H^{-1}}
  逐位成立。
