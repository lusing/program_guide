# 34 抛物方程弱解：Galerkin 方法

**对应书 §7.1.1–§7.1.2（弱解定义、Galerkin 逼近）。**

---

## 34.1 Galerkin 三步走

弱解：u ∈ L²(0,T;H¹₀) ∩ H¹(0,T;H^{-1}) 满足时空双线性恒等式。
**Galerkin 构造**三步：

1. 特征基截断 u_m = Σc_k(t)φ_k ⟹ 模式 ODE 组 **ċ + λc = f**；
2. 能量估计（一致于 m）；
3. 紧性 + 极限（27 章 Rellich 的用武之地）。

## 34.2 机器验证（Julia `34_parabolic_weak.jl`）

- (a) 模式 ODE 的 RK4 vs 闭式 c₁ = (1−e^{−π²t})/π²（10⁻¹⁰）；
- (b) 能量衰减估计 E(t) ≤ E(0)e^{−2λ₁t}，比值恒 0.800（高模式
  更快衰减的谱间隙可视化）；
- (c) 正则性提升的谱面：单模式的 ‖u‖²_{H²} = ‖u_t‖²（时间导数
  与空间正则性同源）；
- (d) 长时衰减 e^{−π²t}（t=10 时 10⁻⁴³）。

## 34.3 要点回顾

1. Galerkin = 谱截断 + ODE + 能量估计 + 紧性——发展方程弱解的
   标准生产线。
2. λ₁ 决定衰减率；谱间隙决定渐近纯度。
