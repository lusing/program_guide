# 44 上下解、非存在与梯度流

**对应书 §9.3（上下解方法）、§9.4（非存在：blow-up、Pohozaev）、
§9.5（几何性质）、§9.6（梯度流与非线性半群）。**

- **上下解**：u₀ ≤ u₁ ⟹ 解存在且被夹住；单调迭代从**上解**出发
  向下夹逼到最小解；
- **非存在**：blow-up（u_t = u² 的 t* = 1/u₀）；**Pohozaev 恒等式**
  ⟹ 临界指标 p ≥ (n+2)/(n−2) 时无解（星形域）；
- **梯度流**：u_t = −∇I（能量最速下降；凸 ⟹ 收敛到极小）。

Julia（`44_subsupersolutions.jl`）：−u″ = u² 的单调迭代（坑账：从
下解 0 出发不动——0 本身是不动点；从上解 4 出发收敛到最小解，
峰值 0.0005 被夹住）；ODE blow-up 时间表；Pohozaev 样本恒等式
（n=2 首项消失的矛盾论证；n=3 临界 p = 5 = Sobolev 临界指数）；
梯度流指数收敛。

要点：上下解给存在 + 定界两样；非存在定理（blow-up/恒等式）划出
可解性的边界；梯度流把变分与抛物结构焊接。

*本章示例：`examples/julia/44_subsupersolutions.jl`。*
