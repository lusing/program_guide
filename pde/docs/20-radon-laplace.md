# 20 Radon 变换与 Laplace 变换

**对应书 §4.3.2（Radon 变换、中心切片定理）与 §4.3.3（Laplace
变换解发展方程）。**

---

## 20.1 Radon 变换

Rf(s,ω) = ∫_{y·ω=s} f dS——**直线积分**族。**中心切片定理**：
投影的 1D Fourier = 2D Fourier 的切片（CT 扫描的数学）。对称约
定下带配平因子 F̂₂ = P̂₁/√(2π)。

## 20.2 Laplace 变换

时间半轴的变换把 t 导数变成 s 乘法：热方程半直线问题 u(0,t) = g(t)
化为 ODE 族 U(x,s)，解出再反演。例：阶跃边界 g = 1 的热方程解
U = e^{−√s x}/s，反演给 **erfc(x/2√t)**。

## 20.3 机器验证（Julia `20_radon_laplace.jl`）

- (a) 圆对称 f = e^{−r²} 的 Radon = √πe^{−s²}（**与角度无关**，
  线积分数值 10⁻⁷）；
- (b) 中心切片定理：投影的 Fourier 与 2D Fourier 切片在三个 ξ
  **逐位一致**（含 (2π)^{−1/2} 配平——19 章约定坑的续集）；
- (c) erfc 解：PDE 残差 ~10⁻⁶（差分精度）、边界值精确 1；
- (d) Laplace 表条目 L[e^{−at}] = 1/(s+a) 数值积分对账 10⁻⁸。

## 20.4 要点回顾

1. Radon = 直线积分族；切片定理连接投影与变换（层析成像原理）。
2. Laplace：时间导数 → 代数乘法；√s 出现在半直线椭圆算子的象。
3. 两个变换都以"约定常数纪律"为第一坑位。
