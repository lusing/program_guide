# 25 逼近、延拓与迹

**对应书 §5.3（磨光逼近三种）、§5.4（延拓定理）、§5.5（迹定理）。**

---

## 25.1 三件事

1. **逼近**（§5.3）：C^∞ 在 W^{k,p} 中稠密——内部逼近（紧支于 U）；
   整体逼近；全局逼近（含边界，需 ∂U 是 C¹）。
2. **延拓**（§5.4）：半空间/半圆的**反射延拓**保持 W^{k,p}（范数
   翻倍以内）；一般 C¹ 域由此拼出。
3. **迹**（§5.5）：u ∈ W^{1,p}(U) ⟹ 限制到边界的**迹** Tu ∈
   L^p(∂U) 有界 ‖Tu‖ ≤ C‖u‖_{W^{1,p}}。反向不真：给定边界值造函
   数（边界层家族）的 W^{1,p} 范数可爆炸——迹算子不可逆。

## 25.2 机器验证（Julia `25_approximation.jl`）

- (a) 磨光逼近：帽子函数 u^ε = η_ε*u 的 L² 误差随 ε = 0.2/0.1/0.05
  为 0.073/0.026/0.009——单调趋零（C^∞ 稠密的数值面）；
- (b) 偶延拓：ũ(x) = u(|x|) 的 ∫|Dũ|^p = **2∫|Du|^p**（数值逐位，
  范数恰翻倍、无新奇性——反射延拓有效的算例）；
- (c) 迹定理的边界层家族 u = e^{−x/δ}：边界值恒 1，而 ‖u‖_{H¹} =
  √(δ/2 + 1/2δ) 在 δ = 1/0.1/0.01 时 1.0/2.2/**7.1 爆炸**——固定
  边界值的能量代价无界；
- (d) Gagliardo-Nirenberg 插值的模式恒等式：‖u′‖² = ‖u‖·‖u″‖ 对
  sin(kx) **逐位精确**（k = 1, 3）。

## 25.3 要点回顾

1. 稠密（磨光）+ 延拓（反射）+ 迹（边界有界）是 Sobolev 机器的
   三个传动轮。
2. 边界层家族是"迹有界但不可逆"的标准反例样本。
3. GN 插值在单模式上取等——常数不可改进的证据。
