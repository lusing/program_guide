# 21 非线性 → 线性：Cole-Hopf、位势与 hodograph

**对应书 §4.4（Cole-Hopf 变换、位势函数、hodograph/Legendre）。**

---

## 21.1 Cole-Hopf 变换

粘性 Burgers 方程 u_t + u u_x = νu_{xx} 经

    **u = −2ν(ln φ)_x**

**线性化**为热方程 φ_t = νφ_{xx}。这是"非线性问题换坐标后变线
性"的教科书案例——14 章的粘性消失解、21 章的行波全由它生成。

## 21.2 位势与 hodograph

- **位势**：u = w_x 把守恒律变成势的 HJ 方程（13 章的桥梁）；
- **hodograph**：把 (u,v) 当自变量、(x,y) 当未知（图象反转）——
  某些一阶方程（如自由边界问题）在 hodograph 平面上线性。

## 21.3 机器验证（Julia `21_cole_hopf.jl`）

- (a) 构造 φ = 1 + ½G（热核平移族），u = −2ν(lnφ)_x（φ_x 用
  **解析闭式**——差分套差分噪声 10⁻³，闭式后残差 **8×10⁻¹⁰**）
  满足粘性 Burgers；
- (b) 粘性激波行波 u = 1/(1+e^{(x−t/2)/2ν})：残差 10⁻⁷；ν → 0
  时剖面中心恒 ½、宽度 → 0——**收敛到 15 章的熵激波**（RH 速度
  ½），Cole-Hopf 是熵解的物理出身；
- (c) 位势形式：13 章 Hopf-Lax 的 w 数值满足 w_t + (w_x)²/2 = 0
  （差分精度内）。

## 21.4 要点回顾

1. Cole-Hopf：非线性 ⟺ 线性的显式桥；粘性激波 → 熵激波的机制。
2. 位势（u = w_x）与 hodograph（交换自变量/未知量）是两个方向
   的"换坐标"。
3. 变换类的机器验证要点：被变换量的导数尽量用闭式。
