## 37.1 双曲组

一阶组 **U_t = A U_x**（A 常对称）：特征值 = 传播速度，特征向量
分解为行波分量。**对称双曲**（A(x,t,u) 对称）的能量估计 d/dt‖U‖²
≤ C‖U‖²（分部积分 + Aᵀ = A）——可对称化的组（如 Euler 线性化）
都有弱解存在性。这是 56 章（守恒律组）的线性热身。

## 37.2 机器验证（Julia `37_hyperbolic_systems.jl`）

- (b) 特征不变量：R± = u_t ± u_x 沿 x∓t 特征常数——d'Alembert 分
  解的微分核对（g′(x+t) 逐位）；
- (c) 组的本征分解：A = [[0,1],[1,0]] 的特征 ±1 = 传播速度；纯
  右行初值（u = v）的脉冲**精确平移**（u(1.0, 0.7) = u₀(0.3) 逐
  位）；
- (d) 对称性 ⟹ 等距（能量守恒）；非对称组的增长/衰减由 A 的符
  号特征控制。

## 37.3 要点回顾

1. 组的特征值 = 波速；特征向量 = 行波分解。
2. 对称双曲 ⟹ 能量估计 ⟹ 存在性（Friedrichs 框架）。
3. 波方程 = 对称组化的原型（(u, u_t) 一阶化）。
