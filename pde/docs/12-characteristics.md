# 12 非线性一阶 II：特征线

**对应书 §3.2（特征 ODE 的推导、边界条件、局部解构造、应用）。**

---

## 12.1 特征 ODE 组

一般一阶方程 F(Du, u, x) = 0。固定解 u，考察沿曲线 x(s) 的值
z(s) = u(x(s)) 与梯度 p(s) = Du(x(s))。要求 z、p 满足 ODE 系统
（书式 (11)）：

    ẋ(s) = D_p F(p, z, x)，ż(s) = D_p F·p，ṗ(s) = −D_z F·p − D_x F。

这是**特征线方程**：PDE 被替换成 (x, z, p) 空间的 ODE 流——解在
特征曲面上被 ODE 唯一确定。局部解存在性（书 §3.2.4）：给非特征
边界曲线上的初值，特征带扫出解曲面，直到特征线相交（11 章的爆
破时刻）。

**非特征条件**：边界切向与特征方向横截（det ≠ 0），否则数据不能
沿边界传播。

## 12.2 机器验证

Julia 通道 `examples/julia/12_characteristics.jl`：

**(a) 拟线性方程** u_x + u·u_y = 0：特征 dx/ds = 1、dy/ds = u、
du/ds = 0——特征线是直线 y = g(ξ)(x−ξ)。数值解隐式方程（Newton
迭代求 ξ(x,y)），残差 u_x + u·u_y = **4×10⁻¹¹**（三点）。

**(b) HJ 方程** u_y + (u_x)²/2 = 0：特征 ẋ = p、ṗ = 0，初值
g = x²/4 ⟹ p₀ = ξ/2。显式解 u = ξ²/4 + ξ²t/8（ξ = x/(1+t/2)）
残差 10⁻¹²。

**(c) 横截性**：边界 y = 0 与特征方向 (1, g) 的行列式 −g ≤ −0.5
< 0 处处成立——非特征，数据合法。

## 12.3 要点回顾

1. 特征线法：PDE ⟹ (x,z,p) 空间的 ODE 流——一阶方程的全部局
   部理论。
2. 拟线性：特征是直线族（u 沿特征常数）；相交 ⟹ 爆破。
3. 非特征边界条件是解存在的门槛。
