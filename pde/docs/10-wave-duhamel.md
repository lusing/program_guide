# 10 波方程 II：Duhamel、能量与有限传播

**对应书 §2.4.2（非齐次问题）与 §2.4.3（能量方法：能量守恒、
有限传播速度、唯一性与连续依赖）。**

---

## 10.1 Duhamel 原理

非齐次波方程 u_tt − Δu = f、零初值的解由 Duhamel 原理给出：
把 f(·,s) 视为 s 时刻的"新初速度"，对每个 s 解齐次问题再积分。
一维显式形式：

    u(x,t) = ½ ∫₀ᵗ ∫_{x−(t−s)}^{x+(t−s)} f(y,s) dy ds。

Julia 通道制造解对账：f = e^{−s}cos y 的解是 A(t)cos x，其中
A'' + A = e^{−t}、A(0) = A′(0) = 0，解出

    A(t) = ½(e^{−t} − cos t + **+** sin t)——

数值 Duhamel 双重 Simpson 与闭式差 **2.7×10⁻¹³**。

> 坑账：初值条件 A′(0) = 0 给出 c₂ = **+**½（因特解 ½e^{−t} 的导
> 数在 0 处是 −½），初版推成 −½——Duhamel 数值当场翻案（差
> 0.78，非数值误差量级）。**制造解的待定系数要代回初始条件逐项
> 核，闭式与数值必须互审。**

## 10.2 有限传播 vs 无限传播（对表高潮）

紧支初值 g（|y| < 0.5）：

- **波**（d'Alembert）：u(x,t) 只依赖 [x−t, x+t] ∩ supp g。
  x = 3/5/2 处锥外的解**精确为零**（不是小，是 0.00e+00）；
- **热**（同初值，06 章核）：x = 5、t = 0.5 处 u = 1.3×10⁻⁶ > 0。

双曲的**依赖锥**与抛物的**无穷传播**在同一个实验里对照——这是
02 章特征线、06 章 Gauss 尾巴、09 章 Huygens 的总收束。

## 10.3 能量方法

书 §2.4.3：E(t) = ½∫(u_t² + |∇u|²) dx 满足 dE/dt = 0（分部积
分，边值贡献为零）——**能量守恒**。三个直接推论：

1. **唯一性**：两解之差零初值 ⟹ 能量恒零 ⟹ 差为零；
2. **连续依赖**：能量范数下解算子等距——数据扰动不放大（适定
   性第三判据的构造性验证）；
3. **有限传播**：局部能量估计压出依赖锥。

数值面（Julia (c)）：单模式 u = cos t·sin x 的动能 + 势能
½(sin²t + cos²t)/2 = **恒 ½**（12 位不变）——动能势能互换而总
和守恒的谱可视。

## 10.4 四大方程收官

至此书第 2 章四大线性 PDE 的显式理论全部完成：

| 方程 | 解公式 | 特征 |
|---|---|---|
| 传输 | g(x−tb) | 沿特征线平移；间断传播 |
| Laplace | Green 函数/Poisson 核 | 边界决定；平均值；无穷光滑 |
| 热 | Gauss 核卷积 | 无穷传播；瞬时磨光；半群 |
| 波 | d'Alembert/Kirchhoff | 有限传播；能量守恒；Huygens |

11 章起进入非线性——特征线方法将把"沿曲线积分 ODE"的思想推广
到特征线本身依赖于解的情形。

## 10.5 要点回顾

1. Duhamel：源项 = 连续注入的新初值；系数待定后必须数值互审。
2. 有限传播（锥内）vs 无限传播（全场即刻）——双曲/抛物分水岭的
   定量对表。
3. 能量守恒 ⟹ 唯一性 + 等距连续依赖 + 有限传播，一石三鸟。
