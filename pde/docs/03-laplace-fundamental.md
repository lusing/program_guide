# 03 Laplace 方程 I：基本解与平均值公式

**对应书 §2.2.1（基本解的导出、Poisson 方程的解，定理 1）与
§2.2.2（平均值公式，定理 2、定理 3）。**

---

## 03.1 从物理到方程

Laplace 方程 Δu = Σu_{x_ix_i} = 0 与 Poisson 方程 −Δu = f 是全
书第一主角。典型解释：u 是平衡态的浓度/温度/静电势。任取光滑子
区域 V，净通量为零：∮_{∂V} F·ν dS = 0；由 Gauss–Green 定理得
div F = 0。物理上通量与梯度反向成比（Fick 扩散 / Fourier 导热 /
Ohm 导电三定律同形 F = −a Du），代入即得 Δu = 0。**椭圆方程 =
无源平衡态**——这是它一切性质的物理根源：没有"时间"，解被边界
完全决定。

调和函数（harmonic）就是 C² 且满足 Δu = 0 的函数。

## 03.2 基本解：对称性先行

策略（书 §2.2.1 的示范）：**先找显式解，再组装**；找显式解时先
用对称性减维。Laplace 方程在旋转下不变 ⇒ 先找径向解 u(x) =
v(r)，r = |x|。代入得径向 ODE（书式 (5)）：

    v″(r) + (n−1)/r · v′(r) = 0。

n ≠ 1 时解出 v′ = a r^{1−n}，再积分：n = 2 得 **a log r + c**；
n ≥ 3 得 **a r^{2−n} + c**。规范化常数后（书式 (6)）：

    Φ(x) = −(1/2π) log|x|     (n = 2)，
    Φ(x) = 1/(n(n−2)α(n)) · |x|^{2−n}    (n ≥ 3)，

其中 α(n) 是单位球体积（α(2) = π、α(3) = 4π/3）。这就是
**基本解**：除原点外调和，在原点带恰好一个"单位电荷"的奇性。

### −ΔΦ = δ 的数值化身：通量恒为 −1

分布意义下 −ΔΦ = δ₀ 的可计算面是**通量**：对任意半径 ρ 的球面，
∮ ∇Φ·ν dS = −1（与 ρ 无关）。n = 2 时 ∇Φ·ν = −1/(2πρ) 是常数，
乘周长 2πρ 得 −1；n = 3 时 −1/(4πρ²)·4πρ² = −1。Julia 通道
`examples/julia/03_laplace_fundamental.jl` 对 ρ = 0.3/1.7/4.0 逐个
积出（圆周梯形，谱精度），全部 −1（误差 < 10⁻¹²）；Prolog 通道
`examples/prolog/03_laplace_fundamental.pl` 把它做成规则：

```prolog
flux_density(2, Rho, D) :- D is -1 / (2 * pi * Rho).
surface(2, Rho, S)      :- S is 2 * pi * Rho.
flux(N, Rho, F)         :- flux_density(N, Rho, D), surface(N, Rho, S), F is D * S.
```

### 定理 1（Poisson 方程的解）

    u(x) = ∫ Φ(x−y) f(y) dy    ⟹    u ∈ C² 且 −Δu = f。

证明的**技术核心是奇点隔离**（书 p.23-25）：Φ 的二阶导数在 y = x
处不可和（估计 (7)），不能天真地在积分号下求导。挖去 B(x,ε)，
在外部分部积分两次，边界项

    K_ε = (1/|∂B(0,ε)|) ∮_{∂B(x,ε)} f dS → f(x)

恰是 f 的球面平均 → f(x)。数值对账（Julia (d) 段）：取 f 为
圆盘 {|y| < a} 的指示函数，则

    u(0) = −∫₀^a r log r dr = a²(1 − 2 log a)/4，

Simpson 数值（奇点尾段解析补 ε²/2·log ε − ε²/4）与闭式对到
9×10⁻¹²。**卷积公式的每一分能对账的都对账**。

## 03.3 平均值公式：定理 2

调和函数的标志性性质（书定理 2）：若 B(x,r) ⊂ U，则

    u(x) = ⨍_{∂B(x,r)} u dS = ⨍_{B(x,r)} u dy——

**点值 = 球面平均 = 球平均**。证明两步：① 定义 φ(r) = 球面平
均，用 Green 公式算出 φ′(r) = (1/(nα(n)r^{n−1}))∫_{B(x,r)} Δu dy
= 0，故 φ 是常数，令 r → 0 得常数 = u(x)；② 球平均 = 球面平均
对 r 的加权平均（极坐标），故也等于 u(x)。

### Lean：完整机器证明

Julia 数值版（圆周梯形 4×10⁻¹⁷、圆盘 Simpson 1.4×10⁻¹⁷）之外，
Lean 通道把这个定理对**非平凡调和函数 u = x² − y²** 完整证出
（`examples/lean/Evanspde/Ch03LaplaceFundamental.lean`）：

```lean
theorem mean_value_x2y2 (cx cy ρ : ℝ) :
    (1 / (2 * π)) * ∫ θ in (0 : ℝ)..2 * π,
      ((cx + ρ * cos θ)^2 - (cy + ρ * sin θ)^2) = cx^2 - cy^2 := by
```

对**一切圆心与半径**成立。证明的骨架与书一致——被积函数展开后
按频率分项：

    (cₓ+ρcosθ)² − (c_y+ρsinθ)² = (cₓ²−c_y²) + 2cₓρcosθ − 2c_yρsinθ + ρ²cos2θ，

其中用了倍角恒等式 cos²θ − sin²θ = cos(θ+θ)。三个非零频分量的
积分各自为 0（FTC + 端点 sin(2π) = sin(4π) = 0），常数项贡献
2π(cₓ²−c_y²)，除以 2π 收官。文件里 ∫cos θ、∫cos 2θ 为独立引理。

这条证明踩出的坑值得记录（Lean 4.33 实测）：

- **嵌套 `HasDerivAt.add` 产生 Pi-加法函数形状**（`(f+g)+h` 逐点
  加法），与手写 λ-体不 defeq-unify——一级加法可以、嵌套不行；
  解法是**分项积分**，每项单独 FTC（文件头注释有完整坑账）。
- `Real.sin_sq` 的右端形状是 `cos (x * 2)`，与 `cos (2 * x)` 不语
  法匹配——倍角一律走 `Real.cos_add`（θ+θ 版本）。
- `integral_eq_sub_of_hasDerivAt` 带可积性副目标，
  `Continuous.intervalIntegrable 0 (2*π)` 显式喂。
- `ring` 不认 π·π⁻¹ = 1（π 是原子）——`field_simp` 加 `positivity`
  提供 π ≠ 0。

## 03.4 定理 3（逆平均值性质）与次/超调和

平均值性质的**逆**也成立：C² 函数若在每点都满足球面平均 = 点值，
则调和。证明一行的精髓：若 Δu ≢ 0，则有球上 Δu > 0，于是

    0 = φ(r) − u(x) = (1/(nα(n)rⁿ))∫_{B(x,r)} Δu dy > 0，

矛盾。这条"平均即调和"的判定面把函数分成三类（数值与规则两通
道同时验证）：

| 类 | 球面平均 − 中心值 | 例子 |
|---|---|---|
| 调和 | = 0 | x² − y² |
| 次调和（sub） | > 0 | \|x\|²，恰超出 ρ² |
| 超调和（super） | < 0 | −\|x\|² |

Julia (b) 段实测：|x|² 在圆心 (0.2,0.5)、半径 0.6 处球面平均超出
中心值 0.360000 = ρ² **逐位精确**（对二次多项式圆周梯形是恒等
式）；Prolog 的 `mean_gap/2` 规则给出符号判定。次/超调和函数在
44 章（上下解方法）升格为构造解的工具。

## 03.5 要点回顾

1. 对称性先行：径向假设把 PDE 降为 ODE，解出 log / r^{2−n}；常
   数规范化使通量恰为 −1（−ΔΦ = δ）。
2. 定理 1 的奇点隔离：ε 球挖除 + 两次分部积分，边界项收敛到
   f(x)——不能在奇异核下天真换序。
3. 平均值公式（点 = 球面 = 球）是调和函数一切精细性质的发动机
   （04 章的 Liouville、Harnack、正则性全部由它驱动）。
4. 平均 ⟺ 调和（定理 3）；次/超调和由平均差的符号定义。
5. Lean 完整证明的平均值公式 + 数值谱精度对账：三通道看到同一
   个定理。
