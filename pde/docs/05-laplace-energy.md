## 05.1 能量方法登场

至此对 Laplace 方程的分析都依赖**表示公式**（基本解、Green 函数）。
书 §2.2.5 换武器：**L² 型的能量估计**——这是第二、三部分（弱解理
论）的先声。

**唯一性的能量证明**（定理 16）：设 u、u' 都是 −Δu = f、u|∂U = g
的解，w = u−u' 调和且零边值。分部积分（Green 公式）

    ∫_U w·Δw dx = −∫_U |∇w|² dx = 0（因 Δw = 0）

⟹ ∫|∇w|² = 0 ⟹ ∇w ≡ 0 ⟹ w 常数 ⟹（零边值）w ≡ 0。与 04 章的
极值原理证法殊途同归，但**能量版不依赖极值原理**——它在线性椭
圆理论里普适得多（系数变号、复值、弱解都行）。

## 05.2 Dirichlet 原理：解是能量极小点

定义**能量泛函**

    E[w] = ∫_U (½|∇w|² − w f) dx    （w 满足边值条件），

则 Poisson 问题的解满足（分部积分）

    E[u + εv] − E[u] = ε·∫(∇u·∇v − fv) + (ε²/2)∫|∇v|²，

第一项（**一阶变分**）因 u 满足弱方程而为零，第二项恒正——
**u 是严格极小点**（Dirichlet 原理）。反过来，极小点的一阶变分
消失正是弱解方程。书随后的存在性证明走变分直接法（极小化序列
+ 下半连续性），那是第 8 章的主题，这里先按下。

### Julia：一阶变分消失 + 凸性 + 极小值闭式

`examples/julia/05_laplace_energy.jl` 三段实验：

**(a)** 制造解 u = sinπx·sinπy（f = 2π²sinπx·sinπy）。数值能量
（中点求积 + 中心差分，O(h²)）：

- 一阶变分：扰动 u + εv₀（v₀ = sin2πx·sinπy 零边值）的能量导数
  中央差分 = **1.3×10⁻⁹**（应零）；
- 凸性：ε = ±0.05/−0.10/+0.30 的能量全部严格高于 E[u]
  （+1.5×10⁻² / +6.2×10⁻² / +5.5×10⁻¹）；
- 极小值闭式：E[u] = ½∫|∇u|² − ∫u·f = π²/4 − π²/2 = **−π²/4**，
  数值 −2.4674518 vs 理论 −2.4674011（差 5×10⁻⁵）。

> 坑账：初版把闭式写成 −π²/16（积分算错一个 4）、数值能量用偏移
> 节点求积（一阶精度）——两个错都被"E[u] 必须等于理论值"当场
> 翻案。**求积节点选中点，闭式系数逐项推。**

**(b)** Rayleigh–Ritz 谱展开：方域 f = 1、零边值，正弦基展开。
**坑账（本章最有价值的一笔）**：能量极小的系数是 c_{mn} = 4f_{mn}/λ_{mn}
——基函数 ∫φ² = 1/4 的那个 **4** 忘掉后，系数少乘 4、能量闭式跟着
错一套；数值能量积分当场对出 4 倍差，逐分量诊断（∫u 分量精确、
梯度分量差 4 倍）定位到系数。修正后：

- E_min 闭式 = −2Σf²/λ = −0.0175173（9 项），数值 −0.0175187 ✓；
- 中心值 u(½,½) 收敛到 **0.073672**——方域扭转函数的经典值。

（对称地，Lean 通道把"系数 = 4f/λ 使能量极小"的代数核独立证出，
见下。）

**(c)** Poincaré 能量控制：‖v‖² ≤ ‖∇v‖²/λ₁（λ₁ = 2π²），第一模
式**逐位饱和**（0.25 = 0.25），混合模式严格小于。

## 05.3 Lean：配方法的完整证明

书 p.43 的论证（一阶变分 = 0 + 二阶变分 > 0）在有限维截断上是
纯代数——`examples/lean/Evanspde/Ch05LaplaceEnergy.lean` 对任意
有限指标集 ι、刚度 λᵢ > 0、载荷 fᵢ 完整证明：

```lean
theorem rrEnergy_diff (hlam : ∀ i, 0 < lam i) (v : ι → ℝ) :
    rrEnergy lam f v - rrEnergy lam f (fun i => f i / lam i)
      = ∑ i, (lam i / 2) * (v i - f i / lam i)^2 := by
```

E(v) − E(c) **恰是平方和** Σ(λ/2)(v−c)²（配方法，`field_simp` +
`ring` 逐项）；由此两条推论直接读出：

- `rrEnergy_minimal`：E(c) ≤ E(v)（平方和非负）——Dirichlet 原理；
- `rrEnergy_unique`：能量达到极小 ⟹ v = c（非负项和为零 ⟹ 逐项
  为零 ⟹ 平方为零 ⟹ 逐点相等）——严格凸性。

这三条正是 ch8 变分直接法（存在）、ch29 Lax–Milgram（唯一）在离
散层面的全部逻辑。Julia 的 (b) 实验是这个定理在 {（m,n）: m,n odd ≤ 5}
（9 元指标集）上的具体实例。

> Lean 坑账：①`variable (hlam : …)` 只在**陈述**引用时自动绑定，
> 证明体内引用必须在签名里显式写参数；②`positivity` 推不出
> λᵢ/2 > 0（λᵢ 是函数值假设），要手动 `div_nonneg (hlam i).le
> two_pos.le`；③嵌套的 Σ 差要**三次** `← sum_sub_distrib` 才能
> 合并到逐项形状。

## 05.4 Prolog：能量规则

`examples/prolog/05_laplace_energy.pl` 把唯一性能量论证写成三段
规则链 `energy_uniqueness`（调和零边值 → 分部积分 → 能量为零 →
梯度为零 ⟹ 常数），一阶变分条件与 RR 系数/能量闭式规则各一条，
数值核与 Julia (b) 的单模式对账（c₁₁ = 4f/λ、E = −2f²/λ 十五
位一致）。

## 05.5 要点回顾

1. 能量唯一性：∫|∇w|² = 0 ⟹ w 常数——不依赖极值原理，弱解理
   论的主力。
2. Dirichlet 原理：解 = 能量极小；一阶变分消失即弱解方程，二阶
   变分恒正即凸性。
3. 谱基下的结构：E_min = −2Σf²/λ（∫φ²=1/4 标度）、c = 4f/λ——
   基归一化常数必须全程跟队。
4. 配方法恒等式 E(v)−E(c) = Σ(λ/2)(v−c)² 是变分法的离散灵魂，
   Lean 完整证明。
