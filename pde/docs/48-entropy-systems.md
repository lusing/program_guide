# 48 Riemann 不变量与熵准则

**对应书 §11.3（两方程组、Riemann 不变量、光滑解非存在）与
§11.4（熵/熵通量对、消失粘性、标量唯一性）。**

- **熵对** (η,q)：凸 η + 相容 η′f′ = q′；熵解满足 η(u)_t + q(u)_x ≤ 0；
- **消失粘性**：粘性剖面（宽 O(ε)）的极限挑出熵解；
- **光滑解非存在**：真非线性场的特征相交时间有限。

Julia（`48_entropy_systems.jl`）：Burgers 熵对 (u²/2, u³/3) 的相容
条件逐位；光滑爆破时间 t* = −1/min u₀′ = 1.0；粘性剖面宽度 4ε
收窄表；**熵耗散** q 跳 − s·η 跳 = 1/12 > 0（穿过激波严格耗散——
物理解的签名）。

要点：熵条件 = 消失粘性 = 熵耗散——同一物理的三种数学表述。

*本章示例：`examples/julia/48_entropy_systems.jl`。*
