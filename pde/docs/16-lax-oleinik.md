## 16.1 Lax-Oleinik 公式

守恒律 u_t + (u²/2)_x = 0 与 HJ 方程是势–导数关系。把 Hopf-Lax
（13 章）作用在**势** W₀(y) = ∫_{−∞}^y g 上再求导，得

    **u(x,t) = (x − y*)/t**，y* 最小化 (y−x)²/2t + W₀(y)。

这是守恒律的显式解公式——熵解（15 章挑出的那个）。

> **坑账（B2 批最大的一个）**：初版把被最小化写成 g 本身（不是
> 原函数），与 Godunov 数值解差到 0.97——对账当场暴露结构性错
> 误。修正为 W₀（erf 闭式）后最大误差 **0.029**（O(h) 抹平级）。
> **公式里"作用在什么上"与公式本身一样重要。**

## 16.2 Riemann 问题与长时行为

**Riemann 问题**（分段常数初值 u_L | u_R）是守恒律的原子问题：

| 数据 | 解 |
|---|---|
| u_L > u_R | 激波，速度 (u_L+u_R)/2（RH） |
| u_L < u_R | 稀疏波 u = x/t 于 [u_L t, u_R t] |
| 一般 | 激波/稀疏的复合（ch47 系统版） |

**长时行为**（书 §3.4.5）：∫g = M 的初值，解当 t → ∞ 收敛到
**N 波**——三角形剖面的行波，支撑边缘 ±√(2Mt) 以 t^{1/2} 外扩。

## 16.3 机器验证（Julia `16_lax_oleinik.jl`）

- (a) **Lax-Oleinik vs Godunov**（1600 格）：t = 0.8、|x| < 3 窗
  口最大误差 0.029——显式公式与数值格式互相确认（含 W₀ 坑账的
  翻案过程）；
- (b) Riemann 三情形（激波/稀疏/常数）的采样点核对，稀疏内部
  u = x/t 精确；
- (c) **N 波**：帐篷初值质量 M = 0.35，支撑边缘 √(2Mt) = ±1.67
  （t=4）/ ±3.35（t=16），边缘处 Lax-Oleinik 值 → 0——质量守恒
  与 t^{1/2} 外扩律的数值面。

## 16.4 第一部分收官

11-16 章走完非线性一阶的全链：完全积分/包络 → 特征线 → 变分
（Hopf-Lax）→ 弱解/粘性 → 守恒律（RH/熵/Lax-Oleinik）。三条主
线在此汇合：**特征线的几何**（何时死）、**变分的分析**（死后谁接
管）、**熵条件的物理**（谁是对的解）。17 章起进入解的表示技巧大
观园（ch4）。
