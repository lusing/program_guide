# 40 极小存在性：直接方法

**对应书 §8.2（强制性、弱下半连续、极小存在、E-L 弱解、局部极小）。**

**直接方法**：I 强制（‖u‖→∞ ⟹ I→∞）+ 弱下半连续（凸性保证）
⟹ 极小存在。Julia（`40_direct_method.jl`）：

- (a) 梯度下降找极小 = Poisson 解 u = x(1−x²)/6（10⁻⁴）；
- (b) 强制性的二次增长表（λ²π²/4 压倒线性项）；
- (c) 双阱位势（无凸性）的过渡层极小（tanh 型，u(½) ≈ 0、
  |u| ≤ 1）——弱下半连续失效时直接方法失败/多极小的样本。

要点：强制 + 凸性是两张门票；双阱展示失去凸性后的多极小世界。

*本章示例：`examples/julia/40_direct_method.jl`。*
