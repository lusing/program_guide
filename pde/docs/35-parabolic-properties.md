# 35 抛物正则性与极值原理

**对应书 §7.1.3（正则性：时间解析）与 §7.1.4（极值原理、唯一性、
渐近行为）。**

---

## 35.1 抛物的刚性

- **正则性**：u_t 的各阶导存在（解析半群 e^{−tA}：谱指数赢过多
  项式幂）——弱解在 t > 0 立即光滑；
- **极值原理**：Lu ≤ 0 ⟹ max 在抛物边界（底边或侧边）；正性保
  持（非负非零初值 ⟹ 内部严格正）；
- **唯一性**：能量法（差满足能量不等式 ⟹ 零）；
- **渐近**：λ₁ > 0 ⟹ 指数衰减到稳态。

## 35.2 机器验证（Julia `35_parabolic_properties.jl`）

- (a) ‖A^m u‖ 对 m = 2/4/8 有限（π^{4m}e^{−2π²t}，指数压制）；
- (b) 正性保持：帐篷初值的热核卷积在 x = 1.5/3.0 严格正（06 章
  核的复用）；
- (c) 收缩性：解差的 L² 范数按 e^{−π²t} 衰减（唯一性的定量面）；
- (d) 衰减率恒 e^{−2π²}（相邻时间量级之比逐位）。

## 35.3 要点回顾

1. 解析半群 = 时间方向的免费正则性；
2. 正性保持 + 极值原理 + 唯一性构成抛物三件套（06/07 章热方程
   性质的算子版）。
