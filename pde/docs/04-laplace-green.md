## 04.1 平均值公式的八个推论

书 §2.2.3 是"平均值公式驱动一切"的展示厅。设 U 有界，u 调和：

1. **强极值原理**（定理 4）：max_Ū u = max_{∂U} u；连通域上内部
   取到最大值 ⟹ u 常数。证明一行：若 u(x₀) = M，则球平均 = M 迫
   使 u ≡ M 于整个球 {u = M} 既开又闭。取 −u 得最小值版。
2. **唯一性**（定理 5）：Poisson 边值问题 −Δu = f、u|∂U = g 至多
   一解——两解之差是零边值的调和函数，极值原理压死。
3. **正则性**（定理 6）：平均值 ⟹ u ∈ C^∞。证明：磨光核卷积
   u_ε(x) = ∫η_ε(x−y)u(y)dy 用极坐标 + 平均值化为 u(x) 本身——
   **u 是磨光算子的不动点**，而 u_ε 自动光滑。
4. **导数估计**（定理 7）：|D^α u(x₀)| ≤ (C_k/r^{n+k})‖u‖_{L¹}，
   常数 C_k 显式（e·k 递增列）。
5. **解析性**（定理 8）：导数估计压出 Taylor 级数收敛半径下界。
6. **可去奇点**（定理 9）：u 调和于 U−{x₀} 且 sup|x−x₀|^{n−2}|u|
   < ∞（n≥3；n=2 用 log 版）⟹ 可修改 x₀ 处值使之整体调和。
7. **Harnack 不等式**（定理 10）：正调和函数在 B(x₀,r) 上
   sup ≤ 3ⁿ inf；球链迭代到一般连通域。
8. **Liouville**（定理 11）：全空间有界调和函数必常数。证明：
   导数估计中令球半径 r → ∞。

### 数值面（Julia (a)(b) 段）

**磨光不动点**：u = x²−y² 与 Gauss 核卷积数值积分（双向 Simpson，
截断 6σ——4σ 时尾部核质量 3×10⁻⁴ 不够，被对账打回），中心点值
2×10⁻¹⁰ 复现 u 自身。

**Harnack 饱和**：u = 1 + x 在单位圆盘正调和，在半径 r 圆周上
max/min = (1+r)/(1−r) **逐位精确**——线性函数使 Harnack 界取等，
说明常数 (1+r)/(1−r)（一维链的最优版本）不可改进。r = 0.25/0.6/0.9
实测 1.667/4.000/19.000。

**Liouville 的反衬**：非常数调和函数 r²cos2θ 沿射线按 r² 无界增
长——"有界⟹常数"的逆否命题的数值具象。

## 04.2 Green 函数：把边界值做成核

书式 (25) 的 Green 表示还带 ∂u/∂ν 项。**corrector** φ^x 解

    Δφ^x = 0 于 U，φ^x = Φ(y−x) 于 ∂U，

定义 **G(x,y) = Φ(y−x) − φ^x(y)**，(25)+(27) 相加消去 ∂u/∂ν，得
表示公式（书式 (30)，定理 12）：

    u(x) = ∮_{∂U} (∂G/∂ν)(x,y) g(y) dS(y) + ∫_U G(x,y) f(y) dy。

符号写法 −ΔG = δ_x、G|∂U = 0；**对称性** G(x,y) = G(y,x)（定理 13，
对 u = G(x,·)、w = G(y,·) 用 Green 恒等式，两个 ε 球边界项的极限
各留下对方值）。

### 镜像法：半空间与球

corrector 的一般边值问题很难，但对两个"简单几何"可以**反射凑出**：

- **半空间** ℝⁿ₊：x 的镜像 x̄ = (x₁,…,−xₙ)，φ^x(y) = Φ(y−x̄)——
  因为 |y−x̄| = |y−x| 于边界 yₙ = 0。得 Poisson 核
  K(x,y) = (2xₙ/nα(n))·1/|x−y|ⁿ。
- **单位球**：x 的**反演** x* = x/|x|²（|x|·|x*| = 1），φ^x(y) =
  Φ(|x|·|y−x*|)——核心恒等式是**边界上 |y−x| = |x|·|y−x*|**，
  由此 G|∂B = 0。得球的 Poisson 核 P(x,y) = (1−|x|²)/(nα(n)|x−y|ⁿ)。

### Lean：镜像恒等式的完整证明

`examples/lean/Evanspde/Ch04LaplaceGreen.lean` 把球情形的核心计算
证成两条定理。先证**差的显式分解**（纯代数，`field_simp` + `ring`）：

```lean
theorem image_identity_diff (x1 x2 y1 y2 : ℝ) (hx : x1^2 + x2^2 ≠ 0) :
    (y1 - x1)^2 + (y2 - x2)^2
      - (x1^2 + x2^2) * ((y1 - x1/(x1^2+x2^2))^2 + (y2 - x2/(x1^2+x2^2))^2)
      = (1 - (x1^2 + x2^2)) * (y1^2 + y2^2 - 1) := by
  field_simp
  ring
```

两侧之差**恰好**是 (1−|x|²)(|y|²−1)——在边界 |y| = 1 上取零，
这就是镜像法有效的全部原因。代入边界条件即得恒等式：

```lean
theorem image_identity (x1 x2 y1 y2 : ℝ) (hx : x1^2 + x2^2 ≠ 0)
    (hy : y1^2 + y2^2 = 1) : (y1 - x1)^2 + (y2 - x2)^2
      = (x1^2 + x2^2) * ((y1 - x1/(x1^2+x2^2))^2 + ...) := by
  have h := image_identity_diff x1 x2 y1 y2 hx
  rw [hy] at h
  simp at h
  linarith
```

（初版直接 `field_simp; nlinarith [hy]` 未能收账——**先分解差、再代
边界条件**的两步走才是干净路线。）

### 数值对账（Julia (c)(d)、Python、Fortran、Prolog）

- **G 在边界恒零**：G(x,y) = Φ(|y−x|) − Φ(|x|·|y−x*|) 在 8 个边
  界点上全部 ≤ 3×10⁻¹⁷（机器精度）；
- **对称性**：G(x₀,y₀) = G(y₀,x₀) 十二位一致；
- **球的 Poisson 核重构**：u(x) = ∮ (1−|x|²)/(2π|x−y|²) g dS，
  g = cos2θ 的解是 r²cos2θ = x²−y²——Julia 三点重构误差
  1.7×10⁻¹⁶ / 1.9×10⁻¹⁶ / 3.6×10⁻¹⁵（谱精度，g 是自己的特征函
  数），Fortran 同核逐位复现；
- **半平面 Poisson 核**（Python）：归一性 ∫K dy₁ = 1（截断尾段
  闭式校正后 1e-10）；g = cos 的有界调和延拓 e^{−x₂}cos x₁ 重
  构误差 1.5×10⁻⁵，且 L 翻倍误差减半（1/L 收敛签名 1.92）；
  g = t² 那种增长边值**不合法**（Poisson 积分发散）——初版拿它
  当测试被发散警告换掉；
- **Kelvin 反演**（Python (c)）：u(x) = v(x*)（n=2）对调和 v 数值
  Laplacian 残差 6×10⁻⁶（截断主导：v(x*) 的四阶导 ~1/s⁶ 放大）；
- **Prolog 规则库**：`reflect(plane/sphere)`、`green_method/2`、
  `harnack_bound/2`，数值核 `image_gap/5` 在 12 个边界点对账
  8.9×10⁻¹⁶。

> 坑账：半平面核截断尾段**必须**校正——核衰减 1/y²，截断误差
> x₂/(πL)（L=60 时 2×10⁻³）；尾段闭式 1 − (1/π)[atan((L−x₁)/x₂) +
> atan((L+x₁)/x₂)]。第一版把 (1/π) 写成 (2/π)，第二版丢了 1− 前
> 缀——两次都被"raw + tail 必须等于 1"打回。**闭式校正也要对账，
> 否则只是把错误换了件衣服。**

## 04.3 要点回顾

1. 平均值公式是发动机：极值原理、唯一性、C^∞、解析性、Harnack、
   Liouville 全部由它一行/几行推出。
2. 磨光不动点 u_ε = u 是"平均值 ⟹ 光滑"的证明核心，数值上是卷
   积恒等式（截断要 6σ）。
3. Green 函数 = 基本解 − corrector；表示公式消去 ∂u/∂ν；对称性
   是 Green 恒等式的对偶。
4. 镜像法：半空间用平面反射、球用反演 x* = x/|x|²；核心恒等式
   的差 = (1−|x|²)(|y|²−1)，Lean 完整证明。
5. 增长边值使 Poisson 积分发散——测试用例必须满足核的合法性条件。
