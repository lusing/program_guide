# 11 非线性一阶 I：完全积分与包络

**对应书 §3.1（完全积分、从包络造新解）。**

---

## 11.1 完全积分

n 个独立变量的**一阶 PDE 的完全积分**是含 n 个参数的解族
u = φ(x; a₁,…,aₙ)（参数不能通过重新参数化减少）。经典例子：

- eikonal |Du| = 1：u = ±(x₁ − a₁) ± ⋯ ± (xₙ − aₙ) + a₀；
- Clairaut 方程 u = x·Du + f(Du)：任何仿射 u = x·a + f(a)。

## 11.2 从包络造新解

书 §3.1.2 的核心观察：解族 u(x, a) 的**包络**（在与族的切点处
取值）仍是解——因为在切点 u = u_a 且 ∇u = ∇u_a（同一切平面）。
Julia 通道 `examples/julia/11_complete_integrals.jl`：

**(a)** eikonal 的解族 u_a(x) = |x − a|：x ≠ a 处 |u′| = 1 数值
核实——距离函数（00 章）就是这族的下包络。

**(b)** Lagrange 完全积分 u_a(x) = ax − a²/2（H(p) = p²/2 的生成
函数）。族关于 a 是**凹**的——切包络是**上包络** max_a：

```julia
u_envelope(x) = maximum(a -> a * x - a^2 / 2, range(-3, 3, length=1201))
```

数值包络 = x²/2（1e-6）、包络导数 = x（切点 a* = x）——这就是
**Legendre 变换**的几何定义（13 章正式化，Lean 证配方恒等式）。

> 坑账：凹族取 min 得到的是区间端点的退化值 −6（不是切包络）——
> **包络方向由族的凹凸性决定**，与"下包络"的直觉相反。

**(c) 梯度爆破预演**：Burgers u_t + uu_x = 0 的隐式解 u =
g(x − ut) 的特征线映射 Jacobian 1 + g′(ξ)t 在

    t* = −1/min g′ = √(e/8) = 0.582912

处首次为零——数值扫描 min g′ 与理论闭式 1e-4 对账；Jacobian 从
+1 → 0.5 → 0 → −0.5 的完整轨迹。经典解在 t* 死亡，弱解（14-16
章）接管。

## 11.3 要点回顾

1. 完全积分 = 含满参数的解族；包络（切点取值）仍是解。
2. Legendre 变换的几何原型：凹族的切包络。
3. 特征线相交 ⟹ Jacobian 归零 ⟹ 梯度爆破——非线性一阶方程没
   有全局经典解，这是全书"广义解"主题的第二个动机。
