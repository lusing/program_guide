# 07 热方程 II：性质、半群与能量恒等式

**对应书 §2.3.2（热球平均值公式）与 §2.3.3（解的性质：光滑性、
正性、无穷传播、唯一性的弱形式）。**

---

## 07.1 热函数的平均值公式

书 §2.3.2 给出热的类似物：u 满足 u_t − Δu = 0 ⟹

    u(x,t) = ⨍_{E(x,t,r)} u(y,s) · |x−y|²/(t−s)² dyds，

其中 E(x,t,r) = {(y,s) : |y−x|² ≤ r² − 4(t−s)，t−r²/4 < s < t}
是"热球"。权重 |x−y|²/(t−s)² 与椭圆情形的均匀权重不同——时间
方向自带衰减。逆命题同样成立（平均值 ⟹ 热方程），与 Laplace 的
定理 3 平行。

## 07.2 四条性质（数值面）

书 §2.3.3 的性质链在 Julia 通道 `examples/julia/07_heat_properties.jl`：

**(a) 半群律**：u(·, t₁+t₂) = G_{t₂} * u(·, t₁)——热核族是半群。
数值：固定观察点 x = 0.4，一步卷积（t = 1）与两步（0.3 再 0.7）
之差 **3.3×10⁻¹⁶**。

> 坑账：初版实验写成了"嵌套原点卷积"（不带观察点的 ∫Φu 连续
> 嵌套），那不是半群律——半群律要**核随外层变量移动**。数学实验
> 的设计错误会被对账直接暴露（差 0.35，一眼非数值误差）。

**(b) 正性保持**：非负非零初值（帐篷函数）的解在 x = 2/5/9 处
t = 0.5 全部严格正——强极值原理的热版（§2.3.3，配合无穷传播）。

**(c) 无穷光滑化**：帐篷只有 C⁰（角点二阶差分跳变），但 t = 0.1
的解四阶差分有限（数值 -0.0000 平滑）——t > 0 即 C^∞（书定理
10 的数值面）。

**(d) 谱耗散**：模式 e^{−k²t}，k = 1/2/3 在同一时间间隔的剩余比
0.951/0.819/0.638——高波数衰减快，解被"选择性地"磨平。

## 07.3 Lean：能量恒等式的单模式完整证明

书 §2.3.4 能量法的核心恒等式 d/dt·½∫u² = −∫|∇u|² 在第一模式
上是闭式（`examples/lean/Evanspde/Ch07HeatProperties.lean`）：

- `integral_sin_sq_pi` / `integral_cos_sq_pi`：∫₀¹sin²(πx) =
  ∫₀¹cos²(πx) = ½——和角公式（cos(x+x) = cos²−sin²，**sin²+cos²=1
  要显式喂给 linarith**，ring 不知三角恒等式）+ ∫₀¹cos(2πx) = 0
  （FTC，端点 sin(2π) = 0）；
- `heat_mode_energy`：e(t) = e^{−2π²t}/4 的导数 = −π²·e^{−2π²t}/2
  = −P(t)——配方法组合子链 raw 直给 + ring。

这条恒等式乘 −2 就是能量耗散：解的时间行为完全由梯度控制——
34 章 Galerkin 弱解、44 章梯度流的地基。

## 07.4 要点回顾

1. 热球平均值：时间加权的平均性质，与椭圆的均匀平均平行；逆也
   成立。
2. 半群律 G_{t+s} = G_s∘G_t 是"时间发展 = 算子指数"的雏形（38
   章半群理论正式化）。
3. 正性保持 + 无穷传播 + 瞬时光滑 = 抛物三联征。
4. 能量恒等式的单模式闭式版是全部弱解能量估计的原型。
