# 15 三层格式与跳点格式

**对应书第 4 章 §1.3–1.5（Richardson 格式、Du Fort–Frankel 格式、
三层隐式格式、跳点格式，式 (1.9)–(1.19)、引理 1.1）。**

---

## 15.1 Richardson：二阶精度的死刑与 DFF 的救赎

**Richardson 格式**（书 (1.9)，02 章例 3.4 已判死刑）：时间空间双
中心差分的三层显式格式，O(τ²+h²) 二阶精度——但增长矩阵特征值一支
模恒超 1，**无条件不稳定**。二阶精度救不了稳定性。

1953 年 Du Fort 与 Frankel 的修正（书 (1.10)）：把 Richardson 中的
2u_jⁿ 换成 u_j^{n+1} + u_j^{n−1}：

    (u_j^{n+1} − u_j^{n−1})/2τ =
        a²(u_{j+1}ⁿ − u_j^{n+1} − u_j^{n−1} + u_{j−1}ⁿ)/h²。

仍是显式（u_j^{n+1} 可解出：(1+2r)u^{n+1} = (1−2r)u^{n−1} +
2r(u_{j+1}ⁿ + u_{j−1}ⁿ)）。稳定性证明用**引理 1.1**（实系数二次方程
μ² − bμ + c = 0 两根模 ≤ 1 ⟺ |c| ≤ 1 且 |b| ≤ 1 + c——Miller 引
理）：增长矩阵特征方程满足引理条件，两根 |μ| ≤ 1——**无条件稳定**。

**相容性的陷阱**（书 §1.3 的精彩讨论）：把光滑解代入 DFF，截断误差
主部多出一项 **(τ/h)²·u_tt**。于是：

- τ/h → 0（τ 比 h 更快地趋于零）：DFF 与扩散方程相容 ✓；
- τ/h → β（固定比）：DFF 实际逼近的是**波动型方程**
  u_t = a²u_xx + β²a²u_tt ——与扩散方程不相容！

"无条件稳定的显式格式"是有的（DFF），但"无条件相容 + 无条件稳定
的显式格式"不存在——相容性把代价藏在 τ/h 的趋零速度里。

## 15.2 跳点格式：同一算法的省存省算实现

**跳点**（书 §1.5）：把网格点按 n + j 的奇偶分成两组。每步先在
偶点用显式 FTCS，再在奇点用"隐式"格式——但此时奇点的两个偶邻居
**已经是新值**，隐式方程逐点可解，实质仍显式。

跳点的妙处：把奇点更新式与下一步的偶点更新式联立消元，得到的正是
**Du Fort–Frankel 格式**（书 (1.19) 的推导）——两者完全等价，但跳点
实现**省一半存储**（奇点新值即用即弃）、**省计算**（消元后的偶点
更新比原始 FTCS 更简单）、且**自启动**（不需要额外的起步层格式，
克服了三层格式的通病）。

## 15.3 三层隐式与二层化

三层隐式格式（书 (1.12)(1.13)）如
(3/2)u^{n+1} − 2uⁿ + ½u^{n−1} = rδ²u^{n+1} 型，用引理 1.1 可证无条
件稳定、二阶精度；(1.13) 把 Richardson 理解为 CN 的三层推广。所有
三层格式的分析套路一致：**化为二层方程组 → 增长矩阵 → 引理 1.1 /
第 2 章判别定理**。

## 15.4 机器验证

### DFF：稳定与"错方程"两副面孔

Julia 通道（`examples/julia/15_three_layer.jl`）：

```julia
# 无条件稳定：r = 5（FTCS/Richardson 都死）
u, tf = dff_run(5.0, 0.01, 0.4)
@assert err < 0.01 "DFF r=5 应稳定且收敛"
# 条件相容：固定 τ/h = 0.5（τ 不比 h 快）⟹ 收敛到错误方程的解
errs_beta = beta_errors()
@assert errs_beta[3] > 0.05 "τ/h 固定时 DFF 不收敛到热方程解"
```

三个实验层层递进：①Richardson 在 r = 0.3（远小于 1/2）60 步爆到
10⁶——无条件不稳定复现；②DFF 在 r = 5（任何显式格式的禁区）稳定
且误差 0.0019；③**固定 τ/h = 0.5 加密网格**：h = 0.04/0.02/0.01 的
误差停在 **0.752/0.754/0.754**——加密完全不再减小误差，因为格式
在收敛到 β² 修正的波动型方程而不是热方程。"无条件稳定"的发票由
"条件相容"来付，这是 DFF 的完整故事。

### 跳点 == DFF

同一参数（r = 5, h = 0.01, T = 0.4）分别跑跳点与 DFF，两条轨迹的
最大差异为 **0.0**（逐位一致）——书 (1.19) 的等价性推导在机器上
逐字兑现（Python 通道复现，差异 2.2e−07，起步层的浮点细节）。

Lean 通道（`Ch15ThreeLayer.lean`）证明 DFF 特征值模方的内核：
`|μ±|² 的分子 = (αc)² + (1 − α²s²) = 1 + α²(c² − s²) ≤ (1+α)²`——
`nlinarith` 三行闭核（引理 1.1 的实例化）。

## 15.5 要点回顾

1. Richardson 二阶精度但无条件不稳定；DFF 用 u^{n+1}+u^{n−1} 替换
   2uⁿ 换来无条件稳定，代价是**条件相容**（须 τ/h → 0）。
2. 相容性判据看修正方程：固定 τ/h = β 的 DFF 逼近波动型方程——
   误差停在 0.75 不再下降是它的数值签名。
3. 跳点与 DFF 代数等价但工程优越：省一半存储、省计算、自启动。
4. 三层格式分析协议：二层化 → 增长矩阵 → Miller 引理（引理 1.1）。
