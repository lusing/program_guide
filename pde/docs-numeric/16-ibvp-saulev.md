# 16 初边值问题：边界处理、Saul'ev 算法与分组显式

**对应书第 4 章 §2（第一/第三类边界条件、数值例子、Saul'ev 算法、
分组显式方法，式 (2.1)–(2.20)）。**

---

## 16.1 边界条件的离散

**第一类（Dirichlet）**：直接转移 u_0ⁿ = μ₁(t_n)、u_Jⁿ = μ₂(t_n)
（书 (2.2)）。

**第三类（Robin：∂u/∂x ± αu = μ）**：两种处理（书 (2.5)(2.6)）：

- 单侧差分（一阶精度）：u_1 − u_0 = h(αu_0 + μ)；
- 中心差分（二阶精度）：引入**虚拟点** u_{−1}（或 u_{J+1}），再把
  内点差分格式推到边界、联立消去虚拟点（书 (2.9)(2.10)）——截断
  误差 O(h²)。

边界处理影响**全局**精度：书例 2.2（表 4.2/4.3）用同一 FTCS 内点、
两种边界处理，t = 1.0 时误差 0.014 vs 0.142——差十倍。

## 16.2 Saul'ev 算法：扫描出来的隐式

显式受 r ≤ 1/2 限制、隐式要解方程组。1957 年 Saul'ev 给出**半隐式**
格式（书 §2.5）：把扩散方程在半点 (x_j, t_{n+1/2}) 上考虑，时间导数
用半点值、空间导数一半用 n+1 层一半用 n 层——得到**单边扫描**格式：

    (2.16) 左→右：−r·u_{j−1}^{n+1} + (1+r)u_j^{n+1} = (1−r)u_jⁿ + r·u_{j+1}ⁿ
    (2.17) 右→左：(1+r)u_j^{n+1} − r·u_{j+1}^{n+1} = (1−r)u_jⁿ + r·u_{j−1}ⁿ

每个公式虽然形式隐式，但扫描时左侧邻居已算出——**显式地解隐式**。
单独用 (2.16) 或 (2.17) 是一阶精度；**交替使用**（奇数步右扫、偶数
步左扫）构成 Saul'ev 算法，增长因子

    G = G⁽²⁾·G⁽¹⁾，|G| ≤ 1 恒成立——**无条件稳定**，精度
    O(τ/h + h)（要求 τ < h）。

## 16.3 分组显式（GE）：为并行而生

Saul'ev 的扫描有内在串行性。1983 年 Evans 等基于它构造**分组显式**
（书 §2.6）：在相邻两点 (j, j+1) 上，一点用 (2.16)、另一点用 (2.17)，
两点联立解出 2×2 方程组——闭式 (2.19)(2.20)：

    u_j^{n+1} = [r(1+r)u_{j−1} + (1−r²)u_j + r(1−r)u_{j+1} + r²u_{j+2}]/(1+2r)
    u_{j+1}^{n+1} = [r²u_{j−1} + r(1−r)u_j + (1−r²)u_{j+1} + r(1+r)u_{j+2}]/(1+2r)

各**点对**之间互不依赖——整层可**并行**计算，且完全显式（无方程
组）。剩余单点用 Saul'ev 单点式收尾。

## 16.4 机器验证

### 边界处理阶数

问题 u_t = u_xx、u(x,0) = cos(πx/2)、u_x(0,t) = 0、u(1,t) = 0（精确
解 e^{−π²t/4}cos(πx/2)）。左边界两种处理：一阶直接转移 vs 二阶对称
（消虚拟点）。实测（Julia，`examples/julia/16_saulev.jl`）：

```julia
e40a = neumann_bc_err(40, 1)   # 一阶：un[1] = un[2]（直接转移）
e40b = neumann_bc_err(40, 2)   # 二阶：un[1] = u[1] + r(2u[2] − 2u[1])
@assert e40b < e40a
```

J = 40 时误差 **0.0109 vs 7.9×10⁻⁵**——二阶边界好 **137 倍**。
边界处理是"全局商品"：一个边界点的低阶处理拖累所有内点。

### Saul'ev 与 GE

Saul'ev 在 r = 5（一切显式的禁区）交替扫描，误差 0.00189——无条件
稳定复现（Fortran 通道 `16_saulev.f90` 同判）。GE 在 r = 0.45 误差
1.0×10⁻⁵，全部点对独立可并行。

## 16.5 要点回顾

1. 边界处理三档：直接转移 / 单侧差分（一阶）/ 消虚拟点（二阶）；
   低阶边界全局拖累内点（实测差 137 倍）。
2. Saul'ev：半隐式扫描格式，单边一阶、交替无条件稳定，免解方程组。
3. GE：点对闭式解、层内全并行——1980 年代为并行机设计的经典。
4. 三个"无条件稳定不用解方程组"的方案（DFF/跳点/Saul'ev/GE）各有
   代价：DFF 条件相容，Saul'ev 要 τ < h，GE 要 r ≠ 1/2。
