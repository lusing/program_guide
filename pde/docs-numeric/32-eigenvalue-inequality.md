# 32 特征值问题与变分不等方程

**对应书第 8 章 §3–§4（非线性问题与变分不等方程简介、特征值问题的
变分形式及有限元方法，式 (4.28)–(4.32)）。**

---

## 32.1 特征值问题的变分形式

−(p u′)′ + q u = λ r u（书 (4.28)）的 Galerkin 变分形式是**广义
特征值问题**（书 (4.31)）：

    求 λ_h ∈ ℝ、u_h ≠ 0 使 D(u_h, v) = λ_h·(r u_h, v) ∀v，
    矩阵形式 **K c = λ M c**，

K = [D(φ_i, φ_j)]（刚度）、M = [(r φ_i, φ_j)]（质量/加权）。对
p = q = r = 1、等距 hat 基（书 §4.4 的特殊情形）：

- 一致质量：λ_j^(h) 的显式（书）；节点精度 O(h⁴)（特征函数样条
  超收敛）；
- 质量集中（梯形近似 M，书 (4.32)）：λ_j = (2/h²)(1 − cos jπh)
  ——**恰好是三点差分格式的特征值**（23 章）。

**从上方逼近**：Rayleigh–Ritz（子空间上的 min ≥ 全空间 min）保证
λ₁,h ≥ λ₁ 精确；谱逼近的定量：λ_j,h − λ_j ~ C j⁴h²（书 §4.4 的
比较，π⁴/12 h² 等）。

## 32.2 非线性问题与变分不等方程

书 §8.3 的两个非线性代表：

- **非线性方程**（§3.1）：拟线性扩散/对流——线性化（Richtmyer，
  20 章）或 Newton；
- **变分不等方程**（§3.2）：障碍问题——解不满足方程而满足**不等式
  系统**：

    u ≥ ψ（障碍约束），D(u, v−u) ≥ F(v−u) 对一切 v ≥ ψ。

  互补条件：自由区（u > ψ）内方程成立；接触区（u = ψ）内不等式
  成立。数值解法：**投影 SOR**——Gauss–Seidel 更新后投影回
  [ψ, +∞)。水坝渗流（§3.2.3）是其物理原型。

## 32.3 机器验证

### 广义特征值全谱

−u″ = λu、零边界、hat 基 K c = λ M c（Julia，
`examples/julia/32_eigenvalue.jl`）：

```julia
evs = eigen(Symmetric(K), Symmetric(M)).values
println("N = 32: lam1_h = ", ..., "  lam2_h = ", ..., "  (exact 9.8696, 39.4784)")
@assert evs32[1] > pi^2 "最小特征值从上方逼近（Rayleigh-Ritz）"
```

实测：N = 8/16/32 的 λ₁,h = 9.997 / 9.901 / 9.878（单调下降逼近
π² = 9.8696）；λ₂ 同步逼近 4π²。**质量集中**：λ₁ = 9.8617 与
闭式 (2/h²)(1 − cos πh) 逐位一致——集中质量 = 三点差分（书 (4.32)
的数值版）。Rayleigh 商 R(sin πx) = 9.8775 ≥ π² ✓。

Lean（`Ch32Eigenvalue.lean`）：从上方逼近的**代数核**——给定 cos
的 Taylor 上界 cos x ≤ 1 − x²/2 + x⁴/24，推出
2(1−cos x)/x² ≥ 1 − x²/12（nlinarith）——即 λ₁,h ≥ π²(1−π²h²/12)
的核不等式（分工纪律：cos 的数值界核对在 Julia/Python 通道）。

### 障碍问题

−u″ = 1 于 (0,1)、u ≥ ψ = 0.05 sin 2πx、零边界。投影 SOR 收敛后：

- **接触集**大小 4/63（正弦障碍中段为正，解被顶住）；
- **互补条件**：自由区内 −u″ = 1 的残差 5.1×10⁻⁸ ✓。

坑账：Python 通道的 ψ 曾用错网格的 h（Rayleigh 段的 1/32 而非
1/64），互补条件残差 3.37 暴露——**外层变量泄漏进闭包**是制造
解实验的常见错。

## 32.4 要点回顾

1. 特征值 FEM = 广义特征值 K c = λ M c；从上方逼近（Rayleigh–
   Ritz）；质量集中退化为差分谱。
2. 变分不等方程 = 约束集上的变分问题；互补条件刻画自由/接触区；
   投影 SOR 是标准解法。
3. 实验纪律：闭包引用的网格参数要与求解网格一致（h 泄漏坑）。
