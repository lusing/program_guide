**对应书第 6 章 §1（古典变分问题、变分问题解的必要条件、Rⁿ 中的
变分问题，Euler 方程推导）。**

---

## 24.1 泛函与变分：函数的函数

变分法的对象是**泛函** J: y ↦ J(y) = ∫ₐᵇ F(x, y, y′)dx。三个古典
例子（书 §1.1）：

- **最速降线**（brachistochrone）：J = ∫√((1+y′²)/(2gy))dx——
  质点沿曲线下滑时间；
- **短程线**：J = ∫√(1+y′²)dx——曲线弧长；
- **极小曲面**：J = ∫y√(1+y′²)dx——旋转面面积。

**一阶变分**（书 §1.2 的推导）：对 y + τα（α 为满足端点条件的扰动），
dJ/dτ|₀ = ∫(F_y·α + F_y′·α′)dx = ∫(F_y − d/dx F_y′)·α dx（分部积分
+ 端点项为零）。极值的**必要条件**是变分对一切 α 为零：

> **Euler 方程**：d/dx F_y′ − F_y = 0。

二阶常微分方程。F 不显含 x 时有** Beltrami 恒等式**
F − y′F_y′ = const——降为一阶。

## 24.2 三个经典解

- 最速降线：Euler 方程 + Beltrami 给出**摆线** x = R(θ−sinθ)、
  y = R(1−cosθ)；
- 弧长泛函：Euler 方程给 y″ = 0——**直线**；
- 极小曲面（1D 版）：(y′/√(1+y′²))′ = 0 ⟹ y′ = const——同样直线。

## 24.3 机器验证

### 最速降线：Newton 解参数 + 双重对账

从 (0,0) 到 (1,1) 的摆线参数 θ₁、R 由联立方程定出（Julia，
`examples/julia/24_variational.jl`）：

```julia
function solve_theta1()
    t = 2.0
    for _ in 1:60
        fv = t - sin(t) - (1 - cos(t))
        t -= fv / (1 - cos(t) + sin(t))   # Newton
    end
    t
end
θ1 = solve_theta1()      # 2.412011
R = 1 / (1 - cos(θ1))    # 0.572917
T_bachistochrone = θ1 * sqrt(R / g)   # 0.583193 s
```

下降时间以三种方式对账：闭式 T = θ₁√(R/g) = 0.5832 s；沿摆线的
参数化数值积分 0.5830 s（吻合到 2×10⁻⁴）；**直线**时间 0.6375 s
（慢 9%）——摆线真的更快。

### 极值曲线与 J 最小性

J = ∫(y′² + y²)dx 的 Euler 方程是 y″ = y，端点 y(0)=0、y(1)=1 的
解 y* = sinh(x)/sinh(1)：

- **残差核对**：y* 的中心差分 y″ 与 y* 本身之差 7.8×10⁻⁸；
- **J 对比**：J(y*) = 1.3129 < J(x^0.8) = 1.4483、J(x) = 1.3332、
  J(x^1.3) = 1.3339——极值曲线在参数曲线族中胜出。

### 极小曲面的梯度下降

min ∫√(1+u′²) 的 Euler 方程 (u′/√(1+u′²))′ = 0。离散能量 + 梯度
下降（步长 ∝ h；初值 = 直线 + 正弦扰动）迭代 200000 步后与直线的
最大偏差 **0.0**——收敛到理论解。实验坑账两笔：初版梯度下降把
∂E/∂u_i 的符号写反（能量上升被立即看见）；步长未按 h² 缩放直接
发散——非线性泛函的梯度量级 ~1/h²，步长必须跟着网格走。

Lean（`Ch24Variational.lean`）：**直接法的代数核**——能量展开
恒等式 `(y*′+w′)² + (y*+w)² = (y*′²+y*²) + 2(y*′w′+y*w) + (w′²+w²)`
（ring 一步）+ 交叉项为零时的最小性（`energy_minimality`）。
配 Python 通道独立复现全部数字。

## 24.4 要点回顾

1. 泛函极值 ⟹ Euler 方程 d/dx F_y′ − F_y = 0（分部积分 + 扰动
   任意性）；Beltrami 恒等式是不显含 x 时的首次积分。
2. 最速降线 = 摆线（参数闭式 + Newton 定参数）；弧长/极小曲面的
   1D 版本都退化为直线。
3. 能量的二次结构（直接法）：J(y*+w) − J(y*) = Q(w) ≥ 0——第 27
   章 Ritz 方法与第 28 章有限元的理论底座。
4. 梯度下降的步长要与离散步长同步（~h²）；方向错了能量会上升——
   都是断言一眼能抓的错。
