# 20 非线性抛物方程

**对应书第 4 章 §6（Richtmyer 线性化方法、拟线性扩散方程的隐式
格式、三层格式、预估-校正方法）。**

---

## 20.1 非线性带来的三件事

拟线性扩散方程 u_t = ∂/∂x(k(u)·∂u/∂x)（k 随解变化）给差分求解
带来三个新问题：

1. **隐式格式变成非线性方程组**——每层要解非线性系统（Newton 迭代）
   或线性化；
2. **显式格式的稳定条件随解变化**——冻结在解的最大值上：
   r·max k(u) ≤ 1/2，实际步长受限更狠；
3. **通量形式依旧是对的选择**——守恒性不依赖线性。

## 20.2 两条实用路线

**Richtmyer 线性化**（书 §6.1）：把 k(u) 在**上一层**的值冻结
（k(uⁿ)），非线性隐式系统退化为线性三对角——每层一次追赶。精度：
空间二阶、时间一阶（线性化的滞后 O(τ)）。若要更高阶可做线性化
迭代（本层内 Picard/Newton 几步）。

**预估-校正**（书 §6.4）：显式预估（FTCS 型，k 在旧层）得到 ũ，
再用 ũ 重算系数做校正（中点时刻）——组合后二阶精度，全部显式，
稳定域受限。

## 20.3 机器验证

制造解基准：k(u) = 1 + u²，u* = e^{−t}sin(πx)，源项 f = u*_t −
(k(u*)u*_x)_x 解析给出（Julia，`examples/julia/20_nonlinear.jl`）：

```julia
function fsource(x, t)
    ut = -exp(-t) * sin(pi * x)
    ux = exp(-t) * pi * cos(pi * x)
    kus = 1 + ustar(x, t)^2
    dkus = 2 * ustar(x, t) * ux
    ut - (dkus * ux + kus * (-exp(-t) * pi^2 * sin(pi * x)))
end
```

**线性化半隐式**（r = 0.4）：加密比 **3.269**——空间二阶主导
（时间一阶项被小 τ 压低，比值略低于 4 是时间项的痕迹）。

**预估-校正**：加密比 **4.022**——二阶兑现。实验自纠一笔：初版
取 r = 0.4 时显式预估步在 n = 50 步爆掉（NaN 追踪定位到 j = 6 的
通量 3.5×10⁶）——**非线性问题的等效网格比是 r·k(u)，k = 1+u² ≥ 1
把稳定裕度吃掉了**；降到 r = 0.05（等效比 ≤ 0.1）后干净收敛。
这正是 20.1 节"稳定条件随解变化"的数值现身说法。

Python 通道逐位复现（3.269 / 4.022）。

## 20.4 要点回顾

1. 非线性隐式 ⟹ 每层线性化（Richtmyer：旧层冻结 k，三对角追赶）。
2. 预估-校正全显式二阶，但稳定域按 max k(u) 缩水——显式步长要给
   非线性系数留裕量。
3. 制造解 + 解析源项是非线性格式的对账基准（解在两个通道间逐位
   一致才是真收敛）。
