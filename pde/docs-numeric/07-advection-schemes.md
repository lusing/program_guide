# 07 一阶常系数双曲方程：迎风、Lax–Friedrichs 与 Lax–Wendroff

**对应书第 3 章 §1.1–1.3（迎风格式、Lax–Friedrichs 格式、Lax–Wendroff
格式）与 §1.5 的特征线插值构造。**

---

## 7.1 三个经典格式

对流方程 u_t + a u_x = 0（a > 0，网格比 λ = aτ/h）的三个两层显式
格式在 03 章已经构造过迎风；本章补齐全家福：

**迎风格式（FTBS，书 (1.4)）**——空间后差：

    u_j^{n+1} = u_jⁿ − λ(u_jⁿ − u_{j−1}ⁿ)。

增长因子 |G|² = 1 − 4λ(1−λ)sin²(θ/2)，稳定条件 **0 ≤ λ ≤ 1**；
一阶精度；λ ≤ 1 时**保单调**（不产生新的极值）。

**Lax–Friedrichs 格式（LF，书 (1.8)）**——用邻点平均代替 u_jⁿ：

    u_j^{n+1} = ½(u_{j+1}ⁿ + u_{j−1}ⁿ) − (λ/2)(u_{j+1}ⁿ − u_{j−1}ⁿ)。

G = cosθ − iλsinθ，|G|² = 1 − (1−λ²)sin²θ，稳定条件 **λ ≤ 1**；
一阶精度；保单调；**耗散严重**（后面实测）。

**Lax–Wendroff 格式（LW，书 (1.14)）**——用方程本身消去 u_tt：
u_t = −a u_x ⟹ u_tt = a²u_xx，于是

    u(x,t+τ) = u + τu_t + (τ²/2)u_tt + O(τ³)
             = u − aτu_x + (a²τ²/2)u_xx + …，

把三个导数都用中心差分离散：

    u_j^{n+1} = u_jⁿ − (λ/2)(u_{j+1}ⁿ − u_{j−1}ⁿ)
                + (λ²/2)(u_{j+1}ⁿ − 2u_jⁿ + u_{j−1}ⁿ)。

G = 1 − 2λ²sin²(θ/2) − iλsinθ，|G|² = 1 − 4λ²(1−λ²)sin⁴(θ/2)，
稳定条件 **|λ| ≤ 1**；**二阶精度**；不保单调（间断附近振荡）。

## 7.2 特征线插值：一个构造出三个格式

书 §1.5 给出漂亮的统一视角。设 a > 0、CFL 成立，过 P = (x_j, t_{n+1})
的特征线与 t_n 层交于 Q（落在网格点 B、C 之间）。解沿特征线为常数：
u(P) = u(Q)。Q 不是网格点，用 t_n 层的已知值**插值** u(Q)：

- 用 B、C **线性**插值 → **迎风格式**；
- 用 B、D（跨两点）线性插值 → **Lax–Friedrichs 格式**；
- 用 B、C、D **抛物**插值 → **Lax–Wendroff 格式**；
- 再往左取一点用左侧三点抛物插值 → **Beam–Warming 二阶迎风**
  （书 (1.16)，稳定域放宽到 **λ ≤ 2**）。

插值多项式的次数 = 格式的精度阶：线性给一阶、抛物给二阶。这个视角
把"格式 = 特征线上的插值"一句话讲透。

## 7.3 耗散与色散：格式的两种性格

数值格式的误差以两种面貌出现：**耗散**（振幅衰减，把解抹平）与
**色散**（不同波数相速不同，波形错位、振荡）。对单波 u = sin(kx)
的传播：

- LF/迎风（一阶）：|G| = 1 − O(θ²)——**二阶耗散**，波幅稳定衰减；
- LW（二阶）：|G| = 1 − O(θ⁴)——**四阶耗散**，波幅几乎不衰；但相位
  误差 O(θ³) 在间断处堆积成振荡。

## 7.4 机器验证

### 书 §1.7 数值例子的数字版（图 3.7）

四格式推进同一方波脉冲（h = 0.005，λ = 0.8，T = 0.5，周期域）。
Julia（`examples/julia/07_advection.jl`）：

```julia
for scheme in (:upwind, :lf, :lw, :bw)
    u = run_scheme(scheme, gwave, lam, h, T)
    println("  ", rpad(string(scheme), 8), " min = ", round(minimum(u), digits=4),
            "  max = ", round(maximum(u), digits=4))
end
```

实测：

| 格式 | min(u) | 性格 |
|---|---|---|
| 迎风 | 0.000 | 单调、抹平（过渡带宽 0.12） |
| LF | 0.000 | 单调、抹得更平（0.18） |
| LW | **−0.174** | 振荡（波前波后下冲/上冲） |
| BW | **−0.246** | 振荡（更窄但更深） |

断言：单调格式的 min ≥ 0、二阶格式的 min < −0.05——书图 3.7 的
"前两个抹平、后两个振荡"逐字复现。过渡带宽度 LF > 迎风 > LW
（0.18 / 0.12 / 0.06）量化了耗散排序。

### 单波传播的振幅与相位

对 k = 8 的单波（λ = 0.8，T = 0.5）用离散 Fourier 系数分离振幅与
相位（代码见 `07_advection.jl` 第 (2) 节），实测振幅：

| 格式 | 振幅（精确 1.0） |
|---|---|
| 迎风 | 0.610 |
| LF | **0.332** |
| LW | **0.993** |
| BW | 0.999 |

LF 把波幅衰减到三分之一（二阶耗散的代价），LW/BW 几乎无耗散
（四阶）。相位滞后上 LF 最差（0.0023 个空间单位）。

### Beam–Warming 的宽稳定域

|G|² = 1 − 4λ(1−λ)²(2−λ)sin⁴(θ/2) 在 λ ∈ [0,2] 上非负。数值确认：
λ = 0.8/1.5/1.9 推进单波有界；λ = 2.2 时方波数据在充分积分后
max|u| = 1.6×10⁶——**二阶迎风的稳定域放宽到 CFL 数 2**，固定 h 时
时间步长限制更宽（书 §1.5 末的实践意义）。

Prolog 通道（`07_advection.pl`）把四格式的增长因子做成复数规则
（BW 的 G 由 e^{−iθ}、e^{−2iθ} 的闭式还原），15 点 θ 网格扫描的
裁决与 Julia 一致：upwind/lf/lw 在 μ ≤ 1 稳、bw 到 μ = 2；特征线
插值构造规则（interpolate([b,c], upwind) 等）与性格表（一阶单调/
二阶振荡、lf 耗散 heavy/lw light）存为可查询事实。

## 7.5 Lean：LW 恒等式

Lean 通道（`examples/lean/Pdenum/Ch07Advection.lean`）：

```lean
/-- Lax–Wendroff 增长因子的模方恒等式：
`(1 − μ²(1−C))² + (μS)² = 1 − μ²(1−μ²)(1−C)²`，其中 `C² + S² = 1`。 -/
theorem lw_G_sq_identity (μ C S : ℝ) (h : C * C + S * S = 1) :
    (1 - μ ^ 2 * (1 - C)) ^ 2 + (μ * S) ^ 2
      = 1 - μ ^ 2 * (1 - μ ^ 2) * (1 - C) ^ 2 := by
  linear_combination μ ^ 2 * h
```

两式之差恰为 μ²·(C²+S²−1)——`linear_combination` 一步闭核（第一版
手推乘数写错被 `ring` 当场驳回，改为展开核对后通过——恒等式自动
化既省力又挑错）。稳定方向 `lw_stable`（μ ∈ [0,1] ⟹ |G|² ≤ 1）
用三个 `mul_nonneg` 拼出耗散项非负。

Fortran 通道（`07_lax_wendroff.f90`）实现 LW 经典内核：方波推进
（min = −0.19 振荡 ✓）与光滑波二阶收敛（h → h/2 误差比 4.000）。

## 7.6 要点回顾

1. 三格式三性格：迎风（一阶/单调/中等耗散）、LF（一阶/单调/耗散
   重）、LW（二阶/振荡/耗散轻）；来源都是 Taylor 展开或特征线插值。
2. 特征线插值统一视角：线性插两点给一阶格式、抛物插三点给二阶
   格式；插值节点选在特征线足点附近。
3. 耗散看 |G| 对 θ 的阶（二阶 vs 四阶），色散看相位误差；间断解
   上二阶格式的振荡是色散的直接表现（消振是守恒律章节的主题）。
4. Beam–Warming 二阶迎风：稳定域 λ ≤ 2，时间步长可以放宽一倍。
5. Julia 笔误警示：括号嵌套 `u[jm(j))]` 类错误在长公式里高频出现，
   机器一秒抓出。
