# 25 两点边值问题的变分形式

**对应书第 6 章 §2（两点边值问题的变分形式、非齐次约束边界条件的
处理、第二/三类边界条件，Galerkin 变分问题 P₂ 与 Ritz 变分问题 P₃）。**

---

## 25.1 从边值问题到变分问题

考虑两点边值问题（书 §2.1 的模型）

    −(p u′)′ + q u = f 于 (0,1)，u(0) = u(1) = 0。

**分部积分**把二阶导数降到一阶：对任意满足零端点的试验函数 v，

    ∫(p u′v′ + q u v)dx = ∫ f v dx。

定义双线性型与线性泛函

    D(u, v) = ∫(p u′v′ + q u v)dx，F(v) = ∫ f v dx，

得到两个等价的变分问题（书 (P₂)(P₃)）：

- **Galerkin 变分问题**：求 u ∈ S（零端点函数集），使
  D(u, v) = F(v) 对一切 v ∈ S（虚功原理）；
- **Ritz 变分问题**：求 u ∈ S 使 J(u) = ½D(u,u) − F(u) 最小
  （最小势能原理）。

D 对称正定时两者等价（24 章的直接法）。**变分形式"吸收"了边界
条件的导数部分**——只有本质（Dirichlet）条件需要显式强加，自然
（Neumann/Robin）条件自动满足。

## 25.2 非齐次与自然边界

- **非齐次 Dirichlet**：u|∂ = g ⟹ 提升技巧 u = u₀ + w（u₀ 延拓 g，
  w 零边界），变分作用于 w（26 章）。
- **第三类边界** u′(1) = αu(1) + μ：分部积分产生的端点项
  [p u′ v]₀¹ 恰好把边界条件吸收进 D——
  D(u,v) 加上 p(1)αu(1)v(1) 项，F(v) 加上 p(1)μv(1)。

## 25.3 机器验证

### hat 基函数的 D 与 F

D(hat_i, hat_j) 只有 |i−j| ≤ 1 非零。闭式（∫hat′² = 2/h、
∫hat² = 2h/3、交叉 ∫hat_i′hat_j′ = −1/h、∫hat_i hat_j = h/6）：

    D(hat_i, hat_i) = 2/h + 2h/3，D(hat_i, hat_{i±1}) = −1/h + h/6。

Julia（`examples/julia/25_twopoint.jl`）数值积分对账：

```julia
println("D(hat_4, hat_4) = ", round(d_ii, digits=6), "  closed form 2/h + 2h/3 = ", ...)
println("D(hat_4, hat_5) = ", round(d_ij, digits=6), "  closed form -1/h + h/6 = ", ...)
@assert abs(d_ii - (2 / h + 2h / 3)) < 1e-9
```

实测 D(hat_4, hat_4) = 16.083333 = 闭式**逐位一致**。坑账一笔：对角
元初版 Simpson 在 hat′ 的**支撑端点**取到外侧值 0（被积函数在此跳
变），损失两个端点格子——把端点判定改成严格不等号（端点取内侧值）
后精确。这正是分段多项式上数值积分的经典陷阱。

### 正定性 + Ritz 解 + 能量最优

组装 (N−1)×(N−1) 刚度矩阵 A：最小特征值 1.389 > 0（对称正定）。
解 Ac = b 得 hat 基 Ritz 解：对 sin(πx) 的最大误差 0.052（N=8 粗网
格的 O(h²) 量级）。**能量最优性**：energy(ritz) = 5.181 ≤
energy(节点插值) = 5.556——Ritz 解在能量范数下击败同子空间的任何
其他函数（24 章定理的数值版）。

Python 通道独立复现全部数字（16.083333 / −7.9525 / 1.3890 / 0.05191 /
5.181069 ≤ 5.556117）。

## 25.4 要点回顾

1. 分部积分 + 试验函数任意性 ⟹ Galerkin 变分形式；对称正定时与
   Ritz 最小化等价。
2. 变分形式吸收自然边界条件；本质条件要显式强加（或提升）。
3. hat 基的 D 闭式三件套：2/h + 2h/3（对角）、−1/h + h/6（次对
   角）——第 28 章有限元装配的全部原料。
4. 分段多项式上的数值积分：跳变端点须取单侧值，否则损失端点
   格子精度。
