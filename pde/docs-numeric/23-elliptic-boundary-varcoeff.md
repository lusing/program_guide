# 23 边界处理、变系数、双调和与特征值

**对应书第 5 章 §3–§6（边界条件的处理、变系数方程、双调和方程、
特征值问题，式 (3.1)–(3.4)、(4.1)–(4.5)、(5.1)–(5.7)）。**

---

## 23.1 一般区域的边界处理

矩形区域外的区域（曲线边界）上网格点不会全落在边界上，边界条件要
**转换**到边界节点（书 §3.2）：

- **直接转移**：边界节点 P 取最近边界点 T 的值 u_P = α(T)——一阶；
- **线性插值**：用 P 与内点 Q 对边界点 T 线性插值——二阶。
- 第三类边界：法向不与坐标轴平行时 ∂u/∂n = cos(n,x)∂u/∂x +
  cos(n,y)∂u/∂y 分量差分；P 不在边界上时沿外法线多点组合。

数值上（Julia 通道的圆盘 Poisson：Δu = −4、u|∂ = 0、精确解
1 − r²），插值型边界（Shortley–Weller 式：法向距离加权）误差
9.7×10⁻²——由边界处理的 O(h) 主导（内部区域比较远离边界处更准）。
这类边界处理在第 29 章有限元对复杂几何的优势对照中还会回来。

## 23.2 变系数椭圆方程

散度型 −∂x(a ∂x u) − ∂y(b ∂y u) + cu = f（书 (4.1)，a,b,c > 0）。
**直接差分**（(4.3)）与**有限体积**（(4.5)：控制体积分 + 中梯形）
给出同一格式——界面系数 a_{i±1/2} 在半点取值，正是 18 章（抛物变系
数）的通量形式在椭圆上的翻版。间断系数时 FV 的调和平均界面依旧
是对的取法。

## 23.3 双调和方程

Δ²u = f（书 (5.1)）直接离散为 **13 点格式**（(5.5)）：

    20u₀ − 8(四邻) + 2(对角四点) + (相距 2 的四点) = h⁴f。

相距 2 的点会越出边界，用两个边界条件（u 与 ∂u/∂n）的离散消去虚
拟点（书 (5.6)(5.7)）。系数核对：对 u = x⁴（Δ²u = 0）代入 13 点模
板，残差 ~O(h⁶)（与理论一致：13 点对四次多项式精确）。

## 23.4 特征值问题

−Δu = λu 的五点离散化是**矩阵特征值问题** A u = λ_h h²·? u，特征
值有 22 章的闭式。最小特征值收敛性：

    λ_min,h / h² = 4−4cos(π/N)·N² → **2π²** = 19.7392…

（单位正方形上 −Δ 的最小特征值，模式 sin πx·sin πy）。实测
N = 8/16/32 给 19.4868 / 19.6759 / 19.7234——单调逼近 2π²。坑账：
初版断言写成收敛到 π²（一维的记忆串台），被数字抓出——**二维方域
最小特征值是 2π²**。

变系数制造解对账（k = 1 + x + y 的通量格式 + 闭式源项）：
h → h/2 误差比 **4.000**——通量形式在椭圆变系数下保持二阶。
（坑账两笔：源项漏乘 k 因子；误差对账数组下标差一格造成假性一阶
——都与断言正面相撞后修正。）

## 23.5 要点回顾

1. 曲线边界：直接转移一阶 / 线性插值二阶；第三类边界注意法向分量。
2. 变系数椭圆：通量形式（界面半点系数）与 18 章同构；FV 对间断
   系数用调和平均。
3. 双调和 13 点格式：直接对 Δ² 双重离散，越界点用两组边界条件消去。
4. 特征值问题的五点离散化有闭式谱；λ_min → 2π²（方域）。
5. 差一格的下标错是"假性一阶"的最常见来源；制造解的源项要乘上
   系数函数本身。
