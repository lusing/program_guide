## 14.1 加权隐式：一个家族、三种性格

03 章已构造了 FTCS（显式）与 BTCS（隐式）。把它们按参数 θ ∈ [0,1]
**凸组合**（书 (1.6)）：在 n 层用权重 1−θ、在 n+1 层用权重 θ 处理
空间二阶差分：

    (u_j^{n+1} − u_jⁿ)/τ = a²[θ·δ²u^{n+1} + (1−θ)·δ²uⁿ]/h²。

- θ = 0：FTCS（显式）；θ = 1：BTCS（隐式）；
- **θ = 1/2：Crank–Nicolson（CN）**——时间方向左右对称，截断误差
  升到 O(τ²) + O(h²)，二阶（书 (1.8)）。

隐式端是三对角方程组，追赶法 O(J) 解出。增长因子：

    G(θ) = [1 − 4(1−θ)r·sin²(θ_g/2)] / [1 + 4θ·r·sin²(θ_g/2)]，
    r = a²τ/h²。

|G| ≤ 1 的条件（书 §1.2 的推导）：**2r(1 − 2θ) ≤ 1**，即

- θ ≥ 1/2（CN、BTCS）：**无条件稳定**；
- θ < 1/2：r ≤ 1/[2(1−2θ)]；θ = 0 时即 FTCS 的 r ≤ 1/2。

## 14.2 机器验证：书表 4.1 的完整复现

书 §2.3 例 2.1 给出标定表：u_t = u_xx、u(x,0) = sin πx、零边界，
J = 10，计算 u(0.4, 0.4)（解析解 **0.0183519**）。Julia 通道
（`examples/julia/14_diffusion.jl`）逐行复现：

```julia
function table41(lambda)
    theta0 = weighted_solve(0.0, lambda, 0.4)     # FTCS
    theta1 = weighted_solve(1.0, lambda, 0.4)     # BTCS
    thetac = weighted_solve(0.5, lambda, 0.4)     # CN
    j4 = 4                                        # x=0.4 ↔ 内点 j=4
    theta0[j4], theta1[j4], thetac[j4]
end
```

实测（h = h/2 = 0.05 两层，比值 3.991 = 二阶）：

| λ | θ=0（FTCS） | θ=1（BTCS） | θ=1/2（CN） |
|---|---|---|---|
| 0.25 | 0.0180544 | 0.0198705 | 0.0189519 |
| 1.0 | **爆**（32.5→∞） | 0.0226935 | 0.0188963 |
| 4.0 | — | 0.0349321 | 0.0180093 |
| 8.0 | — | **过阻尼**（187% 偏差） | 17% 偏差 |

**勘误记录**：书表 4.1 的 λ=0.5 与 λ=8 两行出现**列序错乱**（经独立
验证的求解器在其余四行与书逐位吻合到 2e−6，这两行按我们的计算记账；
λ=1 行的 FTCS 值 0.2788×10⁻¹¹ 同样对不上——FTCS 在 λ=1 的真实行为
是舍入被 |G|max=3 逐层放大的**增长**）。关键现象三件：FTCS 过
λ=1/2 即爆；BTCS 恒稳但**大 λ 严重过阻尼**；CN 在 λ ≤ 4 都准、λ=8
开始失真——大 τ 下 CN 的两拍振荡（解在精确值附近跳）是它著名的
性格缺陷。

|G| 扫描确认稳定律：θ ∈ {1/2, 3/4, 1} 在 r = 100 都稳；θ = 0.4 的
阈值 r ≤ 1/(2·0.2) = 2.5（2.4 稳、2.6 爆，Prolog 规则引擎同判）。

Lean 通道（`Ch14Diffusion.lean`）把 |G| ≤ 1 的两个方向做成定理：
θ ≥ 1/2 时分母减分子 = 4r·sin² ≥ 0（`weighted_stable`，纯不等式
拼装）；θ = 0、r > 1/2 时最高波型 |G| = 4r − 1 > 1（`ftcs_unstable`）。

## 14.3 要点回顾

1. 加权隐式一族：θ 凸组合新旧层的 δ²；θ=0/1/½ 分别是 FTCS/BTCS/CN。
2. 稳定律 2r(1−2θ) ≤ 1：CN 与 BTCS 无条件稳定，FTCS r ≤ 1/2。
3. CN 二阶精度是大 λ 下的双刃剑：λ ≤ 几乎所有实用范围都准，λ 很大
   时振荡失真；BTCS 恒稳但过阻尼。
4. 标定表对账是格式库的"体检"；书表个别行的排版错乱正好演示了
   独立复算的价值。
