## 0.1 为什么要求解偏微分方程

科学与工程计算的绝大部分，最终都落在同一类对象上：**偏微分方程**
（PDE）。原书引论给了三个分量很重的例子：

- **数值核试验**。核反应与核爆炸在高温高压、极短时标下进行，仪器
  根本测不到装置内部物理量的细致变化，描述全过程的数学模型是复杂
  的非线性偏微分方程组，理论上也没有精确解——只能数值模拟。原书
  引用的一组数字很说明问题：我国从研制到与美、苏基本抗衡的水平只
  进行了 338 次核试验，而美、苏分别进行了 936 次和 716 次——数值
  模拟替代了大量实爆试验。
- **数值风洞**。飞行器设计传统上依赖昂贵的风洞实验；20 世纪 90 年代
  初出现的当时最快计算机直接被命名为"数值风洞"，用于航天飞机返回
  计算。数值模拟使新型号飞机设计减少了三分之一以上的风洞实验。
- **战争决策**。海湾战争中，决策者担心数百口油井被点燃会引发全球
  气候灾难；科学家用与 Navier–Stokes 方程组有关的模型做了一系列
  模拟试验，结论是灾难是局部性的。事实证明了模拟的结论。

于是"科学计算"被视为与理论、实验并列的**第三种科学方法**。

更有意思的是一个量化观察：**人类的计算能力正比于计算工具效率与
计算方法效率的乘积**。从 20 世纪 50 年代初到 90 年代中期，计算机
速度提高约一亿倍（10⁸）；同期求解椭圆型偏微分方程的算法速度提高
了约一万亿倍（10¹²）。算法的进步比硬件更陡。本教程要学的正是
"算法效率"这一侧的根基：有限差分方法与有限元方法。

## 0.2 两类方法，两种性格

原书前言明确了选材的侧重，这一定位贯穿本教程：

- **有限差分方法**：把连续问题直接搬到网格上，用差商代替微商。
  它构造直接、分析工具初等，传统上**主攻依赖时间的发展方程**
  （双曲型、抛物型）——本教程第 03–20 章的主体。
- **有限元方法**：从变分原理出发，把问题化为子空间上的极小化或
  弱形式，再在分片多项式空间上离散。它对复杂几何与非光滑系数
  有天然优势，传统上**主攻定态问题**（椭圆型）——本教程第 24–33
  章的主体。第 21–23 章先讲椭圆方程的差分方法作对照。

两类方法会在两处交汇：基于变分原理构造的差分格式（第 31 章），
以及发展方程的有限元半离散（第 31 章）。全书最后（第 34 章）给
出一张方法选择地图。

## 0.3 模型问题与"对表"文化

全书反复使用的模型方程有四个：

    对流方程        u_t + a u_x = 0          （双曲，解沿特征线平移）
    扩散方程        u_t = a u_xx             （抛物，解即时变光滑）
    波动方程        u_tt = a² u_xx           （双曲，解保持波形传播）
    Laplace 方程    u_xx + u_yy = 0          （椭圆，定常，边界决定内部）

数值方法的正确性讨论永远从"精确解已知"的例子开始——本教程称之为
**对表**（calibration）：拿一个已知精确解，检验我们的数值工具
（差商、迭代法、装配器）是否以宣称的精度工作。第一章的机器验证
就做对表，先把"尺子"校准，后面量什么才可信。

三个对表函数：

    u(x,t) = e^{-π²t} sin(πx)      满足 u_t = u_xx（第一模式衰减）
    u(x,t) = sin(πx) cos(πt)       满足 u_tt = u_xx（驻波）
    u(x,y) = e^x sin y             调和函数（满足 Laplace 方程）

## 0.4 机器验证：差商的阶与方法的威力

### 残差按 4 倍收缩

中心差分近似二阶导数的误差是 O(h²)：步长减半，误差应除以 4。
Julia 通道（`examples/julia/00_intro.jl`）用 Simpson 积分底座逐项
检验：

```julia
u_heat(x, t) = exp(-pi^2 * t) * sin(pi * x)   # u_t = u_xx
u_wave(x, t) = sin(pi * x) * cos(pi * t)      # u_tt = u_xx（可分离模式解）
u_gen(x, t) = exp(x + t) + (x - t)^3          # u_tt = u_xx（一般 d'Alembert 解）
u_lap(x, y) = exp(x) * sin(y)                 # u_xx + u_yy = 0

# 热传导残差：中心差分 u_t - u_xx，误差主项 O(h^2)
resid_heat(h) = begin
    x, t = 0.5, 0.05
    dut = (u_heat(x, t + h) - u_heat(x, t - h)) / (2h)
    duxx = (u_heat(x + h, t) - 2 * u_heat(x, t) + u_heat(x - h, t)) / h^2
    abs(dut - duxx)
end
```

对热传导、波动、Laplace 三个方程分别测残差收缩比，全部落在
3.5–4.5 之间（实测 4.141 / 4.001 / 4.0）——**二阶差分算子的
对表通过**。Python 通道（`examples/python/00_intro.py`）是同一实验
的独立第二实现，数字逐位吻合。

### 一个意外的恒等相消

波动方程的实验里藏着一个漂亮的细节。对可分离模式解
u = sin(πx)·cos(πt)，取**时间步与空间步相等**（τ = h）时，中心差分
残差**恒等于零**：

```julia
# 波动残差（τ = h 时可分离解上恒等相消——机器上只能看到舍入噪声）
resid_wave_canceled(h) = begin
    x, t = 0.3, 0.1
    dutt = (u_wave(x, t + h) - 2 * u_wave(x, t) + u_wave(x, t - h)) / h^2
    duxx = (u_wave(x + h, t) - 2 * u_wave(x, t) + u_wave(x, t - h)) / h^2
    abs(dutt - duxx)
end

for h in (1.0e-1, 5.0e-2)
    @assert resid_wave_canceled(h) < 1.0e-9 "tau = h 时可分离解残差应恒为零"
end
```

原因：sin(π(x±h)) = sin(πx)cos(πh) ± cos(πx)sin(πh)，cos(π(t±h))
同理——两个方向上的三点公式给出**完全相同**的二阶差分系数
(2cos(πh) − 2)/h²，残差逐项相消。这不是数值巧合，是三角恒等式。
于是测阶实验换用一般 d'Alembert 解 u = e^{x+t} + (x−t)³ 并取
τ = h/2 打破对称，误差主项 (τ² − h²)/12·(F⁗ + G⁗) 就显出来了。

### 多项式上的精确性

五点 Laplace 算子作用在二次多项式 x² − y² 上**精确为零**（不是
近似为零）：

```julia
x, y, h = 0.3, 0.7, 0.1
u2(s, t) = s^2 - t^2
lap5 = (u2(x + h, y) + u2(x - h, y) + u2(x, y + h) + u2(x, y - h) - 4 * u2(x, y)) / h^2
@assert abs(lap5) < 1.0e-13 "x^2 - y^2 上五点 Laplacian 应精确为零"
```

二阶中心差分对次数 ≤ 3 的多项式精确（第 03 章会证明这一点）。
选对表函数时必须知道工具的"精确类"，否则会把恒等误当收敛。

### 方法效率的具体而微

引论里"算法效率提升 10¹²"的说法，可以在 20×20 的网格上具体感受。
同一个五点 Laplace 方程（第 21 章的主角），三种经典迭代法求解到
1e−8 的停机标准：

```julia
# SOR（最优 omega = 2 / (1 + sin(pi*hh))）
omega = 2.0 / (1.0 + sin(pi * hh))
cnt_s = 0
us = copy(u)
while cnt_s < maxit
    diff = 0.0
    for j in 2:N+1, i in 2:N+1
        gs = 0.25 * (us[i+1, j] + us[i-1, j] + us[i, j+1] + us[i, j-1])
        newv = us[i, j] + omega * (gs - us[i, j])
        diff = max(diff, abs(newv - us[i, j]))
        us[i, j] = newv
    end
    cnt_s += 1
    diff < tol && break
end
```

实测迭代次数：**Jacobi 1263 次，Gauss–Seidel 668 次，SOR 84 次**。
只是把迭代公式改写了一下（Gauss–Seidel 用当天的新值；SOR 再加一个
按理论选取的松弛因子 ω = 2/(1+sin πh)），同样精度下工作量差 15
倍。这就是"算法效率"的微观样品；多重网格方法（第 33 章）还会再
拉开一个数量级。

## 0.7 要点回顾

1. 科学计算是第三种科学方法；计算能力 = 工具效率 × 方法效率，
   算法侧的进步（10¹²）比硬件（10⁸）更陡。
2. 差分法主攻发展方程，有限元主攻定态问题——本教程按此分篇。
3. 数值正确性讨论从"对表"开始：已知精确解 + 已知精度阶的工具；
   对表函数要选在工具的"非精确类"上，否则恒等会被误读为收敛。
4. 同一问题换算法可差一个数量级以上（Jacobi 1263 → SOR 84），
   "选对方法"本身就是数值分析的主题。
