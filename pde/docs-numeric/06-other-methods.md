## 6.1 Hirt 启示性方法：问格式的"第一微分近似"

Fourier 方法要求常系数。对**变系数与非线性**问题，Hirt 给出一个
近似判别：把差分格式在定点作 Taylor 展开，**只留最低阶误差项**，
得到一个带小参数高阶项的"修正微分方程"（第一微分近似）：

> 若第一微分近似适定，则格式稳定；不适定则不稳定。

判例一：迎风格式（1.9）（设 a > 0）。在 (x_j, t_n) 展开，利用对流
方程本身消项，保留最低阶（书 §4.1）：

    u_t + a·u_x = (a/2)(h − aτ)·u_xx = (ah/2)(1 − λ)·u_xx。

这是一个**扩散系数 ν = (ah/2)(1−λ)** 的抛物方程。适定（耗散）要求
ν ≥ 0，即 **aλ ≤ 1**——与 Fourier 方法的结论一致。

判例二：顺风格式（1.7）（a > 0）。同法得第一微分近似的 u_xx 系数
为 **−(a/2)(h + aτ) < 0**——负扩散（反扩散、增长），不适定，故
不稳定——同样与第 05 章判例吻合。

Hirt 方法是**启发式**的（"启示性"三字名副其实）：它没有严格证明，
但对非线性问题往往能给出近似稳定性条件，是 Fourier 方法够不着
处的重要探针。

机器验证（Julia，`examples/julia/06_other_methods.jl`）做的是
"修正方程定量对账"：迎风格式（λ = 0.8, h = 0.01）演化波数为
k = 10π 的单波，波幅衰减应遵循修正方程的预测 exp(−νk²t)：

```julia
nu = (a * h / 2) * (1 - lam)
pred = exp(-nu * kmode^2 * Tend)
rel = abs(amp - pred) / pred
@assert rel < 5.0e-3 "修正方程预测应匹配数值衰减"
```

实测数值波幅 0.903125 vs 预测 0.906018，相对差 3.2×10⁻³——正是
修正方程舍掉的高阶项 O(h²) 的量级。反向实验：同样的波在 FTFS
（负扩散）演化同样时间后波幅 2.21——增长。**修正方程不只是启
示，它定量预言耗散率。**

## 6.2 矩阵法：初边值问题的特征值账本

Fourier 方法面向初值问题（周期化）；**初边值问题**的差分格式在
有限内点上是矩阵迭代 uⁿ⁺¹ = A uⁿ，稳定性 ⟺ ‖Aⁿ‖ ≤ K（2 范数，
书 (4.14)）。结论与 Fourier 方法平行：

- ρ(A) ≤ 1 + Mτ 是必要条件（(4.15)）；
- **A 对称（正规）时充要**——A 对称时 ‖Aⁿ‖ = ρ(A)ⁿ。

FTCS 热传导（第一边界条件，内点 J−1 个）的增长矩阵（书 (4.10)）：

    A = (1−2r)I + rS，   S = tridiag(1, 0, 1)。

求 S 的特征值是经典的特征值问题解法：分量形式是常系数差分方程
w_{j−1} + w_{j+1} = γw_j，设 w_j = μ^j 得 μ + μ⁻¹ = γ，|γ| ≤ 2
（Gerschgorin），故 μ = e^{±iφ}，解 w_j = α₁e^{ijφ} + α₂e^{−ijφ}；
边界条件 w₀ = w_J = 0 逼出 sin(Jφ) = 0 即 **φ = kπ/J**，于是

    γ_k(S) = 2cos(kπ/J)，  λ_k(A) = 1 − 2r + 2r·cos(kπh)
           = 1 − 4r·sin²(kπh/2)，   k = 1..J−1（h = 1/J）。

——**与 Fourier 方法的增长因子同一个公式**（这正是第 03 章模板
恒等式的必然结果：两种方法都在数 sin 波型的特征值）。稳定 ⟺
|λ_k| ≤ 1 ⟺ **r ≤ 1/2**。BTCS 的矩阵 B = (1+2r)I − rS 特征值
1 + 4r·sin² ≥ 1，B⁻¹ 对称、ρ(B⁻¹) < 1——**无条件稳定**。

矩阵法的限制也很清楚：一般高阶矩阵的特征值求不出来，能算清楚的
全靠 S 这种特殊结构。数值上可以把闭式与直接求特征值对账：

```julia
for r in (0.25, 0.49, 0.51, 5.0)
    A = SymTridiagonal(fill(1 - 2r, Jm1), fill(r, Jm1 - 1))
    ev = Vector(eigvals(A))
    theory = sort([1 - 4 * r * sin(k * pi * hh / 2)^2 for k in 1:Jm1])
    @assert maximum(abs.(ev .- theory)) < 1.0e-9
end
```

39 阶矩阵的全部特征值与闭式吻合到 10⁻⁹（Python 通道用
`eigvalsh` 独立复算，同样吻合）；ρ(A) 在 r = 0.5 时 0.9969（危险
模式 sin² < 1，严格内缩）、r = 0.51 时 1.0369 出界；BTCS r = 5
时 ρ(B⁻¹) = 0.9701。

## 6.3 能量不等式方法：变系数问题的严格武器

Fourier 与矩阵法在**变系数、非线性**问题上失效，能量法（PDE 能量
方法的离散模拟）直接从稳定性定义出发做估计。书用变系数对流方程
u_t + a(x,t)u_x = 0（a ≥ 0）的迎风格式（4.18）演示思想：

    u_j^{n+1} = (1 − a_jⁿλ)u_jⁿ + a_jⁿλ·u_{j−1}ⁿ。

核心一行是**凸性不等式**：λ ∈ [0,1] 时加权平均的平方不超过平方的
加权平均——

    ((1−λ)a + λb)² ≤ (1−λ)a² + λb²    （差恰为 λ(1−λ)(a−b)² ≥ 0）。

逐格应用并对 j 求和（h 加权），ℓ² 能量的漂移只来自系数的空间变化
率；若 a 与 x 无关，能量**单调不增**；若 a 依赖 t 且满足书 (4.20)
sup|∂a/∂t| ≤ c，则 ‖uⁿ‖² ≤ (1+c)ⁿ‖u⁰‖²，得稳定性，条件是
(4.19)：max_j a_jⁿλ ≤ 1。常系数时退化为 aλ ≤ 1——与 Fourier 方法
殊途同归。

数值实验（Julia）：

```julia
norms = l2_evolve(fill(0.9, 64), uf, 50)
monotone = all(norms[i+1] <= norms[i] + 1e-12 for i in 1:length(norms)-1)
@assert monotone "λ=0.9 ≤ 1 时 ℓ² 范数应单调不增（凸性）"
```

λ = 0.9 时 ℓ² 范数 50 步内**逐步单调不增**（5.906 → 3.307）；违反
(4.19)（λ = 1.05）时增长 5.906 → 12.806；变系数 a(x) = 1 + 0.5x
（max λ = 0.9）时能量变化 0.3198，压在伸缩和界 (1 + 0.9·0.5h)⁵⁰ =
1.4195 之下。

## 6.4 Lean：凸性内核与"模板 → 放大"组装

Lean 通道（`examples/lean/Pdenum/Ch06OtherMethods.lean`）证明能量
法的代数内核。恒等式部分连假设都不需要：

```lean
/-- 恒等式：`RHS − LHS = λ(1−λ)(a−b)²`，无需任何假设。
（注意：`λ` 是 Lean 保留字，参数名用 `lam`。） -/
theorem convex_identity (a b lam : ℝ) :
    (1 - lam) * a ^ 2 + lam * b ^ 2 - ((1 - lam) * a + lam * b) ^ 2
      = lam * (1 - lam) * (a - b) ^ 2 := by
  ring
```

加上 λ ∈ [0,1] 就是凸性不等式（`convex_sq`）。矩阵法这边，把第
03 章的模板恒等式组装成"格式作用在模式上 = 乘放大因子"：

```lean
/-- FTCS 热传导格式作用在模式 `v_j = sin(jθ)` 上，一步把模式乘以
`1 + r(2cosθ − 2) = 1 − 4r·sin²(θ/2)`——矩阵法求特征值与 Fourier
方法求增长因子**得到同一个数**的代数原因。 -/
theorem ftcs_mode_amplification (r θ j : ℝ) :
    sin (j * θ) + r * (sin ((j + 1) * θ) - 2 * sin (j * θ) + sin ((j - 1) * θ))
      = (1 + r * (2 * cos θ - 2)) * sin (j * θ) := by
```

证明是"第 03 章恒等式 + 一次 `rw` + 一次 `ring`"——两章的内核
链条就此闭合。

## 6.5 要点回顾

1. Hirt 启示法：看第一微分近似的适定性；迎风得耗散系数
   ν = (ah/2)(1−λ)，条件 aλ ≤ 1；FTFS 得负扩散，不稳定。修正
   方程的耗散率与数值衰减定量吻合（相对差 ~h²）。
2. 矩阵法：初边值问题 uⁿ⁺¹ = Auⁿ，A 对称时稳定 ⟺ ρ(A) ≤ 1；
   FTCS 的特征值 1 − 4r·sin²(kπh/2) 与 Fourier 增长因子同式——
   模板恒等式使然。
3. 能量法：凸性不等式逐格相加，变系数下能量漂移由系数变化率控制；
   条件 (4.19) max aλ ≤ 1，常系数退化为 aλ ≤ 1。
4. 三种方法各有辖区：Fourier（常系数初值）、矩阵（特殊结构初边
   值）、能量（变系数/非线性）——选工具先看问题类型。
5. Lean 坑账：`λ` 是保留字（含假设名 hλ1 里的 λ 也非法）。
