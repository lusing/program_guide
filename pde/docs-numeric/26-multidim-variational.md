# 26 高维变分问题

**对应书第 6 章 §3（第一类/其他边值问题的变分问题、间断系数与内
边界、重调和方程，Rⁿ 推广）。**

---

## 26.1 二维 Poisson 的变分形式

−Δu = f 于 Ω、u|∂Ω = 0 的变分形式（Green 公式代替分部积分）：

    D(u, v) = ∫∫_Ω ∇u·∇v dxdy = F(v) = ∫∫_Ω f v dxdy，
    J(u) = ½D(u,u) − F(u)。

与一维完全平行：Galerkin/Ritz 等价、非齐次条件提升、第三类边界
(∂u/∂n + αu = β) 的边界积分项 ∮αuv ds 自动进入 D。

**第二类边界**（纯 Neumann）的特殊性：解不唯一（差常数），可解
条件 ∫f + ∮β = 0（取 v ≡ 1 即得）——变分形式一行给出。

## 26.2 间断系数与内边界

两种材料拼接（k = k₁ 于 Ω₁、k₂ 于 Ω₂，界面 Γ）：微分问题要附加
界面条件 u₁ = u₂（值连续）与 k₁∂ₙu₁ = k₂∂ₙu₂（通量连续）。变分
形式**自动包含**这两个条件——弱解定义 ∫k∇u·∇v = ∫fv 直接跨界面
成立，界面条件成为解的正则性推论（18 章调和平均界面是其差分版）。

重调和方程 Δ²u = f 的变分形式用 D(u,v) = ∫Δu Δv（Clough-Tocher
型），对有限元要求 C¹ 单元（第 30 章 Hermite 的动机）。

## 26.3 机器验证

### 能量泛函在真解处最小

−Δu = 2π²sinπx sinπy、零边界、精确解 u* = sinπx sinπy。能量
J(v) = ½∫|∇v|² − ∫fv（400×400 中心差分求梯度）对 u* 与扰动
u* + t·w（w = sinπx sinπy·x(1−x)，零边界）对比（Julia，
`examples/julia/26_multidim_var.jl`）：

| t | J(u* + t·w) − J(u*) |
|---|---|
| 0.3 | +0.0114 |
| 1.0 | +0.1335 |

真解处能量最小——二维直接法的数值版。

### 提升技巧

u = 1 + xy + sinπx sinπy（边界值 1 + xy，非齐次）：取调和函数
u₀ = 1 + xy（Δu₀ = 0）延拓边界，u = u₀ + w 的 w 满足原方程。制造解
的 Laplace 残差 1.6×10⁻⁵（中心差分 O(h²) 量级）——提升不改方程。

### 离散 Poincaré

五点矩阵最小特征值 λ_min·N² → 2π² = 19.7392（实测 N=40：
19.7291）——D(v,v) ≥ 2π²·‖v‖² 的离散对应，是能量范数与 L² 范数
等价的常数。

Prolog（`26_multidim_var.pl`）规则库：Ritz/Galerkin 等价（对称正定
⟹ 等价）、力学对应（最小势能/虚功）、提升规则、界面双条件吸收。

## 26.4 要点回顾

1. Green 公式 = 高维分部积分；变分形式把自然边界与界面条件全部
   吸收，只强加本质条件。
2. 纯 Neumann：解差常数 + 可解条件 ∫f = −∮β——变分形式直接给出。
3. 间断系数界面（值连续 + 通量连续）是弱解定义的推论。
4. 离散 Poincaré 常数 2π² 连接能量范数与 L² 范数。
