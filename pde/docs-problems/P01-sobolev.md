# P01 Sobolev 空间与 Friedrichs（沙马耶夫 §1.2）

**对应书习题 1.7-1.21 与第 6 章详解 1.12。**

- **1.10a**：H¹(0,1) ⊂ C⁰（1D 绝对连续性）；b) 反例 √x 连续但
  导数 1/(2√x) ∉ L²——不属 H¹；
- **1.12（详解）**：|ln ρ²|^α ∈ H¹(B_{1/2}) ⟺ α < 1/2——数值
  α=0.3 收敛、α=0.7 发散的两面实验；
- **1.17**：非 Friedrichs 区域（哑铃/十字瓶颈 ⟹ 常数 → 0）；
- **1.18**：带形 (0,1)×ℝ 中 Friedrichs 成立（λ₁ = π²）；
- **1.19**：|u(0)| ≤ C‖u‖_{H¹} 于 B(0) ⊂ ℝ² 不成立（峰值族
  u_δ = max(0, 1−|x|/δ)：u(0)=1 恒定、梯度能量恒 π、L² → 0）。

*本章示例：`examples/p-julia/P01_sobolev.jl`。*
