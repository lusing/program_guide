# P04 半有界弦与 Fourier 方法（沙马耶夫 §3.2-3.3）

**对应书习题 3.10-3.22。**

- **半有界弦（延拓法）**：固定端 u(0,t)=0 ⟹ **奇延拓**初值
  （端点值恒零 10⁻¹⁵）；自由端 u_x(0,t)=0 ⟹ **偶延拓**（端点导
  数恒零）——半直线混合问题化为全直线 Cauchy；
- **有界弦驻波**：g = x(1−x) 的系数 a₁ = 8/π³（闭式对账 10⁻⁴）、
  对称性 ⟹ a₂ = 0；
- **共振**：强迫频率 = 本征频率 π 时解 −(t/2π)sin(πx)cos(πt)
  （振幅线性增长：0 → 0.8 → 1.6；残差 10⁻⁸）；
- **非齐次边值**：代换 u = v+(1−x)μ(t) 齐次化（边值恢复逐位）。

> 共振特解坑账：cos(πt) 型（不是 sin(πt)）——设 u = T(t)sin(πx)，
> T″+π²T = sin(πt) 的共振特解是 −t·cos(πt)/(2π)。初版用 sin 型
> 残差 0.22 当场暴露。
