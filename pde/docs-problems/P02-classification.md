# P02 分类、特征与适定性（沙马耶夫第 2 章）

**对应书习题 2.1-2.23。**

- **判别式** D = a₁₂² − a₁₁a₂₂：D<0 椭圆、D>0 双曲、D=0 抛物；
- **2.5**：u_xx − 2u_xy 的特征族 y = C₁ 与 y+2x = C₂（法向
  (0,1)、(2,1) 代入二次型均为零——数值核对）；
- **2.7**：Tricomi u_xx + y·u_yy = 0 的混合型特征 x ± 2√(−y) = C
  （y<0 双曲、y>0 椭圆，特征曲线的微分方程积分）；
- **2.17-2.23**：适定性反例（Laplace Cauchy 的 sin·sinh/n^k 族
  对一切 k 内部爆炸——数值 sinh(10) = 1101 vs 边界 10⁻²）。

> 坑账：y+2x=const 的**法向**是 ∇(y+2x) = (2,1)，不是曲线切向
> (2,−1)——特征条件作用在法向上（曲面 Φ=0 的 ∇Φ 方向）。
