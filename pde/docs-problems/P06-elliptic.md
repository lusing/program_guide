# P06 椭圆方程（沙马耶夫 §5.1-5.3）

**对应书习题 5.1-5.54 精选。**

- **多项式调和**：Re z³ = x³−3xy²（Δ = 0 精确）；
- **极坐标模式**：ρⁿcos(nθ) 的极坐标 Laplacian ≈ 0（n = 1,2,3）；
- **5.18**：一阶项不破坏极值原理（正极大值论证）；
- **5.20**：Harnack 界 u(x)/u(0) ≤ 3ⁿ(1+r)/(1−r)——n=3、r=½ 时
  上界 81 > 10，习题答案"存在"的定量面；
- **5.44 型 Dirichlet 积分**：u = r³cos3θ 的能量 < 任意扰动
  （数值 9.706 < 9.709 < 9.728——Dirichlet 原理的习题面）。
