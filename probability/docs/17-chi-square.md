# 17 卡方分布：正态平方的族谱

**对应 Miller ch16（pp. 443-462）。**

χ²(ν)（ν 自由度）的定义本身就是它与正态的血缘：
**标准正态的平方是 χ²(1)，k 个独立平方和是 χ²(k)**。
它是统计推断（拟合检验、方差分析、区间估计）的发动机。
本章看三条证明路线（直接积分 / 换元定理 / 卷积）与
其中大放异彩的**归一化常数理论**——"免算角度积分"
的免死金牌。

## 17.1 密度：Z² ~ χ²(1)

Y = Z²（Z ~ N(0,1)）。CDF 法（第 11 章换元公式的非
单调现场——平方要**两侧**回溯）：

F_Y(y) = P(Z² ≤ y) = P(−√y ≤ Z ≤ √y) = F_Z(√y) − F_Z(−√y)。

链式法则求导（两项各带 ±(1/2√y)，对称合并）：

f_Y(y) = f_Z(√y)/√y = (1/√(2π))·y^{−1/2}e^{−y/2}
= **y^{1/2−1}e^{−y/2}/(2^{1/2}Γ(1/2))**——Γ(1/2) = √π 恰好
消化 √(2π)。**注意乘法版教训**：平方不是单调的，"解
不等式要开双侧"是 CDF 法在此的关键步。

一般地 **χ²(ν) 密度**：f(y) = y^{ν/2−1}e^{−y/2}/(2^{ν/2}Γ(ν/2))
（y ≥ 0）——Gamma(k = ν/2, σ = 2) 的特例，第 16 章的
族收编了它。

## 17.2 均值与方差（ν = 1）

E[Y] = ∫x·x^{−1/2}e^{−x/2}/(2^{1/2}Γ(1/2))dx，换元 t = x/2、
"加零"配指数 t^{1/2} = t^{3/2−1}，积分恰是 Γ(3/2)：

E[Y] = 2Γ(3/2)/Γ(1/2) = 2·(1/2) = **1**。

E[Y²] 同法到 Γ(5/2)：E[Y²] = 4·Γ(5/2)/Γ(1/2) =
4·(3/2)(1/2) = 3，故 **Var(Y) = 3 − 1 = 2**。

**概率读法更快**：E[Z²] = 1（方差！）、E[Z⁴] = 3!! = 3
（第 15 章偶矩）——Var(Z²) = 3 − 1 = 2。**每一步 Γ 比值
都是函数方程在打工**；两条路（Γ 代数 vs 矩的直读）
互为审计。

## 17.3 自由度的加法：三条证明路线

**定理**：X₁,…,X_k 独立标准正态，则 Y = X₁²+⋯+X_k²
~ **χ²(k)**；且独立 χ²(ν₁)+χ²(ν₂) = χ²(ν₁+ν₂)（**自由度
相加**）。归约：两 χ² 相加的特例 + 分组归纳搞定一切
（proof by grouping 第 n 次出场）。

**路线一（直接积分，k = 2）**：F_Y(y) = ∬_{x₁²+x₂²≤y}
(2π)^{−1}e^{−(x₁²+x₂²)/2}dx₁dx₂——**圆盘 + 径向被积**
请出极坐标：= ∫₀^{2π}dθ/2π·∫₀^{√y}e^{−r²/2}rdr =
1 − e^{−y/2}，求导得 (1/2)e^{−y/2} = χ²(2) 密度 ✓。
（第 15 章极坐标技巧的小型复刻。）

**路线二（换元定理 + 归一化常数理论，一般 k）**：
k 维球坐标 dx₁⋯dx_k = r^{k−1}·C(θ)drdθ（**量纲分析**
先定 r^{k−1}——角变量无量纲，米^k 需要配 r^{k−1}）。
角积分算不出（C(θ) 未知！）但**不必算**：积完角度只剩
常数 C_k，

F_Y(y) = C_k∫₀^{√y}e^{−r²/2}r^{k−1}dr，求导得
f_Y(y) = (C_k/2)e^{−y/2}y^{k/2−1}。

**y 依赖已经全对**；常数由**归一化**反求：
C_k/2 = 1/(2^{k/2}Γ(k/2))——密度必须积分到 1，Γ 的换元
账代劳。**"形状定结构、归一定常数"**——这就是归一化
常数理论的免死金牌：跳过 k 维球坐标的全部角度细节。
副产品：C_k 里藏着 k 维球面面积公式。

**路线三（卷积）**：χ²(ν₁)∗χ²(ν₂) 的卷积积分，Gamma
密度的卷积封闭性（Γ(k₁)∗Γ(k₂) = Γ(k₁+k₂)，参数相加
的积分现场）——第 16 章族的直接红利。

**矩的总账**：χ²(ν) 的 μ = ν、σ² = 2ν（ν 个独立
χ²(1)，均值方差线性可加；Γ 视角 kσ、kσ² 同收）。

## 17.4 为什么 χ² 重要

统计推断的三大件都以它为引擎（第 24 章现场）：**拟合
优度检验**（观察频数 vs 理论频数的偏差平方和 → χ²）、
**方差推断**（正态样本方差的分布）、**区间估计**（μ 未知
时 σ² 的置信区间）。自由度 = 独立平方项个数 = 数据
约束的减法（n 个偏差被 Σxᵢ = x̄ 约束掉一个）。ν 大时
χ² 本身趋于正态（CLT 的又一次预告：ν = ν 个独立平方
和）。

## 17.5 机器通道

**Python（`17_chi_square.py`）**：数值账——① χ²(ν) 密度
的 Simpson 归一（ν = 1..6，Γ(ν/2) 供常数）；② 均值方差
的积分 vs (ν, 2ν)（ν = 1, 3, 5）；③ χ²(2) 的 CDF 闭式
P(Y ≤ y) = 1 − e^{−y/2}：Simpson vs 闭式（y = 2 → 1−e^{−1}
≈ 0.632）；④ 自由度加法的密度验证：χ²(1) 与 χ²(2)
的数值卷积 vs χ²(3) 密度逐点比对；⑤ ν = 1 的中位数
（F⁻¹(1/2) ≈ 0.455，二分法）与右尾 5% 点的量级。

**Julia（`17_chi_square.jl`）**：频率形态——① Z² 的样本
均值/方差 vs (1, 2)；② Σ_k 个 Z²（k = 1, 3, 7）：样本
均值 ≈ k、样本方差 ≈ 2k；③ χ²(2) 的经验 CDF vs
1−e^{−y/2}；④ 可加性模拟：χ²(2)+χ²(5) 的样本矩 vs
χ²(7) 的理论矩 (7, 14)；⑤ ν = 20 的直方图 vs 正态近似
N(20, 40)（CLT 预告的现场）。

**Lean（`Ch17ChiSquare.lean`）**：判决侧——① χ²(1)
常数账：1/(2^{1/2}Γ(1/2)) 与 1/√(2π) 的平方等式；② χ²(2)
密度常数 1/2 与 χ²(3) 常数 1/(2√2·Γ(3/2)) = 1/√(2π) 的
化简判决（与 χ²(1) 同常数的巧合——ν = 1 与 ν = 3 的
Γ(ν/2) 相差一个 (1/2)，恰与 2^{ν/2} 的因子抵消）；③ 矩账
μ = ν、σ² = 2ν 的数值例（ν = 1..5 decide）；④ 半整数
Γ 链在 χ² 常数里的打工（Γ(5/2) = (3/2)(1/2)√π）。

## 17.6 要点回顾

1. Z² ~ χ²(1)：CDF 法 + 双侧开方；密度 y^{−1/2}e^{−y/2}/
   (2^{1/2}Γ(1/2))——Γ(1/2) = √π 消化 √(2π)。
2. k 个独立平方和 ~ χ²(k)；**自由度相加**（独立 χ² 之和），
   分组归纳收官。
3. 三条证明路线：极坐标直接积分（k=2）、k 维球坐标 +
   **归一化常数理论**（免算角度积分、白得球面面积）、
   Gamma 族卷积封闭。
4. μ = ν、σ² = 2ν；Γ(k = ν/2, σ = 2) 特例的族收编。
5. 统计三大件的引擎；ν 大时自身趋正态——CLT 螺旋
   上升的一环。
