# 06 容斥原理

**对应 Miller ch5（pp. 175-204）。**

"至少一个发生"的概率怎么算？02 章的两事件版（加两次减一次）
在本章长成完全体：**容斥原理**——n 个事件的并的概率是
"加上所有单个、减去所有成对、加回所有三重、……"的交错和。
它是概率论里最像会计学的一章：每一层重叠都要记账，一层
都不能漏。

## 06.1 从两到三：交叠的会计学

**两事件**（复习）：P(A∪B) = P(A) + P(B) − P(A∩B)。

**三事件**的推导（数每一块被数了几次）：P(A∪B∪C) =
P(A) + P(B) + P(C)
− P(A∩B) − P(A∩C) − P(B∩C)
+ P(A∩B∩C)。

**读账**：只属于一个事件的部分被数 1 次 ✓；恰属两事件的
部分被加 2 次减 1 次 = 1 ✓；三事件交集被加 3 次减 3 次加
1 次 = 1 ✓。**每一块恰好数一次**——容斥的本质是一张
"覆盖次数"的对账表。

**一般形式（定理 06.A）**：

  P(A₁∪⋯∪Aₙ) = Σᵢ P(Aᵢ) − Σᵢ<ⱼ P(Aᵢ∩Aⱼ) + Σᵢ<ⱼ<ₖ P(ᵢⱼₖ)
  − ⋯ + (−1)^{n+1} P(A₁∩⋯∩Aₙ)。

**证明骨架**（Miller 给出两种）：① **归纳法**——n=2 已证，
把 n 个事件的并写成 (n−1 个的并) ∪ Aₙ 再套两事件版（第 26
章"读证明"方法论的示范现场）；② **逐点计账**——任一样本
点 x 恰属 m 个事件，它在右边的贡献是 Σ(−1)^{k+1}C(m,k) = 1
（二项恒等式，第 03 章的伏笔回收）——每个点恰好数一次。

## 06.2 组合计数版与"至少一个"的补

计数的同构公式：|A₁∪⋯∪Aₙ| = Σ|Aᵢ| − Σ|Aᵢ∩Aⱼ| + ⋯
（等可能空间下除以 |Ω| 就是概率版）。

**最有用的形态是取补**："一个都不满足" =
总数 − |并|。错排（derangement）是招牌应用。

## 06.3 错排：至少一封装对的反面

**问题**：n 封信随机装进 n 个信封，**恰好零封**装对的
方式数 Dₙ（错排数）。

**账**（容斥的教科书级应用）：设 Aᵢ = "第 i 封装对"。
至少一封装对 = |A₁∪⋯∪Aₙ|；错排数
Dₙ = n! − |并| = n! − Σ C(n,1)(n−1)! + Σ C(n,2)(n−2)! − ⋯
= n!·(1 − 1/1! + 1/2! − 1/3! + ⋯ + (−1)ⁿ/n!)。

**每一步的读法**：|Aᵢ| = (n−1)!（i 装对后其余随便），
k 个指定装好的交集 = (n−k)!，k 个的选法 C(n,k) 个——
"指定 k 封装对"的账清晰才有整条链。

**渐近**：Dₙ/n! = Σ(−1)ᵏ/k! → **1/e ≈ 0.3679**（e⁻ˣ 的
Taylor 展开取 x = 1——交错级数收敛，且误差被下一项控制）。
**至少一封装对的概率 → 1 − 1/e ≈ 63.2%**——"完全没有
巧合"的概率只有 37%。相亲匹配问题（n 对男女随机配对，
至少一对天作之合的概率）同构同答。

## 06.4 篮子问题与牌桌的回收

**篮子问题**（原书的招牌例题链）：k 个球独立随机投进 n
个篮子——某篮空着的概率？**至少一篮空**的概率？
- 指定篮空 = (1 − 1/n)ᵏ（每球避开它）；
- **恰好全部非空**（每篮至少一球）= 容斥：
  Σⱼ(−1)ʲC(n,j)((n−j)/n)ᵏ——n 个"篮 j 空"事件的并取补。
- 生日问题是其特例（n = 365 天的篮、k 个人的球——
  "全不同" = 恰好每天至多一球，第 01 章的连乘与容斥
  两条路在同一答案会师）。

**桥牌 void 的回收**（第 04 章的伏笔）：某玩家至少一个
花色缺门 = 四个"缺门"事件的并——容斥四层交错和，结果
≈ 5.1%（单门 1.28% 的四倍不止——交叠项的净贡献为负，
因为同时缺两门很难）。**容斥每加一层，直觉就多校准一格**。

## 06.5 机器通道

**Python（`06_inclusion_exclusion.py`）**：精确分数全套——
① 错排公式 Dₙ = n!·Σ(−1)ᵏ/k! 的精确值（n = 3..10 与
递推 Dₙ = n·Dₙ₋₁ + (−1)ⁿ 双向对拍）；② Dₙ/n! → 1/e 的
收敛账（误差 ≤ 1/(n+1)! 的精确界）；③ 三事件容斥在骰子
空间（36 点）的精确验证；④ 篮子问题 n=3、k=4 的容斥值
vs 全枚举（3⁴ = 81 种投法穷举——终审法庭）。

错排闭式与递推分别独立计算，再要求精确相等：

```python
def der_closed(n):
    return factorial(n) * sum(Fraction((-1) ** k, factorial(k))
                              for k in range(n + 1))

def der_rec(n):
    d = 1 if n == 0 else 0
    for i in range(2, n + 1):
        d = i * d + (-1) ** i
    return d if n != 0 else 1

assert [der_closed(n) for n in range(0, 8)] == [1, 0, 1, 2, 9, 44, 265, 1854]
```

篮子问题则同时用容斥公式和 `product(range(n), repeat=k)` 枚举
全部 81 种投法；两端都得到 `36/81` 才算通过。

**Julia（`06_inclusion_exclusion.jl`）**：① n = 10 的随机
排列模拟"零固定点"频率 vs 1/e；② 篮子问题（n = 5、k = 20）
的"全非空"模拟 vs 容斥公式；③ 至少一封装对的 1 − 1/e
显影。

容斥公式直接翻译成交错和，模拟端则逐球记录哪些篮子出现过：

```julia
ie_prob(n, k) = sum(j -> (-1)^j * binomial(n, j) * ((n - j) / n)^k, 0:n)

function balls_all_covered(n, k, trials = 200_000)
    hit = 0
    for _ in 1:trials
        seen = falses(n)
        for _ in 1:k
            seen[rand(1:n)] = true
        end
        count(seen) == n && (hit += 1)
    end
    hit / trials
end
```

固定种子后，模拟频率与容斥值的差只按重复次数的 `1/√trials`
缩小，因此断言使用小容差，而不是要求逐位相等。

**Prolog（`06_inclusion_exclusion.pl`）**：小宇宙穷举——
① n = 4 的错排全枚举（4! = 24 个排列中数出 D₄ = 9——
错排公式的终审）；② n = 3 篮 k = 4 球的 81 投法全枚举数
"全非空"（对拍容斥）；③ 三事件容斥在 8 点玩具空间的
逐点计账验证。

```prolog
check_balls :-
    findall(Assign, (between(1,3,A1), between(1,3,B1), between(1,3,C1),
                     between(1,3,D1),
                     Assign = [A1,B1,C1,D1]), All),
    length(All, 81),
    include(all_distinct3, All, Full),
    length(Full, NFull),
    NFull =:= 36,
    IE is 81 - 3 * 16 + 3 * 1,
    IE =:= NFull.
```

四个 1–3 的选择给出 `3^4 = 81` 个有序投法；`sort/2` 去掉重复
篮子后长度恰为 3，才表示三个篮子全被覆盖。交错和
`81 − 3·16 + 3·1 = 36` 与穷举计数逐项对齐。

**Lean（`Ch06InclusionExclusion.lean`）**：mathlib 的
`Finset.inclusion_exclusion`?（组合版真名侦察：Finset 侧
的容斥/测度侧 `measure_biUnion` 系列）+ 三事件版的手工
实例（骰子空间的 norm_num 收割）。

## 06.6 要点回顾

1. 容斥 = 覆盖次数的对账表：恰属 m 个事件的点被数
   Σ(−1)^{j+1}C(m,j) = 1 次。
2. 两种证明（归纳/逐点）各有教学价值——"读证明"的
   示范章。
3. 最有用的形态常是取补："一个都不" = 总 − 并。
4. 错排 Dₙ/n! → 1/e（交错 Taylor）；篮子问题/生日/
   桥牌 void 是同一家族的三张面孔。
5. 机器分工：精确分数与递推对拍（Python）、模拟渐近
   （Julia）、24/81 全穷举（Prolog）、组合定理（Lean）。
