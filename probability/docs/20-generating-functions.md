# 20 母函数：把序列折叠成一个函数

**对应 Miller ch19（pp. 508-540）。**

序列 {aₙ} 折叠成 G(s) = Σaₙsⁿ，奇迹是常见的概率序列
（pmf、矩）折叠后**有闭式**——而闭式把卷积变成乘法、
递推变成代数方程。本章：定义与经典闭式（Fibonacci/
Binet 公式）、**卷积定理**（独立和的 pmf = 母函数乘积）、
**矩母函数（MGF）**及其流水线（矩 = 微分、和 = 乘积）。

## 20.1 动机：泊松和的手工推导之痛

Pois(5) + Pois(7) 的 pmf：Σ_ℓ 5^ℓe^{−5}/ℓ!·7^{k−ℓ}e^{−7}/(k−ℓ)!。
三步幸运的代数（乘 1 = k!/k! 配出 C(k,ℓ)；提出 e^{−12}；
二项定理合并 (5+7)^k）得 **Pois(12)**——λ 相加。推导能走
通靠的是"恰好想到"化简路径；**母函数把幸运变成流水线**。

## 20.2 定义与三大闭式

G_a(s) = Σₙ aₙsⁿ（收敛域内）。收敛半径由 aₙ 增速决定：
aₙ = 1 → 1/(1−s)（|s|<1）；aₙ = 1/n! → eˢ（全轴）；aₙ = n!
→ 只在 s = 0 收敛（Stirling 之 n/e 走廊）。**唯一性**：
G_a = G_b ⟹ a = b（系数逐个恢复）——折叠不丢信息。

**Fibonacci 全程**：F₀ = 0、F₁ = 1、Fₙ = Fₙ₋₁+Fₙ₋₂。递推
代入 G_F(s)，移项解出

G_F(s) = s/(1 − s − s²)。

**部分分式**（分母写成 (1−As)(1−Bs)，A+B = 1、AB = −1
⟹ A = φ = (1+√5)/2、B = −1/φ）+ 几何级数展开：

**Binet 公式** Fₙ = (φⁿ − (−1/φ)ⁿ)/√5。

无理数与除法恰好消成整数。**要点**：递推变代数方程、
解出闭式、几何级数读回系数——**位移技巧**（提出 s 的幂
把下标对齐）是全程唯一的巧劲。还有第二路径：矩阵
[[1,1],[1,0]]ⁿ 的对角化 Aⁿ = SΛⁿS⁻¹（快速幂的亲缘）。

## 20.3 卷积定理：独立和 = 母函数乘积

**定理**：X、Y 独立取非负整数值，则 G_{X+Y}(s) =
G_X(s)·G_Y(s)。证明一行：ΣₖP(X+Y = k)s^k 的系数 Σ_ℓ
P(X=ℓ)P(Y=k−ℓ) 正是柯西乘积的系数（第 11 章卷积的
多项式皮肤）。n 重和 = n 次幂（ iid 时 = Gⁿ）。

**泊松回访**：G_Pois(λ)(s) = e^{λ(s−1)}，乘积 e^{(λ₁+λ₂)(s−1)}
= Pois(λ₁+λ₂) 的母函数——**20.1 的三步幸运缩成一行
乘法**。几何/二项同理：Geom(p) 的 1/(1−(1−p)s)、
Bin(n,p) 的 (q+ps)ⁿ（本身就是 n 次幂——伯努利分解的
母函数皮肤）。

## 20.4 连续版与矩母函数

密度卷积的母函数是 **Laplace 变换**思路；概率论的标配
是**矩母函数**：

M_X(t) = E[e^{tX}] = Σ μ'_n tⁿ/n!（存在域 |t| < δ 内）。

**流水线三件套**：
- **矩**：M⁽ⁿ⁾(0) = μ'_n（微分读系数——第 12 章"微分
  恒等式"的统一形态：作用 t·d/dt 就得 Σμ'ₙtⁿ/n!·n）；
- **和**：M_{X+Y} = M_X·M_Y（独立时——e^{t(X+Y)} =
  e^{tX}e^{tY} 的期望乘积，第 10 章积期望定理的消费）；
- **唯一性**：M 相等 ⟹ 分布相等（严格版需复分析，
  第 22 章 Fourier 路线补票）。

**常用 MGF 表**：Exp(λ) 的 1/(1−λt)；N(0,1) 的 e^{t²/2}
（第 19 章 Stirling 路线已推）；N(μ,σ²) 的 e^{μt+σ²t²/2}；
Pois(λ) 的 e^{λ(e^t−1)}；Bin(n,p) 的 (q+pe^t)ⁿ；Gamma(k,σ)
的 (1−σt)^{−k}（k = 1 即 Exp——族的族谱在 MGF 表上
一目了然）。**方差捷径**：Var = M″(0) − M′(0)²。

**存在性警告**：Cauchy 的 MGF 在任何 t > 0 都发散——
MGF 流水线对重尾失效；**特征函数** φ(t) = E[e^{itX}]
因 |e^{itX}| = 1（Pythagoras：cos²+sin² = 1）**恒存在**，
是第 22 章的正主。

## 20.5 机器通道

**Python（`20_generating_functions.py`）**：① Fibonacci 的
母函数系数恢复（G_F(s) 的幂级数展开 vs 递推，n 到 30）；
② Binet 公式的整数性验证（浮点 φⁿ/√5 四舍五入恰为
Fₙ）；③ 泊松卷积定理的数值对拍（Pois(5)+Pois(7) 的
枚举卷积 vs Pois(12) 的 pmf 逐点相等）；④ 二项-几何
卷积（Bin(3,1/2) 的 8 格枚举 vs (q+ps)³ 展开系数）；⑤
MGF 表的数值验证（正态 e^{t²/2} 的 Simpson 积分、Exp 的
1/(1−λt)）；⑥ 矩读取（M′(0)、M″(0) 的数值微分 vs
解析矩）。

**Julia（`20_generating_functions.jl`）**：① 泊松和的模拟
直方图 vs Pois(12) pmf；② Fibonacci 快速计算的三赛跑
（递推 vs Binet vs 矩阵幂——Binet 在大 n 的浮点误差
现场）；③ MGF 数值积分 vs 闭式（正态/指数/均匀三族）；
④ 卷积定理的随机试验（两组 iid 几何的和 vs NegBin 的
pmf 对照）。

**Prolog（`20_generating_functions.pl`）**：小宇宙穷举——
① Fibonacci 递推与 Binet 取整的对照（bignum 精确整数）；
② 多项式乘法 = pmf 卷积的现场（骰子 pmf 多项式平方 =
两骰三角形，系数列表直接对拍）；③ 母函数系数恢复
（s/(1−s−s²) 的长除法展开前 20 项 = Fibonacci）。

## 20.6 要点回顾

1. 序列折叠成母函数常得闭式；唯一性保证折叠无损。
2. 卷积定理：独立和的母函数 = 乘积（泊松 λ 相加缩成
   一行）；iid 和 = Gⁿ。
3. Fibonacci 三步：递推代方程、部分分母配 (1−As)(1−Bs)、
   几何级数读回——Binet 公式 Fₙ = (φⁿ−(−1/φ)ⁿ)/√5。
4. MGF 三件套（矩 = 微分、和 = 乘积、唯一性）+ 六族
   闭式表；Var = M″(0)−M′(0)²。
5. Cauchy 无 MGF、特征函数恒存在——第 22 章的正主。
