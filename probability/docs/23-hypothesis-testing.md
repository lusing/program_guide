# 23 假设检验：概率反哺统计

**对应 Miller ch22（pp. 582-619）。**

全书唯一的长统计章。前面 21 章的概率定理在此变成**检验
的合法性证书**：z 检验的骨料是 CLT 与正态稳定性、t 检验
的骨料是 χ² 分布、拟合优度的骨料是 CLT 的平方形态。流程
固定：**假设 H₀ → 设 α → 造统计量 → 查 p 值 → 裁决**。

## 23.1 z 检验：从麦当劳开始

McDonald's 宣称平均出餐 45 秒；你抽 20 单得 x̄ = 48 秒、
s = 8 秒。是它撒谎还是你手气差？——**假设检验**把这个
非形式问题变成可计算的问题。

**零假设与备择假设**：H₀ : μ ≤ 45（我们想推翻的）、
Hₐ : μ > 45（我们想证明的）。两假设必须**互补**（覆盖参数
的一切可能值）。方向的选择有讲究：证明"药物有效"要假设
"无效"再推翻——*"这药证明了自己"远比"这药还没搞砸"有说
服力*（原书的措辞课程）。

**显著性水平 α**：预先设定"多不可能才算不可能"。α = 0.05
⟹ 双侧检验的临界值 1.96（P(−1.96 ≤ Z ≤ 1.96) = 0.95 的
账）。**α 必须在看到数据之前定**——事后挑 α 是作弊（药厂
想把 0.01 的标准放宽到 0.05 好卖药）。**统计显著 ≠ 实际
显著**：保暖内衣提升 2% 可以统计显著但没人买单。

**z 统计量**（方差已知时）：

z = (x̄ − μ)/√(σ²/n) ~ N(0,1)——分子是标准化、分母是
**样本均值的标准差** σ/√n。经典错误：灯泡例（σ = 100、
n = 20、x̄ = 2050）误用 σ 当分母得 z = 0.5，正确分母
100/√20 ≈ 22.36 给 z ≈ 2.24（p = 0.025，双侧）——
**分母差一个 √n，结论天壤**。

麦当劳账：σ/√20 ≈ 1.79、z = (48−45)/1.79 ≈ 1.68、单侧
p = 0.046 < 0.05——**拒绝 H₀**（但 α = 0.01 时结论反转：
p 值贴着阈值走，"拒绝与否"极其脆弱——这正是只报 p 值
不裁决的理由）。

**单侧 vs 双侧**：单侧只查一侧尾（临界值 1.64 < 1.96），
但要**预先有方向性理由**（麦当劳不会比宣传更快——否则
它早就宣传了）。单侧的便利性质：H₀ : μ ≤ 45 只需检验
μ = 45 的**最极端情形**（μ 更小只会让 z 更大）。

**二项的正态化**（CLT 的 p = 1/2 特例再出场）：西雅图保险
例——n = 10⁴、p₀ = 0.25 下索赔数 ~ N(2500, 43.3²)，观测
2300 给 z = −4.62、p ≈ 2×10⁻⁶：西雅图司机确实更少索赔。

## 23.2 p 值的三重警告

p 值 = **P(数据这般极端或更甚 | H₀ 真)**——是条件概率，
方向别搞反：**不是** P(H₀ 真 | 数据)。

1. **语境依赖**：绝对音感 8 音全对 vs 预知未来 8 音全对——
   同样的 p 值 = (1/12)⁸，一个可信一个荒谬（Carl Sagan：
   非常之主张需要非常之证据）。
2. **大 p ≠ 证 H₀**：20 次掷币 12 正面（p ≈ 0.5）只说明
   "数据与公平硬币相容"，不证明硬币公平——**"不拒绝"永
   远不是"接受"**。
3. **多重比较**：测 20 个指标总有一个 p < 0.05（纯靠运气）。

## 23.3 t 检验：方差未知的世界

z 检验假设**已知 σ**——现实几乎从不。用样本方差

s² = Σ(xᵢ − x̄)²/(n−1)

代替（**n−1 的自由度账**：样本均值已吃掉一个自由度——
知道 x̄ 和 n−1 个观测可算出最后一个；单点样本的 s² 是
0/0 的形式警告）。

代换的代价：统计量 (x̄−μ)/√(s²/n) 不再是 N(0,1) 而是
**t 分布**（自由度 n−1）——更胖的尾巴（两处随机源：x̄
与 s²；**知道得更少不该估得更准**）。密度 Γ((ν+1)/2)/
(√(νπ)Γ(ν/2))·(1+x²/ν)^{−(ν+1)/2}；ν→∞ 时 (1+x²/ν)^ν →
e^{−x²} 回归正态（第 12 章 (1+w/n)^n 的又一次出场）。

**定义的骨架**：t = Z/√(Y/ν)（Z 标准正态、Y ~ χ²(ν)
独立）——正态除以"标准差的估计"，正是代换场景的形式
化。麦当劳 t 检验版：t = 1.68、ν = 19、临界值 1.73——
**不再拒绝**（p = 0.055）；同一数据 z 与 t 结论相反，
自由度的代价现场。

## 23.4 两类错误、司法对照与功效

| | H₀ 真 | H₀ 假 |
|---|---|---|
| 拒绝 | **第一类**（α） | ✓ |
| 不拒绝 | ✓ | **第二类**（β） |

**第一类错误率 = α**（精确地：H₀ 真时按规则行事，拒绝的
概率恰是 α——规则自己写的）。**第二类依赖"假在哪"**：
H₀ 离真值远则易拒（身高 5 尺 vs 真 6 尺：β ≈ 10⁻⁵⁷）；
离得近则难（5'11" vs 6'0"：β ≈ 0.67）。**司法对照**：
H₀ = 无罪；第一类 = 冤枉好人（false positive）、第二类 =
放走坏人；陪审团要求更多证据降第一类必然升第二类——
**唯一同时降两者的办法是更多证据**。猪流感检验例：
阈值 9000 时第一类 0.023、第二类 0.091；把第二类压到
0.05 需阈值降到 8540，第一类升到 0.062——跷跷板的数值
现场。**功效** = 1 − β（假 H₀ 被正确拒绝的概率）；提功效
的正道是**加样本量**（1/√n 律），**效应量**决定"真值离
H₀ 多远"。

## 23.5 χ² 检验与拟合优度

**样本方差的分布**（加零分解的招牌推导）：

Σ((xᵢ−μ)/σ)² = Σ((xᵢ−x̄)/σ)² + ((x̄−μ)/(σ/√n))²

左边 χ²(n)（n 个标准正态平方和）、右边第二项 χ²(1)——
故 **(n−1)s²/σ² ~ χ²(n−1)**（第 17 章的可加性 + 独立性
收尾）。可乐罐装例：σ₀ = 0.05、s² = 0.0045、n = 20 →
χ² = 19·0.0045/0.0025 = 34.2、单侧 p = 0.017——方差
超标有嫌疑（同一组数据测均值 t = 0.67 无嫌疑：**一个
数据集多个问题各查各的**）。

**拟合优度**（列表数据）：

χ² = Σ(Oᵢ − Eᵢ)²/Eᵢ ~ χ²(k−1)——k 类、期望 Eᵢ = npᵢ。
二项情形的证明骨架：χ² = (O₁−np₁)²/(np₁(1−p₁)) =
**标准化的 O₁ 的平方**——CLT 给它正态，平方给 χ²(1)；
k 类的约束 Σpᵢ = 1、ΣOᵢ = n 吃掉一个自由度。**棒球
球员生日例**：12 个月的观测 [387,329,366,344,336,313,
313,503,421,434,398,371]（n = 4515、E = 376.25）→
χ² ≈ 93.07、ν = 11、p = 4×10⁻¹⁵——**均匀生日模型被
处决**（8-10 月偏多：青少年联赛年龄截止日的现实效应，
第 01 章招牌问题的数据侧收官）。方向注意：χ² 检验只
怕**太大**（拟合完美 = 0 = 求之不得）——恒单侧。

## 23.6 双样本检验

**已知方差（z）**：x̄−ȳ ~ N(μx−μy, σx²/nx + σy²/ny)（正态
稳定性 + 独立方差可加），标准化即检验量。睡眠实验：
x̄ = 83.5 vs ȳ = 75.4（各 n = 14）、σ² = 168.6/73.3 代入
z ≈ 1.95、单侧 p ≈ 0.026。

**未知同方差（合并 t）**：**合并方差** s²p = ((nx−1)s²x +
(ny−1)s²y)/(nx+ny−2)——按**自由度加权**的平均（不是算术
平均：1000 个样本的估计不该和 10 个的对半分）；检验量
~ t(nx+ny−2)。

**未知异方差（Welch）**：s²x/nx + s²y/ny **不是** χ² 的倍数
（合并性破坏）→ 无精确 t；**近似 t(ν)**，自由度

ν = (s²x/nx + s²y/ny)² / (s⁴x/(nx²(nx−1)) + s⁴y/(ny²(ny−1)))

——可以是**非整数**（近似世界里 19.394 个自由度合法）；
界在 min(nx−1, ny−1) 与 nx+ny−2 之间。睡眠数据 Welch
版：ν ≈ 22.5、p = 0.032——仍拒绝，但置信缩水。

10000 次检验的拒绝率 ≈ α）。

**Julia（`23_hypothesis_testing.jl`）**：① t 分布随 ν 收敛到

## 23.8 要点回顾

1. 流程：H₀/Hₐ 互补配对 → 预设 α → 统计量 → p < α 则拒
   绝。p 值是 P(数据|H₀)，不是 P(H₀|数据)。
2. z 检验的骨料：CLT（二项/均值正态化）+ 正态稳定性
   （双样本差）；分母是 σ/√n 不是 σ。
3. 方差未知 → s² 代换 → t(ν)（胖尾是代价）；双样本看
   方差知识三档（z / 合并 t / Welch 非整数 ν）。
4. 第一类 = α（规则自证）、第二类依赖真假距离；司法
   跷跷板、功效 1−β、效应量。
5. (n−1)s²/σ² ~ χ²(n−1)（加零分解）；拟合优度 χ² = Σ(O−E)²/E
   ~ χ²(k−1)（标准化平方 + 约束吃自由度），恒单侧。
