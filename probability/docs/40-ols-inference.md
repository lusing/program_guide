# 第 40 章 OLS 抽样分布、t 检验与 F 检验

## 40.1 正态假设买到了什么

第 38、39 章的结论不依赖正态性：估计、无偏、协方差与 Gauss–Markov 只用外生性和球形扰动。

但它们留下两个缺口：

1. $\hat\beta$ 与 $s^2$ 的**精确分布**未知，只能谈渐近；
2. 由此构造的检验只能用渐近临界值。

本章加入假设 A5（$\varepsilon|X\sim N(0,\sigma^2I_n)$ ），补上有限样本的精确理论：

$$\hat\beta|X\sim N(\beta,\sigma^2(X'X)^{-1}), \qquad \frac{(n-k)s^2}{\sigma^2}\sim\chi^2_{n-k}, \qquad \hat\beta\perp s^2\mid X.$$

在这三个事实上，单系数推断得到精确的 $t$ 分布，一般线性约束得到精确的 $F$ 分布。

## 40.2 三个分布事实的推导

**（1）$\hat\beta$ 正态。**
$\hat\beta=\beta+(X'X)^{-1}X'\varepsilon$ 是正态向量的线性变换，故条件于 $X$ 仍正态，均值方差第 39 章已算。

**（2）残差平方和的卡方。**
由 $e=My=M\varepsilon$ ，

$$\frac{(n-k)s^2}{\sigma^2}=\frac{\varepsilon'M\varepsilon}{\sigma^2}.$$

标准正态向量 $\varepsilon/\sigma$ 的二次型 $z'Mz$ ，当 $M$ 对称幂等时服从 $\chi^2_{\operatorname{rank}(M)}$ ——把 $M$ 正交对角化，$z'Mz=\sum_{i=1}^{n-k}\tilde z_i^2$ 恰是 $n-k$ 个独立标准正态的平方和。

第 38 章的 $\operatorname{tr}(M)=n-k$ 在这里兑现为卡方自由度。

**（3）独立。**
$\hat\beta$ 只依赖 $Py$ ，$s^2$ 只依赖 $My$ 。二者联合正态，且

$$\operatorname{Cov}(Py,My|X)=P\cdot\sigma^2I\cdot M=\sigma^2PM=0.$$

联合正态下零协方差蕴含独立（第 21 章），故 $\hat\beta$ 与 $s^2$ 条件独立。

这条性质是正态性的礼物：一般分布下不相关不等于独立，$\hat\beta\perp s^2$ 会失效。

## 40.3 单系数的 t 检验

对第 $j$ 个系数检验

$$H_0:\beta_j=\beta_{j0}.$$

记 $c_{jj}=[(X'X)^{-1}]_{jj}$ ，标准误 $se(\hat\beta_j)=s\sqrt{c_{jj}}$ 。在 $H_0$ 下

$$\frac{\hat\beta_j-\beta_{j0}}{\sigma\sqrt{c_{jj}}}\sim N(0,1), \qquad \frac{s^2}{\sigma^2}=\frac{\chi^2_{n-k}}{n-k},$$

且分子分母独立，按第 22 章 t 分布的定义

$$\boxed{ T_j=\frac{\hat\beta_j-\beta_{j0}}{s\sqrt{c_{jj}}}\sim t_{n-k}. }$$

双侧 5% 检验拒绝当 $|T_j|>t_{n-k,0.975}$ 。

置信区间由第 37 章的对偶反演：

$$\hat\beta_j\pm t_{n-k,0.975}\,s\sqrt{c_{jj}}.$$

正态线性模型里这不是渐近近似：区间覆盖率的错误概率恰好是 $\alpha$ 。

### 五点例的 t 账

沿用 $x=(0,1,2,3,4)$ 、$y=(1,3,2,5,4)$ （第 38–39 章同一组数）：

$$\hat\beta=(7/5,\ 4/5),\qquad s^2=\frac{18/5}{3}=\frac65, \qquad (X'X)^{-1}=\begin{pmatrix}3/5&-1/5\\-1/5&1/10\end{pmatrix}.$$

两个 t 统计量的平方：

$$T_1^2=\frac{(7/5)^2}{(6/5)(3/5)}=\boxed{\frac{49}{18}}\approx2.72, \qquad T_2^2=\frac{(4/5)^2}{(6/5)(1/10)}=\boxed{\frac{16}{3}}\approx5.33.$$

自由度 $n-k=3$ ，双侧 5% 临界值 $t_{3,0.975}=3.1824$ ，平方为 $10.128$ 。

两个 $T^2$ 都低于 10.128——五个点的样本谁也救不了。

$\beta_2$ 的 95% 区间：

$$\frac45\pm3.1824\sqrt{\frac65\cdot\frac1{10}} =0.8\pm1.1024 =(-0.3024,\ 1.9024),$$

包含 0，与检验结论一致。

Julia 通道用 $t_3$ 密度的闭式常数

$$\frac{\Gamma(2)}{\sqrt{3\pi}\,\Gamma(3/2)}=\frac{2}{\pi\sqrt3}$$

数值积分右尾：$T_2=4/\sqrt3\approx2.3094$ 的双侧 p 值为 0.1041。

## 40.4 一般线性约束与 F 统计量

许多经济假设是若干系数的联立约束：

- 规模报酬不变：$\beta_2+\beta_3=1$ ；
- 某变量组整体无效应：$\beta_2=\beta_3=\cdots=0$ ；
- 两期系数相等：$\beta_2=\beta_5$ 。

统一写成

$$H_0:R\beta=r,$$

其中 $R\in\mathbb R^{q\times k}$ 满行秩，$r\in\mathbb R^q$ ，$q\le k$ 。

在 $H_0$ 下 $R\hat\beta-r\sim N(0,\sigma^2R(X'X)^{-1}R')$ ，标准二次型除以 $\sigma^2$ 得 $\chi^2_q$ ；再除以独立的 $s^2/\sigma^2\sim\chi^2_{n-k}/(n-k)$ ，按 F 分布定义：

$$\boxed{ F=\frac{(R\hat\beta-r)'\left[R(X'X)^{-1}R'\right]^{-1}(R\hat\beta-r)/q}{s^2} \sim F(q,\ n-k). }$$

自由度：分子 $q$ （约束个数），分母 $n-k$ （残差自由度）。

### 第二种算法：受约束残差

第 41 章将证明恒等式

$$\mathrm{RSS}_R-\mathrm{RSS}_U =(R\hat\beta-r)'\left[R(X'X)^{-1}R'\right]^{-1}(R\hat\beta-r),$$

于是

$$\boxed{ F=\frac{(\mathrm{RSS}_R-\mathrm{RSS}_U)/q}{\mathrm{RSS}_U/(n-k)}. }$$

两个公式算同一个数；实践中哪个顺手用哪个（嵌套模型回归输出常给后者，矩阵约束常给前者）。

### 联合显著性

特例 $R=(0,\ I_{k-1})$ 、$r=0$ （所有斜率为零）给出回归摘要里的“F 统计量”。用第 39 章的分解 $\mathrm{ESS}=TSS-\mathrm{RSS}$ ：

$$F=\frac{\mathrm{ESS}/(k-1)}{\mathrm{RSS}/(n-k)} =\frac{R^2/(k-1)}{(1-R^2)/(n-k)}.$$

五点例（$k=2$ 时“全部斜率”就是单个 $\beta_2$ ，$q=1$ ）：

$$F=\frac{32/5}{(18/5)/3}=\frac{16}{3},$$

与 $T_2^2$ 完全一致——下文解释这不是巧合。

若把截距也约束为零（$R=I_2$ ），则受约束模型拟合为零向量，$\mathrm{RSS}_R=y'y=55$ ：

$$F=\frac{(55-18/5)/2}{(18/5)/3}=\frac{257}{12}\approx21.4.$$

同一组数据，问不同的问题，得到不同的 F。

## 40.5 单约束时 F = t²：精确等价

$q=1$ 时把 $R$ 记为行向量 $R'$ ，二次型退化为平方：

$$F=\frac{(R'\hat\beta-r)^2}{s^2\,R'(X'X)^{-1}R} =\left(\frac{R'\hat\beta-r}{s\sqrt{R'(X'X)^{-1}R}}\right)^2=T^2.$$

取 $R'$ 为单位向量即单系数检验。

分布层面同一件事：$t_\nu^2\sim F(1,\nu)$ （第 22 章）。

**临界值对应关系要认清方向**：$F(1,\nu)$ 的 5% 上侧临界值等于 $t_\nu$ 的**双侧** 5% 临界值之平方：

$$F_{0.95}(1,3)=10.128=3.1824^2=t_{3,0.975}^2.$$

它与单侧 t 临界值 $t_{3,0.95}=2.3534$ 的平方并不相等——本章机器单元的初版就写错过这一行，被断言当场抓住。

## 40.6 F 显著但每个 t 都不显著

直觉常见错误：“联合检验不过是把各个 t 检验做一遍”。

错。两个检验问的问题不同：

- 单个 $t_j$ 检验 $\beta_j=0$ ，**允许其余系数自由取值补偿**；
- 联合 F 检验 $\beta_2=\beta_3=0$ ，**把两个系数一起摁住**。

当两个解释变量高度相关时，单个系数的识别很差（第 41 章的方差膨胀），但它们的联合方向仍然可以精确识别——数据说“$x_1,x_2$ 合起来有用”，却分不清是谁的功劳。

此时出现经典格局：**每个 t 都不显著，联合 F 显著。**

本章机器单元用一个固定数据集（$n=60$ ，$\rho(x_1,x_2)\approx0.95$ ，$\beta_2=\beta_3=0.12$ ，$\sigma=0.5$ ）演示：

| 检验 | 统计量 | 5% 临界值 | 结论 |
|---|---:|---:|---|
| $H_0:\beta_2=0$ | $t_1=-0.502$ | $\pm2.00$ | 不拒绝 |
| $H_0:\beta_3=0$ | $t_2=1.356$ | $\pm2.00$ | 不拒绝 |
| $H_0:\beta_2=\beta_3=0$ | $F=4.621$ | $3.16$ | **拒绝** |

数据集本身固定嵌入两个语言单元，数值逐位复现，不靠随机运气。

反向的格局也存在：一个强系数带动联合 F 显著，另一个 t 无信息——此时联合检验不告诉我们哪个系数在起作用，需要再看 t 与经济含义。

## 40.7 为什么固定数据而不是再抽一次

联合显著/单个不显著的模式对随机实现敏感：换一个种子，某个 t 可能恰好越过临界值。

为了让教程的数字可复核，本章把 $x_1,x_2,\varepsilon$ 三组数（各 60 个，四位小数）直接写进 Python 与 Julia 文件。

两个通道由此计算完全相同的统计量：

```
joint vs single: t1 = -0.502 t2 = 1.356 F = 4.621 > crit 3.16
```

固定数据不改变现象的统计性质，只是把“演示”与“抽样运气”分开——这与全书“精确对拍优先于再抽一次”的纪律一致。

## 40.8 Python：精确分数与分布函数分工

`examples/python/40_ols_inference.py` 延续精确分数传统：

```python
t2_sq = beta_hat[1] ** 2 / (s2 * XtX_inv[1][1])
t1_sq = beta_hat[0] ** 2 / (s2 * XtX_inv[0][0])
assert t2_sq == F(16, 3) and t1_sq == F(49, 18)
assert t2_sq == beta_hat[1] ** 2 / XtX_inv[1][1] / s2
```

两个写法分别对应“$t^2$ ”与“二次型除以 $s^2$ ”，断言它们是同一个分数——F = t² 在数据层面的体现。

临界值与区间交给 SciPy：

```python
tcrit = float(t_dist.ppf(0.975, n - k))
Fcrit = float(f_dist.ppf(0.95, 1, n - k))
assert abs(Fcrit - tcrit ** 2) < 1e-8
```

联合检验部分同时算两种公式：

```python
F_slopes = (ESS / (k - 1)) / (RSS / (n - k))
R2 = ESS / TSS
assert F_slopes == (R2 / (k - 1)) / ((1 - R2) / (n - k))
```

固定数据集的 F 由二次型直接给出，断言 $F=4.621$ 、两个 $|t|<1.99$ 。

覆盖率审计固定种子：

```python
B = E @ Xd2 @ XtXi2
s2_all = (res ** 2).sum(axis=1) / (nn2 - 2)
se_slope = (s2_all * XtXi2[1, 1]) ** 0.5
coverage = np.mean(np.abs(B[:, 1]) <= tc * se_slope)
assert 0.945 < coverage < 0.955
```

输出：

```
t-interval coverage: 0.95075 ; size: 0.04925
```

正态线性模型的 t 区间覆盖率精确等于 95%，模拟值离它的偏差纯是 Monte Carlo 噪声。

## 40.9 Julia：闭式 t₃ 密度与独立复算

`examples/julia/40_ols_inference.jl` 不依赖分布包。

自由度 3 的 t 密度有初等归一化常数，文件直接写闭式并用 Simpson 积分右尾：

```julia
t3_pdf(x) = 2 / (pi * sqrt(3)) * (1 + x^2 / 3)^(-2)
T3(x) = 0.5 + simpson(t3_pdf, 0.0, x, 4000)
p_two = 2 * (1 - T3(4 / sqrt(3)))
@assert 0.09 < p_two < 0.11
```

归一化用 $\Gamma(2)=1$ 、$\Gamma(3/2)=\sqrt\pi/2$ 化为 $2/(\pi\sqrt3)$ ，避免特殊函数依赖。

临界值自检一行同时验证密度与分位数：

```julia
tcrit = 3.182446
@assert 0.049 < 2 * (1 - T3(tcrit)) < 0.051
```

覆盖率部分把循环封装为 `t_audit(reps)`（Julia 顶层作用域纪律），结果：

```
t-interval coverage = 0.9488; size = 0.0512
```

与 Python 的 0.95075/0.04925 在 Monte Carlo 波动内一致。

## 40.10 Lean：平方账与两个一般锚

`examples/lean/Probability/Ch40OLSInference.lean` 把本章所有分数账交给 `norm_num`：

```lean
example : ((4 : ℚ) / 5) ^ 2 / ((6 / 5) * (1 / 10)) = 16 / 3 := by norm_num
example : ((7 : ℚ) / 5) ^ 2 / ((6 / 5) * (3 / 5)) = 49 / 18 := by norm_num
example : ((32 : ℚ) / 5 / 1) / ((18 / 5) / 3) = 16 / 3 := by norm_num
example : (((55 : ℚ) - 18 / 5) / 2) / ((18 / 5) / 3) = 257 / 12 := by norm_num
```

一般层面有两个锚。

单约束等价：

```lean
theorem f_equals_t_squared (b se : ℚ) (hse : se ≠ 0) :
    (b / se) ^ 2 = b ^ 2 / se ^ 2 := by
  field_simp
```

把“二次型除以 $s^2$ ”读成“比值平方”，即 F = t² 的代数内核。

F 分子非负：

```lean
theorem constraint_distance_nonneg (b r c : ℚ) (hc : 0 < c) :
    0 ≤ (b - r) ^ 2 / c :=
  div_nonneg (sq_nonneg _) (le_of_lt hc)
```

约束离距平方除以正的方差尺度非负——F 统计量只能朝“拒绝”方向积累证据的代数根源。

## 40.11 异方差与大样本下的替代

正态+球形扰动一旦破坏，精确 t/F 不再精确：

- **异方差**：改用稳健协方差（White/HC 系列）构造 t 统计量，临界值走渐近正态或 $t_{n-k}$ 近似（第 35、41 章的 sandwich 思想）；
- **序列相关**：Newey–West 类 HAC 协方差；
- **大样本**：$t_{n-k}\to N(0,1)$ ，两者临界值几乎无差，但小样本差异真实（五点例里 10.128 对 3.84 的差距就是自由度的代价）。

渐近替代的合法性靠第 27–29 章的工具链支撑，不是“样本大了就自动对”。

## 40.12 常见误区

### 误区一：t 不显著就说明该变量无用

不显著只说明“本数据分辨不出”；相关回归变量下单个 t 天生乏力（本章 40.6 的现场）。

### 误区二：F 显著等于每个系数都显著

F 拒绝的是联合零假设；具体谁在起作用要看 t、约束的逐个检验与经济含义。

### 误区三：F(1,ν) 临界值等于单侧 t 临界值的平方

对应的是双侧 t 分位（$t_{0.975}^2=F_{0.95}(1,\nu)$ ），本章机器检查纠正过这个笔误。

### 误区四：精确 t/F 不需要正态性

有限样本精确性完全建立在 A5 上；无正态性只能谈渐近。

### 误区五：联立方程检验可以逐个做 t 了事

多重零假设的整体错误率与单个检验不同（第 37 章 Bonferroni 的回归）。

### 误区六：报告 p 值就等于报告了效应大小

区间 $(-0.30,1.90)$ 同时说明：点估计 0.8，但数据对 0 到 1.9 之间的任何值都无法区分。

## 40.13 本章要点

1. A5 下三事实：$\hat\beta|X$ 正态、$(n-k)s^2/\sigma^2\sim\chi^2_{n-k}$ 、二者条件独立（正态零协方差 ⇒ 独立）。
2. $T_j=(\hat\beta_j-\beta_{j0})/(s\sqrt{c_{jj}})\sim t_{n-k}$ ；区间由对偶反演，覆盖率精确。
3. 一般约束 $R\beta=r$ 的 F 有二次型与受约束残差两种等价算法，自由度 $(q,n-k)$ 。
4. $q=1$ 时 F = t² 精确成立；临界值对应双侧 t 分位：$10.128=3.1824^2$ 。
5. 五点例：$T_1^2=49/18$ 、$T_2^2=16/3$ 均低于 10.128；$\beta_2$ 区间 $(-0.3024,1.9024)$ 。
6. 联合 F 与单个 t 问的问题不同：固定数据集演示 $t=(-0.502,1.356)$ 双双不显著而 $F=4.621$ 显著。
7. 精确推断随正态与球形扰动的破坏而失效，稳健与渐近替代各有自己的账。
