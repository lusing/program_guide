# 04 独立性、条件独立与信息

独立性是概率论中最强、最常被误用的假设之一。它表示知道一个事件是否
发生，不改变另一个事件的概率；但“没有线性关系”“看起来互不影响”
“历史不能线性预测未来”都不等于独立。本章依次区分事件独立、两两独立、
相互独立、条件独立和零相关，并用有限模型把每一处差别算清楚。

## 04.1 两个事件的独立性

设 \((\Omega,\mathcal F,P)\) 是概率空间。事件 \(A,B\in\mathcal F\)
**相互独立**定义为

\[
P(A\cap B)=P(A)P(B).
\]

若 \(P(B)>0\)，由条件概率定义可得

\[
P(A\mid B)=\frac{P(A\cap B)}{P(B)}
=\frac{P(A)P(B)}{P(B)}
=P(A).
\]

同理，若 \(P(A)>0\)，则 \(P(B\mid A)=P(B)\)。所以在正概率情形下，
独立的直觉读法是：观测到 \(B\) 不改变 \(A\) 的概率，观测到 \(A\) 也
不改变 \(B\) 的概率。

乘积形式比条件概率形式更一般，因为当 \(P(B)=0\) 时，\(P(A\mid B)\)
不能用初等商定义，但 \(P(A\cap B)=P(A)P(B)\) 仍有意义。事实上若
\(P(B)=0\)，由单调性 \(P(A\cap B)=0\)，所以零概率事件与任意事件按
乘积定义独立。本章的直觉例子仍主要使用正概率事件。

独立性是关于概率测度 \(P\) 的陈述，不是关于集合是否“看起来无关”的
陈述。同一组事件在一个概率测度下独立，在另一个概率测度下可能不独立。

## 04.2 独立不是互斥

一个常见错误是把“互不相干”理解成互斥。恰好相反，若两个事件都有正
概率，互斥事件一定不独立。

若 \(A\cap B=\varnothing\)，则

\[
P(A\cap B)=0.
\]

但 \(P(A)>0\)、\(P(B)>0\) 时，

\[
P(A)P(B)>0,
\]

所以 \(P(A\cap B)\ne P(A)P(B)\)。互斥意味着知道 \(A\) 发生就立刻
知道 \(B\) 不可能发生，这是非常强的信息，而不是“没有信息”。

例如抛两枚公平硬币，令 \(A\) 为第一枚正面，\(B\) 为第二枚正面。四个
结果 \((0,0),(0,1),(1,0),(1,1)\) 等可能，则

\[
P(A)=P(B)=\frac12,\qquad
P(A\cap B)=\frac14=P(A)P(B).
\]

这两个独立事件可以同时发生。另一方面，第一枚正面事件 \(A\) 与“两枚
都反面”事件 \(D\) 互斥，且

\[
P(A\cap D)=0\ne\frac12\cdot\frac14=P(A)P(D).
\]

## 04.3 两两独立不等于相互独立

对一族事件 \(A_1,\ldots,A_n\)，**两两独立**只要求任意两个事件独立：

\[
P(A_i\cap A_j)=P(A_i)P(A_j)\qquad(i\ne j).
\]

**相互独立**要求任意非空子集 \(I\subseteq\{1,\ldots,n\}\) 都满足

\[
P\left(\bigcap_{i\in I}A_i\right)=\prod_{i\in I}P(A_i).
\]

因此三个事件相互独立不仅要求三个二元等式，还要求

\[
P(A_1\cap A_2\cap A_3)=P(A_1)P(A_2)P(A_3).
\]

两两独立不保证最后这个三元等式。洪永淼教材给出了一个非常清楚的 9 点
反例。令

\[
\Omega=\{aaa,bbb,ccc,abc,bca,cba,acb,bac,cab\},
\]

每个点等可能，概率均为 \(1/9\)。令 \(A_i\) 表示第 \(i\) 个位置的字母
是 `a`。

- \(A_1=\{aaa,abc,acb\}\)，所以 \(P(A_1)=3/9=1/3\)；
- \(A_2=\{aaa,bac,cab\}\)，所以 \(P(A_2)=1/3\)；
- \(A_3=\{aaa,bca,cba\}\)，所以 \(P(A_3)=1/3\)。

任意两个位置同时为 `a` 的点只有 `aaa`，因此

\[
P(A_i\cap A_j)=\frac19
=\frac13\cdot\frac13.
\]

但三个位置同时为 `a` 的点也只有 `aaa`：

\[
P(A_1\cap A_2\cap A_3)=\frac19
\ne
\frac1{27}
=P(A_1)P(A_2)P(A_3).
\]

因此它们两两独立，却不相互独立。

这个反例的经济意义并不牵强。三个变量两两没有成对预测关系，不代表它们
的联合风险可以按三个独立风险相乘。金融危机中的尾部共同暴露、多重市场
同步失灵、多份资产同时违约，往往正是出现在高阶联合事件中。只检查两两
相关矩阵，可能漏掉系统性共同事件。

`examples/python/04_independence.py` 直接枚举这个样本空间：

```python
nine_points = [
    "aaa", "bbb", "ccc",
    "abc", "bca", "cba",
    "acb", "bac", "cab",
]

def at(position, symbol):
    return lambda word: word[position] == symbol

A1, A2, A3 = (at(i, "a") for i in range(3))
for left, right in ((A1, A2), (A1, A3), (A2, A3)):
    assert intersection_prob(left, right, nine_points) == Fraction(1, 9)
triple = empirical(lambda w: A1(w) and A2(w) and A3(w), nine_points)
assert triple == Fraction(1, 9)
assert triple != Fraction(1, 3) ** 3
```

程序不是抽样估计，而是在 9 个点上逐点计数，所有概率都是精确有理数。
Julia 文件 `examples/julia/04_independence.jl` 使用 `Rational{Int}`
做同一套账；Prolog 文件 `examples/prolog/04_independence.pl` 用
`findall/3` 与 `atom_chars/2` 枚举位置事件。

## 04.4 条件独立

若 \(P(C)>0\)，称事件 \(A,B\) 在给定 \(C\) 时**条件独立**，如果

\[
P(A\cap B\mid C)=P(A\mid C)P(B\mid C).
\]

它表示在信息 \(C\) 已知后，再知道 \(A\) 不会改变 \(B\) 的条件概率。
条件独立不是普通独立的推论，普通独立也不是条件独立的推论。二者描述的
是不同信息状态下的关系。

### 共同状态：条件独立但边际相关

先看第一个方向。设潜在经济状态 \(C\) 公平地取 0 或 1。给定 \(C=0\)，
两个二元信号 \(A,B\) 相互独立，成功概率均为 \(1/5\)；给定 \(C=1\)，
它们相互独立，成功概率均为 \(4/5\)。

在每个状态内部，两个信号独立。但边际地把两个状态混合后：

\[
P(A=1)=\frac12\cdot\frac15+\frac12\cdot\frac45=\frac12,
\]

\[
P(B=1)=\frac12,
\]

而

\[
P(A=1,B=1)
=\frac12\left(\frac15\right)^2
+\frac12\left(\frac45\right)^2
=\frac{17}{50}.
\]

由于

\[
\frac{17}{50}\ne\frac14=P(A=1)P(B=1),
\]

\(A,B\) 边际不独立。共同状态像一个不可观测因子：它在每个状态内部解释
了两个信号的同步变化；忽略这个状态，只看边际分布，就会看到相关性。

Julia 程序用带权有限空间计算条件概率：

```julia
mass(; Aval=nothing, Bval=nothing, Cval=nothing) =
    sum(t[4] for t in mixture
        if (isnothing(Aval) || t[1] == Aval) &&
           (isnothing(Bval) || t[2] == Bval) &&
           (isnothing(Cval) || t[3] == Cval); init=0//1)

for c in (0, 1)
    denom = mass(Cval=c)
    pA = mass(Aval=1, Cval=c) // denom
    pB = mass(Bval=1, Cval=c) // denom
    pAB = mass(Aval=1, Bval=1, Cval=c) // denom
    @assert pAB == pA * pB
end
@assert mass(Aval=1, Bval=1) == 17//50
```

这给出了条件概率的重要解释：许多模型并不是假设变量“无条件无关”，而是
假设在控制某些状态、因子或历史信息后，未解释冲击相互独立。

### 对撞量：边际独立但条件相关

第二个方向同样重要。设 \(A,B\) 是两枚公平硬币的结果，令

\[
C=A\oplus B
\]

为异或结果。四个点 \((A,B,C)\) 等可能：

\[
(0,0,0),\quad(0,1,1),\quad(1,0,1),\quad(1,1,0).
\]

边际地有

\[
P(A=1,B=1)=\frac14=P(A=1)P(B=1),
\]

所以 \(A,B\) 独立。但给定 \(C=1\)，只剩 \((1,0)\) 与 \((0,1)\)，于是

\[
P(A=1,B=1\mid C=1)=0,
\]

而

\[
P(A=1\mid C=1)P(B=1\mid C=1)
=\frac12\cdot\frac12=\frac14.
\]

因此给定 \(C=1\) 后它们不独立。知道 \(C=1\) 且看到 \(A=1\)，就能确定
\(B=0\)。

这类变量在图模型中称为对撞结构：\(A\) 与 \(B\) 共同影响 \(C\)。对本来
独立的原因条件化于共同结果，可能产生人为的条件依赖。计量经济学、样本
选择和缺失数据中的许多偏差，都可以在这个四点模型中看到雏形。

Prolog 程序把四点模型写成事实：

```prolog
xor_point(0, 0, 0).
xor_point(1, 0, 1).
xor_point(0, 1, 1).
xor_point(1, 1, 0).
```

枚举显示：四点中 \(A=1\) 有两点，\(B=1\) 有两点，二者同时为 1 有一点；
但 `xor_point(1,1,1)` 没有任何解。边际乘积关系成立，条件乘积关系失败。

## 04.5 零相关不是独立

对随机变量 \(X,Y\)，若协方差

\[
\operatorname{Cov}(X,Y)=E[(X-E X)(Y-E Y)]
\]

存在且等于零，称二者不相关或零相关。零相关只排除线性共变，不排除非线性
依赖。

取四个值等可能：

\[
X\in\{-2,-1,1,2\},\qquad Y=X^2.
\]

则

\[
E[X]=\frac{-2-1+1+2}{4}=0,
\]

且

\[
E[XY]=E[X^3]
=\frac{(-2)^3+(-1)^3+1^3+2^3}{4}=0.
\]

因此

\[
\operatorname{Cov}(X,Y)=E[XY]-E[X]E[Y]=0.
\]

但 \(Y\) 由 \(X\) 完全决定。例如 \(X=2\) 时 \(Y=4\) 的条件概率为 1，
而边际上 \(P(Y=4)=1/2\)。这就是“零相关但完全依赖”的四点反例。

对两个事件的指示变量，零相关确实等价于独立，因为

\[
\operatorname{Cov}(\mathbf 1_A,\mathbf 1_B)
=P(A\cap B)-P(A)P(B).
\]

但一般随机变量有平方、阈值、波动率聚集、区制转换和高阶矩依赖，不能从
零协方差推出独立。经济金融研究中，“收益率一阶自相关接近零”最多说明
线性滞后关系弱，不说明历史信息无用，更不说明增量相互独立。

第 00 章的 logistic 序列是同一教训的动力系统版本。它的下一期值满足

\[
x_t=4x_{t-1}(1-x_{t-1}),
\]

知道 \(x_{t-1}\) 就能精确计算 \(x_t\)；但很长一段序列的一阶滞后相关可以
接近零。零相关与可预测性在这里明确分离。

Python 程序精确计算四点协方差：

```python
xs = (-2, -1, 1, 2)
mean_x = Fraction(sum(xs), len(xs))
mean_y = Fraction(sum(x * x for x in xs), len(xs))
cov = sum((x - mean_x) * (x * x - mean_y) for x in xs) / len(xs)
assert mean_x == 0
assert cov == 0
```

这里不是“样本相关约等于零”，而是在给定四点等可能模型下精确等于零。

## 04.6 独立性与信息集

随机过程把独立性放到信息流中讨论。若 \(\mathcal F_{t-1}\) 是到 \(t-1\)
为止的历史信息集，强形式的不可预测性要求未来冲击 \(X_t\) 与
\(\mathcal F_{t-1}\) 中所有事件独立。这比

\[
\operatorname{Corr}(X_t,X_{t-1})=0
\]

强得多。

几何随机游走

\[
\ln P_t=\ln P_{t-1}+X_t
\]

若增量 \(X_t\) 相互独立且均值为零，则历史价格路径不能提供未来增量的
概率信息。有效市场假说的严格形式通常需要这种 martingale 或独立增量类
条件；仅检验几个自相关系数，不能证明市场有效。

反过来，确定性混沌系统也能产生类似噪声的经验相关图。相关图是线性摘要，
不是完整的条件分布比较。要研究可预测性，应检查条件分布、条件期望、方差、
高阶矩、区间预测误差或具体交易规则，而不能只看一个相关系数。

条件独立还是统计建模的基本积木：

- 在共同因子 \(C\) 后，个体冲击可设为条件独立；
- 在时间序列中，给定历史信息后的预测误差可设为 martingale 差序列；
- 在图模型中，条件独立刻画哪些路径传递信息，哪些路径被阻断；
- 在抽样中，条件独立允许把似然写成条件概率乘积。

这些都是模型假设，必须由抽样机制、制度背景或诊断检验支持，不能因为变量
“属于不同市场”就自动成立。

## 04.7 三个层次的证据

本章示例有意区分三种证据。

第一，有限空间的精确枚举回答“这个模型中到底是多少”。9 点空间、XOR
四点空间和 \(X^2\) 四点空间都不存在抽样误差。

第二，定义和数学证明回答一般性。相互独立的所有子集乘积条件、条件独立
的条件概率形式、协方差公式等，不依赖某一次枚举。

第三，模拟只用于培养频率直觉。上一章 Monty Hall 的 Julia 模拟每次随机
生成大量样本，其频率接近理论值；但真正判定换门胜率为 \(2/3\) 的是 Bayes
公式和合法主持行为的精确枚举。

因此，本章 Python 与 Julia 主要使用 `Fraction` 和 `Rational{Int}`，
Prolog 使用整数计数；它们不是用随机噪声“看起来接近”来证明独立性。

## 04.8 常见误判清单

1. **互斥即独立**：正概率下正好相反。
2. **两两独立即相互独立**：9 点反例给出三元概率 \(1/9\ne1/27\)。
3. **条件独立即边际独立**：共同状态混合会产生边际相关。
4. **边际独立即条件独立**：对共同结果或选择变量条件化可制造依赖。
5. **零相关即独立**：\(Y=X^2\) 在对称四点空间中协方差为零却完全依赖。
6. **零自相关即不可预测**：logistic 映射确定性地由当前值生成下一期值。
7. **独立即没有因果**：独立性是概率关系；是否有因果方向需要额外的结构
   假设。随机实验中的独立处理分配可以帮助识别因果，但那是设计带来的。

## 04.9 本章要点

1. 两事件独立的定义是 \(P(A\cap B)=P(A)P(B)\)。
2. 正概率事件互斥必不独立，因为互斥本身携带强信息。
3. 相互独立要求所有非空子集都满足乘积，而不只要求两两乘积。
4. 条件独立的公式是
   \(P(A\cap B\mid C)=P(A\mid C)P(B\mid C)\)。
5. 共同原因可使变量“条件独立但边际相关”；共同结果可使变量“边际独立
   但条件相关”。
6. 零相关只排除线性关系；\(Y=X^2\) 可在零协方差下完全依赖。
7. 经济时间序列中的独立增量、martingale 差和有效市场是强信息条件，不能
   由近零自相关单独推出。
