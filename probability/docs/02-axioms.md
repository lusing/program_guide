# 02 概率公理、解释与基本定律

**概率基础：随机试验、事件运算、σ 代数、三公理与基本定律。**

概率公式不能靠零散机智无限堆叠。这一章把直觉铸成 **Kolmogorov
三公理**：非负性、规范性和可数可加性。我们先从无限均分、Bertrand
型歧义和容斥错误三个悖论感受公理化的必要性，再复习集合语言，说明
频率、古典对称和主观信念三种概率解释为何能共用同一套公理，最后推出
补律、单调性、容斥、全概率、Boole 不等式和连续性。公理不替你决定
模型，却明确规定模型一旦写下就必须遵守什么。

## 02.1 三个悖论：为什么需要公理

**悖论一（取遍自由）**：随机取一个正整数，"恰好取到 7"的
概率是多少？如果每个整数等可能，p ≥ 0 两种情况都矛盾：
全取同一个正概率则总和超 1（违反规范性）；全取 0 概率则
加起来是 0 而不是 1（违反可数可加）。**"等可能的无穷均分"
不存在**——无限样本空间上的概率必须精心构造。

**悖论二（Bertrand 型不唯一）**：同一个口语化的问题可以有
多个都"合理"的样本空间（著名的 Bertrand 弦悖论的离散版）。
"随机选一条弦，长度超过内接三角形边的概率"答案可以是
1/3、1/2、1/4——取决于"随机"怎么定义。**公理不解决建模
歧义，但把歧义逼到明处**：你必须先写下样本空间 Ω 与每个
事件的概率，争论才有对象。

**悖论三（直觉算术失灵）**：P(A ∪ B) 什么时候等于 P(A) +
P(B)？"至少一个骰子是 6"= 11/36 而不是 12/36——1/36 的
重叠（两个 6）被直觉的加法吞了。**容斥的减法项**不是琐碎
修正，是概率与计数的核心结构（第 06 章容斥原理整章讲它）。

这三个坑不是刁难，而是概率建模中每天都会遇到的问题；
公理系统的价值就是把“什么时候可以加、什么时候必须减”
变成可以逐条检查的规则。

## 02.2 概率的三种解释

在写下公理前，先回答一个哲学和实务都绕不开的问题：概率到底是什么？
同一组数学公理可以承载至少三种常见解释。

**第一种是古典或对称解释**。若随机机制有 $n$ 个等可能基本结果，
事件 $A$ 含其中 $k$ 个，则 $P(A)=k/n$ 。公平硬币、公平骰子、
均匀洗牌都使用这种解释。它简单有力，但“等可能”不能随意假设。无限
空间上也不能把所有实数点视为等可能；古典解释必须有对称性或抽样机制
支持。

**第二种是频率解释**。在可重复、条件稳定的试验中，事件 $A$ 在前
$N$ 次试验中的相对频率为 $N_A/N$ ；当 $N\to\infty$ 时，该频率
趋近的数称为概率。这个解释与 IID 抽样和大数定律密切相关。严格地说，
不能把概率定义成“我们尚未证明的极限必然存在”，而是先建立概率模型，
再由大数定律证明在某些条件下相对频率几乎处处收敛到概率。

**第三种是主观或信念度解释**。概率表示在给定信息下，决策者对某一
命题真实性的合理信念程度。天气预报中的降水概率、金融危机中联系汇率
瓦解的概率、风险中性定价中的概率，常常不能通过重复同一历史事件直接
观测。主观概率不等于任意猜测；它仍须满足三公理，并且新信息到来时
要按条件概率和 Bayes 公式更新。

三种解释的形而上学不同，数学结构却相同。一个函数只要在指定 σ 代数上
满足三公理，就称为概率测度。古典频率可写成均匀测度，长期频率由随机
变量模型描述，主观信念也必须遵守补律和 Bayes 更新。计量经济学中所谓
客观或物理概率与风险中性概率，常常是在同一状态空间上定义的两个不同
概率测度，二者差异反映风险价格和市场偏好，而不是一方满足公理、另一
方不满足公理。

## 02.3 集合语言复习（公理的语法）

事件是样本点（结果）的集合。Ω 是全空间；∅ 是空事件。
本教程用到的集合操作一表清：

| 操作 | 记号 | 概率读法 |
|---|---|---|
| 并 | A ∪ B | A 或 B 至少一个发生 |
| 交 | A ∩ B | A、B 同时发生 |
| 补 | Aᶜ | A 不发生 |
| 差 | A \ B | A 发生且 B 不发生 |
| 包含 | A ⊂ B | A 发生则 B 必发生 |

**De Morgan 律**（本教程用得最多的恒等式）：

  (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ，(A ∩ B)ᶜ = Aᶜ ∪ Bᶜ。

口诀：“补翻交并”。它的一个直接应用是生日问题中的取补：
“至少两人同生日”的补是“所有人生日互不相同”——把难的
“存在性”事件翻成好算的“全称性”事件。

**代码验证集合恒等式**：有限小宇宙上可以枚举 $A,B$ 的
所有组合，逐条检查等式两边。本章把这个传统做成 Prolog 通道的
固定节目——02.6 节的 De Morgan 穷举就是它的直接应用。

**开与闭（一瞥）**：当 Ω = ℝ（连续样本空间）时，开集/闭集
的区别开始重要（[0,1] 与 (0,1) 的差别在有限空间里不存在）。
第 09 章（连续随机变量）会用到"区间可以是开或闭，测度
不差那一点"——这是 σ-代数的预告片。

**可数与不可数（附录 C 提前引用）**：整数是可数的（可以
列表），实数不可数（对角线论证）。02.1 的悖论一正是可数性
的副作用；而"从 [0,1] 均匀取一点，每一点概率为零，总和
却是 1"的表面矛盾，要靠**不可数无穷的"逐点概率"与"总
测度"可以脱钩**来化解——公理只对**可数**并承诺可加性，
对不可数并没有说"加起来"这句话有意义。这是 σ-代数门槛
内侧的第一缕光。

## 02.4 样本空间、事件与三条公理

**定义 02.A（概率空间的入门版）**。一个概率模型 = 样本空间
Ω（所有可能结果的集合）+ 事件族（Ω 的子集的集合，先理解
为"我们关心的事件全体的账本"）+ 概率测度 P（事件 → [0,1]
的函数），满足 **Kolmogorov 三公理**：

  (P1) **非负性**：对每个事件 A，P(A) ≥ 0；
  (P2) **规范性**：P(Ω) = 1；
  (P3) **可数可加性**：两两不交的事件序列 A₁, A₂, … 满足
      P(⋃ᵢ Aᵢ) = Σᵢ P(Aᵢ)。

对有限样本空间，(P3) 只需有限版（数学归纳可从两两不交的
有限并推广）；"可数"版是为连续世界（第 09 章）预留的——
σ-代数的必要性在于：**不是所有集合都能在保持可加性的意义下
被赋予概率**。在实数线上处理极限事件时，事件族必须是
“对补与可数并封闭”的 σ-代数。入门阶段你可以把这句话当
技术门槛；更一般的测度论版本见同仓库《测度论教程》。

**等可能特例（古典概型）**：Ω 有限且各点等可能时，
P(A) = |A|/|Ω|——概率退化为**计数**，这是第 05–07 章
的地盘。生日问题的 Pₖ = 全不同安排数/365ᵏ
正是古典概型的连乘版。

## 02.5 公理的免费午餐：基本定律

以下定律全部是三公理的机械推论——**没有一条需要新假设**。
每条都给一行推导（读懂这些推导是本章的核心练习；"读证明"
本身是原书附录 A.1 的专题）。

**定理 02.B（补律）**：P(Aᶜ) = 1 − P(A)。
推导：A ⊔ Aᶜ = Ω 且不交 ⟹ P(A) + P(Aᶜ) = P(Ω) = 1
（用了 P3 与 P2）。

**定理 02.C（空事件）**：P(∅) = 0。
推导：∅ 与 ∅ 不交且并仍为 ∅ ⟹ P(∅) = P(∅) + P(∅)。

**定理 02.D（单调性）**：A ⊂ B ⟹ P(A) ≤ P(B)。
推导：B = A ⊔ (B\A)，P3 给 P(B) = P(A) + P(B\A) ≥ P(A)
（用了 P1）。

**定理 02.E（容斥二项版）**：
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)。
推导：A ∪ B = A ⊔ (B\A) 且 P(B\A) = P(B) − P(A∩B)
（对 B = (A∩B) ⊔ (B\A) 用 P3）。重叠部分被加了两次，
减回一次——02.1 悖论三的正式安葬。

**定理 02.F（全概率律）**：若 ⋃ᵢ Bᵢ = Ω 且两两不交
（称为 Ω 的一个**分割**），则 P(A) = Σᵢ P(A|Bᵢ)P(Bᵢ)。
本章先用有限两块版：P(A) = P(A∩B) + P(A∩Bᶜ)。它是
第 03 章 Bayes 公式的“分母机器”。

**定理 02.G（Boole 不等式 / 并的上界）**：
P(⋃ᵢ Aᵢ) ≤ Σᵢ P(Aᵢ)。
推导：把并改写成不交塔 T₁ = A₁，T₂ = A₂\A₁，…，则
P(⋃Aᵢ) = ΣP(Tᵢ) ≤ ΣP(Aᵢ)（每步用单调性）。**上界无需
知道重叠结构**——这是"信息不足时的保守估计"，第 18 章
（不等式）的老祖宗。

**定理 02.H（连续性/上下连续，有限版）**：A₁ ⊂ A₂ ⊂ …
递增，则 P(⋃ₙAₙ) = lim P(Aₙ)（证明用不交塔 + 几何级数型
求和）。它告诉你概率对"取极限"守规矩——可数可加性的
另一种说法。

## 02.6 机器通道：公理的第一次落地

**Prolog（`02_axioms.pl`）——小宇宙穷举**。取 Ω = {1,2,3,4}
的玩具空间（每个子集有显式概率），程序做三件事：① 枚举
16 个子集验证补律与单调性（任意 A ⊂ B 都检查 P(A) ≤ P(B)）；
② 对所有 (A,B) 对验证容斥二项版——256 种组合逐一过账，
"加两次减一次"在穷举面前无歧义；③ De Morgan 律的集合
恒等式验证（并补翻转），把 02.3 的编码离题做满。穷举的
哲学：**公理的推论在小宇宙上成立，靠的不是证明而是
数——而数恰恰是计算机最不会错的事**。

核心谓词先把事件表示成点的列表，再逐点累加概率：

```prolog
prob([], 0).
prob([X | Xs], P) :- p_prob(X, Q), prob(Xs, R), P is Q + R.

check_inclusion_exclusion :-
    Omega = [1, 2, 3, 4],
    forall((subsets(Omega, A), subsets(Omega, B)),
           (union(A, B, AuB), inter_list([A, B], Omega, AiB),
            prob(A, P), prob(B, Q), prob(AiB, R), prob(AuB, U),
            U is P + Q - R)).
```

`forall/2` 不是“尝试一个例子”，而是要求所有 256 对事件都成功；
交集被多算一次，所以右端必须减去 `R`。

**Python（`02_axioms.py`）——精确分数的定律实验**。骰子
空间 Ω = {(i,j)}（36 点等概率）上：① P(A ∪ B) 的容斥
账（A = "首骰 6"、B = "次骰 6"：11/36 = 1/6 + 1/6 − 1/36
的精确分数）；② 全概率两块版（B = "首骰为偶"）的逐项
核对；③ Boole 不等式在三事件并上的"保守度测量"
（上界与真值的间隙）。`Fraction` 让每个数字都是精确的
有理数——公理的推论在数字层面零误差。

容斥账的关键只有三行：先枚举 36 个等概率结果，再把事件谓词
传给概率函数：

```python
OMEGA = list(product(range(1, 7), repeat=2))
P = lambda A: Fraction(sum(1 for s in OMEGA if A(s)), 36)

lhs = P(lambda s: A(s) or B(s))
rhs = P(A) + P(B) - P(lambda s: A(s) and B(s))
assert lhs == rhs == Fraction(11, 36)
```

`or` 计算并集，`and` 计算交集；`11/36 = 1/6 + 1/6 − 1/36`
不是浮点近似，而是有理数相等。

**Julia（`02_axioms.jl`）——频率视角**。把同一骰子空间
模拟十万次：经验频率验证补律（freq(A) + freq(Aᶜ) ≈ 1 到
第三位小数）、容斥（freq(A∪B) ≈ freq(A)+freq(B)−freq(A∩B)）。
频率不是概率，但大数定律（第 18 章）保证它们越靠越近
——本章先享受这个事实，18 章再证明它。

```julia
samples = [(rand(1:6), rand(1:6)) for _ in 1:N]
freq(A) = count(A, samples) / N

fA, fB = freq(A_first6), freq(B_second6)
fAiB = freq(s -> s[1] == 6 && s[2] == 6)
fAuB = freq(s -> s[1] == 6 || s[2] == 6)
@assert abs(fAuB - (fA + fB - fAiB)) < 0.001
```

这里断言的是固定样本下的近似，不是概率恒等式；它和 Python 的
精确分数互为“直觉”和“终审”。

**Lean（`Ch02Axioms.lean`）——公理的证明器原文**。mathlib
的 `MeasureTheory.Measure` 就是三公理的化身（`measure_
mono`、`measure_compl`、`measure_union` 分别是 02.D/B/E 的
机器版）。本章 Lean 单元登记这些引理名并用小例子实例化：
在两点均匀空间上，P(A ∪ B) 的账由 `measure_union` 一步
收割。Isabelle 侧（MT02 会话）同样登记 `measure_union`/
`measure_compl` 的 HOL 版——**两套公理系统，同一组免费
午餐**。

## 02.7 要点回顾

1. 公理三行（非负/规范/可数可加）生出全部基本定律——
   概率论是"最少的假设，最多的免费午餐"的典范。
2. 补律 = 取补策略的合法性；容斥减项 = 重叠的会计学；
   Boole = 无结构时的保守上界。
3. 无限样本空间的"等可能均分"不存在（悖论一）；建模
   歧义要靠显式写下 (Ω, P) 来消除（悖论二）。
4. De Morgan 律是口语与集合论之间的翻译器。
5. σ-代数是门内的世界：本章只看一眼（不可数并的可加性
   只对"良民集合"承诺）——跨门见《测度论教程》。
6. 机器通道分工：穷举（Prolog）溶解悖论、精确分数
   （Python）判数字、频率（Julia）养直觉、证明器
   （Lean/Isabelle）管"永远不错"。
