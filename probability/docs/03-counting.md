# 03 计数基础：阶乘与二项系数

**对应 Miller ch3.1（pp. 98-106）。**

古典概型把概率化归为计数（第 02 章）：P(A) = |A|/|Ω|。
本章造计数的两件基本工具——**阶乘**（排列的账）与**二项
系数**（组合的账），并把"什么时候用哪个"练成条件反射。

## 03.1 阶乘：排列的语言

**定义 03.A**。n! = n·(n−1)·…·2·1（约定 0! = 1）。它的
组合身份：**n 个不同物件排成一列的方式数**。为什么？第一
个位置 n 选，第二个 n−1 选……乘法原理（分步相乘）直接给
出连乘。

**乘法原理**（全书最常用又最易错的原则）：做一件事分 k 步，
第 i 步有 mᵢ 种做法且步与步独立，则总数 = m₁·m₂·…·mₖ。
**错误的兄弟是加法原理**（分类相加）——分步还是分类，
读题时先问自己这一句。第 01 章生日问题的"第 j 人避开前
j 人"正是乘法原理的连乘现场。

**子阶乘（derangement，错排）预告**：Dₙ = 恰好没有一封
信装对的装法数。它的闭式（Dₙ = n!·Σ(−1)ᵏ/k!）与渐近值
（Dₙ/n! → 1/e）是第 06 章容斥原理的招牌应用——这里先挂
账，容斥章回来收割。

## 03.2 二项系数：组合的语言

**定义 03.B**。C(n, k) = n!/(k!(n−k)!)（记号也作 C(n,k) 或
n-取-k）。组合身份：**从 n 个不同物件中不计顺序地选 k 个
的方式数**。

**为什么要除以 k!**：先把"选人"当排列算（n·(n−1)·…·
(n−k+1) = n!/(n−k)! 种），但同一组 k 人被数了 k! 次（组内
随便排序都是同一次选择）——除掉重复。**"先算多再除重"**
是计数的核心手法，第 04 章扑克牌型会反复用它。

**对称与边界**：C(n,k) = C(n,n−k)（选 k 个 = 挑走 n−k 个
的补）；C(n,0) = C(n,n) = 1；k > n 时 C(n,k) = 0。

**Pascal 三角**（递推）：

  C(n, k) = C(n−1, k−1) + C(n−1, k)

推导的故事版：从 n 人里选 k 人的方案，按"包含某指定的人
甲"分类——含甲则其余 k−1 人从 n−1 人选（C(n−1,k−1)），
不含甲则 k 人全从 n−1 人选（C(n−1,k)）。加法原理一行
收官。这个"**盯住一个元素分类**"的技巧是二项恒等式的
母机（第 07 章会系统化）。

**代数推导**（不用故事，纯分数恒等）：把
C(n−1,k−1) + C(n−1,k) 通分即得 C(n,k)——两行分数加法。
Miller 的教学立场：**故事推导与代数推导都过一遍**，前者
给你直觉，后者给你确信。

## 03.3 二项定理与恒等式速成

**二项定理**：(x + y)ⁿ = Σₖ C(n,k) xᵏ yⁿ⁻ᵏ。展开式的每
一项对应"n 个因子里选 k 个出 x"的选择——C(n,k) 正是选择
数。两个.instant 推论：取 x = y = 1 得 Σₖ C(n,k) = 2ⁿ
（n 元集的子集总数——二项系数的和的计数身份）；取 x = 1、
y = −1 得 Σₖ (−1)ᵏC(n,k) = 0（偶数项和 = 奇数项和——
容斥的影子）。

**规模感**（数值实验的培养）：C(52,5) = 2,598,960（五张
牌的手数——第 04 章的分母）；C(23,2) = 253（生日问题的
配对数——第 01 章的直觉修正）；2⁵² ≈ 4.5×10¹⁵（52 张牌
的排列数——比"从宇宙大爆炸每秒排一次"还多）。**先有数量
级，再谈精确**——Miller 的 Numerical Test 传统。

## 03.4 计数的三大陷阱

**陷阱一：顺序幻觉**。"从 10 人选 3 人当委员"是 C(10,3)；
"选主席、秘书、财务各一人"是 10·9·8——同一群人，岗位
**不同**则顺序有义。读题关键词：名单/委员会（无序）vs
排名/分奖（有序）。

**陷阱二：重复计数**。"抛 3 次硬币恰好 2 正"：错误的
C(3,2)·2（把正面的位置与反面的位置分开数再乘）多算了；
正确 C(3,2) = 3 种位置组合。**数了两遍的账除以重复度**
——错排公式的 k! 同款。

**陷阱三：漏减交叠**。两个条件都满足的对象被两个类各数
一次——第 02 章容斥二项版的计数版预告（第 06 章的主场）。

## 03.5 机器通道

**Lean（`Ch03Counting.lean`）**：mathlib 的 `Nat.choose`
就是 C(n,k)，本章登记三件：① Pascal 递推的机器版
`Nat.choose_succ_succ`；② 二项定理 `add_pow_le`?——
正式名 `Nat.add_pow_eq_pow_sum`? 直接用 `choose_sum`
（Σ C(n,k) = 2ⁿ）与 `choose_eq_zero_of_lt`（k > n 为零）；
③ **实弹**：C(52,5) = 2598960 与 C(23,2) = 253 的
`decide` 判决（第 04 章分母与生日配对数的机器原文）。

**Python（`03_counting.py`）**：`Fraction` 精确账——①
Pascal 递推的表验证（C(n,k) 表与直接分数公式逐格相等，
n ≤ 15）；② 二项定理恒等式（x = 2, y = 3, n = 8 的两侧
分数相等）；③ 陷阱实验：10 人选 3 委员 = 120 vs 三岗位
= 720 的倍数关系（3! = 6 倍——"先算多再除重"的数字形态）。

**Julia（`03_counting.jl`）**：模拟对拍——① 随机洗牌验证
52! 的可采样性（不重要，暖场）；② 三次抛硬币恰好 2 正的
模拟频率 vs 3/8（陷阱一的现场：错误直觉常猜 1/3）；③
10 人随机选 3 人的所有结果枚举次数（组合的枚举验证）。

**Prolog（`03_counting.pl`）**：小宇宙穷举——① 4 个物件
的排列表（4! = 24 全枚举）与 3-选-2 的组合表（C(4,2) = 6
全枚举，顺序去重的实际代码化）；② Pascal 递推的表填充；
③ 抛 3 硬币样本空间的 8 元枚举与"恰 2 正"的 3 元子集
（陷阱一的穷举溶解）。

## 03.6 要点回顾

1. 乘法原理（分步相乘）与加法原理（分类相加）——先分清
   步与类再动笔。
2. 排列 n!/(n−k)!（有序）vs 组合 C(n,k)（无序）——同门
   相差一个 k!（组内顺序的去重）。
3. Pascal 递推 = 盯住一个元素分类；二项定理 = 展开式的
   计数读法。
4. 三陷阱：顺序幻觉、重复计数、漏减交叠。
5. 数量级先于精确：C(52,5) ≈ 2.6M、2⁵² ≈ 4.5e15。
6. 机器分工：Lean 的 Nat.choose 判决、Python 的精确表、
   Julia 的频率、Prolog 的全枚举。
