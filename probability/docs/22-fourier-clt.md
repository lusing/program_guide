# 22 Fourier 分析与 CLT：特征函数的正宫之路

**对应 Miller ch21（pp. 567-581）。**

MGF 有两个软肋：可能不存在（Cauchy）、唯一性要复分析
黑箱。**特征函数** φ(t) = E[e^{itX}] 两症全治：|e^{itX}| = 1
恒存在；Fourier 反演定理给严格唯一性。本章：积分变换
总览、**卷积定理**（Fourier 把卷积变乘法——第 11 章
伏笔的正式收割）、以特征函数重走 CLT。

## 22.1 积分变换：核的代数

**积分变换**：(Kf)(y) = ∫f(x)K(x,y)dx——核 K 定家族：

- **Laplace**：K = e^{−ts}，(Lf)(s) = ∫₀^∞ f(t)e^{−st}dt；
- **Fourier**（本书记号）：f̂(y) = ∫f(x)e^{−2πixy}dx。

**约定警告**：e^{−ixy}、e^{−ixy}/√(2π)、e^{−2πixy} 三大流派——
查资料先对表。e^{iθ} = cosθ + i·sinθ（Taylor 级数的账）。
MGF 是密度的 Laplace 变换（t = −s）；**特征函数是 Fourier
变换的换装**（φ(t) = f̂(−t/2π)）——"差一个 i，行为天壤"。

**Schwartz 空间** S(ℝ)：无穷可微 + 多项式加权速降。正态
密度在 S(ℝ)（e^{−x²/2} 压过任何多项式——第 16 章的
"借衰减"技术）。**反演定理**：f ∈ S(ℝ) 则 f(x) = ∫f̂(y)
e^{2πixy}dy；特别地 **f̂ = ĝ ⟹ f = g**——第 21 章欠的
唯一性票据在此兑付。

## 22.2 特征函数：恒存在的 MGF

**定义**：φ_X(t) = E[e^{itX}]。**存在性一行**：|φ(t)| ≤
∫|e^{itx}|f(x)dx = ∫f = 1（Pythagoras：|e^{itx}|² = cos² +
sin² = 1）。**基本性质**：φ(0) = 1；φ_{aX+b}(t) = e^{itb}
φ_X(at)；独立和相乘 φ_{X+Y} = φ_X·φ_Y（与 MGF 同构，
但无存在域焦虑）。

**常用表**：标准正态 φ(t) = e^{−t²/2}（**自反**！Gaussian
的 Fourier 变换还是 Gaussian——不确定原理的边界钉子）；
Unif(0,1) 的 e^{it/2}sinc(t/2)；Cauchy 的 e^{−|t|}；Poisson
的 exp(λ(e^{it}−1))；Exp(λ) 的 1/(1−iλt)。

**矩的读取**：φ⁽ⁿ⁾(0) = iⁿμ'_n（存在时）——i 的幂次
是唯一与 MGF 的差别。

## 22.3 卷积定理：Fourier 的杀手锏

**定理**：f̂∗ĝ = f̂·ĝ（**卷积的 Fourier 变换 = 变换的乘积**）。

证明的 Fubini 换序 + 换元 u = x−t。**密度卷积**（第 11
章 f_{X+Y} = f_X ∗ f_Y）由此变身 **φ_{X+Y} = φ_X·φ_Y**——
"难积分变易乘法"的承诺完整兑现；第 20 章母函数卷积
定理是同一件事的幂级数皮肤。反演回去才要付代价
（这是 Fourier 世界与母函数世界的分工：变换域便宜、
回程收费）。

## 22.4 特征函数版 CLT

φ_{Z_N}(t) = [φ_Y(t/√N)]^N（Y 标准化单变量）。Taylor：
φ_Y(u) = 1 − u²/2 + O(u³)（注意符号：i² = −1 使二阶项
**负**——正态 e^{−t²/2} 的负号来历），故

φ_{Z_N}(t) = (1 − t²/(2N) + O(N^{−3/2}))^N → **e^{−t²/2}**

——标准正态的特征函数。反演定理（22.1）补最后一脚：
特征函数收敛到正态 ⟹ 分布收敛到正态。**与 21.4 的
平行对照**：骨架全同，只是 e^{+t²/2} 换 e^{−t²/2}（MGF ↔
特征函数的 i 之差）、唯一性黑箱换成了 Fourier 反演的
白箱。Cauchy 也在此结案：φ_Cauchy(t) = e^{−|t|}，其和
的 φ = e^{−2|t|} = φ_{2×Cauchy}——**稳定但不正态**，CLT
的重尾反例（MGF 流水线在它身上根本无法启动，特征
函数路线则看得清清楚楚）。

## 22.5 机器通道

**Python（`22_fourier_clt.py`）**：① 特征函数的数值积分
vs 闭式表（正态 e^{−t²/2}、Unif 的 sinc、Cauchy 的 e^{−|t|}）；
② 卷积定理的数值验证：两个密度的数值卷积的 Fourier
变换 vs 变换乘积（或等价地：反演回程对照）；③ CLT 的
特征函数现场：三族 φ_{Z_N}(t) vs e^{−t²/2} 的逐点收敛表；
④ Cauchy 稳定性的 φ 账（e^{−|t|}² = e^{−2|t|}）与和的模拟
分布对照；⑤ |φ(t)| ≤ 1 的数值核查。

**Julia（`22_fourier_clt.jl`）**：① 特征函数的蒙特卡洛
估计 E[e^{itX}]（复平均）vs 闭式（正态/均匀/柯西三族，
实虚双部）；② CLT 现场双版：标准化和的经验特征函数
vs e^{−t²/2}（比直方更细的收敛判据）；③ Cauchy 稳定与
发散的复特征函数对照；④ Box-Muller 生成器（两个均匀
造正态——极坐标技巧的回马枪）的直方 vs φ。

## 22.6 要点回顾

1. 特征函数 = 密度的 Fourier 变换（约定差一标度）；
   |e^{itX}| = 1 ⟹ **恒存在**——MGF 的两症全治。
2. 反演定理（Schwartz 空间）兑付唯一性支票；f̂ = ĝ
   ⟹ f = g。
3. **卷积定理** f̂∗ĝ = f̂·ĝ：独立和的 φ 相乘——第 11 章
   "卷积变乘法"的正式兑现。
4. CLT 特征函数版：φ_Y(t/√N)^N → e^{−t²/2}（i² = −1
   的负号）；Cauchy 的 e^{−|t|} 平行对照——稳定但非
   正态的重尾哨兵。
5. Gaussian 的 Fourier 自反性：钟形是变换域的不动点。
