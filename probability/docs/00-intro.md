# 00 经济随机系统与统计推断

这本教程把概率论作为一门**建模与推断的语言**来讲，而不是把它讲成
公式清单。我们会从随机试验、事件、条件概率和独立性出发，经过随机
变量、分布族、抽样分布、大数定律和中心极限定理，最后到达参数估计、
假设检验与经典线性回归。终点不是“会算几道概率题”，而是能回答一类
贯穿经济学、金融学和数据科学的问题：

- 观测到一组数据之后，怎样描述产生它们的数据生成过程；
- 在不确定性下，什么叫一个好的估计、检验或预测；
- 一个统计结论依赖哪些假设，这些假设失效时会错在哪里；
- 机器证明、精确穷举、数值验证和随机模拟分别能保证什么。

本书融合两条主线。第一条主线强调概率训练中的基本功夫：有限样本空间、
计数、变换、生成函数和中心极限定理的完整证明。第二条主线强调经济
统计分析：经济随机系统、数据生成过程、条件期望、矩估计、极大似然、
GMM、假设检验和线性回归。二者不是上下篇的拼贴；现代计量经济学的
大多数核心论证都以前半部分的概率工具为基础。

## 00.1 描述统计与推断统计

统计学首先是一种把大量信息压缩成可理解信息的方法。消费者价格指数、
失业率、均值、方差、分位数、相关系数和回归系数，都是在对观测数据
进行归纳。只处理已有数据、不主动外推的部分称为**描述统计**。

描述统计回答“数据中看见了什么”。例如：

- 过去十年中国年度 GDP 增长率的平均值是多少；
- 一个投资组合日收益率的波动有多大；
- 样本中受教育年限与收入之间的相关方向是什么；
- 某城市住房价格的中位数和 90% 分位数相差多少。

**推断统计**则更进一步。它把观测数据视为某个未知随机机制的一次实现，
试图由样本反推出总体或数据生成过程的性质。它回答的问题包括：

- 一枚硬币是否公平；
- 一种新药是否比安慰剂更有效；
- 股票收益率是否存在可由历史信息预测的部分；
- 教育回报率的置信区间是多少；
- 一个经济政策在控制其他因素后是否有显著作用。

描述统计可以非常有用，但它不自动提供不确定性的度量。仅报告样本均值，
并没有说明换一个样本后均值会变动多少；仅看见两个变量相关，也不能
直接推出因果关系。概率论正是给“样本为何会波动、波动多大、何种条件
下估计量会收敛、检验为何会犯错”提供数学语言。

## 00.2 经济随机系统与数据生成过程

经济数据通常不是物理实验中由研究者完全控制的结果。消费者、企业、
政府、金融市场和国际环境同时行动，观测到的价格、产出、就业、利率和
收益率是许多因素相互作用后的结果。一个基本建模观点是：

1. 经济系统可以视为服从某种概率法则的随机试验或随机过程；
2. 每个经济现象的观测值，都是这个随机试验的一次结果。

这个随机机制常称为**数据生成过程**（Data Generating Process, DGP）。
例如一组月度通胀率可以写成

\[
Y_t=m(X_t,\beta,\varepsilon_t),
\]

其中 \(X_t\) 是可观测条件，\(\beta\) 是未知参数，\(\varepsilon_t\)
汇总了不可观测冲击、省略因素和测量误差。统计与计量分析的目标，是用
可观测的 \((Y_t,X_t)\) 学习未知的 \(m\)、\(\beta\) 或条件分布。

“视为随机系统”并不等于声称经济主体的行为“没有原因”。它的意思是：
在建模者当前信息集下，未来结果不能被完全预测，因而用概率分布描述
未知性是富有操作性的。信息增加后，原来的随机变量可能可以被进一步
解释。今天的天气对只有历史气温数据的人是随机的；对拥有更多大气观测
和更精细模型的人仍然不完全确定，但不确定性的分布会改变。

这也解释了为什么**条件概率和条件期望**是经济统计的核心。资产定价、
预测、滤波、分类、回归和 GMM 都可理解为：在给定信息集后，概率分布
或期望如何更新。

## 00.3 为什么经济统计需要概率论

经济变量的一个基本特征是不可预先知道的波动性或变异性。收益率会波动，
消费会受收入和预期影响，失业率会随产业结构和政策变化，企业投资回报
也不可能在决策时完全确定。概率模型至少承担五项任务。

第一，它把经验事实表达为分布关系。通胀率与失业率的联合分布、资产
收益率的厚尾程度、波动聚集现象，都不是只靠一张表格就能讲透的。

第二，它提供从样本到总体的推断规则。调查一万个人并不等于知道所有
人的偏好；观测二十年的年度 GDP 也不等于知道未来增长率的真实分布。
概率模型说明在什么条件下样本信息能外推、外推误差有多大。

第三，它把风险量化。期望收益不能单独描述一个投资组合；方差、下行
风险、破产概率和风险价值刻画了不同方面。相同期望值的两个随机收益
可能有完全不同的风险含义。

第四，它使动态决策成为可能。经济行动的结果常常在未来出现，决策者
必须基于历史信息预测未来。随机过程、条件期望和时间序列模型给出了
“今天已知的信息如何影响明天的预测”的形式语言。

第五，它帮助研究者辨别关系与因果。两个事件同时变化并不意味着一个
导致另一个。条件概率可以描述预测关系，但因果解释通常还需要经济理论、
实验设计、外生变化或可辩护的识别假设。

## 00.4 IID 假设：有用的起点，不是世界的全貌

入门概率中最常见的假设是独立同分布（IID）：重复试验彼此独立，并且
服从同一个概率分布。掷均匀硬币、从充分混合的牌堆中有放回抽牌、从
固定总体中随机抽样，都可以近似看作 IID。

IID 是一个强有力的简化。独立使联合概率可以相乘，同分布使多次观测
提供关于同一参数的重复信息。大数定律和中心极限定理的经典版本大多
从 IID 开始；没有这个起点，统计学会难学得多。

但经济数据经常违反 IID。今年的 GDP 和去年的 GDP 不独立，金融危机
期间的收益率会出现波动聚集，消费者偏好和技术会随时间变化，不同地区
或企业之间也可能存在联动。因此本教程采取两层态度：

- 在入门阶段用 IID 建立核心直觉和可证明的基准；
- 在渐近理论、随机过程和回归部分明确讨论依赖、异质性、条件期望和
  稳健推断，说明哪些结论可以推广，哪些不能。

还必须看到经济观测数据的另外几个限制。经济过程往往不可逆，2008 年
的年度 GDP 只有一个实现值，不能让同一年在相同条件下重复一千次。
经济结构会随政策、技术、人口和制度变化。许多宏观变量存在测量误差，
地方汇总与全国核算也可能口径不同。统计结论的可信度取决于假设对真实
数据生成过程的近似程度。

## 00.5 随机游走与确定性混沌：零相关不是无关

金融中的几何随机游走常写成

\[
\ln P_t=\ln P_{t-1}+X_t,\qquad
X_t=\ln(P_t/P_{t-1}),
\]

其中 \(X_t\) 表示对数收益率。若各期增量跨期独立，那么过去价格路径
不能用于预测未来增量的分布；在这个理想化意义下，市场关于历史价格
信息是有效的。注意，这并不意味着价格本身独立，也不意味着经济中没有
因果结构；它只针对某类基于历史价格的简单预测。

另一个看起来同样“杂乱”的过程是 logistic 确定性映射：

\[
x_t=4x_{t-1}(1-x_{t-1}),\qquad x_0\in(0,1).
\]

它没有任何随机冲击。给定 \(x_{t-1}\)，下一个值被完全决定。然而参数
为 4 时，轨道对初值极度敏感，长期样本的散点图和滞后相关系数可能看
起来很像随机噪声。

下面的程序比较二者的一阶滞后样本相关系数。相关系数只衡量线性关联，
不能识别所有依赖关系。完整可运行文件是
`examples/python/00_intro.py`：

```python
def lag1_corr(x):
    n = len(x) - 1
    u, v = x[:-1], x[1:]
    mu, mv = sum(u) / n, sum(v) / n
    cov = sum((a - mu) * (b - mv) for a, b in zip(u, v))
    su = sum((a - mu) ** 2 for a in u)
    sv = sum((b - mv) ** 2 for b in v)
    return cov / (su * sv) ** 0.5

def logistic_series(x0, n=20000):
    x = x0
    out = [x]
    for _ in range(n - 1):
        x = 4.0 * x * (1.0 - x)
        out.append(x)
    return out
```

程序对五个初值分别生成 20000 个 logistic 轨道点，再用固定随机种子
生成 20000 个独立高斯增量。固定种子是为了让结果可以逐位复现；它
仍然是模拟，不是证明。实际输出为：

```text
==== 00 intro
logistic x0=0.1      lag1 corr = -0.007850586909
logistic x0=0.2      lag1 corr =  0.000437007035
logistic x0=0.3      lag1 corr = -0.005155145948
logistic x0=0.7      lag1 corr = -0.006089372509
logistic x0=0.123456 lag1 corr =  0.003380791954
i.i.d. Gaussian steps seed=7 lag1 corr = -0.007855816368
logistic is deterministic: next value equals 4*x*(1-x) exactly
END ====
```

这些接近零的数字说明两件事。

1. 独立高斯增量的样本滞后相关接近零，这是意料之中的。
2. logistic 轨道的样本滞后相关也接近零，但 \(x_t\) 是 \(x_{t-1}\) 的
   确定性非线性函数。只要精确知道当前值和映射，下一个值完全可知。

因此，**零相关不等于独立，更不等于不可预测**。相关系数只检验一种
线性关系；独立性要求整个联合分布等于边际分布的乘积，条件要强得多。
后面我们会反复看到这个区分：不相关的随机变量可能函数相关，联合正态
下零相关才等价于独立，均值独立也不等同于完全独立。

这个例子也是全教程的方法论预告：看见一个数值结果时，先要问它验证的
是什么命题。模拟频率接近理论值，不能代替定理证明；一个相关系数接近
零，不能推出任意预测函数都无效。

## 00.6 五种机器证据，强弱不同

本教程使用五条可执行通道，但它们承担的认识论角色不同。

**Lean 4 + mathlib4** 是主证明通道。它把定义、定理和证明交给证明器
检查。证明通过意味着在给定公理、定义和库定理正确的前提下，命题的
逻辑推导成立。

**Isabelle/HOL** 是第二证明通道。它使用另一套形式系统和概率库。
关键结论在两个独立证明系统中都成立，可降低单一库或单一形式化口径的
风险。

**Python + SciPy** 主要承担精确有理数、有限穷举和标准数值计算。
`Fraction` 可以让生日问题、Bayes 公式和组合概率以精确分数通过，
避免浮点误差伪装成数学结论。

**Julia** 主要承担高频模拟、随机实验和数值近似。十万次 Monty Hall、
一百万次生日实验和蒙特卡洛积分能培养直觉，但必须固定种子、说明重复
次数，并把结果称为模拟证据。

**Prolog** 承担有限世界的逻辑穷举。Monty Hall 的合法路径、牌型计数、
小样本空间上的集合恒等式，都可以逐条生成并检查。穷举只对被枚举的
有限空间有效，不能自动证明无穷总体上的命题。

我们把证据强度分成四层：

1. **机器证明**：由 Lean 或 Isabelle 检查逻辑推导；
2. **精确穷举**：有限空间中每种可能性都检查到；
3. **精确符号或有理数计算**：公式两边以精确符号或分数相等；
4. **确定性数值验证或随机模拟**：支持直觉，但不替代证明。

随机模拟尤其不能冒充证明。模拟 100000 次硬币只给频率和误差范围；
它不能证明无穷序列的极限恰好是 1/2。极限命题需要大数定律。反过来，
证明也不能代替建模：一个定理在假设 A 下绝对正确，并不说明真实市场
满足 A。

## 00.7 全书路线

第 01–04 章建立概率空间、公理、条件概率和独立性。第 05–07 章讨论
有限实验中的计数与容斥。第 08–16 章进入一元随机变量：期望、变换、
不等式、常用分布、生成函数和卷积。

第 17–23 章研究多元随机结构与抽样：联合分布、Jacobian、协方差、
条件期望、多元正态、χ²/t/F 分布和充分统计量。第 24–30 章是随机
序列与渐近理论：Markov 链、四种收敛模式、大数定律、中心极限定理、
Fourier 方法、Slutsky、Delta 方法和 Stirling 公式。

第 31–37 章进入统计推断：参数模型、极大似然、矩估计与 GMM、有效性、
Cramér–Rao 下界、渐近估计、Neyman–Pearson 检验以及 Wald、LM、LR
检验。第 38–41 章是经典线性回归：OLS 的投影几何、Gauss–Markov、
t/F 推断、线性约束、遗漏变量和 GLS/WLS。最后第 42–43 章综合案例与
定理地图，把全书方法串起来。

阅读时不必把所有符号一次记住。每章都会重新交代所需定义，重要定理会
给出条件、推导链条和使用边界。公式不是装饰品：我们会说明每个条件在
哪一步被使用，缺少它会出现什么反例。

## 00.8 本章要点

1. 概率论研究不确定现象的数学结构，统计学根据数据推断未知分布或参数。
2. 经济系统可被建模为随机过程，观测值来自由概率法则支配的数据生成
   过程；这是一种建模范式，不是对自由意志或因果性的否定。
3. IID 是重要基准，但经济数据常含依赖、异质性、结构变化和测量误差。
4. 几何随机游走与 logistic 混沌都可能产生接近零的一阶滞后相关；后者
   完全确定，说明零相关不等于独立。
5. 机器证明、精确穷举、有理数计算、数值验证和模拟是不同强度的证据。
6. 统计关系不是自动的因果关系；推断的有效性取决于模型假设。
