# 00 导言：概率论的救生圈与五通道

**对应 Miller《The Probability Lifesaver》前言与 How to use the
Book（pp. 13-20）。**

这本教程以 Steven J. Miller 的 *The Probability Lifesaver*
（Princeton University Press，2017）为纲——一本特别的概率论
教材：它不假设你见过任何概率论，却在入门的每个关口给出**完整
的证明**而非"显然"；它从生日问题与扑克牌开始，却在二十几章后
带你走完中心极限定理的证明与 Fourier 分析。书名里的"救生圈"
是认真的：大多数教材教你游泳，这本书在你下沉的每个位置都放了
一个浮标。本教程的目标是把这本书的完整旅程用中文重走一遍——
**全部内容自包含**，只读这里的正文就能学会，不需要回看原书。

## 00.1 这本书（与这本教程）的三个特质

**第一，直觉先行，证明殿后。** 每个主题从具体问题进入（生日
撞车、投篮得分、扑克牌型、赌场对冲），先把"答案应该长什么样"
的手感建立起来，再把严格陈述与证明补齐。Miller 的顺序是：
例子 → 猜想 → 验证 → 推广。本教程保持这个顺序——你会先算
23 个人里两人生日相同的概率超过一半（并且用代码模拟确认），
然后才见到一般公式。

**第二，计算是第一公民。** 原书几乎每章都有 Numerical Test
（数值检验）小节——用计算机验证手算的答案。本教程把这个
特质放大成**五条机器通道**（00.3 节）：模拟、精确分数、
定理证明器全部上场。概率论恰好是最适合"数值对拍"的数学：
样本空间是具体的，概率是可以枚举的，大数定律本身保证了模拟
必然收敛到理论值。

**第三，难点的台阶极密。** 别的教材一步跨过的沟（为什么
σ-代数长这样、Stirling 公式的常数从哪来、CLT 的证明为什么要
截尾），这本书都垫了石头。附录 A 里甚至有"如何读一个证明"
与十一种证明技术的专门训练。本教程的 26 章会把这些台阶
原样保留。

## 00.2 全书地图（四部分 + 杂题）

Miller 原书 25 章 + 四个附录，教程按主题重组为 28 章：

| 篇 | 教程章 | 主题 | 你将学会 |
|---|---|---|---|
| 导言 | 00 | 地图与工具链 | 这本书怎么用 |
| I 一般理论 | 01-07 | 招牌问题/公理/计数/条件概率/Bayes/容斥/高级组合 | 概率的语言与计数 |
| II 随机变量 | 08-12 | 离散与连续 RV/期望/卷积换元/微分恒等式 | 把随机性变成函数 |
| III 分布族 | 13-17 | 离散五族/均匀指数/正态/Γ 家族/卡方 | 概率论的"元素周期表" |
| IV 极限定理 | 18-22 | 不等式与 LLN/Stirling/母函数/CLT 证明/Fourier | 大数世界的定律 |
| 杂题 | 23-26 | 假设检验/Markov/最小二乘/著名问题/证明十一式 | 概率的工程应用 |

原书四个附录的处理：附录 A（证明技术十一式）升格为教程

（可数与不可数）融入第 02 章（σ-代数的动机）；附录 D 同理。

## 00.3 五条机器通道

本教程的每个主题都配机器验证。五条通道分工如下：

**Lean 4 + mathlib4（主证明通道）**。定理证明器里"概率为零
不可能出错"是字面意思。本科概率的主干在 mathlib 里 surprisingly
齐全：计数（`Nat.choose`、`Finset.card`）、二项/几何/Poisson/
正态/指数分布（`ProbabilityTheory` 命名空间）、Markov/Chebyshev
不等式（`mul_meas_ge_le_pow_eLpNorm'`）、强大数定律与中心极限
定理（`strong_law_ae`、`tendstoInDistribution_inv_sqrt_mul_sum_
sub`）。本教程的 Lean 单元**不要求读者先学 Lean**——每个证明
的骨架在正文里用白话讲解，Lean 代码是"可以运行的证明卡片"。

**Isabelle/HOL（第二证明通道）**。HOL-Probability 是另一套
成熟的概率形式化（含 `central_limit_theorem`）。它出场较少，
但在关键节点（公理结构、条件概率、CLT）提供第二意见——
两个互不相干的系统对同一定理给出证明，是最强的正确性证据。

**Julia（模拟通道）**。概率论的自然实验场：生日问题模拟
一百万次、扑克牌发十万手、正态分布画直方图。Julia 的循环
快、语法近数学，是把"大数定律"从定理变成体验的工具。

**Python（精确通道）**。`fractions.Fraction` 让每个概率账都
是**精确分数**：23 人生日问题的答案不是 0.5073 的浮点近似，
而是分子分母都是确切整数的分数。模拟（Julia）给直觉，
精确（Python）给判决。

**Prolog（穷举通道）**。有限样本空间上，概率 = 计数——
而计数正是逻辑程序的母语。"三囚徒问题"（Monty Hall 的
前身）在 Prolog 里是十几行的穷举程序，每一条路径打印出来，
悖论瞬间解开。Prolog 单元是本书"paradox"（悖论）小节的
天然搭档。

## 00.4 怎么用这本教程

**只读正文**：每章 ≥200 行，所有代码在正文中引用并讲解，
不需要打开源文件；每章末尾的"对应示例"列出文件路径供
进一步把玩。

**验证一切**：在 `probability/` 目录下运行

```powershell
pwsh -NoProfile -Command '& ./build.ps1 -All'
```

全书所有机器单元（Lean/Isabelle/Julia/Python/Prolog）会被
逐一运行并对账——任何时候你的电脑上都可以重现"全绿"。

**动手实验**：每章的数值断言都是可以修改的。把生日问题的
23 改成 30，把扑克的手数从十万改成百万——修改、运行、
观察，这是 Miller 全书的精神。

## 00.5 预备知识清单

- **集合论**：交并补、De Morgan 律（第 02 章复习）；
- **微积分**：求导、积分、级数（用到时第 09 章起逐步复习，
  附录 B 的工具在使用处就讲）；
- **不需要**：测度论、实分析、任何编程经验。

与同仓库的《测度论教程》（`../measuretheory/`）的关系：
那本是研究生向（σ-代数语言、Radon-Nikodym、鞅、Lévy-Khinchin）；
这本是本科向（计数、分布族、CLT、检验）。两本独立可读，
先读哪本都行；读完这本再读那本，会在测度论里遇见"老朋友
的严格版"。

## 00.6 一页时间线（概率论从赌博到救生圈）

1654 年 Pascal 与 Fermat 的通信（点数问题）是起点；Jacob
Bernoulli 的《猜度术》（1713）给出大数定律；de Moivre（1733）
在析望表中瞥见正态曲线；Laplace（1812）的解析概率论集大成；
Chebyshev 与 Markov（19 世纪末）的不等式与矩方法把严格性
请进门；Kolmogorov（1933）的公理化把概率论安家测度论。
Miller 的书是这条线的入门段：前 6 章是 Pascal 与 Fermat 的
世界（计数与组合），中间是 Bernoulli 与 de Moivre 的世界
（分布与极限），末尾逼近 Kolmogorov 世界的门口（σ-代数
在第 02 章向你招手，但全书不跨过那道门）。
