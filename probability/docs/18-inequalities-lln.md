# 18 不等式与大数定律：从 Markov 到强弱律

**对应 Miller ch17（pp. 463-482）。**

精确概率常常算不动（分布难、或要问极限）——不等式给
"够用的范围"。本章三部曲：**Markov → Chebyshev → 弱大数
定律**的接力（每个新工具吃掉上一个的输出），加上收敛的
四种定义与强弱定律的分野。

## 18.1 为什么只知均值不够：Markov 的动机实验

想知道 P(X ≥ a)，只知道 μ = E[X]，能说什么？原书的
**反例扫描**：取 X ~ Unif(−c, c)，P(X ≥ 2) 可从 0（c ≤ 2）
爬到近 1/2；再造两点分布 P(X=2) = p、P(X=−b) = 1−p
（b = 2p/(1−p) 配平零均值），**p 可任意接近 1**——仅凭
均值，P(X ≥ 2) 无非平凡上界。病根：允许 X 取大负值。

两条出路：① 假设 **X ≥ 0**（Markov 路线）；② 假设**方差
有限**（Chebyshev 路线）。弱假设宽适用、弱结论——这个
权衡贯穿本章。

## 18.2 Markov 不等式：一行半的杠杆

**定理**：X ≥ 0、E[X] 有限，则 P(X ≥ a) ≤ E[X]/a。

**证明**（两个小戏法）：x ≥ a 处 1 ≤ x/a，于是

P(X ≥ a) = ∫ₐ^∞ 1·f(x)dx ≤ ∫ₐ^∞ (x/a)f(x)dx ≤ (1/a)∫₀^∞ xf(x)dx = E[X]/a。

**非负性用在哪**：最后一步把积分下界从 a 扩到 0——被积
xf(x) 在 [0,∞) 非负才能只增不减；扩到负半轴则可能变
小、不等号反向。反例：X = ±1 等概率，E[X] = 0，若结论
成立则 P(X ≥ 1/2) ≤ 0，荒谬。

**读法**：P(X ≥ ℓ·E[X]) ≤ 1/ℓ——"**至多 1/ℓ 的样本达到
均值的 ℓ 倍以上**"。收入例：均值 $60,000，则至多一半
家庭收入 ≥ $120,000，至多 6% 是百万富翁。a < E[X] 时
界 > 1 无信息（也理应如此：可以造出概率任意接近 1 的
例子）。界往往极松（真实概率常小几个量级）——**松是
弱假设的代价**。

## 18.3 Chebyshev：多付一个方差，多收一个平方

**定理**：P(|X − μ| ≥ kσ) ≤ 1/k²。

**证明一（Markov 的消费）**：对 W = (X−μ)² 用 Markov
——W ≥ 0、E[W] = σ²；P(W ≥ k²σ²) ≤ σ²/(k²σ²) = 1/k²。
平方比绝对值好（均值即方差，无需处理 |·| 的密度）。
**证明二（直接）**：|x−μ| ≥ kσ 处 1 ≤ ((x−μ)/kσ)²，积分
放大到全域（被积处处非负——与 Markov 的对比：那里
不能扩到负半轴，这里可以扩到全域）。

**k 的换算**：问"P(X ≥ ℓμ)"要先把距离折算成标准差
k = (ℓ−1)μ/σ。**经典错误现场**（原书故意踩坑）：均匀
[0,1] 的 σ² = 1/12，代入时误把 **σ² 当 σ**——k = 0.45/(1/12)
= 27/5 给出界 25/729 ≈ 0.034 **小于真值 0.05**（界居然
低于真值，矛盾暴露错误）；正确 k = 0.45/√(1/12) ≈ 1.56，
界 ≈ 0.41。

**正态对照**：k = 2/5/10 时 Chebyshev 给 25%/4%/1%，
标准正态真值 4.55%/0.000057%/10⁻²¹%——**弱假设的松**
触目惊心；要紧界需 CLT 或精细分布信息。大 ℓ 时
Chebyshev 的 C/ℓ² 衰减快于 Markov 的 C/ℓ——**多一个
矩，衰一个幂**。

**指数对照**：Exp(1) 的 P(X ≥ 4)：真值 e⁻⁴ ≈ 0.018；
Markov 0.25、Chebyshev 1/9 ≈ 0.111（都真但都松，后者
好 2 倍）。

## 18.4 Boole 与 Bonferroni：容斥的截断

容斥原理（第 06 章）是恒等式；**截断到奇偶项**得上下界：

- **Boole**：P(∪Aᵢ) ≤ ΣP(Aᵢ)（次可加，计数的上界）；
- **Bonferroni**：S₁ − S₂ ≤ P(∪Aᵢ) ≤ S₁；一般地截到
  2m−1 项为上界、2ℓ 项为下界（正项停则偏大、负项停则
  偏小）。

**四人全花色例**：P(某人 13 张同花) —— S₁ = 4·C(4,1)/C(52,13)，
配对项天文小，Boole 界已极准。容斥的"无限收敛级数"
变成了"要几位算几位"的工程账。

## 18.5 收敛的四种形态

- **依分布**（ weakest）：F_n(x) → F(x)（F 连续点处）。
  例：离散均匀 {0, 1/n, …, (n−1)/n} 的密度逐点 → 0 但
  CDF → x（Unif(0,1) 的 CDF）——密度不收敛、分布收敛，
  "弱"得名副其实；概率账走 CDF，故仍有用。
- **依概率**：P(|X_n − X| ≥ ε) → 0。例 Xₙ ~ N(1701,
  1/n²)：Chebyshev 给 P ≤ 1/(n²ε²) → 0。
- **几乎必然**：P({ω : X_n(ω) → X(ω)}) = 1（逐样本路径）。
- **必然**：所有 ϒ 无例外。

强度递增：必然 ⟹ 几乎必然 ⟹ 依概率 ⟹ 依分布。

## 18.6 弱大数定律与强大数定律

设 X̄_n = (X₁+⋯+Xₙ)/n（iid、均值 μ）。两级矩的**两行
账**：E[X̄_n] = μ、Var(X̄_n) = σ²/n。

**弱定律（WLLN）**：X̄_n →ᵖ μ。证明即 Chebyshev 的
三行消费：P(|X̄_n − μ| ≥ ε) ≤ σ²/(nε²) → 0。**接力链**：
Markov ⟹ Chebyshev ⟹ WLLN——一环吃一环。

**读法**：独立重复采样，样本均值以趋 1 的概率逼近总体
均值——**蒙特卡洛估计的合法性证书**（机器通道的每一次
模拟对拍都在使用它）。σ/√n 的衰减是"1/√n 律"：精度
翻倍要四倍样本。

**强定律（SLLN）**：X̄_n →ᵃ·ˢ· μ（逐路径收敛，证明需
更多分析，原书从略）。强蕴含弱。**注意**：定律只说均值
收敛；**个体点的概率仍趋零**（第 19 章 2n 次掷币恰 n 正
面的概率 ~ 1/√(πn) → 0）——收敛的是"质量往 μ 收拢"，
不是"概率峰留在原地"。

## 18.8 要点回顾

1. 只知均值无非平凡尾界（零均值两点族把概率推到 1）；
   非负性（Markov）或方差（Chebyshev）解锁非平凡界。
2. Markov：P(X ≥ a) ≤ E[X]/a（非负性护住积分放大）；
   Chebyshev：P(|X−μ| ≥ kσ) ≤ 1/k²（对平方用 Markov）。
3. 换算 k 时 σ 与 σ² 别混（0.45/(1/12) 的 27/5 事故：界
   低于真值即信号）。
4. Boole/Bonferroni = 容斥的截断（奇停上界、偶停下界）。
5. 收敛四级：依分布 < 依概率 < 几乎必然 < 必然；
   WLLN = Chebyshev 三行（1/√n 律），SLLN 更强。
