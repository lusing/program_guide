# 21 中心极限定理：为什么世界是钟形的

**对应 Miller ch20（pp. 541-566）。**

概率论的顶点：**独立同分布随机变量的标准化和收敛到
标准正态**——不论原来什么形状。本章：证明的路线图
（MGF 收敛 ⟹ 分布收敛）、标准化代数、Poisson 特例的
完整账、一般证明、以及 CLT 的使用规范。

## 21.1 证明路线图

设 X₁,…,X_N iid（均值 μ、方差 σ²），X̄_N 为均值，
Z_N = (X̄_N − μ)/(σ/√N)。**策略**：证 M_{Z_N}(t) →
M_Z(t) = e^{t²/2}（第 20 章正态 MGF），再由**唯一性**
（MGF 相等 ⟹ 分布相等）收官。

唯一性这步最重（需复分析）——但**为什么可信**：若
∫h(x)f(x)dx = ∫h(x)g(x)dx 对一大类测试函数 h 成立，
则 f = g。反证：f(0) > g(0) 则连续性给小区间 [−η,η]
内 f−g 保号，取 h_η = ±1/η 的方波，两个积分差 ≥ 1 ≠ 0
矛盾。**"对足够多测试函数积分相等 ⟹ 函数相等"**是
高数学的通用证等法；难点移到"极限与积分交换"——
这正是需要复分析背书的地方（第 22 章 Fourier 反演补全）。

**假设的代价**：MGF 需在 |t| < δ 存在（排除 Cauchy 类
重尾）；条件越强结论越强或证明越短——Markov/Chebyshev
的权衡定律在定理层面重演。

## 21.2 标准化代数（磨刀不误砍柴工）

- E[X̄_N] = μ、Var(X̄_N) = σ²/N（第 18 章 WLLN 的两行账）；
  标准差 σ/√N——**1/√n 律**：均值以 σ/√N 的速度收紧。
- **标准化**：Z = (X−μ)/σ 有 E[Z] = 0、Var = 1。CDF 法
  推密度：Y = X−μ 的 f_Y(y) = f_X(y+μ)；Z = Y/σ 的
  f_Z(z) = σ·f_X(σz+μ)（**换元因子的方向**别丢）。
- 例：Unif(1,3)（μ=2、σ²=1/3）标准化后密度为 √3/2
  支撑在 [−√3,√3]——第 14 章的"方差 1 均匀"重新出生。

**变成正态的是什么**：不是 Xᵢ 本身（形状任意），是
（标准化的）**均值**；原分布只通过 μ、σ 进入极限，形状
信息只剩收敛**速率**（Berry–Esseen 定理的注脚）。

## 21.3 Poisson 特例：完整账

Pois(λ) 的 MGF = e^{λ(e^t−1)}。标准化 Z_λ = (X−λ)/√λ：

M_{Z_λ}(t) = E[e^{t(X−λ)/√λ}] = e^{−t√λ}·e^{λ(e^{t/√λ}−1)}。

指数 = λ(e^{t/√λ} − 1 − t/√λ)：Taylor 展开 e^u − 1 − u =
u²/2 + O(u³)，u = t/√λ ⟹ 指数 = t²/2 + O(λ·λ^{−3/2}) =
**t²/2 + O(1/√λ) → t²/2**。Pois(λ) 标准化后 → N(0,1)
——大 λ 的泊松可用正态近似（λ = 1/3 的邮局小 λ 则不
行；**连续性修正**等使用规范见 21.5）。

## 21.4 一般证明

M_{Z_N}(t) = [M_{(X−μ)/σ}(t/√N)]^N（独立 + iid 的 MGF
乘积形态）。设 Y = (X−μ)/σ（标准化单变量，M_Y(0) = 1、
M′_Y(0) = 0、M″_Y(0) = 1），Taylor：

M_Y(u) = 1 + u²/2 + O(u³)（一阶项为零是标准化的红利），

M_{Z_N}(t) = (1 + t²/(2N) + O(N^{−3/2}))^N → **e^{t²/2}**
（(1+w/N)^N → e^w 的极限，配第 19 章的速率教训：这里
w = t²/2 固定、无 k 增长的陷阱）。代入 21.1 的唯一性，
CLT 完成。**证明骨架四件**：标准化吃掉一阶项、MGF
乘积、Taylor 到二阶、(1+w/N)^N。Poisson 特例是同一
骨架的换装。

## 21.5 使用规范与应用

**CLT 说的是标准化和**：直接用 X̄_N 时正态参数取
N(μ, σ²/N)；用和 S_N 时取 N(nμ, nσ²)。**使用流程**：
所求概率 → 折算成标准化变量 → 查正态表。**经验**：
n ≥ 30 常被引用，但偏态分布要更大（第 14 章指数和
n = 30 的现场）；离散分布加**连续性修正**（P(a ≤ S ≤ b)
按 Φ((b+½−μ)/σ) − Φ((a−½−μ)/σ) 计）。

**三个层次的结果**（全书弧线收拢）：WLLN 给"均值 → μ"
（第 18 章）；CLT 给"标准化均值的**形状** → 正态"——
不止收敛，还刻画了涨落的分布（σ/√N 尺度上的钟形）；
误差的下一阶由 Edgeworth 展开/Berry–Esseen 控制。

## 21.6 机器通道

**Python（`21_clt.py`**）：① Poisson 特例的 MGF 账：
M_{Z_λ}(t) 的数值积分 vs e^{t²/2}（λ = 5、50、500 的收敛）；
② CLT 模拟现场三族（均匀、指数、二项的和的标准化
直方 vs φ 密度，n = 50）；③ (1 + t²/2N + …)^N → e^{t²/2}
的数值验证；④ 连续性修正的对照（二项 P(45 ≤ S ≤ 55)
的精确值 vs 修正/不修正的正态近似）；⑤ Berry–Esseen
式的误差表（不同 n 的最大偏差）。

**Julia（`21_clt.jl`）**：① 三族（均匀/指数/泊松）标准化
和的经验 CDF vs Φ 的最大偏差随 n 衰减（log-log 斜率）；
② 1/√n 律：样本均值标准差的实测 vs σ/√n；③ CLT 的
"形状无关"现场：偏态指数在 n = 50 时钟形化的直方对照；
④ 连续性修正的精度对比。

**Lean（`Ch21CLT.lean`）**：判决侧——① (1+w/N)^N 的
极限常数账（数值形态：大 N 的 (1+t²/2N)^N 与 e^{t²/2}
的接近度判决）；② 标准化的矩账（E = 0、Var = 1 的
代数）；③ Poisson 特例的 Taylor 残差账（λ(e^{t/√λ}−1−
t/√λ) → t²/2 的数值采样）；④ 正态 MGF 的 e^{t²/2} 与
偶矩链的会师（(2m−1)!! = e^{t²/2} 的系数）。

**Isabelle（`MT21/T21_CLT.thy`）**：CLT 的形式侧锚点——
mathlib/Isabelle 的分布收敛记号与 `CLT` 定理名的 `#check`
正名 + 标准化的矩账（pmf_of_set 的线性组合）+ 正态
MGF 的导数判据（HasDerivAt 链）。

## 21.7 要点回顾

1. CLT：iid、MGF 局部存在 ⟹ 标准化均值 →ᵈ N(0,1)；
   原形状只留在收敛速率里。
2. 证明四件套：标准化（吃一阶项）→ MGF 乘积 → Taylor
   二阶 → (1+w/N)^N → e^w；唯一性靠"测试函数积分相等
   ⟹ 函数相等"（复分析背书，第 22 章补票）。
3. Poisson 特例：λ(e^{t/√λ}−1−t/√λ) → t²/2——同一骨架
   的换装。
4. 使用规范：X̄_N ~ N(μ, σ²/N) 近似；n ≥ 30 是经验不是
   定律；离散加连续性修正。
5. 弧线：WLLN（收敛）→ CLT（形状）→ Berry–Esseen
   （速率）。
