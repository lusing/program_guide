# 05 计数原理、排列与组合

在有限等可能模型中，概率问题常变成两个集合有多大：有利样本点数除以总
样本点数。这个说法简单，真正的困难在于样本点是否有顺序、抽样是否放回、
同一对象是否被重复计数。本章建立排列、组合和二项系数的基本账目，并把
四种常见有限抽样方案统一起来。

## 05.1 古典概型与计数比

若样本空间

\[
\Omega=\{\omega_1,\ldots,\omega_N\}
\]

含有 \(N\) 个等可能样本点，事件 \(A\) 含有 \(N_A\) 个样本点，则

\[
P(A)=\frac{|A|}{|\Omega|}=\frac{N_A}{N}.
\]

这个公式只适用于等可能模型。公平骰子、洗匀的牌堆、设计良好的简单随机
抽样可以使用它；现实中的违约、涨跌、政策状态一般不能只因“有几种可能”
就假设等可能。

计数时先回答三个问题：

1. 样本是排成序列，还是组成无序集合？
2. 每次选出后是否放回？
3. 同一种结果会不会因不同叙述顺序被数多次？

这三个问题决定使用 \(n^k\)、排列数、组合数，还是“可重复组合”。

## 05.2 加法原理与乘法原理

若完成一件事有两类互斥方案，第一类有 \(a\) 种，第二类有 \(b\) 种，则
总方案数为 \(a+b\)。这是**加法原理**。

若完成一件事必须依次经过 \(k\) 个步骤，第 \(i\) 步有 \(m_i\) 种选择，
并且各步选择可以任意搭配，则总方案数为

\[
m_1m_2\cdots m_k.
\]

这是**乘法原理**。

例如生成三枚硬币的样本空间，第一、二、三枚各有正、反两种选择，所以

\[
|\Omega|=2\cdot2\cdot2=8.
\]

“恰有两个正面”并不给三枚硬币各自的概率，而只选择正面出现的位置。从
三个位置中选两个为正面，共有

\[
\binom32=3
\]

种：正正反、正反正、反正正。因此概率为 \(3/8\)，而不是凭“正面数可取
0,1,2,3”猜成 \(1/4\)。

## 05.3 阶乘与排列

\(n\) 个不同对象排成一列的方式数为

\[
n!=n(n-1)\cdots2\cdot1,
\]

并约定 \(0!=1\)。第一个位置有 \(n\) 种选法，第二个位置剩 \(n-1\) 种，
最后一个位置只剩 1 种；乘法原理给出 \(n!\)。

从 \(n\) 个不同对象中不放回地依次选出 \(k\) 个，并记录顺序，称为
\(k\)-排列，方案数为

\[
P_n^k=n(n-1)\cdots(n-k+1)=\frac{n!}{(n-k)!}.
\]

当 \(k=n\) 时得到 \(P_n^n=n!\)。当 \(k>n\) 且对象不放回时，方案数为
0。

从 10 人中选主席、秘书、财务三个不同岗位，共有

\[
P_{10}^3=10\cdot9\cdot8=720
\]

种。若只选三人组成委员会，同一组三人的 6 种岗位排列不应重复计算，因此
答案不是 720。

## 05.4 组合与二项系数

从 \(n\) 个不同对象中不计顺序地选 \(k\) 个，方案数为

\[
\binom nk=\frac{n!}{k!(n-k)!},
\qquad 0\le k\le n.
\]

它也记作 \(C_n^k\) 或 `C(n,k)`。推导采用“先算多、再除重”：先按有序
方式选出 \(k\) 人，有 \(n!/(n-k)!\) 种；每个无序的 \(k\) 人组内部又有
\(k!\) 种排列，所以每组被数了 \(k!\) 次。除以 \(k!\) 得组合数。

例如 10 人中选 3 名委员：

\[
\binom{10}{3}=\frac{10\cdot9\cdot8}{3\cdot2\cdot1}=120.
\]

岗位分配与委员会选择之间恰有

\[
720=3!\cdot120
\]

的倍数关系。

二项系数有以下基本性质：

\[
\binom n0=\binom nn=1,
\]

\[
\binom nk=\binom n{n-k},
\]

\[
k>n\Longrightarrow \binom nk=0.
\]

对称性的组合解释是：选出 \(k\) 个留下，等价于选出 \(n-k\) 个去掉。

## 05.5 多项系数

把 \(n\) 个**不同且带标签**的对象分成 \(r\) 个有标签的组，第 \(i\) 组
恰有 \(k_i\) 个对象，其中

\[
k_1+\cdots+k_r=n,\qquad k_i\ge 0,
\]

则分组方式数为

\[
\binom{n}{k_1,k_2,\ldots,k_r}
=\frac{n!}{k_1!k_2!\cdots k_r!}.
\]

它的推导仍是“先排成序列，再去掉组内顺序”。先把 \(n\) 个对象排成一列，
有 \(n!\) 种；第一组内部的 \(k_1!\) 种排列不改变分组，第二组内部的
\(k_2!\) 种排列也不改变分组，依此类推，所以除以所有 \(k_i!\)。

例如把 5 个不同的人分成“甲组 3 人、乙组 1 人、丙组 1 人”，有

\[
\binom{5}{3,1,1}=\frac{5!}{3!1!1!}=20
\]

种分法。若三个组没有标签，而只是三个大小为 \(3,1,1\) 的集合，还要根据
相同大小的组是否交换来进一步除重；多项系数的分母只去除**组内**顺序，
不去除无标签组之间的顺序。

多项定理是二项定理的推广：

\[
(x_1+\cdots+x_r)^n
=
\sum_{k_1+\cdots+k_r=n}
\binom{n}{k_1,\ldots,k_r}
x_1^{k_1}\cdots x_r^{k_r}.
\]

展开时，每个带标签的因子都从 \(x_1,\ldots,x_r\) 中选一个；指数向量
\((k_1,\ldots,k_r)\) 记录每个变量被选了多少次，对应的选择方式正是多项
系数。令所有 \(x_i=1\)，得到

\[
r^n=\sum_{k_1+\cdots+k_r=n}\binom{n}{k_1,\ldots,k_r}.
\]

这也解释了可辨球独立进入可辨桶时的多项分布：若每个球落入第 \(i\) 个桶
的概率为 \(p_i\)，则桶计数恰为 \((k_1,\ldots,k_r)\) 的概率是

\[
\binom{n}{k_1,\ldots,k_r}p_1^{k_1}\cdots p_r^{k_r}.
\]

本章先只做计数；随机变量章节再把它正式定义为多项分布。

## 05.6 Pascal 递推

Pascal 递推为

\[
\binom nk=\binom{n-1}{k-1}+\binom{n-1}{k}.
\]

组合证明盯住一个指定对象，例如甲。从 \(n\) 人中选 \(k\) 人，只有互斥
两类：

- 选甲：还需从其余 \(n-1\) 人中选 \(k-1\) 人，共
  \(\binom{n-1}{k-1}\) 种；
- 不选甲：需从其余 \(n-1\) 人中选 \(k\) 人，共
  \(\binom{n-1}{k}\) 种。

由加法原理得到递推。这个递推适合构造整数表，因为它全程只用加法，不必
先计算可能很大的阶乘。

## 05.7 二项定理

对任意实数或更一般交换环中的 \(x,y\)，有

\[
(x+y)^n=\sum_{k=0}^n\binom nkx^ky^{n-k}.
\]

展开

\[
(x+y)(x+y)\cdots(x+y)
\]

时，每一项都从 \(n\) 个因子中选若干个贡献 \(x\)。若恰有 \(k\) 个因子
贡献 \(x\)，其余 \(n-k\) 个贡献 \(y\)，这样的选择共有 \(\binom nk\) 种。

令 \(x=y=1\)：

\[
2^n=\sum_{k=0}^n\binom nk.
\]

右边正是 \(n\) 元集合所有子集的个数。令 \(x=1,y=-1\)：

\[
0=\sum_{k=0}^n(-1)^k\binom nk.
\]

第二个恒等式说明偶数大小子集与奇数大小子集的总数相等，也预示了第 06 章
容斥中的交错和。

## 05.8 四种有限抽样方案

设总体有 \(n\) 个不同对象，抽取 \(k\) 次。

| 方式 | 是否记录顺序 | 是否放回 | 方案数 |
|---|---:|---:|---:|
| 有序有放回 | 是 | 是 | \(n^k\) |
| 有序无放回 | 是 | 否 | \(n!/(n-k)!\) |
| 无序无放回 | 否 | 否 | \(\binom nk\) |
| 无序有放回 | 否 | 是 | \(\binom{n+k-1}{k}\) |

有序有放回对应长度为 \(k\) 的字符串；每一位都独立地有 \(n\) 种选择。
有序无放回对应排列。无序无放回对应组合。

无序有放回可用“星与条”表示。把 \(k\) 次抽取按 \(n\) 个类型分组，令
\(k_i\) 为第 \(i\) 类被选次数，则

\[
k_1+\cdots+k_n=k,\qquad k_i\ge0.
\]

非负整数解的个数是

\[
\binom{n+k-1}{k}.
\]

例如掷 3 枚相同骰子时，只记录各点数出现次数的频率向量有
\(\binom{8}{3}=56\) 种，但这些向量不等可能；真正等可能的是 \(6^3=216\)
个有序结果。

## 05.9 两个数量级例子

从 52 张牌中选 5 张成一手牌，若不记录发牌顺序，则共有

\[
\binom{52}{5}=2\,598\,960
\]

手。扑克牌型概率都以这个数为分母。

若有 23 个人，只比较两两生日是否相同，则共有

\[
\binom{23}{2}=253
\]

对人。生日问题中“至少一对同生日”的补事件是 253 对全都不同。配对数
随人数平方增长，这正是 23 人时碰撞概率已经约为一半的计数根源。第 07 章
会完整计算生日问题和扑克牌型。

## 05.10 计数的三类常见错误

**第一类是顺序幻觉。**委员会、手牌、样本子集不计顺序；岗位、密码、
带名次的领奖名单计顺序。同一个“选三人”问题，答案可能是 120 或 720。

**第二类是重复计数。**若先有序列出再声称得到无序集合，就必须除以每组
内部的排列数。一般地，若每个目标对象都恰好被同一方案数 \(r\) 次表示，
总数应除以 \(r\)。

**第三类是把不等可能的计数向量当作等可能结果。**两颗骰子的点数和为 7
与点数和为 12 都只是一个“和值”，但前者对应 6 个有序结果，后者只对应
1 个。必须先确定真正等可能的基本样本点。

## 05.11 机器通道

Python 文件 `examples/python/05_counting.py` 用整数递推和精确分数核对
计数账。核心代码如下：

```python
pascal = [[0] * (N + 1) for _ in range(N + 1)]
for n in range(N + 1):
    pascal[n][0] = 1
    for k in range(1, n + 1):
        pascal[n][k] = pascal[n - 1][k - 1] + pascal[n - 1][k]
for n in range(N + 1):
    for k in range(n + 1):
        assert pascal[n][k] == comb(n, k)

ordered = 10 * 9 * 8
unordered = comb(10, 3)
assert ordered == 6 * unordered
```

程序还验证二项定理、\(\sum_{k=0}^{12}\binom{12}{k}=2^{12}\)、
多项系数和星与条计数。多项定理的核心实现是：

```python
def multinomial(n, groups):
    assert sum(groups) == n
    den = 1
    for g in groups:
        den *= factorial(g)
    return factorial(n) // den

assert multinomial(5, (3, 1, 1)) == 20
assert sum(multinomial(5, (a, b, 5 - a - b))
           for a in range(6) for b in range(6 - a)) == 3 ** 5
```

第二个断言检查 \((x+y+z)^5\) 的所有系数之和为 \(3^5\)。脚本另外枚举
\(x_1+x_2+x_3=4\) 的非负整数解，确认解数为
\(\binom{4+3-1}{4}=\binom64=15\)。

Julia 文件 `examples/julia/05_counting.jl` 用三重循环枚举所有递增的
三人下标，直接得到 120 个组合：

```julia
sel = Vector{Int}[]
for i in 1:8, j in (i + 1):9, k in (j + 1):10
    push!(sel, [i, j, k])
end
@assert length(sel) == 120
contains4 = count(s -> 4 in s, sel)
@assert contains4 == 36
```

其中含指定 4 号的组合有 \(\binom92=36\) 个。同一文件检查

\[
\binom{5}{3,1,1}=20,\qquad
\binom{11}{5,3,3}=9240,
\]

并枚举 3 个可辨球进入 2 个可辨桶的 \(2^3=8\) 种分配，按桶中球数得到
直方图 \([1,3,3,1]\)。它还以固定随机种子模拟三枚硬币，观察“恰两个
正面”的频率接近 \(3/8\)；精确答案仍由枚举给出。

Prolog 文件 `examples/prolog/05_counting.pl` 把“不计顺序”实现成
“只枚举递增列表”：

```prolog
combo(_, 0, []).
combo([X | Xs], K, [X | C]) :- K > 0, K1 is K - 1, combo(Xs, K1, C).
combo([_ | Xs], K, C) :- K > 0, combo(Xs, K, C).
```

查询四个对象的二元组合只返回 `[1,2]`、`[1,3]` 等 6 个规范代表，不会
同时返回 `[2,1]`。同一文件枚举 \(4!=24\) 个排列、三枚硬币的 8 个结果，
以及 3 球进 2 桶的多项直方图 \([1,3,3,1]\)。

Lean 文件 `examples/lean/Probability/Ch05Counting.lean` 登记
`Nat.choose_succ_succ` 与 `Nat.sum_range_choose`，并用 `decide` 判决

\[
\binom{52}{5}=2\,598\,960,\qquad
\binom{23}{2}=253.
\]

同一文件还检查 \(5!/(3!1!1!)=20\) 以及
\(\binom30+\binom31+\binom32+\binom33=8\)。这些机器检查把后续生日和
牌型问题的分母固定下来。

## 05.12 本章要点

1. 等可能有限模型中，概率等于有利点数除以总点数。
2. 分步用乘法，分类用加法；先判断“步骤”还是“类别”。
3. 有序无放回抽样数为 \(n!/(n-k)!\)，无序无放回抽样数为
   \(\binom nk\)。
4. 组合数比排列数少一个 \(k!\)，因为同一组内部顺序被重复数了 \(k!\) 次。
5. Pascal 递推通过“指定对象是否入选”分成互斥两类。
6. 多项系数处理带标签对象到带标签组的分配，组内顺序要除以各 \(k_i!\)。
7. 二项定理给组合求和赋予展开式含义；\(\sum_k\binom nk=2^n\) 是子集
   总数。
8. 计数向量不一定等可能；应回到最基本的等可能样本点。
