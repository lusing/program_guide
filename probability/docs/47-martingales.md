# 第 47 章 离散鞅 I：公平赌博的数学

## 47.1 从"公平的赌博"到一个定义

胡书第 7 章开头给的动机是最好的入门：设 $X_n$ 是 $n$ 局赌博后的总所得。若已知前 $n$ 局的结果，下一局的**预期净所得**为零——$E(X_{n+1}-X_n\mid X_1,\dots,X_n)=0$ ——就称这赌博是公平的。这个条件改写一下就是本章的主角：

**定义（胡书定义 7.1.1）** 设 $(\Omega,\mathcal F,P)$ 上有上升的子 $\sigma$ 代数流 $\mathcal F_1\subset\mathcal F_2\subset\cdots$ ，$X_n$ 可积且关于 $\mathcal F_n$ 可测。若 $E(X_{n+1}\mid\mathcal F_n)=X_n$ a.s.，称 $\{X_n,\mathcal F_n\}$ 为**鞅**；把 $=$ 换成 $\le$ （ $\ge$ ）得**上鞅**（**下鞅**）。

直觉分工：鞅是公平赌博的所得（总资产是“现在信息的无条件锚”）；上鞅是衰减的资产（超级鞅 = 超额下跌，如带抽水的赌场），下鞅是增长的趋势（如凸函数作用后的鞅）。注 7.1.4 给出封闭性运算：上鞅取负得下鞅；两个上鞅取 min 仍是上鞅、两个下鞅取 max 仍是下鞅——这些运算封闭性是构造反例的常备工具。

两个最基本的例子值得终生记忆：

- **部分和鞅**（例 7.1.1）：独立零均值 $Y_k$ 的和 $X_n=\sum_{k\le n}Y_k$ 关于自然滤流是鞅——公平游走是其特例；
- **Doob 鞅**（例 7.1.2）：任意可积 $Y$ 与上升滤流，$X_n=E(Y\mid\mathcal F_n)$ 是鞅——"逐步逼近真相的信念序列"。第 48 章将看到它的极限就是 $E(Y\mid\mathcal F_\infty)$ 。

## 47.2 鞅变换：赌博系统打不赢公平

**命题（胡书命题 7.2.1）** 设 $\{X_k\}$ 为下鞅，$\varepsilon_k$ 为关于 $\mathcal F_{k-1}$ 可测的 $\{0,1\}$ 值"是否下注"选择（**可料** = 只依赖过去）。令 $Y_n=X_1+\sum_{k=2}^n\varepsilon_k(X_k-X_{k-1})$ ，则 $Y_n$ 仍是下鞅且 $E(Y_n)\le E(X_n)$ （鞅时取等）。

这就是"鞅变换"：你可以任意聪明地选择何时下注、何时离场，但**没有任何可料策略能从公平（或不利）的赌博中提取正期望**。本章机器账把它做成三层证据：

- Python ② 在四点样本空间上精确计算经典"赌倍法"（输了加倍、赢了收手）：四个终值 $[-3,1,1,1]$ ，平均**精确为 0** ——三胜一败、败者输三倍，期望公平但风险完全不对称；
- Julia ④ 对"只在连输到 $-2$ 后下注"的策略模拟 6000 条轨道：$E[Y_n]$ 在噪声范围内为 0 ；
- Lean/Prolog 的状态机把可料性做成显式的"只读过去"数据流。

## 47.3 上穿不等式：波动税

**定理（胡书定理 7.2.1，上穿不等式）** 下鞅 $\{X_k,k\le n\}$ 向上穿越区间 $(a,b)$ 的次数 $U_{ab}$ 满足

$$ E(U_{ab})\ \le\ \frac{E\big((X_n-a)^+\big)}{b-a}. $$

证明的骨架极富教学价值：定义停时列 $T_1<T_2<\cdots$ （先跌到 $a$ 以下、再升到 $b$ 以上记一次完整往返），只在"升势段"持有头寸，增益恰为 $\sum(X_{T_{2i}}-X_{T_{2i-1}})\ge b\,U_{ab}$ ；再用命题 7.2.1 把这个策略收益的期望压回 $E(X_n)$ ——"上穿次数多 ⟺ 有界的总增益必须分摊到每次很少 ⟺ 期望次数有限"。

本章三通道共用同一个**上穿状态机**：

```python
def upcrossings(path, a, b):
    """上穿计数状态机（与 Lean/Prolog 件同构）。"""
    cnt = 0
    below = True
    for v in path:
        if below:
            if v <= a:
                below = False
        elif v >= b:
            cnt += 1
            below = True
    return cnt
```

精确判定：$[0,1,0,1]$ 对 $(3/10,7/10)$ 恰 2 次上穿；$[1,1,1]$ 从未跌到下沿，0 次；$[0,1/2,1]$ 的中途点 $1/2$ 不计（未过 $b$ 线），完整往返才计 1 次。

把 $[0,1,0,1]$ 的增益账摊开（这是不等式证明在具体路径上的模样）：

| 段 | 状态机相位 | 动作 | 头寸变化 | 累计增益 |
|---|---|---|---|---|
| $k=1$ ，$X=0$ | false（等跌） | $0\le3/10$ ，进场 | 0 → 持有 | 0 |
| $k=2$ ，$X=1$ | true（等升） | $1\ge7/10$ ，计 1 次并离场 | 持有 → 0 | $+1$ |
| $k=3$ ，$X=0$ | false | 再次进场 | 0 → 持有 | $+1$ |
| $k=4$ ，$X=1$ | true | 再计 1 次、离场 | 持有 → 0 | $+2$ |

总增益 $2$ 恰等于两次"从 $0$ 到 $1$ 的完整上升"之和，而下界 $b\cdot U=7/10	imes2=7/5$ ——每个完整上穿至少挣 $b-a$ 的"票价"再减去进场前的等待损耗。一般路径里 $X_{T_{2i}}\ge b$ 而 $X_{T_{2i-1}}\le a$ ，所以每次往返净挣至少 $b-a$ ；但"部分往返"（进场后尚未离场）可能倒亏——不等式的证明正是在处理这段尾巴（用 $X_n\ge0$ 的截断项 $(X_n-a)^+$ 收尾）。Julia ② 把它推进到统计账：200 步公平游走对 $(-2,2)$ 的期望上穿数 $\approx24$ ，远低于简明界 $n/(b-a)=50$ 。

## 47.4 Doob 收敛定理与不等式族

**定理（胡书定理 7.2.5，Doob 收敛定理）** 下鞅若满足 $\sup_n E(X_n^+)<\infty$ ，则存在可积随机变量 $X_\infty$ 使 $X_n\to X_\infty$ a.s.

证明正是上穿不等式的三行应用：若 $X_n$ 不收敛，必有有理数对 $a<b$ 使路径无穷次上穿；但 $E(U_{ab})\le(b-a)^{-1}\sup E(X_n^+)<\infty$ 与"无穷次"矛盾。**收敛性的全部困难被压进了上穿账**——这是本章最值得欣赏的证明结构。

配套的不等式族（胡书定理 7.2.2-7.2.4）：

- **Kolmogorov 不等式**（7.2.2）：鞅的 $\lambda^2P(\max_{k\le n}|X_k|\ge\lambda)\le E(X_n^2)$ ——第 45 章的级数机器其实是它对独立和的特例；
- **Doob 极大不等式**（7.2.3）：非负下鞅的 $\lambda P(\max X_k\ge\lambda)\le E(X_n 1_{\max\ge\lambda})$ 型 $L^1$ 控制；
- **Doob $L^p$ 不等式**（7.2.4）：$E(\max X_k^p)\le\big(\frac p{p-1}\big)^pE(X_n^p)$ ，$p>1$ —— Julia ③ 验证 $p=2$ 的版本：$E(\max S_k^2)\le4E(S_n^2]=4n$ （实测约 $158\le400$ ）。

Julia ③ 把 $L^2$ 版本跑成统计账：

```julia
rng3 = MersenneTwister(4703)
m2 = Float64[]
for _ in 1:2000
    s = 0
    mx = 0
    for _ in 1:100
        s += rand(rng3) < 0.5 ? 1 : -1
        mx = max(mx, abs(s))
    end
    push!(m2, mx^2)
end
# 实测 E[max S_k^2] 约 158 <= 4·E[S_n^2] = 400
```

实测值离界还有很大余量——这不是界的失败，而是 $n=100$ 时随机游走远未用完它的"配额"；不等式的价值在尾部控制而非点估计。

## 47.5 停时：可以停止但不能预知

**定义（胡书定义 7.4.1，第 48 章正式使用）** $T:\Omega\to\{0,1,2,\dots,\infty\}$ 是关于 $\{\mathcal F_n\}$ 的**停时**，若 $\{T\le n\}\in\mathcal F_n$ 对一切 $n$ ——"能否现在停止"只由已有信息决定，不许偷看未来。命题 7.4.1：停时对 $\min/\max$ 、加法、$\inf/\sup/\liminf/\limsup$ 封闭。

本章机器件先做穷举预报。首中时 $\tau_1=\min\{n:S_n\ge1\}$ 在 3 步 ±1 游走上的完整判决（Lean `firstHit` + 8 路径 `native_decide`；Prolog 同构穷举）：

$$ P(\tau_1\le3)=\frac58, $$

与反射原理 $P(\max_{k\le3}S_k\ge1)=2P(S_3\ge1)-P(S_3=1)=2\cdot\frac48-\frac38=\frac58$ 相互印证。**一个诚实的过程记录**：本节第一版文件把答案误写为 $7/8$ ，被 Prolog 的穷举当场驳回——"三条 $-1$ 开头的路径全部漏掉"。穷举通道的价值不在证明定理，而在**防止证明者对自己撒谎**。

把 8 条路径的判决表完整列出（`+` 表示 $\tau_1\le3$ ，即某个前缀和 $\ge1$ ）：

| 路径 | 前缀和 | 判决 |
|---|---|---|
| $(-1,-1,-1)$ | $-1,-2,-3$ | ✗ |
| $(-1,-1,1)$ | $-1,-2,-1$ | ✗ |
| $(-1,1,-1)$ | $-1,0,-1$ | ✗ |
| $(-1,1,1)$ | $-1,0,1$ | ✓（第 3 步首中） |
| $(1,-1,-1)$ | $1,0,-1$ | ✓（第 1 步首中） |
| $(1,-1,1)$ | $1,0,1$ | ✓ |
| $(1,1,-1)$ | $1,2,1$ | ✓ |
| $(1,1,1)$ | $1,2,3$ | ✓ |

$5/8$ 的每一份都能在这张表里点到名——这是"概率 = 计数"在停时语言下的最小实例。

```prolog
first_hit(Steps, T, N) :- first_hit_(Steps, 0, T, 1, N).
% 8 条路径穷举：恰 5 条 τ₁ ≤ 3，P = 5/8
```

## 47.6 机器账总览

先看一眼"公平性"在最简单的两步赌局里长什么样（本章 ② 段的四点空间，也是 Python/Prolog 精确账的共同底座）：第一步赢输各半，第二步按"输了加倍、赢了收手"下注。四个等概率样本点的最终财富是 $-3,1,1,1$ ——三胜一败、败者输三倍。期望 $(−3+1+1+1)/4=0$ 精确成立；但半方差、最大回撤全部恶化。"公平"只承诺期望，不承诺任何风险形态——这是鞅论在金融里必须搭配风险度量才能用的根本原因。

| 通道 | 内容 | 证据形态 |
|---|---|---|
| Lean | 锚墙（定义 7.1.1 至定理 7.2.5 的 mathlib 真名）+ 上穿状态机 + 首中时 8 路径穷举 | `native_decide` 精确判定 |
| Julia | 条件均值的分组验证、上穿期望对界、Doob $L^2$ 极大不等式、赌博系统期望为 0 | 固定种子 MC |
| Python | 上穿状态机精确判定、赌倍法四点精确期望、例 7.3.1 鞅的均值恒 1 | Fraction 精确 |
| Prolog | 同构状态机 + 停时穷举 + 条件期望逐 $s$ 判决 | rdiv 精确 |

其中 Python ③ 提前展示了一个"病态"鞅：$X_n=2^n\prod_{j\le n}Y_j$ （ $Y_j$ 为 Bernoulli(1/2) ，即胡书例 7.3.1 的形式）。精确账：$E(X_n)=2^n(1/2)^n=1$ 对一切 $n$ 成立（Fraction 逐 $n$ 验证），但 $P(X_n>0)=(1/2)^n\to0$ ——**均值恒 1 而几乎每条轨道都归零**。它满足定理 7.2.5（a.s. 收敛到 0 ），却不满足 $L^1$ 收敛——$E|X_n-0|=1$ 永不归零。这个裂缝正是第 48 章（一致可积性）的入口。

## 47.7 从病态例子到第 48 章的桥

把 47.6 的病例再读一遍： $X_n=2^n\prod Y_j$ 的 a.s. 极限是 0 ，但 $E|X_n-0|=1$ 。第 25 章说过 a.s. 收敛不保证 $L^1$ 收敛（尖峰序列反例），但那是"人造"的分布；现在这个例子是**自然的**——一个完全由公平赌博规则产生的鞅。区别在哪？

答案是一条双向通道（第 48 章定理 7.3.5 与推论 7.3.1 将给出完整陈述）：
- **充分方向**（第 48 章定理）：一致可积 + a.s. 收敛 ⟹ $L^1$ 收敛；
- **结构方向**：UI 鞅必能写成 Doob 鞅 $E(Y\mid\mathcal F_n)$ （可积的 $Y$ ），而病例 $X_n$ 恰好不能——它没有"可积的最终真相"可供逼近。

这把第 47 与 48 章缝合成一个整体：第 47 章问"什么时候 a.s. 极限存在"（答案：上穿账有限），第 48 章问"什么时候还能把期望也搬过去"（答案：UI ），而两问之间的缝隙里住着所有套利幻觉——鞅变换保期望的前提是各阶矩账目清白，UI 正是账本上最关键的一页。

## 47.8 经济与统计中的鞅

- **有效市场假说的数学形态**："价格是鞅"就是"可用信息无法预测超额收益"的精确化；上鞅版本对应有交易成本的版本。鞅差分检验（对 $P_{t+1}-P_t$ 做关于信息集的回归，系数应联合为零）是实证金融的标准动作。
- **保险精算**：盈余过程（保费收入 − 理赔）是带正漂移的（上）鞅化目标；破产概率即首中时 $\tau_0$ 的分布问题——47.5 的穷举是它最小的实验室。
- **序贯统计**：似然比 $\prod f_1(X_i)/f_0(X_i)$ 在原假设下是鞅（期望恒 1）——检验的停止规则必须用停时（不许偷看），而 SPRT 的有效性证明正是鞅论证。
- **消费与资产定价**：在无套利假设下，按均衡定价核折算的资产价格是鞅（"等价鞅测度"）；鞅测度的存在性定理是衍生品定价的数学地基。上鞅则对应有红利/交易成本时的"折价"版本。
- **学习理论**：贝叶斯后验对数据的条件期望是 Doob 鞅（例 7.1.2 的直接应用），其 a.s. 收敛（第 48 章定理 7.3.3）就是"贝叶斯学习渐近正确"的证明骨架——martingale convergence theorem 在机器学习理论里的出场率不亚于集中不等式。

## 47.9 常见误区

1. **"鞅就是均值不变"**——不对，鞅是**条件**均值等于当前值；边际均值不变只是推论。反例：$X_n$ 独立同分布均值 0 时 $X_n$ 本身（不是部分和）不是鞅。
2. **"聪明下注能赢"**——命题 7.2.1 的全部内容就是"不能"：任何可料策略的变换仍是鞅（期望不变）或上鞅（更差）。赌倍法的四点账 $[-3,1,1,1]$ 是最短的反直觉教材。
3. **"上穿次数是路径细节，不重要"**——它恰是 Doob 收敛定理证明的全部引擎；而 $E(U_{ab})$ 的上界把"波动大小"变成可计算的概率账。
4. **"停时就是随机的时刻"**——必须 $\{T\le n\}\in\mathcal F_n$ ："第一次赚够 100 万"是停时，"最后一次亏 100 万之前的那个时刻"不是（要偷看未来）。

## 47.10 本章要点

（本章四通道全部通过；三件"完全判定"——四点赌倍法期望精确 0 、8 路径首中时计数 $5/8$ 、上穿状态机逐路径判定——构成鞅论入门阶段可以完全托付给机器的部分。）

1. 鞅 = 条件期望锚定当前值的公平性；上/下鞅是不等号版本；min/max 与取负的封闭性是构造反例的工具箱。
2. 两个基本例子：独立零均值部分和（例 7.1.1）、Doob 鞅 $E(Y\mid\mathcal F_n)$ （例 7.1.2）。
3. 鞅变换（命题 7.2.1）：可料下注不改期望——四点赌倍法 $[-3,1,1,1]$ 均值精确 0 。
4. 上穿不等式（7.2.1）： $E(U_{ab})\le E(X_n-a)^+/(b-a)$ ；只在升势段持有的增益账 $b\,U_{ab}$ 是它的心脏。
5. Doob 收敛定理（7.2.5）： $\sup E(X_n^+)<\infty$ ⟹ a.s. 收敛；证明 = 上穿账 + 有理数对的可数覆盖。
6. 停时 = 不偷看的随机时刻；首中时穷举 $P(\tau_1\le3)=5/8$ 与反射原理互证（且第一版的 $7/8$ 手误被穷举当场纠正——跨通道对账的又一例）。
7. 病例展示： $X_n=2^n\prod Y_j$ 均值恒 1 而轨道归零——a.s. 收敛不等于 $L^1$ 收敛，第 48 章的一致可积性正是补这条裂缝的定理。

**注一（凸函数与下鞅）**：习题 7.4(a) 的方向——鞅过凸函数 $g$ 且 $E|g(X_n)|<\infty$ 时， $g(X_n)$ 序列是下鞅（Jensen 不等式对条件期望成立）。这解释了为什么 $|X_n|$ 、 $X_n^2$ 自动是下鞅：凸性把"公平"扭曲成"倾向增长"。统计里似然比的 $\log$ 处理、金融里效用函数的凹性（得上鞅）都走这条门。

**注二（逆鞅）**：推论 7.2.1 把定理 7.2.5 搬到下降滤流（逆下鞅）：只需 $\inf E(X_n)>-\infty$ 。它貌似生僻，实则是"从大样本回看"的数学装置——第 48 章的逆鞅收敛与 Bayesian 一致性有直接的血脉。

还有一个方向性注记：上穿状态机本身是个**可料策略**——它"在跌到 $a$ 以下时进场、升过 $b$ 离场"的规则只读过去。因此上穿不等式的证明与鞅变换命题 7.2.1 共用同一台引擎并非巧合：两者都是"把路径的几何性质折算成策略收益的期望账"。这个视角把第 45 章的方差账、本章的上穿账与第 46 章的分级账统一成同一门手艺——**为轨道的形状定价**。

**注三（注 7.2.2 的反例账）**：定理 7.2.5 的条件是 $\sup E(X_n^+)<\infty$ ——只约束正半部分。胡书在定理后给出一个精巧的马氏链鞅——$X_0=0$ ，从状态 $n$ 出发以 $p_{n+1}=(2n+1)/(2n+2)$ 升一步、否则跌入吸收态 $-k$ ——它是鞅、a.s. 收敛（极限只取可数个值），但 $E|X_n|	o\infty$ ：**收敛定理的矩条件不是免费的**。机器上复现它的成本很高（转移律随状态变化），本章 Python ③ 的例 7.3.1 鞅是它的"平价替代"——同样演示"均值恒定而轨道坍缩"，但转移律简单到可以做精确分数账。
