# 16 Γ 函数与 Γ 分布：阶乘的连续化

**对应 Miller ch15（pp. 414-442）。**

Γ(s) = ∫₀^∞ e^{−x}x^{s−1}dx 把阶乘延拓到全实轴：Γ(n+1)
= n!。它是指数矩、正态偶矩、χ² 归一化的共同账户——
"一次算一般、处处拔插头"的数学理财术。本章：存在性、
函数方程、特殊值 Γ(1/2) = √π、Beta 关系、分布族
（Gamma/Weibull/Beta）与 Cauchy 的回归。

## 16.1 存在性：两端的体检

任何广义积分先查**两个危险点**：x → 0 与 x → ∞。

- **∞ 端**："借衰减"——e^x > x^M/M!（Taylor 单项），
  故 e^{−x}x^{s−1} ≤ M!·x^{s−M−1}，取 M > s 即可积。
- **0 端**：e^{−x} ≤ 1，∫₀¹x^{s−1} = 1/s < ∞ 当且仅当
  **s > 0**；s ≤ 0 时被积 ≥ x^{s−1}/e 直接爆炸。

结论：Γ(s) 对 s > 0 良定义（此后由函数方程延拓到其余
点）。经验法则：∞ 端衰减快过 1/x^{1+ε}、0 端爆破慢过
x^{−1+ε} 就安全——第 10 章 E[1/X] 反例 (1/x 于 0) 与
Cauchy 均值 (1/x 于 ∞) 的判据统一在此。

## 16.2 函数方程：分部积分的馈赠

**Γ(s+1) = sΓ(s)**（s > 0）。证明一行分部积分：u = x^s、
dv = e^{−x}dx，边界项归零（L'Hôpital），剩 s∫e^{−x}x^{s−1}。

**解析延拓的入门戏法**（原书的精彩类比）：
1 + 2 + 4 + 8 + ⋯ "=" −1？？——几何级数 Σrⁿ = 1/(1−r)
在 |r| < 1 成立，右边却在 r ≠ 1 处处有意义；**把 2 代入
右边**得到的 −1 就是这个发散和的"自然意义"（解析延拓）。
同理 Γ 的积分在 s ≤ 0 发散，但函数方程 Γ(s) =
Γ(s+1)/s 允许**从已知区域向上爬**：

Γ(−3/2) = Γ(−1/2)/(−3/2) = Γ(1/2)/((−3/2)(−1/2))
= (4/3)√π。

奇点恰在 0 与负整数（Γ(0) = ∫e^{−x}/x 爆破，函数方程
逐级传染）。**方向反转的函数方程是延拓的电梯**。

## 16.3 Γ(n+1) = n!：归纳

Γ(1) = ∫e^{−x} = 1 = 0!；设 Γ(n) = (n−1)!，则 Γ(n+1) =
nΓ(n) = n·(n−1)! = n!。阶乘的乘法树被积分表示取代——
"换个高度看问题，新工具（分析学）进场"：第 18 章
Stirling 公式将从这个积分表示榨出 n! 的渐近账。

## 16.4 特殊值 Γ(1/2) = √π

**为什么是 1/2**：整数已拿下，接下来最简单的是半整数
（"先走再跑"的选点哲学）。**与正态的联系**：
I = ∫e^{−x²/2}dx 换元 u = x²/2（x = (2u)^{1/2}、
dx = (2u)^{−1/2}du，再加零整理指数 u^{−1/2} = u^{1/2−1}）：

I = √2·Γ(1/2)——正态归一化（第 15 章极坐标技巧证
I = √(2π)）**等价于** Γ(1/2) = √π。两章互为硬币两面。

**余割恒等式**：Γ(s)Γ(1−s) = π/sin(πs)（s ∉ ℤ）。取
s = 1/2 自反：Γ(1/2)² = π/1 ⟹ **Γ(1/2) = √π**。证明
（附录 15.8）是双积分换元 u = x/y 的工艺品——哑变量
纪律（x、y 分写）、换序、商换元三连，值得精读。

**半整数全家福**：Γ(3/2) = √π/2、Γ(5/2) = 3√π/4、
Γ(7/2) = 15√π/8……每升半格乘一个半整数（函数方程）。

## 16.5 Beta 函数：Γ 的乘法表

B(a,b) = ∫₀¹ t^{a−1}(1−t)^{b−1}dt；**基本关系**
**B(a,b) = Γ(a)Γ(b)/Γ(a+b)**（双积分换元 u = x+y、
t = x/(x+y) 的经典推导）。立查：B(1,1) = 1 = Γ(1)²/Γ(2)；
B(1/2,1/2) = π（= Γ(1/2)²/Γ(1)，圆面积 π 的积分现身）。
Beta 分布（支撑 [0,1]）在统计中共轭先验里挑大梁。

## 16.6 正态偶矩的 Γ 收割

M(2m) = 2^m·Γ(m+1/2)/√π（换元 u = x²/2 + "加零"
配指数）。用 Γ(m+1/2) = (2m−1)!!√π/2^m（函数方程
自 1/2 爬 m 级）回收 **M(2m) = (2m−1)!!**——第 12 章
微分恒等式的结果在此**第二次出生**：一题两解，两条
产线互为审计。

## 16.7 分布族：Gamma 与 Weibull

**Gamma(k, σ)**：f(x) = x^{k−1}e^{−x/σ}/(Γ(k)σᵏ)（x ≥ 0；
k 形状、σ 尺度）。μ = kσ、σ² = kσ²。k = 1 退化为指数；
k 整数退化为 Erlang——**第 14 章 Erlang 是它整数特例**，
Γ(k) = (k−1)! 正是 (n−1)! 的来历。归一化验证 = Γ 的
换元账（∫x^{k−1}e^{−x/σ}dx = σᵏΓ(k)）。

**Weibull(k, σ)**：f(x) = (k/σ)(x/σ)^{k−1}e^{−(x/σ)ᵏ}——
生存分析的常客。k = 1 是指数、x^{k−1}e^{−xᵏ} 家族插值
了指数与 Rayleigh。

**族的思想**：参数滑动产生一族相关分布，建模时"选
族再定参"（统计推断的舞台）。原书的得意应用：用
Weibull 拟合棒球得分分布，仅由平均得分/失分预测胜率
（Pythagorean 预期的理论辩护）——**认识更多分布 =
更大工具箱**。

**Cauchy 回归**（15.9 节）：1/(π(1+x²)) 的均值不存在
（第 10 章已解剖路径依赖）；它还是**稳定分布**（Cauchy +
Cauchy = 2×Cauchy）却**不满足 CLT**——重尾世界与
正态世界的分界哨兵，第 22 章 Fourier 视角再会。

## 16.8 机器通道

**Python（`16_gamma.py`）**：数值账——① Γ(s) 的 Simpson
积分表（s = 1..8 vs (s−1)! 全对齐）；② Γ(1/2)、Γ(3/2)、
Γ(5/2) vs √π 系（√π、√π/2、3√π/4）；③ 函数方程数值链
Γ(s+1) = sΓ(s)（s = 0.5..5.5 连查）；④ Beta 基本关系
数值（(2,3)、(1/2,1/2)、(3,5) 三组 |差| < 10⁻⁶）；⑤ 余割
恒等式数值（s = 1/4、1/3、1/2）；⑥ Gamma(k,σ) 密度的
Simpson 归一与矩账（k = 2、σ = 3：μ = 6、σ² = 18）。

**Julia（`16_gamma.jl`）**：频率与数值——① Gamma(k,σ)
采样（k=2, σ=3）的均值方差 vs 6/18；② k = 1 退化为
指数的直方图对照；③ Weibull k=1 vs 指数、k=2 的形状
对比（样本分位数表）；④ Cauchy 稳定性现场：两独立
Cauchy 之和的一半仍是 Cauchy 尺度（经验分位数对照），
但样本均值照旧发散。

**Lean（`Ch16Gamma.lean`）**：判决侧——① 函数方程的
半整数链（Γ(3/2) = (1/2)Γ(1/2)、Γ(5/2) = (3/2)(1/2)Γ(1/2)
的 ring 形态）；② Γ(1/2) = √π 主权账 ((√π)² = π) 与
Γ(−3/2) = (4/3)√π 的分式判决；③ 偶矩公式 M(2m) =
2^mΓ(m+1/2)/√π 的 m = 1..3 收割（2·(√π/2)/√π = 1、
4·(3√π/4)/√π = 3、8·(15√π/8)/√π = 15）；④ Beta 关系
的整数例（B(1,1) = Γ(1)Γ(1)/Γ(2) 的分式账）。

## 16.9 要点回顾

1. Γ(s) 存在性看两端：0 端 s > 0、∞ 端指数借衰减压
   多项式。
2. 函数方程 Γ(s+1) = sΓ(s)：分部积分一行、延拓的
   电梯（负半轴由此爬升，奇点 0 与负整数）；几何级数
   的 −1 是解析延拓的入门戏法。
3. Γ(n+1) = n!（归纳）；Γ(1/2) = √π 与正态归一化等价
   （换元 u = x²/2）；余割恒等式 s = 1/2 自反收割。
4. B(a,b) = Γ(a)Γ(b)/Γ(a+b)；正态偶矩的第二次出生。
5. Gamma(k,σ) 族统一指数（k=1）与 Erlang（k 整数）；
   Weibull 补充生存分析；Cauchy 稳定但不 CLT。
