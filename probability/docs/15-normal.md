# 15 正态分布：钟形曲线的解剖

**对应 Miller ch14（pp. 387-413）。**

全概率论（乃至全数学）最重要的分布。中心极限定理让
"独立和的极限是正态"成为普遍现象（第 21 章），本章先把
正态自身解剖清楚：归一化常数的**极坐标技巧**、均值方差
的两个经典积分、**和的稳定性**（正态 + 正态 = 正态——
均匀与指数都没有的特权），以及生成与 68-95-99.7 经验
法则。

## 15.1 归一化常数：极坐标技巧

f(x) = (2πσ²)^{−1/2}e^{−(x−μ)²/2σ²}。**先证可归一**（粗糙
上界）：换元缩到 I = (2/√π)∫₀^∞e^{−v²}dv，劈成 [0,1] 与
[1,∞)，后者用 e^{−v²} ≤ e^{−v} 收割：I ≤ (2/√π)(1 + 1/e)
≈ 1.543 < ∞——**量级估计先于精确计算**的工艺（真实值
恰为 1，上界不算差）。

**再证常数恰为 1**（原书的招牌推导）：换元归一到
I = ∫(2π)^{−1/2}e^{−x²/2}dx。平方之，哑变量分写成 x、y：

I² = (1/2π)∬e^{−(x²+y²)/2}dxdy——**二重积分请出极坐标**：

= (1/2π)∫₀^{2π}dθ·∫₀^∞ e^{−r²/2}rdr = (1/2π)·2π·1 = 1。

rdr 的那个 r 正是救星：e^{−r²/2}rdr 有闭式原函数 −e^{−r²/2}。
**为什么想到平方**？看到 π 想圆，x² 是 x²+y² 的一半；
"积不出来的一维积分平方后换极坐标"是数学史级的绝招
（同样的技巧第 17 章再立新功）。副产品：∫e^{−x²/2}dx =
√(2π)、∫₀^∞e^{−x²}dx = √π/2。

## 15.2 均值与方差

**均值**：换元 u = x−μ 拆成 μ·1 + ∫u·（密度）——后者
是奇函数对称积分为零（e 指数只依赖 u²），故 **μ_X = μ**。

原书在此**故意演示经典错误**：对 ∫u·e^{−u²/2σ²}udu 直接
换元 t = u²/2σ² 而**不改积分限**——u 从 −∞ 到 ∞，t 却
"从 ∞ 到 ∞"；换元不可逆（u 与 −u 撞车）时必须**分段**
再换。错误答案 1/√π 非零，与奇函数矛盾——**答案的合
理性检查抓出换元事故**。

**方差**：换元 w = (x−μ)/σ 提出 σ²，剩 ∫w²e^{−w²/2}dw。
分部积分的选边艺术：u = w（降次）、dv = we^{−w²/2}dw
（**只有配上 w 才有原函数** −e^{−w²/2}；裸 e^{−w²/2} 无初等
原函数），得 σ²_X = σ²[0 + ∫e^{−w²/2}dw] = **σ²**（回收
15.1 的积分 1）。

**偶矩**：微分恒等式（第 12 章 σ³d/dσ）给
M(2m) = (2m−1)!!；奇矩全零（对称）。Gamma 视角
M(2m) = 2^m·Γ(m+1/2)/√π（第 16 章会师）。

## 15.3 和的稳定性：正态 + 正态 = 正态

**定理**：X ~ N(μ_X, σ_X²)、Y ~ N(μ_Y, σ_Y²) 独立，则
X+Y ~ **N(μ_X+μ_Y, σ_X²+σ_Y²)**（n 项同理——分组归纳）。

**期望与方差本来就如此**（第 10 章），稀奇的是**形状
也在族内闭合**——这样的分布叫**稳定分布**。均匀不是
（三角形）、指数不是（Erlang）、泊松是（λ 相加——离散
世界的同类特权）、Cauchy 也是（第 16 章）。稳定性是
正态的核心特权，CLT 的深层根源。

**Case 1 完整推导**（μ_X = μ_Y = 0、σ_X² = σ_Y² = 1）：
卷积积分的指数 t² + (z−t)² = 2t²−2zt+z²，**配方**（加零
的艺术）：2(t−z/2)² + z²/2，于是

f_{X+Y}(z) = e^{−z²/4}/√(2π)·∫e^{−u²}du = e^{−z²/4}/(2√π)
= **N(0,2) 的密度** ✓。

读法：配方把 z 从平方项里"挤"到线性位移，剩余高斯
积分与 z 无关、恰好供出归一化常数——**正态在卷积下
闭合的代数引擎就是配方法**。

**Case 2**（一般 μ、σ²）字母汤更浓但结构相同；**快代数
路线**：先证 aX+b ~ N(aμ+b, a²σ²)（换元公式一行），把
两变量标准化后归回 Case 1——**先化简再进攻**的范式。

## 15.4 经验法则与 CLT 先声

**68-95-99.7 法则**：P(|Z| ≤ 1) ≈ 68.27%、P(|Z| ≤ 2) ≈
95.45%、P(|Z| ≤ 3) ≈ 99.73%（Z 为标准正态）——无闭式
CDF 时的速算装备（数值表/机器通道的必要性）。原书
14.5 节的各应用例皆以此打底。

**CLT 先声**：第 14 章均匀和 n = 8、指数和 n = 30 的
正态对照已见雏形；正态自身的稳定性解释了"和族"为何
总是回到正态附近。完整定理（标准化和 → N(0,1)）在
第 20-21 章，届时母函数与 Fourier 变换是发动机。

**生成**：正态无闭式反 CDF——Box-Muller（两个均匀造
两个独立正态，极坐标技巧的回马枪，第 22 章）与拒绝
采样（习题路线）补位；机器通道用 `randn` 的库实现。

## 15.5 机器通道

**Python（`15_normal.py`）**：数值账——① φ 的 Simpson
归一 = 1、均值 0（奇函数积分数值 ~10⁻⁹）、方差 1；
② 偶矩链 M(2)、M(4)、…、M(12) vs (2m−1)!!；③ 68-95-99.7
的 Simpson 数值（68.27/95.45/99.73 三位对齐）；④ 和稳定
性：N(0,1)+N(3,4) 的卷积数值积分 vs N(3,5) 密度逐点比
对（九个点 |差| < 10⁻⁶）；⑤ 极坐标技巧的数值重演：
∬e^{−(x²+y²)/2}/(2π) 在大圆盘上的 Simpson = 1。

**Julia（`15_normal.jl`）**：频率形态——① 标准正态样本
均值 0、方差 1（10⁶ 次）；② 偶矩样本值 vs (2m−1)!!；
③ 和稳定性模拟：X+Y 的样本方差 ≈ σ_X²+σ_Y²、
Shapiro 式偏度检查；④ 68-95-99.7 经验频率；⑤ μ+a 对
称性：P(X ≤ μ−a) = P(X ≥ μ+a) 的频率对照。

**Lean（`Ch15Normal.lean`）**：判决侧——① 密度对称性
(x−μ)² = (μ−x)² 的 ring 判决（均值 μ 的结构根源）；②
偶矩 decide 链（1、3、15、105、945）；③ 和稳定性的常数
账：N(0,2) 在 0 处的密度 (2√π)^{−1} = φ(0)/√2（平方等式
判决）；④ 标准化换元 aX+b 的参数账（μ_Y = aμ+b、
σ_Y² = a²σ² 的数值例）；⑤ √(2π) 与 √π 的代数关系
（极坐标技巧的常数残迹）。

## 15.6 要点回顾

1. 归一化两步走：粗糙上界证可归一（1.543），极坐标
   技巧证常数恰为 1——I² 换极坐标，rdr 是救星。
2. μ、σ² 从密度的 (x−μ)²/σ² 结构读出；换元不改界是
   经典事故（奇函数 vs 非零答案的矛盾抓错）。
3. 偶矩 (2m−1)!!、奇矩 0；M(2m) = 2^mΓ(m+1/2)/√π。
4. **和的稳定性**是正态特权（配方引擎）；泊松与 Cauchy
   也稳定，均匀/指数不。
5. 68-95-99.7 速算；无闭式 CDF → 数值表与采样法。
