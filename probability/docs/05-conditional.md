# 05 条件概率、独立与 Bayes

**对应 Miller ch4（pp. 147-174）。**

新信息到来时，概率怎么更新？这是概率论区别于纯计数的时刻
——**条件概率**是"知道了一部分之后重新下注"的数学。本章的
主线三件套：条件概率的定义与乘法链、独立性的两种检验、
Bayes 定理——终点是 Monty Hall 问题的完整解剖（全书最著名
的悖论）。

## 05.1 条件概率：三种读法一个定义

**定义 05.A**。P(A|B) = P(A∩B)/P(B)（P(B) > 0），读作
"已知 B 发生的条件下 A 的概率"。三种理解：

- **切割读法**：B 把样本空间切小了——新的全空间是 B，A 的
  份额按 A∩B 占 B 的比例重新归一；
- **赌局读法**：B 发生后赌场重新开盘，旧账（B 之外的部分）
  全部作废；
- **频率读法**：在 B 发生的那些试验里，A 也发生的比例
  （数值通道的模拟正是这个读法的机械化）。

**乘法链**（定义的移项）：P(A∩B) = P(A|B)·P(B)；三事件
P(A∩B∩C) = P(A)·P(B|A)·P(C|A∩B)——**按发生顺序逐级
条件化**。抽牌问题的标准姿势："两张 A 的概率" =
(4/52)·(3/51)（第二张在第一张已是 A 的条件下只剩 3 张 A）。

## 05.2 全概率与 Bayes：分母机器与反向推理

**定理 05.B（全概率律）**。{B₁,…,Bₙ} 是 Ω 的分割，则
P(A) = Σᵢ P(A|Bᵢ)P(Bᵢ)。**读法**：想知道 A，把世界按 Bᵢ
分情况讨论，每种情况的"A 概率"按该情况的权重加权——
"分情况求全"的机器化（第 02 章两块版的完全体）。

**定理 05.C（Bayes 定理）**。
P(Bⱼ|A) = P(A|Bⱼ)P(Bⱼ) / Σᵢ P(A|Bᵢ)P(Bᵢ)。
推导一行（全概率做分母）——但意义巨大：**它把推理方向
反过来**。P(A|B) 是"由因推果"（病因→症状），Bayes 给出
P(B|A) 是"由果推因"（症状→病因）——**诊断、滤波、垃圾
邮件分类的数学引擎**。

**先验与后验**：P(Bⱼ) 是见到证据 A 之前的信念（先验），
P(Bⱼ|A) 是更新后的信念（后验）。Bayes = 理性更新的规则。
医学检验的经典账：病率 1/1000、假阳率 5% 的检验呈阳性，
真病概率 = (0.95·0.001)/(0.95·0.001 + 0.05·0.999) ≈ 1.9%
——**直觉的 95% 错在忽略先验**（健康人群的基数压倒一切）。
这一类"基率忽视"是 Bayes 教学的第一课。

## 05.3 独立性：乘法就够了

**定义 05.D**。A 与 B 独立 ⟺ P(A∩B) = P(A)P(B)——
即 P(A|B) = P(A)（B 的信息不改变 A 的赌率）。**两检验**：
乘法检验（定义）与条件检验（等价形式）；实战中先问直觉
（两件事有无物理因果纠缠）再跑检验。

**成对 ≠ 相互**：三个事件可以两两独立却不相互独立（经典
反例：掷两骰，A = "和为偶"、B = "和能被 3 整除"型的构造，
或 ε₁, ε₂, ε₁ε₂ 的三事件系统——机器通道 05.5 会穷举验证）。
"相互独立"要求**一切子族**的乘法成立——这是第 08 章
随机变量独立性的原型。

**条件独立 ≠ 独立**：给定 C 时独立的两事件可以无条件相关
（反之亦然）——"独立"永远是相对于信息集的性质。

## 05.4 Monty Hall：完整解剖

**问题**：三扇门后一车两羊。你选 1 号门；知道内情的主持人
打开 3 号门（露出羊），问：换 2 号门吗？

**错误直觉**：剩下两门，各 1/2——换不换无所谓。

**正确账（条件化）**：设车在 i 号门为事件 Cᵢ（先验各 1/3），
主持人开门为事件 H。策略的账要**对每个 Cᵢ 分情况**：
- C₁（车在 1，你选对了）：主持人随便开 2 或 3（开 3 的
  条件概率 1/2）——此时换门**输**；
- C₂（车在 2）：主持人**必须**开 3（不能开车也不能开你的
  门）——此时换门**赢**；
- C₃：主持人必须开 2——但 H 是"开了 3"，条件概率 0，
  此情况被证据排除。

P(H|C₁)·P(C₁) = 1/2·1/3 = 1/6；P(H|C₂)·P(C₂) = 1·1/3 =
1/3；P(H|C₃) = 0。Bayes：
P(C₂|H) = (1/3)/(1/6 + 1/3) = 2/3——**换门赢率 2/3**。

**错误直觉的病根**：把"主持人开门"当成无信息的随机事件
（那就确实 1/2），但主持人的选择**携带信息**（他不能开车
门）——信息的不对称正是条件概率的舞台。100 扇门的夸张版
（主持人开 98 扇羊门）让 2/3 直观化：你第一次选对的概率
1/100，剩下那扇门几乎必然是车。

**三囚徒问题**（同构前身）与"主持人不知情开到羊"的变体
（此时真 1/2——条件结构变了结论就变）都在正文 05.5 的
Prolog 穷举里一网打尽。

## 05.6 要点回顾

1. 条件概率 = 切割样本空间的重新归一；乘法链按时间顺序
   逐级条件化。
2. 全概率 = 分情况求全的机器；Bayes = 反向推理（先验 ×
   似然 / 证据）。
3. 基率忽视：后验被先验的基数压弯——检验的"准确率"要
   除以证据总账才有意义。
4. 独立的定义是乘法（P(A∩B) = P(A)P(B)）；成对独立 ≠
   相互独立；条件独立是另一门语言。
5. Monty Hall 的 2/3 = 主持人的选择携带信息；穷举 6 行
   胜过千言万语。
6. 机器分工：精确 Bayes 账（Python）、模拟频率（Julia）、
   6 行穷举（Prolog）、定理形式（Lean/Isabelle）。
