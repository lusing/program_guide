# 11 卷积与变量替换：和的密度与变换的密度

**对应 Miller ch10（pp. 302-325）。**

期望线性性（第 10 章）告诉我们"和的期望 = 期望的和"，但**和的
分布**是另一回事——那是本章第一主题（卷积）。第二主题是
**变量替换**：知道 X 的密度，Y = g(X) 的密度如何求？两个
主题共享同一个纲领：**从部件的密度拼出整体的密度**。

## 11.1 为什么"知道两个密度"还不够

设 X 与 Y 都服从 [−1/2, 1/2] 上的均匀分布。Z = X + Y 的密度
是什么？**这个问题无解**——信息不足：

- 若 Y = −X（完全负相关）：Z ≡ 0，全部质量在一点；
- 若 Y = X（完全正相关）：Z = 2X，均匀铺在 [−1, 2]。

同一对边缘密度 fX = fY，联合结构不同则和的分布天差地别。
**独立性是解锁卷积公式的钥匙**（对照第 10 章"线性性不需要
独立"——两章的分界线）。

为什么要关心"和"？Miller 的分解纲领：化学把化合物拆成原子、
数论把整数拆成素数，概率把 n 次投掷拆成单次再**组合**。n 骰
子的分布 = 单骰分布的 n 重卷积；第 21 章的中心极限定理正是
"无穷多次卷积的极限"——卷积是 CLT 证明的发动机。

## 11.2 卷积：定义、定理与证明骨架

**定义**：独立 X、Y（密度 fX、fY）的卷积

- 连续：(fX ∗ fY)(z) = ∫ fX(t)·fY(z−t) dt；
- 离散：(fX ∗ fY)(z) = Σₙ fX(xₙ)·fY(z−xₙ)。

**定理**：Z = X + Y 则 fZ = fX ∗ fY；且卷积可交换。

**证明骨架**（连续情形，"CDF 法"的第一次正式出场）：

FZ(z) = P(Z ≤ z) = ∫ fX(t)·P(Y ≤ z−t) dt = ∫ fX(t)·FY(z−t) dt

对 z 求导（积分号下求导，需分析学背书，附录 B.2.1），链式
法则给出 fY(z−t)，即得卷积公式。

**交换律的"好证明"**：加法交换 ⟹ X+Y = Y+X ⟹ 密度相同
⟹ fX∗fY = fY∗fX——一行结构论证顶替一页换元代数。Miller
的评语值得抄录：*你可以用大量代数解决问题，但往往有更好的
路*。

**读法**：(fX∗fY)(z) 把"和为 z"的所有分解方式 (t, z−t) 的
概率密度乘积聚起来——它是加法结构在密度世界的投影。第 20
章将看到母函数把卷积变成**乘法**（Fourier 变换的核心性质），
难积分变成易乘法。

## 11.3 骰子实弹与 grouping 智慧

**两骰**（第 08 章三角形的卷积再推导）：fZ(8) = Σ_{k=2}^{6}
(1/6)(1/6) = 5/36；一般地

fZ(z) = (z−1)/36（2 ≤ z ≤ 7）、(13−z)/36（7 ≤ z ≤ 12）。

**四骰与 grouping**：朴素链式 X1+(X2+(X3+X4)) 要做 3 个
**不同**的卷积；聪明分组 (X1+X2)+(X3+X4) 只需 **2 种**
（f 的自卷积用两次，再卷一次）。八骰分组
((X1+X2)+(X3+X4))+((X5+X6)+(X7+X8)) 只需 3 种卷积
（对数式节约，与快速幂同构——Miller 习题 10.8.12 点名
x¹⁰⁰ 从 99 次乘法降到 8 次以内）。

**结合律免费**（proof by grouping）：Z = (X1+X2)+X3 与
X1+(X2+X3) 两种括号给出 (f1∗f2)∗f3 = f1∗(f2∗f3)——零
积分、零求和，纯分组论证。n 重和的密度 = n 重卷积（任意
加括号）。

**四骰的账**：f_{X1+X2} 已知（三角形），自卷积一次即四骰
分布。fZ(6) = Σ_k f₂(k)f₂(6−k) = (1·3 + 2·2 + 3·1)/36² =
10/1296 = 5/648——比枚举 1296 个结果省一个数量级。分布的
形状（原书图 10.3）已见钟形轮廓：CLT 的先声。

## 11.4 变量替换公式：fY = fX(h(y))·|h′(y)|

**定理**：X 的密度集中在区间 I，g : I → ℝ 可微、可逆（逆
函数 h），且 g′ 在 I 上定号（除有限个零点）。则 Y = g(X)
的密度

fY(y) = fX(h(y))·|h′(y)|。

**条件的用意**：

- **可逆**：g(x) = x² 在 I = [−1,1] 上不可逆（1/4 回溯到
  ±1/2 两个原像）——公式无处安放；在 I = [0,2] 上可逆 ✓。
- **g′ 定号**：g 严格单调 ⟺ 一一对应；导数为零的孤立点
  无妨（x³ 在 0 处 g′ = 0 但仍严格增）。
- **h′(y) = 1/g′(h(y))**（对 g(h(y)) = y 求导）：知道 g′
  就免解 h 的导数；但 h 本身必须求出（fX 要在 h(y) 处取值）。

**绝对值的来历**（证明的两案例）：g′ > 0 时 I = [a,b] 映到
[g(a),g(b)]，FY(y) = FX(h(y))，求导得 fY = fX(h)·h′（正）；
g′ < 0 时端点翻转，FY(y) = 1 − FX(h(y))，求导得 −fX(h)·h′
（此时 h′ < 0，−h′ = |h′|）。两案例汇合于 |h′|。**归一性
检查**：∫fY = ∫fX(h(y))h′(y)dy 换元 u = h(y) 回 ∫fX = 1 ✓。

**招牌例**：X 均匀于 [0,2]（fX = 1/2），Y = X²。h(y) = √y、
h′(y) = 1/(2√y)：

fY(y) = 1/(4√y)，0 ≤ y ≤ 4。

**y = 0 处密度无穷**——但"弱无穷"：爆破速度慢于 1/y，积分
仍为 1（√y/2 |₀⁴ = 1 ✓）。平方变换把均匀质量向 0 端挤压
（大 x 的像摊得稀疏，小 x 的像挤得紧密）。

**CDF 法（推荐的重新推导）**：不背公式，现场重推——
FY(y) = P(X² ≤ y) = P(0 ≤ X ≤ √y) = F_X(√y) = √y/2，
求导得 1/(4√y)。原书的忠告：*记住"从 CDF 求密度"这个
母法，公式每次现场再生*——比背公式慢一点，但不会错。

## 11.5 附录：积与商的密度

**乘积**（独立非负 X、Y，Z = XY）：

fZ(z) = ∫₀^∞ fX(t)·fY(z/t)·dt/t。

**除商**（Z = X/Y）：

fZ(z) = z⁻²·∫₀^∞ fX(x)·fY(x/z)·x dx。

推导同 CDF 法（对 z 求导换序）。**测度的深层注**：dt 在
加法平移下不变（w = t+α ⟹ dw = dt），dt/t 在乘法缩放下
不变（w = αt ⟹ dw/w = dt/t）——乘积公式配 dt/t 正是
"乘法世界里的均匀测度"。先取对数（U = log X + log Y =
log(XY)）也能把积化为和：**见到乘积就取对数**的巴甫洛夫
反射在此有测度论根据。

**指数商的惊奇**：X、Y 独立同 Exp(λ)，Z = X/Y 则

fZ(z) = 1/(1+z)²，z ≥ 0——**与 λ 无关**！

推导把被积函数配成参数 ω = λ(1+1/z)⁻¹ 的指数分布均值
（分部积分 ∫t·e^{−t/ω} = ω²），λ 全部约去。验证：∫₀^∞
dz/(1+z)² = 1 ✓。原书随即抛出一个模拟陷阱：不同 λ 大量
模拟 X/Y 的**样本均值忽高忽低**——为什么？（答案在第 13
章：这个分布的均值是 ∫z/(1+z)² = ∞，样本均值不收敛，
大数定律失效——机器通道 Julia 将现场复现。）

## 11.7 要点回顾

1. 和的密度由**联合结构**决定，独立性才给出闭式：fX+Y =
   fX ∗ fY；卷积可交换（结构论证）、可结合（分组论证）。
2. grouping 智慧：(X1+X2)+(X3+X4) 比链式括号省一半卷积，
   n 个和只需对数多种卷积——与快速幂同构。
3. 换元公式 fY(y) = fX(h(y))|h′(y)|：g 可逆 + 导数定号；
   绝对值吸收减函数的端点翻转；**CDF 法可现场再生公式**。
4. 积/商公式出自同一 CDF 法；dt/t 的乘法不变性是"取对数
   化积为和"的测度论根据。
5. 指数商 1/(1+z)² 与 λ 无关；其均值无穷（第 13 章伏笔），
   样本均值不收敛是它的频率签名。
