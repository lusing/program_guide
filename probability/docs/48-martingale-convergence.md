# 第 48 章 离散鞅 II：一致可积、停时与选样

## 48.1 一致可积：把期望搬过极限的通行证

第 47 章结尾留下的裂缝是：a.s. 收敛不保证期望收敛。修补它的概念是本章的主角。

**定义（胡书定义 7.3.1）** 称随机变量族 $\{f_n\}$ **一致可积**（UI），若

$$ \lim_{c\to\infty}\ \sup_n\ \int_{\{|f_n|\ge c\}}|f_n|\,d\mu\ =\ 0. $$

读法：不仅每个 $f_n$ 可积，而且"质量的尾巴"被**一致地**控制——把尾部剪掉时，全家族同时喊疼收敛。三条入门事实（注 7.3.1-7.3.3）：每个 $f_n$ 可积不推出 UI（反例见 48.2 ）；被一个可积函数 $g$ 一致控制（ $|f_n|\le g$ ）则 UI（控制收敛定理的前提）；UI 蕴含 $\sup\int|f_n|<\infty$ 。

定理 7.3.1 是 Fatou 引理与控制收敛的"UI 版"：UI 族上，$\liminf\int f_n\le\int\liminf f_n\le\int\limsup f_n\le\limsup\int f_n$ ——期望的极限运算在 UI 下与逐点极限可交换（(b) 款）。定理 7.3.2 再补 $L^p$ 版：若 $f_n\to f$ 依概率且 $\{|f_n|^p\}$ UI，则 $f_n\to f$ 于 $L^p$ 。这两个定理是本章全部后续的引擎。

## 48.2 例 7.3.1：UI 失败的活体标本

胡书例 7.3.1：$Y_j$ iid、$P(Y_j=1)=p$ ，令 $X_n=p^{-n}\prod_{j\le n}Y_j$ 。取 $p=1/2$ ：

- **鞅性**：$E[X_{n+1}\mid\mathcal F_n]=X_n\cdot 2\cdot\frac12=X_n$ ；
- **均值恒 1** ： $E[X_n]=2^n(1/2)^n=1$ 对一切 $n$ ——本章三通道都用精确分数复验这条；
- **轨道坍缩**： $P(X_n>0)=(1/2)^n\to0$ ，a.s. 极限是 0 ；
- **UI 失败**：对任何 $c$ 取 $n$ 使 $2^n>c$ ，则 $E[|X_n|1_{\{|X_n|\ge c\}}]=1$ ——sup 恒 1 。

于是 $E[X_\infty]=0\ne1=\lim E[X_n]$ ：**期望在极限处丢了一整块钱**。丢去哪了？质量 $1$ 藏在概率 $(1/2)^n$ 、取值 $2^n$ 的越来越尖的峰里——每个 $X_n$ 可积，但家族的"质量布局"越搬越远，UI 正是禁止这种搬运的条款。Python ① 段用 $c=4,16,64$ 逐档演示：截断项永远精确等于 1 ：

```python
for c_int in [4, 16, 64]:
    n = c_int.bit_length() + 1          # 保证 2^n > c
    trunc = F(2 ** n) * F(1, 2) ** n    # E|X_n|·1{|X_n|>c}
    assert trunc == 1                   # 截断项恒 1——sup_n 不衰减
```

每一行都不含近似：UI 失败不是一个渐近现象，而是在每个有限的 $n$ 处都精确成立的代数事实。

## 48.3 Lévy 鞅与上升/下降定理

**引理 7.3.1** 条件期望族 $\{E(|Y|\mid\mathcal G_i)\}$ 一致可积——Doob 鞅天然带 UI 装备。

**定理（胡书定理 7.3.3，上升）** $\mathcal F_n\uparrow\mathcal F_\infty$ ，$Y$ 可积，则 $X_n=E(Y\mid\mathcal F_n)$ 同时 a.s. 与 $L^1$ 收敛到 $E(Y\mid\mathcal F_\infty)$ 。

**定理（胡书定理 7.3.4，下降）** $\mathcal F_n\downarrow\mathcal F_\infty$ 时同样成立（逆鞅）。

证明的骨架是"单调类定理 + UI"：a.s. 收敛来自定理 7.2.5（Doob 收敛），$L^1$ 收敛来自引理 7.3.1 的 UI 加定理 7.3.1(b) ，最后用 $\bigcup\mathcal F_n$ 上的测度相等 + 单调族定理钉死极限就是条件期望。

本章机器账给上升定理一个看得见的实现：$Y\sim U(0,1)$ ，$\mathcal F_n$ = "揭示 $Y$ 的二进制展开前 $n$ 位"。则 $X_n$ = 所在二进区间的中点，且

$$ E[(X_n-Y)^2]=\frac{1}{12}\cdot4^{-n} $$

——精确分数逐 $n$ 成立（Python ② / Prolog ③），每多一位信息误差方差除以 4 。Julia ② 的 20000 次模拟逐位对账（$n=6$ 时 $2.04\times10^{-5}$ 对理论 $2.035\times10^{-5}$ ）：

```julia
for n in [1, 3, 6]
    errs = Float64[]
    for _ in 1:20000
        u = rand(rng2)                       # Y ~ U(0,1)
        lo = floor(u * 2^n) / 2^n            # 揭示前 n 位后的区间下端
        x = lo + 1 / (2 * 2^n)               # 区间中点 = E[Y|F_n]
        push!(errs, (x - u)^2)
    end
    @assert abs(mean(errs) - 1 / (12 * 4.0^n)) < 0.1 / (12 * 4.0^n) + 1e-6
end
```

条件期望在这里不是抽象算子，而是"区间中点"这一句三行的实现—— $L^2$ 误差每步除以 4 的速率肉眼可见。二进区间套同时给出 a.s. 收敛的直觉：区间长度趋零，$X_n$ 被"夹"向 $Y$ 。

## 48.4 UI 主定理与鞅的完整收敛

**定理（胡书定理 7.3.5）** $\{X_n,\mathcal F_n\}$ 一致可积下鞅，则 (a) 存在可积 $X_\infty$ 使 $X_n$ 同时 a.s. 与 $L^1$ 收敛；(b) 延拓到 $\mathcal F_\infty$ 后 $\{X_n,\mathcal F_n,n\le\infty\}$ 仍是下鞅；(c) 鞅情形延拓仍是鞅。

**定理 7.3.6** 非负、有最后元素 $X_\infty$ 的下鞅自动 UI。**推论 7.3.1**（全书最漂亮的结构定理之一）：一致可积鞅 **当且仅当** 是 Doob 鞅——存在可积 $Y$ 使 $X_n=E(Y\mid\mathcal F_n)$ a.s.

推论 7.3.1 把第 47 章的两个基本例子缝成了同一个故事的开始与结束：Doob 鞅（例 7.1.2）在 UI 下收敛回"它的真相" $E(Y\mid\mathcal F_\infty)$ ；而例 7.3.1 的病态鞅恰恰**没有**可积的真相可供逼近——它的"真相"是 0 但均值 1 已在途中蒸发。mathlib 的锚：

## 48.5 停时与停时前 σ 代数

先给一个最小的工作示例把定义焐热：两步公平游走、$T$ = 首次 $S\ge1$ 。在 4 个样本点上 $T$ 取值为：$(+,\cdot)$ 两点处 $T=1$ ；$(-,+)$ 处未中（两步内 $S=(-1,0)$ ），$T>2$ ；$(-,-)$ 处同样 $T>2$ 。事件 $\{$ 首步为 $+\}$ 属于 $\mathcal F_T$ ——无论在哪一点，"首步为 $+$ "在停时前已可判定；而事件 $\{$ 第二步为 $+\}$ 不属于 $\mathcal F_T$ ：在 $(+,-)$ 点 $T=1$ ，第二步的结局在停时后才揭晓。**"停时前可知"与"固定时刻可知"的差异在 $T$ 随机提前时就显形了。**

**定义（胡书定义 7.4.1-7.4.2）** $T$ 是停时若 $\{T\le n\}\in\mathcal F_n$ ；**停时前 σ 代数**

$$ \mathcal F_T=\{A\in\mathcal F:\ A\cap\{T\le n\}\in\mathcal F_n,\ \forall n\} $$

收集"在时刻 $T$ 已经确定"的事件。命题 7.4.1 给封闭性（$\min/\max$ 、和、上下确界）；注 7.4.2 给单调性 $T_1\le T_2\Rightarrow\mathcal F_{T_1}\subset\mathcal F_{T_2}$ 。

直觉校准：$\mathcal F_T$ 不是" $T$ 时刻的信息"这么笼统——它是"到停时为止累积的全部信息，停得早就少知道、停得晚就多知道"。选样定理对 $\mathcal F_T$ 可测性有精确要求，这也是它比"代入随机下标"深刻得多的原因。

## 48.6 定理 7.4.2 的三段证明导读

有最后元素的下鞅 $\{X_n,n\le\infty\}$ 上，停时列替换保持下鞅性——胡书的三段拆解值得逐段读：

- **第一段（负部有界）**：先做 $X_n\le1$ 、$X_\infty=0$ 的情形。取 $S_k=T_n\wedge k$ （有界停时），Fatou 引理给 $\limsup\int_{B}X_{S_k}\le0$ ，从而 $Y_n$ 可积；再用注 7.4.3(a) 的有界情形得 $\{X_{T_n\wedge k}\}$ 下鞅，取 $k	o\infty$ 收尾。
- **第二段（Doob 鞅部 UI）**：令 $Z_n=E(X_\infty\mid\mathcal F_n)$ ——引理 7.3.1 保证 $\{Z_n\}$ 一致可积，于是 $\{Z_{T_n}\}$ 满足定理 7.4.1 的 (A)(B)（UI 把截断项一致压零，条件 (B) 的 liminf 直接达成）。
- **第三段（合并）**：原下鞅 $X_n=Z_n+(X_n-Z_n)$ ，其中 $X_n-Z_n\le0$ 部分用第一段、鞅部用第二段，相加得 $\{X_{T_n},\mathcal F_{T_n}\}$ 下鞅。

三段各自独立成立又严丝合缝——这是"先分解后各个击破"的典范，与第 47 章 Doob 分解（习题 7.3：上鞅 = 鞅 − 可料增过程）互为表里：一个分解值序列，一个分解信息结构。

## 48.7 选样定理：停时替换定理

**定理（胡书定理 7.4.1，选样定理）** $\{X_n\}$ 下鞅，$T_1\le T_2\le\cdots$ 单调上升有限停时列，$Y_n=X_{T_n}$ 。若 (A) $E|Y_n|<\infty$ ；(B) $\liminf_{k}c_kP(T_n>k)=0$ ，则 $\{Y_n,\mathcal F_{T_n}\}$ 是下鞅（鞅时 $Y_n$ 也是鞅）。

注 7.4.3 给出最常用的两个充分情形：(a) $T_n\le K_n$ 一致有界；(b) $E(\sup|X_n|)<\infty$ 。**定理 7.4.2** 把有最后元素的下鞅整个搬过去（三段证明：先负部有界、再 Doob 鞅部 UI、再合并）。

**可选停止的正反两课**（本章机器账的核心实验）：

- **正课**：两步公平游走、$T$ = 首次 $S\ge1$ 、截断 $T\wedge2$ ——四路径穷举 $E[S_{T\wedge2}]=0=E[S_2]$ （Lean/Python/Prolog 三方同账，四值 $[1,1,0,-2]$ ）：

```prolog
twostep_value(E1, E2, V) :-
    S1 is E1,
    (   S1 >= 1 -> V = 1          % 首步即中：S_T = 1
    ;   S2 is E1 + E2, V = S2 ).  % 未中：取 T∧2 处即 S_2
% 四值 [1, 1, 0, -2]，sum/4 = 0 —— 精确分数判决
```
- **反课**：$T$ = 首次 $S=+3$ 不截断——$S_T\equiv3$ 精确成立，$E[S_T]=3\ne0=E[S_0]$ ！可选停止失效的原因不是定理出错，而是条件 (A)(B) 同时失守（ $E[T]=\infty$ ）。Julia ④ 演示截断版本 $E[S_{T\wedge n}]$ 随 $n$ 缓慢爬升（$-0.04\to0.08$ ）——"等待成本"以 $o(1)$ 的速度返还，恰是 $E[T]=\infty$ 的数值签名。

## 48.8 习题 7 精选的两件

- **习题 7.5（鞅式 Borel–Cantelli）**：上升滤流上 $A_n\in\mathcal F_{n+1}$ ，则 $A_n\ i.o.$ 与级数 $\sum P(A_{n+1}\mid\mathcal F_n)=\infty$ 相差一个零测集。它把第 25 章的 BC 引理升级成"条件版"——事件的无限复发由**条件概率的和**决定，mathlib 的 `Probability/Martingale/BorelCantelli.lean` 正是这条线。
- **习题 7.6（有理数马氏链鞅）**：状态空间 $[0,1]$ 内有理数、从 $a$ 出发以 $1-a$ 概率跌到 $b$ 、以 $a$ 概率升到 $b+1-a$ 的链——(a) $a=b$ 时是收敛到 0/1 的鞅且 $P(X_\infty=1)=E(X_0)$ ；(b) $b<a$ 时是收敛到 0 的上鞅。它把"鞅的极限分布 = 初始期望"做成一个手玩模型，与例 7.3.1 的坍缩互为对照（一个极限保期望，一个不保）。

## 48.10 应用与误区

- **衍生品定价的"提前行权"**：美式期权的最优停时问题就是选样定理的舞台——鞅（折现价格）在停时处的期望等于现值，最优停止把这个问题变成上确界的可达性；条件 (A)(B) 的检查对应交易策略的可实施性。
- **序贯检验的停止规则**：SPRT 的期望样本量有限性用可选停止 + Wald 引理；非法的"偷看后停"会破坏 $\mathcal F_T$ 结构。
- **误区一**："鞅期望恒定，所以在任何停时处停下期望也不变"。反课实验直接驳倒：$E[S_T]=3\ne0$ 。可变的停时必须过 (A)(B) 两关（本质是"不许无限期等"）。
- **误区二**："UI 是技术条件，实践中可略"。它是"期望可以搬过极限"的唯一通行证；蒙特卡洛里"方差无穷的估计量均值却在漂"的现象，多数是 UI 失败的样本版。
- **误区三**："a.s. 收敛足够强，其他收敛自动跟上"。三层证据链（定理 7.2.5 → UI → $L^1$ ）每一层都有独立反例隔开，例 7.3.1 就是 a.s. 有、 $L^1$ 无的界碑。
- **误区四**："$\mathcal F_T$ 是 $T$ 时刻的 σ 代数"。它是"停时前"累积的信息体，与 $T$ 的取值动态绑定；$T_1\le T_2$ 时的包含关系是理解嵌套信息结构的钥匙。

## 48.13 两道自测题

**题一（UI 判定）**：族 $\{X_n\}$ 中 $X_n$ 以概率 $1-1/n^2$ 取 0 、以概率 $1/n^2$ 取 $n$ 。问：每个 $X_n$ 可积吗（是， $E|X_n|=1/n$ ）；族 UI 吗（是—— $E|X_n|1_{\{|X_n|\ge c\}}\le 1/n	o0$ 且 sup 对 $n\ge\sqrt c$ 后一致小，截断项 $\sup_n\le\max_{n\le\sqrt c}n/n^2$ 收敛）。对比例 7.3.1 把概率换成 $(1/2)^n$ 、取值换成 $2^n$ ：单个质量恒为 1 ，UI 立刻失败。**判定 UI 的手感：质量 × 概率的乘积结构是否随 $c$ 一致归零。**

**题二（停时合法性）**：公平游走、$T$ = 首次 $|S_k|\ge5$ 。$E[S_{T\wedge n}]=0$ 对一切 $n$ 成立（有界停时）；$E[S_T]$ 呢？$T$ a.s. 有限但 $E[T]=\infty$ ——不过此时 $|S_T|\equiv5$ 有界，条件 (A) 对单个 $T$ 成立、(B) 由 $E(\sup) $ ？本题的精确答案依赖对 (B) 的检查：$P(T>k)\cdot k	o0$ 成立（首出时间有指数尾），故 $E[S_T]=0$ 实际成立。与 48.6 反课的区别在于：反课的单侧停时（只等 $+3$ ）让 $S_{T\wedge n}$ 的负漂移暴露在截断里，双侧吸收壁则被指数尾保护。**停时的合法性要看尾巴的形状，不是只看是否 a.s. 有限。**
