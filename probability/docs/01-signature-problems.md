# 01 三个招牌问题：生日、投篮与对冲

**对应 Miller ch1（pp. 22-58）。**

概率论的学习不该从公理开始，而该从一个让你说"不可能吧？"
的问题开始。Miller 的开卷三连正是如此：**生日问题**（23 个人
就有一半概率撞生日——直觉说应该要 183 人）；**投篮问题**
（两个球员谁的得分概率高？答案藏在 300 年前的几何级数里）；
**对冲问题**（2008 超级碗的一笔赌注如何把风险变成套利）。
三个问题各自预告了全书的一个主角：计数、级数、期望。

## 01.1 生日问题：反直觉的第一课

**问题**：一个房间里要有多少人，才能使"至少两人生日相同"
的概率超过 50%？（忽略 2 月 29 日，假设 365 天等可能、
各人独立。）

### 01.1.1 正面强攻为什么难

"至少两人相同"的直接计算要枚举各种撞法（恰好一对、两对、
三连击……），组合结构复杂。**关键一步是取补**：

  P(至少两人同生日) = 1 − P(所有人生日互不相同)。

而"全不同"是好算的：第 1 人任选一天（365/365），第 2 人
避开他（364/365），第 3 人避开前两人（363/365）……k 个人
全不同的概率是

  Pₖ = 365·364·363·…·(365−k+1) / 365ᵏ = 365! / ((365−k)!·365ᵏ)。

于是撞车概率 pₖ = 1 − Pₖ。逐项算：p₂₂ ≈ 0.476，**p₂₃ ≈
0.507**——23 人就过半。直觉的 183 人错在哪？直觉把"与我
同生日"当成事件（那确实需要约 183 人），但题目问的是
**任意两人**——配对数是 C(23,2) = 253 对，每对小概率，
合起来就不小了。"人数 vs 配对数"的混淆是概率论第一课的
经典陷阱。

### 01.1.2 近似的艺术：从乘积到指数

精确连乘在 k 大时手算不动，Miller 教你三步近似（这也是
全书"近似"教学的开场）：

**第一步：对数与 Taylor。** 取 −ln Pₖ = −Σⱼ₌₁^{k−1} ln(1−j/365)。
当 x 小时 ln(1−x) ≈ −x − x²/2，于是

  −ln Pₖ ≈ Σⱼ (j/365) + (1/2)Σⱼ (j/365)² = k(k−1)/730 + 小项。

**第二步：平方律。** 主项是 k(k−1)/(2·365)——**配对数的
一半再除以 365**（与 01.1.1 的配对直觉精确对应）。要 pₖ ≈
1/2 需 −ln Pₖ ≈ ln 2，即 k(k−1)/730 ≈ 0.693，解出 k ≈ 23。

**第三步：误差意识。** 二阶项 (1/2)Σ(j/365)² ≈ k³/(12·365²)
在 k = 23 时约 0.024——影响第三位有效数字，所以"23 人过半"
的结论稳如泰山（数值实验见 01.4 节）。**近似不是偷懒，是
带误差账的精确**——这个态度贯穿全书（第 18 章 Stirling、
第 21 章 CLT 的证明都是它的重演）。

### 01.1.3 一般化：撞的不是生日呢

把 365 换成 N 个等可能类别，"过半"所需人数 k ≈ √(2N ln 2)
——生日悖论是 **平方根律**：类别数开根号。一个直接应用：
哈希冲突（N = 2³² 的哈希空间，约 7.7 万个键就有 50% 冲突），
密码学的生日攻击（对 2ⁿ 位输出找碰撞只需约 2^{n/2} 次尝试，
把暴力破解的指数砍半）。Miller 的"Generalizing the Problem"
一节正是这种训练：**解完一题，把数字换成变量，看看规律
长什么样**。

## 01.2 投篮问题：几何级数的复活

**问题**：A 罚球命中率 p = 1/2；B 有两次机会但每次只有
q = 2/5——两人各得 1 分的条件是"A 罚中至少一次"vs"B 至少
一次罚中"，谁得分概率高？

B 的"至少一次中"取补最干净：1 − (1−q)² = 1 − (3/5)² =
16/25 = 0.64 > 1/2——B 赢。**但这只是热身**。Miller 真正的
问题是循环赛式：两人轮流投篮，先中者赢——A 先投，A 中则
胜；A 不中 B 投；B 也不中轮回 A……**先手优势有多大？**

设 A 单投命中率 p、B 为 q。A 获胜的概率 = 首轮即中 p +
（双方各失一轮后回到原状）(1−p)(1−q)·P(A 胜)。于是

  P(A 胜) = p + (1−p)(1−q)·P(A 胜)
  ⟹ P(A 胜) = p / (1 − (1−p)(1−q)) = p / (p + q − pq)。

**几何级数在这儿的身份**：P(A 胜) = p·[1 + r + r² + …]，其中
r = (1−p)(1−q) 是"一轮白过"的概率——每一轮都是上一轮的
r 倍，无穷回合的胜利概率是一个几何级数，公比 r < 1 保证
收敛到 p/(1−r)。p = 1/2、q = 2/5 时 P(A 胜) = 0.5/0.7 ≈
0.714——先手优势超过 21 个百分点。

**换个读法（条件配重）**：也可以不谈级数，直接写
P(A 胜) = p + r·P(A 胜)——一个**自引用方程**。两种读法
（级数求和 vs 不动点方程）是同一件事的两幅面孔，这个
"自己定义自己"的手法在第 24 章（差分方程与 Markov 链）
会成为主角，第 20 章（母函数）给它完整的代数机器。

Miller 在此节还给了三个副产品：**几何级数的求和公式**
Σₖ≥₀ rᵏ = 1/(1−r) 的推导（错位相减，两行）；**公比的
收敛条件** |r|<1 的必要性讨论；**推广到 n 人轮投**的练习。
以及全书反复出现的解题四步法：**读题两遍 → 找对称性 →
小例子试手 → 验证极限情形**（p→0 或 p→1 时公式是否退化
正确）。

## 01.3 对冲：2008 超级 Bowl 的一笔账

**背景**：2008 年超级碗（Giants vs Patriots），有人事先以
1000:1 的赔率押了 Giants 全胜夺冠。Giants 真的进了超级碗，
且比赛进行到最后关头领先——那张票价值飙升。**问题**：
持票人如何在终场前锁定利润？

设终场时票的价值为：Giants 赢则 V_win（巨大），输则 0。
**对冲**：押注 Patriots 一定金额 h。若 Giants 赢：净得
V_win − h；若 Patriots 赢：净得 h·(赔率) − 已付票本。令两者
相等即锁定无风险利润——这就是**期望的线性性**在金融里
的第一现场：不管你怎么信仰 Giants，组合的价值是可以
精确配平的。

Miller 用这个故事讲三件事：**期望值不是预测**（单场结果
不可知，但期望可计算）；**对冲 = 用小代价买确定性**；
**赌市场的赔率是被押注行为定价的**（庄家的 vig——抽水——
保证长期期望为庄家正，这本身就是一个期望账）。第 10 章
（期望工具）会把这些直觉公理化；第 23 章（Markov 与差分
方程）会处理"多轮赌博"的精细结构。

**一个诚实的提醒**（原书的价值取向）：概率论不教你赢赌场
——期望为负的游戏玩得越久输得越确定（第 18 章大数定律的
残酷版本）；它教你的是**识别**哪些局期望为正、哪些"看似
稳赢"其实是陷阱。救生圈的第一课是自救，不是冲浪。

## 01.4 数值检验：全书的第一组对拍

Miller 每章配 Numerical Test，本教程把它做成机器通道。
本章四组实验（全部在正文引用的文件里，摘要如下）：

**① 精确分数账（Python `01_signature_problems.py`）**：
生日问题的 Pₖ 用 `Fraction` 逐项连乘——p₂₃ 的精确值是
分子 65 位、分母 65 位的分数，其浮点值 0.507297…；
同时对 p₂₂ ≈ 0.4757（未过半）与 p₂₄ ≈ 0.5386 给出精确
上下界，确认"23 是过半的最小人数"。

```python
def all_distinct(k):
    """k 人生日全不同的精确概率（Fraction 连乘）。"""
    p = Fraction(1)
    for j in range(k):
        p *= Fraction(365 - j, 365)
    return p
```

这段代码是"取补 + 连乘"的直接翻译：第 j 人避开前面 j 人
的概率是 (365−j)/365——`Fraction` 保证每一步都是精确分数，
最后 1 − p 就是撞车概率。

**② 模拟账（Julia `01_signature_problems.jl`）**：随机生成
k 个人的生日（1..365 均匀），检查有无重复，重复百万次。
k = 23 时模拟频率稳定在 0.507 附近（±0.001 的波动——这个
波动本身由"二项分布的标准差 √(p(1−p)/N) ≈ 0.0005"预告，
是第 13 章的伏笔）。

**③ 几何级数与投篮（同上两文件）**：模拟两人轮流投篮
100 万局，统计 A 胜频率 vs 理论 p/(p+q−pq)；同时对几何
级数 Σrᵏ 做有限项与 1/(1−r) 的逐 r 对拍（r = 0.3/0.6/0.9）。

**④ 对冲账（Python）**：给定赔率与票值，解出配平金额 h
的精确分数并验证两种结局的净得相等——期望线性性的第一
个机械应用。

## 01.5 Lean 侧：连乘即计数

**（`Ch01SignatureProblems.lean`）**本科概率在定理证明器里
的第一站是**把连乘写成有限积**：mathlib 的 `Finset.prod`
正是 Π_{j∈range k} (365−j)/365。本章 Lean 单元做两件事：
① 把 Pₖ 的分子（365 的 k 下降阶乘）登记为
`Nat.factorial` 的商，并验证 p₂₂ < 1/2 < p₂₃ 的**机器判决**
（两个不等式各一行 `Nat.decide` 或数值计算——mathlib 的
`Real` 上有 `norm_num` 数字审判）；② 几何级数求和公式
`geom_series` 的引用与 r = 3/5 的投篮账实例化。正文不预设
Lean 知识：你只需要知道"这段代码是让计算机替我们重算
同一笔账，且不会算错"。

**Prolog 侧（`01_signature_problems.pl`）**：小宇宙穷举——
房间只有 5 人、年份只有 5 天的玩具生日问题，Prolog 枚举
全部 5⁵ = 3125 种生日安排，数出撞车比例与公式对拍。穷举
是悖论的终极溶解剂：**任何说"直觉上不可能"的论断，在
全部 3125 种可能性面前无话可说**。

## 01.6 要点回顾

1. **取补**：正面难算的事件看它的补——生日问题的第一把
   钥匙。
2. **配对数思维**：C(k,2) 对候选碰撞解释了平方根律 k ≈
   √(2N ln 2)（生日攻击、哈希冲突）。
3. **近似带误差账**：ln(1−x) ≈ −x 的 Taylor 展开给出主项
   与修正项——"精确到够用，并知道差多少"。
4. **自引用方程**：P = p + rP 与几何级数是同一枚硬币
   （不动点 vs 部分和），第 24 章 Markov 链的种子。
5. **期望线性性**：对冲配平不看结果只看组合——期望的
   第一现场（第 10 章公理化）。
6. **数值检验是习惯**：每个手算答案配一次模拟（Julia）
   与一次精确分数（Python）——这个纪律全书不变。
