# 12 微分恒等式：从旧恒等式量产新恒等式

**对应 Miller ch11（pp. 326-342）。**

第三件也是最后一件工具。恒等式是数学的硬通货，但**造出**
一个新恒等式很难；微分恒等式法是印钞机：给旧恒等式装上
自由参数，对参数求导，新恒等式无限量产——"大跳蚤背上
有小跳蚤，小跳蚤背上有更小的跳蚤，以至无穷"。

## 12.1 动机：Σ n/2ⁿ 是多少

Σ_{n≥1} n/2ⁿ = 1/2 + 2/4 + 3/8 + 4/16 + ⋯。它像几何级数，
但分子是 n 而非 1——几何公式够不着。

**关键一步：抽象**。别盯着 1/2，研究一族问题 Σ n·xⁿ⁻¹。
为什么推广反而更容易？① 特例里的数字（2）会误导你以
为它重要；② 一族问题带来自由参数，**参数开启微积分**——
连续统上的恒等式可以对参数求导。

从 Σₙ xⁿ = 1/(1−x)（|x| < 1）出发，两侧对 x 求导（求导与
无穷求和换序需衰减条件背书，附录 B.2.2）：

Σₙ n·xⁿ⁻¹ = 1/(1−x)²。

代 x = 1/2：Σ n/2ⁿ⁻¹ = **4**；除以 2：Σ n/2ⁿ = **2**。

**算子选择的工艺**：用 x·d/dx（而非裸 d/dx）作用，幂次不
降——Σ n·xⁿ = x/(1−x)²。再作用一次：

Σ n²·xⁿ = x(1+x)/(1−x)³，代 x = 1/2 得 Σ n²/2ⁿ = **6**。

两次算子应用，分子从 n 换到 n²。**这就是方法的全貌**：
老恒等式 + 参数 + 求导 = 新恒等式流水线。

## 12.2 方法陈述

设 Σₙ f(n; α, β, …, ω) = g(α, β, …, ω) 对参数 α 成立（f、g
关于 α 可微，f 有足够衰减使求导换序合法）。则

Σₙ ∂f(n; α, …)/∂α = ∂g(α, …)/∂α。

**有限和时换序免费**；无穷和需要衰减条件。两个分析学
要件：求导-求和换序（B.2.2）、求导-积分换序（上一章卷积
证明已用过，B.2.1）。**必须有连续统**——离散的单点恒等式
无导数可言，这就是"抽象到参数族"的代价与回报。

## 12.3 二项分布的矩：p∂/∂p 全账

**均值**。从二项定理出发（q 暂作独立变量！）

Σₖ C(n,k)·pᵏqⁿ⁻ᵏ = (p+q)ⁿ。

两侧作用 p·∂/∂p（p 因子保幂次）：

Σₖ k·C(n,k)pᵏqⁿ⁻ᵏ = np(p+q)ⁿ⁻¹。

**最后才**代 q = 1−p：E[X] = np。

**q 独立性的教训**：若一开始就设 q = 1−p，左边恒为 1，
求导得 0 = 0——信息全灭。**自由参数要养到最后一步才收割**
（与 12.1 的抽象同源）。

**方差**。再作用一次 p·∂/∂p：

Σₖ k²·C(n,k)pᵏqⁿ⁻ᵏ = np(p+q)ⁿ⁻¹ + n(n−1)p²(p+q)ⁿ⁻²

代 q = 1−p：E[X²] = np + n(n−1)p²，故

Var(X) = E[X²] − (np)² = np(1−p)。

对照算子 p²∂²/∂p²：一步给出 Σk(k−1)C(n,k)pᵏqⁿ⁻ᵏ =
n(n−1)p²(p+q)ⁿ⁻²（阶乘矩），再拼 k² = k(k−1)+k 回收——
两条路汇合，但 p∂/∂p 连用两次代数更顺。**选对算子省一
半代数**，这是本章反复出现的工艺课。

**组合学的免费午餐**：代 p = q = 1/2 整理，

Σₖ k·C(n,k) = n·2ⁿ⁻¹，Σₖ k²·C(n,k) = n(n+1)·2ⁿ⁻²。

第 07 章的"平均子集大小"恒等式在此**重新出生**——概率
视角反哺纯计数。即使只想算整数和，连续参数也是杠杆。

## 12.4 正态分布的矩：σ³·d/dσ 与 (2k−1)!!

标准正态密度 φ(x) = (2π)^{−1/2}e^{−x²/2}。奇矩 = 0（奇函
数对称区间）。偶矩从头算需分部积分归纳；微分恒等式更快。

从归一化等式出发（σ 为自由参数）：

σ = ∫ (2π)^{−1/2}·e^{−x²/2σ²} dx（把 σ 从根号里提出来）。

作用 σ³·d/dσ（σ³ 的用意：求导打在 −x²/2σ² 上带下 x²σ⁻³，
σ³ 补偿后右侧 σ 幂次不变）：

1·σ³ = I(2; σ) = ∫ x²·(2π)^{−1/2}e^{−x²/2σ²} dx。

再作用一次：3·1·σ⁵ = I(4; σ)；再一次：5·3·1·σ⁷ = I(6; σ)。
归纳得

I(2k; σ) = (2k−1)!!·σ^{2k+1}，代 σ = 1：**M(2k) = (2k−1)!!**。

1, 1, 3, 15, 105, 945, …（双阶乘链）。**算子的预补偿**（σ³
保幂次、12.3 的 p 保幂次）是同一工艺在积分世界的翻版。

## 12.5 指数分布的矩：λ²·d/dλ 与 k!·λᵏ

Exp(λ) 密度 λ⁻¹e^{−x/λ}（x ≥ 0；此参数化下均值恰为 λ，
x 与 λ 同单位，λ 进指数的是无量纲比 x/λ——原书的单位学）。

归一化等式乘 λ 后：λ = ∫₀^∞ e^{−x/λ}dx。作用 λ²·d/dλ
（补偿求导带下的 x/λ²）：

λ² = ∫₀^∞ x·e^{−x/λ}dx，除以 λ：**E[X] = λ**。

再作用一次：2λ³ = ∫x²e^{−x/λ}dx，除以 λ：E[X²] = 2λ²，
故 **Var(X) = λ²**。继续下去 E[Xᵏ] = k!·λᵏ（阶乘矩链，
第 17 章 gamma 分布 Γ(k+1) = k! 的先声）。

## 12.6 机器通道

**Python（`12_differentiating.py`）**：精确分数账——① 几何
微分链的 Fraction 精确验证（Σxⁿ = 1/(1−x) → Σnxⁿ →
Σn²xⁿ，x = 1/2、1/3 双点）；② 组合收获的枚举审判：n = 8
的 Σk·C(8,k) = 8·2⁷、Σk²·C(8,k) = 8·9·2⁶ 逐项求和对拍；
③ 二项矩账：n = 5、p = 1/3 的 E[X] = 5/3、E[X²] =
np+n(n−1)p² = 5/3 + 20/9 = 35/9，Var = 35/9 − 25/9 =
10/9 = np(1−p)，与直接求和双路会师；④ 正态偶矩递推
M(2k+2) = (2k+1)M(2k) 的数值积分链 vs (2k−1)!!（k 到 6）；
⑤ 指数矩链 E[Xᵏ] = k!λᵏ 的数值积分验证（λ = 2，k 到 5）。

**Julia（`12_differentiating.jl`）**：频率与数值形态——① 截
断和 vs 闭式：Σ_{n≤N} n/2ⁿ 与 Σn²/2ⁿ 的收敛演示（N = 10
已到 3/256 与更小）；② 二项矩的模拟对拍（n = 10、p = 0.3：
均值 ≈ 3、方差 ≈ 2.1）；③ 正态偶矩：样本矩 vs (2k−1)!!；
④ 指数矩：样本矩 vs k!·λᵏ。

**Lean（`Ch12Differentiating.lean`）**：判决侧——① 几何级数
的截断账（Σ_{n≤10} n/2ⁿ = 509/256 的 ℚ 判决 + 与极限 2 的
距离 3/256）；② 二项恒等式的 decide 审判（Σk·C(4,k) = 32、
Σk²·C(4,k) = 80）；③ 双阶乘链的递推判决（105 = 7·15、
945 = 9·105）；④ 二项矩的 ℚ 精确账（n = 4、p = 1/2 的
E[X] = 2、E[X²] = 5、Var = 1）。

## 12.7 要点回顾

1. 方法 = 老恒等式 + 自由参数 + 求导；参数族（连续统）是
   微积分的入场券——特例无导数可言。
2. **算子工艺**：x·d/dx、p·∂/∂p、σ³·d/dσ、λ²·d/dλ——预
   补偿因子保幂次，省一半代数。
3. **q 独立到最后**：早代 q = 1−p 得 0 = 0；自由参数养到
   收割一步。
4. 二项：E = np、Var = np(1−p)；正态偶矩 (2k−1)!!；指数
   E[Xᵏ] = k!λᵏ——三条产线同一台机器。
5. 概率反哺计数：Σk·C(n,k) = n·2ⁿ⁻¹ 从二项矩免费出厂。
