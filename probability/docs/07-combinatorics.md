# 07 高级组合：枚举与二项恒等式

**对应 Miller ch6（pp. 205-236）。**

计数的第三层功夫：**枚举法**（把"满足条件的对象"数出来，
即使条件纠缠）与**二项恒等式的三种证法**（代数、故事、
母函数预告）。本章是第一篇（一般理论）的收官——从这里
毕业，你应当能对任何"数一数"的问题有条不紊地下手。

## 07.1 枚举法：多项式展开的计数读法

**核心工具**：(x₁ + ⋯ + x_k)ⁿ 的展开。每一项 x₁^{a₁}⋯x_k^{a_k}
（a₁+⋯+a_k = n）的系数是 **n!/(a₁!⋯a_k!)**（多项式系数）——
组合身份："n 个位置分给 k 类（第 i 类 aᵢ 个）"的分法数。

**为什么**：n 个因子（每次从 k 个 x 中选一个）的展开产生
kⁿ 项原始单项式，合并同类项后 x₁^{a₁}⋯x_k^{a_k} 的重数正是
"n 个因子的选择序列中恰有 aᵢ 次选 xᵢ"的方式数——排列
n! 除以各类内部的重复 aᵢ!。**第 03 章"先算多再除重"的
k 类推广**。

**球进桶的全账**（第 06 章篮子问题的计数骨架）：k 个球
进 n 个桶、"桶 i 恰 aᵢ 个球"的分配数 = k!/(a₁!⋯aₙ!)——
同一公式的再次出场。**香草例**：三类香草球（n 个，k 种
口味）倒进两个桶 = 每球独立 2 选 → 2ⁿ 种；桶有序（标签
桶），球在桶内无序——枚举法核对：Σ_{j} C(n,j) = 2ⁿ ✓
（按第一桶的球数分类）。

## 07.2 二项恒等式的三种证法

以 **Pascal 恒等式**（03 章已见）与 **Vandermonde 恒等式**
为主线，Miller 示范三种证明路线——**同一等式走三条路**
是本章的教学习惯：

**① 代数证法**：从公式的分数形式出发做通分与消去。
Vandermonde：Σⱼ C(m,j)C(n,k−j) = C(m+n,k)——两边用
阶乘展开直接算（繁琐但机械可靠）。

**② 故事证法**（计数论证）：给等式两边找同一个计数故事。
Vandermonde 的故事：m+n 人中选 k 人 = 按"来自 m 组的人数
j"分类——左边的每一项 C(m,j)·C(n,k−j) 是该类的数法。
**等式 = 两种数法数同一个东西**——组合恒等式的灵魂。

**③ 母函数证法（预告）**：C(m+n,k) 是 (1+x)^{m+n} 的
xᵏ 系数 = (1+x)^m·(1+x)^n 的 xᵏ 系数 = 卷积 Σⱼ C(m,j)·
C(n,k−j)——**系数的世界里恒等式自动成立**。完整机器在
第 20 章（母函数），此处先尝一口。

**Hockey-stick（溜冰鞋）恒等式**：Σ_{i=r}^{n} C(i,r) =
C(n+1,r+1)。故事：从 0..n 号球中选 r+1 个，按"最大的
号码 i"分类——最大为 i 的选法 C(i,r)，求和即总选法。
溜冰鞋的形状：Pascal 三角形沿对角线求和 = 落在斜下方的
一个数。

**实用恒等式速查**（都以三法可证，习题账单见 07.5）：
- C(n,k) = C(n,n−k)（对称）
- k·C(n,k) = n·C(n−1,k−1)（"选committee并选主席"）
- Σ k·C(n,k) = n·2^{n−1}（平均子集大小）
- C(n,k)C(k,j) = C(n,j)C(n−j,k−j)（先选大组再选小组的
  两种记账序）

## 07.3 碱基序列：枚举法的应用现场

原书的生物应用：DNA 序列（A/C/G/T 四字母）长度 n 的序列
总数 4ⁿ；"恰好出现某模式"的计数要用容斥+枚举组合。更
有趣的账：长度 n 的序列中**恰含某指定子串**（如 "GATTACA"）
至少一次的数目——位置叠加（子串自重叠）使直接计数纠缠，
Miller 展示"枚举可行位置 + 容斥去重"的组合拳——这是
第 20 章母函数方法的动机现场（母函数一行解决纠缠计数）。

## 07.4 组合证明的审美

本章结束时回头看：**好的组合证明 = 给等式一个两边都
自然的故事**。代数证明给你确信，故事证明给你理解，母
函数证明给你威力。Miller 的建议（原书附录 A 的预告）：
每见到一个新恒等式，三法各试一遍——试不动的那个方向
暴露你理解的缺口。

## 07.5 机器通道

**Python（`07_combinatorics.py`）**：精确分数验证——
① Vandermonde 的数值例（m,n,k 各两组，两侧精确相等）；
② hockey-stick 的逐 n 验证（Σ vs C(n+1,r+1)）；③ 多项式
系数 n!/(a₁!⋯a_k!) 与多项式定理展开的对拍（(x+y+z)⁵ 的
系数表）；④ "平均子集大小" Σ k·C(n,k) = n·2^{n−1} 的
精确账。

**Julia（`07_combinatorics.jl`）**：① 随机子集的平均大小
模拟（n = 20，均值 ≈ 10 = n/2——恒等式的频率形态）；
② 球进桶的模拟（k = 30 球 n = 10 桶的桶分布直方图 vs
多项式系数的比例）；③ 碱基序列的随机采样统计 4ⁿ 分母
的规模感。

**Prolog（`07_combinatorics.pl`）**：小宇宙穷举——
① 6 人选 3 的 hockey-stick 现场从（Σ C(i,2) = C(7,3) = 35：
枚举验证）；② 多项式系数的球-桶全枚举（3 球 2 桶 = 2³
分配全列 + 按桶计数归并）；③ Vandermonde 的玩具验证
（m = 3、n = 2、k = 2：C(5,2) = 10 = 3·1 + 3·2? 手推后
穷举）。

**Lean（`Ch07Combinatorics.lean`）**：mathlib 的
`Nat.add_choose`?（Vandermonde 的真名侦察：`Nat.add_choose`
或 `choose_add`）+ hockey-stick（`Nat.choose_sum_range_succ`?）
的锚点登记与小例 decide 验证。

## 07.6 要点回顾

1. 多项式系数 n!/(a₁!⋯a_k!) = 分配计数 = 展开系数——
   一个公式三张面孔。
2. 恒等式三证法：代数（确信）、故事（理解）、母函数
   （威力）。
3. Vandermonde 的故事：两种分组法数同一群人；hockey-stick
   的故事：按最大元素分类。
4. "先选大组再选小组"的记账序交换产生一半的组合恒等式。
5. 机器分工：精确对拍（Python）、频率直方图（Julia）、
   玩具全枚举（Prolog）、定理锚（Lean）。
