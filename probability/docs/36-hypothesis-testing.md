# 第 36 章 假设检验与 Neyman–Pearson 理论

## 36.1 检验是一种有错误预算的决策

估计问“参数大概是多少”，假设检验问“按照预先规定的规则，现有数据是否足以拒绝某个假设”。

检验的输出不是参数真值，而是一个决策：拒绝或不拒绝原假设。

因为样本是随机的，任何非平凡决策都可能出错。

成熟的检验理论不会承诺永远正确，而是明确回答：

- 原假设成立时，错误拒绝的概率有多大；
- 某个备择参数成立时，正确拒绝的概率有多大；
- 在所有满足同一错误预算的规则中，哪一个功效最大；
- 观测数据的极端程度应怎样量化。

本章先建立这些概念，再证明 Neyman–Pearson 引理。

第 37 章再把似然比思想推广到 Wald、LM、LR 三大渐近检验和置信区间。

## 36.2 原假设、备择假设与参数空间

设样本 $X$ 来自分布族 $\{P_\theta:\theta\in\Theta\}$ 。

把参数空间分成两个互斥部分：

$$H_0:\theta\in\Theta_0, \qquad H_A:\theta\in\Theta_A,$$

通常 $\Theta_A=\Theta\setminus\Theta_0$ 。

$H_0$ 称为原假设，$H_A$ 称为备择假设。

“原”不表示它更可能为真，也不表示它享有概率上的先验优势。

它表示检验规则首先控制的是：当 $H_0$ 成立时，不要过分频繁地拒绝它。

### 简单假设与复合假设

若 $\Theta_0$ 只含一个参数值，例如

$$H_0:p=1/4,$$

则称原假设是简单假设。

若它含有多个参数值，例如

$$H_0:p\le 1/4,$$

则称原假设是复合假设。

备择假设也按同样方式分类。

“简单”描述的是假设中包含多少个分布，不是这个问题是否容易。

### 双侧与单侧

对标量参数，常见形式有：

$$H_0:\theta=\theta_0,\quad H_A:\theta>\theta_0;$$

$$H_0:\theta\le\theta_0,\quad H_A:\theta>\theta_0;$$

以及

$$H_0:\theta=\theta_0,\quad H_A:\theta\ne\theta_0.$$

前两类是单侧检验，最后一类是双侧检验。

方向应在看到数据之前由科学问题决定。

看完估计值的符号再选择更有利的单侧检验，会使标称的第一类错误率失真。

### 经济假设还要经过模型翻译

例如，“历史价格不能预测未来收益”不是立即可计算的参数假设。

若选择线性自回归模型，它可能翻译为若干滞后系数同时为零。

若真实预测关系是非线性的，不拒绝这些线性系数为零，并不能证明原始市场假说成立。

所以统计检验的结论总是相对于模型和辅助假设而言。

## 36.3 拒绝域与随机化检验

对样本空间中的一个可测集合 $C$ ，规则

$$X\in C\Longrightarrow\text{拒绝 }H_0$$

称为具有拒绝域 $C$ 的检验。

其补集常被称为“不拒绝域”。

本书尽量避免把它直接叫作“接受域”，因为“不拒绝”与“有证据证明假设成立”不是一回事。

离散模型中，临界值两侧的概率可能跳跃，未必能找到拒绝域使第一类错误率恰好等于指定水平。

为此引入随机化检验函数

$$\phi(x)=P(\text{观察到 }x\text{ 后拒绝 }H_0), \qquad 0\le\phi(x)\le1.$$

$\phi(x)=1$ 表示必拒绝，$\phi(x)=0$ 表示不拒绝，中间值表示用独立随机机制决定。

随机化主要用于精确理论和离散临界点。

实际报告中也常直接给出 p 值，而不必真的抛一次硬币。

## 36.4 两类错误、size、level 与功效

两类错误可以列成下表。

| 决策与真实现状 | $H_0$ 成立 | $H_A$ 成立 |
|---|---|---|
| 拒绝 $H_0$ | 第一类错误 | 正确拒绝 |
| 不拒绝 $H_0$ | 正确不拒绝 | 第二类错误 |

对拒绝域 $C$ ，定义功效函数

$$\boxed{ \pi(\theta)=P_\theta(X\in C). }$$

当 $\theta\in\Theta_0$ 时，$\pi(\theta)$ 是在该参数处犯第一类错误的概率。

当 $\theta\in\Theta_A$ 时，$\pi(\theta)$ 是在该参数处正确拒绝的功效。

第二类错误率为

$$\beta(\theta)=1-\pi(\theta),\qquad \theta\in\Theta_A.$$

所以“第二类错误率是 0.1”通常不是完整说法。

必须说明是在哪一个备择参数或哪一种效应大小下计算。

检验的 size 是原假设上最大的第一类错误概率：

$$\boxed{ \operatorname{size}=\sup_{\theta\in\Theta_0}\pi(\theta). }$$

若 size 不超过预先给定的 $\alpha$ ，称检验具有 level $\alpha$ 。

简单原假设下，size 就是唯一的 $P_{\theta_0}(C)$ 。

复合原假设下，不能只挑一个方便的参数计算后就把结果当作 size。

例如对 $H_0:\mu\le\mu_0$ 的右侧正态检验，最大拒绝概率出现在边界 $\mu=\mu_0$ 。

这也是许多复合检验可以只在边界校准的原因，但单调性必须另行证明。

## 36.5 为什么不能让两类错误同时任意小

扩大拒绝域通常会提高备择下的功效，也会增加原假设下的错误拒绝概率。

缩小拒绝域则相反。

在固定样本量下，这形成第一类错误与第二类错误之间的权衡。

增加有效样本量通常能让抽样分布更集中，从而在控制 size 的同时提高功效。

但“多收数据”不是任何情况下都有效。

若数据高度相关、模型误设或参数不可识别，名义样本量不等于有效信息量。

Neyman–Pearson 理论先固定第一类错误预算，再寻找最大功效，而不是含糊地同时最小化两种错误。

## 36.6 Neyman–Pearson 引理的设定

先考虑两个简单假设：

$$H_0:\theta=\theta_0, \qquad H_A:\theta=\theta_1.$$

设样本在两个分布下分别有密度或概率质量函数 $f_0,f_1$ 。

离散情形把下文的积分理解为求和即可。

取常数 $k\ge0$ ，定义似然比检验：

$$\phi(x)= \begin{cases} 1,&f_1(x)>kf_0(x),\\ \gamma(x),&f_1(x)=kf_0(x),\\ 0,&f_1(x)<kf_0(x). \end{cases}$$

边界随机化 $\gamma(x)$ 用来调节 size。

直接比较 $f_1$ 与 $kf_0$ ，比只写 $f_1/f_0>k$ 更稳妥，因为后者在 $f_0=0$ 时需要额外约定。

直观上，同样的第一类错误预算应花在“备择密度相对原假设密度最高”的样本点上。

Neyman–Pearson 引理把这个直觉变成最优性定理。

## 36.7 Neyman–Pearson 引理：陈述与完整证明

**定理。** 若上述似然比检验满足

$$E_0[\phi(X)]=\alpha,$$

而任意其他检验 $\psi$ 满足

$$E_0[\psi(X)]\le\alpha, \qquad 0\le\psi\le1,$$

则

$$E_1[\phi(X)]\ge E_1[\psi(X)].$$

即在所有 level $\alpha$ 的检验中，$\phi$ 对 $\theta_1$ 的功效最大。

**证明的关键只有一条逐点不等式：**

$$\boxed{ [\phi(x)-\psi(x)]\,[f_1(x)-kf_0(x)]\ge0. }$$

分三种情况核对。

若 $f_1>kf_0$ ，则 $\phi=1$ ，所以 $\phi-\psi=1-\psi\ge0$ ，第二个因子也为正。

若 $f_1<kf_0$ ，则 $\phi=0$ ，所以 $\phi-\psi=-\psi\le0$ ，第二个因子为负。

若 $f_1=kf_0$ ，第二个因子为零。

因此不等式在所有样本点成立。

积分后得到

$$E_1[\phi]-E_1[\psi] \ge k\left(E_0[\phi]-E_0[\psi]\right).$$

右边为

$$k(\alpha-E_0[\psi])\ge0.$$

故 $E_1[\phi]\ge E_1[\psi]$ ，证毕。

这个证明没有使用正态性、大样本或独立同分布。

它只需要两个简单分布、可比较的密度以及合法的检验函数。

## 36.8 引理还告诉我们什么

证明同时说明：若一个竞争检验把预算放在似然比不是最高的区域，就会损失功效。

在适当正条件下，最优检验与似然比检验若在功效上相同，则它们只能在零概率集合或临界边界上不同。

若 $T(X)$ 对两个参数都是充分统计量，因子分解给出

$$f_j(x)=g_j(T(x))h(x),\qquad j=0,1.$$

共同的 $h(x)$ 在比较

$$f_1(x)-kf_0(x)$$

时消去，所以最优拒绝域可以只用 $T$ 表示。

这解释了为什么后面的 Bernoulli 和正态例都归结为充分统计量的单侧拒绝域。

NP 引理处理的是两个简单假设。

要从“对每一个 $\theta_1$ 都最优”进一步得到 UMP，还要求同一个拒绝域对整个备择族都适用。

## 36.9 Bernoulli 例：五点样本的完整似然比账

设 $X_1,\ldots,X_5$ iid 服从 Bernoulli $(p)$ ，检验

$$H_0:p=1/4, \qquad H_A:p=3/4.$$

令 $K=\sum_iX_i$ 。

样本似然为

$$L(p)=p^K(1-p)^{5-K}.$$

所以似然比为

$$\frac{L(3/4)}{L(1/4)} =3^K\left(\frac13\right)^{5-K} =\boxed{3^{2K-5}}.$$

它严格随 $K$ 增大，因此拒绝域必为 $K\ge k_c$ ，边界可能随机化。

两个假设下 $K$ 的完整分布如下。

| $K$ | $1024P_{1/4}(K)$ | $1024P_{3/4}(K)$ | 似然比 |
|---:|---:|---:|---:|
| 0 | 243 | 1 | $1/243$ |
| 1 | 405 | 15 | $1/27$ |
| 2 | 270 | 90 | $1/3$ |
| 3 | 90 | 270 | $3$ |
| 4 | 15 | 405 | $27$ |
| 5 | 1 | 243 | $243$ |

这里 $P_{1/4}(K=4)=15/1024$ ，不是 $5/1024$ 。

组合数 $5$ 还必须乘以四次成功和一次失败的概率。

机器首轮检查正是抓住了漏乘 $3/4$ 所造成的错误 size。

## 36.10 临界域、功效与随机化的精确数值

取拒绝域 $K\ge4$ 。

其 size 为

$$P_{1/4}(K\ge4) =\frac{15+1}{1024} =\boxed{\frac1{64}}.$$

在备择下的功效为

$$P_{3/4}(K\ge4) =\frac{405+243}{1024} =\boxed{\frac{81}{128}}.$$

第二类错误率为

$$\beta(3/4)=1-\frac{81}{128}=\frac{47}{128}.$$

若在 $K=3$ 时再以 $1/5$ 的概率拒绝，size 增加

$$\frac15P_{1/4}(K=3) =\frac15\frac{90}{1024} =\frac{18}{1024},$$

故新的 size 为

$$\frac{16+18}{1024}=\frac{17}{512}.$$

功效增加

$$\frac15\frac{270}{1024}=\frac{54}{1024},$$

故新的功效为

$$\frac{648+54}{1024}=\frac{351}{512}.$$

随机化不是凭空调高功效；它同时使用了更多第一类错误预算。

## 36.11 Python：离散尾概率必须精确计算

文件 `examples/python/36_hypothesis_testing.py` 用组合数和 `Fraction` 计算上尾：

```python
def binomial_tail(n, k, p):
    return sum(F(comb(n, j)) * p ** j * (1 - p) ** (n - j)
               for j in range(k, n + 1))

size = binomial_tail(5, 4, F(1, 4))
power = binomial_tail(5, 4, F(3, 4))
assert size == F(1, 64)
assert power == F(81, 128)
```

每一项 $\binom5j p^j(1-p)^{5-j}$ 都保留为有理数。

这里没有浮点舍入，也没有用正态近似代替只有五个观测的精确分布。

边界随机化直接写成两个概率的线性插值：

```python
gamma = F(1, 5)
randomized_size = size + gamma * (
    binomial_tail(5, 3, F(1, 4)) - size)
randomized_power = power + gamma * (
    binomial_tail(5, 3, F(3, 4)) - power)
assert randomized_size == F(17, 512)
assert randomized_power == F(351, 512)
```

减去原来的尾部质量，是因为 $K\ge4$ 的部分已经包含在 $K\ge3$ 中。

程序还断言 $K=4$ 的上尾 p 值为 $1/64$ ，而较不极端的 $K=3$ 对应 $53/512$ 。

## 36.12 Julia：同一离散账的独立复算

`examples/julia/36_hypothesis_testing.jl` 使用 Julia 有理数：

```julia
size = binomial_tail(5, 4, 1 // 4)
power = binomial_tail(5, 4, 3 // 4)
@assert size == 1 // 64
@assert power == 81 // 128
@assert 1 - power == 47 // 128
```

`1 // 4` 是有理数 $1/4$ ，不是整数除法，也不是二进制浮点近似。

随机化部分为：

```julia
boundary_reject = 1 // 5
randomized_size = size + boundary_reject * (
    binomial_tail(5, 3, 1 // 4) - size)
@assert randomized_size == 17 // 512
```

变量没有命名为 `gamma`，因为后文还要使用数学上的 $\Gamma$ 函数概念，命名应避免遮蔽。

两种语言独立得到相同分数，排除了某个数值库特殊尾近似造成结论的可能。

## 36.13 Lean：把 NP 证明的逐点核心形式化

`examples/lean/Probability/Ch36HypothesisTesting.lean` 直接证明第 36.7 节的逐点收益不等式：

```lean
theorem np_pointwise_gain (phi psi f0 f1 k : ℚ)
    (hpsi0 : 0 ≤ psi) (hpsi1 : psi ≤ 1)
    (hupper : k * f0 < f1 → phi = 1)
    (hlower : f1 < k * f0 → phi = 0) :
    0 ≤ (phi - psi) * (f1 - k * f0) := by
  rcases lt_trichotomy f1 (k * f0) with h | h | h
  · rw [hlower h]
    nlinarith
  · simp [h]
  · rw [hupper h]
    nlinarith
```

`lt_trichotomy` 把样本点分成低于、等于和高于临界似然比三种情况。

`nlinarith` 使用 $0\le\psi\le1$ 判断两个因子的符号。

积分或有限求和保持非负性，所以这条逐点定理正是 NP 最优性证明的核心。

Lean 文件还用 `norm_num` 判决：

```lean
example : ((5 : ℚ) * 3 + 1) / 4 ^ 5 = 1 / 64 := by norm_num
example : ((5 : ℚ) * 3 ^ 4 + 3 ^ 5) / 4 ^ 5 = 81 / 128 := by norm_num
```

这里 `5*3` 是 $K=4$ 下五次成功组合数与一次失败概率 $3/4$ 合并后的分子。

形式化文件验证代数与逻辑核心，不代替测度论积分细节。

## 36.14 正态均值：似然比为什么化成右侧 z 检验

设 $X_1,\ldots,X_n$ iid 服从 $N(\mu,\sigma^2)$ ，其中 $\sigma^2$ 已知。

先比较两个简单假设 $\mu_0$ 与 $\mu_1>\mu_0$ 。

对数似然比为

$$\log\frac{L(\mu_1)}{L(\mu_0)} = \frac{n(\mu_1-\mu_0)}{\sigma^2} \left(\bar X-\frac{\mu_0+\mu_1}{2}\right).$$

因为 $\mu_1-\mu_0>0$ ，似然比大等价于 $\bar X$ 大。

因此 NP 拒绝域可写为

$$Z=\frac{\bar X-\mu_0}{\sigma/\sqrt n}>z_\alpha,$$

其中 $P(N(0,1)>z_\alpha)=\alpha$ 。

这个拒绝域不依赖具体选定的 $\mu_1>\mu_0$ 。

所以它对整个 $H_A:\mu>\mu_0$ 都是一致最大功效的，即 UMP。

若备择改为 $\mu<\mu_0$ ，同样的推导给出左侧拒绝域。

方向来自备择和似然比，不是为了得到更小 p 值而临时选择。

## 36.15 正态例的 size、功效和非中心位移

取

$$n=16,\qquad \sigma=4,\qquad \mu_0=10,$$

则 $\sigma/\sqrt n=1$ 。

右侧 5% 临界值为

$$z_{0.05}=1.64485362695.$$

在一般 $\mu$ 下，

$$Z\sim N\left(\frac{\sqrt n(\mu-\mu_0)}{\sigma},1\right).$$

记非中心位移

$$\delta=\frac{\sqrt n(\mu-\mu_0)}{\sigma},$$

功效函数就是

$$\boxed{ \pi(\mu)=P_\mu(Z>z_\alpha) =\Phi(\delta-z_\alpha). }$$

在 $\mu=12$ 时，

$$\delta=\frac{4(12-10)}4=2,$$

所以

$$\pi(12)=\Phi(2-1.64485362695)\approx0.638760.$$

功效曲线上的几个点为：

| 真值 $\mu$ | 非中心位移 | 右侧检验功效 |
|---:|---:|---:|
| 10 | 0 | 0.050000 |
| 10.5 | 0.5 | 0.126135 |
| 11 | 1 | 0.259511 |
| 12 | 2 | 0.638760 |
| 13 | 3 | 0.912315 |

在边界处功效等于 size。

离原假设越远，功效越高；靠近原假设的小效应仍可能很难检出。

## 36.16 双侧检验为什么没有通常意义的 UMP

对 $H_A:\mu\ne\mu_0$ ，右侧检验对每个 $\mu>\mu_0$ 都是 NP 最优。

但若真值在 $\mu_0$ 左侧，右侧检验的功效会很小，甚至低于 $\alpha$ 。

左侧检验则在左侧备择上表现更好。

不存在一个方向固定的检验同时在所有左右备择上达到各自 NP 上界。

双侧检验通过同时拒绝过大和过小的统计量来换取方向对称性。

在正态均值问题中，常见规则是

$$|Z|>z_{\alpha/2}.$$

它不是整个无限制检验类中的 UMP，而是双侧无偏、对称或不变检验类中的自然最优规则之一。

“UMP”必须连同备择族和检验类一起理解。

## 36.17 p 值：观测之后计算极端程度

设较大的检验统计量 $T$ 更不利于 $H_0$ 。

简单原假设下，观测到 $T=t_{\mathrm{obs}}$ 后的上尾 p 值为

$$\boxed{ p(t_{\mathrm{obs}})=P_{H_0}(T\ge t_{\mathrm{obs}}). }$$

复合原假设下，通常定义为

$$p(t_{\mathrm{obs}}) =\sup_{\theta\in\Theta_0} P_\theta(T\ge t_{\mathrm{obs}}).$$

它是“若原假设成立，得到至少这么极端结果的概率”。

它不是：

- $P(H_0\text{ 为真}\mid\text{数据})$ ；
- 结果完全由随机噪声产生的概率；
- 原假设为真的主观概率；
- 效应大小；
- 重复实验中结果会复现的概率。

对连续的上尾检验，$p\le\alpha$ 等价于统计量超过相应的 $\alpha$ 临界值。

离散分布有概率跳跃，p 值的分布也不必恰好均匀，但有效 p 值仍应满足相应尾概率校准。

### p 值方向不能写反

本章正态例观测 $\bar x=11.5$ ，所以

$$z_{\mathrm{obs}}=1.5.$$

右侧 p 值为

$$1-\Phi(1.5)=0.0668072.$$

双侧 p 值为

$$2\{1-\Phi(|1.5|)\}=0.1336144.$$

两者都在 0.05 以上，因此相应检验不拒绝 $H_0$ 。

若误把右尾写成 $\Phi(1.5)$ ，就会把“不极端”误报成“高度显著”。

## 36.18 不拒绝不等于接受

上述正态例的 95% 双侧区间为

$$11.5\pm1.95996398454 =(9.5400360,13.4599640).$$

它同时包含 $\mu=10$ 和 $\mu=12$ 。

因此数据与“均值为 10”相容，也与“均值为 12”相容。

仅因为 $H_0:\mu=10$ 没有被拒绝，就宣布它已经被证明，会忽略区间里还有许多其他参数。

“不拒绝”的完整含义是：在当前模型、检验方向和错误预算下，证据没有越过预设拒绝门槛。

它可能与功效不足、样本量小、噪声大或效应确实很小有关。

若研究目标是证明差异实际可忽略，应预先规定等价界值并做等价性检验，而不是把普通检验的大 p 值当作等价证明。

## 36.19 统计显著不等于实际显著

大样本可以把很小的差异变成很小的 p 值。

例如某种处理使平均指标增加 0.01 个单位，若有足够多样本，检验可能高度显著。

这个差异是否有经济、医学或工程价值，要由效应量、成本、收益和研究背景决定。

反过来，大效应也可能因样本太少而不显著。

因此完整报告至少应包含：

1. 估计的效应及其单位；
2. 标准误或置信区间；
3. 检验方向与样本量；
4. p 值或拒绝决策；
5. 模型假设与实际意义分析。

只报告“$p<0.05$ ”会把这些信息压缩成一个容易误读的标签。

## 36.20 从 z 到 t：未知方差的代价

正态均值且 $\sigma$ 已知时，

$$Z=\frac{\bar X-\mu_0}{\sigma/\sqrt n}\sim N(0,1).$$

若 $\sigma$ 未知，用

$$S^2=\frac1{n-1}\sum_{i=1}^n(X_i-\bar X)^2$$

代替，得到

$$T=\frac{\bar X-\mu_0}{S/\sqrt n}.$$

在正态样本和 $H_0$ 下，第 22 章已经给出

$$T\sim t_{n-1}.$$

t 分布尾部更厚，因为分母也随机。

这不是计算上的麻烦，而是额外不确定性的真实代价。

沿用旧章的出餐时间例：$n=20,\bar x=48,s=8,\mu_0=45$ ，则

$$t=\frac{48-45}{8/\sqrt{20}}=1.67705.$$

若把 $s=8$ 当作已知 $\sigma$ ，右侧正态 p 值为 0.046766。

使用 $t_{19}$ 后，右侧 p 值为 0.054954。

同一数据在 5% 水平下由“拒绝”变成“不拒绝”，说明分布假设和临界值本身就会改变结论。

## 36.21 Python 与 Julia 如何复算正态/t 尾概率

Python 使用 SciPy 的分布函数：

```python
zcrit = float(norm.ppf(0.95))
power_at_12 = float(norm.cdf(2 - zcrit))
p_upper = float(norm.sf(1.5))
p_two_sided = 2 * float(norm.sf(abs(1.5)))
tstat = (48 - 45) / (8 / sqrt(20))
p_t = float(student_t.sf(tstat, 19))
```

`sf` 是生存函数，即右尾概率；对远右尾通常比先算 `cdf` 再做 `1-cdf` 更稳定。

`ppf(0.95)` 是标准正态的 0.95 分位数。

程序断言功效约为 0.638760，并检查 $p_z<0.05<p_t<0.06$ 。

Julia 单元不依赖额外分布包，用 Simpson 积分计算正态尾：

```julia
phi(x) = exp(-x^2 / 2) / sqrt(2 * pi)
Phi(x) = simpson(phi, -10.0, x, 6000)
power_at_12 = Phi(2 - zcrit)
p_upper = 1 - Phi(1.5)
```

对 $t_{19}$ ，程序利用

$$\Gamma(10)=9!, \qquad \Gamma(19/2)=\frac{17!!}{2^9}\sqrt\pi$$

写出精确归一化常数，再数值积分右尾。

两条通道均得到 0.054954 左右。

数值积分只用于连续尾概率，离散二项账始终保持精确有理数。

## 36.22 拟合优度卡方：从旧例保留的一条渐近检验

对 $k$ 个类别，观测计数为 $O_j$ ，原假设下期望计数为 $E_j=np_j$ 。

Pearson 统计量为

$$X^2=\sum_{j=1}^k\frac{(O_j-E_j)^2}{E_j}.$$

在没有额外估计参数且期望计数足够大时，常用近似为

$$X^2\approx\chi^2_{k-1}.$$

自由度少一来自 $\sum_jO_j=\sum_jE_j=n$ 的约束。

若还估计了参数，自由度和估计方式需要重新计算，不能机械套用 $k-1$ 。

旧章的 12 个月生日计数给出

$$n=4515,\qquad E_j=376.25, \qquad X^2=93.0718.$$

在 11 个自由度下，右尾 p 值小于 $10^{-12}$ 。

Python 复算代码为：

```python
expected = sum(births) / 12
chi2_stat = sum((observed - expected) ** 2 / expected
                for observed in births)
assert abs(chi2_stat - 93.07) < 0.02
assert chi2.sf(chi2_stat, 11) < 1e-12
```

这拒绝的是“各月出生概率相同”的模型，不自动给出唯一现实解释。

## 36.23 双样本 Welch 检验：不要强行合并不同方差

两个独立样本的均值差估计为 $\bar X-\bar Y$ 。

未知且可能不等的方差下，Welch 统计量的分母是

$$\sqrt{\frac{S_X^2}{n_X}+\frac{S_Y^2}{n_Y}}.$$

近似自由度为

$$\nu= \frac{(S_X^2/n_X+S_Y^2/n_Y)^2} {S_X^4/[n_X^2(n_X-1)]+S_Y^4/[n_Y^2(n_Y-1)]}.$$

它不必是整数。

沿用旧例数据，程序得到 $\nu\approx22.5085$ ，并验证

$$13\le\nu\le26.$$

Python 中的计算直接逐项实现公式：

```python
welch_nu = ((sx2 / nx + sy2 / ny) ** 2 /
            (sx2 ** 2 / (nx ** 2 * (nx - 1)) +
             sy2 ** 2 / (ny ** 2 * (ny - 1))))
assert min(nx - 1, ny - 1) <= welch_nu <= nx + ny - 2
```

Welch 自由度来自矩匹配近似，不是一个精确卡方分解的必然结果。

若额外假设两方差相同，才可使用合并方差和 $n_X+n_Y-2$ 自由度的经典 pooled t 检验。

## 36.24 固定种子模拟：审计频率，不冒充证明

Python 单元固定种子 36，反复生成 $n=16$ 的正态样本：

```python
rng = np.random.default_rng(36)
null_means = (10 + 4 * rng.standard_normal((reps, 16))).mean(axis=1)
alt_means = (12 + 4 * rng.standard_normal((reps, 16))).mean(axis=1)
empirical_size = np.mean(null_means - 10 > zcrit)
empirical_power = np.mean(alt_means - 10 > zcrit)
```

因为标准误为 1，标准化统计量可直接写成样本均值减 10。

20,000 次重复得到：

- 经验 size 为 0.04995；
- 在 $\mu=12$ 处的经验功效为 0.63895。

它们接近精确值 0.05 和 0.638760。

Julia 用相同种子值但独立随机数实现重复实验：

```julia
xbar = mu + 4 * mean(randn(16))
rejections += xbar - 10 > zcrit
```

得到经验 size 0.049、经验功效 0.64395。

不同语言无需逐位一致，因为随机数生成器不同。

这些频率只审计指定设计，不证明 NP 引理或功效公式；证明已经由似然比和正态分布给出。

## 36.25 多重检验是错误预算的再次分配

即使每个单独检验都严格具有 5% size，同时做很多检验也会提高至少一次假拒绝的概率。

若有 20 个相互独立且都成立的原假设，每个都以 0.05 水平检验，则至少一个假拒绝的概率为

$$1-0.95^{20}\approx0.641514.$$

所以“做了 20 次，终于有一个显著”不能按单次 5% 检验解释。

第 37 章将用 Boole 不等式推导 Bonferroni 校正，并把它与置信区间的多重性一起讨论。

这里先记住：检验次数和数据驱动的选择过程属于检验设计的一部分。

## 36.26 常见误区

### 误区一：原假设就是“没有效应”

它可以是无效应，也可以是任何参数约束，例如规模报酬不变、系数和为一或方差不超过某值。

### 误区二：size 是所有参数下的第一类错误率

复合原假设下，不同参数可以有不同拒绝概率；size 取上确界。

### 误区三：功效是一个固定常数

功效是备择参数的函数，还依赖样本量、效应量、噪声和检验规则。

### 误区四：NP 引理证明任何似然比检验都是 UMP

引理直接处理两个简单假设；复合备择需要同一个拒绝域对全部备择保持最优。

### 误区五：p 值是原假设为真的概率

p 值以原假设为条件计算数据尾概率，方向不是 $P(H_0\mid X)$ 。

### 误区六：大 p 值证明原假设

它也可能来自低功效；不拒绝不是等价性证明。

### 误区七：未知方差仍可用同一正态临界值

正态样本中代换样本方差后应使用 t 分布；大样本时才可能近似正态。

### 误区八：统计显著就是实际重要

实际意义必须由效应大小、区间和应用背景判断。

## 36.27 本章要点

1. 假设检验是控制错误概率的决策规则，不是直接计算假设为真的概率。
2. size 是原假设上第一类错误概率的上确界，功效是备择下拒绝概率的函数。
3. Neyman–Pearson 引理由逐点不等式 $(\phi-\psi)(f_1-kf_0)\ge0$ 立即推出。
4. Bernoulli 五点例中，拒绝 $K\ge4$ 的 size 为 $1/64$ ，功效为 $81/128$ 。
5. 正态均值右侧检验由似然比单调性得到，并对全部右侧备择 UMP。
6. p 值是原假设下至少同样极端的概率；不拒绝不等于接受。
7. z/t、拟合优度卡方和 Welch 检验都依赖各自分布假设与近似条件。
8. 模拟可以审计 size、功效和数值实现，但不能替代最优性与分布证明。
