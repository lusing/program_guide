# 08 离散随机变量：分布列与累积分布

**对应 Miller ch7（pp. 238-254）。**

从本章起进入第二篇：**随机变量**。前七章的全部家当——公理、
计数、条件概率、容斥——现在要装到"数值化"的框架里。随机
变量是把随机**结果**翻译成**数**的机器：掷两颗骰子，样本
空间是 36 个有序对，但我们关心的往往是"点数**和**"这个数。
本章定义离散随机变量的语言：分布列（pmf）与累积分布函数
（CDF），并用伯努利过程与二项分布做第一组完整实弹。

## 08.1 什么是随机变量

**定义**：随机变量 X 是从样本空间 Ω 到实数的函数
X : Ω → ℝ。掷三枚硬币，Ω = {HHH, HHT, …, TTT}（8 个
结果），"正面数" X(HHT) = 2 就是一个随机变量。

为什么值得单独命名？因为一旦结果是数，我们就能问
"P(X = 2)"、"X 的平均值"、"X 超过 5 的概率"——这些问题
对"有序对"没有意义，对数有。**随机变量是概率论对接
分析的接口**。

**离散**随机变量：X 只取有限个（或可数个）值——正面数
取 {0,1,2,3}，骰子点数取 {1,…,6}。描述它只需要一张表：

**分布列（pmf）**：p_X(x) := P(X = x)。它满足两条（且
恰好是第 02 章公理的化身）：

1. **非负**：p_X(x) ≥ 0（概率非负）；
2. **归一**：Σₓ p_X(x) = 1（全概率 1）。

任何满足这两条的有限/可数表**就是**某个离散随机变量的
分布列——你可以反过来构造样本空间（取 Ω = 值域，每个
点 x 携带概率 p_X(x)）。pmf 是离散世界里的"密度"，第 09
章的连续版本会把它换成积分。

**三硬币的完整账**（本章的随身例子）：三枚均匀硬币的
正面数 X，按"哪几枚是正面"分类（第 03 章的计数直接
进场）：P(X = k) = C(3,k)/8：

| k | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| p_X(k) | 1/8 | 3/8 | 3/8 | 1/8 |

验算归一：1/8 + 3/8 + 3/8 + 1/8 = 1 ✓。对称性（k ↔ 3−k）
来自"正面/反面互换"这个保持概率的对称。

## 08.2 伯努利过程与二项分布

Miller 用**伯努利过程**统摄一大类模型：独立重复 n 次同一
试验，每次成功概率 p。记单次试验的示性随机变量为
Xᵢ ∈ {0,1}（P(Xᵢ = 1) = p），则：

- **伯努利分布** Xᵢ：pmf 为 p^X(1−p)^(1−X)；
- **二项分布** X = X₁ + X₂ + ⋯ + Xₙ：n 次中的成功数。

**二项 pmf 的推导**（计数的标准三步）：

1. **特定序列**：某个固定的成功位置集合 S（|S| = k）的
   概率是 pᵏ(1−p)^(n−k)（独立性连乘）；
2. **数序列**：这样的 S 有 C(n,k) 个（第 03 章）；
3. **合并**：P(X = k) = C(n,k)·pᵏ(1−p)^(n−k)。

三硬币即 n = 3、p = 1/2：C(3,k)/2³ = C(3,k)/8——上表的
来历。**验算归一**：Σₖ C(n,k)pᵏ(1−p)^(n−k) = (p + (1−p))ⁿ
= 1（二项定理，第 07 章多项式展开的 k = 2 特例）。

**概率树**：Miller 强调的视觉工具——每次试验分叉（成功/
失败），n 步后 2ⁿ 条路径，每条路径概率是沿途因子之积。
二项 pmf 就是"把等概率层折起来"：同一 k 的 C(n,k) 条
路径合并。树让你**看见**独立性如何把序列概率变成乘积。

**为什么"和"如此重要**：把 X 写成示性变量之和，是概率论
最有用的分解习惯。第 10 章的期望线性性将让
E[X] = np 一行可得，方差 = np(1−p) 两行可得；第 21 章
的中心极限定理将解释为什么 n 大时 X 近似正态。**求和
结构（而不仅仅是分布本身）是后面所有定理的入口**。

## 08.3 累积分布函数（CDF）

**定义**：F_X(x) := P(X ≤ x) = Σ_{t ≤ x} p_X(t)。对离散
变量它是**阶梯函数**：在值域的每个点 xₙ 处跳起
p_X(xₙ)，之间保持水平。

三硬币例：F(2) = P(X ≤ 2) = 1/8 + 3/8 + 3/8 = 7/8，
F 在 x = 3 处完成最后一跳到 1。

**CDF 的四条性质**（对离散与连续同样成立，第 09 章
继承）：

1. **单调不减**：x ≤ y ⟹ F(x) ≤ F(y)（事件 {X ≤ x} ⊆
   {X ≤ y}，第 02 章单调性）；
2. **极限**：lim_{x→−∞} F(x) = 0，lim_{x→+∞} F(x) = 1；
3. **右连续**：F(x⁺) = F(x)（离散阶梯在跳点取"跳完后"
   的值——因为我们定义为 P(X ≤ x) 而非 P(X < x)）；
4. **区间概率**：P(a < X ≤ b) = F(b) − F(a)。

单点概率从 CDF 里回收：P(X = x) = F(x) − F(x⁻)（左极限）
——阶梯在该点的跳高就是 pmf。**pmf 与 CDF 互相决定**：
pmf 是 CDF 的差分，CDF 是 pmf 的累加。前者便于读
"单点"，后者便于读"区间"，工具箱里两把都要有。

**二项 CDF 实弹**（机器通道反复对拍的账）：n = 5、
p = 1/2 时 P(X ≤ 2) = (C(5,0)+C(5,1)+C(5,2))/2⁵ =
(1+5+10)/32 = 1/2——恰好一半，来自 p = 1/2 的对称性
（X 与 5−X 同分布）。

**一个反直觉提醒**：pmf 不是"X 在 x 处的密度质量连续
铺开"而是**全部质量集中在点 x 上**。对离散变量问
P(X = 7) 有实义（可能非零）；第 09 章会看到连续变量
的对应问题答案恒为零——这是两章的分水岭。

## 08.4 两骰之和：pmf 的手工全账

掷两颗均匀骰子，R = 点数和。样本空间 36 个等概率
有序对，按和归类：

P(R = r) = (6 − |r − 7|)/36，r = 2,…,12。

**为什么**：和为 r 的有序对数是 6 − |r − 7|（r ≤ 7 时
r − 1 个，r > 7 时 13 − r 个——"第一颗从 max(1, r−6)
到 min(6, r−1)"的区间长度）。三角形的 pmf，顶点在 7：
1/36, 2/36, …, 6/36, …, 2/36, 1/36。

验算归一：2·(1+2+⋯+6)/36 − 6/36 = 2·21/36 − 6/36 =
36/36 = 1 ✓。对称性：R 与 14 − R 同分布（每颗骰子 x ↦
7 − x 的对称），所以 pmf 关于 7 对称——**先找对称再算账**
的又一次出场。这个分布在第 10 章将再次登场（均值 7、
方差 35/6 的经典计算）。

## 08.5 机器通道

**Python（`08_discrete_rv.py`）**：精确分数账——① 三硬币
pmf 表与归一验算；② 二项 pmf 的枚举对拍：直接枚举
2⁴ = 16 个正面/反面字符串按正面数归并，与公式
C(4,k)/16 逐 k 相等；③ 二项 CDF 阶梯：n = 5、p = 1/2
的 P(X ≤ 2) = 1/2 精确账与全表；④ 两骰和 pmf 的 36
outcome 枚举 vs 三角形公式；⑤ CDF 四性质（单调、极
限、右连续、区间公式）的程序化核查。

**Julia（`08_discrete_rv.jl`）**：频率形态——① 二项 pmf 的
模拟直方图（n = 10、p = 1/2，10⁶ 次采样，逐 k 相对误差
< 1%）；② 两骰和的模拟 vs 三角形公式；③ 概率树的折层
演示：逐条路径累乘再按 k 归并 = 二项 pmf。

**Prolog（`08_discrete_rv.pl`）**：小宇宙穷举——① 三硬币

和的三角形分布；③ n = 4 伯努利过程：16 字符串全枚举
→ 二项 pmf 与 CDF（P(X ≤ 2) = 11/16）。

**Lean（`Ch08DiscreteRV.lean`）**：pmf 归一与 CDF 账的
decide/norm_num 判决——三硬币表、二项定理归一的数值
形态（Σ C(4,k) = 16 = 2⁴）、两骰三角形、二项 CDF 的
1/2 对称账。

## 08.6 要点回顾

1. 随机变量 = 结果到数的函数；离散 pmf 是一张非负、
   归一的表，两张牌缺一不可。
2. 二项 pmf 的三步推导：定序列概率 → 数序列（C(n,k)）→
   合并；归一化即二项定理。
3. 示性变量之和是最有用的分解习惯——期望、方差、
   极限定理全部从"和结构"进场。
4. CDF 单调、极限 0/1、右连续、P(a<X≤b)=F(b)−F(a)；
   pmf 是 CDF 的差分，两者互相决定。
5. 机器分工：精确表账（Python/Prolog）、频率直方图
   （Julia）、归一判决（Lean）。
