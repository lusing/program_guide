# 07 计数实验：扑克、生日与著名问题

本章把前五章的计数工具放进一组著名问题中。它们都使用有限等可能模型，
但规模和审计方式不同：秘书问题与迷你扑克可以完整枚举；生日、52 张扑克
和桥牌使用精确有理数闭式，再用固定种子模拟或小规模全枚举交叉检查。

本章特别区分三件事：

1. **精确闭式**是证明后的计数公式，结果用整数或有理数表示；
2. **全枚举**遍历有限样本空间中的每一个样本点，在小宇宙中给出终审；
3. **固定种子模拟**只产生可复现的频率，用于建立直觉，不冒充证明。

## 07.1 生日问题：22 与 23 的阈值

假设一年有 365 个等可能生日，忽略闰年，且不同人的生日相互独立。\(k\)
个人中至少两人生日相同的概率是多少？

直接计算“至少一对相同”要按相同人数的各种重叠结构分类，很麻烦。取补事件
更简单：所有人生日互不相同。第一个人可在 365 天中任取，第二个人有 364
个不碰撞选择，依此类推。因此

\[
P_k(\text{至少碰撞})
=1-\frac{365\cdot364\cdots(365-k+1)}{365^k}
=1-\prod_{j=0}^{k-1}\frac{365-j}{365}.
\]

精确结果是

\[
P_{22}\approx0.475695<\frac12,
\qquad
P_{23}\approx0.507297>\frac12.
\]

所以 23 人是碰撞概率超过一半的最小人数。50 人时概率已经约为 97%。直觉
常把答案猜成 \(365/2\approx183\)，因为直觉混淆了两个不同事件：

- “某个人和我生日相同”；
- “任意两个人生日相同”。

第一类只比较 \(k-1\) 对；第二类比较所有 \(\binom k2\) 对。

### 一个著名反例：期望碰撞对数不是碰撞概率

23 人共有

\[
\binom{23}{2}=253
\]

对人。若把每对生日相同看成一个指示变量，碰撞对的期望数为

\[
\frac{\binom{23}{2}}{365}=\frac{253}{365}\approx0.693.
\]

但“至少一对碰撞”的概率不是 0.693，而是约 0.507。原因有两点：

1. 若三个人同一天生日，这一个结果贡献三对碰撞，期望计数会把同一事件数
   三次；
2. 各对碰撞事件并不独立，不能用线性期望反推并事件概率。

期望的线性性不需要独立性，但“期望计数为 0.693”只回答平均有多少对，并不
回答“至少一对”的概率。后者必须使用上面的乘积补事件或容斥原理。

`examples/python/07_counting_lab.py` 使用 `Fraction` 做无舍入判决：

```python
def birthday_collision(k):
    no_collision = Fraction(1)
    for j in range(k):
        no_collision *= Fraction(365 - j, 365)
    return 1 - no_collision

p22, p23, p24 = map(birthday_collision, (22, 23, 24))
assert p22 < Fraction(1, 2) < p23 and p24 > p23
```

Julia 文件用大整数有理数重复同一判决：

```julia
function birthday_exact(k)
    q = one(BigInt) // one(BigInt)
    for j in 0:(k - 1)
        q *= big(365 - j) // big(365)
    end
    1 - q
end

p22, p23 = birthday_exact(22), birthday_exact(23)
@assert p22 < 1//2 < p23
```

Lean 文件 `examples/lean/Probability/Ch07CountingLab.lean` 把同一不等式
写成自然数乘法，避免分数和浮点舍入：

```lean
def falling365 (k : ℕ) : ℕ := ∏ j ∈ range k, (365 - j)

example : falling365 22 * 2 > 365 ^ 22 := by decide
example : falling365 23 * 2 < 365 ^ 23 := by decide
```

Julia 通道用 `Rational{BigInt}` 得到精确阈值，再以固定随机种子模拟 23 人
生日碰撞。模拟频率接近 0.5073，但精确答案来自乘积公式。

## 07.2 52 张扑克：九型牌型的结构化计数

从 52 张牌中不计顺序发 5 张，总手数为

\[
\binom{52}{5}=2\,598\,960.
\]

扑克牌型构成一个划分：每一手牌恰好属于九个最高优先级类别之一。计数时必须
先扣除更高类别，否则同花顺会同时被计入“同花”和“顺子”。

| 牌型 | 结构 | 手数 |
|---|---|---:|
| 同花顺 straight flush | 10 个点数区间 × 4 花色 | 40 |
| 四条 four of a kind | 13 个四条点数 × 48 张单牌 | 624 |
| 葫芦 full house | 13 个三条点数 × 4 种三条花色 × 12 个对子点数 × 6 种对子花色 | 3,744 |
| 普通同花 flush | \(4(\binom{13}{5}-10)\) | 5,108 |
| 普通顺子 straight | \(10(4^5-4)\) | 10,200 |
| 三条 three of a kind | \(13\binom43\binom{12}{2}4^2\) | 54,912 |
| 两对 two pair | \(\binom{13}{2}6^2\cdot11\cdot4\) | 123,552 |
| 一对 pair | \(13\cdot6\binom{12}{3}4^3\) | 1,098,240 |
| 无型 nothing | \((\binom{13}{5}-10)(4^5-4)\) | 1,302,540 |

几个关键账目如下。

- 同花顺有 10 个连续点数区间（A2345 到 10JQKA）和 4 个全花色选择，共
  \(10\cdot4=40\)。
- 普通同花先从一个花色的 13 个点数选 5 个，再扣掉 10 个顺子点数区间，所以
  每个花色有 \(\binom{13}{5}-10\) 个。
- 普通顺子有 10 个点数区间，每个位置任选花色共 \(4^5\) 种；扣掉 4 种全
  同色，得到 \(4^5-4\)。
- 三条的另外两张牌必须点数不同，否则会升级成四条或葫芦。
- 无型要求五个点数互不相同、不是顺子，且花色不全相同。

Python 中的完整账本是

```python
poker_counts = {
    "straight_flush": 10 * 4,
    "four_kind": 13 * 48,
    "full_house": 13 * 4 * 12 * comb(4, 2),
    "flush": 4 * (comb(13, 5) - 10),
    "straight": 10 * (4**5 - 4),
    "three_kind": 13 * 4 * comb(12, 2) * 4**2,
    "two_pair": comb(13, 2) * comb(4, 2) ** 2 * 11 * 4,
    "pair": 13 * comb(4, 2) * comb(12, 3) * 4**3,
    "nothing": (comb(13, 5) - 10) * (4**5 - 4),
}
assert sum(poker_counts.values()) == comb(52, 5)
```

最后一个断言保证九类既不遗漏也不重叠。Lean 中也检查九个整数之和恰为
\(\binom{52}{5}\)。Julia 文件则用固定种子发出 50,000 手牌，将每类模拟
频率与精确概率比较；稀有牌型的样本量小，所以使用较宽的多倍标准误区间，
且模拟结果不参与定义精确概率。

## 07.3 迷你扑克：1140 手完整枚举

52 张牌的完整空间有 2,598,960 手，手动分类容易出错。我们先用一个可以
完整枚举的迷你版本审计分类规则：

- 只有 5 个点数、4 个花色，共 20 张牌；
- 每手发 3 张；
- 总手数为

\[
\binom{20}{3}=1140.
\]

三张三张牌的类别计数为

| 类别 | 公式 | 手数 |
|---|---:|---:|
| 同花顺 | 3 个点数区间 × 4 花色 | 12 |
| 三条 | 5 个点数 × \(\binom43\) | 20 |
| 普通同花 | \(4(\binom53-3)\) | 28 |
| 普通顺子 | \(3(4^3-4)\) | 180 |
| 一对 | \(5\binom42\cdot4^2\) | 480 |
| 无型 | 总数减去以上五类 | 420 |

这里共有 3 个三连点数区间。普通同花扣除 3 个顺子区间；普通顺子扣除 4 种
全同色。一对的第三张牌必须来自其余 4 个点数、每个点数 4 张牌，共 16 张。

Prolog 文件逐手生成所有满足牌索引严格递增的三元组：

```prolog
deal3([card(R1,S1), card(R2,S2), card(R3,S3)]) :-
    between(1,5,R1), between(1,4,S1), Ix is (S1-1)*5+R1,
    between(1,5,R2), between(1,4,S2), Jx is (S2-1)*5+R2, Jx > Ix,
    between(1,5,R3), between(1,4,S3), Kx is (S3-1)*5+R3, Kx > Jx.
```

严格递增的牌索引保证一手牌只生成一次。枚举结果与公式逐项相等：

\[
12+20+28+180+480+420=1140.
\]

Python 和 Julia 通道也独立枚举同一空间。三个实现使用不同的牌编码和分类
函数，但得到同一张计数表，这比只核对一个总数更能定位分类错误。

## 07.4 桥牌：花色空缺与 4-4-3-2 分布

桥牌一手有 13 张牌，总手数为

\[
\binom{52}{13}.
\]

### 指定花色空缺

指定某玩家没有黑桃，则 13 张牌全部来自另外三个花色的 39 张牌，概率为

\[
P(\text{无黑桃})=\frac{\binom{39}{13}}{\binom{52}{13}}
\approx0.0128.
\]

### 至少一个花色空缺

令 \(A_s\) 表示花色 \(s\) 空缺。指定 \(j\) 个花色空缺时，13 张牌只能来自
其余 \(52-13j\) 张牌。由容斥原理，

\[
P\left(\bigcup_{s=1}^4 A_s\right)
=
\frac{
\binom41\binom{39}{13}
-\binom42\binom{26}{13}
+\binom43\binom{13}{13}
}{\binom{52}{13}}.
\]

四个花色全空缺不可能，因为还要选 13 张牌，所以四重交为零。这个例子展示
了容斥公式在大组合数上的直接应用。

### 4-4-3-2 花色分布

最常见的桥牌花色形状是 4-4-3-2。先给四个有标签花色分配长度
\((4,4,3,2)\)。因为两个长度 4 互换不产生新模式，长度模式数为

\[
\frac{4!}{2!1!1!}=12.
\]

固定长度后，从各花色中分别选牌，所以手数为

\[
12\binom{13}{4}^2\binom{13}{3}\binom{13}{2}.
\]

除以 \(\binom{52}{13}\)，概率约为 21.6%。Python 精确计算这三个桥牌账，
Prolog 使用大整数组合数核对区间，Julia 则给出精确 `Rational` 结果。

### Yarborough

一手牌没有大于 9 的牌，即 13 张牌全部来自点数 2–9 的 32 张牌，概率为

\[
\frac{\binom{32}{13}}{\binom{52}{13}}\approx\frac1{1828}.
\]

这类历史牌例说明，极小概率并不需要近似模拟；组合数比值可以精确给出。

## 07.5 秘书问题：有限 \(n=4\) 的 11/24

秘书问题描述一个不可逆的在线选择过程：候选人按随机顺序到达，面试后必须
立即决定录用或拒绝，不能召回。策略是：

1. 拒绝前 \(k\) 个候选人，只把他们作为样本；
2. 之后遇到第一个比样本中所有人都优秀的候选人，立即录用；
3. 若之后没有这样的候选人，则失败。

当候选人的优劣顺序是 \(n!\) 个等可能随机排列时，\(n=4\) 可以完整枚举。
令排名 4 表示最优秀。对 \(k=0,1,2,3\)，成功排列数分别为

\[
6,\ 11,\ 10,\ 6.
\]

所以成功概率为

\[
\frac{6}{24},\quad \frac{11}{24},\quad
\frac{10}{24},\quad \frac{6}{24}.
\]

最优选择是 \(k=1\)，即拒绝第一个候选人，成功概率为

\[
\frac{11}{24}\approx0.4583.
\]

有限公式为

\[
P_n(k)=\frac{k}{n}\sum_{m=k}^{n-1}\frac1m,
\qquad k\ge1.
\]

对 \(n=4,k=1\)，

\[
P_4(1)=\frac14\left(1+\frac12+\frac13\right)
=\frac{11}{24}.
\]

公式可通过条件于最优秀候选人的位置得到：若最优秀者位于第 \(m\) 位
（\(m>k\)），策略成功当且仅当前 \(m-1\) 人中的最优秀者出现在前 \(k\) 个
样本位置，概率为 \(k/(m-1)\)；最优秀者位于第 \(m\) 位的概率为 \(1/n\)。

一个重要的有限样本修正是：渐近理论中最优样本比例约为 \(1/e\)，渐近成功
概率也约为 \(1/e\)；但 \(n=4\) 时机械地取 \(k\approx n/e\approx1.47\)
并不直接给出整数策略。完整枚举表明最优是 \(k=1\)，而不是 \(k=2\)。这说明
渐近近似不能代替有限情形下的精确计算。

Python 枚举全部 24 个排列，核心策略函数是

```python
def secretary_wins(k, perm):
    if k == 0:
        return perm[0] == 4
    threshold = max(perm[:k])
    for value in perm[k:]:
        if value > threshold:
            return value == 4
    return False

secretary_counts = [
    sum(secretary_wins(k, p) for p in permutations(range(1, 5)))
    for k in range(4)
]
assert secretary_counts == [6, 11, 10, 6]
```

Prolog 使用同一个排列生成谓词枚举 24 种顺序，并检查闭式
\(\frac14(1+\frac12+\frac13)=11/24\)。Lean 固定该分数等式，并核对四种策略的
成功数合计 \(6+11+10+6=33\)。这个合计跨四种不同策略，不是样本空间大小；
每一种策略各自都在同一组 24 个排列上计数。

## 07.6 机器通道与证据等级

`examples/python/07_counting_lab.py` 是本章的主账本：

- `Fraction` 精确判决生日 22/23 阈值；
- 九型扑克牌型之和等于 \(\binom{52}{5}\)；
- 完整枚举 20 张迷你扑克的 1140 手；
- 精确计算桥牌空缺、4-4-3-2 和 Yarborough；
- 完整枚举秘书问题的 24 个排列。

`examples/julia/07_counting_lab.jl` 同时提供三种证据：`Rational{BigInt}`
计算生日和桥牌，循环枚举 1140 手迷你扑克和 24 个秘书排列，固定种子模拟
生日碰撞与 50,000 手 52 张扑克。模拟断言使用概率偏差区间，文档和输出都
把它标成模拟，而不是定理。

`examples/prolog/07_counting_lab.pl` 负责逻辑全枚举：5 人生日玩具空间的
\(5^5=3125\) 个安排、迷你扑克的 1140 手、桥牌大整数组合数和秘书问题的
24 个排列。

`examples/lean/Probability/Ch07CountingLab.lean` 固定关键算术锚点：

```lean
example : Nat.choose 52 5 = 2598960 := by decide
example : 12 + 20 + 28 + 180 + 480 + 420 = Nat.choose 20 3 := by decide
example : (11 : ℚ) / 24 = (1 : ℚ) / 4 * (1 + 1 / 2 + 1 / 3) := by norm_num
```

这些检查的教育意义在于：不同问题应选择合适的证据规模。小空间用全枚举，
大空间用闭式和划分守恒，随机模拟只检查量级和实现方向。

## 07.7 本章要点

1. 生日问题取补为“所有人生日互不相同”；22 人概率低于一半，23 人高于
   一半。
2. 碰撞对的期望数不是至少碰撞的概率；多重碰撞和事件重叠使二者不同。
3. 五张扑克牌型必须按优先级分类，同花顺不能在同花和顺子中重复计数。
4. 迷你扑克的 1140 手全枚举是检验牌型分类规则的小宇宙。
5. 桥牌至少一个花色空缺使用容斥；4-4-3-2 的长度模式数为 12。
6. 秘书问题 \(n=4\) 的完整枚举给出 \(6,11,10,6\)，最优阈值 \(k=1\)，成功
   概率 \(11/24\)。
7. 精确闭式、全枚举和固定种子模拟是三种不同证据；模拟不能冒充证明。
