# 14 均匀与指数分布：连续两大支柱

**对应 Miller ch13（pp. 365-386）。**

连续分布的开启章。每族的固定巡礼路线：**均值方差 →
独立和的分布 → 应用例 → 随机数生成**。均匀给出"标准化
一个族"的范式与三角形卷积；指数给出无记忆性与逆变换
采样法——两者共同预告了中心极限定理的钟形轮廓。

## 14.1 均匀分布 Unif(a,b)

f(x) = 1/(b−a)（a ≤ x ≤ b）。**一通百通**：若 U ~
Unif(0,1)，则 X = (b−a)U + a ~ Unif(a,b)——研究透一个
成员即研究透整个族（第 12 章"参数族"思想的连续版）。

**均值方差**（对一般 a、b 一杆子算完）：

μ = ∫ₐᵇ x/(b−a)dx = (b²−a²)/2(b−a) = **(a+b)/2**；
σ² = ∫ₐᵇ (x−μ)²/(b−a)dx = **(b−a)²/12**。

**合不合理检查**（原书的肌肉记忆）：均值在中点 ✓；方差
只依赖 b−a（平移 100 不改变波动）✓；单位是米²、标准差
(b−a)/√12 < b−a（比极差小）✓。三个重要特例：
[0,1]：μ = 1/2、σ² = 1/12；[−1/2,1/2]：μ = 0、σ² = 1/12；
[−√3,√3]：μ = 0、**σ² = 1**（标准化均匀）。

**和的三角形密度**：X、Y 独立 Unif(0,1)，Z = X+Y 的
卷积要**分情况**（被积函数的两个 1 各有自己的支撑）：

- 0 ≤ z ≤ 1：f_Z(z) = ∫₀ᶻ 1dt = **z**；
- 1 ≤ z ≤ 2：f_Z(z) = ∫_{z−1}¹ 1dt = **2−z**。

**对称性捷径**：X̃ = 1−X 与 X 同分布，故 z ∈ [1,2] 的值
f(2−u) = u 直接由 z ∈ [0,1] 的结果翻折而来——省一半积分。
**实战例**：P(1/2 ≤ Z ≤ 3/2) = ∫_{1/2}¹ zdz + ∫₁^{3/2}(2−z)dz
= 3/8 + 3/8 = **3/4**。

再卷积（n = 3、8）逐段多项式越来越碎，但形状迅速
趋正态——n = 8 时同均值方差的正态已是极好拟合（CLT
的图示先声，第 21 章正式证明）。Unif(1,3) 版本可经
换元 Z̃ = 2Z+2 化回 [0,1] 情形——**卷积 + 换元**两工具
的联合演练。

## 14.2 指数分布 Exp(λ)：无记忆的等待

f(x) = λ⁻¹e^{−x/λ}（x ≥ 0；此参数化 μ = λ，x/λ 无量纲——
原书的单位学偏好）。

**均值**：换元 t = x/λ 提出参数，μ = λ∫₀^∞ te^{−t}dt；分部
积分（u = t、dv = e^{−t}dt——多项式次数要降不升）得
∫te^{−t} = 1，故 **μ = λ**。边界项 te^{−t}|^∞ 由 L'Hôpital
(t/e^t → 1/e^t → 0) 归零。

**方差**：σ² = λ²∫(t−1)²e^{−t}dt，展开为 Γ(3)−2Γ(2)+Γ(1)
= 2−2+1 = 1（**Gamma 函数的第一次预演**：把 ∫tᵏe^{−t}
统一记账，专章在第 16 章），故 **σ² = λ²**。

**CDF 与无记忆性**：F(x) = 1−e^{−x/λ}；P(X > x+a | X>a)
= P(X > x)——**已经等了 a 丝毫不影响再等 x 的分布**
（几何分布的连续表亲）。这既是有用性质（部件寿命在
"随机老化" absent 时合理），也是警告（真实老化过程
不适用；第 18 章 Markov 链、第 22 章再会）。

**足球例**：进球间隔 ~ Exp(30 分钟)，上半场（45 分钟）
无球的概率 = e^{−45/30} = e^{−3/2} ≈ **22.3%**。

## 14.3 独立和：Erlang 分布

n 个独立 Exp(λ) 之和的密度（电话排队理论的遗产）：

f(x) = xⁿ⁻¹e^{−x/λ}/(λⁿ(n−1)!)，x ≥ 0（**Erlang(λ, n)**），
μ = nλ、σ² = nλ²。

n = 2 的推导比均匀版**更顺**：支撑只有 0 一个断点，
f_{X₁+X₂}(x) = ∫₀ˣ e^{−t}e^{−(x−t)}dt = e^{−x}∫₀ˣdt = xe^{−x}。
指数在卷积里"指数相加、多项式升次"——这是第 16 章
Gamma 分布密度 x^{k−1}e^{−x/σ} 的结构来源。

**神经元例**：10 个独立神经元各平均 12ms 放电一次，
总时间和 < 100ms 的概率 = ∫₀¹⁰⁰ x⁹e^{−x/12}/(12¹⁰·9!)dx
≈ **32.55%**——九次分部积分的痛苦正说明**正态近似**
（用 μ = 120、σ² = 1440……此处需谨慎：100 < 120，
正态近似在尾部要打折）与机器通道的价值。

**CLT 收敛速度的对照**：均匀和 n = 8 已拟合很好，指数
和 n = 30 仍不理想——原因在**三阶中心矩**（均匀对称
为零、指数为 2λ³ ≠ 0），CLT 证明时的误差项它进来了
（第 20 章）。

## 14.4 逆变换采样：从均匀造一切

**定理（CDF 法）**：若 Y ~ Unif(0,1)，则 X = F⁻¹(Y) 以 F
为 CDF。证明只用 F 单调：P(F⁻¹(Y) ≤ z) = P(Y ≤ F(z))
= F(z)。**有闭式反 CDF 的分布都能从均匀数生成**——
第 09 章的 X = √U 已是实例。

**指数现场**：F(x) = 1−e^{−x/λ} 反解 x = −λ·log(1−y)。
合理性三查：依赖 λ ✓；log 有定义（0 ≤ 1−y ≤ 1，y = 1
概率零）✓；负号必要（log(≤1) ≤ 0，密度非负）✓。正态
没有闭式反 CDF——拒绝采样（第 11 章习题路线）或
Box-Muller（第 22 章 Fourier 线）补位。

**均匀数从哪来**：n 次公平硬币掷出二进制小数
a₁/2 + ⋯ + aₙ/2ⁿ——离散格点上的"准均匀"；n = 10⁵ 时
格距小于任何物理测量精度，但与真连续均匀**本质不同**
（极限行为的深刻差异，Kronecker 等分布定理的注脚）。

## 14.5 机器通道

**Python（`14_uniform_exponential.py`）**：精确分数账——
① 均匀三特例的 μ/σ² 与三角形密度的分段 CDF（Fraction
精确：P(1/2 ≤ Z ≤ 3/2) = 3/4、P(Z ≤ 1) = 1/2）；② 三角形
再卷积（n = 3 的分段密度 Simpson 归一）；③ 指数 CDF
账（P(X > 45) = e^{−3/2}）与无记忆性的数值检查
P(X>60)/P(X>30) = P(X>30)；④ Erlang(2) 密度的 Simpson
归一与 [0,1] 概率 1−2/e；⑤ 逆变换采样法向验证（经验
分位数 vs 理论 −λlog(1−y)）。

**Julia（`14_uniform_exponential.jl`）**：频率形态——① 三角
形密度模拟 vs 分段公式；② n = 8 均匀和 vs 正态 N(4, 8/12)
的逐桶比较（CLT 先声）；③ 指数 μ = λ、σ² = λ² 模拟；
④ Erlang(λ=1, n=2/8/30) 模拟 vs 密度与正态近似对照
（n = 30 仍偏的现场）；⑤ 足球 e^{−3/2} 模拟；⑥ 逆变换
采样直方图 vs 密度。

**Lean（`Ch14UniformExponential.lean`）**：判决侧——① 均匀
三特例的 ℚ 账（1/12、0/12、12/12 = 1——[−√3,√3] 的
σ² = (2√3)²/12）；② 三角形卷积的区间账（3/4 与半程
1/2）；③ Erlang n = 2 在 [0,1] 的 CDF 账 1 − 2/e（符号
形态）；④ 指数 CDF F(x) = 1 − e^{−x/λ} 的代数结构
（F(x+a)−F(a) = e^{−a/λ}·F(x)——无记忆性的解析原文）。

## 14.6 要点回顾

1. 均匀：μ = (a+b)/2、σ² = (b−a)²/12；X = (b−a)U+a
   标准化整个族；和是三角形（对称性可省一半积分）。
2. 指数：μ = λ、σ² = λ²；无记忆性是身份证也是警告。
3. Erlang = n 重指数和：xⁿ⁻¹e^{−x/λ}/(λⁿ(n−1)!)——Gamma
   密度的先声；指数族 CLT 收敛慢（三阶矩非零）。
4. 逆变换采样 X = F⁻¹(Y)：闭式反 CDF ⟺ 可从均匀生成；
   指数 −λlog(1−y) 是样板。
5. 巡礼路线固定：矩 → 和 → 例 → 生成——后面每族照此
   办理。
