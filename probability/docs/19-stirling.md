# 19 Stirling 公式：n! 的渐近肖像

**对应 Miller ch18（pp. 483-507）。**

n! 无处不在（排列、二项系数、正态密度里的 √π =
(−1/2)!），但大 n 时既算不动也看不出形状。Stirling 公式
给出渐近肖像：**n! ≈ nⁿe^{−n}√(2πn)**。本章：公式怎么用
（概率、级数收敛、CLT 特例）、怎么半严格地逼近（穷汉
Stirling），以及证明的核心难点（速率陷阱）。

## 19.1 公式的合理性检查

**Stirling**：lim_{n→∞} n!/(nⁿe^{−n}√(2πn)) = 1；更细的
展开 n! = nⁿe^{−n}√(2πn)(1 + 1/(12n) + 1/(288n²) − ⋯)。

**先检查再相信**（原书的肌肉记忆）：① 上界 n! ≤ nⁿ ✓
（Stirling 说多出 eⁿ√n 的量级——界太粗）；② 下界
n! ≥ (n/2)^{n/2} ✓（粗但幂次只有 n/2，Stirling 说应是 n）；
③ **递推一致性**：(n+1)!/n! = n+1，而 Stirling 给

(n+1)^{n+1}e^{−(n+1)}√(2π(n+1)) / (nⁿe^{−n}√(2πn))
= (n+1)·(1+1/n)ⁿ·e^{−1}·√(1+1/n) → (n+1)·e·e^{−1}·1 = n+1 ✓

——(1+1/n)ⁿ → e 恰好消化 e^{−1}。公式与阶乘的 DNA 吻合。

## 19.2 概率应用：2n 次掷币恰 n 正面

P(恰 n 正面) = C(2n,n)/2²ⁿ。Stirling 代入：

C(2n,n) = (2n)!/(n!·n!) ≈ 4ⁿ/√(πn)，故

**P(恰 n 正面) ≈ 1/√(πn)**。

n = 100 时约 5.6%，n = 10⁶ 时不到 0.06%——**期望值处
的概率趋零**！直觉解毒：标准差 √n/2 的"活动窗"以 √n
增长，概率摊到越来越宽的格点上，单点份额自然缩水。

**2008 初选平票案**：Syracuse 的 Clinton–Obama 各得
6001 票。等概率模型下 P(平票) ≈ 1/√(π·6001) ≈ **0.73%**
（精确值 0.0072829）——新闻说"百万分之一"错了三个
数量级；但若用全州 57%-43% 的先验，P = C(12002,6001)
·0.57⁶⁰⁰¹·0.43⁶⁰⁰¹ ≈ **1.9×10⁻⁵⁴**——"几乎不可能"成立。
**模型一换，结论天壤**：概率陈述永远内嵌模型假设。

## 19.3 级数收敛：Stirling 替代审敛法

n!^{1/n} ≈ n/e ⟹ **xⁿ/n! ≈ (1/√(2πn))·(ex/n)ⁿ**：n > 2ex
后每项 < (1/2)ⁿ，比较判别法收全 x 的敛——eˣ 级数全轴
收敛不用比值法。**正态 MGF 同理**：(2m−1)!!/(2m)! =
1/(2^m m!)（第 12 章的恒等式再出场），故

M_Z(t) = Σ t²ᵐ/(2^m m!) = Σ (t²/2)ᵐ/m! = **e^{t²/2}**——

正态的 MGF 闭式登场（第 21 章 CLT 证明的主材料）。

## 19.4 从 Stirling 到 CLT（p = 1/2 特例）

Xᵢ = ±1 等概率，S₂N = X₁+⋯+X₂N（均值 0、方差 2N）。
P(S₂N = 2k) = C(2N, N+k)/2²ᵁ。Stirling 展开后剩

(1 + k/N)^{N+½+k}(1 − k/N)^{N+½−k}

的极限。**速率陷阱**（本章的教学核心）：草率地写
(1 ± k/N)^N ≈ e^{±k} 会得到 e^{2k²/N}；**错**！k 随 N 增长
（Chebyshev 划定有效域 |k| ≤ N^{1/2+ε}），正确做法是
**取对数、Taylor 展开、再指数化**：

log P_{k,N} = (N+½+k)log(1+k/N) + (N+½−k)log(1−k/N)
= k²/N + O(k²/N² + k³/N² + k⁴/N³) = **k²/N + O(N^{−1/6})**。

两项的**次级项互相加强**（∞·0 型未定式的教训）：一个
因子趋于无穷、另一个趋于零，误差项的积累改变了主项
系数。正确结论：

P(S₂N = 2k) ≈ (1/√(πN))·e^{−k²/N} = 2/√(2π·2N)·e^{−(2k)²/2(2N)}

——均值 0、方差 2N 的正态在格点上的质量（因子 2 补偿
"偶数才有质量"）。**CLT 在二项特例下的完整证明**，只
用了 Stirling + Chebyshev + 对数展开三件套。

## 19.5 穷汉 Stirling：积分检验的半程证明

对 log n! = Σlog k 用 **log 的单调性配上下积分**：

∫₁ⁿ log t dt ≤ Σ_{k=1}^n log k ≤ ∫₂^{n+1} log t dt，

右端积分 ∫log t dt = t log t − t（验证：求导即得）。代
入端点得

nⁿe^{−n}·e ≤ n! ≤ nⁿe^{−n}·eⁿ。

主项 nⁿe^{−n} **抓对了**；几何均值 √(e·eⁿ) = e^{√n} ≈
2.718√n，与真值 √(2πn) ≈ 2.5066√n 只差 8%——积分检验
几乎免费地逼近了 Stirling（完整证明要走 Euler–Maclaurin
或 18.6 的驻相法）。**方法论**：乘积取对数化积为和
（Pavlovian 反射）、单调函数的和用积分上下夹。

n!^{1/n} vs n/e 的收敛。

**Julia（`19_stirling.jl`）**：① Stirling 误差的 log-log

## 19.7 要点回顾

1. n! ≈ nⁿe^{−n}√(2πn)；修正链 1 + 1/(12n) + ⋯；递推
   一致性 (1+1/n)ⁿ → e 是最快的合理性检查。
2. C(2n,n)/4ⁿ ≈ 1/√(πn)：期望处概率趋零，质量摊到
   √n 宽的窗口；模型换则概率换（0.73% vs 10⁻⁵⁴）。
3. Stirling 替审敛法：xⁿ/n! 的 (ex/n)ⁿ 读法；正态 MGF
   = e^{t²/2} 的推导。
4. 速率陷阱：(1±k/N)^N 的草率极限差一个 e^{k²/N}——
   对数展开 + 误差追踪是正解，∞·0 未定式要警觉。
5. 穷汉 Stirling：log 单调配积分，主项免费、常数差 8%
   （几何均值 2.718√n vs 2.5066√n）。
