# 10 期望工具：矩、线性性与方差

**对应 Miller ch9（pp. 271-299）。**

期望是随机变量的"重心"。本章是工具章：期望与矩的
定义、**线性性**（概率论最有用的一条定理）、方差的两条
公式、联合分布、独立与协方差。后面每一章（分布族、
极限定理）都在使用这里的工具——Miller 自己说：这是
"一次成本、终身复用"的一章。

## 10.1 动机：矩是密度世界的 Taylor 系数

微积分里，知道 f(0)、f′(0)、f″(0)、… 就能拼出 Taylor
逼近 f(x) ≈ Σ f⁽ᵏ⁾(0)/k!·xᵏ——信息越多，逼近越好。

概率论平移这个思想：**矩**是密度的"导数账"。知道
零阶矩（恒为 1，归一化）只知道"总质量"；知道一阶矩
（均值）知道"重心在哪"；知道二阶中心矩（方差）知道
"散得多开"；三阶、四阶（偏度、峰度）进一步刻画形状。
**每多一个矩，多一分对密度的把握**——第 20 章的母
函数将把这个类比做成定理（矩完全决定母函数）。

## 10.2 期望与矩：定义与三笔实弹

**期望**：X 有密度 f_X，g 是函数，则

E[g(X)] = ∫ g(x)·f_X(x) dx（连续）；Σₙ g(xₙ)·p_X(xₙ)（离散）。

**r 阶矩** E[Xʳ]，**r 阶中心矩** E[(X − E[X])ʳ]。技术条件：
要求 E[|X|] 有限（∫|x|f dx < ∞）——不只是积分收敛，
是**绝对**收敛，10.4 的 Cauchy 反例会揭示为什么这道
闸门不能省。

**实弹一（多项式密度的 r 阶矩，闭式）**：对
f_X = (6/11)(2+3x−5x²)（第 09 章），逐项积分：

E[Xʳ] = (6/11)·∫₀¹ xʳ(2+3x−5x²) dx = (6/11)·(7r+11)/
((r+1)(r+2)(r+3))。

r = 1 得均值 9/22 ≈ 0.409（Python 通道精确复算，Julia
拒绝采样对拍）。

**实弹二（E[eˣ]，分部积分的选边）**：E[eˣ] =
(6/11)(2∫eˣ + 3∫xeˣ − 5∫x²eˣ)。选 u = xᵏ、dv = eˣdx
（多项式次数下降，正确选边；选反则次数上升越算越
繁）：∫₀¹ xeˣ = 1、∫₀¹ x²eˣ = e − 2，合成

E[eˣ] = 6 − 18e/11 ≈ 1.544。

**实弹三（E[1/X]，期望可以不存在）**：
E[1/X] = (6/11)(2∫₀¹ dx/x + …)——∫₀¹ dx/x = ∞（原函数
log x 在 0 处 −∞），**期望不存在**。密度完美合法、均值
健在，但 g(X) = 1/X 的期望爆炸。教训：**期望的定义
域要逐例检查，"X 有密度"不担保"g(X) 可积"**。

## 10.3 均值与方差：定义、单位与两班级例

**均值** μ = E[X]；**方差** σ² = E[(X−μ)²]；**标准差** σ = √σ²。

**两班级例**（Miller 的招牌对比）：甲班五人 {40,45,50,55,60}，
乙班五人 {0,25,50,75,100}，各以 1/5 等权：

μ甲 = μ乙 = 50（均值分不出两者）；

σ²甲 = (100+25+0+25+100)/5 = 50；σ²乙 = (2500+625+0+625+2500)/5 = 1250。

**方差度量围绕均值的散布**，均值同一而方差天差地别。
**单位警示**：若成绩以米记，方差单位是米²——与均值
不可比。**标准差**才与均值同单位：σ甲 = √50 ≈ 7.07 米、
σ乙 = √1250 ≈ 35.4 米。谈论"波动的自然尺度"永远用 σ。

**两骰之和的完整账**（08 章分布的回收）：μ = 7（对称
性直接读出——pmf 关于 7 对称则均值必为 7，免算）；
σ² = Σᵣ (r−7)²(6−|r−7|)/36 = 35/6 ≈ 5.83，σ = √35/6 ≈ 2.42。

## 10.4 均值可以不存在：Cauchy 的警告

密度 f(x) = 1/(π(1+x²))（Cauchy 分布，第 09 章配平过）。
求均值：∫ x/(π(1+x²)) dx。被积函数是奇函数，对称区间
取极限似乎得 0——**但反常积分的定义要求与逼近路径
无关**。取 A = B 得 0；取 B = 2A，则

∫_{−A}^{2A} = 0 + ∫_A^{2A} x/(π(1+x²)) dx ≥ ∫_A^{2A} (1/(2x))/π·2x… 具体地，被积函数 ≥ 1/(2πx)（x ≥ 1 时），积分 ≥ (1/(2π))·log 2 ≠ 0。

**路径依赖 ⟹ 均值不存在**。这就是 10.2 技术条件的用
意：绝对收敛（∫|x|f dx < ∞）排除一切"正负无穷相消"
的假账，也是交换积分次序（Fubini）的入场券。Cauchy
的样本均值永远不收敛——第 22 章的 FFT-CLT 现场再会。

## 10.5 联合分布：边际、独立与"粘硬币"

**联合密度** f_{X,Y}(x,y)：P((X,Y) ∈ S) = ∬_S f。**边际**
= 积掉别人：f_X(x) = ∫ f_{X,Y}(x,y) dy（离散则是行和/
列和）。**独立** ⟺ f_{X,Y} = f_X·f_Y 处处成立。

**表格法**（离散联合的天然形态）：五枚硬币，X = 前三
枚正面数，Y = 后两枚正面数。独立时联合 = 乘积表：
f(1,2) = 3/8 · 1/4? 后两枚正面数 C(2,2)/4 = 1/4，乘 3/8 =
3/32 ✓（Python/Prolog 全表对拍）。

**粘硬币反例**（Miller 的精妙构造）：同样的 X、同样的
边际，但把第 1、4 枚**粘在一起**（同正同反）。可能性
从 32 降到 16，联合表变形：f_{U,V}(0,2) = 0（U = 0 ⟹
第 1 枚反 ⟹ 第 4 枚反 ⟹ V ≤ 1）而 f_U(0)·f_V(2) =
1/8 · 1/4 ≠ 0。**边际相同，联合可以完全不同**——
独立必须逐格验证，一格破坏即不独立。

**连续联合实弹**：单位圆盘均匀取点，f = 1/π（x²+y² ≤ 1）。
边际 f_X(x) = (2/π)√(1−x²)（|x| ≤ 1）——圆盘投影不是
均匀的！验证归一用到三角代换 x = sinθ 与 cos² 的对称
 averaging（∫₀^{π/2} cos² = π/4，Julia 数值对拍）。不独立：
点 (4/5, 4/5) 在圆外，f_{X,Y} = 0 ≠ f_X·f_Y > 0。**"x 接近
1 时 y 的活动范围被挤压"——支撑集的形状本身编码了
依赖**。

## 10.6 线性性：最有用的一条定理

**定理（线性性）**：E[a₁g₁(X₁) + ⋯ + aₙgₙ(Xₙ)] =
Σ aᵢE[gᵢ(Xᵢ)]——**不要求独立**。

证明的骨架（n = 2，连续情形）：从定义出发，把
∫x·f_X(x) dx 换元成二重积分 ∫∫(x₁+x₂)f_{X₁,X₂}，拆开、
逐个积掉一个变量（得边际）、回收两个一维期望。**关键
洞察：期望继承积分的线性**；独立性从头到尾没有出场。

三个直接推论：

1. **E[c] = c**（常数）：∫c·f = c·∫f = c。
2. **平移伸缩**：Y = aX + b ⟹ μ_Y = aμ_X + b、σ²_Y =
   a²σ²_X（b 只搬均值不动方差；a 把方差放大 a²——
   单位账的再次出场）。
3. **方差捷径**：σ² = E[X²] − E[X]²。

方差捷径的证明是线性性的一行消费：E[(X−μ)²] =
E[X² − 2μX + μ²] = E[X²] − 2μE[X] + μ² = E[X²] − μ²。
**先平方后期望 ≠ 先期望后平方**——顺序即差异本身。

**骰子的标准账**：μ = (1+⋯+6)/6 = 7/2；E[X²] = 91/6；
σ² = 91/6 − 49/4 = 35/12 ≈ 2.92。对比定义式逐项算
(1−3.5)²/6 + …，捷径的算术量减半。

## 10.7 独立时的积期望、和的方差、协方差

**积期望定理**：X、Y 独立 ⟹ E[XY] = E[X]·E[Y]。
证明必须回定义（线性性管不了乘积）：E[XY] =
∫∫xy·f_{X,Y} = ∫∫xy·f_X·f_Y（**独立性在此入场**）=
∫xf_X·∫yf_Y。特例：E[(X−μ_X)(Y−μ_Y)] = 0·0 = 0。

**和的方差定理**：X = X₁+⋯+Xₙ 则 μ 可加（线性性）；
**再加独立**则 σ² 可加：σ²_X = Σσ²ᵢ。证明中展开
(X₁−μ₁)+(X₂−μ₂) 的平方，交叉项 2E[(X₁−μ₁)(X₂−μ₂)] =
0 正是积期望定理的消费。**独立性假设不可省**：X 与
−X 最相依，Var(X + (−X)) = 0 ≠ 2σ²。

**协方差**：Cov(X,Y) = E[(X−μ_X)(Y−μ_Y)] = E[XY] −
μ_Xμ_Y（后者由线性性展开）。一般和的方差：
Var(ΣXᵢ) = ΣVar(Xᵢ) + 2Σ_{i<j}Cov(Xᵢ,Xⱼ)——独立即
协方差项清零。**相关系数** ρ = Cov/（σ_Xσ_Y) ∈ [−1,1]
是标准化的协方差。

**两个必记的警示**：

- **零协方差不推出独立**：取 X 均匀于 {−2,−1,1,2}、
  Y = X²。E[X] = 0、Cov = E[X·X²] = E[X³] = 0（对称
  相消），但 Y 完全由 X 决定。协方差只测**线性**关联。
- **粘硬币的再出场**：粘住的 (U,V) 边际独立表全同而联
  合崩坏——10.5 与此处一币两面。

**投资组合应用**（Miller 的现代注脚）：两股票各 $1/
股、回报均值 $3、方差 $2、相互独立。资本 $1 买 w 股
第一只、1−w 股第二只：S = wX₁ + (1−w)X₂。均值恒
$3（与 w 无关）；Var(S) = 2(w² + (1−w)²)，w = 1/2 时最
小 = 1——**对冲把风险减半而不牺牲期望**。机器通道
（Julia）用模拟扫 w 重现这条抛物线。

**偏度与峰度**（一句话备查）：三阶中心矩标准化 = 偏度
（左右尾不对称的方向），四阶 = 峰度（正态为 3；尖顶
厚尾 vs 平顶薄尾）。

## 10.8 机器通道

**Python（`10_expectation.py`）**：精确分数账——① 多项
式密度 E[Xʳ] 闭式逐 r 验证（r = 1..5 与公式
(6/11)(7r+11)/((r+1)(r+2)(r+3))）；② 两班级的均值/
方差/标准差账（50 vs 1250、√50 vs √1250）；③ 骰子
μ = 7/2、E[X²] = 91/6、Var = 35/12 捷径 vs 定义式双
账；④ 两骰和 μ = 7、Var = 35/6 的 36 格精确账；⑤ 三
硬币 E[X] = 3/2、E[X²] = 3、Var = 3/4；⑥ 零协方差不
独立的 X/X² 例（Cov = 0 精确）。

**Julia（`10_expectation.jl`）**：模拟形态——① 线性性：
骰子样本 aX+b 的均值 = a·3.5+b（a=3, b=2 → 12.5）；
② 方差可加：5 颗骰子之和的方差 ≈ 5·35/12；③ 投资
组合：独立双股票模拟扫 w ∈ {0, 0.25, 0.5, 0.75, 1}，
方差抛物线谷底 w = 1/2、Var ≈ 1；④ Cauchy vs 正态
样本均值的发散对比（Cauchy 均值震荡不收敛——10.4
的频率版）。

**Lean（`Ch10Expectation.lean`）**：判决侧——三硬币
矩账（E[X] = 3/2、E[X²] = 3、Var = 3/4）、骰子捷径账
（91/6 − 49/4 = 35/12）、两班级方差账、投资组合
w = 1/2 账（2((1/2)²+(1/2)²) = 1）、零协方差的对称相消
（(1/4)Σx³ = 0）。

**Isabelle（`T10_Expectation.thy`，会话 MT10）**：连续
侧的测度论锚点——`emeasure lborel Icc`（区间体积 =
均匀概率的原文）、密度 2x 的区间积分账（LBINT 的
FTC 形态：∫₀¹ 2x = 1 归一、期望 ∫₀¹ x·2x = 2/3）、
多项式密度的期望积分。

## 10.9 要点回顾

1. 矩是密度世界的 Taylor 系数：均值 = 重心，方差 =
   散布尺度（**谈尺度用 σ，方差只是 σ²**）。
2. 期望可不存在：E[1/X] 于多项式密度、均值于 Cauchy
   ——绝对可积是闸门。
3. **线性性不需要独立**；积期望、方差可加需要。先问
   "独立性在证明哪一步入场"。
4. Var = E[X²] − E[X]²；Y = aX+b 均值平移伸缩、方差
   只缩放 a²。
5. 边际相同不保证联合相同；零协方差不推出独立——
   依赖藏在联合与非线性里。
6. 机器分工：闭式精确复算（Python）、频率对拍与发
   散演示（Julia）、逐笔判决（Lean/Isabelle）。
