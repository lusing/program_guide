# 第 44 章 无穷可分分布：任意切分的分布族

## 44.1 为什么"能任意切分"值得一个名字

把一天的资产对数收益记作 $X$ 。若市场在微观上由大量同质的小时段叠加而成，那么把一天切成 $n$ 个等长时段，应当存在一种时段收益的分布 $F_n$ ，使 $F$ 恰是 $F_n$ 的 $n$ 重卷积——无论 $n$ 多大。这不是所有分布都有的性质：它说的是**分布可以被任意细分割而家族封闭**。胡书定义 5.4.1 把它命名为无穷可分（infinitely divisible, ID）。

ID 是极限定理的"极限侧分类学"：第 43 章问"什么时候和正态化"，本章问"**所有可能的极限律长什么样**"。答案在胡书 §5.5：u.a.n. 三角阵列的行和的任何非退化弱极限，必定无穷可分。正态只是 ID 族里"没有跳跃"的那一支；Poisson 是"纯跳跃"的那一支；Cauchy 是"跳跃活动率无穷"的那一支。

## 44.2 定义与三种等价读法

**定义（胡书定义 5.4.1）** 称分布 $F$ 无穷可分，若对任意正整数 $n$ ，存在分布 $F_n$ 使

$$ F = \underbrace{F_n*\cdots*F_n}_{n\ \text{重}}. $$

三种等价读法（注 5.4.1–5.4.2）：

1. **特征函数**：$f(t)=[f_n(t)]^n$ ——可分 ⟺ 特征函数永远可以开 $n$ 次方（根还必须是特征函数）；
2. **随机变量**：$X\stackrel{d}=X_{n,1}+\cdots+X_{n,n}$ ，$n$ 个独立同分布项——$X$ 可以拆成任意多份 iid 之和；
3. **唯一性**：根 $F_n$ 唯一（注 5.4.2）。

本章机器件的主角是读法 1：对特征函数开 $n$ 次方在代数上是轻的——`exp` 的 $n$ 次幂律 $(e^x)^n=e^{nx}$ 把切分化成一次除法。

## 44.3 成员名录与两个反例

- **正态** $N(\mu,\sigma^2)$ ：根是 $N(\mu/n,\sigma^2/n)$ ——均值平分、方差按平方缩小（独立增量过程的标准像）。
- **Poisson** $(\lambda)$ ：根是 Poisson $(\lambda/n)$ （注 5.4.2：$\varphi_\lambda$ 与 $\varphi_\lambda(t)$ 均可分）。
- **Cauchy**：根对应位移 $\delta/n$ 、尺度 $\gamma/n$ ——没有矩也有完整切分。
- **Gamma、负二项**：Gamma $(a,r)$ 的根是 Gamma $(a/n,r)$ ；负二项整数侧见机器账。

两个经典**反例**给出直觉：

- **Bernoulli $(p)$ 、$0<p<1$ ，不可 2-分**：若 $X=Y_1+Y_2$ （$Y_i$ iid，$X\in\{0,1\}$ ），则 $Y$ 只能取值 $\{0,1/2\}$ ，三点方程 $q_0^2=1-p$ 、$2q_0q_1=p$ 、$q_1^2=0$ 中第三式强制 $q_1=0$ ，代回第二式得 $0=p$ ，矛盾。**原子结构挡住了切分**。
- **均匀分布（三点 $\{0,1,2\}$ ）不可 2-分**：根在 $\{0,1/2,1\}$ 上，$q_2^2=0$ 给 $q_2=0$ 后剩 $q_0^2=q_1^2=1/3$ 与 $2q_0q_1=1/3$ ——平方判据 $(2q_0q_1)^2=4q_0^2q_1^2=4/9\ne1/9=(1/3)^2$ ，连无理解的影子都没有。

直觉：可分律必须"由无穷多无穷小的部分组成"——有限支撑、有原子的律基本出局（退化律与 Poisson 型例外：Poisson 的原子随切分自动变稀）。

## 44.4 定理 5.4.1：ID 是 iid 和极限的闭包

**定理（胡书定理 5.4.1 与推论 5.4.1）** $X$ 无穷可分，当且仅当 $X$ 的分布是形如

$$ S_n=X^{(n)}_1+\cdots+X^{(n)}_n\quad(\text{每行 } n \text{ 个 iid}) $$

的分布序列的弱极限。

方向之一是显然的：ID 的 $n$ 分量切分本身就是这样的阵列。另一个方向（极限仍 ID）是非平凡的，关键在**引理 5.4.1**：切分出的根特征函数 $f_n(t)\to1$ （分量无穷小），从而 $|f(t)|>0$ 对一切 $t$ 成立——极限过程保住了"能继续开方"的能力。这一引理也是 Lévy 连续定理（第 28.10 节）在阵列上的翻版：分量退化 ⟹ 根存在。

这把两章连成一条线：**第 43 章的三角阵列收敛，极限只能是本章的 ID 律**。

## 44.5 Lévy–Khintchine 公式：三元组字典

**定理（胡书定理 5.4.2，式 5.4.7）** $X$ 无穷可分当且仅当其特征函数有表示

$$ \log f(u)=i\beta u+\int_{\mathbb R}\Big(e^{iux}-1-\frac{iux\cdot x}{1+x^2}\Big)\,\nu(dx), $$

其中 $\nu$ 是有限测度且 $\nu(\{0\})=0$ 。

读法：**每个 ID 律由三元组 $(\beta,\sigma^2,\nu)$ 唯一决定**（$\sigma^2$ 从 $\nu$ 在 $0$ 附近的二阶质量读出）。$\nu$ 叫 **Lévy 测度**，是"跳跃的字典"：$\nu(A)$ 是单位时间内跳幅落入 $A$ 的强度。三个词条：

| 律 | $\beta$ | $\sigma^2$ | $\nu$ |
|---|---|---|---|
| $N(\mu,\sigma^2)$ | $\mu$ | $\sigma^2$ | $0$ （纯扩散） |
| Poisson $(\lambda)$ | 修正项由核吸收 | $0$ | $\lambda\,\delta_1$ （纯跳，跳幅恒 $1$ ） |
| Cauchy $(\gamma)$ | $0$ | $0$ | $\frac{\gamma}{\pi(1+x^2)}dx$ （跳幅密集于 $0$ ，无穷活动率） |

证明路线（不逐行复现）：对 $n$ 分量切分定义经验测度 $\mu_n$ ，用截尾不等式（第 43 章引理 5.2.1 的同族工具）证 $\mu_n$ 的紧性（引理 5.4.2–5.4.3），再对 $\int\frac{x^2}{1+x^2}\,\mu_n$ 取极限得 $\nu$ 。**结构上的要点**：$\frac{x^2}{1+x^2}$ 核同时压制大跳（分母）和小跳（分子），是"能收敛"的技术心脏。

## 44.6 稳定分布：ID 的对称子族

**定义（胡书定义 5.4.2）** $X$ 稳定，若对任意 $k$ 与 iid 副本 $X_1,\dots,X_k$ ，存在 $a_k>0$ 、$b_k$ 使

$$ X_1+\cdots+X_k\ \stackrel{d}=\ a_kX+b_k. $$

稳定 ⟹ 无穷可分（把 $k$ 分量之和线性缩回自身就是切分）。**定理 5.4.3** 给出等价刻画：$X$ 稳定 ⟺ $X$ 是 iid 和的线性标准化极限 $T_n=A_n^{-1}(S_n-B_n)$ 的弱极限，且 $A_{nk}=A_nA_k$ 迫使 $A_n\sim n^\lambda$ （注 5.4.5）。**定理 5.4.4** 完成分类：稳定律的特征函数形如式 (5.4.11)，由**指标** $\alpha\in(0,2]$ 与符号参数决定：

- $\alpha=2$ ：正态（唯一有方差的稳定律；胡书 5.4.3 的证明中 $\lambda=1/2$ 恰对应此支）；
- $\alpha=1$ ：Cauchy；
- $\alpha<2$ ：尾部幂律 $P(|X|>x)\sim x^{-\alpha}$ ——方差无穷大，CLT 尺度 $\sqrt n$ 让位于 $n^{1/\alpha}$ 。

第 27 章说过"Cauchy 样本均值不收敛"（26.11 节）；现在可以精确说：Cauchy 的样本均值 $\bar X_n\stackrel{d}=$ 单个 Cauchy——**稳定律是自己的极限**，这正是"自相似"的分布版本。

## 44.7 三角阵列的极限定理（§5.5）

**定理 5.5.1（结构定理）** 设 $\{X_{nj}\}$ 为 u.a.n. 二重序列，$Z_n=\sum_jX_{nj}-c_n$ 弱收敛，则极限律无穷可分，且由三元组的收敛（中心项 $\to\beta$ 、小截断二阶矩 $\to\sigma^2$ 、谱函数收敛）刻画；反之给定满足 (a)–(c) 的三元组，收敛成立。

**定理 5.5.2（正态判据）** u.a.n. 阵列行和收敛到非退化 $F$ ，则 $F$ 正态 $\iff$ Lindeberg 型条件 $\sum_j\int_{|x|\ge\varepsilon}x^2\,dF_{nj}(x)\to0$ 对一切 $\varepsilon>0$ 成立——第 43 章的充要边界在阵列语言下的重述。

**定理 5.5.5（小数律）** $X^{(n)}_k\sim b(1,p_n)$ ，$np_n\to\lambda$ ，则 $S_n\to^{\,d}$ Poisson $(\lambda)$ 。

一个把三定理放在一起看的算例：设每行第 $j$ 个分量为 $X_{nj}=Y_{nj}+Z_{nj}$ ，其中 $Y_{nj}\sim N(0,1/n)$ 、$Z_{nj}$ 以概率 $1/n^2$ 取值 $1$ 。行和的 $Y$ 部分总方差恒为 $1$ （正态成分），$Z$ 部分的期望跳跃次数为 $n\cdot n^{-2}=1/n	o0$ ——Lévy 质量熄灭，极限纯正态。把 $Z$ 的概率改成 $\lambda/n$ ，期望跳跃次数稳定为 $\lambda$ ，极限立刻变成正态与 Poisson $(\lambda)$ 的卷积（跳扩散增量的最简原型）。三元组的三个旋钮各转一格，极限律就沿着 ID 族滑动——这正是定理 5.5.1 作为“化验单”的含义。

三个定理合成一句话：**u.a.n. 极限 = ID 律；想收敛到正态，当且仅当跳跃部分整体熄灭（Lindeberg）；想让极限是纯跳的 Poisson，让每次试验的成功概率 $p_n\to0$ 且期望次数 $\lambda$ 稳定**。

## 44.8 机器账 I：Lean 的根封闭三连

Lean 件（`examples/lean/Probability/Ch44InfinitelyDivisible.lean`）把读法 1 形式化：

```lean
def InfDivisibleCF (φ : ℝ → ℂ) : Prop :=
  ∀ n : ℕ, 0 < n → ∃ ψ : ℝ → ℂ, ∀ t : ℝ, φ t = (ψ t) ^ n
```

三大律的成员资格都是**完全证明**，共用一个模板（`Complex.exp_nat_mul` + 指数层等式）：

```lean
theorem poissonCF_infdiv (lam : ℝ) :
    InfDivisibleCF (fun t => Complex.exp (lam * (Complex.exp (Complex.I * t) - 1))) := ...
```

正态版的根显式给出 $N(\mu/n,\sigma^2/n)$ 的特征函数；Cauchy 版用 $|t|$ （注意 Lean 里 `(|t| : ℝ)` 强制 ℝ 绝对值——直接写 `(|t| : ℂ)` 会去找复绝对值的 Lattice 实例，是个真实的类型类陷阱）。另外两条结构事实：

- 退化律平凡可分（根是自己）；
- **独立和封闭**：`infdivCF_mul`——ID 特征函数逐点乘积仍 ID，对应"可分律的卷积仍可分"（Poisson $(\lambda_1)$ * Poisson $(\lambda_2)$ = Poisson $(\lambda_1+\lambda_2)$ 的一般形式）。

## 44.9 机器账 II：小数律与谱字典的数值面

Julia（`examples/julia/44_infinitely_divisible.jl`）四段。根封闭抽查的三对函数直接翻译 44.8 节的恒等式：

```julia
phi_poi(t, lam) = exp(lam * (exp(I * t) - 1))
psi_poi(t, lam, n) = exp((lam / n) * (exp(I * t) - 1))
phi_nor(t, mu, s2) = exp(I * mu * t - s2 * t^2 / 2)
psi_nor(t, mu, s2, n) = exp(I * (mu / n) * t - (s2 / n) * t^2 / 2)
```


1. **根封闭数值抽查**：三律 $\max_t|\varphi(t)-\psi(t)^n|$ 在 $n=2,3,5$ 全部 $<10^{-10}$ （Lean 已证恒等，这里只是 sanity）；
2. **小数律收敛账**：$\lambda=2$ ，$n=5,20,100,500$ 时 $P(\mathrm{Bin}(n,2/n)=k)$ 与 Poisson 的最大差从 $0.075$ 收敛到 $0.0005$ （$n=5$ 的差保留为教学点：收敛是渐进的）；
3. **Cauchy 稳定的分位数对账**：样本 $(X_1+X_2)/2$ 与 $X$ 的四分位数逐个对上——**没有矩的律只能用分位数体检**，这是重尾统计的标准姿势；
4. **复合 Poisson 的经验特征函数**：N 服从 Poisson $(2)$ 、跳跃为 $\pm1$ ，$|\widehat\varphi(t)|$ 对上 $\exp(2(\cos t-1))$ ——跳跃部分只贡献 $\cos t$ 因子，就是 $\nu=2\delta_1$ 的直接读数。

Python（`examples/python/44_infinitely_divisible.py`）给**精确分数账**，最有意思的是小数律的封闭公式。相邻概率比一行算出、不做任何近似：

```python
def pmf_bin(n, p, k):
    from math import comb
    return F(comb(n, k)) * F(p) ** k * (1 - F(p)) ** (n - k)

# r_n(k) = P(k+1)/P(k) = (n-k) / ((k+1)(n-1))——与 Poisson 的 1/(k+1) 相对
for k in [1, 2, 3]:
    for n in [10, 100, 1000]:
        r = F(n - k, (k + 1) * (n - 1))
        assert r - F(1, k + 1) == F(1 - k, (k + 1) * (n - 1))
```

$P(\mathrm{Bin}(n,1/n)=k)$ 的相邻比

$$ r_n(k)=\frac{n-k}{(k+1)(n-1)}\ \longrightarrow\ \frac1{k+1}\quad(\text{Poisson}(1)\text{ 的比})， $$

且 $r_n(k)-\frac1{k+1}=\frac{1-k}{(k+1)(n-1)}$ 是**精确分数**——$k=1$ 时对一切 $n$ 恒为零。比值的收敛不需要 $e$ 出现，纯有理算术就把小数律钉住了。负二项的整数侧卷积（NB $(1,p)$ * NB $(1,p)$ = NB $(2,p)$ ，$k=0..5$ 逐点）也用 Fraction 全对。

值得记录的一个实现细节：Julia 的复合 Poisson 采样第一版把到达区间写死在 $[0,1]$ ，
对账值恰好落在 Poisson(1) 的理论曲线上（$0.631=\exp(\cos 1-1)$ 逐位吻合）——
"错误但有规律"的输出比"随机错"更危险，正是理论公式反向排查采样器bug的标准用法：
三个 $t$ 值的偏差方向一致且幅度系统化，指向参数错误而非噪声。修正为 $[0,\lambda]$ 后
三点全部贴住理论值。

## 44.10 机器账 III：不可分判决器

Prolog（`examples/prolog/44_infinitely_divisible.pl`）的卷积引擎按索引求和（`rdiv` 精确）：

```prolog
conv_entry(A, B, K, C) :-
    findall(T,
        (   between(0, K, I),
            nth0(I, A, AI), J is K - I,
            nth0(J, B, BI),
            T is AI * BI ),
        Ts),
    sum_list(Ts, C).
```

四段输出：① `Bernoulli^2 = Bin(2)`、`Bernoulli^3 = Bin(3)`、`NB(1)*NB(1) = NB(2)` 全部列表合一（`Cs2 = B2` 直接判等）；② Bernoulli 的 2-根判决——三点方程消元矛盾；③ 均匀三点的平方判据 $4/9\ne1/9$ ；④ 结论行：**Bin 族的"可分"只沿因子发生（$n\mid m$ 时根是 Bin $(m/n,p)$ ），均匀则完全不可切**——与 44.3 节的手工推导互为孪生。

## 44.11 应用与误区

一个把 44.5 与 44.7 串起来的应用判断题：高频做市商关心"一秒内成交笔数的分布够不够正态"。检验次序应当是：先问单笔的时间占比是否 u.a.n.（一秒内任何一笔占比趋零），再看跳跃强度的谱（Lévy 测度 $\nu$ ）是否在离零处有质量——有，则极限含 Poisson 成分，正态近似在该尺度上系统性偏轻尾；没有且小截断二阶矩占满（Lindeberg），正态才成立。三元组 $(\beta,\sigma^2,\nu)$ 就是这套体检的化验单，44.9 节第 4 段的经验特征函数是它的廉价估计器。

- **跳跃与厚尾建模**：跳扩散、Lévy 过程的增量分布必须 ID（增量可任意细分）；实证金融里 $\alpha<2$ 的稳定成分是厚尾的直接模型——但注意 $\alpha<2$ 意味着方差无穷，基于方差的组合理论全部失效。
- **聚合损失**：保单组合总理赔的经典模型是复合 Poisson——ID 保证"总账 = 任意细分的时段账卷积"。
- **误区一**："和的分布总可以开方"。均匀、Bernoulli 直接反例。
- **误区二**："稳定律就是重尾正态"。$\alpha<2$ 稳定律没有方差，第 26–28 章的全部矩工具失效；实证里常用截断稳定/t 混合替代。
- **误区三**："小数律是 Poisson 的近似专利"。它是定理 5.5.1 的特款：让单次概率趋零、期望次数稳定，极限自动落在 ID 族的 Poisson 支上。
- **误区四**："Cauchy 无矩所以无规律"。它有最规整的切分结构（本章三连证之一），无矩只是说矩工具不适用，不是说混沌。

## 44.12 本章要点

1. ID 定义的三种读法：卷积 $n$ 重、特征函数 $n$ 次方、iid 切分；开方在 `exp` 上是轻的（机器件因此全绿）。
2. 定理 5.4.1/推论 5.4.1：ID = iid 阵列和的弱极限闭包；引理 5.4.1（$f_n\to1$ 、$|f|>0$ ）是闭包性的技术心脏。
3. Lévy–Khintchine 三元组 $(\beta,\sigma^2,\nu)$ ：正态 ν=0、Poisson ν=λδ₁、Cauchy ν 连续稠密——"跳跃字典"。
4. 稳定律 = ID 的自相似子族，指标 $\alpha\in(0,2]$ ；正态独占 $\alpha=2$ ，Cauchy 在 $\alpha=1$ 。
5. §5.5 三定理：u.a.n. 极限必 ID；正态 ⟺ Lindeberg（接第 43 章）；$np_n\to\lambda$ 给 Poisson（小数律）。
6. 机器件：Lean 三大律根封闭全证 + 独立和封闭；Python 的比值封闭公式 $r_n(k)-\frac1{k+1}=\frac{1-k}{(k+1)(n-1)}$ ；Prolog 卷积引擎 + 两个不可分判决（$q_1^2=0$ 消元、$4/9\ne1/9$ 平方判据）。
