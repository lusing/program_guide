# 27 收官速查表：概率论一页通

**对应 Miller 附录 B-D 提炼 + 全书 26 章总账。**

28 章旅程的口袋版：公式、常数、决策树、坑账。**用法**：
先扫决策树定位工具，再查表取公式，最后核对"坑"栏
避免经典翻车。

## 27.1 计数与组合

| 工具 | 公式 | 记号 |
|---|---|---|
| 排列 | n! | n 的全排列 |
| 组合 | n!/(k!(n−k)!) | C(n,k) |
| 多项式 | n!/(a₁!⋯a_k!) | 分配/展开系数 |
| 采样 | 有放回 nᵏ / 无放回 P(n,k) | 序列 vs 子集 |
| pigeonhole | n+1 物 n 抽屉 ⟹ 有对 | 生日的直觉版 |

**恒等式三宝**：C(n,k) = C(n,n−k)；ΣC(n,k) = 2ⁿ；
k·C(n,k) = n·C(n−1,k−1)。**Stirling**：n! ≈ nⁿe^{−n}√(2πn)
（修正 1+1/(12n)）；C(2n,n)/4ⁿ ≈ 1/√(πn)。

## 27.2 概率结构

- **公理**：非负、可加、全 1。
- **条件**：P(A|B) = P(A∩B)/P(B)；乘法链 P(A∩B) =
  P(B)P(A|B)；全概率 P(B) = ΣP(B|Aᵢ)P(Aᵢ)；
  **Bayes** P(A|B) = P(B|A)P(A)/P(B)。
- **独立**：P(A∩B) = P(A)P(B)；成对独立 ⇏ 相互独立；
  零协方差 ⇏ 独立（X 与 X²）。
- **容斥**：P(∪Aᵢ) = ΣP(Aᵢ) − ΣP(AᵢAⱼ) + ⋯；截断给
  Boole 上界 / Bonferroni 下界。

## 27.3 随机变量与矩

**期望** E[g(X)] = Σg·pmf / ∫g·pdf；**线性性不需要独立**；
积期望与方差可加需要独立。**方差** Var = E[X²] − E[X]²；
Y = aX+b ⟹ μ' = aμ+b、Var' = a²Var。**协方差**
Cov = E[XY] − μ_Xμ_Y。

**不等式**：Markov P(X≥a) ≤ E[X]/a（X≥0）；Chebyshev
P(|X−μ| ≥ kσ) ≤ 1/k²；WLLN P(|X̄−μ| ≥ ε) ≤ σ²/(nε²)。

## 27.4 分布族速查

| 分布 | pmf/pdf | 均值 | 方差 |
|---|---|---|---|
| Bern(p) | p^x(1−p)^{1−x} | p | p(1−p) |
| Bin(n,p) | C(n,k)pᵏqⁿ⁻ᵏ | np | npq |
| Geom(p) | pq^{n−1} | 1/p | q/p² |
| NegBin(r,p) | C(k+r−1,k)pᵏqʳ | rp/q | rp/q² |
| Pois(λ) | λᵏe^{−λ}/k! | λ | λ |
| Unif(a,b) | 1/(b−a) | (a+b)/2 | (b−a)²/12 |
| Exp(λ) | λ^{−1}e^{−x/λ} | λ | λ² |
| Erlang(n,λ) | xⁿ⁻¹e^{−x/λ}/(λⁿ(n−1)!) | nλ | nλ² |
| N(μ,σ²) | (2πσ²)^{−½}e^{−(x−μ)²/2σ²} | μ | σ² |
| Gamma(k,σ) | x^{k−1}e^{−x/σ}/(Γ(k)σᵏ) | kσ | kσ² |
| χ²(ν) | y^{ν/2−1}e^{−y/2}/(2^{ν/2}Γ(ν/2)) | ν | 2ν |
| Cauchy | 1/(π(1+x²)) | **不存在** | — |

**族谱**：Bin = n·Bern；Geom → NegBin；Bin(npₙ→λ) →
Pois；Pois(λ)+Pois(μ) = Pois(λ+μ)；Exp = Gamma(1)；
Erlang = Gamma(整数)；Gamma(k=ν/2, σ=2) = χ²(ν)；
Z² ~ χ²(1)；正态+正态=正态（**稳定**）；Cauchy 稳定但
无 CLT。

**正态备忘**：偶矩 (2m−1)!!、奇矩 0；68-95-99.7；
无闭式 CDF（查表/erf）。

## 27.5 变换与极限

**卷积**：f_{X+Y} = f_X∗f_Y（独立）；grouping 省一半。
**换元**：f_Y(y) = f_X(h(y))|h′(y)|（g 单调可逆）。
**逆变换采样**：X = F⁻¹(U)。

**MGF**：M(t) = E[e^{tX}]；矩 = 微分、独立和 = 乘积。
表：N(0,1) → e^{t²/2}；Exp(λ) → 1/(1−λt)；Pois →
e^{λ(e^t−1)}；Bin → (q+pe^t)ⁿ。

**特征函数** φ(t) = E[e^{itX}] 恒存在；卷积变乘法；
正态 e^{−t²/2}；Cauchy e^{−|t|}。

**CLT**：(X̄−μ)/(σ/√n) →ᵈ N(0,1)；连续性修正；1/√n
律（精度翻倍样本 ×4）。**大数定律**：X̄ →ᵖ/as μ。
**Γ 函数**：Γ(s+1) = sΓ(s)；Γ(n+1) = n!；Γ(1/2) = √π；
B(a,b) = Γ(a)Γ(b)/Γ(a+b)。

## 27.6 统计检验决策树

1. 检验**均值**？方差已知 → z；未知 → t（单样本 t(n−1)）；
   双样本：方差已知 z / 同方差合并 t(nx+ny−2) / 异方差
   Welch（非整数 ν）。
2. 检验**方差**？→ χ²：(n−1)s²/σ₀² ~ χ²(n−1)。
3. 检验**模型拟合**（列表）？→ χ² = Σ(O−E)²/E ~ χ²(k−1)，
   恒单侧。
4. α 先于数据定；单侧需方向理由；p 值 = P(数据|H₀)
   **不是** P(H₀|数据)；第一类 = α、第二类依赖距离；
   功效 1−β 靠加样本。

## 27.7 坑账精选（28 章血泪）

**数学坑**：① 均值可不存在（Cauchy 路径依赖、E[1/X] 爆
破）——绝对可积是闸门；② q 独立到最后（早代 q=1−p 得
0=0）；③ 无记忆性是指数/几何的身份证也是"无老化"
的警告；④ σ 与 σ² 别混（Chebyshev 换算事故：界低于
真值即信号）；⑤ 单位账：方差是米²、λ 无量纲、1/√n。

**直觉坑**：⑥ 2n 掷币恰 n 正面 → 0（质量摊薄不是集中）；
⑦ 概率陈述内嵌模型（平票 0.73% vs 10⁻⁵⁴）；⑧ "平均
100 个柯西仍柯西"（无 LLN）；⑨ 最佳拟合 ≠ 好估计
（b 的点估计可以很糟）。

**机器坑**：⑩ 裸数字分式默认 ℕ（0=0 假绿）——ℚ 断言
显式标注；⑪ Simpson 撞端点奇异（代换吸收爆破）；⑫
MC 精度地板 1/√reps；⑬ 模拟对拍的容差要含 CLT 形状
残差（不是噪声）。

## 27.8 证明工具腰带（十一式）

归纳（查小基底）· 分组（换括号即证）· 对称（确认再
用）· 蛮力（小宇宙验证器）· 故事（一题两算免费恒等式）·
反证 · 分治（别漏格）· 反例（杀命题最快）· 推广特例
（先算三个）· 抽屉 · 加零乘一（重写至结构现身）。
