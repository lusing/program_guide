# 09 连续随机变量：密度与积分

**对应 Miller ch8（pp. 255-270）。**

硬币的正面数是离散的；但"到下一班地铁的等待时间"、
"随机点落在区间 [0,1] 的位置"取值连续铺满一个区间——
单点概率的账本失效了（每个点的概率都是 0），"表"必须
换成"密度"。本章定义 pdf 与 CDF 的连续版本，讲清楚
归一化常数的来历，并做两类密度的完整实弹（均匀与
多项式密度）。

## 09.1 为什么单点概率为零，密度如何接手

在 [0,1] 上"均匀随机"取点 X：直觉要求落在任何子区间的
概率 = 子区间长度。于是 P(X = c) ≤ P(c ≤ X ≤ c+ε) = ε
对一切 ε > 0 成立，只能 P(X = c) = 0。

**单点概率全为零，但区间概率非零**——所以描述连续
变量的正确对象不是 pmf 而是：

**密度（pdf）**：非负函数 f_X，使
P(a ≤ X ≤ b) = ∫ₐᵇ f_X(x) dx。
归一化条件：∫_{−∞}^{+∞} f_X = 1（全概率的积分形态）。

**读法上的关键纠偏**：f_X(x) **不是** P(X = x)（那是 0）。
f_X(x)·Δx 才近似"X 落在 x 附近一小段 Δx"的概率——
密度是**单位长度的概率质量**，像一根质量 1 千克的
铁棍在 x 处的线密度：任何切点的"质量"是 0，但任一段
的质量是密度的积分。

**立即的宽松红利**：既然单点概率为 0，则
P(a ≤ X ≤ b) = P(a < X ≤ b) = P(a ≤ X < b) = P(a < X < b)
——端点算不算无所谓。离散世界（08 章）里 ≤ 与 < 的
差别是实打实的跳点，连续世界里一笔勾销。

## 09.2 归一化常数：密度的第一道工序

给定一个形状（非负函数），要成为密度必须配平
"曲线下面积 = 1"。**流程**：先算形状的积分 A，再乘 c =
1/A。两个实弹：

**均匀分布 U[a,b]**：f(x) = 1/(b−a)（a ≤ x ≤ b，否则 0）。
归一：∫ₐᵇ c dx = c(b−a) = 1 ⟹ c = 1/(b−a)。区间概率
退回长度比：P(c ≤ X ≤ d) = (d−c)/(b−a)——"均匀 =
按长度配账"，与 09.1 的直觉定义闭环。

**多项式密度**（Miller 的招牌例，机器通道将对拍到底）：

f_X(x) = (6/11)(2 + 3x − 5x²)，0 ≤ x ≤ 1；否则 0。

归一：∫₀¹ (2+3x−5x²) dx = 2 + 3/2 − 5/3 = 11/6，故
c = 6/11 ✓。注意 f 在 [0,1] 上非负（在端点取值 2 与 0），
形状先验合格，配常数后即密度。

Miller 的提醒：**先检查非负与有限面积，再谈常数**。
f(x) = e^{−x²} 归一常数存在（积分 = √π，第 17 章的
大戏），但 f(x) = 1/(1+x²) 在整轴上积分是 π（arctan 的
老朋友）而 f(x) = 1 在整轴上积分发散——后者永远配不
出密度。**单位一致性**：若 X 以米计，f 的单位是 1/米
（概率/长度），概率本身无量纲——第 10 章方差的
"米平方"教训在这里埋下伏笔。

## 09.3 CDF：连续版本与 F′ = f

**定义**照旧：F_X(x) = P(X ≤ x) = ∫_{−∞}^x f_X(t) dt。

08 章的四条性质原封不动（单调、极限 0/1、区间公式
F(b)−F(a)），但**右连续升级为连续**——阶梯被抹平为
斜坡，因为不再有跳点（单点概率为 0）。

**微积分基本定理接线**：在 f 的连续点处

F′_X(x) = f_X(x)。

CDF 是密度的原函数：知道 f 求积分得 F，知道 F 求导数
回 f。两个方向的实弹：

- **均匀 U[0,1]**：F(x) = ∫₀ˣ 1 dt = x（0 ≤ x ≤ 1）。
  F′ = 1 = f ✓；P(1/4 ≤ X ≤ 3/4) = F(3/4) − F(1/4) =
  1/2（长度比的积分版本）。
- **密度 f(x) = 2x**（0 ≤ x ≤ 1）：归一 ∫₀¹ 2x = 1 ✓
  （这个密度天然归一，常数免配）；CDF F(x) = x²；
  F′ = 2x = f ✓；P(X ≤ 1/4) = 1/16。

**分位数与反解**：F 单调满射 [0,1]，可反解。均匀
U[0,1] 的 F(x) = x 恒等——这就是**逆变换采样法**的
理论根基：取 U ~ U[0,1]，令 X = F⁻¹(U)，则 X 服从 F。
对密度 2x：X = √U 即采样（机器通道 Julia 用它做模拟，
不需要拒绝采样）。F⁻¹(1/2) 是**中位数**：密度 2x 的
中位数 1/√2 ≈ 0.707 ≠ 均值 2/3（第 10 章）——中位
数与均值只在对称分布上重合。

**多项式密度的 CDF**（手工全账，Python 通道将精确
复算）：

F(x) = (6/11)(2x + (3/2)x² − (5/3)x³)，0 ≤ x ≤ 1。

验算端点：F(1) = (6/11)(2 + 3/2 − 5/3) = (6/11)(11/6) =
1 ✓。

## 09.4 混合型与病态：存在性的边界

不是每个随机变量都非离散即连续——**混合型**存在：
以概率 1/2 取 0（跳点），以概率 1/2 在 (0,1) 上均匀
（斜坡）。它的 CDF 在 0 处跳 1/2，然后线性爬到 1。
pmf 与 pdf 各管一段，归一账两边合计。

Miller 同时给出**存在性的反例方向**：函数非负且
"看起来可积"还不够——1/(1+x²) 在整轴上配平成 Cauchy
密度（归一常数 1/π），合法；但把形状换成 1（整轴），
积分发散，永远配不出密度。**判断流程**：非负 → 有限
积分 → 常数 = 1/积分，三关全过才是密度。Cauchy 密度
将在第 10 章成为"均值不存在"的招牌反例（反常积分
路径依赖），第 16 章再次登场。

**混合警告**（考试与实战同坑）：对连续部分用积分、对
跳点用单点概率，两套账不可混用。P(X = 0) = 1/2 而
P(0 < X ≤ 1/2) = (1/2)·(1/2) = 1/4——后者那个 1/2 是
"落在连续部分的总概率"，前者是跳点质量。

## 09.5 机器通道

**Python（`09_continuous_rv.py`）**：精确分数账——① 多
项式密度的归一（∫₀¹ 形状 = 11/6 → c = 6/11）与 CDF
多项式的逐点值（x = 0, 1/4, 1/2, 3/4, 1 的 F 表）；② 密
度 2x 的账：归一、CDF = x²、P(X ≤ 1/4) = 1/16、中位数
1/√2 的数值解；③ 均匀的区间账（长度比）；④ Cauchy
形状 1/(1+x²) 的配平演示（数值积分得 π → c = 1/π）；
⑤ 混合型 CDF 的分段账。

**Julia（`09_continuous_rv.jl`）**：模拟对拍——① 密度 2x
的逆变换采样（X = √U）：经验 P(X ≤ 1/4) ≈ 1/16、经验
均值 ≈ 2/3；② 多项式密度的拒绝采样（包络取常数
6/11·4 = 24/11? 以 max f = 24/11 为界）：经验均值 ≈
9/22 ≈ 0.409；③ 均匀的经验区间概率 vs 长度比；④ 单点
概率为零的演示：10⁶ 个样本中恰好等于目标值的比例
恒为 0。

**Lean（`Ch09ContinuousRV.lean`）**：连续侧的 mathlib
锚点与判决——`Real.volume_Icc`（Lebesgue 体积 = 区间
长度，均匀概率的测度原文）；密度 2x 的 CDF 反导数
判据（`HasDerivAt` 形态的 F′ = f）与区间概率的
norm_num 账；多项式 CDF 端点归一的判决。

## 09.6 要点回顾

1. 连续变量单点概率为 0，概率住进区间；密度 f·Δx 才
   是"附近一小段"的近似概率。
2. 密度三关：非负、有限积分、归一常数 1/积分；均匀
   1/(b−a) 与多项式 6/11(2+3x−5x²) 是两件随身实弹。
3. CDF 连续（无跳点），F′ = f 在连续点成立；F 单调
   满射 [0,1] 支撑反解——逆变换采样 X = F⁻¹(U)。
4. 端点开闭在连续世界一笔勾销；混合型变量跳点用
   pmf、连续段用 pdf，两账分记。
5. 机器分工：精确分数（Python）、逆变换/拒绝采样
   （Julia）、测度锚点与反导数判据（Lean）。
