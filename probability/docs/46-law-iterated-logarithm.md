# 第 46 章 重对数律：极限的精确常数

## 46.1 CLT 之后还差什么

第 27 章的 CLT 说 $S_n/\sqrt n$ 的**分布**收敛到正态；第 26 章的强大数定律说 $S_n/n\to0$ 。但两者都没有回答一个更锋利的问题：**轨道本身**能走多远？即 $\limsup_n S_n$ 的精确阶与常数。重对数律（law of the iterated logarithm, LIL）给出极限定理里少有的"精确到常数"的答案：

$$ \limsup_{n\to\infty}\frac{S_n}{\sqrt{2\,\operatorname{var}(S_n)\,\log\log \operatorname{var}(S_n)}}=1\quad\text{a.s.} $$

分母里的 $\log\log$ （对数的对数）是全概率论最著名的慢尺度：要让它等于 $3$ ，需要 $n\approx e^{e^3}\approx 5\times10^8$ 。这解释了 LIL 最出名的实际特征——**有限样本里你几乎永远看不到常数 1**，本章机器账的纪律因此是"不冒领渐近常数"。

## 46.2 为什么偏偏是 log log：几何分级的算术

LIL 上界的证明从不直接看每个 $n$ ，而是把时间轴按**几何速度**分级：只在 $\sigma_n^2$ 翻倍的点（iid 情形即 $n=2^j$ ）检查。为什么这样就够了？在分级点上用正态尾估计：

$$ P\Big(Z\ge\sqrt{2K\log\log n}\Big)\ \lesssim\ \frac{1}{\sqrt{2K\log\log n}}\cdot\frac{1}{(\log n)^K}, $$

（胡书式 (6.3.1)-(6.3.2)，积分比较加 $\log(n+1)-\log n\le1/n$ 的初等控制。）对 $n=2^j$ ，$\log n=j\log2$ ，于是分级点上的尾概率是 $(j\log2)^{-K}$ 量级——$j$ 的幂律！配第 45 章的 $\sum 1/j^2<\infty$ ，第一 Borel–Cantelli 把"无限次越界"杀掉。这就是 $\log\log$ 的来历：**要让尾概率从 $n^{-c}$ 变成可和的 $j^{-K}$ ，恰好需要在根号里放 $\log\log n$ ** 。多一层或少一层 log 都不行：$\sqrt{n\log n}$ 的边界太紧（会被无限次穿越），$\sqrt{n\log n\log\log n}$ 太松（LIL 说它太浪费）。

本章 Lean 件把这条算术链的骨架做成了完全证明的整数证书：

```lean
theorem two_pow_ge_cube (n : ℕ) (hn : 10 ≤ n) : n ^ 3 ≤ 2 ^ n := by
  induction hn with
  | refl => norm_num
  | @step k hk ih => ...
```

指数压倒多项式（$2^n\ge n^3$ 对一切 $n\ge10$ ，归纳证明）是"分级求和可被幂律控制"的代数心脏；Prolog 通道补充了证书的搜索面：$k=3$ 的最小起点是 $n=10$ （$2^9=512<729=9^3$ 恰好失败），$k=5$ 时推迟到 $23$ 。

## 46.3 指数不等式与中位数工具

直接的 Chebyshev 尾 $1/t^2$ 远不够用——分级点上需要**指数小**的尾。胡书定理 6.3.1：设 $X_1,\dots,X_n$ 独立、零均值、有界，记 $s_n^2=\operatorname{var}(S_n)$ 、$c_n=\max_k(\operatorname{ess\,sup}|X_k|)/s_n$ ，则

$$ \text{(a)}\ 0<t<1/c_n\ \Rightarrow\ P(S_n\ge t s_n)\le\exp\Big(-\frac{t^2}{2}(1-\varepsilon(t,c_n))\Big);\qquad \text{(b)}\ t\ge1/c_n\ \Rightarrow\ \text{同样指数级的单边控制}. $$

证明的基石是引理 6.3.1：对 $|X|\le c$ 、$E X=0$ 、$\sigma^2=E X^2$ ，截断的指数矩满足 $E e^{tX}\le\exp(\sigma^2 g(t))$ 型不等式——把"方差小"升级成"指数矩小"，这是所有精细极限定理的通用杠杆。引理 6.3.2 再给中位数版本 $|m(X)|\le\sqrt2\,E X^2$...为没有矩假设的场合（如 Lévy 不等式的推广）保留控制工具。

## 46.4 Kolmogorov 重对数律：双翼证明

**定理（胡书定理 6.3.3）** 设 $X_n$ 独立、$E X_n=0$ 、$d_n=\operatorname{ess\,sup}|X_n|<\infty$ 。记 $\sigma_n^2=\operatorname{var}(S_n)$ 。若 $\sigma_n^2\to\infty$ 且 $d_n=o\big(\sqrt{\sigma_n^2/\log\log\sigma_n^2}\big)$ ，则

$$ \limsup_{n\to\infty}\frac{S_n}{\sqrt{2\sigma_n^2\log\log\sigma_n^2}}=1\quad\text{a.s.} $$

注意它**不要求同分布**——条件是方差增长与单个分量相对尺度的两笔账。iid 情形（$\sigma_n^2=n\sigma^2$ ）就是经典的 Hartman–Wintner 形式。

证明分两翼：

- **上界翼**：取 $t_n=\sqrt{2\log\log\sigma_n^2}$ ，证 $P(S_n>(1+\varepsilon)\sigma_n t_n\ \text{i.o.})=0$ 。在 $\sigma^2$ 翻倍的分级点用 46.3 的指数不等式（胡书 (6.3.18)），分级求和收敛，第一 BC 收尾。
- **下界翼**：证 $P(S_n>(1-\varepsilon)\sigma_n t_n\ \text{i.o.})=1$ 。困难在于分级点之间的事件**不独立**——引理 6.3.5（几何序列的 log 比渐近）与引理 6.3.4 帮助把相互干扰隔离开；在隔离出的子列上，用 Berry–Esseen 定理（胡书 (6.3.5) 的证明处引用）把二项尾逼近成正态尾，概率和发散，第二 BC 抬起测度 1。

双翼合起来，limsup 被 $1\pm\varepsilon$ 夹住。mathlib 面的对应锚点是两个 BC：

```lean
#check @ProbabilityTheory.measure_limsup_eq_one
-- 第二 Borel–Cantelli（下界翼引擎）：独立事件概率和发散 ⟹ 无限发生
#check @ProbabilityTheory.measure_zero_or_one_of_measurableSet_limsup
-- 尾 0-1 律：limsup 型尾事件的测度只能为 0 或 1
```

## 46.5 尾 0-1 律：为什么常数非此即彼

$\{S_n>(1+\varepsilon)\sigma_nt_n\ \text{i.o.}\}$ 是尾事件——改动任何有限个 $X_n$ 都不改变它。Kolmogorov 0-1 律说尾事件测度只能是 $0$ 或 $1$ 。于是 LIL 的证明没有中间地带：上界翼必须把测度压到 $0$ ，下界翼必须抬到 $1$ 。这也解释了 limsup 常数为什么是一个**确定的数**而不是随轨道漂移的量：几乎所有轨道共享同一个 limsup。

0-1 律在数学上通过 limsup σ 代数的平凡性实现（mathlib 的 `measure_zero_or_one_of_measurableSet_limsup`）；其经验面见本章 Julia ③ 段——对每个 $c<1$ ，$\max T_k>c$ 的轨道比例随 $N$ 单调上升（$c=0.4$ 时 $0.907$ 、$c=0.8$ 时 $0.617$ ，$N=5\times10^4$ ），方向与“比例趋于 1”的论断一致，但速度慢得诚实。

## 46.6 机器账 I：分级二项尾的精确账

分级点 $n=2^j$ 上 Rademacher 部分和的尾概率是纯二项账。关键换算（本章三通道共用）：

$$ S_n=2B-n\quad(B\sim\mathrm{Bin}(n,1/2))，\qquad S_n\ge t\iff B\ge\lceil(n+t)/2\rceil. $$

Lean 件在 $n=16$ 、阈值 $t=10$ 处完全展开：

```lean
example : ∑ j ∈ Finset.Ico 13 17, (Nat.choose 16 j : ℚ) / 2 ^ 16
      = (697 : ℚ) / 65536 := by
  rw [show (Finset.Ico (13 : ℕ) 17) = {13, 14, 15, 16} from by decide]
  norm_num [Nat.choose]
```

（$S_{16}\ge10\iff B\ge13$ ，$\sum_{j\ge13}\binom{16}{j}=560+120+16+1=697$ 。第一版文件曾把 $\sum_{j\ge10}$ 误标成 $P(S_{16}\ge10)$ ——那是 $P(S_{16}\ge4)$ 的账；被 Python 的精确分数断言当场抓出，这正是三通道互查的价值。）双侧账 $\times2$ 得 $P(|S_{16}|\ge10)=1394/65536$ ，即上界翼 (6.3.18) 在此点的精确面。

Python 把同一账铺成表：$j=4,6,8,10,12$ 时精确尾 $0.0106\to0.0084\to0.0051\to0.0027\to0.0017$ ，全部 $\le(j\ln2)^{-2}$ 界（$0.130\to0.014$ ）——界是松的，但方向与量级都对，且**每个数字都是精确分数**（例如 $697/65536$ ），不是浮点近似。

## 46.7 机器账 II：慢尺度与"不冒领"

Julia 件是本章的"诚实演示"：

```julia
lil_scale(n) = sqrt(2 * n * log(log(n)))
# 单轨道 max T_k：N = 10^3, 10^4, 10^5, 10^6 全部停在 0.353
```

同一条种子 4601 的轨道，运行最大值 $\max_{k\le N}T_k$ 在 $N$ 放大一千倍后纹丝不动——因为创造该最大值的时刻早早就出现过，而 $\log\log$ 的增长慢到让后续波动追不上分母的膨胀。④ 段做二阶修正实验：把边界从 $1$ 收紧到 $1-\frac{\log\log\log n}{2\log\log n}$ （已知的 LIL 精细化方向），修正后的统计量从 $0.353$ 抬到 $0.415$ ——仍然远低于 $1$ ，但方向说明**部分慢尺度来自修正项**。有限样本的 LIL 检验必须声明这一局限：$N\le10^6$ 时 $\log\log N\le2.6$ ，渐近常数没有任何出场机会。

把慢尺度写成一张小表（数值取自 Julia/Python 通道）：

| $n$ | $\log\log n$ | $\sqrt{2n\log\log n}$ | 模拟的典型 $|S_n|$ |
|---|---|---|---|
| $10^2$ | 1.53 | 17.5 | 约 10 |
| $10^4$ | 2.22 | 211 | 约 120 |
| $10^6$ | 2.63 | 2295 | 约 800 |

三行合起来读：分母增长近线性（ $\log\log$ 几乎不动 ），分子（随机游走的典型位移 $\sim\sqrt n$ ）只能追到分母的六到七成——这正是  $\max T_k$ 停在 $0.35$ 附近的算术原因。要 $\log\log n$ 从 $2.63$ 涨到 $3.5$ ，$n$ 需要从 $10^6$ 涨到 $3	imes10^7$ ；涨到 $5$ 需要 $10^{23}$ 量级。**LIL 的常数 1 是为指数级大的时间尺度准备的**。

## 46.8 机器账 III：Prolog 的证书面

Prolog 件四段，核心是二项尾换算与乘法递推的组合账：

```prolog
tail_num(N, T, S) :-
    Idx is (N + T + 1) // 2,          % S_n >= t  ⟺  Bin >= (n+t)/2
    findall(C, (between(Idx, N, I), comb(N, I, C)), Cs),
    sum_list(Cs, S).

comb(_N, 0, 1) :- !.
comb(N, K, 0) :- K > N, !.
comb(N, K, C) :- K1 is K - 1, N1 is N - 1,
                 comb(N1, K1, C1), C is C1 * N // K.
```

账目四笔：① 分级二项尾的精确分数（$t=8$ 时 $2517/65536$ 、$t=10$ 时 $697/65536$ ，三方对齐）；② 指数压倒多项式的最小起点搜索（$k=3$ 得 $n=10$ ，与 Lean 定理互相印证；$k=5$ 得 $23$ ）；③ 分级求和原型 $\sum_{j\le m}1/j^2$ 的精确部分和（$m=10,100,1000$ 单调有界，上界翼的收敛账）；④ 双侧翻倍 $2\times697/65536$ 。每一笔都是可复核的精确算术——LIL 的分析难点（指数不等式、0-1 律、Berry–Esseen）不在 Prolog 的射程内，但**证明骨架里的每一步初等算术**都在。

## 46.9 分级算术的手工演算

把 46.2 的账在纸上过一遍（也是机器表数字的来源）。取 $K=2$ 、$j=8$ （$n=256$ ）：

1. 分母尺度 $\sqrt{2nK\log\log n}$ ：$\log256=5.545$ ，$\log\log256=1.713$ ，$2	imes256	imes2	imes1.713=1752.6$ ，开方得 $tpprox41.9$ ，取整 $42$ ；
2. 换算到二项：$B\ge(256+42)/2=149$ ；
3. 精确尾：$P(B\ge149)=\sum_{i\ge149}inom{256}i/2^{256}pprox0.0051$ （Python 表中 $j=8$ 行的分数）；
4. 对照界：$(j\ln2)^{-2}=(8	imes0.693)^{-2}=0.0325$ ——尾是界的六分之一，方向量级全对。

$j=12$ （$n=4096$ ）时同样的算术给尾 $0.0017$ 对界 $0.0145$ 。可以看出界大约松一个常数因子——这不影响可和性判断（要的是幂律衰减，不是紧常数），也解释了为什么定理证明用“ $\le$ ”而机器表显示“ $\ll$ ”。

Python 的表由一个纯分数函数生成，整数证书的搜索也在同一文件里：

```python
def binom_tail_frac(n, t):
    """P(S_n >= t) = P(Bin(n,1/2) >= (n+t)/2) 的精确分数（S = 2B - n）。"""
    idx = (n + t + 1) // 2
    num = sum(comb(n, i) for i in range(idx, n + 1))
    return F(num, 2 ** n)

assert binom_tail_frac(16, 10) == F(697, 65536)   # 与 Lean 件同一账

n0 = next(n for n in range(2, 200)
          if 2 ** n >= n ** 3 and 2 ** (n - 1) < (n - 1) ** 3)
assert n0 == 10    # Lean 已证对一切 n >= 10 成立；n = 9 恰好失败（512 < 729）
```

## 46.10 与 CLT、SLLN 的分工

| 定理 | 问的问题 | 回答 | 证据形态 |
|---|---|---|---|
| SLLN（第 26 章） | $S_n/n$ 趋于什么 | $0$ （均值） | 收敛 |
| CLT（第 27 章） | 单点 $n$ 的分布形状 | $N(0,\sigma^2)$ | 分布收敛 |
| LIL（本章） | 整条轨道的上包络 | $\sqrt{2\sigma_n^2\log\log\sigma_n^2}$ ，常数精确到 1 | limsup 常数 |

三者互不替代：SLLN 给趋势、CLT 给快照、LIL 给包络。反过来的蕴含也不成立——知道每个点的分布（CLT）推不出轨道包络（LIL），因为相关性信息在逐点分布里被抹掉了。这正是 46.4 下界翼必须重新处理分级点间相关性的原因，也是“把 CLT 尾直接当 LIL 用”误区（46.11 之三）的技术根源。

## 46.12 与第 25 章收敛模式的对照

LIL 的结论是一个 limsup 等式，落在第 25 章的收敛模式图谱里别有意味：它既不是说 $T_n$ 收敛（它不收敛——limsup 是 1 而 liminf 是 $-1$ ，轨道永远振荡），也不是说它依分布稳定。它描述的是**聚点的边界**：$T_n$ 的取值序列在 $[-1,1]$ 内密密地往返，任何 $c<1$ 都被无穷多次超过、任何 $c>1$ 都只被有限次超过。用第 45 章的语言：事件 $\{T_n>c\}$ 对 $c<1$ 是概率 1 的 i.o. 事件、对 $c>1$ 是概率 0 的 i.o. 事件——同一族事件在临界值两侧的非对称命运，正是 0-1 律最生动的实例。

顺带一提，LIL 有一个更深的后续（Strassen 不变原理）：不仅 limsup 是 1，把部分和轨道整体线性拉伸后，其聚点集恰为某个 Hilbert 单位球上的射影族——LIL 是这个几何定理的投影。该主题超出本书范围，但它说明 $\sqrt{2\log\log n}$ 不是孤立的技巧，而是一个泛函极限定理的第一坐标。

## 46.11 应用与误区

- **长时段风险边界**：LIL 给出"到时刻 $n$ 为止累计漂移的几乎必然包络" $O(\sqrt{n\log\log n})$ ——比 CLT 的 $\sqrt n$ 松半档、比任何 $n^{1/2+\varepsilon}$ 都紧；交易策略的最大回撤控制若以此包络为基准，是概率上最经济的。
- **检验"真随机性"**：伪随机数发生器若独立性有缺陷，长轨道的 $\max T_k$ 会系统性偏离 LIL 包络的统计形态。
- **误区一**："模拟里 $\limsup$ 看起来是 $0.35$ ，定理错了"。不对——$\log\log$ 慢尺度使有限样本的 $\max$ 远低于 $1$ 且极不稳定；46.7 的实验就是本误区的溶解剂。
- **误区二**："LIL 给出收敛速度"。不——limsup 常数是**聚点**信息，不是速度信息；速度要用 46.7 的二阶修正或鞅方法（第 47 章）另算。
- **误区三**："把 CLT 尾直接当 LIL 用"。CLT 只管单点分布；把 $\sqrt{2n\log\log n}$ 的越界概率按正态近似逐点相加会低估相关性，必须走分级 + BC 的路线。
- **误区四**："$\log\log$ 是书写错误"。把根号里的 $\log\log$ 换成任何一个别的缓慢函数，定理都会错——上界或下界翼会塌掉。

## 46.13 一个历史注记与一道思考题

Hartman 与 Wintner（1941）在 iid 情形证明了本章定理；Kolmogorov（1929）更早给出有界独立变量版本（即胡书定理 6.3.3 的直接形态）。反过来，Strassen 1964 年证明：若 iid 部分和满足 $\limsup S_n/\sqrt{2n\log\log n}=1$ ，则方差必须有限——LIL 的常数 1 恰好刻画“有限方差”的边界。这给了本章一个漂亮的闭环：**常数不是证明的副产品，是假设的等价物**。

思考题（可用本章工具做数值实验）：把 Rademacher 步长换成重尾 $P(X=\pm k^{1/4})=c_\pm k^{-1}$ 型衰减的“非均匀步长游走”，LIL 边界应当换成什么？提示——第 45 章的方差账 $\sum\operatorname{var}$ 决定 $\sigma_n^2$ 的增长阶，把它代进定理 6.3.3 的分母即可；机器上可用 46.7 的轨道法对照。

## 46.14 本章要点

1. LIL 给轨道最大斜率的精确常数：$\limsup S_n/\sqrt{2\sigma_n^2\log\log\sigma_n^2}=1$ a.s.（定理 6.3.3，不要求同分布，条件是 $\sigma_n^2\to\infty$ 与 $d_n=o(\sqrt{\sigma_n^2/\log\log\sigma_n^2})$ ）。
2. $\log\log$ 的来历是分级算术：$n=2^j$ 处正态尾 $\approx(j\log2)^{-K}$ 可和，第一 BC 收上界；下界要 Berry–Esseen + 第二 BC，且分级点间不独立是主要困难（引理 6.3.4/6.3.5）。
3. 指数不等式（定理 6.3.1/引理 6.3.1）把方差控制升级为指数矩控制——精细极限定理的通用杠杆。
4. 尾 0-1 律解释常数为何非此即彼：limsup 事件的测度没有中间值，几乎所有轨道共享同一个 limsup。
5. 机器账纪律：精确分数（$697/65536$ 及全表）、整数证书（$2^n\ge n^3$ 从 $n=10$ 起）、慢尺度演示（$10^6$ 步 $\max T=0.353$ ）——每个数字都可复核，渐近常数不冒领。
6. 三通道互查的实例：Lean 件的二项尾最初标错事件（$\sum_{j\ge10}$ 实为 $P(S\ge4)$ 的账），被 Python 精确分数断言当场纠错——形式件也会犯标签错误，跨通道对账是最后一道防线。
