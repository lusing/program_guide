# 13 离散分布族：从伯努利到德国坦克

**对应 Miller ch12（pp. 343-364）。**

第三篇开篇：常用离散分布。两条主线贯穿全章——**伯努利
的家谱树**（Bernoulli → Binomial → Multinomial / Geometric →
Negative Binomial，Poisson 是它的远亲极限）与**每见一个
分布就算均值方差**的肌肉记忆。收尾是二战名案**德国坦克
问题**：离散均匀分布 + 期望反解，拯救了情报高估一个数量
级的困局。

## 13.1 Bernoulli：一切的根

X ~ Bern(p)：P(X = 1) = p、P(X = 0) = 1−p（1 记"成功"）。
线性代数式的两行账：

μ = 1·p + 0·(1−p) = p；σ² = (1−p)²p + p²(1−p) = p(1−p)。

单个伯努利无事可做；威力在于**复制**——n 枚独立硬币
同时掷，或一枚硬币掷 n 次（独立性使两者不可区分）。

## 13.2 Binomial：线性性的红利

X ~ Bin(n, p)：P(X = k) = C(n,k)pᵏ(1−p)ⁿ⁻ᵏ。归一化即
二项定理（第 08 章已验）。均值方差的**推荐证法**：

X = X₁ + ⋯ + Xₙ（n 个独立 Bern(p)），由期望线性性与
独立和方差可加（第 10 章定理）：

μ = p + ⋯ + p = np；σ² = p(1−p) + ⋯ + p(1−p) = np(1−p)。

**一行分解顶掉两页二项系数求和**——"做许多简单题胜过
一道难题"的又一次胜利；而且反过来赠送了组合恒等式
（第 12 章的收割）。另一条路线是微分恒等式（§11.3 的
p∂/∂p 法），两条路都已机器化。

**赌骰例**：四枚独立骰子，押 1–6 中一个数；出现 k 次赢
k 美元，零次输 1 美元。X 取 −1,1,2,3,4，概率为
C(4,k)(1/6)ᵏ(5/6)⁴⁻ᵏ：

E[X] = (−1·625 + 1·500 + 2·150 + 3·20 + 4·1)/1296
= **239/1296 ≈ 0.184**——值得玩（每 1296 局期望净赚 239
美元）。原书用 10⁸ 次模拟复核：0.184213 vs 理论 0.184414。

## 13.3 Multinomial：两种以上结局

n 次独立试验，每次 k 种互斥结局（概率 p₁,…,p_k）。恰
x₁,…,x_k 次（Σxᵢ = n）的概率：

P = n!/(x₁!⋯x_k!) · p₁^{x₁}⋯p_k^{x_k}，

系数来自逐类选择的望远镜乘积（第 07 章多项式系数的
再出场）。**边际即二项**：只盯第 i 类（i vs 非 i），Xᵢ ~
Bin(n, pᵢ)，故 μ_{Xᵢ} = npᵢ、σ²_{Xᵢ} = npᵢ(1−pᵢ)。

**饼干罐**：巧克力 45%/ snickerdoodle 30%/糖 25%，有放回
抽 6 块，恰 3-2-1 的概率 = 6!/(3!2!1!)·0.45³·0.30²·0.25
≈ **0.123**。也可由"合并 B、C 再展开"的二项定理两步
推导（原书示范条件概率 p₂/(p₂+p₃) 的中途出场）。

## 13.4 Geometric：等到第一次成功

X ~ Geom(p)：**等到首次成功的投掷数**，P(X = n) =
p(1−p)^{n−1}（n ≥ 1）。归一化 = 几何级数：p·Σ(1−p)^m
= p/(1−(1−p)) = 1。

**均值的无记忆证明**（原书招牌）：

μ = 1·p + (μ+1)(1−p)——首掷成功（概率 p）计 1；首掷
失败（概率 1−p）则**过程重启**，期望仍是 μ，加上已耗
的 1 次。解之：pμ = 1，**μ = 1/p**。方差
σ² = (1−p)/p²（微分恒等式更顺手）。

**黄紫球罐**：紫球比例 p/(p+y)，有放回抽取，第 m 次前
未见紫球的概率 P(D ≥ m) = (y/(p+y))^{m−1}——几何尾部
的"只留失败"读法。无记忆性 P(X > x+a | X > a) =
P(X > x) 是它的连续表亲指数分布的预告（第 14 章）。

## 13.5 Negative Binomial：等到第 r 次失败

X ~ NegBin(r, p)：**第 r 次失败前的成功数** k，
P(X = k) = C(k+r−1, k)·pᵏ(1−p)ʳ。推导：末掷必为失败
（第 r 个），前 k+r−1 次中恰 k 次成功。μ = rp/(1−p)、
σ² = rp/(1−p)²。

**约定警告**（原书反复强调）：各书对负二项的定义
不同——成功数还是失败数、支撑从 0 还是从 1、p 指成功
还是失败。对比任何资料先查口径。r = 1 时它退化为
Geom 的平移（验证口径的特例法）。

**均值的双证明**：① 微分恒等式——对归一化等式作用
p∂/∂p，移项回收 μ = rp/(1−p)（唯一已知恒等式是"和为
1"，那就微分它）；② 归纳 + 无记忆：μ_{r+1} =
(μ_{r+1}+1)p + μ_r(1−p)——首掷成功则任务不变重启（+1），
首掷失败则剩余需求降为 r（不 +1，因为计数的是成功数；
**这里原书自曝写作时踩过的坑**：误写 (μ_r+1)(1−p) 导致
1+rp ≠ p+rp，靠"预知答案长什么样"倒推定位错误）。

**机器寿命例**：日完好率 98%、5 次故障报废，期望使用
天数（成功数）μ = 5·0.98/0.02 = **245 天**。

## 13.6 Poisson：稀有事件的计数

X ~ Pois(λ)：P(X = n) = λⁿe^{−λ}/n!。归一化 = e 的
Taylor 级数：e^{−λ}·Σλⁿ/n! = e^{−λ}e^λ = 1。

它是 **Bin(n, pₙ) 在 npₙ → λ 下的极限**（大 n 稀有事件；
习题 12.8.20 的推导现场）。均值：λ∂/∂λ 作用于归一式，
μ = λ（同法得 σ² = λ——**均值 = 方差 = λ** 是泊松的指
纹）。单位学注记：λ 必须无量纲（e^{−λ} 的级数各项需同
单位），"λ 与 λ² 同单位"是荒谬的，故 λ 是纯数。

**邮局例**：λ = 1/3，P(至少一位顾客) = 1 − P(0) =
1 − e^{−1/3} ≈ **0.283**（原书 10⁷ 次模拟：28.32%）。
**IKEA 例**：λ = 1/2，P(≤3) = e^{−1/2}(1 + 1/2 + 1/8 +
1/48) ≈ **0.998**。补集法避免无穷和——离散无穷分布的
标准工艺。

## 13.7 离散均匀与德国坦克问题

X 在 {a, a+1, …, a+n−1} 上等概率 1/n：μ = a + (n−1)/2、
σ² = (n²−1)/12（平移到 0 起点再算，加回 a——"先简化
再平移"的代数卫生）。

**德国坦克问题**（本章压轴）：二战盟军由缴获坦克的
序列号 1..N 估计产量 N。观测 k 个编号（无放回），最大
值 M 的分布：

P(M = m) = C(m−1, k−1)/C(N, k)——m 必入选，其余 k−1
个取自 {1,…,m−1}。

**E[M] 的妙算**（归一化常数理论的离散预演）：

E[M] = Σ m·m!/((k−1)!(m−k)!)·k!(N−k)!/N! 乘以
1 = (k/(N+1))·((N+1)/(k+1)) 的巧妙拆项，把求和项配成
"从 N+1 个里抽 k+1 个、最大为 u"的完整概率分布——
求和自动等于 1！于是

**E[M] = k/(k+1)·(N+1)**，反解得估计量 **N̂ = (k+1)/k·m − 1**。

历史战绩：统计估计 169/244/327 vs 情报估计 1000/1550/
1550 vs 战后德国记录 122/271/342——统计完胜。这个
"把求和项配成另一个分布的归一化"的手法，是第 17 章
χ² 密度里"免算角度积分"的同一招。

## 13.9 要点回顾

1. 家谱：Bern → Bin → Multinomial；Bern → Geom →
   NegBin；Bin(npₙ→λ) → Poisson。每见新分布先算 μ 与 σ²。
2. Binomial 矩走线性性（分解为示性和），微分包办其余
   各族（唯一恒等式"和为 1"就是求导的原料）。
3. 无记忆性双现场：Geometric 的重启论证（μ = 1/p）与
   NegBin 的归纳；先猜答案再倒推排错。
4. Poisson：均值 = 方差 = λ（指纹）、补集法避无穷和、
   λ 无量纲。
5. German Tank：E[M] = k/(k+1)(N+1) 由"配成新分布的
   归一化"免算求和；N̂ = (k+1)/k·m − 1 战场完胜情报部门。
