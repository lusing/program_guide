# 16 理论态射与小理论方法

> 对应读本：Farmer《Simple Type Theory》第 13 章全部（动机例子、
> 小理论方法、翻译与态射定理、忠实态射、运输、理论图与组合子）。
> 代码：`examples/16_morph/`——**Lean 旗舰**（MON 作为结构参数证
> 一次、两个实例运输、义务的证明级清偿、GRP 负例）；**Prolog
> 镜像**（表级义务检查与见证机）。

数学知识高度互联：同一个「幺半群」结构换个马甲到处出现。在
每个理论里把同样的定理各证一遍是浪费——**小理论方法**（little
theories method）把知识组织成一张**理论图**：节点是理论、边是
保持定理意义的翻译。证一次，处处运输。这是 IMPS 的心脏，也是
Isabelle locale / PVS theory、以及 Lean 的 section 与结构参数化
背后的共同思想——本章在四层机器面上把它走通。

## 16.1 动机：两份相同的定理包（书 13.1）

在实数理论 COF 里迟早要证两条定理：

> X⁺：`∀x. (∀y. x+y = y = y+x) ⇒ x = 0`（加法幺元唯一）
> X✱：`∀x. (∀y. x·y = y = y·x) ⇒ x = 1`（乘法幺元唯一）

证明一字不差。它们都是**幺半群理论 MON** 的定理
`X : ∀x. (∀y. x·y = y = y·x) ⇒ x = e` 的实例——在 MON 里证一次，
用两个翻译运回来：Φ⁺ 把 `S↦R, ·↦+, e↦0`；Φ✱ 把 `S↦R, ·↦×, e↦1`。
**翻译保义（是态射）是因为 (R,0,+) 与 (R,1,×) 都是幺半群。**

反例同页：把群理论 GRP 的逆元符号也映过去——Ψ⁺（映到 + 与
`−`）是态射（(R,0,+,−) 是群）；Ψ✱（映到 × 与 `·⁻¹`）**不是**
（(R,1,×,·⁻¹) 不是群：0 没逆元）。修复要用**准类型**：把 S 映
到 quasitype `{r:R | r ≠ 0}`——Ψ′✱ 又是态射了。基型不必映到
基型、常数不必映到常数——**映到表达式**，这是翻译的一般形态。

## 16.2 小理论方法与理论图

> **小理论方法**（13.2，Farmer 等的 IMPS 论文）：每个数学话题在
> 抽象层级**最方便**的那个小理论里发展；概念（定义）与事实
> （定理）作为「信息」，经理论图的有向边（态射）从抽象流向具体。

采用这套架构的系统横跨两个世界：证明助手（IMPS、Isabelle、
PVS、MMT、Ergo）与软件规格（CASL、OBJ、Specware、KIDS）。
节点=理论、边=态射——15 章的「理论即规格」在此升级为**规格的
网络**。

## 16.3 翻译与态射定理

> **翻译** Φ = (µ, ν)：µ 给每个基型指定目标中的一个类型（或
> 准类型），ν 给每个常数指定目标中相应类型的**闭表达式**；沿
> 七个构造子爬行即得项与公式的像（ν 的递归定义对应 12 章
> Alonzo 的七构造子，一一对应）。**态射** = 保义的翻译：
> T₁ ⊨ A ⟹ T₂ ⊨ ν(A)。

什么样的翻译是态射？**态射定理**（13.13）给出充分条件：

> 翻译的**义务**（obligation）三类：基型映到准类型时的非空性、
> 每个常数的定义性（ν(c)↓）、每条公理的像。义务全部在 T₂ 中
> 有效 ⟹ Φ 是态射。

证明的引擎是**提取引理**（13.12）：从 T₂ 的任一模型 M₂ 里，沿
Φ 提取出 T₁ 的模型 M₁（准类型的域 = 满足谓词的元素；ν(c) 的值
当解释）——于是 ν(A) 在 M₂ 真 ⟹ A 在 M₁ 真。相对可满足性
（13.14）：态射的目标可满足 ⟹ 源可满足。翻译可复合（13.7，
态射封闭）、包含/嵌入是特例（13.3/13.4）。

## 16.4 Lean 旗舰：小理论 = 结构参数化

`ex16_morph.lean` 的第一层几乎是宣言：**Lean 的 structure +
定理参数化就是小理论方法的内核形态**——

```lean
structure Monoid where
  carrier : Type
  mul : carrier → carrier → carrier
  e : carrier
  assoc : ∀ x y z, mul (mul x y) z = mul x (mul y z)
  lid  : ∀ x, mul e x = x
  rid  : ∀ x, mul x e = x

theorem unique_two_sided_id (M : Monoid) :
    ∀ x : M.carrier, (∀ y : M.carrier, M.mul x y = y ∧ M.mul y x = y) → x = M.e
```

定理证**一次**；两个实例 `NatAddMonoid`（+，0）与 `NatMulMonoid`
（×，1）各自得到 `example`——**Φ⁺ 与 Φ✱ 的运输在 Lean 里的日
常名字就是实例化**。第二层是语构镜像：翻译 ν 在公式 AST 上逐
构造子爬行（`evalT`），MON 三公理的像在目标中的有效性写成
`obligationsHold`，两个目标的义务由 Nat 引理**证明级清偿**：

```lean
theorem plusObligations : obligationsHold { op := (· + ·), unit := 0, ... }
theorem mulObligations  : obligationsHold { op := (· * ·), unit := 1, ... }
```

第三层是负例——GRP 到 (ℕ,1,×) 的逆元公理像**不成立**，机器
把见证 2 揪出来：

```lean
example : ¬ (∀ x : Nat, ∃ y : Nat, y * x = 1 ∧ x * y = 1) := by
  intro h; obtain ⟨y, hy, _⟩ := h 2
  cases y with
  | zero => simp at hy
  | succ n => rw [Nat.succ_mul] at hy; omega
```

义务失败 ⟹ 非态射 ⟹ 定理不许运输——**态射定理的守门在机器
上是硬的**。

## 16.5 Prolog 镜像：表级义务与见证机

`ex16_morph.pl` 把同一套义务搬到运算表世界：目标 = 模 2 加法
表（xor，幺元 0）与合取表（and，幺元 1）。MON 三义务在两表
全过（ν⁺/ν✱ 都是态射）；**GRP 逆元像在 xor 表上成立、在 and
表上失败**——见证机给出无逆元元素恰为 `{0}`：

```prolog
chk(3, 'Ψ⁺：GRP 逆元像在 xor 表上成立（态射）').
chk(4, 'Ψ✱：GRP 逆元像在 and 表上失败（非态射）').
chk(5, '见证机：and 表上无逆元的元素恰是 0').
```

与 Lean 的见证 2 呼应（两个世界选了不同的具体目标），同一句
「逆元像失败 ⟹ 非态射」。运输面也各查一遍：唯一幺元定理的像
在两表上成立（幂元恰为各自幺元）。

## 16.6 忠实态射、运输与理论图

三个收尾概念：**忠实态射**（13.3.4：源可满足 ⟺ 目标可满足
——Ψ′✱ 对 {r≠0} 就是忠实的：子结构里有解当且仅当全结构里有解，
「局部求解 ⟺ 全局求解」的规格学价值）；**运输**（13.4：翻译
延伸到定义与定理包——16.1 的 X⁺/X✱ 就是定理运输，定义运输
还要翻译「定义行为」本身）；**理论图与发展图**（13.5：节点
升级为理论+发展两层，realm 图再抽象一层；库的架构学）。13.6
给出图的**组合子**（sum、translation-composition、renaming
等）——理论图的「构件学」，通往 MMT 的正规化。

> **坑位速记**
> ① `interval_cases` 是 Mathlib 的——standalone core 里用
>   `cases y` + `Nat.succ_mul` + `omega` 三件套；
> ② `holds` 的等式臂必须显式用模式变量 ρ（写成 `_` 会让
>   evalT 的赋值留 metavariable，整条定理报 kernel has
>   metavariables）；
> ③ 多重合取目标用 `refine ⟨fun v w z => …, fun v => …, …⟩`
>   显式分票——`constructor <;> intro v` 会在剩余合取上卡壳；
> ④ `simp [evalT, holds]` 展开到裸算术后不会自动收尾——把
>   `Nat.add_assoc` 等目标引理一并喂给 simp；
> ⑤ Prolog 求见证用「双重否定搜元素」：`\+ (member(X,域),
>   \+ 有逆(X))` 的失败翻转给出全部反例。
