## 44.1 纤维序列与长正合列（书 8.4）

一切定理群的发动机。给定 f : A → B 与 b : B，**纤维**
fib_{f,b} := Σ(a:A). f a = b 装配出无限下行的序列：

```text
⋯ → Ω²(fib) → Ω²(A) → Ω²(B) → Ω(fib) → Ω(A) → Ω(B) → fib → A → B
```

关键引理（8.4.1/8.4.2）：**Ω(B) 到纤维有「连移」**（loop 的
提升），且轮转后回到同层——于是每一步取纤维、取环路交替
下行，各截断层上得到**长正合列**（对 n-截断逐层正合）。机器
原型（cubical 文件）：transport 在族 fib f 上的搬运是「端点
族公式」（36 章 transport-path-fam 的同族镜像）——恒等映射
的纤维 Σ(x:A). x ≡ a 合同（39 章 3.11.8）⇒ 恒等是 −2-连通。
完整轮转等价与 37 章 4.2.6 同列（纤维合同性机械的回填件）。

## 44.2 悬浮的连通提升（书 8.2）

**定理 8.2.1**：n-连通的 f ⇒ Susp f 是 (n+1)-连通——悬浮
把「洞的维度」整体加一。最低层的读法（机器文件样本）：
**Susp ⊥ 是两点离散空间**（north/south 两极、无子午线）——
「-2-连通（空）悬浮成 -1-连通不连通」的边界样本；反之
**Susp 单点 = 区间**（两端一条线——两点但连通）。「悬浮
生产线」（42 章）与「连通度 +1」是同一台机器的几何面与
代数面。

## 44.3 低维球面（书 8.3）

**定理 8.3.1**：k < n ⇒ π_k(Sⁿ) = 1（平凡群）——低维球面
在高维「没有环」。证明是 8.2 + 8.4 的接力：Sⁿ = (n−1)-连通
（悬浮迭代），纤维序列把 π_k 压进低连通层。与 43 章合流：
**π_n(Sⁿ) = ℤ**（n ≥ 1）是 Freudenthal 的直接推论（8.6.11）。

## 44.4 Hopf 纤维：S³ → S²（书 8.5）

同伦论的皇冠宝石在类型论里的形态：**hopf : S³ → S²** 的
「全空间是 S³」。构造走 S¹-主丛路线：S² 上的 S¹-值「相位
函数」（用 S²-elim 在两极取平凡相位、子午线上翻转），其
Σ-配对全空间 Σ(x:S²). 相位 x ≃ S³。随后纤维序列 + 44.3
给出 **π₂(S²) = ℤ**、**π₃(S³) = ℤ** 的第一非平凡高同伦群
（经典拓扑的百年难题在类型论里是「两页半」——书 8.5 的
完整推导）。机器面：陈述级（完整版是 cubical 库 Hopf 模块
的工程量——本指南的诚实边界）。

## 44.5 Freudenthal 悬浮定理（书 8.6）

> **8.6.11（主定理）**：n-连通的类型 X ⇒ ‖Susp X‖ₙ ≃
> ‖X‖ₙ（截断同构）——悬浮在 n 层以下「不改变形状」。

推论链：π_n(Sⁿ) = ℤ、π_{k<n}(Sⁿ) = 1（与 44.3 会师）。
证明的骨架（书 8.6 的四页）：**encode-decode 再上岗**——
code 直接定义在 Susp 的「环路」上，解码由悬浮的 W-式归纳
驱动；关键的「码空间足够小」由连通性保证。43 章 8.9 的一般
陈述正是从这条证明里提炼的模板。

## 44.6 van Kampen 定理（书 8.7）

**pushout 的 π₁ 融合**：X = A ∪_C B（pushout）⇒ π₁(X) 由
π₁(A)、π₁(B) 与 C 的迁移**融合**（pushout of groups——群的
余积模掉 C 的像）。书 8.7 的证明是全书最长战役之一（HIT +
encode-decode + 44.2），结论对胞腔复形（6.6）的 π₁ 计算
立竿见影：一维 CW-复形的 π₁ 是自由群。与 16 章（群论的
四个变换视图）互读：那里群在集合上变换，这里群本身被
pushout 造出来。

## 44.7 Whitehead 定理（书 8.8）

经典代数拓扑的 Whitehead：弱等价（各 πₙ 同构）⇒ 同伦等价。
**在类型论里它几乎免费**（8.8.1）：f 是等价 ⟺ f 逐点
(−1)-连通（纤维 mere inhabited）——「弱等价」与「等价」的
分层在 HoTT 里被 39 章的截断语言重写。反方向（8.8.2 的
Whitehead 原理：所有 π 同构 ⇒ 等价）对**任意类型**不成立
（需要 n-截断版本）——书用 Hopf + Freudenthal 构造反例：
**类型论的白噪声**——单纯集合论的直觉在高维类型必须校准。
与 34 章（四家对照的「等价」文化）遥相呼应。

## 44.8 方法论合流：encode-decode 的一般式（书 8.9）

43.5b 已给出四步曲模板。本章五件主定理的证明全部是它的
变奏：

| 定理 | code 的化身 |
|---|---|
| π₁(S¹) = ℤ | ℤ 的旗帜（43 章） |
| π_k<n(Sⁿ) = 1 | 单点（平凡码） |
| Freudenthal | ‖X‖ₙ 的自守 |
| van Kampen | 融合群的词归约 |
| Hopf | S¹-相位 |

**为什么它总能工作**：code 是「可计算的替身」（有归纳原理
的离散对象），dec 把「环路空间的拓扑」翻译成「码的代数」
——Brown 代表性定理的类型论版。38 章的「泛等三读法」在此
补全第四读：**归纳读法**（code 的归纳原理承载一切计算）。
