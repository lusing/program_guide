## 5.1 对应表：一个系统的两套词汇

把 04 章的 λ→ 类型规则和直觉主义命题逻辑（蕴涵片段）的自然演绎
并排放着，逐条比对：

| λ→ / 类型 | 逻辑 |
|---|---|
| 类型 `A → B` | 公式 `A ⊃ B`（蕴涵） |
| 项 `M : A → B` | 推导「A 蕴 B」 |
| 变量 `x : A`（假设） | 未消化的前提 |
| 抽象 `λx. M` | →引入（蕴涵引入规则） |
| 应用 `M N` | →消去 = **modus ponens** |
| 闭项 `M : A` | 无前提的推导（定理 A） |
| β-归约 | 消除 **cut**（Prawitz：正规化 = 切消） |
| 基类型 α | 原子命题 |

**Curry–Howard 对应**（名字归 Curry 1934/1958 与 Howard 1969）说的
就是：这两张规则表是**同一张表**。区别只在读法。

于是四件事自动成立：

1. **演绎定理是构造子**：`Γ, x:A ⊢ M : B` 转成 `Γ ⊢ λx.M : A → B`
   ——不是元定理，是语构里的一行。三个示例文件都直接演示了
   「转换函数就是 abs/lam」。
2. **组合子是公理**：`K : a → b → a` 与 `S : (a→b→c)→(a→b)→a→c`
   正是 Hilbert 式蕴涵逻辑的两条公理；应用是唯一推理规则。
   Hilbert 系统与自然演绎的等价，翻译层就是 `S`/`K` 的组合
   （经典恒等式 `S K K = I` 在 02 章已被无类型 normalizer 机器验证）。
3. **证明检查 = 类型检查**：证明助手的内核只做一件事——检查
   `M : A`。写证明就是写项。
4. **规范化 = 切消**：把证明里的「中间公式」全消掉，得到正规证明；
   λ 侧就是 β-范式。这是第 36 章一致性的原料。

## 5.2 居留性：公式里有没有证明

「类型 A 有居留项吗」=「公式 A 可证吗」。对蕴涵片段这个问题
**可判定**（Kripke 1963/汪 1959 的决策程序；Hindley 第 8 章给出
搜索策略）。Lean 文件实现了 Hindley 式搜索的直白版本：

```lean
def searchLE (Γ : List Fm) (N : Nat) (T : Fm) : List Tm
```

对 β-正规 **η-长式** 做预算有界枚举——η-长式是关键技巧：任何
居留项都能 η-展开成「箭头目标必为 λ、原子目标必为变量脊」的
规范形态，于是搜索空间分成互斥的两类分支，每类都有限
（给定预算）。机器实测：

| 公式 | 居留项数（预算内） | 判断 |
|---|---|---|
| `a → a` | 1（`λx.x`） | 可证 |
| `a → b → a`（K） | 1 | 可证 |
| `a → a → a` | 2（`λλx` 与 `λλy`） | 可证，且证明恰两个 |
| `(a→b→c)→(a→b)→a→c`（S） | 1（S 自己） | 可证 |
| `((a→b)→a)→a`（Peirce） | **0** | **直觉主义不可证** |
| `(¬a → a) → a` | **0** | 不可证（需双重否定消去） |

Peirce 律与排中律等价（经典逻辑的标志），直觉主义里没有证明——
搜索到预算 8 仍空。这不是「没搜到」：蕴涵逻辑的正规化定理保证
η-长 β-正规式覆盖一切居留项，搜索空 = 真的没有。

## 5.3 经典升级：公理入账

同一个 Peirce 公式，加上经典公理立刻可证。三家的「公理记账」
机制在此同台：

```lean
theorem peirce_classical (a b : Prop) : (((a → b) → a) → a) := by
  intro h
  by_cases ha : a
  · exact ha
  · exact h (fun xa => absurd xa ha)
#print axioms peirce_classical
-- 'peirce_classical' depends on axioms: [propext, Classical.choice, Quot.sound]
```

```coq
(* Coq：Require Import Classical 后 destruct (classic a) *)
Print Assumptions peirce.    (* 依赖 classic *)
Print Assumptions I.         (* Closed under the global context *)
```

```agda
nnem : (P : Set) → ¬ (¬ (P ⊎ ¬ P))
nnem P h = h (inj₂ (λ p → h (inj₁ p)))
```

Agda 那一行值得盯着看三十秒：**排中律的双重否定在直觉主义里
可证**。证明把 `¬(P ∨ ¬P)` 既当「¬P 成立」的证据（喂 `inj₂`），
又在其反面 `P` 出现时当矛盾源（喂 `inj₁`）——一个假设两用，
闭环成立。直觉主义与经典的真实差距只在「去掉 ¬¬」这一步，
而这一步对**可判定的 P** 是免费的——这就是为什么 Agda 里
`Dec P` 类型能安全地充当经典排中（可判定即排中）。

## 5.4 「同构」的精确表述（Hindley 6B）

5.1 的对应表说「两张规则表是同一张表」。严格化这个问题要分
**三层**（Hindley 6B5.1 的框架）：

1. **可证公式 ↔ 封闭项的类型**；
2. **证明 ↔ 封闭 TA_λ-推导**；
3. **推导 ↔ 自然演绎推导**。

映射 (·)ᴸ 的定义（6B1）：把 TA_λ-推导里的**项剥掉、只留类型**——
变量的假设行 `x : τ` 变成裸公式 τ；消去/引入规则的树形原样保留，
(→I) 的释放位置跟随项中自由变量的出现位置。反方向 (·)^Λ（6B4）
要**造项**：先「尽量异名」（每个假设发一个新变量），释放时再
「按需同名」（k 个被释放的同型假设共用一个 x）。

**第三层不是双射——这是全章最重要的警告（6B3）**。取

```text
A₃ : x:a→a→c, y:a, z:a ⊢ x y z : c        A₄ : x:a→a→c, y:a ⊢ x y y : c
```

两个 TA_λ-推导不同（项不同、假设集不同），但剥掉项后**逻辑树
完全相同**（`(a→a→c)` 对 `a` 用两次 (→E)）。一般的规律：把 A₃
的同型变量 y、z 改名成同一个 v，逻辑树不变。(·)ᴸ 非单射，所以
**没有**双向逆。能挽回的是一套「半可逆」结构：

> **6B5（逻辑→λ 引理）**：(A^Λ)ᴸ = A——先造项再剥掉，回到原
> 推导；且造出来的项**每个自由变量恰出现一次**（「最疏散」
> 代表元）。
> **6B6**：(Aᴸ)^Λ 与 A 至多相差「同型变量的黏并」。
> **6B7（Curry–Howard 定理）**：第 1、2 层是**真正的双射**：
> (i) 直觉主义蕴涵逻辑的可证公式恰是封闭项的类型；(ii)
> β₁,…,βₙ ⊢ τ 可证 ⟺ 存在 M 与互异 xᵢ 使 x₁:β₁,…,xₙ:βₙ ⊢ M:τ；
> (iii) 证明层面 (·)ᴸ 与 (·)^Λ 互逆（模 α）。

一句话总结：**「对应」在公式与证明两层是同构，在推导层是
「有典范代表元（最疏散项）的等价类对应」**。本章开头表格里
每一行的合法性由此立据；而 6B7.2 给出可判定性的逻辑面：

> 公式 τ 可证 ⟺ 存在封闭 M 使 ⊢ M : τ。

——这正是 5.2 居留项搜索能当「证明搜索」用的形式化理由。

## 5.5 Curry 式与 Church 式在此汇合

05 章的指派系统（Curry 式）与本章的对应表合起来读：

> **M 可指派类型 A ⟺ M 是公式 A 的「证明草稿」**；
> **A 有居留项 ⟺ A 直觉主义可证**；
> **主类型算法 ⟺ 最一般证明骨架的提取**。

这也解释了 05 章的「主体扩张失败」在逻辑侧的读法：β-展开对应
引入一个 cut，而 cut 引入无用的（甚至不可指派的）中间公式——
切消（=归约）永远安全，反向不一定。

## 5.6 蕴涵之外：完整的 Curry–Howard

把余下的联结词补全，对应表成为整个直觉主义逻辑：

| 类型构造 | 逻辑联结词 | 引入/消去 |
|---|---|---|
| `A × B` | 合取 ∧ | 组对 / 投影 |
| `A + B` | 析取 ∨ | 注入 / 分情况 |
| `⊥`（空类型） | 假 | 无引入 / 荒谬模式 |
| `Σ(x:A). B(x)` | 存在量词 ∃ | 见证对 / 拆包 |
| `Π(x:A). B(x)` | 全称量词 ∀ | 抽象 / 特化 |
| 相等类型 `a = b` | 命题相等 | refl / J（24 章） |

依赖类型（第 19 章起）正是把整张表做成**一套语法**的那一步。
届时「命题」与「类型」、「证明」与「程序」将不再是两个视角，
而是同一个语构——Martin-Löf 类型论。

> **坑位速记**
> ① Coq 的 `Theorem/Lemma` **不接受 `:= term` 直接定义**（语法
> 错误），要 term 式就 `Definition ... := ...`，或 `Proof. exact ...`
> ——且注意 `forall a, a -> a` 的居留项是**双层** λ：`fun a x => x`；
> ② Lean 里 `/-- doc -/` 后必须跟声明——跟 `#eval` 会语法错，
> 普通注释用 `/- -/`；
> ③ 跨行 `|>.length` 链在 example 里解析不稳，`.length` 直接
> 写在括号内；
> ④ mutual 递归的终止测度可以用**字典序对**（`termination_by
> (N, 0)` vs `(N, len+1)`），但先把「冒号前参数不参与模式匹配」
> 修掉（本章 spineAll 第三次踩）；
> ⑤ 居留项搜索的预算口径（λ/槽分别计费）是**宽松上界**：S 的
> 最小真实代价是 6（3λ+3app），本实现的口径要到 8 才搜到——
> 断言用机器口径，不用理论口径；
> ⑥ `S K K = I` 在 Church 式/Agda 隐式求解下不可直接表达
> （两个 K 要不同实例）——多态的表达力问题，04/24 章正反两面
> 各演示过一次。
