# 14 证明系统 A：公理、规则与完备性

> 对应读本：Farmer《Simple Type Theory》第 8 章（证明系统、节俭
> 模型、完备性）+ 附录 A/B/C（元定理、可靠性、Henkin 构造）。
> 代码：`examples/14_proof/`——**Prolog 主场**（公理模式即合一的
> 证明检查器，命题 A.3 的三步原证机器版）；**Lean 对照**（同一
> 标本双机互证 + 每步公式的语义有效性 + MP 保有效性引理）。

12 章给了语义（⊨），13 章给了语构世界里的定义性纪律。本章补上
第三条腿：**证明系统 A**——一组合式的公理与规则，使得「可证」
（⊢）恰好追上「有效」（⊨）。它以 Andrews 命名（A 的 Q0 是其
直系血统），是 Farmer 全书的证明论支柱。

## 14.1 从语义到证明系统：为什么、凭什么

语义有效性（所有广义模型里为真）是个**全称量词压在模型宇宙上**
的概念——没有机器能直接核查。证明系统把「真」换成「可推导」：
有限、可机械检查。设计自由度很大，Farmer 选了 Andrews 的路线：
**极少的规则 + 承担重量的公理模式**。Q0 只有一条推理规则（等式
代换，MP 是导出规则）；A 因为要直接利用定义性公理（A5 族），
把 MP 提升为基本规则、把等式代换换成**准等代换 R2**（Remark
8.5）——13 章的 ≃ 就是在这里进入证明论的。

## 14.2 公理表 A1–A7

七组公理，每组都可以在 12–13 章的机器里找到语义化身：

| 公理 | 内容 | 机器面 |
|---|---|---|
| A1 真值 | `(g T ∧ g F) ⇔ ∀x:o. g x` | 12 章 D_o = {f,t} 的语构版；命题逻辑全靠它（App A.4 重言定理） |
| A2 Leibniz | `x = y ⇒ (h x ⇔ h y)` | 等式替换的种子 |
| A3 外延 | `f = g ⇔ ∀x. f x ≃ g x` | ≃ 进外延性——部分函数世界的函数相等 |
| A4 β-归约 | `A↓ ⇒ (λx.B)A ≃ B[x:=A]`（自由换入） | 13 章双反例的正面陈述 |
| A5 定义性 | 13 条：原子↓、(A=B)↓、(A=B)⇒A↓、λ↓… | TATU 三原则的公理化 |
| A6 确定描述 | `∃!x.A ⇒ (Ix.A) ∈ {x|A}`；否则 ↑ | V6 的公理版 |
| A7 序对 | `(x,y)↓`、fst/snd、单射性 | V7 + 12 章积型 |

## 14.3 Prolog 证明检查器：模式即合一

`ex14_proof.pl` 的核心想法一句话讲完：**「检查 F 是不是某公理
的实例」=「拿 F 去与模式子句合一」**——

```prolog
ax(a5_1, dn(tm(var(_)))).                        % A5.1：(x:α)↓
ax(a4, imp(dn(A), quasi(tm(app(tm(lam(B)), A)), B))) :- free_for_ok(A, B).
```

Prolog 的子句头本来就是带洞的公式，合一就是实例检查。规则侧：
R1 是两个 `nth1` 查步号加一次形状匹配；R2 是**单次出现替换**——
在 de Bruijn 世界里它有一段隐藏的纪律：

```prolog
sub_rep(A, B, C, Bshift, D) :-
    shiftt(A, D, 0, AS), C == AS, !, shiftt(B, D, 0, Bshift).
```

深度 D 下的出现要与「模式 A 平移 D 位」比较，替换进去的也是
「B 平移 D 位」——**浅处的模式自动配不上深处的同形项**。这
正是 R2 的守卫条件（A.2：绑定器第一参数不可替换；Γ 非空时
绑定变量不得自由出现在前提里）的 de Bruijn 化身。13 章讲过的
捕获攻击，在检查器里连「出现」都找不到：

```prolog
chk(8, 'R2 守卫：λ 体深度 +1 后，浅处项匹配不到深处的同形项').
```

**标本：命题 A.3（⊢ A ≃ A）**——书 217 页的三行原证，一步不
少地翻译成证明数据：

```prolog
proof_a3([
  step(dn(tm(var(0))),                    ax(a5_1)),   % (1) x↓
  step(imp(dn(tm(var(0))),                % (2) A4 实例：x↓ ⇒ (λx.x)(x) ≃ x
       quasi(tm(app(tm(lam(tm(var(0)))), tm(var(0)))), tm(var(0)))), ax(a4)),
  step(quasi(...appIx...),                mp(1, 2)),   % (3) R1
  step(quasi(tm(var(0)), tm(var(0))),     r2(3, 3))    % (4) R2：换掉一处出现
]).
```

第 (4) 步是全部巧思所在：拿 (3) 自己当 R2 的**两个前提**——
准等式 (3) 说 `M ≃ N`，把 (3) 里 M 的那一次出现换成 N，得到
`N ≃ N`，即 `x ≃ x`。**一个公式自举出自身的自反性**。检查器
放行（`chk(5)`），伪证明三条全拒：冒充公理编号、MP 前提不是
蕴涵、R2 目标写错。

## 14.4 Lean 对照：双机互证与语义抽查

`ex14_proof.lean` 实现同构的检查器（公理匹配器 `axInst`、R1/R2、
绝对步号检索），同一标本 `checkProof proofA3 = true` 与 Prolog
侧互证——两个独立实现的检查器对同一证明数据同时放行。此外
Lean 侧多走一步**语义抽查**：标本四步公式在 2 元模型的双指派
下全部有效——

```lean
example : valid s1 = true := by decide
example : valid s2 = true := by decide
example : valid s3 = true := by decide
example : valid s4 = true := by decide
theorem mp_preserves (φ) (p q) ... : evalF φ q = true
```

每步都有效 + MP 保有效性：**可靠性定理在标本上的实证面**。
（完整的可靠性是附录 B 对全部公理与规则的归纳——形状与本
实验室完全同构。）

## 14.5 元定理层：从公理到可用的推理

附录 A 是一座桥：公理表那么瘦，日常推理凭什么够用？——靠元
定理把常用推理**导出**成可复用规则：R1′/R2′（引理 A.1/A.2，
把规则变成「可插在证明中间的引理引用」）、准等式规则九条
（A.4：对称、传递、应用两端、序对两端……全部由 A.3 + R2′ 一
击导出）、全称例示（A.14，13 章守卫版 UI 的证明）、α-换名
（A.2.x）、代换规则（A.3.x）、**重言定理**（A.4.x：从 A1 出发
把整个命题逻辑装进来）、**演绎定理**（A.50：Γ∪{A} ⊢ B ⟹
Γ ⊢ A⇒B——条件推理合法化）。这一层对应 Andrews Q0 的 §52，
是「逻辑系统可用性」的工程学。本指南 09–11 章玩过的 D-规则
搜索（Hindley 7D）在其上还能再叠一层：**A + D-完全性 = 主类
型算法**——两条传统在自动推理的祖师爷（UNIVAC 1, 1957）会师。

## 14.6 节俭模型与完备性：模型动物园封顶

第 8 章的后半是全景拼图的最后几块（全书证明在附录 B/C）：

> **节俭广义模型**（frugal）：∥M∥ ≤ ∥L∥——每个域都不超过
> 语言本身的基数。可数语言的节俭模型是可数的。
> **Henkin 定理**（8.11 = 附录 C.3）：A 中一致的句子集有节俭
> 广义模型。
> **可证性 = 有效性**（8.12）：Γ ⊢A A ⟺ Γ ⊨ A ⟺ 每个节俭
> 模型都是 Γ∪{A} 的模型。于是 A **可靠且完备**（8.13），
> Gödel 完备定理（8.14）、紧致性（8.16）一并落地。

模型动物园的包含图（图 8.1）至此闭合：**有限 ⊆ 节俭 ⊆ 广义**；
**节俭无穷模型必非标准**（8.10：可数域上 D_{α→o} 塞不下全体
子集——Cantor）；有限广义模型都是标准模型（12 章定理 5.9）。
两个漂亮的收尾：**有限性不可刻画**（8.17——没有句子能恰好
挑出有限模型，紧致性三行反证）；**标准语义不可完备**（8.2，
证明在 15 章——PA 标准范畴 + 本质不完备合击）。

> **坑位速记**
> ① Lean 冒号前参数不参与模式匹配——`def axInst (s : Nat) :
>   Fm → Bool | 1, ...` 编译报 OfNat Fm 1；改 `def axInst :
>   Nat → Fm → Bool`。本仓库第五次踩（04/05/08/12 章后）；
> ② Lean 公式臂内的**多关注点 match on (Option, Option)** 内核
>   不归约（#eval 对、rfl/decide 假）——拆成 `qcombine` 辅助
>   函数即绿；同文件的 `List.lookup` 也要换手写 `lookupV`；
> ③ `simp` 里写没用的参数会出 warning——build 通道 warning
>   即 FAIL，定理收尾用 `simpa only [...] using h2`；
> ④ build.ps1 的 `-File` 过滤用 `-like`，正斜杠路径匹配不到
>   反斜杠 FullName——传 `examples\14_proof\ex14_proof.lean`；
> ⑤ Prolog 证明检查器的步号引用要**绝对编号**（整张证明表索
>   引），用「当前步之前的列表」当索引域会把 mp(1,2) 指错位。
