## 27.1 表达式与相关度：判断之前的语法层

Nordström 第 3 章不直接谈类型，先造一层**一般的表达式理论**
——它不局限于类型论，而是「数学与计算机科学中表达式的一般
理论」（Martin-Löf 1981 年 Brouwer 研讨会首次发表、1983 年
Siena 改进）。四种表达式形成运算：

> **作用**（application）`e(e₁,…,eₙ)`：把 n 元算子作用于
> 实参——`+(y, sin(y))`；
> **抽象**（abstraction）`(x)e`：把 e 中 x 的自由出现看作
> 空位——被积式 `y+sin(y)` 抽象成 `□+sin(□)`；
> **组合**（combination）⟨e₁,…,eₙ⟩：多元组的语法壳；
> **选取**（selection）`e.i`：从组合里取第 i 支。

每种**常元**带一个**相关度（arity）**——它吃几个 0 阶参数、
几个高阶（函数）参数。比如 `apply` 的相关度是 `0 0 → 0`
（两个 0 阶参数：一个函数、一个实参），`Π` 的相关度是
`0 (0→0) → 0`（一个 0 阶集合加一个集合族）。附录 A 把全书
每个常元的相关度列成总表——**相关度就是无类型 λ 演算世界里
的「最简类型系统**：它只管语法拼装合法，不管语义。

一个贯穿全书的区分在这里立下：**语法函数 vs 函数元素**。
前者是「带空位的表达式」（抽象），后者是笛氏积 Π(A,B) 的
居留项（29 章）。混淆两者时，书用「抽象」指语法概念、
「函数」指 Π 的元素。Agda 件里 `λ n → n + 1` 这一个记号
身兼两职——这是现代语法糖把两层压成一层的结果。

```agda
-- 组合子与选取子的相关度直觉（语法层四种运算的日常形态）
kcomb : (A B : Set) → A → B → A      -- K：丢第二支
kcomb A B a b = a
procomb : (A B : Set) → A → B → A × B  -- 组合：多元组壳
procomb A B a b = a , b               -- ⟨a,b⟩ 的 Agda 拼法
sel1 : (A B : Set) → A × B → A       -- 选取：e.1 的 Agda 拼法
sel1 A B p = proj₁ p
```

## 27.2 四种判断与其语义：值与典则元

第 4 章把一切放进**判断（judgment）**：

```text
A type            （A 是一个类型/集合）
A ≡ B             （A 与 B 定义相等）
a : A             （a 是 A 的居留项）
a ≡ b : A         （A 中 a 与 b 定义相等）
```

Nordström 给每种判断一个**语义解释**，这是全书方法论的地基
——规则不是自明的，每条都要「使自己相信」其正确性。核心
概念是**值**与**典则元（canonical element）**：

> 认识 `a : A`，就是认识 **a 的值**——把 a 计算到底（lazy：
> 只算最外层）之后，得到 A 的一个**典则元**。
> 认识 `a ≡ b : A`，就是认识 a 与 b 的值是 A 的**相同的**
> 典则元。

「典则」= 处于构造子形式：`succ (succ zero)` 是 ℕ 的典则元，
`2 + 2` 不是（它要先算一步才露出 `succ` 的头）。这一解释把
**计算**（求值）与**判断**（类型检查）绑在一起——判断的
正确性论证总是同一个套路：*先求值、再对照典则元形状*。
本章三家件里直接演示：

```agda
one : ℕ
one = suc zero        -- 典则元：构造子形式
two : ℕ
two = one + one       -- 非典则：+ 的递归在第一参数，1+1 未折叠
two-is-two : two ≡ 2
two-is-two = refl     -- refl 能过 ⟺ 定义相等 ⟺ 两者值相同
```

「定义相等」（definitional equality / convertibility）因此
**不可证明、只可判定**——沿定义展开（β/δ/ι）比出相同即得。
三家机器面：Coq `reflexivity`、Lean `rfl`、Agda `refl` 能过
= 定义相等。界碑：`0 + n ≡ n` 在 Coq/Agda 是定义（加法递归
在第一参数），`n + 0 = n` 要归纳；Lean 正相反——01 章的
方向学在这里兑现。

## 27.3 一般规则：判断层的等式公理

第 5 章的一般规则对所有集合成立——它们是判断等式这个
「等价关系 + 替换外延」结构的公理化：

```text
前提      Γ, x:A ⊢ x : A          ——假设即上下文条目
自反      a : A ⊢ a = a ∈ A
对称      a = b ⊢ b = a
传递      a = b, b = c ⊢ a = c
类型等同  a : A, A = B ⊢ a : B     ——相等类型间搬运居留项
替换      a = b, c(x):C(x) ⊢ c(a) = c(b)   ——同余的总纲
```

书里另有一组「**消去 2 类**」规则（形如「分部相等则组合
相等」，如 case(a,b⃗)=case(a′,b⃗′)）——第 6 章起明确约定
**不再逐一列出**：单型表述（35 章）里它们由类型层次上的
对象替代自动得到，多型表述里按模式理解即可。

三家对应物（件里逐条可跑）：

```lean
theorem symRule (a b : Nat) (h : a = b) : b = a := h.symm
theorem substRule (a b : Nat) (h : a = b) (P : Nat → Prop) (pa : P a) : P b := h ▸ pa
```
```coq
Theorem subst_rule : forall a b, a = b -> forall P, P a -> P b.
Proof. intros a b H P Ha. apply (eq_ind a P Ha b H). Qed.
```
```agda
subst-rule : ∀ {A : Set} (P : A → Set) {a b} → a ≡ b → P a → P b
subst-rule P refl pa = pa
```

注意 Agda 版的形态：**对 refl 做模式匹配就是应用 J 规则**——
第 29 章把这句话展开成一门手工课。

## 27.4 计算的意义：选取子的两步法

附录 B 给出全书求值规则的形式描述——**lazy evaluation**。
构造子形式已被求值（`succ(d)`、`⟨c,d⟩`、`λ(c)`、`sup(c,d)`
都是值）；计算发生在**选取子**（非典则常元）上，且全部遵守
同一个两步协议：

```text
case(a, b₁,…,bₙ)     1. 把 a 求值成典则形
                      2. 若值为 iₖ 则继续求 bₖ 的值
apply(a, b)           1. 把 a 求值成典则形（必呈 λ(c)）
                      2. 继续求 c(b) 的值
natrec(a, b, c)       1. 把 a 求值成典则形
                      2a. 若值为 0，求 b 的值
                      2b. 若值为 succ(d)，求 c(d, natrec(d,b,c)) 的值
```

「先求主参数、再按典则形状分派」——这是结构归纳原理的操作
面：**每个选取子都把自己的主参数当作归纳对象**。第 7 章
将以 funsplit 为例展示这个协议如何论证消去规则的正确性
（28.3 节）；36 章单型重铸时，每条「相等性声明」就是这里
的一条计算规则。

顺带把第 5 章起约定省略的「**消去 2 类**」规则说破：形如
「分部相等则整体相等」（case(a,b⃗)=case(a′,b⃗′)，当 a=a′
且逐 bₖ=bₖ′）的规则对每个集合都有一族——多型表述里按
模式理解、不再列出；单型表述（35 章）里它们由类型层次上
的对象替代**自动**得到。现代实现同样不打印它们——Coq/Lean
的「构造子单射 + 分支同余」都藏在内核的转换规则里。

（组合逻辑的血统也在相关度里：`apply(y,y)` 不违相关度——
y 是 0 阶变元、apply 是 00→0——但把 λx.apply(x,x) 放进
`{} → N` 的居留推导需要 31 章的自应用现场才见分晓。）

相关度的速查样例（书附录 A 选四行）：

| 常元 | 相关度 | 读法 |
|---|---|---|
| succ | 0 → 0 | 吃一个集合元素、产一个 |
| apply | 0 0 → 0 | 吃一个函数元素、一个实参 |
| Π | 0 (0→0) → 0 | 吃一个集合、一个集合族 |
| natrec | 0 0 (00→0) → 0 | 吃递归对象、基例、递归步 |

箭头的层数预告了引入/消去规则的前提层数——相关度是规则
形状的语法签名。

最后把第 4 章的假设判断语义留档：「Γ ⊢ J 的意义 =
对 Γ 的每个对象序列代入后 J 成立」——前提的合法性逐位检查
（35 章类型族同款）、判断的意义靠**代入解释**给出。这一
「判断=其全部实例」的读法在 62 章（LF 的意义理论之辩）将
以更强的形式回归——封闭实例语义「既弱于又强于」判断语义
的清算。

> **坑位速记**
> ① Lean `variable` 声明的假设若只在证明里用、不出现在语句，
>   泛化时被丢弃 → `h.symm` 变 unknown identifier——假设写进语句；
> ② Agda 顶层量词裸写 `∀ a b → ...` 会留未解元（a b 的类型是
>   meta）——量词要带类型 `∀ (a b : ℕ) → ...`；
> ③ Lean 核心已占 `Empty`/`Unit`——自定义要换名（Empty2 等）；
> ④ Coq 无构造子的归纳默认落 Prop，**不能消去到 Type**——
>   空类型声明成 `Set`（`: Set := .`）才能当爆炸原理用。
