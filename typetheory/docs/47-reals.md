# 47 实数：Dedekind、Cauchy 与全域数

> 对应读本：HoTT 书第 11 章全部（有理数域、**Dedekind 实数**、
> **Cauchy 实数**、两者比较、**区间紧性**、surreal 全域数）。
> 代码：`examples/47_reals/ex47_reals.lean`（Lean 对照：抽象
> 有序域 Q 的公理化账目、Cauchy 列/等价/商的骨架（Quot 的
> 26 章姊妹工程）、Dedekind 切割的四公理结构、加法相容性
> 定理）。

分析学的老家：实数。集合论里实数是 Dedekind 切割或 Cauchy
商（二选一然后证明一样）；HoTT 里这两条路线**分了家**——
Cauchy 实数是「可计算的实数」，Dedekind 实数是「理想的实数」，
经典数学靠排中把它们捏在一起。本章讲这场分家的机制，以及
类型论给分析学的一件厚礼：**区间紧性不需要选择公理**。

## 47.1 有理数（书 11.1）

基座：ℚ := ℤ × ℕ⁺ 的商（26 章整数商工程的第三服）——有序
域的公理化账目（机器件的 `Q/Qadd/Qlt` axiom 组）。分析学的
全部需要浓缩在 ℚ 的两条**不完备症状**：√2 不在（对角线）、
单调有理列可躲开自己的极限（0,1,0,1,… 的 ε 游击）。实数的
两条构造路线分别补这两条症状。

## 47.2 Dedekind 实数（书 11.2）

**切割**（cut）= 一对谓词（L, U : Q → Prop——子集即谓词的
第三次服役，25/46 章同款策略）加四公理：

```lean
structure Dedekind where
  L U : Cut Q
  Linh Uinh : ∃ q, L q / ∃ q, U q      -- 两边都有人
  Ldown : L q → r < q → L r            -- 左集向下闭
  disjoint : ¬ (L q ∧ U q)             -- 左右不交
  located : q < r → L q ∨ U r          -- 无洞（书 11.2.2）
```

Dedekind 的哲学：实数 = **切割位置的声明**——不构造任何「点」，
只说清界线两侧的居民。机器件的四公理结构即此；序/加/乘在
切割上逐公理装配（书 11.2 的三节推导——docs 地图）。
**Dedekind 的表达力**：∀ 切割存在 ⇒ 完备性强（超穷归纳的
论域），代价是元素**不可计算**（L 的成员资格可以不可判定
——39 章 mere prop 的「信息抹除」在此变现为分析学的表达力）。

## 47.3 Cauchy 实数（书 11.3）

**序列 + 收缩模**：机器件 `CSeq`（seq : Nat → Q + isCauchy
证据）；实数 = 序列的**商**（conv0 等价）：

```lean
def ℝC : Type := Quot (fun x y => conv0 x.seq y.seq)
theorem addSeq_compat (hx : conv0 x.seq x'.seq) (hy : …)
  : conv0 (addSeq x y).seq (addSeq x' y').seq := conv0_add hx hy
```

商提升的良定义性 = 相容性定理（Lean core 无 Quot.lift₂ 的
内置——26 章整数商有完整的三 lift 模板；本章骨架以相容定理
为正式陈述）。**Cauchy 的哲学**：实数 = 可执行的收敛程序
——每个实数自带算法（序列与模），分析学变成「程序的正确性
论证」。代价是完备性弱一档（47.4）。

## 47.4 两种实数的比较（书 11.4）——分家的机制

> **Cauchy ⊆ Dedekind 构造性恒真**（序列极限翻译成切割：
> L q := 序列终将超过 q）；**反向需要排中**。

反方向的障碍（书 11.4.1 的证明）：给定 Dedekind 切割，要在
无排中下「逼近」它——每个 n 找 2⁻ⁿ 精度的定位点——这需要
located 性质的**逐点判定**（L q ∨ ¬L q——LEM 的形状！39 章
LEM 的 mere prop 版恰好在这个口上收费）。于是：

| | Cauchy ℝ | Dedekind ℝ |
|---|---|---|
| 元素 | 收敛程序 | 切割声明 |
| 可计算性 | ✓（自带模） | ✗（谓词可不可判定） |
| 完备性 | Cauchy 完备 | Dedekind 完备（更强） |
| 与对方同构 | ⊆ 恒真 | = 需 LEM |

**这不是 bug 是分层**：两种实数各自忠于「实数」的一个直觉
（算法的/理念的），经典数学用排中把它们焊接，构造数学让
它们各守一方。与 39 章（LEM⇔DNE 的 mere prop 收费口）互读
——本章是那次收费的**最大单**。

## 47.5 区间紧性（书 11.5）——类型论的厚礼

> **Heine-Borel 的类型论版**：[0,1] 的**开覆盖的有限子覆盖**
> 的存在性——**不需要选择公理**（书 11.5.4 的构造版）。

经典拓扑的「紧性⇒选择」依赖（每个开集选点的选择函数）在
类型论里被**依赖类型的精化**消解：覆盖不是「集族的并」而是
**依赖函数**（每点带自己的邻域证据——Σ 的信息保留），有限
子覆盖由归纳构造直接产出。书 11.5 的完整证明是分析学在
HoTT 里最漂亮的展演——「同伦方法给古典定理减负」的代表作。
机器面：陈述级（完整版是 cubical/Coq 分析学模块的工程）。

## 47.6 全域数（书 11.6）——「所有数」的归纳定义

Surreal 数（Conway）：**No := σ (L, R : No 的子集, ∀l∈L r∈R. l < r)**
——「左右集都不空出对方的数」。它**同时包含**全部实数、
全部序数（46.3 握手）、无穷小与无穷大——「数的全域」。书
11.6 的开发：No 的归纳定义（W-型+尺寸限制的归纳递归——41
章 5.7 那块「同伦视角尚未正当化」的留白地恰在此处收租：
surreal 的严格类型论化是开放工程）、生日层级（每个数的
「诞生序数」）、与实数的包含链。**教学定位**：本章以地图
+ 核心定义呈现——它是「归纳定义的表达力尽头」的展品。

## 47.7 第五部分的收束：数学的三个面

46–47 两章合上 Part II（数学）的大门，也合上全书：

| 面 | 章节 | 数学内容 |
|---|---|---|
| 同伦论 | 43–44 | π₁(S¹)、Freudenthal、Hopf |
| 范畴论 | 45 | Yoneda、SIP、Rezk |
| 集合与分析 | 46–47 | Cantor、基数、V、实数、紧性 |

三张面孔共享一套底层机械（36–42 章）：路径、泛等、截断、
HIT、归纳原理。**HoTT 的赌注**：同一套语言同时做代数拓扑、
范畴论与分析学——本书 Part II 是这场赌注的验收单。

> **坑位速记**
> ① Lean axiom 组不能合并声明（`axiom A B : T` 的 B 类型
>   推断失败——逐条分开）；
> ② ℕ 记号在裸 lean 文件里被当 universe 变量——**用 Nat**；
> ③ 依赖 axiom 的 def 要 `noncomputable`（Qadd 是 axiom ⇒
>   addSeq 代码生成失败）；
> ④ 「骨架样本」不能造矛盾结构（Dedekind 的空 U 不满足
>   Uinh）——占位结构也会被公理抓包，改 axiom 账目最诚实；
> ⑤ Quot 的双 lift 在 Lean core 无内置——相容性定理
>   （conv0_add 的形状）是「良定义」的正式载体。
