# 35 类型与单型集合 I：类型层

> 对应读本：Nordström 书第 19 章（类型——元变元问题、Set/El、
> 类型族、一般规则、前提、函数类型）。
> 代码：`examples/35_monotypes/ex35_monotypes.agda`——元变元
> 问题的形式化、Set 的开放性、假设判断↔函数类型翻译、类型层
> β/α/η 三规则、替代规则。

27–33 章读的是书的**多型集合论**（第一部分）：集合是原始概念，
`apply(f,a)` 两参数、类型信息在规则里。书第三部分换一套地基
——**类型（type）比集合更基本**，集合论被**表示**在类型论中。
这一换的动机、机制与收益，是 35–36 两章的内容；它们是 1986
年 Martin-Löf 框架理论的展开，也是 Agda/Coq/Lean 内核设计
的直系蓝图——读完这两章，「证明助手为什么长这样」有了出处。

## 35.1 元变元问题：为什么要类型层

书 19 章开篇的动机出人意料地**实际**。逻辑教科书里的推导
（Kleene《元数学导论》）从来不是完全形式的：

```text
x=y & x=z ⊢ x=y        （模式推导：A、B 是元变元）
```

把它读作 `A&B ⊢ A` 时，A、B 可以换成任何公式——但这已经是
**元层的约定**，不是形式系统内的推导。本书第一部分同样：
「设 A 为集合且 B(x) 为 A 上集合族」这类假设住在元语言里。
**类型层要做的就是把元变元搬进对象语言**——「X 是任意集合」
成为形式前提 `X : Set`，模式推导变成真推导。

Nuprl 的补救（用全域 U）被书明确指出不足：「X∈U 并没有真正
刻划假设 X 是一任意集合，因为 U 仅仅是小集合的集合且有固定的
归纳定义」——31 章的 U 是**闭**的世界（构造子个数固定），
而「任意集合」必须对**尚未定义**的集合开放。Agda 件里这个
对比一眼可见：

```agda
pattern-der : {A B : Set} → A × B → A    -- A、B 是形式化的元变元
pattern-der (a , b) = a

general-set : (X : Set) → Set             -- 「对任意集合 X」的构造
general-set X = X → X

general-family : (X : Set) (Y : X → Set) → Set   -- 「设 Y(x) 为
general-family X Y = (x : X) → Y x                 -- X 上集合族」
```

现代 Agda 的参数化模块、Coq 的 Section 变量、Lean 的
`variable`——全部是这套「形式化元变元」机制的后裔。

## 35.2 Set 与 El：开放的定义

类型层的核心公理两条：

```text
Set-形成    Set type                        （集合的类型）
El-形成     A : Set ⟹ El(A) type           （A 的元素的类型）
             A = B : Set ⟹ El(A) = El(B)
```

配缩写约定：`A set ≜ A : Set`、`a ∈ A ≜ a : El(A)`——第一
部分的集合判断全部成为类型层判断的缩写。

**Set 与 U 的区别是本节的灵魂**：认识集合 A 就是认识「A 的
典则元怎么形成、何时两个典则元相同」——这个解释是**完全开
放的**，「我们没有穷尽定义新集合的可能性」。而 U 的典则元是
一组**固定个数**成集运算的编码（31 章 14.2 甚至要为它重构
枚举才能陈述归纳原理）。一句话：**Set 是开放类型、U 是归纳
数据**。Agda 的 `Set` 正是前者——任何 `data` 声明都往里放、
`Set` 自己住在上一层（`Set : Set₁`——直谓塔把 31 章的分层
继承下来）；`El` 在 Agda 里退化为恒等（集合即类型），书里
的 El 记法是为「集合作为对象」的显式性保留的。

一个类型是一族对象加一个**可判定的等价关系**——「认识 A 为
类型就是认识：何为 A 的对象、两个对象何时相同」。等同性的
可判定性要求来自判断可判定性的总纲（47 章 UTT 的三特征之
一在此奠基）。

## 35.3 类型族与上下文

上下文 `x₁:A₁, x₂:A₂, …, xₙ:Aₙ` 的合法性逐位检查（每位
的 类型依赖于前面的**对象**代入）——27.3 节的语境纪律在
类型层重述。类型族 `A type[x₁:A₁,…]` 的解释是「对上下文的
每个对象序列代入后是类型」，并要求**外延性**：对象逐位相等
⟹ 代入后的类型相等。这是 35.6 替代规则的语义来源。

## 35.4 一般规则：等同与替代

类型层的判断等式规则组（自反/对称/传递/类型等同性）与
**替代四规则**：

```text
类型替代    C type[x:A], a:A ⟹ C[x:=a] type
对象替代    c:C[x:A], a:A ⟹ c[x:=a] : C[x:=a]
等同类型替代 B=C[x:A], a:A ⟹ B[x:=a]=C[x:=a]
等同对象替代 b=c:B[x:A], a:A ⟹ b[x:=a]=c[x:=a]
```

「判断层的同余对全部替代位置封闭」——Agda 件里对象替代与
类型替代各一个化身：

```agda
subst-obj : {A : Set} (C : A → Set) {a b : A} → a ≡ b → C a → C b
subst-ty  : {A : Set} (C : A → Set) {a b : A} → a ≡ b → C a ≡ C b
```

前者是 29 章的 transport（对象沿等式搬家）；后者是**类型沿
等式搬家**——多型第一部分里它藏在集合相等的外延性里，类型
层把它升为显式规则。

## 35.5 前提：C type 就能假设

前提规则是类型层最大的一步：

```text
前提    C type ⟹ x : C[x : C]
```

配 Set 公理，「X 为任意集合」终于形式化：

```text
Set type ⟹ X : Set [X : Set] ⟹ El(X) type ⟹ x : El(X) [X:Set, x:El(X)]
```

读作 `x ∈ X [X set, x ∈ X]`——第一部分的前提形状全部成为
类型层前提的特例。**从今往后「假设一个集合」与「假设一个
自然数」语法上再无区别**——这是 38 章（ADT 规格说明 Σ 链）
与 62 章（LF 的假设判断编码）的地基。

## 35.6 函数类型：β、α、η——判断层有 η！

类型层只引入一个构造：函数类型 `(x:A)B`（B 是 A 上的类型
族）。它的规则组值得整表读——**η 首次成为判断规则**：

```text
Fun-形成   A type, B type[x:A] ⟹ (x:A)B type
作用       c:(x:A)B, a:A ⟹ c(a):B[x:=a]
抽象       b:B[x:A] ⟹ (x)b:(x:A)B
β-规则     ((x)b)(a) = b[x:=a]:B[x:=a]
ξ-规则     b₁=b₂:B[x:A] ⟹ (x)b₁=(x)b₂:(x:A)B
α-规则     (x)b = (y)(b[x:=y])      （y 不自由出现于 b）
η-规则     (x)(c(x)) = c:(x:A)B     （x 不自由出现于 c）
```

**η 的三层地位**在此对齐：多型集合层（29 章）判断**没有**
η（它是 funsplit 可证的**命题**）；类型层（本章）判断**有**
η——函数运算 c 的「数学定义」身份要求外延（书引文献 [125]
第 170 页：LF 的函数运算同理有 η，62 章呼应）；现代 Agda/
Lean 的 defeq 含 η（refl/rfl 直接过）、Coq 不含。件里三
规则的机器面：

```agda
η-type : {A : Set} {B : A → Set} (c : (x : A) → B x)
        → (λ x → c x) ≡ c
η-type c = refl                        -- 类型层 η：判断等（Agda 吸收）

β-type : (b : (x : A) → B x) (a : A) → (λ x → b x) a ≡ b a
β-type b a = refl

α-type : (b : (x : A) → B x) → (λ x → b x) ≡ (λ y → b y)
α-type b = refl                        -- 换名是判断等价
```

函数类型与假设判断的**翻译互逆**（书 19.6 末例）是本节的
收官收获：

```text
a : A[x₁:A₁,…,xₙ:Aₙ]  ⟿  (x₁,…,xₙ)a : (x₁:A₁)…(xₙ:Aₙ)A
```

重复抽象（假设变 λ）与重复应用（λ 变假设）互逆——Agda 件
里 curry/uncurry 的翻译见证 `translate-iso` 一行 refl 收官。
**「上下文里的推导」与「封闭的函数项」是同一物的两副面孔**
——62 章 LF 的判断编码（⊢Γ 编码为 Γ⊢•）把这句话做成整个
框架的基石。

## 35.7 与 62 章 LF 的对读：判断编码的前奏

本章的类型层判断与 62 章 LF 的判断编码表几乎逐行对齐——
Nordström 的单型表述就是 LF 方案在「集合论专用元语言」里
的预演：

| 本章判断 | LF 判断（62 章表 6.1） |
|---|---|
| `Set type` | `Γ ⊢ Set : TYPE`（常量的类别声明） |
| `A : Set` | `Γ ⊢ A : el(Set)` |
| `El(A) type` | 由 el 的形成规则直接给出 |
| `a : El(A)`（缩写 a ∈ A） | `Γ ⊢ a : el(A)` |
| `(x:A)B type` | `(x:el(A))B` 类别的函数运算 |

差别在宗旨：本章是**造一个更大的类型论**（把集合论装进类型
层），LF 是**造一个装得下任何类型论的框架**（规则变常量）。
35–36 章的「引常量+声明等式」法则是两者的公共技术底座。

> **坑位速记**
> ① Agda 的 `where` 块里 `open import` **不达外层签名**——
>   需要在签名用的记号（× 与配对模式）必须顶部 import；
> ② 想给 Set 定义的「成员判断」造语法糖（如 `_∈_` 消除
>   Set）不可行——Set 不可被模式消除；书里的 El 缩写是
>   **记法约定**，不是可定义运算；
> ③ subst-ty 的目标形状是 `C a ≡ C b`（族沿等式搬**类型**），
>   写成 `(x : A) → C x ≡ C b` 会引入无关变元 x、refl 失败；
> ④ 元变元演示件的隐式参数 `{A B : Set}` 就是「模式推导的
>   形式化」——讲清这层对应比造任何新机制都重要。
