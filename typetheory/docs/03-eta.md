# 03 η、βη 与 λI：外延与受限

> 对应读本：Hindley《Basic Simple Type Theory》1C（η-与 βη-归约）、
> 1D（受限 λ-项）；深度材料见 Barendregt 1984 §15.1 与第 9 章。
> 代码：`examples/03_eta/`——Lean / Coq / Agda **三份同构实现**：
> η-步进器 + βη 两阶段规范化 + λI 谓词 + 消元/复制对照实测。

02 章把 η 一笔带过（「函数外延性」一句话）。本章把它做成一门
正经的小理论——η 自己的度量、自己的 Church–Rosser，以及它与 β
拼成 βη 之后那张漂亮的组合式证明图。随后跟着 Hindley 走进 1D：
Church 1941 年研究的其实是一个**受限**的 λ 演算（λI），那里
「K 组合子不可定义」有一个完全初等、却常被忽略的证明。

## 3.1 η-归约：定义与一个容易写错的 contractum

```text
λx. M x  →η  M        （条件：x ∉ FV(M)）
```

直觉 02 章说过：`M` 与「把参数原样转发给 M 的函数」在所有输入上
行为相同。条件 `x ∉ FV(M)` 不可省——`λx. x x` 里若把 `M = x`
「缩」出去就错了：`x` 是自己的参数，不是转发。

de Bruijn 表示下 η-redex 的形态是 `lam (app t (var 0))`，配一个
出现检查：**指标 0 不得在 t 中出现**。三份代码共用同一个
出现函数：

```lean
def occurs (k : Nat) : Term → Bool
  | var j => decide (j = k)
  | lam b => occurs (k + 1) b
  | app f a => occurs k f || occurs k a
```

（查询目标 k 进绑定器要 +1 补偿——与 02 章 subst 的 j+1 同款
深度账。）于是 η 单步：

```lean
def etaStep : Term → Option Term
  | lam (app t (var 0)) =>
      if occurs 0 t then (etaStep (app t (var 0))).map lam
      else some (shift (-1) 0 t)
  | lam b => (etaStep b).map lam
  | app f a => …   -- 与 β 的 step 同款：先函数位再参数位
```

**请注意 contractum 不是 `t`，而是 `shift (-1) 0 t`**。这是本章
第一个实测坑，值得盯着看：η 的条件只保证 0 不出现，但 t 里其余
自由指标**全体 ≥ 1**——它们都是被这个 λ 抬高过的。绑定器删掉后，
它们必须全体降 1。漏掉这次平移，`λx. f x` 会缩成「自由指标 1」
而不是「自由指标 0」，字面上把 f 认成了隔壁变量。β 的出口平移
（02 章 `shift (-1) 0`）在这里原样重演——区别只是入口无须代换。

机器实测（三份镜像同一批断言）：

```text
λx. f x        →η  f            -- etaStep (lam (app (var 1) (var 0))) = some (var 0)
λx. x x（ω）    η-nf            -- occurs 0 (var 0) = true，整个项不是 η-redex
```

## 3.2 η 的度量：每步恰减 2

β-归约可以永远不停（Ω），η 却**必然停**。Hindley 的度量 |M| 是
**变量出现次数**（1A2：`|x| = 1`，`|λx. M| = 1 + |M|`——绑定器
也算 x 的一次出现，`|M N| = |M| + |N|`）。于是 η-redex `λx. M x`
的度量是 `1 + |M| + 1 = |M| + 2`，contractum `M` 是 `|M|`——
**每收缩一步恰减 2**，任何 η-归约链的长度严格小于 `|P|/2`。
证明就这一行（1C2）。

这就是「η-family 有限」（1C3.1）的全部理由：从 P 出发 η 可达的
项组成有限集。对照 β 的 family（可以是无穷集，想想 Church 数的
无穷展开），η 是个 terminating 的、几乎无害的小系统。

代码里我们用结点数 `size`（λ/应用/变量各计 1）做另一套口径的
账——结点口径下 η 每步减 3，界同样成立。机器记账：

```lean
example : etaSteps 50 N2 = 2 := by rfl
example : size N2 = 7 := by rfl      -- 2 ≤ 7/2 = 3：账面成立
```

η 的 Church–Rosser 定理（1C4）「straightforward」——两个 η-redex
要么不相干（收缩互不影响），要么嵌套（`λx. (λy. M y) x` 缩外层
或缩内层，一步之后汇合）。真正的工作在下一节：η 与 β **混起来**
之后还能合流吗？

## 3.3 βη-合流：一张组合出来的证明图

βη-redex 就是「β-redex 或 η-redex」，βη-归约允许两种步任意穿插。
要证的定理（1C8）：

> 若 `M →βη* P` 且 `M →βη* Q`，则存在 T 使 `P →βη* T`、`Q →βη* T`。

Hindley 的证明是**组装**出来的，四个零件（每个都有独立的名字）：

1. **β-CR**（02 章 / 1B5）：β 自己合流。
2. **η-CR**（1C4）：η 自己合流（上节）。
3. **交换引理**（1C7）：`M →β* P` 且 `M →η* Q`，则存在 T 使
   `P →η* T` 且 `Q →β* T`——一步 β 与一步 η 的「菱形」能闭上，
   而且闭合时**η 只往 η 那边走、β 只往 β 那边走**。
4. **η-后置定理**（1C6）：任何混合归约 `M →βη* N` 都可以重排成
   **先全 β、后全 η**：存在 P 使 `M →β* P →η* N`。

四件组装：混合序列里每个 η 步用交换引理推到队尾。图 1C7a 画的
就是这个「斜菱形」。结论不止于 CR：

> **推论（1C9.3）**：一个 β-范式 N 的 η-family 里，恰好有一个
> βη-范式（把 N 缩 η 到头，即 `N*η`）。

「恰好一个」是 CR 的标准红利（范式唯一性），但这里的表述更细：
它说 η-family 是**以 βη-nf 为尖顶的一族**，族内互相 βη-等价。

### 机器样本：两条第一步就汇合

代码里放了一个浓缩样本 `N2 = λx. (λy. f y) x`（f 自由）：

```lean
def F  : Term := lam (app (var 1) (var 0))        -- λy. f y
def N2 : Term := lam (app (shift 1 0 F) (var 0))  -- λx. (λy. f y) x
```

它的两步归约故事（注意 `shift 1 0 F` 是把闭语境的 F 搬进新绑定器
的标准动作）：

```text
η 先行：N2 →η F        （整个 λx.(…)x 是 η-redex：x 不在内部出现）
β 先行：N2 →β F        （缩掉体内的 (λy. f y) x，得到同一个 F）
再一步：F  →η f
```

两条路的**第一步就汇合**——这正是交换引理菱形的最小实例：
η 步与 β 步在同一对邻居上交换，顺序无所谓。三份镜像断言：

```lean
example : etaStep N2 = some F := by rfl
example : step N2    = some F := by rfl
example : etaStep F  = some (var 0) := by rfl
```

## 3.4 范式策略：先 β 后 η（1C9.5）

有了后置定理，求 βη-范式的算法一目了然：

> **两阶段**：先做最左 β-归约到 β-范式 `M*β`；再对 `M*β` 做最左
> η-归约——由 1C2 链长 < `|M*β|/2`，立等可取。

```lean
def nfBetaEta (fuel : Nat) (t : Term) : Term := nfEta fuel (nfBeta fuel t)
```

支撑它的两条引理（1C9.2）值得一字不差地读懂：

- **(i)** η-收缩**不会制造新的 β-redex**。这是「先 β 后 η 不吃亏」
  的引擎：如果 η 会造 β-redex，后置的 η 阶段就得回头补 β。
  为什么不造？η-redex `λx. M x` 收缩后，M 顶上少了一层
  「等一个参数」的结构；原本在应用位上的邻居（若有）在收缩前
  就已构成 redex——η 只是让它们更靠外，不无中生有。
- **(ii)** `(M*β)*η = M*βη`：两阶段的结果就是 βη-范式。

再加一条关键的等价（1C9.4，证明引 Curry 1972 / Barendregt）：

> **一个项有 βη-范式 ⟺ 它有 β-范式。**

方向 ← 是 (ii)。方向 → 才是深的那半：βη-范式存在时 β-范式也在
（后置定理 + 有限性拼出来）。注意别读反：它**不**说「β-范式 =
βη-范式」——`λx. f x` 是 β-范式但不是 βη-范式（还能 η 一步）。
Hindley 特意加了个括号警告这一点。

机器收尾：

```lean
example : nfBetaEta 50 N2 = var 0 := by rfl               -- λx.(λy.fy)x →βη* f
example : nfBetaEta 50 (lam (app I (var 0))) = I := by rfl -- λx. I x →βη* I
```

## 3.5 λI：Church 的原版演算

Hindley 1D1 拉开一段常被遗忘的历史：**Church 1941 的《The
Calculi of Lambda-Conversion》研究的主演算是受限的 λI-项**：

> **λI-项**：每个子项 `λx. M` 都满足 x 在 M 中**至少出现一次**。
> 无此限制的通常项叫 **λK-项**（1D1.2 的命名）。

动机是哲学性的：Church 认为**没有范式的项是「无意义」的**
（meaningless），而他希望「有意义」是项的**遗传**性质——有意义
的项不该藏着无意义的子项。λI 恰好做到（Church 1941 §7 定理）：

> λI-项若有范式，则它的**每个子项**都有范式。

λK-世界直接违反这条：`(λx. y) Ω` 有范式 y，但子项 Ω 发散。

`isLI` 的实现是谓词式的一行事：

```lean
def isLI : Term → Bool
  | var _ => true
  | lam b => occurs 0 b && isLI b
  | app f a => isLI f && isLI a
```

机器初筛（三份镜像同一批）：

| 项 | λI？ | 死因/存活理由 |
|---|---|---|
| `K = λx y. x` | ✗ | y 空绑定（注意：**不是** x 的问题） |
| `S = λx y z. x z (y z)` | ✓ | 三个绑定器都被使用 |
| `I = λx. x` | ✓ | |
| `ω = λx. x x` | ✓ | 自应用也用过 x！λI 并不禁自应用 |
| Church 数 n（n ≥ 1） | ✓ | `λf x. fⁿx` 两者都用 |
| Church 数 0 = `λf x. x` | ✗ | f 空绑定——λI 数系的一个著名尴尬 |

最后一条值得停一秒：**λI 连 0 都写不利索**（标准 Church 0 的 f
是空绑定）。Church 原书为此单独处理 0。这不是缺陷表演——它解释
了为什么后来大家搬到 λK：不受限的演算表达力宽得多，代价是失去
「意义性遗传」。

λI 对 βη 封闭（1D4）：λI-项缩出来的还是 λI-项。机器实例账：

```lean
example : nfBetaEta 100 (app (app S I) I) = omega := by rfl
example : isLI (nfBetaEta 100 (app (app S I) I)) = true := by rfl
```

（`S I I` 缩到 `ω = λx. x x`——顺带复习：S I I 不是 I，是 ω。）

## 3.6 K 在 λI 中不可定义：一个初等证明

「λK 比 λI 强」可以量化：**没有任何封闭 λI-项的行为像 K**。
定理（Barendregt 1984 Ch. 9 有经典版本；下面是适合手推的证明）：

> 不存在封闭 λI-项 M 使得对一切 x、y 有 `M x y =βη x`。

证明靠一条**自由变量持存引理**：

> λI-项经 βη-归约，自由变量一个都不会消失（可能被复制，永不归零）。

分两步看：

- **β 步不消元**：收缩 `(λz. N) P`，λI 条件说 z 在 N 中出现
  ≥1 次，于是 P 至少代入一次——P 的自由变量在结果里至少还在。
  机器实例：`(λx. x x) a →β a a`，a 出现一次变两次，不归零：

  ```lean
  example : step (app (lam (app (var 0) (var 0))) (var 1))
            = some (app (var 1) (var 1)) := by rfl
  ```

- **η 步只删绑定变量**：`λz. P z →η P` 删掉的 z 出现属于 redex
  自己的骨架，其余自由变量原样穿过（出绑定器的 shift(-1) 不改
  变量身份）。

现在反设 M 封闭且 `M x y =βη x`（x、y 是新变元）。起点项 `M x y`
的自由变量集是 {x, y}；终点 x 的自由变量集是 {x}——**y 消失了**，
与持存引理矛盾。∎

对照组（λK 的消元现场）：`(λx y. y) P →β λy. y`，实参 P 整个
蒸发——这不是 bug，是 λK 的法定能力：

```lean
example : step (app (lam (lam (var 0))) (var 3)) = some (lam (var 0)) := by rfl
example : occurs 3 (app (lam (lam (var 0))) (var 3)) = true := by rfl
example : occurs 3 (lam (var 0)) = false := by rfl
```

持存引理的完整归纳证明（含代换与 shift 引理链）留给 48 章元理论
的路线图；本章机器面只到「实例账」——但请注意上面三行断言恰好
是引理在**这一步**上的全息切片：消元只发生在非 λI 项上。

## 3.7 预告：BCKλ 与 BCIλ（1D2–1D3、1D5–1D6）

1D 还定义了两个更紧的受限类，本章只立定义、逻辑戏份留给 09 章：

> **BCKλ-项**：每个绑定变量至多出现一次，且自由变量恰出现一次。
> **BCIλ-项（线性 λ-项）**：每个绑定变量**恰**出现一次，自由变量
> 也恰一次。（= λI ∩ BCKλ）

名字来自组合逻辑：封闭 BCKλ-项恰由 B、C、K 组合子可复合表达；
BCIλ 对应 B、C、I（1D2.3；细节在 9F）。样本对照（Hindley 1D2.1）：
B、C、I、K、`λx y. xⁿy`（n ≤ 1）都是 BCKλ；S、`λx y. x y y`、
`λx y. xⁿy`（n ≥ 2）都不是。配套词汇（1D5–1D6）之后会反复用：

> β-收缩**消元**（cancel，绑定变量 0 次）或**复制**（duplicate，
> ≥2 次）；λI 的 β-归约**永不消元**，BCKλ 的**永不复制**，BCIλ
> 两者皆不——「线性」名副其实。

这三族与子结构逻辑（相关/仿射/线性）的对应，09 章正式开演。

## 3.8 三家代码导读

`examples/03_eta/ex03_eta.{lean,v,agda}` 与 02 章同构（Term/shift/
subst/step 直接复制），新增 occurs/etaStep/nfEta/nfBetaEta/isLI
六件与同一批 20 条断言。三家差异集中在一处：

| 环节 | Lean | Coq | Agda |
|---|---|---|---|
| η 的嵌套模式 | 编译器接受 `lam (app t (var 0))` 直接递归 | **守卫拒绝**重建子项，须先 match `lam b` 再看 b 的形状 | **终止检查拒绝**，同样重构 |
| Bool 连接词 | `&&`/`||` 内建 | `andb`/`orb` | 从 Data.Bool 导入 `∧ ∨`——**连同 `Bool true false` 一起导**，漏了报 NotInScope |
| 自然数加法 | 无歧义 | 无歧义 | Data.Integer 的 `_+_` 遮蔽数字版，size 里须用改名导入的 `_+ℕ_` |

Coq 与 Agda 的「嵌套模式递归」撞墙是同一件事的两个方言：递归
调用的参数必须是**结构子项变量**（b），不能是模式里「重新拼出来」
的 `app t (var 0)`。Lean 的编译方程恰好多走一步（brecOn 对嵌套
模式做了展开），于是三家写法分岔——这与 02 章「if 的条件类型」
同款：同一算法，三种语言哲学。

> **坑位速记**
> ① η 的 contractum 是 `shift (-1) 0 t` 不是 t——t 的自由指标
> 全体 ≥ 1，出绑定器必须降 1（本章头号实测坑，三家同一处）；
> ② Coq 守卫 / Agda 终止检查都不认嵌套模式重建的递归参数
> （`eta_step (app u (var 0))`），先 `match lam b` 再看 b；
> ③ Coq 里组合子 `Definition S` 会遮蔽 nat 后继构造子——
> 含 `S n` 模式的 Fixpoint（iter）须放在 S 之前；
> ④ Agda 从 Data.Bool 导入运算符时把 `Bool; true; false` 一并
> 列入 using，且 Data.Integer `_+_` 与 Nat `_+_` 撞名要改名导入；
> ⑤ λI 不禁自应用（ω 是 λI）、也不缺发散项（S I I → ω）；
> 它禁的是**空绑定**——K 的死因是 y 不是 x。
