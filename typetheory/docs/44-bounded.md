# 44 囿量词：F<: 与不可判定性

> 对应读本：TAPL 书第 26 章（囿量词）、第 27 章（实例分析：
> 命令性对象约式）、第 28 章（量词元理论）。代码：
> `examples/44_bounded/ex44_bounded.pl`（bounded quantification
> 的类型语法与定型/子类型规则、**kernel 与 full F<: 两版
> SA-All 并载对照**、囿实例化的界检查样本）。

39 章的 <: 遇上 18 章的 ∀ 会怎样？——**囿量词**
∀X<:T：全称量化的类型变量带上界。「对**所有**满足 X<:T 的
类型 X」——多态与子类型的联姻，面向对象类型系统的理论内核。

## 44.1 动机与定义（书 26.1–26.2）

书 26.1 的动机：`λx:Top. x` 是「丢弃类型信息」的恒等——
`∀X. X→X` 的函数收到一个 X 后，关于 X **什么都做不了**
（只知道它是类型）。加上界后 `∀X<:Nat. X→X` 的函数知道
「X 至少是 Nat」——可以对 X 的值做算术。**上界 = 多态
函数的最低服务承诺**。三条核心规则（机器件直译）：

```prolog
/* T-TAbs 囿版：ΛX<:T. t 在 X<:T 下定型 */
typeof(tabs(X, B, Body), G, forall(X, B, T2)) :-
    typeof(Body, [X<:B|G], T2).
/* T-TApp 囿版：t [T1] 要求 T1 <: 界 */
typeof(tapp(M, T1), G, Body2) :-
    typeof(M, G, forall(X, B, Body)),
    sub(T1, B, G),
    subst_ty(Body, X, T1, Body2).
```

## 44.2 kernel vs full：一条规则的两种命运（书 28）

全称类型的子类型规则 SA-All 有两个版本：

> **kernel**：∀X<:S.T <: ∀X<:S.T′（**两侧界相同**，比体）
> **full**：∀X<:S.T <: ∀X<:S′.T′ 当 **S′ <: S**（右侧的界
> 更窄——「承诺面更窄的量词是更小的类型」）+ 体在扩展
> 环境下比。

机器件两版并载，同一样本一决雌雄：

```prolog
check("kernel 拒绝界收窄的全称子类型",
       ( \+ sub(forall(x, top, var(x)),
                forall(x, natt, var(x)), []) )),
check("full 接受同一判断（SA-All 的 T1<:S1）",
       sub_full(forall(x, top, var(x)),
                forall(x, natt, var(x)), [])),
```

这对差异的**重量级后果**（书 28 的主线）：kernel F<: 的
子类型**可判定**；full F<: 的子类型**不可判定**（28.5，
Ghelli 1995 的归约证明）。一条规则从「同界」放宽到「变界」
就把可判定性买走了——「表达力的每一分都有价目」在类型
系统设计中的极端案例。书 28 的元理论清单：**揭示引理**
（28.1，类型的「最小形状」——39 章最小类型的量化版）、
**最小类型算法**（28.2）、**不可判定性**（28.5）——机器件
装的是算法子类型，揭示与最小化的完整机械以 docs 地图
呈现。

## 44.3 命令性对象，约式（书 27）

第 27 章（一章的实例分析）：用 F<: 把 40 章的命令式对象
**约式**——对象 = 记录，self 的类型 = 囿量化的类型变量
`∀Self<:Interface. Interface`。书 27 的展开（32.3 节的
预演）：简单对象 → 加 self → 加状态 → 加接口类型——
每一层的类型代价在 F<: 里逐层计价。**44 章与 40 章的
关系**：40 章的编码是「能不能跑」（Prolog 机器），44 章
的类型是「跑的时候类型上发生了什么」——两层合起来才是
完整的对象类型学。

## 44.4 一页总结（本章的三个公式）

> 囿量词 = ∀ + 上界：多态函数对类型变量的最低承诺。
> kernel SA-All 同界、full SA-All 变界——一条规则的宽严
> = 可判定性的去留。
> 揭示引理 + 最小类型 = 算法化的双支柱（28.1/28.2）。

> **坑位速记**
> ① Prolog 自定义 `<:` 记号要先 `:- op(950, xfx, (<:))` —
>   否则环境条目 X<:B 全线语法错误（本批实测四连报）；
> ② 子类型检查器要加**结构相等快速通道**（`sub(T,T,_)`）——
>   tv(X) <: tv(X) 走界的传递路径会失败（界是 Top ≠ tv(X)）；
> ③ typeof 变量子句要分**模式**：T 未定时直给类型、已定时
>   做 T-Sub 强制——不分会把自由目标模式统一坍缩成 Top；
> ④ full SA-All 的方向是 **T₁（右侧界）<: S₁（左侧界）**——
>   直觉写反是第一错误（本批实测：∀X<:Nat.X <: ∀X<:Top.X
>   恰是**假**的——收窄界的量词才更小）。
