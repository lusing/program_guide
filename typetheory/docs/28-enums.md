## 28.1 枚举集合：一套规则，三种规格

Nordström 第 6 章从最简单的集合起步——**枚举集合**
`{i₁,…,iₙ}`：列出全部元素，别无其他。它的规则组是全书
第一个完整样本，值得整表读一遍：

```text
{i₁,…,iₙ}-形成      {i₁,…,iₙ} set
{i₁,…,iₙ}-引入 1    iₖ ∈ {i₁,…,iₙ}        （n 条：每个常元一个）
{i₁,…,iₙ}-引入 2    iₖ = iₖ ∈ {…}          （构造子互斥的正面：
                                              仅当相同典则元才相等）
{i₁,…,iₙ}-消去      a ∈ {…}, C(x) set[x∈{…}], b₁∈C(i₁),…,bₙ∈C(iₙ)
                    ⟹ case(a, b₁,…,bₙ) ∈ C(a)
{i₁,…,iₙ}-相等性    case(iₖ, b₁,…,bₙ) = bₖ ∈ C(iₖ)   （n 条）
```

三件套是它的三个特例：

| 集合 | 构造子 | 消去子 | 逻辑读法 |
|---|---|---|---|
| `⊥`（空 {}） | 无 | 到任意目标的函数 | 假（爆炸原理的原型） |
| `⊤`（单 {tt}） | `tt` | 常值函数 | 真 |
| `Bool`（双） | `true`/`false` | if-then-else | （命题级即 ¬ 与 ∨ 的前身） |

**消去子（eliminator）是 MLTT 的关键字眼**：一个集合的意义 =
「怎么构造」+「怎么使用」。消去规则的**语义论证**值得看一遍
（书 6 章的示范）：要说明 `case(a,b⃗) ∈ C(a)`，就计算 case
表达式的值——第一步求 a 的值，由前提 a 是典则元 iⱼ；第二步按
计算规则值得 bⱼ 的值，由前提它是 C(iⱼ) 的典则元；最后由族
语义 C(a) = C(iⱼ)，这个值也是 C(a) 的典则元。**每条消去规则
的论证都是这个三步舞**——值分析、前提对照、集合相等收尾。

Bool 的相等性规则两条（`if true then c else d = c`、
`if false then c else d = d`）。一个重要的辨析（书 6.3）：
判断 `true ∈ Bool` 与判断 `C true` **毫无关系**——前者只说
true 这个程序算出来是典则元 true（「名可以任意，有些语言用
0 和 1」），后者说命题 C 有证明。bool 值与真值是两个世界，
枚举集合只是恰好借用了逻辑词汇作名字。

## 28.2 空集合、单元素与自然推理形式

n=0 时空集合 `{}` 无引入规则，消去规则变成「从无到有」：

```text
⊥-消去   ⊥ true, C prop ⟹ C true       （爆炸原理）
⊤-引入   ⊤ true
⊤-消去   ⊤ true, C true ⟹ C true       （书注：显见而不常用）
```

这是**自然推理规则形式**——把集合规则里的证明对象全部隐去
（`a ∈ A` 换成 `A true`）就得到直觉主义逻辑的规则表。命题即
集合的整座桥就这样搭起来：消去子的居留项是「证明怎么用」，
引入规则是「证明怎么造」。

空集合的三家荒谬拼写：

- **Lean**：`nomatch e`（穷尽性检查发现无构造子可匹配，直接收）；
- **Agda**：荒谬模式 `()`——「此处不可能有构造子」的证据语法；
- **Coq**：`match e with end`（无分支的 match）。

构造子**互斥**（引入 2）同样机器化：Lean 用自动生成的
`noConfusion`，Coq 用 `discriminate`，Agda 最直白——对
`refl` 匹配直接荒谬：

```agda
true≢false : true ≡ false → ⊥
true≢false ()
```

## 28.3 Π：一族集合的笛氏积

Nordström 第 7 章的主角是 Π——集合族 `B : A → Set` 的笛氏积
`Π(A,B)`（写作 `(Πx∈A) B(x)`），元素是「给每个 x 一个 B(x)
的元素」的函数。它比函数集合 A→B 更广：**作用结果所在集合
可以依赖被作用的值**——书里给的动机例子正是程序规格说明：
排序程序作用于列表 a，输出在 Op(a)（a 的有序置换集合）中，
输出类型依赖输入值。

Π 的典则元由**语义**直接定义（不是规则而是含义）：

> 若 `b(x) ∈ B(x)[x∈A]`，则 `λ(b)` 是 Π(A,B) 的典则元；
> 若逐点 `b(x) = b₂(x) ∈ B(x)`，则 λ(b) 与 λ(b₂) 是**相等的**
> 典则元——相等性从族的外延性继承。

规则组：

```text
Π-形成     A set, B(x) set[x∈A] ⟹ Π(A,B) set
Π-引入     b(x) ∈ B(x)[x∈A] ⟹ λ(b) ∈ Π(A,B)
Π-消去 1   f ∈ Π(A,B), a ∈ A ⟹ apply(f,a) ∈ B(a)
Π-相等性1  apply(λ(b),a) = b(a) ∈ B(a)      （β）
Π-消去 2   f ∈ Π(A,B), C(v) set[v∈Π(A,B)],
           d(y) ∈ C(λ(y))[y(x)∈B(x)[x∈A]]
           ⟹ funsplit(f,d) ∈ C(f)
Π-相等性2  funsplit(λ(b),d) = d(b) ∈ C(λ(b))
```

由 Π 定义的常元（书 7.3）：**受限函数集合** `A→B =
Π(A,(x)B)`、**全称量词** `(∀x∈A)B(x) = Π(A,B)`、**蕴含**
`A⊃B = A→B`——把居留项隐去即得 ∀ 与 ⊃ 的自然推理规则
（∀-消去 = apply，∀-引入 = λ）。Pascal 的 record 也是 Π 的
特例（`(Πx∈{i₁,…,iₙ}) B(x)` 的元素即 n 元组，`f.j` 就是
apply）。

**funsplit 是 7.2 的教学重头**：多数集合的非典则形式遵循
结构归纳原理（对典则元分派即可），但 **apply 不遵循**——它
从 λ 演算的 β 而来，「因为有名所以直接取作原始」。funsplit
是遵循结构归纳原理的替代品：对 f 的典则形 λ(b) 分派。两者
的关系可以用一行定义看清——**apply 可由 funsplit 定义**：

```text
apply(f,a) ≜ funsplit(f, (λ)(x·a))
```

而反向（funsplt 由 apply 定义）做不到——apply 的两参语境
装不下「以函数变元 y 为参数」的分支体。Agda 件里把这个
从属关系机器化：

```agda
-- funsplit：结构归纳原理版消去子（对 λ 模式分派）
funsplit : {A : Set} {B : A → Set} {C : Set}
  (f : (x : A) → B x) (d : ((x : A) → B x) → C) → C
funsplit f d = d f

-- apply 可由 funsplit 定义（分支体把实参喂给函数变元）
apply′ : {A : Set} {B : A → Set} (f : (x : A) → B x) (a : A) → B a
apply′ f a = funsplit f (λ g → g a)

-- β 等式：定义相等层面直接成立（refl 见证）
β-direct : {A : Set} {B : A → Set} (f : (x : A) → B x) (a : A)
           → apply′ f a ≡ f a
β-direct f a = refl
```

## 28.4 Π-on-Bool：填表直觉

在有限枚举上，Π 就是**填表**：

```agda
bothCases : (P : Bool → Set) → P true → P false → ∀ b → P b
bothCases P pt pf true  = pt
bothCases P pt pf false = pf
```

两行 = 两个构造子 = Π 的全部居留项形状（函数外延性下唯一）。
Bool 上的依赖函数与「按构造子索引的表」是同一个数学对象——
这是后续归纳族（30 章）在最小舞台上的预演。族要先立
（`Sel : Bool → Set` 两行定义）再填表；直接写 `if2 b ⊤ Bool`
不成立——`if2` 是非依赖的，两个分支必须同型。依赖版本的
if 叫 `bothCases`/`Bool2_rect`/大_elim——「消去子的依赖版
自动生成」正是三家归纳机制的核心服务（30 章细看）。

（中置记号 `x · y ≜ apply(x,y)` 沿用自组合逻辑传统——
书里 apply 的中置形与 λ-抽象的配对正是 β 的两翼。）

还有一条书 7 章的辨析值得单独记：`true ∈ Bool` 与判断
`C true` 属于两个世界——前者只是「程序 true 求值为典则元
true」（有些语言用 0/1 当这两个名字），后者才有「命题 C
有证明」的意思。Bool 值 ≠ 真值：把 `Bool` 当命题宇宙是
经典逻辑的越权（命题是集合、Bool 只有两个元素——两者之间
没有越界的通道，除非自己造 `if b then P else Q` 的依赖
分派）。

Π 的三个特例（书 7 章末）值得整段记：受限函数集合
`A→B ≜ Π(A,(x)B)`（B 不依赖 x——一阶函数）；全称量词
`(∀x∈A)B(x) ≜ Π(A,B)`（命题读法）；**Pascal 的 record
类型形成子**——`(Πx∈{name,age,salary}) B(x)` 的元素是
三元组，`f.name` 就是 apply(f,name)。有穷枚举上的 Π 是
「按标签取分量」的语法糖——记录类型是 Π 的退化特例，
这一视角把 39 章的依赖多元组（Σ 链）与本章的 Π 接成了
一对「标签取分量 / 顺序取分量」的镜像。

Π-引入的语义论证（书 7.1）是三步舞的函数版：λ(b) 的值
是典则的（λ-形式）；b(a) ∈ B(a) 由前提的代入解释；逐点
相等继承族的外延性——「典则元相等 = 分部相等」对函数而言
就是**值的逐点相等**，这为 29 章 η 讨论埋下语义伏笔
（η 把逐点相等升到判断层的条件正是外延性）。

> **坑位速记**
> ① 非依赖 `if` 的两分支必须同型；类型要随参数变就得走
>   消去子的依赖版（族先立、再填表）；
> ② Coq 空类型要声明在 `Set`（无构造子归纳默认落 Prop，
>   禁止消去到 Type）；
> ③ Lean 的 `nomatch`、Agda 的 `()`、Coq 的空 `match ... with end`
>   是同一荒谬的三种拼写；
> ④ Lean 核心库占用 `Empty`/`Unit`/`Bool`——自定义换名避免遮蔽；
> ⑤ Agda 里 `funsplit f d = d f` 能写、`refl` 直接见证 β——
>   因为模式匹配已在判断层吸收了 funsplit 的语义；书里
>   apply/funsplit 的「谁定义谁」不对称是**形式系统设计**
>   的课，不是 Agda 能否编译的课。
