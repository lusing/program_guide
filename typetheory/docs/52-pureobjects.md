# 52 纯函数对象：存在编码的收官

> 对应读本：TAPL 书第 32 章（实例学习：纯函数对象）。代码：
> `examples/52_pureobjects/ex52_pureobjects.pl`（存在包 × 记录
> 接口 × self 应用的三合一编码——纯函数计数器的求值链、
> 「对象更新 = 函数组合」的机器见证、接口封闭性）。

TAPL 的收官案例分析：**纯函数对象**——不用引用（44 章）、
不用类表（46 章 FJ），只用 49 章存在类型 + 43 章记录 +
self 参数，把「对象」编码进纯 λ 演算。这是「面向对象 =
类型论的什么」的第三种答案，也是全书的终点站。

## 52.1 编码阶梯（书 32.1–32.5）

对象类型 = 存在类型包装的记录接口，接口的方法**收 self
作参数**：

> Counter = ∃Self. { get : Self → Nat, inc : Self → Self }

阶梯五步（书 32.1–32.5 的展开）：**简单对象**（32.1：记录
里是普通函数）→ **加 self 参数**（32.2：方法都收 self —
晚绑定的最低配置）→ **子类型化**（32.3：接口可加字段 —
45 章 <: 上岗）→ **囿量词**（32.4：Self 的界 = 接口类型
本身 — 50 章上岗）→ **接口类型**（32.5：行为约束的完整
类型）。机器件的最小编码：

```prolog
counter_pure(pack(natt,
                 rcdobj([get=lm(s, natt, vr(0)),      % self 即状态
                         inc=lm(s, natt, succ(vr(0)))]),
                 exists(self, rcdt([get=arr(natt, natt),
                                    inc=arr(natt, natt)])))).
```

**表示即状态**（Nat 本身当 self）——极简但诚实：inc 的
「更新」不是副作用而是**产出一个新状态**。

## 52.2 调用与更新（书 32.5–32.7）

**send 的语义 = self 应用**：`obj.inc(state)` 一步 β —
机器见证：

```prolog
check("inc 的 self 应用产新状态：inc(0) ⇓ 1", ...),
check("双 inc 后 get ⇓ 2（对象更新 = 函数组合）",
       ( counter_pure(O),
         Chain = ap(prj(O, get),
                    ap(prj(O, inc),
                       ap(prj(O, inc), zero))),
         steps(Chain, [], succ(succ(zero)), _) )),
```

「更新链」是纯函数语义的核心：命令式对象（46 章）的
`o.inc()` **改变** o；纯函数对象（本章）的
`o.inc(o)` **返回**新 o——外部世界的每一「状态」都是
一条不可变的函数组合链。**多态更新**（32.7）是本章的
技术难点：「给记录加一个字段而保留其余」的操作在类型层
需要囿量词 + 存在的组合拳——书里的 32.7/32.8（加实例
变量）逐层展示「拷贝并扩展」的类型代价。

## 52.3 三条对象路线的对照（全书的收束）

| | 46 章 命令式 | 46 章 FJ | 52 章 纯函数 |
|---|---|---|---|
| 状态 | ref 单元 | 类字段 | self 参数 |
| 更新 | 赋值副作用 | 字段写入 | 函数组合 |
| self | fix 不动点 | this 隐式 | 显式首参 |
| 类型学 | 27 章约式 | 类表 + 名义 <: | ∃ + 囿 Self |
| 语义模型 | 存储机 | 类表机 | 纯 λ |

三条路线在「封装」上会师、在「更新」上分家——**可变性
是对象模型的独立变量**。书 32.10 注记指路后续研究：
对象演算（Abadi–Cardelli 的 Ob<:）、行多态（row
polymorphism）、以及「对象 = 记录 + 存在」与「对象 =
递归类型」的等价性（47 章 μ 的另一应用）。

## 52.4 一页总结（本章的三个公式）

> 纯函数对象 = 存在包 × 记录接口 × self 应用——面向对象
> 的纯 λ 化身。
> 更新 = 函数组合：可变性从语言原语降为编码模式。
> 对象类型学全书收束：<:（39）+ 引用（38）+ ∀<:（44）+
> kind（45）+ ∃（43）——五件合体。

> **坑位速记**
> ① 「又一个 λ 机」的 lm 参数个数（本章命名 3 参）——
>   五张表（isvalue/shift/subst/step/typeof）元数一致性
>   是装配机的第一坑（49 章三连环的续集）；
> ② 投影穿透 pack 的教学捷径（`prj(pack(...),L) → prj(V,L)`）
>   简化 send 链——真版走 unpack；两版别混用；
> ③ self 应用的求值链里**表示值与对象值交替出现** —
>   `ap(prj(O, get), zero)` 的 zero 是表示不是对象——
>   编码阶梯的「表示即状态」简化下两者同体，正式版
>   （Self 接口）不同体，写样本时要分清在哪一层。
