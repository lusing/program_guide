# 12 Alonzo：Church 式简单类型论

> 对应读本：Farmer《Simple Type Theory》(2023) 第 3–5 章（预备概念 /
> 语法 / 语义）。代码：`examples/12_alonzo/`——Lean 侧 Alonzo 求值器
> （七构造子 + V1–V7 部分赋值 + Henkin 落域检查 + 定理 5.9 引擎）；
> Prolog 侧语义实验室（同款求值 + 同构换标 + 最小模型）。

03–11 章走的是 Hindley 的 **Curry 式**路线：无类型项先存在，类型
事后指派，主角是主类型算法。本章换到对岸的 **Church 式**路线：
类型长在表达式身上，主角是**模型**。载体是 Farmer 的 Alonzo——
以丘奇命名、以安德鲁斯（Andrews 的 Q0）为证明论血统的实用逻辑。
两条路线在 05–06 章已隔河相望（λ-模型），现在正式过桥。

## 12.1 两种简单类型论：一张对照表

| 维度 | Hindley（03–11 章） | Farmer（本章起） |
|---|---|---|
| 项的来源 | 无类型 λ 项，类型事后指派 | 表达式生来带类型 |
| 类型的角色 | 指派的标签 | 语构的一部分（七构造子各有定型的规则） |
| 核心问题 | 这个项有哪些类型？主类型？ | 这句话在哪些模型里真？ |
| 工具箱 | 合一、范式、计数 | 广义模型、理论、态射 |
| 逻辑立场 | 证明论（可归约性） | 模型论（可满足性） |

**类型**只有四条：真值型 `o`（域固定为 {f, t}）、基型 `a`（非空
集合）、箭头 `α→β`、积 `α×β`——比 04 章的 λ→ 多了积、少了类型
变量。**表达式**恰好七种（Farmer 4.4）：

```text
变量 (x:α)   常数 cα   等式 Aα = Bα（结果型 o）
应用 Fα→β Aα   抽象 λx:α.Bβ
确定描述 Ix:α.Ao   序对 (Aα, Bβ)
```

后两个是 λ→ 里没有的新面孔：**确定描述** `Ix:α.A` 读作「使 A 为
真的**那个** x」，**序对**是原生的（不靠 Kuratowski 编码）。每种
表达式按语构定型——Lean 侧的 `typeOf` 就是这七条定型规则的可执行
版（`ex12_alonzo.lean` 的 `typeOf` 函数），书里习题 4.9.2a 的
`c_A d_B` 不良型，机器一查即知：

```lean
example : typeOf 0 (.app c0 c1) = none := by rfl
```

**语言** `L = (B, C)`：一袋基型 + 一袋常数。整个实验室的语言是
`B = {N}`、`C = {0, 1, plus, ∆}`——两个元素 0、1、模 2 加法、
一个空函数，够演全部核心条款。

## 12.2 框架与广义模型：F1–F4 与 V1–V7

**框架**（5.1）给每个类型配一个非空域，四条条款里藏着本章第一个
惊喜——**F2/F3 的不对称**：

> F1. `D_o = {f, t}`；
> F2. `D_{α→o}` 是 `D_α → D_o` **全函数**的某个集合；
> F3. `D_{α→β}`（β≠o）是 `D_α → D_β` **部分与全函数**的某个集合；
> F4. `D_{α×β} = D_α × D_β`。

谓词必须全，函数可以偏——这不是疏忽，是 Farmer「传统未定义性
进路」（TATU）的语构支点：**公式永远有定义**（见 13 章），而非
布尔表达式可以无定义。框架只要求「某个集合」，于是 `D_{α→β}`
可以**不满**（full 的反义）——这正是 Henkin 广义模型的手筋。

**广义模型** `M = (D, I)` 带一个**部分赋值函数** V，七条条款
（5.2）逐条值得读慢：

> V1/V2. 变量取指派、常数取解释——总有定义。
> V3. `A = B` 为 t 若两者有定义且相等，**否则为 f**——等式永远有定义。
> V4. `F A`：三者（F、A、F 在 A 处）都有定义才取值；否则
> **目标型是 o 给 f，不是 o 给无定义**。
> V5. `λx.B` 逐点取值成（部分）函数。
> V6. `Ix.A` 取**恰一**满足者；零个或多个都无定义。
> V7. 序对严格：任一分量无定义则整体无定义。

V3 的锋利处第一次见会扎手：**⊥ = ⊥ 是假**，不是无定义。⊥ 自身
无定义，于是「相等」的分款够不着「有定义且相等」，落到 otherwise
的 f。真正「两边都无定义也算相等」的是 13 章的准等式 ≃。Lean 侧
一条断言钉死：

```lean
example : evalV M1 [] (.eq botN botN) = some (.tv false) := by rfl
```

V4 的不对称本章先埋种子（∆ 应用折成假），13 章收全账。

## 12.3 Lean 求值器：把 V1–V7 逐条写下来

`ex12_alonzo.lean` 的三层数据：`Ty`（四条）、`Tm`（七构造子，
de Bruijn 指标 + 类型注解）、`Val`（真值 / 基域元素 / 函数表 /
序对）。函数值就是**关联表**，缺键 = 该点无定义——空表 `[]` 即
空函数 ∆。求值器 `evalV` 与七条款一一对应，以 V4 为例：

```lean
| φ, .app F A =>
    match typeOf 0 F with
    | some (.arrow _ β) =>
        match evalV M φ F, evalV M φ A with
        | some f, some a => applyV f a <|> (if β == .o then some (.tv false) else none)
        | _, _ => if β == .o then some (.tv false) else none
    | _ => none
```

书的例 5.3 逐步复算——`(λx:N. plus(x,x) = 1) 0`：内层
`plus(0,0) ↦ 0`，`0 = 1 ↦ f`，λ 逐点成表，应用取值 `f`：

```lean
example : evalV M1 [] ex53 = some (.tv false) := by rfl
```

V6 的三态同样一条一个断言：`Ix. x=c0` 恰一 ↦ 0；`Ix. x=x`
二义 ↦ 无定义；零满足 ↦ 无定义。第三条有个漂亮的副产品：**⊥_N
的纯等式编码**——`Ix. (x=c0) = (x=c1)` 在每个 x 处都是
「真=假」即假，零满足者，恰是 ⊥。不需要否定词，两个等式就够了。

## 12.4 Henkin 条款可执行化：不是每个解释都是模型

广义模型的定义还要求 V 的取值**落在域里**。满框架自动满足
（5.2 命题）；不满框架就要逐个检查——**λ 的指称必须在手选的
`D_{α→β}` 里**。这本是元定理里的归纳论证，实验室里可以做成
布尔函数：

```lean
def frameOK (M : Model) (φ : List Val) : Tm → Bool
  | .lam x B => ... (domOf M (.arrow x β)).contains ...
```

M1 的 `D_{N→N}` 只装 4 张表（恒等、常 0、常 1、空——16 张全表
里挑 4 张）。`M1bad` 故意抽掉常 1 函数，于是：

```lean
example : frameOK M1bad [] (.lam N c1) = false := by rfl   -- 不是广义模型
example : frameOK M1 [] (.lam N c1) = true := by rfl
```

「解释」与「模型」之间的鸿沟就此可执行：**随便给域分派常数不算
数，λ-闭包条款（Henkin 条款）是入场券**。06 章 λ-模型的「足够
多的函数」一说，在这里落成了具体的 `contains` 检查。

## 12.5 有限广义模型 = 标准模型：定理 5.9 的两个引擎

**标准模型** = 满框架的广义模型。两条语义（⊨ 对一切广义模型、
⊨s 只对标准模型）就此分家（5.8 节：标准语义是数学实践的语义、
广义语义是逻辑实践的语义——后者才有完备性/紧致性/LST 这一族
定理，14–15 章逐个兑现）。

有限世界有个反直觉的好定理：

> **定理 5.9**：有限广义模型都是标准模型。

证明的两个引擎都能上机。**基数引擎**（5.6 命题 2 用到）：n 个
点上有 n 个常函数 + 恒等函数，共 n+1 个互异成员——

```lean
def constsAndId : List Val :=
  [.fv N N (constTab (.el 0 0)), .fv N N (constTab (.el 0 1)), .fv N N idTab]
#eval constsAndId.length   -- 3 = 2 + 1 > |D_N|
```

**穷尽引擎**（证明的谓词层）：2 点域上全部 4 个谓词，4 个 λ 项
就写完了——`λx.x=x`（全）、`λx.x=c0`、`λx.x=c1`、
`λx.(x=c0)=(x=c1)`（空）。Lean 与 Prolog 双机对表：

```lean
example : [pAll, p0, p1, pNone].all (fun p => predTabs.contains (tabOf M1 p)) = true := by decide
```

```prolog
chk(10, '5.9 引擎：4 个 λ 项给出 4 个互异谓词且全落域') :- ...
```

——谓词层被 λ 项「吃满」，任何不满的谓词域都会被某个 λ 项的
指称戳穿；函数层靠 V6 描述算子搭 case 树同理。所以有限广义模型
想偏都偏不了。顺带的推论图景（图 5.1）：**非标准模型必然是
无限的**——15 章紧致性造出来的 PA 非标准模型因此只能是无穷的。

## 12.6 模型动物园：最小模型与同构

Prolog 侧补两件 Lean 侧没做的事。**最小语言/最小模型**：基型袋
空、常数袋空，一切从 `o` 长出。`D_{o→o}` 满空间恰 4 张表（恒等、
否定、常 t、常 f），λx.x 与 K 组合子双双落域：

```prolog
chk(12, '最小模型：λx.x 落域').
chk(13, '最小模型：K 落域（满空间含常函数）').
```

**同构**（5.6/5.13）：两个模型同构则对同样的句子给出同样的真值。
实验室把 m1 的所有表与常数沿换标 θ（0↔1）重写得到 m1s，于是同一
个闭式在两边的值恰好差一个 θ——

```prolog
chk(11, '同构 5.12/5.13：I x.x=c0 的值随 θ 走') :-
    ..., eval(m1, [], D, V1), theta(V1, V1s), eval(m1s, [], D, V1s).
```

「同构的模型可以视为同一个」从口号变成了一次可执行的换标。

> **坑位速记**
> ① **Lean `deriving BEq` 遇嵌套递归字段（`List (Val × Val)`）
>   生成的实例在内核归约下卡死**：`#reduce (el 0 0 == el 0 0)`
>   停在 `instBEqVal.beq`，`by rfl` 全线失败而 `#eval` 正常——
>   手写 `valEq`（含 `tabEq`）后全部转绿。凡值类型含「自身列表
>   字段」都要警惕；
> ② Prolog 手写嵌套 `tm(app(tm(lam(...))))` 十次九次括号错——
>   改用**命名部件法**（`t_c1/1`、`A = ...` 逐行组合），括号
>   天花板立刻消失；
> ③ SWI 目标失败时 `format` 输出会被吞（不 flush 就退场）——
>   电池要写成链式 `cond(N)` 谓词、失败即 `halt(1)`，先报后死；
> ④ `:- encoding(utf8).` 必须在含中文的横幅**之前**，否则横幅
>   以本地码页误读报 Illegal multibyte；
> ⑤ 管道 `swipl ... | head` 的 `$?` 是 head 的退出码——验退出码
>   时别接管道。
