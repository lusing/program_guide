# 04 Curry 式类型指派与主类型

> 对应读本：Hindley《Basic Simple Type Theory》第 2–3 章（TA_λ 与
> 主类型算法 PT）；TAPL 第 22 章（类型推断的工程视角）。
> 代码：`examples/04_curry/ex04_curry.lean`——Robinson 合一 +
> 约束生成 + 主类型算法的完整 Lean 实现，经典组合子的主类型
> 全部 `by rfl` 机器验证。

## 4.1 指派：类型作为项的「外挂属性」

Church 式（03 章）让类型住进语法；Curry 式把类型做成**外挂关系**：
项还是无类型 λ 项，指派规则只有三条（Hindley 的 TA_λ）：

```text
(1)  Γ(k) = T                (2)  Γ, x:σ ⊢ M : τ              (3)  Γ ⊢ M : σ → τ    Γ ⊢ N : σ
     ─────────────                ─────────────────                ─────────────────────────────
     Γ ⊢ var k : T                Γ ⊢ λx. M : σ → τ                Γ ⊢ M N : τ
```

与 03 章的差别一望便知：抽象规则里 `σ` 是**任意**的——λx. x x 在
`x : (σ→τ)` 与 `x : σ→τ` …照样不行（ω 依旧不可指派），但 `λx. x`
可以被指派成 `σ → σ` 对**每个** σ。一个项可以有很多类型，也可以
没有。于是自然要问：

> **主类型问题**（Hindley 3A）：给定 M，有没有一个「最一般的」类型
> π，使得 M 的所有指派类型恰好是 π 的替换实例？

答案是有（对可指派的项），π 叫**主类型**（principal type），求它的
算法叫 **PT 算法**——这就是本章实现的东西。把它扩到 `let` 多态
就得到 Milner 的**算法 W**，是 ML/Haskell/Rust（局部）/OCaml 的
类型推断之祖。Hindley 1958 与 Curry 1958 分别独立发现了它比
Milner 早近十年（故也常叫 Hindley–Milner）。

## 4.2 主类型的钥匙：合一

对封闭项 M 主行 PT 算法两步走（实现见 `gen` + `solve`）：

1. **约束生成**：给每个绑定器发一个新鲜类型变元，结构递归地给
   M 配一个「带洞的类型」+ 一张等式约束表。应用位 `M N` 生成
   `typeof(M) = typeof(N) → r`（r 新鲜）。
2. **解约束**：反复使用合一（unification）——

```text
unify(t, t)         = 恒等
unify(x, t)         = [x := t]        （x 是变元且 x ∉ FV(t)）
unify(t, x)         = [x := t]        （同上）
unify(s1→s2,t1→t2)  = unify(s1,t1) ∘ 后续
其他                  = 失败
```

其中 `x ∉ FV(t)` 这条**occurs check** 正是 ω 的死因：
`λx. x x` 生成约束 `x₀ = x₀ → r`，合一器要解 `x₀ ≟ x₀ → r`，
x₀ 出现在右边——解只能是无限项 `x₀ = x₀ → r = (x₀→r)→r = …`，
有限类型里不存在，算法拒绝。**occurs check 失败 = 类型化自应用
的签名**。

## 4.3 实现导读

`ex04_curry.lean` 的关键设计决策：

- **代换做成函数**（`Subst := Nat → Ty`）而不是关联表：链式查表
  的终止性依赖「表无环」（occurs check 的推论），教学实现里证明
  这个不划算；函数式表示让 `applyS` 纯结构递归，Lean 终止检查
  直接放行。
- **`solve` 用燃料递归**：曾用 `termination_by cs.length`（map 保长）
  过了终止检查，但 `WellFounded.fix` 展开对内核 defeq 不友好，
  `by rfl` 断言全体卡壳——换成燃料版后内核可解，全部断言过。
  这是个值得记住的 Lean 工程：**要被 rfl/native 断言的函数，
  优先结构/燃料递归**。
- **变元编号确定性**：新鲜计数器按「绑定器 → 应用结果」的顺序
  消耗，主类型的字面编号因此完全确定（`λf x. f x` 得
  `(t1→t2)→(t1→t2)` 而非书上的 `(a→b)→(a→b)`——只差 α-换名）。
  断言里写的字面必须跟机器走，不跟书走。

实测结果一览（全部 `by rfl`）：

| 项 | 主类型（机器字面） |
|---|---|
| `λx. x` | `t0 → t0` |
| `λx y. x`（K） | `t0 → t1 → t0` |
| `λf x. f x` | `(t1→t2) → t1 → t2` |
| `λf g x. f (g x)`（B） | `(t3→t4) → (t2→t3) → t2 → t4` |
| `λx y z. x z (y z)`（S） | `(t2→t4→t5) → (t2→t4) → t2 → t5` |
| `λx. x x`（ω） | `none`（occurs check） |
| `Ω = ω ω` | `none` |
| 含自由变量的项 | `none`（封闭算法对自由变量说不） |

对照 Hindley 书末的「主类型表」（Table of principal types）：
组合子逻辑的名角们（B、C、K、S、W…）的主类型与我们的机器
输出逐个 α-一致。

## 4.4 指派世界的元定理

TA_λ 有几条与 Church 式**不对称**的元性质（Hindley 2C–2D）：

- **主体归约成立**：`Γ ⊢ M : T` 且 `M →β N` 则 `Γ ⊢ N : T`。
  ——归约只会让约束变松。
- **主体扩张不成立**！`Ω →β Ω` 自身；取 `M = (λx. x x) I`：
  `M →β I I`。`I I` 可指派（在 `I : (σ→σ)` 时……不，`I I` 需要
  `I : σ→σ` 且 `I : σ`，不可指派）；但 `M = ω I` 呢——同样不可。
  Hindley 给的反例：`(λx. y) Ω →β y`，`y : σ` 可指派，但左边
  要给 Ω 配型——不可。**归约后的项可指派，归约前的项未必**：
  这就是「β-展开会破坏类型」的经典事实（λ 抽象是安全的，应用
  的逆不安全）。
- **可指派项恰是无类型世界里的「良行为」子集**：它们都是强
  规范化的（SN 对 Curry 式也成立，借道 Church 式的擦除/装饰）。

## 4.5 从 PT 到算法 W：一步之遥

PT 处理的是**单态**指派。ML 的 `let f = λx. x in f 7` 要求 f 在
`int → int` 和 `bool → bool` 两处使用——单态做不到，需要**量化**：
给 f 的主类型配上 ∀（`∀a. a → a`），每次使用时**实例化**。这就是
Milner 算法 W 的 `generalize`/`instantiate` 二重奏。但要小心
`let rec` 与值限制（value restriction）的坑——那是 TAPL 第 22 章
与 ML 语言的故事了。真正的类型层量化（System F）下一章正式登场，
届时可以看到 `∀` 不只是推断引擎的内部技巧，而是一等公民的类型。

> **坑位速记**
> ① Lean 的 WF 递归（`termination_by` + `decreasing_by`）能过终止
> 检查，但 `WellFounded.fix` 难被内核 defeq 展开——`by rfl` 断言
> 会卡；改燃料/结构递归即可（本文件 `solve` 的实测教训）；
> ② `def f (fuel : Nat) : T → U | 0, _ => ...` 里 fuel 在冒号前
> **不参与模式匹配**——`| 0, _` 的 0 匹配的是 T；要匹配 fuel 得
> 写 `def f : Nat → T → U`；
> ③ 主类型的**字面**依赖新鲜变元的发号顺序（绑定器先、应用结果
> 后），断言值要按机器输出写，与教材字母只保证 α-一致；
> ④ 函数式代换（`Nat → Ty`）比关联表好写好证明，代价是不能
> `deriving Repr`——但最终断言比较的是 Ty，不受影响。
