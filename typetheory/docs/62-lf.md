## 62.1 元理论七律与六律（书 6.1）

**上下文七律**（定理 6.1）——关于判断的「形状合法性」：

| # | 名称 | 内容 |
|---|---|---|
| 1 | FV 基本性质 | 可推导判断的自由变量都在上下文里、两两不同 |
| 2 | 上下文合法性 | Γ ⊢ J ⟹ ⊢ Γ |
| 3 | 类型反射 | Γ ⊢ a:A ⟹ Γ ⊢ A type |
| 4 | 置换 | 上下文换序（等式保证下）可推导性保持 |
| 5 | 弱化 | Γ ⊆ Γ′ ⟹ 可推导性保持 |
| 6 | 强化 | 无用假设可删（书注：证明通常**相当复杂**） |
| 7 | 替换（Cut） | Γ,x:A ⊢ b 与 Γ ⊢ a:A ⟹ Γ ⊢ [a/x]b |

**计算六律**（定理 6.2）——关于归约与等式：

| # | 名称 | 内容 |
|---|---|---|
| 1 | 定义性等式 ≡ 变换等式 | a=b:A 可推导 ⟺ 计算相通 |
| 2 | Church–Rosser | 变换相等者可归约到共同后继 |
| 3 | 主题归约 | 计算不改类型（42 章 preservation 已证！） |
| 4 | 强正规化 | 一切计算终止 |
| 5 | 可判定性 | 类型检测/定义性等式可判 |
| 6 | 等式反射 | 空上下文下命题等式 ⟹ 定义性等式 |

这两张表是**证明助手的存在理由**（书 5.1）：de Bruijn 标准
（证明检查器小到可以人工审读）靠的是判断可判定；实现里
「计算不再查类型」靠主题归约——75 章的 Lean 元定理组将
以 de Bruijn 编码把其中数律做成完整机器证明；本章 Coq 件
补弱化引理的现场：

```coq
Lemma mweaken : forall G t T, mhas G t T ->
  forall G', incl G G' -> mhas G' t T.
Proof.
  induction 1; intros G' HI.
  - constructor. apply HI. assumption.
  - constructor. apply IHmhas.
    intros y Hy. destruct Hy as [Heq | inG].
    + left. exact Heq.
    + right. apply HI. exact inG.
  - econstructor.
    + apply IHmhas1. exact HI.
    + apply IHmhas2. exact HI.
Qed.
```

名字版（变量为自然数、上下文为表）三行半；**de Bruijn 版
要 mlift 全深度泛化**——书 6.1 脚注说「强化引理的证明通常
相当复杂」，复杂性的实体就是指标的提升管理（件里以注释
保留 de Bruijn 版的 mlift 骨架作对照）。

## 62.2 逻辑框架 LF（书 6.2.1–6.2.2）

LF 本身是一个小依赖类型系统——**元语言**。它的「类型」叫
**类别（kind）**：

> K ::= TYPE（目标论所有类型的类别）| el(A)（A 的对象们）
> 　　| (x:K)K′（依赖函数类别）

判断五式（Γ valid / K kind / k:K / K=K′ / k=k′:K），对象是
**函数运算** `[x:K]k`——满足 β **和 η**（`[x]f(x) = f`）。
η 这里有深意：LF 的函数运算是「数学定义」的形式化身（书引
文献 [125] 第 170 页），定义自然外延；而**目标类型论的 λ 不
满足 η**（29 章：η 是命题等式、非判断等式）——元语言比
对象语言**外延**，一层之差各司其职。

**用 LF 定义类型论** = 引常量 + 计算等式。引常量 `c : K`
意味着加一条规则；等式 `k = k′ : K` 意味着加一条计算规则。
**表 6.1（判断编码）**是整个方案的枢纽：

| 目标论判断 | LF 判断 |
|---|---|
| ⊢ Γ | Γ ⊢ • |
| Γ ⊢ A type | Γ ⊢ A : TYPE |
| Γ ⊢ a : A | Γ ⊢ a : el(A) |
| Γ ⊢ A = B | Γ ⊢ A = B : TYPE |

Prolog 件 `ex62_lf.pl` 把它做成**可执行的微缩检查器**——
kind_of/lfk 双判断 + 常量表。例 6.1 的 Nat 组逐条过检：

```prolog
lf_const(nat_c, ktype).                          (* Nat : TYPE *)
lf_const(zero_c, kel(c(nat_c))).                 (* 0 : Nat *)
lf_const(succ_c, kpi(n, kel(c(nat_c)), kel(c(nat_c)))).
lf_const(e_nat, kpi(cc, kpi(n1, kel(c(nat_c)), ktype), …)).
```

第 2 章要一整页的「Nat 的形成/引入/消去/计算四组规则」，
在 LF 里是**四行常量声明**（E_Nat 的类别就是归纳原理的
形状）。Σ 组同理（Σ/pair/π1）。「规则即常量、计算即等式」
——定义类型论的终极压缩。

## 62.3 归纳模式（书 6.2.3）

现代类型论的归纳类型有一般规律：**归纳模式（inductive
schema）**。核心定义两个：

> **基本类别** K ::= el(A) | (x:K)K′——**不含 TYPE**！
> **严格正算子** Pos(X, (x₁:K₁)…X)：X 只出现在最右端的
> 正位置（不被任何箭头穿过）

归纳模式 Φ ::= X | (x:K)Φ₀ | (Φ)Φ₀——**(TYPE)X 与
((A)TYPE)X 被排除**，否则引入不该有的类型乃至悖论。Coq 的
Inductive 检查器就是这道防线的实现——机器件的 Fail 见证：

```coq
Fail Inductive BadNeg : Type :=
| kNeg : (BadNeg -> nat) -> BadNeg.   (* X 在负位：Non strictly
                                         positive occurrence！ *)
```

而正位的全家福畅通——书 6.3.1 的 **12 例**逐一落地
（ex62_lf.v）：0/1/2/Nat/List/→/Π/×/Σ/+/BT/**W**。M[Φ₁,…,Φₙ]
的引入算子是构造子、消去算子是自动生成的 _rect 归纳原理
（`Check NatL_rect` / `Check WL_rect`——W 类型的归纳原理
Coq 白送，因为严格正所以合法）。

## 62.4 UTT 与强制子类型的 LF 形式化（书 6.3.1–6.3.3）

**UTT 三件套**在 LF 里的化身（图 6.2）：Prop 空间五常量
（Prop:TYPE / Prf / ∀ / Λ / Ev + 一条等式）、归纳类型
M[Φ] 三件（6.7–6.10）、直谓宇宙 Typeᵢ 五件（6.11–6.15，
含解码函数 Tᵢ 与 TYPES_Γ **直谓性条件**——归纳类型的名称
只能落在「够得着」的层）。53 章的每一件（Prop⊂Type₀、
塔斯基解码、提升算子）在此各就各位。

**强制子类型**（6.3.2）：三级系统——T[C]°（只加子类型
判断与结构规则，保守）、T[C]（升级到子**类别**，图 6.4 的
el 同余与逆变传播）、T[C]*（应用位打星 `f * k₀` 标记省略
点）。**合谐性定义 6.8**（任意两型间至多一强制）是**定理
6.4 保守扩张**的前提——60 章的机器面（ambiguous-paths 警告
与展开无痕）在此升格为元定理。

**标记类型论** TS[C]（6.3.3）：LFs（带标记的 LF）+ 标记内
子类型条目——**定理 6.5**：把标记 Δ 翻译成「Γ_Δ + C_Δ」
（上下文部分与子类型判断部分），TS[C] 的 ⊢_Δ 就被 T[C∪C_Δ]
**表示**——65 章 Section 化身的正式后盾：局部强制的语义
就是「把局部条目收集成局部判断集」。

## 62.5 意义理论之辩（书 6.4）——哲学尾声

证明论语义（inference semantics）的梦想：**摆脱元语言**，
让逻辑系统自我辩护。Prawitz 的泛证明论与 Martin-Löf 的
意义理论共享一个基本想法：

> 条件判断 Γ ⊢ J 的意义 = 其**全部封闭实例** [γ/Γ]J 的
> 意义（γ 取遍 Γ 的所有代入）

书给出清醒的清算（脚注 (6.17) vs (6.18)）：封闭实例语义
**既弱于又强于**判断语义——弱者：`x:0 ⊢ 0:Bool` 不正确但
其封闭实例集为空（0 无封闭对象）所以「全真」；强者：判断
可判定而「全部实例」可能不可判定。所以「意义解释 = 类型
检测的过程」**至今仍依赖元理论**（终止性、可判定性）——
书 6.4 末的坦白：「摒弃元理论的愿望能否实现相当渺茫，但
仍不失为一个值得为之努力的美好愿望」。这是全书的哲学
收官：类型论的**可判定性**（53 章开场的三特征之一）既是
工程资产也是意义理论的基石——而它自己住在元理论里。

## 62.6 一页总结（本章的三个公式）

> LF：类别 TYPE/el(A)/(x:K)K′ + 函数运算（有 η！）；定义
> 类型论 = 常量（规则）+ 计算等式（计算）；表 6.1 四行
> 编码把判断搬进元语言。
> 归纳模式：基本类别不含 TYPE、严格正性——Coq 的 Inductive
> 检查器就是防线（负位 Fail 见证）；12 例全家福 = 检查器
> 的通行证。
> 七律（上下文）六律（计算）是证明助手的存在理由；合谐性
> ⟹ 保守扩张（6.8⟹6.4）；标记的局部强制 = Γ_Δ/C_Δ 翻译
> （定理 6.5）。

> **坑位速记**
> ① Coq 8.20 对空/单点 Inductive 自动降 Prop 并发**弃用
>   警告**——`Unset Automatic Proposition Inductives.`
>   压制（8.20 实测；未来版本将成默认）；
> ② `nth_error_Some` 在 8.20 是**当且仅当**（`<> None
>   <-> n < length`）——要用 proj1 拆方向，别按旧版单边
>   引理 apply；
> ③ 名字版弱化三行半、de Bruijn 版要全深度 mlift 泛化——
>   教学件选名字版并注明复杂性去向（强化引理更难，书
>   6.1 脚注同款警告）；
> ④ Prolog 微缩检查器里「依赖类别的真替换」（[k′/x]K）
>   是坑——Σ(A,B(x)) 的名称应用涉及绑定变元的替换，教学
>   版以 ktype 占位并注明（LF 的 β 是完整版的功课）；
> ⑤ kind_ok 检查**开类别**（含绑定名）时伪常量出作用域
>   （kel(c(a)) 里的 a 是绑定名不是全局常量）——只查外层
>   形状（kpi(_, ktype, _)）是诚实的降级。
