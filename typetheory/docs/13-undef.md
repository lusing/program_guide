# 13 未定义性：部分函数世界的逻辑

> 对应读本：Farmer《Simple Type Theory》3.4 节（TATU 三原则）、
> 6.4 节（定义性记法）、第 7 章（β-归约与非法 β-归约）。
> 代码：`examples/13_undef/`——Lean 侧（V1–V7 机器 + 定义性记法层 +
> 非法 β 双反例 + 例示守卫）；Prolog 侧（强 Kleene 三值逻辑 vs
> TATU 的对照实验室，1/0 四连断言）。

12 章的语义已经允许「无定义」：`∆ c0` 没有值、描述算子二义时
落空。本章把这盏灯拧到最亮：**数学实践里人人都在用、却很少明说
的「传统未定义性进路」（TATU, Traditional Approach to
Undefinedness）**——它是什么、为什么不是三值逻辑、β-归约要在它
面前让出哪两步。

## 13.1 TATU：三原则与四大好处

无定义表达式在数学里无处不在：`√−2`、`1/0`、`f(x)` 当 `x ∉
dom(f)`、二义的描述「使 P 成立的那个 x」。TATU（Farmer 3.4，
参考文献 45）把数学家对待它们的惯例提炼成三原则：

> **原则一**：原子表达式（变量、常数）永远有定义。
> **原则二**：复合表达式可以无定义——应用 `f(a)` 在 `f↑`、
> `a↑` 或 `a ∉ dom(f)` 时无定义；描述算子无满足者或多满足者时
> 无定义。
> **原则三**：**公式永远真或假**，因此永远有定义——于是「无定义
> 的谓词应用」按惯例取 **f**。

原则三是整个进路的定音锤：数学家强烈拒绝第三真值，「直觉上
无定义的谓词应用」只好二选一，f 是更好的选择。12 章的 V3/V4
条款就是它的语义化身。文献里这类逻辑叫**负自由逻辑**（negative
free logic；「自由」指摆脱了存在假设），首个发表的是 Schock
（1968）；Andrews 的 Q0 略改语构与语义即得 LwTU 版 Qu0，
Alonzo 是同族。

TATU 的四大好处（3.4 节）值得整段体会：**含无定义成分的陈述
仍然有意义**（`∀x. 0≤x ⇒ (√x)² = x` 即使代进 −2 也有真值）；
**定义域可以隐含**（用 ≃ 定义 `k(x) ≃ 1/x + 1/(x−1)` 无需声明
定义域）；**定义性假设可以隐含**（`x/y = z ⇒ x = y·z` 不必写
`y≠0`——前提里的 `x/y` 已经替你说了）；**值可以用描述算子隐含
定义**（`√x ≃ Iy. 0≤y ∧ y²=x` 直接造出部分平方根函数）。
此外子类型、有限序列、递归定义函数都能在此框架里自然形式化
——它是 15 章「理论」全部实用性的地基。

## 13.2 双等式：`=` 与 `≃`

一条分界线切出两种「相等」（3.4 节）：

> `a = b`：双方**都有定义**且同值；
> `a ≃ b`（准等式 quasi-equality）：`a = b`，或**双方都无定义**。

书的样板四连（用 1/0 当无定义样本），机器在 Prolog 侧用缺键的
除法表复刻（`ex13_undef.pl`）：

```prolog
cond(5) :- tfml(eq(over(1,0), num(1)), f).        % 1/0 = 1   假
cond(6) :- tfml(eq(over(1,0), over(1,0)), f).     % 1/0 = 1/0 假
cond(7) :- tfml(quasi(over(1,0), num(1)), f).     % 1/0 ≃ 1   假
cond(8) :- tfml(quasi(over(1,0), over(1,0)), t).  % 1/0 ≃ 1/0 真
```

第三行是 12 章埋的刺：`⊥ = ⊥` 为**假**。第四行给出真正的「无
定义世界的相等」：`⊥ ≃ ⊥` 为真。记法层（书表 6.4）全部可定义：

```text
⊥_o = F_o         ⊥_α = Ix:α. x ≠ x（12 章用纯等式编码过）
∆_{α→β} = λx:α. ⊥_β   （空函数）
A↓ := A = A      A↑ := ¬(A↓)
A ≃ B := (A↓ ∨ B↓) ⇒ (A = B)
```

Lean 侧的 `dn/up/quasiEq` 三个组装器就是最后三行的直译
（`ex13_undef.lean`），断言电池覆盖：`⊥↑` 真、`∆` 有定义、
`∆ c0` 无定义、含 `∆` 应用的公式照样两值。

## 13.3 分野：TATU 不是三值逻辑

「部分函数 + 真值缺」最容易想到的是 Kleene 三值逻辑（K3）：
引入第三值 u，`u∨u = u`、`u = u = u`。Prolog 实验室把两套语义
并排跑：

```prolog
chk(2, 'K3：A⇒A 在 u 处塌掉（u⇒u = u ≠ t）').   % 连同一律都不是重言式
chk(13, '分野：同输入 K3 给 u、TATU 给 f').
```

K3 的代价惨重：`A⇒A`、`A∨¬A`、`A∧A` 在 u 处全部塌掉——**连
同一律都不是重言式**。TATU 一寸都不让：公式层永远是古典两值，
u 只住在非布尔表达式层（`1/0` 是 u，`1/0 = 1/0` 是 f）。同一个
输入 `undef = undef`，K3 给 u、TATU 给 f——这一格就是两个逻辑
家族（Kleene/LP 系 vs 负自由逻辑系）的楚河汉界。Lean 侧同样：
公式求值 `evalV` 在 type o 上**结构性不可能**返回 none（V3
兜底 + V4 的 o-落点），原则三是被语构保证的。

## 13.4 非法 β-归约：双反例（书例 7.5）

β-归约定理（7.1）说：**A 有定义且 A 自由换入 B** 时，
`(λx.B)A ≃ B[x:=A]`。两个侧条件各废掉一半——书例 7.5 的两部
机器全复刻。

**反例一：捕获（自由换入失败）**。`F = λx.λy.x`，实参加自由变
量 y。朴素代换 `(λy.x)[x:=y] = λy.y`——y 被绑定器逮住，出来
的是**恒等函数**；而语义说 `F y` 应是**常函数**（把 y 的值常量化）。
Lean 侧专门造了一个命名项小机器演示捕获（`nsub` 故意不避让）：

```lean
def wrongBeta : NTm := nsub "x" argY (.lam "y" (.var "x"))  -- λy.y
example : evalV M13 [.el 0 1] (toDb ["y"] wrongBeta) = some (.fv N N idT) := by rfl
example : evalV M13 [.el 0 1] appFy = some (.fv N N const1T) := by rfl   -- 语义真相
```

y↦1 时一个是恒等、一个是常 1——**朴素 β 把值改了**。解药是
α-换名（7.6：先把绑定器改成新名再代换），03 章的 de Bruijn
表示让这一步免费，这也是本指南从一开始就用指标而不用名字的
回报。

**反例二：无定义实参（A↓ 失败）**。`F ⊥` 的语义按 V4 无定义
（实参↑ 且目标型 ≠ o）；朴素 β 却给出 `λy.⊥ = ∆`——空函数，
**有定义**：

```lean
example : evalV M13 [] (.app Fd botN) = none := by rfl          -- 语义：无定义
example : evalV M13 [] (.lam N botN) = some (.fv N N []) := by rfl  -- 朴素 β：有定义
```

**归约把定义性改了**——这就是 A↓ 守卫存在的理由。命题 7.3 把
它写成正面陈述：`A↑ ⇒ (λx.B)A ≃ ⊥_β`，Lean 侧用
`⊥_{N→N}`（描述算子多满足者版）机器化：

```lean
example : evalV M13 [] (quasiEq (.app Fd botN) botNN) = some (.tv true) := by rfl
```

## 13.5 全称例示的守卫（推论 7.4）

同一块石头第三次绊脚。全称例示的古典形状 `(∀x.A) ⇒ A[x:=t]`
在 TATU 里必须加守卫：

> **推论 7.4**：`((∀x:α. A) ∧ t↓) ⇒ A[x := t]` 有效（t 自由换入）。

机器上把守卫的必要性演成一对事实——取 `A := x ≠ c0`，全称式
`(λx.T) = (λx. x≠c0)` 为**假**（两张表不同）：

```lean
example : evalV M13 [] allNe0 = some (.tv false) := by rfl
example : evalV M13 [] (notc (.eq botN c0)) = some (.tv true) := by rfl
```

——**假全称的 ⊥-实例却是真**（⊥=c0 为假 ⇒ ¬为真）。没有
`t↓` 守卫的例示规则会从可驳前提「例示出」真实例；守卫让前件在
`t = ⊥` 时坍成假，蕴涵空洞成立。加上 05 章 ω 之死（项层自应用）、
10 章类型层循环项，**occurs check / 守卫条件**家族在本指南完成
三连击——每次都是「不加这个检查，机器会一本正经地证明假命题」。

> **坑位速记**
> ① Lean 里 Curry 式两参布尔算子（o→o→o）的值表必须「先吃一参
>   吐一张剩一参的函数表」（`curry2`）；直接拿序对当键的表是
>   o×o→o 的表——typeOf 对得上、求值对不上；
> ② ≃ 的展开是 `(A↓∨B↓) ⇒ (A=B)`——书里这条记法定义抄错
>   极容易把 ∨ 写成 ∧（本章初版实测）；
> ③ Prolog 公式求值器若允许「变量已换成值」的中间形态，必须给
>   叶子值加直通子句（`k3_fml(u,u).`）——否则 not(u) 这类
>   半展开项静默无解；
> ④ `:- encoding(utf8).` 必须**物理第一行**——本轮两次忘在
>   横幅前，中文注释以 GBK 误读报 Illegal multibyte；
> ⑤ Prolog 电池的稳定形态：`chk(N, 描述)` 纯事实 + `cond(N)`
>   纯条件 + main 里 `between + \+ cond`——描述与条件分离，
>   失败信息不丢、无单例变量。
