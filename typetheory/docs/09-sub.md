# 09 弱逻辑与子结构 λ：相关、仿射、线性

> 对应读本：Hindley《Basic Simple Type Theory》6C（弱逻辑）、6D
> （公理式版本）；子结构逻辑全景见 Anderson–Belnap 1975 与
> Girard 1987。
> 代码：`examples/09_sub/`——**Lean 走项侧**（λI/BCKλ/BCIλ 谓词
> 与名角矩阵）；**Prolog 走公理侧**（四系统 Hilbert 式证明搜索，
> 合一即代换）。

08 章的 Curry–Howard 把 λ→ 与直觉主义蕴涵逻辑缝成一体。一个
自然的实验：**把 λ-项的限制（03 章 1D 的三族）套到对应上，得到
什么逻辑？** Hindley 6C 的答案是三种子结构逻辑——相关、仿射、
线性——而 6D 给出它们的 Hilbert 公理版，恰好是组合子 B、C、
I/K/W 的主类型拼图。

## 9.1 三个「弱化」直觉主义（6C1–6C3）

直觉主义自然演绎的 (→I) 规则允许释放（discharge）假设：把
分支顶端的假设「收进」新引入的蕴涵。释放有两种越界用法：

- **空释放**：x 在体内根本没出现，却写成 λx. M——「假装用了」；
- **多重释放**：x 出现 5 次，一次绑定全收下——「无限复用」。

各禁一条，得到三个系统（与直觉主义 Int 的四连同调）：

| 系统 | 禁令 | 一句话哲学 | 项侧（6C5） |
|---|---|---|---|
| **R_**（相关逻辑） | 空释放 | a→τ 可证须 a **真的被用到** | 封闭 λI-项的类型 |
| **BCK**（仿射） | 多重释放 | 假设**不可复用**（non-re-usable information） | 封闭 BCKλ-项的类型 |
| **BCI**（线性） | 双禁 | 每个假设**恰用一次** | 封闭 BCIλ-项的类型 |

相关逻辑的动机（6C1.1）值得整段转述：在一种重要的蕴涵观里，
`a → b → a` **不该可证**——它说的是「a 真则任何 b 推出 a」，
哪怕 b 与 a 毫无语义联系。R_ 是捕捉「相关蕴涵」最早的尝试之一
（Moh 1950、Church 1951 独立发明；可判定）。BCK 的历史同样长
（Fitch 1936 起）。而 BCI 有个显赫的等价身份（6C3.1）：

> **BCI-逻辑恰是 Girard 1987 线性逻辑的蕴涵片段。**

「线性」= 每个资源用恰一次——三十年前的哲学动机与 1980 年代的
线性逻辑、今天的线性类型系统（Rust 的 move 语义！）一脉相承。

## 9.2 精炼 Curry–Howard（6C5）与逻辑格（6C4）

> **定理（Refined Curry–Howard，6C5）**：R_/BCK/BCI 的可证
> 公式恰是封闭 λI-/BCKλ-/BCIλ-项的类型；带前提版同理
> （Γ ⊢ M : τ 且 M 属对应类）。

两个方向的引理都是「直接归纳」（6C5.1：项侧限制经 (·)ᴸ 映射
成释放限制；6C5.2：反向构造 (·)^Λ 的「先异名后按需黏并」自动
落在对应类里）。定理集的关系（6C4）：

```text
BCI ⊆ BCK ⊆ Int        BCI ⊆ R_ ⊆ Int        （BCK 与 R_ 互不包含）
```

「互不包含」的见证公式正是老朋友 `a → a → a`（6C1.2–6C3.2）：
两个直觉主义证明 λx y. x 与 λx y. y **各空放一个绑定器**——
在 BCK 里双双合法（空放不犯规）、在 R_/BCI 里双双被毙。而
体内别无他法（x、y 都是原子，无法都消耗掉），于是 a→a→a
**在 BCK 可证、在 R_ 不可证**。反方向见证是 K：BCK 的公理、
R_ 的非定理。

## 9.3 项侧矩阵（Lean）

三族谓词一行一个（03 章 occurs + 新成员 countFree）：

```lean
def isLI  : Term → Bool                      -- 绑定器至少一次（禁弱化）
  | lam b => occurs 0 b && isLI b | …
def isBCK : Term → Bool                      -- 绑定器至多一次（禁收缩）
  | lam b => countFree 0 b ≤ 1 && isBCK b | …
def isBCI (t : Term) : Bool := isLI t && isBCK t   -- 恰一次 = 线性
```

名角矩阵（全部 `by rfl`，六行断言×三谓词）：

| 封闭项 | λI | BCKλ | BCIλ | 死因 |
|---|---|---|---|---|
| `I = λx. x` | ✓ | ✓ | ✓ | — |
| `B = λx y z. x (y z)` | ✓ | ✓ | ✓ | — |
| `C = λx y z. x z y` | ✓ | ✓ | ✓ | — |
| `K = λx y. x` | ✗ | ✓ | ✗ | y 空绑定：λI/BCI 毙，BCK 放行 |
| `W = λx y. x y y` | ✓ | ✗ | ✗ | y 用两次：BCK/BCI 毙，λI 放行 |
| `S = λx y z. x z (y z)` | ✓ | ✗ | ✗ | z 用两次——S 谁家都不收（1D2.1 原文） |

三行分化样本（a→a→a 的两个证明 p1 = λxy.x、p2 = λxy.y）：

```lean
example : isLI p1 = false ∧ isLI p2 = false := ⟨by rfl, by rfl⟩
example : isBCK p1 = true ∧ isBCK p2 = true := ⟨by rfl, by rfl⟩
example : isBCI p1 = false ∧ isBCI p2 = false := ⟨by rfl, by rfl⟩
```

配合 07 章 2D8（BCKλ ⟹ typable）与 03 章 K-不可定义（λI 内
无 K），这张矩阵就是 6C4 格的机器面。

## 9.4 公理式版本：A-逻辑（6D1–6D2）

四套逻辑历史上都以 **Hilbert 式**问世（6D 开篇）。A-逻辑框架
（6D1）：取一组经典永真的蕴涵公式集 A 当公理，推理规则两条：

- **(→E)** 即 modus ponens（分离规则），`σ→τ` 与 `σ` 推 `τ`；
- **(Sub)** 代换规则，侧条件：只能代换「只出现在公理中的变量」。

6D1.2 有一个值得手工走一遍的小推导——**从 C 和 K 推出 I**
（= I 在 BCK-逻辑中可证，6D6.1 的 (i)）：

```text
(C)  (a→b→c)→b→a→c
      代换 [a↦a, b↦a→b→a, c↦a]
      (a→(a→b→a)→a)→(a→b→a)→a→a          (C 的实例)
(K)  a→b→a
      代换 [b↦a→b→a]
      a→(a→b→a)→a                          (K 的实例)
      ─────────── (→E)
      (a→b→a)→a→a
(K)  a→b→a
      ─────────── (→E)
      a→a                                  (I 得证)
```

两条工程性结论：**(Sub) 尽可推到叶端**（6D2 substitutions-first
引理：Sub 在 (→E) 下方可上提，两个 Sub 可合并——所以「叶端
实例化公理 + 纯 MP」不损失一般性）；**别以为子系统都简单**
（6D1.3 警告：有的 A-逻辑研究了 30 多年可判定性未知；Gladstone
1965 证明每个递归可枚举不可解度都是某个**有限** A 的可证性
问题的度）。

## 9.5 四系统的公理集（6D3–6D6）与公理的独立读法

> Intuitionist = {B, C, K, W}；R_ = {B, C, **I**, W}；
> BCK = {B, C, K}；BCI = {B, C, **I**}

一眼看清格局：**K 与 I 互换**区分相关/仿射；**去 W** 区分
完整/子结构。公理名就是组合子名——它们的主类型（书末主类型表，
05 章机器算过）：B = `(a→b)→(c→a)→c→b`，C = `(a→b→c)→b→a→c`，
I = `a→a`，K = `a→b→a`，W = `(a→a→b)→a→b`。6D6.1 给出每条
公理的独立逻辑读法：

| 公理 | 主类型 | 独立读法 |
|---|---|---|
| (I) | a→a | 蕴涵的**自反**性 |
| (C) | (a→b→c)→b→a→c | 假设可**交换** |
| (K) | a→b→a | **冗余**假设可添加（弱化） |
| (W) | (a→a→b)→a→b | **重复**假设可消除（收缩） |
| (B) | (a→b)→(c→a)→c→b | **传递**/右替换 |

「子结构逻辑」的标准手术清单就在这张表上：R_ 摘 K（禁弱化）、
BCK 摘 W（禁收缩）、BCI 双摘——而 B、C 是四家共享的骨架。

## 9.6 Prolog 实验室：合一即代换

公理模式写成 Prolog 项（类型变元即 Prolog 变量，每次调用
新鲜），四系统各是组合子名单：

```prolog
ax(i, arr(A, A)).   ax(k, arr(A, arr(_, A))).   ax(w, arr(arr(A, arr(A, B)), arr(A, B))).  …
system(int, [b,c,k,w]).   system(r_, [b,c,i,w]).
system(bck, [b,c,k]).     system(bci, [b,c,i]).
```

「叶端实例化公理」就是**目标与模式合一**——(Sub) 规则被
Prolog 的母语吸收；MP 是深度受限的两行递归：

```prolog
prove(Sys, T, _) :- axiom_instance(Sys, T).
prove(Sys, T, D) :- D > 1, D1 is D - 1,
    prove(Sys, arr(A, T), D1),   % 大前提：合一自动落地 σ
    prove(Sys, A, D1).           % 小前提
```

12 格结果矩阵（正格深度 5、反格**有界反驳**深度 4——反格的
真正排除靠 9.2 的定理侧，有界搜索只是机器面证据）：

| | Int | R_ | BCK | BCI |
|---|---|---|---|---|
| I | ✓（C+K 推出，9.4 的推导机器重跑） | ✓ 公理 | ✓（6D1.2 复算） | ✓ 公理 |
| K | ✓ 公理 | ✗ 有界 | ✓ 公理 | ✗ 有界 |
| W | ✓ 公理 | ✓ 公理 | ✗ 有界 | ✗ 有界 |

——恰好是 6D6.1 与 6C4 的全部内容。

### 翻案实录：occurs-check 的第二次显灵

初版 `axiom_instance` 用裸合一（`ax(Cb, T)`），12 格里
「K 不在 R_」一格**搜出了证明**。把证明树打出来看：

```text
c : (q→(p→p)) → (p→(q→p))
    w : (S→S) → (S→(q→(p→p)))     其中 S 被绑成 S = arr(S, …)！
    i : S → S                       （同一个循环绑定）
  MP ⇒ …
MP ⇒ p→(q→p)
```

`W` 的模式 `arr(arr(A, arr(A,B)), arr(A,B))` 与开放目标合一
时，**无 occurs-check 的 Prolog 造出了 S = arr(S, …) 的循环项**
——一个「无穷公式」被当作合法实例放行，整棵证明树随之变形。
修复是三行：

```prolog
ax(Cb, Schema), unify_with_occurs_check(Schema, T).
```

修复后矩阵恰为 6D6.1。这与 05 章的类型推断首尾呼应：**项层
的 ω = λx. x x 死于 occurs check，类型层的伪证明死于同一个
检查**——合一的完整性边界在两层是同一块石头。工程侧的同款
坑在 Prolog 世界著名（SWI 默认关 occurs-check 换速度），而
「用循环项伪造结构」正是 R. A. Kowalski 时代以来的经典事故。

> **坑位速记**
> ① `unify_with_occurs_check/2` 是子结构实验室的**安全带**：
>   裸合一会拿 S = arr(S,…) 的循环项当公理实例（本批翻案
>   实录，伪证明 K∈R_ 的完整病理解剖见 9.6）；
> ② Prolog 子句里只出现一次的变量给 Singleton 警告（构建通道
>   直接判 FAIL）——用 `_` 或 `prove(Sys, T, _)` 消除；
> ③ Lean 的三谓词共用 occurs/countFree 两个度量函数（≥1 / ≤1 /
>   恰 1 = 两个的合取）——别为 BCI 单写第三个计数函数；
> ④ 有界反驳的预算要写进断言名（bounded d4），别让读者把
>   「没搜到」读成「不可证」——语义侧的证明在正文，不在机器。
