## 33.1 子集类型：证据随值走

Nordström 第二部分问：MLTT 全是「全函数」，怎么表达**部分性**
（只对正数有定义的除法、只对非空表有意义的 head）？答案：
**子集类型**——值与证据打包：

```text
{ x : A | P x }  =  Σ(x : A). P x 的命题版
```

三家写法：

```lean
def Pos : Type := {n : Nat // n > 0}
def three : {n : Nat // n > 0} := ⟨3, by omega⟩
def safeDiv (n : Nat) (d : {d : Nat // d > 0}) : Nat := n / d.val
```
```coq
Definition Pos : Type := {n : nat | n > 0}.
Definition pone : Pos.  Proof. exists 1. lia. Defined.
```
```agda
PosSet = Σ[ n ∈ ℕ ] n > 0
one = 1 , s≤s z≤n
```

子集类型把「定义域约束」从文档搬进类型：`safeDiv` 的类型就是
它的前置条件——调用方必须出示 `d > 0` 的证据。反过来，
**前驱函数只能返回裸 Nat**（`pred 1 = 0` 不再正——子集类型
逼你正视定义域塌缩）：Lean 文件里 `posPred : Pos → Nat` 的
返回类型变化就是教学点。

## 33.2 第 17 章的坏消息：弱消去规则

书 17 章先把子集合当**普通原始集合**加入（与其他成集运算
并列）——典则元：「a 是 A 的典则元且 B(a) 真」。立刻撞墙：
「a 的值为典则形」这个要求**不能写成引入规则的前提**（值
的语法形状不是判断），于是引入规则退化为：

```text
子集合-引入 1   a ∈ A,  b ∈ B(a) ⟹ a ∈ {x∈A|B(x)}
子集合-消去 1   c ∈ {x∈A|B(x)},  d(x) ∈ C(x)[x∈A, y∈B(x)]
                ⟹ d(c) ∈ C(c)        （y 不自由出现于 d、C）
```

注意消去规则里 **y 不可用**——证据 b 在结论中消失了。这导致
最想用的命题拿不出来（Salvesen & Smith [90]）：

```text
(∀x∈{z∈A|P(z)}) P(x)        （*）—— 一般不可证！
```

在内涵表述（Id 相等）里，(*) 甚至对某些 P 完全不可证；把
P 取为 Kleene T 谓词的形态后，(*) 在「含上述子集合规则的
任意扩张」中都推不出——**只要**选择公理可证、项可由 Turing
机计算。工程含义直白：**子集元素只能算、不能证**——从
`a ∈ {x∈A|P(x)}` 里取不出 P(a) 的证据。若改用外延 Eq +
全域，则 (*) 对**稳定谓词**（¬¬P(x)→P(x)）成立——又一次
外延换能力的交易（29.3 节的分叉在此重现）。

书 18 章的应对是釜底抽薪：**换语义**——既然「命题即集合」
在子集合处失灵，就造一个新理论，把命题从集合世界里分出来。

## 33.3 第 18 章：子集合理论——命题脱离集合

子集合理论（subset theory）重新解释**全部判断**，而集合
（基本理论中的）成为解释的底座：

> 子集合理论中的一个「集合」A 是一个**配对 (A′,A″)**：
> A′ 是基本理论中的集合（**载体**），A″ 是 A′ 上的命题函数
> （**成员谓词**）。
>
> `a ∈ A` 就是：a ∈ A′ **且** A″(a) true。
> `A = B` 就是：A′ = B′ 且 A″(x) ↔ B″(x)（谓词等价）。
> **`a = b : A` 就是：a = b ∈ A′**——相等只看载体！

三个直接后果：

1. **命题不再是集合**。逻辑常元 &、∨、⊃、⊥、∀、∃、=ₐ
   成为独立的原始常元（其语义翻译到基本理论的集合：如
   `(P ⊃ Q)* = P* → Q*`、`(a =ₐ b)* = Id(A′,a,b)`）——
   这是「Curry–Howard 的局部化」：子集合理论内部用逻辑
   词汇、底层仍由集合实现，但**两套语言不再混用**。
2. **相等不带谓词**。a=b 只要求载体相等——两个元素在
   A″ 上可以证明状态不同？不：成员判断已含 A″(a) true，
   但**相等判断不重复检查**。这为「计算可见、证明隐藏」
   的子集语义铺路（元素的计算行为与它的证据无关）。
3. **上下文可以含命题前提**。`x ∈ C, P(x) true, y ∈ D(x)`
   成为合法上下文形状——判断的解释里，命题前提翻译成
   基本理论的额外居留假设。前提规则因此变成「假设即
   义务」的二元形式。

各成集运算的翻译都带**证明义务**（书 18.6）：

```text
N′ = N，         N″ = (z)⊤                    -- 自然数全员通过
Π 的 ″：f ∈ Π″ ⟺ ∀x, A″(x) true ⟹ B″(x, f x) true
{ x∈A | P(x) }′ = A′，  ″ = (x)P*(x)          -- 概括：谓词直接换岗
```

Π 的成员谓词把「作用保谓词」内嵌进集合语义——子集合理论
里的函数**天生只承诺在子集上定义**。Agda 件里把这个语义
做成最小模型（载体 + 谓词的记录，成员判断与相等判断分离）：

```agda
record SSet : Set₁ where
  field carrier : Set
        mem : carrier → Set      -- 成员谓词（命题）
_∈ₛ_ : (S : SSet) → SSet.carrier S → Set
S ∈ₛ a = SSet.mem S a            -- 成员判断 = 载体元素 + 谓词居留
```

——`mem` 的证据**不进**相等判断，33.2 的（*）困境在这个
模型里看得见摸得着。

## 33.4 extrinsic vs intrinsic：两种证明哲学

同一个「非空表」约束有两条实现路线：

| | 写法 | 约束在哪 | 代表 |
|---|---|---|---|
| **extrinsic** | `{l : List α // l.length > 0}` | 谓词（事后证明） | Coq/Lean 的 sig/Subtype 文化 |
| **intrinsic** | `Vec α (n+1)`（索引族） | 索引（语法即规格） | Agda 文化、19 章 |

二者表达力相当（可互译），工程取向不同：extrinsic 改动小
（换包装）、证明量大；intrinsic 类型即真相、改规格要动骨架。
「非法状态不可表示」在 intrinsic 下是语法事实，在 extrinsic
下是随身证据的检查。真实项目两者混用（Lean 的 Mathlib 里
`Subtype` 与 `Fin`/`Vec` 并存）。书 17–18 章的教训在工程面的
回声：**Subtype 的证据是只写不读的**（Lean 提取时丢掉、
Coq 的 `{x : A | P}` 在 Prop 里证明无关）——「计算可见、
证明隐藏」从理论难题变成了设计选择。

## 33.5 强制子类型（Luo）：不是包含，是记法

《现代类型论的发展与应用》2.5 区分两条线：

1. **包含式子类型**（`A ⊆ B`）：改变语义——集合论的进路，
   类型论里问题成堆（与类型抽象、宇宙冲突）；
2. **强制子类型**（`A ⇒ B`，coercive subtyping，Luo 1999）：
   只是**缩写机制**——`c : A ⇒ B` 是一个函数，在需要 B 的地方
   看到 A 时自动插入，**展开后无痕**（不改变类型论本体）。

工程落点三家三态：

```coq
Record Boxed := mkBoxed { unbox : nat }.
Coercion unbox : Boxed >-> nat.
Compute boxed3 + 1.        (* 4：+ 的 nat 位自动解箱 *)
```
```lean
structure Boxed where unbox : Nat
instance : CoeOut Boxed Nat := ⟨Boxed.unbox⟩
#eval (boxed3 : Nat) + 1   -- ascription 触发 Coe
```
```agda
-- Agda：没有语言级强制。要「把 Boxed 当 ℕ 用」，手写 unbox。
_ = unbox boxed3 + 1
```

Coq 的 `Coercion` 最顺手（还能把记录字段注册成投影强制）；
Lean 的 Coe 家族挂在 instance 机制上、常要显式 ascription
触发；Agda 干脆不做——「读到的就是写下的」，代价是啰嗦、
收益是零隐式插入。

**理论的完整版在 54 章**：包含式子类型为何破坏规范性
（nil(A)、(0,p) 两反例）、CA/CD 双规则的语义、合谐性
（任意两类型间至多一条强制——Coq 亲报 ambiguous-paths
的现场）、保守扩张定理；54–65 章的 MTT 语义学全线以
本节的机制为地基。

> **坑位速记**
> ① Coq 8.20 的 `ltac:(lia)` 在**项位置**系统性失灵
>   （"Cannot find witness"）——子集类型的证据走证明模式
>   （`Proof. exists 1. lia. Defined.`）；
> ② Lean 的 Σ（`(a : A) × B`）两分量必须是 **Type**——
>   Prop 谓词要用 Subtype 记法 `{x // P x}`；
> ③ Lean 的 class 字段访问符带 instance 隐参——当普通函数
>   用（如塞进 CoeOut）时把 class 改 structure；
> ④ 子集类型上的「部分函数」要检查**值域还在子集里**：
>   `pred : Pos → Pos` 对 1 处崩——要么改返回裸值，要么
>   换定义（succPos）；
> ⑤ Agda 里「重建证据比搬运证据省事」：模式匹配出
>   `suc k` 后 `s≤s z≤n` 直接居留（2 * suc k 定义展开即
>   suc 打头）；
> ⑥ (A′,A″) 模型件的字段引用要带记录名限定（`SSet.carrier S`）
>   ——裸 `carrier S` 在 open field 之外不可见。
