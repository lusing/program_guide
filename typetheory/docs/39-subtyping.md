# 39 子类型：包含、算法化与最小类型

> 对应读本：TAPL 书第 15 章（子类型）、第 16 章（元理论）、
> 第 17 章（ML 实现）。代码：`examples/39_subtyping/`——
> Prolog 件 `ex39_subtyping.pl`（声明式/算法化双引擎 + 含包含
> 与最小类型双类型机 + 十对样本的等价检定）、Coq 件
> `ex39_subtyping.v`（声明关系 + 燃料版算法检查器 + **可靠性
> 定理 16.1.5 方向一的完整证明** + 非反对称见证）。

「为什么 `(λr:{x:Nat}. r.x) {x=0, y=1}` 过不了类型检查？」——
书 15.1 的开篇之问。函数明明只用 x，参数多带一个 y 完全无害。
**子类型化**把「一些类型比另一些更精确」形式化：

> **安全代换原则**：S <: T 意为「类型 S 的项可以用在要 T 的
> 上下文里」。朴素语义：S 的值集 ⊆ T 的值集。

## 39.1 包含规则与记录三律（书 15.1–15.2）

类型关系与子类型关系的桥梁是一条**结构规则**：

> **T-Sub**：Γ⊢t : S 且 S <: T ⟹ Γ⊢t : T

子类型关系本身（图 15.1+15.3）：自反 S-Refl、传递 S-Trans、
**S-Top**（Top 是万物之父）、**S-Arrow** 与记录三律——

- **宽度**（S-RcdWidth）：`{l₁:T₁…lₙ₊ₖ} <: {l₁:T₁…lₙ}`——
  **忘掉尾部字段**。「子类型反而字段更多」的直觉校正：字段
  越多约束越紧、值集越小（37 章的「有序记录」立场在此放开
  为「至少含这些字段」）；
- **深度**（S-RcdDepth）：逐字段递归取子型；
- **置换**（S-RcdPerm）：字段次序无关——**它使子类型不是
  反对称的**（前序而非偏序，15.2 末注记；机器见证见下）。

Prolog 件三律逐条对译（声明式部分）：

```prolog
subtype(rcd(SF), rcd(TF)) :- nonvar(TF),        % S-RcdWidth
    length(SF, N), length(TF, M), M < N,
    common_fields(SF, TF).
```

**箭头的逆变**是三律外最重要的一条：S1→S2 <: T1→T2 需要
**T1 <: S1**（参数侧反向）与 S2 <: T2（结果侧同向）。读法：
「接受面宽的函数可以顶替接受面窄的职位」。机器检定（注意
方向—— `{x}→N <: {x,y}→N` 成立、反向不成立）：

```prolog
check("箭头逆变：{x}→N <: {x,y}→N（参数侧反宽）",
       asubtype(arr(rcd([x=natt]), natt),
                arr(rcd([x=natt, y=natt]), natt))),
```

## 39.2 算法化：把不可读的规则翻成程序（书 16.1）

声明式的 S-Refl（结论盖一切）与 S-Trans（**猜中继类型 U**——
无穷搜索）都不是语法制导的——「自底向上读规则」造不出检查器。
这正是第 16 章的全部动机。解法两步：先把记录三律**合并成宏
规则 S-Rcd**（书 16.1.1 的等价改写——宽度+深度+置换一次做完），
再删掉 S-Refl/S-Trans 得到**算法子类型**（图 16.2）：

> SA-Top / SA-Arrow（逆变同前）/ SA-Rcd（T 的每个字段在 S 里
> 找到子型匹配）

三条规则、无重叠、每个递归调用两侧类型都严格变小——
**终止性**（16.1.6）由结构归纳白送。Coq 件把它写成一个
带燃料的布尔函数并**完整证明可靠性**（16.1.5 的方向一）：

```coq
Theorem asub_sound : forall n T S, asub n T S = true -> sub S T.
```

证明里的两个教学点：(1) **逆变交换了参数的角色**——SA-Arrow
的参数检查以 S1 为上界侧，单参数结构递归放不下，燃料编码了
「两侧都变小」的尺寸度量（书 16.1.6 的机器形态）；(2) 记录
分支的可靠性靠 `forallb_forall` 把布尔全称翻回命题全称，再由
`findf_sound` 提取 In 见证。Prolog 侧则用十对样本做**双向等价
检定**（正例两版都过、负例两版都拒——16.1.5 的机器面）：

```prolog
findall(ok, (sample_pair(S, T),
             (  subtype(S, T) -> asubtype(S, T)
             ;  \+ asubtype(S, T) )), Oks),
```

## 39.3 算法类型化与最小类型（书 16.2）

T-Sub 同样不可读（裸元变量 t 盖一切结论）。**算法类型化**把
每条规则改成「给项计算**最小类型**」（最多信息的类型），
T-App 处用算法子类型检查参数。定理（16.2）：算法可类型化
⟺ 声明式可类型化；且算法给每个可类型化项**惟一**的 минimal
类型——破坏惟一性的正是 T-Sub 本身（声明式下一个项可以有
无穷多个类型）。Prolog 件双引擎并载，机器见证双版本给同一
答案 + 算法版对 `{x=1,y=2}` 只给单解：

```prolog
check("最小类型的惟一性：算法版单解",
       findall(T, atypeof(rc([x=zero, y=zero]), [], T), [_])),
```

**合类型**（join，16.3）与 **Bot**（16.4）是元理论的两个续章：
`if t then t₁ else t₂` 的两分支类型不同时需要一个最小上界
（合类型）——这是含 if 的子类型语言的真正难点；**Bot**（万物
之子）给 error 一个紧致类型（37/38 章预告的兑现：`error : Bot`
随 T-Sub 升到任何类型——「无穷多类型折成一个」的第一种方案，
第二种是 45 章的 ∀X.X）。

## 39.4 ML 实现（书 17）与强制语义（15.6/15.7）

书 17 章把算法子类型/算法类型化写成 OCaml——本指南的对应物
就是本章的两个机器件（Prolog 双引擎 + Coq 检查器）。15.6 的
**强制语义**（coercion semantics：子类型化也可编译成「运行时
转换函数的插入」——如把 `{x,y}` 忘成 `{x}` 是投影函数）给出
子类型的另一种读法：**包含语义**（值不动、视角变）vs **转换
语义**（值被转换）——两者在记录/函数上等价，在高阶场合
（15.7 的交叉类型 intersection types）开始分家。与 33 章
（MLTT 子集类型）和 Luo 的强制子类型（33 章的第三种立场：
「不是包含，是记法」）三点对照：子类型的语义光谱从「纯视角」
到「真计算」。

## 39.5 一页总结（本章的三个公式）

> 声明式 = 三律 + Refl/Trans/Top + T-Sub——**可读不可算**。
> 算法化 = SA 三条 + 最小类型——**可算且等价**（16.1.5/16.2）。
> 记录越多越子、箭头逆变、Top 万物之父、（Bot 万物之子）。

> **坑位速记**
> ① Prolog 声明式子类型的 S-Trans 是**无界搜索**——负例
>   直接栈爆/发散（本批实测），机器件只装直推规则+算法版
>   对照——这正是书 16 章算法化的动机的「事故现场版」；
> ② 记录三律的子句要加 **nonvar(TF) 模式守卫**——T 侧未定时
>   `length(TF, M)` 会造出无界列表（本批实测 1GB 栈爆）；
> ③ 投影定型别走 `subtype(S, rcd(未定))`——**开箱版**
>   dtypeof_rc 直接取字段表绕开无界模式；
> ④ Coq 燃料检查器的燃料耗尽分支返回 false——**可靠性**
>   （asub = true → 声明式）不受影响，完备性方向需要
>   「燃料足够大」的补充条款（20 层对示例语言绰绰有余）；
> ⑤ Coq `<:` 自定义记号与列表 `;` 记号**相互作用**会错位
>   解析（实测量子错乱）——直接写 `sub S T` 最稳；
> ⑥ iff 引理（forallb_forall）要用 **rewrite** 不是 apply；
> ⑦ `destruct … eqn:Hf` 后 match 型假设**不会自动归约**——
>   `cbn in H; rewrite Hf in H; cbn in H` 三连是标准动作
>   （38 章坑位④的子类型版）；
> ⑧ 逆变方向的样本极易写反——`{x,y}→N <: {x}→N` 是**假**
>   的（参数侧要求 {x} <: {x,y} 不成立）；正确样本
>   `{x}→N <: {x,y}→N`（本批第一版就写反了）。
