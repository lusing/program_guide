# 06 等式规则与语义完备性

> 对应读本：Hindley《Basic Simple Type Theory》第 4 章全部（4A 等式
> 规则；4B 语义与完备性）。λ-模型的完整理论见 Barendregt 1984
> Ch. 5 与 HS 86 Ch. 11。
> 代码：`examples/06_eqsem/`——**Lean 走语构**（Eq 规则机器化为
> 「给范式配型」）；**Prolog 走语义**（4B 的有限结构实验室：
> 类型解释/外延性/组合完全性探针）。

05 章留了一个遗憾：类型集合不是转换不变量——`(λx. y) Ω →β y`，
`y` 有类型而左边没有。「主体扩张失败」说的是 β-展开不保类型。
本章做最直接的补救试验：**把「=β 相等」直接做成一条类型规则**，
然后看看我们付出什么、得到什么。付出的清单里有两件意外的东西：
可判定性没了、推导结构没了；得到的则是一整套**语义**——λ-模型、
类型解释、可靠性、完备性——简单类型论自己的「模型论」。

## 6.1 Eq 规则：一行定义

在 TA_λ 的两条规则（→E、→I）之上加第三条（Hindley 4A1）：

```text
(Eqβ)   Γ ⊢ M : T     M =β N
        ──────────────────────
        Γ ⊢ N : T
```

（把 `=β` 换成 `=βη` 得到 TA_λ+βη。）名字读法：**类型随等式走**。
若 `M` 配得型 `T` 而 `M` 与 `N` β-相等，则 `N` 也配得 `T`。

立刻看主角出场。取

```text
P = (λz. I) Ω        其中 I = λx. x，Ω = (λx. x x)(λx. x x)
```

P 一步 β 缩到 I。在 TA_λ 里 P **不可指派**（实参 Ω 进约束表后
occurs check 拒绝——05 章的死法）；在 TA_λ+β 里它是标准的推导：

```text
⊢ I : a → a          （→I 两次）
I =β P               （一步 β）
────────── (Eqβ)
⊢ P : a → a
```

机器面（Lean 文件的主秀，全部 `by rfl`）：

```lean
example : principal P = none := by rfl                  -- TA_λ：拒绝
example : eqTypable? 50 P = some (arrow (tvar 0) (tvar 0)) := by rfl
                                                       -- TA_λ+β：放行
```

## 6.2 两张账单（4A1.3）

免费的午餐不存在，Hindley 把代价列得很清楚：

- **(i) Eq 不可判定**。`M =β N` 本身不可判定（这是 λ 演算的经典
  定理），所以没有算法能判定 `(Eq)` 的前提。TA_λ+β 的可指派性
  因此**不可判定**（4A10 还会再算一笔总账：它等价于「是否 =β I」）。
  对照 TA_λ：主类型算法是终止的判定程序。
- **(ii) 推导结构定理失效**。05 章的推导树形状由项的形状决定
  （subject-construction）；`(Eq)` 一进来，推导里就有了「跳线」，
  树形不再反映项形。连 `Subjects(Γ) ⊇ FV(M)` 这种基本引理都会翻车。

初看是重创。但本章的主定理说的是：**(ii) 没有看上去那么糟**。

## 6.3 等式后置定理（4A2）

> **定理（Equality-postponement）**：TA_λ+β[η] 中任何推导都可以
> 改写成 **(Eq) 只出现在末尾** 的推导。即 Γ ⊢ M : T 蕴涵存在
> M′ =β[η] M 使 Γ ⊢noeq M′ : T。

证明是**局部重排**的汇编，三种「(Eq) 在别的规则上方」的局部
形状各给一种交换：

1. (Eq) 在 (→E) 上方：先做左边的应用、把两个 (Eq) 挪到结论层；
2. (Eq) 在 (→I) 上方：抽象与等式的换序——`λx.P =β λx.P′` 当
   `P =β P′`（等式兼容抽象）；
3. (Eq) 叠 (Eq)：传递律合并成一个。

反复施行，(Eq) 步就像气泡一样**冒到推导顶部**。整个证明用到的
事实只有「等式兼容应用与抽象」两条——书上特意点出（4A2.1），
这正是 03 章交换引理的推导版镜像。

## 6.4 WN 有、SN 无（4A3）

把后置定理与 05 章的 WN 拼起来：

> **弱规范化定理（TA_λ+β[η] 版，4A3）**：每个可指派项 M 都有
> β[η]-范式 M*，且 **Γ ⊢ M : T ⟺ Γ ⊢noeq M* : T**。

后一个等价是全章的枢纽：**TA_λ+β[η] 无非是「给范式配型」的
理论**（4A8 的原话释义）。两个机器实例：

```lean
-- Ω 无范式：Eq 也救不了（4A3 的必要条件在机器上的样子）
example : eqTypable? 50 Omega = none := by rfl
-- K Ω 的范式 λy.Ω 里的 Ω 永远缩不完——同因
example : eqTypable? 50 (app K Omega) = none := by rfl
```

**警示（4A3.1）**：WN 不能加强成 SN。主角还是 P：P =β I 可指派，
但 P 内部藏着 Ω——**存在无限归约序列**（先缩 Ω 永远缩不完）。
可指派 ≠ 一切归约都停：normal order 会停（有范式必达），
「乱序」可以跑 forever。「有范式」与「所有路径终止」的差别，
在这里第一次成为定理而不是直觉。

对封闭项还有个干净的总结（4A5）：

> Types_β(M) = Types_β(M*β) = Types_noeq(M*β)（βη 版同理）。

**M 的全部类型 = M 的范式的全部类型**。机器上用「实例」检查复述
（主类型定理说 Types = 主类型的替换实例集）：

```lean
-- (σ→σ)→(σ→σ) 是 t0→t0 的实例；σ→τ 不是（两边必须同一个 σ）
example : (matchInst 20 ((t1→t1)→(t1→t1)) (t0→t0)).isSome = true := by rfl
example : matchInst 20 (t1→t2) (t0→t0) = none := by rfl
```

## 6.5 TA_λ+β[η] 的主类型（4A7）与 βη 的收紧效应

> **PT 定理（TA+β[η] 版）**：可指派项有主类型，且 = 其 β[η]-范式
> 在 TA_λ 里的主类型。

这就是 `eqTypable?` 的实现原理——先求范式再跑 05 章的 PT：

```lean
def eqTypable? (fuel : Nat) (t : Term) : Option Ty :=
  principal (nfBeta fuel t)
def eqTypableEta? (fuel : Nat) (t : Term) : Option Ty :=
  principal (nfBetaEta fuel t)
```

βη 版有个漂亮的对照样本 `M = λg. λx. g x`：

- TA_λ：主类型 `(t1→t2) → (t1→t2)`——「g 必须是函数」的过度
  约束（x 被原样转发，约束生成器不知道）；
- TA_λ+βη：βη-范式是 `λg. g`，主类型 `t0 → t0`——**更一般**。

```lean
example : principal M = some ((t1→t2) → (t1→t2)) := by rfl
example : eqTypableEta? 50 M = some (t0 → t0) := by rfl
```

且 `(t1→t2)→(t1→t2)` 是 `t0→t0` 的实例、反之不是——**Eq 把类型
集合严格放大**。语义侧（6.9）会告诉我们为什么 βη 版需要**外延**
模型：η 本来就是外延性公理（03 章）。

## 6.6 不可判定性总账（4A10）

> **定理**：没有算法判定任意 Γ、M、T 是否 Γ ⊢β[η] M : T。

证明三行：取 Γ = ∅、T = a→a。若 ⊢β M : a→a，由 4A3 取范式 M*
（封闭、β[η]-范式、noeq 配型 a→a）；封闭 βη-范式的指派树只能是
**λx. x 的形状**（对 a→a 而言）。于是

```text
⊢β M : a→a   ⟺   M =βη I
```

而「M 是否 =β I」不可判定（λ 演算标准结果）。判定器若存在，
就能判定 convertibility-to-I——矛盾。∎

（机器面只能验证前半段的实例：`eqTypable? 50 P = some (t0→t0)`
且 P =β I。不可判定性本身没有 witnesses，只有定理。）

## 6.7 语义登场：λ-模型（4B1–4B4）

到此为止语法管家的账算清了。Hindley 现在换一个视角：**给 TA_λ+β
一个塔斯基式语义**——「Γ ⊢ M : T」什么时候在某个数学结构里
「真」？

**λ-模型**（4B2）是个三元组 𝒟 = (D, ·, ‖·‖)：

- D 是**至少两元**的集合；`· : D × D → D` 是一个全的应用运算；
- ‖·‖ 给每个项在每个环境下配一个 D 中元素（4B1：环境 E 给每个
  项变量配 D 元素），满足六条：
  1. `‖x‖E = E(x)`（变量查环境）；
  2. `‖P Q‖E = ‖P‖E · ‖Q‖E`（应用即点乘）；
  3. `‖λx.P‖E = ‖λx.Q‖E`，若对所有 d 有 `‖P‖[d/x]E = ‖Q‖[d/x]E`
     （**外延条款**：点行为相同则解释相同）；
  4. ‖M‖E 只依赖 E 在 FV(M) 上的值；
  5. α-等价项解释相同；
  6. （β-条款的另一面：见 4B4。）

**外延模型**（4B3）：`∀e (d1·e = d2·e) ⟹ d1 = d2`。

两条分界定理（4B4）把模型类与等式理论对齐：

> 每个 λ-模型满足 β-相等（M =β N ⟹ ‖M‖E = ‖N‖E）；λ-模型
> 外延 ⟺ 它满足 βη-相等。

这一段是「语义版的 03 章」：η 在语义侧的名字叫外延性。

**λ-模型存在吗？** 存在，但不平凡——最简单的构造是**项模型**
（4B7，6.9 节）。Prolog 实验室先做一个反方向的实验：随手拿一个
有限应用结构 (D,·)，它**不配**当 λ-模型——连 K 和 S 都没有家：

```prolog
check("no K-like element in D",
      \+ ( d(Kk), forall( (d(D1),d(D2)),
                          ( app(Kk,D1,C1), app(C1,D2,D1) ) ) ))
check("no S-like element in D",  …同款… )
```

三元素 D 里搜遍找不到 `k` 使 `k·d1·d2 = d1`——**组合完全性**
（每个 λ-项都有化身）是 λ-模型的硬门槛，不是白送的。（有趣的
是：恒等**有**化身——表里 `a1·e = e`。孤立常元容易，成套的组合
子体系才要模型结构。）

## 6.8 类型的解释：箭头就是 modus ponens（4B5–4B6）

λ-模型解释**项**；类型这样解释（4B5）：类型变量指派为 D 的子集
（赋值 V），然后

```text
‖σ → τ‖V  =  { d ∈ D : ∀ e ∈ ‖σ‖V,  d · e ∈ ‖τ‖V }
```

**请盯着这个定义看三十秒**：`d ∈ ‖σ→τ‖` 说的就是「d 把 ‖σ‖ 的
每个元素送进 ‖τ‖」。于是 (→E) 的**可靠性由定义直接成立**——
d ∈ ‖σ→τ‖ 且 e ∈ ‖σ‖ 则 d·e ∈ ‖τ‖，这不是定理，是箭头解释的
展开式。Prolog 实验室在具体结构上枚举验证：

```text
||p->q||  = [a0,a1,a2]     （p={a1}，q={a1,a2}：三元素全合格）
||p->p||  = [a1]           （只有 a1 把 a1 送回 a1）
ok   (->E) soundness by construction
```

空类型的两件奇观也值得一趟：

```text
||r->p|| = [a0,a1,a2]      （前提 ‖r‖=∅：空洞前提人人合格）
||p->r|| = []              （要送进空集：无人胜任）
```

——r→p 人人居留而 p→r 无人居留，「空」在语义侧的滋味与 17 章
⊥ 的荒谬模式遥相呼应。

**满足与有效**（4B6）：`M : T` 被 (E, V) 满足 = `‖M‖E ∈ ‖T‖V`；
`Γ ⊨ M : T` = 凡满足 Γ 的 (E,V) 都满足 M:T；`⊨β`/`⊨βη` 分别取
遍全部 λ-模型/全部**外延** λ-模型。

## 6.9 项模型与完备性（4B7–4B9）

> **项模型 TM_β**：D = 全体 β-等价类 {[M]β}；应用定义
> `[M]β · [N]β = [M N]β`；解释 `‖M‖E = [M[Q_i/x_i]]β`
> （E 把 x_i 送到 [Q_i]β）。TM_βη 同构，改用 βη-类。

「用语法本身当论域」——塔斯基语义的标准起手式。TM_βη 天生
外延（条件 3 直接成立）；TM_β 不外延（`[λx.M x]β ≠ [M]β`，
虽然两者点行为相同——这正是 η 该抹平的差别）。

> **可靠性（4B8）**：Γ ⊢β[η] M:T ⟹ Γ ⊨β[η] M:T。
> **完备性（4B9）**：Γ ⊨β[η] M:T ⟹ Γ ⊢β[η] M:T。

可靠性证明是对推导的结构归纳，每条规则对应 6.7–6.8 的一条
定义条款（(→E) 就是箭头定义；(Eq) 就是「模型满足 =β[η]」）。
完备性证明的骨架值得记：**只用一个模型**——TM_β。把 Γ 扩充成
Γ⁺（每个类型配无穷多新鲜变量），定义关键赋值

```text
V₀(a) = { [P]β : Γ⁺ ⊢ P : a }
```

然后按类型归纳证明**刻画引理**（书上编号 (1)）：

> `[P]β ∈ ‖σ‖V₀  ⟺  Γ⁺ ⊢ P : σ`

原子情形是定义；箭头情形要证 (2)：「PQ 对一切合格的 Q 都配得
型 τ」⟺「P 配得型 σ→τ」——⇐ 是 (→E)；⇒ 用一个**新鲜的 z**
（Γ⁺ 保证它配好了型 σ）抽象一步 (→I)。刻画引理落地后，
Γ ⊨ M:T 在 TM_β 的 V₀ 下给出 Γ⁺ ⊢ M:T，削掉多余变量即得
Γ ⊢ M:T。∎

这套语义叫 **simple semantics**（4B6.1）——类型解释只允许
「D 的子集」这一种形状。更强的语义（Hindley 1983、Mitchell
1988）留给文献；对完备性来说，simple 就够——而且它教会我们
一件事：**Curry 式类型论的语义 = 无类型 λ-模型 + 子集解释**
（4B4.1 的对照：Church 式模型每个类型一个论域，Henkin 1950）。

两处工程细节值得点破：

1. **Prolog 判定协议**：文件首行 `:- encoding(utf8).`（SWI 在
   Windows GBK locale 下读 UTF-8 注释会告警）；构建通道用
   `swipl -q -g main -t halt -l 文件` 跑 `main/0`——成功 0、
   `fail` 1、抛错 2，正好做退出码判定。
2. **Lean 的两台机器合流**：β 机器（03 章）+ PT 机器（05 章）
   复制进同一文件；`unify`/`matchInst` 的 fuel 参数必须放冒号
   **后**（`def unify : Nat → Ty → …`）——冒号前参数不参与
   模式匹配，`| 0, _, _` 会把 0 往 Ty 上凑（本批实测重踩）。

> **坑位速记**
> ① SWI-Prolog 在 Windows 上按系统 locale 读源文件——中文注释
> 必须首行 `:- encoding(utf8).`，否则一串 Illegal multibyte
> Sequence 告警直接判 FAIL；
> ② `-l 文件` 不会执行 `initialization/2`（要 `-g main -t halt`）；
> 位置参数形式也不行——本批三种调用方式实测只有 `-g` 组合可靠；
> ③ Lean 断言语境写不了 `= some _`（类型里的占位符先于证明
> 综合）——用 `(…).isSome = true` 或写出完整值；
> ④ `def f (fuel : Nat) : T → U | 0, _ => …` 的 0 匹配的是 T——
> fuel 须移到冒号后（05 章记过，本章在 unify/matchInst 又踩）；
> ⑤ λ-模型不存在有限非平凡代表（K/S 无家可归）——语义实验室
> 用有限结构「探定义」，真模型用项模型，别在正文混淆两者。
