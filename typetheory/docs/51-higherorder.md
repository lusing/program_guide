# 51 类型算子与 Fω：高阶多态

> 对应读本：TAPL 书第 29 章（类型算子和分类）、第 30 章
> （高阶多态）、第 31 章（高阶子类型）。代码：
> `examples/51_higherorder/ex51_higherorder.pl`（kind 检查机、
> 类型级 λ 与 β 归约、Pair : *⇒*⇒* 的实例化链、Fω 的
> kind 上界量化样本）。

「类型上有函数吗？」——有，而且它们自己的「类型」叫
**kind**（类属）。这是类型论的最后一次升维：项 : 类型 ::
类型算子 : kind。

## 51.1 类型算子与 kind（书 29）

类型算子是**类型上的函数**：`Pair = λA. λB. A→B`——喂
两个类型产一个。kind 的语法很小：

> K ::= *（类型的 kind）| K ⇒ K（算子的 kind）

`→` 的 kind 是 `*⇒*⇒*`；`List : *⇒*`；恒等算子
`λX.X : *⇒*`。**kind 检查**（29.2 的规则）保证应用逐位
对齐——机器件直译：

```prolog
kind_of(tapp2(F, A), E, K2) :-
    kind_of(F, E, karr(K1, K2)),
    kind_of(A, E, K1).
kind_of(tlam(X, K, B), E, karr(K, K2)) :-
    kind_of(B, [X=K|E], K2).
```

「拿 * 的地方喂算子」被拒——kind 系统就是**类型的类型
检查器**。书 29.1 的直觉：类型算子让「参数化数据结构」
（List/Tree/Pair）从库函数升为类型层面的原语——ML 的
`'a list`、Haskell 的 `Functor` 都生活在这里。

## 51.2 类型级 λ 与 β（书 30）

Fω = System F + **类型级 λ**。类型层面的语法从此与项层面
同构：抽象 tlam、应用 tapp2、β 归约——机器件的类型级
一步归约：

```prolog
tstep(tapp2(tlam(X, _, B), A), R) :- tsubst(B, X, A, R).
```

样本链：`(λA.λB.A→B)[Nat][Bool]` 两步 β 到 `Nat→Bool` —
**类型在编译期也有计算**。Fω 的量化上界从类型升为 kind：
`∀F:*⇒*. ∀X:*. F X → F X`——「对任何类型算子 F」的多态
（机器件见证其 kind 为 *）。书 30.2 的实例：自然数级的
`Pair Nat Bool`、以及 λ 立方体的 λω 角（20 章的 PTS 表在
此第三次出场：类型算子 = λ→ 在类型层）。

## 51.3 高阶子类型（书 31）

Fω<: = Fω + <: + 囿量词——**全书的合流点**：45 章（<:）+
18 章（∀）+ 本章（kind）三线汇一。高阶子类型的规则比
50 章多一层：算子之间的 <: 按 kind 逐位比较（31.2），
全称类型的界从类型升为 kind。书 31 的样本（同余算子的
子类型、F-bounded quantification——`∀X<:C[X]. …` 的
自引用界）是「对象接口的完整类型学」的最终拼图——58 章
的收尾用它。机器件以 kind 检查承载本章的可执行面，高阶
<: 的算法陈述入 docs。

## 51.4 一页总结（本章的三个公式）

> kind = 类型的类型：* 与 K⇒K——应用逐位对齐的检查器。
> Fω = F + 类型级 λ：类型在编译期也有 β 计算。
> Fω<: = 三线合流：<:（39）+ ∀（18）+ kind（本章）。

> **坑位速记**
> ① Prolog 的 kind 检查器五条规则按构造子**逐一对译**即可
>   ——本章机器件一次通过（少见的好消息：没有隐式参/
>   记号冲突，纯结构递归）；
> ② 类型级 β 的代换 tsubst 与项级 subst 是**两套函数** —
>   类型变量与项变量不同名空间，混用一处即静默错位；
> ③ `tapp2(F, A)` 应用链的 kind 对齐**从左往右推断**——
>   机器件把 K1 作为「检查 A」的目标传出，天然双向。
