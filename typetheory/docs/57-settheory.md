# 57 集合论：Set 范畴、基数、序数与累积层级

> 对应读本：HoTT 书第 10 章全部（Set 的范畴、**基数**、**序数**、
> 经典良序、**累积层级 V**）。代码：`examples/57_settheory/
> ex57_settheory.lean`（Lean 对照：Set 的卡氏封闭、**Cantor
> 定理的构造版机器证明**（Russell 自产自销）、注入序 Embed
> 的结构样本——set 层在 Lean 天然）。

集合论在 HoTT 里经历一次身份翻转：从「数学的地基」变成
「类型论的一个章节」——集合（0-类型）只是层级塔的一层，
而 ZF 集合论的整个宇宙可以在类型论内部**构造出来**（累积
层级 V）。本章看这场翻转的两面：集合作为**对象**（Set 范畴
的范畴论）与集合论作为**结构**（V 的类型论重建）。

## 57.1 Set 的范畴（书 10.1）

上一章的 precategory 理论应用到自己：**Set**（0-类型的范畴）
是**范畴**（饱和——iso→eq）：函数的 iso 恰是类型的相等——
这就是泛等！Set 在 HoTT 里不是「万物的背景」而是「第一个
非平凡范畴」，它的范畴性是定理（49 章）。

Set 的范畴论性质（书 10.1 的表格，机器件 `curry/uncurry`
样本）：积 = ×、余积 = ⊎、**卡氏封闭**（X × A → B ≃ X →
(A → B)——58 章泛性质样本的范畴化）、子对象分类器 = Prop
（True : 1 → Prop 泛等下的拉回刻画子集）。与 56 章（Set
是饱和范畴的第一个实例）互读。

## 57.2 基数（书 10.2）

「大小」的高维化：**cardinal := ‖Set‖₀**（0-截断的类型）——
同构的类型有同一基数（截断把 iso 等价类压成一点）。基数的
序：

> |X| ≤ |Y| := 有单射 X → Y（机器件 `Embed` 结构）
> |X| < |Pow X| 恒成立（Cantor）

**Cantor 定理的构造版机器证明**（Lean 文件，无 choice）：

```lean
theorem russell {A : Prop} (h : A ↔ ¬ A) : False :=
  h.mp (h.mpr (fun a => h.mp a a)) (h.mpr (fun a => h.mp a a))

theorem cantor (X) (f : X → Pow X) : ∃ D, ∀ x, ¬ Feq (f x) D :=
  ⟨fun y => ¬ f y y, fun x h => russell (h x)⟩
```

对角谓词 D y := ¬(f y y) 不在像中——Russell 悖论的自产自销
（A ↔ ¬A ⇒ False）在**无排中**的世界照样工作。注意机器面的
技术件：函数等式逐点化（Feq := ∀x. P x ↔ Q x——25 章 PSet
策略的第三次服役）、Embed 用 **structure 而非 ∃**（从 Prop
投影数据要 choice——本指南第四次撞见 choice 税）。

序的代数（书 10.2）：≤ 自反传递、**Schröder–Bernstein**（X≲Y
且 Y≲X ⇒ 等价）——在构造世界 SB 的证明需要排中（书 10.2.4
后的注记），机器面以诚实清单呈现（`lt_pow` 只做入向）。

## 57.3 序数（书 10.3）

良基外延序的**截断**化身：

> ordinal := ‖(W-set 结构)‖₀——良基、外延（≤ 的截断相等
> 决定相等）、线性的序的等价类

序数的三合一：它是「良序集」（经典）、是 **W-型的余代数**
（构造——32 章良序语义的回收）、是「迭代的层级」（序数 α
= 前 α 层的收集）。机器面：32 章 W 的 Agda 件 + 本章 Lean
的序骨架呼应；完整 ordinal 开发（书 10.3 的三节）以 docs
地图呈现。

## 57.4 经典良序与选择（书 10.4）

LEM 的集合论后果：**良序定理**（每集合可良序 ⟺ 排中）与
选择公理的等价链（Zorn ⇔ AC ⇔ 良序——书 10.4.6 的 HoTT 版
重建）。与 50 章（AC 的正确形状：截断两侧）合读：50 章
说明「AC 在 HoTT 里写对了形状依然是公理」，本章说明「排中
一旦加入，集合论的全部经典机械复活」。工程视角：Lean 的
Classical 模块正是这条通道的工业化（choice→LEM→良序→dec）。

## 57.5 累积层级 V（书 10.5）——ZF 在类型论内部

本章的压轴构造：**V : Type → 的超限迭代**

> V₀ := ∅；V_{α+1} := Pow(V_α)（或子集截断版）；V_λ := ⋃
> ——全部层合成 V := Σ α. V_α 的截断层级

书 10.5 的完整构造：V 是 **0-类型**、∈ 是 mere relation、
V 上两两成员关系满足 **ZF 的全部公理**（外延、配对、并、
幂、无穷、替换——替换需要 resizing 或宇宙塔）。**类型论
没有「吞掉」集合论——它把集合论解释为一个结构**。三层
世界观就此合拢：

| 层 | 世界 | 「集合」的身份 |
|---|---|---|
| 经典 | ZF 论域 | 万物的基础（未定义原语 ∈） |
| 类型论（本书主线） | 类型/宇宙 | 0-类型的层级塔（39/51 章） |
| 类型论内部 | V 的构造 | **定理**（迭代幂集的截断） |

与 25 章（λD 子集即谓词）的终局对照：那里「集合」是谓词的
标签，这里「集合论」是类型论的一间客房——同一门学科在
三种基础里的三种身份，全部机器可查。

## 57.5b 替换公理与 resizing（书 10.5 的细目）

V 的 ZF 公理清单里最难安装的一条：**替换**（image of a
definable function is a set）。类型论的对应物是「Σ-类型的
存在」（族 {F x | x ∈ A} = Σ(x:A). F x ✓ 免费！）——但**层级
检查**会来收费：F : V → V 的像落在哪一层需要「层的传播」
论证，而一般传播需要 **propositional resizing**（50 章 3.5.5
的公理）或宇宙塔的约定。两条路线的取舍：

- **+resizing**：ZF 全套定理一步到位（V 满足完整 ZF），
  代价是 mere prop 层的非直谓性（50 章的直谓立场放弃）；
- **+宇宙塔**：V_α 只满足「直到 α 的替换」（分层版本），
  保持直谓，代价是 ZF 的定理分批兑现。

这是「数学基础的大教堂与集市」在类型论内的精确交易——
书 10.5.10 的总结是 HoTT 的经典立场陈述之一。与 31 章
（宇宙塔的 Girard 边界）互读：层级不仅是防悖论，更是
表达力的计量单位。

## 57.11 一页总结（本章的三个公式）

> Cantor：|X| < |Pow X|——对角线自产自销（机器零 choice）。
> 序数 = 良基外延序的截断——32 章 W 的余代数化身。
> V = 迭代幂集的层级——ZF 全套公理在类型论内的**定理**身份。

> **坑位速记**
> ① 函数等式在 Type 层——「不在像中」要 Prop 化（Feq 逐点
>   iff），直接 ≠ 会在 eq 上卡 elaborator；
> ② Prop 的 ∃ 投影数据（h.1 : Y → Z）被 Lean 拒绝——结构
>   性数据（函数）用 **structure** 不用 ∃（choice 税的第四
>   现身）；
> ③ singl b a 的 beta 展开是 **a = b**（y = x 的双翻转）——
>   心算方向两次翻转后极易装反（本章实测：先 .symm 后删，
>   最终答案是裸的 hh.mp rfl）；
> ④ 定理陈述 Embed X X 类型非 Prop ⇒ 用 def（theorem 必须
>   Prop）。

## 57.9 幂集塔与悖论的边界（跨章合流）

Cantor 定理（57.2）+ 累积层级（57.5）+ 宇宙塔（31 章）+
bool 的非平凡自等价（49 章）在同一根轴上：**「更大的东西」
永远造得出**。四条边界的对比：

| 构造 | 保证 | 悖论防线 |
|---|---|---|
| Pow : Set → Set | Cantor：严格更大 | 分层不封顶（ZF 的类论防线） |
| V_α 的层级 | 替换公理推进 | 序数无顶（ZF 内不饱和） |
| U₀ : U₁ : …（31 章） | 全域塔 | Girard 悖论防线（不设 U : U） |
| ua : U 群胚化（49 章） | 自等价丰富 | 与 ∞-版 LEM 冲突（LEM∞被否证） |

最后一行是 HoTT 特有的边界形态：宇宙的「大」不再是基数
问题而是**道路丰富性**问题——泛等把「更多」从尺寸维度
转到了同伦维度。全书收束时（59–60 章）这条轴会再次出现
（元理论的一致性坐标）。
