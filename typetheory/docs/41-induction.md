## 41.1 归纳型的唯一性：同伦初始（书 5.2/5.4）

集合论直觉说「归纳型由构造子唯一生成」。同伦视角的精确化分
两层：

- **唯一性（浅）**：满足同样构造子的两个类型等价（书 5.2 的
  enc-iso：2 与 Bool 同构到合同，5.2.4 例子）；
- **同伦初始性（深）**：归纳型 W 是「代数」范畴的**同伦初始
  对象**——到任何代数的态射不仅存在，而且「存在」本身是
  合同的（书 5.4.2：is-haunt unique）。唯一性从性质升级为
  **结构**：态射空间合同。

这个升级是理解 5.5（**同伦归纳型**）的钥匙：一个类型可以
只满足「同伦级」的归纳原理（递归子的存在性只到合同、不必
逐点定义）——标准归纳型是它的严格版。书 5.5 的定理：同伦
初始代数彼此等价、且都是标准 W 的「软化」。机器面：本章
以陈述级呈现（完整机械化需要代数范畴装配——45 章后回填），
32 章（W 的良序语义）在阅读时是直接前驱。

## 41.2 W 型的双消去与 ℕ 再现身（书 5.3）

cubical 文件给出递归/归纳**并排**的两行：

```agda
W-ind : (P : W A B → Set)                       -- 归纳（依赖 motive）
      → (∀ a f → (∀ b → P (f b)) → P (sup a f)) → ∀ w → P w
W-rec : (X : Set)                               -- 递归（cata：折叠）
      → (∀ a → (B a → X) → X) → W A B → X
W-rec X step = W-ind (λ _ → X) (λ a f ih → step a ih)
```

第二行是第一行的非依赖特例——**递归是归纳的投影**。初始代数
的语言：W-ind 说 sup 是初始的；W-rec 是它的 cata（折叠）。
ℕ 的 W-编码在 cubical 里复活（对照 32 章三家版）：

```agda
ℕW = W Bool (λ b → branch b ⊥ ⊤)
wzero = sup true (λ ())          -- 零参数构造子（空分支）
wsucc n = sup false (λ _ → n)   -- 单参数构造子（哑分支）
```

注意编码方向：**true 配空分支**（零没有参数）、false 配单元
分支（后继有一个哑参数）。`wIsZero`（cata 版判零）在具体项
上定义性计算——初始代数的「解构即折叠」。

## 41.3 互相归纳与更远的疆域（书 5.6/5.7）

机器样本：even/odd 互相定义、**成对消去**（motive 一对同时
覆盖——书 5.6 例）：

```agda
even-odd-ind : (P : even → Set) (Q : odd → Set)
             → P zero-e → (∀ n → Q n → P (esucc n))
             → (∀ n → P n → Q (osucc n)) → ∀ e → P e
```

书 5.7 的路标图（机器面到此为止、地图入 docs）：

| 推广 | 一句话 | 现状 |
|---|---|---|
| 归纳族 | 构造子可造**族**（索引化） | 30 章全家（Vec/Even） |
| 互相归纳 | 多个类型同时定义 | 本章 even/odd |
| inductive-inductive | 索引类型与索引**同时**归纳 | 书 11 章实验性使用 |
| inductive-recursive | 类型与**函数**同时定义 | 书明言「同伦视角尚不知如何正当化」 |

最后一行的诚实留白值得品味：不是所有集合论可行的定义方式都
自动有同伦语义——归纳递归的正当性到今天仍是开放工程。

## 41.4 恒等类型作为归纳族（书 5.8 上半）

「相等也能归纳地定义？」——两种打法（书把两种 J 追溯到两个
归纳族定义）：

- **自由版**：族 (=_A) : A → A → U，构造子 refl : ∀ a. a = a
  ——消去子是 path induction（motive 覆盖全部对 (a,b,p)）；
- **基于版**：固定 a0，族 (a0 =_A –) : A → U，构造子 refl——
  消去子是 based path induction（motive 只需一个基座 d）。

cubical 文件 `J-free-from-based` 给出**互推**（1.12.2 的机
器版；based 版就是我们的 J——cubical 里两者都是 transport 的
服装）。关键的**祛魅**（书 5.8 的讨论）：归纳类型「由构造子
自由生成」不等于「元素都是构造子」——自由群由 x,y 生成但含
xyx⁻¹；类型作为 ∞-群胚，其「运算」是路径运算。恒等族 (a0 = –)
是 **a0 处的自由表示函子**（Yoneda 的化身——45 章将回收这个
视角）：它的「元素」是 a0 出发的全部道路，refl 只是生成元。

## 41.5 恒等系统（书 5.8 下半）——本章高潮

定义 5.8.1：pointed predicate (R, r0)（R : A → Set、r0 : R a0）
是**恒等系统**，若它满足归纳原理（对一切 D、d 造 f）。定理
5.8.2 的五连环（等价！）：

> (i) (R,r0) 满足 based 归纳原理 ⟺ (iii) pointed 映射族合同
> ⟺ (iv) transport 沿 R 是等价 ⟺ (v) Σ(b:A).R(b) 合同

机器核心（cubical 文件 `pointed-induction`）：

```agda
-- (v) ⇒ (i)：指定中心的合同性 ⇒ 归纳原理
pointed-induction : (R : A → Set) (a0 : A) (r0 : R a0)
  → (∀ u → (a0 , r0) ≡ u)          -- 以 (a0,r0) 为中心的收缩
  → (D : ∀ b → R b → Set) (d : D a0 r0)
  → ∀ b r → D b r
pointed-induction R a0 r0 contr D d b r =
  transportF (λ u → D (fst u) (snd u)) (contr (b , r)) d
```

——**归纳原理就是 transport 沿合同性的搬运**：f(b,r) := 把
基座 d 沿「中心到 (b,r) 的路」搬过去。这就是 39 章 3.11.8
（单端点路径空间合同）与 J 的关系之正式揭晓：**J 的全部力量
= 路径空间的合同性**。基座等式（f(a0,r0) = d）由收缩在中心
处可取 refl 给出（完整链条与 37 章 4.2.6 同列回填件）。

## 41.6 等价归纳与同伦归纳（书推论 5.8.5/5.8.6）

把 5.8.2 的五连环应用到两个具体族，得到泛等与函数外延的
「归纳面孔」：

**等价归纳**：泛等 ⟺ (≃, id) 是宇宙上的恒等系统 ⟺
「要证 ∀ A B (e : A ≃ B). D A B e，只需证 ∀ A. D A A id」。
——证明等价的性质，**只需证恒等映射的情形**！书 4.1.1
（qinv(f) ≃ Π(x=x)）的证明已经在偷偷用它（「先 ua 成路、
再 J」就是等价归纳的展开形）。cubical 里它是 uaβ 的归纳版
（37 章），Glue 的计算律兑现了这条归纳。

**同伦归纳**：funext ⟺ (∼, refl) 是函数类型上的恒等系统
⟺ 同伦上的归纳原理。cubical 里 funext 是 λ i j → h j i——
同伦归纳免费成为「方形的 transport」。

三张面孔对照（38.2 的表升维）：

| 公理/定理 | 外延面孔 | 计算面孔 | 归纳面孔 |
|---|---|---|---|
| 泛等 | (A≡B) ≃ (A≃B) | ua+uaβ | 等价归纳 |
| 函数外延 | f∼g ⇒ f≡g | λ i j → h j i | 同伦归纳 |

——同一头大象的三个摸法。公理化世界任选一张立公理，cubical
世界三张同时免费（都是 Glue/方形的计算律）。

> **坑位速记**
> ① Agda 点-free 子句的隐式参不在 where 辖域（**本章再踩**：
>   pointed-induction 的 A/ℓ'——最终解法是**内联 motive λ**，
>   让 where 块整个消失——比绑定隐式参更稳）；
> ② ℓ 与 ℓ' 的 prime 字符（U+2032 vs ASCII '）混用会产生
>   「同名不同字」的 NotInScope——文件级统一 ASCII；
> ③ Agda 无 `if-then-else` 原生语法——自造 branch 函数；
> ④ W 编码 ℕ 时 true/false 与空/单元分支的**配对方向**：
>   零 = 零参数构造子（sup true (λ ())），反着配会自引用
>   不终止（Termination checker 抓获——这正是构造子语义
>   的运行时体现）；
> ⑤ isContr 的收缩从**中心**出发——要「以指定点为中心」的
>   合同性需换心（sym·concat 拼接）；归纳原理的基座等式
>   依赖收缩在中心为 refl（5.8.2 的隐含细节）；
> ⑥ 互相归纳的 data 用**两个声明**（data even / data odd
>   先声明后定义）——Agda 的 mutual 语法。
