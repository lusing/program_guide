「类型到底挡住了什么？」上一章的答案是「挡住等式不守恒」；本章
的答案是更深的一层：**挡住了不终止**。可指派项不但每个都能算到

比「标准方法」早二十五年的证明。

## 7.1 WN 与 SN：两种「安全」

（Hindley 2D4 的原始表述）把归约看作「求值」，两条安全性是：

> **WN（弱规范化）**：每个可指派项**存在**一条归约路到达范式——
> 「想算就能算出结果」。
> **SN（强规范化）**：可指派项的**一切**归约序列都有限——
> 「怎么算都终会结束」。

对 TA_λ 两条都成立：

> **WN 定理（2D5，Turing 1942；Curry–Feys 1958）**：每个 TA_λ-
> 可指派项都有 β-范式与 βη-范式。
> **SN 定理（2D6，Sanchis 1967；Diller 1968）**：可指派项的每条
> βη-归约序列都有限。

SN 蕴含 WN（取任一序列走到底），所以逻辑上 WN 是冗余的——但
Hindley 明说（2D6.1）：图灵的 WN 证明**更简单也更早**，而且实践
中多数应用只需要 WN。本章机器化的正是它。

## 7.2 可指派类的形状（2D1–2D3）

**可指派**（typable，历史上也叫 stratified）＝存在 Γ 与 T 使
Γ ⊢ M : T。这个类有漂亮的封闭性（2D2，每条引用前几章的定理）：

1. 取子项封闭（推导结构定理 2B2 的红利）；
2. βη-归约封闭（主体归约 2C1）；
3. **非消元且非复制的** β-展开封闭（03 章的消元/复制词汇在这里
   上岗：展开 `(λx.M)N` 时若 x 在 M 中恰出现一次，安全性不破）；
4. λ-抽象封闭（→I 规则本身）。

**可判定**（2D3）：主类型算法（05 章）就是判定程序——机器面即
`typable M = (principal M).isSome`。

## 7.3 刻画账本：三张机器票

### 票一：Y 不可指派（2D5.1 的逆否用法）

Y 组合子满足 `Y f →β f (Y f)`——它**没有 β-范式**（1B9.1）。
WN 说可指派项必有范式，于是 Y 不可指派：

```lean
example : principal Y = none := by rfl
example : isNf (goFuel 60 Y) = false := by rfl
```

第二行是「不停」的机器面：烧掉 60 步燃料，手里的项仍不是范式。
（不能直接断言「不停」——那是全称命题；范式判定失败的见证是
我们能拿到的一切，而且 60 步只是下界。）

### 票二：SN 推不出可指派（方向警示）

```lean
example : isNf (lam (app (var 0) (var 0))) = true := by rfl   -- λx. x x 是范式（故 SN）
example : principal (lam (app (var 0) (var 0))) = none := by rfl  -- 但不可指派
```

**「可指派 ⟹ SN」是真的，逆命题是假的**——λx. x x 自己就是
反例：它没有任何 redex（SN 得毫无悬念），但 occurs check 拒绝
给它配型。类型系统的安全性比「终止性」**严格更强**：它还要管
「每一处应用的形状」。这张票防止读者把 2D6 读反。

### 票三：BCKλ ⟹ 可指派（2D8）

反方向的桥也在：**每个 BCKλ-项都可指派**（Hindley 1989，证明
依赖 WN）。BCKλ-项是「每个绑定变量至多用一次」的项（03 章
1D2）——**不重复使用 ⟹ 必可指派**。机器验三张成员票：

```lean
example : typable Bc = true := by rfl    -- B = λx y z. x (y z)
example : typable Cc = true := by rfl    -- C = λx y z. x z y
example : typable (lam (lam (var 1))) = true := by rfl   -- K
```

配合票二读：不可指派性必然涉及**变量的多重使用**（2D8.1）——
但多重使用不必然不可指派（S 用了 x 两次却可指派）。三个类
BCKλ ⊊ 可指派类 ⊊ SN 类，层层收窄。

### 加映：β-相等可判定（2D7）

> 可指派项之间的 β（与 βη）相等是可判定的：两边各缩到范式，
> 比较即可。

正确性 = WN（范式存在）+ 最左归约必达（02 章）+ CR（范式唯一）。
机器面用 02 章的老朋友：

```lean
example : goNF 100 (app (app S Kc) Kc) = goNF 100 Iu := by rfl
```

SKK 与 I 的范式相同——β-相等判定器的完整一跑。（2D7.1 的复杂度
注记：Statman 证明该判定程序在 Grzegorczyk 层级 𝒢⁴ 时间可跑、
𝒢³ 不可——「可判定」与「便宜」是两回事。）

## 7.4 从 Curry 到 Church：证明的搬桥（5A–5B 摘要）

Hindley 证明 WN 不直接对 TA_λ 动手，而是先造 **Church 式带注解项**
（5A——即本指南 04 章的三路线之一），再证明两级 WN 之间的桥：

> 带注解项与 TA_λ 推导一一对应（5B）；**带注解项的 WN ⟹ 可指派
> 项的 WN**（5C1.1：给 Γ ⊢ M : T，取对应注解项 P，缩 P 到范式，
> 擦掉注解就是 M 的范式）。

为什么绕这一趟？因为带注解项的 redex **自带类型信息**——下一步
的「度数」要有类型才能定义。Curry 式项的类型是外挂的，跟着
归约会变（06 章的教训），不适合当测度。

## 7.5 图灵的证明（5C1）：度数策略

现在正面证明**带注算项的 WN**。图灵 1942 的三步舞：

**第一步：给 redex 定度数。** 带注解项的每个 β-redex 形如
`((λx:σ→τ. M) N)`，其函数部分注解 σ→τ 叫 redex 的**支配类型**，
它的**大小**（原子出现数）叫度数：

```lean
def tySize : Ty2 → Nat
  | .base _ => 1
  | .arrow a b => 1 + tySize a + tySize b
```

**第二步：两条度数引理。**（残余概念来自 9B，我们取其结论：）

- **残余不升**：收缩一个 redex 后，别的 redex 的残余**度数不变**
  （代换不动函数注解）；
- **新生严格降**：收缩 `((λx:σ→τ. M) N)` 造出的**新** redex，
  函数部分只能是 `N`（类型 τ）或 `[N/x]M` 的某个子应用（支配
  类型是 σ 或 τ）——度数至多 max(|σ|,|τ|) < |σ→τ|。

第二条就是「类型在收缩中变小」的精确形态：β-收缩永远在
**拆箭头**。

**第三步：策略与测度。** 永远收缩当前**最大度数**的 redex
（一轮做完所有最大度的，即「最小完全发展」）。每轮之后：
最大度数 d(P) **严格下降**（残余不升 + 新生严格降）。d(P) 是
自然数，降有限次必到 0——0 度即无 redex——范式到手。∎

### 机器面：完整策略三件套

```lean
def redexDegrees : Tm → List Nat    -- 全部 redex 的度数（最左外次序）
def stepMax (t : Tm) : Option Tm    -- 收缩最左一个最大度 redex
def degreeTrace : Nat → Tm → List Nat  -- 每次收缩前的最大度数序列
```

两个样本把两条度数引理演成戏：

```text
E1 = (λ(g:(a→a)→(a→a)). g (λx:a. x)) I        其中 I : a→a→? …见文件
E2 = twice2 argC  （twice2 = λg x. g (g x)，g 的注解 (a→a)→(a→a)）
```

断言账（全部 `by rfl`）：

| 断言 | 值 | 讲的是哪条引理 |
|---|---|---|
| `redexDegrees E1` | `[7]` | 头 redex 支配类型 (a→a)→(a→a)，大小 7 |
| `redexDegrees (stepMax E1)` | `[3]` | **新生** redex 度数 |a→a| = 3 < 7（引理二） |
| `redexDegrees (stepMax E2)` | `[3, 3]` | 一个残余一个新生，都 ≤ 3（引理一+二） |
| `degreeTrace E1` | `[7, 3]` | 最大度数逐轮严格降 |
| `degreeTrace E2` | `[7, 3, 3]` | 同轮两刀（度 3 的两个 redex），再降 |
| `normalizeTuring E1/E2` | `ida` / `idT` | 策略到达范式 |
| `normalizeViaFuel E2` | `idT` | normal order 同达——CR 的实例面 |

E2 值得停一眼：`twice2 argC` 的头 redex 度数 7，一刀下去剩
`argC (argC x)`——**度数 3 的两个**（外层新生、内层残余）。
这就是「残余不升 + 新生严格降」在同一帧里的合影。

## 7.6 SN 的方法论（5C2）：computability 简史

SN 定理 Hindley 不重证（引 HS 86 附录 2），但 5C2 给了两件
值得记录的东西：

**(ii) 有界版**：存在算法输出 k(P)，使 P 的一切归约序列长度
≤ k(P)。证法：把所有可能的归约做成一棵有限分支树，SN 说枝
皆有限，**König 引理**说树有限，取最深枝长。——代价：König
引理非构造。构造化的补救（Mints 1979、Gandy 1980b、de Vrijer
1987、Schwichtenberg 1991）给出可计算的界函数。

**方法史**（5C2.2，一段浓缩的证明技术史）：几乎所有 SN 证明
都走**可计算性谓词**（computability predicate）路线——按类型
归纳定义「可计算项」类，先证可计算 ⟹ SN，再证全体带注解项
可计算。Tait 1967 定型；Girard 1970s 把它加强成 candidats de
réductibilité 证下 System F 的 SN（18 章的天花板正是它挡住的）。
本指南 41 章的 SN 策略地图把这条路画在图灵路线旁边——
**WN 有初等策略证明，SN 要逻辑关系**，这是简单类型论的
方法论分水岭。

## 7.7 代码导读

`ex07_norm.lean` 单文件双幕：

- **甲幕（Curry 侧，2D）**：β 机器 + PT 机器（复制自 05 章），
  跑三张票与加映；
- **乙幕（Church 侧，5C1）**：带注解项 + infer（04 章同款）+
  度数机械三件套 + 样本断言表。

一个设计决策值得点破：`stepMaxWith md t` 在「头 redex 度数不是
最大」时，**递归进函数体与实参**继续找——这是把「最左外优先」
与「最大度优先」两个策略正交组合：位置序决定**谁先**，度数决定
**谁能**。图灵的原策略是「整轮做完所有最大度的」（完全发展），
机器版退化为「逐个收缩最大度的最左者」——测度 (d, 最大度 redex
个数) 的字典序下降让两种表述等价（残余不升保证同轮计数只减
不增）。

> **坑位速记**
> ① Lean 4.25 core **没有** `List.maximum?`（那是 Batteries/
> Mathlib 的）——自写 `maxOf` 三行；
> ② `Option.get!` 需要 `Inhabited` 实例——`deriving` 加上
> Inhabited 即可（var 0 当默认值）；
> ③ 数据类型互相引用须先声明被引用者（Tm 的构造子吃 Ty2，
> Ty2 要在前）——前向引用的报错是一串莫名其妙的 Repr/BEq 失败；
> ④ `example : e = t := by rfl where …` 非法（where 只挂在
> def 上）——辅助函数提为顶层 def；
> ⑤ `#eval` 判等要 `==`（BEq），裸 `=` 要 Decidable 实例；
> ⑥ 工具坑：用 python heredoc 批量改 Lean 源码时，三引号字符串
> 会被 Lean 的 `t'` 变量名咬穿——多行替换改用 Edit 工具
> （本批两处替换静默失手的教训）。
