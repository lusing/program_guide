# 抽象代数教程 · 构建计划

以 Rotman《抽象代数基础教程（原书第3版）》（李样明、冯明军译，机械工业 2008；
原书 *A First Course in Abstract Algebra with Applications*, 3rd ed.）为纲，
写成自包含的中文教程：讲解为主、代码为辅，每章配四/五通道可验证示例
（Lean 4 + mathlib 钉版 / Isabelle HOL-Algebra 选配 / Julia / Python+sympy / SWI-Prolog）。

## 通道纪律

- lean：定向导入（禁 `import Mathlib` 整包——内存峰值会炸）；每章一个
  `Abstractalgebra/ChNNXxx.lean`；mathlib 钉版 H:/Lang/lean4/mathlib4-4.33.1。
- julia：`NN_xxx.jl`，无第三方包；输出 `==== NN` 与 `END ====` 标记。
- python：`NN_xxx.py`，sympy 允许；`python -I` 运行。
- prolog：`NN_xxx.pl`，SWI-Prolog `swipl -q -f ... -g main -t halt`；
  文件头 `:- encoding(utf8).` 必带。
- isabelle：选配通道，群/环/理想等 HOL-Algebra 擅长章加 `examples/isabelle/ROOT`
  会话 AANN；不强求全章覆盖。

- OCR 只作取材骨架；数学内容按领域知识重建，定理编号引用以原书为准。
- 每章 ≥200 行 docs、文字多于代码；所有代码在正文引用并讲解。
- 每章末尾「要点回顾」+ Zig 式上一章/下一章导航。
- 数值断言一律精确（整数/有理数算术），不用浮点容差冒充等式。
