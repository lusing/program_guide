**对应原书 §7.2（pp. 381-390）。**

## 35.1 分解存在与唯一：两条腿走路

第 20 章在 ℤ 与 k[x] 里证明了唯一分解；现在问：**什么样的整环
保证分解存在且唯一**？答案分两半证明（原书命题 7.15）：

> **命题 7.13** 整环中 (a) ⊇ (b) ⟺ a | b；a、b 相伴 ⟺ (a) = (b)。

> **命题 7.15** 整环 R 是 UFD ⟺ (i) 每个非零非单位的元素都写成
> 不可约元之积（存在性），且 (ii) 每个不可约元 p 生成的 (p) 是
> 素理想（唯一性的实质）。

**存在性**用"主理想的严格升链终止"（引理 7.14 的 ACC 雏形——
下一章的主角在此首次亮相）：若 r = r₁r₂⋯ 无限分解，则
(r) ⊊ (r₁) ⊊ (r₁r₂) ⊊ … 无限严格升——矛盾。

> **定理 7.16** PID 是 UFD（特别地，欧氏环是 UFD）。

存在性来自 ACC（PID 中理想链对应 gcd 链，严格降的 gcd 数值递减）；
唯一性来自定理 7.11（PID 中不可约 ⟹ 极大 ⟹ 素）。第 20 章的
ℤ 与 k[x] 定理由此一遍带走。

> **命题 7.17** UFD 中任何一组元素的 gcd 存在（素分解的 min 指数）。

## 35.2 高斯引理：本原多项式

把 UFD 性从 R 搬到 R[x] 是本章的技术高峰。工具是**内容**：

> **定义** f(x) = Σaᵢxⁱ ∈ R[x] 的**内容** c(f) 是系数的 gcd；
> c(f) = 1 时称 f **本原**。f = c(f)·f*，f* 本原。

> **引理 7.19（高斯）** 两个本原多项式之积仍本原。

**证明**（反证的经典）：设 fg 不本原，某素 p 整除全部系数。设
aᵢ、bⱼ 分别是 f、g 中**最前的**不被 p 整除的系数，则 (fg)_{i+j}
= (Σ a_{i'}b_{j'}) + aᵢbⱼ，前段各项含 p（某因子被 p 整除），
末项 aᵢbⱼ 不被 p 整除（p 素！）——总和不被 p 整除，与 p 整除
全部系数矛盾。∎

> **引理 7.20** c(fg) 与 c(f)c(g) 相伴；本原多项式在 R[x] 中
> 整除 ⟹ 在 Frac(R)[x] 中整除（商的本原性）。

> **定理 7.21（高斯）** R 是 UFD ⟹ R[x] 是 UFD。

**证明骨架**：R[x] 的分解存在性由 Frac(R)[x]（PID ⟹ UFD）的
分解经内容缩放拉回；唯一性：f 的两个分解拉到 Frac(R)[x] 中用
那里的唯一性，再用本原性把相伴关系落回 R。∎

> **推论 7.22** 域 k 上 k[x₁,…,xₙ] 是 UFD（对 n 归纳）。

注意与第 36 章的分界：k[x,y] 是 **UFD 但不是 PID**——(x, y)
需要两个生成元。唯一分解与"每个理想主"是两个世界。

## 35.3 反例：ℤ[√−5]

不可约 ⟹ 素在 UFD 中成立，但在一般整环中**失效**——最短反例是
ℤ[√−5] = {a + b√−5}。范数 N(a + b√−5) = a² + 5b² 乘性
（N(αβ) = N(α)N(β)，复共轭的模平方）。关键算表：

- N(2) = 4、N(3) = 9、N(1 ± √−5) = 6；
- 方程 a² + 5b² = 2 与 = 3 都无整数解（b = 0 时 a² = 2、3 非平方；
  |b| ≥ 1 时 ≥ 5）——**范数 2、3 的元素不存在**。

于是在
**6 = 2 · 3 = (1+√−5)(1−√−5)**
中，四个因子的真因子都要求范数 2 或 3——不存在，故四个因子都
**不可约**；两条分解不能互相重组（2 与 1+√−5 不相伴：范数 4 ≠ 6）。
⟹ ℤ[√−5] 不是 UFD。且 **2 是不可约元但不是素元**：2 整除乘积
(1+√−5)(1−√−5) = 6，却不整除任何一个因子（商的系数出现 ½）。

这个五平方反例是代数数论的起点：ℤ[√−5] "缺少"某些元素——
补全成**类数**的整数环（加进 (1+√−5)/2 型的元素）就恢复唯一
分解。那是另一门课的故事。

## 35.4 机器验证一：Lean——数值面

**文件：`examples/lean/Abstractalgebra/Ch35Ufd.lean`**。
分解唯一性与高斯引理的完整证明在 mathlib 中都有正式化，本章取
可 decide 的数值面：360 的两套分解重组相等、gcd = min 指数
（gcd(72, 108) = 2²·3² = 36——注意指数取 min 是 2 与 2，
开发时先写错成 2²·3，`decide` 立即证伪）、高斯引理的具体恒等式
(2x+2)(3x+3) = 6(x+1)²（内容 2·3 = 6）与
(4x+6)(10x+15) 展开系数 gcd = 10 = gcd(4,6)·gcd(10,15)。
ℤ[√−5] 的部分：范数恒等式的有理版 + "a² + 5b² = 2、3 无解"的
有界枚举 `decide`。

## 35.5 机器验证二：Julia——范数机器

**文件：`examples/julia/35_ufd.jl`**。三台机器：

```julia
nmul((a, b), (c, d)) = (a * c - 5 * b * d, a * d + b * c)   # ℤ[√−5] 乘法
norm((a, b)) = a * a + 5 * b * b                             # 范数
```

断言组：(1) 试除分解 2..200 重组还原、gcd min-指数公式与欧几里得
在 1..60 网格全对拍；(2) **高斯引理随机 200 组**：随机整系数
三次多项式 f、g，content(fg) = content(f)·content(g)（正、负、
零系数全参与）；(3) ℤ[√−5]：范数乘性在 [−3,3]⁴ 全网格核对
（2401 组）、6 = 2·3 = (1±√−5) 两分解、范数 2/3 无解的取值表、
`divides((2,0), (1,1))` 为假但 `divides((2,0), (6,0))` 为真
——**不可约 ≠ 素**的完整机器重演；(4) 内容-本原分解
f = c(f)·f*、c(f*) = 1 随机 100 组。

## 35.6 机器验证三：Python 与 Prolog

**文件：`examples/python/35_ufd.py`**。sympy 的 `factorint`/
`factor`/`factor_list` 三件套承担"标准答案"角色：ℤ 分解重组
（2..300）、gcd 公式对拍、`expand(factor(f)) = f` 恒等、多变元
`factor_list` 的因子重组还原（推论 7.22 的 sympy 面）。ℤ[√−5]
用符号 √−5：`sp.sqrt(-5)` 自动规范为 √5·i，除法判定取
q = β/α 的两个坐标是否皆整——**注意 sympy 会把 2·(x−1) 自动
吸收成 (2x−2)**，结构相等判定要用 `expand(差) == 0`。

**文件：`examples/prolog/35_ufd.pl`**。全部整数算术重建：
试除分解、min-指数 gcd 与欧几里得对拍（1..40 网格）、
`poly_mul/3`（位置-乘积对收集再按位求和）+ content 四组核对、
范数乘性 2401 网格、6 的两分解与"2 非素"。一个 Prolog 细节：
`gcd2(A, B, G) :- gcd_(abs(A), abs(B), G)` 把**项** `abs(0)` 传给
gcd_，漏进子句 3 触发 mod 0——`abs` 必须经 `is` 求值
（第 31 章同款写法靠后续 `is` 兜底侥幸，此处当场爆雷）。

## 35.7 要点回顾

1. UFD ⟺ 分解存在 + 不可约 ⟹ (p) 素（命题 7.15）；存在性由
   主理想 ACC（引理 7.14），唯一性由素性。
2. PID ⟹ UFD（定理 7.16）；UFD 中 gcd 恒存在（min 指数，
   命题 7.17）。
3. 高斯引理链：本原积本原（7.19）→ 内容乘积（7.20）→
   R UFD ⟹ R[x] UFD（7.21）→ k[x₁,…,xₙ] UFD（7.22）。
4. ℤ[√−5]：6 的两分解、范数 2/3 无解、2 不可约不素——
   UFD 的最短反例，也是"补元素恢复分解"（类域论）的起点。
5. UFD ≠ PID：k[x,y] 有唯一分解但 (x,y) 不是主理想——
   下一章（诺特条件）恰好补上"有限生成"这一层。
