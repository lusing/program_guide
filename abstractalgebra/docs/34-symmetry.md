## 34.1 平面等距的完全分类

第 2 章我们知道 Isom(ℝ²)（保持距离的双射）是一个群；现在把它拆开看。
复坐标 z = x + iy 下每个等距有形状

> **命题 6.36** 固定 0 的等距 Φ 满足 Φ(z) = e^{iθ}z（旋转）或
> Φ(z) = e^{iθ}z̄（反射）。

（证明用引理 6.35：圆心 P、Q 的两圆恰交一点 ⟺ 三点共线——等距把
圆送到圆，于是把"圆的公切点"送到"圆的公切点"，逼出保角性。）
加上平移 t_c(z) = z + c（推论 6.37），一般的等距是
Φ(z) = e^{iθ}z + c 或 Φ(z) = e^{iθ}z̄ + c。命题 6.38 与 6.40 再把
第二种拆干净：反射（轴上点全固定）或**滑动反射**（反射 + 沿轴
平移的复合，无固定点）。

> **定理 6.42** 每个平面等距恰为下列四种之一：**平移、旋转、
> 反射、滑动反射**。

> **推论 6.43（固定点分类）** 无固定点 ⟹ 平移或滑动反射；
> 恰一个固定点 ⟹ 旋转；多于一个固定点 ⟹ 反射或恒等。

四个基本等距（规范到实轴）在机器通道里反复出现，用仿射对
(A, c)（A ∈ 四个对角符号矩阵）表示：
t(x, y) = (x+1, y)（单位平移）、R(x, y) = (−x, −y)（半翻转）、
α(x, y) = (x, −y)（水平反射）、β(x, y) = (−x, y)（竖直反射）、
ρ(x, y) = (x+½, −y)（滑动反射）。它们的关系代数：

ρ² = t，R² = α² = β² = id，βα = R，αt = tα，βt = t⁻¹β，
Rt = t⁻¹R，αρ = ρα（= 半平移）。

这组关系式就是四种等距"乘法表"的内核——三通道全部逐条机器核验。

## 34.2 Leonardo 定理：有限对称群只有两种

装饰品（有限图形）的对称群是 Isom(ℝ²) 的有限子群。da Vinci
（为画"理想城市"研究过的）结论：

> **引理 6.45** 等距把重心送到重心。
> **引理 6.46** 有限子群 G 有公共不动点 c（逐个元素的重心论证）。

> **定理 6.47（Leonardo）** Isom(ℝ²) 的有限子群 ≅ C_m（纯旋转，
> m 重旋转对称）或 D_{2m}（加反射，正 m 边形的完全对称群）。

证明骨架：平移到公共不动点后 G ⊆ O(2)，元素是旋转或反射；
纯旋转情形取最小旋转角，G 循环；含反射情形，旋转部分循环
⟨h⟩，任一反射 σ 满足 σhσ⁻¹ = h⁻¹，于是 G = ⟨h⟩ ⊔ σ⟨h⟩ ≅ D_{2m}。∎
（"无限二面体" D∞ = ⟨t, R⟩ 是它在带群里的极限形态。）

## 34.3 带群：檐壁上的七种对称

> **定义** **带群（frieze group）**是 Isom(ℝ²) 中固定一条直线的
> 子群 G（把带状装饰的中线映回自己）。规范化：中线取实轴、
> G ∩ Trans = ⟨t⟩（t 为最短平移，单位化）。

第二个工具是**点群**：去掉平移部分，π(G) ⊆ O₂(ℝ)。

> **引理 6.48 / 推论 6.49** 规范带群的点群
> π(G) ⊆ {1, f, g, h} ≅ V₄（克莱因四元群），
> 其中 f(z) = z̄、g(z) = −z、h(z) = −z̄。

（限制来自"固定实轴"：π(G) 必须把实轴映回实轴，只剩四个对角
符号矩阵。）V₄ 恰有 5 个子群——{1}、⟨f⟩、⟨g⟩、⟨h⟩、V₄——但每个
点群可能有**两种提升**（比如 ⟨f⟩ 提升成"纯反射 α"或"纯滑动 ρ"），
组合出恰七个群：

> **定理 6.50** 至多存在 7 个（规范）带群。
> **定理 6.51** 7 个都会出现（各给出一个带状图案的完整对称群）。

七个群及其"代数类型"（Z(F) 按原书记号）：

| 群 | 生成元 | 含 | 抽象类型 |
|---|---|---|---|
| F₁ | ⟨t⟩ | 平移 | ℤ |
| F₂ | ⟨t, R⟩ | + 半翻转 | D∞ |
| F₃ | ⟨t, β⟩ | + 竖直反射 | D∞ |
| F₄ | ⟨t, α⟩ | + 水平反射 | ℤ × ℤ₂ |
| F₅ | ⟨ρ⟩ | 只有滑动 | ℤ |
| F₆ | ⟨t, R, β⟩ 型 | 混合 | ℤ × ℤ₂ |
| F₇ | ⟨t, R, α⟩ = ⟨t, α, β⟩ | 全部 | ℤ₂ × D∞ |

两个深刻的现象：**F₁ ≅ F₅、F₂ ≅ F₃、F₄ ≅ F₆ 是代数同构而几何不同**
（原书明确强调：F₂ 只含平移与半翻转，F₃ 含真正的反射——图案的
"几何指纹"比抽象群更细）；而 G/⟨t⟩ ≅ π(G)（第二同构定理）给出
指数 1/2/2/4 的窗口计数。

## 34.4 晶体学限制：五折对称为何不存在

墙纸（二维点格）的对称群里，旋转的阶被死死限住：

> **晶体学限制** 格对称群中的旋转阶 n ∈ {1, 2, 3, 4, 6}。

一行证明：格上旋转 = **迹为整数**的 2×2 整数矩阵，而 n 阶旋转的
迹 = 2cos(2π/n) ∈ {−2, −1, 0, 1, 2} ⟺ n ∈ {1, 2, 3, 4, 6}。
n = 5 的迹是 (√5−1)/2（黄金比倒数，无理）——**五折对称的墙纸
不存在**；n = 7+ 同理。这扇门后是 17 个壁纸群与 230 个空间群
（原书结束注记），以及多面体的对称群（正四面体 A₄、正方体/正
八面体 S₄、正十二/二十面体 A₅）——第 31 章的 A₅ 在这里以
"对称"的面目最后一次现身，全书在"装饰"与"不可解"的呼应中收束。

## 34.5 机器验证一：Lean——等距的函数代数

**文件：`examples/lean/Abstractalgebra/Ch33Symmetry.lean`**。
五个等距定义为 ℚ² 上的具体函数，34.1 的关系表逐条变成
函数等式——每个证明都是 `funext + simp (+ ring)`：

```lean
/-- 滑动反射（x-轴反射 + 沿轴半单位平移）。 -/
def Rho (p : ℚ × ℚ) : ℚ × ℚ := (p.1 + 1 / 2, -p.2)

-- 滑动反射的平方是单位平移（ρ² = t）
example : Rho ∘ Rho = T := by
  funext p; simp [Rho, T]; ring

example : Beta ∘ T = Tinv ∘ Beta := by    -- βt = t⁻¹β
  funext p; simp [Beta, T, Tinv]; ring
```

（注意 1/2 在 ℚ 上精确——滑动反射的"半单位"没有浮点阴影。）
点群部分：V₄ ≅ ℤ/2 × ℤ/2 的全员自逆 `decide`；旋转矩阵
M₄ = [[0,−1],[1,0]]（阶 4）与 M₆ = [[0,−1],[1,1]]（M₆³ = −I
⟹ 阶 6）的幂由 `decide` 算出，迹核对 tr M₄ = 0 = 2cos(2π/4)、
tr M₆ = 1 = 2cos(2π/6)。

## 34.6 机器验证二：Julia——窗口、点群与矩阵阶

**文件：`examples/julia/34_symmetry.jl`**。等距表示为
(A, c)（A 四个对角符号矩阵、c 半整数平移），复合
`(A,c)∘(B,d) = (AB, Ad+c)`：

```julia
comp((A, c), (B, d)) = (A * B, A * d + c)
const RHO = (ALPHA, [0.5, 0.0])   # 滑动反射 ρ
@assert iseq(comp(RHO, RHO), T)   # ρ² = t
```

**带群窗口**：闭包枚举 |平移| ≤ 3 内的全部元素（生成元连同
逆元一起长——只乘正生成元窗口只向一边长，是本章调试实录），
得 F₁ = 7、F₂ = 14、F₄ = 14、F₇ = 28 个元素——正是指数
[G : ⟨t⟩] = 1/2/2/4 的直接读数；**点群**取元素的线性部分，
四个群分别给 {1}、{1,R}、{1,α}、V₄，V₄ 封闭、自逆、交换逐项核验。
**晶体学限制**：枚举 {−1,0,1}⁴ 的 81 个矩阵中可逆者，逐个求阶
（幂迭代到 I 或超时），阶集合恰 {1,2,3,4,6}；迹论证数值面
2cos(2π/n) 只在这五个 n 取整值、n = 5 给非整的 (√5−1)/2。

## 34.7 机器验证三：Python 与 Prolog

**文件：`examples/python/34_symmetry.py`**。与 Julia 同构，但用
`Fraction` 精确有理数（滑动反射的 ½ 一步到位）；迹论证升到
**符号层**：`sp.simplify(2*cos(2π/n) − val) == 0` 对五个合法 n
精确成立，`2*cos(2π/5) = (√5−1)/2` 化简验证、`.is_integer` 为假
——阶 5 被排除是**无理性证明**，不是浮点比对。

**文件：`examples/prolog/34_symmetry.pl`**。把半单位平移编码成
偶数：等距 = iso(Sx, Sy, N)（z ↦ (Sx·x + N/2, Sy·y)），复合
`C is Sx1*N2 + N1` 全整数算术；`grow/3` 窗口闭包（注意输出参
不能与输入参同名——合一会把答案钉死在初值上，本章调试实录）；
点群子群与封闭性、晶体学限制 81 矩阵枚举、迹核对（120° 矩阵
[0,−1,1,−1] 迹 −1、60° 矩阵 [0,−1,1,1] 迹 1，阶由幂迭代判定）。
三个数值通道（julia/python/prolog）取同一组断言值，互相锁死。

## 34.8 要点回顾

1. 等距四分法（定理 6.42/6.43）：平移、旋转、反射、滑动反射；
   固定点个数是分类器。
2. Leonardo 定理（6.47）：有限平面对称群 = C_m 或 D_{2m}
   （重心引理给出公共不动点，旋转部分循环，反射翻转它）。
3. 带群七个（定理 6.50/6.51）：点群 ⊆ V₄ 只有 5 个子群，但提升
   有两种——组合出 7；代数类型只有 4 种（ℤ、D∞、ℤ×ℤ₂、ℤ₂×D∞），
   "代数同构 ≠ 几何相同"。
4. 点群是同态的像：G/⟨t⟩ ≅ π(G)——第 12 章的同构定理在装饰
   世界落地。
5. 晶体学限制：格旋转的迹必须取整 ⟹ 阶 ∈ {1,2,3,4,6}，
   五折对称被 (√5−1)/2 的无理性排除。
