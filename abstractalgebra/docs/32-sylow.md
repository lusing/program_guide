# 32 西罗定理

**对应原书 §6.2（pp. 487-497）。**

---

## 32.1 拉格朗日的逆问题

拉格朗日定理说子群的阶整除群的阶；逆命题**不成立**——A₄（12 阶）
没有 6 阶子群（原书命题 2.97）。那么"整除"能保证什么？西罗
（L. Sylow，1872）的答案：**素数幂方向全对**。这一节的三个定理
（6.19、6.21，配合引理 6.18）合称西罗定理，是有限群论最锋利的
工具。原书的历史注记值得一看：阿贝尔群的基定理（师林 1868 /
克罗内克 1870 / 弗罗贝尼乌斯-施蒂克贝格 1878）与西罗定理（1872）
几乎同时出现——"分类 p-子群"与"存在 p-子群"是同一场运动。

> **定义** 有限群 G 的**西罗 p-子群**是极大的 p-子群 P
> （若 Q 是 p-子群且 P ⊆ Q 则 P = Q）。

存在性是平凡的：有限群里任何 p-子群链必终止（阶严格递增）。
非平凡的是西罗子群的**阶**、**个数**与**共轭结构**。

## 32.2 共轭作用与正规化子

工具是第 13 章的群作用（复习）：G 共轭地作用在子群集合
Sub(G) 上（g : H ↦ gHg⁻¹），H 的稳定子叫**正规化子**
N_G(H) = {g : gHg⁻¹ = H}。

> **命题 6.17** H 的共轭个数 = [G : N_G(H)]（轨道-稳定子定理
> 的直接情形）。

> **引理 6.18** 设 P 是西罗 p-子群：
> (i) P 的共轭也是西罗 p-子群；
> (ii) p ∤ |N_G(P)/P|；
> (iii) 若 p-幂阶元 g 满足 gPg⁻¹ = P，则 g ∈ P。

(ii) 的证明是典型的"放大 contradiction"：若 p | |N/P|，柯西定理
给出 N/P 中的 p 阶元，对应定理把它提升成严格包含 P 的 p-子群——
与极大性矛盾。

## 32.3 两个西罗定理

> **定理 6.19（西罗第二、第三定理）** 有限群 G 的西罗 p-子群
> 全体互相共轭；个数 r 满足 r ≡ 1 (mod p) 且 r | |G|/p^e。

**证明骨架**：让 P 共轭作用在西罗子群集 X 上。含 P 的轨道长为
|X| ≡ 1 (mod p)（其余轨道长都是 p 的倍数）；若 Q 不共轭于 P，
Q 作用在 X 上没有长为 1 的轨道，得 |X| ≡ 0 (mod p)，矛盾。
最后 r = [G : N_G(P)] | |G|，结合 r ≡ 1 (mod p) 推出 r | m。∎

> **推论 6.20** 唯一西罗 p-子群 ⟺ 正规西罗 p-子群。

> **定理 6.21（西罗第一定理强化版）** 若 |G| = p^e·m（p ∤ m），
> 则西罗 p-子群的阶恰为 p^e。

**证明骨架**（很漂亮，值得记）：让 G 作用在**大小为 p^e 的子集**
B 的集合上。轨道长 |O(B)| = [G : G_B]（G_B 是稳定子）。
p^e·m = |G| = |G_B|·|O(B)|，所以 p ∤ 某个 |O(B)|，对该 B 有
p^e | |G_B|；另一方面单射 G_B → B（g ↦ gb）给出 |G_B| ≤ p^e。
夹逼完成。∎

推论链：**命题 6.26**（p^k | |G| ⟹ 存在 p^k 阶子群）——西罗子群
内部用阿贝尔 p-群之外的事实（原书命题 2.150：p-群有每阶子群）。
拉格朗日逆命题在**素数幂方向**成立。

## 32.4 应用：小群的非单性

**引理 6.24** 不存在阶为 p^e·m（p ∤ m，p ∤ (m−1)!）的非阿贝尔
单群。（西罗子群 P 指数 m ⟹ 作用在陪集上嵌入 S_m，阶比较矛盾。）

**引理 6.25** 不存在阶 < 60 的非阿贝尔单群。

证明是逐案计数，三个幸存候选 30、40、56 逐一击毙——这是本章
机器通道的主菜：

- **30**：n₅ | 6 ∧ ≡ 1 (mod 5) ⟹ n₅ ∈ {1, 6}；单群非正规 ⟹ n₅ = 6，
  供 6×4 = 24 个非单位元。n₃ | 10 ∧ ≡ 1 (mod 3) ⟹ n₃ = 10，供
  20 个。24 + 20 = 44 > 29（非单位元预算）——矛盾。
- **40**：n₅ | 8 ∧ ≡ 1 (mod 5) ⟹ n₅ = 1——西罗 5-子群正规。
- **56**：n₇ | 8 ∧ ≡ 1 (mod 7) ⟹ n₇ ∈ {1, 8}；n₇ = 8 时 8 个
  7 阶子群（两两交 {e}）供 48 个非单位元，加单位元与任一西罗
  2-子群的 7 个非单位元**恰好 56 封顶**——第二个西罗 2-子群
  必然贡献新元素而超限，故西罗 2-子群唯一 ⟹ 正规，非单。

60 = |A₅| 是第一个非阿贝尔单群——第 13 章（定理 2.156）与
第 30 章的伏笔在这里收口。

## 32.5 UT 群族：西罗子群的天然标本

> **定义** UT(n, k)：k 上 n×n **单位上三角矩阵**全体
> （对角线全 1）。

> **命题 6.27/6.28** UT(n, k) ≤ GL(n, k)；UT(n, 𝔽_q) 是 p-群
> （q = p^f），阶 q^{n(n−1)/2}——自由参数是严格上三角的
> n(n−1)/2 个格子。

> **命题 6.29** 对奇素数 p，UT(3, 𝔽_p) 是 p³ 阶非阿贝尔群，
> 且每个元素满足 x^p = 1。

(x = I + N，N³ = 0，二项展开 (I+N)^p = I + pN + (p 选 2)N² = I。)
于是 UT(3, 𝔽_p) 与 ℤ_p×ℤ_p×ℤ_p 有**完全相同的阶档案**
（1 个单位元 + p³−1 个 p 阶元）却不同构——第 31 章的"阶档案
是完全不变量"**只对阿贝尔群成立**，这是最短的反例。p = 2 的
情形不同：(I+N)² = I + N²（N² ≠ 0），UT(3, 𝔽₂) 的指数是 4，
阶谱 {1, 2⁵, 4²}——与 D₄ 相同（原书习题 2.123：二者同构）。

> **定理 6.30** |GL(n, 𝔽_q)| = (qⁿ−1)(qⁿ−q)⋯(qⁿ−q^{n−1})。

（逐列数基：第 j 列有 qⁿ−q^{j−1} 个选择——避开已选列张成的
子空间。）

> **定理 6.32** UT(n, 𝔽_q)（q = p^f）是 GL(n, 𝔽_q) 的西罗
> p-子群。

阶数对账：|GL(n, 𝔽_q)| 的 p-部分 = q^{n(n−1)/2} 恰是 |UT|。
例如 |GL(3, 𝔽₂)| = 7·6·4 = 168 = 21·8，UT(3, 𝔽₂) 是其 8 阶
西罗 2-子群。GL(3, 𝔽₂) 是著名的**单群**（168 阶，第二小的
非阿贝尔单群）——原书随后引出有限单群分类（约 10⁴ 页的集体
工程）的历史注记。

## 32.6 机器验证一：Lean——候选枚举与计数算术

**文件：`examples/lean/Abstractalgebra/Ch32Sylow.lean`**。
西罗计数条件 n_p | m ∧ n_p ≡ 1 (mod p) 是纯整数量词于有界集，
`decide` 直接枚举：

```lean
-- 40 = 2³·5：n₅ | 8 且 ≡ 1 (mod 5) 只有 1 ⟹ 西罗 5-子群正规
example : (List.range 9).filter (fun d => d ∣ 8 ∧ d % 5 = 1) = [1] := by decide

-- 56 = 2³·7：n₇ | 8 且 ≡ 1 (mod 7) ∈ {1, 8}；非单群走 n₇ = 8 分支
example : (List.range 9).filter (fun d => d ∣ 8 ∧ d % 7 = 1) = [1, 8] := by decide
```

引理 6.25 的三案计数同样 `norm_num`：`6 * (5 - 1) + 10 * (3 - 1) = 44`
且 `> 30 - 1`（30 案超限）；`8 * 6 + 1 + (8 - 1) = 56` 且 `+1 > 56`
（56 案封顶）。|GL| 公式、168 = 21·8 的 p^e·m 分解、以及
"4 ∣ 12 有子群（V₄）而 6 ∣ 12 无子群"的拉格朗日反例背景数值。

## 32.7 机器验证二：Julia——子群枚举与 UT 群

**文件：`examples/julia/32_sylow.jl`**。手写置换群机器
（复合/闭包），然后**枚举全部子群**（单点与点对的闭包——这些
小群中每个子群至多 2 生成）数出西罗：

```julia
function sylow_count(G, gorder, p)
    e = 0; m = gorder
    while m % p == 0; m ÷= p; e += 1; end
    count(S -> length(S) == p^e, subgroups(G))
end
```

断言组：S₃（n₂ = 3, n₃ = 1）、A₄（n₂ = 1, n₃ = 4）、D₄（2-群
自身）、S₄（n₂ = 3, n₃ = 4），每个都核对 ≡ 1 (mod p) 与 | m；
30/40/56 的候选枚举与计数封顶；**UT(3, F₂)**（矩阵实现：
8 元、封闭、非交换、阶谱 {1,2⁵,4²} 与 D₄ 的置换实现逐项相等）；
**UT(3, F₃)**（27 元、全部元素 ≤ 3 阶——阶档案 = (ℤ/3)³
但非阿贝尔）；|GL(2,F₂)| = 6、|GL(3,F₂)| = 168。

## 32.8 机器验证三：Python 与 Prolog

**文件：`examples/python/32_sylow.py`**。sympy 的
`PermutationGroup.sylow_subgroup(p)` 给出一个西罗子群，然后
**用共轭轨道数它**（命题 6.17 的机器化）：

```python
def sylow_count(G, p):
    P = G.sylow_subgroup(p)
    pelems = list(P.elements)
    conj = set()
    for g in G.elements:
        conj.add(frozenset(~g * x * g for x in pelems))
    return len(conj)
```

对 S₃/A₄/S₄/D₆（六边形二面体群）逐一验证两条件与阶 p^e；
正规性按定义核验（A₄ 的 V₄ 共轭封闭、S₃ 的 2-子群共轭搬家）；
30/40/56 候选与计数；UT 用**海森伯元组乘法**
(a,b,c)·(d,e,f) = (a+d, b+e, c+f+ae) mod p 实现（与矩阵实现
互为对拍）；|GL(2,F₂)| = 6、|GL(3,F₂)| = 168 = 21·8、
|GL(2,F₃)| = 48。

**文件：`examples/prolog/32_sylow.pl`**。与 Julia 同构的
闭包机器（`close_set/2` 排序去重到不动点；`subgroups/2` 由
单点/点对闭包生成），`sylow_count/4` 把两个条件写进子句体——
条件不满足整个查询失败，断言与定理同形。UT 群用元组乘法，
`ut_step/5` 迭代幂求元素阶。全部断言与 Julia/Python 三通道
取同一组数值（n₂/n₃ 各群、UT 阶谱、GL 阶），互相锁死。

## 32.9 要点回顾

1. 西罗三件套：存在（定理 6.21，子集作用证明，阶恰 p^e）、
   共轭（定理 6.19，作用在西罗子群集上）、计数
   （n_p ≡ 1 mod p ∧ n_p | m）。
2. 唯一 ⟺ 正规（推论 6.20）——"数出 n_p = 1"是最常用的
   找正规子群手法。
3. 小群非单性的标准剧本：枚举 n_p 候选 ⟹ 排除 n_p = 1 ⟹
   元素计数超限（30/40/56 三案是模板）；< 60 无非阿贝尔单群。
4. 拉格朗日逆命题：素数幂方向成立（命题 6.26），一般方向
   失败（A₄ 无 6 阶子群）。
5. UT(3, 𝔽_p) 家族：西罗子群的天然标本（定理 6.32）+
   阶档案非不变性的最短反例（奇 p）；p = 2 时 ≅ D₄。
