## 15.1 从数到环：减法进入公理

群描述"一种运算"，代数的主战场却需要**两种运算**——加与乘。它们要
和平共处，就得签一份**分配律**契约。

> **定义（交换环）** 交换环 (R, +, ·) 是带两个运算的集合，满足：
> (i) (R, +) 是阿贝尔群（单位元 0，逆元 −a）；
> (ii) 乘法结合、交换，有单位元 1；
> (iii) **分配律**：a(b + c) = ab + ac。
> 若还要求 1 ≠ 0（排除零环），称非平凡环。

交换环清单第一页：ℤ、ℚ、ℝ、ℂ、ℤ/mℤ、多项式环 R[x]、函数环
ℝ^ℝ（逐点运算）。非交换环（矩阵环）本教程只作背景板。

公理立刻挤出几条"负号纪律"（原书命题 3.5 一带，证明全是分配律的
机械推论）：

> (i) a·0 = 0；　(ii) (−a)b = −(ab)；　(iii) (−a)(−b) = ab；
> (iv) (a − b)c = ac − bc；　(v) 若 1 = 0 则 R 是零环。

(iii) 是"负负得正"的公理化解释：由 (−a)(−b) + (−a)b = (−a)((−b)+b) =
(−a)·0 = 0，得 (−a)(−b) = −((−a)b) = −(−ab) = ab。

## 15.2 零因子、单位与整环

> **定义** a ≠ 0 是**零因子**，若存在 b ≠ 0 使 ab = 0。a 是**单位**
> （unit），若存在 b 使 ab = 1（b 唯一，记 a⁻¹）。无零因子的非平凡
> 交换环称**整环**（domain）；每个非零元都是单位的环称**域**（field）。

三个关键事实：

> **命题 3.14** a 可逆 ⟹ a 不是零因子（ab = 0 两边乘 a⁻¹）。
> **消去律** 整环中 ab = ac ∧ a ≠ 0 ⟹ b = c（分配律减法 + 无零因子）。
> **命题 3.15** ℤ/mℤ 是整环 ⟺ m 是素数；此时它还是域。

ℤ/6ℤ 的乘法表（第 05 章 Prolog 通道已打印过）里 3·4 = 0——零因子现场。
而 ℤ/7ℤ 的非零行没有零，且每行都有 1（费马小定理保证了 1 的出现）。
域 ⟹ 整环（命题 3.14 的逆否），反向不真：ℤ 是整环不是域。

> **命题 3.2x（域的分数化）** 每个整环 D 可以嵌入一个域 Frac(D)——
> D = ℤ 时 Frac = ℚ。构造与"分数相等"的良定义（a/b = c/d ⟺ ad = bc，
> 需要整环性保证）是本节的技术核心，也是第 16 章的开场白。

**函数环 ℝ^ℝ** 是"天然有零因子"的教材：f(x) = max(x,0) 与
g(x) = max(−x,0) 都非零，但 fg = 0。子环判别（习题 3.12-3.13）：
非空 + 对减法与乘法封闭。

## 15.3 子环与同态预告

> **定义** S ⊆ R 是**子环**，若 1 ∈ S 且对减法、乘法封闭。

例：ℤ[√2] = {a + b√2} 是 ℝ 的子环（乘法封闭靠 (a+b√2)(c+d√2) =
(ac+2bd) + (ad+bc)√2）；ℤ[i]（高斯整数）是 ℂ 的子环。**环同态**
f : R → S 满足 f(1) = 1、f(a+b) = f(a)+f(b)、f(ab) = f(a)f(b)——
细节第 18 章展开。

## 15.4 机器验证一：Lean——Ring 公理层

**文件：`examples/lean/Abstractalgebra/Ch15Rings.lean`。**
mathlib 的 `CommRing R` 类型类就是全部公理。文件证明"负号纪律"五条：

```lean
-- a·0 = 0（分配律 + 加法单位唯一）
example {R : Type*} [CommRing R] (a : R) : a * 0 = 0 := by
  have h : a * 0 + a * 0 = a * 0 + 0 := by
    calc a * 0 + a * 0 = a * (0 + 0) := by ring
      _ = a * 0 := by ring
      _ = a * 0 + 0 := by ring
  rw [add_right_cancel h]

-- 负负得正：(−a)(−b) = ab
example {R : Type*} [CommRing R] (a b : R) : (-a) * (-b) = a * b := by ring

-- 命题 3.14：单位不是零因子
example {R : Type*} [CommRing R] {a b : R} (ha : IsUnit a) (h : a * b = 0) :
    b = 0 := by
  obtain ⟨u, hu⟩ := ha
  calc b = (u.inv * u.val) * b := by rw [u.mul_inv]; ring
    _ = u.inv * (u.val * b) := by ring
    _ = 0 := by rw [show u.val = a from hu, h]; ring
```

（a·0 = 0 的证明是"加法消去"的标准操作——比 `ring` 直给更能展示
公理的挤出过程；负号条目则 `ring` 一步。命题 3.14 手工展开单位乘逆。）
ℤ/mℤ 侧：`ZMod 7` 是域（mathlib 实例），断言每个非零元可逆
（`IsUnit` 逐元素 decide）；`ZMod 6` 中 3·4 = 0（零因子现场）。

## 15.6 机器验证三：Python 与 Prolog

**文件：`examples/python/15_rings.py`**：复算 Julia 断言，并加做
**单位群表**：U(ℤ_m) = {a : gcd(a,m) = 1} 的乘法表对 m = 5..12 逐个

（有限交换环里"零因子 ∪ 单位 = 全部非零元"的实验）。

**文件：`examples/prolog/15_rings.pl`**：

```prolog
% 零因子：存在非零 b 使 ab = 0
zero_divisor(R, A) :- elem(R, A), A \= z0,
    elem(R, B), B \= z0, mul(R, A, B, z0).

% 命题 3.15 的有限验证：ℤ_m 整环 ⟺ 无零因子
domain(R) :- \+ zero_divisor(R, _).
```

文件构造 ℤ₅/ℤ₆/ℤ₈ 的加乘双表（表驱动），断言：ℤ₅ 无零因子且非零
元均可逆；ℤ₆ 零因子恰 {2,3,4}；ℤ₈ 零因子恰 {2,4,6}；m = 2..16 的
domain 谱 = 素数集。

## 15.7 要点回顾

1. 交换环 = 加法群 + 乘法幺半群 + 分配律；负号纪律（a·0 = 0、
   负负得正）全部是分配律的推论。
2. 三种身份：零因子（ab = 0 的非零解）/ 单位（ab = 1 的解）/ 普通元素。
   整环 = 无零因子；域 = 全是非零单位；域 ⟹ 整环。
3. 消去律 ⟺ 整环——第 01 章良序推导出的"消去"在环论里的化身。
4. ℤ/mℤ 整环 ⟺ m 素 ⟺ ℤ/mℤ 域（命题 3.15）——素数的三张面孔。
5. 函数环 ℝ^ℝ 天然有零因子；ℤ[√2]、ℤ[i] 是手算友好的子环。
