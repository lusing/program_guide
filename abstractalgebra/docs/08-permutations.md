## 8.1 置换：第一个"运算的主角"

第 07 章的命题 2.13 埋了伏笔：集合 X 到自身的**双射**全体 Sₓ 在复合下
封闭、有恒等（恒等函数）、每个元素有逆（反函数）——这三条正是下一章
"群"的定义。本章先把最重要的实例 S_n = {1, 2, …, n} 上的双射全体研究透。

> **定义** n 元集合 X 上的置换是 X → X 的双射。Sₓ 记全体置换；
> X = {1,…,n} 时记 S_n。|S_n| = n!（n 个位置放 n 个不同的数，逐位
> 递减）。

习惯用"两行记号"α = (1→α(1), …, n→α(n))，例如 S₃ 中
α = (1 2 3 / 2 1 3) 表示 α(1)=2, α(2)=1, α(3)=3。**复合从右向左读**：
(αβ)(i) = α(β(i))——与函数复合一致，但初学时务必盯紧顺序。

## 8.2 循环与完全分解

> **定义** 设 i₁, …, i_r 互不相同。r-循环 (i₁ i₂ … i_r) 是把
> i₁ ↦ i₂, i₂ ↦ i₃, …, i_r ↦ i₁ 且固定其余点的置换。2-循环称为
> **对换**。两个循环**不相交**是指它们移动的点集不相交。

> **引理 2.22** 不相交的置换（特别地，不相交循环）交换。

> **命题 2.24（完全分解存在）** 每个置换 α ∈ S_n 或是循环，或是
> 不相交循环之积。

证明是"跟着 α 走"：从任一被移动的点 i 出发迭代 i, α(i), α²(i), …，
有限性保证回到 i（否则单射性被破坏），得到一个循环；删掉这些点，在剩余
部分重复。∎

> **定理 2.26（完全分解唯一）** 不计循环的书写顺序与固定点（1-循环），
> 完全分解唯一。

> **命题 2.25** 完全分解中 α 在点 i 上的轨道 = 含 i 的那个循环。
> **命题 2.55（本节最重要的计算工具，原书放在 §2.3）** α 的**阶**
> （最小正 k 使 α^k = 1）= 完全分解中各循环长度的最小公倍数。

例：(1 2 3)(4 5) ∈ S₅ 的阶 = lcm(3, 2) = 6。算幂时注意循环是独立转的：
每个 r-循环转满 r 次回家，整体回家要等所有循环同时回家——lcm。

## 8.3 共轭与循环结构

> **引理 2.31** α γ α⁻¹ 把 i ↦ j 时，α γ α⁻¹ 把 α(i) ↦ α(j)。

直接验证：α γ α⁻¹(α(i)) = α γ(i) = α(j)。于是"共轭只是给所有点改名"：

> **命题 2.32** α γ α⁻¹ 与 γ 有相同的**循环结构**（把 γ 的完全分解中
> 每个点 i 换成 α(i) 即得）。
> **命题 2.33** γ, γ′ ∈ S_n 共轭 ⟺ 循环结构相同。

例：在 S₅ 中 (1 2 3)(4 5) 的全部共轭元恰是全部 (abc)(de) 型置换——
5!/(3·2) = 10 个（3-循环选法 C(5,3)×2 = 20 种 × 2-循环 1 种…直接数：
5!/(3·1·1·2·1) hmm，通用公式见第 13 章类方程）。**循环结构**是共轭
的不变量，也是第 13 章 S_n 共轭类分类的钥匙。

## 8.4 奇偶性与符号

> **定义** sgn : S_n → {±1} 定义为
> sgn(α) = ε(α)/n!，其中 ε(α) = #{(i, j) : i < j, α(i) > α(j))} 是
> **逆序数**。逆序数为偶的称偶置换，奇的称奇置换。

sgn 的良定义性初看令人不安：同一个 α 有很多对换分解（命题 2.35 保证
至少存在一种），凭什么每种分解给出的奇偶一致？原书的路线是：

> **命题 2.35** 每个 α ∈ S_n (n ≥ 2) 是对换之积。
> （r-循环 (i₁ … i_r) = (i₁ i_r)(i₁ i_{r−1}) … (i₁ i₂)。）

> **引理 2.38** 若 τ 是对换，则 sgn(τα) = −sgn(α)。
> **定理 2.39** sgn(αβ) = sgn(α)·sgn(β)。
> **定理 2.40** "α 是偶/奇置换"与所选的对换分解无关：偶置换 ⟺ 偶数
> 个对换之积。

定理 2.39 是关键一步——它说 **sgn 是"乘法保持"的**（同态的预告），而
引理 2.38 是它的单步引擎。定理 2.40 指出"奇偶性"不依赖分解：若 α 同时
是 t₁ 个与 t₂ 个对换之积，则 sgn 由两种算法给出 (−1)^{t₁} = (−1)^{t₂}。

偶置换全体构成 S_n 的子群 **A_n（交错群）**，|A_n| = n!/2（对换陪集
对半分——第 10 章拉格朗日定理解释"一半"的确切含义；直接证：α ↦ τα
是偶奇置换间的双射）。

**15-字谜（例 2.36/2.42）** Sam Loyd 的 15 字谜：4×4 格含 15 块滑块与
1 个空格，问哪些初始布局能复原。答案是纯粹的群论：把空格视为第 16 个
"块"，每次滑动 = 一个对换（空格与某块交换），但棋盘的几何限制使得
**空格的行走路径上黑白格交替**，最终能实现的置换只有偶置换——故初始
布局 α 可解 ⟺ α ∈ A₁₆（加上空格归位的行列条件）。著名的"14-15 互换"
布局不可解，正因为它是对换（奇置换）。计算机科学里"无解证明"的第一个
群论范例。

## 8.5 机器验证一：Lean——Equiv.Perm 与符号

**文件：`examples/lean/Abstractalgebra/Ch08Permutations.lean`。**
mathlib 把置换做成 `Equiv.Perm X`，符号做成 `Equiv.Perm.sign`，循环字做成
`List.formPerm`。文件证明：sign 的乘法性（定理 2.39）、对换的符号
（引理 2.38）、完全分解的具体算例（命题 2.55 的阶）、以及 |A₅| = 60。

```lean
-- 定理 2.39 的机器版：sign 是乘法同态（mathlib：Equiv.Perm.sign_mul）
example {α : Type*} [Fintype α] [DecidableEq α] (f g : Equiv.Perm α) :
    Equiv.Perm.sign (f * g) = Equiv.Perm.sign f * Equiv.Perm.sign g :=
  Equiv.Perm.sign_mul f g

-- 对换的符号 = −1（引理 2.38 的基础）
example {α : Type*} [Fintype α] [DecidableEq α] (x y : α) (h : x ≠ y) :
    Equiv.Perm.sign (Equiv.swap x y) = -1 :=
  Equiv.Perm.sign_swap h
```

（`Equiv.Perm.sign` 取值在 ℤˣ 中，−1 即那个记号。）具体算例：手工构造
α = (0 1 2)(3 4) ∈ S₅——

```lean
def alpha5 : Equiv.Perm (Fin 5) :=
  (List.formPerm [0, 1, 2] * List.formPerm [3, 4] : Equiv.Perm (Fin 5))

set_option maxRecDepth 20000 in
example : alpha5 ^ 6 = 1 := by decide

example : alpha5 ^ 3 ≠ 1 := by decide

example : alpha5 ^ 2 ≠ 1 := by decide

-- α 的符号 = −1：3-循环（偶）× 对换（奇）= 奇（推论 2.41）
example : Equiv.Perm.sign alpha5 = -1 := by decide
```

幂轨迹断言组就是命题 2.55（阶 = lcm(3, 2) = 6）在这个具体置换上的核验；
sign 断言则演示推论 2.41 的"奇偶相乘"规则——**偶 × 奇 = 奇**，别想当然
写成 +1。文件还断言 |A₅| = 60 = 5!/2（sign 把 S₅ 均分两半的计数版）。

## 8.6 机器验证二：Julia——从复合到 Burnside 级穷举

**文件：`examples/julia/08_permutations.jl`**。置换用 `Vector{Int}` 表示
（p[i] = α(i)），三件核心：

```julia
compose(α, β) = [α[β[i]] for i in eachindex(β)]   # (αβ)(i) = α(β(i))
inv(α) = begin r = similar(α); for (i, ai) in enumerate(α); r[ai] = i; end; r end

"""循环分解：返回 [(i₁,…,i_r), …]，只列长度 ≥ 2 的循环。"""
function cycles(α)
    n, seen, out = length(α), falses(length(α)), Vector{Int}[]
    for i in 1:n
        seen[i] && continue
        c = Int[]; j = i
        while !seen[j]
            seen[j] = true; push!(c, j); j = α[j]
        end
        length(c) > 1 && push!(out, c)
    end
    out
end

signum(α) = (-1)^count(i < j && α[i] > α[j] for i in 1:length(α), j in 1:length(α))
```

断言组：(1) S₃ 全部 6 个置换的完全分解与手算一致，复合表逐项核对；
(2) **阶 = lcm(循环长)**（命题 2.55）：S₄ 全部 24 个置换逐个验证；
(3) **sgn 乘法性**（定理 2.39）：S₄ 全部 24² = 576 对乘积验证
sgn(αβ) = sgn(α)sgn(β)；(4) |A₄| = 12；(5) **共轭保持循环结构**
（命题 2.32）：随机/全量取 α, γ ∈ S₄，比对 cycles(αγα⁻¹) 与
"γ 的循环点集过 α 的像"；(6) 循环结构类的大小：S₅ 中 (abc)(de) 型
恰 20 个 = 5!/6，与类方程预告一致。

## 8.7 机器验证三：Python 与 Prolog

**文件：`examples/python/08_permutations.py`** 用 itertools.permutations
复算 Julia 全部断言（S₄ 级），并加做 15-字谜判定器：输入 4×4 布局，
计算其作为 S₁₆ 置换的奇偶与空格行位置，按"目标布局的奇偶 + 空格行差
奇偶"给出可解性判定；对已知可解布局（目标自身、单次合法滑动得到的布局）
断言判定器说"可解"，对 14-15 互换布局断言"不可解"。

**文件：`examples/prolog/08_permutations.pl`** 用列表表示置换：

```prolog
% 复合：α∘β 逐点计算
perm_compose(Alpha, Beta, AB) :-
    length(AB, N),
    forall(between(1, N, I),
           ( nth1(I, Beta, B), nth1(B, Alpha, A), nth1(I, AB, A) )).
```

（用 `nth1/3` 读写第 i 项——列表即函数表。）循环分解用同样的"跟着走"
逻辑：`cycle_of(Alpha, I, Cs)` 从 I 迭代到回到起点。文件断言：S₃ 的
6 个置换循环分解正确、sign 由逆序数算出且 sgn(αβ) = sgn(α)sgn(β) 在
S₃ 全体 36 对上成立、恒等置换是唯一偶 3-循环…再加对换 = 奇置换的单点
断言。

## 8.8 要点回顾

1. Sₙ = {1..n} 上双射全体，|Sₙ| = n!；复合从右向左。
2. 每个置换有唯一的（不计顺序）不相交循环完全分解；阶 = 各循环长的 lcm
   （命题 2.55）。
3. 共轭 α γ α⁻¹ = "γ 改名"；共轭类 ⟺ 循环结构（命题 2.33）——第 13
   章类方程的钥匙。
4. sgn : Sₙ → {±1} 乘法保持（定理 2.39），奇偶性与对换分解的选取无关
   （定理 2.40）；偶置换全体 Aₙ 占一半。
5. 15-字谜可解 ⟺ 布局是偶置换——"不可解"的第一个群论证明。
