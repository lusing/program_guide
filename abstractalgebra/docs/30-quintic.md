# 30 一般五次方程的不可解性

**对应原书 §5.2-5.3（pp. 447-472）。**

---

## 30.1 陈述：不是"没有公式"，是"没有根式公式"

> **定理（Abel–Ruffini，1824）** 一般五次方程 x⁵ − x − 1 = 0 型
> （更准确：一般方程 x⁵ + a₄x⁴ + ⋯ + a₀ = 0 以独立超越元为系数）
> **没有根式解**：不存在一个"用系数经 +、−、×、÷、ⁿ√ 的有限表达式"
> 给出它的根。

精确的表述需要"根式扩张塔"的语言：

> **定义** F 上的元素 α **可用根式表出**（over F），若存在塔
> F = F₀ ⊆ F₁ ⊆ ⋯ ⊆ F_r ∋ α，每层 F_{i+1} = F_i(βᵢ)，βᵢ^{nᵢ} ∈ F_i。
> 方程 f(x) = 0 **根式可解**，若它的全部根都可用根式表出。

二次（√）、三次（∛ + 复数）、四次（嵌套平方根）都根式可解；
五次一般不行——这就是 26 岁的 Abel 证明、Galois 用群论重写的历史
转折点。

## 30.2 伽罗瓦群：方程的对称指纹

> **定义** f(x) ∈ F[x]，E 是它的分裂域（把全部根添加进 F 的最小域）。
> **伽罗瓦群** Gal(E/F) = E 的保持 F 逐点不动的全部自同构构成的群。

自同构必须把 f 的根送到 f 的根（系数不动 ⟹ 根满足的方程不动），
所以 Gal(E/F) 嵌入根集的置换群 Sₙ——**方程的群 = 根的对称群**。
经典案卷：
- x² − 2 over ℚ：E = ℚ(√2)，Gal = C₂（√2 ↦ −√2）；
- x³ − 2 over ℚ：E = ℚ(∛2, ω)，Gal ≅ S₃（三个根任意置换）；
- x⁴ − 10x² + 1 over ℚ：E = ℚ(√2, √3)，Gal ≅ V₄（克莱因四元群）。

> **伽罗瓦对应（主定理的化身）** 中间域 F ⊆ K ⊆ E 与 Gal(E/F) 的子群
> 一一对应（K ↦ Gal(E/K)）；塔的包含关系与子群的包含关系**反向**。
> **可解性判别**：f 根式可解 ⟺ Gal(E/F) **可解群**（有子群链
> G = G₀ ⊳ G₁ ⊳ ⋯ ⊳ 1，每层商群 Gᵢ/Gᵢ₊₁ 素数阶循环）。

根式塔的每层 ⊆ 对应群塔的每层正规子群——"开 n 次方" ↔ "商循环群"。
这是全书最深刻的一座桥：**域的加法结构 ↔ 群的商结构**。

## 30.3 为什么五次死了：A₅ 是单群

一般五次方程的伽罗瓦群是 S₅（五个根独立）。S₅ 的子群链只有
S₅ ⊳ A₅ ⊳ 1，而 **A₅ 是单群**（第 13 章定理 2.156 已证）——A₅ 没有
非平凡正规子群，所以 S₅ 的可解链必须一步跨过 A₅，但 S₅/A₅ ≅ C₂ 之后
A₅ 本身再无法拆成循环商。S₅ 不可解 ⟹ 一般五次方程根式不可解。∎

第 13 章的 Aₙ 单性定理在这里完成闭环——那不是孤立的奇观，而是
Abel–Ruffini 定理的承重墙。

## 30.4 具体不可解的五次

"一般五次"是超越系数的抽象物；具体整系数例子更狠：

> **例** x⁵ − 6x + 3。Eisenstein（p = 3）不可约 ⟹ Gal(E/ℚ) 在 5 根上
> 传递。实分析：f 有恰三个实根（f′ = 5x⁴ − 6 的两个临界点给出
> 局部极值符号交替），复共轭给出一个对换；不可约 + 素数次 + 对换
> ⟹ Gal ⊇ A₅（传递 + 对换 ⟹ Gal(E/ℚ) ≅ S₅）。S₅ 不可解 ⟹
> **x⁵ − 6x + 3 无根式解**。

这是"具体判据"的样板：不可约（Eisenstein）→ 实根计数 → 复共轭对换
→ 群够大 → 不可解。

## 30.5 机器验证一：Lean——判据的代数内核

**文件：`examples/lean/Abstractalgebra/Ch30Quintic.lean`。**
mathlib 的伽罗瓦理论库（`Mathlib.FieldTheory.Galois`）体量巨大，
全量导入在本教程的构建纪律下不可行；文件以可编译的内核断言呈现
判据链条中可 decidable 的每一环：

```lean
-- Eisenstein（p = 3）的三个数值条件：3 | 6、3 ∤ 1、9 ∤ 3
example : (3 : ℕ) ∣ 6 := by decide
example : ¬ (3 : ℕ) ∣ 1 := by decide
example : ¬ (9 : ℕ) ∣ 3 := by decide

-- f(−2) < 0、f(−1) > 0：一个实根在 (−2, −1)
example : (-2 : ℚ) ^ 5 - 6 * (-2) + 3 < 0 := by norm_num
example : (-1 : ℚ) ^ 5 - 6 * (-1) + 3 > 0 := by norm_num
```

实根计数的五点符号表（−2, −1, 0, 1, 2 → −, +, +, −, +）逐点
`norm_num`；x⁵−2 的 Eisenstein（p = 2）三条件；置换计数骨架
5! = 120、120/2 = 60；可解链断裂数值版 60 = 2²·3·5。

## 30.6 机器验证二：Julia——数值侦察与群结构

**文件：`examples/julia/30_quintic.jl`**：

```julia
# x⁵−6x+3 的实根计数：f' = 5x⁴ − 6 的两个实临界点 ±(6/5)^{1/4}
c1 = -(6 / 5) ^ 0.25
c2 = (6 / 5) ^ 0.25
pts = [-2, c1, 0, c2, 2]
signs = [sign(f(x)) for x in pts]
@assert signs == [-1, 1, 1, -1, 1]
changes = count(i -> signs[i] * signs[i+1] < 0, 1:4)
@assert changes == 3
```

断言组：(1) **实根计数**：五点符号 [−,+,+,−,+] 恰三次变号，配合
f′ 仅两实零点（分段单调）得恰三实根；(2) **置换枚举**：字典序
next-permutation 算法生成 S₅ 全部 120 个置换，逆序数奇偶分出
60 个偶置换；(3) **可解对照**：x⁵−2 的根 2^{1/5}·ωᵏ（k = 0..4）
逐根 |z⁵−2| < 1e-12、根之和 = 0（韦达）；(4) **根式塔数值对拍**：
ℚ → ℚ(√2) → ℚ(√2, √(1+√2)) 的嵌套恒等式在 BigFloat 精度下验证
（残差 < 1e-70）——"根式扩张"的每一层都是一次开方。

## 30.7 机器验证三：Python 与 Prolog

**文件：`examples/python/30_quintic.py`**。sympy 内置伽罗瓦群计算
（`sp.galois_group`，预解式方法）把 30.4 的五步判据压缩成一行：

```python
G5, _alt = sp.galois_group(sp.Poly(x**5 - 6 * x + 3, x), by_name=True)
assert G5.name == "S5"                    # x⁵−6x+3 的群 = S₅
assert not SymmetricGroup(5).is_solvable  # ⟹ 无根式解
G2, _ = sp.galois_group(sp.Poly(x**5 - 2, x), by_name=True)
assert G2.name == "M20"                   # 对照：x⁵−2 = Frobenius 群 F₂₀
```

断言组：Eisenstein 系数条件（3 | −6、3 | 3、9 ∤ 3、3 ∤ 1）、
`nroots` 恰三实根、<5-循环, 换位> 阶 120、3-循环生成 A₅（60）、
`is_solvable` 对 S₅/A₅ 均假、x⁵−2 的 M₂₀ 由 (01234) 与 k↦2k 的
4-循环生成且可解、根 2^{1/5}ωᵏ 符号幂验证、随机不可约五次扫描
（30 例中 29 例群 = S₅ 的通有性佐证）。

**文件：`examples/prolog/30_quintic.pl`**。置换机器全部手写
（复合/求逆/奇偶/闭包/共轭），其中 **A₅ 单性的类算术**是本章的
重头戏——把第 13 章的证明压缩成可枚举的计算：

```prolog
% A₅ 的共轭类大小经 60×60 次共轭暴力算出 = [1,12,12,15,20]
% 正规子群必为含 e 的类并：1 + (子多重集和) 必须整除 60（Lagrange）
forall((selections([12, 12, 15, 20], Sub), sum_list(Sub, S0), N is S0 + 1),
       ((N = 1 ; N = 60 ; 60 mod N =\= 0))),
```

16 种类并除 {1, 60} 外无一整除 60——A₅ 没有非平凡正规子群。
这是**完整**的单性证明：类大小是机器算的，Lagrange 是引理，剩下的
只有算术。文件另证：符号同态 sgn(στ) = sgn(σ)sgn(τ) 在全部
14400 对置换上成立、<5-循环, 换位> 的闭包恰 120 元、20 个 3-循环
生成 A₅、x⁵−6x+3 的 Eisenstein 与五点符号表、以及 **F₂₀ 的可解
证书**：20 元闭包内 C₅ = ⟨5-循环⟩ 共轭封闭（正规）且左陪集分解
4 × 5——链 1 ⊂ C₅ ⊂ F₂₀ 的商 ℤ/5、ℤ/4 交换，与 S₅ 的断裂对照。

## 30.8 要点回顾

1. 不可解 = 无根式塔；一般五次方程的群是 S₅。
2. 伽罗瓦群 = 分裂域的自同构群 = 根的置换群；域塔 ↔ 群塔反向对应。
3. 根式可解 ⟺ 群可解（素循环商链）；S₅ ⊳ A₅ ⊣ 1 且 A₅ 单
   （第 13 章闭环）⟹ S₅ 不可解 ⟹ Abel–Ruffini。
4. 具体判据五步：Eisenstein 不可约 → 实根计数恰三 → 复共轭给对换
   → 传递+对换 ⟹ 含 A₅ → 不可解。x⁵ − 6x + 3 是样板。
5. x⁵ − 2 可解（F₂₀ 群）：五次方程很多可解，死的是"一般"五次。
