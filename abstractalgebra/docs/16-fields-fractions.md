# 16 域与分式域

**对应原书 §3.2（pp. 158-166）。**

---

## 16.1 域：算术的完整舞台

> **定义** 域 F 是非平凡交换环，其中每个非零元都是单位。
> 域必是整环（命题 3.14）：ab = 0 ∧ a ≠ 0 ⟹ b = a⁻¹(ab) = 0。

域清单：ℚ、ℝ、ℂ、ℤ/pℤ（p 素）；**有限域都是素数幂阶的**
（ℤ₄、ℤ₈ 不是域——4 阶域另有其人，第 22 章揭晓 GF(4)）。
域上的线性代数（第 24 章）与多项式论（第 19-21 章）之所以顺畅，
全因"非零即可除"。

**方程的域论读法**（命题 2.106/3.2x 的合流）：域 F 上
ax = b (a ≠ 0) 有唯一解 x = a⁻¹b。线性方程组、矩阵求逆的整个
高斯消元故事，前提都是"系数在域里"——ℤ 上 2x = 1 无解正是
"ℤ 不是域"的第一个信号。

## 16.2 分式域：从 ℤ 到 ℚ 的普适再造

ℤ 是整环但不是域；人类历史上的解决方案是发明分数。这份方案可以
批量生产：

> **定理 3.21（分式域存在）** 每个整环 D 嵌入一个域 Frac(D)，
> 使 D 的每个非零元在 Frac(D) 中可逆，且 Frac(D) 的每个元素都是
> d/d′ 形（d, d′ ∈ D, d′ ≠ 0）。

**构造**（与第 12 章商群同一血统——又是"取商"！）：

1. 载体：D × D* 的序对 (a, b)，理解为"a 除以 b"；
2. 等价关系：(a, b) ~ (c, d) ⟺ **ad = bc**——整环性首次发力：
   这个关系的传递性证明需要消去律（非整环上传递性破产，
   原书用 ℤ/6ℤ 给出反例）；
3. 运算：[a/b] + [c/d] = [(ad+bc)/bd]，[a/b]·[c/d] = [ac/bd]——
   良定义性检查又是"换代表元逐项验"，bd ≠ 0 靠整环无零因子；
4. 嵌入 d ↦ [d/1]；逆元 [a/b]⁻¹ = [b/a]。

例：Frac(ℤ) = ℚ；Frac(ℤ[√2]) = ℚ(√2) = {a + b√2}；Frac(F) = F
（域已经"满了"——习题 3.17(vii)）。

**普适性**（原书以例示）：整环 D 到域 K 的单同态可以唯一扩张到
Frac(D)。"最小域"的地位由此锁定——分式域是"让 D 的非零元全部
可除"的最经济工程。

## 16.3 分式域的良定义性：为什么非要整环

等价关系 ~ 的传递性在 ℤ/6ℤ 上的破产值得慢镜头回放：取
[2/1] ~ [4/2]? 在 ℤ/6ℤ 中 2·2 = 4·1 = 4 ✓；[4/2] ~ [2/1]? 对称显然；
但要造出 a ~ b ~ c 而 a ≁ c：取 (2,1) ~ (4,2)（2·2 = 4·1）与
(4,2) ~ (8,4)（4·4 = 8·2 = 16 ≡ 4 ✓ hmm 需要仔细算）——机器通道
（下节 Julia）直接在 ℤ/6ℤ 上跑"伪造的等价关系"，输出反例三元组。
**结构定理的条件不是装饰，每一条都对应一堵真实的墙。**

## 16.4 机器验证一：Lean——Frac 的正式化侧影

**文件：`examples/lean/Abstractalgebra/Ch16Fields.lean`。**
mathlib 的分式域是 `FieldOfFractions`/`IsFractionRing` 体系；文件以
两个可计算侧面呈现：

```lean
-- 域 ⟹ 整环：消去律
example {F : Type*} [Field F] {a b c : F} (ha : a ≠ 0) (h : a * b = a * c) :
    b = c := by
  calc b = a ⁻¹ * (a * b) := by field_simp
    _ = a ⁻¹ * (a * c) := by rw [h]
    _ = c := by field_simp

-- 域上 a ≠ 0 ⟹ ax = b 有唯一解（ax = b 的域论读法）
example {F : Type*} [Field F] (a b : F) (ha : a ≠ 0) :
    ∃! x : F, a * x = b := ⟨a ⁻¹ * b, by field_simp, fun y hy => by
      field_simp [hy]⟩
```

（`field_simp` 是 mathlib 专为"非零即可除"设计的自动化——它自动
挑出非零假设移走除法/逆元，域上证明的标准姿势。）ℚ = Frac(ℤ) 的
正式化由 `Rat` 与 `IsFractionRing ℤ ℚ` 实例承担；文件断言
Frac(ℤ[√2]) 的模型 ℚ(√2) 中 (√2)² = 2 型的算术（以 a + b√2 的
序对模型手算加乘，decide 收尾）。

## 16.5 机器验证二：Julia——序对分式的完整机器化

**文件：`examples/julia/16_fields.jl`** 把 16.2 节的构造**逐字实现**：

```julia
"""序对 (a, b) 表示 a/b；等价类代表元取既约形式（b > 0, gcd = 1）。"""
struct Frac
    num::Int
    den::Int            # > 0
end

frac(a::Int, b::Int) = begin
    b == 0 && error("分母为零")
    g = gcd(a, b); s = b < 0 ? -1 : 1
    Frac(s * a ÷ g, s * b ÷ g)
end

Base.:+(f::Frac, g::Frac) = frac(f.num * g.den + g.num * f.den, f.den * g.den)
Base.:*(f::Frac, g::Frac) = frac(f.num * g.num, f.den * g.den)
```

断言组：(1) ℤ 上跑通：1/2 + 1/3 = 5/6、1/2 · 2/3 = 1/3、
(2/6) == (1/3)（等价关系的代表元无关性由既约化保证）；(2) 把同一
套构造搬到 **ℤ[√2]** 上（序对 (a,b) 表示 a + b√2，乘法 (a,b)(c,d) =
(ac+2bd, ad+bc)），造出 Frac(ℤ[√2])，断言 (0,1)⁻¹·(1,1)·(0,1) = (1,0)
（√2 · √2 = 2）型算术 ✓；(3) **良定义性爆破实验**：在 ℤ/6ℤ 上强行
定义 (a,b) ~ (c,d) ⟺ ad ≡ bc (mod 6)，程序自动找到传递性反例
（输出具体三元组），与 16.3 节的警告互证；(4) ℤ_m 上 gcd 消去跑
m = 2..20：分式构造良性 ⟺ m 素（命题 3.15 的再确认）。

## 16.7 要点回顾

1. 域 = 非零元全可逆 ⟹ 整环；ℚ/ℝ/ℂ/ℤ_p 是四大样板，有限域皆素幂阶。
2. 分式域构造 = 商构造第三次登场（ℤ/mℤ、商群之后）：序对 + 等价类 +
   良定义运算；等价关系 (a,b) ~ (c,d) ⟺ ad = bc 的传递性**必须**
   整环（消去律）。
3. Frac(ℤ) = ℚ；Frac(F) = F；分式域是"让非零元可除"的最小工程。
4. field_simp 是域上证明的自动化利器；良定义性爆破实验（ℤ/6ℤ 上
   分式构造失败）是"定理条件非装饰"的最佳教具。
5. 下一章起进入多项式环——域与整环的公理化回报即将变现。
