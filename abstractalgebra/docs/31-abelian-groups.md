# 31 有限阿贝尔群

**对应原书 §6.1（pp. 473-486）。**

---

## 31.1 分类：阿贝尔群的"算术基本定理"

第 I 篇（第 9-14 章）我们学会了用拉格朗日定理、群作用和共轭类去**逼近**
一个有限群的结构，但"把所有 n 阶群列出来"这件事，非阿贝尔情形至今
没有闭式答案。有限**阿贝尔**群则完全不同——本章的定理说：**n 阶阿贝尔
群的清单可以像 n 的因数分解一样写出来**。这是群论里罕见的"完全分类"，
地位相当于整数世界的算术基本定理。

先看两个基石概念（原书命题 6.1、6.2）：

> **命题 6.1** 阿贝尔群 G 的子群 S、T 满足 G = S + T 当且仅当
> G = S ⊕ T 且 S ∩ T = {0}（即每个 g 有唯一分解 g = s + t）。

> **命题 6.2** 若 G = S ⊕ T，则 G ≅ S × T（外直积与内直和互相实现）。

外直积（第 9 章）与内直和于是"同一枚硬币的两面"。下面的书写从此混用
⊕ 与 ×。

## 31.2 准素分解：先把素数分开

整数分解先拆素数幂；群分解先拆**准素分支**：

> **定义** 阿贝尔群 G 是 **p-准素**的，若每个元素都被某个 p 的幂零化。
> G 的 **p-准素分支**是 G_p = {a : pⁿa = 0 对某 n ≥ 1}。

准素分支总是子群（阿贝尔性保证）；非阿贝尔群这是**假的**——原书给的
反例：S₃ 的"2-准素部分" {e, (12), (13), (23)} 根本不是子群，
(12)(13) = (132) 跑出去了。

> **定理 6.5（准素分解定理）**
> (i) 每个有限阿贝尔群 G 是其 p-准素分支的直和：G = ⊕_p G_p；
> (ii) G ≅ G′ 当且仅当对每个素数 p 有 G_p ≅ G′_p。

**证明思路（i）**：取非零元 r，其阶 d = p₁^e₁⋯p_r^e_r。令 rᵢ = (d/pᵢ^eᵢ)r，
则 rᵢ ∈ G_{pᵢ} 且诸 rᵢ 的 gcd 是 1，用 Bézout 系数把 r 拆进各准素分支
——每个元素都落进 ⊕G_p，再证和是直和。∎

于是分类问题被切成两半：**每个素数各自处理，最后用 CRT 拼回去**。
拼回去用的正是第 9 章的定理 2.126：m, n 互素 ⟹ ℤ/mn ≅ ℤ/m × ℤ/n。
例如 ℤ/6 ≅ ℤ/2 × ℤ/3、ℤ/72 ≅ ℤ/8 × ℤ/9——"不变因子形"（72 阶循环群）
与"初等因子形"（8 阶 × 9 阶）互相翻译。

## 31.3 基定理：p-准素群拆成循环的直和

现在 G 是 p-准素的。目标：把 G 拆成 **p^k 阶循环群的直和**。证明的工具
链很漂亮，三步走：

**第一步：d(G) = dim(G/pG)——把群问题变成线性代数**（命题 6.8）。
商群 G/pG 天然是 𝔽_p 上的向量空间（数乘 k·(g + pG) = kg + pG 定义
良好，因为 k ≡ r mod p 时 kg − rg ∈ pG）。定义
**d(G) = dim(G/pG)**，它在直和上可加：d(G ⊕ H) = d(G) + d(H)。

**引理 6.9** d(G) = 1 当且仅当 G 循环。（循环群的商循环；反之
G/pG 循环 ⟹ 取 g 使 g + pG 生成，再用 p-准素性把 G 整个吃进 ⟨g⟩。）

**第二步：纯子群（pure subgroup）**——直和项的代数刻画。
S ⊆ G 是**纯**的，若 S ∩ pⁿG = pⁿS（方程 s = pⁿg 在 G 中可解时，
在 S 中也可解）。例 6.6：直和项必纯；但 ℤ/p² 中子群 ⟨pg⟩ ≅ ℤ/p
**不纯**（(pg) = p·g 在 G 中有解，在 S 中无解）——纯性筛掉了那些
"斜着嵌进去"的循环子群。

**引理 6.7** 有限 p-准素群有非零纯循环子群。

**第三步：对 d(G) 归纳**（定理 6.11 的证明骨架）。取非零纯循环子群 S，
引理 6.10 给出 d(G/S) = d(G) − d(S) = d(G) − 1 < d(G)，归纳假设
把 G/S 拆开，再"提升"回 G——纯性恰好保证提升可行。

> **定理 6.11（基定理）** 每个有限阿贝尔群是一些**准素循环群**
> （素数幂阶循环群）的直和。

## 31.4 唯一性：数一数每种阶有几个

存在性到手，唯一性呢？朴素希望"n 阶群的分解唯一"被定理 2.126 打碎：
ℤ/6 既能写成"它自己"（循环 ℤ/6）也能写成 ℤ/2 ⊕ ℤ/3。**退一步，数
准素循环项的个数**——像算术基本定理唯一性一样，先固定"素"的构件。

对 p-准素群 G = ⊕Cᵢ（诸 Cᵢ 循环），设 pⁿ 阶的直和项有 bₙ 个。
关键引理：

> **引理 6.12** d(pⁿG) = b_{n+1} + b_{n+2} + ⋯ + b_r。

为什么：pⁿG = pⁿB_{n+1} ⊕ ⋯ ⊕ pⁿB_r（pⁿ 把低阶项 B_j (j ≤ n) 杀光），
每项 pⁿB 还是循环且与 B 同阶型，于是 d 数出来的正是"阶 ≥ p^{n+1} 的项数"。

> **推论 6.14** G ≅ G′ 当且仅当对所有 n ≥ 0，U_p(n, G) = U_p(n, G′)
> （U_p(n, ·) := d(pⁿ·)——分解的**数字指纹**）。

> **定义** G 的**初等因子**：把每个数 p^{n+1} 重复 U_p(n, G) 次；
> 全群的初等因子 = 各准素分支的初等因子之并。

例（原书）：ℤ/2⊕ℤ/2⊕ℤ/2 的初等因子是 (2,2,2)；ℤ/6 的是 (2,3)；
ℤ/12⊕ℤ/2 的是 (2,2,4,... )——注意 12 = 4·3 拆成 (4,3) 后并上 (2)。

> **定理 6.15（有限阿贝尔群的基本定理）** 两个有限阿贝尔群同构
> ⟺ 它们有相同的初等因子。

分类的最终形态：**n 阶阿贝尔群 ⟺ n 的素分解中每个指数 e_p 的整数
分拆**。个数 = ∏ p(e_p)（分拆数函数）。72 = 2³·3² ⟹ p(3)·p(2) = 3·2
= **6 个群**；360 = 2³·3²·5 ⟹ 3·2·1 = 6 个；1024 = 2¹⁰ ⟹ p(10) = 42 个。

三种 8 阶阿贝尔群及其初等因子：

| 群 | 初等因子 | 元素阶谱（阶档案） |
|---|---|---|
| ℤ/8 | (8) | {1,2,4,4,8,8,8,8} |
| ℤ/4 ⊕ ℤ/2 | (4,2) | {1,2,2,2,4,4,4,4} |
| ℤ/2 ⊕ ℤ/2 ⊕ ℤ/2 | (2,2,2) | {1,2,2,2,2,2,2,2} |

三行的"阶档案"两两不同——这不是巧合，而是推论 6.14 的可计算化身：
**阶档案是有限阿贝尔群的完全不变量**（知道每个元素阶的个数，
U_p(n, G) 可反解，初等因子可重建）。

## 31.5 机器验证一：Lean——不变量的 decide 面

**文件：`examples/lean/Abstractalgebra/Ch31AbelianGroups.lean`。**
三件事各自几行：

```lean
-- ℤ/8 有 8 阶元（1 的阶恰为 8：4•1 ≠ 0 且 8•1 = 0）
example : (4 : ℕ) • (1 : ZMod 8) ≠ 0 := by decide
example : (8 : ℕ) • (1 : ZMod 8) = 0 := by decide

-- ℤ/2 × ℤ/2 × ℤ/2 的每个元素都是 2 阶以下（指数 2）
example : ∀ x : Fin 3 → ZMod 2, x + x = 0 := by decide

-- U₂ 计数（引理 6.12 的形状：被 p 零化的元素数是不变量）
example : (Finset.univ.filter
    (fun x : Fin 3 → ZMod 2 => (2 : ℕ) • x = 0)).card = 8 := by decide
example : (Finset.univ.filter
    (fun x : ZMod 8 => (2 : ℕ) • x = 0)).card = 2 := by decide
```

`Fin 3 → ZMod 2` 是函数类型实现的直积——`decide` 枚举全部 8 个元素
逐个验证；三个 U₂ 计数（8、2、4）正好区分三种 8 阶群。CRT 走
mathlib 的 `ZMod.chineseRemainder`：

```lean
example : ∃ e : ZMod 6 ≃+* ZMod 2 × ZMod 3, Function.Bijective e :=
  ⟨ZMod.chineseRemainder (show Nat.Coprime 2 3 by decide), Equiv.bijective _⟩
```

（同一定理给出 ℤ/72 ≅ ℤ/8 × ℤ/9——不变因子形与初等因子形的翻译器。）
文件还验证 ℤ/6 的指数是 6（全部元素被 6 零化、5 不够）与
72 = 2³·3²、360 = 2³·3²·5 的分解算术。

## 31.6 机器验证二：Julia——分类器与阶档案

**文件：`examples/julia/31_abelian_groups.jl`**。两个核心函数：

```julia
"""ℤ/m 中 a 的阶 = m ÷ gcd(a, m)（a=0 时 gcd=m 得 1）。"""
elem_order(a, m) = m ÷ gcd(a, m)

"""ℤ/m₁ × ⋯ × ℤ/m_k 的全部元素阶（各分量阶的 lcm），升序。"""
function order_profile(ms)
    sort(vec([reduce(lcm, [elem_order(a, m) for (a, m) in zip(T, ms)])
              for T in Iterators.product([0:m-1 for m in ms]...)]))
end
```

断言组：(1) 8 阶三群的阶档案与 31.4 的表格逐项相等、两两不同；
(2) `abelian_forms(72)` 用分拆枚举（每个素数的指数分拆、笛卡尔组合）
生成全部 6 个初等因子形，`[8, 9] ∈ forms`（ℤ/8×ℤ/9，即循环的 ℤ/72）
与 `[2,2,2,3,3]` 都在列，6 个档案两两不同；(3) 计数公式抽查
8→3、12→2、16→5、36→4、72→6、360→6；(4) CRT 逐点：36 对
(x, y) 核对模加法保序、6 对 (a, b) 各恰一解；(5) 循环判据：直积
循环 ⟺ 两两互素 ⟺ 指数 = 阶，在 7 个形上双向核对。

## 31.7 机器验证三：Python 与 Prolog

**文件：`examples/python/31_abelian_groups.py`**。与 Julia 同构的
`order_profile`/`abelian_forms`，另加两件 sympy 设施：
`sympy.partition(n)`（分拆数）直接对拍计数公式（含 1024 → p(10) = 42）；
`sympy.combinatorics.named_groups.AbelianGroup(2, 2, 2)` 给出置换群
实现（order = 8、is_abelian），`AbelianGroup(6)` 循环且指数 6（指数由
全部元素阶的 lcm 现算——`PermutationGroup` 没有 `exponent` 方法）；
CRT 用 `sympy.ntheory.modular.crt([2,3], [a,b])`，36 对元素逐一核对
双射与保加法。

**文件：`examples/prolog/31_abelian_groups.pl`**。纯整数算术重建
同一套机器：`cartesian/2` 枚举直积元素（`between` 的界必须先 `is`
求值——直接写 `between(0, M-1, A)` 不求值）、`order_profile/2`、
分拆枚举 `partitions/2`、试除法 `factorize/2`、组合器 `abelian_forms/2`。
断言组与 Julia 相同（8 阶三群、72 → 6 种全档案互异、计数公式、
CRT 36+6 对、循环判据双向）。一个 Prolog 细节：gcd 的零分支写成
`gcd_(A, 0, G) :- !, G = A.` 而不是 `gcd_(A, 0, A)`——后者在第三参
不合一时（如 `gcd(2, 2, 1)`）会掉进下一条子句的 `mod 0`（项目坑账
老朋友，见第 03 章记录）。

## 31.8 要点回顾

1. 准素分解（定理 6.5）：G = ⊕_p G_p，同构 ⟺ 逐素数同构——
   分类问题按素数切开。
2. 基定理（6.11）：每个有限阿贝尔群 = 准素循环群的直和。证明工具链：
   G/pG 是 𝔽_p-空间（命题 6.8）⟹ d(G) 可加；纯子群（例 6.6/引理 6.7）
   保证循环片"摆得正"；对 d(G) 归纳。
3. 唯一性（引理 6.12 → 6.13 → 6.15）：数每种 pⁿ 阶循环项的个数
   bₙ，d(pⁿG) = Σ_{k>n} b_k 是数字指纹；初等因子是完全不变量。
4. 分类清单：n 阶阿贝尔群 ⟺ 每个指数 e_p 的分拆；个数 = ∏p(e_p)。
5. 阶档案（各阶元素的个数）是完全不变量的可计算形态——机器通道
   用它区分所有同阶不同构的阿贝尔群。
