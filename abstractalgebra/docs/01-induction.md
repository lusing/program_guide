**对应原书 §1.1（pp. 1-12）。**

## 1.1 归纳推理为什么不算证明

学抽象代数之前，先要接受一个纪律：**看得再多也不算证**。原书用四个例子把
这条纪律钉死，这里照单全收并补充验证手段。

**例（平面分割空间）** n 个平面最多把三维空间分成几个区域？n = 0, 1, 2, 3
时答案依次是 1, 2, 4, 8——恰好是 2ⁿ。于是"显然"该猜 2ⁿ。但 n = 4 时答案是
**15**，不是 16。正确的公式是 (n³+5n+6)/6，它在 n ≤ 3 时与 2ⁿ 撞了车。
教训：前几项吻合的规律可能随时翻脸。

**例（欧拉多项式）** f(n) = n² − n + 41 对 n = 0, 1, …, 40 全是素数——
四十个正面证据！然后 f(41) = 41² 不是素数。这个例子出自欧拉，它说明
"验证到第 40 个"与"永远成立"之间隔着深渊。

**例（谢尔宾斯基反例）** 命题"991n² + 1 不是完全平方数"对极其漫长的
一段 n 都成立：第一个反例出现在 n = 12 055 735 790 331 359 447 442 538 767，
约 1.2 × 10²⁸。按每天验证一个 n 计算，从地球诞生验证到今天也远不够撞上
第一个反例。但反例确实存在（这是佩尔方程 m² = 991n² + 1 的解）。

**例（哥德巴赫猜想）** 每个 ≥ 4 的偶数都是两素数之和。已被验证到
10¹³ 量级，至今既无反例也无证明。"证据多"在数学里永远买不来"成立"。

这四个例子划出了本章要解决的问题：需要一个**从有限通往无穷的合法通道**。
通道的地基是下面这条关于 ℕ 的公理。

## 1.2 良序原则与最小反例

> **最小整数公理（良序原则）** ℕ 的每个非空子集 C 都含有最小整数。

这条公理不能被证明——它是"自然数是什么"的一部分。但它符合直觉：要找
C 的最小元，从 0 开始逐个检查，0 ∈ C 则完毕，否则查 1，再查 2……C 非空
保证这个过程会终止。

良序原则的第一个推论是原书命题 1.1，它把"证明所有 S(n) 成立"转化为
"不存在第一个假命题"：

> **命题 1.1（最小反例）** 设 S(k), S(k+1), … 是一族命题。若其中有假命题，
> 则其中必有**第一个**假命题。

**证明** 设 C = {n ≥ k : S(n) 为假}。若有假命题则 C 非空，由良序原则 C
有最小元 m，S(m) 就是第一个假命题。∎

它的第一个应用是原书定理 1.2，这也是全书第一个"结构定理"：

> **定理 1.2** 每个整数 n ≥ 2 或是素数，或是若干素数的乘积。

**证明（最小反例）** 反设存在 n ≥ 2 既非素数也非素数之积，取最小的这样的
m。m 不是素数，故 m = ab，2 ≤ a < m，2 ≤ b < m。由 m 的最小性，a 和 b
都使定理成立：a = p₁p₂…，b = q₁q₂…，于是 m = ab 是素数之积，矛盾。∎

注意证明里"最小性传给因子"的用法：a、b 严格小于 m，所以它们**逃出了
反例集合**。这个模式会反复出现。

> **命题 1.3（试除判别法）** 设 m ≥ 2。若 m 不被任何 ≤ √m 的素数整除，
> 则 m 是素数。

**证明** 若 m 不是素数，则 m = ab 且 1 < a, b < m，于是 a、b 中必有一个
≤ √m（否则 ab > m）。由定理 1.2，那个小因子自身是素数或含素因子 p ≤ √m。∎

判别 991 是否素数，只需用 2, 3, 5, …, 31（共 11 个素数）试除——
这正是"结构性结果换来计算捷径"的第一个案例。

## 1.3 第一归纳法

把最小反例"翻译"成更好用的形式，就得到：

> **定理 1.4（数学归纳法）** 设 S(1), S(2), … 是一族命题。若
> (i) **基础步骤**：S(1) 成立；
> (ii) **归纳步骤**：对一切 n ≥ 1，S(n) 成立 ⟹ S(n+1) 成立；
> 则对所有 n ≥ 1，S(n) 成立。

**证明** 若有假命题，由命题 1.1 取第一个假命题 S(m)。由 (i) m ≥ 2，故
S(m−1) 存在且成立（m 是**第一个**假的），由 (ii) S(m) 也成立，矛盾。∎

两点澄清（原书特意强调，初学者最容易在这两点上出错）：

1. **两步缺一不可**。命题 S(n): "n = n+3" 的归纳步骤成立（若 n = n+3，
   两边加 1 得 n+1 = n+4，即 S(n+1)），但基础步骤不成立，整族全假。
   反过来，S(n): "n = n" 基础成立而归纳步骤不成立。两例分别对应"梯子
   的第二级够不着"与"第一级就不存在"。
2. **归纳步骤不是循环论证**。它证明的是蕴含式"S(n) ⟹ S(n+1)"本身，
   而不是 S(n+1)。好比"如果你复习得最好，就会得最高分"这句话可以是真的，
   哪怕你并没复习得最好。

基础步骤也不必从 1 开始——可以从任意整数 k 开始（甚至负数），结论变成
"对一切 n ≥ k 成立"。原书命题 1.8 是标准示例：

> **命题 1.8** 对一切整数 n ≥ 5，2ⁿ > n²。

**证明** 基础：2⁵ = 32 > 25。归纳：设 2ⁿ > n²（n ≥ 5），则
2^{n+1} = 2·2ⁿ > 2n² = n² + n² ≥ n² + 2n + 1 = (n+1)²，
其中用了 n ≥ 5 ⟹ n² ≥ 3n + 1 > 2n + 1。∎

为什么恰好从 5 开始？因为 n = 2, 4 时 2ⁿ = n²，n = 3 时 2ⁿ < n²——
命题在开头是**假**的。"从哪里开始成立"本身是需要证明的一部分，不能想当然。

再看两个书上的经典：命题 1.5（2ⁿ > n，n ≥ 1）与命题 1.6
（1 + 2 + ⋯ + n = n(n+1)/2）。后者配着高斯的故事：小高斯把 S = 1+⋯+100
与 S = 100+⋯+1 竖着相加得 2S = 100·101，S = 5050。高斯的技巧是"配对"，
归纳法是"爬梯"——两条路通向同一公式，这一现象（同一事实的多种证明各自
携带不同启发）在本教程里会不断重演。

## 1.4 前后夹击：算术-几何平均不等式

归纳法不只是"基础+爬梯"的机械运动。原书定理 1.11（AM-GM 不等式）的
证明是柯西式"向前-向后"归纳的经典，值得完整走一遍。

> **引理 1.9** 若 0 < m < 1 < M，则 m + M > 1 + mM。
> **引理 1.10** 若 k₁, …, k_n > 0 且 k₁k₂⋯k_n = 1，则 k₁ + ⋯ + k_n ≥ n，
> 且等号成立当且仅当所有 k_i = 1。

引理 1.9 是一行因式分解：m + M − 1 − mM = (M−1)(1−m) > 0。引理 1.10
对 n 归纳：n = 2 时若 k₁k₂ = 1 且 k₁ ≠ 1，不妨 0 < k₁ < 1 < k₂，用引理 1.9
得 k₁ + k₂ > 2。n ≥ 3 时若所有 k_i = 1 则完毕；否则有 k₁ < 1 < k₂，
把 k₁k₂ 换成 1（积不变、和变小，由引理 1.9），得到 n−1 个数积为 1，
套归纳假设，再放缩回来。细节留给习题。

> **定理 1.11（算术-几何平均不等式）** 若 a₁, …, a_n 都是正数，则
> (a₁ + ⋯ + a_n)/n ≥ (a₁a₂⋯a_n)^{1/n}，等号成立当且仅当所有 a_i 相等。

**证明** 令 G = (a₁⋯a_n)^{1/n}，k_i = a_i/G，则 k₁⋯k_n = 1，套引理 1.10：
(a₁+⋯+a_n)/nG ≥ 1，即算术平均 ≥ G。∎

这个证明展示了归纳法的弹性：归纳发生在一个"归一化"之后的辅助命题上，
而不是原命题本身。

## 1.5 第二归纳法（强归纳法）

有时证明 S(n) 需要的不只是 S(n−1)，而是"之前所有"命题。

> **定理 1.12（第二归纳法）** 设 S(1), S(2), … 是一族命题。若
> (i) S(1) 成立；
> (ii) 对一切 n > 1，若 S(1), …, S(n−1) **全部**成立，则 S(n) 成立；
> 则对一切 n，S(n) 成立。

**证明** 若有假命题，取第一个 S(m)。则 S(1), …, S(m−1) 全真而 S(m) 假，
与 (ii) 矛盾。∎

两种归纳法逻辑上等价（习题），但用起来手感不同。标准例子是"剥离 2 的幂"：

> **命题** 每个 n ≥ 1 可唯一写成 n = 2ᵏ·m，其中 k ≥ 0、m 为奇数。

**存在性（第二归纳法）** n = 1 取 k = 0, m = 1。n ≥ 2 时：n 奇数则
k = 0, m = n；n 偶数则 n = 2b，b < n，由归纳假设 b = 2^j·m'（m' 奇），
于是 n = 2^{j+1}·m'。∎

**唯一性** 若 2ᵏm = 2ᵗm'（m, m' 奇），设 k > t，约去 2ᵗ 得 2^{k−t}m = m'，
左边偶右边奇，矛盾；故 k = t，进而 m = m'。∎

存在性用第二归纳法才顺：从 n 到 n/2，而不是从 n 到 n−1。定理 1.2
（素因子分解存在）用第二归纳法同样更自然：m = ab 时对 a、b 分别用归纳
假设。唯一性要等算术基本定理（第 04 章）才补全。

## 1.6 黄金比例与斐波那契：归纳法遇见无理数

古希腊人认为满足 a : b = b : (a+b) 的矩形最悦目。这个比例导出二次方程
(b/a)² − (b/a) − 1 = 0，其正根

  φ = (1+√5)/2 ≈ 1.61803…

就是**黄金比例**，满足 φ² = φ + 1。它与斐波那契序列 F₀ = 0, F₁ = 1,
F_{n} = F_{n−1} + F_{n−2}（0, 1, 1, 2, 3, 5, 8, 13, …）深度绑定。

> **命题 1.15（比内公式）** 对一切 n ≥ 0，
> F_n = (φⁿ − ψⁿ)/√5，其中 ψ = (1−√5)/2。

证明是对 n 的第二归纳法：n = 0, 1 直接验证；n ≥ 2 时
φⁿ + ψⁿ = (φ^{n−1}+ψ^{n−1}) + (φ^{n−2}+ψ^{n−2})
（因为 φ² = φ+1、ψ² = ψ+1），套递推即得。有趣之处在于：右边是两个无理数
之差除以无理数，结果却是整数——而"它确实是整数"这件事，是由归纳法而非
数值近似保证的。

> **推论 1.16** 对一切 n ≥ 3，F_n > φ^{n−2}。

这个看似冷僻的下界在第 03 章证明拉梅定理（欧几里得算法的步数上界）时
会回来当主角——菲波那契数是欧几里得算法的"最坏输入"。

## 1.7 机器验证一：Lean 证明四连

**文件：`examples/lean/Abstractalgebra/Ch01Induction.lean`。**
本章机器证明五个命题：2ⁿ > n（命题 1.5）、高斯求和（命题 1.6）、
6 ∣ n³ − n、剥离 2 的幂（第二归纳法）、卡西尼恒等式。先看第一个：

```lean
theorem two_pow_gt (n : ℕ) (hn : 0 < n) : n < 2 ^ n := by
  induction n with
  | zero => omega
  | succ k ih =>
    -- 归纳假设 ihk : k < 2 ^ k；把 2 ^ (k+1) 展成 2 * 2 ^ k 后
    -- "k+1 ≤ 2k < 2·2^k" 对 omega 是线性不等式（2^k 视作原子）
    have ihk := ih hk
    have h1 : 2 ^ (k + 1) = 2 * 2 ^ k := by ring
    rw [h1]
    omega
```

证明结构就是 1.3 节的数学证明：`induction n with | zero | succ k ih` 对应
"基础步骤 / 归纳步骤"，`ih` 就是归纳假设 S(k)。最后一步 `omega`（Lean 的
线性算术自动求解器）把 `k + 1 ≤ 2k < 2·2^k` 的放缩自动补全——把 2^k
当作一个原子，剩下的全是线性关系。k = 0 的基础案由 `norm_num` 数值化验证
（2¹ = 2 > 1）。

高斯求和公式，机器版需要先给出"Σᵢ₌₁ⁿ i"的递归定义，再对 n 归纳：

```lean
def sumTo : ℕ → ℕ
  | 0 => 0
  | n + 1 => sumTo n + (n + 1)

theorem gauss_sum (n : ℕ) : 2 * sumTo n = n * (n + 1) := by
  induction n with
  | zero => rfl
  | succ k ih =>
    show 2 * (sumTo k + (k + 1)) = (k + 1) * (k + 2)
    linarith [ih]
```

这里证的是"两边乘 2"的版本 `2 * sumTo n = n * (n + 1)`——刻意避开除法，
留在整数世界里。`linarith [ih]` 自动用归纳假设完成线性放缩，对应数学证明中
"n(n+1)/2 + (n+1) = (n+1)(n+2)/2"的那步通分。

6 ∣ n³ − n 走结构路线：在 ℤ 上因式化 n³ − n = (n−1)·n·(n+1)（`ring` 一步），
"相邻两数必有偶"给出 2 ∣（偶/奇二分案），"n mod 3 三分案"给出 3 ∣；
每个因子都以 `Dvd.dvd.mul_right` 的链式形式拼装，最后"2 ∣ c 且 3 ∣ c ⟹
6 ∣ c"化成 omega 能处理的模算术。

"剥离 2 的幂"是强归纳法的机器版。Lean 里强归纳用 `Nat.strongRecOn`，
它直接对应定理 1.12——对一切更小的数已有结论可用：

```lean
theorem two_pow_mul_odd : ∀ n : ℕ, 0 < n → ∃ k m, n = 2 ^ k * m ∧ ¬2 ∣ m := by
  intro n
  induction n using Nat.strongRecOn with
  | ind n ih =>
    intro hn
    rcases Nat.even_or_odd n with ⟨r, hr⟩ | ⟨w, hw⟩
    · -- 偶：n = r + r，0 < r < n，强归纳作用于 r
      have hr0 : 0 < r := by omega
      obtain ⟨k, m, hm, hmo⟩ := ih r (by omega) hr0
      exact ⟨k + 1, m, by rw [← hm]; ring, hmo⟩
    · -- 奇：n = 2w + 1，直接取 k = 0
      exact ⟨0, n, by simp, fun hdvd => by obtain ⟨c, hc⟩ := hdvd; omega⟩
```

读法与数学证明逐行对齐：奇数取 k = 0（`simp` 证 n = 2⁰·n）；偶数分解
n = r + r 后，`ih r (r < n) (0 < r)` 把"对更小的 r 已证"取出来，2 的指数
加一。奇数分支的"¬2 ∣ n"由反证收尾：n = 2w+1 与 n = 2c 在 omega 眼里
不相容。

卡西尼恒等式还演示了一个 Lean 实战细节：`fib (k+1+1)` 与 `fib (k+2)`
定义相等（`rfl` 可证），但重写引理按**语法**匹配——先用
`have e : Nat.fib (k + 1 + 1) = Nat.fib (k + 2) := rfl` 统一拼写，再展开
递推 `fib_add_two`，最后 `push_cast`（把 ℕ → ℤ 的类型转换推到叶子，让
两边的原子对齐）加 `linear_combination -ih`（目标恰是 −1 × 归纳假设的
线性组合）一步收尾。

## 1.8 机器验证二：Julia 与 Python——反例猎人

证明通道负责"不可能错"，计算通道负责"直觉落地"。**文件：
`examples/julia/01_induction.jl`** 的核心是一个"最小反例搜索器"，它把
良序原则变成可运行的程序——对一个谓词 `bad`，从 1 起逐个检查，返回第一个
使 `bad` 为真的 n（或报告在前 N 个里没有）：

```julia
function first_counterexample(bad, N)
    for n in 1:N
        bad(n) && return n
    end
    return nothing
end
```

用它扫描本章开头的两枚"炸弹"：

```julia
# 欧拉多项式：n² - n + 41 在 n = 0..40 全素，n = 41 处爆炸
first_counterexample(n -> !isprime(n^2 - n + 41), 100)   # => 41

# 谢尔宾斯基：991n² + 1 不是平方数——第一个反例 ~1.2e28，扫不动
# 但可以验证：前 10⁶ 个 n 内确实无反例（isqrt 精确判别）
first_counterexample(n -> isqrt(991*n^2 + 1)^2 == 991*n^2 + 1, 10^6)  # => nothing
```

`isqrt` 是精确整数平方根，所以第二条是**严格判定**而非浮点近似。它扫完
10⁶ 个 n 一无所获——这正是 1.1 节的教训的可执行版本：证据再多（10⁶ 个），
也顶不住 1.2×10²⁸ 处埋着的反例。同文件还验证了 2ⁿ > n² 恰从 n = 5 开始
成立（n = 2, 4 相等、n = 3 反向），以及平面分割空间的区域数
R(n) = (n³+5n+6)/6 与 2ⁿ 在 n = 0..3 撞车、n = 4 处分道扬镳（15 ≠ 16）。

**文件：`examples/python/01_induction.py`** 验证 AM-GM。为避免浮点说谎，
用 `fractions.Fraction` 做精确有理数算术，几何平均则绕开开方：对正有理数
a₁,…,a_n，断言 `(Σaᵢ/n)ⁿ ≥ Πaᵢ`，两边都是精确有理数：

```python
from fractions import Fraction
from math import prod

def am_gm_gap(as_):
    n = len(as_)
    lhs = Fraction(sum(as_), n) ** n      # (算术平均)ⁿ
    rhs = prod(as_)                        # 几何平均的 n 次方
    return lhs - rhs                       # ≥ 0，等号 ⟺ 全相等

assert am_gm_gap([Fraction(1), Fraction(2), Fraction(4), Fraction(8)]) > 0
assert am_gm_gap([Fraction(3,7)] * 5) == 0   # 全相等时取等
```

两组断言分别对应定理 1.11 的"严格不等"与"取等"两个分支。随机有理数
批量测试也在文件里：每个随机组都给出非负的 gap，全等组 gap 恒为零。

## 1.9 机器验证三：Prolog——良序原则的直译

Prolog 的天然能力是"按定义搜索"，而良序原则说"最小者存在"，两者是绝配。
**文件：`examples/prolog/01_induction.pl`**：

```prolog
% 最小反例：从 1 起找第一个满足 bad/1 的 N（良序原则的可执行版）
first_counterexample(Bad, N) :-
    between(1, 200, N), call(Bad, N), !.

% 欧拉多项式在 n=41 处的第一个合数值
euler_bad(N) :- N1 is N*N - N + 41, \+ prime(N1).

prime(N) :- N >= 2, \+ (between(2, N, D), D*D =< N, N mod D =:= 0).
```

`between(1, 200, N)` 按 1, 2, 3, … 的顺序生成候选——顺序即良序；`!,`（割断）
保证取到第一个就停，这就是"最小反例"的直译。`prime/1` 的定义本身就是
命题 1.3 的程序化：`\+ (between(2,N,D), D*D =< N, N mod D =:= 0)` 读作
"不存在 D ≤ √N 整除 N"。查询 `first_counterexample(euler_bad, N)` 得
N = 41，与 Julia 通道互证。

同一文件还用 `2^N > N*N` 的逐点检查复现"恰从 5 开始成立"，并用递归求和
对照公式 n(n+1)/2 抽查 n ≤ 100。

## 1.10 要点回顾

1. 归纳推理不算证明：n²−n+41 与 991n²+1 是两枚永久警示弹。
2. 良序原则（ ℕ 的非空子集有最小元）派生最小反例（命题 1.1），最小反例
   派生两种归纳法；三者逻辑等价，手感各有侧重。
3. 第一归纳法 = 基础 + 单步爬梯；第二归纳法 = 基础 + "此前全真"。
   剥离 2 的幂、素因子分解存在性天然属于第二类。
4. 基础步骤的起点（如 2ⁿ > n² 的 n = 5）是命题的一部分，须证明而非宣称。
5. Binet 公式让整数以无理数面目出现；F_n > φ^{n−2} 是第 03 章拉梅定理的
   伏笔。
