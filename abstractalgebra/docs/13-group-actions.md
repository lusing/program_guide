# 13 群作用

**对应原书 §2.7（pp. 136-147）。**

---

## 13.1 让群动起来

> **定义** 群 G 在集合 X 上的**作用**是函数 α : G × X → X（写 g·x），
> 满足 g·(h·x) = (gh)·x 与 1·x = x。

> **命题 2.136** 作用 ⟺ 同态 G → S_X（g ↦ (x ↦ g·x)）。

这张"翻译证"价值连城：**作用就是群到置换群的同态**。两个极端之间
的一切都在其中——平凡作用（都映恒等）与忠实作用（单射）。

**凯莱定理（定理 2.132）**作为第一个应用免费到手：让 G 作用在自身上
（g·x = gx，左正则作用），得单同态 G ↪ S_G——**每个有限群都是置换群
的子群**。抽象群论从此"住在"具体置换里。

> **定理 2.133（陪集表示）** 更精细：G 作用在 G/H 的陪集上，得同态
> G → S_n（n = [G:H]），核含于 H——子群指数小时，群几乎就是置换群。

## 13.2 轨道与稳定子

> **定义** x 的**轨道** O(x) = {g·x : g ∈ G}；**稳定子** G_x =
> {g : g·x = x}（它是子群）。

> **命题 2.142** 轨道构成 X 的划分（又是等价关系：x ~ y ⟺ ∃g, g·x = y）。
> **定理 2.143（轨道-稳定子定理）** |O(x)| · |G_x| = |G|。

证明：映射 g ↦ g·x 满射到 O(x)，且 g·x = g′·x ⟺ g′⁻¹g ∈ G_x ⟺
g′H = gH（H = G_x）——所以 O(x) 与陪集集 G/G_x 等势，而陪集个数 =
|G|/|H|（拉格朗日）。∎

**轨道-稳定子是拉格朗日的"元素版"**：拉格朗日数的是子群陪集，轨道-
稳定子数的是一根轨道上的点。两个经典秒杀：

- G 传递地作用在自己上：轨道全 G，稳定子 {1}，|G| = |G|·1。
- 置换 α ∈ S_n 在 X = {1..n} 上作用：O(i) = α 的循环含 i，G_i =
  固定其余点的循环群——定理 2.55（阶 = lcm 循环长）的陪集版重导出。

> **推论 2.145** x 的共轭类大小 = [G : C_G(x)]（中心化子指数）。
> **类方程** |G| = |Z(G)| + Σ [G : C_G(xᵢ)]（跑过非中心共轭类代表元）。

共轭作用（g·x = gxg⁻¹）把第 08 章"循环结构定共轭类"（命题 2.33）与
计数公式（推论 2.146：同循环结构置换数 = n!/|C|）统一进作用框架。

## 13.3 柯西定理与 p-群

> **定理 2.147（柯西，1801 之前的形式）** 素数 p ∣ |G|，则 G 有 p 阶
> 元素。

原书的证明（例 2.151 一带的巧妙组合论证）研究素元组 (a₁, …, a_p) 满
足 a₁⋯a_p = 1 的集合 X 上的 ℤ_p-作用（循环移位），轨道大小 1 或 p，
不动点恰是"全部 aᵢ 相等"的 p 阶元——|X| ≡ |不动点| (mod p) 逼出
不动点存在。**柯西定理是拉格朗日的半个逆**：素因子方向总有子群。

> **定理 2.148** p-群（|G| = p^e ≥ 2）的中心非平凡。
> **推论 2.149** p² 阶群都阿贝尔（中心指数只能 1 或 p；p 会破坏类方程
> 的整除性）。

例 2.150 补上反例：UT(3, ℤ_p)（上三角 3×3 单位矩阵）是 p³ 阶非阿贝尔
群——p² 是阿贝尔的终点。

## 13.4 Aₙ 的单性：五次方程的伏笔

> **定理 2.158** 对一切 n ≥ 5，交错群 Aₙ 是**单群**（无非平凡正规
> 子群）。

证明骨架（引理 2.154-2.157）：Aₙ 的正规子群若含一个 3-循环，则含其
全部共轭（正规性），而 3-循环在 Aₙ 中共轭（引理 2.154），3-循环生成
Aₙ，故 H = Aₙ；再用"偶置换都能写成 3-循环之积"把一般情形拉回。∎

这条定理是第 30 章"五次方程不可解"的**结构性地基**：方程的可解性
最终取决于伽罗瓦群有没有某种正规塔，而 Aₙ 的单性把这个塔堵死。第 05
篇（域）到时会回来引用它。命题 2.153 先给了阿贝尔版：阿贝尔群单 ⟺
素数阶。

## 13.5 伯恩赛德计数

> **引理 2.159 + 定理（Burnside）** 有限群 G 作用在有限集 X 上，轨道
> （="本质不同对象"）个数 = (1/|G|) Σ_{g∈G} |Fix(g)|。

证明梗概（原书用"数表格"：行 g 列 x，格中打钩当 g·x = x——按行数
得 Σ|Fix(g)|，按列数得 Σ|O(x)|·|G_x| = Σ_{轨道} |G|，两者相等）。∎

**范例（项链计数）**：n 珠 m 色项链在旋转下本质不同的个数 =
(1/n) Σ_{d∣n} φ(d) m^{n/d}。取 m = 2, n = 6：(1/6)(2⁶ + 2³ + 2² +
2·2 + 2·2 + 2)?? ——直接套公式容易错，机器通道（下节）用 Burnside 与
暴力双重验证：答案 14。更妙的是加入翻转（二面体作用 D₆，12 元），
结果再变——同一根项链，换个对称群就换份答案，"**数对象 = 先问清
等价意义**"的教学样板。

## 13.6 机器验证一：Lean——MulAction 与轨道-稳定子

**文件：`examples/lean/Abstractalgebra/Ch13Actions.lean`。**
mathlib 的作用是 `MulAction G X` 类型类，轨道-稳定子有现成定理：

```lean
-- 定理 2.143 的机器版：|O(x)| · |G_x| = |G|（有限群）
example {G X : Type*} [Group G] [Fintype G] [MulAction G X] [Fintype X]
    [DecidableEq X] (x : X)
    [Fintype (MulAction.orbit G x)] [Fintype (MulAction.stabilizer G x)] :
    Fintype.card (MulAction.orbit G x) * Fintype.card (MulAction.stabilizer G x)
      = Fintype.card G :=
  MulAction.card_orbit_mul_card_stabilizer_eq_card_group G x
```

文件再以两个具体作用核对：(1) S₃ 自然作用在 Fin 3 上——传递性写成
"∀ y，∃ p，p • 0 = y"的穷举 decide；稳定子成员资格 `p ∈ stabilizer ↔
p 0 = 0` 是 `Iff.rfl`（定义即定理）；|S₃| = 6 与稳定子恰 2 元各一条，
3 × 2 = 6 的两条腿都落地；(2) 凯莱定理（定理 2.132）的实例化：
`g • x = g * x` 由 `rfl` 给出（左正则作用就是群的乘法），ZMod 6 的
传递性 `∀ y，∃ g，g • 1 = y` 同样 decide 收尾。

## 13.7 机器验证二：Julia——Burnside 与暴力双色计数

**文件：`examples/julia/13_actions.jl`**。作用由"每元素一张置换表"
给出，核心两件：

```julia
"""轨道：从 x 沿所有 g·x 收集。"""
function orbit(action, G, x)
    S = Set([x])
    for g in G, y in collect(S)
        push!(S, action(g, y))
    end
    S   # 有限集上一次扫描即闭包
end

"""Burnside：轨道数 = 固定点平均。"""
burnside(action, G, X) =
    sum(g -> count(x -> action(g, x) == x, X), G) // length(G)
```

断言组：(1) **项链双重验证**：m = 2, n = 6 的旋转作用（群 ℤ₆，作用 =
循环移位）——Burnside 给 14，暴力法（枚举 2⁶ = 64 个染色，按轨道归并）
也给 14；加入反射（D₆，12 元）后两法同给 13；(2) **轨道-稳定子**：
对全部 (g 作用, x) 组合断言 |O|·|G_x| = |G|；(3) **类方程**（13.2）：
D₄ 的共轭类大小 [1, 2, 1, 2, 2?] 实算为 {1,1,2,2,2}（中心 2 元 + 三类），
|D₄| = 2 + 2+2+2 ✓；(4) **共轭类 = 中心化子指数**（推论 2.145）逐元素
核对；(5) **S₄ 的循环结构类**（推论 2.146）：(abc) 型 8 个 = 4!/3，
(ab)(cd) 型 3 个，(abcd) 型 6 个——与 n!/中心化子公式逐型吻合。

## 13.8 机器验证三：Python 与 Prolog

**文件：`examples/python/13_actions.py`**：复算项链双验证（旋转 14、
二面体 13），加做 m = 3 色的 n = 4, 5, 6 项链表，与查表公式
(1/n)Σ_{d∣n} φ(d) m^{n/d} 逐项吻合；并用 `sympy` 的 divisors/totient
交叉验算公式侧。

**文件：`examples/prolog/13_actions.pl`**：

```prolog
% 作用即置换表：act(G, X, Y) 读 g 把 x 送到 y
orbit(G, X, O) :- closure([X], G, O).

% Burnside 的不动点计数
fixed(G, X, N) :- aggregate_all(count, act(G, X, X), N).
```

文件断言：ℤ₆ 旋转作用在 2 色 6 珠上的轨道数 = 14（`findall` 归并后
计数）；每个轨道大小整除 6（推论 2.144）；D₄ 作用在正方形 4 顶点
（Klein 意义）上的轨道-稳定子恒等式逐点成立。

## 13.9 要点回顾

1. 作用 = 同态 G → S_X（命题 2.136）；凯莱定理（左正则作用）与陪集
   表示（作用在 G/H 上）都是它的免费套餐。
2. 轨道-稳定子 |O|·|G_x| = |G|（定理 2.143）= 拉格朗日的元素版；
   共轭类大小 = 中心化子指数（推论 2.145），类方程把 |G| 拆成中心 +
   非中心共轭类。
3. 柯西定理（定理 2.147）：素因子 ⟹ p 阶元——拉格朗日的半个逆；
   p-群中心非平凡（定理 2.148），p² 阶群必阿贝尔（推论 2.149）。
4. Aₙ（n ≥ 5）单（定理 2.158）——第 30 章五次方程不可解的结构地基。
5. Burnside：轨道数 = 固定点平均；项链计数（14 vs 13）演示"先问清
   等价再计数"。
