# 10 子群与拉格朗日定理

**对应原书 §2.4（pp. 104-111）。**

---

## 10.1 子群：内部的小群

> **定义** 群 G 的子群 H ≤ G 是对运算封闭、含单位元、含逆元的子集。
> **命题 2.68（一步判别）** H ≤ G ⟺ H 非空且 x, y ∈ H ⟹ x y⁻¹ ∈ H。
> **命题 2.69（有限版）** 有限群的非空子集 H 是子群 ⟺ H 对运算封闭。

命题 2.69 的"封闭即子群"是有限性的红利：封闭性自动保证逆元（x, x², …
必在有限集中重复，x^m = x^n 给 x^{m−n} = e ∈ H）。无限时失效：
(ℕ, +) 在 (ℤ, +) 中封闭却非子群。

**命题 2.76 / 推论 2.77**：任意一族子群的交仍是子群；任一子集 X 被
最小子群 ⟨X⟩ 包住（所有含 X 的子群之交）。⟨a⟩ = {aⁿ : n ∈ ℤ} 称
**循环子群**——由一个元素生成的世界。

## 10.2 陪集：等价关系第三次登场

> **定义** H ≤ G，a ∈ G。**左陪集** aH = {a h : h ∈ H}。

关键引理（原书引理 2.82）：

> (i) aH = bH ⟺ b⁻¹a ∈ H；
> (ii) 每个 aH 与 H 等势（h ↦ a h 是双射）；
> (iii) aH ∩ bH ≠ ∅ ⟹ aH = bH。

(iii) 说**左陪集构成 G 的划分**——"a ~ b ⟺ a⁻¹b ∈ H"是等价关系，
等价类恰是左陪集。第 07 章的抽象定理在此兑现第二次（第一次：ℤ mod m
的同余类 = 子群 mℤ 的陪集！）。第 05 章"ℤ 按 m 碎成 m 块"的每个细节
现在都有了群论身份。

## 10.3 拉格朗日定理

> **定理 2.83（拉格朗日，1771）** G 有限，H ≤ G，则 |H| ∣ |G|。更精确：
> |G| = [G:H]·|H|，其中指数 [G:H] = 陪集个数。

**证明** 陪集划分 G，每个陪集大小恰为 |H|（引理 2.82(ii)）。
数块数乘块大小。∎

这个证明是"划分 + 等势"的免费午餐，与第 05 章费马小定理的"乘积置换"
证明是同一血统。三个立即的推论：

> **推论 2.85** 元素的阶整除群的阶（⟨a⟩ ≤ G）。
> **推论 2.86** 有限群 G 中 a^|G| = 1。
> **推论 2.87** 素数阶 p 的群必循环（且同构 ℤ_p）。

推论 2.86 是**费马小定理与欧拉定理的群论总纲**：取 G = (ℤ/mℤ)*
（第 05 章已证它是群），|G| = φ(m)，则对与 m 互素的 a：a^{φ(m)} ≡ 1
(mod m)。第 05 章的两个定理原来是一条定理的两个实例——**抽象的胜利**。

**拉格朗日的逆不成立**（重要！）：|H| ∣ |G| 不保证 H 存在。原书命题
2.99 给出反例：A₄（12 阶）没有 6 阶子群。**循环群则是乖孩子**：

> **命题 2.73** 循环群的子群都循环。
> **命题 2.75** n 阶循环群对 n 的每个因子 d 恰有**一个** d 阶子群（= ⟨a^{n/d}⟩）。
> **命题 2.71 / 推论 2.72** ⟨a⟩（n 阶）中 a^k 是生成元 ⟺ gcd(k, n) = 1；
> 生成元共 φ(n) 个。

> **命题 2.80（数论回望）** 在 (ℤ, +) 中：⟨a⟩ + ⟨b⟩ = ⟨gcd(a,b)⟩，
> ⟨a⟩ ∩ ⟨b⟩ = ⟨lcm(a,b)⟩。第 03-04 章的 gcd/lcm 恒等式原来是
> "ℤ 的子群格"的两条运算律——贝祖等式 = "⟨a⟩+⟨b⟩ 中有 1"。

## 10.4 机器验证一：Lean——mathlib 中的拉格朗日

**文件：`examples/lean/Abstractalgebra/Ch10Lagrange.lean`。**
mathlib 把陪集做成 `leftCoset a H`，拉格朗日做成：

```lean
-- 定理 2.83：子群的阶整除群的阶
example {G : Type*} [Group G] (H : Subgroup G) :
    Nat.card H ∣ Nat.card G := H.card_subgroup_dvd_card

-- 推论 2.85：元素的阶整除群阶
example {G : Type*} [Group G] [Fintype G] (a : G) :
    orderOf a ∣ Fintype.card G := orderOf_dvd_card

-- 推论 2.86：a ^ |G| = 1
example {G : Type*} [Group G] (a : G) : a ^ Nat.card G = 1 := pow_card_eq_one'
```

（`orderOf_dvd_card` 与 `pow_card_eq_one'` 是 mathlib 对推论 2.85/2.86
的正式化——引理名即定理名。）具体轨道走计数与倍数：U(ℤ₉) 有 φ(9) = 6
个元素（欧拉定理 2.109 的群侧），ℤ₁₂ 中 4·3 ≡ 0 而 2·3 ≢ 0（3 的阶
恰为 4）、3·4 ≡ 0、2·6 ≡ 0 而 1·6 ≢ 0（6 的阶为 2）、每元素 ×12 回零
——命题 2.75 的"因子恰一个子群"以元素阶倍数事实呈现，全部 `decide`。

## 10.5 机器验证二：Julia——陪集分解实景

**文件：`examples/julia/10_lagrange.jl`** 从凯莱表出发实现全部概念：

```julia
"""子群判别（命题 2.69 有限版：非空 + 封闭）。"""
is_subgroup(tbl, H) = !isempty(H) &&
    all(tbl[x, y] in H for x in H, y in H)

"""左陪集分解：返回互异的 aH 列表。"""
function cosets(tbl, H)
    left = Int[]; blocks = Vector{Int}[]
    for a in 1:size(tbl, 1)
        a in left && continue
        C = sort!([tbl[a, h] for h in H])
        push!(blocks, C); append!(left, C)
    end
    blocks
end
```

断言组：(1) **子群枚举**：D₄（8 阶）恰有 10 个子群，阶只能取
1, 2, 4, 8——拉格朗日允许的阶全部出现（8 = 2³ 每个因子都有子群，D₄
是"乖"的）；S₃ 恰有 6 个子群（1, 2, 2, 2, 3, 6 阶）；(2) **陪集分解**：
对每个 (群, 子群) 对验证块数 × 块大小 = |G|、块两两不交、并回全集；
(3) **元素阶 | 群阶**（推论 2.85）与 a^|G| = 1（推论 2.86）在 D₄、S₃、
U(8)、ℤ₁₂ 上全量验证；(4) **命题 2.75**：ℤ₁₂ 的因子 1,2,3,4,6,12 各
恰一个子群，其生成元个数 = φ(d)；(5) **命题 2.80**：ℤ₃₆ 中 ⟨4⟩+⟨6⟩ =
⟨gcd⟩、交 = ⟨lcm⟩（用加法陪集 = 周期格点）。

## 10.6 机器验证三：Python 与 Prolog

**文件：`examples/python/10_lagrange.py`**：同构地复算 Julia 断言，并加做
**A₄ 无 6 阶子群**的机器验证（命题 2.99——拉格朗日逆命题的反例）：
把 A₄ 做成 12 个偶置换的凯莱表，枚举全部 2¹² 个子集太慢，改为枚举
所有可能的 6 元子集（C(12,6) = 924 个）逐一检查封闭性——**没有一个
封闭**，与原书证明（3-循环的封闭性迫使爆炸）的结论一致。

**文件：`examples/prolog/10_lagrange.pl`**：

```prolog
% 左陪集：aH 的元素表
coset(G, H, A, C) :- findall(P, (member(Hi, H), op(G, A, Hi, P)), C0),
                     sort(C0, C).

% 拉格朗日验证：陪集划分 + 大小乘积
lagrange(G, H) :-
    subgroup(G, H),
    cosets(G, H, Blocks),
    length(Blocks, Idx),
    length(H, Ord),
    size(G, N),
    N =:= Idx * Ord,
    union_blocks_cover(G, Blocks).
```

文件对 ℤ₆/⟨2⟩、S₃/⟨(123)⟩、D₄/⟨旋转⟩ 逐对调用 `lagrange/2`，全部
通过；并断言 S₃ 的子群数恰为 6（用 `subset` 枚举 + `is_subgroup` 过滤，
2⁶ = 64 个子集全查——Prolog 的回溯在这里是天然优势）。

## 10.7 要点回顾

1. 子群一步判别：非空 + x y⁻¹ ∈ H；有限群只需封闭（命题 2.68/2.69）。
2. 左陪集是等价类（a ~ b ⟺ a⁻¹b ∈ H），构成划分——第 07 章定理的
   第二次兑现；ℤ mod m 同余类 = 子群 mℤ 的陪集。
3. 拉格朗日：|G| = [G:H]·|H|；推论：元素阶整除群阶、a^|G| = 1、
   素数阶群循环。费马/欧拉定理是推论 2.86 的两个实例。
4. 逆命题不真：A₄（12 阶）无 6 阶子群（命题 2.99）；循环群里逆命题成立
   且每个因子恰一个子群（命题 2.73/2.75）。
5. ⟨a⟩+⟨b⟩ = ⟨gcd⟩、⟨a⟩∩⟨b⟩ = ⟨lcm⟩（命题 2.80）——数论的群论底牌。
