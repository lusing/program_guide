## 6.1 历法为什么是个数学问题

"1776 年 7 月 4 日是星期几？"要回答它，先得知道"一年有多长"。麻烦在于
**一年不是整数天**：地球绕太阳一周约 365.2422 天，而日历必须用整数天拼出
平均值恰好等于它的"年"。

公元前 46 年，凯撒的儒略历每四年一闰，平均年长 365.25 天——比真实值多出
0.0078 天（约 11 分 14 秒）。128 年就多出一天，累积到 1582 年，春分已经
从尼西亚会议（公元 325 年）认定的 3 月 21 日漂到了 3 月 11 日。教皇格里高利
十三世当年改革：抹掉 10 天（1582 年 10 月 4 日的第二天是 10 月 15 日），
并修改闰法——**四年一闰，但整百年不闰，整四百年又闰**。格里高利历的平均
年长 (303·365 + 97·366)/400 = 365.2425 天，每 3300 年才差一天。

> **闰年规则（格里高利历）** y 年是闰年 ⟺ (4 ∣ y 且 100 ∤ y) 或 400 ∣ y。

从"闰年"到"星期几"要过的河，是上一章的同余：星期以 7 为周期，问题归结为
"从某个基准日到目标日共过了多少天，mod 7"。

## 6.2 日历公式

原书命题 1.74 的推导思路干净得可以背下来。**关键决策：把"年"从 3 月 1 日
开始算**（1、2 月算作前一年）——这样"2 月 29 日"这个插入日落在"年末"，
一年之内月份天数不再中途变异。

以虚构的 0000 年为参考（0000 年 3 月 1 日对应某数 a，0 ≤ a ≤ 6，星期日
记 0）。从 0000-03-01 到 0001-03-01 经过 365 ≡ 1 (mod 7) 天；闰年过去
366 ≡ 2 (mod 7) 天。所以 y 年 3 月 1 日对应

  a + y + L (mod 7)，L = 0000 到 y 年间的闰年数 = ⌊y/4⌋ − ⌊y/100⌋ + ⌊y/400⌋。

（L 的三项正是闰法的三条：4 年加闰、100 年扣闰、400 年还闰。）月份的
贡献同样加法化：3 月有 31 ≡ 3 (mod 7) 天，4 月 30 ≡ 2 天……把逐月累加
做成查表，得

> **命题 1.74（日历公式）** 视 1、2 月为前一年后，y 年 m 月 d 日对应
> **A ≡ d + j(m) + g(y) (mod 7)**，其中
> j(m) = 2, 5, 0, 3, 5, 1, 4, 6, 2, 4, 0, 3（3 月取 j = 2，…，2 月取 j = 3），
> g(y) = y + ⌊y/4⌋ − ⌊y/100⌋ + ⌊y/400⌋。
> （星期日 = 0，星期一 = 1，…，星期六 = 6。）

j(m) 有两个助记法：j(m) = ⌊2.6m − 0.2⌋（m 从 3 月起算为 1），或英文句子
"My Uncle Charles has eaten nothing cold; supper eats hot"的单词长度
3, 6, 3, 7, 5, 7, 3, 4, 3, 4, 3, 5——再 mod 7 折叠。

**例 1.75** 1776 年 7 月 4 日：7 月对应 m = 5（3 月为 1），j(5) = 5，
g(1776) = 1776 + 444 − 17 + 4 = 2207 ≡ 2207 − 315·7 = 2 (mod 7)。
A = 4 + 5 + 2 = 11 ≡ 4 (mod 7)——星期四。独立核验：美国国庆日 1776-07-04
确为星期四。✓

> **推论 1.76（世纪简化）** y = 100C + N（0 ≤ N ≤ 99）时
> A ≡ d + j(m) + N + ⌊N/4⌋ + c(C)，其中世纪修正 c(C) 把格里高利 400 年
> 周期折叠成 1600: 2, 1700: 0, 1800: 5, 1900: 3, 2000: 2（每 400 年循环）。

推导：g(100C + N) = 100C + N + ⌊(100C+N)/4⌋ − ⌊(100C+N)/100⌋ + ⌊…/400⌋，
逐项 mod 7 收拢，C 的部分全吸进 c(C)。

**星期五十三号** 某年 13 日是不是星期五，取决于 13 + j(m) + g(y) ≡ 5。
让 m 走遍 12 个月，j(m) 取遍 mod 7 的全部余数——所以**任何年份至少有一个
星期五十三号**（落在 5 月或 11 月附近，视 g(y) 而定）；又因 j(m) 无任何
余数出现三次，一年最多三个（此时 1、2 月"归属前一年"的小把戏允许三个
挤在同一自然年内，如 1987 年：2 月、3 月、11 月）。

## 6.3 康威的审判日系统

数学家康威（J. H. Conway）把日历公式改造成了**心算系统**。定义 y 年的
**审判日（Doomsday）**为该年"2 月最后一天"的星期数：

| 世纪年 | 审判日 |
|---|---|
| 1600-02-29 | 星期二 (2) |
| 1700-02-28 | 星期日 (0) |
| 1800-02-28 | 星期五 (5) |
| 1900-02-28 | 星期三 (3) |
| 2000-02-29 | 星期二 (2) |

（每过一百年审判日 −2，逢 400 的倍数改回 +1，形成 2, 0, 5, 3 的四拍循环。）

> **命题 1.78（康威公式）** 设 D 是 100C 年的审判日，0 ≤ N ≤ 99，
> N = 12q + r。则 100C + N 年的审判日 ≡ D + q + r + ⌊r/4⌋ (mod 7)。

推导：审判日随年加 1、随闰年再加 1，共 N + ⌊N/4⌋ = 12q + r + 3q + ⌊r/4⌋
≡ q + r + ⌊r/4⌋ (mod 7)。心算流程"除 12 → 加回 → 除 4 向下取整"三步
搞定任何年份，例如 2024：C = 20（审判日 2），N = 24 = 12·2 + 0，
2 + 2 + 0 + 0 = 4——2024 的审判日是星期四 ✓（2024-02-29 是星期四）。

审判日的价值在于一组**与审判日同星期**的锚点日期：

  4/4，6/6，8/8，10/10，12/12，5/9，9/5，7/11，11/7

（读法 "9 点上班 5 点下班，7-11 便利店"）。再加上 3 月的"π 日" 3/14
（平年）、1 月的 1/3（平年）或 1/4（闰年），任何日期先落到最近的锚点
±几天，一步得出星期。例如 2024-11-04：审判日星期四，11/7 是锚点，
4 日 = 7 日 − 3 天 → 星期四 − 3 = 星期一。✓

## 6.4 复活节与侦探小说：历法的应用现场

**福尔摩斯案（习题 1.98）** 嫌疑人声称 1893 年 4 月 21 日与母亲过复活节。
复活节 = 春分后（含当日）第一个满月之后的第一个星期日，高斯给出算法：
对年份 y，令 a = y mod 19, b = y mod 4, c = y mod 7，再经 k 修正算出
"教会满月日" d（3 月起算的天数），复活节 = d + (8 − (b + d) mod 7)。
对 y = 1893 计算得复活节 = 4 月 2 日——**4 月 21 日不是复活节**，嫌疑人
在星期几上撒谎（1893-04-21 是星期五，复活节永远在星期日）。历法知识
当庭戳破谎言。

**椰子问题（习题 1.97）** 五个人和一只猴子：每人半夜把椰子分成五份余一
（余的给猴子），藏起自己一份再睡。问最初椰子最少多少个？设 N₀ 为总数，
每轮 N_{i+1} = 4(N_i − 1)/5，要求五轮全整除。倒着看：N₅ ≡ 0 (mod 4)
即可（早晨不必再分），答案 N₀ = 3121 = 5⁵ − 4。这个数不是巧合：条件组
恰是 N₀ ≡ −4 (mod 5⁵)。本章 Prolog 通道用 `between(1, 20000)` 搜索，
第一个命中就是 3121。

## 6.5 机器验证一：Julia——与标准库对拍

**文件：`examples/julia/06_calendar.jl`** 把命题 1.74 写成函数：

```julia
const Jm = [0, 3, 2, 5, 0, 3, 5, 1, 4, 6, 2, 4]   # 1..12 月的偏移
# 原书 j(m) 按"3 月=1"给出 2,5,0,3,5,1,4,6,2,4,0,3；
# 平移到自然月下标 Jan..Dec 得此表（推导见文件注释）。

function dayofweek_formula(y, m, d)
    if m <= 2; y -= 1; end               # 1、2 月归属前一年
    g = y + fld(y,4) - fld(y,100) + fld(y,400)
    mod(d + Jm[m] + g, 7)                # 0=星期日
end
```

（自查三例：1776-07-04：g(1776) = 2207 ≡ 2，A = 4+5+2 ≡ 4 = 星期四；
2000-02-29：按 1999 年算，g ≡ 5，A = 29+3+5 ≡ 2 = 星期二；
2024-11-04：g(2024) = 2515 ≡ 2，A = 4+2+2 ≡ 1 = 星期一。）对拍对象是
Julia 标准库 `Dates.dayofweek`——它按 Proleptic Gregorian 历法实现，
与本教程的参考系一致：

```julia
using Dates
for y in 1600:2200, m in 1:12, d in 1:Days_inmonth(y, m)
    @assert dayofweek_formula(y, m, d) == Dates.dayofweek(Date(y,m,d)) - 1
end
```

三重循环扫过 1600–2200 年的**每一天**（约 219,000 天），公式与标准库
逐日一致——这是"应用同余证明的公式在真实日历上无一处偏差"的完整核验。
文件还实现康威系统（`doomsday(y) = mod(c + q + r + fld(r,4), 7)`，先算
世纪锚 c），断言：每年 2 月最后一天的 `dayofweek_formula` 输出恰等于
`doomsday(y)`（两套独立公式互证）；星期五十三号普查 1600–2200 年：每年
1 到 3 个、总数分布与 6.2 节结论吻合，1987 年恰有 3 个（2/13、3/13、
11/13），并打印出"只有一个"的年份样本（如 2022 年仅 5 月）。

## 6.6 机器验证二：Python 与 Prolog

**文件：`examples/python/06_calendar.py`**：自实现 `dayofweek_formula`
与 `doomsday`，对 `datetime.date(...).weekday()` 全量对拍（1800–2100 年
每天）；高斯复活节算法实现 + 对 1990–2030 年已知复活节日期表逐个核验
（表来自标准历书），并输出 1893 年复活节 = 4 月 2 日，宣判福尔摩斯案；
椰子问题先 brute force（1..20000 找到 3121），再用同余语言重解：
断言 3121 ≡ −4 (mod 3125) 且五轮递推 N ↦ 4(N−1)/5 全部整除。

**文件：`examples/prolog/06_calendar.pl`**：

```prolog
% 椰子问题：五人一猴，直接搜索最小解
coconut(N) :-
    between(1, 20000, N),
    chain5(N).                      % 五轮 (N-1) 整除 5 且传 4(N-1)/5

chain5(N0) :- chain(N0, 5).
chain(N, 0) :- !, N mod 4 =:= 0.    % 早晨四人分得动（习题口径）
chain(N, K) :- K > 0,
    N1 is N - 1, N1 mod 5 =:= 0,    % 余一给猴子
    N2 is 4 * (N1 div 5),           % 藏一份，剩四份
    K1 is K - 1, chain(N2, K1).
```

`between` 从 1 起升序生成——第一个成功的就是最小解 3121，良序原则的
又一次可执行化。同文件实现日历公式 `dow/4`，断言三组史实：1776-07-04 =
星期四、2000-02-29 = 星期二、2024-02-29 = 星期四；并复算 1987 年的三个
星期五十三号。全文件只用整数算术，无任何浮点。

## 6.7 要点回顾

1. 历法 = 用整数天逼近 365.2422 天的无限工程；格里高利闰法
   (4∣y 且 100∤y) 或 400∣y 把误差压到 3300 年一天。
2. 日历公式 A ≡ d + j(m) + g(y) (mod 7)；两大技巧：年从 3 月起算
   （闰日归年末）、闰年数 L = ⌊y/4⌋ − ⌊y/100⌋ + ⌊y/400⌋。
3. 康威系统 = 世纪锚（2, 0, 5, 3 循环）+ N + ⌊N/4⌋ + 锚点日期组
   （4/4, 6/6, 8/8, 10/10, 12/12, 5/9, 9/5, 7/11, 11/7）——纸笔秒算
   任意日期。
4. 每年至少一个、最多三个星期五十三号；j(m) 取遍 mod 7 全部余数是原因。
5. 复活节规则（春分-满月-星期日）与椰子问题（N ≡ −4 mod 5⁵）是同余
   思想在历法与趣味数论的两个现场应用。
