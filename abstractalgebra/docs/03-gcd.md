## 3.1 带余除法：整数系的第一块拱心石

> **定理 1.29（除法算式）** 设 a, b ∈ ℤ，b > 0。则存在**唯一**的 q, r 使
> a = qb + r，0 ≤ r < b。

**存在性（良序原则）** 考虑集合 C = {a − nb : n ∈ ℤ, a − nb ≥ 0}。
取 n 充分小（比如 n = −|a|）可使 a − nb > 0，故 C 非空。由良序原则 C 有
最小元 r = a − qb。若 r ≥ b，则 r − b = a − (q+1)b ∈ C 且比 r 小，矛盾。
**唯一性** 若 a = qb + r = q'b + r'，则 (q−q')b = r' − r，左边是 b 的倍数
而右边绝对值小于 b，只能都为零。∎

"存在 + 唯一"是整除理论一切良定义性的来源：余数 r 是**一个确定的数**，
于是"a mod b"可以进程序、进符号。比较一下就明白它多珍贵：下一章的算术
基本定理、第 17 章的多项式除法、第 38 章的多元多项式"广义除法"，全都在
复刻这条定理——谁有带余除法，谁就有整套因子理论。

第一个应用顺带复习上一章：

> **推论 1.30（欧几里得）** 素数有无穷多个。

**证明** 给定有限个素数 p₁, …, p_k，数 M = p₁p₂⋯p_k + 1。M ≥ 2，由定理 1.2
它有素因子 p。但 p ≠ 每个 p_i（否则 p | M 且 p | p₁⋯p_k，得 p | 1）。∎

## 3.2 最大公因子与贝祖等式

设 a, b 不全为零。公因子的最大者记 (a, b) 或 gcd(a, b)。表面上看它是个
"大小比较"概念，但整除理论给了它一个远为有用的刻画：

> **定理 1.32（贝祖）** (a, b) 是 a 与 b 的**线性组合**：存在 s, t ∈ ℤ 使
> (a, b) = sa + tb。而且 (a, b) 是能写成 sa + tb 的最小正整数。

**证明** 设 I = {sa + tb : s, t ∈ ℤ}。I 中有正元（如 a + b 或 −a − b，
视符号而定），由良序原则取最小正元 d = s₀a + t₀b。用除法算式写
a = qd + r，0 ≤ r < b？不对——是 0 ≤ r < d。则
r = a − qd = (1 − qs₀)a − qt₀b ∈ I；由 d 最小且 r < d 得 r = 0，即 d | a；
同理 d | b。反过来任何公因子 c 整除 s₀a + t₀b = d。所以 d = (a, b)。∎

> **推论 1.33** 非负公因子 d 是最大公因子 ⟺ 存在 s, t 使 d = sa + tb
> （且 d 被每个公因子整除）。

> **推论 1.34（ℤ 的理想结构）** ℤ 的非空子集 I 若对加、减封闭，则
> I = (d) := {nd : n ∈ ℤ}，d 是 I 中的最小正元。

推论 1.34 说 ℤ 的"加法封闭子系统"必然长成某个 d 的全部倍数——d 由 I
唯一决定。第 34 章会把"(d) 是理想"这个概念推广到任意交换环，届时你会认出
贝祖定理的本质就是"ℤ 中每个理想都是主理想"。抽象名词晚两章出现，但
结构现在就已经在了。

> **定理 1.35（欧几里得引理）** p 素且 p | ab ⟹ p | a 或 p | b。
> 更一般地，p | a₁a₂⋯a_k ⟹ p 整除某个 a_i。

**证明** 设 p ∤ a。由命题 1.31（素数与不整除它的数互素）(p, a) = 1，
贝祖给出 1 = sp + ta。两边乘 b：b = spb + tab。p 整除右边两项，故 p | b。∎

> **推论 1.37** 若 (c, a) = 1 且 c | ab，则 c | b。

证明逐字复制（把 p 换成 c）。欧几里得引理的"消去"能力是唯一分解的命门：
下一章证明算术基本定理的**唯一性**时，全部力气都花在这里。

两个经典应用收尾本节。其一，√2 是无理数：若 √2 = a/b 既约，则 a² = 2b²，
故 2 | a²，欧几里得引理给 2 | a，写 a = 2c 得 b² = 2c²，又得 2 | b——与
既约矛盾（原书命题 1.40）。其二，命题 1.36：p 素时 C(p, r) = p!/(r!(p−r)!)
的分母不含因子 p，故 p | C(p, r)（0 < r < p）；它将在第 05 章一秒钟证明
 freshman's dream (a+b)^p ≡ a^p + b^p (mod p)。

## 3.3 欧几里得算法：人类最古老的算法

定理 1.32 的证明是存在性的，但贝祖系数 s, t 怎么**找**？答案是欧几里得
算法（定理 1.41）：反复做除法算式，余数严格递减，最后非零余数就是 gcd。

以原书例 1.42 的 (326, 78) 为例（手算全程）：

```
326 = 4·78 + 14
 78 = 5·14 +  8
 14 = 1· 8 +  6
  8 = 1· 6 +  2      ← 最后非零余数：gcd(326,78) = 2
  6 = 3· 2 +  0
```

把每行"回代"就得到贝祖系数：2 = 8 − 1·6 = 8 − (14 − 8) = 2·8 − 14
= 2·(78 − 5·14) − 14 = 2·78 − 11·14 = 2·78 − 11·(326 − 4·78)
= 46·78 − 11·326。验证：46×78 = 3588，11×326 = 3586，差 2 ✓。
顺手把 78/326 约分成既约分数：除以 2 得 39/163。

> **命题 1.43（拉梅，1844）** 设 b > a > 0，d(a) 为 a 的十进制位数。
> 欧几里得算法求 (a, b) 的除法次数 ≤ 5·d(a)。

**证明要点** 算法中连续余数满足 r_{i+1} < r_i，且可以证明每两步至少
"减半"；更精确的分析表明最坏情况发生在**相邻斐波那契数**上：若算法
做 n 步，则 b ≥ F_{n+2}。由推论 1.13（F_m > φ^{m−2}），φ^{n} < F_{n+2} ≤ b，
取对数得 n < log_φ b < 5·d(b) ≤ 5·d(a)……精确常数是 log₁₀φ ≈ 0.209，
1/0.209 > 4.78，所以 5 次除法足够每一位数字。∎

这个定理有双重历史地位：它是第一个**复杂度分析**定理（比计算机早一百年），
而斐波那契数作为"最坏输入"的现象会在第 20 章多项式欧几里得算法里
原样重现。

## 3.4 进制表示与天平称量

> **命题 1.44（b 进制表示）** 设 b ≥ 2。每个正整数 m 唯一地写成
> m = d_k b^k + ⋯ + d₁b + d₀，0 ≤ d_i < b，d_k ≠ 0。

存在性由"除 b 取余、商继续除"的循环给出（每次严格变小，归纳法收尾），
唯一性仍是"两表示相减看最低不同位"。例 1.45：12345 = 5·7⁴ + 0·7³ +
6·7² + 6·7 + 4，即 12345 = (50664)₇。

进制表示的一个妙用是原书例 1.46/1.50 的**天平称量问题**：有一架天平与
重量为 1, 3, 9, 27 磅的砝码各一枚，能称出哪些整数重量？"天平"意味着
砝码可以放两边——物体一侧的砝码相当于**负重量**。于是问题变成：哪些 n
能写成 e₀·1 + e₁·3 + e₂·9 + e₃·27，其中 e_i ∈ {−1, 0, 1}？

答案漂亮：**1 到 40 的每一个重量都能称**，而且方式唯一。这正是**平衡
三进制**（balanced ternary，数字 −1, 0, 1）表示的存在唯一性。例如
19 = 27 − 9 + 1（砝码 27 与货物同盘、9 与 1 在对盘）。三进制是"信息
效率"与"对称性"的平衡点——苏联的 Сетунь 计算机真的用平衡三进制造过。

## 3.5 机器验证一：Lean——贝祖与欧几里得引理

**文件：`examples/lean/Abstractalgebra/Ch03Gcd.lean`。**
mathlib 把本章定理几乎全部正式化了，我们的任务是**把课本证明的骨架
复原出来**，并验证具体算例。核心四件：

```lean
-- 除法算式存在性：mathlib 的 a/b 与 a%b 直接给出
theorem division_alg_exists (a b : ℕ) (hb : 0 < b) :
    ∃ q r, a = b * q + r ∧ r < b := by
  refine ⟨a / b, a % b, ?_, Nat.mod_lt _ hb⟩
  rw [Nat.div_add_mod a b]

-- 贝祖等式：mathlib 的 Int.gcdA/gcdB 由 xgcd 回代产生
theorem bezout (a b : ℤ) : ∃ s t : ℤ, (Int.gcd a b : ℤ) = a * s + b * t := by
  refine ⟨Int.gcdA a b, Int.gcdB a b, ?_⟩
  exact Int.gcd_eq_gcd_ab a b

-- 欧几里得引理
example (p : ℕ) (hp : Nat.Prime p) {a b : ℕ} (h : p ∣ a * b) :
    p ∣ a ∨ p ∣ b := (hp.dvd_mul).mp h

-- 具体算例：gcd(326, 78) = 2，机器算出的贝祖系数满足等式
example : Nat.gcd 326 78 = 2 := by decide
example : (326 : ℤ) * Int.gcdA 326 78 + (78 : ℤ) * Int.gcdB 326 78 = 2 := by
  native_decide
```

存在性一段里 `Nat.div_add_mod a b` 恰好就是 b·(a/b) + a%b = a——重写后
目标自闭合；唯一性在文件中以 ℤ 版陈述（`division_alg_unique`），关键步
(q−q')·b = r′−r 的符号分析由 `linear_combination` + `mul_le_mul_of_nonneg_right`
+ `omega` 三件套完成。贝祖一段调 `Int.gcd_eq_gcd_ab`——mathlib 的 gcd 定义
本身就是欧几里得递归，`gcdA/gcdB` 就是回代出的贝祖系数（对 326、78 机器
给出的恰是 −11 与 46，与 3.3 节手算一致）。文件里还有 `Nat.Prime` 下
2 ∣ a² → 2 ∣ a（√2 无理性的整数内核）、欧几里得无穷素数
（`Nat.exists_infinite_primes`）、991 的素性，以及 `Nat.digits 7 12345`
的 7 进制数字。

## 3.6 机器验证二：Julia——扩展欧几里得与拉梅实测

**文件：`examples/julia/03_gcd.jl`** 实现带回代的扩展欧几里得算法：

```julia
function extgcd(a::T, b::T) where T<:Integer
    old_r, r = a, b
    old_s, s = T(1), T(0)
    old_t, t = T(0), T(1)
    while r != 0
        q = div(old_r, r)
        old_r, r = r, old_r - q*r
        old_s, s = s, old_s - q*s   # 系数跟着同一套初等变换走
        old_t, t = t, old_t - q*t
    end
    return old_r, old_s, old_t      # (d, s, t)：d = s*a + t*b
end
```

不变量 `old_r = old_s·a + old_t·b` 在循环中保持——这正是"回代"的程序化，
一行注释点破：**贝祖系数跟着除法算式的初等变换同步演化**。文件断言：
(1) `extgcd(326, 78) == (2, -11, 46)`——与手算完全一致；
(2) 对 1 ≤ a ≤ b ≤ 500 的全部整数对，`d == gcd(a,b)` 且 `s*a + t*b == d`
（约 12 万对全数验证）；(3) 拉梅实测：对相邻斐波那契对 (F_{n+1}, F_n)，
n = 5..30，记录除法步数，断言步数 ≤ 5 × 位数(F_{n+1})，并打印出
"斐波那契对恰好取到理论上界附近"的对照表。

天平称量部分用**三重枚举** e_i ∈ {−1,0,1} 直接验证 1..40 全部可称且
表示唯一，顺带打印 19 = 27 − 9 + 1 这类有趣表示。

## 3.7 机器验证三：Python 与 Prolog

**文件：`examples/python/03_gcd.py`**：用 `sympy.gcdex`（整数扩展 gcd）
对照自实现的 extgcd；随机 10⁴ 对验证贝祖恒等式；√2 的"有限证据"扫描
（对所有 b ≤ 10⁴、a = round(√2·b)，断言 2b² ≠ a²——并**如实说明**这只是
证据不是证明，证明在 Lean 文件与正文里）；平衡三进制转换器与 1..40
唯一性检查。

**文件：`examples/prolog/03_gcd.pl`** 用纯递归直译算法：

```prolog
% 欧几里得算法的直译：gcd(a, 0) = a；否则换 (b, a mod b)
gcd(A, 0, A) :- !.
gcd(A, B, D) :- C is A mod B, gcd(B, C, D).
```

第一条子句就是"余数为零，除数即答案"；第二条是除法算式的递推。扩展版
`extgcd/5` 用三元组回代返回 (d, s, t)——递归时记住商，回代时执行
"T = S₁ − Q·T₁"的代换（文件注释里写明了这一步对应手算的哪一行）。
天平称量交给 CLPFD：

```prolog
weighable(N, E1, E3, E9, E27) :-
    [E1, E3, E9, E27] ins -1..1,       % 砝码可放两盘：-1, 0, 1
    N #= E1 * 1 + E3 * 3 + E9 * 9 + E27 * 27,
    label([E1, E3, E9, E27]).
```

五行程序 = 定义直译。`?- weighable(19, E1, E3, E9, E27)` 给出
E27 = 1, E9 = −1, E1 = 1，即 19 = 27 − 9 + 1。文件用 `findall` 断言
1..40 的每个重量**恰有一种**称法——平衡三进制存在唯一性的机器版。

## 3.8 要点回顾

1. 除法算式（存在 + 唯一）由良序原则生出，是全部因子理论的地基；
   推论 1.30（素数无穷）是它的第一次亮相。
2. gcd 的三种身份：最大公因子 / 最小正线性组合 / 理想 (a,b) 的生成元。
   贝祖等式 (a,b) = sa + tb 把"比较大小"升级成"代数操作"。
3. 欧几里得引理（p | ab ⟹ p | a 或 p | b）依赖贝祖，是唯一分解的命门；
   √2 无理是它的经典应用。
4. 欧几里得算法 + 回代给出贝祖系数；拉梅定理（步数 ≤ 5×位数）是最早的
   复杂度定理，最坏输入是相邻斐波那契数。
5. b 进制表示存在唯一；天平砝码 1, 3, 9, 27 称尽 1..40 是平衡三进制的
   化身——负数字不是歪门邪道，而是"对称表示"的自然产物。
