## 27.1 与置换的重逢：完全展开

第 08 章埋下的种子在这里发芽。当时我们为每个置换 α ∈ S_n 配了一个
符号 sgn(α) = ±1（定理 2.39：sgn(αβ) = sgn(α)·sgn(β)），只说它是
"对换计数的奇偶性"，没说有什么用。行列式的**完全展开**定义就是它的
第一个正经应用：

> **定义** R 是交换环，A = [a_{ij}] 是 R 上的 n×n 矩阵。则
> det(A) = Σ_{σ∈S_n} sgn(σ) · a_{σ(1),1} a_{σ(2),2} ⋯ a_{σ(n),n}。

读法：从每一**列**各取一个元素相乘（行号由 σ 给出），乘上 σ 的符号，
对所有 n! 个置换求和。σ 是双射保证"每列恰取一行、每行恰取一次"——
这正是一个"没有王后互相攻击"的选格方案，符号 sgn(σ) 再决定这一项
带加号还是减号。n = 2 时只有两个置换：

```
det [[a,b],[c,d]] = sgn(id)·a·d + sgn(swap)·b·c = ad − bc
```

n = 3 时 S₃ 有六项（三个偶置换带 +，三个奇置换带 −），这正是中学
"对角线法则"的来历——但完全展开在任意交换环上成立（定义里只用了
加、乘），这是它在本章后面的用武之地：矩阵可以取值在 ℤ、k[x] 甚至
ℤ/m 里。

**锚点**：det[[1,2],[3,4]] = 1·4 − 2·3 = −2。这一颗锚点钉进四条
机器通道，谁算出别的值谁尴尬。

## 27.2 公理化：一个好函数的三条禀性

完全展开是"算法"，但直接从它证明行列式的性质（尤其是乘法性）是
出了名的繁琐。原书的路线是**公理化**：把 det 看成"把 n 个行向量
α₁, …, α_n 压成一个数"的函数 D : Mat_n(R) → R，要求三条禀性：

> **定义** D 是**行列式函数**，若
> (i) **交错**：两行相等时 D = 0；
> (ii) **多线性**：固定其余行，D 对每一行是线性的（加性 + 齐性）；
> (iii) **规范化**：D(单位矩阵) = 1。

三条禀性各有分工：交错性负责"换两行变号、比例因子提出去"，多线性
负责"逐行拆开"，规范性负责"校准常数"——最终结论是：

1. **至多一个**这样的 D（任何行列式函数都等于完全展开）；
2. **恰好一个**：Laplace 展开给出的递归公式（按第 i 行）
   det(A) = Σ_j (−1)^{i+j} a_{ij} det(A_{ij})
   （A_{ij} 是删去第 i 行第 j 列的余子式）满足三条禀性——这就是
   存在性的归纳证明。(−1)^{i+j} 的棋盘符号来自交错性：展开前先把
   第 i 行换到第一行（换 i−1 次，每次变号）。

存在性与唯一性合在一起，我们才能放心地说"**这个**行列式"：无论用
完全展开、Laplace 递归还是下一节的高斯消元来算，答案必然相同——
三台机器互相对拍的合法性由一条定理担保，不是碰巧。

> **练习（三角阵）** 上三角矩阵的行列式 = 对角元之积。（归纳：
> 按第一列展开，只剩 a₁₁ · det(余子式)。）

## 27.3 三条工程定律

公理化路线的最大红利是三条"工程定律"——原书对前两条的证明从略
（完整证明在外代数教材里，用外代数一次讲清），但它们对计算是刚需：

> **式 (1)（乘法性）** det(AB) = det(A) · det(B)。
> **式 (2)（转置）** det(Aᵀ) = det(A)。

乘法性把"矩阵乘法"映到"数的乘法"——det 是一个乘法半群同态；转置
定律则免费奉送"按**列**展开"：对 Aᵀ 按行展开 = 对 A 按列展开。

第三条工程定律是**算得快**。完全展开要 n! 项，Laplace 递归是指数
级，都不能用。救兵是第 24 章的高斯消元：三类行变换
（I 倍加、II 倍乘、III 换行）分别使 det 变为 r·det，其中
r = 1、c、−1。于是"消元到上三角，追迹因子，取对角乘积"就是
O(n³) 的行列式算法：

```text
det(A) = (追迹因子) × (上三角化的对角元乘积)
```

机器通道里 `det_elim` 就是这个算法的精确有理数实现。注意 II 类
（倍乘）在整数矩阵上会引入分数——所以实现里把矩阵升格为
Rational{Int}，保证每一步都是精确算术。

## 27.4 伴随矩阵与可逆判别

Laplace 展开还有一个"反向"读法：把余子式排成矩阵。定义 A 的
**伴随** adj(A) = [c_{ij}]，其中 **c_{ji} = (−1)^{i+j} det(A_{ij})**
——注意下标**反转**（转置着放），这不是笔误：只有这样排，"按第 i
行展开"才能读成"矩阵乘法的一行"。

> **命题 4.86** A · adj(A) = det(A) · I = adj(A) · A。

证明的妙处在 j ≠ i 的那些对角线外元素：把它们读成"某矩阵按某行
的 Laplace 展开"，而那个矩阵有两行相同——交错性判 0。于是 A·adj(A)
是一个对角线全是 det(A) 的对角阵。

> **推论 4.87** A 可逆 ⟺ det(A) 是 R 中的**单位**；且
> det(A⁻¹) = det(A)⁻¹。

在域上"单位"就是"非零"，得到熟知的"A 可逆 ⟺ det ≠ 0"。但推论
的环论读法更有趣：

- **R = ℤ**：单位只有 ±1 ⟹ 整数矩阵有整数逆 ⟺ det = ±1。
  例：[[2,1],[1,1]] 的 det = 1，逆 [[1,−1],[−1,2]] 果然还是整数阵；
  [[2,0],[0,1]] 的 det = 2，在 ℤ 上不可逆（在 ℚ 上当然可以）。
- **R = k[x]**：单位只有非零常数 ⟹ 多项式矩阵可逆 ⟺ det 是
  非零常数。反例：[[x,1],[−1,x]] 的 det = x²+1 不是常数，故它
  在 k[x] 上不可逆；正例：[[x,−1],[1,0]] 的 det = 0·x −(−1)·1 = 1，
  它有多项式逆 [[0,1],[−1,x]]。第 39 章 Grobner 基之间的基变换
  矩阵正是这种 det = ±1 的阵——补基步只做行加减与单位倍乘。

这正是第 35 章"单位/相伴"概念的矩阵版预习。

## 27.5 相似不变量：特征多项式的系数

> **命题 4.88** P 可逆时 det(PMP⁻¹) = det(M)。
> **推论 4.89** 线性变换 T 的任何矩阵表示有相同的 det——
> det(T) 良定义。

证明只有一行：det(P)·det(M)·det(P)⁻¹ = det(M)，乘法性两次加
一个交换。但推论 4.89 的意义重大：**行列式是线性变换的不变量**，
与基的选取无关。同样的论证用于 xI − A（注意 x 与矩阵元素交换，
可在 k[x] 上取行列式）得到：

> **命题 4.93** h_A(x) = det(xI − A) 是 n 次首一多项式；
> x^{n−1} 的系数 = −tr(A)（迹 = 对角元之和），常数项 = (−1)ⁿ det(A)。

于是三项"对称函数"——迹、e₂（主 2×2 子式之和）、det——都从特征
多项式里读出。旋转矩阵 [[0,1],[−1,0]] 的 det(xI−A) = x²+1 没有
实根：**特征值不一定住在系数域里**。这句话是第 28 章（特征值）
和第 30-31 章（伽罗瓦）共同的起跑线。三个数量恒等式
（tr = 特征值之和、det = 特征值之积，推论 4.95）在 28 章收割。

## 27.6 机器验证一：Lean——定理的证明论形态

**文件：`examples/lean/Abstractalgebra/Ch27Determinants.lean`。**
Lean 通道证明"定理本身"：mathlib 的 `Matrix.det_apply'` 与原书完全
展开逐字对应——

```lean
/-- 完全展开的定义形态（mathlib：det_apply'）。 -/
example (M : Matrix (Fin 3) (Fin 3) ℤ) :
    M.det = ∑ σ : Equiv.Perm (Fin 3), Equiv.Perm.sign σ * ∏ i, M (σ i) i :=
  Matrix.det_apply' M
```

2×2 显式式由 Laplace 展开引理（`det_succ_row_zero`）两行推出；
乘法性与转置（式 (1)/(2)）各引用 mathlib 正式化：

```lean
example (A B : Matrix (Fin 2) (Fin 2) ℤ) : (A * B).det = A.det * B.det :=
  Matrix.det_mul A B
```

本章的"一级定理"是命题 4.86 与推论 4.87 的**一般形式**（任意
交换环、任意阶）：

```lean
/-- 命题 4.86：A·adj(A) = det(A)·I（任意交换环）。 -/
example {R : Type*} [CommRing R] {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n R) : A * A.adjugate = A.det • 1 :=
  Matrix.mul_adjugate A

/-- 推论 4.87：方阵可逆 ⟺ 行列式是单位。 -/
example {R : Type*} [CommRing R] {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n R) : IsUnit A ↔ IsUnit A.det :=
  Matrix.isUnit_iff_isUnit_det A
```

命题 4.88（相似不变性）的证明没有现成引理可用，走"det 乘法性 +
det(P⁻¹) = det(P)⁻¹"的手写路线：由 `nonsing_inv_mul` 得 P⁻¹·P = 1，
两边取 det 挤出 hdetinv，再 `field_simp` 收尾。ℤ 上 det = ±1 的两个
具体侧（[[2,1],[1,1]] 可逆、[[2,0],[0,1]] 不可逆）用"先 decide 算
det、再用 `Int.isUnit_iff_abs_eq` 判单位"的套路。

## 27.7 机器验证二：Julia——三台机器对拍

**文件：`examples/julia/27_determinants.jl`。** 本章 Julia 通道的
主题是"三种互不相干的算法必须同值"。第一台是完全展开——置换
生成器是"把 k 依次插进每个槽位"的插入法，符号由逆序数算出：

```julia
sgn_perm(p::Vector{Int})::Int =
    iseven(count(p[j] > p[i] for i in 1:length(p) for j in 1:i-1)) ? 1 : -1

function det_perm(A::Matrix{Int})::Rational{Int}
    n = size(A, 1)
    s = 0 // 1
    for p in permutations(n)
        term = 1 // 1
        for col in 1:n
            term *= A[p[col], col]     # 每列恰取一行
        end
        s += sgn_perm(p) * term
    end
    return s
end
```

第二台是 Laplace 递归（`det_laplace`，按第 1 行），第三台是高斯
消元（`det_elim`，倍加不变、换行乘 −1、上三角取对角乘积）。断言组：
(1) **40 张随机矩阵（2..5 阶）三机同值**——27.2 节"存在唯一"的
实验面；(2) 锚点 −2；(3) 乘法性与转置不变各 20 组随机对；(4)
命题 4.86 的 3×3 实例（A₃ = [[2,1,0],[1,3,1],[0,1,2]]，det = 8，
手写 `adj3` 与 A₃ 相乘恰为 8·I）；(5) ℤ 侧可逆判别（[[2,1],[1,1]]
与 [[2,0],[0,1]]）；(6) **特征多项式系数**——自建 10 行的微型
多项式类型 `Poly`，用多项式矩阵的 Laplace 展开算 det(xI − A)，
对三个矩阵逐系数断言 [−det, e₂, −tr, 1]，其中旋转块
[[0,1,0],[−1,0,0],[0,0,5]] 给出 x³ − 5x² + x − 5（含无实根因子
x²+1，28 章的预告）。

## 27.8 机器验证三：Python 与 Prolog

**文件：`examples/python/27_determinants.py`。** 与 Julia 同构的
`det_perm`/`det_laplace`，加上**sympy 第三方对拍**：
`sp.Matrix(A).det()` 与两台自实现三方同值（30 张随机矩阵）；自实现
3×3 伴随与 `M.adjugate().tolist()` 逐项相等（开发实录：sympy 的
Matrix 迭代是**逐元素**的，取行要用 `.tolist()`——又一处"想当然
API"被抓）；多项式矩阵 [[x,1],[−1,x]] 的 det = x²+1 非常数 ⟹
ℤ[x] 上不可逆；最后用 `charpoly` 核对命题 4.93 的系数律。

**文件：`examples/prolog/27_determinants.pl`。** 纯整数路线：
`perm/2`（select 回溯生成）、`inversions/2`（foldl 累键对——
开发实录：状态对是"计数-已见表"，解构写成 `I-Tail, Tail = []`
会永假，正确写法是 `I-_`；`include(<(X), Seen, …)` 的部分应用
方向也容易写反）、`det_perm/2` 完全展开、`det_laplace/2` 余子式

+5——旋转块 det = +5 不是 −5，手算想当然写成 −5 被机器当场
纠正）；转置不变；乘法性双例（含 A₃² 的 det = 64）；命题 4.86
的 8·I；ℤ 侧可逆判别。

## 27.9 要点回顾

1. 完全展开 det = Σ sgn(σ)∏a_{σ(i),i}——第 08 章符号函数的
   第一正业；任意交换环上成立。
2. 公理化（交错 + 多线性 + 规范化）⟹ 存在唯一：Laplace 展开、
   完全展开、高斯消元三种算法必然同值。
3. 工程定律：det(AB) = det(A)det(B)、det(Aᵀ) = det(A)、
   行变换因子律（1 / c / −1）——计算走高斯消元，O(n³)。
4. adj 的下标反转是定义的一部分；命题 4.86 的对角线外元素
   "两行相同"归零；推论 4.87 在 ℤ 上读作 det = ±1、在 k[x] 上
   读作 det 非零常数——单位的矩阵版。
5. det 是相似不变量（4.88/4.89），特征多项式 det(xI−A) 的系数
   给出 tr/e₂/det 三个对称函数；特征值可能不住在系数域里——
   下一章从这句线头抽丝。
