## 5.1 同余：把无限个整数折成有限类

> **定义** 设 m ≥ 0。a ≡ b (mod m) 表示 m ∣ (a − b)。

高斯 1801 年《算术研究》引入的这个记号，是"在 m 的倍数处把 ℤ 粘合起来"
的视角切换。第一组事实（原书命题 1.57、1.58）几乎不需要证明，却值得逐条
念出声，因为它们正是"等价关系 + 保持运算"两套性质的合体：

1. a ≡ a（自反）；a ≡ b ⟹ b ≡ a（对称）；a ≡ b, b ≡ c ⟹ a ≡ c（传递）。
   ——所以"模 m 同余"把 ℤ 划分成 m 个**同余类** [0], [1], …, [m−1]
   （推论 1.59：每个整数恰与 0, 1, …, m−1 中的一个同余——除法算式立得）。
2. a ≡ b, a' ≡ b' ⟹ a ± a' ≡ b ± b'，aa' ≡ bb'，且 n ≥ 0 时
   aⁿ ≡ bⁿ（命题 1.60）。

第二组说：**同余类的加法与乘法是良定义的**。这句话在第 15 章（商环）会
升格为一般原理，现在先用小例子感受它的力量。

**例 1.61** 对一切 a，a² ≡ 0, 1 或 4 (mod 8)。证：a ≡ r (mod 8)，
0 ≤ r ≤ 7，则 a² ≡ r²，逐一平方：0,1,4,1,0,1,4,1。∎
顺手得到一个古典应用：形如 8k + 7 的数不是完全平方数。

**弃九法（例 1.66）** 因为 10 ≡ 1 (mod 9)，由命题 1.60 得各位数字之和与
数本身模 9 同余（推论 1.65 的 9 情形）。于是验算乘法有了穷人版：检验
(12345 + 5261934) × 1776 = 9367119504 是否算对——r(12345) = 6，
r(5261934) = 3，r(1776) = 3，故左边 r([6+3]×3) = r(27) = 0；右边
9367119504 各位数字和 45，r = 0。两边余数一致，**通过了弃九法的检验**
（通过≠算对，但通不过必定错——它只是便宜的第一道安检）。推论 1.67 把
同样的把戏推广到 p 进制：数字和模 (p−1) 不变；
例 1.68 用它心算 3¹²³⁴⁵ mod 7：先写 12345 = (50664)₇，数字和 5+0+6+6+4
= 21 ≡ 3 (mod 6)，而 3⁶ ≡ 1 (mod 7)（费马定理），故 3¹²³⁴⁵ ≡ 3³ =
27 ≡ 6 (mod 7)。**进制换底 + 费马 = 指数折叠**，这个技巧在算法竞赛里叫
"快速幂的数学版"。

## 5.2 费马小定理与"新生代梦"

> **定理 1.64（费马小定理）** 若 p 是素数，则对每个 a ∈ ℤ 有
> a^p ≡ a (mod p)；等价地，p ∤ a 时 a^{p−1} ≡ 1 (mod p)。

原书的证明走组合路线，只需命题 1.39（p ∣ C(p, r)，0 < r < p）：

**证明** 对 n 归纳证明 (a + b)^p ≡ a^p + b^p (mod p)（命题 1.63）：
二项式展开的中间系数 C(p, r) 全被 p 整除，模 p 消失。于是对一切非负整数
a，a^p = (1 + 1 + ⋯ + 1)^p ≡ 1^p + ⋯ + 1^p = a (mod p)；负数情形用
(−a)^p = −a^p（p 奇）与 2a ≡ 0 的细节补齐。等价形式：p ∤ a 时两边乘
a 的"逆"——严格说，(a, p) = 1（命题 1.34），贝祖给出 sa + tp = 1，
sa ≡ 1 (mod p)，同余世界里的除法对**与模互素的元素**合法。∎

(a+b)^p ≡ a^p + b^p (mod p) 被戏称为 freshman's dream——新生误以为
"乘方分配 over 加法"，而在特征 p 的世界里**梦想成真**。这句话将在第 22
章（有限域）变成严格的理论基石，第 29 章（经典公式）里还会再见到它。

费马小定理的第二个证明（乘积置换法）同样重要：设 p ∤ a，把
1, 2, …, p−1 全乘以 a，得 a, 2a, …, (p−1)a——它们模 p 两两不同
（消去律：ax ≡ ay ⟹ x ≡ y，因 (a,p)=1），故这批数模 p 恰是 1..p−1 的
重排。于是 a·2a⋯(p−1)a ≡ (p−1)!，即 a^{p−1}(p−1)! ≡ (p−1)!，
同余世界合法约去 (p−1)! 得 a^{p−1} ≡ 1。这个"乘一个元素 = 重排整个
有限群"的论证，是第 10 章拉格朗日定理证明的**逐字预演**。

> **命题 1.62** 存在无穷多个素数 p ≡ 2 (mod 3)。

**证明** 反设 p₁, …, p_k 是全部这样的素数。令 M = 3p₁p₂⋯p_k − 1 ≥ 4，
则 M ≡ 2 (mod 3)，且 M 与每个 p_i 不同（除以 p_i 余 −1）。M 有素因子
分解；若所有素因子都 ≡ 1 (mod 3)，则乘积 M ≡ 1 (mod 3)，矛盾。故 M 有
素因子 q ≡ 2 (mod 3)，而 q 不是任何 p_i。∎
这是欧几里得无穷素数证明的"定向改装版"——第 32 章狄利克雷定理
（等差数列中的素数）的免费样品。

## 5.3 线性同余方程

> **定理 1.69** 若 (a, m) = 1，则对每个 b，同余方程 ax ≡ b (mod m)
> 有解；且任意两解模 m 同余（解在模 m 意义下唯一）。

**证明** 贝祖：sa + tm = 1，故 sa ≡ 1 (mod m)，x = sb 即解。若 ar ≡ as
(mod m)，则 m ∣ a(r − s)，由推论 1.40（(a,m)=1 的消去）得 r ≡ s。∎

推论 1.70：p 素且 p ∤ a 时 ax ≡ b (mod p) 总有解——在模素数的世界里，
**非零元素全体可除**，运算规则与有理数一样顺畅。这个观察是"ℤ/pℤ 是域"
（第 16 章）的同余预演。

解不唯一的情形照样有价值。当 d = (a, m) > 1 时：ax ≡ b (mod m) 有解
⟺ d ∣ b；有解时恰有 d 个模 m 不同的解（习题）。例 1.72 的实战：
51x ≡ 10 (mod 94)。(51, 94) = 1，故解唯一。第 03 章的扩展欧几里得给出
19·94 − 35·51 = 1，即 51⁻¹ ≡ −35 ≡ 59 (mod 94)（验证：51·59 = 3009 =
32·94 + 1 ✓），于是 x ≡ 59·10 = 590 ≡ 26 (mod 94)。复核：51·26 =
1326 = 14·94 + 10 ✓。本章 Julia 通道会把这个例子一步打出来。

## 5.4 中国剩余定理

公元四世纪《孙子算经》："有物不知其数，三三数之剩二，五五数之剩三，
七七数之剩二，问物几何？"——同余方程组的千年老题。

> **定理 1.73（中国剩余定理，CRT）** 设 (m, m') = 1。则对任意 b, b'，
> 方程组 x ≡ b (mod m)，x ≡ b' (mod m') 有解，且任意两解模 mm' 同余。

**证明** 存在性：求 s 使 sm ≡ 1 (mod m')（定理 1.69，因 (m, m') = 1）。
令 x = b + (b' − b)·sm。第一式：x ≡ b (mod m) 显然；第二式：
sm ≡ 1 使 x ≡ b + (b' − b) = b' (mod m')。唯一性：两解之差被 m 与 m'
都整除，互素则整除乘积（贝祖），故模 mm' 同余。∎

构造性证明直接给出算法：**CRT = 定理 1.69 两次 + 一次组合**。
孙子问题的解：x ≡ 2 (mod 3), 3 (mod 5), 2 (mod 7) → x = 23 (mod 105)
（最小正解 23，孙子原书给 23、140、233…）。

> **命题 1.76（不互素的推广）** 设 d = (m, m')。方程组
> x ≡ b (mod m), x ≡ b' (mod m') 有解 ⟺ b ≡ b' (mod d)；
> 有解时解模 lcm(m, m') 唯一。

"互素"的真正作用只是让 lcm = 乘积、让相容条件自动满足。把 m, m' 分解
成素数幂（第 04 章！），任何方程组都拆成素数幂模的独立方程组——CRT 的
深层含义是：**ℤ/mℤ 按素因子裂解成笛卡尔积**。这句话在第 22 章
（商环与有限域）将获得环论表述。

**例 1.78（玛雅历）** 玛雅人的卓尔金历由两个循环叠加：13 个数字与
20 个日名，合周期 260 天。"Akbal 13 之后多少天是 Muluc 8"就是一道 CRT：
天数 d 满足 d ≡ 6 (mod 20)（日名差）、d ≡ 8 (mod 13)（数字差），
解得 d ≡ 86 (mod 260)。玛雅祭司做的心算，与《孙子算经》的作者做的是
同一道代数题——同余是全人类共享的语言。

## 5.5 公钥密码：数论第一次改变世界

原书例 1.79 讲了一个战场故事：间谍网要广播加密消息，但对称密钥一旦
泄露全线崩溃——能不能让**加密方法公开**而解密仍然只有自己会？1977 年
RSA 给出肯定答案，其数学内核全部来自本章：

1. 取大素数 p ≠ q，都 ≡ 2 (mod 3)，公开 N = pq（保密分解）。
2. 编码：明文 a（0 ≤ a < N）加密为 a³ mod N——**加密只是三次方取模**，
   任何人都能做。
3. 解密能力 = 知道 t 使 3t ≡ 1 (mod (p−1)(q−1))。这样的 t 存在，因为
   p ≡ q ≡ 2 (mod 3) 使 (3, (p−1)(q−1)) = 1（命题 1.34）。由费马小定理，
   对一切 a：a^{3t} ≡ a (mod p) 且 a^{3t} ≡ a (mod q)（指数模 p−1 折叠），
   再由 p, q 互素 + 命题 1.76 前的引理（p ∣ c 且 q ∣ c ⟹ pq ∣ c）得
   a^{3t} ≡ a (mod N)。**立方-开立方在模 N 世界里互逆**。
4. 想算 t 必须知道 (p−1)(q−1)，等价于分解 N。由第 04 章的警告，分解大 N
   是公认的难——p, q 各几百位时，N 有上千位，现有算法与算力都无能为力。
   而换钥只需重选一对 p, q（命题 1.62 保证 ≡ 2 (mod 3) 的素数管够）。

单向门的本质：**乘起来容易，拆开来难**。RSA 把第 03、04 两章的
"gcd 快、分解慢"不对称直接兑换成了安全。当然，"分解难"从未被证明——
整个体系建立在一条**经验性**难题上，这与本教程其余定理的确定性形成
有趣对照（量子计算机的 Shor 算法能多项式时间分解，则 RSA 终结——数论
也负责送葬）。

## 5.6 机器验证一：Lean——费马、新生代梦与 CRT

**文件：`examples/lean/Abstractalgebra/Ch05Congruence.lean`。**

```lean
-- 新生代梦的穷举证明：ZMod 3 是有限环，decide 逐元素验证
example : ∀ a b : ZMod 3, (a + b) ^ 3 = a ^ 3 + b ^ 3 := by decide

-- 费马小定理的穷举版（p = 5，含 a = 0 的 a⁵ ≡ a 情形）
example : ∀ a : ZMod 5, a ^ 5 = a := by decide

-- 一般版：模素数 p 的非零元素满足 a^(p−1) = 1
theorem fermat_general (p : ℕ) [Fact (Nat.Prime p)] (a : ZMod p) (ha : a ≠ 0) :
    a ^ (p - 1) = 1 :=
  ZMod.pow_card_sub_one_eq_one ha
```

`ZMod p` 是 mathlib 对 ℤ/pℤ 的正式化。前两个例子用 `decide` **穷举所有
元素**——有限结构上"穷举也是证明"，这是机器通道独有的证明方式：3² 对
与 5 个元素，人手懒而计算机不懒。第三个是一般费马：`ZMod.pow_card_sub_one_eq_one`
正是"非零剩余类的乘法群有 p−1 个元素，故每个元素的 p−1 次幂为 1"的
正式化（单位群路线的极致——引理名就说明了它住在有限域库里）。线性同余
部分验证例 1.72：`51 * 26 % 94 = 10` 由 `decide` 算出，唯一性用
`interval_cases` 把 0..93 的剩余类逐个 `decide`。孙子问题交给 `omega`
（它原生支持模常数算术）：三模联立的最小解 23 一步得出；两模构造解
则调 mathlib 的 `Nat.chineseRemainder'`——一个返回子类型
`{k // k ≡ a [MOD n] ∧ k ≡ b [MOD m]}` 的**构造函数**，其对 3、5 给出的
witness 恰为 8。

## 5.7 机器验证二：Julia——快速幂、CRT 与玩具 RSA

**文件：`examples/julia/05_congruence.jl`** 的三件核心：

```julia
# 快速幂取模：指数折半，复杂度 O(log e) 次乘法
function powmod(a::BigInt, e::Integer, m::BigInt)
    r = big(1); a = a % m
    while e > 0
        e & 1 == 1 && (r = r * a % m)
        a = a * a % m; e >>= 1
    end
    r
end

# 中国剩余定理：定理 1.73 的构造性证明直译
function crt(b1, m1, b2, m2)
    d, s, _ = extgcd(m1, m2)          # 复用第 03 章
    d == 1 || error("模不互素")
    x = b1 + (b2 - b1) * s * m1       # x ≡ b1 (mod m1)，x ≡ b2 (mod m2)
    mod(x, m1 * m2)
end
```

`crt` 的两行主体就是 5.4 节证明的"存在性"部分逐句翻译。断言组：
(1) 费马小定理对 p ≤ 100 的全部素数与全部余数成立（含 p ∣ a 情形）；
(2) 3¹²³⁴⁵ mod 7 = 6——例 1.68 的心算被机器复核，并顺带用"数字和折叠"
路径独立算了一遍（数字和 21 ≡ 3 mod 6，3³ ≡ 6），两路一致；
(3) 孙子问题 crt 链式求解得 23；
(4) 51x ≡ 10 (mod 94) 的解 x ≡ 26 (mod 94)（用 extgcd 得 51⁻¹ ≡ 59，
与 5.3 节手算一致）；
(5) **玩具 RSA**：p = 2003, q = 3011（都 ≡ 2 mod 3），N = 6031033，
明文 "HELLO" 分块编码，加密 c = a³ mod N，解密 a = c^t mod N，其中
t = 3⁻¹ mod ((p−1)(q−1))，往返还原逐块断言相等——5.5 节的完整流程
在 30 行代码里复活。

## 5.8 机器验证三：Python（sympy 交叉印证）与 Prolog（约束求解）

**文件：`examples/python/05_congruence.py`**：用 Python 内建三参数
`pow(a, e, m)`（即快速幂）复算全部 Julia 断言；用 `sympy.ntheory.modular.crt`
与自实现 `crt` 对拍（互素模全量组合）；弃九法演示：(12345 + 5261934) ×
1776 = 9367119504 逐位核对，两侧数字根同为 0；玛雅历 CRT：d ≡ 6 (mod 20)
∧ d ≡ 8 (mod 13) ⟹ d = 86 (mod 260)，并模拟卓尔金历逐日推进，确认第 86 天
正是 "Muluc 8"。

**文件：`examples/prolog/05_congruence.pl`** 用 CLPFD 表达同余：

```prolog
% 孙子问题：x ≡ 2 (mod 3), x ≡ 3 (mod 5), x ≡ 2 (mod 7)
sun_tzu(X) :-
    X #> 0, X #< 105,
    X mod 3 #= 2, X mod 5 #= 3, X mod 7 #= 2,
    indomain(X).           % 标签化：从最小候选开始试探
```

约束即定义。`indomain/1` 让 SWI 的模约束求解器给出最小正解 X = 23。
同一文件穷举验证新生代梦（p = 3：三重循环 a, b ∈ 0..2，断言
(a+b)³ mod 3 = (a³+b³) mod 3）与费马 p = 5, 7 的全部余数；解例 1.78 的
玛雅方程组（`D mod 20 #= 6, D mod 13 #= 8`）；最后做"全同余类乘法表"
——打印 ℤ/6ℤ 与 ℤ/7ℤ 的乘法表各一张，肉眼可见：模 7 的非零行没有零、
模 6 的有（3×4 ≡ 0）——为第 16 章"零因子"概念预铺现场。

## 5.9 要点回顾

1. 同余 = 等价关系 + 运算良定义；ℤ 按模 m 裂成 m 类，类上可加可乘。
2. 费马小定理 a^p ≡ a 的两条证明路：二项式系数（新生代梦）与乘积置换
   （拉格朗日的预演）；指数可在模 φ 的世界里折叠。
3. 线性同余 ax ≡ b (mod m)：有解 ⟺ (a,m) ∣ b；互素时模 m 唯一。
   同余世界的"除法"只对与模互素的元素开放。
4. CRT：互素模方程组解模 mm' 唯一；构造 = 两次求逆 + 组合。深层含义：
   ℤ/mℤ 按素因子裂成积。玛雅历与《孙子算经》同题。
5. RSA 把"gcd 快、分解难"兑换成公钥加密：加密 a³ mod N 公开，解密
   需要 (p−1)(q−1)，即分解。安全建立在一条未证明的经验难题上。
