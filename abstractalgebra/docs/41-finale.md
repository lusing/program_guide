## 41.1 全书一座桥：从数到结构

Rotman 这部教材的暗线只有一句话：**把"解方程"升级成"研究结构的
对称"**。四十二讲的旅程可以画成一张地图：

```
数论（01-06）                群 I（07-14）                交换环 I（15-23）
  归纳/二项式/gcd              集合/置换/群/子群             环/域/多项式/理想
  同余/费马/欧拉               拉格朗日/同态/商群/           域上除法/根/不可约/
  ──────────────▶             作用/Pólya 计数               UFD/有限域/设计
        gcd 的消去律  ──────▶  群作用的轨道计数  ──────▶  k[x] 的欧氏除法
                    │                                       │
                    ▼                                       ▼
  线性代数（24-29）           域（30-31）                  群 II（32-34）
  向量空间/线性映射/          经典公式/五次不可解           有限阿贝尔群分类/
  行列式/特征值/码            （伽罗瓦群的胜利）            西罗定理/装饰对称
                    │                                       │
                    └──────────┬────────────────────────────┘
                               ▼
                     交换环 II（35-40）
                     素理想/UFD/诺特/簇/
                     广义除法/格罗布纳基
                     （代数与算法会师）
```

三条大动脉贯穿始终：

1. **除法算式线**：ℤ 的带余除法（03）→ k[x] 的带余除法（17）→
   欧几里得环公理化（19）→ 多元单项式序下的广义除法（39）→
   Grobner 基（40）。每一站都是"先给元素排序，再做消去"。
2. **同态-商线**：同态定理（11/18）→ 商群/商环（12/18）→
   对应定理（12/18/35）→ Var/Id 的伽罗瓦式对应（38）→
   伽罗瓦对应本尊（31.5，Epilog）。
3. **对称-作用线**：置换（08）→ 群作用与轨道（13）→ Pólya（14）→
   伽罗瓦群（31）→ 带群与晶体学限制（34）。

## 41.3 机器验证总账

全书 159 个验证单元，五条通道（Lean 4 + mathlib 4.33、Julia 1.13、
Python + sympy、SWI-Prolog；Isabelle 选配位留白）各司其职：

- **Lean/mathlib**：恒等式证书（`ring`/`linear_combination`）、
  有限枚举（`decide`）、正式化引用（`Matrix.mul_adjugate`、
  `GaussianInt.norm_mod_lt`、`Nat.Prime.sq_add_sq`）——"定理为真"
  的证明论形态。
- **Julia**：自实现算法的数值对拍（分类器、闭包、高斯除法、
  Buchberger、韦达三角解）——"算得出"的工程形态。
- **Python/sympy**：符号标准答案（`factor`、`galois_group`、
  `groebner`、`charpoly`、`minimal_polynomial`）——与自实现互相锁死。
- **Prolog**：纯逻辑重建（关系式即谓词，断言即定理陈述）——
  "可枚举即可信"的极简形态。

三个反复出现的纪律：数值断言一律精确（整数/有理算术，浮点只作
残差窗口）；三通道同值互锁（同一组数字，谁错谁尴尬）；文档里的
代码段与真实文件逐字同步（snippet 对账）。

机器抓出的数学错误（部分清单，详见各章"调试实录"）：卡尔达诺
相伴立方根的分支约束（30）、费拉里预解三次的系数（30）、韦达
cos 表半值（30）、商环 ℤ/n/(d) ≅ ℤ/d 的方向（35）、UT(3,F₂) 的
指数是 4 非 2（33）、gcd(72,108) = 36 非 12（36）、二维 V(x²) 是线
不是点（38）、旋转块 det = +5 非手滑的 −5（27）、Prolog 矩阵乘积
首行 [4,7] 非手滑的 [2,7]（27）、理想相等的反例初选不当（40）。
**机器不是诚实的仆人——它是最较真的同事。**

## 41.4 附录掠影

原书附录 A（不等式）与 B（伪码）是全书算法面的工具箱：A 的
算术-几何不等式（中译本升格进了 §1.1，英文版在附录——见第 01 章
的"补录"标注）支撑了第 24-28 章的范数与内积论证；B 的伪码
约定（while 循环、归纳不变式）就是第 39-40 章除法与 Buchberger
算法的书写格式。四通道示例文件即是"伪码的可执行版"。

## 41.5 继续前进的四个方向

1. **伽罗瓦理论**：第 30-31 章只走到"群判定可解性"+ Epilog 的
   对应陈述；完整的对应（中间域 ↔ 子群）是下一门课（原书第 5 章
   结束语的展望——31.5 节已把地图摊开）。
2. **模论与结构定理**：诺特环 + 有限生成模 = 第 32 章分类的
   非交换推广（Noether–Skolem、Krull–Schmidt）。
3. **计算代数**：Grobner 基之后是 F4/F5、结式、圆柱代数分解
   （CAD）——符号计算的全部家底。
4. **代数几何**：定理 7.45 的"点 ↔ 极大理想"字典推到
   Spec 与概形——几何的算术化在更高处重演。
