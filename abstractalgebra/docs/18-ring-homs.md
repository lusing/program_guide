# 18 环同态

**对应原书 §3.4（pp. 240-249）。**

---

## 18.1 保持两种运算

> **定义** 环同态 φ : R → S 满足 φ(1) = 1、φ(a + b) = φ(a) + φ(b)、
> φ(ab) = φ(a)φ(b)。核 ker φ = {a : φ(a) = 0}，像 im φ = φ(R)。
> 双射同态称同构。

例清单：
- **求值同态** φₐ : R[x] → R，f ↦ f(a)（第 17 章）；
- **mod m**：ℤ → ℤ/mℤ，k ↦ [k]；
- **包含** ℤ ↪ ℚ（分式域定理的嵌入半场）；
- **复共轭** ℂ → ℂ 是**同构**（z ↦ z̄ 保加乘）；
- **范数** ℤ[i] → ℤ，z ↦ z z̄ = N(z)——**不是**同态（乘性
  N(zw) = N(z)N(w) ✓，加性破产）。

与群同态的平行结论全部搬来（第 11 章的复刻）：

> **命题 3.3x** ker φ 是 R 的子环（且对"乘任意元"封闭——**理想**的
> 预告），im φ 是 S 的子环；φ 单 ⟺ ker φ = {0}。

**|R| = |ker|·|im|** 的数值规律同样成立（有限环上逐陪集数）。

## 18.2 核的新身份：理想

群同态的核是**子群**，环同态的核更强——它对"乘上环中任意元素"封闭：

> **定义** 交换环 R 的**理想** I ⊆ R 是加法子群且 rI ⊆ I
> （r ∈ R, x ∈ I ⟹ rx ∈ I）。理想是"核"的公理化。

ℤ 的理想恰为 mℤ（第 03 章推论 1.34 的回响！）；R[x] 中
(f) = f·R[x] 是主理想。"理想"这个名字源于库默尔时代的"理想数"，
如今它是环论的承重墙——第 22 章商环、第 35 章素/极大理想都以它
为基本粒子。**子环 vs 理想**：ℤ 是 ℚ 的子环但不是理想（(1/2)·1 ∉ ℤ）；
2ℤ 是 ℤ 的理想但不是子环（无单位元）——两个概念交错不包含。

> **例（mod m 的核）** ℤ → ℤ/mℤ 的核 = mℤ。第一同构定理的环版
> （第 22 章）将给出 ℤ/mℤ ≅ ℤ/mℤ（平凡）与 R[x]/(x²+1) ≅ ℂ 的
> 非平凡实例——后者是"造新环"的招牌动作，值得在第 22 章细看。

## 18.3 环同构与"换个坐标看环"

> **命题 3.3x** φ 同构 ⟹ 逆映射也是同构；"a 是单位 ⟺ φ(a) 是
> 单位"、"a 是零因子 ⟺ φ(a) 是零因子"（同构保持环论的全部内部
> 性质）。

经典判定例：ℤ[√2] ≇ ℤ[√3]?——用"单位群大小"或"元素平方"等
不变量区分。机器通道（下节）用**表同构搜索**验证小型案例。

**高斯整数的范数** N(a+bi) = a² + b² 满足 N(zw) = N(z)N(w)——
虽然 N 不是环同态，但这个乘性使它成为"研究 ℤ[i] 整除性的探针"
（第 36 章的伏笔）：N(z) = 1 ⟺ z = ±1, ±i（单位），N(zw) = N(z)N(w)
把 ℤ[i] 的因子问题翻译成 ℤ 的因子问题。

## 18.4 机器验证一：Lean——RingHom

**文件：`examples/lean/Abstractalgebra/Ch18RingHoms.lean`。**
mathlib 的 `RingHom R S`（记号 R →+* S）：

```lean
-- 同态基本律（结构层给出）
example {R S : Type*} [CommRing R] [CommRing S] (f : R →+* S) : f 1 = 1 :=
  f.map_one
example {R S : Type*} [CommRing R] [CommRing S] (f : R →+* S) (a b : R) :
    f (a * b) = f a * f b := f.map_mul a b

-- 核是理想（mathlib：RingHom.ker 是 Ideal）
example {R S : Type*} [CommRing R] [CommRing S] (f : R →+* S) :
    ∀ (r : R) (x : R), x ∈ f.ker → r * x ∈ f.ker := by
  intro r x hx
  simp [RingHom.mem_ker] at hx ⊢
  rw [map_mul, hx, mul_zero]

-- 复共轭是环自同构
example : Function.Bijective (Complex.conj : ℂ → ℂ) :=
  Complex.conj_bijective
```

具体轨道：ℤ → ℤ/6ℤ 的自然同态（`Int.castMod`/ZMod 机器），
断言核 = 6ℤ 型集合（`RingHom.ker` 的元素判定逐个 decide）；
范数 N : ℤ[i] → ℤ 非加性的具体反例（N((1+i) + (1+i)) = 8 ≠
2·2 = 4 + 4? N(2+2i) = 8，N(1+i)+N(1+i) = 4——8 ≠ 4 ✓ 断言）。

## 18.5 机器验证二：Julia——同态表与核的画像

**文件：`examples/julia/18_ring_homs.jl`**：

```julia
"""环同态检查：f(1) = 1、保加、保乘（全元素对）。"""
is_ring_hom(addR, mulR, addS, mulS, f) =
    f[one] == one &&
    all(addS[f[a]+f[b]+1] == f[addR[a+b+1]] for ...)
```

断言组：(1) **mod 同态** ℤ₁₂ → ℤ₄（k mod 4）——12×12 对全查通过，
核 = {0, 4, 8}（3 元），|ℤ₁₂| = 3 × |im = ℤ₄| = 3 × 4 ✓；
(2) 求值同态 φ₂ : ℤ₇[x] → ℤ₇（x ↦ 2）在次数 ≤ 3 的多项式全表上
核大小 = 7³（每个多项式由余式 mod (x−2) 决定——第一同构定理的
数值投影）；(3) **非同态反例**：平方映射 ℤ₇ → ℤ₇ 保乘不保加
（具体数字：φ(1+1) = 4 ≠ 1 + 1 = 2）；范数 ℤ[i] → ℤ 非加性复算；
(4) 复共轭做成 ℂ 的 4×4 有理模型 ℚ(i) 上的表同构（2 元序对模型，
搜索双射命中恒等与共轭两个自同构）。

## 18.6 机器验证三：Python 与 Prolog

**文件：`examples/python/18_ring_homs.py`**：复算 Julia 断言；
sympy 的 `Poly.eval` 驱动求值同态的核统计（ℤ₇[x] 次数 ≤ 2 的
343 个多项式中，核恰 49 = 7² 个——kernel = (x−2) 的倍数）；
ℤ → ℤ/mℤ 核 = mℤ 对 m = 2..12 的清单。

**文件：`examples/prolog/18_ring_homs.pl`**：

```prolog
% 核的吸收性：r * x ∈ ker（理想性质）
absorbed(R, Ker) :-
    forall((elem(R, X), member(K, Ker), mul(R, X, K, XK)),
           member(XK, Ker)).
```

文件断言：ℤ₁₂ → ℤ₄ 同态核 {0,4,8} 的吸收性；枚举 ℤ₄ → ℤ₄ 的
全部映射（4⁴ = 256）筛出同态个数（恰 4 个：k ↦ ck）；核-像-
原像的集合恒等式（|R| = |ker| × |im|）逐个核验。

## 18.7 要点回顾

1. 环同态保 1、保加、保乘；求值、mod、包含、共轭是四大样板；
   范数"乘性非加性"是重要反例。
2. ker φ 不止是子环——对乘任意环元素封闭（理想）；理想 = 核的
   公理化，第 22/35章的基本粒子。
3. φ 单 ⟺ 核零；|R| = |ker|·|im|（有限环数值规律）。
4. 同构保持全部内部性质（单位、零因子、可逆性）——"换坐标看环"。
5. 高斯范数 N(zw) = N(z)N(w)：非同态的乘性映射同样值钱——
   ℤ[i] 整除研究的探针（第 36 章伏笔）。
