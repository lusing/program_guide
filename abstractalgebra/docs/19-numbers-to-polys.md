# 19 从数到多项式：根与因子

**对应原书 §3.5（pp. 250-271）。**

---

## 19.1 大翻译：整数的定理 → 多项式的定理

第 03-04 章的整除理论几乎逐字平移到 F[x]（F 域）——因为唯一的
引擎是**除法算式**，而 F[x] 有它（第 17 章）。对照表：

| ℤ | F[x] |
|---|---|
| 除法算式 a = qb + r | f = qg + r（deg r < deg g） |
| gcd 存在（欧几里得算法） | gcd 存在（多项式欧几里得） |
| 贝祖：d = sa + tb | d = sa(x) + tb(x) |
| 欧几里得引理 | 不可约 g ∣ fg ⟹ g ∣ f 或 g ∣ g |
| 算术基本定理 | 唯一分解（第 20 章） |
| 素数 | **不可约多项式** |
| ℤ 的理想都是主理想 | F[x] 的理想都是主理想 |

"带余除法的整环"被抽象成**欧几里得整环**（Euclidean domain），
ℤ 与 F[x] 是两大初始样本——这条抽象线第 36 章正式展开。

## 19.2 根：多项式的零点算术

> **定义** a ∈ R 是 f ∈ R[x] 的**根**，若 f(a) = 0。

> **因子定理（命题 3.4x）** a 是 f 的根 ⟺ (x − a) ∣ f。
> **命题 3.4x** f 在整环 R 中至多有 deg f 个根。

证明（重数计数）：f = (x−a₁)(x−a₂)⋯(x−aₖ)·g，代 x = aᵢ 逐个
消去——整环无零因子保证每次消去合法。∎

**反例警示**：整环性必要！ℤ/8ℤ 中 x² − 1 有 4 个根（1, 3, 5, 7），
超过次数 2——零因子让"次数 = 根数上限"破产。

> **定理 3.4x（代数基本定理的实用版）** n 次复多项式恰有 n 个根
> （计重数）——ℂ[x] 的完全分裂。d 次多项式在域 F 上至多 d 个根，
> 恰 d 个 ⟺ 在 F 上完全分裂。

## 19.3 有理根与整系数多项式

整系数多项式的有理根可以**穷举**：

> **命题 3.4x（有理根定理）** f = sₙxⁿ + ⋯ + s₀ ∈ ℤ[x]，既有理根
> p/q（既约）满足 p ∣ s₀ 且 q ∣ sₙ。

例：f = 2x³ + x − 3 的候选有理根 = ±{1, 3} ÷ ±{1, 2}，逐一检验
发现 x = 1 是根（2+1−3 = 0），故 f = (x−1)(2x²+2x+3)，二次因子
判别式 4 − 24 < 0 无实根——**有理根定理 + 试除 = 三次方程的
人肉求解器**。这是第 30 章（经典公式）的土法前奏。

**不可约的传递**（习题常用）：f ∈ ℤ[x] 在 ℚ[x] 不可约 ⟺ 在
ℚ[x] 看作本原多项式（系数 gcd = 1）不可约——Gauss 引理的
内容，第 21 章展开。

## 19.4 多项式欧几里得算法与 gcd

与整数版逐字对应：反复做多项式除法，余式次数严格下降，终止于
零余式；最后一个非零余式（取首一化）即 gcd。贝祖等式
d(x) = s(x)f(x) + t(x)g(x) 由回代产生（第 03 章 extgcd 的多项式版）。

**应用一（最小公倍式）**：lcm(f,g) = fg/gcd(f,g)。
**应用二（部分分式的胚）**：1/(fg) = s/d + t/d′ 的分解依赖贝祖。
**应用三（中国剩余的环版）**：(x−a)(x−b) 互素 ⟺ a ≠ b，插值
多项式的存在性（习题：拉格朗日插值 = CRT 在 F[x] 上的实现）。

## 19.5 欧几里得环：除法算式的公理化

ℤ 与 k[x] 共享"带余除法"这件事，值得提纯成公理（原书 §3.5 的
Euclidean Rings 小节，英文 3 版 pp. 265-272）：

> **定义** 整环 R 是**欧几里得环**，若存在度函数
> ∂ : R×→ℕ 使得
> (i) ∂(f) ≤ ∂(fg) 对一切非零 f, g；
> (ii)（除法算式）对任意 g 与非零 f，存在 q, r 使 g = qf + r，
> 且 r = 0 或 ∂(r) < ∂(f)。

三个初始样本（例 3.76）：**域**（∂ ≡ 0，且 ∂ ≡ 0 是度函数的整环
必为域——1 = qf + r 强制 r = 0）、**ℤ**（∂ = |m|，还是乘性的）、
**k[x]**（∂ = 次数，加性的）。乘性的度函数叫**欧几里得范数**，
下一个样本是明星：

> **例 3.77（高斯整数环 ℤ[i]）** ∂(a+bi) = a²+b² 是欧几里得范数，
> ℤ[i] 是欧几里得环。

三步证明值得完整过一遍。(1) **乘性**：∂(α) = α·ᾱ（共轭乘积，
推论 1.20 的 |zw| = |z||w| 整数版），于是 ∂(αβ) = ∂(α)∂(β)。
(2) **公理 (i)**：β ≠ 0 时 ∂(β) ≥ 1 ⟹ ∂(α) ≤ ∂(α)∂(β)。
(3) **除法算式**：把 α/β = αβ̄/∂(β) 看成平面上的点 (x, y)，取
**最近整点** (m, n)（|x−m|, |y−n| ≤ 1/2），令 q = m+ni、
r = β·((x−m)+(y−n)i)。则 r ∈ ℤ[i]，且

∂(u+vi) = u²+v² ≤ 1/4 + 1/4 = 1/2 < 1（u, v 是小数部分）

乘性给出 ∂(r) = ∂(β)·∂(u+vi) < ∂(β)。∎ **最近整点**是整个证明
的灵魂：方格纸上的任何点离某格点不超过半格。

**商与余不唯一**——这是欧几里得环比 ℤ 多出来的自由度。α = 3+5i
除以 β = 2：α/β = 3/2 + 5/2 i，实部虚部都恰在两格点**正中间**
（m = 1 或 2，n = 2 或 3），于是四种"最近整点"给出四个商：

```
3+5i = 2(1+2i) + (1+i) = 2(1+3i) + (1−i)
     = 2(2+2i) + (−1+i) = 2(2+3i) + (−1−i)
```

每个余数的 ∂ = 2 < 4 = ∂(2)。（ℤ 里其实也有半份自由：3 = 1·2+1
= 2·2−1，|±1| < 2；定理 1.29 用"余数非负"强行挑出一个。）四条
机器通道把这四个分解全部验证。

> **命题 3.78** 欧几里得环都是 PID（主理想整环）。
> 证明：取理想 I 中度数最小的非零元 d（最小整数公理），除法算式
> 把任何 g ∈ I 写成 qd + r，r ∈ I 且 ∂(r) < ∂(d)——最小性逼 r = 0。

**逆命题不成立**，而且第一个反例就藏在二次整环里（例 3.79）：
R = ℤ[(1+√−19)/2] 是 PID 但不是欧几里得环（Motzkin 1949）。判别
工具是 Motzkin 的**普遍侧因子**：u 非单位且对任意 x，要么 u∣x、
要么存在单位 z 使 u∣(x+z)。命题 3.80：非域的欧几里得环必有普遍
侧因子（取度数最小的非单位 u，除法算式的余数 r 要么 0 要么度数
更小——后者只能是单位）。Motzkin 验证 ℤ[(1+√−19)/2] 没有普遍侧
因子，从而拆散"欧几里得 ⟹ PID"的逆。"存在度函数"这一性质竟然
**不能**用理想的语言重述——这是抽象代数早期的一记警钟。

> **命题 3.81（PID 的红利）** PID 中 (i) 任意 α, β 有 gcd，且是
> 线性组合 δ = σα + τβ；(ii) 素元满足欧几里得引理：π∣αβ ⟹
> π∣α 或 π∣β。
> 证明与 ℤ 版（定理 1.32/1.35）逐字平行：理想 (α, β) = (δ)。

## 19.6 费马二平方和：ℤ[i] 的第一份红利

哪些素数 p 能写成 a²+b²？费马 1640 年给出口头证明（欧拉 1747 年
首发书面版），高斯补上唯一性。ℤ[i] 的范数把这个问题翻译成"p 在
ℤ[i] 中是否保持素性"：

> **引理 3.82** p 素且 p ≡ 1 (mod 4) ⟹ 存在 m 使 m² ≡ −1 (mod p)。
> 证明走群论：G = (ℤ/p)× 的阶 p−1 ≡ 0 (mod 4)，由命题 2.122 G
> 有 4 阶子群 S；p 素 ⟹ S 循环（4 个元素 x⁴=1 与二次方程根数
> 矛盾——命题 2.132 的语言），设 S = ⟨[m]⟩，则 [m]² 的阶为 2，
> 而 (ℤ/p)× 中阶 2 元唯一（x²−1 只有两根 ±1），故 [m]² = [−1]。∎

> **定理 3.83（费马二平方和）** 奇素数 p 是二平方和 ⟺ p ≡ 1 (mod 4)。
> **(⇐)** 取引理的 m：p ∣ m²+1 = (m+i)(m−i)。若 p 在 ℤ[i] 中
> 仍是素元，则由命题 3.81(ii)（欧几里得引理）p∣(m+i) 或 p∣(m−i)，
> 两边取范数得 p² ∣ ∂(m+i) = m²+1 < p²+p… 矛盾（或直接：p∣m+i
> 会逼出 p∣2i，∂(p) = p² > ∂(2i) = 4 荒谬）。故 p = αβ 非平凡
> 分解，取范数：p² = ∂(α)∂(β)，两因子都 ≠ 1、≠ p²，只能都是 p
> ——∂(α) = a²+b² = p。∎
> **(⇒)** 平方 mod 4 只取 0, 1：a²+b² ≢ 3 (mod 4)，故 p ≡ 3 (mod 4)
> 时无表示。∎

证明的每个零件都已在前文就位：范数乘性（19.5）、欧几里得引理
（3.81）、阶 4 子群（2.122）——**五个章节的线头在这里打结**。
机器面：对 p ∈ {5, 13, 17, 29, 41, 61}（≡1 mod 4）搜出表示
(a,b) 并核验 a²+b² = p；对 p ∈ {3, 7, 11, 19}（≡3 mod 4）穷举
无表示；引理 3.82 的见证 m 也一并算出（如 p = 5: 2²≡−1；p = 13:
5² = 25 ≡ −1；p = 29: 12² = 144 ≡ −1）。

## 19.7 机器验证一：Lean——根与因子定理

**文件：`examples/lean/Abstractalgebra/Ch19Roots.lean`。**

```lean
-- 因子定理：(x − a) ∣ f ⟺ f(a) = 0
example {F : Type*} [Field F] (f : Polynomial F) (a : F) :
    (Polynomial.X - Polynomial.C a) ∣ f ↔ f.eval a = 0 :=
  Polynomial.X_sub_C_dvd_iff_eval_eq_zero f a

-- 根数 ≤ 次数（整环上）
example {R : Type*} [CommRing R] [IsDomain R] (f : Polynomial R) :
    Fintype.card f.roots ≤ f.natDegree := ...
```

本章新增的欧几里得环单元用的是 mathlib 的高斯整数库
（`NumberTheory.Zsqrtd.GaussianInt`；`ℤ[i]` 记法在该文件内是 local 的，
本教程文件里须写 `GaussianInt` 全名）。**例 3.77 的除法算式在 mathlib
里就是 `norm_mod_lt`**——

```lean
/-- 例 3.77 的核心：高斯整数的除法算式（mathlib 正式化）。 -/
example (x : GaussianInt) {y : GaussianInt} (hy : y ≠ 0) :
    Zsqrtd.norm (x % y) < Zsqrtd.norm y :=
  GaussianInt.norm_mod_lt x hy
```

四商恒等式两条以 `decide` 直接收口；**定理 3.83 的 mathlib 正式化**
在 `NumberTheory.SumTwoSquares`：`Nat.Prime.sq_add_sq : p % 4 ≠ 3 →
∃ a b, a² + b² = p`——费马二平方和是现成的证明对象，不只是计算对象。
引理 3.82 的三个见证以 ZMod 上的 `decide` 核验（2²≡−1 mod 5、
5²≡−1 mod 13、12²≡−1 mod 29）。

（`X_sub_C_dvd_iff_eval_eq_zero` 正是因子定理的正式化；根集
`Polynomial.roots` 在整环上的基数不等式由 `Polynomial.card_roots'`
承担。）具体轨道：x³ − x 在 ℚ 上 3 根（−1, 0, 1）、在 ℤ/8ℤ 模型上
x² − 1 有 4 根的反例（以 ℤ/8ℤ 为系数环 decide 计根）；有理根定理
的实例：2x³ + x − 3 的候选 {±1, ±3, ±1/2, ±3/2} 中恰 x = 1 入选。

## 19.8 机器验证二：Julia——根搜索与欧几里得

**文件：`examples/julia/19_roots.jl`**：

```julia
"""多项式欧几里得（F = ℤ_p）：返回 (gcd, s, t) 使 d = sf + tg。"""
function poly_extgcd(f, g, p)
    old_r, r = f, g
    old_s, s = [1], [0]
    old_t, t = [0], [1]
    while any(!=(0), r)
        q, rem = polydiv(old_r, r, p)
        old_r, r = r, rem
        old_s, s = s, old_s .- polymul(q, s; p) |> x -> trim!(x)
        ...
    end
    (old_r, old_s, old_t)
end
```

断言组：(1) **根穷举**：ℤ₇[x] 中 x³ − x 的根 = {0, 1, 6}（逐点
求值），恰 3 = deg ✓；ℤ₈[x] 中 x² − 1 的根 = {1, 3, 5, 7}（4 个
> 次数——反例现场）；(2) **有理根定理机器化**：f = 2x³+x−3 的
候选集（divisor(s₀) × divisor(sₙ)）逐一求值，恰 {1} 是根；
(3) **贝祖回代**：ℤ₅[x] 中 gcd(x²+1, x+2) 的 s, t 满足
sf + tg = d（系数 mod 5 逐项核对）；(4) gcd 幂等：
gcd(f, g) = gcd(g, f mod g) 递归正确性（50 组随机对拍）；
(5) **拉格朗日插值**：ℤ₇ 上过 (1,2), (2,4), (3,0) 的二次多项式
存在且唯一（解线性方程组 vs CRT 公式双路）；(6) **高斯整数**
（例 3.77）：`gauss_divide` 用最近整点实现高斯除法（α/β = αβ̄/∂(β)
的实虚部分别取最近整点），断言四商恒等式、40 对随机 α, β 的
∂(r) < ∂(β)、20 对范数乘性；(7) **二平方和**（定理 3.83）：六个
p ≡ 1 (mod 4) 的素数各搜出表示 (a, b) 并核验，引理 3.82 的见证 m
一并断言，四个 p ≡ 3 (mod 4) 的素数穷举无表示。

## 19.10 要点回顾

1. 除法算式 ⟹ 欧几里得算法 ⟹ 贝祖 ⟹ 欧几里得引理——F[x] 完整
   复刻 ℤ 的整除理论；"素数"对应"不可约多项式"。
2. 因子定理：根 ⟺ 线性因子；整环上根数 ≤ 次数（ℤ/8ℤ 反例警示
   整环性必要）。
3. 有理根定理：p ∣ 常数项、q ∣ 首项系数——候选穷举 = 人肉求解器。
4. 多项式欧几里得 + 回代给出贝祖 s(x)f + t(x)g = d(x)；lcm、
   部分分式、插值全是它的下游。
5. ℂ[x] 的 n 次多项式恰 n 根（计重数）——代数基本定理的实用形态。
6. 欧几里得环 = 度函数公理化（∂(f) ≤ ∂(fg) + 除法算式）；域、ℤ、
   k[x]、ℤ[i] 四大样本；商余不唯一（3+5i ÷ 2 四商）；欧几里得
   ⟹ PID（命题 3.78），逆命题假（Motzkin 的 ℤ[(1+√−19)/2]）。
7. 费马二平方和（定理 3.83）：p ≡ 1 (mod 4) ⟺ p = a²+b²——ℤ[i]
   范数乘性 + 引理 3.82（m² ≡ −1）+ 欧几里得引理的三步合奏。
