## 30.1 从卡尔达诺到拉格朗日：三百年前的战争

16 世纪的意大利半岛，数学决斗是一场真刀真枪的娱乐产业。三次方程的求根
公式是文艺复兴时期最有分量的数学成果，其产权纠纷（del Ferro → Tartaglia
→ Cardano 的誓言与背叛）比公式本身更有名。本节把这条公式的完整推导
走过一遍——并且用"根的置换"重新理解它，这正是通向五次不可解的暗道。

** depressed cubic（消二次项）**：x³ + ax² + bx + c = 0 代换 x = t − a/3
化为 t³ + pt + q = 0。所有力气花在缺二次项的形式上。

> **卡尔达诺公式**：t³ + pt + q = 0 的一个根是
> t = ∛(−q/2 + √(q²/4 + p³/27)) − ∛(q/2 + √(q²/4 + p³/27))。
> 其中 Δ = q²/4 + p³/27 是**判别式**（差一个常数因子）。

**推导（换元 u + v）**：设 t = u + v，代入得
u³ + v³ + (3uv + p)(u + v) + q = 0。强迫 3uv + p = 0（我们有权选 v），
则 u³ + v³ = −q 且 u³v³ = −p³/27——u³ 与 v³ 是二次方程
z² + qz − p³/27 = 0 的两根。z = −q/2 ± √(q²/4 + p³/27) 即公式。∎

**四个三次的实况**：
- Δ > 0：一个实根 + 一对共轭复根（公式直接给实根）；
- Δ = 0：重根（t = −3q/p 重一）；
- Δ < 0：**三个不同实根**，但公式穿过复数世界才能到达（√Δ 为虚）——
  **不可约情形（casus irreducibilis）**。这曾是 16 世纪的心理障碍：
  实答案必须借道复数，证明"复数不是歪门邪道"的第一推动力。

## 30.2 四次：费拉里的配平术

> **费拉里方法**：x⁴ + ax² + bx + c = 0（先消三次项）改写为
> x⁴ = −ax² − bx − c，两边加 (x²·s + s²/4) 配成平方差：
> (x² + s/2)² = (s − a)x² − bx + (s²/4 − c)。
> 选 s 使右边也是完全平方（判别式 = 0），得 s 的三次**预解方程**；
> 每个根 s 给出两个二次方程，共得四根。

四次归结为三次、三次归结为二次——**降次链**。拉格朗日 1770 年发问：
这条链背后的统一机制是什么？答案是**根的置换**：

> **拉格朗日预解式**：对 n 次方程取根 r₁,…,rₙ 与一个 n 次单位根 ω，
> 定义 (r₁ + ωr₂ + ω²r₃ + ⋯)。它的 n 次幂在"轮换"下不变，因而
> 可由原方程系数（经 n−1 次方程的根）表出。二次用 ω = −1（和差），
> 三次用 ω³ = 1（三次单位根），四次用 ω⁴ = 1——**n = 5 时预解式的
> 最小多项式次数不降反升**，链条断裂。

拉格朗日已经摸到了答案的边缘：**置换群的可解结构决定公式的存在**。
下一章（第 31 章）把这句话变成定理。

**韦达定理与对称函数**：根与系数的关系
e₁ = Σrᵢ = −a_{n−1}/a_n、e₂ = Σ_{i<j} rᵢrⱼ = a_{n−2}/aₙ、…
是对称多项式；牛顿定理说明**每个对称多项式都能表成 e₁,…,eₙ 的多项式**——
这正是"系数看得见根的对称函数、看不见根本身"的代数表述，也是伽罗瓦
理论里"固定基域 = 固定对称函数"的雏形。

## 30.3 韦达的三解：三角公式替代开立方

卡尔达诺公式在三实根（casus irreducibilis，判别式 27r²+4q³ ≤ 0）时
必须穿过**复数**才能落回实根——"无理实根用复数表示"是十六世纪不能
接受的悖论，也是"根式"这个概念需要反思的第一现场。韦达给出第二条路
（定理 5.12，英文 3 版 pp. 443-447）：**用余弦替代开立方**。武器是
三倍角恒等式（推论 1.23）

cos 3θ = 4cos³θ − 3cosθ，

它说明 u = cos θ 恰是三次方程 y³ − (3/4)y − (1/4)cos3θ 的根，而另外
两根是 cos(θ+120°)、cos(θ+240°)（习题 5.9：三个角的三倍角相同）。
于是对 f(x) = x³ + qx + r（三实根情形）做**伸缩替换** v = t·u：

0 = f(tu) = t³(u³ + (q/t²)u) + r。

选 t² = −4q/3（q < 0 保证 t 实），括号里就成了 y³ − (3/4)y；再选
cos3θ = −4r/t³（判别式条件恰好保证 |·| ≤ 1，这是证明里最细的一步：
27r² ≤ −4q³ ⟹ |3r/q| ≤ t ⟹ |−4r/t³| ≤ 1），三个根

**v = t·cos θ，t·cos(θ+120°)，t·cos(θ+240°)**

就到手了。**Scipione 的技巧把根写成和（α+β），韦达的技巧把根写成积
（t·u）**——两种"降维"殊途同归。

> **例 5.13** x³ − 7x + 6 = (x−1)(x−2)(x+3)：t = √(28/3) ≈ 3.055，
> cos3θ = −24/t³ ≈ −0.842，3θ ≈ 148°，θ ≈ 49°；查三角表得
> 3.055·cos49° ≈ 2.00、3.055·cos169° ≈ −3.00、3.055·cos289° ≈ 1.00。
> 卡尔达诺公式里的 ∛(−3+√(−100/27)) 在这里一次复数都没碰。

**整数展示例**（机器通道的最爱）：x³ − 3x − 2 = (x−2)(x+1)²。
t² = −4·(−3)/3 = 4 ⟹ t = 2；cos3θ = −4·(−2)/8 = 1 ⟹ 3θ = 0°，
θ ∈ {0°, 120°, 240°}；cos 表 {1, −1/2, −1/2} 给出根
{2·1, 2·(−1/2), 2·(−1/2)} = **{2, −1, −1}**——韦达公式把二重根
也一并吐出，全程整数。

> **注（双曲变体）** 判别式 27r² + 4q³ > 0（单实根）时 −4q/3 < 0，
> t 是虚数，三角路线失效。原书用双曲函数接棒：cosh3θ = 4cosh³θ −
> 3coshθ（习题 5.8），实根 v = t·cosh(φ/3)（t² = −4q/3 需 q > 0 侧
> 调整；sinh 版处理 q < 0）。三倍角恒等式的"椭圆亲戚"各管半边天。

韦达路线的哲学意义在第 31 章兑现：**"根式解"与"三角解"是两种不同的
可解性**——后者对三实根的 x³ − 3x − 1 依然有效（有理根不存在，
卡尔达诺要穿复数，韦达直接查表）。但五次方程在**两种**意义下都死了。

## 30.4 机器验证一：Lean——卡尔达诺恒等式

**文件：`examples/lean/Abstractalgebra/Ch30Formulas.lean`。**
三次求根公式的符号验证在 Lean 里较重；文件以**恒等式内核**呈现：
设 u、v 满足 3uv = −p，则 t = u+v 自动满足
t³ + pt = u³ + v³——公式的正确性归结为这个一行代数：

```lean
-- 3uv = −p ⟹ (u+v)³ + p(u+v) = u³ + v³
example (u v p : ℚ) (h : 3 * u * v = -p) :
    (u + v) ^ 3 + p * (u + v) = u ^ 3 + v ^ 3 := by
  have h0 : (3 * u * v + p) = 0 := by linarith [h]
  calc (u + v) ^ 3 + p * (u + v)
      = (u ^ 3 + v ^ 3) + (3 * u * v + p) * (u + v) := by ring
    _ = u ^ 3 + v ^ 3 := by rw [h0, zero_mul, add_zero]
```

展开式 (u+v)³ + p(u+v) = u³ + v³ + (3uv + p)(u+v) 由 `ring` 直接验证——
**换元 u+v 的全部魔力都在括号项归零**。文件还验证：韦达定理 2 次
（x² − (r₁+r₂)x + r₁r₂ = (x−r₁)(x−r₂)）与 4 次的展开恒等式、
t³−7t+6 = (t−1)(t−2)(t+3) 的因式分解与三根逐一代入、
判别式 Δ = 9 − 343/27 = −100/27 < 0 的 `norm_num` 判定。

**韦达定理 5.12 的替换证书**（本章新增）——三个条件（伸缩 t² = −4q/3、
c 的定义式 t³c = −4r、三倍角 4u³−3u = c）合起来直接把 (tu)³ + q(tu) + r
打成零，一行 `linear_combination`：

```lean
example (q r t u c : ℚ) (h1 : 3 * t ^ 2 = -4 * q) (h2 : t ^ 3 * c = -4 * r)
    (h3 : 4 * u ^ 3 - 3 * u = c) : (t * u) ^ 3 + q * (t * u) + r = 0 := by
  linear_combination (t ^ 3 / 4) * h3 + (1 / 4) * h2 + (u * t / 4) * h1
```

证书的读法：目标 = (t³/4)·(4u³−3u−c) + (1/4)·(t³c+4r) + (ut/4)·(3t²+4q)
——三块恰好对应三条件，`linear_combination` 展开即零。整数展示例
(x−2)(x+1)² = x³−3x−2 与两根代入也在列（注意 cos 表是
{1, −1/2, −1/2}——手滑写成 {1,−1,−1} 会被机器当场纠正）。

## 30.5 机器验证二：Julia——三次方程全流程

**文件：`examples/julia/30_formulas.jl`**。两个核心函数：

```julia
"""depressed 化归：x³ + ax² + bx + c --(x = t − a/3)--> t³ + pt + q。"""
depress(a, b, c) = (b - a^2 / 3, 2a^3 / 27 - a*b / 3 + c)

"""卡尔达诺公式全分支（复数域）。
u³ = A = −q/2 + √Δ；相伴立方根直接锁死约束 3uv = −p（v = −p/(3u)），
由恒等式 AB = −p³/27 自动保证 v³ = B——若分别取 A、B 的主立方根，
乘积 uv 未必落在正确分支上。"""
function cardano(p, q)
    Δ = q^2 / 4 + p^3 / 27
    A = -q / 2 + sqrt(complex(Δ))
    u = A ^ (1 / 3)
    v = -p / (3u)                    # 3uv = −p（⟹ v³ = −p³/(27A) = B）
    ω = exp(2im * π / 3)
    [(u * ω^k + v * ω^(-k)) for k in 0:2]
end
```

`v = -p / (3u)` 这一行是实现里最值得停留的地方：**立方根有三个分支，
u 与 v 不能独立取**——它们必须满足 3uv = −p，否则 t = u+v 不满足
原方程（本章开发时曾用 v = B/u 的"想当然"版本，三个根的残差是
O(10)，机器验证当场抓出）。由恒等式 AB = (−q/2)² − Δ = −p³/27，
取 v = −p/(3u) 自动保证 v³ = B，约束一次锁死。

断言组：(1) **depressed 化归**：x³−6x²+11x−6（根 1,2,3）→ t³−t
（t 根 −1,0,1）；(2) **卡公式取根**：t³−7t+6（根 −3,1,2，Δ<0）
复路取实部后残差 < 1e-9；(3) **Δ>0 分支**：t³−1 得根 1, ω, ω²，
逐根 |z³−1| < 1e-12；(4) **不可约情形**：t³−3t+1（Δ = −3/4 < 0，
三实根 ≈ {−1.8794, 0.3473, 1.5321}）——"实答案走复路"的现场；
(5) **整条流水线**：一般三次 → depress → cardano → 回移 x = t−a/3，
x³−6x²+11x−6 的三根 {1,2,3} 全回收；(6) **韦达定理**：随机三次
50 组逐根核对；(7) **韦达三角解**（本章新增）：`viete(q, r)` 实现
t = √(−4q/3)、cos3θ = −4r/t³、根 = t·cos(θ+120°k)；整数例
{2,−1,−1} 精确核对，例 5.13 的 x³−7x+6 三根 ≈ {−3,1,2}（残差
< 1e-10，与卡尔达诺复路殊途同归）；(8) **费拉里**：x⁴−9x²+4x+12 = (x+3)(x+1)(x−2)²
经预解三次 s³−ps²−4rs+(4rp−q²) = 0（扫描+二分取最大实根，完全
平方判别 B²−4AC = 0 的断言内嵌）回收四根 {−3,−1,2,2}，q=0 退化
的 x⁴−5x²+4 同样四根 {−2,−1,1,2} 全回收。

## 30.6 机器验证三：Python 与 Prolog

**文件：`examples/python/30_formulas.py`**。sympy 精确代数与数值
实现双轨：depressed 化归的符号展开（`(t+2)³−6(t+2)²+11(t+2)−6
= t³−t`）、与 julia 同构的 `cardano_num`（v = −p/(3u)）、随机
三次 200 组 `nroots` 对拍（逐根残差 < 1e-10；重根案例上 mpmath
高精度反而不收敛，须放宽步数）、判别式分类四案、韦达 + 牛顿
对称函数（幂和 p₁ = e₁、p₂ = e₁²−2e₂、p₃ = e₁³−3e₁e₂+3e₃）
50 组整数核对、费拉里 `ferrari_exact`——预解三次取实根后
**完全平方判别 B²−4AC = 0 是符号零**（sympy `expand` 精确判定，
不是浮点近似），四根回乘还原原多项式，并与 `sympy.factor` 对拍：

```python
def ferrari_exact(p, q, r):
    """预解三次 s³ − ps² − 4rs + (4rp − q²) = 0；任一实根化两个二次。"""
    sroot = [z for z in sp.solve(res, s) if z.is_real][-1]
    A, B, C = sroot - p, -q, sroot**2 / 4 - r
    assert sp.expand(B**2 - 4 * A * C) == 0          # 完全平方（精确零）
    ...
```

（实现细节：二次的根用 `sp.roots` 而非 `solve` 取——后者把
(x−2)² = 0 的重根去重成单根，四根只剩三根。）

韦达部分（本章新增）：**替换的多项式证书**——把 q = −3t²/4、
r = −t³c/4 代入 (tu)³ + q(tu) + r，sympy `expand` 精确验证它等于
t³(4u³−3u−c)/4（三倍角条件一挂即零）；整数例 x³−3x−2 因式分解 +
重根字典 {2:1, −1:2}；例 5.13 的韦达三根与 `sp.roots` 标准答案对拍。

**文件：`examples/prolog/30_formulas.pl`**。整数域精确验证，
卡尔达诺内核在 49 组整数 (u, v) 上逐一核对；韦达部分（本章新增）
是整数展示例：t = 2、cos3θ = 1 的 cos 表 {1, −1/2, −1/2}
（**有理数 rdiv**——cos 值是半整数，手写整数会算出 2·(−1) = −2
的假根，机器当场纠正），两根 2、−1 代入 x³−3x−2 归零：

```prolog
% 3uv = −p ⟹ (u+v)³ + p(u+v) = u³ + v³（整数精确）
kernel_ok(U, V, P) :-
    3 * U * V =:= -P,
    T is U + V,
    L is T*T*T + P*T,
    R is U*U*U + V*V*V,
    L =:= R.
```

其余断言：韦达定理 343 组整数根全过；判别式分类用 27q²+4p³ 的
符号代替 q²/4+p³/27（同号，纯整数）：t³−7t+6（Δ<0，整根
{−3,1,2} 暴力回收）、t³−t（Δ<0）、t³−3t+2 = (t−1)²(t+2)
（Δ=0 重根案，另验导数 3t²−3 在 1 处为零）、t³+3t+2（Δ>0，
无整根）；费拉里恒等式取 16 倍缩放的整系数版
(4x²+2s)² − [16(s−p)x²−16qx+4s²−16r] = 16(x⁴+px²+qx+r)，
在 6 个整数点上核对（四次恒等式 5 点即足）——多点代入法是
Prolog 通道验证多项式恒等式的标准姿势。

## 30.7 要点回顾

1. 三次：depressed 化 → u+v 换元 → 3uv = −p + u³v³ = −p³/27 → 二次。
2. 判别式三分法：Δ>0 单实根、Δ=0 重根、Δ<0 三实根（不可约情形：
   实答案必须走复路——复数合法性的历史起点）。
3. 四次费拉里：配方 + 平方差 + 预解三次——降次链 4→3→2。
4. 拉格朗日预解式：根的置换中不变量决定可解性；n = 5 链条断裂。
5. 韦达定理是对称函数的第一课：系数 = 根的对称函数；伽罗瓦理论
   把"对称"变成"群"，下一章兑现。
6. 韦达三角解（定理 5.12）：三实根情形 v = t·cos(θ+120°k)，
   t² = −4q/3、cos3θ = −4r/t³——用三倍角恒等式替代开立方，
   实根不再绕道复数；判别式 > 0 时由 cosh/sinh 双曲变体接棒
   （"根式解"与"三角解"是两种不同的可解性）。
