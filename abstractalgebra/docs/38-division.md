# 38 广义的除法算式

**对应原书 §7.5（pp. 406-414）。**

---

## 38.1 为什么要为难"除法"

一元多项式的除法算式（第 17 章）是整个消元法的引擎：带余除法、
Eisenstein 判别、分裂域构造全都靠它。多元多项式 k[x₁,…,xₙ] 里
没有天生的"xⁿ > x^{n−1}"——**单项式必须先排队**。本章做两件事：
给 ℕⁿ 一个好序（单项式序），然后重建除法算式。代价出人意料：
多元除法的**余式不再唯一**——这个缺陷正是下一章 Grobner 基的
全部动机。

> **定义** f 的项 c x^α 的**多重次数**是 α = (α₁,…,αₙ) ∈ ℕⁿ。

## 38.2 单项式序：良序 + 乘法相容

> **定义**（7.5.1 节）**单项式序**是 ℕⁿ 上的良序 ≤，满足
> (i) α ≤ β ⟹ α + γ ≤ β + γ（与乘法相容）；
> (ii) 每个 α ≠ 0 有 α > 0（常数最小）。

两个标准款（命题 7.54/7.57 证明它们确是单项式序）：

- **字典序 lex**：α >lex β 若 α−β 的第一个非零坐标为正——
  x₁ 的指数压倒一切；
- **次数-字典序 grlex**（原书主用）：先比总次数 |α| = Σαᵢ，
  平局时按字典序。

第三款 grevlex（总次优先，平局比**最后**一个非零差、小者优先）
在计算实践中更快——机器通道把三款都实现了，并在 9 个单项式的
小世界里枚举核对三条公理：**反对称、完全、乘法相容**。

> **定义** 固定单项式序后 f 的**首项** LT(f) = c_α x^α（α 最大）。
> 命题 7.58：LT(fg) = LT(f)·LT(g)（相容性的直接推论）。

## 38.3 多元除法算式

> **定理 7.60（除法算式）** 固定单项式序与**有序**多元组
> G = [g₁,…,g_m]。任何 f 可写成
> f = q₁g₁ + ⋯ + q_m g_m + r，
> 其中 r 的任何单项式都不被任何 LT(gᵢ) 整除（r "既约"），
> 且 qᵢ 的单项式在过程中严格下降。r 称 **f mod G 的余式**。

算法就是一元版的双循环推广：反复拿 LT(f) 试除各 LT(gᵢ)
（**按 G 的固定次序**），除得动就消；全都除不动就把 LT(f) 搬进
余式。终止性由"每次操作 LT 严格下降 + 良序无无穷降链"保证
（命题 7.53 的用武之地）。

原书的警示例（机器三通道全部复演）：f = xy² − x，
G = [xy+1, y²−1]：

- 按此序除：余式 r = **−x − y**；
- 换序 G' = [y²−1, xy+1]：余式 r' = **0**。

**同一个 f、同一个理想、不同的余式**——甚至可以 r ≠ 0 而
f 就在理想中。多元余式因此**不能**当理想成员判据。第 39 章
的 Grobner 基就是让"余式唯一且 f ∈ I ⟺ r = 0"成立的那些
好基。

## 38.4 机器验证一：Lean——恒等式证书

**文件：`examples/lean/Abstractalgebra/Ch38Division.lean`**。
除法算法本身是程序性的（三通道实现），Lean 通道验证它输出的
**分解恒等式**（定理 7.60 的核心承诺 f = Σqᵢgᵢ + r）：

```lean
-- f = x²y + xy² + y² 除以 [xy−1, y²−1]（lex）：
-- q₁ = x+y、q₂ = 1、余式 r = x + y + 1
example : ∀ x y : ℚ,
    (x * x * y + x * y * y + y * y)
      = (x + y) * (x * y - 1) + 1 * (y * y - 1) + (x + y + 1) := by
  intro x y; ring
```

顺序依赖的两组证书（余式 −x−y 与 0）同样各一行 `ring`；
命题 7.58 的个案：(2x²+3)(5xy³−7x) 的首项 10x³y³ 由完整展开
核对。（注意：除法过程中 lex 下 x 的次数 1 会压过 y² 的总次 2——
首项比较先看首坐标。手推时最容易在此出错，机器通道同样踩过：
julia 与 Lean 的第一次对账各给出不同商形，原因都是平局处理。）


## 38.5 机器验证二：Julia——除法机器

**文件：`examples/julia/38_division.jl`**。多项式 =
`Dict{指数向量 → 有理系数}`：

```julia
comp-free 实现：leading_term(f, ord) 按 ord 扫最大指数；
divide(f, fs, ord) 双循环（先到先得），商累积在 quot[j]。
```

断言组：(1) **序公理枚举**——lex/grlex/grevlex 在 9 个单项式上
反对称、完全、乘法相容（含 a > b ⟹ a+c > b+c 的三重量化）；
(2) 三款序对同一多项式给出不同首项（lex 首项 x₁ vs grlex/grevlex
首项 x₂x₃²）；(3) 原书除法例：f = x²y+xy²+y² mod [xy−1, y²−1]
余式 x+y+1 + **分解恒等式 f = Σqᵢgᵢ + r 整体核对**（商的具体
形状依赖平局选择，恒等式才是定理的承诺）；(4) 顺序依赖例：
−x−y vs 0。

## 38.6 机器验证三：Python 与 Prolog

**文件：`examples/python/38_division.py`**。与 Julia 同构
（Fraction 精确系数），加一层 **sympy 对拍**：
`G.reduce(xy²−x)` 在 Grobner 基下余式唯一为 0，与手算换序版
一致——Grobner 前后的余式行为差异在此埋点。命题 7.58 个案
（首项乘法）同款核对。

**文件：`examples/prolog/38_division.pl`**。多项式 = `(I-J)-C`
对表；`merge_terms` 排序合并是全章地基——其"相邻同键合并"
子句有两个经典坑（本章调试实录）：**切割过猛**把"不同键相邻"
的分支堵死（combine_runs 失败）；合并出的零项必须**回灌递归**
重新检查，直接拼进输出会让 0 系数项存活、除法循环永不终止。
除法 `divide/4` 与顺序依赖例（−x−y vs 0）三值一致。

## 38.7 要点回顾

1. 单项式序 = 与乘法相容的良序（命题 7.53/7.54/7.57）；
   lex 与 grlex 是两件标准兵器，grevlex 是计算实践的优选。
2. 除法算式（定理 7.60）对**有序**多元组成立：f = Σqᵢgᵢ + r，
   r 既约；终止性靠良序无降链。
3. 余式依赖被除式的**次序**——xy²−x 的 −x−y vs 0 是最短警示；
   多元余式不是理想成员判据。
4. 修复方案预告：让"每一步的消首都不再回头"的基 = Grobner 基
   （下一章）——余式唯一、成员判定完备、消元三角形。
