# 35 素理想与极大理想

**对应原书 §7.1（pp. 516-521）。**

---

## 35.1 商环的"素数们"

第 18 章把理想比作"正规子群的环论版本"；现在要问：哪些理想在商环里
行为良好？两条判别标准主宰一切：

> **命题 7.1（对应定理）** I 是交换环 R 的真理想，则自然映射
> π : R → R/I 诱导 R 中含 I 的理想与 R/I 的理想之间的一一对应
> （J ↦ π(J)）。特别地 R/I 是域 ⟺ 没有理想严格介于 I 与 R 之间。

> **定义** 真理想 I 是**素理想**，若 ab ∈ I ⟹ a ∈ I 或 b ∈ I；
> I 是**极大理想**，若没有理想 J 满足 I ⊊ J ⊊ R。

> **命题 7.5** I 素 ⟺ R/I 是整域。
> **引理 7.6** (0) 极大 ⟺ R 是域。
> **命题 7.7** I 极大 ⟺ R/I 是域。

于是有一条不等式链：**极大 ⟹ 素**（推论 7.8——域是整域），
反向一般不真。素理想把"乘法结构的不可约性"翻译成"商的整性"——
这是第 20 章"ℤ 中 (p) 素 ⟺ p 素数"的推广。

**ℤ 与 ℤ/n 的完全清单**（机器通道的主战场）：ℤ 是 PID，理想全是
(d)。(d) ⊇ (e) ⟺ d | e。商 ℤ/(d) ≅ ℤ/d：

- (p) 极大 ⟺ ℤ/p 是域 ⟺ p 素数；
- (p) 素 ⟺ 同上（ℤ 是 PID，非零素理想皆极大——定理 7.11）；
- ℤ/12：理想 (1),(2),(3),(4),(6),(12) 六个；(2)、(3) 极大
  （商 ℤ/2、ℤ/3 是域），(4)、(6) 非素（商 ℤ/4、ℤ/6 有零因子
  2·2 = 0、2·3 = 0）。

> **定理 7.11（PID 中素 = 极大）** PID 的非零素理想都是极大的。

**证明骨架**：素理想 (p) 与极大之间插进理想 (d)，p | d | r（某 r）。
p 素 ⟺ p 不可约 ⟹ d 与 p 相伴或 d 是单位——没有中间层。∎

## 35.2 造域术：k[x]/(不可约)

> **推论 7.12** p(x) ∈ k[x] 不可约 ⟹ k[x]/(p) 是域。

这是"从现有域造新域"的正规手段——第 22 章的有限域 GF(pⁿ) 全部
由此而来。最小的非平凡例子：GF(4) = ℤ/2[x]/(x²+x+1)。四个元素
0、1、x、x+1，乘法按 x² ≡ x+1 归约——机器通道逐格验证封闭性与
可逆性。

> **推论 7.10** (x₁−a₁, …, xₙ−aₙ) 是 k[x₁,…,xₙ] 的极大理想。

（商同构于 k——"在点 a 处求值"的核。）第 38 章将看到：k 代数闭时
这已是**全部**极大理想（定理 7.45）——几何与代数在此接轨。

**素而不极大的例子**：ℤ[x] 的 (x)。商 ℤ[x]/(x) ≅ ℤ 是整域非域。
在 PID 之外，"素 ≠ 极大"是常态——分层（维数）的代数萌芽。

## 35.3 局部环与一点展望

原书随后定义**局部环**（唯一极大理想的环）并证明每个真理想都含于
某个极大理想（Zorn 引理，推论 7.27 的第一版）。本章机器面集中在
有限环上，把"素/极大"的全部判别都做成了可枚举的算术。

## 35.4 机器验证一：Lean——域实例与零因子

**文件：`examples/lean/Abstractalgebra/Ch34Ideals.lean`。**
ℤ/p 是域在 mathlib 里是带条件实例（需要 `Fact (Nat.Prime p)`）：

```lean
instance fact5 : Fact (Nat.Prime 5) := ⟨by decide⟩

example : Field (ZMod 5) := inferInstance
```

注意实例要从 `Mathlib.Algebra.Field.ZMod` 定向导入（`Data.ZMod.Basic`
里没有）。反向的"非素"用零因子 witnesses：ℤ/6 中 2·3 = 0 且
2、3 ≠ 0（`decide`），⟹ ℤ/6 非整域 ⟹ (6) 不素。最有分量的一条：

```lean
-- ℤ/p² 中 (p) 素：ab ≡ 0 (mod p) ⟹ a ≡ 0 或 b ≡ 0 (mod p)（25 格全枚举）
example : ∀ a < 25, ∀ b < 25, (a * b) % 25 = 0 → a % 5 = 0 ∨ b % 5 = 0 := by
  decide
```

理想格的计数由 `(List.range 13).filter (fun d => 12 % d == 0)` 直接
枚举（6 个除数）；极大性的商环判别归约为 ℤ/d 是否域的素性判定
（`Nat.Prime 2` 真、`Nat.Prime 4` 假）。

## 35.5 机器验证二：Julia——理想格与 GF(4)

**文件：`examples/julia/35_ideals.jl`**。ℤ/n 的理想 (d) 表示为
`Set((d*k) % n for k in 0:n-1)`，包含关系即整除：

```julia
for a in 1:12, b in 1:12
    if 12 % a == 0 && 12 % b == 0
        @assert (zn_ideal(12, a) ⊇ zn_ideal(12, b)) == (b % a == 0)
    end
end
```

**注意商环方向的算术**：理想 (d) ⊆ ℤ/n 有 n/d 个元素，商环 ≅ ℤ/d
（不是 ℤ/(n/d)）——本章开发时曾把两者对调，机器立即抓出。整域/域
的暴力判定 `zn_is_domain`/`zn_is_field` 扫描 n ∈ 2..20：域 ⟺ 素
⟺ 整域（有限整域是域）。GF(4) 用系数对 (c₀, c₁) 实现，乘法
`(c₀+c₁x)(d₀+d₁x)` 按 x² ≡ x+1 归约，断言封闭、非零可逆、无零
因子。

## 35.6 机器验证三：Python 与 Prolog

**文件：`examples/python/35_ideals.py`**。同构的理想格机器 +
`sp.isprime` 对拍素性；GF(4) 走 sympy 的 `sp.rem(…, modulus=2)`
做模 2 归约，`gf4_reduce` 封闭性与 `x*x ≡ x+1` 逐项核验；
ℤ[x]/(x) ≅ ℤ 用"多项式模 (x) 只剩常数项"呈现。

**文件：`examples/prolog/35_ideals.pl`**。`zn_domain/1` 与
`zn_field/1` 是纯枚举谓词（找零因子/找逆），2..20 全扫描；
ℤ/12 的包含-整除对应 `subset/2` 与 `mod` 双向核对；(p) ⊂ ℤ/p²
的素性 forall 枚举；GF(4) 乘法表 `gf4_mul/3` 三行实现
（ω² = ω+1 的 mod 2 算术）。

## 35.7 要点回顾

1. 素理想 ⟺ 商是整域；极大理想 ⟺ 商是域；极大 ⟹ 素（7.5/7.6/7.7/7.8）。
2. ℤ 与 ℤ/n 的理想格 = 除数格：(a) ⊇ (b) ⟺ a | b，商 ℤ/n/(d) ≅ ℤ/d。
3. PID 中非零素 = 极大（定理 7.11）；PID 之外常见"素而不极大"
   （ℤ[x] 的 (x)）。
4. k[x]/(不可约) 造域（推论 7.12）：GF(4) = ℤ/2[x]/(x²+x+1) 是
   最小的标本；一般 GF(pⁿ) 是第 22 章的机器主场。
5. (x₁−a₁,…,xₙ−aₙ) 型极大理想（推论 7.10）是"求值同态"的核，
   为第 38 章的 ℂ[x] 极大理想完全分类埋线。
