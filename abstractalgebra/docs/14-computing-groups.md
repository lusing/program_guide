# 14 用群计算：伯恩赛德与 Pólya

**对应原书 §2.8（pp. 205-213）。**

## 14.1 数对象的正确姿势

原书本节的口号是"应用群论做精妙的计算"。问题的公共形状：**给 n 个
位置染色 q 种颜色，两个染色若被某个对称变换互变则视为相同——问本质
不同的染色有多少？**

- 项链：n 珠 q 色，旋转（或再加翻转）视为相同；
- 旗子：n 条纹 q 色，整面旗翻转视为相同；
- 棋盘：n×n 格 q 色，旋转 90° 的幂视为相同；
- 赌盘：n 扇形 q 色，旋转视为相同。

错误做法是直接 qⁿ 除以"对称个数"—— orbits 大小不齐（单色旗被翻转
固定不动，轨道只有 1 个元素），除法失真。正确做法由两步组成：把
"本质相同"公理化成一个群作用，然后数**轨道**。

## 14.2 伯恩赛德引理

> **引理 2.157** (i) G_{g·r} = g G_r g⁻¹；(ii) |G_{τ·r}| = |G_r|。
> **定理（伯恩赛德引理）** 有限群 G 作用在有限集 X 上，则轨道数
>   N = (1/|G|) Σ_{τ∈G} |Fix(τ)|，Fix(τ) = {x : τ·x = x}。

**证明（数表格法）** 列出 |G| × |X| 的表格，(τ, x) 格打钩当 τ·x = x。
按**行**数：第 τ 行的钩数 = |Fix(τ)|，总钩数 = Σ|Fix(τ)|。按**列**数：
第 x 列的钩数 = |G_x|；一条轨道 O 内各点的稳定子互相共轭、等大小
（引理 2.157），每列恰 |G_x| 个钩、每轨道恰 |G| 个钩，总钩数 = N·|G|。
两个总数相等。∎

**例（旗子）** 6 条纹 3 色、允许整面翻转（群 G = {e, t} ≅ ℤ₂ 作用在
条纹位置上）：
  N = (3⁶ + 3³)/2 = (729 + 27)/2 = **378**。
（翻转 t 的不动点 = 回文染色：前 3 条任染、后 3 条镜像。）

**例（项链）**（第 13 章已算）2 色 6 珠：旋转群 ℤ₆ 给 N = (1/6)Σ 2^{d}
= 14；加上翻转（二面体 D₆）给 13。

## 14.3 Pólya 计数定理

伯恩赛德要求逐个群元素数不动点；当 X = 全体染色、G 是位置上的置换群
时，不动点数有一个闭式：

> **定理 2.163（Pólya）** 设 G 作用在位置集 {1, …, n} 上，从而作用在
> q-染色集合上（g·(c₁,…,cₙ) 重排坐标）。若 τ 的完全分解有 t(τ) 个
> 循环，则 |Fix(τ)| = q^{t(τ)}，且本质不同染色数为
>   N = (1/|G|) Σ_{τ∈G} q^{t(τ)}。

理由：τ 固定一个染色 ⟺ 同一循环内的位置全部同色——t(τ) 个循环各自
独立选色，q^{t(τ)} 种。∎ 再把"逐 τ 数循环"打包成母函数（**循环指标**
多项式 Z_G = (1/|G|) Σ τ 的循环结构单项式），N = Z_G 在"所有变量 = q"
处的取值。

**例 2.159/2.163（4×4 双色棋盘）** 旋转群 C₄ 作用在 16 格上：恒等
16 个循环（2¹⁶），R₉₀/R₂₇₀ 各 4 个循环（2⁴），R₁₈₀ 8 个循环（2⁸）：

  N = (2¹⁶ + 2·2⁴ + 2⁸)/4 = (65536 + 32 + 256)/4 = **16456**。

16 位染色共 65536 种，旋转等价把宇宙压缩到 1/4 附近但不恰好 1/4
（16456 × 4 = 65824 ≠ 65536）——差额正是被非平凡旋转固定的"高对称"
棋盘。**轨道大小不齐，除法失效，Pólya 修正它**。

习题 2.139/2.140 把同一模板搬到 n×n 棋盘与 n 扇形赌盘，公式
(棋盘) N = (q^{n²} + q^{⌈n²/2⌉}·? + 2q^{⌊(n²+1)/2⌋}?)…——精确形状
交给机器通道逐一验证，不背公式。

## 14.4 群计算综述：本篇的工具箱

第二篇（第 07-14 章）至此合龙。回头看，"用群计算"的全部本钱是四件
工具，按威力排序：

1. **拉格朗日**（第 10 章）：|H| ∣ |G|，元素阶 ∣ |G|——一刀切掉不可能。
2. **轨道-稳定子**（第 13 章）：|O|·|G_x| = |G|——把"对称性大小"变成
   可整除性论证；类方程是它的共轭版。
3. **同态 + 第一同构定理**（第 11-12 章）：|G| = |ker|·|im|，商群把
   "粘合"精确化——分类循环群、证 φ 乘性全靠它。
4. **Burnside/Pólya**（本章）：数轨道 = 平均不动点——组合计数的群论
   化。

四件工具的共同前身是第 07 章的划分-等价关系与第 01 章的良序归纳——
"抽象代数 = 把计数与结构装进同一台机器"。

## 14.5 机器验证一：Lean——Pólya 的循环数账本

**文件：`examples/lean/Abstractalgebra/Ch14Computing.lean`。**
90° 旋转用**循环字**直接写出（`List.formPerm` 把 [0,4,8,12] 变成循环
(0 4 8 12)），四个循环相乘：

```lean
-- r90 = (0 4 8 12)(1 5 9 13)(2 6 10 14)(3 7 11 15)：四个 4-循环
def r90 : Equiv.Perm (Fin 16) :=
  (List.formPerm [0, 4, 8, 12] *
   (List.formPerm [1, 5, 9, 13] *
    (List.formPerm [2, 6, 10, 14] * List.formPerm [3, 7, 11, 15])))

-- 转四下回家、转两下不回家（阶 = 4）
example : r90 ^ 4 = 1 := by native_decide

example : r90 ^ 2 ≠ 1 := by native_decide

-- 循环数 t(τ)：r90 与 r270 各 4 个循环因子，r180 = r90² 恰 8 个
example : r90.cycleFactorsFinset.card = 4 := by native_decide

example : (r90 ^ 2).cycleFactorsFinset.card = 8 := by native_decide
```

四个 t(τ) 值（恒等 16、r90 4、r180 8、r270 4）备齐后，Pólya 公式的
三项和 `(2^16 + 2·2^4 + 2^8)/4 = 16456` 由 `norm_num` 一步收尾——
例 2.161 的机器版。

## 14.6 机器验证二：Julia——四个计数现场的 Burnside/暴力双跑

**文件：`examples/julia/14_polya.jl`** 实现通用 Pólya 计数器：

```julia
"""Pólya：群元素以循环表给出（cycles(g) = [[i₁,i₂,…], …]）。"""
polya(cycles_list, q) =
    sum(cs -> BigInt(q)^length(cs), cycles_list) // length(cycles_list)

"""暴力对拍：枚举全部染色，按轨道归并计数。"""
function brute_orbits(action, G, positions, q)
    colorings = Iterators.product(fill(1:q, length(positions))...)
    seen = Set{Vector{Int}}()
    for c in colorings
        v = collect(c)
        v in seen && continue
        orbit = Set([action(g, v) for g in G])
        union!(seen, orbit)
    end
    length(seen)
end
```

断言组（全部 Burnside/暴力双跑吻合）：(1) 6 条纹 3 色旗 = 378；
(2) 2 色 6 珠项链：旋转 14、二面体 13；(3) **4×4 双色棋盘 = 16456**
（暴力枚举 65536 个染色按 C₄ 轨道归并）；(4) 5 扇形 2 色赌盘
（习题 2.140 形态）：(2⁵ + 2 + 2 + 2 + 2)/5 = 8；(5) 循环指标交叉：
ℤ₆ 的 Z = (x₁⁶ + x₂³ + 2x₃² + 2x₆)/6 在 q = 2 取值 = 14，q = 3 取值
= 92——项链公式的两例。

## 14.7 机器验证三：Python 与 Prolog

**文件：`examples/python/14_polya.py`**：复算 Julia 五组断言，并把
n = 1..10 的 2 色/3 色旋转项链数列成表，与闭式

**文件：`examples/prolog/14_polya.pl`**：

```prolog
% Pólya：q^(循环数) 的平均值
polya(GroupCycles, Q, N) :-
    length(GroupCycles, G),
    sum_list_counts(GroupCycles, Q, S),   % Σ q^t(τ)
    S mod G =:= 0,
    N is S // G.
```

文件对旗子（t 的循环结构 = 3 个 2-循环：t(τ) = 3+3? ——以条纹位置

## 14.8 要点回顾

1. 计数问题三步：公理化等价（= 群作用）→ 数轨道 → Burnside/Pólya。
2. Burnside：轨道数 = 不动点数的群平均；证明是"数表格"（行和 = 列和）。
3. Pólya：τ 的不动染色 = q^{t(τ)}（t = 循环数）；循环指标多项式把
   全部 q 一次打包。
4. 名场面：6 条纹 3 色旗 = 378；2 色 6 珠项链 14（旋转）/13（含翻转）；
   4×4 双色棋盘 = 16456——直接除以 |G| 都会算错。
5. 第二篇工具箱合龙：拉格朗日 → 轨道-稳定子 → 同构定理 → Pólya，
   全部植根于第 07 章的"等价关系 = 划分"。
