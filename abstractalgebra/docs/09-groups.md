# 09 群的定义与例子

**对应原书 §2.3（pp. 121-143）。**

---

## 9.1 公理：三条换一个宇宙

> **定义** 群 (G, *) 是带运算 * 的集合，满足：
> (i) **结合律**：(a*b)*c = a*(b*c)；
> (ii) **单位元**：存在 e ∈ G 使 e*a = a*e = a 对一切 a；
> (iii) **逆元**：对每个 a 存在 a⁻¹ 使 a*a⁻¹ = a⁻¹*a = e。
> 若再满足交换律 a*b = b*a，称**阿贝尔群**（abelian）。

请立刻把前三章的存货清点一遍，它们全是群：

| 群 | 运算 | 单位元 | 阿贝尔？ |
|---|---|---|---|
| (ℤ, +) | 加法 | 0 | ✓ |
| (ℚ*, ·), (ℝ*, ·), (ℂ*, ·) | 乘法 | 1 | ✓ |
| (ℤ/mℤ, +) | 模加 | [0] | ✓ |
| ((ℤ/mℤ)*, ·)（与 m 互素的剩余类） | 模乘 | [1] | ✓ |
| S_n（第 08 章） | 复合 | 恒等 | ✗（n ≥ 3） |
| 圆群 S¹ = {z : \|z\| = 1} | 复数乘 | 1 | ✓ |
| GL(2, ℝ)（可逆 2×2 矩阵） | 矩阵乘 | I | ✗ |

注意 (ℤ*, ·) **不是**群（除 ±1 外无逆），而 (ℤ/mℤ)* 只在 m 素时才是
全部非零类（第 05 章定理 1.65 的群论读法）。也要注意群公理**不要求**
a*b = b*a——S₃ 已经给出反例：(1 2)(1 3) ≠ (1 3)(1 2)。

公理看似松散，却能立刻挤出性质（原书命题 2.45 / 引理 2.46）：

> **命题 2.45** (i) 单位元唯一；(iv) 逆元唯一；
> (ii) (a*b)⁻¹ = b⁻¹ * a⁻¹；(iii) (a⁻¹)⁻¹ = a。

证明全部是"乘上逆元 + 消去"的标准操作。以 (ii) 为例（袜子鞋子原理：
先穿袜后穿鞋，脱时要先脱鞋后脱袜）：

  (a b)(b⁻¹ a⁻¹) = a (b b⁻¹) a⁻¹ = a e a⁻¹ = e，故 (ab)⁻¹ = b⁻¹a⁻¹。

**消去律**（由 a*c = b*c 两边右乘 c⁻¹ 得 a = b）是群区别于半群的关键
特权——第 07 章"单射"概念的运算化身。

> **定理 2.49（广义结合律）** 结合律自动升级为"任意加括号都相等"：
> n 个因子的积不需要括号。
> **命题 2.51（指数律）** a^{m+n} = a^m a^n，(a^m)^n = a^{mn}；若群
> 阿贝尔还有 (ab)^m = a^m b^m（非阿贝尔时**错**：(ab)² = abab ≠ a²b²）。

> **引理 2.53** a^k = 1 ⟹ ord(a) ∣ k。（证明用除法算式：k = q·ord + r，
> 0 ≤ r < ord，则 a^r = 1，由最小性 r = 0——**除法算式在群论里的复活**，
> 原书还给了理想论的第二证明：⟨ord⟩ = {k : a^k = 1} 是 ℤ 的理想。）

## 9.2 元素的阶

> **定义** a 的阶 ord(a) 是最小正 n 使 aⁿ = e；不存在则称无限阶。

ℤ 中 1 是无限阶；(ℤ/6ℤ) 中 [2] 的阶是 3；S₃ 中 3-循环阶 3、对换阶 2。
命题 2.54（上章已用）给出置换的阶 = 完全分解循环长的 lcm。引理 2.53
则说明 a 的全部幂恰好在 a⁰, a¹, …, a^{ord(a)−1} 里循环。

## 9.3 例外的美感：平面等距与二面体群

原书用 §2.3 的后半构造了两组"看得见摸得着"的群——它们是抽象定义落地的
最佳教具。

**平面等距** Isom(ℝ²)：保持距离的双射（旋转、平移、反射、滑移反射）。

> 等距保持点积与角度（原书 §2.3 正文，英文版 pp. 135-136；中译本编号
> 引理 2.56）。**命题 2.56** 等距把共线三点映为共线
> 三点。**命题 2.57** 固定原点的等距是线性变换。**推论 2.58** 等距是
> 双射；固定原点的等距 = 正交矩阵（O(2, ℝ)）。**命题 2.59** Isom(ℝ²)
> 与 O(2, ℝ) 都是群。

**正 n 边形的对称群** Σ(Π_n)（dihedral group D_n）：

> **定理 2.63** 正 n 边形的对称群是 **2n 阶二面体群**，由旋转 α
>（转 2π/n）与反射 b（关于某对称轴）生成，满足
> αⁿ = 1，b² = 1，bab = α⁻¹。

这三个关系是 D_n 的"身份证"：n = 3 时 |D₃| = 6，元素恰为 1, α, α²,
b, αb, α²b——与 S₃ 同构（正三角形的对称 = 三个顶点的置换）！n = 4 时
D₄（8 元）不再是置换群 S₄ 的全部，而是嵌在其中的"正方形对称"子群。
"关系 bab = α⁻¹"读作：**照镜子后再转，等于先反转再照镜子**——生活中
拧螺丝的左右手版本。

## 9.4 机器验证一：Lean——一般群 + 具体群双轨

**文件：`examples/lean/Abstractalgebra/Ch09Groups.lean`。**
mathlib 的 `Group G` 类型类就是三条公理（结合律、单位、逆）。文件在
**任意群**上复原命题 2.45 的四条：

```lean
-- 单位元唯一：若 e' 也满足 e' * a = a，则 e' = 1
example {G : Type*} [Group G] {e' : G} (h : ∀ a, e' * a = a) : e' = 1 := by
  have h1 : e' * 1 = 1 := by rw [h 1]
  rw [mul_one] at h1
  exact h1

-- 袜子鞋子：(a * b)⁻¹ = b⁻¹ * a⁻¹（mathlib: mul_inv_rev）
example {G : Type*} [Group G] (a b : G) : (a * b) ⁻¹ = b ⁻¹ * a ⁻¹ :=
  mul_inv_rev a b

-- 消去律
example {G : Type*} [Group G] {a b c : G} (h : a * c = b * c) : a = b :=
  mul_right_cancel h
```

（第一例是"乘 1 / 乘逆"的标准操作：e' * 1 = 1 两边一挤；后两例调
mathlib 的正式化 `mul_inv_rev` 与 `mul_right_cancel`——引理名即证明
思路。）具体群轨道走 ℤ₆：以倍数事实呈现元素阶——6·1 ≡ 0 且 2·1、3·1、
5·1 都 ≠ 0（1 的阶恰为 6，生成元），3·2 ≡ 0 而 2·2 ≢ 0（2 的阶为 3），
全部由 `decide` 直接计算（推论 2.84 的 ℤ₆ 版"每元素 ×6 回零"也在列）。

## 9.5 机器验证二：Julia——凯莱表与阶

**文件：`examples/julia/09_groups.jl`** 把群做成**凯莱表**（乘法表），
配上公理自动检查器：

```julia
"""凯莱表是否定义群：封闭/结合律/单位元/逆元 全查。"""
function is_group(tbl::Matrix{Int})
    n = size(tbl, 1)
    all(tbl .>= 1) && all(tbl .<= n) || return false     # 封闭（值域）
    e = findfirst(i -> tbl[i, :] == collect(1:n) && tbl[:, i] == collect(1:n), 1:n)
    isnothing(e) && return false
    all(i -> tbl[i, e] == i == tbl[e, i], 1:n) || return false
    all(i -> any(j -> tbl[i, j] == e, 1:n), 1:n) || return false   # 逆元
    all(tbl[tbl[i, j], k] == tbl[i, tbl[j, k]] for i in 1:n, j in 1:n, k in 1:n)  # 结合律
end
```

三组构造器：`zn_add(n)`（循环群 ℤ_n）、`un_mul(m)`（单位群 U(m)）、
`dihedral(n)`（按定理 2.63 的关系 αⁱbʲ · α^k b^l 化正规形）。断言：
(1) ℤ₅、U(8)、U(10)、D₃、D₄ 的表全部通过群检查（结合律 O(n³) 全查）；
(2) D₃ 的表与 S₃ 的复合表**逐项相等**（同构的有限群版）；
(3) 元素阶扫描：U(8) = {1,3,5,7} 全是 2 阶（Klein 四元群），U(10) ≅ ℤ₄；
(4) αⁿ = 1, b² = 1, bab = α⁻¹ 在生成的 D_n 表上成立（n = 3..6）；
(5) 指数律抽查与非阿贝尔反例 (ab)² ≠ a²b² 在 D₃ 中给出具体数字。

## 9.6 机器验证三：Python 与 Prolog

**文件：`examples/python/09_groups.py`**：复算 Julia 断言（凯莱表检查器
+ 三个构造器 + D₃≅S₃ 表比对），加做**逆元表 vs 元素阶表**的交叉核对
（阶 = 逆元轨道回到 1 的步数），并对 U(16) 打出完整凯莱表观察
"平方根级"结构（1,3,5,7,9,11,13,15 中 2 阶元竟有 3 个）。

**文件：`examples/prolog/09_groups.pl`** 把凯莱表写成事实
`op(G, X, Y, Z)`，公理检查直译：

```prolog
closed(G)    :- forall((elem(G, X), elem(G, Y), op(G, X, Y, Z)), elem(G, Z)).
identity(G)  :- elem(G, E),
                forall(elem(G, X), (op(G, E, X, X), op(G, X, E, X))).
inverses(G)  :- forall(elem(G, X),
                (elem(G, E), member(Y, Glist), op(G, X, Y, E))).
associative(G) :- forall((elem(G,X), elem(G,Y), elem(G,Z),
                op(G,X,Y,XY), op(G,Y,Z,YZ), op(G,XY,Z,L), op(G,X,YZ,R)),
                L == R).
```

（表驱动的 `forall` 在**验证侧**语义正确。）文件构造 ℤ₄、U(8)、D₃ 三张
表，断言四条公理全过；对 D₃ 断言 bab = α⁻¹ 与 b 的 2 阶性——定理 2.63
的关系在表上逐项核验；并计算每元素的阶（`order(G, X, N)` 沿幂轨道走）。

## 9.7 要点回顾

1. 群 = 结合律 + 单位元 + 逆元；阿贝尔是额外语境。清单七例覆盖
   数/剩余类/置换/矩阵/几何对称。
2. 公理挤出性质：单位元与逆元唯一、(ab)⁻¹ = b⁻¹a⁻¹（袜子鞋子）、
   消去律；广义结合律（定理 2.49）让"积"摆脱括号。
3. 阶：a^k = 1 ⟹ ord(a) ∣ k（引理 2.53，除法算式的群论转世）。
4. 二面体群 D_n = ⟨α, b : αⁿ = b² = 1, bab = α⁻¹⟩，阶 2n（定理 2.63）；
   D₃ ≅ S₃，几何对称第一次与置换会师。
5. 凯莱表是有限群的完整快照——四条公理全部可以在表上机械检查。
