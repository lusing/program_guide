# 03 · 四大内置数据结构：集合、序列、函数、记录

对应示例：`../examples/Ch03DataStructures.tla`

TLA+ 建模几乎全靠这四种数据结构。它们是**数学对象**、**不可变**：你不能"修改"一个
集合，只能用 `EXCEPT` 造一个新的。这点和命令式语言很不一样，但正是规格好推理的原因
——没有"别名改了同一块内存"这种烦心事。

本章同样用"单状态 spec + 不变式断言"把每个值实测一遍。本机实测：
`No error has been found`。

## 集合 SET

集合**无序、无重复**：`{1, 2, 2, 3}` 就是 `{1, 2, 3}`，`{1,2,3} = {3,2,1}`。

| 运算 | 写法 | 例 |
|---|---|---|
| 属于 | `x \in S` / `x \notin S` | `2 \in {1,2,3}` |
| 并 | `S \cup T` | `{1,2} \cup {2,3} = {1,2,3}` |
| 交 | `S \intersect T` | `{1,2} \intersect {2,3} = {2}` |
| 差 | `S \ T`（反斜杠） | `{1,2,3} \ {2} = {1,3}` |
| 子集 | `S \subseteq T` | `{1,2} \subseteq {1,2,3}` |
| 基数 | `Cardinality(S)` | `Cardinality({1,2,3}) = 3`（来自 `FiniteSets`） |
| 幂集 | `SUBSET S` | `SUBSET {1,2} = {{},{1},{2},{1,2}}` |
| 摊平 | `UNION S` | `UNION {{1,2},{2,3}} = {1,2,3}` |

> `Cardinality`、`IsFiniteSet` 来自标准模块 `FiniteSets`；`SUBSET`/`UNION` 是 TLA+
> 内置。`SUBSET S` 是"S 的所有子集构成的集合"，`UNION S` 是"把集合的集合摊平成一个"。

### 集合构造：两种核心写法

```tla
{x \in S : P(x)}      \* 从 S 里「筛」出满足 P 的元素（filter）
{f(x) : x \in S}      \* 对每个元素施加 f，收集结果（map）
```

实测：

```tla
{x \in 1..6 : x % 2 = 0} = {2, 4, 6}      \* 筛出偶数
{x * x : x \in 1..4}     = {1, 4, 9, 16}  \* 平方映射
{<<x, y>> : x \in {1, 2}, y \in {"a"}}    \* 多变量 = 笛卡尔积
    = {<<1, "a">>, <<2, "a">>}
```

## 序列 SEQUENCE

序列 = 有限长度的元组，**有序、可重复**，下标从 **1** 开始。`<<1,2,3>>` 本质上
就是"定义域为 `1..3` 的函数"。

| 运算 | 例 | 结果 |
|---|---|---|
| 取下标 | `<<1,2,3>>[2]` | `2` |
| 长度 | `Len(<<1,2,3>>)` | `3` |
| 首元素 | `Head(<<1,2,3>>)` | `1` |
| 去头 | `Tail(<<1,2,3>>)` | `<<2,3>>` |
| 追加 | `Append(<<1,2>>, 3)` | `<<1,2,3>>` |
| 拼接 | `<<1>> \o <<2,3>>` | `<<1,2,3>>` |
| 截取 | `SubSeq(<<1,2,3,4>>, 2, 3)` | `<<2,3>>` |
| 空序列 | `<<>>` | — |

`a..b`（如 `1..3`）是**整数集合** `{1,2,3}`，常用作序列下标域。
`Seq(S)` 表示"S 中元素组成的所有有限序列"的集合（无限集，但能做成员判断）。

## 函数 FUNCTION

TLA+ 的函数是"定义域 → 值"的数学映射。三种关键语法：

```tla
[x \in S |-> e]        \* 构造：在 S 上逐点定义为 e
f[x]                   \* 应用：求值
[S -> T]               \* 函数集合：所有「S 到 T」的函数
[f EXCEPT ![a] = v]    \* 造一个「只在 a 处改成 v」的新函数
DOMAIN f               \* 取定义域
```

实测：

```tla
LET f == [x \in 1..3 |-> x * x]        \* f = {1|->1, 2|->4, 3|->9}
IN
  f[2] = 4
  DOMAIN f = {1, 2, 3}
  f = <<1, 4, 9>>                       \* 1..3 上的函数 ≡ 长度为 3 的序列
  [f EXCEPT ![2] = 99][2] = 99          \* EXCEPT 改一个点 -> 新函数
  [f EXCEPT ![2] = 99][1] = 1           \* 其它点不变
  Cardinality([{1,2} -> {0,1}]) = 4     \* {1,2}->{0,1} 共 2^2 = 4 个函数
```

`EXCEPT` 是 TLA+ 里"改一个不可变值"的标准手段：`![a]` 里的 `!` 代表"当前这个函数/
记录"，`[f EXCEPT ![2] = 99]` 读作"基于 f、把下标 2 改成 99 的新函数"。第 14/15/17
章会大量用它来更新"某进程的 pc""某账户的余额"。

## 记录 RECORD

记录 = 有命名字段的元组，等价于"字段名 → 值"的函数。

```tla
LET p == [name |-> "ada", id |-> 7]
IN
  p.name = "ada"                  \* 点号取字段
  p["id"] = 7                     \* 也可用下标（字段名是字符串）
  p = [id |-> 7, name |-> "ada"]  \* 字段书写顺序无关
  [p EXCEPT !.id = 8].id = 8      \* EXCEPT 改字段，!. 是「当前记录」
  DOMAIN p = {"name", "id"}       \* 记录的「定义域」是字段名集合
```

注意记录改字段用 `!.字段`（点），函数改下标用 `![下标]`（方括号）。

## 小结：该用哪个？

| 你想要 | 用 |
|---|---|
| 一堆无序、不重复的东西（进程集合、账户集合） | **集合** |
| 有序、可重复、按位置访问（缓冲区、消息队列、操作日志） | **序列** |
| 给每个 key 关联一个 value（每进程的状态、每账户的余额） | **函数** |
| 几个固定命名字段打包（一条消息、一个配置） | **记录** |
